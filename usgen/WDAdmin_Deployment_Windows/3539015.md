## Overview
<a name="overview_ELTTEXTE000099"></a>
WDTestSite is used to run several tests on a WEBDEV site.





<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## The various tests
<a name="the_various_tests_ELTTEXTE000123"></a>


- **Stress test**: 
	The stress test consists in simulating the connection of several Web users to a dynamic WEBDEV site. Each of these users executes a sequence of operations (scenario) simultaneously.

- **Regression test**: 
	The regression tests consist in checking the behavior of a WEBDEV site between two updates. The regression test consists in checking whether a scenario performed with an earlier site version still operates properly once the site was updated.

- **Testing a site in multi-user mode**: 
	The test of a site in multi-user mode checks whether concurrent accesses to the data files are handled properly. This test consists in simulating the simultaneous connection of several users to a WEBDEV website. Each of these users executes a sequence of operations (scenario) simultaneously.

- **Comparison of different servers**: 
	WDTestSite compares the speed of different servers. Simply run the same scenario on different servers and compare the scenario execution time.

- **Optimization of processes developed in WLanguage**: 
	WDTestSite compares the execution time of a scenario before and after the WLanguage code is optimized.

<a name="NOTE3_1"></a>


## Main principle of WDTestSite
<a name="main_principle_wdtestsite_ELTTEXTE000147"></a>
WDTestSite is used to:

- create a scenario for a WEBDEV website. This scenario contains a set of actions that must be performed on a WEBDEV website. This scenario should be created on the Web server where the WEBDEV site is deployed.

- run the test of a scenario directly. 

- consecutively run several executions of the same scenario from the same computer or from different computers.

- start the same scenario (simultaneous Web users) from the same computer or from different computers.




For more details, see the online help about WDTestSite.
