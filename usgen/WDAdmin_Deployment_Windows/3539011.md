


## Error messages that can be displayed in the browser
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000771"></a>
This help page presents the different error messages that can be displayed in the browser.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Error message
<a name="error_message_ELTTEXTE000795"></a>
The error messages that can be displayed in the browser are as follows:

| Errors | Designation |
| --- | --- |
| Error opening access log. Check setup | This message is displayed when starting a WEBDEV site. This message is displayed by the OmniHTTPd server. This message can have several causes:<br><br>- the OmniHTTPd server is installed in a directory that uses long names. <br>	**Solution**: Reinstall the OmniHTTPd server in a directory that doesn't use long names.<br><br>- several OmniHTTPd servers are opened. <br>	**Solution**: Close all open servers and restart a single instance of OmniHTTPd.<br><br>- the "Log file" directory does not exist. <br>	**Solution** In the server Control Panel, disable all "Log File" directories and restart the server.<br><br><br> |
| HTTP/1.0 404 Object not found or Resource not found | This message is displayed in the Internet browser when starting the site. This message is caused by a bad configuration of the Internet server. It means that the server cannot find the CGI protocol manager.<br><br>**Solution**: Check the configuration of the Internet Server used, in particular:<br><br>- the virtual directory (or alias) pointing to the directory containing the CGI protocol manager, WD310AWP.EXE<br><br>- the registry key of the CGI protocol manager must be set to WD310AWP.EXE. <br>	Reminder: WEBDEV configuration information is stored in the registry, in the "HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0" entry.<br><br><br> |
| Internet Explorer cannot open the Internet site ... | This message is displayed by the Internet browser when running a WEBDEV website if no Internet server is started when running the site.<br><br>**Solution**: Launch an Internet server before launching a WEBDEV site. |
| Could not resolve local name, Error code: 11004 | This message is displayed when starting the OmniHTTPD server.<br><br>**Solution**:<br><br>1. Open the properties of OmniHTTPD server (right-click the server icon in the taskbar).<br><br>2. Go to the "Server" tab.<br><br>3. Uncheck "Lookup Site Address (Dynamic)".<br><br>4. Validate and restart the server.<br><br><br> |
| RunTime Error .WDD missing or invalid JW06 name | If you are using a WEBDEV site in development mode:<br><br>- Open your project in WEBDEV.<br><br>- Save your project.<br><br><br>If you are using a WEBDEV website with the WEBDEV Application Server:<br><br>- Recompile your project: under "Project", in the "Project" group, pull down "Recompile and synchronize" and select "Recompile project".<br><br>- Regenerate the library.<br><br>- Recreate the setup of your site.<br><br>- Re-install the site on the server.<br><br><br>**Remark**:<br><br>- In all cases, check whether the installation directory of example corresponds to the directory used by the WEBDEV administrator ("Applications" tab).<br><br>- Otherwise: <br><br>	- delete the administrator site. <br><br>	- in the development version, open your project in WEBDEV and click the "GO" icon. <br><br>	- re-install the site on the WEBDEV Application Server.<br><br><br><br><br><br> |
| 1, ERR_MISSING_PAGE | The request is incomplete. It contains no information about the context.<br><br>This error message is displayed during a click on a link that uses an invalid syntax or that points to an HTML page that does not exist.<br><br>Check the syntax used for the link and the existence of page called. |
| 4, ERR_BUTTON_EXPECTED | The request is invalid. The action to perform is missing.<br><br>This error message can be displayed in several cases:<br><br>- a link is specified in the HTML page with the [%URL()%] syntax without button name in the parameters.<br>	**Solution**: <br>	in the parameters of a link, specify the name of button in the WEBDEV page corresponding to the action to perform.<br><br>- a click was performed on a button that only exists in the HTML page. This button does not exist in the page. <br>	**Solution**: <br>	The buttons found in the HTML page must have an equivalent in the corresponding WEBDEV page.<br><br>- a form validation is performed without using a button (JavaScript code) or a validation is performed via the ENTER button. <br>	**Solution**:<br>	A button must be used to perform the validation of a form. <br>	**Tip**: <br>	To enable the user to validate a form using the ENTER key, simply define a button of the "Send field value to server" type in the WEBDEV page, associating the ENTER call letter ("Detail" tab of the field).<br><br><br> |
| 5, ERR_NO_CURRENT_PAGE | The site did not work properly because no page was returned (<u><u><u><u>EndProgram</u></u></u></u> may have been called without returning a page).<br><br>This error message occurs when a WEBDEV website is closed without using the HTML page indicating the end of connection.<br><br>To avoid this message, a page indicating the end of connection must be displayed by <u><u><u><u>PageDisplay</u></u></u></u> or <u><u><u><u>EndProgram</u></u></u></u>. |
| 6, ERR_PARSER | Syntax error in the HTML file named &lt;FILE_NAME&gt;, line &lt;LINE_NUM&gt;.<br><br>An invalid syntax was used in the HTML page displayed.<br><br>Check the code in the HTML controls or the HTML code inserted into the controls of your WEBDEV website ("Advanced" tab in the control description window). |
| 7, ERR_BAD_ACTION | The special action named &lt;ACTIONNAME&gt; is unknown.<br><br>A specific action was defined by the WD_ACTION_ parameter in the HTML page but invalid parameters have been used. You must correct the syntax used to define the action.<br><br>This error can occur when implementing a link used to open or close a secure transaction. Check and correct the syntax used. |
| 8, ERR_NO_PAGE | You want to work on the &lt;PAGE_NAME&gt; page. It does not exist or it is hidden by an object of another type (a control for example).<br><br>The WEBDEV page used is hidden by another object on the server: the corresponding HTML page cannot be displayed.<br><br>This error can occur when using the browser "Back" and "Next" buttons. Check the management mode of the browser "Back" button in your site. |
| 9, ERR_BAD_PARAMETER | The &lt;COMMAND_NAME&gt; command does not contain the proper parameters.<br><br>A specific action was defined by the WD_ACTION_ parameter in the HTML page but invalid parameters have been used. You must correct the syntax used to define the action.<br><br>This error can occur when using a custom action defined for a button or for a link, or when using a link to open or close a secure transaction. Check the syntax used. |
| 10, ERR_BAD_FILE | The &lt;FILE_NAME&gt; file cannot be opened (and therefore returned).<br><br>The HTML file that must be displayed in the browser does not exist. Check the presence of the file in the site directory. |
| 11, ERR_WWADMIN_EXIST | The WEBDEV administrator was already started. A single one is allowed on each computer.<br><br>Several sessions of the WEBDEV administrator (WD310ADMIN.EXE) cannot be started on the same computer. |
| 12, ERR_NO_WWADMIN | The management program of WEBDEV was not started.<br><br>The access to a dynamic WEBDEV website can be performed only if the WEBDEV administrator (WD310ADMIN.EXE) is started and run on the Internet server.<br><br>Check whether the WEBDEV administrator is started on the server. |
| 13, ERR_OUT_OF_MEMORY | Insufficient memory to perform the operation.<br><br>Insufficient memory to run the program.<br><br>Reminder: The resource required for each connected Web user:<br><br>For each connected Web user, you must plan for:<br><br>- about 400 KB of RAM per connection, in addition to the memory required by the server.<br><br>- about 1 MB of disk space per connection.<br><br><br>For example, for 20 parallel connections, you must plan for:<br><br>- RAM: 67.8 MB (7.8 MB of RAM for this site, 60 MB for the NT server)<br><br>- Virtual memory: 84 MB (20 MB for the connections, 64 MB for the NT server)<br><br><br>The number of connections can be limited in the management tool (WD310ADMIN.EXE ) to avoid a drop in the system performance. |
| 14, ERR_MAX_CONNECTION | The connection is refused because the maximum number of connections (&lt;NB_CONNECTION&gt;) allowed by the Webmaster for this site has been reached. Retry later.<br><br>This message is displayed on the Internet browser when the number of connections to the dynamic WEBDEV websites installed at the hosting provider is greater than the total number of authorized simultaneous connections. Check the setting of WEBDEV administrator at the hosting provider. |
| 15, ERR_BAD_COMMANDLINE | The command line passed to the (&lt;ENGINE_NAME&gt;) engine is invalid. The &lt;SWITCH_NAME&gt; switch is missing.<br><br>A WEBDEV website is started from an incorrect command line (bad arguments, ...).<br><br>Check the command line used to start your WEBDEV website. |
| 17, ERR_BAD_CONFIG | The configuration of the &lt;SITE_NAME&gt; site is incorrect for the &lt;VALUE_NAME&gt; value. This error is caused by a wrong site setup in the registry. You must:<br><br>- re-install the site.<br><br>- correct the site configuration in the registry.<br><br><br>Reminder: When a WEBDEV site is installed, a new entry is created in the registry. This new entry is created in the following key:<br>"HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0\\&lt;ProjectName&gt;".<br><br>The project name and directory are specified. |
| 18, ERR_BAD_WEBDEV_CONFIG | Wrong overall WEBDEV configuration. The &lt;KEY_NAME&gt; key is missing or incorrect.<br><br>The WEBDEV setup was not performed properly in the registry.<br><br>Note: WEBDEV configuration information is stored in the registry under "HKEY_LOCAL_MACHINE\\SOFTWARE\\ PC SOFT\\WEBDEV\\31.0".<br><br>An entry is created for each new WEBDEV website. |
| 19, ERR_BAD_CONTEXT | The context to which this request refers (&lt;CONTEXT_NAME&gt;) does not exist (or does not exist anymore). You may have been disconnected.<br><br>This message is displayed by the Web browser when the WEBDEV engine is not active anymore.<br><br>The WEBDEV engine is not active anymore in several cases:<br><br>- the idle time was exceeded: the user has been disconnected. <br>	**Solution** Relaunch the site and, if necessary, set a disconnection timeout in the administrator options in the event of greater inactivity.<br><br>- the HTML page was not refreshed (in test mode only)<br>	**Solution**: Refresh the page display using the "Refresh" button under the Internet browser.<br><br><br> |
| 20, ERR_BAD_URL | The &lt;URL_NAME&gt; URL is not valid.<br><br>This message is displayed when an invalid URL is used in the HTML page.<br><br>In WEBDEV, a URL is valid if it starts with:<br><br>- the following syntax: [%URL()%] for example:<br>	&lt;a hRef="[%URL()%]?Table=[%TABLE%]&RESULT"&gt;<br><br>- a "/" sign: for example:<br>	&lt;a hRef="/Img_WEB/Hello.gif"&gt;<br><br>- the http protocol: for example: <br>	&lt;a hRef="http://flop.www/pages/Index.html "&gt;<br><br><br> |
| 21, ERR_INTERNAL | Internal error: &lt;ERREUR&gt;<br><br>A very rare error occurred.<br><br>Try to establish a reproduction protocol for this error and contact Free Technical Support. |
| 22, ERR_TIMEOUT_REQUEST | The request did not respond within the timeout (&lt;TIMEOUT&gt; seconds).<br><br>An action was requested from the Internet server and the response time has exceeded the timeout specified in the WEBDEV administrator (WD310ADMIN.EXE). The Web user was disconnected.<br><br>Check whether the response time is long enough. |
| 23, ERR_SESSION_CLOSED | You have been logged out.<br><br>The Web user was disconnected by the WEBDEV administrator.<br><br>Reminder: From the WEBDEV administrator, you have the ability to disconnect:<br><br>- a user of a WEBDEV website<br><br>- all users of WEBDEV sites available from the host<br><br><br> |
| 24, ERR_CLOSED_PAGE | The request refers to the &lt;PAGE_NAME&gt; page that does not exist anymore. (it may have been closed by the process).<br><br>This error means that the page corresponding to the HTML page is not available anymore. During a process, the current page may have been closed by a procedure.<br><br>Check the code of your site, especially the existence of context for the page used (with <u><u><u><u>ContextExist</u></u></u></u> for example). |
| 25, ERR_MSG_BOX | The site has generated the following error message &lt;ERROR_MESSAGE&gt;.<br><br>A dialog box was displayed on the server, locking the site. WEBDEV automatically closes the message box and the corresponding message is displayed in the browser.<br><br>Correct the site according to the error message displayed. In most cases, the error corresponds to a programming error found in the site. |
| 26, ERR_BAD_SERIAL_NUMBER | The serial number is invalid.<br><br>The serial number used for WEBDEV is invalid. |
| 27, ERR_SYSCALLFAILED | The call to the &lt;FUNCTION_NAME&gt; system function failed.<br><br>The site tries to use a WLanguage function. The resources required by this function (WEBDEV DLL) are not accessible.<br><br>Make sure that all the DLLs required for your site are on the Web server. |
| 28, ERR_CANNOT_OPEN_FILE | The HTML file named &lt;FILE_NAME&gt; cannot be opened.<br><br>The HTML file corresponding to the WEBDEV page or requested by <u><u><u><u>PageDisplay</u></u></u></u> is not accessible and it cannot be opened. |

Re-install the site and/or check its configuration in the registry.<br><br>**Reminder** When a WEBDEV site is installed, a new entry is created in the registry.<br><br>A new entry is created in the following key:<br><br>"HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0\\&lt;ProjectName&gt;".<br><br>The project name and directory are specified. |
| 33, ERR_BAD_DLLEXE | The &lt;DLL_NAME&gt; DLL is not compatible with this WEBDEV version.<br><br>This message is displayed if:<br><br>- a conflict occurs between the DLLs installed on the computer.<br><br>- the WEBDEV DLLs are not installed properly. Reinstall WEBDEV<br><br><br> |
| 34, ERR_NO_DLLEXE | Unable to load the &lt;DLL_NAME&gt; DLL.<br><br>Some of the WEBDEV DLLs required by the WEBDEV administrator and by the WEBDEV engine have not been copied onto the setup computer. Reinstall WEBDEV. |

Reinstall WEBDEV.<br><br>Reminder: There are:<br><br>- ***WEBDEV Development Version***, used when developing a WEBDEV website.<br><br>- ***WEBDEV Application Server.*** This server must be installed at the hosting provider when deploying a WEBDEV website.<br><br><br> |
