## Common problems
<a name="common_problems_ELTTEXTE000067"></a>
Several problems may occur:

- The AWP protocol manager is not configured properly on the Web server. See [Configuring the Web server for the AWP protocol](../Editeurs/2037005.md).

- The AWP protocol manager (WD310AWP.EXE) is not in the WEBDEV AWP subdirectory. In this case, reinstall WEBDEV.
