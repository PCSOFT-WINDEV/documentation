


## Preparing a Web server for a first deployment

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000094"></a>
Deploying a dynamic WEBDEV website consists in installing the WEBDEV website on a Web server.

Two types of deployment can be done:

- **[Remote deployment (via FTP or HTTP)](../WDAdminDeploiement/3539064.md)**:
	Two types of remote deployment are available: 

	1. **Remote deployment directly from the development workstation**: WEBDEV site managers can deploy their sites directly from the development workstation. The necessary files will be transferred by FTP. This type of deployment is required if the Web server is not directly accessible by the site manager. 

	2. **Remote deployment from an administration workstation**: the developer does not need to know the server's characteristics to create the installation program (called a "Package" in this case).. The server parameters are specified when the package is run on a management computer. 
			This type of deployment is recommended when the developer does not know the server characteristics when creating the setup program.







- **[Deployment by physical media (CD/DVD, etc.)](../WDAdminDeploiement/3539088.md)**: The files required to install the site are transmitted to the server administrator via a physical medium: CD/DVD, ... The server administrator must launch the site installation from the physical medium.
	This type of deployment is possible when the Web server is directly accessible. This type of deployment is available for a Windows server only. 




**Remarks**: For each Web server hosting WEBDEV 2026 dynamic sites, a WEBDEV 2026 Application Server license is required.**Simplified web server configuration**

WEBDEV Application Server version 2026 includes the **WEBDEV Account Manager**. This Control Center simplifies the different steps of the web server configuration. This control center can be run on a computer that uses a server operating system and an IIS server.
