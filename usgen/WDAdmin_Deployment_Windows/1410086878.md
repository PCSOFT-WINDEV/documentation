
## Creating a group of users
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
To be able to globally manage the rights of the Windows accounts that will perform the setups of WEBDEV websites, we advise you to create a group.

In Windows 2008 R2: 
To create a new group of users:

1. Right-click the "computer" and select "Manage".

2. Expand the treeview on the left to see the "Configuration", "Users and local groups" and "Groups" folders.

3. Right-click "Groups" and select "New group...".

4. Create a "WEBDEV_FTP" group. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Deploie_Win_Compte2.gif)





You also have the ability to create a second group for the Windows accounts that will make the Internet sites operate. You have the ability to use an existing group such as the "IUSR_WPG" group (Windows 2008).

In Windows 2010:

1. Start the server manager.

2. In the server manager, expand "Tools" and select "Computer management".

3. Expand the treeview on the left to see the "Configuration", "Users and local groups" and "Groups" folders.

4. Right-click "Groups" and select "New group...".

5. Create a "WEBDEV_FTP" group. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Deploie_Win_Grpe_User.gif&type=thumb)
