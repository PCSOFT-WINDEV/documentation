
## Customize errors
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000203"></a>
The WEBDEV administrator (Deployment version) allows you to customize the error messages of a dynamic WEBDEV website.

On a Linux server, the customization of errors is performed by [the remote administrator](../WDAdminDeploiement/3539019.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Customize errors
<a name="customize_errors_ELTTEXTE000227"></a>
You can customize:

- the error messages for all sites.

- the error messages for a specific site.



<a name="NOTE2_2"></a>


### Customizing the error messages for all sites
<a name="customizing_the_error_messages_for_all_sites_ELTPARAGRAPHE000034"></a>

To customize the error messages for all WEBDEV websites installed on the current computer (and on the Web server during the setup), choose "All sites" in the "Site" combo box.

This customization applies to:

- the text of error messages.

- the page displaying the error message.



<a name="NOTE2_3"></a>


### Customizing the error messages for a specific site
<a name="customizing_the_error_messages_for_specific_site_ELTPARAGRAPHE000048"></a>

To customize the error message for a specific site installed on the current computer (and on the Web server during the setup), choose the name of your site in the "Site" combo box.

This customization applies to:

- the text of error messages.

- the page displaying the error message.



<a name="NOTE2_4"></a>


### Priority order for the customization
<a name="priority_order_for_the_customization_ELTPARAGRAPHE000062"></a>

The priority order for the customization is:

1. customizing all messages for all sites installed on the server.

2. customizing the messages for a specific site.


**Caution**: Customizing error messages is not recommended for all websites when using a shared server. This modification will be applied to all WEBDEV websites installed on the server.

## How to?
<a name="how_ELTTEXTE000269"></a>
To customize the error messages:

1. Select the site that must be customized (specific site or all sites).

2. To customize ***the page used for all errors***:
	By default, the errors are displayed in a specific page. To customize this page:

	- Choose the "Custom" option:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=WDADMIN_Onglets%20-%20HC%20N%B0007%202.gif&type=thumb)


	- Select an HTML page accessible from your computer.
			This must be a static HTML page that may contain images, ...
			Two Static Text controls are optional on this page: the tags [%MSG%] and [%SYS%] correspond to the value of these controls respectively. These controls will be respectively replaced with:

	- the full error message of WEBDEV

	- the text of system error. 

3. To customize ***the error message and/or the error page***:

	- Choose the error identifier: the default caption is displayed.

	- For more details, see [Error messages that can be displayed in the browser](../WDAdmin/3539002.md).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=WDADMIN_Onglets%20-%20HC%20N%B0007%201.gif&type=thumb)


	- Select "Custom caption" and enter the new caption associated with the option. 

- Select "HTML page" and select a specific HTML page to display this error. 
			This must be a static HTML page that may contain images, ...
			Two Static Text control fields are optional on this page: the tags [%MSG%] and [%SYS%] correspond respectively to the value of these fields. These controls will be respectively replaced with:

	- the full error message of WEBDEV

	- the text of system error. 

4. To ***apply the changes***:

	- Click "Apply" to immediately apply the changes to the current computer.

	- Click "Save" to save the changes in a ".REG" file.

	- If the selected site is a specific site, the configuration file is saved in the project directory.

	- If the selected site is "All the sites", the configuration file is saved in the WEBDEV directory.




5. To ***install the modified files***:

	- If the customization applies to a specific site, the remote setup will automatically select the configuration file and will run it on the server. If the HTML file for customizing the error page is in the project images directory (&lt;Project_Name&gt;_Web), it will be automatically installed.

	- If the customization affects all the sites on the server, you must:

		- Optional step: copy (if necessary) the HTML files of error pages and the associated images onto the Web server. 
						These files must be located in a server directory for which an alias was defined.

		- copy and run the ERR_MSG_WEBDEV.REG file on the Web server.
						**Caution**: This customization is an advanced modification, requiring a good knowledge in the management of web servers.
