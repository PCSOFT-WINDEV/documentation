
## Installing WEBDEV Application Server (Windows)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
**Warning**: Installation must be run as a seat administrator after checking the prerequisites. The serial number and the setup key are required.
In this example, we perform a complete installation in the directory: "C:\\WEBDEV2026\\" with the option of hosting sites in earlier versions.
Don't forget to check the option allowing the administrator to be installed as service. Otherwise, you will not be able to connect to the WEBDEV websites if no session is opened on the server.

**The installation steps are as follows**: 

1. Select the setup language. 

2. Select the type of version to install: full version or version 10 connections. In this case, let's install a full version. Enter the serial number and setup key. 

3. Validate the license. 

4. Specify the WEBDEV Application Server installation directory (C:\\WEBDEV 2026 by default). 

5. Select the Application Server mode: "Stand-alone server". 

6. Specify the directory to be used for deployment ("C:\\Sites" by default). 

7. Specify the remote administration site(s) to be installed:

	- The WEBDEV Application Server remote installation site allows you to remotely manage all deployed sites and web services, WEBDEV accounts and application server configuration. 

	- The HFSQL administration site allows you to remotely manage HFSQL databases. 




8. Indicate whether **hosting SaaS sites should be taken into account**. If the "Enable SaaS management" option is selected, a SaaS management site and web service will be installed on the WEBDEV Application Server.  

9. Indicate whether **the replication server should be installed**. The replication server can be used to perform an assisted universal replication. 

10. Indicate whether the **telemetry server** applications (WDAnalytices) should be activated. 

11. In the case of telemetry server installation: 

	1. Specify the characteristics of the HFSQL server used for telemetry (previously installed): <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Install_serveur_telemetrie%20-%20HC%20N%B0003.gif&type=thumb)


		- Name of the HFSQL server, 

- Port. 

- Name and password of the HFSQL server administrator. This information is required to automatically configure the telemetry database and the associated user. 

2. Test the connection to check your parameters. 

3. Specify the parameters specific to the database used for telemetry: 

	- name of the database dedicated to telemetry (TLM by default). 

	- username and password of the telemetry administrator. 

12. Specify whether **BaaS services** are to be activated. These solutions include the User Groupware, an OAuth authentication server and a Private Store. 

13. In the case of BaaS:

	1. Specify the characteristics of the HFSQL server used for WDBaaS modules (User Groupware/Private Store). 
			Note: This HFSQL server must have been previously installed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Install_serveur_store%20-%20HC%20N%B0003.gif)
These characteristics are:

		- Name of the HFSQL server, 

		- Port. 

		- Name and password of the HFSQL server administrator. This information is required to automatically configure the WDBaaS database and the associated user. 




2. Test the connection to check your parameters. 

3. Specify the parameters specific to the WDBaaS database used by the User Groupware/Private Store: 

	- name of the dedicated database: WDBAAS by default. 

	- username and password for the database. 

14. Go to the next step.

15. Indicate whether **access to third-party databases** should be enabled. If this access is enabled, the Application Server will include a specific web service. In this case, you need to specify the web service address. 

16. Specify whether an SSL connection is required for the remote administration sites. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Install_serveur_store%20-%20HC%20N%B0004.gif)


17. Go to the next step.

18. Indicate whether ODBC drivers for HFSQL are to be installed. 

19. Specify advanced installation settings:

	- Activate the application list page. 

	- Prevent access to directories of other WEBDEV accounts. 

	- Enable NTLM/Kerberos authentication. 

	- Indicate whether idle sessions should be terminated. 




20. The setup summary is displayed. 

21. Go to the next step.   

22. The wizard checks for a web server on the client computer. 

	- If no web server is installed, the wizard prompts the user to install and configure one. 

	- If there is a web server on the computer, the wizard configures it so that you can use WEBDEV Application Server. 




23. At the end of the installation, the wizard displays a summary. 




**Once the WEBDEV Application Server is installed**, you can find the web server for which it is configured and the virtual sites in which it is configured at any time.
To do so, you must:

1. Start the interface of WEBDEV administrator.

2. Select the "Advanced" tab and click the "Server" button.

3. Choose the server in the list.

4. Click the "Virtual servers" button.
	In the table, simply check the virtual servers in which you want the WEBDEV Application Server to be configured: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Install_Serveur_appli%20-%20HC%20N%B0001.gif&type=thumb)



You will be able to run one or more dynamic WEBDEV websites (sites in Session or AWP mode) in each virtual server in which the Application Server is configured.

**Important security note:**
As soon as the WEBDEV Application Server is installed, don't forget to change the password of WEBDEV account (ADMIN account). To do so:

1. Start the WEBDEV administrator.

2. On the "Setups/Accounts" tab, click the "Accounts" button.

3. Double-click the "ADMIN" line.

4. On the "General" tab, click the "Password" button.

5. Change the password and confirm.
