## The available statistics
<a name="the_available_statistics_ELTTEXTE000155"></a>
The statistics displayed by WDStatistics are as follows:


|   |   |
| --- | --- |
| <br><br>- ***Dashboard***:<br><br><br> | Dashboard containing:<br><br>- the number of visitors.<br><br>- the number of pages viewed.<br><br>- the average number of pages per visitor.<br><br>- the average number of visitors per day.<br><br>- the average number of pages viewed per day.<br><br>- the maximum number of connections.<br><br>- the minimum number of connections.<br><br>- the date of the last import of log files.<br><br>- the time zone of the site.<br><br>- the type of site (Classic or AWP).<br><br><br> |
| <br><br>- ***Search engines***:<br><br><br> | List of keywords used on the search engines to reach the site. |
| <br><br>- ***Distribution***:<br><br><br> | List of operating systems used by users and browsers. |
| <br><br>- ***Traffic***:<br><br><br> | Chart summarizing the number of visits according to different time slots. |
| <br><br>- ***Geographical view***:<br><br><br> | Breakdown of each visitor by country. |
| <br><br>- ***Pages visited by users***:<br><br><br> | Navigation paths taken by each visitor through the website (time spent on the website and time spent on each page). |
