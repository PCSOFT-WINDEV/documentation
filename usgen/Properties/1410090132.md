
## Linestring (Property)

***In french: Polyligne***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Linestring** property is used to define the different linestrings that constitute a MultiLinestring. This property is available for: 

- a variable of type [MultiLinestringGeo](../WDLang4/1410090133.md). 

- a variable of type [MultiLinestring2D](../WDLang4/1410090131.md).
