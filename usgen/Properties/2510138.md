


## Visible (Property)

***In french: Visible***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Visible** property is used to:

- Determine whether an element is visible.

- Make an element visible or invisible.




This property applies to the:

- controls and groups of controls in a window, page or report.

- report blocks,

- menu options.




**Remarks**:

- In the window editor and in the page editor, the control visibility is defined in the "UI" tab of the control description.

- In the report editor, the control visibility is defined in the "Details" tab of the control description.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The **Visible** property is available for Table control rows.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Make the "EDT_Company" control visible if it is invisible
IF EDT_Company.Visible = False THEN
	EDT_Company.Visible = True
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining whether an element is visible

`<Result> = <Element used>.Visible`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified element is visible,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Element used>: (Type of element)`**

Name of the element to be manipulated.  


<a name="SYNTAXE2"></a>

### Making a control or a report block visible/invisible

`<Element used>.Visible = <Visible/Invisible>`
---

**`<Element used>: (Type of element)`**

Name of the element to be manipulated.

**`<Visible/Invisible>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified element must be visible,

- <u><u><u><u>False</u></u></u></u> if the specified element must be invisible.

## Remarks


### Control attributes
<a name="control_attributes_ELTPARAGRAPHE000107"></a>

The **Visible** property does not modify the other state attributes of the control (selection without input, active or grayed out)
<a name="NOTE0_2"></a>


### Group of controls
<a name="group_controls_ELTPARAGRAPHE000116"></a>

If the specified object is a group of controls, the visibility of all controls from that group changes.

### Determining whether an element is visible in WEBDEV
<a name="determining_whether_element_visible_webdev_ELTPARAGRAPHE000125"></a>

Reading the **Visible** property in WEBDEV can cause issues.. The result of the **Visible** property takes into account the visibility of parent elements.. 

If the **Visible** property is used on one of the controls of a popup page in the server-side code, the result will always be <u><u><u><u>False</u></u></u></u>. The code that displays the popup page is executed on the browser side only. The server cannot determine whether or not the popup page is visible. Therefore, the controls in the popup are always considered invisible (<u><u><u><u>False</u></u></u></u>).

### Controls on tabs
<a name="controls_tabs_ELTPARAGRAPHE000160"></a>

If a control on a tab pane is visible, but the pane is not displayed, the **Visible** property will return <u><u><u><u>False</u></u></u></u>.

### Rows in a Table control
<a name="rows_table_control_ELTPARAGRAPHE000175"></a>A row found in a Table control can be made visible or invisible. For example:


```wl
// Makes the second row of the Table control invisible
TABLE_Table[2].Visible = False
```
If the Table control uses bars with alternated colors, the alternation of colors will be respected.

Note: If the **Visible** property is used on a table cell, none of the cells in the corresponding column will be rendered.

### Action Bar
<a name="action_bar_ELTPARAGRAPHE000193"></a>

The **Visible** property can be used to hide an Action Bar control. 
In this case, an animation is automatically applied when the Action Bar disappears.

The **Visible** property can also be used to show or hide a pane from the action bar (in the navigation bar). In this case, the following syntax must be used: 

```txt
<Action Bar name>[<Index>].Visible
```
where Index represents a view in the Action Bar control. 

For example, to make the second pane invisible, the WLanguage code is as follows: 

```wl
ACTB_ActionBar[2].Visible = False
```




Note: For more details on action bar panes/views, see [Action Bar control description](../WDChamp/1000025005.md). 
<a name="NOTE0_7"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Columns in a Table control
<a name="columns_table_control_ELTPARAGRAPHE000226"></a>

The **Visible** property can be used to hide columns of a Table control.

However, the **Visible** property must not be used in Ajax code to modify columns in non-Ajax Table controls. In this case, columns will be invisible, but column titles will not.
