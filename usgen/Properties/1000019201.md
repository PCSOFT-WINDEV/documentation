


## ZOrder (Property)

***In french: Altitude***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ZOrder** property gets and sets the Z-order of an element. This property can be used on:

For more details, see the help on the [ZOrder](../Proprietes/2510002.md) property.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property can only be used to get the Z-order of a control.
