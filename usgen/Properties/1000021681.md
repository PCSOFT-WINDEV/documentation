


## TransparencyMode (Property)

***In french: ModeTransparence***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **TransparencyMode** property gets and sets the transparency mode of an image.

Note: The transparency mode is set in the editor using the "Transparency" option in the field description window.. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the transparency mode of the image found in the "IMG_CarImage" control
IMG_CarImage.TransparencyMode = trsImage
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the current transparency mode

`<Current transparency> = <Control used>.TransparencyMode`
---

**`<Current transparency>: (Integer constant)`**

Current transparency mode of the image:



|   |   |
| --- | --- |
| *trsTopLeftCorner* | Points of the same color as the top left of the image will be transparent. |
| *trsImage*  | Image transparency is preserved. |
| *trsMagenta* | Magenta in the image will be transparent when displayed. |



**`<Control used>: (Control name)`**

Name of control to use: 

- Image control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image column.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Background of a Chart control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Thumbnail control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Clickable Image control.





<a name="SYNTAXE2"></a>

### Modifying the transparency mode

`<Control used>.TransparencyMode = <New mode>`
---

**`<Control used>: (Control name)`**

Name of control to use: 

- Image control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image column.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Background of a Chart control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Thumbnail control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Clickable Image control.




**`<New mode>: (Integer constant)`**

New transparency mode of the image:



|   |   |
| --- | --- |
| *trsTopLeftCorner* | Points of the same color as the top left of the image will be transparent. |
| *trsImage*  | Image transparency is preserved. |
| *trsMagenta* | Magenta in the image will be transparent when displayed. |

## Remarks


### Background image of a Chart control
<a name="background_image_chart_control_ELTPARAGRAPHE000086"></a>

When modifying the transparency mode of background image found in a Chart control, the chart display must be refreshed (by [grDraw](../WDLang3/3042026.md) for example) in order for the change of transparency mode to appear.
<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000096"></a>

The **TransparencyMode** property can only be used in the following controls:

- Image control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image column.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Background of a Chart control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Thumbnail control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Clickable Image control.
