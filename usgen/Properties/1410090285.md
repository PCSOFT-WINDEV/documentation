
## Grow (Property)

***In french: Agrandissement***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Grow** property defines how much the halo grows around an element in a step of a Guided Tour. This property can be used on:

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
