
## OpeningParameters (Property)

***In french: ParamètresOuverture***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **OpeningParameters** property is used to get and set:

- the parameters passed to the internal window corresponding to the bottom sliding window.
	

- the parameters passed to a window manipulated using its type. 
	



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

**Example for bottom sliding windows:**

```wl
MyBottomSlidingWindow.OnHide = () => { Trace("The bottom sliding window has been hidden") }
MyBottomSlidingWindow.OpeningParameters = (42, "Adams")
MyBottomSlidingWindow.InternalWindow = "IW_Sliding_menu"
MyBottomSlidingWindow.HeightCollapsed = 58 // Value in pixels
MyBottomSlidingWindow.HeightHalfExpanded = swFitToContent
MyBottomSlidingWindow.HeightExpanded = 0.9 // 90% 
MyBottomSlidingWindow.Modal = True
MyBottomSlidingWindow.Hideable = True
MyBottomSlidingWindow.RoundedCorner = False

// Opens the bottom sliding window
WinSlidingVisible(swBottom, swHalfExpanded)
```
<a name="Exemple2"></a>


**Example for window variables:**


```wl
// -- Global declarations of WIN_Calendar 
PROCEDURE WIN_Calendar (sSelDate)
// sSelDate: Date to be selected
```

```wl
My_Calendar_Window is Window WIN_Calendar
// Pass parameters
My_Calendar_Window.OpeningParameters.sSelDate = Today()
// Open window
My_Calendar_Window.Open()
```

## Syntax
<a name="SYNTAXE1"></a>

### Bottom sliding window: Getting the parameter values

`<Result> = <Sliding window>.OpeningParameters`
---

**`<Result>: (Value tuple)`**

Value tuple corresponding to the different values passed to the internal window used as a bottom sliding window. 

**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.


<a name="SYNTAXE2"></a>

### Bottom sliding window: Setting the parameter values

`<Sliding window>.OpeningParameters = <New values>`
---

**`<Sliding window>: ()`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.

**`<New values>: (Value tuple)`**

Tuple of parameter values to be passed to the internal window corresponding to the bottom sliding window. 


<a name="SYNTAXE1B"></a>

### Window variable: Getting the value of parameters passed to the window

`<Result> = <Window used>.OpeningParameters.<Parameter name>`
---

**`<Result>: (Type corresponding to the parameter value)`**

Parameter value. 

**`<Window used>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window used. 

**`<Parameter name>: (Character string)`**

Name of the window parameter with the desired value. 


<a name="SYNTAXE2B"></a>

### Window variable: Setting the value of parameters passed to the window

`<Window used>.OpeningParameters.<Parameter name> = <Value>`
---

**`<Window used>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window used.  

**`<Parameter name>: (Character string)`**

Name of the window parameter with the desired value.

**`<Value>: (Type corresponding to the parameter value)`**

New parameter value.

## Remarks


### Syntax for manipulating an internal window
<a name="syntax_for_manipulating_internal_window_ELTPARAGRAPHE000094"></a>

- A value must be assigned to the **OpeningParameters** property before the [InternalWindow](../Proprietes/1410089635.md) property.

- The internal window will be created when a new value is assigned to the [InternalWindow](../Proprietes/1410089635.md) property.





### Syntax for manipulating a Window variable
<a name="syntax_for_manipulating_window_variable_ELTPARAGRAPHE000108"></a>

- A value must be assigned to the **OpeningParameters** property before opening the window. 

- After opening the window, the **OpeningParameters** property is cleared. 

- After closing the window, the **OpeningParameters** property defines all the options to open the window again.
