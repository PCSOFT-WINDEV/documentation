


## AnchorRateBottom (Property)

***In french: TauxAncrageBas***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AnchorRateBottom** property is used to:

- Find out the anchor rate when a control moves on the vertical axis

- Modify the anchor rate when a control moves on the vertical axis.




The anchor rate is used to define how the control is moved or resized in relation to the evolution of size of window (or report) to which it is anchored. The anchor rate corresponds to the percentage by which the control moves in relation to the window (or report). Therefore, if the anchor rate is set to 0, the control will not be resized. If it is set to 1000, the control will be resized normally.

The bottom anchor rate (**AnchorRateBottom** property) is applied if the control is anchored to the bottom (*anchorBottom* constant used with the [Anchor](../Proprietes/2510001.md) property).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This property can only be used to find out the anchor rate of the report controls.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The List Box control will be resized by 50% relative to the window size
LIST_ListPersons.AnchorRateBottom = 500
```

## Syntax

### Finding out the anchor rate when an anchored control moves to the bottom

`<Result> = <Control used>.AnchorRateBottom`
---

**`<Result>: (Integer)`**

Anchor rate included between 0 (unmoved control) and 1000 (normal anchor).

**`<Control used>: (Control name)`**

Name of the control to be used. This control can be a control: 

- of a window.

### Modifying the anchor rate when an anchored control moves to the bottom

`<Control used>.AnchorRateBottom = <Anchor rate>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.

**`<Anchor rate>: (Integer)`**

New anchor rate included between 0 (unmoved control) and 1000 (normal anchor).

## Remarks


### Anchoring a control

	For more details, see [Anchoring applied to window controls](../WDChamp/2026002.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) In a report, the [Anchor](../Proprietes/2510001.md) property is used to find out how the control is resized or moved when the report is resized. This behavior was defined in the report editor. 
	For more details, see [Anchoring controls in a report](../WDChamp/1013298.md).

### Limits
<a name="limits_ELTPARAGRAPHE000119"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **AnchorRateBottom** property can be used in all the controls of a window.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **AnchorRateBottom** property can only be used in the following controls:

- Button control.

- Static Text control.

- Edit control.

- Image control.

- Check Box control.

- Radio Button control.

- List Box control.

- Combo Box control.

- TreeView control.

- Tab control.

- Table control.

- Supercontrol.
