


## Server (Property)

***In french: Serveur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Server** property is used to manage the data source of a connection (HFSQL Client/Server, OLE DB, etc.). You can:

- Find out the data source used for a connection (HFSQL Client/Server, OLE DB, ...).

- Define the data source used for the connection (HFSQL Client/Server, OLE DB, ...). In this case, when you open a file that uses an open connection, that connection will be closed and reopened with the new parameters.




Warning: if your database is remote and you're using an Internet connection to access it, you'll need to redirect the router's input port to the HFSQL server. For more details, see [Managing ports](../WDLang4/3044334.md).

**Note**: The connection can correspond:

- a connection defined in the data model editor,

- a connection defined with [HConnect](../WDLang4/3044263.md), [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- a connection defined with a variable of type [Connection](../WDLang4/1514073.md).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyConnection is Connection
// Describe the connection
MyConnection.User = "USER"
MyConnection.Password = "PASSWORD"
MyConnection.Server = "MYSERVER" 
MyConnection.Database = "Database"
MyConnection.Provider = hAccessHFClientServer
MyConnection.Access = hOReadWrite
MyConnection.ExtendedInfo = "Extended information"
MyConnection.CursorOptions = hClientCursor
HOpenConnection(MyConnection)
```

<a name="SYNTAXE1"></a>

## Syntax

### Finding out the data source of the connection

`<Data source> = <Connection used>.Server`
---

**`<Data source>: (Character string)`**



- Name of the server (for HFSQL Client/Server, SQL Server, Oracle, MySQL, etc.)

- Name of the file used as data source (for Access, XML, xBase, etc.)




**`<Connection used>: (Character string or Connection variable)`**

Name of the connection used. This name is defined:

- in the data model editor,

- with the [HDescribeConnection](../WDLang4/3044205.md) and [HOpenConnection](../WDLang4/3044107.md) functions,

- with the [Connection](../WDLang4/1514073.md) type.  





<a name="SYNTAXE2"></a>

### Defining the data source of the connection

`<Connection used>.Server = <Data source>`
---

**`<Connection used>: (Character string or Connection variable)`**

Name of the connection used. This name is defined:

- in the data model editor,

- with the [HDescribeConnection](../WDLang4/3044205.md) and [HOpenConnection](../WDLang4/3044107.md) functions,

- with the [Connection](../WDLang4/1514073.md) type.




**`<Data source>: (Character string)`**



- Name or IP address of the server (for HFSQL Client/Server, SQL Server, Oracle, MySQL, ...)

- Name of the file used as data source (for Access, XML, xBase, etc.)  

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **For a connection to an HFSQL Client/Server database on the development computer from an Android emulator**, use the IP address 10.0.2.2 with the server port. Example: "10.0.2.2:4900".

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **For a connection to an HFSQL Client/Server database on the network of the development computer from an Android emulator**, use the full name of the server with the domain. With the WINDEV Mobile simulator, the name of the computer without domain may be sufficient. Example: "Server@domain.com:4900".

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **For a connection to an SQLite database**, full path of the file containing the SQLite database on the Android device.
	Example: /sdcard/bdd/MaBaseDeDonnees.db
	If the parameter corresponds to an empty string (""), the file containing the database data will be created in the "databases" directory of application and its name will be identical to the application name followed by the ".db" extension.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The **Server** and [Source](../Proprietes/2510147.md) properties are equivalent.

These two properties are kept to make the code easier to understand. In the HFSQL Client/Server, SQL Server, Oracle or MySQL connection, the **Server** property is recommended because it is necessary to specify a server name.

However, in an Access, XML or xBase connection, it is recommended to use the [Source](../Proprietes/2510147.md) property because it is necessary to specify a table.
