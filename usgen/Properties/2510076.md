


## Memory (Property)

***In french: Mémoire***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Memory** property determines if the specified control is populated programmatically or is based on a table.

The fields to which the **Memory** are the List, Image control, Combo, Table, Hierarchical Table or RepeatString fields (depending on the product used: WINDEV, WINDEV Mobile or WEBDEV).

**Reminder**: 

- List Box, ListView, Combo Box, Table, TreeView Table and Looper controls **populated programmatically** handle data stored in memory. 

- List Box, ListView, Combo Box, Table, TreeView Table and Looper controls **based on a table** handle data from tables or queries.




**Important: This property is retained by compatibility**. It is recommended to use the [FillType](../Proprietes/1000017723.md) property. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF LIST_List1.Memory = True THEN
	ListAdd(LIST_List1, "Paris")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Control used>.Memory`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the content of the control comes from the additions performed programmatically.

- <u><u><u><u>False</u></u></u></u> if the content of the control comes from a table.




**`<Control used>: (Control name)`**

Name of the control (List Box, ListView, Combo Box, Looper, Table or TreeView table) to handle.

## Remarks


### List Box, ListView, Combo Box and data-bound Table controls based on a table
<a name="list_box_listview_combo_box_and_databound_table_controls_based_table_ELTPARAGRAPHE000069"></a>

The following properties define the records that will be displayed.

- [BrowsedFile](../Proprietes/2510040.md): Name of the base table.

- [BrowsedItem](../Proprietes/2510111.md): Name of the item used to loop through the table and sort records.

- [Filter](../Proprietes/2510042.md): If this filter is not empty, only the records corresponding to the filter will be displayed.

- [AutoBrowse](../Proprietes/2510093.md): Indicates whether the path events associated with the element are used.

### Limit
<a name="limit_ELTPARAGRAPHE000089"></a>
