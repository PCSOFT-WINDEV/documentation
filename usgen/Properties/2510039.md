


## State (Property)

***In french: Etat***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **State** property gets and sets the state: 

- of a control in a window, page or report. 

- of a block in a report,

- of a window. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) **In a window**, the **State** property is used to get and change the state:

- of a window,

- of a control or group of controls,

- of a "container" control (Tab control, Internal Window, Layout, etc.),

- of a cell or row in a Table control,

- of a menu option.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **In a page**, the **State** property is used to get and change the state:

- of a control or group of controls,

- of a "container" control (Tab control, Internal Page, Layout, etc.),

- of a group of controls.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **In a report**, the **State** property is used to get and change the visibility of a control or block. This property is kept for compatibility with WINDEV 5.5 and WEBDEV 1.5. To show or hide a control or a block in a report, use the [Visible](../Proprietes/2510138.md) property.

## Example


```wl
// The STC_Static1 control becomes active
STC_Static1.State = Active
```

### Getting the state of a window or an element in a window

`<Current state> = <Element name>.State`
---

**`<Current state>: (Integer constant)`**

Current status of object.



|   |   |
| --- | --- |
| **Window controls** |
| *Active* | The control is active and editable. |
| *ReadOnlyNoSelection* | For Table fields only: Field displayed, no input possible.<br><br>In this case, the user will not be able to select a row in the Table control using the mouse or the arrow keys. A row can only be selected programmatically with [TableSelectPlus](../WDLang1/3074031.md). This row will be selected with the selection bar. |
| *DisplayOnly* or *Inactive* | The control is read-only, no input or action is allowed.<br><br>For Table, Hierarchical Table and RepeatString fields, the user can select a line. It can also be selected programmatically (using [TableSelectPlus](../WDLang1/3074031.md) in Table controls, for example). |
| *Grayed* | Grayed-out control. |
| *InactifFlou* | Inactive field with blurred content. <br>Available for Static Text control, Edit control, Image and Combo Box control. <br> The default blur radius is 12. This radius can be modified using the [Effect](../Proprietes/1410090859.md) property. The larger the radius, the greater the blurring. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| **Row or cell in a Table, TreeView Table, List Box, ListView, Combo Box, Looper control** |
| *Active* | The control is enabled and is in edit mode (if the Table control is in edit mode). |
| *ReadOnlyNoSelection* | The control is read-only, no input or action is allowed. The user will not be able to select a row in the control using the mouse or the arrow keys. Rows can only be selected programmatically (using [TableSelectPlus](../WDLang1/3074031.md) in Table controls, for example). <br><br>This row will be selected with the selection bar. |
| *Grayed* | Grayed-out control |
| ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Feature not supported. |
| **Windows** |
| *Active* | Window that can be handled by the user. |
| *DisplayOnly* | The controls of the window can no longer be modified. However, the user will be able to modify the row selected in the Table, TreeView Table or Looper controls. The window cannot be moved. |
| *Grayed* | Grays out all window controls. |
| *OutsideScreen* | The window is active but its coordinates are negative |



**`<Element name>: (Character string)`**

Name of control, table row, cell, group of controls or window.

## Remarks


### Status (Status editor): Visible or invisible field/block
<a name="status_status_editor_visible_invisible_fieldblock_ELTPARAGRAPHE000318"></a>

In a report, the only possible state for a control or a block is visible or invisible. To set the visibility of a control, it is recommended to use the [Visible](../Proprietes/2510138.md) property. This property optimizes the management of control visibility.
<a name="NOTE0_2"></a>


### State of a group of controls
<a name="state_group_controls_ELTPARAGRAPHE000328"></a>

- Find out the status of a group of fields: the status returned corresponds to the status of the first field in the group.

- Modify the status of a group of fields: all the fields in the group are modified to match the new status.



<a name="NOTE0_3"></a>


### State of a column in a Table control
<a name="state_column_table_control_ELTPARAGRAPHE000336"></a>

If the **State** property is applied to a column of a Table control, the state of the entire column is changed (and not only the state of the cell). 

Please note: the **State** property can only be used to restrict the column status defined in the description window.. For example, if the column is read-only, no column cell can become editable.

### Tabs and controls in a tab pane
<a name="tabs_and_controls_tab_pane_ELTPARAGRAPHE000351"></a>

The state of a control in a tab pane depends on the state of the tab:

- If the tab is not selected, the control is invisible.

- If the tab is selected and invisible, the control is invisible.

- If the tab is selected and grayed out, the control is grayed out.

- If the tab is selected and disabled, the control is disabled.

- If the tab is selected and enabled, the control can be enabled, disabled, grayed out or invisible.

### Sidebar and controls in a tab pane
<a name="sidebar_and_controls_tab_pane_ELTPARAGRAPHE000366"></a>

The state of a control in a sidebar pane depends on the state of the tab:

- If the tab is not selected, the control is invisible.

- If the tab is selected and grayed out, the control is grayed out.

- If the tab is selected and disabled, the control is disabled.

- If the tab is selected and enabled, the control can be enabled, disabled, grayed out or invisible.

### Radio Button/Check Box controls and their options
<a name="radio_buttoncheck_box_controls_and_their_options_ELTPARAGRAPHE000381"></a>

You can change the state of the control or the state of an option of the Radio Button/Check Box control. An option can be grayed out or enabled.

- To change the state of a Radio Button control: 
	
	```txt
	RADIO_Radio1.State = Grayed
	```


- To change the state of an option in a Radio Button control: 
	
	```txt
	RADIO_Radio1[2].State = Grayed
	```





**Caution**: The state of an option depends on the state of the Radio Button control.. Therefore, if the following operations are performed:

1. An option is grayed out.

2. The Radio Button/Check Box control is grayed out.

3. The Radio Button/Check Box control is re-enabled. The option is still grayed out.

### Active control made invisible or not
<a name="active_control_made_invisible_not_ELTPARAGRAPHE000403"></a>

The [Visible](../Proprietes/2510138.md) property can be used to hide a control (enabled, grayed out or read-only).

When the field is invisible, it loses all the characteristics of its previous state: the field is invisible and cannot be used. The only way to run its code is to call [ExecuteProcess](../WDLang1/3013031.md). For example, an invisible control does not respond when using the shortcut. For example, an active button made invisible does not respond when using the shortcut.

To restore the previous state of the control, simply use the [Visible](../Proprietes/2510138.md) property again.

### Menu options
<a name="menu_options_ELTPARAGRAPHE000425"></a>

The **State** property determines if the menu option is enabled or greyed out. To show or hide a menu option, use the [Visible](../Proprietes/2510138.md) property.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The **State** property hides a context menu option.
