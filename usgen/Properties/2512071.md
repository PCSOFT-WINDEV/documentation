


## PasswordProtected (Property)

***In french: ProtégéParMotDePasse***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PasswordProtected** property is used to determine if a datafile is password-protected.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out whether the Customer table is password-protected 
ResProtection = Customer.PasswordProtected
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Protected> = <Table>.PasswordProtected`
---

**`<Protected>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table is password-protected,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table>: (Character string)`**

Name of the table used. This table has been described in the data model editor.
