
## Executable (Property)

***In french: Executable***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Executable** property gets and sets the executable file to be used. This property is used by:

- a variable of type [Process](../WDLang1/1000018696.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) a variable of type [Command](../WDLang1/1410090491.md).
