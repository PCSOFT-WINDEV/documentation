


## ProgressBarColor (Property)

***In french: CouleurJauge***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ProgressBarColor** property gets and sets the progress color in the following controls and elements: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Progress Bar control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Progress Bar column,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Progress Bar cell,

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) infinite Progress Bar control of type "Native circular".




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This property can only be used on Progress Bar controls.

## Syntax

### Getting the color of a progress bar

`<Progression color> = <Control used>.ProgressBarColor`
---

**`<Progression color>: (Integer or constant)`**

Color of the progress bar displayed in the specified element. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Control used>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) a Progress Bar control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a Progress Bar column, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Progress Bar cell,

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) an infinite Progress Bar control representing a native circular progress bar.

## Remarks
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Defining the color of the progress bar in the window editor
<a name="defining_the_color_the_progress_bar_the_window_editor_ELTPARAGRAPHE000130"></a>

The color of a progress bar can be defined in the "Style" tab of the control description ("Color" option of the "Progress percentage" element).

If the progress bar uses a gradient color, it will change while maintaining the same lightness.
<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000139"></a>

- The **ProgressBarColor** property can be used:

	- on Progress Bar controls,

	- on Progress Bar columns (for Table and TreeView Table controls),

	- on Progress Bar cells (for Table and TreeView Table controls).




- If the progress bar uses an image to show the progress, the **ProgressBarColor** property has no effect.
