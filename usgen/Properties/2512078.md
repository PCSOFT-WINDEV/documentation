


## Directory (Property)

***In french: Répertoire***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Directory** property is used to manage the physical directory of HFSQL files. This property takes into account the possible changes of directory performed by [HChangeDir](../WDLang4/3044168.md) or [HSubstDir](../WDLang4/3044028.md). You can:

- Identify the physical directory of a table defined in the data model editor or programmatically.

- Define a physical directory for a table (only for tables defined programmatically).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the name and full path of the Customer table
NameAndFullPath is String
NameAndFullPath = Customer.Directory + "\" + Customer.PhysicalName + Customer.Extension
// NameAndFullPath corresponds to "C:\MyFiles\Customer.Fic"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the physical directory of a table

`<Current directory> = <Table>.Directory`
---

**`<Current directory>: (Character string)`**

Name of the directory of the table. This name takes into account the possible changes of directory performed by [HChangeDir](../WDLang4/3044168.md) or [HSubstDir](../WDLang4/3044028.md).

**`<Table>: (Character string)`**

Logical name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining a physical directory for a table described programmatically

`<Table>.Directory = <New directory>`
---

**`<Table>: (Character string)`**

Logical name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New directory>: (Character string)`**

Physical name of the directory.

![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The directory of the table must be relative to the database schema found on the server. For example: ".\\Data"
