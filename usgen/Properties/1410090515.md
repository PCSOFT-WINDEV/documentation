
## Autofill (Property)

***In french: RemplissageAuto***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Autofill** property indicates the type of information to be automatically entered in an Edit control. This information is then used by autofill services. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
EDT_LastName.Autofill = afFamilyName
EDT_FirstName.Autofill = afGivenName
EDT_Email.Autofill = afEmail
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the type of information contained in the control

`<Result> = <Edit control>Autofill`
---

**`<Result>: (Integer constant)`**

Type of information contained in the control:



|   |   |
| --- | --- |
| *afAddressPostalCode* | Postal code of the address. |
| *afAddressCountry* | Country in which the address is located. |
| *afAddressRegion* | Region or state in which the address is located. |
| *afAddressStreet* | Street of the address. |
| *afAddressCity* | City in which the address is located. |
| *afNone* | The control is never filled in automatically.  |
| *afAutomatic* | Autofill based on: <br><br>- The input mask of the control (Phone, Email, Postal code, etc.)<br><br>- the caption of the control, its type, etc.<br><br><br> |
| *afCreditCardSecurityCode* | Credit card security code. |
| *afCreditCardExpirationYear* | Credit card expiration year. |
| *afCreditCardExpirationDate* | Credit card expiration date. |
| *afCreditCardExpirationMonth* | Credit card expiration month. |
| *afCreditCardNumber* | Credit card number. |
| *afBirthDate* | Birth date. |
| *afBirthDateYear* | Birth year. |
| *afBirthDateDay* | Birth day. |
| *afBirthDateMonth* | Birth month. |
| *afMiddleName* | A person's middle name. |
| *afEmail* | Email address. |
| *afPassword* | Password. |
| *afName* | A person's full name. |
| *afFamilyName* | A person's last/family name. |
| *afUsername* | Username. |
| *afNewPassword* | New password. |
| *afNewUsername* | New username. |
| *afPhoneNumber* | Phone number. |
| *afFlightNumber* | Flight number. |
| *afNamePrefix* | Name prefix. |
| *afGivenName* | A person's first name. |
| *afSMSOneTimeCode* | One-time code sent by SMS. |
| *afNameSuffix* | Name suffix. |



**`<Edit control>: (Control name)`**

Name of the Edit control used.
