


## Token (Property)

***In french: Jeton***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Token** property is used to manage the different tokens associated with a "Text token" Edit control.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property can only be used to get the value of a token.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
J is Token
J.Value = "My token"
EditAddToken(EDT_Email, J)
// equivalences:  
// EDT_Email.AddToken(J)
// Add(EDT_Email.Token[J])
Info(EDT_Email.Token[1].Value)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the value of a token

`<Result> = <Edit control>.Token[<Token index>]`
---

**`<Result>: (Character string)`**

Token value. 

**`<Edit control>: (Control name)`**

Name of the "Text token" Edit control. 

**`<Token index>: (Integer)`**

Index of the token to be handled. The indexes correspond to the current display order of the tokens (and not the initial addition or insertion index of the token).


<a name="SYNTAXE2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available in browser code
### Modifying the value of a token

`<Edit control>.Token[<Token index>] = <New value>`
---

**`<Edit control>: (Control name)`**

Name of the "Text token" Edit control. 

**`<Token index>: (Integer)`**

Index of the token to be handled. The indexes correspond to the current display order of the tokens (and not the initial addition or insertion index of the token).

**`<New value>: (Character string)`**

New token value.
