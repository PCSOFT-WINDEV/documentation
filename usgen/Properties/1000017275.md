


## CalendarButton (Property)

***In french: BoutonCalendrier***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CalendarButton** property is used to determine and specify whether a Date Edit control has a button to display a popup calendar.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=BoutonCalendrier.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays a Calendar button if necessary
IF EDT_Date.CalendarButton = False THEN 
	EDT_Date.CalendarButton = True
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining whether a Calendar button is displayed

`<Result> = <Edit control>.CalendarButton`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a Calendar button is displayed, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Edit control>: (Control name)`**

Name of the Date Edit control to use.  


<a name="SYNTAXE2"></a>

### Displaying a Calendar button

`<Edit control>.CalendarButton = <Display>`
---

**`<Edit control>: (Control name)`**

Name of the Date Edit control to use.

**`<Display>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a Calendar button must be displayed, 

- <u><u><u><u>False</u></u></u></u> otherwise.

### Calendar control behavior
<a name="calendar_control_behavior_ELTPARAGRAPHE000075"></a>

At runtime, Date Edit controls include the "Calendar" option by default. This option displays a calendar to select a date.

If the **CalendarButton** property is used to display a Calendar button in the date Edit control, the "Calendar" option is no longer available in the context menu of the Date control.

**Note** You can deactivate the calendar display for a project or field (via the button or context menu) by pressing [AAFDisable](../WDLang1/1000022018.md).
