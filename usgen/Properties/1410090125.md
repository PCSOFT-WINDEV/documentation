
## Hole (Property)

***In french: Trou***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Hole** property is used to define the holes of a polygon. This hole is a single, closed linestring within a polygon. This property is available for: 

- a variable of type [Polygon2D](../WDLang4/1410090122.md). 

- a variable of type [PolygonGeo](../WDLang4/1410090127.md).
