
## FocusColor (Property)

***In french: CouleurFocus***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FocusColor** property gets and sets the color used to highlight input fields in a PDF form (displayed in a PDF Reader control).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Background color for controls in PDF forms displayed in the PDF Reader control
PDF_Reader.ControlColor = DarkGreen
// Color of the control that has focus in PDF forms displayed in the PDF Reader control
PDF_Reader.FocusColor = LightBlue
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the background color of input fields with focus

`<Result> = <Control used>.FocusColor`
---

**`<Result>: (Constant or character string)`**

Background color of input fields with focus. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a preset color](../WDLang5/3010002.md).




**`<Control used>: (Control name)`**

Name of the PDF Reader control.


<a name="SYNTAXE2"></a>

### Setting the background color of input fields with focus

`<Control used>.FocusColor = <New color>`
---

**`<Control used>: (Control name)`**

Name of the PDF Reader control.

**`<New color>: (Constant or character string)`**

New background color of input fields with focus. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).
