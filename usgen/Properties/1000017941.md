
## Version (Property)

***In french: Version***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Version** property gets and sets the version of an element. This property can be used on:

- a variable of type [rssStream](../WDLang5/1000017795.md).

- a variable of type [xlsDocument](../WDLang5/1000017464.md).

- a variable of type [xmlDocument](../WDLang5/1000018782.md).

- a variable of type [hbReading](../WDLang4/1000021701.md).

- a variable of type [pdfParameter](../WDLang6/1410087857.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [GuidedTour](../WDLang6/1410090170.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [zipExeCreationParameter](../WDLang3/1410091226.md).
