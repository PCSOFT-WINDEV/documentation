
## SourceKey (Property)

***In french: CléSource***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SourceKey** property sets the characteristics of a link. You can:

- Get the item of the source table used in the link.

- Change the item of the source table used in the link.



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=cleSource.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change the source key
LinkClubPerson.SourceKey = Club.ClubID
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the source key of a link

`<Key> = <Link>.SourceKey`
---

**`<Key>: (Character string)`**

Name of the key in the source table.

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Changing the source key of a link

`<Link>.SourceKey = <New key>`
---

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.

**`<New key>: (Character string)`**

Name of the new key used in the source table. This key was defined in the data model editor or via the [Item Description](../WDLang4/1514071.md) type.
