


## Extension (Property)

***In french: Extension***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Extension** property is used to:

- get the extension of a table defined in the data model editor or programmatically.

- define the extension of a table (for programmed table description only).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the name and full path of the Customer table
NameAndFullPath is string
NameAndFullPath = Customer.Directory + "\" + Customer.PhysicalName + Customer.Extension ...
	Customer.PhysicalName + Customer.Extension
// NameAndFullPath corresponds to "C:\MyFiles\Customer.Fic"
```
<a name="Exemple2"></a>

```wl
// Set UnFile table extension
AFile is File Description
AFile.Name = "CUSTOMER"
AFile.Extension = ".AAA"
// The created file will be named "CUSTOMER.AAA"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the extension of a table

`<File extension> = <Table>.Extension`
---

**`<File extension>: (Character string)`**



- Extension of the table used (preceded by a dot). 

- Empty string ("") if the table has no extension.




**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the extension of a table

`<Table>.Extension = <New extension>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New extension>: (Character string)`**

Extension of the table used (preceded by a dot).
