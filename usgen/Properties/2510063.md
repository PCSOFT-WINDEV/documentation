


## InitialState (Property)

***In french: EtatInitial***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InitialState** property gets the initial state of a control. The initial state is defined in the control description ("UI" tab).


|   |   |
| --- | --- |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=EtatInitial_Champ.gif)<br>Initial state of an Edit control ("UI" tab) | <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Etat_init_champ_btn.gif)<br>Initial state of a control (e.g., Button) |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Table_initial.gif)<br>Initial state of a Table control ("UI" tab) | <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Etat_init_col.gif)<br>Initial state of a column in a Table control ("UI" tab) |

To know if a control is visible, use the [Visible](../Proprietes/2510138.md) property.

```wl

```

<a name="SYNTAXE1"></a>

## Syntax

`<Initial state> = <Control>.InitialState`
---

**`<Initial state>: (Integer constant)`**

Initial state of the control, defined in the editor.


|   |   |
| --- | --- |
| *Active* | The control is active, visible and editable |
| *DisplayOnly or Inactive* | The control is read-only, no input or action is allowed<br>For Table controls, the user will be able to select a table row. It can also be selected programmatically with [TableSelectPlus](../WDLang1/3074031.md). |
| *Grayed* | Grayed field |
| *ReadOnlyNoSelection* | For Table fields only: Field displayed, no input possible..<br>In this case, the user will not be able to select a row from the table using the mouse or the arrow keys. A row can only be selected programmatically with [TableSelectPlus](../WDLang1/3074031.md). This row will be selected with the selection bar. |



**`<Control>: (Name of control or group of controls)`**

Name of control or group of controls.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### State of a group of controls
<a name="state_group_controls_ELTPARAGRAPHE000118"></a>

If the **InitialState** property is used on a group of controls, the state returned is the initial state of the first control in the group.
<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000127"></a>

- The **InitialState** property cannot be used on a menu or menu option.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The **InitialState** property is only available on Table controls.
