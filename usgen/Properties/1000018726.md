
## Subject (Property)

***In french: Sujet***
	

<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Subject** property gets and sets the subject of an element. 

This property can be used on:

- the [Email](../WDLang3/3032029.md) structure.

- a variable of type [Email](../WDLang3/1000018713.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docProperty](../WDLang1/1000022945.md). 

- a variable of type [JWTParameters](../WDLang3/1410089572.md).
