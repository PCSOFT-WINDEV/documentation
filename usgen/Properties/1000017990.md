
## Event

***In french: Evénement***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Event** keyword can correspond to:  

- the **[Event](../WDLang1/3015011.md)** function, which is used to intercept Windows events. 

- the **Event** property of a variable of type [gglCalendar](../WDLang5/1000017418.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the **Event** property of a variable of type [Contact](../WDLang3/1000020254.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Event](../WDLang3/1000020248.md).
