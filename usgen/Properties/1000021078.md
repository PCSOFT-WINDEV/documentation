


## Member (Property)

***In french: Membre***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
When used on Variant variables, the **Member** property is used to get the array of named elements. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
v est un variant = JSONVersVariant(JSON)
POUR TOUT x DE v..Membre
	Trace("Le membre " + x.Nom + " a la valeur " + x.Valeur)
FIN
```
<a name="Exemple2"></a>

```wl
jedi est un JSON = [
	{
	"id": 5,
	"name": "Luke Skywalker",
	"pilotingScore": 98,
	"shootingScore": 56,
	"isForceUser": true
	}
]

v est un Variant = JSONVersVariant(jedi)
Trace("Dans le JSON Jedi:")
POUR TOUT x DE v..Membre
	Trace("Le membre " + x.Nom + " a la valeur " + x.Valeur)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the array of named elements of a Variant variable

`<Result> = <Variant>.Member`
---

**`<Result>: (Array)`**

Array of named elements. You can iterate through the array using FOR EACH. 

**`<Variant>: (Character string)`**

Name of the Variant variable to be used.
