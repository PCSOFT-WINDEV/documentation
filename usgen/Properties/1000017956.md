
## Type (Property)

***In french: Type***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The Type keyword can correspond to: 

- the keyword used to define a type alias. For more details, see [Type aliases](../Motscles/1514089.md).

- the WLanguage **Type** property.  




The **Type** property gets and sets the type of an element. This property can be used on:

- the controls of a window or page. For more details, see [Type property](../Proprietes/2510131.md).
