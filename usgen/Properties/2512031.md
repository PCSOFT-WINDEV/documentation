


## LinkedFile (Property)

***In french: FichierRelié***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LinkedFile** property sets the characteristics of a link. You can:

- Find out the name of the linked table used in the link.

- Change the linked table used in the link.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FichierRelie.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change the linked table
ProjectManagement.LinkedFile = Project
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the linked table used in the link

`<Table> = <Binding>.LinkedFile`
---

**`<Table>: (Character string)`**

Name of the linked table used in the link.

**`<Binding>: (Character string)`**

Name of the link defined in the data model editor or via the [Link description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Changing the linked table used in the link

`<Link>.LinkedFile = <Table>`
---

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link description](../WDLang4/1514039.md) type.

**`<Table>: (Character string)`**

Name of the linked table used in the link. Name defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.
