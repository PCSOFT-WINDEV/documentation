


## HeightExpanded (Property)

***In french: HauteurDéroulée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **HeightExpanded** property gets and sets the "expanded" height of the bottom sliding window associated with the current window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurEtendue = 0.9 // 90% 
// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the "extended" height of a bottom sliding window

`<Result> = <Sliding window>.HeightExpanded`
---

**`<Result>: (Integer or Integer constant)`**



- Value greater than 1: Height (in pixels) of bottom sliding window display in "extended" mode..  

- Value between 0 and 1: Percentage of screen height. 

- Negative value: Constant used to define the "extended" height of the bottom sliding window: 
	


|   |   |
| --- | --- |
| *swDisabled* | The extended mode of bottom sliding windows is disabled. |
| *swFitToContent* | The height in extended mode corresponds to the height of the internal window. |
| *swSysMedium* | The height in extended mode is half the height of the host window. |






**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.


<a name="SYNTAXE2"></a>

### Setting the "extended" height of a bottom sliding window

`<Sliding window>.HeightExpanded = <New extended height>`
---

**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.

**`<New extended height>: (Integer or Integer constant)`**

New extended height for bottom sliding windows. This height can correspond to: 

- a number of pixels. 

- a percentage of the maximum height (integer between 0 and 1),

- one of the following constants: 
	


|   |   |
| --- | --- |
| *swDisabled* | The extended mode of bottom sliding windows is disabled. |
| *swFitToContent* | The height in extended mode corresponds to the height of the internal window. |
| *swSysMedium* | The height in extended mode is half the height of the host window. |
