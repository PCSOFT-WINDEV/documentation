
## DefaultFunctions (Property)

***In french: FonctionsParDéfaut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DefaultFunctions** property gets and sets the list of functions available by default in the Code Editor control, or with the [Compile](../WDLang1/3013015.md), [ExecuteCode](../WDLang1/1000019783.md), or [EvaluateExpression](../WDLang1/1000019782.md) functions. 

This property is available for: 

- the [Compiler](../Proprietes/1410090383.md) property of the Code Editor control. 

- a variable of type [WLanguageCodeCompiling](../WDLang1/1410090373.md).
