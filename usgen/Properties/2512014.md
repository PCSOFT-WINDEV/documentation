


## MmoEncryption (Property)

***In french: CryptageMmo***

<a name="Utilisation"></a>
<a name="description"></a>
The **MmoEncryption** property sets the encryption method of the memo file (.MMO) associated with a table. You can:

- Know how to encrypt a memo file associated with a table (table defined in the data model editor or programmatically defined).

- Programmatically define the encryption method of a memo file.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the encryption method of the memo file associated with the Customer table
ResEncrypt = Customer.MmoEncryption
```

## Syntax

### Getting the encryption method of a MMO file

`<Current encryption method> = <Table>.MmoEncryption`
---

**`<Current encryption method>: (Integer constant)`**

The encryption methods are:


|   |   |
| --- | --- |
| *hEncryptionAES128* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using a 128-bit AES algorithm with the Output Feedback (OFB) mode. |
| *hEncryptionAES192* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using a 192-bit AES algorithm with the Output Feedback (OFB) mode. |
| *hEncryptionAES256* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using a 256-bit AES algorithm with the Output Feedback (OFB) mode. |
| *hEncryptionAuto* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using an optimized 16-round RC5 algorithm with a 128-bit key. |
| *hEncryptionNO* | No encryption is performed on the file. |
| *hEncryptionRC5_12* | The memo file is encrypted using an optimized 12-round RC5 algorithm with a 128-bit key. |
| *hEncryptionRC5_16* | The memo file is encrypted using an optimized 16-round RC5 algorithm with a 128-bit key. |
| *hEncryptionStandard* | The memo file is encrypted using an optimized 128-bit algorithm. |



**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.

### Defining the encryption method of a MMO file

`<Table>.MmoEncryption = <New encryption method>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New encryption method>: (Integer constant)`**

The encryption methods are:


|   |   |
| --- | --- |
| *hEncryptionAES128* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using a 128-bit AES algorithm with the Output Feedback (OFB) mode. |

| *hEncryptionAES256* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using a 256-bit AES algorithm with the Output Feedback (OFB) mode. |
| *hEncryptionAuto* | Encryption is performed only if a password is set for the table. In this case, the memo file is encrypted using an optimized 16-round RC5 algorithm with a 128-bit key. |
| *hEncryptionNO* | No encryption is performed on the file. |
| *hEncryptionRC5_12* | The memo file is encrypted using an optimized 12-round RC5 algorithm with a 128-bit key. |
| *hEncryptionRC5_16* | The memo file is encrypted using an optimized 16-round RC5 algorithm with a 128-bit key. |
| *hEncryptionStandard* | The memo file is encrypted using an optimized 128-bit algorithm. |

## Remarks


### 128-bit, 192-bit and 256-bit AES encryption with the Output Feedback (OFB) mode
<a name="128bit_192bit_and_256bit_aes_encryption_with_the_output_feedback_ofb_mode_ELTPARAGRAPHE000118"></a>

- If the Memo file is encrypted using the AES algorithm, you need to use the same method to encrypt data ([FicEncryption](../Proprietes/2512046.md) property) and indexes ([NdxEncryption](../Proprietes/2512010.md) property).

- If there is encryption that uses the AES algorithm, the option "Enable enhanced security " is automatically applied.
