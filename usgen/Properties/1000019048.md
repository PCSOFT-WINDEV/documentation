


## DayOfMonthOrDayOfWeek (Property)

***In french: JourDuMoisOuDeLaSemaine***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DayOfMonthOrDayOfWeek** property is used to set the execution of a scheduled task by specifying the day number of the week or the day number of the month. Example: execution every Monday, 1st day of the month.

This property can be used on:

- a variable of type [hScheduledTask](../WDLang4/1000017448.md).

- a variable of type [hScheduling](../WDLang4/1000018853.md).

- a variable of type [Repetition](../WDLang1/1000019262.md).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [appServerScheduledTask](../WDLang2/1000022367.md).
