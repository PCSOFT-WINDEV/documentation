
## TransactionFile (Property)

***In french: FichierTransaction***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **TransactionFile** property is used to determine if a table is a transaction file.

**Reminder** A transaction file is used to store the various operations carried out during a transaction. These operations are either validated, or canceled. The transaction file is created at the start of the transaction by [HTransactionStart](../WDLang4/3044002.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
EXTERN SALESMGT_TRS
HDeclareExternal("C:\WINDEV\Examples\SalesMgt\SALESMGT_TRS.fic", "SALESMGT_TRS")
IF SALESMGT_TRS.TransactionFile = True THEN
	Info("You are handling a transaction file.")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table>.TransactionFile`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table is a transaction file,

- <u><u><u><u>False</u></u></u></u> otherwise. 
	Note: The tables described in the database schema are not transaction files.




**`<Table>: (Character string)`**

Logical name of the table used. May correspond to an alias name of a table declared by function [HDeclareExternal](../WDLang4/3044204.md).
