
## Alias (Property)

***In french: Alias***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Alias** property gets the alias of an element. This property can be used on:

- a WINDEV, WEBDEV or WINDEV Mobile element: 

	- to get and set the alias of a window (WINDEV). 

	- to get and set the alias of a dynamic tab (WINDEV).

	- to get the internal HTML/JavaScript name of a control (WEBDEV).


 For more details, see the help on the [Alias](../Proprietes/2510004.md) property. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [mongoGridFSFileInfo](../WDLang4/1000022417.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docStyle](../WDLang1/1000022486.md). 

- a variable of type [Option Description](../WDLang1/1000023072.md). 

- a variable of type [Value description](../WDLang1/1000023061.md). 

- a variable of type [YAML](../Motscles/1000024438.md). 

- [OpeningOptions](../Proprietes/1410091299.md) properties of a variable of type [Window](../WDLang1/1410091366.md). 
	

- a variable of type [WindowOpeningOptions](../WDLang1/1410091298.md).
