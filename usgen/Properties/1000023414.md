


## RowDetailsBinding (Property)

***In french: LiaisonsDétailLigne***
	

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>26</B>, ***LinksLineDetails*</**>** is kept for backward compatibility. This property has been replaced with ***RowDetailsBinding*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The property **LineDetailLinks** property lets you identify and modify the data binding used to display line details in a Table field linked to a table. 

**Reminder** The details of a line are a "sub-table" displayed below the line when the user clicks [+] in front of the line or double-clicks on the line in the Table control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the orders when clicking the row displaying the customer
TABLE_CUSTOMER.RowDetailsBinding = "CUSTOMERID:ORDER.CUSTOMERID"
```



```wl
// Displays the city name when clicking the row displaying the customer
TABLE_CUSTOMER.RowDetailsBinding = "ZC:CITY.ZC:NAME"
```



```wl
// Displays the orders as well as the city and state when clicking the row displaying a customer 
TABLE_CUSTOMER.RowDetailsBinding = [
CUSTOMERID:ORDER.CUSTOMERID
ZC:CITY.ZC:NAME,STATE
]
```

## Syntax
<a name="SYNTAXE1"></a>

### Identifying the data binding used to display the details of a row in a data-bound Table control

`<Result> = <data-bound Table control>.RowDetailsBinding`
---

**`<Result>: (Constant or character string)`**

Current binding: 



|   |   |
| --- | --- |
| *lldNone* | No binding was defined. <br>No detail is displayed in the data-bound Table control when clicking the "[+]" sign or when double-clicking the row. |
| *lldAutomatic* | The links defined in the database schema are used to find the data from the linked tables to be displayed. <br>If several tables are bound in the database schema, the user will be able to choose the table to display in the details via a context menu. |
| Character string | The binding is customized. The detailed window displays the specified data. <br>This string has the following format: <br><br><pre><code>ITEM:FILEA.ITEMA:DispItem1,DispItem2,DispItem3<CR><br>ITEM2:FILEB.ITEMB</code></pre><br>where: <br><br>- ITEM,ITEM2 are the items found in the main search file of Table control,<br><br>- FILEA, FILEB are the bound tables that will be displayed in detail,<br><br>- ITEMA, ITEMB are the items bound to the ITEM, ITEM2 items in these files,<br><br>- DispItem1, DispItem2, DispItem3 are the items found in FILEA that will be displayed in detail. If this element is not filled, all visible database schema items will be displayed.<br><br><br><br><br>For example, the line: <br><br><pre><code>OrderRef:QRY_OrderLine.ParamOrderRef:VISUAL,REF,<br>CAPTION,UNITPRICE,QUANTITY,TOTALBT</code></pre><br> binds the OrderRef item in the Table control to the ParamOrderRef item in the QRY_OrderLine query. <br>The items displayed in the detailed window are the VISUAL, REF, CAPTION, UNITPRICE, QUANTITY, TOTALBT items of query result. |



**`<data-bound Table control>: (Control name)`**

Name of the data-bound Table control to be used.
