
## Effect (Property)

***In french: Effect***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Effect** property gets and sets the blur radius on the contents of a control.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Control content is blurred
EDT_Name.State = DisabledBlur
// Blur radius
EDT_Name.Effect.Blur.Radius = 12
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the values of a control's effect properties

`<Result> = <Control used>.Effect.<Property>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<Control used>: (Control name)`**

Name of the control used. 

**`<Property>: ()`**

Effect property applied: 


| Property | Type | Description |
| --- | --- | --- |
| *Blur.Radius* | Integer | Blur radius applied to the contents of a control. <br>Reminder: The content of a control can be blurred using the [State](../Proprietes/2510039.md) property with the *inactiveFlou* constant. <br>By default, this property is set to 12. |




<a name="SYNTAXE2"></a>

### Setting the values of a control's effect properties

`<Control used>.Effect.<Property> = <New value>`
---

**`<Control used>: (Control name)`**

Name of the control used. 

**`<Property>: ()`**

Name of the property to be applied: 


| Property | Type | Description |
| --- | --- | --- |
| *Blur.Radius* | Integer | Blur radius applied to the contents of a control. <br>Reminder: The content of a control can be blurred using the [State](../Proprietes/2510039.md) property with the *inactiveFlou* constant. <br>By default, this property is set to 12. |



**`<New value>: (Type corresponding to the property)`**

New value of the property. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The **Effect** property applies to the following control:

- Static Text control. 

- Edit control. 

- Combo Box control. 

- Image control.
