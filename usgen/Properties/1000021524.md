
## StatusCode

***In french: CodeEtat***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StatusCode** property gets the status of the response to the request. This property can be used on:

- a variable of type [httpResponse](../WDLang3/1000021165.md). 

- a variable of type [restResponse](../WDLang3/1000021477.md).
