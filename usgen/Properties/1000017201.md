


## Zoom (Property)

***In french: Zoom***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Zoom** property gets or sets the zoom value: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) in an Image control. The management of automatic scrollbars and zoom must be enabled in this Image control ("Automatic scrollbars and zoom" in the "Details" tab of the control description window).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) in a Map control.

### Drawing functions, zoom and automatic scrollbars
<a name="drawing_functions_zoom_and_automatic_scrollbars_ELTPARAGRAPHE000341"></a>

The "Automatic scrollbars and zoom" option, available for Image controls, is not compatible with [dStartDrawing](../WDLang1/3029009.md). If this option is used on the Image control, [dStartDrawing](../WDLang1/3029009.md) freezes the image in the control. The zoom is also fixed. The standard behavior is restored when [dEndDrawing](../WDLang1/3029019.md) is called.

You can get the same effect with [dPixelColor](../WDLang1/3029014.md) and [dRotation](../WDLang1/3029024.md).

### How zoom works
<a name="how_zoom_works_ELTPARAGRAPHE000371"></a>

The **Zoom** property corresponds to a value between the values of the [MinZoom](../Proprietes/1410088098.md) and [MaxZoom](../Proprietes/1410088099.md) properties . This value corresponds to the magnification factor. For example, if the **Zoom** property is set to 2, it means that a '2x' zoom is applied. 

- If the value of the **Zoom** property is greater than that of the [MaxZoom](../Proprietes/1410088099.md) property, the zoom takes the value of [MaxZoom](../Proprietes/1410088099.md). 

- If the value of the **Zoom** property is less than that of the [MinZoom](../Proprietes/1410088098.md) property, the zoom takes the value of [MinZoom](../Proprietes/1410088098.md).
