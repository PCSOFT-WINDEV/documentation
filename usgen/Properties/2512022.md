


## CtDescribedUserName (Property)

***In french: CxUtilisateurDécrit***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CtDescribedUserName** property sets the username used to connect to a specific table via OLE DB. You can:

- Get the username used to connect to a table via OLE DB (table defined in the table model editor or programmatically). This username is specified in the table description.

- Set the username used to connect to a table via OLE DB (only for tables defined programmatically). 




**Reminder**: [HConnect](../WDLang4/3044263.md) can be used to redefine one or more parameters of the OLE DB connection on a table. By default, the characteristics of the OLE DB connection are defined in the table description.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the name of the user
Customer.CtDescribedUserName = "Julia"
...
// Validate the table description
HDescribeFile(Customer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the name of the user

`<User> = <Table>.CtDescribedUserName`
---

**`<User>: (Character string)`**

OLE DB source user name specified when defining the table in the data model editor.

**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the name of the user

`<Table>.CtDescribedUserName = <New username>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New username>: (Character string)`**

OLE DB source user name.
