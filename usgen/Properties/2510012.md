
## InitialAnimation (Property)

***In french: AnimationInitiale***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InitialAnimation** property determines whether the animation of an Image, Button, Static or Carousel control is enabled when the control is created. The initial status of the animation is defined in the control description window ("Details" tab).
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=AnimationInitiale%20-%20HC%20N%B0001.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is only available for Label fields.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) 
```wl
// Reset the image to its initial state
IMG_Image1.Animation = IMG_Image1.InitialAnimation
```



```wl
// Reset label animation to initial state
LIB_Promotions.Animation = LIB_Promotions.AnimationInitial
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<State> = <Control used>.InitialAnimation`
---

**`<State>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the animation is enabled in the Image, Button, Carousel or Static Text control when created,

- <u><u><u><u>False</u></u></u></u> otherwise. 


The animation is set to <u><u><u><u>True</u></u></u></u> by default.

**`<Control used>: (Control name)`**

Name of the control used. This control can correspond to: 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) an Image control, 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) a Button control, 

- a Static Text control,

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) a Carousel control.

<a name="NOTE0_1"></a>

## Remarks
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) 

### Animating an image
<a name="animating_image_ELTPARAGRAPHE000081"></a>

The image to be animated in the Image control can be:

- an animated image (animated GIF, for example).

- an image animated by WINDEV. In this case, the type of animation can be defined in the Image control description window ("Details" tab) or programmatically with the [AnimationSetMode](../WDLang1/3017001.md) function.




Animating an image in a Button control: Only an animated image can be associated with a Button control (e.g. Animated GIF).
<a name="NOTE0_2"></a>


### Animate text in a Static Text control
<a name="animate_text_static_text_control_ELTPARAGRAPHE000096"></a>

To animate the text displayed in a Static Text control, you must choose the animation:

- in the Static Text control description window ("Details" tab),

- programmatically with the [AnimationSetMode](../WDLang1/3017001.md) function.



<a name="NOTE0_3"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000109"></a>

The **InitialAnimation** property applies only to: 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Image, Button, Static, Progress Bar and Carousel controls in a window.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Static Text controls in a window.
