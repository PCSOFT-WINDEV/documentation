


## Description (Property)

***In french: Description***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Description** property is used to get and change the description of an element. This property can be used on:

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a WEBDEV page. For more details, see the help on the [Description](../Proprietes/1000017164.md) property used on pages.

- a variable of type [gglCalendar](../WDLang5/1000017418.md).

- a variable of type [hBackupDescription](../WDLang4/1000017455.md). 

- a variable of type [hScheduledOptimization](../WDLang4/1000018854.md).

- a variable of type [hScheduledTask](../WDLang4/1000017448.md).

- a variable of type [Marker](../WDLang3/1000019940.md).

- a variable of type [rssChannel](../WDLang5/1000017769.md).

- a variable of type [rssStream](../WDLang5/1000017795.md).

- a variable of type [rssImage](../WDLang5/1000017799.md). 

- a variable of type [rssEntry](../WDLang5/1000017792.md).

- a variable of type [rssTextInput](../WDLang5/1000017802.md)

- a variable of type [hRSConfig](../WDLang4/1000020484.md).

- a variable of type [inAppProduct](../WDLang3/1000020868.md).

- a variable of type [hScheduleMaterializedView](../WDLang4/1000021444.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [beaconGroup](../WDLang3/1000023105.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [notificationCategory](../WDLang3/1000023981.md).

- a variable of type [MapCircle](../WDLang3/1000025504.md).

- a variable of type [MapImage](../WDLang3/1000025523.md).

- a variable of type [MapPolygon](../WDLang3/1000025476.md).

- a variable of type [MapPolyline](../WDLang3/1000025489.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Permission](../WDLang3/1410087419.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadInfo](../WDLang3/1410087306.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadParameter](../WDLang3/1410087293.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [GuidedTourStep](../WDLang6/1410090178.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the [Accessibility](../Proprietes/1410090235.md) property of a control.
