
## Modal (Property)

***In french: Modale***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Modal** property determines whether the bottom sliding window associated with the current current window is modal or modeless. 

Note: If the bottom sliding window is modal, the host window will be inaccessible. It will be grayed out by the Dim Disabled Windows mechanism (DDW). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyBottomSlidingWindow.OnHide = () => { Trace("The bottom sliding window has been hidden") }
MyBottomSlidingWindow.OpeningParameters = (42, "Adams")
MyBottomSlidingWindow.InternalWindow = "IW_Sliding_menu"
MyBottomSlidingWindow.HeightCollapsed = 58 // Value in pixels
MyBottomSlidingWindow.HeightHalfExpanded = swFitToContent
MyBottomSlidingWindow.HeightExpanded = 0.9 // 90% 
MyBottomSlidingWindow.Modal = True
MyBottomSlidingWindow.Hideable = True
MyBottomSlidingWindow.RoundedCorner = False

// Opens the bottom sliding window
WinSlidingVisible(swBottom, swHalfExpanded)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Check if the bottom sliding window is modal

`<Result> = <Sliding window>.Modal`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the bottom sliding window is modal,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.


<a name="SYNTAXE2"></a>

### Making the bottom sliding window modal or modeless

`<Sliding window>.Modal = <New value>`
---

**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.

**`<New value>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to make the bottom sliding window modal,

- <u><u><u><u>False</u></u></u></u> otherwise.
