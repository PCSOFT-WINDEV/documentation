
## Icon

***In french: Icone***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Icon** keyword can correspond to:

- the **Icon** property. This property is used to get and change the icon of an element. This property can be used on:

	- a window. For more details, see [Icon property](../Proprietes/1000019344.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Notification](../WDLang3/1000019441.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [upnpDevice](../WDLang3/1000020903.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [notificationAction](../WDLang3/1000021304.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [QuickAction](../WDLang3/1410090054.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [zipExeCreationParameter](../WDLang3/1410091226.md). 
			




- a variable of type [Icon](../WDLang1/1000020811.md).
