


## GUIDFile (Property)

***In french: GUIDFichier***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **GUIDFile** property returns the GUID of the table defined in the database schema that was used to create the table. This identifier is used in the .REP file (for more details, see [Managing .REP files](../WDLang4/3044186.md)).

**Note** The GUID of the table can also be found in the data model editor ("General" tab of the table description).


<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GUIDFichier%20-%20HC%20N%B0001.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// GUID of "Customer" table
Trace(Customer.GUIDFile)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<File GUID> = <Table>.GUIDFile`
---

**`<File GUID>: (Character string)`**



- GUID of the table defined in the database schema. This database schema was used to create the table. 

- Empty string ("") if the table was created by programming, or if the table used is not in HFSQL Classic or Client/Server format.




**`<Table>: (Character string)`**

Name of the table for which the GUID is requested.

<a name="NOTE0_1"></a>
