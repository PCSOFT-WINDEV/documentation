


## InputType (Property)

***In french: TypeSaisie***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **TypeSaisie** property lets you know or modify the type of input allowed by a field: Duration, Date, Numerical, ...

This property can be used in the following controls:

- Edit control.

- Column of a Table control.

- Static Text control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Table column displayed by a Combo Box control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Editable Combo Box control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pivot Table control.




**Note**: The type of a field is defined in the "General" tab of the field description.

## Example


```wl
// Connaître le type du champ de saisie "SAI_Date"
SI SAI_Date.TypeSaisie = typSaisieDate ALORS
	Message("Saisissez une date")
FIN
```

```wl
// Connaître le type du champ de saisie "SAI_Date"
SI SAI_Date.TypeSaisie = typSaisieDate ALORS
	Message("Saisissez une date")
FIN
```

```wl
SAI_dynamique.TypeSaisie = SAI_DateHeure.TypeSaisie
SAI_dynamique.FormatMémorisé = "AAAAMMJJHHmmSSCCC"
SAI_dynamique.MasqueSaisie = SAI_DateHeure.MasqueSaisie 
SAI_dynamique = SAI_DateHeure
```

## Syntax

### Identifying the type of a control

`<Result> = <Control used>.InputType`
---

**`<Result>: (Constant)`**

Type of control. The possible values are:



|   |   |
| --- | --- |
| *typInputCurrency* | Currency type. |
| *typInputDate* | Date type. |
| *typInputDuration* | Duration type. |
| *typInputNum* | Numeric type (integer, real, ...). |
| *typInputNumericPrecise* | Numeric type (for Edit controls associated with the Numeric type only). |
| *typInputText* | Text type. |
| *typInputTime* | Time type. |



**`<Control used>: (Control name)`**

Name of the control to be used.  


<a name="SYNTAXE2"></a>

### Changing the type of a control

`<Control used>.InputType = <New type>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.

**`<New type>: (Constant)`**

New type, the possible values are:



|   |   |
| --- | --- |
| *typInputCurrency* | Currency type. |
| *typInputDate* | Date type. |
| *typInputDuration* | Duration type. |
| *typInputNum* | Numeric type (integer, real, ...). |
| *typInputNumericPrecise* | Numeric type (for Edit controls associated with the Numeric type only). |
| *typInputText* | Text type. |
| *typInputTime* | Time type. |

### Pivot Table control
<a name="pivot_table_control_ELTPARAGRAPHE000120"></a>You can use the following syntaxes to identify and change the type displayed for a value in a Pivot Table control:


```txt
{{"Nom_Valeur"}}.TypeSaisie = typSaisieDurée
```
or: 


```txt
Nom_Valeur.TypeSaisie = typSaisieDurée
```
