
## StartTimestamp (Property)

***In french: DateHeureDébut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StartTimestamp** property sets the start date and time of an action. It is available for the following types of variables:

- [hbReading](../WDLang4/1000021701.md),

- [hbScanParameter](../WDLang4/1000021715.md).
