


## MaxAutoID (Property)

***In french: IDAutoMax***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MaxAutoID** property is used to get the maximum automatic identifier of a replicated table. **This property is read-only**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the maximum automatic identifier of the Customer table 
ResMaxAutoID = Customer.MaxAutoID
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table>.MaxAutoID`
---

**`<Result>: (Integer)`**



- Maximum value of the automatic identifier defined for the table,

- 0 if the bounds have not been defined or if the table is not replicated.




**`<Table>: (Character string)`**

Logical name of the table used.
