
## Height (Property)

***In french: Hauteur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Height** property gets and sets the height of an element. This property can be used on:

- an element in a window, page or report. For more details, see [Height](../Proprietes/2510050.md).

- a variable of type [rssStream](../WDLang5/1000017795.md).

- a variable of type [rssImage](../WDLang5/1000017799.md).

- a variable of type [xlsDocument](../WDLang5/1000017464.md).  

- a variable of type [xlsRow](../WDLang5/1000017325.md).

- a variable of type [Image](../WDLang1/1000019650.md).
