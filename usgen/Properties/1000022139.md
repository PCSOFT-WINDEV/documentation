
## ConnectionTimeout (Property)

***In french: TimeoutConnexion***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ConnectionTimeout** property sets the connection timeout. This property is available for:

- a variable of type [sshSession](../WDLang3/1000021157.md).

- a variable of type [httpRequest](../WDLang3/1000021158.md).

- a variable of type [restRequest](../WDLang3/1000021481.md).

- a variable of type [mqttSession](../WDLang3/1000023023.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [apiRequest](../WDLang3/1410088935.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [memcachedConnection](../WDLang4/1000023339.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [redisConnection](../WDLang4/1000023527.md).
