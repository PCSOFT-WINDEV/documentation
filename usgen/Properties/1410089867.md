
## Authentication (Property)

***In french: Authentication***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Authentication** property defines the authentication method required to access resources in a given server or website. This property can be used on:

- a variable of type [httpRequest](../WDLang3/1000021158.md). 

- a variable of type [restRequest](../WDLang3/1000021481.md).
