


## NullSupported (Property)

***In french: NullSupporté***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **NullSupported** property is used to manage the NULL value in HFSQL tables.

This property is used to:

- Determine how the NULL value is handled for a table described in the data model editor.

- Define that the NULL value will be handled when a table is defined programmatically.




**Note** If a table supports the NULL value and the field allows NULL (property [NullAllowed](../Proprietes/1000019492.md)), it will be possible to use property [Null](../Proprietes/2512064.md) to assign NULL to the field for the current record, for example.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the management mode of the NULL value in the Customer table
Customer.NullSupported = True
```

<a name="SYNTAXE1"></a>

## Syntax

### Determining if the data supports the NULL value

`<Result> = <Table>.NullSupported`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file supports the NULL value, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table>: (Character string)`**

Logical name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.

### Defining how the NULL value will be handled

`<Table>.NullSupported = <Management mode>`
---

**`<Table>: (Character string)`**

Logical name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<Management mode>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to manage the NULL value, 

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks


### Special case: View and query
<a name="special_case_view_and_query_ELTPARAGRAPHE000083"></a>

When used on a view or query, the **NullSupported** property returns <u><u><u><u>True</u></u></u></u> if at least one of the source files supports the NULL value.


### Error cases
<a name="error_cases_ELTPARAGRAPHE000094"></a>

Write access to the [Null](../Proprietes/2512064.md) property fails if the **NullSupported** property is set to <u><u><u><u>False</u></u></u></u>.

The error 70409 ("You have called [HModify](../WDLang4/3044042.md). The &lt;XXXX&gt; file does not support the access to the Null property. The management of the Null value must be enabled in the file description.") occurs if the following conditions are fullfilled:

- an item found in a query or in a view is set to NULL, 

- this item comes from a file that does not support the NULL value

- [HModify](../WDLang4/3044042.md) is used on the query or on the view.
