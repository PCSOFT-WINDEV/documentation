
## KeyFileType (Property)

***In french: TypeFichierClé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **KeyFileType** property defines the type of encoding used for a key file. This property can be used on:

- a variable of type [xmlSignature](../WDLang5/1000020736.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) a variable of type [xmlSignatureVerification](../WDLang5/1410090389.md). 

- a variable of type [xmlXAdESSignature](../WDLang5/1410091158.md).
