
## Comment (Property)

***In french: Commentaire***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Comment** property gets and sets the different characteristics of comments in a cell of a Spreadsheet control. These properties are as follows: 

- Text: specifies the text of the comment.  

- Rectangle: defines the rectangle in which the comment will be displayed.  

- Visible: indicates whether or not the comment should be visible. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create a comment
PSHEET_MySpreadsheet["B1"].Comment.Text = "Text of my comment"
PSHEET_MySpreadsheet["B1"].Comment.Visible = True
PSHEET_MySpreadsheet["B1"].Comment.Rectangle.Height = 50
PSHEET_MySpreadsheet["B1"].Comment.Rectangle.Width = 50
PSHEET_MySpreadsheet["B1"].Comment.Rectangle.X = 50
PSHEET_MySpreadsheet["B1"].Comment.Rectangle.Y = 50
```

## Syntax
<a name="SYNTAXE1"></a>

### Getting the characteristics of a comment 

`<Result> = <Spreadsheet control>[<Cell>].Comment.<Property name>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<Spreadsheet control>: (Control name)`**

Name of the Spreadsheet control used. 

**`<Cell>: (Character string)`**

Cell of the Spreadsheet control. 

**`<Property name>: ()`**

Property applied: 


| Property | Type | Description |
| --- | --- | --- |
| Position | Character string | Name of the associated cell. <br><br>This property is read-only. |
| Rectangle | [Rectangle](../Motscles/1514079.md) variable | Defines the rectangle in which the comment is displayed. The **Width** and **Height** properties determine the size of the rectangle (in millimeters), while **X** and **Y** determine the position of the comment (in millimeters with respect to the beginning of the current sheet. |
| Text | Character string | Comment text. |
| Visible | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> to show the comment, <br><br>- <u><u><u><u>False</u></u></u></u> to make the comment invisible. In this case, a red triangle in the upper-right corner of the cell will let the user know that the cell is associated with a comment. <br><br><br> |

## Remarks


### Using an xlsComment variable
<a name="using_xlscomment_variable_ELTPARAGRAPHE000097"></a>

You can define the properties of a comment using a variable of type [xlsComment](../WDLang5/1000024870.md). This makes it possible to set the characteristics of the comment using the following syntax: 

```txt
<Spreadsheet control>.Comment = <xlsComment variable>
```


Example: 


```wl
// Create a comment
MyComment is xlsComment
MyComment.Text = "Comment text"
MyComment.Visible = True
MyComment.Rectangle.Height = 50
MyComment.Rectangle.Width = 50
MyComment.Rectangle.X = 50
MyComment.Rectangle.Y = 50

PSHEET_MySpreadsheet["B1"].Comment = MyComment
```
