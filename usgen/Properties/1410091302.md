
## Animation (Property)

***In french: Animation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Animation** property animates an element. This property is used to: 

- start or stop the animation of an image or text (in a Static Text control). For more details, see the help on the [Animation](../Proprietes/2510006.md) property. 

- set the animation of a window when it opens. For more details, see [WindowOpeningOptions](../WDLang1/1410091298.md).
