
## InvalidInputPreventExit (Property)

***In french: SaisieInvalideBloquante***
	

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29</B>, this property is kept for backward compatibility. It is now recommended to use the [InvalidInput](../Proprietes/1410090439.md) property. 
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InvalidInputPreventExit** property is used to determine if it is possible to leave the control in case of invalid input. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SI SAI_MotDePasse.SaisieInvalideBloquante = Vrai ALORS
	SaisieInvalideAfficheBulle("Saisie non valide.")
FIN
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Identifying the invalid input management mode

`<Result> = <Control used>.InvalidInputPreventExit`
---

**`<Result>: ()`**



- <u><u><u><u>True</u></u></u></u>: it is not possible to exit the field if the entry is invalid and/or the field is empty.. 

- <u><u><u><u>Faux</u></u></u></u>: it is possible to leave the field in all cases. 




**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- an Edit control, 

- an editable Combo Box control.
