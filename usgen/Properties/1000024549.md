
## TokenURL (Property)

***In french: URLToken***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **TokenURL** property gets and sets the URL for retrieving an access token. This property can be used on: 

- a variable of type [OAuth2Parameters](../WDLang3/1000022212.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) a variable of type [JWTParameters](../WDLang3/1410089572.md).
