


## CtDescribedDatabase (Property)

***In french: CxBaseDeDonnéesDécrite***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CtDescribedDatabase** property is used to set the OLE DB data source when connecting to a specific table via OLE DB. You can:

- Get the OLE DB data source used to connect to a table via OLE DB. This table source is defined in the data model editor or when defining the table programmatically.
	Warning: the **CxDescribedDatabase  property** property does not take into account any modifications made with the [HConnect](../WDLang4/3044263.md) function.
	This property can be used for a table defined in the data model editor or programmatically.

- Define the OLE DB data source used to connect to a table via OLE DB (only for tables defined programmatically). This property is equivalent to the [CtDatabase](../Proprietes/2512047.md) property. 




**Reminder** The [HConnect](../WDLang4/3044263.md) function can be used to redefine one or more parameters of the OLE DB connection to a table. By default, the characteristics of the OLE DB connection are set:

- when defining the table in the data model editor,

- when defining the table programmatically.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the OLE DB data source
ResOLEDBDatabase = Customer.CtDescribedDatabase
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the OLE DB data source

`<OLE DB data source> = <Table>.CtDescribedDatabase`
---

**`<OLE DB data source>: (Character string)`**

Full path of the OLE DB data source, specified in the table description.

**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the OLE DB data source

`<Table>.CtDescribedDatabase = <OLE DB data source>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<OLE DB data source>: (Character string)`**

Full path of the OLE DB data source.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The [CtDatabase](../Proprietes/2512047.md) property gets and sets the data source specified for the OLE DB connection.
