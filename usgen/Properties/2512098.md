


## GUIDAnalysis (Property)

***In french: GUIDAnalyse***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **GUIDDatabase schema** property returns the GUID of the database schema that was used to create the table. This identifier is used in the .REP file (for more details, see [Management of .REP files](../WDLang4/3044186.md)). 

**Note** The GUID of the database schema can also be found in the data model editor, in the "General" tab of the database schema description window. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GUIDAnalyse%20-%20HC%20N%B0001.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(Customer.GUIDAnalysis)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Database schema GUID> = <Table>.GUIDAnalysis`
---

**`<Database schema GUID>: (Character string)`**



- GUID of the database schema that was used to create the table. 

- Empty string ("") if the table was created programmatically or if it is not an HFSQL Classic or Client/Server table




**`<Table>: (Character string)`**

Name of the table for which the GUID of the database schema is requested.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
[GUIDFile](../Proprietes/2512099.md) is used to get the GUID of the file. This GUID was defined in the database schema that was used to create the table.
