


## AnimationDuration (Property)

***In french: DuréeAnimation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AnimationDuration** property gets and sets the length of time an animation takes to complete one cycle: 

- in a Chart control. This duration is set to 30 hundredths of a second by default.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) in an infinite Progress Bar control. This duration is set to 200 hundredths of a second by default.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) in an Image Gallery Looper control. This duration is defined in the "General" tab of the image gallery description window.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase timeout
CHART_MyChart.AnimationDuration = 2000
```

<a name="SYNTAXE1"></a>

## Syntax

### Finding out the animation duration

`<Result> = <Control used>.AnimationDuration`
---

**`<Result>: (Integer)`**

Duration of control animation, in hundredths of a second. 

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- A Chart control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) An infinite Progress Bar control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) An Image Gallery Looper control.





<a name="SYNTAXE2"></a>

### Modifying the animation duration

`<Control used>.AnimationDuration = <New duration>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- A Chart control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) An infinite Progress Bar control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) An Image Gallery Looper control.




**`<New duration>: (Integer or Duration)`**

New duration for the control animation in hundredths of a second. If this new duration is set to 0, the animation will not be performed anymore. 
This parameter can correspond to: 

- an integer corresponding to the number of hundredths of a second,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a Duration variable,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the duration in a readable format (e.g., '1cs' or '10 ms').
