


## FullName (Property)

***In french: NomComplet***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FullName** property is used to find out the full name:

- of a control.

- of a window.

- of a menu option.

- of a table column.

## Syntax

### Finding out the full name of specified element

`<Result> = <Element used>.FullName`
---

**`<Result>: (Character string)`**



- Full name of specified element.

- Empty string ("") for: 

	- lines in Table, List, List Box control or Combo fields,

	- cells in Table controls.







**`<Element used>: (Character string)`**

Name of the element to be used.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The **FullName** property can only be used with the following elements:

- Button control.

- Static Text control.

- Image control.

- Window.
