
## TimeUTC (Property)

***In french: HeureUTC***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **TimeUTC** property gets and sets a Coordinated Universal Time (UTC). 

This property can be used on: 

- a variable of type [hScheduledTask](../WDLang4/1000017448.md).

- a variable of type [hScheduling](../WDLang4/1000018853.md).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [appServerScheduledTask](../WDLang2/1000022367.md).
