


## URL (Property)

***In french: URL***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **URL** property is used to:

- Get the address associated with a control.

- Change the address associated with a control.




This control can correspond to:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) an HTML Display control, in the window editor.

- a link, button, clickable image, iFrame control, Peeling Corner control, Bar Code control or menu option (defined in the editor or through programming), in the page editor.

- a link in the report editor.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
LINK_LINK1.URL = "http://www.windev.com"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the address associated with a control

`<Result> = <Control used>.URL`
---

**`<Result>: (Character string)`**

Address associated with the control.

**`<Control used>: (Control name)`**

Name of control to use:

- Window field: HTML Display control field. 

- Page control: Link, Button, Image, iFrame, Peeling Corner control, Barcode or menu option.

- Report field: Link.  





<a name="SYNTAXE2"></a>

### Changing the address associated with a link

`<Control used>.URL = <New address>`
---

**`<Control used>: (Control name)`**

Name of control to use:

- Window field: HTML Display control field. 

- Page control: Link, Button, Image, iFrame, Peeling Corner control, Barcode or menu option.

- Report field: Link.




**`<New address>: (Any type)`**

New address associated with the link. This address must contain "http://".

### URL property and Value property
<a name="url_property_and_value_property_ELTPARAGRAPHE000089"></a>

The **URL** property has the same effect as the [Value](../Proprietes/2510130.md) property on Button, Link and iFrame controls.
<a name="NOTE0_2"></a>


### Limits
<a name="limits_ELTPARAGRAPHE000101"></a>

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The **URL** property is only available for:

- Link controls in a page.

- Button controls in a page.

- Clickable Image controls in a page.

- iFrame controls in a page.

- menu options in a page.

- Peeling Corner controls in a page.

- Bar Code controls in a page.  

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the Link controls in a report.


 
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The **URL** property can only be used on:

- Link controls in a page.

- Image controls in a page.

- Clickable Image controls in a page.

- links in a Breadcrumb control.

- Peeling Corner controls in a page.

- Captcha controls in a page.

- menu options in a page.
