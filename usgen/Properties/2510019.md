


## Checked (Property)

***In french: Cochée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Checked** property gets and sets the checkmark state of an element. 

This property can be used: 

- in the options of the main menus and context menus. In this case, you can know whether the checkmark is displayed to the left of the option. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) on the rows of TreeView controls. In this case, you can determine whether the checkmark is displayed, hidden or in an undefined state. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Clic sur l'option "Afficher les Totaux"
SI OPT_OptionAfficher.Cochée ALORS
	OPT_OptionAfficher.Cochée = Faux
	LIB_TOTAL.Visible = Faux
SINON
	OPT_OptionAfficher.Cochée = Vrai
	LIB_TOTAL.Visible = Vrai
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the checkmark state of an element

`<Result> = <Element to handle>.Checked`
---

**`<Result>: (Boolean or integer)`**



- For a menu option: 

	- <u><u><u><u>True</u></u></u></u> if the menu option is checked,

	- <u><u><u><u>False</u></u></u></u> otherwise.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For a line of a TreeView control: 

	- 1 if the option is checked

	- 0 if the option is unchecked

	- -1 if the option state is undefined.







**`<Element to handle>: (Character string)`**

Name of element to use: 

- Name of the menu option. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView control line specified with the following notation: &lt;Champ Arbre&gt;[Line index]. 





<a name="SYNTAXE2"></a>

### Changing the checkmark state of an element

`<Element to handle>.Checked = <Displayed>`
---

**`<Element to handle>: (Character string)`**

Name of element to use: 

- Name of the menu option. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView control line specified with the following notation: &lt;Champ Arbre&gt;[Line index]. 




**`<Displayed>: (Boolean or integer)`**



- For a menu option: 

	- <u><u><u><u>True</u></u></u></u> if the menu option is checked,

	- <u><u><u><u>False</u></u></u></u> otherwise.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For a line of a TreeView control: 

	- 1 if the option is checked

	- 0 if the option is unchecked

	- -1 if the option state is undefined.
