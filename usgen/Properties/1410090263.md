
## AutomaticValidationTimeout (Property)

***In french: DuréeValidationAutomatique***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AutomaticValidationTimeout** property defines the time elapsed before the steps of a Guided Tour are automatically validated. This property can be used on:

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
