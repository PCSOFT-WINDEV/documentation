
## Termination (Property)

***In french: Terminaison***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Termination** property defines the WLanguage procedure executed when the user goes to the next or previous step, or at the end of a Guided Tour. This property can be used on:

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
