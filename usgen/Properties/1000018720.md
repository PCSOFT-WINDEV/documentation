
## Priority (Property)

***In french: Priorité***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Priority** property is used to get and change the priority level of an element. 

This property can be used on:

- the [Email](../WDLang3/3032029.md) structure.

- a variable of type [Email](../WDLang3/1000018713.md). 

- a variable of type [Notification](../WDLang3/1000019441.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [notificationCategory](../WDLang3/1000023981.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [Document](../WDLang1/1000022461.md).

- a variable of type [Thread](../WDLang1/1000024879.md).
