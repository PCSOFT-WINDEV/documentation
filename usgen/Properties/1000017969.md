
## State (Property)

***In french: Etat***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **State** property gets and sets the state of an element. This property can be used on:

- **controls, windows, pages and reports**. For more details, see [State property on controls](../Proprietes/2510039.md).

- a variable of type [ParallelTask](../WDLang1/1000021220.md).

- a variable of type [Thread](../WDLang1/1000024879.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadInfo](../WDLang3/1410087306.md).

- a variable of type [hSchedulingHistory](../WDLang4/1410090764.md).

- a variable of type [hReindexingHistory](../WDLang4/1410091059.md).
