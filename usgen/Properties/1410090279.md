
## EndTour (Property)

***In french: FinVisite***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **EndTour** property is used to allow or prevent the user from ending the Guided Tour from the tooltip of a given step. This property can be used on:

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
