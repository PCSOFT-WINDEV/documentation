
## Markdown (Property)

***In french: Markdown***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Markdown** property is used to enable or disable Markdown formatting: 

- in a control in a window. For more details, see the help on the [Markdown](../Proprietes/1410089000.md) property. 

- in a Static Text control in a report. For more details, see the help on the [Markdown](../Proprietes/1410089000.md) property. 

- in the controls of the internal window (title and description) used as a step of the Guided Tour. This property can be used on:

	- a variable of type [GuidedTour](../WDLang6/1410090170.md).

	- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
