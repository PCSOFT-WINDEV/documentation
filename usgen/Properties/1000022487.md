
## Style (Property)

***In french: Style***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Style** property is used to: 

- retrieve or assign the entire style of a control (including the overrides). For more details, see the help on the [Style](../Proprietes/1000021472.md) property. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) get the style associated with a Word Processing document. This property can be used on the [Document](../WDLang1/1000022461.md) variables.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) define button styles for a Windows notification. This property can be used on the [sysNotificationButton](../WDLang1/1410087947.md) variables.
