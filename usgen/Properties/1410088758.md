
## NullableIndex (Property)

***In french: NullIndexé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **NullIableIndex** property determines if a key item supports the "Null" value. You can:  

- Determine if a key item supports the "Null" value. 

- Allow or disallow the use of "Null" values in a key item (only when defining the table programmatically). 




Note: This property is equivalent to the **"Allow NULL values in indexes (the table will be compatible only with version 28 and later)"** option in the "Details" tab of the table description window, in the database schema editor. 

**Note: Tables with the "Allow NULL values in indexes" option are only compatible with applications in version 28 or later.**
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AFile is File Description
AnItem is Item Description
// Describe the "CUSTOMER" table
AFile.Name = "CUSTOMER"
AFile.Type = hFileNormal
AFile.NullableIndex = True
// Item description 
AnItem.Name = "Message"
AnItem.Type = hItemText
AnItem.Size = 40
HDescribeItem(AFile, AnItem)
// Validate the table description 
HDescribeFile(AFile)
```

## Syntax

### Determining if a key item supports the "Null" value 

`<Result> = <Table>.NullableIndex`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table is configured to support "Null" values in a key item,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table>: (Character string)`**

Name of the table used. This name was defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.


<a name="SYNTAXE2"></a>

### Allowing or disallowing the use of "Null" values in a key item (table defined programmatically)

`<Table>.NullableIndex = <NULL value supported>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<NULL value supported>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table should be configured to support "Null" values in a key item,

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### "Null" value supported in key items
<a name="null_value_supported_key_items_ELTPARAGRAPHE000071"></a>

If the keys in the table support the "Null" value: 

- You can use search functions including the "Null" value. 

- Several keys in the table can contain the "Null" value.
