


## Selected (Property)

***In french: Sélectionnée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Selected** property is used to:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Select, or determine if a row is selected in a List, ListView or Table control. 
	**Remark**: Unlike the [ListSelect](../WDLang1/3049011.md) function, this property lets you know directly whether the line with the specified index is selected or not.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Select, or determine if a column or cell is selected in a Table control with row or column selection.   

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Select, or determine if a tab menu option is selected.

### Determining if an element is selected

`<Result> = <Control used>[<Row index>].Selected`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element is selected, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (Control name)`**

Name of control to use: 

- List, ListView control or Table field name: indicates whether the line is selected.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Column name: shows whether the cell is selected. If the row index is not specified, allows you to determine whether the column is selected. 




**`<Row index>: (Integer)`**

Index of the row to use.  


<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 
### Selecting an element

`<Control used>[<Row index>].Selected = <Selection>`
---

**`<Control used>: (Control name)`**

Name of control to use: 

- List, Image List or Table field name: select or deselect a line.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Column name: to select or deselect a cell. If the row index is not specified, enables you to select or deselect the table column. 




**`<Row index>: (Integer)`**

Index of the row to use.

**`<Selection>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element must be selected, 

- <u><u><u><u>False</u></u></u></u> otherwise.

### Single-selection and multi-selection List Box control
<a name="singleselection_and_multiselection_list_box_control_ELTPARAGRAPHE000150"></a>

In multi-selection List Box controls, the **Selected** property is used to:

- find out the selected rows.

- select several rows.




In single-selection List Box controls, when a row is selected with the **Selected** property, the previously selected row is automatically deselected.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The multi-selection List Box controls are not available.

### Limits
<a name="limits_ELTPARAGRAPHE000172"></a>

The **Selected** property applies only to:

- Table controls.

- List Box controls.

- ListView controls.

- Table columns.

- Table cells.
