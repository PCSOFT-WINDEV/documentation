
## Polygon (Property)

***In french: Polygone***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Polygon** keyword can correspond to: 

- a variable of type [Polygon](../WDLang1/1000025624.md). 

- a property of a variable of type [ocrTextBlock](../WDLang6/1000025639.md). 

- a property of a variable of type [MultiPolygon2D](../WDLang4/1410090135.md).

- a property of a variable of type [MultiPolygonGeo](../WDLang4/1410090136.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [aiImageResult](../WDLang6/1410087965.md).
