


## OperationLogDirectory (Property)

***In french: RépertoireJournalOperation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DirectoryJournalOperation** property is used to manage the directory of the log of operations file associated with a log table.. You can:

- Find out the directory of operation log linked to a log table defined in the data model editor or programmatically.

- Define the directory of the operation log for a table (when describing the table through programming).




**Reminder** The log of operations file (JournalOperation.fic) and the log file identification file (journalIdentification.fic) are not created by default when logging a table. These files are automatically created when a table is logged in read-only or when replication is implemented on a table.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines the directory of operation log
// for the Orders table (described through programming)
Commande.RépertoireJournalOpération = "C:\MesFichiers\Opérations"
...
// Validate the table description
HDescribeFile(Orders)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the directory of the operations file of a log table

`<Current directory> = <Table>.OperationLogDirectory`
---

**`<Current directory>: (Character string)`**



- Directory name of "LogOperation.fic" file associated with the logged table,

- "." if the directory corresponds to the current directory.




**`<Table>: (Character string)`**

(Logical) name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the directory of the operations file for a log table described programmatically

`<Table>.OperationLogDirectory = <New directory>`
---

**`<Table>: (Character string)`**

(Logical) name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New directory>: (Character string)`**

Directory name of the "JournalOpération.fic" file associated with the logged table.
