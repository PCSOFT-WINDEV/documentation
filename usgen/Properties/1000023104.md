
## FilePath (Property)

***In french: CheminFichier***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FilePath** property gets: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the name of the xlsx file associated with a Spreadsheet control. This name can be initialized using [SpreadsheetLoad](../WDLang1/1000021340.md) and [SpreadsheetSave](../WDLang1/1000021341.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the name of the file associated with an Image Editor control. This name can be initialized using [PicOpen](../WDLang1/1000023379.md) and [PicSave](../WDLang1/1000023381.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the name of the PDF file associated with a PDF Reader control. This name can be initialized using [PDFReaderOpen](../WDLang1/1000023452.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the name of the DOCX file associated with a Word Processing control. This name can be initialized using [DocOpen](../WDLang1/1000022622.md) and [DocSave](../WDLang1/1000022387.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of the wddiag file associated with a Diagram Editor control. This name can be initialized using [DiagramLoad](../WDLang1/1410088123.md) and [DiagramSave](../WDLang1/1410088122.md).

<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
IF PSHEET_MySpreadsheet.FilePath <> "" THEN
	STC_SpreadsheetTitle = PSHEET_MySpreadsheet.FilePath
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the name of the file associated with the control

`<Result> = <Control to use>.FilePath`
---

**`<Result>: (Character string)`**

Name of the file associated with the control. 

**`<Control to use>: (Control name)`**

Name of control to use: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Spreadsheet control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image Editor control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Word Processing control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) PDF Reader control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Diagram Editor control.

<a name="NOTE0_1"></a>

## Remarks


- By default, the **FilePath** property is an empty string.

- This property is available for: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Spreadsheet controls in a window. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image Editor controls.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Word Processing controls.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) PDF Reader controls. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Diagram Editor controls.
