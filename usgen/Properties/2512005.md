
## MaxSourceCardinality (Property)

***In french: CardinalitéSourceMax***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MaxSourceCardinality** property sets the characteristics of a link. You can:

- Get the maximum cardinality of the source item in the link.

- Change the maximum cardinality of the source item in the link.



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CardinaliteMLDwb%202.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change the maximum cardinality
LinkClubMember.MaxSourceCardinality = hInfiniteCardinality
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the maximum cardinality of the source item

`<Cardinality> = <Link>.MaxSourceCardinality`
---

**`<Cardinality>: (Integer)`**

Maximum cardinality of the source item for the link. The *hInfiniteCardinality* constant identifies the "n" cardinality.

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Changing the maximum cardinality of the source item

`<Link>.MaxSourceCardinality = <New cardinality>`
---

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.

**`<New cardinality>: (Integer)`**

New maximum cardinality for the source item of the link. The *hInfiniteCardinality* constant defines the "n" cardinality. By default, when a link is defined programmatically, the maximum cardinality of the source item is 1.
