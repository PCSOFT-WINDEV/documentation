
## DefaultFilePath (Property)

***In french: CheminFichierParDéfaut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DefaultFilePath** property gets and sets the full file name (path and file name) suggested by default when saving a document in a Word Processing or HTML Editor control via the "Save as" option.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WP_WPControl.DefaultFilePath = "C:\mydocs\doc.docx"
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the full file name suggested by default

`<Result> = <Control used>.DefaultFilePath`
---

**`<Result>: (Character string)`**

Full file name suggested by default when saving a document via the "Save as" option. 

**`<Control used>: (Control name)`**

Name of the control used: 

- Word Processing control. 

- HTML Editor control. 





<a name="SYNTAXE2"></a>

### Changing the full file name suggested by default

`<Control used>.DefaultFilePath = <Default path>`
---

**`<Control used>: (Control name)`**

Name of the control used: 

- Word Processing control. 

- HTML Editor control. 




**`<Default path>: (Character string)`**

Full file name suggested by default when saving a document via the "Save as" option.
