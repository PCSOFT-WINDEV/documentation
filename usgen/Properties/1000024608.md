
## Visible (Property)

***In french: Visible***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Visible** property sets the visibility of an element. This property can be used on:

- controls in a window, page or report. For more details, see [Visible](../Proprietes/2510138.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [picLayer](../WDLang1/1000024604.md).

- a variable of type [kbCard](../WDLang1/1410089167.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the [LeftButton](../Proprietes/1410090001.md) property of an Edit control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the [RightButton](../Proprietes/1410090002.md) property of an Edit control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [xlsComment](../WDLang5/1000024870.md). 

- a variable of type [WindowOpeningOptions](../WDLang1/1410091298.md).
