


## MinValue (Property)

***In french: BorneMin***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MinValue** property is used to:

- get and set the bottom value of a **report based on a table**. The bottom value is the minimum value allowed for the search key of the HFSQL table the report is based on.

- get the minimum value of the **current filter** (set by [HFilter](../WDLang4/3044100.md)) on an HFSQL table, view or query.

- get the minimum value of a **data series in a chart**.

- get and set the minimum value for **some types of controls**.

## Syntax

### Getting the minimum value of a control or report

`<Current value> = <Element used>.MinValue`
---

**`<Current value>: (Character string)`**

Current minimum value:

- of the report based on a table.

- of a control in a window or page.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) of the Calendar control in a page. The minimum value represents the minimum date that can be displayed in the calendar.




**`<Element used>: (Control or report name)`**

This parameter corresponds to:

- the name of the report used (report based on a table).

- the name of the control for which you want to get the minimum value (control in a window or page). The list of the controls that can be manipulated is in the "Limitations" paragraph. 





<a name="SYNTAXE2"></a>

### Changing the minimum value of a control or report

`<Element used>.MinValue = <New value>`
---

**`<Element used>: (Control or report name)`**

This parameter corresponds to:

- the name of the report used (report based on a table).

- the name of the control for which you want to get the minimum value (control in a window or page).




**`<New value>: (Int)`**

New minimum value:

- of the report based on a table.

- of a control in a window or page. The list of the controls that can be manipulated is in the "Limitations" paragraph. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) of the Calendar control in a page. The minimum value represents the minimum date that can be displayed in the calendar.  

- of the Rating control. Only values 0 and 1 are allowed.

### Getting the minimum value of the current filter

`<Current value> = <Element used>.MinValue`
---

**`<Current value>: (Type of filter used)`**



- Current minimum value of the filter applied on the specified element. This filter is defined with the [HFilter](../WDLang4/3044100.md) function. 

- Empty string ("") in the following cases:

	- no filter was defined for the specified element

	- the filter is disabled

	- no minimum value was specified for the filter







**`<Element used>: (Element name)`**

Name of the table, query or view used.

### Get the minimum value of a data series in a chart

`<Minimum value> = <Series>.MinValue`
---

**`<Minimum value>: (Int)`**

Minimum value of the data series. This value only exists if it has been calculated (for example, if the series has been drawn).

**`<Series>: (Character string)`**

Series to use. Use the following notation: *&lt;Chart name&gt;[&lt;Series number&gt;]*.

## Remarks


### Bounds for a report based on a table
<a name="bounds_for_report_based_table_ELTPARAGRAPHE000155"></a>

Bounds select only those records whose search key is between the bottom value (returned by the **MinValue** property) and the top value (returned by the [MaxValue](../Proprietes/2510009.md) property).
<a name="NOTE0_2"></a>


### Limits for a report
<a name="limits_for_report_ELTPARAGRAPHE000167"></a>

The **MinValue** property can only be used on reports based on tables. When creating the report, you need to specify that the search is bounded by the minimum value. 
<a name="NOTE0_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Limits for a window control
<a name="limits_for_window_control_ELTPARAGRAPHE000178"></a>

The minimum value cannot be greater than the maximum value. The maximum value is returned by the [MaxValue](../Proprietes/2510009.md) property.
<a name="NOTE0_4"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000188"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) This property can be used on the following types of controls:

- Scrollbar control, 

- Progress Bar control and Progress Bar columns,

- Slider control (linear or circular),

- Spin control, 

- Splitter control, 

- Calendar control, 

- Numeric Edit control (no number less than the defined value can be entered),

- Duration Edit control (no duration less than the defined value can be entered),

- Range Slider, 

- Rating.




The default minimum value can be defined in the "Details" tab of the control description window.

- Slider controls.

- Progress Bar controls.

- Rating controls.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Edit controls (numeric, date, time, duration).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Editable columns in a Table control (numeric, date, time, duration).




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property can be used on the following types of controls:

- Duration Edit controls (no duration less than the defined value can be entered),

- Chart controls.

- Numeric columns of Table controls.




The default minimum value can be defined in the "Details" tab of the control description window.
