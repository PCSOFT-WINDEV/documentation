


## PhoneNumber (Property)

***In french: Téléphone***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PhoneNumber** property is used to get and change a phone number. This property can be used on:

- a variable of type [gglContact](../WDLang5/1000017434.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Contact](../WDLang3/1000020254.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [gpwUser](../WDLang6/1000021088.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [WBAdminAccount](../WDLang2/1410089382.md).
