
## MinSourceCardinality (Property)

***In french: CardinalitéSourceMin***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MinSourceCardinality** property sets the characteristics of a link. You can:

- Get the minimum cardinality of the source item in the link.

- Change the minimum cardinality of the source item in the link.



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CardinaliteMLDwb%202.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change the minimum cardinality
LinkClub.MinSourceCardinality = 0
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the minimum cardinality of the source item

`<Cardinality> = <Link>.MinSourceCardinality`
---

**`<Cardinality>: (Integer)`**

Minimum cardinality of the source item.

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Changing the minimum cardinality of the source item

`<Link>.MinSourceCardinality = <New cardinality>`
---

**`<Link>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.

**`<New cardinality>: (Integer)`**

New minimum cardinality for the source item. By default, when a link is defined programmatically, the minimum cardinality of the source item is 0.
