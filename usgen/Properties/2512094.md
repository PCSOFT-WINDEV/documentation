


## WDD55 (Property)

***In french: WDD55***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WDD55** property is used to:

- Get the name and full path of the Hyper File 5.5 WDD file. This table is used to access the Hyper File 5.5 files in an HFSQL Classic database schema.

- Set the name and full path of the Hyper File 5.5 WDD file. This table is used to access the Hyper File 5.5 files in an HFSQL Classic database schema. This property can be used to programmatically describe a Hyper File 5.5 table in an HFSQL Classic database schema.




**Warning** This property can only be used for Hyper File 5.5 tables that have not been migrated to HFSQL Classic format.

The name of the 5.5 WDD format can be retrieved in the description of the table in the database schema ("Compatibility" tab).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the path of the Orders table
ResPath = Orders.WDD55
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the path of the Hyper File 5.5 WDD file

`<Result> = <Table>.WDD55`
---

**`<Result>: (Character string)`**

Path of the WDD corresponding to the initial Hyper File 5.5 database schema. If the runtime directory of the database schema corresponds to the current directory, the path is relative to the current directory.

**`<Table>: (Character string)`**

Name of the Hyper File 5.5 file used.  


<a name="SYNTAXE2"></a>

### Setting the path of the Hyper File 5.5 WDD file

`<Table>.WDD55 = <Path>`
---

**`<Table>: (Character string)`**

Name of the table used. Name defined using the [File Description](../WDLang4/1514065.md) type.

**`<Path>: (Character string)`**

Path of the WDD corresponding to the initial Hyper File 5.5 database schema.
