


## LogBackupDirectory (Property)

***In french: RépertoireSauvegardeJournal***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LogBackupDirectory** property is used to manage the backup directory of log files. You can:

- Find out the backup directory of the log for a table defined in the data model editor or programmatically.

- Define the backup directory of the log for a table (only when describing the table through programming).




**Note** This path is used for automated modification of tables for archiving logs. [HHistoryModification](../WDLang4/3044344.md) will also search for change history in these files.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the log directory of the Orders table
Orders.LogBackupDirectory = "C:\MyFiles\MyLogs_BCK"
...
// Validate the file description
HDescribeFile(Orders)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the backup directory of a file log

`<Current name> = <Table>.LogBackupDirectory`
---

**`<Current name>: (Character string)`**

Name of the backup directory of the log file associated with the table. By default, this path corresponds to: &lt;répertoire des fichiers JNL&gt;\\__JNLBackup. If this parameter corresponds to a relative path (and starts with a dot), the path will be relative to tables.

**`<Table>: (Character string)`**

Logical name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the backup directory of the log for a file created programmatically

`<Table>.LogBackupDirectory = <New name>`
---

**`<Table>: (Character string)`**

Logical name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New name>: (Character string)`**

Backup path of the log files corresponding to the specified table. By default, this path corresponds to: &lt;répertoire des fichiers JNL&gt;\\__JNLBackup. 
If this parameter corresponds to an empty string (""), the current location is not modified. 
If this parameter corresponds to a relative path (and starts with a dot), the path will be relative to tables.
