
## FilePath (Property)

***In french: CheminFichier***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FilePath** property gets the name of the file associated with a control. This property can be used on:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) an office control in a window (Spreadsheet, Word Processing, Image Editor and PDF Reader controls). For more details, see [FilePath](../Proprietes/1000023104.md).

- a variable of type [Document](../WDLang1/1000022461.md).
