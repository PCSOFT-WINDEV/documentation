


## CtDescribedAccess (Property)

***In french: CxAccèsDécrit***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CtDescribedAccess** property is used to set the type of access to the table when connecting to a specific table via OLE DB. You can:

- Get the type of access to the table used to connect to a table via OLE DB. This type of access is defined in the data model editor or when defining the table programmatically.
	Warning: The **CxAccèsDécrit** property does not take into account any modifications made with the [HConnect](../WDLang4/3044263.md) function.
	This property can be used for a table defined in the data model editor or programmatically.

- Define the type of access to the table used for connecting to a table via OLE DB (only for tables defined programmatically). This property is equivalent to the [CtAccess](../Proprietes/2512015.md) property. 




**Reminder** The [HConnect](../WDLang4/3044263.md) function can be used to redefine one or more parameters of the OLE DB connection to a table. By default, the characteristics of the OLE DB connection are set:

- when defining the table in the data model editor,

- when defining the table programmatically.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the type of access to the Customer table
ResAccessType = Customer.CtDescribedAccess
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the type of access to the table via OLE DB

`<Type of access> = <Table>.CtDescribedAccess`
---

**`<Type of access>: (Constant)`**

Returns the type of access to the specified table. 
This information is defined when defining the table (in the data model editor or programmatically).



|   |   |
| --- | --- |
| *hORead* | The table can be accessed in read-only mode. It is only possible to read records. It is not possible to add or remove records. |
| *hOReadWrite* | The table can be accessed in read/write mode. It is possible to read and write new records. |



**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the type of access to the file via OLE DB

`<Table>.CtDescribedAccess = <Type of access>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<Type of access>: (Constant)`**

Defines the type of access to the table.



|   |   |
| --- | --- |
| *hORead* | The table can be accessed in read-only mode. It is only possible to read records. It is not possible to add or remove records. |
| *hOReadWrite* | The table can be accessed in read/write mode. It is possible to read and write new records. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The [CtAccess](../Proprietes/2512015.md) property is used to identify the type of access currently used for the OLE DB connection. This property can also be used to define the type of access (only for tables defined programmatically).
