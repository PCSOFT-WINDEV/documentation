


## NullAllowed (Property)

***In french: NullAutorisé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **NullAllowed** property is used to manage the NULL value in the items of HFSQL tables.

This property is used to:

- Find out the management mode of the NULL value for a table item described in the data model editor.

- Define the management mode of the NULL value when a table item is defined programmatically.




If the table and the item support NULL values, the [Null](../Proprietes/2512064.md) property can be used to assign NULL to the item for the current record.

The **NullAllowed** property is useful to prevent the use of the NULL value for some items in a table defined through programming (a table that supports the NULL value).  


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining if the item allows the use of the NULL value

`<Résultat> = <Fichier de données>.<Rubrique>.NullAuthorized`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the item allows the use of the NULL value, 

- <u><u><u><u>False</u></u></u></u> if the item does not allow the use of the NULL value.




**`<Table>: (Character string)`**

Logical name of the table used. This name was defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.

**`<Item>: (Character string)`**

Name of the item used. This name was defined in the data model editor or with the [Item Description](../WDLang4/1514071.md) type.


<a name="SYNTAXE2"></a>

### Defining the management mode of the NULL value for the item

`<item>.NullAllowed = <Management mode>`
---

**`<Item>: (Character string)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<Management mode>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to manage the NULL value, 

- <u><u><u><u>False</u></u></u></u> not to support the NULL value.







## Remarks


### How to know whether a table supports the management of NULL value
<a name="how_know_whether_table_supports_the_management_null_value_ELTPARAGRAPHE000077"></a>

To determine if a table allows the use of the NULL value, use the [NullSupported](../Proprietes/2512061.md) property.

Caution:

- Assigning the property **NullAllowed** property on a table or field that does not support NULL value management is prohibited: a fatal error is displayed.

- Reading the **NullAllowed** property on a table or item that does not support the NULL value always returns <u><u><u><u>False</u></u></u></u>.



<a name="NOTE0_2"></a>


### Limits
<a name="limits_ELTPARAGRAPHE000100"></a>

The NULL value cannot be used:

- on array items.

- on automatic identifiers.

- on composite keys.
