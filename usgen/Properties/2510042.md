


## Filter (Property)

***In french: Filtre***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Filter** property is used to identify and change the filter applied to records in: 

- Data-bound Table controls,

- browsing TreeView Table controls,

- List Box controls based on a table,

- Combo Box controls based on a table,

- Looper controls based on a table. 




This filter (if it exists) can be defined during the control description ("Content" tab).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Filtre.gif)
This filter (property **Filter** property or filter entered in the editor) has the following characteristics:

- "Starts with" filter.

- applies to the search item only.

- affects the object used (Table, Combo Box, List Box or ListView control)

- does not affect the table on which the object is based (except for the data-bound Table controls based on a table, see below).




Remarks:

- To use a filter on a composite key, use [HFilter](../WDLang4/3044100.md).

- The **Filter** property cannot be used to identify filters defined by the user (with the [TableEnableFilter](../WDLang1/1000017149.md) function, for example).

<a name="sample_code"></a>

## Example


```wl
// - Code whenever a Combo Box control is modified
// Update elements of the Combo Box control according to
// the letters entered in the edit control of the Combo Box
COMBO_Element.Filter = COMBO_Element
```
<a name="Exemple2"></a>

```wl
// Identifies the filter condition on the City search key
IF TABLE_Customer.Filter = "" THEN
	TABLE_Customer.Filter = "PARIS"
END
```

## Syntax

### Finding out the filter defined on the search item

`<Filter value> = <Control used>.Filter`
---

**`<Filter value>: (Type of filter)`**

Current value of filter defined on the search item. This filter is a "Start with" filter.

**`<Control used>: (Control name)`**

Name of the field whose current filter we want to know: this filter has been defined either by the property **Filter PROPERTY**property, or directly in the window or page editor (in the field description). The type of this control must be: 

- List or List image file, 

- File combo, 

- browsing Table or TreeView Table,

- Looper based on a table.  





<a name="SYNTAXE2"></a>

### Modifying the filter defined on the search item

`<Control used>.Filter = <New filter value>`
---

**`<Control used>: (Control name)`**

Name of control whose current filter will be modified. The type of this control must be: 

- List or List image file, 

- File combo, 

- browsing Table or TreeView Table,

- Looper based on a table.    




**`<New filter value>: (Type of filter)`**



- New value for the filter defined on the search key, 

- Empty string ("") for no filter.

## Remarks


### Filter property and data-bound Table controls
<a name="filter_property_and_databound_table_controls_ELTPARAGRAPHE000098"></a>

For data-bound Table controls, the Check Box "Use HFilter to browse the file" is used to keep the search and sort options on the filtered columns (magnifier, etc.).

If "Use HFilter to browse the file" is checked:

- the property is not applied to the data-bound Table control only but it is also applied to the table onto which the control is based. Therefore, a browse performed on the base file of the control will be filtered.

- A filter ([HFilter](../WDLang4/3044100.md)) is automatically applied to the table onto which the data-bound Table control is based.

- If a filter is defined on the table ([HFilter](../WDLang4/3044100.md)) BEFORE displaying the data-bound Table control ([TableDisplay](../WDLang1/3074003.md) for example), only the filter of the data-bound Table control will be taken into account. Then, the table will be browsed according to the filter of the Table control.



<a name="NOTE0_2"></a>


### Manipulation of Table, List, ListView control, Combo and RepeatString file fields using properties
<a name="manipulation_table_list_listview_control_combo_and_repeatstring_file_fields_using_properties_ELTPARAGRAPHE000128"></a>

- The records displayed in a List Box, Table, Combo Box or Looper control based on a table come from the table or query specified with the [BrowsedFile](../Proprietes/2510040.md) property.

- The sort direction is defined by the [BrowsedItem](../Proprietes/2510111.md) property.

- The records can be filtered using the **Filter** property or the [HFilter](../WDLang4/3044100.md) function. **Attention** property **Filter** property only allows "Starts with" filtering on the route key.



<a name="NOTE0_3"></a>


### Modifying the properties used to loop through a Table, List Box, ListView, Combo Box or Looper control based on a table
<a name="modifying_the_properties_used_loop_through_table_list_box_listview_combo_box_looper_control_based_table_ELTPARAGRAPHE000150"></a>

To modify several properties ([BrowsedItem](../Proprietes/2510111.md), **Filter** and [BrowsedFile](../Proprietes/2510040.md)), it is recommended to:

1. Stop the iteration by assigning an empty string ("") to the [BrowsedFile](../Proprietes/2510040.md) property.

2. Change the relevant properties.

3. Restart the iteration with the [BrowsedFile](../Proprietes/2510040.md) property.


This method is used to optimize the modifications performed. Each one of the modifications made individually restarts the iteration. These operations can become quite slow when they are performed on large files.
<a name="NOTE0_4"></a>


### Limit
<a name="limit_ELTPARAGRAPHE000177"></a>

The **Filter** property applies only to controls in a window or page. This property applies only to the following controls:

- Data-bound List Box control,

- ListView control image file,

- Browsing Combo Box control, 

- Data-bound Table control, 

- Looper control RepeatString file field, 

- Browsing TreeView Table control.
