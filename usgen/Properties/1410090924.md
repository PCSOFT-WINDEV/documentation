
## DisplayedName (Property)

***In french: NomAffiché***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DisplayedName** gets the name of the account or contact as it is displayed in the applications that use it. This name can be a user's nickname. 

This property can be used on:

- a variable of type [Contact](../WDLang3/1000020254.md).

- a variable of type [gglAccount](../WDLang3/1410089816.md).
