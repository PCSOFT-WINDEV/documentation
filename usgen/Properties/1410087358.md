
## Progress (Property)

***In french: Progress***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Progress** property returns the task progress status. This property can be used on:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [GanttTask](../WDLang1/1000020881.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadInfo](../WDLang3/1410087306.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [sysNotificationProgressBar](../WDLang1/1410090964.md).

- a variable of type [hReindexingHistory](../WDLang4/1410091059.md).
