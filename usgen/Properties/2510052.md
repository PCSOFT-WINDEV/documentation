


## Timeout (Property)

***In french: Timeout***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Timeout** property gets and sets the time after which the connection is considered to have "failed". This timeout is taken into account when the [StreamConnect](../WDLang3/3039008.md) function and the [Address](../Proprietes/2510017.md) property are used.



The default timeout is set to 2 minutes by default.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase timeout
MyStream.Timeout = 150000
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the timeout before the connection fails

`<Result> = <Stream name>.Timeout`
---

**`<Result>: (Integer)`**

Time after which the connection is considered to have "failed". This time is expressed in milliseconds. The default timeout is set to 2 minutes (or 120 000 milliseconds).

**`<Stream name>: (Character string)`**

Name of the stream or name of the Conference control associated with the stream.  


<a name="SYNTAXE2"></a>

### Modifying the timeout before the connection fails

`<Stream name>.Timeout = <New timeout>`
---

**`<Stream name>: (Character string)`**

Name of the stream or name of the Conference control associated with the stream.

**`<New timeout>: (Integer or Duration)`**

Time after which the connection is considered to have "failed". This time is expressed in milliseconds. The default timeout is set to 2 minutes (or 120 000 milliseconds). This parameter can correspond to: 

- an integer corresponding to the number of thousands of a second,

- a Duration variable,

- the duration in a readable format (e.g., '1cs' or '10 ms').
