


## TouchZoom (Property)

***In french: ZoomAuDoigt***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>30.3 (3003)</B>, ***ZoomWithFinger*</**>** is kept for backward compatibility. This property has been replaced with ***TouchZoom*</**>**.

<a name="Utilisation"></a>
<a name="description"></a>
The **TouchZoom** property allows you to:

- determine if an Image or Camera control supports pinch zoom. 

- enable or disable pinch zoom in an Image or Camera control. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To use this property on a Camera control, the control must have been created with version 27 or have the following option unchecked: Version-26-compatible mode: Use VideoParameter( ) to configure the control ("General" tab of the Camera control).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// In drawing mode, no pinch zoom
IF bDrawing = True THEN
	IMG_Image1.TouchZoom = False
ELSE
	IMG_Image1.TouchZoom = True
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Determining if an Image or Camera control supports pinch zoom

`<Result> = <Control used>.TouchZoom`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if pinch zoom is enabled,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Control used>: (Control name)`**

Name of control to use: 

- Image control,

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Camera control. 





<a name="SYNTAXE2"></a>

### Enabling or disabling pinch zoom in an Image or Camera control

`<Control used>.TouchZoom = <Authorization>`
---

**`<Control used>: (Control name)`**

Name of control to use: 

- Image control,

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Camera control. 




**`<Authorization>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to enable pinch zoom,

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks


### Use in an Image control
<a name="use_image_control_ELTPARAGRAPHE000093"></a>

- This property is mainly used to temporarily interrupt the pinch zoom in order to drawn in an Image control. Similarly, touch scrolling can be interrupted with the [TouchScrollable](../Proprietes/1000019284.md) property. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Note: For an Image control, the scroll and zoom features must have been enabled in the description window ("Automatic scrolling and zoom" option in the "Details" tab).  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=multitouch.gif)


- Calling [dStartDrawing](../WDLang1/3029009.md) automatically disables pinch zoom and touch scrolling. 



<a name="NOTE0_2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Use in a Camera control
<a name="use_camera_control_ELTPARAGRAPHE000115"></a>

- When pinch zoom is enabled, the user can zoom in/out by moving two fingers together or apart in the Camera control. 

- This property corresponds to the "Enable pinch zoom" option in the "General" tab of the control description window. 

- When the user zooms in or out, the "Zoom in or out" event is executed. This event gets the value of the new zoom. To handle this parameter, it is necessary to declare a procedure directly in the "Zoom in or out" event.
	The procedure must be declared with the following syntax: 
	
	```txt
	PROCEDURE <Procedure name>(<Zoom>)
	```
where &lt;Zoom&gt; is the new zoom value expressed as a percentage.
