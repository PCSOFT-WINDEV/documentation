
## PageNumber (Property)

***In french: NuméroPage***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PageNumber** property gets and sets a page number. This property can be used on:

- an Image control or a report. For more details, see [ PageNumber](../Proprietes/2510106.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [ pdfBookmark](../WDLang6/1410089195.md).
