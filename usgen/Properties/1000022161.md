


## OriginWaypoint (Property)

***In french: OriginePointDePassage***
	

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>27</B>, ***OriginPassingPoint*</**>** is kept for backward compatibility. This property has been replaced with ***OriginWaypoint*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **OriginWaypoint** property is used to get and define the origin of points whose coordinates are specified in the [WayPoint](../Proprietes/1000021957.md) property. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Le champ Fil passe par le champ LIB_Centre
FIL_MonFil.OriginePointDePassage = filOrigineFenêtre  
pt1 est un Point = [LIB_Centre.X, LIB_Centre.Y]
FIL_MonFil.PointDePassage = [pt1]
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Identifying the origin of points specified in the WayPoint property

`<Result> = <Wire control>.OriginWaypoint`
---

**`<Result>: (Integer constant)`**

Current origin taken into account for the coordinates of the points: 



|   |   |
| --- | --- |
| *wireOriginStartControl* | The coordinates are relative to the top left point of the source control of the Wire control. |
| *wireOriginStartPoint* | The coordinates are relative to the starting point of the Wire control. |
| *wireOriginWindow* | The coordinates are relative to the origin of the window. <br><br>Note: This constant is used to force the Wire control to pass through a fixed position, even if the field is moved.. |



**`<Wire control>: (Control name)`**

Name of the Wire control to be used.


<a name="SYNTAXE2"></a>

### Modifying the mandatory waypoints for a Wire control

`<Wire control>.WayPoint = <New Origin>`
---

**`<Wire control>: (Control name)`**

Name of the Wire control to be used

**`<New Origin>: (Integer constant)`**

New origin taken into account for the coordinates of the points: 



|   |   |
| --- | --- |
| *wireOriginStartControl* | The coordinates are relative to the top left point of the source control of the Wire control. |
| *wireOriginStartPoint* | The coordinates are relative to the starting point of the Wire control. |
| *wireOriginWindow* | The coordinates are relative to the origin of the window. <br><br>Note: This constant is used to force the Wire control to pass through a fixed position, even if the field is moved.. |
