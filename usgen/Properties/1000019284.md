


## TouchScrollable (Property)

***In french: ScrollAuDoigt***

<a name="description"></a>
The **TouchScrollable** property is used to:

- Determine if the control supports touch scrolling.

- Enable or disable touch-responsiveness for a control. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) This property corresponds to the "Touch scrolling" option available in the "Details" tab of List Box, Table and Looper controls.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) This property is mainly used to temporarily disable touch scrolling to draw in an Image control. Similarly, the pinch zoom can be interrupted with the [TouchZoom](../Proprietes/1000022497.md) property. Calling [dStartDrawing](../WDLang1/3029009.md) and [dEndDrawing](../WDLang1/3029019.md) automatically disables and re-enables pinch zoom and touch scrolling.

## Example


```wl
IF CBOX_TouchInterface = True THEN
	TABLE_CustomerTable.TouchScrollable = True
ELSE
	TABLE_CustomerTable.TouchScrollable = False
END
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) 
```wl
IF CBOX_DrawingMode = False THEN
	IMG_Photo.TouchScrollable = True
ELSE
	IMG_Photo.TouchScrollable = False
```

## Syntax

### Finding out if a control supports touch scrolling

`<Result> = <Control used>.TouchScrollable`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control supports touch scrolling,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- a List Box control.

- a Table control.

- a Looper control. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) an Image control.





<a name="SYNTAXE2"></a>

### Enabling or disabling touch scrolling

`<Control used>.TouchScrollable = <Touch scrolling>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- a List Box control.

- a Table control.

- a Looper control. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) an Image control.




**`<Touch scrolling>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control supports touch scrolling,

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000113"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The **TouchScrollable** property can only be used on List Box, Table and Looper controls. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) The **TouchScrollable** property can only be used on Image controls. ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Note: The scroll and zoom features must have been enabled in the Image control description window ("Automatic scrolling and zoom" option in the "Details" tab).  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Scrollaudoigt%20-%20HC%20N%B0001.gif)

<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Special cases
<a name="special_cases_ELTPARAGRAPHE000137"></a>

Some systems may enable touch scrolling by default, even if the feature is disabled for the control.
