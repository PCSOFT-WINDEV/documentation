
## ColorLED (Property)

***In french: CouleurLED***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ColorLED** property is used to set the color of the LED light when displaying notifications. This property can be used on:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Notification](../WDLang3/1000019441.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [notificationCategory](../WDLang3/1000023981.md).
