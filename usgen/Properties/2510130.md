


## Value (Property)

***In french: Valeur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Value** property is used to:

- Find out and modify the value of a report control.

- Find out and modify the value of a control or the title of a window.

- Find out the identifier of a stream. 

- Find out and modify the value of a control or the title of a page.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Find out the files managed by an Upload control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Find out and modify the plane currently displayed in a Sliding Banner control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Center the map found in a Map control on a specific position.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Find out and modify the lower value of the interval currently selected in a Range Slider control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Find out the identifier or the handle associated with a Native Container control.

## Syntax

### Finding out the value of an element

`<Result> = <Element used>.Value`
---

**`<Result>: (Any type)`**

This result depends on the element type.

**`<Element used>: (Type of element)`**

Name of the element to be used.  


<a name="SYNTAXE2"></a>

### Modifying the value of an element

`<Element used>.Value = <New value>`
---

**`<Element used>: (Type of element)`**

Name of element to use.

**`<New value>: (Any type)`**

New value for the specified element. This parameter depends on the type of specified element.

<a name="value_edit_control_ELTPARAGRAPHE000250"></a>

The **Value** property is used to retrieve or change the value entered in an Edit control.

- character string if the subtype of the Edit control corresponds to "Text", "Date" or "Time",

To find out the value typed in an edit control, use one of the following syntaxes:


```txt
ResValue = <Edit control>.Value

ResValue = <Edit control>
```

### Segmented Button control field value
<a name="segmented_button_control_field_value_ELTPARAGRAPHE000307"></a>

The property **Value PROPERTY** property can be used to retrieve or modify elements selected in a Segmented Button control. 

It is possible to: 

- know and modify the selected option using: 
	
	```txt
	<Champ Bouton segmenté>[Option index]
	```
The value returned or assigned is 0 if the option is not selected, and 1 if the option is selected. 

- know and modify the option selected in a "picker" type Segmented Button control field. In this case, the property **Value** property corresponds to the number of the selected option. 
	Example: Option 1 is selected:
	
	```wl
	Trace(SB_Test.Value) // Returns 1
	```


- find out about and modify the options selected in a Segmented Button control "switch" field. In this case, the property **Value** property corresponds to a character string made up of 0s and 1s, corresponding to the options selected (1) or not (0). 
	
	Example: In this control, options 1 and 3 are selected and options 2 and 4 are not: 
	
	```wl
	Trace(SB_Test.Value) // Returns 1010
	```

### Value of Check Box control or value of option in a Check Box control
<a name="value_check_box_control_value_option_check_box_control_ELTPARAGRAPHE000342"></a>

The **Value** property is used to:

- Check or uncheck an option in a Check Box control.

- Find out whether an option found in a Check Box control is checked or unchecked




&lt;Result&gt; is a boolean: 

- <u><u><u><u>True</u></u></u></u> if the option is checked,

- <u><u><u><u>False</u></u></u></u> otherwise.




To find out whether an option found in a Check Box control is checked or not, use one of the following syntaxes:


```txt
ResChecked = <Check Box control>[<Option number>].Value

ResChecked = <Check Box control>[<Option number>]

CheckedResult = <Option name>.Value

ResChecked = <Option name>
```
Note: If the &lt;Option number&gt; parameter is not specified, the first option is selected by default.

### Value of List Box, ListView or Table control
<a name="value_list_box_listview_table_control_ELTPARAGRAPHE000395"></a>

Two distinct cases may occur.

- The List Box, ListView or Table control is populated programmatically OR the [StoredItem](../Proprietes/2510110.md) property is set to an empty string ("").
	The **Value** property is used to:

	- Get the selected row. If no row is selected, the **Value** property returns -1. If the control allows for multiple selection, the number of the last selected row is returned.
			To find out the selected row, use one of the following syntaxes:
			
		```txt
		ResLigne = <Nom du champ>.Value
		
		ResLigne = <Nom du champ>
		```


	- Select another row by specifying the number of the new row to select. The rows previously selected are deselected.   




- The List Box, ListView, or Table controls are based on a table AND the [StoredItem](../Proprietes/2510110.md) property is not empty.
	The **Value** property is used to identify the stored item for the record associated with the selected row. If no row is selected, the **Value** property returns an empty string ("").
	To find out the stored item associated with the selected row, use one of the following syntaxes:
	
	```txt
	ResRubMem = <Nom du champ>.Value
	
	ResRubMem = <Nom du champ>.StoredItem
	```

### Value of cell in a Table control
<a name="value_cell_table_control_ELTPARAGRAPHE000443"></a>

The **Value** property is used to determine or modify the value of a cell in a Table control.

&lt;Result&gt; is a character string.

To find out the value of a cell, use one of the following syntaxes:


```txt
ResCell = <Table control>[<Row number>][<Column number>].Value

ResCell = <Table control>[<Row number>][<Column number>]

ResCell = <Column>[<Row number>].Value

ResCell = <Column>[<Row number>]
```


**Special case: Value of a cell found on the current row**
If only the column name is specified, the **Value** property can be used to:

- Find out the value of the cell identified by the specified column and by the current row in the Table control. If there is no current row, an empty string ("") is returned.

- Modify the value of the cell identified by the specified column and by the current row in the Table control.




&lt;Result&gt; is a character string.

To find out the value of the cell identified by the specified column and by the current row in the Table control, use one of the following syntaxes:


```txt
ResColumn = <Column name>.Value

ResColumn = <Column name>
```

### Value of a Progress Bar, Slider, Spin or Scrollbar control
<a name="value_progress_bar_slider_spin_scrollbar_control_ELTPARAGRAPHE000557"></a>

The **Value** property is used to determine or modify the value in a Progress Bar, Slider, Spin or Scrollbar control.

&lt;Result&gt; is a real.

To find out the value of a Progress Bar, Slider, Spin or Scrollbar control, use one of the following syntaxes:


```txt
ResValue = <Nom du champ>.Value

ResValue = <Control name>
```

### Value of Map control
<a name="value_map_control_ELTPARAGRAPHE000718"></a>

The **Value** property is used to center the map (in a Map control) on the position that corresponds to a [geoPosition](../WDLang3/1000019191.md) variable. 

Example: 


```wl
// Centers the map displayed by the "MAP_Position" control on a geographical position
MyPosition is geoPosition
MAP_Position.Value = MyPosition
```
**Remarks**: 

- The **Value** property is equivalent to the [MapDisplayPosition](../WDLang3/1000019787.md) function. The only difference is that when using the [MapDisplayPosition](../WDLang3/1000019787.md) function, positioning on the requested position is carried out using an animation. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The **Value** property can only be used to change the position in a Map control.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The **Value** property gets and sets the position in a Map control.
