


## Thumbnail (Property)

***In french: Vignette***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Thumbnail** property is used to: 

- get the value of an item thumbnail. This item was defined in the data model editor or programmatically. For more details, see [HFSQL thumbnails](../WDLang4/3044348.md). 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) find out and modify the image associated with a Thumbnail control.

<a name="sample_code"></a>

## Example


```wl
// Value of first thumbnail of Customer.Photo item
ThumbnailValue is string
ThumbnailValue = Customer.Photo.Thumbnail[1]
// equivalent to ThumbnailValue = Customer.Photo.Thumbnail

// Null value?
IF ThumbnailValue <> "" THEN
	Info("The value of this label is: " + LabelValue)
ELSE
	ErrorString = Customer.Photo.InfoThumbnailGeneration[1]
	Error("Generation error", ErrorString)
END
```

## Syntax

### Getting the value of an item thumbnail

`<Value> = <Data file>.<item>.Thumbnail`
---

**`<Value>: (Character string)`**

Image of specified thumbnail in binary memo format.

**`<Table>: (Character string)`**

Name of the table used. This name was defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.

**`<Item>: (Character string)`**

Name of binary memo item used. This name is defined in the data model editor or with the [Item Description](../WDLang4/1514071.md) type.  


<a name="SYNTAXE2"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 
### Getting the path to the image associated with a Thumbnail control

`<Result> = <Thumbnail control>.Thumbnail`
---

**`<Result>: (Character string)`**

Path to the image used for the thumbnail. This path is relative to the "_WEB" directory of the project.

**`<Thumbnail control>: (Control name)`**

Name of Thumbnail control to use.   


<a name="SYNTAXE3"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 
### Changing the path to the image associated with a Thumbnail control

`<Thumbnail control>.Thumbnail = <New image>`
---

**`<Thumbnail control>: (Control name)`**

Name of Thumbnail control to use. 

**`<New image>: (Character string)`**

New full path to image used as thumbnail. This path is relative to the "_WEB" directory of the project.

## Remarks


### Item thumbnail
<a name="item_thumbnail_ELTPARAGRAPHE000095"></a>

The **Thumbnail** property is available:

- in HFSQL Classic and HFSQL Mobile: on the fields of a table, view or query.

- in HFSQL Client/Server: on table fields only.




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The **Thumbnail** property is only available on table items in HFSQL Client/Server.
