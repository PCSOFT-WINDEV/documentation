


## GenerationNumber (Property)

***In french: NuméroGénération***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **GenerationNumber** property is used to get the generation number of the physical table associated with the logical table.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the generation number of the Customer table
ResGenerationNum = Customer.GenerationNumber
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table>.GenerationNumber`
---

**`<Result>: (Integer)`**

Generation number of the physical table currently associated with the specified logical table.

**`<Table>: (Character string)`**

Logical name of the table used.
