


## Language (Property)

***In french: Langue***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Language** property gets and sets the language used. This property can be used on:

- data file items to set the language used for comparisons and sorts. For more details, see [Language property on items](../Proprietes/1000017053.md).

- a variable of type [gglMapParameter](../WDLang5/1000017505.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [nfcData](../WDLang3/1000020406.md).

- a variable of type [rssChannel](../WDLang5/1000017769.md).

- a variable of type [sfUserInfo](../WDLang5/1000018423.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [SpeechSynthesisVoice](../WDLang3/1000025986.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [WLanguageCodeFormatting](../WDLang1/1410090146.md).
