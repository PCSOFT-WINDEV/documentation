
## Selection (Property)

***In french: Sélection***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Selection** property manages selection features. This property is available on: 

- Word Processing, Spreadsheet, HTML Editor and Diagram Editor controls. 

- a variable of type [pdfProtection](../WDLang6/1410091145.md).
