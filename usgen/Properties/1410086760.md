
## AICaption (Property)

***In french: IALibellé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AICaption** property gets and sets the label that identifies the AI model's response in the AI Chat control.                                                                                                                                                                                      
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AICHAT_AIChat.AICaption = "Software companion"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the label used to identify the AI model's response

`<Result> = <AI Chat control>.AICaption`
---

**`<Result>: (Character string)`**

Label used. 

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.   


<a name="SYNTAXE2"></a>

### Setting the label used to identify the AI model's response

`<AI Chat control>.AICaption = <New label>`
---

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.

**`<New label>: (Character string)`**

New label.
