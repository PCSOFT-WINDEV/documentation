
## Parent (Property)

***In french: Parent***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Parent** property gets the parent element of an element. This property can be used on:

- a variable of type [docElement](../WDLang1/1000022484.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docParagraph](../WDLang1/1000022483.md).

- a variable of type [jsonReader](../WDLang1/1410090783.md). 
	

- a variable of type [WindowOpeningOptions](../WDLang1/1410091298.md).
