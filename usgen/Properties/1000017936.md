
## Format (Property)

***In french: Format***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Format** property is used to identify and change the format of an element. This property can be used on:

- the tables. For more details, see [Format property on tables](../Proprietes/2512045.md).

- a variable of type [gglMapParameter](../WDLang5/1000017505.md). 

- a variable of type [Icon](../WDLang1/1000020811.md).

- a variable of type [Notification](../WDLang3/1000019441.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docNumberingLevel](../WDLang1/1000022799.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [WLanguageCodeFormatting](../WDLang1/1410090146.md).
