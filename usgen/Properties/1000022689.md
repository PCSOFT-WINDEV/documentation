
## LeftMargin (Property)

<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **LeftMargin** property sets the left margin of an element. This property can be used: 

- on reports. For more details, see [LeftMargin](../Proprietes/2511048.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) on [docSection](../WDLang1/1000022685.md) variables.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) on [xlsLayout](../WDLang5/1000023139.md) variables.
