


## StartTotalRange (Property)

***In french: DébutEtendueTotale***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StartTotalRange** property is used to: 

- getting the first date or time that can be displayed: 

	- in a Scheduler control. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) in a TimeLine control.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) change the first time that can be displayed in a TimeLine control.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Champ TimeLine sur 2 minutes au total
TimelineChangeMode(TL_TimeLine, plnModeSeconde, 120)

// équivalent à:
TL_TimeLine.DébutEtendueTotale = 0  // commence à 0 sec
TL_TimeLine.FinEtendueTotale = 120 // fin à 120 sec 

// Rendre visible les 30 premières secondes 
TL_TimeLine.DébutEtendueVisible = 0 // commence à 0 sec
TL_TimeLine.FinEtendueVisible = 30 // taille à 30 sec
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the first date or time that can be displayed

`<Result> = <Control used>.StartTotalRange`
---

**`<Result>: (Integer or character string in Date/Time format)`**

First value displayed in the control. This value corresponds to: 

- an integer for: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a TimeLine control, 

	- a Scheduler control in second, millisecond or microsecond mode. 




- a date in YYYYMMDDHHSSCC format for a Scheduler control in day, week or month mode.




**`<Control used>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Scheduler control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a TimeLine control. 





<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
### Changing the value of the first time that can be displayed

`<TimeLine control>.StartTotalRange = <New value>`
---

**`<TimeLine control>: (Control name)`**

Name of the TimeLine control to be used. 

**`<New value>: (Integer)`**

First value to be displayed in the control. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- All the events represented in the control are between **StartTotalRange** and [EndTotalRange](../Proprietes/1000020393.md). This corresponds to the total range of the scrollbar or range slider associated with the control. 

- All the events visible in the control are between [StartVisibleRange](../Proprietes/1000020394.md) and [EndVisibleRange](../Proprietes/1000020395.md). This corresponds to the size of the scroll bar cursor or range slider associated with the control. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The **StartTotalRange** and [StartVisibleRange](../Proprietes/1000020394.md) properties are equivalent. They are used to get the first visible value in the control.
