
## Protection (Property)

***In french: Protection***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Protection** property gets and sets the protection features of a PDF file. 

This property can be used with:

- a variable of type [pdfParameter](../WDLang6/1410087857.md).

- a variable of type [pdfDocument](../WDLang6/1000024909.md).
