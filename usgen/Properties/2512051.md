


## ModificationRule (Property)

***In french: RègleModification***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ModificationRule** property is used to configure the modification rule (integrity management) to be applied to the table described in the code. You can:

- Find out the modification rule used for a table defined in the database schema or programmatically.

- Define the modification rule used for a table (when the link is described through programming).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the modification rule used in the OrdLine link
OrdLine.ModificationRule = hIntegrityForbidden
...
// Validate the table description
HDescribeFile(OrdLine)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the modification rule

`<Modification rule> = <Link>.ModificationRule`
---

**`<Modification rule>: (Integer constant)`**

The different modification rules are as follows:



|   |   |
| --- | --- |
| *hIntegrityCascade* | Cascading modification: modification of the key field in the source file results in cascading modification of all linked records. |
| *hIntegrityDefaultValue* | Default modification: when the key field is modified in the source file, the linked keys are initialized by their default value. |
| *hIntegrityForbidden* | Modification forbidden: the key field in the source file cannot be modified if the record is linked to a record. |
| *hIntegrityNone* | No integrity management: modification of the key field in the link source file does not lead to any specific action in the linked file. |



**`<Link>: (Character string)`**

Name of the link defined in the database schema or by the [Link Description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Defining the modification rule used in the link defined programmatically

`<Link>.ModificationRule = <Modification rule>`
---

**`<Link>: (Character string)`**

Name of the link defined in the database schema or by the [Link Description](../WDLang4/1514039.md) type.

**`<Modification rule>: (Integer constant)`**

The different modification rules are as follows:



|   |   |
| --- | --- |
| *hIntegrityCascade* | Cascading modification: modification of the key field in the source file results in cascading modification of all linked records. |
| *hIntegrityDefaultValue* | Default modification: when the key field is modified in the source file, the linked keys are initialized by their default value. |
| *hIntegrityForbidden* | Modification forbidden: the key field in the source file cannot be modified if the record is linked to a record. |
| *hIntegrityNone* | No integrity management: modification of the key field in the link source file does not lead to any specific action in the linked file. |
