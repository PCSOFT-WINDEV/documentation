
## TitleBackgroundColor (Property)

***In french: CouleurFondTitre***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***BrushColorTitle*</**>** is kept for backward compatibility. This property has been replaced with ***TitleBackgroundColor*</**>**.

<a name="Utilisation"></a>
<a name="description"></a>
The **TitleBackgroundColor** property gets and sets the background color of a column title in a Table or TreeView Table control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SI bCLientImportant ALORS
	COL_Remarque.CouleurFondTitre = RougeClair
SINON
	COL_Remarque.CouleurFondTitre = CouleurDefaut
FIN
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the background color of a column title

`<Background color> = <Column used>.TitleBackgroundColor`
---

**`<Background color>: (Integer or constant)`**

Background color of the column title. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a preset color](../WDLang5/3010002.md).




**`<Column used>: (Control name)`**

Name of a column in a Table or TreeView Table control. 


<a name="SYNTAXE2"></a>

### Changing the background color of a column title

`<Column used>.TitleBackgroundColor = <New background color>`
---

**`<Column used>: (Control name)`**

Name of a column in a Table or TreeView Table control. 

**`<New background color>: (Integer or constant)`**

New background color of the column title. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a preset color](../WDLang5/3010002.md), 

- the *DefaultColor* constant. In this case, the background color corresponds to the background color common to all column titles (defined in the control style). 


Note: If the column title background is an image, the title background is overridden with this new color..
