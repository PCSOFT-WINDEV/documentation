
## SignatureAlgorithm (Property)

***In french: AlgorithmeSignature***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SignatureAlgorithm** property defines the method used to generate the signature. This property can be used on:

- a variable of type [xmlSignature](../WDLang5/1000020736.md). 

- a variable of type [xmlXAdESSignature](../WDLang5/1410091158.md).
