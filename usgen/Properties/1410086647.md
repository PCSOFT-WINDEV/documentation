
## FillCharacter

***In french: CaractèreRemplissage***
	

<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **FillCharacter** property gets and sets the character used to fill an element. This property can be used on:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docTabulation](../WDLang1/1000022573.md).

- a variable of type [NumericFormat](../WDLang1/1410089836.md).
