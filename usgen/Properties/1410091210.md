
## ProcedureData (Property)

***In french: ProcédureDonnées***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DataProcedure** property is used to specify the name of the WLanguage procedure called as data is received. This procedure can be used to progressively retrieve an HTTP response, e.g., when the server returns a chunked or a large response

This property can be used on:

- a variable of type [httpRequest](../WDLang3/1000021158.md).

- a variable of type [restRequest](../WDLang3/1000021481.md).
