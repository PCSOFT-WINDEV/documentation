


## FontSize (Property)

***In french: PoliceTaille***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FontSize** property is used to:

- Identify the size of the font used in a control.

- Change the size of the font used in a control.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change the size of the font used in "EDT_CustomerName"
EDT_CustomerName.FontSize = 16
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Identifying the size of the font used in a control

`<Result> = <Control used>.FontSize`
---

**`<Result>: (Integer)`**

Size of the font used in the specified object.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter is a string.

**`<Control used>: (Control name)`**

Name of the control to be used.  


<a name="SYNTAXE2"></a>

### Changing the size of the font used in a control

`<Control used>.FontSize = <Font size>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.

**`<Font size>: (Integer)`**

New size of the font used in the specified control.  
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter is a string.

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000078"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In a report, the **FontSize** property can only be used on:

- a Static Text control.

- a Calculated control.

- a Preset control.

- a Link control.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) In a window, the **FontSize** property cannot be used on:

- a Spin control, 

- a Web Camera control, 

- a Conference control.Note: This property only applies to ListView controls in standard "List Box" display mode.


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The **FontSize** property cannot be used on table columns.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **FontSize** property can only be used with the following elements:

- Button, 

- Static,

- Combo Box,

- TreeView, 

- Table column.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In a page, the **FontSize** property applies only to the following elements:

- Edit control, 

- Static,

- Button, 

- Check box/Radio button, 

- List box, combo box,

- Table, 

- Formatted display control,

- HTML control, 

- Link,

- HTML static,

- Table column (not available in browser code), 

- Table cell (available in red-only and not available in browser code),

- Pager (not available in browser code), 

- Site map path (not available in browser code and in PHP), 

- Group of controls (not available in browser code).
