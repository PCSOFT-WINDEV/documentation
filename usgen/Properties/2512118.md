
## IntegerPart (Property)

***In french: PartieEntière***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **IntegerPart** property is used to configure Numeric items. It is possible to:

- Find out the number of digits in the integer part of a Numeric item.

- Define the number of digits in the integer part of a Numeric item.




**Note** The [DecimalPart](../Proprietes/2512119.md) property is used to define and identify the number of digits in the decimal part of a Numeric field.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Describe the AFile table
...

// Describe the "Amount" item
AnItem.Name = "AMOUNT"
AnItem.Type = hItemNumeric
AnItem.IntegerPart = 15
AnItem.DecimalPart = 7

// Validate the description of the "Amount" item
HDescribeItem(AFile, AnItem)

// Validate the description of the AFile table
...
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Find out the number of digits in the integer part of a Numeric item

`<Result> = <Data file>.<Item>.IntegerPart`
---

**`<Result>: (Int)`**

Number of digits taken into account by the integer part of the item.

**`<Table>: (Character string)`**

Name of the table used. This name was defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.

**`<Item>: (Character string)`**

Name of the item used. This name is defined in the data model editor or with the [Item Description](../WDLang4/1514071.md) type.  


<a name="SYNTAXE2"></a>

### Define the number of digits in the integer part of a Numeric item

`<Item>.IntegerPart = <Number of digits>`
---

**`<Item>: (Character string)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<Number of digits>: (Int)`**

Number of digits that must be taken into account for the integer part of the Numeric item.
