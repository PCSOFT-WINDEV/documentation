
## Protocol (Property)
			

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Protocol** property gets and sets the protocol used. This property can be used on:

- a variable of type [rssCloud](../WDLang5/1000017785.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [InstantMessaging](../WDLang3/1000020247.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [aiModelInfoChat](../WDLang1/1410086683.md).
