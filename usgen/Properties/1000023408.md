
## SynchroHFSQL (Property)

***In french: SynchroHFSQL***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SynchroHFSQL** property is used to: 

- know how to refresh a Table control linked to an HFSQL Client/Server table. 

- specify the refresh mode of a data-bound Table control bound to an HFSQL Client/Server table. 




Note: This property is equivalent to the "Synchronize display" option in the "Contents" tab of the Table control window: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Table_Fichier_Synchro%20-%20HC%20N%B0001.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines the refresh mode of Table control
TABLE_Customer.SynchroHFSQL = syncModification
// Modification of the Client/Server HFSQL table linked to the field
CUSTOMER.ZC = 34980
HModify(CUSTOMER) 
// The Table control will be automatically refreshed if this customer is visible in the control
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Learn how to refresh a Table control linked to an HFSQL Client/Server table

`<Result> = <Table control>.SynchroHFSQL`
---

**`<Result>: (Integer constant)`**

Current refresh mode: 


|   |   |
| --- | --- |
| *syncAddition* | Synchronization when adding a record into the table. |
| *syncNone* | No synchronization is performed. |
| *syncModification* | Synchronization when modifying a record in the table |
| *syncDeletion* | Synchronization when deleting a record from the table |



**`<Table control>: (Control name)`**

Name of the Table control to be used. This field is linked to a table. 


<a name="SYNTAXE2"></a>

### Modify the refresh mode of a data-bound Table control linked to an HFSQL Client/Server table

`<Table control>.SynchroHFSQL = <New mode>`
---

**`<Table control>: (Control name)`**

Name of the Table control to be used. This field is linked to a table. 

**`<New mode>: (Integer constant (or combination of constants))`**

New refresh mode: 


|   |   |
| --- | --- |
| *syncAddition* | Synchronization when adding a record into the table. |
| *syncNone* | No synchronization is performed. |
| *syncModification* | Synchronization when modifying a record in the table<br><br>Please note: Only lines displayed by the data-bound Table control (i.e. visible) can be modified automatically when editing the linked HFSQL table. |
| *syncDeletion* | Synchronization when deleting a record from the table |


Note: It is possible to combine the constants *syncAdd*, *syncModification constants* and *syncDelete constants*. 
Please note: As the number of cases managed increases, so does the server load.. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- This property is ignored for: 

	- Table fields linked to an HFSQL Classic table, 

	- Table controls manipulating tables via a Native Access connector,

	- programmatically populated Table fields, etc.




- Caution: Enabling this feature increases server load when displaying the Table control or when moving within the field.

- The modifications performed in the table can come from the same application, from another application on the same computer or from another application on another computer.
