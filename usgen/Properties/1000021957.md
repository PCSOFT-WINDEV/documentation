


## WayPoint (Property)

***In french: Pointdepassage***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WayPoint** property is used to determine and change the points a Wire control has to pass through.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
x est un Champ
x <- ChampCrée("", typFil)
x.ChampDépart = BTN_SansNom1
x.ChampArrivée = BTN_SansNom2
x.PointDePassage = "10,50,10,120"
```



```wl
// On ajoute un point de passage au fil pour qu'il prenne le chemin que l'on souhaite
PointPassage1, PointPassage2 sont des Points 

PointPassage1.X = 280
PointPassage1.Y = 54

PointPassage2.X = 320
PointPassage2.Y = 54
FIL_MonFil.NbMaxSegment = 20

FIL_MonFil.PointDePassage = [PointPassage1, PointPassage2]
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the mandatory waypoints for a Wire control

`<Result> = <Wire control>.WayPoint`
---

**`<Result>: (Array of points)`**

Array of [Point](../Motscles/1000018908.md) variables containing the coordinates of waypoints. 

Caution: By default, waypoint coordinates are those relative to the start position of the thread.. To change this behavior, use the [OriginWaypoint](../Proprietes/1000022161.md) property.

**`<Wire control>: (Control name)`**

Name of the Wire control to be used.


<a name="SYNTAXE2"></a>

### Modifying the mandatory waypoints for a Wire control

`<Wire control>.WayPoint = <New Points>`
---

**`<Wire control>: (Control name)`**

Name of the Wire control to be used

**`<New Points>: (Array of points)`**



- Array of [Point](../Motscles/1000018908.md) variables containing the coordinates of waypoints.

- Character string containing the different coordinates separated by commas. 

- Empty string ("") to delete all the waypoints. 




Caution: By default, waypoint coordinates are those relative to the start position of the thread.. To change this behavior, use the [OriginWaypoint](../Proprietes/1000022161.md) property.
