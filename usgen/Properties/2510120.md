


## AnchorRateWidth (Property)

***In french: TauxAncrageLargeur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AnchorRateWidth** property is used to:

- Find out the anchor rate when a control (or a table column) stretches on the horizontal axis.

- Modify the anchor rate when a control (or a table column) stretches on the horizontal axis.




The anchor rate is used to define how the control is moved or resized in relation to the evolution of size of window (or report) to which it is anchored. The anchor rate corresponds to the percentage by which the control moves in relation to the window (or report). Therefore, if the anchor rate is set to 0, the control will not be resized. If it is set to 1000, the control will be resized normally.

The horizontal anchor rate (**AnchorRateWidth** property) is applied if the control is anchored horizontally(*anchorWidth* constant used with the [Anchor](../Proprietes/2510001.md) property).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This property can only be used to find out the anchor rate of the blocks or controls found in a report.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Le champ Liste s'élargit de 50% de l'agrandissement de la fenêtre (500 pour 1000).
LISTE_ListePersonne.TauxAncrageLargeur = 500
```

## Syntax

### Getting the anchor rate when enlarging a control horizontally

`<Result> = <Control used>.AnchorRateWidth`
---

**`<Result>: (Integer)`**

Anchor rate included between 0 (unstretched control) and 1000 (standard anchor)

**`<Control used>: (Control name)`**

Name of control (or column) to use. This control can be a control: 

- of a window.

### Changing the anchor rate when enlarging a control horizontally

`<Control used>.AnchorRateWidth = <Anchor rate>`
---

**`<Control used>: (Control name)`**

Name of control (or column) to use.

**`<Anchor rate>: (Integer)`**

New anchor rate included between 0 (unstretched control) and 1000 (standard anchor)

## Remarks


### Anchoring a control

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In a window, the [Anchor](../Proprietes/2510001.md) property is used to determine how a control is resized or moved when the window is resized. If the control is associated with a Tab control, the anchor is defined in relation to the tab.
	For more details, see [Anchoring applied to window controls](../WDChamp/2026002.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The [Anchor](../Proprietes/2510001.md) property is not available for columns in Table or TreeView Table controls. The anchors of a column can be specified directly with the **AnchorRateWidth** property.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) In a report, the [Anchor](../Proprietes/2510001.md) property is used to find out how the control is resized or moved when the report is resized. ### Limitations
<a name="limitations_ELTPARAGRAPHE000133"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **AnchorRateWidth** property can be used in all the controls of a window.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) The **AnchorRateWidth** property can be used in all the controls of a report. In this case, you can only find out the anchor rate used.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **AnchorRateWidth** property can only be used with the following elements:

- Button.

- Wording.

- Edit control.

- Image.

- Check Box.

- Radio Button.

- List Box.

- Combo Box.

- TreeView.

- Tab.

- Table.

- Supercontrol.

- Ribbon group.
