


## Grayed (Property)

***In french: Grisé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Grayed** property is used to: 

- Determine if a control (or a group of controls) is grayed out. 

- Gray out or ungray a control, a group of controls or a window. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Grays out the GR_ShippingCost group of controls according to the value in EDT_Price
IF EDT_Price > 100 THEN
	GR_ShippingCost.Grayed = True
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out whether an element is grayed out

`<Result> = <Element used>.Grayed`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element is grayed out,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Element used>: (Control name or window name)`**

Name of element to use: 

- Name of control,

- Name of group of controls,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Window name. 





<a name="SYNTAXE2"></a>

### Modifying the grayed out status for an element

`<Element used>.Grayed = <New value>`
---

**`<Element used>: (Control name or window name)`**

Name of element to use: 

- Name of control,

- Name of group of controls,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Window name. 




**`<New value>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element should be grayed out,

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000107"></a>

The **Grayed** property set to <u><u><u><u>True</u></u></u></u> and the [State](../Proprietes/2510039.md) property set to *Grayed* are equivalent, except for read-only controls that keep their "read-only" state. 


### Limits
<a name="limits_ELTPARAGRAPHE000121"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The **Grayed** property applies to all types of controls (except for status bar cells).  

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) The **Grayed** property hides a context menu option.
