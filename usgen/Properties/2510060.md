


## DataBinding (Property)

***In french: LiaisonFichier***

<a name="description"></a>
The **DataBinding** property gets and changes the binding between a control and:

- a table item.

- a variable. 

- several variables (in this case, each variable can be bound to a different property of the control).




**Reminder**: The binding between a control and an item or variable is usually defined in the window or page editor, in the control description ("Binding" tab). This binding allows you to specify the table item that will be used by the synchronization functions ([WindowToData](../WDLang4/3044146.md), [ScreenToSource](../WDLang4/1000017342.md), [PageToFile](../WDLang4/3044022.md), [PageToSource](../WDLang4/1000017406.md), [FileToScreen](../WDLang4/3044210.md), [FileToPage](../WDLang4/3044148.md), [SourceToScreen](../WDLang4/1000017341.md), [SourceToPage](../WDLang4/1000017405.md)).

A control can be bound to an item from a base table, or to an item from a linked table. This is referred to as complex binding. Example of complex binding:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LiaisonFichier%20-%20HC%20N%B0001.gif)
This property is equivalent to the [ControlAlias](../WDLang1/3025016.md) function.

## Example


```wl
// Binds the EDT_Edit1 control to the Name item of the Customer table
EDT_Edit1.DataBinding = "Customer.Name"
// Same but from the Order table with 1 binding
EDT_Edit2.DataBinding = "Order.CustomerID" + TAB + "Customer.CustomerID:Name"
// Same but from the OrdLine table with 2 bindings
EDT_Edit3.DataBinding = "OrdLine.OrdID" + TAB + ...
		"Order.OrdID:CustomerID" + TAB + "Customer.CustomerID:Name"
// Binds TABLE_Table1 to Array_Month
TABLE_Table1.DataBinding = ":Array_Month"
// Update on the screen
FileToScreen()
```



```wl
// Whenever SourceToScreen is called, the EDT_Current_Allowed control will have: 
// - its displayed value updated by the Authorizing property of a class instance,
// - a background color assigned by the value of a global variable
gclContact is cContact
gsColor is int = PastelBlue
EDT_Current_Allowed.DataBinding = ":gclContact.Authorizing" + TAB + ...
	"value" + CR + ":gsColor" + TAB + "BackgroundColor"
// Update on the screen
SourceToScreen()
```

## Syntax

### Getting the binding between a control and an item or variable

`<Current binding> = <Control used>.DataBinding`
---

**`<Current binding>: (Character string)`**

There are different types of bindings:

- No binding: empty string ("")

- Simple binding to a table item: 
	
	```txt
	"<Base table>.<Base item>"
	```


- Complex binding to a table item:
	
	```txt
	"<Base table>.<Base item>[ + TAB + <Binding> [+ TAB + <Binding>]]"
	```

	where &lt;Binding&gt; corresponds to:
	&lt;Bound table&gt;.&lt;Key&gt;:&lt;Bound item&gt;[&lt;Index&gt;]

- Binding to a variable: 
	
	```txt
	":<prefix><Variable name>"
	```
 or 
	```txt
	":<Variable name>"
	```
(the prefix is applied only if the code style is enabled in the project).




**`<Control used>: (Control name)`**

Name of the control with the binding to be identified.  


<a name="SYNTAXE2"></a>

### Changing the binding between a control and an item or variable

`<Control used>.DataBinding = <New binding>`
---

**`<Control used>: (Control name)`**

Name of the control for which you want to change the data binding.

**`<New binding>: (Character string)`**

There are different types of bindings:

- No binding: empty string ("")

- Simple binding to a table item: 
	
	```txt
	"<Base table>.<Base item>"
	```


- Complex binding to a table item:
	
	```txt
	"<Base table>.<Base item>[ + TAB + <Binding> [+ TAB + <Binding>]]"
	```

	where &lt;Binding&gt; corresponds to:
	&lt;Bound table&gt;.&lt;Key&gt;:&lt;Bound item&gt;[&lt;Index&gt;]
	**Note**: You can also use the following syntax:
	
	```txt
	<[Base table>.<Item>[<[Index]>] [: <Binding> [: <Binding>] ]
	```

	where &lt;Binding&gt; = &lt;Bound table&gt;.&lt;Key&gt;:&lt;Displayed item&gt; [&lt;[Index]&gt;]

- Binding to a variable: 
	
	```txt
	":<prefix><Variable name>"
	```
 or 
	```txt
	":<Variable name>"
	```
The prefix must be specified only if the code style is enabled in the project (whether or not prefixes are displayed).

- Binding to a variable of type [data source](../WDLang4/1514053.md): 
	
	```txt
	<Variable name>.Name + ".<Base item>"
	```


- Binding multiple properties to multiple variables. The string that describes the binding must have the following format:
	
	```txt
	":" + <Variable name 1> + TAB + <Name of property 1> + CR + ...
	":" + <Variable name 2> + TAB + <Name of property 2> + CR + ...
	":" + <Name of variable N> + TAB + <Name of property N>
	```

## Remarks

### ListView control
<a name="listview_control_ELTPARAGRAPHE000194"></a>

The **DataBinding** property allows you to get and modify the binding between the captions in a ListView control and a table item.
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Display error
<a name="display_error_ELTPARAGRAPHE000205"></a>

You can use [ControlError](../WDLang1/3025036.md) to customize the error message displayed in the controls when the control value cannot be displayed.
<a name="NOTE0_3"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000215"></a>

The **DataBinding** property applies only to controls in a window or page.
![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This property applies only to the following controls: 

- Button control.

- Static Text control.

- Image control.
