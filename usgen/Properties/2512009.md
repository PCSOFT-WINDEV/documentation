


## Abbreviation (Property)

***In french: Abréviation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Abbreviation** property gets the abbreviation of a table. This abbreviation is defined in the data model editor when defining the table. This property is read-only.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Abbreviation of the Order table
ResAbbreviation = Order.Abbreviation
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Abbreviation of table> = <Table>.Abbreviation`
---

**`<Abbreviation of table>: (Character string)`**

Two letters that identify the abbreviation of the table.

**`<Table>: (Character string)`**

Name of table to use.
