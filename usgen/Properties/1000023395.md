
## NamespaceDeclared (Property)

***In french: NamespaceDéclaré***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **NamespaceDeclared** property manages defined namespaces. This property can be used on:

- a variable of type [xmlNode](../WDLang5/1000018786.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [xmlReader](../WDLang5/1000023392.md).
