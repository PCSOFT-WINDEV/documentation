


## Name55 (Property)

***In french: Nom55***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Name55** property is used to manipulate the logical name of a Hyper File 5.5 table that has not been migrated and is located in a WINDEV 2026 database schema. You can:

- Find out the logical name of a table.

- Define the name of a 5.5 table created programmatically in a WINDEV 2026 database schema.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the logical name of the Customer table
ResName55 = Customer.Name55
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the logical name of a table in 5.5 format

`<Logical name> = <Table>.Name55`
---

**`<Logical name>: (Character string)`**

Logical name of the table in 5.5 format.

**`<Table>: (Character string)`**

Logical name of the table in the database schema in WINDEV 2026 format.  


<a name="SYNTAXE2"></a>

### Defining the logical name of a table in 5.5 format created programmatically

`<Table>.Name55 = <New logical name>`
---

**`<Table>: (Character string)`**

Name of the table defined through programming via the [File Description](../WDLang4/1514065.md) type.

**`<New logical name>: (Character string)`**

Logical name of the table in 5.5 format.
