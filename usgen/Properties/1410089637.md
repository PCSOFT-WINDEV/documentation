
## HeightHalfExpanded (Property)

***In french: HauteurIntermédiaire***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **HeightHalfExpanded** property gets and sets the "half-expanded" height of the bottom sliding window associated with the current window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurEtendue = 0.9 // 90% 
// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the "half-extended" height of a bottom sliding window

`<Result> = <Sliding window>.HeightHalfExpanded`
---

**`<Result>: (Integer or Integer constant)`**



- Value greater than 1: Height (in pixels) of the bottom sliding window display in "intermediate" mode..  

- Value between 0 and 1: Percentage of screen height. 

- Negative value: Constant used to define the "intermediate" height of the bottom sliding window: 
	


|   |   |
| --- | --- |
| *swDisabled* | The half-extended mode of bottom sliding windows is disabled. |
| *swFitToContent* | The height in half-extended mode corresponds to the height of the internal window. |
| *swSysMedium* | The height in half-extended mode is half the height of the host window. |






**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.


<a name="SYNTAXE2"></a>

### Setting the "half-extended" height of a bottom sliding window

`<Sliding window>.HeightHalfExpanded = <New half-expanded height>`
---

**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.

**`<New half-expanded height>: (Integer or Integer constant)`**

New half-extended height for bottom sliding windows. This height can correspond to: 

- a number of pixels. 

- a percentage of the screen height (integer between 0 and 1),

- one of the following constants: 
	


|   |   |
| --- | --- |
| *swDisabled* | The half-extended mode of bottom sliding windows is disabled. |
| *swFitToContent* | The height in half-extended mode corresponds to the height of the internal window. |
| *swSysMedium* | The height in half-extended mode is half the height of the host window. |
