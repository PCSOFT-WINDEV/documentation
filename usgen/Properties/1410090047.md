
## Monochrome (Property)

***In french: Monochrome***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Monochrome** property determines whether an image should be used in monochrome mode. This property can be used on:

- Image controls, via the [Monochrome](../Proprietes/1410090978.md) property. 

- the [LeftButton](../Proprietes/1410090001.md) property of an Edit control.

- the [RightButton](../Proprietes/1410090002.md) property of an Edit control.
