


## CtDescribedPassword (Property)

***In french: CxMotDePasseDécrit***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CtDescribedPassword** property allows you to set the password used to open a table in an OLE DB connection (only for tables defined programmatically). 


**Reminder** The [HConnect](../WDLang4/3044263.md) function can be used to redefine one or more parameters of the OLE DB connection to a table. By default, the characteristics of the OLE DB connection are set:

- when defining the table in the data model editor,

- when defining the table programmatically.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Set the password to open the Customer table
Customer.CtDescribedPassword = "Password"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Table>.CtDescribedPassword = <Password>`
---

**`<Table>: (Character string)`**

Name of the table used. Name defined using the [File Description](../WDLang4/1514065.md) type.

**`<Password>: (Character string or Secret string)`**

Password of the file to be opened via an OLE DB connection.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The [Password](../Proprietes/2510086.md) property is used to set the password associated with a user and a connection.
