


## HugeFile (Property)

***In french: GrosFichier***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **HugeFile** property sets the maximum possible size of a table. You can:

- Find out if a table is configured to contain more than 2 GB of data (table defined in the data model editor or programmatically defined).

- Define the size characteristics of a table (only for tables defined programmatically).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the maximum size of the Customer table
Customer.HugeFile = True
...
// Validate the table description
HDescribeFile(Customer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Checking whether the table can contain more than 2 GB of data

`<Result> = <Table>.HugeFile`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table is configured to contain more than 2 GB of data,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table>: (Character string)`**

Name of the table used. This name was defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.


<a name="SYNTAXE2"></a>

### Defining whether the table can contain more than 2 GB of data (table defined programmatically)

`<Table>.HugeFile = <Size 2GB>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<Size 2GB>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file must be configured to contain more than 2 GB of data, 

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Tables over 2 GB
<a name="tables_over_2_ELTPARAGRAPHE000071"></a>

The tables exceeding 2 GB can only be created on the NTFS disks. Furthermore, the operating system must support the files exceeding 2 GB.
