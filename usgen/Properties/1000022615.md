
## RightIndent (Property)

***In french: RetraitDroit***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **RightIndent** property gets and sets the right indent of an element. This property can be used on:

- edit controls and Static Text controls. For more details, see [RightIndent](../Proprietes/1000021110.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [docParagraph](../WDLang1/1000022483.md) variables.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [docNumberingLevel](../WDLang1/1000022799.md) variables.
