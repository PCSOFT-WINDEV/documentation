
## OpeningOptions (Property)

***In french: OptionsOuverture***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **OpeningOptions** gets and sets the opening options of a window manipulated via a [Window](../WDLang1/1410091366.md) variable.  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Set window opening options
My_Exe_Window is Window WIN_Main
My_Exe_Window.OpeningOptions.X = 50
My_Exe_Window.OpeningOptions.Y = 100
My_Exe_Window.OpeningOptions.Animation = waRotationX + waMorphCylinder
// Open window
Open(My_Exe_Window)
```

## Syntax
<a name="SYNTAXE1"></a>

### Getting the value of opening properties

`<Result> = <Window used>.OpeningOptions.<Property name>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<Window used>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable to be used. 

**`<Property name>: ()`**

Window opening property.

| Animation | Integer constant | Type of animation to apply:<br><br>- Available in WINDEV:<br><br>	- *waNone*: No animation available.<br><br>	- *waDefault*: Default animation provided by WINDEV. <br>			This constant cannot be combined with the other constants.<br><br>	- *wasRandom*: Animation randomly selected by WINDEV. <br>			This constant cannot be combined with the other constants.<br><br>	- *waVista*: Windows Vista-style animation.<br><br><br><br><br>- Morphing:<br><br>	- *waCircularFadeIn*: The window appears inside a growing circle.<br><br>	- *waTopFilling*: The window appears from the top.<br><br>	- *waInterleave*: Multiple segments of the window appear from each corner and merge into each other.<br><br>	- *afFountain*: The window appears little by little, as a projection of water coming out of a fountain.<br><br>	- *waBook*: The window emulates an opening book.<br><br>	- *waMorphCylinder*: The window is projected onto a cylinder that gradually transforms into a plane.<br><br>	- *afMorphSphere*: The window is projected onto a sphere that gradually transforms into a plane.<br><br>	- *waMorphWave*: The window appears gradually, emulating dimming waves.<br><br><br><br><br>- Rotation:<br><br>	- *waRotationMulti*: Rotates the window on all axes.<br><br>	- *waRotationX*: Quick rotation around the X-axis.<br><br>	- *waRotationY*: Slow rotation around the Y-axis.<br><br>	- *afZigZag*: Zigzag effect.<br><br><br><br><br>- Transparency:<br><br>	- *waTransparent1*: Window transparency increases from 30% to 80%.<br><br>	- *waTransparent2*: Window transparency increases from 0% to 100%.<br><br>	- *waTransparentFixed*: Transparency remains at 50% during the animation.<br><br><br><br><br>- Zoom:<br><br>	- *waZoom*: Zoom from click position to end position (in a straight line at constant speed).<br><br><br><br><br><br><br><br>Note: This property is equivalent to the [WinAnimationOpening](../WDLang1/3038051.md) | Height | Integer | Initial height of the window. |
| Opacity | Integer | Window opacity value ranging from 0 (fully transparent) to 100 (full opacity).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This property is not available.<br><br>Note: This property is equivalent to the [Opacity](../Proprietes/2514006.md) property used on a window. |
| Parent | Window name | Name of the parent window. This makes it possible to avoid using the current window. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is not available. |
| PersistentPath | Character string | Path used to save persistent values. The separator to use is '\\'. By default, corresponds to the name of the window or its alias if it has one. <br><br>Remarks: <br><br>- The save format of persistent values is defined with [InitParameter](../WDLang1/3025044.md). <br><br>- Persistent options include window size and position, and persistent control values.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is not available. |
| Position | Integer constant | Window opening position:<br><br>- *winPositionCascading*: The window is cascaded relative to its parent. <br><br>- *winPositionCenteredInScreen*: The window is centered in the screen. <br><br>- *winPositionCenteredInParent*: The window is centered relative to its parent. <br><br>- *winPositionOffScreen*: The window is off screen. <br><br>- *winPositionMaximized*: The window is maximized. <br><br>- *winPositionRelativeToScreen*: Position relative to the screen. <br><br>- *winPositionRelativeToParent*: Position relative to the parent window. <br><br><br> |
| Title | Character string | Title of the window to be displayed. <br><br>Note: This property is equivalent to the [NextTitle](../WDLang1/3038043.md) function. |
| Visible | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the window must be visible,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br><br><br>Note: By default, visibility is defined in the description window. This property allows you to override that option.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is not available. |
| Width | Integer | Initial width of the window. |
| X | Integer | Horizontal coordinate of the window (in pixels), relative to the upper-left corner of the screen or parent window. |
| Y | Integer | Vertical coordinate of the window (in pixels), relative to the upper-left corner of the screen or parent window. |
