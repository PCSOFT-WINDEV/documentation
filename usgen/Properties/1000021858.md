


## PersistedCalculatedItem (Property)

***In french: PersistanceRubriqueCalculée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PersistedCalculatedItem** property is used to:

- Find out whether the value of a calculated item is stored in the table. This item was defined in the data model editor or programmatically.

- Define whether the value of a calculated item is stored in the table (when describing the item through programming).




Note: The calculated fields correspond to the "Formula" fields in the data model editor. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AFile is File Description
AnItem is Item Description
AnItem.Name = "CmdDate"
AnItem.CalculatedItemExpression = "'Written by ' + CURRENT_USER + ' on ' + SYSDATE"
AnItem.PersistedCalculatedItem = True
HDescribeItem(AFile, AnItem)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Find out whether the value of a calculated item is stored in the table

`<Result> = <Data file>.<Item>.PersistedCalculatedItem`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the value of the calculated item is stored in the table.

- <u><u><u><u>False</u></u></u></u> if the value of the item is recalculated at each reading.




**`<Table>: (Name of table)`**

Name of the table used.

**`<Item>: (Item name)`**

Name of item used.

### Indicating whether the value of a calculated item must be stored in the table

`<Item>.PersistedCalculatedItem = <Value>`
---

**`<Item>: (Item name)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<Value>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the value of the calculated item must be stored in the table.

- <u><u><u><u>False</u></u></u></u> if the value of the item must be recalculated at each read operation.
