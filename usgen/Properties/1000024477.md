
## AuthURL (Property)

***In french: URLAuth***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **URLAuth** property gets and defines the authorization URL to be used (first URL of the OAuth 2.0 specification). This property can be used on: 

- a variable of type [OAuth2Parameters](../WDLang3/1000022212.md). 

- a variable of type [gpwOAuthParameters](../WDLang6/1000024751.md).
