
## FirstName (Property)

***In french: Prénom***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FirstName** property can be used on:

- a variable of type [saasUser](../WDLang3/1000019083.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Contact](../WDLang3/1000020254.md). 

- a variable of type [gpwUser](../WDLang6/1000021088.md).

- a variable of type [OpenIDIdentity](../WDLang3/1000023567.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [AppleID](../WDLang3/1000025405.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [gglAccount](../WDLang3/1410089816.md).
