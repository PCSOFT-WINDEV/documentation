


## LogFile (Property)

***In french: FichierJournal***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LogFile** property is used to determine if a table is a log file.

**Reminder** A log file is used to store the various operations performed on a logged table. A log file is created if log options have been defined for one or more tables of the database schema.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
EXTERN SupplierJNL
HDeclareExternal("C:\WINDEV\Examples\SalesMgt\SupplierJNL.fic", "SupplierJNL")
IF SupplierJNL.LogFile = True THEN
	Info("You are handling a log file")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table>.LogFile`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file is a log file, 

- <u><u><u><u>False</u></u></u></u> otherwise. 


Note: The tables described in the database schema are not "log" files.

**`<Table>: (Character string)`**

Logical name of the table used. Can correspond to a name of file alias declared by [HDeclareExternal](../WDLang4/3044204.md).
