


## Compiler (Property)

***In french: Compilateur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Compiler** property gets and sets the compiler options in the Code Editor control, in particular, which functions are allowed or disallowed.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CODEEDT_Example.Compiler.AllowedFunctions = AllFunctions
CODEEDT_Example.Compiler.ForbiddenFunctions = "fDelete"
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the value of compiler options

`<Result> = <Code editor>.Compiler.<Property name>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<Code editor>: (Control name)`**

Name of the Code Editor control used. 

**`<Property name>: ()`**

Compiler option applied: 


| Property | Type | Description |
| --- | --- | --- |
| *AllowedFunctions* | Character string | List of allowed functions, separated by CR, commas or semicolons. <br>Example: <br><br><pre><code>"fOpen" + CR + "fCreate"</code></pre><br>Remarks: <br><br>- Specify functions using the standard syntax only. The associated prefix syntax will be automatically taken into account. <br><br>- Function names can be in English or French: both languages are automatically taken into account.<br><br><br> |
| *DefaultFunctions* | Integer constant | Specifies the functions available by default:<br><br>- *AllFunctions*: All WLanguage functions available by default. You can disallow certain functions using the **ForbiddenFunctions** property. <br><br>- *NoFunction*: No function available by default. You can allow certain functions using the **AllowedFunctions** property.<br><br><br> |
| *ForbiddenFunctions* | Character string | List of disallowed functions, separated by CR, commas or semicolons. <br>Example: <br><br><pre><code>"fOpen" + CR + "fCreate"</code></pre><br>Remarks: <br><br>- Specify functions using the standard syntax only. The associated prefix syntax will be automatically taken into account. <br><br>- Function names can be in English or French: both languages are automatically taken into account.<br><br><br> |
