


## Path (Property)

***In french: Chemin***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Path** property gets and sets a path. This property can be used on:

- a variable of type [gglMapParameter](../WDLang5/1000017505.md).

- a variable of type [rssStream](../WDLang5/1000017795.md).

- a variable of type [rssCloud](../WDLang5/1000017785.md).

- a variable of type [Cookie](../WDLang3/1000019222.md).

- a variable of type [hdfsStatus](../WDLang4/1000021973.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [URI](../WDLang3/1000024027.md).

- a variable of type [GglFile](../WDLang3/1410089586.md).
