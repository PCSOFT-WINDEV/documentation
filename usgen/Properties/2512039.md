


## MinAutoID (Property)

***In french: IDAutoMin***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MinAutoID** property is used to get the minimum automatic identifier of a replicated table. **This property is read-only**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the minimum automatic identifier of the Customer table 
ResMinAutoID = Customer.MinAutoID
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table>.MinAutoID`
---

**`<Result>: (Integer)`**



- Minimum value of the automatic identifier defined for the table,

- 0 if the bounds have not been defined or if the table is not replicated.




**`<Table>: (Character string)`**

Logical name of the table used.
