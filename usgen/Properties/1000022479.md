
## Replication (Property)

***In french: Réplication***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Replication** property gets and sets the replication mode. This property can be used on:

- a table. For more details, see [Replication](../Proprietes/2512073.md).

- a variable of type [hServerOperation](../WDLang4/1000022471.md).
