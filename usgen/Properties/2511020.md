


## SourceWindow (Property)

***In french: FenêtreSource***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SourceWindow** property is used to get the source of an internal window (i.e. the internal window displayed by the Internal Window control).

**Note**: To modify the internal window associated with an "Internal window" field, use function [ChangeSourceWindow](../WDLang1/3038053.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(FI_ChampFenInterne1.FenêtreSource) // Affiche FI_FenInterne2
```
<a name="Exemple2"></a>

```wl
// Changement de la source de la fenêtre interne
SI FI_ChampFen1.FenêtreSource = "FI_SaisieParam" ALORS
	ChangeFenêtreSource(FI_ChampFen1, FI_SaisieParam2)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Internal window used> = <Internal Window control>.SourceWindow`
---

**`<Internal window used>: (Window name)`**

Name of the internal window used by the "Internal Window" control.

**`<Internal Window control>: (Control name)`**

Name of the Internal Window control.
