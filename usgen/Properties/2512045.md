


## Format (Property)

***In french: Format***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Format** property is used to define the data format of a table. You can:

- Know the data format used for a table (table defined in the data model editor or programmatically defined).

- Define the data format of a table (only for tables defined programmatically).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defining the data format
Customer.Format = hUnicodeFormat
...
// Validate the table description
HDescribeFile(Customer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Identifying the data format

`<Current format> = <Table>.Format`
---

**`<Current format>: (Integer constant)`**

One of the available formats:



|   |   |
| --- | --- |
| *hANSIFormat* | Ansi format (used by Windows). |
| *hUnicodeFormat* | Unicode format. |



**`<Table>: (Character string)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the data format

`<Table>.Format = <New format>`
---

**`<Table>: (Character string)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New format>: (Integer constant)`**

One of the available formats:



|   |   |
| --- | --- |
| *hANSIFormat* | Ansi format (used by Windows). |
| *hUnicodeFormat* | Unicode format. |
