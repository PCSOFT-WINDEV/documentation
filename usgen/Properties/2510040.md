


## BrowsedFile (Property)

***In french: FichierParcouru***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **BrowsedTable** property gets and sets the data source used to display records in controls based on a table or variable. Some of these controls are:

- Table or TreeView Table controls,

- List Box or ListView controls.

- Combo Box controls.

- Combo Box columns.

- Looper controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organizer controls.

- Scheduler controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organization Chart controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pivot Table controls.

- Kanban controls.

- internal windows (if the swipe gesture is enabled). 

- supercontrols. 




This data source can be:

- a table or a query. The records displayed are from this table or query.

- a variable (array, class member, advanced member, etc.).




This data source is defined in the control description ("Content" tab).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays all the customers in a Table control
TABLE_Table1.BrowsedFile = "Customers"
// Displays the entire content of the Qry_Customers query in a Table control
TABLE_Table1.BrowsedFile = "Qry_Customers"

// Displays the contacts of the gAContact variable
// gAContact is a gglContact variable
TABLE_Table1.BrowsedFile = ":gAContact"
```

## Syntax

### Getting the table, query or variable used as data source

`<Browsed element> = <Control used>.BrowsedFile`
---

**`<Browsed element>: (Character string)`**

Name of the element used as data source for the relevant control. This element can correspond to:

- the name of the table or query.

- the name of the variable. This name has the following format ":&lt;prefix&gt;&lt;Variable name&gt;" or ":&lt;Variable name&gt;". The prefix is applied only if the code style is enabled in the project.




**`<Control used>: (Control name)`**

Name of the control used. This control must be of the following type: 

- Table, TreeView Table.

- List Box or ListView.

- Combo Box.

- Combo Box column.

- Looper.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organizer.

- Scheduler.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organization Chart.

- Internal window.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pivot Table.

- Kanban.





<a name="SYNTAXE2"></a>

### Changing the table, query or variable used as data source

`<Control used>.BrowsedFile = <New data source>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control must be of the following type: 

- Table, TreeView Table.

- List Box or ListView.

- Combo Box.

- Combo Box column.

- Looper.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organizer.

- Scheduler.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organization Chart.

- Internal window.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pivot Table.

- Kanban.




**`<New data source>: (Character string)`**

Name of the element that must be associated with the relevant control:

- Name of the table or name of the query.

- Variable name. This name has the following format ":&lt;prefix&gt;&lt;Variable name&gt;" or ":&lt;Variable name&gt;". The prefix must be specified only if the code style is enabled in the project (whether or not prefixes are displayed).


The control will be empty if this parameter does not correspond to a valid name. The iteration will be stopped if this parameter is an empty string.

## Remarks


### Using the **BrowsedFile** property
<a name="using_the_docparampagetitleshort_property_ELTPARAGRAPHE000184"></a>

The **BrowsedFile** property can be used both in programmed and automatic data source iteration operations.

If the **BrowsedFile** property is used to change the data source used, the iteration operation starts over again. For a Table control, this operating mode is identical to the use of [TableDisplay](../WDLang1/3074003.md) associated with the *taStart* constant.
<a name="NOTE0_2"></a>




### Changing the properties linked to the iteration of a data-bound control
<a name="changing_the_properties_linked_the_iteration_databound_control_ELTPARAGRAPHE000203"></a>

To change multiple properties ([BrowsedItem](../Proprietes/2510111.md), [Filter](../Proprietes/2510042.md) and **BrowsedFile**) it is recommended to:

1. Stop the iteration by assigning an empty string ("") to the **BrowsedFile** property.

2. Change the relevant properties.

3. Restart the iteration with the **BrowsedFile** property.


This method is used to optimize the modifications performed. Each one of the modifications made individually restarts the iteration. These operations can become quite slow when they are performed on large tables.
<a name="NOTE0_3"></a>


### Type of iteration
<a name="type_iteration_ELTPARAGRAPHE000228"></a>

- ***Automatic iteration:*** WINDEV, WEBDEV and WINDEV Mobile automatically manage table iteration and data display in the control. No specific programming is required.
	If the control can be sorted (table...), the sort is performed on the search item defined in the "Content" tab of the element description. 
	If a filter is specified ("Filter on the search item" in the "Content" tab of the object description), this filter is used.

- ***Programmed iteration***: The developer must program the iteration over the table and the way in which data is displayed in the control.
	A programmed iteration allows you to sort and filter records with precision. However, a programmed iteration is slower and more complex than an automatic iteration.



<a name="NOTE0_4"></a>


### Manipulating the data-bound controls via the properties
<a name="manipulating_the_databound_controls_via_the_properties_ELTPARAGRAPHE000242"></a>

- The records displayed in the browsing controls come from the table or query specified by the **BrowsedFile** property.

- The sort direction is defined by the [BrowsedItem](../Proprietes/2510111.md) property.

- Depending on the type of control, the records can be filtered using the [Filter](../Proprietes/2510042.md) property or the [HFilter](../WDLang4/3044100.md) function.



<a name="NOTE0_5"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000262"></a>

The **BrowsedFile** property applies only to controls in a window or page. This property only applies to controls bound to a data source:

- Table and TreeView Table controls,

- List Box and Image controls,

- Combo Box controls, 

- Supercontrols, 

- Table columns (used to modify the table linked to a Combo Box table column).

- Looper controls, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organizer controls.

- Scheduler controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) TreeView controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Organization Chart controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pivot Table controls.

- internal windows (if the swipe gesture is enabled). 

- Kanban controls.
