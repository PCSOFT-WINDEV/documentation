
## Hideable (Property)

***In french: Masquable***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Hideable** property determines if the user can close a bottom sliding window with a touch gesture.

Note: The bottom sliding window can still be closed programmatically, using the [WinSlidingVisible](../WDLang1/1000020978.md) function. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyBottomSlidingWindow.OnHide = () => { Trace("The bottom sliding window has been hidden") }
MyBottomSlidingWindow.OpeningParameters = (42, "Adams")
MyBottomSlidingWindow.InternalWindow = "IW_Sliding_menu"
MyBottomSlidingWindow.HeightCollapsed = 58 // Value in pixels
MyBottomSlidingWindow.HeightHalfExpanded = swFitToContent
MyBottomSlidingWindow.HeightExpanded = 0.9 // 90% 
MyBottomSlidingWindow.Modal = True
MyBottomSlidingWindow.Hideable = True
MyBottomSlidingWindow.RoundedCorner = False

// Opens the bottom sliding window
WinSlidingVisible(swBottom, swHalfExpanded)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Checking if the user can close the bottom sliding window with a touch gesture

`<Result> = <Sliding window>.Hideable`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the user can close the bottom sliding window with a touch gesture, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.


<a name="SYNTAXE2"></a>

### Allowing or preventing the user from closing the bottom sliding window with a touch gesture

`<Sliding window>.Hideable = <New value>`
---

**`<Sliding window>: (MyBottomSlidingWindow)`**

[MyBottomSlidingWindow](../Motscles/1511030.md) keyword corresponding to the bottom sliding window defined for the current window.

**`<New value>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the user can close the bottom sliding window with a touch gesture, 

- <u><u><u><u>False</u></u></u></u> otherwise.
