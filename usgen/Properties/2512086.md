


## FilteredItem (Property)

***In french: RubriqueFiltrée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FilteredItem** property is used to identify the item that has a filter implemented by [HFilter](../WDLang4/3044100.md). This property can be used on an HFSQL table, view or query.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enables the filter
HFilter(Customer, CustomerName, "D" + hValMin, "F" + hValMax, "City='Paris'")
Trace(Customer.FilteredItem)  // Indicates "CustomerName"

// Disables the filter
HDeactivateFilter(Customer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Item> = <Element used>.FilteredItem`
---

**`<Item>: (Character string)`**



- Item onto which the filter defined by [HFilter](../WDLang4/3044100.md) is applied, 

- Empty string ("") if no filter is enabled.




**`<Element used>: (Character string)`**

Name of the HFSQL table, query or view on which the filter was defined.
