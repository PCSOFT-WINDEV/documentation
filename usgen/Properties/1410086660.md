
## NormalizationAlgorithm (Property)

***In french: AlgorithmeNormalisation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **NormalizationAlgorithm** property defines the XML standardization method (C14N). This property can be used on:

- a variable of type [xmlSignature](../WDLang5/1000020736.md). 

- a variable of type [xmlXAdESSignature](../WDLang5/1410091158.md).
