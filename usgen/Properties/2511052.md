


## WidthInPixel (Property)

***In french: LargeurPixel***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WidthInPixel** property is used to get the width in pixels of a control in a report.

**Remark**: The field frame is included in its width. The [Width](../Proprietes/2510059.md) property gets and sets the width of a control in millimeters.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the width of the "ITEM_CustomerName" control
ResWidth = ITEM_CustomerName.WidthInPixel
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Control used>.WidthInPixel`
---

**`<Result>: (Real)`**

Width (in pixels) of the specified control.

**`<Control used>: (Control name)`**

Name of the control (from a report) to be manipulated.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The **WidthInPixel** property cannot be used on:

- an entire report, 

- a report block, 

- a group of controls,

- a Check Box control, 

- an Edit control, 

- an Organizer control, 

- a Scheduler control, 

- a Gantt Chart control, 

- a Signature control.
