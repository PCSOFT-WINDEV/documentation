
## Number (Property)

***In french: Numéro***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Number** property gets the number of an element. This property can be used on:

- a variable of type [API Description](../WDLang1/1000019149.md).

- a variable of type [gglPhoneNumber](../WDLang5/1000017573.md).  

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Phone](../WDLang3/1000020241.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docSection](../WDLang1/1000022685.md).
