
## InvalidInput (Property)

***In french: SaisieInvalide***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InvalidInput** property determines if a control prevents the user from leaving when they enter invalid data. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF m_bCriticalAccount THEN
	EDT_Password.InvalidInput = invalidInputNonBlocking
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Determining if a control detects invalid input

`<Result> = <Control used>.InvalidInput`
---

**`<Result>: (Integer constant)`**

Invalid input check mode: 


|   |   |
| --- | --- |
| *invalidInputBlocking* | The input validation blocks the user. If the input does not match the expected input mask, the user cannot leave the control. |
| *invalidInputNonBlocking* | The input validation does not block the user. If the input does not match the expected input mask, the user can continue entering data. |
| *invalidInputNone* | No input validation has been defined for the control. |



**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- an Edit control, 

- a Combo Box control. 





<a name="SYNTAXE2"></a>

### Enabling or disabling input validation in a control

`<Control used>.InvalidInput = <Invalid input>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- an Edit control, 

- a Combo Box control. 




**`<Invalid input>: (Integer constant)`**

New input validation mode: 


|   |   |
| --- | --- |
| *invalidInputBlocking* | The input validation blocks the user. If the input does not match the expected input mask, the user cannot leave the control. |
| *invalidInputNonBlocking* | The input validation does not block the user. If the input does not match the expected input mask, the user can continue entering data. |
| *invalidInputNone* | No input validation has been defined for the control. |
