


## RepeatableReadSupported (Property)

***In french: RepeatableReadSupporté***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **RepeatableReadSupported** property is used to: 

- Know whether the table (defined in the table model editor or programmatically) can be used in HFSQL Client/Server in a transaction with a "REPEATABLE READ" isolation mode.

- Allow the use of a transaction with a "REPEATABLE READ" isolation mode for a table (when describing the table programmatically only).




Warning: if this option is enabled, the table is incompatible with versions 18 and earlier.

This property corresponds to the "Allow REPEATABLE READ transactions" option, available in the "Options" tab of the table description window in the database schema. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=RepeatableReadSupport%E9%20-%20HC%20N%B0001.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
If Customer.RepeatableReadSupported = False THEN Info("Unable to use the Repeatable Read mode")
```

<a name="SYNTAXE1"></a>

## Syntax

### Whether the table can be used in "REPEATABLE READ" mode 

`<Result> = <Table>.RepeatableReadSupported`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table can be used in "REPEATABLE READ" mode,

- <u><u><u><u>False</u></u></u></u> otherwise.  




**`<Table>: (Name of table)`**

Name of the table used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Define whether the table can be used in "REPEATABLE READ" mode. 

`<Table>.RepeatableReadSupported = <"REPEATABLE READ" Mode>`
---

**`<Table>: (Name of table)`**

Name of the table used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<"REPEATABLE READ" Mode>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table can be used in "REPEATABLE READ" mode,

- <u><u><u><u>False</u></u></u></u> otherwise.
