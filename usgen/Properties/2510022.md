


## BackgroundColor (Property)

***In french: CouleurFond***

<a name="Utilisation"></a>
<a name="description"></a>
The **BackgroundColor** property gets and sets the background color of: 

- a control.

- a window. 

- a page.

- a report block.

- text in a menu option.




**Note**: The effects of the **BackgroundColor** property depend on the type of control (for more details, see "Remarks").


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The background color is modified according to the displayed value
IF EDT_Total > 15000 THEN
	EDT_Total.BackgroundColor = LightRed
END
```

## Syntax

### Determining the background color

`<Background color> = <Element used>.BackgroundColor`
---

**`<Background color>: (Integer or constant)`**

Color of the specified element. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a preset color](../WDLang5/3010002.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The color is returned as a string by the browser.

**`<Element used>: (Type of element)`**

Name of the element to be manipulated: control, window, page or report block.  


<a name="SYNTAXE2"></a>

### Changing the background color

`<Element used>.BackgroundColor = <New color>`
---

**`<Element used>: (Type of element)`**

Name of the element to be manipulated: control, window, page or report block.

**`<New color>: (Integer or constant)`**

New color of the specified element. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).

### Background color of a Table control and its cells, columns or rows
<a name="background_color_table_control_and_its_cells_columns_rows_ELTPARAGRAPHE000269"></a>

Used on the entire Table control, the **BackgroundColor** property allows you to:

- Delete the colors specific to the cells and columns via the following syntax:
	
	```txt
	<Table control>.BackgroundColor = DefaultColor
	```


- Change the background color of all the columns in the Table control (especially columns and cells with no background color). For example, the following code applies blue color to all the columns:
	
	```txt
	<Table control>.BackgroundColor = DarkBlue
	```





This property gets and sets the background color of a cell in a Table control. The following syntax must be used to specify the cell: 

```txt
<Table control>[RowNum][ColumnNum]
```


Example: The following code changes the background color of the cell in the first row of the second column.


```wl
TABLE_Table1[1][2].BackgroundColor = DarkBlue
```
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=table.gif)
**Note**: To keep the background color when selecting a row in a data-bound Table control, simply use the **BackgroundColor** property in the "Select a row" process.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Note**: To change the style of the background color of a cell, column or row in a Table or TreeView Table control, use the [BackgroundStyle](../Proprietes/2513019.md) property.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The **BackgroundColor** property is available in Browser code only for Table controls in "Browser" mode on:

- Rows of the Table control (browser). 

- Columns of the Table control (browser). 

- Cells of the Table control (browser). 


This property is not available in Browser code for Table controls in "Server" or "Server + AJAX" mode.

### Background color of a Tab control
<a name="background_color_tab_control_ELTPARAGRAPHE000329"></a>

For Tab controls:

- For the tabs: 

	- The [Color](../Proprietes/2510071.md) property gets and sets the text color in the tabs.

	- When used on tabs, the **BackgroundColor** property gets and sets the background color of the tabs. 




- For the Tab control: The **BackgroundColor** property gets and sets the background color of the entire Tab control (color of tabs, tab panes and area behind the tabs).

### Limitations
<a name="limitations_ELTPARAGRAPHE000374"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **Limitations on report controls**
The **BackgroundColor** property has no effect on:

- reports (as a whole).

- Internal Report controls.

- Signature controls.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Limitations on controls in WINDEV windows**
The **BackgroundColor** property has no effect on the following controls:

- HTML controls,

- Web Camera controls,

- Slider controls. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Limitations on page controls**
The **BackgroundColor** property has no effect on the elements of a List Box or Combo Box control. 
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In Browser code, the **BackgroundColor** property works only on the following controls:

- edit controls,

- List Box controls and elements in a List Box control, 

- Combo Box controls and elements in a Combo Box control, 

- rows of a Table control,

- Static and HTML Static controls.

- 3-state Button controls. 

- Check Box and Radio Button controls. 

- Image controls.

- "Formatted display" controls.

- Link controls.

- HTML controls.

- cells.

- Thumbnail controls.

- iFrame controls.

- rows of a Table control in "Browser" mode.

- columns of a Table control in "Browser" mode.

- cells of a Table control in "Browser" mode.




The **BackgroundColor** property can also be used on pages. 
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **BackgroundColor** property can only be used with the following elements:

- Button control.

- Static Text control.

- Edit control.

- Image control.

- Check Box control.

- Radio Button control.

- List Box control.

- Combo Box control.

- TreeView control.

- Tab control.

- Window.

- Table control.

- Table control column.


![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The **BackgroundColor** property can only be used with the following elements:

- Button control.

- Static Text control.

- Image control.

- Window.


![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) The **BackgroundColor** property can only be used with the following elements:

- Static Text control.
