
## KeyInformation (Property)

***In french: InformationClé***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **KeyInfo** property is used to define information about the key. This property can be used on:

- a variable of type [xmlSignature](../WDLang5/1000020736.md).
