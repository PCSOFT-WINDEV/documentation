
## Checked (Property)

***In french: Coché***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Checked** property determines whether or not an element is checked. 

This property can be used: 

- on menu options and rows of a TreeView control. For more details, see [the Checked property on controls](../Proprietes/2510019.md). 

- on a variable of type [docElementCheckBox](../WDLang1/1410089762.md).
