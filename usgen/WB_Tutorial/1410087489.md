## Adding a new product via the "Product form" page
<a name="adding_new_product_via_the_product_form_page_ELTTEXTE000446"></a>


### Adding a product when the page is initialized
<a name="adding_product_when_the_page_initialized_ELTPARAGRAPHE000040"></a>

Let's go back to our example. 

First, we will change the opening mode of "PAGE_Product_form":

1. Click "PAGE_Product_form" in the open document tabs.

2. Press F2 to open the different WLanguage events of the page.

3. In the "Global declarations" event, we will assign a default value to the parameter passed to the page. When a record is modified, the parameter passed always corresponds to the identifier of the product to be modified. But when a record is added, the element does not yet have an identifier. To handle this case, we will set "-1" as the default value.

4. Replace the following line of code in the "Global declarations" event:
	Global declarations of PAGE_Product_form (server)

	```wl
	PROCEDURE MyPage(NumProductToDisplay is 8-byte int)
	```

	with the code:
	Global declarations of PAGE_Product_form (server)

	```wl
	PROCEDURE MyPage(NumProductToDisplay is 8-byte int=-1)
	```


5. We will now handle the "-1" value (when a record is added). Replace the following code:
	Global declarations of PAGE_Product_form (server)

	```wl
	Product.ReadSeekFirst(ProductID, NumProductToDisplay)
	IF Product.Found() = False THEN
		// Display the list of products
		PAGE_List_of_products.Display()
	END
	Product.ToPage()
	```

	with the code:
	Global declarations of PAGE_Product_form (server)

	```wl
	IF NumProductToDisplay = -1 THEN
		Product.Reset()
	ELSE
		Product.ReadSeekFirst(ProductID, NumProductToDisplay)
		IF Product.Found() = False THEN
			// Display the list of products
			PAGE_List_of_products.Display()
		END
	END
	Product.ToPage()
	```

	Let's analyze this code:

	- If the product identifier is set to -1, it means that a product is added. In this case, [Reset](../WDLang4/1000025052.md) is executed. This function initializes the item variables in the "Product" table with the default values to add a new record.

	- If the product identifier has a value different from -1, we use the code to open the form in edit mode.




6. Close the code window.







### Adding a product when the page is validated
<a name="adding_product_when_the_page_validated_ELTPARAGRAPHE000086"></a>

The "OK" Button control must also add the record.

1. Select the "OK" button in "PAGE_Product_form".

2. Open the WLanguage events associated with the control (F2).

3. Leave the code in the "Click xxx (browser)" event unchanged, as the verifications to be made are the same. Only the Server code must be modified.

4. In the "Click xxx (server)" event, replace the existing code with the following code:
	Click (server)

	```wl
	Product.FromPage()
	Product.Save()
	PAGE_List_of_products.Display()
	```

	Let's take a look at this code. [&lt;Table&gt;.Save](../WDLang4/1000024606.md) checks whether the record is already in the "Product" table and allows you to add it or modify it, where necessary. 

5. Save changes (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WB_GAF.jpg) or Ctrl + S).

6. Close the code window.





### Adding a product in the page menu
<a name="adding_product_the_page_menu_ELTPARAGRAPHE000110"></a>

We will modify the page menu to allow users to add a new product.

1. In the open documents bar, click "PAGE_List_of_products".

2. Right-click a menu option to open the context menu and select "Open template".

3. In the page template, select the menu.

4. Open the context menu and select "Edit menu". A yellow outline appears around the menu. This outline indicates that the menu is in "Edit" mode and can be modified.

5. Select the "Product form" option, right-click and select "Option description" in the context menu.

6. On the "General" tab, in "Option action": 

	- select "Display a site page". 

	- select the "PAGE_Product_form" page.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Site%20Complet%20-%207%20Fiche%20Produit%20Cr%E9ation%20-%20HC%20N%B0001.jpg)





7. Confirm. 

8. In the template bar, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Site%20Complet%20-%205%20Gestion%20des%20menus%20-%20HC%20N%B0002%201.jpg) to apply the changes made to the template to all the pages that use it.

9. In our case, the two project pages are proposed. Validate the page template update window.

10. Close the page template.




Now, we want the "Product form" option to be selected when the corresponding page is displayed. To do so, we will override the menu displayed in "PAGE_Product_form", and then the "Product form" option.
Perform the following actions:

1. Right-click the "Product form" option and select "Override control".

2. Open the context menu of the menu again and select "Edit menu". A yellow outline appears around the menu to indicate it has switched to edit mode.

3. Right-click the "Product form" option and select "Override control".

4. Right-click the "Product form" option once again and select "Set this menu option as selected".

5. Press Esc to exit edit mode.

6. Save the page (Ctrl + S).



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Site%20Complet%20-%207%20Fiche%20Produit%20Cr%E9ation%20-%20HC%20N%B0002.jpg)


The page is ready to be tested.

### Managing the product image
<a name="managing_the_product_image_ELTPARAGRAPHE000149"></a>

In the Product table, an item is used store the image associated with the product.

We have already inserted an Image control in the page to view the image. Now we will define the options to allow users to change the product image.

Users will be able to upload an image from their computer and it will be bound to an item in the table. We will use an Upload control.Uploading consists in copying a file from the client computer to the server.

Downloading, on the other hand, consists in copying a file from the server to the client computer.
WEBDEV features an Upload Smart control. 
To create the Upload control:

1. On the "Creation" tab, in the "Usual controls" group, expand "Button". The list of available types of buttons is displayed.

2. Select "File upload".

3. Click at the desired location to create the control in the page (below the Image control, for example). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Site%20Complet%20-%207%20Fiche%20Produit%20Cr%E9ation%20-%20HC%20N%B0003.jpg&type=thumb)



The Upload control includes:

- a cell containing: 

	- a Static Text control, 

	- a Looper control used to display the characteristics of the files to upload. 




- an Add button enabling the user to select the files to upload,

- a Send button enabling the user to send files to the server.




Now we will adapt the control's code to upload files in our site.

To configure the Upload control:

1. Select the "ADD" Button control and press F2 to open its code.

2. Different WLanguage events are associated with the Upload control. We will modify the "Receive files uploaded" event to copy the image to the site data directory.

3. Write the following code in the "Receive files uploaded" event (ignore compilation errors, we will correct them later):
	Receive files uploaded from UPL_Upload

	```wl
	UploadCopyFile(MySelf, fDataDir(), UploadFileName(MySelf, False))
	ImagePath = fDataDir() + [fSep()] + UploadFileName(MySelf, False)
	IMG_Visual = ImagePath
	```


4. Let's analyze this code:

	- [UploadCopyFile](../WDLang2/3012023.md) saves the file uploaded by the user on the server. In our case, the file is copied to the data directory (returned by [fDataDir](../WDLang1/3036001.md)). The file name is kept.

	- The path of the uploaded image is then stored in a global variable named ***ImagePath***.
			**Why use a global variable?** 

A global variable is required here because the image path will be used in the code of the "OK" button, to save the new image in the table.

For more details on the conditions for using local and global variables, see the [WLanguage tutorial](../TutoWB/1410087226.md).


	- [fSep](../WDLang1/1000019647.md) gets the separator to be used on the server's operating system ("\\" for Windows and "/" for Linux). Therefore, your site is independent of the server where it is installed!

- Then, the uploaded image is displayed in the IMG_Visual Image control.

5. In the code editor, the ***ImagePath*** variable is displayed in red and a compilation error appears next to the lines of code: "The element 'ImagePath' is unknown or inaccessible". We have not declared this global variable yet. These errors also appear in the compilation errors pane. 

6. To declare the global variable:

	- Go to the "Global declarations" event of the page (for example, in the Code editor, go to the "Code" tab, and select "Global declarations" in the combo box that lists all the events). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Site%20WebDev%20-%20Fiche%20Produit%20-%202%20-%20HC%20N%B0004.jpg&type=thumb)


	- Type the following code after the procedure declaration:
			Global declarations of PAGE_Product_form (server)

		```wl
		ImagePath is string
		```


7. Save changes by clicking ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WB_GAF.jpg) in the quick access buttons. The compilation errors disappear.

8. Close the code editor.


Our image can now be uploaded on the server. Now we only need to save the image in the database.


To save the image in the Product table:

1. Open the code of the "OK" Button control:

	- Select the "OK" button.

	- Press F2.




2. In the "Click xxx (server)" event of the Button control, enter the following code AFTER the call to [&lt;Table&gt;.FromPage](../WDLang4/1000021405.md):
	Click on BTN_OK (server)

	```wl
	IF ImagePath<>"" THEN
		Product.Visual = fLoadBuffer(ImagePath) 
	END
	```


3. Let's take a look at this WLanguage code:

	- This code checks the content of the ***ImagePath*** global variable. If this variable does not correspond to an empty string, it means that the image was uploaded by the user. In this case, the "Visual" item of the Product table is updated with the binary content of the image. This content is retrieved with [fLoadBuffer](../WDLang1/1000019410.md). 

	- [&lt;Table&gt;.Modify](../WDLang4/1000025038.md) (already used in the code) saves changes in the table.




4. Save changes (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WB_GAF.jpg) or Ctrl + S).

5. Close the code window.

### Testing the addition of a product
<a name="testing_the_addition_product_ELTPARAGRAPHE000284"></a>

We have made all the changes required to add a product. Now, we can simply run a test. 

To test the addition of a product:

1. Test the project (click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Go_Projet_WB_GAF.jpg) in the quick access buttons). The page containing the list of products appears. 

2. Click "Product form".

3. Enter a new product with the following characteristics:

	- Reference: M49629

	- Caption: Xxx bag

	- Description: Leather bag

	- Price: 150




4. Confirm. The new product appears in the list of products.




To add an image to a product: 

1. In the list of products, click the "Edit" link of the new product. The product form appears. 

2. Click the "Add" button (below "Drop files here") and select an image file on your computer. 

3. Click the "Send" button. 

4. Click "OK" to confirm changes. 

5. The new photo now appears for the product we just edited.
