Proceed to the next step of the wizard.

3. In the list of preset tables, select "Customer". Go to the next step.

4. The list of items to be included in the Customer table is displayed.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%202%20-%20Fichier%20Client%20WB%20-%20HC%20N%B0002.jpg&type=thumb)

### Creating a table from scratch
<a name="creating_table_from_scratch_ELTPARAGRAPHE000123"></a>

Now, let's create the Order table without using the wizard:

1. In the data model editor, on the "Database schema" tab, in the "Creation" group, click "New table". The table creation wizard opens.

2. In the wizard, select "Create a new table description".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0001.jpg&type=thumb)
Proceed to the next step of the wizard.

3. In the wizard, enter the name of the table: "Order". This name will be used:

	- to handle the table in the code. The variable associated with the table will be "Order".

	- to build the name of the associated physical table ("Order.fic" file).


 The caption and description of the elements represented by the records in the table appear automatically.
	In "A record represents", enter "An order".
	The name you enter in this field is used to generate a clear description of the links between tables. A description is automatically created based on the table name.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0002.jpg)


6. In the "Automatic identifier" section, keep "8-byte automatic identifier". 
	If an automatic identifier is defined on the table, it means that the table includes a unique key, automatically managed by WEBDEV.
Each time a record is added to the table, WEBDEV automatically assigns a value to the table identifier. This value is unique.


7. In the next step of the wizard, you can select the type of database associated with the table. We are going to work on HFSQL Classic tables. Click "Finish" to confirm. 




The table is automatically created in the database schema. The description window of items is opened.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0003.jpg&type=thumb)


We are going to create the items of the "Order" table. In the description window of the items, you will notice that an "OrderID" item has been automatically created. This item corresponds to the automatic identifier of the table. This item consists of the name of the table and the letters "ID".

We are going to create the other items of this table.

**First, let's create the "Date" item.** This item will contain the date of the order.

1. In the item description window, double-click in the "Name" column of the first empty row. This column automatically becomes editable. Type "Date".

2. Click the "Caption" column. The item name is automatically displayed. Click the item caption and type "Order date". In the "Type" column, the "Text" type is automatically selected. Expand the list and select the "Date" type.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0004.jpg)


3. This item will be a key item (index) in the table. 
	Keys are used access and sort data faster.
A key is part of the item characteristics. An item can be non-key, unique key, key with duplicates or primary key. For more details on the different types of key, see [Key items](../Editeurs/2011023.md). 


4. In this example, the "Date" item is a key with duplicates. This means the value of the key may be present several times in the table.

	- Select the row of the "Date" item again to see its description on the right of the screen. 

	- Choose "Key with duplicates".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0004%201.jpg)





5. You can also define the default sort order of the key. In our case, the default sort order of this key will be "ascending".




**We will create the "Status" item** to get the order status.

1. Move the cursor to a new row in the table of items. Enter the following values:

	- Name: Status

	- Caption: Order status

	- Type: Radio Button, List Box, Combo Box. In the window that appears, you can select the type of control to be created by default for this item. In this case, select Radio Button. Validate the window.




2. In the lower section of the screen, click the link to display the parameters of the control bound to the selected item. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0004%202.jpg)
The information in the window displayed will be automatically used when creating pages linked to the table. This window displays the type of control and the caption.
	We will define the different options corresponding to the order status in the "Content" tab:

	- Click the "Content" tab.

	- Click the "+" icon to add a new option. 

	- Option 1 corresponds to "Pending". Type "Pending" instead of "Option 1".

	- Click the "+" icon to add a new option. 

	- Type "Validated" instead of "Option 2".

	- Click the "+" icon to add a new option. 

	- Type "Canceled" instead of "Option 3".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%203%20-%20Fichier%20Commande%20WB%20-%20HC%20N%B0005.jpg&type=thumb)





3. Click "OK" to confirm and close the window.

### Importing a CSV file
<a name="importing_csv_file_ELTPARAGRAPHE000252"></a>

To create the "PaymentMethod" table, which contains the payment characteristics, we will use a different method: we will import a CSV file.A CSV file is a text file that uses a specific format. This file contains data on each line. The data is separated by a separator character (usually a comma, a semi-colon or a tab).
Based on the CSV file containing the data, WEBDEV will create:

- the description of the table in the database schema,

- the HFSQL table with the table in the CSV table.




To import the CSV file into the data model editor, follow these steps: 

1. In the ribbon, on the "Database schema" tab, in the "Creation" group, expand "Import" and select "Import file/table descriptions...". 

2. The table import wizard opens.

3. Select the format of the table to import. In this case, select "Text file".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0001.jpg&type=thumb)
Proceed to the next step of the wizard.

4. Enter the path of the file to be imported: "\\Tutorial\\WB\\Exercises\\My_WEBDEV_Site\\PaymentMethod.csv", located in the WINDEV Suite installation directory. Proceed to the next step of the wizard.

5. Specify the following import options:

	- Records delimited by: "&lt;Carriage return/Line feed&gt;"

	- Columns delimited by: "&lt;Semicolon&gt;"

	- Strings delimited by: "&lt;None&gt;"

	- Decimal separator: "&lt;Automatic: dot or comma&gt;"<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0002.jpg&type=thumb)





6. Don't forget to check "The first row contains the names of the columns". Go to the next step.

7. The wizard displays the structure of the new table. Keep the default options. Go to the next step.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0003.jpg&type=thumb)


8. The content of the CSV file will be automatically converted to HFSQL. The wizard suggests creating the HFSQL table in the project directory.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0004.jpg&type=thumb)
Keep the default options and go to the next step.

9. Finish the wizard. WEBDEV creates the table.




Let's examine the description of the imported table:

1. Select the "PaymentMethod" table, and then select "Table description" in the context menu.

2. In the window that appears, delete "(Imported)" from the table caption.

3. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%207%20-%20Ligne%20de%20commande%20WB%20-%20HC%20N%B0001%201.jpg) (bottom left) to open the description of the table items.

4. This table does not have an automatic identifier or a unique key. We will set the "Code" item as a unique key:

	- Select the "Code" item if necessary.

	- On the right side of the screen, click "Unique key". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0005.jpg)<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%204%20-%20Import%20CSV%20WB%20-%20HC%20N%B0005%201.jpg)





5. Validate the item and table description windows.

## Creating links
<a name="creating_links_ELTTEXTE000774"></a>
We have created all the necessary table descriptions: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%205%20-%20Import%20FIC%20WB%20-%20HC%20N%B0001.jpg&type=thumb)
Now we will create the links between the tables. 
A link is used to define the integrity constraints (cardinalities) between two tables.



First, let's create the link between the "Customer" and "Order" tables. We can consider that: 

- a customer can have one or more orders. 

- each order is linked to a customer.


To create the link: 

1. In the ribbon, on the "Database schema" tab, in the "Creation" group, click "New link". The mouse cursor turns into a pen.

2. Click the "Customer" table, then the "Order" table.

3. The link creation wizard opens.

4. Answer the questions asked by the wizard: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%206%20-%20Liaisons%20WB%20-%20HC%20N%B0001.jpg&type=thumb)


	- Each Customer has at least one Order: No

- Each Customer can have several Orders: Yes

- Each Order has at least one Customer: Yes

- Each Order can have several Customers: No
			**If you know the cardinalities**, you can also specify the link cardinalities directly in the wizard.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%206%20-%20Liaisons%20WB%20-%20HC%20N%B0001%201.jpg)


5. Go to the next step. The wizard automatically shows the key used by the link (CustomerID).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%206%20-%20Liaisons%20WB%20-%20HC%20N%B0002.jpg&type=thumb)


6. Proceed to the next step of the wizard. The wizard proposes to create the "CustomerID" key in the Order table to store the customer corresponding to the order.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%206%20-%20Liaisons%20WB%20-%20HC%20N%B0003.jpg&type=thumb)


7. Accept this option by going to the next step.

8. This step defines the integrity rules that will be automatically applied. In our case, you can set the behavior when deleting a customer and when modifying the customer identifier.

9. Validate the integrity rules by going to the next step of the wizard.

10. Click "Finish". The link is automatically created in the data model editor.

## Generating the database schema
<a name="generating_the_database_schema_ELTTEXTE000825"></a>
The generation of the database schema consists in validating the changes made to the database schema (create tables, add or delete items, etc.) and applying them to the entire project (pages, bound controls, reports, etc.).

If changes have been made to the database schema, a synchronization dialog box appears automatically when the data model editor is closed.

You can also generate the database schema manually. That's what we are going to do.

To generate the database schema:

1. In the ribbon of the data model editor, go to the "Database schema" tab, "Database schema" group and click "Generation".

2. The database schema generation starts automatically.

3. Since we modified the description of the tables in the database schema, WEBDEV suggests synchronizing the structure of the deployed data to update the tables of the application (this also referred to as "table update procedure"). This operation updates the physical tables (".fic" files) based on their description in the database schema.

4. Click the "Start" button. 




The automatic modification wizard opens. 

1. Validate the different steps of the wizard until you reach the list of tables to be taken into account:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%207%20-%20Ligne%20de%20commande%20WB%20-%20HC%20N%B0006.jpg&type=thumb)


	- The PaymentMethod table must be updated. Keep this table selected.

- The Product table was copied into the project directory. WEBDEV prompts you to associate it with the database schema. Check the table. 

2. Go to the next step.

3. The wizard proposes to make a back up copy of the existing tables, don't change anything and go to the next step.

4. The wizard allows you to define a password to protect the tables that were modified during the automatic modification. Keep the default options and go to the next step.

5. The list of tables to modify is displayed. Finish the wizard.


The tables are updated.

Close the data model editor.
