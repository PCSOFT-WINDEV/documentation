


## HFSQL Control Center: Opening a database schema
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000179"></a>
The HFSQL Control Center allows you to fully manage a database schema. It provides access to all the databases included in the database schema: HFSQL Classic, HFSQL Client/Server and external databases.

The characteristics of a database schema can be displayed:

- by starting the HFSQL Control Center from a project: 

	1. Open the WINDEV, WINDEV Mobile or WEBDEV project. 

	2. On the "Tools" tab, in the "Database" group, click "HFSQL". 

	3. The home window of HFSQL Control Center is displayed. The "Open an analysis" option is selected and the path of the current database schema appears in the input field. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Passage%20analyse%20en%20CS%20-%20HC%20N%B0008.gif&type=thumb)


	4. Validate. The database schema is opened in the HFSQL Control Center. 

- from the HFSQL Control Center: 

	1. Open the HFSQL Control Center. 

	2. In the home window, click "Open an analysis". 

	3. Specify the database schema path (WDD file) and the database schema password if necessary. 

	4. Validate. The database schema is opened in the HFSQL Control Center.

## Characteristics of the database schema
<a name="characteristics_the_database_schema_ELTTEXTE000203"></a>


### "HFSQL Classic" tab
<a name="hfsql_classic_tab_ELTPARAGRAPHE000054"></a>This tab shows information about the HFSQL Classic tables in the database schema.
The following information is displayed:

- Logical name of the table,

- Full path (if it exists),

- Size of the table,

- Number of active records,

- Number of deleted records,

- Total number of records.





### "HFSQL C/S" tab
<a name="hfsql_tab_ELTPARAGRAPHE000067"></a>This tab shows information about the HFSQL Client/Server tables in the database schema.
The following information is displayed:

- Logical name of the table,

- Server,

- Associated database,

- Size of the table,

- Number of active records,

- Number of deleted records,

- Total number of records.





### "External database" tab
<a name="external_database_tab_ELTPARAGRAPHE000081"></a>This tab shows all the information about non-HFSQL tables present in the database schema.
The following information is displayed:

- Logical name of the table,

- Type,

- Data source,

- Total number of records.





### "Links" tab
<a name="links_tab_ELTPARAGRAPHE000092"></a>

This tab shows all the information about the links between the tables in the database schema.

The following information is displayed:

- Name of the link, 

- Name of the source table,

- Source cardinality, 

- Name of destination table, 

- Destination cardinality, 

- Integrity rule for deletion, 

- Integrity rule for modification. 




Note: Links are created and edited in the data model editor.

## Ribbon options
<a name="ribbon_options_ELTTEXTE000245"></a>
When you open a database schema in the HFSQL Control Center, the ribbon shows the following options:

- In the "Manage files" group: 

	- **Synchronize files**: This option starts automatic table modification to synchronize the tables and their descriptions in the database schema. This operation is performed via a wizard. 

	- **Add a deployment directory**: This option allows you to select a directory in which the tables corresponding to the database schema are to be searched. 

	- **Manage .REP files**: This option lists the locations of the tables saved in the .REP file linked to the database schema. You can add files to and delete files from the .REP file. 




- In the "Tables" group: This group appears only for tabs that allow access to tables. In particular, it allows direct access to tables. For HFSQL tables, it is also possible to launch an optimization and repair of tables.
