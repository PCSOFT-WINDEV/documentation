


## Managing HFSQL servers
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000346"></a>
The HFSQL Control Center allows you to fully manage HFSQL servers.

To display the characteristics of an HFSQL server: 

1. Connect (if necessary) to an HFSQL server. For more details, see [Managing HFSQL Client/Server databases](../CCHF/35400013.md). 

2. Double-click the name of HFSQL server in the tree structure. 

3. The right section of Control Center displays a tab with the server name. This tab includes: 

	- several tabs used to manage the characteristics of HFSQL server.

	- a ribbon used to configure the HFSQL server. 







<a name="NOTE2"></a>


## Detailed characteristics of an HFSQL server
<a name="detailed_characteristics_hfsql_server_ELTTEXTE000370"></a>


### "Dashboard" tab
<a name="dashboard_tab_ELTPARAGRAPHE000032"></a>

This tab displays the main characteristics of the server.

Several actions can be performed on the server from the dashboard. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0001.gif&type=thumb)


This tab displays the following characteristics in widget format: 

- **Server name and status**. The time, the amount of RAM and the system are also displayed. 

- **Server version**with update mode. To configure the server update, click the corresponding link. For more details, see [Automatic server update](../CCHF/35400018.md). 

- **Current user**. You have the ability to edit the profile of the current user. 

- **Uses and groups defined on the server**. A click performed on the information displayed allows you to access the characteristics of the users or groups. 

- **Transactions** Displays current transactions. 

- **Configuration** Displays the main server configuration features: calculation of key statistics, activity statistics, index cache, log management, etc. Click an option to open the corresponding settings window. 

- **Server activity** Displays current tasks. A click on the number of current tasks is used to get the task details. 

- **Security audit**: Detects the following problems: 

	- No password security policy in place. 

	- One or more users have expired passwords to connect to the server.
			




- **Scheduled tasks** Displays the different types of scheduled tasks available on the server. A click performed on these tasks is used to see their configuration. 

- **Notifications** Displays notifications received. You have the ability to configure the recipients of notifications directly. 

- **Replication** Displays replications of defined server data. You can directly configure the server replication. 

- **Backup** Displays scheduled backups. You have the ability to configure the scheduled backups. 

- **Connections** Displays the number of connections. The link "More details" is used to display the "Connections" tab. 

- **Database volume** Displays a graph showing the volume of each database installed on the server. The option "Display the list of databases" is used to display the "Databases" tab. 




To configure the widgets displayed in the Dashboard: 

1. Display the table context menu of the "Dashboard" tab (in a location containing no widget for example). 

2. Select "Modification mode". 

3. The dashboard appears in "modification" mode. You can: 

	- Hide some widgets. 

	- Display the hidden widgets. 

	- Resize the widgets with the mouse. 




4. To exit from the modification mode and to apply your changes, select "Modification mode " in the context menu.

### "Connections" tab
<a name="connections_tab_ELTPARAGRAPHE000082"></a>This tab lists the different users connected to the different databases found on the server.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0002.gif&type=thumb)
The list of active connections contains the following information:

- the database name,

- the username,

- the computer name,

- the name of the application that accesses the database, etc.




From this tab, you can:

- Filter connections by machine, user, application or database.

- Block connections: prohibit or authorize connections, via the "Block connections" option in the ribbon.

- Disconnect users. 
	Simply select the user(s) you wish to disconnect, and click "Disconnect selected users".

- Send a message to the users. 
	Simply select the recipients, and click "Send a message to the selected users".




The option "Don't display the connections of HFSQL Control Center (stated on this computer)" is used to only display the connections of users via the applications. 
<a name="NOTE2_3"></a>


### "Databases" tab
<a name="databases_tab_ELTPARAGRAPHE000123"></a>This tab is used to list the different databases found on the server. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0003.gif&type=thumb)
The following information is specified for each database: 

- The number of connections, 

- the number of locks, 

- the number of tables. 




When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Databases" group, are used to: 

- access the selected database, 

- display the details of the selected database or the details of all databases. One or more new tabs are opened, displaying the details of the database. 

- delete the selected database from the server. 



<a name="NOTE2_4"></a>


### "Users" tab
<a name="users_tab_ELTPARAGRAPHE000142"></a>

This tab is used to manage the users (creation, modification, deletion, search).

When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Users" group, are used to: 

- create a new user, 

- edit the characteristics of an existing user, 

- delete a user. 




When a user is created, the user can be a superuser: users designated as "superuser" are authorized to perform all actions on the server, databases and all tables.
<a name="NOTE2_5"></a>


### "Group" tab
<a name="group_tab_ELTPARAGRAPHE000157"></a>

This tab is used to manage the groups of users (creation, modification, deletion).

When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Groups" group, are used to: 

- create a new group, 

- edit the characteristics of an existing group, 

- delete a group.



<a name="NOTE2_6"></a>


### "Transactions" tab
<a name="transactions_tab_ELTPARAGRAPHE000170"></a>

This tab is used to manage the current transactions or the interrupted transactions on the server. It is possible to: 

- See the current transactions, 

- Free records held by a transaction.

### "Scheduled elements" tab
<a name="scheduled_elements_tab_ELTPARAGRAPHE000182"></a>

This tab is used to create, modify and delete schedule operations on the server: 

- backups. For more details, see [Scheduling backups](../CCHF/3540006.md).  

- tasks (stored procedures). For more details, see [Task scheduler](../CCHF/3540009.md).

- optimization. For more details, see [Scheduled optimization planning](../CCHF/1410087348.md).

- refresh of materialized views. For more details, see [Scheduling refreshes of materialized views](../CCHF/1410087349.md). 




When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Scheduled elements" group, are used to: 

- create a new scheduling, 

- display the details of a scheduling,

- run a scheduling,

- delete a scheduling. 

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0005.gif&type=thumb)

### "Backups" tab
<a name="backups_tab_ELTPARAGRAPHE000215"></a>

This tab allows you to: 

- view all backups (running or completed). 

- restore server and/or database backups.  




When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Backups" group, are used to: 

- create a new backup (hot or scheduled backup),

- restart a backup,

- restore a backup,

- delete a backup. 




For more details, see [Backups](../CCHF/3540006.md).
<a name="NOTE2_9"></a>


### "Notifications" tab
<a name="notifications_tab_ELTPARAGRAPHE000237"></a>

This tab lists the different server notifications:

- Failed scheduled tasks,

- Failed backups,

- Replication server not accessible,

- etc.




When this tab is selected, additional options are displayed in the ribbon. These options, found in the "Notifications" group, are used to: 

- Delete the selected notifications.

- Delete all the notifications from the server.




For more details on notifications, see [Notifications of an HFSQL server](../WDLang4/1000017311.md).

## Ribbon options
<a name="ribbon_options_ELTTEXTE000442"></a>
When the server characteristics are displayed, the ribbon shows several options: 

- general options. 

- options specific to the different selected tabs. 

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0001%201.gif&type=thumb)
The general options are as follows: 

- In the "SQL query" group: 

	- New query: This option opens a specific tab for creating a new query..  

	- Open a query: This option opens a specific tab with a previously executed query. 




- In the "Server" group: 

	- Stop server: This option stops the server.. 

	- Start server: This option starts the server (if it has been previously stopped).. 




- In the "Databases" group: 

	- New database: This option allows you to create a new database on the server.. 

	- Import an HFSQL Classic database: This option lets you import an HFSQL Classic database onto the server in Client/Server mode.. A wizard allows you to select the tables to import. 

	- Recover files from the server: This option allows you to locally copy tables from the server. A wizard allows you to select the different copy options as well as the copy directory.




- In the "Rights" group: 

	- Rights management: This option lets you manage server rights for the selected user or group.. You have the ability to store and restore a configuration of rights.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_HF_Gestion_Serveur%20-%20HC%20N%B0006.gif&type=thumb)





- In the "Parameters" group, the option "Server configuration" is used to configure the server. For more details, see [HFSQL server configuration](../CCHF/3540004.md). 

- In the "Logs and statistics" group: 

	- Display server logs: This option gives you an overview of database usage between two dates:

		- most used queries, longest queries, 

		- most consuming applications

		- statistics by application, process, etc.


 This option is available only if the logs are enabled on the server.

- Show server stats: This option is only available if activity statistics are enabled on the server.
