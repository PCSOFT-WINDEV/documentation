## Default events
<a name="default_events_ELTTEXTE000245"></a>


### Events supported by WINDEV and WINDEV Mobile
<a name="events_supported_windev_and_windev_mobile_ELTPARAGRAPHE000031"></a>

The following events appear by default in the code editor:

| Event | Runtime condition |
| --- | --- |
| Initialization | Executed when the window is opened. \* |
| Click on a link | Executed when a link is clicked in the HTML Display control. Only external links (to another page) trigger this event. Internal links (to an anchor in the same page, for example) do not trigger this event. <br><br>This event accepts parameters: <br><br><pre><code>PROCEDURE ClickLink(sURL is string, bInNewWindow is boolean, <br>	sDestination is string)</code></pre><br>where &lt;sURL&gt; is an optional string that contains the URL of the link clicked in the HTML Display control. <br><br>If this event returns <u><u><u><u>False</u></u></u></u>, the action associated with the link will not be performed.<br> <br>Caution: the code must not include processing that is too slow or allows the field to regain focus. In this case, the default action will still be performed.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Remarks: <br><br>- The code in the "Click on link" event must not execute a blocking process (e.g. display a dialog box).<br><br>- This event is only available for Android 7.0 (Nougat) and higher. <br>	Reminder: To find out which Android system version the application is running on, use the [SysAndroidVersion](../WDLang1/1000019785.md) function. <br><br>- This event will not be called if the clicked link corresponds to an anchor link in the page.<br><br>- The event is called only when the user clicks the link. A "simulated" click from JavaScript code, for example, will not trigger the event.<br><br><br>Code sample: <br><br><br><pre><code>// Open links with a new window as destination, <br>// in another specific window of the application<br>PROCEDURE ClickLink(sURL is string, bInNewWindow is boolean, <br>	sDestination is string)<br>IF bInNewWindow THEN<br>	// Open another requested window: <br>	// opening process of the other window, <br>	// delayed so that the current process responds <br>	// before opening the new window<br>	OpenNewBrowser(sURL)	<br>	RETURN False // Overrides default behavior<br>ELSE<br>	RETURN True // Keeps default behavior<br>END<br><br>	INTERNAL PROCEDURE DisplayNewBrowser(sURLParam) <Delay=10ms> <br>		// Important: set even the smallest delay<br>		<COMPILE IF ConfigurationType = Android OR ConfigurationType = iOS><br>			OpenMobileWindow(WIN_POPUP, sURLParam) <br>		<ELSE>	<br>			OpenChild(WIN_POPUP. sURLParam) <br>		<END><br>	END</code></pre><br> |
| Before loading HTML page | Executed before loading the HTML document in the HTML Display control. If the user navigates using links in the HTML Display control, this event is executed before each HTML document is loaded. <br><br>This event accepts parameters: <br><br><pre><code>PROCEDURE ChangePage(sURL is string, sDestination is string)</code></pre><br>where &lt;sURL&gt; is an optional string that contains the URL of the page to be displayed. <br><br>If this event returns <u><u><u><u>False</u></u></u></u>, the page will not load. |
| After loading HTML page | Executed after the HTML document has been loaded in the HTML Display control. If the user navigates using links in the HTML Display control, this event is executed after each HTML document has been loaded. |
| Load resources | Allows you to be notified and prevent application scripts or images from being loaded (for security purposes, for example). <br><br>This event accepts parameters: <br><br><pre><code>PROCEDURE LoadResources(sURL is string, nType is int)</code></pre><br> where: <br><br>- &lt;sURL&gt; is a string that corresponds to the URL of the resource to be loaded.<br><br>- &lt;nType&gt; is a constant used to identify the type of resource to be downloaded: <br><br>	- *typehtmlResImage* the resource to download is an image. <br><br>	- *typehtmlResScript* type: the resource to download is a script. <br><br>	- *typehtmlResCss* the resource to download is a CSS style.  <br><br>	- *typehtmlResXMLHttpRequest* The resource to be downloaded is an XML document generated in response to an HTTP request. <br><br>	- *typehtmlOther* the resource to be downloaded is of an unknown type. <br><br><br><br><br><br><br><br>If this event returns <u><u><u><u>False</u></u></u></u>, the resource will not be loaded. |
| Right click on a link | Executed when the user right-clicks a link (to open a context menu). This event has the following format: <br><pre><code>PROCEDURE RightClickLink(sURL is string)</code></pre><br> where &lt;sURL&gt; is a string that contains the URL of the link. |


(\*) By default, the "Initialization" event of each control is executed according to the order in which the controls were created in the window. To change this order: 

1. On the "Window" tab, in the "Order" group, click "Initialization". 

2. In the window that appears, use the arrows on the right to change the order in which the controls are initialized.

## Optional events
<a name="optional_events_ELTTEXTE000269"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Several optional events can be added.
To add an optional event:

1. Select the desired control.

2. Display the code window of this control (F2 key).

3. Click the link "Add other events to xxx" at the bottom of the window code, after the last event.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Traitements_optionnels_WD_OK%20-%20HC%20N%B0001.gif)


4. All the optional events available for the control are displayed. 

5. Check the optional event to add and validate. 
	Note: Several optional events can be selected. 

6. The selected optional event is automatically added to the events managed by the control.




To disable an optional event, simply perform the same operations to display the list of optional events. Then simply uncheck the optional events to delete. 
Note: If the deactivated code contains WLanguage code, this code is automatically deleted..For example, you can use the following events:

- the mouse hover over the control,

- left mouse button down, up, double click,

- right mouse button down, up, double click, 

- mouse wheel, etc.





### Optional Event: Page loading error
<a name="optional_event_page_loading_error_ELTPARAGRAPHE000165"></a>

The "Error loading page" event is executed if an error is detected when loading a page in the control. This event gets the details of the error encountered: 

```wl
PROCEDURE LoadError(sUrl is string, sError is string, nErrorCode is int)
```
 where: 

- &lt;sURL&gt; is a string that corresponds to the URL of the resource to be loaded.

- &lt;sErreur&gt; is a string containing the error message. 

- &lt;nErrorCode&gt; is an integer corresponding to the error code.
