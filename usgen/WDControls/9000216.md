
## Bottom sliding window (Bottom sheet)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000244"></a>
Bottom sliding windows (commonly known as "bottom sheets") are increasingly used in mobile applications.

This type of window has the following characteristics: 

- It appears from the bottom of the screen. 

- It can be modal or modeless. 

- It has 4 display modes: hidden, collapsed, half-expanded and expanded. Depending on the mode used, the sliding window partially or completely covers the host window. 




This type of window is commonly used to open a menu, or to display additional data related to the host window.

<a name="NOTE2_1"></a>


## Characteristics of a bottom sliding window
<a name="characteristics_bottom_sliding_window_ELTTEXTE000268"></a>


### Type of window
<a name="type_window_ELTPARAGRAPHE000024"></a>There are two types of window: 

- Modal bottom sliding window: 
	Modal bottom sliding windows offer users a range of options, but prevent them from interacting with the rest of the screen. They provide an alternative to menus and dialog boxes by offering additional space for content and actions. 
	The host window is grayed out. 
	The bottom sliding window disappears when the users taps anywhere else. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Bottom-Sheet%20modal.png)


- Persistent bottom sliding window: 
	Persistent bottom sliding windows contain interactive elements, but also allow users to view and interact with the host window. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Bottom-Sheet%20standard.png)

	They are commonly used: 

	- to offer a feature or secondary content, 

	- to provide additional information about the content displayed in the host window.

<a name="NOTE3_1"></a>


## The different display modes
<a name="the_different_display_modes_ELTTEXTE000292"></a>
Several display modes are available: 

- Hidden: The bottom sliding window is not shown on screen. 

- Collapsed: Only the content at the top of the sliding window is shown at the bottom of the host window. 

- Half-expanded: Most of the content is shown on screen. Generally, this mode takes up half of the host window. 

- Expanded: The bottom sliding window takes up the entire screen or most of it, hiding the contents of the host window. 




Users can switch from one display mode to another by dragging the bottom sliding window up or down.

## How to implement bottom sliding windows (bottom sheets)?
<a name="how_implement_bottom_sliding_windows_bottom_sheets_ELTTEXTE000316"></a>
Below are the steps to implement bottom sliding windows: 

1. [Creating internal windows](#NOTE2b_2). These internal windows will be the sliding windows. 

2. [Configuring the sliding windows in the description of the main window](#NOTE2b_3). 

3. Defining the display mode of sliding windows: 

	- swipe gesture (default: swipe up from the bottom edge of the screen to open the sliding window). 

	- [programmatically](#NOTE3b_1). 






<a name="NOTE2b_2"></a>


### Creating internal windows
<a name="creating_internal_windows_ELTPARAGRAPHE000103"></a>

The sliding windows are internal windows.  

This internal window has the following characteristics: 

- When used in the bottom sliding window or in the main window, [Close](../WDLang1/3038018.md) will close both windows. 

- The controls of the bottom sliding window can be accessed via the main window, using the [MyBottomSlidingWindow](../Motscles/1511030.md) keyword: 
	
	```wl
	// Changes the color of a text in the bottom sliding window
	MyBottomSlidingWindow.STC_Caption.Color = LightRed
	```


- Sliding window appearance: 
	To apply the color and border defined by the internal window, uncheck "System appearance (corners, shadow, etc.)". 

- To display more or less detailed information in the various display modes of the bottom sliding window, it is recommended to define several layouts in the internal window. Each layout should correspond to a display mode. 



<a name="NOTE2b_3"></a>


### Configuring the bottom sliding window associated with a window
<a name="configuring_the_bottom_sliding_window_associated_with_window_ELTPARAGRAPHE000131"></a>

To define the sliding windows associated with a window: 

1. Go to the "Details" tab of the main window description. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Fen%EAtre_coulissante_basse%20-%20HC%20N%B0001.gif)


2. Select the internal window to be used as a bottom sliding window: 

	- In "Bottom sliding window (Bottom sheet)", specify: 

		- the internal window to be displayed. 
						Expand the list to see the available internal windows of the application 





. 

- the appearance of the internal window. 
	If "System appearance (corners, shadow, etc.)" is checked, the sliding window will match the style defined by the system. If this option is unchecked, you will be able to integrate a custom border directly into the internal window.  

- whether the sliding window is modal or modeless. If the sliding window is modeless, you can allow or prevent users from closing the window. In this case, users will be able to hide the entire window. 

- the different heights of the bottom sliding window: 

	- Expanded height: Maximum height of the bottom sliding window. 

	- Half-expanded height: Height of the half-expanded display mode. 

	- Collapsed height: Minimum height. 







- These different heights can be specified as a percentage of the screen height, or in pixels. You can also choose a preset value. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Fen%EAtre_coulissante_basse%20-%20HC%20N%B0002.gif)
To make a display mode unavailable, set the height to 0 or choose the "Mode disabled" option. The anchors defined in the internal window will be applied. 




1. Confirm.

## Programming bottom sliding windows
<a name="programming_bottom_sliding_windows_ELTTEXTE000352"></a>


### Displaying the bottom sliding window
<a name="displaying_the_bottom_sliding_window_ELTPARAGRAPHE000172"></a>

To be used, bottom sliding windows must first be visible. 

You can set the visibility of bottom sliding windows: 

- using the options defined in the description of the host window. 

- programmatically, with the [WinSlidingVisible](../WDLang1/1000020978.md) function. 




[WinSlidingVisible](../WDLang1/1000020978.md) can also be used to specify the display mode of the bottom sliding window. 


### WLanguage properties for manipulating bottom sliding windows
<a name="wlanguage_properties_for_manipulating_bottom_sliding_windows_ELTPARAGRAPHE000189"></a>

The [MyBottomSlidingWindow](../Motscles/1511030.md) keyword is used to manipulate the bottom sliding window associated with the current window. 

The following properties are used to manipulate bottom sliding windows: 



|   |   |
| --- | --- |
| [HeightCollapsed](../Proprietes/1410089636.md) | The **HeightCollapsed** property gets and sets the "collapsed" height of the bottom sliding window associated with the current window. |
| [HeightExpanded](../Proprietes/1410089638.md) | The **HeightExpanded** property gets and sets the "expanded" height of the bottom sliding window associated with the current window. |
| [HeightHalfExpanded](../Proprietes/1410089637.md) | The **HeightHalfExpanded** property gets and sets the "half-expanded" height of the bottom sliding window associated with the current window. |
| [Hideable](../Proprietes/1410089640.md) | The **Hideable** property determines if the user can close a bottom sliding window with a touch gesture. |
| [InternalWindow](../Proprietes/1410089635.md) | The **InternalWindow** property gets and sets the internal window contained in the bottom sliding window associated with the current window. |
| [Modal](../Proprietes/1410089639.md) | The **Modal** property determines whether the bottom sliding window associated with the current current window is modal or modeless. |
| [OnHide](../Proprietes/1410091043.md) | The **OnHide** property allows you to define a procedure to be called when the bottom sliding window associated with the current window is hidden.<br><br>**This property is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [OpeningParameters](../Proprietes/1410091044.md) | The **OpeningParameters** property is used to get and set the parameters passed to a window.<br><br>**This property is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [RoundedCorner](../Proprietes/1410089641.md) | The **RoundedCorner** property allows you to determine whether the bottom sliding window associated with the current window has rounded corners. |
