


## Table field linked to a table (Table file)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000341"></a>
A data-bound Table control linked to a table is a field whose columns are linked to fields in a table or query. The table and the query are considered to be the data source. 

Each Table control column can be:

- Bound to an item of the data source.

- Linked to a field in a table linked to the data source.

- Calculated: If the column is not linked to a field in a table, it is a **calculated column.**. For calculated columns, the content of the column is recalculated each time a row is displayed.




Each row in the Table control corresponds to a record of the data source.

**A Table control linked to a table allows you to**:

- View the content of a table (or query) with one record per row and select a record (view the entire table or a selection of records selected according to a filter).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) View the content of bound records (for example, view the order lines associated with an order displayed in the Table control). 

- Delete a record by deleting a row from the Table control.

- Modify a record by modifying the content of a row found in the Table control.

- Add a record by entering a row in the Table control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Automatically refresh the data modified from another computer.  




The number of records that can be viewed is unlimited, but only the visible rows in the Table control are loaded in memory.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Note**: When a non-Ajax data-bound Table control is created, a ***reglette*** is automatically associated with it. This pager is used to display the records from the Table control.




### Notes
<a name="notes_ELTPARAGRAPHE000056"></a>

- Table control fields linked to a table are mainly used to visualize data. To enter data, use the Edit controls.

- The row selected in the Table control corresponds to the current record in the table. If the position is set to a different row in the data-bound Table control, the position in the table also changes to the corresponding record.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Limitations for Android
<a name="limitations_for_android_ELTPARAGRAPHE000064"></a>

- Input is not available in table fields linked to a table. The functions [TableAdd](../WDLang1/3074017.md), [TableAddLine](../WDLang1/3074006.md), [TableInsert](../WDLang1/3074025.md), [TableInsertLine](../WDLang1/3074026.md), [TableModify](../WDLang1/3074019.md) and [TableModifyLine](../WDLang1/3074028.md) are not available for this field type. 

- Only automation is available in table control fields linked to a table. Iterations set programmatically are not available. 

- Table controls linked to a "memory-loaded" table are not restricted.



![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Limitations for iOS
<a name="limitations_for_ios_ELTPARAGRAPHE000091"></a>

Table controls are available for viewing only: Input is not available in this version.

### The different types of Table fields
<a name="the_different_types_table_fields_ELTPARAGRAPHE000102"></a>

Two types of table fields linked to a table are available:

- The Table control fields can be found at **direct access to a table.**. 
	The Table control displays the entire table. This type of field can be used to load very large tables. Low memory occupancy. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Table fields linked to a table with direct access offer sorting and magnifying on all columns (if the number of records is less than 100,000 and the field doesn't use a bounce scrollbar).



- The Table control fields are based on **a table loaded in memory.**. Only a specific number of table records (defined in the editor) are loaded into memory. These Table controls can be used to sort and search on any column.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) You cannot define the number of records loaded in memory.




For more details on these two types of Table control, see [Comparison between the features of Table controls](../WDChamp/1013290.md).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Java limitation: Cascading input
<a name="java_limitation_cascading_input_ELTPARAGRAPHE000135"></a>

In Java, cascading input is not available for Table controls based on a direct-access table. Cascading input is only available for Table controls based on a table loaded in memory.

## Automatic synchronization (HFSQL Client/Server data)
<a name="automatic_synchronization_hfsql_clientserver_data_ELTTEXTE000413"></a>
A data-bound Table control linked to a table can refresh automatically as soon as the associated HFSQL Client/Server table is modified. This feature can be defined: 

- in the editor: 

	1. Open the Table control description window. 

	2. On the "Content" tab, select the display synchronization mode: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Table_Fichier_Synchro%20-%20HC%20N%B0001.gif)


		- Never: No synchronization is performed (default case). 

- Modification only: Synchronization takes place only when a record is modified. 

- Add/Delete only: Synchronization takes place only when a record is added or deleted.

- Always: Synchronization is performed as soon as a write or delete operation is performed in the table.

3. Validate. 

- programmatically: by using the [SynchroHFSQL](../Proprietes/1000023408.md) property on the Table control field. 




The automatic synchronization is performed:

- between the different instances of the same application on a post or different posts,

- between different applications on one or multiple computers,

- between the different windows of the same application, whether or not the HFSQL context is the same between the windows.




Caution: Enabling this feature increases server load when displaying the Table control or when moving within the control.

## Automatic view of bound records
<a name="automatic_view_bound_records_ELTTEXTE000437"></a>
In a Table control linked to a table, it is possible to scroll down a line to view the records of other tables linked to the selected line. 

Example: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_auto%20-%20HC%20N%B0004.gif&type=thumb)



### Implementation via the window editor (automatic mode)
<a name="implementation_via_the_window_editor_automatic_mode_ELTPARAGRAPHE000186"></a>

To allow the user to scroll down the rows of a Table control to view related records: 

1. Open the Table control description window. 

2. On the "Content" tab, check "Show row details with [ + ]". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_auto%20-%20HC%20N%B0001.gif&type=thumb)
The settings window appears automatically. 

3. In the settings window: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_auto%20-%20HC%20N%B0002.gif)


	- If necessary, check "Display bound data". 

- Select the "Automatic" display mode. In this mode, all related tables are shown to the user. 

- Validate. 

4. Validate the Table control description window. 




When the data-bound Table control is run, a context menu is available to display the various data related to the table currently displayed in the data-bound Table control. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_auto%20-%20HC%20N%B0003.gif)<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_auto%20-%20HC%20N%B0004.gif&type=thumb)


Note: the image of the "+" displayed at the beginning of the line can be customized: 

1. Open the Table control description window. 

2. In the "Style" tab: 

	- Select "[+]/[-] image IW for row details". 

	- Click the "Plus/Minus image of the details internal window" button. 

	- Select the image corresponding to the button and validate.








### Implementation via the window editor (custom mode)
<a name="implementation_via_the_window_editor_custom_mode_ELTPARAGRAPHE000234"></a>

To allow the user to expand rows in a data-bound Table control to see the bound records: 

1. Open the Table control description window. 

2. On the "Content" tab, check "Show row details with [ + ]". The settings window appears automatically. 

3. In the settings window: 

	- If necessary, check "Display bound data". 

	- Select the "Manual" display mode. In this mode, only the data from one table is shown to the user. You can customize the data to be displayed. 

	- Select the source item in the table displayed by the data-bound Table control. 

	- Select the bound item in the linked table. 

	- Select the items that will be displayed in the table of bound data. You can use the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=IconeAjouterPropriete.gif) and ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=IconeSupprimerPropriete.gif) buttons to choose the information to be displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_manuel%20-%20HC%20N%B0001.gif&type=thumb)


	- Validate. 

4. Validate the Table control description window. 




At runtime, a "+" sign allows the user to see the table related to the table currently displayed in the data-bound Table control. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visu_enreg_li%E9_manuel%20-%20HC%20N%B0003.gif)


Note: the image of the "+" displayed at the beginning of the line can be customized: 

1. Open the Table control description window. 

2. In the "Style" tab: 

	- Select "[+]/[-] image IW for row details". 

	- Click the "Plus/Minus image of the details internal window" button. 

	- Select the image corresponding to the button and validate.








### Implementation programmatically
<a name="implementation_programmatically_ELTPARAGRAPHE000286"></a>

To allow the user to scroll down the rows of a Table control to view related records: 

1. Create a data-bound Table control based on a table or query. 

2. In the Table control initialization code, use the [RowDetailsBinding](../Proprietes/1000023414.md) property.
