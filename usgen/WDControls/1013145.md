## Edit control overview
<a name="edit_control_overview_ELTTEXTE000535"></a>
The Edit control allows users to enter data. This control can also be used to view information.






### Create an "Edit" control
<a name="create_edit_control_ELTPARAGRAPHE000030"></a>

To create an "Edit" control: 

1. On the "Creation" tab, in the "Usual controls" group, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_saisie.gif).

2. Click where you want to create the control in the window or page. The control appears in the editor.




**Note**: You can also expand "Edit" to choose an Edit control from a list of preset controls. The list of available controls is displayed with the project theme. Simply click the control you want to create in the editor.

**To view the control characteristics**, select "Description" in the context menu.

**Report editor**: You can also create an Edit control in a report. For more details, see [Input in reports](../WDChamp/1011074.md).

### Type of an Edit control
<a name="type_edit_control_ELTPARAGRAPHE000061"></a>

The format of an Edit control depends on the type of information displayed or entered. The following types of edit controls can be created:

- [Text](../WDChamp/9500149.md) to display or enter a string (name, address, etc.).

- [Multiline text](../WDChamp/9500149.md) to display or enter several lines separated by a "Carriage Return".

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) [RTF text](../WDChamp/9500149.md) to enter and display information in RTF. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [HTML text](../WDChamp/9500149.md) to enter and format rich text.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Markdown read-only](../WDChamp/9500149.md) to display Markdown text.

- [Password](../WDChamp/9500149.md): when typing information, all characters will be replaced with asterisks on the screen.

- [Numeric](../WDChamp/9500149.md) to display or enter a numeric value (weight, etc.). The "+++" characters are displayed if the control is not large enough to display the entire number.

- [Currency](../WDChamp/9500149.md) to display or enter monetary values.

- [Currency + Euro](../WDChamp/9500149.md) to manage prices for example

- [Date](../WDChamp/9500149.md) to display or enter dates.

- [Time](../WDChamp/9500149.md) to enter or display times.

- [Duration](../WDChamp/9500149.md) to enter or display durations.

- [Text tokens](../WDChamp/9500150.md) to manage an input with tokens. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [Upload](../WDChamp/9500149.md) to manage file uploads. 

	<B><B><B><B>Warning</B></B></B></B>

	 This type of Edit control is kept for compatibility. It is recommended to use [the Upload control](../WDChamp/1016330.md). 






![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For Text Edit controls, you can check **File path autocomplete**. This option shows the different directories and files accessible as the user types a file name with its path. This option is not available if the control already uses standard input suggestions.

### Types and masks
<a name="types_and_masks_ELTPARAGRAPHE000148"></a>

- **Input masks**: A large number of [input masks](../WDChamp/1014003.md) is available for each type of Edit control. 
	**Input masks support multiple languages**. You can set different input masks according to the project language. For more details, see [Multiple languages in the controls](../WDChamp/1013031.md). 
	These input masks can be modified programmatically with the [InputMask](../Proprietes/2510033.md) property. 
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The keyboard displayed when entering data in the control automatically adapts to the selected input mask. For example, the numeric keyboard will be automatically displayed to enter values in a control using a numeric input mask. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **Display masks**: You can also define display masks for certain types of controls (Currency, Currency + Euro, Date, Time and Duration). These display masks are used to define the characteristics of the control when it is not in edit. 
	For example, a Date control can have: 

	- the "DD/MM/YYYY" input mask. 

	- the "DDDD DD MMMM YYYY"  display mask. This represents a date in words. 
			Display masks can be multilingual and can be modified programmatically with the [DisplayMask](../Proprietes/1000020008.md) property. 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Autofill**: This option allows you to set up autofill functionalities via services such as Dashlane, Google, etc.. For more details, see [Autofill in Edit controls](../WDChamp/1010046.md).

### Specific HTML 5 features
<a name="specific_html_5_features_ELTPARAGRAPHE000201"></a>

Some characteristics of Edit controls use HTML 5 features: 

- **Input masks**. By choosing an HTML 5 input mask, the site lets the browser handle and check the input. It is not the page (the site) that performs the checks, but the browser itself. In any case, you can run WLanguage code when exiting a control, which allows for additional checks on the data entered. These features are only available from certain browser versions: Firefox 5, Chrome 12, Opera 11, Safari 5, etc.
	For more details, see the help about the input masks of [text](../WDChamp/1014014.md), [numeric](../WDChamp/1014015.md), [date](../WDChamp/1014016.md) and [time](../WDChamp/1014017.md) controls. 

- **HTML 5 search control**: If this option is selected for a text control, the browser will display an "X" on the right of the control. This X allows the user to clear the control content. 
	This option is available in the "General" tab of the control description window. 
	Note: This option is only available on browsers that support HTML 5, such as Chrome 12 and Safari 5. 

- **Autocomplete**: This option (located in the "Details" tab of the Edit control description window) enables or disables the autocomplete feature on Edit controls. Automatic completion is enabled by default. When the user starts typing information in a form, all the page controls are immediately and automatically filled with the data previously typed on this computer. 
	Autocomplete is a dangerous feature. It must be disabled when processing confidential data.
	Most browsers that support HTML 5 (Firefox, Chrome, Safari, Opera, etc.) support this feature as well.

### Validation of Edit controls via the Enter key
<a name="validation_edit_controls_via_the_enter_key_ELTPARAGRAPHE000268"></a>

For each Edit control in a page, you can specify the action that will be run when the user presses the Enter key.

This allows, for example, to improve the default events in a page. For instance, there can be several search controls can in the same page, and each control can be validated by pressing the Enter key. The action performed will be the one associated with the Edit control that has focus.

To define the action associated with an Edit control: 

1. Create a button in your page containing the desired code.

2. Open the Edit control description. On the "UI" tab, select the desired button in the " Action on 'Enter'      " option.





![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png)

## Main features of the "Details" tab
<a name="main_features_the_details_tab_ELTTEXTE000643"></a>
An Edit control can:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) be used to perform a drag-and-drop operation. For more details, see [Drag and Drop](../WDLang1/3030007.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) support **input suggestions**: When the user enters a value in a control, the application automatically suggests the corresponding value from the HFSQL key item bound to the control. 
	For example, after the user types "Lo" in a "City" field, the application will automatically suggest "London". 
	This feature can only be used with key items and Text items. 
	Input suggestions cannot be used with non-key items, numeric items, or if an input mask is used for dates. For more details, see [Input suggestions in an Edit control](../WDLang1/1000021089.md)




An Edit control can also include:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) a **spelling checker** that uses:

	- the [OpenOffice dictionary](../Editeurs/1013146.md) installed on the computer, or a spelling and grammar checker that uses the Word dictionary.

	- an integrated spelling checker (based on Hunspell dictionaries). 




- The type of spelling checker can be selected in the [project description window ("Options" tab)](../Editeurs/9500227.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) an **input history**: When a users starts typing in the control, the list of values previously entered will appear automatically. This input history is not available for multiline controls. For more details, see [Saving entered data (AAF)](../WDChamp/9500128.md). 



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Customizing the alphanumeric keypad
<a name="customizing_the_alphanumeric_keypad_ELTPARAGRAPHE000357"></a>

In Android and iOS applications, an on-screen keyboard appears automatically when a text input control receives the focus. This keyboard allows the user to enter the desired text. 

This keyboard includes a button (bottom right) that can be customized: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=IOS_Clavier.gif)


To configure this button: 

1. Go to the "Details" tab of the Edit control description window. 

2. In the "Keyboard button" option, select the desired type of button. Depending on the selected type, the system will display the corresponding button in the current language on the device. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=WM_Clavier_alpha%20-%20HC%20N%B0001.gif)

	Note: The "Custom" button can only be added in Android. 

3. Validate. 




The event associated with this button can be entered in the code editor. It corresponds to the optional event "Validation via keyboard". For more details, see [Edit control events](../WDChamp/1013229.md).

### Displaying a hint text in an Edit control
<a name="displaying_hint_text_edit_control_ELTPARAGRAPHE000391"></a>

The hint text is used to display a help text in the empty edit control. This help text disappears automatically as soon as the user enters the first character in the control.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Indication.gif)


This hint text is available for:

- Text Edit controls. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Numeric, Currency and Currency + Euro Edit controls. 
	To show the hint text in Numeric, Currency or Currency + Euro edit controls, the option "Blank if zero" must be checked ("Details" tab of the control description).
	You can also display the lower bound and the upper bound of the numeric edit control:

	- in the hint text ("Display the bounds in the hint text" in the "Details" tab of the control description).

	- in the control tooltip ("Display the bounds in the tooltip" in the "Details" tab of the control description). 







The help text can be typed:

- in the Edit control description window ("Help" tab in WINDEV/WINDEV Mobile and "Content" tab in WEBDEV).

- programmatically with the [Hint](../Proprietes/1000017043.md) property.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The style of the hint text displayed in the control can be configured in the "Style" tab. By default, it corresponds to the style of the input area, in gray and italic. To modify it, simply select "Hint text" and check "Customize the style of the hint text".

The [HintTextColor](../Proprietes/1000022643.md) property gets and sets the color of the hint text programmatically. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The hint text uses the same style as the input area, in italic and gray.

## Converting an Edit control to a Static Text control
<a name="converting_edit_control_static_text_control_ELTTEXTE000721"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) WINDEV and WINDEV Mobile allow you to automatically covert an Edit control to a Static Text control: 

1. Select the Edit control to be converted. 

2. On the "Modification" tab, in the "Transformations" group, expand "Refactoring and swapping" and select "Edit control to Static Text".




A Static Text control is automatically created for the caption of the Edit control and also for the input area.
