
## Manipulating Code Editor controls programmatically

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000136"></a>
WINDEV and WEBDEV offer various [Code Editor control functions](../WDLang1/1410090410.md) to manipulate Code Editor controls programmatically. 

This help page explains how to manipulate a Code Editor control programmatically. 





## Manipulating Code Editor controls programmatically
<a name="manipulating_code_editor_controls_programmatically_ELTTEXTE000160"></a>
To manipulate a Code Editor control programmatically, simply use the variable that represents the control directly in the code.

The variable that represents the Code Editor control is the name of the control. 


### Initializing the Code Editor control
<a name="initializing_the_code_editor_control_ELTPARAGRAPHE000025"></a>

To assign WLanguage code to the Code Editor control programmatically, you can: 

- directly assign a multiline string. For example: 
	
	```wl
	CODEEDT_Example = [
	Res is string
	StringToConvert is string = "Crème brûlée"
	Res = AnsiToOem(StringToConvert)
	Info(Res)
	]
	```


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) use the [CodeEditorLoad](../WDLang1/1410090372.md) function. This function loads WLanguage code from a file. 



![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Allowing and disallowing functions in the Code editor control
<a name="allowing_and_disallowing_functions_the_code_editor_control_ELTPARAGRAPHE000042"></a>

The [Compiler](../Proprietes/1410090383.md) property gets and sets the compiler options in the Code Editor control, in particular, which functions are allowed or disallowed.

In the following example, all WLanguage functions are allowed, except **fDelete**: 

```wl
CODEEDT_Example.Compiler.AllowedFunctions = AllFunctions
CODEEDT_Example.Compiler.ForbiddenFunctions = "fDelete"
```



### Making a selection in the Code editor control
<a name="making_selection_the_code_editor_control_ELTPARAGRAPHE000053"></a>

The [Cursor](../Proprietes/2510025.md) and [CursorEnd](../Proprietes/2510047.md) properties can be used to make a simple selection in the Code Editor control. 
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Undo / Redo support
<a name="undo_redo_support_ELTPARAGRAPHE000066"></a>

You can implement the Undo/Redo functionality in the Code Editor control using [AAFExecute](../WDLang1/1000022099.md) with the *aafUndo* and *aafRedo* constants. 

Example: 


```wl
AAFExecute(CODEEDT_MyCode, aafUndo)
AAFExecute(CODEEDT_MyCode, aafRedo)
```






## Properties specific to Code Editor controls
<a name="properties_specific_code_editor_controls_ELTTEXTE000210"></a>
The following properties are used to manipulate Code Editor controls programmatically.




|   |   |
| --- | --- |
| [Compiler](../Proprietes/1410090383.md) | The **Compiler** property gets and sets the compiler options in the Code Editor control, in particular, which functions are allowed or disallowed. |
| [LineCursor](../Proprietes/1410090384.md) | The **LineCursor** property gets and sets the number of the line where the cursor is located in a Code Editor control. |





For a complete list of WLanguage properties that can be used with Code Editor controls, see [Code Editor control properties](../WDChamp/1410087304.md).
