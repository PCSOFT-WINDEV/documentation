


## Characteristics of non-maximized windows
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000092"></a>
A non-maximized window can be resized by the user and it can occupy a section of the screen only. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Several options can be configured in the wizard for window creation. 

To start the wizard for window creation: 

- Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

- When the new element window appears, click "Window" then "Window".

- The window creation wizard starts. 

- Select "Wizard" in the wizard.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) You also have the ability to define non-maximized windows in the "Style" tab of the description window of the window ("Non-maximized window" option). 

The different options of non-maximized windows are as follows: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) [Options available in Android](../WDChamp/9000121.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Options available in iOS](../WDChamp/9000148.md).
