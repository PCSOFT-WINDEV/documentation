<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000070"></a>
A maximized window occupies the entire screen of the mobile device. Several options can be configured in the wizard for window creation.  

Reminder: To launch the window creation wizard: 

- Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

- When the new element window appears, click "Window" then "Window".

- Select "Wizard" and validate.
