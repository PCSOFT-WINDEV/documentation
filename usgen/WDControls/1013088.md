


## Programming the looper attributes
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000086"></a>
All the Looper controls attributes can be handled through programming.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, only the following types of attributes can be handled: 



|   |   |
| --- | --- |
| Attribute on a check box | You only have the ability to handle an attribute on the value of the check box (reading and modification). |
| Attribute on a link | No operation can be performed by programming. |
| Attribute on a radio button | You only have the ability to handle an attribute on the value of the radio button (reading and modification). |
| Attribute on a static | No operation can be performed by programming. |
| Attribute on an image or on a clickable image | You only have the ability to handle an attribute on the value of the image associated with the control (reading and modification). |
