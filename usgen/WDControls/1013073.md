## Implementation
<a name="implementation_ELTTEXTE000129"></a>


### Creating an on/off button
<a name="creating_onoff_button_ELTPARAGRAPHE000035"></a>

To create an on/off button:

1. Create a button.

2. Go to the "UI" tab of the button description window and select "On/Off button".

3. Validate the description window.



<a name="NOTE2_2"></a>


### Programming
<a name="programming_ELTPARAGRAPHE000050"></a>

Programming an on/off button is identical to programming other types of buttons (see [Manipulating a button by programming](../WDChamp/1013094.md)). The only difference is that push-button status is managed by the [Pushed](../Proprietes/2510038.md) property.
