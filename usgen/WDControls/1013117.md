
## Manipulating Scrollbar controls programmatically
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000140"></a>
WINDEV allows you to programmatically manipulate Scrollbar controls. To do so, use the variable of the scrollbar control in the code.

The variable of the Scrollbar control:

- corresponds to the name of the scrollbar.

- is initialized with the position of scrollbar box.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Retrieving the cursor position
<a name="retrieving_the_cursor_position_ELTTEXTE000164"></a>
To retrieve the position of the cursor in a Scrollbar control, use the following syntax:


```txt
<Position> = <Nom Ascenseur>
```


&lt;Position&gt; is an integer variable

**Note**: It's also possible to use the [Value](../Proprietes/2510130.md) property.

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Modifying the cursor position
<a name="modifying_the_cursor_position_ELTTEXTE000188"></a>
To modify the position of the cursor in a Scrollbar control, use the following syntax:


```txt
<Nom Ascenseur> = <valeur>
```


&lt;Value&gt; is a value found between the minimum and maximum value of the scrollbar. These values have been defined in the control description window or in the code with the [MinValue](../Proprietes/2510008.md) and [MaxValue](../Proprietes/2510009.md) properties.

**Note**: It's also possible to use the [Value](../Proprietes/2510130.md) property.

## Properties specific to Scrollbar controls
<a name="properties_specific_scrollbar_controls_ELTTEXTE000212"></a>
The following properties are specific to programmable Scrollbar control.


|   |   |
| --- | --- |
| [Advance](../Proprietes/1000021574.md) | Used to find out and modify the scroll value of a Scrollbar control. |
| [ScrollValue](../Proprietes/2510011.md) | Used to find out and modify the scroll value of a Scrollbar control. |
| [MaxValue](../Proprietes/2510009.md) | Used to find out and modify the maximum bound of a Scrollbar control. |
| [MinValue](../Proprietes/2510008.md) | Used to find out and modify the minimum bound of a Scrollbar control. |


For a complete list of WLanguage properties that can be used with Scrollbar controls, see [Scrollbar control properties](../WDChamp/1013112.md).
