
## Binding a List Box control to an item
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Item characteristics
<a name="item_characteristics_ELTTEXTE000094"></a>
A List Box control can be bound to an item in a table, query, etc.

The following types of items can be bound to a List Box control:

- Text, 

- Numeric, 

- Date or Time, 

- Radio Button, List Box, Combo Box.




**The item bound to the List Box control will contain the index of the element selected in the List Box control.**

**Note** When a field is associated with a List Box control, the contents of the list are the same for all records in the table. 

The contents of the List Box control can be: 

- entered directly in the data model editor,

- entered in the window or page editor,

- assigned in the code (with [ListAdd](../WDLang1/3049004.md)).

## Handling the item and the List Box control
<a name="handling_the_item_and_the_list_box_control_ELTTEXTE000118"></a>


### To update the List Box control with the value stored in the item:
<a name="update_the_list_box_control_with_the_value_stored_the_item_ELTPARAGRAPHE000038"></a>

**1st case: window or page fields are bound to fields in a table** (Binding)
All the controls bound to an item in the table (or a related file) will be updated by:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) [FileToScreen](../WDLang4/3044210.md) in WINDEV or WINDEV Mobile.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [FileToPage](../WDLang4/3044148.md) in WEBDEV. 




**Case 2: window or page fields are not associated with fields in a table**
A value must be assigned to each control using the following syntax:


```txt
<Control name> = <Data file>.<Item>
```

<a name="NOTE3_2"></a>


### To update an item with the index of the element selected in the List Box control:
<a name="update_item_with_the_index_the_element_selected_the_list_box_control_ELTPARAGRAPHE000045"></a>

**1st case: window or page fields are bound to fields in a table** (Binding)
All the items in the table (or a related table) that are bound to a control in the window or page will be updated by:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) [ScreenToFile](../WDLang4/3044146.md) in WINDEV or WINDEV Mobile.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [PageToFile](../WDLang4/3044022.md) in WEBDEV.




**Case 2: window or page fields are not associated with fields in a table**
The value of each control must be assigned to each item using the following syntax:


```txt
<Data file>.<Item> = <Control name>
```
