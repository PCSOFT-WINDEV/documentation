
## Image control: supported formats
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000140"></a>
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) The following image formats are supported in Windows:

- Bitmap (\*.BMP)

- Graphics Interchange Format (\*.gif)

- Joint Picture Experts Group (\*.jpg ; \*.jpeg)

- Kodak Photo CD (\*.pcd)

- PaintBrush (\*.pcx)

- Adobe Photoshop Format (\*.psd)

- TrueVision TARGA (\*.tga)

- Tagged Image File Format (\*.tif ; \*.tiff)
	Note: the "Tiled TIFF" option in TIFF 6.0 is not supported. In this case, we advise you to save the image in tiff 5.0 standard. 

- Portable Network Graphics (\*.png)

- Windows MetaFiles (\*.emf ; \*.wmf)

- Icons (\*.ico ; \*.icw)
	Remarks: 

	- HQ display (High Quality) available.

	- Management of sheets in transparent BMP format (32 bits).




- Cursors (\*.cur)

- Portable Document Format (\*.pdf)

- Scalable Vector Graphics (\*.svg)

- WINDEV images (generated by the image editor, \*.WDPIC).

- Images in WebP format (\*.webp). 




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The following image formats are supported in Linux: 

- Bitmap (\*.BMP)

- Graphics Interchange Format (\*.gif)

- Joint Picture Experts Group (\*.jpg ; \*.jpeg)

- Portable Network Graphics (\*.png)

- Portable Bitmap (\*.pbm)

- Portable Graymap (\*.pgm)

- Portable Pixmap (\*.ppm)

- Tagged Image File Format (\*.tiff)
	Note: the "Tiled TIFF" option in TIFF 6.0 is not supported. In this case, we advise you to save the image in tiff 5.0 standard. 

- X11 Bitmap (\*.xbm)

- X11 Pixmap (\*.xpm)

- Scalable Vector Graphics (\*.svg)
	Note: To handle this format, you need to install a QT library that supports the SVG format.

- WINDEV images (generated by the image editor, \*.WDPIC).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The supported image formats are: 

- Bitmap (\*.BMP)

- Joint Picture Experts Group (\*.jpeg)

- Portable Network Graphics (\*.png)

- Scalable Vector Graphics (\*.svg)
	Warning: CSS styles and elements of type &lt;filter&gt; elements in SVG images are not supported. 

- WINDEV images (generated by the image editor, \*.WDPIC).
	Please note: If a file of type ".WDPIC" is to be programmatically assigned to a field, it must first be added to the list of project elements.




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The supported image formats are: 

- Portable Network Graphics (\*.png)

- Joint Picture Experts Group (\*.jpg ; \*.jpeg)

- Tagged Image File Format (\*.tiff or \*.tif)
	Note: The "tiff mosaic" option in tiff 6.0 is not supported. In this case, we advise you to save the image in tiff 5.0 standard. 

- Graphics Interchange Format (\*.gif)
	**Attention**: Animated GIFs are not supported. 

- Bitmap (\*.BMP)

- X11 Bitmap (\*.xbm)

- Scalable Vector Graphics (\*.svg)

- WINDEV images (generated by the image editor, \*.WDPIC).




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The supported image formats are: 

- Bitmap (\*.BMP)

- Graphics Interchange Format (\*.gif)
	Please note: Animated GIFs are not supported.

- Joint Picture Experts Group (\*.jpeg)

- Portable Network Graphics (\*.png)

- WINDEV images (generated by the image editor, \*.WDPIC).
	Please note: If a file of type ".WDPIC" is to be programmatically assigned to a field, it must first be added to the list of project elements.
