## Overview of Map control
<a name="overview_map_control_ELTTEXTE000389"></a>
The Map control allows you to display a map in order to geolocate, display points of interest (POI) and more, ... 

This map comes from: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the Google Maps service for Android applications. 
	**Attention** The use of a Map control is subject to specific conditions of use. For more details, see [Conditions for using the Map control](../WDChamp/1000019823.md). Check the Google license before deploying your applications. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Apple's geolocation service for iPhone/iPad applications. 
	Please note: It is necessary to comply with the license of the service used. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) the Google Maps service for Web sites via the Google Maps API. 
	The use of the Map control is subject to specific terms and conditions. Depending on the use mode, you may have to use a Google key ([MapLicenseGgl](../WDLang3/1000021299.md)). Check the Google license before deploying your applications. ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: To use the Map control, the user computer must run Windows 10 or later. 




The map displayed is interactive: you can zoom in and out, move around, etc. It can be displayed in map view or satellite view. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ModeCarte.gif)

## Map control creation and description
<a name="map_control_creation_and_description_ELTTEXTE000413"></a>
<a name="NOTE1_2"></a>


### Creating a Map control
<a name="creating_map_control_ELTPARAGRAPHE000075"></a>

To create a Map control: 

1. On the "Creation" tab, in the "Graphic controls" group, click "Map".

2. Click where you want to create the control in the window or page.





### Describing the Map control
<a name="describing_the_map_control_ELTPARAGRAPHE000095"></a>

**To view the control characteristics**, select "Description" in the context menu of the control. 
The "General" tab is used to define: 

- display mode: map or satellite, 

- whether traffic information is shown or hidden.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) whether the zoom buttons must be displayed (or not) in the control,

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) how the compass is displayed.

- the image used for the POI markers. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) These markers can be displayed with or without a shadow. 

- the default popup displayed when a marker is clicked. This popup can correspond to: 

	- None: the default popup will be used. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Predefined window: In this case, an internal window is automatically integrated into your project.. 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Predefined page: In this case, an internal page is automatically integrated into your project.. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) an internal window in your project.

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) an internal page in your project. 







The "Details" tab allows you to define: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) whether zoom by double click is enabled,

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) gesture options:

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Enable zoom.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Enable rotation.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Enable scrolling. 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Enable tilt. 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) double-tap to zoom.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) remember the last position displayed.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The unique customization identifier of the Google map displayed in the. For more details, see [Styling maps from Google Maps](../WDChamp/1000019827.md). 
	




**Remarks**: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) A single Map control can be used in a window. Several Map controls cannot be used in the same window. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The Map control cannot be used in automated tests. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [geoRunApp](../WDLang3/1000019954.md) is used to start the device's native maps application.

### Popup for displaying markers
<a name="popup_for_displaying_markers_ELTPARAGRAPHE000191"></a>

Depending on the platform, when a preset window or page is used to manage marker popups, the following elements are included: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) FI_WinDevPopupMarqueur_WD (internal window in the WDFAA component).

- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) FI_WinDevPopupMarqueur_WM (internal window in the WDFAA component).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the IPAGE_WEBDEVPopupMarker internal page.




These elements contain: 

- two controls used to display the name and description of the marker. 

- a declaration code to handle the current Marker variable.

## Displaying and handling maps
<a name="displaying_and_handling_maps_ELTTEXTE000458"></a>


### Displaying the maps
<a name="displaying_the_maps_ELTPARAGRAPHE000215"></a>

When a window containing a Map control is opened, a world map is automatically displayed: the map is centered on Europe, with a medium zoom level.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The last memorized position can be displayed by selecting "Remember last position displayed" in the "Detail" tab of the Map control description window. In this case, the last location is displayed with the same zoom level.


### Maps handled by the user
<a name="maps_handled_the_user_ELTPARAGRAPHE000228"></a>

The user can move on the map: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) by scrolling the map with one or more fingers. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) by scrolling the map using the mouse.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) via the control positioning buttons (if "Show zoom buttons" has been selected in the "General" tab of the control description window). 




The user can zoom in or out: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) by using the zoom buttons of the control (if the option has been selected in the "General" tab of the control description window). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) using a "scale" (or "pinch") gesture: two fingers spread apart on the screen to zoom in, and two fingers brought together on the screen to zoom out. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) by double-tapping the map to zoom in one level on a position (if this option has been checked in the "General" tab of the control description window). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) by double-clicking the map to zoom one level on a position (if this option has been checked in the "General" tab of the control description window). 

- programmatically with the [Zoom](../Proprietes/1000017201.md) property. 


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If "Enable zoom" is disabled (in the "Details" tab of the control description or [WithZoom](../Proprietes/1000020554.md) property), the user will not be able to zoom in or out.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Note: Optional events specific to the Map control can also be used. For more details, see [Map control events](../WDChamp/1000019819.md).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) For more details on the options available at runtime, see [Map control: Application automation features (AAF)](../WDChamp/1000019824.md).
