### Events supported by WINDEV and WINDEV Mobile
<a name="events_supported_windev_and_windev_mobile_ELTPARAGRAPHE000011"></a>

By default, WINDEV and WINDEV Mobile manage the following events (order of appearance in the code editor) on break headers in Table or Looper controls:

| Event | Runtime condition |
| --- | --- |
| Initialization | Executed when the window is opened. |
| Display a row | Executed when the break header is displayed. |
| Collapse, expand break | Executed when the break is collapsed or expanded. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) These events are not available.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Events supported in WEBDEV
<a name="events_supported_webdev_ELTPARAGRAPHE000039"></a>

By default, WEBDEV manages the following events (order of appearance in the code editor) on break headers in Table or Looper controls:

| Event | Runtime condition |
| --- | --- |
| Initialization | Executed when the page is opened. |
| Display a row | Executed when the break header is displayed. |
