## Overview of Action Bar
<a name="overview_action_bar_ELTTEXTE000239"></a>
Action Bars replace the title bar of a window and display different types of information:

- the application icon,

- the window title,

- some menu options,

- the drop-down menu of your window.

## Creating and configuring an Action Bar
<a name="creating_and_configuring_action_bar_ELTTEXTE000263"></a>
By default, windows are created with an Action Bar.

You can configure the bars used in the window: 

1. Open the window description ("Description" option in the context menu). 

2. On the "Style" tab, specify the content of the top bar: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_Action_bar%20-%20HC%20N%B0001.gif)


	- Full screen: no strikethrough, 

- System bar only: Only the system bar is displayed. 

- System Bar + Action Bar: System Bar and Action Bar are displayed. 

- Action Bar only: Only the Action Bar is displayed. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Sheet mode (iOS13 and +): if this type of bar is selected, the window can open from the bottom of the screen. The window remains "cascaded": it does not completely cover the window below. It can be closed simply by swiping it down. 
			If this option is selected: 

	- the window has no bars in the editor. 

	- the "Allow closing" event is automatically associated with the window. If this event returns: 

		- <u><u><u><u>True</u></u></u></u>, the window is closed. 

		- <u><u><u><u>False</u></u></u></u>, the window is reactivated.




Depending on the type of bar selected, the "Edit bar style" button allows you to set the style options used (color and font). 

Remarks: 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If you use the system bar, you can configure the system bar transparency on iOS 7 and later.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) For iPhone X, you can shift the bars according to the sensor area.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Up to version 25**Action Bar control fields are 48 px high by default. 
	**Starting with new projects created in version 26**Action Bar control height is set to 56 px by default. The default height can be selected in the project configuration description window: option "Action bar height" in the "General" tab. 
	Remarks: 

	- If the height is modified, the new height applies to all windows in the project.




- For more details on project configurations, see [Project configuration](../Editeurs/9000030.md). 





### Bar style
<a name="bar_style_ELTPARAGRAPHE000118"></a>

The "Edit bar style" button allows you to define the style options of the selected bars: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_Action_bar%20-%20HC%20N%B0002.gif)


- System bar.

- Action Bar.

- Navigation Bar. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **If you use the system bar**, you can configure: 

- background color: this color can be: 

	- a specific color, a system color or transparent. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_Action_bar%20-%20HC%20N%B0003.gif)
If the color is "Transparent", the color of the system bar is that of the Action Bar. This option is taken into account only if the window contains an Action Bar. 

	- adapted to the Action Bar. In this case, if the "Material design" theme is used, the system bar uses the same color as the Action Bar, with a darker tone. Otherwise, the color of the Action Bar is used. 




- the text color. 

- whether the bar should be in overlay mode. If the "Bar overlay" option is checked, the origin of the controls is modified and the [Opacity](../Proprietes/2514006.md) property can be used on the Action Bar control. The bar will be displayed over the controls. 




**If you use the Action Bar**, you can configure: 

- background color: this can be a specific or automatic color. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the Action Bar shadow. 

- the font color. 

- whether the font color should be applied to the active icons. 

- the background image of the Action Bar. 

- if the bar should be displayed over the controls. If the "Bar overlay" option is checked, the origin of the controls is modified and the [Opacity](../Proprietes/2514006.md) property can be used on the Action Bar control. The bar will be displayed over the controls. 




**If you use the navigation bar**, you can configure the colors used for active and inactive elements. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Remarks: 

- This system bar color configuration is only available in Android 5.0 and later. 

- The bar color cannot be changed on Nexus devices.

- Use the [SystemBarColor](../Proprietes/1000022485.md) property to programmatically change this color.
