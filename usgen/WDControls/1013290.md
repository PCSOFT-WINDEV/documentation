
## The different types of Table fields: programmatically populated, file with or without direct access
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000327"></a>
WINDEV, WEBDEV and WINDEV Mobile allow you to use:

- Table controls populated programmatically. 

- Table controls linked to a table with direct access to the data source. 

- Table fields linked to a table loaded in memory. In this case, only a limited number of records is loaded in memory. If the table contains more records than the number defined in the Table field description, a warning message appears: "There are more than XXX records. Only the first XXX rows will be displayed".




The table below presents the different features available (or not) for the different types of Table controls.

Note: The concept of a field based on a "table loaded in memory" is also applicable:

- List Box controls, 

- ListView controls, 

- Combo Box controls.

Table control with direct access to the data source and Table control with direct access to the data source are very similar. The main differences between these two types of controls are shown in bold.

Table fields on tables "with in-memory access" offer many advantages, including the ability to sort and search on any column in the field. They are also used to store the value of calculated columns for all the rows.
