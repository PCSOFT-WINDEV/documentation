
## Animating a Static Text control
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Principle
<a name="principle_ELTTEXTE000183"></a>
Two methods can be used to animate a Static Text control in WINDEV and WINDEV Mobile:

- scrolling text: The text scrolls within the control in a given direction. 

- blinking text: The text alternates between two colors.






<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Animating a Static Text control
<a name="animating_static_text_control_ELTTEXTE000207"></a>


### How to?
<a name="how_ELTPARAGRAPHE000032"></a>

To animate a Static Text control: 

1. Open the text description window (select "Description" in the context menu).

2. In the "Details" tab, go to "Animation" and set the animation options. Choose the type of animation and configure the associated options. The options depend on the selected animation mode.




For **scrolling** text, you can define the following options:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Libell%E9_Animation%20-%20HC%20N%B0002.gif)


- Refresh rate.

- Number of pixels the text moves each time it is refreshed.

- The scroll direction. Text can scroll: 

	- from left to right, 

	- from right to left, 

	- from bottom to top, 

	- from top to bottom.  




- If the animation must repeat, and if so, the number of loops.
	




For **blink** text, you can define the following options:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Libell%E9_Animation%20-%20HC%20N%B0001.gif)


- Blink rate.

- Text blinking color. Two colors are required to achieve the text blinking effect:

	- standard text color.

	- text blinking color. If this color is transparent, the text will appear every other time.






<a name="NOTE2_2"></a>


### Remarks
<a name="remarks_ELTPARAGRAPHE000070"></a>

- RTF and text with a "Blurred shadow" cannot be animated.

- The animation of a Static Text control is only visible at runtime.

- Animated text is limited to 1024 bytes.

- The animation does not work anymore if functions for text formatting are used ([gFontBold](../WDLang1/3029061.md), [gFontSize](../WDLang1/3029064.md), [gFontItalic](../WDLang1/3029062.md), [gFontUnderlined](../WDLang1/3029063.md)).

- You can also make long text scroll automatically in a Static Text control. This option is particularly useful for Static Text controls displaying dynamic data. For more details, see [Auto-scrolling text](../WDChamp/9000226.md).

## Programming
<a name="programming_ELTTEXTE000237"></a>
Several WLanguage functions are used to manage the animated static controls. These functions are as follows:


|   |   |
| --- | --- |
| [AnimationGetParameter](../WDLang1/3017003.md) | Reads the value of an animation parameter defined for an image in a Static Text control. |
| [AnimationSetMode](../WDLang1/3017001.md) | Changes the type of animation used in a Static Text control. |
| [AnimationSetParameter](../WDLang1/3017002.md) | Changes one of the animation parameters defined for a text in a Static Text control. |


<a name="NOTE3_2"></a>
Several WLanguage properties are used to manage the animated static controls. These properties are as follows:


|   |   |
| --- | --- |
| [Animation](../Proprietes/2510006.md) | Used to find out the current status of the animation in a Static Text control and to start/stop an animation in an animated Static Text control. |
| [InitialAnimation](../Proprietes/2510012.md) | Used to find out the initial status of the animation in a Static Text control. |
