


## Nested Proportional Area chart
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000130"></a>
Nested Proportional Area charts allow you to compare proportions (sizes, quantities, etc.) and get a quick overview of the relative size of data without using a scale.

This chart has the following characteristics:

- only one series is displayed. 

- the data in the series must be sorted in ascending order before being added. If the data is not in ascending order, the chart will not be displayed.

## Characteristics of a Nested Proportional Area chart
<a name="characteristics_nested_proportional_area_chart_ELTTEXTE000154"></a><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=graphe_zone_nested.gif)
Elements in the chart:

**1. Start angle**. 
Angle applied to the chart. This parameter can be defined in the "General" tab of the Chart control description window ("Start angle (in degrees): "). 

**2. Chart title**. 
The characteristics of the chart title can be defined in the "Details" tab of the control description ("Edit chart title").
You can define the chart title, its position and style.

**3. Legend**. 
The characteristics of the legend can be defined in the "Details" tab of the control description ("Edit chart legend").
You can define its position and its style.

**4. Category label**. 
The category labels are displayed in the legend. The category labels can be defined in the "Series" tab of the control description. The source of category labels can be a column in a Table control, a table, a WLanguage array, a List Box, etc. 

**5. Color of the area**. 
The color of the areas is defined automatically. To change the color of areas, use [grSeriesColor](../WDLang3/3042013.md) and specify the number of the area. 

**6. Area label**. 
Area labels can contain:

- the value of the area. To view this value, select "Show values" in the "Details" tab of the Chart control description window.

- the labels of categories ("Show labels of categories" option in the "General" tab of the Chart control description window). 

- the percentages ("Show percentages" option in the "General" tab of the Chart control description window).
