


## Linking a data-bound Table control to a table or query
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000209"></a>
A Table control can be used to display the contents of a table or query: a user can select one or more records from the table or query.

A Table control can be linked to:

- an existing ***query*** Simply select this query from the list of queries in your project.

- a query ***integrated with the Table control*** This query will be created in the Table control creation wizard. This query will be available for this control only.




When a Table control is linked to a table (or a query), the Table control can be initialized with the contents of the table:

- **or automatically** No specific code is required to initialize the Table control field. The options to loop through the table linked to the control can be defined in the "Content" tab of the data-bound Table control description.

- **or by programming**: It is necessary to enter the path code of the table linked to the Table control in the various events of the Table control. This method is not recommended.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This method is not available.




**Note**: When a Table control is created, the wizard asks for the information needed to link the field to a table (or query).

For details of how to manage Table control fields linked to a query, see [Table fields linked to a query](../WDChamp/1013203.md).

## Table control linked to a table with automatic browsing
<a name="table_control_linked_table_with_automatic_browsing_ELTTEXTE000233"></a>
A data-bound Table control displays data from a specific data source (table, query, etc.).

The content of the Table control is defined when it is created and can be modified in the description window ("Content" tab).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_Table_Contenu.gif)
In this window, you can define whether the Table control is based on a table or is populated programmatically. For a data-bound Table control, you can define how to loop through the data source:



|   |   |
| --- | --- |
| <br><br>- **Table**<br><br><br> | File or query containing the data to display.<br>If the Table control is based on an embedded query, the name of the browsed file has the following format: &lt;Window Name&gt;_&lt;Number&gt;$Query. In this case, all the options of the "Embedded query" button are available. |
| <br><br>- **Stored item** (optional)<br><br><br> | Item whose value is returned to the program when a row is selected in the Table control. |
| <br><br>- **Automatic iteration**<br><br><br> | If this option is checked, the runtime engine iterates over the file and displays the data in the Table control. No WLanguage code is required. |
| <br><br>- **Search item**<br><br><br> | Item used to loop through the data source. The records displayed in the Table control are sorted based on this item. <br>If &lt;Automatic&gt; is selected, the HFSQL engine automatically selects the best search key. |
| <br><br>- **Reverse iteration (descending)**<br><br><br> | The iteration direction depends on the browse item. The iteration direction is defined in the data model editor, in the characteristics of the item.<br>If this option is checked, the iteration direction used will be the opposite of the one defined in the data model editor. |
| <br><br>- **Display records whose browse item starts with**<br><br><br> | Condition used to filter the displayed records. This is a "Start with" filter and is applied to the browse item. To implement more complex filters, use [HFilter](../WDLang4/3044100.md). | ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Display content while moving the scrollbar** | If this option is checked, the size of the vertical scrollbar cursor will be proportional to the number of elements in the Table control. |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) **Use HFilter to loop through the table** | Allows you to filter the records displayed in the Table control and the base table of the control. ## data-bound Table control updated programmatically
<a name="databound_table_control_updated_programmatically_ELTTEXTE000257"></a>
If you use a table-bound Table control with programmed initialization, the code to loop through the tables must be entered in the different events associated with the control. This method is not recommended and is only kept for backward compatibility.

**For example**: Initialize a Table control with the clients of the CLIENT table.


```wl
// Initialize the Table control
HReadFirst(CUSTOMER, NAME)

// Previous record 
HReadPrevious(CUSTOMER, NAME)
// Next record 
HReadNext(CUSTOMER, NAME)
// Last record
HReadLast(CUSTOMER, NAME)
```
