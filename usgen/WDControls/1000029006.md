## How to create a Pivot Table control (in a window or page)?
<a name="how_create_pivot_table_control_window_page_ELTTEXTE000197"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To create a Pivot Table control in a window**: 

1. On the "Creation" tab, in the "Data" group, expand "Table and List Box" and select "Pivot Table (PVT)". 

2. Click at the desired location to create the control. The control creation wizard opens. This wizard is used to define the main elements of the pivot table. 

3. At the end of the wizard, the Pivot Table control is automatically created with the Button control used to fill it at runtime. 




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **To create a Pivot Table control in a page**:

1. On the "Creation" tab, in the "Data" group, click on "Pivot Table (PVT)". 

2. Click where you want to create the control in the page. The control creation wizard opens. This wizard is used to define the main elements of the pivot table. 

3. At the end of the wizard, the Pivot Table control is automatically created. 




Remarks: 

- The Pivot Table control works: 

	- on the HFSQL databases, 

	- on other databases via arrays of structures.  




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The content of the Pivot Table control can be printed via its context menu. For more details, see [Printing the content of a Pivot Table control (AAF)](../WDChamp/1000029009.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) You can create a report based on a Pivot Table control. For more details, see [Pivot Table report](../WDChamp/1011092.md).

## Wizard for creating a Pivot Table control
<a name="wizard_for_creating_pivot_table_control_ELTTEXTE000230"></a>
The Pivot table control creation wizard is used to define the main elements of the table. 

1. First, the wizard is used to define the **values displayed** in the cells of the pivot table. A cell in a pivot table can display, for example, the sum of sales, total quantities, number of orders, etc.
	Therefore, for each value displayed in the cell, you need to define: 

	- the **source table**. This table corresponds to the table containing the value used for the calculation. For example, the OrdLine table to calculate sales. 

	- the **calculation displayed**. Several calculations are available: sum, mean, count, etc.

	- the **calculation source**, i.e. the item of the source table to be used. For example, to calculate sales, the sum will be calculated on the sales price (Total_Row item in the OrdLine table). 
			The "Add an additional value" button is used to define a new value that will be displayed in the cell. 
			**Remarks**: 

		- The Pivot Table control can be based on a query. In this case, the source table is the query. 

		- The Pivot Table control can be based on an Array of Structures variable. In this case, the source table is the variable.




2. The next step consists in defining the **column header** of the Pivot Table control. The column header comes directly from your tables. 
	One or more column headers can be found. 
	For each column header, the header lets you define: 

	- the link used to access the item displayed in the header. This link is performed from the table used for the source of calculation. 

	- if the column header corresponds to a Date item, the wizard suggests different display modes: Year, Semester, Quarter, Month, Fortnight, Week, Day. A new grouping will be defined for each selected display mode. For example, if only the years, quarters and months are displayed, the column header will be:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=TCD_Entete_Date.gif)
**Remarks**: 

		- If the Pivot Table control is based on a query, the data displayed in the column header comes directly from the query. 

		- If the Pivot Table control is based on an Array of Structures variable, the data displayed in the column header comes from the members of the structure. 




3. The next step consists in defining the **row header** of the Pivot Table control. The row header comes from your tables. 
	One or more row headers can be found. 
	For each row header, the wizard lets you define: 

	- the link used to access the item displayed in the header. This link is performed from the table used for the source of calculation. 

	- if the row header corresponds to a Date item, the wizard suggests different display modes: Year, Semester, Quarter, Month, Fortnight, Week, Day. A new grouping will be defined for each selected display mode.
			**Remarks**: 

		- If the Pivot Table control is based on a query, the data displayed in the row header comes directly from that query. 

		- If the Pivot Table control is based on an Array of Structures variable, the data displayed in the row header comes from the members of the structure. 




4. Give a name to the Pivot Table control and validate. 
	Note: The dimensions of the control are optimized to take up the available space at the specified position. If you are not happy with the size of the control, press Ctrl + Z key to restore the control to its default size.

5. The Pivot Table control is automatically created in the window or page. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The Pivot Table control is created in the window with a "Calculate" Button control. This Button control is used to start the calculation of the Pivot Table control. 

**Caution**: If the source of the Pivot Table control is:

- a query, the query must be run before calculating the Pivot Table control.

- an array of structures, the array of structures must be filled before calculating the Pivot Table control.




To change the characteristics of the Pivot Table control, open the control description ("Description" option in the context menu). For more details, see [Pivot Table control description](../WDChamp/1000029007.md).
