## Overview
<a name="overview_ELTTEXTE000195"></a>
WINDEV, WEBDEV and WINDEV Mobile propose different types of charts. 
The types of charts available are as follows:

- [Pie, Donut or Semi-circular charts](../WDChamp/3042007.md).

- [Column chart](../WDChamp/3042011.md).

- [Line chart](../WDChamp/3042002.md).

- [Scatter chart](../WDChamp/3042008.md). 
	

- [Stock chart](../WDChamp/3042004.md).

- [Radar chart](../WDChamp/3042073.md).

- [Area chart](../WDChamp/3042074.md).

- [Bubble chart](../WDChamp/1000019190.md)
	**Note**: Bubble charts are not available in the report editor.

- [Funnel chart](../WDChamp/1000019193.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) [Surface chart](../WDChamp/1000020624.md).

- [Waterfall chart](../WDChamp/1000021009.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) [Sunburst chart](../WDChamp/1000021010.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) [Heatmap chart](../WDChamp/1000021011.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Composite chart, made of several charts](../WDChamp/1000021016.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Pyramid chart](../WDChamp/1000021023.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Real-time chart](../WDChamp/1000021037.md).

- [Range Area chart](../WDChamp/1000021038.md).

- [Radial Bar chart](../WDChamp/1000021039.md).

- [Polar Area chart](../WDChamp/1000021040.md).

- [Waffle chart](../WDChamp/1000021041.md).

- [Pictorial Percentage chart](../WDChamp/1000021044.md).

- [Nested Proportional Areas chart](../WDChamp/1000021045.md). 
	




For more information on each type of chart, see the corresponding help page.
