
## Diagram editor (WEBDEV): Features
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000133"></a>
WEBDEV's Diagram Editor control includes many features accessible via: 

- The ribbon: open, save, search, print, ...

- The "Library" panel, which presents the different elements that can be used in the diagram. 

- The "Modifier" panel, which allows you to edit and configure the current element.

## The ribbon
<a name="the_ribbon_ELTTEXTE000157"></a>
WEBDEV's Diagram Editor control allows you to perform all the basic actions on a diagram. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001.gif&type=thumb)
This ribbon includes the following options: 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%201.gif): Undo/redo last action. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%202.gif): Open an existing diagram. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%203.gif): Save (download) a copy of the diagram currently displayed in the editor. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%204.gif): Export as image (PNG or SVG). 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%205.gif): Print the current diagram. The print preview opens and allows you to select the print mode. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%206.gif): Format painter. 
	To use this option, simply: 

	1. Select an element to copy its formatting. 

	2. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%206.gif). 

	3. Click the desired element. The formatting of the first element will be applied to the second element. 




- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%208.gif): Show or hide the grid. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2011.gif): Bring an element to the front, send to the back, bring forward or send backward one level, ... 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2012.gif): Group / Ungroup selected elements. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2010.gif): Freehand drawing.

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%209.gif): Zoom management: Zoom in, zoom out, 100%, window zooming. 

- <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0001%207.gif)
: Search in the text of the diagram.

## "Library" panel
<a name="library_panel_ELTTEXTE000181"></a>
The "Library" panel presents the different elements that can be inserted in the diagram. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0002%201.gif)


Each pane of the Library panel corresponds to a diagram. This diagram contains the different elements or images that can be reused in the diagram editor.  

<a name="NOTE4"></a>
<a name="NOTE4_1"></a>


## "Modifier" panel
<a name="modifier_panel_ELTTEXTE000205"></a>
The "Modifier" panel provides information about the selected element and, if necessary, allows you to edit this information. <br>![Characteristics of the page](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_diagramme_WB%20-%20HC%20N%B0002.gif)


Thus, the "Modifier" panel allows you to: 

- Format text area: font, size, position, etc.

- Define shape characteristics: background color, border color, border style, etc.

- Define link characteristics: routing, start image style, finish image style, etc.

- Define page options, etc.
