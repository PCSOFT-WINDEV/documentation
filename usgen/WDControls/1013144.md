


## Manipulating Edit controls programmatically
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000298"></a>
You can manipulate Edit controls programmatically. To do so, use the variable that corresponds to the Edit control in the code.

This variable is the name of the control itself. The variable type depends on the type of Edit control (numeric, text, monetary, etc.).

## Displaying information in an Edit control
<a name="displaying_information_edit_control_ELTTEXTE000322"></a>
To display information in an Edit control, simply assign a value.

For example:

- direct assignment:
	
	```wl
	EDT_CustomerLastName = "Doe"
	```


- assignment using a variable:
	
	```wl
	EDT_LASTNAME = Customer_LastName
	```


- assignment by calculation:
	
	```wl
	EDT_LASTNAME = NoSpace(CUSTOMER.LASTNAME) + TAB + NoSpace(CUSTOMER.FIRSTNAME)
	```



**Remark**: If the field is associated with an item in a table, assignment is automatically performed using:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) the [FileToScreen](../WDLang4/3044210.md) function.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the [FileToPage](../WDLang4/3044148.md) function. 


You can also use the following notation: CustomerLastName = CUSTOMER.LASTNAME. For more details, see [Bind an Edit control to an item](../WDChamp/1013159.md).

## Retrieving the value entered in an Edit control
<a name="retrieving_the_value_entered_edit_control_ELTTEXTE000346"></a>
To retrieve the content of an Edit control:

- perform a simple assignment. 
	For example:
	
	```wl
	CurrentEditContent = EDT_EDIT1
	```


- retrieve part of the information. 
	For example:
	
	```wl
	Initial = Left(EDT_LastName, 1) 
	Initial = EDT_LastName[[1]]
	```


- use the [Value](../Proprietes/2510130.md) property




**Note** If the Edit control is associated with an item in a table, the value entered is automatically retrieved using:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) the [WindowToData](../WDLang4/3044146.md) function.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the [PageToFile](../WDLang4/3044022.md) function.


You can also use the following notation: CUSTOMER.LASTNAME = Edit1. For more details, see [Bind an Edit control to an item](../WDChamp/1013159.md).

## Properties specific to Edit controls
<a name="properties_specific_edit_controls_ELTTEXTE000370"></a>
The following properties allow you to define the characteristics of Edit controls.


|   |   |
| --- | --- |
| **Any type of edit control** |
| [HorizontalAlignment](../Proprietes/2510023.md) | Gets and sets the horizontal alignment of an Edit control. |
| [VerticalAlignment](../Proprietes/2510054.md) | Gets and sets the vertical alignment of an Edit control. |
| [Cursor](../Proprietes/2510025.md) | Gets and sets the position of the mouse cursor in an Edit control. |
| [DndTarget](../Proprietes/2510016.md) | Gets and sets the behavior of the target control during a drag-and-drop operation. |
| [DndSource](../Proprietes/2510014.md) | Gets and sets the behavior of the source control during a drag-and-drop operation. |
| [Ellipse](../Proprietes/2510051.md) | Gets and sets the type of ellipsis in an Edit control. |
| [CursorEnd](../Proprietes/2510047.md) | Gets and sets the end position of a selection made with the cursor. |
| [InputMask](../Proprietes/2510033.md) | Gets and sets the input mask. |
| [LeftIndent](../Proprietes/2513018.md) | Gets and sets the left indent of the text in the Edit control. |
| [RichEdit](../Proprietes/2510108.md) | Determines if a control supports RTF, and enables or disables RTF support for that control. |
| [SelectedText](../Proprietes/1000017193.md) | Gets and changes the text selected in an Edit control. |
| [InputType](../Proprietes/2510136.md) | Gets the type of Edit control. |
| **Text Edit controls only** |
| [DeleteButton](../Proprietes/1000021924.md) | Determines whether or not the control contains a Delete button. |
| [AutomaticLink](../Proprietes/2513017.md) | Gets and sets the link detection mode in multiline Edit controls. |
| [Password](../Proprietes/2510086.md) | Determines if an Edit control is of type "Password". |
| [Multiline](../Proprietes/2510105.md) | Determines if an Edit control supports multiple lines of text. |
| [AutoLineWrap](../Proprietes/1000021868.md) | Determines if a multiline Edit control supports automatic line wrapping. |
| **Currency + Euro Edit controls only** |
| [DisplayCurrency](../Proprietes/2510030.md) | Gets and sets the currency used to display or enter a value in a "Currency + Euro" Edit control. |
| [MemoryCurrency](../Proprietes/2510013.md) | Gets and sets the currency used when manipulating a "Currency + Euro" Edit control programmatically. |
| **Duration and Numeric Edit controls** |
| [MaxValue](../Proprietes/2510009.md) | Gets and sets the upper bound of values in an Edit control. |
| [MinValue](../Proprietes/2510008.md) | Gets and sets the lower bound of values in an Edit control. |


For a complete list of WLanguage properties that can be used with Edit controls, see [Edit control properties](../WDChamp/1013230.md).

## Special case: Edit control type UPLOAD (retained for compatibility)
<a name="special_case_edit_control_type_upload_retained_for_compatibility_ELTTEXTE000394"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The Upload Edit control allows users to easily send files from their computer to the server.

WEBDEV proposes two WLanguage functions for managing the file upload: 



|   |   |
| --- | --- |
| [UploadCopyFile](../WDLang2/3012023.md) | Saves a file "uploaded" by the user to the server. |
| [UploadFileName](../WDLang2/3012022.md) | Returns the name of a file "uploaded" by the Web user. This file must have been uploaded: <br><br>- via an "Upload" edit control. <br><br>- via a single-file or multi-file Upload field.<br><br><br> |



For more details, see [File upload](../WDLang2/3012024.md).

**Note** There is also an Upload control for single or multi-file uploads. For more details, see [Upload control](../WDChamp/1016330.md).
