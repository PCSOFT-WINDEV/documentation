


## Report based on a class (MVP)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000278"></a>
Reports based on a class allow you to directly print data from an Array member of a class. 

This is particularly useful to create reports in MVP applications. 

Note: The instance of the parent class must be passed as a parameter when creating the report. 

[**Reports & Queries**](../Presentation/3088004.md) does not allow you to create or edit reports based on a class.

## Creating a report based on a class (MVP)
<a name="creating_report_based_class_mvp_ELTTEXTE000311"></a>
To create a report based on a variable:

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

	- The new element window appears. Click "Report", and then "Report". 

	- The report creation wizard opens. 




2. In the wizard, choose the layout of your report (table, form, label, etc.). For more details, see [The different types of reports](../WDChamp/1011054.md).

3. Select (if necessary) the report template to use. A report template allows you to use a specific layout. For more details on report templates, see [Report templates](../WDChamp/9000105.md). 

4. Select the data source of the report ("A class used as a parameter in the report initialization (MVP)").

5. Select the array member on which the report will be based. Only the classes in the current project and the associate members are available.

6. You can create breaks between array elements in order to group records. To create breaks, answer "Yes" to "Do you want to insert breaks into the report?".
	The next step of the wizard is to select the variables that define the breaks. 
	**Caution**: Before printing the report, you need to programmatically sort the array by the value of the variables that define the breaks. You can define the sorting order using [Sort](../WDLang1/1000017364.md).  
	For more details on breaks, see [Breaks in a report](../WDChamp/1011028.md).

7. Select the members to be displayed in the report. If necessary, use the arrow buttons to the right of the list to reorder the controls in the report.

8. Select the block in which each variable will be displayed. You can also change the control caption. 
	Note: By default, the controls associated with variables are displayed in the Body block. By default, the control caption corresponds to the variable name. You can also change the caption directly in the report editor.

9. If the variable associated with the report contains at least one numeric item, you can perform calculations on these items. Specify the calculation performed for each item (sum, average, etc.). Two types of calculations are available:

	- general calculation: A Calculated control will be created in the *End of document* block.

	- calculation within breaks: A Calculated control will be created in the *Break footer* block. In calculations within breaks, the result of the calculation is reset at each break. To perform this type of calculation, the report must contain at least one break.




10. Depending on the type of report being created, indicate the specific options.
	

| Type of report | Specific options |
| --- | --- |
| Report based on a form | Form image, form image print mode, etc.<br>Options presented in detail in [Report based on a form](../WDChamp/1011067.md) |
| Label report | Label format, number of identical copies, etc.<br>Options presented in detail in [Label report](../WDChamp/1011050.md) |



11. Specify the format of the sheet on which the report will be printed. By default, the report is printed in A4 format.
	Note: By default, the report controls are displayed in a single column. To create a multi-column report, simply specify the desired number of columns in the "Format" tab of the report description window.

12. Select the theme of the report if necessary.

13. Type the name and title of the report (name of the ".WDE" file corresponding to the report). This name will be used to identify the report in your programs.

14. Confirm the report creation. 

15. The report editor automatically suggests changing the report format in the following cases:

	- the report includes a table.

	- the report format does not allow to display all table columns.




16. If necessary, specify the mode for reducing the size of the report: 

	- Print the report on several pages. In this case, the end user will have to group the pages. For more details, see [Printing on multiple pages](../WDChamp/1011065.md).

	- Use the landscape mode. 

	- Reduce the report size. Note: Depending on the reduction percentage selected, the printed report may become illegible. 




17. The report is displayed in the report editor.

## Printing a report based on a class (MVP)
<a name="printing_report_based_class_mvp_ELTTEXTE000335"></a>


### Printing a report based on a class
<a name="printing_report_based_class_ELTPARAGRAPHE000125"></a>

To print a report based on a class, simply:

1. Initialize the class, the associated object and the member used.

2. If necessary, sort the member of type array (with [ArraySort](../WDLang1/3075007.md), for example). 

3. Configure the report print destination:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) In WINDEV, using [iDestination](../WDLang5/3046074.md) (report viewer, print to an HTML file, etc.).

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In WEBDEV, using [iDestination](../WDLang5/3046074.md) (print to an HTML file, etc.).


 For more details, see [Print modes of a report](../WDChamp/1011031.md).

4. Specify the name of the report to be printed and the instance of the parent class in the call to [iPrintReport](../WDLang5/3046032.md).


If necessary, you can specify additional parameters when printing a report with parameters based on a class. For example, you can pass the name of the Array variable as a parameter. In this case, the report is a report with parameters based on an Array variable (see next paragraph).  In [Reports & Queries](../Presentation/3088004.md), you can print a report:

- by starting a print job (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Ico_Imprimer.gif)). 

- by testing the report (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Ico_Go_Fenetre_WD_bl.gif)). 


Therefore, no programming is required to print the report.



### Remarks
<a name="remarks_ELTPARAGRAPHE000175"></a>

- When used in the code of the report, the [SourceName](../Proprietes/2511035.md) property allows you to get and change the name of the variable associated with the report.

- When used in the code of the report, the [DisplayedItem](../Proprietes/2510123.md) property allows you to get and change the name of the variable associated with the item.

- The **MyStoredValue** keyword is used to identify the current object in the class array when printing a report based on a class. 





### Printing a report with parameters based on a class
<a name="printing_report_with_parameters_based_class_ELTPARAGRAPHE000190"></a>

To print a report with parameters based on a class, simply:

1. Initialize the class, the associated object and the member used.

2. If necessary, sort the member of type array (with [ArraySort](../WDLang1/3075007.md), for example). 

3. Configure the report print destination:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) In WINDEV, using [iDestination](../WDLang5/3046074.md) (report viewer, print to an HTML file, etc.).

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In WEBDEV, using [iDestination](../WDLang5/3046074.md) (print to an HTML file, etc.).


 For more details, see [Print modes of a report](../WDChamp/1011031.md).

4. Specify the following parameters with [iPrintReport](../WDLang5/3046032.md):

	- name of the report to be printed.

	- parent class instance. 

	- parameters expected by the report (in the order specified in the report).







Note: For more details on how to pass parameters to a report, see [Reports with parameters](../WDChamp/1011008.md).
