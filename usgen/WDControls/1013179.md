## Static Text control overview
<a name="static_text_control_overview_ELTTEXTE000379"></a>


### Control in a window, in a page (static or dynamic) or in a report
<a name="control_window_page_static_dynamic_report_ELTPARAGRAPHE000011"></a>

## Creating a Static Text control in a window or page
<a name="creating_static_text_control_window_page_ELTTEXTE000403"></a>


### Creating a Static Text control in a window or page
<a name="creating_static_text_control_window_page_ELTPARAGRAPHE000101"></a>

To create a Static Text control in a window or page:

1. On the "Creation" tab, in the "Usual controls" group, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_libelle18.gif).

2. Click where you want to create the control in the window or page. The control appears in the editor.




To view the characteristics of the control, select "Description" in the context menu. You can type text in the control or define the type of information that will be displayed. 
<a name="NOTE2_2"></a>


### Handling long text
<a name="handling_long_text_ELTPARAGRAPHE000123"></a>

If the text is too long, there are several possible solutions:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Reduce font size**: 
	You can set a minimum font size for text that is too long ("Reduce font size" in the "Details" tab of the control description window).

- **Display an ellipsis**: You can use an ellipsis.. Ellipses (three consecutive dots) replace excessively long text. 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In a page, text can only be truncated at the end, and the omitted words are replaced with three dots. The "Truncate with an ellipsis at the end" option can be found in the "UI" tab of the control description window. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In a window, you can use an ellipsis at the end or in the middle of a long text. The use of the ellipsis can be defined in the "Details" tab of the Static Text control.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Use an animation**: You can use an animation to make the text scroll automatically. This will allow the user to see the entire text. For more details on how to configure the animation, see [Animating a Static Text control](../WDChamp/1013160.md).

### Special case: RTF Static Text control
<a name="special_case_rtf_static_text_control_ELTPARAGRAPHE000170"></a>

To create a Static Text control in RTF in a window: 

1. On the "Creation" tab, in the "Usual controls" group, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_libelle18.gif).

2. Open the control description window (select "Description" in the context menu). 

3. In the "General" tab: 

	- Select the type of Static Text control: "RTF". 

	- Enter the RTF text. A specific text formatting toolbar automatically appears.







Remarks:

- You can also create an RTF Static Text control via the "RTF text" Smart control. 

- An RTF Static Text control can also be created by pasting RTF text directly in the window.

- To use a Static Text control in RTF, the "RICHED20.DLL" file must be on the current computer. In most cases, the "RICHED20.DLL" file is in the Windows system directory.

- You can also use the [RichEdit](../Proprietes/2510108.md) property to modify the RTF type of a Static Text control programmatically.

## Content of Static Text control
<a name="content_static_text_control_ELTTEXTE000463"></a>
Static Text controls can display information:

- entered in the editor. 

- defined programmatically. 

- from a table. In this case, the Static Text control is bound to a table item. In this case, the control is used to view the content of the items in the table.





### Entering text in a Static Text control in the editor
<a name="entering_text_static_text_control_the_editor_ELTPARAGRAPHE000246"></a>

To type the text of the Static Text control:

1. Click the Static Text control in the editor. The input cursor is displayed.

2. Type the text of the Static Text control.
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For RTF Static Text controls (in a window or report), the format of each element can be defined via a toolbar.




Note: You can also edit the text in a Static Text control from the control description window.

### Content of Static Text control (report editor)
<a name="content_static_text_control_report_editor_ELTPARAGRAPHE000264"></a>

- **The character string displayed in the Static Text control can contain the value of an item printed in the report**. To insert the value of an item or a control of the report into the text of the Static Text control, enter the name of the item or control between [% and %]. 
	For example, the text of the control can correspond to: 
	The **]**%**SupplierName**%**[** supplier sells the **]**%**ProductName**%**[** product at **]**%**PriceIOT**%**[**. 
	SupplierName, ProductName and PriceIOT will be replaced with their value when the report is executed.

- **Text can span multiple lines**. In this case, the control must be a multiline control and its size must be large enough. 
	Note: If an angle is applied to a multiline control, automatic carriage returns are ignored. Only manual carriage returns are taken into account.




**Reminder**: The "Auto-resizing" option automatically resizes the control according to its content.
