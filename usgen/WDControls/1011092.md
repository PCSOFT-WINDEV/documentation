
## Pivot Table control in a report
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000121"></a>
The report editor allows you to create "Crosstab" reports. In this case, there are two possibilities for a WINDEV application: 

- if the data source corresponds to multiple tables, a Crosstab report based on a query will be created. 

- if the data source corresponds to a Pivot Table control present in a window (as presented in this page), the report will contain a Pivot Table control. 




When creating a report based on a Pivot Table control from a window, the report contains only a Pivot Table control. This type of control can only be created within this type of report.. 

In the editor, this control includes two blocks: 

- The "Header" block that displays the titles of the columns in the Pivot Table. 

- The "Pivot Table" block that displays the titles of the rows and the associated data. 




For more details on the different sources of a "Crosstab" report, see [Crosstab report](../WDChamp/1011062.md).

## Creating a Crosstab report based on a Pivot Table control
<a name="creating_crosstab_report_based_pivot_table_control_ELTTEXTE000145"></a>


### Creating the report
<a name="creating_the_report_ELTPARAGRAPHE000031"></a>

To create a "Pivot Table" report: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

2. The window for creating a new element is displayed: click "Report" then "Report".

3. The report creation wizard starts. 

4. In this wizard, specify:

	- the type of report you want to create: "Crosstab".

	- the Pivot Table control used as data source.

	- the theme template of the report (if necessary).

	- the name and title of the report. This name (".WDE". file corresponding to the report) will be used to identify the report in your programs.

## Characteristics of a Pivot Table report and a Pivot Table control
<a name="characteristics_pivot_table_report_and_pivot_table_control_ELTTEXTE000169"></a>


### Characteristics of the Pivot Table (Report editor)
<a name="characteristics_the_pivot_table_report_editor_ELTPARAGRAPHE000052"></a>

You can change the following characteristics of a Pivot Table report: 

- The data source of the report can be modified in the "Data" tab of the description window of report ("Report description" in the context menu of the report). 

- The "General" tab of the Pivot Table control description window is used to specify: 

	- **the cell width calculation mode**. The following options are available:

		- Use the width defined in edit mode: The width of the cells will be the same as the one defined in the report editor.
						Note: You can use the sizing handles to resize the data area in the Pivot Table control in the report. 

		- Fill pages horizontally as much as possible: Cells will grow to fill the available space on the page.

		- Avoid truncated cells: When possible, cells will be enlarged to display all the data they contain.




- **the dimension expansion mode**. The following options are available:

	- Like the control: The level of detail displayed in the report will be the same as that of the Pivot Table control used as the data source.

	- All expanded: All the data of the Pivot Table control will be displayed.

	- All collapsed: Only the first level of detail of the Pivot Table control will be displayed.

- In the "Style" tab of the Pivot Table control description, you can check "Define style independently of the printed PVT control" to define a specific style for the control in the report. If this option is checked, you have the ability to specify the style for the row headers and for the data.
