## Overview of Preset control
<a name="overview_preset_control_ELTTEXTE000119"></a>


### Control in a report
<a name="control_report_ELTPARAGRAPHE000011"></a>

The "Preset" control allows you to display the frequently used controls without programming. A "Preset" control can be inserted into a report to display the following information:

- System date.

- System time.

- Number of the current page.

- Page number/Number of pages.

- Total number of pages in the report.




Note: When a report is created, preset fields such as "Date" and "Page number / Number of pages" are automatically inserted in the report.

## Creating a Preset control
<a name="creating_preset_control_ELTTEXTE000143"></a>
To create a "preset" control in a report:

1. On the "Creation" tab, in the "Text" group, click "Preset".

2. Click where you want to create the control.

3. In the control creation wizard, select the type of control you want to create.

4. Specify the content or the format of control.

5. The control is automatically created at the specified location.




Note: It is also possible to use the default Preset controls. In the "Creation" pane, in the "Text" group, click on "Preset" and select the type of field you wish to create. Then, click where you want to create the control in the report.

## How to modify the type of information displayed in a "preset" control?
<a name="how_modify_the_type_information_displayed_preset_control_ELTTEXTE000167"></a>
To modify the type of information displayed in a "preset" control:

1. Go to the "General" tab in the description window of the "preset" control ("Description" in the control context menu).

2. Select the type of information displayed ("Type" combo box).
