
## Positioning a toolbar
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000093"></a>
A Toolbar control can be created in a standard window or in an MDI parent window. Depending on the type of window, the toolbar docking options and the organization of the controls in the window may vary.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Toolbar in a standard window
<a name="toolbar_standard_window_ELTTEXTE000117"></a>
In a standard window, when the user docks the toolbar, all the controls in the window are moved proportionally to the size of the toolbar. The controls are moved according to the anchoring options previously set in the window.

## Toolbar in an MDI parent window
<a name="toolbar_mdi_parent_window_ELTTEXTE000141"></a>
In an MDI parent window, when the user docks the toolbar, the size of the MDI area changes.
