These are the main concepts for programming data-bound Looper controls.

WLanguage includes multiple functions to programmatically manage data-bound Looper controls.

Do not hesitate to see the documentation about these functions. For more details, see [Looper control functions](../WDLang2/3083007.md).

## Adding or modifying a row in a data-bound Looper control
<a name="adding_modifying_row_databound_looper_control_ELTTEXTE000129"></a>
The addition and modification of a row in a Looper control (and of a record in the table) consist of two phases:

1. Add or modify the record in data the file (via a form window or page, for example)

2. Refreshing the content of the data-bound Looper control ([LooperDisplay](../WDLang2/3083001.md)).




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Deleting a row from a data-bound Looper control
<a name="deleting_row_from_databound_looper_control_ELTTEXTE000153"></a>
To delete a row from a data-bound Looper control:: 

1. Delete the record from the table (via [HDelete](../WDLang4/3044018.md)).

2. Refresh the content of the data-bound Looper control (using [LooperDisplay](../WDLang2/3083001.md)).


**Important**: [LooperRecNum](../WDLang2/3083010.md) returns the number of the current record in a data-bound Looper control.
