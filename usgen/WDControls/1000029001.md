## Pivot Table control overview
<a name="pivot_table_control_overview_ELTTEXTE000144"></a>
The PivotTable field dynamically displays data that comes from the intersection of different tables in a database. 

This enables you to display the volume of sales according to families of products, products, regions, over time, with or without details. 

The Pivot Table operates: 

- on the HFSQL databases, 

- on other databases via arrays of structures.  




Remarks:

- The content of the Pivot Table control can be printed via its context menu. For more details, see [Printing the content of a pivot table (AAF)](../WDChamp/1000029009.md). 

- You can create a report based on a Pivot Table control. For more details, see [Pivot Table report](../WDChamp/1011092.md).

## Example of pivot table (based on HFSQL tables)

### Example
<a name="example_ELTPARAGRAPHE000071"></a>

Let's see an example of pivot table based on HFSQL tables. The main concepts of the pivot table will be presented from this example.  

Associated database schemas:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_TCD%20-%20HC%20N%B0001.gif)


Created pivot table: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Champ_TCD%20-%20HC%20N%B0002.gif)


This pivot table represents product sales (sorted by category) per year, quarter and month. 

In the center (1), the values from the source table are displayed. These values are automatically calculated according to the groups defined. 

Row and column headers (2) represent the items used to group the data:

- In row, in our example, the total of sales is displayed by product and by category. From the "OrdLine" table, a group is defined using the "ProdCap" item of the "Product" table. Then, another group is defined using the "CategoryCap" item of the "Category" table. 

- In our example, columns show the sales total by month, quarter, category. From the "OrdLine" table, a group is defined using the "OrderDate" item of the "Order" table.  




The totals (3) are automatically calculated. 

The creation of a pivot table is performed in the editor via a wizard. For more details, see [Creating a pivot table](../WDChamp/1000029006.md).
