## Evénements gérés par défaut
<a name="evenements_geres_par_defaut_ELTTEXTE000190"></a>
WEBDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :


| Evénement | Condition d'exécution |
| --- | --- |
| Initialisation (Code serveur) | Exécuté à l'ouverture de la page. |
| Clic sur le lien (Code navigateur) | Exécuté lorsque l'internaute clique sur le lien. Ce code est toujours exécuté, quel que soit le type de l'action du lien. |
| Clic sur le lien (Code serveur) | Exécuté lorsque l'internaute clique sur le lien. <br><br>Si l'action du lien est de type : <br><br>- Détection automatique des codes serveur et navigateur à exécuter, le code serveur sera exécuté uniquement s'il contient du code WLangage. <br><br>- Toujours exécuter les codes serveur et navigateur, le code serveur sera toujours exécuté (même s'il ne contient pas de code WLangage. <br><br>- Exécuter le code de clic navigateur uniquement : le code serveur ne sera pas exécuté. <br><br><br> |




Deux codes de clic sont associés aux champs Lien :

- **un code de clic navigateur**, saisi en WLangage (ou en Javascript) sous l'éditeur de code. Ce code est intégré à la page HTML et sera exécuté sur le poste de l'internaute.

- **un code de clic serveur**, saisi en WLangage uniquement. Ce code sera exécuté sur le serveur.





**Remarque** : Dans une page statique, seuls les codes navigateur sont disponibles.

## Evénements optionnels
<a name="evenements_optionnels_ELTTEXTE000238"></a>
Plusieurs événements optionnels peuvent être gérés.



Il est ainsi possible de gérer par exemple :

- le survol du champ par la souris,

- le bouton gauche enfoncé, relâché, avec un double-clic,

- le bouton droit enfoncé, relâché, avec double-clic,

- la roulette de la souris, ...




Pour plus de détails, consultez les [Evénements optionnels](../WDChamp/1014004.md).
