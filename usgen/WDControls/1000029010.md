## Overview
<a name="overview_ELTTEXTE000189"></a>
When used in a web page, Pivot Table controls offer a number of Application Automatic Features (AAF), enabling the user to take full advantage of this type of control. 

The user can: 

- collapse/expand columns and rows by clicking the header icons "+" and "-". 

- open a context menu to perform several actions on rows and columns. 

- open a context menu of the different cells. 

- select several rows, columns or cells via the Shift and Ctrl keys. This option is available only if multiple selection is allowed in the control. For more details, see [Pivot Table control description](../WDChamp/1000029007.md). 




The context menu of rows and columns includes the following features: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FAA_TCD_WB%20-%20HC%20N%B0002.gif)


- [Collapse or expand all columns](#NOTE2_2),

- [Expand a level and all its sub-levels](#NOTE2_2),

- [Compare date ranges](#NOTE2_Comparer). 




The context menu of cells includes the following features: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FAA_TCD_WB%20-%20HC%20N%B0004.gif)


- Copy the element.

- [Change the cell background](#NOTE2_6). 

- [Compare date ranges](#NOTE2_Comparer). 




Note: If the Pivot Table control allows for multiple selection, certain operations are available only for the selected rows, columns or cells.

### Collapse/Expand columns or rows
<a name="collapseexpand_columns_rows_ELTPARAGRAPHE000061"></a>

For a Pivot Table with many elements and subelements, you can:

- collapse or expand all the columns and/or rows in a single action. 

- expand a level and all its sublevels in a single action (in columns or rows). 




For example: 

- If all the columns are expanded, the pivot table displays all the details. All intermediate results are shown from the highest to the lowest level. 

- If all the columns are collapsed, the pivot table hides the details, and shows only first-level results. 



<a name="NOTE2_Comparer"></a>


### Compare date ranges
<a name="compare_date_ranges_ELTPARAGRAPHE000076"></a>

This option is used to compare the data displayed in the Pivot Table control over 2 date ranges. 

When this option is selected: 

- A dialog box appears, allowing you to enter the details of the comparison:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FAA_TCD_Comparer_WB%20-%20HC%20N%B0001.gif&type=thumb)
This comparison will take into account the reference date range specified in this dialog box; not the date range currently displayed in the Pivot Table control. 

	- Reference date range. 

	- Previous date range for comparison. 

	- Evolution between years.




- Once you confirm changes in this dialog box, the data is recalculated to show only the data in the comparison. 


To restore the standard Pivot Table control, select "Cancel date range comparison" in the context menu. 
<a name="NOTE2_6"></a>


### Changing the background color of a cell
<a name="changing_the_background_color_cell_ELTPARAGRAPHE000096"></a>The context menu of a cell allows the user to easily change the color of a cell in the Pivot Table control. This makes it easier to identify important elements in the pivot table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FAA_TCD_WB%20-%20HC%20N%B0005.gif)


Tip: The last color used is automatically suggested in the context menu of the cell. This feature is useful to apply the same color to multiple cells. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FAA_TCD_WB%20-%20HC%20N%B0006.gif)


When saving the content of the pivot table (with UI), the specified colors are saved.

## Settings
<a name="settings_ELTTEXTE000258"></a>


### Settings of the automatic menu in a Pivot Table control
<a name="settings_the_automatic_menu_pivot_table_control_ELTPARAGRAPHE000113"></a>

The context menu of a Pivot Table control can be disabled. To show or hide the context menu:

1. Open the description window of the Pivot Table control.

2. Select the "UI" tab.

3. Choose the desired menu in the "Context menu" combo box. You can: 

	- "Display the AAF menu (System)": In this case, the automatic menu of the Pivot Table control will be used (AAF menu). For more details on how to configure this menu, see [AAF menu settings](../Editeurs/2010040.md).

	- "Add a context menu": If this option is checked, you can select the custom context menu to be displayed.







Remarks: 

- If both options are checked, the custom context menu can be added before or after the AAF menu. 

- If no option is selected, no context menu will be selected. The &lt;Disabled&gt; option will be displayed in the description window. 

- The [ContextMenu](../Proprietes/2510077.md) property is also used to remove the AAF-specific context menu and restore the standard Windows menu for a given control.
