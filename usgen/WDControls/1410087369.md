## AI Chat control overview
<a name="chat_control_overview_ELTTEXTE000161"></a>
With the AI Chat control, your WINDEV applications can easily interface with the AI model of your choice.
The conversation can contain:

- text, 

- images, 

- one or more actions in the application.


The AI Chat control lets users enter conversation elements.

It sends them to the model, retrieves the response and displays it as it goes along.

If the model requires an action, the AI Chat control will perform it.

**Caution**

- The use of an AI Chat control in a WINDEV application requires an API key for the AI model used. AI models supported:

	- ChatGPT (provider: OpenAI)

	- Claude (provider: Anthropic)

	- Gemini (provider: Google)

	- OpenRouter (provider: OpenRouter)

	- Le chat (provider: Mistral AI)

	- xAI (provider: Grok)




- The use of conversational AI in your WINDEV application involves purchasing tokens from the provider of the AI model.

## Creating an AI Chat control
<a name="creating_chat_control_ELTTEXTE000185"></a>
**To create an AI Chat control:**

1. Go to the "Creation" tab, "Graphic controls" group, expand "Office", and then click "AI Chat". 

2. Click at the desired location to create the control.




Note: The dimensions of the control are optimized to take up the available space at the specified position. If you are not happy with the size of the control, press Ctrl + Z key to restore the control to its default size.

To view the characteristics of the control, select "Description" in the context menu.

## AI Chat control features
<a name="chat_control_features_ELTTEXTE000213"></a>
You can configure the main features of AI Chat controls in the the "General" and "Details" tabs of the description window. 


### General tab
<a name="general_tab_ELTPARAGRAPHE000070"></a>

In the "General" tab, you can:

- choose the AI model you want to use. Simply select:

	- a provider from the list. 

	- corresponding API key. 

	- model (optional)

	- URL (optional). 




- system prompt. 
	This prompt provides context for conversational AI. This makes it possible to focus on specific areas. It is also possible to indicate the sequence of procedures to be used to answer certain questions. 






**Providers - special cases**

- The provider is set to "Defined programmatically". In this case, the details of the provider must be defined using the AIModelInfo property. 

- The provider is set to "Custom". In this case, you must specify: 

	- protocol,

	- corresponding API key. 

	- model (optional)

	- URL (optional). 










### Details tab
<a name="details_tab_ELTPARAGRAPHE000097"></a>

In the "Details" tab, you can customize each element of the chat window. You can use and customize an internal window for each element. 

The following elements can be customized:

- question area: The question area contains the question sent by the user. 

- loading area: The loading area appears while the AI model searches for response elements. 

- response header: The response header presents the response. This area can contain the logo of the AI, a text indicating the response comes from the AI model, etc. 

- tool: This area indicates the tool currently used. 
	Reminder: Tools are WLanguage procedures that can be called by the AI model. 

- response: This area contains the body of the response sent by the AI model. 

- response footer: This area contains the icons shown below the body of the response. This area can be used to include a copy button, for example. 

- input area: This area allows users to write their questions. 
	You can show the number of tokens used by the request. 

- error: This area contains the details of the detected errors, if any.
