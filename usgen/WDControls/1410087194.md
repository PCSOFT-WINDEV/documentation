
## Properties associated with the options of a Switch control
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000102"></a>
Both options of a Switch control can be managed in WLanguage in a window or page with the following properties.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Properties available in a window
<a name="properties_available_window_ELTTEXTE000126"></a>
**Properties available in a window**

The following properties are associated with options of Switch controls:



|   |   |
| --- | --- |
| [BackgroundColor](../Proprietes/2510022.md) | The **BackgroundColor** property is used to set the background color of a control, window, page or block of a report. |
| [Caption](../Proprietes/2510053.md) | **In a database**, the **Caption** property is used to:<br><br>- Find out the caption associated with a file item. <br><br>- Find out the caption associated with a table. <br><br>- Find out and modify the connection caption. <br><br><br><br><br>**In a report**, the **Caption** property is used to:<br><br>- Find out the text displayed in a Static or Link control.<br><br>- Modify the text displayed in a Static or Link control.<br><br><br><br><br>**In a window or page**, the **Caption** property is also used to:<br><br>- Find out and modify the caption of a control found in a window or in a page.<br><br>- Find out and modify the caption of a menu option.<br><br>- Find out and modify the title of a window or page.<br><br>- Find out the content of a Breadcrumb control.<br><br><br><br><br> |
| [Color](../Proprietes/2510071.md) | The **Color** property gets or sets the font color of:<br><br>- a Font variable.<br><br>- text displayed in a Static or Calculated control of a report.<br><br>- text displayed in a window control.<br><br>- text displayed in a page control.<br><br><br> |
| [FullName](../Proprietes/2514005.md) | The **FullName** property is used to find out the full name:<br><br>- of a control.<br><br>- of a window.<br><br>- of a menu option.<br><br>- of a table column.<br><br><br><br><br> |
| [Grayed](../Proprietes/1000019648.md) | The **Grayed** property is used to: <br><br>- Determine if a control (or a group of controls) is grayed out. <br><br>- Gray out or ungray a control, a group of controls or a window.<br><br><br> |
| [Height](../Proprietes/2510050.md) | The **Height** property gets and sets the height:<br><br>- of a control or block in a report.<br><br>- of a control (in a window), window, row of a Table, List Box or ListView control, option of a Radio Button or Check Box control, break header or footer of a Table or Looper control.<br><br>- of a control (in a page), break header or footer in a Table or Looper control. The control can be overlayable or not.<br><br>- of a break cell in a Table or Looper control.<br><br><br> |
| [HelpNumber](../Proprietes/2510141.md) | The **HelpNumber** property is used to identify and modify the help number associated with a control. |
| [Image](../Proprietes/2510034.md) | The **Image** property gets and sets the background image of a control or block. |
| [Markdown](../Proprietes/1410089000.md) | The **Markdown** property is used to enable or disable Markdown formatting in the controls of a window or a report. |
| [Name](../Proprietes/2510082.md) | The **Name** property is used to get:<br><br>- the name of the font associated with a Font variable.<br><br>- the name of a control, report or report block.<br><br>- the name of a control, group of controls or window.<br><br>- the name of a control, group of controls or page.<br><br><br> |
| [ParallaxRateHeight](../Proprietes/1000021921.md) | The **ParallaxRateHeight** property is used to determine and specify how fast a control is reduced when the scrollbar in the window, internal window or page moves. |
| [ReturnedValue](../Proprietes/2510134.md) | The **ReturnedValue** property is used to:<br><br>- Get and change the value returned by a window, page or report.<br><br>- Get and change the value returned by an option in a Radio Button control. <br><br><br> |
| [State](../Proprietes/2510039.md) | The **State** property gets and sets the state of an element. |
| [SubCaption](../Proprietes/1000017232.md) | The **SubCaption** property is used to get and change: <br><br>- the secondary caption of an option found in a Radio Button or Check Box control.<br><br>- the secondary caption of an element found in a TreeMap control. <br><br><br> |
| [ToolTip](../Proprietes/2510005.md) | The **ToolTip** property gets and sets the text displayed in a tooltip. This tooltip can be associated with: <br><br>- a control in a window or page,<br><br>- a control in a report. In this case, the tooltip will only be visible in the report viewer.<br>	<br><br><br> |
| [TriState](../Proprietes/2510124.md) | The **TriState** property is used to:<br><br>- Determine if a check box option supports 3 or 2 states.<br><br>- Determine if a TreeView control uses 3-state or 2-state check boxes. <br><br>- Modify the type of a switch option: 3-state or 2-state options.<br><br><br><br><br> |
| [Visible](../Proprietes/2510138.md) | The **Visible** property is used to:<br><br>- Determine whether an element is visible.<br><br>- Make an element visible or invisible.<br><br><br> |





Note: Depending on the platform used, some properties may not be available. For more details, see the property's help page.
