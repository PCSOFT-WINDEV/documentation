
## Organizer control: Customizing appointments
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000195"></a>
In the Organizer control, the appointment is displayed in a specific area. You can translate and customize this area by setting the title color, appointment background color, etc.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Customizing the aspect of appointments
<a name="customizing_the_aspect_appointments_ELTTEXTE000219"></a>
**To change the aspect of the appointments used by default**, you can change the style options defined for this element.  

1. Open the description window of the Organizer control. 

2. In the "Style" tab, select the element related to appointments ("Appointments"; "Selected appointment", "Background of appointments"). 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For example, for "Appointment", you can: 

- use a shadow,

- use a separator in dots between hours, 

- define the title and background options: 

	- solid background,

	- gradient background,

	- Solid background, multiline title and bottom line. This option makes it possible to display the title on several lines, if necessary




- define the fonts used, ...




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) On the "Style" tab, you can customize: 

- the borders, title and details of the appointment. 

- the borders, title and details of the selected appointment.

### Customization using internal windows
<a name="customization_using_internal_windows_ELTPARAGRAPHE000054"></a>

**To fully customize appointments** (required for translation):

1. Open the description window of the Organizer control. 

2. On the "General" tab, select the internal window used for the appointments: 

	- "None": The default display mode will be used. 

	- "Preset window": If this option is selected, the WDAAF internal component is immediately added to the current project. 

		- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The "IW_WinDevViewAPT" internal window is automatically associated with the "Internal window for the appointments" option. 

		- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The "IW_WinDevMobileViewAPT" internal window is automatically associated with the "Internal window for the appointments" option. 


 Remarks: 

- If the WDAAF component already exists, only the window is added to the component.  

- This window is also used to customize appointments in Scheduler controls.  

- Any internal window in your project. 

3. If necessary, click OK in the control description window. 




**Remarks**:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The preset internal window can be used in both Day and Week modes. To enable Month mode, go to the "General" tab of the control description window and check "Use the internal window in "Month" mode".

- The custom internal window is available in the "Project explorer" pane, in the "Internal components" folder. It can be edited in the window editor. 

- The internal window must receive the appointment as a parameter in order to display it. The global variables of the internal window must be declared using the following syntax: 
	
	```txt
	PROCEDURE MyWindow(My_Appointment is dynamic Appointment)
	```


- You can create controls in the internal window to display the various elements of the appointment. These controls display the contents of the variable of type [Appointment](../WDLang1/1000019244.md).

- **Note**: This internal window only allows you to customize the appearance of appointments.. Only the "Global declarations" event is executed. No other events are executed. Therefore, you cannot add buttons with a specific click code. 

- If you are using the suggested preset window, the style options of the appointment (selected in the "Style" tag) are applied.

### Customization using internal pages
<a name="customization_using_internal_pages_ELTPARAGRAPHE000111"></a>

**To fully customize appointments** (required for translation):

1. Open the Scheduler control description window. 

2. On the "General" tab, select the internal page used for appointments: 

	- "None": The default display mode will be used. 

	- "Preset page": If this option is selected, the WDAAF internal component is immediately added to the current project. 
			The "IP_WEBDEVViewAppointment" is automatically associated with the "Internal page for appointments" option. 

	- "New internal page": If this option is selected, a new internal page is automatically created and associated with the control.   

	- Any internal page in the project. 




3. If necessary, click OK in the control description window. 




**Remarks**:

- The preset internal page can be used in both Day and Week modes. To enable Month mode, go to the "General" tab of the control description window and check "Internal page in "Month" mode".   

- The preset internal page can be found in the "Project explorer" pane, in the "Internal components" folder. It can be edited in the page editor. 

- To be displayed, the appointment must be passed to the internal page as a parameter. The declaration of global variables of the internal page must have the following format: 
	
	```txt
	PROCEDURE MyPage(My_Appointment is dynamic Appointment)
	```


- You can create controls in the internal page to display the various elements of the appointment. These controls display the contents of the variable of type [Appointment](../WDLang1/1000019244.md). 

- **Note**: This internal page only allows you to customize the appearance of appointments. Only the "Global declarations" event is executed. No other events are executed. Therefore, you cannot add buttons with a specific click code.

- If you use the preset page, the style options of the appointment (selected in the "Style" tab) will be applied.
