


## ListView control linked to a table (or to a query)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000093"></a>
A ListView control can be used to display the content of a table (or the content of a query).

When a ListView control is linked to a table (or to a query), this control can be initialized with the content of the table:

- or automatically: No specific code is required to initialize the List Box control. The options to loop through the table linked to the control can be defined in the "Content" tab of the control description.

- or by programming: enter the path code of the table linked to the ListView control in the initialization code of the field. This method is not recommended.




The content of two different items is displayed in the ListView control:

- an item corresponding to the captions ("Text" item for example).

- an item corresponding to the images ("Sound, Image, Binary" item for example).




**Note** When creating an Image control ListView control, the wizard suggests the various types of image list. For a ListView control linked to a table or to a query, the wizard asks for the necessary information (table used, items used, etc.).

## Initialization code of a programmed ListView control
<a name="initialization_code_programmed_listview_control_ELTTEXTE000117"></a>
If you are using a ListView control based on a table with programmed initialization, the code for browsing the table must be entered in the initializing code of the control.

**Example** Initialization of a ListView control with photographs from the VOYAGE table.


```wl
// -- Initialization code of ListView control
HReadFirst(TRAVEL, Photo)
WHILE NOT HOut()
	ListAdd(LSV_TravelPhoto, TRAVEL.Photo)
	HReadNext(TRAVEL, Photo)
END
```

## HFSQL thumbnails
<a name="hfsql_thumbnails_ELTTEXTE000141"></a>
The item linked to the images displayed in the ListView control can use HFSQL thumbnails. In this case, the display of images will be optimized.

For more details, see [HFSQL thumbnails](../WDLang4/3044348.md).
