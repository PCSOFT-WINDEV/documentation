
## TmeLine control linked to a table or variable
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000125"></a>
You can create TimeLine controls directly linked to the data. You can create: 

- a **TimeLine field** table: the TimeLine field will be linked to a table or a query. In this case, the table contains the characteristics of the events. 

- a **TimeLine control on a** variable: the TimeLine control is linked to a variable (usually a class instance). In this case, the class lists the events and their characteristics. 




The programming of the TimeLine controls is simplified. 





## How to?
<a name="how_ELTTEXTE000149"></a>


### Creating a data-bound TimeLine control
<a name="creating_databound_timeline_control_ELTPARAGRAPHE000020"></a>

To create a Timeline control based on a table: 

1. Open the control description window (select "Description" in the context menu). 

2. In the "Content" tab, select the "Table/Query" option and select the table source used. This data source can be: 

	- a table defined in the database schema,

	- a query of the project,

	- a query included in the window. 




3. Associate the different items of the data source with the characteristics of the event. The elements preceded by a star are mandatory. 
	**Note**: If the associated table does not directly contain the corresponding item, a multi-table binding can be set up. 

4. Validate the TimeLine control description window. The TimeLine control is bound to a table. 







### Creating a TimeLine control based on a variable
<a name="creating_timeline_control_based_variable_ELTPARAGRAPHE000037"></a>

To create a TimeLine control based on a variable: 

1. Open the control description window (select "Description" in the context menu). 

2. In the "Content" tab, select the "Variable" option and select the data source used (class, etc.). 

3. Associate the different elements (members of the class for example) of the data source with the characteristics of the event. The elements preceded by a star are mandatory. 

4. Validate the TimeLine control description window. The TimeLine control is based on a variable. 








## Handling a data-bound TimeLine control or variable
<a name="handling_databound_timeline_control_variable_ELTTEXTE000179"></a>


### Browsing TimeLine control
<a name="browsing_timeline_control_ELTPARAGRAPHE000049"></a>

Data-bound TimeLine controls are very easy to handle: 

- If the user handles the timeline via the context menu, all additions, deletions and changes made to the events will be automatically applied to the table linked to the control.

- If the user handles the events via a specific window, simply modify the table linked to the timeline. The displayed data will be automatically updated. It is also possible to use [TimelineDisplay](../WDLang1/1000020683.md) to update the data displayed in the control. 




**Remark**: If the field is linked to a data source, any deletion made in the field is also made in the linked data source.. 


### TimeLine control based on a variable
<a name="timeline_control_based_variable_ELTPARAGRAPHE000065"></a>

TimeLine controls based on a variable are very easy to handle: 

- If the user handles the timeline via the context menu, all additions, deletions and changes made to the events will be automatically applied to the data source of the control.

- If the user handles the events via a specific window, simply modify the elements linked to the timeline (class members for example). The displayed data will be automatically updated. It is also possible to use [%00000048% %00000048%](../WDLang1/1000020683.md) to update the data displayed in the control. 




**Remark**: If the field is linked to a data source, any deletion made in the field is also made in the linked data source..
