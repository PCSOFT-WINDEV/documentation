


## Crosstab report
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000194"></a>
The report editor lets you create "Crosstab" type reports. In this case, the report contains a double-entry table only.

**Example**: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=etatTableaucroise2.gif&type=thumb)


**Data source of the Crosstab report**: 
The Crosstab report can be based: 

- on one or more tables. In this case, an embedded query is used. This query is created via the wizard for creating a "Crosstab" report. For more details, see [Creating a Crosstab report based on a query](#NOTE2_1). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Pivot Table control. For more details, see [Pivot Table report](../WDChamp/1011092.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) no data source: this option can be used, for example, to specify the Pivot Table control field to be used only at runtime, using the [SourceName](../Proprietes/2511035.md) property.




**Note** If the "Crosstab" report is based on a query, you can modify the embedded query in the Query Editor. To edit the embedded query in the query editor:

1. Select "Description" in the context menu of the report. The description window of the report is displayed.

2. Go to the "Data" tab.

3. Click the "Edit" button.

## Creating a Crosstab report based on a query
<a name="creating_crosstab_report_based_query_ELTTEXTE000218"></a>
To create a "Crosstab" report based on a query: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons: 

2. The new element window appears. Click "Report", and then "Report".

3. The report creation wizard opens. Select "Crosstab".

4. The wizard then asks you to select the report source: choose "From one or more files". 




In this wizard, you must specify:

- the item corresponding to the captions of the columns.
	**Note** If this field is of type "Date", the wizard suggests:

	- keep the day, the month or the year only for these dates.

	- define the period to take into account (start date and end date).




- the item corresponding to the captions of the rows.
	**Note** If this field is of type "Date", the wizard suggests:

	- keep the day, the month or the year only for these dates.

	- define the period to take into account (start date and end date).




- the information that will be displayed in the table cells. This information can correspond to:

	- either **the number of records corresponding to the intersection of rows and columns**.
			For example: the number of orders placed per year and per customer. The customer named "Smith" has placed 2 orders in 2000 and 3 orders in 2001.

	- the **sum, the average, the maximum or the minimum of an item**.
			For example: the number of products ordered per product and per year. In 2000, 279 sofas were ordered.

	- an **item**.
			For example: the score awarded by each referee to an ice skater. At the 2000 European Championships, the Italian judge awarded 5.2 to skater "A".




- the calculation of totals for the table rows and columns (if necessary).

- the format of the page on which the report will be printed. The report is printed in A4 format by default.

- the theme of the report (if necessary).

- the name and title of the report. This name (".WDE". file corresponding to the report) will be used to identify the report in your programs.




The new report contains a Table control to display the data. 

Note: When printing a crosstab report, if the report format does not allow all the columns in the array to be displayed, the array is automatically adapted to the report print format (font reduction and column size adaptation).

## Creating a Crosstab report based on a Pivot Table control
<a name="creating_crosstab_report_based_pivot_table_control_ELTTEXTE000242"></a>
To create a "Crosstab" report: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

2. The new element window appears. Click "Report", and then "Report".

3. The report creation wizard opens. 

4. In this wizard, specify:

	- the type of report you want to create: "Crosstab".

	- the Pivot Table control used as data source.

	- the theme of the report (if necessary).

	- the name and title of the report. This name (".WDE". file corresponding to the report) will be used to identify the report in your programs.







The new report contains a Pivot Table control to display the data. 




### Pivot Table control (Report editor) features
<a name="pivot_table_control_report_editor_features_ELTPARAGRAPHE000125"></a>

You can configure the following features of a Crosstab report containing a Pivot Table control: 

- The data source of the report can be modified in the "Data" tab of the description window of report ("Report description" in the context menu of the report). 

- The "General" tab of the Pivot Table control description window is used to specify: 

	- **the cell width calculation mode**. The following options are available:

		- Use the width defined in edit mode: The width of the cells will be the same as the one defined in the report editor.
						Note: You can use the sizing handles to resize the data area in the Pivot Table control in the report. 

		- Fill pages horizontally as much as possible: Cells will grow to fill the available space on the page.

		- Avoid truncated cells: When possible, cells will be enlarged to display all the data they contain.




- **the dimension expansion mode**. The following options are available:

	- Like the control: The level of detail displayed in the report will be the same as that of the Pivot Table control used as the data source.

	- All expanded: All the data of the Pivot Table control will be displayed.

	- All collapsed: Only the first level of detail of the Pivot Table control will be displayed.

- In the "Style" tab of the Pivot Table control description, you can check "Define style independently of the printed PVT control" to define a specific style for the control in the report. If this option is checked, you have the ability to specify the style for the row headers and for the data.
