
## Manipulating Button controls programmatically
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000270"></a>
WINDEV, WINDEV Mobile and WEBDEV allow you to programmatically manipulate Button controls. To do so, use the variable of the Button control in the code.

The variable of the Button control:

- corresponds to the name of the Button control.

- is initialized with the caption of the Button control.

## Retrieving and modifying the caption of the Button control
<a name="retrieving_and_modifying_the_caption_the_button_control_ELTTEXTE000294"></a>


### Retrieving the caption
<a name="retrieving_the_caption_ELTPARAGRAPHE000023"></a>

To retrieve the caption of the Button control, use the following syntax:

- direct syntax: 
	
	```txt
	<Caption> = <Button control>
	```





- using the [Caption](../Proprietes/2510053.md) property: 
	
	```txt
	<Caption> = <Button control>.Caption
	```





&lt;Caption&gt; is Character String variable.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: If the label is in RTF ("RTF" option checked in the "General" tab of the field description), the recovered label will contain the RTF tags. To get the caption without the RTF tags, use [RTFToText](../WDLang1/3025032.md). 
For example: 


```wl
MyCaption is string
MyCaption = RTFToText(BTN_Button.Caption)
```

<a name="NOTE2_2"></a>


### Changing the caption
<a name="changing_the_caption_ELTPARAGRAPHE000056"></a>

To modify the caption of the Button control, use the following syntax:


```txt
<Button control> = <Caption>
```


&lt;Caption&gt; is Character String variable.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: If the label is in RTF ("RTF" option checked in the "General" tab of the field description), the new label may or may not contain RTF text.

## Changing the target of a Button control
<a name="changing_the_target_button_control_ELTTEXTE000348"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The target of a Button control is defined in the page editor at the same time as the action to perform (in the description window of the Button control). For more details, see [Action associated with the Button control](../WDChamp/1013071.md).

WEBDEV allows you to change this target programmatically. Indeed, in some sites, the target of a Button control can be modified according to the action performed by the Web user.

**Example** If you enter your name and password:

- if the password is correct, the application continues in the current page

- if the password is incorrect, a new browser is opened to ask for the name and password again.




In this example, in most cases, the Web user will enter a correct password. The error is an exception.
<a name="NOTE4_2"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### To use a simple target (frame of the frameset for example) in most cases and a new browser in some cases:
<a name="use_simple_target_frame_the_frameset_for_example_most_cases_and_new_browser_some_cases_ELTPARAGRAPHE000121"></a>

1. In the Button control description, define the "simple" target (frame of the frameset, current browser, etc.).

2. In the browser code of the Button control, use [ChangeTarget](../WDLang2/3058005.md):
	
	```txt
	IF <Condition> THEN
		// Change the target
		// Display in a new browser
		ChangeTarget(NewBrowser, "New")
	END
	```




<a name="NOTE4_3"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### To open a browser in most cases and to use a specific destination in some cases:
<a name="open_browser_most_cases_and_use_specific_destination_some_cases_ELTPARAGRAPHE000136"></a>

1. In the Button control description, define the "New browser" target by defining the parameters of the new browser.

2. In the browser code of the Button control, use [ChangeTarget](../WDLang2/3058005.md):
	
	```txt
	IF <Condition> THEN
		// Change the target
		// Display in the "FRM_Target" frame
		ChangeTarget(FRM_Target)
	END
	```

## Modifying the image displayed in the Button control
<a name="modifying_the_image_displayed_the_button_control_ELTTEXTE000384"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) To change the image displayed in the Button control, use the [Image](../Proprietes/2510034.md) property:


```txt
<Button control>.Image = <Image path>
```


&lt;Image path&gt; is a Character String variable

The following image formats are supported in Windows:

- Bitmap (\*.BMP)

- Graphics Interchange Format (\*.gif)

- Joint Picture Experts Group (\*.jpg ; \*.jpeg)

- Kodak Photo CD (\*.pcd)

- PaintBrush (\*.pcx)

- Adobe Photoshop Format (\*.psd)

- TrueVision TARGA (\*.tga)

- Tagged Image File Format (\*.tif ; \*.tiff)
	Note: the "Tiled TIFF" option in TIFF 6.0 is not supported. In this case, we advise you to save the image in tiff 5.0 standard. 

- Portable Network Graphics (\*.png)

- Windows MetaFiles (\*.emf ; \*.wmf)

- Icons (\*.ico ; \*.icw)
	Remarks: 

	- HQ display (High Quality) available.

	- Management of sheets in transparent BMP format (32 bits).




- Cursors (\*.cur)

- Portable Document Format (\*.pdf)

- Scalable Vector Graphics (\*.svg)

- WINDEV images (generated by the image editor, \*.WDPIC).

- Images in WebP format (\*.webp). 




**Note** To manage TIFF, GIF and JPEG images, Wxxximg.dll must be installed with the other WINDEV DLLs.
<a name="NOTE5_2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### To change the image of a Button control in browser code
<a name="change_the_image_button_control_browser_code_ELTPARAGRAPHE000171"></a>

1. Save the new image in the "&lt;ProjectName&gt;_WEB" directory.

2. Use the [FolderWeb](../WDLang2/3012015.md) function. For example:
	
	```wl
	BTN_IMAGE = FolderWeb() + "/VSXP15022_MODIF.gif"
	```

## Properties specific to the management of images in a Button control
<a name="properties_specific_the_management_images_button_control_ELTTEXTE000448"></a>
The following properties are used to programmatically handle the images used in a Button control.


|   |   |
| --- | --- |
| [BackgroundImage](../Proprietes/2510056.md) | Allows you to find out and modify the image associated with the border of a Button control. |
| [BackgroundImageState](../Proprietes/2510057.md) | Allows you to find out and modify the number of drawings found in the image associated with the border of a Button control. |
| [Image](../Proprietes/2510034.md) | Allows you to find out and modify the image of a Button control. |
| [ImageState](../Proprietes/2510055.md) | Allows you to find out and modify the number of drawings found in the image associated with a Button control. |
| [Pushed](../Proprietes/2510038.md) | Enables you to view and modify the status of a Button control field (button pressed or not). |
| [Value](../Proprietes/2510130.md) | Allows you to find out and modify the caption of a Button control. |


For a complete list of WLanguage properties that can be used with Button controls, see [Button control properties](../WDChamp/1013127.md).
