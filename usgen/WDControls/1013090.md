


## Properties associated with the attributes of a Looper control
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000102"></a>
The attributes of a Looper control found in a window or in page can be handled by the WLanguage properties.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Properties available in a window
<a name="properties_available_window_ELTTEXTE000126"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Properties that can be used in a window
<a name="properties_that_can_used_window_ELTPARAGRAPHE000020"></a>The following properties can be used with the attributes of the loopers:



|   |   |
| --- | --- |
| [DataBinding](../Proprietes/2510060.md) | The **DataBinding** property gets and changes the binding between a control and:<br><br>- a table item.<br><br>- a variable. <br><br>- several variables. <br><br><br> |
| [FullName](../Proprietes/2514005.md) | The **FullName** property is used to find out the full name:<br><br>- of a control.<br><br>- of a window.<br><br>- of a menu option.<br><br>- of a table column.<br><br><br><br><br> |
| [Name](../Proprietes/2510082.md) | The **Name** property is used to get:<br><br>- the name of the font associated with a Font variable.<br><br>- the name of a control, report or report block.<br><br>- the name of a control, group of controls or window.<br><br>- the name of a control, group of controls or page.<br><br><br> |
| [Pane](../Proprietes/1000021098.md) | The **Pane** property is used to: <br><br>- Find out the pane tabs associated with a control. <br><br>- Define the pane tabs associated with a control.<br><br><br> |
| [Value](../Proprietes/2510130.md) | The **Value** property is used to:<br><br>- Find out and modify the value of a report control.<br><br>- Find out and modify the value of a control or the title of a window.<br><br>- Find out the identifier of a stream. <br><br>- Find out and modify the value of a control or the title of a page.<br><br><br> |
| [WinEditAllowed](../Proprietes/1000021850.md) | The **WinEditAllowed** property is used to determine and configure the actions allowed on a control when the window switches to "Allow end users to modify the UI" mode. |



Note: Depending on the platform used, some properties may not be available. For more details, see the property's help page.

### Properties that can be used in a page (Server code)

|   |   |
| --- | --- |
| [Alias](../Proprietes/2510004.md) | The **Alias** property is used to: <br><br>- get or change the alias of a window (WINDEV and WINDEV Mobile).<br><br>- get or change the alias of a dynamic tab (WINDEV).<br><br>- get the internal HTML/JavaScript name of a control (WEBDEV).<br><br><br> |
| [DataBinding](../Proprietes/2510060.md) | The **DataBinding** property gets and changes the binding between a control and:<br><br>- a table item.<br><br>- a variable. <br><br>- several variables. <br><br><br> |
| [FullName](../Proprietes/2514005.md) | The **FullName** property is used to find out the full name:<br><br>- of a control.<br><br>- of a window.<br><br>- of a menu option.<br><br>- of a table column.<br><br><br><br><br> |
| [Name](../Proprietes/2510082.md) | The **Name** property is used to get:<br><br>- the name of the font associated with a Font variable.<br><br>- the name of a control, report or report block.<br><br>- the name of a control, group of controls or window.<br><br>- the name of a control, group of controls or page.<br><br><br> |
| [Process](../Proprietes/1000020878.md) | The **Process** property is used to modify the processes to be executed by the events available on a control, window, page, report, etc. |
| [SortOption](../Proprietes/1000017044.md) | The **SortOption** property gets and sets the sort options used in:<br><br>- text columns in Table controls,<br><br>- text columns in Treeview Table controls, <br><br>- List Box and ListView controls,<br><br>- Combo Box controls,<br><br>- attributes of Looper controls, <br><br>- images, clickable images and thumbnails with automatic sequence.<br><br><br> |
| [Type](../Proprietes/2510131.md) | The **Type** property is used to get:<br><br>- the type of element (table or item) defined programmatically or in the data model editor, view or query.<br><br>- the type of object.<br><br>- the type of data held in a Variant.<br><br><br> |
| [Value](../Proprietes/2510130.md) | The **Value** property is used to:<br><br>- Find out and modify the value of a report control.<br><br>- Find out and modify the value of a control or the title of a window.<br><br>- Find out the identifier of a stream. <br><br>- Find out and modify the value of a control or the title of a page.<br><br><br> |
