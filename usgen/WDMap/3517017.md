


## WDMap: Add, modify and delete records in a table
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000144"></a>
WDMap allows you to perform simple operations (addition, modification or deletion) on the records found in a table.

These operations can only be performed while developing the application (WDMap cannot be redistributed).

For example, you can add, modify or delete records before the corresponding windows are created in your application. You can also directly run the test of your processes.

**Warning**: If you are working with fields in linked tables (in the table model editor), it is advisable to activate integrity and duplicate management. 
The integrity management and the duplicate management are enabled by default. 
Integrity management is only enabled if the original database schema of the table is known: integrity management is not enabled if the table is opened directly in the explorer with WDMap.

**Remarks**:

- To enable the management of integrity, select "Parameters .. Management of integrity". 
	**Warning**: It is sometimes necessary to manually locate the tables linked to the manipulated table. To manually locate missing tables, click on the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=IconeGestionIntegrite.gif) icon and select the directory of each table contributor to the integrity management of the current table.

- To enable the management of duplicates, select "Parameters .. Management of duplicates".

## Adding a record into a table
<a name="adding_record_into_table_ELTTEXTE000168"></a>
To add a record into a table:

1. Display the table into which the record will be added (for more details, see [Viewing the records found in a table](../WDMap/3517012.md)).

2. Select "Edit .. Add a record" (or click the first empty row of viewing table). A new row is added to the viewing table.

3. In this new row, enter the values corresponding to the new record.
	**Note**: To move from one column to another, use the arrow keys on the keyboard.

4. Click a different row to validate the addition.
	**Note**: If duplicate handling is enabled and a duplicate error is detected, the HFSQL security mechanism is triggered. Modify the values and validate.




**Note**: WDMap also allows you to duplicate a record:

1. Select the record to duplicate.

2. Select "Edit .. Duplicate a record" (or press Ctrl + D).

## Modifying a record in a table
<a name="modifying_record_table_ELTTEXTE000192"></a>
To modify a record in a table:

1. Display the table where the record will be modified (for more details, see [Viewing the records found in a table](../WDMap/3517012.md)).

2. Select the record to modify in the viewing table.

3. Click the column to modify. The input cursor is displayed.

4. Enter the new value.

5. Click another row to validate the modification.
	**Note**: If duplicate handling is enabled and a duplicate error is detected, the HFSQL security mechanism is triggered. Modify the values and validate.




**Batch processing**: WDMap allows you to modify all the records displayed in a single operation:

1. Select "Edit .. Modify these records".

2. Select "&lt;Initialization&gt;" in the rows corresponding to the items to modify.

3. Enter the new values.

## Deleting a record from a table
<a name="deleting_record_from_table_ELTTEXTE000216"></a>
To delete a record from a table:

1. Display the table from which the record must be deleted (for more details, see [Viewing the records found in a table](../WDMap/3517012.md)).

2. Select the record to delete in the viewing table.

3. Select "Edit .. Delete the record" (or press the Del key).

4. Confirm the deletion.
	**Note**: An error message appears if integrity is managed and an integrity rule is applied to the deleted record. The record will not be deleted.




**Tip**: All recordings viewed can be deleted in a single operation using the "Edit . Delete all records".
