## Overview
<a name="overview_ELTTEXTE000206"></a>
WDMap is a tool used to view and handle a table while developing an application. **This tool is only available in 32-bit mode.**

WDMap can be used to:

- Quickly check the content of a record.

- Test an application with meaningful data.




The table used can be:

- in HFSQL format (Classic or Client/Server). 

- in Hyper File 5.5 format

- accessed via an OLE DB provider, an ODBC driver or a native access.

## Starting WDMap
<a name="starting_wdmap_ELTTEXTE000230"></a>


### Starting WDMap
<a name="starting_wdmap_ELTPARAGRAPHE000055"></a>

WDMap can be started:

- from the data model editor: under "Database schema", in the "Table" group, click "Edit with WDMap",

- from the ribbon: under the "Tools" pane, in the "Database" group, click on "WDMap",

- by running "WDMAP.EXE" directly.




**Remark**: If WDMap is launched from the data model editor:

- The physical file corresponding to the description of the selected table will be created if necessary.

- To take into account the modifications performed on the table description, we advise you to generate the database schema before viewing the table content.



<a name="NOTE2_2"></a>


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000095"></a>

WDMap cannot be redistributed. WDMap cannot be installed with the applications developed with WINDEV or WEBDEV.

To use WDMap , WINDEV, WEBDEV or WINDEV Mobile must be installed on the current computer.

## Notes
<a name="notes_ELTTEXTE000284"></a>


- WDMap can be used to view a single file at a time.

- If the database schema is password protected (runtime password defined in the database schema description), this password is requested when the database schema is selected in WDMap.

- If the table is password protected (password defined by [HPass](../WDLang4/3044108.md), [HCreation](../WDLang4/3044255.md) or [HCreationIfNotFound](../WDLang4/3044254.md), or during the [automatic data modification](../WDLang4/3044195.md)), this password will be requested when the physical file is selected in WDMap.

- It is possible to view data in an HFSQL Client/Server table: for example, if the database schema tables are defined as Client/Server, with one connection, the "Edit table with WDMAPEdit table with WDMAP" option opens the server table according to the defined connection.
