


## WDMap: Reindexing an HFSQL table
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000119"></a>
WDMap can be used to determine whether an HFSQL table needs to be reindexed, as well as to reindex an HFSQL table.

- ***Normal reindexing***: Classic reindexing (with statistics and without compaction).

- ***Reindexing with Compaction***: Reindexing with compaction (retains only active records. All the crossed or deleted records are permanently deleted).




**Reminder**:

- The indexes are reorganized by the reindex operation. After the indexing operation, the access to indexes is optimized. The indexing operation may be required if the index file is lost or damaged.

- WDMap allows you to easily reindex a table. However, to reindex a table more completely, use the [WDOptimizer](../WDOptimiseur/3519002.md) tool.

- A table can also be reindexed using Windows Explorer. Simply select the "Optimize" option from the context menu of the table to be re-indexed. Then, the reindexing is performed by [WDOptimizer](../WDOptimiseur/3519002.md).

## How to?
<a name="how_ELTTEXTE000143"></a>


### WDMap started from the editor
<a name="wdmap_started_from_the_editor_ELTPARAGRAPHE000034"></a>

To reindex a table:

1. Display the table to reindex (for more details, see [Viewing the records found in a table](../WDMap/3517012.md)).

2. To perform:

	- a ***normal reindexing***: select the "Tools ... Reindexing . Normal" option.

	- a ***reindexing with compaction***: select the "Tools . Reindexing . With compaction".






<a name="NOTE2_2"></a>


### WDMap started by the "WDMAP.EXE" program
<a name="wdmap_started_the_wdmapexe_program_ELTPARAGRAPHE000050"></a>

To reindex a table:

1. In the wizard, select "Reindex a file" and go to the next step.

2. Select the table to be reindexed and confirm.




Remarks:

- If the table is password-protected (password defined either by [HPass](../WDLang4/3044108.md), [HCreation](../WDLang4/3044255.md) or [HCreationIfNotFound](../WDLang4/3044254.md), or by [automatic data modification](../WDLang4/3044195.md)), specify the password.

- If the table comes from a 5.5 database schema, specify the full path to the original database schema and the password for this database schema.
