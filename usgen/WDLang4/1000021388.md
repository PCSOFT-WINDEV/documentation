


## &lt;Window&gt;.FromSource (Function)

***In french: &lt;Fenêtre&gt;.DepuisSource***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Automatically updates the controls in a window or page with:

- the values of the bound items in the current record (loaded in memory) of the HFSL table described in the data model editor. 

- the values of the bound WLanguage variables. 


This operation is performed regardless of the state of the controls (grayed, inactive or invisible).

**Remarks**: 

- **&lt;Window&gt;.FromSource** does not read records on the table. The value of the record loaded in memory is used to update the controls. Therefore, a record must be loaded in memory previously: 

	- [&lt;Source&gt;.Read](../WDLang4/1000025019.md), [&lt;Source&gt;.ReadSeek](../WDLang4/1000025023.md), [&lt;Source&gt;.ReadFirst](../WDLang4/1000025022.md), etc. 

	- [&lt;Looper&gt;.Display](../WDLang2/1000023451.md) for a Looper control, etc.




- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is also available for WEBDEV pages. It is equivalent to [&lt;Page&gt;.FromSource](../WDLang4/1000021393.md). 

- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the binding to the table items is supported. Bindings to WLanguage variables are not supported in this version.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Searches for customer in the table
CUSTOMER.ReadSeekFirst(NAME, "PAUL")
IF CUSTOMER.Found() = True THEN
	// Displays the client found in the current window
	WIN_Customer.FromSource()
END

// Read the record and
// transfer items to the controls in WIN_Customer
CUSTOMER.ReadFirst(NAME)
WIN_Customer.FromSource()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Window>.FromSource([<Source>])`
---

**`<Window>: (Window name)`**

Name of the window or page containing the controls to be updated.

Summary: Called when a control gains focus.

**`<Source>: (Optional character string)`**

Name (in quotation marks) of the source the controls to be updated are bound to. This source can be:

- The name of a table: only fields linked to a field in this table are taken into account.

- The name of a WLanguage variable. In this case, only the controls bound to the WLanguage variable are taken into account.
	Remarks: 

	- If the name of the variable is enclosed in quotes, the control will be bound to the specified variable. 

	- If the name of the variable is not enclosed in quotes, the control will be bound to the variable data (e.g., a variable containing the name of another variable).





If this name is not specified, all the window controls bound to a table item described in the data model editor or to a WLanguage variable will be taken into account.

<a name="NOTE0_1"></a>

## Remarks


### Binding between a control and a WLanguage variable or between a control and a table item
<a name="binding_between_control_and_wlanguage_variable_between_control_and_table_item_ELTPARAGRAPHE000263"></a>

The binding between a control and a WLanguage variable or between a control and a table item can be determined:

- In the editor, in the control description window ("Binding" tab).

- Programmatically, with the [DataBinding](../Proprietes/2510060.md) property.



<a name="NOTE0_2"></a>


### Linking to a field: types of links
<a name="linking_field_types_links_ELTPARAGRAPHE000279"></a>

There are two types of bindings between a control and an item

- *direct binding*: In this case, **&lt;Window&gt;.FromSource** transfers the value of the items from the record loaded in memory to the bound control, without reading any values.

- *binding by reading the records in the associated table*.



<a name="NOTE0_3"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000294"></a>

- **Auto-filled Combo Box control bound to an HFSQL table**: **&lt;Window&gt;.FromSource** must not be in the "Global declarations" event of the window. The function must be in the "Initialization" event of the window.

- Space characters in HFSQL items are kept.

- **&lt;Window&gt;.FromSource** updates Image controls with the value of the bound image memo items.

- **&lt;Window&gt;.FromSource** supports the NULL value. If the item content is NULL, an empty string will be displayed in the bound Edit control. To change this display mode, use [ControlError](../WDLang1/3025036.md).

- **&lt;Window&gt;.FromSource** is not available on views. The values of the items must be assigned to each control.

- **Binding with "Secure Password" items**:

	- In an Edit control bound to a Password item, "\*\*\*\*\*" characters are displayed. If the Edit control is of type "Password", dots are displayed instead. 

	- The value of the "Password" item cannot be read again until the user changes the password value.

	- The value of the "Password" item can still be compared to a string (e.g., "" or "1234").
