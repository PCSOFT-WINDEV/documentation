


## &lt;Source&gt;.CheckIndex (Function)

***In french: &lt;Source&gt;.VérifieIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the data found in the index file (.NDX file) properly refers the data found in the table (.FIC file). This function applies to the HFSQL tables (Classic or Client/Server) only. 

![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The HFSQL Client/Server table is automatically locked during the verification.![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The indexes of an HFSQL Client/Server table can be checked asynchronously using [&lt;HFSQL connection&gt;.CheckIndexAsynchronous](../WDLang4/1410091223.md). 


**Reminder**: An index is corrupted when one of the records it references is not the one expected. In this case, the table must be reindexed.

<a name="sample_code"></a>

## Example


```wl
// Check the index
let IndexResult = Customer.CheckIndex()
// Manage the result
SWITCH IndexResult
	CASE 0
		Info ("The index is correct")
	CASE 1
		Info("The file must be optimized.")
	CASE 2
		Info("HFSQL error" + HError() + " during the test")
END
```

## Syntax

`<Result> = <Source>.CheckIndex([<Key item> [, <Progress Bar>]])`
---

**`<Result>: (Integer)`**

Can correspond to: 

- 0 if the check is correct.

- 1 if the index is corrupted. This means that a reindex is required ([&lt;Source&gt;.Index](../WDLang4/1000025060.md)).

- 2 in the event of an HFSQL error: Inaccessible table, etc.

- 3 if the function is not supported by this type of table (xBase, AS400, etc.).




**`<Source>: (Type corresponding to the specified source)`**

Name of the table used. 

**`<Key item>: (Optional character string)`**

Name of the key item to check. If this parameter is not specified, all the keys of the table are checked.

**`<Progress Bar>: (Optional control name or window name)`**



- Name of the window in which the progress bar will be displayed, 

- Name of the Progress Bar control to use. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter is ignored.

## Remarks


### Corrupted index
<a name="corrupted_index_ELTPARAGRAPHE000246"></a>

When the function detects a problem in the index file, the **H.Comment** variable contains:

```txt
<Name of affected key> + TAB + <Record number causing problem> + CR + 
<Name of affected key 2> + TAB + <Record number causing problem 2> ...
```

&lt;Record number causing problem&gt; is equal to -1 if no record was defined.

**Note**: If the index file is entirely corrupted, no values are specified for the *H.Comment* variable.
