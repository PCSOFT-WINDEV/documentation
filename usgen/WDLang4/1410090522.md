


## &lt;Polygon2D variable&gt;.Contain (Function)

***In french: &lt;Variable Polygone2D&gt;.Contient***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if geometry A (of type 2D polygon) contains geometry B.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FormeContient.gif)
**Remarks**: 

- If geometry A "contains" geometry B, this means that geometry B lies completely inside geometry A. In this case: 

	- No point of geometry B lies outside geometry A. All points of geometry B are either in the interior or on the boundary of geometry A.

	- The interiors of A and B have at least one point in common.




- Difference compared with [&lt;Polygon2D variable&gt;.Cover](../WDLang4/1410090526.md): With [&lt;Polygon2D variable&gt;.Cover](../WDLang4/1410090526.md), the interiors of both geometries must not necessarily have a point in common. A polygon covers its own boundary, but it does not contain it.

## Example


```wl
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-4.00, -4.00)
o2DPolygon_1.Outline.AddPoint(-4.00, 2.00)
o2DPolygon_1.Outline.AddPoint(5.00, 2.00)
o2DPolygon_1.Outline.AddPoint(5.00, -4.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-4.00, -4.00)

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(-1.00, -2.00)
o2DPolygon_2.Outline.AddPoint(2.00, 0.00)
o2DPolygon_2.Outline.AddPoint(2.00, -2.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(-1.00, -2.00)

let p2_in_p1 = o2DPolygon_1.Contain(o2DPolygon_2) // Returns "True"
o2DPolygon_2.Within(o2DPolygon_1) // Returns "True"
```

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Contains(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if geometry A contains geometry B,

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

## Remarks


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000350"></a>

In a table, you can apply a filter on spatial data and loop through the table. For example, the filter can be based on the result of **&lt;Polygon2D variable&gt;.Contain**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;Polygon2D variable&gt;.Contain**. 

- Spatial_item is a spatial item in the table. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire table is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
