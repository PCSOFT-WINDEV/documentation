


## HInfoAnalysis (Function)

***In french: HInfoAnalyse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about a database schema (WDD file).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(HInfoAnalysis())
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HInfoAnalysis([<Path of the WDD file> [, <Password of the WDD file>]])`
---

**`<Result>: (Character string)`**

Database schema information. This information uses the following format: 

```txt
<GUID Analyse> + RC + <Numéro génération>
```


**`<Path of the WDD file>: (Optional character string)`**

Full path of the database schema (.WDD file) to use. 
If this parameter is not specified or is an empty string (""), the current database schema is used.
Projects with multiple database schemas: If several database schemas are underway, only the main database schema is taken into account.

**`<Password of the WDD file>: (Optional string or Secret string)`**

Password defined for the database schema. If no password is defined, this parameter must be an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
