


## MultiPolygon2D (Variable type)

***In french: MultiPolygone2D***
			
				



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **MultiPolygon2D** type can be used to store a collection of non-overlapping polygons defined with 2D coordinates.

A variable of type **MultiPolygon2D** can be used to store a collection of polygons defined with 2D coordinates in a single HFSQL record. This avoids having to use one record for each polygon. This type of variable is necessary, for example, if the collection of polygons corresponds to the entity manipulated by a program (in this case, each polygon is not manipulated independently).

To be considered valid, a multipolygon must meet certain criteria:

- All polygons belonging to a multipolygon must be valid.

- The interiors of polygons belonging to a multipolygon must not intersect.

- The boundaries of two polygons in the same multipolygon can only intersect at a tangent point: they cannot have a continuous segment in common. Therefore, two polygons can only touch at a finite number of points.




You can check the validity of a multipolygon using [GeometryIsValid](../WDLang4/1410090158.md).

**Remark**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Properties


### Properties specific to MultiPolygon2D variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000038"></a>

The following properties can be used to manipulate a variable of type **MultiPolygon2D**:

| Property name | Type used | Effect |
| --- | --- | --- |
| Polygon | Array of [Polygon2D](../WDLang4/1410090122.md) | Polygons in the variable. |
| Type | Integer constant | Type of the current geometry. For a collection of polygons defined with 2D coordinates, corresponds to the *gtMultiPolygon2D* constant.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPolygon2D*.<br><br>**This property is available in read-only.** |
