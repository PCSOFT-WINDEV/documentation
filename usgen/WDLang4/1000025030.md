


## &lt;Source&gt;.WatchStop (Function)

***In french: &lt;Source&gt;.SurveilleStop***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***Source.TackStop*</**>** is kept for backward compatibility. This function has been replaced with ***&lt;Source&gt;.WatchStop*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops watching a table on an HFSQL server. This watch task was started with [&lt;Source&gt;.Watch](../WDLang4/1000025029.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Starts watching the Order table
// The ProcessOrder procedure is called whenever a record is added to the table
Order.Watch(ProcessOrder, hRecNumAll, hwAdd)
...
// Stops watching the Order table
Order.WatchStop(ProcessOrder, hRecNumAll)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Source>.WatchStop(<WLanguage procedure> [, <Record number>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the watch task was stopped,

- <u><u><u><u>False</u></u></u></u> otherwise (watch task not found, for example). To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Source>: (Type corresponding to the specified source)`**

Name of HFSQL table to use. 

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure that should no longer be called to watch the table.

**`<Record number>: (Optional integer)`**

Number of the record that will no longer be watched. 
If this parameter is not specified or corresponds to the *hRecNumAll* constant, **&lt;Source&gt;.WatchStop** will stop watching all the table records (i.e. the entire table).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
[&lt;Source&gt;.Watch](../WDLang4/1000025029.md) and **&lt;Source&gt;.WatchStop** can be used in a Windows service.
