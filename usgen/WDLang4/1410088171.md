


## RedisGet (Function)

***In french: RedisRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the value of a key from a Redis server as a string.

Note: To retrieve the value of a key as a binary string, use the [RedisExecuteCommand](../WDLang4/1000023541.md) function.

This function can also be used to manipulate data on a Valkey server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
gRedis is redisConnection
gRedis.Server = "MyRedisServer:7001"

RedisSet(gRedis, "MyKey", "MyValue", 1h)
Trace(RedisGet(gRedis, "MyKey"))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = RedisGet(<Connection> , <Key>)`
---

**`<Result>: (Character string)`**



- Key value.

- Null, if the key has no value. 




**`<Connection>: (redisConnection variable)`**

Name of the [redisConnection](../WDLang4/1000023527.md) variable that corresponds to the Redis server connection.

**`<Key>: (Character string or Secret string)`**

Name of the key to get.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
