


## HCheckMemo (Function)

***In french: HVérifieMémo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the structural integrity of memos in an HFSQL table.

![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The structural integrity of memos in an HFSQL Client/Server table can be checked asynchronously using [HCheckMemoAsynchronous](../WDLang4/1410091107.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF HCheckMemo(Customer, PROGBAR_ProgBar1) <> "" THEN
	Info("Memo corrupted")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HCheckMemo(<Table name> [, <Progress Bar>])`
---

**`<Result>: (Character string)`**



- Empty string ("") if there is no problem. 

- In case of problem, string in the following format: 
	
	```txt
	<Item 1> + TAB + <Record number 1> + CR + ...
	<Item N> + TAB + <Record number N>
	```
 where: 

	- &lt;Item X&gt; is the memo item, 

	- &lt;Record number&gt; is the number of the record containing the Memo item. 




- ![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) In the event of corruption of the list of free blocks, &lt;Résultat&gt; will be of the form: 
	
	```txt
	<TAB> + "-1"+ CR + <Item 1> + TAB + <Record number 1> + CR + ...
	<Item N> + TAB + <Record number N>
	```





**`<Table name>: (Character string)`**

Name of the HFSQL table to check.

**`<Progress Bar>: (Optional window or control name)`**



- Name of the window in which the progress bar will be displayed. 

- Name of the Progress Bar control.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter is ignored.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The list of free blocks is checked in HFSQL Client/Server only.

- **HCheckMemo** is faster than [HIndex](../WDLang4/3044133.md) with the *hCheckMemo* constant.. 

- If a problem is detected, you can use [HIndex](../WDLang4/3044133.md) with the *hCheckMemo* constant. 

- From version 27 onwards, memo verification has been enhanced and deepened, which may result in longer processing times.
