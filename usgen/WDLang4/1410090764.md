
## hSchedulingHistory (Variable type)

***In french: hHistoriquePlanification***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **hSchedulingHistory** type is used to get all the characteristics of the execution history of a scheduled job (optimization, backup, etc.). These characteristics can be identified using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
mySchedule is hSchedulingHistory
```





<a name="PROPS"></a>

## Properties


### WLanguage properties that can be used with the hSchedulingHistory type
<a name="wlanguage_properties_that_can_used_with_the_hschedulinghistory_type_ELTPARAGRAPHE000026"></a>

The following properties can be used to define the characteristics of **hSchedulingHistory** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| StartDate | DateTime | Start date and time of the scheduled job.<br>**This property is read-only**. |
| EndDate | DateTime | End date and time of the scheduled job.<br>**This property is read-only**. |
| Error | Character string | Error encountered (if the **Status** property is set to the *hExecSchedulingError* constant). |
| Identifier | Integer | Identifier of the scheduled job execution. <br>**This property is read-only**. |
| ManualRun | Boolean | <br><br>- <u><u><u>True</u></u></u> if the scheduled job was started manually (i.e. via a WLanguage function or via the HFSQL Control Center),<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**. |
| Status | Integer | Status of the scheduled job execution: <br><br>- *hExecSchedulingCanceled*: The execution of the scheduled job has been canceled. <br><br>- *hExecSchedulingInProgress*: The scheduled job is being executed. <br><br>- *hExecSchedulingError*: The execution of the scheduled job encountered an error. <br><br>- *hExecSchedulingCompleted*: The execution of the scheduled job has been completed.<br><br><br><br><br>**This property is read-only**. |
| Type | Integer | Scheduled job executed: <br><br>- *hlpOptimization*: Table optimization.<br><br>- *hlpFullBackup*: Full backup. <br><br>- *hlpDifferentialBackup*: Differential backup. <br><br>- *hlpTask*: Scheduled task.<br><br>- *hlpMaterializedView*: Refresh a materialized view.<br><br><br><br><br>**This property is read-only**. |
| User | Character string | <br><br>- User who created the scheduled job, if it was executed automatically. <br><br>- User who executed the scheduled job, if it was executed manually. <br><br><br>**This property is read-only**. |
