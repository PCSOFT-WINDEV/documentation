


## &lt;Source&gt;.DeclareExternal (Function)

***In french: &lt;Source&gt;.DéclareExterne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Temporarily imports into the current database schema the description of a table from an existing HFSQL table. This table is opened. To no longer use this File Description, call [&lt;Source&gt;.CancelDeclaration](../WDLang4/1000024192.md).

### Use with an OLE DB access, a Native Connector, HFSQL Client/Server and an existing connection

`<Result> = <Source>.DeclareExternal(<Alias> , <Connection>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Source>: (Type corresponding to the specified source)`**

Name of the table in the external database.
![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) This parameter corresponds to the physical name of table, in relation to the database (extension included). Example: "monfichier.fic" (or if the database has sub-directories: ".\\repertoire\\monfichier.fic"). 
If the table is password protected, this password must be specified with [&lt;Source&gt;.Password](../WDLang4/1000025044.md) before using **&lt;Source&gt;.DeclareExternal**.

**`<Alias>: (Character string)`**

Logical name of the table. This name will be used to handle the table in the current application. This name can also correspond to a Data Source variable.

**`<Connection>: (Character string)`**

Connection to a database. This connection has been defined in the data model editor or described programmatically with [HDescribeConnection](../WDLang4/3044205.md).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only connections to an HFSQL Client/Server database are available.

### Use with an OLE DB access or a Native Connector

`<Result> = <Source>.DeclareExternal(<Alias> , <User> [, <Password> [, <Data source> [, <OLE DB provider or Native Connector> [, <Access>]]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed,

**`<Source>: (Type corresponding to the specified source)`**

Name of the table in the external database.

**`<Alias>: (Character string)`**

Logical name of the table. This name will be used to handle the table in the current application.

**`<User>: (Character string)`**

Name of the user of the data source.

Password of the table to open (if there is a password).

**`<Access>: (Optional constant)`**

Configures the type of access to the table.


|   |   |
| --- | --- |

| *hOReadWrite*<br>(default value) | The table can be accessed in read/write mode. It is possible to read and write new records. |

## Remarks


- All the HFSQL functions can be used on the imported table except for the integrity management.

- You can import as many descriptions as necessary.

- This function can be used with tables in XML format.

- To use **&lt;Source&gt;.DeclareExternal** in a stored procedure:

	- the relative path of the table must be specified in relation to the directory of the database containing the stored procedure. The path must include the name and extension of the table.

	- don't use a connection: the current database containing the stored procedure will be used.




- By default, if the current project:

	- is associated with a database schema, the lock mode applied to the tables is the multi-user mode (the tables are not locked when they are opened and they can be accessed by the other applications).

	- is not associated with a database schema, the locking mode applied to tables is single-user: tables are completely locked for reading and writing as soon as they are opened. This mode prevents the other applications from accessing the files already opened by the current application.
