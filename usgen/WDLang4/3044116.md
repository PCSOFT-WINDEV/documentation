


## HStatTime (Function)

***In french: HStatHeure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the time of the last update for the index statistics. These statistics have been calculated with [HStatCalculate](../WDLang4/3044134.md) or [HIndex](../WDLang4/3044133.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Calculate statistics for the CustomerName key in the Customer table
HStatCalculate(Customer, CustomerName)

// Get the time the statistics were calculated
ResTime = HStatTime()
Info("The statistics for the CustomerName field were carried out at: " + ...
	TimeToString(ResTime))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HStatTime([<Table> [, <Key item>]])`
---

**`<Result>: (Character string)`**

Time in HHMMSS format (HH corresponds to the hours, MM to the minutes and SS to the seconds). The time is returned in UTC format (Universal Time Coordinate).

**`<Table>: (Optional character string)`**

Name of the table used. If this name is not specified, **HStatTime** uses the last table used by the last HFSQL management function (function starting with "H").

**`<Key item>: (Optional character string)`**

Name of the key item on which the statistics have been calculated. If this name is not specified, **HStatTime** will use the last key item used by the last HFSQL management function (function starting with "H").  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- In HFSQL tables, statistics can be calculated on key items only.
