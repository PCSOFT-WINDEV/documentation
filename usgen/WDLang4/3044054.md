


## HCloseAnalysis (Function)

***In french: HFermeAnalyse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the current database schema (or all current database schemas in the case of a project with multiple database schemas). 

All the HFSQL date files, views and queries currently opened are closed and freed. After the call to **HCloseAnalysis**, there is no current database schema.

## Syntax

`<Result> = HCloseAnalysis()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the database schema was closed, 

- <u><u><u><u>False</u></u></u></u> in the event of a problem: the database schema is not closed. [HError](../WDLang4/3044088.md) is used to identify the error.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- A project can be associated with one or more database schemas (projects with multiple database schemas).

- The **HCloseAnalysis** function closes: 

	- open database schemas with the [HOpenAnalysis](../WDLang4/3044106.md) function.

	- open database schemas with the [HOpenComplementaryAnalysis](../WDLang4/1410090082.md) function.




- **HCloseAnalysis** has no effect if there is no current database schema.
