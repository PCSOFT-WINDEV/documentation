


## Geometry (Variable type)

***In french: Geometry***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Geometry** type can be used to store any type of geometry: point, polygon, etc. 

This means that any WLanguage function that can return a point or polygon depending on its parameters, can have a variable of type **Geometry** as return value.

Once declared, **Geometry** variables are empty until a value is assigned to them.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
// Example 1: Get a point without verification
f is Geometry()
// Get geometry
f = GetPoint() // GetPoint is a procedure used to get a point
p is Point2D = f
```



```wl
// Example 2: Check type of geometry to make sure a point is retrieved before attempting conversion
f is Geometry 
// Get geometry ...
// Check geometry
IF f.Type = gtPoint2D then
   my2DPoint is Point2D
   my2DPoint = f
   //...
END
```

```wl
// Example 3: The type of a geometry can be changed
point is Point2D
linestring is Linestring2D
f is Geometry // Geometry is empty and can take any type of geometry
f = point // Geometry now contains a Point2D object.
f = linestring // Geometry now contains a Linestring2D object.
```

```wl
// Example 4: Get a geographic polygon without verification
// No need to declare an intermediate geometry 
// Directly convert the result of a function
f = GetGeometry() // GetGeometry is a procedure used to get a geometry
IF f.Type = gtPolygonGeo THEN
   polygon is PolygonGeo
   polygon = f
   // ...
END
```

```wl
// Example 5: If the type of geometry retrieved is unknown,
// different code can be executed according to the type of geometry
UnknownGeometry is Geometry
UnknownGeometry = GetUnknownGeometry() 
// GetUnknownGeometry is a procedure used to get a geometry
SWITCH UnknownGeometry.Type 
	CASE gtPoint2D:
	       // ...
	CASE gtLinestring2D:
	       // ...
	CASE gtPolygon2D:
	       // ...
	OTHER CASE:
	       // ...
END
```

## Properties


### Properties specific to Geometry variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000043"></a>

The following properties can be used to manipulate a variable of type **Geometry**:

| Property name | Type used | Effect |
| --- | --- | --- |
| Type | Integer constant | Type of the current geometry: <br><br>- *gtInvalid*: Invalid type.<br>	Note: Until version 2024 Update 2, this constant was named *stInvalid*.<br><br>- *gtGeometryCollection*: Collection of geometries.<br>	Note: Until version 2024 Update 2, this constant was named *stShapeCollection*.<br><br>- *gtMultiPoint2D*: Collection of 2D points.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiPoint2D*.<br><br>- *gtMultiPointGeo*: Collection of geographic points.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiPointGeo*.<br><br>- *gtMultiPolygon2D*: Collection of 2D polygons.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiPolygon2D*.<br><br>- *gtMultiPolygonGeo*: Collection of geographic polygons.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiPolygonGeo*.<br><br>- *gtMultiLinestring2D*: Collection of 2D multilinestrings.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiLinestring2D*.<br><br>- *gtMultiLinestringGeo*: Collection of geographic linestrings.<br>	Note: Until version 2024 Update 2, this constant was named *stMultiLinestringGeo*.<br><br>- *tgPoint2D*: 2-dimensional point, defined by X and Y coordinates on a Cartesian plane.<br>	Note: Until version 2024 Update 2, this constant was named *stPoint2D*.<br><br>- *gtPointGeo*: Geographic point, defined by latitude and longitude.<br>	Note: Until version 2024 Update 2, this constant was named *stPointGeo*.<br><br>- *tgPolygone2D*: Collection of straight consecutive segments that form a polygon.<br>	Note: Until version 2024 Update 2, this constant was named *stPolygon2D*.<br><br>- *gtPolygonGeo*: Collection of consecutive curved segments that form a polygon (the curvature of these segments respects the Earth's curvature).<br>	Note: Until version 2024 Update 2, this constant was named *stPolygonGeo*.<br><br>- *gtLinestring2D*: Set of consecutive straight segments.<br>	Note: Until version 2024 Update 2, this constant was named *stLinestring2D*.<br><br>- *gtLinestringGeo*: Collection of consecutive curved segments (the curvature of these segments respects the Earth's curvature).<br>	Note: Until version 2024 Update 2, this constant was named *stLinestringGeo*.<br><br><br>**This property is available in read-only**. |

|   |   |
| --- | --- |
| [GeometryArea](../WDLang4/1410090167.md) | Calculates the area of a given geometry. |
| [GeometryContain](../WDLang4/1410090138.md) | Determines if geometry A contains geometry B. |
| [GeometryConvexHull](../WDLang4/1410090169.md) | Calculates the convex hull of the specified geometry. |
| [GeometryCorrect](../WDLang4/1410090157.md) | Returns a corrected version of the specified geometry. |
| [GeometryCover](../WDLang4/1410090140.md) | Determines if geometry A covers geometry B. |
| [GeometryCoveredBy](../WDLang4/1410090141.md) | Determines if every point of geometry A lies inside or on the boundary of geometry B. |
| [GeometryCross](../WDLang4/1410090341.md) | Compares two geometries and determines if their intersection spatially crosses. |
| [GeometryDeserializeWKT2D](../WDLang4/1410090336.md) | Builds a 2D geometry from a Well-Known Text (WKT) representation. |
| [GeometryDeserializeWKTGeo](../WDLang4/1410090335.md) | Builds a geometry in geographic coordinates from a Well-Known Text (WKT) representation. |
| [GeometryDifference](../WDLang4/1410090156.md) | Returns a geometry representing the difference between two geometries. |
| [GeometryDisjoint](../WDLang4/1410090307.md) | Determines whether two geometries are disjoint, i.e. whether their intersection is empty. |
| [GeometryDistance](../WDLang4/1410090297.md) | Calculates the distance between two geometries. |
| [GeometryEqual](../WDLang4/1410090295.md) | Determines whether two geometries are spatially equal, i.e. whether the first geometry is included in the second, and vice versa. |

| [GeometryIntersection](../WDLang4/1410090153.md) | Returns a geometry representing the intersection of two geometries. |
| [GeometryIsValid](../WDLang4/1410090158.md) | Checks whether the specified geometry is valid according to the OGC rules. |
| [GeometryLength](../WDLang4/1410090296.md) | Calculates the length of a given geometry. |
| [GeometryOverlap](../WDLang4/1410090308.md) | Determines whether two geometries overlap. |
| [GeometryPerimeter](../WDLang4/1410090168.md) | Calculates the perimeter of a given geometry (polygon or multipolygon). |
| [GeometrySerializeDSV](../WDLang4/1410090121.md) | Serializes a geometry using the specified DSV format. |
| [GeometrySerializeWKT](../WDLang4/1410090108.md) | Serializes a geometry using the Well-Known Text (WKT) format. |

| [GeometryTouch](../WDLang4/1410090114.md) | Determines whether two geometries touch. |
