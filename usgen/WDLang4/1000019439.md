


## HModifyStructure (Function)

***In french: HModifieStructure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to update the structure of an HFSQL table by performing an automatic data modification (also called Synchronization of the Structure of Deployed Data).

**Please note** Links are not managed (existing links cannot be created or updated). 
To update links, use [HUpdateLink](../WDLang4/1000024555.md). 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000021445&name=hmodifystructure_function">See additional examples</a>

```wl
// Update the structure of table Customer in the background
HModifyStructure(Customer, hmsBackgroundTask)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HModifyStructure(<Table> [, <Option> [, <New password> [, <Backup> [, <Progress Bar>]]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the automatic data modification was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) and [HErrorInfo](../WDLang4/3044071.md) are used to identify the error.




**`<Table>: (Character string)`**

Name of table (defined in the database schema) whose structure must be updated. 
If this parameter is equal to "\*", the automatic data modification will be applied to all the known tables (described in the database schema).
This parameter can also correspond to the name of a [group of files (or custom-folder) defined in the database schema](../Editeurs/2011003.md) (not available in Android and Android widget).

**`<Option>: (Optional constant (or combination of constants))`**

Options for the automatic data modification: 


|   |   |
| --- | --- |
| *hmsBackgroundTask* | A hot automatic modification is performed (available for the HFSQL Client/Server tables only). |
| *hmsNoCheck* | The automatic data modification is performed even if:<br><br>- the description of the table is more recent than the description of the database schema,<br><br>- the GUID of the table differs from the GUID of the database schema.<br><br><br> |
| *hmsNormal* <br>(Default value) | Default operating mode of the automatic data modification. |
| *hmsSavegardeJournal* | The following steps are performed during automatic data modification: <br><br>- Backup log files (in log file backup directory). <br><br>- Deleting log files. <br><br>- Start automatic data modification. <br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Constant not available. |


**Note**: In *hmsNormal* or *hmsWithoutControl*mode, the table being handled must not be opened (by the application or by another application).. 

**`<New password>: (Optional string or Secret string)`**



- New password of the table. 

- Empty string ("") to delete the password. 




If this parameter is not specified (or if this parameter corresponds to NULL), the existing password is not modified.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Backup>: (Optional character string)`**



- Backup directory. 

- Empty string ("") to perform no backup (default value).




**`<Progress Bar>: (Optional control name or window name)`**

Name of the Progress Bar control or name of the window that shows the progress of the automatic data modification.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available.

## Remarks


### Password
<a name="password_ELTPARAGRAPHE000168"></a>

If **HModifyStructure** is the first function that handles the specified table, the password is checked when using the table. This password must have been specified by [HPass](../WDLang4/3044108.md). If the password is incorrect: 

- [HErrorPassword](../WDLang4/3044082.md) returns <u><u><u><u>True</u></u></u></u>.

- **HModifyStructure** returns <u><u><u><u>False</u></u></u></u>.
