
## SQLColumn (Function)

***In french: SQLColonne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the characteristics of all the columns (or items):

- for a given table.

- for a given query.




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The SQL functions are used to handle the local databases (such as Web SQL databases). For more details, see [Accessing a database in local mode (SQLite)](../WDLang4/9000119.md).![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **SQLColumn** returns only the characteristics of the columns for a given query. A result must have been returned by the query to get the query characteristics.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection to a database
Connection_Number is int 
Connection_Number = SQLConnect(SourceName, "", "", "", "ODBC")
i is int
// LIST_TableList is a list containing the list of tables
i = LIST_TableList
IF i <> -1 THEN
	ListAdd(LIST_List1, SQLColumn(Connection_Number, LIST_TableList[i]))
END
```

### Columns of a given table

`<Result> = SQLColumn(<Connection number> , <Table name> [, <Details>])`
---

**`<Result>: (Character string)`**

Name of the table columns.

- If &lt;Details&gt; is set to <u><u><u><u>False</u></u></u></u>, the character string contains the name of each table column separated  by CR: 
	
	```txt
	Column1 + RC + Column2 + RC + ... + ColumnN
	```


- If &lt;Details&gt; is set to <u><u><u><u>True</u></u></u></u>, the character string contains the name of each table column along with various information about the column (name, type, size): 
	
	```txt
	ColumnName + TAB + Type1 (N/T) + TAB + Type2 (number) + TAB + Size + CR
	```

	This format is presented in the Remarks.




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The results regarding the types and the sizes of columns may differ from the results returned in WINDEV.

**`<Connection number>: (Integer)`**

Number of the connection to use, returned by [SQLConnect](../WDLang4/3072005.md).

**`<Table name>: (Character string)`**

Name of the table for which to get the columns.

**`<Details>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default option) for a detailed result, 

- <u><u><u><u>False</u></u></u></u> for a simplified result.

### Columns of a given query

`<Result> = SQLColumn(<Query name> [, <Details>])`
---

**`<Result>: (Character string)`**



- If &lt;Details&gt; is set to <u><u><u><u>False</u></u></u></u>, the character string contains the name of each table column separated  by CR characters (Carriage Return): 
	
	```txt
	Column1 + RC + Column2 + RC + ... + ColumnN
	```


- If &lt;Details&gt; is set to <u><u><u><u>True</u></u></u></u>, the character string contains the name of each table column along with various information about the column (name, type, size): 
	
	```txt
	ColumnName + TAB + Type1 (N/T) + TAB + Type2 (number) + TAB + Size + CR
	```

	This format is presented in the Remarks.




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The results regarding the types and the sizes of columns may differ from the results returned in WINDEV.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Warning** If the query did not return any results, the characteristics of the columns cannot be known. 

**`<Query name>: (Character string)`**

Name of the query (executed with [SQLExec](../WDLang4/3072007.md) or [SQLExecWDR](../WDLang4/3072010.md)) for which we want to get the columns.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Only the queries created and run by [SQLExec](../WDLang4/3072007.md) are available. 

**`<Details>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> for a detailed result, 

- <u><u><u><u>False</u></u></u></u> (default option) for a simple result.

## Remarks




### Detailed information about the columns 
<a name="detailed_information_about_the_columns_ELTPARAGRAPHE000172"></a>

If &lt;Details&gt; is set to <u><u><u><u>True</u></u></u></u>, the character string contains the names of all the columns of a table with various information about these columns (name, type, size) in the following format: 


```txt
Column_Name + TAB + Type 1 (N/T) + TAB + Type 2 (number) + TAB + Size
```


- Type 1 (N/T): "N" numeric column, "T" text column

- Type 2: internal number indicating the exact type of column (see array)
	

| Type 1 | Type 2 | ODBC type |
| --- | --- | --- |
| N | 1 | SQL_BIT: Bit |
| N | 2 | SQL_TINYINT: Integer |
| N | 3 | SQL_BIGINT: Long integer |
| N | 4 | SQL_LONGVARBINARY: Binary memo type |
| N | 5 | SQL_VARBINARY: Variable-size binary string |
| N | 6 | SQL_BINARY: Binary |
| T | 7 | SQL_LONGVARCHAR: ASCII string memo |
| T | 9 | SQL_CHAR: Fixed-length string |
| N | 10 | SQL_NUMERIC: Numerical |
| N | 11 | SQL_DECIMAL: Decimal number |
| N | 12 | SQL_INTEGER: Integer |
| N | 13 | SQL_SMALLINT: Integer |
| N | 14 | SQL_FLOAT: Double real |
| N | 15 | SQL_REAL: Simple real |
| N | 16 | SQL_DOUBLE: Double real |
| T | 17 | SQL_DATE: Date |
| T | 18 | SQL_TIME: Time |
| T | 19 | SQL_TIMESTAMP: Date time |
| T | 20 | SQL_VARCHAR: Variable-size string |
| T | 0 | SQL_WCHAR: variable-size Unicode string |
| T | -2 | SQL_WLONGVARCHAR: Unicode memo |






- Size: Displayable size of column: for strings, size of string, and for numericals, size of numerical in bytes.




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code: 

- Only two types are supported: 
	

| Type 1 | Type 2 | ODBC type |
| --- | --- | --- |
| N | 16 | SQL_DOUBLE: Double real |
| T | 0 | SQL_WCHAR: variable-size Unicode string |



- the size is empty. 




**Reminder** If the query has not returned any results, the characteristics of the columns cannot be known.

### Tip: How can I speed up the execution time of the SQLColumn function? 
<a name="tip_how_can_speed_the_execution_time_the_sqlcolumn_function_ELTPARAGRAPHE000357"></a>

Simply prefix the table name with the owner: the result is almost immediate: 


```wl
SQLColumn(ConnectionNum, OWNER.CUSTOMER)
```
