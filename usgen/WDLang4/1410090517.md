


## &lt;Polygon2D variable&gt;.Area (Function)

***In french: &lt;Variable Polygone2D&gt;.Aire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the area of a polygon defined using 2D coordinates.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
A2DPolygon is Polygon2D = GeometryDeserializeWKT2D("POLYGON((0 0, 10 75,20 85, 25 12, 0 0))")
Area is real = A2DPolygon.Area()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Geometry used>.Area()`
---

**`<Result>: (Real)`**



- Area of the geometry. If the program uses meters, the result will be expressed in square meters. If the program uses miles, the result will be in square miles.
	If the geometry is a collection of geometries, the result will be the sum of the areas of the different geometries.

- 0 if the area of the geometry cannot be calculated. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
The unit of the area is the square of the unit used to define the points of the geometry.

**`<Geometry used>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.
