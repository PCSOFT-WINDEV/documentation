


## &lt;PolygonGeo variable&gt;.Correct (Function)

***In french: &lt;Variable PolygoneGéo&gt;.Corrige***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Returns a corrected version of the specified geographic polygon. 

**Note**: Some problems can be automatically corrected, such as misaligned points in a polygon.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Correct a geographic polygon missing the last point
myGeoPolygon is PolygonGeo
myGeoPolygon.Outline.AddPoint(2.681548, 43.802043)
myGeoPolygon.Outline.AddPoint(2.816297, 43.725179)
myGeoPolygon.Outline.AddPoint(2.842733, 43.817899)
myGeoPolygon.Outline.AddPoint(2.644979, 43.837466)
Trace("myGeoPolygon.IsValid() = " + myGeoPolygon.IsValid()) // False

// Correction
myGeoPolygon_corrected is PolygonGeo
myGeoPolygon_corrected = myGeoPolygon.Correct()
Trace("myGeoPolygon_corrected.IsValid() = " + myGeoPolygon_corrected.IsValid()) // True
Trace("myGeoPolygon.IsValid() = " + myGeoPolygon.IsValid()) 
// Still False: The geometry passed as a parameter is not modified
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.GeometryCorrect()`
---

**`<Result>: (Variable corresponding to the geometry)`**

Corrected geometry.

**`<Geometry>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.
