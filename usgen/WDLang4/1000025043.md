


## &lt;Source&gt;.Open (Function)

***In french: &lt;Source&gt;.Ouvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a table.

**Remark**: Table opening is automatically managed. However, in some cases, you may have to explicitly open a table (to check the table existence or the password validity for example).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open Customer table
Customer.Open()
```
<a name="Exemple3"></a>

```wl
// Check status report of <source>.Open
IF Customer.Open("ABCD", hORead) = False THEN
	Error("Unable to open the Customer table" + HErrorInfo())
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.Open([<Password> [, <Access mode>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table was opened.

- <u><u><u><u>False</u></u></u></u> if a problem occurred (wrong password, ...). [HError](../WDLang4/3044088.md) is used to identify the error. [HErrorInfo](../WDLang4/3044071.md) returns more details.




**`<Source>: (Type corresponding to the specified source)`**

Name of table used (logical name, defined in the database schema). 

**`<Password>: (Optional string or Secret string)`**

Password of the table. 
If no password is associated with the table, you have the ability to use an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Access mode>: (Optional integer constant)`**

Configures the access mode to the table. 
If this parameter is not specified, the table will be opened according to its characteristics (if the table is read-only, it will be opened in read-only; if the table is read/write, it will be opened in read/write mode).


|   |   |
| --- | --- |
| *hORead* | The table can be accessed in read-only mode. It is only possible to read records. It is not possible to add or remove records. |
| *hOReadWrite* | The table can be accessed in read/write mode. It is possible to read and write new records. |

## Remarks


### Password management
<a name="password_management_ELTPARAGRAPHE000298"></a>

The password can be specified:

- when the table is opened with **&lt;Source&gt;.Open**,

- before the table is opened with [&lt;Source&gt;.Password](../WDLang4/1000025044.md).



<a name="NOTE0_2"></a>


### Creating or opening a table
<a name="creating_opening_table_ELTPARAGRAPHE000318"></a>

[&lt;Source&gt;.CreateIfNotFound](../WDLang4/1000024208.md) can replace **&lt;Source&gt;.Open**. Indeed, if the table exists, it is automatically opened.
<a name="NOTE0_3"></a>


### Opening a table that is already opened
<a name="opening_table_that_already_opened_ELTPARAGRAPHE000334"></a>

If **&lt;Source&gt;.Open** is used on a data file already opened with a different &lt;Access mode&gt;, the filters, locks and characteristics of the current iteration are lost.
<a name="NOTE0_4"></a>


### Managing the list of tables used (.REP)
<a name="managing_the_list_tables_used_rep_ELTPARAGRAPHE000346"></a>

WINDEV Mobile allows you to update a list of tables used by the application (equivalent to the.REP file in WINDEV).

**&lt;Source&gt;.Open** specifies the list of tables used by the application (.REP for WINDEV and WEBDEV) if updates are enabled for this list.

For more details, see [List of tables handled by an application](../WDLang4/3044045.md).
<a name="NOTE0_5"></a>


### Managing fatal errors
<a name="managing_fatal_errors_ELTPARAGRAPHE000365"></a>If a fatal error occurs when opening a table, it may be interesting to continue the program while processing the error. To do so, we recommend that you perform the following exception process:

```wl
WHEN EXCEPTION IN
	Parent.Open()
DO
	Error("HFSQL error: " + HError())
ELSE
	Trace("File opened")
END
```

### Opening a connection and the specified table
<a name="opening_connection_and_the_specified_table_ELTPARAGRAPHE000386"></a>

If necessary, **&lt;Source&gt;.Open** opens the connection to the database before opening the specified table. If the connection is already open (with the same parameters), this connection is automatically used.

Note: The default connection used corresponds to the connection associated with the table in the data model editor.
