


## &lt;Source&gt;.ToFile (Function)

***In french: &lt;Source&gt;.VersFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Copies a data source (file, query, view, ...) to a physical HFSQL table with the same description. This table is neither encrypted nor password protected.  

This function can be used, for example, to save a history: a query selects all records for the year 2019, the result is transferred to a table, and a new query deletes all records for the year 2019.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF MyView.ToFile("C:\temp\Test.fic") = True THEN
	Info("Data transferred into a table")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.ToFile(<Destination file>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> otherwise (the destination file already exists for example).




**`<Source>: (Type corresponding to the specified source)`**

Logical name of the table source to copy (table, view, query, ...).

**`<Destination file>: (Character string)`**

Full name of the physical table into which the records found in the source must be copied. This table and the data source will have the same description. To access this table, use [&lt;Source&gt;.DeclareExternal](../WDLang4/1000024214.md) for example.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Filtered source
<a name="filtered_source_ELTPARAGRAPHE000206"></a>

Only the records corresponding to the filter will be copied if a filter is defined and enabled on the data source.
<a name="NOTE0_2"></a>


### Data source: View or query
<a name="data_source_view_query_ELTPARAGRAPHE000216"></a>

If the data source is a view or a query, all the items will be keys of the created table except for:

- Memo items.

- items whose size exceeds 260 characters and not key in the source file of the view or query.
