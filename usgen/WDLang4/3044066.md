


## HSetTransaction (Function)

***In french: HGèreTransaction***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables the management of transactions for one or more tables.

When the management of transactions is disabled, all transaction-related functions are inhibited ([HTransactionStart](../WDLang4/3044002.md), [HTransactionEnd](../WDLang4/3044032.md), [HTransactionCancel](../WDLang4/3044001.md)).

**Note**: By default, transaction management is active.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This function can be used with HFSQL Client/Server tables only.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Disable the management of transactions on the Customer table
HSetTransaction(Customer, False)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HSetTransaction([<Table>, ] <Options>)`
---

**`<Result>: (Boolean)`**

Corresponds to the former management mode of transactions (before the call to **HSetTransaction**): 

- <u><u><u><u>True</u></u></u></u> if the management of transactions was enabled,

- <u><u><u><u>False</u></u></u></u> if the management of transactions was disabled. 


If &lt;Data file&gt;= "\*", &lt;Result&gt; is set to <u><u><u><u>True</u></u></u></u> if the management of transactions was enabled for at least one data file in the former transaction management mode.

**`<Table>: (Optional character string)`**

Name of the table used. If this name is not specified or if it corresponds to "\*", the management of transactions is taken into account for all the tables found in the database schema.

**`<Options>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the management of transactions must be enabled for the table,

- <u><u><u><u>False</u></u></u></u> if this management must be disabled.

<a name="NOTE0_1"></a>

## Remarks


### Management of transactions enabled
<a name="management_transactions_enabled_ELTPARAGRAPHE000121"></a>

If the management of transactions is enabled for a single file, only the operations performed on this table will be taken into account in the management of transactions (regardless of the tables specified in [HTransactionStart](../WDLang4/3044002.md)).

<a name="limit_ELTPARAGRAPHE000135"></a>
