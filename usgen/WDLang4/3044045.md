


## HListFile (Function)

***In french: HListeFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of tables:

- current database schema. 

- database schemas in progress (projects with multiple database schemas). 

- a specific database schema recognized by the HFSQL engine. 

- available on a connection via a Native Connector or an OLE DB driver.

- for a group defined in the data model editor.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The groups defined in the data model editor are not supported.

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003044045&name=hlistfile_function">See additional examples</a>

```wl
// Retrieves the tables described in the current database schema and programmatically
FileList is string
FileList = HListFile(hLstDetail + hLstAll)
// Add the list of tables in COMBO_COMBO1
ListAdd(COMBO_COMBO1, FileList)
// Display in a trace
Trace(FileList)
```

## Syntax

### Listing the tables of a database schema

`<Result> = HListFile([<Path of the WDD file> [, <Password of the WDD file>]] [, <Options>])`
---

**`<Result>: (Character string)`**

List of tables found in the current database schema or in the specified database schema. 

Case of projects with multiple database schemas: If several database schemas are in progress, all the tables from all the database schemas in progress are listed (without duplicates). 

The descriptions of each database schema are separated by a carriage return. The result is more or less detailed depending on the constant used:


|   |   |
| --- | --- |
| *hLstDetail* is not specified | &lt;Name of table 1&gt; + CR + &lt;Name of table 2&gt; + CR + ... |
| *hLstDetail* is specified | &lt;Name of table 1&gt; + TAB + &lt;Abbreviation&gt; + TAB + &lt;Caption&gt; + TAB + &lt;Physical name&gt; + CR + ... |


Where:


- &lt;Nom du fichier de table X&gt; Logical name of table (used in programming).

- &lt;Abréviation&gt; Table abbreviation.

- &lt;Libellé&gt; Table name.

- &lt;Nom physique&gt; Physical name of table (on disk). This name corresponds to the short file name, without extension or path. 




**`<Path of the WDD file>: (Optional character string)`**

Full path of database schema (.WDD file) where the table is described. 
If this parameter is not specified or is equal to an empty string (""), the tables to be listed are searched:

- in the current database schema.

- in all current database schemas (case of projects with multiple database schemas). 




**`<Password of the WDD file>: (Optional string or Secret string)`**

Password defined for the database schema. 
If no password is defined, this parameter must be an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Options>: (Optional Integer constant (or combination of constants))`**

Configures the type of list to perform:


|   |   |
| --- | --- |
| *hLstAll* | Lists all the tables (including the ones described by [HDeclare](../WDLang4/3044203.md), [HDeclareExternal](../WDLang4/3044204.md) and [HDescribeFile](../WDLang4/3044206.md)).<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This parameter is ignored. |
| *hLstDetail* | Lists the detailed information (same as WINDEV 5.5). |
| *hLstNormal*<br>(default value) | List not sorted, not detailed, without the tables described programmatically. |
| *hLstSorted* | Sorts the list of tables in ascending order.<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This parameter is ignored. |

### Listing the tables of a group

`<Result> = HListFile(<Group name> [, <Options>])`
---

**`<Result>: (Character string)`**

List of tables belonging to the group. The descriptions of each table are separated by a carriage return.

**`<Group name>: (Character string)`**

Name of the table group. This group of tables was defined in the data model editor.

**`<Options>: (Optional Integer constant (or combination of constants))`**

Configures the type of tables to list:


|   |   |
| --- | --- |
| *hLstMaterializedView* | ![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) List of materialized views. |
| *hLstQuery* | Lists the queries that have been run. |
| *hLstStoredProcedure* | List of stored procedures. |
| *hLstSystemTable* | List of system tables.<br>![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) This option is not available. |
| *hLstTable*<br>(default value) | List of user tables.<br>![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The names of tables correspond to the physical names of tables. |
| *hLstView* | List of views.<br>![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) **Oracle Native Access** Access: The constant *hLstVue* constant is used to list views and synonyms.<br>![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Lists the SQL views. |

### HListFile function and the Native MySQL or MariaDB Connector
<a name="hlistfile_function_and_the_native_mysql_mariadb_connector_ELTPARAGRAPHE000530"></a>

- For the Native MySQL Connector, **HListFile** has evolved along with the versions: 

	- In version 15, **HListFile** returns the list of files in the current database. 

	- In version 16, to be able to use the new features of MySQL 5, if the Native Connector is connected to a MySQL 5 server (or later), **HListFile** returns the list of files from all accessible databases. In this case, the name of the file has the following format: "&lt;Database name&gt;.&lt;File name&gt;. 

	- Starting with version 170069, **HListFile** returns the list of files in the current database. [HListDatabase](../WDLang4/3044288.md) lists the accessible databases and their files. 




- For the Native MariaDB Connector, **HListFile** returns the list of files from the current database. [HListDatabase](../WDLang4/3044288.md) lists the accessible databases and their files.
