


## HListCustomFolder (Function)

***In french: HListePersoDossier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns a list of defined Custom-Folders (also called groups): 

- in the current database schema, 

- in ongoing database schemas (case of projects with multiple database schemas).

- in the specified database schema. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(HListCustomFolder())
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HListCustomFolder([<Path of the WDD file> [, <Password of the WDD file>]])`
---

**`<Result>: (Character string)`**

List of defined Custom-Folders:

- in the current database schema, 

- in ongoing database schemas (case of projects with multiple database schemas).

- in the specified database schema. 




The name of the Custom-Folders are separated by CR characters (Carriage Return). The result has the following format: 

```txt
<Perso-file 1> + CR + <Perso-file 2> + ... + <Perso-file N>
```


**`<Path of the WDD file>: (Optional character string)`**

Full path of the database schema (.WDD file) to use. 
If this parameter is not specified or is equal to an empty string (""), Custom-Folders are searched: 

- in the current database schema. 

- in all current database schemas (in the case of projects with multiple database schemas).




**`<Password of the WDD file>: (Optional string or Secret string)`**

Password defined for the database schema. If no password is defined, this parameter must be an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
