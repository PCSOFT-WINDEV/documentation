


## &lt;Polygon2D variable&gt;.IsValid (Function)

***In french: &lt;Variable Polygone2D&gt;.EstValide***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Checks whether the specified 2D polygon is valid according to the OGC rules.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
myPolygon is Polygon2D = MunicipalitiesFile.PolygonItem
// => True or False depending on whether myPolygon is valid: 
// points in the right order, 
// no intersections of the exterior ring and holes of the polygon, etc.
Trace(myPolygon.IsValid())
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.IsValid()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the geometry is valid,

- <u><u><u><u>False</u></u></u></u> otherwise.


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.
