The following constants are used by the HDFS functions: 

| Constant | Description | Used by the functions or types of variables |
| --- | --- | --- |
| **hdfsDefault** | Copy or rename options: if the destination file already exists on the server, it is not overwritten. | [hdfsCopyTo](../WDLang4/1000021679.md), <br>[hdfsRename](../WDLang4/1000021676.md), <br>[hdfsDelete](../WDLang4/1000021674.md) |
| **hdfsDirectory** | Deletion: The contents of the directory and sub-directories are also deleted. | [hdfsDelete](../WDLang4/1000021674.md) |
| **hdfsFile** | The element is a file. | [hdfsStatus](../WDLang4/1000021973.md) type |
| **hdfsLink** | The element is a link to another file. | [hdfsStatus](../WDLang4/1000021973.md) type |
| **hdfsOverwrite** | <br><br>- Copy options: if the destination file already exists on the server, it is replaced by the file copied from the local machine.<br><br>- Rename options: if the destination file already exists, it is replaced by the renamed file.<br><br><br> | <br><br>- [hdfsCopyTo](../WDLang4/1000021679.md)<br><br>- [hdfsRename](../WDLang4/1000021676.md)<br><br><br> |
| **hdfsRecursive** | The element is a link to a directory. | [hdfsStatus](../WDLang4/1000021973.md) type |
