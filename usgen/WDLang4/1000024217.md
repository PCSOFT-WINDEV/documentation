


## &lt;Source&gt;.Last (Function)

***In french: &lt;Source&gt;.Dernier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the position on the last record of a table according to a browse item. **The record is not read**.
The number of the current record is modified only when it is returned by [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md). For functions handling the current record number by default (functions [&lt;Source&gt;.Delete](../WDLang4/1000025071.md), [&lt;Source&gt;.Read](../WDLang4/1000025019.md), [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), ...), the value of this number is not updated: you must use the [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md)() function. For example: do not: 

```wl
Customer.Delete()
```
but 

```wl
Customer.Delete(Customer.RecNum())
```

The highest value in the browse item is read (for more details, see remarks).

**Warning** The record loaded into memory is not modified. HFSQL variables (e. g. Customer.Name, or the *Name* item of the *Customer* table) are not updated.

In most cases, **&lt;Source&gt;.Last** is used to set the position in the table in order to perform a read loop with [&lt;Source&gt;.Previous](../WDLang4/1000025047.md).

Several cases may occur after the call to **&lt;Source&gt;.Last**:

- the table is empty or there is no record corresponding to the filter (defined by [&lt;Source&gt;.Filter](../WDLang4/1000024960.md)): function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.

- the function attempts to block a record already blocked in play mode: function [HErrorLock](../WDLang4/3044099.md) returns <u><u><u>True</u></u></u> and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: lock management is not supported for databases that are accessed through JDBC.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Management of locks not available in SQLite databases.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Browse a table from the last record
Customer.Last(Name)
WHILE NOT Customer.Out()
	// Process the record
	Customer.Previous(Name)
END
```

## Syntax

`<Result> = <Source>.Last([<Search key item> [, <Options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the position was set,

- <u><u><u><u>False</u></u></u></u> if an error occurs. This problem can be caused by:

	- or a positioning problem (empty table, etc.): function [&lt;Source&gt;.Found](../WDLang4/1000025076.md) returns <u><u><u><u>False</u></u></u></u> and function [HError](../WDLang4/3044088.md) returns 0.

	- an error: [HError](../WDLang4/3044088.md) returns an integer other than 0. [HErrorInfo](../WDLang4/3044071.md) returns more details.







**`<Source>: (Type corresponding to the specified source)`**

Name of the table used. 

**`<Search key item>: (Optional character string)`**

Name of the key item used to loop through the table. If this name is not specified, **&lt;Source&gt;.Last** will use the last browse item used on this table by the last HFSQL management function (function starting with "H"). If this item does not exist, the best browse item is automatically used.

**`<Options>: (Optional constant)`**

Configures the lock set on the record selected by **&lt;Source&gt;.Last**:


|   |   |
| --- | --- |
| *hKeepFilter* | The filter set by [&lt;Source&gt;.Filter](../WDLang4/1000024960.md) will be taken into account, even if the search key is not optimized for the filter. Reminder: [&lt;Source&gt;.Filter](../WDLang4/1000024960.md) returns the optimized search key for the filter. <br>**Caution**: in this case, on large tables, performance problems may occur..<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant cannot be used. |
| *hLockNo* | No blocking: the Record can be played back or modified by another application. |
| *hLockReadWrite* | Lock in read/write mode: the selected record cannot be read or modified by another application. |
| *hLockWrite* | Lock in write mode: the selected record can be read by another application, but cannot be modified by another application.<br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: This constant is not available. |
| *hNoRefresh* | ![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The table or query content will not be refreshed. All the saved positions are stored. <br> If this parameter is not specified, function **&lt;Source&gt;.Last** resets the browse for the specified item: the contents of the table or query are refreshed with data from the OLE DB database.. All the saved positions are lost. The position will be restored according to the value of best item.<br>  Note: Routes and positions saved on other browse items are never assigned. |


![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The lock options will have no effect if the locks are not supported by the OLE DB provider or by the Native Connector.![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) The lock options are ignored. ## Remarks


### Read operation based on a key 
<a name="read_operation_based_key_ELTPARAGRAPHE000427"></a>

**&lt;Source&gt;.Last** sets the position on the record with the greatest key value.

The sort order taken into account is the one specified in the database schema for this key.

If duplicates are found, **&lt;Source&gt;.Last** sets the position on the first "duplicate" record according to the sequence of record numbers.

### Password verification
<a name="password_verification_ELTPARAGRAPHE000447"></a>

If **&lt;Source&gt;.Last** is the first function that handles the specified table, the password is checked when opening the table.

If the password is incorrect, [HErrorPassword](../WDLang4/3044082.md) returns <u><u><u><u>True</u></u></u></u> and [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u><u>True</u></u></u></u>.
<a name="NOTE0_3"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000477"></a>

- [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md) returns the current record number.

- [&lt;Source&gt;.ChangeKey](../WDLang4/1000024198.md) changes the search key while keeping the position on the current record.



<a name="NOTE0_4"></a>


### Comparing [&lt;Source&gt;.ReadLast](../WDLang4/1000025020.md) and &lt;Source&gt;.Last
<a name="comparing_readlastwdlang41000025020md_and_docparampagetitleshort_ELTPARAGRAPHE000496"></a>

The function **&lt;Source&gt;.Last** function does not play the Record: the **&lt;Source&gt;.Last** is therefore faster than function [&lt;Source&gt;.ReadLast](../WDLang4/1000025020.md).

### Locks
<a name="locks_ELTPARAGRAPHE000523"></a>

By default (&lt;Options&gt; not specified), the record is not locked.

If a lock is requested (*hLockWrite* or *hLockReadWrite* constant), the position will be set on the record only if it is not already locked.
