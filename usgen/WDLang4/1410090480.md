


## &lt;Source&gt;.QueryExecuted (Function)

***In french: &lt;Source&gt;.RequêteExécutée***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if a query has been executed. This function can be used before looping through the query results, for example. If you try to loop through the result of a query that has not been executed, a WLanguage error will be displayed. 

**Difference with [&lt;Source&gt;.DataSourceKnown](../WDLang4/1410090481.md)**: [&lt;Source&gt;.DataSourceKnown](../WDLang4/1410090481.md) determines if the data source is known to the HFSQL engine, regardless of its content. **&lt;Source&gt;.QueryExecuted** can only be used with queries.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
qryFlightsStat is SQL Query =
[
	SELECT * FROM  Flights
	WHERE Flights.DepartureAirportID = {ParamDepartureAirportID}
	AND Flights.ArrivalAirportID = {ParamArrivalAirportID}
]
qryFlightsStat.ParamDepartureAirportID = 12
qryFlightsStat.ParamArrivalAirportID = 2

IF NOT qryFlightsStat.QueryExecuted() THEN
	qryFlightsStat.ExecuteSQLQuery()
END
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Query to check>.QueryExecuted()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the query has already been executed,

- <u><u><u><u>False</u></u></u></u> otherwise, or if the &lt;Query to check&gt; parameter is not a query. [HErrorInfo](../WDLang4/3044071.md) returns more details about the problem.




**`<Query to check>: (Query name)`**

Name of the query to be checked. This parameter can be: 

- Name and full path of the query (".WDR" file).

- Query logical name.

- Name of a variable of type [SQL query](../Motscles/1514082.md).


If this parameter is not a query name, &lt;Result&gt; will be <u><u><u><u>False</u></u></u></u>.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
"INSERT", "DELETE" and "CREATE" queries can only be looped through if they contain the SQL "RETURNING" clause.
