


## HInfoLock (Function)

***In french: HInfoBlocage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the lock set on a table, on one or all the records in a table.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
LockList is string
// Lists all the locks of the Customer table
LockList = HInfoLock(Customer)
// Lists all the locks set on the tables of CSConnection
LockList = HInfoLock(CSConnection)
// Lists all the locks set on the Customer.fic table of CSConnection
LockList = HInfoLock(CSConnection, ".\customer.fic")
```

<a name="SYNTAXE1"></a>

## Syntax

### Information about the locks set on a table identified by its name

`<Result> = HInfoLock(<Table> [, <Record number>])`
---

**`<Result>: (Character string)`**



- Empty string ("") if there is no block or if the table manipulated is not an HFSQL Client/Server table.

- Information about the lock.  This information is separated by TAB characters and it has the following format:
	
	```txt
	<Physical name of the table relative to the database> + TAB + 
	<Record number> + TAB + 
	<User> + TAB + <Name of client computer> + TAB + 
	<IP address of client computer> + TAB + <Name of client application> + TAB + 
	<Type of lock> + TAB + <Date of lock implementation> + TAB + 
	<Number of seconds since start of lock> + CR
	```


	- &lt;Record number&gt; is set to -1 if the lock was set on the table.

	- The &lt;Type of lock&gt; parameter can correspond to:

		- W: Lock in write mode.

		- RW: Read/Write blockage.

		- W-T: Transaction lock in write mode.

		- RW-T: Read/write lock performed by a transaction.




- The &lt;Date de pose du blocage&gt; parameter is of the form: AAAAMMJJHHmmSS. This date is in UTC format (Universal Time Coordinated).




**`<Table>: (Character string)`**

Name of the table used. 
If this parameter is an empty string (""), **HInfoLock** manipulates the last table used by the last HFSQL function (function starting with "H").

**`<Record number>: (Optional integer)`**

Number of the record for which the lock information is requested. 
If this parameter is not specified, **HInfoLock** lists all the locks of the table.  


<a name="SYNTAXE2"></a>

### Information about the locks set on a table identified by its connection

`<Result> = HInfoLock(<Connection> [, <Table path>] [, <Record number>])`
---

**`<Result>: (Character string)`**

Information about the lock. This information is separated by TAB characters and it has the following format:

```txt
<Physical name of file relative to the database> + TAB + <Record number> + 
TAB + <User> + TAB + <Name of client computer> + TAB + 
<IP address of client computer> + TAB + <Name of client application> + 
TAB + <Type of lock> + TAB + <Start date of lock> + TAB + 
<Nb of seconds since start of lock> + CR
```


- &lt;Record number&gt; is set to -1 if the lock was set on the table.

- The &lt;Type of lock&gt; parameter can correspond to:

	- W: Lock in write mode.

	- W-T: Transaction lock in write mode.

	- RW: Read/Write blockage.

	- RW-T: Read/write lock performed by a transaction.




- The &lt;Date de pose du blocage&gt; parameter is of the form: AAAAMMJJHHmmSS. This date is in UTC format (Universal Time Coordinated).




**`<Connection>: (Character string or Connection variable)`**

Connection for which the lock information is requested. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).


If this parameter is not a connection name, **HInfoLock** considers that it corresponds to the name of a table.

**`<Table path>: (Optional character string)`**

Full path of the table, relative to the database schema defined by &lt;Connection&gt;. 
If the &lt;Connection&gt; parameter corresponds to the logical name of a table, it is ignored. 
If this parameter is not specified, all the locks set on all the tables of the database are returned.

**`<Record number>: (Optional integer)`**

Number of the record for which the lock information is requested. 
If this parameter is not specified, **HInfoLock** lists all the locks of the table.
