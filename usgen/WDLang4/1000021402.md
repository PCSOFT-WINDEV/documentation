


## SourceFromWindow (Function)

***In french: SourceDepuisFenêtre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Automatically initializes:

- the values of a table's items in memory with the values from the controls in the window. The table items bound to the window controls are automatically updated with the values of these controls.

- the value of the WLanguage variables with the value of the window controls. The WLanguage variables bound to the window controls are automatically updated with the values of these controls.




**Remarks**:

- The function **SourceFromWindow FUNCTION** function does not write to the table: only the variables of the table fields are assigned (i.e., the variables of the record loaded into memory). To modify the records, use [HAdd](../WDLang4/3044147.md), [HModify](../WDLang4/3044042.md), [HWrite](../WDLang4/3044092.md), etc.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is also available for WEBDEV pages. It is equivalent to [PageToSource](../WDLang4/1000017406.md). 

- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the binding to the table items is supported. Bindings to WLanguage variables are not supported in this version.

## Example


```wl
// Click the "Add" button
SourceFromWindow(Customer)
HAdd(Customer)
IF HErrorDuplicates() = True THEN Error("This number already exists")
```

## Syntax

`SourceFromWindow(<Source> [, <Window>])`
---

**`<Source>: (Type corresponding to the specified source)`**

Name of the source containing the data to update. For example, this source can be:

- The name of a table. In this case, only the controls bound to the items of the table are taken into account.

- The name of a WLanguage variable. In this case, only the controls bound to the WLanguage variable are taken into account.
	Remarks: 

	- If the name of the variable is enclosed in quotes, the control will be bound to the specified variable. 

	- If the name of the variable is not enclosed in quotes, the control will be bound to the variable data (e.g., a variable containing the name of another variable). 







**`<Window>: (Window name)`**

Name of the window that contains the controls.

Summary: Called when a control gains focus.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) If this parameter is specified, it must correspond to the name of the current page. Otherwise, an error occurs.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If this parameter is specified, it must correspond to the name of the current window. Otherwise, an error occurs.

## Remarks


### Binding between a control and a WLanguage variable or between a control and a table item
<a name="binding_between_control_and_wlanguage_variable_between_control_and_table_item_ELTPARAGRAPHE000105"></a>

The binding between a control and a WLanguage variable or between a control and a table item can be determined:

- In the editor, in the control description window ("Binding" tab).

- Programmatically, with the [DataBinding](../Proprietes/2510060.md) property.



<a name="NOTE0_2"></a>


### Section updates: Special cases
<a name="section_updates_special_cases_ELTPARAGRAPHE000120"></a>



- To automatically assign the NULL value to an item with **SourceFromWindow**:

	1. Check "Support NULL values" in the table description. 

	2. Check "Allow NULL values" for the item in the data model editor.

	3. Check "Return NULL if empty" in the "Details" tab of the Edit control bound to the item.




- The items of the table that are not bound to a control are not updated by **SourceFromWindow**.

- If multiple controls in the window or page are bound to the same table item, **SourceFromWindow** may not update the bound item properly. ***It is not recommended to bind multiple controls of a window or page to the same item***.

- **SourceFromWindow** does not update the items with the values from Image controls. Use the [HLinkMemo](../WDLang4/3044173.md) function.

- **SourceFromWindow** is not available on views.

- **Link with "Secure password" fields** The value of the "Secure password" field is not modified until the user modifies the value in the field linked to the field.
