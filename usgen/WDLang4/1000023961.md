


## &lt;Connection variable&gt;.InfoFile (Function)

***In french: &lt;Variable Connexion&gt;.InfoFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the characteristics of an HFSQL Classic or Client/Server table.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

<a name="3044311_Exemple2"></a>

```wl
// Get the size of a table by using a connection 
// Connection parameters
CntTest is Connection
CntTest.Provider = hAccessHFClientServer
CntTest.User = "admin"
CntTest.Password = "pass_admin"
CntTest.Server = "server:4930"
CntTest.Database = "TestDatabase"
Trace("Total Client table size: " + ...
	CntTest.InfoFile("FileName.FIC", hTotalSize))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Getting the details of an HFSQL Client/Server table

`<Result> = <Connection>.FileInfo(<Table> , <Information>)`
---

**`<Result>: (Type of the desired information)`**



- Desired information, 

- 0 if the connection exists but the table does not exist on the disk.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<Table>: (Character string)`**

Physical name of the table to apply the database schema.

**`<Information>: (Integer constant)`**

Requested information about the table:


|   |   |
| --- | --- |
| *hFicSize* | Table (".Fic") size in bytes. |
| *hFtxSize* | Full-text index file (".Ftx") size in bytes. |
| *hMmoSize* | Memo file (".Mmo") size in bytes. |
| *hNdxSize* | Index file (".Ndx") size in bytes. |
| *hSdxSize* | Spatial index file (".Sdx") size in bytes. |
| *hTotalSize* | Total table size in bytes (cumulative size of table, memo file and index file). |
