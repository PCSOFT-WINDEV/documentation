


## HCheckMemoAsynchronous (Function)

***In french: HVérifieMémoAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the structural integrity of memos in an HFSQL Client/Server table. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
DatabaseConnection is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
ArrayAdd(FileArray, MyFileParam)

HCheckMemoAsynchronous(DatabaseConnection, FileArray, CB_HCheckMemoAsynchronous)
	INTERNAL PROCEDURE CB_HCheckMemoAsynchronous(MyFile is string, MyResult is string)
		IF MyResult = "" THEN
			Trace("File processed and checked" + MyFile)
		ELSE
			Trace("File processed. Some problems were found " + MyFile)
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HCheckMemoAsynchronous(<Connection> , <Tables to check> [, <WLanguage procedure>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the check has been started,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Connection>: (String or Connection variable)`**

Connection to the server containing the tables to be manipulated. This connection corresponds to:

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).




**`<Tables to check>: (Array of hFileParameter variables)`**

Name of the array of [hFileParameter](../WDLang4/1000018900.md) variables corresponding to the list of tables to be processed. 

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called for each table processed. This procedure is used to manipulate the current table.

For more details on this procedure, see [Parameters of the procedure used by HCheckMemoAsynchronous](../WDLang4/1410091106.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The list of free blocks is checked in HFSQL Client/Server only.

- **HCheckMemoAsynchronous** is faster than [HReindexAsynchronous](../WDLang4/1410091053.md) with the *hCheckMemo* constant.. 

- If a problem is detected, you can use [HReindexAsynchronous](../WDLang4/1410091053.md) with the *hCheckMemo* constant.
