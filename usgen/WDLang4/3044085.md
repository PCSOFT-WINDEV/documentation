


## HDeactivateFilter (Function)

***In french: HDésactiveFiltre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Temporarily disables the filter on a table (view or query). This filter was created by [HFilter](../WDLang4/3044100.md). **HDeactivateFilter** has no effect if no filter was declared.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003044085&name=hdeactivatefilter_function">See additional examples</a>

```wl
// Filter declaration: customer selection
// between 20 and 60 years old
HFilter(Customer, Age_Customer, 20, 60)
...
HDeactivateFilter(Customer) // Disabled filter
...
// Browse the table with a filter on age
// Process the customers who are between 20 and 60 years old
// (ProcessCustomer2060 procedure)
HActivateFilter(Customer)
HReadFirst(Customer, Age_Customer)
WHILE HFound(Customer) = True
	ProcessCustomer2060()
	HReadNext(Customer, Age_Customer)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HDeactivateFilter([<Table>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the filter is disabled, 

- <u><u><u><u>False</u></u></u></u> if an error occurred (table or item not found).




**`<Table>: (Optional character string)`**

Name of the table, view or query used. 
If this parameter is not specified, **HDeactivateFilter** handles the last table used by the last HFSQL management function (function starting with "H").

<a name="NOTE0_1"></a>

## Remarks


### Enabling and disabling a filter
<a name="enabling_and_disabling_filter_ELTPARAGRAPHE000083"></a>

The filter is enabled once it has been declared ([HFilter](../WDLang4/3044100.md)). A filter disabled by **HDeactivateFilter** can be re-enabled by [HActivateFilter](../WDLang4/3044158.md).

Note: When calling function [HClose](../WDLang4/3044073.md), the filter activated by function **HFilter** function is automatically deleted.
<a name="NOTE0_2"></a>


### Number of possible active filters
<a name="number_possible_active_filters_ELTPARAGRAPHE000105"></a>

A single filter can be enabled at a time for a specific table.
<a name="NOTE0_3"></a>


### Browse
<a name="browse_ELTPARAGRAPHE000114"></a>

The modifications performed by [HFilter](../WDLang4/3044100.md) and **HDeactivateFilter** are taken into account when using [HReadFirst](../WDLang4/3044051.md)/[HFirst](../WDLang4/3044113.md), [HReadLast](../WDLang4/3044140.md)/[HLast](../WDLang4/3044101.md) or [HReadSeekFirst](../WDLang4/3044036.md)/[HReadSeekLast](../WDLang4/3044034.md).
