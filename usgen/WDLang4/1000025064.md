


## &lt;Source&gt;.StatCalculate (Function)

***In french: &lt;Source&gt;.StatCalcule***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Collects statistics on table keys.

This function is equivalent to [HAccelerateSpeed](../WDLang4/1000019375.md).

These statistics are used when applying a filter, creating a query or creating a view on the table. The HFSQL engine analyzes the selection condition, then uses these statistics to define the most discriminating items that will be used to optimize iterations on tables.

The statistics are used to get information about the content of the table when they are calculated. Also, the more modifications there are to the table after this calculation, the less accurately these statistics represent the contents of the table. The more records the table contains, the less the modification of a single record impacts the overall statistics.

**Note**: **&lt;Source&gt;.StatCalculate** prevents any write operations to the table while statistics are being calculated (the table is read for each key).
![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Statistics can be calculated in the background, without locking the table. ![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Statistics for an HFSQL Client/Server table can be calculated asynchronously using [&lt;HFSQL connection&gt;.StatCalculateAsynchronous](../WDLang4/1410091224.md). 


**Note**: For optimal results, this calculation must include all tables (e.g. multi-table query).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Statistics on the CustName key of the Customer table
Customer.StatCalculate(CustomerName)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.StatCalculate([<Key item> [, <Option>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the calculation was performed, 

- <u><u><u><u>False</u></u></u></u> if a problem occurred (table locked by an application for example). [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Source>: (Type corresponding to the specified source)`**

Name of the table used. 
Caution: This table must not be locked by an application.

**`<Key item>: (Optional character string)`**

Name of the key item used to calculate statistics. If this name is not specified or is set to "\*", statistics will be calculated for all key items in the table.

**`<Option>: (Integer constant)`**

Option for calculating the statistics. 

- If this parameter is not specified, the calculation of statistics locks the table. 

- If this parameter is set to the *hBackgroundTask* constant, statistics are calculated in the background, without locking the table. 


**Important**: This parameter is only taken into account for HFSQL Client/Server tables. In all other cases, the table is automatically locked while statistics are being calculated. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **&lt;Source&gt;.StatCalculate** does not close the table.

- Statistics can also be updated using [&lt;Source&gt;.Index](../WDLang4/1000025060.md). [&lt;Source&gt;.Index](../WDLang4/1000025060.md) and **&lt;Source&gt;.StatCalculate** can both be used to update the file statistics.

- In HFSQL Classic or Client/Server tables, only key items can be used to calculate statistics.

- The syntax **&lt;Source&gt;.StatCalculate**(&lt;Data file&gt;) is equivalent to **&lt;Source&gt;.StatCalculate**(&lt;Data file&gt;, "\*")

- To use **&lt;Source&gt;.StatCalculate** with the data files of an HFSQL cluster, the &lt;Option&gt; parameter must correspond to the *hBackgroundTask* constant to avoid locking the cluster.
