


## &lt;Connection variable&gt;.SetIntegrity (Function)

***In french: &lt;Variable Connexion&gt;.GèreIntégrité***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables the management of an integrity constraint on a file link.

**Note** By default, all integrity rules defined in the database schema description are active.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Disable integrity rules on the link between an order and a customer
// with use of a connection
CtSourceFile is Connection
CtLinkedFile is Connection

CtSourceFile.SetIntegrity(CtLinkedFile, CustomerOrder, ... 
	hCardinality + hOnUpdate + hOnDelete, False)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Enabling or disabling the management of an integrity constraint by specifying the connection of table

`<Result> = <Source table connection>.SetIntegrity([<Linked table connection>, ] <Link description> [, <Integrity constraint>] , <Management mode>)`
---

**`<Result>: (Boolean)`**

Former management mode of integrity (before the call to **&lt;Connection variable&gt;.SetIntegrity**): 

- <u><u><u>True</u></u></u> if the management of integrity was enabled,

- <u><u><u>False</u></u></u> if the management of integrity was disabled.




**`<Source table connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to which the link source table belongs.

**`<Linked table connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to which the linked file of the link belongs.

**`<Link description>: (Link Description variable)`**

Name of the [Link description](../WDLang4/1514039.md) variable that contains the characteristics of the link.

**`<Integrity constraint>: (Optional Integer constant (or combination of constants))`**

Integrity constraints that must be managed. If this parameter is not specified, the new management mode is applied to all link constraints.


|   |   |
| --- | --- |
| *hCardinality* | Check the link cardinalities. |
| *hOnDelete* | Integrity rule applied during a deletion. |
| *hOnUpdate* | Integrity rule applied during a modification. |



**`<Management mode>: (Boolean)`**



- <u><u><u>True</u></u></u> if the integrity constraint is enabled,

- <u><u><u>False</u></u></u> if this management must be disabled. If only this parameter is specified, the management mode is applied to all tables.

## Remarks


### Enabling the management of integrity
<a name="enabling_the_management_integrity_ELTPARAGRAPHE000278"></a>

If an operation performed on a table triggers a violation of an integrity constraint on an active rule, the operation is not performed and provokes the error of the function. In this case, [HErrorIntegrity](../WDLang4/3044086.md) returns <u><u><u><u>True</u></u></u></u>.

**Note**: Only functions [&lt;Source&gt;.Add](../WDLang4/1000024187.md), [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), [&lt;Source&gt;.Delete](../WDLang4/1000025071.md), [&lt;Source&gt;.Cross](../WDLang4/1000025051.md) and [&lt;Source&gt;.Write](../WDLang4/1000024331.md) can generate an integrity error.
<a name="NOTE0_2"></a>


### Disabling the integrity rules
<a name="disabling_the_integrity_rules_ELTPARAGRAPHE000322"></a>

Disabling an integrity rule means the possibility not to comply with the constraints specified during the description of the tables in the data model editor. Deactivating an integrity rule is therefore not a trivial operation: it must be used wisely.

### In HFSQL Client/Server mode
<a name="hfsql_clientserver_mode_ELTPARAGRAPHE000334"></a>

Using the **&lt;Connection variable&gt;.SetIntegrity**(&lt;Management&gt;) syntax affects the behavior of all HFSQL servers (no matter whether the connection is opened before or after the call to **&lt;Connection variable&gt;.SetIntegrity**).

Using **&lt;Connection variable&gt;.SetIntegrity** by specifying the link name can be done if:

- The link is described in the client database schema (or by [HDescribeLink](../WDLang4/3044191.md)).

- The two tables linked by this link are found on the same HFSQL server.




If **&lt;Connection variable&gt;.SetIntegrity** is called before the tables are in Client/Server mode (if [&lt;Source&gt;.ChangeConnection](../WDLang4/1000024199.md) is used for example), the server enables the integrity rule.

A right is associated with integrity management on the database: *hDroitGèreIntégrité*. An error occurs when the user tries not to comply with the integrity constraint (when using [&lt;Source&gt;.Add](../WDLang4/1000024187.md), [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), ...).
