


## H.VisibleAutoIndexing (Variable)

***In french: H.RéindexationAutomatiqueVisible***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether the indexing window must be displayed during the automatic reindexing of HFSQL tables.

**Note** Whether or not the indexing window is displayed, the current application is unusable for the duration of the reindexing process.
<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Value of H.VisibleAutoIndexing
<a name="value_hvisibleautoindexing_ELTPARAGRAPHE000019"></a>

- By default, the variable **H.AutomaticReindexingVisible** is set to <u><u><u><u>True</u></u></u></u> the indexing window will be displayed during automatic re-indexing.

- If **H.VisibleAutoIndexing** is set to <u><u><u><u>False</u></u></u></u>, the indexing window will be invisible.




**Warning** If a lock error occurs during re-indexing (e.g. when the table or a record in the table is locked in read/write mode), automatic re-indexing will be stopped and a fatal corrupted index error will be displayed. Then, you will have to reindex the table.
<a name="NOTE0_2"></a>


### Customizing the window for automatic indexing
<a name="customizing_the_window_for_automatic_indexing_ELTPARAGRAPHE000037"></a>

The window for automatic indexing is supplied in French and in English. This window can be customized. For more details, see [HFSQL error handling help](../WDLang4/3044188.md).
