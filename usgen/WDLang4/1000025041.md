


## &lt;Source&gt;.RecNum (Function)

***In french: &lt;Source&gt;.NumEnr***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns:

- the number of the current record in the HFSQL table.

- the number of the current record in the HFSQL view.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Current record in the "Customer" table
CurrentCustomerRec = Customer.RecNum()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.RecNum()`
---

**`<Result>: (entier)`**

Corresponds to:

- the number of the current record in the table.

- the number of the current record in the view or in the query (and not the number of the current record in the table). 
	**Warning** When used on an HFSQL Classic view, this parameter does not correspond to the value of variable [H.NumRec](../WDLang4/3044076.md).

- the *hInvalidRecNum* constant if there is no current record (position outside the table).




[HError](../WDLang4/3044088.md) returns more details about the problem.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) When used on a Hyper File 5.5 view, **&lt;Source&gt;.RecNum** returns the number of the current record in the table associated with the view.

**`<Source>: (Type corresponding to the specified source)`**

Name of HFSQL table, query or view used.

<a name="NOTE0_1"></a>

## Remarks


### Non-HFSQL tables
<a name="nonhfsql_tables_ELTPARAGRAPHE000214"></a>

- There is no record number on the tables.

- The call to this function triggers a WLanguage error.
