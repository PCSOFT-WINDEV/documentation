


## &lt;PolygonGeo variable&gt;.Area (Function)

***In french: &lt;Variable PolygoneGéo&gt;.Aire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the area of a polygon defined using geographic coordinates.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
myGeoPolygon is PolygonGeo
// Declaration of a linestring to define the exterior ring of the polygon
myGeoLinestring is LinestringGeo

// Build the linestring that represents the exterior ring of the polygon by defining 4 points
myGeoLinestring.AddPoint(2.681548, 43.802043)
myGeoLinestring.AddPoint(2.816297, 43.725179)
myGeoLinestring.AddPoint(2.842733, 43.817899)
myGeoLinestring.AddPoint(2.644979, 43.837466)
// Close the polygon, adding the first point at the end of the boundary
myGeoLinestring.AddPoint(2.681548, 43.802043)

// Assign exterior ring built previously
myGeoPolygon.Outline = myGeoPolygon

// Calculate area
Area is real = myGeoPolygon.Area()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Geometry used>.GeometryArea()`
---

**`<Result>: (Real)`**



- Area of the geometry, expressed in square metres. If the geometry is a collection of geometries, the result will be the sum of the areas of the different geometries.

- 0 if the area of the geometry cannot be calculated. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
The unit of the area is the square of the unit used to define the points of the geometry.

**`<Geometry used>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.
