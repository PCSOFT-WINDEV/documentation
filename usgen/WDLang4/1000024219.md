


## &lt;Source&gt;.DeactivateAutoFilter (Function)

***In french: &lt;Source&gt;.DésactiveFiltreAuto***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disables an automatic filter on the linked tables when browsing an XML file. This filter was enabled by [&lt;Source&gt;.ActivateAutoFilter](../WDLang4/1000024171.md).

**Please note** This function is only available for XML Native Access.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enable all the possible automatic filters on the Customer table
Customer.ActivateAutoFilter("*")
// except between Customer and Order
Customer.DeactivateAutoFilter(Order)

/////////////////////////////

// Browse orders
Order.ReadFirst(OrderID)
WHILE Order.Out() = False
	// Browses the order lines of the current order
	OrdLine.ReadFirst(OrderID)
	WHILE OrdLine.Out() = False
		OrdLine.ReadNext(OrderID)
	END
	// Next order
	Order.ReadNext(OrderID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.DeactivateAutoFilter(<Table not to filter>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the filter is disabled, 

- <u><u><u><u>False</u></u></u></u> if an error occurred (table or item not found).




**`<Source>: (Type corresponding to the specified source)`**

Name of the table used for the browse.

**`<Table not to filter>: (Character string)`**



- Name of the table to not filter when positioned in the browse table.

- "\*" to disable all the automatic filters.
