


## &lt;HFSQL connection&gt;.StatCalculateAsynchronous (Function)

***In french: &lt;Connexion HFSQL&gt;.StatCalculeAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets various statistics on the keys of an HFSQL Client/Server table. 

These statistics are used when applying a filter, creating a query or creating a view on the table. The HFSQL engine analyzes the selection condition, then uses these statistics to define the most discriminating items that will be used to optimize iterations on tables.

The statistics are used to get information about the content of the table when they are calculated. Also, the more modifications there are to the table after this calculation, the less accurately these statistics represent the contents of the table. The more records the table contains, the less the modification of a single record impacts the overall statistics.

**Reminder**: [&lt;Source&gt;.StatCalculate](../WDLang4/1000025064.md) prevents writing to the table while statistics are being calculated. By using **&lt;HFSQL connection&gt;.StatCalculateAsynchronous**, you can complete this process in a background task, without blocking the application. 

**Note**: For optimal results, this calculation must include all tables (e.g. multi-table query).

## Example


```wl
DatabaseConnection is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
FileArray.Add(MyFileParam)

IF bBackgroundTask THEN
	DatabaseConnection.StatCalculateAsynchronous(FileArray, hBackgroundTask, Callback_HStatCalculateAsynchronous)
ELSE
	DatabaseConnection.StatCalculateAsynchronous(FileArray, Callback_HStatCalculateAsynchronous)
END
	INTERNAL PROCEDURE Callback_HStatCalculateAsynchronous(MyFile is string, MyResult is boolean)
		IF MyResult THEN
			Trace("Statistics calculated for the table " + MyFile)
		ELSE
			Trace("Unable to calculate statistics for the table " + MyFile + ErrorInfo())
		END
	END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.StatCalculateAsynchronous(<Tables to check> [, <Option>] [, <WLanguage procedure>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if statistics are being calculated,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Connection>: (Connection variable)`**

Connection to the server containing the tables to be manipulated. This connection corresponds to the name of a variable of type [Connection](../WDLang4/1514073.md).

**`<Tables to check>: (Array of hFileParameter variables)`**

Name of the array of [hFileParameter](../WDLang4/1000018900.md) variables corresponding to the list of tables to be processed.

**`<Option>: (Optional integer)`**

Option for calculating the statistics. 

- If this parameter is not specified, the calculation of statistics locks the table. 

- If this parameter is set to the *hBackgroundTask* constant, statistics are calculated in the background, without locking the table.




**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called for each table processed. This procedure is used to manipulate the current table.

For more details on this procedure, see [Parameters of the procedure used by &lt;HFSQL connection&gt;.StatCalculateAsynchronous](../WDLang4/1410091116.md).
