


## HListAnalysis (Function)

***In french: HListeAnalyse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of WINDEV or WEBDEV database schemas (in HFSQL Classic format) available in a given directory. The search is performed recursively in the entire tree structure of the specified directory.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003044049&name=hlistanalysis_function">See additional examples</a>

```wl
// Fills a Combo field with the list of database schemas available in \My directories
ListAdd(COMBO_Combo, HListAnalysis("\My Directories"))
```

```wl
// Fills a multiline edit control 
// using the comma and RC as separators
EDT_Edit1 = HListAnalysis("\My Projects", "," + CR)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HListAnalysis(<Search directory> [, <Separator>])`
---

**`<Result>: (Character string)`**

I'm sorry, but it seems there is an incomplete portion of your request after "Full name of the analyses found, in the following format:". Could you please provide the full context or complete the sentence 

```txt
<Database schema 1> + <Separator> + <Database schema 2> + ...
```

where &lt;database schema X&gt; corresponds to the full name of the database schema (.WDD) found.

**`<Search directory>: (Character string)`**

Path of the directory where the search for database schemas must start. If this parameter is set to "\*" or to "\*:\\", all the directories on all the accessible drives will be searched (depending on the case, this search can take quite a long time).

**`<Separator>: (Optional character string)`**

Character string used to separate the different database schemas in &lt;Result&gt;. If this parameter is not specified, CR (Carriage return) is used by default.
