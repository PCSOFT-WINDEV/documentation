


## &lt;Source&gt;.RecordToString (Function)

***In french: &lt;Source&gt;.EnregistrementVersChaîne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts the content of the current record to string (in a table, HFSQL view, query, etc.).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Rec is string = Customer.RecordToString()
```
<a name="1000025983_Exemple2"></a>

```wl
// Retrieves the string containing the entire record
MyRecord is string = Customer.RecordToString()
// Extracts the last name of the customer
CustomerLastName is string = MyRecord.ExtractString(1)
// Extracts the first name of the customer
CustomerFirstName is string = MyRecord.ExtractString(2)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Convert the contents of a record for the specified table into a string

`<Result> = <Source>.RecordToString([<Item separator> [, <Array separator> [, <Format>]]])`
---

**`<Result>: (Character string)`**

Value of the record, in the following format: 

```txt
<Content of item 1> + <Item separator> + <Content of item 2> + ...
```


The contents of items are extracted according to the physical order of items in the table. If the item corresponds to NULL, &lt;Content of item&gt; corresponds to an empty string ("").

Depending on the &lt;Format&gt; specified, this character string is in ANSI (default) or Unicode format.

**`<Source>: (Type corresponding to the specified source)`**

Name of the table (view or query) used. If this name is not specified, **&lt;Source&gt;.RecordToString** will use the last table used by the last HFSQL function (function starting with "H").

**`<Item separator>: (Optional character string)`**

Character string used to separate the different items in &lt;Result&gt;. The default separator is TAB.

**`<Array separator>: (Optional character string)`**

Character string used to separate the values of array items (or sub-items) in &lt;Result&gt;. The default separator is TAB.
Please note: for compatibility with WINDEV 5.5, separators are not shown when array fields are empty.

**`<Format>: (Optional Integer constant)`**

Format used to return the value of the record. By default, an ANSI format character string is returned. To obtain a string in Unicode format, use the following constant:


|   |   |
| --- | --- |
| *hUnicode* | &lt;Résultat&gt; is a Unicode character string. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The content of Binary Memo items is not retrieved but the item separator is present (to avoid a shift).

- The content of composite keys is not retrieved but the item separator is present (to avoid a shift).
