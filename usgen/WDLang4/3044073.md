


## HClose (Function)

***In french: HFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes either a table or all tables opened by the current user: all corresponding physical tables are closed for the current user. For the HFSQL tables, the following tables are closed:

- the table (.FIC),

- the index file (.NDX) if it exists,

- the memo file (.MMO) if it exists.

- the full-text index file (.FTX) if it exists.




**When closing the table**:

- The locks (on the table and/or some of its records) are unlocked.

- The filters defined on the table with [HFilter](../WDLang4/3044100.md) are automatically deleted. 

- The current iterations on the table are canceled. 

- The current searches on the table are canceled. 




Once the table is closed, the reassignments performed by [HChangeName](../WDLang4/3044141.md), [HChangeDir](../WDLang4/3044168.md) and [HSubstDir](../WDLang4/3044028.md) are kept.

If a query was executed on the table, [HCancelDeclaration](../WDLang4/3044174.md) must be called on the query in order for the closing to be effective.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Close the "Supplier" table
HClose(Supplier)
```
<a name="Exemple2"></a>

```wl
IF NOT HClose("") THEN
	Error ("Problem when closing tables")
END
```

## Syntax

`<Result> = HClose([<Table>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the table was closed,

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<Table>: (Optional character string)`**

Name of table to close. 
If this name is not specified, **HClose** will close the last table used by the last HFSQL management function (function starting with "H").
If this parameter is equal to "\*" or if it corresponds to an empty string (""), all the opened tables will be closed. 
This parameter can also correspond to the name of a [group of files (or custom-folder) defined in the database schema](../Editeurs/2011003.md) (not available in Android and Android widget).

## Remarks


### Closing the tables and the connection
<a name="closing_the_tables_and_the_connection_ELTPARAGRAPHE000130"></a>

When all the tables that use the same connection (tables opened on the same database with the same connection parameters) are closed, the connection is automatically closed.

To close a connection, use [HCloseConnection](../WDLang4/3044095.md).
