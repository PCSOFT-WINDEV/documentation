


## HInfoFileProperty (Function)

***In french: HInfoPropriétéFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the properties of a table located in an HFSQL server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection description
HDescribeConnection("MyConnection", "Julia", "Password", "MyHFServer", "MyDatabase", ...
	hAccessHFClientServer, hORead)
// Open the connection
HOpenConnection("MyConnection")
...
OwnerName is string
OwnerName = HInfoFileProperty("MyConnection", hOwner, "MyDatabase", "Customer.fic")
IF OwnerName <> "" THEN 
	Trace("Database owner: " + OwnerName)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HInfoFileProperty(<Connection> , <Property> , <Database> , <Table>)`
---

**`<Result>: (Character string)`**



- Value of requested property, 

- Empty string ("") if an error occurred.




**`<Connection>: (String or Connection variable)`**

Connection for which a property value is requested. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).




**`<Property>: (Integer constant)`**

Requested file property: 


|   |   |
| --- | --- |
| *hApplication* | Name of the application from which the table was created. <br>If this constant is used, &lt;Result&gt; will be a character string with the following format: <br>&lt;Executable name&gt;(&lt;Project name>). |
| *hComputer* | Name of the computer from which the table was created. <br>If this constant is used, &lt;Result&gt; will have the following format: <br>&lt;Name of client computer&gt; + TAB + &lt;IP address of client computer&gt;. |
| *hCreator* | Name of file owner.<br>If this constant is used, &lt;Result&gt; is a character string. |
| *hDate* | Creation date of the table. <br>If this constant is used, &lt;Result&gt; is a string in the following format: YYYYMMDDHHmmSSCCC. |
| *hNotes* | Description of the table or any other information associated with the table by [HModifyFileProperty](../WDLang4/3044330.md). <br>If this constant is used, &lt;Result&gt; is a character string. |
| *hOwner* | Owner of table. <br>If this constant is used, &lt;Result&gt; is a character string. |



**`<Database>: (Character string)`**

Name of the database containing the file for which to get the properties. 
If this parameter corresponds to an empty string (""), the database defined in the connection will be used. 
A WLanguage error occurs if no database is defined in the connection.

**`<Table>: (Character string)`**

Name of HFSQL table for which to get the properties. The file extension must be specified. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To modify the properties of a table, use [HModifyFileProperty](../WDLang4/3044330.md).

- Please note: the table being manipulated must have been created on the server (functions [HCreation](../WDLang4/3044255.md) or [HCreationIfNotFound](../WDLang4/3044254.md)).
