


## HEndNoModif (Function)

***In french: HFinInterditModif***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Unlocks a table that was locked by the same program with [HNoModif](../WDLang4/3044053.md).

**Caution**: Does not unlock blocks made by other programs.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HNoModif(Invoice)
// Process
HEndNoModif(Invoice)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HEndNoModif(<Table>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if no problem occurred, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<Table>: (Character string)`**

Name of the table used.
