


## &lt;Source&gt;.RecordToJSON (Function)

***In french: &lt;Source&gt;.EnregistrementVersJSON***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the structure and value of the current record and exports them into a string in JASON format.

**Remark**: This function can be used on both tables and queries.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

<a name="1000021909_Exemple2"></a>

```wl
// Export current record of "Customer"
sJSON is string 
sJSON = Customer.RecordToJSON()
```
<a name="1000021909_Exemple3"></a>

```wl
// Export current record of "Customer"
// Note: Only the NAME and NUMBER items are taken into account
sJSON is string 
sJSON = Customer.RecordToJSON("NAME,NUMBER")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.RecordToJSON([<List of items>])`
---

**`<Result>: (Character string)`**

Structure and value of the current record in JSON format. This structure has the following format:


```txt
{"File":
	{
		"Item1":Data of item 1,
		"Item2":Data of item 2,
		...
		}
}
```


**`<Source>: (Type corresponding to the specified source)`**

Name of the HFSQL table or query used. 

**`<List of items>: (Optional character string)`**

Items to export. 
If several items are specified, the name of the items must be separated by a comma. 
Composite key, binary memo or binary items are ignored. 
If this parameter is not specified or is an empty string (""), all items are exported (except compound keys, binary and binary memo items) in the order in which they were created in the physical file.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Array items
<a name="array_items_ELTPARAGRAPHE000215"></a>If one of the exported items is an array item, each element of the array item is exported in a new level:


```txt
{"File":
	{
	"Item1":Data of item 1,
	"Item2":Data of item 2,
	"ArrItem":
		[Data element 1, Data element 2, ...]
	...
	}
}
```

**Reminder**: Composite key, binary memo or binary items are ignored.
