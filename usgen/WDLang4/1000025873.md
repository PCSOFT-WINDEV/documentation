
## HTriggerRecordBefore (Function)

***In french: HTriggerEnregistrementAvant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the value of the current record before the trigger(s) are executed.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sRecord is Record of FEES
// FEES is the name of the file on which the trigger has been fired
sRecord = HTriggerRecordBefore()
let sString = HRecordToString(sRecord)
Trace("sEnreg: ", sString)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HTriggerRecordBefore()`
---

**`<Result>: (Record variable)`**

[Record](../WDLang4/1000020962.md) variable corresponding to the initial record.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If a new record is added in the table, the returned record is an "empty" record marked as "deleted". 

- Special case: If the table is a Client/Server file and the trigger is an "after" trigger executed on the client workstation, then the function **HTriggerRecordBefore** function does not return the memos.
