


## HDeactivateAutoFilter (Function)

***In french: HDésactiveFiltreAuto***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disables an automatic filter on the linked tables when browsing an XML file. This filter was enabled by [HActivateAutoFilter](../WDLang4/3044297.md).

**Please note** This function is only available for XML Native Access.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enable all the possible automatic filters on the Customer table
HActivateAutoFilter(Customer, "*")
// except between Customer and Order
HDeactivateAutoFilter(Customer, Order)

/////////////////////////////

// Browse orders
HReadFirst(Order, OrderID)
WHILE HOut() = False
	// Browses the order lines of the current order
	HReadFirst(OrdLine, OrderID)
	WHILE HOut() = False
		HReadNext(OrdLine, OrderID)
	END
	// Next order
	HReadNext(Order, OrderID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HDeactivateAutoFilter(<Browse table> , <Table not to filter>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the filter is disabled, 

- <u><u><u><u>False</u></u></u></u> if an error occurred (table or item not found).




**`<Browse table>: (Character string)`**



- Name of the table used for the browse.

- "\*" to disable all the automatic filters.




If &lt;Browse data file&gt; and &lt;Data file not to filter&gt; correspond to "\*", &lt;Result&gt; is set to <u><u><u><u>True</u></u></u></u> and no filter is disabled.

**`<Table not to filter>: (Character string)`**



- Name of the table to not filter when positioned in the browse table.

- "\*" to disable all the automatic filters.




If &lt;Browse data file&gt; and &lt;Data file not to filter&gt; correspond to "\*", &lt;Result&gt; is set to <u><u><u><u>True</u></u></u></u> and no filter is disabled.
