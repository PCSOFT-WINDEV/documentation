
## Password management policy
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000146"></a>
To manipulate data in an HFSQL Client/Server database, users need to authenticate using login credentials. 
You can now implement a password security policy to define how long and how complex passwords should be, and how often they should be renewed (e.g. passwords must be changed every month). 
This policy can be defined and modified:

- [via the HFSQL Control Center](#NOTE2_1). 

- [programmatically](#NOTE3_1).

## Password management policy in the HFSQL Control Center
<a name="password_management_policy_the_hfsql_control_center_ELTTEXTE000170"></a>
The HFSQL Control Center allows you to:

- [Enable a password management policy](#NOTE2_2). 

- [Set user passwords](#NOTE2_3)

- [Report problems via the "Security audit" widget](#NOTE2_4). 



<a name="NOTE2_2"></a>


### Enabling a password management policy
<a name="enabling_password_management_policy_ELTPARAGRAPHE000041"></a>

To enable the various password management policy options:

1. Open the HFSQL Control Center.  

2. Connect (if necessary) to an HFSQL server. For more details, see [Managing HFSQL Client/Server databases](../CCHF/35400013.md). 

3. Double-click the name of HFSQL server in the tree structure. 

4. In the ribbon, click "Server configuration". 

5. In the configuration window, click "Password security". The window that appears shows the available options to implement a password security policy. 




The following options can be activated: 

- **Password validity period** Enables control of password validity period. You can modify this period (60 days by default) by clicking on the default number of days. When this time has elapsed, the user's password must be changed. 

- **Delay before change** Enables control of the minimum time between password changes. You can modify this period (0 days by default) by clicking on the default number of days.

- **Delay before re-use** Enables control of the delay between two re-uses of the same password.   You can modify this period (365 days by default) by clicking on the number of days proposed by default. 

- **Change before reuse** Enables control over the number of password changes before an old password is reused. You can modify this number (default: 3 changes) by clicking on the default number. 

- **Block after invalid entry** Enables you to control the number of failed password entries before blocking the connection for a set period of time. You can modify this number (default: 5 failures) and the duration (default: 5 minutes) by clicking on the various default values. 

- **Size** Enables control of minimum password size. You can change this size (default 12 characters) by clicking on the default number of characters.  

- **Complexity** Allows you to control the expected complexity of the password. By default, no control is performed ("Low" option). 

	- The "Average" option is used to check that passwords contain at least one uppercase, one lowercase and one numeric character. 

	- The "High" option checks that passwords contain at least one uppercase, one lowercase, one numeric and one special character.








<a name="NOTE2_3"></a>


### Setting user passwords
<a name="setting_user_passwords_ELTPARAGRAPHE000059"></a>

When creating or editing a user in the HFSQL Control Center, you can set or change the user's password. 

If the password management policy has been activated, password size and complexity criteria are automatically applied when a user is created. 
<a name="NOTE2_4"></a>


### Server dashboard: "Security audit" widget
<a name="server_dashboard_security_audit_widget_ELTPARAGRAPHE000068"></a>

In the HFSQL Control Center dashboard, the "Security audit" widget shows whether one or more users have expired passwords to connect to the server.

## Implementing a password management policy programmatically
<a name="implementing_password_management_policy_programmatically_ELTTEXTE000242"></a>
To implement the password management policy in WLanguage:

1. Create a variable of type [hSecurityPolicy](../WDLang4/1410091181.md). Define the values of the associated properties. 

2. Enforce the password management policy with [HSecurityPolicySet](../WDLang4/1410091205.md). 




Several functions are available to manage the password management policy: 



|   |   |
| --- | --- |
| [HSecurityPolicyCheck](../WDLang4/1410091206.md) | Checks that each user accounts complies with the password security policy associated with the HFSQL server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
| [HSecurityPolicyGet](../WDLang4/1410091207.md) | Gets the security policy of an HFSQL server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
| [HSecurityPolicySet](../WDLang4/1410091205.md) | Sets the password security policy of an HFSQL server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
| [HSecurityPolicyUnlockAccount](../WDLang4/1410091235.md) | Unlocks a user account that has been locked due too many unsuccessful login attempts.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
