


## &lt;redisConnection variable&gt;.Disconnect (Function)

***In french: &lt;Variable redisConnexion&gt;.Déconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes a connection to a Redis server (or cluster).

This function can also be used to manipulate data on a Valkey server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
gRedis is redisConnection
gRedis.Server = "MyRedisServer:7001"
IF gRedis.Connect() THEN
    gRedis.Disconnect()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Connection>.Disconnect()`
---

**`<Connection>: (redisConnection variable)`**

Name of the [redisConnection](../WDLang4/1000023527.md) variable that corresponds to the Redis server connection.
