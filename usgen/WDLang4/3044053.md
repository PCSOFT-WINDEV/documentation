


## HNoModif (Function)

***In french: HInterditModif***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Forbids all the modifications on a table (for all the programs, including the one that requested the no-modification policy). The records can be accessed in read-only.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The restriction is performed for all the sessions and other programs (developed with WEBDEV), including the session that requested the restriction.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HNoModif(Invoice)
// Process...
HEndNoModif(Invoice)
```

## Syntax

`<Result> = HNoModif(<Table>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if no problem occurred, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.


If the table is still locked after [H.NbRetry](../WDLang4/3044075.md) attempts, [HErrorLock](../WDLang4/3044099.md) returns <u><u><u><u>True</u></u></u></u> (the H.Locked variable is set to <u><u><u><u>True</u></u></u></u>). 
If the table was locked, [HErrorLock](../WDLang4/3044099.md) returns <u><u><u><u>False</u></u></u></u>.

**`<Table>: (Character string)`**

Name of the table used.

## Remarks


### Locks set by HNoModif
<a name="locks_set_docparampagetitleshort_ELTPARAGRAPHE000085"></a>

**HNoModif** can lock **in write mode** a file already locked by another program (with **HNoModif**). Therefore, several programs can forbid the modifications on the same table at the same time. A locking read function run after **HNoModif** in the same program reads the record without locking it.

**HNoModif** cannot lock a table already locked **in read/write** by another program.
Reminder: the table could not be blocked by **HNoModif** only if the table is blocked for reading and writing by another program.

Remarks:

- In single-user mode ([HMode](../WDLang4/3044039.md)), **HNoModif** is equivalent to [HOpen](../WDLang4/3044120.md) (the tables are locked in read/write as soon as they are opened).

- You have the ability to lock a table whose records are locked by another application.



<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000122"></a>

The maximum number of programs that can request the no-modification policy on a table depends on the size of a record in the table. It can be calculated as follows: 

```txt
MaxNbSessionsOrPrograms = RecordSize - 20
```
