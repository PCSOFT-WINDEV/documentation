
## &lt;Connection variable&gt;.SecurityPolicySet (Function)

***In french: &lt;Variable Connexion&gt;.PolitiqueSécuritéModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the password security policy of an HFSQL server. 

Note: To use this function, you need to be connected to the HFSQL server with a "super user" account. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySecurityPolicy is hSecurityPolicy
IF NOT MyConnection.SecurityPolicySet(MySecurityPolicy) THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.SecurityPolicySet(<SecurityPolicy>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified password security policy has been applied,

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<SecurityPolicy>: (hSecurityPolicy variable)`**

[hSecurityPolicy](../WDLang4/1410091181.md) variable corresponding to the password security policy to be applied.
