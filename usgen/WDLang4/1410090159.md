


## Linestring2DAddPoint (Function)

***In french: Polyligne2DAjoutePoint***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Adds a new point to a 2D linestring.

**Reminder**: A 2D polygon is a set of 2D linestrings. 
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
MyLine is Linestring2D
// Add points to linestring
Linestring2DAddPoint(MyLine, 32, 22)
Linestring2DAddPoint(MyLine, 134, 12)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`Linestring2DAddPoint(<Linestring> , <X> , <Y>)`
---

**`<Linestring>: (Linestring2D variable)`**

Name of the [Linestring2D](../WDLang4/1410090109.md) variable to which to add the points. 

**`<X>: (Real)`**

 X-coordinate of the point.

**`<Y>: (Real)`**

Y-coordinate of the point.
