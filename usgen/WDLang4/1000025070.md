


## &lt;Source&gt;.Next (Function)

***In french: &lt;Source&gt;.Suivant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the position on the next table record according to a browse item. ***The record is not read.***
The number of the current record is modified only when it is returned by [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md). For functions handling the current record number by default (functions [&lt;Source&gt;.Delete](../WDLang4/1000025071.md), [&lt;Source&gt;.Read](../WDLang4/1000025019.md), [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), ...), the value of this number is not updated: you must use the [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md)() function. For example: do not: 

```wl
Customer.Delete()
```
but 

```wl
Customer.Delete(Customer.RecNum())
```

Values in the browse item are read in ascending order (for more details, see the remarks).

Warning: ***Record loaded into memory is not modified***. The HFSQL variables (for example Customer.Name, i.e. the *Name* item of the *Customer* file) are not updated.

Generally, **&lt;Source&gt;.Next** sets the position in the table during a loop operation.

Several cases may occur after the call to **&lt;Source&gt;.Next**:

- the table is empty or there is no record corresponding to the filter (defined by function [&lt;Source&gt;.Filter](../WDLang4/1000024960.md)): function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>

- the function attempts to block a record already blocked in play mode: function [HErrorLock](../WDLang4/3044099.md) returns <u><u><u>True</u></u></u> and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: Lock management is not available for databases accessed via JDBC.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Customer.First(Name)
WHILE Customer.Out() = False
	// Process the record
	Customer.Next(Name)
END
```

## Syntax

`<Result> = <Source>.Hnext([<Search key item> [, <Options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the position was set,

- <u><u><u><u>False</u></u></u></u> if an error occurs. This problem can be caused by:

	- or a positioning problem (empty table, etc.): function [&lt;Source&gt;.Found](../WDLang4/1000025076.md) returns <u><u><u><u>False</u></u></u></u> and function [HError](../WDLang4/3044088.md) returns 0.

	- an error: [HError](../WDLang4/3044088.md) returns an integer other than 0. [HErrorInfo](../WDLang4/3044071.md) returns more details.







**`<Source>: (Type corresponding to the specified source)`**

Name of the HFSQL table. 

**`<Search key item>: (Optional character string)`**

Name of the key item used to loop through the table. If this name is not specified, **&lt;Source&gt;.Next** will use the last browse item used on this table by the last HFSQL management function (function starting with "H"). If this item does not exist, the best browse item is automatically used.

**`<Options>: (Optional constant)`**

Configures the lock and the management of duplicates performed on the record selected by **&lt;Source&gt;.Next**:


|   |   |
| --- | --- |
| *hDistinct* | If there are any duplicates, sets the position on a single record of the duplicates. This parameter is taken into account only if the iteration is performed on a key item. <br>By default, all duplicates are iterated over.<br>![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) This constant is ignored. |
| *hLockNo* | No blocking: the Record can be played back or modified by another application. |
| *hLockReadWrite* | Lock in read/write mode: the selected record cannot be read or modified by another application.<br><br>![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png) Lock in write mode only: the record currently being read can be read by another application, but cannot be modified by another application. <br>Operating mode equivalent to the one of *hLockWrite*. |
| *hLockWrite* | Lock in write mode: the selected record can be read by another application, but cannot be modified by another application. |

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Access through JDBC: This parameter is ignored.![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The lock options will have no effect if the locks are not supported by the OLE DB provider or by the Native Connector.![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png) The lock mode specified with [&lt;Source&gt;.ReadFirst](../WDLang4/1000025022.md) will remain effective when [&lt;Source&gt;.ReadPrevious](../WDLang4/1000025021.md) and [&lt;Source&gt;.ReadNext](../WDLang4/1000025035.md) are called.

To change the lock mode, use:

- [&lt;Source&gt;.ReadSeekFirst](../WDLang4/1000025034.md) or [&lt;Source&gt;.ReadSeekLast](../WDLang4/1000025024.md).

- **HReadFirst** or [&lt;Source&gt;.ReadLast](../WDLang4/1000025020.md).

- [&lt;Source&gt;.LockRecNum](../WDLang4/1000024197.md) or [&lt;Source&gt;.UnlockRecNum](../WDLang4/1000024212.md).


![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) The lock options are ignored. Use the lock functions ([&lt;Source&gt;.LockRecNum](../WDLang4/1000024197.md)) kept for backward compatibility.

## Remarks


### Read operation based on a key
<a name="read_operation_based_key_ELTPARAGRAPHE000434"></a>

**&lt;Source&gt;.Next** positions on the next record with the greatest key value. The sort order taken into account is the one specified in the database schema for this key.
<a name="NOTE0_2"></a>


### Comparison between &lt;Source&gt;.Next and [&lt;Source&gt;.ReadNext](../WDLang4/1000025035.md)
<a name="comparison_between_docparampagetitleshort_and_readnextwdlang41000025035md_ELTPARAGRAPHE000446"></a>

The function **&lt;Source&gt;.Next** function does not play the Record: the **&lt;Source&gt;.Next** is therefore faster than function [&lt;Source&gt;.ReadNext](../WDLang4/1000025035.md).
<a name="NOTE0_3"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000471"></a>

- [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md) returns the current record number.

- [&lt;Source&gt;.ChangeKey](../WDLang4/1000024198.md) changes the search key while keeping the position on the current record.

### Locks
<a name="locks_ELTPARAGRAPHE000492"></a>

By default (&lt;Options&gt; not specified), the record is not locked.

If a lock is requested (*hLockWrite* or *hLockReadWrite* constant), the position will be set on the record only if it is not already locked.
