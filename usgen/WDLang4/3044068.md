


## HCheckStructure (Function)

***In french: HVérifieStructure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the mode for comparing tables. This comparison is performed when the tables are opened.

Are compared:

- the structure of the HFSQL table defined in the database schema,

- the real structure of physical HFSQL table.




By default, these two structures must be strictly identical in order to handle the table.

Depending on the selected mode, a WLanguage error may occur if incompatible structures are found. In this case, you need to run an automatic table modification ([HModifyStructure](../WDLang4/1000019439.md)).

**Note** The description used by the application always corresponds to the description of the physical HFSQL table.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is available for HFSQL tables only. It is not available for the tables accessed by JDBC. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Allows opening the "Customer" table
// Even if the structures are different
HCheckStructure(Customer, hNoCheck)
```

## Syntax

`<Result> = HCheckStructure([<Table>, ] <Management mode>)`
---

**`<Result>: (Integer constant)`**

Old description mode (before the call to **HCheckStructure**).

**`<Table>: (Optional character string)`**

Name of the table used.
If this parameter is not specified or corresponds to "\*", descriptions are taken into account for all the tables in the database schema.

**`<Management mode>: (Integer constant)`**

Selected management mode:


|   |   |
| --- | --- |
| *hCompatible*<br>(default value) | The structures of tables must be compatible. If one of the following operations is performed, the structures are considered as being incompatible:<br><br>- Adding a unique key item (except an automatic identifier).<br><br>- Switching a key with duplicates into unique key.<br><br>- Deleting or renaming an item.<br><br>- Changing the type of an item (except changing from text to Unicode text).<br><br>- Reducing the size of item.<br><br>- Reducing the integer part or the decimal part of a Numeric item.<br><br>- An item becomes a non-key item.<br><br>- Deleting a full-text index.<br><br>- Adding or deleting items to/from a full-text index (however, the creation of a new full-text item is compatible).<br><br><br> |
| *hIdentical*<br> | The structures must be strictly identical. |
| *hNoCheck* | As no verification is performed, the descriptions of the database schema and the physical table may differ. |

## Remarks


### Tips
<a name="tips_ELTPARAGRAPHE000129"></a>

**HCheckStructure** must be used: 

- before establishing the connection to avoid the calls to the server. 

- before opening the tables. 



<a name="NOTE0_2"></a>


### hCompatible: conditions allowing structures to be considered incompatible
<a name="hcompatible_conditions_allowing_structures_considered_incompatible_ELTPARAGRAPHE000143"></a>

If any of the following differences exist between the table description present in the database schema and the table description stored in the physical table, the structures are considered by the HFSQL engine to be incompatible: an automatic modification is required.


|   |   |   |
| --- | --- | --- |
| **Structure in the database schema** | **Structure read in the physical table** | **Possible consequence** |
| - automatic identifier<br>or<br>- key with duplicates<br>or<br>- non-key item | Unique key and not automatic identifier | A duplicate error may occur when adding a record. <br><br><br>Note: If only reads are performed on the table, no problems will occur. |
| Using the "XXX" item | The "XXX" item does not exist | Add a value for a non-existent field in the physical table. |
| The "XXX" item was renamed. |
| Different type of item | Invalid conversion when assigning the value to the item.<br>Value assigned to the truncated item. <br><br>Change of operating mode: <br><br>- Exact-match search only<br><br>- Browse performed on the record number<br><br><br> |
| Different size of item |
| Key item | Non-key item |
