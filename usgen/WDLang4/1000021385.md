


## &lt;Window&gt;.ToFile (Function)

***In french: &lt;Fenêtre&gt;.VersFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Automatically updates:

- the values of a table's items in memory with the values from the controls in the window. The table items bound to the window controls are automatically updated with the values of these controls (even if they are grayed, inactive or invisible).

- the value of the WLanguage variables with the value of the window controls. The WLanguage variables bound to the window controls are automatically updated with the values of these controls (even if they are grayed out, inactive or invisible).




**Remarks**: 

- **&lt;Window&gt;.ToFile** cannot be used to write to the table. Only the variables of the table items can be updated (i.e variables of the record loaded in memory). To modify the records, use [&lt;Source&gt;.Add](../WDLang4/1000024187.md), [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), [&lt;Source&gt;.Write](../WDLang4/1000024331.md), etc.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is also available for WEBDEV pages. It is equivalent to [&lt;Page&gt;.ToFile](../WDLang4/1000021390.md). 

- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the binding to the table items is supported. Bindings to WLanguage variables are not supported in this version.

## Example


```wl
// Click the "Add" button
WIN_Customer.ToFile()
Customer.Add()
IF HErrorDuplicates() = True THEN 
	Error("This number already exists")
END
```

## Syntax

`<Window>.ToFile([<Source>])`
---

**`<Window>: (Window name)`**

Name of the window that contains the controls. Summary: Called when a control gains focus.

**`<Source>: (Optional character string)`**

Name of the source containing the data to update. This source can be:

- The name of a table. In this case, only the controls bound to the items of the table are taken into account.

- The name of a WLanguage variable. In this case, only the controls bound to the WLanguage variable are taken into account.
	Remarks: 

	- If the name of the variable is enclosed in quotes, the control will be bound to the specified variable. 

	- If the name of the variable is not enclosed in quotes, the control will be bound to the variable data (e.g., a variable containing the name of another variable).





If this name is not specified, all the window or page controls that are bound to a table described in the data model editor or to a WLanguage variable will be taken into account.

<a name="NOTE0_1"></a>

## Remarks


### Binding between a control and a WLanguage variable or between a control and a table item
<a name="binding_between_control_and_wlanguage_variable_between_control_and_table_item_ELTPARAGRAPHE000256"></a>

The binding between a control and a WLanguage variable or between a control and a table item can be determined:

- In the editor, in the control description window ("Binding" tab).

- Programmatically, with the [DataBinding](../Proprietes/2510060.md) property.



<a name="NOTE0_2"></a>


### Updating items: Special cases
<a name="updating_items_special_cases_ELTPARAGRAPHE000272"></a>



- To automatically assign the NULL value to an item with **&lt;Window&gt;.ToFile**:

	1. Check "Support NULL values" in the table description. 

	2. Check "Allow NULL values" for the item in the data model editor.

	3. Check "Return NULL if empty" in the "Details" tab of the Edit control bound to the item.




- The items of the table that are not bound to a control are not updated by **&lt;Window&gt;.ToFile**.

- If multiple controls in the window or page are bound to the same table item, **&lt;Window&gt;.ToFile** may not update the bound item properly. ***It is not recommended to bind multiple controls of a window or page to the same item***.

- **&lt;Window&gt;.ToFile** does not update the items with the values from Image controls. Use the [&lt;Source&gt;.LinkMemo](../WDLang4/1000024194.md) function.

- **&lt;Window&gt;.ToFile** is not available on views.

- **Link with "Secure password" fields** The value of the "Secure password" field is not modified until the user modifies the value in the field linked to the field.
