


## &lt;Source&gt;.ListKey (Function)

***In french: &lt;Source&gt;.ListeClé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of keys in a table (query or view) recognized by the HFSQL engine. You can determine:

- the type of key,

- its size, 

- whether the key is unique or with duplicates, etc.


The files defined by [&lt;Source&gt;.Declare](../WDLang4/1000024213.md), [&lt;Source&gt;.DeclareExternal](../WDLang4/1000024214.md) and [HDescribeFile](../WDLang4/1000024215.md) are taken into account.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the keys of a table found in the current database schema
KeyList is string
KeyList = Customer.ListKey(hLstDetail)
// Adds the list of keys into COMBO_COMBO1
COMBO_COMBO1.Add(KeyList)
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.ListKey([<Path of the WDD file> [, <Password of the WDD file> [, <Options>]]])`
---

**`<Result>: (Character string)`**

List of items found in the specified table. The different descriptions of each key are separated by CR characters (Carriage Return). The listed keys are sorted according to the physical order of the keys in the table (except if the *hLstSorted* constant is used).

The result is more or less detailed depending on the constant used:



|   |   |
| --- | --- |
| *hLstDetail* is not specified | &lt;Name of key 1&gt; + CR + &lt;Name of key 2 + CR + ...<br>The result with the constants *hLstKey* and/or *hLstCompoundKey* and/or *hLstSorted* is identical. |
| *hLstDetail* is specified | &lt;Name of key 1&gt; + TAB + &lt;Type&gt; + TAB+ &lt;Size&gt; + TAB + &lt;Expression&gt; + TAB + &lt;Unique&gt; + TAB + &lt;Caption&gt; + CR +... |
| *hLstDetailPlus* | &lt;Name of key 1&gt; + TAB + &lt;Type&gt; + TAB + &lt;Size&gt; + TAB + &lt;Expression&gt; + TAB + &lt;Unique&gt; + TAB + &lt;Caption&gt; + TAB + &lt;Integer part of numeric keys&gt; + TAB + &lt;Decimal part of numeric keys&gt; + CR +... |

Where:

- &lt;Nom de clé X&gt; key name.

- &lt;Type&gt; key type: "T" for text (and monetary) or "N" for numeric.

- &lt;Taille&gt;: column size.

- &lt;Formule&gt;: key formula if the key is compound (if the key is simple, only the key name is returned).

- &lt;Unique&gt;:

	- "2" for primary keys.

	- "1" for a unique key,

	- "0" for a key with duplicates.




- &lt;Libellé&gt;: key label.

- &lt;Partie entière des clés numériques&gt; number of digits in the integer part of numeric keys.

- &lt;Partie décimale des clés numériques&gt; number of digits in the decimal part of numeric keys.




**`<Source>: (Type corresponding to the specified source)`**

Name of table (query or view) whose keys will be listed.

If a query name is specified, the query must be running ( or ) to use ****. Otherwise, a WLanguage error occurs.

**`<Path of the WDD file>: (Optional character string)`**

Full path of the database schema (i.e. the .WDD file) in which the table has been defined. 
If this parameter is not specified or is an empty string (""), the table is searched for in the current database schema.

**`<Password of the WDD file>: (Optional string or Secret string)`**

Password defined for the database schema. 
If no password is defined, this parameter must be an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Options>: (Optional Integer constant (or combination of constants))`**

Type of list to perform:



|   |   |
| --- | --- |
| *hLstAll* | Lists all the keys (*hLstKey* + *hLstCompositeKey*).<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstCompositeKey* | Lists the composite key items only.<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstDetail* | Detailed information (idem WINDEV 5.5). |
| *hLstDetailPlus* | For the numeric keys, add the number of digits found in the integer part and in the decimal part.<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstKey* | Lists the key items (non-composite keys only).<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstLogicalOrder* | Sorts the list in logical order of items (ignored if *hLstSorted* is specified).<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstNormal*<br>(default value) | Corresponds to *hLstAll*. Default value used if constants *hLstKey*, *hLstCompoundKey* and *hLstAll* are not used. |
| *hLstOriginalItem* | Used on a log file (xxxJNL.fic), lists the keys of the initial source file (that was logged). For example, on CustomerJNL.Fic, list the key items of CUSTOMER file.<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |
| *hLstSorted* | Sorts the list in ascending order.<br>![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This constant is ignored. |

## Remarks


### Displaying the result in a List Box or Combo Box control
<a name="displaying_the_result_list_box_combo_box_control_ELTPARAGRAPHE000344"></a>

&lt;Result&gt; can be directly assigned to a List Box or Combo Box control by [&lt;List Box&gt;.Add](../WDLang1/1000017319.md). Each row will contain the name of one of the keys found.
<a name="NOTE0_2"></a>


### Extracting information from the result
<a name="extracting_information_from_the_result_ELTPARAGRAPHE000359"></a>

To extract information from the detailed result, it is recommended to use [&lt;ANSI string&gt;.ExtractString](../WDLang1/1000024876.md).
