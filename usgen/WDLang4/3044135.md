


## HSecurity (Function)

***In french: HSécurité***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables the automatic security mechanism on one or more tables.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HSecurity(False) // Disables the protection mechanism
HSecurity(True) // Enables the protection mechanism
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HSecurity([<Table>, ] <Security level>)`
---

**`<Result>: (Integer)`**

Former security level (before running **HSecurity**). 

**`<Table>: (Optional character string)`**

Name of the table used. 
If this name is not specified, **HSecurity** manipulates all the tables defined in the database schema.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This parameter is ignored. Security is enabled for all tables in the current database schema.

**`<Security level>: (Integer or boolean)`**

Requested security level:

- 0 or <u><u><u><u>False</u></u></u></u> (default): Safety mechanism disabled. Data is written to tables at the highest speed possible.

- 1 or <u><u><u><u>True</u></u></u></u>: Security mechanism activated: writing speed is slower than with the HSecurity(0) option, but security is guaranteed when writing to tables.

- 2: Maximum security mechanism: Table writing speed is slower than with the HSecurity(1) option..

## Remarks


### HSecurity and HFlush functions
<a name="docparampagetitleshort_and_hflush_functions_ELTPARAGRAPHE000095"></a>

**HSecurity** and [HFlush](../WDLang4/3044004.md) can both be used to force a physical write operation on disk.

However:

- **HSecurity** forces the table(s) to be written. The HFSQL engine automatically performs the write operation. The tables are not closed during this write operation. This results in slower write speeds.

- [HFlush](../WDLang4/3044004.md) forces a write operation to the tables when it is called. The tables are closed and then re-opened during this write operation. The write operation is not slowed down.
