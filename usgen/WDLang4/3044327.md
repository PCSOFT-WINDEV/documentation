


## HModifyFileRights (Function)

***In french: HModifieDroitFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the rights granted to a user or group on an HFSQL Client/Server table.

**Note**: You can use the [HInfoFileRights](../WDLang4/3044321.md) function to find out the rights of a group or user to an HFSQL Client/Server table. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Copy the rights from one user to another 
sRights is string
sRights = HInfoFileRights("MyConnection", "Moore", hRightsRead + hRightsInsert, "MyDatabase", "MyFile.fic")
HModifyFileRights("MyConnection", "Doe", hRightsRead + hRightsInsert, ...
		sRights, "MyDatabase", "MyFile.FIC")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HModifyFileRights(<Connection> , <User/Group> , <Rights to modify> , <New values> , <Database> , <Table>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the rights have been modified, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error. 


No modification is performed if the new value is already assigned to the specified rights.

**Note**: [HErrorInfo](../WDLang4/3044071.md) will return "Unknown user" or "Unknown group" if the current user tries to access information about a specific user or group but does not have enough permissions (*hRightsSeeUser* constant).

**`<Connection>: (String or Connection variable)`**

Connection for which the rights granted to a user or group of users should be modified. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 




**`<User/Group>: (Character string)`**

Name of the user or group whose rights should be modified.

**`<Rights to modify>: (Integer constant (or combination of constants))`**

List of rights to modify:


|   |   |
| --- | --- |
| *hRightsAutoModif* | Rights to perform the automatic table modification on a table. |
| *hRightsChangeLink* | Rights to change the integrity rules of a table. |
| *hRightsChangeOwner* | Rights to change the owner of an element. |
| *hRightsChangeRights* | Rights to change rights. |
| *hRightsDelete* | Rights to delete the records from a table. |
| *hRightsDeleteFile* | Rights to delete a table ([HDeleteFile](../WDLang4/3044294.md)). |
| *hRightsInsert* | Rights to add records to a table. |
| *hRightsLock* | Rights to lock the tables or the records of a table. |
| *hRightsMaintenance* | Rights to start a reindex operation or to calculate statistics on a table. |
| *hRightsManageDuplicate* | Rights to enable and disable the management of duplicates. |
| *hRightsRead* | Rights to read the records of a table. |
| *hRightsUnmask* | Rights to unmask items in a table. |
| *hRightsUpdate* | Rights to modify the records of a table. |



**`<New values>: (Integer constants)`**

List of new values for the modified rights. New values must be assigned to all the rights specified in &lt;Rights to modify&gt; (in the same order).

If a single value is indicated in this parameter, it will be assigned to all the rights specified in &lt;Rights to modify&gt;.

The possible values are:


|   |   |
| --- | --- |
| *hAllowed* | The relevant rights are granted to the user or group. |
| *hForbidden* | The relevant rights are not granted to the user or group. |
| *hInherit* | The right is undefined at this level for the user (or the group to which they belong). The HFSQL server uses the right defined at the upper level for the user (or the group to which they belong). For a table, the HFSQL server uses the right defined for the user (or the group to which the user belongs) at database level. |



**`<Database>: (Character string)`**

Name of the database containing the table for which the rights must be modified. 

- If the database corresponds to the one defined in the connection, this parameter can correspond to an empty string (""). 

- A WLanguage error occurs if no database is defined in the connection and if this parameter corresponds to an empty string.




**`<Table>: (Character string)`**

Name of the table for which the rights should be modified.

<a name="NOTE0_1"></a>

## Remarks


### When are rights changed? 
<a name="when_are_rights_changed_ELTPARAGRAPHE000208"></a>

Rights are modified when **HModifyFileRights** is run. There is no need to restart the server to apply the new rights.
