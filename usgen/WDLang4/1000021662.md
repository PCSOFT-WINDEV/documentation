


## hdfsRights (Variable type)

***In french: hdfsDroit***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **hdfsRights** type is used to define the advanced characteristics regarding the access rights to an element (file, link, directory) of the Hadoop file system. You can define and change the characteristics of these rights using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection
MyConnection is hdfsConnection
MyConnection.namenode = "MyServer"
MyConnection.User = "Admin"
hdfsOpenConnection(MyConnection)
// Retrieve the directory content
Content is array of hdfsStatus = hdfsList(MyConnection, "/")
// Display the rights
FOR EACH elem OF Content
	Trace("------------------------------")
	Trace(elem.Rights.UserWriting)
	Trace(elem.Rights.GroupWriting)
	Trace(elem.Rights.OtherWriting)
END
```

## Properties


### Properties specific to hdfsRights variables
<a name="properties_specific_hdfsrights_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used to handle the rights:

| Property name | Type used | Effect |
| --- | --- | --- |
| GroupExecution | Boolean | <br><br>- <u><u><u>True</u></u></u> if the members of the owner group have the rights to run a file or the files found in a directory.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| GroupReading | Boolean | <br><br>- <u><u><u>True</u></u></u> if the members of the owner group have the rights to read.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| GroupWriting | Boolean | <br><br>- <u><u><u>True</u></u></u> if the members of the owner group have the rights to write.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| OtherExecution | Boolean | <br><br>- <u><u><u>True</u></u></u> if a user (other than the owner and the members of his group) has the rights to run a file or the files found in a directory.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| OtherReading | Boolean | <br><br>- <u><u><u>True</u></u></u> if a user (other than the owner and the members of his group) has the rights to read.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| OtherWriting | Boolean | <br><br>- <u><u><u>True</u></u></u> if a user (other than the owner and the members of his group) has the rights to write.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| UserExecution | Boolean | <br><br>- <u><u><u>True</u></u></u> if the owner has the rights to run a file or the files found in a directory.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| UserReading | Boolean | <br><br>- <u><u><u>True</u></u></u> if the owner has the rights to read.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| UserWriting | Boolean | <br><br>- <u><u><u>True</u></u></u> if the owner has the rights to write.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
