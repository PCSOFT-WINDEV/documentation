


## GeometryCollection (Variable type)

***In french: MultiGéométrie***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **GeometryCollection** type is used to store a collection of geometries of different types. In other words, it is a heterogeneous collection. It can store a collection of points, polygons, etc. 

You can also store geometries defined using different coordinate systems (e.g., points defined with geometric coordinates and points defined with geographic coordinates) in a single variable of type **GeometryCollection**. However, bear in mind that storing different types of points together may lead to errors if an operation tries to mix both types. For example, the distance between a point in geometric coordinates and a point in geographic coordinates cannot be defined.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
GeoCollection is GeometryCollection
g is Geometry 

// Add a point in geometric (2D) coordinates
p is Point2D
g = p
GeoCollection.Geometry.Add(g)

// Add a polygon in geographic coordinates
polyGeo is PolygonGeo
polyGeo.Outline.AddPoint(0, 1)
polyGeo.Outline.AddPoint(1, 1)
polyGeo.Outline.AddPoint(1, 0)
polyGeo = GeometryCorrect(polyGeo)
g = polyGeo
GeoCollection.Geometry.Add(g)
```

## Properties


### Properties specific to GeometryCollection variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000037"></a>

The following properties can be used to manipulate a variable of type **GeometryCollection**:

| Property name | Type used | Effect |
| --- | --- | --- |
| Geometry | Array of [Geometry](../WDLang4/1410090098.md) | Geometries stored in the variable of type **GeometryCollection**. |
| Type | Integer constant | Type of the current geometry. For a collection of geometries, corresponds to the *gtGeometryCollection* constant.<br>Note: Until version 2024 Update 2, this constant was named *stShapeCollection*.<br><br>**This property is available in read-only.** |
