


## &lt;Source&gt;.Found (Function)

***In french: &lt;Source&gt;.Trouve***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the current record corresponds to the current filter or search.

**&lt;Source&gt;.Found** returns <u><u><u>True</u></u></u> if the current record exists and if one of the following conditions is met:

- the table browse is filtered and the current record corresponds to the filter conditions,

- the table browse was started by a search and the current record corresponds to the sought value,

- the table browse is neither filtered nor started by a search.




When an operation causes an exit from the filter or table (i.e. when [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>), **&lt;Source&gt;.Found** returns <u><u><u>False</u></u></u>.

**Note** The function **&lt;Source&gt;.Found** corresponds to the variable H.Trouve.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Customer.ReadSeekFirst(Name, "Moore")
IF Customer.Found() = True THEN
	Info("Record found")
ELSE
	Error("No record found")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.Find()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the current record corresponds to the filter or to the search, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<Source>: (Type corresponding to the specified source)`**

 
Name of the table, view or query used.
