


## &lt;Polygon2D variable&gt;.Cover (Function)

***In french: &lt;Variable Polygone2D&gt;.Couvre***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if geometry A (of type 2D polygon) covers geometry B. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FormeCouvre.gif)
Remarks: 

- If geometry A covers geometry B, this means that every point of geometry B lies inside or intersects the boundary of geometry A. In this case, no point of geometry B lies outside geometry A.

- Difference compared with [&lt;Polygon2D variable&gt;.Contain](../WDLang4/1410090522.md): With **&lt;Polygon2D variable&gt;.Cover**, the interiors of both geometries must not necessarily have a point in common. A polygon covers its own boundary, but it does not contain it.



<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create a large polygon
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-5.00, 3.00)
o2DPolygon_1.Outline.AddPoint(4.00, 5.00)
o2DPolygon_1.Outline.AddPoint(4.00, -3.00)
o2DPolygon_1.Outline.AddPoint(-4.00, -3.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-5.00, 3.00)

// Create a smaller polygon inside the larger one
o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(-2.00, 1.00)
o2DPolygon_2.Outline.AddPoint(3.00, 1.00)
o2DPolygon_2.Outline.AddPoint(0.00, -1.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(-2.00, 1.00)

// Test Geometry.Cover and Geometry.Contain
//--------------------------------------------------
o2DPolygon_1.Cover(o2DPolygon_2) // True
o2DPolygon_1.Contain(o2DPolygon_2) // Also True

o2DPolygon_1.Cover(o2DPolygon_2.Outline) // True: A polygon COVERS its own boundary.
o2DPolygon_1.Contain(o2DPolygon_1.Outline) // False: A polygon DOES NOT CONTAIN its own boundary.
```

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.GeometryCover(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if geometry A covers geometry B,

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).

## Remarks


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000336"></a>

In a table, you can apply a filter on spatial data and loop through the table. For example, the filter can be based on the result of **&lt;Polygon2D variable&gt;.Cover**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;Polygon2D variable&gt;.Cover**. 

- Spatial_item is a spatial item in the table. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire table is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
