


## &lt;mongoDatabase variable&gt;.ExecuteCommand (Function)

***In french: &lt;Variable mongoBase&gt;.ExécuteCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Runs a generic command on a MongoDB database.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MDBDatabase is MongoDatabase
// Run a command on a MongoDB database
BaseMDB.ExecuteCommand("{ ""ping"": 1 }" )
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Running a command on a MongoDB database

`<Result> = <Database>.RunCommand(<Command>)`
---

**`<Result>: (mongoResult variable)`**

[mongoResult](../WDLang4/1000022415.md) variable corresponding to the result of command. If a problem occurs. [ErrorInfo](../WDLang1/3013008.md) is used to identify the error.

**`<Database>: (mongoDatabase variable)`**

Name of the [mongoDatabase](../WDLang4/1000022410.md) variable corresponding to the MongoDB database where the command will be run.

**`<Command>: (Character string, buffer or variant)`**

Document describing the command to run. This document can be: 

- a document in JSON format. In this case, this parameter corresponds to a character string. 

- a document in BSON format. In this case, this parameter corresponds to a buffer. 

- a variant.
