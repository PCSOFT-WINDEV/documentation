
## HSecurityPolicyCheck (Function)

***In french: HPolitiqueSécuritéVérifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks that each user accounts complies with the password security policy associated with the HFSQL server. 

Note: To use this function, you need to be connected to the HFSQL server with a "super user" account. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(HSecurityPolicyCheck(MyConnection))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HSecurityPolicyCheck(<Connection> , <Type of check>)`
---

**`<Result>: (Character string)`**

List of users that match the criteria of the security check. User names are separated by carriage returns (CR). 

**`<Connection>: (String or Connection variable)`**

HFSQL server connection to be manipulated. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 




**`<Type of check>: (Integer constant)`**

Type of verification:



|   |   |
| --- | --- |
| *hLockedOutAccount* | Returns a list of users whose accounts have been locked. <br><br>Note: To unlock a locked account, use [HSecurityPolicyUnlockAccount](../WDLang4/1410091235.md). |
| *hPasswordCheckExpiration* | Returns a list of users who have exceeded the password validity period. |
