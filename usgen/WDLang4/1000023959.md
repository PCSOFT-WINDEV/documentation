<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Checking the existence of a table in HFSQL Client/Server

`<Result> = <Connection>.FileExist(<Physical file>)`
---

**`<Result>: (Boolean)`**



- <u><u><u>True</u></u></u> if the physical table exists on the server, 

- <u><u><u>False</u></u></u> otherwise.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection associated with the table.

**`<Physical file>: (Character string)`**

Physical name of the searched table. The file extension must be specified ("Customer.fic" for example).


<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **&lt;Connection variable&gt;.FileExist** can be used whether the file is open or closed.

- **&lt;Connection variable&gt;.FileExist** does not open the table if it is closed.
