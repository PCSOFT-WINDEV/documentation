


## HCreateServerTrigger (Function)

***In french: HCréeTriggerServeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds or modifies a server trigger on the HFSQL server. To perform these operations: 

- The trigger must have been previously described in the database schema.

- The stored procedure released by the trigger must exist on the server. This procedure can be updated by [HUpdateSet](../WDLang4/3044354.md).




**This function is used to update the HFSQL server without having to perform an automatic data update.**

**Reminder** Server triggers are stored procedures executed by the server before or after a write action performed on a database file. For more details, see [Server triggers](../WDLang4/3044369.md).  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HCreateServerTrigger(ClientTrigger)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HCreateServerTrigger(<Trigger>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Trigger>: (Character string)`**

Name of the server trigger to create. This trigger was described in the database schema. 
If this parameter corresponds to "\*", all the triggers described in the database schema will be created.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The server triggers described in the database schema can be updated via the automatic data modification.
