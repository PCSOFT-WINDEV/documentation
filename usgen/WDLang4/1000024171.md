


## &lt;Source&gt;.ActivateAutoFilter (Function)

***In french: &lt;Source&gt;.ActiveFiltreAuto***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables an automatic filter on the linked tables when browsing an XML file. This filter can be disabled by [&lt;Source&gt;.DeactivateAutoFilter](../WDLang4/1000024219.md).

**Attention** This function is only available for the XML Native Connector.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enable all the possible automatic filters on the Customer table
Customer.ActivateAutoFilter("*" )
// except between Customer and Order tables
Customer.DeactivateAutoFilter(Order)

/////////////////////////////

// Browse orders
Order.ReadFirst(OrderID)
WHILE NOT Order.Out()
	// Browse order lines of current order
	OrdLine.ReadFirst(OrderID)
	WHILE NOT OrdLine.Out()
		OrdLine.ReadNext(OrderID)
	END
	// Next order
	Order.ReadNext(OrderID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Browse table>.ActivateAutoFilter(<Table to filter>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the filter is enabled, 

- <u><u><u><u>False</u></u></u></u> if an error occurred (file or item not found).




**`<Browse table>: (Name of table)`**

Name of the table used for the browse.





**`<Table to filter>: (Name of table)`**

Name of the table to filter when positioned in the browse table.

This parameter can correspond to "\*". In this case, all the possible automatic filters will be enabled.





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Let's see a simple example:

```wl
Parent.ActivateAutoFilter(Child)
```

This code indicates that when the records of the Son table are browsed, this browsing is done with respect to the current 'context' (node) of the Father table: all the 'Sons' of the current 'Father' will be browsed.


```wl
Parent.DeactivateAutoFilter(Child)
```

This code indicates that the previous filtering is not active: the Son table will be browsed independently of the Father table.. This means that all the records of Child will be browsed in the given child.

**&lt;Source&gt;.ActivateAutoFilter** is used to enable/disable the hierarchical link between Parent and Child during browse operations.
