


## HUpdateLink (Function)

***In french: HMiseAJourLiaison***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Updates on the server all the links of an HFSQL Client/Server table.

Note: All tables related to the links must have been configured with [HChangeDir](../WDLang4/3044168.md), if necessary.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Updates the links of the Customer table
HUpdateLink(Customer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HUpdateLink(<Table> [, <Option>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the update was completed,

- <u><u><u><u>False</u></u></u></u> if an error occurs. 




**`<Table>: (Character string)`**

Name of the table used to know the list of the links taken into account. This parameter can also correspond to: 

- "\*", to indicate that all tables must be taken into account,

- a table group name, defined in the database schema. 




**`<Option>: (Optional constant (or combination of constants))`**

Options for the automatic data modification: 


|   |   |
| --- | --- |
| *hmsNoCheck* | The automatic data modification is performed even if:<br><br>- the description of the table is more recent than the description of the database schema,<br><br>- the GUID of the table is different from the GUID of the database schema.<br><br><br> |
| *hmsNormal* <br>(Default value) | Default operating mode of the automatic data modification. |


**Note**: The tables used must not be open (by the application or by another application).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The items used by the links must exist.

- All the files of the database schema must be present if you use the "\*" parameter

- When links are updated, the links removed from the database schema are also removed from the HFSQL server. 

- You can use [HModifyStructure](../WDLang4/1000019439.md) before **HUpdateLink**.
