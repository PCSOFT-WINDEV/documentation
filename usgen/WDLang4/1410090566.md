


## &lt;Polygon2D variable&gt;.Distance (Function)

***In french: &lt;Variable Polygone2D&gt;.Distance***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Calculates the distance between a 2D polygon and another geometry. For geometries other than points, this distance is calculated from the nearest points between the two geometries.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Distance(<Geometry B>)`
---

**`<Result>: (Real)`**

Distance between nearest points of geometry A and geometry B. 

- **For geometries defined with 2D coordinates**, this distance is calculated based on the Euclidean (Pythagorean) distance. The distance is returned in the same units as the point coordinates.

- **For geometries defined using geographic coordinates**, this distance is calculated using the WGS84 reference system, which takes into account the curvature of the earth. The distance is returned in meters.




**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Second geometry used. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).

## Remarks


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000253"></a>

In a table, you can apply a filter on spatial data and loop through the table. For example, the filter can be based on the result of **&lt;Polygon2D variable&gt;.Distance**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;Polygon2D variable&gt;.Distance**. 

- Spatial_item is a spatial item in the table. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire table is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
