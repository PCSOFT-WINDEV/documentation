


## Structure of log files (HFSQL Client/Server)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000255"></a>
The following files are automatically created when logging an HFSQL Client/Server table:


|   |   |
| --- | --- |
| **JNL_FILES.FIC** | Description of log tables. |
| **JNL_OPERATION.FIC** | Description of actions performed on a log table. |
| **JNL_USERS.FIC** | Description of users performing an action on a log table. |
| **xxxJNL.FIC** | File created for each log table. Contains the value of records used before and after each operation. |


These files are created according to the following structure:


|   |   |
| --- | --- |
| ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Journal_CS.gif) | **1. __JNL directory**<br>This directory contains:<br><br>- The table log file.<br><br>- The user log.<br><br>- The operation log.<br><br>- For each log table in each database, the corresponding log file. The tree structure used corresponds to the tree structure of the tables associated with the database schema.<br><br><br>**For example**if the Command table in DataApplicationA is logged, the subdirectory __JNL\\DataApplicationA will contain the table CommandJNL.FIC.<br><br>**Another example** If the Customer table of DataApplicationB is jounalized, the subdirectory __JNL\\DataApplicationA\\Customer will contain the table CustomerJNL.FIC.<br><br>**2. Database directory** DataApplicationA<br><br>**3. Database directory** DataApplicationB |

This page presents the structure of these files.

<a name="NOTE2_1"></a>


## Table JNL_FILES.FIC
<a name="table_jnlfilesfic_ELTTEXTE000279"></a>
The various fields in the JNL_FILES.FIC table are as follows:


|   |   |
| --- | --- |
| **JNLFile_ID** | Table identifier. |
| **Source_DB_File_Location** | Name of database + '\\' + relative path of log file. |
| **Source_File_GUID** | GUID of log table. |
| **JNL_File_GUID** | GUID of write-to-file log. |



<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Table JNL_OPERATION.FIC
<a name="table_jnloperationfic_ELTTEXTE000303"></a>
The various fields in the JNL_OPERATION.FIC table are as follows:


|   |   |
| --- | --- |
| **Operation_ID** | Identifier of the operation. |
| **USER_ID** | Identifier of user who performs the operation. This identifier corresponds to the identifier of the table JNL_USER.Fic |
| **JNLFile_ID** | Identifier of logged file where the operation is performed. This identifier corresponds to the identifier of the table JNL_FILES.Fic. |
| **WLFunction_ID** | Identifier of the WLanguage function used in the program. To find out the name of the WLanguage function used, simply check the ListeDéfinitionHF.WL file (located in the "Personal\\Extern\\" subdirectory of the product) |
| **Server_Time** | Date of operation on the server (in UTC format, universal time) |
| **Record_Number** | Number of the modified record |
| **Source_Record_Backup_ID** | Identifier in the file of values. Corresponds to the record value before the operation. |
| **Modified_Record_Backup_ID** | Identifier in the file of values. Corresponds to the record value after the operation. |
| **HLogInfoMsg** | Value defined by [HLogInfo](../WDLang4/3044009.md). |
| **HComputer_ID** | Text defined by [HComputer](../WDLang4/3044111.md). |

<a name="NOTE4_1"></a>


## Table JNL_USERS.FIC
<a name="table_jnlusersfic_ELTTEXTE000327"></a>
The various fields in the JNL_USERS.FIC table are as follows:


|   |   |
| --- | --- |
| **USER_ID** | User identifier. |
| **Login** | Username. |
| **Workstation_Name** | Name of user computer. |
| **Workstation_IPAddress** | IP address of user computer. |
| **Application** | Application name |

<a name="NOTE5_1"></a>


## Table *JNL.FIC (log file)
<a name="table_jnlfic_log_file_ELTTEXTE000351"></a>
The table \*JNL.Fic contains:

- the items found in the table below, 

- all log fields in the corresponding HFSQL log table.





|   |   |
| --- | --- |
| **USER_ID** | Identifier of the user who performed the operation. This number identifies the record in the JNL_Users.Fic table |
| **Record_Number** | Record number in original log file. |
| **Record_Status** | Record status (modified, deleted, added, ...) |
| **WLFunction_ID** | Identifier of the WLanguage function used in the program. To find out the name of the WLanguage function used, simply check the ListeDéfinitionHF.WL file (located in the "Personal\\Extern\\" subdirectory of the product used) |
| **Server_Time** | Date of operation on the server (in UTC format, universal time) |
| **HLogInfoMsg** | Value defined by [HLogInfo](../WDLang4/3044009.md). |
| **HComputer_ID** | Text defined by [HComputer](../WDLang4/3044111.md). |
| **IDJNL** | Identifier of the log |
