


## &lt;Source&gt;.Password (Function)

***In french: &lt;Source&gt;.MotDePasse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the password used to create or open a table. The password is stored and it will be used when opening or creating the table if no password is specified.

Remarks: 

- **Attention** A password is required to encrypt data. The data encryption must be configured during the file description in the data model editor ("Details" tab).

- This password can also be specified in the functions for creating the table ([&lt;Source&gt;.Creation](../WDLang4/1000024207.md), [&lt;Source&gt;.CreateIfNotFound](../WDLang4/1000024208.md)) and for opening the table ([&lt;Source&gt;.Open](../WDLang4/1000025043.md)).

- **Encrypted files in an HFSQL connection**:  **Caution**: The order of use of functions for connecting to an HFSQL Client/Server database is important.. For more details, see [Optimizing the connection times to the HFSQL Client/Server databases](../WDLang4/9000176.md).


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: This function is not available for databases accessed via JDBC.

<a name="sample_code"></a>

## Example


```wl
// Open a table with password and error check
Customer.Password("Password")
IF Customer.CreateIfNotFound() = False THEN
	Error("HFSQL error: " + HErrorInfo())
	RETURN
END
// <Source>.ErrorPassword is used to find out whether the error that occurred is a password error
IF Customer.CreateIfNotFound() = False THEN
	// Error details
	IF HErrorPassword() = True THEN
		Error("Invalid password")
		// Code to retry
	END
END
```

## Syntax

`<Result> = <Source>.Password([<Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the password is saved,

- <u><u><u><u>False</u></u></u></u> if an error occurred (insufficient memory for example). [HError](../WDLang4/3044088.md) and [HErrorInfo](../WDLang4/3044071.md) return more details about the problem.




**`<Source>: (Type corresponding to the specified source)`**

Name of table that uses a password. 
If the table is declared with [&lt;Source&gt;.DeclareExternal](../WDLang4/1000024214.md), &lt;Source&gt; corresponds to the name of the table alias.

**`<Password>: (Optional character string)`**

Password associated with the table. 
If this parameter is not specified or is an empty string (""), no password is defined for the table. The password size is not limited.


**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png)![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) HFSQL table password is case insensitive.

## Remarks


### When to use &lt;Source&gt;.Password?
<a name="when_use_docparampagetitleshort_ELTPARAGRAPHE000291"></a>

**&lt;Source&gt;.Password** must be called:

- before explicit opening or creation functions: [&lt;Source&gt;.Open](../WDLang4/1000025043.md), [&lt;Source&gt;.Creation](../WDLang4/1000024207.md), [&lt;Source&gt;.CreateIfNotFound](../WDLang4/1000024208.md).

- before the HFSQL functions that access the tables and that automatically open the tables if not already done (read, search, add, ...).




Remarks: 

- If a password is specified in the explicit opening or creation functions ([&lt;Source&gt;.Open](../WDLang4/1000025043.md), [&lt;Source&gt;.Creation](../WDLang4/1000024207.md), [&lt;Source&gt;.CreateIfNotFound](../WDLang4/1000024208.md)), the password specified in **&lt;Source&gt;.Password** is ignored.

- HFSQL table passwords are case insensitive.

- To change a password on an existing table or add a password to a table created without a password, you must use [&lt;Source&gt;.ChangePassword](../WDLang4/1000024591.md).



<a name="NOTE0_2"></a>


### Defining a password on a table
<a name="defining_password_table_ELTPARAGRAPHE000351"></a>

A table will be protected by password if:

- **&lt;Source&gt;.Password** was used before the function for creating the table ([&lt;Source&gt;.Creation](../WDLang4/1000024207.md) and [&lt;Source&gt;.CreateIfNotFound](../WDLang4/1000024208.md)),

- or the password has been specified directly in the table creation function.




**Note** A table can be password-protected without being encrypted, and vice versa. The password is independent of data encryption. The data encryption must be configured during the file description in the data model editor ("Details" tab).
<a name="NOTE0_3"></a>


### Deleting the password defined on a table
<a name="deleting_the_password_defined_table_ELTPARAGRAPHE000378"></a>

To delete a password on a table, an automatic table modification must be performed.

To do so, perform a modification in the database schema (modify the size of an item for example). In this case, an automatic table modification will be proposed when the database schema is generated. You will be able to modify or delete the password associated with one or more tables.

If your tables are already deployed, specify that an automatic table modification is required when creating the setup program. The password will be deleted or modified.

**Attention**: if you remove the password from your tables, don't forget to adapt your code.
