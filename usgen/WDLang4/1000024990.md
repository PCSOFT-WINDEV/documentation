


## &lt;Source&gt;.ImportHF55 (Function)

***In french: &lt;Source&gt;.ImporteHF55***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Imports a Hyper File 5.5 table into a table in HFSQL Classic format.

- The table in Hyper File 5.5 format must be described in the data model editor.

- The table in HFSQL Classic format must be described in the data model editor, or it must be declared by [&lt;Source&gt;.Declare](../WDLang4/1000024213.md), [&lt;Source&gt;.DeclareExternal](../WDLang4/1000024214.md) or [HDescribeFile](../WDLang4/1000024215.md).




**Remarks**: 

- The two tables can have different structures.

- This function is not available when using a self-contained executable.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Imports the name and address of customers,
// ignore the other items
IF NOT Customer.ImportHF55("Customer", "C:\AnExample\CUSTOMER.FIC", ...
			"C:\AnExample\AnExample.wdd", "", "FullName,Address", ...
			"Name,Addr", hDefaultVal + hImpConversion) THEN
		  Error("Unable to import")
ELSE
	// Process
	...
END
```

## Syntax

### Import into a table of the same structure

`<Result> = <Source>.ImportHF55(<HF55 File> , <Full path of HF55 File> , <Password of HF55 File> , <Full path of WDD 55 file> , <Password of WDD 55 File> [, <Options> [, <Progress Bar>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HError](../WDLang4/3044088.md) is used to identify the problem.




**`<Source>: (Type corresponding to the specified source)`**

Logical name of table in HFSQL Classic format into which the import will be performed.

**`<HF55 File>: (Character string)`**

Logical name of table in Hyper File 5.5 format, described in WINDEV 5.5 database schema (.WDD file) and containing data to be imported.

**`<Full path of HF55 File>: (Character string)`**

Full access path of Hyper File 5.5 table to import.

**`<Password of HF55 File>: (Character string)`**

Password associated with the table to import. This password will be used to decrypt the data found in the table. If no password was defined, use an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Full path of WDD 55 file>: (Character string)`**

Access path to the .WDD file of database schema in Hyper File 5.5 format. This database schema contains the description (or structure) of table to import. All the database schema formats recognized by Hyper File 5.5 can be used (WINDEV 5.5B, 5.5, 5.0, and 4.1).

**`<Password of WDD 55 File>: (Character string or Secret string)`**

Password associated with the database schema containing the table to import. If no password was defined, use an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Options>: (Optional Integer constant (or combination of constants))`**

Type of import to perform: 



|   |   |
| --- | --- |
| *hCopyAutoID* | The automatic identifier is copied. It is not recalculated.<br>If the HFSQL Classic table contains an automatic identifier while the Hyper File 5.5 table contains no automatic identifier, the automatic identifier is reset to 0 in the HFSQL Classic table. |
| *hDefaultVal* | For the non-imported items, the values of current record (HFSQL Classic) are reinitialized with their default value. |
| *hImpBreakable* | The import can be interrupted by pressing the Esc key on the keyboard. If the import is interrupted, the imported records are kept in the table. A re-index operation is automatically performed if necessary (cannot be interrupted). |
| *hImpConversion* | Associated fields do not have the same type or size: data extracted from the imported table is automatically converted or truncated. |
| *hImpCreation* | If the table in which the import is performed (HFSQL Classic) exists, it is overwritten. |
| *hImpIgnoreItem* | Fields in the destination table (HFSQL Classic) that have no associated fields in the imported table (Hyper File 5.5) are filled with their default value.<br>Fields in the imported table (Hyper File 5.5) that have no correspondence in the destination table are ignored. |
| *hImpNormal*<br>(default value) | This mode of import avoids any risk of data loss. The import is not performed and an error occurs in the following cases:<br><br>- fields present in the Hyper File 5.5 table but not in the HFSQL Classic table.<br><br>- associated items in the two tables but with a different size and/or format.<br><br><br>If the table to be imported (HFSQL Classic) already exists, it is populated with the imported data, otherwise the table is created. <br>Data integrity and duplicates are not checked.<br>Non-imported items take the value of the current record.<br>Automatic identifiers are recalculated. |
| *hImpNoSpace* | The space characters found at the end of string are automatically deleted during the import. |
| *hImpTestDuplicates* | Checks the duplicates during the import. |
| *hImpTestIntegrity* | Checks data integrity during an import operation. |



**`<Progress Bar>: (Optional control name or window name)`**



- Name of window where the import progress bar will be displayed. 

- Name of the Progress Bar control where the import progress will be displayed.

## Remarks


### Encrypted table
<a name="encrypted_table_ELTPARAGRAPHE000461"></a>

If the table in HFSQL Classic format to be imported is encrypted, it is necessary to specify the password before using the function **&lt;Source&gt;.ImportHF55** Use the [&lt;Source&gt;.Password](../WDLang4/1000025044.md) function.
<a name="NOTE0_2"></a>


### HFSQL Client/Server
<a name="hfsql_clientserver_ELTPARAGRAPHE000478"></a>

If the import must be performed into an HFSQL Client/Server table, the connection must be specified before using **&lt;Source&gt;.ImportHF55**. For example: 

```txt
cntHFCS is Connection
MyCSFile.ChangeConnection(cntHFCS)
MyCSFile.ImportHF55(My55File, ...)
```
