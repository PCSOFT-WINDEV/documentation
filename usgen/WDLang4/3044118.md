


## HReset (Function)

***In french: HRAZ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes: 

- one or all variables of file items with their default values. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) one or all items of a [Record](../WDLang4/1000020962.md) variable with their default values.


The default values are defined when the table is described in the data model editor.

**Remarks**: 

- **HReset** does not modify the record in the table, it only modifies the data in memory. 

- The **function HReset** modifies the [NewRecord](../Proprietes/1000017090.md) property of the table concerned: this property changes to <u><u><u>Vrai</u></u></u>.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Assign the default values to the items
HReset(Customer)
// Display
FileToPage()
```

## Syntax

### Initializing the file items with their default values

`<Result> = HReset([<Table> [, <Item>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the initialization was performed,

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) returns more details.




**`<Table>: (Optional character string)`**

Name of the table used. If this name is not specified, **HReset** will use the last table used by the last HFSQL function (function starting with "H").

**`<Item>: (Optional character string)`**

Name of item to initialize. If this parameter is not specified or if it is equal to "\*", the initialization will be performed for all table items.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This parameter is ignored. All the items are automatically reinitialized.

### Initializing the record items with their default values (Record variable)

`<Result> = HReset(<Record> [, <Item>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the initialization was performed,

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) returns more details.




**`<Record>: (Record variable)`**

Name of the [Record](../WDLang4/1000020962.md) variable used. 

**`<Item>: (Optional character string)`**

Name of item to initialize. If this parameter is not specified or if it is equal to "\*", the initialization will be performed for all record items.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) This parameter is ignored. All the items are automatically reinitialized.

## Remarks


### Opening tables
<a name="opening_tables_ELTPARAGRAPHE000188"></a>

**HReset** opens the table used. Therefore, the table must have been created.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) During the custom management of errors, the test of [HErrorLock](../WDLang4/3044099.md) must be run after the call to **HReset**.

<a name="record_variable_ELTPARAGRAPHE000213"></a>

To reset a variable of type [Record](../WDLang4/1000020962.md), you can also use [VariableReset](../WDLang1/3013069.md).
