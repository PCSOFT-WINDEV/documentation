


## HChangePassword (Function)

***In french: HChangeMotDePasse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the password of an HFSQL Classic or HFSQL Client/Server table. Applications using the old password will no longer be able to access this table: a password error will be displayed.. 

**Caution**: This is an advanced function. It must be used with great care because it can trigger errors in the client applications. 


<a name="sample_code"></a>

## Example


```wl
// Former password
HPass("*", "Password")
// Modify the password
HChangePassword(Customer, "NewPassword")
```

```wl
// Create a table with password
HPass(FileA, "TEST")
HCreation(FileA)

// Add data
FileA.ItemA = "Test 1"
HAdd(FileA)

// Read data
HReadFirst(FileA)
Info(FileA.ItemA)

// Change the password
Info("Changing the password...")
HChangePassword(FileA, "NW_Test")
Info("Password changed, the first record is read again")

// Read data again
HReadFirst(FileA)
Info(FileA.ItemA)

// Manage the errors
CASE ERROR:
	Error(HErrorInfo())
	RETURN
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HChangePassword(<Table> , <New password>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the password was modified,

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Table>: (Character string)`**

Name of HFSQL table (defined in the database schema) to use.  

**`<New password>: (Character string or Secret string)`**

New password that will be used for the table.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If the table is already password protected, this password must be specified with [HPass](../WDLang4/3044108.md) before using **HChangePassword**. 

- To modify the password of a table, you must have the rights to perform an automatic modification (*hRightsAutoModif* constant). These rights can be defined by [HModifyFileRights](../WDLang4/3044327.md). 

- This function starts an automatic modification of the table. If the table was encrypted with a different password, it will be entirely re-encrypted with the new password. This operation can take quite a long time.
