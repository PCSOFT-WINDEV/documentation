


## &lt;Polygon2D variable&gt;.Disjoint (Function)

***In french: &lt;Variable Polygone2D&gt;.Disjoint***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines whether two geometries are disjoint, i.e. whether their intersection is empty.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Example 1: Two disjoint polygons
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1.Outline.AddPoint(0.00, 3.00)
o2DPolygon_1.Outline.AddPoint(-2.00, -1.00)
o2DPolygon_1.Outline.AddPoint(-3.00, -1.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(2.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, -2.00)
o2DPolygon_2.Outline.AddPoint(-2.00, -2.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(2.00, 4.00)
o2DPolygon_2 = o2DPolygon_2.Correct()

Trace(o2DPolygon_1.Disjoint(o2DPolygon_2)) // True
```



```wl
// Example 2: Two polygons with an intersection
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1.Outline.AddPoint(0.00, 3.00)
o2DPolygon_1.Outline.AddPoint(-2.00, -1.00)
o2DPolygon_1.Outline.AddPoint(-3.00, -1.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(1.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 1.00)
o2DPolygon_2.Outline.AddPoint(-1.00, -1.00)
o2DPolygon_2.Outline.AddPoint(-3.00, 1.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(1.00, 4.00)
o2DPolygon_2 = o2DPolygon_2.Correct()

Trace(o2DPolygon_1.Disjoint(o2DPolygon_2)) // False
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Disjoint(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the intersection of geometry A and geometry B is empty.  

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).
