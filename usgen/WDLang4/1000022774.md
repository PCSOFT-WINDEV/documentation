


## &lt;Connection variable&gt;.InfoLock (Function)

***In french: &lt;Variable Connexion&gt;.InfoBlocage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the lock set on a table, on one or all the records in a table.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CSConnection is Connection
LockList is string
...
// Lists all the locks set on the tables of CSConnection
LockList = CSConnection.InfoLock()
// Lists all the locks set on the Customer.fic table of CSConnection
LockList = CSConnection.InfoLock(".\customer.fic")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Information about the locks set on a table identified by its connection

`<Result> = <Connection>.InfoLock([<Table path>] [, <Record number>])`
---

**`<Result>: (Character string)`**

Name of the table used. 

**`<Connection>: (Control name)`**

Number of the record for which the lock information is requested. 
If this parameter is not specified, **&lt;Connection variable&gt;.InfoLock** lists all the locks of the table.

**`<Table path>: (Optional character string)`**

Full path of the table, relative to the database schema defined by &lt;Connection&gt;. 
If the &lt;Connection&gt; parameter corresponds to the logical name of a table, it is ignored. 
If this parameter is not specified, all the locks set on all the tables of the database are returned.

**`<Record number>: (Optional integer)`**

Number of the record for which the lock information is requested. 
If this parameter is not specified, **&lt;Connection variable&gt;.InfoLock** lists all the locks of the table.
