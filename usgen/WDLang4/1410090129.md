


## MultiPoint2D (Variable type)

***In french: MultiPoint2D***
			
				



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **MultiPoint2D** type is used to store a set of points defined with 2D coordinates. It is a collection of points: unlike in a linestring, points are not connected.

A variable of type **MultiPoint2D** can be used to store a collection of points defined with 2D coordinates in a single HFSQL record. This avoids having to use one record for each point. This type of variable is necessary, for example, if the collection of points corresponds to the entity manipulated by a program (in this case, each point is not manipulated independently).

**Remark**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
myPoint is Point2D
mltp is MultiPoint2D
myPoint.X = 0
myPoint.Y = 1
mltp.Point.Add(myPoint)
myPoint.X = 2
myPoint.Y = 3
mltp.Point.Add(myPoint)
myPoint.X = 4
myPoint.Y = 5
mltp.Point.Add(myPoint)
myPoint.X = 6
myPoint.Y = 7
mltp.Point.Add(myPoint)
```

## Properties


### Properties specific to MultiPoint2D variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000027"></a>

The following properties can be used to manipulate a variable of type **MultiPoint2D**:

| Property name | Type used | Effect |
| --- | --- | --- |
| Point | Array of [Point2D](../WDLang4/1410090100.md) | Points in the variable. |
| Type | Integer constant | Type of the current geometry. For a collection of points defined with 2D coordinates, corresponds to the *gtMultiPoint2D* constant.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPoint2D*.<br><br>**This property is available in read-only.** |
