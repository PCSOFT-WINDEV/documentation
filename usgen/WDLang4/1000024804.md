
## WLanguage procedure called by HWatch



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [HWatch](../WDLang4/1000022407.md) when a change is made on the specified table.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Starts watching the Order table
// The ProcessOrder procedure is called whenever a record is added to the table
HWatch(Order, ProcessOrder, hRecNumAll, hwAdd)

PROCEDURE ProcessOrder(FileName, RecNum, Action)
IF BitwiseAND(Action, hsAdd) = hsAdd THEN
	Trace("An element was added to the following table: "+ FileName)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HWatch_Callback(<Modified table> , <Record number> , <Action>)`
---

**`<Modified table>: (Character string)`**

Name of the modified HFSQL table. 

**`<Record number>: (Integer)`**

Number of the modified record (equivalent to the number returned by [HRecNum](../WDLang4/3044063.md)). 

**`<Action>: (Integer constant)`**

Action that triggered the procedure. The possible values are: 



|   |   |
| --- | --- |
| *hwAdd* | Procedure started once a record is added into the table. |
| *hwCross* | Procedure started once a record is crossed in the table. |
| *hwDelete* | Procedure started once a record is deleted from the table. |
| *hwModify* | Procedure started once a record is modified in the table. |


**Caution**: If a process adds a record and modifies this record immediately after, [HWatch](../WDLang4/1000022407.md) is called once with a combination of the *hwAdd* and *hwModify* constants.
To identify these actions in the WLanguage procedure, use [BitwiseAND](../WDLang1/3050010.md). For example: 

```wl
IF BitwiseAND(Action, hsAdd) = hsAdd THEN ...
```

## Remarks


### WLanguage procedure executed in the main thread
<a name="wlanguage_procedure_executed_the_main_thread_ELTPARAGRAPHE000077"></a>

By default, this WLanguage procedure is called in the main thread of the application, with the HFSQL context that corresponds to the procedure:

- If the procedure is a local procedure of a window that uses an independent context, the context of the window will be used. 

- If the procedure belongs to a component that uses an independent context, the context of the component will be used.





|   |
| --- |
| **Caution**:<br>The procedure associated with [HWatch](../WDLang4/1000022407.md) can be called at any time in the application.<br>If the procedure reads records or moves between records in the tables, this will have an impact on the application (like the timers).<br>Therefore, you may have to call [HSavePosition](../WDLang4/3044136.md) and [HRestorePosition](../WDLang4/3044137.md) to save the contexts of files used.<br><br>[Multitask](../WDLang1/3015004.md) must not be used in the procedure code. |




### WLanguage procedure executed in a secondary thread
<a name="wlanguage_procedure_executed_secondary_thread_ELTPARAGRAPHE000237"></a>

If the WLanguage procedure is called in a secondary thread: 

- the HFSQL context is copied the **first time** **WLanguage procedure called by HWatch** is called. Only the directories containing the tables in HFSQL Classic mode and/or the connections in HFSQL Client/Server mode are stored.
	**Note**: If [HChangeDir](../WDLang4/3044168.md) is called between two calls to the **WLanguage procedure called by HWatch** function, [HChangeDir](../WDLang4/3044168.md) is ignored. Example: 
	
	```wl
	HWatch(AFile, hSecondaryThread)
	// The HChangeDir function is ignored
	HChangeDir(AnotherFile)
	HWatch(AnotherFile, hSecondaryThread)
	```


- UI elements (windows, controls, etc.) cannot be manipulated in the secondary thread. When a secondary thread must interact with the user or update the UI, it must use a process started from the main thread. This process can correspond to:

	- a global procedure of the project or a local procedure (of a window, etc.) called by [ExecuteMainThread](../WDLang1/1000019862.md),

	- the "Request for refreshing the display" event of a window run by [RequestRefreshUI](../WDLang1/1000023899.md).







For more details on this procedure, see [Parameters of the procedure used by WLanguage procedure called by HWatch](../WDLang4/1000024804.md).
