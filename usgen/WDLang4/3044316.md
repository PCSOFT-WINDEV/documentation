


## HFSQL Client/Server functions
			



**Note**: These functions are also available in prefix syntax ([HFSQL Client/Server functions (prefix syntax)](../WDLang4/1000025031.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000084"></a>
Several HFSQL functions are used to manage the HFSQL Client/Server data.

These functions are mainly used to:

- Manage users and groups of users (creation, rights, ...)

- Manage the tables found on the server

- Manage the referential integrity (functions for managing the links)

- Manage the server.
