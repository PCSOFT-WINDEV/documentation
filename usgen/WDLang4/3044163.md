


## HDBOpen (Function)

***In french: HDBOuvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the xBase table and the "memo" file, if any.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HDBOpen("ORDERS", "OR", "C:\FILE\ORDERS.DBF")
HDBIndex("ORDERS", "C:\FILE\ORDERS.NTX", "OrdNum")
HDBOpen("PRODUCT", "PR", "C:\FILE\PRODUCT.DBF")
HDBIndex("PRODUCT", "C:\FILE\PRODUCT.NTX", "ProdNum")

// Display the characteristics of the order 
HReadFirst("ORDERS", "OrdNum")
IF HOut() = False THEN
	HReadSeek("PRODUCT", "ProdNum", CO.PRODNUM)
	FileToScreen()
ELSE
	Error("Empty file")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HDBOpen(<Logical name of xBase file> , <Abbreviation of xBase file> , <Full name of xBase file>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Logical name of xBase file>: (Character string)`**

Logical name given to the xBase file. This name will be used to handle the xBase file programmatically.

**`<Abbreviation of xBase file>: (Character string)`**

Prefix (2 characters) used through programming to identify a file item. For example, if the prefix of the "Customer" table is CL, to use the "Name" field in this table, use the syntax CL.NAME.
Warning: several tables opened with **HDBOpen** cannot have the same abbreviation, even if the tables have been closed.

**`<Full name of xBase file>: (Character string)`**

Path and full name of xBase file to open (with the extension).

## Remarks


### Link between xBase files
<a name="link_between_xbase_files_ELTPARAGRAPHE000050"></a>The links between xBase files are not automatically managed. Therefore, you must write the "link" code to access a record in a linked file. The record in the linked file must be read whenever the file is read:


```wl
// Read the xBase file
IF HOut() = False THEN
	HReadSeek(FileName, KeyName, Key_Value)
END
```

<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000059"></a>

This function is not available when using a stand-alone executable.
