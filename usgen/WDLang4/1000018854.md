


## hScheduledOptimization (Variable type)

***In french: hOptimisationPlanifiée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **hScheduledOptimization** type is used to programmatically manage a scheduled optimization task on an HFSQL server. A scheduled optimization task periodically performs statistical calculations or reindexes the tables on the HFSQL server.

The characteristics of this scheduled optimization task can be defined and modified using various WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see ["Declaring a variable"](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Recalculate the statistics for the files found in "MyDatabase" every Saturday at 23:00
Optim is hScheduledOptimization
Optim.Description = "Recalculating the statistics for the files found in the MyDatabase database"

Optim.Scheduling.Month = "*"
Optim.Scheduling.DayOfWeek = "Saturday"
Optim.Scheduling.Hour = "23"
Optim.Scheduling.Minute = "0"

Optim.File[1].Name = "MaBase"
Optim.File[1].Option = hOptStat

HAddScheduledOptimization(MyConnection, Optim)
```

## Properties


### Properties specific to hScheduledOptimization variables
<a name="properties_specific_hscheduledoptimization_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used to define the characteristics of **hScheduledOptimization** variables:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Description | Character string | Text describing the scheduling of the optimization.<br>The description of the optimization scheduling corresponds to an empty string ("") by default. |
| Enabled | Boolean | <br><br>- <u><u><u>True</u></u></u> if the scheduling of the optimization is enabled, <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| File | Array of [hFileParameter](../WDLang4/1000018900.md) variables | Description of the files that must be taken into account during the optimization. |
| Identifier | Integer | Identifier of the optimization task. <br>**This property is read-only**. |
| NumberExecution | Integer | Number of times the task for optimization scheduling must be run. This property can also correspond to the *Infinite* constant. |
| Scheduling | [hScheduling](../WDLang4/1000018853.md) variable | Characteristics of the scheduling. |
| User | Character string | User who created the task for optimization scheduling. <br>This property is read-only. |

### Functions that use the hScheduledOptimization type
<a name="functions_that_use_the_hscheduledoptimization_type_ELTPARAGRAPHE000112"></a>The following functions can be used to handle **hScheduledOptimization** variables:



|   |   |
| --- | --- |
| [HAddScheduledOptimization](../WDLang4/1000018860.md) | Adds an optimization task of HFSQL Client/Server tables. |
| [HAddScheduling](../WDLang4/1000021447.md) | Adds a scheduled operation on an HFSQL server. This operation can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |
| [HDeleteScheduling](../WDLang4/1000021448.md) | Delete a scheduled item on an HFSQL server: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
| [HDeleteSchedulingHistory](../WDLang4/1410090760.md) | Deletes the executions of a scheduled operation on an HFSQL server. This operation can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |
| [HExecuteScheduling](../WDLang4/1000021453.md) | Immediately executes a scheduled item regardless of its scheduling: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
| [HListSchedulingHistory](../WDLang4/1410090762.md) | Lists the executions of a scheduled job on an HFSQL server. This job can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |
| [HModifyScheduledOptimization](../WDLang4/1000018931.md) | Modifies a scheduled optimization task on the HFSQL server defined by the connection. |
| [HModifyScheduling](../WDLang4/1000021450.md) | Modify a scheduled item on an HFSQL server: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
