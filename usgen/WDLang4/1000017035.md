


## HDeactivateServerTrigger (Function)

***In french: HDésactiveTriggerServeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disables an HFSQL Client/Server server trigger on a server. This trigger is disabled for all the clients of this server. This trigger can be re-enabled by [HActivateServerTrigger](../WDLang4/1000017034.md).  

**Note** Server trigger manipulation functions are advanced functions. The server triggers can be created directly in the data model editor. For more details, see [Server triggers](../WDLang4/3044369.md).


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Disable a server trigger on logical HFSQL tables

`HDeactivateServerTrigger(<Trigger> , <HFSQL Client/Server logical tables>)`
---

**`<Trigger>: (Character string)`**

Name of the trigger to disable. This name was defined with [HDescribeServerTrigger](../WDLang4/1000017033.md).

**`<HFSQL Client/Server logical tables>: (Character string)`**

Logical name of one or more HFSQL Client/Server tables. 
To specify several names, the names of the tables must be separated by a comma (",").  


<a name="SYNTAXE2"></a>

### Disable a server trigger on physical HFSQL tables on a server

`<Result> = HDeactivateServerTrigger(<Connection> , <Trigger> [, <HFSQL Client/Server physical tables>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was performed, 

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Connection>: (Character string or Connection variable)`**

Connection to the HFSQL server. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).




**`<Trigger>: (Character string)`**

Name of the trigger to disable. This name was defined with [HDescribeServerTrigger](../WDLang4/1000017033.md).

**`<HFSQL Client/Server physical tables>: (Optional character string)`**

Physical name of one or more HFSQL Client/Server tables associated with the connection ("CUSTOMER.FIC" for example). 
To specify several names, the names of the tables must be separated by a comma (","). 
If this parameter is not specified or is an empty string (""), the trigger will be disabled on all the tables of the databases.
