


## &lt;PolygonGeo variable&gt;.ConvexHull (Function)

***In french: &lt;Variable PolygoneGéo&gt;.EnveloppeConvexe***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Calculates the convex hull of the specified geographic polygon. The convex hull is the smallest convex geometry that encloses the entire specified geometry.

The convex hull of an object or group of geometric objects is the smallest convex set that contains the object(s).  
In a plane, a convex hull can be compared to the region defined by a rubber band wrapped around the geometries.

Generally, convex hulls are polygons.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.ConvexHull()`
---

**`<Result>: (Variable containing spatial data)`**

Variable corresponding to convex geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).




**`<Geometry>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.
