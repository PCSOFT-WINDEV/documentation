


## GeometryLength (Function)

***In french: GéométrieLongueur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the length of a given geometry.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
p is Linestring2D
Linestring2DAddPoint(p, 1, 2)
Linestring2DAddPoint(p, 1, 5)
Linestring2DAddPoint(p, 3, 5)
// Calculate the length of the linestring
let length = GeometryLength(p) // length = 3 + 2 = 5
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GeometryLength(<Geometry>)`
---

**`<Result>: (Real)`**

Length of the specified geometry. 

- For geometries defined with 2D coordinates, length is calculated based on the Euclidean (Pythagorean) distance. The length uses the same unit as the point coordinates.

- For geometries defined using geographic coordinates, length is calculated using a reference system that takes into account the curvature of the earth. Length is returned in meters




**`<Geometry>: (Variable containing spatial data)`**

Variable corresponding to the geometry for which to calculate the length. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).
