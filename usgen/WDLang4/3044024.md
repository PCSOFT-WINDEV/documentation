


## H.AutoIndexingLimit (Variable)

***In french: H.LimiteRéindexationAutomatique***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the maximum number of records in the table used to manage the automatic reindexing.

As long as this number is not reached, the HFSQL engine starts the automatic reindexing if an index error occurs.

Reminder: Automatic re-indexing is not available for tables in Hyper File 5.5 format.
<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Value of H.AutoIndexingLimit
<a name="value_hautoindexinglimit_ELTPARAGRAPHE000021"></a>

- H.AutoIndexingLimit is set to 100 000 by default.

- If H.AutoIndexingLimit is set to 0, the automatic reindexing is disabled.

- If H.AutoIndexingLimit is initialized with a negative value, the value of this variable will automatically correspond to the default value.




**Warning** If a lock error occurs during re-indexing (e.g. when the table or a record in the table is locked in read/write mode), automatic re-indexing will be stopped and a fatal corrupted index error will be displayed. Then, you will have to reindex the table.
