


## HSave (Function)

***In french: HEnregistre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the current record if it exists, otherwise adds a new record.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ScreenToFile(Customer)
HSave(Customer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HSave([<Table> [, <Options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition or the modification was performed,

- <u><u><u><u>False</u></u></u></u> if an error occurs.




**`<Table>: (Optional character string)`**

Name of the table, view or query used. If this name is not specified, **HSave** will use the last table used by the last HFSQL function (function starting with "H").

**`<Options>: (Optional integer constant)`**

Used to configure:

- the effect of addition or modification on the current iteration.

- the mode for calculating the automatic identifier. For more details, see [Managing the automatic identifier during an addition](../WDLang4/3044183.md).

- the lock mode of the added or modified record.

- the management of duplicates.

- the management of integrity.

## Remarks


- If the [NewRecord](../Proprietes/1000017090.md) property is set to <u><u><u><u>True</u></u></u></u>, **HSave** adds the record to the table ([HAdd](../WDLang4/3044147.md)). For more details, see the documentation about [HAdd](../WDLang4/3044147.md). 

- If [NewRecord](../Proprietes/1000017090.md) is set to <u><u><u><u>False</u></u></u></u>, **HSave** modifies the record in the table ([HModify](../WDLang4/3044042.md)). For more details, see the documentation about [HModify](../WDLang4/3044042.md). 

- Warning: The [HReset](../WDLang4/3044118.md) function modifies the [NewRecord](../Proprietes/1000017090.md) property: if the [HReset](../WDLang4/3044118.md) function is used, the [NewRecord](../Proprietes/1000017090.md) property changes to <u><u><u><u>True</u></u></u></u>.
