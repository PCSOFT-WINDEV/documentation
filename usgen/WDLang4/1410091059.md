
## hReindexingHistory (Variable type)

***In french: hHistoriqueRéindexation***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **hReindexingHistory** type gets all the details of previous asynchronous optimizations: reindexing, index verification, memo verification, statistics, etc. The details of these optimizations are returned by several WLanguage properties. 

This type of variable is handled by [HListReindexingHistory](../WDLang4/1410091060.md). 



**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

<a name="sample_code"></a>

## Example


```wl
arrHistoryEntries is array of hReindexingHistory = HListReindexingHistory(DatabaseConnection)
FOR EACH ELEMENT HistoryEntry OF arrHistoryEntries
		Counter =+ 1
		Trace(counter)
		Trace("Type: " + HistoryType(HistoryEntry.Type))
		Trace("File: " + HistoryEntry.File)
		Trace("Start date: " + HistoryEntry.StartDate)
		Trace("End date: " + HistoryEntry.EndDate)
		Trace("Density: " + HistoryEntry.Density)
		Trace("Option: " + HistoryOption(HistoryEntry.Option))
		Trace("Progress: " + HistoryEntry.Progress)
		Trace("Status: " + HistoryStatus(HistoryEntry.Status))
		Trace("Error: " + HistoryEntry.Error)
END

	INTERNAL PROCEDURE HistoryType(nType)
	SWITCH nType
		CASE hOptIndex: RETURN "hOptIndex"
		CASE hOptStat: RETURN "hOptStat"
		CASE hOptCheckIndex: RETURN "hOptCheckIndex"
		CASE hOptCheckMemo: RETURN "hOptCheckMemo"
		OTHER CASE: RETURN "Unexpected type"
	END
	END

	INTERNAL PROCEDURE HistoryOption(nOption)
	SWITCH nOption
		CASE 0: RETURN "<None>"
		CASE hChangeCharset: RETURN "hChangeCharset"
		CASE hFTX: RETURN "hFTX"
		CASE hMmoCompact: RETURN "hMmoCompact"
		CASE hNdxCompact: RETURN "hNdxCompact"
		CASE hNdxMinimal: RETURN "hNdxMinimal"
		CASE hNdxSilent: RETURN "hNdxSilent"
		CASE hNdxNormal: RETURN "hNdxNormal"
		CASE hNdxNoStat: RETURN "hNdxNoStat"
		CASE hNdxDelete: RETURN "hNdxDelete"
		CASE hSDX: RETURN "hSDX"
		CASE hBackgroundTask: RETURN "hBackgroundTask"
		CASE hCheckMemo: RETURN "hCheckMemo"
		OTHER CASE
		RETURN "Unexpected option"
	END
	END

	INTERNAL PROCEDURE HistoryStatus(nStatus)
	SWITCH nStatus
		CASE hReindexingPending: RETURN "hReindexingPending"
		CASE hReindexingInProgress: RETURN "hReindexingInProgress"
		CASE hReindexingFailed: RETURN "hReindexingFailed"
		CASE hReindexingCompleted: RETURN "hReindexingCompleted"
		CASE hCorruptIndex: RETURN "hCorrupIndex"
		CASE hCorruptMemo: RETURN "hCorruptMemo"
		OTHER CASE: RETURN "Unexpected status"
	END
	END
```

## Properties


### Properties specific to hReindexingHistory variables
<a name="properties_specific_hreindexinghistory_variables_ELTPARAGRAPHE000037"></a>

The following properties can be used to manipulate reindexing/optimization history files:

| Property name | Type used | Effect |
| --- | --- | --- |
| Progress | Integer | Progress percentage if the operation is in progress. <br><br><br><br>**This property is read-only.** |
| Density | Integer | Density rate of indexes.<br><br>- A higher rate increases the density of the index and reduces its size. In this case, iterations, searches, filters and queries will be faster. Adding and modifying records may take longer.<br><br>- A smaller rate reduces the density of the index and increases its size. In this case, iterations, searches, filters and queries will be slower. Adding and modifying records will be faster.<br><br><br><br><br>Note: This property is only available for reindexing. In all other cases, this property is set to 0.  <br><br>**This property is read-only.** |
| EndDate | Character string or DateTime variable | Optimization end date and time (in UTC format). <br><br>**This property is read-only.** |
| Error | Character string | Error text (in case of error during optimization). <br><br>**This property is read-only.** |
| File | Character string | Name of the file used. <br><br>**This property is read-only.** |
| Option | Integer constant | Reindexing or statistics options:<br><br>- *hFTX*: Reindexing of full-text indexes.<br><br>- *hMmoCompact*: Reindexing of "Mmo" files with compression and defragmentation.<br><br>- *hNdxCompact*: Reindexing with compression. Only active records are preserved. <br><br>- *hNdxMinimal*: Reindex only corrupted keys.<br><br>- *hNdxSilent*: Reindexing without UI.<br><br>- *hNdxNormal*: Standard reindexing (with statistics, without compression).<br><br>- *hNdxNoStat*: Reindexing without calculating statistics. <br><br>- *hNdxDelete*: Reindex and delete damaged records.<br><br>- *hSDX*: Reindexing of spatial indexes.<br><br>- *hBackgroundTask*: Operation run in the background. <br><br>- *HCheckMemo*: Normal reindexing with memo verification and correction if necessary (allows recovery of some damaged memos).<br><br>- 0: The calculation of statistics locks the table.<br><br><br><br><br>**This property is read-only.** |
| StartDate | Character string or DateTime variable | Optimization start date and time (in UTC format). <br><br>**This property is read-only.** |
| Status | Integer constant | Current optimization status:<br><br>- *hCorruptIndex*: The index is corrupt ([HCheckIndexAsynchronous](../WDLang4/1410091105.md)). <br><br>- *hCorruptMemo*: The memo is corrupt ([HCheckMemoAsynchronous](../WDLang4/1410091107.md)). <br><br>- *hReindexingPending*: Optimization/reindexing has not yet been started. <br><br>- *hReindexingInProgress*: Optimization/reindexing in progress. <br><br>- *hReindexingFailed*: Optimization/reindexing has encountered an error. The **Error** property contains the text of the error encountered. <br><br>- *hReindexingCompleted*: Optimization/Reindexing is complete. <br><br><br><br><br>**This property is read-only.** |
| Type | Integer constant | Type of reindexing/optimization:<br><br>- *hOptIndex*: Optimize indexes. <br><br>- *hOptStat*: Recalculate statistics. <br><br>- *hOptCheckIndex*: Check indexes. <br><br>- *hOptCheckMemo*: Check memos. <br><br><br><br><br>**This property is read-only.** |
