


## SQLDisconnect (Function)

***In french: SQLDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the current connection and frees the memory used by the connection. **SQLDisconnect** must be systematically called to close the connection, even if this connection failed.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) There is no need to use **SQLDisconnect** in the following cases

- if no session is used.

- if the connection failed. 




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The SQL functions are used to handle the local databases (such as Web SQL databases). For more details, see [Accessing a database in local mode (SQLite)](../WDLang4/9000119.md).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png)![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png)![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png)![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) 
```wl
// Example associated with the SALESMGT analysis
// TABLE_QryTable is a Table control populated programmatically
ResConnect is int
ResExec is boolean
MyDatabase is string = "C:\SALESMGT.WDD"
ResConnect = SQLConnect(MyDatabase, "", "")
IF ResConnect <> 0 THEN
	ResExec = SQLExec("SELECT NAME, CITY FROM POP", "QRY1")
	IF ResExec = True THEN
		// Retrieve the data in the table
		SQLTable("QRY1", TABLE_QryTable)
	ELSE
		// Error while running the query 
		// Retrieve information about the query run
		SQLInfo("QRY1")
		Error(SQL.MesError)
	END
	// Free the query in any case
	SQLClose("QRY1")
ELSE
	 // Connection error
	 Error("The connection to the database" + MyDatabase + " failed")
END
// Free the query in any case
SQLDisconnect()
```

### HFSQL analysis connection
<a name="hfsql_analysis_connection_ELTPARAGRAPHE000080"></a>

In a connection with an HFSQL analysis, **SQLDisconnect** closes the analysis (same as [HCloseAnalysis](../WDLang4/3044054.md)). To continue to use the analysis files, the analysis must be opened by [HOpenAnalysis](../WDLang4/3044106.md).
<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000095"></a>

- A single connection can be established at a given time.

- The memory allocated during the connection (execution of "SQLFreeConnect") is automatically freed.
