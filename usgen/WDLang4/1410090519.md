


## &lt;Polygon2D variable&gt;.Overlap (Function)

***In french: &lt;Variable Polygone2D&gt;.Chevauche***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if a 2D polygon overlaps another geometry. 

Two geometries overlap if they meet the following criteria:  

- The geometries have the same dimension (i.e., two 2D polygons). 

- The interiors of the geometries have a non-empty intersection of the same dimension as the input geometries. 

- Each geometry has at least one point inside the other.

## Example


```wl
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-4.38, 6.50)
o2DPolygon_1.Outline.AddPoint(-6.81, 1.51)
o2DPolygon_1.Outline.AddPoint(-1.42, -0.23)
o2DPolygon_1.Outline.AddPoint(0.89, 4.19)
o2DPolygon_1.Outline.AddPoint(-4.38, 6.50)
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(2.35, 7.52)
o2DPolygon_2.Outline.AddPoint(-3.01, 4.47)
o2DPolygon_2.Outline.AddPoint(1.82, 2.10)
o2DPolygon_2.Outline.AddPoint(2.35, 7.52)
o2DPolygon_2 = o2DPolygon_2.Correct()

Trace("o2DPolygon_1.Overlap(o2DPolygon_2) = " + o2DPolygon_1.Overlap(o2DPolygon_2))
```

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Overlap(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the geometries overlap, 

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000331"></a>

- If geometry A is contained in geometry B, their intersection is equal to geometry A. In this case, **&lt;Polygon2D variable&gt;.Overlap** returns <u><u><u><u>False</u></u></u></u>.

- If the &lt;Geometry A&gt; and &lt;Geometry B&gt; parameters are identical, **&lt;Polygon2D variable&gt;.Overlap** returns <u><u><u><u>False</u></u></u></u>.

- If the input geometries are multipolygons, **&lt;Polygon2D variable&gt;.Overlap** returns <u><u><u><u>True</u></u></u></u> if one of the polygons of geometry A overlaps one of the polygons of geometry B.



<a name="NOTE0_2"></a>


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000361"></a>

In a table, you can apply a filter on spatial data and loop through the table. For example, the filter can be based on the result of **&lt;Polygon2D variable&gt;.Overlap**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;Polygon2D variable&gt;.Overlap**. 

- Spatial_item is a spatial item in the table. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire table is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
