
## Parameters of the procedure used by HCheckMemoAsynchronous



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [HCheckMemoAsynchronous](../WDLang4/1410091107.md) for each HFSQL Client/Server table checked.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
DatabaseConnection is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
ArrayAdd(FileArray, MyFileParam)

HCheckMemoAsynchronous(DatabaseConnection, FileArray, CB_HCheckMemoAsynchronous)
	INTERNAL PROCEDURE CB_HCheckMemoAsynchronous(MyFile is string, MyResult is string)
		IF MyResult = "" THEN
			Trace("File processed and checked" + MyFile)
		ELSE
			Trace("File processed. Some problems were found " + MyFile)
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HCheckMemoAsynchronous_Callback(<Table> , <Result>)`
---

**`<Table>: (Character string)`**

Name of the HFSQL Client/Server table manipulated. 

**`<Result>: (Character string)`**



- Empty string ("") if no problem is found. 

- If the list of free blocks is corrupt, &lt;Result&gt; will contain:
	
	```txt
	<TAB> + "-1"+ CR + <Item 1> + TAB + <Record number 1> + CR + ...
	<Item N> + TAB + <Record number N>
	```
 where: 

	- &lt;Item X&gt; is the memo item, 

	- &lt;Record number&gt; is the number of the record containing the Memo item.
