
## Spatial data functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate spatial data: 



|   |   |
| --- | --- |
| [GeometryArea](../WDLang4/1410090167.md) | Calculates the area of a given geometry. |
| [GeometryContain](../WDLang4/1410090138.md) | Determines if geometry A contains geometry B. |
| [GeometryConvexHull](../WDLang4/1410090169.md) | Calculates the convex hull of the specified geometry. |
| [GeometryCorrect](../WDLang4/1410090157.md) | Returns a corrected version of the specified geometry. |
| [GeometryCover](../WDLang4/1410090140.md) | Determines if geometry A covers geometry B. |
| [GeometryCoveredBy](../WDLang4/1410090141.md) | Determines if every point of geometry A lies inside or on the boundary of geometry B. |
| [GeometryCross](../WDLang4/1410090341.md) | Compares two geometries and determines if their intersection spatially crosses. |
| [GeometryDeserializeWKT2D](../WDLang4/1410090336.md) | Builds a 2D geometry from a Well-Known Text (WKT) representation. |
| [GeometryDeserializeWKTGeo](../WDLang4/1410090335.md) | Builds a geometry in geographic coordinates from a Well-Known Text (WKT) representation. |
| [GeometryDifference](../WDLang4/1410090156.md) | Returns a geometry representing the difference between two geometries. |
| [GeometryDisjoint](../WDLang4/1410090307.md) | Determines whether two geometries are disjoint, i.e. whether their intersection is empty. |
| [GeometryDistance](../WDLang4/1410090297.md) | Calculates the distance between two geometries. |
| [GeometryEqual](../WDLang4/1410090295.md) | Determines whether two geometries are spatially equal, i.e. whether the first geometry is included in the second, and vice versa. |
| [GeometryIntersect](../WDLang4/1410090115.md) | Checks whether two geometries have a non-empty intersection. |
| [GeometryIntersection](../WDLang4/1410090153.md) | Returns a geometry representing the intersection of two geometries. |
| [GeometryIsValid](../WDLang4/1410090158.md) | Checks whether the specified geometry is valid according to the OGC rules. |
| [GeometryLength](../WDLang4/1410090296.md) | Calculates the length of a given geometry. |
| [GeometryOverlap](../WDLang4/1410090308.md) | Determines whether two geometries overlap. |
| [GeometryPerimeter](../WDLang4/1410090168.md) | Calculates the perimeter of a given geometry (polygon or multipolygon). |
| [GeometrySerializeDSV](../WDLang4/1410090121.md) | Serializes a geometry using the specified DSV format. |
| [GeometrySerializeWKT](../WDLang4/1410090108.md) | Serializes a geometry using the Well-Known Text (WKT) format. |
| [GeometrySymmetricDifference](../WDLang4/1410090164.md) | Calculates the symmetric difference between two geometries. |
| [GeometryTouch](../WDLang4/1410090114.md) | Determines whether two geometries touch. |
| [GeometryUnion](../WDLang4/1410090155.md) | Returns a geometry corresponding to the union of two geometries. |
| [GeometryWithin](../WDLang4/1410090139.md) | Determines whether geometry A is completely within geometry B (i.e., geometry B completely contains geometry A). |
| [Linestring2DAddPoint](../WDLang4/1410090159.md) | Adds a new point to a 2D linestring. |
| [LinestringGeoAddPoint](../WDLang4/1410090160.md) | Adds a new point to a geographic linestring. |






 
Spatial data functions manipulate the following variable types: 

- Variables corresponding to geometries defined using 2D coordinates: 
	


|   |   |
| --- | --- |
| [Linestring2D](../WDLang4/1410090109.md) | The **Linestring2D** type is used to define all the advanced characteristics of a linestring defined with 2D coordinates. |
| [MultiLinestring2D](../WDLang4/1410090131.md) | The **MultiLinestring2D** type can be used to store a collection of linestrings defined with 2D coordinates. |
| [MultiPoint2D](../WDLang4/1410090129.md) | The **MultiPoint2D** type is used to store a set of points defined with 2D coordinates. It is a collection of points: unlike in a linestring, points are not connected. |
| [MultiPolygon2D](../WDLang4/1410090135.md) | The **MultiPolygon2D** type can be used to store a collection of non-overlapping polygons defined with 2D coordinates. |
| [Point2D](../WDLang4/1410090100.md) | The **Point2D** type is used to define all the characteristics of a location represented on a Cartesian plane. |
| [Polygon2D](../WDLang4/1410090122.md) | The **Polygon2D** type is used to define all the advanced characteristics of a 2D polygon. |

- Variables corresponding to geometries defined using geographic coordinates: 
	


|   |   |
| --- | --- |
| [LinestringGeo](../WDLang4/1410090128.md) | The **LinestringGeo** type is used to define all the advanced characteristics of a geographic linestring. |
| [MultiLinestringGeo](../WDLang4/1410090133.md) | The **MultiLinestring** type can be used to store a collection of linestrings defined with geographic coordinates. |
| [MultiPointGeo](../WDLang4/1410090130.md) | The **MultiPointGeo** type is used to store a set of points defined with geographic coordinates. It is a collection of points: in this case, points are not connected. |
| [MultiPolygonGeo](../WDLang4/1410090136.md) | The **MultiPolygonGeo** type can be used to store a collection of non-overlapping polygons defined with geographic coordinates. |
| [PointGeo](../WDLang4/1410090102.md) | The **PointGeo** type is used to define all the advanced characteristics of a location represented on the spheroidal surface of the earth. |
| [PolygonGeo](../WDLang4/1410090127.md) | The **PolygonGeo** type is used to define all the advanced characteristics of a geographic polygon. |
