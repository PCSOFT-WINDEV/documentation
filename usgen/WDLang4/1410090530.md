


## &lt;Polygon2D variable&gt;.Difference (Function)

***In french: &lt;Variable Polygone2D&gt;.Différence***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Returns a geometry representing the difference between a 2D polygon and another geometry. 

Example: <br>![Input A and B geometries](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Spatial_Difference_Avant.png)

<br>![Difference](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Spatial_Difference_Apres.png)

<a name="sample_code"></a>

## Example


```wl
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(2.00, 2.00)
o2DPolygon_1.Outline.AddPoint(2.00, -2.00)
o2DPolygon_1.Outline.AddPoint(-2.00, -2.00)
o2DPolygon_1.Outline.AddPoint(-2.00, 2.00)
// The last point of the polygon is the same as the first
o2DPolygon_1.Outline.AddPoint(2.00, 2.00)
// Corrects the new geometry
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(3.00, 1.00)
o2DPolygon_2.Outline.AddPoint(3.00, -1.00)
o2DPolygon_2.Outline.AddPoint(1.00, -1.00)
o2DPolygon_2.Outline.AddPoint(1.00, 1.00)
// The last point of the polygon is the same as the first
o2DPolygon_2.Outline.AddPoint(3.00, 1.00)
// Corrects the new geometry
o2DPolygon_2 = o2DPolygon_2.Correct()

// The difference is a 2D polygon
// The difference between two polygons is always a MultiPolygon
Difference is MultiPolygon2D = o2DPolygon_1.Difference(o2DPolygon_2)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Difference(<Geometry B>)`
---

**`<Result>: (Variable of type MultiPoint2D, MultiPointGeo, MultiLinestring2D, MultiLinestringGeo, MultiPolygon2D or MultiPolygonGeo)`**

Difference. This geometry contains a collection of geometries of a given type: 

- [MultiPoint2D](../WDLang4/1410090129.md) or [MultiPointGeo](../WDLang4/1410090130.md), 

- [MultiLinestring2D](../WDLang4/1410090131.md) or [MultiLinestringGeo](../WDLang4/1410090133.md), 

- [MultiPolygon2D](../WDLang4/1410090135.md) or [MultiPolygonGeo](../WDLang4/1410090136.md). 


If the difference between two geometries consists of a single element, the collection will contain a single element.
If the difference is empty (e.g., difference between identical geometries), the collection will be empty. 
If the result of the difference is disjoint (e.g. by splitting a polygon into two), the collection will contain several elements.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Geometry to be compared against geometry A. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).
