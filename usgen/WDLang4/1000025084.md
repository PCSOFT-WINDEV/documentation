


## &lt;Source&gt;.ViewToFile (Function)

***In french: &lt;Source&gt;.VueVersFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves the modifications performed in an HFSQL view (by [&lt;Source&gt;.Modify](../WDLang4/1000025038.md), [&lt;Source&gt;.Delete](../WDLang4/1000025071.md) or [&lt;Source&gt;.Cross](../WDLang4/1000025051.md)) in the corresponding table.

**Note**: This operation can only be performed if the view has been created with the constant *hVueBlocage* (i.e. records imported into the view have been blocked in the table). After the call to **&lt;Source&gt;.ViewToFile**, the records are unlocked in the view source file.

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Saves the modifications of Customer34 view
// into Customer file
Customer34.ViewToFile()
```


<a name="Exemple2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png) 
```wl
// Check the status report of HViewToFile
IF Customer13.ViewToFile() <> True THEN
	Error("Unable to save the modifications performed on the view")
```

## Syntax

`<Result> = <Source>.ViewToFile()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the view was transferred into the table, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<Source>: (Source type)`**

Name of view used.   



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
If an error occurs when updating the table, [HError](../WDLang4/3044088.md) is used to identify the records that caused the problem. Simply loop through the view again and run [HError](../WDLang4/3044088.md) on each record in the view.
