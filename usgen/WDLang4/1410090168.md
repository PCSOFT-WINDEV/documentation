


## GeometryPerimeter (Function)

***In french: GéométriePérimètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the perimeter of a given geometry (polygon or multipolygon). 

**Remarks**: 

- The perimeter of a polygon is the sum of the length of its exterior and interior rings.

- The perimeter of a multipolygon is the sum of the perimeters of its polygons.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Build a square where each side has a length of 2
o2DPolygon_1 is Polygon2D
Linestring2DAddPoint(o2DPolygon_1.Outline, -1.00, 1.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 1.00, 1.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 1.00, -1.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, -1.00, -1.00)
// Add last point (same as first)
Linestring2DAddPoint(o2DPolygon_1.Outline, -1.00, 1.00)

Perimeter is real = GeometryPerimeter(o2DPolygon_1)
Trace(Perimeter) // Displays "8"
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GeometryPerimeter(<Geometry>)`
---

**`<Result>: (Real)`**



- Perimeter of the specified geometry. This geometry must be a polygon or multipolygon. 

	- For geometries defined with 2D coordinates, the perimeter is calculated based on the Euclidean (Pythagorean) distance. The unit is the same as the one used for the point coordinates.

	- For geometries defined using geographic coordinates, the perimeter is calculated using a reference system that takes into account the curvature of the earth. The perimeter is returned in meters.




- 0 in other cases (geometry other than a polygon or multipolygon). 




**`<Geometry>: (Variable containing spatial data)`**

Variable corresponding to the geometry for which to calculate the perimeter. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).
