


## Hyper File functions available for backward compatibility
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following are the Hyper File functions (used in version 5.5) kept for compatibility and the equivalent functions in version 2026.


|   |   |
| --- | --- |
| <a name="BinaireInfo"></a><br>BinaryInfo | Used to get information on 4.1 binary memo (type, name, date, time and size of the source file).<br><br>Equivalent function: [HInfoMemo](../WDLang4/3044008.md) |
| <a name="BinaireCharge"></a><br>BinaryLoad | Loads a binary file in a 4.1 memo item (initialize a binary memo with the file content).<br><br>Equivalent function: [HLinkMemo](../WDLang4/3044173.md). |
| <a name="BinaireSauve"></a><br>BinarySave | Saves the content of a 4.1 binary memo item in a file.<br><br>Equivalent function: [HExtractMemo](../WDLang4/3044072.md) |
| <a name="HAlias_55"></a><br>HAlias_55 | Creates an alias for a logical file or cancels all existing aliases of a logical file.<br><br>Equivalent function: [HAlias](../WDLang4/3044176.md). |
| <a name="HAliasExterne"></a><br>HAliasExternal | Loads the description of Hyper Table files contained in a database schema external to the application without closing the current database schema.<br><br>Equivalent functions: <br><br>- [HDeclare](../WDLang4/3044203.md): Imports a file description from a database schema other than the current database schema.<br><br>- [HDeclareExternal](../WDLang4/3044204.md): Imports a file description from an existing file.<br><br><br> |
| <a name="HAssigne"></a><br>HAssign | Modifies the access path to a file.<br><br>Equivalent function: [HChangeDir](../WDLang4/3044168.md). |
| <a name="HCopieEnreg_55"></a><br>HCopyRecord_55 | Copies the current record in a file to the current record of another file with the same structure.<br><br>Equivalent function: [HCopyRecord](../WDLang4/3044261.md) |
| <a name="HCréeVue_55"></a><br>HCreateView_55 | Creates a view on a Hyper File file.<br><br>Equivalent function: [HCreateView](../WDLang4/3044159.md). |
| <a name="HDécritClé"></a><br>HDescribeKey | Describes a simple or composite key in a temporary file in Hyper File format. <br><br>Equivalent method: <br><br>1. Declare a variable of type [Item Description](../WDLang4/1514071.md).<br><br>2. Define all the properties of the item with the HFSQL properties.<br><br>3. Use [HDescribeItem](../WDLang4/3044233.md) to validate the item creation.<br><br><br> |
| <a name="HDécritTrigger_55"></a><br>HDescribeTrigger_55 | Adds or modifies a trigger on Hyper File. <br><br>Equivalent function: [HDescribeTrigger](../WDLang4/3044074.md) |
| <a name="HDoublon"></a><br>HDuplicates | Checks the uniqueness of a key.<br><br>Equivalent operation: this function has been replaced by:<br><br>- an automatic management of duplicates, allowing the user to enter a different value for the item generating a duplicate error.<br><br>- the [HErrorDuplicates](../WDLang4/3044077.md) function.<br><br><br> |
| <a name="HFinVerrou"></a><br>HEndLock | Marks the end of file locking: all locked records are unlocked. <br><br>Equivalent functions: <br><br>- Use read functions with appropriate constants: [HRead](../WDLang4/3044047.md), [HReadFirst](../WDLang4/3044051.md), [HReadNext](../WDLang4/3044037.md), .... <br><br>- Open the table in read/write mode with [HOpen](../WDLang4/3044120.md).  <br><br>- [HUnlockFile](../WDLang4/3044160.md) function. <br><br><br> |
| <a name="HImporteTexte_55"></a><br>HImportText_55 | Imports a text file into a Hyper File file. <br><br>Equivalent function: [HImportText](../WDLang4/3044011.md). |
| <a name="HRéindexe_55"></a><br>HIndex_55 | Reindexes a Hyper File file belonging to the current database schema.<br><br>Equivalent function: [HIndex](../WDLang4/3044133.md). |
| <a name="HInfoGéné"></a><br>HInfoGene | Returns general information about a Hyper File file.<br><br>Equivalent operation: this function has been replaced by:<br><br>- functions (for example, [HNbRec](../WDLang4/3044006.md) replaces the H.NbRec variable).<br><br>- [HFSQL properties](../Proprietes/2512070.md) (for example, the **Directory** property replaces the H.Dir variable).<br><br><br> |
| <a name="HInfoRubrique"></a><br>HInfoItem | Used to get information about a database schema item. <br><br>Equivalent operation: this function has been replaced by various [HFSQL properties](../Proprietes/2512070.md). |
| <a name="HDéjàBloque"></a><br>HIsLocked | Checks whether the last WINDEV operation was run or not. <br><br>Equivalent operation: this function has been replaced by:<br><br>- an automatic management of locks (that can be disabled if necessary), <br><br>- the [HErrorLock](../WDLang4/3044099.md) function.<br><br><br> |
| <a name="HLitPremierBloque"></a><br>HReadFirstLock | Reads and locks the first record of the file according to the specified key.<br><br>Equivalent function: [HReadFirst](../WDLang4/3044051.md) with constants for blocking management. |
| <a name="HLitPremierSansBloquer"></a><br>HReadFirstNoLock | Reads the first record according to the specified key. If the file is locked, the record read is not locked.<br><br>Equivalent function: [HReadFirst](../WDLang4/3044051.md) with constants for blocking management. |
| <a name="HLitDernierBloque"></a><br>HReadLastLock | Reads and locks the last record of the file according to the key passed as parameter.<br><br>Equivalent function: [HReadLast](../WDLang4/3044140.md) with constants for blocking management. |
| <a name="HLitDernierSansBloquer"></a><br>HReadLastNoLock | Reads the last file record according to the key passed as parameter. If the file is locked, the record read is not locked.<br><br>Equivalent function: [HReadLast](../WDLang4/3044140.md) with constants for blocking management. |
| <a name="HLitBloque"></a><br>HReadLock | Reads and locks a record according to the specified record number. <br><br>Equivalent function: [HRead](../WDLang4/3044047.md) with constants for blocking management. |
| <a name="HLitSuivantBloque"></a><br>HReadNextLock | Reads and locks the previous record according to the specified key.<br><br>Equivalent function: [HReadNext](../WDLang4/3044037.md) with constants for blocking management. |
| <a name="HLitSuivantSansBloquer"></a><br>HReadNextNoLock | Reads the next record according to the specified key. If the file is locked, the record read is not locked.<br><br>Equivalent function: [HReadNext](../WDLang4/3044037.md) with constants for blocking management. |
| <a name="HLitSansBloquer"></a><br>HReadNoLock | Reads the record according to the specified record number. If the file is locked, the record read is not locked.<br><br>Equivalent function: [HRead](../WDLang4/3044047.md) with constants for blocking management. |
| <a name="HLitPrécédentBloque"></a><br>HReadPreviousLock | Reads and locks the previous record according to the specified key.<br><br>Equivalent function: [HReadPrevious](../WDLang4/3044048.md) with constants for blocking management. |
| <a name="HLitPrécédentSansBloquer"></a><br>HReadPreviousNoLock | Reads the previous record according to the specified key. If the file is locked, the record read is not locked. <br><br>Equivalent function: [HReadPrevious](../WDLang4/3044048.md) with constants for blocking management. |
| <a name="HLitRechercheBloque"></a><br>HReadSeekLock | Reads and locks the first record which value of the specified key is equal to or greater than the value of the search criterion.<br><br>Equivalent function: [HReadSeek](../WDLang4/3044050.md) with constants for blocking management.<br><br>Equivalent function: [HReadSeek](../WDLang4/3044050.md) with constants for blocking management. |
| <a name="HLitRechercheSansBloquer"></a><br>HReadSeekNoLock | Reads the first record which value of the specified key is equal to or greater than the value of the search criterion. If the file is locked, the record read is not locked.<br><br>Equivalent function: [HReadSeek](../WDLang4/3044050.md) with constants for blocking management. |
| <a name="HDébutVerrou"></a><br>HStartLock | Marks the beginning of the read lock on files. All the 'simple' read functions automatically lock the records that have been read.<br><br><br>Equivalent functions: <br><br>- Use read functions with appropriate blocking constants: [HRead](../WDLang4/3044047.md), [HReadFirst](../WDLang4/3044051.md), [HReadNext](../WDLang4/3044037.md), .... <br><br>- Open the table in read mode with [HOpen](../WDLang4/3044120.md).  <br><br>- [HLockFile](../WDLang4/3044153.md) function<br><br><br> |
| <a name="HSubstNom"></a><br>HSubstName | Modifies the physical name of a table.<br><br>Equivalent function: [HChangeName](../WDLang4/3044141.md). |
| <a name="HVueVersTable"></a><br>HViewToTable | Populates a Table control programmatically with a view.<br><br>Equivalent function: [FileToMemoryTable](../WDLang1/3074005.md). |
