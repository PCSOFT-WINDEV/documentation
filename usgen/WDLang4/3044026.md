


## HTransactionInterrupted (Function)

***In french: HTransactionInterrompue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out whether a transaction was interrupted (the transaction was neither validated nor canceled). The characteristics of the interrupted transaction are returned by the HFSQL variables.

We advise you to call this function in the project initialization code. If the transaction is interrupted, you can:

- ![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png) start [WDTRANS](../WDTrans/3524005.md) or [WDOptimizer](../WDOptimiseur/3519002.md).

- ![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) start the HFSQL Control Center.

- cancel the transaction programmatically.




![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) This function is useful when transactions have been interrupted on password-protected tables.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The management of transactions is available for HFSQL Client/Server databases.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF HTransactionInterrupted("") = True THEN
	HTransactionCancel()
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HTransactionInterrupted([<Transaction file>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a  transaction was interrupted,

- <u><u><u><u>False</u></u></u></u> if no transaction was interrupted. The following HFSQL variables are updated: 
	


|   |   |
| --- | --- |
| **H.TrsApplicationName** | Value if transaction interrupted: Application name in the form: Executable name(Project name).<br>Value if transaction not interrupted: Empty string ("").<br>**Note** This variable is only available in HFSQL Client/Server mode. |
| **H.TrsInternalID** | Value if the transaction has been interrupted: Internal number uniquely identifying the transaction. <br>Value if transaction not interrupted: -1 |
| **H.TrsMachineName** | Value if the transaction was interrupted: Client workstation name and workstation IP address.<br>Value if transaction not interrupted: Empty string ("").<br>**Note** This variable is only available in HFSQL Client/Server mode. |
| **H.TrsPost** | Value if the transaction was interrupted: Identifier defined by the [HComputer](../WDLang4/3044111.md) function or name of the machine from which the transaction was initiated.<br>Value if transaction not interrupted: Empty string ("") |






**`<Transaction file>: (Optional character string)`**

Full name of the transaction file (used to store the operations performed within the transaction). This file is automatically destroyed when [HTransactionEnd](../WDLang4/3044032.md) or [HTransactionCancel](../WDLang4/3044001.md) is used. 
If this name corresponds to an empty string ("") or is not specified, the transaction file used is the default transaction file (in the application directory with the name: &lt;Nom Projet&gt;_$TRS_OPERATION.trs)..
![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) This parameter is ignored by the Client/Server transactions, it is only taken into account by the HFSQL Classic transactions.

## Remarks


### Handling records during a transaction
<a name="handling_records_during_transaction_ELTPARAGRAPHE000129"></a>

During a transaction, some rules must be complied with when handling the records. For more details, see [Transactions: Handling the records during a transaction](../WDLang4/3044336.md).
<a name="NOTE0_2"></a>


### Transactions and independent HFSQL context
<a name="transactions_and_independent_hfsql_context_ELTPARAGRAPHE000139"></a>

When copying a context, if a transaction is in progress on the first context, the new context is not in transaction. You must call [HTransactionStart](../WDLang4/3044002.md) (or [HTransaction](../WDLang4/1000023384.md)) to start a transaction in the new context.
