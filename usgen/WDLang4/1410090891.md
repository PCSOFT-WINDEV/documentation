


## &lt;Connection variable&gt;.DeleteSchedulingHistory (Function)

***In french: &lt;Variable Connexion&gt;.SupprimeHistoriquePlanification***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the executions of a scheduled operation on an HFSQL server. This operation can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyDatabaseConnection is Connection
MyBackup is hBackupDescription

IF NOT MyDatabaseConnection.DeleteSchedulingHistory(MyScheduledTask) THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Deleting the history of a scheduled backup

`<Result> = <Connection>.DeleteHistoryPlanning(<Scheduled backup>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the history was deleted,

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<Scheduled backup>: (hBackupDescription variable)`**

Name of the [hBackupDescription](../WDLang4/1000017455.md) variable used.


<a name="SYNTAXE2"></a>

### Deleting the history of a scheduled optimization task

`<Result> = <Connection>.DeleteHistoryPlanning(<Scheduled optimization task>)`
---

**`<Result>: (Boolean)`**

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Connection variable)`**

**`<Scheduled optimization task>: (hScheduledOptimization variable)`**

Name of the [hScheduledOptimization](../WDLang4/1000018854.md) variable used.
