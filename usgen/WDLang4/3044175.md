


## HCreateMasterReplica (Function)

***In french: HCréeRéplicaMaître***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates the description file of a Master Replica (**log-based replication or universal replication)**). The extension of the corresponding file is ".rpm".

The description file of a Master Replica contains the list of Subscriber Replicas with their date of last synchronization. This file is empty when it is created. You must call [HCreateSubscriberReplica](../WDLang4/3044253.md) to initialize this file.

**Remark**: This function is automatically called during the installation phase of the replication application.

## Syntax

`<Result> = HCreateMasterReplica([<Master replica directory>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the master replica was created, 

- <u><u><u><u>False</u></u></u></u> otherwise (the file already exists in the specified directory for example).




**`<Master replica directory>: (Optional character string)`**

Directory where the description file of Master Replica must be created. This directory must be accessible when **HCreateMasterReplica** is used. 
If this parameter:

- is not specified or corresponds to an empty string: the table **ReplicaMaster.rpm** is created in the directory defined in the database schema (RPL subdirectory of tables by default). For the universal replication, if this parameter is not specified or if it corresponds to an empty string (""), the file is created in the current directory.

- corresponds to a directory name (network or UNC directory): the ReplicaMaître.rpm file is created in the specified directory. 
	**Example** HCreateMasterReplica("C:\\Temp") creates the file ReplicaMaster.rpm in the directory C:\\Temp.

- is of the form &lt;Répertoire&gt;\\&lt;NomFichier&gt;.rpm: the file &lt;NomFichier&gt;.rpm is created in the specified directory.. 
	**Example** HCreateMasterReplica("C:\\Temp\\Paris.rpm") creates the file Paris.rpm in the C:\\Temp directory.

### Day-to-day replication and logging: File creation directories
<a name="daytoday_replication_and_logging_file_creation_directories_ELTPARAGRAPHE000092"></a>

Log-based replication is closely linked to the log process. The log process is automatically enabled when log-based replication is implemented in an application.

For all the tables used (tables, log files or replication files), the paths of the corresponding physical files can be defined in the data model editor or programmatically.

By default, the tree structure of tables is as follows (example for the SalesMgt application):
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Replic_repertoire.gif)


The following table presents the default value for these different directories and their configuration mode in the data model editor or programmatically.

|   | Default value | Where to configure it in the data model editor? | How to change the default value through programming? |
| --- | --- | --- | --- |
| **Table directory** | Executable directory. | <br><br>- For all tables in the application: "Detail" tab in the database schema description<br><br>- For each table: "Info" tab in the table description.<br><br><br> | To modify the default directory for the tables of the application, use [HSubstDir](../WDLang4/3044028.md).<br>When creating the files for the log process and for the replication, the created directories will be relative to this new directory. <br>**Note**: To modify only the directory of one of the files, use the [HChangeDir](../WDLang4/3044168.md) function. |
| **Replication file directory** | RPL subdirectory of the default directory of the tables. | "Log\\Replica" tab of the database schema description. | Specify the desired directory in [HCreateMasterReplica](../WDLang4/3044175.md) and [HCreateSubscriberReplica](../WDLang4/3044253.md). |
| **Log file directory** | JNL subdirectory of the default directory of tables. | <br><br>- For all application tables: "Log\\Replica" tab in the database schema description.<br><br>- For each table: "Miscellaneous" tab in the table description.<br><br><br> | To modify the directory of log files, use [HChangeLogDir](../WDLang4/3044164.md). <br>This function is used to:<br><br>- change the directory of the Log file (JNL file)<br><br>- change the directory of the JNL file and logging files (JournalIdentification and JournalOperation files).<br><br><br> |


**Please note** To manage log replication in an application, the log operations table (JournalOperation.fic table) must be identical for all replicated tables in the same database schema.
