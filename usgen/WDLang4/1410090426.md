


## HListSpatialKeys (Function)

***In french: HListeClésSpatiales***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the spatial keys of a table (used in a query or view) recognized by the HFSQL engine.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the spatial keys of a table in the current database schema
SpatialKeyList is string
SpatialKeyList = HListSpatialKeys(Towns)
// Adds the list of spatial keys to COMBO_Combo1
ListAdd(COMBO_Combo1, SpatialKeyList)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HListSpatialKeys(<Table> [, <Path of the WDD file> [, <Password of the WDD file>]])`
---

**`<Result>: (Character string)`**

List of spatial keys in the specified table. Names of spatial items are separated by carriage returns (CR). 

**`<Table>: (Character string)`**

Name of the table, query, or view with spatial keys to be listed.

If a query name is specified, the query must be running ([HExecuteQuery](../WDLang4/3044080.md) or [HExecuteSQLQuery](../WDLang4/3044084.md)) to use **HListSpatialKeys**. Otherwise, a WLanguage error occurs.

**`<Path of the WDD file>: (Optional character string)`**

Full path of the database schema (i.e. the .WDD file) in which the table has been defined. 
If this parameter is not specified or is an empty string (""), the table is searched for in the current database schema.

**`<Password of the WDD file>: (Optional string or Secret string)`**

Password defined for the database schema. 
If no password is defined, this parameter must be an empty string ("").
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
