


## &lt;Source&gt;.InfoLock (Function)

***In french: &lt;Source&gt;.InfoBlocage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the lock set on a table, on one or all the records in a table.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
LockList is string
// Lists all the locks of the Customer table
LockList = Customer.InfoLock()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Information about the locks set on a table identified by its name

`<Result> = <Source>.InfoLock([<Record number>])`
---

**`<Result>: (Character string)`**



- Empty string ("") if there is no block or if the table manipulated is not an HFSQL Client/Server table.

- Information about the lock.  This information is separated by TAB characters and it has the following format:
	
	```txt
	<Physical name of the table relative to the database> + TAB + 
	<Record number> + TAB + 
	<User> + TAB + <Name of client computer> + TAB + 
	<IP address of client computer> + TAB + <Name of client application> + TAB + 
	<Type of lock> + TAB + <Date of lock implementation> + TAB + 
	<Number of seconds since start of lock> + CR
	```


	- &lt;Record number&gt; is set to -1 if the lock was set on the table.

	- The &lt;Type of lock&gt; parameter can correspond to:

		- W: Lock in write mode.

		- RW: Read/Write blockage.

		- W-T: Transaction lock in write mode.

		- RW-T: Read/write lock performed by a transaction.




- The &lt;Date de pose du blocage&gt; parameter is of the form: AAAAMMJJHHmmSS. This date is in UTC format (Universal Time Coordinated).




**`<Source>: (Type corresponding to the specified source)`**

Name of the table used. 

**`<Record number>: (Optional integer)`**

Number of the record for which the lock information is requested. 
If this parameter is not specified, **&lt;Source&gt;.InfoLock** lists all the locks of the table.
