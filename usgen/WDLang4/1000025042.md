


## &lt;Source&gt;.Optimize (Function)

***In french: &lt;Source&gt;.Optimise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to handle the idle periods of a software (period without processes) to optimize the queries and the browses that will be run thereafter. Optimizes the access to the indexes of HFSQL Classic tables (the indexes of HFSQL Client/Server tables cannot be optimized).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Customer.Optimize(Name)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.Optimize([<Key item>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was optimized, 

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) returns more details.




**`<Source>: (Type corresponding to the specified source)`**

Name of the HFSQL Classic table used.

**`<Key item>: (Optional character string)`**

Name of the key item to optimize. If this parameter is not specified, **&lt;Source&gt;.Optimize** optimizes all the keys in the table.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Differences between HOptimize and HOptimizeQuery
<a name="differences_between_hoptimize_and_hoptimizequery_ELTPARAGRAPHE000194"></a>

- **&lt;Source&gt;.Optimize** loads the system caches with the entire index of the table. There is a risk of overloading the system caches if the table is very large or if the application uses several large tables. 
	To avoid the risk of overload, avoid calling &lt;Source&gt;.Optimize on a large number of tables or key items.

- [HOptimizeQuery](../WDLang4/3044003.md) loads the system caches with only the index parts needed for the specified query (for all the tables used by the query). This function is used to optimize the queries.



<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000213"></a>

- **&lt;Source&gt;.Optimize** immediately gives control back to the program and is run in the background.

- **&lt;Source&gt;.Optimize** has no effect on non-key items or on tables that are not in HFSQL Classic format.
