


## HSetCache (Function)

***In french: HGèreCache***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to configure the management of caches in the HFSQL Client/Server engine.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HSetCache(hPageSize, 2000)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HSetCache(<Parameter to modify> [, <Table> [, <Item>]] , <Value>)`
---

**`<Result>: (Integer)`**

Former value of modified parameter (value before modification). 

**`<Parameter to modify>: (Constant)`**

Parameter of the cache to modify:


|   |   |
| --- | --- |
| *hPageSize* | Size of a block of caches. This block of caches will be used when browsing a table. <br>A large block of caches improves the browse and increases the transfers via network and the memory consumption.<br>This parameter corresponds to the number of records read during the browse. |



**`<Table>: (Optional character string)`**

Name of the table to which the modification must be applied. 
If this parameter is not specified, the modification is applied to all the tables.

**`<Item>: (Optional character string)`**

Name of the item to which the modification must be applied. 
If this parameter is not specified, the modification will be applied to all the items found in the specified table.

**`<Value>: (Integer)`**

New value that must be given to the parameter.

For the *hPageSize* constant, this value must be between 1 and 5000 (the default value on a PC is 1000 and on a mobile is 10).
