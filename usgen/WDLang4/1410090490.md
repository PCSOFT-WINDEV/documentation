


## Spatial data constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manipulate spatial data:

| Constant | Details | Variable type |
| --- | --- | --- |
| **gtInvalid** | Type of the current geometry: Invalid type.<br>Remark: Until version 2024 Update 2, this constant was named *stInvalid*. | [Geometry](../WDLang4/1410090098.md) variable |
| **gtGeometryCollection** | Type of the current geometry: Collection of geometries.<br>Remark: Until version 2024 Update 2, this constant was named *stShapeCollection*. | [Geometry](../WDLang4/1410090098.md) variable, [GeometryCollection](../WDLang4/1410090298.md) variable |
| **gtMultiPoint2D** | Type of the current geometry: MultiPoint2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPoint2D*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiPoint2D](../WDLang4/1410090129.md) variable |
| **gtMultiPointGeo** | Type of the current geometry: MultiPointGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPointGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiPointGeo](../WDLang4/1410090130.md) variable |
| **gtMultiPolygon2D** | Type of the current geometry: MultiPolygon2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPolygon2D*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiPolygon2D](../WDLang4/1410090135.md) variable |
| **gtMultiPolygonGeo** | Type of the current geometry: MultiPolygonGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiPolygonGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiPolygonGeo](../WDLang4/1410090136.md) variable |
| **gtMultiLinestring2D** | Type of the current geometry: MultiLinestring2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiLinestring2D*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiLinestring2D](../WDLang4/1410090131.md) variable |
| **gtMultiLinestringGeo** | Type of the current geometry: MultiLinestringGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stMultiLinestringGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [MultiLinestringGeo](../WDLang4/1410090133.md) variable |
| **gtPoint2D** | Type of the current geometry: Point2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stPoint2D*. | [Geometry](../WDLang4/1410090098.md) variable, [Point2D](../WDLang4/1410090100.md) variable |
| **gtPointGeo** | Type of the current geometry: PointGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stPointGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [PointGeo](../WDLang4/1410090102.md) variable |
| **gtPolygon2D** | Type of the current geometry: Polygon2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stPolygon2D*. | [Geometry](../WDLang4/1410090098.md) variable, [Polygon2D](../WDLang4/1410090122.md) variable |
| **gtPolygonGeo** | Type of the current geometry: PolygonGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stPolygonGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [PolygonGeo](../WDLang4/1410090127.md) variable |
| **gtLinestring2D** | Type of the current geometry: Linestring2D type.<br>Remark: Until version 2024 Update 2, this constant was named *stLinestring2D*. | [Geometry](../WDLang4/1410090098.md) variable, [Linestring2D](../WDLang4/1410090109.md) variable |
| **gtLinestringGeo** | Type of the current geometry: LinestringGeo type.<br>Remark: Until version 2024 Update 2, this constant was named *stLinestringGeo*. | [Geometry](../WDLang4/1410090098.md) variable, [LinestringGeo](../WDLang4/1410090128.md) variable |
