


## &lt;HFSQL connection&gt;.CheckIndexAsynchronous (Function)

***In french: &lt;Connexion HFSQL&gt;.VérifieIndexAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the data found in the index file (.NDX file) properly refers the data found in the table (.FIC file). This function is only available for HFSQL Client/Server tables.
The HFSQL Client/Server table is automatically locked during the verification.

**Reminder**: An index is corrupted when one of the records it references is not the one expected. In this case, the table must be reindexed.

## Example


```wl
MyConnection1 is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
FileArray.Add(MyFileParam)

MyConnection1.CheckMemoAsynchronous(FileArray, Callback_HCheckMemoAsynchronous)

	INTERNAL PROCEDURE Callback_HCheckIndexAsynchronous(MyFile is string, 
			MyResult is int, Report is string)
		Res is string
		SWITCH MyResult
			CASE 0: Res = "Correct index"
			CASE 1: Res = "The file requires optimization."
			CASE 2: Res = "HFSQL error" + HErrorInfo() 
		END
		Trace("File processed: " + MyFile)
		Trace("Function result: ", Res)
		Trace("Summary: " + Replace(Report, CR, "<CR>"))
	END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.CheckIndexAsynchronous(<Tables to check> [, <WLanguage procedure>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the check has been started,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Connection>: (Connection variable)`**

Connection to the server containing the tables to be manipulated. This connection corresponds to the name of a variable of type [Connection](../WDLang4/1514073.md).

**`<Tables to check>: (Array of hFileParameter variables)`**

Name of the array of [hFileParameter](../WDLang4/1000018900.md) variables corresponding to the list of tables to be processed.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called for each table processed. This procedure is used to manipulate the current table.

For more details on this procedure, see [Parameters of the procedure used by &lt;HFSQL connection&gt;.CheckIndexAsynchronous](../WDLang4/1410091216.md).
