
## WDOptimizer: Editing a ".REP" file
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000116"></a>
The file &lt;MonProjet&gt;.REP file contains a list of tables handled by the application (identifier, logical name and full path of the physical file).

The GUID of the database schema is the unique identifier of the database schema linked to the project, containing the description of the tables. This identifier can be found in the data model editor, in the database schema description ("Options" tab).

The GUID of the table corresponds to the identifier of the logical table. This identifier can be found in the data model editor, in the description of the table ("Notes" tab).

This .REP file is automatically created in the application directory and populated by the HFSQL engine.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## REP files
<a name="rep_files_ELTTEXTE000140"></a>


### What are REP files for?
<a name="what_are_rep_files_for_ELTPARAGRAPHE000024"></a>

The .REP file is used to easily locate the tables that have been used by the WINDEV application or by the WEBDEV website.

The WINDEV application or the WEBDEV website automatically updates the .REP file but it does not often use the .REP file.

This file is used by all the tools that handle the tables of the application, and mainly by the automatic update of the tables, etc.
<a name="NOTE2_2"></a>


### Example: Updating an application while modifying the database schema
<a name="example_updating_application_while_modifying_the_database_schema_ELTPARAGRAPHE000035"></a>

When updating a WINDEV application, the automatic table modification is automatically started if the structure of the database is modified.

This procedure uses the .REP file to find and modify the physical tables used by the application.

## Editing and modifying a .REP file
<a name="editing_and_modifying_rep_file_ELTTEXTE000170"></a>


### Editing and modifying a .REP file
<a name="editing_and_modifying_rep_file_ELTPARAGRAPHE000046"></a>

To edit and modify a REP file:

1. Start WDOptimizer:

	- Directly from WINDEV, WEBDEV or WINDEV Mobile: in the "Tools" pane, in the "Database" group, click on "WDOptimizer".

	- run "WDOptimizer.EXE" directly.




2. Select "Edit and modify a .REP file".

3. Select the .REP file. The tables contained in the selected .REP file are listed.

4. To delete all tables that don't exist, click on the "Clean" button.

5. To delete the selected table, click on the "Delete" button.
