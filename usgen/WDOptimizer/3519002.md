## Overview
<a name="overview_ELTTEXTE000249"></a>


### WDOptimizer
<a name="wdoptimizer_ELTPARAGRAPHE000011"></a>

The different operations that can be performed with WDOptimizer are as follows:

- **Index optimization**
	This option allows you to perform several types of operation:

	1. **Check indexes** Checks consistency between index and tables.

	2. **Optimize index speed (Re-calculate statistics)** Optimize indexes by calculating index statistics. These statistics are used to optimize the filters, the queries and the HFSQL views. 
			Note: The more the table is modified, the less the statistics reflect the content of the HFSQL table.. The more records the table contains, the less the modification of a single record impacts the overall statistics.

	3. **Reconstruct indexes** Optimize access to table records and recalculate statistics. All the crossed records are automatically deleted. 

	4. **Rebuild indexes and memos** Optimizes the entire table, its indexes and memos.

	5. ** Revise and compress indexes and memos** Optimize the entire table, index and memos. The memos will be compressed. Advanced options are available ("Options for compressing the memos").




- **Viewing the properties of a table**
	Displays the characteristics of a table (name, extension, format, encryption, etc.).

- **Editing and modifying a ".REP" file**
	Optimizes the access to the tables.

- **Roll back a transaction or release transaction records**
	Rolls back a transaction without interrupting the execution of the program.

## Use
<a name="use_ELTTEXTE000273"></a>


### Starting WDOptimizer
<a name="starting_wdoptimizer_ELTPARAGRAPHE000047"></a>

WDOptimizer can be started in interactive mode via one of the following methods:

- From WINDEV, WEBDEV or WINDEV Mobile, on the "WDOptimizer" tab, in the "Tools" group, click "Database".

- Run "WDOptimizer.EXE" directly.




The different operations that can be performed with WDOptimizer are as follows:

1. Optimizing indexes. For more details, see [Index optimization](../WDOptimiseur/3519004.md).

2. View the properties of a table. This table can be selected in the list displayed on the screen or it can be selected via the table picker.

3. Editing a .REP file: Simply select the .REP file you wish to edit.. For more details, see [Editing and modifying a ".REP" file](../WDOptimiseur/3519001.md)

4. Handling transactions. For more details, see [Roll back a transaction or release transaction records](../WDOptimiseur/3519006.md)




**Remark**: On the development workstation, WDOptimizer can also be launched directly from WDTool.

WDOptimizer can also be run in command line. For more details, see [Starting WDOptimizer in a command line](../WDOptimiseur/3519005.md).

### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000090"></a>

WDOptimizer can be freely distributed. WDOptimizer can be installed with the applications developed with WINDEV or WEBDEV. The license agreement of WINDEV or WEBDEV is fully enforced.

When creating the setup procedure, WDOptimizer is automatically supplied with your applications.

**Reminder**: The setup procedure can be created:

- or from the wizard: under "Project", in the "Generation" group, click on "Setup procedure". 

- from the setup editor: On the "Tools" tab, in the "Utilities" group, click "WDInst".

## Reminder: Indexing a table
<a name="reminder_indexing_table_ELTTEXTE000309"></a>
The index of a table is a specific file (.NDX). This file is created according to the browse keys defined on the table. It allows you to quickly find data in a table.

For a better performance of the searches performed in your tables, the index should be optimized on a regular basis.
