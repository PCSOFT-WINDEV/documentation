
## WDConver: Command-line operation

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000241"></a>


### Command Line mode
<a name="command_line_mode_ELTPARAGRAPHE000011"></a>

Using WDConver in command line mode consists in running a conversion description created and saved with WDConver (".WDV" file).

The following syntax is used to start WDConver in command line:


```txt
WDConver.EXE [-report][-error][-wizard]/SCRIPT=<WDVFile>
```


**Details of parameters**:

| Parameters | Meaning |
| --- | --- |
| [-report] | If this parameter is specified, a status report will be displayed at the end of the script execution.<br>By default, if this parameter is not specified, no status report will be displayed at the end of the script execution. |
| [-error] | If this parameter is specified, an error message will be displayed at the end of the script execution.<br>By default, if this parameter is not specified, no error message will be displayed at the end of the script execution. |
| [-wizard] | If this parameter is specified, the wizard for data conversion will be started.<br>By default, if this parameter is not specified, the wizard for data conversion will not be started. |
| /SCRIPT=&lt;WDVFile&gt; | Character string containing the name and full path of the description de conversion to use (".WDV" file).<br>This parameter is **mandatory** except if the "-wizard" parameter is specified. |
| /WDD=&lt;Database schema path&gt; | Character string containing the path of the WINDEV, WEBDEV or WINDEV Mobile database schema. This path must be enclosed in quotes if it contains space characters. |
| /PWD=&lt;Unencrypted password of the database schema&gt; | Character string containing the password of the WINDEV, WEBDEV or WINDEV Mobile database schema. This password must be enclosed quotes if it contains space characters. |
| /WDD55=&lt;Path of WINDEV 5.5 database schema&gt; | Character string containing the path of the WINDEV 5.5 database schema. This path must be enclosed in quotes if it contains space characters. |
| /PWD55=&lt;Unencrypted password of WINDEV 5.5 database schema&gt; | Character string containing the password of the WINDEV 5.5 database schema. This password must be enclosed quotes if it contains space characters. |
| /SRCDIR=&lt;Directory of sought Hyper File 5.5 tables&gt; | Character string containing the path of the Hyper File 5.5 tables to convert. |
| /DSTDIR=&lt;Directory of converted tables&gt; | Character string containing the directory where the tables converted to HFSQL Classic will be created |
| /FILE=&lt;Source table&gt; | Character string containing:<br><br>- the path of the Hyper File 5.5 table to convert<br><br>- the name of the table to convert on the server.<br><br><br> |
| /NAME=&lt;Logical name in the WINDEV 5.5 database schema of the table to convert&gt; | Character string corresponding to the logical name of the table to convert in the WINDEV, WEBDEV or WINDEV Mobile database schema. |
| /FILEPWD55=&lt;Unencrypted password of source file&gt; | Character string corresponding to the password of the WINDEV 5.5 file to convert. |
| /FILEDST=&lt;Destination path of converted file&gt; | Character string corresponding to the path of the converted file |
| /NOREP | Used to ignore the .REP file in WINDEV 5.5 format. |
| /MODE=[HF5 \ EXTERN \ XML \ TEXT] Type of source files | Defines the format of the files to import:<br><br>- HF5: Hyper File 5.5 tables<br><br>- EXTERN: external files/tables (e.g. C/S database)<br><br>- XML: XML files<br><br>- TEXT: text files<br><br><br> |
| /PROVIDER=&lt;OLEDB provider or Native Connector&gt; | Character string that defines the provider or the Native Connector (also known as Native Access) used to access the data to convert.<br>For Native Connectors, use the following strings: WinDevOracle, WinDevSQLServer, WinDevInformix, ... |
| /DATASOURCE=&lt;Name of the source (file or server)&gt; | Character string. This parameter is used when converting a file via a Native Connector or an OLE DB provider, ...<br>Corresponds to the name of the data source. |
| /USER=&lt;Username&gt; | Character string. Corresponds to the name of the user of the data source. |
| /USERPWD=&lt;Unencrypted user password&gt; | Character string. Corresponds to the password of the user of the data source. |
| /DATABASE=&lt;Database name&gt; | Character string. Corresponds to the accessed database (if several ones are found on the server). |

**Note** The above array shows the various parameters that can be used to launch WDConver in command line mode. To get these parameters when starting WDConver, use one of the following syntaxes:

- WDConver.EXE /help

- WDConver.EXE /?




**Note**: Scripts created with an earlier version of WINDEV 7 cannot be used with WDConver version 8 and higher.. The scripts created with WINDEV 7.5 can be used with WDConver version 8 and later.

## Examples
<a name="examples_ELTTEXTE000265"></a>


### Usage example of a script:
<a name="usage_example_script_ELTPARAGRAPHE000160"></a>

The following command line is used to run the conversion description named "C:\\MyDirectory\\MyDescription.WDV". If an error occurs, a message is displayed at the end of the automatic modification of the tables ("-error" parameter). The wizard for automatic modification of the tables will not be started.


```wl
ExeRun("C:\MyTools\WDConver.EXE " +...
	"-error/SCRIPT=C:\MyDirectory\MyDescription.WDV")
```

<a name="NOTE2_2"></a>


### Use example
<a name="use_example_ELTPARAGRAPHE000169"></a>

The following command line is used to:

- Select all the Hyper File 5 files accessible by the ".REP" file and in the "C:\\data" directory.

- Convert these files to HFSQL Classic in the directory "C:\\dataclassic".





```wl
ExeRun("C:\MyTools\WDConver.EXE " +...
	"/WDD55=C:\WDProject\Project5\Project.WD5\Project.WDD" +... 
	"/WDD=""C:\My Projects\Project\Project.wdd" +...
	"/SRCDIR=""C:\data"" /DSTDIR=c:\dataclassic")
```

<a name="NOTE2_3"></a>


### Example for converting a single file
<a name="example_for_converting_single_file_ELTPARAGRAPHE000181"></a>

The following command line is used to convert a specific file:


```wl
ExeRun("C:\MyTools\WDConver.EXE " +... 
	"/WDD55=C:\WDProject\Project5\Project.WD5\Project.WDD " +...
	"/WDD=C:\My Projects\Project\Project.wdd " +...
	"/FILE=C:\data\exchange.fic /NAME=EXCHANGE " +...
	"/DSTDIR=c:\dataclassic /NOREP")
```

<a name="NOTE2_4"></a>


### Example of conversion via a Native Connector (or Native Access)
<a name="example_conversion_via_native_connector_native_access_ELTPARAGRAPHE000190"></a>

The following command line is used to convert the "DEMO.CUSTOMER" table via the Native Oracle Connector. The logical name of this table is "CUSTOMER" on the "MARS" server. The HFSQL Classic table will be created in the "c:\\data" directory.


```wl
ExeRun("C:\MyTools\WDConver.EXE " +...
	"/MODE=EXTERN /DATASOURCE=MARS "+...
	"/PROVIDER=WinDevOracle /USER=DEMO "+...
	"/USERPWD=DEMO "+...
	"/WDD=""C:\My Projects\test.ANA\test.wdd"""+...
	"/DSTDIR=c:\data /FILE=DEMO.CUSTOMER /NAME=CUSTOMER")
```
