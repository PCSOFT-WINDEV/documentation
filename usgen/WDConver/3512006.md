## Overview
<a name="overview_ELTTEXTE000215"></a>


### WDConver
<a name="wdconver_ELTPARAGRAPHE000011"></a>

WDConver is a tool used to convert **data** to an HFSQL Classic table from a file:

- a Hyper File 5 or 4 file.

- a text file.

- an XML file.

- a database accessed via an OLE DB provider or an ODBC driver (Excel, Access, Oracle, SQL Server, etc.).

- a database accessed via a Native WINDEV Connector (SQL Server, Oracle or AS/400).




**Caution**: WDConver can only convert **data** from a file. To perform this conversion, the **structure** of the table must have been converted previously. To convert the structure of a table, on the "Database schema" tab, in the "Creation" group, expand "Import" and select "Import file/table descriptions...". 

**Note**: Imports can be programmed using functions [HImportHF55](../WDLang4/3044055.md), [HImportText](../WDLang4/3044011.md), [HImportXML](../WDLang4/3044007.md), ...

**Example of use** After a major data update in an external file, WDConver re-imports all the data into a WINDEV database.

## Use
<a name="use_ELTTEXTE000239"></a>


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000053"></a>

WDConver can be redistributed. WDConver can be installed with the applications developed with WINDEV. The terms of the WINDEV license agreement apply.

When creating the setup procedure, WDConver can be supplied with your applications.

**Reminder** The installation procedure can be created:

- or from the wizard: in the "Project" pane, in the "Generation" group, pull down "Setup procedure" and select "Create installation procedure", 

- or from the installation editor: in the "Tools" pane, in the "Utilities" group, click on "WDInst".

## Starting WDConver
<a name="starting_wdconver_ELTTEXTE000269"></a>
WDConver can be started:

- [**In interactive mode**](../WDConver/3512002.md)You can do this by launching the "WDConver.EXE" program directly, or from the data model editor: in the "Database schema" pane, in the "Creation" group, pull down "Import" and select "Import data from another database".

- [**In command line mode**](../WDConver/3512003.md) to perform a conversion from a WINDEV application.
