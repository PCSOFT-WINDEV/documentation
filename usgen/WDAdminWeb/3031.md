## ERR_MSG_BOX error
<a name="errmsgbox_error_ELTTEXTE000063"></a>
The site generated the following error message:... ERR_MSG_BOX (25)

A dialog box was displayed on the server, locking the site. WEBDEV automatically closes the message box and the corresponding message is displayed in the browser.
Correct the dynamic WEBDEV website according to the error message displayed. In most cases, the error corresponds to a programming error in the WEBDEV site.
