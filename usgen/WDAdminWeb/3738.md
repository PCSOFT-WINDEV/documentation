## ERR_DISCONNECTED_BY_ADMIN error
<a name="errdisconnectedbyadmin_error_ELTTEXTE000068"></a>
This error occurs on the browser of the Web user when:

- the Web user was disconnected from the dynamic site by the local WEBDEV management tool ([Disconnect] or [Disconnect All] button

- the Web user was disconnected from the dynamic site by the remote WEBDEV management tool






By default, the Web user is automatically reconnected to the site after 3 seconds.
