## ERR_MAX_CONNECTION error
<a name="errmaxconnection_error_ELTTEXTE000071"></a>


### The connection is refused because the maximum number of authorized connections (&lt;NB_CONNECTION&gt;) has been reached. Retry later. ERR_MAX_CONNECTION (14)
<a name="the_connection_refused_because_the_maximum_number_authorized_connections_has_been_reached_retry_later_errmaxconnection_14_ELTPARAGRAPHE000007"></a>



This message is displayed on the Internet browser when the number of connections to the dynamic WEBDEV websites installed at the hosting provider is greater than the total number of authorized simultaneous connections.
It may be necessary to review the WEBDEV Application Server settings.

Reminder: The global maximum number of connections is defined for the server and a site in the WEBDEV administrator on the Web server ("Configuration" tab).
This number of connections can also be limited:

- for each site in the WEBDEV administrator ("Settings" button in the "Sites" tab).

- for each deployment account. This option is available in the WEBDEV Account Manager for Windows servers, or in the account settings in the WEBDEV Administrator for Linux.
