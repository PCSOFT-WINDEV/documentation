## ERR_LOADMOREDLL error
<a name="errloadmoredll_error_ELTTEXTE000059"></a>
The user component cannot be loaded - ERR_LOADMOREDLL (42)

A user component was defined in the registry by the MOREDLL entry (to optimize the management of AS/400 for example). This registry key is invalid.
