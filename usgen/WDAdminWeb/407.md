
## Remote WEBDEV administrator: Parameters of a WEBDEV site in Session mode or of a Web service
			



## Configuring web services and sites in Session mode
<a name="configuring_web_services_and_sites_session_mode_ELTTEXTE000145"></a>
To view the configuration of a specific web service or WEBDEV website in Session mode from the remote administrator:

1. In the menu bar, select "Sites" or "Web services". 

2. The list of elements found on the WEBDEV Application Server is displayed.

3. Select the site or the web service to configure. 

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003.gif)


**Remark**: The Application Server manager can configure all sites and web services, while users can only configure sites and web services that belong to them.


### Available parameters
<a name="available_parameters_ELTPARAGRAPHE000018"></a>

The site characteristics are grouped in several themes: 

- General characteristics,

- Security

- SaaS parameters

- User Groupware file location




**1. General parameters**

The site may be **Blocked for maintenance**: When a site is set to this state, the Application Server refuses new connections and interrupts current connections.

For the next options, "General" indicates that the parameter corresponds to the value selected in the "Configuration" option, "Specific" is used to customize the parameter. You can customize: 

- the authorized idle time,

- the duration of AWP contexts,

- the maximum task duration,

- the number of authorized connections,

- the maximum number of connections allowed for the same user,

- the maximum number of pre-launched sessions.




You can also ask to generate a specific log file. 

**2. Security**

These security options are defined at server level in the "Configuration" option of remote WEBDEV administrator. These options can be customized. 

**3. SAAS parameters**

You have the ability to specify the URL of the SaaS web service to use. This parameter corresponds to: 

- the name of the host of the SaaS web service (for example "Computer", "Computer.MyNetwork.com", "http://Mydomain.com").

- the full URL of the SaaS web service (for example, "http://domain.com/WDSAAS310_WEB/WDSaaS310.awws").




**4. User Groupware file location**

If the site uses the User Groupware: 

- version 18 and higher, you need to specify the location of the rights file.

- legacy version, you need to specify the location of the rights and users file. 




**5. Icons for a specific configuration**

Several icons can be used to perform a specific configuration: 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%202.gif) is used to list and manage the scheduled tasks. By clicking this button, the list of scheduled tasks is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0005.gif)
 It is possible to: 

	- Run a scheduled task directly,

	- Modify the scheduling of a scheduled task,

	- Delete a scheduled task. This scheduled task will be deleted until the server is restarted or until the next site deployment. 

	- Refresh the list. 




- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%203.gif) is used to access the site directory. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%204.gif) is used to access the data directory. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%205.gif) is used to access the statistics. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%206.gif) allows you to [manage the site backups](../WDAdminWeb/205.md). 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%201.gif) allows you to [customize the error messages for a given site](../WDAdminWeb/306.md).

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0003%207.gif) is used to delete a site.
