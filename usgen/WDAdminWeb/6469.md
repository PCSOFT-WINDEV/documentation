
## Remote WEBDEV administrator: Importing statistics
			



## Overview
<a name="overview_ELTTEXTE000098"></a>
The remote WEBDEV administrator proposes a module for managing the statistics. This module is used to: 

- import the statistics of a site.

- view the statistics about one or more sites.




A specific account dedicated to the management of statistics is required to access this statistical module. This account can be created via the remote administrator. For more details on how to create the account, see [Configuring the remote administrator](../WDAdminWeb/6468.md). 





## How to?
<a name="how_ELTTEXTE000122"></a>


### Viewing the statistics of a site
<a name="viewing_the_statistics_site_ELTPARAGRAPHE000020"></a>

To view the statistics of a site:


1. **Launch the remote WEBDEV administrator** by entering the following address: 
	
	```txt
	http://<server>/WDAdminWeb
	```
where &lt;server&gt; represents the WEBDEV Application Server address (name or IP address).

2. To view the statistics, you must authenticate yourself with the username and the password corresponding to the account for viewing statistics. 

3. The site for viewing the statistics appears. A message is displayed if not data is imported. 







### Importing the statistics of a site
<a name="importing_the_statistics_site_ELTPARAGRAPHE000034"></a>

To import the statistics of a site:

1. Click the "Import" tab of the remote WEBDEV administrator. 

2. In the "Import the logs of a site" section, select: 

	- the relevant site. 

	- the start date of the import. 




3. Click the "Start the import" button. 
	**Caution**: Depending on the duration specified, importing statistics may take a relatively long time.. 




**Remarks**: 

- The "Reset" button resets all the statistics of the site. 

- When the import is in progress, it appears in the "Imports in progress" area. 

- When the import is completed, it appears in the "Completed imports" area.
