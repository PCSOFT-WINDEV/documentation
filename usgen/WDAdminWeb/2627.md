## ERR_NO_APPLICATION  error
<a name="errnoapplication_error_ELTTEXTE000082"></a>
The &lt;SITE_NAME&gt; site is unknown: it was not configured for WEBDEV. ERR_NO_APPLICATION (32)

The WEBDEV application (dynamic site, SOAP or REST web service) is not installed correctly (invalid correspondence with the registry). Reinstall the application and/or check its configuration in the registry.

Reminder:
When a WEBDEV application is installed, a new entry is created in the registry.
A new entry is created in the following key:
"HKEY_LOCAL_MACHINE\\SOFTWARE\\WOW6432Node\\PC SOFT\\WEBDEV\\31.0\\&lt;Type&gt;\\&lt;Name&gt;"
where: 

- &lt;Type&gt; corresponds to one of the following: 

	- "Applications" for dynamic WEBDEV websites,

	- "web services" for SOAP web services,

	- "RESTWebservices" for REST web services. 




- &lt;Name&gt; corresponds to the name of the deployed application. 




The name of the project and its directory are specified.
