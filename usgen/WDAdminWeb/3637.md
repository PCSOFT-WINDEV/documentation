## ERR_DISCONNECTED_TIMEOUT error
<a name="errdisconnectedtimeout_error_ELTTEXTE000061"></a>
This error occurs on the browser of the Web user when the response time of the last action performed is greater than the time configured in the local or remote WEBDEV management tool.
By default, the Web user is automatically reconnected to the site after 3 seconds.
