## ERR_DISCONNECTED_ERROR error
<a name="errdisconnectederror_error_ELTTEXTE000060"></a>
This message is displayed when the Web user tries to reconnect to a dynamic WEBDEV site that ended by an error.

By default, the Web user is automatically reconnected to the site after 3 seconds.
