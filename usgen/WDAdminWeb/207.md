
## Remote WEBDEV administrator: Personal information
			



## User information
<a name="user_information_ELTTEXTE000128"></a>
The remote administration tool is used to check and modify (if necessary) your personal information.

Note: By default, this information is entered by the server administrator when the WEBDEV account is created.


### Modifying your personal information
<a name="modifying_your_personal_information_ELTPARAGRAPHE000012"></a>

To modify your personal information:

1. Click the "&lt;Login&gt;" link found in the menu bar. In the popup that is displayed, click "See my profile".

2. In the "Your personal information" section, modify the displayed information if necessary. Check the validity of the email address.

3. Click the "Modify" button. Your personal information is automatically modified.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0014.gif&type=thumb)





This information is automatically carried over into the description of your [WEBDEV account](../WDAdminWeb/304.md) found on the Web server.





## Password
<a name="password_ELTTEXTE000158"></a>
The password used to access the remote administration tool is defined by the server administrator, when creating the [WEBDEV account](../WDAdminWeb/304.md).

This password is used:

- for the connection to the remote administration tool.

- when installing or updating WEBDEV websites remotely (by FTP).




This password can be modified at any time from the remote administration tool.


### Modifying your password from the remote administration tool
<a name="modifying_your_password_from_the_remote_administration_tool_ELTPARAGRAPHE000042"></a>

To modify your password from the remote administration tool:

1. Click the "&lt;Login&gt;" link found in the menu bar. In the popup that is displayed, click "See my profile".

2. In the "Your personal information" section, click the "Modify the password" button. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0014%201.gif)<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0015.gif&type=thumb)


3. Click the "Modify" button. The new password is immediately valid.






## Statistics accounts
<a name="statistics_accounts_ELTTEXTE000188"></a>


### Overview
<a name="overview_ELTPARAGRAPHE000058"></a>

The statistical accounts are used to access the statistical module of the remote WEBDEV administrator. All you have to do is start the remote administrator and specify the login and password of the statistical account. For more details on statistics, see [Remote WEBDEV administrator: Statistics](../WDAdminWeb/6466.md).  


### Creating a statistical account
<a name="creating_statistical_account_ELTPARAGRAPHE000066"></a>

To create a statistical account:

1. Click the "&lt;Login&gt;" link found in the menu bar. In the popup that is displayed, click "See my profile".

2. In the "Editing the statistical accounts" section, click the "New" button.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Admin_WebDev_distant%20-%20HC%20N%B0014%202.gif&type=thumb)


3. Enter the requested information: login, password, ...

4. Click the "Apply" button to validate. 

5. Indicate the sites and the web services for which the statistics can be viewed. 

6. The account for viewing statistics is created and it can be used. 




**Remarks**: 

- The "Edit" button is used to modify the information about a statistical account. 

- The "Delete" button is used to delete a statistical account.
