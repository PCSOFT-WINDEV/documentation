## ERR_NOTAVAILABLE error
<a name="errnotavailable_error_ELTTEXTE000062"></a>
This command is only available in development mode - ERR_NOTAVAILABLE (40)

WEBDEV "Deployment Version" is used to deploy a dynamic WEBDEV website.

Solution: You need to install WEBDEV "Deployment version" to deploy a dynamic WEBDEV site.
