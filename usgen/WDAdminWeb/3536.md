## ERR_BAD_CONTEXT error
<a name="errbadcontext_error_ELTTEXTE000072"></a>
The context to which this request refers does not exist (or does not exist anymore). You may have been disconnected ERR-BAD_CONTEXT. 

This message is displayed by the Web browser when the WEBDEV engine is not active anymore.

The WEBDEV engine is not active anymore in several cases:

- the idle time was exceeded: the user has been disconnected.
	**Solution:** restart the application and configure (if necessary) a longer disconnection time in the options of the local or remote administration tool.

- the HTML page was not refreshed (in test mode only)
	**Solution:** Refresh the display of the page via the [Refresh] button in the Internet browser.
