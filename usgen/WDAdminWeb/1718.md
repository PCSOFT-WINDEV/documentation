## ERR_NO_CURRENT_PAGE error
<a name="errnocurrentpage_error_ELTTEXTE000063"></a>
The site did not work properly because no page was returned. ERR_NO_CURRENT_PAGE (5).

This error message occurs when a dynamic WEBDEV website is closed without using the HTML page indicating the end of connection.

To avoid this message, a page indicating the end of connection must be displayed by **PageDisplay** or **EndProgram**
