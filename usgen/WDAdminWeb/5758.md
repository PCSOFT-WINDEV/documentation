### WEBDEV is configured to forbid the remote setup
<a name="webdev_configured_forbid_the_remote_setup_ELTPARAGRAPHE000008"></a>



This message is displayed when trying to perform a remote update. The local management tool (found on the Web server) is not configured to allow the remote setup.
