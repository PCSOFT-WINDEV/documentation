
## ERR_DISCONNECTED_RELOG 
			



## ERR_DISCONNECTED_RELOG error
<a name="errdisconnectedrelog_error_ELTTEXTE000062"></a>
This message appears, for example, when the user uses the browser's "Back" button: the user is on an old page of the site, and the corresponding context no longer exists.

By default, the Web user is automatically reconnected to the site after 3 seconds.
