
## Remote WEBDEV administrator
			



## Overview of remote WEBDEV administrator
<a name="overview_remote_webdev_administrator_ELTTEXTE000109"></a>
The remote administration tool, that can be run from any computer equipped with an Internet browser, is a module allowing:

- the managers of WEBDEV websites to configure their dynamic WEBDEV websites and their web services installed on a Web server.

- the server administrators to configure all the dynamic WEBDEV websites and the web services installed on a server.




The operations that can be performed from the remote administration tool affect:

**1. The management of information regarding the site manager**:

- [Viewing and modifying the personal details](../WDAdminWeb/207.md)

- [Changing the password](../WDAdminWeb/207.md)

- [Sending messages to the server administrator (option reserved to the site manager)](#MsgAdmin)

- [Managing the WEBDEV accounts (option reserved to the server administrator)](../WDAdminWeb/304.md)

- [Managing the accounts for viewing statistics](../WDAdminWeb/6468.md)




**2. The management of information regarding the dynamic WEBDEV sites and the web services**: 

- [Configuring the server (option reserved to the server administrator)](../WDAdminWeb/105.md)

- [Viewing the connections to the dynamic WEBDEV websites](../WDAdminWeb/508.md)

- [Configuring a dynamic WEBDEV website or a web service](../WDAdminWeb/407.md)

- [Distributing the available connections among the sites (option reserved to the site managers)](../WDAdminWeb/407.md)

- [Changing error messages on a WEBDEV website](../WDAdminWeb/306.md)

- [Saving and restoring a WEBDEV website](../WDAdminWeb/205.md)

- [Viewing the statistics regarding the traffic of sites](../WDAdminWeb/6466.md)

## Contacting the manager of the Application Server
<a name="contacting_the_manager_the_application_server_ELTTEXTE000133"></a>
A site manager can contact the administrator of the Web server at any time.

**Note**: This operation is only available to site managers via the remote administration tool.


### Contacting the server administrator
<a name="contacting_the_server_administrator_ELTPARAGRAPHE000057"></a>

To contact the server administrator:

1. Click the "Contact the server administrator" link on the home page.

2. The details of the server administrator are displayed. If an email address is specified, all you have to do is click this address to directly send a message to your server administrator.
