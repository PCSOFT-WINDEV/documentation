## ERR_OUT_OF_MEMORY error
<a name="erroutofmemory_error_ELTTEXTE000077"></a>
Insufficient memory to perform the operation. ERR_OUT_OF_MEMORY 

Insufficient memory to run the program.



**Reminder: The resource required per connected user:**
For each connected Web user, you must plan for:

- about 400 KB of RAM per connection, in addition to the memory required by the server.

- about 1 MB of disk space per connection.






For example, for 20 parallel connections, you must plan for:

- RAM: 67.8 MB (7.8 MB of RAM for this site, 60 MB for the NT server)

- Virtual memory: 84 MB (20 MB for the connections and 64 MB for the NT server)






The number of connections can be limited in the remote administration tool to avoid a drop in the system performance.
