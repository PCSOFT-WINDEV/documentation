


## Appendix 1: WEBDEV vocabulary
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
This page presents the main terms specific to WEBDEV used in the documentation of WEBDEV Application Server.

**Server administrator**
Person responsible for installing programs or sites on one or more servers at the hosting provider. In the case of a shared server, the server administrator handles the distribution of connections per site manager, the physical location of sites on the server, etc.

**Remote WEBDEV administrator** 
Site installed on the Web server, allowing:

- the site manager to remotely check and/or modify the configuration of their WEBDEV websites installed on a server.

- the server administrator to remotely check and/or modify the configuration of all WEBDEV websites installed on the server. The server administrator can also manage User accounts.




**WEBDEV administrator**
Windows application installed on the server allowing the server administrator to configure the dynamic WEBDEV websites installed on the current server.
The WEBDEV administrator can also be used to create User accounts.

**User account**
Account associated with a site manager.
This account allows the server administrator to:

- group the sites that belong to a site manager.

- configure the number of authorized connections for a site manager.

- configure the setup directories of sites.

- configure the transfer directory (for a setup or an update via FTP).




This account allows the site manager to:

- use the remote administrator.

- perform remote site setups and updates.




This account is created on a Web server by the server administrator via:

- the local administrator,

- the remote administrator.




Site developer
Person who creates and modifies WEBDEV websites with WEBDEV Development version.

**Hosting provider**
Company proposing to host Internet sites on their Web servers.

**Web user**
User of Internet sites.

**Site manager**
Person responsible for deploying and maintaining one or more WEBDEV websites. This person is in direct contact with the server administrator.
