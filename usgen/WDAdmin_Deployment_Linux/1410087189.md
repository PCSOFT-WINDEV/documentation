## Files of WEBDEV Application Server for Linux
<a name="files_webdev_application_server_for_linux_ELTTEXTE000159"></a>
WEBDEV 2026 Application Server for Linux installs the following files and directories:

- WEBDEV configuration file 2026: /etc/PC SOFT/WEBDEV/31.0/WEBDEV.conf

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_1.gif)


- Installed sites configuration file: /etc/PC SOFT/WEBDEV/31.0/Applications/&lt;Nom site&gt;.conf

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_2.gif)


- WEBDEV Application Server for Linux installation directory: /usr/local/WebDev/31.0

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_3.gif)


- AWP protocol installation directory: /usr/local/WebDev/31.0/AWP

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_4.gif)


- Remote WEBDEV administrator installation directory: /usr/local/WebDev/31.0/WDAdminWeb

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_5.gif)


- Installation directory for programs used to deploy sites on the server: /usr/local/WebDev/31.0/WDInstalle

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_6.gif)

## Files installed when deploying a dynamic WEBDEV site
<a name="files_installed_when_deploying_dynamic_webdev_site_ELTTEXTE000183"></a>
Several types of files are installed when deploying a WEBDEV site:

- pages, images, etc. are installed in the sub-directory of the site corresponding to the user. In this example, the files are installed in the app\\&lt;site name&gt; subdirectory of the user named "Pat". This information (pages installation directory, etc.) was specified when creating the User account in the remote administrator ([Creating user accounts](../wdadmin_deploiement_linux/1410087177.md)).

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_8.gif)


- the tables (HFSQL only) are installed in the table subdirectory corresponding to the user. In this example, the files are installed in the data\\&lt;site name&gt; subdirectory of the user named Pat.
	This information (data installation directory, etc.) was specified when creating the User account in the remote administrator ([Creating user accounts](../wdadmin_deploiement_linux/1410087177.md)).

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LinuxTree_7.gif)
