


## WEBDEV Application Server for Linux - Overview
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
WEBDEV is a complete development environment dedicated to the Internet and Intranet. WEBDEV is the best solution for developing Internet and Intranet sites that may require access to a database.
The technology used ensures that the sites work with all the browsers available on the market, regardless of their version and platform (PC, MAC, Android, iOS, etc. 
This technology also allows sites to be used with any Linux or Windows server on the market: Apache, IIS, etc.




The Linux distributions supported by WEBDEV Application Server are as follows:

- Debian 9 or later

- Fedora 25 or later

- Ubuntu version 18.04 or higher (minimum GCC version: 5.1)

- OpenSUSE:Leap:15.0 with GCC 7. OpenSUSE Leap 15.2 is also supported.




Starting with version 27, the following Linux distributions are no longer supported: 

- CentOS 7 (GCC 4.8)




WEBDEV includes:

- WEBDEV Development Version: 
	This version, Installed on the development computer, allows you to develop a WEBDEV website and test it locally.

- WEBDEV Application Server: 
	Installed on an HTTP server at the hosting provider, this version is used to deploy a dynamic WEBDEV website (site with database). The WEBDEV site can be used by all the Web users.




**Note** WEBDEV Application Server is not required for deployment of a static site (which does not use data).
<a name="NOTE1_2"></a>


### Features of WEBDEV Application Server for Linux
<a name="features_webdev_application_server_for_linux_ELTPARAGRAPHE000034"></a>

**The WEBDEV Application Server** must be installed on a server (at the hosting provider or on an Intranet server). With the WEBDEV Application Server:

- Web users can use dynamic WEBDEV websites.

- The server administrator can:

	- Manage and configure dynamic WEBDEV websites located on the server.

	- Configure the User accounts associated with each site manager.

	- Monitor the setup and update of dynamic WEBDEV websites remotely (via FTP or HTTP).




- The manager of the WEBDEV sites can:

	- Install or update dynamic sites remotely (via FTP or HTTP).

	- Change the configuration of dynamic WEBDEV websites.
