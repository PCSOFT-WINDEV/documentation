
## ReplicEdit: Updating replicated data with changes from the database schema
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000078"></a>
When modifying the database schema of a replicated application (add an item, a table, ...), this modification must be taken into account in the description of the replication.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000102"></a>
To take the modifications made to the database schema into account in the .WER file of the replication:

1. Open the requested .WER file in ReplicEdit.

2. Select "Replication .. Update from the database schema description".



<a name="NOTE2_2"></a>


### Caution
<a name="caution_ELTPARAGRAPHE000026"></a>

If the connections defined in the database schema are password protected, the passwords must be specified in ReplicEdit (for more details, see [Replication options](../ReplicEdit/3526502.md)).
