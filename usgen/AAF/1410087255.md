


## Export your data to Word
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
You can easily export data from a table to Word. Simply export the table to your preferred program (Word, OpenOffice, etc.). The corresponding file is automatically created from the table content and can be used right away in a word processing program.

To export to Word:

1. Right-click to open the context menu of the table and select "Export table to Word/OpenOffice" (the option varies depending on the software installed on your computer).  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Exportez%20vos%20donn%E9es%20vers%20Word.jpg)


2. Specify the name and location of the file to be created.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Exportez%20vos%20donn%E9es%20vers%20Excel%202.jpg)


3. The file can be viewed immediately.




You can search for data in the content displayed in the word processor.

Note: If the file already exists, you can overwrite it.
<a name="NOTE1_2"></a>


### Tip
<a name="tip_ELTPARAGRAPHE000016"></a>

This export functionality is also available for data displayed in a pivot table.
