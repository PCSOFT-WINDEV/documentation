


## Customize your interface: Move, enlarge or color controls
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
You want to make some simple changes in your interface, such as moving a control? Simply use the UI edit mode. 

To enable the UI edit mode: 

1. Right-click the window background to open the context menu. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Personnalisez%20votre%20interface.jpg)


2. Select "Customize interface" and "Change to edit mode". 

3. The interface changes to edit mode. You can perform simple actions: 

	- Move a control. 
			Simply select the control and move it in the window. 

	- Make a control invisible. 
			 Select the control, right-click to open the context menu and uncheck "Visible". 

	- Change the text color.
			Select the control that contains the text, open the context menu, select "Text color" and choose the desired color.

	- Change the text size. 
			Select the control that contains the text, open the context menu, select "Text size" and choose the desired size.




4. To apply changes, simply select "End of edit mode".
