


## Export your data to Excel
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
You can easily make simulations with Excel or Open Office. Simply export the table to your preferred spreadsheet program (Excel, OpenOffice, etc.). The corresponding file is automatically created from the table content and can be used in another software.

To export to Excel:

1. Right-click to open the context menu of the table and select "Export the table to Excel/OpenOffice" (the option varies depending on the software installed on your computer).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Exportez%20vos%20donn%E9es%20vers%20Excel%201.jpg)


2. Specify the name and location of the file to be created.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Exportez%20vos%20donn%E9es%20vers%20Excel%202.jpg)


3. The file can be viewed immediately. 
	You can search for data, run a simulation, make specific calculations or calculate statistics on the data displayed in the spreadsheet editor.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Exportez%20vos%20donn%E9es%20vers%20Excel%203.jpg)



Note: If the file already exists, you have the option of overwriting the existing file or merging it with the file being created. The merge operation allows you to keep all the changes made to your spreadsheet (format of cells, formula, etc.).
This process also applies when exporting data to a word processing software.
<a name="NOTE1_2"></a>


### Tip
<a name="tip_ELTPARAGRAPHE000016"></a>

This export functionality is also available for data displayed in a pivot table.
