


## Printing reports? Annotate, print and search in the report viewer
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
You can view printouts in the report viewer. This report viewer features many options by default.


<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Visualiseur%20de%20rapports.jpg)
The report viewer contains the following elements: 

- A ribbon-like menu that includes the following tabs: 

	- Preview: used to manage the current preview: zoom, crosshair, move, move between pages. 

	- Print: used to manage the direct print on the printer. 

	- Export: used to manage the different export modes of the print (PDF, Word, Excel, ...). 

	- Search: used to manage the search in the preview. 

	- Annotate: used to write annotations in the report currently displayed in the preview.




- A context menu with most of the options.


Please note: For security reasons, some options may be disabled.

Explore these tabs to discover all of their options.
