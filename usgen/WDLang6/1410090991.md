
## Palette functions

<a name="NOTE1_1"></a>

|   |   |
| --- | --- |
| [PaletteChange](../WDLang6/1410090897.md) | Changes the palette used by the project or by a window. |
| [PaletteGet](../WDLang6/1410090898.md) | Gets the palette currently used by the project or window. |
