


## &lt;Window&gt;.PaletteGet (Function)

***In french: &lt;Fenêtre&gt;.PaletteRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the palette currently used by the window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPalette is Palette = WIN_Menu.PaletteGet()
STC_Problem.BackgroundColor = MyPalette["caution"]
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Window>.PaletteGet()`
---

**`<Result>: (Palette variable)`**

[Palette](../WDLang1/1000021347.md) variable containing the palette of the specified window. 

**`<Window>: (Window name)`**

Name of the window whose palette is to be retrieved.
