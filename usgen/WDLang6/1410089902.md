


## PDF file functions (prefix syntax)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>

WLanguage includes different types of variables to manipulate PDF files:  



|   |   |
| --- | --- |
| [pdfAttachment](../WDLang6/1000024899.md) | The **pdfAttachment** type is used to define all the advanced characteristics of an attachment in a PDF document. |
| [pdfBookmark](../WDLang6/1410089195.md) | The **pdfBookmark** type is used to define all the advanced characteristics of a bookmark in a PDF document. |
| [pdfControl](../WDLang6/1410090536.md) | The **pdfControl** type is used to get all the characteristics and values of a control present in a PDF form. |
| [pdfControlOption](../WDLang6/1410090533.md) | The **pdfControlOption** type is used to get and set the following characteristics of an option of a control present in a PDF form: <br><br>- option text. <br><br>- selected or deselected state of the option.<br><br><br> |
| [pdfDocument](../WDLang6/1000024909.md) | The **pdfDocument** type is used to get all the characteristics of a PDF file, including author, date created, page content, etc. |
| [pdfPage](../WDLang6/1000024904.md) | The **pdfPage** type is used to define all the advanced characteristics of a page from a PDF document loaded in memory. |
| [pdfParameter](../WDLang6/1410087857.md) | The **pdfParameter** type defines all the characteristics of the PDF file to be generated. |
| [pdfProtection](../WDLang6/1410091145.md) | The **pdfProtection** type allows you to identify the protection options applied to a PDF document present in a variable of type [pdfDocument](../WDLang6/1000024909.md).<br><br>**This variable type is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
| [pdfSignature](../WDLang6/1000022255.md) | The **pdfSignature** type is used to define the advanced characteristics of the signature that will be applied to a PDF file when signing an existing PDF (via [&lt;pdfDocument variable&gt;.Sign](../WDLang6/1410090339.md)).  |
| [pdfTextElement](../WDLang6/1000024556.md) | The **pdfTextElement** type is used to find out all the characteristics of a text element in a PDF page. |






The following functions are used to manipulate PDF files, using prefix syntax: 



|   |   |
| --- | --- |
| [&lt;pdfDocument variable&gt;.AddWatermark](../WDLang6/1410087872.md) | Adds a watermark to all the pages of an existing PDF file. |
| [&lt;pdfDocument variable&gt;.ExtractPage](../WDLang6/1410090338.md) | Extracts a page from a PDF file in a variable of type [Image](../WDLang1/1000019650.md). |
| [&lt;pdfDocument variable&gt;.GetSignature](../WDLang6/1410088159.md) | Gets the signature of a PDF document as a buffer. |
| [&lt;pdfDocument variable&gt;.GetSignatureDate](../WDLang6/1410088157.md) | Gets the date of one of the signatures of a PDF document. |
| [&lt;pdfDocument variable&gt;.NbSignatures](../WDLang6/1410088154.md) | Gets the number of signatures in a PDF document. |
| [&lt;pdfDocument variable&gt;.Save](../WDLang6/1410088160.md) | Saves the content of a [pdfDocument](../WDLang6/1000024909.md) variable in a ".PDF" file. |
| [&lt;pdfDocument variable&gt;.Sign](../WDLang6/1410090339.md) | Adds an approval signature to an existing PDF. |
| [&lt;pdfDocument variable&gt;.ToText](../WDLang6/1410090340.md) | Extracts text from a PDF file. |
| [&lt;pdfDocument variable&gt;.VerifySignatures](../WDLang6/1410091037.md) | Checks the validity of PDF signatures.<br><br> |
| [&lt;pdfPage variable&gt;.AddImage](../WDLang6/1410087875.md) | Adds an image to a page in an existing PDF file. |
| [&lt;pdfPage variable&gt;.AddWatermark](../WDLang6/1410087871.md) | Adds a watermark to a page of an existing PDF file. |
