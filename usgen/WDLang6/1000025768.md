


## ocrOption (Variable type)

***In french: ocrOption***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ocrOption** type is used to define all the general options of the native OCR (Optical Character Recognition) system. You can define and change the characteristics of these options using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Creation of options
MyOCROptions is ocrOption

// Detect only numbers when reading an image
MyOCROptions.OnlyDigit = True

OCRParameter(MyOCROptions)
```

<a name="PROPS"></a>

## Properties


### Properties specific to ocrOption variables
<a name="properties_specific_ocroption_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to handle the advanced options of the native OCR system:

| Property name | Type used | Effect |
| --- | --- | --- |
| Accuracy | Integer constant | ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Accuracy mode to use: <br><br>- *ocrPrecise*: Precise reading is a priority. <br><br>- *ocrRapid*: Speed of reading is the priority. <br><br><br> |
| ListWord | Array of strings | ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) List of words to add to the model. |
| OnlyDigit | Boolean | <br><br>- <u><u><u>True</u></u></u> if the OCR system must return Arabic numerals only,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is not available. |
| WithSpellingChecker | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to enable the spelling checker,<br><br>- <u><u><u>False</u></u></u> to disable it. <br><br><br> |
