
## pdfProtection (Variable type)

***In french: pdfProtection***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **pdfProtection** type allows you to identify the protection options applied to a PDF document present in a variable of type [pdfDocument](../WDLang6/1000024909.md). 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
my_doc is pdfDocument = "mypdf.pdf"

IF my_doc.Protection.Modification = True THEN
	Info("Modification allowed")
END

IF my_doc.Protection.Assembly = True THEN
	Info("Page addition, deletion and rotation allowed")
END
```

## Properties


### Properties specific to pdfProtection variables
<a name="properties_specific_pdfprotection_variables_ELTPARAGRAPHE000033"></a>

The following properties can be used to define the characteristics of **pdfProtection** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Assembly | Boolean | <br><br>- <u><u><u>True</u></u></u> if document assembly is allowed,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| Comment | Boolean | <br><br>- <u><u><u>True</u></u></u> if the insertion of comments in the document is allowed,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| CopyAccessibility | Boolean | <br><br>- <u><u><u>True</u></u></u> if content copying for accessibility is allowed,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| FillForm | Boolean | <br><br>- <u><u><u>True</u></u></u> if the form contains controls that allow user input,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| Modification | Boolean | <br><br>- <u><u><u>True</u></u></u> if document editing is allowed,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| Printing | Boolean | <br><br>- <u><u><u>True</u></u></u> if printing is allowed,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
| Selection | Boolean | <br><br>- <u><u><u>True</u></u></u> if the contents of the PDF file can be copied or extracted,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>This property is read-only. |
