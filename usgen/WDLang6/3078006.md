
## Twain constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used by the Twain functions: 

| Constant | Description | Used by the functions |
| --- | --- | --- |
| **tsLoaded** | The Twain manager is loaded | [TwainState](../WDLang6/3078002.md) |
| **tsOpen** | The Twain manager is opened |
| **tsSourceEnabled** | The source is enabled |
| **tsSourceOpen** | The source is opened |
| **tsSourceReady** | The source is ready to transfer data |
| **tsSourceTransfer** | The source is currently transferring data. |
| **tsUnloaded** | The Twain manager is not loaded |
| **TwainAnyType** | Retrieves any type of image | [TwainToBMP](../WDLang6/3078010.md),<br>[TwainToControl](../WDLang6/3078008.md),<br>[TwainToGIF](../WDLang6/3078012.md),<br>[TwainToJPEG](../WDLang6/3078009.md),<br>[TwainToPDF](../WDLang6/1000020877.md)<br>[TwainToClipboard](../WDLang6/3078011.md)<br>[TwainToTIFF](../WDLang6/1000020875.md) |
| **TwainAutoDeskewEnabled** | Twain device properties: Automatic image straightening management mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainAutoResizeEnabled** | Twain device properties: Automatic resizing management mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainAutoRotationEnabled** | Twain device properties: Image rotation management mode | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainBarCodeDetectionEnabled** | Twain device properties: Strikethrough detection mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainBitsByPixel** | Twain device property: Number of bits per pixel. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainBlackWhite** | Retrieves the image in black and white | [TwainToBMP](../WDLang6/3078010.md),<br>[TwainToControl](../WDLang6/3078008.md),<br>[TwainToGIF](../WDLang6/3078012.md),<br>[TwainToJPEG](../WDLang6/3078009.md),<br>[TwainToPDF](../WDLang6/1000020877.md)<br>[TwainToClipboard](../WDLang6/3078011.md)<br>[TwainToTIFF](../WDLang6/1000020875.md) |
| **TwainBlankPageSkipEnabled** | Twain device properties: White page management mode | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainBorderDetectionEnabled** | Twain device property: Edge detection mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainBrightness** | Twain device property: Device brightness. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainContrast** | Twain device property: Twain device contrast. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainDuplex** | Twain device properties: Duplex support. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainDuplexEnabled** | Twain device property: Duplex management mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainFeederEnabled** | Twain device property: Feeder management mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainGrayScale** | Retrieves the image in grayscale | [TwainToBMP](../WDLang6/3078010.md),<br>[TwainToControl](../WDLang6/3078008.md),<br>[TwainToGIF](../WDLang6/3078012.md),<br>[TwainToJPEG](../WDLang6/3078009.md),<br>[TwainToPDF](../WDLang6/1000020877.md)<br>[TwainToClipboard](../WDLang6/3078011.md)<br>[TwainToTIFF](../WDLang6/1000020875.md) |
| **TwainHeight** | Twain device property: Maximum height (in millimeters). | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainInterfaceControllable** | Twain device property: User interface management mode. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainPalette** | Retrieves the image using colors from a palette (1 , 4 or 8 bits per pixel) | [TwainToBMP](../WDLang6/3078010.md),<br>[TwainToControl](../WDLang6/3078008.md),<br>[TwainToGIF](../WDLang6/3078012.md),<br>[TwainToJPEG](../WDLang6/3078009.md),<br>[TwainToPDF](../WDLang6/1000020877.md)<br>[TwainToClipboard](../WDLang6/3078011.md)<br>[TwainToTIFF](../WDLang6/1000020875.md) |
| **TwainReady** | Twain device ownership: Device status. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainResolution** | Twain device property: Resolution in pixels per inch. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainRGB** | Retrieves the RGB image (24 bits per pixel) | [TwainToBMP](../WDLang6/3078010.md),<br>[TwainToControl](../WDLang6/3078008.md),<br>[TwainToGIF](../WDLang6/3078012.md),<br>[TwainToJPEG](../WDLang6/3078009.md),<br>[TwainToPDF](../WDLang6/1000020877.md)<br>[TwainToClipboard](../WDLang6/3078011.md)<br>[TwainToTIFF](../WDLang6/1000020875.md) |
| **TwainType** | Twain device property: Type of images managed. | [TwainProperty](../WDLang6/1000021192.md) |
| **TwainWidth** | Twain device properties: Maximum width (in millimeters) | [TwainProperty](../WDLang6/1000021192.md) |
