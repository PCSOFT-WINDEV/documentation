
## gpwListUser (Function)

***In french: gpwListeUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the list of users in the User Groupware.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrUser is array of gpwUser
AUser is gpwUser
arrUser = gpwListUser()
IF ErrorOccurred THEN
	ErrorInfo(errMessage)
ELSE
	FOR EACH AUser OF arrUser
		Trace(AUser.Username + "//" + AUser.LastName + "//" + AUser.FirstName)
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Users> = gpwListUser()`
---

**`<Users>: (WLanguage array)`**

Array of [gpwUser](../WDLang6/1000021088.md) variables corresponding to the users in the User Groupware. 
If an error occurs (e.g., no connection), the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. You can get the details of the error with [ErrorInfo](../WDLang1/3013008.md).
**Note**: The information retrieved is different if the user currently logged in is a supervisor or a simple user.. If the user is not a supervisor, only the **Login** and **Enabled** properties of the [gpwUser](../WDLang6/1000021088.md) variable will be accessible.
