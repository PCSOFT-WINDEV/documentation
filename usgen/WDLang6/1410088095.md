


## aiNeuralNetworkModel (Variable type)

***In french: iaModèleRéseauDeNeurones***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **aiNeuralNetworkModel** type is used to define all the advanced characteristics of a neural network used by [AIDetectModel](../WDLang6/1410087982.md). You can define and change the characteristics of this neural network using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Image declaration
MyImage is Image
MyImage = IMG_Test

// Declare a model
MyAINNModel is aiNeuralNetworkModel

MyAINNModel.Configuration = "MyModel.cfg"
MyAINNModel.TrainedWeights = "MyModel.weights.pb"
MyAINNModel.PixelScaleFactor = 1.0

// Please note: X and Y dimensions are model-dependent. 
// If the specified dimensions do not match the model,
// AIDetectModel returns an error. 
MyAINNModel.XDimension = 300 
MyAINNModel.YDimension = 300 

MyAINNModel.AverageIntensityR = 104
MyAINNModel.AverageIntensityG = 117
MyAINNModel.AverageIntensityB = 113
MyAINNModel.RGBColor = True

myMatrixArray is array of 1 array of 1 by 1 by 200 by 7 real

// Run model
myMatrixArray = AIDetectModel(MyAINNModel, MyImage)
```

## Properties


### Properties specific to aiNeuralNetworkModel variables
<a name="properties_specific_aineuralnetworkmodel_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used to handle a neural network model:

| Property name | Type used | Effect |
| --- | --- | --- |
| AverageIntensityB | Integer | Average intensity of the Blue (B) color in the training data. <br><br>This property is optional. |
| AverageIntensityG | Integer | Average intensity of the Green (G) color in the training data. <br><br>This property is optional. |
| AverageIntensityR | Integer | Average intensity of the Red (R) color in the training data. <br><br>This property is optional. |
| Configuration | Character string | Full path of the file that contains the configuration of the model.<br><br>Note: The following configuration types are possible: <br><br>- Caffe: \*.prototxt<br><br>- Tensorflow: \*.pbtxt<br><br>- Darknet: \*.cfg<br><br><br> |
| OutputLayerName | Character string | Name of the output neural network layer. |
| PixelScaleFactor | Real | Used to scale pixel values. Set to 1.0 by default (no scaling). |
| RGBColor | Boolean | <br><br>- <u><u><u>True</u></u></u> if the provided images are encoded in RGB. In this case, the conversion to BGR encoding will be done automatically. <br><br>- <u><u><u>False</u></u></u> (default value) if the provided images are encoded in BGR. <br><br><br><br><br>This property is optional. |
| TrainedWeights | Character string | Full path of the file that contains the trained weights of the model. <br><br>Note: The following weight types are available: <br><br>- Caffe: \*.caffemodel<br><br>- Tensorflow: \*.pb<br><br>- Darknet: \*.weights<br><br>- Open Neural Network Exchange (ONNX): \*.onnx<br><br><br> |
| TransposeRequired | Boolean | <br><br>-  if transposition is required, <br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br><br><br>When to use this property? <br>OpenCV creates matrices based on images and defines them as "Number of columns, Number of rows, Number of channels". <br>Some models expect matrices with the following format: "Number of channels, Number of columns, Number of rows". This means it is necessary to modify the matrix representation of the image created by OpenCV. |
| XDimension | Integer | Image size required by the model: value corresponding to X. <br><br>By default, this property corresponds to the width of the image. |
| YDimension | Integer | Image size required by the model: value corresponding to Y. <br><br>By default, this property corresponds to the height of the image. |
