
## gpwDefault (Function)

***In french: gpwDéfaut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the value corresponding to "DEFAULT" depending on the framework used or the language specified. 

Note: As groupware and groupware files are multilingual, it is possible to retrieve the value of the constant representing the word "DEFAULT".
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sCstDEfauLt is string
sCstDefault = gpwDefault()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = gpwDefault([<Language>])`
---

**`<Result>: (Character string)`**

Value corresponding to "DEFAULT". 

If the &lt;Langue&gt; parameter is not specified, the value returned depends on the framework used: 

- "DEFAULT" if the framework is in English,

- "DEFAUT" if the framework is in French. 




**`<Language>: (Optional constant)`**

Language to be used to obtain the value corresponding to "DEFAULT": 


|   |   |
| --- | --- |
| *languageEnglish* | Value corresponding to "DEFAULT". |
| *languageFrench* | Value corresponding to "DEFAULT" in French: "DEFAUT". |
| *languageSpanish* | Value corresponding to "DEFAULT" in Spanish: "DEFAULT". |
