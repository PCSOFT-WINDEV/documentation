


## GuidedTourInfo (Function)

***In french: VisiteGuidéeInfo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about a Guided Tour.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Affiche la visite guidée uniquement au premier lancement
SI VisiteGuidéeInfo(VisiteDécouverte, vgInfoOccurrence) = 0 ALORS
	VisiteGuidéeDémarre(VisiteDécouverte)
FIN
```

```wl
// Affiche la visite guidée 1 fois par jour max et 5x max
SI VisiteGuidéeInfo(VisiteDécouverte, vgInfoDate) < DateSys() 
		_ET_ VisiteGuidéeInfo(VisiteDécouverte, vgInfoOccurrence) < 5 ALORS
	VisiteGuidéeDémarre(VisiteDécouverte)
FIN
```

```wl
// Affiche les nouveautés d'une version 
VisiteNouveauté est une VisiteGuidée
VisiteNouveauté.Identifiant = "Nouveauté de la version"
VisiteNouveauté.Version = 29
SI VisiteGuidéeInfo(VisiteNouveauté, vgInfoVersion) < 29 ALORS
	VisiteNouveauté.Etape[1].Cible = SAI_Prénom
	VisiteNouveauté.Etape[1].Titre = "Nouveau!"
	VisiteNouveauté.Etape[1].Description = "Vous pouvez maintenant saisir votre prénom"
	VisiteGuidéeDémarre(VisiteNouveauté)
FIN
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GuidedTourInfo(<Guided Tour> , <Information>)`
---

**`<Result>: (Type of information)`**

Requested information. 

**`<Guided Tour>: (String or variable of type GuidedTour)`**

Guided Tour used. This parameter can correspond to: 

- the identifier of the Guided Tour. 

- the name of the [GuidedTour](../WDLang6/1410090170.md) variable.




**`<Information>: (Integer constant)`**

Information sought: 


|   |   |
| --- | --- |
| *gtInfoDate* | Date the Guided Tour was last viewed on the current computer. |
| *gtInfoCount* | Number of times the user has seen the Guided Tour. |
| *gtInfoVersion* | Version number of the last Guided Tour viewed by the user. |

## Remarks

### Resetting the Guided Tour counter to 0 (information provided by the *gtInfoCount* constant)
<a name="resetting_the_guided_tour_counter_0_information_provided_the_gtinfocount_constant_ELTPARAGRAPHE000097"></a>

In WINDEV applications, the Guided Tour counter can be reset to zero using the following code: 

```txt
SauveParamètre("VisiteGuidee\<identifiant_visite>\occurrence",0)
```
where &lt;tour_ID&gt; corresponds to the identifier of the Guided Tour. For example:

```wl
Visite est une VisiteGuidée
Visite.Identifiant = "Visite_20240503_1119"
SauveParamètre("VisiteGuidee\Visite_20240503_1119\occurrence",0)
```
