


## &lt;GuidedTour&gt;.Stop (Function)

***In french: &lt;VisiteGuidée&gt;.Arrête***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops the specified Guided Tour.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyGetStartedTour is GuidedTour
// ...
// Start Guided Tour
MyGetStartedTour.Start()
// ...
// Stops the MyGetStartedTour
MyGetStartedTour.Stop()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Guided Tour>.Stop()`
---

**`<Guided Tour>: (GuidedTour variable)`**

Name of the [GuidedTour](../WDLang6/1410090170.md) variable that corresponds to the Guided Tour to be stopped.
