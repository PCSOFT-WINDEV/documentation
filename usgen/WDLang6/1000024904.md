


## pdfPage (Variable type)

***In french: pdfPage***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **pdfPage** type is used to define all the advanced characteristics of a page from a PDF document loaded in memory. You can define and change the characteristics of this page using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPDF is pdfDocument = "test.pdf"
FOR EACH DocumentPage OF MyPDF.Page
	Trace(DocumentPage.Height)
END
PDFSave(MyPDF, "passwordtest.pdf")
// It is also possible to use prefix syntax
// MyPDF.Save("passwordtest.pdf")
```

```wl
PDFFile is pdfDocument = PDFOpen(fDataDir + fSep + "MYPDF.pdf")
APage is pdfPage
// Adds an image to a page
APage = PDFFile.Page[1]
APage.AddImage(fDataDir + fSep + "MYIMAGE.jpg", 0, 0, APage.Width, APage.Height)
// Displays the PDF document in a PDF Reader control
PDF_NoName1 = PDFFile
```

```wl
MyPDFDoc is pdfDocument = PDFOpen("C:\temp\Myguide.pdf")
Trace(MyPDFDoc.PDFVersion)
Trace(MyPDFDoc.Author)
Trace(MyPDFDoc.Page.Count)
Trace(MyPDFDoc.Page[1].Width)
Trace(MyPDFDoc.Page[36].Height)
FOR EACH ATextElement OF MyPDFDoc.Page[2].TextElement
	Trace(ATextElement.Text + " X = " + 
	ATextElement.X + " Y = " + ATextElement.Y + " L = " + 
	ATextElement.Width + " H = " + ATextElement.Height)
END
MyPDFDoc2 is PDFDocument = "C:\temp\plan.pdf"
// Add pages
Add(MyPDFDoc2.Page, MyPDFDoc.Page[5])
// Insert pages
Insert(MyPDFDoc2.Page, 1, MyPDFDoc.Page[32])
// Save modified PDF
PDFSave(MyPDFDoc2, "MyPDFDoc2.pdf")
ShellExecute("MyPDFDoc2.pdf")
```

## Properties


### Properties specific to pdfPage variables
<a name="properties_specific_pdfpage_variables_ELTPARAGRAPHE000051"></a>

The following properties can be used to handle a page of a PDF document:

| Property name | Type used | Effect |
| --- | --- | --- |
| Control | Array of [pdfControl](../WDLang6/1410090536.md) | Characteristics of controls in a PDF form. <br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **This property is not available**. |
| Height | Real | Page height in millimeters. <br><br>If this height is changed, the page is automatically resized and the elements are repositioned. <br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **This property is read-only**. |
| Orientation | String constant | Allows you to view and change the page orientation: <br><br>- *Orient0*: Default orientation.<br><br>- *Orient90*: Page rotation angle set to 90°.<br><br>- *Orient180*: Page rotation angle set to 180°.<br><br>- *Orient270*: Page rotation angle set to 270°.<br><br><br> |
| TextElement | Array of [pdfTextElement](../WDLang6/1000024556.md) | Information about the text in the page. |
| Width | Real | Page width in millimeters. <br><br>If this width is changed, the page is automatically resized and the elements are repositioned. <br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **This property is read-only**. |
