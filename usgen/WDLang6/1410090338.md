


## &lt;pdfDocument variable&gt;.ExtractPage (Function)

***In french: &lt;Variable pdfDocument&gt;.ExtraitPage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extracts a page from a PDF file in a variable of type [Image](../WDLang1/1000019650.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Extracts page 3 from the text.pdf file
MyPDF is pdfDocument = PDFOpen("test.pdf")
MyImage is Image = MyPDF.ExtractPage(3)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE2"></a>

`<Result> = <PDF document>.ExtractPage(<Page number> [, <Width> [, <Height> [, <Password>]]])`
---

**`<Result>: (Image (image variable))`**

[Image](../WDLang1/1000019650.md) variable that contains the image of the extracted page. The returned image is a raster image.

Note: If the PDF or the page does not exist, the [Image](../WDLang1/1000019650.md) variable returned will be invalid. The [ErrorOccurred](../WDLang1/3087001.md) variable will be set to <u><u><u><u>True</u></u></u></u>.

**`<PDF document>: (pdfDocument variable)`**

Name of the [pdfDocument](../WDLang6/1000024909.md) variable that corresponds to the PDF document to be used.

**`<Page number>: (Integer)`**

Number of the page to be extracted.

**`<Width>: (Optional integer)`**

Width at which the page is to be rasterized. 
If this parameter is not specified (or is set to 0), the height and width will be calculated from the page size (in millimeters), using a DPI of 300.

**`<Height>: (Optional integer)`**

Height at which the page is to be rasterized. 
If this parameter is not specified (or is set to 0), the height and width will be calculated from the page size (in millimeters), using a DPI of 300.

**`<Password>: (Optional string or Secret string)`**

Password of the PDF document.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications.
