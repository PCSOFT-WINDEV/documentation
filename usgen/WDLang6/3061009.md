
## BurnerList (Function)

***In french: GraveurListe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of burners installed on the current computer.

**Remarks**: 

- [BurnerSelect](../WDLang6/3061012.md) is used to select the default burner.

- [BurnerPath](../WDLang6/3061004.md) is used to find out the drive associated with the current burner.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003061009&name=burnerlist_function">See additional examples</a>

```wl
// Find out the burners installed
ListBurner is string
ListBurner = BurnerList()
IF ListBurner ~= "" THEN
	Error("No burner was detected on the computer")
	RETURN
END
// To view the entire example, click the "Examples" link
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = BurnerList([<Details>])`
---

**`<Result>: (Character string)`**

List of burners installed on the current computer, in the following format:

- **detailed list (if the &lt;Details&gt; parameter corresponds to <u><u><u><u>True</u></u></u></u>)**:
	
	```txt
	<Identifier of Burner 1> + TAB + <Make of Burner 1> + TAB + 
	<Model of Burner 1> + TAB + <Firmware of Burner 1> + CR + ...
	<Identifier of Burner N> + TAB + <Make of Burner N> + TAB + 
	<Model of Burner N> + TAB + <Firmware of Burner N>
	```


- **non-detailed list (if the &lt;Details&gt; parameter corresponds to <u><u><u><u>False</u></u></u></u>**):
	
	```txt
	<Recorder identifier 1> + CR + ... + <Recorder identifier N>
	```



Where: 

- &lt;Identifier of Burner 1&gt; ... &lt;Identifier of Burner N&gt; correspond to the identifier of the burners.

- &lt;Brand of Burner 1&gt; ... &lt;Brand of Burner N&gt; correspond to the brand of the burners.

- &lt;Model of Burner 1&gt; ... &lt;Model of Burner N&gt; correspond to the model of the burners.

- &lt;Logiciel intégré du graveur 1&gt;... &lt;Logiciel intégré du graveur N&gt; correspond to the version of the burners' embedded software (also known as "firmware").




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The current computer corresponds to the Web server.

**`<Details>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> to list the detailed information about the burners, 

- <u><u><u><u>False</u></u></u></u> (by default) to list the identifiers of the burners.

## Remarks




### Required configuration 
<a name="required_configuration_ELTPARAGRAPHE000075"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Burning CDs is available for Windows XP and later. Burning DVDs is available for Windows Vista and for Windows XP when using the KB932716 update for Windows XP (this update must be downloaded from the Microsoft site and installed manually because it is not taken into account by the Live Update mechanism).   
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The CDs and the DVDs will be burned on the Web server. To burn CDs or DVDs, the server must be running Windows XP or later. To burn CDs in Windows 2003 Server, the IMAPI burn service (named "IMAPI CD-burning COM service") must be enabled. To burn DVDs in Windows 2003 Server, you also have to install the KB932716 update.
