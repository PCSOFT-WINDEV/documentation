


## PaletteGet (Function)

***In french: PaletteRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the palette currently used by the project or window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPalette is Palette = PaletteGet()
STC_Problem.BackgroundColor = MyPalette["caution"]
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PaletteGet([<Window>])`
---

**`<Result>: (Palette variable)`**

[Palette](../WDLang1/1000021347.md) variable containing the palette of the specified window or project. 

**`<Window>: (Optional window name)`**

Name of the window whose palette is to be retrieved. If this parameter is not specified, the palette of the current project will be retrieved.
