


## &lt;pdfDocument variable&gt;.ToText (Function)

***In french: &lt;Variable pdfDocument&gt;.VersTexte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extracts text from a PDF file.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPDF is pdfDocument = PDFOpen("test.pdf")
MyString = MyPDF.ToText("1-2")
// Display text in a multiline Edit control
EDT_EditMultiText = MyString
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE2"></a>

## Syntax

`<Result> = <PDF document>.ToText([<Pages to extract>])`
---

**`<Result>: (Character string)`**

Text of the PDF file.

**`<PDF document>: (pdfDocument variable)`**

Name of the [pdfDocument](../WDLang6/1000024909.md) variable to be used.

**`<Pages to extract>: (Optional character string)`**

Range of pages from which the text will be extracted. Pages are selected in a window with the same range boxes as a standard print window. Use semicolons to separate individual pages or ranges. For example, "1;3;4;6-10;12" means that the text of pages 1, 3, 4, 6 to 10, and 12 will be extracted.

If this parameter is not specified or is an empty string (""), all pages are extracted.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Converting PDF to text
<a name="converting_pdf_text_ELTPARAGRAPHE000212"></a>

- When converting a PDF to text, the document formatting is lost.

- Text is extracted in the order in which the PDF commands appear and is written sequentially in the resulting string. Text blocks and paragraphs are preserved (as well as carriage returns).  

- Unicode characters are not returned.

- Data from a PDF form is not extracted (this data is not stored in the PDF file).



<a name="NOTE0_2"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000225"></a>

- [PDFIsProtected](../WDLang6/1000017491.md) is used to know if a password is required to open a PDF file.

- [PDFNumberOfPages](../WDLang6/1000017480.md) returns the total number of pages in a PDF file.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Starting with version 28, this function is supported by 32-bit ARM processors only if the *pvtCompatible* constant is used. New PDF features require a 64-bit execution mode.
	If an application is to be run on devices with 32-bit ARM processors, it must be generated with WINDEV Mobile 27.
