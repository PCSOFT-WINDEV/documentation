


## &lt;pdfDocument variable&gt;.GetSignatureDate (Function)

***In french: &lt;Variable pdfDocument&gt;.RécupèreDateSignature***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the date of one of the signatures of a PDF document.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPDF is pdfDocument = PDFOpen("test.pdf")

// Number of signatures in the PDF file
nNbSignatures is int = MyPDF.NbSignatures()

// Get signature details
POUR i = 1 _TO_ nNbSignatures
	// Get signature
	bufSignature is Buffer = MyPDF.GetSignature(i)
	
	// Get signature date
	dtSignatureDate is DateTime = MyPDF.GetSignatureDate(i)

	// Get certificate
	Certif is Certificate = CertificateExtract(bufSignature)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PDFGetSignatureDate(<PDF document> , <Index>)`
---

**`<Result>: (DateTime)`**

Date of the signature.

**`<PDF document>: (pdfDocument variable)`**

[pdfDocument](../WDLang6/1000024909.md) variable corresponding to the PDF document to be analyzed. 

**`<Index>: (Integer)`**

Index of the signature in the document (the number of signatures is returned by [&lt;pdfDocument variable&gt;.NbSignatures](../WDLang6/1410088154.md)).
