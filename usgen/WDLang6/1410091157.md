
## PDFControlInfoXY (Function)

***In french: PDFChampInfoXY***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the characteristics of an interactive control currently hovered over in a PDF Reader control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get page and mouse position in mm from PDF document
page_num is int = PDFReaderInfoXY(MySelf, pdfPageNumber, MouseXPos(), MouseYPos())
X is real = PDFReaderInfoXY(MySelf, pdfXCoord, MouseXPos(), MouseYPos())
Y is real = PDFReaderInfoXY(MySelf, pdfYCoord, MouseXPos(), MouseYPos())
// If the pointer is outside the document
IF page_num = -1 THEN
	Info("No page at this position")
	RETURN
END
// Get the control at the found position
pdf_doc is pdfDocument = MySelf
form_control is pdfControl = PDFControlInfoXY(pdf_doc.Page[page_num], X, Y)
IF form_control.Name = "" THEN
	Info("No controls at this position")
ELSE
	Info(form_control.Name + " = " + form_control.Value)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PDFControlInfoXY(<Page> , <X> , <Y>)`
---

**`<Result>: (pdfControl variable)`**

[pdfControl](../WDLang6/1410090536.md) variable containing the characteristics of the hovered control, including its name, coordinates, width, height, value, etc. 

**`<Page>: (pdfPage variable)`**

Name of the [pdfPage](../WDLang6/1000024904.md) variable corresponding to the page containing the control. 

**`<X>: (Real)`**

X-coordinate (in millimeters) to be analyzed. This coordinate is relative to the control.

**`<Y>: (Real)`**

Y-coordinate (in millimeters) to be analyzed. This coordinate is relative to the control.
