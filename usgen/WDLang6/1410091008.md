
## Palette functions (prefix syntax)

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate palettes in prefix syntax: 




|   |   |
| --- | --- |
| [&lt;Palette variable&gt;.Generate](../WDLang6/1410091001.md) | Generates a palette from a base color. |
| [&lt;Palette variable&gt;.Load](../WDLang6/1410091000.md) | Loads a palette from a .wdpalette file. |
| [&lt;Palette variable&gt;.Save](../WDLang6/1410091002.md) | Saves a palette to a file. |
| [&lt;Window&gt;.PaletteGet](../WDLang6/1410091003.md) | Gets the palette currently used by the window. |
