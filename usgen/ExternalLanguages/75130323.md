
## WDEnd (External language)

***In french: WDTermine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ends a program that uses WINDEV.
Note: **WDTermine** is mandatory in all WINDEV programs.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// En C
WDTermine();
```


<a name="Exemple2"></a>



```txt
// En Pascal
WDTermine;
```


<a name="Exemple3"></a>





```txt
// En VB
call WDTermine
```

<a name="SYNTAXE1"></a>

## Syntax

`WDEnd()`
