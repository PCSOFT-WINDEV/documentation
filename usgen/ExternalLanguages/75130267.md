
## Screen,Next (External language)

***In french: Ecran,Suivant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the next editable control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
CALLWD("Screen,Next");
strcpy(ControlName,WdName);
Subscript=WDSubscript;
```


<a name="Exemple2"></a>



```txt
// In Pascal
CALLWD('Screen,Next');
ControlName:=WdName;
Subscript:=WDSubscript;
```


<a name="Exemple3"></a>



```txt
// In VB
call CALLWD("Screen,Next")
ControlName=WdName
Subscript=WdSubscript
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Screen,Next()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The name of the control is returned in WdName.

- For an indexed control, WdIndex contains the subscript of the control.
