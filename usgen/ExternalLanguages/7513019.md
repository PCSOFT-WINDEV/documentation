
## nWDGetHFContext: Get HFSQL context
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Use
<a name="use_ELTTEXTE000066"></a>
Gets the HFSQL context (applies to C, Pascal and Visual Basic only). This function is used in the initialization code of a project that uses an HFSQL analysis.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Syntax
<a name="syntax_ELTTEXTE000090"></a>

```wl
Int      nWDGetHFContext(void** ppHFContext);
```
