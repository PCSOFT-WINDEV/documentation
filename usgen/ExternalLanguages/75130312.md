
## Table,Save (External language)

***In french: Table,Enregistre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Updates or adds a record in the data file linked to the Table control.

**Note**: This function should only be used with Table based on a data file fields.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
CALLWD("Table,Save,ProdTable");
```


<a name="Exemple2"></a>



```txt
// In Pascal
CALLWD('Table,Save,ProdTable');
```


<a name="Exemple3"></a>



```txt
// In VB
call CALLWD("Table,Save,ProdTable")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Table,Save(<Table control>)`
---

**`<Table control>: (Control name)`**

Name of the Table control based on a data file to be used.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **Table,Save** updates the variables of the data file items with the values from the controls in the current row of the Table control. The record is written to the data file.

- **Table, Save** does not manage the items in linked files. HAdd or HModify must be used to write into the linked file.

- To modify the data file linked directly to a Table field, don't use the HAdd (or HModify) function: use [Table,Add](../LangageExt/75130309.md), [Table,Insert](../LangageExt/75130313.md) or [Table,Modify](../LangageExt/75130314.md) and [Table,Save](../LangageExt/75130312.md).
