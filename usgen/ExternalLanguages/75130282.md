
## LCommand (External language)

***In french: LCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the command line passed as parameter to the executable program. WdString contains the command line passed as parameter to the executable program (without the name of the executable itself).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
CALLWD("LCommand");
strcpy(CommandLine,WDSTRING)
```


<a name="Exemple2"></a>



```txt
// In Pascal
CALLWD('LCommand');
CommandLine=WdString;
```


<a name="Exemple3"></a>



```txt
// In VB
call CALLWD("LCommand")
CommandLine=WdString
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`LCommand()`
