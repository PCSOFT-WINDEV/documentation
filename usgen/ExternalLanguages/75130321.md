
## Test (External language)

***In french: Test***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays each function call and each status report returned by the function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// En C
APPELWD("Test,Oui");
```


<a name="Exemple2"></a>



```txt
// En Pascal
APPELWD('Test,Oui');
```


<a name="Exemple3"></a>



```txt
// En VB
call APPELWD("Test,Oui")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Test(<Indicator>)`
---

**`<Indicator>: (Character string)`**

 Can be set to:

- "yes" to switch to test mode

- "no" to inhibit the test mode.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To execute the next function, press a key.

- To cancel the test mode, all you have to do is press the Esc key (equivalent to Option,Test,No).
