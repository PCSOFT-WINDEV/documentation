
## Screen,Input (External language)

***In french: Ecran,Saisie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts the input in the controls of a window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
while (strcmp(Key,"ESC")!=0) {
	CALLWD("Screen,Input");
	strcpy(Key, WDKey);
```


<a name="Exemple2"></a>





```txt
// In Pascal
While Key<>'ESC' DO
Begin
	CALLWD('Screen,Input');
	Key:=WDKey;
	...
End;
```


<a name="Exemple3"></a>



```txt
// In VB
While Key<>"ESC"
	call CALLWD("Screen,Input")
	Key=WdKey
	...
WEnd
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Screen,Input(</CR> , </NONLOCKING>)`
---

**`</CR>: ()`**

Enables you to detect whether an error occurred. If this parameter is specified, WdKey contains "\*E\*" if an error occurred.

**`</NONLOCKING>: ()`**

Allows you to immediately exit from the input without necessarily waiting for a result. If this parameter is specified: "\*N\*" is returned in WdTouche if no action has been taken.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- At the end of input, the WdKey variable contains the status report of the input modified in WLanguage by ReturnWdKey or WdKey=&lt;Key Code&gt;.

- At the end of menu input, the WdKey variable contains "\*M\*" and WdString contains the sequence of shortcuts for the selected options.
