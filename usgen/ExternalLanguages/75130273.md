
## Close (External language)

***In french: Ferme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the current window and restores the context that existed before the window was opened.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
CALLWD("Close");
```


<a name="Exemple2"></a>





```txt
// In Pascal
CALLWD('Close');
```


<a name="Exemple3"></a>





```txt
// In VB
call CALLWD("Close")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Close()`
