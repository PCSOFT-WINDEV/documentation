


## Software Factory administrator options
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000188"></a>
Several options can be configured in the Software Factory administrator: 

- [Authentication](#NOTE2_1).

- [Coordinator](#NOTE3_1).

- [Robots](#NOTE4_1).

- [Other options](#NOTE5_1): 

	- Environment variables.

	- Software Factory permissions.
			

	- Dialog boxes. 







To configure these options: 

1. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens. 

4. Click the "Options" tab to configure the Software Factory administrator.

## Authentication - Parameters of Control Centers
<a name="authentication_parameters_control_centers_ELTTEXTE000221"></a>
The authentication parameters are used to define the database for the accounts used by the Software Factory. The Software Factory uses the accounts of the Control Centers. You must specify the options for connecting to this database. This database can be: 

- a local database in shared mode. Simply specify the share directory containing the tables of the Control Center database. 

- an HFSQL Client/Server database. Simply specify the server, port and database used. 
	Note: Click "Test" to check the parameters entered. 

- a Cloud platform. Simply specify the name of the platform used. 
	Note: You can directly create a Cloud platform, if necessary.
	**PCSCloud** is a paid, turnkey solution. For more details, see [PCSCloud](https://pcscloud.net/UK/cloud_development.awp). 

- an SCM Drive platform. Simply enter the name of the account used. 
	Note: You can directly create a PCSCloud account, if necessary.
	 **SCMDrive** is a paid, turnkey solution. For more details, see [SCMDrive](https://pcscloud-drive.net/UK/SCMDrive/index.awp). 


The option "Request password at startup" is used to force the user authentication when the Software Factory administrator starts.

## Coordinator
<a name="coordinator_ELTTEXTE000245"></a>
Configuring the coordinator allows you to: 

- Choose the coordinator.

- Define the coordinator options ("Coordinator options" link). 




The coordinator options affect: 

- The database of Control Centers used to store the action plans and store their status reports. 

- The results history settings. You can define the number of results stored for each action plan. 

- The method used for sending the action plan status reports (Control Centers messaging solution, email, etc.). 

- The recipients in case of robot failure.

## Robots
<a name="robots_ELTTEXTE000269"></a>
The **Change priority order of robots** option allows you to define the order in which to use the computers that run the action plans. 

When several computers are available, you have the ability to select a specific computer to run the action plans (the fastest computer for example). 
Reminder: You can add robots in the "Robots" tab of the Software Factory administrator.

## Other options
<a name="other_options_ELTTEXTE000293"></a>
The following options are also available:

- **Edit the list of environment variables**: This option lists the environment variables that can be used in action plans. For example, these variables may correspond to an internal version number, release version, etc. Updating these variables will have an impact on all action plans that use them. The change will be taken into account the next time the action plan is run. 

- Software Factory rights: This option allows an administrator (defined in the Control Center database) to define user rights for the Software Factory. For more details, see [Rights management](../Editeurs/1000019594.md). 
	

- **"Don't show again" dialog boxes**: This option allows you to re-enable previously disabled dialog boxes (e.g., by checking the "Don't show again" option).
