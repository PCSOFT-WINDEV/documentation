


## SCM Administrator: Administrator-only options
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000252"></a>
The SCM administrator includes specific tools for managing repositories. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0001.gif)


Administration tools are available only when you log in to the SCM repository as an administrator. 

To log in as an administrator:

1. On the "Home" tab, in the "Repository" group, click "Connection ". 

2. In the window that appears:

	- Specify the characteristics of the repository.

	- Specify the name and password of the repository administrator:

		- If you use an SCM repository in HFSQL Classic format, the username is set to "Admin" by default (without password).

		- If you use an SCM repository in HFSQL Client/Server format, the user is defined "Administrator" by default.







**Note**: Logging in to the repository as an administrator is not the same as "Becoming master on the project". To perform administration tasks, you need to be logged in as administrator.

## Administration options
<a name="administration_options_ELTTEXTE000276"></a>


### Authentication settings
<a name="authentication_settings_ELTPARAGRAPHE000047"></a>

In the authentication settings, you can use the Control Center database to authenticate SCM users. Login credentials are those specified in the Project Management Hub.

This option is available only if you are working with an SCM repository in HFSQL Classic format.

To enable authentication:

1. On the "Administration" tab, in the "Security" group, click "Authentication settings".

2. Check "Enable authentication".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0002.gif)


3. Specify the Control Center database (in HFSQL Classic format).

4. Confirm. 



<a name="NOTE3_4"></a>


### Canceling check-outs
<a name="canceling_checkouts_ELTPARAGRAPHE000076"></a>

The administrator can cancel all ongoing check-outs in the selected project. To do so, go to the "Administration" tab, "Check-outs" group and click "Undo check-outs".

A window lists all checked-out elements. You can also list elements checked out for testing or elements checked out in a different remote directory.

Simply select the desired elements and click "Undo check-out". The check-out is undone. In the repository, the element is kept in the state it was before the check-out.

You can let users know if their checkouts were undone ("Notify users whose checkout was undone").
<a name="NOTE3_5"></a>


### Repository backup
<a name="repository_backup_ELTPARAGRAPHE000101"></a>

The administrator can make a backup copy of the SCM repository. To do so, go to the "Administration" tab, "Backups" group and click "Full backup". This backup copy is saved to a .ZIP file. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0003.gif)
**Remarks**:

- During the backup, the SCM repository is read-only.

- A single zip file is created for the backup. 
	




You can also back up the repository in command line mode using the following notation:


```txt
WDGDSAdmin.exe /SAVE 
		/BASE=<Repository address> 
		/LOGIN=<Login> 
		/PASS=<Password> 
		/ZIP=<Full name of zip file>
```
In this code, &lt;Repository address&gt; has the following format: 

- HFSQL Client/Server: "CS:\\\\&lt;Server IP address&gt;:&lt;Server port&gt;\\&lt;SCM repository name&gt;"

- HFSQL Classic: The local path of the repository must be specified. For example: "D:\\PC SOFT\\Local SCM repository\\"




Example: 


```wl
ExeRun("""C:\WINDEV\Programs\WDGDSAdmin.exe"" /SAVE /BASE=CS:\\DOC2:4900\GDS " + ...
		" /LOGIN=admin /PASS=admin /ZIP=C:\Temp\test.zip")
```

<a name="NOTE3_6"></a>


### Saving and clearing the history
<a name="saving_and_clearing_the_history_ELTPARAGRAPHE000141"></a>

The administrator has the ability to delete part of the history from the SCM repository. To do so, go to Administration" tab, "Backups" group and click "Clear history with backup". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0004.gif)
The deleted part is automatically saved in a .ZIP file. This backup can then be restored.

To save and clear the history, specify the date from which the history must be stored.

Note: A single zip file is created for the backup. 
<a name="NOTE3_7"></a>


### Restoring a full backup
<a name="restoring_full_backup_ELTPARAGRAPHE000170"></a>

To restore a full backup of the repository, on the "Administration" tab, in the "Backups" group, click "Full restore". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0005.gif&type=thumb)

<a name="NOTE3_8"></a>


### Restoring a history backup
<a name="restoring_history_backup_ELTPARAGRAPHE000190"></a>

To restore a backup of the repository history, on the "Administration" tab, in the "Backups" group, click"Restore history". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Admin_Admin%20-%20HC%20N%B0006.gif&type=thumb)
