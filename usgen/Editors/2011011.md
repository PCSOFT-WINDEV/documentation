


## Project database schema: the Logical Data Model (LDM)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000150"></a>
An LDM (Logical Data Model) describes the data structures (tables, fields, etc.) used in a WINDEV, WEBDEV or WINDEV Mobile application. This Logical Data Model is called a "Database Schema" in WINDEV, WEBDEV or WINDEV Mobile, and can be created and edited via the database schema data model editor. 

**Remarks**:

- The terms "MLD" and "Analyse" are used interchangeably to define the database structure associated with a project.

- For details of how to manipulate a database schema (MLD), see [Manipulating a database schema (LDM)](../Editeurs/2011006.md).

## Creating a database schema (LDM)
<a name="creating_database_schema_ldm_ELTTEXTE000174"></a>
To create a database schema (LDM):

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

	- In the window that appears, click "Table", then "Database Schema".

	- The database schema creation wizard opens.




2. In the first step of the wizard, indicate:

	- the ***database schema name and directory***. The database schema corresponds to a ".WDA" file. By default, this table will be created in the directory of the project database schema (&lt;Project name&gt;.ANA directory). This directory must be accessible in read/write mode.

	- whether the database schema must be associated with the current project instead of the current database schema (when creating a database schema in a project already associated with a database schema). 

	- the ***database schema description*** that briefly describes the subject of the database schema. 




3. The next step of wizard is to specify the type of database the project will use: 

	- HFSQLDrive (paid solution). For more details on HFSQLDrive, see [HFSQLDrive, your database in the Cloud in 3 clicks](https://pcscloud-drive.net/UK/HFSQLDrive/index.awp).

	- PCSCloud (paid solution). For more details on PCSCloud, see [Cloud for HFSQL databases](https://pcscloud.net/UK/cloud_applications.awp).

	- HFSQL Client/Server,

	- HFSQL Classic, 

	- External databases: SQL Server, Oracle, MySQL, etc.
			Note: If the database schema is to handle an external database, the corresponding native connector must be installed on the seat. 




4. For any database other than HFSQL Classic, the wizard allows you to define the connection to the database (name, caption) and specify advanced settings (server, user and password). This information can be edited later in the data model editor.

5. Confirm. The created database schema becomes the current database schema.

6. Create all the elements of the database schema (tables, items and links).
	**Note** For more details, see [Database schema tables](../Editeurs/2011010.md), [Items of a table](../Editeurs/2011009.md) and [Database schema links](../Editeurs/2011008.md).

7. To use the database schema in your project, generate the database schema: under the "Database schema" pane, in the "Database schema" group, pull down "Generation" and select "Generate". For more details, see [Generating a database schema](../Editeurs/2011012.md).
