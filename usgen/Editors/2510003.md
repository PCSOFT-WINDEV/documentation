
## SCM: Local history
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000145"></a>
By saving an element to the local history, you set a local save point. This makes it possible to:

- return to this save point.

- decide whether or not to check this save point back into the repository. 




When an element is saved to the local history, no data is checked back into the SCM. 



**Note**: If a check-in policy has been defined, elements can only be saved to the local history if they comply with the policy. For more details, see [Check-in policy](../Editeurs/2038024.md).

## Saving an element to the local history
<a name="saving_element_the_local_history_ELTTEXTE000178"></a>


### Implementation
<a name="implementation_ELTPARAGRAPHE000028"></a>

To save an element to the local history, go to the "SCM" tab, "Current element" group, expand "Check in", and select "Save to local history".

When saving an element to the local history, the following window appears:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Int%E9gration%20dans%20le%20GDS%20-%20HC%20N%B0010.gif)


This window includes different tabs where you can specify the check-in details:

- The "Tasks" tab, where you can indicate whether the element in the history corresponds to the execution or completion of a task.

- The "Incidents" tab, where you can indicate if the checked-in element fixes an incident.

- The "Comment" tab, where you can enter a check-in comment. For example, you can indicate that the window proposes a new menu option. 
	The "AI: Generate comment" button automatically generates a comment based on changes made in the code. For more details, see [AI in the code editor](../Editeurs/9000219.md). 




This window also allows you to: 

- View the changes made to the element ("My changes" button).

- View the properties of the element ("Properties" button).



<a name="NOTE2_2"></a>


### Retrieving a version from the local history
<a name="retrieving_version_from_the_local_history_ELTPARAGRAPHE000062"></a>

You can retrieve a local version of an element directly from the history window. 

1. On the "SCM" tab, in the "Current element" group, click "History". 

2. In the window that appears, you can retrieve a locally saved version. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Int%E9gration%20dans%20le%20GDS%20-%20HC%20N%B0011.gif)




<a name="NOTE2_3"></a>


### Checking an element from the local history into the SCM
<a name="checking_element_from_the_local_history_into_the_scm_ELTPARAGRAPHE000081"></a>

To check an element from the local history into the SCM, go to the "SCM" tab, "Current element" group, and click "Check in".

In this case, the check-in window shows the number of local versions and shows a specific option: "Squash local versions". If this option is enabled, the details of the local versions will be ignored in the history of the element that is checked into the SCM.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Int%E9gration%20dans%20le%20GDS%20-%20HC%20N%B0012.gif)
