


## Result of a query in test mode
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000146"></a>
After its execution in test mode (see [Query test](../Editeurs/2019011.md)), the result of the query can be: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Requete_ResultatTestRequete.gif)


- exported to a text file (Word or Open Office).

- exported to an XML file.

- exported to a spreadsheet file (Excel or Open Office).

- exported to an HFSQL table.

- printed.




A record found in the query result can also be copied to the clipboard.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Exporting the result to a text file
<a name="exporting_the_result_text_file_ELTTEXTE000170"></a>
For the next operation, we consider that the query result is displayed.

To export the query result to a text file:

1. Display the context menu (right-click) for the query result.

2. Select the option "Other automated features (FAA) .. Export table to Word" (or the option "Export table to OpenOffice.org Writer"). The window for selecting the "RTF" file is displayed.

3. Specify the name and location of the "RTF" file.

4. Validate. The records found in the query result are automatically exported to the "RTF" file.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Requete_ExporterFichierText.gif)

## Exporting the result to an XML file
<a name="exporting_the_result_xml_file_ELTTEXTE000194"></a>
For the next operation, we consider that the query result is displayed.

To export the query result to an XML file:

1. Display the context menu (right-click) for the query result.

2. Select the "Other automatic features (FAA) .. Export table to XML" option. The window for selecting the XML file is displayed.

3. Specify the name and location of the XML file.

4. Validate. The records found in the query result are automatically exported to the XML file.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Requete_ExporterFichierXML.gif)

## Exporting the result to an HFSQL table
<a name="exporting_the_result_hfsql_table_ELTTEXTE000242"></a>
For the next operation, we consider that the query result is displayed.

To export the query result to an HFSQL table:

1. Click on the "Export to HFSQL table" button or select the "Export to HFSQL table" option in the context menu (right-click) of the query result. The HFSQL table selection window appears.

2. Specify the name and location of the HFSQL table.

3. Validate. The records found in the query result are automatically exported to the HFSQL table. The result can be viewed with WDMap for example.

<a name="NOTE6_1"></a>


## Printing the result
<a name="printing_the_result_ELTTEXTE000266"></a>
For the next operation, we consider that the query result is displayed.

To print the query result:

1. Select "Print" in the context menu (right click) of the query result or click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_imprimer.gif). The window for selecting the items to print is displayed.

2. Indicate the items to print and validate. 

3. A print preview showing the query result is displayed.
