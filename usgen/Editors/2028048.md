


## WEBDEV site deployment: automatic modification of tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000095"></a>
The automatic modification of the tables allows updating the description of tables on the Web server.

For more details, see [Automatic table modification](../WDLang4/3044195.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Configuring the automatic data modification
<a name="configuring_the_automatic_data_modification_ELTTEXTE000119"></a><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=D%E9ploiement%20-%20HC%20N%B0005.gif&type=thumb)
To perform the automatic modification of tables:

- in HFSQL Classic format, check the "Include automatic modification of tables in installation" option and check the database schema associated with the site.

- in HFSQL Client/Server format, check "Perform the modification of the HFSQL Client/Server tables". The "Connections" button is used to describe the parameters of the relevant HFSQL Client/Server connections.

- in Hyper File 5.5 format to HFSQL Classic, check "Perform the automatic modification of the Hyper File 5.5 tables and the conversion to HFSQL Classic".



<a name="NOTE2_2"></a>


### Managing the passwords for the HFSQL Classic tables
<a name="managing_the_passwords_for_the_hfsql_classic_tables_ELTPARAGRAPHE000033"></a>

If your HFSQL Classic tables are password-protected, click on the "Set table passwords" link.

For each table of database schema, specify if necessary:

- table password (if any) in HFSQL Classic database schema format. 
	**Note**: To change this password, select "Change password" and enter the new password.

- if the site uses a migrated Hyper File 5.5 database schema:

	- the source database schema in Hyper File 5.5 format (".WDA" file).

	- the name of the table in Hyper File 5.5 format.

	- the password of the table (if any) in Hyper File 5.5 format.







**Note**: All information except passwords is automatically displayed.
