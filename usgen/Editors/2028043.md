## Overview
<a name="overview_ELTTEXTE000120"></a>
The automatic table modification updates the description of tables on user computers.

For more details, see [Automatic table modification](../WDLang4/3044195.md).

## Configuring the automatic data modification with the wizard
<a name="configuring_the_automatic_data_modification_with_the_wizard_ELTTEXTE000144"></a>
To configure the automatic data modification with the wizard, select the application (.exe file) for which you want to run the modification.

If the tables are password-protected, or if they are in an HFSQL Client/Server database, you will need to specify the passwords:

1. Click the "Advanced" button.

2. Select the database schema in WINDEV format (".WDD" file) associated with the application.

3. If necessary, specify the following for each table in the database schema:

	- the password of the file (if any) in the database schema. 
			**Note**: To change this password, select "Change password" and enter the new password.

	- if the application uses a WINDEV 5.5 database schema that was migrated, specify:

		- the source database schema in WINDEV 5.5 format (".WDA" file).

		- the name of the table in the database schema in WINDEV 5.5 format.

		- the file password (if it exists) in the database schema in WINDEV 5.5 format.







This information (except for the passwords) is automatically displayed.

**Remarks**:

- During the update, the tables automatically found are:

	- the files found in the installation directory of the application.

	- the files listed in the ".REP" file. For more details, see the help about the [management of .REP files](../WDLang4/3044186.md).




- The wizard suggests running a "silent" automatic data modification. In this case, no configuration window will be shown to the end user. 

- To allow the user to configure the automatic modification, you can use WDInst to include the "Advanced options" button in the setup program.
