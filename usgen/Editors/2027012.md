


## The "Database schema" pane

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000126"></a>
The "Database schema" pane shows:

- the tables and items in the current database schema. Keys are bold and unique keys are both bold and underlined. 

- the stored procedures, stored queries and triggers in the current database schema.

- the SQL views and materialized views in the current database schema.

- the connections described in the current database schema.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=VoletAnalyse.gif&type=thumb)
The context menu (right click) of the "database schema" pane is used to:

- Open the database schema.

- Create: 

	- a table.

	- an SQL or materialized view.

	- a Custom-Folder. For more details, see [Custom-Folders in the database schema](../Editeurs/2011003.md).

	- a set of stored procedures. 

	- a stored query.

	- a trigger.

	- an enumeration.

	- a combination.




- Show the database schema description. 

- Show table descriptions.

- View table descriptions.

- Manage connections. 

- Generate the database schema.

- Print the database schema documentation.




**Note**: The information displayed corresponds to the current database schema in the table model editor. This information can differ from the one displayed in the ["Project explorer" pane](../Editeurs/2027029.md) (that displays the information of the last generated database schema).

## Displaying the "database schema" pane
<a name="displaying_the_database_schema_pane_ELTTEXTE000150"></a>
**To open the "Database Schema" pane**, go to the "Home" tab, "Environment" group, expand "Panes", select "Panes", and then select "Database Schema".

For more details on how to manage panes, see [Manipulating dockable panes](../Editeurs/2027001.md).
