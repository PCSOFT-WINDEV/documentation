


## Query and project
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
A query is not necessarily attached to a project. However, a query must be included in a project in order to be called from a process of the project.

On the contrary, a query is necessarily attached to a WINDEV, WEBDEV or WINDEV Mobile database schema. A query can handle the data coming from a database schema other than the creation database schema. In this case, the structure of the files and items used by the query must be identical.

The WINDEV, WEBDEV or WINDEV Mobile database schema contains the description of the tables that will be interrogated by the query.

If the database schema is modified, an automatic synchronization is performed between the database schema and the queries.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Requete_et_projet.gif)
When creating the query:

- if a project associated with a database schema is opened, the query will be automatically attached to the database schema of the project.

- if no project is opened, the database schema used must be specified in the wizard for query creation.
