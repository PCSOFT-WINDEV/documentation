


## Importing a CSS style sheet
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000107"></a>
WEBDEV gives you the ability to import a CSS style sheet into a WEBDEV project.

This allows you to reuse the styles created with another tool and to include them in your WEBDEV website.

**Note**: When importing an existing HTML page, WEBDEV also suggests importing its CSS styles. For more details, see [Importing an existing HTML page](../Editeurs/2030029.md). 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Importing an existing style sheet
<a name="importing_existing_style_sheet_ELTTEXTE000131"></a>
To import an existing CSS style sheet:

1. Open a page in the page editor. 

2. On the "Page" tab, "Theme and styles" group, expand "Styles" and select "Edit WEBDEV element styles and external CSS references". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Styles_CSS_externe.gif)


3. In the window that appears, click the "External CSS resources" tab. From this window, you can: 

	- Import a CSS file: 
			In the file explorer, select the CSS file you want to import. If necessary, this file will be copied to the project directory. 

	- Reference a CSS resource: 
			Enter the URL of the resource to be referenced. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=R%E9f%E9rencer_css.gif)

			Note: The resource must be referenced and accessed from a different domain. 
			

	- Delete the selected CSS resource. 

	- Relocate the selected CSS resource. 




4. Confirm. 




**Note**: Imported styles can be used:

- directly in the "Style" tab of the controls, specifying the CSS class to be used in "Element style". 

- when creating a new style.
