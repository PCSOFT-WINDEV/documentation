## Overview
<a name="overview_ELTTEXTE000109"></a>
WINDEV, WEBDEV and WINDEV Mobile allow you to create a help file and associate it with an application or website. This online help can be started by the user:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) from a window of the application (help button, for example).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) from a web page.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) from the "? .. Help" option.




The help system associated with the application can be created in a dedicated editor.

The following help formats are available:

- **HTML**: Help in HTML format. The help system is a static website with a summary and full-text search. 

- **CHM**: Compiled HTML Help.

- **PDF**: PDF help file. 




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) For WEBDEV websites or WINDEV Mobile applications, it is recommended to use a PDF help file.
