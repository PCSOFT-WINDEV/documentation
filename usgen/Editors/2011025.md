


## Importing tables into the database schema (external database, etc.)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000204"></a>
WINDEV and WEBDEV allow you to easily handle external databases (Oracle, SQL Server, Access, etc.) via WLanguage functions.

To use an external database, you must:

1. Import the tables from the external database into the database schema. During this import, the data can be:

	- stored in its current format. No conversion is required.
			**Note**: You can detect any changes made to the database. Simply [synchronize the database schema with the external database](../Editeurs/2011024.md).

	- converted to HFSQL.




2. Generate the database schema.

3. Handle the imported tables via the WLanguage functions. For more details, see [Database access](../WDLang4/3044202.md).




**Remarks**: 

- You can also convert only data in a specific table with [WDConver](../WDConver/3512006.md). To perform this operation, the table description must have been imported into the database schema.

- The data model editor allows you to perform the following operations: 

	- Import a table from an external database into an HFSQL Classic database schema.

	- Import a HFSQL Classic table into a new HFSQL Classic database schema.

### Importing a table into a database schema
<a name="importing_table_into_database_schema_ELTPARAGRAPHE000110"></a>

To import a table into a database schema:

1. In the data model editor, open the database schema where the import must be performed.

2. On the "Database schema" tab, in the "Creation" group, expand "Import" and select "Import file/table descriptions...". The table import wizard opens.

3. Select the desired data source.

4. **If you want to import an external database**:

	- For data sources that use a Native Connector, a connection to the external database is automatically established and associated with the tables imported into the database schema. This connection will be used to handle the tables programmatically.

	- If necessary, specify the connection parameters. These include: data server, user and password, database, connection name, etc.

	- Specify the data access mode. You can: 

		- access the data in its current format directly. Only the description of the tables is imported into the database schema. No conversion is required.

		- convert the data to HFSQL Classic.




- Select the tables (files) to import.

5. **If you want to import HFSQL Classic tables**:

	- Select the desired HFSQL Classic table (.FIC extension).

	- Specify the password of this table if necessary.




6. Confirm the import. The current database schema is automatically generated.

7. If the data must be converted to HFSQL Classic:

	- Specify the creation directory of HFSQL Classic tables.

	- Save (if necessary) the description of the conversion (script). This operation creates a ".WDV" file in the specified directory. This script can be reused by [WDConver](../WDConver/3512006.md).

	- Validate the data conversion.







Remarks: 

- To import an HFSQL classic table into a database schema, drag the table from the Windows File Explorer and drop it onto the data model editor. The import wizard opens automatically.

- From version 19, you can no longer import Hyper File 5.5 tables. This import can only be performed with WINDEV or WEBDEV 18 (or earlier).
