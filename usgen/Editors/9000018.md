Some important points regarding the access to data from a Java application in WINDEV:  

- The execution performed in test mode is not a Java execution but a Windows execution. A different connection must be established depending on whether or not test mode is used (e.g., InTestMode()=True).

- The RMI and JDBC connections cannot be defined in the database schema. These connections must be defined programmatically ([SQLConnect](../WDLang4/3072005.md) or [HOpenConnection](../WDLang4/3044107.md)).
