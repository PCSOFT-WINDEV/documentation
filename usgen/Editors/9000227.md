## Overview
<a name="overview_ELTTEXTE000213"></a>
It is now common for individuals or businesses to sign contracts electronically. Electronic signatures make it possible to:

- notify different contributors that the document has been read and its content validated. 

- prevent a document from being edited. The slightest modification of the document will invalidate the signature. Users will be notified that the document has been modified since the last signature.




Starting with version 2025, you can integrate Yousign functionalities in WLanguage via a wizard.

Note: To sign documents using Yousign solutions, an API key is required. To obtain this key, you need to subscribe to one of the plans offered by Yousign.

## Principle
<a name="principle_ELTTEXTE000237"></a>


### Signature workflow with Yousign
<a name="signature_workflow_with_yousign_ELTPARAGRAPHE000025"></a>

1. The WINDEV application provides Yousign with the document (usually as a PDF file) to be signed and the list of people who need to sign it.

2. Yousign then sends an email to the signatories with a link to the Yousign website for signing. 

3. Once all the signers have signed, Yousign notifies the WINDEV application. The application then retrieves the signed document from Yousign.



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign-Sch%E9ma.gif)


Note: A document can also be approved before being signed (optional). 

The Yousign coding wizard allows you to manage all the stages of the signature workflow, view the status of a document signature, etc. 


### Signature
<a name="signature_ELTPARAGRAPHE000038"></a>

A document is signed by a trusted third party, Yousign in this case. This trusted third party is responsible for the validity of the signature.

It is possible to request 3 types of electronic signatures:

- Simple electronic signature (SES)

- Advanced electronic signature (AES), which uses at least identity verification via SMS. In this case, a phone number has to be provided. 

- Qualified electronic signature (QES), which involves an ID document verification. 




Note: Qualified electronic signatures are only form of electronic signature that is considered equivalent to a handwritten signature.

## Prerequisites
<a name="prerequisites_ELTTEXTE000267"></a>


### Testing prerequisites
<a name="testing_prerequisites_ELTPARAGRAPHE000055"></a>

To test the integration of electronic signature functionalities in your application, please follow these steps: 

1. Create a Yousign account ([https://yousign.app/welcome](https://yousign.app/welcome)).  

2. Create a new API key. Specify: 

	- Environment: Sandbox

	- Permissions: Full-Access




3. Create the key.  

4. Copy and save the key. 




Note: In this mode, signature request emails are sent, but the content indicates that the email is sent for test purposes only. 


### Prerequisites for using all the Yousign features
<a name="prerequisites_for_using_all_the_yousign_features_ELTPARAGRAPHE000073"></a>

To take full advantage of all the features in Yousign, you need to create a production account. To see the different plans available, visit [https://yousign.com/pricing-api](https://yousign.com/pricing-api).

## Yousign wizard
<a name="yousign_wizard_ELTTEXTE000297"></a>


### Opening the code wizard
<a name="opening_the_code_wizard_ELTPARAGRAPHE000085"></a>

To use the Yousign code wizard: 

1. Select the control that should start the Yousign signing process and open the code editor. 

2. Type "Yousign" and confirm.
	<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0001.gif)

	The Yousign wizard opens. 

3. The first step is to enter the API key previously obtained via the Yousign account.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0002.gif)


4. In the next step, you can select the service you want to use.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0003.gif)



### Signature request
<a name="signature_request_ELTPARAGRAPHE000102"></a>

To implement Yousign signature features in your application, the first step is to request a signature. This feature is available in the Yousign wizard: 

1. Select "Request a signature" and go to the next step. 

2. Indicate the document to be signed.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0004.gif)
 This document can be: 

	- a variable, a control or a document returned by a function. 

	- a file. In this case, simply indicate the file path. 




3. The next step is to select the document recipients.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0005.gif)
 For each recipient, specify: 

	- The identity of the recipient.  

	- If the recipient must: 

		- sign the document. 

		- approve the document. 

		- receive a copy. 




- If the recipient should sign the document, please indicate the desired signature level, the authentication method and the recipient's email address and/or phone number. 

- If the recipient should simply approve the document or receive a copy, only their email address is required. 

- The interface language. You can use a specific language for each recipient (7 different languages available). 

4. The wizard then requests the signature location(s) for each signer. You can determine this location using a string from the document or a set of coordinates. To enable signers to sign multiple pages in the document, you need to add multiple locations.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0006.gif)


5. The next step is to configure the email that will be sent to the recipients.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0007.gif)


6. The next step displays the generated code. This code can be copied and/or printed.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Yousign%20-%20HC%20N%B0008.gif)


7. Finish the wizard. 

	- The WLanguage code is automatically integrated into the current code. You can adapt or edit this code later. 

	- The Yousign component is integrated into the project. Since it is written in WLanguage, this internal component performs low-level operations. 
			Note: It is not recommended to modify the code of this internal component.








### Other wizard features
<a name="other_wizard_features_ELTPARAGRAPHE000140"></a>

The Yousign wizard includes many document and signature management features: 

- Retrieve a document (signed or unsigned).

- Track the status of a signature request. 

- Get document details: date last modified, etc. 

- Get signer details: identity, signed documents, etc. 

- Cancel or list requests, 

- Import the component. 




For most of these actions, you need to specify the ID generated and sent by Yousign in the signature request response. This identifier corresponds to the 'Id' property of the clRequest variable.  


### Yousign component
<a name="yousign_component_ELTPARAGRAPHE000154"></a>

The Yousign component is automatically integrated into your project. This component includes all the procedures required to use Yousign functionalities.

## Remarks
<a name="remarks_ELTTEXTE000339"></a>


- You can sign docx, pdf or html documents. 

- Reminder: To test the application, it is recommended to use a free developer account. 

- Note: At runtime, a login page may appear when you log in to your Yousign account. Once login has been completed, a blank page appears and can be closed. 

- By default, messages sent by Yousign to the various signers are written in English.
