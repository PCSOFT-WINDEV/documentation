## Overview
<a name="overview_ELTTEXTE000114"></a>
When creating a link, you can simply specify the destination. By default, the link opens the page specified in the current help page.

However, you can define the type of link and the destination in the link properties.

**To open the link properties**:

1. Position the mouse cursor on the desired link.

2. Select "Link properties" in the context menu. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=proprieteLien.gif)





Note: Links are available in all help system generation modes.

## Link properties
<a name="link_properties_ELTTEXTE000138"></a>
The following information is displayed in this window:

- **Link text**: Link label. The caption will be underlined in the help page. The underlining informs the user that a link is available.

- **Hyperlink to**: Type of link. A link is used to open:

	- another page of the help system.

	- an Internet page.

	- an anchor of a page.

	- a link toward a page found in another help file. Please note: the WDH file corresponding to this second help system must be present in the project directory.




- **Destination page**: Page to be opened by the link. This option corresponds to:

	- one of the pages found in the current help system.

	- an Internet address (www.windev.com for example).
			

	- an anchor on one of the pages found in the current help system.

	- a page found in another help system found in the project directory.




- **Opening mode**: Mode of opening the page opened by the link. The available options are:

	- *Current window*: The page uses the same description as the current help window.

	- * Popup window* (help page opening only): The help page is displayed as a popup (tooltip).. 
			**Warning** In this case, the help page must not have a fixed zone.

	- *Specific window*: The help page will be opened in the selected help window.
