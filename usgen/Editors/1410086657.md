## Overview
<a name="overview_ELTTEXTE000115"></a>
Tailwind CSS is an open source CSS framework.
The main feature of this library is that it provides a list of CSS utility classes that can be combined to obtain the desired style.
This approach differentiates Tailwind CSS from other CSS frameworks (such as Bootstrap), which generally provide predefined classes for high-level elements (buttons, tables, etc.).

## How to use Tailwind CSS?
<a name="how_use_tailwind_css_ELTTEXTE000139"></a>
To use Tailwind CSS styles in a WEBDEV project:

1. Enable the use of Tailwind CSS in the project description: 

	- Open the project description window. To do so, go to the "Project" tab, "Project" group, and click "Description". 

	- On the "Advanced" tab, check "Enable Tailwind CSS class generation".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=TailwindCSS%20-%20HC%20N%B0001.gif)


	- Confirm. 

2. Add the Tailwind CSS styles to the styles of the controls: 

	- Go to the "Style" tab of the control description window. 

	- Add each Tailwind CSS class in "Element styles". Styles are displayed as tokens, to make them easier to identify, edit and delete.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=TailwindCSS%20-%20HC%20N%B0003.gif)


	- Confirm. The style is automatically applied to the control in the page editor.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=TailwindCSS%20-%20HC%20N%B0004.gif)




**Remarks**: 

- Additional Tailwind CSS styles are not always applied immediately in the page editor. It is necessary to save the page so that Tailwind can detect the styles used and update its style sheet. 
	WEBDEV can then refresh the elements in the page editor.

- Once applied to one control within the project, Tailwind CSS styles will be reflected immediately when applied to new controls, as the style is already present in the style sheet.





### Special case: Using Tailwind CSS in an external component
<a name="special_case_using_tailwind_css_external_component_ELTPARAGRAPHE000058"></a>

You may find external components containing pages for WEBDEV sites and applications. This component can include Tailwind CSS classes. This option can be found in the component description. 

To use Tailwind CSS styles in an external component for WEBDEV:

1. Open the "Component" configuration description window. In the "Project explorer" pane, open the context menu of the component configuration and select "Description". The component description window appears. 

2. In the "General" tab, enable Tailwind CSS class generation. 

3. Confirm.
