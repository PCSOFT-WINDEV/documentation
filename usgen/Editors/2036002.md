


## Installing WINDEV, WEBDEV or WINDEV Mobile
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000361"></a>
This page describes the configuration required to install WINDEV, WEBDEV or WINDEV Mobile, as well as the different installation steps.

Note: To install WINDEV, WEBDEV or WINDEV Mobile, you must be logged in as an administrator

<a name="NOTE2_1"></a>


## Required configuration
<a name="required_configuration_ELTTEXTE000385"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Configuration required for installing WINDEV
<a name="configuration_required_for_installing_windev_ELTPARAGRAPHE000022"></a>

We will distinguish between the configuration of the development computer (your computer) and the configuration required for the applications developed by WINDEV to operate (the end-user computers).

**Development computer**:

- Minimum screen size: 1920 x 1080

- 8 GB of RAM (16 GB or more recommended).

- 20 GB of disk space.

- running Windows 10 or later. 

- Note: To install WINDEV, you must be logged in as an administrator. 




**User computer**:

- 2 GB of RAM.

- running Windows Vista or 7 (32 or 64-bit) or later. An SSE2 processor is required.
	Note: To use the Map control, the user computer must run Windows 10 or later. 




Please note that the source code of WINDEV applications remains the same, regardless of the Windows version the programs will run under.

**Note**: When the development computer has a screen with a high resolution, the font size in the WINDEV editors may be too small to be readable. This is the case on retina screens (2 560 x 1 600) or high-resolution Windows computers (3 000 x 1 800). To increase the size of all the fonts: 

1. Open the WINDEV general options ("Options" tab, "Home" group, "Environment"). 

2. Go to the "General" tab. 

3. In "DPI management", select "Let Windows manage DPI".

4. The DPI settings will be applied next time WINDEV Mobile is started.


For more details, see [WINDEV options](../Editeurs/2036001.md).

### Configuration required to install WEBDEV
<a name="configuration_required_install_webdev_ELTPARAGRAPHE000080"></a>

We will distinguish between the configuration of the development computer (your computer), the configuration required to host your sites (the computer of your hosting provider) and the configuration required for using the sites developed in WEBDEV (the computers of the Web users).

**Development computer**:

- Minimum screen size: 1920 x 1080

- 8 GB of RAM (16 GB or more recommended).

- 20 GB of disk space.

- running Windows 10 or later. 
	Note: If WEBDEV is used in a virtual machine, hardware acceleration must not be enabled. 

- Note: To install WEBDEV, you must be logged in as an administrator. 




**Host computer**:

- Server 16 GB of RAM.

- System: 

	- Minimum version: Windows 2016 and higher

	- Recommended version: Windows Server 2016 edition (standard or datacenter) and later.




- SSE4.1 and later processors.

- Web server (see "Configuring the Web servers").




Please note that the source code of WINDEV applications or WEBDEV sites remains the same, regardless of the Windows version the programs will run under.

**User computer**: Standard web browser:

- Edge 16 (or later),

- Chrome 57 (or later),

- Firefox 53 (or later).




**Note**: When the development computer has a screen with a high resolution, the font size in the WEBDEV editors may be too small to be readable. This is the case on retina screens (2 560 x 1 600) or high-resolution Windows computers (3 000 x 1 800). To increase the size of all the fonts: 

1. Open the WEBDEV general options ("Home" tab, "Environment" group, "Options"). 

2. Go to the "General" tab. 

3. In "DPI management", select "Let Windows manage DPI".

4. The DPI settings will be applied next time WINDEV Mobile is started.


For more details, see [WEBDEV options](../Editeurs/2036001.md).

We will distinguish between the configuration of the development computer (your computer) and the configuration required for the applications developed by WINDEV Mobile to operate (the end-user computers).

**Development computer**:

- Minimum screen size: 1920 x 1080

- 8 GB of RAM (16 GB or more recommended).

- 20 GB of disk space.

- running Windows 10 or later.

**Note**: When the development computer has a screen with a high resolution, the font size in the WINDEV Mobile editors may be too small to be readable. This is the case on retina screens (2 560 x 1 600) or high-resolution Windows computers (3 000 x 1 800). To increase the size of all the fonts:

2. Go to the "General" tab.

**Mobile device**:

- ARM or ARM-compatible processors (XScale, Samsung, etc.), X86 or X86-compatible processors (Intel Transmeta, Geode, etc.) with 64 MB of RAM.

- in Android. 

- in iOS.




Please note that the source code of WINDEV Mobile applications remains the same, regardless of the Android or iOS version the programs will run under.

**Remarks**: 

- Windows Mobile, Windows CE and Windows Embedded are no longer supported by Microsoft, but are still used in the industrial field. 
	To continue developing for Windows Mobile, you must use version 26. Version 2026 gives you access to version 26, which can be downloaded as a subscription-based version [here](https://download.windev.com/UK/SaaS.awp) or purchased as a dongle-based version [here](https://download.windev.com/UK/index.awp).

- The "Universal Windows 10 App" platform are no longer supported in WINDEV, WEBDEV and WINDEV Mobile. 
	To continue developing an application in Universal Windows 10 App mode, use version 2024. Version 2026 gives you access to version 2024, which can be downloaded as a subscription-based version [here](https://download.windev.com/UK/index.awp) or purchased as a dongle-based version [here](https://download.windev.com/UK/dongle.awp).

## Setup
<a name="setup_ELTTEXTE000445"></a>
The setup is very easy, simply follow the instructions included with the installation package.

You can install WEBDEV and WINDEV Mobile separately, or integrate them into WINDEV if it is already installed. WEBDEV and WINDEV Mobile can be integrated into 32 and 64-bit versions of WINDEV.

To make things easier, the setup procedure automatically creates the "WINDEV", "WEBDEV" or "WINDEV Mobile" program group in "Start .. Programs" and installs the necessary files.

The WINDEV, WEBDEV and WINDEV Mobile setup wizard prompts you to help improve the installed software by allowing usage data collerction. This optional and anonymous data collection allows PC SOFT to improve its products.

## Dongle (used only for the legacy version)
<a name="dongle_used_only_for_the_legacy_version_ELTTEXTE000499"></a>
The dongle supplied with your product is specific to the development environment.

This dongle is not required for end users or for the hosting provider of your websites.

The dongle must simply be plugged in when the software is used. It can be a standard USB key or a network-based key. 

In the case of a standard USB key, plug it into an available USB port and start WINDEV, WEBDEV or WINDEV Mobile.

**Note**: If the key doesn't light up or flashes, refer to the following FAQ: [Installing the driver required to recognize the dongle of WINDEV, WEBDEV or WINDEV MOBILE](https://faq.windev.com/faqread.awp?idfaq=3519). 

**Dongles are no longer required if you use a subscription-based version.**
