## Overview
<a name="overview_ELTTEXTE000159"></a>
As soon as it is created, a control is associated with a style. A control style corresponds to:

- the appearance of the control (background color, font, borders, etc.),

- the control details (background image, size, etc.).




When it is created, the control can be:

- associated with a style (a style from the custom style sheet or a style from the style sheet of the theme for example).

- associated with no style (the control is dissociated). In this case, the control uses the style proposed by default.

<a name="NOTE2_1"></a>


## How to link a control to an existing style?
<a name="how_link_control_existing_style_ELTTEXTE000183"></a>
The style of a control can be chosen:

- directly via the style selection window ("Choose a style" option in the context menu).

- via the control description window ("Style" tab, "Choose another style" link).




Once chosen, the style is linked to the control. The selected style is copied to the control and the control stores the information regarding the linked style (style identifier, version of the style used, etc.).

**Note**: To link multiple controls of the same type to the same style, simply select the controls (by holding down the Ctrl key, for example) open the context menu and open the style selection window.

## How to create a style?
<a name="how_create_style_ELTTEXTE000207"></a>


### Creating a style from the control description (recommended)
<a name="creating_style_from_the_control_description_recommended_ELTPARAGRAPHE000040"></a>

You can create a style simply by editing the style of an existing control.

To create a style from a control description:

1. Open the control description.

2. On the "Style" tab, make the necessary style changes.

3. Create a new style based on the changes you have made: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Style_d_un_champ%20-%20HC%20N%B0001.gif&type=thumb)
Two methods are available:

	- Click "Create style from control". 

	- Expand the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Style_d_un_champ%20-%20HC%20N%B0001%202.gif) menu and select "Create style from control". 




4. Give the style and name and indicate the relevant style sheet, if necessary. 

5. Confirm. 




Note: If the project is present in the SCM, creating a style automatically extracts the style sheet and updates or creates the .sty file. If the style sheet was created, it is added to the SCM.
<a name="NOTE3_2"></a>


### Creating a style from the style window
<a name="creating_style_from_the_style_window_ELTPARAGRAPHE000064"></a>

To create a style from the style window:

1. Create a control ("Creation" pane) in a window of your project. For example, to create a new button style, create a button control.

2. Open the style sheet edit window ("Choose a style" in the context menu).

3. Select a style and open its context menu. Select "New blank style". The style description window appears.

4. Specify the desired style options ("General" and "Style" tabs) and validate. This new style is automatically added to the custom style sheet of the current project. This style can be applied to the controls of the same type in all the projects that use this style sheet.

## Modifying and overriding the style of a control
<a name="modifying_and_overriding_the_style_control_ELTTEXTE000237"></a>
As soon as a style modification is made on a control linked to a style, one or more overrides are created. 

An override is used to modify one or more characteristics of the style while remaining linked to the style of the control for all the other characteristics.

Therefore, if the style linked to the overridden control is modified:

- The modifications that do not affect the overridden characteristics are updated.

- The control keeps the overridden characteristics.




For example, a static control uses the "Header" style. The font for this style is black by default. For a specific window, the color of the font must be red. To avoid creating a new style and remain synchronized with the "Header" style, simply change the font color in the style description. This will automatically override the style.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Style_d_un_champ%20-%20HC%20N%B0001%201.gif)
The style of the control is automatically updated you confirm changes in the description window. The override is taken into account. If the "Header" style is modified, all style attributes will be updated except the font color.

**Note**: Clicking the number of overrides opens a window listing the existing overrides. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Style_d_un_champ%20-%20HC%20N%B0002.gif)
You can:

- Cancel an override.

- Restore an override.




We advise you to cancel the override if the control and the reference style have the same properties.
Note: Style overrides are available in window and control templates.
<a name="NOTE4_2"></a>


### Limitations of style overrides
<a name="limitations_style_overrides_ELTPARAGRAPHE000108"></a>

- Style sheets cannot be overridden.

- A control linked to the style sheet of a theme is overridden. We advise you to keep the overrides. Therefore, if the theme is added to the style sheet of the project, the control loses the link with the theme and it will no longer inherit from the modifications performed in the style of the theme.

- The style override is not available for menus and menu options (main menu or context menu).
