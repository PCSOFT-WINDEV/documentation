


## Recycle code windows
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000143"></a>
By default, a single code window is opened for each open element in the editor

For example, a code window displays the code of a button used in a window. When you try to open the code of another element from this window, the same code window will be used.

This is called code window recycling (default mode).

To display the code of multiple objects in multiple windows, simply disable the code window recycling feature.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000167"></a>


### Implementing code window recycling
<a name="implementing_code_window_recycling_ELTPARAGRAPHE000024"></a>

To recycle the code windows of a WINDEV or WEBDEV file (window, report, etc.):

1. Open the code of the desired element.

2. On the "Display" tab, in the "Editing help" group, check "Reuse same code window". 



<a name="NOTE2_2"></a>


### Use multiple code windows for the same element
<a name="use_multiple_code_windows_for_the_same_element_ELTPARAGRAPHE000046"></a>

By default, code window recycling is used. A single code window is displayed for each element (window, page, etc.). 

To display multiple code windows for a WINDEV, WINDEV Mobile or WEBDEV element (window, report, etc.):

1. Open the code of the desired element.

2. On the "Display" tab, in the "Editing help" group, uncheck "Reuse same code window".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_vue_multiple%20-%20HC%20N%B0001.gif)





When there are multiple code windows open for the same element (for example, one code window open for each button in the window): 

1. A specific icon appears in the tab: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_vue_multiple%20-%20HC%20N%B0002.gif)


2. You can click this icon to access the different code windows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_vue_multiple%20-%20HC%20N%B0003.gif)



Note: To view code windows side by side, you can use the "Undock active view" option and move the different code views: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_vue_multiple%20-%20HC%20N%B0004.gif&type=thumb)

## Notes
<a name="notes_ELTTEXTE000197"></a>


### Global procedures, classes and other elements.
<a name="global_procedures_classes_and_other_elements_ELTPARAGRAPHE000083"></a>

When a procedure or method is selected in the "Project explorer" pane, the "Edit code in a new window" option in the context menu opens a new code window for viewing global procedures (whether or not the "Reuse same code window" option is checked). You can then change the displayed code view and/or detach it by clicking the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_vue_multiple%20-%20HC%20N%B0003%201.gif) icon. 


### Using several code windows for the same WINDEV/WINDEV Mobile/WEBDEV element (window, report, etc.)
<a name="using_several_code_windows_for_the_same_windevwindev_mobilewebdev_element_window_report_etc_ELTPARAGRAPHE000094"></a>

If the code of the same element (button code, control code, etc.) is requested several times, the corresponding code window is re-enabled
