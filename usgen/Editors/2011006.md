## Overview
<a name="overview_ELTTEXTE000227"></a>
The main manipulations possible on a database schema (MLD) are as follows:

- [Duplicate/Copy a database schema](#NOTE2_1).

- [Delete a database schema](#NOTE2_2).

- [Rename a database schema](#NOTE2_3).

## Handling a database schema (MLD)
<a name="handling_database_schema_mld_ELTTEXTE000251"></a>


### Duplicate/Copy a database schema
<a name="duplicatecopy_database_schema_ELTPARAGRAPHE000039"></a>

Duplicating a database schema makes it possible to have two identical database schemas with different names.

To duplicate/copy a database schema:

1. Open the database schema to duplicate in the table model editor.

2. On the "Home" tab, in the "General" group, expand "Save" and select "Save as". The database schema description is displayed.

3. Modify the database schema name and directory.

4. Confirm changes:

	- All tables used to describe the duplicated database schema are automatically copied into the specified directory.

	- The duplicated database schema is automatically associated with the current project.







**Note**: Backup subdirectories from the original database schema are not copied. The new database schema contains no backup.
<a name="NOTE2_2"></a>


### Delete a database schema
<a name="delete_database_schema_ELTPARAGRAPHE000070"></a>

To delete a database schema:

1. Open the Windows explorer.

2. Delete the full directory of the database schema (&lt;Project name&gt;.ANA directory).




**Note** If a project was using this database schema, it will be necessary to associate the project with another database schema when opening it.
<a name="NOTE2_3"></a>


### Rename a database schema
<a name="rename_database_schema_ELTPARAGRAPHE000082"></a>

To rename a database schema:

1. Open the database schema to be renamed in the data model editor.

2. On the "Home" tab, in the "General" group, expand "Save" and select "Save as". The database schema description is displayed.

3. Enter the new database schema name.

4. Confirm changes.

5. All tables used to describe the renamed database schema are automatically copied into the specified directory.

6. The renamed database schema is not automatically associated with the current project. Associate (if necessary) the renamed database schema with the current project. For more details, see [Linking a database schema to an existing project](#NOTE2_4).

7. In the Windows explorer, delete (if necessary) the directory of source database schema.



<a name="NOTE2_4"></a>


### Linking a database schema to an existing project
<a name="linking_database_schema_existing_project_ELTPARAGRAPHE000112"></a>

To link a database schema to an existing project:

1. Open the project to associate.

2. On the "Project" tab, in the "Project" group, click "Description". The project description opens.

3. In the "Database schema" tab, click on "Add database schema" and select the path of the WDD file corresponding to the database schema you wish to associate.




**Remarks**: 

- Several database schemas can be associated with a single project. For more details, see [Project with multiple database schemas](../Editeurs/1410087296.md). 

- Deleting a database schema and replacing it with a new one: If data from the original database schema is manipulated in the project, associating a new database schema can lead to errors (duplicate errors, display errors, etc.).



<a name="NOTE2_5"></a>


### Zoom factor
<a name="zoom_factor_ELTPARAGRAPHE000145"></a>

You can specify a zoom factor in the data model editor to reduce or enlarge the graph display of the current database schema.

To specify a zoom factor:

- **1st method**:

	- On the "Display" tab, in the "Help for edit" group, choose the desired zoom factor.

	- Enter the zoom factor in the status bar of the editor (bottom right).




<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ZoomBarreMessage.gif)


- **2nd method**:

	- Press the Ctrl key.

	- Modify the zoom factor with the mouse wheel while keeping the Ctrl key down.






<a name="NOTE2_6"></a>


### Move the display of a database schema
<a name="move_the_display_database_schema_ELTPARAGRAPHE000174"></a>

To move the display of a database schema:

1. Display the database schema in the table model editor.

2. Press Alt.

3. Change the position of the database schema graph by holding down both the left mouse button and the Alt key.
