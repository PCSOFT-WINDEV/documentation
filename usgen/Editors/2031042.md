## Overview
<a name="overview_ELTTEXTE000144"></a>
The RAD (Rapid Application Development) is a technology used to easily create a full application (or site).

The RAD is based on preset programming patterns used to generate the requested application. It's also possible to create your own "patterns" to automatically generate a customized application: you decide on the code generated and the positioning of fields.

RAD can be launched as follows: under the "Project" pane, in the "Generation" group, click on "Full Application RAD".. Once the pattern is chosen, simply follow the different steps of the wizard.

**
Note**: The creation of windows and pages also offers RAD generation. For more details, see: 

- [WINDEV: Windows created via the RAD model](../Editeurs/2031003.md). 

- [WEBDEV: Pages created via the RAD model](../Editeurs/2031008.md).

### WINDEV application
<a name="windev_application_ELTPARAGRAPHE000049"></a>

The following RAD patterns are proposed by default:

- **Simple RAD**:
	This pattern is used to generate a full application. This application contains forms, tables and loopers. The code used is as simple as possible. Any style book can be applied.

- **Antakara pattern**:
	This pattern is used to create an application that proposes some advanced features such as a task list, a calendar, … This application also proposes a menu made of animated images.

- **Pure pattern**:
	This pattern is used to create an application with an interface suitable for the large screens.

- **Jet'Tames pattern**:
	This pattern is used to create an application that proposes a specific feature for sending emails. The menu of the application uses a carousel of images.

### WEBDEV website
<a name="webdev_website_ELTPARAGRAPHE000082"></a>

The following RAD patterns are proposed by default:

- **AWP RAD pattern**:
	This pattern is intended for generating an AWP site. It offers the following functionalities: Ajax tables, repeated zones, PDF report generation, menu management, search Engine Optimization management, moveable cell management, etc. 

- **Intranet pattern**:
	This pattern is intended for generating an Intranet/Extranet site. It features Ajax tables, PDF report generation and tabbed menu management.
