## Overview
<a name="overview_ELTTEXTE000196"></a>
The project description window allows you to configure various elements of your project. This window includes the following tabs:

- The ["Project"](../Editeurs/2030046.md) tab, which allows you to enter general information about the project.

- The "Database Schema" tab, which allows you to associate one or more database schemas with the project and/or a UML model.

- The ["Tables"](../Editeurs/2030052.md) tab, which allows you to enter information about the tables used by the application. This tab is only available if the project uses a database schema.

- The "Live Data" tab, which allows you to configure how the data from the tables is displayed in the different editors.

- The ["Languages"](../Editeurs/9500219.md) tab, which is used to configure the different languages used by the project as well as the options to be used for each language.

- The **"Style" tab** which lets you choose templates, palettes, custom style sheets and customize the report viewer. You can also configure screen sizes.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The ["Theme"](../Editeurs/1410087360.md) tab, which allows you to choose the project theme, the associated palette, style sheet and external resources. 

- The ["SCM"](../Editeurs/9500239.md) tab, which is used to manage teamwork (SCM or Git).

- The ["Options"](../Editeurs/9500227.md) tab, which allows you to define the creation, update and save options of the different elements of the project. This tab also allows you to synchronize templates, enable strict mode and define the code style.

- The ["Advanced"](../Editeurs/9500236.md) tab, which allows you to enable "Reports and Queries", configure the AAFs and lock the application.

- The ["Compilation"](../Editeurs/9500218.md) tab, which allows you to configure the compilation options.

- The ["Telemetry"](../Editeurs/9500223.md) tab, which allows you to configure the telemetry options for the project. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This option is not available.

## Style tab
<a name="style_tab_ELTTEXTE000277"></a>


### Project theme
<a name="project_theme_ELTPARAGRAPHE000031"></a>

The "Style" tab of the project description window allows you to identify and define the theme used by the project. 

- **Name of theme used** The name of the theme used is displayed. You can modify the project theme by scrolling down the combo box. A thumbnail shows the corresponding look. 
	**Note** If the theme is modified via the project description window, this modification is only taken into account for the new windows created. To apply a theme to existing windows, go to the "Project" tab, "Other actions" group, and click "Apply a skin template to the project". 

- **Apply theme to system windows**:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The " Info, YesNo, Confirm, and Dialog system windows (WINDEV configurations) " option can be used to customize system information windows, by using the AAFs or by integrating the corresponding windows directly into the project. For more details, see [Customizing the system information windows (or dialog boxes)](../WDLang1/3021003.md).

	- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The "Customize Info, YesNo, Confirm, and Dialog system windows (Android and iOS configurations)" option is used to customize system information windows. For more details, see [Customizing the system information windows (or dialog boxes)](../WDLang1/3021003.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The "Apply theme of theme to the components included in the project and to AAF windows" option makes it possible to use the theme of the project theme on all the elements that are included in the project: components, specific AAF windows, etc.

	- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The " Allow switching to dark theme (automatically or manually via ChangeTheme) " option enables automatic dark theme support in your mobile applications. For more details, see [Dark theme on mobile devices](../WDLang3/1000025338.md). 




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Tooltip look management**The "Tooltip" option lets you define how tooltips are displayed in your application. By default, the display mode is "Standard". You can customize the tooltips of the application. For more details, see [Custom tooltips](../Editeurs/9500233.md).

### Palettes
<a name="palettes_ELTPARAGRAPHE000108"></a>

When using a theme with palette, the palette is automatically associated with the project. Several palettes can be associated with a single project. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Palettes_ok%20-%20HC%20N%B0001%201.gif)


The <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Palettes_ok%20-%20HC%20N%B0001%202.gif)
 button opens the palette selection window: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Palettes_ok%20-%20HC%20N%B0002.gif&type=thumb)
 Simply select the palette to be added to the project. 

The <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Palettes_ok%20-%20HC%20N%B0001%204.gif)
 button is used to define the default palette. The default palette is the first palette in the palette list. 

For more details on color palettes, see [Color palettes](../WDLang6/1410090992.md). 


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Report viewer
<a name="report_viewer_ELTPARAGRAPHE000132"></a>

The report viewer allows end users of a WINDEV application to view reports before printing them. This report viewer can be customized to match the look of your application. For more details, see [Customizing the report viewer (preview)](../WDChamp/2024002.md). 


### Style sheets
<a name="style_sheets_ELTPARAGRAPHE000140"></a>

This option allows you to select the style sheet(s) associated with the project. 
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Window size at creation
<a name="window_size_creation_ELTPARAGRAPHE000147"></a>

This option allows you to select the size that will be proposed by default when creating windows in the window editor.
