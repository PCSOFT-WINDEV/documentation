## Overview
<a name="overview_ELTTEXTE000248"></a>
The image catalog included in WINDEV, WEBDEV, WINDEV Mobile represents several thousand images provided for your applications and sites. 

The images in this catalog can be used on all the graphic elements of your applications and websites. 

As soon as an image can be used (in a field, window, state, etc.), the element description window proposes the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Menu_Image_Editeur%20-%20HC%20N%B0001.gif) button to select the image. This button displays different options. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Menu_Image_Editeur%20-%20HC%20N%B0002.gif)
The "Catalog" option lets you select an image from the thousands provided in the WINDEV, WEBDEV, WINDEV Mobile image catalog. 



This image catalog is used to group:

- Clipart: 1- or multi-state images that can be used for images, buttons, etc.

- Splash Screen, advanced Splash Screen,

- Shapes,

- GIF animations,

- Banner, Backgrounds of windows,

- Powered by,

- Border,

- Bullets, Graphic buttons,

- Custom images,

- Images used to customize the style of the different controls (tabs, table columns, ...)




**Note** You can also access the image catalog directly:

- from the code editor. Indeed, when typing functions that handle images, the "&lt;Image catalog&gt;" option is automatically proposed by the assisted input.

- via the ["Image catalog"](../Editeurs/2027019.md) pane.

## The image catalog
<a name="the_image_catalog_ELTTEXTE000272"></a>


### Image catalog display mode
<a name="image_catalog_display_mode_ELTPARAGRAPHE000054"></a>

The image catalog can be displayed in 2 ways: 

- **simplified mode** This mode is automatically selected when the image catalog is displayed from the "Image catalog" option of an Image control. This simplified mode displays only the search control and the corresponding images. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Catalogue_Image_bis%20-%20HC%20N%B0002.gif&type=thumb)


- **full mode** Full mode: this mode is automatically selected when the image catalog is displayed from the "Image catalog" option of a specific field: icon, button frame, ... This mode allows you to select a theme, as well as the category of the image you're looking for, ... <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Catalogue_Image_bis%20-%20HC%20N%B0003.gif&type=thumb)



Use the handle (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Catalogue_Image_bis%20-%20HC%20N%B0004.gif)) to switch between simplified and full mode.. 

Note: to create applications with a "Windows 11" look, use the "Windows 11" theme in the image catalog.

## How to use the images found in the image catalog
<a name="how_use_the_images_found_the_image_catalog_ELTTEXTE000296"></a>


### Performing a search in the image catalog
<a name="performing_search_the_image_catalog_ELTPARAGRAPHE000076"></a>

Several search modes are available depending on the display mode. 

**In simplified mode**, simply enter the search keyword the launch the search using the magnifier. For example: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Catalogue_image.gif&type=thumb)


To search **in full mode**:  

1. Specify the search parameters:

	- **keyword** The keyword is used only when searching among cliparts. The keyword is searched among the keywords associated with the cliparts. The name of sought file can also be typed directly.

	- **theme** Select a theme to display all graphic elements using the same graphic style. Several themes are available. 

	- **image type** Clipart, Splash screen, ...




2. If you have entered a keyword, start the search using the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=catalogue_image%201.gif) button. The images corresponding to the selected criteria are displayed.



<a name="NOTE2_3"></a>


### Associating an image found in the catalog with the current element
<a name="associating_image_found_the_catalog_with_the_current_element_ELTPARAGRAPHE000097"></a>

To associate an image found in the catalog with the current element:

1. In the description window of current element, click the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Menu_Image_Editeur%20-%20HC%20N%B0001.gif) button and select "Catalog". Note: The images proposed by the image catalog adapt to the current field. For example, if the image catalog is displayed from the description of a button border, only the images of button borders will be proposed by default.

2. Search for the requested image if necessary.

3. Select the image. 

4. Double-click this image. 
	

5. The window for configuring the image is displayed: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Catalogue_image_Detail.gif&type=thumb)


6. Specify: 

	- The name of image to generate

	- The format to be generated: bmp, gif, jpg, png, svg, ico, ...
			The svg format is now available for most of the cliparts.

	- The number of states in the image (for the cliparts).

	- The characteristics of generated image: 

		- colors: It is possible to:  

			- use the default colors available in the image catalog. 

			- use HSL colors. In this case, you can change the Hue, Saturation and Lightness of the image. 

			- colorize the image (especially for monochrome images). A color picker allows you to define the color and threshold used (saturation).  




- rotation,

- symmetry,

- background color and transparency level of background color,

- image opacity: pixels with a value below the defined threshold will be completely transparent.

- The image size.

- Whether you want to generate an animation (only if the current element corresponds to the background image of a button).

- Whether you want to store the parameters for the next image selected from the catalog.

7. Validate. The image is automatically copied into the project directory and associated with the current element.




The "Edit image" button also allows you to open and edit the image in a new view of the editor. You can move this view and take advantage of all the options of the image editor.

### Displaying custom images
<a name="displaying_custom_images_ELTPARAGRAPHE000153"></a>

To display custom images:

1. Open the image catalog in full mode if necessary.

2. Click "Custom images". 

3. To add an image, click "Add".

4. On the "Image" tab, select the requested image file. Specify the name of the image and its description.

5. On the "Keywords" tab, specify the keywords linked to the image. These keywords can be chosen among the existing keywords or they can be created.

6. Validate. Your image is automatically added to the custom images. It will be taken into account by the next searches.




**Remarks**:

- It is also possible to modify the characteristics of a custom image or to delete a custom image.

- The custom images are referenced in the Control Center database. These images will be kept when changing computer or when changing the version of WINDEV, WEBDEV or WINDEV Mobile. For more details, see [Database of the Control Centers](../CCSuivi/3540720.md).

## Images found in the catalog
<a name="images_found_the_catalog_ELTTEXTE000332"></a>


### Image format
<a name="image_format_ELTPARAGRAPHE000179"></a>

Catalog images are available in various formats: GIF, BMP, PNG, SVG, ...

![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Only GIF, BMP, JPEG and PNG images are available.

Please note: PNG (24-bit) images require careful configuration of the user workstation (slower display).
<a name="NOTE3_2"></a>


### The graphic buttons
<a name="the_graphic_buttons_ELTPARAGRAPHE000192"></a>

By selecting the graphic buttons, the image catalog presents all the available graphic buttons. These buttons are classified by color. Several shapes are proposed for each color.
<a name="NOTE3_3"></a>


### The bullets
<a name="the_bullets_ELTPARAGRAPHE000199"></a>

By selecting the bullets, the image catalog presents a range of bullets that can be used in your applications.
