## Manipulating a table
<a name="manipulating_table_ELTTEXTE000213"></a>


### Duplicate/Copy a table
<a name="duplicatecopy_table_ELTPARAGRAPHE000034"></a>

Duplicating a table is used to get two identical tables with different names.

To duplicate/copy a table:

1. Select the table to be duplicated in the database schema editor.

2. On the "Home" tab, in the "Editing" group, click "Duplicate". 
	Note: It is also possible to select the "Duplicate" option from the table context menu. 

3. Specify the requested information and validate. The duplicated table is automatically created in the current database schema (LDM).



<a name="NOTE2_2"></a>


### Delete a table
<a name="delete_table_ELTPARAGRAPHE000061"></a>

To delete a table:

1. Select the table to be deleted in the data model editor.

2. Right-click to open the context menu of the table.

3. Select "Delete". The table is automatically deleted from the database schema (LDM). If links pointed to this table, these links are also deleted.




**Note**: When creating a table with the same name as a previously deleted table, WINDEV, WEBDEV and WINDEV Mobile offer to restore the description of the deleted table.
<a name="NOTE2_3"></a>


### Rename a table
<a name="rename_table_ELTPARAGRAPHE000074"></a>

To rename a table:

1. Select the table to be renamed in the data model editor.

2. Display the file description: 

	- On the "Database schema" tab, in the "Current element" group, click "Description".

	- Display the table context menu (right-click) and select "Table description". 




3. In the description window, modify the name of the table (and its name on disk if necessary). 

4. Validate. The table is automatically renamed.



<a name="NOTE2_4"></a>


### Use a dictionary
<a name="use_dictionary_ELTPARAGRAPHE000101"></a>

A table can be included in a dictionary in order to be reused in a new application for example. To integrate the table into a dictionary, simply drag and drop the table from the data model editor into the dictionary (displayed in the ["Dictionary" pane](../Editeurs/2027014.md)).

When it is included in the dictionary, the description of the table can subscribe to the modifications. Any modification made in the description of the table will be applied to the dictionary object and to all the uses of this object.

For more details, see [dictionary](../Editeurs/2023002.md).
<a name="NOTE2_5"></a>


### Create an empty physical the table corresponding to the description
<a name="create_empty_physical_the_table_corresponding_the_description_ELTPARAGRAPHE000118"></a>

To create the corresponding empty physical table:

1. In the data model editor, select the table for which a physical file is to be created.

2. Display the table context menu (right-click) and select "Create table".

3. Select the directory where the table will be created and validate.




The following files are automatically created in the specified directory:

- "&lt;Table&gt;.FIC" (table).

- "&lt;Table name&gt;.MMO" (memo file).

- "&lt;Table name&gt;.NDX" (index file).




If the table is logged, a "JNL" sub-directory will be automatically created, containing the various log files.

If the table contains a full-text index, a "&lt;Nom du tableau&gt;.FTX" file will be created. 

**Remarks**:

- This option is equivalent to calling [HCreationIfNotFound](../WDLang4/3044254.md).

- This option will be ignored if the table already exists in the specified directory.
