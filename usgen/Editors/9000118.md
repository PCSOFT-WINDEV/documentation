## Deployment via Play Store (formerly Android Market/Google Play)
<a name="deployment_via_play_store_formerly_android_marketgoogle_play_ELTTEXTE000172"></a>
Play Store (formerly Android Market or Google Play) is an online service used to download applications (free of charge or not) on mobile devices compatible with Android. 

Once published, the application can be downloaded by users worldwide via the Play Store application installed on their phones. 

The publication of applications on Play Store must comply with specific constraints: 

- During the first publication, you must register beside the Play Store service via a Google account.
	When this documentation was published, the link used for registration is: 
	[http://play.google.com/apps/publish/signup](http://play.google.com/apps/publish/signup)
	Once registered, you have the ability to publish or update an many applications as you want as many times as necessary. 

- The published application must be signed with a private cryptographic key. You can sign your own application.This means you don't have to use a third-party service. The validity period of the certificate must end after October 23, 2033. 
	Applications generated by WINDEV Mobile are automatically signed using the information provided in the generation wizard ("Application signature" step) with a sufficient validity period. 
	Caution: Do not publish an application signed with a generic key. This type of key should be used for testing purposes only. 

- An icon must be associated with the application. WINDEV Mobile's generation wizard lets you choose the icon to be used. 


**Note**: Play Store is the best-known application, but there are also other apps.

## Deployment via a web server
<a name="deployment_via_web_server_ELTTEXTE000196"></a>
You can make Android applications available for download via a link on a web page. 

**To do so, you must:** 

- Copy the APK file to the web server that hosts the page from which the application will be downloaded. 

- Add a link in the download web page. This link has the following format: 
	
	```txt
	<a href='Path of the APK file on the server'>Link</a>
	```


- Add the following MIME type on the server: application/vnd.android.package-archive




The user will only have to display the page with the browser of the phone. The application will be downloaded when the link is clicked. Then, simply click the downloaded file (in the download manager) to install the application. 

**Caution**: To use this installation method, make sure the "Unknown sources" option is enabled on the device. To enable this option, refer to your phone's documentation. Depending on the phone and its version, the corresponding option can be found in "Application", "Security" for example, ...

## Deployment from the PC via ADB (advanced mode)
<a name="deployment_from_the_via_adb_advanced_mode_ELTTEXTE000220"></a>
ADB (Android Debug Bridge) is a tool provided with the Android SDK. It is used to install or uninstall from the PC an Android application (APK file) on a mobile device compatible with Android. 

This setup mode is an advanced mode. For more details, see the online help about the specific commands used to install an application ([https://developer.android.com/studio/command-line/adb.html](https://developer.android.com/studio/command-line/adb.html))

**Caution**: To use this installation method, make sure the "Unknown sources" option is enabled on the device. To enable this option, refer to your phone's documentation. Depending on the phone and its version, the corresponding option can be found in "Application", "Security" for example, ...

## Copying the application to the Mobile device
<a name="copying_the_application_the_mobile_device_ELTTEXTE000244"></a>
The easiest way to install an Android application on a mobile device is to copy the APK file to the device and run it. The following operations must be performed: 

1. Connect the device to the PC by USB. 

2. Copy the APK file of the application to the device (external memory, for example). 

3. On the device, use a file explorer to go to the directory where the APK file was copied and click the file to start its setup. 


**Note**: Not all devices come with file browsers, but there are many available for free.

**Caution**: To use this installation method, make sure the "Unknown sources" option is enabled on the device. To enable this option, refer to your phone's documentation. Depending on the phone and its version, the corresponding option can be found in "Application", "Security" for example, ...
