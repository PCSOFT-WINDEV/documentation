


## Deploying a WEBDEV website to a remote WEBDEV Application Server or WEBDEV Cluster
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000161"></a>
Installing a dynamic WEBDEV (in Session or AWP mode) site on a remote application server requires:

- A web server.

- The WEBDEV Application Server installed on the deployment Web server. 

- The creation of a WEBDEV account in the WEBDEV administrator, the communication of account name and password.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Steps to follow
<a name="steps_follow_ELTTEXTE000185"></a>
The different steps for deploying on a remote server are as follows:

1. [Enter server details](../Editeurs/2028046.md). 
	A connection is automatically established with the server. Usernames and passwords are checked.
	This step allows you to define all the options for accessing the server (HTTPS, authenticated requests, FTP server, etc.). 

2. [Choose deployment with or without downtime](../Editeurs/2028111.md). 

3. [Select the files you want to install](../Editeurs/2028058.md).

4. [Automatic table modification](../Editeurs/2028048.md).

5. [Site settings and security](../Editeurs/2028051.md).

6. File transfer and setup. 
	Error messages may appear at various stages of the remote installation process. For more details, see [Errors during an FTP installation](../Editeurs/2028057.md).

7. A notification appears when the site is deployed. When you click this notification, you will see:

	- the link to launch the installed site. A bar code also appears. This bar code allows launching the site from a mobile device. 

	- a link to the installation log. You will be able to view and save the corresponding ".log" file. It contains all the actions completed in order to install the site. It also contains the details of the errors encountered, if any.

## Remarks and special cases
<a name="remarks_and_special_cases_ELTTEXTE000218"></a>


### Installation on a WEBDEV Cluster
<a name="installation_webdev_cluster_ELTPARAGRAPHE000063"></a>

Installation on a WEBDEV Cluster requires the following:

- A web server.

- The WEBDEV Application Server installed on the deployment Web server. 

- The creation of a WEBDEV account in the WEBDEV administrator, the communication of account name and password.

- The WEBDEV Application Server must be installed in Cluster mode and the WEBDEV Cluster must contain at least one node. For more details, see [Installing a WEBDEV Cluster](../Editeurs/1410086635.md). 

- A proxy must be installed and configured to be used with the WEBDEV Cluster. For more details, see [WEBDEV Cluster: Proxy configuration](../WDAdminDeploiement/3539085.md). 

- The site or web service must be installed via the proxy. The proxy address is therefore necessary. 




When a site is deployed to a WEBDEV Cluster, a notification is displayed at the end of the deployment. This notification indicates that the deployment process has been completed. 

This notification is displayed when the site is deployed to all WEBDEV Cluster nodes. In the event of a problem on one of the nodes, the notification indicates that the deployment is complete, but that a check is required on the individual nodes. 


### Installation via FTP
<a name="installation_via_ftp_ELTPARAGRAPHE000098"></a>

For an installation via FTP, the following elements are also required: 

- An FTP server installed on the deployment Web server ** only for a deployment by FTP**. The FTP server is not necessary for an HTTP deployment.

- The creation of an FTP account, the communication of name and password of FTP account as well as the server IP address.





### Notes on the WEBDEV Application Server
<a name="notes_the_webdev_application_server_ELTPARAGRAPHE000106"></a>

- For an Application Server in version 24 or earlier, any version of WEBDEV (up to version 24) can be used on the development computer.

- For an Application Server in version 25 or later, WEBDEV 24 or later must be used on the development computer.
	Special case: For remote deployment from WEBDEV 24 to an Application Server in version 25 or later, you need to  request the WWINST.EXE module for WEBDEV 24. Visit [https://www.windev.com/ts/useful_resources.htm](https://www.windev.com/ts/useful_resources.htm) and select "Upgrades available for WINDEV, WEBDEV or WINDEV Mobile".
