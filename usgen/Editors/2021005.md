


## Live Data: view data in editors 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000300"></a>
The "Live Data" is used to view the content of the tables in the controls currently created in the different editors of the product used (window editor, page editor, report editor, ...). This feature allows you to configure the size of a control according to the data that can be displayed in the control.

**Attention** To use Live Data, you must:

- associate a database schema with the project,

- handle the existing tables.

## How to implement Live Data?
<a name="how_implement_live_data_ELTTEXTE000324"></a>


### Implementing "Live Data" on the current project (window editor, page editor and report editor)
<a name="implementing_live_data_the_current_project_window_editor_page_editor_and_report_editor_ELTPARAGRAPHE000023"></a>

To implement the "Live Data" on the current project (window editor, page editor and report editor): 

1. On the "Project" tab, in the "Project" group, click "Description". The project description window appears.

2. Go to the "Live Data" tab.

3. Check "Enable Live Data".

4. For each table, specify if necessary:

	- Table type: This option allows you to select the type of table to be used for previewing. In fact, the table used can be an HFSQL Classic table, or an HFSQL Client/Server, Oracle, SQL Server, ... Simply select the corresponding connection.
			Different types of tables can be used at the same time.

	- the directory: The directory can correspond to:

		- "Automatic localization": the table is automatically localized. You can also click "Automatic localization".

		- "Test mode directory": the tables used are those defined for Test mode (the directory is defined in the "Tables" tab of the project description.

		- "Directory defined in database schema": the tables used are those defined in the database schema.

		- "Browse": selects the required table.




- the password of the table.  

5. Validate.


**Note** In this case, Live Data will only be taken into account the next time windows, pages and/or reports are opened.

		- "Directory defined in database schema": the tables used are those defined in the database schema.

		- "Browse": selects the required table.




- the password of the table.  

4. Validate.


**Note** In this case, Live Data will only be taken into account the next time you open reports and queries that can be modified in "Reports & Queries".

## How to disable the Live Data?
<a name="how_disable_the_live_data_ELTTEXTE000354"></a>


### Disabling "Live Data" on the current project (window editor, page editor and report editor)
<a name="disabling_live_data_the_current_project_window_editor_page_editor_and_report_editor_ELTPARAGRAPHE000102"></a>

To disable "Live Data" on the current project (window editor, page editor and report editor):

1. On the "Project" tab, in the "Project" group, click "Description". The project description window appears.

2. Go to the "Live Data" tab.

3. Uncheck "Enable Live Data" and validate.


**Note** In this case, deleting Live Data will only take effect the next time windows, pages and/or reports are opened.

## How to change the directory of the tables used for Live Data?
<a name="how_change_the_directory_the_tables_used_for_live_data_ELTTEXTE000384"></a>


### Changing the directory of the tables used for "Live Data"
<a name="changing_the_directory_the_tables_used_for_live_data_ELTPARAGRAPHE000151"></a>

To change the directory of the tables used for "Live Data":

1. On the "Project" tab, in the "Project" group, click "Description". The project description window appears.

2. Go to the "Live Data" tab.

3. Check "Enable Live Data".

4. For each table, indicate its location. The "Automatic localization" button automatically searches for tables. This search may take quite a long time.

5. Validate.

## How to specify the password of the tables used for Live Data?
<a name="how_specify_the_password_the_tables_used_for_live_data_ELTTEXTE000414"></a>


### Specify the password of the tables to be used for "Live Data"
<a name="specify_the_password_the_tables_used_for_live_data_ELTPARAGRAPHE000208"></a>To specify the password of the tables to be used for "Live Data": 
If the tables used for "Live Data" are password protected, the password can be specified in the project options:

1. On the "Project" tab, in the "Project" group, click "Description". The project description window appears.

2. Go to the "Live Data" tab.

3. Check "Enable Live Data".

4. For each table, specify the corresponding password and validate.


**Note** If the password is not specified for a protected table, the records in this table will not be displayed.
