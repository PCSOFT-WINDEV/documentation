


## Project description: Options tab
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000231"></a>
The project description window allows you to configure various elements of your project. This window includes the following tabs:

- The ["Project"](../Editeurs/2030046.md) tab, which allows you to enter general information about the project.

- The "Database Schema" tab, which allows you to associate one or more database schemas with the project and/or a UML model.

- The ["Tables"](../Editeurs/2030052.md) tab, which allows you to enter information about the tables used by the application. This tab is only available if the project uses a database schema.

- The "Live Data" tab, which allows you to configure how the data from the tables is displayed in the different editors.

- The ["Languages"](../Editeurs/9500219.md) tab, which is used to configure the different languages used by the project as well as the options to be used for each language.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The ["Style"](../Editeurs/9500234.md) tab, which allows you to customize the print preview and to choose the theme and custom style sheet. You can also configure screen sizes.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The ["Theme"](../Editeurs/1410087360.md) tab, which allows you to choose the project theme, the associated palette, style sheet and external resources. 

- The ["SCM"](../Editeurs/9500239.md) tab, which is used to manage teamwork (SCM or Git).

- The **"Options"** tab, which allows you to define the creation, update and save options of the different elements of the project. This tab also allows you to synchronize templates, enable strict mode and define the code style.

- The ["Advanced"](../Editeurs/9500236.md) tab, which allows you to enable "Reports and Queries", configure the AAFs and lock the application.

- The ["Compilation"](../Editeurs/9500218.md) tab, which allows you to configure the compilation options.

- The ["Telemetry"](../Editeurs/9500223.md) tab, which allows you to configure the telemetry options for the project. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This option is not available.

## Options tab
<a name="options_tab_ELTTEXTE000314"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000031"></a>

The following options are also available:

- **Ask for the location of the new elements in the project**: If this option is selected, you will be prompted to choose a location any time you save a new element in the project. 

- **Generate all the configurations in the "Exe" directory (not recommended if several configurations)**: If this option is selected, all configurations will be generated in the same directory. If this option is not selected, each project configuration will be generated in a subdirectory of the project's 'Exe' directory. This generation subdirectory will have the same name as the project configuration.

- **Include the new elements only in the current configuration**: If this option is selected, all new project elements will be included **only** in the current project configuration. 

- **Group all Private Store applications into one application (compatibility)**: This option indicates whether the server that hosts the application setup for the Private Store will use different settings for each project configuration. If this option is checked, the server settings will be the same for all project configurations. If this option is unchecked (default), the Private Store settings can be different for each project configuration. 

- **Default save format**: You can choose between Binary or text format. Text format is required to share files via Git. For more details, see [Share your projects via Git](../Editeurs/9500230.md).

- 
	<B><B><B><B>Subscription-exclusive feature</B></B></B></B>

	**Enable WINDEV Suite's subscription-exclusive features in the project**: This option enables subscription-exclusive features, which become available as new updates are released. This option is equivalent to the "Subscription" switch in the project dashboard. For more details, see [Using subscription-exclusive new features](../Editeurs/1410087359.md).

### Spelling checker
<a name="spelling_checker_ELTPARAGRAPHE000073"></a>

This option is used to: 

- **Choose the spelling checker used**. This spelling checker will be used by default to correct misspell words in Edit controls and Word Processing controls. 

- **Automatically copy the dictionaries to the generation directory**: If this option is selected, the dictionaries of the languages of the application will be automatically copied to the generation directory when the application is generated. 





### Template synchronization
<a name="template_synchronization_ELTPARAGRAPHE000085"></a>

The "Synchronize templates during generation" option allows you to automate the synchronization of control, window, page or report templates when generating the application. 
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Page generation
<a name="page_generation_ELTPARAGRAPHE000096"></a>

The "Generate HTML pages in the current language for the test mode" option reduces the WEBDEV-page-to-HTML-page generation time during a test (GO) by taking into account only the current language. 


### Development in strict mode
<a name="development_strict_mode_ELTPARAGRAPHE000101"></a>

Strict mode consists of following the development tasks defined in the Project Management Hub. 

If "Enable strict mode" is selected, the developer won't be able to modify an element of the project without previously selecting the task affected by such changes. 


### Code style
<a name="code_style_ELTPARAGRAPHE000112"></a>

The following options are available:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Documentation_automatique%20-%20HC%20N%B0004.gif)


- "Automatically prefix variables and elements in the project" activates the code style. 
	The code style allows you to automatically add prefixes to the names of variables and elements in the project (windows, report controls, classes, etc.). These prefixes allow you to easily identify and/or find an element of a given type.
	**To use the code style in the project**, simply select "Automatically prefix variables and elements in the project". You can: 

	- choose the desired code style. 
			 The "Create a code style" and "Edit code style" buttons allow you to create and customize your own code style. 

	- automatically add (or not) the prefixes ("Add prefixes automatically" option).

	- generate a UI error if an invalid prefix is used ("Throw a UI compilation error if a control has the wrong prefix"). 


 For more details, see [Code style](../Editeurs/9000074.md). 

- The "Block delimiters (code suggestions)" option allows you to select the code block delimiter used in the code suggestions (e.g. conditional statement):

	- END (default). Example: 
			
		```txt
		IF Condition THEN
		
		END
		```


	- Braces ** { }**. Example: 
			
		```txt
		IF Condition THEN
		{
		
		}
		```





- The "Automatic comment format" option allows you to select the format used to automatically comment a procedure. Two formats are available:

	- legacy format. 

	- Doxygen format.  


For more details on automatic documentation, see [Automatic documentation of procedures and methods](../Motscles/1513006.md).
