


## SCM: Ribbon options
			





## SCM menu
<a name="scm_menu_ELTTEXTE000192"></a>
The operations on the SCM can be performed from the SCM tab of WINDEV, WEBDEV or WINDEV Mobile.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002.gif&type=thumb)
This pane contains several sections: 

- "Add project".

- "Repository".

- "All elements".

- "Current element". 

- "Project". 

- "Other actions".




Let's see the options of these sections. 


### "Add project" group
<a name="add_project_group_ELTPARAGRAPHE000022"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0001.gif)
This section is shown only if the current project has not been checked into the SCM or pushed to Git. 

This group allows you to add the current project:  

- In the SCM. For more details, see [Adding a project to the repository](../Editeurs/2038002.md). 

- In Git. For more details, see [Share your projects via Git](../Editeurs/9500230.md). 





### "SCM" group
<a name="scm_group_ELTPARAGRAPHE000039"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0003.gif)
The "Manage" option is used to: 

- Open the SCM administrator. For more details, see [SCM administrator](../Editeurs/2038008.md). 

- Creating a repository. For more details, see [Creating a repository](../Editeurs/2038005.md). 

- Define a check-in policy. For more details, see [SCM: Check-in policy](../Editeurs/2038024.md).





### "All elements"group
<a name="all_elementsgroup_ELTPARAGRAPHE000058"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002%201.gif)
This group contains options to manage all the project elements. 

The available options are as follows: 

- **Retrieve all**: This option retrieves all new versions of project elements present in the repository. Elements currently checked out by the user are not included. For more details, see [SCM: Retrieving all elements](../Editeurs/2038033.md). 

- **Check all in**: This option checks all the checked-out project elements into the SCM repository. Some elements can remain checked out. For more details, see [SCM: Checking in all elements](../Editeurs/2038033.md). 

- **Element status** Allows you to view and search the status of project elements: 

	- View item status: Displays the list of project elements, with the date of the last extraction and the author of each element.  

	- Refresh the status of the elements. This option updates the list and the status of each element. 

	- Search for extractions: Displays the search window for extracted items. This window allows you to search for extracted items according to several filters. If necessary, you can add an element directly from this window. 








### "Current element" group
<a name="current_element_group_ELTPARAGRAPHE000082"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002%202.gif)
This group contains options to manage the current element in the editor. 

The available options are as follows: 

- **Check out**: Checks out the file corresponding to the current element from the repository. The latest version of the element is copied onto the local computer. Several check-out modes are available. For more details, see [Checking out an element](../Editeurs/2038006.md).

- **Check in**: Checks the file corresponding the to current element into the repository. The element is copied into the SCM repository. It is made available to the other users of SCM. For more details, see [Checking an element back in](../Editeurs/2038007.md).

- **Undo check-out**: Undoes the last check-out. The modifications are canceled and the file goes back to "Read-only".

- **Get latest version**: Gets the last version of the current element in the editor. This latest version is the one found in the SCM repository. 

- **Compare**: 

	- **Show changes since checkout**: Shows the changes made to an element since it was last checked out.

	- **Compare with the repository version**: Compares the current element (available locally) with the previous version in the repository. This comparison can be performed even if the element was not checked out. Used to check the modifications made before the element is checked back in.




- **Add**: Adds the current element to the repository. If this option is used from the data model editor, the database schema is added to the repository. For more details, see [Adding an element to the repository](../Editeurs/2038009.md).

- **Properties**: Shows the properties of the current element (check-outs, shares, etc).

- **History**: Shows the changes made to the element and the authors of those changes. You can get an earlier version, save it, search for the differences (between 2 versions for example) or merge the SCM version with your version.





### "Project" group
<a name="project_group_ELTPARAGRAPHE000111"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002%203.gif)
This group contains options to manage the current project in the editor. 

The available options are as follows:

- **Project history**: This option gets the list of changes made to the project and to the project file (WDP, WWP or WPP file). You can get an earlier version, save it, find the differences (between 2 versions for example), label the project version, etc. 

- **Branches**: Allows you to: 

	- Create a branch. 

	- Retrieve modifications from a branch. 


 For more details, see [GDS: Managing branches](../Editeurs/2038016.md). 

- **Import from SCM**: Imports an element from the SCM into the current project (e.g., a component or window from another project). You can share the element or import a copy.

- **Master / Guest** Allows you to manage handling options for master and guest projects. For more details, see [Working with the Source Code Manager](../Editeurs/2038004.md).

- **List shares** Displays a window listing directories that have shares with the current directory. These shares can be files or directories. For each directory, you can obtain a detailed list of shared files and folders. You can quickly see which projects will be affected by a change in these elements. 





### "Other actions" group
<a name="other_actions_group_ELTPARAGRAPHE000137"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002%204.gif)
This group contains project style sheet and remote work options. 

It is possible to: 

- Check out or check in the project style sheet. 

- Log off to work offline, then log back in and synchronize.
