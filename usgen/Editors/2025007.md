## Overview
<a name="overview_ELTTEXTE000201"></a>
Two types of directories can be configured when creating the executable:

- [the creation directory of tables managed by the User Groupware](#NOTE3_1).

- [the creation directory of HFSQL Classic tables created by the application](#NOTE4_1).

## Directory in which the User Groupware tables will be created
<a name="directory_which_the_user_groupware_tables_will_created_ELTTEXTE000225"></a>
Two categories of tables are managed:

- **the tables used to identify the users**. These tables can be common to several applications.

- **the tables used to manage the rights granted to the users on the different application windows**. These files are specific to the application.




For details of these tables (names, fields, etc.), see [The User Groupware tables](../Editeurs/2018002.md).

By default, these tables are created in the "&lt;ApplicationName&gt;_GPW" subdirectory of the installation directory of the application. However, this directory can be modified. This directory can correspond to:

- a specific directory

- the directory of the application data. This choice is adapted to the UAC mechanism of Windows Vista. If the users work with Windows Vista (or later) and if the UAC mechanism is enabled, they will be able to use the application without any specific administrator rights.

## Directory for creating the HFSQL Classic tables of the application
<a name="directory_for_creating_the_hfsql_classic_tables_the_application_ELTTEXTE000249"></a>
By default, HFSQL tables are created in the directories specified when describing tables in the database schema. However, these directories can be modified:

- **when creating the executable of the application**.
	Several options are available: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=D%E9ployer%20l'application%20-%20HC%20N%B0003.gif)


	- **Automatic (recommended)**: This option installs the tables: 

	- in the application data directory (if the executable is installed in "Program files"). 

	- in the executable directory. 

- **through programming** with [HSubstDir](../WDLang4/3044028.md) or [HChangeDir](../WDLang4/3044168.md).

- **when installing the application**. The directory for creating the tables will be selected by the user.




In any case, the directory for creating the tables is defined according to the following priority order:

1. Directory specified by [HSubstDir](../WDLang4/3044028.md) or [HChangeDir](../WDLang4/3044168.md).

2. Directory selected when installing the application (if this option is proposed to the user).

3. Directory selected when creating the executable.

4. Directory specified when describing tables in the database schema.




Therefore, the directory defined by [HSubstDir](../WDLang4/3044028.md) or [HChangeDir](../WDLang4/3044168.md) has priority over all the other directories.

**Special case: tables installed with the application**
These tables are installed in the directory specified when creating the setup program (destination directory specified in the "Tables installed" step).
The same directory should be used to install the tables supplied with the application and to create the new tables.
