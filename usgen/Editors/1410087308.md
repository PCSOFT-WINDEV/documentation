## Overview
<a name="overview_ELTTEXTE000126"></a>
WINDEV, WEBDEV and WINDEV Mobile include a string management tool that allows you to view and manipulate all the strings used in the project (or in an element of the project). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0001.gif)


This string manager is mainly used to: 

- List simple and multilingual strings, or constants used in a project or element of the project. 

- Filter strings by content and/or length. 

- Perform specific actions: convert to multilingual string, convert to constant, etc. 




The string manager can be opened from the code editor via one of the following options: 

- on the "Refactoring" tab, in the "Strings" group, expand "Strings in this element" and choose whether you want to view the strings used in the current element or in the entire project. 

- on the "Code" tab, in the "Languages" group, expand "Translate strings" and select "Project string manager".

## Project string manager features
<a name="project_string_manager_features_ELTTEXTE000150"></a>


### List strings
<a name="list_strings_ELTPARAGRAPHE000052"></a>

The string manager lists the different types of strings used in the project or in an element of the project. Multilingual strings are clearly identified by a flag.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0003.gif)


The different options allow you to choose between: 

- strings in the whole project or in a specific element. 

- simple strings, multilingual strings, or constants containing strings. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0002.gif)


- strings of a given length or containing a specific text. You can set a specific string length. 





### Perform actions on strings
<a name="perform_actions_strings_ELTPARAGRAPHE000065"></a>

Several actions are available in the string manager: 

- View the code containing the selected string. The code editor opens and shows the line that contains the current string. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0006.gif&type=thumb)


- Edit the string. 

- Convert to multilingual string: Converts a simple string to a multilingual string. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0004.gif)
In multilingual applications, this action is necessary to determine which strings should be extracted and translated. This action can be performed on multiple strings at once.  

- Convert to simple string: Converts a multilingual string to a simple string. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestionnaires_chaines%20-%20HC%20N%B0005.gif)
This action is necessary for certain strings that remain the same regardless of the language used by the application (e.g., command line parameter). This action can be performed on multiple strings at once.  

- Merge multiple strings into a constant: You need to select the different strings to be merged. These strings must have the same content. Then, you can simply indicate the name of the constant. The replacement is done automatically in the editor. 

- Hide a string in the string manager. To show a string again, check "Show hidden strings".
