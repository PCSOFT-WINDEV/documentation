
## Sticky header (Code editor)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000149"></a>
When working in a large code file (larger than the screen), it can sometimes be difficult to determine where you are in the code. 

When enabled, this feature leaves the first line of each block of code visible at the top of the screen as you scroll through the code. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Entete_epingle%20-%20HC%20N%B0003.gif)

## How to use sticky headers?
<a name="how_use_sticky_headers_ELTTEXTE000173"></a>


### Enabling or disabling sticky headers
<a name="enabling_disabling_sticky_headers_ELTPARAGRAPHE000019"></a>

You can enable sticky headers in the code editor options: 

1. On the "Home" tab, in the "Environment" group, expand "Options" and select "Code editor options".

2. On the "Code" tab, select (or deselect) "Enable sticky header (WLanguage)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Entete_epingle%20-%20HC%20N%B0001.gif&type=thumb)


3. Confirm. 




To temporarily enable or disable sticky headers in the code editor: 

1. Go to the code editor. 

2. On the "Display" tab, in the "Help for edit" group, check or uncheck "Sticky header (WLanguage)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Entete_epingle%20-%20HC%20N%B0002.gif)






### How sticky headers work
<a name="how_sticky_headers_work_ELTPARAGRAPHE000063"></a>

As you scroll, the first line of each statement block remains visible at the top of the code editor. 

Clicking one of the headers takes you to the corresponding block of code. 


### Sticky header scrolling mode
<a name="sticky_header_scrolling_mode_ELTPARAGRAPHE000070"></a>

By default, 8 lines are pinned. 

If the number of lines to be pinned is greater, the lines from higher-level scopes remain visible. 

You can change this scope in the in the code editor options: 

1. On the "Home" tab, in the "Environment" group, expand "Options" and select "Code editor options".

2. On the "Code" tab, under "Sticky header", you can set: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Entete_epingle%20-%20HC%20N%B0001%201.gif)


	- the number of lines to be pinned (8 by default). 

- the preferred scope if there are more lines to be pinned: 

	- Show higher-level scopes (default).  

	- Show lower-level scopes ("Prefer inner scopes" option selected).
