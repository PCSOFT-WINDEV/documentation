
## Database schema maintenance
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000098"></a>
The data model editor lets you perform several maintenance operations on the current database schema. 

To find these options, go to the "Database schema" tab, "Database schema" group and expand "Maintenance". 





<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## List of items with a masking rule
<a name="list_items_with_masking_rule_ELTTEXTE000122"></a>
To list the items with a masking rule in the data model editor: 

1. In the data model editor, on the "database schema" tab, in the "database schema" group, expand "Maintenance" and select "List of items with a masking rule".

2. The window that appears lists the different items that use a data mask in each file, as well as the masking rule used. 




For more details on data masking, see [Automatic data masking](../WDLang4/9000215.md).

## Changing the case of file and item names
<a name="changing_the_case_file_and_item_names_ELTTEXTE000146"></a>
To change the case of file names: 

1. In the data model editor, on the "Database schema" tab, in the "Database schema" group, expand "Maintenance" and select "Change case of table names". 

2. In the window that is displayed, select: 

	- the desired case: lowercase, uppercase or capitalize each word. 

	- the file names to be modified. 




3. Confirm. Changes are applied immediately to the selected files.  



To change the case of item names: 

1. In the data model editor, on the "Database schema" tab, in the "Database schema" group, expand "Maintenance" and select "Change case of item names". 

2. In the window that is displayed, select: 

	- the desired case: lowercase, uppercase or capitalize each word. 

	- the names of the items to be modified in each file. 




3. Confirm. Changes are applied immediately to the selected items.
