## Summary
<a name="summary_ELTTEXTE000201"></a>
In a WINDEV application, users have multiple help features at their disposal: 

- Tooltip.

- Status bar.

- Help window.

- Advanced tooltip.

- Help page. 

- CHM file.





### Tooltip
<a name="tooltip_ELTPARAGRAPHE000021"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=BULLEAIDE.GIF)


- **Level of help provided**: Short help (a few words)

- **How to create it**:

	- Control description window, "Help" tab

	- Programming: Property [ToolTip](../Proprietes/2510005.md)




- **How to launch** help: Automatic launch when hovering over the field.

- **For more details**: [User help](../Editeurs/2010012.md)





### Custom tooltip
<a name="custom_tooltip_ELTPARAGRAPHE000038"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Bulles_aide_personnalisees%20-%20HC%20N%B0005.gif)


- **Level of help provided**: Context-sensitive help.

- **How to create it**: 

	- Project editor, to define the appearance.  

	- Control description window, "Help" tab to define the content




- **How to launch** help: Automatic launch when hovering over the field.

- **For more details**: [Custom tooltips](../Editeurs/9500233.md)





### Status bar
<a name="status_bar_ELTPARAGRAPHE000053"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=BARREMSG.GIF)


- **Level of help provided**: Simple help (a sentence, the time, a ProgressBar, etc.)

- **How to create it**:

	- Control description window, "Help" tab

	- Programming: Function [Message](../WDLang1/3021006.md) or property [Message](../WDLang1/3021006.md)




- **How to launch Help**: Automatic launch (window must have a status Bar). 
	The information specific to a control is displayed when the control has focus.

- **For more details**: [User help](../Editeurs/2010012.md)





### Help window
<a name="help_window_ELTPARAGRAPHE000075"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Fenetre_Aide.gif)


- **Level of help provided**: Help may contain a few sentences.

- **How to create it**: Field description window, "Help" tab

- **How to launch** help: Automatic launch (F1 key).

- **For more details**: [User help](../Editeurs/2010012.md)





### Help page
<a name="help_page_ELTPARAGRAPHE000087"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P0_Aide_Browser.jpg&type=thumb)


- **Level of help provided**: Advanced help (help pages, links, summary, images, etc.).

- **How to create it**: Help editor: Click on ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) among the quick access buttons. The window for creating a new element appears: click on "Architecture", then on "Help".

- **How to launch help**: Launch by programming (function [WHelp](../WDLang1/3013053.md))

- **How to open the context help of a window or control**: 

	1. Context-sensitive help page on a control:

		- Specify the number of the page to display in the control description window.

		- Use the [WHelp](../WDLang1/3013053.md) and [NumHelp](../WDLang1/3013027.md) functions.




2. Context-sensitive help page on a window:

	- Use [WHelp](../WDLang1/3013053.md) and specify the number of the page to display.

- **For more details, see:** [Creating the help (CHM)](../Editeurs/2010002.md)





### CHM file
<a name="chm_file_ELTPARAGRAPHE000122"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P0_Aide_Browser.jpg&type=thumb)


- **Level of help provided**: Advanced help (help pages, links, summary, images, etc.).

- **How to create it**: Help editor: Click on ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) among the quick access buttons. The window for creating a new element appears: click on "Architecture", then on "Help".

- **How to launch help**: Launch by programming (function [WHelp](../WDLang1/3013053.md))

- **How to open the context help of a window or control**:

	1. Context-sensitive help page on a control:

		- Specify the number of the page to display in the control description window.

		- Use the [WHelp](../WDLang1/3013053.md) and [NumHelp](../WDLang1/3013027.md) functions.




2. Context-sensitive help page on a window:

	- Use [WHelp](../WDLang1/3013053.md) and specify the number of the page to display.

- **For more details, see:** [Creating the help (CHM)](../Editeurs/2010002.md)
