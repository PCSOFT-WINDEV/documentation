


## Search in current code
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000178"></a>
When you're writing code, you often want to do a quick search in the code.


There are several ways to do this: 

- Use the [general environmental research](../Editeurs/9000150.md) (Ctrl F).
	However, this requires using the mouse and setting the search options. 

- Use the [immediate search](#NOTE1b_1) performed on the element present in the code editor (Ctrl F3)
	This requires the "Find replace" pane to be displayed. 

- Use [QUICK SEARCH](#NOTE2_1), to search the current code (Alt F3). 




**Note**: It is also possible to access a WLanguage event of the current element. For more details, see [Access to current element events](#NOTE3_1).

## How do I make an immediate search?
<a name="how_make_immediate_search_ELTTEXTE000202"></a>
**To perform an immediate search on an element in the code editor**, simply press Ctrl F3 on an element of code editor (the "Find/Replace" pane being displayed). 

Press Ctrl + F3: 

- fills the search control with the word onto which the cursor is positioned. 

- triggers the search. 

- highlights in the code all the occurrences found and positions on the first occurrence. 





### Search in a selection
<a name="search_selection_ELTPARAGRAPHE000052"></a>

The code editor allows you to perform a search (and a replacement) in a selection. 

If a selection exceeding one line is active, the search is automatically performed in this selection. 

When performing a search in a selection, the searched word is highlighted in the code. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_Recherche_Selection.gif)
The F3 and Shift F3 keys allow you to navigate from an occurrence to another one via the keyboard.

## How to do a quick search?
<a name="how_quick_search_ELTTEXTE000232"></a>
During a quick search, the string searched for is highlighted in the code in real time as you type. The number of occurrences is displayed.

**To perform a quick search in the code**: 

1. Open a project in the editor and go to the code of an element. 

2. Press Alt + F3 to open the quick search box: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0001.gif)


3. To switch to "Find/Replace" mode, press Ctrl + R when the search box has the focus. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002.gif)

	Note: To exit the replacement mode, click on the cross or use the Esc key. 




**How the search box works**

- You cannot open multiple quick search boxes. 

- The box is closed by clicking the close button or by pressing Esc. 

- You can navigate between results by clicking the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%201.gif) buttons or by pressing F3 or Shift + F3.  

- If a single line is selected when the search box is opened, the selection is automatically pasted into the search box and the search is launched. 

- The search is automatically launched when the user enters the search box. 

- The following filter options are available: 

	- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%205.gif) Case and accent sensitive. 

	- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%206.gif) Whole word search. 

	- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%207.gif) Search using regular expressions. 




- To replace an element: 

	- Press Ctrl + R to switch to replace mode. The cursor automatically appears in the input field for the replacement text. 

	- Press Alt + R (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%203.gif)) to replace the current element and select the next. 

	- Press Enter (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%202.gif)) to replace all the elements found.




- Press Ctrl + F (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche_rapide_code%20-%20HC%20N%B0002%204.gif)) to open the search pane.

## How do I access an event in the current element?
<a name="how_access_event_the_current_element_ELTTEXTE000256"></a>


### Finding and accessing an event
<a name="finding_and_accessing_event_ELTPARAGRAPHE000116"></a>

The code editor lets you search for and access an event in the current element: window, page, status, etc. 

1. On the "Code" tab, in the "Navigation" group, type the event you want to find. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Code_Recherche_Traitement.gif)
Note: To display the event list automatically, use the Alt + C key combination.

2. Select the desired event in the list. It is automatically displayed in the code editor.
