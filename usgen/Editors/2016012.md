


## Theme elements
			





## Overview
<a name="overview_ELTTEXTE000100"></a>
The theme elements are used to quickly change the visual aspect of a project without having to retouch every page and every page template.

The theme elements include three elements:

- **[the preset page templates](../Editeurs/2016019.md)**: these are made up of fields (essentially [cells](../WDChamp/1013096.md)) and define a default layout for project pages.

- **[the theme](../Editeurs/2016020.md)** This is a standardized style sheet that can be interchanged with that of any other theme. A theme is applied to a page, to a page template or to the entire project.

- **[the color palette](../Editeurs/2016021.md)**: made up of a series of harmonious colors whose names are standardized so that they can be interchanged. It is applied to the styles of the theme to redefine the shades.






## Using theme elements
<a name="using_theme_elements_ELTTEXTE000124"></a>


### Use in a new project
<a name="use_new_project_ELTPARAGRAPHE000030"></a>

When creating a new project, the project creation wizard allows you to choose a theme and a color palette. These ones will be associated with the project and used by default in all the pages.

The theme of a project can be modified at any time in the editor. To do so:

1. Open the project description window. To do so, go to the "Project" tab, "Project" group, and select "Description".

2. Select the "Theme" tab.

3. Choose the new theme and its color palette.

4. Validate the project description window. 




When creating the pages, you will be able to choose the preset page templates to use.
