
## Allowing nullable types
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000093"></a>
Allowing nullable types in a project changes the way your project handles null values. 

It is not recommended to enable this option in existing projects. You need to make numerous changes to both the analysis and the code of your application. 

This page lists the main differences between the new and the old null value handling systems. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>
