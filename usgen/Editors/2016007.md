## Overview
<a name="overview_ELTTEXTE000434"></a>
Controls from a WEBDEV project are associated with WEBDEV styles. This style is composed of several WEBDEV element styles. 



WEBDEV element styles allow you to apply a specific characteristic to all the controls that use this element style. For example, you can create a WEBDEV element style to define the characteristics of the font used in all Button controls of a website. 
**Note**: WEBDEV element styles are based on standard CSS properties. 

**To create or edit a WEBDEV element style**:

1. Go to the "Style" tab of the control description window.

2. In "Element styles", right-click a token (or Edit control) and select one of the following options:

	- Edit element style. 

	- Create a new element style. 




3. The WEBDEV element style description window appears. 




**Remarks**: 

- This window can also be opened:

	- from the "Style" tab of the control description window, by clicking "+ overrides". In this case, changes made in the window only apply to the current control. These changes will not be propagated to other controls that use this WEBDEV element style.  

	- from the WEBDEV element style window ("Modify" option in the context menu). For more details, see [Editing WEBDEV element styles in a project](../Editeurs/2016001.md). 




- WEBDEV element styles from a skin cannot be edited. 



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Sty.gif)


This window allows you to:

- **Modify the characteristics of an existing style**. Simply select a state, change the desired style characteristics and confirm.
	**Note**: By default, changes are local to the control. They override the reference style of the current control. You can update the style from the "Style" tab. For more details, see [WEBDEV styles](../Editeurs/2016008.md). 

- **Reset selected state**. This button clears all overrides for the selected state. 

- **Reset all**. This button clears all overrides for all states. 

- **Import CSS code**. This button allows you to import CSS code to modify certain CSS characteristics of the style. In the window that appears, write the code of a desired CSS selector. 




This help page presents the different options available in the "Text" tab and in the "Background" tab. The preview is used to dynamically view the characteristics of the style.

## Text tab
<a name="text_tab_ELTTEXTE000482"></a>


### Fonts
<a name="fonts_ELTPARAGRAPHE000240"></a>

Select one of the available font families.

A font family is an organized font set. If the first font is not available on the computer of the Web user, the second font is sought. If this font is available, it is used; otherwise, the next font is sought.

The [...] button is used to create new font families as well as duplicate and modify the existing families. 

For more details, see [Font family](../Editeurs/2016022.md).
<a name="NOTE3_2"></a>


### Size
<a name="size_ELTPARAGRAPHE000262"></a>

Select the size of the font. The available sizes are:

- A defined size, specified in a specific unit (pixels, centimeters, millimeters, inches, point, pica, percentage, ...).

- A size relative to the current font (when the page is displayed):

- xx-small: Extremely small size

- x-small: Extra small size

- small: Small size

- medium: Normal size

- x-large: Extra large size

- xx-large: Extremely large size

- -1: Smaller size

- +1: Larger size



<a name="NOTE3_3"></a>


### Decoration
<a name="decoration_ELTPARAGRAPHE000280"></a>

Additional font formatting options. These options can be used, for example, to underline or cross out links.

- None: No additional decoration

- Strikethrough: Text is strikethrough. Example: a

- Underline: Text is underlined. Example: <u><u><u><u>B</u></u></u></u>

- Blinking: Text blinks (applies to Netscape only)

- Overline: A line is drawn above the text.



<a name="NOTE3_4"></a>


### Other parameters of the font
<a name="other_parameters_the_font_ELTPARAGRAPHE000296"></a>


|   |   |
| --- | --- |
| Alignment | Text layout: left-aligned, centered, right-aligned or justified (left- and right-aligned). |
| Case | Character formatting: Capitalize first letter, uppercase, lowercase or none (default). |
| Character spacing | Spacing between the letters. Specify a value that can be expressed in pixels, centimeters, millimeters, inches, point, pica, percentage, etc. |
| Color | Select the color of the font. |
| Hyphenation | Hyphenation. You can use standard hyphenation or cut the words if necessary. |
| Indent | Indent for the first line. Specify a value that can be expressed in pixels, centimeters, millimeters, inches, point, pica, percentage, ... |
| Line spacing | Line spacing. Specify a value that can be expressed in pixels, centimeters, millimeters, inches, point, pica, percentage, etc. |
| Style | Character style: normal, italic, oblique |
| Variant | Character display mode: Normal or small caps. |
| Vertical alignment | Alignment of the text in height in relation to the available area. |
| Weight | Character thickness. You have the ability to select:<br><br>- a preset weight (normal, bold, heavy, light)<br><br>- a thickness (from 100 to 900)<br><br><br> |


<a name="NOTE3_5"></a>


### Paragraphs
<a name="paragraphs_ELTPARAGRAPHE000353"></a>

You have the ability to manage the spacing before and after each paragraph. All you have to do is specify the value of the spacing and the selected unit.

## Background tab
<a name="background_tab_ELTTEXTE000530"></a>
The following characteristics can be modified in the "Background" tab:


|   |   |
| --- | --- |
| Color | Select the background color of the control. |
| Image | Image displayed in the control background. The selected image must be found in the image directory of the project (&lt;ProjectName&gt;_WEB). |
| Tiled | Repetition of the image in the control. The image can be tiled:<br><br>- in tiles (repeated option)<br><br>- horizontally (repeated X option)<br><br>- vertically (repeated Y option)<br><br><br> |
| Fixed position | If this option is checked, the image will not be scrolled when the scrollbar is used. |
| Horizontal and vertical position | Position of the image in relation to the control. The value can be expressed in pixels, centimeters, millimeters, inches, point, pica, percentage, ... |
