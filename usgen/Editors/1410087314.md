
## Cloning a theme or a theme
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000244"></a>
"Themes" and "themes" are UI templates that you can apply to a project. Themes apply to applications, while themes apply to websites.

If necessary, you can dissociate the control from the theme or theme, or override the style of the control.

In version 2024, you no longer need to override styles. A new method consists in cloning (or duplicating) an existing theme or theme, renaming it, and then directly modifying the styles, natively, without having to override them. This makes it easier to define styles. Please note that once duplicated, the theme or theme no longer benefits from any updates provided by PC SOFT.

**The principle is straightforward**: 

1. Clone [the theme](#NOTE2_1) or [the theme](#NOTE2b_1). 

2. Edit [the styles of the cloned theme template or theme](#NOTE3_1).

## Cloning a theme
<a name="cloning_theme_ELTTEXTE000268"></a>


### How to?
<a name="how_ELTPARAGRAPHE000034"></a>

To clone a theme:

1. Open the desired WINDEV or WINDEV Mobile project. 

2. On the "Project" tab, in "Other actions", expand "Project themes" and select "Clone project theme". 

3. In the window that appears, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0001.gif)


	- The theme to clone. You can choose a theme other than the one currently used in the project. 

- The name of the new theme. This name will identify the theme used. 

- The different options: 

	- **Apply cloned theme to all the windows that use the original theme**: This option automatically associates the cloned theme with the windows that use the theme to be cloned. Keep in mind you can apply the cloned theme at any time (for more details, see [Apply a theme](../Editeurs/2016011.md)). 

	- **Rename images**: This option renames all the images of the cloned theme. This makes it possible to modify the images of the new theme without accidentally modifying those of the original theme (for example, if both themes remain associated with the project). 

	- **Set as default theme for the project**: This option allows you to change the theme associated with the project (in the project description window). In this case, all new windows will use the cloned theme. 

4. Confirm. 




The selected theme is cloned in the current project. Depending on the selected options, the cloned theme is applied to the windows that use the original theme and/or becomes the project's default theme. 

The cloned theme is copied to the project directory ("Themes" subdirectory).




### Remarks
<a name="remarks_ELTPARAGRAPHE000073"></a>

- If the project contains multiple configurations (e.g. WINDEV and WINDEV Mobile), cloning WINDEV themes will apply to WINDEV configurations and cloning WINDEV Mobile themes will apply to WINDEV Mobile configurations. 

- If the same theme is cloned with the same name in two different projects, the changes made in the cloned theme in the first project are not carried over to the second project. 

- If the cloned theme is copied to the WINDEV or WINDEV Mobile theme directory, it will appear in the list of available themes. 

- If the project only uses the styles of the cloned theme, the directory of the original theme will be automatically deleted when the styles are updated. 

- Project in the SCM: 

	- When a theme is cloned, all windows are checked out to apply that theme.

	- To share a cloned theme between multiple projects, simply share the theme directory via the SCM.

## Cloning a theme
<a name="cloning_theme_ELTTEXTE000298"></a>


### How to?
<a name="how_ELTPARAGRAPHE000090"></a>

To clone a theme:

1. Open the desired WEBDEV project. 

2. On the "Project" tab, in "Other actions", expand "More actions" and select "Clone project theme". 

3. In the window that appears, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_Ambiance%20-%20HC%20N%B0001.gif)


	- The theme to clone. You can choose a theme other than the one currently used in the project. 

- The name of the new theme. This name will identify the theme used. 

- If the theme should become the project's default theme. By selecting this option, you will change the theme associated with the project (in the project description window). In this case, all new pages will use the cloned theme. 

4. Confirm. 




The selected theme is cloned in the current project. Depending on the selected options, the cloned theme becomes the project's default theme. 

The cloned theme is copied to the project directory (as a subdirectory with the name of the new theme).




### Remarks
<a name="remarks_ELTPARAGRAPHE000110"></a>

- If the project contains multiple configurations (e.g. WINDEV and WEBDEV), cloning WEBDEV themes will only apply to WEBDEV configurations. 

- If the same theme is cloned with the same name in two different projects, the changes made in the cloned theme in the first project are not carried over to the second project. 

- If you copy the directory of the cloned theme to the WEBDEV themes directory, the cloned theme will appear in the list of available themes. 

- Project in the SCM: 

	- When a theme is cloned, all pages are checked out to apply that theme.

	- To share a cloned theme between multiple projects, simply share the theme directory via the SCM.

## Editing styles
<a name="editing_styles_ELTTEXTE000328"></a>


### How to?
<a name="how_ELTPARAGRAPHE000126"></a>

When your project uses a cloned theme (or theme), you can edit the styles to suit your needs. Several methods are available. 

**Method 1: Modifying the style by propagating overrides** ("Style" tab):

1. Change the control style: 

	- Select the control for which you want to change the default style.

	- Go to the "Style" tab of the control description window. The style displayed is the style of the cloned theme (or theme), with or without overrides. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0002.gif)


	- Make the desired changes, and apply them if you want to see the result. 

2. Edit the style of the cloned theme (or theme):
	To propagate the changes (overrides) to the style of the cloned theme template or theme, you can:

	- Click the "Propagate" link in the description window.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0003.gif)


	- Expand the burger menu next to the style and select "Propagate overrides".  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0004.gif)




In this case: 

- All the controls that use the style of the cloned theme (or theme) are modified. 

- The control will appear to no longer contain any overrides. It will use a style "without overrides". 

- Other controls using the modified style will keep their own overrides, if any. 




**Method 2: Modifying a style via the "Choose a style" option**:

1. Select the control for which you want to change the default style.

2. Open the context menu and select: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) "Choose a style". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0005.gif)


	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Choose a WEBDEV style".

3. Select the desired style for the control in the modified theme (or theme). 

4. In the context menu of the style, select "Modify". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0006.gif)


5. Make the desired changes to the style in the window that appears. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cloner_gabarit%20-%20HC%20N%B0007.gif)


6. Confirm changes. 




The style of the cloned theme (or theme) is modified. These changes are automatically applied to all controls using the style from the cloned theme (or theme) in the project. All controls keep their overrides (even the control from which the changes were made). 

**Method 3: Modifying the style of a theme** (Control style):

1. Change the control style: 

	- Select the control for which you want to change the default style.

	- Go to the "Style" tab of the control description window. The style displayed is the style from the cloned theme. 

	- Make the desired changes, and apply them if you want to see the result. 




2. Edit the style of the cloned theme:
	To apply the changes made in the control to the style of the theme, you can:

	- Click the "Change style" link in the description window. 

	- Expand the burger menu next to the style and select "Change style". 





In this case: 

- All the controls that use the style of the cloned theme are modified. 

- The control keeps its overrides. 

- Other controls using the modified style will keep their own overrides, if any.
