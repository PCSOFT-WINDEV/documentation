
## Text editing in the code editor
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000174"></a>
When developing a new feature, it may be useful to open text files without leaving the development environment. 

The code editor can open text files and apply syntax highlighting (if the programming language is supported). 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Opening a text file
<a name="opening_text_file_ELTTEXTE000207"></a>
To open a text file in the code editor:

- Drag the file and drop it onto the project editor. 

- Go to the "Home" tab, "General" group, expand "Open" and select "Open". Select the text file you want to open. 

- If the file is in the "Project explorer" pane, double-click its name. 



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_texte_code%20-%20HC%20N%B0001.gif)





### Information shown in the editor
<a name="information_shown_the_editor_ELTPARAGRAPHE000042"></a>

Once the file is open in the code editor, a specific banner shows some file details, which can be modified if necessary. 

The following information is displayed: 

- text file language, 

- encoding, 

- end-of-line type. 




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Information details
<a name="information_details_ELTTEXTE000237"></a>


### Language and syntax highlighting
<a name="language_and_syntax_highlighting_ELTPARAGRAPHE000057"></a>

The language of the file appears first. Language detection is based on the file extension.

To change the language of the file:

1. Click the name of the current language. An alphabetical menu appears. 

2. Select the initial letter, then the desired language. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_texte_code%20-%20HC%20N%B0002.gif)



Syntax highlighting is automatically applied according to the characteristics of the selected language. 

Remarks: 

- Syntax highlighting is not applied to .txt files. 

- Many languages are supported. For example:

### File encoding on disk
<a name="file_encoding_disk_ELTPARAGRAPHE000106"></a>

Encoding is automatically detected when the file is opened. UTF-8 encoding is used by default when you create a new text file. 

To change the encoding of a file:

1. Click the current encoding. The list of available encodings appears.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_texte_code%20-%20HC%20N%B0003.gif)


2. Select the desired encoding. 

3. Save the file.





### End-of-line type
<a name="endofline_type_ELTPARAGRAPHE000118"></a>

You can view and change the end-of-line delmiter used by the file. This is automatically detected when the file is opened. 

To change the end-of-line delimiter of the file:

1. Click the current delimiter.  

2. Select the desired delimiter. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_texte_code%20-%20HC%20N%B0004.gif)


3. Save the file.
