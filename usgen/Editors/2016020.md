


## Themes
			





## Overview
<a name="overview_ELTTEXTE000138"></a>
The themes are used to standardize the visual aspect of a site and they allow you to easily change style.

A theme includes:

- a style sheet containing WEBDEV styles.

- an image directory.

- a default color palette.

- a set of reports used as base to build the new project reports.




Let's take a look at these elements: 

- The style sheet: 
	**Note**: A style sheet includes WEBDEV styles. Each WEBDEV style groups: 

	- one or more CSS styles, 

	- values of properties for the control.
			A WEBDEV style applies to a specific type of control.
			The styles of a theme have standardized names. Therefore, the themes can be interchanged between themselves.




- The images: 
	The images supplied with the theme are used to define the visual aspect of the cells, tables, tab controls, etc.

- The color palette: 
	The default color palette of a theme can be replaced with any other color palette. For more details, see [Color palettes](../Editeurs/2016021.md).






## Sequence for applying the themes
<a name="sequence_for_applying_the_themes_ELTTEXTE000162"></a>
The theme of a page can be defined at three different levels (in descending order of priority):

- In the project.

- In the page template from which the page inherits the properties.

- In the page itself.




The general theme must be defined at project level. 

If a set of pages (e.g., "Promotion" pages of an e-commerce site) must use a specific theme, you can redefine the project theme as a page template. 

If a particular page must have a different theme, this theme can be chosen for the page itself.



## Using the themes
<a name="using_the_themes_ELTTEXTE000186"></a>


### Choosing the theme of a project
<a name="choosing_the_theme_project_ELTPARAGRAPHE000055"></a>

To choose the theme of a project:

1. On the "Project" tab, in the "Project" group, click "Description".

2. Select the "Theme Styles" tab.

3. Choose a theme among the proposed ones (as well as its color palette) and validate. 





### Changing the theme of a page or page template
<a name="changing_the_theme_page_page_template_ELTPARAGRAPHE000076"></a>

To change the theme of a page or page template:

1. Select "Description" in the context menu of the page.

2. Select the "Style" tab.

3. Click the browse button to select a theme.

4. If the selected theme is "None", the project theme will be used.






## Updating themes
<a name="updating_themes_ELTTEXTE000216"></a>
If a theme used by a project was updated (which means modified), WEBDEV proposes to update this project when it is opened. 

You have the ability not to select this new version of the theme, the previous theme being directly stored in each project.
