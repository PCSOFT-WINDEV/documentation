
## AI companion in the environment
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000112"></a>
Starting with version 2026, the development environment features a conversational AI companion. 

This conversational companion is displayed in the "AI companion" pane of the development environment. 

The AI companion can:

- answer your questions in "Conversation" mode. You can ask questions about the code of your project and its components. 
	The companion allows you, for example, to search your code, get help to perform an action, summarize the action of a procedure, etc.

- perform an action on your project in "Action" mode. 
	For example, the companion can create queries, database schemas, files, etc. Simply describe the desired action using natural sentences, for example "Generate a query that selects the customers in a state", "Create a table to store orders", "Change all variables to uppercase", etc. 




One of the advantages of conversational AI is that you can refine and clarify your requests. 
The companion can also ask questions for further clarification. 
This translates into precise results.

## Prerequisites
<a name="prerequisites_ELTTEXTE000136"></a>
To use an AI companion, you need an account with access to APIs from the respective AI providers. This account will enable you to use the API from a given provider. An API key is attached to this account

You must specify the AI model and corresponding API key details in the WINDEV Suite options. 

Remarks:

- The API account creation process may be different according to the provider. Please refer to the provider's website for further details.

- The name used for the API account may be different according to the provider.

- Your API account must be associated with a payment method. Depending on the provider, you can fund your credit balance or be billed at the end of the month.

- If you reach the usage limits of your plan, a "quota exceeded" notification will appear.

## Using the AI companion
<a name="using_the_companion_ELTTEXTE000160"></a>
To use conversational AI:

1. Open the "AI Companion" pane. To do so, go to the "Home" tab, "Environment" group, expand "Panes" and select "Panes" then "AI companion".

2. Click "New conversation". 

3. Choose between conversation and action modes. 

4. Describe your request and confirm.

<a name="NOTE4_1"></a>


## The companion has access to your project and can perform a series of operations on it
<a name="the_companion_has_access_your_project_and_can_perform_series_operations_ELTTEXTE000184"></a>
Whether in conversation or action mode, the companion analyzes your project using various tools. These tools enable the AI companion to list the elements in your project, read their code, etc.

When you ask a question, the AI engine executes the tool(s) to obtain an answer or perform a search. It is possible to use a sequence of tools to answer a question or perform an action. The tools used are automatically indicated in the conversation pane.
