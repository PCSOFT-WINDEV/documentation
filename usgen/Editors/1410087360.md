


## Project description: Theme tab
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000148"></a>
The project description window allows you to configure various elements of your project. This window includes the following tabs:

- The ["Project"](../Editeurs/2030046.md) tab, which allows you to enter general information about the project.

- The "Database Schema" tab, which allows you to associate one or more database schemas with the project and/or a UML model.

- The ["Tables"](../Editeurs/2030052.md) tab, which allows you to enter information about the tables used by the application. This tab is only available if the project uses a database schema.

- The "Live Data" tab, which allows you to configure how the data from the tables is displayed in the different editors.

- The ["Languages"](../Editeurs/9500219.md) tab, which is used to configure the different languages used by the project as well as the options to be used for each language.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The ["Style"](../Editeurs/9500234.md) tab, which allows you to customize the print preview and to choose the theme and custom style sheet. You can also configure screen sizes.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The **"Ambiance" tab** lets you choose the project theme, palette, style sheet and external resources. 

- The ["SCM"](../Editeurs/9500239.md) tab, which is used to manage teamwork (SCM or Git).

- The ["Options"](../Editeurs/9500227.md) tab, which allows you to define the creation, update and save options of the different elements of the project. This tab also allows you to synchronize templates, enable strict mode and define the code style.

- The ["Advanced"](../Editeurs/9500236.md) tab, which allows you to enable "Reports and Queries", configure the AAFs and lock the application.

- The ["Compilation"](../Editeurs/9500218.md) tab, which allows you to configure the compilation options.

- The ["Telemetry"](../Editeurs/9500223.md) tab, which allows you to configure the telemetry options for the project. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This option is not available.

## Theme tab
<a name="theme_tab_ELTTEXTE000229"></a>


### Theme of the project
<a name="theme_the_project_ELTPARAGRAPHE000033"></a>

The "Theme" tab of the project description window allows you to identify and define the theme used by the project. A preview shows the theme in use.

**Note**: If the theme is modified via the project description window, this modification is only taken into account for new pages. To apply a theme to existing pages you need to go to each individual page:

1. Open the desired page in the editor. 

2. On the "Page" tab, in the "Theme and styles" group, select "Theme". 

3. In the window that appears, select the desired theme and the associated palette. 

4. Confirm. 





### Project palette
<a name="project_palette_ELTPARAGRAPHE000053"></a>

Color palettes define a set of colors that are available in all the color pickers of the project.

These colors are also applied to the styles defined in the project theme in order to easily change the visual aspect of a project.

The "Theme" tab allows you to view and modify the color palette associated with the theme. 

**Note**: If the palette is modified via the project description window, this modification is only taken into account for new pages. To change the palette used by an existing page you need to go to each individual page: 

1. Open the desired page in the editor. 

2. On the "Page" tab, in the "Theme and styles" group, expand "Palette" and choose one of the palettes associated with the current theme. 




The project description window also allows you to view all available palettes and to create a color palette. For more details, see [Color palettes](../Editeurs/2016021.md).  


### Theme options
<a name="theme_options_ELTPARAGRAPHE000080"></a>

You can also: 

- Choose the **theme language**. Themes are available in English and French. 

- Apply the theme to the dialog boxes (YesNo and OKCancel): If this option is selected, the dialog boxes displayed by the site will use the characteristics of the theme. 





### Style sheets
<a name="style_sheets_ELTPARAGRAPHE000091"></a>

You can: 

- Select the style sheet(s) associated with the project. 

- Add external resources (JavaScript files or external CSS style sheets). CSS style sheets are automatically loaded when the project is opened.  




For more details, see [Including JavaScript files or a Web resource](../Editeurs/1012027.md).
