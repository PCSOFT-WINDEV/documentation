


## SCM: Checking out an element
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000176"></a>
To edit an element of a project hosted on an SCM repository, you must first check out the element.

Two check-out modes are available:

- Automatic check-out (default): You will be automatically prompted to check out the element the first time you try to modify it.

- Manual check-out: You must request the check-out before editing the element.




**To change the check-out mode**: 

1. On the "Home" tab, in the "Environment" group, expand "Options" and select "WINDEV/WEBDEV/WINDEV Mobile general options".

2. Select the "General" tab. The "Check out elements on first modification" option switches all currently open projects to automatic mode. 

3. Validate. 




**Special case: Before generating the database schema**, it is recommended to get the latest version of all project elements. Checked-out elements cannot be modified. This means they cannot be synchronized with the database schema. Therefore, make sure that:

- all the elements of the project are checked in,

- the latest version of the project elements is found on the computer where the database schema is generated.

## Checking out an element
<a name="checking_out_element_ELTTEXTE000200"></a>


### How to check out an element?
<a name="how_check_out_element_ELTPARAGRAPHE000050"></a>

- **1st solution: Automatic check-out**:

	1. Open the element in the editor.

	2. Make the desired changes. When you confirm changes, the SCM automatically prompts you to check out the element to apply those changes. If you accept, changes are applied to the checked-out element. If you don't accept, the element is not modified.




- **2nd solution: Check-out request** (available in manual or automatic check-out mode):

	- In the "Project explorer" pane:

		1. Select the element in the "Project explorer" pane.

		2. Select "Check out" in the context menu of the element. 




- In the ribbon:

	1. Open the element in the editor. 

	2. On the "SCM" tab, in the "Current element" group, click "Check out" (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Barre_outils%20-%20HC%20N%B0002%206.gif)).

- **3rd solution: Manual check-out**:

	1. Open the element in the editor. An orange panel indicates that the element has not been checked out and that it cannot be modified.

	2. In the orange panel, click the check-out icon to modify the element.






<a name="NOTE2_2"></a>


### Checking out an element
<a name="checking_out_element_ELTPARAGRAPHE000084"></a>

Regardless of the method, the SCM offers the following check-out options: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0012.gif)
The check-out mode can be:

- ***Exclusive***: This element will not be available until it is checked back in. The element can be checked out for tests only.

- ***For test***: The element can be modified, but changes won't be checked in.

- ***Multiple***: Other users will also be able to check out the element. In this case, the differences between the element versions can be viewed when the element is checked back in.




When you click OK, the element is checked out and opened in the editor. The title bar indicates that the element is checked out.

**Remarks**:

- If you try to modify the source code of an element that is not checked out, the Source Code Manager automatically proposes to check out the element.  

- If you select "Don't show again", you can re-enable this window via the [SCM administrator options](../Editeurs/2038023.md).



<a name="NOTE2_3"></a>


### Checking out an element already checked out in exclusive mode
<a name="checking_out_element_already_checked_out_exclusive_mode_ELTPARAGRAPHE000107"></a>

The SCM will show you a notification if the element you are trying to check out has already been checked out in exclusive mode by another user. 

You can:

- See the characteristics of checked-out element ("Properties").

- Send a message to the person who checked out the element ("Send a message" button). 
	**Reminder**: WINDEV, WEBDEV and WINDEV Mobile include a messaging tool. This tool uses the parameters specified in the control centers (users, files location, etc.). To open the messaging tool, on the "Tools" tab, in the "Control Centers" group, click "WDBal - Messaging".

- Check out the element for test only. In this case, the changes made to the element will be ignored in the reference project (on the SCM server).
