
## WINDEV theme generator: Customize elements
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000477"></a>
The generator of WINDEV themes is used to generate the necessary files for creating a custom theme for the WINDEV projects. 

You have the ability to customize the generated elements: 

- [Images](#NOTE2_1): these images will be used in the style of controls. 

- [Window templates](#NOTE3_1). 

- [Report templates](#NOTE4_1). 




This help page presents the main images used as well as the modifications that can be performed. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Images of theme
<a name="images_theme_ELTTEXTE000501"></a>


### Tips
<a name="tips_ELTPARAGRAPHE000030"></a>

- The extension of the image files can be modified. The following formats can be used: JPG, PNG and GIF.

- In order for an image not to be used in a control, simply make it transparent and set its size to 1x1 pixel. In this case, the image must be in PNG format. Therefore, the image will not be generated when generating the theme.

- In order for the images to be properly display in your themes, don't modify the dimensions of the files.

## Window templates
<a name="window_templates_ELTTEXTE000531"></a>
The window templates are found in the "Template" directory of the source project of the theme. The available window templates are: 

- Modele.wdt: General template for your windows. This template is used to define the background of your windows (background color, background image, ...). 

- Modele_Menu.wdt: Template used for menu windows. 

- Modele_MessBox.wdt: Template used for message box windows. 

- Modele_Popup.wdt: Template used for Popup windows. 

- Modele_Preview.wdt: Template used for print previews. 




To customize the window templates, simply open them in WINDEV. We advise you to open these elements in WINDEV **outside the project** (Drag and Drop the element to WINDEV for example).

<a name="NOTE4_1"></a>


## Report templates
<a name="report_templates_ELTTEXTE000555"></a>
The report templates are found in the "Template" directory of the source project of the theme. The available report templates are: 

- Modele_Etats.wte: General state model. 

- Modele_Etiquette.wte: Template used for Etiquette reports. 

- Modele_Mailing.wte: Template used for Mailing reports. 




To customize the report templates, simply open them in WINDEV. We advise you to open these elements in WINDEV **outside the project** (Drag and Drop the element to WINDEV for example).
