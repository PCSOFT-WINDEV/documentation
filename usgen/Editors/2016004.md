


## WEBDEV element styles
			





## Overview
<a name="overview_ELTTEXTE000132"></a>
Controls from a WEBDEV project are associated with WEBDEV styles. WEBDEV styles are composed of multiple WEBDEV element styles. 

WEBDEV element styles allow you to apply a specific characteristic to all the controls that use this element style. For example, you can create a WEBDEV element style to define the characteristics of the font used in all Button controls of a website. 
**Note**: WEBDEV element styles are based on standard CSS properties. 

In WEBDEV, you can manage WEBDEV element styles as required. You can: 

- [Create a WEBDEV element style](#NOTE3_1).

- [Edit a WEBDEV element style](#NOTE3_2).

- [Associate a WEBDEV element style with a control](#NOTE3_3).

## Managing WEBDEV element styles
<a name="managing_webdev_element_styles_ELTTEXTE000156"></a>


### Creating and editing a WEBDEV element style
<a name="creating_and_editing_webdev_element_style_ELTPARAGRAPHE000037"></a>

You can create and edit WEBDEV element styles:

- [from the control style description window](#NOTE3_2). 

- from the WEBDEV element style management window. For more details, see [Editing WEBDEV element styles](../Editeurs/2016001.md). 



<a name="NOTE3_2"></a>


### Creating and editing a WEBDEV element style from the control style description window
<a name="creating_and_editing_webdev_element_style_from_the_control_style_description_window_ELTPARAGRAPHE000052"></a>

You can manage the style of a control in the "Style" tab of the control description window. Several elements can be adjusted in the "Style" tab. You can associate different styles with a specific element. For example, for a List Box control: 

- you can use a style for the text of the control.

- you can use a style for the elements within the control (input area).




The element style can be modified or overridden. 

- If it is modified, changes will be applied to all the controls that use this element style. 
	To edit an element style, right click the corresponding token and select "Edit element style" in the context menu. 

- If it is overridden, these overrides will be taken into account locally, for the current control. Other controls using this element style will not be affected by the change. 
	To override an element style, change the options in the "Style" tab of the control. Click "+ overrides" for more options. 
	 Note: Local overrides are not recommended, as they increase the size of the resulting HTML pages. This means pages will take longer to load on the browser.




For more details on the description of a WEBDEV element style, see [WEBDEV element style description window](../Editeurs/2016007.md).
<a name="NOTE3_3"></a>


### Associating a WEBDEV element style with a control
<a name="associating_webdev_element_style_with_control_ELTPARAGRAPHE000078"></a>

To associate a WEBDEV element style with a control:

1. Open the control description window.  

2. In the "Style" tab, select the element with the style you want to edit: Input area, Caption, etc.

3. In "Element styles", add the desired element styles by selecting them from the list. 

4. Validate the control description window.
