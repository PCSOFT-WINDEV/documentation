
## Software Factory administrator
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000165"></a>
The Software Factory administrator allows you to:

- [manage action plans: execution, settings, etc.](#NOTE2_1)

- [manage action plan schedules](#NOTE3_1). 

- [manage robots](#NOTE4_1). 

- [manage action plans in the warehouse](#NOTE5_1). 

- [set administrator options](../Editeurs/1000019583.md). 




The various options are grouped together in the different Software Factory administrator tabs. To launch the Software Factory administrator:

1. On the "Tools" tab, in the "Utilities" group, click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens.

## Managing action plans
<a name="managing_action_plans_ELTTEXTE000189"></a>
The "Action plans" tab shows the different users, owners and last run dates. 

You can: 

- Run the selected action plan(s),

- Refresh the UI. 

- Use an action plan. This option adds an action plan to the current user's action plan list. When adding an action plan, you must:

	- Select the action plan to be added from the list of action plans in the warehouse. 

	- Configure the action plan. This options creates a plan instance (also called a "custom action plan"). In these settings, you can define the description, action plan parameters, notifications and associated labels. 




- Delete the settings. In this case, the settings that are specific to the action plan will be deleted. 

- Edit the settings. This option allows you to edit the action plan options. In particular, you can define the schedule and execution options. 

- Duplicate the settings. This option clones the settings of the current action plan. This option allows you to easily create new settings by reusing most of the options of the current settings. 

- Schedule the action plan. You can schedule the execution of the action plan via a wizard.

## Schedule management
<a name="schedule_management_ELTTEXTE000213"></a>
The "Schedule" tab shows the schedules defined for the action plans of the current user. You can add, change or delete a schedule. 

The "Show schedules of all custom action plans in the warehouse" option lists all the action plans with a schedule.

## Manage robots
<a name="manage_robots_ELTTEXTE000237"></a>
The "Robots" tab shows the robots managed by the coordinator and the action plans currently in progress. 

Several actions are available:

- Add or delete a robot. 

- Edit a robot. This option allows you to associate a label with a robot. 
	Labels can be associated with a custom action plan and with a robot. An action plan with one or more labels will be run on the robot with the same label.





You can also manipulate the action plan spool. You can: 

- Delete an action plan,

- Define the order of execution of action plans.

## Managing action plans in the warehouse
<a name="managing_action_plans_the_warehouse_ELTTEXTE000270"></a>
The "Warehouse" tab lists all libraries and action plans that have been deployed on the coordinator. 

These action plans are ready to be used. When an action plan is used, a copy of the action plan is automatically created. To use an action plan:

- Select the action plan,

- Click "Configure action plan". 


The action plan will appear in the "Action plans" tab. 

This tab allows you to:

- Add a library. This option lets you add an action plan library generated but not deployed. For more details, see [Deploying an action plan](../Editeurs/1000019571.md).

- Update, delete or edit action plan libraries.

- Configure or edit action plans. 

	- The "Configure action plan" option allows you to create a custom action plan, which will be displayed in the "Action plans" tab. 

	- The "Edit action plan" option opens the details of the action plan, and shows all the custom plans created from the current action plan.
