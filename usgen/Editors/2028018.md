


## WDInst: Set automatic modification of tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000195"></a>
The automatic table modification updates the description of tables on user computers.

For more details, see [Automatic table modification](../WDLang4/3044195.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Configuring the automatic table modification in WDInst
<a name="configuring_the_automatic_table_modification_wdinst_ELTTEXTE000219"></a>
The automatic table modification must be configured:

- in the setup options ("Setup settings .. HFSQL files").

- in the description of each ".EXE" file that uses tables to be modified ("File description" window),




To discover the different elements in the WDInst UI, see [WDInst interface](../Editeurs/2028022.md)

The following paragraphs present the automatic modification in the following cases:

- the automatic modification of HFSQL Classic tables.

- the automatic modification of Hyper File 5.5 tables or the migration from Hyper File 5.5 to HFSQL Classic.



<a name="NOTE2_2"></a>


### Running the automatic modification of WINDEV tables
<a name="running_the_automatic_modification_windev_tables_ELTPARAGRAPHE000040"></a>

To run the automatic modification of WINDEV tables:

1. Select "Setup settings .. HFSQL files".

2. Check "Run the automatic data modification". 

3. Specify the operating mode of the automatic data modification:

	- "Automatic data modification without GUI" enables the automatic data modification without allowing any action from the user. 
			This option is available by default when the application's setup program is configured via the wizard. 

	- the option "Ask for confirmation before running the automatic table modification" is used to display the list of modified tables and to ask the end user for confirmation. 

	- the option "Display the advanced options of the automatic data modification" is used to display a specific window to the end user (see [Updating with automatic table modification](#NOTE3_1)). 




4. Specify (if necessary) the password associated with the database schema. 

5. Validate the window for setup options. 

6. In the "List of setup files" window, select the executable file (".EXE") on which the automatic table modification must be performed. On the "HFSQL" tab, check "Manage automatic data modification". 

7. Click the "Advanced" button.

8. Select (if necessary) the database schema in WINDEV format (".WDD" file) associated with the application.

9. For each table of the database schema, specify (if necessary) the password of the table (if it exists). 
	To change this password, select "Change password" and enter the new password.


**Note**: If automatic modification is to be performed on tables used by several ".EXE" files, repeat the operations for all ".EXE" files concerned.
<a name="NOTE2_3"></a>


### Running the automatic modification of HFSQL Classic tables or migrating from Hyper File 5.5 to HFSQL Classic
<a name="running_the_automatic_modification_hfsql_classic_tables_migrating_from_hyper_file_55_hfsql_classic_ELTPARAGRAPHE000078"></a>

To run the automatic modification of Hyper File 5.5 tables or to migrate Hyper File 5.5 tables to HFSQL Classic, follow the same steps. 

In the "List of setup files" window: 

1. Select the executable (".EXE") file on which automatic table modification should be run.

2. In the "HFSQL" tab: 

	- Check "Manage the automatic data modification".

	- Check "Manage Hyper File 5.5 files".

	- Click the "Advanced" button.




3. Select the database schema in HFSQL Classic format (".WDD" file) associated with the application.

4. For each table of database schema, specify if necessary:

	- the password of the table (if it exists) in the database schema in WINDEV format.
			Note: To change this password, check the "Change password" option and enter the new password twice.

	- if the application uses a migrated WINDEV 5.5 database schema:

		- the source database schema in WINDEV 5.5 format (".WDA" file).

		- the name of the table in the database schema in WINDEV 5.5 format.

		- the password of the table (if it exists) in the database schema in WINDEV 5.5 format.







**Note**: If automatic modification is to be performed on tables used by several ".EXE" files, repeat the operations for all ".EXE" files concerned.

## Updating an application with automatic table modification
<a name="updating_application_with_automatic_table_modification_ELTTEXTE000255"></a>
When installing an update with automatic modification of tables, the user can configure automatic modification: an "Advanced options" button is then displayed in the foreground of the installation program. The following window is displayed: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Param%E9trer_modif_auto_des_fichiers%20-%20HC%20N%B0001.gif&type=thumb)
This window allows you to:

- create a report of the operations performed by the automatic data modification. If a problem occurs, this file can be given to the application manager. 
	By default, this file is named "LOGMODAUTO.TXT" and it is created in the installation directory of the application.

- list the HFSQL tables on which the automatic modification will be performed. You will have the ability to add to this list:

	- additional tables.

	- additional directories containing tables.




- specify additional directories containing tables in Hyper File 5.5 format that are not automatically found during the update.




**Note**: When updating, the tables automatically found are:

- the files found in the installation directory of the application.

- the files listed in the ".REP" file. For more details, see the help about the [management of .REP files](../WDLang4/3044186.md).




To prevent the user from accessing the options used to configure the automatic modification, the setup editor WDInst allows you to make the "Advanced" button invisible in the setup program.
<a name="NOTE3_2"></a>


### Making the "Advanced" button invisible
<a name="making_the_advanced_button_invisible_ELTPARAGRAPHE000139"></a>

To make the "Advanced" button invisible:

1. Select "Setup settings .. HFSQL files".

2. Check "Automatic data modification without GUI".
