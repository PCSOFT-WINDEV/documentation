
## Software Factory: Rights management
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000237"></a>
You can implement a rights management system to secure the execution of action plans. This system can be implemented by users logged in as "Administrator" in the Control Center database. 

This means it will be possible to define different permissions for an intern and an experienced developer, for example. 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Rights management
<a name="rights_management_ELTTEXTE000270"></a>
You can define permissions for:

- [a Software Factory](#NOTE3_1), 

- [an action plan library](#NOTE3_2), 

- [an action plan](#NOTE3_3), 

- [a custom action plan](#NOTE3_4). 




You can define one or multiple permissions for each element. Each permission can have one of the following values:


|   |   |
| --- | --- |
| Allowed | The user is allowed to use the feature. |
| Forbidden | The user is not allowed to use the feature. If the user attempts to use this feature, a notification will appear, indicating that they do not have sufficient rights. |
| Inherited | The permission is not defined at this level. The permission defined at the higher level is used:<br><br>- permissions defined at action plan level apply to custom action plans.<br><br>- permissions defined at library level apply to action plans. <br><br>- permissions defined at Software Factory level apply to libraries.<br><br><br> |

## Available permissions and implementation
<a name="available_permissions_and_implementation_ELTTEXTE000294"></a>


### Software Factory permissions
<a name="software_factory_permissions_ELTPARAGRAPHE000059"></a>

The following permissions are available for the **Software Factory**:

- Add or delete the configuration of an action plan. 

- Edit action plan settings.

- Execute an action plan.

- Add, edit or delete an action plan library.

- Change the Software Factory configuration. This permission affects:

	- adding, pausing or deleting a robot. 

	- changing the priority order of robots. 

	- adding or deleting labels. 

	- changing labels associated with robots. 

	- changing the value of environment variables. 







To define these permissions:

1. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens. 

4. In the "Options" tab, click "Software factory permissions". 

5. Specify the permissions for each user and confirm changes. 



<a name="NOTE3_2"></a>


### Library permissions
<a name="library_permissions_ELTPARAGRAPHE000098"></a>

The following permissions are available for a **library**:

- Add or delete the configuration of an action plan

- Edit action plan settings

- Execute an action plan

- Add, edit or delete an action plan library




To define these permissions:

1. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens. 

4. In the "Warehouse" tab, select a library, then click "Edit library". 

5. In the library description, click "Library permissions". 

6. Specify the permissions for each user and confirm changes. 



<a name="NOTE3_3"></a>


### Action plan permissions
<a name="action_plan_permissions_ELTPARAGRAPHE000131"></a>

The following permissions are available for an **action plan**:

- Add or delete the configuration of an action plan.

- Edit action plan settings.

- Execute an action plan.




To define these permissions:

1. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens. 

4. In the "Warehouse" tab, select an action plan from a library, then click "Edit action plan". 

5. In the action plan description, click "Action plan permissions". 

6. Specify the permissions for each user and confirm changes. 



<a name="NOTE3_4"></a>


### Custom action plan permissions
<a name="custom_action_plan_permissions_ELTPARAGRAPHE000163"></a>

The following permissions are available for a **custom action plan**:

- Add or delete the configuration of an action plan.

- Edit action plan settings.

- Execute an action plan.




To define these permissions:

1. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

2. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

3. The Software Factory administrator opens. 

4. In the "Action plans" tab, select a custom action plan and click "Edit settings". 

5. In the action plan description, click "Permissions". 

6. Specify the permissions for each user and confirm changes.
