
## Environment of the data model editor 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The environment of the data model editor is as follows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=EnvEditeurAnalyses.gif&type=thumb)


The main elements of the WINDEV data model editor are the following:


|   |   |
| --- | --- |
| ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CERCLE1.gif) | **Editor menu**<br>Gives quick access to the main features of the data model editor. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle2.gif)<br> | **Database schema graph**<br>Scrollbars allow you to scroll through the graph elements (database schema with several tables). You also have the ability to zoom in the graph to better view the database schema elements (Ctrl + mouse wheel). |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle3.gif)<br> | **[Database schema pane](../Editeurs/2027012.md)**<br>Lists the different tables present in the current database schema. Simply expand the desired table to see the names and types of its items. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle4.gif)<br> | **Table description window**<br>Allows you to:<br><br>- view and/or change the characteristics of the table.<br><br>- open the description window of the items in the table.<br><br><br> |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle5.gif)<br> | **[Open documents](../Editeurs/2029012.md)**<br>Displays a button for each document opened in the editor. To display the requested element in the foreground, click the corresponding "button". |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle6.gif)<br> | **Browser window**<br>Used to see all elements found in the opened folder. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Cercle7.gif)<br> | **Description of items**<br>Opens the description of the items in the current table. |
