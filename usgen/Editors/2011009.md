## Creating an item
<a name="creating_item_ELTTEXTE000250"></a>
To create an item: 

1. Double-click the table where the item will be created. The description window of file items is displayed.

2. Click the first empty row in the table of items or click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%201.GIF).

3. In the table, specify: 

	- the item name,

	- the item caption,

	- the item type and its size if necessary, 

	- whether the item concerns personal data (GDPR checkmark). For more details, see [Defining the "Personal data" items](../Editeurs/1410086744.md).


 Note: For more details on the different types of rubrics, see [The different types of items](../Editeurs/2011026.md).

4. In the right section of the window, indicate the details of the new item (type of key, sort order, format, etc.).

5. Validate the item description.

## Handling an item
<a name="handling_item_ELTTEXTE000274"></a>


### Duplicate/Copy an item
<a name="duplicatecopy_item_ELTPARAGRAPHE000068"></a>

When creating an item whose name is identical to the name of an existing item, WINDEV, WEBDEV and WINDEV Mobile automatically propose to use the description of initial item.

An item can also be duplicated: 

- in the same file.

- in a different file.  




**To duplicate a heading in the same file**directly from the heading description window: 

1. Select the item you want to duplicate in description window of a table's items.

2. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%2013.gif). The item is automatically duplicated. Its name is the name of the original item suffixed with a number.


Remarks: 

- Alternatively, you can use the "Duplicate" option in the context menu of the item to be duplicated.

- The "Copy", "Paste before" and "Paste after" options in the context menu can also be used to perform these operations. 




**To duplicate an item in another file**: 

1. Select the item you want to duplicate in description window of a table's items.

2. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%2010.gif). 

3. In the window that appears, indicate the file description in which the item is automatically duplicated. 

4. Confirm. The item appears in the description of the selected file.



<a name="NOTE3_2"></a>


### Delete an item
<a name="delete_item_ELTPARAGRAPHE000105"></a>

To delete an item:

1. Select the item to delete in the description of file items.

2. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%202.gif). The item is automatically deleted from the table.




**Remarks**: 

- When creating an item whose name is identical to the name of an item that was previously deleted, WINDEV, WEBDEV and WINDEV Mobile automatically propose to restore the description of deleted item.

- Deleting an item triggers the deletion of data during the next automatic data modification, even if a new item with the same name is created.

- The ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%2012.gif) button or the "Cut" option in the field's context menu can also be used to delete the field. 



<a name="NOTE3_3"></a>


### Rename an item
<a name="rename_item_ELTPARAGRAPHE000127"></a>

To rename an item:

1. Select the item to rename in the description of file items.

2. Type the new item name.

3. Confirm changes. The item is automatically renamed.



<a name="NOTE3_4"></a>


### Use a dictionary
<a name="use_dictionary_ELTPARAGRAPHE000138"></a>

An item can be included in a dictionary in order to be re-used in a new application for example. To add an item to a dictionary, you just have to drag it from the data model editor and drop it onto the dictionary (in the ["Dictionary" pane](../Editeurs/2027014.md)).

When it is included in a dictionary, the item description can subscribe to the modifications. Any modification performed in the item description will be applied to the dictionary object and to all uses of this object.

For more details, see [Dictionary](../Editeurs/2023002.md).

## Sorting the items displayed in the table description
<a name="sorting_the_items_displayed_the_table_description_ELTTEXTE000316"></a>
Table items can be displayed according to the following criteria:

- logical order. 

- physical order. 

- alphabetical order.




To modify the display order of items: 

1. Double-click the table. The description window of file items is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001.gif&type=thumb)


2. The buttons found in the "Display" section are used to sort the items displayed in this window: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%203.gif)


	- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%204.gif) sorts in alphabetical order. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%205.gif) sorts he items and indexes in physical order. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0002.gif) sorts the items in logical order. 

3. Use the funnel in the "Name" column (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Manipulations_rubriques%20-%20HC%20N%B0001%206.gif)) to perform a search: simply click on the funnel and enter the letters of the heading you're looking for. All matching items will be displayed.
