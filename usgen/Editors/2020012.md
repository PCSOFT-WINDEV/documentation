<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000109"></a>
The development environment opens automatically when WINDEV, WEBDEV and WINDEV Mobile are first launched. This environment includes all the latest options you may need in your projects. 

Note: Custom environment options from previous versions (if any) are automatically retrieved. 







<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Environment options
<a name="environment_options_ELTTEXTE000142"></a>
The default development environment offers the following options:

- Dark theme (environment and code). 
	For more details, see [Editor themes](../Editeurs/2036001.md). 

- Prefix syntax. 

- Generic vocabulary in the UI (Table). 
	For more details, see [Choice of vocabulary](../Editeurs/2036001.md). 

- Lowercase for keywords in the code editor. 
	For more details, see [Code editor options](../Editeurs/9000218.md). 

- Automatic documentation of procedures in Doxygen format. 
	For more details, see [Code editor options](../Editeurs/9000218.md). 

- Text format for all project elements. 

- Code style disabled. 
	For more details, see [Code style](../Editeurs/9000074.md). 

- Support of nullable types. 
	For more details, see [Allowing nullable types](../Motscles/1511031.md). 




You can change these options at any time.
