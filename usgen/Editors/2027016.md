<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000094"></a>
The "UML database schema" pane displays the different UML diagrams (class diagram, deployment diagram, ...) of the current project.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=VoletAnalyseUML.gif)
The context menu (right mouse click) of the "UML database schema" pane is used to:

- Create a new UML model. The UML model associated with the project can contain several UML diagrams.

- Open a UML model.

- Open the UML model of the current project.

- Display the description of the diagrams.

- Open and close the diagrams.

- Rename the diagrams.

- Delete the diagrams.




If no UML model is associated with the current project, the "UML database schema" pane proposes to create a new model.

## Displaying the "UML database schema" pane
<a name="displaying_the_uml_database_schema_pane_ELTTEXTE000118"></a>
**To display the "UML database schema" pane**, go to the "Home" tab, "Environment" group, expand "Panes", select "Panes", and then select "UML database schema".

For more details on how to manage panes, see [Manipulating dockable panes](../Editeurs/2027001.md).
