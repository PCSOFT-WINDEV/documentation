
## Database schema associated with a project
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000069"></a>
When a WINDEV, WEBDEV or WINDEV Mobile project uses tables, it must be associated with a database schema. A database schema describes the structure of the tables (table, items, etc.) used in your project.

The data model editor allows you to easily create a database schema.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P47-Analyse%20Structure%20de%20la%20base%20de%20donn%E9es.gif)


Two methods can be used to create a database schema:

- ** 1st method**: Direct creation of the database schema (i.e. a Logical Data Model (LDM)).

- ** 2nd metod**: Creating the Conceptual Data Model (CDM), then creating the database schema from the CDM.




**Note**: In a WINDEV, WEBDEV or WINDEV Mobile application, the terms "LDM" and "database schema" are used interchangeably to define the structure of the database associated with a project.
