## Overview
<a name="overview_ELTTEXTE000100"></a>
In WEBDEV, you can manage all the styles used in a project. You can see the WEBDEV styles available for each type of control.

<a name="NOTE2_1"></a>


## Editing the WEBDEV style sheet of a project
<a name="editing_the_webdev_style_sheet_project_ELTTEXTE000124"></a>
To edit the WEBDEV styles of a project:

1. Select a type of control for which you want to find out the available WEBDEV styles (e.g., a Button control, to see the different WEBDEV styles associated with it). 

2. On the "Modification" tab, in the "Style" group, click "Styles".

3. The list of WEBDEV styles in the project that can be associated with the selected control (Button control in our example) is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_styles_WB%20-%20HC%20N%B0001.gif)





You can select a different WEBDEV style for the current control.

The context menu of WEBDEV styles allows you to:   <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition_styles_WB%20-%20HC%20N%B0002.gif)


- Edit an existing style. This option is only available for styles that do not come from a theme. 

- Duplicate the selected style.

- Delete a style. This option is only available for styles that do not come from a theme. 

- Create a new style.

- Delete the selected style. In this case, the style associated with the control will be the same but it will be local to the control.

- Set a new default style. All new controls of the current type will use this style by default. 

- See the uses of the style. You can see the list of controls that use the selected style. 




The style editing window includes the style properties of the control for which the style was defined. For more details, see [WEBDEV style editing window](../Editeurs/2016002.md).
