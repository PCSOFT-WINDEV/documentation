


## Custom-Folders in the database schema
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000188"></a>
When handling database schemas containing several descriptions of tables, the database schema graph is difficult to read. To manage these large database schemas, WINDEV, WEBDEV and WINDEV Mobile propose Custom-Folders in the database schema. 

Custom-Folders are used to group several descriptions of tables together.

These "Custom-Folders" are used to simplify: 

- the search and display of a table description in a large database schema. 

- how the groups of tables are manipulated programmatically. 
	For example, you can change the connection for all the tables in a Custom-Folder with [HChangeConnection](../WDLang4/3044150.md). To do so, simply specify the name of the Custom-Folder to be manipulated directly in the WLanguage function (see the list of available functions below). 
	This feature is available for HFSQL Classic, HFSQL Client/Server tables and tables manipulated by Native Connectors. 




These groups are defined in the ["Database schema" pane](../Editeurs/2027012.md) or in the database schema graph. These Custom-Folders are not physically created.

The following example groups the tables according to their category:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=GroupeAnalyses.gif)


**Limitations**:

- A Custom-Folder can be empty and contain no table description.

- It is not mandatory to associate a table description to a Custom-Folder.

- A Custom-Folder cannot belong to another Custom-Folder.

- Two Custom-Folders cannot have the same name.

- A Custom-Folder cannot have the same name as a table description.

## Handling Custom-Folders in the database schema
<a name="handling_customfolders_the_database_schema_ELTTEXTE000212"></a>
The different operations that can be performed on the Custom-Folders of the database schema are as follows:

- create a Custom-Folder.

- rename a Custom-Folder.

- delete a Custom-Folder.

- associate a table description with a Custom-Folder.

- disassociate a table description from a Custom-Folder.


To handle the Custom-Folders in the database schema, the "Database schema" pane must be displayed. To display the "database schema" pane, go to the "Home" tab, "Environment" group, expand "Panes", select "Panes" and then select "database schema".
<a name="NOTE2_2"></a>


### Handling a Custom-Folder
<a name="handling_customfolder_ELTPARAGRAPHE000073"></a>

To create a Custom-Folder:

1. In the "Database schema" pane (or in the database schema graph), select "New Custom-Folder" in the context menu (right click). A new Custom-Folder is automatically created.

2. Enter the name of this Custom-Folder and confirm (Enter key).




To rename a Custom-Folder:

1. Select the Custom-Folder to rename in the "database schema" pane.

2. Open the context menu (right click) and select "Rename" (or press F2).

3. Enter the new name of this Custom-Folder and confirm (Enter key).




To delete a Custom-Folder:

1. Select the Custom-Folder to delete (in the "Database schema" pane or in the database schema graph).

2. Open the context menu (right click) and select "Delete". 

3. The Custom-Folder is deleted. The tables associated with this Custom-Folder are automatically dissociated from this Custom-Folder.




To associate a table description with a Custom-Folder:

1. Select the description of the table you want to associate with the Custom-Folder.

2. Drag and Drop the description in the desired Custom-Folder. The description is automatically associated with the Custom-Folder.
	**Note**: If the description already belonged to a Custom-Folder, the description is only associated with the new Custom-Folder.




To dissociate a table description from a Custom-Folder:

1. .

2. Right-click to open the context menu and select "Remove from Custom-Folder". 

3. The table description is automatically dissociated from the Custom-Folder.

## Actions that can be performed on a Custom-Folder
<a name="actions_that_can_performed_customfolder_ELTTEXTE000242"></a>


### Customizing the graphic representation of the Custom-Folder
<a name="customizing_the_graphic_representation_the_customfolder_ELTPARAGRAPHE000110"></a>

Customizing a Custom-Folder consists in displaying a specific background image in the Custom-Folder.

To customize the graphic representation of a Custom-Folder:

1. Select the Custom-Folder in the database schema graph. 

2. Right-click to open the context menu and select "Description".

3. Check "Representation of the Custom-Folder in the analysis graph" and select the desired image. This image will be displayed in the graphic representation of the Custom-Folder.

4. Validate.



<a name="NOTE3_2"></a>


### Printing the content of the Custom-Folder
<a name="printing_the_content_the_customfolder_ELTPARAGRAPHE000128"></a>

You have the ability to print the documentation of the elements found in the Custom-Folder: 

1. Select the Custom-Folder in the "Database schema" pane. 

2. Open the context menu (right click) and select "Print".

## Handling groups/Custom-Folders programmatically
<a name="handling_groupscustomfolders_programmatically_ELTTEXTE000272"></a>
Several WLanguage functions can be used to handle the custom-folders programmatically: 



|   |   |
| --- | --- |
| [HChangeConnection](../WDLang4/3044150.md) | Dynamically changes the connection associated with a table. |
| [HChangeDir](../WDLang4/3044168.md) | Changes the path to a table (i.e. directory in which the file will be handled). |
| [HChangeLocation](../WDLang4/3044167.md) | Modifies the search mode of physical tables (.FIC, .NDX, ...). |
| [HClose](../WDLang4/3044073.md) | Closes either a table or all tables opened by the current user: all corresponding physical tables are closed for the current user. |
| [HCreationIfNotFound](../WDLang4/3044254.md) | Performs the following operations: <br><br>- If the table doesn't exist, create an empty table (file with ".FIC" extension) with the index file, the full-text index file and the memo file if necessary. The function is equivalent to [HCreation](../WDLang4/3044255.md).<br><br>- If the table exists, opens the table.<br><br><br> |
| [HFlush](../WDLang4/3044004.md) | Forces the operating system of the computer where the tables are found to write data onto the disk. |
| [HListFile](../WDLang4/3044045.md) | Returns the list of files:<br><br>- current database schema. <br><br>- database schemas in progress (projects with multiple database schemas).<br><br>- a specific database schema recognized by the HFSQL engine. <br><br>- available on a connection via a Native Connector or an OLE DB driver.<br><br>- for a group of files defined in the data model editor.<br><br><br> |
| [HOpen](../WDLang4/3044120.md) | Opens a table. |
| [HPass](../WDLang4/3044108.md) | Defines the password used to create or open a table. |
