
## Describing a WEBDEV style
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000072"></a>
When editing a WEBDEV style for a given type of control, you can define the characteristics of the various elements that make up the control. 

The WEBDEV style description window allows you to:

- define the name of the style. 

- define the element styles and additional options for each element that makes up the control associated with the WEBDEV style. 




For more details, see: 

- [WEBDEV styles](../Editeurs/2016008.md). 

- [WEBDEV element styles](../Editeurs/2016004.md).
