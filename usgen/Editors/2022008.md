
## Enlarging a window or page
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000145"></a>
Modern UIs generally use larger windows, pages and fonts. 

Now, you can automatically increase the font size of all the controls in a selection, window, page or project. This means you don't have to use a different theme or resize controls one by one. 

When the font is resized, all the controls are automatically enlarged and moved to preserve the current layout. The window or page is also enlarged if necessary.



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000169"></a>
To enlarge a window or page: 

1. Open the window or page to be enlarged in the editor. 

2. On the "Alignment" tab, in the "Other alignments" group, expand "Enlarge
Space out" and select "Enlarge". 

3. In the window that appears, specify the enlargement options: 
	


|   |   |
| --- | --- |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Agrandir_la_fen%EAtre%20-%20HC%20N%B0002.gif&type=thumb)<br> | <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Agrandir_une_page%20-%20HC%20N%B0001.gif&type=thumb)<br> |
| Options for enlarging a window | Options for enlarging a page |



4. You can: 

	- specify a scaling factor. 

	- specify whether the font and styles should be enlarged. 
			![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) In this case, you can: 

		- Create style overrides: In this case, the original style will be overridden to apply the changes. 

		- Create / Use an enlarged theme: In this case, a new theme based on the current theme is generated. For example, if the window uses the "Phoenix" theme, with a scaling factor of 25%, a "Phoenix (x1.25)" theme will be created.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Only the elements coming from a template and containing overrides will be enlarged.

5. Validate. The chosen options are applied. 




Remarks: 

- You can apply size changes to the current selection, window, page, or to the entire project. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) If you choose to create an "enlarged" theme, you will be able to apply it to other elements in the project. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) If the original theme is updated, the "enlarged" theme will automatically be updated. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) If the window contains a window template, you will need to enlarge the window template as well. You can also enlarge elements in the entire the project (the template will be automatically enlarged with the other elements in the project). 

- Control templates are not enlarged.
