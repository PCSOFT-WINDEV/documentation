


## Editing WEBDEV element styles in a project
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000138"></a>
WEBDEV allows you to manage all the WEBDEV element styles used in a project. 

You can:

- edit WEBDEV element styles in a project.

- set default WEBDEV element styles. 






<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Editing element styles in a project
<a name="editing_element_styles_project_ELTTEXTE000162"></a>
To edit WEBDEV element styles in a project:

1. On the "Page" tab, in the "Theme and styles" group, expand "Styles" and select "Edit WEBDEV element styles and external CSS references".

2. The list of element styles present in the project is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Edition-StyleCSS.gif)





This window shows: 

- the list of WEBDEV element styles present in the project style sheet. These are, for example, elements styles created from the current project. 

- the list of WEBDEV element styles present in the theme associated with the project. 
	Reminder: These element styles cannot be modified.  




This window allows you to:

- Edit the selected element style. These changes will be applied to all the controls that use this element style.

- Create a blank element style.

- Duplicate the selected element style.

- Delete the selected element style. In this case, the element style associated with the control will remain unchanged, but will be dissociated, i.e., it will be local to the control. 

- See the uses of the element style. 




Note: WEBDEV element styles in the project theme are read-only. However, they can be duplicated and the duplicated style can be modified.

## Setting default element styles
<a name="setting_default_element_styles_ELTTEXTE000186"></a>
Default WEBDEV element styles are styles that will be used by default for new controls.

If there is no WEBDEV style in the project for a given type of control, you can define one or more default element styles (depending on the type of control).

**To set the default element styles in a project**:

1. On the "Page" tab, in the "Theme and styles" group, expand "Styles" and select "Set default WEBDEV element styles". The list of available controls and styles is displayed.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Styles_CSS_Defaut.gif)


2. Select a type of control. You can see the list of available styles depending on the type of control selected. You can move styles from one list to another. 

3. Select the style you want to use, and check "Default style". 

4. Confirm ("OK" button).
