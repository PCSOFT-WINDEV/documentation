
## WEBDEV Account Manager
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000079"></a>
WEBDEV Account Manager allows you easily host websites developed with WEBDEV 2026. This tool is mainly intended for webmasters and hosting providers. It allows you to manage WEBDEV accounts, but also "IIS Web server" accounts (versions 5.xx, 6.xx, 7.xx and 8.xx) and Windows permissions.

WEBDEV Account Manager is installed on the deployment computer (WEBDEV Account Manager.exe) and only works with Windows and an IIS server.

It is very easy to use. Simply: 

1. [Configure the specific characteristics of the server](../CCHebergement/9000101.md). This configuration will be used by default for all users. 

2. Create the [deployment accounts](../CCHebergement/9000102.md). This operation can be automated by using a [command line](../CCHebergement/9000204.md).





	<B><B><B><B>Warning</B></B></B></B>

	 Until version 28, this tool was named "Hosting Control Center".
