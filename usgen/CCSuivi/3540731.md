
## Project Management Hub: Kanban
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000082"></a>
The Project Management Hub features a Kanban board to view the tasks of a contributor in a sprint. 

Kanban boards allow you to check the progress status of a developer's tasks at a glance (pending, in progress, paused or completed tasks). 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=CC_Suivi_Kanban%20-%20HC%20N%B0001.gif)


You can simply drag and drop a task to change its status.

## How to?
<a name="how_ELTTEXTE000106"></a>


### Opening the Kanban board
<a name="opening_the_kanban_board_ELTPARAGRAPHE000022"></a>

To open a Kanban board, add a "Kanban" tab. By default, the Kanban board shows the tasks of the current user, in the current sprint. 



The Project Management Hub allows you to choose which tasks are displayed in the Kanban board: 

- Sprint. 

- Type of task to be displayed. 

- Contributor(s). 




Tasks are displayed as cards, and are sorted into 4 lists: pending, in progress, paused or completed.

Cards can be displayed in standard or compact mode.
