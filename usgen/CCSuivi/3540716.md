## Overview
<a name="overview_ELTTEXTE000108"></a>
To manage the project development lifecycle, the Project Management Hub allows you to set requirements.

A requirement is an action that a program or service should be able to complete.

Lets take the case of a WINDEV application: a requirement can correspond, for example, to a new feature (display statistics in the sales application for instance). This new feature groups several elements:

- One or more development tasks, to integrate the feature into the application.

- One or more test tasks to test the feature.

- One or more documentation tasks to document the feature.




This feature (or requirement) can also be linked to one or more business rules or to one or more incidents.

Once all the elements linked to the requirement are completed, the requirement is validated. In our example, the feature can be made available to the users via an application update.

Note: You can indicate which team member is the **manager of the requirement**. In this case: 

- the manager cannot set a task as "completed" until the tasks of the other members are completed. 

- the manager will be notified each time a team member completes his or her task. 




Therefore, the Project Management Hub covers the entire development cycle, from the initial idea of the feature to its implementation.

## How to?
<a name="how_ELTTEXTE000132"></a>
The following steps must be performed to implement requirements:

1. [Creating a list of requirements](../CCSuivi/3540717.md). This list can group the necessary requirements for a new software version.

2. [Creating the requirements](../CCSuivi/3540717.md).

3. [Assigning the different dependencies to requirements](../CCSuivi/3540718.md) (tasks, business rules, etc.).

4. [Monitoring requirements](../CCSuivi/3540718.md).



<a name="NOTE2_2"></a>


### Starting the requirement management tool
<a name="starting_the_requirement_management_tool_ELTPARAGRAPHE000057"></a>You can manage requirements in the Project Management Hub. The requirement management tool can also be started directly. To do so, run the executable of the Project Management Hub (CCSuivi.exe) by passing the following command line:


```txt
CCSuivi.exe /MODE=REQUIREMENT
```
