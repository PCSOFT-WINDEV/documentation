
## 1. Project and database schema

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The development of a mobile **Application** (Android, iOS, etc.) with WINDEV Mobile is based on two main elements: the Project and the database schema.

A **WINDEV Mobile project** is a set of elements (windows, controls, classes, components, etc.) which put together, make it possible to create an application.

A **WINDEV Mobile database schema** contains the different tables used by the application.

An application is built from a project.

When a WINDEV Mobile project uses tables, it must be associated with a database schema. Generally, a project is associated with one database schema, but it can also be associated with several database schemas. 

A database schema can be associated with one or more projects.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P9-Projet-et-Analyse.png)
