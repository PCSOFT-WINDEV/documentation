


## Numeric (Variable type)

***In french: Numérique ***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The type **numeric** type is used to contain integers or decimals, specifying if necessary the number of digits in the integer part and in the decimal part.

This variable type is recommended for calculations on real values requiring high precision.

A numeric code manages a maximum of 38 significant digits (default 32 for the integer part, 6 for the decimal part). The Numeric type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md). 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Counter is numeric
Counter1 is numeric (*)
Counter2 is numeric (5,7)
```


<a name="Exemple2"></a>

```wl
num1 is numeric (2,15)
num2 is numeric (2,15)
num1 = 0n10.000000000000033
num2 = 0n10.000000000000055
Info(num1+num2)
```

## Syntax

### Numeric type declaration (default number of digits: 32 for the integer part and 6 for the decimal part)

`<Variable name> is numeric

<Variable name 1>, <Variable name 2> are numeric`
---

**`<Variable name>: ()`**

Name of the variable to declare. This variable will be a numeric variable with 32 digits for the integer part and 6 digits for the decimal part.


<a name="SYNTAXE2"></a>

### Declaring a numeric type (automatic number of digits)

`<Variable name> is numeric (*)

<Variable name 1>, <Variable name 2> are numeric (*)`
---

**`<Variable name>: ()`**

Name of the variable to declare. (\*) means that the variable format automatically adapts to the value contained.


<a name="SYNTAXE3"></a>

### Declaring a numeric type while specifying the integer part

`<Variable name> is numeric (<Integer part>)

<Variable name 1>, <Variable name 2> are numeric (<Integer part>)`
---

**`<Variable name>: ()`**

Name of the variable to declare.

**`<Integer part>: ()`**

Number of digits in the integer part. A numeric can contain up to 38 significant digits.


<a name="SYNTAXE4"></a>

### Declaring a numeric type while specifying the integer part and the decimal part

`<Variable name> is numeric (<Integer part>, <Decimal part>)

<Variable name 1>, <Variable name 2> are numeric (<Integer part>, <Decimal part>)`
---

**`<Variable name>: ()`**

Name of the variable to declare.

**`<Integer part>: ()`**

Number of digits in the integer part. A numeric can contain up to 38 significant digits.

**`<Decimal part>: ()`**

Number of digits in the decimal part. A numeric can contain up to 38 significant digits.

## Remarks


### Assigning a numeric variable
<a name="assigning_numeric_variable_ELTPARAGRAPHE000096"></a>

When a value (entered directly, given by a function, etc.) is assigned to a numeric variable, **the compiler automatically converts this value to a real**.

For example:


```wl
num1 is numeric
num1 = 1234567890123456789123456789

Trace(num1) // num1 does not contain the correct value
```



```wl
num2 is numeric
num2 = 1234567890123456789.0
Trace(num2) // num2 does not contain the correct value
```


**To force the assignment of a numeric type**, use **0n** before the value. For example:


```wl
num1 is numeric
num1 = 0n1234567890123456789123456789
Trace(num1) // num1 contains the correct value
```



```wl
num2 is numeric
num2 = 0n1234567890123456789.0
Trace(num2) // num2 contains the correct value
```

<a name="NOTE0_9"></a>


### Thousand separator
<a name="thousand_separator_ELTPARAGRAPHE000117"></a>You can use spaces and underscore characters to separate thousands in numbers. For example:


```wl
num1 is numeric
num1 = 123 456.478

num2 is numeric
num2 = 0n 47 568 014.478

num3 is numeric
num3 = 7_014.478
```

<a name="NOTE0_2"></a>


### Operations that can be performed with a numeric type
<a name="operations_that_can_performed_with_numeric_type_ELTPARAGRAPHE000126"></a>

The following operations can be performed with numeric variables:

- Comparisons: You can use the following operators: =, &lt;&gt;, &lt;, &lt;=, &gt;, &gt;=

- Arithmetic operations: Addition (+), negation (-), subtraction (-), multiplication (-), division (/), modulus.

- Combined operations: ++, --, +=, -=



<a name="NOTE0_3"></a>


### Operation involving a numeric type
<a name="operation_involving_numeric_type_ELTPARAGRAPHE000137"></a>

During an operation that involves a numeric variable, all the calculations are performed in the format of the numeric values handled.

For example, to perform an operation involving a numeric variable and a real, the real is converted to numeric.
<a name="NOTE0_4"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000146"></a>

A numeric type can have 38 significant digits.

The "highest" cases ((0,38) or (1,37) for example) can produce calculations errors caused by overflows.

The "lowest" cases ((38,0) or (37,1) for example) can produce calculation errors caused by loss of decimal values.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Numbers (real, integer, currency, numeric) cannot exceed 14 significant digits in PHP. If they exceed this limit, they are rounded to 14 digits.
<a name="NOTE0_5"></a>


### Currency/Numeric comparison
<a name="currencynumeric_comparison_ELTPARAGRAPHE000161"></a>

The [Currency](../Motscles/1514043.md) type is faster for the calculations that do not require a precision greater than 24 significant digits (up to 17 digits for the integer part and up to 6 digits for the decimal part).

Caution: When a numeric variable is used as the result of a calculation, the result is truncated to the specified number of decimal places, without rounding up if the decimal place is greater than 5.
