
## Explicit conversion operator for simple types
			



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
When the '=' operator is used between variables of simple types (int, real, string, etc.), there may be an implicit conversion.

Example of implicit conversion: 


```wl
s is a string = "43"
n is int
n = s // n contains 43: the string has been converted to an integer
```


The '()' operator allows you to force the conversion of a variable to a given type. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ref_produit is string = (string) 378 + (string) 578
// ref_Produit is 378578 and not 956
```

```wl
// Convert string to integer
AProcedure((int)a_value)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`(<Destination type>) <Source expression>
(<Destination type>) (<Source expression>)
`
---

**`<Destination type>: ()`**

Desired type of variable.

**`<Source expression>: ()`**

Expression or variable to convert to &lt;Destination type&gt;. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Supported types
<a name="supported_types_ELTPARAGRAPHE000037"></a>

The following types are supported:

- boolean

- int

- real

- currency

- numeric

- Date

- Time

- Duration

- DateTime

- string

- ANSI string

- Unicode string

- Buffer


Only static conversion is available for simple types. If conversion is not allowed, an exception will occur at runtime.
