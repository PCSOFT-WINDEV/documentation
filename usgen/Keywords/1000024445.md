
## Fixed string of (Variable type)

***In french: Chaîne fixe sur***
				

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	 This type of variable is kept for backward compatibility. 
</DIV><a name="description"></a>
The **Fixed string of** type corresponds to a fixed-length string. A fixed-length string cannot exceed 2 GB. The string is padded: 

- with 0 if a value has not yet been assigned to the string.

- with spaces if a value has already been assigned to the variable (similar to the "string" type of Visual Basic).




Remarks: 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The Fixed String type is not supported. It is replaced with the String type.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This type of character string is in ANSI format.

- For a variable of type "Fixed string of", [TypeVar](../WDLang1/3013056.md) returns the *wlFixedString* constant (value: 22).

## Example


```wl
FirstName is fixed string of 8
FirstName = "Florence"
```

## Syntax

### Declaring and initializing a "Fixed string of" variable

`<Variable name> is fixed string of <Length> = <Value>
OR

 <Variable name> is fixed string of <Length>
<Variable name> = <Value>`
---

**`<Variable name>: ()`**

Name of the variable to declare. When several variables of the same type are declared and initialized on the same line, only the last variable is initialized.

**`<Length>: ()`**

Maximum length for the string. 

**`<Value>: ()`**

Value given to the variable.

## Remarks


### Default value
<a name="default_value_ELTPARAGRAPHE000054"></a>

A declared and uninitialized "Fixed string of" variable is padded with zeroes ("0").

Note: The "Fixed string of" type must be used to send input/output parameters to Windows APIs.

### Fixed string
<a name="fixed_string_ELTPARAGRAPHE000182"></a>

- The memory required by a fixed-length string is allocated when the string is declared. Therefore, you should avoid using very large strings.

- Fixed-length strings are filled with spaces. Initializing and assigning a large string (several hundreds kilobytes) may take a long time.

### Cross-platform code
<a name="crossplatform_code_ELTPARAGRAPHE000196"></a>

Fixed-length strings are not available in Java. They are replaced with the String type at runtime.

However, [Complete](../WDLang1/3024010.md) can be used on a String variable:


```wl
MyString is string
MyString = Complete("Test", 10)
// Equivalent to 
// MyString is fixed string of 10 characters
// MyString = "Test"
```
