## Loop statements
<a name="loop_statements_ELTTEXTE000183"></a>
The loop statements of WLanguage are as follows: 



|   |   |
| --- | --- |
| [FOR](../Motscles/1510001.md) | The statement block is repeated until a limit value |
| FOR EACH | Element path: <br><br>- [FOR EACH](../Motscles/1510013.md): HFSQL iteration (full iteration, search, filter).<br><br>- [FOR EACH](../Motscles/1510016.md): Iterates through the arrays.<br><br>- [FOR EACH](../Motscles/1510019.md): Browse the associative arrays.<br><br>- [FOR ALL](../Motscles/1510018.md): Iterates over the characters of a string.<br><br>- [FOR ALL](../Motscles/1510017.md): Iterates through the controls.<br><br>- [FOR ALL](../Motscles/1510024.md): Route through the options available in the combinations.<br><br>- [FOR ALL](../Motscles/1510023.md): Browse available values in enumerations.<br><br>- [FOR ALL](../Motscles/1510022.md): Browse on a [xmlReader](../WDLang5/1000023392.md) type variable. <br><br>- [FOR ALL](../Motscles/1510029.md): Browse on a [jsonReader](../WDLang1/1410090783.md) type variable.<br>	<br><br><br> |
| [LOOP](../Motscles/1510004.md) | The statement block is repeated endlessly |
| [WHILE](../Motscles/1510010.md) | The statement block is repeated according to a condition |


The FOR EACH statement can also be used to browse the .Net objects that implement the IEnumerable interface.
