
## MyStoredValue

***In french: MaValeurMémorisée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MyStoredValue** keyword is used to identify the current object in the class array when printing a report based on a class. 

This makes it possible to identify the different values of the members of the current class and, if necessary, to group them together. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let o = MyStoredValue
Trace(o.m_customername + o.m_companyname)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MyStoredValue`
