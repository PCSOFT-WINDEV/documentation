
## Explicit conversion operator for advanced types
			



<a name="description"></a>
The instances of a variable derived from a base advanced type can be manipulated using a variable of the base type. 

To manipulate the instance using its actual type from a variable of the base type, you can use a variable of the actual type and assign it using the &lt;- operator.

The explicit conversion operator allows you to manipulate the instance using its actual type, without any intermediate variable. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code without explicit conversion
FOR EACH diagramShape OF DIAGEDT_MyDiagram.Shape
	ImageShape is diagImage <- diagramShape
	IF ImageShape <> Null THEN
 	 // The shape is an image
	END
END
```

```wl
// Code with explicit conversion
FOR EACH diagramShape OF DIAGEDT_MyDiagram.Shape
	IF ((diagImage?)diagramShape) THEN
 	 // The shape is an image
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Static conversion: Causes a runtime exception if the conversion is invalid

`((<Derived type>) <Base type variable>)`
---

**`<Derived type>: ()`**

Variable type that derives from the base type.

**`<Base type variable>: ()`**

Variable to convert to &lt;Derived type&gt;. 


<a name="SYNTAXE2"></a>

### Dynamic conversion: Returns Null if conversion is invalid

`((<Derived type>?) <Base type variable>)`
---

**`<Derived type>: ()`**

Variable type that derives from the base type.

**`<Base type variable>: ()`**

Variable to convert to &lt;Derived type&gt;. 

**Note**: Dynamic conversion does not cause runtime errors if the conversion is invalid. A dummy object is returned. When compared with **Null**, this object returns <u><u><u><u>True</u></u></u></u>. An exception will be thrown if this dummy object is manipulated.
