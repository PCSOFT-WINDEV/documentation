
## Indirection operators

***In french: Opérateurs d'indirection***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Operators **{**and  operators **}** operators are used to access a field, variable, class member or table item by dynamically constructing the name of the field, variable, class member or item.

The **{** and **}** operators present several benefits:

- Passing as parameter the name of a control, variable, class member or item.

- Building the name of a control, variable, class member or item programmatically.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) To use an indirection on a control of a page, the option "Allow indirections (slows the execution down)" must be checked ("Details" tab in the control description window).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Indirections cannot be performed local variables. **Indirections can only be performed on global variables only**. An indirection on a local variable of a process will trigger an "unknown element" error.

## Example


```wl
// Simple indirection 
{"NAME"} = CustName               // Is equivalent to NAME=CustName 
{"NAME"} = {"CU.CUSTNAME"}        // Is equivalent to NAME=CU.CUSTNAME 
{"CUSTWIN.NAME"} = CustName        // Is equivalent to CUSTWIN.NAME=CustName 
{"CUSTWIN"+".NAME"} = CustName     // Is equivalent to CUSTWIN.NAME=CustName 

// Typed indirection
{"Name",indControl} = CustName

// Indirection with a table name in a variable
nFileName is string = "Customer"
{nfileName + ".Name"} = "Smith"
HAdd({nFileName})
```




<a name="Exemple2"></a>





```wl
// Indirection in a procedure 
ControlName is string
ControlName = "EDT_EDIT1"			// EDT_EDIT1 is the name of the control 
// Call to a procedure used to make a control invisible 
Make_Invisible(ControlName)

PROCEDURE Make_Invisible(ControlN)
{NChamp}..Status = Invisible
```

```wl
// Indirection with variable 
AliasName is string
AliasName = PreviousWin()
// NAME is the name of the control 
// CustName is the value to assign 
{AliasName+".NAME"} = CustName 
Abbrev is string
```

## Syntax

### Simple indirection

`{ <Expression> }
`
---

**`<Expression>: (Character string)`**

Expression used to identify the control, the variable or the item to use. The element is sought:

- among the variables, 

- according to the number of dots found in the name:

	- 0 point: search among fields, then HFSQL items.

	- 1 point: search through HFSQL fields, then query parameters.

	- greater than 1 point: search among fields.




- among the special elements kept for compatibility (_Tabx for example, ...).




A WLanguage error occurs if this expression corresponds to an empty string ("").


<a name="SYNTAXE2"></a>

### Indirection on a class member

`{ <Expression> }
`
---

**`<Expression>: (Character string)`**

Expression used to identify the class member.

If the member is:

- global, use the following syntax: {" **::** MemberName"}

- is not global, use the following syntax: {" **:** MemberName"}




A WLanguage error occurs if this expression corresponds to an empty string ("").  


<a name="SYNTAXE3"></a>

### Indirection on a class member

`{ <Class> , <Member> }`
---

**`<Class>: (Character string)`**

Class instance

**`<Member>: (Character string or Variable Description variable)`**

Corresponds to: 

- the member name,

- a variable of type [Variable Description](../WDLang1/1000019560.md). 





<a name="SYNTAXE4"></a>

### Indirection by specifying the element type (optimizes the execution speed)

`{ <Expression>, <Type> }
`
---

**`<Expression>: (Character string)`**

Expression used to identify the control, the variable or the item to use. A WLanguage error occurs if this expression corresponds to an empty string ("").

**`<Type>: (Constant)`**

Constant used to specify the type of sought element:


|   |   |
| --- | --- |
| *indControl* | Element sought among the controls and the groups. |
| *indConnection* | Element sought among the connections. |
| *indReport* | Element sought among the reports.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available in PHP. |
| *indWindow* | Element sought among the windows.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available in PHP. |
| *indFile* | Item searched for in tables. |
| *indGPW* | Element sought among the elements of user groupware (used to retrieve the initial status of controls).<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available in PHP. |
| *indLink* | Element sought among the links.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available in PHP. |
| *indQueryParameter* | Element sought among the parameters of queries. |
| *indItem* | Element sought among the items. |
| *indVariable* | Element sought among the variables.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The element is only sought within the global variables. |
| *indPage* | Element sought among the pages.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the current page is accessible. |

## Remarks




### When should indirection be used?
<a name="when_should_indirection_used_ELTPARAGRAPHE000218"></a>

The indirection can be used for example:

- To access the value of an element (control, variable, item, ...):
	
	```wl
	{s_ControlName} = 10
	ControlValue = {s_ControlName}
	```


- To use a property:
	
	```wl
	{s_ControlName}..Height = 10
	```


- To programmatically handle a column of a Table control:
	
	```wl
	{s_ColumnName, indControl}[Row_Number] = 10
	```


- To handle a table column:
	
	```wl
	{s_TableName + "." +s_ColumnName, indControl}[Row_Number] = 10
	```

### Indirection on a structure
<a name="indirection_structure_ELTPARAGRAPHE000276"></a>

An indirection cannot contain an access to a structure or to a class instance. However, the following syntax can be used:


```txt
{<Variable structure>}: member
```

### Using the indirection on the paths in an XML document
<a name="using_the_indirection_the_paths_xml_document_ELTPARAGRAPHE000287"></a>

The indirection operators can be used to build the path of an element in an XML document. 

Example: 


```wl
sXMLDoc is string = [
	<?xml version="1.0" encoding="UTF-8"?>
	<Document>
	<VersionInfo>
	<Version>21</Version>
	<Year>2016</Year>
	</VersionInfo>
	</Document>
]

xmlExample is xmlDocument = XMLOpen(sXMLDoc, fromString)

sParam is string = "WINDEV_Param"

// Direct reading of information ...
Trace(xmlExample.Document.VersionInfo.Version) 

// Reading with part of XML path found in a variable
// (idem if file item, window parameter, method, ...)
sParameter is string = "VersionInfo"
Trace ({"xmlExample.Document." + sParameter + ".Version"})
```

### Limitations
<a name="limitations_ELTPARAGRAPHE000296"></a>

The indirection operator allows you to find an element by its name.

Therefore, the following operations are not allowed in an indirection:

- access to a member of a class instance or structure other than the current class instance (operators: and:: ).

- access to a subelement in a control or array ([] operator).

- access to a substring ([[]] operator).

- access to a property (.. operator).

- indirection ({ } operator).

- call to a procedure or to a method of Automation object.

- declaring a variable.




**Remarks**:

- Access operators on an element (operators: and [] and [[]] and . ) can be used on the element obtained by indirection. For example:
	
	```txt
	{ <indirection> }: member
	
	{ <indirection> } [index]
	
	{ <indirection> } [[ index ]]
	
	{ <indirection> }..property
	```


- To call a procedure identified by its name, use [Execute](../WDLang1/3013041.md) or [ExecuteProcess](../WDLang1/3013031.md).

- To combine these operations dynamically, you have the ability to use the dynamic compilation (see [Compile](../WDLang1/3013015.md)).
