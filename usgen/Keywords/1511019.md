
## MyTable (Reserved word)

***In french: MonFichier***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The keyword **MyTable** keyword is used to identify the table in a trigger that triggers the trigger. At runtime, this keyword is automatically replaced with the current table.

**Interest** The keyword **MyTable** keyword can be used to create generic triggers, without using indirections on the H.TableName variable. This allows you to handle the table, its properties or its items.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the name of the table that activates the trigger
TriggeringFile = MyTable..Name
```

<a name="SYNTAXE1"></a>
