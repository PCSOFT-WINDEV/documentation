
## FOR EACH statement (loop through a jsonReader variable)

***In french: POUR TOUT / POUR TOUS***
				



<a name="description"></a>
The **FOR EACH** statement loops through a variable of type [jsonReader](../WDLang1/1410090783.md) in various ways:

- Loop through a level. 

- Loop through a level with copy. 

- In-depth loop. 




**Note**: The **FOR EACH, FOR ALL** statements are accepted. The **FOR EACH** statement will be used in this documentation but it can be replaced with **FOR ALL**.

## Example

JSON file processed: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gros_Json.JPG&type=thumb)



```wl
// Loop through a level
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH Reader
	// Read root array on row 1
	FOR EACH Reader
		// Read objects on rows 2 and 21
		FOR EACH Reader
			// Read members on rows 3 to 5, 22 to 24
			FOR EACH Reader
				// Read objects on rows 7, 13, 26 and 32
				FOR EACH Reader
					// Read members on rows 8 to 11, 14 to 17, 27 to 30 and 33 to 36
				END
			END
		END
	END
END
```



```wl
// Loop through a level with copy
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH customer_array OF Reader
	// Read root array on row 1
	FOR EACH customer OF customer_array
		// Read objects on rows 2 and 21
		FOR EACH customer_property OF customer
			// Read members on rows 3, 4, 5, 22, 23 and 24
			IF customer_property.Name = "addresses" THEN
				FOR EACH address OF customer_property
					// Read objects on rows 7, 13, 26 and 32
					FOR EACH property_address OF address
						// Read members on rows 8 to 11, 14 to 17, 27 to 30 and 33 to 36
					END
				END
			END
		END
	END
END
```



```wl
// In-depth loop
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH Reader IN-DEPTH
	// Read all elements on rows 1, 2, 3 to 5, 7, 8 to 11, 13, 14 to 17, 
	// 21, 22 to 24, 26, 27 to 30, 32 and 33 to 36 
END
```

## Syntax

### Iterating over the elements of the JSON file on a level

`FOR EACH <JSON reader> 
       FOR EACH <JSON reader>
    	 ...
       END
END
`
---

**`<FOR EACH>: ()`**

Marks the beginning of the statement block.
Used to iterate over the children of the current level. 

**`<JSON reader>: ()`**

[jsonReader](../WDLang1/1410090783.md) variable corresponding to the JSON file to loop through. 
Inside the loop, the [jsonReader](../WDLang1/1410090783.md) variable points to the current JSON element. 

Note: You can use nested loops on the JSON reader. 


<a name="SYNTAXE2"></a>

### Loop through a level with copy

`FOR EACH <Element> OF <JSON reader> 
        FOR EACH <Element A> OF <Element>
         ...
        END
END`
---

**`<FOR EACH>: ()`**

Marks the beginning of the statement block.
Used to iterate over the children of the current level. 

**`<Element>: ()`**

Inside the loop, &lt;Element&gt; points to the current JSON element. It can be used to perform a new FOR EACH loop to iterate over its children. 

**`<JSON reader>: ()`**

[jsonReader](../WDLang1/1410090783.md) variable corresponding to the JSON file to loop through. 


<a name="SYNTAXE3"></a>

### In-depth loop

`FOR EACH <JSON reader> IN-DEPTH
       ...
END

FOR EACH <Element> OF <JSON reader> IN-DEPTH
       ...
END
`
---

**`<FOR EACH>: ()`**

Marks the beginning of the statement block.
Goes deep in the JSON tree. Iterates over the child, grandchild, then the child of the grandchild until a leaf is reached. 

**`<Element>: ()`**

Inside the loop, &lt;Element&gt; points to the current JSON element. Used to perform a reading in depth from an element. 

**`<JSON reader>: ()`**

[jsonReader](../WDLang1/1410090783.md) variable corresponding to the JSON file to loop through.

## Remarks




### Syntax 1: Iterating over the elements of the JSON file on a level
<a name="syntax_1_iterating_over_the_elements_the_json_file_level_ELTPARAGRAPHE000092"></a>

This syntax is used to iterate over the children of the current level. Inside the loop, the [jsonReader](../WDLang1/1410090783.md) variable points to the current JSON element.

You can nest loops on the [jsonReader](../WDLang1/1410090783.md) variable to iterate over the children of the element on the current level. 
<a name="NOTE0_2"></a>




### Syntax 2: Looping through a level with copy
<a name="syntax_2_looping_through_level_with_copy_ELTPARAGRAPHE000108"></a>

This syntax is used to iterate over the children of the current level. Inside the loop, &lt;Element&gt; points to the current JSON element and can be used to iterate over its own children. 

Note: It is possible to iterate over the &lt;Element&gt; variable only once.
<a name="NOTE0_3"></a>




### Syntax 3: In-depth loop
<a name="syntax_3_indepth_loop_ELTPARAGRAPHE000118"></a>

This syntax allows you to traverse the JSON tree in depth, i.e. child, grandchild, etc., until you reach a leaf. When the leaf is reached, the loop goes to the next child.
