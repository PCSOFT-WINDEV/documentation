## Overview
<a name="overview_ELTTEXTE000068"></a>
Enabling by-value mode implies making numerous changes in the way you pass parameters to procedures:

- by-value mode set by default.

- stricter type checking.


It is not recommended to enable this option in existing projects. Many changes need to be made to the code of your application.
