
## Variant (Variable type)

***In french: Variant***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The Variant type is used to:

- store any **value of simple type**: Boolean, Numerical (Monetary, Real, Integer, ...), Character and String, Date (Date, Time, DateTime and Duration), ...

- store named or indexed subelements.

- store any **value of complex** type: structures, classes, advanced types, arrays, associative arrays, queues, stacks and lists.

- handle the NULL value in WLanguage.

- store interactions with ActiveX objects and Automation programming.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
nValeur est un variant = 10 
nValeur = SAI_Saisie1 
nValeur = Client.Nom
```

## Syntax

### Declaring and assigning a Variant type

`<Variable name> is Variant = <Value>
 
OR 

 
  <Variable name> is Variant
  <Variable name> = <Value>
`
---

**`<Variable name>: ()`**

Name of the variable to declare.

**`<Value>: ()`**

Value to be assigned to the variable. One of the following values can be assigned to a Variant variable:

- any literal value,

- the content of a variable,

- the content of a simple control,

- the content of an item.

## Remarks




### Variant type and NULL values
<a name="variant_type_and_null_values_ELTPARAGRAPHE000077"></a>

To specify that a Variant variable contains no value, use the NULL constant.

Remarks: 

- for a Variant type, NULL means "Not assigned".

- for a Numeric type, NULL means "equal to 0".





```wl
nVal est un entier
SI nVal = Null ALORS ... // le test renvoie Vrai car nVal=0
nVal = 5
SI nVal = Null ALORS ... // le test renvoie Faux car nVal=5
```



```wl
vVal est un Variant
SI vVal = Null ALORS ... // renvoie Vrai car le variant n'est pas affecté
vVal = 0
SI vVal = Null ALORS ... // renvoie Faux car le variant est affecté avec un entier de valeur 0
vVal = 5
SI vVal = Null ALORS ... // renvoie Faux car le variant est affecté avec un entier de valeur 5
```



```wl
vVal est un Variant
vVal = Null
SI vVal = 0 ALORS ... // renvoie Vrai car une variable non affectée 
// et une valeur ne sont pas comparables, Vrai est retourné par convention
```

### Type of a variant
<a name="type_variant_ELTPARAGRAPHE000096"></a>

The type of a variant is returned by the [Type](../Proprietes/2510131.md) property. The [Type](../Proprietes/2510131.md) property gets the type of value stored in the variable.

Remarks: 

- [VariantConvert](../WDLang1/3013054.md) is used to convert the type of value stored in a Variant variable.

- [TypeVar](../WDLang1/3013056.md) is used to determine the type of variable (Variant type for a Variant variable). 





```wl
vVal est un Variant
TypeVar(vVal)  // renvoie le numéro du type variant
vVal..Type     // renvoie le type de la valeur stockée dans le variant
```

### Named subelements
<a name="named_subelements_ELTPARAGRAPHE000132"></a>

You can directly use members without any declaration on a Variant variable.

**When assigning a value to a member**, if the member does not exist, it is automatically created; if the member already exits, it is modified.

Example: 


```wl
Personne est un Variant
Personne.Nom = "DUPONT"
Personne.Prénom = "Michel"
```


**When reading a member**, if the member does not exist, it is not created. You can check if a member exists using the **Exist** property.
Example: 

```wl
Personne est un Variant
SI PAS Personne.Nom..Existe ALORS
	Erreur("Le nom n'a pas été renseigné")
FIN
```


If the member does not exist, the returned value is Null. Multiple methods can be used to test the Null value: 

- use the **Value** property. 
	Example: 
	
	```wl
	Elément est un variant
	SI Elément.MembreInexistant..Valeur = Null ALORS
		...
	FIN
	```


- test the Null value directly. Example: 
	
	```wl
	Elément est un variant
	SI Elément.MembreInexistant = Null ALORS
		...
	FIN
	```





Named subelements can be manipulated using the following properties: 


|   |   |
| --- | --- |
| **Exist** | Returns: <br><br>- <u><u><u><u>True</u></u></u></u> if the element exists,<br><br>- <u><u><u><u>False</u></u></u></u> if the element does not exist. The element is not created. <br><br><br> |
| **Name** | Element name |
| **Type** | Type of element (same values as [TypeVar](../WDLang1/3013056.md)). |
| **Value** | Element value. |


Using the [Member](../Proprietes/1000021078.md) property on Variant variables allows you to get the array of named elements. This array can be handled by FOR EACH, the [Count](../Proprietes/2510097.md) property, the [ ] operator, ... 
It is also possible to delete an element. Example: 

```wl
o est un JSON
o.m = 1
o.n = 2
Trace(o)

x est un Variant = o
Supprime(x..Membre, 1)
Trace(x) // Le membre m a été supprimé.
```

<a name="NOTE0_5"></a>


### Indexed subelements
<a name="indexed_subelements_ELTPARAGRAPHE000218"></a>

The Variant variable can be directly used as a Variant array. Using the [ ] operator automatically creates the array.

Example: 


```wl
Jours est un Variant
Jours[1] = "lundi"
Jours[2] = "mardi"
Jours[3] = "mercredi"
Jours[4] = "jeudi"
Jours[5] = "vendredi"
Jours[6] = "samedi"
Jours[7] = "dimanche"
```


Array operations can be performed directly on the variable of type Variant: FOR ALL, [Count](../Proprietes/2510097.md), operator [ ], ...
<a name="NOTE0_6"></a>


### Nesting named and indexed subelements
<a name="nesting_named_and_indexed_subelements_ELTPARAGRAPHE000242"></a>

Since the named and indexed subelements are of type Variant, they can be nested recursively.

Example: 


```wl
Bibliotheque est un Variant
Bibliotheque.Livre[1].Titre = "Les trois mousquetaires"
Bibliotheque.Livre[1].Auteur = "Alexandre Dumas"
Bibliotheque.Livre[2].Titre = "Les misérables"
Bibliotheque.Livre[2].Auteur = "Victor Hugo"
```
