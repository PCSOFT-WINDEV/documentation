
## Character (Variable type)

***In french: Character***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Character** type is used to manipulate a character. This type of variable corresponds to a 1, 2 or 4-byte character, according to the string management mode and execution platform.The Character type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md). 




**Remarks**: 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The Character type is not supported. It is replaced with the String type.

- For a character, [TypeVar](../WDLang1/3013056.md) returns the *wlCharacter* constant (value: 81).

## Syntax

### Declaring and initializing a character variable

`<Variable name> is character = <Value>
OR

 <Variable name> is character
<Variable name> = <Value>`
---

**`<Variable name>: ()`**

Name of the variable to declare. When several variables of the same type are declared and initialized on the same line, only the last variable is initialized.

**`<Value>: ()`**

Value given to the variable.

## Remarks


### Default value
<a name="default_value_ELTPARAGRAPHE000051"></a>

A declared and uninitialized "Character" variable corresponds to Charact(0).

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) When a character is empty, its value corresponds to empty string.
<a name="NOTE0_2"></a>


### Encoding of the Character type according to different platforms
<a name="encoding_the_character_type_according_different_platforms_ELTPARAGRAPHE000062"></a>

The "Character" type is used to manipulate a character. This type of variable corresponds to a 1, 2 or 4-byte character, according to the string management mode and execution platform.

- In Windows: 

	- in Ansi, a character is encoded on 1 byte, 

	- in Unicode, a character is encoded on 2 bytes.




- In Linux:

	- in Ansi, a character is encoded on 1 byte, 

	- in Unicode, a character is encoded on 4 bytes.




- In iOS, in Unicode, a character is coded on 4 bytes.

### ANSI/Unicode
<a name="ansiunicode_ELTPARAGRAPHE000083"></a>

- If the current configuration uses ANSI strings at runtime, the Character variables will be ANSI characters (default behavior).

- If the current configuration uses Unicode strings at runtime, the Character variables will be Unicode characters.




**Reminder**: To change the string format in the current configuration:


1. Open the project description window. To do so, go to the "Project" tab, "Project" group, and click "Description".

2. On the "Project" tab, click "Configuration description". 

3. In the window that appears, go to the "Unicode" tab and select the desired mode.



<a name="NOTE0_4"></a>


### Differences between WINDEV/WEBDEV and WINDEV Mobile
<a name="differences_between_windevwebdev_and_windev_mobile_ELTPARAGRAPHE000114"></a>

- In WINDEV and WEBDEV, ANSI characters are used by default. 

- In WINDEV and WEBDEV, Unicode characters are used by default.
