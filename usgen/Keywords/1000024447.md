
## Unicode string on (Variable type)

***In french: Chaîne unicode sur***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **type Unicode string on** is a fixed-length string containing only characters in Unicode format.

**Remarks**: 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This type of character string is not supported. It is replaced with the String type. 

- For a variable of type "Unicode string on", function [TypeVar](../WDLang1/3013056.md) returns the constant *wlUnicodeString* (value 16).. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Prénom est une chaîne Unicode sur 8
Prénom = "Florence"
```

## Syntax

### Declaring and initializing a "UNICODE string of" variable

`<Variable name> is Unicode string of <Length> = <Value>
OR

 <Variable name> is Unicode string of <Length>
<Variable name> = <Value>`
---

**`<Variable name>: ()`**

Name of the variable to declare. When several variables of the same type are declared and initialized on the same line, only the last variable is initialized.

**`<Length>: ()`**

Maximum length for the string. 

**`<Value>: ()`**

Value given to the variable.

## Remarks


### Default value
<a name="default_value_ELTPARAGRAPHE000046"></a>

A declared and uninitialized "Unicode string on" variable corresponds to an empty string ("").

### Fixed string
<a name="fixed_string_ELTPARAGRAPHE000172"></a>

- The memory required by a fixed-length string is allocated when the string is declared. Therefore, you should avoid using very large strings.

- Fixed-length strings are filled with spaces. Initializing and assigning a large string (several hundreds kilobytes) may take a long time.

### Cross-platform code
<a name="crossplatform_code_ELTPARAGRAPHE000186"></a>

Fixed-length strings are not available in Java. They are replaced with the String type at runtime.

However, [Complete](../WDLang1/3024010.md) can be used on a String variable:


```wl
MyString is string
MyString = Complete("Test", 10)
// Equivalent to 
// MyString is fixed string of 10 characters
// MyString = "Test"
```
