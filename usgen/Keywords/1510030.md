
## USE IN (transaction)

***In french: UTILISER DANS***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The instruction **USE ... IN** statement is used to define the block of operations to be performed in a transaction. 

This statement is used to outline a block of code in which several operations are to be processed as a single atomic transaction.

This means that all operations must succeed together, or be cancelled entirely in the event of an error, thus guaranteeing data integrity.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
USE HTransaction() IN
	// Add a customer
	HAdd(CUSTOMER)
	// Add an order linked to this customer	
	HAdd(COMMAND)	
	// In the event of an error, you can roll back a transaction
	IF ErrorOccurred() THEN
		GIVE UP AND GET OUT
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`USE HTransaction() IN 
     ...
END
`
---

**`<USING IN>: ()`**

Marks the beginning of the statement block. when entering this block, a transaction is automatically opened.
In this way, you can group together several operations (additions, modifications, deletions) on tables managed by HFSQL.

**`<HTransaction>: ()`**

Activate transaction.

## Remarks


### Exit the block: validation or cancellation
<a name="exit_the_block_validation_cancellation_ELTPARAGRAPHE000038"></a>

There are several ways to exit the block: 

- Commit transaction
	If the code executes to the end of the block without interruption (to the END), or if the EXIT instruction is used, the transaction is automatically validated.
	This behavior is equivalent to calling the WLanguage function [HTransactionEnd](../WDLang4/3044032.md).
	In this case, all HFSQL data modifications made in this block are permanently saved.

- Roll back transaction
	To interrupt the transaction and cancel all modifications made to HFSQL data, simply use the instruction **ABORT AND EXIT**.
	This instruction cancels the transaction and allows you to exit the block while maintaining consistent data.
	This behavior is equivalent to the WLanguage function [HTransactionCancel](../WDLang4/3044001.md).

- Any other output (exception, functions [SetFocusAndReturnToUserInput](../WDLang1/3025027.md), [Closes](../WDLang1/3038018.md), [EndProgram](../WDLang1/3013033.md), etc.)
	In this case, the transaction is also automatically rolled back.
