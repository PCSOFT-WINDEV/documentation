### Creating a table from scratch
<a name="creating_table_from_scratch_ELTPARAGRAPHE000138"></a>

Now, let's create the Order table from the beginning:

1. In the data model editor, on the "Database schema" tab, in the "Creation" group, click "New table". The table creation wizard opens.

2. In the wizard, select "Create a new table description". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0001.jpg&type=thumb)
Proceed to the next step of the wizard.

3. In the wizard, enter the name of the table: "Order". This name will be used: 

	- to handle the table in the code. The variable associated with the table will be "Order". 

	- to build the name of the associated physical table ("Order.fic" table). The caption and description of the elements represented by the records in the table appear automatically.
			In "A record represents", enter "An order".
			The name you enter in this field is used to generate a clear description of the links between tables. A description is automatically created based on the table name.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0002.jpg)





4. In the "Automatic identifier" section, keep "8-byte automatic identifier".
	If an automatic identifier is defined on the table, it means that the table includes a unique key, automatically managed by WINDEV.
Each time a record is added to the table, WINDEV automatically assigns a value to the table identifier. This value is unique.


5. Go to the next step and select the type of database associated with the table. We are going to work on HFSQL Classic tables. Click "Finish" to confirm. 




The table is automatically created in the data model editor. The description window of the items and indexes appears. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0003.jpg&type=thumb)
We are going to create the items of the "Order" table. In the table description window, you will notice that an item has been automatically created: "OrderID". This item corresponds to the automatic identifier of the table. This item consists of the name of the table and the letters "ID".

We are going to create the other items of this table. 

**First, let's create the "Date" item.** This item will contain the date of the order.

1. In the item description window, double-click in the "Name" column of the first empty row. This column automatically becomes editable. Type "Date".

2. Click the "Caption" column. The item name is automatically displayed. Click the item caption and type "Order date". In the "Type" column, the "Text" type is automatically selected. Expand the list and select the "Date" type. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0004.jpg)


3. This item will be a key item (index) in the table.
	Keys are used access and sort data faster.
A key is part of the item characteristics. An item can be non-key, unique key, key with duplicates or primary key. For more details on the different types of key, see [Key items](../Editeurs/2011023.md). 


4. In this example, the "Date" item is a key with duplicates. This means the value of the key may be present several times in the table.

	- Select the row of the "Date" item again to see its description on the right of the screen. 

	- Choose "Key with duplicates". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0005.jpg)





5. You can also define the default sort order of the key. In our case, the default sort order of this key will be "ascending".




**We will create the "Status" item** to get the order status.

1. Position the cursor on a new table row. Enter the following values:

	- Name: Status

	- Caption: Status

	- Type: Radio Button, List Box, Combo Box. In the window that appears, you can select the type of control to be created by default for this item. In this case, select Radio Button. Confirm changes.




2. In the lower section of the screen, click the link to display the parameters of the control bound to the selected item. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Fichier%20Commande%20-%20HC%20N%B0005%201.jpg)
The information typed in the new window that is displayed will be automatically used when creating windows linked to the table. This window displays the type of control and the caption.
	We are going to type the following options in the "Content" tab:

	- Click the "Content" tab.

	- Click the "+" button to add the first option.

	- The option 1 corresponds to Pending. Type "Pending" in the first Edit control.

	- Type "Validated" instead of "Option 2".

### Importing a CSV file
<a name="importing_csv_file_ELTPARAGRAPHE000271"></a>

To create the "PaymentMethod" table, which contains the payment characteristics, we will use a different method: we will import a CSV file.A CSV file is a text file that uses a specific format. This file contains data on each line. Data is separated by a delimiter character (a comma, semicolon or tab).
From the CSV file containing the data, WINDEV will create:

- the description of the table in the database schema,

- the HFSQL table with the table in the CSV table.




To import a CSV file into the database schema:

1. In the ribbon, on the "Database schema" tab, in the "Creation" group, expand "Import" and select "Import file/table descriptions...".

2. The table import wizard opens.

3. Select the format of the files to import. In this case, select "Text file". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0001.jpg&type=thumb)
Proceed to the next step of the wizard.

4. Enter the path of the file to be imported: "\\Tutorial\\WD\\Exercises\\WD My First Database\\PaymentMethod.csv", located in the WINDEV Suite installation directory. 

5. Proceed to the next step of the wizard.

6. Specify the following import options:

	- The records are delimited by: "&lt;Carriage Return/Line Feed>".

	- The columns are delimited by: "&lt;Semicolon&gt;".

	- The strings are delimited by: "&lt;None&gt;".

	- Decimal separator: "&lt;Automatic: dot or comma&gt;" <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0002.jpg&type=thumb)





7. Don't forget to check "The first row contains the names of the columns".

8. Go to the next step.

9. The structure of the table that will be created is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0003.jpg&type=thumb)
Keep the default options. Proceed to the next step of the wizard. 

10. The content of the CSV file will be automatically converted to HFSQL. The wizard suggests creating the HFSQL table in the project directory. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0004.jpg&type=thumb)
Keep the default options and go to the next step.

11. Finish the wizard. WINDEV creates the table.




Let's examine the description of the imported table:

1. Select the "PaymentMethod" table.

2. Right-click to open the context menu and select "Table description".

3. In the window that appears, delete "(Imported)" from the table caption.

4. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_Ma%20Premi%E8re%20Base%20-%207%20-%20Ligne%20de%20commande%20WB%20-%20HC%20N%B0001%201.jpg) (bottom left) to open the description of the table items.

5. This table does not have an automatic identifier or a unique key. We will set the "Code" item as a unique key:

	- Select the "Code" item if necessary.

	- On the right side of the screen, click "Unique key". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0005%201.jpg)





6. We get the following data: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Import%20CSV%20-%20HC%20N%B0005.jpg)


7. Validate the item and table description windows.

A link is used to define the integrity constraints (cardinalities) between two tables.

First, let's create the link between the "Customer" and "Order" tables. We can consider that:

## Generating the database schema
<a name="generating_the_database_schema_ELTTEXTE000881"></a>
The generation of the database schema consists in validating the changes made to the database schema (create tables, add or delete items, etc.) and applying them to the entire project (pages, bound controls, reports, etc.). The project will thus "know" all the tables, items and links defined in the database schema. It will be very easy to handle these elements in the different editors of WINDEV. 

If changes have been made to the database schema, a synchronization dialog box appears automatically when the data model editor is closed.

You can also generate the database schema manually. That's what we are going to do. 

To generate the database schema:

1. In the ribbon of the data model editor, go to the "Database schema" tab, "Database schema" group and click "Generation". 

2. The database schema generation starts automatically.

3. Since we modified the description of the tables in the database schema, WINDEV automatically starts the table update procedure. This operation updates the physical tables (".fic" files) based on their description in the database schema.




The automatic modification wizard opens. 

1. Validate the different steps until you reach the screen that lists the tables to take into account.

	- WINDEV detects that the PaymentMethod table must be updated. Keep this table selected. 

	- WINDEV detects that the Product table is out of sync. Select this table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%207%20-%20G%E9n%E9ration%20bis%20-%20HC%20N%B0001.jpg&type=thumb)





2. Go to the next step.

3. The wizard proposes to make a back up copy of the existing tables, don't change anything and go to the next step.

4. The wizard allows you to define a password to protect the tables that were modified during the automatic modification. Keep the default options and go to the next step.

5. The list of tables to modify is displayed. Finish the wizard.


The tables are updated.

Close the data model editor.
