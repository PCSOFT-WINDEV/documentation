## Database schema and project: Definitions
<a name="database_schema_and_project_definitions_ELTTEXTE000209"></a>
To create an application with WINDEV, you need to create a project. This project contains all the elements required to run the application.

As you develop the application, you may have to handle data. To store the data, you must create a "database".

The first thing you should do in a WINDEV project that handles data is create a **database schema**. A "database schema" contains the description of the tables containing the application data.


When the application is run, these descriptions will be used to create the database and/or the tables. Data will be stored in this database or these tables.

## Project with database schema
<a name="project_with_database_schema_ELTTEXTE000242"></a>
In this tutorial, we will create and associate a project with an HFSQL database.WINDEV supports a wide range of database formats. It natively supports HFSQL, a built-in database system. The HFSQL database is available in Local, Network, Cluster, Client/Server (Windows and Linux), Cloud and Mobile versions.




To create an application with a database, you must:

- Create the project linked to the application. This project will group together all the elements of the application (windows, code, queries, reports, etc.).

- Create the database schema associated with the project. The database schema is used to describe all tables handled by the application.

## Creating the project
<a name="creating_the_project_ELTTEXTE000275"></a>
To develop any application with WINDEV, we need to create a project.


To create a project, simply follow the steps of the project creation wizard:

1. Open WINDEV and go to the home page (Ctrl + &lt;). 

2. On the home page, click "Create a project" and select "Windows or Linux application". The project creation wizard opens. The different steps of the wizard will help you create your project. 
	The information specified in this wizard can be modified later.


3. The wizard allows you to choose the style book. Select "Eleven_Palette". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0001.jpg&type=thumb)
Go to the next step. 
	The style book is defined based on themes. Themes allow you to quickly create outstanding interfaces. A theme defines the window style as well as the style of all the controls that will be used in the window. Thus, the interface will always be cohesive and beautiful.


4. The wizard prompts you to enter the project name and location. In our case, name the project "WD My First Database". By default, WINDEV creates this project in the ".\\My projects\\WD My First Database" directory. You can keep this location or change it via the [...] button. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0002.jpg&type=thumb)


5. Click "Finish" to complete the project creation process. The new element window appears. Close this window by clicking "X" in the upper-right corner.

## Creating the database schema
<a name="creating_the_database_schema_ELTTEXTE000317"></a>
Now, let's create the database schema of the project: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Analyse_GAF.jpg) in the quick access buttons. The database schema creation wizard opens. 

2. Specify the database schema name and directory. By default, the database schema name corresponds to the project name and the database schema directory is a ".ana" directory in the project directory. Keep the default parameters. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0003.jpg&type=thumb)
Proceed to the next step of the wizard.

3. Next, you can choose the types of databases used by the project. Select "HFSQL Classic". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0004.jpg&type=thumb)
Proceed to the next step of the wizard.

4. Confirm. The table creation wizard opens automatically. 

5. Close this wizard. In the next lesson, we will look at the different ways of creating a table description.
