## Overview
<a name="overview_ELTTEXTE000348"></a>
WINDEV allows you to create applications that access an HFSQL Client/Server database. The Client/Server mode lets you migrate databases to a server. This operating mode: 

- increases data security,

- allows you to easily manage multiple users,

- facilitates maintenance, etc. 



In this tutorial, we will follow all the necessary steps to develop and deploy an application that uses an HFSQL Client/Server database. 

To follow these steps, we will use the "WD Full Application" project. This lesson will explain how to install a local HFSQL server and adapt an application to use an HFSQL Client/Server database. In the next lesson, we will see how to manage a Client/Server database. 

For more details on HFSQL Client/Server, see [HFSQL Client/Server](../WDLang4/3044306.md).

## Installing a local HFSQL server
<a name="installing_local_hfsql_server_ELTTEXTE000381"></a>
The first operation to perform consists in installing an HFSQL server.

This server can be installed on the development computer (that's what we are going to do). On the deployment side, the server can be installed on a specific computer.

The HFSQL server setup program is included in the WINDEV, WEBDEV and WINDEV Mobile setup media. If you don't have this media, the HFSQL server setup is also available on our site ([www.windev.com](https://www.windev.com)).

To install the HFSQL server locally:

1. Start the WINDEV/WEBDEV/WINDEV Mobile setup program.

2. Select "Install HFSQL Client/Server".

3. Then, select "Install or update an HFSQL server".

4. Accept the license agreement.

5. Select a platform ("For Windows on this computer").

6. If there are HFSQL servers already installed on the current computer, select "Install a new server".

7. Select the installation directory and specify the server name and port. The port 4900 will be used by default.
	Don't forget to open this port on the firewall in order to connect to the HFSQL server from another computer.


8. Specify the login credentials of the user with administrator privileges that will be created by default on the HFSQL server. By default, this user is "Admin" and has no password. 
	For security reasons, don't forget to change the administrator password.


9. Install the HFSQL Control Center if it is not already installed or cannot be accessed from your computer.
	
	<B><B><B><B>Warning</B></B></B></B>

	 The HFSQL Control Center is required to manage the HFSQL Client/Server database.



10. The wizard prompts you to configure the sending of notifications to identify server problems in real time. In this case, go to the next step and indicate that the settings will be defined "Later". 

11. The wizard allows you to enable the Active Directory authentication. Enable this option if necessary. 

12. You can help us improve by allowing us to collect information regarding the use of our products. This optional and anonymous data collection allows PC SOFT to improve its software products.




The installation is completed. By default (if you have not changed the administrator settings), to connect to the server in administrator mode, you must use the "Admin" user without password. 

**Note**: In this tutorial, we explain how to adapt an existing application to Client/Server mode. However, once the HFSQL server has been installed, you can directly develop an application that uses HFSQL Client/Server data. The only difference with a project that uses HFSQL Classic data is the format of the data manipulated in the database schema. The databases used by the project are in "HFSQL Client/Server" mode. For more details on how to create a WINDEV project and a database schema, see [Creating a WINDEV project and its database schema](../TutoWD/1410087520.md).

## Adapting an application to use an HFSQL Client/Server database
<a name="adapting_application_use_hfsql_clientserver_database_ELTTEXTE000441"></a>
Switching an HFSQL Classic database to Client/Server is the most common operation.

WINDEV offers different methods to switch the database:

- from the data model editor.

- from the HFSQL Control Center.


To better understand the different steps, we are going to switch the WD Full Application project to Client/Server mode using the first method, the data model editor.
<a name="NOTE5_2"></a>


### Opening the example project
<a name="opening_the_example_project_ELTPARAGRAPHE000120"></a>

This tutorial uses the "WD Full Application" project. To open this example: 

1. Go to the WINDEV home page (Ctrl + &lt;).

2. On the home page, click "Tutorial", then in "Tutorial - Manage an HFSQL Client/Server database", click "Open exercise project".





	<B><B><B><B>Warning</B></B></B></B>

	 This project will be used in the different lessons of this tutorial. 





### Adapting the project
<a name="adapting_the_project_ELTPARAGRAPHE000133"></a>

To adapt the "WD Full Application" project:

1. Load the database schema of your project in the data model editor. To do so, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Analyse_GAF.jpg) in the quick access buttons. The data model editor is displayed.

2. On the "Database schema" tab, in the "Connection" group, click "New connection". A wizard opens, allowing you to create a connection.

3. Select the type of connection to create: "HFSQL Client/Server". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0001.jpg&type=thumb)


4. Go to the next step. 

5. In the following steps, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0002.jpg&type=thumb)


	- the server name (name of your computer for example) and the port number. 

- the username and password (leave these fields empty to log in as administrator) . 

- the database name (in this case, "WD Full Application"). 

- the name of the connection (keep the default name).

6. Go to the next step and validate. The connection to the database is automatically created. A dialog box prompts you to associate the different tables from the database schema with the connection that was just created. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0003.jpg)


7. Click "Yes".

8. In the next step, select all the tables:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0004.jpg&type=thumb)
Go to the next step. 

9. A dialog box prompts you to copy the tables to the server. Validate ("Copy now"). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0005.jpg)


10. Select the database schema tables to be copied to the server. In this case, copy all tables in the "EXE\\Windows 64-bit executable" directory. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0006.jpg&type=thumb)


11. Go to the next step and validate.

12. The tables in the database schema are automatically changed into HFSQL Client/Server tables and associated with the selected connection. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0007.jpg&type=thumb)


13. **Generate the database schema**. Go to the "Database schema" tab, "Database schema" group and click "Generation". An automatic modification of the tables is automatically proposed. If all the tables are up to date, the automatic modification of the tables can be canceled.
	**Recommendations to switch to Client/Server mode**

	- Check the code of your project. In HFSQL Client/Server mode, [HSubstDir](../WDLang4/3044028.md) and other similar functions have no effect.

	- You can modify the connection defined in the database schema with [HOpenConnection](../WDLang4/3044107.md) and [HChangeConnection](../WDLang4/3044150.md) according to the parameters specified when it was created. 

	- [HOpenConnection](../WDLang4/3044107.md) allows you to switch to HFSQL Classic mode. Simply specify the path of the directory containing the HFSQL Classic tables.





14. The development project was successfully adapted. You may also have to adapt the deployed application (e.g., if the deployed application uses HFSQL Classic tables). This operation is configured when creating the setup program of the application. The steps to create the setup program are explained in lesson 3 of this tutorial.
