## Overview
<a name="overview_ELTTEXTE000305"></a>
Now that we know how to create and/or adapt an application to run in HFSQL Client/Server mode, let's see how to manage the associated database.

A Client/Server database requires:

- a specific configuration on the computers (install an HFSQL server, etc.).

- management via the HFSQL Control Center.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Configuring the computers
<a name="configuring_the_computers_ELTTEXTE000329"></a>
To use an HFSQL Client/Server database, an HFSQL server must be installed on the server. Several HFSQL servers that use different ports can be installed on the same computer. 

For example, it is possible to install a test HFSQL server (with a test database) and a production HFSQL server on the same computer, using a different port.

However, for performance reasons, this configuration is not recommended. One or more databases can be installed on each server.

## Open the HFSQL Control Center
<a name="open_the_hfsql_control_center_ELTTEXTE000353"></a>
The HFSQL Control Center is used to fully manage HFSQL Client/Server databases and servers.

We will present the most important features.

First, we will open the HFSQL Control Center from the "WD Full Application" project that we used in the previous lesson.


	<B><B><B><B>Warning</B></B></B></B>

	 **All the actions from the previous lesson must have been completed to perform the actions on the "WD Full Application" project in this lesson**.



### Starting the HFSQL Control Center
<a name="starting_the_hfsql_control_center_ELTPARAGRAPHE000067"></a>

To open the HFSQL Control Center from WINDEV and access the data: 

1. In the WINDEV menu, on the "Tools" tab, in the "Database" group, click "HFSQL". The HFSQL Control Center is displayed.

2. The HFSQL Control Center home window appears. The database schema of the current project is automatically selected. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0008.jpg&type=thumb)


3. Confirm. The HFSQL Control Center is displayed. This start mode allows you to see the different tables linked to the database schema of the current project.

4. Click the vertical tab named "HFSQL C/S" if necessary. The list of HFSQL Client/Server tables appears. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0009.jpg&type=thumb)
The Control Center lists the Client/Server tables found in the database schema linked to the current project. No connection is established. The tables are grayed out.

5. To view the records in the tables, double-click one of the tables in the list on the left (for example, "Order"). If the HFSQL Control Center does not recognize all the connection parameters, a window will allow you to establish the connection with the HFSQL Client/Server server used. If this window is displayed, specify the password and confirm.

6. The information of the selected table that uses this connection is displayed in a new "Order" tab. This information is available in several vertical tabs: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0011.jpg&type=thumb)


	- The "Description" tab shows information about the tables (keys, items, etc.). 

- The "Content" tab shows the records in the tables.




**The entire HFSQL Client/Server database can be managed from the HFSQL Control Center**.

## Creating a user account in the HFSQL Control Center
<a name="creating_user_account_the_hfsql_control_center_ELTTEXTE000392"></a>
As explained before, an administrator account consisting of the "Admin" username and no password is created when the HFSQL server is installed.

User accounts enable **secure access to data**. Not all the users of the application are administrators. Specific rights can be granted to each user (or group of users). Some users may not have rights to write to some tables, for example.

	<B><B><B><B>Warning</B></B></B></B>

	 User rights defined in the HFSQL Control Center are **database rights**, not application rights. Client/Server database rights should not be confused with User Groupware rights.



To do a simple test, we will create a user and allow the user to see the records in the Customer table. We are going to: 

- Connect to the database on the HFSQL server. 

- Create a user. 

- Grand different permissions to the user. 





### Connecting to the HFSQL Client/Server database 
<a name="connecting_the_hfsql_clientserver_database_ELTPARAGRAPHE000108"></a>

To directly connect to the WD Full Application database located on the HFSQL server:

1. Expand the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0009%201.jpg) menu at the top left of the HFSQL Control Center and select "Connect to an HFSQL server".

2. The HFSQL Control Center home window appears. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0012.jpg&type=thumb)


3. The option "Connect to an HFSQL server" is selected by default. Specify the characteristics of the server that was installed in the previous lesson and validate. 

4. The characteristics of the HFSQL server are displayed. 




Let's take a closer look at the information displayed:

- the name of the HFSQL server and the list of databases are displayed in the left panel.

- in the right section, a new tab appears and shows the characteristics of the HFSQL server. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0013.jpg&type=thumb)








### Creating a user
<a name="creating_user_ELTPARAGRAPHE000128"></a>

To create a new user: 

1. On the right section of the screen, select the "Users" tab. This tab is used to manage the users of the server.
	Only the "Admin" user exists at this point. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0014.jpg&type=thumb)


2. In the menu, in the "Users" group, click "New". The window used to define the user characteristics is displayed. 

3. Enter the following information: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0015.jpg&type=thumb)
 (use "Test" as password for example).
	Several characteristics can be observed:

	- Superuser: Users defined as "Superusers" are allowed to perform all actions on the server, databases and tables.

	- Account enabled: If this option is not checked, the user exists but he is not enabled (users on holiday for example).

	- Password expiration: You can make a password valid only for a given number of days.





4. Validate the user creation. By default, no rights are granted to this user.





### Defining the rights of the new user
<a name="defining_the_rights_the_new_user_ELTPARAGRAPHE000151"></a>

We are now going to grant the user rights. The "Test" user can connect to the database and view the contents of the Customer table. 

To grant rights to connect to the database:

1. In the HFSQL Control Center, double-click the "WD Full Application" database.

2. On the "WD Full Application" tab, in the "Rights" group, click "Database rights".

3. Select the "Test" user in the list of users.

4. In the list of rights, for the action named "Rights to connect to the server (encrypted and unencrypted connection)", click in the "Defined rights" column and select the green checkmark. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0016.jpg&type=thumb)


5. Click "Apply" at the bottom of the window. The rights become effective.

6. Close the rights management window.




To grant rights to read the Customer table:

1. In the HFSQL Control Center, expand the "WD Full Application" database and double-click the Customer table (on the left of the screen).

2. On the "Customer" tab, in the "Rights" group, click "File rights".

3. Select the "Test" user in the list of users.

4. In the list of rights, for the action named "Rights to read the records of a file", click in the "Defined rights" column and select the green checkmark. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P5_Passage%20analyse%20en%20CS%20-%20HC%20N%B0017.jpg&type=thumb)


5. Click "Apply" at the bottom of the window. The rights become effective.

6. Close the rights management window.


Rights can be defined:

- for the HFSQL server.

- for the database.

- for the database files.



Once the account has been created, it can be used when the application connects to the server using [HOpenConnection](../WDLang4/3044107.md). 
In our example, the "Test" user can only browse through the records in the Customer table. If this user tries to perform another action, a message will be displayed: "The Test user has no sufficient rights to XXXX" (where XXXX corresponds to the action performed).

## To sum up
<a name="sum_ELTTEXTE000452"></a>
We have seen the basics of the HFSQL Control Center. This database management program can also be used to:

- stop or restart a server if a problem occurs,

- manage users and rights,

- reindex tables if necessary,

- create database backups.




**The HFSQL Control Center is a redistributable tool that can be installed on the computers of users who are working with HFSQL Client/Server databases. The HFSQL Control Center must be used by the database administrator.**

**Further information**: 

- In this lesson, we explained how to manage users using the HFSQL Control Center. You can also manage users and their rights programmatically using specific WLanguage functions. 
	For more details, see [HFSQL Client/Server functions](../WDLang4/3044316.md). 

- To learn more about the HFSQL Control Center, see [HFSQL Control Center: Overview](../CCHF/3540001.md).
