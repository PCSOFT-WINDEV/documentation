## Overview
<a name="overview_ELTTEXTE000223"></a>
This lesson explains how to manipulate SQL databases with WINDEV.This lesson is intended for users who are familiar with SQL databases. Some operations to perform on the SQL database will not be presented in detail.




To create an application that uses an SQL database, you need to:

- Create the project linked to the application. This project will group together all the elements of the application (windows, code, queries, reports, etc.). 

- Import the description of SQL tables.


**To follow this lesson**: 

1. You need to download the necessary elements to your computer. 

	- On the home page, click "Tutorial".

	- In "Tutorial - Using data from an external database", click "Download elements for the exercise". 




2. Connect to your SQL server. 

3. Select the SQL script files and the image directory  (located in "\\Exercises\\SQLDatabase\\", in the directory that contains the examples of this tutorial) , and import them into the SQL server, using the available import tools (MySQL, Oracle, SQL Server, etc.). The image directory is used to get the images of the Product table. 

4. Lastly, you need to run the SQL script files on the SQL server. 
	Note: The provided SQL scripts run on Oracle only.


Your SQL database is ready for this lesson.

## Creating the project
<a name="creating_the_project_ELTTEXTE000265"></a>
To create the project:

1. Open WINDEV and go to the home page (Ctrl + &lt;). 

2. On the home page, click "Create a project" and select "Windows or Linux application". The project creation wizard opens. The different steps of the wizard will help you create your project. 
	The information specified in this wizard can be modified later.


3. The wizard allows you to choose the style book. Select "Eleven". 

4. The wizard prompts you to enter the project name, location and description. In our case, this project will be named "sqldatabase".  

5. Finish the wizard. 

6. In the "New" window, click "Data" and then click "Database schema". 

7. The database schema creation wizard opens.

## Creating the database schema
<a name="creating_the_database_schema_ELTTEXTE000298"></a>
The steps of the database schema creation wizard are as follows:

1. Specify the database schema name and directory. By default, the database schema name corresponds to the project name and the database schema directory is a ".ana" directory in the project directory. Keep the default parameters. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8_Import%20OLEDB%20-%20HC%20N%B0001.jpg&type=thumb)
Proceed to the next step of the wizard. 

2. Next, you can choose the types of databases used by the project. Select OLE DB (or the SQL database used if you own the corresponding Native Connector). 
	Note: Native Connectors are listed first. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8_Import%20OLEDB%20-%20HC%20N%B0002.jpg&type=thumb)
Proceed to the next step of the wizard.

3. Select the OLE DB source that corresponds to the type of your database.
	Proceed to the next step of the wizard.

4. In the following steps, specify the parameters of your OLE DB connection (the same steps apply for a Native Connector):

	- the name of the database server. 

	- the username and password. 

	- the database name if necessary. 

	- the connection name (the caption associated with the connection is optional). 


 Go to the next step.

5. Finish the wizard. The database schema of the project is created. The table creation wizard opens. 




In the table creation wizard:

1. Select "Use the tables from an existing database". Proceed to the next step of the wizard. 

2. Select the type of data to be imported, OLE DB (or the SQL database used if you have the corresponding Native Connector). Proceed to the next step of the wizard.

3. Select the OLE DB source that corresponds to the type of your database.
	Proceed to the next step of the wizard.

4. Select the connection used to create the database schema. 
	Proceed to the next step of the wizard.

5. Specify the data access mode. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8_Import%20OLEDB%20-%20HC%20N%B0003.jpg&type=thumb)
You can:

	- access the data in its current format directly. Only the description of the tables is imported into the database schema. No conversion is required.

	- convert the data to HFSQL Classic. 




6. In our case, choose "Access the data in its current format directly". Go to the next step. 

7. Select the table(s) to be imported<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8_Import%20OLEDB%20-%20HC%20N%B0004.jpg&type=thumb)


8. Confirm and finish the wizard. The tables are imported and displayed in the data model editor.

## Generating the database schema
<a name="generating_the_database_schema_ELTTEXTE000322"></a>
The generation of the database schema consists in validating the changes made to the database schema (create tables, add or delete items, etc.) and applying them to the entire project (pages, bound controls, reports, etc.).

If changes have been made to the database schema, a generation dialog box appears automatically when the data model editor is closed.

You can also generate the database schema manually. That's what we are going to do. 

To generate the database schema:

1. In the data model editor, on the "Database schema" tab, in the "Database schema" group, click "Generation".

2. The database schema generation starts automatically.
