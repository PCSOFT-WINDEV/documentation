
## 1. Project and Database Schema

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The development of a **Windows application** with WINDEV is based on two main elements: the Project and the database schema.

A **WINDEV Project** is a set of elements (windows, reports, controls, classes, components, etc.), which put together, make it possible to create a Windows application.

A **WINDEV database schema** contains the different tables used by the application.

An application is built from a project.

When a WINDEV project uses tables, it must be associated with a database schema. Generally, a project is associated with one database schema, but it can also be associated with several database schemas. 

A database schema can be associated with one or more projects.
