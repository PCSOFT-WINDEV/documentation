
## 17. Project Management Hub

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
WINDEV includes a Project Management Hub to manage development projects. The Project Management Hub allows you to:

- Manage project requirements,

- Monitor the progress of a project (schedule tasks),

- Manage bugs and changes made to a project.




The Project Management Hub uses the Control Center database, which can be in HFSQL Classic or Client/Server mode. This database is shared between different tools available in WINDEV:
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2-Les%20centres%20de%20controle.gif)


Note: When installing WINDEV, the setup program enables you to:

- create the database of the Control Centers (database of the Project Management Hub). This database will be automatically created in HFSQL Classic format in the specified directory.

- share an existing database of the Control Centers.
