
## 1. Database schema: database structure

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
When a WINDEV, WEBDEV or WINDEV Mobile project uses tables, it must be associated with a database schema. A database schema describes the structure of the tables (table, items, etc.) used in your project.

The data model editor allows you to easily create a database schema.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P47-Analyse%20Structure%20de%20la%20base%20de%20donn%E9es.gif)


The database schema of a WINDEV, WEBDEV, or WINDEV Mobile project corresponds to the LDM (Logical Data Model). This database schema defines the entire data structure of the project. All data is grouped into "tables". Each file contains multiple data fields, called items.

In the database schema, the description of a table can be linked to a file type (HFSQL Classic, HFSQL Client/Server, SQLite, etc.).
