
## iReset (Function)

***In french: iRAZ***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>17</B>, ***iRAZ*</**>** is kept for backward compatibility. This function has been replaced with ***iReset*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reinitializes the print settings (margins, font, paper format, orientation, ...) stored in the print library.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
iReset()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`iReset()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
 **iReset** must be used to modify the current print parameters when [iConfigure](../WDLang5/3046072.md) and [iParameter](../WDLang5/3046008.md) cannot be used.
