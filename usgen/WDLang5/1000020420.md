


## GglPrintDocument (Function)

***In french: GglImprimeDocument***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>27</B>, This function is no longer available, as Google Cloud Print was discontinued. It is now recommended to use the [iPrintPDF](../WDLang5/1000020519.md) function. 
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Prints a document (text or PDF file, images, Word or Excel document, ...) by using the Cloud Print service of Google.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sPath is string = CompleteDir(SysDirStorageCard()) + "invoice.pdf"
IF NOT GglPrintDocument(sPath)
	Error("The document was not printed.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GglPrintDocument(<Path>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the print request has been carried out (i.e. if the printer selection window has been displayed), 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


Note: It is not possible to know whether the print launch has been validated by the user. 

**`<Path>: (Character string)`**

Name and full (or relative) path of the document to print. This parameter can correspond to: 

- a file found in the application directory.

- a file found on the external memory (SDCard).

- a file included in the application from the generation wizard. In this case, only the name of the file and its extension are required. The file does not have to be extracted beforehand.

- an online resource. In this case, the URL of the resource must be prefixed by "http" (or "https").

## Remarks


### Google Cloud Print
<a name="google_cloud_print_ELTPARAGRAPHE000056"></a>

Google Cloud Print is a free service that is used to send, on the Google servers, the files that will be printed on the preset printers. Therefore, the print is performed via Internet.

To use the Google Cloud Print service: 

1. Configure the printers on the site of Google Cloud Print. 

2. In the application, use **GglPrintDocument**. 




For full details of how to use Google Cloud Print, visit: [http://www.google.com/cloudprint](http://www.google.com/cloudprint).
<a name="NOTE0_2"></a>


### Operating mode on the phone
<a name="operating_mode_the_phone_ELTPARAGRAPHE000075"></a>

**GglPrintDocument** opens several pages in the current application. 

- If the user is not connected, a page for connecting to Google is displayed. In this page, you must type the login and password of the Google account that was used to define the printers. 

- A page proposes the different available printers. All you have to do is select the requested printer to define the print options and to start the final print.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000249"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**GglPrintDocument** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
