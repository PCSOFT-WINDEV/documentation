


## xlsClose (Function)

***In french: xlsFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes an XLS file.

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003080015&name=xlsclose_function">See additional examples</a>

```wl
MyXLSFile is xlsDocument

// Open an XLS file
MyXLSFile = xlsOpen("C:\MyDirectories\File.XLS")
...
// Close the XLS file
xlsClose(MyXLSFile)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Syntax that uses the xlsDocument type

`xlsClose(<XLS document>)`
---

**`<XLS document>: (xlsDocument variable)`**

Name of the [xlsDocument](../WDLang5/1000017464.md) variable corresponding to the XLS file to close. The physical file associated with this variable (if it exists) is closed. The modifications performed in the file will not be saved until it is closed (use [xlsSave](../WDLang5/1000018057.md) if necessary).  


<a name="SYNTAXE2"></a>

### Syntax kept for backward compatibility with version 12

`xlsClose(<XLS file identifier>)`
---

**`<XLS file identifier>: (Integer)`**

Identifier of the XLS file to close, returned by [xlsOpen](../WDLang5/3080017.md).
