


## &lt;fbSession variable&gt;.Stop (Function)

***In french: &lt;Variable fbSession&gt;.Ferme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the Facebook session opened with [&lt;fbSession variable&gt;.Start](../WDLang5/1000021944.md).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Note**: This feature is available up to Android 11. Starting with Android 12, this function causes a fatal error. 
We advise you to: 

- use [SysAndroidVersion](../WDLang1/1000019785.md) to test the Android version used.

- use [AuthIdentify](../WDLang3/1000022219.md) to manage Facebook authentication. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySession is fbSession
// Connection to Facebook
...
// Disconnection
MySession.Stop()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Session>.Close()`
---

**`<Session>: (fbSession variable)`**

Name of the [fbSession](../WDLang5/1000021851.md) variable corresponding to the session to be closed.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The session is automatically stopped when closing the application. 

- To use the Facebook services again, you must reconnect with [&lt;fbSession variable&gt;.Start](../WDLang5/1000021944.md).
