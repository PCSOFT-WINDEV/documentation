## Syntax
<a name="SYNTAXE1"></a>

### Retrieving the source of an XML document found in an xmlDocument variable

`<Result> = <XML document>.BuildString([<Creation options>])`
---

**`<Result>: (Character string)`**

Formatted XML document. This result can be:

- handled in memory.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) saved in a file in XML format by [fSaveText](../WDLang1/3036046.md).

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) sent to the server.

- ...




**`<XML document>: (Control name)`**

[xmlDocument](../WDLang5/1000018782.md) variable containing the XML document to format.

**Warning** Result encoding corresponds to property **Encoding** property of variable [xmlDocument](../WDLang5/1000018782.md). If no encoding is specified, the XML document will be encoded in UTF-8.

**`<Creation options>: (Optional Integer constant)`**

Combination of following values:


|   |   |
| --- | --- |
| *XMLDocumentDefault* <br>(default value) | Generates the XML code with a header and from the root. |
| *XMLFormatting* | Generates XML code with formatting (indentation and carriage returns).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is now available.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *XMLNoHeader* | Generates the XML code without header. |
