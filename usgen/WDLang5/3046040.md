
## iEndReport (Function)

***In french: iFinEtat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Forces the report print to stop. The page footer and the "end of document" block are printed.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) If the report is printed in the report viewer, the preview window is not closed again.

**Note**: This function can only be used with reports created using the report editor.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Print in Linux](../Editeurs/9000078.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// End of print if the text file is not found
GLOBAL
	// Identifier of text file
	gfnFileID is int = 0

Local
	sTextFile is string = fCurrentDir() + "\Reports\Product.txt"

// Open the text file
gfnFileID = fOpen(sTextFile, foRead)
IF gfnFileID = -1 THEN
	Error(ErrorInfo())
	iEndReport() // Stop printing the report
END
```


<a name="Exemple2"></a>



```wl
// End of print forced when printing a record
IF MySelf..Source.CustomerName = "SMITH" THEN
	iEndReport()
END
```
