


## XMLSign (Function)

***In french: XMLSigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Signs an XML document.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyDoc is xmlDocument
NodeToSign is xmlNode, description="ProjectXSDSchema.RootNode"
MyCertificate is Certificate
	
MySignature is xmlSignature
MySignature.AlgorithmNormalization = atC14NExclusiveWithComments
MySignature.AlgorithmSignature = asRSA_SHA_160
MySignature.Key = MyCertificate

IF XMLSign(MySignature, MyDoc.NodeToSign) = True THEN 
	Trace("Document signed")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = XMLSign(<Signature> , <Insertion node>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the XML document has been signed,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Signature>: (xmlSignature or xmlXAdESSignature variable)`**

Signature to be used. This parameter can be one of the following:

- Name of the [xmlSignature](../WDLang5/1000020736.md) variable. 

- Name of the [xmlXAdESSignature](../WDLang5/1410091158.md) variable.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This type of variable is not available.
	




**`<Insertion node>: (xmlNode variable)`**

Name of the [xmlNode](../WDLang5/1000018786.md) variable that corresponds to the location where the signature should be inserted. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- You can use certificates stored on smart cards to sign XML documents. In this case, an RSA SHA 256 signature is used by default.
