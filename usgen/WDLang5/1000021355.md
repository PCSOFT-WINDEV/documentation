
## mlSetVariable (Function)

***In french: mlEcritVariable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Writes the value of a variable for the MATLAB session.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
gnIdSession is an integer
gnIdSession = mlInitialize()

IF gnIdSession = -1 THEN
	Error(ErrorInfo(errFullDetails))
END

// Code of BTN_Create_Variables button
aParameter is array of 1 real = [4]
aResult is array of 1 by 1 real = [[123]]

IF NOT mlSetVariable(gnIdSession, "i", tParameter) THEN
	Error("Failure writing the variable")
	RETURN
END

sCodeToRun is string = "myRoot = sqrt(i)"
SAI_Result = mlExecute(gnIdSession, sCodeAExecute)

tResult = mlGetVariable(gnIdSession, "maRac")
IF ErrorOccurred THEN
	Trace("Error: " + ErrorInfo())
END

Trace("Root = " + aResult[1,1])

Trace("List of variables before deletion: " + mlListeVariable(gnIdSession))

mlDeleteVariable(gnIdSession, "i")
mlDeleteVariable(gnIdSession, "maRac")

Trace("List of variables after deletion: " + mlListVariable(gnIdSession))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = mlSetVariable(<Session identifier> , <Variable name> , <Value>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the variable was modified, 

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant. 




**`<Session identifier>: (Integer)`**

Identifier of MATLAB session. This identifier is returned by [mlInitialize](../WDLang5/1000021351.md). 

**`<Variable name>: (Character string)`**

Name of the variable to write.

**`<Value>: (Array of integers, reals, ...)`**

Value of the variable.

## Remarks


### Supported types
<a name="supported_types_ELTPARAGRAPHE000066"></a>

The supported types are:

- signed and unsigned integers on 1, 2, 4 and 8, 

- reals on 4 and 8, 

- booleans, 

- characters.
