


## XMLDocument (Function)

***In french: XMLDocument***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a new XML document. This document can be:

- an empty document. It can be filled by [XMLAddAttribute](../WDLang5/3081011.md), [XMLAddChild](../WDLang5/3081002.md), ...

- a document containing the XML code that will be used by the XML functions of WLanguage. This code can come from a file in XML format or from a web service. The current element automatically corresponds to the root tag (the root is not created if it does not exist). This document can be closed by [XMLClose](../WDLang5/3081034.md).




**Note** The function **XMLDocument** function does not manipulate a file but an XML code.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) To create an XML document, the support for the XML parser must be enabled on the PHP server.

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003081008&name=xmldocument_function">See additional examples</a>

```wl
XMLSource is string
Res is boolean
// Create the XML document
Res = XMLDocument("XMLDoc", XMLSource)
// Was the document created?
IF Res = False THEN
	Error("The document was not created.")
ELSE
	Info("The document was successfully created. It is ready to be used.")
END
// Modify the document
...
```

## Syntax

`<Result> = XMLDocument(<XML document> [, <XML code> [, <Option>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the XML document is created, 

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs: 

	- the current position remains unchanged. 

	- the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).







**`<XML document>: (Character string)`**

Name given to the XML document. This name will be used by all the XML functions.

**`<XML code>: (Optional character string)`**

XML code that will be analyzed by the XML functions. If this parameter is not specified, a new empty XML document is created.

Caution: 

- If the encoding of the document is not specified in the XML header, the encoding used is "UTF-8".

- To specify a different encoding, the "encoding" attribute must be added to the XML tag.
	For example: &lt;?xml version="1.0" encoding="UCS-2"?&gt;


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This code must be in ANSI format. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) To create an empty XML document, this parameter must correspond to an empty string ("").

**`<Option>: (Optional constant)`**

Type of the created XML document (no option is selected by default): 



|   |   |
| --- | --- |
| *xdHTML* | XHTML document. This constant is used to optimize the operating mode of [XMLBuildString](../WDLang5/3081016.md). The document is processed by using the XHTML mode. |
| *xHTML* | HTML document.<br><br>**Warning**: **This constant is no longer available**. In fact, the operation of this constant was not optimized: the document was manipulated using the XML format, then in the event of failure it was then manipulated using the XHTML format. |

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is ignored.

## Remarks


### Reminder: XML language
<a name="reminder_xml_language_ELTPARAGRAPHE000143"></a>

XML is a language containing tags and attributes (called "elements" in this help). The structure of the XML code corresponds to a tree structure: information is organized in a treelike way.

The following terms are used to describe the different parts of an XML code:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=schema_xml.gif)

<a name="NOTE0_2"></a>


### XML functions and threads
<a name="xml_functions_and_threads_ELTPARAGRAPHE000292"></a>

If your application uses threads, the XML document is shared between all these threads. For more details on threads, see [Managing threads](../WDLang1/3077026.md).
<a name="NOTE0_3"></a>


### Limit
<a name="limit_ELTPARAGRAPHE000158"></a>

**XMLDocument** is suitable for loading XML documents whose size of text nodes does not exceed 9 MB. To handle documents with a greater size of nodes, you must use the [XMLDocument](../WDLang5/1000018782.md) type.
