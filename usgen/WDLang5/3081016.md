


## XMLBuildString (Function)

***In french: XMLConstruitChaîne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves and formats the content of an XML document. 
This XML document could: 

- have been created with [XMLDocument](../WDLang5/3081008.md) and modified with the XML functions.

- correspond to an [xmlDocument](../WDLang5/1000018782.md) variable.

Reminder: The [fSaveText](../WDLang1/3036046.md) function creates a text-only file in ANSI format. To create a Unicode text file, use  [fOpen](../WDLang1/3036036.md) / [fWrite](../WDLang1/3036014.md).![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The corresponding character string can be sent to the server for example.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the final XML document, the list of attributes is sorted in alphabetical order.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the XML document to format contains the declaration of an internal DTD, the description of this DTD will not be transcribed in the final XML document.

## Syntax
<a name="SYNTAXE1"></a>

### Retrieving the source of an XML document created by XMLDocument

`<Result> = XMLBuildString(<Name of the XML document> [, <Creation options> [, <Output format>]])`
---

**`<Result>: (Character string)`**

Formatted XML document. This result can be:

- handled in memory.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) saved in a file in XML format by [fSaveText](../WDLang1/3036046.md).

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) sent to the server.

- ...




**`<Name of the XML document>: (Character string)`**

Name of XML document to format. This document was created by [XMLDocument](../WDLang5/3081008.md) and it was modified by the [XML functions](../WDLang5/3081005.md).

**`<Creation options>: (Optional Integer constant)`**

Combination of following values:


|   |   |
| --- | --- |
| *XMLCurrentPosition* | Generates the XML code from the current position in the XML document (instead of the root). |
| *XMLDocumentDefault* <br>(default value) | Generates the XML code with a header and from the root. |
| *XMLFormatting* | Generates XML code with formatting (indentation and carriage returns). |
| *XMLNoHeader* | Generates the XML code without header. |



**`<Output format>: (Optional Integer constant)`**

Indicates the encoding used in the file header:


|   |   |
| --- | --- |
| *XMLEncodingIso8859_1* | Encoding according to the Latin character set |
| *XMLEncodingIso8859_2* | Encoding according to Iso8859_2 |
| *XMLEncodingIso8859_3* | Encoding according to Iso8859_3 |
| *XMLEncodingIso8859_4* | Encoding according to Iso8859_4 |
| *XMLEncodingIso8859_5* | Encoding according to Iso8859_5 |
| *XMLEncodingIso8859_6* | Encoding according to Iso8859_6 |
| *XMLEncodingIso8859_7* | Encoding according to Iso8859_7 |
| *XMLEncodingIso8859_8* | Encoding according to Iso8859_8 |
| *XMLEncodingIso8859_9* | Encoding according to Iso8859_9 |
| *XMLEncodingIso8859_15* | Latin-9 encoding |
| *XMLEncodingUTF8* | UNICODE 8 encoding |
| *XMLEncodingUTF16* | UNICODE encoding<br>Note: in this case, the function **XMLBuildString** function generates a 2-byte header to specify the "Byte Order". |
| *XMLNoEncoding*<br>(Default value) | No encoding |


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available. The encoding used is Iso8859_1.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The encoding used by default will be Iso8859_1 (Latin character set).

### Retrieving the source of an XML document found in an xmlDocument variable

`<Result> = XMLBuildString(<XML document> [, <Creation options>])`
---

**`<Result>: (Character string)`**

Formatted XML document. This result can be:

- handled in memory.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) saved in a file in XML format by [fSaveText](../WDLang1/3036046.md).

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) sent to the server.

- ...




**`<XML document>: (xmlDocument variable)`**

[xmlDocument](../WDLang5/1000018782.md) variable containing the XML document to format.

**Warning** Result encoding corresponds to property **Encoding** property of variable [xmlDocument](../WDLang5/1000018782.md). If no encoding is specified, the XML document will be encoded in UTF-8.

**`<Creation options>: (Optional Integer constant)`**

Combination of following values:


|   |   |
| --- | --- |
| *XMLDocumentDefault* <br>(default value) | Generates the XML code with a header and from the root. |
| *XMLFormatting* | Generates XML code with formatting (indentation and carriage returns).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is now available.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *XMLNoHeader* | Generates the XML code without header. |
