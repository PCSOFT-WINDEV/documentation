


## fbSession (Variable type)

***In french: fbSession***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **fbSession** type is used to describe a connection to the Facebook service and to manage the authentication to this service. You can define and change the characteristics of this connection using different WLanguage properties. 

**Important: Before using this type of WLanguage, you need to declare your application to Facebook.**. For more details, see [Using Facebook authentication](../WDLang5/1000021926.md). 

**Remarks**: 

- For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

- This type of variable is available in Linux only for WEBDEV websites. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Note**: This feature is available up to Android 11. Starting with Android 12, this function causes a fatal error. 
We advise you to: 

- use [SysAndroidVersion](../WDLang1/1000019785.md) to test the Android version used.

- use [AuthIdentify](../WDLang3/1000022219.md) to manage Facebook authentication. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySession is fbSession
MySession.AppID = "1702546803104741"
MySession.AppSecret = "badf00ddeadbeefbadc0deoff1ce8ecd"
MySession.Permission = [fbInfoProfile, fbEmail]
IF FBStartSession(MySession) THEN
	Info("Connected")
END
```

## Properties


### Properties specific to fbSession variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000047"></a>

The following properties can be used to handle a Facebook session:

| Property name | Type used | Effect |
| --- | --- | --- |
| AppID | Character string | Identifier of the application supplied when declaring the Facebook application. |
| AppSecret | Character string or Secret string | Secret code of the application supplied when declaring the Facebook application. <br><br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is ignored. |
| Email | Character string | Email of the end user (may be used to fill the connection dialog beforehand). <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is ignored. |
| PageID | Character string | Identifier of the Facebook page to open. If this parameter is empty, the session is started on a user and not on a page. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
| Permission | Array | Rights required during the Facebook connection. The rights (or permissions) to supply are defined by Facebook. The list of available rights can be consulted on the page: [https://developers.facebook.com/docs/facebook-login/permissions/v2.3](https://developers.facebook.com/docs/facebook-login/permissions/v2.3). <br><br>For some rights (the most common ones), you have the ability to use the following constants: <br><br>- *fbEmail* permission "email": allows access to a person's first email address. <br><br>- *fbInfoFriends* permission "user_friends": allows access to your application's list of friends. <br><br>- *fbInfoProfile* permission "public_profile": allows access to a person's public profile. <br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The "public_profile" permission is always required when starting a Facebook session. If this permission was not specified in the list of permissions for the [fbSession](../WDLang5/1000021851.md) variable passed as parameter to [FBStartSession](../WDLang5/1000021835.md), this permission will be automatically requested. |

## Remarks
<a name="NOTE0_3"></a>


### Closing the session
<a name="closing_the_session_ELTPARAGRAPHE000129"></a>

An open Facebook session is persistent: it will remain open: 

- until the application is closed. 

- until [FBStopSession](../WDLang5/1000021836.md) is called.
