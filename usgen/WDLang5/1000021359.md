
## mlSaveWorkspace (Function)

***In french: mlSauveEspaceDeTravail***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves the session workspace in a MATLAB file.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
gnIdSession is int = mlInitialize()
IF ErrorOccurred THEN
	ErrorInfo(errFullDetails)
	RETURN
END

sWorkspaceName is string = "TestWorkS.mat"
sVariableName, sListVariables is string

mlExecute(gnIdSession, "maVar = 1")
Trace("1 - Variables: " + mlListVariable(gnIdSession))
mlSaveWorkspace(gnIdSession, sNameSpace)

mlResetWorkspace(gnIdSession)
Trace("2 - Variables: " + mlListVariable(gnIdSession))
mlExecute(gnIdSession, "maVarEffacee = 2")
mlLoadWorkspace(gnIdSession, sNameSpace, False)
sListeVariables = mlListeVariable(gnIdSession)
Trace("3 - Variables: " + sListeVariables)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = mlSaveWorkspace(<Session identifier> , <File name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if saved successfully.

- <u><u><u><u>False</u></u></u></u> otherwise (if no variable is defined in the session for example). To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Integer)`**

Identifier of MATLAB session. This identifier is returned by [mlInitialize](../WDLang5/1000021351.md). 

**`<File name>: (Character string)`**

Path and name of the Mat-File file to use.
