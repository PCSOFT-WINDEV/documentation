
## mlGetVariable (Function)

***In french: mlRécupèreVariable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the value of a variable for the MATLAB session.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
gnIdSession is int = mlInitialize()
IF ErrorOccurred() THEN
	ErrorInfo(errFullDetails)
	RETURN
END
...
aResult is array of 1 by 1 real = [[123]]

mlResetWorkspace(gnIdSession)
tResult = mlGetVariable(gnIdSession, "maRac")
IF ErrorOccurred THEN
	Trace("Error: " + ErrorInfo())
END

Trace("Root = " + aResult[1,1])
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = mlGetVariable(<Session identifier> , <Variable name>)`
---

**`<Result>: (Array of integers, reals, ...)`**

Value of sought variable.

If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Session identifier>: (Integer)`**

Identifier of MATLAB session. This identifier is returned by [mlInitialize](../WDLang5/1000021351.md). 

**`<Variable name>: (Character string)`**

Name of the variable to retrieve.

## Remarks


### Supported types
<a name="supported_types_ELTPARAGRAPHE000059"></a>

The supported types are:

- signed and unsigned integers on 1, 2, 4 and 8, 

- reals on 4 and 8, 

- booleans, 

- characters.
