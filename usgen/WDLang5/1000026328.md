
## HTML constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manipulate HTML files:

| Constant | Details | Function / Type of variable |
| --- | --- | --- |
| **htmlNodeCDATA** | Node type in HTML document: CDATA node (XHTML compatibility). | [htmlNode](../WDLang5/1000026081.md) type |
| **htmlNodeComment** | Type of node in HTML document: Comment node. | [htmlNode](../WDLang5/1000026081.md) type |
| **htmlNodeElement** | Type of node in HTML document: Element node, an HTML tag. | [htmlNode](../WDLang5/1000026081.md) type |
| **htmlNodeTexte** | Type of node in HTML document: Text node. | [htmlNode](../WDLang5/1000026081.md) type |
