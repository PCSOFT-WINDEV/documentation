


## XMLExtractDocument (Function)

***In french: XMLExtraitDocument***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a new XML document from an existing XML document.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the final XML document, the list of attributes is sorted in alphabetical order.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
XMLSource is string
Res is boolean
// Load the XML content
XMLSource = fLoadText("C:\Temp\example.xml")

// Create the XML document
Res = XMLDocument("XMLDoc", XMLSource)

// Was the document created?
IF Res = False THEN
	Error("The following problem has been detected: " + ErrorInfo())
ELSE
	Res = XMLExtractDocument("XMLDoc", "MyNewDoc")
	IF Res = False THEN
		Error("The following problem has been detected: " + ErrorInfo())
	ELSE
		Info("New document successfully created")
	END
END
```

## Syntax

`<Result> = XMLExtractDocument(<Source XML document> , <New XML document>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the new XML document was created,

- <u><u><u><u>False</u></u></u></u> otherwise (the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>). To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Source XML document>: (Character string)`**

Name of the XML document from which the new XML document will be created. The new XML document will be created from the current position in the document (at current branch level).

**`<New XML document>: (Character string)`**

Name of the XML document to create.
