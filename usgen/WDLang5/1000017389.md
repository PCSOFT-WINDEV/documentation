


## RSS feed functions
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following functions are used to manage RSS feeds:



|   |   |
| --- | --- |
| [rssBuildString](../WDLang5/1000017395.md) | Builds the RSS feed and returns the result (in XML format) in a character string. |
| [rssDisplay](../WDLang5/1000017397.md) | Builds a RSS feed and returns the content of the RSS feed to the client. |
| [rssInitialize](../WDLang5/1000017388.md) | Loads a RSS feed in memory. |
| [rssSave](../WDLang5/1000017396.md) | Builds the RSS feed and saves the RSS feed in an XML file. |
