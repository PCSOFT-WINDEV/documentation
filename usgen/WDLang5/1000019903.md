
## iSequencingPrint (Function)

***In french: iEnchaînementImprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Prints a sequence of reports.

Note: Report print chaining allows you to print different reports in succession, visible as a single printout in the report viewer. You can add various types of documents in this sequence. For more details, see [Sequencing reports](../WDChamp/9000128.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
iDestination(iViewer)
iSequencingAdd(RPT_Report1)
iSequencingAdd(RPT_Report2, 3)
iSequencingPrint()
```
