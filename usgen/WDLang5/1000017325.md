


## xlsRow (Variable type)

***In french: xlsLigne ***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xlsRow** type is used to describe and modify a row in an Excel document. The characteristics of this line can be defined and modified using various WLanguage properties.

This type of variable is used by the [xlsDocument](../WDLang5/1000017464.md) type. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
// Ouverture d'un fichier Excel
sFichierExcel est une chaîne
sFichierExcel = fSélecteur("", "", "Sélectionnez un fichier Excel...", "Excel" + TAB + ...
	"*.xlsx" + RC + "Tous les fichiers (*.*)" + TAB + "*.*", "*.xlsx")
SI sFichierExcel = "" ALORS RETOUR

// Ouverture du document Excel
MonDocument est un xlsDocument
MonDocument = xlsOuvre(sFichierExcel)

// Police de caractères
MaPolice est une Police
MaPolice.Nom = "Arial"
MaPolice.Taille = 12
MaPolice.Gras = Vrai
MaPolice.Couleur = Blanc

// Cellule par défaut
MaCelluleDéfaut est un xlsCellule
MaCelluleDéfaut.CouleurFond = VertFoncé
MaCelluleDéfaut.Police = MaPolice

// Variable xlsLigne
MaLigne est un xlsLigne
MaLigne..Hauteur = 200
MaLigne..CelluleDéfaut = MaCelluleDéfaut

// Toutes les cellules de la ligne 2 ont 
// les caractéristiques de la cellule (couleur, taille, police, ...)
MonDocument..Ligne[2] = MaLigne

// Sauvegarde les modifications.
xlsSauve(MonDocument)
xlsFerme(MonDocument)
```

## Properties


### Properties specific to xlsRow variables
<a name="properties_specific_xlsrow_variables_ELTPARAGRAPHE000056"></a>

The following properties can be used to manipulate a variable of type **xlsLigne**:

| Name | Type used | Effect |
| --- | --- | --- |
| Cell | Array of [xlsCell](../WDLang5/1000017472.md) | Cells of the column. |
| DefaultCell | xlsCell | The default style of the row will correspond to the style of the specified cell. |
| Height | Double real | Height of row in pixels (between 0 and 545 pixels). If this property is initialized to -1, the default height of the rows in the Excel document will be used. |
