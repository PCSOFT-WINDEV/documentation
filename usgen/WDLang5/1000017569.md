


## gglInstantMessaging (Variable type)

***In french: gglMessagerieInstantanée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **gglInstantMessaging** type is used to describe and modify the characteristics of an instant messaging program used by a contact.

This type of variable is used by the [gglContact](../WDLang5/1000017434.md) type.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection to Google
Cnt is gglConnection
Cnt.Email = "balthazar@gmail.com"
Cnt.Password = "qwerty"
Cnt.ApplicationName = "MyApp-01"
IF GglConnect(Cnt) = False THEN
	Error(ErrorInfo())
END

...

// Retrieve the array of contacts
arrContacts is array of gglContact
arrContacts = GglListContact(Cnt)

// Display the data of instant messaging for the first contact
MyContact is gglContact = arrContacts[1]
Msg is dynamic gglInstantMessaging
FOR EACH Msg OF MyContact.InstantMessaging
	Trace(Mess.Label + ": " + Mess.Address)
END
```

## Properties


### Properties specific to gglInstantMessaging variables
<a name="properties_specific_gglinstantmessaging_variables_ELTPARAGRAPHE000030"></a>

The following properties can be used to define the characteristics of **gglInstantMessaging** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Address | Character string | Address of contact on the instant messaging. |
| Caption | Character string | Caption for describing the address. |
| Messaging | Integer constant | Type of instant messaging. Can correspond to one of the following constants:<br><br>- *gglAIM messaging*: AIM messaging<br><br>- *gglGoogleTalk messaging*: Google Messaging<br><br>- *gglICQ messaging*: ICQ messaging<br><br>- *gglJabber messaging*: Jabber messaging<br><br>- *gglMSN messaging*: MSN messaging<br><br>- *gglQQ messaging*: QQ messaging<br><br>- *gglSkype messaging*: Skype messaging<br><br>- *gglYahoo messaging* Yahoo Mail<br><br><br> |
| Primary | Boolean | <br><br>- <u><u><u>True</u></u></u> if the address corresponds to the main address of the contact, <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| Type | Integer constant | Type of the address corresponding to one of the following variables:<br><br>- *gglOther*: Neither home nor work address.<br><br>- *gglBureau*: Business address.<br><br>- *gglHome*: Home address.<br><br><br> |
