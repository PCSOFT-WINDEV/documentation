


## &lt;sfConnection variable&gt;.Add (Function)

***In french: &lt;Variable sfConnexion&gt;.Ajoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a record in a file of a Salesforce database. This file can be a preset file or a custom file.

**Note** A "Salesforce record" is also called a "Salesforce object".




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connect to Salesforce
Cnt is sfConnection
Cnt..Login = "vince@gmail.com"
Cnt..Password = "qwerty" + "XXB12VCZ54"
IF Cnt.Connect() = False THEN
	Error("The connection failed")
	RETURN
END

// Define the records
MyRecords is array of sfObjects
ARecord is sfObject
ARecord..ObjectType = "Mileage__c"
ARecord..Date__c = "2009-02-14"
ARecord..Miles__c = 333
Add(MyRecords, ARecord)

ARecord..Date__c = "2009-02-15"
ARecord..Miles__c = 222
Add(MyRecords, ARecord)

// Add the records
arrRes is array of sfSaveResult
arrRes = Cnt.Add(MyRecords)

// Read the result
res is sfSaveResult
err is sfError
FOR EACH res OF arrRes
	Trace("---------- " + res..ID + ": " + res..Success + " ----------")
	FOR EACH err OF res..Error
		Trace("Error: " + err..ErrorCode + " -> " + err..Message + "(" + err..Field + ")")
	END
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Salesforce connection>.Add(<Records to create>)`
---

**`<Result>: (Array variable)`**

Array of [sfSaveResult](../WDLang5/1000018460.md) variables containing the result data, especially the identifiers of records actually created.

**`<Salesforce connection>: (sfConnection variable)`**

Name of the variable of type [sfConnection](../WDLang5/1000017579.md) to be used.

**`<Records to create>: (Array variable)`**

Array of [sfObject](../WDLang5/1000018439.md) variables corresponding to the records (Salesforce objects) to create.

## Remarks


### Possible error cases: 
<a name="possible_error_cases_ELTPARAGRAPHE000200"></a>

- The Internet connection is not valid.

- The authentication was not performed properly.

- The XML response of the server cannot be read.




To find out whether an error occurred, use the [ErrorOccurred](../WDLang1/3087001.md) variable.
