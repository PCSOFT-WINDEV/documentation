
## iEndPrinting (Function)

***In french: iFinImprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Signals the end of the document to be printed and initiates the actual printing of data currently stored in the printer's print queue by functions [iPrint](../WDLang5/3046031.md), [iPrintImage](../WDLang5/3046017.md), [iNewLine](../WDLang5/3046035.md), ... All this data constitutes the document to be printed.

**Note** If the **iEndPrinting** function is not executed, all editing will be lost. This function must only be used with the reports created programmatically. This function must not be called in the processes of a report created with report editor in WIINDEV.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
iPrint("List of customers")
iSkipLine()
// Process
iEndPrinting()
```

## Remarks




### Action performed by iEndPrinting
<a name="action_performed_iendprinting_ELTPARAGRAPHE000062"></a>

**iEndPrinting** cancels:

- the configuration of [iMargin](../WDLang5/3046011.md),

- the fonts created beforehand.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the current "print preview" mode.

### Processes to interrupt during a print job
<a name="processes_interrupt_during_print_job_ELTPARAGRAPHE000082"></a>

During a print, the following processes must be interrupted:

- timer (with [EndTimer](../WDLang1/3015007.md)),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) management of DDE links (with [DDEUnLink](../WDLang1/3028005.md)),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) event (with [EndEvent](../WDLang1/3015010.md)).
