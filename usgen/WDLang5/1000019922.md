


## Watermark (Variable type)

***In french: Filigrane***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Watermark** type is used to handle the text printed in watermark in the reports created with the report editor or programmatically.

The **Watermark** type is used to define the advanced characteristics of the text in watermark. You can define and change the characteristics of this text using different WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Print a watermark in report background
MyWatermark is Watermark

// Text of the watermark
MyWatermark.Text = "Confidential"
// Font used
MyWatermark.Font.Name = "Arial"
// The watermark will be horizontally centered at bottom
MyWatermark.Position = iCenterH + iBottom
// Print in the report viewer
iDestination(iViewer)
// Indicates that the watermark will be printed during the print and in the duplicates
iParameterWatermark(iwatermarkPrinting + iwatermarkDuplicate, MyWatermark)
// Starts printing the report
iPrintReport(RPT_Commercial)
```

## Properties


### Properties specific to Watermark variables
<a name="properties_specific_watermark_variables_ELTPARAGRAPHE000049"></a>

The following properties can be used to handle a text as watermark:

| Property name | Type used | Effect |
| --- | --- | --- |
| Angle | Integer constant | Tilt angle of the watermark text. This angle can correspond to one of the following constants: <br><br>- *iAnglePolice* text tilt angle corresponds to the angle defined in the font. <br><br>- *iDiagonalDescending* text is printed on a 45° descending diagonal. <br><br>- *iDiagonalMontante* text is printed on a 45° rising diagonal. <br><br>- *iHorizontal* text is printed horizontally.<br><br><br><br><br>Before version 24, this property was named "Orientation". |
| Font | [Font](../Motscles/1514045.md) variable | Characteristics of the font that must be used for the watermark text.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This property is not available. By default, the Watermark uses the "Arial, Helvetica" font family. |
| Opacity | Integer | Watermark text opacity percentage. This percentage varies from 0 (invisible text) to 100 (totally opaque text). |
| Position | Integer constant | Constant (or combination of constants) used to define the position of watermark text: <br><br>- *iBas* text is aligned to the bottom of the text area. <br><br>- *iCentreH* text is centered horizontally in the text area. <br><br>- *iCentreV* text is centered vertically in the text area. <br><br>- *iRight* text is aligned to the right of the text area<br><br><br> |
| Size | Integer constant | Font size. This size corresponds to one of the following constants:  <br><br>- *iAutomatic* font size is automatically selected according to the length of the watermark text and the width of the report. <br><br>- *iToliceSize*: the size defined in the font is used.<br><br><br> |
| Text | Character string | Watermark text. |
