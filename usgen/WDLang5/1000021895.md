
## Facebook constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used by the functions for managing Facebook connections: 


| Constant | Description | Used by the functions |
| --- | --- | --- |
| **fbEmail** | <br><br>- Information to retrieve: User's Email. <br><br>- Rights requested when connecting to Facebook: "Email" permission: Allows access to a person's first email address.<br><br><br> | <br><br>- [FBGetUserInformation](../WDLang5/1000021837.md)<br><br>- [fbSession type](../WDLang5/1000021851.md)<br><br><br> |
| **fbIdentifier** | Information to be retrieved: User's Facebook ID. | [FBGetUserInformation](../WDLang5/1000021837.md) |
| **fbImage** | Information to be retrieved: User image. | [FBGetUserInformation](../WDLang5/1000021837.md) |
| **fbInfoFriends** | Permission "user_friends": Allows access to your application's list of friends. | [fbSession type](../WDLang5/1000021851.md) |
| **fbInfoProfile** | Permission "public_profile": Allows access to a person's public profile. | [fbSession type](../WDLang5/1000021851.md) |
| **fbName** | Information to retrieve: User name. | [FBGetUserInformation](../WDLang5/1000021837.md) |
| **fbSessionClosed** | Session status: Facebook session closed. | [FBSessionStatus](../WDLang5/1000021852.md) |
| **fbSessionIncorrectPermission** | Session status: Facebook session opened with different rights from those of the session passed in parameter. | [FBSessionStatus](../WDLang5/1000021852.md) |
| **fbSessionOpened** | Session status: Facebook session open. | [FBSessionStatus](../WDLang5/1000021852.md) |
