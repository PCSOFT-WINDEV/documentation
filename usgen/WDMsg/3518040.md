## Overview
<a name="overview_ELTTEXTE000200"></a>
You can create multilingual projects in WINDEV, WEBDEV or WINDEV Mobile. In this case, all the text of the project (from windows, pages, reports or controls) must be translated into the different languages.

A project can be translated using the following methods:

- You can translate the different elements of your project **as you go along**. The translation can be entered in the "Details" tab of the element description window. 
	You can easily translate using the "Translate" button ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Combo_des_saisie_btn_multilangue.GIF). The "Translate" button translates a selected input area according to the preferences defined in the options of the IDE used. Reminder: To set the desired options, under the "Home" pane, in the "Environment" group, pull down "Options" and select "WINDEV/WEBDEV/WINDEV Mobile general options". This solution is suitable for small-size applications, but can quickly become tedious.

- You can **use WDMSG**. This tool extracts the text that can be translated or corrected from your project. Once translated, the text can be reintegrated with WDMSG.
	**WDMSG is an optional tool of WINDEV, WEBDEV and WINDEV Mobile.**If you do not own WDMSG, contact the PC SOFT sales team or visit [www.windev.com](https://www.windev.com).




The extraction process creates an "Extraction file" with all the messages, text of controls, etc. This file can be: 

- a text file, 

- an HFSQL table,

- a WDMSG file (default recommended format). 




**If the extraction file is an HFSQL table or a WDMSG table**, the different elements of the table need be translated with WDTRAD. WDTRAD is a powerful translation tool that uses a dictionary. 
If you already use a dictionary from another translation software (often referred to as a "Translation memory"), it can also be used with WDTRAD. This allows you to take advantage of all the features of WDTRAD. 

**If the extraction file is a text file**, the different elements of this file can be:

- translated directly or via a translation tool.

- checked by a spelling checker.

- modified to standardize messages, titles, etc.


When translating or correcting text from the extraction file, the file format (specific to WDMSG) must not be modified. Changing the file format would prevent reintegrating the text that has been translated or edited.

**WDMSG can also be used to**:

- extract text added or edited since the last extraction. With this feature, you can make sure that all the text is translated. You can then translate and reintegrate this text into your project.

- compare the project text between two languages. This feature identifies any possible errors (e.g., same text in both languages, or missing translations). You can then fix any problems and reintegrate the text into your project.




For more details, see [Using WDMSG](../WDMsg/3518039.md).

## Remarks
<a name="remarks_ELTTEXTE000224"></a>


### Installing and starting WDMSG 2026
<a name="installing_and_starting_wdmsg_docparamversioncom_ELTPARAGRAPHE000072"></a>

- WDMSG 2026 is available for download. The download link is sent to you by email and/or with the package. 

- WDMSG 2026 must be installed in the WINDEV, WEBDEV or WINDEV Mobile 2026 installation directory.
	Please note: WDMSG 2026 only works with WINDEV, WEBDEV or WINDEV Mobile 2026.

- WDMSG 2026 can be started directly from WINDEV, WEBDEV or WINDEV Mobile 2026.

- You must use the dongle provided with WDMSG 2026.

- Only the projects developed in WINDEV, WEBDEV or WINDEV Mobile 2026 can be handled by WDMSG 2026.



<a name="NOTE2_2"></a>


### Installation package
<a name="installation_package_ELTPARAGRAPHE000106"></a>

The installation package of WDMSG 2026 allows you to install the following elements: 

- WDMSG 2026 and WDTRAD 2026: label extraction and translation tools for WINDEV, WEBDEV and WINDEV Mobile projects 2026. 

- WDINT 2026: tool for extracting messages displayed by WINDEV, WINDEV Mobile or WEBDEV frameworks (".DLL" files) and displayed by your Applications' Automation Functions (AAF). 



<a name="NOTE2_3"></a>


### Extraction files
<a name="extraction_files_ELTPARAGRAPHE000126"></a>

- The extraction file in text format created with WDMSG 2026 can be translated using specific translation software or with [WDTRAD 2026](../WDTRAD/3518010.md), the translation input tool supplied with WDMSG 2026. [WDTRAD 2026](../WDTRAD/3518010.md) creates a new file containing the translated text. 

- The extraction table in HFSQL table format or WDMSG format created with WDMSG 2026 can only be translated using [WDTRAD 2026](../WDTRAD/3518010.md), the translation entry tool supplied with WDMSG 2026. The text translated with [WDTRAD 2026](../WDTRAD/3518010.md) is in the same file.
