
## 4. Dedicated server and shared server

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Hosting providers offer two types of servers for installing WEBDEV websites:

- **shared server**:  
	Server whose resources are shared by multiple clients (organizations using the services of a hosting provider). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8-Serveur%20d%E9di%E9%20ou%20mutualis%E9-serveur%20mutualis%E9.gif)

	**Characteristics**:
	The hosting provider provides a server for different clients.
	The hosting provider:

	- configures the FTP server (required only for FTP deployments).

	- defines the maximum number of connections for all dynamic sites belonging to the same client (via WEBDEV Account Manager).
			Dynamic or static sites can be installed and updated via FTP.




- **dedicated server**: 
	The server is entirely dedicated to the client.
	The computer is either leased by the hosting provider, or provided by the client. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P8-Serveur%20d%E9di%E9%20ou%20mutualis%E9-serveur%20d%E9di%E9.gif)

	**Characteristics**:
	The hosting provider only provides Internet access (IP address, cable, etc.). 
	The client must:

	- provide the server (or rent it), 

	- configure the computer (system, etc.),

	- install the web server, 

	- install and configure WEBDEV websites (via HTTP, FTP or DVD-ROM).
