<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
During the development and deployment phases, the WEBDEV administrator is required to run dynamic WEBDEV websites.

When developing a dynamic WEBDEV website, the administrator is mainly used to:

- test dynamic sites via the test page ("Advanced" tab, "Test page" button).

- manage web services ("web services" tab).

- manage WebSocket servers ("WebSockets" tab). 

- configure the connections to dynamic sites for testing: connection timeout, etc. ("Configuration" tab).

- delete the current test connections ("Connections" tab).

- choose the web server used for testing ("Advanced" tab, "Server").

- diagnose any problems encountered when launching a dynamic WEBDEV site ("Advanced" tab, "Diagnostic" button).

- allow remote debugging ("Configuration" tab).

During the deployment phase, the WEBDEV administrator allows you to:

- manage the configuration of the different dynamic sites installed on the server: number of authorized connections, etc. ("Sites" tab).

- customize error messages displayed in the different dynamic sites installed on the server ("Advanced" tab).

- configure WEBDEV Clusters ("Cluster" tab).
