
## 13. Universal replication

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Universal replication enables you to keep databases of identical or different formats (HFSQL Classic, Oracle, SQL Server, etc.) up to date.. For example, you can synchronize an HFSQL Classic database with an Oracle database.

Universal replication uses a centralized model. This means that all databases are synchronized with a master database. Then, the master database reflect the changes in the other databases. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Replication_Bdd.gif)


The synchronization can be adapted to special cases. For example, it is possible to retrieve only records concerning a specified product or records made on a certain date, to manage conflicts, and so on.

These adaptations must be done through programming with [HRplFilterProcedure](../WDLang4/3044300.md).
