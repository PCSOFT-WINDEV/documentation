
## 1. Project and database schema

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The development of a **website** with WEBDEV is based on two main elements: the Project and the database schema.

A **WEBDEV Project** is a set of elements (pages, reports, controls, classes, components, etc.), which put together, make it possible to create a website.

A **WEBDEV database schema** contains the different tables used by the site.

A site is built from a project.

When a WEBDEV project uses tables, it must be associated with a database schema. Generally, a project is associated with one database schema, but it can also be associated with several database schemas. 

A database schema can be associated with one or more projects.
