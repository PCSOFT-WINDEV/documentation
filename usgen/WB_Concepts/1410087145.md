## Information required for deployment
<a name="information_required_for_deployment_ELTTEXTE000130"></a>
You need the information below to start the installation. Contact your hosting provider to get this information.

**Before deploying via FTP**, the developer must have the following information:

- Name of the server where the installation will be performed (or its IP address).

- Username and password defined in the FTP server.




**When deploying via FTP**, the developer must specify the following in [WDDeploy](../WDDeploie/3533001.md):

- the information provided by the hosting service.

- the files to install.
