<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
WEBDEV includes a debugger to help you optimize your code.

The debugger allows you to run your dynamic sites step by step, by viewing the WLanguage code run, the content of variables, ...<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P6_WB_Debogueur%20-%20HC%20N%B0002.gif&type=thumb)
**To start the debugger, use**:

- ***a breakpoint placed directly in the code editor***: The debugger will automatically start when the line preceded by a breakpoint is executed.
	To set a breakpoint, click in the left margin next to the line of code: the breakpoint appears as a red dot.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P6_WB_Debogueur%20-%20HC%20N%B0001.gif&type=thumb)


- ***WLanguage's STOP server keyword in your code***: The debugger will start automatically when this line of code is executed.

- ***the "Debug project"*** option: The debugger will start at the same time as the dynamic website test. On the "Project" tab, in the "Test mode" group, expand Test mode and select "Debug project".
