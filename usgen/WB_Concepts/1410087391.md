
## 5. Which type of server to choose?

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The table below shows the advantages and disadvantages of the different types of servers.

Regardless of the type of server, a deployment license is required for each server.

Each server hosts one or more dynamic WEBDEV websites (in Session or AWP mode).

| Server | Benefits / Drawbacks | When to use <br>this server? |
| --- | --- | --- |
| Shared | Advantages:<br><br>- Lower cost.<br><br>- Server managed by the hosting provider.<br><br><br><br><br>Disadvantages:<br><br>- Resources are shared with other websites on the same server.<br><br>- If one website becomes inaccessible, all the other websites are also affected.<br><br>- Stand-alone executable programs can rarely be used.<br><br>- Non-secure access to data: <br>	Unauthorized users can access the data. This includes the hosting provider, and possibly other clients, if the server is not configured properly. <br>	Tip: Encrypt data files to prevent unauthorized access.<br><br><br> | A shared server is recommended for:<br><br>- **sites with low traffic** (up to 20 or 30 simultaneous connections)<br><br>- sites requiring little memory (no large calculations performed on the server),<br><br>- Sites in startup phase.<br><br><br> |
| Dedicated | Advantages:<br><br>- The server resources are entirely available for your websites.<br><br>- You can decide how to retrieve your data: <br><br>	- sending a replication file by email,<br><br>	- using WDREPLIC, <br><br>	- copying files via FTP. <br><br><br><br><br><br><br><br>Disadvantages:<br><br>- More expensive.<br><br>- Server mostly managed by the client.<br><br><br> | A dedicated server is recommended for:<br><br>- **sites with high traffic**,<br><br>- sites that require a lot of disk space and memory,<br><br>- websites that handle sensitive data,<br><br>- dynamic sites.<br><br><br> |
