## Displaying the list of products
<a name="displaying_the_list_products_ELTTEXTE001342"></a>
We will create a window to list different products. These products will be displayed in a "Looper" control. 


### Creating the window
<a name="creating_the_window_ELTPARAGRAPHE000050"></a>

To create a new window:

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Nv_WM_GAF.jpg) in the quick access buttons (or press Ctrl + N). 

2. In the "New" window, click "Window", then "Window".

3. In the wizard, select the "Standard" tab. 

4. In the "Phone" area, choose "Looper" and confirm.
	Reminder: The different lessons of this tutorial are based on an Android configuration. If you are using an iOS configuration, you might find iOS-specific options.


5. The window creation wizard opens.

6. Since our project contains multiple platforms (iOS and Android), the wizard prompts you to select the platform to be used to create the window. We recommend that you select the platform with the lowest resolution (in this case, "Generic iPhone"). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0002.jpg&type=thumb)
Proceed to the next step of the wizard.
	If your project contains both platforms (Android and iOS), choosing "generic iPhone" will automatically generate the window for this platform. "iOS" automatically becomes the current platform of your project.


7. The wizard prompts you to choose the data source associated with the window. In our case, it will be the "Product" table:

	- The "Tables" option is selected by default.

	- Select the Product table.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0004.jpg&type=thumb)





8. Go to the next step.

9. Select the style of the Looper control: "Image + Title + Text below". This template provides an interface containing the product image, name and description.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0005.jpg&type=thumb)


10. Go to the next step.

11. The wizard automatically shows the table items that correspond to the different controls of the generated looper.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0006.jpg&type=thumb)


12. Keep the default items and go to the next step.

13. Keep the suggested sort on the "ProductID" item. Go to the next step.

14. The wizard shows multiple options for generating the Looper window: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0008.jpg&type=thumb)


	- **Generate a creation button in the Action Bar**: If this option is selected, you will be able to generate a window containing multiple Edit controls. 

- **Enable a swipe-to-delete gesture**: If this option is selected, the user will be able to delete an element from the Looper control by swiping the corresponding row.

- **Row selection code**: If "Generate the opening code of the form in read-only mode" (or "Generate the opening code of the form in edit mode") is selected, you will be able to generate a form window in read-only or edit mode.

15. In our example, keep the default options. Go to the next step.

16. Define a title and a name for the window. Enter "List of products" for the window title. The window name is automatically filled in.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0009.jpg&type=thumb)


17. Finish the wizard. The window is automatically created, displayed in the editor and saved. If your project uses the iOS and Android configurations, the window appears in the iOS configuration. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Liste_produit_RAD%20-%20HC%20N%B0010.jpg)

	The data is already displayed in the control, even in the editor. **This is known as "Live data"**: The contents of the tables located on the development computer are used in the windows or reports manipulated in the editor. This feature is very useful to define the size of the controls in a window, for example.
It can also be used to adapt the size of the controls to their content.





Our project uses two configurations. Let's now see the same window on Android

1. Expand "Configurations (iOS application)" at the top of the "Project explorer" pane. 

2. Double-click the "Android application" configuration. 

3. The Android configuration is automatically selected and the corresponding window appears.

## Creating the form window
<a name="creating_the_form_window_ELTTEXTE001414"></a>
We will create a new window to display the product form. Then, this window will be opened from the list of products to display the details of the selected product.


### Creating the window
<a name="creating_the_window_ELTPARAGRAPHE000150"></a>

To create the form window:

1. Create a new blank window.

	- Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Nv_WM_GAF.jpg) in the quick access buttons.

	- In the window that appears, click "Window" then "Window".

	- In the wizard, select the "Standard" tab, choose "Blank" and confirm.




2. The save window appears. Enter "Product form" for the window title. The name is automatically filled in ("WIN_Product_form"). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20Enregistrement%20-%20HC%20N%B0001.jpg)
Confirm. 

3. The window is added to the project, for all configurations. 

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20Enregistrement%20-%20HC%20N%B0002.jpg)
**If multiple platforms are defined in the project**, the save window associates the new element to all platforms.
To associate the element to a single platform, simply expand "Configurations" in the save window and choose the desired platform. 



### Creating the controls
<a name="creating_the_controls_ELTPARAGRAPHE000173"></a>

Our window must contain different controls with the product details. These controls will be bound to the items of the Product table. 

To create the different controls, we will use the items of the Product table directly:

1. In the "Project explorer" pane, expand "Database schema" by clicking the ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_Application%20compl%E8te%20-%202%20-%20Fiche%20produit%20-%20HC%20N%B0001%201.jpg) icon. The tables defined in the project database schema are displayed.

2. Click the icon to the left of the "Product" table to view all its items.

3. Select the items of the "Product" table displayed in the pane (except for the "ProductID" item).

4. Drag the items and drop them onto the window (for example, on the upper-left area).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%202%20-%20HC%20N%B0002.jpg&type=thumb)



The controls are automatically created and selected. 

We need to make a few changes to improve the UI. 


### Improving the UI
<a name="improving_the_ELTPARAGRAPHE000192"></a>

We are going to reorganize and resize the controls. 

Move all the controls to the bottom of the window. 

1. If necessary, select all the controls (Ctrl + A). 
	Note: Controls are selected by default when they are created. 

2. Move all the controls down. 




We will now create our UI step by step.  

**Step 1 - Image**
Click the Image control to select it. Move the control to the top center of the window. 
Alignment guides appear when moving the Image control. These guides help you place controls relative to the window or to other controls. 
**Step 2 - Caption**
Horizontally enlarge the control that contains the caption so that it fits the window. 
Place the control below the Image control. 

**Step 3 - Description**
Move the "Desc." control below the Caption control. "Desc." is a multiline control that contains the product description. 
Enlarge the control vertically to display at least three lines of text. 
Align the Caption and Description controls: 

1. Select both controls (the caption must be selected first). 

2. Go to the alignment options ("Alignment" tab of the WINDEV Mobile ribbon). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%202%20-%20HC%20N%B0001.jpg)


3. We will align the outside and inside borders of the controls. Click "Justify (Ins. and Out.)". 
	




**Step 4 - Price and Reference**
Move the Price control below "Desc.". Reduce the control so that it occupies half of the window width. 
Place the Reference control next to Price and reduce it horizontally so that it fits the window. Use the alignment guides to align the right side of the Reference control with the Caption and Description controls.  
Tip: You can adjust the size of the input area using the red sizing handles to reduce the space between the label and the input area.  
**Step 5 - Bar code**
Place the Bar code control below the Price control. 

**Step 4 - Quantity and Reorder**
Place the Quantity and Reorder controls side by side as you did for the Price and Reference controls.  

You will get the following result. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20-%20HC%20N%B0001.jpg&type=thumb)


Save the window.**Tab order in the window**
We changed the order of the controls in the window. This order defines how focus moves from one control to another. For more details, see [Tab order in a window, a page, etc](../Editeurs/2026006.md).
Let's quickly test the window: 

1. Test the window (click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_GO_Fen_WM_GAF.jpg) in the quick access buttons). 

2. The window is displayed with empty controls.

3. Close the simulator.




The controls are empty because no record has been selected in the table. Therefore, no data is displayed. 

We will see how to display the data of a given record in the window, and how to open this window from the list of products. 


### Displaying the data of a given record in the product form
<a name="displaying_the_data_given_record_the_product_form_ELTPARAGRAPHE000276"></a>

You can programmatically display the data from a given table record. 

To display the product data:

1. Open the WLanguage events of the WIN_Product_form window:

	- In the open document tabs, right-click the tab of the current window.

	- In the context menu that appears, select "Element code". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20-%20HC%20N%B0002.jpg)


	- The code editor appears.

2. Enter the following WLanguage code in the "End of initialization of WIN_Product_form" event:
	
	```wl
	Product.ToWindow()
	```

	[&lt;Table&gt;.ToWindow](../WDLang4/1000021397.md) gets the data from the current record in the table and displays it in the window controls. In our case, the current record is the record selected in the Looper control of "WIN_List_of_products". This Looper control is linked to the Product table. 

3. Close the code window.

4. Save the window.




To test this code, a record must be selected. To do so, we will write the code to open the product form from the list of products. 


### Opening the form from the list of products
<a name="opening_the_form_from_the_list_products_ELTPARAGRAPHE000301"></a>

To open the product form of the selected product, perform the following actions: 

1. Click "WIN_List_of_products" in the open document tabs (under the WINDEV Mobile ribbon): <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20-%20HC%20N%B0001%201.jpg)


2. Select the Looper control. 
	Make sure you select the Looper control, and not one of the controls it contains. 

3. Right-click the Looper control to open the context menu and select "Code".

4. In the code editor, write the following WLanguage code in the "Select a row in LOOP_Product" event:
	
	```wl
	WIN_Product_form.OpenMobileWindow()
	```

	Start writing and let the code completion system guide you. A drop-down list with the names of the different elements of the project appears as you type the name of the window. Select the name of the desired window. 
Similarly, the different functions and properties that can be used in the window appear when you insert a '.' (dot) after the name of the window.  


5. Save changes by clicking ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WM_GAF.jpg) in the quick access buttons.

6. Close the code window (click the "X" icon in the upper-right corner of the code editor).




Let's test the "WIN_List_of_products" window again in the simulator: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_GO_Fen_WM_GAF.jpg) in the quick access buttons.

2. In the list of products, click one of the products.

3. The detailed product window is displayed.




Close the simulator.

		- If no image is associated with the option.

	- In the "Preset image" area, expand the list and select "Done". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Cr%E9ation%20modif%20produit%20-%20HC%20N%B0005.jpg&type=thumb)

7. The WLanguage code of this option will be used to save the changes in the "WIN_Product_form" window. To write this code:

### Refreshing the list of products
<a name="refreshing_the_list_products_ELTPARAGRAPHE000428"></a>

When the product form is closed, the content of the list of products in the "WIN_List_of_products" window must be refreshed to take into account the changes made in the form. To do so, use the "Close a child window" of "WIN_List_of_products" event.

1. Click "WIN_List_of_products" in the open document tabs: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Fiche%20produit%20-%20HC%20N%B0001%201.jpg)


2. Right-click the window background and select "Code" in the context menu. The following WLanguage code is automatically displayed in the "Close a child window" event:
	
	```wl
	LooperDisplay(LOOP_Product,taCurrentSelection)
	```

	The generated code does not use prefix syntax but WLanguage "standard" syntax. In prefix syntax, this code is as follows: 


	```wl
	LOOP_Product.Display(taCurrentSelection)
	```



3. Let's take a look at this WLanguage code:

	- The "Close a child window" event is run when the child window of the current window is closed. In our case, it is run when the "WIN_Product_form" window is closed.

	- [&lt;Looper&gt;.Display](../WDLang2/1000023451.md) (or [LooperDisplay](../WDLang2/3083001.md)) updates the Looper control data in the "WIN_List_of_products" window. The **taCurrentSelection** constant updates the data according to the selection bar.
			This WLanguage code was automatically generated when the wizard created the window.




4. Close the code window (click the "X" icon in the upper-right corner of the code editor).

## Adding a product

### Principle
<a name="principle_ELTPARAGRAPHE000477"></a>

The principle for creating a product is as follows:

- In the list of products, we will add an option in the window Action Bar to open the "Product form" window.

- Then, we will edit the WLanguage code of the "Product form" window to add data to the Product table.





### Opening the product form from the Action Bar
<a name="opening_the_product_form_from_the_action_bar_ELTPARAGRAPHE000485"></a>

To add an option to the Action Bar:

1. Click "WIN_List_of_products" in the open document tabs to open the window in the editor.

2. Select the Action Bar (at the top of the window).

3. Right-click the Action Bar to open the context menu and select "Description". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Nv_Produit%20-%20HC%20N%B0001.jpg&type=thumb)


4. Click number 2 (any number 2 in the window). The window will switch to an interface where you can edit toolbar options. 

5. Click "+" (below the "Top right" area) to add an option. A new option is created at the top right. Change the option characteristics: 

	- In the "Option caption" area, type "New product". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Nv_Produit%20-%20HC%20N%B0002.jpg&type=thumb)


	- In the "Preset image" area, expand the list and select "Add". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Nv_Produit%20-%20HC%20N%B0003.jpg&type=thumb)

6. The WLanguage code of this option will open the "Product form" window and reset its controls. To enter this WLanguage code:

	- Select the Action Bar control. 

	- Click the "+" button. 

	- A drop-down menu with the "New product" option is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P4_MP%20-%20Nv_Produit%20-%20HC%20N%B0005.jpg)


	- Right-click the option.

- Select "Code" in the context menu that appears.

- Write the following WLanguage code in the "Select a menu" event:
			
		```wl
		Product.Reset()
		WIN_Product_form.OpenMobileWindow()
		```

			[&lt;Table&gt;.Reset](../WDLang4/1000025052.md) resets the item variables in the "Product" table to the default values to handle the new record.

7. Save changes by clicking ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WM_GAF.jpg) in the quick access buttons.

8. Close the code window (click the "X" icon in the upper-right corner of the code editor).





### Adding a product
<a name="adding_product_ELTPARAGRAPHE000527"></a>

Let's now check how to add records in the product form window.

1. Select the "WIN_Product_form" tab to open the window in the editor.

2. Open the code of the validation option in the Action Bar:

	- Select the Action Bar.

	- Click "OK". 

	- A drop-down menu with the "Done" option appears. 

	- Right-click "Done" and select "Code" in the context menu.

	- The WLanguage code of the "Click" event does not change:
			
		```wl
		Product.FromWindow()
		Product.Save()
		Close()
		```

			Let's look at this code again:

		- By default, [&lt;Table&gt;.Save](../WDLang4/1000024606.md) and [&lt;Table&gt;.Modify](../WDLang4/1000025038.md) have the same effect. In both cases, the current record in the table is modified. 

		- If [&lt;Table&gt;.Reset](../WDLang4/1000025052.md) has been called before [&lt;Table&gt;.Save](../WDLang4/1000024606.md) (which is the case when a new product is added), [&lt;Table&gt;.Save](../WDLang4/1000024606.md) adds the new record in the table (equivalent to [&lt;Table&gt;.Add](../WDLang4/1000024187.md)). 




3. Close the code window (click the "X" icon in the upper-right corner of the code editor).

### Taking photos
<a name="taking_photos_ELTPARAGRAPHE000670"></a>

We will now enter the WLanguage code to take a photo and display it in the Image control of the product form.



To take photos:

1. Right-click the Button control and select "Code" in the context menu.

2. Write the following WLanguage code in the "Click" event:
	
	```wl
	// Local variable
	ProductImage is string 
	// Start the camera
	ProductImage = VideoStartApp(viPictureCapture)
	IF ProductImage <> "" THEN
		IMG_Photo = ProductImage
	END
	```
In this WLanguage code, [VideoStartApp](../WDLang1/1000019368.md) is used to launch the native camera application on the device to record videos or take photos.

### Displaying stores on the Map control
<a name="displaying_stores_the_map_control_ELTPARAGRAPHE000907"></a>

We will write the code to display all the stores from the "Store" table on a map.

To do so, we will loop through the "Store" table with a FOR EACH loop. Then, we will use Marker variables. Marker variables allow you to define the markers that will be displayed on a map.

A marker contains different information. We will use the following information:

- Name,

- Latitude,

- Longitude.


[&lt;Map&gt;.AddMarker](../WDLang3/1000022422.md) adds a marker in the Map control. Then, simply adjust the zoom level to view all the markers in the Map control. If the zoom is not properly adjusted, some markers may not be visible or may overlap on the control.


### WLanguage code associated with the window
<a name="wlanguage_code_associated_with_the_window_ELTPARAGRAPHE000924"></a>

We will write the WLanguage code used to display the stores directly in the initialization event of the window that contains the Map control. 

To write the WLanguage code to display the stores:

1. Select the window tab in the open document tabs and click "Element code" in the context menu. The different WLanguage events associated with the window are displayed.

2. Write the following WLanguage code in the "Global declarations of..." event.
	
	```wl
	// Global variables
	StoreMarker is Marker
	// Load the stores
	FOR EACH Store 
		// Marker coordinates
		StoreMarker.Position.Latitude = Store.Latitude
		StoreMarker.Position.Longitude = Store.Longitude
		// Marker name
		StoreMarker.Name = Store.Name
		// Add the marker
		MAP_STORE.AddMarker(StoreMarker)
	END
	// Best zoom to view all markers on the map
	MAP_STORE.Zoom = zoomAdaptSize
	```


3. Save changes by clicking ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WM_GAF.jpg) in the quick access buttons.

4. Close the code window.




Test the "WIN_Map_of_stores" window in the simulator (click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_GO_Fen_WM_GAF.jpg) in the quick access buttons).

These conditions must be met for the Map control to be displayed correctly on the device. For more details, see [Conditions for using the Map control](../WDChamp/1000019823.md).
