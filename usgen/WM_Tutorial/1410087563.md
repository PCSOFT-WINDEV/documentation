## Creating the project
<a name="creating_the_project_ELTTEXTE000368"></a>
To start developing with WINDEV Mobile, we need to create a project. We will create our first project for Android and iOS.


	<B><B><B><B>Warning</B></B></B></B>

	 This project will be used in the different lessons of this tutorial.



To create a project, simply follow the steps of the project creation wizard:

1. Start WINDEV Mobile if necessary. 

2. Go to the WINDEV Mobile home page (Ctrl + &lt;).

3. Click "Create a project" (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0001%201.jpg) icon), then select "Android or iOS application". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0001.jpg&type=thumb)


4. The project creation wizard opens.
	The information specified in this wizard can be modified later.


5. The first step of the wizard allows you to define the project execution platform: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0002.jpg&type=thumb)
We will create a cross-platform application. Select "Android and iOS cross-platform" and proceed to the next step. 

6. The wizard prompts you to choose the type of devices the project is intended for: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0003.jpg&type=thumb)

	If the application will run on different types of Android and/or iOS devices (e.g. phones of different sizes or resolutions), it is recommended to use one of the following options: 

	- "Generate an application for phones and tablets", 

	- "Generate an application for phones".




In this case, WINDEV Mobile uses the smallest resolution to create the windows of the application. You can use anchors to adapt the application to any device. 


7. In this example, we are going to generate an application for phones. Select "Generate an application for phones" and go to the next step.

8. The wizard then allows you to choose the style book. Select "Phoenix_Palette". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0004.jpg&type=thumb)

	The style book is defined based on themes. Themes allow you to quickly create outstanding interfaces. A theme defines the window style as well as the style of all the controls that will be used in the window. Thus, the interface will always be cohesive and beautiful.


9. Go to the next step. 

10. The wizard prompts you to enter the project name and location. We will name our project "My_iOS_Android_Project". By default, WINDEV Mobile creates the project in ".\\My projects\\My_iOS_Android_Project". You can keep this location or change it via the [...] button. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet%20-%20HC%20N%B0005.jpg&type=thumb)


11. Click "Finish".




**The following actions are automatically performed**: 

- The project is automatically created. 

- Two project configurations are also created: 

	- an "iOS application" configuration, which is automatically selected.  

	- an "Android application" configuration. 


 We will take a closer look at these project configurations later in this tutorial. 

- The new element window appears. It allows you to create all the elements that can be associated with a project. Don't close this window, we will use it to create the first window of the application.

## First window: Displaying data
<a name="first_window_displaying_data_ELTTEXTE000419"></a>
In the first window, we will create a "Display" button that will show a message to the user.


### How to create the window?
<a name="how_create_the_window_ELTPARAGRAPHE000116"></a>

To create the window, we will use the window for creating new elements:

1. In the "New" window, click "Window", then "Window". The window creation wizard opens.

2. In the list of windows, select "Blank". Since the "iOS" configuration is selected by default, the wizard will prompt you to create a window for iPhone. The name of the theme used is displayed at the lower-right section of the wizard. 

3. Confirm. 




The window is automatically created in the editor. The save window appears. This window is used to specify:

- the element title. This title will be displayed in the Action Bar of the window.

- the element name (window name in this case). This name will be used programmatically.

- the element location. This location is the directory where the element will be saved (by default, the project directory)




In this example:  

1. In "Element title", enter "Welcome". The name of the element is automatically filled in ("WIN_Welcome"). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet2%20-%20HC%20N%B0001.jpg)


2. Confirm. 
	**Key information**:
The window name (that will be used in the code) is created automatically from the element title. If you want, you can simply write a name different from the element title.





The window is displayed in the window editor. As the default configuration is an iOS configuration, it uses the style of iOS windows.  This window is composed of multiple areas: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon_Premier_Projet_IOS%20-%20HC%20N%B0001.jpg)


1. The system bar, which shows the time. 

2. The Action Bar. Action Bars replace the title bar of a window and display different types of information: application icon, window title, menu options, etc.

3. The content area of the window, which will contain the different controls of the application. 





### Displaying a message
<a name="displaying_message_ELTPARAGRAPHE000150"></a>

The first window has now been created. We will now create a Button control to display a message.



To create the "Display" Button control:

1. On the "Creation" tab, in the "Usual controls" group, click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Bouton_WM_GAF.jpg). The control appears in creation mode under the mouse pointer.

2. Move the cursor to the position where you want to create the control (e.g. at the top of the window). To drop the control, simply click the window. The control appears with a box and sizing handles to indicate that it is selected.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon_Premier_Projet_IOS%20-%20HC%20N%B0002.jpg)

	**How to select a control?**
Simply click a control to select it. Selection handles then appear around the control. If the control is already selected, you can click the control again to edit the caption.





We will change the characteristics of this control: 

1. Right-click the control previously created. The context menu of the control appears. Select "Description" in this context menu. The Button control description window appears.

2. Enter the following control details: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet2%20-%20HC%20N%B0004.jpg&type=thumb)


	- Name: "BTN_Display".

- Caption: "Display".

3. Click OK to confirm changes in the control description window. The new control caption appears in the window editor.




To improve the UI of our first window, we will center the Button control in the window: 

1. Click the Button control to select it. 

2. On the "Alignment" tab, in the "Centering and distribution" group, click "Center in the parent (Horz.)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=P2_WM%20-%20Mon%20Premier%20Projet2%20-%20HC%20N%B0005.jpg)


3. The result appears immediately.  


If you don't know which alignment to choose, hover over the different options available in the "Alignment" tab. When you hover the mouse over an option, the controls selected in the window are automatically positioned and/or resized according to the hovered option.
**To apply the alignment**, click the option.
**If you don't want to apply the alignment**, simply exit the alignment options. The controls go back to their initial position.



In this lesson, we will display a message in a dialog box when the button is clicked. To do so, we will use the [Info](../WDLang1/3021011.md) WLanguage function.

1. Select the control (when the control is selected, sizing handles appear around it). 

2. Right-click the control to open its context menu.

3. Select "Code". This option opens the WINDEV Mobile code editor, in which all WLanguage statements can be typed. 
	The code editor lets you write all WLanguage instructions, organized in events associated with controls.


4. Write the following WLanguage code in the "Click BTN_Display" event: 
	
	```wl
	Info(“Hello”)
	```
[Info](../WDLang1/3021011.md) displays the message passed as parameter.
	
	




Save the changes by clicking ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ICO_Sauver_WM_GAF.jpg) in the quick access buttons or by pressing Ctrl + S.

Close the code editor (click the "X" icon in the upper-right corner of the code editor). The window editor appears again.
