## Events to use AJAX automatically
<a name="events_use_ajax_automatically_ELTTEXTE000490"></a>
The following events can be switched to automatic AJAX mode:

- "Click" server event of a Button, Link, Image (with clickable areas), TreeView or Pager control.

- "Whenever modified" server event of List Box, Combo Box, Check Box or Radio Button control.




By default, WLanguage events are not in Ajax mode: <br>![Event without AJAX technology](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche%20-%20Ajax%20-%20HC%20N%B0001.GIF)
The event header contains the "Full page reload" link. 

To switch an event to automatic AJAX mode:

1. Click the "Full page reload" link in the event header. 

2. Select "Minimal page reload (AJAX)". <br>![Event with AJAX technology](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Recherche%20-%20Ajax%20-%20HC%20N%B0002.GIF)


3. Now the event header shows a "Minimal page reload (AJAX)" link. 




**Remarks**:

- If an event that uses AJAX is run on a browser that does not support this technology, the event is run "as if" it did not use AJAX (the entire page is refreshed for example).

- If an AJAX event contains a function that is not available in AJAX mode, a compilation error is displayed.

### Automatic AJAX progress bar
<a name="automatic_ajax_progress_bar_ELTPARAGRAPHE000365"></a>

An automatic progress bar can be displayed in a page while an AJAX process/event is performed.

AJAX processes/events do not display the standard browser page load progress bar, as there is no loading process.

To display an automatic AJAX progress bar:

1. Add a Cell, Image, Static or HTML Static control to the page.

2. Customize this control. This control can contain a text ("Loading..." for example) and/or an animated image.

3. Go to the "Details" tab of the page description ("Description" in the context menu of the page).

4. In the "Automatic AJAX progress bar" control, select the control you have added and define its position.

## Specific features
<a name="specific_features_ELTTEXTE000544"></a>


### Specific features of the Pager control
<a name="specific_features_the_pager_control_ELTPARAGRAPHE000387"></a>

When a Table or Looper control is **automatically updated** in AJAX mode (when clicking a button that runs an AJAX code for example), the content of the pager associated with this control is automatically updated.

**Note**: To run the pager click code in AJAX mode:

- check "AJAX mode" in the Pager control description window, "General" tab.

- switch the "Click" event of the Pager control to automatic AJAX mode (click "AJAX" in the event bar).



<a name="NOTE4_2"></a>


### Table/Looper control and AJAX mode
<a name="tablelooper_control_and_ajax_mode_ELTPARAGRAPHE000403"></a>

When a Table or Looper control is in AJAX mode ("Server + AJAX" mode in the control description), rows are no longer displayed using a pager, but a vertical scrollbar.

For more details, see ["Server + AJAX" Table controls](../WDChamp/3055117.md).
<a name="NOTE4_3"></a>


### Special characters
<a name="special_characters_ELTPARAGRAPHE000415"></a>

Some special characters are automatically replaced with an empty string ("") in AJAX mode. These characters are the characters whose ASCII code is strictly less than 32, except for the  characters 9, 10 and 13 (TAB and CR respectively).

In most cases, these special characters are not used in the strings.
