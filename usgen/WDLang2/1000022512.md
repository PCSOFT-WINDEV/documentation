


## BannerStopSliding (Function)

***In french: BandeauArrêteDéfilement***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***BannerStopScrolling*</**>** is kept for backward compatibility. This function has been replaced with ***BannerStopSliding*</**>**.
</DIV><a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Stops the automatic slide on a Sliding Banner control.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stop sliding (stays on the current banner)
BannerStopSliding(BAN_Banner)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`BannerStopSliding(<Sliding Banner control>)`
---

**`<Sliding Banner control>: (Control name)`**

Name of Sliding Banner control to use.
