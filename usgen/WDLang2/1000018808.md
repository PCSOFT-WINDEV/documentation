


## UploadDelete (Function)

***In french: UploadSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a file from the list of files to upload: the file will not be uploaded on the server. 

**Note**: This function can only be used with a Multi-file Upload control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// -- Browser click code of "BTN_Delete"
nFile is int = ListSelect(LIST_MultiUpload)
IF nFile <> -1 THEN
	UploadDelete(UPL_MultiUpload, nFile)
	// No need to update the list of files to upload
	// it will be automatically done by the modification code of the Upload control
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`UploadDelete(<Upload control> , <File index>)`
---

**`<Upload control>: (Control name)`**

Name of the multi-file Upload control used. 

**`<File index>: (Integer)`**

Index of the file to be removed from the list of files to be uploaded (1 for the first file in the list, 2 for the second, etc.).

## Remarks


### Maximum size of files to upload
<a name="maximum_size_files_upload_ELTPARAGRAPHE000173"></a>

**By default,** the size of files to upload is not limited in the WEBDEV engine. This size can be limited by the WEBDEV Application Server. 
The file will not be uploaded if its size exceeds the limit size.
To modify the maximum size of the files to upload in the WEBDEV Application Server, the registry must be modified on the server:  

1. To change the size of uploaded files for all WEBDEV 2026 applications, select the following key: 

	- 32-bit: HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0

	- 64-bit: HKEY_LOCAL_MACHINE\\SOFTWARE\\WOW6432Node\\PC SOFT\\WEBDEV\\31.0




2. Add the MAX_UPLOAD string. The value of this string will be the maximum size of files to upload (in KB).
