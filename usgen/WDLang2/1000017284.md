
## JSONExecute (Function)

***In french: JSONExécute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calls the URL of a page on the server that returns data in JSON format (JavaScript Object Notation). The server data is evaluated and returned as an object.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyContacts is dynamic object
MyContacts = JSONExecute(FolderWeb() + "US/Page_Object.awp?id=12")

// Process the data received
FOR i = 1 _TO_ Dimension(MyContacts:List)
	ListAdd(LIST_List_of_contacts, MyContacts:List[i]:Name + ...
	" " + MyContacts:List[i]:FirstName)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Synchronous syntax: function is blocked until data is received

`<Result> = JSONExecute(<Page URL>)`
---

**`<Result>: (Dynamic object)`**

Data returned by the server. This result must be assigned to a dynamic object.

**`<Page URL>: (Character string)`**

URL of the page that returns the JSON data. It can be an absolute or relative URL.

- If the URL does not start with 'http:', it is used directly. Warning: the domain must be in the domain of the current page (or a sub-domain), otherwise the call will fail.

- If the URL starts with '/', it is considered as an absolute path in the current domain.

- In all the other cases, the URL is considered as a path relative to the directory of the current page.  





<a name="SYNTAXE2"></a>

### Asynchronous syntax: a procedure is executed when data is received

`JSONExecute(<Page URL> , <Procedure name>)`
---

**`<Page URL>: (Character string)`**

URL of the page that returns the JSON data. It can be an absolute or relative URL.  

- If the URL does not start with 'http:', it is used directly. Warning: the domain must be in the domain of the current page (or a sub-domain), otherwise the call will fail.

- If the URL starts with '/', it is considered as an absolute path in the current domain.

- In all the other cases, the URL is considered as a path relative to the directory of the current page.  




**`<Procedure name>: (Character string)`**

Name of the browser procedure (global or local procedure) that performs the process of the JSON data.
This procedure has the following format:


```txt
PROCEDURE <Browser procedure> (<JSON result of the call>)
```
The parameter passed to this procedure is a dynamic object that contains the JSON data. It must be indicated in the declaration of the procedure.

## Remarks




### Querying a server on the same domain or on a different domain
<a name="querying_server_the_same_domain_different_domain_ELTPARAGRAPHE000055"></a>

In most cases, the server is located on the domain that hosts the site. In this case, no specific operation is required. 

When querying a server on another domain: 

- the server must implement the CORS protocol, 

- the curernt site must be allowed to contact the server. 




For more details, see [https://www.w3.org/wiki/CORS](https://www.w3.org/wiki/CORS) about the CORS protocol (Cross-Origin Resource Sharing). 
<a name="NOTE0_2"></a>




### Page that returns JSON data
<a name="page_that_returns_json_data_ELTPARAGRAPHE000073"></a>

The page that returns the JSON data can be an Active WEBDEV Page, a PHP page or another type of page.

**If it is a WEBDEV page,** it can be an Active WEBDEV Page or a PHP page. This page must return the JSON data with [StringDisplay](../WDLang2/3012001.md). Furthermore, [StringToUTF8](../WDLang1/3024042.md) must also be used to get a valid format.

For example, the following code creates the string that will be returned. This string contains the code used to define an object and an array. The code used is JavaScript code.


```wl
sObject is string = [
{id: 12,
List: [
	{Last name: "smith", First name: "john"},
	{Last name: "dupond", First name: "marie"},
	{Last name: "martin", First name: "lauré"}]
}
]
StringDisplay(StringToUTF8(sObject))
```

<a name="NOTE0_3"></a>


### IMPORTANT: JSON validity
<a name="important_json_validity_ELTPARAGRAPHE000092"></a>

The validity of the JSON data received from the server is not checked. Make sure that the called page is a trusted page to prevent JavaScript injection attacks in the current page.
<a name="NOTE0_4"></a>


### Security
<a name="security_ELTPARAGRAPHE000099"></a>

To protect data, you can use a secure page (https URL).
