


## &lt;Page&gt;.ClosePopup (Function)

***In french: &lt;Page&gt;.FermePopup***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Hides a page displayed as a popup via [&lt;Page&gt;.DisplayPopup](../WDLang2/1410087260.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Closes the page displayed as a popup
PAGE_ProductDetails.ClosePopup()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Page>.ClosePopup()`
---

**`<Page>: (Page name)`**

Name of the page displayed as a popup that will be hidden. This page must have been displayed by [&lt;Page&gt;.DisplayPopup](../WDLang2/1410087260.md). Otherwise, **&lt;Page&gt;.ClosePopup** has no effect.




<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Browsers don't refresh the display in the middle of Javascript code: functions [&lt;Page&gt;.DisplayPopup](../WDLang2/1410087260.md) and **&lt;Page&gt;.ClosePopup** must be used in different processes/events. If these functions are used in the same process/event, the Popup page is not displayed.
