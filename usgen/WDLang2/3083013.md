


## LooperModify (Function)

***In french: ZoneRépétéeModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the values of the attributes in a row of a Looper control. 

**Note**: We recommend using the [LooperModifyLine](../WDLang2/3083015.md) function.. Indeed, [LooperModifyLine](../WDLang2/3083015.md) allows you to insert:

- TAB characters into the attributes/controls.

- all types of values into the attributes/controls.

## Example


```wl
// Modification d'une répétition dans un champ Zone répétée
ZoneRépétéeModifie(ZR_Zone1, NomProduit + TAB + CodeProduit, Indice)
```
<a name="Exemple2"></a>

```wl
// Modifie une valeur dans le champ Zone répétée en 12ème position
ZoneRépétéeModifie(ZR_Zone1, Nom + TAB + Prenom + TAB + ...
	NumTel + TAB + NumFax, 12)
```

<a name="SYNTAXE1"></a>

## Syntax

`LooperModify(<Looper control> , <Value> [, <Index>])`
---

**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter is equal to an empty string (""), the modification will be performed in the current Looper control.

**`<Value>: (Character string)`**

List of modified values. This parameter must have the following format: 

```txt
<Valeur 1> + TAB + ... + <Valeur N>
```

The different values must be specified in the order of the attributes (Looper control description window).
To specify no value for an attribute, use an empty string ("") or 0 (depending on the type of the attribute).

**`<Index>: (Optional integer)`**

Index of the row to be modified.

- If this parameter is not specified, the modification will be performed on the current element.

- If &lt;Index&gt; is greater than the number of rows, **LooperModify** is equivalent to [LooperAdd](../WDLang2/3083006.md).

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000126"></a>

**LooperModify** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **LooperModify** can only be used on a Looper control populated programmatically.
<a name="NOTE0_2"></a>


### Sort
<a name="sort_ELTPARAGRAPHE000140"></a>

If **LooperModify** modifies a sort attribute of the current Looper control, the sort order set with this attribute will be removed.
<a name="NOTE0_3"></a>


### Handling a binary memo
<a name="handling_binary_memo_ELTPARAGRAPHE000151"></a>

To modify a binary memo in a Looper control, use [LooperModifyLine](../WDLang2/3083015.md).

### Modifying a Looper control without attributes
<a name="modifying_looper_control_without_attributes_ELTPARAGRAPHE000165"></a>

To modify a Looper control without attributes, it is recommended to directly change the value of the relevant controls.

For example:

```wl
// Modification de la valeur des champs
// du champ Zone répétée "ZR_Zone1" pour la répétition 23
ZR_Zone1[23].ChampNom = "Hobbes"
ZR_Zone1[23].ChampPrénom = "Samantha"
```
