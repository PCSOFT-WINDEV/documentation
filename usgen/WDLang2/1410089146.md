
## WLanguage procedure called by PopupDisplayPage



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [PopupDisplayPage](../WDLang2/1410087258.md) after the popup page is closed. This is a browser procedure, and it can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 
```wl
// Displays PAGE_ProductDetails as popup
// Waits for the page to close and displays the returned value
PopupDisplayPage(PAGE_Details, (nProductID), PopupDisplay_Callback, BTN_CONTROL, popupPositionXY, 10, 10)
	
	INTERNAL PROCEDURE PopupDisplay_Callback(ReturnPopupPage)
		Trace("Popup returned: [%ReturnPagePopup%]")
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PopupAffichePage_Callback(<Return value>)`
---

**`<Return value>: (Type of the return value)`**

Value that will be returned by the page via the [PopupClosePage](../WDLang2/1410087259.md) function.
