


## &lt;Looper&gt;.DeleteAll (Function)

***In french: &lt;Zone répétée&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all rows from a Looper control populated programmatically.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Reset
LOOP_Looper1.DeleteAll()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Looper control>.DeleteAll()`
---

**`<Looper control>: (Control name)`**

Name of the Looper control to be used.

<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000196"></a>

**&lt;Looper&gt;.DeleteAll** can only be used on a Looper control populated programmatically. 
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **&lt;Looper&gt;.DeleteAll** can only be used on a Looper control populated programmatically.
