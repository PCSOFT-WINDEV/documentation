
## PageCurrentLayout (Function)

***In french: PageAgencementEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the index of the current layout: 

- in the current page.

- in the specified page.






![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, it is only possible to see the layout of the current page. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF PageCurrentLayout() = 2 THEN
	STC_Details = Customer.Details
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the layout of the current page

`<Result> = PageCurrentLayout()`
---

**`<Result>: (Integer)`**



- Index of the current layout.

- 0 if the page has no layout. 

- one of the following constants: 
	


|   |   |
| --- | --- |
| *agencementWINDEVMobile* | The specific layout for WINDEV Mobile is in progress. |
| *layoutPrint* | The specific layout for printing is being used. |
| *layoutWINDEV* | The specific layout for WINDEV is being used. |
| *layoutWINDEVMobileTablet* | The specific layout for WINDEV Mobile (tablet) is in progress. |







<a name="SYNTAXE2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available in browser code
### Getting the layout of a specific page

`<Result> = PageCurrentLayout(<Page>)`
---

**`<Result>: (Integer)`**



- Index of the current layout.

- 0 if the internal page has no layout. 

- one of the following constants: 
	


|   |   |
| --- | --- |
| *agencementWINDEVMobile* | The specific layout for WINDEV Mobile is in progress. |
| *layoutPrint* | The specific layout for printing is being used. |
| *layoutWINDEV* | The specific layout for WINDEV is being used. |
| *layoutWINDEVMobileTablet* | The specific layout for WINDEV Mobile (tablet) is in progress. |






**`<Page>: (Page name)`**

Name of the page used. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Layouts are numbered in the order in which they were created.

- The layout changes if the device orientation changes or if [PageChangeLayout](../WDLang2/1000024598.md) is run.
