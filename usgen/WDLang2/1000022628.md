


## &lt;Sliding Banner&gt;.StopSliding (Function)

***In french: &lt;Bandeau défilant&gt;.ArrêteDéfilement***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***Scolling Banner.StopScrolling*</**>** is kept for backward compatibility. This function has been replaced with ***&lt;Sliding Banner&gt;.StopSliding*</**>**.
</DIV><a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Stops the automatic slide on a Sliding Banner control.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stop sliding (stays on the current banner)
BAN_Banner.StopSliding()
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Sliding Banner control>.StopSliding()`
---

**`<Sliding Banner control>: (Control name)`**

Name of Sliding Banner control to use.
