


## LooperAdd (Function)

***In french: ZoneRépétéeAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row at the end of a Looper control.






	<B><B><B>Warning</B></B></B>

	 It is recommended to use [LooperAddLine](../WDLang2/3083004.md). [LooperAddLine](../WDLang2/3083004.md) allows you to add:

- TAB characters into the attributes/controls.

- all types of values into the attributes/controls.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initialisation du champ Zone répétée ZR_REPETE1 
ZoneRépétéeSupprimetout(ZR_REPETE1) 
HLitPremier(Produit, NomProd) 
TANTQUE HEnDehors() = Faux
	ZoneRépétéeAjoute(ZR_REPETE1, Produit.NomProd + TAB + Produit.CodeProduit) 
	HLitSuivant(Produit, NomProd) 
FIN
```
<a name="Exemple2"></a>

```wl
// Ajout d'une répétition vide 
ZoneRépétéeAjoute(ZR_Zone1) 
// Positionnement sur la répétition vide 
Indice = ZoneRépétéeOccurrence(ZR_Zone1) 
// Puis initialisation des attributs 
ATT_AttributNom[Indice] = "Hobbes"
ATT_AttributPrénom[Indice] = "Samantha"

// Ou initialisation des champs
// ZR_Zone1[Indice].ChampNom = "Hobbes"
// ZR_Zone1[Indice].ChampPrénom = "Samantha"
```

## Syntax

### Adding a row to a Looper control with attributes

`<Result> = LooperAdd(<Looper control> [, <Value>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was successful,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter is an empty string (""), the row will be added in the current Looper control.

**`<Value>: (Optional character string)`**

List of values that will be inserted into the new row. This parameter must have the following format: 

```txt
<Valeur 1> + TAB + ... + <Valeur N>
```

The different values must be specified in the order of the attributes (Looper control description window).
If you don't want to specify a value for one of the attributes, use an empty string ("") or 0 (depending on the attribute type).
An empty row will be added if this parameter corresponds to an empty string ("").

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000150"></a>

**LooperAdd** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **LooperAdd** can only be used on a Looper control populated programmatically.
<a name="NOTE0_2"></a>


### Adding an empty row
<a name="adding_empty_row_ELTPARAGRAPHE000178"></a>

After adding an empty row, each attribute or control must be initialized individually.

For example:

- For a Looper control with attributes:
	
	```wl
	// Ajout d'une répétition vide
	ZoneRépétéeAjoute(ZR_Zone1)
	
	// Positionnement sur la répétition vide
	Indice = ZoneRépétéeOccurrence(ZR_Zone1)
	// Puis initialisation des attributs
	ATT_AttributNom[Indice] = "Hobbes"
	ATT_AttributPrénom[Indice] = "Samantha"
	ATT_AttributCouleurPrénom[Indice] = RougeClair
	ATT_AttributVisibleAdresse[Indice] = Faux
	```


- For a Looper control without attributes: 
	
	```wl
	// Ajout d'une répétition vide
	ZoneRépétéeAjoute(ZR_Zone1)
	
	// Positionnement sur la répétition vide
	Indice = ZoneRépétéeOccurrence(ZR_Zone1)
	// Puis initialisation des champs
	ZR_Zone1[Indice].ChampNom = "Hobbes"
	ZR_Zone1[Indice].ChampPrénom = "Samantha"
	ZR_Zone1[Indice].ChampPrénom.CouleurFond = RougeClair
	ZR_Zone1[Indice].ChampAdresse.Visible = Faux
	```




<a name="NOTE0_3"></a>


### Row characteristics
<a name="row_characteristics_ELTPARAGRAPHE000206"></a>If a value is the result of a calculation, enclose the numerical expression in brackets. For example:

```wl
ZoneRépétéeAjoute(ZR_ZoneCalcul, (53+29) + TAB + (83-21))
```

<a name="NOTE0_4"></a>


### Position of the new row
<a name="position_the_new_row_ELTPARAGRAPHE000221"></a>

By default, the row is added at the end of the Looper control.

If the Looper control is sorted ([LooperSort](../WDLang2/3083009.md)), the added row is positioned in the Looper control according to the current sort.
<a name="NOTE0_5"></a>


### Handling a binary memo
<a name="handling_binary_memo_ELTPARAGRAPHE000235"></a>

To add a binary memo into a Looper control, use [LooperAddLine](../WDLang2/3083004.md).
