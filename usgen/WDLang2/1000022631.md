


## &lt;Sliding Banner&gt;.StartSliding (Function)

***In french: &lt;Bandeau défilant&gt;.LanceDéfilement***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***Scrolling Banner.StartScrolling*</**>** is kept for backward compatibility. This function has been replaced with ***&lt;Sliding Banner&gt;.StartSliding*</**>**.
</DIV><a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Enables the automatic slide on a Sliding Banner control.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start sliding
BAN_Banner.StartSliding()
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Sliding Banner control>.StartSliding()`
---

**`<Sliding Banner control>: (Control name)`**

Name of Sliding Banner control to use.
