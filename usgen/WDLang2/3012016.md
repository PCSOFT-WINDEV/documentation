


## ScriptExecute (Function)

***In french: ScriptExecute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calls an external script (.asp or .php) and returns the result in a string. An http request is sent: you can use either a POST method or a GET method.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Runs the "Script1.php" script found at the root of the Web site 
// and returns the result in MyBuffer
MyBuffer is Buffer
MyBuffer = ScriptExecute("/Script1.php")
```
<a name="Exemple2"></a>

```wl
// Login page in asp. Sends 3 parameters with the POST method
MyBuffer is Buffer
MyBuffer = ScriptExecute("/ASP/Login.asp", ...
	"Name=BOB&Pass=My+Secret&Lang=3", True)
```
<a name="Exemple3"></a>

```wl
// Retrieve the "home" page of the "server2" site
MyBuffer is Buffer
MyBuffer = ScriptExecute("http://www.server2.csom/default.htm")
HTMSTC_HTMLStatic = MyBuffer
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ScriptExecute(<Script name> [, <"Name1=Param1&Name2=Param2&..."> [, <Runtime method>]])`
---

**`<Result>: (Buffer or character string)`**

Result of ASP script. In most cases, this result can be displayed by [StringDisplay](../WDLang2/3012001.md).

**`<Script name>: (Character string)`**

Address of the script. The script URL can have the following format:

- "http://NomDeServeur/Adresse.asp": the Adresse.asp script is located on the "ServerName" machine

- "/Scripts/MonScript.php": The MonScript.php script is located on the current server, in the "/Scripts" subdirectory of the site.

- you have the ability to use a secure address (https)




**`<"Name1=Param1&Name2=Param2&...">: (Optional character string)`**

Parameters intended for the script. This string contains for each parameter:

- the parameter name,

- the  sign'=', 

- the parameter value.


Two parameters are separated by the  sign'&'.

**`<Runtime method>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> to run a POST method, 

- <u><u><u><u>False</u></u></u></u> (default) to run a GET method.

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000060"></a>

**ScriptExecute** is slower than [ScriptDisplay](../WDLang2/3012017.md). 
<a name="NOTE0_2"></a>


### Encoding parameters
<a name="encoding_parameters_ELTPARAGRAPHE000072"></a>

The content of parameters is automatically encoded to get a valid URL:

- transformation into UTF-8 (according to the options of the page and project)

- encoding of special characters
