


## LooperDelete (Function)

***In french: ZoneRépétéeSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a row from a Looper control. The RepeatString field is automatically refreshed.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete row 1
LooperDelete(LOOP_ProdLooper, 1)
```
<a name="Exemple2"></a>

```wl
// Delete the current row
LooperDelete(LOOP_ProdLooper)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`LooperDelete(<Looper control> [, <Index> [, <Animation>]])`
---

**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter is equal to an empty string (""), the deletion will be performed in the current Looper control.

**`<Index>: (Optional integer)`**

Index of the row to delete.

- If this parameter is not specified, the deletion will be performed in the current row.

- If &lt;Index&gt; is greater than the number of rows, **LooperDelete** has no effect.




**`<Animation>: (Optional Integer constant)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Management of animation during the deletion: 



|   |   |
| --- | --- |
| *loopAnimationDelete* | Plays an animation during the deletion. This animation corresponds to a disappearance effect by reducing the height of the row. |
| *loopAnimationNone*<br>(Default value) | No animation is played during the deletion. |

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000115"></a>

**LooperDelete** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **LooperDelete** can only be used on a Looper control populated programmatically.


### Use with a Looper control based on a table
<a name="use_with_looper_control_based_table_ELTPARAGRAPHE000127"></a>

If the Looper control is based on a table:

- the record is deleted from the table. 

- the next row is selected (if the last row is deleted, the previous row will be selected). The record selected in the linked table corresponds to the selected row.
