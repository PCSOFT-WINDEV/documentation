


## &lt;WBAdminAuth variable&gt;.CreateAccount (Function)

***In french: &lt;Variable adminWBAuth&gt;.CréeCompte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a WEBDEV account on a WEBDEV Application Server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
wbAuthLogin is WBAdminAuth
wbAuthLogin.ServerAddress = "https://my-server.internal/"
wbAuthLogin.User = "WWW\DATA"
wbAuthLogin.Password = "www"

WBAccount is WBAdminAccount
WBAccount.User = "USER_X"
WBAccount.VirtualServer = WBAccount.User

ResultCreate is boolean = wbAuthLogin.CreateAccount(WBAccount, "USERXPASSWORD")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <WEBDEV Application Server>.CreateAccount(<Account> , <Password> [, <Existing account>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the account was created,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<WEBDEV Application Server>: (WBAdminAuth variable)`**

Name of the [WBAdminAuth](../WDLang2/1410089328.md) variable that describes the server and the administrator account used to query the WEBDEV Application Server. 
Warning: To add WEBDEV accounts, the Windows account used must be the Server administrator..

**`<Account>: (WBAdminAccount variable)`**

Name of the [WBAdminAccount](../WDLang2/1410089382.md) variable with the description of the account to be created.

**`<Password>: (Character string or Secret string)`**

Password of the account to be created.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Existing account>: (Optional Integer constant)`**

Existing accounts. 

- By default, an existing account cannot be created again. In this case, &lt;Result&gt; is <u><u><u><u>False</u></u></u></u>. 

- Constant *adminWBEcraseSiExisting*Allows recreation of an existing account.

## Remarks


### Two-factor authentication
<a name="twofactor_authentication_ELTPARAGRAPHE000214"></a>

You can enable two-factor authentication for an account through the Remote WEBDEV administrator. Two-factor authentication requires a unique code to verify the user's identity. This code can be received by email or via an Authenticator app.

When you use WEBDEV Application Server functions, you may encounter authentication errors if the account uses two-factor authentication. Two cases must be taken into account: 

- the function returns a boolean and &lt;Result&gt; is <u><u><u><u>False</u></u></u></u>. To check if it is an authentication error, it is necessary to check the value of the [ErrorOccurred](../WDLang1/3087001.md) variable and the value returned by [ErrorInfo](../WDLang1/3013008.md).

- the function does not return a boolean. To determine if the error is due to the authentication process, the following conditions must be met: 

	- variable [ErrorOccurred](../WDLang1/3087001.md) is set to <u><u><u><u>True</u></u></u></u>, 

	- when used with the *errCode* constant, [ErrorInfo](../WDLang1/3013008.md) returns 2. 







To fix this error: 

- Create a window/page where users can enter their verification code. 

- If an error occurs due to two-factor authentication: 

	- Open the verification code input window. 

	- Users automatically receive the authentication code according to the method chosen in the Remote WEBDEV administrator. They can then enter the code in the window or page.

	- Assign the code to the **OneTimePassword** property of the [WBAdminAuth](../WDLang2/1410089328.md) variable. 

	- Run the function again.
