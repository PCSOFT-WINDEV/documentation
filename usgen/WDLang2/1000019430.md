


## ImagePrevious (Function)

***In french: ImagePrécédent***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Displays the previous image for the scroll.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Goes back to the previous banner
ImagePrevious(IMG_Banner)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`ImagePrevious(<Image control>)`
---

**`<Image control>: (Control name)`**

Name of the control to be used: 

- Image control.

- Clickable Image control.

- Thumbnail control.






<a name="NOTE0"></a>

## Remarks


### Managing the transition effects
<a name="managing_the_transition_effects_ELTPARAGRAPHE000047"></a>

If transition effects have been specified during the control description: 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) These transition effects are taken into account when **ImagePrevious** is used . 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) These transition effects are ignored when **ImagePrevious** is used. Indeed, the page is entirely refreshed. To take these effects into account, you must use a code in Ajax mode.
