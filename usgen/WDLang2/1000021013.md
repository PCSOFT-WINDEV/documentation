
## FullScreenDisable (Function)

***In french: PleinEcranDésactive***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disables the "Full screen" mode of browser. 

Note: To activate "Full screen" mode, use the [FullScreenEnable](../WDLang2/1000021012.md) function.. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
FullScreenDisable()
```
