


## ImageLast (Function)

***In french: ImageDernier***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Displays the last image for the scroll.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the last banner
ImageLast(IMG_Banner)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`ImageLast(<Image control>)`
---

**`<Image control>: (Control name)`**

Name of control to use:

- Image control.

- Clickable Image control.

- Thumbnail control.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Managing the transition effects
<a name="managing_the_transition_effects_ELTPARAGRAPHE000048"></a>

If transition effects have been specified during the control description: 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) These transition effects are taken into account when **ImageLast** is used . 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) These transition effects are ignored when **ImageLast** is used. Indeed, the page is entirely refreshed. To take these effects into account, you must use a code in Ajax mode.
