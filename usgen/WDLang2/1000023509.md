


## &lt;Looper&gt;.Insert (Function)

***In french: &lt;Zone répétée&gt;.Insère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a row into a Looper control.

**Note**: We recommend using the [&lt;Looper&gt;.InsertLine](../WDLang2/1000023511.md) function.. Indeed, [&lt;Looper&gt;.InsertLine](../WDLang2/1000023511.md) allows you to insert:

- TAB characters into the attributes/controls.

- all types of values into the attributes/controls.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) For the Looper controls without attributes, we recommend that you use [&lt;Looper&gt;.InsertLine](../WDLang2/1000023511.md).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initialisation du champ Zone répétée ZR_REPETE1
ZR_REPETE1.SupprimeTout()
Produit.LitPremier(NomProd)
TANTQUE Produit.EnDehors() = Faux
	ZR_REPETE1.Insère(Produit.NomProd + TAB + Produit.Code)
	Produit.LitSuivant(NomProd)
FIN
```
<a name="Exemple2"></a>

```wl
// Ajout de valeurs dans le champ Zone répétée en 12ème position
ZR_REPETE1.Insère(Nom + TAB + Prénom + TAB + NumTel + TAB + NumFax, 12)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Looper control>.Insert(<Value> [, <Index>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was successful,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Looper control>: (Control name)`**

Name of the Looper control to be used.

**`<Value>: (Character string)`**

List of values that will be inserted into the new row. This parameter must have the following format:

```txt
<Valeur 1> + TAB + ... + <Valeur N>
```

The different values must be specified in the order of the attributes (Looper control description window).
To specify no value for an attribute, use an empty string ("") or 0 (depending on the type of the attribute).

**`<Index>: (Optional integer)`**

Index of the row from which the new row will be inserted.

- If this parameter is not specified or is equal to -1, the row will be inserted before the current row. If no row is selected, the row will be inserted at the end of the Looper control.

- If &lt;Index&gt; is greater than the number of rows, the row will be inserted at the last position in the Looper control. In this case, **&lt;Looper&gt;.Insert** is equivalent to [&lt;Looper&gt;.Add](../WDLang2/1000023469.md).

- If this parameter is 0, the row will be inserted at the first position in the Looper control.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000280"></a>

**&lt;Looper&gt;.Insert** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **&lt;Looper&gt;.Insert** can only be used on a Looper control populated programmatically.
<a name="NOTE0_2"></a>


### Row characteristics
<a name="row_characteristics_ELTPARAGRAPHE000309"></a>If a value is the result of a calculation, enclose the numerical expression in brackets. For example:

```wl
ZR_ZoneCalcul.Insère((53+29) + TAB + (83-21), 12)
```

<a name="NOTE0_3"></a>


### Handling a binary memo
<a name="handling_binary_memo_ELTPARAGRAPHE000325"></a>

To insert a binary memo into a Looper control, use [&lt;Looper&gt;.InsertLine](../WDLang2/1000023511.md).
<a name="NOTE0_4"></a>


### Sort
<a name="sort_ELTPARAGRAPHE000340"></a>

**&lt;Looper&gt;.Insert** ignores the sort.
