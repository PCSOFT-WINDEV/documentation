
## WBAdminApplication (Variable type)

***In french: adminWBApplication***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WBAdminApplication** type is used to define all the advanced characteristics of an application deployed on a WEBDEV Application Server. You can define and change the characteristics of this application using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
login is WBAdminAuth
login.ServerAddress = "http://xxxx"
login.User = "myuser"
login.Password = "mypassword"

Applications is array of WBAdminApplication
Applications = WBAdminListApplication(login)
FOR i = 1 _TO_ Applications.Count  
     Trace(Applications[i].Name)
     Trace(Applications[i].OwnerAccount)
END
```

## Properties


### Properties specific to WBAdminApplication variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000026"></a>

The following properties can be used to manipulate a variable of type **WBAdminApplication**:

| Property name | Type used | Effect |
| --- | --- | --- |
| OwnerAccount | Character string | Application owner account. |
| Name | Character string | Application name. |
| Type | Integer constant | Type of application:<br><br>- *adminWBTypeSite* Site. <br><br>- *adminWBTypeWebserviceSOAP* SOAP web service. <br><br>- *adminWBTypeWebserviceREST* REST web service. <br><br>- *adminWBTypeWebSocket* WebSocket. <br><br><br> |
