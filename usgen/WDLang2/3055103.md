| ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Num%E9ro6_bleu.gif) | Database schema of the procedure result. |

[AJAXExecute](../WDLang2/3055114.md) allows you to call a server procedure from Browser code. No other process is run until the result of the server procedure is received. 
When this function is used, no values from the control are sent to the server. With this function, the browser requests the server to execute a procedure and return a result. The result can be in JSON or XML format, or be a series of "simple" variables (int, string, boolean, real). 

[AJAXExecuteAsynchronous](../WDLang2/3055115.md) executes a server procedure without refreshing the page. This function does not block the application. The other processes continue to run, whether or not the result of the procedure is received. 
Once the result of the server procedure is available, [AJAXExecuteAsynchronous](../WDLang2/3055115.md) automatically calls a browser procedure to retrieve the result.

## AJAX functions
<a name="ajax_functions_ELTTEXTE000277"></a>
For more complex processes, WEBDEV offers several AJAX functions (listed here in order of interest):


|   |   |
| --- | --- |
| [AJAXAvailable](../WDLang2/3055112.md) | Determines whether the AJAX technology is supported by the current browser. |
| [AJAXExecute](../WDLang2/3055114.md) | Executes a server procedure without refreshing the page. This function blocks the application. No other process is run until the result of the server procedure is received. |
| [AJAXExecuteAsynchronous](../WDLang2/3055115.md) | Executes a server procedure without refreshing the page. This function does not block the application. The other processes continue to run (no matter whether the result of the procedure run is retrieved or not). |
| [AJAXAsynchronousCallPending](../WDLang2/3055111.md) | Determines if a server procedure called by [AJAXExecuteAsynchronous](../WDLang2/3055115.md) is being executed. |
| [AJAXCancelAsynchronousCall](../WDLang2/3055110.md) | Cancels the automatic execution of the browser procedure called by [AJAXExecuteAsynchronous](../WDLang2/3055115.md). |


These functions allow you to run a server procedure from a browser process.

**Note**: It is necessary to ensure consistency between the data stored on the server and the data shown to the end user. For example, if data is modified, this data must be modified both on the server and on the page displayed in the browser.

## Procedures that can be called by AJAX
<a name="procedures_that_can_called_ajax_ELTTEXTE000301"></a>
To secure the WEBDEV websites, the server procedures are protected from illegal calls (attempt to re-route a session for example). To run a server procedure from a browser process ([AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)), you must allow this procedure to be called by AJAX.

By default, new server procedures are set to "automatic" mode. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Ajax_procedures%20-%20HC%20N%B0002.gif)


Automatic mode detects if there are any calls to the server procedure written in Browser code. This includes any use of the [AJAXExecute](../WDLang2/3055114.md) function or any direct calls. The number of detected calls appears in the procedure header. 

Two other modes can be enabled via the context menu of the procedure header:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Ajax_procedures%20-%20HC%20N%B0003.gif)


- "Always accessible from Browser code" (accessible). 

- "Never accessible from Browser code" (inaccessible). 




You can force accessible mode to handle cases where calls are not automatically detected. This happens when procedures are located in external components and calls are made from the project. 

You can also force inaccessible mode. In this case, the procedure can never be called from a Browser code. 

**Note**: Procedures accessible from Browser code can be executed with malicious intent. "Inaccessible" mode provides additional security compared to automatic mode. "Automatic" mode makes the procedure inaccessible from a browser only if it has never been called from Browser code.

## WLanguage functions useless in AJAX
<a name="wlanguage_functions_useless_ajax_ELTTEXTE000346"></a>
All the functions available in WEBDEV server can be used in AJAX. However, the folllowing functions are useless in AJAX. Therefore, these functions are not available in AJAX.


|   |   |
| --- | --- |
| [ContextClose](../WDLang2/3058003.md) | Closes a page session |
| [ContextOpen](../WDLang2/3058004.md) | Opens a new page context without returning the information to the browser. |
| [FileDisplay](../WDLang2/3012005.md) | Displays a file in the user's browser. |
| [FramesetDisplay](../WDLang2/3058006.md) | Displays a WEBDEV frameset in the user's browser. |
| [FramesetRefresh](../WDLang2/3058014.md) | Refreshes a frameset displayed in the user's browser from the context on the server. |
| [FramesetUse](../WDLang2/3058012.md) | Displays a WEBDEV frameset in the browser of the Web user and closes all the current page and frameset contexts. |
| [InitWindow](../WDLang1/3038019.md) | Resets (or not) the controls found in the current page and runs the initialization processes of controls. |
| [PageInitialization](../WDLang2/3058025.md) | Resets (or not) the controls found in the current page and runs the initialization processes of controls. |
| [PageUse](../WDLang2/3058016.md) | Displays a WEBDEV page in the browser of the Web user and closes all the current page contexts. |
| [ScriptDisplay](../WDLang2/3012017.md) | Calls an external script (.php, .asp, .mhtml or .mht) and returns the result page in the current browser window. |
| [StringDisplay](../WDLang2/3012001.md) | Displays a character string (or a buffer) in the browser. |
| [UploadCopyFile](../WDLang2/3012023.md) | Saves on the server a file "uploaded" by the Web user. |
| [UploadFileName](../WDLang2/3012022.md) | Returns the name of a file "uploaded" by the user. |
| [Use](../WDLang1/3038044.md) | Displays a page in the user's browser. |


This list can evolve. It is recommended to check the documentation for each function. The ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=IconeAjax.GIF) logo indicates whether the function is available in AJAX.
