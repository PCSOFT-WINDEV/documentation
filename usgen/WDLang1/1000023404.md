


## &lt;Table&gt;.AddLine (Function)

***In french: &lt;Table&gt;.AjouteLigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row in: 

- a Table control,

- a TreeView Table control. 




If the added row is the first row of the control, the added row becomes the current row.

**Remarks**: 

- To add a row at a specific position, use [&lt;Table&gt;.InsertLine](../WDLang1/1000023407.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To add a row with an animation, use [&lt;Table&gt;.AddLineWithAnimation](../WDLang1/1000023678.md).











<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Ajout des éléments "Dubois" et "Pierre"
// dans la dernière ligne du champ "TABLE_TableProduit"
TABLE_TableProduit.AjouteLigne("Dubois", "Pierre")
```


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Exemple de champ Table
// avec une colonne "Liste de valeurs" (WEBDEV) ou "Combo" (WINDEV).
// Cette colonne peut être remplie directement dans sa description
// ou par programmation.
// L'exemple ci-dessous traite le cas par programmation.

// 1 - Ajout des valeurs possibles dans la colonne "liste de valeurs" / Combo
TABLE_MaTable.COL_Valeur.Ajoute("Val 1")
TABLE_MaTable.COL_Valeur.Ajoute("Val 2")
TABLE_MaTable.COL_Valeur.Ajoute("Val 3")
TABLE_MaTable.COL_Valeur.Ajoute("Val 4")

// 2 - Ajout de lignes avec des éléments sélectionnés 
// dans la colonne "liste de valeurs" ou Combo
// ici la seconde colonne correspond à la liste de valeurs / combo.
// Seul l'indice à sélectionner dans la liste de valeurs ou combo est précisé.
TABLE_MaTable.AjouteLigne("ligne 1", 1) // Où 1 correspond à "Val 1"
TABLE_MaTable.AjouteLigne("ligne 2", 4) // Où 4 correspond à "Val 4"
```

## Syntax

`<Result> = <Table control>.AddLine([<Element column 1> [... [, <Element column N>]]])`
---

**`<Result>: (Integer)`**



- Index of the added row, 

- -1 if an error occurred.




**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control.




**`<Element column 1>: (Type of associated column (optional))`**

Elements of the row that will be added into the specified control. Each element corresponds to a control column. The type of the added element must be compatible with the type of relevant column.
If none of these parameters is specified, an empty row is added into the control. For a control based on a data file, the default values defined in the linked data file are taken into account.



**`<Element column N>: (Type of associated column (optional))`**

Elements of the row that will be added into the specified control. Each element corresponds to a control column. The type of the added element must be compatible with the type of relevant column.
If none of these parameters is specified, an empty row is added into the control. For a control based on a data file, the default values defined in the linked data file are taken into account.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000304"></a>

**&lt;Table&gt;.AddLine** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **&lt;Table&gt;.AddLine** cannot be used on data-bound Table controls. 
<a name="NOTE0_2"></a>


### Characteristics of row elements
<a name="characteristics_row_elements_ELTPARAGRAPHE000346"></a>

- To specify no value for an element, use an empty string ("") or 0 (according to the type of column).

- If an element corresponds to the calculation result, the numeric expression must be enclosed in brackets. 
	For example: 
	
	```wl
	TABLE_TableCalcul.AjouteLigne((53+29), (83-21))
	```




<a name="NOTE0_3"></a>


### Position of the new row
<a name="position_the_new_row_ELTPARAGRAPHE000368"></a>

By default, the row is added at the end of the rows displayed by the control.

Special case: 

- If the control is sorted by [&lt;Table&gt;.Sort](../WDLang1/1000024293.md), the added row is positioned in the control according to the current sort.

- If the control is sorted by the user, the sort is ignored when inserting the row. The row is added at the end of control.



<a name="NOTE0_4"></a>


### Limits: Maximum number of lines displayed
<a name="limits_maximum_number_lines_displayed_ELTPARAGRAPHE000390"></a>

The maximum number of rows that can be displayed in a TreeView Table control or hierarchical Table is limited only by available RAM (theoretical maximum: 2 billion rows).

However, we do not advise you to use large Table or TreeView Table controls for performance and user-friendliness reasons (time required to fill the control for example).

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000406"></a>

- **If the cascading input is enabled**, the table linked to the control is automatically modified when the user goes to the next row.

- **If the cascading input is not enabled**, the table linked to the control is not modified. To write the content of the new row to the linked table, [&lt;Table&gt;.Save](../WDLang1/1000024249.md) must be used after **&lt;Table&gt;.AddLine**.




**Remarks**: 

- The "Cascading input (Add)" option can be selected in the "Details" tab of the control description.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available for Table controls populated programmatically and with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available for "Server + AJAX" data-bound Table controls based on a table.

### Table field/Hierarchical table file: Add multiple lines
<a name="table_fieldhierarchical_table_file_add_multiple_lines_ELTPARAGRAPHE000444"></a>

A virtual row is created each time **&lt;Table&gt;.AddLine** is called in a Table or TreeView data-bound Table control. The information will be saved in the linked table only when [&lt;Table&gt;.Save](../WDLang1/1000024249.md) is called.

If **&lt;Table&gt;.AddLine** is successively called in the same process without being followed by [&lt;Table&gt;.Save](../WDLang1/1000024249.md), only the FIRST call is effective (the following calls are ignored). Only one row is added to the Table or TreeView Table control.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This operating mode is only available for "Server + AJAX" Table controls based on a table.

### Table or TreeView data-bound Table control in edit mode
<a name="table_treeview_databound_table_control_edit_mode_ELTPARAGRAPHE000499"></a>

If **&lt;Table&gt;.AddLine** is called:

- In a control event, the cursor is automatically positioned on the first editable column in the new row.

- In an event that does not belong to the control (or in another process), [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) must be used to resume the input in the Table or TreeView Table control.



<a name="NOTE0_9"></a>


### Adding images
<a name="adding_images_ELTPARAGRAPHE000517"></a>

To add an image to a Table or TreeView Table control: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) specify the name and full path of the image to be added. For example:
	
	```wl
	TABLE_MaTable.AjouteLigne("C:\MesDocuments\MonImage.BMP")
	```


- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) specify the path and name of image to add. The path is relative to the "&lt;Project_Name&gt;_WEB" directory. For example:
	
	```wl
	// Ajoute l'image située dans le répertoire "WB_MonAppli_WEB"
	TABLE_MaTable.AjouteLigne("MonImage.BMP")
	```



**Note**: To display the added image correctly, the column must be of type Image.
