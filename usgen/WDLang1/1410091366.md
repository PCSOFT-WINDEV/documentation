
## Manipulating a window using its type
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000205"></a>
A WINDEV or WINDEV Mobile window is a type of variable that can be manipulated programmatically. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Declaration syntax
<a name="declaration_syntax_ELTTEXTE000229"></a>
To manipulate a variable associated with a window, use the following declaration syntax:


```txt
<Window_variable_name> is Window <Window name>
```


Example: 


```wl
My_Exe_Window is Window WIN_Main
```

**Before opening the** window, you can define:

- the window opening options (using the [OpeningOptions](../Proprietes/1410091299.md) property),

- the window parameters (using the **OpeningParameters** property). 


Any attempt to access another element of the window triggers an exception: "The window has not been opened". 
Comparing the window variable to Null returns True. 

**After opening the window** (with [Open](../WDLang1/3038035.md), [OpenChild](../WDLang1/3038021.md), [OpenSister](../WDLang1/3038045.md), etc.), you can manipulate the window and its elements (controls, procedures, variables, etc.). 
The property **OpeningParameters** property is cleared.
Comparing the window variable to Null returns False.  

**Once the window is closed**:

- the [OpeningOptions](../Proprietes/1410091299.md) and **OpeningParameters** properties define all the options to open the window again. 

- the **ReturnedValue** property gets the value returned by the window


Any attempt to access another element of the window triggers an exception: "The window has not been opened". 
Comparing the window variable to Null returns True. 

Note: You can use [WinStatus](../WDLang1/3038030.md) at any time to determine the status of the window. 


### Scope of variables
<a name="scope_variables_ELTPARAGRAPHE000070"></a>

Variable scope rules apply. 
The window is not closed when the variable goes out of scope. It remains accessible to the user, and can still be manipulated using its name (or alias).


### Simplified declaration syntax
<a name="simplified_declaration_syntax_ELTPARAGRAPHE000077"></a>

To declare a variable of type Window, you can also use a simplified declaration syntax: 

```txt
<Window_variable_name> is <Window name>
```


To use this simplified declaration:

1. Enable the use of simplified syntax. To do so, go to the "Project" tab, "Project" group, and click "Description". 

2. On the "Compilation" tab, select "Allow simplified declaration of Window types". 

3. Confirm. 


**Caution**: Using the simplified declaration can have certain consequences. There is a risk of conflict between WLanguage types and the variables that represent windows. 
In this case, if a variable of type Window has the same name as a WLanguage variable type, the WLanguage type must be prefixed with "WL.".

## OpeningOptions and OpeningParameters properties
<a name="openingoptions_and_openingparameters_properties_ELTTEXTE000280"></a>


### Window opening options
<a name="window_opening_options_ELTPARAGRAPHE000099"></a>

You can define the window opening options using the [OpeningOptions](../Proprietes/1410091299.md) property. This property corresponds to a variable of type [WindowOpeningOptions](../WDLang1/1410091298.md). 

This makes it possible to define the window coordinates, size, etc. 

The following syntax must be used: 

```txt
<Window_variable>.OpeningOptions.<Property> = <Value>
```


Example:  

```wl
// Set window opening options
My_Exe_Window is Window WIN_Main
My_Exe_Window.OpeningOptions.X = 50
My_Exe_Window.OpeningOptions.Y = 100
My_Exe_Window.OpeningOptions.Animation = waRotationX + waMorphCylinder
// Open window
My_Exe_Window.Open()
```

<a name="NOTE3_2"></a>


### Passing parameters to a window
<a name="passing_parameters_window_ELTPARAGRAPHE000122"></a>

You can indicate the value of the different parameters passed to the window using the [OpeningParameters](../Proprietes/1410091044.md) property. 

The following syntax must be used: 

```txt
<Window_variable_name>.OpeningParameters.<Parameter name> = <Parameter value>
```


Example:  

1. Declaration of the window to be opened: 
	
	```wl
	// -- Global declarations of WIN_Calendar 
	PROCEDURE WIN_Calendar (sSelDate)
	// sSelDate: Date to be selected
	```


2. Window opening code: 
	
	```wl
	My_Calendar_Window is Window WIN_Calendar
	// Pass parameters
	My_Calendar_Window.OpeningParameters.sSelDate = Today()
	// Open window
	My_Calendar_Window.Open()
	```

## Available WLanguage functions
<a name="available_wlanguage_functions_ELTTEXTE000310"></a>
Window variables can be used:

- by the functions used to open windows: 
	


|   |   |
| --- | --- |
| [MDIOpen](../WDLang1/3052005.md) | Opens and enables an MDI child window. |
| [Open](../WDLang1/3038035.md) | Opens a modal WINDEV window. |
| [OpenAsynchronous](../WDLang1/1410087804.md) | Opens a window whose result will be retrieved via a WLanguage procedure ("callback"). |
| [OpenChild](../WDLang1/3038021.md) | Opens a non-modal child window. |
| [OpenMobileWindow](../WDLang1/1000021018.md) | Opens a window in a mobile application. |
| [OpenSibling](../WDLang1/3038045.md) | Opens a non-modal sibling window. |

- by the [WinStatus](../WDLang1/3038030.md) function. 

- by the functions used to close windows: 
	


|   |   |
| --- | --- |
| [Close](../WDLang1/3038018.md) | Closes a WINDEV window (and returns a value if necessary). |
