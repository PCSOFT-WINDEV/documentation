
## SysRecentDocList (Function)

***In french: SysDocRécentListe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of recently opened documents.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Affiche dans la liste LISTE_DocRécent la liste des documents récemment ouverts
LISTE_DocRécent = SysDocRécentListe()
```



```wl
// Affiche dans la liste LISTE_DocRécent 
// la liste des documents et des répertoires récemment ouverts
// triée par date et avec la date affichée
Trace(SysDocRécentListe(sdrlTriDate + sdrlDate))
// Affiche par exemple
// C:\MesDoc	20180322105130
// C:\MesDoc\Poster.jpg	20180322105130
// C:\MesDoc\Poster2.jpg	20180322095020
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SysRecentDocList([<Options>])`
---

**`<Result>: (Character string)`**

List of recently opened documents. This list has the following format:

```txt
<Chemin document 1> + RC + <Chemin document 2> + RC + ... + <Chemin document N>
```
Depending on the options used, this list can also display: 

- the last access date in YYYYMMDDHHmmSS format.  

- the name of the accessed directories.




**`<Options>: (Combinable Integer constants)`**



- Process mode of paths: 
	


|   |   |
| --- | --- |
| *fUnicodePath* | &lt;Result&gt; will be a Unicode string.<br><br>WARNING: If this option is not specified, document paths containing strings that cannot be translated into ANSI will be replaced by the corresponding short path. |



- Information displayed in the list: 
	


|   |   |
| --- | --- |
| *srdlDate* | In addition to the requested information, &lt;Result&gt; contains the file's last access date in YYYYMMDDHHmmSS format (separated from the element path by a tab). |
| *srdlDefault* | &lt;Result&gt; contains the list of last opened documents (file path corresponding to the opened document). |
| *srdlSortDate* | &lt;Result&gt; contains the list of last accessed directories and last opened documents (separated by CR), sorted from the most recent one to the oldest one. <br><br>This constant can be combined with the *constant sdrlDate*: the date of the last access is then added (separated from the path by an RC).. |

## Remarks


### Associating an application with a file extension
<a name="associating_application_with_file_extension_ELTPARAGRAPHE000072"></a>

To associate an application with a file extension via the registry, you must create the following keys:

- "HKEY_CLASSES_ROOT\\.ext": 
	where **ext** is the extension. 
	The default value corresponds to the type of file (free string).

- "HKEY_CLASSES_ROOT\\nom_type": 
	where **type_name** is the name of the type given to the extension.
	The default value corresponds to the description that will be displayed in the "Type" column of the Windows explorer.

- "HKEY_CLASSES_ROOT\\nom_type\\shell\\open\\command": 
	The default value is the command that will be run by [ShellExecute](../WDLang1/3035007.md) on this type of file. In the command line, the %1 string will be replaced with the path of the file.
