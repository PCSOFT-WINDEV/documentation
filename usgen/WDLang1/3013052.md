


## TraceStart (Function)

***In french: TraceDébut***

<a name="Utilisation"></a>
<a name="description"></a>
Opens the trace window or saves the trace information in a text file.

**Remarks**:

- **TraceStart** has no effect if the trace window is already opened.

- **TraceStart** is optional. The first call to [Trace](../WDLang1/3013050.md) or to [TraceBuild](../WDLang1/1000021683.md) automatically opens the trace window.

**`<Trace file>: (Optional character string)`**

Name and full path of the file where the information found in the trace window will be saved. If this parameter is not specified, the trace file will be created at the root of the "C" drive and its name will have the following format "Trace_&lt;ProjectName&gt;.txt".

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) If this parameter is not specified, the trace file will be created in the temporary UNIX directory as "Trace_&lt;ProjectName&gt;.txt".![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If this parameter is not specified, the file is created in the current directory of the application (known via [fCurrentDir](../WDLang1/3036022.md))  under the name, "Trace_&lt;ProjectName&gt;.txt". 
 
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) If this parameter is not specified, the file is created in the "documents" directory of the application and it is named "Trace_&lt;ProjectName&gt;.txt".

## Remarks


### Use conditions according to the platforms
<a name="use_conditions_according_the_platforms_ELTPARAGRAPHE000212"></a>

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **TraceStart** is used to save the requested information in a file. By default, this file is created in the UNIX temporary directory with the name "Trace_&lt;Project&gt;.txt".![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **TraceStart** is used to display the requested information in the current page or to store it in a file.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In AWP mode, **TraceStart** can only be used to save the requested information in a file.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **TraceStart** is used to save the requested information: 

- in the application log (at runtime or in emulator mode). This log can be viewed when the device is connected via USB or when using the emulator from the DDMS application provided with the Android SDK.

- in a specific text file. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) **TraceStart** is used to: 

- display the requested information in the window for standard output of Xcode. 

- save the requested information in a specific text file. 



<a name="NOTE0_2"></a>


### Closing the trace window
<a name="closing_the_trace_window_ELTPARAGRAPHE000249"></a>

[TraceEnd](../WDLang1/3013044.md) is used to close the trace window.

If the *trFile* constant is specified, [TraceEnd](../WDLang1/3013044.md) stops saving to the trace file.
<a name="NOTE0_3"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 

### Trace window
<a name="trace_window_ELTPARAGRAPHE000265"></a>

The trace window displayed from a Browser code is different from the one displayed from a Server code. Therefore, two different trace windows can be opened at the same time.
