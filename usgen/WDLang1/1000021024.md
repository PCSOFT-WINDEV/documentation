


## PVTSelect (Function)

***In french: TCDSelect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the position of the selected cell and selects a cell in a Pivot Table control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the current position
pvtPos is pvtPosition
pvtPos = PVTSelect(PVT_Stats)
IF NOT pvtPos.Out THEN
	TRACE(pvtPos.Country + " " + pvtPos.City)
END
```

```wl
// Loop through the selected cells
pvtPos is pvtPosition of PVT_MyPVT

nbSel is int = PVTSelectCount(PVT_MyPVT)
FOR i = 1 TO nbSel
	pvtPos = PVTSelect(PVT_MyPVT, i)
	Trace(pvtPos.COL_Today_Date + ":" + pvtPos.COL_Product))
END
```

```wl
pvtPos is pvtPosition
// Select "France / 2014" 
pvtPos.Country = "FRANCE"
pvtPos.Year = "2014"
PVTSelect(PVT_Stats, pvtPos)
```

## Syntax
<a name="SYNTAXE1"></a>

### Getting the position of the selected cell in a Pivot Table control

`<Result> = PVTSelect(<Pivot Table control> [, <Rank>])`
---

**`<Result>: (pvtPosition variable)`**

[pvtPosition](../WDLang1/1000020726.md) variable containing the position of the selected cell in the control. If no element is selected, the **Out** property of the [pvtPosition](../WDLang1/1000020726.md) variable returned is set to <u><u><u><u>True</u></u></u></u>.

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Rank>: (Optional integer)`**

Rank of selected values in a multi-selection control. If this parameter is not specified, the position of the first selected cell is returned.


<a name="SYNTAXE2"></a>

### Selecting a position in a Pivot Table control

`PVTSelect(<Pivot Table control> , <Position> [, <Value>])`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Position>: (pvtPosition variable)`**

Name of the [pvtPosition](../WDLang1/1000020726.md) variable corresponding to the position to be selected. If the position does not correspond to a visible cell, a WLanguage error occurs. 

**`<Value>: (Character string)`**

Name of the value to be selected. If this parameter is not specified and there are several values in the same cell, the first value is selected.
