


## &lt;Command variable&gt;.IsRunning (Function)

***In french: &lt;Variable Commande&gt;.ExécutionEstEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether the executable associated with a command is currently running. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'
// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute.Executable = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)

WHILE MyCommandToExecute.IsRunning() = True
	// Refresh a progress bar
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Command manipulated>.IsRunning()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the executable associated with the command is running,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Command manipulated>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable to be used.
