


## TableEnumColumn (Function)

***In french: TableEnumèreColonne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of a column found in a Table or Treeview Table control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Name of third column found in the "TABLE_ProductTable" control
ResColumnName = TableEnumColumn(TABLE_ProductTable, 3)
```

```wl
AColumn is Control

	AColumn <- TableEnumColumn(TABLE_ProductTable, nColumn)
	Trace(AColumn.FullName + "//" + AColumn.Title)
END
```

## Syntax

`<Result> = TableEnumColumn(<Table control> , <Column index>)`
---

**`<Result>: (Character string)`**



- Column name. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This result can be assigned to a [Control](../WDLang1/1000020967.md) variable.

- Empty string ("") if &lt;Column index&gt; is equal to the number of columns in the Table control + 1.




**`<Table control>: (Control name)`**

Name of the Table control to be used.

If this parameter corresponds to an empty string (""), the Table control to which the current process belongs will be used.

**`<Column index>: (Integer)`**

Index of the column, between 1 and the number of columns in the Table control + 1. 
A WLanguage error occurs if this parameter is greater than the number of columns found in the Table control + 1.

To find out the number of columns in a Table control, use [TableCount](../WDLang1/3074021.md).

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000126"></a>

**TableEnumColumn** can be used on:

- a data-bound Table control or populated programmatically. 

- a TreeView data-bound Table control or populated programmatically.

- single-selection or multi-selection controls, 




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for "classic" Table control fields.
<a name="NOTE0_2"></a>


### The different types of column indexes
<a name="the_different_types_column_indexes_ELTPARAGRAPHE000145"></a>

There are 2 types of indexes for columns:

- Visible position index: column index when the window is run.

- Creation index: column index when the field is created in the window editor.




These two types of indexes are returned by [TableColumnIndex](../WDLang1/3074016.md).

These indexes change if the user moves the columns.

**TableEnumColumn** uses the column creation index.
