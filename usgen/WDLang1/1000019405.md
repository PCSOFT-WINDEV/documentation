


## InWebserviceMode (Function)

***In french: EnModeWebservice***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines if the code is being executed in the AWWS engine.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code executed from a web service?
IF InWebserviceMode() = True THEN
	// Processes to perform
	...
ELSE
	// Processes to perform
	...
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = InWebserviceMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the code is executed in the AWWS engine,

- <u><u><u><u>False</u></u></u></u> in all other cases. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter always corresponds to <u><u><u><u>False</u></u></u></u>.

<a name="NOTE0_1"></a>

## Remarks


### Function availability
<a name="function_availability_ELTPARAGRAPHE000198"></a>

**InWebserviceMode** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **InWebserviceMode** can be shared between several products without generating any compilation error.
