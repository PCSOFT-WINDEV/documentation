


## TableDisplay (Function)

***In french: TableAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Refreshes a Table or TeeeView Table control from a given position:

- for a "file" Table or hierarchical Table field: changes made to the linked table are reflected in the field.

- for a Table or hierarchical Table field "programmatically": calculated columns are re-calculated.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Refresh the "TABLE_ProductTable" control from the beginning
TableDisplay(TABLE_ProductTable, taStart)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableDisplay(<Table control> [, <Position>])`
---

**`<Table control>: (Control name)`**

Name of the control to be refreshed. This control can correspond to:

- a Table control,

- a TreeView Table control.


If this parameter is an empty string (""), the control to which the current event belongs is refreshed.

**`<Position>: (Integer, character or constant (optional))`**

Indicates the start position for the refresh. If this parameter is not specified:

- ***For a control based on a table***, the function behaves as if the *taInit* constant was passed as parameter.

- ***For a control populated programmatically***, the function has no effect.




This parameter can correspond to:

- An integer. The refresh is performed from this position. The row selected in the control is not modified.
	***For a control based on a data file***, the "Display a row" event of the &lt;Position&gt; row is executed. The row selected in the control corresponds to the current record in the table.
	***For a control populated programmatically***, the &lt;Position&gt; row is displayed again.

- A character or a constant:

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000213"></a>

**TableDisplay** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The page containing the control is refreshed.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for "classic" Table control fields.
<a name="NOTE0_2"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000235"></a>

**TableDisplay** has no effect:

- If &lt;Position&gt; is an integer and if this integer is invalid.

- If &lt;Position&gt; is an integer and &lt;Table control&gt; is a data-bound Table control with a "bouncing scrollbar".




**Reminder** The rebound elevator is an old-fashioned method of operation. With a bouncing scrollbar, the cursor returns to the middle of the track each time you click on the scrollbar arrow buttons (or by using the up arrow or down arrow of the keyboard). To create a bouncing scrollbar, uncheck "Proportional scrollbar" in the "Details" tab of the control description window.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **TableDisplay** has no effect if the &lt;Position&gt; parameter is an integer and if that integer is invalid.
<a name="NOTE0_3"></a>


### Tip for Table and TreeView data-bound Table controls
<a name="tip_for_table_and_treeview_databound_table_controls_ELTPARAGRAPHE000260"></a>

To display a calculation in a calculated column or to format a cell ("red background if value greater than 50" for example), use the "Display a row" event of the control.

### Native SQL Server Connector
<a name="native_sql_server_connector_ELTPARAGRAPHE000271"></a>

If **TableDisplay** handles a control linked to a table accessed by the Native SQLServer Connector, we recommend that you use the *taCurrentFirst* and *taStart* constants.
