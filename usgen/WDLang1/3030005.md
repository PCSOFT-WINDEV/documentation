
## DnDAccept (Function)

***In french: DnDAccepte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the action accepted by the target of Drag/Drop and manages the mouse cursor during Drag/Drop.

**Note**: The **DnDAccept** function must be used when calling the *dndLâcher* event ([DnDEvent](../WDLang1/3030006.md) function).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003030005&name=dndaccept_function">See additional examples</a>

```wl
// Procedure called by the dndDrop event
PROCEDURE OnDrop()
// Only the move is allowed (not the copy)
DnDAccept(dndMove)
```

## Syntax

`DnDAccept(<Authorized action>)`
---

**`<Authorized action>: (Constant)`**

Action allowed on the target control:


|   |   |
| --- | --- |
| *dndCopy* | Copying data is allowed in the target control. The copy cursor will be displayed during the copy: ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=dndcp.gif) |
| *dndDefault* | Copying data or moving data is allowed in the target control. <br>The default cursor will be displayed during the move:![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=flechdnd.gif)<br>(to perform a copy, keep the Ctrl key down while moving the data. The default cursor will be:![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=dndcp.gif)). |
| *dndMove* | Moving data is allowed in the target control. The move cursor will be displayed during the move: ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=flechdnd.gif) |
| *dndNone* | No action is allowed in the target control. The "forbidden" cursor will be displayed during the copy/move: ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=dndinter.gif) |

## Remarks




### Variables
<a name="variables_ELTPARAGRAPHE000076"></a>

The following variables can be used:

| Variable name | Description |
| --- | --- |
| **_DND.Action** | Action specified in **DnDAccept**.<br><br>The various possible values are as follows: *dndCopy*, *dndMove* and *dndProhibited*.<br><br>This variable is not filled at the beginning of Drag and Drop in a source control (*dndBeginDrag* constant) or when exiting from a target control (*dndDragLeave* constant). |
| **_DND.TargetControl** | Name of target control.<br><br>This variable is not filled at the beginning of Drag and Drop in a source control (*dndBeginDrag* constant) or when exiting from a target control (*dndDragLeave* constant). |
| **_DND.SourceControl** | Name of source control. |
| **_DND.CtrlDown** | Status of Ctrl key:<br><br>- True: the Ctrl control key is pressed.<br><br>- False: the Ctrl control key is not pressed.<br><br><br>This variable is not filled at the beginning of Drag and Drop in a source control (*dndBeginDrag* constant) or when exiting from a target control (*dndDragLeave* constant). |
| **_DND.SourceWin** | Name of source window.<br><br>This variable is not filled when exiting from a target control (*dndDragLeave* constant). |
| **_DND.MouseXPos** | Horizontal position (X) of mouse cursor in relation to the control handled during the event.<br><br>This variable is not filled when exiting from a target control (*dndDragLeave* constant). |
| **_DND.MouseYPos** | Vertical position (Y) of mouse cursor in relation to the control handled during the event.<br><br>This variable is not filled when exiting from a target control (*dndDragLeave* constant). |


The **_DND.SourceControl** and **_DND.SourceWin** variables return an empty string ("") when the Drag and Drop comes from an application other than the current application.

During a Drag/Drop, the data found in the source must be deleted through programming in the code corresponding to the "Drop" (to do so, test **_DND.Action** and **_DND.SourceControl**).
