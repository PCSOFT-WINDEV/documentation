| **schDateTime** | Type of information requested: Date and time of appointment corresponding to the contact details provided. | [SchedulerInfoXY](../WDLang1/1000019553.md) |
| **schModeDay** | Display mode: One-day display. | [SchedulerChangeMode](../WDLang1/1000019440.md), <br>[TimelineChangeMode](../WDLang1/1000020397.md) |
| **schModeMicrosecond** | Display mode: microsecond display. | [TimelineChangeMode](../WDLang1/1000020397.md) |
| **schModeMillisecond** | Display mode: millisecond display. | [TimelineChangeMode](../WDLang1/1000020397.md) |
| **schModeMonth** | Display mode: Display over one month. | [SchedulerChangeMode](../WDLang1/1000019440.md),<br>[TimelineChangeMode](../WDLang1/1000020397.md) |

| **schModeAccordingApt** | Schedule display mode: Displays the schedule using a number of days to show all available appointments. | [SchedulerChangeMode](../WDLang1/1000019440.md) |
| **schModeWeek** | Display mode: 5- or 7-day week display. | [SchedulerChangeMode](../WDLang1/1000019440.md),<br>[TimelineChangeMode](../WDLang1/1000020397.md) |
| **schCurrentMonth** | Type of date searched: First day of the month displayed in the Scheduler control field. | [SchedulerPosition](../WDLang1/1000019372.md) |
| **schMaxOccurrence** | Repeat feature: The appointment repeat has a defined maximum number of occurrences. | [Repetition](../WDLang1/1000019262.md) variable |
| **schScreenOrigin** | The coordinates are relative to the screen. | [SchedulerInfoXY](../WDLang1/1000019553.md) |
| **schNoEnd** | Repeat feature: The appointment will be repeated ad infinitum. | [Repetition](../WDLang1/1000019262.md) variable |
| **schAptSelected** | Type of appointment required: Appointment currently selected in the Scheduler control field. | [SchedulerListAppointment](../WDLang1/1000019276.md) |
| **schAptHovered** | Appointment type searched for: Appointment hovered over in the Scheduler control. | [SchedulerListAppointment](../WDLang1/1000019276.md) |
| **schAppointment** | Type of information requested: Appointment index corresponding to the contact details provided. | [SchedulerInfoXY](../WDLang1/1000019553.md) |
| **schResource** | Type of information requested: Name of the resource corresponding to the contact details provided. | [SchedulerInfoXY](../WDLang1/1000019553.md) |
| **schWithoutExecuteQuery** | Display the schedule without re-running the base query of the control. | [SchedulerDisplay](../WDLang1/1000019426.md),<br>[TimelineDisplay](../WDLang1/1000020683.md) |
| **schEveryYear** | RepeatString type: the appointment will be repeated every year, on the same day at the same time. | [Repetition](../WDLang1/1000019262.md) variable |
| **schEveryDay** | RepeatString type: the appointment will be repeated every day at the same time. | [Repetition](../WDLang1/1000019262.md) variable |
| **schEveryMonth** | RepeatString type: the appointment will be repeated every month, on the same day at the same time. | [Repetition](../WDLang1/1000019262.md) variable |
| **schEveryWeek** | RepeatString type: the appointment will be repeated every week, on the same day at the same time. | [Repetition](../WDLang1/1000019262.md) variable |
| **tlEveSelected** | Event type required: Event currently selected in the TimeLine control. | [TimelineListEvent](../WDLang1/1000020401.md) |
| **tlEveHovered** | Event type searched for: Event hovered over by mouse in TimeLine control. | [TimelineListEvent](../WDLang1/1000020401.md) |
