
## ControlExist (Function)

***In french: ChampExiste***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>17</B>, ***FieldExist*</**>** is kept for backward compatibility. This function has been replaced with ***ControlExist*</**>**.

<a name="Utilisation"></a>
<a name="description"></a>
Checks for a control (or group of controls) in a window, page or report.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Check for the "EditName" control
ResExist = ControlExist("EditName")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ControlExist(<Control used>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control (or group of controls) exists,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (String or Control variable)`**

Control to check for. This parameter can correspond to: 

- the name of the control **between quotes**. This parameter can also correspond to a group of controls. 
	To check for controls in other windows, pages or reports, &lt;Control used&gt; must be used in the following syntax:
	"&lt;Name of window, page or report&gt;.&lt;Name of control in window, page or report&gt;". 

- the name of a variable of type [Control](../WDLang1/1000020967.md).

## Remarks




### Controls taken into account
<a name="controls_taken_into_account_ELTPARAGRAPHE000088"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Cells in status bars and menu options are not considered controls.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Menu options are not considered controls.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Table control columns are not considered controls.
