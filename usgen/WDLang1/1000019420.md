
## RGBToHTML (Function)

***In french: RVBVersHTML***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the HTML color corresponding to the RGB color. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
RGBToHTML(255) // Returns "#0000FF"
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = RGBToHTML(<RGB color>)`
---

**`<Result>: (Character string)`**

HTML color expressed in hexadecimal.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) &lt;Result&gt; corresponds to a [Color](../WDLang1/1000019661.md) variable. 

**`<RGB color>: (Integer)`**

RGB color that must be converted into HTML color. This color can correspond to: 

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).

<a name="NOTE0_1"></a>

## Remarks
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Tip
<a name="tip_ELTPARAGRAPHE000082"></a>

If the result is displayed in a trace ([Trace](../WDLang1/3013050.md)), the [Color](../WDLang1/1000019661.md) variable is converted into a string corresponding to the color in RGB format.
