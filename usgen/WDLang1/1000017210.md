


## MultimediaPosition (Function)

***In french: MultimediaPosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns or modifies the current position of the media file currently played in the Multimedia control.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Note** Depending on the type of video and browser configuration, this function may not be supported. In this case, its use will have no effect but no error will be triggered.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MyFile is string = "C:\My music\mysong.mp3"
MultimediaPlay(MM_Multimedia1, MyFile)
// Positions 10 seconds after the beginning of file
MultimediaPosition(MM_Multimedia1, 10000) 
MultimediaStop(MM_Multimedia1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the position in the file

`<Result> = MultimediaPosition(<Multimedia control>)`
---

**`<Result>: (Integer)`**

Current position in the file, expressed in milliseconds.

**`<Multimedia control>: (Control name)`**

Name of the Multimedia control to be used.  


<a name="SYNTAXE2"></a>

### Modifying the position in the file

`<Result> = MultimediaPosition(<Multimedia control> , <New position>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the position was set,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Note: The [ErrorInfo](../WDLang1/3013008.md) function is not available.

**`<Multimedia control>: (Control name)`**

Name of Multimedia control to use.

**`<New position>: (Integer or Duration)`**

New position in the media file, expressed in milliseconds. This parameter can correspond to: 

- an integer representing the number of milliseconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms).
