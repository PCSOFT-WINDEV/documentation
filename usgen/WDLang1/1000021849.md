


## WinEdLoad (Function)

***In french: FenEdCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads: 

- the changes made by the end user in a window. These changes have been saved in memory or in a file. 

- the notes created by the end user in a window. 




Note: This function can be used when the "UI modification by end user" mode is enabled for application windows.. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click on [Save]
WinEdSave(WIN_Overview, "My changes.wdmodif")

// Click on [Load]
WinEdLoad(WIN_Overview, "My changes.wdmodif")
IF ErrorOccurred = True THEN
	Info("Unable to load" + CR + ErrorInfo()) 
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Loading the changes saved in a buffer

`<Result> = WinEdLoad(<Window> , <Buffer>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if changes were loaded,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Window>: (Window name)`**

Name of the window or internal window to be used. 

**`<Buffer>: (Buffer variable)`**

Buffer containing the changes (previously saved with [WinEdSave](../WDLang1/1000021848.md)). 


<a name="SYNTAXE2"></a>

### Loading the changes saved in a file

`<Result> = WinEdLoad(<Window> , <File>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if changes were loaded,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Window>: (Window name)`**

Name of the window or internal window to be used. 

**`<File>: (Character string)`**



- Name and full or relative path of the ".wdmodif" file containing the changes made (previously saved with [WinEdSave](../WDLang1/1000021848.md)). 

- Name and full or relative path of the ".wdnote" file containing the notes created by the user (the notes have been saved beforehand by [WinEdSaveNote](../WDLang1/1000022120.md)).
