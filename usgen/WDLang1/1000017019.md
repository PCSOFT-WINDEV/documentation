
## SysScreenResolution (Function)

***In french: SysRésolutionEcran***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the resolution of a screen.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Affichage de la résolution de l'écran principal
ChaîneRes est une chaîne
ChaîneRes = SysRésolutionEcran()
Trace("Résolution Largeur =" + ExtraitChaîne(ChaîneRes, 1) + RC + ...
	"Résolution Hauteur =" + ExtraitChaîne(ChaîneRes, 2) + RC + ...
	"Nb bits par pixel = " + ExtraitChaîne(ChaîneRes, 3) + RC + ...
	"Taux de rafraîchissement =" + ExtraitChaîne(ChaîneRes, 4))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysScreenResolution([<Screen name>])`
---

**`<Result>: (Character string)`**



- Resolution of the screen in the following format:
	
	```txt
	<Résolution Largeur> + TAB + <Résolution Hauteur> + TAB + 
	<Nombre de bits par pixel> + TAB + <Taux de Rafraîchissement>
	```


- Empty string ("") if an error occurred. [ErrorInfo](../WDLang1/3013008.md) returns more information on the error.




**`<Screen name>: (Optional character string)`**

Name of the screen whose the resolution you want to get.

If this parameter is not specified, the resolution of the main screen is returned. If the specified name does not exist, &lt;Result&gt; corresponds to an empty string ("").

**Note**: The list of screen names can be obtained using the [SysListScreen](../WDLang1/1000017014.md) function. .
