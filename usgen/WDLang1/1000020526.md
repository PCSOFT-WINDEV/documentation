
## dbgError (Function)

***In french: dbgErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Provokes: 

- an assertion during the test of element or project (Go mode). 

- an error in automated test mode. 





<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`dbgError(<Comment 1> [, <Comment 2> [... [, <Comment N>]]])`
---

**`<Comment 1>: (Character string)`**

Text that will be displayed in the assertion window or in the status report of unit test. 

**`<Comment 2>: (Optional character string)`**

Text that will be displayed in the assertion window or in the status report of unit test. 



**`<Comment N>: (Optional character string)`**

Text that will be displayed in the assertion window or in the status report of unit test. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- When **dbgError** is called:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in automated test mode, an error is added to the test status report (equivalent to [TestWriteResult](../WDLang1/1000013001.md)).

	- in manual test mode, an assertion is displayed (equivalent to [dbgAssert](../WDLang1/3014022.md)).

	- in runtime mode, an assertion is displayed if the assertions have been enabled (equivalent to [dbgAssert](../WDLang1/3014022.md)).




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The messages of **dbgError** will be written into the ADB log (at "Assert" level). For more details, see [Managing ADB logs](../Editeurs/9000108.md).
