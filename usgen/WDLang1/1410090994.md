


## FontLoad (Function)

***In french: PoliceCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a custom font from a file or buffer. After loading, the fonts and variants declared by the file or buffer will be available throughout the application.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
FontLoad("Roboto-Regular.ttf")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = FontLoad(<Font>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the font was loaded,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Font>: (Character string or Buffer)`**



- Name and path of the file corresponding to the font to be loaded. 

- Buffer containing the font to be loaded. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To unload a font, use [FontUnload](../WDLang1/1410090995.md).

- Supported formats include .ttf, .otf and .woff, and depend on the platform.

- If the same font is loaded multiple times, [FontUnload](../WDLang1/1410090995.md) must be called as many times as **FontLoad**.

- If a font with the same name is loaded from more than one file or buffer, only the first one will be taken into account.

- Fonts loaded with **FontLoad** are not listed by [FontList](../WDLang1/3060003.md).
