


## TreeDeleteAll (Function)

***In french: ArbreSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all elements from a TreeView control.

Example of TreeView control:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Arbre_Vocabulaire.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete the content from the "TREE_TVRecipe" control
ResDelete = TreeDeleteAll(TREE_TVRecipe)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TreeDeleteAll(<TreeView control>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<TreeView control>: (Control name)`**

Name of the TreeView control to be used.
