
## fAddBuffer (Function)

***In french: fAjouteBuffer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds the content of a buffer at the end of a file. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyBuffer is Buffer 
MyBuffer = fLoadBuffer("C:\tmp\Page1.html")

IF fAddBuffer("C:\test\MyFile.html", MyBuffer)
	Info("Addition successful")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fAddBuffer(<File used> , <Buffer to add>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was performed, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<File used>: (Character string)`**

File to be used (up to 260 characters). This parameter can correspond to: 

- a file name. This file will be automatically searched in the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)).

- a file name with its full or relative path. A UNC path can be used.




**Caution**: this file is modified by the **function fAddBuffer**. 

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder** Under iPhone/iPad, on both the device and the emulator, the file system is read-only. An application can only write to its installation directory or one of its subdirectories.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).

**`<Buffer to add>: (Buffer)`**

Name of the buffer variable whose content must be added to the file.
