
## ToClipboardRTF (Function)

***In french: VersPressePapierRTF***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Writes a character string in RTF into the clipboard.

**Note** Clipboard contents in RTF format can be retrieved using the [ClipboardRTF](../WDLang1/1000017200.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Copies the content of the EDT_RTF control to the clipboard in RTF
ToClipboardRTF(EDT_RTF)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ToClipboardRTF(<Text or Control in RTF Format>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the text was copied to the clipboard,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Text or Control in RTF Format>: (Character string)`**

RTF text that must be written into the clipboard or name of the control containing the text in RTF.
