


## AssistedInputClose (Function)

***In french: SaisieAssistéeFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the list of input suggestion of an Edit control. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF EDT_Direction = "" THEN
	AssistedInputClose(EDT_Direction)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`AssistedInputClose(<Edit control>)`
---

**`<Edit control>: (Control name)`**

Name of the Edit control to be used.
