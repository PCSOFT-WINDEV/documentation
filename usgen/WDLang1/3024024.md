
## NumToString (Function)

***In french: NumériqueVersChaîne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts a numeric value (integer, real or currency) to a string according to a specified format.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In this version, the numeric value to convert must be an integer or real.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NumToString(123)	// Returns "123"
NumToString(1.23)	// Returns "1.23"
NumToString(12345.5, "+10.2f") // Returns " +12345.50"
NumToString(12345.5, "-+10.2f") // Returns "+12345.50 "
NumToString(12345.5, "+010.2f") // Returns "+012345.50"
NumToString(12345.5, "010.2f") // Returns "0012345.50"

NumToString(12345.5, "10.2fS")
// Returns " 12 345.50" (the thousand separator is " ")

NumToString(12345.5, "10,2fS")
// Returns " 12 345,50" (the decimal separator is ",")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NumToString(<Number> [, <Format>])`
---

**`<Result>: (Character string)`**

String representing the number according to a specified format. 
If &lt;Number&gt; is a string, the returned string is the same as the initial string. The format is ignored.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) If &lt;Number&gt; is a string, the string is converted as if it were a number.

**`<Number>: (Integer or real)`**

Numeric value to convert to a string (according to the specified format).

**`<Format>: (Optional character string, constant or NumericFormat variable)`**



- String format defined with a variable of type [NumericFormat](../WDLang1/1410089836.md). 

- String format expressed as follows: 
	
	```txt
	"[<Align>][<Sign>][<Zero>][<Length>][<.Precision>]<Type>[<Thousand>]"
	```

	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The string is expressed in the following format: 
	```txt
	"[<Zero>][<Align>][<Length>][<.Precision>]<Type>"
	```

	For more details, see [the remarks](#NOTE0_1).

## Remarks




### Detailed format of the character string to obtain
<a name="detailed_format_the_character_string_obtain_ELTPARAGRAPHE000108"></a>

To convert a numeric value to a string, you need to specify the format of the string to be obtained. The format is as follows: 


```txt
"[<Align>][<Sign>][<Zero>][<Length>][<.Precision>]<Type>[<Thousand>]"
```


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The format is as follows: 
```txt
"[<Zero>][<Align>][<Length>][<.Precision>]<Type>"
```


The possible values are as follows: 


|   |   |
| --- | --- |
| &lt;Align&gt; | If this parameter is specified, forces the number to be left-aligned (&lt;Align&gt; = "-"). <br>By default, the number is right-aligned. |
| &lt;Sign&gt; | If this parameter is specified, displays a sign for positive numbers (&lt;Sign&gt; = "+"). This sign will appear to the left of the first significant digit. <br>By default, only negative numbers have a "-" sign to the left of the first significant digit.<br>Special case: if this parameter is specified and the number is 0, the "+" sign will be displayed. This sign will also be displayed if a negative number becomes 0. |
| &lt;Zero&gt; | If this parameter is specified (&lt;Zero&gt; ="0"), the number will be padded with leading zeros if the first significant part of the number is smaller that the specified length and the number is right-aligned. <br>By default, the number is not padded with leading zeros "0".<br>For example: NumToString(123, "05d") will give "00123". |
| &lt;Length&gt; | Defines the total length of the result string. The total width corresponds to the following elements: sign, thousands separator, decimal point, exponent, integer and decimal parts of the number. The length must be less than 100. <br>If the specified length is too small to contain the significant part of the number, it will be ignored. <br>By default, the number will be the same length of the significant part (it cannot be padded with zeros). This is also the case if &lt;Length&gt; = 0. <br>If the specified length is greater than the significant part of the number:<br><br>- the result string will be padded with trailing spaces if the number is left-aligned, <br><br>- the result string will be padded with leading spaces or zeros if the number is right-aligned.<br><br><br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Defines the total length of the result string or the total length of the integer part if the number is padded with zeros. The total width corresponds to the following elements: sign, thousands separator, decimal point, exponent, integer and decimal parts of the number. <br>If the specified length is too small to contain the significant part of the number, it will be ignored. <br>By default, the number will be the same length of the significant part (it cannot be padded with zeros). This is also the case if &lt;Length&gt; = 0. <br>If the specified length is greater than the significant part of the number:<br><br>- the result string will be padded with trailing spaces if the number is left-aligned, <br><br>- the result string will be padded with leading spaces or zeros if the number is right-aligned.<br><br><br> |
| &lt;.Precision&gt; | Defines the decimal separator ("." or ",") and the number of decimal places (for float ("f") and exponent ("e") &lt;Types&gt; only). <br><br>**Decimal separator**: <br><br>- If the decimal separator is a comma, the decimal separator used will be the one defined: <br><br>	- in the linguistic parameters of Windows.<br><br>	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in the Windows configuration of the server.<br><br>	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) for the current user.<br><br><br><br><br>- If the decimal separator is a period, the decimal separator used will be a period.  <br><br><br><br><br>Remarks: <br><br>- [ChangeSeparator](../WDLang1/3054004.md) has no effect on this separator. This function affects the display mask of numeric values in the controls. <br><br>- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The syntax &lt;,Précision&gt; cannot be used: you must use &lt;.Précision&gt;.<br><br><br><br><br>**Number of decimals**: <br><br>- The number of decimal places must be less than 100. <br><br>- If the number of decimal places in the number is greater than &lt;Precision&gt;, the decimal part is rounded to the specified number of decimal places.<br><br>- If the number of decimal places in the number is less than &lt;Precision&gt;, the decimal part will be padded with trailing zeros "0".<br><br>- The value of &lt;Precision&gt; can be greater than &lt;Length&gt;. In this case, &lt;Length&gt; is ignored.<br><br><br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Defines the number of decimals (for the float ("f") and exponent ("e") &lt;Types&gt; only). <br><br>- If the number of decimal places in the number is greater than &lt;Precision&gt;, the decimal part is rounded to the specified number of decimal places.<br><br>- If the number of decimal places in the number is less than &lt;Precision&gt;, the decimal part will be padded with trailing zeros "0".<br><br>- The value of &lt;Precision&gt; can be greater than &lt;Length&gt;. ### Limitations
<a name="limitations_ELTPARAGRAPHE000261"></a>

- The "f" format returns a valid result for numbers between -1e+17 and 1e+17.

- Formats "x", "d", or "o": the integer part must not exceed 99,999,999,999,999,999.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **How to use a comma for the decimal separator?** 
	If the Windows configuration on the server does not use a comma as a decimal separator, you can: 

	- use a numeric Edit control (hidden if necessary). The displayed value can be obtained with [DisplayedValue](../Proprietes/2510129.md). 

	- use a formatted display control.
