
## CharactType (Function)

***In french: CaractType***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the type of character. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CharactType("A") // the function returns ctAlpha|ctUppercase

CharactType("é") // the function returns ctAlpha|ctLowercase|ctAccent

// Checks if a character is a letter
IF BitwiseAND(CharactType("c"), ctAlpha) <> 0 Then
	Trace("This character is a letter")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CharactType(<Character>)`
---

**`<Result>: (Integer constant (or combination of constants))`**

Type of studied character: 


|   |   |
| --- | --- |
| *ctAccent* | Accented or diacritical character.<br>The *ctAccent* constant can only be combined with *ctAlpha*. |
| *ctAlpha* | Letter. |
| *ctLowercase* | Lowercase character.<br>The *ctLowercase* constant can only be combined with *ctAlpha*. |
| *ctNumeric* | Numeric character. |
| *ctPunctuation* | Punctuation character. |
| *ctSpace* | Space. |
| *ctUppercase* | Uppercase character.<br>The *ctUppercase* constant can only be combined with *ctAlpha*. |



**`<Character>: (Character string)`**

Character to use. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The character 0 returns 0. 

- Some character information can be combined: a character can be an accented letter.. In this case, the following constants can be combined: *ctAccent*, *ctLettre*, *ctMajuscule* and *ctMinuscule*. 
	To check a single piece of information (for example, if the character is a letter): we recommend testing the corresponding constant using the [BitwiseAND](../WDLang1/3050010.md) function or the "&" operator. For example: 
	
	```wl
	// Checks if a character is a letter
	IF BitwiseAND(CharactType("c"), ctAlpha) <> 0 Then
		Trace("This character is a letter")
	END
	```
