


## &lt;Table&gt;.Insert (Function)

***In french: &lt;Table&gt;.Insère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a row into: 

- a Table control,

- a TreeView Table control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a table displayed in a Combo Box control.


**Remarks**: 

- It is recommended to use [&lt;Table&gt;.InsertLine](../WDLang1/1000023407.md). [&lt;Table&gt;.InsertLine](../WDLang1/1000023407.md) is used to insert:

	- TAB characters into the columns, 

	- all types of values into the columns.




- To add rows inside a hierarchy (TreeView Table control), use [&lt;TreeView Table&gt;.InsertChild](../WDLang1/1000021934.md).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Insert the "Vince" and "Moore" elements 
// in the 5th row of "TABLE_CustomerTable" control
ResInsert = TABLE_CustomerTable.Insert("Vince" + TAB + "Moore", 5)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table control>.Insert([<Row> [, <Index>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element was inserted,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control with table.




**`<Row>: (Optional character string)`**

Row to insert. This row has the following format: 

```txt
<Element column1> + TAB + <Element column2> + TAB + ...
```

If this parameter is not specified, an empty row is inserted into the control. For a data-bound control, the default values defined in the linked table are taken into account.

**`<Index>: (Optional integer)`**

Index of the row to insert. The index of the first row is set to 1.


|   |   |
| --- | --- |
| Index not specified | The row will be inserted before the current row. If no row is selected, the row is inserted at the bottom of the control. |
| Index greater than the number of control rows. | The row is inserted at the bottom of the control. |
| Index equal to 0 | The row is inserted at the beginning of the control. |
| Index equal to -1 | The row will be inserted before the current row. |

## Remarks
**&lt;Table&gt;.Insert** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **&lt;Table&gt;.Insert** cannot be used on data-bound Table controls.
<a name="NOTE0_2"></a>


### Characteristics of inserted row
<a name="characteristics_inserted_row_ELTPARAGRAPHE000372"></a>

- Each inserted element is converted into the type of relevant column.

- If you don't want to specify a value for an element, use an empty string ("") or 0 (depending on the column type). For example:
	
	```wl
	TABLE_CustomerTable.Insert("Moore" + TAB + "Vince" + TAB + "" + TAB + "06/21/72")
	```


- If an element corresponds to the result of a calculation, enclose the numerical expression in brackets. For example:
	
	```wl
	TABLE_CalculationTable.Insert((53+29) + TAB + (83-21))
	```




<a name="NOTE0_3"></a>


### Position of inserted row
<a name="position_inserted_row_ELTPARAGRAPHE000398"></a>

By default, the row is inserted at the specified position.

Special cases: 

- If the control is sorted with [&lt;Table&gt;.Sort](../WDLang1/1000024293.md), the new row is positioned according to the current sort and not the specified index.

- If the control is sorted by the user, the sort is ignored when inserting the row. The row is inserted at the specified position.



<a name="NOTE0_4"></a>


### Limits: Maximum number of lines displayed
<a name="limits_maximum_number_lines_displayed_ELTPARAGRAPHE000418"></a>

The maximum number of rows that can be displayed in a TreeView Table control or hierarchical Table is limited only by available RAM (theoretical maximum: 2 billion rows). 

However, we do not advise you to use large Table or TreeView Table controls for performance and user-friendliness reasons (time required to fill the control for example).
<a name="NOTE0_5"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000430"></a>

To add rows at the end of a Table or TreeView Table control, use [&lt;Table&gt;.AddLine](../WDLang1/1000023404.md).

### Cascading input
<a name="cascading_input_ELTPARAGRAPHE000468"></a>

To perform a cascading input, **&lt;Table&gt;.Insert** must be used in the "Exit a row" event of the Table control:

```wl
IF TABLE_CustomerTable.NewLine = True THEN
	TABLE_CustomerTable.Insert()
END
```
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is only available for Table control fields in AJAX mode.

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000491"></a>

**If the cascading input is enabled**, the content of table linked to the control is automatically modified when the user goes to the next row.

**If the cascading input is not enabled**, the content of table linked to the control is not modified. To write the content of the inserted row into the table, [&lt;Table&gt;.Save](../WDLang1/1000024249.md) must be called after **&lt;Table&gt;.Insert**. 

**Remarks**: 

- The "Cascading input (Add)" option can be selected in the "Details" tab of the control description.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available for Table controls populated programmatically and with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available for "Server + AJAX" data-bound Table controls based on a table.

### Table field/Hierarchical table file: Insert several lines
<a name="table_fieldhierarchical_table_file_insert_several_lines_ELTPARAGRAPHE000528"></a>

A virtual row is created each time **&lt;Table&gt;.Insert** is called in a Table or TreeView data-bound Table control. The information will be saved in the table during the call to [&lt;Table&gt;.Save](../WDLang1/1000024249.md).

If **&lt;Table&gt;.Insert** is successively called in the same process without being followed by [&lt;Table&gt;.Save](../WDLang1/1000024249.md), only the FIRST call is effective (the following calls are ignored). Only one row is added to the Table or TreeView Table control.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This operating mode is only available for "Server + AJAX" Table controls based on a table.

### Editable Table or TreeView Table control
<a name="editable_table_treeview_table_control_ELTPARAGRAPHE000559"></a>

If **&lt;Table&gt;.Insert** is called:

- In a control event, the cursor is automatically positioned on the first column to edit in the inserted row.

- In an event that does not belong to the control (or in another process), [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) must be used to resume the input in the Table or TreeView Table control.



<a name="NOTE0_11"></a>


### Inserting images
<a name="inserting_images_ELTPARAGRAPHE000577"></a>

To insert an image into a Table control: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) specify the name and full path of image to insert. For example:
	
	```wl
	TABLE_MyTable.Insert("C:\MyDocuments\MyImage.BMP")
	```


- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) specify the path and name of image to insert. The path is relative to the "&lt;Project_Name&gt;_WEB" directory. For example:
	
	```wl
	// Adds the image found in the "WB_MyApp_WEB" directory
	TABLE_MyTable.Insert("MyImage.BMP")
	```



**Note**: To correctly display the added image, the column must be of type Image.
