
## SysStandby (Function)

***In french: SysMiseEnVeille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to: 

- enable and disable the standby mode.
	**Remark**: Standby settings are application-specific: 

	- when the application is ended, the initial setting is restored. 

	- when the application is moved to the background, the initial settings are restored. When the application returns to the foreground, the standby settings are restored.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enables the standby mode
SysStandby(sysBattery, sysStandbyActive)
```

<a name="SYNTAXE1"></a>

## Syntax
<a name="SYNTAXE4"></a>

### Enabling/Disabling the standby mode

`SysStandby(<Power mode> , <Standby>)`
---

**`<Power mode>: (Integer constant)`**

Power mode for which the management of the standby mode must be modified:


|   |   |
| --- | --- |
| *sysBattery* | Manage the standby mode when the device is powered by the battery. |
| *sysMainsPower* | Manage the standby mode when the device is plugged in. |

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This parameter is ignored. The standby mode is applied both when the device is on running on batteries or plugged in.

**`<Standby>: (Integer constant)`**

Enable or disable the standby mode: 


|   |   |
| --- | --- |
| *sysStandbyActive* | Enable the standby mode. The amount of idle time before switching to standby mode depends on the system settings. |
| *sysStandbyInactive* | Disable the standby mode when the application moves to the foreground. |




<a name="SYNTAXE5"></a>

### Finding out the standby mode

`<Result> = SysStandby(<Power mode>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the standby mode is enabled, 

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Power mode>: (Integer constant)`**

Power mode for which the management of the standby mode must be known:


|   |   |
| --- | --- |
| *sysBattery* | Manage the standby mode when the device is powered by the battery. |
| *sysMainsPower* | Manage the standby mode when the device is plugged in. |





This parameter is ignored. The standby mode is applied both when the device is on running on batteries or plugged in.
