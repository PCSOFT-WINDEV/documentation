


## String functions (prefix syntax)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to handle strings, using prefix syntax:




|   |   |
| --- | --- |
| [&lt;ANSI string&gt;.AnsiToOem](../WDLang1/1000024891.md) | Converts an ANSI string (Windows) to an OEM string (DOS). |
| [&lt;ANSI string&gt;.AnsiToUnicode](../WDLang1/1000024892.md) | Converts a string in ANSI (Windows) format into a string in Unicode format. |
| [&lt;ANSI string&gt;.BufferToHexa](../WDLang1/1000024894.md) | Converts an Ansi or Unicode string into a displayable hexadecimal string (e.g. "4A 5B 00"). |
| [&lt;ANSI string&gt;.CharactTypeCount](../WDLang1/1000024895.md) | Returns the number of characters matching a given type. |
| [&lt;ANSI string&gt;.Complete](../WDLang1/1410089823.md) | Returns a character string of a specified length. |
| [&lt;ANSI string&gt;.Contains](../WDLang1/1410089824.md) | Allows you to check if a substring is within a string. |
| [&lt;ANSI string&gt;.DeleteDuplicate](../WDLang1/1410087983.md) | Removes duplicates among substrings of a string, based on one or more separators. |
| [&lt;ANSI string&gt;.EndsWith](../WDLang1/1000024903.md) | Checks whether a character string ends with: <br><br>- with a specific character string.<br><br>- with one of the character strings in an array.<br><br><br> |
| [&lt;ANSI string&gt;.ExtractString](../WDLang1/1000024876.md) | Allows you to:<br><br>- extract a substring from a string based on a specified string separator.<br><br>- search for substrings in a string based on a specified string separator.<br><br><br> |
| [&lt;ANSI string&gt;.Format](../WDLang1/1000024877.md) | Formats a character string according to the selected options. |
| [&lt;ANSI string&gt;.Increment](../WDLang1/1000024905.md) | Increments a number at the beginning or at the end of a string. |
| [&lt;ANSI string&gt;.Insert](../WDLang1/1000024906.md) | Inserts a string into another character string at a given position. |
| [&lt;ANSI string&gt;.RegexMatch](../WDLang1/1410090618.md) | Checks whether a string matches the format defined by a regular expression. |
| [&lt;ANSI string&gt;.RegexReplace](../WDLang1/1410090617.md) | Replaces all the parts of a string that match a specific format. |
| [&lt;ANSI string&gt;.RegexSearch](../WDLang1/1410090616.md) | Searches for all the parts of a string that match a specific format. |
| [&lt;ANSI string&gt;.Replace](../WDLang1/1000024890.md) | Replaces all occurrences of a specified substring in a string with another specified substring. |
| [&lt;ANSI string&gt;.Reverse](../WDLang1/1000024908.md) | Reverses the characters of a string. |
| [&lt;ANSI string&gt;.Right](../WDLang1/1410089825.md) | Extracts the last characters from a string or string buffer. |
| [&lt;ANSI string&gt;.Split](../WDLang1/1000024902.md) | Extracts all the substrings from a character string based on one or more string separators. |
| [&lt;ANSI string&gt;.StartsWith](../WDLang1/1000024901.md) | Checks whether a character string starts: <br><br>- with a specific character string. <br><br>- with one of the character strings in an array.<br><br><br> |
| [&lt;ANSI string&gt;.ToNum](../WDLang1/1410087984.md) | Returns the numeric value of a character string. This feature enables you to perform numeric calculations on strings. |
| [&lt;Buffer&gt;.AnsiToUnicode](../WDLang1/1000026033.md) | Converts a buffer containing an ANSI string (Windows) to a buffer containing a UNICODE string. |
| [&lt;Buffer&gt;.UTF8Valid](../WDLang1/1410090487.md) | Checks the validity of a UTF-8 buffer. |
| [&lt;OEM string&gt;.OemToAnsi](../WDLang1/1410090334.md) | Converts an OEM string (DOS) to an ANSI string (Windows). |
| [&lt;Unicode string&gt;.RegexMatch](../WDLang1/1410090621.md) | Checks whether a string matches the format defined by a regular expression. |
| [&lt;Unicode string&gt;.RegexReplace](../WDLang1/1410090620.md) | Replaces all the parts of a string that match a specific format. |
| [&lt;Unicode string&gt;.RegexSearch](../WDLang1/1410090619.md) | Searches for all the parts of a string that match a specific format. |
