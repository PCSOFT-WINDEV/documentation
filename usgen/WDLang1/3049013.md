


## ListDeleteAll (Function)

***In french: ListeSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Clears a List Box, ListView or Combo Box control populated programmatically.

**Note**: The **ListDeleteAll** function can be used for both single-selection and multi-selection List Box controls..
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Attention**: The List (or Combo) Box control will only be emptied on the page displayed in the browser.. For more details, see Remarks.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete all elements from the "LIST_CustomerList" control
ListDeleteAll(LIST_CustomerList)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ListDeleteAll(<List Box control>)`
---

**`<List Box control>: (Control name)`**

Name of List Box (or Combo Box) control to use. If this parameter corresponds to an empty string (""), all the elements of the List Box control (or Combo Box) to which the current event belongs are deleted.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The name of the List Box (or Combo Box) control to use must be specified.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Deletion on the browser
<a name="deletion_the_browser_ELTPARAGRAPHE000085"></a>

When deleting elements from a List Box (or Combo Box) control in browser code, these elements are deleted on the page displayed in the browser only. In order for these elements to be deleted from the server, **ListDeleteAll** must be run on the server.

Calling **ListDeleteAll** in browser code is useful when using [AJAX technology](../WDLang2/3055101.md), in "Programmed AJAX" mode (via [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)).

**Reminder** In "automatic and immediate AJAX" mode, simply pass the server processing containing the function **ListDeleteAll FUNCTION** in automatic AJAX mode. That's it! No additional programming is required. For more details, see [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000116"></a>

- To delete all the rows from a Table control, use [TableDeleteAll](../WDLang1/3074034.md).

- **ListDeleteAll** can be used on a "Combo Box" table column.

- For the editable Combo Box controls, the input area is cleared.
