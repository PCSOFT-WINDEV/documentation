


## &lt;Array&gt;.Info (Function)

***In french: &lt;Tableau&gt;.Info***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the characteristics of an array: type of elements, number of dimensions, dimensions, etc.

**Note**: This function can only be used with [WLanguage arrays](../Motscles/1514030.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Total number of elements found in a one-dimensional array
MyArray is array of 5 int
...
nbDim is int
nbDim = MyArray.Info(tiTotalNumber)
// nbDim is equal to 5
```
<a name="Exemple2"></a>

```wl
// Array dimensions
MyArray is array of 5 by 2 int
nbRowDim is int 
nbRowDim = MyArray.Info(tiNumberRows)
// NbRowDim is equal to 5
nbColumnDim is int 
nbColumnDim = MyArray.Info(tiNumberColumns)
// NbColumnDim is equal to 2
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <WLanguage array>.Info(<Type of information> [, <Additional parameter>])`
---

**`<Result>: (Integer or boolean)`**

Requested information.

Note: The function returns no result on a dynamic array that has not been allocated.

**`<WLanguage array>: (Array)`**

Name of the Array variable to use.

**`<Type of information>: (Integer constant)`**

Type of information to retrieve:


|   |   |
| --- | --- |
| *tiAssociativeWithDuplicate* | Boolean.<br><br>- <u><u><u><u>True</u></u></u></u> if the associative array supports the duplicates<br><br>- <u><u><u><u>False</u></u></u></u> otherwise.<br><br><br> |
| *tiDimension* | Integer. Number of elements found in a dimension of the array.<br>&lt;Additional parameter&gt; must contain the index of the dimension whose number of elements you want to get. <br>Default value for &lt;Paramètre supplémentaire&gt;: 1<br>Associative array: number of elements in the array. |
| *tiDynamic* | Boolean.<br><br>- <u><u><u><u>True</u></u></u></u> if the array is a dynamic array.<br><br>- <u><u><u><u>False</u></u></u></u> otherwise.<br><br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiElementDefinition* | [Definition](../WDLang1/1000019540.md) variable. Definition of the type of elements.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiElementSize* | Integer. Size (in bytes) of an array element.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiElementType* | Integer. Type of array elements. &lt;Result&gt; is an integer corresponding to the constants of [TypeVar](../WDLang1/3013056.md).<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiKeyType* | Integer. Type of keys found in the associative array. &lt;Result&gt; is an integer corresponding to the constants of [TypeVar](../WDLang1/3013056.md).<br>Non-associative array: &lt;Résultat&gt; is 0. |
| *tiNumberColumns* | Integer. Number of columns found in a two-dimensional array. The number of columns corresponds to the 2nd dimension of the array. <br>If the array in not a two-dimensional array, tiNumberColumns = 0.<br>Associative array: 0. |
| *tiNumberDimensions* | Integer. Number of array dimensions (between 1 and 10)<br>Associative array: 1. |
| *tiNumberRows* | Integer. Number of rows found in a two-dimensional array. The number of rows corresponds to the 1st dimension of the array. <br>If the array is not a two-dimensional array, tiNumberRows = 0.<br>Associative array: 0. |
| *tiTotalNumber* | Integer. Total number of elements found in the array. |
| *tiTotalSize* | Integer. Total size (in bytes) of array.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |



**`<Additional parameter>: (Optional)`**

Additional parameter that must be specified according to the requested information.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Equivalences
<a name="equivalences_ELTPARAGRAPHE000341"></a>

- The *tiNumberRows* constant is equivalent to the *tiDimension* constant used with &lt;Additional parameter&gt; = 1. The following codes are identical:
	
	```wl
	MyArray.Info(tiNumberRows)
	MyArray.Info(tiDimension, 1)
	```


- The *tiNumberColumns* constant is equivalent to the *tiDimension* constant used with &lt;Additional parameter&gt; = 2.
	
	```wl
	MyArray.Info(tiNumberColumns)
	MyArray.Info(tiDimension, 2)
	```




<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000366"></a>

This function can be used with:

- simple arrays.

- fixed arrays.

- dynamic arrays.

- associative arrays.
