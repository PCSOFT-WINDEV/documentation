


## dRoundedRectangle (Function)

***In french: dRectangleArrondi***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a rounded rectangle:

- in an Image control,

- in a variable of type [Image](../WDLang1/1000019650.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This type of variable is not available. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in a variable of type [WDPic](../WDLang1/1000023503.md) (on the background layer),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in a variable of type [picLayer](../WDLang1/1000024604.md).




Note: To draw custom rectangles, use the [dBorder](../WDLang1/1000021894.md) function.. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md).

## Example


```wl
// Initialize the drawing in an Image control
dStartDrawing(IMG_Drawing)

// Draw a rounded rectangle whose background is light yellow
// and light blue borders
dRoundedRectangle(10, 10, 50, 50, 3, LightYellow, LightBlue)
```

### Drawing a rounded rectangle by specifying the coordinates of the rectangle and the diameter of corners

`dRoundedRectangle([<Image>, ] <X1> , <Y1> , <X2> , <Y2> , <Corner diameter> [, <Background> [, <Line>]])`
---

**`<Image>: (Optional control name or optional Image, WDPic or picLayer variable)`**

![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Image to use. This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [WDPic](../WDLang1/1000023503.md). Only the background layer will be handled. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [picLayer](../WDLang1/1000024604.md).




If this parameter is not specified, it is necessary to define the drawing destination with [dStartDrawing](../WDLang1/3029009.md).![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter is not available.

**`<X1>: (Integer)`**

X-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<Y1>: (Integer)`**

Y-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<X2>: (Integer)`**

X-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Y2>: (Integer)`**

Y-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Corner diameter>: (Integer)`**

Diameter of rectangle corners.

**`<Background>: (Integer or Integer constant (optional))`**



- Background color of rectangle. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

	- [a WLanguage preset color](../WDLang5/3010002.md), 

	- a variable of type [Color](../WDLang1/1000019661.md),

	- transparent if this parameter is not specified and if [dBackground](../WDLang1/3029002.md) has not been used. 




- Background characteristics: 

	- variable of type [Background](../WDLang1/1000022038.md). In this case, the gradient defined in the variable is ignored. 

	- characteristics specified in the last call to [dBackground](../WDLang1/3029002.md) if this parameter is not specified. 







To use a gradient background color, call [dRectangleGradient](../WDLang1/1000017059.md).

**`<Line>: (Integer, constant or Border variable (optional))`**

Color of rectangle line. This color can be:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md),

- a variable of type [Color](../WDLang1/1000019661.md). 


If this parameter is not specified: 

- color specified in the last call to [dPen](../WDLang1/3029029.md). 

- color identical to the color used for the background if [dPen](../WDLang1/3029029.md) has not been used.

Y-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Border>: (Border variable)`**

Name of the [Border](../Motscles/15140100.md) variable that defines the characteristics of the rectangle. Only the following properties are taken into account: 

- Rounding: if the property corresponds to the constant *RoundingIndefined*, no rounding is performed.. 

- Color: if the Property corresponds to the constant *UndefinedColor*the color defined during the last call to function [dPen](../WDLang1/3029029.md) is used. If this function has not been used, the background color of the rectangle will be used. 

- Thickness: if the Property corresponds to the constant *ThicknessIndefined*the thickness defined during the last call to function [dPen](../WDLang1/3029029.md) is used. If this function has not been used, the thickness will be set to 1. 

- Trait: if the property corresponds to *TraitIndéfini*the stroke type defined during the last call to function [dPen](../WDLang1/3029029.md) is used. If this function has not been used, the line will be solid.  




**`<Background>: (Integer, constant or Background variable (optional))`**



- Background color of rectangle. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- a variable of type [Color](../WDLang1/1000019661.md),

- Background characteristics:

	- characteristics specified in the last call to [dBackground](../WDLang1/3029002.md) if this parameter is not specified. 







To use a gradient background color, call [dRectangleGradient](../WDLang1/1000017059.md).

### Coordinates

<a name="NOTE0_2"></a>


### Using the drawing functions
<a name="using_the_drawing_functions_ELTPARAGRAPHE000901"></a>

The drawing functions can be used according to 2 methods:

- **Method 1: Using the dDrawingStart**function 

	- [dStartDrawing](../WDLang1/3029009.md) must be called before any other drawing function. [dStartDrawing](../WDLang1/3029009.md) is used to define the element (Image control or variable) to which the drawing functions will be applied.

	- When drawing on an Image control: 

		- The drawing functions operate on a copy ("bitmap") of the image. You can use the drawing functions of Windows (via [API](../WDLang1/3014005.md) or [CallDLL32](../WDLang1/3014003.md)) but these functions must use the DC (Device Context) returned by [dStartDrawing](../WDLang1/3029009.md).

		- [dEndDrawing](../WDLang1/3029019.md) and [dStartDrawing](../WDLang1/3029009.md) must not be called in the same process.
						If function [dEndDrawing](../WDLang1/3029019.md) is called in the same process as function [dStartDrawing](../WDLang1/3029009.md), the drawing will not appear: it will be automatically deleted.




- ![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) **Method 2: specify design destination directly in syntax (via parameter)**
	The &lt;Image&gt; parameter is used to specify directly the target of the drawing. [dStartDrawing](../WDLang1/3029009.md) becomes useless. This function must be deleted.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000966"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
