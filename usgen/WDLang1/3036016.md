
## fCompress (Function)

***In french: fCompacte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Compresses a file. This file can be decompressed by [fUncompress](../WDLang1/3036021.md).

**Note**: Small files are unlikely to be compacted.

**Reminder** Archiving functions ([zipXXX functions](../WDLang3/3082006.md)) can be used to manage archives in ZIP, CAB, 7z, etc. format.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003036016&name=fcompress_function">See additional examples</a>

```wl
// Compress a file
Res = fCompress("C:\Directories\File.txt", "C:\Directories\CompressedFile.txt")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = fCompress(<Path of file to compress> , <Path of compressed file>)`
---

**`<Result>: (Integer)`**



- 0 if the compression was performed,

- an error code (value greater than 0) otherwise.




**`<Path of file to compress>: (Character string)`**

Name and full (or relative) path of the file to compress (up to 260 characters). A UNC path can be used.

**`<Path of compressed file>: (Character string)`**

Name and full (or relative) path of compressed file (up to 260 characters). A UNC path can be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Error codes
<a name="error_codes_ELTPARAGRAPHE000047"></a>

The following error codes are returned:

- 1: The file to be compressed cannot be opened.

- 2: Unable to create compressed file. This error occurs if &lt;Path of compressed file&gt; does not exist.

- 4: The file cannot be compressed: it is simply copied (for example, the size of the file to be compressed is too small).

- 5: Not enough memory available for compression.

- 6: Compression has been aborted by the user: function [fStopCompress](../WDLang1/3036057.md) has been executed.

- 7: Not enough space to create the compressed file.




The error code message can be retrieved using the [ErrorInfo](../WDLang1/3013008.md) function with the *rrMessage* constant.
<a name="NOTE0_2"></a>
<a name="NOTE0_3"></a>




### Progress Bar
<a name="progress_bar_ELTPARAGRAPHE000077"></a>

To view the progress of file compression, use [Event](../WDLang1/3015011.md) to process the <u><u><u><u>GaugeCompaction</u></u></u></u> message (1174). When this message is received, the _EVE.wParam variable contains the percentage of file compression.
