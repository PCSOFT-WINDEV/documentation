
## MemOut (Function)

***In french: MemEnDehors***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>20</B>, this feature is kept for backward compatibility. We recommend that you use [Associative arrays](../Motscles/1514058.md).

<a name="Utilisation"></a>
<a name="description"></a>
Used to find out whether the browse performed on a memory area is outside this memory area.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MemFirst("MyMemoryZone")
// Browse outside "MyMemoryZone"?
WHILE MemOut("MyMemoryZone") = False
	// Processes in the memory area
	...
	// End of processes
	MemNext("MyMemoryZone")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = MemOut(<Memory area>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the end of the memory area was reached, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Memory area>: (Character string)`**

Name of the memory area, defined by [MemCreate](../WDLang1/3053005.md).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Call function MemOut
<a name="call_function_docparampagetitleshort_ELTPARAGRAPHE000080"></a>

**MemOut** must be used after the call to [MemFirst](../WDLang1/3053014.md), [MemLast](../WDLang1/3053004.md), [MemNext](../WDLang1/3053017.md), [MemPrevious](../WDLang1/3053011.md) and [MemSeek](../WDLang1/3053015.md) in order to check whether the end of the memory area was reached.
<a name="NOTE0_2"></a>


### Existence of memory area
<a name="existence_memory_area_ELTPARAGRAPHE000233"></a>

The existence of the memory area is not checked.

If the specified memory area does not exist, a WLanguage error occurs when **MemOut** is used. 

To check the existence of a memory area, use [MemExist](../WDLang1/3053006.md).
