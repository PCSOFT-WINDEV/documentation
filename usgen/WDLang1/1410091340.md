
## aiConversation (Variable type)

***In french: aiConversation***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **aiConversation** type represents a conversation with an AI model used in the AI Chat control. 

You can define and change the characteristics of this conversation using different WLanguage properties.

You can also get the details of the conversation with the [AIConversation](../Proprietes/1410091344.md) property of the AI Chat control.  

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF AICHAT_MyAIChat.AIConversation.RequestInProgress THEN
   IMG_ProgressBar.Visible = True
END
```





<a name="PROPS"></a>

## Properties


### Properties specific to aiConversation variables
<a name="properties_specific_aiconversation_variables_ELTPARAGRAPHE000033"></a>The following properties can be used to handle a conversation in an AI Chat control:


| Property name | Type used | Effect |
| --- | --- | --- |
| Element | Array of [aiConversationElement](../WDLang1/1410091337.md) | Array of AI conversation elements: Sequence of questions and answers, in order. <br><br>The first element of the array corresponds to the system prompt. |
| Name | Character string | Conversation name |
| RequestInProgress | Boolean | <br><br>- <u><u><u>True</u></u></u> if a request to the AI model is in progress. An animation is then displayed in the AI Chat control. <br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br><br><br>**This property is read-only**. |
| TokenCount | Integer | Number of tokens used by the conversation. <br><br>**This property is read-only**. |
