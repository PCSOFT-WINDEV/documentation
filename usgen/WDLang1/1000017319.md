


## &lt;List Box&gt;.Add (Function)

***In french: &lt;Liste&gt;.Ajoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an element to: 

- a List Box control populated programmatically,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) a ListView control populated programmatically, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Carousel control, 

- a Combo Box control populated programmatically.




**Remarks**:

- To add an element at a specific position, use [&lt;List Box&gt;.Insert](../WDLang1/1000017326.md).

- **&lt;List Box&gt;.Add** can be used on the single-selection and multi-selection List Box controls.

- To add an image to a standard List Box control, use [gImage](../WDLang1/3029042.md).

- To add elements to a Combo Box control found in a container column of a Table control, use [Content](../Proprietes/1000017242.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Attention**: The element will only be added to the page displayed in the browser.. For more details, see Remarks.

## Example


```wl
// Add the customer named "Moore" into "LIST_CustomerList"
LIST_CustomerList.Add("Moore")
```

## Syntax

`<Result> = <Control to use>.Add([<Element> [, <Path of image to display>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element was added,

- <u><u><u><u>False</u></u></u></u> otherwise.


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **&lt;List Box&gt;.Add** returns no result.

**`<Control to use>: (Control name)`**

Name of the control to be used.

**`<Element>: (Optional character string)`**

Element that will be added into the specified control. If this parameter is not specified, an empty row is added into the List Box or Combo Box control. 
This parameter can contain:

- Carriage Return characters (CR) to add several elements.

- tabs (TAB) to obtain a multi-element List Box control (see Notes).

- [gStoredValue](../WDLang1/1410088363.md) to indicate the value that will be returned when the element is selected. 


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **For a Carousel control**, the content of this parameter is displayed in the upper-left corner of the Carousel control.![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **For a ListView control,** this parameter corresponds to the image caption. This parameter can contain Carriage Return characters (CR) to add several elements. In this case: 

- if &lt;Path of image to display&gt; is not specified, the added elements will be associated with the default image (defined in the "Details" tab of the description window of control).

- if &lt;Path of image to display&gt; is specified, only the first element will be added. This element will be associated with the specified image.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The Carriage Return characters (CR) are supported while the tabulations (TAB) are not supported.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) To add several consecutive spaces, use non-breaking spaces: Caract(160).

**`<Path of image to display>: (Optional character string)`**

Name and path of image that will be added into a ListView control. You can also use an image memo field or a [Image](../WDLang1/1000019650.md) type variable. 
This parameter is taken into account for ListView controls displayed in ListView mode only. 
If this parameter is not specified, the default image (defined in the "Detail" tab of the control description window) is used..
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

## Remarks


### List Boxes containing more than 10 000 elements
<a name="list_boxes_containing_more_than_10_000_elements_ELTPARAGRAPHE000364"></a>

The maximum number of elements contained in a List Box control is limited only by available RAM (theoretical maximum: 2 billion lines). Nevertheless, filling a List Box control with an important number of elements (more than 10 000) affects performance

To add many elements to a List Box control, it is recommended to use a List Box control based on a table (i.e., a list directly linked to an HFSQL table).

### Sorted/Unsorted List Box control
<a name="sortedunsorted_list_box_control_ELTPARAGRAPHE000415"></a>

- If the List Box control is sorted, the new element is inserted according to the sort order.

- If the List Box control is not sorted, the new element is added at the end of the list.




The control type (sorted or not) is chosen during the control description ("Details" tab).

Use **&lt;List Box&gt;.Add** rather than [&lt;List Box&gt;.Insert](../WDLang1/1000017326.md) to add an element to a sorted List Box control.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The element is added at the end of control, no matter whether the List Box control is sorted or not.

### Tabulations: Multi-element List Box control
<a name="tabulations_multielement_list_box_control_ELTPARAGRAPHE000458"></a>To manage the tabulations in a List Box control (for aligning columns), use the *TAB* constant. For example:

```wl
LIST_Customer.Add(LastName + TAB + FirstName)
```
In this example, all the first names start at the same position and are aligned one under the other.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=LISTETABULATION.gif)
**Note** The first call to the **&lt;List Box&gt;.Add** function sets the tab position. These positions will be taken as reference for all values added thereafter. Similarly, if values have been typed entered in the editor, the positions of these values are taken as reference. During the first call to **&lt;List Box&gt;.Add**, we advise you to define the width of columns with [&lt;ANSI string&gt;.Complete](../WDLang1/1410089823.md). For example, to fix the width of columns found in "CUSTOMERS" to 10 characters:

```wl
LIST_Customer.Add(Complete(LastName, 10) + TAB + Complete(FirstName, 10))
```

### Adding an element to the browser
<a name="adding_element_the_browser_ELTPARAGRAPHE000494"></a>

When adding an element in browser code, this element is added to the page displayed in the browser only. In order for this element to be added onto the server, **&lt;List Box&gt;.Add** must be run on the server.

Calling **&lt;List Box&gt;.Add** in browser code is useful when using [AJAX technology](../WDLang2/3055101.md), in "Programmed AJAX" mode (via [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)).

**Reminder** In "automatic and immediate AJAX" mode, simply pass the server processing containing the function **&lt;List Box&gt;.Add FUNCTION** in automatic AJAX mode. That's it! No additional programming is required. For more details, see [AJAX](../WDLang2/3055101.md).
