


## ImageInfo (Function)

***In french: InfoImage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the characteristics of an image file or the characteristics of a PDF file:

- format.

- width and height.

- number of bits per pixel.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) alpha channel.

## Example


```wl
bWithTransparency is boolean = ImageInfo("MyImage.png", ibTransparencyColor)
```

```wl
bWithOpacity is boolean = ImageInfo("MyImage.png", ibWithAlphaLayer)
```

```wl
// List of pages separated by CR. 
// Page info: width + TAB + height + TAB + bits per pixel
sPageList is string = ImageInfo("doc.pdf", ibListInfoPages)
FOR EACH STRING sPageInfo OF sPageList SEPARATED BY CR
	Trace(sPageInfo)
END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ImageInfo(<Image file name> [, <Desired information>])`
---

**`<Result>: (Character string)`**



- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Requested characteristic (if the &lt;Requested information&gt; parameter is specified). 

- All image characteristics in the following format:
	
	```txt
	<Format> + TAB + <Width> + TAB + <Height> + TAB + <Bits/pixel>
	```

	


|   |   |   |
| --- | --- | --- |
| &lt;Format&gt; | Character string | <br><br>	- Three characters identifying the image format: "BMP", "GIF", "PDF", etc.<br><br>	- "BAD" if the image name is an non-existing file or if the format is unknown<br><br><br> |
| &lt;Width&gt; | Integer | Image width in pixels.<br>Note: The width and height can be inverted depending on the position of the (0,0) point of the image. To get the width and height taking into account the orientation of the image, use a variable of type [Image](../WDLang1/1000019650.md). |
| &lt;Height&gt; | Integer | Image height in pixels.<br>Note: The width and height can be inverted depending on the position of the (0,0) point of the image. To get the width and height taking into account the orientation of the image, use a variable of type [Image](../WDLang1/1000019650.md). |
| &lt;Bits/pixel&gt; | Character string | Number of bits per pixel:<br><br>	- 1 (monochrome image)<br><br>	- 4 (16-color palette)<br><br>	- 8 (256-color palette)<br><br>	- 24 (no palette, 16 millions of colors)<br><br>	- 32 (no palette, true color)<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The number of bits per pixel is always equal to 0.<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The number of bits per pixel is always 32. |



- If an error occurs, the following string is returned: 
	```txt
	"BAD" + TAB + TAB + TAB
	```





**`<Image file name>: (Character string)`**



- Name of the image or PDF file, including its full or relative path (up to 260 characters). A UNC path can be used.

- Name of the control bound to an image memo item.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The PDF files are not supported.  

**`<Desired information>: (Optional Integer constant)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Desired information.



|   |   |
| --- | --- |
| *ibWithAlphaLayer* | Determines whether the image has an alpha channel. If this constant is used, &lt;Result&gt; will correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> if the image has an alpha channel,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *ibTransparencyColor* | Determines whether the image has a transparent area. If this constant is used, &lt;Result&gt; will correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> if the image has a transparent area,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *ibListInfoPages*<br>(Default value) | Gets information on each page of a multi-page image. Each page is separated by a carriage return (CR) character.<br><br>The information is returned in the following format: <br><br><pre><code>Width + TAB + Height + TAB + Bits per pixel</code></pre><br> where: <br><br>- Width: Width in pixels. <br><br>- Height: Height in pixels. <br><br>- Bits per pixel: Number of bits per pixel:<br><br>	- 1 (monochrome image)<br><br>	- 4 (16-color palette)<br><br>	- 8 (256-color palette)<br><br>	- 24 (no palette, 16 millions of colors)<br><br>	- 32 (no palette, true color)<br><br><br><br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The number of bits per pixel is always equal to 0.![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The number of bits per pixel is always 32. |

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000198"></a>

- **ImageInfo** can be used with PDF files. 
	Note: [the GDI + framework](../Editeurs/2020007.md) must be installed on the computer..
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This feature is not available. 

- For WMF or EMF images, &lt;Bits/pixel&gt; is equal to 0.

- The following image file formats are supported:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png) All the formats described in [fGraphicFilter](../WDLang1/3036009.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JPEG, PNG, GIF or BMP.

	- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) JPG, PNG, GIF, BMP. Depending on the version of the GD library, these formats may not be supported.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000360"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.
