


## &lt;WDPic variable&gt;.DrawSlice (Function)

***In french: &lt;Variable WDPic&gt;.DessinePortion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a section of a circle or an ellipse in a variable of type [WDPic](../WDLang1/1000023503.md) (on the background layer).![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
// Draw a circle section whose
// background is light yellow and whose border is light blue
MyWDPicImage.DrawSlice(10, 10, 50, 50, 20, 20, 40, 50, LightYellow, LightBlue)
IMG_MyDrawing = MyWDPicImage
```

## Syntax

### Drawing a sector of a circle, specifying all the coordinates of the rectangle containing the circle

`<WDPic image>.DrawSlice(<X1> , <Y1> , <X2> , <Y2> , <X3> , <Y3> , <X4> , <Y4> [, <Background color> [, <Line color>]])`
---

**`<WDPic image>: (WDPic variable)`**

Name of the [WDPic](../WDLang1/1000023503.md) variable to be used. Only the background layer will be handled. 

**`<X1>: (Integer)`**

X-coordinate of the upper-left corner of the rectangle containing the circle. These coordinates are expressed in pixels.

**`<Y1>: (Integer)`**

Y-coordinate of the upper-left corner of the rectangle containing the circle. These coordinates are expressed in pixels.

**`<X2>: (Integer)`**

X-coordinate of the lower-right corner of the rectangle containing the circle. These coordinates are expressed in pixels.

**`<Y2>: (Integer)`**

Y-coordinate of the lower-right corner of the rectangle containing the circle. These coordinates are expressed in pixels.

**`<X3>: (Integer)`**

X-coordinate of the start point of the circle section. These coordinates are expressed in pixels.

**`<Y3>: (Integer)`**

Y-coordinate of the start point of the circle section. These coordinates are expressed in pixels.

**`<X4>: (Integer)`**

X-coordinate of the end point of the circle section. These coordinates are expressed in pixels.

**`<Y4>: (Integer)`**

Y-coordinate of the end point of the circle section. These coordinates are expressed in pixels.

**`<Background color>: (Integer or constant (optional))`**

Background color of the circle section. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a variable of type [Color](../WDLang1/1000019661.md). 




If this parameter is not specified, the background color:

- is *Transparent* if [&lt;WDPic variable&gt;.Background](../WDLang1/1000024481.md) has not been used beforehand, 

- corresponds to the color specified in the last call to [&lt;WDPic variable&gt;.Background](../WDLang1/1000024481.md).




**`<Line color>: (Integer or constant (optional))`**

Color of the line for the circle section. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a variable of type [Color](../WDLang1/1000019661.md). 




If this parameter is not specified, the line color:

- is *Transparent* if [&lt;WDPic variable&gt;.Pen](../WDLang1/1000024636.md) has not been previously used. 
	For a variable of type [Image](../WDLang1/1000019650.md), the line will be black. 

- corresponds to the color specified in the last call to [&lt;WDPic variable&gt;.Pen](../WDLang1/1000024636.md).

## Remarks


### Coordinates
<a name="coordinates_ELTPARAGRAPHE000663"></a>If *the start point and the end point* are not located on the border of the circle (or on the border of the ellipse), the point taken into account corresponds to the intersection between the circle and the line that joins the specified point and the center of the rectangle (which means the center of the circle).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=RbPortion.gif)
Coordinates are specified with respect to the upper-left corner of the image (coordinates: (0.0)).

The drawing sections are drawn counterclockwise.
<a name="NOTE0_2"></a>


### Non-solid figure
<a name="nonsolid_figure_ELTPARAGRAPHE000693"></a>

To draw a non-solid figure (without taking into account the center of the circle), use [&lt;WDPic variable&gt;.DrawChord](../WDLang1/1000024468.md).

### Drawing with opacity or anti-aliasing
<a name="drawing_with_opacity_antialiasing_ELTPARAGRAPHE000710"></a>

In the case of drawing with opacity (function [&lt;WDPic variable&gt;.StartDrawing](../WDLang1/1000024471.md) with constant *dWithOpacity*) or anti-aliasing (function [&lt;WDPic variable&gt;.ChangeMode](../WDLang1/1000024405.md) with constant *drawingAntiAliasing*), the outline is drawn over the inside of the portion: the line is therefore partly combined with the inside of the portion. If the line is very thick, it will be displayed in two colors.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000801"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000823"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
