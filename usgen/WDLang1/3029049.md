
## RGBBlue (Function)

***In french: RVBBleu***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the blue component of an RGB color.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
RGBBlue(RGB(128, 38, 15)) // Returns 15
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = RGBBlue(<RGB color>)`
---

**`<Result>: (Integer)`**

Blue component of the RGB color (included between 0 and 255).

**`<RGB color>: (Integer)`**

Color (24 bits). This color is the result of the following formula:

Color = 65536 \* Blue Component + 256 \* Green Component + Red Component.

## Remarks




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000066"></a>

- [RGB](../WDLang1/3029012.md) returns the identifier of the color described from its Red, Green and Blue components.

- [RGBRed](../WDLang1/3029050.md) returns the red component of an RGB color. [RGBGreen](../WDLang1/3029051.md) returns the green component of an RGB color.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000083"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.  

**To enable this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.
