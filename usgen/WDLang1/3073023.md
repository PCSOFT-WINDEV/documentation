
## SysGetDC (Function)

***In french: SysRécupèreDC***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the DC (Device Context) of a window, control or screen. This DC can be used to handle the window or the control with Windows API (especially the drawing functions of the Windows API).

**Remark**: If function **SysGetDC** has already been called and the previous DC has not been released by function [SysReleaseDC](../WDLang1/3073021.md), function **SysGetDC** automatically releases the old DC.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Récupération du DC de la fenêtre "Microsoft Word - Ventes 2000.DOC"
ResHandle = SysFenHandle("Microsoft Word - Ventes 2000.DOC")
ResRécupèreDC = SysRécupèreDC(ResHandle)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysGetDC(<Handle>)`
---

**`<Result>: (Integer)`**



- DC of the window, control or screen, 

- 0 if an error occurs.




**`<Handle>: (Integer)`**



- Handle of the window or control to use.

- 0 to retrieve the DC of the screen.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The window handle is returned:

- by [Handle](../WDLang1/3015005.md) for a WINDEV window.

- by [SysWinHandle](../WDLang1/3073007.md) for a window not created with WINDEV.




The handle of a control is returned by [Handle](../WDLang1/3015005.md).
