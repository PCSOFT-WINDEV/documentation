
## NoSpace (Function)

***In french: SansEspace***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns a character string without the space characters: 

- from the left and right side of the initial string.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) within the string.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NoSpace("   3.75 Euros   ")   // Returns "3.75 Euros"
```


<a name="Exemple2"></a>

```wl
NoSpace("Abra ca da bra", sscInside)   // Returns "Abracadabra"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NoSpace(<Initial string> [, <Position>])`
---

**`<Result>: (Character string)`**

String without spaces.

**`<Initial string>: (Character string)`**

Initial string from which the leading and trailing spaces will be removed. This character string is not modified.

**`<Position>: (Integer constant)`**

Position of the spaces to be removed. This position can correspond to one of the following constants: 


|   |   |
| --- | --- |
| *sscAll* | Removes all spaces from the initial string. <br>Equivalent to *sscRight* + *sscLeft* + *sscInside*. |
| *sscInside* | Removes spaces within the initial string. |
| *sscLeft* | Removes spaces from the left side of the initial string. |
| *sscOutside*<br>(Default value) | Removes spaces from both sides of the initial string. <br>Equivalent to *sscRight* + *sscLeft*. |
| *sscRight* | Removes spaces from the right side of the initial string. |




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

## Remarks




### Special cases
<a name="special_cases_ELTPARAGRAPHE000125"></a>

- [Left](../WDLang1/3024001.md) can also be used to remove spaces from the right side of the string.

- [Right](../WDLang1/3024016.md) can also be used to remove spaces from the left side of the string.

- **Non-breaking spaces**: Non-breaking spaces (constant *ESP* or character &lt;160&gt;) are not removed by the function **NoSpace**. To remove them, use [NoRightCharacter](../WDLang1/1000020479.md) with the *ESP* constant.



<a name="NOTE0_2"></a>




### NoSpace and UNICODE
<a name="docparampagetitleshort_and_unicode_ELTPARAGRAPHE000144"></a>

If the string passed as a parameter is an ANSI string, the result will be an ANSI string.

If the string passed in parameter is in Unicode format, the result will be in Unicode format.

**Note** If the result of the **NoSpace** function used on an ANSI string is assigned to a Unicode string (and vice versa), ANSI/Unicode conversion will be implicitly performed.

For more details, see [Unicode management](../WDLang1/3024038.md).
