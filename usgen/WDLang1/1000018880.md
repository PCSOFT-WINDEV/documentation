


## OrganizerListAppointment (Function)

***In french: AgendaListeRendezVous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns: 

- the list of appointments found between two dates in an Organizer control,

- all appointments found in an Organizer control,

- a specific appointment (selected or hovered).  









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// List all the appointments of the Organizer control
arrApt is array of Appointment
arrApt = OrganizerListAppointment(ORG_MyOrganizer)

// Adds the appointments into a Table control
FOR EACH gMyAppointment OF arrApt
	TableAddLine(TABLE_Table1, gMyAppointment.StartDate, ...
			gMyAppointment.EndDate, gMyAppointment.Title)
END
```
<a name="Exemple2"></a>

```wl
// Lists the appointments from today's date
arrApt is array of Appointment
arrApt = OrganizerListAppointment(ORG_MyOrganizer, DateSys())
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Retrieving the list of appointments found between two dates

`<Result> = OrganizerListAppointment(<Organizer control> [, <Start date> [, <End date>]])`
---

**`<Result>: (Array of Appointment variables)`**

Array containing the [Appointment](../WDLang1/1000019244.md) variables. 
If an appointment corresponding to the specified criteria exists, this array will contain a single element. 
If no appointment corresponds to the specified criteria, this array will contain zero appointments.

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Start date>: (Optional DateTime variable)`**

Start date for selecting the appointments.

If this parameter is not specified, all the appointments found in the Organizer control will be returned.

**`<End date>: (Optional DateTime variable)`**

End date for selecting the appointments.

If this parameter is not specified, all appointments found from &lt;Start date&gt; will be returned.


<a name="XSYNTAXE2"></a>
<a name="SYNTAXE2"></a>

### Retrieving the information about a specific appointment

`<Result> = OrganizerListAppointment(<Organizer control> , <Type of appointment>)`
---

**`<Result>: (Array of Appointment variables)`**

Array containing the [Appointment](../WDLang1/1000019244.md) variable. 
If an appointment corresponding to the specified criteria exists, this array will contain a single element. 
If no appointment corresponds to the specified criteria, this array will contain zero appointments.

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Type of appointment>: (Integer constant)`**

Type of sought appointment:


|   |   |
| --- | --- |
| *orgAptHovered* | Appointment hovered by the mouse cursor in the Organizer control. If no appointment is hovered over, &lt;Résultat&gt; will correspond to an array of 0 elements.<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *orgAptSelected* | Appointment currently selected in the Organizer control. If no appointment is selected, &lt;Résultat&gt; will correspond to an array of 0 elements. |
