


## &lt;Kanban list&gt;.DeleteAllCard (Function)

***In french: &lt;Liste de Kanban&gt;.SupprimeToutCarte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all cards from a Kanban control or Kanban List control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Deletes all cards from LIST_To_Do
LIST_To_Do.DeleteAllCard()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Control used>.DeleteAllCard()`
---

**`<Control used>: (Control name)`**

Name of the Kanban List control.
