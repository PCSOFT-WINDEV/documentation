


## Repetition (Variable type)

***In french: Repetition ***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Repetition** type is used to describe and modify the characteristics of a repetition for an appointment via the different WLanguage properties. Then, the appointment will be displayed in an Organizer control or in a Scheduler control.

This type of variable is used by the [Appointment](../WDLang1/1000019244.md) type.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines an appointment for the morning
MyAppointment is Appointment
MyAppointment.StartDate = DateSys() + "090000"
MyAppointment.EndDate = DateSys() + "093000"
MyAppointment.Title = "Appointment with the development team"
MyAppointment.Guest = "Jack, Mark, Sandra"
MyAppointment.Content = "Daily meeting regarding the progress of the projects."
MyAppointment.WithRepetition = True

// Configures a daily repetition of the appointment
RepetitionParameter is Repetition
RepetitionParameter.Type = schEveryDay
RepetitionParameter.TypeEnd = schNoEnd
MyAppointment.Repetition = ConfigureRepetition

OrganizerAddAppointment(ORG_Organizer1, MyAppointment)
```

## Properties


### Properties specific to Repetition variables
<a name="properties_specific_repetition_variables_ELTPARAGRAPHE000043"></a>

The following properties can be used to define the characteristics of **Repetition** variables:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| DayOfMonth | Character string | Number of the day for which the appointment is scheduled ("31" for example). This number is included between 0 and 31.<br>This property can also correspond to:<br><br>- a list of numbers separated by commas in order to specify several months.<br><br>- an interval. For example, "9-13" (the appointment is repeated from the 9th to the 13th of the month).<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step. For example, "\*/2" to repeat the appointment every even day of the month.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) You cannot specify the values of the **DayOfWeek** and **DayOfMonth** properties for the same recurring event. |
| DayOfMonthOrDayOfWeek | Boolean | <br><br>- <u><u><u>True</u></u></u> repeat the appointment every Monday AND the first day of the month (cumulated conditions).<br><br>- <u><u><u>False</u></u></u> to repeat the appointment on Monday 1st (exclusive conditions).<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available for an appointment displayed in a Scheduler control. |
| DayOfWeek | Character string | Number of the day for which the appointment is scheduled ("2" for example). This number is included between 1 and 7 (1 = Monday, 2 = Tuesday, ...).<br>This property can also correspond to:<br><br>- a list of numbers separated by commas in order to specify several days.<br><br>- an interval. For example, "1-3" (the appointment is repeated on Monday, Tuesday and Wednesday).<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step. For example, "\*/2" to repeat the appointment every even day of the week.<br><br>- the day of the week in letters ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday").<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) You cannot specify the values of the **DayOfWeek** and **DayOfMonth** properties for the same recurring event. |
| EndDate | Character string | End date of the repetition. This property is used if the **TypeEnd** property is equal to the *schEndDate* constant. |
| Hour | Character string | Time of the repetition in UTC format (universal time). The possible values are:<br><br>- a digit included between 0 and 23.<br><br>- a list of numbers separated by commas in order to specify several hours.<br><br>- an interval. For example, "9-13".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step. for example, "\*/2" to repeat the appointment every even hour.<br><br><br> |
| Minute | Character string | Minutes of the time for the appointment repetition. The possible values are:<br><br>- a digit included between 0 and 59.<br><br>- a list of numbers separated by commas in order to specify several minutes.<br><br>- an interval. For example, "9-13".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step. For example, "\*/2" to repeat the appointment every even minute.<br><br><br> |
| Month | Character string | Number of the month for the appointment repetition. The possible values are:<br><br>- a digit included between 1 and 12.<br><br>- a list of numbers separated by commas in order to specify several months.<br><br>- an interval. For example, "9-11".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step. For example, "\*/2" to repeat the appointment every even month.<br><br><br> |
| NbOccurrence | Integer | Maximum number of repetitions. This property is taken into account when the **TypeEnd** property is equal to the *schMaxOccurrence* constant.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available for an appointment displayed in a Scheduler control. |
| Type | Integer constant | Type of repetition. <br>This property corresponds to one of the following constants:<br><br>- *plnAllDays* RepeatString: the appointment will be repeated every day at the same time.<br><br>- *plnEveryWeek*: the appointment will be repeated every week, on the same day at the same time.<br><br>- *plnEveryMonth* RepeatString: the appointment will be repeated every month, on the same day at the same time.<br><br>- *plnAllYears*: the appointment will be repeated every year, on the same day at the same time.<br><br><br> |
| TypeEnd | Integer constant | Condition for stopping the repetition. <br>This property corresponds to one of the following constants:<br><br>- *plnDateFin*: the appointment will stop being repeated from the date indicated in the property **DateFin property**.<br><br>- *plnOccurrenceMax*: the appointment will stop being repeated after the number of repetitions specified in property **NbOccurrence**. <br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available.<br><br>- *plnNoEnd* the appointment will be repeated ad infinitum.<br><br><br> |
