


## &lt;Segmented Button&gt;.Add

***In french: &lt;Bouton segmenté&gt;.Ajoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a new option (i.e. a new button) to a Segmented Button control. The option is added after the existing options.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SB_Time.Add("D+1")
SB_Time.Add("D+7")
SB_Time.Add("D+30")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Segmented Button control>.Add(<Option caption>)`
---

**`<Result>: (Integer)`**



- Index of the new option.

- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Segmented Button control>: (Control name)`**

Name of the Segmented Button control to which the option should be added. The option is added after the existing options.

**`<Option caption>: (Character string)`**

Text of the option to be added.
