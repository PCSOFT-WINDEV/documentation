


## ChangeSkinTemplate (Function)

***In french: ChangeGabarit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dynamically changes the theme:

- of all windows found in the current application,

- of the windows found in the WINDEV components used by the application,

- of a specific window found in the project.




**Caution**: 

- This function has no effect on the themes applied to a report.

- This function has no effect on the clipped windows. The theme is not modified. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Use the "Sea" theme for all application windows
ChangeSkinTemplate("", "C:\MyApp\Sea.WDY")
```
<a name="Exemple2"></a>

```wl
// Use the "Emerald" theme for the current window
ChangeSkinTemplate(MyWindow.Name, "EmeraldWDY")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ChangeSkinTemplate(<Element to modify> , <New theme> [, <WLanguage procedure>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the theme was modified,

- <u><u><u><u>False</u></u></u></u> if a problem occurred.




**`<Element to modify>: (Constant or character string)`**

This parameter can correspond to:


|   |   |
| --- | --- |
| "" (empty string) | The new theme will be applied to all windows found in the current application (including the windows found in the WINDEV components used by the application). <br>In a .NET assembly generated by WINDEV, the new theme will be applied to all windows found in the current assembly and to all windows found in the WINDEV .NET assemblies that are loaded in parallel by the application. |
| *AllComponents* | The new theme will be applied to the windows found in all the WINDEV components used by the application |
| "&lt;Window name&gt;" | The new theme will be applied to the specified window |



**`<New theme>: (Character string)`**

Name of the theme to be applied (name and path of the "\*.WDY" file, if necessary). If this parameter corresponds to an empty string (""):

- the theme defined in the window editor will be applied by default. 
	**Warning** If a theme has been dynamically applied with the function **ChangeSkinTemplate**function, this dynamic theme will be retained.

- the windows already opened will keep the current theme.  




**`<WLanguage procedure>: (Optional procedure name)`**

WLanguage procedure ("callback" procedure) called when the theme is applied to an internal window further to the call to [ChangeSourceWindow](../WDLang1/3038053.md). 
This procedure has the following format:

```txt
PROCEDURE <Procedure name>(<Destination internal window>, <Skin template>)
```
 where: 

- &lt;Destination internal window&gt; is a **Control** variable corresponding to the internal window to which the skin template is applied. 

- &lt;Theme&gt; is a string corresponding to the name of the theme used.

## Remarks


### Not applying the theme to one of the project windows
<a name="not_applying_the_theme_one_the_project_windows_ELTPARAGRAPHE000091"></a>

To avoid applying the theme to one of the project windows:

1. Open the description of the corresponding window. 

2. On the "Style" tab, check "Always keep the initial theme/theme". 

3. Validate. 



<a name="NOTE0_1"></a>


### ".WDY" file
<a name="wdy_file_ELTPARAGRAPHE000106"></a>

The description of a theme is stored in a ".WDY" file.

The ".WDY" files corresponding to the themes proposed by WINDEV are provided with WINDEV.

Remarks:

- When creating a theme, the ".WDY" file is automatically created.

- To generate the ".WDY" file of an existing theme, open the "&lt;NameOfTheme&gt;.STY" file in WINDEV and save this file (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_Enregistrer.gif)).



<a name="NOTE0_2"></a>


### Deploying an application
<a name="deploying_application_ELTPARAGRAPHE000122"></a>

When creating the setup program of your application, the following elements must be added into the list of elements to install:

- the ".WDY" file of the new theme set with **ChangeSkinTemplate**.

- the image files used by the new theme applied by **ChangeSkinTemplate**.




Please note: Images must have different names in the different themes used, otherwise they will not be modified.. For the buttons, the image of the button is not affected by the change, only the image of the border is replaced with the image of the theme.

**Note**: To add one or more items to the list of project items:

1. On the "Project" tab, in the "Project" group, expand "List of elements" and select "List of project elements".

2. Click the "Add" button.

3. Select the files to add and validate.



<a name="NOTE0_3"></a>


### Font
<a name="font_ELTPARAGRAPHE000156"></a>

Dynamically loading themes has no effect on the font of the static controls. Indeed, systematically changing the font could trigger unexpected display effects (truncated or overlapping text) because the size of the static controls changes with the font.

If a change of font must be done when a new theme is applied through programming, use [Font](../Proprietes/2510095.md) in addition to **ChangeSkinTemplate**.
<a name="NOTE0_4"></a>


### Style of controls
<a name="style_controls_ELTPARAGRAPHE000170"></a>

**ChangeSkinTemplate** dynamically changes the theme of ALL the controls (controls linked to a project style or dissociated controls). To apply the style of a theme to some controls only, apply [ChangeStyle](../WDLang1/1000017171.md) to the relevant controls.

Note: It is also possible to copy the style from one field to another using the [Style](../Proprietes/1000021472.md) property. 
<a name="NOTE0_5"></a>


### Internal windows
<a name="internal_windows_ELTPARAGRAPHE000191"></a>

Internal windows have the "Before changing theme" and "After changing theme" optional events. 

These events can be used to save and reapply specific properties to internal window controls when changing the theme. You can also change one or more characteristics of the controls depending on the theme applied. For more details, see [Events associated with internal windows](../WDChamp/1013257.md).
