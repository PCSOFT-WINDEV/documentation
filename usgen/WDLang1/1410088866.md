


## &lt;Window&gt;.InXPos (Function)

***In french: &lt;Fenêtre&gt;.IntPosX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the horizontal position of the upper-left corner of the client area of a window in relation to the upper-left corner of the screen.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Windows: Frame and title bar not taken into account. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Fenet2.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Maximized moving windows: This position always corresponds to 0. 

- For non-maximized moving windows and popup windows: This position corresponds to the horizontal position of the top left corner of the internal zone (without the frame).. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Position horizontale de la zone interne de la fenêtre "FEN_SaisieClient" 
ResPosH = FEN_SaisieClient.IntPosX()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Window>.InXPos()`
---

**`<Result>: (Integer)`**

Horizontal position or X-coordinate (in pixels) of the upper-left corner of the internal area of the window in relation to the upper-left corner of the screen.

**`<Window>: (Window name)`**

Name or alias of the window to be used. If this parameter is not specified or if it corresponds to an empty string (""), the horizontal position of the internal area of the current window is returned.
