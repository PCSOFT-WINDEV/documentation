


## &lt;Image variable&gt;.ModifyHSL (Function)

***In french: &lt;Variable Image&gt;.ModifieTSL***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the hue, saturation and lightness of an image in an [Image](../WDLang1/1000019650.md) variable.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is Image = "Test.bmp"
// Changes the hue, the lightness and the saturation
// of the image found in the IMG_Image1 control
MyImage.ModifyHSL(50,50,50)
IMG_MyDrawing = MyImage
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Image variable>.ModifyHSL(<Variation of hue> , <Variation of saturation> , <Variation of lightness> [, <Destination image>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the change has been made, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Image variable>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used.

**`<Variation of hue>: (Integer)`**

Value included between -360 and +360. This value will be added to the current hue of each pixel to get a new hue.

**`<Variation of saturation>: (Integer)`**

Value between -100 and +100. This value will be added to the current saturation of each pixel to get a new saturation.

**`<Variation of lightness>: (Integer)`**

Value between -100 and +100. This value will be added to the current lightness of each pixel to get a new lightness.

**`<Destination image>: (Name of the Image control or variable)`**

Image where the transformed image will be drawn. This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.




If this parameter is not specified, the transformation will be performed on &lt;Image variable&gt;
