


## Procedure Description (Variable type)

***In french: Description de procédure***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Procedure Description** type allows you to get information about a class method. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieves the definition of type class of variable x
MyDefinition is Definition
MyDefinition = GetDefinition(x)

// Retrieves the description of Calc method
MyProcedure is Procedure Description 
MyProcedure = MyDefinition.Procedure["Calc"]
```

## Properties


### Properties specific to Procedure Description variables
<a name="properties_specific_procedure_description_variables_ELTPARAGRAPHE000033"></a>

The following properties can be used to define the characteristics of Procedure Description variables:


|   |   |   |
| --- | --- | --- |
| **Property name** | **Type used** | **Effect** |
| Associated | Boolean | <br><br>- <u><u><u>True</u></u></u> if the method comes from an associated class,<br><br>- <u><u><u>False</u></u></u> if the meethod comes from a base class. <br><br><br> |
| Declaration | Definition | Definition of the class that contains the method. <br>**This property is read-only**. |
| Global | Boolean | <br><br>- <u><u><u>True</u></u></u> if the method is global,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**. |
| Inherited | Boolean | <br><br>- <u><u><u>True</u></u></u> if the method is inherited from a base class,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**. |
| Name | Character string | Method name. <br>**This property is read-only**. |
| Syntax | Array of [Syntax Description](../WDLang1/1410089154.md) | Array of procedure syntaxes. <br><br>Note: If the code of the procedure is empty, the procedure will not be described at runtime in the syntax array. <br><br> |
| Virtual | Boolean | <br><br>- <u><u><u>True</u></u></u> if the method is virtual,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**. |

## Remarks
<a name="NOTE0_2"></a>


### Calling a method
<a name="calling_method_ELTPARAGRAPHE000140"></a>

The method whose description was retrieved can be called using [ExecuteProcess](../WDLang1/3013031.md).

- Calling a static method
	
	```txt
	p is Procedure Description
	p = ...
	ExecuteProcess(Null, p, <param1>, <param2>, ...)
	```


- Calling an instance method
	
	```txt
	p is Procedure Description
	p = ...
	ExecuteProcess(<object variable>, p, <param1>, <param2>, ...)
	```
