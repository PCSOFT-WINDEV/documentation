
## BitcoinCore functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate Bitcoin Core servers: 



|   |   |
| --- | --- |
| [BitcoinCoreBlockCount](../WDLang1/1410090321.md) | Returns the size of the blockchain known by the Bitcoin node (i.e. the number of blocks created since January 3, 2009). This makes it possible, for example, to calculate the approximate date of the next halving. |
| [BitcoinCoreBlockHash](../WDLang1/1410090774.md) | Returns the hash of a block identified by its index.<br><br> |
| [BitcoinCoreConfigure](../WDLang1/1410090320.md) | Specifies the Bitcoin Core server connection parameters, in order to use [BitcoinCoreXXXX](../WDLang1/1410090347.md) functions. |
| [BitcoinCoreConnectionCount](../WDLang1/1410090772.md) | Returns the number of connected peers.<br><br> |
| [BitcoinCoreDateTimeLastLaunched](../WDLang1/1410090771.md) | Returns the date and time Bitcoin Core was last launched.<br><br> |
| [BitcoinCoreDateTimeLatestBlock](../WDLang1/1410090322.md) | Returns the date and time when the latest block was created. |
| [BitcoinCoreDiskSpaceUsed](../WDLang1/1410090773.md) | Indicates the blockchain size on disk.<br><br> |
| [BitcoinCoreHashRate](../WDLang1/1410090319.md) | Returns the number of times per second the sha256 function had to be run to calculate the last block. This number corresponds to a proof of work. |
| [BitcoinCoreHashRate](../WDLang1/1410086762.md) | Calculates the current hash rate required to create new blocks. |
| [BitcoinValidAddress](../WDLang1/1410088858.md) | Checks whether a Bitcoin wallet address is valid. |





Note: BitcoinCorexxx functions require a Bitcoin server and an RPC server. For more details, see [Setting up and using a Bitcoin Core server](../WDLang1/1410090348.md).
