
## BitcoinCoreConnectionCount (Function)

***In french: BitcoinCoreConnexionOccurrence***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of connected peers.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get number of connected peers
nbPeers is int
nbPeers = BitcoinCoreConnectionCount()
IF ErrorOccurred THEN
	Error()
	RETURN
END
Trace("Connected peers:" + nbPeers)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BitcoinCoreConnectionCount()`
---

**`<Result>: (Integer)`**

Number of connected peers.
