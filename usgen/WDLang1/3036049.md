
## fExeDir (Function)

***In french: fRepExe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the directory from which the execution is started.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns the runtime directory of the project. This directory must be accessible in read/write mode. In most cases, it contains the tables and the other files handled by the WEBDEV site.

**Attention**: **function fExeDir** is used to find out the launch directory, while [fCurrentDir](../WDLang1/3036022.md) is used to find out the current directory.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Runtime directory
Info("This application is started from " + fExeDir())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = fExeDir()`
---

**`<Result>: (Character string)`**

Directory from which the executable is run. This path does not end with the "\\" character. 

- In test mode (GO from WINDEV), corresponds to: 

	- the generation directory given in the description of the current [project configuration](../Editeurs/9000030.md). 

	- the EXE subdirectory of the project directory. 




- At runtime, corresponds to the directory containing the current executable.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Runtime directory of the project. In test mode and in deployment (GO from WEBDEV), corresponds to the EXE subdirectory of the project directory.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Installation directory of the application (in the internal storage area). 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Root directory of application (accessible in read-only).

### SOAP server
<a name="soap_server_ELTPARAGRAPHE000091"></a>

When **fExeDir** is used on a SOAP server, it returns the path of the directory containing the library of the SOAP server being run.
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Application used in Windows Vista (and later) 
<a name="application_used_windows_vista_and_later_ELTPARAGRAPHE000102"></a>

In Windows Vista (and later), the [UAC mechanism](../Editeurs/2025014.md) implies some development constraints.

Therefore, the files used by the application (tables or INI files for example) should be stored in the specific directories of the application (and not in the directory of the executable). These directories are returned by [fDataDirCommon](../WDLang1/3036070.md), [fDataDirUser](../WDLang1/3036071.md), [fGlobalDirCommon](../WDLang1/3036072.md) and [fGlobalDirUser](../WDLang1/3036073.md).
<a name="NOTE0_3"></a>




### Path of a system directory
<a name="path_system_directory_ELTPARAGRAPHE000127"></a>

To find out the path of a system directory, use [SysDir](../WDLang1/3073026.md).
