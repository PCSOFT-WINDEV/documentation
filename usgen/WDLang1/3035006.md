
## ExeRun (Function)

***In french: LanceAppli***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Executes a program (an executable file, for example) from the current application. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) This allows you to retrieve:

- the return value of executable with the *exeReturnValue* constant.

- the process identifier, also called PID with the *exePID* constant.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Remarks**:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) It is also possible to run a command in console mode. For more details, see [Functions for handling commands in console mode](../WDLang1/1410090746.md).

- From Windows Vista, the applications may fail to start if the UAC mechanism is enabled. For more details, see [remarks](#NOTE0_5).

- In 64-bit Windows, you can access a system directory from a 32-bit executable in a different directory. For more details, see [Native 64-bit and native 32-bit](../Editeurs/2030048.md).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)

```wl
// Start Notepad in default mode

```


<a name="Exemple2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Start a program with long name containing space characters
// For example: Launch Microsoft Word with "My documents" as the working directory

// Solution 1: Specific syntax for multiline strings
// (avoids doubling or tripling quotes)
IF ExeRun([
	"C:\Program Files\Microsoft Office\Office12\WINWORD.EXE"
	], ...
	exeActive, exeDontWait, SysDir(srMyDocuments)) = False THEN
		Error(ErrorInfo())
END

// Solution 2: Double quotations
ExeRun("""C:\Program Files\Microsoft Office\Office12\WINWORD.EXE""", ...
	exeActive, exeDontWait, SysDir(srMyDocuments))
```

## Syntax

### Running an executable (in locking or non-locking mode)

`<Result> = ExeRun(<Program name> [, <Mode> [, <Wait for end> [, <Working directory>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the program was started,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns more details about the error.




![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function returns no result.

**`<Program name>: (Character string)`**

Name of the program to be launched, including its path and/or the parameters to be passed, if necessary. 

- **If no path is specified**, the program is sought in the current directory, then in the Windows directory and in the directories accessible by PATH. 

- **If the executable corresponds to a long name with space characters**, the following syntax must be used:
	
	```txt
	<Program name> = " " " Long_name_with_spaces" " Command_line"
	```





![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Full name of the application to be started (with the package name) with the parameters to be passed to the program, if necessary. 

- Example: To launch Google Maps, specify "com.google.android.apps.maps" in &lt;Program name&gt;.

- To specify parameters to be passed in command line, simply use the following notation: 
	
	```txt
	<Program name> = <Package name> <Parameter name 1> = <Parameter value 1>
	```



**Starting with Android 11**, the package name must be added in the application manifest. You can find an example at FAQ below: [How to allow another application to be launched with ExeRun from an application in Android 11?](https://faq.windev.com/faqread.awp?idfaq=22657)

**`<Mode>: (Optional integer constant)`**

Program start mode (no action on DOS programs): 


|   |   |
| --- | --- |
| *exeActive*<br>(Default value) | The launched program run is and takes precedence over the current program. |
| *exeIconize* | The launched program is inactive and is minimized.<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *exeInactive* | The launched program is inactive. It runs but the current program maintains focus. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *exeMaximize* | The launched program is active. It takes precedence over the current program and the window is maximized.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *exeNoHandleInheritance* | Indicates that the executable should not inherit handles from the parent (applies to ALL handles, including files). The executable is independent of the application that launched it.  <br><br>This constant can be combined with other application launch constants. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The launched program is always active. It runs and takes precedence over the current program. 

**`<Wait for end>: (Optional Boolean constant)`**

Configures the timeout before resuming the execution of the current program: 


|   |   |
| --- | --- |
| *exeDontWait*<br>(Default value) | The current program and the launched program run in parallel. |
| *exeWait* | The current program resumes its execution when the program run is over.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The application can be started in non-locking mode only. A fatal error occurs if the *exeWait* constant is used. |

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

**`<Working directory>: (Optional character string)`**

Working directory of the application to be started.

### Starting a program and retrieving a value

`<Result> = ExeRun(<Program name> [, <Mode> [, <Element to return> [, <Working directory>]]])`
---

**`<Result>: (Integer)`**

Sought value:

- Return value of the executable if &lt;Element to return&gt; corresponds to the *exeReturnValue* constant.

- PID of the executable if &lt;Element to return&gt; corresponds to the *exePID* constant.




[ErrorInfo](../WDLang1/3013008.md) is used to find out whether an error occurred.

**`<Program name>: (Character string)`**

Name of the program to be launched, including its path and/or the parameters to be passed, if necessary. 

- **If no path is specified**, the program is sought in the current directory, then in the Windows directory and in the directories accessible by PATH. 

- **If the executable corresponds to a long name with space characters**, the following syntax must be used:
	&lt;Program name&gt; = " " " Long_name_with_spaces" " Command_line"




**`<Mode>: (Optional integer constant)`**

Program start mode (no action on DOS programs).


|   |   |
| --- | --- |
| *exeActive*<br>(Default value) | The program run is active, it "takes control" over the current program |
| *exeIconize* | The program run is inactive and it is minimized |
| *exeInactive* | The launched program is inactive. It runs but the current program maintains focus |
| *exeMaximize* | The program run is active, it "takes control" over the current program (the execution window is maximized) |

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is ignored. The program run is active, it "takes control" over the current program. 

**`<Element to return>: (Optional constant)`**

Configures the function result:


|   |   |
| --- | --- |
| *exePID* | The current program and the launched program run in parallel. &lt;Result&gt; corresponds to the identifier of created process (also called PID) if the executable was successfully run, 0 if an error occurred. <br>This identifier can be used in some APIs for example.<br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *exeReturnValue* | The current program resumes its execution when the program run is over. &lt;Result&gt; is the return value of the executable. |



**`<Working directory>: (Optional character string)`**

Working directory of the application to be started.

## Remarks


### Using a command line
<a name="using_command_line_ELTPARAGRAPHE000273"></a>

To pass parameters in command line to the executable run, you must specify the name and full path of the executable to run.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) If the program run was developed with WINDEV or WINDEV Mobile, you can get the command line using [CommandLine](../WDLang1/3013051.md).

### Using the exeActive constant
<a name="using_the_exeactive_constant_ELTPARAGRAPHE000289"></a>

If the process where the application is run (with the *exeActive* constant) runs a code allowing the calling program to regain focus, the called program loses control.

In order for the called program to keep focus, you must avoid:

- call another window or dialog box after the call to **ExeRun**, 

- calling [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) after **ExeRun**.




In addition, the Button control (if there is one) whose associated "Click" event contains a call to **ExeRun** must not be "Tab Stop" ("Accessible by TAB" in the "UI" tab of the control description).

### Return value of a WINDEV executable
<a name="return_value_windev_executable_ELTPARAGRAPHE000318"></a>

A WINDEV executable can return a value. Simply:

1. Create an Integer variable global to the project.

2. Initialize this variable with the value to return.

3. Return this variable with the [RETURN](../Motscles/1510007.md) keyword in the project closing code.

### Starting an application in WEBDEV Server code
<a name="starting_application_webdev_server_code_ELTPARAGRAPHE000334"></a>

**ExeRun** is run on the server, therefore the started application is run on the server.

By default, the application is only visible in the task manager because it is started from a service that does not interact with the Windows desktop.

In order for the program run to be visible on the server, the option "Allow the service to interact with the desktop" must be checked in the properties of the WEBDEV service.

### Starting an application in Windows Vista (and later)
<a name="starting_application_windows_vista_and_later_ELTPARAGRAPHE000349"></a>

If UAC (User Account Control) is enabled, the application that uses **ExeRun** to start another application must have higher permissions than the application that is started.

For example, a first application started with the administrator rights can start a second application that requires no specific rights. 

If the second application requires greater rights than the application that starts it, the second application may fail to start. Windows proposes to enable the management of compatibility with Windows Vista. If compatibility is enabled, the second application will run the next time it is launched. You can also use [ShellExecute](../WDLang1/3035007.md).

### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000367"></a>

- **ExeRun** does not modify the current directory. The current directory before running **ExeRun** is identical to the current directory after running **ExeRun**. 

- If the launched program does not take into account the specified execution mode, it is launched in *exeActive* mode.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000548"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ExeRun** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
