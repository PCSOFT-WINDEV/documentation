
## SpreadsheetGetSortInfo (Function)

***In french: TableurRécupèreInfoTri***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns various information about the sort performed in a Spreadsheet control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Shows the area that will be sorted
sSel is string 
sSel = SpreadsheetGetSortInfo(PSHEET_Spreadsheet, psheetInfoSortSelection) 
IF sSel = "" THEN
	RETURN // not sortable
END
sMin is string = ExtractString(sSel, 1, ":")
sMax is string = ExtractString(sSel, 2, ":")

// Selects the area 
SpreadsheetSelectPlus(PSHEET_Spreadsheet, sMin, sMax)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SpreadsheetGetSortInfo(<Spreadsheet control> , <Type of information>)`
---

**`<Result>: (Character string)`**

Requested information. 

**`<Spreadsheet control>: (Control name)`**

Name of the Spreadsheet control to be used. 

**`<Type of information>: (Integer constant)`**

Desired information: 


|   |   |
| --- | --- |
| *psheetInfoSortCriteria* | Gets the last sort criteria used in the Spreadsheet control. &lt;Result&gt; has the following format: <br><br><pre><code>"<Name of column1>[;< Option>]" + TAB + <br>"<Name of column2>" + TAB + ...</code></pre><br>where: <br><br>- &lt;Name of column&gt; is the name of sorted column,<br><br>- &lt;Option&gt; corresponds to one of the sort constants defined for [SpreadsheetSortSelection](../WDLang1/1000023463.md). <br><br><br><br><br>Example: "A&lt;Tab&gt;B;3" |
| *psheetInfoSortSelection* | Gets the selection that will be sorted via the Automatic Application Features (AAFs) in the Spreadsheet control. Example: "A2:B4". <br><br>Note: If the selection does not allow sorting, &lt;Résultat&gt; corresponds to an empty string ("").. |
| *psheetInfoSortWithTitle* | Determines if the selection sorted by the Automatic Application Features (AAFs) in the Spreadsheet control contains a title. &lt;Result&gt; can correspond to: <br><br>- 1 if the selection to sort includes a title,<br><br>- 0 otherwise. <br><br><br> |
