
## BitcoinCoreDateTimeLastLaunched (Function)

***In french: BitcoinCoreDateHeureDernierLancement***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the date and time Bitcoin Core was last launched.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the date and time Bitcoin Core was last launched
d is DateTime
d = BitcoinCoreDateTimeLastLaunched()
IF ErrorOccurred THEN
	Error()
	RETURN
END
Trace("Last launched:" + DateToString(d))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BitcoinCoreDateTimeLastLaunched()`
---

**`<Result>: (DateTime)`**

Date and time Bitcoin Core was last launched.
