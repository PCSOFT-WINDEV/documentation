
## WLanguage procedure called by PVTCalculateAllAsynchronous



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [PVTCalculateAllAsynchronous](../WDLang1/1410090244.md) once all the data of a Pivot Table control has been calculated. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
PVTCalculateAllAsynchronous(PVT_Statistics, Calculation_completed)
	INTERNAL PROCEDURE Calculation_completed(bOK is boolean)
		IF NOT bOK THEN
			Error(ErrorInfo())
			RETURN
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PVTCalculateAllAsynchronous_Callback(<Status>)`
---

**`<Status>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the data of the Pivot Table control has been calculated,

- <u><u><u><u>False</u></u></u></u> otherwise. In this case, you can use [ErrorInfo](../WDLang1/3013008.md) to determine why the data could not be calculated.
