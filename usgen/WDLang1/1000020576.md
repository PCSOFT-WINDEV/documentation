
## fWatchStopAll (Function)

***In french: fSurveilleStopTout***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***fTrackStopAll*</**>** is kept for backward compatibility. This function has been replaced with ***fWatchStopAll*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops all current watch tasks of files and directories. The watch task could have been started with [fWatchFile](../WDLang1/1000020522.md) or [fWatchDirectory](../WDLang1/1000020523.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stop all current watch tasks
IF NOT fWatchStopAll() THEN
	Error("No watch task has been started.")
ELSE
	Info("Watch task stopped successfully.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fWatchStopAll()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if all active watch tasks have been stopped, 

- <u><u><u><u>False</u></u></u></u> otherwise (no watch task was found).
