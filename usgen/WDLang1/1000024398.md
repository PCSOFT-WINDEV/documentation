


## &lt;Word Processing&gt;.UndoCount (Function)

***In french: &lt;Traitement de texte&gt;.UndoOccurrence***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24 (75H)</B>, ***Word Processing.UndoOccurrence*</**>** is kept for backward compatibility. This function has been replaced with ***&lt;Word Processing&gt;.UndoCount*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of actions that can be undone in a Word Processing control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the number of actions that can be undone in the control
Info(WP_MyDocument.UndoCount())
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Word Processing control>.UndoCount()`
---

**`<Result>: (Integer)`**

Number of actions that can be undone.

**`<Word Processing control>: (Control name)`**

Name of the Word Processing control to use.
