


## AnimationSetParameter (Function)

***In french: AnimationChangeParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes one of the animation parameters used for:

- an animated image (in an Image control),

- an animated text (in a Static Text control).




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In this version, you can only change the animation parameters used for an animated text (in a Static Text control).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Change animation parameters for an Image control
IMG_Image1.Animation = True
AnimationSetParameter(IMG_Image1, acpDirectionAlternate, True)
```
<a name="Exemple2"></a>

```wl
// Change the animation parameters of a Static Text control
STC_MyStatic.Animation = True
AnimationSetMode(STC_MyStatic, actBlinking)
AnimationSetParameter(STC_MyStatic, acpDuration, 100)
AnimationSetParameter(STC_MyStatic, acpColor, DarkBlue)
```

### Changing the animation parameters of an image

`AnimationSetParameter(<Image control> , <Parameter to modify> , <Parameter value>)`
---

**`<Image control>: (Character string)`**

Name of the Image control to be used.

**`<Parameter to modify>: (Constant or character string)`**

Name of parameter to modify.


|   |   |
| --- | --- |
| *acpDirection* (or "Direction") | Scroll direction.<br>**"Scrolling" animation only.**<br>These parameters can be combined.<br><br>- 1 (default): stretching from left to right<br><br>- 2: stretching from right to left<br><br>- 4: stretching from bottom to top<br><br>- 8: stretching from top to bottom<br><br><br>Example of combination:<br><br>- 3 (2+1): left right: gradual widening from the center<br><br>- 5 (4+1) from bottom to top and from right to left<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpDirectionAlternate* (or "DirectionAlternate") | Read the image drawings from the first drawing to the last one, then from the last drawing to the first one continuously (this parameter is set to <u><u><u><u>False</u></u></u></u> by default). |
| *acpDuration* (or "Duration") | Amount of time for displaying each drawing of the animation in milliseconds (300 ms by default). |
| *acpLoop* (or "Loop") | Read the image drawings from the first drawing to the last one continuously (this parameter is set to <u><u><u><u>True</u></u></u></u> by default). |
| *acpNbImageX* (or "NumberOfImagesX") | Number of drawings found in the width of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br>**"Image to animate" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpNbImageY* (or "NumberOfImagesY") | Number of drawings found in the height of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br>**"Image to animate" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpNbStep* (or "NumberOfSteps") | 10 by default<br>**"Scrolling" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpReverse* (or "Reverse") | Read the image drawings from the last drawing (bottom right) to the first drawing (top left) (this parameter is set to <u><u><u><u>False</u></u></u></u> by default) |



**`<Parameter value>: (Type of expected parameter)`**

New value for the parameter.

### Changing the animation parameters of a static control

`AnimationSetParameter(<Static Text control> , <Parameter to modify> , <Parameter value>)`
---

**`<Static Text control>: (Character string)`**

Name of the Static Text control to be used.

**`<Parameter to modify>: (Constant or character string)`**

Name of parameter to modify.


|   |   |
| --- | --- |
| *acpColor* (or "Color") | Blinking color. This parameter can correspond to a [color constant](../WDLang5/3010002.md). This color corresponds to *Transparent* by default.<br>**"Blinking" animation only.** |
| *acpDirection* (or "Direction") | Scroll direction.<br>**"Scrolling" animation only.**<br>These parameters cannot be combined.<br><br>- 1 (default): dequeue to the left<br><br>- 2: Dequeue to the right<br><br>- 4: scroll down<br><br>- 8: scrolls upwards <br><br><br> |
| *acpDuration* (or "Duration") | Time for displaying each animation element in milliseconds (300 ms by default). |
| *acpLoop* (or "Loop") | Dequeue continuously (this parameter is <u><u><u><u>True</u></u></u></u> by default).<br>**"Scrolling" animation only.**<br> |
| *acpNbLoopMax* (or "NombreBoucleMax") | Number of loops for continuous dequeue (0 unlimited number of loops). <br>**"Scrolling" animation only.**<br> |
| *acpNbPixel* (or "NumberOfPixels") | Number of pixels for each scrolling step.<br>**"Scrolling" animation only.** |



**`<Parameter value>: (Type of expected parameter)`**

New value for the parameter.
