
## SysNameMainScreen (Function)

***In french: SysNomEcranPrincipal***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the main screen for the computer.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Affiche le nom de l'écran principal
Info(SysNomEcranPrincipal()) 
// Affiche par exemple: \\.\DISPLAY2\Monitor2 Écran Plug-and-Play
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysNameMainScreen()`
---

**`<Result>: (Character string)`**



- Name of the main screen, 

- Empty string ("") if an error occurred.
