


## ToastDisplay (Function)

***In french: ToastAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a "Toast" message.

Toasts are a short messages that appear on the screen for a few seconds before fading out without any user intervention. Toasts are modeless, don't take focus and don't interrupt the execution of the application.

Toasts are recommended to show information to the user without blocking the execution of the application (e.g. short message to indicate that a download has been completed).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ToastAffiche.gif)
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available for Linux WEBDEV websites only.

```wl
MyToast is Toast
MyToast.Title = "Did you know?"
MyToast.Text = "AAFs are really cool."
MyToast.Button[1].Caption = "Learn more..."
MyToast.Button[1].ActionClick = FuncHelp
MyToast.ActionClose = clickClose
ToastDisplay(MyToast)
INTERNAL PROCEDURE FuncHelp
	Open ("WIN_Help")
END
INTERNAL PROCEDURE clickClose(nButton)
	Trace("Click to close. Button: " + nButton)
END
```

### Displaying a toast based on a Toast variable

`ToastDisplay(<Toast>)`
---

**`<Toast>: (Toast variable)`**

Name of the [Toast](../WDLang1/1000024638.md) variable that defines the toast to be displayed. 

Note: You can use the [Toast](../WDLang1/1000024638.md) variable to to define a number of parameters. 




<a name="SYNTAXE1"></a>

### Defining and displaying a toast

`ToastDisplay(<Message> [, <Display duration> [, <Vertical alignment> [, <Horizontal alignment> [, <Background color>]]]])`
---

**`<Message>: (Character string)`**

Message to display. This message can be multiline

**`<Display duration>: (Optional integer)`**

Constant indicating the display duration of Toast message: 


|   |   |
| --- | --- |
| *toastLong* | The Toast message will be displayed during a long period of time. |
| *toastShort*<br>(Default value) | The Toast message will be displayed during a short period of time. |


**Note**: The exact display duration depends on the device.

**`<Vertical alignment>: (Optional integer)`**

Constant indicating the vertical alignment of the message. This alignment is relative: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) to the screen.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) to the window.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) to the page.





|   |   |
| --- | --- |
| *vaBottom*<br>(Default value) | The Toast message is displayed at the bottom. |
| *vaMiddle* | The Toast message is displayed in the middle. |
| *vaTop* | The Toast message is displayed at the top. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Starting with Android 11, it is no longer possible to set the position of toast messages. This parameter is ignored. 

**`<Horizontal alignment>: (Optional integer)`**

Constant indicating the horizontal alignment of the message. This alignment is relative: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) to the screen.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) to the window.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) to the page.





|   |   |
| --- | --- |
| *haCenter*<br>(Default value) | The Toast message is displayed in the center.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The toast will always be centered horizontally. |
| *haLeft* | The Toast message is displayed on the left.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |
| *haRight* | The Toast message is displayed on the right.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Starting with Android 11, it is no longer possible to set the position of toast messages. This parameter is ignored. 

**`<Background color>: (Optional integer)`**

Background color used to display the message. This parameter can correspond to: 

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This parameter is not available.

## Remarks


### Managing threads
<a name="managing_threads_ELTPARAGRAPHE000240"></a>

**ToastDisplay** can be called from a WLanguage thread (to notify the user of events that occurred during the thread execution for example).


### Successive calls
<a name="successive_calls_ELTPARAGRAPHE000249"></a>

If **ToastDisplay** is called several times, each toast is displayed once the previous toast has disappeared. This behavior can be changed using the **Overlayable** property of the [Toast](../WDLang1/1000024638.md) variable. This property allows you to get the same behavior as in version 24, in which toasts could be displayed one over another.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If **ToastDisplay** is called several times, only the last call to the function will be taken into account.
