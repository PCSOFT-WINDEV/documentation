


## TableDelete (Function)

***In french: TableSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a row from: 

- a Table control,

- a TreeView Table control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a table displayed in a Combo Box control.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: To delete a line with animation, use the [TableDeleteWithAnimation](../WDLang1/1000022400.md) function.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete row #5 from the "TABLE_Product" control
TableDelete(TABLE_Product, 5)
```
<a name="Exemple2"></a>

```wl
// Delete all selected rows from a Table control
// TableDeleteSelect is available from version 18
i is int
NbSelection is int = TableSelectCount(TABLE_MyTable)
FOR i = NbSelection TO 1 STEP -1
	TableDelete(TABLE_MyTable, TableSelect(TABLE_MyTable, i))
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableDelete(<Table control> [, <Index>])`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control with table.


If this parameter is an empty string (""), the Table control of the current event will be used.

**`<Index>: (Optional integer)`**

Index of the row to delete. 
If this parameter is not specified, the selected rows are deleted. If this parameter is not specified and if no row is selected, **TableDelete** has no effect.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000126"></a>

**TableDelete** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.
<a name="NOTE0_2"></a>


### Deleting records in a Table or TreeView data-bound Table control based on a table
<a name="deleting_records_table_treeview_databound_table_control_based_table_ELTPARAGRAPHE000162"></a>

**TableDelete** deletes the corresponding record from the table associated with the control. If items are linked to other tables, no modification is automatically performed on these linked tables.
<a name="NOTE0_3"></a>


### Referential integrity and Table or TreeView data-bound Table controls
<a name="referential_integrity_and_table_treeview_databound_table_controls_ELTPARAGRAPHE000173"></a>

If the management of referential integrity is enabled ([HSetIntegrity](../WDLang4/3044058.md)), [HErrorIntegrity](../WDLang4/3044086.md) must be called after **TableDelete** to check the integrity. 

If an integrity error is detected, the row is not deleted and it remains visible in the control.
<a name="NOTE0_4"></a>


### Deleting records in a data-bound Table control and Trigger
<a name="deleting_records_databound_table_control_and_trigger_ELTPARAGRAPHE000192"></a>

You have the ability to activate a trigger when deleting a record from a data-bound Table control based on a table. For more details, see the documentation about [HDescribeTrigger](../WDLang4/3044074.md).
<a name="NOTE0_5"></a>


### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000204"></a>

The [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> if the deletion fails. To get the details of the error, use [ErrorInfo](../WDLang1/3013008.md).  

Example of error: Deleting a line whose index corresponds to a non-selected line in the visible part of the Table control.
<a name="NOTE0_6"></a>


### Locking the linked table
<a name="locking_the_linked_table_ELTPARAGRAPHE000225"></a>

If the table is locked in the current process, **TableDelete** deletes the specified row and unlocks the table.
<a name="NOTE0_7"></a>


### Deleting records in a Table control populated programmatically with a "Contains" filter
<a name="deleting_records_table_control_populated_programmatically_with_contains_filter_ELTPARAGRAPHE000236"></a>

When used on a Table control populated programmatically with a "Contains" filter, **TableDelete** displays the records that do not match the filter. The filters defined by the AAFs (Automatic Application Features) are canceled.
