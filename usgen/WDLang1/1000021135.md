


## PVTHeaderValue (Function)

***In french: TCDValeurEntête***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the value displayed in a Pivot Table control header.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
i is int = 1
s is string = PVTHeaderValue(PVT_Stat, "DPVT_Family", i)
WHILE s <> "" 
	Trace(s)
	s = PVTHeaderValue(PVD_Stat, "DPVT_Family", i)
	i++
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PVTHeaderValue(<Pivot Table control> , <Header> , <Index>)`
---

**`<Result>: (Character string)`**



- Value of the specified header.

- Empty string ("") if the specified index is invalid. 




**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used

**`<Header>: (Character string)`**

Name of a Pivot Table control header.

**`<Index>: (Integer)`**

Index of the value to retrieve.
