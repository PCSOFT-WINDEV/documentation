
## ShellExecute (Function)

***In french: LanceAppliAssociée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a document in its associated application. The application is opened first, then the specified document.

**Remarks**: 

- The application used to open the document is the one associated with the extension of the document in Windows (INI file or registry). This associated application may differ according to the configurations used.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This document is opened on the server. This function can be used on the development computer because this compute is considered as being the server.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This document must be found on the server or at any Internet address. This document is opened on the computer of the Web user.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The application used to open the document is the application corresponding to the MIME type associated with the file extension. If several applications correspond to the same type of file, a dialog box will be displayed to select the application to start.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) **ShellExecute** will block the application until the document and its associated application are closed. The document must be on the computer. 

- To display any page in a browser, you can also use [BrowserRunApp](../WDLang2/1000019424.md).

## Syntax

`<Result> = ShellExecute(<File name> [, <Verb>])`
---

**`<Result>: (Boolean)`**



-  if the document exists and if the associated application has been launched. 

- <u><u><u><u>False</u></u></u></u> otherwise.




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available. This function returns no result.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Returns <u><u><u><u>False</u></u></u></u> if the application is run with a Java virtual machine (JRE) earlier than version 1.6. 

**`<File name>: (Character string)`**

Name and full (or relative) path of the document to open. A UNC path can be used. 
If space characters are found in the name or path of the document to open, the quotes found around this parameter must be tripled.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) This parameter can also correspond to a Windows shortcut.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path, to a relative path or to a URI. 

For example: 

- "/sdcard/photo.png"

- "/sdcard/video.3gp". 

- "http://www.windev.com": Opens the web browser on the specified page. 

- "geo:1.44951,43.604363": Launches Google Maps or equivalent. 

- "mailto:info@windev.com": Launches the email application. 

- "sms:0612345678": Launches the SMS application. 




The files found in the application directory (or in one of its sub-directories) are not accessible by most of the external applications. It is recommended to use **ShellExecute** with files located on the external memory of the device (e.g. SD card). as they are accessible from all the applications.

**`<Verb>: (Optional character string)`**

Verb that must be used to start the document. The verbs are defined for each application, to indicate the actions that can be performed. The most common verbs are **open** or **print**. If this parameter is not specified, the verb used will be the default verb for the type of document.

 
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

## Remarks


### Use in service mode
<a name="use_service_mode_ELTPARAGRAPHE000170"></a>

When **ShellExecute** is used in service mode, it runs the associated application but the interface of this application is not visible. 




<a name="NOTE0_4"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Running an APK file setup
<a name="running_apk_file_setup_ELTPARAGRAPHE000184"></a>

From Android 8, to run the setup of an APK file with **ShellExecute**, it is necessary to modify the permissions required by the application.  

Required permission: REQUEST_INSTALL_PACKAGES. 

This permission is used to install packages. 

For more details (especially for previous versions of WINDEV Mobile), see [FAQ 16927: What to do under Android 8 if it is no longer possible to install an APK with the ShellExecute function?](https://faq.windev.com/faqread.awp?idfaq=16927). 
<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000339"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ShellExecute** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
