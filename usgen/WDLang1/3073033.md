
## SysSerialNum (Function)

***In french: SysNumSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the IMEI number of the current device.

This function is equivalent to [SysIMEI](../WDLang1/3073029.md). 

Warning: This information can be retrieved up to Android 9. From Android 10 onwards, this information is no longer available: this function causes a fatal error..  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SI Val(SysVersionAndroid(sysVersionNuméro))<10 ALORS  
	// Récupération du numéro de série du téléphone en cours
	Info("Le numéro de série de ce téléphone est " + SysNumSérie())
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysSerialNum()`
---

**`<Result>: (Character string)`**



- Serial number of the current Android phone,

- Empty string ("") if an error occurred.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000054"></a>

- [SysIMEI](../WDLang1/3073029.md) gets the IMEI number of a phone. 

- Devices that do not have a SIM card slot do not have an IMEI number (most tablets).
