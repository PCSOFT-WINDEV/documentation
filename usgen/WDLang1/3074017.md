


## TableAdd (Function)

***In french: TableAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row in: 

- a Table control,

- a TreeView Table control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control "with table" (Table control displayed in a Combo Box control).




**Note**: It is recommended to use [TableAddLine](../WDLang1/3074006.md). [TableAddLine](../WDLang1/3074006.md) is used to add:

- TAB characters into the columns, 

- all types of values into the columns, 

- UNICODE data automatically and without conversion.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add "Moore", "Vince" and "06/21/72"
// at the end of the "TABLE_CustomerTable" control
ResAdd = TableAdd(TABLE_CustomerTable, "Moore" + TAB + "Vince" + TAB + "06/21/72")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TableAdd(<Table control> [, <Row>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element was added,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control with table.


If this parameter corresponds to an empty string (""), the control to which the current event belongs will be used.

**`<Row>: (Optional character string)`**

Row to add. This row has the following format: 

```txt
<Element of column 1> + TAB + <Element of column 2> + TAB + ...
```

If this parameter is not specified, an empty row is added into the control. For a data-bound control, the default values defined in the linked table are taken into account.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000124"></a>

**TableAdd** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **TableAdd** cannot be used on data-bound Table controls. 
<a name="NOTE0_2"></a>


### Row characteristics
<a name="row_characteristics_ELTPARAGRAPHE000165"></a>

- Each added element is converted into the type of the relevant column.

- If you don't want to specify a value for an element, use an empty string ("") or 0 (depending on the column type). For example:
	
	```wl
	TableAdd(TABLE_CustomerTable, "Moore" + TAB + "Vince" + TAB + "" + TAB + "06/21/72")
	```


- If an element corresponds to the result of a calculation, enclose the numerical expression in brackets. For example:
	
	```wl
	TableAdd(TABLE_CalcTable, (53+29) + TAB + (83-21))
	```




<a name="NOTE0_3"></a>


### Position of the new row
<a name="position_the_new_row_ELTPARAGRAPHE000190"></a>

By default, the row is added at the end of the rows displayed by the control.

Special case: 

- If the control is sorted by [TableSort](../WDLang1/3074035.md), the added row is positioned in the control according to the current sort.

- If the control is sorted by the user, the sort is ignored when inserting the row. The row is added at the end of control.



<a name="NOTE0_4"></a>


### Limits: Maximum number of lines displayed
<a name="limits_maximum_number_lines_displayed_ELTPARAGRAPHE000207"></a>

The maximum number of rows that can be displayed in a TreeView Table control or hierarchical Table is limited only by available RAM (theoretical maximum: 2 billion rows).

However, we do not advise you to use large Table or TreeView Table controls for performance and user-friendliness reasons (time required to fill the control for example).
<a name="NOTE0_5"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000218"></a>

- To add a row at a specific position in a Table or TreeView Table control, use [TableInsertLine](../WDLang1/3074026.md).

- If the added row is the first row of the control, the added row becomes the current row.

### Cascading input
<a name="cascading_input_ELTPARAGRAPHE000253"></a>

To perform a cascading input, **TableAdd** must be used in the "Exit a row" event of the Table control:

```wl
IF TABLE_CustomerTable.NewLine THEN
	TableAdd(TABLE_CustomerTable)
END
```
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is only available for Table control fields in AJAX mode.

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000276"></a>

- **If the cascading input is enabled**, the table linked to the control is automatically modified when the user goes to the next row.

- **If the cascading input is not enabled**, the table linked to the control is not modified. To write the content of the new row to the linked table, [TableSave](../WDLang1/3074008.md) must be used after **TableAdd**.




**Remarks**: 

- The "Cascading input (Add)" option can be selected in the "Details" tab of the control description.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available for Table controls populated programmatically and with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available for "Server + AJAX" data-bound Table controls based on a table.

### Table field/Hierarchical table file: Add multiple lines
<a name="table_fieldhierarchical_table_file_add_multiple_lines_ELTPARAGRAPHE000309"></a>

A virtual row is created each time **TableAdd** is called in a Table or TreeView data-bound Table control. The information will be saved in the linked table only when [TableSave](../WDLang1/3074008.md) is called.

If **TableAdd** is successively called in the same process without being followed by [TableSave](../WDLang1/3074008.md), only the FIRST call is effective (the following calls are ignored). Only one row is added to the Table or TreeView Table control.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This operating mode is only available for "Server + AJAX" Table controls based on a table.

### Table or TreeView data-bound Table control in edit mode
<a name="table_treeview_databound_table_control_edit_mode_ELTPARAGRAPHE000352"></a>

If **TableAdd** is called:

- In a control event, the cursor is automatically positioned on the first editable column in the new row.

- In an event that does not belong to the control (or in another process), [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) must be used to resume the input in the Table or TreeView Table control.



<a name="NOTE0_12"></a>


### Adding images
<a name="adding_images_ELTPARAGRAPHE000369"></a>

To add an image to a Table or TreeView Table control: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) specify the name and full path of the image to be added.
	For example:
	
	```wl
	TableAdd(TABLE_MyTable, "C:\MyDocuments\MyImage.BMP")
	```


- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) specify the path and name of image to add. The path is relative to the "&lt;Project_Name&gt;_WEB" directory. 
	For example:
	
	```wl
	// Adds the image found in the "WB_MyApp_WEB" directory
	TableAdd(TABLE_MyTable, "MyImage.BMP")
	```



**Note**: To correctly display the added image, the column must be of type Image.
<a name="NOTE0_13"></a>


### Unicode management
<a name="unicode_management_ELTPARAGRAPHE000596"></a>

You can define how Unicode will be managed in the project configuration ("Unicode" tab of the configuration description window): 

- If "Use ANSI strings at runtime" is selected: data is converted using the current character set. 
	Reminder: [ChangeCharset](../WDLang1/3054001.md) is used to modify the current character set.

- If "Use UNICODE strings at runtime" is selected, the data is inserted without being converted.
