
## MultimediaClose (Function)

***In french: MultimédiaFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the media file currently played in the Multimedia control. The memory allocated to the media file is freed.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MyFile is string = "C:\My music\mysong.mp3"

MultimediaPlay(MM_Multimedia1, MyFile)
...
MultimediaClose(MM_Multimedia1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = MultimediaClose(<Name of Multimedia control>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file played in the Multimedia control is closed properly,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Note: The [ErrorInfo](../WDLang1/3013008.md) function is not available.

**`<Name of Multimedia control>: (Character string)`**

Name of the Multimedia control to be used.

## Remarks

### Specific features for iPhone/iPad
<a name="specific_features_for_iphoneipad_ELTPARAGRAPHE000071"></a>

**MultimediaClose** and [MultimediaStop](../WDLang1/1000017203.md) are equivalent. Media playback in the Multimedia control is stopped, but the media file remains loaded in memory.
