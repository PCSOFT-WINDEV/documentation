
## ThreadEnd (Function)

***In french: ThreadFin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>

## Remarks


- If the current the thread is the main the thread, function **ThreadEnd** is equivalent to function [EndProgram](../WDLang1/3013033.md): the application is stopped.. 




- **To stop a secondary Thread**: 

	- First method: 

		- Use function [ThreadRequestStop](../WDLang1/1000021218.md) from the thread that is to request the stop. The secondary thread will not be stopped automatically.. 

		- The secondary thread's code must check if the stop is requested using the [ThreadStopRequested](../WDLang1/1000021219.md) function.. It must then be terminated "cleanly" by ending the current code or calling function **ThreadEnd**.




- Second method: You can also set up a stop system using the **ThreadEnd**function. . You have the ability to: 

	- In the main thread, declare a global variable of type Boolean. This variable determines whether the secondary thread must be stopped. 

	- In the secondary thread, check the value of the variable. If this value is , use the **ThreadEnd** function to terminate the current secondary the thread.. 

	- In main the thread, set the variable to <u><u><u><u>True</u></u></u></u> to force the secondary thread to stop.
