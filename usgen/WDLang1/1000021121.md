


## &lt;Gantt chart&gt;.AddTask (Function)

***In french: &lt;Diagramme de Gantt&gt;.AjouteTâche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a task in a Gantt Chart column in a Table or TreeView Table control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NewTask is GanttTask

// Configures the task
NewTask.ID = GetIdentifier()
NewTask.Row = 1
NewTask.Progress = 50
NewTask.StartDate = Today()
NewTask.DurationInDay = 1
NewTask.Title = "New task"

// Adds the task
COL_Gantt.AddTask(NewTask)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Gantt column>.AddTask(<Task>)`
---

**`<Gantt column>: (Control name)`**

Name of the Gantt Chart column (in a Table or TreeView Table control) to be used.

**`<Task>: (GanttTask variable)`**

Name of the [GanttTask](../WDLang1/1000020881.md) variable that describes the characteristics of the task to add.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The new task is added then it is displayed.

- The task can be retrieved in a [GanttTask](../WDLang1/1000020881.md) variable by using [&lt;Gantt chart&gt;.GetTask](../WDLang1/1000021137.md): 
	



```txt
<Variable name> <- <Gantt column>GetTask(<Identifier>)
```

where Identifier is the identifier of the task to retrieve. 
For example: 

```wl
// Modify a task
MyTask is GanttTask
MyTask <- COL_Gantt.GetTask("ID1")
MyTask.Progress = 70
MyTask.ProgressColor = LightGreen
```

As the task is retrieved by the **<-** operator, the modifications performed on the [GanttTask](../WDLang1/1000020881.md) variable will be automatically applied to the Gantt chart. 
You also have the ability to retrieve a task by using the following syntax: 

```txt
<Variable name> <- <Gantt column>["<Identifier>"]
```

For example: 

```wl
t <- COL_Gantt["ID1"]
t.BackgroundColor = LightBlue
```


- A WLanguage error occurs if the task has no identifier or if this identifier already exists.
