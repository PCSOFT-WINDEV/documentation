
## gFontSize (Function)

***In french: gPoliceTaille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a sequence of characters used to specify the size of the font for a text found in a graphic string.

**Note** All text written **following** function is assigned.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) In a window, this sequence of characters is used to indicate the font size:  

- in an element of a List Box or Combo Box control.

- in the title bar and/or status bar of a window. 

- in a Static Text control. 







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Display the "WINDEV, IDE #1 in France" title of the next window
NextTitle(gFontSize(12) + "WINDEV" + gFontSize(10) + ", #1 in France.")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = gFontSize(<Font size>)`
---

**`<Result>: (Character string)`**

Sequence of characters defining the font size for the rest of the text.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This sequence of characters can be: 

- used in [ListAdd](../WDLang1/3049004.md), [ListInsert](../WDLang1/3049002.md) or [ListModify](../WDLang1/3049009.md).

- assigned to a Static Text control. 

- used in the title bar or status bar of a window. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This sequence of characters is not interpreted by the controls in WEBDEV. This function can be used to format the string returned by a WEBDEV web service consumed by a WINDEV or WINDEV Mobile application.

**`<Font size>: (Integer)`**

New font size for the text after the call to **gFontSize**.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The default font defined for the control used is restored after the call to [gFontXXX](../WDLang1/3029028.md).

- All the other characteristics of the font are kept (italics, etc.).
