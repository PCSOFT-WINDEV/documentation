


## &lt;Image variable&gt;.DrawTextRTF (Function)

***In french: &lt;Variable Image&gt;.DessineTexteRTF***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws RTF text in a variable of type [Image](../WDLang1/1000019650.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is Image = "Test.bmp"
// Draw RTF text
MyImage.DrawTextRTF(10, 20, MyTextRTF)
IMG_MyDrawing = MyImage
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Drawing RTF text by specifying coordinates

`<Image>.DrawTextRTF(<X-coordinate> , <Y-coordinate> , <RTF text> [, <Width> [, <Height>]])`
---

**`<Image>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used. 

**`<X-coordinate>: (Integer)`**

X-coordinate of the RTF text to draw (in pixels).

**`<Y-coordinate>: (Integer)`**

Y-coordinate of the RTF text to draw (in pixels).

**`<RTF text>: (Character string)`**

RTF text to draw.

**`<Width>: (Optional integer)`**

Maximum width of the text. No maximum width is defined by default.

**`<Height>: (Optional integer)`**

Maximum height of the text. No maximum height is defined by default.


<a name="SYNTAXE2"></a>

### Drawing RTF text in a rectangle

`<Image>.DrawTextRTF(<Rectangle> , <RTF text>)`
---

**`<Image>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used. 

**`<Rectangle>: (Rectangle variable)`**

Name of the [Rectangle](../Motscles/1514079.md) variable that corresponds to the area in which to draw the text.

**`<RTF text>: (Character string)`**

RTF text to draw.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Syntax using coordinates
<a name="syntax_using_coordinates_ELTPARAGRAPHE000383"></a>

Coordinates are specified with respect to the upper-left corner of the image (coordinates: (0.0)).

The coordinates correspond to the upper-left corner of the rectangle into which the text will be drawn.
