


## dSaveImageJPEG (Function)

***In french: dSauveImageJPEG***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves an image:

- in a JPEG file.

- in memory.




This image corresponds to the image found:

- in an Image control.

- in a variable of type [Image](../WDLang1/1000019650.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.

- in a Bar Code control.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The Bar Code controls are not available in this version. Therefore, no image found in a Bar Code control can be saved.

- in a Web Camera control.




**Remarks**:

- Only the visible part of the Image control is saved.

- This function can only be used to save the images for screen resolutions up to 32-bit.

- This function cannot be used with the Image controls found in reports.

- This function can also be used to save the changes made by [ImageInfoModify](../WDLang1/3091005.md) on the Exif tags of an image.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Saving images in JPEG format is supported only if the application is run by the Java Virtual Machine (JVM) distributed by SUN. Images in JPEG format cannot be saved with other Java virtual machines. 


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In Browser code, this function can only be used to save an image in memory.

### Saving an image in a JPEG file

`<Result> = dSaveImageJPEG(<Image> , <File name> [, <Quality> [, <Exif tag>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the image was saved,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Image>: (Name of the Image control or variable)`**



- Name of the Image, Bar Code or Web Camera control to be used. Image controls in a report cannot be used. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Name of the Image or Web Camera control to be used.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Name of the Image control to be used.

- Name of the [Image](../WDLang1/1000019650.md) variable to be used.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.




**`<File name>: (Character string)`**

Name and full (or relative) path of JPEG file. A UNC path can be used. The file extension is optional.

**Caution**: 

- The destination directory must exist in order for the image to be saved.

- The existence of the JPEG file is not checked. This file is automatically overwritten if it already exists.




**`<Quality>: (Optional integer)`**

Quality of the image saved. Value between 1 and 100 (80 by default). Lower image quality translates into higher image compression rate and smaller file size.

**`<Exif tag>: (Optional constant (or combination of constants))`**

Save the Exif tags modified by [ImageInfoModify](../WDLang1/3091005.md):


|   |   |
| --- | --- |
| *imgAddThumbnail* | Adds a thumbnail into the image file (&lt;File name&gt;).<br>If there is a thumbnail in the image file displayed in the Image control, this constant is not taken into account.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *imgGrayScale* | Used to save the image in black and white ("Grayscale" display mode).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *imgProgressiveJPEG* | Allows you to save the image in progressive JPEG format. This format is mainly used for the Web sites. It allows the pages to be loaded faster (the images being loaded and displayed progressively).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *imgSaveTag* | Saves the Exif tags.<br>If there is a thumbnail in the image file displayed in the Image control, a new thumbnail is recalculated.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant can be used only if &lt;Image name&gt; is a variable of type [Image](../WDLang1/1000019650.md). The thumbnail will not be recalculated. <br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |


By default, the Exif tags are not saved, no operation is performed on the thumbnails.

![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is now available for iOS applications.

### Saving an image in memory

`<Result> = dSaveImageJPEG(<Image> , <inMemory> [, <Quality> [, <Exif tag>]])`
---

**`<Result>: (Buffer)`**

Byte string containing the image in JPEG format.
Then this byte string can be assigned to an Image control, saved in a file ([fSaveText](../WDLang1/3036046.md)), sent via a network (with the [Socket functions](../WDLang3/3070007.md)), ...

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In Browser code, this byte string can only be assigned to another image ("Localize the image in the _WEB directory in Browser code" must be unchecked). It cannot be saved in a file to build an image file.

**`<Image>: (Name of the Image control or variable)`**



- Name of the Image, Bar Code or Web Camera control to be used. Image controls in a report cannot be used. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Name of the Image or Web Camera control to be used.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Name of the Image control to be used.

- Name of the [Image](../WDLang1/1000019650.md) variable to be used.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.




**`<inMemory>: (Constant)`**

*inMemory*: Constant used to save an image in memory.

**`<Quality>: (Optional integer)`**

Quality of the image saved. Value between 1 and 100 (80 by default). Lower image quality translates into higher image compression rate and smaller file size.

**`<Exif tag>: (Optional constant (or combination of constants))`**

Save the Exif tags modified by [ImageInfoModify](../WDLang1/3091005.md):


|   |   |
| --- | --- |
| *imgAddThumbnail* | Adds a thumbnail into the image file (&lt;File name&gt;).<br>If there is a thumbnail in the image file displayed in the Image control, this constant is not taken into account.<br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *imgProgressiveJPEG* | Allows you to save the image in progressive JPEG format. This format is mainly used for the Web sites. It allows the pages to be loaded faster (the images being loaded and displayed progressively). |
| *imgSaveTag* | Saves the Exif tags.<br>If there is a thumbnail in the image file displayed in the Image control, a new thumbnail is recalculated.<br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |


By default, the Exif tags are not saved, no operation is performed on the thumbnails.

This parameter is available only if &lt;Control name&gt; corresponds to the name of an Image control.

## Remarks


### Image found in a Web Camera control
<a name="image_found_web_camera_control_ELTPARAGRAPHE000419"></a>

Only the image displayed when **dSaveImageJPEG** is executed is saved. To save this image, you can also use:

- the [VideoCapture](../WDLang1/3079007.md) function: the image will be saved in BMP format

- the [dSaveImageBMP](../WDLang1/3029026.md) function: the image will be saved either in BMP format or in memory.

- the [dSaveImageGIF](../WDLang1/3029040.md) function: the image will be saved either in Gif format or in memory.

- the [dSaveImagePNG](../WDLang1/3029027.md) function: the image will be saved either in PNG format or in memory.



<a name="NOTE0_2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000451"></a>

The image saved in memory can be directly assigned to an Image control. Depending on the browser used, the result may not be the expected one. 

For example, with the current version of FireFox and Opera (available when this documentation was published), images in JPEG format are not displayed properly (they are displayed on a black background). 

This operating mode may be improved during the next upgraded versions of these browsers.  
<a name="NOTE0_3"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000614"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.
