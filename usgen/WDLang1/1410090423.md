
## Bitcoin Core server constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manipulate Bitcoin Core servers:

| Constant | Details | Function |
| --- | --- | --- |
| **btcRpcServerAddress** | Bitcoin Core server address. | [BitcoinCoreConfigure](../WDLang1/1410090320.md) |
| **btcRpcUser** | Username used to log in to the Bitcoin Core server. | [BitcoinCoreConfigure](../WDLang1/1410090320.md) |
| **btcRpcPassword** | Password used to log in to the Bitcoin Core server. | [BitcoinCoreConfigure](../WDLang1/1410090320.md) |
| **btcRpcPortNumber** | Bitcoin Core server connection port number. | [BitcoinCoreConfigure](../WDLang1/1410090320.md) |
| **btcTimeout** | Bitcoin Core server connection timeout. | [BitcoinCoreConfigure](../WDLang1/1410090320.md) |
