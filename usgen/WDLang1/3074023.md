


## TableInputInProgress (Function)

***In french: TableSaisieEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether or not a Table or TreeView Table control is in edit mode.

**Note** If the user uses Search mode in the column header (magnifying glass), the Table or Hierarchical Table field is considered to be currently being entered.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The user is not performing an input in the control
IF TableInputInProgress(TABLE_TABLE1) = False THEN
	// Updates the Table control
	TableDisplay(TABLE_Table1)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TableInputInProgress(<Table control>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control is currently in edit (which means if the user is typing information in the control),

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a TreeView Table control. 
	![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The TreeView Table controls are not available.

<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000097"></a>

This function is available on: 

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function is available for Table controls in "Server + AJAX" mode and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.
