
## SysVersion (Function)

***In french: SysVersion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the PHP version used on the current server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the PHP version
 Info("PHP version " + SysVersion())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysVersion()`
---

**`<Result>: (Character string)`**



- Requested information about the PHP version, 

- Empty string ("") if an error occurred.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function is also available in WEBDEV Server in order to be used when debugging a PHP site. The function returns "PHP simulation mode". A fatal error is displayed if this function is used outside the debug mode of a PHP site.
