
## ShamirGeneratePrime (Function)

***In french: ShamirGénèreNombrePremier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Generates a random prime number that can be used to create shares using Shamir's algorithm. This number is generated according to the secret. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
secret is Buffer = "Secret data"
hex_prime_number is ANSI string = ShamirGeneratePrime(secret)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Prime number> = ShamirGeneratePrime(<Secret>)`
---

**`<Prime number>: (Character string)`**

Prime number usable with Shamir's algorithm for the specified secret. 
Note: As this prime number can be very large, it is formatted as an ANSI string. 

**`<Secret>: (Buffer)`**

Secret that will be encoded using Shamir's algorithm.
