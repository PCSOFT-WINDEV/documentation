
## SysScreenOrientation (Function)

***In french: SysOrientationEcran***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to: 

- know your device's screen orientation (Android or iOS phone).

- set the screen orientation of the device (Android phone).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Remplir le champ Liste "LISTE_Orientations" avec les orientations possibles
ListeAjoute(LISTE_Orientations, SysListeOrientationEcran())

// Sélectionner l'orientation actuel de l'écran dans le champ Liste
LISTE_Orientations = SysOrientationEcran()
```


<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
```wl
// Changer l'orientation de l'écran
// L'écran sera retourné
SysOrientationEcran(Orient180)
```

## Syntax

### Getting the screen orientation

`<Result> = SysScreenOrientation()`
---

**`<Result>: (Character String constant)`**

Value of the current screen orientation:


|   |   |
| --- | --- |
| *Orient0* | The screen is oriented in the default direction. |
| *Orient90* | The screen is turned around by 90° clockwise. |
| *Orient180* | The screen is turned around by 180°. |
| *Orient270* | The screen is turned around by 90° counterclockwise (or by 270° clockwise). |




<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
### Setting the screen orientation

`<Result> = SysScreenOrientation(<Orientation>)`
---

**`<Result>: (Character String constant)`**

Orientation of the screen after the call to the function.

**`<Orientation>: (Character String constant)`**

Indicates the new orientation of the screen:


|   |   |
| --- | --- |
| *Orient0* | The screen is oriented in the default direction. |
| *Orient90* | The screen is turned around by 90° clockwise. |
| *Orient180* | The screen is turned around by 180°. |
| *Orient270* | The screen is turned around by 90° counterclockwise (or by 270° clockwise). |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The screen orientation cannot be changed in all types of mobile devices. When this feature is not available, **SysScreenOrientation** always returns *Orient0*.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The modification of the orientation will affect the current window only. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Depending on the type of device on which the application is run (phone or tablet), the default orientation (*Orient0*) can correspond to: 

	- the portrait mode (for most of the phones), 

	- the landscape mode (for most of the tablets). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) To define whether an application is displayed in portrait or landscape mode, it is recommended to compare the values returned by [SysXRes](../WDLang1/3073024.md) and [SysYRes](../WDLang1/3073006.md): 

	- if the value returned by [SysXRes](../WDLang1/3073024.md) is less than the value returned by [SysYRes](../WDLang1/3073006.md), the application is in portrait mode, 

	- otherwise, it is in landscape mode.
