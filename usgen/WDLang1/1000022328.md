


## &lt;Window&gt;.EdRedo (Function)

***In french: &lt;Fenêtre&gt;.EdRedo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Runs the last action undone by the end user ("Allow end users to modify the UI" option enabled). This function is equivalent to a "Redo" (Ctrl + Y) performed by the user. 

This function is mainly used when creating an editor through programming (see "Remarks").
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// [Restore] button
WIN_Form.EdRedo()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Window>.EdRedo()`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. This window must be in edit mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000175"></a>

- **&lt;Window&gt;.EdRedo** has no effect if no action was undone. 

- If the last action is a custom action run by [&lt;Window&gt;.EdDo](../WDLang1/1000022327.md), the procedure declared in this function is run.

- The restored action can be undone again by pressing Ctrl + Z or programmatically with [&lt;Window&gt;.EdUndo](../WDLang1/1000022335.md).



<a name="NOTE0_2"></a>


### Use example
<a name="use_example_ELTPARAGRAPHE000199"></a>

[&lt;Window&gt;.EdDo](../WDLang1/1000022327.md) is used to create custom actions (control creation for example) that support the undo/redo feature.

Let's take a simple example: creating a graphical object editor. 

A button is used to create a shape. The user must have the ability to undo the shape creation. The following operations are performed: 

- The window switches to edit mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)). 

- Call function [&lt;Window&gt;.EdDo](../WDLang1/1000022327.md). The procedure called by this function is used to create the shape. This procedure also contains the call to [WinEdDeclareUndo](../WDLang1/1000021898.md). [WinEdDeclareUndo](../WDLang1/1000021898.md) is used to define the behavior in case of user cancellation. 

- The window switches to standard mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)). 




The end user can undo this action (Ctrl + Z or [&lt;Window&gt;.EdUndo](../WDLang1/1000022335.md)) and eventually redo it (Ctrl + Y or [&lt;Window&gt;.EdRedo](../WDLang1/1000022328.md)).
