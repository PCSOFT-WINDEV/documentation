
## AIChatAsk (Function)

***In french: ChatIADemande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Launches a new request in the AI Chat control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AIChatAsk(AICHAT_MyChat, "Generate a report")

AIChatAsk(AICHAT_MyChat, "What is the capital of France?")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`AIChatAsk(<AI Chat control> , <Request>)`
---

**`<AI Chat control>: (Control name)`**

AI Chat control used. 

**`<Request>: (Character string)`**

Request text sent. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The text of the request is sent to the control, as when an end user presses the Enter key. 

- The "Before sending the request" event is executed. Other events associated with the control are executed as the AI returns a response.
