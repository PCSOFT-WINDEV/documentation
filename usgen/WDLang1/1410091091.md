


## SysDecrypt (Function)

***In french: SysDécrypte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Decrypts data using Windows user credentials. This data must have been previously encrypted with [SysEncrypt](../WDLang1/1410091090.md). 

Data can be decrypted only by the user who encrypted the data and on the computer where it was encrypted.
For example, encrypted data can come from a file saved by the same user on the same computer as the application that attempts to decrypt the data.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Data decryption
MyBuffer is Buffer = SysDecrypt(EncryptedBuffer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SysDecrypt(<Buffer to decrypt> [, <Application password>])`
---

**`<Result>: (Character string)`**



- Buffer containing the decrypted data.

- Empty buffer if an error occurs. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<Buffer to decrypt>: (Buffer)`**

Buffer to decrypt. This buffer must have been encrypted [SysEncrypt](../WDLang1/1410091090.md). 

**`<Application password>: (Optional buffer)`**

Buffer containing the password used to apply an additional encryption key (salt). This buffer must have been used with [SysEncrypt](../WDLang1/1410091090.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If the user changes their password between encryption and decryption, they will still be able to decrypt the data.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The credentials used are those of the Windows account used to run the sites and web services (set up for the site administrator in the WEBDEV Account Manager).
	All users of sites managed by the same WEBDEV server account share the same Windows user.
	As a result, if a user on a site encrypts data, this data can be decrypted by another user on this site, or on another site managed by the same account (provided the user has access to this data).
