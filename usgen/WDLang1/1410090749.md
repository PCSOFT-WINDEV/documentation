


## &lt;Command variable&gt;.AddOption (Function)

***In french: &lt;Variable Commande&gt;.AjouteOption***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an option to the command to be executed in console mode. 

Note: By default, the option indicator is: 

- '/' in Windows, 

- '-' on Linux.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line 
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Command>.AddOption(<Key> , <Value> [, <Separator>])`
---

**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command to be manipulated.

**`<Key>: (Character string)`**

Key of the new option.

**`<Value>: (Character string)`**

Value of the new option.

**`<Separator>: (Optional character string)`**

Separator between the key and the value. By default, the '=' character is used as separator (in order to be used with [CommandLine](../WDLang1/3013051.md)).
