
## AppOpenForm (Function)

***In french: AppliOuvreFiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens: 

- the application page on Play Store or App Store so that users can rate and/or comment.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the form for configuring the In-App purchases of an application.

## Syntax
<a name="SYNTAXE1"></a>

`AppOpenForm([<Application> [, <Type of form>]])`
---

**`<Application>: (Optional character string)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Full name of the application for which the page should be opened. This name has the following format: &lt;package&gt;.&lt;application name&gt; (for example: com.pcsoft.wm_expense_report). If this parameter is not specified, the form of current application will be opened.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) iTunes ID of the application. To get this identifier:  
**1.** Go to [http://linkmaker.itunes.apple.com/us/](http://linkmaker.itunes.apple.com/us/). 
**2.** Type the application name. The number is found in the returned URL. 

For example, for the WB Quizz application of PC Soft, the address is "https://itunes.apple.com/us/app/wb-quizz/id473232570?mt=8&uo=4" target="itunes_store"" and the identifier is **473232570**. 

**`<Type of form>: (Optional Integer constant)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Indicates the type of form to open: 


|   |   |
| --- | --- |
| *formApplication*<br>(Default value) | Opens the application form. |
| *formInAppPurchase* | Opens the window for configuring In-App purchases.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Opens the same form as when using the *formApplication* constant. |

## Remarks


### Necessary conditions
<a name="necessary_conditions_ELTPARAGRAPHE000088"></a>

The application for which the form must be opened must have been published on the store beforehand.
<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000226"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**AppOpenForm** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
