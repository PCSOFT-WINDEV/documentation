


## dArc (Function)

***In french: dArc***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws an arc of circle or an arc of ellipse:

- in an Image control, 

- in a variable of type [Image](../WDLang1/1000019650.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in a variable of type [WDPic](../WDLang1/1000023503.md) (on the background layer),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in a variable of type [picLayer](../WDLang1/1000024604.md).




The arc is drawn counterclockwise.
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md).

## Syntax

### Drawing an arc, specifying all the coordinates of the bounding rectangle

`dArc([<Image>, ] <X1> , <Y1> , <X2> , <Y2> , <X3> , <Y3> , <X4> , <Y4> [, <Line color> [, <Line thickness>]])`
---

**`<Image>: (Optional control name or optional Image, WDPic or picLayer variable)`**

This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [WDPic](../WDLang1/1000023503.md). Only the background layer will be handled. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [picLayer](../WDLang1/1000024604.md).


If this parameter is not specified, it is necessary to define the drawing destination with [dStartDrawing](../WDLang1/3029009.md). 

**`<X1>: (Integer)`**

X-coordinate (in pixels) of the upper-left corner of the rectangle containing the circle.

**`<Y1>: (Integer)`**

Y-coordinate (in pixels) of the upper-left corner of the rectangle containing the circle.

**`<X2>: (Integer)`**

X-coordinate (in pixels) of the lower-right corner of the rectangle containing the circle.

**`<Y2>: (Integer)`**

Y-coordinate (in pixels) of the lower-right corner of the rectangle containing the circle.

**`<X3>: (Integer)`**

X-coordinate (in pixels) of the starting point of the arc.

**`<Y3>: (Integer)`**

Y-coordinate (in pixels) of the starting point of the arc.

**`<X4>: (Integer)`**

X-coordinate (in pixels) of the end point of the arc.

**`<Y4>: (Integer)`**

Y-coordinate (in pixels) of the end point of the arc.

**`<Line color>: (Integer or constant (optional))`**

Color of the arc of circle. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md), 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) a variable of type [Color](../WDLang1/1000019661.md).


If this parameter is not specified, the line color:

- is *Transparent* if [dPen](../WDLang1/3029029.md) has not been previously used. 
	For a variable of type [Image](../WDLang1/1000019650.md), the line will be black. 

- corresponds to the color specified in the last call to [dPen](../WDLang1/3029029.md).




**`<Line thickness>: (Optional integer)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Thickness (in pixels) of the arc of circle to draw. If this parameter is not specified, the value taken into account can be:

- the last value specified in the last call to [dPen](../WDLang1/3029029.md).

- 1 if [dPen](../WDLang1/3029029.md) was not used beforehand.

## Remarks


### Coordinates of the arc
<a name="coordinates_the_arc_ELTPARAGRAPHE000479"></a>If ***the start and end points*** are not located on the border of the circle (or on the border of the ellipse), the point taken into account corresponds to the intersection between the circle and the line that joins the specified point and the center of the rectangle (which means the center of the circle).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=RBArc2.gif)
The origin considered for calculating the coordinates corresponds to the top left corner of the image (coordinates (0,0)).
<a name="NOTE0_2"></a>


### Drawing a solid figure
<a name="drawing_solid_figure_ELTPARAGRAPHE000490"></a>

To draw a solid figure (a full arc), use [dChord](../WDLang1/3029008.md) or [dSlice](../WDLang1/3029021.md).
<a name="NOTE0_3"></a>


### Using the drawing functions
<a name="using_the_drawing_functions_ELTPARAGRAPHE000509"></a>

The drawing functions can be used according to 2 methods:

- **Method 1: Using the dDrawingStart**function 

	- [dStartDrawing](../WDLang1/3029009.md) must be called before any other drawing function. [dStartDrawing](../WDLang1/3029009.md) is used to define the element (Image control or variable) to which the drawing functions will be applied.

	- When drawing on an Image control: 

		- The drawing functions operate on a copy ("bitmap") of the image. You can use the drawing functions of Windows (via [API](../WDLang1/3014005.md) or [CallDLL32](../WDLang1/3014003.md)) but these functions must use the DC (Device Context) returned by [dStartDrawing](../WDLang1/3029009.md).

		- [dEndDrawing](../WDLang1/3029019.md) and [dStartDrawing](../WDLang1/3029009.md) must not be called in the same process.
						If function [dEndDrawing](../WDLang1/3029019.md) is called in the same process as function [dStartDrawing](../WDLang1/3029009.md), the drawing will not appear: it will be automatically deleted.




- ![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) **Method 2: specify design destination directly in syntax (via parameter)**
	The &lt;Image&gt; parameter is used to specify directly the target of the drawing. [dStartDrawing](../WDLang1/3029009.md) becomes useless. This function must be deleted.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000575"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.


**Limitation for function dArc**: Opacity defined with function [dBackground](../WDLang1/3029002.md) is not taken into account.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000756"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
