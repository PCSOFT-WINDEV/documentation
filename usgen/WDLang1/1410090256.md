


## CodeEditorDeleteAll (Function)

***In french: EditeurCodeSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the contents of the Code Editor control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Clears the Code Editor control
CodeEditorDeleteAll(CODEEDT_Example)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`CodeEditorDeleteAll(<Code Editor control>)`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
