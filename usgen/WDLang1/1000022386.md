


## Camera/Video functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>



|   |   |
| --- | --- |
| [&lt;Camera&gt;.Capture](../WDLang1/1000022382.md) | Captures the images received from the camera:<br><br>- as an image: take a photo.<br><br>- as a video: record a video.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [&lt;Camera&gt;.Configure](../WDLang1/1000022379.md) | Allows you to configure the video capture driver. |
| [&lt;Camera&gt;.Display](../WDLang1/1000022380.md) | Displays in a Camera field the camera preview stream currently being transmitted by a web camera or by the mobile device camera.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [&lt;Camera&gt;.SetDriver](../WDLang1/1000022378.md) | Connects the "Camera" control to a specific driver for video capture. |
| [&lt;Camera&gt;.StartDecoding](../WDLang1/1000022475.md) | Starts decoding bar codes in a Camera control. |
| [&lt;Camera&gt;.Status](../WDLang1/1000022476.md) | Returns the status of a Camera control.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [&lt;Camera&gt;.Stop](../WDLang1/1000022381.md) | Stops the video preview or video recording in a Camera control.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [&lt;Camera&gt;.StopDecoding](../WDLang1/1000022474.md) | Stops decoding a bar code in a Camera control. |
