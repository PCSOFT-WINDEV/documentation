


## TableInsertLine (Function)

***In french: TableInsèreLigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a row into: 

- a Table control,

- a TreeView Table control.




**Remarks**: 

- To add elements at the end of a Table control, use [TableAddLine](../WDLang1/3074006.md).

- To add rows inside a hierarchy (TreeView Table control), use [TableInsertChild](../WDLang1/1000010005.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To insert a row with an animation, use [TableInsertLineWithAnimation](../WDLang1/1000022401.md).











<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Insert the "Vince" and "Moore" elements into the fifth
// row of the "TABLE_CustomerTable" control
TableInsertLine(TABLE_CustomerTable, 5, "Vince", "Moore")
```

```wl
// Insert a row below the selected row
TableInsertLine(TABLE_Contact, TABLE_Contact + 1, "New contact")
TableSelectPlus(TABLE_Contact, TABLE_Contact + 1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableInsertLine(<Table control> [, <Subscript> [, <Element column 1> [... [, <Element column N>]]]])`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control.


If this parameter corresponds to an empty string (""), the control to which the current event belongs will be used.

**`<Subscript>: (Optional integer)`**

Index of the row into which the elements will be inserted. The index of the first row is set to 1.


|   |   |
| --- | --- |
| Index not specified | The row will be inserted before the current row. If no row is selected, the row is inserted at the bottom of the control. |
| Index greater than the number of control rows | The row is inserted at the bottom of the control. |
| Index equal to 0 | The row is inserted at the beginning of the control. |
| Index equal to -1 | The row will be inserted before the current row. |



**`<Element column 1>: (Type of associated column (optional))`**

First row elements that will be inserted into the specified control. Each element corresponds to a column of the control. The type of inserted element must be compatible with the type of relevant column.
If none of these parameters is specified, an empty row is added to the control. For a data-bound control, the default values defined in the linked table are taken into account.



**`<Element column N>: (Type of associated column (optional))`**

Nth row elements that will be inserted into the specified control. Each element corresponds to a column of the control. The type of inserted element must be compatible with the type of relevant column.
If none of these parameters is specified, an empty row is added to the control. For a data-bound control, the default values defined in the linked table are taken into account.

## Remarks
**TableInsertLine** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **TableInsertLine** cannot be used on data-bound Table controls.
<a name="NOTE0_2"></a>


### Characteristics of the row elements
<a name="characteristics_the_row_elements_ELTPARAGRAPHE000161"></a>

- To specify no value for one of the elements, use an empty string ("") or 0 (depending on the type of column).

- If an element corresponds to the result of a calculation, enclose the numerical expression in brackets. For example:
	
	```wl
	TableInsertLine(TABLE_CalcTable, 3, (53+29), (83-21))
	```




<a name="NOTE0_3"></a>


### Position of inserted row
<a name="position_inserted_row_ELTPARAGRAPHE000409"></a>

By default, the row is inserted at the specified position.

Special cases: 

- If the control is sorted with [TableSort](../WDLang1/3074035.md), the new row is positioned according to the current sort and not the specified index.

- If the control is sorted by the user, the sort is ignored when inserting the row. The row is inserted at the specified position.



<a name="NOTE0_4"></a>


### Limits: Maximum number of lines displayed
<a name="limits_maximum_number_lines_displayed_ELTPARAGRAPHE000427"></a>

The maximum number of rows that can be displayed in a TreeView Table control or hierarchical Table is limited only by available RAM (theoretical maximum: 2 billion rows). 

However, we do not advise you to use large Table or TreeView Table controls for performance and user-friendliness reasons (time required to fill the control for example).

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000441"></a>

**If the cascading input is enabled**, the content of table linked to the control is automatically modified when the user goes to the next row.

**If the cascading input is not enabled**, the content of table linked to the control is not modified. To write the content of the inserted row into the table, [TableSave](../WDLang1/3074008.md) must be called after **TableInsertLine**. 

**Remarks**: 

- The "Cascading input (Add)" option can be selected in the "Details" tab of the control description.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available for Table controls populated programmatically and with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available for "Server + AJAX" data-bound Table controls based on a table.

### Table field/Hierarchical table file: Insert several lines
<a name="table_fieldhierarchical_table_file_insert_several_lines_ELTPARAGRAPHE000476"></a>

A virtual row is created each time **TableInsertLine** is called in a Table or TreeView data-bound Table control. The information will be saved in the table during the call to [TableSave](../WDLang1/3074008.md).

If **TableInsertLine** is successively called in the same process without being followed by [TableSave](../WDLang1/3074008.md), only the FIRST call is effective (the following calls are ignored). Only one row is added to the Table or TreeView Table control.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This operating mode is only available for "Server + AJAX" Table controls based on a table.

### Editable Table or TreeView Table control
<a name="editable_table_treeview_table_control_ELTPARAGRAPHE000503"></a>

If **TableInsertLine** is called:

- In a control event, the cursor is automatically positioned on the first column to edit in the inserted row.

- In an event that does not belong to the control (or in another process), [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) must be used to resume the input in the Table or TreeView Table control.



<a name="NOTE0_8"></a>


### Inserting an image
<a name="inserting_image_ELTPARAGRAPHE000213"></a>

To insert an image into a Table or TreeView Table control: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) specify the name and full path of image to insert.
	For example:
	
	```wl
	TableInsertLine(TABLE_MyTable, 5, "C:\MyDocuments\MyImage.BMP")
	```


- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) specify the path and name of image to insert. The path is relative to the "&lt;Project_Name&gt;_WEB" directory.
	For example:
	
	```wl
	// Adds the image found in the "WB_MyApp_WEB" directory
	TableInsertLine(TABLE_MyTable, "MyImage.BMP")
	```



**Note** To display the inserted image correctly, the column must be of type Image.
