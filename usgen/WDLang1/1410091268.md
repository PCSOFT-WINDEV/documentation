
## JSON: Handling large (multi-gigabyte) files
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000098"></a>
WINDEV, WEBDEV and WINDEV Mobile 2025 and later feature a JSON parser for handling large (multi-gigabyte) JSON files. Some examples include data from Open Street Map or Open Data France.

Reading speed and memory consumption are significantly improved on large JSON files. The file is not loaded into memory, it is simply read.

<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000122"></a>


### Method
<a name="method_ELTPARAGRAPHE000022"></a>

To read a large JSON file:

1. Open the JSON file to be read with [JSONOpenReader](../WDLang1/1410090784.md). This function is used initialize a variable of type [jsonReader](../WDLang1/1410090783.md). 
	For example: 
	
	```wl
	Reader is jsonReader = JSONOpenReader("MyFile.json")
	```


2. Loop through the JSON file using one of the [FOR EACH](../Motscles/1510029.md) syntaxes.

3. The properties of [jsonReader](../WDLang1/1410090783.md) variable are used to find the characteristics of element read. 





### Examples
<a name="examples_ELTPARAGRAPHE000047"></a>

Below is a JSON file example and various iteration modes, with a list of the elements that are iterated over. 

JSON file processed: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gros_Json.JPG&type=thumb)



```wl
// Loop through a level
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH Reader
	// Read root array on row 1
	FOR EACH Reader
		// Read objects on rows 2 and 21
		FOR EACH Reader
			// Read members on rows 3 to 5, 22 to 24
			FOR EACH Reader
				// Read objects on rows 7, 13, 26 and 32
				FOR EACH Reader
					// Read members on rows 8 to 11, 14 to 17, 27 to 30 and 33 to 36
				END
			END
		END
	END
END
```



```wl
// Loop through a level with copy
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH customer_array OF Reader
	// Read root array on row 1
	FOR EACH customer OF customer_array
		// Read objects on rows 2 and 21
		FOR EACH customer_property OF customer
			// Read members on rows 3, 4, 5, 22, 23 and 24
			IF customer_property.Name = "addresses" THEN
				FOR EACH address OF customer_property
					// Read objects on rows 7, 13, 26 and 32
					FOR EACH property_address OF address
						// Read members on rows 8 to 11, 14 to 17, 27 to 30 and 33 to 36
					END
				END
			END
		END
	END
END
```



```wl
// In-depth loop
// Reader is the variable corresponding to the JSON file
Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH Reader IN-DEPTH
	// Read all elements on rows 1, 2, 3 to 5, 7, 8 to 11, 13, 14 to 17, 
	// 21, 22 to 24, 26, 27 to 30, 32 and 33 to 36 
END
```
