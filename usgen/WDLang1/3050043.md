
## MatStack (Function)

***In french: MatCompresse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Compresses the memory footprint occupied by a matrix.

**Note** Compression is necessary if you are handling a large matrix on which many calculations have been performed. If the matrix contains several null columns and/or rows, compression can significantly reduce the matrix memory size.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003050043&name=matstack_function">See additional examples</a>

```wl
// Compress a matrix
MatStack("MyMatrix")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MatStack(<Matrix>)`
---

**`<Matrix>: (Character string)`**

Name of matrix to compress, defined by [MatCreate](../WDLang1/3050058.md).

## Remarks




### Existence of matrix to compress
<a name="existence_matrix_compress_ELTPARAGRAPHE000065"></a>

The matrix existence is not checked. To check the matrix existence, use [MatExist](../WDLang1/3050076.md).
<a name="NOTE0_2"></a>




### Error management
<a name="error_management_ELTPARAGRAPHE000076"></a>

**Caution**: The **MatStack** function does not return a result.. To find out whether errors have been generated by the compression, use [MatError](../WDLang1/3050044.md) on this matrix. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
