


## SaveParameter (Function)

***In french: SauveParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves a persistent value: 

- in the registry or the equivalent file on the runtime platform.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) In Android, the persistent values are saved in the Shared Preferences of the application.

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) In iOS, the persistent values are stored in the parameters of the application ("NSUserDefault"). 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a WEBDEV website, persistent values are stored in a browser cookie. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) In a Linux application, persistent values are saved in the $HOME/.local/share folder.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) in the file specified by [InitParameter](../WDLang1/3025044.md).




This value can be read by [LoadParameter](../WDLang1/3025047.md) the next time the application is started.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Save
SaveParameter("LOGIN", EDT_Edit1)

// Restore
EDT_Edit1 = LoadParameter("LOGIN")
```

## Syntax

`SaveParameter(<Parameter name> , <Parameter value>)`
---

**`<Parameter name>: (Character string)`**

Name of the parameter to be saved. This parameter must not correspond to an empty string.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) A full path can be specified if this parameter was saved in the registry. The accepted separators are ".","/" and "\\". The [FullName](../Proprietes/2514005.md) property returns the full path of a control. For more details, see [the remarks](#NOTE0_1).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the selected initialization mode is the registry, **SaveParameter** is case and accent-insensitive (e.g. "Parameter" and "parameter" are equivalent).

**`<Parameter value>: (Character string or integer)`**

Value to save.

## Remarks


### Name of the parameter in a registry
<a name="name_the_parameter_registry_ELTPARAGRAPHE000119"></a>

- **Case 1: Parameter name is "Param1 "**: 
	This parameter is saved in the registry by using the following path:
	HKEY_CURRENT_USER\\Software\\&lt;Company&gt;\\&lt;Application&gt;\\Param1

- **Case 2: parameter name is "FEN_Window1\\SAI_Entry2\\Param1 "**: 
	This parameter is saved in the registry by using the following path:
	HKEY_CURRENT_USER\\Software\\&lt;Company&gt;\\&lt;Application&gt;\\WIN_Window1\\EDT_Edit2\\Param1

- **Case 3: parameter name is "FEN_Fenêtre1.SAI_Saisie2.Param1 "**: 
	This parameter is saved in the registry by using the following path:
	HKEY_CURRENT_USER\\Software\\&lt;Company&gt;\\&lt;Application&gt;\\WIN_Window1\\EDT_Edit2\\Param1




**Reminder** To find out the path to the registry where application information is stored, use the [ProjectInfo](../WDLang1/3064004.md) function with the constant *piRegistre*.

&lt;Company&gt; corresponds to the company specified when creating the executable. If this name is not specified, &lt;Company&gt; corresponds to "WINDEV applications".

**Note**: In Test mode, the path used in the registry is as follows: HKEY_CURRENT_USER\\SOFTWARE\\PC SOFT\\WinDev\\31.0\\TestMode\\&lt;project&gt;.
