
## SysValidHandle (Function)

***In french: SysHandleValide***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the validity of a window handle.

**Remark**: A handle is no longer valid if, for example, the corresponding window has been closed.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Validité du handle de la fenêtre "Microsoft Word - Ventes 2000.DOC"
ResHandle = SysFenHandle("Microsoft Word - Ventes 2000.DOC")
ResHandleValide = SysHandleValide(ResHandle)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysValidHandle(<Window handle>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified handle is valid, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Window handle>: (Integer)`**

Handle of the window to test.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Window handle
<a name="window_handle_ELTPARAGRAPHE000042"></a>

The window handle is returned:

- by [Handle](../WDLang1/3015005.md) for a WINDEV window.

- by [SysWinHandle](../WDLang1/3073007.md) for a window not created with WINDEV.
