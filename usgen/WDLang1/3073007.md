
## SysWinHandle (Function)

***In french: SysFenHandle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the handle of a window identified by its title. This window was not created by WINDEV.

**Note**: To find out the handle number of a WINDEV window, use the [Handle](../WDLang1/3015005.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connaître le numéro de handle de la fenêtre "Ventes 2011 - Microsoft Word.DOC"
ResHandleFen est un entier
ResHandleFen = SysFenHandle("Ventes 2011 - Microsoft Word.DOC")
SI ResHandleFen = Null ALORS Trace("Fenêtre non trouvée")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysWinHandle(<Window title>)`
---

**`<Result>: (Integer)`**



- Handle of the specified window. 

- Null constant or 0 if the window was not found.




**`<Window title>: (Character string)`**

Title of the window to use. This parameter must be identical to the title displayed in the title bar of the window.

<a name="NOTE0_1"></a>

## Remarks


### Window handle
<a name="window_handle_ELTPARAGRAPHE000038"></a>

[SysWinShow](../WDLang1/3073003.md), [SysWinTitle](../WDLang1/3073008.md) and [SysValidHandle](../WDLang1/3073009.md) use the handle of the windows that were not created by WINDEV.

To manipulate windows created with WINDEV, it's best to use the following specific functions: [Restore](../WDLang1/3038042.md), [Maximize](../WDLang1/3038001.md), [WinStatus](../WDLang1/3038030.md), [Iconize](../WDLang1/3038015.md), ...
