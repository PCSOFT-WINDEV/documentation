


## &lt;Window&gt;.OutWidth (Function)

***In french: &lt;Fenêtre&gt;.ExtLarg***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the full width of a window.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the Windows operating system: The total width of a window includes the border.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The total width of a mobile window corresponds to the width of the window. 
In the case of maximized mobile windows, the width is the same as the one returned by [&lt;Window&gt;.InWidth](../WDLang1/1410090626.md).  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt_Mobile.gif)
**Remark**: The **&lt;Window&gt;.OutWidth** function is equivalent to the [Width](../Proprietes/2510059.md) property (&lt;Window&gt;.Width).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Width of the "WIN_EditCustomer" window
ResWidth = WIN_EditCustomer.OutWidth()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Window used>.OutWidth()`
---

**`<Result>: (Integer)`**

Width of the window (in pixels).

**`<Window used>: (Window name)`**

Name or alias of the window to be used. If this parameter is not specified or if it corresponds to an empty string (""), the width of the current window is returned.

### Difference between the result of &lt;Window&gt;.OutWidth and the resolution
<a name="difference_between_the_result_docparampagetitleshort_and_the_resolution_ELTPARAGRAPHE000202"></a>

The result of **&lt;Window&gt;.OutWidth** used on a maximized window may be 8 pixels more that the resolution because **&lt;Window&gt;.OutWidth** takes into account the "Border" of the window outside the screen (4 pixels on each side).

Therefore, for a resolution of 1280x1024, **&lt;Window&gt;.OutWidth** and [&lt;Window&gt;.OutHeight](../WDLang1/1410088867.md) return 1288x1032.
