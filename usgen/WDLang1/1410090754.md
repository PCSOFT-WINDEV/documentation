


## &lt;Command variable&gt;.GetExitCode (Function)

***In french: &lt;Variable Commande&gt;.RécupèreCodeRetour***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the exit code of the command executed in console mode, i.e. the value returned when the command finishes executing.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'

// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)
// Write to standard input (possible because the stream is open)
MyCommandToExecute.WriteStandardInput("Write test" + CR)
// Get return code of the command (value received when the command finishes executing)
code is int = MyCommandToExecute.GetExitCode(True)
// Read from standard output (possible because the stream is open)
stdout is string = MyCommandToExecute.ReadStandardOutput()
// Read from error output (not possible because the stream is not open)
// Error message: 'STDERR' is not open.
stderr is string = MyCommandToExecute.ReadErrorOutput()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Exit code> = <Command>.GetExitCode([<Blocking>])`
---

**`<Exit code>: (Integer)`**

Exit code of the command executed in console mode. This exit code is the value returned by the program. 
Note: Generally, a program that terminates successfully returns 0, and returns another value in case of error. This is by no means a rule.

**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command executed in console mode.

**`<Blocking>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default) to read data only after the command has been executed. 

- <u><u><u><u>False</u></u></u></u> to read data even if the command is still being executed. If the command has not finished executing, an error will be displayed.
