


## SysIsAdministrator (Function)

***In french: SysEstAdministrateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether the current user has administrator rights on the computer.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF SysIsAdministrator() = True THEN
	Info("You have administrator rights on the computer.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SysIsAdministrator()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the current user has administrator rights on the computer,

- <u><u><u><u>False</u></u></u></u> otherwise.
