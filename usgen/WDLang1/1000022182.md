


## &lt;Pivot Table&gt;.Expand (Function)

***In french: &lt;Tableau croisé dynamique&gt;.Déroule***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Expands all the data in a Pivot Table control according to a row or column header. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Expands all quarters
PVT_Sales.Expand(COL_OrderDate_Quarter)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Pivot Table control>.Expand(<Header to expand>)`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Header to expand>: (Character string)`**

Name of the row header or column header to expand.
