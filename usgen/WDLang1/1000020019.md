
## TimePicker (Function)

***In french: HeureSélecteur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the system time picker.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=HeureSelecteur.gif)


**Note**: To select a time via the time picker, we recommend that you use the **"Time Picker" input mask** for the "Time" Edit control. This input mask is also available for iPhone/iPad applications. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
h is Time = TimePicker()
```



```wl
StartTime is Time = "0730"
TimeSelected is Time = TimePicker(StartTime, True, "Enter the end time")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = TimePicker([<Initial time> [, <24-hour mode> [, <Title>]]])`
---

**`<Result>: (Time or character string)`**



- Time selected in the picker, 

- Empty string ("") if the selection was canceled by the user.




**`<Initial time>: (Time or optional character string)`**

Time displayed when the picker is opened. If this time is not specified, the picker will display the current time.

**`<24-hour mode>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default) to display the time in 24-hour format.

- <u><u><u><u>False</u></u></u></u> to display the time in AM/PM format. 




**`<Title>: (Optional character string)`**

Title that must be displayed in the picker. If this parameter is not specified, the title will be the time displayed in the picker in text format.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000186"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**TimePicker** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
