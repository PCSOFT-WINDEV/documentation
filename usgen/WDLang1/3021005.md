


## YesNo (Function)

***In french: OuiNon***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a message in a standard dialog box that proposes "Yes" and "No" and returns the user's choice.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=fonctions_dialogue%20-%20HC%20N%B0007.gif)


Remarks: 

- **This is a blocking dialog box**. To continue running the application, the user must validate one of the buttons. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To avoid blocking the application, use [YesNoAsynchronous](../WDLang1/1000025272.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV allows you to apply the theme of your project to this dialog box. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Exit choice
IF YesNo("Do you want to exit the program?") = Yes THEN 
	Close()
END
```

```wl
// Prerequisites: The WebDevYesNo internal window must have been created
YesNo(Yes,YesCode, NoCode, "Question?")
```

```wl
// "Yes" procedure
PROCEDURE YesCode()
Trace("You clicked Yes")
RETURN True
```

```wl
// "No" procedure
PROCEDURE NoCode()
Trace("You clicked No")
RETURN True
```

### Displaying a Yes/No dialog box

`<Result> = YesNo([<Selected button>, ] <Text> [, <Line 2> [... [, <Line N>]]])`
---

**`<Result>: (Integer constant)`**

Identifies the button selected by the user:


|   |   |
| --- | --- |
| *No* (or 0) | The user selected [NO]<br>or closed the dialog box via the 'X' icon. |
| *Yes* (or 1) | The user selected [YES] |



**`<Selected button>: (Optional integer constant)`**

Button selected by default in the dialog box:


|   |   |
| --- | --- |
| *No* (or 0) | The "No" button is selected by default. |
| *Yes* (or 1)<br>(Default value) | The "Yes" button is selected by default. |



**`<Text>: (Character string)`**

Text to display.

**`<Line 2>: (Optional character string)`**

Text displayed on the second line.



**`<Line N>: (Optional character string)`**

Text displayed on the Nth line.

### Displaying a Yes/No dialog box on the browser (WebDeVYesNo)

`YesNo([<Selected button>, ] <Code for Yes> , <Code for No> , <Text> [, <Line 2> [... [, <Line N>]]])`
---

**`<Selected button>: (Optional integer constant)`**

Button selected by default in the dialog box:


|   |   |
| --- | --- |
| *No* (or 0) | [NO] button selected by default |
| *Yes* (or 1)<br>(Default value) | [YES] button selected by default |



**`<Code for Yes>: (Character string)`**

Code to run if the Yes button is chosen by the Web user. This parameter can correspond to:

- the name of a button. If the Yes button is selected, the click code of this button will be run.

- the name of a browser function or procedure. If the Yes button is selected, this procedure will be run.

- a string or another value. If the Yes button is selected, the value will be run as being a JavaScript code.




**`<Code for No>: (Character string)`**

Code to run if the No button is chosen by the Web user. This parameter can correspond to:

- the name of a button. If the No button is selected, the click code of this button will be run.

- the name of a browser function or procedure. If the No button is selected, this procedure will be run.

- a string or another value. If the No button is selected, the value will be run as being a JavaScript code.




**`<Text>: (Character string)`**

Text to display.

**`<Line 2>: (Optional character string)`**

Text displayed on the second line.



**`<Line N>: (Optional character string)`**

Text displayed on the Nth line.

## Remarks


### Features of the dialog box
<a name="features_the_dialog_box_ELTPARAGRAPHE000168"></a>



- The title of the dialog box corresponds to the title of the current window (or page).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To comply with the system specifications, the title of dialog box is empty by default. To define this title, use [NextTitle](../WDLang1/3038043.md).

- To modify or define the title of dialog box, use [NextTitle](../WDLang1/3038043.md).




- The message is aligned to the left.

- The captions of buttons depend on the runtime language of Windows.

- The maximum number of characters cannot exceed 4096. If a larger string is passed as parameter, it will be truncated.

- The icon displayed (exclamation mark) cannot be modified.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To customize this dialog box** (and all the system dialog boxes in your application), check "Customize system windows (Info, YesNo, Confirm, Dialog)" in the "Style" tab of the project description. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **To customize this dialog box** (and all the system dialog boxes in your site), check "Apply the theme to the dialog boxes (YesNo and OKCancel)" in the "Theme" tab of the project description window. 
<a name="NOTE0_2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Displaying the dialog box
<a name="displaying_the_dialog_box_ELTPARAGRAPHE000198"></a>

The dialog box does not lock other processes. The dialog box is displayed in the center of the page, with a DDW effect (Dim Disabled Windows).

**YesNo** uses the "WebDeVYesNo" internal page. To include this page in your project:

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_nouveau.gif) in the quick access buttons. 

2. The window for creating a new element is displayed: click "Page" then "Page".

3. On the "Internal Page" tab, select the internal page named "Yes/No".

4. Validate. The "WebDeVYesNo" page appears in the editor.

5. Save the page by keeping its default name.




Limitation: **YesNo** must not be used in Browser code in a page that uses "Slices (legacy Responsive mode". 
<a name="NOTE0_3"></a>


### Line break in the dialog box
<a name="line_break_the_dialog_box_ELTPARAGRAPHE000221"></a>The CR string (Carriage Return) can be used to force a break to the next line. For example:


```wl
YesNo("The XXX form was modified." + CR + ...
	"Do you want to save it before exiting?")
```


is equivalent to:


```wl
YesNo("The XXX form was modified.", ...
	"Do you want to save it before exiting?")
```


You also have the ability to use the syntax of multiline strings. For example: 


```wl
YesNo(
[
The XXX form has been modified.

Do you want to save changes before closing?
])
```

### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000240"></a>

- Timers ([TimerSys](../WDLang1/3015006.md)) are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Windows events are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [DelayBeforeClosing](../WDLang1/3038040.md) limits how long the message is displayed. The dialog box is automatically closed. For question or confirmation dialog boxes, the default button corresponds to the expected answer.

- The text of the buttons is displayed in the system language.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The first syntax is not available in Active WEBDEV Pages. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) If your project uses pre-launched sessions, this function must not be used in the project initialization event. This function must be used in the "Initialization in pre-launched session mode" event. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function must not be used: 

	- in the "Resize" event of the window. Otherwise, the application will be locked.

	- in the "Change the orientation" event of the window. 

	- in the "Move to the foreground" event associated with the project. 
			 Note: However, the function can be used in the "Move to the foreground" event of a window. 

	- in a thread. 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The position of the buttons varies according to the Android version. From Android 4.1, the system sets the validation button on the right. [Dialog](../WDLang1/3021015.md) is used to define the position of the buttons, if necessary.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000477"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**YesNo** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
