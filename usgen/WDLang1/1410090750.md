


## &lt;Command variable&gt;.WriteStandardInput (Function)

***In french: &lt;Variable Commande&gt;.EcritEntréeStandard***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Writes data to the standard input of the command executed in console mode.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'

// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)
// Write to standard input (possible because the stream is open)
MyCommandToExecute.WriteStandardInput("Write test" + CR)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Command>.WriteStandardInput(<Data>)`
---

**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command to be manipulated.

**`<Data>: (Character string)`**

Data to be sent to the command. 

Caution: The input stream must be open in the [Command](../WDLang1/1410090491.md) variable (**Streams** property).
