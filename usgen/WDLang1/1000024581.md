


## &lt;picLayer variable&gt;.DrawRectangleGradient (Function)

***In french: &lt;Variable picCalque&gt;.DessineRectangleDégradé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a rectangle in a variable of type [picLayer](../WDLang1/1000024604.md).

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
MyLayer is picLayer

// Draw a rectangle whose background changes from red to blue
// via yellow
MyLayer.DrawRectangleGradient(10, 20, 100, 150, LightRed, LightBlue, 0, LightYellow, 30)
IMG_MyDrawing = MyWDPicImage
```

## Syntax

### Drawing a rectangle by specifying the points of the rectangle and the gradient

`<picLayer image>.DrawRectangleGradient(<X1> , <Y1> , <X2> , <Y2> , <Start color> , <End color> [, <Angle> [, <Color 3> [, <Distance color 3> [, <Color 4> [, <Distance color 4>]]]]])`
---

**`<picLayer image>: (picLayer variable)`**

Name of the [picLayer](../WDLang1/1000024604.md) variable to be used.

**`<X1>: (Integer)`**

X-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<Y1>: (Integer)`**

Y-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<X2>: (Integer)`**

X-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Y2>: (Integer)`**

Y-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Start color>: (Integer or constant)`**

Start color of the gradient. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).




**`<End color>: (Integer or constant)`**

End color of the gradient. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).




**`<Angle>: (Optional integer)`**

Angle that will be used for the selection of colors in the gradient. The angle value is included between 0 (horizontal angle, default value) and 360°.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only the following angles can be used: 0,90,180,270,360.

**`<Color 3>: (Optional constant or integer)`**

Color that will be used in the gradient. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available.

**`<Distance color 3>: (Optional integer)`**

Percentage separating the start color from color 3.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available.

**`<Color 4>: (Optional constant or integer)`**

Color that will be used in the gradient. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available.

**`<Distance color 4>: (Optional integer)`**

Percentage separating the start color from color 4.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available.

## Remarks


### Gradient parameters
<a name="gradient_parameters_ELTPARAGRAPHE000813"></a>The color parameters are used as follows:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=drectangledegrade.gif)
The angle is used to define the orientation of the gradient.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=angle_degrade.gif)
The gradients performed with 3 or 4 colors are only available for an angle set to 0 or 90 degrees.

**Note** Gradients are not available on certain systems (e.g. Windows 98 or Me) or under TSE 256 colors. In this case, a rectangle whose color corresponds to &lt;Start color&gt; is displayed.
<a name="NOTE0_2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000835"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
