


## &lt;Window&gt;.EdDeselectAll (Function)

***In french: &lt;Fenêtre&gt;.EdDésélectionneTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deselects all the controls when the interface is modified by the end user ("Allow end users to modify the UI" option enabled).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enables editing in the window 
WIN_Form.EdActive(True)
WIN_Form.EdDeselectAll(True)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Window>.EdDeselectAll()`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. This window must be in edit mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)).
