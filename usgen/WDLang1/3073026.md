
## SysDir (Function)

***In french: SysRep***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the path of a system directory.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns the path of a system directory on the server.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In this version, this function can only be used to return the system directory.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png)

## Syntax

---

**`<Result>: (Character string)`**

Full path of specified directory.

## Remarks


### Temporary directory
<a name="temporary_directory_ELTPARAGRAPHE000523"></a>

To get the temporary directory for the current user, use [fTempPath](../WDLang1/3036044.md).
<a name="NOTE0_2"></a>


### Bin
<a name="bin_ELTPARAGRAPHE000533"></a>

The "Bin" corresponds to a virtual directory managed by Windows. Therefore, **SysDir** cannot be used to find out the path of "Bin".
