
## LoadParameter (Function)

***In french: ChargeParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads a persistent value. The persistent value was saved by [SaveParameter](../WDLang1/3025046.md): 

- in the registry (or equivalent file on the runtime platform). For example: 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) In Android, the persistent values are saved in the Shared Preferences of the application. 

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) In iOS, the persistent values are stored in the parameters of the application ("NSUserDefault"). 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a WEBDEV website, persistent values are stored in a browser cookie. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) In a Linux application, parameters are saved in the $HOME/.local/share folder.




- ![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) in the file specified by [InitParameter](../WDLang1/3025044.md).

<a name="sample_code"></a>

## Example


```wl
// Save
SaveParameter("LOGIN", EDT_Edit1)
// Restore
EDT_Edit1 = LoadParameter("LOGIN", "")
```

## Syntax

`<Result> = LoadParameter(<Parameter name> [, <Default value>])`
---

**`<Result>: (Character string or integer)`**



- Value of the search parameter. 

- If the search parameter is not found, corresponds to &lt;Default value&gt; or to an empty string ("") if no default value was specified.




**`<Parameter name>: (Character string)`**

Name of the parameter to be found. This parameter must not correspond to an empty string.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the selected initialization mode is the registry, **LoadParameter** is case and accent-insensitive (Parameter and parameter are equivalent).

**`<Default value>: (Optional character string or optional integer)`**

Default value of the parameter. This value will be returned if the value of the parameter is not found.
