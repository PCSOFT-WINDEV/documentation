


## &lt;Table&gt;.SelectToFile (Function)

***In french: &lt;Table&gt;.SelectVersFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Positions on the table record corresponding to a row selected in the multi-selection data-bound Table control.

**Note**: In a single-selection Table control, the current record in the table always corresponds to the item selected in the Table control.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
i is int
FOR i = 1 TO TABLE_Product.SelectCount()
	TABLE_Product.SelectToFile(i)
	Trace(Product.ProductID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Table control>.SelectToFile(<Rank>)`
---

**`<Table control>: (Control name)`**

Name of the data-bound Table control to be used. 
A WLanguage error occurs if this parameter does not correspond to a data-bound Table control.

**`<Rank>: (Integer)`**

Rank of the selection. A WLanguage error occurs if this parameter does not correspond to an existing rank.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
This function can be used with a single-selection data-bound Table control if and only if &lt;Rank&gt; is equal to 1
