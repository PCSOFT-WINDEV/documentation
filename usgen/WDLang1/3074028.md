


## TableModifyLine (Function)

***In french: TableModifieLigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies a row in: 

- a Table control,

- a TreeView Table control. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the "Paul" and "Moore" elements 
// in the 5th row of "TABLE_CustomerTable" control
TableModifyLine(TABLE_CustomerTable, 5, "Paul", "Moore")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableModifyLine(<Table control> , <Index> [, <Element column 1> [... [, <Element column N>]]])`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control.


If this parameter corresponds to an empty string (""), the control to which the current event belongs will be used.

**`<Index>: (Integer)`**

Index of the row to be modified. The index of the first row is set to 1.


|   |   |
| --- | --- |
| Index equal to -1 | The current row is modified. No effect if no row is selected. |
| Index greater than the number of control rows | A WLanguage error occurs. |



**`<Element column 1>: (Optional character string)`**

First element of the modified row. The value of this element replaces the existing value. Each element corresponds to a column. Each type of modified element must be compatible with the type of relevant column.
If none of the &lt;Element column X&gt; parameters are specified, **TableModifyLine** has no effect.



**`<Element column N>: (Optional character string)`**

Nth element of the modified row. The value of this element replaces the existing value. Each element corresponds to a column. Each type of modified element must be compatible with the type of relevant column.
If none of the &lt;Element column X&gt; parameters are specified, **TableModifyLine** has no effect.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000120"></a>

**TableModifyLine** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **TableModifyLine** cannot be used on data-bound Table controls.
<a name="NOTE0_2"></a>


### Characteristics of the row elements
<a name="characteristics_the_row_elements_ELTPARAGRAPHE000161"></a>

- To modify the value of an element in a row, use the following syntax: 
	
	```txt
	TableControl.ColumnName[RowIndex] = NewValue
	```


- If an element corresponds to the result of a calculation, enclose the numerical expression in brackets. 
	For example:
	
	```wl
	TableModifyLine(TABLE_CalcTable, (53+29),(83-21))
	```

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000184"></a>

- **If the cascading input is enabled**, the table linked to the control is automatically modified when the user goes to the next row.

- **If the cascading input is not enabled**, the table linked to the control is not modified. To write the content of the modified row to the linked table, [TableSave](../WDLang1/3074008.md) must be used after **TableModifyLine**.




**Remarks**: 

- The "Cascading input" option can be selected in the "Details" tab of the control description.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available on Table controls populated programmatically or with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available on Table control Ajax file fields. 



<a name="NOTE0_4"></a>


### Changes in a Table or TreeView data-bound Table control based on a table
<a name="changes_table_treeview_databound_table_control_based_table_ELTPARAGRAPHE000211"></a>

To modify a row in a Table or TreeView Table control based on a table, we advise you to:

- modify the record in the table with [HModify](../WDLang4/3044042.md),

- use [TableDisplay](../WDLang1/3074003.md) to refresh the control.

### TableModifyLine function and Modified property
<a name="docparampagetitleshort_function_and_modified_property_ELTPARAGRAPHE000231"></a>

**TableModifyLine** has no influence on the [Modified](../Proprietes/2510080.md) property. The [Modified](../Proprietes/2510080.md) property is used to know if the current row has been directly modified by the user (direct input in the control).
