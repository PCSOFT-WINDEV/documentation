
## dbgLogStatus (Function)

***In french: dbgEtatLog***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns and modifies the status of runtime log.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Starts the runtime log
dbgEnableLog()
...
// Pauses the runtime log
dbgLogStatus(LogPause)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the status of runtime log

`<Result> = dbgLogStatus()`
---

**`<Result>: (Integer constant)`**

Current status of runtime log:


|   |   |
| --- | --- |
| *LogDisabled* | The runtime log is not enabled.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *LogEnabled* | The runtime log is enabled. |
| *LogPause* | The runtime log is paused. |




<a name="SYNTAXE2"></a>

### Modifying the status of runtime log

`<Former status> = dbgLogStatus(<New status>)`
---

**`<Former status>: (Integer constant)`**

Activity status of the runtime log before the changes made by **dbgLogStatus**.


|   |   |
| --- | --- |
| *LogDisabled* | The runtime log is not enabled.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *LogEnabled* | The runtime log is enabled. |
| *LogPause* | The runtime log is paused. |



**`<New status>: (Integer constant)`**

New status of runtime log:


|   |   |
| --- | --- |
| *LogDisabled* | Permanently stops the runtime log. To re-enable it, you will have to use [dbgEnableLog](../WDLang1/1000017137.md).<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *LogEnabled* | Enables the runtime log (after a pause). |
| *LogPause* | Temporarily stops the runtime log. |
