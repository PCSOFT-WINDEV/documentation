


## Segmented Button functions (prefix syntax)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate Segmented Button controls using prefix syntax:



|   |   |
| --- | --- |
| [&lt;Segmented Button&gt;.Add](../WDLang1/1410090903.md) | Adds a new option (i.e. a new button) to a Segmented Button control. |
| [&lt;Segmented Button&gt;.Delete](../WDLang1/1410090905.md) | Deletes an option from a Segmented Button control. |
| [&lt;Segmented Button&gt;.DeleteAll](../WDLang1/1410090906.md) | Deletes all the options from a Segmented Button control. |
| [&lt;Segmented Button&gt;.Insert](../WDLang1/1410090904.md) | Inserts a new option into a Segmented Button control. |
