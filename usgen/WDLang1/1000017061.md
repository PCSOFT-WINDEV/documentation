


## TableToText (Function)

***In french: TableVersTexte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a character string from the data found in a Table or TreeView Table control. This string can be saved in a specific format thereafter.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sText is string
sText = TableToText(TABLE_TABLE1, taNoTitle, ";")
fSaveText("Export.csv", sText)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TableToText(<Table control> [, <Options> [, <Column separator> [, <Row separator> [, <Start row> [, <End row>]]]]])`
---

**`<Result>: (Character string)`**



- Character string containing the data of the Table control. In this string, the columns are separated by &lt;Separator&gt; and the rows are separated by CR characters (Carriage Return). 

- Empty string ("") if an error occurs or if the Table control is empty




**`<Table control>: (Control name)`**

Name of the control to be used. This field may correspond to: 

- a Table control. 

- a TreeView Table control.




**`<Options>: (Optional constant)`**

Configures the information that must be taken into account in the string.


|   |   |
| --- | --- |
| *taColumnDisplayedOrder* | Exports the columns according to the order of columns currently displayed in the control (and not according to the order of columns defined in the editor).<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *taColumnsTitles*<br>(Default value) | The title of the columns is inserted. |
| *taNoTitle* | Only the data is copied. |
| *taNoTotal* | Does not export: <br><br>- the rows containing totals, mean and automatic count (these rows are exported by default).<br><br>- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the rows containing custom calculations (these rows are exported by default).<br><br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *taSelectedLines* | Exports the selected rows only (all the rows are exported by default). |
| *taWithInvisibleColumns* | Also exports the invisible control columns.<br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The columns defined as non printable and non exportable are exported. These columns are defined: <br><br>- or by programming: property [VisibleInExportAndPrint](../Proprietes/1000022320.md) to <u><u><u><u>False</u></u></u></u>. <br><br>- either in the "General" tab of the column description window: option "Export and print" to "Never".<br><br><br> |



**`<Column separator>: (Optional character string)`**

Separator used between the columns. The default separator is the tabulation (TAB).

**`<Row separator>: (Optional character string)`**

Separator used between the rows. The separator used by default is the CR character (Carriage Return).

**`<Start row>: (Optional integer)`**

Number of the row where the export will start. 
If this parameter is not specified, the start row is the first row of the control.

**`<End row>: (Optional integer)`**

Number of the row where the export will end. 
If this parameter is not specified, the end row is the last row of the control.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000127"></a>

**TableToText** can be used on: 

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls. 



<a name="NOTE0_2"></a>


### Limit
<a name="limit_ELTPARAGRAPHE000142"></a>

The merged columns are ignored.
