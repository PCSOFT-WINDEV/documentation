


## AnimationGetParameter (Function)

***In french: AnimationLitParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads the value of one of the animation parameters defined for an Image or Static Text control.



![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In this version, you can only read the value of the animation parameters defined for a Static Text control.

If AnimationGetParameter(IMG_Image1, acpLoop) = True THEN
	AnimationSetParameter(IMG_Image1, acpLoop, False)

IF AnimationGetParameter(STC_CustomerNameSta, acpColor) = Transparent THEN

### Reading the animation parameters of an image (Image control)

`<Result> = AnimationGetParameter(<Image control> , <Parameter name>)`
---

**`<Result>: (Type of expected parameter)`**

Value of sought parameter.

**`<Image control>: (Control name)`**

Name of the Image control to be used.

**`<Parameter name>: (Constant or character string)`**

Name of parameter to read.


|   |   |
| --- | --- |
| *acpDirection* (or "Direction") | Scroll direction. <br>**"Scrolling" animation only.**<br>These parameters can be combined.<br>1 (default): left to right<br>2: right to left<br>4: from bottom to top<br>8: top to bottom<br><br>Example of combination: <br>3 (2+1): left right: gradual widening from the center <br>5 (4+1) from bottom to top and from right to left<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpDirectionAlternate* (or "DirectionAlternate") | Read the image drawings from the first one to the last one, then from the last one to the first one continuously (this parameter is set to <u><u><u><u>False</u></u></u></u> by default). |
| *acpDuration* (or "Duration") | Amount of time for displaying each drawing of the animation in milliseconds (300 ms by default). |
| *acpLoop* (or "Loop") | Read the image drawings from the first one to the last one continuously (this parameter is set to <u><u><u><u>True</u></u></u></u> by default). |
| *acpNbImageX* (or "NumberOfImagesX") | Number of drawings found in the width of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br>**"Image to animate" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpNbImageY* (or "NumberOfImagesY") | Number of drawings found in the height of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br>**"Image to animate" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpNbStep* (or "NumberOfSteps") | 10 by default<br>**"Scrolling" animation only.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *acpReverse* (or "Reverse") | Read the image drawings from the last one (bottom right) to the first one (top left) (this parameter is set to <u><u><u><u>False</u></u></u></u> by default). |

### Reading the animation parameters of a static text (Static Text control)

`<Result> = AnimationGetParameter(<Static Text control> , <Parameter name>)`
---

**`<Result>: (Type of expected parameter)`**

Value of sought parameter.

**`<Static Text control>: (Control name)`**

Name of the Static Text control to be used.

**`<Parameter name>: (Constant or character string)`**

Name of parameter to read.


|   |   |
| --- | --- |
| *acpColor* (or "Color") | Blinking color. This parameter can correspond to a [color constant](../WDLang5/3010002.md). This color corresponds to *Transparent* by default. <br>**"Blinking" animation only.** |
| *acpDirection* (or "Direction") | Scroll direction.<br> **"Scrolling" animation only.**<br>These parameters cannot be combined.<br>1 (default): left to right<br>2: right to left<br>4: from bottom to top<br>8: top to bottom |
| *acpDuration* (or "Duration") | Time for displaying each animation element in milliseconds (300 ms by default) |
| *acpLoop* (or "Loop") | Continuous Dequeue (this setting is <u><u><u><u>True</u></u></u></u> by default).<br>**"Scrolling" animation only.**<br> |
| *acpNbLoopMax* (or "NombreBoucleMax") | Number of loops for continuous dequeue (0 unlimited number of loops). <br>**"Scrolling" animation only.** <br> |
| *acpNbPixel* (or "NumberOfPixels") | Number of pixels for each scrolling step. <br>**"Scrolling" animation only.** |

### Image control: Available parameters and their values
<a name="image_control_available_parameters_and_their_values_ELTPARAGRAPHE000286"></a>

Two types of animations are available for Image controls:

- Image to animate (animation performed by WINDEV or WINDEV Mobile), 

- ![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Scrolling.





|   |   |
| --- | --- |
| **Parameters common to the different animations** |
| Loop | Read the image drawings from the first one to the last one continuously (this parameter is set to <u><u><u><u>True</u></u></u></u> by default). |
| Reverse | Read the image drawings from the last one (bottom right) to the first one (top left) (this parameter is set to <u><u><u><u>False</u></u></u></u> by default). |
| DirectionAlternate | Read the image drawings from the first one to the last one, then from the last one to the first one continuously (this parameter is set to <u><u><u><u>False</u></u></u></u> by default). |
| Duration | Amount of time for displaying each drawing of the animation in milliseconds (300 ms by default). |
| **Parameter specific to the "Image to animate"** |
| NumberOfImagesX | Number of drawings found in the width of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter cannot be defined programmatically. |
| NumberOfImagesY | Number of drawings found in the height of image file. Depending on the specified number, the image will be automatically divided into as many drawings as necessary (1 by default).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter cannot be defined programmatically. |
| **Parameter specific to "Scrolling"** |
| Direction | Scroll direction. These parameters can be combined.<br>1 (default): left to right<br>2: right to left<br>4: from bottom to top<br>8: top to bottom<br><br>Example of combination:<br>3 (2+1): left right: gradual widening from the center<br>5 (4+1) from bottom to top and from right to left |
| NumberOfSteps | 10 by default. |

### Static Text control: available parameters and their values
<a name="static_text_control_available_parameters_and_their_values_ELTPARAGRAPHE000373"></a>

Two types of animations are available for Static Text controls:

- Blinking, 

- Scrolling.





|   |   |
| --- | --- |
| **Parameters common to the different animations.** |
| Duration | Amount of time for displaying each drawing of the animation in milliseconds (300 ms by default). |
| **Parameter specific to "Blinking"** |
| Color | Blinking color. This parameter can correspond to a [color constant](../WDLang5/3010002.md).<br>This color corresponds to *Transparent* by default. |
| **Settings specific to "Scrolling"** |
| Loop | Continuous Dequeue (this parameter corresponds to <u><u><u><u>True</u></u></u></u> by default).<br><br><br> |
| MaxLoopCount | Number of scroll loops to perform (0 for unlimited scrolling number. <br><br><br> |
| NumberOfPixels | Number of pixels for each scrolling step. |
| Direction | Scroll direction. These parameters cannot be combined.<br>1 (default): left to right<br>2: right to left<br>4: from bottom to top<br>8: from top to bottom. |
