
## Telemetry constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


Telemetry constants are as follows:

| Constant | Details | Function |
| --- | --- | --- |
| **tsAbandon** | Current telemetry status: telemetry is abandoned after too many sending errors. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tsCollect** | Current telemetry status: telemetry is active and being collected. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tsWaiting** | Current telemetry status: telemetry is active, but sending information to the server has failed.. Data is waiting to be sent at a later date. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tsSend** | Current telemetry status: telemetry is active and has successfully sent information. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tsError** | Current telemetry status: telemetry is active, but sending information to the server has failed. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tsInactive** | Current telemetry status: telemetry is inactive. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcEnableLog** | Configures the telemetry log. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcIdleTimeout** | Telemetry settings (window activity count): the countdown timer is automatically stopped after this period of inactivity. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcStatus** | Current telemetry status. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcFileLog** | Telemetry log settings: Telemetry uses a log file.. The corresponding file is saved in the "\\AppData\\Roaming\\\\" directory. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcMemoryLog** | Telemetry log settings: Telemetry uses a memory log. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcOfflineMode** | Telemetry settings: Telemetry operating mode. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcNumberSendAttempts** | Telemetry settings: Maximum number of attempts to send telemetry data in connected mode | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcMaximumPeriodCollection** | Telemetry settings: Maximum frequency (in seconds) of telemetry data collection. The data will be sent at the end of this period, regardless of the size of the data collected. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcMinimumPeriodCollection** | Telemetry settings: Minimum frequency (in seconds) for telemetry data collection. The data can be sent at the end of this period if the minimum size is reached. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcMinimumSizeCollection** | Telemetry settings: minimum size (in kilobytes) of data collected for the minimum collection period. | [TelemetryConfigure](../WDLang1/1000021913.md) |
| **tcGetMemoryLog** | Returns the contents of the memory log. | [TelemetryConfigure](../WDLang1/1000021913.md) |
