


## StringToUTF8 (Function)

***In french: ChaîneVersUTF8***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts an ANSI or Unicode string to UTF-8.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyUnicodeString is a Unicode string = "start"
// MyUnicodeString contains the byte sequence: 0064 00E9 0062 0075 0074

MyUTF8String is Buffer = StringToUTF8(MyUNICODEString)
// MaChaineEnUTF8 contains the byte sequence: 64 C3 A9 62 75 74
// The character "é" was encoded in C3 A9
```

```wl
IF UTF8Valid(MyUTF8String) THEN
	// Convert to Unicode
	MyUnicodeString is Unicode string = UTF8ToString(MyUTF8String)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = StringToUTF8(<String to convert> [, <Charset of string to convert>])`
---

**`<Result>: (Character string or Buffer)`**



- Character string or buffer in UTF-8 format, 

- EOT if conversion problems occurred.




**`<String to convert>: (Character string)`**

String to convert to UTF-8.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This string can correspond to:

- an ANSI string in the current character set. The result will be an ANSI string containing the conversion to UTF-8.

- an ANSI string in a specified character set. The result will be an ANSI string containing the conversion to UTF-8. This conversion takes the initial character set into account.

- a Unicode string. The result will be a buffer containing the conversion to UTF-8.




**`<Charset of string to convert>: (Optional integer)`**

Source character set of string to convert. By default, this parameter corresponds to the *charsetCurrent* constant (specified in [ChangeCharset](../WDLang1/3054001.md)).


|   |   |
| --- | --- |

| *charsetArabic* | Arabic characters |

| *charsetCurrent*<br>(Default value) | Uses the current character set specified with [ChangeCharset](../WDLang1/3054001.md) (*charsetOccidental* by default) |
| *charsetDefault* | Uses the computer's default character set. ## Remarks
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Conversion in PHP
<a name="conversion_php_ELTPARAGRAPHE000282"></a>

The conversion in PHP uses the following extensions:

- the php_iconv.dll extension

- the php_mbstring.dll extension




If none of these PHP extensions are used, only Latin characters will be converted (e.g., Chinese or Russian characters will not be converted).

The php_iconv.dll and php_mbstring.dll extensions are currently proposed on PHP servers. To find out if your host offers these extensions, simply enter the following information into a search engine: phpinfo &lt;Host Name&gt;.

To install these extensions on your own PHP server, simply uncomment the desired extension in the PHP.INI file.
