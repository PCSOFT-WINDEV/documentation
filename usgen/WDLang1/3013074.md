


## InAJAXMode (Function)

***In french: EnModeAJAX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Specifies whether the code is run from:

- a process in AJAX mode.

- a procedure called by [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md).




For more details on AJAX, see [Overview of AJAX](../WDLang2/3055101.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code run from an AJAX process?
IF InAJAXMode() = True THEN
	// AJAX mode
	// Processes to perform
	...
ELSE
	// Non-AJAX mode
	// Processes to perform
	...
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = InAJAXMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the code is run from a process in AJAX mode or from a procedure called with [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md),

- <u><u><u><u>False</u></u></u></u> otherwise.




**InAJAXMode** returns <u><u><u><u>True</u></u></u></u> if the current process is not in AJAX mode but was called from a process in AJAX mode (with [ExecuteProcess](../WDLang1/3013031.md), for example).  

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter always corresponds to <u><u><u><u>False</u></u></u></u>.

### Processes in AJAX mode
<a name="processes_ajax_mode_ELTPARAGRAPHE000119"></a>

The following processes can be switched to automatic AJAX mode:

- "Click" server process of Button control, Link control or Clickable Image control.

- "Whenever modified" server process of List Box control, Combo Box control, Check Box control or Radio Button control.




To switch to the automatic AJAX mode, click the "AJAX" word in the process bar:<br>![Process not using the AJAX technology](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=AJAXBarre.GIF)

### Function availability
<a name="function_availability_ELTPARAGRAPHE000283"></a>

**InAJAXMode** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **InAJAXMode** can be shared between several products without generating any compilation error.
