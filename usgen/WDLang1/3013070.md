


## MemoryToFile (Function)

***In french: MémoireVersFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Automatically initializes the memory value of the items for the current table record with the values of the members:

- of a structure. 

- of a class. 

- of an advanced type.




**Note**: The **MemoryToFile** function does not write to the table: only the variables of the table fields are assigned (i.e. the variables of the record loaded into memory). To modify the records, use , , , etc, ...


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MemoryToFile(<Name of Structure or Class> , <File name>)`
---

**`<Name of Structure or Class>: (Structure or Class variable)`**

Name of the structure or name of the class containing the values of items.

**`<File name>: (Character string)`**

Name of the table to which the linked items belong.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If a member of the structure or class is named like an item of the HFSQL table, the value of the member is copied into the item in memory. The name of the member must contain no prefix. The case and the accented characters are ignored when comparing the name of items and the names of members.

- If an HFSQL field has no member in the class or structure, its value is not modified: no recopy is performed. To initialize the value of the HFSQL items before the call to **MemoryToFile**, use [HReset](../WDLang4/3044118.md).
