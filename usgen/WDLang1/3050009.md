
## Sin (Function)

***In french: Sinus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the sine of an angle.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Sine of 30
ResSine = Sin(30)
// Returns 0.5
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = Sin(<Angle>)`
---

**`<Result>: (Real)`**

Sine of the specified angle.

**`<Angle>: (Integer or real)`**

Angle (in degrees) to use.
