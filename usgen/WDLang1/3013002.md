


## ProfilerEnd (Function)

***In french: AnalyseurFin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops "collecting data" for the [performance profiler](../Editeurs/2030035.md).

The WPF file containing the database schema of all the processes performed is saved. This file can be opened by the [performance profiler](../Editeurs/2030035.md) or in the editor, via ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ico_ouvrir.gif) in the quick access buttons.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ProfilerStart("Test_StartProcedure.wpf")
StartProcedure()
ProfilerEnd()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ProfilerEnd()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
If [ProfilerStart](../WDLang1/3013012.md) was not called before **ProfilerEnd**, the call to **ProfilerEnd** has no effect.
