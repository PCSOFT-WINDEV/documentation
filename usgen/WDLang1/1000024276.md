


## &lt;Table&gt;.RecNum (Function)

***In french: &lt;Table&gt;.NumEnr***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of the current record in a data-bound Table control based on a table.

**Note** The function **&lt;Table&gt;.RecNum** function can be used on both single-selection and multi-selection Table controls.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Current record number in the "TABLE_ProductTable" control
ResRecNum = TABLE_TableProduct.RecNum()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Table control>.RecNum()`
---

**`<Result>: (Integer)`**



- Current record number in the table linked to the data-bound Table control,

- 0 if there is no current row or if the current row is not saved yet in the table linked to the Table control.




**`<Table control>: (Control name)`**

Name of the Table control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If the query was run with the *hWithFilter* constant (option checked in the query editor), **&lt;Table&gt;.RecNum** returns the number of the current record in the query.

- If the query was run without the *hWithFilter* constant, **&lt;Table&gt;.RecNum** returns an undefined result.
