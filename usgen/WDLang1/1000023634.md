


## &lt;Window&gt;.WinRedraw (Function)

***In french: &lt;Fenêtre&gt;.Repeint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Immediately redraws the window controls for which a graphic update is required.

**Note**: This function is identical to [MultitaskRedraw](../WDLang1/3038004.md).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function has no effect on pages. This function is available only to simplify the webification of WINDEV or WINDEV Mobile projects.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
i is int 
FOR i = 1 TO 1000
	LongProcess()
	WIN_Customer.Redraw()
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Window>.Redraw()`
---

**`<Window>: (Window name)`**

Name of the window to redraw.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Comparison with Multitask
<a name="comparison_with_multitask_ELTPARAGRAPHE000207"></a>

Unlike [Multitask](../WDLang1/3015004.md), the call to **&lt;Window&gt;.WinRedraw** does not interrupt the current code (the Timer functions are not called for example).
