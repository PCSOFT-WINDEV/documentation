
## CurrentTitle (Function)

***In french: TitreEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the title of the current window (returned by [CurrentWin](../WDLang1/3038033.md)).

**Reminder** By default, the window title is the one defined in the editor.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Replace the title of the current window
CurrentTitle(gBackground(LightRed) + gPen(Black) + "Modifying a customer form")
```
<a name="Exemple2"></a>

```wl
// Modify the title of the current window
// Adds "in progress"
CurrentTitle(EOT + gBackground(LightRed) + gPen(Black) + " in progress")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`CurrentTitle(<New window title>)`
---

**`<New window title>: (Character string)`**

New title for the current window. 

- If the EOT constant is specified, the new title will be added to the existing title.   

- In this string, you can use [gBackground](../WDLang1/3029037.md) to change the background color, [gPen](../WDLang1/3029039.md) to change the text color, etc. For more details, see the [remarks](#NOTE0_3). 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Title of dialog boxes
<a name="title_dialog_boxes_ELTPARAGRAPHE000080"></a>

The windows opened by [Warning](../WDLang1/3021009.md), [Confirm](../WDLang1/3021007.md), [Dialog](../WDLang1/3021015.md), [Error](../WDLang1/3021013.md), [ErrorInfo](../WDLang1/3013008.md), [Info](../WDLang1/3021011.md), [OKCancel](../WDLang1/3021004.md) or [YesNo](../WDLang1/3021005.md) have the same title as the previous window.

To change the title of the next window to open, use [NextTitle](../WDLang1/3038043.md).
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Title of clipped windows
<a name="title_clipped_windows_ELTPARAGRAPHE000118"></a>

**CurrentTitle** can also be used to change the title of clipped windows. However, this title is not displayed in the window.

If a clipped theme was used, the title of the window is displayed in a Static Text control. The content of this control is ignored by **CurrentTitle**. It must be modified specifically. 
<a name="NOTE0_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Title presentation
<a name="title_presentation_ELTPARAGRAPHE000133"></a>

The [graphic string functions](../WDLang1/3029033.md) (starting with "g") are used to:

- add drawings to the title,

- modify the formatting of title (background color, text color, etc.) with [gBackground](../WDLang1/3029037.md) and [gPen](../WDLang1/3029039.md).




For example: to change the text color and background color of a title:


```wl
CurrentTitle(EOT + gBackground(RGB(0, 255, 255)) + gPen(RGB(255, 0, 0)) + "Color test")
```


**Special case under Windows Vista and 7** Windows using the "Aero system" look cannot have a graphic title: the graphic part is ignored. If "Aero" is not enabled, the graphic title will be displayed as usual.
<a name="NOTE0_4"></a>




### Equivalence
<a name="equivalence_ELTPARAGRAPHE000159"></a>The following code: 


```txt
CurrentTitle(<New window title>)
```

is equivalent to the [Title](../Proprietes/2510090.md) property:


```txt
MyWindow.Title = <New window title>
```

### Minimized window
<a name="minimized_window_ELTPARAGRAPHE000177"></a>

When a window is minimized, the title of this window is displayed beside the icon in the taskbar.
