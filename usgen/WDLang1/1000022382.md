


## &lt;Camera&gt;.Capture (Function)

***In french: &lt;Caméra&gt;.Capture***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Captures the images received from the camera: 

- as an image: take a photo. 

- as a video: record a video.   




ELTSPECIAL000163 ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)
	<B><B><B>Warning</B></B></B>

	 **Starting with version 27, this function is deprecated for Android and iOS applications**. This function is kept only for Camera controls created with earlier versions and with the "Version-26-compatible mode" option enabled ("General" tab of the control description window).



Depending on the platform, the following photo and video formats are used:  

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) BMP images or AVI videos. 
	 If the file extension is.jpg or.jpeg, the image is saved in JPEG format 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) JPEG images or videos. The format and quality of the video depend on the default device settings and may differ from one device to another. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) JPEG images or videos. The format and quality of the video depend on the default device settings and may differ from one device to another. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Note: To obtain a photo or video directly using the device's native camera application, use the [VideoStartApp](../WDLang1/1000019368.md) function.

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Saves the video captured in the "CAM_Kitchen" control
// as a 1-minute AVI file ("C:\Temp\MyVideo.AVI")
ResSave = CAM_Kitchen.Capture("C:\Temp\MyVideo.AVI", viVideoCapture, 60)
IF ResSave = True THEN
	Info("Video successfully saved")
ELSE
	Error(ErrorInfo())
END
```

## Syntax

`<Result> = <Camera control>.Capture(<File to create> [, <Type of capture> [, <Capture duration> [, <Images per second> [, <Preview stream>]]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the video was recorded successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Camera control>: (Control name)`**

Name of the Camera control to be used.

**`<File to create>: (Character string)`**

Name and full (or relative) path of the file to create.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) When a photo is taken, a BMP file is created. When a video is recorded, an AVI file is created![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) When a photo is taken, a JPEG file is created. If a video is recorded, the format and quality of the video will depend on the default settings of the device and may differ from one device to another. **Warning** It is not possible to use a UNC path.

**`<Type of capture>: (Optional integer constant)`**

Type of capture:


|   |   |
| --- | --- |
| *viPictureCapture* | ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Captures an image and saves it as a BMP file.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Captures an image and saves it as a JPEG file. |
| *viVideoCapture*<br>(Default value) | ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Captures a video and saves it as an AVI file.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) If a video is recorded, the format and quality of the video will depend on the default settings of the device and may differ from one device to another. |



**`<Capture duration>: (Optional integer)`**

Length of the video recording (in seconds). If this parameter is set to 0 or is not specified, the video recording will stop:

- when [&lt;Camera&gt;.Stop](../WDLang1/1000022381.md) is called.

- when there is no more space on the disk.


This parameter can correspond to: 

- an integer corresponding to the number of seconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms). 




**`<Images per second>: (Optional integer)`**

Number of frames per second (15 by default). This parameter is taken into account only if &lt;Type of capture&gt; is equal to *viVideoCapture*.

**`<Preview stream>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (by default) if the video stream must be displayed in the specified Camera control,

- <u><u><u><u>False</u></u></u></u> otherwise.  


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This parameter is ignored. The preview stream is always displayed in the Camera control.

## Remarks


### Saving a photo
<a name="saving_photo_ELTPARAGRAPHE000325"></a>

Only the image displayed when **&lt;Camera&gt;.Capture** is executed is saved as a BMP image. To save this image, you can also use:

- function [&lt;Image&gt;.SaveBMP](../WDLang1/1000024341.md): the photo will be saved in BMP format.

- the [&lt;Image&gt;.SaveGIF](../WDLang1/1000024342.md) function: the photo will be saved in Gif format.

- the [&lt;Image&gt;.SaveJPEG](../WDLang1/1000024344.md) function: the photo will be saved in Jpeg format.





### Use conditions: 
<a name="use_conditions_ELTPARAGRAPHE000356"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) To use this function, a "web camera" must be connected to the current computer.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This function requires a device equipped with a camera. It can also be used in the Android emulator (only to capture images).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) To get and set the camera settings, use [VideoParameter](../WDLang1/1000019694.md) and [VideoListParameter](../WDLang1/1000019695.md).



<a name="NOTE0_2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000388"></a>

This function changes the permissions required by the application.

Required permissions: 

- CAMERA: This permission allows applications to access the camera. 

- RECORD_AUDIO: This permission allows applications to record sound.
