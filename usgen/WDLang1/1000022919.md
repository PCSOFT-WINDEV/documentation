


## DocAdd (Function)

***In french: DocAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds: 

- at the end of a word processing document: an element, document, paragraph, text, image or fragment.

- at the end of a fragment: an element, text or image.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Adds an image
// Select the image file 
sFile is string  
sFile = fImageSelect(fCurrentDir(), "", "Add an image",
	"JPEG (*.JPG)" + TAB + "*.jpg" + CR + "PNG (*.PNG)" + TAB + "*.png" + CR + 
	"All files (*.*)" + TAB + "*.*")
IF sFile = "" THEN
	RETURN
END
// The image file is transferred into an Image variable 
img is Image = sFile
// Add the image at the end of document 
DocAdd(WP_NoName1, img)
```
<a name="Exemple2"></a>

```wl
// Add a page break
DocAdd(WP_NoName, Charact(12))
```

## Syntax
<a name="SYNTAXE1"></a>

### Adding at the end of a Word Processing document

`<Result> = DocAdd(<Document> , <Object to add>)`
---

**`<Result>: (docFragment variable)`**

[docFragment](../WDLang1/1000022482.md) variable with the added fragment. 

**`<Document>: (Control name or Document variable)`**

Document to use. This document corresponds to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the name of a Word Processing control. 

- a variable of type [Document](../WDLang1/1000022461.md).




**`<Object to add>: (Type of added object)`**

Object to add: 

- Element: Name of the [docElement](../WDLang1/1000022484.md) type variable corresponding to the element to be added.

- Document: Name of the [Document](../WDLang1/1000022461.md) variable corresponding to the document to be added.
	**Attention**: The following elements of the added document are not retained: 

	- The default layout of the added document (e.g. margins). 

	- The parameters of the main section of the added document (e.g. headers and footers). 




- Paragraph: Name of the [docParagraph](../WDLang1/1000022483.md) variable corresponding to the paragraph to be added. This paragraph must have been retrieved from a document, it cannot be created from nothing because the array of paragraph elements is read-only.

- String text: Text to be added.
	You can use the following constants in the text to add to manage the different possible breaks: 
	


|   |   |
| --- | --- |
| *docColumnBreak* | Adds a column break in a multicolumn section. If the section is not multicolumn, a page break is added. |
| *docLineBreak* | Adds a line break. |
| *docPageBreak* | Adds a page break. |
| *docParagraphBreak* | Adds a paragraph break. |



- Image: Name of variable of type [Image](../WDLang1/1000019650.md) to be added.

- Fragment: Name of variable of type [docFragment](../WDLang1/1000022482.md) to be added.





<a name="SYNTAXE2"></a>

### Adding at the end of a fragment

`<Result> = DocAdd(<Fragment> , <Object to add>)`
---

**`<Result>: (docFragment variable)`**

[docFragment](../WDLang1/1000022482.md) variable with the added fragment. 

**`<Fragment>: (docFragment variable)`**

Name of the [docFragment](../WDLang1/1000022482.md) variable to be used.

**`<Object to add>: (Type of added object)`**

Object to add: 

- Element: Name of the [docElement](../WDLang1/1000022484.md) type variable corresponding to the element to be added.

- String text: Text to be added.
	You can use the following constants in the text to add to manage the different possible breaks: 
	


|   |   |
| --- | --- |
| *docColumnBreak* | Adds a column break in a multicolumn section. If the section is not multicolumn, a page break is added. |
| *docLineBreak* | Adds a line break. |
| *docPageBreak* | Adds a page break. |
| *docParagraphBreak* | Adds a paragraph break. |



- Image: Name of variable of type [Image](../WDLang1/1000019650.md) to be added.
