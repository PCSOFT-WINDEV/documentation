


## WinInWidth (Function)

***In french: FenIntLarg***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the interior width of a window. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) For Windows windows: This width does not include the frame.. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Case of maximized moving windows: This width corresponds to the width of the window.. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt_Mobile.gif)
This width is identical to that returned by the [WinOutWidth](../WDLang1/3038029.md) function.. 

- For non-maximized moving windows and popup windows: This width corresponds to the width of the window, excluding the thickness of the frame..

## Syntax

`<Result> = WinInWidth([<Window used>])`
---

**`<Result>: (Integer)`**

Inside width of the window (in pixels).

**`<Window used>: (Optional window name or optional string)`**

Name or alias of the window to be used. If this parameter is not specified or corresponds to an empty string (""), the interior width of the current window is returned.
