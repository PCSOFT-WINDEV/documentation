
## BitcoinCoreBlockHash (Function)

***In french: BitcoinCoreHashBloc***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the hash of a block identified by its index.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get hash of a block identified by its index
let BlockHash = BitcoinCoreBlockHash(2)
IF ErrorOccurred THEN
	Error()
	RETURN
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BitcoinCoreBlockHash(<Index>)`
---

**`<Result>: (Character string)`**

Block hash. 

**`<Index>: (Integer)`**

Block number.
