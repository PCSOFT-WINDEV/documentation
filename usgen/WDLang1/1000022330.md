


## &lt;Window&gt;.EdSave (Function)

***In french: &lt;Fenêtre&gt;.EdSauve***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves the changes made when the "Modification of UI by the end user" mode is enabled. These modifications can be saved in memory or in a file.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click on [Save]
WIN_Overview.EdSave("My changes.wdmodif")

// Click on [Load]
WIN_Overview.EdLoad("My changes.wdmodif")
IF ErrorOccurred = True THEN
	Info("Unable to load" + CR + ErrorInfo()) 
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Saving changes to a buffer

`<Result> = <Window>.EdSave(<inMemory> , <Save mode>)`
---

**`<Result>: (Buffer)`**

Buffer containing the result of the backup. The buffer is empty if no modification was performed.

**`<Window>: (Window name)`**

Name of the window or internal window to be used.

**`<inMemory>: (Constant)`**

*inMemory*: Constant used to save modifications in memory.

**`<Save mode>: (Integer constant)`**

Mode for saving the modifications: 



|   |   |
| --- | --- |
| *weModeDifferential*<br>(Default value) | Save all the modification operations, including custom operations ([&lt;Window&gt;.EdDo](../WDLang1/1000022327.md)). All these operations will be replayed during the reload operation (like for a log). |
| *weModeFull* | Save changes for all controls and their current properties. This constant can be used on an internal window only.  |
| *weModeReposionableNote* | Save only repositionable notes created by the user. This constant is equivalent to the "Export the notes" feature in the context menu of repositionable notes (AAF). |




<a name="SYNTAXE2"></a>

### Saving changes to a file

`<Result> = <Window>.EdSave(<File name> , <Save mode>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if modifications have been saved, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


Note: If no changes have been made, &lt;Result&gt; is <u><u><u><u>False</u></u></u></u>.

**`<Window>: (Window name)`**

Name of the window or internal window to be used.

**`<File name>: (Character string)`**

Name of the file in which the modifications must be saved. The extension of this file is "wdmodif".

**`<Save mode>: (Integer constant)`**

Mode for saving the modifications:



|   |   |
| --- | --- |
| *weModeDifferential*<br>(Default value) | Save all the modification operations, including custom operations ([&lt;Window&gt;.EdDo](../WDLang1/1000022327.md)). All these operations will be replayed during the reload operation (like for a log). |
| *weModeFull* | Save changes for all controls and their current properties. This constant can be used on an internal window only.  |
| *weModeReposionableNote* | Save only repositionable notes created by the user. This constant is equivalent to the "Export the notes" feature in the context menu of repositionable notes (AAF).<br><br>You can also use [WinEdSaveNote](../WDLang1/1000022120.md) to save only the repositionable notes created by the user. |
