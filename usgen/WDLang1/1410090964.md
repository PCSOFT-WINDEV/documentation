


## sysNotificationProgressBar (Variable type)

***In french: sysNotificationJauge***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **sysNotificationProgressBar** type is used to define all the characteristics of a progress bar displayed in an interactive notification, including text, progress, etc. You can define and change the characteristics of this progress bar using different WLanguage properties. 

The **sysNotificationProgressBar** type is used by [sysNotification](../WDLang1/1410087893.md) variables. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
notif is sysNotification
notif.Title = "Download pending..."
notif.ProgressBars[1].Title = "Video"
notif.ProgressBars[1].Status = "Downloading..."
notif.ProgressBars[1].ProgressText = "0/4"
notif.ProgressBars[1].Progress = 0.0
SysNotificationSend(notif)

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.25
notif.ProgressBars[1].ProgressText = "1/4"
SysNotificationProgressBarUpdate(notif.ProgressBars[1])

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.50
notif.ProgressBars[1].ProgressText = "2/4"
SysNotificationProgressBarUpdate(notif.ProgressBars[1])

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.75
notif.ProgressBars[1].ProgressText = "3/4"
SysNotificationProgressBarUpdate(notif.ProgressBars[1])

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 1.0
notif.ProgressBars[1].ProgressText = "4/4"
notif.ProgressBars[1].Status = "Downloading complete"
SysNotificationProgressBarUpdate(notif.ProgressBars[1])
```

## Properties


### Properties specific to sysNotificationProgressBar variables
<a name="properties_specific_sysnotificationprogressbar_variables_ELTPARAGRAPHE000036"></a>

The following properties can be used to handle a progress bar in a notification:

| Property name | Type used | Effect |
| --- | --- | --- |
| Progress | Real | Progress percentage (value between 0.0 and 1.0). |
| ProgressText | Character string | Text corresponding to the progress status. This text is displayed below the progress bar, on the right. Example: 15/20 files. |
| Status | Character string | Progress bar status. This string is displayed below the progress bar, on the left. Examples: "Downloading...", "Download complete". |
| Title | Character string | Progress bar title, displayed above the progress bar. |


**Note**: The progress bar displayed in an interactive notification is updated using [SysNotificationProgressBarUpdate](../WDLang1/1410091055.md).
