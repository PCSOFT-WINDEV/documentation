
## WINDEVVersion (Function)

***In french: WINDEVersion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the version number of the wdxxxvm DLL.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Returns the version number of the wdxxxjava.jar archive.

**Note** This function is equivalent to [ExeInfo](../WDLang1/3035001.md) with the constant *exeVersion*.

## Syntax

`<Result> = WINDEVVersion([<Version>])`
---

**`<Result>: (Character string or constant)`**



- Version number of the requested element.

- Constant that corresponds to the framework used. 




**`<Version>: (Optional Integer constant)`**

Requested version:


|   |   |
| --- | --- |
| *versionFramework* | Returns the version number of PC SOFT framework ("01F310039g" for example).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Not available. |
| *versionLanguage* | Returns a constant that corresponds to the language of the framework: <br><br>- *languageEnglish*: Framework in English.<br><br>- *languageChinese*: Framework in Chinese. <br><br>- *langueFrench*: Framework in French. <br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available. |
| *versionVM*<br>(default value) | Returns the version number of the wdxxxvm DLL ("31.01Dn" for example).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Returns the version number of the wdxxxjava.aar archive.<br>To get the version of this archive, simply:<br><br>1. Open the ".jar" or ".aar" archive (zip archive),<br><br>2. Go to the "\\res\\raw\\" folder,<br><br>3. Open "build_info.properties". This text file contains (for example): <br>	<br><pre><code>major.number=25<br>	minor.number=0<br>	build.number=341<br>	revision.number=8</code></pre><br><br><br><br><br><br>If an Android APK / AAB file is generated with this framework version, **WINDEVVersion** returns "25.0.341.8". |
