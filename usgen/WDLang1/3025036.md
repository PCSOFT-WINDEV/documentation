
## ControlError (Function)

***In french: ChampErreur***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>17</B>, ***FieldError*</**>** is kept for backward compatibility. This function has been replaced with ***ControlError*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Customizes the value displayed in the controls when the value cannot be displayed.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the ceOverflow error
ControlError(ceOverflow, "The control mask is too small")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ControlError(<Type of error> , <Error message>)`
---

**`<Type of error>: (Constant)`**

Type of error:


|   |   |   |
| --- | --- | --- |
| *ceBrokenBinding* | The value of linked item is not found (the linked value does not exist or an error occurred while it was read). | Default display value (corresponds to 3 hash characters): "###" |
| *ceNull* | The linked item is an HFSQL item that contains NULL. | Default value displayed (empty string): "" |
| *ceOverflow* | The control value is greater than the input/display mask defined for the control. | Default value (corresponds to 5 characters plus): "+++++" |
| *ceReadField* | Error reading a field: the field doesn't exist, the table is empty, ... | Default display value (corresponds to 4 hash characters): "####" |



**`<Error message>: (Character string)`**

New error message associated with the type of error.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Modifying the values displayed
<a name="modifying_the_values_displayed_ELTPARAGRAPHE000069"></a>

The new values will be effective only for future errors. The values assigned to the controls before using **ControlError** do not change.

The change is global to the current program.
