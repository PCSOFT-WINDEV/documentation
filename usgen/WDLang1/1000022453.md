
## CameraRequestPermission (Function)

***In french: CaméraDemandePermission***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Requests permission to use the device's camera.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF CameraRequestPermission() = True THEN
	OpenMobileWindow(WIN_Camera)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CameraRequestPermission()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the permission to use the video camera was granted,

- <u><u><u><u>False</u></u></u></u> otherwise.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Operating mode in Android
<a name="operating_mode_android_ELTPARAGRAPHE000041"></a>

- If the "CAMERA" permission was not added to the list of application permissions in the generation wizard, **CameraRequestPermission** will return <u><u><u><u>False</u></u></u></u>.

- From Android 6.0 or later, calling this function may trigger a dialog box asking the user to allow the application to use the camera of the device. If the authorization is not granted by the user, this dialog box will be displayed whenever this function is called. 







### Equivalence
<a name="equivalence_ELTPARAGRAPHE000054"></a>

This function is equivalent to [VideoRequestPermission](../WDLang1/1000022355.md).
