


## MenuMark (Function)

***In french: MenuMarque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Positions the checkmark ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Marque.gif) in front of the menu option (context menu or drop-down menu).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Marquage de l'option "OPT_Option1" du menu contextuel "MenuContextuel1"
MenuMarque(OPT_Option1)
// Equivalent à: MenuMarque(MenuContextuel1.OPT_Option1)
```
<a name="Exemple2"></a>

```wl
// Marquage de l'option "OPT_BarreIcone"
MenuMarque(OPT_BarreIcone)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MenuMark([<Window>, ] <Menu option>)`
---

**`<Window>: (Optional window name)`**

Name of the window containing the menu option to mark. 
If this parameter is not specified, **MenuMark** will handle the current window.

**`<Menu option>: (Option name)`**

Name of the menu option to mark. This name is defined in the description window of the menu option. 
This name must be specified without quotes.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Displaying a checkmark in an option associated with an image
<a name="displaying_checkmark_option_associated_with_image_ELTPARAGRAPHE000050"></a>

If a checkmark is associated with a menu option containing an image, the image is not replaced with the checkmark.
<a name="NOTE0_2"></a>


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000057"></a>

This function is equivalent to the [Checked](../Proprietes/2510019.md) property.
