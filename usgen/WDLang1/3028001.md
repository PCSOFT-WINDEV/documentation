
## DDERecipient (Function)

***In french: DDEDestinataire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies the recipient of a DDE connection.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open a DDE connection
ConnectionNum = DDEConnect(ServerName, "MyTopic")
...

// Recipient of the current connection
Recipient = DDERecipient(ConnectionNum)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = DDERecipient([<Connection ID>])`
---

**`<Result>: (Character string)`**

Recipient of the DDE connection.

**`<Connection ID>: (Optional integer)`**

Connection identifier, returned by [DDEConnect](../WDLang1/3028015.md). If this parameter is not specified, **DDERecipient** uses the last connection handled.
