
## SysWindowsAccentColor (Function)

***In french: SysCouleurAccentuation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the Windows accent color.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get Windows accent color
oAccentColor is Color = SysWindowsAccentColor()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SysWindowsAccentColor()`
---

**`<Result>: (Color variable)`**

[Color](../WDLang1/1000019661.md) variable corresponding to the color and opacity of the Windows accent color.
