


## &lt;Segmented Button&gt;.Insert (Function)

***In french: &lt;Bouton segmenté&gt;.Insère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a new option into a Segmented Button control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SB_Mode.Insert(2, "Advanced mode")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Segmented Button control>.Insert(<Option index> , <Option text>)`
---

**`<Result>: (Integer)`**



- Index of the inserted option. 

- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Segmented Button control>: (Control name)`**

Name of the Segmented Button control to which the option should be added. The option is added after the existing options.

**`<Option index>: (Integer)`**

Index of the option to be inserted.
If this parameter:

- is greater than the number of options in the control, the option is added at the last position.

- is equal to 1 or 0, the element is added before the first option in the control.




**`<Option text>: (Character string)`**

Text of the option to be inserted.
