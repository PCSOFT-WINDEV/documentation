


## End-user UI editing functions (prefix syntax)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>



|   |   |
| --- | --- |
| [&lt;Window&gt;.EdActive](../WDLang1/1000022294.md) | Allows you to: <br><br>- determine if the "Allow end users to modify the UI" option is enabled in a window (or internal window).<br><br>- enable or disable the "Allow end users to modify the UI" option in a window (or internal window).<br><br><br> |
| [&lt;Window&gt;.EdCreateNote](../WDLang1/1000022301.md) | Creates a Repositionable Note control. |
| [&lt;Window&gt;.EdDeselectAll](../WDLang1/1000022317.md) | Deselects all the controls when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdDo](../WDLang1/1000022327.md) | Runs an action (defined programmatically) and enables Undo/Redo operations on this action. |
| [&lt;Window&gt;.EdLoad](../WDLang1/1000022292.md) | Loads the changes made by the end user in a window. |
| [&lt;Window&gt;.EdRedo](../WDLang1/1000022328.md) | Runs the last action undone by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdRestore](../WDLang1/1000022329.md) | Undoes all the changes made by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdSave](../WDLang1/1000022330.md) | Saves the changes made when the "Modification of UI by the end user" mode is enabled. |
| [&lt;Window&gt;.EdSelect](../WDLang1/1000022331.md) | Returns one of the controls selected when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdSelectMinus](../WDLang1/1000022332.md) | Deselects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdSelectOccurrence](../WDLang1/1000022333.md) | Indicates the number of controls selected when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdSelectPlus](../WDLang1/1000022334.md) | Selects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [&lt;Window&gt;.EdUndo](../WDLang1/1000022335.md) | Undoes the last action performed by the end user when modifying the interface ("Allow end users to modify the UI" option enabled). |
