
## WLanguageCodeCompiling (Variable type)

***In french: CodeWLangageCompilation***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WLanguageCodeCompiling** type is used to define all the compiler options used by the [Compile](../WDLang1/3013015.md), [ExecuteCode](../WDLang1/1000019783.md) and [EvaluateExpression](../WDLang1/1000019782.md) functions, as well as by the Code Editor control (via the [Compiler](../Proprietes/1410090383.md) property). You can define and change the characteristics of these parameters using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CompilerOptions is WLanguageCodeCompiling
CompilerOptions.DefaultFunctions = AllFunctions
CompilerOptions.ForbiddenFunctions = "fDelete"

// Code Editor control options
CODEEDT_MyControl.Compiler.DefaultFunctions = AllFunctions
CODEEDT_MyControl.Compiler.ForbiddenFunctions = "fDelete"


// Compile function options
MySourceCode is string = [
PROCEDURE AddXandY(aa, bb)
RETURN aa + bb
]
MyProc is procedure = Compile(MySourceCode, CompilerOptions)
Trace(MyProc(2, 3))
```

## Properties


### Properties specific to WLanguageCodeCompiling variables
<a name="properties_specific_wlanguagecodecompiling_variables_ELTPARAGRAPHE000038"></a>

The following properties can be used to define the characteristics of **WLanguageCodeCompiling** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| AllowedFunctions | Character string | List of allowed functions, separated by CR, commas or semicolons. <br>Example: <br><br><pre><code>"fOpen" + CR + "fCreate"</code></pre><br>Remarks: <br><br>- Specify functions using the standard syntax only. The associated prefix syntax will be automatically taken into account. <br><br>- Function names can be in English or French: both languages are automatically taken into account.   <br><br><br> |
| DefaultFunctions | Integer constant | Specifies the functions available by default:<br><br>- *AllFunctions*: All WLanguage functions available by default. You can disallow certain functions using the **ForbiddenFunctions** property. <br><br>- *NoFunction*: No function available by default. You can allow certain functions using the **AllowedFunctions** property.<br><br><br> |
| ForbiddenFunctions | Character string | List of disallowed functions, separated by CR, commas or semicolons. <br>Example: <br><br><pre><code>"fOpen" + CR + "fCreate"</code></pre><br>Remarks: <br><br>- Specify functions using the standard syntax only. The associated prefix syntax will be automatically taken into account. <br><br>- Function names can be in English or French: both languages are automatically taken into account.   <br><br><br> |
