


## OrganizerChangeMode (Function)

***In french: AgendaChangeMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the time range displayed by an Organizer control (Day/Week/Month).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the first four days of the week
OrganizerChangeMode(ORG_MyOrganizer, orgzWeek, 4)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`OrganizerChangeMode(<Organizer control> , <Display range> [, <Number of days>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Display range>: (Integer constant)`**

Time range that must be displayed in the Organizer control:


|   |   |
| --- | --- |
| *orgzCustomNbDay* | Displays the organizer on the number of days specify in &lt;Number of days&gt;.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *orgzDay* | Display the organizer on one day. |
| *orgzMonth* | Display the organizer on one month. |
| *orgzWeek* | Displays the organizer on the number of days specify in &lt;Number of days&gt;. |
| *orgzWeekOn5* | Display the organizer on 5 days (the weekend is not displayed). |



**`<Number of days>: (Optional integer)`**

Number of days displayed. If the parameter &lt;Display range&gt; is equal to: 

- *agzWeek*: Number of days displayed in the week. If this parameter is not specified, the organizer will be displayed on a full week. 

- *agzNbCustomDay* Number of days displayed in the Organizer control. 


In other cases, a WLanguage error is displayed.
