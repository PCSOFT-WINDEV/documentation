
## gCircle (Function)

***In french: gCercle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a sequence of characters containing a circle or an ellipse. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) In a window, this sequence of characters is used to draw a circle or an ellipse:  

- in an element of a List Box or Combo Box control.

- in the title bar and/or status bar of a window. 

- in a Static Text control. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Draw a circle in an element of the "LIST_ShapeList" List Box
// The circle background is light green and the borders are light yellow
ListAdd(LIST_ShapeList, gCircle(0, 0, 25, 18, LightGreen, LightYellow))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = gCircle(<X1> , <Y1> , <X2> , <Y2> [, <Background color> [, <Line color>]])`
---

**`<Result>: (Character string)`**

Sequence of characters defining a circle or an ellipse. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This sequence of characters can be: 

- used in [ListAdd](../WDLang1/3049004.md), [ListInsert](../WDLang1/3049002.md) or [ListModify](../WDLang1/3049009.md).

- assigned to a Static Text control. 

- used in the title bar or status bar of a window. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This sequence of characters is not interpreted by the controls in WEBDEV. This function can be used to format the string returned by a WEBDEV web service consumed by a WINDEV or WINDEV Mobile application.

**`<X1>: (Real)`**

X-coordinate (in pixels) of the upper-left corner of the rectangle containing the circle.

**`<Y1>: (Real)`**

Y-coordinate (in pixels) of the upper-left corner of the rectangle containing the circle.

**`<X2>: (Real)`**

X-coordinate (in pixels) of the lower-right corner of the rectangle containing the circle.

**`<Y2>: (Real)`**

Y-coordinate (in pixels) of the lower-right corner of the rectangle containing the circle.

**`<Background color>: (Integer or constant (optional))`**

Circle background color. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the background color corresponds to the background color of the current text (defined by [gBackground](../WDLang1/3029037.md)).

**`<Line color>: (Integer or constant (optional))`**

Color of the circle line. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the color of the line corresponds to the color of the current text (defined by [gPen](../WDLang1/3029039.md)).

<a name="NOTE0_1"></a>

## Remarks


### Coordinates
<a name="coordinates_ELTPARAGRAPHE000129"></a>

All coordinates are expressed in pixels in relation to the upper-left corner of the element used (row in the List Box or Combo Box control, title bar of the window, status bar of window or Static Text control).
<a name="NOTE0_2"></a>


### Width/Height of rectangle
<a name="widthheight_rectangle_ELTPARAGRAPHE000136"></a>

The width of the reference rectangle is set to &lt;X2&gt; - &lt;X1&gt;.

The height of the reference rectangle is set to &lt;Y2&gt; - &lt;Y1&gt;.
