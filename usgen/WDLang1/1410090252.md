


## CodeEditorDuplicateLine (Function)

***In french: EditeurCodeDupliqueLigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Duplicates the current line in the Code Editor control.

You can also duplicate the current line in the Code Editor control by pressing Ctrl + D. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Duplicates the current line in the Code Editor control
CodeEditorDuplicateLine(CODEEDT_Example)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`CodeEditorDuplicateLine(<Code Editor control>)`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
