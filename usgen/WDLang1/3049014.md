


## ListCount (Function)

***In french: ListeOccurrence***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of elements in a List Box, ListView or Combo Box control.

**Note**: The **ListCount** function can be used on both:

- List Box controls based on a table or populated programmatically,

- single-selection or multi-selection List Box controls.









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Number of elements found in the "LIST_CustomerList" control
ResNumberElements = ListCount(LIST_CustomerList)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ListCount(<List Box control>)`
---

**`<Result>: (Integer)`**

Number of elements (rows) found in the specified control.

**`<List Box control>: (Control name)`**

Name of the List Box or Combo Box control to be used. If this parameter corresponds to an empty string (""), the control to which the current process belongs will be used.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The name of the List Box (or Combo Box) control to use must be specified.

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000086"></a>

If the specified List Box or Combo Box control is linked to a table that contains more than 2,147,483,647 records, the returned value is truncated to this value.

### List Box control file
<a name="list_box_control_file_ELTPARAGRAPHE000097"></a>

For a List Box control based on a table, **ListCount** returns:

- the total number of records found in the linked file if no filter was defined.

- the number of records matching the filter if a filter was defined.

- the number of records found in the query linked to the control.




The end of initialization code of control is run once the total is calculated.

**Warning** The time required to calculate the number of Records may be long.
<a name="NOTE0_3"></a>


### Last element
<a name="last_element_ELTPARAGRAPHE000117"></a>To position on the last element of List Box control, use the following syntax:

```txt
ListSelectPlus(<List Box control>, <List Box control>.Count)
```


or


```txt
<List Box control> = <List Box control>.Count
```
or

```txt
<List Box control> = ListCount(<List Box control>)
```
