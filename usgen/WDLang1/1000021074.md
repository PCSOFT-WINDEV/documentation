


## AssistedInputConfigure (Function)

***In french: SaisieAssistéeParamètre***

<a name="Utilisation"></a>
<a name="description"></a>
Specifies how to open and filter the autocomplete suggestion list.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AssistedInputDeleteAll(EDT_Direction)
AssistedInputAdd(EDT_Direction, "Left")
AssistedInputAdd(EDT_Direction, "Right")
AssistedInputAdd(EDT_Direction, "Center")

// To disable the filter 
AssistedInputConfigure(EDT_Direction, aiFilter, filterNone)

// Activate the "Contains" filter, which will be applied at each keystroke 
// to the 3 previously added values
AssistedInputConfigure(EDT_Direction, aiFilter, filterContains)

// The suggestion list will be opened next time AssistedInputOpen is called
AssistedInputConfigure(EDT_Direction, aiAutomaticOpening, False)
AssistedInputOpen(EDT_Direction)
```

## Remarks


- If **AssistedInputConfigure** is called on a edit control, the option "Assisted input based on data binding" is automatically enabled on this control ("Details" tab of the control description window).

- The suggestion list does not open immediately. To do so: 

	- the user must type a value that matches the first characters of one of the suggestions,

	- the [AssistedInputOpen](../WDLang1/1000020048.md) function must be called. 




- If the Edit control is linked to a table:

	- only the default filter ("Starts with") is available. 

	- the bound item in the data source must be key (faster iteration).
