


## &lt;WDPic variable&gt;.Background (Function)

***In french: &lt;Variable WDPic&gt;.Fond***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Declares the default background color for the rectangles, circles, etc., used in a variable of type [WDPic](../WDLang1/1000023503.md).![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPic is WDPic = "Test.bmp"

// Declare the background color of the different drawings in the MyWDPic variable
MyWDPic.Background(LightGreen)

IMG_MyDrawing = MyWDPic
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<WDPic image>.Background(<Color> [, <Fill style> [, <Type of hatching> [, <Opacity>]]])`
---

**`<WDPic image>: (WDPic variable)`**

Name of the [WDPic](../WDLang1/1000023503.md) variable to be used. Only the background layer will be handled.

**`<Color>: (Integer or constant)`**

Default background color of different drawings. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).

- a variable of type [Color](../WDLang1/1000019661.md). In this case, the opacity specified in the variable is taken into account.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available.




**`<Fill style>: (Optional integer or Integer constant)`**

Default background fill of different drawings:


|   |   |
| --- | --- |
| *BackgroundHatched* | Background filled with hatching. <br>Corresponds to value 2 for compatibility. |
| *BackgroundSolid*<br>(Default value) | Solid background. <br>Corresponds to value 0 for compatibility. |
| *BackgroundTransparent* | Transparent background (&lt;Color&gt; is ignored).<br>Corresponds to value 1 for compatibility. |


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This value is ignored. In this version, you cannot hatch the background of a drawing.![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The drawing of hatching is not supported.

**`<Type of hatching>: (Optional integer)`**

Type of background hatching used by default in the different drawings. To use this parameter, the value of &lt;Fill style&gt; must be equal to 2. If the value of &lt;Fill style&gt; is different from 2, &lt;Type of hatching&gt; is ignored. The different types of hatching are:

- 0: Horizontal hatching

- 1: Vertical crosshatching

- 2: 60% diagonal cut

- 3: 120% diagonal hatching

- 4 (default): Cross-hatching

- 5: Diagonal cross-hatching


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This value is ignored. In this version, you cannot hatch the background of a drawing.

**`<Opacity>: (Optional integer)`**

Opacity of color, included between 0 (transparent) and 255 (opaque). An opacity set to 128 is used to blend 50% of the color with the existing color found in the control.

**Remarks**: 

- This opacity will be taken into account if the drawing was initialized with the *dWithOpacity* constant ([&lt;WDPic variable&gt;.StartDrawing](../WDLang1/1000024471.md)).

- If parameter &lt;Couleur&gt; corresponds to a variable of type [Color](../WDLang1/1000019661.md), this parameter must not be specified: the opacity specified in the variable will be taken into account.
