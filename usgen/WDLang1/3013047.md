
## Sound (Function)

***In french: Son***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Plays a sound in WAV format. This sound can be:

- stored on the disk.

- included in the library (.WDL).

- in an HFSQL memo.




This function can also be used to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) play a system sound. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) play a sound of a given frequency for the desired time.




**Note** A sound card must be installed on the workstation. The sound will be played according to the Windows settings (volume, balance, quality, etc.).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Plays the sound found in the "TADA.WAV" file
Sound("Tada.wav")
// Plays while locking on sound card
Sound("tada.wav", soundWait)
// Plays while looping on sound card
Sound("C:\MSOFFICE\Sounds\Car.wav", soundLoop)
```

```wl
	END
END
```

## Syntax

### Playing a .WAV file

`Sound(<Name of WAV file> [, <Option>])`
---

**`<Name of WAV file>: (Character string)`**

Full or relative name of file to play. This file can be: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a WAV file.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) an audio file corresponding to all the formats supported by the OS (wav, mp3, 3gp, ogg, etc.). A summary of the supported audio files is available from the following address: [http://developer.android.com/guide/appendix/media-formats.html](http://developer.android.com/guide/appendix/media-formats.html). 
	Remarks: 

	- Android does not support 32-bit wav files. 

	- This parameter can correspond to a URL. In this case, it is necessary to add the INTERNET permission when generating the application. 




- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a file in wav format. 




Remarks: 


- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The audio file to play can also be included in the application via the generation wizard. To play it, simply specify the file name (name + extension). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) WAV files in HFSQL memo items cannot be played.




**`<Option>: (Optional integer constant)`**

Sound execution mode:


|   |   |
| --- | --- |
| *soundDefault*<br>(Default value) | The code continues to run as soon as the sound is started. |
| *soundLoop* | The sound is played in a loop.<br><br>Note: The file to be played must be on disk, not in the library (WDL file).. |
| *soundWait* | The code is locked as long as the sound is not entirely played. |

### Playing a system sound

`Sound(<System sound>)`
---

**`<System sound>: (Constant)`**

Preset system sound to play: 


|   |   |
| --- | --- |
| *soundSystemAsterisk* | Asterisk system sound. |
| *soundSystemClosing* | System sound for closing Windows. |
| *soundSystemCriticalStop* | System sound corresponding to the critical shutdown of the system. |
| *soundSystemDefault* | Default system sound (beep in most cases). |
| *soundSystemExclamation* | Exclamation system sound. |
| *soundSystemQuestion* | Question system sound. |

### Playing a sound of a given frequency during the requested time

`<Result> = Sound(<Frequency> , <Duration>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the sound was played, 

- <u><u><u><u>False</u></u></u></u> otherwise.




Note: Up to Windows 7, sound is played through the PC's internal speaker.. From Windows 7, the sound is played on the sound card.  

**`<Frequency>: (Unsigned integer)`**

Frequency of the sound in Hertz.

Note: For versions below Windows 7, only audible frequencies can be used (between 37 and 32767).

**`<Duration>: (Unsigned integer)`**

Duration (in milliseconds) during which the sound is played. Warning: the sound is blocking. This parameter can correspond to: 

- an integer representing the number of milliseconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms).

## Remarks


### Stopping a non-locking sound
<a name="stopping_nonlocking_sound_ELTPARAGRAPHE000226"></a>

A sound played in non-locking mode can be stopped by the following code, called on a user action for example (click, control modification, etc.): 


```wl
Sound("")
```

<a name="NOTE0_2"></a>


### Size of sound files
<a name="size_sound_files_ELTPARAGRAPHE000235"></a>

Using large WAV files may trigger several problems (not enough RAM to load the sound, system stopped depending on the Windows version, etc.). For large ".WAV" files (several dozen megabytes), we recommend that you use the [MCI functions](../WDLang1/3051010.md).
<a name="NOTE0_3"></a>


### Locking sound
<a name="locking_sound_ELTPARAGRAPHE000245"></a>

A sound is necessarily locking:

- If the sound is stored in a WINDEV library (.WDL file).

- If the sound comes from a binary memo.



<a name="NOTE0_4"></a>


### Sound and component
<a name="sound_and_component_ELTPARAGRAPHE000255"></a>

**Sound** is a non-blocking function by default. To use **Sound** in a component without locking the application, you must comply with the following constraints:

- The file corresponding to the sound must not be found in the WDL or in the component.

- The file corresponding to the sound must be found in the EXE directory of the application.
