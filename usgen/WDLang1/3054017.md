


## Defining specific character sets in HFSQL tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000163"></a>
When an application displays or saves data in HFSQL tables, this data is typed in the current language.

If the application is used in a country that uses a Latin character set, no specific configuration is required.

If the application is used in a country that uses a specific character set, this character set must also be supported by the tables. Therefore, most of the operations (searches, sorts, ...) will be performed according to the selected character set.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Defining the character set of a table
<a name="defining_the_character_set_table_ELTTEXTE000187"></a>


### Defining the character set used by a table
<a name="defining_the_character_set_used_table_ELTPARAGRAPHE000022"></a>

To define the character set used by a table:

1. Define the character set with [ChangeCharset](../WDLang1/3054001.md).

2. Create the table with [HCreation](../WDLang4/3044255.md) (or [HCreationIfNotFound](../WDLang4/3044254.md)). In these functions, use the *hChangeCharset* constant to take into account the character set specified by [ChangeCharset](../WDLang1/3054001.md).




All the functions used to perform sorts and searches will use the specific features of the selected character set.
<a name="NOTE2_2"></a>


### Notes and limitations
<a name="notes_and_limitations_ELTPARAGRAPHE000046"></a>

- The size of string items specified in the database schema is expressed in bytes and not in characters. Depending on the character set used, you may have to increase the item size (if the characters used are coded on 2 bytes for example).

- The character set of the table must always be identical to the character set specified by [ChangeCharset](../WDLang1/3054001.md). Otherwise, when accessing a string index (string, character, date, time):

	- Reading and searching for a record: no error will be displayed. However, the data read will not correspond to the expected data.

	- Modifying a record (addition, modification, deletion of records or crossed records): a WLanguage error will be displayed.




- No query with joins can be performed on text items that use different character sets.

- The sort order in HFSQL indexes ignores double letters (e.g., "CH" in Spanish or "LJ" in Croatian).

- ![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) In HFSQL Client/Server, only the sort order for the following languages is managed: French, Arabic, Chinese, Korean, Estonian, Greek, Hebrew, Japanese, Polish, Russian, Thai, Turkish and Vietnamese.



<a name="NOTE2_3"></a>


### Creating a table in Hebrew
<a name="creating_table_hebrew_ELTPARAGRAPHE000065"></a>


```wl
// Language used in the application: Hebrew
Nation(nationHebrew)
// Change the character set
ChangeCharset(charsetHebrew)
// Create the table 
// and take the change of character set into account
HCreation(Azaa, "", "", "", hChangeCharset)
// Enter a record
Azaa.toto = "סיגכניחלעכנגכךניע"
HAdd(Azaa)
```

## Changing the character set of a table
<a name="changing_the_character_set_table_ELTTEXTE000223"></a>
In some cases, you may want to change the character set of a table without recreating this table. For example:

- a table was translated.

- a table is filled when installing an application with the data corresponding to the setup language.

- ...



<a name="NOTE3_2"></a>


### Modifying the character set used for the searches and for the sorts
<a name="modifying_the_character_set_used_for_the_searches_and_for_the_sorts_ELTPARAGRAPHE000083"></a>

To modify the character set used for the searches and for the sorts: 

1. Specify the character set to use with [ChangeCharset](../WDLang1/3054001.md).

2. Reindex the table with [HIndex](../WDLang4/3044133.md). Use the *hChangeCharset* constant to use the character set specified by [ChangeCharset](../WDLang1/3054001.md).

### Changing the fonts according to the character set of the table read
<a name="changing_the_fonts_according_the_character_set_the_table_read_ELTPARAGRAPHE000114"></a>


```wl
HOpen(Customer)
FileLanguage is int = Customer.Charset
// Changes the character set according to the table format
SWITCH FileLanguage
	CASE charsetArabic: ChangeCharset(charsetArabic)
	CASE charsetDefault: ChangeCharset(charsetDefault)
	CASE charsetGreek: ChangeCharset(charsetGreek)
	CASE charsetHebrew: ChangeCharset(charsetHebrew)
	CASE charsetOccidental: ChangeCharset(charsetOccidental)
	CASE charsetRussian: ChangeCharset(charsetRussian)
	CASE charsetTurkish: ChangeCharset(charsetTurkish)
	OTHER CASE
		// Switch to western character set
	  	ChangeCharset(charsetOccidental)
END
```
