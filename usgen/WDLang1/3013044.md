
## TraceEnd (Function)

***In french: TraceFin***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>17 (78)</B>, ***EndTrace*</**>** is kept for backward compatibility. This function has been replaced with ***TraceEnd*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the trace window if this window was opened or stops saving the trace information in a text file. 

**Note** When the project is closed, the trace window is automatically closed and recording to the text file is automatically stopped.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Closing the trace window
TraceEnd()
```

<a name="SYNTAXE1"></a>

## Syntax

`TraceEnd()`
