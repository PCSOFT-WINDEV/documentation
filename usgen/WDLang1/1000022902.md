


## &lt;Scheduler&gt;.DisplayNextPeriod (Function)

***In french: &lt;Planning&gt;.AffichePériodeSuivante***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Moves the time area displayed on the next area (next weeks for example) in a Scheduler control. The Scheduler control is displayed from the day corresponding to the next time area. 

**Note** The [&lt;Scheduler&gt;.DisplayPreviousPeriod](../WDLang1/1000022901.md) and **&lt;Scheduler&gt;.DisplayNextPeriod** functions are used to implement simple "Next / Previous" Button control fields. These controls allow you to scroll through the time areas displayed by the Scheduler control.
 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click the BTN_Next Button control
SCH_RoomScheduler.DisplayNextPeriod()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Scheduler control>.DisplayNextPeriod()`
---

**`<Scheduler control>: (Control name)`**

Name of the Scheduler control to be used.
