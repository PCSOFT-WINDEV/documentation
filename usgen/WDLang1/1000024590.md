


## &lt;picLayer variable&gt;.Rotation (Function)

***In french: &lt;Variable picCalque&gt;.Rotation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Rotates an image in a variable of type [picLayer](../WDLang1/1000024604.md).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=dRotation.gif)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
MyLayer is picLayer

// Rotate layer by 45 degrees
Result1 is boolean
Result1 = MyLayer.Rotation(45)
IF Result1 = False THEN Error("The operation failed")
IMG_MyDrawing = MyWDPicImage
```

## Syntax

### Performing a simple rotation

`<Result> = <picLayer image>.Rotation(<Rotation angle> [, <Options>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the rotation has been completed, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<picLayer image>: (picLayer variable)`**

Name of the [picLayer](../WDLang1/1000024604.md) variable to be used.

**`<Rotation angle>: (Real)`**

Rotation angle (in degrees). 

- If the angle is positive, the image rotates clockwise. 

- If the angle is negative, the image rotates counterclockwise.




**`<Options>: (Integer constant)`**

|   |   |
| --- | --- |
| *drAdapt* | The image is flipped and enlarged. Then, its size is reduced to correspond to the initial image size. |

## Remarks


### End of drawing
<a name="end_drawing_ELTPARAGRAPHE000381"></a>

If [&lt;picLayer variable&gt;.EndDrawing](../WDLang1/1000024473.md) and **&lt;picLayer variable&gt;.Rotation** are called in the same process, the image changes will not be displayed.
<a name="NOTE0_2"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000402"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.



<a name="NOTE0_3"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000424"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
