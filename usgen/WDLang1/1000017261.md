
## AppInstallUPD (Function)

***In french: AppliDéclencheMAJ***

<a name="Utilisation"></a>
<a name="description"></a>
Triggers the automatic update of current application.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This function is only available for applications deployed in the Private Store.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF AppUPDAvailable() = appUPDAvailMandatory THEN
	IF YesNo("An update is available for the application.", ...
		  "Do you want to perform this update?") = Yes THEN
			  AppInstallUPD()
	END
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = AppInstallUPD()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the update is triggered,

- <u><u><u><u>False</u></u></u></u> if the update was not triggered. For more details on the error, use [ErrorInfo](../WDLang1/3013008.md). 




If the update is triggered, the application ends and the update is installed.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
When running **AppInstallUPD**:

- the current application is closed. The project closing code is run.

- the application is restarted (without command line). The update is detected and installed.

- the application is restarted at the end of the update, without command line.
