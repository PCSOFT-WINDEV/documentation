


## &lt;Word Processing&gt;.ClearFormatting (Function)

***In french: &lt;Traitement de texte&gt;.EffaceMiseEnForme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Replaces the current formatting of a selection in a Word Processing control with the default formatting.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Deletes the formatting of the selection in the Word Processing control
WP_Letter.ClearFormatting()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Word Processing control>.ClearFormatting()`
---

**`<Word Processing control>: (Control name)`**

Name of the Word Processing control to be manipulated.
