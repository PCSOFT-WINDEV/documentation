
## gFontBold (Function)

***In french: gPoliceGras***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a sequence of characters used to specify whether the text that follows the call to this function is in bold or not. 

**Note** All text written **following** function is assigned.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) In a window, this sequence of characters allows you to use bold (or normal) text:  

- in an element of a List Box or Combo Box control.

- in the title bar and/or status bar of a window. 

- in a Static Text control. 







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Display the title "WINDEV, #1 in France." in the next window
NextTitle(gFontBold() + "WINDEV" + gFontBold(False) + ", #1 in France.")
// Displays "WINDEV, #1 in France." in the title of the WIN_NextWindow window
Open(WIN_NextWindow)
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = gFontBold([<Bold>])`
---

**`<Result>: (Character string)`**

Sequence of characters defining whether the text must be written in bold or not.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This sequence of characters can be: 

- used in [ListAdd](../WDLang1/3049004.md), [ListInsert](../WDLang1/3049002.md) or [ListModify](../WDLang1/3049009.md).

- assigned to a Static Text control. 

- used in the title bar or status bar of a window. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This sequence of characters is not interpreted by the controls in WEBDEV. This function can be used to format the string returned by a WEBDEV web service consumed by a WINDEV or WINDEV Mobile application.

**`<Bold>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (by default) if the text that follows **gFontBold** should be bold,

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The default font is restored after the call to the [gFontXXX](../WDLang1/3029028.md) functions.

- All the other characteristics of the font are kept (italics, etc.).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) If the "bold" attribute is enabled in the style of the element to which the graphic string is assigned, a call to **gFontBold** with &lt;Bold&gt; set to False will not allow you to disable this attribute.
