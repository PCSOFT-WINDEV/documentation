


## FileToArray (Function)

***In french: FichierVersTableau***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Fills an array of classes or structures with the content of an HFSQL table or query. The values of members of instances of structures or classes are filled with the values of items of records found in the table or in the query.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Declare a MyContacts class
MyContacts is class
 	FamilyName is string
 	FirstName is string
 	EmailAddress is string
END

// Load records from the Contacts.fic file
// in an array of objects of MyContacts class
arrContact is array of MyContacts

HOpen(Contacts)
FileToArray(arrContact, Contacts)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`FileToArray(<Array> [, <Table> [, <Search key>]])`
---

**`<Array>: (Array of structures or objects)`**

Name of one-dimensional array into which the elements found in the table or in the query will be added. This array must be allocated in a structure or class type.

**`<Table>: (Character string)`**

Name of the HFSQL table or query used.

**`<Search key>: (Character string)`**

Name of search item used. This parameter is used when a filter is defined by [HFilter](../WDLang4/3044100.md). This parameter corresponds to the optimal search key to use, returned by [HFilter](../WDLang4/3044100.md).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is ignored.




## Remarks


- The array is entirely cleared by **FileToArray**.

- The automatic arrays are automatically resized according to the requirements.

- The table is browsed according to the current filter on the table.

- The position and the values of the current record are not modified by **FileToArray**.

- For each record found in the table or in the query:

	- for each member of structure or class with the same name, or same "[mapping](../Motscles/1515003.md)" attribute, as a file item, the item value is copied into the member value. 

	- if a structure or class member has no item with the same name in the table, its value is not modified.

	- if an item of table has no member with the same name in the class, no copy of value will be performed.




- Warning: The **FileToArray** function blocks all threads.
