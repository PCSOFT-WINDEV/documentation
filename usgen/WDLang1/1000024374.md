
## PDF Reader control and PDF file management constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used by the functions for managing PDF Reader controls:

| Constant | Detail | Function or type of variable |
| --- | --- | --- |
| **dispWithCoverPage** | Page display mode in the PDF reader used: considers the first page of the PDF file as a cover page. The first page is displayed on the right when the page display is in 2-page mode. | [pdfParameter](../WDLang6/1410087857.md) type |
| **dispEnableScrolling** | Page display mode in the PDF reader used: Dequeue display: Displays pages in an uninterrupted vertical column occupying the width of a page. Scrolling can be enabled for both 1-page and 2-page display modes. | [pdfParameter](../WDLang6/1410087857.md) type |
| **dispDefault** | Page display mode in the PDF reader used: Default display. | [pdfParameter](../WDLang6/1410087857.md) type |
| **dispTwoPage** | Page display mode in the PDF reader used: Display of two pages at a time, side by side from the PDF file in the PDF reader. | [pdfParameter](../WDLang6/1410087857.md) type |
| **dispSinglePage** | Page display mode in the PDF reader used: Display of a single page at a time from the PDF file in the PDF reader.. Margins are not displayed. | [pdfParameter](../WDLang6/1410087857.md) type |
| **pdfCertificateExpired** | The signature certificate has expired. <br><br> | [Procedure parameters used by the PDFVerifySignatures function](../WDLang6/1410090989.md) |
| **pdfXCoord** | X-coordinate of the specified position on the page (expressed in millimetres). | [PDFReaderInfoXY](../WDLang1/1000025332.md) |
| **pdfYCoord** | Y-coordinate of the specified position on the page (expressed in millimetres). | [PDFReaderInfoXY](../WDLang1/1000025332.md) |
| **pdfColor** | Color management in PDF files: Create a full-color PDF file. | [pdfParameter](../WDLang6/1410087857.md) type |
| **pdfModifiedAfterSignature** | PDF modified after signature.  <br><br> | [Procedure parameters used by the PDFVerifySignatures function](../WDLang6/1410090989.md) |
| **pdfGrayscale** | Color management in PDF files: Create a black & white PDF file. | [pdfParameter](../WDLang6/1410087857.md) type |
| **pdfPageNumber** | Number of the page that contains the specified position. | [PDFReaderInfoXY](../WDLang1/1000025332.md) |
| **pdfOriginScreen** | Changes the origin to calculate a position in the PDF Reader control. | [PDFReaderInfoXY](../WDLang1/1000025332.md) |
| **pdfSignatureInvalid** | The signature is invalid.   <br><br> | [Procedure parameters used by the PDFVerifySignatures function](../WDLang6/1410090989.md) |
| **rotationAnticlockwise** | Rotates the page -90 degrees. | [PDFReaderRotatePage](../WDLang1/1000023940.md) |
| **rotationClockwise** | Rotates the page 90 degrees. | [PDFReaderRotatePage](../WDLang1/1000023940.md) |
| **zoomFitVisible** | Default zoom applied to PDF file when opened: Zoom to content. | [pdfParameter](../WDLang6/1410087857.md) type |
| **zoomDefault** | Default zoom applied to PDF file when opened: Default zoom. | [pdfParameter](../WDLang6/1410087857.md) type |
| **zoomFullPage** | Zoom applied by default to the PDF file when it is opened: Zoom to display an entire page. | [pdfParameter](../WDLang6/1410087857.md) type |
| **zoomFullHeight** | Default Zoom applied to the PDF file when it is opened: Zoom to display the entire page at its full height. | [pdfParameter](../WDLang6/1410087857.md) type |
| **zoomFullWidth** | Default Zoom applied to the PDF file when it is opened: Zoom to display the entire page width. | [pdfParameter](../WDLang6/1410087857.md) type |
| **zoomActualSize** | Default Zoom applied to the PDF file when it is opened: Zoom at 100%/. | [pdfParameter](../WDLang6/1410087857.md) type |
