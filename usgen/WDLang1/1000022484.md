


## docElement (Variable type)

***In french: docElément***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docElement** type handles each element in a [docParagraph](../WDLang1/1000022483.md) variable. 

You can define and change the characteristics of this element using different WLanguage functions and properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Opens a docx file in the Word Processing control
WP_MyDoc = DocOpen(fExeDir() + fSep() + "MyDoc.docx")

// Fragment positioned at the end of document
fEnd is docFragment(WP_MyDoc, -1)
// Selects the document
TextFragment is docFragment(WP_MyDoc, 1, fEnd.EndPosition)

FOR EACH MyCurrentElement OF TextFragment.Element
	MyParagraph is docParagraph = MyCurrentElement.Paragraph
	Trace(MyParagraph.StartPosition)
	Trace(MyParagraph.EndPosition)
END
```

```wl
// Opens a docx file in the Word Processing control
WP_MyDoc = DocOpen(fExeDir() + fSep() + "MyDoc.docx")
MonDoc is a Document = TT_MonDoc
// Go through the paragraphs to find the switches
sElement is string
sParagraph is a string
sValue,sBegin,sEnd,sType are strings
FOR EACH MyPara OF MyDoc.Paragraph
	sParagraph = sParagraph + [RC] + sElement
	sElement = ""
	FOR ALL MyElement OF MyPara.Element
		sDebut = MyElement.StartPosition
		sFin = MyElement.PositionFin
		SELON MonElement.Type
			CAS typeDocElementFieldSwitch
			sType = "Checkbox"
			CheckBox is a docToggleElement <- MyElement..Field
			sValue = CheckBox.Checked
		END
		sElement = sElement + [RC] + sValue + TAB + sBegin + TAB + sEnd + TAB + sType
	END
END
```

## Properties


### Properties specific to docElement variables
<a name="properties_specific_docelement_variables_ELTPARAGRAPHE000036"></a>

The following properties can be used to define the characteristics of **docElement** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Cell | [docCell](../WDLang1/1000022927.md) variable | Cell characteristics (only if the element corresponds to a table cell). |
| Champ |   | Field characteristics (e.g. Check Box control field). <br><br>For Check Box control fields, use the **elt;-** operator to retrieve the switch's characteristics.. <br><br>Example: <br><br><pre><code>CheckBox is a docToggleElement <- MyElement..Field</code></pre><br> |
| EndPosition | Integer | End position of element in the document.<br>**This property is read-only**. |
| Formula | [docElementFormula](../WDLang1/1000022937.md) variable | Formula characteristics: formula, formula formatting, formula result (only for formula elements). |
| Image | [docElementImage](../WDLang1/1000022696.md) variable | Image characteristics (can be used for an Image element only). |
| Link | [docElementLink](../WDLang1/1000022970.md) variable | Link characteristics (only if the element corresponds to a link). <br><br>These characteristics are available in read-only. |
| Paragraph | [docParagraph](../WDLang1/1000022483.md) variable | Paragraph that contains the element. |
| Parent | [docElement](../WDLang1/1000022484.md) variable | Element that contains the element.<br>**This property is read-only**. |
| StartPosition | Integer | Start position of element in the document.<br>**This property is read-only**. |
| TableOfContents | [docTableOfContents](../WDLang1/1000024893.md) variable | Characteristics of the table of contents of the document. |
| Text | [docElementText](../WDLang1/1000022493.md) variable | Text characteristics (can be used for a Text element only). |
| TextArea | [docElementTextArea](../WDLang1/1000023420.md) variable | Characteristics of text area (can be used for a Text Area element only). |
| Type | Integer | Type of element corresponding to one of the following constants: <br><br>- *typeDocCellElement* Cell type element of an array.\*=<br><br>- *typeDocElementSwitchField* Check Box control element (check box on a form).<br><br>- *typeDocDocumentElement* Document type element.<br><br>- *typeDocHeaderElement* Page header element.<br><br>- *typeDocFormulaElement* Element of type Formula<br><br>- *typeDocImageElement* Image element.<br><br>- *typeDocUnrecognizedElement* Unrecognized element type. <br><br>- *typeDocLinkElement* Link element.<br><br>- *typeDocParagraphElement* Paragraph element with no text (empty text).<br><br>- *typeDocFooterElement* Footer element.<br><br>- *typeDocTableOfContents element* Table of contents element.<br><br>- *typeDocTextElement* Text element.<br><br>- *typeDocTextBoxElement* Text area element type. <br><br><br> |
