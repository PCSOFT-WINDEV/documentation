


## Close (Function)

***In french: Ferme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes a WINDEV window (and returns a value if necessary).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available only to simplify the Webification of WINDEV projects. In a WEBDEV website, this function has the same behavior as [PageCloseDialog](../WDLang2/1000017166.md) or [ContextClose](../WDLang2/3058003.md), according to each case. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Close the "WIN_Edit" window 
Close(WIN_Edit)
```

## Syntax

`Close([<Window> [, <Returned value> [... [, <Returned value N>]]]])`
---

**`<Window>: (Optional window name or window variable)`**



- Name of the window to close. 

- Name of the [Window](../WDLang1/1410091366.md) variable to be closed.
	


If this parameter is not specified or is an empty string (""), the current window is closed.

**`<Returned value>: (Type corresponding to the returned value (optional))`**

Value returned by the window when it is closed. 
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This value is retrieved only if the window was opened using [Open](../WDLang1/3038035.md). 
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) This value is retrieved only if the window was opened with [OpenMobileWindow](../WDLang1/1000021018.md) or [OpenChild](../WDLang1/3038021.md).

The following can be returned: 

- simple types (string, boolean, etc.). 

- advanced types: structure, dynamic structure, class, advanced type, array, associative array, queue, stack, list.

## Remarks


### Codes executed when the window is closed
<a name="codes_executed_when_the_window_closed_ELTPARAGRAPHE000149"></a>

- When a window is closed:

	1. The current process is permanently interrupted.

	2. The "Close" event of the window is executed.




- If [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) is called in the "Close" event, the window is not closed.

- If **Close** is run in a procedure called by [Timer](../WDLang1/3015008.md), [WinStatus](../WDLang1/3038030.md) or [CurrentWin](../WDLang1/3038033.md) must be used to confirm the existence of the window to close, otherwise all open windows may be closed. For example:
	
	```wl
	// Procedure called by the Timer function
	Window is string 
	Window = CurrentWin()
	IF Window <> "Window name" THEN
		Close()
	END
	```




<a name="NOTE0_2"></a>


### Window closing behavior according to its type
<a name="window_closing_behavior_according_its_type_ELTPARAGRAPHE000177"></a>

- If the window to be closed has child windows, these child windows will be closed first (their close code is executed).

- If the window to be closed is a child window, the parent window becomes the current window. The "focus gain" code of the parent window is executed.



<a name="NOTE0_3"></a>


### Last project window
<a name="last_project_window_ELTPARAGRAPHE000185"></a>

If the last window is closed, the "Close" event of the project is executed before the end of the program.

### Value returned to the Open function
<a name="value_returned_the_open_function_ELTPARAGRAPHE000205"></a>

**Close** can be used to return one or more values to [Open](../WDLang1/3038035.md).

Reminder: You can also use the [ReturnedValue](../Proprietes/2510134.md) property (&lt;Window name&gt;.*ReturnedValue*) before the **Close** function to return a value. In this case, only one value can be returned. 

Examples: 

- The user must type a password in a window. This password is retrieved when the window is closed and is returned to [Open](../WDLang1/3038035.md):
	
	```wl
	MyPassword = Open(WIN_EditPassword)
	IF MyPassword <> "" THEN
		Info("Wrong password") 
	END
	
	// -- Click code on the "OK" button in the "WIN_EditPassword" window
	// Users enter their password in the EDT_Password control 
	// and validates the window.
	Close("", EDT_Password)
	```


- The user must enter a username and a password in a window. The username and password are retrieved when the window is closed and returned to [Open](../WDLang1/3038035.md): 
	
	```wl
	(MyUsername, MyPassword) = Open(WIN_EditPassword)
	IF MyUsername <> "" OR MyPassword <> "" THEN 
		Info("Wrong username or password")
	END
	
	// -- Click code on the "OK" button in the "WIN_EditPassword" window
	// Users enter their username and password 
	// in the EDT_Password control and validate the window.
	Close("", EDT_Username, EDT_Password)
	```

### Value returned when closing a child window
<a name="value_returned_when_closing_child_window_ELTPARAGRAPHE000245"></a>

**Close** is used to return a value to the parent window that opened the child window.

Reminder: You can also use the [ReturnedValue](../Proprietes/2510134.md) property (&lt;Window name&gt;.*ReturnedValue*) before the **Close** function to return a value.

The value returned by the child window can be read in the "Close a child window" event of the parent window (the one that called [OpenMobileWindow](../WDLang1/1000021018.md) or [OpenChild](../WDLang1/3038021.md)). Simply use the [ReturnedValue](../Proprietes/2510134.md) property with the [MyChildWindow](../Motscles/1511021.md) keyword.

For example:

- In the closing code of the child window, [Close](../WDLang1/3038018.md) is used to return a parameter: 
	
	```wl
	Close("", MyParameter)
	```


- In the "Close a child window" event of the calling window, the name of the child window as well as the returned value can be retrieved using the [MyChildWindow](../Motscles/1511021.md) keyword: 
	
	```wl
	// Close a child window
	NameChildWindow = MyChildWindow.Name
	ValueChildWindow = MyChildWindow.ReturnedValue
	```




<a name="NOTE0_7"></a>


### Alt + F4 keys
<a name="alt_keys_ELTPARAGRAPHE000290"></a>

Pressing Alt + F4 can trigger several behaviors:

- If the window contains a "Cancel" button, the WLanguage event associated with the cancel button is executed.

- If the window has a button with Alt + F4 as keyboard shortcut, the WLanguage event associated with this button is executed.

- If the window does not contain a "Cancel" button, or a button with Alt + F4 as keyboard shortcut, the "Close" event of the window is executed and the window is closed (except if [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md) is called).

- If a window is opened from a program in an external language, Alt + F4 returns "ESC" in WdKey.



<a name="NOTE0_8"></a>


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000305"></a>The following line of code: 


```txt
WinStatus(<Window>, NotFound)
```
is equivalent to: 


```txt
Close(<Window>)
```
