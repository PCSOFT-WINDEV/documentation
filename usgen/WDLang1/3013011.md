


## InTestMode (Function)

***In french: EnModeTest***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>

<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether the application or the site is started:

- from the WINDEV or WEBDEV editor,

- from the executable or browser.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) from the WEBDEV administrator.




![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function has no effect in this version.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF InTestMode() = True THEN 
	Trace("Variable NumMenu: " + NumMenu)
END
```

## Syntax

### Checking the start mode of application

`<Result> = InTestMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the application is run:

	- from the WINDEV editor (window or project Go).

	- from the editor of Reports and Queries (report Go).

	- in debug on Mobile.

	- in component debug via executable.

	- from the WEBDEV editor (page or project Go).

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) from the WEBDEV administrator (Test button).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) in debug mode on an Android device (or if the application generated for debug mode is started on the Android device).




- <u><u><u><u>False</u></u></u></u> otherwise.




Special cases: 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In AWP mode, this parameter always corresponds to <u><u><u><u>False</u></u></u></u>. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a REST web service, this parameter always corresponds to <u><u><u><u>False</u></u></u></u>.




- ![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter always corresponds to <u><u><u><u>False</u></u></u></u>.





<a name="SYNTAXE2"></a>

### Checking the origin of start mode of application test

`<Result> = InTestMode([<Type of execution>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the test is run from the requested element,

- <u><u><u><u>False</u></u></u></u> otherwise.




**Remark**: The launch mode taken into account is that of the test origin.. For example, if the test of the report is run from a window displayed by a project GO, the origin of test will be the project GO. 

**`<Type of execution>: (Integer constant (or combination of constants))`**

Origin of test execution: 


|   |   |
| --- | --- |
| *tmPage* | Test run from a page Go. |
| *tmProcedure* | Test run from a procedure Go. |
| *tmProject* | Test run from a project Go. |
| *tmQuery* | Test run from a query Go. |
| *tmReport* | Test run from a report Go. |
| *tmTest* | Test run from the Go of an automated test. |
| *tmWindow* | Test run from a window Go. |

### GO from Reports & Queries
<a name="from_reports_queries_ELTPARAGRAPHE000200"></a>

**InTestMode** and [InReportsAndQueriesMode](../WDLang1/3013068.md) return <u><u><u><u>True</u></u></u></u> when a report is tested from Reports and Queries ("GO" button).

We advise you to replace the standard test:


```wl
IF InTestMode() = True THEN
	Trace("...")
END
```
by the following test:


```wl
IF InTestMode() = True AND InReportsAndQueriesMode() = False THEN
	Trace("...")
END
```

<a name="NOTE0_3"></a>


### Function availability
<a name="function_availability_ELTPARAGRAPHE000362"></a>

**InTestMode** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **InTestMode** can be shared between several products without generating any compilation error.
