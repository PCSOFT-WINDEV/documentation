


## &lt;Buffer&gt;.UTF8Valid (Function)

***In french: &lt;Buffer&gt;.UTF8Valide***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the validity of a UTF-8 buffer.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
bufUTF8 is Buffer
// Check if a UTF-8 buffer is valid
IF bufUTF8.UTF8Valid() THEN
	// Yes => Convert to UNICODE
	sUNICODE is Unicode string = bufUTF8.UTF8ToString()
	...
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Buffer to check>.UTF8Valid()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the UTF-8 string is valid,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Buffer to check>: (Buffer)`**

Buffer containing UTF-8 data.
