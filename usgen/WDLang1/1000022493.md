


## docElementText (Variable type)

***In french: docElémentTexte***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docElementText** type is used to handle the characteristics of a Text element found in a [docElement](../WDLang1/1000022484.md) variable.

The characteristics of this type of variable can be handled by several WLanguage properties. 

**CAUTION: This type must not be used directly. It must be used via the [docElement](../WDLang1/1000022484.md) type**.

<a name="PROPS"></a>

## Properties


### Properties specific to docElementText variables
<a name="properties_specific_docelementtext_variables_ELTPARAGRAPHE000026"></a>

The following properties can be used to define the characteristics of **docElementText** variables:

   | --- |
| --- | --- | --- |
| Property name | Type used | Effect |
| Formatting | [docFormatting](../WDLang1/1000022817.md) variable | Informations for element formatting. |
| Value | Character string | Text of element. |
