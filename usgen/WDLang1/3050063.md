
## Round (Function)

***In french: Arrondi***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the rounded value of a numeric value according to the specified number of decimal places.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the rounded value of -16.238167
ResRound = Round(-16.238167, 2)
// Returns -16.24
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = Round(<Numeric value> [, <Number of decimals>])`
---

**`<Result>: (Integer or real)`**

Rounded value of the specified numeric value.

**`<Numeric value>: (Real or currency)`**

Numeric value to round. We recommend that you use the currency type in order to get reliable results.

**`<Number of decimals>: (Optional integer)`**

Number of decimals to return. If this parameter is not specified, no decimal is returned.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Numeric value
<a name="numeric_value_ELTPARAGRAPHE000059"></a>

If &lt;Numeric value&gt; is included between:

- 0 and 0.49: the number is rounded to 0. For example, 3.2 is rounded to 3 (no decimal).

- 0.5 and 0.99: the number is rounded to 1. For example, 3.7 is rounded to 4 (no decimal).




Caution: Rounding with the "Real" type is not precise. In fact, operations with the "real" type are not precise due to the computer representation of the reals. To get an exact rounding, we recommend that you use the [Currency](../Motscles/1514043.md) or [Numeric](../Motscles/1514072.md) type that uses an exact memory representation. For more details, see the [real](../Motscles/1514048.md) type.
<a name="NOTE0_2"></a>




### Decimal separator
<a name="decimal_separator_ELTPARAGRAPHE000081"></a>

The decimal separator for real numbers is "." (point).
