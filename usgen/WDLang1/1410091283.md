


## &lt;Image&gt;Difference (Function)

***In french: &lt;Image&gt;.Différence***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Compares two images and returns a grayscale image and a percentage determining the differences between the images.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Image containing the differences between the compared images
ImageDifference is Image
// Percentage of differences between images
PercentageDifference is real
// Calculate differences between images
(ImageDifference, PercentageDifference) = IMG_Image1.Difference(IMG_Image2)
// Show differences
IMG_Difference = ImageDifference
// Indicate if images are identical
IF PercentageDifference = 0 THEN
	Info("The images are identical.")
ELSE
	Info("The images are different.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`(<Differences>, <Percentage>) = <First image>.Difference(<Second image>)`
---

**`<Differences>: (Image variable)`**

[Image](../WDLang1/1000019650.md) variable containing the differences between the images. 

- These differences are shown in grayscale. The image has the maximum width and height of the compared images.

- If a given point is identical in the compared images, it will be black in the resulting difference image. The more different the point is in the compared images, the lighter it will be in the difference image.

- If a point is present in one of the images and not in the other (e.g., one image is wider than the other), the corresponding point in the result image will be white.


**Note**: The alpha channel is ignored.

**`<Percentage>: (Integer)`**

Percentage of differences between the compared images.
This percentage will be 0 for two identical images, and 100 for two completely different images (e.g. a solid white and a solid black image).

**`<First image>: (Control name)`**

First image for comparison. This image corresponds to the name of an Image control.

**`<Second image>: (Name of the Image control, Image, WDPic or picLayer variable)`**

Second image for comparison. This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [WDPic](../WDLang1/1000023503.md). Only the background layer will be handled. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [picLayer](../WDLang1/1000024604.md).
