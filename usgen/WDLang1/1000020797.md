


## HourglassNetwork (Function)

***In french: SablierRéseau***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29</B>, this function is no longer available: 

- in iOS, 

- under Android version 14 and higher.

<a name="Utilisation"></a>
<a name="description"></a>
Displays or hides an endless progress bar: 

- in the status bar of an iOS application. 

- in the title bar of windows found in an Android application.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the progress bar
HourglassNetwork(True)
// Process
...
Multitask(-1)
...
// Hide the progress bar
HourglassNetwork(False)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HourglassNetwork(<Activation>)`
---

**`<Activation>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to enable the endless progress bar, 

- <u><u><u><u>True</u></u></u></u> to hide the endless progress bar.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
<a name="NOTE0_2"></a>


### Operating mode in Android
<a name="operating_mode_android_ELTPARAGRAPHE000050"></a>

If **HourglassNetwork** is called with the activation parameter set to <u><u><u><u>True</u></u></u></u>, the infinite progress bar will be displayed in the title bar (or ActionBar) of all open windows of the application as well as all the windows opened afterwards, until **HourglassNetwork** is called again with the activation parameter set to <u><u><u><u>False</u></u></u></u>. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=SablierReseau_Android.gif)
Remarks: 

- When running long processes, we advise you to add calls to [Multitask](../WDLang1/3015004.md) in the code in order to give time to the progress bar to refresh its display.

- You can also use [HourGlass](../WDLang1/3071011.md). In this case, the endless progress bar is displayed in a specific window. 

- The display of progress bars in the ActionBar using the Material Design them is not supported by the system. **HourglassNetwork** will have no effect if the window contains an ActionBar control and if the "Apply Material design theme to native controls and to Info/Error/Dialog windows" option has been checked in the Android configuration options.
