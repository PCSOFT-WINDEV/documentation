
## AI Chat functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate AI Chat controls: 



|   |   |
| --- | --- |
| [AIChatAsk](../WDLang1/1410091334.md) | Launches a new request in the AI Chat control. |
| [AIChatLoadConversation](../WDLang1/1410091365.md) | Loads a conversation into an AI Chat control. |
| [AIChatRetryRequest](../WDLang1/1410091360.md) | Launches a new request based on the current conversation in the AI Chat control. |
| [AIChatSaveConversation](../WDLang1/1410091364.md) | Saves the current conversation in an AI Chat control to memory or as a JSON file. |
| [AIChatStopRequest](../WDLang1/1410091363.md) | Stops a request in progress in the AI Chat control. |
