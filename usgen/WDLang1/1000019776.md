
## dbgCheckEqual (Function)

***In french: dbgVérifieEgalité***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the expressions are equal in assertive programming and in automated test mode.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The function should return 0 
dbgCheckEqual(CalcFunction(), 0)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`dbgCheckEqual(<Obtained expression> , <Expected expression> [, <Comments> [, <Parameter 1> [... [, <Parameter N>]]]])`
---

**`<Obtained expression>: (Character string)`**

Expression corresponding to the obtained result. 

**`<Expected expression>: (Character string)`**

Expression corresponding to the expected result.

**`<Comments>: (Character string)`**

Character string in the format defined by [StringBuild](../WDLang1/3024006.md). 

**`<Parameter 1>: (Any type)`**

First parameter expected by &lt;Comments&gt;.



**`<Parameter N>: (Any type)`**

Last parameter expected by &lt;Comments&gt;.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- When the expressions are not equal:

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in automated test mode, an error is added to the test status report (equivalent to [TestWriteResult](../WDLang1/1000013001.md)).

	- in manual test mode, an assertion is displayed (equivalent to [dbgAssert](../WDLang1/3014022.md)).

	- in runtime mode, an assertion is displayed if the assertions have been enabled (equivalent to [dbgAssert](../WDLang1/3014022.md)).




- **dbgCheckEqual** is used to compare the content of an array passed as first parameter with an array of values ([1, 2, 3] syntax) passed as second parameter.

- When running an application, the expression is not evaluated if the assertions are not enabled.

- [dbgOnError](../WDLang1/1000020722.md) allows you to automatically start a WLanguage procedure used to retrieve the comment linked to the error. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The messages of **dbgCheckEqual** will be written into the ADB log (at "Assert" level). For more details, see [Managing ADB logs](../Editeurs/9000108.md).
