


## &lt;WDPic variable&gt;.Font (Function)

***In french: &lt;Variable WDPic&gt;.Police***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Declares the font that will be used by [&lt;WDPic variable&gt;.DrawText](../WDLang1/1000024676.md) in a variable of type [WDPic](../WDLang1/1000023503.md).

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
// Declare the character font:
// Arial, size 12, bold
MyWDPicImage.Font("Arial", 12, iBold)

IMG_MyDrawing = MyWDPicImage
```

## Syntax

### Using a specific font for the drawings

`<WDPic image>.Font(<Font> [, <Font size> [, <Font attributes> [, <Text inclination>]]])`
---

**`<WDPic image>: (WDPic variable)`**

Name of the [WDPic](../WDLang1/1000023503.md) variable to be used. Only the background layer will be handled. 

**`<Font>: (Character string)`**

Name of the font used when the text is drawn by [&lt;WDPic variable&gt;.DrawText](../WDLang1/1000024676.md). This parameter must not correspond to a font family. The list of fonts installed on the current computer is returned by [FontList](../WDLang1/3060003.md). 

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the name of the font is not found, Windows searches for a font whose name is close to the requested one. To do so, [&lt;WDPic variable&gt;.StartDrawing](../WDLang1/1000024471.md) must have been used.

**`<Font size>: (Optional integer)`**

Size of the font (in pixels). The default value is 12.

**`<Font attributes>: (Optional constant (or combination of constants))`**

Font attributes to use:


|   |   |
| --- | --- |
| *iBold* | Assigns the bold attribute to the text drawn. |
| *iItalic* | Assigns the italic attribute to the text drawn. |
| *iNormal*<br>(Default value) | Normalizes the text drawn |
| *iStrikeOut* | Strikes the text drawn. <br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not supported. |
| *iUnderlined* | Underlines the text drawn. <br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not supported. |



**`<Text inclination>: (Optional integer)`**

Specifies the inclination of the text (in degrees). The default value is 0.

### Using a font created programmatically

`<WDPic image>.Font(<Font used>)`
---

**`<WDPic image>: (WDPic variable)`**

Name of the [WDPic](../WDLang1/1000023503.md) variable to be used. Only the background layer will be handled.

**`<Font used>: (Font)`**

Font that will be used for the drawings. This parameter corresponds to a variable of type [Font](../Motscles/1514045.md). The font characteristics have been defined with [FontCreate](../WDLang1/3060002.md) or via the [font properties](../Proprietes/2515045.md).

### Fonts
<a name="fonts_ELTPARAGRAPHE000597"></a>

[FontList](../WDLang1/3060003.md) is used to retrieve the list of valid fonts (TrueType, PostScript) installed on the current computer.

To get the best possible result when angling the text drawn, the &lt;Font&gt; used must be a "TrueType" font.

### Fonts in PHP
<a name="fonts_php_ELTPARAGRAPHE000613"></a>

To use the formatting attributes (bold, italic, ...), the files of corresponding fonts must be accessible (ttf files). These files must be in the directory of the site (directory _WEB returned by [fWebDir](../WDLang1/3036052.md)) and be named as follows: 

- &lt;Name of standard font&gt;

- &lt;Name of standard font&gt;_Bold

- &lt;Name of standard font&gt;_Italic

- &lt;Name of standard font&gt;_Italic_Bold




The management of the underlined is automatic like the management of &.

If no font is found, the text will be normal, without management of &.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000639"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000661"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
