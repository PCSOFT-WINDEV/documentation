


## Window functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>



|   |   |
| --- | --- |
| [&lt;Element&gt;.ExecuteRefreshUI](../WDLang1/1410088729.md) | Immediately executes the "Request for refreshing the display" event of the given element. |
| [&lt;Element&gt;.RequestRefreshUI](../WDLang1/1410088728.md) | Requests the execution of the "Request for refreshing the display" event of the specified element (and gives back control **without waiting for the execution of the event**). |
| [&lt;Window&gt;.ChangeLayout](../WDLang1/1410088842.md) | Applies a specific layout to: <br><br>- a window. <br><br>- an internal window.<br><br><br> |
| [&lt;Window&gt;.CurrentLayout](../WDLang1/1410088841.md) | Returns the index of the current layout in the window or internal window. |
| [&lt;Window&gt;.EnableDDW](../WDLang1/1410088766.md) | Enables or disables the Dim Disabled Window (DDW) feature for a specific window: |
| [&lt;Window&gt;.Iconize](../WDLang1/1000023884.md) | Minimizes a WINDEV window. |
| [&lt;Window&gt;.InHeight](../WDLang1/1410090629.md) | Returns the interior height of a window (without title bar and border). |
| [&lt;Window&gt;.InWidth](../WDLang1/1410090626.md) | Returns the interior width of a window (without border). |
| [&lt;Window&gt;.InXPos](../WDLang1/1410088866.md) | Returns the horizontal position of the upper-left corner of the internal area (without border and title bar) of a window in relation to the upper-left corner of the screen. |
| [&lt;Window&gt;.InYPos](../WDLang1/1410090627.md) | Returns the vertical position of the upper-left corner of the internal area (without border and title bar) of a window in relation to the upper-left corner of the screen. |
| [&lt;Window&gt;.Maximize](../WDLang1/1000023886.md) | Displays a WINDEV window in its maximum size. |
| [&lt;Window&gt;.Open](../WDLang1/1000023903.md) | Opens a modal WINDEV or WINDEV Mobile window. |
| [&lt;Window&gt;.OpenAsynchronous](../WDLang1/1410087862.md) | Opens a window whose result will be retrieved via a WLanguage procedure ("callback"). |
| [&lt;Window&gt;.OpenChild](../WDLang1/1000023904.md) | Opens a non-modal child window. |
| [&lt;Window&gt;.OpenMobileWindow](../WDLang1/1000023887.md) | Opens a window in a mobile application. |
| [&lt;Window&gt;.OpenPopupAsynchronous](../WDLang1/1410087873.md) | Opens a popup window whose result will be retrieved via a WLanguage procedure ("callback"). |
| [&lt;Window&gt;.OpenPopupPosition](../WDLang1/1410087874.md) | Opens a popup window by specifying its opening position and waits until it is closed. |
| [&lt;Window&gt;.OutHeight](../WDLang1/1410088867.md) | Returns the outer height of a window. |
| [&lt;Window&gt;.OutWidth](../WDLang1/1410090624.md) | Returns the full width of a window. |
| [&lt;Window&gt;.OutXPos](../WDLang1/1410090628.md) | Returns the horizontal position of the upper-left corner of a window in relation to the upper-left corner of the screen. |
| [&lt;Window&gt;.OutYPos](../WDLang1/1410090625.md) | Returns the vertical position of the upper-left corner of a window in relation to the upper-left corner of the screen. |
| [&lt;Window&gt;.Restore](../WDLang1/1000023888.md) | Displays a WINDEV window to its initial size. |
| [&lt;Window&gt;.WindowBitmap](../WDLang1/1000023885.md) | Creates the image of the specified window in a BMP file. |
| [&lt;Window&gt;.WinRedraw](../WDLang1/1000023634.md) | Immediately redraws the window controls for which a graphic update is required. |
| [&lt;Windows&gt;.OpenSibling](../WDLang1/1410086669.md) | Opens a non-modal sibling window. |
