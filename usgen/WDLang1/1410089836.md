


## NumericFormat (Variable type)

***In french: FormatNumérique***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **NumericFormat** type allows you to define all the characteristics of the format to be used with the [NumToString](../WDLang1/3024024.md) function. You can define and change the characteristics of this format using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
f is NumericFormat
f.Notation = nfnDecimal
f.Sign = nfsAlways
f.DigitsAfterPoint = 4
f.MinimumLength = 8
f.ThousandSeparator = "'"
f.FillCharacter = " "
sResult is string = NumToString(1234.567, f)
```

## Properties


### Properties specific to **NumericFormat** variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000028"></a>

| Property name | Type used | Effect |
| --- | --- | --- |
| Alignment | Integer constant | Number alignment. This property is also used to indicate on which side the fill characters will be added if necessary: <br><br>- *fncRight* (Default): Right alignment, fill characters will be added on the left. <br><br>- *fncLeft*: Left alignment, fill characters will be added on the right. <br><br><br> |
| Decimal separator | Character string | Text to be used as decimal separator. By default, the decimal separator is the one defined for the current language ("Languages" tab in the project description window).<br>Example: '3.14' with the "point" string used as decimal separator will be displayed as '3point14'. |
| DigitsAfterPoint | Integer | Number of digits after the decimal point. By default, there are 6 digits after the decimal point. <br><br>Example: '3.14' with 4 digits after the decimal point will be displayed as '3.1400'.<br><br>Remarks: <br><br>- The number of decimal places must be less than 100.<br><br>- If the number has more decimal places than the value specified in the **DigitsAfterPoint** property, the decimal part will be truncated.<br><br>- If the number has less decimal places than the value specified in the **DigitsAfterPoint** property, the decimal part will be padded with zeroes ("0") on the right.<br><br><br> |
| ExponentialSign | Integer constant | Sign options for a number in exponential notation: <br><br>- *fnsMoinsiNégatif*: The sign is displayed only if the number is negative.. <br><br>- *fnsAlways*: The sign is always displayed. <br><br><br> |
| FillCharacter | Character | Characters to be used if the string is longer than the number to be displayed.<br>Example: '3.14' in a string that is 6 characters long, using "x" as a fill character will be displayed as "3.14xx". |
| MinimumLength | Integer | Minimum string length. This property is associated with the **Alignment** property. The number of fill characters will correspond to the minimum total length minus the length of the number itself. If the number exceeds the minimum length, the **MinimumLength** property will be ignored. <br><br>Note: The total length corresponds to the following elements: sign, thousands separator, decimal point, exponent, integer and decimal parts of the number. This length must be less than 100. |
| Notation | Integer constant | Type of notation to be used. Standard (decimal, i.e. `12.34`), or other (binary, hexadecimal, octal, exponential).<br><br>- *fnnBinary*: Binary notation. <br><br>- *fnnDecimal* (Default value): Decimal notation. <br><br>- *fnnExponential* Exponential notation. <br><br>- *fnnHexadecimal* Hexadecimal notation. <br><br>- *fnnOctal*: Octal notation. <br><br><br> |
| Prefix | Character string | Text to be used as prefix for the number, when displayed as a string. This property can correspond to: <br><br>- a custom string. <br>	Example: '3.14' with the 'abc' prefix will be displayed as 'abc3.14'.<br><br>- the *nfpAuto* constant, to define an automatic prefix. In this case: <br><br>	- decimal or exponential format: no prefix. <br><br>	- binary format: 0b<br><br>	- hexadecimal format: 0x<br><br>	- octal format: 0o<br><br><br><br><br><br> |
| Sign | Integer constant | Sign display options: <br><br>- *fnsMinSiNegative* (Default value): The '-' sign is displayed only if the number is negative. <br><br>- *fnsParenthèsesSiNégatif*: If the number is negative, it is surrounded by parentheses.. <br><br>- *fnsAlways*: The sign is always displayed, <br><br><br> |
| ThousandSeparator | Character | Character to be used to split series of three zeros. By default, the thousand separator is disabled.<br>Example: 10000 with the 'Z' character as a thousand separator will be displayed as '10Z000'. |
| Uppercase | Boolean | <br><br>- <u><u><u>True</u></u></u> to use capital letters when displaying a number in a format using letters (for example: 0xAB24DA),<br><br>- <u><u><u>False</u></u></u> to use lowercase characters. <br><br><br> |
