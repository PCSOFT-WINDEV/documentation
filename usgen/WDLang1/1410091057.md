


## &lt;sysNotificationProgressBar variable&gt;.Update (Function)

***In french: &lt;Variable sysNotificationJauge&gt;.Maj***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Updates the characteristics of a progress bar present in a system notification. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
notif is sysNotification
notif.Title = "Download pending..."
notif.ProgressBars[1].Title = "Video"
notif.ProgressBars[1].Status = "Downloading..."
notif.ProgressBars[1].ProgressText = "0/4"
notif.ProgressBars[1].Progress = 0.0
notif.Send()

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.25
notif.ProgressBars[1].ProgressText = "1/4"
notif.ProgressBars[1].Update()

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.50
notif.ProgressBars[1].ProgressText = "2/4"
notif.ProgressBars[1].Update()

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 0.75
notif.ProgressBars[1].ProgressText = "3/4"
notif.ProgressBars[1].Update()

// Wait to update the notification
Multitask(1s)
notif.ProgressBars[1].Progress = 1.0
notif.ProgressBars[1].ProgressText = "4/4"
notif.ProgressBars[1].Status = "Downloading complete"
notif.ProgressBars[1].Update()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Notification>.Upd()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the progress bar was updated,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Notification>: (sysNotificationProgressBar variable)`**

[sysNotificationProgressBar](../WDLang1/1410090964.md) variable corresponding to the progress bar to be updated in the notification.
