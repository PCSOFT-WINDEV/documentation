


## CodeEditorLoad (Function)

***In french: EditeurCodeCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a WLanguage code file in a Code Editor control. This file contains the WLanguage code to be displayed in the control.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sFile is string
// Opens the file picker
sFile = fSelect("", "", "Select a file...", "WLangage code (*.WL)" + TAB + "*.WL", "*.WL")

IF sFile <> "" THEN
	// Loads the file into the Code Editor control
	CodeEditorLoad(CODEEDT_Example, sFile)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CodeEditorLoad(<Code Editor control> , <File to load>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was loaded into the Code Editor control,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.

**`<File to load>: (Character string)`**

Name and full path of the file to be loaded. This file corresponds to a file previously saved with [CodeEditorSave](../WDLang1/1410090245.md).
