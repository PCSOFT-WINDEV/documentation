


## &lt;picLayer variable&gt;.DrawText (Function)

***In french: &lt;Variable picCalque&gt;.DessineTexte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a text in a variable of type [picLayer](../WDLang1/1000024604.md).

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
MyLayer is picLayer

// Draw a text in light yellow
MyLayer.DrawText(10, 20, "Easy development", LightYellow)
IMG_MyDrawing = MyWDPicImage
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Image>.DrawText(<X-coordinate> , <Y-coordinate> , <Text> [, <Text color> [, <& character support>]])`
---

**`<Image>: (picLayer variable)`**

Name of the [picLayer](../WDLang1/1000024604.md) variable to be used.

**`<X-coordinate>: (Integer)`**

X-coordinate of text to draw (in pixels).

**`<Y-coordinate>: (Integer)`**

Y-coordinate of text to draw (in pixels).

**`<Text>: (Type corresponding to the text to draw)`**

Text to draw. This text can be:

- a string (without formatting marks such as TAB, CR, etc.),

- a numeric.




**`<Text color>: (Integer or constant (optional))`**

Text color to use. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the color of the text:

- is Black if [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) has not been used beforehand,

- corresponds to the color specified in the last call to [&lt;Image&gt;.Pen](../WDLang1/1000024016.md).




**`<& character support>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default value) if the "&" character must not be interpreted as an underline operator. 

- <u><u><u><u>False</u></u></u></u> if the "&" character must be interpreted as an underline operator. In this case, the character after "&" will be underlined.  


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) If this parameter is set to <u><u><u><u>False</u></u></u></u>, the "&" character will not be displayed but the following character will not be underlined.

## Remarks


### Font
<a name="font_ELTPARAGRAPHE000446"></a>

By default:

- The font used is "MS Sans Serif" (size 13).

- The writing direction is horizontal (from left to right).

- The coordinates of the upper-left corner of the image are (0,0).

- The "&" character is not interpreted.




To change these parameters, use [&lt;picLayer variable&gt;.Font](../WDLang1/1000024503.md).
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The default font may differ according to the system on which the application is run.
<a name="NOTE0_2"></a>
<a name="NOTE0_3"></a>


### Coordinates
<a name="coordinates_ELTPARAGRAPHE000486"></a>

Coordinates are specified with respect to the upper-left corner of the image (coordinates: (0.0)).
The coordinates correspond to the upper-left corner of the rectangle into which the text will be drawn. The precise location of the text in this rectangle depends on the size, shape and attributes of the font.
<a name="NOTE0_3_bis"></a>


### Management of '&'
<a name="management_ELTPARAGRAPHE000514"></a>The parameter &lt;Management of & &gt; makes it possible to manage the use of the '&' character. 
Example: 

- the "&" character must not be interpreted as an underline operator. For example: 
	
	```wl
	MyLayer.DrawText(10, 10, "Tom&Jerry", LightRed, True)
	```

	will display "Tom&Jerry".

- the "&" must be interpreted as an underline operator: the character following the "&" character will be underlined.. For example: 
	
	```wl
	MyLayer.DrawText(10, 10, "&Edit", LightRed, False)
	```

	will display "<u><u><u><u>E</u></u></u></u>dit".

### Limitations
<a name="limitations_ELTPARAGRAPHE000685"></a>

In anti-aliasing mode ([&lt;picLayer variable&gt;.ChangeMode](../WDLang1/1000024432.md)) or in opacity mode ([&lt;picLayer variable&gt;.StartDrawing](../WDLang1/1000024470.md)), **&lt;picLayer variable&gt;.DrawText** is available for the TrueType fonts only.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The anti-aliasing mode is not available.
<a name="NOTE0_6"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000714"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000736"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
