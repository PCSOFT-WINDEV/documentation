
## MenuAddMenuBrowser (Function)

***In french: MenuAjouteMenuNavigateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a new menu to an existing menu. This new menu can execute a browser procedure passed as a parameter. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add a new menu and enable users to select the menu option
MenuAddMenuBrowser(_Menu, "MNU_Dates", "Date", DisplayDate)
```





<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`(<Option>, <Position>) = MenuAddMenuBrowser(<Source menu> , <Menu to add> , <Caption> , <WLanguage browser procedure> [, <Parameter>])`
---

**`<Option>: (Character string)`**

Option added to parent menu. If the option is not added, a fatal error occurs.

**`<Position>: (Character string)`**

Position of the option in the parent menu. If the option is not added, a fatal error occurs.

**`<Source menu>: (Menu name)`**

Name of the drop-down or context menu to which the new menu should be added.

**`<Menu to add>: (Character string)`**

Name of the menu to be added. This name will be used to programmatically handle the menu. A fatal error occurs if this name corresponds to an existing menu.

**`<Caption>: (Character string)`**

Text of the new menu. This text will be displayed in the page.

**`<WLanguage browser procedure>: (Procedure name)`**

Name of the WLanguage browser procedure executed when the menu is selected.

**`<Parameter>: (Optional variant)`**

Parameter that can be passed to &lt;WLangage browser procedure&gt; when the menu is selected by the user.
