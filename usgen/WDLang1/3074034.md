


## TableDeleteAll (Function)

***In french: TableSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all rows from: 

- a Table control populated programmatically,

- a TreeView Table control populated programmatically,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a table displayed in a Combo Box control.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete all rows from the "TABLE_Product" control
TableDeleteAll(TABLE_Product)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableDeleteAll(<Table control>)`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control with table.


If this parameter is an empty string (""), the Table control of the current event will be used.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000100"></a>

**TableDeleteAll** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in "Server" mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.
