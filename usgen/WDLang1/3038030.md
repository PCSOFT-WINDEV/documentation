
## WinStatus (Function)

***In french: FenEtat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets or sets the window state.

**Note**: **WinStatus** can also be used to check the existence of a window.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the current window state
ResWinState = WinStatus()
```


<a name="Exemple2"></a>



```wl
// Modify the state of a window
SWITCH WinStatus(WIN_WindowName)
	CASE Active
		WinStatus(WIN_WindowName, Grayed)
	CASE NotFound
		Open(WIN_WindowName)
END
```

## Syntax

### Getting the window state

`<Result> = WinStatus([<Window used>])`
---

**`<Result>: (Constant)`**

Current window state:


|   |   |
| --- | --- |
| *Active* | Active window (window in edit mode, even if it does not have focus). |
| *DisplayOnly* | Inactive window (the window is not in edit mode). |
| *Grayed* | The window controls are grayed out. |
| *Invisible* | The window is hidden and inactive. |
| *NotFound* | Window closed or not found. |
| *OutsideScreen* | Active window outside the visible area of the screen.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |



**`<Window used>: (Optional window name, string or Window variable)`**



- Name or alias of the window to be used.

- Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be manipulated.
	


If this parameter is not specified or is an empty string (""), the current window state is returned.

## Remarks


### Modal and modeless windows
<a name="modal_and_modeless_windows_ELTPARAGRAPHE000216"></a>

When you use modal windows (MDI parent window and MDI child window), **WinStatus** cannot be used:

- to make a parent window active.

- to display a child window in front of all the other windows using the *Above* or *AboveAll* constant from an MDI parent window.




When using modal windows, if a parent window is hidden, its children are also hidden.

When using modeless windows, if a parent window is hidden, its children are not hidden.
<a name="NOTE0_2"></a>


### Differences between the Invisible and OutsideScreen constants
<a name="differences_between_the_invisible_and_outsidescreen_constants_ELTPARAGRAPHE000232"></a>

- If a parent window is set to:

	- ***OutsideScreen***, it is displayed in the list of Windows applications (accessible via Alt + Tab).

	- ***Invisible***, it is not displayed in the list of Windows applications (accessible via Alt + Tab).




- The coordinates of a window set to ***OutsideScreen*** are negative.

- Switching the state from:

	- ***Invisible*** to ***Active*** results in an inconsistent execution of the focus gain and focus loss events.

	- ***OutsideScreen*** to ***Active*** properly executes the focus gain and focus loss events.







**Tip**: Use *OutsideScreen* instead of *Invisible*.

- If a window set to *OutsideScreen* is displayed again using **WinStatus** with the *Active* constant, **WinStatus** does not set the focus to the window.

- If a window set to *OutsideScreen* did not have focus, it does not receive focus after the call to **WinStatus**.

### Inactive or invisible window
<a name="inactive_invisible_window_ELTPARAGRAPHE000262"></a>

If the current window is hidden or becomes inactive, the "focus loss" event of the window will be executed before the state changes.

### Closing the window
<a name="closing_the_window_ELTPARAGRAPHE000273"></a>

The following code closes the window: 


```txt
WinStatus(<Window name>, NotFound)
```


This code is equivalent to [Close](../WDLang1/3038018.md).
