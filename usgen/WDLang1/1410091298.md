
## WindowOpeningOptions (Variable type)

***In french: OptionsOuvertureFenêtre***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WindowOpeningOptions** type is used to define a window's opening options. These opening options can be defined and changed using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
show_customer_details is Window WIN_Customer_details
show_customer_details..OpeningOptions..X = 100
show_customer_details..OpeningOptions..Y = 100
Open(show_customer_details)
```

constants.<br><br>	- *waVista*: Windows Vista-style animation.<br><br><br><br><br>- Morphing:<br><br>	- *waCircularFadeIn*: The window appears inside a growing circle.<br><br>	- *waTopFilling*: The
