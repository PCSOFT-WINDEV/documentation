


## &lt;List Box&gt;.Modify (Function)

***In french: &lt;Liste&gt;.Modifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies an element in a List Box, ListView or Combo Box control populated programmatically.

**Note**: The **&lt;List Box&gt;.Modify** function can be used for both single-selection and multi-selection List Box controls..
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Attention**: The element will be modified only on the page displayed in the browser. For more details, see Remarks.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modification of the element located at index 4 in the "LISTE_ListeClient" List Box control.
LIST_CustomerList.Modify("Smith", 4)
```


<a name="Exemple2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Modify the image found at index 4 in "LSV_Diving"
LSV_Diving.Modify("Coral Reef", "C:\MyImages\CoralReef.JPG", 4)
```

## Syntax

`<List Box control>.Modify(<Element> [, <Image> [, <Element index>]])`
---

**`<List Box control>: (Control name)`**

Name of control to use: 

- List Box control, 

- Combo Box control.




**`<Element>: (Character string)`**

Element to modify in the specified List Box (or Combo Box) control.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **For a ListView control,** this parameter corresponds to the image caption.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The Carriage Return characters (CR) and the tabulations (TAB) are not supported.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) To add several consecutive spaces, use non-breaking spaces: Caract(160).

**`<Image>: (Optional character string)`**

Name and path of image that will be added into a ListView control. This parameter is taken into account for ListView controls displayed in ListView mode only. 
If this parameter is not specified, the default image (defined in the "Detail" tab of the control description window) is used..
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

**`<Element index>: (Optional integer)`**

Index of the element to be modified.

If this parameter:

- is not specified or if it is set to -1, the current element is modified. **&lt;List Box&gt;.Modify** has no effect if there is no current element.

- is equal to 0, the first element is modified.

- is greater than the number of items in the List Box control (or Combo Box control), a WLanguage error is generated.. The number of elements in a List Box (or Combo Box) control is returned by [&lt;List Box&gt;.Count](../WDLang1/1000017334.md).


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **&lt;List Box&gt;.Modify** has no effect if this parameter is equal to 0 or if it is greater than the number of elements found in the List Box (or Combo Box) control.

## Remarks


### Multi-selection List Box control
<a name="multiselection_list_box_control_ELTPARAGRAPHE000280"></a>

If one or more elements are selected in the List Box control, **&lt;List Box&gt;.Modify** deselects no element.

### Modified element
<a name="modified_element_ELTPARAGRAPHE000294"></a>

When modifying an element containing an invisible value (specified by [gStoredValue](../WDLang1/1410088363.md)), [gStoredValue](../WDLang1/1410088363.md) must be re-used. Otherwise, this invisible value will be lost during the modification.

For example:

- adding "MyElement": 
	
	```wl
	COMBO_MyCombo.Add("MyElement" + gStoredValue("1"))
	```


- modifying "MyElement":
	
	```wl
	COMBO_MyCombo.Modify("MyNewElement" + gStoredValue("1"))
	```

### Modifying an element in the browser
<a name="modifying_element_the_browser_ELTPARAGRAPHE000331"></a>

When modifying an element in browser code, this element is modified only for the page displayed in the browser. To make changes to this element on the server as well, **&lt;List Box&gt;.Modify** must be executed on the server.

Calling **&lt;List Box&gt;.Modify** in browser code is useful when using [AJAX technology](../WDLang2/3055101.md), in "Programmed AJAX" mode (via [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)).

**Reminder** In "automatic and immediate AJAX" mode, simply pass the server processing containing the function **&lt;List Box&gt;.Modify FUNCTION** in automatic AJAX mode. That's it! No additional programming is required. For more details, see [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_4"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000363"></a>

- To modify an element in a Table control, use [&lt;Table&gt;.Modify](../WDLang1/1000024273.md).

- **&lt;List Box&gt;.Modify** can be used on a "Combo Box" table column.
