


## &lt;Pivot Table&gt;.ExpandAll (Function)

***In french: &lt;Tableau croisé dynamique&gt;.DérouleTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Expands all row and/or column headers in a Pivot Table control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Loads the table
PVT_Statistics.Load(sFile)
// Expands all headers of the Pivot Table control
PVT_Statistics.ExpandAll()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Pivot Table control>.ExpandAll([<Type of header>])`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used. This Pivot Table control must have been populated using [&lt;Pivot table&gt;.CalculateAll](../WDLang1/1000022180.md) or [&lt;Pivot Table&gt;.Load](../WDLang1/1000022181.md).

**`<Type of header>: (Optional Integer constant (or combination of constants))`**

Type of the header to expand: 


|   |   |
| --- | --- |
| *pvtColumnHeader* | Expands the column headers. |
| *pvtRowHeader* | Expands the row headers. |


If this parameter is not specified, row headers **AND** column headers are expanded.
