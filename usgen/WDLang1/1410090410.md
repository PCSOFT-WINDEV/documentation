
## Code Editor control functions
			

**Note**: These functions are also available in prefix syntax ([Code Editor control functions (prefix syntax)](../WDLang1/1410090424.md)).



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate Code Editor controls: 



|   |   |
| --- | --- |
| [CodeEditorComment](../WDLang1/1410090247.md) | Comments the current selection in the Code Editor control. "//" characters are inserted at the beginning of the current line. |
| [CodeEditorCompile](../WDLang1/1410090249.md) | Compiles the WLanguage code displayed in the Code Editor control and displays any errors. |
| [CodeEditorDeleteAll](../WDLang1/1410090256.md) | Deletes the contents of the Code Editor control. |
| [CodeEditorDuplicateLine](../WDLang1/1410090252.md) | Duplicates the current line in the Code Editor control. |
| [CodeEditorExecute](../WDLang1/1410090253.md) | Executes the WLanguage code displayed in the Code Editor control. |
| [CodeEditorGetError](../WDLang1/1410090257.md) | Gets a compilation error from the code in the Code Editor control. |
| [CodeEditorInsert](../WDLang1/1410090254.md) | Inserts a string in the Code Editor control. |
| [CodeEditorLoad](../WDLang1/1410090372.md) | Loads a WLanguage code file in a Code Editor control. |
| [CodeEditorReplace](../WDLang1/1410090251.md) | Finds and replaces a string in the Code Editor control. |
| [CodeEditorSave](../WDLang1/1410090245.md) | Saves the contents of a Code Editor control to a file. |
| [CodeEditorSearch](../WDLang1/1410090250.md) | Searches for a string or regular expression in the Code Editor control. |
| [CodeEditorUncomment](../WDLang1/1410090248.md) | Uncomments the current selection in the Code Editor control. "//" characters at the beginning of the current line are removed. |
