
## docAutoReplace (Variable type)

***In french: docRemplacementAutomatique***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docAutoReplace** type is used to define all the advanced characteristics of a string used to automatically replace another string as the user types in a Word Processing control . You can define and change the characteristics of this automatic correction using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
c est un docRemplacementAutomatique
c.NouvelleChaîne = "10 fois plus vite"
TT_MondocCommercial.CorrectionAutomatique.Remplacement["10f"] = c

// Autre syntaxe acceptée (sans passer par la variable docRemplacementAutomatique)
TT_MondocCommercial.CorrectionAutomatique.Remplacement["20f"] = "20 fois plus vite"
```
<a name="Exemple2"></a>

```wl
d est un Document
DocInsère(d, 1, "Bonjour")

TT_MondocCommercial.CorrectionAutomatique.Remplacement["bb"] = d

d2 est un Document 
d2 <- TT_MondocCommercial..CorrectionAutomatique.Remplacement["bb"]..NouvelleChaîneFormatée
```

## Properties


### Properties specific to docAutoReplace variables
<a name="properties_specific_docautoreplace_variables_ELTPARAGRAPHE000028"></a>

The following properties can be used to handle **docAutoReplace** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| NewChain | Character string | String containing the correction. <br><br>Note: The **New** String property takes precedence over the **New** Formatted String property (if it exists). |
| NewFormattedString | [Document](../WDLang1/1000022461.md) | New string, as a document that can contain formatting.<br><br>Note: This property can also correspond to a variable of type [docParagraph](../WDLang1/1000022483.md), [docElement](../WDLang1/1000022484.md), ... |
