
## WindowsVersion (Function)

***In french: VersionWindows***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the runtime mode of Windows.

**Reminder** WINDEV allows you to create [32-bit and 64-bit executables](../Editeurs/2030048.md).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns the runtime mode of the WEBDEV Application Server.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Know your Windows version: 32-bit or 64-bit

Version is int
Version = WindowsVersion()
SWITCH Version 
	CASE 32: Info("Windows runs in 32 bits")
	CAS 64: Info("Windows runs in 64 bits")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = WindowsVersion()`
---

**`<Result>: (Character string)`**

Returns the runtime mode of program in the current environment:

- "32": the program runs in 32-bit mode in a 32-bit environment.

- "64": the program runs in 32-bit mode or in 64-bit mode in a 64-bit environment.
