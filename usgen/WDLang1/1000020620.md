


## StartShare (Function)

***In french: LancePartage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a popup allowing you to select the application that will be used to share a resource (text or document). The application will be opened with the specified resource. 

For example, an image can be shared with the application for sending emails. In this case, a new email will be created with the specified image in attachment.

<a name="sample_code"></a>

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
```wl
// Share an image displayed in an Image control
sPath is string = CompleteDir(SysDirExternalStorage(1, ssePublicPhoto)) + "MyImage.png"
IF dSaveImagePNG(IMG_Image, sPath) = True THEN
	NextTitle("Sharing an image")
	StartShare(sPath) 
END
```
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) <a name="Exemple2"></a>

```wl
// Share an image displayed in an Image control
sPath is string = CompleteDir(fDataDir()) + "MyImage.png"
IF dSaveImagePNG(IMG_Image, sPath) = True THEN
	NextTitle("Sharing an image")
	StartShare(sPath) 
END
```


<a name="Exemple3"></a>

```wl
// Share a text displayed in an edit control
IF StartShare(shareText, EDT_Edit) = False THEN
	Error(ErrorInfo())
END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = StartShare([<Type>, ] <Parameter 1> [, <Parameter 2> [... [, <Parameter N>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified resources can be shared. 
	 Remarks: 

	- This function does not block the application. The code that follows the call to this function will continue to execute after the popup has been displayed

	- It is not possible to find out whether an application was selected by the user to perform the share. 




- <u><u><u><u>False</u></u></u></u> if no application allowing to share the resources is found. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Type>: (Optional Integer constant)`**

Type of resource to share: 


|   |   |
| --- | --- |
| *shareDocument* <br>(Default value) | One or more documents (image, video, pdf, etc.) are shared. These documents are identified by their full path, specified as parameter (&lt;Parameter 1&gt; to &lt;Parameter N&gt;).<br><br>The document must be located on the shared memory of the device (e.g., SD Card) so that it can be manipulated by the application selected for sharing.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Only the images are supported. |
| *shareText* | Text is shared.<br><br>If several character strings are specified as parameters (&lt;Parameter 1&gt; to &lt;Parameter N&gt;), they are concatenated and separated by carriage returns (CR).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Note: The Facebook application does not support automatic text sharing. |



**`<Parameter 1>: (Character string)`**

First resource to share. Corresponds to: 

- a file path (if the *shareDocument* constant is used). 

- a character string (if the *shareText* constant is used). 




**`<Parameter 2>: (Optional character string)`**

Second resource to share. Corresponds to: 

- a file path (if the *shareDocument* constant is used). 

- a character string (if the *shareText* constant is used). 






**`<Parameter N>: (Optional character string)`**

Last resource to share. Corresponds to: 

- a file path (if the *shareDocument* constant is used). 

- a character string (if the *shareText* constant is used).

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000102"></a>

- To customize the title of popup for selecting the application, use [NextTitle](../WDLang1/3038043.md) before **StartShare**. 

- If only one application lets you share the resource on the mobile, the popup is not displayed and the application starts directly. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Note: This function is available in the Android emulator.. This function is not available in the Android simulator.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000249"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**StartShare** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
