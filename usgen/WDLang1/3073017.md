
## SysIconize (Function)

***In french: SysIconisé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to find out whether a window is minimized. This window was not created by WINDEV.

**Note**: To find out whether a WINDEV window is iconized, use the [WinSize](../WDLang1/3038020.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Savoir si la fenêtre "Microsoft Word - Ventes.DOC" est iconisée
ResHandle = SysFenHandle("Microsoft Word - Ventes.DOC")
ResIconiseFen = SysIconisé(ResHandle)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysIconize(<Window handle>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified window is minimized, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Window handle>: (Integer)`**

Handle of the window to test. This handle is returned by [SysWinHandle](../WDLang1/3073007.md).
