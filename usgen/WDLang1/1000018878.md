
## ErrorBuild (Function)

***In french: ErreurConstruit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a custom error message in a system error window.

To close the window, the user must click the OK button to validate.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV allows you to apply the theme of your project to this dialog box. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a web service, **ErrorBuild** is used to define the error returned by the web service. If **ErrorBuild** is called multiple times, the error messages are concatenated.

## Syntax

`ErrorBuild(<Format string> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Format string>: (Character string)`**

Character string to display containing optional parameters (%1 to %n). To display the % character, this character must be typed twice (%%).

**`<Parameter 1>: (Optional character string)`**

First parameter that will be inserted into the formatted character string.
&lt;Parameter 1&gt; will replace the %1 character, &lt;Parameter 2&gt; will replace the %2 character, etc.
The number of specified parameters must be equal to or greater than the number of parameters used in &lt;Format string&gt;.
If &lt;Format string&gt; contains more parameters, the additional parameters will be replaced with empty strings.



**`<Parameter N>: (Optional character string)`**

Nth parameter that will be inserted into the formatted character string.
&lt;Parameter 1&gt; will replace the %1 character, &lt;Parameter 2&gt; will replace the %2 character, etc.
The number of specified parameters must be equal to or greater than the number of parameters used in &lt;Format string&gt;.
If &lt;Format string&gt; contains more parameters, the additional parameters will be replaced with empty strings.

## Remarks




### Features of the dialog box
<a name="features_the_dialog_box_ELTPARAGRAPHE000100"></a>



- The title of the dialog box corresponds to the title of the current window (or page).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To comply with the system specifications, the title of dialog box is empty by default. To define this title, use [NextTitle](../WDLang1/3038043.md).

- To modify or define the title of dialog box, use [NextTitle](../WDLang1/3038043.md).




- The message is aligned to the left.

- The button caption depends on the runtime language of Windows.

- The maximum number of characters cannot exceed 4096. If a larger string is passed as parameter, it will be truncated.

- The icon displayed (white cross) cannot be modified.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To customize this dialog box** (and all the system dialog boxes in your application), check "Customize system windows (Info, YesNo, Confirm, Dialog)" in the "Style" tab of the project description. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **To customize this dialog box** (and all the system dialog boxes in your site), check "Apply the theme to the dialog boxes (YesNo and OKCancel)" in the "Theme" tab of the project description window. 
<a name="NOTE0_4"></a>




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000117"></a>

- Timers ([TimerSys](../WDLang1/3015006.md)) are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Windows events are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [DelayBeforeClosing](../WDLang1/3038040.md) limits how long the message is displayed. The dialog box is automatically closed. For question or confirmation dialog boxes, the default button corresponds to the expected answer.

- The caption of the button is displayed in the language used by Windows on the current computer.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function must not be used: 

	- in the "Resize" event of the window. Otherwise, the application will be locked.

	- in the "Change the orientation" event of the window. 

	- in the "Move to the foreground" event associated with the project. 
			 Note: However, the function can be used in the "Move to the foreground" event of a window. 

	- in a thread.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000341"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ErrorBuild** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
