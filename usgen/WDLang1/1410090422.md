


## &lt;Code Editor&gt;.DeleteAll (Function)

***In french: &lt;Editeur de code&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the contents of the Code Editor control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Clears the Code Editor control
CODEEDT_Example.DeleteAll()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Code Editor control>.DeleteAll()`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
