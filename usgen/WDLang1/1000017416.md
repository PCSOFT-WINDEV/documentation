


## &lt;List Box&gt;.DeleteAll (Function)

***In french: &lt;Liste&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Clears a List Box, ListView or Combo Box control populated programmatically.

**Note**: The **&lt;List Box&gt;.DeleteAll** function can be used for both single-selection and multi-selection List Box controls..
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Attention**: The List (or Combo) Box control will only be emptied on the page displayed in the browser.. For more details, see Remarks.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete all elements from the "LIST_CustomerList" control
LIST_CustomerList.DeleteAll()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<List Box control>.DeleteAll()`
---

**`<List Box control>: (Control name)`**

Name of List Box (or Combo Box) control to use.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Deletion on the browser
<a name="deletion_the_browser_ELTPARAGRAPHE000209"></a>

When deleting elements from a List Box (or Combo Box) control in browser code, these elements are deleted on the page displayed in the browser only. In order for these elements to be deleted from the server, **&lt;List Box&gt;.DeleteAll** must be run on the server.

Calling **&lt;List Box&gt;.DeleteAll** in browser code is useful when using [AJAX technology](../WDLang2/3055101.md), in "Programmed AJAX" mode (via [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)).

**Reminder** In "automatic and immediate AJAX" mode, simply pass the server processing containing the function **&lt;List Box&gt;.DeleteAll FUNCTION** in automatic AJAX mode. That's it! No additional programming is required. For more details, see [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000241"></a>

- To delete all the rows from a Table control, use [&lt;Table&gt;.DeleteAll](../WDLang1/1000024292.md).

- **&lt;List Box&gt;.DeleteAll** can be used on a "Combo Box" table column.

- For the editable Combo Box controls, the input area is cleared.
