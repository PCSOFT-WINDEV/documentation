
## Control (Variable type)

***In french: Champ***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Control** type is used to define the characteristics of a control. This control can be dynamically created using [ControlCreate](../WDLang1/1000020876.md) or a control in a window or report. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The [ControlCreate](../WDLang1/1000020876.md) function is not available.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Dynamically create a control in a window
c is Control
c <- ControlCreate("BUTTON_1", typBouton, 30, 40, 140, 20) // Caution, not '='
c.Caption = "Click here"
c.Process[trtClick] = myProcedure
```

## Remarks
<a name="NOTE0_1"></a>


### Declaring a Control variable
<a name="declaring_control_variable_ELTPARAGRAPHE000053"></a>The following syntax is used to declare a Control variable: 


```txt
<Variable name> is Control
```
Example: 

```wl
c is Control
```


In the declaration of a variable of type Control, you can specify the type of control using the following syntax:
```txt
<Variable name> is Control <control type = <Control type>>
```
where &lt;Control type&gt; is the constant that corresponds to the type of control to be created (see below). 

Example: 

```wl
MyControl is Control <control type = typButton>
```

### Assigning a value to a Control variable
<a name="assigning_value_control_variable_ELTPARAGRAPHE000085"></a>

A **Control** variable can be used to manipulate: 

- a control in a window or report. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a control created with the [ControlCreate](../WDLang1/1000020876.md) function. 




You can assign a value to a Control variable using the '<-' operator. 

Examples: 


```wl
// Assign an existing control
c is Control
c <- EDT_Edit1
```



```wl
// Assign a value using an indirection
// The variable references the EDT_EDIT2 control
c <- {"EDT_EDIT2"}
```


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Assign a control created with ControlCreate
c is Control
c <- ControlCreate("BUTTON_1", typButton, 30, 40, 140, 20)
```


**Caution**: The '=' operator must not be used to assign a value to a variable of type **Control**. This operator is used to transfer the value of a control into another control of the same type. For example: 


```wl
// Assign an existing control
c is Control
c <- EDT_Edit1

// Modify the value 
c = EDT_Edit3 // Equivalent code: EDT_Edit1.Value = EDT_Edit3.Value
c = "Text" // Equivalent code: EDT_Edit1.Value = "Text"
```


**Note**: To determine if a value has been assigned to a variable of type **Control**, use the [Type](../Proprietes/2510131.md) property on the variable. Example: 

```wl
PROCEDURE ValueAssignedToControlVariable(varControl is Control): boolean
// Check whether a control has been assigned to a variable of type Control 
sType is int
WHEN EXCEPTION IN
	sType = varControl..Type
DO
	RETURN False
END
RETURN True
```

### Using a Control variable in a procedure
<a name="using_control_variable_procedure_ELTPARAGRAPHE000126"></a>

The **Control** type can be a parameter of a procedure. 

**Method 1**: Syntax without the type of the control:

- procedure code: 
	
	```wl
	PROCEDURE MyProcedure(C is Control)
	C = "It is " + TimeSys()
	```


- procedure call: 
	
	```wl
	MyProcedure(EDT_Edit1)
	```



In this case, the type of the control is not checked at compile time. 

**Method 2**: Syntax with the type of the control:

- procedure code: 
	
	```wl
	PROCEDURE MyProcedure(C is Control <control type = typInputDate>)
	C = "It is " + TimeSys()
	```


- procedure call: 
	
	```wl
	MyProcedure(EDT_Edit1)
	```



**Advantage**: If the procedure call uses a control of an unexpected type, a compilation error is displayed: "The type of control passed as parameter is not compatible with the expected type."
<a name="NOTE0_4"></a>


### Optimizing processes that use indirections
<a name="optimizing_processes_that_use_indirections_ELTPARAGRAPHE000157"></a>

The **Control** type can be used to optimize processes that use indirections. You can write for example: 


```wl
C is Control <-{s, indControl}
C.Width = 10
C.Height = 20
```


rather than the following code: 


```wl
{s, indControl}..Width = 10
{s, indControl}..Height = 20
```





<a name="NOTE0_5"></a>


### Properties associated with a Control variable
<a name="properties_associated_with_control_variable_ELTPARAGRAPHE000171"></a>

The **Control** type can be used to manipulate all types of controls in a window or report. The available properties depend on the type of control used. 

For example, if a variable of type **Control** is used to manipulate an Edit control, all the Edit control WLanguage properties will be available for that variable. 
By specifying the type of control when declaring the **Control** variable, only the properties of that type will be suggested in the code editor.

To learn more about the properties of a control, go to the corresponding page and click "See also". For more details, see [Window controls](../WDChamp/1013081.md). 
<a name="NOTE0_6"></a>


### Functions that use a Control variable
<a name="functions_that_use_control_variable_ELTPARAGRAPHE000188"></a>All the WLanguage functions that manipulate the controls can be used on a **Control** variable. However, only the WLanguage functions corresponding to the type of control used will be available. 
By specifying the type of control when declaring the **Control** variable, only the functions of that type will be suggested in the code editor.

For example, if a variable of type **Control** is used to manipulate a Table control, all the TableXXX functions will be available for that variable. 

Note: [ControlExist](../WDLang1/3025035.md) can be used on a variable of type **Control** to check for a given control.
