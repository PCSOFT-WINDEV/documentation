


## WinInHeight (Function)

***In french: FenIntHaut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the interior height of a window.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) For Windows windows: This internal height does not include the title bar or the frame.. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Maximize moving windows: Action Bar control and system bar taken into account: 

	- If the Action Bar control overlaps the other controls (style option), its height is ignored. The vertical height of the window starts below the system bar. In this case, **WinInHeight** returns the same result as [WinOutHeight](../WDLang1/3038032.md). 

	- If the system bar overlaps the other controls (style option), its height is ignored. The interior height of the window starts at the top of the screen. 




- For non-maximized moving windows and popup windows: This height corresponds to the height of the window without its frame.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=FenExtInt_Mobile.gif)

## Example


```wl
// Hauteur interne de la fenêtre "FEN_SaisieClient"
ResHauteurInterne = FenIntHaut(FEN_SaisieClient)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = WinInHeight([<Window>])`
---

**`<Result>: (Integer)`**

Interior height of the window (in pixels).

**`<Window>: (Optional window name)`**

Name or alias of the window to be used. If this parameter is not specified or if it is an empty string (""), the interior height of the current window is returned.
