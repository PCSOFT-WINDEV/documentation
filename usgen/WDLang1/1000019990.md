


## &lt;Multimedia&gt;.Status (Function)

***In french: &lt;Multimédia&gt;.Etat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the status of the media file played in the Multimedia control.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Note** Depending on the type of video and browser configuration, this function may not be supported. In this case, the call to this function will have no effect and no error will be triggered.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MyFile is string = "C:\My music\mysong.mp3"

MM_Multimedia1.Open(Myfile)
...
IF MM_Multimedia1.Status() = MultimediaStatusPause THEN
	MM_Multimedia1.Beginning()
	MM_Multimedia1.Play()
END
...
MM_Multimedia1.Close()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Multimedia control>.Status()`
---

**`<Result>: (Integer constant)`**

Status of the media file currently found in the Multimedia control.


|   |   |
| --- | --- |
| *MultimediaStatusPause* | The file is paused. |
| *MultimediaStatusPlay* | The file is opened and it is currently played. |
| *MultimediaStatusStop* | The file is stopped.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Depending on video type and browser configuration, this constant may never be returned: a loaded media file may only be playing or paused. |



**`<Multimedia control>: (Control name)`**

Name of the Multimedia control to be used.
