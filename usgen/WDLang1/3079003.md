


## Video functions
			



**Note**: These functions are also available in prefix syntax ([Camera/Video functions (prefix syntax)](../WDLang1/1000022386.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following functions are used to manage videos:



|   |   |
| --- | --- |
| [VideoCapture](../WDLang1/3079007.md) | Captures the images received from the camera:<br><br>- as an image: take a photo.<br><br>- as a video: record a video.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoConfigure](../WDLang1/3079009.md) | Allows you to configure the video capture driver. |
| [VideoDisplay](../WDLang1/3079004.md) | Displays in a Camera field the camera preview stream currently being transmitted by a web camera or by the mobile device camera.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoGenerateThumbnail](../WDLang1/1000020268.md) | Generates a thumbnail of the specified photo or video. |
| [VideoListDriver](../WDLang1/3079008.md) | Lists the video capture drivers installed on the current computer. |
| [VideoListParameter](../WDLang1/1000019695.md) | Lists the values supported by the device camera for a given parameter.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoParameter](../WDLang1/1000019694.md) | Returns or modifies the value of a parameter for the device camera.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoRequestPermission](../WDLang1/1000022355.md) | Requests permission to use the device's camera. |
| [VideoSetDriver](../WDLang1/3079010.md) | Connects the "Camera" control to a specific driver for video capture. |
| [VideoStartApp](../WDLang1/1000019368.md) | Starts the device's native camera application to record a video or to take a photo. |
| [VideoStartDecoding](../WDLang1/1000022163.md) | Starts decoding bar codes in a Camera control. |
| [VideoStatus](../WDLang1/3079006.md) | Returns the status of a Camera control.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoStop](../WDLang1/3079001.md) | Stops the video preview or video recording in a Camera control.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Function kept for "Version-26-compatible" Camera controls. |
| [VideoStopDecoding](../WDLang1/1000022164.md) | Stops decoding a bar code in a Camera control. |





<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


### Remarks: 
<a name="remarks_ELTPARAGRAPHE000041"></a>

- The Videoxxx and Cameraxxx functions are identical. 

- [dSaveImageJPEG](../WDLang1/3029038.md) saves the image from a Camera control:

	- in a JPEG file.

	- in memory.




- [dSaveImageBMP](../WDLang1/3029026.md) saves the image from a Camera control:

	- in a BMP file.

	- in memory.
