
## SysReleaseDC (Function)

***In french: SysLibèreDC***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Frees the current DC (Device Context) retrieved by [SysGetDC](../WDLang1/3073023.md).

**Remark**: If a DC (Device Context) has been retrieved during an application and no release has been made, the current DC (Device Context) is automatically released at the end of the application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Libération du DC
SysLibèreDC()
```
