


## fEncrypt (Function)

***In french: fCrypte***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>

<a name="description"></a>
Encrypts a file in binary or ASCII format.

**Note** This file can be decrypted with [fDecrypt](../WDLang1/3036018.md).

## Syntax

`<Result> = fEncrypt(<Path of file to encrypt> , <Path of encrypted file> , <Password> [, <Type of encryption> [, <Format of encrypted file>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if encryption has been performed, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Path of file to encrypt>: (Character string)`**

Name and full (or relative) path of the file to encrypt (up to 260 characters). A UNC path can be used.


![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In iOS/iPadOS, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories.

Name and full (or relative) path of the encrypted file (up to 260 characters). A UNC path can be used.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).

**`<Password>: (Character string or Secret string)`**

Password used to encrypt the file. This password will be used to decrypt the encrypted file ([fDecrypt](../WDLang1/3036018.md)). A long password provides better encryption security.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications.

**`<Type of encryption>: (Optional constant)`**

Indicates the type of encryption:


|   |   |
| --- | --- |
| *encryptFast*<br>(Default value) | Priority is given to the encryption speed (algorithm on 128 bits).<br><br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The algorithm used will be a Blowfish algorithm.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is not available.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The algorithm used will be a Blowfish algorithm with 16 rounds. |
| *encryptNone* | No encryption is performed. |
| *encryptRC516* | Priority is given to the encryption security (RC5 algorithm on 16 rounds).<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant has no effect. |
| *encryptSecure* | Priority is given to the encryption security (RC5 algorithm on 128 bits).<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The algorithm used will be a PBE algorithm (Password Based Encryption).<br><br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The algorithm used will be a 128-bit RIJNDAEL algorithm. |



**`<Format of encrypted file>: (Optional Integer constant)`**

Indicates the format of the encrypted file:


|   |   |
| --- | --- |
| *encodeBASE64* | BASE 64 format. <br>The file is encrypted with the BASE64 algorithm. The encrypted file will be larger (about 30%) than the initial file. <br>This format can be used to insert an encrypted file into the email body for example. |
| *encodeNone* or *False* | Binary format. <br>The encrypted file may contain non-printable characters. The file will be larger (about 4 bytes) than the initial file. |
| *encodePCS* or *True*<br>(Default value) | ASCII format. <br>The encrypted file will contain printable characters only. The encrypted file will be larger (about 30%) than the initial file. <br>This format can be used to insert an encrypted file into the email body for example. |
| *encodeUUEncode* | UUEncode format. <br>The file is encrypted with the UUEncode algorithm. The encrypted file will be larger (about 30%) than the initial file. <br>This format can be used to insert an encrypted file into the email body for example. |

## Remarks




### Error handling
<a name="error_handling_ELTPARAGRAPHE000245"></a>

**fEncrypt** throws an error in the following cases:

- the file to encrypt does not exist, 

- the file to encrypt is locked, 

- the path of the file to encrypt is invalid, 

- &lt;Password&gt; is an empty string, 

- the user has no read rights on the file to encrypt, 

- the user has no write rights on the encrypted file.

### Operating mode in Windows Vista (and later)
<a name="operating_mode_windows_vista_and_later_ELTPARAGRAPHE000448"></a>

If this function does not work properly in Windows Vista (and later), check whether the file or directory used is not in one of the system directories (Windows directory or "Program Files" directory).

**In Windows Vista (and later), with the [UAC mechanism](../Editeurs/2025014.md) (User Account Control) enabled**, you must have administrator privileges to handle and/or modify the files or directories in system directories (Windows directory or "Program Files" directory).

**Programming tip**: If you need to manipulate / modify files or directories, without needing administrator privileges, it is advisable:

- avoid writing to the Windows directory or to the "Program Files" directory, 

- use the system directory of the application (returned by [SysDir](../WDLang1/3073026.md) with the *srAppDataCommun* constant, for example).




**Remark**: Under Windows Vista (and higher), the virtualization mechanism makes applications Vista-compatible.. If the file is created in a system directory without having sufficient rights, this file will actually be created in another directory (C:\\Users\\&lt;LOGIN&gt;AppData\\Local\\VirtualStore\\Windows\\). In this case, the file cannot be shared between several applications.

### Encrypting/Decrypting a character string
<a name="encryptingdecrypting_character_string_ELTPARAGRAPHE000271"></a>

To encrypt/decrypt a character string, use [Encrypt](../WDLang1/3024014.md) and [Decrypt](../WDLang1/3024035.md).
<a name="NOTE0_4"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Encryption in PHP**
In PHP, the BlowFish encryption (*encryptFast* constant) and the RINJDAEL encryption (*encryptSecure* constant) are based on the MCrypt library. This library is commonly used by the PHP hosting providers and therefore it is always enabled. This library can be downloaded from the PHP site.

To enable (if necessary) this library locally, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must include the "extension=php_mcrypt.dll" line.

- the php_mcrypt.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.



<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **Encryption in Android/Java and decryption by a WINDEV application (or conversely)**
Warning: the encryption/decryption algorithms used in Java and Android are not the same as those used by WINDEV. Therefore, you cannot encrypt a file in Java or Android and decrypt it with WINDEV and vice versa.
