
## AIChatStopRequest (Function)

***In french: ChatIAStopDemande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops a request in progress in the AI Chat control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click "Stop"
AIChatStopRequest(CHATIA_MyChat)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`AIChatStopRequest(<AI Chat control>)`
---

**`<AI Chat control>: (Control name)`**

AI Chat control used.
