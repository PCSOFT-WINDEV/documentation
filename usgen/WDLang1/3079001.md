


## VideoStop (Function)

***In french: VidéoArrête***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops the video preview or video recording in a Camera control.

ELTSPECIAL000198 ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)
	<B><B><B>Warning</B></B></B>

	 **Starting with version 27, this function is deprecated for Android and iOS applications**. This function is kept only for Camera controls created with earlier versions and with the "Version-26-compatible mode" option enabled ("General" tab of the control description window).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stops the camera preview stream
// in the "CAM_Kitchen" control
ResStop = VideoStop(CAM_Kitchen, viStopDisplay)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = VideoStop(<Camera control> [, <Action to stop>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the camera preview stream or the video recording in the Camera control is stopped properly,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Camera control>: (Control name)`**

Name of the Camera control to be used.

**`<Action to stop>: (Optional integer constant)`**

Type of action to stop:


|   |   |
| --- | --- |
| *viStopAll*<br>(Default value) | Stops the camera preview stream and the video recording. The corresponding file is generated. The specified Camera control becomes empty. |
| *viStopCapture* | Stops recording the video. The corresponding file is generated. |
| *viStopDisplay* | Stops the camera preview stream. The specified Camera control becomes empty. |

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000079"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) To use this function, a "camera" must be connected to the current computer.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This function requires a device equipped with a camera. It can also be used in the Android emulator.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function requires a device equipped with a camera.


**Note**: This function is equivalent to [CameraStop](../WDLang1/1410086596.md).
<a name="NOTE0_2"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000106"></a>

- To save the video captured by a web camera, use [VideoCapture](../WDLang1/3079007.md).

- To display the video captured by a web camera in a Camera control, use [VideoDisplay](../WDLang1/3079004.md).



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000124"></a>

This function changes the permissions required by the application.

Permission required: CAMERA.

This permission allows the applications to access the camera.
