
## jsonReader (Variable type)

***In french: jsonReader***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **jsonReader** type is used to loop through large JSON documents with optimal performance and low memory usage. You can read the characteristics of this JSON document using different WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
JSON_Reader is jsonReader = JSONOpenReader("file.json")
FOR EACH JSON_Reader IN-DEPTH
	...
END
```





<a name="PROPS"></a>

## Properties


### Properties specific to jsonReader variables
<a name="properties_specific_jsonreader_variables_ELTPARAGRAPHE000030"></a>

The following properties can be used to handle a JSON document:

| Property name | Type used | Effect |
| --- | --- | --- |
| Name | Character string | <br><br>- Member name, if the current element is a member of an object. <br><br>- Empty string ("") if the current element is the root or is an array element. <br><br><br><br><br>**This property is read-only.** |
| Depth | Integer | Depth of the current element.<br><br>**This property is read-only.** |
| JSONSource | Character string | JSON source corresponding to the current element. <br><br>**This property is read-only.** |
| Parent | jsonReader | Parent element in an in-depth loop. <br><br>**This property is read-only.** |
| Type | Integer | Type of the current element:<br><br>- *wlBoolean*: Simple JSON boolean value. <br><br>- *wlUnicodeString*: Simple JSON string. <br><br>- *wlInt*: Simple JSON integer.  <br><br>- *wlNull*: Simple JSON Null value. <br><br>- *wlNumeric*: Simple JSON decimal value. <br><br>- *wlVariantObject*: JSON object. <br><br>- *wlVariantArray*: JSON array.<br><br>- *wlEmpty*: Reader not initialized.<br><br><br><br><br>**This property is read-only.** |
| Value | All types | Value if the current element is a simple type (other than object or array). <br><br>**This property is read-only.** |
