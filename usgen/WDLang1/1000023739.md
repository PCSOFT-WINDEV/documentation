


## &lt;Spreadsheet&gt;.StyleSelection (Function)

***In french: &lt;Tableur&gt;.StyleSélection***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns or modifies the style of selected cells in a Spreadsheet control found in a window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// CLICK on [BOLD]
TBLR_Tableur.StyleSelection(tblrGras, True)


// Displays the B1 cell in bold
PSHEET_Spreadsheet.SelectPlus("B1")
TBLR_Tableur.StyleSelection(tblrGras, True)
```

```wl
sRes is boolean = PSHEET_Spreadsheet.StyleSelection(psheetBold)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the selection style

`<Result> = <Spreadsheet control>.StyleSelection(<Attribute>)`
---

**`<Result>: (Type of expected result)`**

Requested attribute.

**`<Spreadsheet control>: (Control name)`**

Name of the Spreadsheet control to be used.

**`<Attribute>: (Integer constant)`**

Attribute to find out: 


|   |   |
| --- | --- |
| *psheetAlignmentH* | Horizontal alignment. <br><br>In this case, &lt;Result&gt; can correspond to: <br><br>- *chCentre* centered alignment. <br><br>- *chRight* Right alignment. <br><br>- *chLeft* Left alignment.<br><br><br> |
| *psheetAlignmentV* | Vertical alignment. <br><br>In this case, &lt;Result&gt; can correspond to: <br><br>- *cvBas* Bottom alignment. <br><br>- *cvTop* Top alignment. <br><br>- *cvMiddle* Alignment in the middle.<br><br><br> |
| *psheetAutomaticLineWrap* | Automatic line wrap. <br><br>In this case, &lt;Result&gt; can correspond to: <br><br>- <u><u><u><u>True</u></u></u></u> to use the automatic line wrap,<br><br>- <u><u><u><u>False</u></u></u></u> not to use the automatic line wrap. <br><br><br> |
| *psheetBackgroundColor* | Text background color. <br><br>In this case, &lt;Result&gt; can correspond to: <br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a WLanguage preset color](../WDLang5/3010002.md).<br><br><br> |
| *psheetBold* | Bold text in the cell.<br><br>In this case, &lt;Result&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to display in bold,<br><br>- <u><u><u><u>False</u></u></u></u> not to display in bold.<br><br><br> |
| *psheetFontAngle* | Text rotation angle. <br><br>In this case, &lt;Result&gt; can correspond to an integer included between -180 and +180. |
| *psheetFontName* | Name of font used. <br><br>In this case, &lt;Result&gt; can correspond to a character string containing the font name. |
| *psheetFontSize* | Font size. <br><br>In this case, &lt;Result&gt; corresponds to the font size (integer). |
| *psheetItalic* | Italicized text in the cell. <br><br>In this case, &lt;Result&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to display in italic,<br><br>- <u><u><u><u>False</u></u></u></u> not to display in italic.<br><br><br> |
| *psheetStrikeOut* | Strikethrough text in the cell. <br><br>In this case, &lt;Result&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to strike out,<br><br>- <u><u><u><u>False</u></u></u></u> not to strike out.<br><br><br> |
| *psheetTextColor* | Text color. <br><br>In this case, &lt;Result&gt; can correspond to: <br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a WLanguage preset color](../WDLang5/3010002.md).<br><br><br> |
| *psheetUnderlined* | Underlined text in the cell. <br><br>In this case, &lt;Result&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to underline,<br><br>- <u><u><u><u>False</u></u></u></u> not to underline.<br><br><br> |

### Modifying the selection style

---

**`<Spreadsheet control>: (Control name)`**

Name of the Spreadsheet control to be used.

**`<Attribute>: (Integer constant)`**

Attribute to modify. This element can correspond to: 


|   |   |
| --- | --- |
| *psheetAlignmentH* | Horizontal alignment. <br><br>In this case, &lt;Value&gt; can correspond to: <br><br>- *chCentre* centered alignment. <br><br>- *chRight* Right alignment. <br><br>- *chLeft* Left alignment.<br><br><br> |
| *psheetAlignmentV* | Vertical alignment. <br><br>In this case, &lt;Value&gt; can correspond to: <br><br>- *cvBas* Bottom alignment. <br><br>- *cvTop* Top alignment. <br><br>- *cvMiddle* Alignment in the middle.<br><br><br> |
| *psheetFontAngle* | Text rotation angle. <br><br>In this case, &lt;Value&gt; can correspond to an integer included between -180 and +180. |
| *psheetStrikeOut* | Strikethrough text in the cell. <br><br>In this case, &lt;Value&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to strike out,<br><br>- <u><u><u><u>False</u></u></u></u> not to strike out.<br><br><br> |
| *psheetBackgroundColor* | Text background color. <br><br>In this case, &lt;Value&gt; can correspond to: <br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a WLanguage preset color](../WDLang5/3010002.md).<br><br><br> |
| *psheetTextColor* | Text color. <br><br>In this case, &lt;Value&gt; can correspond to: <br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a WLanguage preset color](../WDLang5/3010002.md).<br><br><br> |
| *psheetBold* | Bold text in the cell. <br><br>In this case, &lt;Value&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to display in bold,<br><br>- <u><u><u><u>False</u></u></u></u> not to display in bold.<br><br><br> |
| *psheetItalic* | Italicized text in the cell. <br><br>In this case, &lt;Value&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to display in italic,<br><br>- <u><u><u><u>False</u></u></u></u> not to display in italic.<br><br><br> |
| *psheetFontName* | Name of font used. <br><br>In this case, &lt;Value&gt; can correspond to a character string containing the font name. |
| *psheetAutomaticLineWrap* | Automatic line wrap. <br><br>In this case, &lt;Value&gt; can correspond to: <br><br>- <u><u><u><u>True</u></u></u></u> to use the automatic line wrap,<br><br>- <u><u><u><u>False</u></u></u></u> not to use the automatic line wrap. <br><br><br> |
| *psheetUnderlined* | Underlined text in the cell. <br><br>In this case, &lt;Value&gt; can correspond to:<br><br>- <u><u><u><u>True</u></u></u></u> to underline,<br><br>- <u><u><u><u>False</u></u></u></u> not to underline.<br><br><br> |
| *psheetFontSize* | Font size. <br><br>In this case, &lt;Value&gt; corresponds to the font size (integer). |



**`<Value>: (Variant)`**

Value that will be given to the attribute.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The modification operation is added to the list of operations to be undone: the user can undo this operation via the context menu or by pressing Ctrl + Z.

- This function can only be used on a Spreadsheet control found in a window.
