


## &lt;List variable&gt;.Info (Function)

***In french: &lt;Variable File&gt;.Info***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the type and number of elements in a WLanguage list.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// List whose elements are instances of MyClass
MyList is list of MyClass
// Retrieve the definition of the type of elements
MyDefinition is Definition 
MyDefinition = MyList.Info(tiElementDefinition)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <WLanguage list>.Info(<Information>)`
---

**`<Result>: (Variant)`**

Requested information.

**`<WLanguage list>: (List)`**

Name of the [List](../WDLang1/1514023.md) variable to be used.

**`<Information>: (Integer constant)`**

Information to retrieve:


|   |   |
| --- | --- |
| *tiElementDefinition* | &lt;Result&gt; is a [Definition](../WDLang1/1000019540.md) variable and it contains the definition of the type of elements.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *tiElementType* | &lt;Result&gt; is an Integer variable and it contains the type of the elements found in the list. This result is compatible with [TypeVar](../WDLang1/3013056.md).<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiTotalNumber* | &lt;Result&gt; is an Integer variable and it contains the total number of elements in the list. |
