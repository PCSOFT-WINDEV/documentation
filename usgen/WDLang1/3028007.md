
## DDEItem (Function)

***In french: DDEItem***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies the item affected by a DDE event.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Equivalent to: Item = _DDE.Item
Item = DDEItem()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = DDEItem([<Connection ID>])`
---

**`<Result>: (Character string)`**

Item affected by the DDE event.

**`<Connection ID>: (Optional integer)`**

Connection identifier, returned by [DDEConnect](../WDLang1/3028015.md). If this parameter is not specified, **DDEItem** uses the last connection handled.
