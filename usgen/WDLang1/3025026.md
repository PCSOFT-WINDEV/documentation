
## Reset (Function)

***In french: RAZ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reinitializes:

- all controls found in the current window or in the current page (including the groups of controls, the supercontrols, the popups and the internal windows).

- the controls found in a group of controls, a supercontrol, a popup, an internal window or an internal page.




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Reinitializes all the controls to their initial value. The initial value of controls corresponds to the value of controls during the last page display on the browser (first page display or display during a refresh operation, ...).

## Example


```wl
// Add a customer
ScreenToFile()
HAdd(Customer)
// Reinitialize controls to enter a new customer
Reset(True)
```

## Syntax

### Reinitializing all the controls in the current window or page

`RESET([<Management of Special controls>])`
---

**`<Management of Special controls>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u>:

	- Edit controls and Static Text controls are reinitialized to their initial value, 

	- List, Combo, Table and RepeatString fields (file or memory) are not cleared or reset.. They keep their current content.




- <u><u><u><u>False</u></u></u></u> (default value):

	- Edit controls and Static Text controls are reinitialized to their initial value, 

	- the List, Combo Box control, Table and RepeatString "memory" fields are cleared and reset to their initial contents,

	- browsing List Box, Combo Box, Table and Looper controls are only reinitialized (they are not cleared).







![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available: all page fields are reset to their initial values. The initial value of controls corresponds to the value of controls during the last page display on the browser (first page display or display during a refresh operation, ...).

### Reinitializing all the controls found in a group of controls, a supercontrol, an internal window or an internal page

`RESET(<Element name> [, <Management of Special controls>])`
---

**`<Element name>: (Character string)`**

Name of element whose controls will be reinitialized. Can correspond to: 

- Name of group of controls. 

- Name of supercontrol. 

- Name of internal window or page. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Name of control template.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Name of popup.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Name of group of controls to reinitialize.

**`<Management of Special controls>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u>:

	- Edit controls and Static Text controls are reinitialized to their initial value, 

	- List, Combo, Table and RepeatString fields (file or memory) are neither cleared nor reset.. They keep their current content.




- <u><u><u><u>False</u></u></u></u> (default value):

	- Edit controls and Static Text controls are reinitialized to their initial value, 

	- the List, Combo Box control, Table and RepeatString "memory" fields are cleared and reset to their initial contents,

	- browsing List Box, Combo Box, Table and Looper controls are only reinitialized (they are not cleared).  







![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available: all page fields are reset to their initial values. The initial value of controls corresponds to the value of controls during the last page display on the browser (first page display or display during a refresh operation, ...).

### File variables
<a name="file_variables_ELTPARAGRAPHE000167"></a>

The [HReset](../WDLang4/3044118.md) function is used to reset variables in HFSQL tables. To reset only the variables in HFSQL tables on a page, use the following code:


```txt
HRESET(<Nom de fichier de données>)
FileToPage()
```


**Warning** If fields are associated with table items, these items are marked with stars ("\*").

### Initialization process
<a name="initialization_process_ELTPARAGRAPHE000183"></a>

Do not confuse **Reset** and [PageInitialization](../WDLang2/3058025.md). Indeed:

- **Reset** resets the controls

- [PageInitialization](../WDLang2/3058025.md) resets the controls and runs the initialization processes.

### Table and Looper controls
<a name="table_and_looper_controls_ELTPARAGRAPHE000204"></a>

A Table or Looper control linked to a table can never be empty. This control is automatically initialized with the values of the linked items in the table.
<a name="NOTE0_4"></a>




### Limitations
<a name="limitations_ELTPARAGRAPHE000212"></a>

**Reset** does not reset the labels of the Button controls. 

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reset** has no effect on the following controls:

- Static Text control,

- Button control, 

- Image control.
