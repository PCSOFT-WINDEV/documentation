
## SpeechRecognitionDeleteCommand (Function)

***In french: ReconnaissanceVocaleSupprimeCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a voice command previously added with [SpeechRecognitionAddCommand](../WDLang1/1000020014.md).

**Remarks**: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) A speech recognition program must be installed on the runtime computer. A speech recognition program is supplied with Windows Vista. For the other systems, "Dragon Naturally Speaking" must be installed (tests run with version 9 "Preferred" or "standard").

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The service for speech recognition must be installed on the phone. The recognition of the voice commands must be triggered by [SpeechRecognitionTrigger](../WDLang1/1000020013.md). 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function can be used from iOS 10. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start the "Proc_Anim_Window" procedure if the voice command is recognized
Voice1ID is int
Voice1ID = SpeechRecognitionAddCommand("Proc_Anim_Window", "Animate the window")
...
// Delete the voice command
SpeechRecognitionDeleteCommand(Voice1ID)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`SpeechRecognitionDeleteCommand(<Identifier of the voice command>)`
---

**`<Identifier of the voice command>: (Integer)`**

Identifier of the voice command to delete. This identifier was returned by [SpeechRecognitionAddCommand](../WDLang1/1000020014.md).
