


## HTMLEditorInsertTable (Function)

***In french: EditeurHTMLInsèreTableau***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a table at the cursor position in an HTML Editor control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Insert a 4 x 3 table
HTMLEditorInsertTable(HTMEDT_MyHTMLEditor, 4, 3, "border=2")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HTMLEditorInsertTable(<HTML Editor control> , <Number of columns> , <Number of rows> [, <CSS style>])`
---

**`<HTML Editor control>: (Control name)`**

Name of the HTML Editor control used.

**`<Number of columns>: (Integer)`**

Number of columns to insert. 

**`<Number of rows>: (Integer)`**

Number of rows to insert. 

**`<CSS style>: (Optional character string)`**

CSS name of the style to apply to the inserted table. This parameter can also correspond to a style embedded in a tag &lt;table&gt; tag (for example: "border=1").
