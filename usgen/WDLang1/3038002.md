


## MenuUnMark (Function)

***In french: MenuDémarque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Removes the checkmark ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Marque.gif) displayed in front of the menu option (context menu or drop-down menu).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Démarquage de l'option "OPT_BarreIcone"
MenuDémarque(OPT_BarreIcone)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MenuUnmark([<Window>, ] <Menu option>)`
---

**`<Window>: (Optional window name)`**

Name of the window containing the menu option to unmark. 
If this parameter is not specified, **MenuUnMark** will handle the current window.

**`<Menu option>: (Option name)`**

Name of the menu option to unmark. This name is defined in the description window of the menu option. 
Note: This name must be specified without quotation marks..

<a name="NOTE0_1"></a>
