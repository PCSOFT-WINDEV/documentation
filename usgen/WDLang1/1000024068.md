
## Input suggestion functions (prefix syntax)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following functions are used to program input suggestion options in Edit controls using the prefix syntax:



|   |   |
| --- | --- |
| [&lt;Edit&gt;.AddAssistedInput](../WDLang1/1000023671.md) | Adds a row to the list of values available in the input suggestions of an Edit control. |
| [&lt;Edit&gt;.CloseAssistedInput](../WDLang1/1000023946.md) | Closes the list of input suggestion of an Edit control. |
| [&lt;Edit&gt;.ConfigureAssistedInput](../WDLang1/1000024064.md) | Specifies how to open and filter the autocomplete suggestion list. |
| [&lt;Edit&gt;.DeleteAllAssistedInput](../WDLang1/1000024065.md) | Clears the values in the suggestion list of an Edit control. |
| [&lt;Edit&gt;.OpenAssistedInput](../WDLang1/1000024063.md) | Opens the list of suggestions of an Edit control. |
