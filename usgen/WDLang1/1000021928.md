
## Constants for managing the modification of windows by the user
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


| Constant | Description | Used by properties/functions |
| --- | --- | --- |
| **weAddRepositionableNote** | Modification authorization: The end user can add a repositionable note in the window. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weAddWire** | Modification authorization: End-users can add a thread between several fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weAll** | Modification authorization: All modifications are authorized. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weChangeTooltip** | Modify permission: End-users can modify field tooltips. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weChangeWire** | Authorization to modify: End-users can modify wires between fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weModeDifferential** | Type of backup to be performed: Backup of all editing operations, including custom operations (function [WinEdDo](../WDLang1/1000021897.md)). All these operations will be replayed during the reload operation (like for a log). | [WinEdSave](../WDLang1/1000021848.md) |
| **weModeFull** | Type of backup to be performed: Backup of all fields and their current properties. This constant can be used on an internal window only. | [WinEdSave](../WDLang1/1000021848.md) |
| **weModeReposionableNote** | Type of backup to be performed: Backup of user-created repositionable notes only. This constant is equivalent to the "Export the notes" feature in the context menu of repositionable notes (AAF). | [WinEdSave](../WDLang1/1000021848.md) |
| **weMoveControl** | Modification authorization: end-users can move fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weMultiSelection** | Modification authorization: end-users can select several fields at a time. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weNone** | Modification authorization: No modification authorized. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **wePosition** | Modification authorization: end-users can move fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weResizeControl** | Modification authorization: End-users can resize fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weSelection** | Authorization to modify: End-users can select fields. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
| **weSize** | Modification authorization: end-users can modify field sizes. | [WinEditAllowed](../Proprietes/1000021850.md), [WinEditMode](../Proprietes/1000021824.md) |
