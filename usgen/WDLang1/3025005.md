
## EnumControl (Function)

***In french: EnumèreChamp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of Nth control found in the specified element. This element must be displayed. 

In a loop, this function is used to enumerate the controls found in an element.



![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The specified element can be a window, a report, a group of controls, a Tab control, a Looper control or a supercontrol. The Toolbar controls and the SideBar controls are not supported. 

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The specified element can be a page, a report, a group of controls, a Looper control, a break in a Looper control, a Cell control or a supercontrol

## Syntax

`<Result> = EnumControl(<"Parent" object> , <Control number> [, <Type of enumeration>])`
---

**`<Result>: (Character string)`**



- Name of control found,

- Empty string ("") if no control was found.




**`<"Parent" object>: (Character string)`**

Name of the "parent" object (containing the control). This parameter corresponds to the name of a window, a Looper control, a break in a Looper control, a group, a Tab control, a supercontrol o a report.

If the "parent" object is a Tab field, the following notation should be used: &lt;Tab field name&gt;[&lt;Tab pane number&gt;]. For example: ONG_Onglet1[2].

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)  Name of the "parent" object (containing the control). This parameter corresponds to the name of a page, a report, a group of controls, a Looper control, a break in a Looper control, a Cell control or a supercontrol.

**`<Control number>: (entier)`**

Number of the control whose name you want to get. Each control is associated with a number. This number corresponds to:

- the creation order of the controls (by default) if the type of enumeration is performed by the *byCreationOrder* constant

- the tab order (which means the order in which the controls gain focus in the "parent" object) if the type of enumeration is performed with the *byTabOrder* constant. 
	The F5 key is used to see the navigation order in the window editor and in the page editor




**`<Type of enumeration>: (Optional Integer constant)`**

Order in which the enumeration is performed:



|   |   |
| --- | --- |
| *byCreationOrder*<br>(Default value) | Enumeration performed according to the creation order of controls (in the editor or by [ControlClone](../WDLang1/3025017.md)). |
| *byTabOrder* | Enumeration performed according to the navigation order with the tab key (Tab). The controls that are not accessible with the tab key (Tab) are listed at the end. |
| *byZOrder* | Enumeration performed according to the Z-index of controls, from the lowest one to the highest one. |


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter is not available.

## Remarks




### Belonging of controls
<a name="belonging_controls_ELTPARAGRAPHE000150"></a>

Only the controls that directly belong to the specified "parent" object are enumerated.

For example, if &lt;"Parent" object&gt; corresponds to the name of a window or page, **EnumControl** only affects the controls that directly belong to this window or page. **EnumControl** cannot be used to retrieve the names of the controls belonging to the Tab controls or the supercontrols of this window (or page).






### Using retrieved controls
<a name="using_retrieved_controls_ELTPARAGRAPHE000163"></a>

When the name of a control retrieved by **EnumControl** is contained in a variable, the control itself can be used thanks to [indirection operators (braces { and })](../Motscles/1512005.md). Example:


```wl
// Name of control 7 in the page
ControlName is string = EnumControl(MyPage, 7)
// Control caption
ToastDisplay({ControlName}..Caption)
```
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) To use an indirection on a control of a page, the option "Allow indirections (slows the execution down)" must be checked ("Details" tab in the control description window).


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Tab controls with dynamic tabs
<a name="tab_controls_with_dynamic_tabs_ELTPARAGRAPHE000187"></a>

If &lt;"Parent" object&gt; corresponds to the name of a Tab control with dynamic tabs, the aliases of the dynamic tabs are enumerated. 
<a name="NOTE0_2"></a>




### List sub-elements
<a name="list_subelements_ELTPARAGRAPHE000195"></a>

The **EnumControl**function, used in a loop, lists the fields in a window.. 
However, this function does not go down the tree structure of fields: for example, it does not list the fields contained in the panes of a Tab Control in a window.
To go down the field tree structure, you can use the [EnumSubElement](../WDLang1/3064002.md) function:

```wl
j is int = 1
ResChamp is chain
ResChamp = EnumControl(MyWindow.Name, j)

WHILE ResControl <> ""
	j++
	Trace(ResControl)
	ItemList(MyWindow.Name + "." + ResChamp)
	ResChamp = EnumControl(MyWindow.Name, j)
END

INTERNAL PROCEDURE ElementList (ElementName)
	i is int = 1
	sReschampSousElt is chain
	sReschampSousElt = EnumSubElement(NomElt, i)
	TANTQUE sReschampSousElt <> ""
		i++
		Trace(NameElt+". "+sReschampSousElt)
		ElementList(ElementName +". "+ sFieldSubElt)
		sReschampSousElt = EnumSubElement(NomElt, i)
	END
END
```

<a name="NOTE0_3"></a>




### WLanguage error
<a name="wlanguage_error_ELTPARAGRAPHE000213"></a>

A WLanguage error occurs if:

- &lt;Control number&gt; is negative.

- &lt;Control number&gt; is greater than the number of controls found in &lt;"Parent" object&gt; +1. This is used to avoid the endless loops.

- &lt;"Parent" object&gt; is not a window, a page, a report, a group, a Tab control or a supercontrol.
