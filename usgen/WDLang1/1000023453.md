


## PDFReaderClose (Function)

***In french: LecteurPDFFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes and frees the PDF file displayed in a PDF Reader control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
PDFReaderClose(PDF_MyPDFReader)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PDFReaderClose(<PDF Reader control>)`
---

**`<PDF Reader control>: (Control name)`**

Name of PDF Reader control containing the PDF file to close.

<a name="NOTE0_1"></a>

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Starting with version 28, this function is not supported by 32-bit ARM processors. New PDF features require a 64-bit execution mode. 
If an application is to be run on devices with 32-bit ARM processors, it must be generated with WINDEV Mobile 27.
