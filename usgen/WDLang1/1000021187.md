


## &lt;Radio button&gt;.Insert (Function)

***In french: &lt;Sélecteur&gt;.Insère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts a new option into a Radio Button control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Inserts an option at position 2 
RADIO_Options.Insert(2, "Read a book on a tablet")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Radio Button control>.Insert(<Element index> , <Caption> [, <Sub-caption> [, <Image>]])`
---

**`<Result>: (Integer)`**



- Index of the inserted option. 

- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Radio Button control>: (Control name)`**

Name of Radio Button control into which the option will be inserted.

**`<Element index>: (Integer)`**

Index of the element to be inserted. 

If this parameter:

- is greater than the number of options in the Radio Button control, the option is added at the last position. 

- is equal to 1 or 0, the element is added before the first option in the Radio Button control.




**`<Caption>: (Character string)`**

Text of the option to be added.

**`<Sub-caption>: (Optional character string)`**

Sub-heading of option to be added. 
If this parameter is not specified, the new option has no subtext. 
If this parameter is specified, the sub-caption will be displayed even if the radio button uses a display mode without sub-caption.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This parameter is not available.

**`<Image>: (Optional character string)`**

Image associated with the option to add. 
If this parameter is not specified, the added option has no image.
If this parameter is specified, the image will be displayed only if the radio button uses a "Vista style" display mode (with image).
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This parameter is not available.

## Remarks


- The characteristics of added option can also be modified via the following properties used on the option: 

	- [Caption](../Proprietes/2510053.md) to modify the caption. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [SubCaption](../Proprietes/1000017232.md) to modify the sub-caption. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) [Image](../Proprietes/2510034.md) to modify the image. 




- When inserting options into a Radio Button control, the control size is not modified. The added options may not be visible if the control is not large enough. The control can be enlarged by the [Width](../Proprietes/2510059.md) and [Height](../Proprietes/2510050.md) properties.

- To add an option after the existing options, use [&lt;Radio button&gt;.Add](../WDLang1/1000021186.md). 

- When inserting an option: 

	- the index of the inserted option is &lt;Element index&gt;. 

	- if the radio button uses option numbering, the options following the inserted option are automatically renumbered. 




- **Use of returned values** If the picker uses returned values, you can define the value returned by the inserted option using the [ReturnedValue](../Proprietes/2510134.md) property. 
	For example: 
	
	```wl
	nIndex is int
	nIndex = RADIO_Option.Insert(2, "Read a book on a tablet")
	RADIO_Option[nIndex].ReturnedValue = "Tablet"
	// Select the new option
	RADIO_Option = "Tablet"
	```
