


## OrganizerMode (Function)

***In french: AgendaMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the display mode of an Organizer control: day, week, month, ...

Note: Use [OrganizerChangeMode](../WDLang1/1000019497.md) to change the display mode of the Organizer control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Toggles between daily display and monthly display
IF OrganizerMode(ORG_MyOrganizer) = orgzDay THEN
	OrganizerChangeMode(ORG_MyOrganizer, orgzMonth)
ELSE
	OrganizerChangeMode(ORG_MyOrganizer, orgzDay)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = OrganizerMode(<Organizer control>)`
---

**`<Result>: (Integer constant)`**

Time range displayed by the Organizer control:


|   |   |
| --- | --- |
| *orgzCustomNbDay* | Displays the Organizer control over a number of days specified by [OrganizerChangeMode](../WDLang1/1000019497.md).<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *orgzDay* | The Organizer control displays one day. |
| *orgzMonth* | The Organizer control displays a full month. |
| *orgzWeek* | The Organizer control displays a full week (or a partial week if a number of days was specified with [OrganizerChangeMode](../WDLang1/1000019497.md)). |
| *orgzWeekOn5* | The Organizer control displays a 5-day week (without weekend). |



**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.

## Remarks


### Compatibility
<a name="compatibility_ELTPARAGRAPHE000130"></a>

**OrganizerMode** replaces [OrganizerZoom](../WDLang1/1000018884.md) (kept for backward compatibility).


### Equivalences
<a name="equivalences_ELTPARAGRAPHE000141"></a>The following lines of code are equivalent: 

```wl
OrganizerChangeMode(ORG_Organizer, orgzWeek, 5)
```
and

```wl
OrganizerChangeMode(ORG_Organizer, orgzWeekOn5)
```
 

In both cases, **OrganizerMode** returns the *orgzWeekOn5* constant.
