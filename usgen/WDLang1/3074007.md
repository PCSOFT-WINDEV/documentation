


## TableInfoXY (Function)

***In french: TableInfoXY***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns for a given position in a Table or TreeView Table control (coordinates of a control point):

- the name of the column displayed for the specified position.

- the index of the row or column for the specified position.








![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, this function is only available for Table fields.. It is not available for TreeView Table control fields..

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003074007&name=tableinfoxy_function">See additional examples</a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Optional click code on the TABLE_TABLE1 control
MyRow is int
MyColumn is string
MyRow = TableInfoXY(TABLE_TABLE1, tiLineNumber, MouseXPos(), MouseYPos())
MyColumn = TableInfoXY(TABLE_TABLE1, tiColName, MouseXPos(), MouseYPos())
Trace("You have selected the cell (" + MyColumn+", " + MyRow + ")")
```


<a name="Exemple2"></a>

```wl
// Index of the row at point (50, 100) of the "TABLE_ProductTable" control 
ResInfo = TableInfoXY(TABLE_ProductTable, tiLineNumber, 50, 100)
```

## Syntax

`<Result> = TableInfoXY(<Table control> , <Type of information> , <X> , <Y>)`
---

**`<Result>: (String, integer or boolean)`**



- Requested information.

- An empty string ("") if there is no column name.

- -1 if there is no column index or row number, or if the specified position corresponds to an empty row or column.




**`<Table control>: (Control name)`**

Name of the Table or TreeView Table control to be used.

If this parameter corresponds to an empty string (""), the control to which the current event belongs will be used.

**`<Type of information>: (Integer constant)`**

Type of information requested:


|   |   |
| --- | --- |
| *tiColName* | Column name.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *tiColNumber* | Column creation index.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *tiLineNumber* | Row number. |
| *tiOnButtonCollapseExpand* | "+/-" buttons to expand/collapse a row. In this case, &lt;Result&gt; is set to <u><u><u><u>True</u></u></u></u> (1). <br><br>This constant is only available for TreeView Table controls.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tiOriginScreen* | The coordinates to be analyzed are relative to the screen. <br><br>Reminder: By default, the coordinates to be analyzed are given in relation to the Table control: the point (0,0) corresponds to line 1, column 1 of the manipulated Table control (with the scrollbars at the origin).<br><br>This constant cannot be used on its own.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |



**`<X>: (Integer)`**

X-coordinate (in pixels) to be analyzed. This coordinate is given in relation to the control (if the *tiOriginScreen* constant is not specified).

**`<Y>: (Integer)`**

Y-coordinate (in pixels) to be analyzed. This coordinate is given in relation to the control (if the *tiOriginScreen* constant is not specified).

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000162"></a>

**TableInfoXY** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.

- the function doesn't return any result if the Table control is empty.





<a name="NOTE0_2"></a>


### The different types of column indexes
<a name="the_different_types_column_indexes_ELTPARAGRAPHE000184"></a>

There are 2 types of indexes for columns:

- Visible position index: column index when the window is run.

- Creation index: column index when the table is created in the window editor.


These indexes change if the user moves the columns.

Additionally, if the horizontal scrollbar is used, **TableInfoXY** takes this change into account.
<a name="NOTE0_3"></a>


### Using MouseXPos and MouseYPos
<a name="using_mousexpos_and_mouseypos_ELTPARAGRAPHE000202"></a>

To use [MouseXPos](../WDLang1/3071007.md) and [MouseYPos](../WDLang1/3071008.md) in the X and Y parameters of the function, make sure that a single mouse click will trigger the execution of the code containing this function. 

For example, the "Select a row" event of a Table control can be started by a simple click but also by a keyboard selection. Therefore, [MouseXPos](../WDLang1/3071007.md) and [MouseYPos](../WDLang1/3071008.md) should not be used in this event. Use an optional event instead. In this example, use the optional event "Left button down" on aTable control.
