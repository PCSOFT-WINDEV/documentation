
## SysSpace (Function)

***In french: SysEspace***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the physical memory space for the current computer.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns the physical memory space for the server.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This function can only be used to determine the free space or the total space on the memory card (primary external storage zone). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connaître l'espace mémoire physique
ResEspMémoire = SysEspace()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SysSpace([<Type of memory>])`
---

**`<Result>: (Integer)`**

Desired space (in bytes) on the current computer (or server).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **SysSpace** returns 0 if the memory card is not detected or if it does not show up.

**Note**: Function **SysSpace** returns an 8-byte integer if the requested size is greater than 2 GB.

**`<Type of memory>: (Optional integer constant)`**

Type of memory to return:


|   |   |
| --- | --- |
| *sysFreeProgramSpace* | Unused physical memory space.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is not available. |
| *sysFreeStorageSpace* | Available storage space<br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *sysProgramSpace*<br>(Default value) | Physical memory space.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is not available. |
| *sysStorageSpace* | Space used for storage<br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
