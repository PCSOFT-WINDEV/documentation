


## &lt;TreeView&gt;.Modify (Function)

***In french: &lt;Arbre&gt;.Modifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies an element (node or leaf) in a TreeView control.

Example of TreeView control: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Arbre_Vocabulaire.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the caption of "Desserts" node in the "TREE_TVRecipe" TreeView control
Res = TREE_TVRecipe.Modify("Recipes" + TAB + "Desserts", "Ice creams")
```
<a name="Exemple2"></a>

```wl
// Modify the root image in the "TREE_TVRecipe" TreeView control
Res = TREE_TVRecipe.Modify("Recipes", Null, ...
		"C:\MyImages\Img1.GIF", "C:\MyImages\Img2.GIF")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <TreeView control>.Modify(<Path of element to modify> , <New caption> [, <New collapsed image> [, <New expanded image> [, <New element identifier> [, <Tooltip text>]]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element was modified in the TreeView control,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<TreeView control>: (Control name)`**

Name of the TreeView control to be used.

**`<Path of element to modify>: (Character string)`**

Full path of element to modify. This parameter has the following format:

```txt
"<Root name>" + TAB + ["<Name of 1st node>" + TAB + ...
["<Name of 2nd node>" + TAB + [...]]]"<Leaf name>"
```


**`<New caption>: (Character string)`**



- New caption for the specified element,

- *NULL* constant to keep the existing caption.




**`<New collapsed image>: (Optional character string or constant)`**

New image associated with the specified element. This image is displayed when this element is collapsed (see the Remarks). This parameter corresponds to:

- the name and full (or relative) path of image. A UNC path can be used.

- the constant:
	


|   |   |
| --- | --- |
| *Null* | Stores the image of specified element |
| *tvDefault*<br>(Default value) | Default image (closed folder): ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ImageEnroule.GIF) |






**`<New expanded image>: (Optional character string or constant)`**

New image associated with the specified element. This image is displayed when this element is expanded (see the Remarks). This parameter corresponds to:

- the name and full (or relative) path of image. A UNC path can be used.

- the constant:
	


|   |   |
| --- | --- |
| *Null* | Stores the image of specified element |
| *tvDefault*<br>(Default value) | Default image (opened folder): ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=ImageDeroulee.GIF) |






**`<New element identifier>: (Character string or integer (optional))`**

New identifier of element or the *NULL* constant to keep the identifier of specified element.

**Attention**: The Tab character (TAB) is forbidden in element identifiers.

**`<Tooltip text>: (Optional character string)`**

If this parameter is specified, its content will be displayed in a tooltip when the element is hovered by the mouse cursor. This parameter corresponds to an empty string by default. If no tooltip is associated with the element, the tooltip associated with the TreeView control will be automatically displayed.

## Remarks


### Format of collapsed/expanded images
<a name="format_collapsedexpanded_images_ELTPARAGRAPHE000249"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The following image formats are supported in Windows:

- Bitmap (\*.BMP)

- Graphics Interchange Format (\*.gif)

- Joint Picture Experts Group (\*.jpg ; \*.jpeg)

- Kodak Photo CD (\*.pcd)

- PaintBrush (\*.pcx)

- Adobe Photoshop Format (\*.psd)

- TrueVision TARGA (\*.tga)

- Tagged Image File Format (\*.tif ; \*.tiff)
	Note: the "Tiled TIFF" option in TIFF 6.0 is not supported. In this case, we advise you to save the image in tiff 5.0 standard. 

- Portable Network Graphics (\*.png)

- Windows MetaFiles (\*.emf ; \*.wmf)

- Icons (\*.ico ; \*.icw)
	Remarks: 

	- HQ display (High Quality) available.

	- Management of sheets in transparent BMP format (32 bits).




- Cursors (\*.cur)

- Portable Document Format (\*.pdf)

- Scalable Vector Graphics (\*.svg)

- WINDEV images (generated by the image editor, \*.WDPIC).

- Images in WebP format (\*.webp). 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The following image formats are supported:  GIF, JPEG, PNG or SVG (depending on the browser).


### Type of collapsed/expanded images
<a name="type_collapsedexpanded_images_ELTPARAGRAPHE000298"></a>

The images used can be:

- image files, 

- items of a "Binary Memo" HFSQL table containing an image.

- drawings created with the [drawing functions for List and Combo Box controls](../WDLang1/3029028.md).




The specified image is scaled down to 16 x 16 pixels: in most cases, the height of the image corresponds to the height of the line in the TreeView control.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Only image files can be used. These files must be in the "&lt;ProjectName&gt;_WEB" directory. These images are not transformed when the page is saved. There is no need to use [fWebDir](../WDLang1/3036052.md) to specify the image path. This path is relative to the "&lt;ProjectName&gt;_WEB" directory.

**Note** We recommend using 16 x 16 pixel images (size of small icons).
