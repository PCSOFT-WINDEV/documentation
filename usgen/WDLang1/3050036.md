
## StatAverage (Function)

***In french: StatMoyenne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the arithmetic, geometric or harmonic mean for a series of values.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003050036&name=stataverage_function">See additional examples</a>

```wl
// Arithmetic mean of the elements in row 1 of a matrix
ResAverage = StatAverage("MyMatrix", statArithmetic, 1 , False)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = StatAverage(<Matrix> [, <Type of mean> [, <Row/Column number> [, <Row/Column>]]])`
---

**`<Result>: (Real)`**

Mean for the series.

**`<Matrix>: (Character string)`**

Name of the matrix containing the data, defined by [MatCreate](../WDLang1/3050058.md).

**`<Type of mean>: (Optional constant)`**

Specifies the type of mean to calculate:


|   |   |
| --- | --- |
| *statArithmetic*<br>(Default value) | Arithmetic mean |
| *statGeometric* | Geometric mean |
| *statHarmonic* | Harmonic mean |



**`<Row/Column number>: (Optional integer)`**

Number of the row or column containing the data (1 by default).

**`<Row/Column>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (by default) if the series of values corresponds to a matrix column, 

- <u><u><u><u>False</u></u></u></u> if the series of values corresponds to a matrix row.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Number of elements found in a matrix row or in a matrix column
<a name="number_elements_found_matrix_row_matrix_column_ELTPARAGRAPHE000093"></a>

The number of elements found in a matrix row or in a matrix column is taken as a reference. This number of elements corresponds to:

- the total number of matrix rows, returned by [MatNbLine](../WDLang1/3050060.md) (if the calculation is performed on a column), 

- the total number of matrix columns, returned by [MatNbColumn](../WDLang1/3050073.md) (if the calculation is performed on a row).




If the series contain less elements than the matrix, the missing values are automatically filled with 0. These values are taken into account during the calculations.
<a name="NOTE0_2"></a>




### Error management
<a name="error_management_ELTPARAGRAPHE000112"></a>

**Caution**: **StatAverage** returns no error code. To determine if this function has generated errors, use [StatError](../WDLang1/3050019.md). To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
