
## gPen (Function)

***In french: gStylo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a sequence of characters used to describe the color of the text and/or the color of the shape outline (rectangle or circle).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **In a window**, this sequence of characters sets the text and/or outline color:  

- in an element of a List Box or Combo Box control.

- in the title bar and/or status bar of a window. 

- in a Static Text control. 
	Note: It may be necessary to crop this label after defining its content.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Add "Yellow" colored in yellow in "LIST_ListColors"
ListAdd(LIST_ListColors, gPen(LightYellow) + "Yellow")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = gPen(<Color>)`
---

**`<Result>: (Character string)`**

Sequence of characters defining the color of the text or the color of the shape outline (circle, rectangle, ...).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This sequence of characters can be: 

- used in [ListAdd](../WDLang1/3049004.md), [ListInsert](../WDLang1/3049002.md) or [ListModify](../WDLang1/3049009.md).

- assigned to a Static Text control. 

- used in the title bar or status bar of a window. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This sequence of characters is not interpreted by the controls in WEBDEV. This function can be used to format the string returned by a WEBDEV web service consumed by a WINDEV or WINDEV Mobile application.

**`<Color>: (Integer or constant)`**

Display color for the text or for the outline of a shape (rectangle or circle). This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).
