


## FontUnload (Function)

***In french: PoliceDécharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Unloads a font previously loaded with [FontLoad](../WDLang1/1410090994.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
FontUnload("Roboto-Regular.ttf")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = FontUnload(<Font>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the font was unloaded,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Font>: (Character string or Buffer)`**



- Name and path of the file corresponding to the font to be unloaded. This path is specified to load the font.  

- Buffer containing the font to be unloaded. This buffer is used to load the font. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
If the same font is loaded multiple times, **FontUnload** must be called as many times as [FontLoad](../WDLang1/1410090994.md).
