


## HTMLEditorToEmail (Function)

***In french: EditeurHTMLVersEmail***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Exports the content of an HTML Editor control to an Email variable (to send the email). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyMessage is Email
HTMLEditorToEmail(HTMEDT_MyHTMLEditor, MyMessage)
MyMessage.Recipient = "flo-us@gmal.com"
MyMessage.Subject = "Test"
EmailSendMessage(MySession, MyMessage, emailOptionEncodeHeader)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HTMLEditorToEmail(<HTML Editor control> , <Email> [, <Option>])`
---

**`<HTML Editor control>: (Control name)`**

Name of the HTML Editor control used. 

**`<Email>: (Email variable)`**

Name of the [Email](../WDLang3/1000018713.md) variable into which the HTML document in the HTML Editor control is to be imported. If this parameter is not specified or is an empty string (""), the [Email](../WDLang3/3032029.md) structure is used.
 
Note: The **HTML** property of variable type [Email](../WDLang3/1000018713.md) (or variable **Email.HTML** variable of structure [Email](../WDLang3/3032029.md)) is automatically assigned with the HTML contained in the HTML Editor field. The characters are encoded in UTF-8 and the corresponding charset is inserted.

**`<Option>: (Optional Integer constant)`**

Export options, valid only when using the Email structure: 


|   |   |
| --- | --- |
| *emailOptionDefault*<br>(Default value) | A unique identifier is generated to identify each image found in the HTML file. **This identifier is unique regardless of the exported HTML file**.<br><br>Default operating mode. |
| *emailOptionNoCID* | An identifier is generated for the images in the HTML file. **This identifier is not unique. If multiple HTML files are exported, they can use the same image identifiers**. |

## Remarks


### Operating mode of images and attachments
<a name="operating_mode_images_and_attachments_ELTPARAGRAPHE000080"></a>

If the HTML Editor field refers to images:

- these images are automatically added as attachments to the email (in the [Email](../WDLang3/3032029.md) or in the [Email](../WDLang3/1000018713.md) variable).

- the HTML code of message is modified in order to reference the attachments.




**Warning** Attachments are "added" to the Email. For example, if the variable **Email.NbAttachment** is set to 2 before calling the function **HTMLEditorToEmail** and if the content of the HTML Editor field refers to an image, this image will be put into the variable **Email.Attach[3] variable** and the variable **Email.NbAttache** variable will be set to 3.

The additional attachments must be added before using **HTMLEditorToEmail**.

The order in which the attachments are sent is not necessarily respected when the email is received.
The identifier of images is a unique identifier.Note: If the import is performed in a variable of type [Email](../WDLang3/1000018713.md), images embedded by encoding in the source HTML file are also processed.
