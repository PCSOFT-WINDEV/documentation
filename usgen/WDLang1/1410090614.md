


## &lt;Spreadsheet&gt;.ListComment (Function)

***In french: &lt;Tableur&gt;.ListeCommentaire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists all the comments on the current worksheet of a Spreadsheet control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Make all comments visible
FOR EACH Comment OF PSHEET_MySpreadsheet.ListComment()
	Comment..Visible = True
END
```

```wl
// Delete all comments
FOR EACH Comment OF PSHEET_MySpreadsheet.ListComment()
	Comment..Text = ""
END
```

```wl
MyCommentArray is array of xlsComment
MyCommentArray = PSHEET_MySpreadsheet.ListComment()
FOR EACH comment OF MyCommentArray
	Trace(comment..Text)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Spreadsheet control>.ListComment()`
---

**`<Result>: (Array)`**

Array containing the different comments with their characteristics. This array contains [xlsComment](../WDLang5/1000024870.md) variables.

**`<Spreadsheet control>: (Control name)`**

Name of the Spreadsheet control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Modifying a comment in the array also modifies it in the Spreadsheet control. 

- Adding or deleting a comment in the array has no effect on the comments in the Spreadsheet control. 

- If there is no comment in the worksheet, the array is empty.
