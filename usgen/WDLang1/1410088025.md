
## Interactive notification management constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manipulate interactive notifications:

| Constant | Details | Variable type |
| --- | --- | --- |
| **sysNotifAlarm** | Specific behavior: The notification stays on screen until the user interacts with it. A "reminder" sound alert defined by the system is played in a loop. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifButtonStyleCritical** | Button style: Red button (style defined by Windows to indicate an error).<br><br> | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifButtonStyleDefault** | Button style: Default. <br><br> | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifButtonStyleSuccess** | Button style: Green button (style defined by Windows to indicate success). <br><br> | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifCall** | Specific behavior: The notification stays on screen until the user interacts with it. An incoming call sound defined by the system is played in a loop, and a different style is used for the buttons. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifCircleCrop** | Cropping to be applied to the logo: Circle-cropped image. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifCloseButton** | Specific behavior or positioning: System button that automatically closes the notification. | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifContextButton** | Specific behavior or positioning: Button to be added to the context menu of the notification. | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifInputCombo** | Type of control for user interaction: Combo Box control. | [sysNotificationInput](../WDLang1/1410088024.md) |
| **sysNotifInputText** | Type of control for user interaction: Edit control. | [sysNotificationInput](../WDLang1/1410088024.md) |
| **sysNotifNoCrop** | Cropping to be applied to the logo: No cropping, square image. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifReminder** | Specific behavior: The notification stays on screen until the user interacts with it. A "reminder" sound alert defined by the system is played when the notification appears. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifReminderButton** | Specific behavior or positioning: "Remind later" system button | [sysNotificationButton](../WDLang1/1410087947.md) |
| **sysNotifStandard** | Specific behavior: The notification appears on screen for a few seconds before moving to the Windows Action Center. | [sysNotification](../WDLang1/1410087893.md) |
| **sysNotifStandardButton** | Specific behavior or positioning: Simple button. | [sysNotificationButton](../WDLang1/1410087947.md) |
