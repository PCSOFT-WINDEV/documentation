
## Gesture variable
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000176"></a>
The Gesture variable is used to retrieve gesture (sweep) parameters: direction, speed, distance, etc.

This variable can be used: 

- in the swipe event of elements in a Looper control, to know the swipe direction. 

- in multitouch events (zoom, scroll and swipe) to avoid declaring parameters in the events.

## Gesture variable
<a name="gesture_variable_ELTTEXTE000200"></a>
The Gesture variable includes the following elements:


|   |   |
| --- | --- |
| ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Gesture.AltitudeAngle | Real<br><br>Angle (expressed in degrees) corresponding to the inclination of an Apple Pencil in relation to the tablet plan.<br><br>This variable is filled in the "Pressed/Left button down" event only. |
| ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Gesture.Azimuth | Real<br><br>Azimuth angle (expressed in degrees) of an Apple Pencil in relation to the mark of current control.<br><br>This variable is filled in the "Pressed/Left button down" event only. |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Gesture.Direction | Integer constant<br><br>Direction of the gesture. Can correspond to one of the following constants:<br><br>- *BottomTop* Scan from bottom to top.<br><br>- *RightLeft* Scan from right to left.<br><br>- *LeftRight* Scan from left to right.<br><br>- *UpDown* Scan from top to bottom.<br><br><br>This variable is filled in Scroll and Swipe events. |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Gesture.Distance | In the case of scroll: displacement value (in pixels) in the direction indicated by Gesture.Direction.<br><br>For pinch zoom: value of the distance (in pixels) between the two contact points.<br><br>This variable is filled in Scroll and Pinch zoom events. |
| ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Gesture.Force | Real<br><br>Pressure during a press.<br><br>This pressure can take a value included between 0,0 and 1,0.<br><br>This variable is filled in the "Pressed/Left button down" event only. |
| ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Gesture.MaximumForce | Real<br><br>Maximum pressure during a press.<br><br>This pressure can take a value included between 0,0 and 1,0.<br><br>This variable is filled in the "Pressed/Left button down" event only. |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Gesture.Speed | Integer<br><br>Speed of the move in the direction specified by Gesture.Direction. <br>This speed is expressed in pixels per second.<br><br>This variable is filled in Swipe events. |

## Example
<a name="example_ELTTEXTE000224"></a>


### Retrieving gesture information
<a name="retrieving_gesture_information_ELTPARAGRAPHE000127"></a>


```wl
// Scroll with Finger event of IMG_Image
SWITCH Gesture.Direction
	CASE RightLeft: SEL_Direction = 1
	CASE LeftRight: SEL_Direction = 2
	CASE UpDown: SEL_Direction = 3
	CASE BasEnHaut: SEL_Direction = 4
END

EDT_Speed = Gesture.Speed
EDT_Distance = Gesture.Distance
```
