


## Trace (Function)

***In french: Trace***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays the requested information (content of a control, for example) in a window opened next to the current window.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Trace.gif)
**Remarks**:

- **** is useful during the development process to check whether a program runs properly. In the editor, the ["Debugger trace"](../Editeurs/2027028.md) displays the information found in the trace window as well as the full text of errors that occurred.

- The trace window is displayed in both development and run mode. To avoid a runtime display, use the [InTestMode](../WDLang1/3013011.md) function.




 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// ------------------
// Display information in the trace window 
Trace("Calculation result: " + ResCalcul)
// ----------------
```



```wl
// Trace display override
PROCEDURE Trace(MessageToDisplay)
IF InTestMode() THEN Trace(MessageToDisplay)
```

```wl
// Call the overridden Trace function
WL.Trace("Start trace")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Trace(<Information> [, <Additional information 1> [... [, <Additional information N>]]])`
---

**`<Information>: (Any type)`**

Set of elements that will be displayed in the trace window.

**`<Additional information 1>: (Any type (optional))`**

Additional information to be displayed in the trace window. It will be displayed on the same line as &lt;Information&gt;.




**`<Additional information N>: (Any type (optional))`**

Additional information to be displayed in the trace window. It will be displayed on the same line as &lt;Information&gt;.

## Remarks


### Use conditions according to the platforms
<a name="use_conditions_according_the_platforms_ELTPARAGRAPHE000084"></a>

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Trace** can be used to display the requested information in a file only. By default, this file is created in the UNIX temporary directory with the name "Trace_&lt;Project&gt;.txt".![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The information of **Trace** is displayed at the beginning of the HTML page returned.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) For WEBDEV pages: 

- The trace window is displayed in test mode ("Go" option) only for dynamic pages (other than Active WEBDEV Pages). 

- In AWP and deployment mode, **Trace** can only be used to write the specified information to a file (***trFile*** constant used with [TraceStart](../WDLang1/3013052.md)).




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) For Mobile applications: 

- **In the simulator**the trace window is displayed. 

- **When testing on the mobile**the trace window is displayed on the device (test via WMDev (for iOS applications), via USB or Wi-Fi). 
	

- **At runtime**: 

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **Trace** displays requested information in the Xcode standard output window.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Trace** saves the requested information in the application log ("ADB log") at runtime or in emulator mode. This information appears in the "Info" section. 
			This log can be viewed when the device is connected via USB or when using the emulator from the DDMS application provided with the Android SDK.
			For more details, see [Managing ADB logs](../Editeurs/9000108.md).

	- The trace window can be displayed using function [TraceStart](../WDLang1/3013052.md) with the constant *trWindow*. 
			






<a name="NOTE0_2"></a>


### Trace window
<a name="trace_window_ELTPARAGRAPHE000149"></a>

- The information passed as parameter is displayed on the next line of the trace window.

- The trace window opens automatically the first time **Trace** is called ([TraceStart](../WDLang1/3013052.md) is executed automatically). By default, this window is opened in the upper-left corner of the screen. It can be moved. The new position is automatically saved. 

- **Trace** is similar to [Info](../WDLang1/3021011.md) but the information is displayed in another window and no key needs to be pressed.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The trace window displayed from a Browser code is different from the one displayed from a Server code. Therefore, two different trace windows can be opened at the same time.




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Special features on mobile: 

- The trace window is:

	- finger-moveable via title bar. 

	- resizable by fingertip. 




- By default, the trace window has a size of 200x200 and is positioned in the bottom right-hand corner of the screen. 

- The trace window can be rolled up or down using the. 

- Text size can be changed with a finger (pinch). 

- The trace window cannot leave the screen. 

- The trace window is always displayed on top of all application windows. 

- It can be displayed in the project initialization code or via a secondary thread. 

- The trace window cannot be displayed from a widget or background process. 



<a name="NOTE0_3"></a>


### Context menu of the trace window
<a name="context_menu_the_trace_window_ELTPARAGRAPHE000191"></a>

The context menu of the trace window allows you to:

- copy/cut/paste the content of trace window.

- save the content of the trace window in a text file. 
	Note: This option is only available if the wdxxxstd.dll library is present on the end-user workstation.

- clear the contents of the trace window.

- open the trace window on top of all the other windows (including the windows from the other applications).

- save the size and position of the trace window when it is closed. When this window is displayed again, it will keep the size and position saved.

- display a horizontal scrollbar.

- Display control characters: Special characters will be displayed in grayed and literal form: EOT, TAB, etc. Therefore, the "Carriage Return" (CR) characters in the trace window are represented as "&lt;\\r&gt;&lt;\\n&gt;".
	Note: This option will only be taken into account from the next line of information displayed.




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Special features on mobile: 
The context menu offers the following options: 

- Copy / copy all trace window contents. 

- clear the contents of the trace window.

- show or hide control characters.
