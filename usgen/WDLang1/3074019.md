


## TableModify (Function)

***In french: TableModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies a row in: 

- a Table control,

- a TreeView Table control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a table displayed in a Combo Box control.




**Note**: It is recommended to use [TableModifyLine](../WDLang1/3074028.md). [TableModifyLine](../WDLang1/3074028.md) is used to add:

- TAB characters into the columns, 

- all types of values into the columns.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the "Paul" and "Moore" elements on the fifth
// row of the "TABLE_CustomerTable" control
TableModify(TABLE_CustomerTable, "Paul" + TAB + "Moore", 5)
```
<a name="Exemple2"></a>

```wl
// Modification in a column of a Table control
TableModify(COL_LASTNAME, "Moore", 5)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableModify(<Table control> , <Row> [, <Index>])`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Combo Box control with table.


If this parameter corresponds to an empty string (""), the control used will be the control to which the current event belongs.

**`<Row>: (Character string)`**

Modified row replacing the specified row. This row has the following format: 

```txt
<Element of column 1> + TAB + <Element of column 2> + TAB + ...
```


**`<Index>: (Optional integer)`**

Index of the row to be modified. The value of first row is set to 1.


|   |   |
| --- | --- |
| Index not specified or equal to -1 | The current row is modified. This constant has no effect if no row is selected. |
| Index greater than the number of control rows | A WLanguage error occurs. |

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000139"></a>

**TableModify** can be used on:

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for classic Table control fields.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table controls in "Server" and "Server + AJAX" mode, and for TreeView Table controls. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is available for Table controls in "Browser" mode only.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The TreeView Table control is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Data-bound Table controls are not available in edit mode. **TableModify** cannot be used on data-bound Table controls.
<a name="NOTE0_2"></a>


### Row characteristics
<a name="row_characteristics_ELTPARAGRAPHE000180"></a>

- Each row element is changed into the type of the associated column.

- If one of the elements corresponds to an empty string ("") or to 0 (depending on the column type), its value will be overwritten. 
	For example:
	
	```wl
	TableModify(TABLE_CustomerTable, "Moore" + TAB + "Peter" + TAB + "" + ...
			TAB + "06/21/72")
	```


- If an element corresponds to the result of a calculation, enclose the numerical expression in brackets. 
	For example:
	
	```wl
	TableModify(TABLE_CalcTable, (53+29) + TAB + (83-21))
	```


- To modify the value of an element in a row, use the following syntax:
	
	```txt
	TableName.ColumnName[RowIndex] = NewValue
	```

### Table field/Hierarchical file table: Changes to the linked table
<a name="table_fieldhierarchical_file_table_changes_the_linked_table_ELTPARAGRAPHE000214"></a>

**If the cascading input is enabled**, the table linked to the control is automatically modified when the user goes to the next row.

**If the cascading input is not enabled**, the table linked to the control is not modified. To write the record into the linked table, [TableSave](../WDLang1/3074008.md) must be called after **TableModify**.

**Remarks**: 

- The "Cascading input" option can be selected in the "Details" tab of the control description window.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The cascading input is not available for Table controls with direct access to the data source. This option is only available for Table controls populated programmatically and with in-memory data source.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cascading input is only available for "Server + AJAX" data-bound Table controls based on a table. 



<a name="NOTE0_4"></a>


### Changes in a Table or TreeView data-bound Table control based on a table
<a name="changes_table_treeview_databound_table_control_based_table_ELTPARAGRAPHE000242"></a>

To modify a row in a Table or TreeView Table control based on a table, we advise you to:

- modify the record in the table with [HModify](../WDLang4/3044042.md),

- use [TableDisplay](../WDLang1/3074003.md) to refresh the control.

### TableModify function and Modified property
<a name="docparampagetitleshort_function_and_modified_property_ELTPARAGRAPHE000276"></a>

**TableModify** has no influence on the [Modified](../Proprietes/2510080.md) property. The [Modified](../Proprietes/2510080.md) property is used to know if the current row has been directly modified by the user (direct input in the control).
