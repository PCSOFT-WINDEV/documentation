
## Multitask (Function)

***In french: Multitâche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to:

- define a timeout,

- give control back to Windows,

- give control back to Windows and to WLanguage.




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Warning: The **Multitask** function MUST NOT be used to fill RepeatString, List or Multiline Zone control fields. In this case, use a timer: each time the timer is called, an element is added to the. 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Calculation loop
FOR i = 1 TO 10000
	CalculationProcedure(i)
	// Give control back to the system in order to display the results
	Multitask()
END
// Wait 1 second 
Multitask(100)
```

<a name="SYNTAXE1"></a>

## Syntax

`Multitask([<Timeout>])`
---

**`<Timeout>: (Optional integer or optional Duration)`**



- **Perform a delay**: &lt;Delay&gt; = positive integer. 
	The execution of the application is interrupted during &lt;Timeout&gt; hundredths of a second without giving control back to the system. The mouse clicks and the actions performed on the keyboard keys are ignored by the application. For example, the window can be moved but it cannot be resized.
	The [optional processes](../WDChamp/1014004.md) of controls are always run.
	**Note**: If &lt;Delay&gt; = 1, the application immediately returns control to Windows, without waiting 1 hundredth of a second.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The modification of window size is not ignored. On the contrary, the mouse clicks and the actions on the keyboard keys are ignored.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The positive values are ignored on Android. If the parameter of the function is positive, it will be processed like a negative integer.
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In PHP, the values of &lt;Timeout&gt; are rounded to the higher second. For example, if &lt;Timeout&gt; is equal to 125, the actual timeout will be equal to 2 seconds.
	![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The positive values are not allowed.

- **Handing control back to the system**: &lt;Delay&gt; = 0 or not specified. 
	The system ends the current processes, gives control back to the WINDEV, WEBDEV or WINDEV Mobile application, then takes into account the clicks and the actions performed on the keyboard keys.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **Multitask** has no effect if &lt;Timeout&gt; = 0.
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The value 0 is not allowed on iPhone/iPad.

- **Return control to Windows and WLanguage**: &lt;Delay&gt; = negative integer. 
	The execution of the application is interrupted during &lt;Timeout&gt; hundredths of a second. Other processes can be run during this time period (redisplaying or running a click code for example). The interactions with the users (mouse click, keystroke, ...) are processed as usual. 
	**Note**: If &lt;Temporisation&gt; = -1, the application immediately returns control to Windows without waiting 1 hundredth of a second.


Note: This parameter can be: 

- an integer corresponding to the number of hundredths of a second,

- a Duration variable,

- the duration in a readable format (e.g., '1s' or '10cs'). 


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter can only correspond to an integer.

## Remarks
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Example of timeout
<a name="example_timeout_ELTPARAGRAPHE000131"></a>

The user presses the Esc key before or during the call to **Multitask**:

- if &lt;Temporisation&gt; is positive: the Escape key is not taken into account.

- if &lt;Temporisation&gt; is equal to 0: The Escape key is taken into account at the end of current WINDEV processing.

- if &lt;Temporisation&gt; is negative: the Escape key is used immediately.



<a name="NOTE0_2"></a>




### Tips
<a name="tips_ELTPARAGRAPHE000145"></a>

- To refresh the UI, use [MultitaskRedraw](../WDLang1/3038004.md).

- The events and timers started before the execution of **Multitask** are managed during the timeout.

- In a Service application, **Multitask** must be replaced with [ServiceWait](../WDLang1/1000018712.md).



<a name="NOTE0_3"></a>




### Note
<a name="note_ELTPARAGRAPHE000165"></a>

It is recommended to use [ThreadPause](../WDLang1/3077029.md) instead of **Multitask** or [Timeout](../WDLang1/3015012.md) when using multiple threads (including the main thread of the application) if the timer does not need to process user actions.
