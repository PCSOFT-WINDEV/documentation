


## &lt;Tab&gt;.CloseAll (Function)

***In french: &lt;Onglet&gt;.FermeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes all dynamic tabs of a Tab control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
TAB_DynTab.CloseAll()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Tab control>.CloseAll()`
---

**`<Tab control>: (Control name)`**

Name of the Tab control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
All the internal windows associated with the dynamic tabs are unloaded and the dynamic tabs are deleted from the specified Tab control.
