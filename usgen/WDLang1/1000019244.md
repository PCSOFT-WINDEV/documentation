
## Appointment (Variable type)

***In french: RendezVous***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The type **Appointment** type lets you define all the advanced features of an appointment: times, location, etc. 

This type of variable can be used:  

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) in an Organizer control or in a Scheduler control. The **Appointment** type will be handled by the WLanguage functions for managing Organizer controls or the Scheduler controls.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) by the [functions for appointment management](../WDLang3/1000011009.md) on an Android or iOS device.




You can define and change the characteristics of this appointment using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
// Build an Appointment variable
MyAppointment is Appointment

// The appointment starts now and it lasts two hours
MyAppointment.StartDate = DateSys() + TimeSys()
MyAppointment.EndDate = MyAppointment.StartDate
MyAppointment.EndDate.Time = MyAppointment.EndDate.Time + 2

MyAppointment.Title = "Appointment with the sales director"
MyAppointment.Importance = 1
MyAppointment.Guest = "Tommy, Vince, Sandra"
MyAppointment.Content = "Establishing the new price list"
MyAppointment.Note = "Remember to bring the blue folder."
MyAppointment.Tooltip = MyAppointment.Title + CR + MyAppointment.Note

// Add the appointment into the organizer
OrganizerAddAppointment(ORG_MyOrganizer, MyAppointment)
```


<a name="Exemple2"></a>

```wl
// Adds an appointment by using the Appointment type and with repetition
// Every first Monday of the month 
// a Monday found in days from 1 to 7 of the month = 1st of month.

x is Appointment
x.StartDate = Today() + "1200"
x.EndDate = Today() + "1400"
x.WithRepetition = True
y is Repetition
y.Type = schEveryDay
y.DayOfWeek = 1 
y.DayOfMonth = "1-7" 
y.DayOfMonthOrDayOfWeek = False
x.Repetition = y
OrganizerAddAppointment(ORG_Organizer, x)
```

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) 
```wl
gAPT is Appointment
gCal is Calendar
arrCalendar is array of Calendar 
// Retrieves the list of calendars
arrCalendar = AppointmentListCalendar()
gCal = arrCalendar[1]

// Add a new appointment into the first calendar
gAPT.Title = EDT_Title
gAPT.StartDate = EDT_StartDate + EDT_StartTime
gAPT.EndDate = EDT_EndDate + EDT_EndTime
gAPT.Location = EDT_Location
gAPT.Content = EDT_Desc
IF EDT_TimeZone <> "" THEN
	gAPT.TimeZone = EDT_TimeZone
END
gAPT.Author = EDT_Author
gAPT.Guest = EDT_Guests
gAPT.WholeDay = CBOX_WholeDay[1]

IF AppointmentAdd(gCal, gAPT) THEN
	ToastDisplay("APT added")
ELSE
	Error(ErrorInfo())
END
```

### Properties specific to Organizer and Scheduler controls
<a name="properties_specific_organizer_and_scheduler_controls_ELTPARAGRAPHE000084"></a>

The following properties can be used to handle an appointment:

| Property name | Type used | Effect |
| --- | --- | --- |
| Author | Character string | Name of appointment author. If this property is not specified, the appointment has no author.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| BackgroundColor | Integer | Background color used to display the appointment in the Organizer control or in the Scheduler control.<br>This color can correspond to:<br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)), <br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)), <br><br>- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).<br><br><br>If this property is not specified, a color will be automatically calculated. The appointments found in the same category will have the same color.<br><br>Before version 24, this property was named "BackgroundColor". |
| Category | Character string | Category of appointment. If this property is not specified, the appointment is associated with no category. |
| Content | Character string | Detailed description of the appointment. <br><br>For a Scheduler control (or for an Organizer control), the content is displayed in the control.<br><br>If this property is not specified, the appointment has no description. |
| EndDate | Character string or DateTime variable | End date and time of the appointment.  A valid date must be assigned to this property before using the variable.<br><br><br>This property must be specified. |
| Extra | Variant | Allows you to store advanced information without affecting the execution of the application. You can store values of any type (array, etc.). It is also possible to add members to the **Extra** property. <br>Example: <br><br><pre><code>MyVariable.Extra.Info1 = Value<br>MyVariable.Extra[Info2] = Value2<br>MyVariable.Extra.Date = DateSys()</code></pre><br> |
| ID | Character string | Identifier associated with the appointment. Allows you to store the identifier of an element that must be associated with the appointment in order to use it later in programming. <br><br>For example, this identifier can correspond to the identifier of a record in a database. |
| Image | Character string | Image associated with the appointment. This image is displayed in the Organizer control or in the Scheduler control (in addition to the logo that represents an important appointment if necessary). <br><br>This property can correspond to: <br><br>- the path to an image accessible from the current computer,<br><br>- an image file found in the application library,<br><br>- an Image control containing an image,<br><br>- a drawing performed in an Image control with the drawing functions and saved in memory.<br><br><br>If this property is not specified, the appointment has no associated image.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The image file must be found in the &lt;Project_Name&gt;_WEB directory. The specified path must be relative to this directory. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| Importance | Integer | Importance of appointment. <br><br>If this property is greater than or equal to 1, an icon (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=agRendezVous_IconeImportant.gif)) will be displayed in the Organizer or Scheduler control to indicate an important event. <br><br>If this property is not specified, its value is set to 0.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| Location | Character string | Location of the appointment. <br><br>If this property is not specified, the appointment has no location.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| Note | Character string | Note associated with the appointment. <br><br>If this property is not specified, no note is associated with the appointment.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| Order | Integer | Order of appointments (for overlapping appointments). <br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This property is not available. |
| Repetition | [Repetition](../WDLang1/1000019262.md) variable | Advanced parameters of repetition. This property is taken into account only if the **WithRepetition** property is set to <u><u><u><u>True</u></u></u></u>.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |
| Resource | Character string | Resource associated with the appointment. This property is taken into account only when the appointment is used by a Scheduler control. |
| StartDate | Character string or DateTime variable | Start date and time of the appointment. A valid date must be assigned to this property before using the variable.<br><br>This property must be specified. |
| Title | Character string | Appointment title. The title is displayed in the Organizer control or in the Scheduler control. <br><br>If this property is not specified, the appointment has no title. |
| ToolTip | Character string | Tooltip displayed when the appointment is hovered. By default, this value includes the start time and the end time of appointment as well as the appointment title.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
| WholeDay | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the appointment is an appointment for the entire day. <br><br>- <u><u><u><u>False</u></u></u></u> otherwise (default value). <br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Attention**: For full-day appointments to be correctly displayed in the field, the "Display and allow full-day appointments" option must be checked in the "Detail" tab of the field description.. |
| WithRepetition | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the appointment must be repeated,<br><br>- <u><u><u><u>False</u></u></u></u> if the appointment takes place once only. <br><br><br>If the appointment is repeated, the **Repetition** property allows you to specify the frequency of the repetition. <br><br>This property is set to <u><u><u><u>False</u></u></u></u> by default.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This property is not available. |

### Properties specific to the management of Appointment functions
<a name="properties_specific_the_management_appointment_functions_ELTPARAGRAPHE000336"></a>

The following properties can be used to handle an appointment:

| Property name | Type used | Effect |
| --- | --- | --- |
| Author | Character string | Name of appointment author. If this property is not specified, the appointment has no author.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not supported. |
| Calendar | [Calendar](../WDLang3/1000020663.md) variable | <br><br>- Calendar to which the appointment belongs. <br><br>- Null if the appointment belongs to no calendar. <br><br>- Calendar to which the appointment belongs. <br><br>- Null if the appointment belongs to no calendar. <br><br><br>To add an appointment to a given calendar, use [AppointmentAdd](../WDLang3/1000011001.md). |
| Content | Character string | Detailed description of the appointment. <br><br>If this property is not specified, the appointment has no description. |
| EndDate | Character string or DateTime variable | End date and time of the appointment.  A valid date must be assigned to this property before using the variable.<br><br>The end time of the appointment is always expressed in the time zone associated with the appointment. The name of the time zone is returned by the **TimeZone** property |
| Guest | Character string | List of persons invited to the appointment. <br><br>If this property is not specified, the appointment has no guest.<br><br>The value of this property has the following format: <br><br><br><pre><code><Name guest 1> + TAB + <Email guest 1> + CR + ... <br>+ CR + <Name guest N> + TAB + <Email guest N></code></pre><br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **This property is read-only**. |
| ID | Character string | Identifier associated with the appointment. Allows you to store the identifier of an element that must be associated with the appointment in order to use it later in programming. <br><br>This property is read-only. This property is automatically filled when reading the appointment in the corresponding calendar. We do not advise you to store this identifier beyond the lifetime of the application because this identifier can be modified when synchronizing the calendars. |
| Location | Character string | Location of the appointment. <br><br>If this property is not specified, the appointment has no location. |
| Reminder | Array of [Reminder](../WDLang3/1000020688.md) variables | Array containing the list of reminders associated with the appointment. If no reminder is associated with the appointment, the array is empty. |
| StartDate | Character string or DateTime variable | Start date and time of the appointment. A valid date must be assigned to this property before using the variable.<br><br>The start time of the appointment is always expressed in the time zone associated with the appointment. The name of the time zone is returned by the **TimeZone** property |
| TimeZone | Character string | Name of time zone for the start and end times of appointment. This name must correspond to the full name of the time zone defined by the IANA Time Zone Database. For example: "Europe/Paris", "Europe/London", "America/New_York", ...<br><br>This property is initialized by default with the current time zone. To reinitialize this property with the current time zone, use "" (empty string). |
| Title | Character string | Appointment title. <br><br>If this property is not specified, the appointment has no title. |
| WholeDay | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the appointment is an appointment for the entire day. <br><br>- <u><u><u><u>False</u></u></u></u> otherwise (default value). <br><br><br><br><br>If this property is set to <u><u><u><u>True</u></u></u></u>: <br><br>- the time zone associated with the appointment must correspond to "UTC", <br><br>- the start and end times of the appointments must be set to midnight. <br><br><br><br><br>Example: Appointments for July 17, 2012: <br><br><br><pre><code>Apt is Appointment<br>Apt.StartDate = "201201170000"<br>Apt.EndDate = "201201180000"<br>Apt.WholeDay = True</code></pre><br> |
