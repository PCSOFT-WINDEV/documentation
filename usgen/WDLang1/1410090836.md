


## SegmentedButtonDelete (Function)

***In french: BoutonSegmentéSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes an option from a Segmented Button control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
FOR i = 4 TO 1 NOT -1  
	IF SB_Level[i].Caption = "Advanced" THEN
		SegmentedButtonDelete(SB_Level, i)
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`SegmentedButtonDelete(<Segmented Button control> , <Option index>)`
---

**`<Segmented Button control>: (Control name)`**

Name of the Segmented Button control used. 

**`<Option index>: (Integer)`**

Index of the option to be deleted. This index must be between 1 and the number of options in the Segmented Button control. The [Count](../Proprietes/2510097.md) property gets the number of options in a Segmented Button control.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Deleting an option does not change the size of the Segmented Button control. The control size can be changed using the [Width](../Proprietes/2510059.md) and [Height](../Proprietes/2510050.md) properties.

- When an option is deleted, the indexes of the options that follow the deleted option are automatically renumbered.
