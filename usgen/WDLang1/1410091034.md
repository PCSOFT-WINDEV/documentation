


## &lt;Command variable&gt;.Kill (Function)

***In french: &lt;Variable Commande&gt;.Termine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Forces the termination of a running executable associated with a command. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'
// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute.Executable = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)
...
IF MyCommandToExecute.IsRunning() = True THEN
	MyCommandToExecute.Kill()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Command manipulated>.Kill()`
---

**`<Command manipulated>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command to be manipulated.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
You can force the termination of the executable associated with a command via the **AutoTerminate** property of a variable of type [Command](../WDLang1/1410090491.md). 

If the **AutoTerminate** property is set to <u><u><u><u>False</u></u></u></u>, you can:

- determine if the executable is currently running, with [&lt;Command variable&gt;.IsRunning](../WDLang1/1410091033.md). 

- force the termination of the executable, with **&lt;Command variable&gt;.Kill**.
