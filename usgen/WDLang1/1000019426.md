


## SchedulerDisplay (Function)

***In french: PlanningAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reinitializes the content of a Scheduler control from its data source (HFSQL table, for example). All appointments are deleted from the Scheduler control and they are recreated from the data source.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add a new appointment in an HFSQL table
HAdd(File_Appointment)
// Reinitialize the Scheduler control
SchedulerDisplay(SCH_Schedule)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`SchedulerDisplay(<Scheduler control> [, <Options>])`
---

**`<Scheduler control>: (Control name)`**

Name of the Scheduler control to be used. 
The Scheduler control must be linked to a data source. Otherwise (if the control is populated programmatically), **SchedulerDisplay** has no effect.

**`<Options>: (Integer constant)`**

Options for displaying the Scheduler control: 


|   |   |
| --- | --- |
| *schWithoutExecuteQuery* | Used to avoid automatically re-running the query linked to the Scheduler control (for a Scheduler control linked to a query). |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If the data source linked to the Scheduler control is a query, this query is reinitialized. 

- The position in the Scheduler control is not modified.
