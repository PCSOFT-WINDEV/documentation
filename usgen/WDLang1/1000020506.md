


## TableDeleteSelect (Function)

***In french: TableSupprimeSelect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the selected rows from a Table or Treeview Table control.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Deletes all selected rows
IF YesNo("Do you really want to delete the selected customers?") THEN
	TableDeleteSelect(TABLE_Customer_Display)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`TableDeleteSelect(<Table control>)`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000073"></a>

**TableDeleteSelect** can be used on: 

- Table or TreeView data-bound Table controls based on a table.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Reminder** Multi-selection is not available for Table control fields in classic mode.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Table control fields in AJAX mode, Table control fields in classic mode and TreeView Table control fields. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is only available for Browser Table controls.. The TreeView Table control is not available.
<a name="NOTE0_2"></a>


### Deleting records in a Table or TreeView data-bound Table control based on a table
<a name="deleting_records_table_treeview_databound_table_control_based_table_ELTPARAGRAPHE000099"></a>

**TableDeleteSelect** deletes the corresponding records from the table associated with the control. If items are linked to other tables, no modification is automatically performed on these linked tables.
<a name="NOTE0_3"></a>


### Referential integrity and Table or TreeView data-bound Table controls
<a name="referential_integrity_and_table_treeview_databound_table_controls_ELTPARAGRAPHE000110"></a>

If the management of referential integrity is enabled ([HSetIntegrity](../WDLang4/3044058.md)), [HErrorIntegrity](../WDLang4/3044086.md) must be called after **TableDeleteSelect** to check the integrity. If an integrity error is detected, the row is not deleted and it remains visible in the control.
<a name="NOTE0_4"></a>


### Deleting records in a data-bound Table control and Trigger
<a name="deleting_records_databound_table_control_and_trigger_ELTPARAGRAPHE000127"></a>

You have the ability to activate a trigger when deleting a record from a data-bound Table control based on a table. For more details, see the documentation about [HDescribeTrigger](../WDLang4/3044074.md).
<a name="NOTE0_5"></a>


### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000139"></a>

The [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> if the deletion fails. To get the details of the error, use [ErrorInfo](../WDLang1/3013008.md).
<a name="NOTE0_6"></a>


### Locking the linked table
<a name="locking_the_linked_table_ELTPARAGRAPHE000158"></a>

If the table is locked in the current process, **TableDeleteSelect** deletes the specified row and unlocks the table.
