


## &lt;picLayer variable&gt;.DrawPolygon (Function)

***In french: &lt;Variable picCalque&gt;.DessinePolygone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a polygon in an [picLayer](../WDLang1/1000024604.md) variable.![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWDPicImage is WDPic = "Test.bmp"
MyLayer is picLayer

// Draw a 4-side polygon whose 
// background is light yellow and whose border is light blue
MyLayer.DrawPolygon(4, 10, 20, 20, 50, 40, 60, 50, 10, LightYellow, LightBlue)
IMG_MyDrawing = MyWDPicImage
```

## Syntax

### Building a polygon point by point

`<picLayer image>.DrawPolygon(<Number of sides> , <X1> , <Y1> , <X2> , <Y2> [, <X3> , <Y3> [... [, <Xn> , <Yn>]]] [, <Background color> [, <Side color>]])`
---

**`<picLayer image>: (picLayer variable)`**

Name of the [picLayer](../WDLang1/1000024604.md) variable to be used.

**`<Number of sides>: (Integer)`**

Number of sides in the polygon (up to 23 sides). This parameter defines the number of &lt;X&gt;, &lt;Y&gt; pairs to specify in the function.

**`<X1>: (Integer)`**

X-coordinate of first point of the polygon. These coordinates are expressed in pixels.

**`<Y1>: (Integer)`**

Y-coordinate of first point of the polygon. These coordinates are expressed in pixels.

**`<X2>: (Integer)`**

X-coordinate of second point of the polygon. These coordinates are expressed in pixels.

**`<Y2>: (Integer)`**

Y-coordinate of second point of the polygon. These coordinates are expressed in pixels.

**`<X3>: (Integer)`**

X-coordinate of 3rd point of the polygon. These coordinates are expressed in pixels.

**`<Y3>: (Integer)`**

Y-coordinate of 3rd point of the polygon. These coordinates are expressed in pixels.



**`<Xn>: (Optional integer)`**

X-coordinate of nth point of the polygon. These coordinates are expressed in pixels.

**`<Yn>: (Optional integer)`**

Y-coordinate of nth point of the polygon. These coordinates are expressed in pixels.

**`<Background color>: (Integer or constant (optional))`**

Polygon background color. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the background color:

- is *Transparent* if [&lt;picLayer variable&gt;.Background](../WDLang1/1000024480.md) has not been used beforehand, 

- corresponds to the color specified in the last call to [&lt;picLayer variable&gt;.Background](../WDLang1/1000024480.md).




**`<Side color>: (Integer or constant (optional))`**

Color of polygon sides. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the line color:

- is *Transparent* if [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) has not been previously used. 
	For a variable of type [Image](../WDLang1/1000019650.md), the line will be black. 

- corresponds to the color specified in the last call to [&lt;Image&gt;.Pen](../WDLang1/1000024016.md).

## Remarks


### Coordinates
<a name="coordinates_ELTPARAGRAPHE000795"></a>Drawing a polygon:

```wl
MyImage is WDPic
MyLayer is picLayer

MyLayer.DrawPolygon(5, 80, 10, 10, 150, 100, 200, 160, 80, 140, 40)
```
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=rbPolygo1.gif)
Coordinates are specified with respect to the upper-left corner of the image (coordinates: (0.0)).

**Note**: There is no need to close the polygon (the coordinates of the last point do not have to be equal to the coordinates of the first point). The polygon is automatically "closed".

**Limitations**: A polygon can have a maximum of 100,000 points in WINDEV, WEBDEV and Java, and 1,000 points in Windows CE.

### Drawing with opacity or anti-aliasing
<a name="drawing_with_opacity_antialiasing_ELTPARAGRAPHE000830"></a>

For a drawing with opacity ([&lt;picLayer variable&gt;.StartDrawing](../WDLang1/1000024470.md) with the *dWithOpacity* constant) or anti-aliasing ([&lt;picLayer variable&gt;.ChangeMode](../WDLang1/1000024432.md) with the *drawAntiAliasing* constant), the outline is drawn inside the polygon. This means that the line will partly be partly combined with the interior of the polygon. If the line is very thick, it will be displayed in two colors.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000921"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000943"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
