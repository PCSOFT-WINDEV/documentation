


## CertificateLoad (Function)

***In french: CertificatCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a certificate from a file or from a buffer. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Load from a file
arrCertificate is array of Certificate
MyCertificate is certificate

arrCertificate = CertificateLoad("MyCertificate.cer", "MyPassword")
MyCertificate = arrCertificate[1]
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Loading the certificate from a file

`<Result> = CertificateLoad(<Certificate file> , <Password>)`
---

**`<Result>: (Array of Certificates)`**

Array of [Certificate](../WDLang1/1000019287.md) variables containing the loaded certificates. 

**`<Certificate file>: (Character string)`**

Path of file containing the certificate to load.
 
This file can contain: 

- a PKCS#12 certificate of the "Public-Key Cryptography Standards" family. These files usually have a ".p12", ".cer" or ".crt" extension.

- a certificate in PFX format (predecessor to the PKCS#12 format). These files usually have a ".pfx" extension.


Note: If the certificate path is not specified, the certificate will be searched for in the project library. 

**`<Password>: (Character string or Secret string)`**

Certificate password.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 


<a name="SYNTAXE2"></a>

### Loading the certificate from a buffer

`<Result> = CertificateLoad(<Buffer> , <Password>)`
---

**`<Result>: (Array of Certificates)`**

Array of [Certificate](../WDLang1/1000019287.md) variables containing the loaded certificates. 

**`<Buffer>: (Buffer variable)`**

Buffer containing the certificate data. 

**`<Password>: (Character string or Secret string)`**

Certificate password.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).

## Remarks


- The certificate does not have to be found in the Windows store.

- This function can be used to load the certificate used by [SocketConnectSSL](../WDLang3/1000017042.md) and [NotifPushSend](../WDLang3/1000020819.md). 
	
	```wl
	arrCertificate is array of Certificates
	cerCertificatClient is a Certificate
	//------------------ Client certificate
	tabCertificate = CertificateLoad("Certificat_client.p12", PASS_CERTIF)
	IF ErrorDetected _OR_ tabCertificate.Occurrence < 1 THEN
		Error("No client certificate " + ErrorInfo(errMessage))
		RETURN
	END
	// Client certificate
	cerCertificatClient = tabCertificat[tabCertificat.Occurence]
	
	// It is possible to perform additional checks on the certificate
	// by directly manipulating the cerCertificatClient variable
	
	//------------------ Login
	IF NOT SocketConnectedSSL(sConnectionName, nPortNumber, sServerAddress, 
			ProtocoleTLS1_2 + ProtocoleTLS1_3, 5s,cerCertificatClient) THEN
		Error("Failed to connect to server [%sAdresseServeur%] on port [%nNumPort%]", 
				ErrorInfo())
		RETURN
	END
	Trace("Server found")
	// Rest of code
	```


- The certificate can be included in the project library (WDL file).
