


## Pivot Table control functions
			



**Note**: These functions are also available in prefix syntax ([Pivot Table control functions (prefix syntax)](../WDLang1/1000022194.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


These functions are used to manipulate Pivot Table controls:



|   |   |
| --- | --- |
| [PVTAxisXY](../WDLang1/1000021113.md) | Allows you to: <br><br>- Set the row and column headers displayed in a Pivot Table control. <br><br>- Get the row and column headers displayed in a Pivot Table control.<br><br><br><br><br> |
| [PVTCalculateAll](../WDLang1/1000020539.md) | Calculates or recalculates all the data of a Pivot Table control.<br><br> |
| [PVTCalculateAllAsynchronous](../WDLang1/1410090244.md) | Entirely calculates or recalculates a Pivot Table control, without blocking the application.<br><br> |
| [PVTCalculateUpdate](../WDLang1/1000020534.md) | Updates part of the data in a Pivot Table control from a given date.<br><br> |
| [PVTCalculateUpdateAsynchronous](../WDLang1/1410089990.md) | Updates some of the data found in a Pivot Table control from a given date without blocking the application.<br><br> |
| [PVTCollapse](../WDLang1/1000020698.md) | Collapses all the data in a Pivot Table control according to a row or column header. <br><br> |
| [PVTCollapseAll](../WDLang1/1000020622.md) | Collapses all row and/or column headers in a Pivot Table control.<br><br> |
| [PVTCompareDateRange](../WDLang1/1000024869.md) | Calculates and displays a date range comparison in a Pivot Table control.<br><br> |
| [PVTExpand](../WDLang1/1000020699.md) | Expands all the data in a Pivot Table control according to a row or column header.<br><br> |
| [PVTExpandAll](../WDLang1/1000020623.md) | Expands all row and/or column headers in a Pivot Table control.<br><br> |
| [PVTFilter](../WDLang1/1000020531.md) | Enables or disables a filter in a Pivot Table control.<br><br> |
| [PVTHeaderValue](../WDLang1/1000021135.md) | Returns the value displayed in a Pivot Table control header.<br><br> |
| [PVTInfoXY](../WDLang1/1000020735.md) | Returns the values of the headers at a given position expressed in pixels in a Pivot Table control.<br><br> |
| [PVTListPositionHeader](../WDLang1/1000020975.md) | Returns all values associated with a row or column header in a Pivot Table control.<br><br> |
| [PVTLoad](../WDLang1/1000020507.md) | Loads the result of a Pivot Table control calculation from a backup file located on disk or in a buffer.<br><br> |
| [PVTSave](../WDLang1/1000020471.md) | Saves the result of the calculation performed in a Pivot Table control (in a file or in memory).<br><br> |
| [PVTSelect](../WDLang1/1000021024.md) | Gets the position of selected cells and selects cells in a Pivot Table control. <br><br> |
| [PVTSelectCount](../WDLang1/1000022175.md) | Returns the number of selected cells in a Pivot Table control.<br><br> |
| [PVTToExcel](../WDLang1/1000020703.md) | Creates an Excel file with data from a Pivot Table control.<br><br> |
