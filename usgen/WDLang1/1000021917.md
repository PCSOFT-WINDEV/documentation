
## iCalendarToScheduler (Function)

***In french: iCalendarVersPlanning***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Imports data in iCalendar format into a Calendar control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
siCal is ANSI string
siCal = fLoadBuffer("calendar.ics")

iCalendarToScheduler(SCH_MySchedule, "user", siCal)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`iCalendarToScheduler(<Scheduler control> , <Resource> , <iCalendar data>)`
---

**`<Scheduler control>: (Control name)`**

Name of the Scheduler control to be used. This control can correspond to:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the Scheduler control of a window,

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the Scheduler control of a page,

- the Scheduler control of a report.




**`<Resource>: (Character string)`**

Name of the resource associated with the appointments. 

**`<iCalendar data>: (ANSI character string in UTF-8 format)`**

Data in iCalendar format.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To export data from a Scheduler control in iCalendar format, use [SchedulerToiCalendar](../WDLang1/1000021920.md). 

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available for the WEBDEV websites in Linux. This function is not available for WINDEV applications in Linux.
