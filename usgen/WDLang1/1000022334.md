


## &lt;Window&gt;.EdSelectPlus (Function)

***In french: &lt;Fenêtre&gt;.EdSelectPlus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Selects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add a control and select the control
X is Control
X -> ControlCreate("STC" + GetIdentifier(), typStatic, 10, 10, 100, 24, True)
X.Caption = "New text"
WIN_Form.EdSelectPlus(X)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Window>.EdSelectPlus([<Control used>])`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. This window must be in edit mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)).

**`<Control used>: (Optional control)`**

Control to select in the window. 

- If multiple selection is not enabled, the current selection is replaced with the specified control. 

- If multiple selection is enabled, the specified control is added to the selection. 


The function has no effect if the specified control is not selected.

If this parameter is not specified: 

- if multiple selection is enabled, all the controls in the window are selected.

- if multiple selection is not enabled, the function has no effect.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The selected control is returned by [&lt;Window&gt;.EdSelect](../WDLang1/1000022331.md).  

- If multiple selection is enabled, you can determine the number of selected controls with [&lt;Window&gt;.EdSelectOccurrence](../WDLang1/1000022333.md) and iterate over them with [&lt;Window&gt;.EdSelect](../WDLang1/1000022331.md).
