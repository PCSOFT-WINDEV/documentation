## New features in version 2026
<a name="new_features_version_docparamversioncom_06d04cb93e584c28b62fe7f474ce8772"></a>
List of new features classified by theme: 




|   |
| --- |
| **Environment** |




- Conversational AI in the environment:

	- Ask a question in your IDE and let the AI give you an answer.

	- Ask AI to execute actions in your projects. 

	- Get AI-powered answers about your project. 

	- Chat with your AI companion. 

	- Use the AI model of your choice: Claude, Mistral, Chatgpt, Gemini, etc.

	- Come back to previous conversations.

	- Undo one or multiple actions.







- Direct2D in the environment. 

- Modifier: New options. 

- Simplified environment configuration. 

- All environment tools available in 64-bit version .






|   |
| --- |
| **Project editor** |






- New security audit available. 

- Internal components:

	- Project dashboard: The "Component" widget now includes details on internal components. 

	- Internal components can be renamed. 




- Home window: 

	- The date on which projects were last opened is displayed.









- **WINDEV Mobile palettes**

	- Palette editor. 

		- New palette creation wizard. 

		- Edit existing palettes. 

		- View changes in the editor.




- New color palettes. 

- Dark palettes combined with light palettes.






|   |
| --- |
| **Window editor** |




- **New control**

	- Grid control: Use a grid for relative positioning in your UIs.







- **New Smart controls in WINDEV Mobile**

	- Clearer presentation of Smart controls.

	- New Smart controls: 

		- Segmented buttons. 

		- Product Looper. 

		- Event Looper. 

		- Token input with suggestions.







- **Improved controls in WINDEV Mobile**

	- Map control: 

		- OpenStreetMap

		- Multiple map formats available

		- Multiple layers supported on the same map




- Circular Progress Bar control:

	- Additional settings available. 




- **Window editor features**

	- Hot Reload: See your changes in real time, without leaving the test mode.

	- Edit and continue.   







- **New UI errors**

	- A UI error notification is displayed when the content of a Combo Box is empty in one of the languages associated with the project.









|   |
| --- |
| **Image editor** |




- Multiple selection with free-form tool. 

- Smart crop






|   |
| --- |
| **Data model editor** |




- New "Modifier" pane in the database schema. 

	- Information about the tables. 

	- Information about the items. \*




- Automatic database schema reorganization. \*






|   |
| --- |
| **Query editor** |




- Query optimization: Queries with overlapping condition ranges are optimized.






|   |
| --- |
| **Code editor** |




- Editor:

	- Ability to edit code files in text format: CSS, HTML, JSON, etc.

	- Semantic search in the code. 

	- Tooltips for web service procedures and variables. 

	- Current line highlighted in the code editor. 

	- Sortable methods and procedures. 

	- Regular expression generation wizard. 

	- New programming standard that indicates mixes of vocabulary. 

	- Ability to copy WLanguage code to third-party software: text and HTML formats









|   |
| --- |
| **Report editor** |




- Control templates. 

- Ability to create class-based reports (MVP)

- Ability to create reports based on an array of classes. 

- Flexbox in reports. 

- Scheduler reports: Weeks displayed in ISO 8601 format

- EXIF data for images in reports. 

- Radio Button control.

| --- |
| **SCM (Source Code Manager)** |




- Local history. 

- Error log. 

- Single repository backup file. 

- Notification when using an obsolete SCM repository version. 

- Branch support in executable patches. 

- Connection to multiple SCM repositories.








|   |
| --- |
| **Git / GitHub / GitLab** |




- Multilingual strings in text format.

- The features specified by an app administrator are automatically updated on the application download page.

- GDPR items are now indicated in the technical documentation.

- Rights management. 

- New actions:

	- Delete an SCM branch

	- Convert a project to text or binary format

	- Generate a project statistics file




- Software Factory administrator available in Spanish.

| **Tools** |




- Static audit: 

	- Detects the use of multilingual strings in legacy format (now deprecated)







- Security audit: 

	- Static security audit. 

	- Dynamic security audit. 







- Monitoring robot:

	- SSH monitoring. 

	- HFSQL server monitoring on a local area network (LAN)

	- Multilingual support (English and Spanish).





 




|   |
| --- |
| **Project Management Hub** |




- Sprint Burndown chart. 

- The Project Management Hub is now available in 64-bit version. 

- Multiple selection available in the incident list. 

- Filter by multiple sprints in the task and incident lists.


 






|   |
| --- |
| **User Groupware** |




- OAuth token for authentication.








|   |
| --- |
| **Programming and WLanguage** |




- **Internal component**: Factur-X

	- An internal Factur-X component is now available for generating electronic invoices. 

	- Multiple profiles supported. 

	- Generate the XML file

	- Smart choice of units. 

	- The Factur-X logo can be inserted.







- **GraphQL web services**: New graphqlQuery type. 




- **Chunked data**:

	- HTTPRequest variable: New ProcedureData property. 

	- New WebServiceSendChunk function. 







- **Email functions**: New functions to manage special cases: 

	- EmailExecuteCommand

	- EmailSubscribeToFolder

	- EmailUnsubscribeFromFolder









- **OAuth**

	- Certificate-based authentication to an OAuth server. 

	- JWT assertion support. 

	- Client Secret Basic authentication. 







- **OpenID**

	- Certificate-based authentication to a server. 

	- Client Secret Basic authentication. 







- **FTP functions**

	- New **ftpConnexion** variable type available for all FTP functions. 







- **SSH functions**

	- 2 new functions: **SSHConnectCommand** and **SSHDisconnectCommand**. 







- = operator for arrays.






- Trace window on mobile




- **Reactive procedure**

	- Unique and centralized code.

	- Declaration and options.

	- Watch local variables. 

	- Watch controls. 

	- Cascading mode. 

	- Determine if a control is observed or modified by a reactive procedure.  

	- Declare the variable to be observed. 







- **Navigation bar**: Ability to change button images. 

	- Visible property to make controls visible. 

	- Image property to change the image associated with a button. 







- Changes automatically applied when a sliding window is collapsed. 




- **Archives**:

	- 30% faster compression of ZIP archives

	- 90% faster compression of 7z archives







- **PDF**

	- PDF file protection details:

		- The **Protection** property gets the protection options of a PDF file. 

		- The **PDFPassword** and **iParameterPDF** functions can be used to define new protection options for PDF files.









- **OOP (Object Oriented Programming)**

	- Zombie attribute on classes.









- New functions, properties and types.

	- New functions

	- New types

- OAuth authorization server:

- Consume GraphQL web services.

| **HFSQL** |




- HFSQL semantic search

	- Semantic index creation. 

	- New SemanticSearch function to search semantic indexes

	- Search insensitive to spelling mistakes. 

		- Language-insensitive search.




- Limited number of notifications. 

- Asynchronous execution of stored procedures. 

- Password security policy. 

- New Linux driver for UnixODBC. 




- **SQL**

	- New SQL functions. 







- **WLanguage functions**

	- Password security policy functions. 

	- Asynchronous reindexing functions









- **HFSQL Docker**: 

	- Docker and Podman now support English and French, depending on the language specified as an environment variable in the docker image. 







- **HFSQL Cluster**

	- Optimizations. 

	- Faster node resynchronization. 

	- Automatic timestamp items. 







- **Universal replication**

	- Integrity errors according to the order of operations. \*

	- Ignore active filters.
