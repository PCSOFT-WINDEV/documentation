## Overview
<a name="overview_ELTTEXTE000148"></a>
WEBDEV includes several WEBDEV Application Servers: 

- **The complete WEBDEV Application Server** (deployment version): This WEBDEV Application Server lets you take advantage of all WEBDEV features: 

	- Unlimited connections for WEBDEV websites and web services, 

	- Specific applications (Replication server, Telemetry server, BaaS modules, web services for access to third-party databases).

	- OAuth server.

	- WEBDEV Cluster support.  

	- WEB Administrators: SaaS, HFSQL, WEBDEV Application Server.




- **WEBDEV Application Server 10 connections** This WEBDEV Application Server can only manage 10 simultaneous connections to WEBDEV sites and web services. 




Remarks: 

- Starting with version 28, a single setup program is used to install both the full version of WEBDEV Application Server and WEBDEV Application Server - 10 connections. 

- As of version 2026, the Reserved server (present in previous versions) is no longer available.
