## New features in version 2026
<a name="new_features_version_docparamversioncom_1fea3c536ceb4abaae605d67105bb437"></a>
List of new features classified by theme: 




|   |
| --- |
| **Environment** |




- Conversational AI in the environment:

	- Ask a question in your IDE and let the AI give you an answer.

	- Ask AI to execute actions in your projects. 

	- Get AI-powered answers about your project. 

	- Chat with your AI companion. 

	- Use the AI model of your choice: Claude, Mistral, Chatgpt, Gemini, etc.

	- Come back to previous conversations.

	- Undo one or multiple actions.







- Direct2D in the environment. 

- Modifier: New options. 

- Simplified environment configuration. 

- All environment tools available in 64-bit version .






|   |
| --- |
| **Project editor** |




- New security audit available. 

- Internal components:

	- Project dashboard: The "Component" widget now includes details on internal components. 

	- Internal components can be renamed. 




- Home window: 

	- The date on which projects were last opened is displayed.









- New project configuration: DLL.

- Warning message: Executable file with compilation errors.






- MVP RAD: Report generation.






- **WINDEV palettes**

	- Palette editor.

		- New palette creation wizard. 

		- Edit existing palettes. 

		- View changes in the editor.  




- New color palettes.

- Dark palettes combined with light palettes. 

- Toasts: Automatically adapt to the colors of the current palette. \*

- Gradient with palette colors. 

- Installer with the app's color palette.

| **Window editor** |




- **New control**

	- AI Chat control: 

		- Integrate the AI model of your choice into your WINDEV applications. 

		- Integrate a conversational AI companion into your applications. 




- Grid control: Use a grid for relative positioning in your UIs.




- **New Smart controls in WINDEV**

	- Clearer presentation of Smart controls. 

	- New Smart controls: 

		- Segmented buttons. 

		- Product Looper. 

		- Event Looper. 

		- IBAN input with document database schema. 

		- SIREN number with code checker.







- **Improved controls in WINDEV**

	- Edit controls: 

		- Define the style of buttons displayed in Edit controls.




- Pivot Table control: 

	- By default, Pivot Table controls preserve previously set layout options. 

	- Pivot Table controls can now be calculated asynchronously. 




- **Window editor features**

	- Hot Reload: See your changes in real time, without leaving the test mode.

	- Edit and continue.   







- **New UI errors**

	- A UI error notification is displayed when the content of a Combo Box is empty in one of the languages associated with the project.

	- Regular expression generation wizard. 

	- New programming standard that indicates mixes of vocabulary. 

	- Ability to copy WLanguage code to third-party software: text and HTML formats







- Debugger: 

	- Breakpoints: Memory leak detection. 

	- Edit and Continue. 

	- View long strings.

- Flexbox in reports. 

- Scheduler reports: Weeks displayed in ISO 8601 format

- EXIF data for images in reports. 

- Radio Button control. 

- Report viewer: Tooltip on controls

- Reports and Queries is now available in 64-bit version.

- Branch support in executable patches. 

- Connection to multiple SCM repositories.

- Multilingual strings in text format.

- Pivot Table control

	- The "Remember size and groups" option also saves the order of headers defined by the end user. \*

- OAuth token for authentication.




- BaaS mode: The **gpwFindUser** function is now available.






|   |
| --- |
| **Programming and WLanguage** |






- **Internal component**: Factur-X

	- An internal Factur-X component is now available for generating electronic invoices. 

	- Multiple profiles supported. 

	- Generate the XML file

	- Smart choice of units. 

	- The Factur-X logo can be inserted.







- **GraphQL web services**: New graphqlQuery type. 




- **Chunked data**:

	- HTTPRequest variable: New ProcedureData property. 

	- New WebServiceSendChunk function. 







- **Email functions**: New functions to manage special cases: 

	- EmailExecuteCommand

	- EmailSubscribeToFolder

	- EmailUnsubscribeFromFolder









- **OAuth**

	- Certificate-based authentication to an OAuth server. 

	- JWT assertion support. 

	- Client Secret Basic authentication. 







- **OpenID**

	- Certificate-based authentication to a server. 

	- Client Secret Basic authentication. 







- **FTP functions**

	- New **ftpConnexion** variable type available for all FTP functions. 







- **SSH functions**

	- 2 new functions: **SSHConnectCommand** and **SSHDisconnectCommand**. 







- = operator for arrays.






- FOR EACH statement: &lt;Ignore filter&gt; attribute to iterate over every element in a table regardless of any active filters. 




- **Certificate-based signature with smart cards**

	- All signature functions support certificates stored on smart cards. 







- **PDF**

	- PDF file protection details:

		- The **Protection** property gets the protection options of a PDF file. 

		- The **PDFPassword** and **iParameterPDF** functions can be used to define new protection options for PDF files. 




- Ability to identify the control at cursor position. 




- **Window opening**:

	- Initialize the properties of a window before opening it. 

	- Initialize parameters passed to a window before opening it.







- **Reactive procedure**

	- Declare the variable to be observed. 







- **Windows notifications**:

	- Progress bars. 

	- New functions and properties. 







- **Archives**:

	- Creation of self-extracting 64-bit archives. 

	- Ability to specify a version number when creating a self-extracting archive. 

	- 30% faster compression of ZIP archives

	- 90% faster compression of 7z archives







- **JSON**

	- Binary serialization of JSON types.

	- The JSONToString function can now encode accented characters using UTF-8.









- **OOP (Object Oriented Programming)**

	- New "Classes are references" mode. 

		- Simplified parameter passing mode. 

		- Ability to apply mode to the project or to an internal component

		- Ability to modify the caller's reference.

		- Nullable classes




- Zombie attribute on classes. 

- Equal structures. 

- Reflection: Retrieve methods of classes overridden by reflection. 

- Interfaces: IS and DOWNCAST keywords and Class property now available.






- **New functions, properties and types**.

	- New function families: 

		- AI Chat control functions. 

		- Shamir's secret sharing functions. 




- New functions: 

	- Window functions

		- **WinListOpenWindow**: Lists all open windows. 

		- **WinListOpenChildWindow**: Lists child windows opened by a given window. 

- **Updated functions**:

	- **TablePosition**: New constant for showing the end of the last row. 

	- **SysWindowsVersion**: The *sysIsServer* constant indicates whether the current operating system is server-specific. 




- **Updated types**:

	- **pvtPosition**: Gets the details about an element selected in a Pivot Table control. \*









- **Third-party languages**:

	- Third-party language support in the code editor.









- **IOT**

	- Ability to determine the status of an MQTT connection. 

	- Ability to pass a Windows Certificate Store as a parameter to the **SocketCreateSSL** function.
