## Overview

### The WEBDEV administrator
<a name="the_webdev_administrator_ELTPARAGRAPHE000011"></a>

The WEBDEV administrator is a module used to manage dynamic WEBDEV websites (in Session or AWP mode).

When developing a dynamic WEBDEV website, the administrator is mainly used to:

- run the test of the site via the test page ("Advanced" tab, "Test page" option).

- set site connection parameters for your tests: disconnection time, ... ("Configuration" tab).

- delete the current test connections ("Connections" tab).

- choose the web server used for testing ("Advanced" tab, "Server").

- perform diagnostics in the event of a problem when launching a WEBDEV site ("Configuration" tab, "Diagnostics" option).

- ...




During the deployment phase, two types of WEBDEV administrators are available:

- **the WEBDEV Deployment administrator**, supplied with the WEBDEV Application Server, that allows the hosting provider to manage the dynamic WEBDEV websites installed on a Web server.

- **the remote WEBDEV administrator** that allows the site manager to manage their dynamic WEBDEV websites remotely from any computer.




This help page presents only the administrator for WEBDEV Development version.

For more details, see the help about the other types of WEBDEV administrator.

## Starting the administrator of WEBDEV Development version
<a name="starting_the_administrator_webdev_development_version_ELTTEXTE000184"></a>
To start the administrator of WEBDEV Development version, use one of the following methods:

- On the "Tools" tab, in the "Web utilities" group, click "WDAdmin" in WEBDEV Development version.

- Select "Programs .. WEBDEV 2026 .. WEBDEV administrator" from the "Start" menu.




The WEBDEV administrator is automatically launched the first time the site is tested.. The administrator can then be left running in the background.

By default, the WEBDEV administrator allows ten simultaneous connections to the same dynamic WEBDEV website (GO icon).

**Remark**: When WEBDEV administrator is launched, the corresponding icon appears in the Windows taskbar.. The context menu of the systray icon allows you to: 

- open the administrator. 

- exit the administrator. 

- disconnect all users.

## Interface of the administrator of WEBDEV Development version
<a name="interface_the_administrator_webdev_development_version_ELTTEXTE000208"></a>
The administrator of WEBDEV Development version includes a window with several tabs:

- ["Connections"](../WDAdmin/3539041.md) tab to configure the characteristics of current connections.

- ["Sites"](../WDAdmin/3539008.md) tab, which lists the WEBDEV websites installed on the current computer.

- ["Web services"](../WDAdmin/3539075.md) tab, which lists the WEBDEV web services installed on the current computer. This tab is identical to ["Sites"](../WDAdmin/3539008.md) but for web services. 

- ["WebSockets"](../WDAdmin/3539082.md) tab, which lists the WebSocket servers installed on the current computer. 

- ["Configuration"](../WDAdmin/3539046.md) tab to configure the general configuration of WEBDEV websites installed on the current computer.

- ["Setups/Accounts"](../WDAdmin/3539065.md) tab to manage the WEBDEV server on the current computer.

- ["Advanced"](../WDAdmin/3539066.md) tab to configure specific features.

- ["Logs"](../WDAdmin/3539073.md) tab to analyze the log status reports. 




Note: Some WEBDEV administrator functions can be controlled via WLanguage functions.. For more details, see [WEBDEV Application Server administration functions](../WDLang2/1410089709.md).
