## Overview
<a name="overview_ELTTEXTE000074"></a>
Using reference mode implies making numerous changes in the way you handle object-oriented types:

- structures

- classes

- advanced types

- Control type

- Window type

- .NET objects

- Python objects


It is not recommended to enable this option in existing projects. Many changes need to be made to the code of your application.
