
## Explicit conversion operator for classes
			

<a name="description"></a>
The downcast operator allows you to convert a base class to a derived class without using a local variable. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Call a method of the derived class
an_instance is BaseClass <- Null
IF an_instance is DerivedClass THEN
	((DerivedClass)an_instance).DerivedMethod()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Static conversion: Causes a runtime exception if the conversion is invalid

`((<Derived class>) <Base class instance>)`
---

**`<Derived class>: ()`**

Class that derives from the base class.

**`<Base class instance>: ()`**

Instance of the base class to be converted to the &lt;Derived class&gt;. 


<a name="SYNTAXE2"></a>

### Dynamic conversion: Returns Null if conversion is invalid

`((<Derived class>?) <Base class instance>)`
---

**`<Derived class>: ()`**

Class that derives from the base class.

**`<Base class instance>: ()`**

Instance of the base class to be converted to the &lt;Derived class&gt;.

**Note**: Static conversion does not cause runtime errors if the conversion is invalid. A dummy object is returned for which the comparison to **Null** returns <u><u><u><u>True</u></u></u></u>. A compilation error will be displayed if this dummy object is manipulated.
