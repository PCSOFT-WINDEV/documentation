## Overview
<a name="overview_ELTTEXTE000103"></a>
WDHFDiff is a tool used to compare HFSQL tables.

WDHFDiff is used to compare:

- [structure of two HFSQL tables](../WDHFDiff/3542002.md).

- [table found in two HFSQL tables](../WDHFDiff/3542002.md).

- [common tables found in two different directories](../WDHFDiff/3542002.md).




The tables used must be in HFSQL format (HFSQL Classic or Hyper File 5.5).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Starting WDHFDiff
<a name="starting_wdhfdiff_ELTTEXTE000127"></a>
WDHFDiff can be started:

- from WINDEV, WEBDEV or WINDEV Mobile. To do so, go to the "Tools" tab, "Database" group and select "WDHFDiff".

- by directly running the "WDHFDiff.EXE" file in the "Programs" subdirectory of the WINDEV, WEBDEV or WINDEV Mobile installation directory.



<a name="NOTE2_2"></a>


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000052"></a>

WDHFDiff cannot be redistributed. WDHFDiff cannot be installed with applications developed with WINDEV, WEBDEV or WINDEV Mobile.

To use WDHFDiff, WINDEV, WEBDEV or WINDEV Mobile must necessarily be installed on the current computer.
