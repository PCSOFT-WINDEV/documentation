


## &lt;Chart&gt;.AxisTitleFont (Function)

***In french: &lt;Graphe&gt;.PoliceTitreAxe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the font used for the titles of the chart axes.

Example of titles for the axes: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titreaxe.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the font used for
// the title of axes in "CHART_MyChart".
MyFont is Font
MyFont.Name = "Arial"
MyFont.Size = 12
MyFont.Bold = True
CHART_MyChart.AxisTitleFont(MyFont)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Defining the font used for the title of the chart axes

`<Chart control>.AxisTitleFont(<Font used>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control used in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font used>: (Font)`**

Font to use. This parameter corresponds to a variable of type [Font](../Motscles/1514045.md). The font characteristics have been defined with [FontCreate](../WDLang1/3060002.md) or via the [font properties](../Proprietes/2515045.md).


<a name="SYNTAXE2"></a>

### Defining the font used for the title of the chart axes (syntax kept for backward compatibility)

`<Chart control>.AxisTitleFont(<Font identifier>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control used in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font identifier>: (Integer)`**

Font identifier, defined by [grCreateFont](../WDLang3/3042001.md). A WLanguage error occurs if this font does not exist.

<a name="NOTE0_1"></a>

## Remarks


### Chart title
<a name="chart_title_ELTPARAGRAPHE000280"></a>The title of chart axes can be displayed for the different axes.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titre.gif)
The content of the title for the chart axes is defined by [&lt;Chart&gt;.AxisTitle](../WDLang3/1000024153.md). This function can also be used to set the position of the title.

The font used for the chart title can be modified by **&lt;Chart&gt;.AxisTitleFont**.
<a name="NOTE0_2"></a>


### Initializing fonts
<a name="initializing_fonts_ELTPARAGRAPHE000301"></a>

The default font used for the title of the axes has the following characteristics:

- Font name: Arial,

- Size: 14,

- Style: Normal,

- Color: Black.
