


## grSeriesSecondaryAxis (Function)

***In french: grSérieAxeSecondaire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines whether a series will be drawn on the secondary axis.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Places the series 2 of GRF_MyCHart on the secondary axis
grSeriesSecondaryAxis(GRF_MyChart, 2, True)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grSeriesSecondaryAxis(<Chart name> , <Series number> , <Position>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of Chart control.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to modify.

**`<Position>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to set the series position on the secondary axis, 

- <u><u><u><u>False</u></u></u></u> otherwise.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- This function can only be used on the charts with axes. It does not work with the Pie, Radar or Funnel charts.

- This function is equivalent to the [SecondaryAxis](../Proprietes/1000019187.md) property.
