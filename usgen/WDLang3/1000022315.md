### Sending an email via MS Exchange, Lotus Notes or Outlook

`<Result> = EmailSendMessage(<Session ID> [, <Email> [, <Display> [, <Type>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the message was placed in the outbox of MS Exchange, Lotus Notes or Outlook,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session ID>: (Integer or emailOutlookSession variable)`**



**`<Email>: (Optional Email variable)`**

Name of the [Email](../WDLang3/1000018713.md) variable corresponding to the email to be sent.

If this parameter is not specified, the information contained in the [Email](../WDLang3/3032029.md) structure is used.

**`<Display>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> to display the message in a dialog box before sending it,

- <u><u><u><u>False</u></u></u></u> (by default) to display no dialog box.




This parameter is taken into account only if the email session was started by [&lt;EmailOutlookSession variable&gt;.StartSession](../WDLang3/1000022302.md), by using the MS Exchange syntax with a profile name. In the other cases, the dialog box is not displayed.

**Note**: This parameter is not available for Lotus Notes.

**`<Type>: (Optional character string)`**

Describes the type of message to send. By default, &lt;Type&gt; = "IPM" (Inter Personal Message).

### Asynchronous mode
<a name="asynchronous_mode_ELTPARAGRAPHE000432"></a>

If the session was started in asynchronous mode ([&lt;EmailOutlookSession variable&gt;.StartSession](../WDLang3/1000022302.md) and [EmailStartSMTPSession](../WDLang3/3032025.md)), **&lt;emailOutlookSession variable&gt;.SendMessage** creates an identifier for each email sent.

The email identifier is stored in the ***Email.MailIdentifier*** variable and can be used by [EmailStatus](../WDLang3/3032009.md) to get the current status of the outgoing email (sent, in progress, etc.).

Line error handling in asynchronous mode: The function **&lt;emailOutlookSession variable&gt;.SendMessage** function returns <u><u><u><u>True</u></u></u></u> if the Email is placed in the Email spooler, <u><u><u><u>False</u></u></u></u> if it is not possible to contact the spooler. To determine if the email was sent, use [EmailStatus](../WDLang3/3032009.md).
