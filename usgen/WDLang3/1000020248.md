


## Event (Variable type)

***In french: Evénement***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Event** type allows you to define all the advanced features of an event (birthday, anniversary, etc.)

You can define and change the characteristics of this event using different WLanguage properties. 

This type of variable is used by the [Contact](../WDLang3/1000020254.md) variables.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieves the birthday of a contact
sDate is string
FOR EACH evt of MyContact.Event
	IF evt.Type = evtBirthday THEN
		sDate = evt.RawDate
		RETURN
	END
END
```

## Properties


### Properties specific to Event variables
<a name="properties_specific_event_variables_ELTPARAGRAPHE000040"></a>

The following properties can be used to handle an event:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Label | Character string | Label for the custom types of events (optional).<br>If the **Type** property does not correspond to the *evtCustom* constant, the value of this property will be ignored. |
| RawDate | Character string | Start date of the event. The character string is not formatted.<br><br> |
| Type | Integer constant | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Type of event: <br><br>- *evtBirthday*: Birthday/Date of birth. <br><br>- *evtOther*: Other types.<br><br>- *evtAnniversary*: Anniversary.<br><br>- *evtCustom*: Custom type corresponding to the value of the **Label** property.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Type of event: <br><br>- *evtAnniversary*: Anniversary.<br><br>- *evtCustom*: Custom type corresponding to the value of the **Label** property.<br><br><br> |
