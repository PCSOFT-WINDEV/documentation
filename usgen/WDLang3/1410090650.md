## Syntax
<a name="SYNTAXE1"></a>

`SharingProximityDemandConnection(<Remote device identifier> , <Device name> , <IncomingData procedure> , <Notification procedure>)`
---

**`<Remote device identifier>: (Character string)`**

Identifier of the remote device you wish to connect to. This identifier was received as a parameter to the callback procedure passed to function [SharingProximitySearchApparatus](../WDLang3/1410090648.md).#

**`<Device name>: (Character string)`**

Name of device requesting connection. This name will be received by the remote device as a parameter of the [SharingProximityAttendConnection](../WDLang3/1410090655.md) function procedure executed when the remote device receives the connection request.n

**`<IncomingData procedure>: (Procedure name)`**

Name of the WLanguage procedure (also called "callback") executed when the connection request has been received by the remote device.
In the code of this procedure, it is customary to accept the connection (function [ShareCloseAcceptConnect](../WDLang3/1410090646.md)) or to refuse it (function [SharingProximityRefuseConnection](../WDLang3/1410090651.md)). 

For more details on this procedure, see [Parameters of the procedure used by the ShareProximityRequestConnection function (Request)](../WDLang3/1410090666.md).

**`<Notification procedure>: (Procedure name)`**

Name of the WLanguage procedure (also called "callback") called to notify the status of the connection with a remote device.t

For more details on this procedure, see [Parameters of the procedure used by the ShareProximityRequestConnection function (Notification)](../WDLang3/1410090667.md).

<a name="NOTE0_1"></a>

## Remarks


- The function **ShareCloseRequestConnection FUNCTION** function can be called when a remote device has been found following a call to the [SharingProximitySearchApparatus](../WDLang3/1410090648.md) function.#

- If the remote device accepts the connection request, the IncomingData procedure passed to the **ShareCloseRequestConnection FUNCTION** function will be executed, and it will then be possible to accept the connection in turn ([ShareCloseAcceptConnect](../WDLang3/1410090646.md) function) to start exchanging data with the remote device.t
