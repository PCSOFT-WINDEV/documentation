


## &lt;btleCharacteristic variable&gt;.GetADescriptor (Function)

***In french: &lt;Variable btleCaractéristique&gt;.RécupèreUnDescripteur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the descriptor of a Bluetooth Low Energy characteristic corresponding to the specified identifier (UUID).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyDevice is btleDevice
...
MyDesc is btleDescriptor 
MyCharacteristic is btleCharacteristic
MyCharacteristic = MyDevice.Service[1].Characteristic[1]

MyDesc = MyCharacteristic.GetADescriptor("AD09")
IF ErrorOccurred THEN
	Error("The descriptor does not exist.")
	RETURN
END
...
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Characteristic>.GetADescriptor(<Identifier>)`
---

**`<Result>: (btleDescriptor variable)`**

[btleDescriptor](../WDLang3/1000022064.md) variable corresponding to the information of requested descriptor. If no descriptor corresponds to the specified identifier, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>.

**`<Characteristic>: (btleCharacteristic variable)`**

Name of the [btleCharacteristic](../WDLang3/1000022060.md) variable corresponding to the characteristic used.

**`<Identifier>: (Character string)`**

Identifier (UUID) of descriptor to retrieve.
