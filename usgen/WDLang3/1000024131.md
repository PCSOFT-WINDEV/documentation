


## &lt;Chart&gt;.SeriesSecondaryAxis (Function)

***In french: &lt;Graphe&gt;.SérieAxeSecondaire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines whether a series will be drawn on the secondary axis.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Places the series 2 of GRF_MyCHart on the secondary axis
CHART_MyChart.SeriesSecondaryAxis(2, True)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart control>.SeriesSecondaryAxis(<Series number> , <Position>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to be used. 
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to modify.

**`<Position>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to set the series position on the secondary axis, 

- <u><u><u><u>False</u></u></u></u> otherwise.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- This function can only be used on the charts with axes. It does not work with the Pie, Radar or Funnel charts.

- This function is equivalent to the [SecondaryAxis](../Proprietes/1000019187.md) property.
