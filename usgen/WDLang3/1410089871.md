
## NotifPushUnsubscribe (Function)

***In french: NotifPushDésabonne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Unsubscribes an Android application from a topic. The application will no longer receive notifications sent with [NotifPushSendSubscriber](../WDLang3/1410089872.md) for the specified topic.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The application will no longer receive notifications related to the "score" topic
NotifPushUnsubscribe("score")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = NotifPushUnsubscribe(<Topic>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if unsubscribed successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) is used to identify the error returned by the notification service.




**`<Topic>: (Character string)`**

Topic of the notifications from which to unsubscribe the application.
