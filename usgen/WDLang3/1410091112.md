


## SSHConnectCommand (Function)

***In french: SSHConnecteCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Keeps the SSH session active between several commands sent to an SSH server (using the [SSHCommand](../WDLang3/1000021143.md) function)

Reminder: By default, when sending a command to an SSH server, the session is opened and closed automatically after the command has been sent.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Session is sshSession
// Session properties
// ...
// Initialize SSH session to keep
SSHConnectCommand(Session)
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
// Close SSH session to go back to normal behavior
SSHDisconnectCommand(Session)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SSHConnectCommand(<SSH session>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the session has been opened correctly,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<SSH session>: (sshSession variable)`**

Name of a variable of type [sshSession](../WDLang3/1000021157.md) containing the connection parameters of the SSH session to keep open
