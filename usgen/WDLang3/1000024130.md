


## &lt;Chart&gt;.PiePullOut (Function)

***In french: &lt;Graphe&gt;.SecteurPartExcentrée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Pulls out a section (or all sections) in a chart. This function can be used on Pie charts, on Donut charts and on Semi-circular charts.

Example of pulled-out section in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grSecteurPartExcentr%E9e%20-%20HC%20N%B0002.gif)


**Note** Each part of the graph can be eccentric independently of the others.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Pull out the third section by 20 pixels in "CHART_MyChart"
CHART_MyChart.PiePullOut(3, 20)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Eccentricity on one side

`<Chart control>.PiePullOut(<Section subscript> , <Offset>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Section subscript>: (Integer)`**

Index of section to pull out.

**`<Offset>: (Integer)`**

Offset of specified section (in pixels).


<a name="SYNTAXE2"></a>

### Eccentricity on all sides

`<Chart control>.PiePullOut(<Offset>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Offset>: (Integer)`**

Offset of different sections (in pixels).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Pulling out a chart section has no effect on the charts other than the Pie charts, the Donut charts and the Semi-circular charts.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Semi-circular charts are not available.

- Any changes made with **&lt;Chart&gt;.PiePullOut** will take effect the next time [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is called.
