
## NearbyShareSend (Function)

***In french: PartageProximitéEnvoie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends data (binary buffer) to one or more nearby devices to which the current device is connected.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareSend(garrSelectedDevices, EDT_Message, CallbackSend)
```



```wl
PROCEDURE CallbackSend(bResult is boolean, nTransferID is int)
IF bResult THEN
	ToastDisplay("Message sent")
ELSE
	ToastDisplay(ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Send data to a single device

`NearbyShareSend(<Nearby device identifier> , <Data to send> [, <WLanguage procedure>])`
---

**`<Nearby device identifier>: (Character string)`**

Identifier of the device to which data is to be sent.

**`<Data to send>: (Buffer)`**

Data to be sent to the nearby device.
Data size is limited to 1047552 bytes (approximately 1 MB). 
To send more data, split it and send it in several parts, or use a file on disk ([NearbyShareSendFile](../WDLang3/1410090654.md)).

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called to notify whether or not the data was sent successfully. 
**Note**: If successful, this does not mean that the data has been received by the nearby device. You need to use the procedure of the [NearbyShareAcceptConnection](../WDLang3/1410090646.md) function to monitor the status of the transfer.
For more details on this procedure, see [Parameters of the procedure used by NearbyShareSend](../WDLang3/1410090645.md). 


<a name="SYNTAXE2"></a>

### Sending data to multiple devices

`NearbyShareSend(<Device list> , <Data to send> [, <WLanguage procedure>])`
---

**`<Device list>: (WLanguage array)`**

Name of the WLanguage array containing the list of identifiers of the devices to which data is to be sent.

**`<Data to send>: (Buffer)`**

Data to be sent to nearby devices.
Data size is limited to 1047552 bytes (approximately 1 MB). 
To send more data, split it and send it in several parts, or use a file on disk ([NearbyShareSendFile](../WDLang3/1410090654.md)).

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called to notify whether or not the data was sent successfully. 
**Note**: If successful, this does not mean that the data has been received by the nearby device. You need to use the procedure of the [NearbyShareAcceptConnection](../WDLang3/1410090646.md) function to monitor the status of the transfer.
For more details on this procedure, see [Parameters of the procedure used by NearbyShareSend](../WDLang3/1410090645.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **NearbyShareSend** sends data in a single block. 

- Data sent with **NearbyShareSend** is always received in the order in which it was sent. However, the order of files sent with [NearbyShareSendFile](../WDLang3/1410090654.md) is unknown.
