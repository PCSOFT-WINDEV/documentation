
## TaskPrevious (Function)

***In french: TâchePrécédent***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads the task before the current task in a Lotus Notes or Outlook task list. This task becomes the current task.

When reading a task, the data of this task is updated in the [Task structure](../WDLang3/1000012010.md). To retrieve the data of the current task, simply retrieve the values of the [Task structure](../WDLang3/1000012010.md).

**Note**: This function **cannot be used** to read the task before the current task in an Outlook Express task list.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf",...
					"C:\Users\Julia\AppData\Local\Lotus\Notes\Data\user.id")

// Read the last task
TaskLast(SessionID)
// Add the tasks found into a list
WHILE mTask.Out = False
	ListAdd(LIST_TaskList, mTask.Subject + TAB + mTask.Category)
	TaskPrevious(SessionID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TaskPrevious(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the previous task was read, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md). 




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).

## Remarks




### Current task
<a name="current_task_ELTPARAGRAPHE000068"></a>

The mTask.Out variable is used to find out whether a current task exists.
