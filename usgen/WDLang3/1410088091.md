


## &lt;Chart&gt;.StartAngle (Function)

***In french: &lt;Graphe&gt;.AngleDépart***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the starting angle of the first section in the following types of chart:

- Pie, Semi-circular and Donut.

- Sunburst.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Radial Bar chart.




Example of the starting angle in a Semi-circular chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grSecteurPartExcentr%E9e%20-%20HC%20N%B0001.gif)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase the starting angle of "CHART_MyChart"
CHART_MyChart.StartAngle(45)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart name>.StartAngle(<Angle>)`
---

**`<Chart name>: (Control name)`**

Name of the Chart control to use in the window, page or report editor.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Angle>: (Integer)`**

Starting angle of the first section (expressed in degrees, clockwise from the top point). 
By default, the starting angle in a Pie chart, Semi-circular chart or Donut chart is 0.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Only the following charts allow defining the starting angle of the first section: 

	- Pie charts (*grPie* constant). 

	- Semi-circular charts (*grSemiCircular* constant).
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of chart is not available.

	- Donut charts (*grDonut* constant).

	- Radial Bar charts (*grRadialBar*constant).
			![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of chart is not available.




- The data defined by **&lt;Chart&gt;.StartAngle** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The data defined by **&lt;Chart&gt;.StartAngle** is taken into account immediately.
