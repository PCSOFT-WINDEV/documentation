


## grPieStartAngle (Function)

***In french: grSecteurAngleDépart***

<a name="description"></a>
Indicates the starting angle of the first slice in a Sector, Hemicycle or Donut graph.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 










<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase the starting angle of "CHART_MyChart"
grPieStartAngle(CHART_MyChart, 45)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grPieStartAngle(<Chart name> , <Angle>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Angle>: (Integer)`**

Starting angle of the first section (expressed in degrees, clockwise from the top point). 
By default, the starting angle in a Pie chart, Semi-circular chart or Donut chart is 0.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Only the following charts allow defining the starting angle of the first section: 

	- Pie charts (*grPie* constant). 

	- Semi-circular charts (*grSemiCircular* constant).
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of chart is not available.

	- Donut charts (*grDonut* constant).




- The data defined by **grPieStartAngle** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The data defined by **grPieStartAngle** is taken into account immediately.
