


## &lt;Chart&gt;.ScatterPointSize (Function)

***In french: &lt;Graphe&gt;.NuageTaillePoint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the size of points in a "Scatter" chart. 

**Reminder**: By default, the size of points in a Scatter chart is 1 pixel.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase the size of points in "CHART_MyChart".
// This chart is a "Scatter" chart.
CHART_MyChart.ScatterPointSize(3)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.ScatterPointSize(<Size>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Size>: (Integer)`**

Size of a point (in pixels).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Size of a point
<a name="size_point_ELTPARAGRAPHE000249"></a>The point is a square and its sides are calculated using the following formula: (&lt;Size&gt;\*2)-1 pixels.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Graphe2.gif)

<a name="NOTE0_2"></a>


### Points in the "Scatter" charts
<a name="points_the_scatter_charts_ELTPARAGRAPHE000260"></a>

- In the "Scatter" charts, a point is defined by its coordinates (X-coordinate and Y-coordinate).

- The data defined by **&lt;Chart&gt;.ScatterPointSize** will be taken into account in the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).

- **&lt;Chart&gt;.ScatterPointSize** can only be used for the "Scatter" charts. This function has no effect with the other types of charts.
