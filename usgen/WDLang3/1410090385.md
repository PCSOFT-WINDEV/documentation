


## &lt;QuickAction variable&gt;.Add (Function)

***In french: &lt;Variable ActionRapide&gt;.Ajoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a new quick action to the application. This quick action will appear in the context menu of the application icon.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
action is QuickAction
action.Identifier = "ACTION_ID__SEND_MESSAGE"
action.Caption = "Send a message"
action.Procedure = ProcSendMessage // ProcSendMessage is a global procedure
IF action.Add() THEN
	ToastDisplay("Action added.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Action>.Add()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the quick action was added,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<Action>: (QuickAction variable)`**

[QuickAction](../WDLang3/1410090054.md) variable describing the action to be added.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If a quick action with the same identifier has already been added to the application, it will be updated with the data contained in the [QuickAction](../WDLang3/1410090054.md) variable passed as parameter.

- To list quick actions already added to the application, use [QuickActionList](../WDLang3/1410090067.md).

- To remove a quick action defined for the application, use [&lt;QuickAction variable&gt;.Remove](../WDLang3/1410090386.md).
