


## DriveListDirectory (Function)

***In french: DriveListeRépertoire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists drive directories.

## Example


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

ResEnvoi est un booléen
oMonDrive est un Drive
oMonDrive = oDriveConnecte(oOAuth2Param)

UnRépertoire, ResListeRépertoire sont des chaînes
// Liste tous les répertoires dans mon drive depuis le répertoire "MesPhotos".
// Le parcours se fait uniquement dans le répertoire courant 
ResListeRépertoire = DriveListeRépertoire(oMonDrive, "/MesPhotos/", frNonRécursif)

// Pour chaque répertoire trouvé, ajout dans un champ Table
POUR TOUTE CHAÎNE UnRépertoire DE ResListeRépertoire SÉPARÉE PAR RC
	// Ajout du répertoire dans le champ Table TABLE_TableRépertoire
	TableAjoute(TABLE_TableRépertoire, UnRépertoire)
FIN
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DriveListDirectory(<Drive> , <Start directory> [, <Options>])`
---

**`<Result>: (Character string)`**

List of directories on the specified drive, at the specified location. This list has the following format: 

```txt
<Nom du répertoire 1> + RC + ... + <Nom du répertoire N>
```


**`<Drive>: (Drive or gglDrive variable)`**

Name of the [Drive](../WDLang3/1410089369.md) or [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the drive to be used. The connection to the drive must have been previously established. Otherwise, directories will not be listed. 

**`<Start directory>: (Character string)`**

Path of the directory from which directories are to be listed. This must be an absolute path: 

- Directory names must be separated by '/' or '\\'.

- Directory names must start with '/' or '\\'.


If the path is invalid, an error will be generated. 

**`<Options>: (Optional Integer constant)`**

Type of iteration:



|   |   |
| --- | --- |
| *frNotRecursive* | The iteration is non-recursive. Subdirectories are ignored. |
| *frRecursive*<br>(Default value) | The iteration is recursive. Subdirectories are automatically taken into account. |

## Remarks


### &lt;Start directory&gt; parameter
<a name="parameter_ELTPARAGRAPHE000081"></a>

Examples of valid paths: 

```txt
"/holidays directory/2021/"
"\photos"
```


Examples of invalid paths:

```txt
"directoryA/DirectoryB"
"This/Path/Is/invalid"
"c:\Users\"
```
