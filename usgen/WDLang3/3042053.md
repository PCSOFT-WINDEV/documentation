


## grPiePullOut (Function)

***In french: grSecteurPartExcentrée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Pulls out a section (or all sections) in a chart. This function can be used on Pie charts, on Donut charts and on Semi-circular charts.

Example of pulled-out section in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grSecteurPartExcentr%E9e%20-%20HC%20N%B0002.gif)


**Note** Each part of the graph can be eccentric independently of the others.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Pull out the second section by 10 pixels in "MyChart"
// (Chart created through programming)
grPiePullOut("MyChart", 2, 10)
```
<a name="Exemple2"></a>

```wl
// Pull out the third section by 20 pixels in "CHART_MyChart"
grPiePullOut(CHART_MyChart, 3, 20)
```

## Syntax

### Eccentricity on one side

`grPiePullOut(<Chart name> , <Section subscript> , <Offset>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Section subscript>: (Integer)`**

Index of section to pull out.

**`<Offset>: (Integer)`**

Offset of specified section (in pixels).  


<a name="SYNTAXE2"></a>

### Eccentricity on all sides

`grPiePullOut(<Chart name> , <Offset>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Offset>: (Integer)`**

Offset of different sections (in pixels).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Pulling out a chart section has no effect on the charts other than the Pie charts, the Donut charts and the Semi-circular charts.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Semi-circular charts are not available.

- Any changes made with **grPiePullOut** will take effect the next time [grDraw](../WDLang3/3042026.md) is called.
