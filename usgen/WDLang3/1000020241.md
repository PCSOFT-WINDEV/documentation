


## Phone (Variable type)

***In french: Téléphone***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Phone** type is used to handle a phone number as well as its type (home, work, ...).

The characteristics of this variable can be defined and modified using various WLanguage properties. 

This type of variable is used by the [Contact](../WDLang3/1000020254.md) variables.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Dials the first professional phone number of a contact
tel is Phone
FOR EACH tel OF contact.Phone
	IF tel.Type = phoneCellWork OR tel.Type = phoneWork THEN
		tapiDialerCall(tel.Number)
		RETURN
	END
END
```

## Properties


### Properties specific to Phone variables
<a name="properties_specific_phone_variables_ELTPARAGRAPHE000040"></a>

The following properties can be used to handle a phone number:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Label | Character string | Label for the custom types of phone numbers (optional).<br>If the **Type** property does not correspond to the *phoneCustom* constant, the value of this property will be ignored. |
| Number | Character string | Phone number. No formatting is performed. |
| Type | Integer constant | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Type of number: <br><br>- *telOther* other types<br><br>- *telOffice* office landline phone<br><br>- *telDomicile* Home telephone number<br><br>- *telFaxOffice* office fax<br><br>- *telFaxDomicile* Home fax number<br><br>- *telMobileBureau*: office cell phone<br><br>- *telMobileHome*: home cell phone<br><br>- *telCustom* custom type corresponding to the value of the property **Label**.<br><br>- *car phone*: car phone<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Type of number: <br><br>- *telDomicile* Home telephone number<br><br>- *telFaxOffice* office fax<br><br>- *telFaxDomicile* Home fax number<br><br>- *telMobileHome*: home cell phone<br><br>- *telCustom* custom type corresponding to the value of the property **Label**.<br><br><br> |
