


## &lt;QuickAction variable&gt;.Pin (Function)

***In french: &lt;Variable ActionRapide&gt;.Epingle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Generates a request to pin a quick action.

When an action is pinned, an icon is created on the home screen and allows users to perform that action with a single tap. This can be useful for frequently used actions or functionalities that require direct access.

Note: This feature is only available from Android 8.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
action is QuickAction
//##########
arrAction is array of QuickAction = QuickActionList()
FOR EACH action OF arrAction
	IF action.Identifier = "ACTION_ID_SEND_MESSAGE" THEN
		action.Pin()
	END
END
```

## Syntax
<a name="SYNTAXE1"></a>
<a name="SYNTAXE2"></a>

### Pinning a quick action using a QuickAction variable

`<Result> = <Action>.Pin()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the action was added,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.


Warning: The function will return <u><u><u><u>True</u></u></u></u> even if the user has refused the operation.

**`<Action>: (QuickAction variable)`**

Name of the [QuickAction](../WDLang3/1410090054.md) variable that describes the action to be pinned. The quick action must already have been added to the application in order to be pinned.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The function opens a dialog box requesting authorization to add a shortcut to the home screen. 

- The quick action must already have been added to the application in order to be pinned.

- This function should be called when the application is in the foreground. It is not recommended to call it in the application initialization events.
