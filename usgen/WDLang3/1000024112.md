


## &lt;Chart&gt;.MenuOption (Function)

***In french: &lt;Graphe&gt;.OptionMenu***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the text of an option in the context menu of a chart.

**Remark**: 

- The context menu is enabled by default. To modify the status of the context menu, use [&lt;Chart&gt;.Menu](../WDLang3/1000024094.md).

- This function can be used only if the chart menus are in compatibility mode (enabled with the *grMenuForCompatibility* constant of the [&lt;Chart&gt;.Menu](../WDLang3/1000024094.md) function).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the line 50 in the context menu of CHART_MyChart
CHART_MyChart.MenuOption(50, "Print the chart")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.MenuOption(<Option identifier> , <Text>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window editor).

**`<Option identifier>: (Integer)`**

Identifier of the option in the context menu.

**`<Text>: (Character string)`**

New text for the specified menu option. If this parameter corresponds to an empty string (""), the specified menu line is deactivated: this line will no longer be displayed in the menu..

<a name="NOTE0_2"></a>


### Enabled/Disabled line
<a name="enableddisabled_line_ELTPARAGRAPHE000479"></a>

- To disable a menu option, use **&lt;Chart&gt;.MenuOption** and specify an empty string ("") in the &lt;Text&gt; parameter.

- To re-enable a menu option disabled by **&lt;Chart&gt;.MenuOption**, use this function with the same menu identifier and specify a non-empty caption.

- The data defined by **&lt;Chart&gt;.MenuOption** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).



<a name="NOTE0_3"></a>


### Languages
<a name="languages_ELTPARAGRAPHE000502"></a>

- The context menu is available in two languages (English and French). No language can be added.

- The text is modified in the current language. To manage the foreign languages, modify the preset texts.
