


## FTPTime (Function)

***In french: FTPHeure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the different creation, modification or access times associated with a file located on an FTP server (File Transfer Protocol).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Returns the modification time of a file located on an FTP server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003040013&name=ftptime_function">See additional examples</a>

```wl
// Find out the time of modification made to
// "/Documents/File.txt" on the FTP server
ResTime = FTPTime(7, "/Documents/File.txt")
```
<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
FTPConnect(MyFTPConnection)

// Find out the time of modification made to
// "/Documents/File.txt" on the FTP server
ResTime = FTPTime(MyFTPConnection, "/Documents/File.txt")
```

## Syntax
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Syntax not available in PHP
### Getting the different times of a file (connection via an ftpConnection variable)

`<Result> = FTPTime(<FTP connection> [, <File name>] [, <Type of time>])`
---

**`<Result>: (Character string)`**



- Requested time (HHMMSS format). 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only the file modification time is available.

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 


**`<File name>: (Optional character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/").  
**If this parameter is not specified**, the date returned will be that of the last file accessed using one of the following FTP functions: [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md). In this case, no request is sent to the server. This syntax is recommended. 

**`<Type of time>: (Optional constant)`**

Requested time:



|   |   |
| --- | --- |
| *ftpAccess* | Time the file was last accessed. |
| *ftpCreation* | Time the file was created. |
| *ftpModification*<br>(Default value) | Time the file was last modified. |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available. Only the modification time of the specified file is available.

### Getting the different times of a file (connection via the identifier of the connection to the FTP server)

`<Result> = FTPTime(<Connection ID> , <Name of file#-1> [, <Type of time>]])`
---

**`<Result>: (Character string)`**



- Requested time (HHMMSS format). 
	![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the time the file was last modified is returned.

	- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.







**`<Connection ID>: (Integer)`**

Connection identifier, returned by [FTPConnect](../WDLang3/3040016.md).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is a Variant parameter.

**`<Name of file#-1>: (Character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/").

**`<Type of time>: (Optional constant)`**

Indicates the time to use:
Requested time:



|   |   |
| --- | --- |
| *ftpAccess* | Time the file was last accessed. |
| *ftpCreation* | Time the file was created. |
| *ftpModification*<br>(Default value) | Time the file was last modified. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available. Only the modification time of the specified file is available.

**Note**: If the &lt;Connection ID&gt; and &lt;File name&gt; parameters are not specified, the time returned will be that of the last file accessed using one of the following FTP functions: [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md). In this case, no request is sent to the server. This syntax is recommended.

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000415"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified: 

- when connecting to the FTP server with [FTPConnect](../WDLang3/3040016.md) (&lt;Timeout&gt; parameter).

- when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
	



<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000455"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_4"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000216"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	Example: /ad/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [FTPCurrentDir](../WDLang3/3040003.md).


When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.
