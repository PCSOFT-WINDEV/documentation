


## DriveDownloadGglFile (Function)

***In french: DriveRécupèreFichierGgl***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Downloads a Google Docs Editors file (Docs, Sheets, etc.) from Google Drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

gglMyDrive is gglDrive
gglMyDrive = GglDriveConnect(oOAuth2Param) 

arrGglFile is array of GglFile
arrGglFile = DriveListFileGgl(gglMyDrive, "/", frRecursive)

FOR EACH File OF arrGglFile
	SWITCH File.MimeType
		CASE mimeTypeGglDocs: File.ExportMimeType = mimeTypeDOCX
		CASE mimeTypeGglSheets: File.ExportMimeType = mimeTypeXLSX
		OTHER CASE: File.ExportMimeType = mimeTypePDF
	END 
	let ResDownload = DriveDownloadGglFile(gglMyDrive, arrGglFile[1], "c:\MyDocuments")
	IF ErrorOccurred THEN
		// Error handling
		Trace ("An error has occurred")
		RETURN
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`DriveDownloadGglFile(<Google Drive> , <File to download> , <Destination directory>)`
---

**`<Google Drive>: (gglDrive variable)`**

Name of the [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the Google Drive service to be used. The connection to the drive must have been previously established. 

**`<File to download>: (GglFile variable)`**

Name of the [GglFile](../WDLang3/1410089586.md) variable corresponding to the file to be recovered. 

**`<Destination directory>: (Character string)`**

Absolute path of the file to be saved on the local computer. If this parameter does not correspond to a valid file path, or if a file with the same name already exists, the file will not be downloaded.
