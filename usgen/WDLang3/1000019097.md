


## &lt;zipArchive variable&gt;.Open (Function)

***In french: &lt;Variable zipArchive&gt;.Ouvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens an existing archive. 

For the archives in "CAB" or "RAR" format, the archive is created if it does not exist. 

The archive can be:

- in WinZip or PKZip format (.ZIP extension).

- in WINDEV format (.WDZ extension).

- in Cabinet file format (.CAB extension).

- in RAR format (.RAR extension). 

- in 7z format (.7z extension). 

- in TAR format (.TAR extension). 

- in TGZ format (.TGZ extension). 

- in TAR.GZ format (.TAR.GZ extension). 

- in gzip format (extension ;gz).

- an executable (.EXE) corresponding to a .WDZ file changed into a self-extracting archive.

MyArchive is zipArchive

## Syntax

`<Result> = <Archive>.Open(<Archive path> [, <Opening mode>])`
---

**`<Result>: (Integer)`**



- 0 if the archive was opened,

- An error code (value greater than 0) otherwise. For more details on these error codes, see the Remarks.




**`<Archive>: (zipArchive variable)`**

Name of a variable of type [zipArchive](../WDLang3/1000018679.md) corresponding to the archive to use.

The archive is created if it does not exist (except for the "CAB" or "RAR" formats).

**`<Archive path>: (Character string)`**

Path and name of archive (up to 260 characters). The archive extension can be specified. If the archive extension is not specified, the default extension is .WDZ.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the extension is not specified, the extension will be ".ZIP".

**`<Opening mode>: (Optional constant (or combination of constants))`**

Mode for opening the archive: 


|   |   |
| --- | --- |
| *zipCreateIfNotFound* | Creates the archive if it does not exist<br>(not available for .CAB and .RAR files) |
| *zipHeader64* | Allows you to create an archive larger than 4 GB on which [&lt;zipArchive variable&gt;.ChangePath](../WDLang3/1000026329.md) can be used.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available.<br><br>Archive in TAR or TGZ format (TAR.GZ): This constant is not available. |
| *zipRead* | Opening in read-only |
| *zipWrite* | Opening in read/write<br>(not available for .CAB and .RAR files) |


The default opening mode is: *zipCreationIfNonexistent* + *zipWrite*.

## Remarks


### Error codes
<a name="error_codes_ELTPARAGRAPHE000321"></a>

The following error codes are returned:

- 1: Path passed as parameter does not exist.

- 2: Access denied: user does not have sufficient rights.

- 3: The archive is corrupt.

- 6: The files in the sub-archives are not in the right order (this is the case when opening a multi-part archive).


The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Only archives in ZIP, gzip, TAR and TGZ (TAR.GZ) formats are available.

### Special case of the .GZ extension
<a name="special_case_the_extension_ELTPARAGRAPHE000349"></a>

'.tar.gz' files generated by GitHub should not be confused with compressed '.gz' files.
Content compressed in gzip format can be decompressed with [Uncompress](../WDLang1/3024009.md).
