
## SMSReset (Function)

***In french: SMSRAZ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Resets all variables of [SMS structure](../WDLang3/3068003.md).

<a name="sample_code"></a>

## Example


```wl
// Reinitialize the SMS structure
SMSReset()
```
