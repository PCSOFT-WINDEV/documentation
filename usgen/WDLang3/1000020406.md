


## nfcData (Variable type)

***In french: nfcDonnée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **nfcData** type is used to describe and handle the data of a variable of type [nfcTag](../WDLang3/1000020411.md). You can define and change the characteristics of this data using different WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

<a name="sample_code"></a>

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Write a url into an NFC tag
tag is nfcTag
url is nfcData
url.Type = nfcURI
url.Content = "www.pcsoft.com"
Add(tag, url)
NFCWriteTag(tag)
IF ErrorOccurred = True THEN
	Error("Unable to write NFC tag.", ErrorInfo())
END
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Save an image in an NFC tag
tag is nfcTag
url is nfcData
url.Type = nfcMedia
url.Content = fLoadBuffer(CompleteDir(SysDirStorageCard()) + "imagepng")
url.MIMEType = "image/png"
Add(tag, url)
NFCWriteTag(tag)
IF ErrorOccurred = True THEN
	Error("Unable to write NFC tag.", ErrorInfo())
END
```



```wl
// Read the data of an NFC tag
tag is nfcTag
tag = nfcReadTag()
IF NOT ErrorOccurred = True THEN
	FOR EACH data of tag.Data
		SWITCH data.Type
			CASE nfcText
				sLanguage is string = LanguageToName(data.Language)
				sText is string = data.Content
			CASE nfcURI
				IF StringStartsWith(data.Content, "http") THEN
					BrowserRunApp(data.Content)
				END
			CASE nfcMedia
				IF data.MIMEType ~= "image/png" THEN
					fSaveBuffer(CompleteDir(SysDirStorageCard()) +  ...
						"image.png", data.Content)
				END
		END
	END
END
```

## Properties


### Properties specific to nfcData variables
<a name="properties_specific_nfcdata_variables_ELTPARAGRAPHE000044"></a>

The following properties can be used to handle data of an NFC tag:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Content | Binary/Buffer | Data content. Its type depends on the value of the **Type** property.<br><br>If the **Type** property corresponds to: <br><br>- the *nfcText* constant: <br><br>	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the **Content** property can be an Ansi or Unicode string. <br><br>	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the **Content** property is a Unicode string. <br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) When writing the NFC tag: <br><br>- if the **Content** property is an ANSI string, the text will be encoded in UTF-8, <br><br>- if the **Content** property is a Unicode string, the text will be encoded in UTF-16.  <br><br>- the *nfcURI* constant, the **Content** property corresponds to an Ansi string. <br><br>- the *nfcMedia* constant, the **Content** property corresponds to a buffer.<br>	The interpretation of the buffer data depends of MIME type associated with the **nfcData** variable. <br><br>- the *constant nfcVide*: A fatal error will be triggered if an attempt is made to modify the **property Contenu**.<br><br>- the constant *nfcInconnu*: A fatal error will be triggered if an attempt is made to modify the property **Contenu**.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **This property is read-only**. |
| Language | Integer | Language of the text stored in the **Content** property.<br><br>This property must be used only when the type of the **nfcData** variable is *nfcText*. A fatal error will occur if there is an attempt to read or modify the **Language** property of a variable of type **nfcData** or a different type. <br><br>By default, the **Language** property is initialized with the current language of the application.<br><br>To find out: <br><br>- the language name, use [LanguageToName](../WDLang1/3054020.md).<br><br>- the nation corresponding to the language, use [LanguageToNation](../WDLang1/3054019.md).<br><br><br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **This property is read-only**. |
| MIMEType | Character string | MIME type of the resource stored in the **Content** property. <br><br>The specified MIME type can correspond to: <br><br>- a standard MIME type. More than 150 types are defined in the MIME communication standard (available on Internet). The most common values are: <br><br>	- "application/pdf": PDF file (\*.pdf) <br><br>	- "text/html": HTML page (\*.htm, \*.html) <br><br>	- "text/plain": text file (\*.txt)<br><br>	- "image/gif": GIF image (\*.gif) <br><br>	- "image/jpeg": JPEG image (\*.jpg, \*.jpeg)<br><br>	- "video/mpeg": MPEG video (\*.mpg, \*.mpeg)<br><br>	- "application/msword": Word file. <br><br>	- "application/vnd.ms-excel": Excel file.<br><br><br><br><br>- a custom type. <br><br><br>The **MIMEType** property must be used only when the **nfcData** variable is of type *nfcMedia*. A fatal error will occur if there is an attempt to read or modify the **MIMEType** property of a variable of type **nfcData** or a different type.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **This property is read-only**. |
| Type | Integer constant | Type of data, corresponding to one of the following constants: <br><br>- *nfcText* Text data.<br><br>- *nfcURI* URI (Uniform Resource Identifier) data type. Can correspond to: <br><br>	- the url of a Web page (http://www.windev.com),<br><br>	- an FTP address (ftp://ftp.windev.com/), <br><br>	- a phone number (tel:0123456789), <br><br>	- an email address (mailto:address@mail.com), etc.<br>			You have the ability to use [ShellExecute](../WDLang1/3035007.md) with this URI (for example, to open the browser when the URI corresponds to the address of a Web site).<br><br><br><br><br>- *nfcMedia* Media type data. Can correspond to any resource identified by a MIME type (image, video, document, etc.).<br><br>- *nfcVide* Empty type. This type is used when creating a variable of type **nfcData** as long as no data type has been specified.<br><br>- *nfcUnknown* Type unknown.<br><br><br>**Important note** Changing the type of a variable of type **nfcData** variable results in a reset of its contents. Therefore, don't forget to specify the type before the content.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **This property is read-only**. |
