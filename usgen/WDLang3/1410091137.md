


## &lt;ftpConnection variable&gt;.Name (Function)

***In french: &lt;Variable ftpConnexion&gt;.Nom***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the last file accessed by an FTP function.

**Note**: **&lt;ftpConnection variable&gt;.Name** is particularly useful when browsing files on an FTP server with [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md).


<a name="sample_code"></a>

## Example

<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Name of last file accessed by an FTP function
ResName = MyFTPConnection.Name()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax
<a name="SYNTAXE2"></a>

`<Result> = Name(<FTP connection>)`
---

**`<Result>: (Character string)`**



- Name of the last file accessed by an FTP function. The file must have been modified by one of the following FTP functions: [&lt;ftpConnection variable&gt;Attribute](../WDLang3/1410091117.md), [&lt;ftpConnection variable&gt;.Date](../WDLang3/1410091120.md), [&lt;ftpConnection variable&gt;.Time](../WDLang3/1410091125.md), [&lt;ftpConnection variable&gt;.Size](../WDLang3/1410091134.md), [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md).  

- Empty string ("") if an error occurred.  To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Request to FTP server
<a name="request_ftp_server_ELTPARAGRAPHE000287"></a>

**&lt;ftpConnection variable&gt;.Name** sends no request to the FTP server.
<a name="NOTE0_2"></a>


### Timeout
<a name="timeout_ELTPARAGRAPHE000301"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_4"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000334"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
