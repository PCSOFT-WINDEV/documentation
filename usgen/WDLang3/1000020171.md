
## SpeechSynthesisInitialize (Function)

***In french: SynthèseVocaleInitialise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the parameters of speech synthesis for the current application. You can initialize: 

- Only the language used (syntax 1). 

- All the voice characteristics via a [SpeechSynthesisVoice](../WDLang3/1000025986.md) variable (syntax 2). 




**Note**: The use of **SpeechSynthesisInitialize** is optional. The default parameters will be used if [SpeechSynthesisReadText](../WDLang3/1000019805.md) or [SpeechSynthesisReadFile](../WDLang3/1000020172.md) is called while the parameters of speech synthesis have not been specified in **SpeechSynthesisInitialize**.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF NOT SpeechSynthesisInitialize(NationToLanguage(Nation())) THEN
	Error("Failure initializing the speech synthesis.", ErrorInfo())
END
```

## Syntax
<a name="SYNTAXE1"></a>

### Initializing the language only

`<Result> = SpeechSynthesisInitialize(<Language> [, <Speed>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the initialization was performed,

- <u><u><u><u>False</u></u></u></u> in case of failure. In this case, [ErrorOccurred](../WDLang1/3087001.md) is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Language>: (Integer or Integer constant)`**



- Language that will be used to read the text. If the specified language is not supported by the speech synthesis engine, the function will return <u><u><u><u>False</u></u></u></u> and the first available language from the following sequence will be used: 

	- Language of the application (default language or language defined by [Nation](../WDLang1/3054014.md)). 

	- Language of the device

	- English

	- Default language of engine for speech synthesis.




- 0 to use the current application language.

<a name="SYNTAXE2"></a>

### Initializing all the voice characteristics

`<Result> = SpeechSynthesisInitialize(<Voice> [, <Speed>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the initialization was performed,

- <u><u><u><u>False</u></u></u></u> in case of failure. In this case, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Voice>: (SpeechSynthesisVoice variable)`**

Name of the [SpeechSynthesisVoice](../WDLang3/1000025986.md) variable to be used for reading the text. 

**`<Speed>: (Optional integer)`**

Speed for reading the text, included between 0 (very slow) and 10 (very fast). If this parameter is not specified, its value will be set to 5 (average speed).

## Remarks


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000343"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) If no engine for speech synthesis is installed on the device, its download will be automatically proposed. 
	If the language to be used for speech synthesis is not the system language, this language must be specified in Android's "Text-to-speech Engine" settings. In "Language", replace "Use system language" with the desired language.

- To synthesize a character string or a text file, use [SpeechSynthesisReadText](../WDLang3/1000019805.md) and [SpeechSynthesisReadFile](../WDLang3/1000020172.md) respectively.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Speech synthesis functions are only available on devices with Android 1.6 or higher (API level 4).
	A fatal error occurs if the function is used with an earlier system version. 
	To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Speech synthesis functions are only available on devices with iOS 7 and higher. The speech synthesis does not work on the iOS 8 emulators.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000518"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**SpeechSynthesisInitialize** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
