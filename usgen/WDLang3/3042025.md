


## grExist (Function)

***In french: grExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence of a chart in memory. 

The chart used can be:

- a chart created through programming ([grCreate](../WDLang3/3042005.md)).

- a Chart control in the window editor, page editor or report editor.




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Checks the existence of "MyChart"
ResExist = grExist("MyChart")
```
<a name="Exemple2"></a>

```wl
// Checks the existence of CHART_MyChart
ResExist = grExist(CHART_MyChart)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = grExist(<Chart name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the chart exists, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.  


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.
