


## xmlSignatureInformationKeyX509 (Variable type)

***In french: xmlSignatureInformationCléX509***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xmlSignatureInformationKeyX509** type is used to define the information that must be included in the **KeyInfo** section of the XML signature. This enables you to add the information about a X509 certificate. You can define and change the characteristics of this type of variable using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySignature is xmlSignature
Info is xmlSignatureInformationKeyX509
Info.WithCertificate = True
Add(MySignature.KeyInformation, Info)
```

## Properties


### Properties specific to xmlSignatureInformationKeyX509 variables
<a name="properties_specific_xmlsignatureinformationkeyx509_variables_ELTPARAGRAPHE000049"></a>

The following properties can be used to define the characteristics of **xmlSignatureInformationKeyX509** variables:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| WithCertificate | Boolean | <br><br>- <u><u><u>True</u></u></u>: The certificate is added to the signature description, <br><br>- <u><u><u>False</u></u></u>: The certificate is not added to the signature description.<br><br><br> |
| WithIssuer | Boolean | <br><br>- <u><u><u>True</u></u></u>: The name of the certificate issuer is added to the signature description,<br><br>- <u><u><u>False</u></u></u>: The name of the certificate issuer is not added to the signature description.<br><br><br> |
| WithSubjectName | Boolean | <br><br>- <u><u><u>True</u></u></u>: The certificate subject is added to the signature description,<br><br>- <u><u><u>False</u></u></u>: The certificate subject is not added to the signature description.<br><br><br> |
