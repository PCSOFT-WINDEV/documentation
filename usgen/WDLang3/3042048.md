


## grTitleFont (Function)

***In french: grPoliceTitre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the font used for the chart title.

Example of title in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titre.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the font used for the title of CHART_MyChart
// The identifier of font used is 7.
grTitleFont(CHART_MyChart, 7)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Defining the font used for the chart title

`grTitleFont(<Chart name> , <Font used>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font used>: (Font)`**

Font to use. This parameter corresponds to a variable of type [Font](../Motscles/1514045.md). The font characteristics have been defined with [FontCreate](../WDLang1/3060002.md) or via the [font properties](../Proprietes/2515045.md).  


<a name="SYNTAXE2"></a>

### Defining the font used for the chart title (syntax kept for backward compatibility)

`grTitleFont(<Chart name> , <Font identifier>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font identifier>: (Integer)`**

Font identifier, defined by [grCreateFont](../WDLang3/3042001.md). A WLanguage error occurs if this font does not exist.

## Remarks


### Chart title
<a name="chart_title_ELTPARAGRAPHE000149"></a>The chart title can be displayed above or below the chart.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titre.gif)
The content of the chart title is defined with [grTitle](../WDLang3/3042056.md). This function can also be used to set the position of the title.

The font used for the chart title can be modified by **grTitleFont**.

The data defined by **grTitleFont** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).
<a name="NOTE0_2"></a>


### Initializing fonts
<a name="initializing_fonts_ELTPARAGRAPHE000174"></a>

The default font used for the chart title has the following characteristics:

- Font name: Arial

- Size: 14

- Style: Normal

- Color: Black




When [grCreate](../WDLang3/3042005.md) is used, the default font is used for the chart title.
