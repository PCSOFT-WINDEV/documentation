
## SpeechSynthesisReadText (Function)

***In french: SynthèseVocaleLitTexte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads the specified text using the device's text-to-speech engine.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SpeechSynthesisReadText("WINDEV is great!")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SpeechSynthesisReadText(<Text> [, <Locking>])`
---

**`<Result>: (Integer)`**



- <u><u><u><u>True</u></u></u></u> if the text has been read (blocking mode) or has been added to the print queue (non-blocking mode), 

- <u><u><u><u>False</u></u></u></u> in case of failure. If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Text>: (Character string)`**

Text to read.

**`<Locking>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u>: The function is executed in blocking mode. The code following the call to the function will be run once the entire text is read or when the function fails. An hourglass will be displayed during the read operation. Use [NextTitle](../WDLang1/3038043.md) to customize the message displayed by the hourglass.
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This runtime mode is not available.

- <u><u><u><u>False</u></u></u></u> (default): The function is executed in non-blocking mode. The code following the call to the function will be run as soon as the reading of the text starts or when the function fails.

## Remarks


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000084"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Speech synthesis functions are only available on devices with Android 1.6 or higher (API level 4).
	A fatal error occurs if the function is used with an earlier system version. 
	To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Speech synthesis functions are only available on devices with iOS 7 and higher. The speech synthesis does not work on the iOS 8 emulators.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) If no engine for speech synthesis is installed on the device, its download will be automatically proposed. 
	If the language to be used for speech synthesis is not the system language, this language must be specified in Android's "Text-to-speech Engine" settings. In "Language", replace "Use system language" with the desired language.

- If a new read operation is triggered while another read operation is in progress, the new read operation will start once the first one is over. 
	To know whether a read operation is in progress on the speech synthesis engine, use [SpeechSynthesisInProgress](../WDLang3/1000020173.md). 
	To stop the current read operations, use [SpeechSynthesisStop](../WDLang3/1000020174.md).

- To define the parameters that will be used by the engine for speech synthesis (language, reading speed, etc.), use [SpeechSynthesisInitialize](../WDLang3/1000020171.md).
	If the parameters of speech synthesis have not been defined by [SpeechSynthesisInitialize](../WDLang3/1000020171.md), the default parameters will be used and the language for text reading will be the first language available for the engine of speech synthesis according to the following sequence: 

	- Application language (default language or language defined by [Nation](../WDLang1/3054014.md)), 

	- Device language,

	- English,

	- Default language of the speech synthesis engine.




- To read the content of a text file, use [SpeechSynthesisReadFile](../WDLang3/1000020172.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) To adjust the volume, use [VolumeModify](../WDLang3/1000020169.md) with the *volumeMusic* constant.

- Note: **SpeechSynthesisReadText** does not read the text immediately when the mobile device is in standby mode. In this case, you can: 

	- prevent from going in standby mode with [SysStandby](../WDLang1/3073032.md). 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) use a persistent thread ([ThreadPersistent](../WDLang1/1000020584.md)) in order for the application to continue to run even during the standby mode.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000299"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**SpeechSynthesisReadText** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
