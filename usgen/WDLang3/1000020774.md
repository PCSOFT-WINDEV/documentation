


## emailHeader (Variable type)

***In french: emailEntête***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **emailHeader** type is used to retrieve or define the additional email headers. You can define and change the characteristics of a header using different WLanguage properties. 

This type of variable is used by [Email](../WDLang3/1000018713.md) variables. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMyEmail is Email
cAHeader is emailHeader
cAHeader.Name = "List-Unsubscribe"
cAHeader.Value = "<mailto:unsubscribe@domain.com>"
Add(cMyEmail.Header, cAHeader)
EmailSendMessage(MySession, cMyEmail, emailOptionEncodeHeader)
```

<a name="PROPS"></a>

## Properties


### Properties specific to emailHeader variables
<a name="properties_specific_emailheader_variables_ELTPARAGRAPHE000041"></a>

The following properties can be used to handle an email header:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Name | Character string | Name of the header. |
| Value | Character string | Value of the header. <br><br>**Note** If the [EmailSendMessage](../WDLang3/3032005.md) function uses the constant *emailOptionEncodeHead*the header value will be encoded in base 64. |
