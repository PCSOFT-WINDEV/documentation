


## grInterval (Function)

***In french: grGraduation***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>28 (75)</B>, ***grGraduate*</**>** is kept for backward compatibility. This function has been replaced with ***grInterval*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the interval between values on the vertical and horizontal axis of a chart. 

**Reminder** By default, the graduation pitch is 0. This interval is adjusted to fit the available space in the selected destination.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart created programmatically
// Vertical axis of the chart with an interval set to 5
grInterval("MyChart", 5, grYCoordinate)
```
<a name="Exemple2"></a>

```wl
// Chart control
// Horizontal axis of chart with an interval set to 10
grInterval(CHART_MyChart, 10, grXCoordinate)
```

## Syntax

`grInterval(<Chart name> , <Interval> [, <Type of axis>])`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Interval>: (Real)`**

Interval between two marks. If this parameter is set to 0, the interval will be adjusted to fit the available space in the selected destination.

**`<Type of axis>: (Optional constant)`**

Type of the axis for which the interval is defined:


|   |   |
| --- | --- |
| *grSecondaryYCoordinate* | Marks on the secondary X-axis. |
| *grXCoordinate* <br>(Default value) | Marks on the X-axis. |
| *grYCoordinate* | Marks on the Y-axis. |
| *grZCoordinate* | Marks on the Z-axis (Surface chart only).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |

## Remarks


### Marks on axes
<a name="marks_axes_ELTPARAGRAPHE000150"></a>

- Limits: 100 graduations above and 100 graduations below the "X" axis.

- The last mark displayed is the first multiple of &lt;Interval&gt; greater than the highest data value. The entire data is displayed regardless of the destination dimension.

- To modify the start and end marks on the horizontal, vertical or secondary axis of a chart, use [grOrigin](../WDLang3/3042039.md).

- The data defined by **grInterval** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).



<a name="NOTE0_2"></a>


### Types of charts
<a name="types_charts_ELTPARAGRAPHE000170"></a>

The marks on axes have no effect on the Pie charts.
