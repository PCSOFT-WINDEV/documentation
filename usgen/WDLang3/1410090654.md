
## NearbyShareSendFile (Function)

***In french: PartageProximitéEnvoieFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends a file to one or more nearby devices to which the current device is connected.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareSendFile(garrSelectedDevices, sResourcePath, CallbackSend)
```



```wl
PROCEDURE CallbackSend(bResult is boolean, nTransferID is int)
IF bResult THEN
	ToastDisplay("File sent")
ELSE
	ToastDisplay(ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Sending a file to a single device

`NearbyShareSendFile(<Nearby device identifier> , <File to upload> [, <WLanguage procedure>])`
---

**`<Nearby device identifier>: (Character string)`**

Identifier of the device to which the file is to be sent.

**`<File to upload>: (Character string)`**

Full path of the file to be sent.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called to notify whether or not the data was sent successfully. 
**Note**: If successful, this does not mean that the data has been received by the nearby device. You need to use the procedure of the [NearbyShareAcceptConnection](../WDLang3/1410090646.md) function to monitor the status of the transfer.
For more details on this procedure, see [Parameters of the procedure used by NearbyShareSendFile](../WDLang3/1410090670.md). 


<a name="SYNTAXE2"></a>

### Sending a file to multiple devices

`NearbyShareSendFile(<Device list> , <File to upload> [, <WLanguage procedure>])`
---

**`<Device list>: (WLanguage array)`**

Name of the WLanguage array containing the list of identifiers of the devices to which the file is to be sent.

**`<File to upload>: (Character string)`**

Full path of the file to be sent.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called to notify whether or not the data was sent successfully. 
**Note**: If successful, this does not mean that the data has been received by the nearby device. You need to use the procedure of the [NearbyShareAcceptConnection](../WDLang3/1410090646.md) function to monitor the status of the transfer.
For more details on this procedure, see [Parameters of the procedure used by NearbyShareSendFile](../WDLang3/1410090670.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Once received, the file will have the same name and extension as the original file.

- Depending on its size, the file can be split and sent in blocks. 

- [NearbyShareAcceptConnection](../WDLang3/1410090646.md) function: 

	- The reception procedure of [NearbyShareAcceptConnection](../WDLang3/1410090646.md) will be executed when the entire file is transferred.

	- The progress procedure of [NearbyShareAcceptConnection](../WDLang3/1410090646.md) can be used to track the progress of the transfer.




- Files sent with **NearbyShareSendFile** are always received in the order in which they were sent. However, the order of data sent with [NearbyShareSend](../WDLang3/1410090653.md) is unknown.
