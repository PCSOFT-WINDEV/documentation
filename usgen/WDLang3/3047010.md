
## J2EEError (Function)

***In french: J2EEErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the error for the last J2EE procedure that failed.

**Note** This procedure was carried out by function [J2EERun](../WDLang3/3047007.md) or [J2EERunXML](../WDLang3/3047008.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Returns the error message of the last J2EE procedure run
ResErrorMessage = J2EEError(J2EEErrMessage)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = J2EEError(<Type of error>)`
---

**`<Result>: (Character string)`**



- Error of the last J2EE procedure that failed.

- An empty string ("") if:

	- no error was returned by the server, 

	- no connection was established to the server.







**`<Type of error>: (Constant)`**

Type of error to return:


|   |   |
| --- | --- |
| *J2EEErrActor* | URL of the server that triggered the error (useful if the procedure is run by several servers). |
| *J2EEErrCode* | Error of the last J2EE procedure run:<br><br>- "VersionMismatch": The J2EE version used on the current workstation is different from the one used on the server.<br><br>- "MustUnderstand": The server does not understand the parameter specified in the header (only if the parameter &lt;Procedure Execution&gt; in the header is set to <u><u><u><u>True</u></u></u></u>).<br><br>- "Client": Incorrect settings for procedure execution.<br><br>- "Server": The server has not executed the Procedure.<br><br><br>**Remark**: This string can be completed with additional information.. The following format is used: "&lt;Error&gt;.&lt;Information&gt;". For example: "Client.Authentication" if the error is due to client authentication. |
| *J2EEErrDetails* | Error details. This message is in XML format. |
| *J2EEErrMessage* | Error message returned by the server on the last J2EE procedure run. |
