


## URISelect (Function)

***In french: URISélecteur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a system window to select or create a resource from: 

- the device file system,

- the Cloud (Google Drive, Microsoft OneDrive, etc.)

- one of the content managers installed on the device.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
```wl
// Open the system window to select an image or a pdf
UriResource is URI = URISelect(uriImage + TAB + "application/pdf")
IF NOT ErrorOccurred THEN
	// Displays the name of the selected resource
	Info(URIGetInfo(UriResource, uriInfoName))
END
```


<a name="Exemple2"></a>
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Open the system window to select an image or a pdf
URISelect(MyProcURISelect, uriImage + TAB + "application/pdf")

INTERNAL PROCEDURE MyProcURISelect(Success is boolean, Result1 is URI)
	IF Success = True THEN
		// Displays the name of the selected resource
		ToastDisplay(URIGetInfo(Result1, uriInfoName))
	END
END
```
<a name="Exemple3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
URISelect(MyProcURISelect, uriAudio + TAB + uriImage + TAB + uriVideo)

	IF Success = True THEN
		// Displays the name of the selected resource
		ToastDisplay(Result1..Value)
	END
END
```

### Selecting or creating a resource (synchronous code)

`<Result> = URISelect([<MIME types> [, <Mode> [, <Document name>]]])`
---

**`<Result>: (URI variable)`**



- [URI](../WDLang3/1000024027.md) that corresponds to the selected resource. 

- If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<MIME types>: (Optional character string or constant)`**



- List of MIME types of selectable files, separated by TAB. 

- One of the following constants: 
	


|   |   |
| --- | --- |
| *uriAudio* | Allows all types of audio files. |
| *uriImage* | Allows all types of image files. |
| *uriVideo* | Allows all types of video files. |


	Note: Constants can be concatenated by separating them with TAB. 


If a specified MIME type is not known by the system, it will be ignored.
If this parameter is not specified, all files will be selectable.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) On Android, files that do not match the specified MIME types will be visible but users will not be able to select them. 

**`<Mode>: (Optional Integer constant)`**

Selection mode: 



|   |   |
| --- | --- |
| *uriCreate* | Opens the picker in "Creation" mode to create a new document. The default name of this document can be specified in &lt;Document name&gt;. |
| *uriOpen*<br>(Default value) | Opens the picker in "Open" mode to open an existing document.  |



**`<Document name>: (Optional character string)`**

Default name of the document to be created when the picker is open in creation mode. This parameter is taken into account only if &lt;Mode&gt; corresponds to the *uriCreate* constant.

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000204"></a>

- To manage the URI returned by **URISelect**, use the URIxxx functions.

- To retrieve additional information (name, size, MIME type) on the selected resource, use [URIGetInfo](../WDLang3/1000024037.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **URISelect** is only available on devices running Android 4.4 or later (API level 19). 
	A fatal error occurs if the function is used with an earlier system version. 
	To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) This function is mainly used to write multi-platform code.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000367"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**URISelect** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
