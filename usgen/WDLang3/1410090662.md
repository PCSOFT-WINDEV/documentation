
## WLanguage procedure called by NearbyShareWaitForConnection (Result)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareWaitForConnection](../WDLang3/1410090655.md) once the device has advertised itself and starts waiting for a connection request. This procedure checks whether the device is visible to other devices.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Each time the connection wait check box is changed
CBOX_Wait_connection.State = Grayed
IF CBOX_Wait_connection THEN
	NearbyShareWaitForConnection(gsDeviceName, CallbackResult, CallbackRequestConnection, 
		CallbackConnection, gnTopology)
ELSE
	NearbyShareStopWaiting()
	CBOX_Wait_connection.State = Active
END
	INTERNAL PROCEDURE CallbackResult(bResult is boolean)
		IF bResult THEN
			CBOX_Wait_connection.State = Active
		ELSE
			Info("Search or connection request failed: " + CR + ErrorInfo())
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareWaitForConnection_Callback_Result(<Result>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the device is visible to nearby devices and is waiting for a connection request,

- <u><u><u><u>False</u></u></u></u> if an error occurs. For more details on the error, use [ErrorInfo](../WDLang1/3013008.md).
