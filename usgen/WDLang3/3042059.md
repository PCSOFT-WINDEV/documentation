


## grAxisTitleFont (Function)

***In french: grPoliceTitreAxe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the font used for the titles of the chart axes.

Example of titles for the axes: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titreaxe.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the font used for
// the title of axes in "CHART_MyChart".
MyFont is Font
MyFont.Name = "Arial"
MyFont.Size = 12
MyFont.Bold = True
grAxisTitleFont(CHART_MyChart, MyFont)
```

<a name="SYNTAXE1"></a>

## Syntax

### Defining the font used for the title of the chart axes

`grAxisTitleFont(<Chart name> , <Font used>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font used>: (Font)`**

Font to use. This parameter corresponds to a variable of type [Font](../Motscles/1514045.md). The font characteristics have been defined with [FontCreate](../WDLang1/3060002.md) or via the [font properties](../Proprietes/2515045.md).  


<a name="SYNTAXE2"></a>

### Defining the font used for the title of the chart axes (syntax kept for backward compatibility)

`grAxisTitleFont(<Chart name> , <Font identifier>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font identifier>: (Integer)`**

Font identifier, defined by [grCreateFont](../WDLang3/3042001.md). A WLanguage error occurs if this font does not exist.

## Remarks


### Chart title
<a name="chart_title_ELTPARAGRAPHE000149"></a>The title of chart axes can be displayed for the different axes.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titre.gif)
The content of the title for the chart axes is defined by [grAxisTitle](../WDLang3/3042057.md). This function can also be used to set the position of the title.

The font used for the chart title can be modified by **grAxisTitleFont**.
<a name="NOTE0_2"></a>


### Initializing fonts
<a name="initializing_fonts_ELTPARAGRAPHE000167"></a>

The default font used for the title of the axes has the following characteristics:

- Font name: Arial,

- Size: 14,

- Style: Normal,

- Color: Black.




When [grCreate](../WDLang3/3042005.md) is used, the default font is used for the axis titles.
