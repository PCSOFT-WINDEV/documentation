


## grRealTimeInterval (Function)

***In french: grTempsRéelIntervalle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the time interval visible in a time chart with real-time display. 

Example: In this example, the time interval is 10 seconds. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Graphe%20temps%20r%E9el%20-%20HC%20N%B0001%201.gif)
Note: This function only applies to graphs with a time scale, for which data is added using function [grAddTimeData](../WDLang3/1000023532.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
FOR I = 1 TO 10
	d is Duration
	d.Minute = I
	grAddTimeData(CHART_MyChart, 1, d, 2 + Sin(i*36))
END

d is Duration = 2min
grRealTimeInterval(CHART_MyChart, d)
grDraw(CHART_NoName1)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grRealTimeInterval(<Chart control> , <Interval>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to be used. 

**`<Interval>: (Duration)`**

Time interval visible in the chart (expressed in milliseconds). By default, this value is 60 seconds. If this parameter corresponds to 0, the default value is used.
