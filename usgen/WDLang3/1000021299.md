


## MapLicenseGgl (Function)

***In french: CarteLicenceGgl***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the "Google Maps API" license key that will be used in the Map controls (of WINDEV or WEBDEV). This key may be required to use the "Google Maps API for work" features. For more details, see the "Google Maps API" license.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) You also have the ability to enter the "Google Maps API" license in the description window of project ("Project" tab).![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Important**: **MapLicenseGgl** must be called **before** opening the window that contains the Map control. If the Map control is found in the first project window, the call to **MapLicenseGgl** must be performed in the project initialization code.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In test mode, the Map control uses the Map control of WINDEV. This function is used to specify (if necessary) the "Google Maps API" license key in order for the Map control to be displayed properly during a GO on the development computer.

<a name="sample_code"></a>

## Example


```wl
// Initialize the Google key
MapLicenseGgl("ABCDEF12345789abcdef")
```

## Remarks


- The use of the Map control is subject to specific terms and conditions. Check the Google license regarding the use of mapping services.

| **Note: Google Maps terms of service changed on June 22, 2016**. From now on, a license key **must necessarily** be specified to use this service. You must: <br><br>	1. The operations to perform are as follows (valid at the date this page was written): <br><br>		- Use a Google account to connect to the developer console. <br><br>		- Create a Google project if necessary. <br><br>		- Access the "API manager" of the project.<br><br>		- In the "Google Maps API" item, click the "Google Maps JavaScript API" link.<br><br>		- Click "Enable" to enable the Google Maps JavaScript API. <br><br>		- In the "Identifiers" item, expand the "Create identifiers" button. <br><br>		- Select "API key". <br><br>		- Select "API key". <br><br>			- For a WEBDEV website, select "Browser key". It is recommended to specify the domain that will use the key in order to monitor queries and avoid any fraud.<br><br>			- For a WINDEV application, select "Server key". It is recommended to specify the address that will use the key in order to monitor queries and avoid any fraud.<br><br><br><br><br>	- Validate the key creation and copy the key created by Google. <br><br>	2. Specify the key used in the application or site with **MapLicenseGgl**.<br><br><br> |



- This function allows you to specify the license to use in order for the provider of Google Maps to give the application: 

	- **from June 22 2016**, access to the "Google Maps JavaScript API" features. 

	- access to the extended features of "Maps API for work" (greater number of queries, monitoring, quota, ...).




- The license is applied to all the maps of the application and it will be used for all the new Map controls created after this call. We advise you to call this function in the project initialization code.
