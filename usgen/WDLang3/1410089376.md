
## oDriveConnect (Function)

***In french: oDriveConnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a connection to OneDrive.

## Example



## Syntax
<a name="SYNTAXE1"></a>

### Authenticating to OneDrive using the OAuth 2.0 protocol

`<Result> = oDriveConnect(<Authentication parameters>)`
---

**`<Result>: (Drive variable)`**

[Drive](../WDLang3/1410089369.md) variable that contains all the OneDrive connection information. 
If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and an invalid variable is returned. 

**`<Authentication parameters>: (OAuth2Parameters variable)`**

Name of the [OAuth2Parameters](../WDLang3/1000022212.md) variable that contains the authentication parameters:

- The **ClientID** and **ClientSecret** properties must be specified. 

- The **RedirectionURL** property can be specified. By default, this property is set to "http://localhost:3400/".





<a name="SYNTAXE2"></a>

### Authenticating to OneDrive using a token (refresh token)

`<Result> = oDriveConnect(<Authentication parameters>)`
---

**`<Result>: (Drive variable)`**

[Drive](../WDLang3/1410089369.md) variable that contains all the OneDrive connection information. 
If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and an invalid variable is returned. 

**`<Authentication parameters>: (AuthToken variable)`**

Name of the [AuthToken](../WDLang3/1000022220.md) variable that contains the authentication parameters. 







<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
It is recommended to to pass a token with a refresh token so that users do not have to log in each time the application is launched. If necessary, the token will be automatically updated.

Information needed to connect to a drive using an existing token: 


| Properties of the OAuth2Parameters variable | Value used by the oDriveConnect function |
| --- | --- |
| AuthURL | "https://login.microsoftonline.com/common/oauth2/v2.0/authorize" |
| TokenURL | "https://login.microsoftonline.com/common/oauth2/v2.0/token" |
| Scope | "offline_access Files.ReadWrite.All" |
| RedirectionURL (Editable) | "http://localhost:3400/" |
