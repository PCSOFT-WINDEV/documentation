


## &lt;Map&gt;.AddItinerary (Function)

***In french: &lt;Carte&gt;.AjouteItinéraire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an itinerary onto a Map control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays a car itinerary between two specified addresses
MAP_MapControl.AddItinerary(["Place de la Comédie, Montpellier", ...
		"Avenue des Champs Elysées, Paris"], itineraryCar)
```
<a name="Exemple2"></a>

```wl
// Displays an itinerary corresponding to the list of specified geographical positions
posDeparture is geoPosition
posDeparture.Latitude = XXX
posDeparture.Longitude = XXX

posArrival is geoPosition
posArrival.Latitude = XXX
posArrival.Longitude = XXX

MAP_MapControl.AddItinerary([posDeparture, posArrival])

// You also have the ability to use the following code:  
// arrPositions is array of geoPosition
// Add(arrPositions, posDeparture)
// Add(arrPositions, posArrival)
// MAP_MapControl.AddItinerary(arrPositions)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Map control>.AddItinerary(<Positions> [, <Mode> [, <Color> [, <Opacity> [, <Thickness>]]]])`
---

**`<Result>: (Character string)`**



- Identifier of added itinerary,

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function is asynchronous: it is not possible to know whether the function has returned an error. 

**`<Map control>: (Control name)`**

Name of the Map control to be used.

**`<Positions>: (Array)`**

Name of Array variable containing the different positions: 

- The first element corresponds to the departure point of itinerary. 

- The last element corresponds to the arrival point. 

- The other array elements represent the intermediate steps of itinerary. This array must contain at least two elements (departure position and arrival position). If you are using the default Google Map license, this array can contain up to 8 intermediate positions (steps). If you are using a "Google Maps API" license key, the number of intermediate positions is unlimited.  


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This array must contain two elements (departure position and arrival position). You cannot specify the different steps of the itinerary.

This array can be: 

- an array of character strings, describing the address corresponding to each itinerary position. For example: avenue des Champs Elysée, Paris, France. 

- an array of [Address](../WDLang3/1000019944.md) variables, describing the address corresponding to each position of the itinerary. 

- an array of [geoPosition](../WDLang3/1000019191.md) variables, indicating the geographical position corresponding to each itinerary position.

- an array of [Marker](../WDLang3/1000019940.md) variables, representing each itinerary position on the map (the markers will be automatically added to the Map control if not already added).




**`<Mode>: (Optional Integer constant)`**

Mode for calculating the itinerary. This parameter can take one of the following values: 


|   |   |
| --- | --- |
| *itineraryCar*<br>(Default value) | The itinerary will be drawn taking into account the roads accessible to cars.<br><br>Characteristics of this mode:<br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br> |
| *itineraryCarNotOptimized* | The itinerary will be drawn taking into account the roads accessible to cars.<br><br>Characteristics of this mode:<br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- The order of the stops will not be changed.<br><br><br> |
| *itineraryCyclist* | The itinerary will be drawn by respecting the ways accessible to the bicycles. The itineraries for cyclists are not available in all the countries. For more information, please consult the Google geolocation service documentation.<br><br>Characteristics of this mode:<br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |
| *itineraryManual* | The itinerary will be drawn in a straight line between each specified position while ignoring the roads.<br><br>This mode avoids the use of Google's geolocation mode.. In this case, &lt;Positions&gt; must correspond to an array of [geoPosition](../WDLang3/1000019191.md) variables or to an array of [Marker](../WDLang3/1000019940.md) variables.<br><br>In this mode, the intermediate steps are taken into account according to the addition order in the array.<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Please note: If you're using Internet Explorer 4, parameter &lt;Positions&gt; parameter must correspond to an array of variables of type [geoPosition](../WDLang3/1000019191.md). |
| *itineraryPedestrian* | The itinerary will be drawn by respecting the ways accessible to the pedestrians.<br><br>Characteristics of this mode:<br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |



**`<Color>: (Optional integer)`**

Color for drawing the itinerary. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Opacity>: (Optional integer)`**

Percentage of opacity for drawing the itinerary. 

- 0: transparent trace, 

- 100: no opacity. 


This parameter is set to 60 by default.

**`<Thickness>: (Optional integer)`**

Thickness (in pixels) for drawing the itinerary. The thickness is set to 8 pixels by default.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Using Google maps: the "Directions" API must be activated in your Google Maps key. 

- Caution: The order of intermediate stages can be automatically modified to display an optimized route.

- To customize the image of the itinerary markers, all you have to do is add the markers beforehand with [&lt;Map&gt;.AddMarker](../WDLang3/1000022422.md) on the same itinerary positions.

- To delete an itinerary from a map, use [&lt;Map&gt;.DeleteItinerary](../WDLang3/1000022465.md).

- To delete all the itineraries from a map, use [&lt;Map&gt;.DeleteAll](../WDLang3/1000022472.md).

- **Warning** Creating routes between two distant positions may require a very large number of points to be stored in memory for route design (particularly for cycle and pedestrian routes).  Therefore, we advise you to limit the number of itineraries simultaneously displayed on the Map control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To manage specific features regarding the management of itineraries, use [&lt;Map&gt;.ExecuteJS](../WDLang3/1000022384.md).
