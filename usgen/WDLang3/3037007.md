
## FaxDisconnect (Function)

***In french: FaxDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes a connection to a fax server (established beforehand by [FaxConnect](../WDLang3/3037005.md)).

**Note** This function can only be used with Windows 2000, XP or higher. In Windows Vista (and later), the management of faxes is available with Windows Professional and Windows Integral Edition.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ConnectID is int
ConnectID = FaxConnect()
...
IF FaxDisconnect(ConnectID) = False THEN 
	Error("The disconnection failed", ErrorInfo(errSystemMessage))
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = FaxDisconnect(<Connection ID>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the disconnection was performed, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. The corresponding error message is returned by [ErrorInfo](../WDLang1/3013008.md).




**`<Connection ID>: (Integer)`**

Connection identifier, returned by [FaxConnect](../WDLang3/3037005.md).
