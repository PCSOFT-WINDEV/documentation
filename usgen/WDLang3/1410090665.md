
## Parameters of the procedure used by the ProximityShareAttendConnection function (Notification)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure (also called "callback") called by the [SharingProximityAttendConnection](../WDLang3/1410090655.md) function to notify the connection status with a remote device.t
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Each time the switch to enable/disable connection waiting is changed
INT_Attente_connexion.status = Grayed
IF INT_Wait_connection THEN
	PartageProximitéAttendConnexion(gsNomAppareil, CallbackRésultat, CallbackDemandeConnexion, 
		CallbackConnection, NetworkTopology)
ELSE
	ShareProximityRequest()
	INT_Attente_connexion.status = Active
END
```

```wl
PROCÉDURE CallbackConnexion(sIdAppareil is a string, nEtat is an integer)
SWITCH nStatus
	CASE ppRefusConnexion
		ToastDisplay("Connection request refused.")
	CASE ppConnexion
		ToastDisplay(StringBuild("You are connected to device %1.", sIdDevice)
	CAS ppDisconnect
		ToastDisplay("You are logged out.")
	CASE ppEchecConnexion
		ToastDisplay("Connection failed." + ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PartageProximitéAttendConnexion_Callback_Notification(<Remote device identifier> , <Status>)`
---

**`<Remote device identifier>: (Character string)`**

Remote device identifier.t

**`<Status>: (Integer constant)`**

Connection status with remote device: 


|   |   |
| --- | --- |
| *ppConnexion* | Connection established. |
| *ppDisconnect* | Disconnection. |
| *ppEchecConnexion* | Connection failure. In this case, [ErrorInfo](../WDLang1/3013008.md) returns the details of the error. |
| *ppRefusConnexion* | Connection refused by remote device.t |
