
## Nearby sharing constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manage data exchange between nearby devices:

| Constant | Details | Function |
| --- | --- | --- |
| **nsCanceled** | Data transfer canceled. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090657.md) |
| **nsBuffer** | The data received is a binary buffer. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090644.md) |
| **nsCluster** | Cluster topology between nearby devices.<br>In this topology, each device can connect to several devices and/or accept connections from several devices. Each device can act either as an "advertiser", which can accept incoming connections from N other devices, or as a "discoverer", which can initiate an outgoing connection to a single device. | [NearbyShareWaitForConnection](../WDLang3/1410090655.md)<br>[NearbyShareDiscoverDevice](../WDLang3/1410090648.md) |
| **nsConnected** | Nearby device connection status: Connection established. | [NearbyShareWaitForConnection (procedure)](../WDLang3/1410090665.md)<br>[NearbyShareRequestConnection (procedure)](../WDLang3/1410090667.md) |
| **nsDisconnected** | Nearby device connection status: Disconnected | [NearbyShareWaitForConnection (procedure)](../WDLang3/1410090665.md)<br>[NearbyShareRequestConnection (procedure)](../WDLang3/1410090667.md) |
| **nsRequestConfirmation** | Opens a dialog box to show the authentication token to the user and ask for confirmation. <br><br> | [NearbyShareAcceptConnection](../WDLang3/1410090646.md) |
| **nsConnectionFailed** | Nearby device connection status: Connection failed | [NearbyShareWaitForConnection (procedure)](../WDLang3/1410090665.md)<br>[NearbyShareRequestConnection (procedure)](../WDLang3/1410090667.md) |
| **nsInProgress** | Data transfer in progress. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090657.md) |
| **nsError** | Data transfer error. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090657.md) |
| **nsStar** | Topology intended for applications that distribute information from a centralized point.<br>At any time, each device can act either as an "advertiser", which can accept incoming connections from N other devices, or as a "discoverer", which can initiate an outgoing connection to a single device. Once the connection has been established, the devices retain their role until the connection is terminated. | [NearbyShareWaitForConnection](../WDLang3/1410090655.md)<br>[NearbyShareDiscoverDevice](../WDLang3/1410090648.md) |
| **nsFile** | The data received corresponds to a file. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090644.md) |
| **nsPointToPoint** | Topology for "one-to-one" connections where each device can only connect to one other device at a time. This allows for the highest bandwidth possible. | [NearbyShareWaitForConnection](../WDLang3/1410090655.md)<br>[NearbyShareDiscoverDevice](../WDLang3/1410090648.md) |
| **nsConnectionRejected** | Nearby device connection status: Connection rejected by the nearby device. | [NearbyShareWaitForConnection (procedure)](../WDLang3/1410090665.md)<br>[NearbyShareRequestConnection (procedure)](../WDLang3/1410090667.md) |
| **nsCompleted** | Data transfer completed. | [NearbyShareAcceptConnection (procedure)](../WDLang3/1410090657.md) |
