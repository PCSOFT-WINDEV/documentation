


## zipStartAddingFile (Function)

***In french: zipDébutAjoutFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Declares the start of the optimized addition of files to a CAB, ZIP, WDZ, 7z, TAR, gzip or TGZ (TAR.GZ) archive.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start optimized file additions
zipStartAddingFile(MyArchive)
// Add files to archive
FOR EACH FilePath OF arrFileList
	zipAddFile(MyArchive, FilePath)
END
// End optimized file additions 
zipEndAddingFile(MyArchive)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = zipStartAddingFile(<Archive>)`
---

**`<Result>: (Integer)`**



- 0 if the start of the file addition has been declared,

- an error code (value greater than 0) otherwise. For more details on these error codes, see the remarks.




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive in which to start adding files.
This name can correspond to:

- an archive name defined with [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md).

## Remarks


### When to use optimized addition of files
<a name="when_use_optimized_addition_files_ELTPARAGRAPHE000077"></a>

For ZIP, WDZ and 7Z archives, some operations are performed each time a file is added, in order to get a valid archive. These operations can increase the time it takes to create an archive. 

Thus, it takes longer to add a series of files with [zipAddFile](../WDLang3/3082008.md) than with [zipAddFileList](../WDLang3/3082038.md). With [zipAddFileList](../WDLang3/3082038.md), these operations are carried out only once. 

To get the same behavior with [zipAddFile](../WDLang3/3082008.md), it is necessary to add the files between the **zipStartAddingFile** and [zipEndAddingFile](../WDLang3/1410091115.md) functions. 

Note: This function can only be used for ZIP, WDZ and 7Z archives. RAR archives are not supported.


### How to use optimized additions
<a name="how_use_optimized_additions_ELTPARAGRAPHE000107"></a>

For optimized additions:

1. Call **zipStartAddingFile**. The archive will wait for files to be added. 

2. Use [zipAddFile](../WDLang3/3082008.md) to add the desired files. The function remains unchanged. 

3. Finish adding the files with [zipEndAddingFile](../WDLang3/1410091115.md). 




Remarks: 

- Calling a function other than [zipAddFile](../WDLang3/3082008.md) between **zipStartAddingFile** and [zipEndAddingFile](../WDLang3/1410091115.md) will cause a fatal error.

- [zipEndAddingFile](../WDLang3/1410091115.md) must be used after **zipStartAddingFile** to obtain a valid archive. 





### Error codes 
<a name="error_codes_ELTPARAGRAPHE000143"></a>

The following error codes are returned:

- 1: The path passed as parameter does not exist.

- 3: The archive is corrupted.
