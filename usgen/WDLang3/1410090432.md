


## &lt;Notification variable&gt;.Modify (Function)

***In french: &lt;Variable Notification&gt;.Modifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies a notification currently displayed in the system bar of the device.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
notif is Notification
notif.Title = "New incoming message"
notif.Message = "Click here to display the message"
notif.Add()
...
notif.Title = "2 incoming messages"
notif.Message = "Click here to display the messages"
notif.Modify()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Notification>.Modify()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the notification was modified, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**Note** In the simulator, this function has no effect and always returns <u><u><u><u>False</u></u></u></u>.

**`<Notification>: (Notification variable)`**

Name of the [Notification](../WDLang3/1000019441.md) variable containing the description of the notification to update.
