


## &lt;upnpDevice variable&gt;.GetBrightness (Function)

***In french: &lt;Variable upnpPériphérique&gt;.RécupèreLuminosité***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the brightness of a UPnP device.

**Attention**: To use this function, the device must have a "RenderingControl" service.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrDevice is array of upnpDevices 
arrDevice = UPNPListDevice(...
		"urn:schemas-upnp-org:device:MediaRenderer:1", 5)
FOR EACH Device of arrDevice
	Trace(Device.Name + ": " + Device.RecoverLuminosity())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <UPnP device>.GetBrightness()`
---

**`<Result>: (Integer)`**

Brightness of the device (between 0 and 100).

**`<UPnP device>: (upnpDevice variable)`**

Name of the [upnpDevice](../WDLang3/1000020903.md) variable corresponding to the UPnP device to use.
