


## grAxisTitle (Function)

***In french: grTitreAxe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the title of X-axis and the title of Y-axis in a chart.

Example of titles for the chart axes: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=titreaxe.gif)


**Note** By default, the axes of a graph have no title.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the title of the vertical axis in "MyChart"
grAxisTitle("MyChart", "Time", grYCoordinate)
```
<a name="Exemple2"></a>

```wl
// Modify the title of the horizontal axis in "CHART_MyChart"
grAxisTitle(CHART_MyChart, "Time", grYCoordinate)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grAxisTitle(<Chart name> , <Title> , <Axis direction>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Title>: (Character string)`**

Title of specified axis.

**`<Axis direction>: (Constant)`**

Orientation of axis to use:


|   |   |
| --- | --- |
| *grSecondaryYCoordinate* | Marks on secondary Y-axis (vertical axis). |
| *grXCoordinate*<br>(default value) | Marks on X-axis (horizontal axis). |
| *grYCoordinate* | Marks on Y-axis (vertical axis). |

## Remarks


### Types of charts
<a name="types_charts_ELTPARAGRAPHE000145"></a>

Depending on the type of chart and on &lt;Axis direction&gt;, **grAxisTitle** is taken into account or not:

| Chart type | Horizontal axis | Vertical axis |
| --- | --- | --- |
| Line chart | **grAxisTitle** taken into account. | **grAxisTitle** taken into account. |
| Stock chart (Candlestick and BarChart) | **grAxisTitle** taken into account. | **grAxisTitle** taken into account. |
| Column chart | **grAxisTitle** taken into account. | **grAxisTitle** taken into account. |
| Min/Max Stock chart | **grAxisTitle** taken into account. | **grAxisTitle** taken into account. |
| Scatter | **grAxisTitle** taken into account. | **grAxisTitle** taken into account. |
| Pie | **grAxisTitle** not taken into account. | **grAxisTitle** not taken into account. |


Any changes made with **grAxisTitle** will take effect the next time [grDraw](../WDLang3/3042026.md) is called.
<a name="NOTE0_2"></a>


### Title of axes
<a name="title_axes_ELTPARAGRAPHE000231"></a>The title of chart axes can be displayed for the different axes.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Titre.gif)
The content of the title for the chart axes is defined by **grAxisTitle**. This function can also be used to position this title according to the desired axis. You cannot define the positioning and/or the orientation of the title in relation to the axis.  

The font used for the chart title can be modified by [grAxisTitleFont](../WDLang3/3042059.md).
<a name="NOTE0_3"></a>


### Languages that use a non-Latin character set
<a name="languages_that_use_nonlatin_character_set_ELTPARAGRAPHE000249"></a>



### Languages that use a non-Latin character set
<a name="languages_that_use_nonlatin_character_set_ELTPARAGRAPHE000384"></a>

**grAxisTitle** will use the selected non-Latin character set only if the associated project configuration uses UNICODE strings at runtime.

To check the selected option in the current configuration: 

1. In the "Project Explorer" pane, display the context menu for the "Configurations" option and select "Description".  

2. Display the "Unicode" tab: the "Use UNICODE strings at runtime" option must be checked.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Gestion_Unicode%20-%20HC%20N%B0001.gif)


3. Validate if necessary.
