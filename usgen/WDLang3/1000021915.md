<a name="Utilisation"></a>
<a name="description"></a>
Specifies the starting angle of the first section in a Sunburst chart.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Increase the starting angle of "CHART_MyChart"
grSunburstStartAngle(CHART_MyChart, 45)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grSunburstStartAngle(<Chart name> , <Angle>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In pages, only "Interactive chart" controls are available for Sunburst charts.

**`<Angle>: (Integer)`**

Starting angle of the first section (expressed in degrees, clockwise from the top point). 
By default, the starting angle in a Sunburst chart is equal to 0.
