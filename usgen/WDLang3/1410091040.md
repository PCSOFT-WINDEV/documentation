


## EmailUnsubscribeFromFolder (Function)

***In french: EmailDésabonneDuDossier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Removes a folder from the list of subscribed folders. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
session is emailIMAPSession
session.ServerAddress = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Name = "XXXXX"
session.Password = "XXXXXXX"
EmailStartSession(session)

// List of email management folders and subscribed folders
res is string
res = EmailListFolder(session, LstFolderNormal)
Trace(res)
Trace("---------------------------------------------------")
// Unsubscribe from Test folder
Trace("Unsubscribe: " + (EmailUnsubscribeFromFolder(session, "Test")? "OK" ELSE "KO"))
Trace("---------------------------------------------------")
// List of email management folders and subscribed folders
// Test folder is no longer listed
res = EmailListFolder(session, LstFolderNormal)
Trace(res)
Trace("---------------------------------------------------")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = EmailUnsubscribeFromFolder(<IMAP session> , <Folder>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified folder has been unsubscribed,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<IMAP session>: (emailIMAPSession variable)`**

Name of the [emailIMAPSession](../WDLang3/1000018957.md) variable corresponding to the IMAP session connected to the mail server. 

**`<Folder>: (Character string)`**

Name and path of the folder to be removed from the list of subscribed folders. 



<a name="NOTE0"></a>

## Remarks


- Folders deleted with [EmailRemoveFolder](../WDLang3/3032134.md) are automatically unsubscribed. 

- Deleted folders are automatically removed from the list of subscriber folders. 

- [EmailListFolder](../WDLang3/3032133.md) with the *LstFolderNormal* constant lists folders containing emails and subscribed folders.

- [EmailListFolder](../WDLang3/3032133.md) with the *LstFolderAll* constant lists all folders (folders containing emails and subscribed or non-subscribed folders).
