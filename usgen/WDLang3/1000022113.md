


## BTLEGetACharacteristic (Function)

***In french: BTLERécupèreUneCaractéristique***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the characteristic of a Bluetooth Low Energy service corresponding to the specified identifier (UUID).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyDevice is btleDevice
...
MyCharac is btleCharacteristic 
MyCharac = BTLEGetACharacteristic(MyDevice.Service[1], "ACC54-DAD4D5-DADD")
IF ErrorOccurred THEN
	Error("The characteristic does not exist.")
	RETURN
END
...
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BTLEGetACharacteristic(<Service> , <Identifier>)`
---

**`<Result>: (btleCharacteristic variable)`**

[btleCharacteristic](../WDLang3/1000022060.md) variable corresponding to the characteristic found for the specified service. If no characteristic corresponds to the specified identifier, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>.

**`<Service>: (btleService variable)`**

Name of the [btleService](../WDLang3/1000022057.md) variable corresponding to the service used.

**`<Identifier>: (Character string)`**

Identifier (UUID) of characteristic to retrieve.

Caution: If several characteristics correspond to the same identifier (UUID), only the first characteristic is retrieved.. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Several characteristics of the same device can correspond to the same identifier (UUID). To retrieve all the characteristics corresponding to the same identifier, use [BTLEGetAllCharacteristics](../WDLang3/1000022115.md).
