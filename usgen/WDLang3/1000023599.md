


## &lt;Chart&gt;.SeriesColor (Function)

***In french: &lt;Graphe&gt;.CouleurSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the color of a series, the color of a pie section or the color of a funnel section. 

By default, the colors of series (or the colors of sections) are selected according to a preset order among a set of 11 colors. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modifies the color of series 2 in the "CHART_MyChart" control
CHART_MyChart.SeriesColor(2, LightYellow)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.SeriesColor(<Series number> , <Color>)`
---

**`<Chart control>: (Control name)`**

Name of manipulated Chart control (present in window, page or report editor).
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to use. 

**For a Pie chart** (constant *grSector*), this parameter corresponds to the index of the data in the series (the sector number).
**For a Funnel chart** (constant *grFunnel*), this parameter corresponds to the index of the data in the series (the portion number).

**`<Color>: (Integer or Integer constant)`**

Color of the specified series. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The following colors are used by default: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grCouleurSerie.gif)


- The colors defined by **&lt;Chart&gt;.SeriesColor** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).

- To display the color gradients, use [&lt;Chart&gt;.Gradient](../WDLang3/1000024061.md).

- To define a color for the series in "Scatter" charts, it is recommended to use [&lt;Chart&gt;.ScatterSeriesColor](../WDLang3/1000024106.md).

- The [SeriesColor](../Proprietes/2510145.md) property allows you to get and initialize the color of a series or a pie section (same as **&lt;Chart&gt;.SeriesColor**).
