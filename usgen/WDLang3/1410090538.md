


## AuthLogout (Function)

***In french: AuthDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Logs out a user previously authenticated via: 

- the OAuth 2.0 protocol on any web service.

- the OpenID protocol on any web service.
	

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) a JSON Web Token (JWT).




Remarks: 

- The logout opens a browser (as for the login). The redirect URL is called when the logout is performed. To log in again, the user will have to go through the entire login process.

- When you use a variable of type [OAuth2Parameters](../WDLang3/1000022212.md), you need to specify the logout URL with the **LogoutURL** property. 

- This function is not available **for an iOS configuration**. It is recommended to use [AuthRevokeToken](../WDLang3/1410090634.md).

## Example


```wl
stOpenIDParam is OpenIDParameters
stOpenIDParam.ConfigurationURL = "https://login.microsoftonline.com/99f49690-a048-4e6e-a51e-9e6e96b4981d/v2.0/.well-known/openid-configuration"
stOpenIDParam.ClientID = "99f10db4-c3b1-437f-8362-8070750f0190"
stOpenIDParam.Scope = "email openid"
stOpenIDParam.RedirectionURL = "http://localhost:9874"
stToken is AuthToken = AuthIdentify(stOpenIDParam)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
	RETURN
END
Identity is OpenIDIdentity = OpenIDReadIdentity(stToken)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
	RETURN
END
Trace(Identity.Email)
AuthLogout(stToken)
```

## Syntax
<a name="SYNTAXE2"></a>

### Logging out a user previously authenticated using OAuth 2.0

`<Result> = AuthLogout(<OAuth authentication>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the logout was performed,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<OAuth authentication>: (OAuth2Parameters variable)`**

Name of the [OAuth2Parameters](../WDLang3/1000022212.md) variable corresponding to the session to be closed. The **LogoutURL** property indicates the page to be displayed after logout. 


<a name="SYNTAXE3"></a>

### Logging out a user previously authenticated using OAuth 2.0 (asynchronous syntax)

`AuthLogout(<OAuth authentication> , <WLanguage procedure>)`
---

**`<OAuth authentication>: (OAuth2Parameters variable)`**

Name of the [OAuth2Parameters](../WDLang3/1000022212.md) variable corresponding to the session to be closed. The **LogoutURL** property indicates the page to be displayed after logout. 

**`<WLanguage procedure>: (Procedure name)`**

Optional WLanguage procedure to be called when the logout is performed. This procedure has the following format: 

```txt
<Procedure name>(<Logout>)
```
 where &lt;Logout&gt; is a boolean indicating whether or not the logout has been performed (<u><u><u><u>True</u></u></u></u> or <u><u><u><u>False</u></u></u></u>, respectively).
