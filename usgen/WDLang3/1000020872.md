


## inAppListProductInfo (Function)

***In french: inAppListeInfoProduit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves, from the store, information about the "In-App" products associated with the application.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrIdentifier is array of strings 
IF InAndroidMode() THEN
	arrIdentifier = ["product1", "product2", "product3", "product4", "unknown product"]
ELSE
	arrIdentifier = ["ProductID1", "ProductID2", "ProductID3", ...
		"ProductID4", "ProductID5", "unknown product"]
END
IF inAppListProductInfo(arrIdentifier, ListProductInfo) THEN
	 ToastDisplay("Asks for the list of products sent.")
ELSE
	Error("ERROR: " + ErrorInfo)
END
```

```wl
// --------------------
// ListProductInfo procedure
PROCEDURE ListProductInfo(bSuccess is boolean, arrProducts is array of inAppProduct)
IF NOT bSuccess THEN
	Error("Error: " + ErrorInfo())
	RETURN
END
LooperDeleteAll(LOOP_ProductInfo)
FOR I = 1 _TO_ arrProducts.Count
	LooperAddLine(LOOP_ProductInfo, arrProducts[i].Caption, ...
		arrProducts[i].Description, arrProducts[i].Identifier, arrProducts[i].Price)
END
// Copy into the array global to the window
garrProduct <= arrProducts
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = inAppListProductInfo(<Identifiers of products> , <WLanguage procedure>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the request for retrieving product information was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Identifiers of products>: (Array of character strings)`**

Identifiers of products to use. These identifiers are the ones defined when creating the products: 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) in iTunes Connect.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) in the Google Play developer console.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) You cannot ask to retrieve information about more than 20 products at a time. A fatal error occurs if more than 20 identifiers are specified.

Note: If an identifier does not correspond to an existing product, it is ignored. 

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") executed when the product details are received. For more details on this procedure, see [Parameters of the procedure used by inAppListProductInfo](../WDLang3/1000024696.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The information request is asynchronous. This allows the application to keep running while the product details are being retrieved. This operation can be quite long because network requests must be performed.

- To find out the list of products purchased by the user and not consumed and the list of active subscriptions, use [inAppListPurchase](../WDLang3/1000020888.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **inAppListProductInfo** has no effect if it is run from the Android simulator or emulator.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **inAppListProductInfo** must be called before any other call to [inAppXXX](../WDLang3/1000021034.md) functions.
