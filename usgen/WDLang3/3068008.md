
## SMSDelete (Function)

***In french: SMSSupprime***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>25</B>, this function should no longer be used. Starting with Android 4.4, SMS deletion through programming is no longer allowed. Using this function causes a fatal error in the application.  
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes an SMS message from the memory of the Android phone. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The system no longer allows SMS deletion through programming since Android 4.4.


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SMSDelete(<Location> , <SMS index>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the SMS was deleted,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) From Android 4.4 (Kit Kat), the system no longer allows SMS deletion from the inbox. **SMSDelete** will always return <u><u><u><u>False</u></u></u></u>.

**`<Location>: (Integer constant)`**

Location of SMS to delete:


|   |   |
| --- | --- |
| *smsMemory* | SMS stored in the device memory. |
| *smsSIM* | SMS stored in the SIM card<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is not allowed and it triggers a fatal error. |



**`<SMS index>: (Integer)`**

Index of the SMS message to be deleted. This index is returned by the SMS.Index variable. For more details, see [SMS structure](../WDLang3/3068003.md).
