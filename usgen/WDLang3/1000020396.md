The following constants are used to manipulate Map controls: 

| Constant | Description | Used by the functions |
| --- | --- | --- |
| **addressCustom** | Address type: personalized address. | [Address](../WDLang3/1000019944.md) variable |
| **addressHome** | Address type: home address. | [Address](../WDLang3/1000019944.md) variable |
| **addressOther** | Address type: other address type. | [Address](../WDLang3/1000019944.md) variable |
| **addressWork** | Address type: business (office) address. | [Address](../WDLang3/1000019944.md) variable |
| **itineraryCar** | The itinerary will be drawn taking into account the roads accessible to cars.<br><br>Characteristics of this mode:<br><br><br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br> | [MapAddItinerary](../WDLang3/1000020383.md) |
| **itineraryCarNotOptimized** | The itinerary will be drawn taking into account the roads accessible to cars.<br><br>Characteristics of this mode:<br><br><br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- The order of the stops will not be changed.<br><br><br> | [MapAddItinerary](../WDLang3/1000020383.md) |
| **itineraryCyclist** | The itinerary will be drawn by respecting the ways accessible to the bicycles. The itineraries for cyclists are not available in all the countries. For more information, please consult the Google geolocation service documentation.<br><br>Characteristics of this mode:<br><br><br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br> | [MapAddItinerary](../WDLang3/1000020383.md) |
| **itineraryManual** | The itinerary will be drawn in a straight line between each specified position while ignoring the roads.<br><br>This mode avoids the use of Google's geolocation mode.. In this case, the &lt;Positions&gt; parameter must correspond to an array of geoPosition or Marker variables.<br><br><br><br>In this mode, the intermediate steps are taken into account according to the addition order in the array. | [MapAddItinerary](../WDLang3/1000020383.md) |
| **itineraryPedestrian** | The itinerary will be drawn by respecting the ways accessible to the pedestrians.<br><br>Characteristics of this mode:<br><br><br><br>- This mode uses Google's geolocation mode. An Internet access is required.<br><br>- You can rearrange the order of the stops get the best possible route.<br><br><br> | [MapAddItinerary](../WDLang3/1000020383.md) |
| **mcsAubergine** | Style applied to card: "eggplant" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsAutomatic** | Style applied to map: The style will be applied according to the application's light or dark mode:<br><br>- Clear theme: the style used will be the "standard" style,<br><br>- Dark theme: the style used will be "night".<br><br><br>If the theme of the application changes while the Map control is displayed, the style will change automatically. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsCustom** | Style applied to card: Custom style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsDark** | Style applied to map: "Dark" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsNight** | Style applied to card: "Night" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsRetro** | Style applied to the card: "Retro" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsSilver** | Style applied to card: "Silver" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mcsStandard** | Style applied to card: "standard" style. | [MapGetStyle](../WDLang3/1000025557.md), [MapChangeStyle](../WDLang3/1000025556.md) |
| **mkBottom** | Marker alignment mode when displayed on a map: Marker displayed at bottom of position. | [Marker](../WDLang3/1000019940.md) type |
| **mkCenter** | Marker alignment mode when displayed on a map: Marker displayed on position. | [Marker](../WDLang3/1000019940.md) type |
| **mkLeft** | Marker alignment mode when displayed on a map: Marker displayed to the left of position. | [Marker](../WDLang3/1000019940.md) type |
| **mkRight** | Marker alignment mode when displayed on a map: Marker displayed to the right of position. | [Marker](../WDLang3/1000019940.md) type |
| **mkTop** | Marker alignment mode when displayed on a map: Marker displayed at top of position. | [Marker](../WDLang3/1000019940.md) type |
