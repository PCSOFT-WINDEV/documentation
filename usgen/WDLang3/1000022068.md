


## BTLEConnectionStatus (Function)

***In french: BTLEEtatConnexion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the current status of the connection to a Bluetooth Low Energy device or asks to be notified when the connection status changes. 

**Note**: Bluetooth functions are not available in the Android emulator.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
myDevice is btleDevice
BTLEConnect(myDevice)
...
SWITCH BTLEConnectionStatus(myDevice)
	CASE btleStatusConnected
	// Process
	OTHER CASE
	...
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the current connection status

`<Result> = BTLEConnectionStatus(<Device>)`
---

**`<Result>: (Integer constant)`**

Status of the connection: 


|   |   |
| --- | --- |
| *btleStatusConnected* | The device is connected to the specified Bluetooth device. |
| *btleStatusDisconnected* | The device is not connected to the specified Bluetooth device. |



**`<Device>: (btleDevice variable)`**

Name of the [btleDevice](../WDLang3/1000022054.md) variable corresponding to the device to use.


<a name="SYNTAXE2"></a>

### Enabling the notification whenever Bluetooth activation changes

`BTLEConnectionStatus(<WLanguage procedure>)`
---

**`<WLanguage procedure>: (Procedure name)`**

Name of WLanguage procedure (called "callback") called when Bluetooth connection status changes on the device. This procedure has the following format: 


```txt
PROCEDURE <Procedure name> (<Device>, <Status>)
```
where: 

- &lt;Device&gt; is a [btleDevice](../WDLang3/1000022054.md) variable corresponding to the Bluetooth device whose status is retrieved. 

- &lt;Status&gt; is an integer corresponding to the status of Bluetooth connection on the device: 
	


|   |   |
| --- | --- |
| *btleStatusConnected* | The device is connected to the specified Bluetooth device. |
| *btleStatusDisconnected* | The device is not connected to the specified Bluetooth device. |




There is no need to pass parameters to this procedure. Indeed, these parameters are automatically filled during each call.

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000232"></a>

This function changes the permissions required by the application.

Permission required: BLUETOOTH.

This permission allows the applications to connect to the Bluetooth services.

**Necessary versions**


- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Applications ANDROID**: 

	- Bluetooth Low Energy WLanguage functions are only available on devices with Android 4.3 or later (api level 18). 

	- A fatal error occurs if the function is used with an earlier system version. 

	- To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).




- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **iOS applications**: 
	The WLanguage Bluetooth Low Energy functions are available for the devices running iOS 9. 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) **Applications WINDEV**: 

	- Bluetooth Low Energy WLanguage functions are only available on:  

		- PCs that support at least Bluetooth Low Energy 5. 

		- PCs using a Bluetooth device that supports at least Bluetooth Low Energy 5. 




- If necessary, you can check the Bluetooth version of a PC in the Windows device manager: [https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793](https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793)

- Pairing must be done via Windows. Therefore, [BTLEListDevice](../WDLang3/1000021882.md) will only list devices that are visible and associated in the Windows Bluetooth settings.
