


## MapIDGgl (Function)

***In french: CarteIdentifiantGgl***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets or sets the style used in the Map control. This style corresponds to a map ID defined in the Google Cloud console. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines the map to use from those defined in Google Cloud Platform
MapIDGgl(MAP_NoName1, "DetailedMapID")
// Displays the identifier
Trace(MapIDGgl(MAP_NoName1))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the map identifier associated with a Map control

`<Result> = MapIDGgl(<Map control>)`
---

**`<Result>: (Character string)`**

Map identifier associated with the control. 

**`<Map control>: (Control name)`**

Name of the Map control used. 


<a name="SYNTAXE2"></a>

### Setting the map identifier associated with a Map control

`MapIDGgl(<Map control> , <Identifier>)`
---

**`<Map control>: (Control name)`**

Name of the Map control used. 

**`<Identifier>: (Character string)`**

Map identifier representing the map styling to be used.

## Remarks


### Defining a map identifier
<a name="defining_map_identifier_ELTPARAGRAPHE000075"></a>

A map ID is a unique identifier that represents Google Maps styling and configuration settings stored in Google Cloud. Map IDs can be used to enable features or style maps on your websites and in your applications.

For more details, see [https://developers.google.com/maps/documentation/javascript/cloud-customization#creating_map_styles](https://developers.google.com/maps/documentation/javascript/cloud-customization#creating_map_styles). 

You can define map IDs in the Google Cloud console: 

1. Open the Google Cloud console and log in. 

2. In the menu, select "Map Styles". Click "Create style". You can define different colors for roads, natural features, etc. Name and save the new style.

3. In the menu, select "Map Management" and click "Create map ID". Enter the name of the ID (this name will be used by **MapIDGgl**). The associated map must be of type "JavaScript". 

4. You can add map IDs in the map style description. It is then possible to associate the map ID with the new map style.

5. Publish your map style for use in your application or website.
