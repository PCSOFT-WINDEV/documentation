
## AppointmentDelete (Function)

***In french: RendezVousSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the current appointment from the calendar of a Lotus Notes or Outlook messaging.
	**Reminder** This function cannot be used to delete the current appointment from the Outlook Express calendar.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) an appointment from the calendar found on an Android device.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) an appointment from the calendar found on an iOS device.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", ...
	"email/julia.nsf", "C:\Lotus Notes\julia.id")
// Read the last appointment
AppointmentLast(SessionID)
// Delete the appointment
AppointmentDelete(SessionID)
```


<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Deletes the appointment corresponding to the identifier <25>
arrAPT is array of Appointment
arrAPT = AppointmentList(MyCalendar, aptIdentifier, 25)
IF arrAPT..Occurrence > 0 THEN
	AppointmentDelete(arrAPT[1])
END
```

## Syntax

### Deleting the current appointment from the calendar of a Lotus Notes or Outlook messaging 

`<Result> = AppointmentDelete(<Session identifier> [, <Appointment identifier>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant. 




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).  

**`<Appointment identifier>: (Optional character string)`**

Identifier of the appointment to be deleted. This identifier is found in the mAppointment.ID variable.

### Deleting an appointment from the calendar found on a mobile device (Android/iOS)

`<Result> = AppointmentDelete(<Appointment>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Appointment>: (Appointment variable)`**

Name of the [Appointment](../WDLang1/1000019244.md) variable corresponding to the appointment to be deleted from the calendar of the Android or iOS device.

### Android calendar
<a name="android_calendar_ELTPARAGRAPHE000127"></a>

**AppointmentDelete** can be used in the emulator but not in the simulator.

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000140"></a>

This function changes the permissions required by the application.
Required permissions: 

- READ_CALENDAR: This permission allows the application to read the user's Calendar data.

- WRITE_CALENDAR: This permission allows the application to write the user's Calendar data.
