


## QuickActionRemove (Function)

***In french: ActionRapideSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Removes a quick action defined for the application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ActionRapideSupprime("ID_ACTION_ENVOI_MESSAGE")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Removing a quick action using a QuickAction variable

`<Result> = QuickActionRemove(<Action>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the quick action was removed,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<Action>: (QuickAction variable)`**

[QuickAction](../WDLang3/1410090054.md) variable describing the action to be removed


<a name="SYNTAXE2"></a>

### Removing a quick action using its identifier

`<Result> = QuickActionRemove(<Identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the quick action was removed,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<Identifier>: (Character string)`**

Identifier of the quick action to be removed.
