


## WLanguage procedure called by inAppCheckSubscription



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [inAppCheckSubscription](../WDLang3/1000022719.md) if one of the subscriptions has been renewed. This procedure can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Project initialization code
inAppCheckSubscription(CheckSubscription)
```

```wl
PROCEDURE CheckSubscription(bSuccess is boolean, Product is inAppProduct)
IF NOT bSuccess THEN
	ToastDisplay(ErrorInfo())
	RETURN
ELSE	
	// Call the inAppListPurchase function 
	// to check the start and end dates of subscription
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`inAppCheckSubscription_Callback(<Success> , <Product>)`
---

**`<Success>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the subscription was renewed,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Product>: (inAppProduct variable)`**

[inAppProduct](../WDLang3/1000020868.md) variable corresponding to the product for which the subscription renewal is checked.
