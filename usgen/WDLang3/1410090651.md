
## NearbyShareRejectConnection (Function)

***In french: PartageProximitéRefuseConnexion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Rejects a connection request from a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Button to reject the connection
NearbyShareRejectConnection(gsDeviceID)
Close()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareRejectConnection(<Device identifier>)`
---

**`<Device identifier>: (Character string)`**

Identifier of the nearby device for which the connection is to be rejected.
