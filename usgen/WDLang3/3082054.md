


## zipCompressionLevel (Function)

***In french: zipNiveauCompression***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the compression level used when creating an archive in ZIP format or in 7z format.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
NumZipErr is int
MyArchive is zipArchive

// Create the archive named "MyArchive"
NumZipErr = zipCreate(MyArchive, "C:\MyDocuments\Archive.zip")
IF NumZipErr <> 0 THEN
	Error(zipMsgError(NumZipErr))
	RETURN
END

// Add a file and use the default compression level (6)
NumZipErr = zipAddFile(MyArchive, "C:\MyImages\Image1.jpg", zipNone)
IF NumZipErr <> 0 THEN
	Error(zipMsgError(NumZipErr) + "On the file " + zipCurrentFile(MyArchive))
END

// Change the compression level
// The next file will be stored (no compression)
zipCompressionLevel(MyArchive, 0)

// Add a file
NumZipErr = zipAddFile(MyArchive, "C:\MyImages\Image2.jpg", zipNone)
IF NumZipErr <> 0 THEN
	Error(zipMsgError(NumZipErr) + "On the file " + zipCurrentFile(MyArchive))
END
```

## Syntax

`<Result> = zipCompressionLevel(<Archive> , <Compression level>)`
---

**`<Result>: (Integer)`**



- 0 if the compression level was changed,

- An error code (value greater than 0) otherwise (see the Notes).




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- an archive name defined with [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [zipArchive](../WDLang3/1000018679.md) variables are not available in Java.




**`<Compression level>: (Integer)`**

Value included between 0 (storage without compression) and 9 (maximum compression). 
The default compression level is set to 6.

<a name="NOTE0_1"></a>

## Remarks


### Error codes
<a name="error_codes_ELTPARAGRAPHE000093"></a>

The following error codes are returned:

- 15: CAB format archive.

- 27: Archive in WDZ format.

- 28: Invalid compression level.




The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).
<a name="NOTE0_2"></a>


### Compression level and addition time
<a name="compression_level_and_addition_time_ELTPARAGRAPHE000109"></a>

**Caution**: The higher the compression level, the longer it will take to add a file to the archive.
<a name="NOTE0_3"></a>


### Notes
<a name="notes_ELTPARAGRAPHE000116"></a>

The compression level is defined by the call to the function for all the files that will be added to the archive thereafter (the compression level for the files already found in the archive remains the same).

**Please note** It is not possible to change the compression level of a file in an existing archive.
