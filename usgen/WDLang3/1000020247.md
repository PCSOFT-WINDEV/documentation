


## InstantMessaging (Variable type)

***In french: MessagerieInstantanée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InstantMessaging** type is used to define the advanced characteristics of the instant messaging of a contact (Google Talk, Skype, MSN, etc.). 

The characteristics of this messaging system can be defined and modified using various WLanguage properties. 

This type of variable is used by the [Contact](../WDLang3/1000020254.md) variables.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="PROPS"></a>

## Properties


### Properties specific to InstantMessaging variables
<a name="properties_specific_instantmessaging_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used:

| Address | Character string | Address of contact on the relevant instant messaging. |
| Label | Character string | Label for the custom messaging (optional). <br>If the **Type** property does not correspond to the *imCustom* constant, the value of this property will be ignored. |
