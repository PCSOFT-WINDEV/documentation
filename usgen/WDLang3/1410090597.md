


## Phone functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate phones features, using prefix syntax:



|   |   |
| --- | --- |
| [&lt;Notification variable&gt;.Add](../WDLang3/1410090431.md) | Adds a notification to the system bar (Android) or notification center (iOS). |
| [&lt;Notification variable&gt;.Delete](../WDLang3/1410090434.md) | Removes a notification from the system bar. |
| [&lt;Notification variable&gt;.Modify](../WDLang3/1410090432.md) | Modifies a notification currently displayed in the system bar of the device. |
| [&lt;Notification variable&gt;.SendPush](../WDLang3/1410090433.md) | Sends a push notification to a mobile device (iOS or Android). |
| [&lt;Notification variable&gt;.SendPushSubscriber](../WDLang3/1410090479.md) | Sends a notification to Android devices that are subscribed to a topic. |
