
## RecorderAction (Function)

***In french: MagnetoAction***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Runs an action on the recorder or dictaphone found on the current device.

**Note**: This function is only available if the current device has a tape recorder function.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
```wl
// Read the sound file named "Music.3gpp"
RecorderAction(recorderPlay, "Music.3gpp")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = RecorderAction(<Action> [, <File name>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified action was started, 

- <u><u><u><u>False</u></u></u></u> otherwise.


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

**`<Action>: (Integer constant)`**

Type of action to perform:


|   |   |
| --- | --- |
| *recorderClose* | Closes the recorder. |
| *recorderPlay* | Opens the recorder and plays the specified sound file. |
| *recorderRecord* | Opens the recorder and starts recording.<br>The recording starts when the user presses the button that calls **RecorderAction**. |
| *recorderStop* | Stops the current recording.<br>The recording stops when the user releases the button that calls **RecorderAction**. |



**`<File name>: (Optional character string)`**

Name and full path of the sound file:

- to record (*recorderRecord* constant).

- to play (*recorderPlay* constant).  




This file has the following format: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) ".3gpp" in Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) ".WAV" in iPhone/iPad.

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Required permissions**
This function changes the permissions required by the application.

Permission required: RECORD_AUDIO 

This permission is used to record the sounds.
