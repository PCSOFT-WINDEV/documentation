


## gglDrive (Variable type)

***In french: gglDrive***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **gglDrive** type is used to handle Google Drive. To use a **gglDrive** variable, you need to connect to Google Drive using [GglDriveConnect](../WDLang3/1410089373.md). 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

Drive is gglDrive
Drive = GglDriveConnect(oOAuth2Param)
```



```wl
oMyOAuthParameters is OAuth2Parameters
// Authentication parameters
oOAuth2Token is AuthToken
oOAuth2Token = AuthIdentify(oMyOAuthParameters)
// Connection
Drive is gglDrive
Drive = GglDriveConnect(oOAuth2Token)
```

<a name="PROPS"></a>

## Properties


### Specific cases when using Google Drive with an existing token
<a name="specific_cases_when_using_google_drive_with_existing_token_ELTPARAGRAPHE000030"></a>

The properties of [OAuth2Parameters](../WDLang3/1000022212.md) variables used by the [GglDriveConnect](../WDLang3/1410089373.md) function are as follows: 

| Property of OAuth2Parameters variables | Value used by the GglDriveConnect function |
| --- | --- |
| AuthURL | "https://accounts.google.com/o/oauth2/v2/auth" |
| TokenURL | "https://oauth2.googleapis.com/token" |
| Scope | "https://www.googleapis.com/auth/drive" |
| RedirectionURL (Editable) | "http://localhost:3400/" |
