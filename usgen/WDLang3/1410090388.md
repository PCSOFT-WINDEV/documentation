


## App shortcuts functions (prefix syntax)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate app shortcuts (also called "quick actions") using prefix syntax:



|   |   |
| --- | --- |
| [&lt;QuickAction variable&gt;.Add](../WDLang3/1410090385.md) | Adds a new quick action to the application. |
| [&lt;QuickAction variable&gt;.Pin](../WDLang3/1410090409.md) | Generates a request to pin a quick action. |
| [&lt;QuickAction variable&gt;.Remove](../WDLang3/1410090386.md) | Removes a quick action defined for the application. |
