


## TwoFactorAuthenticationGenerateLink (Function)

***In french: DoubleAuthGénèreLien***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Generates a link to register an account in an authentication application. When associated with a Bar Code control, this link will show a QR code that can be scanned in the authentication app installed on the phone. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let sURL = TwoFactorAuthenticationGenerateLink(sTOTPKey, sEmail, sAppName)
BAC_MyQRCode = sURL
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = TwoFactorAuthenticationGenerateLink(<TOTP key> , <Account> , <Application>)`
---

**`<Result>: (Character string)`**

URL used to create an account in an authentication application.

**`<TOTP key>: (String, Buffer or Secret string)`**

TOTP key of the user to be authenticated. This TOTP key was generated with [DoubleAuthGenerateKey](../WDLang3/1000025974.md).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter can be "Buffer - ASCII" or "Buffer - UTF-8".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications.

**`<Account>: (Character string)`**

Name of the account to be registered (the email address is generally used).

**`<Application>: (Character string)`**

Name of the application to be registered on the authentication application.
