


## DriveCopyDirectory (Function)

***In french: DriveCopieRépertoire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Copies a directory and its contents to another directory of a remote drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

oDrive is Drive
oDrive = oDriveConnect(oOAuth2Param)

IF DriveCopyDirectory(oDrive, "/MyPhotos/2000/", "/Backups/") = False THEN
	Error("Unable to copy directory", ErrorInfo())
	RETURN
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DriveCopyDirectory(<Drive> , <Directory to copy> , <Destination directory>)`
---

**`<Result>: (Boolean)`**



-  if the file was copied successfully,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Drive>: (Drive or gglDrive variable)`**

Name of the [Drive](../WDLang3/1410089369.md) or [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the drive to be used. The connection to the drive must have been previously established. Otherwise, the element is not copied.  

**`<Directory to copy>: (Character string)`**

Absolute path of the directory to be copied. If this parameter does not correspond to a valid directory path, the directory will not be copied. All the contents of the directory will be copied, including subdirectories and files. 

**`<Destination directory>: (Character string)`**

Path of the destination directory to which the source directory will be copied. If this path is not valid, the directory will not be copied. Missing directories in the path are not created.

## Remarks


### &lt;Directory to copy&gt; and &lt;Destination directory&gt;
<a name="and_ELTPARAGRAPHE000070"></a>

Examples of valid paths: 

```txt
"/holidays directory/2021/"
"\photos"
```


Examples of invalid paths:

```txt
"directoryA/DirectoryB"
"This/Path/Is/invalid"
"c:\Users\"
```
