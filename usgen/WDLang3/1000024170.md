


## &lt;Chart&gt;.DeleteAll (Function)

***In french: &lt;Graphe&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Erases a chart drawn and created by [grCreate](../WDLang3/3042005.md) and destroys this chart. Destroying a chart allows you to free the memory space occupied by the matrix used by this chart.

**Note** All graphs used in an application are systematically destroyed when the window or application is closed.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Destroy the chart named "MyChart"
CHART_MyChart.DeleteAll()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.DeleteAll()`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.
