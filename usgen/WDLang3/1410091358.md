
## User management functions for the WEBDEV OAuth authentication server
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manage users on a WEBDEV OAuth authentication server:




|   |   |
| --- | --- |
| [wdbaasCreateUser](../WDLang3/1410091289.md) | Creates a new user in the OAuth authentication server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 4.** |
| [wdbaasDeleteUser](../WDLang3/1410091292.md) | Removes a user from the WEBDEV OAuth authentication server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 4.** |
| [wdbaasEditUser](../WDLang3/1410091291.md) | Updates a user in the WEBDEV OAuth authentication server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 4.** |
| [wdbaasListUser](../WDLang3/1410091288.md) | Returns the list of users of a WEBDEV OAuth authentication server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 4.** |
| [wdbaasUserInfo](../WDLang3/1410091290.md) | Gets user information from the WEBDEV OAuth server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 4.** |

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000153"></a>

To use user management functions on a WEBDEV OAuth server, you need to define permissions for the OAuth credentials. These permissions are defined in WEBDEV's BaaS administration site. 

For example, you can grant the following permissions:

- Create users only.

- Read user information only.

- All (read, create, modify, delete).

- etc. 




For more details, see [BaaS administration site](../WDLang3/1410086668.md).
