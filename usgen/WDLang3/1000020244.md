


## EmailAddress (Variable type)

***In french: AdresseEmail***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **EmailAddress** type is used to handle an email address as well as its type (home, office, etc.).

The characteristics of this email address can be defined and modified using various WLanguage properties. 

This type of variable is used by the [Contact](../WDLang3/1000020254.md) variables.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyContact is Contact

// Retrieves the first professional email address of a contact
sAddress is string
FOR EACH Email of MyContact.Email
	IF Email.Type = emailWork THEN
		sAddress = Email.Address
		RETURN
	END
END
```

```wl
// Displays the contacts and their different emails
garrContacts is array of Contact
gCurrentContact is Contact

garrContacts = ContactList(Null)
Info("Number of contacts: " + gtabContacts.Occurrence)

FOR EACH gCurrentContact OF garrContacts	
	Info(gCurrentContact.DisplayedName)
	FOR EACH Email of gCurrentContact.Email
		Info(Email.Address)	
	END
END
```

## Properties


### Properties specific to EmailAddress variables
<a name="properties_specific_emailaddress_variables_ELTPARAGRAPHE000041"></a>

The following properties can be used to handle an Email address:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Address | Character string | Email address. |
| Label | Character string | Label for the custom types of email addresses (optional).<br>If **Type** does not correspond to the *emailCustom* constant, the value of this property will be ignored. |
| Type | Integer constant | Type of email address: <br><br>- *emailOther* other types.<br><br>- *emailOffice* office email address.<br><br>- *emailDomicile* Home email address.<br><br>- *emailMobile* phone's email address.<br><br>- *emailCustom* custom type corresponding to the value of the property **Label**.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
