


## &lt;AuthToken&gt;.Revoke (Function)

***In french: &lt;AuthToken&gt;.Révoque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Revokes a JSON Web Token (JWT). 

Remarks: 

- Revocation consists of executing a request to invalidate the specified token.  To log in again, the user will have to go through the entire login process.

- When you use a variable of type [OAuth2Parameters](../WDLang3/1000022212.md), you need to specify the revocation URL with the **RevocationURL** property.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
stOpenIDParam is OpenIDParameters
stOpenIDParam.ConfigurationURL = "https://accounts.google.com/.well-known/openid-configuration"
stOpenIDParam.ClientID = "686331726510-0ojt7fqbkmtns8qjne242v5fuqb8v3tr.apps.googleusercontent.com"
stOpenIDParam.ClientSecret = "vEhFxP8I5AjppVFJsLYi0uKt"
stOpenIDParam.Scope = "email openid"
stOpenIDParam.RedirectionURL = "http://localhost:9874"
stToken is AuthToken = AuthIdentify(stOpenIDParam)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
	RETURN
END
Identity is OpenIDIdentity = stToken.OpenIDReadIdentity()
 IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
	RETURN
END
Trace(Identity.Email)
stToken.Revoke()
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection token>.Revoke()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the logout was performed,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Connection token>: (AuthToken variable)`**

Name of the [AuthToken](../WDLang3/1000022220.md) variable corresponding to the access token.
