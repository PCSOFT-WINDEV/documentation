| Constant | Details | Used by |
| --- | --- | --- |
| **zipAdministrator** | Forces the created executable file to run as administrator. This mode avoids file virtualization from Windows Vista. | [zipCreateExe](../WDLang3/3082013.md) |
| **zipAnsi** | Saves ANSI file names in the Archive file.<br><br>This constant is used by default in applications using the ANSI standard. | [zipCreate](../WDLang3/3082003.md) |
| **zipCancel** | Cancels the extraction of files from the archive. | [zipExtractFileList](../WDLang3/1000017234.md), [zipExtractAll](../WDLang3/3082011.md) |
| **zipCreateIfNotFound** | Creates the archive if it does not exist. | [zipOpen](../WDLang3/3082044.md) |
| **zipCurrentDirectory** | All files in the archive will be extracted to the current directory. | [zipCreateExe](../WDLang3/3082013.md), [zipExeCreationParameter](../WDLang3/1410091226.md) |
| **zipDefaultDir** | Uses the default directory. | [zipCreateExe](../WDLang3/3082013.md), [zipExeCreationParameter](../WDLang3/1410091226.md) |
| **zipDirectory** | Stores the different directories that are part of the path, as well as the file name and extension. For example: \\Directory\\Files\\FileName.pdf<br>Returns the different directories of the file (the file name and extension are not returned) | [zipAddFile](../WDLang3/3082008.md)<br>[zipAddDirectory](../WDLang3/3082014.md)<br>[zipExtractPath](../WDLang3/3082023.md)<br>[zipExtractFile](../WDLang3/3082019.md)<br>[zipExtractAll](../WDLang3/3082011.md) |
| **zipDrive** | Stores the full and absolute path of the file (disk, directories, file name and extension). For example: C:\\Directory\\Files\\FileName.pdf <br>This constant has no effect on the ZIP format.<br>Returns the unit name only. | [zipAddFile](../WDLang3/3082008.md)<br>[zipAddDirectory](../WDLang3/3082014.md)<br>[zipExtractPath](../WDLang3/3082023.md)<br>[zipExtractFile](../WDLang3/3082019.md)<br>[zipExtractAll](../WDLang3/3082011.md) |
| **zipExe64** | Creates a 64-bit self-extracting executable. | [zipCreateExe](../WDLang3/3082013.md) |
| **zipExtension** | Returns only the file extension (preceded by "."). | [zipExtractPath](../WDLang3/3082023.md) |
| **zipFilename** | Returns only the file name (without extension). | [zipExtractPath](../WDLang3/3082023.md) |
| **zipFormat7Z** | 7z archive file. | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatCAB** | CAB archive file. | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatNone** | No archive file is created. | [hBackupDescription](../WDLang4/1000017455.md) variable |
| **zipFormatRAR** | RAR archive file. | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatTAR** | TAR format (decompressed archive file). | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatTARGZ** | TARGZ archive file. | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatWDZ** | WDZ archive file. | [zipArchive](../WDLang3/1000018679.md) variable |
| **zipFormatZIP** | ZIP archive file. | [zipArchive](../WDLang3/1000018679.md) variable<br>[hBackupDescription](../WDLang4/1000017455.md) variable |
| **zipHeader64** | Allows you to create an archive larger than 4 GB on which [zipChangePath](../WDLang3/3082027.md) can be used. | [zipCreate](../WDLang3/3082003.md), <br>[zipOpen](../WDLang3/3082044.md), <br>[zipOpenCAB](../WDLang3/1000017250.md), <br>[zipOpenRAR](../WDLang3/1000017294.md) |
| **zipIgnore** | Ignores file extraction with errors. | [zipExtractFileList](../WDLang3/1000017234.md), [zipExtractAll](../WDLang3/3082011.md) |
| **zipInMemory** | Enables you to manipulate archives stored in memory (add files from a buffer or extract files to a buffer). | [zipAddFile](../WDLang3/3082008.md), [zipExtractFile](../WDLang3/3082019.md) |
| **zipNone** | Stores the file name and extension. For example: FileName.pdf<br>Files are extracted to the current directory without restoring the tree structure. | [zipAddFile](../WDLang3/3082008.md)<br>[zipExtractFile](../WDLang3/3082019.md) |
| **zipOverwrite** | During extraction, existing read-only files in the destination directory are automatically overwritten with the extracted files. | [zipExtractAll](../WDLang3/3082011.md) |
| **zipRead** | Opens an archive in read-only mode. | [zipOpen](../WDLang3/3082044.md) |
| **zipRelative** | The path passed as a parameter is considered the root of the archive. The stored path for all files and subdirectories is relative to this root. | [zipAddDirectory](../WDLang3/3082014.md) |
| **zipRetry** | Retries the file extraction. | [zipExtractFileList](../WDLang3/1000017234.md), [zipExtractAll](../WDLang3/3082011.md) |
| **zipSelectRestorePath** | The self-extractor shows the "Preserve tree structure" option in the dialog box. | [zipCreateExe](../WDLang3/3082013.md) |
| **zipTempDirectory** | The archive files will be extracted to the temporary directory of the computer where the executable file is run. All files are extracted to the same location. | [zipCreateExe](../WDLang3/3082013.md), [zipExeCreationParameter](../WDLang3/1410091226.md) |
| **zipTree** | The files will be extracted while preserving the archive's directory structure. | [zipCreateExe](../WDLang3/3082013.md) |
| **zipUncompressed** | The contents of the archive will not be compressed. | [zipCreate](../WDLang3/3082003.md) |
| **zipUnicode** | Saves Unicode file names in the Archive file.<br><br>This constant is used by default in an application using Unicode. | [zipCreate](../WDLang3/3082003.md) |
| **zipWithUI** | The self-extractor will display a dialog box allowing users to chose the destination directory.<br><br>Note: In previous versions, this constant corresponds to *zipWithGUI*. | [zipCreateExe](../WDLang3/3082013.md) |
| **zipWrite** | Opens an archive in read/write mode. | [zipOpen](../WDLang3/3082044.md) |
