


## ScanDocumentFromCamera (Function)

***In french: ScanDocumentDepuisCaméra***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a specific window for scanning one or more documents using the phone or tablet camera. Scanned documents can be edited. A "+" button allows users to scan multiple pages or documents. 

**Note**: This window is the same regardless of the version of the device. The device must support the scan functionality.This function is equivalent to [ScanFromCameraToImage](../WDLang3/1410090763.md).

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
INTERNAL PROCEDURE onScan(ScanStatus, docs is array of Image)
		SWITCH ScanStatus
			CASE sdcFailed
				ToastDisplay("Scan error: "+ ErrorInfo)
			CASE sdcCanceled
				ToastDisplay("Scan canceled by user")
			CASE sdcSuccess
				FOR EACH scanned_image OF docs
					ProcessImage(scanned_img)
				END
			END
		END

ScanDocumentFromCamera(onScan)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`ScanDocumentFromCamera(<WLanguage procedure> [, <Maximum number of pages>])`
---

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") executed when the scan is completed, when it fails, or when it is canceled by the user.
For more details on this procedure, see [Parameters of the procedure used by ScanDocumentFromCamera](../WDLang3/1410090546.md).

**`<Maximum number of pages>: (Optional integer)`**

Maximum number of pages that can be scanned. If this parameter is 0 or not specified, there is no limit.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This parameter is not allowed.

## Remarks


### Retrieving PDF documents
<a name="retrieving_pdf_documents_ELTPARAGRAPHE000194"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) For each page scanned, a JPEG image is saved in the application's internal cache directory.

- Scanned images are saved in an array of PDF documents, which can be accessed in the WLanguage procedure executed at the end of the scan.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000215"></a>

This function changes the permissions required by the application.

Required permission: WRITE_EXTERNAL_STORAGE

This permission allows the application to write to external storage.
