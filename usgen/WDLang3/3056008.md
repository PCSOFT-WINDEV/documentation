
## Net constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


| Constant | Description | Used by the functions |
| --- | --- | --- |
| **INTERNET** | Response waiting time (TimeOut) used for connection: Value adapted to Internet use (long response waiting time). | [NetConnect](../WDLang3/3056004.md) |
| **INTRANET** | Response waiting time (TimeOut) used for connection: Value adapted to Intranet use (low response waiting time). | [NetConnect](../WDLang3/3056004.md) |
| **IPv4** | Lists the IPv4 addresses of a computer. | [NetListIPAddress](../WDLang3/1000019683.md) |
| **IPv6** | Lists the IPv6 addresses of a computer. | [NetListIPAddress](../WDLang3/1000019683.md) |
| **netConfirm** | Type of dialog box to be displayed: Message box with "Yes", "No" and "Cancel" buttons. | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **netInfo** | Type of dialog box to be displayed: Information type message box ("OK" button only). | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **netOkCancel** | Type of dialog box to be displayed: Message box with "OK" and "Cancel" buttons. | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **netOptionSendBuffer** | Manages client rights on the server workstation: authorize or deny use of the [NetSendBuffer](../WDLang3/3056001.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionSendFile** | Manages client rights on the server workstation: authorize or deny use of the [NetSendFile](../WDLang3/3056005.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionSendMessage** | Manages client rights on the server workstation: authorize or deny use of the [NetSendMessage](../WDLang3/3056003.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionExecute** | Manages client rights on the server workstation: authorize or deny use of the [NetExecute](../WDLang3/3056002.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionDiskList** | Manages client rights on the server workstation: authorize or deny use of the [NetDiskList](../WDLang3/3056015.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionDirList** | Manages client rights on the server workstation: authorize or deny use of the [NetDirList](../WDLang3/3056016.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionRemoteMessageBox** | Manages client rights on the server workstation: authorize or deny use of the [NetRemoteMessageBox](../WDLang3/3056020.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionGetFile** | Manages client rights on the server workstation: authorize or deny use of the [NetGetFile](../WDLang3/3056025.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionRenameFile** | Manages client rights on the server workstation: authorize or deny use of the [NetRenameFile](../WDLang3/3056006.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netOptionEraseFile** | Manages client rights on the server workstation: authorize or deny use of the [NetEraseFile](../WDLang3/3056018.md) function. | [NetServerOption](../WDLang3/3056022.md) |
| **netYesNo** | Type of dialog box to be displayed: Message box with "Yes" and "No" buttons. | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **netRetryCancel** | Type of dialog box to be displayed: Message box with "Retry" and "Cancel" buttons. | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **netRetryIgnore** | Type of dialog box to be displayed: Message box with "Abort", "Retry" and "Ignore" buttons. | [NetClientMessageBox](../WDLang3/3056017.md),<br>[NetRemoteMessageBox](../WDLang3/3056020.md) |
| **niConnected** | Type of connection information required: shows whether the connection is active. | [NetInfoRemoteAccess](../WDLang3/3056028.md) |
| **niConnectionDuration** | Type of connection information required: time since connection was opened. | [NetInfoRemoteAccess](../WDLang3/3056028.md) |
| **niNbByteReceived** | Type of connection information required: number of bytes received since the connection was opened. | [NetInfoRemoteAccess](../WDLang3/3056028.md) |
| **niNbByteTransmitted** | Type of connection information required: number of bytes transmitted since the connection was opened. | [NetInfoRemoteAccess](../WDLang3/3056028.md) |
| **FTPServer** | Type of server used: WINDEV FTP server. | [NetConnect](../WDLang3/3056004.md)[NetStartServer](../WDLang3/3056013.md) |
| **RPCServer** | Type of server used: WINDEV RPC server. | [NetConnect](../WDLang3/3056004.md),<br>[NetStartServer](../WDLang3/3056013.md) |
