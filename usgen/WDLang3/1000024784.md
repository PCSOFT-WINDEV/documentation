


## WLanguage procedure called by BTLECharacteristicChangeOfValue



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [BTLECharacteristicChangeOfValue](../WDLang3/1000022071.md) when a characteristic changes on the device. This procedure can be a local, global or internal procedure. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
characteristic is btleCharacteristic
BTLECharacteristicChangeOfValue(characteristic, CB_ChangeValue)
// ===========================
PROCEDURE CB_ChangeValue (characteristic is btleCharacteristic <useful> , bufValue is Buffer)
// Get value and display it in a Static Text control
sBuf is ANSI string = bufValue
STC_SubscriptionValue = sBuf
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`BTLECharacteristicChangeOfValue_Callback(<Characteristic> , <Value>)`
---

**`<Characteristic>: (btleCharacteristic variable)`**

[btleCharacteristic](../WDLang3/1000022060.md) variable that corresponds to the Bluetooth device characteristic whose value has changed.

**`<Value>: (Buffer)`**

New value of the characteristic.
