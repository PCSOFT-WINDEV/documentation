


## grSeriesLineType (Function)

***In french: grTypeTraitSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the type of line for a series found in a Line, Area, Scatter and Radar chart.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines dotted lines for series 2
grSeriesLineType(CHART_MyChart, 2, LineDotted)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grSeriesLineType(<Chart name> , <Series number> , <Type>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control (present in the window or report editor).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series for which the type of line must be defined.

**`<Type>: (Integer constant)`**

Type of line for the series: 



|   |   |
| --- | --- |
| *LineDash* | Line with dashes (---). |
| *LineDotAndDash* | Line mixing dots and dashes (.-.-.-). |
| *LineDotted* | Dotted line (.......). |
| *LineNone* | No line is drawn. Only points in the series are drawn (defined with [grSeriesPointType](../WDLang3/1000022271.md)). <br><br> |
| *LineSolid* | Solid line. |
