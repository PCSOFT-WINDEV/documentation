


## DriveListFileGgl (Function)

***In french: DriveListeFichierGgl***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists Google Docs Editors files (Docs, Sheets, etc.) present on Google Drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

gglMyDrive is gglDrive
gglMyDrive = GglDriveConnect(oOAuth2Param) 

arrGglFile is array of GglFile
arrGglFile = DriveListFileGgl(gglMyDrive, "/", frRecursive)

FOR EACH File OF arrGglFile
	SWITCH File.MimeType
		CASE mimeTypeGglDocs: File.ExportMimeType = mimeTypeDOCX
		CASE mimeTypeGglSheets: File.ExportMimeType = mimeTypeXLSX
		OTHER CASE: File.ExportMimeType = mimeTypePDF
	END 
	let ResDownload = DriveDownloadGglFile(gglMyDrive, arrGglFile[1], "c:\MyDocuments")
	IF ErrorOccurred THEN
		// Error handling
		Trace ("An error has occurred")
		RETURN
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DriveListFileGgl(<Google Drive> , <Start directory> [, <Options>])`
---

**`<Result>: (Array of GglFile variables)`**

Array of [GglFile](../WDLang3/1410089586.md) variables corresponding to the files found.

**`<Google Drive>: (gglDrive variable)`**

Name of the [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the Google Drive service to be used. The connection to the drive must have been previously established. Otherwise, files will not be listed.  

**`<Start directory>: (Character string)`**

Drive directory from which files are to be listed. This directory must be an absolute path: 

- Directory names must be separated by '/' or '\\'. 

- Directory names must start with '/' or '\\'. 


If the path is invalid, an error will be generated.

**`<Options>: (Optional Integer constant (or combination of constants))`**

Type of iteration:



|   |   |
| --- | --- |
| *fdFullInformation* | Provides detailed information on the files hosted on the drive. <br><br>If this constant is specified, the **Size** and **DateLastModified** properties of the [GglFile](../WDLang3/1410089586.md) variable will be specified. <br><br>This constant must be used with the *frNotRecursive* or *frRecursive*constants. |
| *frNotRecursive* | The iteration is non-recursive. Subdirectories are ignored. |
| *frRecursive*<br>(Default value) | The iteration is recursive. Subdirectories are automatically taken into account. |

## Remarks


### &lt;Start directory&gt; parameter
<a name="parameter_ELTPARAGRAPHE000087"></a>

Examples of valid paths: 

```txt
"/holidays directory/2021/"
"\photos"
```


Examples of invalid paths:

```txt
"directoryA/DirectoryB"
"This/Path/Is/invalid"
"c:\Users\"
```
