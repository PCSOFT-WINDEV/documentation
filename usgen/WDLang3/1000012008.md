
## TaskDelete (Function)

***In french: TâcheSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the current task from the task list of a Lotus Notes or Outlook messaging.

**Attention** This function **does not** delete the current task from the task list of an Outlook Express mailbox.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf",...
					"C:\Users\Julia\AppData\Local\Lotus\Notes\Data\user.id")
// Read the first task
TaskFirst(SessionID)
// Delete this task
TaskDelete(SessionID)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TaskDelete(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant. 




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).
