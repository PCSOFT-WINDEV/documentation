
## QuickActionList (Function)

***In french: ActionRapideListe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists the application's quick actions.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrAction is array of QuickAction = QuickActionList()
FOR EACH action OF arrAction
	IF action.Identifier = "ACTION_ID_SEND_MESSAGE" THEN
		QuickActionPin(action)
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = QuickActionList()`
---

**`<Result>: (Array)`**

Array of [QuickAction](../WDLang3/1410090054.md) variables describing the application's quick actions.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The **Icon** property of the [QuickAction](../WDLang3/1410090054.md) variable cannot be read.
