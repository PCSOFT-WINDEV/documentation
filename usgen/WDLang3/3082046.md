


## zipMerge (Function)

***In french: zipRegroupe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Merges the different sub-archives found in a multi-part archive to create a single-part archive.

## Syntax

`<Result> = zipMerge(<Archive> , <Archive destination> [, <Progress bar management>])`
---

**`<Result>: (Integer)`**



- 0 if the sub-archives have been merged,

- an error code (value greater than 0) otherwise. For more details on these error codes, see the [Remarks](#NOTE0_1).




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- the name of an archive, defined by [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) the name of a variable of type [zipArchive](../WDLang3/1000018679.md).




**`<Archive destination>: (Character string)`**

Physical path of new single-part archive (up to 260 characters). This path must contain the name of single-part archive to create. If the extension (.WDZ or .ZIP) is not specified, the extension corresponds to the initial extension. It is possible to specify the same path and name as the cut archive: the cut archive will be overwritten by the grouped archive.

**`<Progress bar management>: (Optional character string)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Name of the Progress Bar control in a window. The progress bar will display the progress of the grouping.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000128"></a>

**Note**: Grouping can only be carried out if:

- The archive exists (archives are created using [zipCreate](../WDLang3/3082003.md)).

- The archive is a multi-part archive.

- The archive is not in "CAB" format, "RAR" format or in "gzip", "TAR" or TARGZ" format.




Reminder: 

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Only archives in ZIP, gzip, TAR and TGZ (TAR.GZ) formats are available.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only ZIP archives are available.



<a name="NOTE0_2"></a>


### Error codes
<a name="error_codes_ELTPARAGRAPHE000153"></a>

The following error codes are returned:

- 1: Path passed as parameter does not exist.

- 2: Access denied: user does not have sufficient rights.

- 3: The archive is corrupt.

- 6: Sub-archives are not in order.




The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).
<a name="NOTE0_3"></a>


### Closing the archive
<a name="closing_the_archive_ELTPARAGRAPHE000172"></a>

Once **zipMerge** has been used on an archive, this archive is not closed. You must use:

- [zipClose](../WDLang3/3082005.md) to close the multi-part archive.

- [zipOpen](../WDLang3/3082044.md) to open the new single-part archive.



<a name="NOTE0_4"></a>


### Number of parts
<a name="number_parts_ELTPARAGRAPHE000190"></a>

[zipNbPart](../WDLang3/3082029.md) is used to determine the number of sub-archives in a multi-part archive.
<a name="NOTE0_5"></a>


### Actions that can be performed on a multi-part archive
<a name="actions_that_can_performed_multipart_archive_ELTPARAGRAPHE000201"></a>

Some archiving functions can only be used with single-part archives (add and delete files, create a self-extracting executable, etc.). To perform these operations, simply merge the sub-archives (**zipMerge**) to get a single-part archive.

From a multi-part archive, you can only:

- Merge the different parts (**zipMerge**).

- Get information about the archive and the files in the archive ([zipExtractPath](../WDLang3/3082023.md), [zipInfoFile](../WDLang3/3082040.md), [zipListFile](../WDLang3/3082031.md), etc.).

- Extract the files ([zipExtractFile](../WDLang3/3082019.md), [zipExtractAll](../WDLang3/3082011.md)).

### The multi-part archive is found on diskettes
<a name="the_multipart_archive_found_diskettes_ELTPARAGRAPHE000237"></a>

If the different sub-archives are found on diskettes, the next diskette will be automatically requested via a dialog box when the sub-archives are merged. An error will occur if the merge operation is canceled by the user (the multi-part archive is not found).
