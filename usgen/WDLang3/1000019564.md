


## EmailRunApp (Function)

***In french: EmailLanceAppli***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts the native email application on the current computer: 

- Computer running Windows (using the MAPI client), 

- Mobile device: Android, iPhone, iPad.




The content and recipients of the email message are initialized from the information specified in the WLanguage [Email](../WDLang3/3032029.md) structure.

**Caution**: 

- The email application found on the current computer must have been configured with a valid account for sending emails (SMTP).

- The current directory can be modified according to the configuration of the email application. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Remarks: 

- This function is based on the MAPI client installed on the computer ("Simple MAPI" is not sufficient). If the MAPI client is not found, the function searches for the default client, including Microsoft Outlook, Outlook Express, Eudora, IncrediMail, Netscape, Mozilla Thunderbird, Mozilla.

- Both the application and the MAPI client must be in 32 or in 64-bit. If the client is a 64-bit application, it will only be seen by applications compiled in 64-bit. The same applies to 32-bit applications.. 
	The [EmailAppGetArchitecture](../WDLang3/1410090512.md) function gets the execution mode of the default email client. Depending on the MAPI client's architecture, you can also launch a 32 or 64-bit application to run the client.

## Example


```wl
// Send a message with an attachment 
Email.Recipient[1] = "recipient@email.com"
Email.NbRecipient = 1
Email.Subject = "Message subject"
Email.Message = "Message text"
// Photo.jpg is a file created by the application
Email.Attach[1] = SysDirExternalStorage(1, ssePublicDocument) + [fSep] + "photo.jpg"
Email.NbAttach = 1
EmailRunApp()
```
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
nArchitecture is int = EmailAppGetArchitecture()
IF ErrorOccurred THEN
	Error("Unable to determine default email client architecture.")
	RETURN
END
<COMPILE IF Configuration32>
	IF nArchitecture = arch32 THEN
		EmailRunApp()
	ELSE
		// Launch a WINDEV 64-bit executable to run the email client
		ExeRun(fExeDir() + [fSep()] + "LaunchEmailClient_64.exe")
	END
	RETURN
<END>
<COMPILE SI Configuration64>
	IF nArchitecture = arch64 THEN
		EmailRunApp()
	ELSE
		// Launch a WINDEV 64-bit executable to run the email client
		ExeRun(fExeDir() + [fSep()] + "LaunchEmailClient_64.exe")
	END
	RETURN
<END>
Error("Unable to determine application architecture")
```

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000087"></a>

- A non-fatal error is triggered if no email application is found on the current computer. To find out whether the email application failed to start, use the [ErrorOccurred](../WDLang1/3087001.md) variable.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **EmailRunApp** can be used in the emulator. It cannot be used in the simulator.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The default email application included in earlier versions of Android (&lt;= 1.6) does not allow messages to be initialized with more than one attachment. In this case, only the first attachment described in Email.Attach will be associated with the message.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) In Android, if the message to be sent includes attachments, these must be located on shared memory (e.g., the SDCard) in order to be accessible to the mail client. 

- To reinitialize the Email structure, use [EmailReset](../WDLang3/3032023.md). 

- **EmailRunApp** is a non-blocking function. The code that follows the call to this function will continue to run as soon as the email application is launched. 

- There is no way to find out whether the sending of the email was validated by the user.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000288"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**EmailRunApp** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
