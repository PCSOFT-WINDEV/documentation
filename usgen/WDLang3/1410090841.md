
## AuthIntrospectToken (Function)

***In french: AuthIntrospecteToken***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines the set of metadata for an OAuth token. Introspection enables any client application to check the current status of an access token. This makes it possible to check the validity of the token and to identify the scopes associated with it.

Note: In web services, this function is particularly useful to check the validity of an access token. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
g_openid_param is OpenIDParameters
g_openid_param.ConfigurationURL = "http://webapp/.well-known/openid-configuration"
g_openid_param.ClientID = "e2776f74-7a74-4ecf-9f0b-09aa9ebc8ab4"
g_openid_param.ClientSecret = "11492281-3238-4503-9312-6c9c03c7051b"
g_openid_param.Scope = "email profile"
g_openid_param.GrantType = gtAuthorizationCode

g_token is AuthToken = AuthIdentify(g_openid_param)
IF NOT g_token.Valid THEN
	IF ErrorOccurred THEN
		Info(ErrorInfo(errFullDetails))
	ELSE
		Info("Invalid token")
	END
	RETURN
END

identity is OpenIDIdentity = OpenIDReadIdentity(g_token)
IF NOT identity.Valid THEN
	IF ErrorOccurred THEN
		Info(ErrorInfo(errFullDetails))
	ELSE
		Info("Invalid identity")
	END
	RETURN
END
Trace("Email = " + identity.Email)

token is JSON = g_token.ServerResponse
access_token is JSON = token.access_token
res is JSON = AuthIntrospectToken(access_token, oauth2AccessToken, "http://webapp/oauth2/v1/introspect")
Trace(res)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = AuthIntrospectToken(<Token> , <Type of the token> , <Introspection URL>)`
---

**`<Result>: (JSON string or variable)`**

JSON string containing the metadata of the token. 

**`<Token>: (String or variable of type AuthToken)`**

Token to be introspected. This token can be: 

- a character string,

- a variable of type [AuthToken](../WDLang3/1000022220.md). 




**`<Type of the token>: (Integer constant)`**

Type of token to be introspected: 


|   |   |
| --- | --- |
| *oauth2AccessToken* | Access token. |
| *oauth2IdToken* | ID token. |



**`<Introspection URL>: (Character string)`**

Token introspection URL.
