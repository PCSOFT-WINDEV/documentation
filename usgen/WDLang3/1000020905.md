


## upnpImage (Variable type)

***In french: upnpImage***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **upnpImage** type is used to define the advanced characteristics of an image of UPnP device. You can define and change the characteristics of this UPnP image using different WLanguage properties. 

This type of variable is used by [upnpDevice](../WDLang3/1000020903.md) variables. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="PROPS"></a>

## Properties


### Properties specific to upnpImage variables
<a name="properties_specific_upnpimage_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to handle an image of a UPnP device:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| BitPerPixel | Integer | Number of bits per pixel. |
| Height | Integer | Image height in pixels. |
| Image | [Image](../WDLang1/1000019650.md) variable | Image |
| MIMEType | Character string | MIME type of image. |
| URL | Character string | Image URL. |
| Width | Integer | Image width in pixels. |
