


## JWTCreateAssertion (Function)

***In french: JWTCréeAssertion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a JWT assertion. This assertion has a specific structure. 

An assertion is a JSON Web Token (JWT) that consists of three parts separated by points (.).

1. Header:
	The header contains metadata such as the type of token (JWT) and the signature algorithm used (e.g., HS256 or RS256).
	JSON example:
	
	```txt
	{
	  "alg": "HS256",
	  "typ": "JWT"
	}
	```


2. Payload:
	This part contains the claims, i.e. the information to be sent. It can be:

	- Standard claims (e.g., "iss" for issuer, "exp" for expiry date).

	- Custom claims, depending on your needs.


JSON example:
	
	```txt
	{
	  "sub": "1234567890",
	  "name": "John Doe",
	  "admin": true,
	  "iat": 1516239022
	}
	```


3. Signature:
	The signature guarantees the integrity of the token. It is calculated from the header and payload using a secret key (for HMAC) or a private/public key pair (for RSA or ECDSA).

## Syntax
<a name="SYNTAXE1"></a>

### Creating a JWT assertion signed with a private key

`<Result> = JWTCreateAssertion(<JWT header> , <JWT payload> , <Private key>)`
---

**`<Result>: (Character string)`**

JWT assertion to be used for authentication.  

**`<JWT header>: (Character string)`**

JWT assertion header in JSON format. 

**`<JWT payload>: (Character string)`**

JWT payload to be used for the assertion. 

**`<Private key>: (Character string)`**

Private key to be used to sign the JWT. 


<a name="SYNTAXE2"></a>

### Creating a JWT assertion signed with a certificate

`<Result> = JWTCreateAssertion(<JWT header> , <JWT payload> , <Certificate>)`
---

**`<Result>: (Character string)`**

JWT assertion to be used for authentication. 

**`<JWT header>: (Character string)`**

JWT assertion header in JSON format. 

**`<JWT payload>: (Character string)`**

JWT payload to be used for the assertion. 

**`<Certificate>: (Certificate variable)`**

Name of the [Certificate](../WDLang1/1000019287.md) variable to be used to sign the JWT. This certificate mainly used for RS256 encryption.

## Remarks


### How to use a JWT assertion
<a name="how_use_jwt_assertion_ELTPARAGRAPHE000080"></a>

In OAuth 2.0, assertions are an efficient and secure method of client authentication. Compared to the usual customer ID and secret, assertion uses JSON Web Tokens (JWTs) for better security and flexibility, making the authentication process clearer and more reliable.

If the JWT has a standard structure, the information present in its different parts may depend on the information expected by the authentication server. 

To use the new JWT assertion, the following elements must be specified in the [OAuth2Parameters](../WDLang3/1000022212.md) variable:

- the **GrantType** property must be set to *gtCustomGrantType*. 

- the **AdditionalParameters** property must contain the code to include the JWT assertion in the authentication process. 




Note: Depending on the information expected by the authentication server, the **ClientSercret** and **ClientID** properties of the [OAuth2Parameters](../WDLang3/1000022212.md) variable must be specified, even when using a JWT assertion.
