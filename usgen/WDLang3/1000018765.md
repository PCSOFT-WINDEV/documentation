


## emailSMTPSession (Variable type)

***In french: emailSessionSMTP***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **emailSMTPSession** type is used to access a messaging server by using the SMTP protocol (Simple Mail Transfer Protocol) in order to send emails. You can define and change the characteristics of the connection using different WLanguage properties.

**Remarks**:

- For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

- In most cases, the SMTP server to use is the SMTP server of Internet provider (and not the one of email account). For example, if you have Internet access via Orange and a Free email account, you must use the SMTP server of Orange (and not the one of Free). To use a different SMTP server, you must use an authenticated SMTP server, that requires a secure connection in most cases.

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Connection with authentication 
// SMTP session with TLS
MySMTPSession is emailSMTPSession
OAuthGoogleCnt is OAuth2Parameters

// OAuth connection parameters
OAuthGoogleCnt.ClientID = "Application ID"
OAuthGoogleCnt.ClientSecret = "Secret application ID"
OAuthGoogleCnt.AuthURL = "https://accounts.google.com/o/oauth2/auth"
OAuthGoogleCnt.TokenURL = "https://accounts.google.com/o/oauth2/token"
OAuthGoogleCnt.Scope = "https://mail.google.com/"
OAuthGoogleCnt.RedirectionURL = "http://localhost:9000"
OAuthGoogleCnt.ResponseType = oauth2ResponseTypeCode

// OAuth authentication
MySMTPSession.ServerAddress = "smtp.gmail.com"
MySMTPSession.Name = "user@gmail.com"
MySMTPSession.Password = "secret"
MySMTPSession.Port = 587
MySMTPSession.Option = emailProtocolSMTPS
MySMTPSession.AuthToken = AuthIdentify(OAuthGoogleCnt)

// If the authentication was successful, log in to email inbox
IF MySMTPSession.AuthToken <> Null THEN
	IF EmailStartSession(MySMTPSession) = False THEN
		// Error while starting the session
		Error("Unable to start the SMTP session.", ErrorInfo(), ...
			"In case of timeout, check the parameters of the " + ...
			"""Firewall"" on port (" + MySMTPSession.Port + ")")
		RETURN
	END
	// Send a message
	MyEmail is Email
	...
	EmailSendMessage(MySMTPSession, MyEmail)
	...
	EmailCloseSession(MySMTPSession)
ELSE
	// Authentication error
END
```

## Properties


### Properties specific to emailSMTPSession variables
<a name="properties_specific_emailsmtpsession_variables_ELTPARAGRAPHE000049"></a>

The following properties can be used to define the characteristics of **emailSMTPSession** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Asynchronous | Boolean or Integer constant | <br><br>- *emailAsynchronous* (or <u><u><u>True</u></u></u>) if the emails sent during the session started by [EmailStartSMTPSession](../WDLang3/3032025.md) must be transmitted in asynchronous mode.<br><br>- *emailSynchronous* (or <u><u><u>False</u></u></u>) otherwise (default value).<br><br><br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This property is not available: sending is always synchronous. |
| AuthToken | [AuthToken](../WDLang3/1000022220.md) variable | Email server access token to be used when if the OAuth 2.0 protocol is used (two-factor authentication). This access token is retrieved by [AuthIdentify](../WDLang3/1000022219.md).<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This property is not available.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This property is now available. |
| IgnoreError | Integer constant | Specifies the ignored errors. Corresponds to a constant or to a combination of constants:<br><br>- *emailSessionIgnoreCertificateInvalid* Certificate is ignored.<br><br>- *emailSessionIgnoreNameCertificateInvalid* The site name in the certificate is ignored.<br><br>- *emailSessionIgnoreCertificateExpired* Certificate date is ignored. <br><br>- *emailSessionIgnoreRevocation* The check in the list of revoked certificates is ignored.<br><br><br><br><br>**Warning** This property can only be used if the email function uses the cross-platform implementation (set with the [EmailConfigure](../WDLang3/1000022269.md) function). To use this implementation, use the following line of code: <br><br><pre><code>EmailConfigure(emailParameterMode, 1)</code></pre><br> |
| Name | Character string | Username to be used for authenticated SMTP sessions. |
| Option | Integer constant | Options of SMTP connection. The possible values are:<br><br>- *emailOptionDefault* (default value): <br>	Start a non-secure SMTP session. In this case, the standard port is 25.<br><br>- *emailProtocolSMTPS*: <br>	Start an SMTP session secured by the TLS protocol. In this mode:<br><br>	- the initial connection is established without encryption, then a **STARTTLS** command is sent to start encryption,<br><br>	- the standard port is 587.<br><br><br><br><br>- *optionTLS*: <br>	Start an SMTP session secured by the TLS protocol. In this case, the standard port is 465.<br><br><br> |
| Password | Character string or Secret string | User password. This password is given by the service provider or by the network administrator. This password is used to start an authenticated SMTP session.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications. |
| Port | Integer | Identifies the port used for SMTP (25 by default). |
| ServerAddress | Character string | DNS name or IP address of email server (outgoing protocol). This address is supplied by the service provider or by the network administrator.<br><br>**Warning** You must use the SMTP server of your Internet connection provider. This SMTP server may have no link with the SMTP server associated with the email account. |


**Remark**: **Modification of constant names (version 28 Update 4)**: 
In version 28 Update 4, theses constants were renamed for better code readability. Constant names correspond as follows: 

- *emailOptionSecuredTLS* is now *emailProtocolSMTPS*. 

- *optionSSL* is now *optionTLS*. 


The old constant names:

- are no longer recognized by syntax highlighting,

- no longer appear in the code completion suggestions,

- can still be used without causing a compilation error or unexpected behavior at runtime.
