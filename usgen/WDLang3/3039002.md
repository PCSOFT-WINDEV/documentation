


## StreamStop (Function)

***In french: FluxStop***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops receiving or broadcasting a type of data in a stream. The emission or the reception of the data type can be resumed via [StreamPlay](../WDLang3/3039010.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stops receiving sound in the stream
StreamStop(STREAM_MyStream.Value, StreamIncomingSound)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`StreamStop(<Stream identifier> [, <Type of stream>])`
---

**`<Stream identifier>: (Integer)`**

Identifier of the stream to use. This identifier is defined in the "Connection request of new stream" event associated with the stream. It can also be identified with the [Value](../Proprietes/2510130.md) property on the stream.

**`<Type of stream>: (Optional Integer constant (or combination of constants))`**

Type of stream to stop:

- Simple constants
	


|   |   |
| --- | --- |
| *StreamIncomingSound* | Incoming sound stream. |
| *StreamIncomingVideo* | Incoming video stream. |
| *StreamOutgoingSound* | Outgoing sound stream. |
| *StreamOutgoingVideo* | Outgoing video stream. |



- Constants corresponding to a combination of constants
	


|   |   |
| --- | --- |
| *StreamAll*<br>(default value) | Video + sound stream (*StreamFullDuplexSound*+ *StreamFullDuplexVideo*). |
| *StreamFullDuplexSound* | Incoming and outgoing sound stream (corresponds to *StreamIncomingSound* + *StreamOutgoingSound*). |
| *StreamFullDuplexVideo* | Incoming and outgoing video stream (corresponds to *StreamOutgoingVideo* + *StreamIncomingVideo*). |

## Remarks


### Procedure for stream detection
<a name="procedure_for_stream_detection_ELTPARAGRAPHE000077"></a>

A stream is associated with the "Connection request of new stream" event. This event is executed when a request to connect to an incoming stream is detected.

This event is run in one of the following cases: 

- if the [Detection](../Proprietes/2510031.md) property applied to the stream is set to <u><u><u><u>True</u></u></u></u>.

- if the option "Detection of active incoming streams" has been checked in the stream description window.




**Note** This event is executed in a specific WLanguage Thread. Therefore, it is subject to limitations specific to the threads. For more details on threads, see [Managing threads with WINDEV](../WDLang1/3077026.md).
