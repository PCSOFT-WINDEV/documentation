


## grInfoXY (Function)

***In french: grInfoXY***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the series found at a specific chart point. This information is identical to the one displayed in the tooltip.

**Note**: This function is not available for 3D or surface charts.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md).

## Syntax

`<Result> = grInfoXY(<Chart name> , <Type of information> [, <X> , <Y>])`
---

**`<Result>: (Integer or real)`**



- Requested information.

- If no chart element is found under the mouse,

	- -1 (*grSeries* and *grCategory* constants)

	- 0 (*grValueXXXX* constant).







**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control (in the window or page editor).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Only interactive Chart controls are available ("Interactive chart" option in the "Details" tab of the control description window).

**`<Type of information>: (Constant)`**

Type of information requested:


|   |   |
| --- | --- |
| *grCategory* | Number of pointed category. |
| *grTheoreticalCategory* | Number of the category that corresponds to a pointed X-coordinate (regardless of the series) and even if the cursor is not on the chart drawing. <br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *grPath* | Path of section in the Sunburst chart. <br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *grXCoord* | X-coordinate of chart point.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *grYCoord* | Y-coordinate of chart point. <br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *grSecondaryYCoord* | Y-coordinate according to the secondary axis of chart point. <br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *grSeries* | Series number.<br>**Note** For Stock charts and Scatter charts, there is only one series out of 4 or 2. |
| *grValue* | Value of series. |
| *grStartValue* | Start value of the series for a Stock chart.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |

| *grXValue* | X value of series for a Scatter chart.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |

**`<X>: (Optional integer)`**

X-coordinate (in pixels) to be analyzed. This coordinate is expressed in relation to the control. 
If this parameter is not specified, the position used in the last call to **grInfoXY** is taken into account.

**`<Y>: (Optional integer)`**

Y-coordinate (in pixels) to be analyzed. This coordinate is expressed in relation to the control. 
If this parameter is not specified, the position used in the last call to **grInfoXY** is taken into account.

## Remarks


### X and Y positions
<a name="and_positions_ELTPARAGRAPHE000268"></a>

The &lt;X&gt; and &lt;Y&gt; parameters must be specified at least once.

A WLanguage error occurs if the chart has changed between 2 calls to **grInfoXY** and if the X and Y positions are not specified.
<a name="NOTE0_2"></a>


### Column chart
<a name="column_chart_ELTPARAGRAPHE000281"></a>

When clicking a bar of the column chart, the area taken into account will be a little bit larger (at the top and at the bottom).
