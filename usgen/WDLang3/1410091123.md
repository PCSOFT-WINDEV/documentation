


## &lt;ftpConnection variable&gt;.Send (Function)

***In french: &lt;Variable ftpConnexion&gt;.Envoie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Transfers a file or directory to an FTP server (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Transfer the "C:\MyDocuments\File.DOC" file
// into the "/Temp" directory on the FTP server
ResSend = MyFTPConnection.Send("C:\MyDocuments\File.DOC", "/Temp")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <FTP connection>.Sends(<File/Directory to transfer> , <Destination file/directory> [, <WLanguage procedure> [, <Transfer mode>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the transfer has been completed,

- <u><u><u><u>False</u></u></u></u> otherwise. Use [ErrorInfo](../WDLang1/3013008.md) to get the details of the error.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.

**`<File/Directory to transfer>: (Character string)`**

Name and full or relative path of the file or directory to be transferred. A UNC path can be used. Wildcard characters cannot be used (\* or?).
***If this parameter corresponds to a directory***, all files in the directory are transferred. A directory with the same name is created on the FTP server at the location specified by &lt;Destination file/directory&gt;.
***If this parameter corresponds to a file***:

- If &lt;Destination file/directory&gt; is an existing directory on the FTP server, the file to be transferred is copied to the destination directory.

- If &lt;Destination file/directory&gt; is an existing file on the FTP server, the file to be transferred is copied and renamed.




**`<Destination file/directory>: (Character string)`**

Name and full or relative path of the destination file or directory. This file or directory is located on the FTP server. The different parts of the path are separated by "slashes" ("/").

- A full path has the following format: "/&lt;DirectoryName&gt;/&lt;FileName&gt;". The tree structure has the following format: "/&lt;DirectoryName&gt;/&lt;FileName&gt;".

- A relative path has the following format: "&lt;DirectoryName&gt;/&lt;FileName&gt;". The tree structure has the following format: "/&lt;CurrentServerDirectory&gt;/&lt;DirectoryName&gt;/&lt;FileName&gt;".




**`<WLanguage procedure>: (Procedure name)`**

Name of the procedure automatically called to check the transfer progress.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

**`<Transfer mode>: (Optional Integer constant)`**

Transfer mode used:					


|   |   |
| --- | --- |
| *ftpASCIIMode* | Transfer in ASCII mode. This mode is used to transfer files between different operating systems, e.g. UNIX to Windows. The file is delivered in the ASCII format used by the receiving system. |
| *ftpBinaryMode*<br>(Default value) | Transfer in binary mode. In this mode, the file received is strictly identical to the file sent. |

### Managing the progress of the transfer
<a name="managing_the_progress_the_transfer_ELTPARAGRAPHE000319"></a>

**&lt;ftpConnection variable&gt;.Send** is a blocking function. No other action can be performed until the current transfer has been completed. To check the transfer progress, **&lt;ftpConnection variable&gt;.Send** can automatically call the &lt;Procedure name&gt; procedure at regular intervals.

This procedure is declared as follows:


```txt
PROCEDURE <Procedure name>(<Total size>, <Transferred size>)
```


- &lt;Total size&gt; is an integer representing the total size of the file or directory being transferred.

- &lt;Transferred size&gt; is an integer representing the number of bytes already transferred.




For example, you can:

- display a progress bar,

- determine if the transfer is completed (&lt;Total size&gt; = &lt;Transferred size&gt;).




**&lt;ftpConnection variable&gt;.Send** cannot be interrupted until all files have been transferred. To stop the function, use the following line of code in &lt;Procedure name&gt;:


```wl
RETURN False
```
In any other case (to continue), &lt;Procedure name&gt; MUST return <u><u><u><u>True</u></u></u></u>.

An error is generated if no value (neither <u><u><u><u>True</u></u></u></u> nor <u><u><u><u>False</u></u></u></u>) is returned by &lt;Procedure name&gt;.
<a name="NOTE0_2"></a>


### Timeout
<a name="timeout_ELTPARAGRAPHE000368"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_4"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000401"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_5"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000413"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	ex: /pub/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [&lt;ftpConnection variable&gt;.CurrentDir](../WDLang3/1410091131.md).




When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.
