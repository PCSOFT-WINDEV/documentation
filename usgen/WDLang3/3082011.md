


## zipExtractAll (Function)

***In french: zipExtraitTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extracts all files from an archive and decompresses them.

The archive handled can be in CAB, RAR, ZIP, WDZ, 7z, gzip, TAR or TGZ (TAR.GZ) format.

## Syntax

`<Result> = zipExtractAll(<Archive> [, <Destination of the extracted files> [, <Options>] [, <WLanguage procedure>] , [ <Progress bar management>]])`
---

**`<Result>: (Integer)`**



- 0 if the files have been extracted,

- An error code (value greater than 0) otherwise. For more details on these error codes, see the [Remarks](#NOTE0_1).




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- an archive name defined with [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [zipArchive](../WDLang3/1000018679.md) variables are not available in Java.




**`<Destination of extracted files>: (Optional character string or constant)`**

**Destination path of extracted files**:

- Optional character string: files are extracted to the specified path plus the memorized tree structure for each file (the disk is not preserved). The specified path is created if it does not exist.

- Optional constant:
	


|   |   |
| --- | --- |
| *zipDirectory* | Extraction into the current directory while restoring the tree structure of file (if it was stored). |
| *zipDrive* | Extraction:<br><br>	- to the initial file location if it was stored and if the drive exists.<br><br>	- while restoring the tree structure of the file on the current drive if the drive or the stored directory does not exist.<br><br>	- into the current directory if only the file name and extension have been stored.<br><br><br>**Remark**: If the constant *zipDisk* is used, the WDZ format memorizes the complete path of the file (including the drive letter), whereas the ZIP format memorizes only the drive letter..<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. The directories have no root.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant and *zipDirectory* will have the same effect<br><br>**Archives in format 7z**: This constant will have the same effect as the *constant zipDirectory*. |
| *zipOverwrite* | During the extraction, the existing read-only files are automatically overwritten by the extracted files. This constant can be combined with the *zipDrive* and *zipDirectory* constants.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |






**`<Options>: (Optional constant)`**

Configure the extraction (if &lt;Destination of files&gt; corresponds to a character string):



|   |   |
| --- | --- |
| *zipOverwrite* | During the extraction, the existing read-only files are automatically overwritten by the extracted files.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |



**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure that will be called if an error occurs when extracting files. 
**WARNING**: This parameter can only be used if the &lt;Archive&gt; parameter corresponds to a variable of type [zipArchive](../WDLang3/1000018679.md).

This procedure has the following format: 


```txt
PROCEDURE <Procedure name>(<Error code>, <File name>)
```


where: 

- &lt;Error code&gt; is an integer corresponding to the code of the error that occurred when extracting the file.

- &lt;File name&gt; is a character string that contains the path of the file processed by **zipExtractAll**.




The procedure can return one of the following constants: 


|   |   |
| --- | --- |
| *zipCancel* | Cancels the extraction of files from the archive.  |
| *zipIgnore* | Ignores the file in error. |
| *zipRetry* | Retries the file extraction. |


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This procedure must be a server procedure.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not allowed.

**`<Progress>: (Control name or procedure name)`**

Progress bar management mode. This parameter can correspond to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the name of a Progress Bar control found in a window. The progress bar will display the progress regarding the extraction of all the files used.  

- the name of a WLanguage procedure. This procedure has the following format: 
	
	```txt
	PROCEDURE <Procedure name> (<Current file>, 
	<Global progress percentage>, <File progress percentage>)
	```

	where: 

	- &lt;Current file&gt; corresponds to the name of the file currently processed. 

	- &lt;Global progress percentage&gt; corresponds to the progress percentage of the extraction of files from the archive. 

	- &lt;File progress percentage&gt; corresponds to the progress percentage of the file being extracted from the archive.







**If you are using an archive**: 

- **in gzip, TAR or TGZ (TAR.GZ) format**ProgressBar is updated only when each file has been extracted. 

- **in CAB and RAR format**, the progress bar is refreshed at the end of the extraction of each file. 

- **in 7z format**, only &lt;Overall progress percentage&gt; is specified. &lt;File progress percentage&gt; will have the same value.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The procedure must be a server procedure.

## Remarks


### Error codes
<a name="error_codes_ELTPARAGRAPHE000266"></a>

The following error codes are returned:

- 1: The path passed as parameter does not exist.

- 2: Access denied: The user does not have sufficient rights.

- 3: The archive is corrupted.

- 4: The path does not exist in the archive.

- 6: Sub-archive files are not in order (case of extraction from a multi-part archive).




The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).

Reminder: 

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Only ZIP, TAR, gzip and TGZ (TAR.GZ) archives are available.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only ZIP archives are available.

- RAR is supported up to and including version 5.



<a name="NOTE0_2"></a>


### Extracted file
<a name="extracted_file_ELTPARAGRAPHE000303"></a>

The extracted files are not deleted from the archive. To delete one file or all the files from the archive, use [zipDeleteFile](../WDLang3/3082041.md) or [zipDeleteAll](../WDLang3/3082051.md).
