


## ContactAdd (Function)

***In french: ContactAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a contact: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png) in a Lotus Notes or Outlook address book. 
	**Attention** This function **does not** add a Contact to an Outlook Express address book.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) from the list of contacts on the device (Android, iPhone or iPad).

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000020272&name=contactadd_function">See additional examples</a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Initialize the variables of Contact structure
ContactReset()
// Fill the variables for the new contact
mContact.Name = "Smith"
mContact.FirstName = "Adriana"
mContact.Email = "adriana.smith@mycompany.com"
// Add the contact
IF ContactAdd(SessionID) = True THEN
	Info("Contact added")
ELSE
	Error("Error during the addition", ErrorInfo())
END
```
<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Local variables
tContact is Contact
tPhone is Phone

// Identity
tContact.Name = EDT_LastName
tContact.FirstName = EDT_FirstName

// Home phone numbers
IF EDT_HomePhone <> "" THEN
	tPhone.PhoneNumber = EDT_HomePhone
	tPhone.Type = phoneHome
	Add(tContact.Phone, tPhone)
END

// Add
IF NOT ContactAdd(tContact, gSource) THEN
	Error("Unable to create the contact.")
ELSE
	WIN_TableContacts.RefreshContactList()
	Close()
END
```

### Adding a contact into the Lotus Notes or Outlook messaging

`<Result> = ContactAdd(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Integer)`**

Session ID to be used. This identifier is returned by [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).

### Adding a contact to the device's contact list

`<Result> = ContactAdd(<Contact> [, <Source>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable corresponding to the contact to add. 

**`<Source>: (Optional ContactSource variable)`**

Name of the [ContactSource](../WDLang3/1000020211.md) variable corresponding to the source or to the account into which the contact will be added. If this parameter is not specified, the contact will be associated with no account.

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000135"></a>

This function changes the permissions required by the application.
Permission required: WRITE_CONTACTS
This permission allows the application to write (without reading) the data of the user contacts.
