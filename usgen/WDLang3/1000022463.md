


## &lt;Map&gt;.GetPosition (Function)

***In french: &lt;Carte&gt;.RécupèrePosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the geographical position of the point located in the center of the map currently displayed in a Map control.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Note**: This function is available in the Android emulator and in the Android simulator.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Returns the point in the map corresponding to the current user position
MyLocation is geoPosition
MyPosition = MAP_Position.GetPosition()
IF ErrorOccurred = False THEN
	RETURN MAP_Position.InfoPosition(MyLocation)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Map control>.GetPosition()`
---

**`<Result>: (geoPosition variable)`**

[geoPosition](../WDLang3/1000019191.md) variable corresponding to the geographical position of the point currently displayed in the center of the Map control.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.

**`<Map control>: (Control name)`**

Name of the Map control to be used.
