


## grScatterLinkPoint (Function)

***In french: grNuageReliePoint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Links (or not) the points found in a "Scatter" chart.

Example of chart with linked points: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=TraitRelie.gif)


**Reminder**: By default, the points of a "Scatter chart" are connected.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Unlink the points found in the "Scatter" chart named "MyChart"
grScatterLinkPoint("MyChart", False)
```
<a name="Exemple2"></a>

```wl
// Unlink the points found in the "Scatter" chart named CHART_MyChart
grScatterLinkPoint(CHART_MyChart, False)
```

<a name="SYNTAXE1"></a>

## Syntax

### Linking or unlinking the points found in a Scatter chart

`grScatterLinkPoint(<Chart name> , <Bind>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Bind>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the points must be linked between themselves,

- <u><u><u><u>False</u></u></u></u> otherwise.  





<a name="SYNTAXE2"></a>

### Linking or unlinking the points found in a series of Scatter chart

`grScatterLinkPoint(<Chart name> , <Series number> , <Bind>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to use. 

**`<Bind>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the points must be linked between themselves,

- <u><u><u><u>False</u></u></u></u> otherwise.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- In the "Scatter" charts, a point is defined by its coordinates (X-coordinate and Y-coordinate).

- The data defined by **grScatterLinkPoint** will be taken into account in the next call to [grDraw](../WDLang3/3042026.md).

- **grScatterLinkPoint** can only be used for the "Scatter" charts. This function has no effect with the other types of charts.

- The points are linked in the order in which they have been added
