


## Drive functions: OneDrive, Google Drive, Dropbox
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manage cloud-based storage services: 



|   |   |
| --- | --- |
| [dpDriveConnect](../WDLang3/1410089379.md) | Creates a connection to Dropbox. |
| [DriveCopyDirectory](../WDLang3/1410089554.md) | Copies a directory on a remote drive to another directory. |
| [DriveCopyFile](../WDLang3/1410089524.md) | Copies a single file on a remote drive to another directory on same drive. |
| [DriveCreateDirectory](../WDLang3/1410089479.md) | Creates a directory on the remote drive. |
| [DriveCreateFile](../WDLang3/1410089477.md) | Creates a file on the remote drive. |
| [DriveDeleteDirectory](../WDLang3/1410089481.md) | Deletes a directory and its files from a remote drive. |
| [DriveDeleteFile](../WDLang3/1410089480.md) | Deletes a file from a remote drive. |
| [DriveDownloadDirectory](../WDLang3/1410089559.md) | Downloads a directory and its files from a remote drive to the user's computer. |
| [DriveDownloadFile](../WDLang3/1410089558.md) | Downloads a file from a remote drive to the user's computer. |
| [DriveDownloadGglFile](../WDLang3/1410089618.md) | Downloads a Google Docs Editors file from Google Drive in a given compatible format. |
| [DriveListDirectory](../WDLang3/1410089448.md) | Lists drive directories. |
| [DriveListFile](../WDLang3/1410089380.md) | Lists the files in a cloud-based drive directory. |
| [DriveListFileGgl](../WDLang3/1410089601.md) | Lists Google Docs Editors files (Docs, Sheets, etc.) present on Google Drive. |
| [DriveMoveDirectory](../WDLang3/1410089556.md) | Moves a directory and its contents to another directory within a remote drive. |
| [DriveMoveFile](../WDLang3/1410089555.md) | Moves a file on a remote drive from one directory to another. |
| [DriveRename](../WDLang3/1410089566.md) | Renames a file or directory on a remote drive. |
| [DriveUploadDirectory](../WDLang3/1410089564.md) | Uploads a directory and its contents to a remote drive. |
| [DriveUploadFile](../WDLang3/1410089563.md) | Uploads a local file to a remote drive. |
| [GglDriveConnect](../WDLang3/1410089373.md) | Creates a connection to Google Drive. |
| [oDriveConnect](../WDLang3/1410089376.md) | Creates a connection to OneDrive. |
