
## ftpConnection (Variable type)

***In french: ftpConnexion***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ftpConnection** type is used to define all the advanced characteristics of an FTP connection. 

This type of variable can be used: 

- with the [FTPConnect](../WDLang3/3040016.md) function. 
	

- via a variable of type [hBackupDescription](../WDLang4/1000017455.md) to implement FTP or SFTP backup downloads. 




You can define and change the characteristics of this type of variable using different WLanguage properties. 

**Remarks**:

- [FTPConfigure](../WDLang3/1000020947.md) is used to modify the behavior of FTP functions. When a variable of type **ftpConnection** is used:

	- The FTP operating mode (*ftpConfigureMode* constant) is forced to 1. FTP functions use a native Windows-independent FTP implementation, with UTF-8 support.

	- The encryption mode (*ftpesConfigureSecureMode* constant) is determined by the **FTPESMode** property of the **ftpConnection** variable. 

	- The *ftpConfigureReuseConnection* constant can be used to force or prevent the connection to an FTP server from being reused between two requests (by default, the connection is reused).




- For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

<a name="sample_code"></a>

## Example


```wl
// Upload a backup to an FTP server
Backup_Doc is hBackupDescription
Backup_Doc.Description = "BackupWithPermissions"
Backup_Doc.WithIndex = True
Backup_Doc.Destination = "Back/BackupWithPermissions"
Backup_Doc.Source = "Anonymization/*"

Backup_Doc.Server = "chorizo-2k8"
Backup_Doc.User = "TT"
Backup_Doc.Password = "TT"
Backup_Doc.Ftp.PortNumber= 22
Backup_Doc.Ftp.Connection.ConnectionType= ftpActiveMode
Backup_Doc.Ftp.DestinationPath = "/tmp"

// Save backup 
HBackup(MyConnection, Backup_Doc)
```

## Properties


### Properties specific to ftpConnection variables
<a name="properties_specific_ftpconnection_variables_ELTPARAGRAPHE000063"></a>

The following properties can be used to define the characteristics of **ftpConnection** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| PrivateKey | Character string | Name and path of file corresponding to the private key used during a connection in SFTP mode. This file must have been generated in OpenSSH format. <br><br>By default, the connection is secured by implementing &lt;User&gt; / &lt;Password&gt; authentication. |
| ConnectionType | Integer | Type of connection: <br><br>- *ftpActiveMode*: Active connection to the FTP server.<br>	In this mode, the client initiates the data connection. This type of connection may be refused by some protected FTP servers.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Not available.<br><br>- *ftpPassiveMode* (Default): Passive connection to the FTP server (PASV command). <br>	In this mode, the server initiates the data connection. This type of connection allows you to bypass some firewalls.<br>	Note: If the connection to the server is established using IPV6, then the connection will be made in extended passive mode (passive mode does not support IPv6). <br><br>- *ftpExtendedPassiveMode*: Extended passive connection to the FTP server (EPSV command).<br>	In this mode, the server initiates the data connection. This type of connection allows you to bypass some firewalls. <br>	If the server does not support the extended passive mode (the FEAT command is sent to the server to get its capabilities), the connection is downgraded to simple passive mode. <br>	Limitation: This mode is not supported when using the Windows "wininet" module (see [FTPConfigure](../WDLang3/1000020947.md)). In this case, *ftpPassiveMode* is used. <br><br>- *ftpPassiveModeIgnoreIP*: Passive connection to the FTP server (PASV command). <br>	When transferring files in passive mode, the server sets the port and IP address for data transfer. With this parameter, only the port is taken into account. The IP address is ignored. This type of connection allows the use of FTP servers that return non-routable IP addresses but are reachable via the connection IP address.<br>	Limitation: This mode is not supported when using the Windows "wininet" module (see [FTPConfigure](../WDLang3/1000020947.md)). In this case, *ftpPassiveMode* is used. <br><br><br> |
| FTPESMode | Integer constant | Sets the FTPES encryption mode.<br><br>- *ftpSSLRequiredForAll*: Encryption applies to FTP data and commands. This is the default mode for functions in FTPES.<br><br>- *ftpSSLRequiredForControl*: SSL encryption applies only to FTP commands. This mode may be required for some FTPES servers.<br><br><br><br><br> |
| IgnoreError | Integer constant | In a secure transaction, some security errors may cause the function to fail. The connection can still be established by ignoring these errors, using the following constants: <br><br>- *ftpIgnoreInvalidCertificate*: The certificate is ignored.<br><br>- *ftpIgnoreExpiredCertificate*: The certificate date is ignored.<br><br>- *ftpIgnoreInvalidCertificateName*: The site name specified in the certificate is ignored.<br><br>- *ftpIgnoreDeprecated*: Ignores errors related to the use of deprecated algorithms (e.g. SHA-1 certificate signature).<br><br>- *ftpIgnoreUnsafeRenegotiation*: Ignores the error indicating that the server does not support secure renegotiation (RFC 5746).<br><br>- *ftpIgnoreRevocation*: Certificate revocation is ignored.<br><br><br>These errors are ignored only for the current connection instance. <br><br> |
| Password | String or secret string | Password that authenticates the user on the FTP server. This password corresponds to:<br><br>- the specified &lt;Password&gt; if this parameter is not an empty string (""), <br><br>- the email address of the user if &lt;Username&gt; is not specified or is an empty string (""), <br><br>- an empty string ("") if this parameter is not specified and &lt;Username&gt; is not an empty string ("").<br><br><br>Note: If the password contains special characters, it may be necessary to convert it to UTF-8 using [StringToUTF8](../WDLang1/3024042.md).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). <br><br>**This property is only available in write mode.** |
| PortNumber | Integer | Port number on which the server is to be run. This parameter is set by FTP site administrator.<br><br>By default: <br><br>- for an insecure connection, this port is port 21.<br><br>- for a secure connection in FTPS mode, this port is port 990. <br><br>- for a secure connection in FTPES mode, this port is port 21.<br><br>- for a secure connection in SFTP mode, this port is port 22.<br><br><br> |
| PrivateKeyPassword | String or secret string | Password of file containing the private key used during a connection in SFTP mode.<br>If UNICODE strings are used at runtime ("Unicode" tab of the [current configuration](../Editeurs/9000030.md)), the password must not be specified between quotation marks. It must be in a string variable declared in ANSI format.<br>If this parameter is not specified, the connection is secured by implementing &lt;User&gt; / &lt;Password&gt; authentication.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). <br><br>**This property is only available in write mode.** |
| ProcedureTrace | Procedure | Name of the WLanguage procedure used to identify the data and headers that have been sent and received. This procedure has the following format: <br><br><pre><code>PROCEDURE <Procedure name>(<InfoType> is int, <br>	<Data> is Buffer)</code></pre><br> where: <br><br>- &lt;InfoType&gt; is an integer constant that corresponds to the type of data being traced: <br><br>	- *httpTraceDataSent*: Data sent.<br><br>	- *httpTraceDataReceived*: Data received.. <br><br>	- *httpTraceHeaderSent*: Header sent. <br><br>	- *httpTraceHeaderReceived*: Header received. <br><br>	- *httpTraceInfo*: Detailed information about the execution of the request (low-level cURL/OpenSSL error, step in progress, warnings, etc.).<br><br><br><br><br>- &lt;Data&gt; is a buffer that contains the information. <br><br><br><br><br>Procedure example: <br><pre><code>PROCEDURE ProcTrace(nInfoType is int, ...<br>		bufByData is Buffer)<br>	SWITCH nInfoType<br>		CASE httpTraceHeaderSent<br>			Trace("Header: ", ...<br>				UTF8ToString(bufByData))<br>		CASE httpTraceDataSent:<br>			Trace("Data: ", ...<br>					bufByData)<br>		CASE httpTraceHeaderReceived:<br>			Trace("Header received: ", ...<br>				UTF8ToString(bufByData))<br>		CASE httpTraceDataReceived:<br>			Trace("Data received: ", ...<br>					bufByData)<br>	END</code></pre><br><br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available.<br><br> |
| Server | Character string | Name or IP address of the FTP server (for example, "ftp.cdrom.com" or "192.54.12.8").<br><br>This property defines the protocol used: <br><br>- if the server name starts with "ftp://", the connection is established in non-secure mode. <br><br>- if the server name starts with "ftps://", the connection is established in secure mode using FTPS (FTP secured by implicit SSL encryption). <br><br>- if the server name starts with "ftpes://", the connection is established in secure mode using FTPES (FTP secured by explicit SSL encryption). <br><br>- if the server name starts with "sftp://", the connection is established in secure mode via an SSH tunnel using SFTP. <br><br><br> |
| Timeout | Integer | Number of seconds after which the request for connecting to the FTP server is canceled (20 by default). <br><br>This timeout applies to all FTP operations performed on this connection. If no response is received from the server within the specified time, the connection fails. <br><br>This property can correspond to: <br><br>- an integer corresponding to the number of seconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., '1s').<br><br><br> |
| User | Character string | Name of the user that tries to log in using login credentials. <br><br>If this property is set to an empty string (""), the connection will be anonymous. |
