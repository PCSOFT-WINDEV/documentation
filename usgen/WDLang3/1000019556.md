
## ContactCreate (Function)

***In french: ContactCrée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the native "Create contact" window of the device (Android, iPhone or iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Create a contact and initialize the Contact structure
IF ContactCreate() = True THEN
	Info(StringBuild("The contact %1 was added to your list of contacts: ", ...
		 mContact.Name))
END
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
gCurrentContact is Contact
garrContacts is array of Contact

// Create a contact in the default window
IF ContactCreate() = True THEN
	// Refreshes the list of contacts displayed in a Looper control
	nIndex is int = LOOP_CONTACTS
	LooperDeleteAll(LOOP_CONTACTS)
	// List of contacts
	garrContacts = ContactList()
	// Sort the contacts
	ArraySort(garrContacts, asMember, "+Name")
	// Add into the looper
	FOR EACH tContact OF garrContacts
		LooperAddLine(LOOP_CONTACTS, tContact..LastName, tContact..FirstName)
	END
END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ContactCreate([<Contact>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the contact was created,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable containing the data of the new contact.

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000065"></a>

- If the user creates a new contact, the [Contact structure](../WDLang3/1000006111.md) or the [Contact](../WDLang3/1000020254.md) variable is automatically populated with the details of this new contact.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **ContactCreate** is a blocking function until the user validates or cancels the contact creation window.

- **ContactCreate** can be used in the emulator. It cannot be used in the simulator.



<a name="NOTE0_2"></a>


### Creating a contact (without using the creation window)
<a name="creating_contact_without_using_the_creation_window_ELTPARAGRAPHE000086"></a>

To create a new contact programmatically (without opening any window): 

1. Describe the contact using the [Contact](../WDLang3/1000020254.md) variable. 

2. Use the [ContactAdd](../WDLang3/1000006101.md) function.



<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000258"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ContactCreate** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
