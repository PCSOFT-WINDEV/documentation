


## sshSession (Variable type)

***In french: sshSession***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **sshSession** type is used to define the characteristics of a connection to an SSH server. The characteristics of this connection can be defined using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMySession is sshSession
cMySession.Address = "127.0.0.1"
cMySession.Port = 22
cMySession.User = "login"
cMySession.UserPassword = "pass"
```

<a name="PROPS"></a>

## Properties


### Properties specific to sshSession variables
<a name="properties_specific_sshsession_variables_ELTPARAGRAPHE000045"></a>

The following properties can be used to define a connection to an SSH server:

| Property name | Type used | Effect |
| --- | --- | --- |
| Address | Character string | Address of the SSH server. <br><br>This address can be specified as follows:<br><br>- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).<br><br>- IP address containing the server name (e.g. SSHServer). This syntax is recommended.<br><br><br> |
| ConnectionTimeout | Integer or Duration | Connection timeout expressed in milliseconds (20 seconds by default, i.e. 20000 milliseconds). This property can correspond to: <br><br>- an integer representing the number of milliseconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., 20 s or 20000 ms). <br><br><br> |
| KeepAliveInterval | Integer or Duration | Time between requests sent to keep the connection alive and check that the SSH server is still responding. If the SSH server shuts down unexpectedly while a long command initiated by [SSHCommand](../WDLang3/1000021143.md) is being executed, the keep alive functionality can detect the loss of connection between the application and the server. <br><br>This property can correspond to: <br><br>- an integer corresponding to the number of seconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., 20 s or 20000 ms).<br><br><br><br><br>If this property is set to: <br><br>- 0, the keep alive functionality will be disabled. <br><br>- less than 2 seconds, the duration will be set to 2 seconds for technical reasons.<br><br><br> |
| Port | Integer | Connection port (22 by default). |
| PrivateKey | Character string or [Certificate](../WDLang1/1000019287.md) variable | <br><br>- Name of the [Certificate](../WDLang1/1000019287.md) variable<br><br><br>or <br><br>- Path to the file containing the private key in OpenSSH format (for a private-key based authentication). <br><br><br><br><br>If this property is specified, a key-based authentication will be used. Only the **User**, **PrivateKey** and **PrivateKeyPassword** properties are taken into account. |
| PrivateKeyPassword | Character string or Secret string | Password of the key file (for a private-key based authentication). The **PrivateKey** property corresponds to the private key to be used.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| User | Character string | Username. |
| UserPassword | Character string or Secret string | User password (the **User** property corresponds to the user's name).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |


<a name="NOTE0"></a>

## Remarks
<a name="NOTE0_2"></a>


### Authentication mode
<a name="authentication_mode_ELTPARAGRAPHE000153"></a>

Key-based authentication takes precedence over password-based authentication. 

Key-based authentication is used if: 

- the server supports this authentication mode. 

- the **PrivateKey** property is specified. 




Password-based authentication is used if: 

- the server supports this authentication mode. 

- the **UserPassword** property is specified. 



<a name="NOTE0_3"></a>


### Using sshSession variables
<a name="using_sshsession_variables_ELTPARAGRAPHE000170"></a>

**sshSession** variables can be used with the following WLanguage functions:

- standard syntax: 
	


|   |   |
| --- | --- |
| [SCPGetFile](../WDLang3/1410089103.md) | Gets a file via the Secure Copy Protocol. |
| [SCPSendFile](../WDLang3/1410089102.md) | Transfers files via the Secure Copy Protocol. |
| [SSHCommand](../WDLang3/1000021143.md) | Sends a command to an SSH server. The session is automatically started and closed as soon as the command is sent. |
| [SSHConnectCommand](../WDLang3/1410091112.md) | Keeps the SSH session active between several commands sent to an SSH server (using the [SSHCommand](../WDLang3/1000021143.md) function).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [SSHConnectShell](../WDLang3/1000021147.md) | Starts a new SSH session of "Shell" type. |
| [SSHDisconnectCommand](../WDLang3/1410091113.md) | Stops the SSH session that was active to send a series of commands.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [SSHDisconnectShell](../WDLang3/1000021148.md) | Closes an SSH session that was opened by [SSHConnectShell](../WDLang3/1000021147.md). |
| [SSHRead](../WDLang3/1000021149.md) | Reads the data found on the output buffer of the SSH session. |
| [SSHWrite](../WDLang3/1000021150.md) | Writes data into the specified SSH session. |

- prefix syntax: 
	


|   |   |
| --- | --- |
| [&lt;sshSession variable&gt;.Command](../WDLang3/1410091176.md) | Sends a command to an SSH server. The session is automatically started and closed as soon as the command is sent. |
| [&lt;sshSession variable&gt;.ConnectCommand](../WDLang3/1410091177.md) | Keeps the SSH session active between several commands sent to an SSH server (using the [SSHCommand](../WDLang3/1000021143.md) function).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;sshSession variable&gt;.ConnectShell](../WDLang3/1000021163.md) | Starts a new SSH session of "Shell" type. |
| [&lt;sshSession variable&gt;.DisconnectCommand](../WDLang3/1410091178.md) | Stops the SSH session that was active to send a series of commands.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;sshSession variable&gt;.DisconnectShell](../WDLang3/1000021164.md) | Closes an SSH session that was opened by [SSHConnectShell](../WDLang3/1000021147.md). |
| [&lt;sshSession variable&gt;.Read](../WDLang3/1000021167.md) | Reads the data found on the output buffer of the SSH session. |
| [&lt;sshSession variable&gt;.Write](../WDLang3/1000021166.md) | Writes data into the specified SSH session. |
