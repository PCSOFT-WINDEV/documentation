


## ContactDelete (Function)

***In french: ContactSupprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the current contact: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png) from a Lotus Notes or Outlook address book. 
	**Attention** This function **does not** delete a Contact from an Outlook Express address book.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) from the list of contacts on the device (Android, iPhone or iPad).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf", ...
		"C:\Lotus Notes\julia.id")
// Find the contact to delete
IF ContactSearch(SessionID, "Smith", mContactLastName, "Adriana", mContactFirstName) = True THEN
	// Delete contact
	ContactDelete(SessionID)
	Info("This contact was deleted")
ELSE
	Info("No contact was found")
END
```
<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
gCurrentContact is Contact
garrContacts is array of Contact 
garrContacts = ContactList(Null)

// Delete the selected contact
gCurrentContact = garrContacts[LOOP_CONTACTS]

IF YesNo(Yes, "Do you want to delete this contact?") = Yes THEN
	// Delete contact
	ContactDelete(gCurrentContact)
	// Refresh contacts
	RefreshContacts()
END
```

### Deleting a contact from a Lotus Notes or Outlook address book

`<Result> = ContactDelete(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Integer)`**

Session ID to be used. This identifier is returned by [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).

### Delete a contact from the device contact list (Android, iPhone, iPad)

`<Result> = ContactDelete(<Contact>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if deleted successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable corresponding to the contact to delete.
