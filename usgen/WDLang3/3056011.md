
## NetDisconnect (Function)

***In french: NetDéconnecte***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	 This function is kept for backward compatibility. It is recommended to use a standard FTP, SSH or SCP server. For more details, see [Handling files on an FTP server](../WDLang3/3040009.md) and [Standard FTP functions](../WDLang3/3040004.md).
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disconnects from an FTP (File Transfer Protocol) or RPC (Remote Procedure Call) server powered by WINDEV.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ConnectRPC is int
ConnectRPC = NetConnect("148.61.125.245", RPCServer, "GUEST", "")
...
NetDisconnect(ConnectRPC)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`NetDisconnect(<Connection ID>)`
---

**`<Connection ID>: (Integer)`**

Identifier of the connection to disconnect (returned by [NetConnect](../WDLang3/3056004.md)).
