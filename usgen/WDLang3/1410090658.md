
## Parameters of the procedure used by NearbyShareWaitForConnection (Request)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareWaitForConnection](../WDLang3/1410090655.md) executed when a nearby device sends a connection request.
In the code of this procedure, the request can be accepted ([NearbyShareAcceptConnection](../WDLang3/1410090646.md)) or rejected ([NearbyShareRejectConnection](../WDLang3/1410090651.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Each time the connection wait check box is changed
CBOX_Wait_connection.State = Grayed
IF CBOX_Wait_connection THEN
	NearbyShareWaitForConnection(gsDeviceName, CallbackResult, CallbackRequestConnection, 
		CallbackConnection, gnTopology)
ELSE
	NearbyShareStopWaiting()
	CBOX_Wait_connection.State = Active
END
```

```wl
PROCEDURE CallbackRequestConnection(sDeviceID is string, sDeviceName is string, sToken is string)
Info([
	ID: [%sDeviceID%]
	Name: [%sDeviceName%]
])
Trace("[%sDeviceName%] wants to connect for nearby sharing")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareWaitForConnection_Callback_Request(<Device identifier> , <Device name> , <Authentication token>)`
---

**`<Device identifier>: (Character string)`**

Identifier of the device requesting the connection.

**`<Device name>: (Character string)`**

Name of the device that sends the connection request. 
This name corresponds to the device name passed to [NearbyShareRequestConnection](../WDLang3/1410090650.md).

**`<Authentication token>: (Character string)`**

Short, random character string that allows users to confirm that they are connecting to the right device.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Authentication tokens
<a name="authentication_tokens_ELTPARAGRAPHE000168"></a>

Both devices receive the same token. These tokens must be verified programmatically. 

A common practice is to display the token on both devices and ask users to compare and confirm manually (e.g., Bluetooth pairing).

[NearbyShareAcceptConnection](../WDLang3/1410090646.md) allows you to open a dialog box with the authentication token. The connection request can then be accepted or rejected.
