


## ContactSelect (Function)

***In french: ContactSélectionne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays the list of contacts found on the device (Android, iPhone or iPad, Universal Windows). The user has the ability to select one of the contacts. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example



<a name="Exemple2"></a>

```wl
gCurrentContact is Contact
// Selects a contact and dials the phone numbers of this contact
// (using the contact variable)
IF ContactSelect(gCurrentContact) = True THEN
	tel is Phone
	FOR EACH tel OF gCurrentContact.PhoneNumber
		IF tel.Type = phoneCellWork OR tel.Type = phoneWork THEN
			tapiDialerCall(tel.Number)
			RETURN
		END
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ContactSelect(<Contact>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a contact has been selected,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable to be specified with the characteristics of the selected contact.

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000088"></a>

- If the user selects a contact, the [Contact](../WDLang3/1000020254.md) variable is automatically populated with the details of the selected contact.

- **ContactSelect** blocks execution until the user selects a contact or leaves the selection window.

- **ContactSelect** can be used in the emulator. It cannot be used in the simulator.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000241"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ContactSelect** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
