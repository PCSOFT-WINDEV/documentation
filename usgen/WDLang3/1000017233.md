


## zipExist (Function)

***In french: zipExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines whether an archive exists. An archive exists if it was opened by [zipOpen](../WDLang3/3082044.md) or if it was created by [zipCreate](../WDLang3/3082003.md).

<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
MyArchive is zipArchive
// Create the archive
ResCreate = zipCreate(MyArchive, "C:\Temp\Archive.zip")
...
// Check the archive existence 
IF zipExist(MyArchive) = True THEN
	// Add a file into an archive
	ResAddFile = zipAddFile(MyArchive, ...
			"C:\MyDirectory\MyFiles\File.pdf", zipDrive)
	// Display an error message if the file was not added
	IF ResAddFile <> 0 THEN 
		Error(zipMsgError(ResAddFile))
	END
END
```

## Syntax

`<Result> = zipExist(<Archive>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the archive exists,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- the name of an archive, defined by [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [zipArchive](../WDLang3/1000018679.md) variables are not available in Java.
