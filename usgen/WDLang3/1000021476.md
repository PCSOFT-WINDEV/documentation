


## RESTSend (Function)

***In french: RESTEnvoie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends a REST request and waits for the server response.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMyRequest is restRequest
cMaRequete.URL = "<adresse serveur>"
cMyResponse is restResponse = RESTSend(cMyRequest)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
ELSE
	Info(cMyResponse.Content)
END
```

```wl
// The code sample below explains how to call a WINDEV REST web service with parameters.
// The procedure found in the web service has the following format:
// PRIVATE PROCEDURE UpdateTopBar(bTestMode is boolean)

// The test URL has the following format:
// http://<Server IP>/<Common component>
//?test

// WLanguage code used to call it by passing the parameter
cMyRequest is restRequest
cMyRequest.Method = httpGet
cMaRequete.URL = "http://<IP du serveur>/CDM/UpdateBandeauhaut/1" 
//Where CDM is the common component and 1 the parameter value

cMyResponse is restResponse = RESTSend(cMyRequest)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
ELSE
	IF cMyResponse.Content = True THEN
		Info("The site was updated.")
	ELSE
		Error(cMyResponse.Content)
	END
END
```

## Syntax
<a name="SYNTAXE1"></a>

### Syntax that uses a restRequest variable

`<REST response> = RESTSend(<REST request>)`
---

**`<REST response>: (restResponse variable)`**

Name of the [restResponse](../WDLang3/1000021477.md) variable containing the response received from the REST server.

**`<REST request>: (restResponse variable)`**

Name of the [restRequest](../WDLang3/1000021481.md) variable that contains the characteristics of the REST request to be sent to the server.


<a name="SYNTAXE2"></a>

### Simplified syntax for sending a request 

`<REST response> = RESTSend(<URL>)`
---

**`<REST response>: (restResponse variable)`**

Name of the [restResponse](../WDLang3/1000021477.md) variable containing the response received from the REST server.

**`<URL>: (Character string)`**

URL to interrogate.

### Asynchronous syntax that uses a restRequest variable

`RESTSend(<HTTP request> , <WLanguage procedure>)`
---

**`<HTTP request>: (restResponse variable)`**

Name of the [restRequest](../WDLang3/1000021481.md) variable that contains the characteristics of the REST request to be sent to the server.

**`<WLanguage procedure>: (Procedure name)`**

Name of WLanguage procedure called during the response from the REST server. This procedure has the following format: 

```txt
PROCEDURE <Procedure name>(<Response> is restResponse)
```
where &lt;Response&gt; is a [restResponse](../WDLang3/1000021477.md) variable containing the response received from the REST server.

### Security error in a secure transaction
<a name="security_error_secure_transaction_ELTPARAGRAPHE000303"></a>

During a secure transaction, the request may fail due to security errors:

- invalid certificate or certificate issued by an unknown organization.

- the name of the site specified in the certificate does not correspond to a server.

- invalid or expired certificate date.

- redirection to a non-secure server.




These errors are returned by [ErrorInfo](../WDLang1/3013008.md).

If one of these errors occurs, you can re-run the request while ignoring the errors. To do so, simply modify the **IgnoreError** property of the [httpRequest](../WDLang3/1000021158.md) variable:

| Error returned by [ErrorInfo](../WDLang1/3013008.md)<br>  (with the *errCode* constant) | Value of the **IgnoreError** property of the [restRequest](../WDLang3/1000021481.md) variable<br>(these values can be combined) | Description |
| --- | --- | --- |
| *httpErrorInvalidCertificate*<br>Invalid certificate or certificate coming from an unknown company. | *httpIgnoreInvalidCertificate* | Ignores the certificate. |
| *httpErrorInvalidCertificateName*<br>The site name specified in the certificate does not correspond to a server. | *httpIgnoreInvalidCertificateName* | Ignores the site name specified in the certificate. |
| *httpErrorExpiredCertificate*<br>Invalid or expired certificate date. | *httpIgnoreExpiredCertificate* | Ignores the certificate date. |
|   | *httpIgnoreDeprecated* | Ignores errors related to the use of deprecated algorithms (e.g. SHA-1 certificate signature). |
| *httpErrorRedirectToHTTP*<br>Redirection to a non-secure server. | *httpIgnoreRedirectToHTTP* | The redirection to a non-secure server is allowed. |
| *httpIgnoreRedirectToHTTPS*<br>Redirection to a secure server. | *httpIgnoreRedirectToHTTPS* | The redirection to a secure server is allowed. |
|   | *httpIgnoreUnsafeRenegotiation* | Ignores the error indicating that the server does not support secure renegotiation (RFC 5746). |
|   | *httpIgnoreRevocation* | The certificate found in the list of revoked certificates is not checked. |


Remarks: 

- When the HTTP queries are run in several threads, the **HTTP.IgnoreError** variable has a specific value for each thread.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The following errors are handled: *httpIgnoreExpiredCertificate*, *httpIgnoreInvalidCertificate*, *httpIgnoreInvalidCertificateName*, *httpIgnoreRevocation*, *httpIgnoreRedirection*.
