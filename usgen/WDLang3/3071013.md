
## SIPVisible (Function)

***In french: ClavierVisible***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays the keyboard.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In iOS, you only have the ability to make a keyboard invisible. 




<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SIPVisible(<Visible/Invisible>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the current keyboard was visible before the call to this function,

- <u><u><u><u>False</u></u></u></u> otherwise. 


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) &lt;Result&gt; is always set to <u><u><u><u>True</u></u></u></u>. 

**`<Visible/Invisible>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to make the current keyboard visible,

- <u><u><u><u>False</u></u></u></u> to make the current keyboard invisible.  


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) You only have the ability to make the keyboard invisible. Only <u><u><u><u>False</u></u></u></u> can be used for this parameter. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### "Enable the keyboard in edit"
<a name="enable_the_keyboard_edit_ELTPARAGRAPHE000092"></a>

The option "Enable the keyboard in edit" ("Details" tab of the edit control description window) automatically makes the current keyboard visible when the control is in edit mode.
<a name="NOTE0_3"></a>


### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000107"></a>

**Caution**: **SIPVisible** does not return an error code.. To determine if this function generated an error, use the [ErrorOccurred](../WDLang1/3087001.md) variable. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).
