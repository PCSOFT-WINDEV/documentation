


## WLanguage procedure called by tapiDial



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [tapiDial](../WDLang3/3076013.md) to manage the progress of the dialing process. This procedure can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="3076013_sample_code"></a>

## Example


```wl
IF tapiDial(EDT_PhoneNumber, "LineStatus")=True THEN 
	Info("Click OK to hang up") 
	tapiHangUp() 
END
```

```wl
PROCEDURE TestLineStatus(ValueLineStatus is int) 
SWITCH ValueLineStatus 
	CASE telLigneOccupée: Message("Line is busy") 
	CASE telLigneDecrochée: Message("OK, connected")
	CAS telLigneNumérote: Message("Dialing in progress") 
	CAS telLineTone: Message("Tone")
	CASE telLigneRaccrochée: Message("The correspondent has hung up")
	CAS telLigneAttendRéponse: Message("Search for correspondent")
	CASE telLigneSonnerie: Message("Ringing at correspondent's home")
END
```



<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`tapiDial_Callback(<Status of the line> , <Parameter>)`
---

**`<Status of the line>: (Integer)`**

Corresponds to one of the following values: 



|   |   |
| --- | --- |
| *tapiLineBusy* | The line is currently busy. |
| *tapiLineConnected* | The line is connected. |
| *tapiLineDialing* | Dialing in progress.<br><br>Note: If TAPI 3.1 technology is used, this constant is no longer returned. |
| *tapiLineDialTone* | The line gets a dial tone. |
| *tapiLineDisconnected* | The correspondent has hung up. |
| *tapiLineProceeding* | The call is dialed: looking for the person called. |
| *tapiLineRingBack* | Ringing in progress. |



**`<Parameter>: (Variant)`**

Custom parameter passed to [tapiDial](../WDLang3/3076013.md).
