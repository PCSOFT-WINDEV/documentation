


## &lt;btleCharacteristic variable&gt;.ChangeOfValue (Function)

***In french: &lt;Variable btleCaractéristique&gt;.ChangementValeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables detection of changes in the value of a Bluetooth Low Energy characteristic. 

For example, this makes it possible to generate a notification when a temperature sensor detects any changes. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
characteristic is btleCharacteristic
characteristic.ChangeOfValue(ProcDetectChange)
// ===========================
PROCEDURE CB_ChangeValue (characteristic is btleCharacteristic <useful> , bufValue is Buffer)
// Get value and display it in a Static Text control
sBuf is ANSI string = bufValue
STC_SubscriptionValue = sBuf
```

```wl
crtc is btleCharacteristic
crtc.ChangeOfValue()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Asking to be notified whenever the value of a characteristic changes

`<Characteristic>.ChangeOfValue([<WLanguage procedure>])`
---

**`<Characteristic>: (btleCharacteristic variable)`**

Name of the [btleCharacteristic](../WDLang3/1000022060.md) variable corresponding to the characteristic to use.

**`<WLanguage procedure>: (Name of the WLanguage procedure)`**

Name of the WLanguage procedure (called "callback") called when a characteristic changes on the device. For more details on this procedure, see [Parameters of the procedure used by &lt;btleCharacteristic variable&gt;.ChangeOfValue](../WDLang3/1000024784.md).


<a name="SYNTAXE2"></a>

### Stopping the detection regarding the change of characteristic value

`<Characteristic>.ChangeOfValue()`
---

**`<Characteristic>: (btleCharacteristic variable)`**

Name of the [btleCharacteristic](../WDLang3/1000022060.md) variable corresponding to the characteristic to use.
