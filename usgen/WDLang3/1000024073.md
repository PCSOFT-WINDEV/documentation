


## &lt;Chart&gt;.SeriesLabel (Function)

***In french: &lt;Graphe&gt;.EtiquetteSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the label of a data series in a chart.

Example of series label:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=EtiquetteSerie.gif)
To display the label, use [&lt;Chart&gt;.Legend](../WDLang3/1000024089.md).

**Reminder** By default, a graph has no label. For more details on managing legends, labels, etc., see [Managing legends in the charts](../WDChamp/3042069.md). 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initialize the "Sales" label of second data series in CHART_MyChart
CHART_MyChart.SeriesLabel(2, "Sales")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.SeriesLabel(<Series number> , <Label>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series for which a label will be initialized.

**`<Label>: (Character string)`**

Caption of label to initialize.

## Remarks


### Series labels
<a name="series_labels_ELTPARAGRAPHE000258"></a>The set of series labels correspond to the chart legend.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=EtiquetteSerie.gif)
Series labels cannot be used in pie charts.

Series labels are defined with **&lt;Chart&gt;.SeriesLabel**. 

The data defined by **&lt;Chart&gt;.SeriesLabel** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).

The legend font can be changed with [&lt;Chart&gt;.LegendFont](../WDLang3/1000024118.md).  

[&lt;Chart&gt;.Legend](../WDLang3/1000024089.md) indicates the presence and position of the legend (i. e. all series labels).

**Note** To define series labels for Scatter charts, use function [&lt;Chart&gt;.ScatterSeriesLabel](../WDLang3/1000024107.md).
<a name="NOTE0_2"></a>


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000303"></a>

The **&lt;Chart&gt;.SeriesLabel** function is equivalent to the [Legend](../Proprietes/2510143.md) property.
