


## MQTTDisconnect (Function)

***In french: MQTTDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to disconnect from a MQTT server (also called "Broker").


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyMQTTSession is mqttSession
...
MQTTDisconnect(MyMQTTSession)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`MQTTDisconnect(<MQTT session>)`
---

**`<MQTT session>: (mqttSession variable)`**

Name of the [mqttSession](../WDLang3/1000023023.md) variable corresponding to the parameters of the connection to end. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Log off
<a name="log_off_ELTPARAGRAPHE000055"></a>

On disconnection or loss of connection, the **IsConnected** property of the [mqttSession](../WDLang3/1000023023.md) variable changes to <u><u><u><u>False</u></u></u></u>.
