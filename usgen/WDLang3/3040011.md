


## FTPDisconnect (Function)

***In french: FTPDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the connection between the current computer and the FTP server (File Transfer Protocol). This connection was established by [FTPConnect](../WDLang3/3040016.md).

## Syntax

`<Result> = FTPDisconnect(<FTP connection>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the disconnection was performed, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. [ErrorInfo](../WDLang1/3013008.md) returns more details.




**`<FTP connection>: (Integer or ftpConnection variable)`**



- Connection identifier, returned by [FTPConnect](../WDLang3/3040016.md).
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is a Variant parameter.

- Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.
	

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available.

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000284"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified: 

- when connecting to the FTP server with [FTPConnect](../WDLang3/3040016.md) (&lt;Timeout&gt; parameter).

- when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000323"></a>

This function changes the permissions required by the application. 
Required permission: INTERNET 
This permission allows the applications to open the network sockets.
