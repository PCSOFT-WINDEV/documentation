## Mobile development environment
<a name="mobile_development_environment_ELTTEXTE000101"></a>
WINDEV Mobile is a development environment for PC that allows you to develop: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) applications for Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) applications for iPhone/iPad. 




**Remarks**: 

- The generated applications operate on mobile devices only (equipped with ARM, XScale, Samsung and ARM-compatible processors). These applications do not work on PC.

- Starting with version 27, it is no longer possible to develop Windows Mobile applications. Windows Mobile, Windows CE and Windows Embedded are no longer supported by Microsoft, but are still used in the industrial field. 
	To continue developing for Windows Mobile, you must use version 26. Version 2026 gives you access to version 26, which can be downloaded as a subscription-based version [here](https://download.windev.com/UK/SaaS.awp) or purchased as a dongle-based version [here](https://download.windev.com/UK/index.awp).

- Universal Windows Platform app development is no longer available from version 2025. The "Universal Windows 10 App" platform are no longer supported in WINDEV, WEBDEV and WINDEV Mobile. 
	To continue developing an application in Universal Windows 10 App mode, use version 2024. Version 2026 gives you access to version 2024, which can be downloaded as a subscription-based version [here](https://download.windev.com/UK/index.awp) or purchased as a dongle-based version [here](https://download.windev.com/UK/dongle.awp).

## WLanguage functions
<a name="wlanguage_functions_ELTTEXTE000149"></a>
Most of the WLanguage functions available in WINDEV are also available in WINDEV Mobile. These functions are common to both IDEs.

Only the functions specific to Windows are not available in WINDEV Mobile.

The following diagram presents the WLanguage functions that can be used according to the type of developed application:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Pocket-fonctions%20communes.gif)

## Database
<a name="database_ELTTEXTE000173"></a>
The data handled by a WINDEV Mobile application can come from:

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an HFSQL Classic or HFSQL Client/Server database.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) an SQLite database.

- ".INI" files.

- text files (ANSI or Unicode).
