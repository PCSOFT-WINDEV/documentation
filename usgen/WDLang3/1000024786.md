


## WLanguage procedure called by BTLEStatus



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [BTLEStatus](../WDLang3/1000021885.md) when the Bluetooth activation status changes on the device. This procedure can be a local, global or internal procedure.
<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`BTLEStatus_Callback(<New status> , <Former status>)`
---

**`<New status>: (Integer constant)`**

New Bluetooth activation status on the device: 


|   |   |
| --- | --- |
| *btActivationInProgress* | The Bluetooth is being enabled on the device. |
| *btDeactivationInProgress* | The Bluetooth is being disabled on the device. |
| *btDisabled* | The Bluetooth is disabled on the device. |
| *btEnabled* | The Bluetooth is enabled on the device. |



**`<Former status>: (Integer constant)`**

Bluetooth activation status on the device before the change: 


|   |   |
| --- | --- |
| *btActivationInProgress* | The Bluetooth is being enabled on the device. |
| *btDeactivationInProgress* | The Bluetooth is being disabled on the device. |
| *btDisabled* | The Bluetooth is disabled on the device. |
| *btEnabled* | The Bluetooth is enabled on the device. |
