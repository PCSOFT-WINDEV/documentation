


## UPNPMediaPlay (Function)

***In french: UPNPMédiaJoue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts reading the current media on the UPnP device.

**Attention**: To use this function, the device must have an "AVTransport" service.. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrDevice is array of upnpDevices
arrDevice = UPNPListDevice(...
		"urn:schemas-upnp-org:device:MediaRenderer:1", 5)
FOR EACH Device of arrDevice
	UPNPMediaPlay(Device)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = UPNPMediaPlay(<UPnP device>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the reading was started, 

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<UPnP device>: (upnpDevice variable)`**

Name of the [upnpDevice](../WDLang3/1000020903.md) variable corresponding to the UPnP device to use.
