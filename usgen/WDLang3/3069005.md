


## SOAPError (Function)

***In french: SOAPErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the error of the last SOAP procedure that failed.

**Note** This procedure was carried out by function [SOAPRun](../WDLang3/3069013.md) or [SOAPRunXML](../WDLang3/3069014.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003069005&name=soaperror_function">See additional examples</a>

```wl
// Returns the error message of the last SOAP procedure run
ResErrorMessage = SOAPError(SOAPErrMessage)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SOAPError(<Type of error>)`
---

**`<Result>: (Character string)`**



- Error of the last SOAP procedure that failed.

- An empty string ("") if:

	- no error was returned by the SOAP server, 

	- no connection was established by the SOAP server.







**`<Type of error>: (Constant)`**

Type of error to return:


|   |   |
| --- | --- |
| *SOAPErrActor* | URL of the SOAP server that triggered the error (useful if the procedure is run by several SOAP servers). |
| *SOAPErrCode* | Error of last SOAP procedure run:<br><br>- "VersionMismatch": The SOAP version used on the current workstation is different from the one used on the SOAP server.<br><br>- "MustUnderstand": The SOAP server does not understand the parameter specified in the header (only if the parameter &lt;Procedure execution&gt; of the header is set to <u><u><u><u>True</u></u></u></u>).<br><br>- "Client": Incorrect settings for procedure execution.<br><br>- "Server": The SOAP server has not executed the Procedure.<br><br><br>Note: This string can be completed with additional information. The following format is used: "&lt;Error&gt;.&lt;Information&gt;". For example: "Client.Authentication" if the error is due to client authentication. |
| *SOAPErrDetails* | Error details. This message is in XML format. |
| *SOAPErrMessage* | Error message returned by the SOAP server on the last SOAP procedure run. |
