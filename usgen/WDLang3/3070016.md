


## SocketConnect (Function)

***In french: SocketConnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Connects a client computer to a given socket.

**Remarks**:

- **UDP sockets**: Since UDP is a connectionless communication protocol, it cannot be used with **SocketConnect**. To send or receive data with the UDP protocol, you must create a UDP socket ([SocketCreateUDP](../WDLang3/3070019.md)) then send/receive data with the "special UDP" syntaxes of [SocketWrite](../WDLang3/3070002.md) and [SocketRead](../WDLang3/3070014.md). 

- **SSL sockets**: To send or receive data using the SSL protocol, you must create an SSL socket ([SocketCreateSSL](../WDLang3/1000017041.md)) and connect to the socket with [SocketConnectSSL](../WDLang3/1000017042.md).

- **Communication with robots or non-WINDEV applications**: To simplify data exchange via sockets, a transmission mode is initialized by default. To communicate with an external module (non-WINDEV application, robot, etc.), this transmission mode can prevent communications from working properly. [SocketChangeTransmissionMode](../WDLang3/3070005.md) changes the data exchange mode (the *SocketNoEndTag* constant is used to leave the read and write frames unchanged).

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **WebSockets**: WebSockets enable bidirectional communication between web applications (Intranet or Internet sites run in a browser) and web servers. **SocketConnect** is used to connect to the WebSocket server. For more details, see [Managing WebSockets](../WDLang3/1000017192.md). 
	
	<B><B><B>Warning</B></B></B>

	From version <B><B><B>27</B></B></B>, it is recommended to use [WebSocketClientConnect](../WDLang3/1410087751.md) and [WebSocketClientConnectSSL](../WDLang3/1410087752.md) to connect to the WebSocket server. 






**Reminder**: A socket is a communication resource used by applications to communicate from one computer to another regardless of the type of network.

		CASE SocketOpening
			SocketWrite("client", "Send message from the browser.")

			Info("Server message received: " + sMessage)

	END

### Connecting to a socket

`<Result> = SocketConnect(<Socket name> , <Port number> [, <Address> [, <Maximum timeout>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Socket name>: (Character string)`**

Name that will be given to the connection opened on the server socket. This name will be used by all socket functions.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: The socket name is case sensitive.

**`<Port number>: (Integer)`**

Port number of the socket. If you are using a socket associated with a preset protocol, use the port number associated with the protocol.
If the socket was created by a WINDEV application, this number must be included between 5 000 and 65 000. In this case, the number must be identical to the port number specified in [SocketCreate](../WDLang3/3070011.md).

**`<Address>: (Optional character string)`**

Server address. If this parameter is not specified, the server is sought on the current computer. This address can be specified as follows:

- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).

- URL containing the server name (www.windev.com for example). This syntax is recommended.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The address can also correspond to the IP address returned by [NetIPAddress](../WDLang3/3056023.md).![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The address must be the server IP address (not the server name).

**`<Maximum timeout>: (Optional integer or optional Duration)`**

Maximum timeout (in milliseconds) for establishing the connection. This timeout will be used if the server refuses the connection ([SocketDeny](../WDLang3/3070010.md)). In this case, the connection will not be locking. This parameter can correspond to: 

- an integer representing the number of milliseconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms). 


This timeout is set to 5000 milliseconds by default (5 seconds). For more details, see [the remarks](#NOTE0_2). 

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is ignored.

### Connecting to a WebSocket

`SocketConnect(<Socket name> , <Address> , <Browser WLanguage procedure> [, <Protocol(s)>])`
---

**`<Socket name>: (Character string)`**

Name that will be given when connecting to the server. This name will be used by all socket functions.
Note: The socket name is case sensitive.

**`<Address>: (Character string)`**

Address of the WebSocket server that will be used for the connection. This address has the following format: **ws[s]://server[:port][/directoryX/.../]**. In this case:

- the **ws** prefix indicates that the server is a WebSocket server. **wss** is used for a secure WebSocket server.

- **server** corresponds to the server address in the following format: server name, server domain name or IP address.

- **port** corresponds to the number of the communication port used to dialog with the server. This number must be identical to the port number specified in [SocketCreate](../WDLang3/3070011.md) if the WebSocket server was created in WLanguage with WINDEV or WEBDEV.

- **directoryX** corresponds to the possible virtual directories of server. 




**`<Browser WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") written in Browser code. Name of the procedure called when the connection to the server is established. This procedure can be used to send a message to the server with [SocketWrite](../WDLang3/3070002.md), for example.
For more details on this procedure, see [Parameters of the procedure used by SocketConnect](../WDLang3/1000024821.md).

**`<Protocol(s)>: (String or array of strings (optional))`**

Protocol(s) corresponding to the format of the WebSocket response. For example: "JSON", "XML". If this parameter is not specified or is an empty string, no protocol is used.

### Optimizing the connections for an IP address
<a name="optimizing_the_connections_for_address_ELTPARAGRAPHE000237"></a>

When an IP address is passed to **SocketConnect**, the connection can be optimized by using the following code:  

```wl
Socket.Option = SocketOptimizeIPConnection
```
This option is not enabled by default because the connection may fail in some configurations. However, it may be useful in some applications for which the performance is critical.

**Note**: To restore the default behavior, simply use the *SocketOptionDefault* constant:

```wl
Socket.Option = SocketOptionDefault
```

### Timeout
<a name="timeout_ELTPARAGRAPHE000253"></a>

The timeout specified by &lt;Maximum timeout&gt; groups the timeout of two steps:

- the address resolution timeout. This time cannot be configured, but can be optimized (see below).

- the maximum time for the server to accept the connection. Several cases may occur:

	- the server refuses the connection.

	- the server accepts the connection within the time limit.

	- the server is not available.

	- the specified address is invalid.







To optimize the timeout for address resolution (time required to find the address), we advise you to:

- use a DNS on the network. Therefore, this address will be searched for toward this server and not for each computer (1 search instead of x searches where x represents the number of computers). Each computer must be registered toward this server.

- for an IP address, use the **Socket.Option** variable as follows: 
	
	```wl
	Socket.Option = SocketOptimizeIPConnection
	```

### Connecting to an infrared port
<a name="connecting_infrared_port_ELTPARAGRAPHE000280"></a>

To connect to a socket that uses an infrared port:

1. Create a socket using the infrared port on the server ([SocketCreateInfrared](../WDLang3/3070012.md) in a WINDEV application).

2. In the client application (WINDEV application), use [SocketConnectInfrared](../WDLang3/3070018.md) to connect to this socket.

### Name resolution
<a name="name_resolution_ELTPARAGRAPHE000298"></a>

The Android emulator does not use the system of name resolution of the computer on which it is run. This detail is important if your development computer is configured to automatically add a suffix of domain name local to the computer names to resolve. In the Android emulator, the full names must be specified.

For exemple: If your computer is configured to add the "mydomain.com" suffix to the simple names, the following code:


```wl
SocketConnect("myserver")
```
will attempt to connect to myserver.mydomain.com if it is run directly on the PC and to "myserver" in the Android emulator.
When executed on an Android device, **SocketConnect** expects an IP address: 


```wl
SocketConnect("125.5.110.100") // or a string that contains the IP address.
```
