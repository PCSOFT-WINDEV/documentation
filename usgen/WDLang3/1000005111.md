
## NotesCloseDatabase (Function)

***In french: NotesFermeBase***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the local or remote database used (Lotus Notes or Domino). This database was opened by [NotesOpenDatabase](../WDLang3/1000005101.md).

**Remark**: This base will be automatically closed at the end of the WINDEV program or WEBDEV session.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Ouverture de la session
IDSession est un entier
IDSession = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Ouverture de la base
SI NotesOuvreBase(IDSession, "mail/julie.nsf") <> 0 ALORS
	Info("Session ouverte et base spécifiée")
SINON
	Erreur(ErreurInfo())
FIN
...
// Fermeture de la base
NotesFermeBase(IDSession)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NotesCloseDatabase(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the Lotus Notes database was closed,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Character string)`**

Identifier of the session to use. This identifier is returned by [NotesOpenConnection](../WDLang3/1000005102.md).
