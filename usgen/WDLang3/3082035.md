


## zipNbFile (Function)

***In french: zipNbFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of files in an archive (in CAB, RAR, ZIP, WDZ, 7z, gzip, TAR or TAGZ format).

## Example

```wl
MyArchive is zipArchive
// Open an archive
ResOpenArchive = zipOpen(MyArchive, "C:\MyArchives\Archive.zip")
IF ResOpenArchive = 0 THEN
	...
	// Number of files in the archive
	ResNbFiles = zipNbFile(MyArchive)
	Info(ResNbFiles + " files found in this archive") 
	...
END
```

## Syntax

`<Result> = zipNbFile(<Archive>)`
---

**`<Result>: (Integer)`**

Number of files in the specified archive.

**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- an archive name defined with [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [zipArchive](../WDLang3/1000018679.md) variables are not available in Java.
