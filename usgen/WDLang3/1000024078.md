


## &lt;Chart&gt;.ColumnSpacing (Function)

***In french: &lt;Graphe&gt;.HistoEspacement***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the spacing between each data category in: 

- a Column chart. 

- a Funnel chart.

- a Minimum/Maximum stock chart.

- a Waffle chart.




Examples of column charts with space between categories: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grHistoEspacement%20-%20HC%20N%B0001.gif)


**Reminder** By default, the space between two data categories is 10 pixels.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Space between two data categories in the "GRF_MonGraphe" column chart: 15 pixels
CHART_MyChart.ColumnSpacing(15)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.ColumnSpacing(<Spacing>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Spacing>: (Integer)`**

Spacing (in pixels) between two categories.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Spacing
<a name="spacing_ELTPARAGRAPHE000254"></a>

If the destination is large enough, the spacing is expressed as follows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=Grespace.gif)


If the destination does not allow spacing to be displayed, this is reduced to 0: the bars are therefore "glued" together.
<a name="NOTE0_2"></a>


### Effect due to spacing
<a name="effect_due_spacing_ELTPARAGRAPHE000267"></a>

- The spacing between two data categories has no effect on charts other than: 

	- Column charts.

	- Funnel charts.

	- Minimum/Maximum Stock charts.

	- Waffle charts.




- Any changes made with **&lt;Chart&gt;.ColumnSpacing** will take effect the next time [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is called.
