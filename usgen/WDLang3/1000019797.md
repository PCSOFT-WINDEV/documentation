
## geoGetAddress (Function)

***In french: géoRécupèreAdresse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves an address or a list of addresses corresponding to the description of a geographic location.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieves the address of a monument
MyAddress is Address 
MyAddress = geoGetAddress("Eiffel Tower")
IF ErrorOccurred = False THEN
	Info(MyAddress.Country)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>
![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Not available in Catalyst mode
### Retrieving an address

`<Result> = geoGetAddress(<Description>)`
---

**`<Result>: (Address variable)`**

[Address](../WDLang3/1000019944.md) variable corresponding to the description of the location. 

To find out whether the position failed to be retrieved, use the [ErrorOccurred](../WDLang1/3087001.md) variable. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

**`<Description>: (Character string)`**

Location whose address must be retrieved. This character string can correspond to: 

- the location specified as city and country. Example: "Paris, France". 
	Note: The location must be expressed in the language of the Phone. 

- the location expressed by the position ("&lt;latitude&gt;, &lt;longitude&gt;"). Example: "43.639942,3.837672". 





<a name="SYNTAXE2"></a>
![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Not available in Catalyst mode
### Retrieving a list of addresses

`<Result> = geoGetAddress(<Description> , <Array of addresses> [, <Number of addresses>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if at least one address was retrieved, 

- <u><u><u><u>False</u></u></u></u> otherwise. 




To find out whether the position failed to be retrieved, use the [ErrorOccurred](../WDLang1/3087001.md) variable. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

**`<Description>: (Character string)`**

Location whose address must be retrieved. This character string can correspond to: 

- the location specified as city and country. Example: "Paris, France". 
	Note: The location must be expressed in the language of the Phone. 

- the location expressed by the position ("&lt;latitude&gt;, &lt;longitude&gt;"). Example: "43.639942,3.837672".




**`<Array of addresses>: (Array)`**

Name of the array of [Address](../WDLang3/1000019944.md) variables that will be filled with the list of addresses corresponding to the position. The different properties of the [Address](../WDLang3/1000019944.md) variables (street, city, etc.) will be filled according to the precision of the information returned by the geolocation service.

**`<Number of addresses>: (Optional integer)`**

Maximum number of addresses returned in the list. If this parameter is not specified, the maximum number of addresses will be set to 10.


<a name="SYNTAXE3"></a>

### Retrieving a list of addresses (asynchronous mode)

`geoGetAddress(<Description> , <WLanguage procedure> [, <Number of addresses>])`
---

**`<Description>: (Character string)`**

Location whose address must be retrieved. This character string can correspond to: 

- the location specified as city and country. Example: "Paris, France". 
	Note: The location must be expressed in the language of the Phone. 

- the location expressed by the position ("&lt;latitude&gt;, &lt;longitude&gt;"). Example: "43.639942,3.837672".




**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called for the place with the address that must be retrieved. For more details on this procedure, see [Parameters of the procedure used by geoGetAddress](../WDLang3/1000025033.md). 

**`<Number of addresses>: (Optional integer)`**

Maximum number of addresses returned in the list. If this parameter is not specified, the maximum number of addresses will be set to 10.

## Remarks


### Managing multiple addresses (syntax 1)
<a name="managing_multiple_addresses_syntax_1_ELTPARAGRAPHE000147"></a>

If multiple addresses correspond to the same description: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a dialog box prompts the user to select one of the addresses. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) only the first address is returned.




To get the list of addresses that match the description, use the second or third syntax. You can use [OpenMobileWindow](../WDLang1/1000021018.md) or [OpenAsynchronous](../WDLang1/1410087804.md) to open a selection window.
