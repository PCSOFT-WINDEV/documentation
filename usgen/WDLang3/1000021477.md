


## restResponse (Variable type)

***In french: restRéponse***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **restResponse** type is used to define all the advanced characteristics of a REST response. You can define and change the characteristics of the request using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMyRequest is restRequest
cMyRequest.URL = "http://www.windev.com"
cMyResponse is restResponse = RESTSend(cMyRequest)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
ELSE
	Info(cMyResponse.Content)
END
```

<a name="PROPS"></a>

## Properties


### Properties specific to restResponse variables
<a name="properties_specific_restresponse_variables_ELTPARAGRAPHE000039"></a>

The following properties can be used to handle the response of a REST request:

| Property name | Type used | Effect |
| --- | --- | --- |
| Content | Buffer | Body of server response.<br><br>**This property is read-only**. |
| ContentType | Character string | String: Type of content of the HTTP message received.<br><br>**This property is read-only**. |
| DescriptionStatusCode | Character string | Description of the **StatusCode** property.<br><br>**This property is read-only**. |
| Header | Associative array of strings | Key/Value set of received headers. |
| RawHeader | Character string | Header that was returned with the response.<br><br><br><br>**This property is read-only**. |
| StatusCode | Integer | Status of response. This property corresponds to one of the codes of HTTP protocol. The most common codes are: <br><br>- 200: Query successfully processed<br><br>- 301: Document moved permanently<br><br>- 302: Document moved temporarily<br><br>- 403: The server received the request, but refuses to execute it.<br><br>- 404: Resource not found<br><br>- 500: Internal server error<br><br>- 503: Service temporarily unavailable or down for maintenance<br><br><br><br><br>The **DescriptionStatusCode** property gets the description of the error code. <br><br>**This property is read-only**. |
