
## BrightnessGet (Function)

***In french: LuminositéRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the current setting of the brightness for the screen of the device.

**Note**: This function can be used in the emulator.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
nBrightness is int = BrightnessGet()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BrightnessGet()`
---

**`<Result>: (Integer)`**

Current setting for the brightness of the screen in manual mode, included between 0 and 100.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Warning** If the brightness setting is in automation mode, the value returned may differ from the actual brightness of the display. To find out whether the setting was performed in automatic mode, use [BrightnessAuto](../WDLang3/1000020182.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To modify the value of the current setting for the brightness of the screen, use [BrightnessModify](../WDLang3/1000020170.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) [BrightnessAuto](../WDLang3/1000020182.md) returns or modifies the activation status of the automatic adjustment of the brightness on the device.
