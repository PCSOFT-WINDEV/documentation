
## Parameters of the procedure used by NearbyShareRequestConnection (Notification)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareRequestConnection](../WDLang3/1410090650.md) executed to notify the status of the connection with a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ShareProximityRequestConnection(gSelectedDevice.ID, ...
	gsDeviceName, CallbackDemandConnexion, CallbackConnexion)
```



```wl
PROCÉDURE CallbackDemandeConnexion(sIdAppareil is a string, sNomAppareil is a string, sToken is a string)
Info([
	ID: [%sIdApparatus%]
	Name: [%sApparatusName%]
])
```



```wl
PROCÉDURE CallbackConnexion(sIdAppareil is a string, nEtat is an integer)
SWITCH nStatus
	CASE ppRefusConnexion
		ToastDisplay("Connection request refused.")
	CASE ppConnexion
		ToastDisplay(StringBuild("You are connected to device %1.", sIdDevice)
	CAS ppDisconnect
		ToastDisplay("You are logged out.")
	CASE ppEchecConnexion
		ToastDisplay("Connection failed." + ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareRequestConnection_Callback_Notification(<Nearby device identifier> , <Status>)`
---

**`<Nearby device identifier>: (Character string)`**

Nearby device identifier.

**`<Status>: (Integer constant)`**

Nearby device connection status: 


|   |   |
| --- | --- |
|  *nsConnected* | Connection established. |
| *nsConnectionFailed* | Connection failure. In this case, [ErrorInfo](../WDLang1/3013008.md) returns the details of the error. |
| *nsConnectionRejected* | Connection rejected by the nearby device. |
| *nsDisconnected* | Disconnection |
