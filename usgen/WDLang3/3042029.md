


## grGradient (Function)

***In french: grDégradé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables the display of color gradients in a chart. 

**Reminder** By default, graph colors are Gradient.
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart created programmatically
grCreate("MyChart", grCandlestick)
...
// Disables the color gradients
grGradient("MyChart", False)
```
<a name="Exemple2"></a>

```wl
// Chart control
// Disables the color gradients
grGradient(CHART_MyChart, False)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grGradient(<Chart name> , <Gradient>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Gradient>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to display the chart by using the color gradients,

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The charts display the color gradients by default. The color gradients can be displayed by all the types of charts.

- The settings defined with **grGradient** will be taken into account next time [grDraw](../WDLang3/3042026.md) is called.

- During the print, the gradient mode will not be taken into account for the Pie charts.
