


## The SMS structure
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000209"></a>
The SMS structure is a preset structure of WLanguage (no declaration is required). This structure is used to create and read an SMS.

**Note** To reset all variables in the SMS structure, use the [SMSReset](../WDLang3/3068001.md) function.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only SMS messages found in the phone memory can be handled by the SMS functions.![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The SMS structure is used to generate QR Codes (when printing a bar code for example).

## The variables of the SMS structure
<a name="the_variables_the_sms_structure_ELTTEXTE000233"></a>
The structure contains the following members:


|   |   |
| --- | --- |
| **Attachment** | Character string corresponding to the path of the attachment to associate to the message. If this variable is specified, the message sent will be an MMS. <br><br>**Please note** To be sent, the document attachment must be located on the device's shared memory (e.g. on the SD card). <br><br>**Note** This variable is only used when sending SMS with the [SMSRunApp](../WDLang3/1000020864.md) function. It is ignored in all other cases. <br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This variable is ignored. |
| **CountryPrefix** | Character string containing the international prefix (33 by default for France).<br>If the recipient number starts with "0" and if a national prefix is specified, "0" will be replaced with this prefix.<br>If the national prefix is not specified, use a number in international format. For example, 1612345678.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This variable is ignored. |
| **Index** | Integer corresponding to the index of the incoming SMS.<br><br> |
| **Message** | Character string containing the outgoing message or the incoming message (up to 160 characters).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The message is not limited to 160 characters. |
| **Number** | Character string containing the recipient number or the sender number. |
| **NumberType** | Indicates the type of number used:<br><br>- ***smsInternationalNumber*** (default value): these numbers are accessible from anywhere and take the form 06.xx.xx.xx.xx<br><br>- ***smsNuméroNational***: short number, accessible only from France.<br><br><br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This variable is ignored. |
| **ReceiveDate** | Date and time when the SMS was received.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This variable is ignored. |
| **Retry** | Boolean (<u><u><u><u>True</u></u></u></u> by default)<br>Indicates whether the message must be sent on a regular basis if no reception.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This variable is ignored. |

## Differences between GO mode and runtime
<a name="differences_between_mode_and_runtime_ELTTEXTE000257"></a>
In **GO mode** (simulation on the development computer), a WLanguage error occurs when a variable of the SMS structure is used.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The SMS functions can be used during a GO on the Android emulator. To simulate the sending of SMS messages to the emulator, see the documentation of the Android SDK: [https://developer.android.com/studio/run/emulator#console](https://developer.android.com/studio/run/emulator#console)
