
## WLanguage procedure called by ScanFromCameraToImage/ScanDocumentFromCamera



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") executed when a scan is completed with the [ScanFromCameraToImage](../WDLang3/1410090763.md) function, when the scan fails or when it is canceled by the user

Note: This procedure can also be called by [ScanDocumentFromCamera](../WDLang3/1410090545.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
INTERNAL PROCEDURE onScan(ScanStatus, docs is array of Image)
		SWITCH ScanStatus
			CASE sdcFailed
				ToastDisplay("Scan error: "+ ErrorInfo)
			CASE sdcCanceled
				ToastDisplay("Scan canceled by user")
			CASE sdcSuccess
				FOR EACH scanned_image OF docs
					ProcessImage(scanned_img)
				END
		END
END
ScanFromCameraToImage(onscan)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`ScanFromCamera_Callback(<Scan status> , <Scanned images>)`
---

**`<Scan status>: (Integer constant)`**

Scan operation status:


|   |   |
| --- | --- |
| *sdcCanceled* | The user canceled the scan. |
| *sdcFailed* | There was an error during the scan. Use [ErrorInfo](../WDLang1/3013008.md) to get more details. |
| *sdcSuccess* | Documents were successfully scanned. |



**`<Scanned images>: (Array of images)`**

Name of the array of [Image](../WDLang1/1000019650.md) variables in which the various scanned images are stored.
