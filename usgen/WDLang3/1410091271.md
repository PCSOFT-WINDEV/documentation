
## WebServiceSendChunk (Function)

***In french: WebserviceEnvoieMorceau***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables a REST web service to immediately return a chunk of the response to the client (before the end of execution of the endpoint). 
The REST web service response will be chunked and sent.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
PROCEDURE ws_chunk()
WebserviceWriteMIMEType("application/json")
HExecuteQuery(QRY_BOOKS)
FOR EACH QRY_BOOKS
	WebServiceSendChunk("{""title"":""[%QRY_BOOKS.Title%]"", ""note"":""[%REQ_BOOKS.Note%]""}" + CR)
end
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`WebServiceSendChunk(<Content>)`
---

**`<Content>: (Character string or Buffer)`**

Content to be returned. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- When **WebServiceSendChunk** is used, all data must be sent with **WebServiceSendChunk**. The RETURN keyword must not be used in the procedure.

- The [WebserviceWriteMIMEType](../WDLang3/1000022681.md), [WebserviceWriteHTTPCode](../WDLang3/1000022785.md) and [WebserviceWriteHTTPHeader](../WDLang3/1000022788.md) functions must be called before the first call to **WebServiceSendChunk**.

- When this function is used, WEBDEV sends data to the web server in chunks. Depending on the configuration (buffering, compression), the server can group these chunks together before sending them to the client.
	In the case of an Apache server running on Linux, the following commands must be added to the Apache configuration: 
	
	```txt
	SetEnv no-gzip 1
	FcgidOutputBufferSize 0
	```
