
## sEscape (Function)

***In french: sEchap***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Runs different functions that directly affect the bits of serial port, parallel port or infrared port, independently of the communication protocol. These functions are used to manage:

- the DTR signal,

- the RTS signal,

- the XOFF and XON characters.




**Remarks**: 

- The port must be opened beforehand ([sOpen](../WDLang3/3062013.md)).

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Infrared ports are not supported.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function returns information regarding the server.

<a name="sample_code"></a>

## Example


```wl
// Clears the DTR signal
sEscape(PortNum, "CLRDTR")
```

## Syntax

`<Result> = sEscape(<Port number> , <Function>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was run,

- <u><u><u><u>False</u></u></u></u> otherwise. If the port was not opened beforehand (by [sOpen](../WDLang3/3062013.md)), **sEscape** has no effect.




**`<Port number>: (Integer)`**

Identifier of the port used: 

- Port number: 

	- Serial port number: 1, 2, 3, ... 32 for COM1, COM2, COM3, ... COM32.

	- Parallel port number: -1, -2, -3 or -4 for LPT1, LPT2, LPT3 or LPT4.

	- Infrared port number: 1, 2, 3, ... 32 for IR1, IR2, IR3, ... IR32.




- Port identifier returned by [sOpen](../WDLang3/3062013.md) (if this function was called with a port name). 
	![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Only this type of parameter is available.




**`<Function>: (Character string)`**

Function to run:


|   |   |
| --- | --- |
| CLRBREAK | Clears the "Break line" signal.<br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is not supported. |
| CLRDTR | Clears the DTR signal. |
| CLRRTS | Clears the RTS signal. |
| RESETDEV | Reinitializes the device if possible.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is not supported. |
| SETBREAK | Enables the "Break Line" signal.<br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is not supported. |
| SETDTR | Sends the DTR signal. |
| SETRTS | Sends the RTS signal. |
| SETXOFF | The transmission behaves like if the XOFF character was received.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is not supported. |
| SETXON | The transmission behaves like if the XON character was received.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This function is not supported. |








## Remarks
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Special case for Linux**: 

- Only serial ports can be opened and initialized. 

- By default, users do not have access to serial ports. It is necessary to grant them specific rights to manage serial ports. 





![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Using an external library: RXTX
<a name="using_external_library_rxtx_ELTPARAGRAPHE000328"></a>

In Java, the use of serial and parallel port manipulation functions (functions [sOpen](../WDLang3/3062013.md), [sWrite](../WDLang3/3062009.md), [sRead](../WDLang3/3062012.md), ...) requires the presence of an external library: RXTX. 

This library includes a Jar archive and one or more native libraries that depend on the operating system on which the application is run.
 
To use these functions: 

- the Jar archive (RXTXComm.jar) must: 

	- be found in the same directory as the Java application generated by WINDEV, 

	- be found in the execution classpath of the application, 

	- be directly included in the generated application (from the wizard for Java generation). 




- the native libraries corresponding to the operating system on which the application is run must be found: 

	- in the same directory as the Java application generated by WINDEV, 

	- in the path of the application libraries (librarypath).







You can download the RXTX library and its documentation from the following link: [http://users.frii.com/jarvi/rxtx/index.html](http://users.frii.com/jarvi/rxtx/index.html) (link valid at the time of writing). 

**Attention**: Infrared port management not available in Java.

### Features specific to Android and Android widget 
<a name="features_specific_android_and_android_widget_ELTPARAGRAPHE000186"></a>

In Android and Android widget mode, the serial and parallel port functions can be used: 

- Only on serial (not parallel or infrared) ports.

- Only with devices that support the CDC/ACM protocol (Arduino ATmega32U4) and the following USB to serial converter chips:

	- FTDI FT232R, FT232H, FT2232H, FT4232H, FT230X, FT231X, FT234XD

	- Silabs CP210x

	- Qinheng CH340, CH341A

	- Prolific PL2303
