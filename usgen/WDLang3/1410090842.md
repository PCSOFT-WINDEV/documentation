
## WLanguage procedure called by ScanFromCameraToPDF



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") executed when a scan is completed with the [ScanFromCameraToPDF](../WDLang3/1410090790.md) function, when the scan fails or when it is canceled by the user
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
INTERNAL PROCEDURE onScan(ScanStatus, MyPDF is pdfDocument)
	SWITCH ScanStatus
		CASE sdcFailed
			ToastDisplay("Scan error: "+ ErrorInfo)
		CASE sdcCanceled
			ToastDisplay("Scan canceled by user")
		CASE sdcSuccess
			PDFSave(MyPDF, "MyScan.pdf")
	END
END
ScanFromCameraToPDF(onscan)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`ScanFromCameraToPDF_Callback(<Scan status> , <PDF document>)`
---

**`<Scan status>: (Integer constant)`**

Scan operation status:


|   |   |
| --- | --- |
| *sdcCanceled* | The user canceled the scan. |
| *sdcFailed* | There was an error during the scan. Use [ErrorInfo](../WDLang1/3013008.md) to get more details. |
| *sdcSuccess* | Documents were successfully scanned. |



**`<PDF document>: (pdfDocument variable)`**

[pdfDocument](../WDLang6/1000024909.md) variable containing all scanned documents in PDF. You can then save the document with [PDFSave](../WDLang6/1000024864.md) or manipulate its contents using [PDF functions](../WDLang6/1000015007.md).
