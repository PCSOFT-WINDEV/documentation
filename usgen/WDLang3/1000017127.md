
## BTIsVisible (Function)

***In french: BTEstVisible***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out whether a Bluetooth radio is visible.

**Note**: A Bluetooth radio corresponds to a Bluetooth transmitter.. This transmitter can correspond to a Bluetooth USB key or it can be an element included in a computer (laptop for example).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Caution**: Bluetooth functions are not available in the Android emulator.

## Example

![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
bVisible is boolean
// Identifier of Bluetooth radios listed in a Table control
nRadioID is int 
nRadioID = TABLE_Radios.COL_ID[TABLE_Radios]
// Checks whether the selected radio is visible
bVisible = BTIsVisible(nRadioID)
// Display 
IF bVisible = True THEN
	Trace("Visible")
ELSE 
	Trace("Not visible")
END
// Change the visibility
BTChangeVisibility(nRadioID, NOT bVisible)
```

### Syntax that can be used in Windows

`<Result> = BTIsVisible(<Radio identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the Bluetooth radio is visible,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Radio identifier>: (Integer)`**

Identifier of Bluetooth radio to use. This identifier is returned by [BTListRadio](../WDLang3/1000017125.md).

### Limitation
<a name="limitation_ELTPARAGRAPHE000085"></a>

Only the Microsoft Bluetooth stack is supported by this function. To know the stack used, call [BTStack](../WDLang3/1000017229.md).  

For more details, see [Which stacks to use?](../WDLang3/1000017231.md)

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000102"></a>

This function changes the permissions required by the application.

Permission required: BLUETOOTH.

This permission allows the applications to connect to the Bluetooth services.
