


## GglFile (Variable type)

***In french: FichierGgl***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **GglFile** type is used to get all the characteristics of a file used in one of the Google Docs Editors (Docs, Sheets, etc.). These files can only be stored and edited on Google Drive. This drive is handled using a variable of type [gglDrive](../WDLang3/1410089374.md). 

**NOTE**: Variables of type **GglFile** can only be created and initialized with [DriveListFileGgl](../WDLang3/1410089601.md). 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

gglMyDrive is gglDrive
gglMyDrive = GglDriveConnect(oOAuth2Param) 

arrGglFile is array of GglFile
arrGglFile = DriveListFileGgl(gglMyDrive, "/", frRecursive)

FOR EACH File OF arrGglFile
	SWITCH File.MimeType
		CASE mimeTypeGglDocs: File.ExportMimeType = mimeTypeDOCX
		CASE mimeTypeGglSheets: File.ExportMimeType = mimeTypeXLSX
		OTHER CASE: File.ExportMimeType = mimeTypePDF
	END 
	let ResDownload = DriveDownloadGglFile(gglMyDrive, arrGglFile[1], "c:\MyDocuments")
	IF ErrorOccurred THEN
		// Error handling
		Trace ("An error has occurred")
		RETURN
	END
END
```

## Properties


### Properties specific to GglFile variables
<a name="properties_specific_gglfile_variables_ELTPARAGRAPHE000040"></a>

The following properties can be used to manipulate Google files:

| Property name | Type used | Effect |
| --- | --- | --- |
| Path | Character string | Path to the file on the drive.<br><br>This property is read-only. |
| ExportMimeType | Character String constant | Mime type corresponding to the different export possibilities according to the document type (see Remarks). |
| LastModificationDate | DateTime | Date and time the file was last modified. This property is only specified if the *fdFullInformation* constant has been used with the [DriveListFileGgl](../WDLang3/1410089601.md) function. <br><br>This property is read-only. |
| Length | Integer | File size in bytes. This property is only specified if the *fdFullInformation* constant has been used with the [DriveListFileGgl](../WDLang3/1410089601.md) function. <br><br>This property is read-only. |
| MimeType | Character String constant | Mime type of the Google file: <br><br>- *mimeTypeGglAppsScript*: Apps Script. <br><br>- *mimeTypeGglDrawings*: Google Drawings.  <br><br>- *mimeTypeGglDocs*: Google Docs. <br><br>- *mimeTypeGglSheets*: Google Sheets.  <br><br>- *mimeTypeGglSlides*: Google Slides. <br><br><br><br><br>This property is read-only. |
| Name | Character string | Name of the file on the drive.<br><br>This property is read-only. |
