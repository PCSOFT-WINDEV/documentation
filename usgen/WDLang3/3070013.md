
## SocketExist (Function)

***In french: SocketExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks if a socket already exists.

**Remarks**: 

- To check the validity of the connection, use [SocketClientInfo](../WDLang3/3070009.md) to check the IP address of the client socket and the port number. 

- The socket exists if it has not yet been closed with [SocketClose](../WDLang3/3070015.md). 

- If the communication is interrupted, **SocketExist** may still return a positive result even if the dialog is stopped.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Check if the socket exists before creating a new one
IF SocketExist("MySocket") = False THEN
	IF SocketCreate("MySocket", 8000) = False THEN
		 Error("Creation error" + ErrorInfo(errMessage))
	 END
ELSE
	 SocketRead("MySocket", False)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SocketExist(<Socket name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the socket exists,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Socket name>: (Character string)`**

Name of the socket to be checked. 

For a WINDEV application, this name is defined:

- by [SocketCreate](../WDLang3/3070011.md), [SocketCreateSSL](../WDLang3/1000017041.md) or [SocketCreateInfrared](../WDLang3/3070012.md) (for a simplified server). 

- by [SocketAccept](../WDLang3/3070004.md) (for a standard server).

- by [SocketConnect](../WDLang3/3070016.md) (for a WEBDEV website).


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: The socket name is case sensitive.
