


## &lt;zipArchive variable&gt;.CurrentFile (Function)

***In french: &lt;Variable zipArchive&gt;.FichierEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the archived file currently handled by the functions for adding and extracting files. This function can be used on archives in CAB, RAR, WDZ, ZIP, gzip, TAR and TGZ (TAR.GZ) formats.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
Archive is zipArchive

FOR Index = 1 TO 5
	// Extract the first 5 files from the archive
	ResExtractFile = Archive.ExtractFile(Subscript)
	...
	// Find the name of the file currently extracted
	ResCurrentFile = Archive.CurrentFile()
	// Display the name of the file in the status bar
	Message(ResCurrentFile)
	...
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Archive>.CurrentFile()`
---

**`<Result>: (Character string)`**

File currently handled by [&lt;zipArchive variable&gt;.AddFile](../WDLang3/1000019050.md), [&lt;zipArchive variable&gt;.AddDirectory](../WDLang3/1000019078.md), [&lt;zipArchive variable&gt;.ExtractFile](../WDLang3/1000019082.md) or [&lt;zipArchive variable&gt;.ExtractAll](../WDLang3/1000019085.md).

**`<Archive>: (zipArchive variable)`**

Name of a variable of type [zipArchive](../WDLang3/1000018679.md) corresponding to the archive to use.

<a name="NOTE0_2"></a>


### Error while adding or extracting files
<a name="error_while_adding_extracting_files_ELTPARAGRAPHE000277"></a>

If an error occurs during the addition or extraction processes, **&lt;zipArchive variable&gt;.CurrentFile** contains the name of the file that was not read or written in the archive.
