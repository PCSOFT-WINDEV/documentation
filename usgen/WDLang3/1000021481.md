


## restRequest (Variable type)

***In french: restRequête***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **restRequest** type is used to define the advanced characteristics of a REST request. You can define and change the characteristics of the REST request using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMyRequest is restRequest
cMyRequest.URL = "http://www.windev.com"
cMyResponse is restResponse = RESTSend(cMyRequest)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
ELSE
	Info(cMyResponse.Content)
END
```

## Properties


### Properties specific to restRequest variables

Kerberos is the default authentication protocol. If it is not available, the NTLM protocol is used. <br><br>- *auNTLM*: The client and server exchange a certain amount of information before establishing a connection via the NTLM protocol (Windows only). <br><br><br><br><br>Note: Although still widely used, the NTLM protocol is no longer recommended. |

If this parameter must be different, you need to build the http URL.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available. |
| ClientCertificate | String or buffer | Corresponds to: <br><br>- a character string with an access path to the .p12 file that contains the certificate to attach to the request. | ClientCertificatePassword | Character string or Secret string | Password associated with the client certificate (empty string by default).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| ConnectionTimeout | Integer | Maximum timeout for the connection expressed in milliseconds (20 seconds by default, i.e. 20000 milliseconds). | ContentType | Character string | Type of the HTTP message content to be sent to the server. | Destination | Character string | Full path of the backup file of the HTTP request result.<br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available. |

| IgnoreError | Integer constant | Specifies the ignored errors. Corresponds to a constant or combination of constants:<br><br>- *httpIgnoreInvalidCertificate*: The certificate is ignored.<br><br>- *httpIgnoreInvalidCertificateName*: The site name specified in the certificate is ignored.<br><br>- *httpIgnoreExpiredCertificate*: The certificate date is ignored. <br><br>- *httpIgnoreDeprecated*: Ignores errors related to the use of deprecated algorithms (e.g. SHA-1 certificate signature).<br><br>- *httpIgnoreRedirection*: Redirection to a page is ignored.<br><br>- *httpIgnoreRedirectToHTTP*: Redirection to a non-secure server is allowed.<br><br>- *httpIgnoreRedirectToHTTPS*: Redirection to a secure server is allowed.<br><br>- *httpIgnoreUnsafeRenegotiation*: Ignores the error indicating that the server does not support secure renegotiation (RFC 5746).<br><br>- *httpIgnoreRevocation*: The revoked certificate list verification is ignored.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Only the following errors are handled: *httpIgnoreExpiredCertificate*, *httpIgnoreInvalidCertificate*, *httpIgnoreInvalidCertificateName*, *httpIgnoreRevocation*, *httpIgnoreRedirection*. <br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available. |

### Managing redirections
<a name="managing_redirections_ELTPARAGRAPHE000299"></a>

Redirections are supported by default. To ignore redirections, use the *httpIgnoreRedirection* constant in the **IgnoreError** property.

### HTTP cookies
<a name="http_cookies_ELTPARAGRAPHE000310"></a>

Cookies received in response to a call to [RESTSend](../WDLang3/1000021476.md) are stored while waiting for a subsequent call to [RESTSend](../WDLang3/1000021476.md) on the same domain. In this case, the **restRequest** variable is updated.
For more details, see [HTTPCookieManage](../WDLang3/1000019218.md).
