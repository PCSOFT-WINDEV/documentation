


## &lt;Chart&gt;.Gradient (Function)

***In french: &lt;Graphe&gt;.Dégradé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables the display of color gradients in a chart. 

**Reminder** By default, graph colors are Gradient.
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart control
// Disables the color gradients
CHART_MyChart.Gradient(False)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Gradient(<Gradient>)`
---

**`<Chart control>: (Control name)`**

Name of manipulated Chart control (present in window, page or report editor).

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Gradient>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to display the chart by using the color gradients,

- <u><u><u><u>False</u></u></u></u> otherwise.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The charts display the color gradients by default. The color gradients can be displayed by all the types of charts.

- The settings defined with **&lt;Chart&gt;.Gradient** will be taken into account next time [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is called.

- During the print, the gradient mode will not be taken into account for the Pie charts.
