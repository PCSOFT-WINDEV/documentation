


## HTTPCookieGet (Function)

***In french: HTTPCookieRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the cookies read: 

- via a call to [HTTPRequest](../WDLang3/3043007.md) for an HTTP domain.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) via a call to [HTTPSend](../WDLang3/1000021183.md) for an HTTP domain. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) in variable [httpResponse](../WDLang3/1000021165.md) (containing the result of function [HTTPSend](../WDLang3/1000021183.md)). 


**Note** Cookies read and sent by the [HTTPRequest](../WDLang3/3043007.md) function are only stored in the application's memory. They are not related to the cookies of Web browsers installed on the computer.

<a name="sample_code"></a>

## Example


```wl
// Request toward the google.com site
HTTPRequest("www.google.com")

// Read the array of cookies returned by the site
arrCookie is array of Cookies
arrCookie = HTTPCookieGet(".www.google.com")
Info("The www.google.com site currently stores " + arrCookie.Occurrence + " cookies locally")
```

## Syntax
<a name="SYNTAXE1"></a>

### Retrieving the cookies read via a call to HTTPRequest

`<Result> = HTTPCookieGet(<Domain>)`
---

**`<Result>: (Array of Cookie variables)`**

List of cookies stored in memory for the specified domain.

**`<Domain>: (Character string)`**

Domain for which the list of cookies currently stored in memory will be retrieved.

### Retrieving the cookies read via a call to HTTPSend

`<Result> = HTTPCookieGet(<HTTP request> , <Domain>)`
---

**`<Result>: (Array of Cookie variables)`**

List of cookies stored in memory for the specified domain.

**`<HTTP request>: (httpRequest variable)`**

Name of the [httpRequest](../WDLang3/1000021158.md) variable for which the cookies will be listed. 

**`<Domain>: (Character string)`**

Domain for which the list of cookies currently stored in memory will be retrieved.

### Retrieving the cookies read via an httpResponse variable

`<Result> = HTTPCookieGet(<HTTP response>)`
---

**`<Result>: (Array of Cookie variables)`**

List of cookies stored in memory for the specified domain.

**`<HTTP response>: (httpResponse variable)`**

Name of the [httpResponse](../WDLang3/1000021165.md) variable for which the cookies will be listed.
