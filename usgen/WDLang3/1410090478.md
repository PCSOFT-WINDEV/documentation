


## DNS constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The DNS constants are as follows:

| Constant | Details | Function |
| --- | --- | --- |
| **dnsA** | Gets the IPv4 address associated with the domain name. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsAAAA** | Gets the IPv6 address associated with the domain name. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsCNAME** | Gets the aliases of a domain name. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsDNAME** | Gets the aliases of a domain and its subdomains. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsMX** | Gets the mail servers associated with the specified domain. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsNAPTR** | Gets rewrite rules, allowing for more possibilities of correspondence between a domain name and a resource. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsNS** | Gets a list of DNS servers for the specified domain. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsPTR** | Gets the host or domain name associated with an IP address (opposite of A/AAAA). | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsSOA** | Provides general information about the domain: main server, contact e-mail, various durations including expiration, zone serial number, etc. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsSRV** | Gets the mail server associated with a domain name with additional data such as the load balancing weight for a given service. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsTLSA** | Gets the TLS certificate associated with the domain name. | [DNSQuery](../WDLang3/1410089873.md) |
| **dnsTXT** | Gets the text associated with a DNS record. | [DNSQuery](../WDLang3/1410089873.md) |
