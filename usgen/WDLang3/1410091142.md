


## Standard FTP functions (prefix syntax)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
FTP functions are as follows (prefix syntax):



|   |   |
| --- | --- |
| [&lt;ftpConnection variable&gt;.Command](../WDLang3/1410091118.md) | Sends a specific FTP command to a server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Connect](../WDLang3/1410091119.md) | Connects the current computer to an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.CurrentDir](../WDLang3/1410091131.md) | Gets or sets the current directory on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Date](../WDLang3/1410091120.md) | Returns the different dates of a file (date the file was created, modified or accessed) located on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.DateTime](../WDLang3/1410091121.md) | Returns the different creation, modification or access dates and times associated with a file located on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.DeleteFile](../WDLang3/1410091133.md) | Deletes a file from an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.DirExist](../WDLang3/1410091282.md) | Checks for a directory on an FTP server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 3.** |
| [&lt;ftpConnection variable&gt;.FileExist](../WDLang3/1410091124.md) | Checks if a given file exists on an FTP server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Get](../WDLang3/1410091127.md) | Transfers a file or directory from an FTP server (File Transfer Protocol) to the current computer.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.GetFile](../WDLang3/1410091128.md) | Transfers a file from an FTP (File Transfer Protocol) server to the current computer.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md) | Lists the directories or files in a directory located on an FTP server and returns the number of files and/or directories.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.MakeDir](../WDLang3/1410091130.md) | Creates a directory on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Name](../WDLang3/1410091137.md) | Returns the name of the last file accessed by an FTP function.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.RemoveDir](../WDLang3/1410091132.md) | Deletes a directory and its content (files and subdirectories) from an FTP server.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.RenameFile](../WDLang3/1410091129.md) | Renames or moves a file located on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Send](../WDLang3/1410091123.md) | Transfers a file or directory to an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Size](../WDLang3/1410091134.md) | Returns the size (in bytes) of a file located on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;.Time](../WDLang3/1410091125.md) | Returns the different creation, modification or access times associated with a file located on an FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;ftpConnection variable&gt;Attribute](../WDLang3/1410091117.md) | Gets the attributes of a file located on an FTP server.<br><br> |
| [FTPDeconnecte_objetftpConnexion](../WDLang3/1410091122.md) | Closes the connection between the current computer and the FTP server (File Transfer Protocol).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
