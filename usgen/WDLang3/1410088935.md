
## apiRequest (Type of request)

***In french: apiRequête***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **apiRequest** type is used to define all the advanced characteristics of a request executed via a REST web service imported using the OpenAPI documentation. These characteristics can be defined and changed using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Req is apiRequest
Req.HTTPHeader["key"] = "Value"
// Call a REST web service entry point 
// passing the header and the expected parameters
MyWebService.GetUserList(Req, param1_WS, param2_WS)
```

## Properties


### Properties specific to apiRequest variables 
<a name="properties_specific_apirequest_variables_ELTPARAGRAPHE000042"></a>

The following properties can be used to define the characteristics of **apiRequest** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| ClientCertificate | String or buffer | Corresponds to: <br><br>- a character string with an access path to the .p12 file that contains the certificate to attach to the request. The certificate will be automatically loaded taking into account:<br><br>	- the certificate in the executable library (if it has been integrated into the application),<br><br>	- the certificate at the specified location on disk (if the certificate has not been integrated into the executable library).<br><br><br><br><br>- a buffer with the certificate ([fLoadBuffer](../WDLang1/1000019410.md)).<br><br><br><br><br>If this property is set to an empty string (""), the default certificate is reset to "&lt;None&gt;". |
| HTTPHeader | Associative array of strings | Key/Value set of headers to send.<br><br>Usage example of this property: <br><br><br><pre><code>cMyRequest.HTTPHeader["Authorization"] = ...<br>	" WSSE profile=""UsernameToken"""<br>cMyRequest.HTTPHeader["X-WSSE"] = ...<br>	"UsernameToken Username=blahblah "<br>cMyRequest.Header["Cache-Control"] = " no-cache"</code></pre><br> |
| ClientCertificatePassword | Character string or Secret string | Password associated with the client certificate (empty string by default).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| ConnectionTimeout | Integer or Duration | Maximum timeout for the connection expressed in milliseconds (20 seconds by default, i.e. 20000 milliseconds). This property can correspond to: <br><br>- an integer representing the number of milliseconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., 20 s or 20000 ms). <br><br><br><br><br>The connection fails if it cannot be established within this period. |

## Remarks
<a name="NOTE0_2"></a>


### Handling different MIME types in the web service request
<a name="handling_different_mime_types_the_web_service_request_ELTPARAGRAPHE000106"></a>

Some web service functions can expect different Mime types in their parameters. 

If the Mime type of the request is not JSON, serialization is required. 

Example: 

1. Creation of the element to be passed to the API: 
	
	```wl
	// Create an Author element (type defined by the API)
	author is 'Library Management API'.Author
	author.id = 12
	author.name = "Molière"
	author.birthDate = "16091205"
	author.nationality = "French"
	```


2. The MIME type of the request is "application/json": 
	
	```wl
	APIReqJSON is apiRequest
	APIReqJSON..HTTPHeader["Content-Type"] = mimeTypeJSON
	'Library Management API'._authorspost(APIReqJSON,"token",author)
	```


3. The MIME type of the request is "application/xml" instead of "application/json". Serialization is required: 
	
	```wl
	// Serialize author before passing it as a parameter to the API
	sAuthor is string
	oXml is xmlNode = JSONToXML(author)
	sAuthor = oXml..XMLSource
	
	APIReqXML is apiRequest
	APIReqXML..HTTPHeader["Content-Type"] = mimeTypeXML
	'Library Management API'._authorspost(APIReqXML,"token",sAuthor)
	```
