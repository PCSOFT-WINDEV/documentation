
## SocketCreate (Function)

***In french: SocketCrée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a socket. A socket is a communication resource used by applications to communicate from one computer to another regardless of the type of network.

**Remarks**:

- This function must be called on the server used for the communication. If the client computer uses a WINDEV application to connect to this socket, this application will have to use [SocketConnect](../WDLang3/3070016.md).

- **SSL sockets**: To create an SSL socket, use [SocketCreateSSL](../WDLang3/1000017041.md).

- **UDP Sockets**: To create a UDP socket, use [SocketCreateUDP](../WDLang3/3070019.md).

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003070011&name=socketcreate_function">See additional examples</a>

```wl
IF SocketCreate("Server", 8000) = False THEN
	Error("creation error" + ErrorInfo(errMessage))
END
```

## Syntax

`<Result> = SocketCreate(<Socket name> , <Port number> [, <Address>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Socket name>: (Character string)`**

Name that will be given to the socket. This name will be used by all socket functions. Note: The socket name is case sensitive.

**`<Port number>: (Integer)`**

Port number that will be given to the socket. This number must be between 1 and 65000. This number is specified when client computers connect to the server.
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) You must be "root" to create a socket on a port less than or equal to 1024 (being "root" means being the user who has all the permissions on the system). 

**`<Address>: (Optional character string)`**

IP address on which the socket must be created on the current computer. If the current computer is associated with several IP addresses (or with several network cards), this parameter enables you to choose the IP address that will be associated with the socket.

This IP address can have the following format:

- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).

- IP address containing the server name (e.g. www.windev.com). This syntax is recommended.

## Remarks


### Recreating a socket
<a name="recreating_socket_ELTPARAGRAPHE000102"></a>

If a socket is not closed properly by [SocketClose](../WDLang3/3070015.md) (restarting the computer for example), recreating the socket may take quite a long time. You will have to wait for the system to release the socket.

### Using an address that is already in use
<a name="using_address_that_already_use_ELTPARAGRAPHE000114"></a>

By default, **SocketCreate** allows you to use an address that is already used by the same application or by another application. To change this mode, write the following line of code:


```wl
Socket.Option = SocketNoReuseAddress
```


**Note**: This option also indicates whether an address or port is already in use. In this case, **SocketCreate** returns an error.

### Connecting to an infrared port
<a name="connecting_infrared_port_ELTPARAGRAPHE000131"></a>

To connect to a socket that uses an infrared port:

1. Create a socket using the infrared port on the server ([SocketCreateInfrared](../WDLang3/3070012.md) in a WINDEV application).

2. In the client application (WINDEV application), use [SocketConnectInfrared](../WDLang3/3070018.md) to connect to this socket.

This permission allows the applications to open the network sockets.
