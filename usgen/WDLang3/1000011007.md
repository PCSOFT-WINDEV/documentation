
## AppointmentNext (Function)

***In french: RendezVousSuivant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads the appointment after the current appointment in a Lotus Notes or Outlook calendar.

When reading an appointment, the data of this appointment is updated in the [Appointment structure](../WDLang3/1000011010.md). To retrieve the data of the current appointment, simply retrieve the values from the [Appointment structure](../WDLang3/1000011010.md).

**Reminder** This function does not allow you to read the appointment following the current one in the Outlook Express calendar.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf", "C:\Lotus Notes\julia.id")
// Read the first appointment
AppointmentFirst(SessionID)
// Add the appointments found into a List Box control
WHILE mAppointment.Out = False
	ListAdd(LIST_APTList, mAppointment.Subject + TAB + mAppointment.Location)
	AppointmentNext(SessionID)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = AppointmentNext(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the next appointment was read, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant. 




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The mAppointment.Out variable allows you to find out whether there is a current appointment.

- In Outlook, the management mode of contacts/participants can be specified when starting the session ([EmailStartOutlookSession](../WDLang3/3032128.md) or [OutlookStartSession](../WDLang3/3032123.md)).
