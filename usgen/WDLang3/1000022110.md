


## BTLEInitialize (Function)

***In french: BTLEInitialise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes Bluetooth Low Energy.
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function must be called before any other WLanguage function for managing Bluetooth Low Energy.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This function is useless in Android. The initialization is automatically performed. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
BTLEInitialize(InitBTLE)

	INTERNAL PROCEDURE InitBTLE(nStatus is int)
		IF nStatus = btEnabled THEN
			BTLEListDevice(ScanBTLE)
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`BTLEInitialize(<WLanguage procedure>)`
---

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure (called "callback") called when Bluetooth Low Energy is initialized on the device. This procedure has the following format: 

```txt
PROCEDURE <Procedure name> (<Status of Bluetooth Low Energy>)
```

where &lt;Status of Bluetooth Low Energy&gt; corresponds to the activation status of Bluetooth Low Energy on the device. This status can correspond to one of the following constants (integer type): 



|   |   |
| --- | --- |
| *btActivationInProgress* | The Bluetooth is being enabled on the device.<br><br>![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) This constant is not available. |
| *btDeactivationInProgress* | The Bluetooth is being disabled on the device.<br><br>![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) This constant is not available. |
| *btDisabled* | The Bluetooth is disabled on the device. |
| *btEnabled* | The Bluetooth is enabled on the device. |

## Remarks


- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If Bluetooth Low Energy is not available (iOS version earlier than version 9.0), the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and [ErrorInfo](../WDLang1/3013008.md) returns more details about the problem.

- **Necessary versions**
	

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Applications ANDROID**: 

		- Bluetooth Low Energy WLanguage functions are only available on devices with Android 4.3 or later (api level 18). 

		- A fatal error occurs if the function is used with an earlier system version. 

		- To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).




- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **iOS applications**: 
			The WLanguage Bluetooth Low Energy functions are available for the devices running iOS 9. 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) **Applications WINDEV**: 

	- Bluetooth Low Energy WLanguage functions are only available on:  

		- PCs that support at least Bluetooth Low Energy 5. 

		- PCs using a Bluetooth device that supports at least Bluetooth Low Energy 5.
