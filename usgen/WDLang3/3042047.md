


## grLegend (Function)

***In french: grLégende***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the presence and position of legend in a chart.

Example of legend in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=grLegende.gif)


**Remark**: The legend groups together the colors and labels of the series (or sectors) of a chart.. 



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart created programmatically
grCreate("MyChart", grColumn)
grDestinationWnd("MyChart", "", "Title of the window")
// The legend is displayed on the right of "MyChart"
grLegend("MyChart", grAtRight)
...
grDraw("MyChart")
```
<a name="Exemple2"></a>

```wl
// Using a Chart control
// The legend is displayed on the left of CHART_MyChart
grLegend(CHART_MyChart, grAtLeft)
...
grDraw(CHART_MyChart)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grLegend(<Chart name> , <Position>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Position>: (Integer)`**

Position of chart legend:


|   |   |
| --- | --- |
| *grAtBottom* | Legend displayed below the chart. |
| *grAtLeft* | Legend displayed on the left of chart. |
| *grAtRight* | Legend displayed on the right of chart. |
| *grAtTop* | Chart legend displayed above the chart. |
| *grNone* | No legend. |

## Remarks


### Chart legend
<a name="chart_legend_ELTPARAGRAPHE000146"></a>The set of series labels correspond to the chart legend.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=214&name=EtiquetteSerie.gif)
Serial labels cannot be used with Pie charts.

Series labels are defined with [grSeriesLabel](../WDLang3/3042024.md). 

The legend font can be changed with [grLegendFont](../WDLang3/3042037.md).  

**grLegend** indicates the presence and position of the legend (i. e. all series labels). Any changes made with **grLegend** will take effect the next time [grDraw](../WDLang3/3042026.md) is called. You can change the position of the chart legend via a context menu.

**Note** To define series labels for "Scatter charts", use the [grScatterSeriesLabel](../WDLang3/3042038.md) function. For more details, see [Legends of a chart](../WDChamp/3042069.md). 
<a name="NOTE0_2"></a>


### Manual legend positioning: grLegend without effect
<a name="manual_legend_positioning_grlegend_without_effect_ELTPARAGRAPHE000184"></a>

**grLegend** has no effect if the legend is positioned manually ("Manual positioning" in the chart legend window).
