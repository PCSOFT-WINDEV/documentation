
## ProximityShareStopAll (Function)

***In french: NearbyShareStopAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stop the current proximity share(s): 

- stop waiting for connection, 

- stop searching for remote devices, 

- disconnect all currently connected devices.s
