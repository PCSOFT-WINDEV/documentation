


## grSurfaceMaillage (Fonction)

***En anglais : grSurfaceMesh***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active ou désactive le maillage sur un graphe de type Surface. 

**Remarque** : Le maillage d'un graphe de type Surface peut également être activé/désactivé dans la fenêtre de description du champ Graphe (option "Afficher un maillage sur la surface" dans l'onglet "Général" de la description du champ). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
grSurfaceMaillage(GRF_Graphe1, Vrai, BleuFoncé)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grSurfaceMaillage(<Nom du graphe> , <Maillage> , <Couleur>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe de type Surface à manipuler. Ce nom peut correspondre :

- au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- au nom du champ Graphe (présent dans l'éditeur de fenêtres ou d'états).




**`<Maillage> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> pour activer le maillage. 

- <u><u><u><u>Faux</u></u></u></u> pour désactiver le maillage. 




**`<Couleur> : (Entier ou constante de type Entier)`**

Couleur du maillage. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](../WDLang5/3010002.md)).
