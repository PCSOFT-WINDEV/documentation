


## zipFinAjoutFichier (Fonction)

***En anglais : zipEndAddingFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Termine une série d'ajouts optimisés de fichiers dans une archive.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Début des ajouts optimisés de fichiers
zipDébutAjoutFichier(MonArchive)
// Ajout des fichiers dans l'archive
POUR TOUT CheminFichier DE tabListeFichier
	zipAjouteFichier(MonArchive, CheminFichier)
FIN
// Fin ajouts optimisés de fichiers 
zipFinAjoutFichier(MonArchive)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = zipFinAjoutFichier(<Archive>)`
---

**`<Résultat> : (Entier)`**



- 0 si la déclaration de la fin d'ajout de fichiers a été effectuée,

- un code d'erreur (valeur supérieure à 0) dans le cas contraire. Pour plus de détails sur ces codes d'erreur, consultez les remarques.




**`<Archive> : (Chaîne de caractères ou variable de type zipArchive)`**

Nom de l'archive à manipuler.
Ce nom peut correspondre :

- soit au nom d'une archive défini avec la fonction [zipOuvre](../WDLang3/3082044.md) ou [zipCrée](../WDLang3/3082003.md).

- soit au nom d'une variable de type [zipArchive](../WDLang3/1000018679.md).

## Remarques


### Dans quels cas utiliser l'ajout optimisé de fichiers dans une archive
<a name="dans_quels_cas_utiliser_ajout_optimise_fichiers_dans_une_archive_ELTPARAGRAPHE000070"></a>Pour les archives de type ZIP, WDZ et 7Z, certaines opérations permettant d'obtenir une archive valide sont effectuées lors de chaque ajout. Ces opérations peuvent influer sur le temps de création d'une archive. 

Ainsi, une succession d'ajouts de fichiers via la fonction [zipAjouteFichier](../WDLang3/3082008.md) est plus chronophage que l'ajout de ces mêmes fichiers via la fonction [zipAjouteListeFichier](../WDLang3/3082038.md). En effet, avec la fonction [zipAjouteListeFichier](../WDLang3/3082038.md), les opérations de vérification ne sont effectuées qu'une seule fois. 

Pour obtenir un comportement similaire en utilisant la fonction [zipAjouteFichier](../WDLang3/3082008.md), il est nécessaire de réaliser les ajouts entre les fonctions [zipDébutAjoutFichier](../WDLang3/1410091114.md) et **zipFinAjoutFichier**. 

Remarque : Cette fonction n'est pas utilisable sur les archives de type RAR et n'est utile que pour les archives de type ZIP, WDZ et 7Z.


### Comment utiliser les ajouts optimisés ? 
<a name="comment_utiliser_les_ajouts_optimises_ELTPARAGRAPHE000101"></a>Pour réaliser des ajouts optimisés : 

1. Appelez la fonction [zipDébutAjoutFichier](../WDLang3/1410091114.md). L'archive est en attente de l'ajout des fichiers. 

2. Utilisez la fonction [zipAjouteFichier](../WDLang3/3082008.md) pour ajouter les différents fichiers voulus. Toutes les caractéristiques de cette fonction restent valables. 

3. Terminez l'ajout des fichiers avec la fonction **zipFinAjoutFichier**. 




Remarques : 

- Tout appel à une fonction autre que [zipAjouteFichier](../WDLang3/3082008.md) sur l'archive entre un appel aux fonctions [zipDébutAjoutFichier](../WDLang3/1410091114.md) et **zipFinAjoutFichier** provoquera une erreur fatale.

- Il est obligatoire d'utiliser la fonction **zipFinAjoutFichier** après la fonction [zipAjouteFichier](../WDLang3/3082008.md) pour obtenir une archive valide. 





### Codes d'erreur 
<a name="codes_erreur_ELTPARAGRAPHE000141"></a>Les codes d'erreur retournés sont les suivants :

- 1 : Le chemin passé en paramètre n'existe pas.

- 3 : L'archive est corrompue.
