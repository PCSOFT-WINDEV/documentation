
## PartageProximitéDéconnecte (Fonction)

***En anglais : NearbyShareDisconnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme la connexion avec un appareil distant.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéDéconnecte(gAppareilSélectionné.ID)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéDéconnecte(<Identifiant de l'appareil>)`
---

**`<Identifiant de l'appareil> : (Chaîne de caractères)`**

Identifiant de l'appareil distant pour lequel la connexion doit être fermée.
