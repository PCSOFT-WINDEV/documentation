


## &lt;Variable ActionRapide&gt;.Supprime (Fonction)

***En anglais : &lt;QuickAction variable&gt;.Remove***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une action rapide de l'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
action est une ActionRapide
action.Identifiant = "ID_ACTION_ENVOI_MESSAGE"
action.Libellé = "Envoyer un message"
action.Procédure = "ProcEnvoiMessage" // ProcEnvoiMessage est une procédure globale
action.Ajoute()
// ...
action.Supprime()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Action>.Supprime()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'action rapide a été supprimée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.




**`<Action> : (Variable de type ActionRapide)`**

Variable de type [ActionRapide](../WDLang3/1410090054.md) décrivant l'action à supprimer
