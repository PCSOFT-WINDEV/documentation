


## zipFerme (Fonction)

***En anglais : zipClose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme une archive.

## Syntaxe

`zipFerme(<Archive>)`
---

**`<Archive> : (Chaîne de caractères ou variable de type zipArchive)`**

Nom de l'archive à manipuler.
Ce nom peut correspondre :

- soit au nom d'une archive défini avec la fonction [zipOuvre](../WDLang3/3082044.md) ou [zipCrée](../WDLang3/3082003.md).

- soit au nom d'une variable de type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Les variables de type [zipArchive](../WDLang3/1000018679.md) ne sont pas disponibles en JAVA.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000115"></a>

- La fermeture d'une archive ne peut être réalisée que si :

	- L'archive est ouverte. L'ouverture d'une archive s'effectue avec la fonction [zipOuvre](../WDLang3/3082044.md).

	- L'archive existe. La création d'une archive s'effectue avec la fonction [zipCrée](../WDLang3/3082003.md).




- A l'arrêt de l'application, toutes les archives manipulées seront automatiquement fermées.

- Une erreur du WLangage est affichée si l'archive à fermer n'existe pas. Le programme est alors arrêté.
