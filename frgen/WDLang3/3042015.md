


## grEtiquetteCatégorie (Fonction)

***En anglais : grCategoryLabel***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de : 

- Initialiser l'étiquette d'une catégorie de données (ou d'un secteur) d'un graphe. 
	![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Non disponible.

- Connaître l'étiquette d'une catégorie de données (ou d'un secteur) d'un graphe.




Exemple d'étiquette de catégorie :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteCat.gif)


**Rappel** : Par défaut, un élément de graphe n'a aucune étiquette.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Initialisation de l'étiquette "Février" de la seconde catégorie de données
// dans le graphe "MonGraphe"
grEtiquetteCatégorie("MonGraphe", 2, "Février")
```
<a name="Exemple2"></a>

```wl
// Initialisation de l'étiquette "Février" de la seconde catégorie de données
// dans le graphe "GRF_MonGraphe"
grEtiquetteCatégorie(GRF_MonGraphe, 2, "Février")
```
<a name="Exemple3"></a>

```wl
// Lecture de l'étiquette de la seconde catégorie de données
// dans le graphe "GRF_MonGraphe"
MonEtiquette est une chaîne = grEtiquetteCatégorie(GRF_MonGraphe, 2)
```

## Syntaxe
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Non disponible en code navigateur
### Initialiser l'étiquette d'une catégorie de données (ou d'un secteur) d'un graphe

`grEtiquetteCatégorie(<Nom du graphe> , <Indice> , <Étiquette>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Indice> : (Entier)`**

Indice de la donnée dans la série.

**`<Étiquette> : (Chaîne de caractères)`**

Libellé de l'étiquette à initialiser. 
Ce paramètre peut également correspondre à une durée, une date, une heure ou une date-heure. 
**Note** : Si vous utilisez une échelle des abscisses temporelle, il est nécessaire d'appeler la fonction **grEtiquetteCatégorie** systématiquement à chaque ajout de données dans le graphe avec la fonction [grAjouteDonnée](../WDLang3/3042023.md).


<a name="SYNTAXE2"></a>

### Connaître l'étiquette d'une catégorie de données (ou d'un secteur) d'un graphe

`<Résultat> = grEtiquetteCatégorie(<Nom du graphe> , <Indice>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Libellé de l'étiquette.

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Indice> : (Entier)`**

Indice de la donnée (dont l'étiquette est recherchée) dans la série.

## Remarques


### Gestion des étiquettes de catégories
<a name="gestion_des_etiquettes_categories_ELTPARAGRAPHE000207"></a>Les étiquettes de catégories sont affichées :

- sous les graduations horizontales pour les graphes de type courbe ou les graphes boursiers de type Chandelier japonais et BarCharts,

- sous l'axe des X pour les histogrammes ou les graphes de type boursier Minimum/Maximum.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteCat.gif)
Les étiquettes de catégories ne sont pas utilisables avec les graphes de type Nuage de points.

La position des étiquettes de catégorie ne peut pas être modifiée. 

La définition des étiquettes de catégories est réalisée avec la fonction **grEtiquetteCatégorie**.

Les données définies avec la fonction **grEtiquetteCatégorie** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).

Il est possible de modifier la police de l'étiquette grâce à la fonction [grPoliceEtiquette](../WDLang3/3042012.md).

Les étiquettes de catégories définies avec la fonction **grEtiquetteCatégorie** peuvent être affichées dans le libellé du graphe de type Secteur (constante *grAfficheEtiquette* utilisée avec la fonction [grLibellé](../WDLang3/3042046.md)).
