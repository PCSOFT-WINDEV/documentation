


## &lt;Variable Drive&gt;.DéplaceFichier (Fonction)

***En anglais : &lt;Drive variable&gt;.MoveFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déplace un fichier du drive (disque distant) vers un autre répertoire du même drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI oDrive.DéplaceFichier("/MesRépertoires/Fichier.txt", "/Sauvegardes/") = Faux ALORS
	Erreur("Impossible de déplacer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Drive>.DéplaceFichier(<Fichier à déplacer> , <Répertoire destination>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été déplacé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, le déplacement n'est pas réalisé.

**`<Fichier à déplacer> : (Chaîne de caractères)`**

Chemin absolu du fichier à déplacer. Si ce paramètre ne correspond pas à un chemin de fichier valide, l'élément ne sera pas déplacé.

**`<Répertoire destination> : (Chaîne de caractères)`**

Chemin absolu du répertoire destination. Si ce paramètre ne correspond pas à un chemin valide, l'élément ne sera pas déplacé. Les répertoires manquants dans le chemin ne sont pas créés.

## Remarques


### Paramètre &lt;Répertoire destination&gt;
<a name="parametre_ELTPARAGRAPHE000206"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
