


## grTypePointSérie (Fonction)

***En anglais : grSeriesPointType***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la forme du point d'une série dans un graphe de type Courbe, Aire, Nuage de points et Radar.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Transforme tous les points de la série 1 en cercle
grTypePointSérie(GRF_MonGraphe, 1, grPointCercle)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grTypePointSérie(<Nom du graphe> , <Numéro de la série> , <Type>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe (présent dans l'éditeur de fenêtres ou d'états).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la série> : (Entier)`**

Numéro de la série dans laquelle le type de point doit être modifié.

**`<Type> : (Constante de type Entier)`**

Nouveau type de point de la catégorie : 


|   |   |
| --- | --- |
| *grNonDessiné* | Les points ne sont pas dessinés. |
| *grPointCarré* | Point en forme de carré. |
| *grPointCercle* | Point en forme de cercle. |
| *grPointCroix* | Point en forme de croix. |
| *grPointLosange* | Point en forme de losange. |
| *grPointTriangle* | Point en forme de triangle. |
