


## Fonctions FTP Standard
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
 


Les fonctions de gestion du FTP sont les suivantes:



|   |   |
| --- | --- |
| [FTPAttribut](../WDLang3/3040006.md) | Identifie les attributs d'un fichier présent sur un serveur FTP (File Transfer Protocol). |
| [FTPCommande](../WDLang3/3040017.md) | Envoie une commande FTP spécifique à un serveur. |
| [FTPConnecte](../WDLang3/3040016.md) | Connecte le poste en cours à un serveur FTP (File Transfer Protocol). |
| [FTPDate](../WDLang3/3040015.md) | Renvoie les différentes dates (date de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). |
| [FTPDateHeure](../WDLang3/1000020946.md) | Renvoie les différentes dates et heures (de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). |
| [FTPDéconnecte](../WDLang3/3040011.md) | Ferme la connexion entre le poste en cours et le serveur FTP (File Transfer Protocol). |
| [FTPEnvoie](../WDLang3/3040014.md) | Transfère un fichier ou un répertoire sur un serveur FTP (File Transfer Protocol). |
| [FTPFichierExiste](../WDLang3/1000020948.md) | Teste l'existence d'un fichier sur un serveur FTP. |
| [FTPHeure](../WDLang3/3040013.md) | Renvoie les différentes heures (heure de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). |
| [FTPListeFichier](../WDLang3/3040018.md) | Liste les fichiers d'un répertoire (et/ou les répertoires) d'un serveur FTP et retourne le nombre de fichiers (et/ou de répertoires) listés. |
| [FTPNom](../WDLang3/3040019.md) | Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol). |
| [FTPParamètre](../WDLang3/1000020947.md) | Modifie le comportement des fonctions FTP standard. |
| [FTPProxy](../WDLang3/1000019366.md) | Spécifie si les fonctions de communication utilisant le protocole FTP doivent ou non passer par un proxy pour exécuter leurs requêtes. |
| [FTPRécupère](../WDLang3/3040002.md) | Transfère un fichier ou un répertoire d'un serveur FTP (File Transfer Protocol) sur le poste en cours. |
| [FTPRécupèreFichier](../WDLang3/1000024597.md) | Transfère un fichier d'un serveur FTP (File Transfer Protocol) sur le poste en cours.<br><br> |
| [FTPRenommeFichier](../WDLang3/3040005.md) | Renomme ou déplace un fichier présent sur un serveur FTP (File Transfer Protocol). |
| [FTPRepCrée](../WDLang3/3040001.md) | Crée un répertoire sur un serveur FTP (File Transfer Protocol). |
| [FTPRepEnCours](../WDLang3/3040003.md) | Identifie ou modifie le répertoire en cours sur un serveur FTP (File Transfer Protocol). |
| [FTPRepExiste](../WDLang3/1410091242.md) | Permet de savoir si un répertoire existe sur un serveur FTP (File Transfer Protocol).<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [FTPRepSupprime](../WDLang3/3040008.md) | Supprime un répertoire et son contenu (fichiers et sous-répertoires) d'un serveur FTP (File Transfer Protocol). |
| [FTPSupprimeFichier](../WDLang3/3040010.md) | Supprime un fichier d'un serveur FTP (File Transfer Protocol). |
| [FTPTaille](../WDLang3/3040007.md) | Renvoie la taille (en octets) d'un fichier présent sur un serveur FTP (File Transfer Protocol). |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Attention**: Les fonctions FTP ne peuvent pas être utilisées dans l'émulateur Android.
Les fonctions FTP manipulent désormais une variable de type [ftpConnexion](../WDLang3/1410090869.md) contenant les différents paramètres de la connexion FTP à utiliser.
