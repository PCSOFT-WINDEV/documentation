


## &lt;Graphe&gt;.VignetteCatégorie (Fonction)

***En anglais : &lt;Chart&gt;.CategoryThumbnail ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise une image de catégorie dans les graphes de type Secteur, Beignet ou Hémicycle.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=grVignetteCat%E9gorie%20-%20HC%20N%B0001.gif&type=thumb)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
GRF_Consommation.SupprimeTout()
GRF_Consommation.AjouteDonnée(1, 1, 35)
GRF_Consommation.EtiquetteCatégorie(1, "Chauffage")
GRF_Consommation.VignetteCatégorie(1, IMG_Chauffage)
GRF_Consommation.CouleurCatégorie(1, HTMLVersRVB("#FF5722"))

GRF_Consommation.AjouteDonnée(1, 2, 20)
GRF_Consommation.EtiquetteCatégorie(2, "Eau")
GRF_Consommation.VignetteCatégorie(2, IMG_Eau)
GRF_Consommation.CouleurCatégorie(2, HTMLVersRVB("#2196F3"))

GRF_Consommation.AjouteDonnée(1, 3, 12)
GRF_Consommation.EtiquetteCatégorie(3, "Recharge voiture")
GRF_Consommation.VignetteCatégorie(3, IMG_Voiture)
GRF_Consommation.CouleurCatégorie(3, HTMLVersRVB("#8BC34A"))

GRF_Consommation.AjouteDonnée(1, 4, 18)
GRF_Consommation.EtiquetteCatégorie(4, "Électroménager")
GRF_Consommation.VignetteCatégorie(4, IMG_Electromenager)
GRF_Consommation.CouleurCatégorie(4, HTMLVersRVB("#9C27B0"))

GRF_Consommation.Dessine()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Graphe>.VignetteCatégorie(<Indice> , <Image>)`
---

**`<Champ Graphe> : (Nom de champ)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.

**`<Indice> : (Entier)`**

Indice de la donnée dans la série.

**`<Image> : (Chaîne de caractères ou variable de type Image)`**

Image de la catégorie. Cette image peut correspondre à : 

- une rubrique mémo, 

- le chemin d'un fichier image (ou juste son nom si l'image est présente dans le répertoire de l'exécutable), 

- un nom du champ Image contenant une image. 

- une variable de type [Image](../WDLang1/1000019650.md).






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- L'image est réduite pour être affichée dans la portion. Si la taille de l'image est trop petite ou si la portion dans laquelle l'image doit être affichée est trop petite, l'image n'est pas affichée. 

- Par défaut, si le graphe est redimensionné, la vignette n'est pas redimensionnée. Pour gérer l'agrandissement de la vignette, il est nécessaire d'utiliser la fonction [&lt;Graphe&gt;.Paramètre](../WDLang3/1000024115.md) avec la constante *grVignetteAvecAgrandissement*. 

- Il est possible d'afficher à la fois l'image et le libellé de la catégorie. 

- La fonction [&lt;Graphe&gt;.MAJAutomatiqueEtiquetteCatégorie](../WDLang3/1000024091.md) n'a pas d'impact sur l'affichage des vignettes de catégories.
