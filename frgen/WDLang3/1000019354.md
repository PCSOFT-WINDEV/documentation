
## WiFiEtat (Fonction)

***En anglais : WiFiStatus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'état actuel d'activation du Wi-Fi sur l'appareil ou demande à être notifié des changements d'état d'activation du Wi-Fi.

**Remarques** : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Pour activer ou désactiver le Wi-Fi sur l'appareil, utilisez la fonction [WiFiActive](../WDLang3/1000019350.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) L'accès Wi-Fi n'est pas disponible dans l'émulateur Android.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Attention : Cette fonctionnalité est disponible jusqu'à Android 9. A partir d'Android 10, cette information n'est plus accessible : cette fonction provoque une erreur fatale. Il est conseillé de tester la version d'Android utilisée via la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître l'état actuel d'activation du Wi-Fi sur le poste en cours

`<Résultat> = WiFiEtat()`
---

**`<Résultat> : (Entier)`**

Etat actuel d'activation du Wi-Fi :


|   |   |
| --- | --- |
| *wifiActif* | Le Wi-Fi est activé sur l'appareil. |
| *wifiActivationEnCours* | Le Wi-Fi est en cours d'activation sur l'appareil.<br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette constante n'est pas disponible. |
| *wifiDésactivationEnCours* | Le Wi-Fi est en cours de désactivation sur l'appareil.<br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette constante n'est pas disponible. |
| *wifiDésactivé* | Le Wi-Fi est désactivé sur l'appareil. |
| *wifiErreur* | L'état d'activation du Wi-Fi n'a pas pu être récupéré.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette constante ne correspond pas à une option possible. |




<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 
### Activer la notification des changements d'activation du Wi-Fi

`WiFiEtat(<Procédure WLangage>)`
---

**`<Procédure WLangage> : (Nom de procédure)`**

Procédure WLangage (également nommée "callback") appelée lorsque l'état d'activation du Wi-Fi sur l'appareil change. 

Cette procédure est de la forme : 

```txt
PROCEDURE <Nom de la procédure> (<Nouvel état>, <Ancien état>)
```
où : 

- &lt;Nouvel état&gt; est un entier correspondant au nouvel état d'activation du Wi-Fi sur l'appareil 

- &lt;Ancien état&gt; est un entier correspondant à l'état d'activation du Wi-Fi sur l'appareil avant le changement d'état.




Les paramètres de cette procédure sont optionnels. Il n'est pas nécessaire de passer de paramètres à cette procédure. En effet, ces paramètres sont renseignés automatiquement à chaque appel.

Si ce paramètre vaut chaîne vide (""), les notifications de changement d'état ne seront plus envoyées. Si aucune demande de notification n'a été effectuée, la fonction est sans effet.

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000117"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise :  ACCESS_WIFI_STATE

Cette permission permet aux applications d'accéder à des informations concernant les réseaux Wi-Fi.
