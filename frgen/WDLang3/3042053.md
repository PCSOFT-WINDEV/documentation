


## grSecteurPartExcentrée (Fonction)

***En anglais : grPiePullOut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Excentre une part ou toutes les parts d'un graphe. Cette fonction est utilisable sur les graphes de type Secteur, les graphes de type Beignet (donut) et les graphes de type Hémicycle.

Exemple de part excentrée dans un graphe : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=grSecteurPartExcentr%E9e%20-%20HC%20N%B0002.gif)


**Remarque** : Chaque part du graphe peut être excentrée indépendamment des autres.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Décalage de la seconde part du graphe "MonGraphe" de 10 pixels
// (Graphe créé par programmation)
grSecteurPartExcentrée("MonGraphe", 2, 10)
```
<a name="Exemple2"></a>

```wl
// Décalage de la troisième part du graphe "GRF_MonGraphe" de 20 pixels
grSecteurPartExcentrée(GRF_MonGraphe, 3, 20)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Excentrage d'une part

`grSecteurPartExcentrée(<Nom du graphe> , <Indice de la part> , <Décalage>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Indice de la part> : (Entier)`**

Indice de la part à excentrer.

**`<Décalage> : (Entier)`**

Décalage de la part spécifiée (en pixels).  


<a name="SYNTAXE2"></a>

### Excentrage de toutes les parts

`grSecteurPartExcentrée(<Nom du graphe> , <Décalage>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Décalage> : (Entier)`**

Décalage des différentes parts (en pixels).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Le décalage d'une part d'un graphe est sans effet sur les graphes autres que les graphes de type Secteur, les graphes de type Beignet (donut) et les graphes de type Hémicycle.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Les graphes de type Hémicycle ne sont pas disponibles.

- Les modifications effectuées avec la fonction **grSecteurPartExcentrée** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).
