


## &lt;Carte&gt;.SupprimeMarqueur (Fonction)

***En anglais : &lt;Map&gt;.DeleteMarker***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un marqueur d'une carte affichée par un champ Carte. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Remarque** : Cette fonction est disponible dans l'émulateur Android et dans le simulateur Android.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression d'un marqueur
MonMarqueur est un Marqueur
MonMarqueur.Nom = "Destination"
MonMarqueur.Position.Latitude = 43.613708 
MonMarqueur.Position.Longitude = 3.876972

SI INT_AfficheMaDestination = Vrai ALORS
	CARTE_Position.AjouteMarqueur(MonMarqueur)
SINON
	CARTE_Position.SupprimeMarqueur(MonMarqueur)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Champ Carte>.SupprimeMarqueur([<Marqueur>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le marqueur a pu être supprimé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Champ Carte> : (Nom de champ)`**

Nom du champ Carte à manipuler.

**`<Marqueur> : (Variable de type Marqueur ou chaîne de caractères optionnelle)`**

Marqueur à supprimer. Ce paramètre peut correspondre : 

- à une variable de type [Marqueur](../WDLang3/1000019940.md) correspondant au marqueur à supprimer. 

- à une chaîne de caractères correspondant au nom du marqueur à supprimer. Ce nom correspond à la propriété **Nom** de la variable de type [Marqueur](../WDLang3/1000019940.md).




Si ce paramètre n'est pas spécifié, tous les marqueurs de la carte seront supprimés (équivalent à la fonction [&lt;Carte&gt;.SupprimeTout](../WDLang3/1000022472.md)).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Seul un marqueur précédemment ajouté au champ Carte peut être supprimé. 

- Pour ajouter un nouveau marqueur dans un champ Carte, utilisez la fonction [&lt;Carte&gt;.AjouteMarqueur](../WDLang3/1000022422.md).

- Pour modifier un marqueur affiché dans un champ Carte, utilisez la fonction [&lt;Carte&gt;.ModifieMarqueur](../WDLang3/1000022383.md).
