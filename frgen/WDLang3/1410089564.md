


## DriveEnvoieRépertoire (Fonction)

***En anglais : DriveUploadDirectory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Envoie un répertoire et ses fichiers (présents sur la machine de l'utilisateur) vers un drive (disque distant).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"
// Connexion au drive OneDrive
oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)
// Sélection et envoi du répertoire
sRépertoire est une chaîne
sRépertoire = fRepSélecteur(fRepExe(), "Répertoire local à envoyer")
SI DriveEnvoieRépertoire(oDrive, sRépertoire, "/A vérifier") = Faux ALORS
	Erreur("Impossible d'envoyer le répertoire demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = DriveEnvoieRépertoire(<Drive> , <Répertoire à envoyer> , <Répertoire destination>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire a été envoyé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, le répertoire n'est pas envoyé. 

**`<Répertoire à envoyer> : (Chaîne de caractères)`**

Chemin absolu du répertoire présent sur le poste local et devant être envoyé. Si ce paramètre ne correspond pas à un chemin valide, le répertoire et son contenu ne seront pas envoyés.

**`<Répertoire destination> : (Chaîne de caractères)`**

Chemin absolu du répertoire destination dans le drive. 

- Si ce paramètre ne correspond pas à un chemin valide, l'élément ne sera pas envoyé. 

- Les répertoires manquants dans le chemin ne sont pas créés.

- Si le répertoire existe déjà à l'emplacement indiqué dans le drive, il sera fusionné avec le répertoire envoyé.

## Remarques


### Dropbox
<a name="dropbox_ELTPARAGRAPHE000078"></a>Selon le type de compte Dropbox utilisé, les appels à cette fonction peuvent être considérés comme des transferts de données. Certains types de compte ont une limite pour les données transférées par mois. Pour plus de détails, consultez [https://www.dropbox.com/developers/reference/data-transport-limit](https://www.dropbox.com/developers/reference/data-transport-limit). 


### Paramètre &lt;Répertoire destination&gt;
<a name="parametre_ELTPARAGRAPHE000088"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
