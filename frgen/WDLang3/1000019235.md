
## telDialerCompose (Fonction)

***En anglais : tapiDialerCall***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre l'application de téléphonie (dialer) par défaut du téléphone et compose le numéro spécifié.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
telDialerCompose("0612345678")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = telDialerCompose(<Numéro de téléphone>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'application de téléphonie a été correctement lancée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. En cas d'erreur, il est possible d'obtenir le détail de l'erreur grâce à la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Numéro de téléphone> : (Chaîne de caractères)`**

Numéro de téléphone à composer. 
Si ce paramètre correspond à une chaîne vide (""), la fonction retournera <u><u><u><u>Faux</u></u></u></u>.
Attention : le numéro ne doit pas contenir d'espaces.

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000076"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Pour afficher l'écran de numérotation sans composer de numéro, utilisez la fonction [telDialerAffiche](../WDLang3/1000019236.md).

- Il n'est pas possible de déclencher automatiquement l'appel des numéros d'urgence.

- Il n'est pas possible de composer des codes USSD.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000232"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **telDialerCompose** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
