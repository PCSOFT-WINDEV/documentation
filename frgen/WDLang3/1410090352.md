


## &lt;Variable Drive&gt;.CréeFichier (Fonction)

***En anglais : &lt;Drive variable&gt;.CreateFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Crée un fichier sur un drive (disque distant).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"
oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI oDrive.CréeFichier("/MesRépertoires/Fichier.txt") = Faux ALORS
	Erreur("Impossible de créer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Drive>.CréeFichier(<Fichier à créer>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été créé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la création n'est pas réalisée.

**`<Fichier à créer> : (Chaîne de caractères)`**

Chemin absolu du fichier à créer. Si ce paramètre ne correspond pas à un chemin valide, l'élément ne sera pas créé. Les répertoires manquants dans le chemin ne sont pas créés.

## Remarques


### Paramètre &lt;Fichier à créer&gt;
<a name="parametre_ELTPARAGRAPHE000187"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
