
## Génération et réception d'un code SMS à usage unique
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000140"></a>
Dans une application mobile, la double authentification est un moyen standard pour identifier l'utilisateur. Un code de vérification est généralement envoyé par SMS. 

Vous pouvez maintenant récupérer directement ce code dans vos applications WINDEV Mobile. Cette fonctionnalité est également disponible via un Champ Métier prêt à l'emploi.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Principe
<a name="principe_ELTTEXTE000164"></a>
Pour mettre en place une authentification par un code SMS unique dans une application mobile, le principe est le suivant : 

- Mise en place d'un serveur "backend". 
	Ce serveur d'authentification permet de : 

	- vérifier l'identité de l'utilisateur, 

	- effectuer l'envoi du SMS, 

	- contrôler le code à usage unique lorsqu'il est renvoyé au serveur pour effectuer toutes les tâches de post-validation requises. 




- L'application mobile doit : 

	- Récupérer le code présent dans le SMS. 

	- Demander la vérification du code au serveur "backend". 







Remarque : La communication entre l'application mobile et le serveur est libre. 
Une solution possible consiste à exposer une API REST avec deux points de terminaison : 

- un qui reçoit les requêtes de demande de validation avec les informations d'identification de l'utilisateur et envoie les messages par SMS au format attendu. 

- un qui reçoit le code à usage unique reçu par l'application pour des traitements supplémentaires.

## Fonctionnalité du serveur "backend"
<a name="fonctionnalite_serveur_backend_ELTTEXTE000188"></a>


### Format du SMS
<a name="format_sms_ELTPARAGRAPHE000044"></a>Le SMS contenant le code à usage unique doit respecter les critères suivants : 

- sa taille ne soit pas dépasser 140 octets. 

- il doit contenir un code à usage unique. Ce code doit être une suite de 4 à 10 chiffres (6 caractères minimum recommandé), sans séparateurs. 

- il doit se terminer par une chaîne de 11 caractères qui identifie votre application.




**Exemple** : 

```txt
Votre code d'authentification est : 123456
HQ+6aVM7NXq
```


**Remarque** : La chaîne à la fin du SMS est une chaîne de hachage composée des élément suivants : 

- le nom du package de l'application. 

- le certificat de clé publique de l'application. 


Vous pouvez trouver cette chaîne dans l'assistant de génération Android lorsque la fonction [SMSDétecteCodeUsageUnique](../WDLang3/1410090437.md) est présente dans le code de l'application. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=SMSDetecteCodeUsageUnique%20-%20HC%20N%B0001.gif)

Vous pouvez également générer cette chaîne avec l'outil keytool. Pour plus de détails, consultez [Outil keytool](https://developers.google.com/identity/sms-retriever/verify?hl=fr#computing_your_apps_hash_string).




### Génération du code envoyé via le SMS
<a name="generation_code_envoye_via_sms_ELTPARAGRAPHE000050"></a>Il est conseillé de générer une suite de 6 à 10 chiffres aléatoire et de le stocker dans une table de base de données en associant ce code à un identifiant d'utilisateur et à une date d'expiration.

## Mise en place dans l'application mobile
<a name="mise_place_dans_application_mobile_ELTTEXTE000244"></a>


### Récupération du code présent dans le SMS
<a name="recuperation_code_present_dans_sms_ELTPARAGRAPHE000060"></a>La récupération du code reçu par SMS est effectuée via la fonction [SMSDétecteCodeUsageUnique](../WDLang3/1410090437.md). L'appel de cette fonction déclenche l'écoute pendant 5 minutes des SMS reçus sur le téléphone. Si durant ce délai un SMS contenant un code à usage unique est reçu, la procédure passée à la fonction est automatiquement exécutée avec le code reçu en paramètre et la détection est arrêtée. 


### Vérification du code présent dans le SMS
<a name="verification_code_present_dans_sms_ELTPARAGRAPHE000068"></a>La vérification du code présent dans le SMS peut être effectuée par la procédure exécutée par la fonction [SMSDétecteCodeUsageUnique](../WDLang3/1410090437.md).

## Un champ métier pour votre application mobile
<a name="champ_metier_pour_votre_application_mobile_ELTTEXTE000274"></a>
Le champ Métier "Authentification par code à usage unique" propose une solution "prête à l'emploi" pour intégrer la lecture d'un code SMS dans votre application. 

Ce champ métier contient : 

- un bouton permettant de demander un code à usage unique. 
	ATTENTION : Dans le code de ce bouton, vous devez inclure l'appel au serveur "backend" qui va générer le code et l'envoyer par SMS. 
	Ce bouton déclenche également la détection du SMS. 

- un ensemble de champs de saisie qui vont contenir les différents chiffres du code reçu. 

- une procédure VerifierCode qui permet notamment de vérifier le code reçu. 
	ATTENTION : Dans le code de cette procédure, vous devez inclure un appel au serveur d'authentification "backend" pour vérifier le code.
