
## RendezVousModifie (Fonction)

***En anglais : AppointmentModify***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie le rendez-vous en cours : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) dans l'agenda d'une messagerie Lotus Notes ou Outlook.
	Lors de la lecture d'un rendez-vous, les données de ce rendez-vous sont mis à jour dans la [structure RendezVous](../WDLang3/1000011010.md). Pour modifier le rendez-vous en cours, il suffit de modifier les valeurs de la [structure RendezVous](../WDLang3/1000011010.md) et de valider les modifications avec la fonction **RendezVousModifie**.
	**Rappel** : Cette fonction ne permet pas de modifier le rendez-vous en cours dans l'agenda d'une messagerie Outlook Express.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) dans un calendrier (ou agenda) d'un appareil Android. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) dans un calendrier (ou agenda) d'un appareil iOS. 







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier rendez-vous
RendezVousDernier(IDSession)
// Modification du lieu
mRendezVous.Lieu = "Salle 5H"
RendezVousModifie(IDSession)
```




<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Rendez-vous à modifier
gRDV est un RendezVous
// ...

// Modification du rendez-vous
gRDV.Titre = SAI_Titre
gRDV.DateDébut = SAI_DateDeb + SAI_HeureDeb
gRDV.DateFin = SAI_DateFin + SAI_HeureFin
gRDV.Lieu = SAI_Lieu
gRDV.Contenu = SAI_Desc
SI SAI_Fuseau <> "" ALORS
	gRDV.FuseauHoraire = SAI_Fuseau
FIN
gRDV.Auteur = SAI_Auteur
gRDV.Invité = SAI_Invités
gRDV.JournéeEntière = INT_Jentière[1]

SI RendezVousModifie(gRDV) ALORS
	ToastAffiche("RDV modifié")
SINON
	Erreur(ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Modifier un rendez-vous dans l'agenda d'une messagerie Lotus Notes ou Outlook

`<Résultat> = RendezVousModifie(<Identifiant de la session> [, <Identifiant du rendez-vous>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la modification a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md). 




**`<Identifiant de la session> : (Entier)`**

Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](../WDLang3/3032121.md), [EmailOuvreSessionOutlook](../WDLang3/3032128.md), [NotesOuvreBase](../WDLang3/1000005101.md) ou [OutlookOuvreSession](../WDLang3/3032123.md).  

**`<Identifiant du rendez-vous> : (Chaîne de caractères optionnelle)`**

Identifiant du rendez-vous à modifier. Cet identifiant est contenu dans la variable mRendezVous.ID.

### Modifier un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS)

`<Résultat> = RendezVousModifie(<Rendez-vous>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la modification a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Rendez-vous> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) correspondant au rendez-vous à modifier dans le calendrier de l'appareil Android/iOS.
