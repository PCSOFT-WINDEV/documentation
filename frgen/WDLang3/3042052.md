


## grQuadrillage (Fonction)

***En anglais : grGridlines***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche ou rend invisible le quadrillage d'un graphe.

Exemple de quadrillage : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=quadrillage.gif)


**Rappel** : Par défaut, le quadrillage d'un graphe est invisible.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affichage du quadrillage vertical du graphe "MonGraphe"
grQuadrillage("MonGraphe", Vrai, grOrdonnée)
```
<a name="Exemple2"></a>

```wl
// Affichage du quadrillage horizontal du graphe GRF_MonGraphe
grQuadrillage(GRF_MonGraphe, Vrai, grAbscisse)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`grQuadrillage(<Nom du graphe> , <Affiche> , <Sens de l'axe>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Affiche> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le quadrillage doit être affiché, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Sens de l'axe> : (Constante ou combinaison de constantes de type Entier)`**

Axe utilisé pour le quadrillage : 



|   |   |
| --- | --- |
| *grAbscisse*<br>(valeur par défaut) | Graduations sur l'axe des abscisses (axe horizontal). |
| *grOrdonnée* | Graduations sur l'axe des ordonnées (axe vertical). |


La combinaison de ces deux constantes permet d'obtenir un quadrillage complet (vertical et horizontal).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Le quadrillage est pris en compte :

	- dans les graphes de type histogramme (constantes *grHisto* et *grHistoEmpilé*), nuage de points (constante *grNuage*), courbe (constante *grCourbe*) et boursier (constantes *grChandelier*, *grBarCharts* et *grMinMax*) lorsque le paramètre &lt;Sens de l'axe&gt; correspond à la constante *grAbscisse*.

	- dans les graphes de type nuage de points (constante *grNuage*), courbe (constante *grCourbe*) et boursier (constantes *grChandelier* et *grBarCharts*) lorsque le paramètre &lt;Sens de l'axe&gt; correspond à la constante *grOrdonnée*.




- Le quadrillage est sans effet sur les graphes de type secteur (constante *grSecteur*) ou entonnoir (constante *grEntonnoir*).

- Les données définies avec la fonction **grQuadrillage** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).
