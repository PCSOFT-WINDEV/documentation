


## FTPHeure (Fonction)

***En anglais : FTPTime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie les différentes heures (heure de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Renvoie l'heure de modification d'un fichier présent sur un serveur FTP (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003040013&name=ftpheure_fonction">Voir des exemples supplémentaires</a>

```wl
// Connaître l'heure de modification du fichier
// "/Documents/Fichier.txt" présent sur le serveur FTP
ResHeure = FTPHeure(7, "/Documents/Fichier.txt")
```
<a name="Exemple2"></a>

```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
FTPConnecte(MaConnexionFTP)

// Connaître l'heure de modification du fichier
// "/Documents/Fichier.txt" présent sur le serveur FTP
ResHeure = FTPHeure(MaConnexionFTP, "/Documents/Fichier.txt")
```

## Syntaxe
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Syntaxe non disponible en PHP
### Récupérer les différentes heures d'un fichier (connexion via un variable ftpConnexion)

`<Résultat> = FTPHeure(<Connexion FTP> [, <Nom du fichier>] [, <Type d'heure>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Heure demandée (au format HHMMSS). 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Seule l'heure de modification du fichier est disponible.

- Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) décrivant les caractéristiques de la connexion au serveur FTP. 


**`<Nom du fichier> : (Chaîne de caractères optionnelle)`**

Nom et chemin absolu (ou relatif) du fichier à manipuler. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/").  
**Si ce paramètre n'est pas spécifié**, la date renvoyée correspond à celle du dernier fichier accédé au moyen de l'une des fonctions FTP suivantes: [FTPDate](../WDLang3/3040015.md), [FTPHeure](../WDLang3/3040013.md), [FTPTaille](../WDLang3/3040007.md), [FTPListeFichier](../WDLang3/3040018.md). Dans ce cas, aucune requête n'est envoyée au serveur. Cette syntaxe est à privilégier dès que possible. 

**`<Type d'heure> : (Constante optionnelle)`**

Heure demandée:



|   |   |
| --- | --- |
| *ftpAccès* | Heure du dernier accès au fichier. |
| *ftpCréation* | Heure de création du fichier. |
| *ftpModification*<br>(Valeur par défaut) | Heure de dernière modification du fichier. |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Ce paramètre n'est pas disponible. Seule l'heure de modification du fichier spécifié est disponible.

## Remarques


### Délai
<a name="delai_ELTPARAGRAPHE000415"></a>

Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié: 

- lors de la connexion au serveur FTP avec la fonction [FTPConnecte](../WDLang3/3040016.md) (paramètre &lt;Durée de non réponse&gt;).

- lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
	



<a name="NOTE0_3"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000455"></a>

La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
<a name="NOTE0_4"></a>


### Chemin relatif et absolu
<a name="chemin_relatif_absolu_ELTPARAGRAPHE000216"></a>

Les notions de chemin relatif et de chemin absolu sont très importantes dans une application FTP.

- Un chemin commençant par un slash est considéré comme un **chemin absolu**: il s'agit du chemin par rapport à la racine du serveur FTP (paramètre propre au serveur).
	Exemple: /pub/user/JULIE

- Si le chemin ne commence pas par un slash, il est considéré comme un **chemin relatif**, c'est-à-dire le chemin par rapport au répertoire en cours. Ce répertoire en cours peut-être connu ou modifié avec la fonction [FTPRepEnCours](../WDLang3/3040003.md).


Lors de la connexion à un site FTP, le répertoire initial, le "home directory" de l'utilisateur n'est pas forcément la racine du serveur FTP. Il est donc conseillé d'utiliser des chemins relatifs.
