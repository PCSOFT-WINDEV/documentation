


## Fonctions SSH (syntaxe préfixée)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions (syntaxe préfixée) permettant de se connecter et de dialoguer avec un serveur SSH sont les suivantes : 



|   |   |
| --- | --- |
| [&lt;Variable sshSession&gt;.Commande](../WDLang3/1410091176.md) | Envoie une commande à un serveur SSH. La session est ouverte et refermée automatiquement après l'envoi de la commande. |
| [&lt;Variable sshSession&gt;.ConnecteCommande](../WDLang3/1410091177.md) | Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [&lt;Variable sshSession&gt;.Commande](../WDLang3/1410091176.md)) à un serveur SSH.<br><br> |
| [&lt;Variable sshSession&gt;.ConnecteShell](../WDLang3/1000021163.md) | Ouvre une nouvelle session SSH de type "Shell". |
| [&lt;Variable sshSession&gt;.DéconnecteCommande](../WDLang3/1410091178.md) | Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [&lt;Variable sshSession&gt;.DéconnecteShell](../WDLang3/1000021164.md) | Ferme une session SSH précédemment ouverte grâce à la fonction [&lt;Variable sshSession&gt;.ConnecteShell](../WDLang3/1000021163.md). |
| [&lt;Variable sshSession&gt;.Ecrit](../WDLang3/1000021166.md) | Ecrit des données dans la session SSH spécifiée. |
| [&lt;Variable sshSession&gt;.Lit](../WDLang3/1000021167.md) | Lit les données présentes sur le buffer de sortie de la session SSH. |



Remarque : Le protocole géré est SSH-2.
