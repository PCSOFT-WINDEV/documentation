


## &lt;Variable emailSessionIMAP&gt;.AbonneAuxDossiers (Fonction)

***En anglais : &lt;emailIMAPSession variable&gt;.SubscribeToFolder***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un dossier existant à la liste des dossiers abonnés. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXX"
session.MotDePasse = "XXXXXXX"
session.OuvreSession()

// Liste des dossiers de gestion des mails et des dossiers abonnés
res est chaîne
res = session.ListeDossier(LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
// Abonne le dossier "Test"
Trace("Abonnement : " + (session.AbonneAuDossier("Test") ? "OK" sinon "KO"))
Trace("---------------------------------------------------")
// Liste des dossiers de gestion des mails et des dossiers abonnés
// Le dossier Test est désormais listé
res = session.ListeDossier(LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Session IMAP>.AbonneAuDossier(<Dossier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le dossier spécifié a été abonné, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Session IMAP> : (Variable de type emailSessionIMAP)`**

Nom de la variable de type [emailSessionIMAP](../WDLang3/1000018957.md) correspondant à la session IMAP connectée au serveur de mails.

**`<Dossier> : (Chaîne de caractères)`**

Nom et chemin du dossier à ajouter dans la liste des dossiers abonnés.



<a name="NOTE0"></a>

## Remarques


- Les dossiers créés avec la fonction [&lt;Variable emailSessionIMAP&gt;.AjouteDossier](../WDLang3/1000022273.md) sont automatiquement abonnés. 

- La fonction [&lt;Variable emailSessionIMAP&gt;.ListeDossier](../WDLang3/1000022290.md) utilisée avec la constante *LstDossierNormal* liste les dossiers contenant les emails et les dossiers abonnés. Si un dossier abonné contient des sous dossiers, ces sous dossiers seront également listés. 

- La fonction [&lt;Variable emailSessionIMAP&gt;.ListeDossier](../WDLang3/1000022290.md) utilisée avec la constante *LstDossierTous* liste tous les dossiers (dossiers contenant les emails et dossiers abonnés ou non abonnés).
