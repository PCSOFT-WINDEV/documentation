


## PhotoLanceAppli (Fonction)

***En anglais : PhotoRunApp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance l'application caméra native de l'appareil afin de prendre une photo.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
sPhoto est une chaîne = PhotoLanceAppli()
SI sPhoto <> "" ALORS
	Info("Photo sauvegardée dans le fichier : " + sPhoto)
FIN
```
<a name="Exemple2"></a>

```wl
// Lance l'application
PhotoLanceAppli(CB_PhotoLanceAppli)

	PROCEDURE INTERNE CB_PhotoLanceAppli(sChemin est une chaîne)
		// Si le retour vaut chaîne vide (""), une erreur a eu lieu
		SI sChemin ~= "" ALORS
			Erreur(ErreurInfo())
			RETOUR
		FIN
		// Message de fin d'enregistrement
		Info("La photo a été enregistrée ici : " + sChemin)
	FIN
```





<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Lancer l'application caméra native (appel bloquant)

`<Résultat> = PhotoLanceAppli()`
---

**`<Résultat> : (Chaîne de caractères)`**



- Chemin complet du fichier dans lequel la photo a été enregistrée, 

- Chaîne vide ("") en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).





<a name="SYNTAXE2"></a>

### Lancer l'application caméra native (appel non bloquant)

`<Résultat> = PhotoLanceAppli([<Procédure WLangage>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Chemin complet du fichier dans lequel la photo a été enregistrée, 

- Chaîne vide ("") en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également nommée "callback") appelée lors de l'enregistrement de la photo.
Cette procédure est de la forme :

```txt
PROCEDURE <Nom de la procédure> (<Chemin>)
```

où &lt;Chemin&gt; correspond au chemin de sauvegarde de l'image.

<a name="NOTE0_1"></a>

## Remarques


### Photos enregistrées
<a name="photos_enregistrees_ELTPARAGRAPHE000060"></a>Les paramètres des photos enregistrées (format, résolution, taille) sont ceux définis dans le paramétrage de l'application native de prise de photos.
<a name="NOTE0_2"></a>


### Répertoires de sauvegarde
<a name="repertoires_sauvegarde_ELTPARAGRAPHE000067"></a>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Dans les applications Android** : 

- La photo est stockée sur la SDCard de l'appareil et est également automatiquement ajoutée à l'album.
	**A partir de Android 11**, la photo est stockée dans le répertoire publique des images sur le stockage externe. Cet emplacement peut être obtenu par la fonction [SysRepStockageExterne](../WDLang1/1000021793.md) utilisée avec la constante constante **ssePublicPhoto**.
	Pour plus de détails sur les emplacements autorisés à partir de Android 11, consultez [Android 11 : Modifications du comportement des applications](../Editeurs/9000201.md).
	

- Si des photos doivent être utilisées dans vos applications Android, il est conseillé de travailler avec des miniatures et non les photos originales prises par l'appareil. Pour générer les miniatures, utilisez la fonction [VidéoGénèreMiniature](../WDLang1/1000020268.md). 




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Dans les applications iPhone/iPad** : 
Par défaut, les photos sont enregistrées dans le répertoire "Documents" de l'application. 

Il est possible également de : 

- mémoriser le contenu binaire de l'image dans une base de données, grâce à une rubrique de type Mémo. 

- ajouter la photo dans l'album photo de l'appareil grâce à la fonction [AlbumSauve](../WDLang3/1000020191.md). Dans ce cas, l'image pourra être réutilisée grâce à la fonction [AlbumSélecteur](../WDLang3/1000020186.md). 





![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000111"></a>L'utilisation de cette fonction entraîne automatiquement la modification des permissions requises par l'application.

Permissions requises :

- READ_EXTERNAL_STORAGE : Cette permission permet à une application de lire sur un stockage externe (carte mémoire, ...).

- WRITE_EXTERNAL_STORAGE : Cette permission permet à une application d'écrire sur un stockage externe (carte mémoire, ...).

- READ_MEDIA_VIDEO : Cette permission permet à une application de lire des fichiers vidéo à partir d'un stockage externe.

- READ_MEDIA_IMAGES : Cette permission permet à une application de lire des fichiers image à partir d'un stockage externe.




**Attention** : **A partir de Android 13**, lors d'une publication sur Google Play Store, les permissions READ_MEDIA_VIDEO, READ_MEDIA_IMAGES, READ_MEDIA_AUDIO nécessitent une justification de leur utilisation dans la console Google Play. Si nécessaire, il est possible de retirer les permissions depuis l'assistant de génération. Pour plus de détails, consultez [Stockage de fichiers sous Android](../WDLang1/1000021925.md).
