


## &lt;Graphe&gt;.SecteurAngleDépart (Fonction)

***En anglais : &lt;Chart&gt;.PieStartAngle***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Avertissement</B><BR>
	A partir de la version <B>27</B>,  cette fonctionnalité n'est plus disponible
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique l'angle de départ de la première part dans un graphe de type Secteur, Hémicycle ou Donut.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 










<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Augmentation de l'angle de départ du champ Graphe "GRF_MonGraphe"
GRF_MonGraphe.SecteurAngleDépart(45)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Graphe>.SecteurAngleDépart(<Angle>)`
---

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler présent dans l'éditeur de fenêtres, de pages ou d'états.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Angle> : (Entier)`**

Angle de départ de la première part (exprimé en degrés dans le sens des aiguilles d'une montre à partir du point haut du disque). 
Par défaut, l'angle de départ dans un graphe de type Secteur, Hémicycle ou Donut est égal à 0.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La définition de l'angle de départ de la première part d'un graphe est disponible uniquement sur les graphes suivants : 

	- graphes de type Secteur (constante *grSecteur*). 

	- graphes de type Hémicycle (constante *grHémicycle*).
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Ce type de graphe n'est pas disponible.

	- graphes de type Donut (constante *grDonut*).




- Les données définies avec la fonction **&lt;Graphe&gt;.SecteurAngleDépart** seront prises en compte lors du prochain appel à la fonction [&lt;Graphe&gt;.Dessine](../WDLang3/1000024062.md).
	![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Les données définies avec la fonction **&lt;Graphe&gt;.SecteurAngleDépart** sont prises en compte immédiatement.
