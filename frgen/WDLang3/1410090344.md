


## Fonctions de gestion des drives : OneDrive, Google Drive, Dropbox
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des drives sont les suivantes : 



|   |   |
| --- | --- |
| [dpDriveConnecte](../WDLang3/1410089379.md) | Crée une connexion à un drive Dropbox. |
| [DriveCopieFichier](../WDLang3/1410089524.md) | Copie un fichier unique du disque distant vers un autre répertoire du disque distant. |
| [DriveCopieRépertoire](../WDLang3/1410089554.md) | Copie un répertoire du drive vers un autre répertoire de ce drive (disque distant). |
| [DriveCréeFichier](../WDLang3/1410089477.md) | Crée un fichier sur le disque distant. |
| [DriveCréeRépertoire](../WDLang3/1410089479.md) | Crée un répertoire sur le disque distant. |
| [DriveDéplaceFichier](../WDLang3/1410089555.md) | Déplace un fichier présent dans un répertoire d'un drive vers un autre répertoire de ce drive (disque distant). |
| [DriveDéplaceRépertoire](../WDLang3/1410089556.md) | Déplace un répertoire et son contenu vers un autre répertoire du même drive (disque distant). |
| [DriveEnvoieFichier](../WDLang3/1410089563.md) | Envoie un fichier (présent sur la machine de l'utilisateur) vers un drive (disque distant). |
| [DriveEnvoieRépertoire](../WDLang3/1410089564.md) | Envoie un répertoire et ses fichiers (présents sur la machine de l'utilisateur) vers un drive (disque distant). |
| [DriveListeFichier](../WDLang3/1410089380.md) | Liste les fichiers d'un répertoire d'un drive. |
| [DriveListeFichierGgl](../WDLang3/1410089601.md) | Liste les fichiers de la suite Google (Google Docs, Google Sheets, etc.) présents dans un drive Google. |
| [DriveListeRépertoire](../WDLang3/1410089448.md) | Liste les répertoires d'un drive. |
| [DriveRécupèreFichier](../WDLang3/1410089558.md) | Récupère un fichier présent sur un drive (disque distant) et enregistre ce fichier sur le poste de l'utilisateur. |
| [DriveRécupèreFichierGgl](../WDLang3/1410089618.md) | Récupère un document de la suite Google présent sur un Google Drive dans le format compatible souhaité. |
| [DriveRécupèreRépertoire](../WDLang3/1410089559.md) | Récupère un répertoire (et ses fichiers) présent sur un drive (disque distant) pour l'enregistrer sur le poste de l'utilisateur. |
| [DriveRenomme](../WDLang3/1410089566.md) | Renomme un fichier ou un répertoire présent sur un drive. |
| [DriveSupprimeFichier](../WDLang3/1410089480.md) | Supprime un fichier dans un drive (disque distant). |
| [DriveSupprimeRépertoire](../WDLang3/1410089481.md) | Supprime un répertoire (et les fichiers qu'il contient) sur un drive (disque distant). |
| [GglDriveConnecte](../WDLang3/1410089373.md) | Crée une connexion à un drive Google Drive. |
| [oDriveConnecte](../WDLang3/1410089376.md) | Crée une connexion à un drive OneDrive. |
