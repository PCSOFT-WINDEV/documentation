
## telRécupèreNuméro (Fonction)

***En anglais : tapiGetNumber***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche la fenêtre d'autorisation et de sélection du ou des numéros de téléphone de l'utilisateur enregistrés sur l'appareil.

Remarques : 

- Pour utiliser cette fonction, le partage de numéros doit être activé sur le téléphone. Pour activer le partage, dans les paramètres du téléphone, sélectionnez "Google .. Tous les services .. Saisie automatique .. Partage du numéro de téléphone". Attention : Cette option peut être différente selon le téléphone utilisé. 

- Cette fonction est notamment utile pour gérer automatiquement la double authentification par SMS. 

- La fonction [SMSDétecteCodeUsageUnique](../WDLang3/1410090437.md) permet de récupérer un code à usage unique envoyé par SMS. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
telRécupèreNuméro(procRécupèreNuméro)

	PROCEDURE INTERNE procRécupèreNuméro(sNuméro est une chaîne)
		SI sNuméro <> "" ALORS
			ToastAffiche("Numéro de téléphone sélectionné : " + sNuméro)
		SINON
			ToastAffiche(ErreurInfo()))
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`telRécupèreNuméro(<Procédure WLangage>)`
---

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également appelée "callback") appelée lorsqu'un numéro est sélectionné ou en cas d'erreur. Cette procédure est de la forme :

```txt
PROCEDURE <Nom de la procédure>(<Numéro>)
```
 où &lt;Numéro&gt; est une chaîne de caractères contenant le numéro de téléphone sélectionné (ou une chaîne vide en cas d'erreur). En cas d'erreur, la fonction [ErreurInfo](../WDLang1/3013008.md) permet de récupérer le message d'erreur.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La fonction **telRécupèreNuméro** doit obligatoirement être exécutée depuis le thread principal de l'application et au moins une fenêtre de l'application doit être ouverte au moment de son appel. Une erreur fatale sera levée dans le cas contraire.
