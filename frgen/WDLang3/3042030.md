


## grIncrémenteDonnée (Fonction)

***En anglais : grIncreaseData***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une valeur à une donnée dans un graphe. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute la valeur 7 à la deuxième donnée de la première série
grIncrémenteDonnée("MonGraphe", 1, 2, 7)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`grIncrémenteDonnée(<Nom du graphe> , <Numéro de la série> , <Indice> , <Valeur>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la série> : (Entier)`**

Numéro de la série dans laquelle une valeur doit être ajoutée. Si la série spécifiée n'existe pas, le grapheur crée autant de séries que nécessaire pour obtenir une matrice de données cohérente. Les séries ainsi créées sont toutes initialisées à 0.

**`<Indice> : (Entier)`**

Indice de la donnée dans la série. Si la donnée spécifiée n'existe pas, le grapheur crée autant de données que nécessaire pour obtenir une matrice de données cohérente. Les données ainsi créées sont toutes initialisées à 0.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) L'indice de la donnée dans la série doit être un entier strictement positif.

**`<Valeur> : (Entier ou réel)`**

Valeur à ajouter à la donnée spécifiée.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Types de graphes
<a name="types_graphes_ELTPARAGRAPHE000122"></a>Pour les graphes de type Secteur, seules les données de la première série sont utilisées.
<a name="NOTE0_2"></a>


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000131"></a>

- Les données définies avec la fonction **grIncrémenteDonnée** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).

- Une série peut être composée de 8000 éléments maximum.

- Il est impossible de dessiner un graphe de type Secteur si toutes les données de la première série sont nulles.
