


## Webservice REST : Tester et déployer
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000187"></a>
WINDEV et WEBDEV permettent de créer des Webservices REST. 

Lorsque le Webservice REST est développé, il est possible de : 

- Tester et déboguer le Webservice REST.

- Déployer le Webservice REST. 




Lorsque le Webservice REST est déployé, il est possible d'appeler les différentes fonctions du Webservice.

## Tester et déboguer un Webservice REST
<a name="tester_deboguer_webservice_rest_ELTTEXTE000211"></a>
WINDEV et WEBDEV permettent de tester votre Webservice REST sous le débogueur. Pour cela, il suffit de mettre des points d'arrêt dans le code des procédures du Webservice et de lancer son test (GO).

Pour tester et déboguer un Webservice REST : 

1. Lancez au préalable l'administrateur WEBDEV sur le poste de développement. 
	Remarque : WDADMIN est l'administrateur du serveur d'application fourni avec WEBDEV. Ce serveur d'application permet de tester en local les sites WEBDEV et Webservices développés à l'aide de WEBDEV ou WINDEV.

2. Affichez si nécessaire la description du Webservice REST sous l'éditeur. 

3. Déroulez ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_GO_Projet_WD.gif) présent parmi les boutons d'accès rapide et sélectionnez "Déboguer le Webservice". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Test_WebService_Rest_Generer%20-%20HC%20N%B0001.gif)
Le projet est compilé. La fenêtre suivante s'affiche. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Test_Webservice_Rest_Generer%20-%20HC%20N%B0002.gif&type=thumb)


4. Sélectionnez la méthode de test :

	- **Tester le Webservice à l'aide de l'outil de test de l'éditeur** : Un outil est fourni en standard avec WINDEV et WEBDEV pour tester individuellement chaque point d'entrée du Webservice (voir ci-dessous). 

	- **Tester le Webservice avec un programme externe** : Choisissez cette option si vous avez écrit un programme spécifique pour appeler le Webservice. A la fin de l'exécution de l'exécutable, le mode test est arrêté. 

	- **Tester le Webservice manuellement** : L'éditeur de WINDEV ou WEBDEV se met en attente d'un appel externe. Par exemple, il est possible d'ouvrir un navigateur et de saisir l'URL de la requête correspondant à un des points d'entrée du Webservice à tester. La requête va être traitée et une réponse sera retournée dans le navigateur.   




5. Cliquez sur le bouton "Lancer le test".  





### Outil de test de Webservice : WDTestRest
<a name="outil_test_webservice_wdtestrest_ELTPARAGRAPHE000048"></a>L'outil WDTestRest est fourni en standard avec WINDEV et WEBDEV. Cet outil recense tous les points d'entrée du Webservice à tester. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=test%20Webservice_Rest_Generer%20-%20HC%20N%B0003.gif&type=thumb)
Le volet de gauche représente :

- la liste de tous les points d'entrée du Webservice,

- l'historique de tous les tests effectués.


La partie de droite affiche la liste de tous les points d'entrée testés sous forme de volets.

Pour tester un point d'entrée : 

1. Double-cliquez sur un point d'entrée dans le volet à gauche. Un volet s'ouvre à droite.

2. Complétez l'URL. Par exemple, remplacez les paramètres attendus entre **{...}** par une vraie valeur.

3. Sélectionnez le type d'authentification dans la liste.

4. Saisissez les paramètres de l'entête si nécessaire.

5. Cliquez sur le bouton "Envoyer" pour exécuter le test. Le résultat s'affiche.

	- Le volet "Réponse" contient le résultat renvoyé par l'URL.

	- La valeur "Statut" correspond au code de retour HTTP retourné par l'URL. 







Le lien "Générer le code WL" permet de générer et de récupérer le code WLangage équivalent au test effectué pour l'inclure dans votre projet.

Pour plus de détails, consultez [WDTestRest : Testez vos Webservices REST](../WDLang3/1000022795.md).

## Génération et déploiement du Webservice REST
<a name="generation_deploiement_webservice_rest_ELTTEXTE000241"></a>


### Générer un webservice REST
<a name="generer_webservice_rest_ELTPARAGRAPHE000082"></a>Pour générer un Webservice REST: 

1. Sélectionnez si nécessaire la configuration de projet correspondant au Webservice REST. 

2. Générez le Webservice REST :  

	- Méthode 1 : Sous le volet "Projet", dans le groupe "Génération", cliquez sur "Générer". 

	- Méthode 2 : Cliquez sur l'icône de génération parmi les boutons d'accès rapide. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Webservice_Rest_Generer%20-%20HC%20N%B0001.gif)





3. L'assistant de génération de Webservice se lance.

4. Indiquez le nom du Webservice. Par défaut, le nom du Webservice correspond au nom du projet en cours.

5. Validez. 

6. L'assistant de déploiement est automatiquement lancé à la suite.





### Déployer un Webservice REST
<a name="deployer_webservice_rest_ELTPARAGRAPHE000110"></a>Pour être utilisable, un Webservice doit être déployé sur un Serveur d'Application WEBDEV.

Il existe plusieurs méthodes de déploiement : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=WS_Deployer.gif&type=thumb)


- Déploiement du Webservice dans le CLOUD pour les applications PC SOFT.

- Déploiement du Webservice sur un serveur d'application WEBDEV distant.

- Création d'un package de déploiement distant.

- Création d'une installation par média physique.

- Création d'une image Docker du Webservice. 

- Déploiement du Webservice via le service d'hébergement de test PC SOFT.

- Déploiement du Webservice sur le poste local.




Les options de déploiement d'un Webservice sont identiques à celles de déploiement d'un site WEBDEV. Pour plus de détails, consultez [Déploiement d'un site](../Editeurs/2028039.md). 
<a name="NOTE5_2"></a>


### Cas particulier : Déploiement et test d'un Webservice sur le poste local
<a name="cas_particulier_deploiement_test_webservice_sur_poste_local_ELTPARAGRAPHE000133"></a>Il est possible de tester le Webservice créé directement sur le poste du développeur. Pour cela, il suffit de choisir l'option "Déployer le Webservice sur le poste local". Ce type d'installation est disponible uniquement si WEBDEV est disponible sur le poste de développement. Dans ce cas, le serveur d'application utilisé est celui de WEBDEV.

A la fin de l'installation, un écran s'affiche avec un lien permettant d'afficher la description du Webservice. 

Le Webservice est prêt à être utilisé.
