
## Paramètres de la procédure utilisée par la fonction PartageProximitéAttendConnexion (Demande)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéAttendConnexion](../WDLang3/1410090655.md) exécutée lorsqu'un appareil distant demande à se connecter.
Dans le code de cette procédure, il est d'usage de traiter la demande en l'acceptant (fonction [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md)) ou en la refusant (fonction [PartageProximitéRefuseConnexion](../WDLang3/1410090651.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// A chaque modification de l'interrupteur permettant d'activer / désactiver l'attente de connexion
INT_Attente_connexion.Etat = Grisé
SI INT_Attente_connexion ALORS
	PartageProximitéAttendConnexion(gsNomAppareil, CallbackRésultat, CallbackDemandeConnexion, 
		CallbackConnexion, gnTopologieDeRéseau)
SINON
	PartageProximitéArrêteAttente()
	INT_Attente_connexion.Etat = Actif
FIN
```

```wl
PROCÉDURE CallbackDemandeConnexion(sIdAppareil est chaîne, sNomAppareil est une chaîne, sToken est une chaîne)
Info([
	ID : [%sIdAppareil%]
	Nom : [%sNomAppareil%]
])
Trace("L'appareil [%sNomAppareil%] demande à se connecter pour un partage de proximité")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéAttendConnexion_Callback_Demande(<Identifiant de l'appareil> , <Nom de l'appareil> , <Jeton d'authentification>)`
---

**`<Identifiant de l'appareil> : (Chaîne de caractères)`**

Identifiant de l'appareil qui demande la connexion.

**`<Nom de l'appareil> : (Chaîne de caractères)`**

Nom de l'appareil qui cherche à se connecter. 
Ce nom correspond au nom d'appareil qui a été donné à la fonction [PartageProximitéDemandeConnexion](../WDLang3/1410090650.md).

**`<Jeton d'authentification> : (Chaîne de caractères)`**

Chaîne de caractères courte et aléatoire permettant aux utilisateurs de confirmer qu'ils se connectent bien à l'appareil prévu.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion du jeton d'authentification
<a name="gestion_jeton_authentification_ELTPARAGRAPHE000168"></a>

Les deux appareils reçoivent le même jeton. La vérification de ces jetons doit être effectuée par programmation. 

Une pratique courante consiste à afficher le jeton sur les deux appareils et de demander aux utilisateurs de comparer et de confirmer manuellement (comme dans le cas d'un couplage Bluetooth).

La fonction [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md) permet d'afficher une boîte de dialogue pour afficher le jeton d'authentification. Il est alors possible d'accepter ou refuser la connexion.
