


## NetAdresseIP (Fonction)

***En anglais : NetIPAddress***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'adresse IP (Internet Protocol) d'un poste. 

**Attention** : Seules les adresses IPV4 sont renvoyées. Ce fonctionnement est conservé pour compatibilité avec les versions précédentes. Pour connaître les adresses IPV4 et/ou IPV6, utilisez la fonction [NetListeAdresseIP](../WDLang3/1000019683.md). 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Attention** : Cette information est disponible jusqu'à Android 10. A partir d'Android 11, cette information n'est plus accessible : Cette fonction renvoie une chaîne vide.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche l'adresse IP de la machine locale
Info(NetAdresseIP())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = NetAdresseIP([<Nom du poste>] [, <Indice>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Adresse IP du poste spécifié (au format XXX.XXX.XXX.XXX), 

- Chaîne vide ("") si le poste possède moins d'adresses IP que l'&lt;Indice&gt; demandé.




**`<Nom du poste> : (Chaîne de caractères optionnelle)`**

Nom du poste à manipuler. Si ce paramètre n'est pas spécifié, le poste considéré sera le poste en cours.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Il n'est pas possible de récupérer les adresses d'une machine autre que celle sur laquelle l'application s'exécute.

**`<Indice> : (Entier optionnel)`**

Indice de l'adresse IP dans la liste des adresses du poste. Par défaut, l'adresse renvoyée est la première adresse de la liste des adresses du poste. La première adresse a pour indice 0.

<a name="NOTE0_1"></a>

## Remarques


### Nombre d'adresses IP
<a name="nombre_adresses_ELTPARAGRAPHE000063"></a>

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Dans un site WEBDEV, la fonction **NetAdresseIP** renvoie l'adresse IP du serveur sur lequel est installé le site. 
	Pour obtenir l'adresse IP de l'internaute, il faut utiliser la fonction [NavigateurAdresseIP](../WDLang2/3055003.md). 
	**Attention** : Si l'internaute est derrière un routeur, la fonction [NavigateurAdresseIP](../WDLang2/3055003.md) renvoie l'adresse IP du routeur.

- Il existe une adresse IP pour chaque protocole TCP/IP installé sur un même poste.

- Pour lister les différentes adresses IP d'un poste (IPV4 et/ou IPV6), utilisez la fonction [NetListeAdresseIP](../WDLang3/1000019683.md).
