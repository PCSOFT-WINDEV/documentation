
## Fonctions de gestion des utilisateurs sur le serveur d'authentification OAuth WEBDEV
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des utilisateurs sur le serveur d'authentification OAuth WEBDEV sont les suivantes :




|   |   |
| --- | --- |
| [wdbaasCréeUtilisateur](../WDLang3/1410091289.md) | Crée un nouvel utilisateur dans le serveur d'authentification OAuth.<br><br> |
| [wdbaasInfoUtilisateur](../WDLang3/1410091290.md) | Récupère les informations concernant un utilisateur sur le serveur OAuth WEBDEV.<br><br> |
| [wdbaasListeUtilisateur](../WDLang3/1410091288.md) | Renvoie la liste des utilisateurs du serveur d'authentification OAuth WEBDEV.<br><br> |
| [wdbaasModifieUtilisateur](../WDLang3/1410091291.md) | Modifie un utilisateur existant dans le serveur d'authentification OAuth WEBDEV.<br><br> |
| [wdbaasSupprimeUtilisateur](../WDLang3/1410091292.md) | Supprime un utilisateur existant du serveur d'authentification OAuth WEBDEV. |

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000149"></a>L'utilisation des fonctions de gestion d'un utilisateur sur un serveur OAuth WEBDEV nécessite la mise en place de droits au niveau de l'identifiant OAuth utilisé. Ces droits sont mis en place dans le site d'administration des services BaaS de WEBDEV. 

Il est possible par exemple de donner les droits suivants : 

- Autoriser la création d'utilisateurs uniquement.

- Autoriser la lecture des informations des utilisateurs.

- Tout autoriser (lecture, création, modification, suppression).

- etc. 




Pour plus de détails, consultez [Site d'administration des services BaaS](../WDLang3/1410086668.md).
