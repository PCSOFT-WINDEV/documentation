


## grSupprimeSérie (Fonction)

***En anglais : grDeleteSeries***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une série de données d'un graphe. Toutes les données de la série sont effacées. 

Attention : Les séries restantes sont re-numérotées. Par exemple, lors de la suppression de la série 1, la série 2 devient la série 1, ...



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression de la seconde série de données du graphe "MonGraphe"
grSupprimeSérie("MonGraphe", 2)
```
<a name="Exemple2"></a>

```wl
// Suppression de la troisième série de données du graphe "GRF_MonGraphe"
grSupprimeSérie(GRF_MonGraphe, 3)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`grSupprimeSérie(<Nom du graphe> [, <Numéro de la série> [, <Options>]])`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe, défini avec la fonction [grCrée](../WDLang3/3042005.md) ou nom du champ Graphe.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la série> : (Entier optionnel)`**

Numéro de la série à supprimer. Si ce paramètre n'est pas spécifié, toutes les données du graphe sont effacées.

**`<Options> : (Constante de type Entier)`**

Type de suppression à réaliser : 


|   |   |
| --- | --- |
| *grDonnées* | Suppression uniquement des données de la série. |
| *grDonnéesEtStyle*<br>(Valeur par défaut) | Suppression des données et du style de la série. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si toutes les séries d'un graphe sont supprimées, il faut ajouter de nouvelles données afin de pouvoir re-dessiner le graphe.

- Les modifications effectuées avec la fonction **grSupprimeSérie** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).

- Dans le cas d'une série basée sur une rubrique, les données sont effacées. La source de données est conservée, et les données peuvent donc être reconstruites. Pour couper le lien à la source, utilisez la fonction [grSourceSérie](../WDLang3/3042067.md) en modifiant la source de la série.
