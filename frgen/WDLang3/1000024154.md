


## &lt;Graphe&gt;.TypePoint (Fonction)

***En anglais : &lt;Chart&gt;.PointType***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la forme du point d'une catégorie ou d'une valeur particulière dans un graphe de type Courbe, Aire, Nuage de points et Radar. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Transforme en cercle le point (catégorie) 2 de la série 1
GRF_MonGraphe.TypePoint(1, 2, grPointCercle)

// Transforme en carré le point (catégorie) 3 de toutes les séries
GRF_MonGraphe.TypePoint(3, grPointCarré)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Modifier la forme du point d'une catégorie (pour toutes les séries)

`<Champ Graphe>.TypePoint(<Numéro de la catégorie> , <Type>)`
---

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la catégorie> : (Entier)`**

Indice de la catégorie à modifier.

**`<Type> : (Constante de type Entier)`**

Nouveau type de point de la catégorie : 



|   |   |
| --- | --- |
| *grNonDessiné* | Point non dessiné. |
| *grPointCarré* | Point en forme de carré. |
| *grPointCercle* | Point en forme de cercle. |
| *grPointCroix* | Point en forme de croix. |
| *grPointLosange* | Point en forme de losange. |
| *grPointTriangle* | Point en forme de triangle. |




<a name="SYNTAXE2"></a>

### Modifier la forme d'un point particulier

`<Champ Graphe>.TypePoint(<Numéro de la série> , <Numéro de la catégorie> , <Type>)`
---

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la série> : (Entier)`**

Numéro de la série dans laquelle le type de point doit être modifié.

**`<Numéro de la catégorie> : (Entier)`**

Indice de la catégorie à modifier.

**`<Type> : (Constante de type Entier)`**

Nouveau type de point de la catégorie : 



|   |   |
| --- | --- |
| *grNonDessiné* | Point non dessiné. |
| *grPointCarré* | Point en forme de carré. |
| *grPointCercle* | Point en forme de cercle. |
| *grPointCroix* | Point en forme de croix. |
| *grPointLosange* | Point en forme de losange. |
| *grPointTriangle* | Point en forme de triangle. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
<a name="NOTE0_2"></a>
Pour changer le type de tous les points d'une série, il est recommandé d'utiliser la fonction [&lt;Graphe&gt;.TypePointSérie](../WDLang3/1000024155.md).
