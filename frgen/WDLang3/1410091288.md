
## wdbaasListeUtilisateur (Fonction)

***En anglais : wdbaasListUser***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des utilisateurs du serveur d'authentification OAuth WEBDEV. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Paramètres de connexion
param est un OAuth2Paramètres
param.ClientID = "d07c7d45-103c-48ad-a6b2-1bb9354eb947"
param.ClientSecret = "e260eeb0-15fb-4db7-964f-a72de7324e0d"
param.URLToken = "https://serveur/oauth2/v1/token"
param.TypeAutorisation = taApplicationCliente
param.Scope = "wdbaas:users:read"
// Connexion
token_admin est un AuthToken = AuthIdentifie(param)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
// Récupère la liste des utilisateurs
tab_utilisateur est un tableau de gpwUtilisateur = wdbaasListeUtilisateur(token_admin)
POUR TOUT utilisateur DE tab_utilisateur
	Trace(utilisateur.Login, utilisateur.Email)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = wdbaasListeUtilisateur(<Token>)`
---

**`<Résultat> : (Tableau WLangage)`**

Tableau de variables de type [gpwUtilisateur](../WDLang6/1000021088.md) correspondant à la liste des utilisateurs. 
En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et la fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur. 

**`<Token> : (Variable de type AuthToken)`**

Nom de la variable [AuthToken](../WDLang3/1000022220.md) correspondant au token d'identification sur le serveur OAuth.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000167"></a>L'utilisation des fonctions de gestion d'un utilisateur sur un serveur OAuth WEBDEV nécessite la mise en place de droits au niveau de l'identifiant OAuth utilisé. Ces droits sont mis en place dans le site d'administration des services BaaS de WEBDEV. 

Il est possible par exemple de donner les droits suivants : 

- Autoriser la création d'utilisateurs uniquement.

- Autoriser la lecture des informations des utilisateurs.

- Tout autoriser (lecture, création, modification, suppression).

- etc. 




Pour plus de détails, consultez [Site d'administration des services BaaS](../WDLang3/1410086668.md).
