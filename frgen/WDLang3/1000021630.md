


## grHMLibelléX (Fonction)

***En anglais : grHMCaptionX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie le libellé d'une catégorie sur l'axe des abscisses d'un graphe de type Heatmap.

Note : Par défaut, le libellé d'une catégorie correspond à la valeur numérique de la catégorie.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
grHMLibelléX(GRF_HMap, 1, "X1")
grHMLibelléX(GRF_HMap, 2, "X2")
```

```wl
// Libellé des axes
POUR TOUT ELEMENT nIndice, nTempérature DE gtaTempérature
	grHMLibelléX(GRF_Graphe, nIndice, "" + nTempérature)
FIN
POUR TOUT ELEMENT nIndice, nVent DE gtaVent
	grHMLibelléY(GRF_Graphe, nIndice, "" + nVent)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grHMLibelléX(<Nom du graphe> , <X> , <Libellé>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres ou d'états.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<X> : (Entier)`**

Position de la catégorie sur l'axe des abscisses.

**`<Libellé> : (Chaîne de caractères)`**

Nouveau libellé de la catégorie. Si ce paramètre correspond à une chaîne vide (""), la valeur numérique de la catégorie est affichée.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Le libellé défini avec la fonction **grHMLibelléX** sera pris en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).
