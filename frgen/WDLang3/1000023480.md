
## Constantes de gestion des tâches en arrière-plan
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les constantes de gestion des tâches en arrière-plan sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **tâcheEnArrièrePlanRafraîchissement** | La tâche est une tâche de rafraîchissement en arrière-plan. <br> <br>Attention : Pour qu'une tâche de rafraîchissement puisse être exécutée, les conditions suivantes doivent être réunies :<br><br>- le traitement de la tâche peut durer quelques secondes, <br><br>- le device n'a pas une batterie faible,<br><br>- le mode d'économie d'énergie n'est pas actif sur le device,<br><br>- dans les réglage du device, l'option "Actualiser en arrière-plan" est positionnée sur "Oui" et l'option est active pour l'application.  <br><br>- l'application a été lancée et utilisée récemment,<br><br>- l'application est dans la liste des applications récente (app switcher),<br><br>- le budget de CPU et de données réseau n'est pas dépassé,<br><br>- le nombre d’exécution n'est pas dépassé.<br><br><br> | [TâcheEnArrièrePlanAjoute](../WDLang3/1000023454.md) |
| **tâcheEnArrièrePlanTraitement** | La tâche correspond à un traitement en arrière-plan. <br>Attention : Pour qu'un traitement en arrière-plan puisse être exécuté, les conditions suivantes doivent être réunies :<br><br>- le traitement de la tâche peut durer quelques minutes,<br><br>- le device n'a pas une batterie faible,<br><br>- le mode d'économie d'énergie n'est pas actif sur le device,<br><br>- dans les réglage du device, l'option "Actualiser en arrière-plan" est positionnée sur "Oui" et l'option est active pour l'application.\* l'application a été lancé dans la semaine précédente (ou 2 semaines précédentes),<br><br>- l'application est dans la liste des applications récente (app switcher),<br><br>- l'utilisateur n'utilise pas activement le device (exemple, la nuit en chargement).<br><br><br> | [TâcheEnArrièrePlanAjoute](../WDLang3/1000023454.md) |
