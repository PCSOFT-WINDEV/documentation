
## DNSInterroge (Fonction)

***En anglais : DNSQuery***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Envoie une requête à un serveur DNS.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
s est une chaîne = DNSInterroge("google.com", dnsA)
```

```wl
soit ResDNS = DNSInterroge("91.90.97.90", dnsPTR)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
SINON
	Info("le nom de domaine associé est : " + ResDNS)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = DNSInterroge(<Elément manipulé> , <Type de la requête> [, <Serveur DNS>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Résultat de la requête vers un serveur DNS. Si plusieurs informations sont renvoyées, elles sont séparées par des Retour-Chariot (RC). 

En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et la fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître la cause de l'erreur.

**`<Elément manipulé> : (Chaîne de caractères)`**

Nom de domaine ou adresse IP sur lesquels la requête doit être exécutée. 

**`<Type de la requête> : (Constante de type Entier)`**

Type de la requête à exécuter : 


|   |   |
| --- | --- |
| *dnsA* | Renvoie l'adresse IPv4 associée au nom de domaine. |
| *dnsAAAA* | Renvoie l'adresse IPv6 associée au nom de domaine. |
| *dnsCNAME* | Renvoie les alias de nom de domaine. |
| *dnsDNAME* | Renvoie les alias de nom de domaine et de ses sous domaines. |
| *dnsMX* | Renvoie les serveurs de courriel pour le domaine spécifié. |
| *dnsNAPTR* | Renvoie les règles de réécriture de l'information, permettant des correspondances assez lâches entre un nom de domaine et une ressource. |
| *dnsNS* | Liste les serveurs DNS du domaine spécifié. |
| *dnsPTR* | Renvoie le nom d'hôte ou de domaine correspondant à une l'adresse IP (inverse du A/AAAA). |
| *dnsSOA* | Donne les informations générales du domaine : serveur principal, courriel de contact, différentes durées dont celle d'expiration, numéro de série de la zone, etc. |
| *dnsSRV* | Renvoie le serveur de courriel associé à un nom de domaine avec des données complémentaires comme le taux de répartition de charge pour un service donné. |
| *dnsTLSA* | Renvoie le certificat TLS associé au nom de domaine. |
| *dnsTXT* | Renvoie le texte associé à un enregistrement DNS. |



**`<Serveur DNS> : (Chaîne de caractères optionnelle)`**

Adresse du serveur DNS à manipuler. Par défaut, le serveur DNS actuel est utilisé.
