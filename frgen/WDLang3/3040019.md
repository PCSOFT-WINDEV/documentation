


## FTPNom (Fonction)

***En anglais : FTPName***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol).

**Remarque**: La fonction **FTPNom** est utile notamment lors d'un parcours de fichiers sur un serveur FTP au moyen de la fonction [FTPListeFichier](../WDLang3/3040018.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Nom du dernier fichier accédé par une fonction FTP
ResNom = FTPNom()
```
<a name="Exemple2"></a>

```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
FTPConnecte(MaConnexionFTP)

// Nom du dernier fichier accédé par une fonction FTP
ResNom = FTPNom(MaConnexionFTPNom)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Syntaxe non disponible en PHP
### Connaître le nom du dernier fichier accédé (connexion via un variable ftpConnexion)

`<Résultat> = FTPNom(<Connexion FTP>)`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom du dernier fichier accédé par une fonction FTP. Ce fichier a été modifié par une des fonctions FTP suivantes: [FTPAttribut](../WDLang3/3040006.md), [FTPDate](../WDLang3/3040015.md), [FTPHeure](../WDLang3/3040013.md), [FTPTaille](../WDLang3/3040007.md), [FTPListeFichier](../WDLang3/3040018.md).  

- Chaîne vide ("") en cas d'erreur.  Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) décrivant les caractéristiques de la connexion au serveur FTP. 



<a name="SYNTAXE2"></a>

### Connaître le nom du dernier fichier accédé (connexion via l'identifiant de la connexion au serveur FTP)

`<Résultat> = FTPNom()`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom du dernier fichier accédé par une fonction FTP. Ce fichier a été modifié par une des fonctions FTP suivantes: [FTPAttribut](../WDLang3/3040006.md), [FTPDate](../WDLang3/3040015.md), [FTPHeure](../WDLang3/3040013.md), [FTPTaille](../WDLang3/3040007.md), [FTPListeFichier](../WDLang3/3040018.md).  

- Chaîne vide ("") en cas d'erreur.  Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Requête au serveur FTP
<a name="requete_serveur_ftp_ELTPARAGRAPHE000151"></a>

La fonction **FTPNom** ne provoque pas l'envoi d'une requête au serveur FTP.
<a name="NOTE0_2"></a>


### Délai
<a name="delai_ELTPARAGRAPHE000337"></a>

Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié: 

- lors de la connexion au serveur FTP avec la fonction [FTPConnecte](../WDLang3/3040016.md) (paramètre &lt;Durée de non réponse&gt;).

- lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
	



<a name="NOTE0_4"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000377"></a>

La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000386"></a>

L'utilisation de cette fonction entraîne la modification des permissions requises par l'application. 
Permission requise : INTERNET 
Cette permission autorise l'application à ouvrir des sockets réseau.
