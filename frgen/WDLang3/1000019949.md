


## CarteFinDéplacement (Fonction)

***En anglais : MapEndOfMove***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête le suivi du déplacement de l'appareil dans un champ Carte. Ce suivi de déplacement a été précédemment lancé avec la fonction [CarteSuitDéplacement](../WDLang3/1000019953.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Démarre le suivi du déplacement dans le champ Carte
CarteSuitDéplacement(CARTE_Position)
...
// Stoppe le suivi du déplacement dans le champ Carte
CarteFinDéplacement(CARTE_Position)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`CarteFinDéplacement([<Champ Carte>])`
---

**`<Champ Carte> : (Nom de champ optionnel)`**

Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, le champ Carte auquel appartient l'événement en cours sera utilisé.
