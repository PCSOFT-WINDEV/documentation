


## grPIValeurMaximale (Fonction)

***En anglais : grPPCMaximumValue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de spécifier la valeur maximale du graphe permettant de calculer automatiquement les pourcentages d'un graphe de type "Pourcentage imagé".
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ImageGraphe est une Image = "rocket.png"
grSupprimeSérie(GRF_Pourcentage, 1)
nSomme est un entier
POUR TOUTE LIGNE DE TABLE_Série
	nValeur est un entier = COL_Données
	nSomme += nValeur
	grAjouteDonnée(GRF_Pourcentage, 1, nValeur)
FIN
grPIValeurMaximale(GRF_Pourcentage, nSomme)
grPIImage(GRF_Pourcentage, ImageGraphe)
grDessine(GRF_Pourcentage)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grPIValeurMaximale(<Graphe> , <Valeur maximale>)`
---

**`<Graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres ou de pages.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.

**`<Valeur maximale> : (Réel)`**

Nouvelle valeur maximale à prendre en compte. Cette valeur est strictement positive. 
Par défaut, cette valeur vaut 100, ainsi les données sont exprimées en pourcentage. Lors du changement de cette valeur, les données du graphe sont recalculées automatiquement.
