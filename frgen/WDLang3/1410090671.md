


## &lt;AuthToken&gt;.Déconnecte (Fonction)

***En anglais : &lt;AuthToken&gt;.Logout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déconnecte un utilisateur précédemment authentifié via le protocole OAuth 2.0 sur un service Web quelconque.

Remarques : 

- La déconnexion ouvre un navigateur (comme pour la connexion). L'URL de redirection est appelée lorsque la déconnexion est effectuée. A la prochaine connexion, le processus de connexion devra être entièrement refait.

- Lors de l'utilisation d'une variable de type [OAuth2Paramètres](../WDLang3/1000022212.md), il est nécessaire de spécifier l'URL de déconnexion avec la propriété **URLDéconnexion**. 

- **Pour une configuration IOS**, cette fonction n'est pas disponible. Il est conseillé d'utiliser la fonction [&lt;AuthToken&gt;.Révoque](../WDLang3/1410090672.md).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
OAuth2Params est OAuth2Paramètres
OAuth2Params.ClientID = "01234567890123456789" 
OAuth2Params.ClientSecret = "98765432109876543210"
OAuth2Params.URLAuth = "https://www.dropbox.com/oauth2/authorize"
OAuth2Params.URLToken = "https://api.dropboxapi.com/oauth2/token"
OAuth2Params.ParamètresSupplémentaires = "force_reapprove=false"
<COMPILE SI TypeConfiguration <> SITE>
	// Si ce n'est pas dans un site WEB il faut une URL de redirection en localhost
	OAuth2Params.URLRedirection = "http://localhost:9874/"	
<FIN>

// Demande d'authentification : ouvre la fenêtre de login
MonToken est un AuthToken = AuthIdentifie(OAuth2Params)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN

//Déconnexion
MonToken.Déconnecte()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0

`<Résultat> = <Token de la connexion>.Déconnecte()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la déconnexion a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Token de la connexion> : (Variable de type AuthToken)`**

Nom de la variable de type [AuthToken](../WDLang3/1000022220.md) correspondant au token de la connexion.


<a name="SYNTAXE6"></a>

### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0 (syntaxe asynchrone)

`<Token de la connexion>.Déconnecte(<Procédure WLangage>)`
---

**`<Token de la connexion> : (Variable de type AuthToken)`**

Nom de la variable de type [AuthToken](../WDLang3/1000022220.md) correspondant au token de la connexion.

**`<Procédure WLangage> : (Nom de procédure)`**

Procédure WLangage optionnelle qui sera appelée lors de la déconnexion. Cette procédure est de la forme : 

```txt
<NomProcédure>(<Déconnexion>)
```
 où &lt;Déconnexion&gt; est un booléen permettant de savoir si la déconnexion a été effectuée (<u><u><u><u>Vrai</u></u></u></u>) ou non (<u><u><u><u>Faux</u></u></u></u>).
