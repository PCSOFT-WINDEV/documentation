


## ContactSupprime (Fonction)

***En anglais : ContactDelete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime le contact en cours : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png) du carnet d'adresses d'une messagerie Lotus Notes ou Outlook. 
	**Attention** : Cette fonction **ne permet pas** de supprimer un contact dans le carnet d'adresses d'une messagerie Outlook Express.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) dans la liste des contacts de l'appareil (Android, iPhone ou iPad).

<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", ...
		"C:\Lotus Notes\julie.id")
// Recherche du contact à supprimer
SI ContactCherche(IDSession, "Dupont", mContactNom, "Axelle", mContactPrénom) = Vrai ALORS
	// Suppression du contact
	ContactSupprime(IDSession)
	Info("Ce contact a été supprimé")
SINON
	Info("Aucun contact n'a été trouvé")
FIN
```
<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
gContactEnCours est un Contact
gtabContacts est un tableau de Contact 
gtabContacts = ContactListe(Null)

// Supprime le contact sélectionné
gContactEnCours = gtabContacts[ZR_CONTACTS]

SI OuiNon(Oui, "Voulez-vous vraiment supprimer ce contact ?") = Oui ALORS
	// Suppression du contact
	ContactSupprime(gContactEnCours)
	// Rafraîchit les contacts
	RafraîchitContacts()
FIN
```

## Syntaxe
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
### Supprimer un contact dans la messagerie Lotus Notes ou Outlook

`<Résultat> = ContactSupprime(<Identifiant de la session>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Identifiant de la session> : (Entier)`**

Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](../WDLang3/3032121.md), [EmailOuvreSessionOutlook](../WDLang3/3032128.md), [NotesOuvreBase](../WDLang3/1000005101.md) ou [OutlookOuvreSession](../WDLang3/3032123.md).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
### Supprimer un contact dans la liste des contacts de l'appareil (Android, iPhone, iPad)

`<Résultat> = ContactSupprime(<Contact>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Contact> : (Variable de type Contact)`**

Nom de la variable de type [Contact](../WDLang3/1000020254.md) correspondant au contact à supprimer.
