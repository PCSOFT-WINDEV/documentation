


## grGraduation (Fonction)

***En anglais : grInterval***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique le pas des graduations sur l'axe vertical/horizontal d'un graphe (c'est-à-dire l'intervalle entre deux graduations). 

**Rappel** : Par défaut, le pas des graduations est égal à 0. Ce pas est ajusté au mieux selon la place disponible dans la destination choisie.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Graphe créé par programmation
// Axe vertical du graphe gradué avec un pas de 5
grGraduation("MonGraphe", 5, grOrdonnée)
```
<a name="Exemple2"></a>

```wl
// Champ Graphe
// Axe horizontal du graphe gradué avec un pas de 10
grGraduation(GRF_MonGraphe, 10, grAbscisse)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`grGraduation(<Nom du graphe> , <Pas> [, <Type de l'axe>])`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Seuls les champs Graphe sont disponibles.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Pas> : (Réel)`**

Intervalle entre deux graduations. Si ce paramètre est égal à 0, le pas sera ajusté au mieux selon la place disponible dans la destination choisie.

**`<Type de l'axe> : (Constante optionnelle)`**

Type de l'axe pour lequel le pas des graduations est défini :


|   |   |
| --- | --- |
| *grAbscisse* <br>(Valeur par défaut) | Graduations sur l'axe des abscisses. |
| *grAltitude* | Graduations sur l'axe des altitudes (graphe de type Surface uniquement).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *grOrdonnée* | Graduations sur l'axe des ordonnées. |
| *grOrdonnéeSecondaire* | Graduations sur l'axe secondaire des ordonnées. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Graduations des axes
<a name="graduations_des_axes_ELTPARAGRAPHE000147"></a>

- Limites : 100 graduations au-dessus et 100 graduations en dessous de l'axe des "X".

- La dernière graduation affichée est le premier multiple de &lt;Pas&gt; supérieur à la plus grande valeur des données. La totalité des données est donc visible quelle que soit la dimension de la destination.

- Pour modifier les graduations de début et de fin sur l'axe horizontal, vertical ou secondaire d'un graphe, utilisez la fonction [grOrigine](../WDLang3/3042039.md).

- Les données définies avec la fonction **grGraduation** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).



<a name="NOTE0_2"></a>


### Types de graphes
<a name="types_graphes_ELTPARAGRAPHE000168"></a>La graduation des axes est sans effet sur les graphes de type Secteur.
