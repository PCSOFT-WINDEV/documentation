


## &lt;Variable sshSession&gt;.ConnecteCommande (Fonction)

***En anglais : &lt;sshSession variable&gt;.ConnectCommand***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [&lt;Variable sshSession&gt;.Commande](../WDLang3/1410091176.md)) à un serveur SSH.

Rappel : Par défaut, lors de l'envoi d'une commande à un serveur SSH, la session est ouverte et refermée automatiquement après l'envoi de la commande.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Session est une sshSession
// Propriétés de la session
// ...
// Initialise la session SSH à conserver
Session.ConnecteCommande()
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
// Ferme la session SSH pour retrouver un fonctionnement normal
Session.DéconnecteCommande()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Session SSH>.ConnecteCommande()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la session a été ouverte correctement,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Session SSH> : (Variable de type sshSession)`**

Nom d'une variable [sshSession](../WDLang3/1000021157.md) contenant les paramètres de connexion de la session SSH à ne pas déconnecter.
