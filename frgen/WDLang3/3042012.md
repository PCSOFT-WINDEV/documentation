


## grPoliceEtiquette (Fonction)

***En anglais : grLabelFont***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la police utilisée pour les étiquettes de catégorie d'un graphe. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteCat.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 






<a name="sample_code"></a>

## Exemple

<a name="Exemple1"></a>

```wl
// Modification de la police des étiquettes des axes du champ Graphe : GRF_Graphe

// Création d'une police spécifique
polEtiquettes est une Police
polEtiquettes.Nom = "Verdana"
polEtiquettes.Taille = 10
polEtiquettes.Gras = Vrai

// Changement de police
grPoliceEtiquette(GRF_Graphe, polEtiquettes)
grDessine(GRF_Graphe)
```
<a name="Exemple2"></a>

```wl
// Utilisation de la syntaxe conservée par compatibilité
// Modification de la police utilisée pour les étiquettes du graphe "MonGraphe"
// L'identifiant de la police utilisée est 7
grPoliceEtiquette("MonGraphe", 7)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Définition de la police utilisée pour les étiquettes d'un graphe

`grPoliceEtiquette(<Nom du graphe> , <Police utilisée>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur d'états.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Police utilisée> : (Police)`**

Police à utiliser. Ce paramètre correspond à une variable de type [Police](../Motscles/1514045.md). Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](../WDLang1/3060002.md) ou grâce aux [propriétés de gestion des polices](../Proprietes/2515045.md).  


<a name="SYNTAXE2"></a>

### Définition de la police utilisée pour les étiquettes d'un graphe (syntaxe conservée par compatibilité)

`grPoliceEtiquette(<Nom du graphe> , <Identifiant de la police>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur d'états.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Identifiant de la police> : (Entier)`**

Identifiant de la police, défini avec la fonction [grCréePolice](../WDLang3/3042001.md). Si cette police n'existe pas, une erreur du WLangage est générée.

<a name="NOTE0_1"></a>

## Remarques


### Manipulation des étiquettes de catégories
<a name="manipulation_des_etiquettes_categories_ELTPARAGRAPHE000152"></a>Les étiquettes de catégories sont affichées :

- sous les graduations horizontales pour les graphes de type courbe ou les graphes boursiers de type chandelier japonais et BarCharts,

- sous l'axe des X pour les histogrammes ou les graphes de type boursier Minimum/Maximum.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteCat.gif)
Les étiquettes de catégories ne sont pas utilisables avec les graphes de type nuage de points.

La définition des étiquettes de catégories est réalisée avec la fonction [grEtiquetteCatégorie](../WDLang3/3042015.md).

Il est possible de modifier la police de l'étiquette grâce à la fonction **grPoliceEtiquette**.

Les étiquettes de catégories définies avec la fonction [grEtiquetteCatégorie](../WDLang3/3042015.md) peuvent être affichées dans le libellé du graphe de type Secteur (constante *grAfficheEtiquette* utilisée avec la fonction [grLibellé](../WDLang3/3042046.md)).
<a name="NOTE0_2"></a>


### Initialisation des polices
<a name="initialisation_des_polices_ELTPARAGRAPHE000185"></a>La police utilisée par défaut pour les étiquettes a les caractéristiques suivantes :

- Nom de la police : Arial

- Taille : 14

- Style : Normal

- Couleur : Noir


Lors de l'utilisation de la fonction [grCrée](../WDLang3/3042005.md), la police utilisée pour les étiquettes est la police par défaut.
<a name="NOTE0_3"></a>


### Orientation de la police
<a name="orientation_police_ELTPARAGRAPHE000203"></a>Dans le cas des étiquettes d'un graphe, la propriété "orientation" de la police est ignorée. 

Pour changer l'orientation de la police des étiquettes, il faut modifier directement la description du champ Graphe dans la fenêtre à 7 onglets. 

Par défaut, l'orientation est choisie de manière automatique. Cette orientation tient compte de la taille et du nombre d'étiquettes à afficher.
