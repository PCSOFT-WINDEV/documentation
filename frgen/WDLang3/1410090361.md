


## &lt;Variable Drive&gt;.ListeRépertoire (Fonction)

***En anglais : &lt;Drive variable&gt;.ListDirectory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les répertoires d'un drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

ResEnvoi est un booléen
oMonDrive est un Drive
oMonDrive = oDriveConnecte(oOAuth2Param)

UnRépertoire, ResListeRépertoire sont des chaînes
// Liste tous les répertoires dans mon drive depuis le répertoire "MesPhotos".
// Le parcours se fait uniquement dans le répertoire courant 
ResListeRépertoire = oMonDrive.ListeRépertoire("/MesPhotos/", frNonRécursif)

// Pour chaque répertoire trouvé, ajout dans un champ Table
POUR TOUTE CHAÎNE UnRépertoire DE ResListeRépertoire SÉPARÉE PAR RC
	// Ajout du répertoire dans le champ Table TABLE_TableRépertoire
	TABLE_TableRépertoire.Ajoute(UnRépertoire)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Drive>.ListeRépertoire(<Répertoire de départ> [, <Options>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des répertoires présents sur le drive spécifié, à l'emplacement spécifié. Cette liste est de la forme : 

```txt
<Nom du répertoire 1> + RC + ... + <Nom du répertoire N>
```


**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, les répertoires ne sont pas listés.

**`<Répertoire de départ> : (Chaîne de caractères)`**

Chemin du répertoire dans le drive à partir duquel les répertoires doivent être listés. Ce chemin correspond à un chemin absolu du drive : 

- Les noms des répertoires doivent être séparés par des '/' ou des '\\'.

- Le nom des répertoires doit débuter par un '/' ou un '\\'.


Si le chemin est invalide, une erreur sera générée.

**`<Options> : (Constante optionnelle de type Entier)`**

Type de parcours effectué :



|   |   |
| --- | --- |
| *frNonRécursif* | Le parcours est non récursif. Les sous-répertoires ne sont pas pris en compte. |
| *frRécursif*<br>(Valeur par défaut) | Le parcours est récursif. Les sous-répertoires sont automatiquement pris en compte. |

### Paramètre &lt;Répertoire de départ&gt;
<a name="parametre_ELTPARAGRAPHE000200"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
