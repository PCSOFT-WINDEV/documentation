


## ScanDepuisCaméraVersImage (Fonction)

***En anglais : ScanFromCameraToImage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre une fenêtre spécifique permettant de numériser sous forme d'image un ou plusieurs documents à l'aide de la caméra du téléphone ou de la tablette. Les documents scannés peuvent être retouchés. Un bouton "+" permet de scanner plusieurs pages ou documents. 

**Remarque** : Cette fenêtre est identique quelle que soit la version du périphérique utilisé. Le périphérique doit supporter la fonctionnalité de scan. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCÉDURE INTERNE onScan(EtatScan, docs est un tableau d'Image)
		SELON EtatScan
			CAS sdcEchec
				ToastAffiche("Erreur du scan : " + ErreurInfo)
			CAS sdcAnnulation
				ToastAffiche("Scan annulé par l'utilisateur")
			CAS sdcSuccès
				POUR TOUT img_scannée DE docs
					TraitementImage(img_scannée)
				FIN
		FIN
FIN
ScanDepuisCaméraVersImage(onscan)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ScanDepuisCaméraVersImage(<Procédure WLangage> [, <Nombre de pages maximum>])`
---

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également nommée "callback") exécutée à la fin du scan ou bien en cas d'échec ou annulation par l'utilisateur.
Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction ScanDepuisCaméraVersImage](../WDLang3/1410090546.md). 

**`<Nombre de pages maximum> : (Entier optionnel)`**

Nombre de pages maximum pouvant être scannées. Si ce paramètre vaut 0 ou n'est pas spécifié, il n'y a pas de limite.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Ce paramètre est interdit.

## Remarques


### Récupération des documents PDF
<a name="recuperation_des_documents_pdf_ELTPARAGRAPHE000055"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Pour chaque page scannée, une image au format JPEG sera enregistrée dans le répertoire cache interne de l'application.

- Les images scannées sont enregistrées dans un tableau de documents PDF, accessible dans la procédure WLangage exécutée à la fin du scan.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000067"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : WRITE_EXTERNAL_STORAGE

Cette permission autorise l'application à écrire un stockage externe.
