
## SynthèseVocaleArrête (Fonction)

***En anglais : SpeechSynthesisStop***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stoppe toutes les lectures en cours du moteur de synthèse vocale.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI SynthèseVocaleEnCours() = Vrai ALORS
	SynthèseVocaleArrête()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`SynthèseVocaleArrête()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Seules les lectures lancées par l'application sont arrêtées. Pour savoir si une lecture est en cours par le moteur de synthèse vocale, utilisez la fonction [SynthèseVocaleEnCours](../WDLang3/1000020173.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 1.6 (api level 4).
	Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. 
	Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure à la version 6. La synthèse vocale ne fonctionne pas sur les émulateurs iOS 8.
