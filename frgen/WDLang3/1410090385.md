


## &lt;Variable ActionRapide&gt;.Ajoute (Fonction)

***En anglais : &lt;QuickAction variable&gt;.Add***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une nouvelle action rapide à l'application. Cette action rapide apparaîtra dans le menu contextuel de l'icône de raccourci de l'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
action est une ActionRapide
action.Identifiant = "ID_ACTION_ENVOI_MESSAGE"
action.Libellé = "Envoyer un message"
action.Procédure = ProcEnvoiMessage // ProcEnvoiMessage est une procédure globale
SI action.Ajoute() ALORS
	ToastAffiche("Action ajoutée.")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Action>.Ajoute()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'action rapide a été ajoutée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.




**`<Action> : (Variable de type ActionRapide)`**

Variable de type [ActionRapide](../WDLang3/1410090054.md) décrivant l'action à ajouter.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si une action rapide avec le même identifiant a déjà été ajoutée pour l'application, elle sera mise à jour avec les informations contenues dans la variable [ActionRapide](../WDLang3/1410090054.md) passée en paramètre.

- Pour lister les actions rapides déjà ajoutées pour l'application, utilisez la fonction [ActionRapideListe](../WDLang3/1410090067.md).

- Pour supprimer une action rapide définie pour l'application, utilisez la fonction [&lt;Variable ActionRapide&gt;.Supprime](../WDLang3/1410090386.md).
