
## RendezVousAffiche (Fonction)

***En anglais : AppointmentDisplay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche un rendez-vous dans l'application native de gestion des rendez-vous de l'appareil mobile (Android ou iOS).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI PAS RendezVousAffiche(rdv) ALORS
	Erreur("Impossible d'afficher le rendez-vous.", ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = RendezVousAffiche(<Rendez-vous>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la description du rendez-vous a pu être affichée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Rendez-vous> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) correspondant au rendez-vous dont la description doit être affichée. Ce rendez-vous doit exister et appartenir à un calendrier de l'appareil (obtenu par la fonction [RendezVousListe](../WDLang3/1000020690.md)).

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000058"></a>

- La fonction **RendezVousAffiche** rend la main à l'application immédiatement après l'affichage de la description du rendez-vous dans l'application native.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) La fonction **RendezVousAffiche** peut être utilisée dans l'émulateur mais pas dans le simulateur.



<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000205"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **RendezVousAffiche** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
