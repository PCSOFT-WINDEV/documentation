


## EmailAbonneAuDossier (Fonction)

***En anglais : EmailSubscribeToFolder***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un dossier existant à la liste des dossiers abonnés. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXX"
session.MotDePasse = "XXXXXXX"
EmailOuvreSession(session)

// Liste des dossiers de gestion des mails et des dossiers abonnés
res est chaîne
res = EmailListeDossier(session, LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
// Abonne le dossier "Test"
Trace("Abonnement : " + (EmailAbonneAuDossier(session, "Test") ? "OK" sinon "KO"))
Trace("---------------------------------------------------")
// Liste des dossiers de gestion des mails et des dossiers abonnés
// Le dossier Test est désormais listé
res = EmailListeDossier(session, LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EmailAbonneAuDossier(<Session IMAP> , <Dossier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le dossier spécifié a été abonné, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Session IMAP> : (Variable de type emailSessionIMAP)`**

Nom de la variable de type [emailSessionIMAP](../WDLang3/1000018957.md) correspondant à la session IMAP connectée au serveur de mails. 

**`<Dossier> : (Chaîne de caractères)`**

Nom et chemin du dossier à ajouter dans la liste des dossiers abonnés.



<a name="NOTE0"></a>

## Remarques


- Les dossiers créés avec la fonction [EmailAjouteDossier](../WDLang3/3032129.md) sont automatiquement abonnés. 

- La fonction [EmailListeDossier](../WDLang3/3032133.md) utilisée avec la constante *LstDossierNormal* liste les dossiers contenant les emails et les dossiers abonnés. Si un dossier abonné contient des sous dossiers, ces sous dossiers seront également listés. 

- La fonction [EmailListeDossier](../WDLang3/3032133.md) utilisée avec la constante *LstDossierTous* liste tous les dossiers (dossiers contenant les emails et dossiers abonnés ou non abonnés).
