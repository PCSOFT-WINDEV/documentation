


## Procédure WLangage appelée par la fonction BTLECaractéristiqueChangementValeur



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure (également appelée "Callback") appelée par la fonction [BTLECaractéristiqueChangementValeur](../WDLang3/1000022071.md) lorsqu'une caractéristique change sur l'appareil. Cette procédure peut être une procédure locale, globale ou interne. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
caractéristique est une btleCaractéristique
BTLECaractéristiqueChangementValeur(caractéristique, CB_ChangementValeur)
// ===========================
PROCÉDURE CB_ChangementValeur(caractéristique est une btleCaractéristique <utile>, bufValeur est un Buffer)
// Récupération de la valeur et affichage dans un champ Libellé
sBuf est une chaîne ANSI = bufValeur
LIB_ValeurAbonnement = sBuf
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`BTLECaractéristiqueChangementValeur_Callback(<Caractéristique> , <Valeur>)`
---

**`<Caractéristique> : (Variable de type btleCaractéristique)`**

Variable de type [btleCaractéristique](../WDLang3/1000022060.md) correspondant à la caractéristique du périphérique Bluetooth dont la valeur a changé.

**`<Valeur> : (Buffer)`**

Nouvelle valeur de la caractéristique.
