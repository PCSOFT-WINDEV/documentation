


## AuthDéconnecte (Fonction)

***En anglais : AuthLogout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déconnecte un utilisateur précédemment authentifié via : 

- le protocole OAuth 2.0 sur un service Web quelconque.

- le protocole OpenID sur un service Web quelconque.
	

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) un token JWT.




Remarques : 

- La déconnexion ouvre un navigateur (comme pour la connexion). L'URL de redirection est appelée lorsque la déconnexion est effectuée. A la prochaine connexion, le processus de connexion devra être entièrement refait.

- Lors de l'utilisation d'une variable de type [OAuth2Paramètres](../WDLang3/1000022212.md), il est nécessaire de spécifier l'URL de déconnexion avec la propriété **URLDéconnexion**. 

- **Pour une configuration IOS**, cette fonction n'est pas disponible. Il est conseillé d'utiliser la fonction [AuthRévoqueToken](../WDLang3/1410090634.md). 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
stOpenIdParam est un OpenIDParamètres
stOpenIdParam.URLConfiguration = "https://login.microsoftonline.com/99f49690-a048-4e6e-a51e-9e6e96b4981d/v2.0/.well-known/openid-configuration"
stOpenIdParam.ClientID = "99f10db4-c3b1-437f-8362-8070750f0190"
stOpenIdParam.Scope = "email openid"
stOpenIdParam.URLRedirection = "http://localhost:9874"
stToken est un AuthToken = AuthIdentifie(stOpenIdParam)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
identite est un OpenIDIdentité = OpenIDLitIdentité(stToken)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
Trace(identite.Email)
AuthDéconnecte(stToken)
```

## Syntaxe
<a name="SYNTAXE2"></a>

### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0

`<Résultat> = AuthDéconnecte(<Authentification OAuth>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la déconnexion a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Authentification OAuth> : (Variable de type OAuth2Paramètres)`**

Nom de la variable de type [OAuth2Paramètres](../WDLang3/1000022212.md) correspondant à la connexion à fermer. La propriété **URLDéconnexion** permet d'indiquer la page à afficher lors de la déconnexion. 


<a name="SYNTAXE3"></a>

### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0 (syntaxe asynchrone)

`AuthDéconnecte(<Authentification OAuth> , <Procédure WLangage>)`
---

**`<Authentification OAuth> : (Variable de type OAuth2Paramètres)`**

Nom de la variable de type [OAuth2Paramètres](../WDLang3/1000022212.md) correspondant à la connexion à fermer. La propriété **URLDéconnexion** permet d'indiquer la page à afficher lors de la déconnexion. 

**`<Procédure WLangage> : (Nom de procédure)`**

Procédure WLangage optionnelle qui sera appelée lors de la déconnexion. Cette procédure est de la forme : 

```txt
<Nom de la procédure>(<Déconnexion>)
```
 où &lt;Déconnexion&gt; est un booléen permettant de savoir si la déconnexion a été effectuée (<u><u><u><u>Vrai</u></u></u></u>) ou non (<u><u><u><u>Faux</u></u></u></u>).
