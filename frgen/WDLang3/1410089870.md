
## NotifPushAbonne (Fonction)

***En anglais : NotifPushSubscribe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Abonne l'application Android en cours aux notifications push relatives à un sujet. L'application recevra automatiquement les notifications push envoyées avec la fonction [NotifPushEnvoieAbonné](../WDLang3/1410089872.md) pour le sujet spécifié.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Demande à recevoir les notifications push du sujet "score"
NotifPushAbonne("score")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = NotifPushAbonne(<Sujet>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'abonnement a été effectué, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître l'erreur renvoyée par le service de notification.




**`<Sujet> : (Chaîne de caractères)`**

Sujet (ou topic) associé aux notifications push auxquelles l'application veut s'abonner.
