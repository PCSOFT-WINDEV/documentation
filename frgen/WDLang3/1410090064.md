


## ActionRapideSupprime (Fonction)

***En anglais : QuickActionRemove***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une action rapide de l'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ActionRapideSupprime("ID_ACTION_ENVOI_MESSAGE")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Supprimer une action rapide identifiée par une variable de type ActionRapide

`<Résultat> = ActionRapideSupprime(<Action>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'action rapide a été supprimée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.




**`<Action> : (Variable de type ActionRapide)`**

Variable de type [ActionRapide](../WDLang3/1410090054.md) décrivant l'action à supprimer


<a name="SYNTAXE2"></a>

### Supprimer une action rapide identifiée par son identifiant

`<Résultat> = ActionRapideSupprime(<Identifiant>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'action rapide a été supprimée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.




**`<Identifiant> : (Chaîne de caractères)`**

Identifiant de l'action rapide à supprimer.
