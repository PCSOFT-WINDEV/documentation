
## zipParamètreCréationExe (Type de variable)

***En anglais : zipParamètreCréationExe***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **zipParamètreCréationExe** permet de définir toutes les informations nécessaires à la création d'une archive auto-extractible sous forme d'un exécutable (.EXE). Ces informations peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

Ce type de variable doit être passé en paramètre à la fonction [zipCréeExe](../WDLang3/3082013.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Archive à transformer en archive auto-extractible
MonArchive est une zipArchive

// Ouverture de l'archive
SI zipOuvre(MonArchive, "D:\Sauvegardes\Sauvegarde.zip") = 0 ALORS
	// Paramétrage de la création de l'archive auto-extractible
	ParamExe est un zipParamètreCréationExe
	ParamExe.CheminExe = "C:\Répertoires\Archive.exe"
	ParamExe.OptionRépertoire = zipRepCourant
	ParamExe.Icone = "Icone.ico"
	// Création d'une archive auto-extractible
	zipCréeExe(MonArchive, ParamExe)
	...
FIN
```





<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type zipParamètreCréationExe 
<a name="proprietes_specifiques_description_des_variables_type_zipparametrecreationexe_ELTPARAGRAPHE000037"></a>Les propriétés suivantes peuvent être utilisées pour manipuler les paramètres de création d'une archive auto-extractible :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| AvecUI | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si une boîte de dialogue doit être affichée : l'utilisateur peut ainsi choisir le répertoire de destination de l'extraction, <br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) si aucune boîte de dialogue ne doit être affichée.<br><br><br> |
| CheminExe | Chaîne de caractères | Chemin de l'exécutable à créer (260 caractères maximum). Ce chemin peut correspondre à un chemin relatif au répertoire en cours ou à un chemin complet.<br>L'extension ".EXE" est obligatoire. |
| ChoixRespecterArborescence | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> pour afficher la case à cocher "Conserver l'arborescence" dans l'UI d'extraction, <br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) dans le cas contraire. <br><br><br> |
| Exe64 | Booléen | Mode d'exécution de l'exécutable d'auto-extraction : <br><br>- <u><u><u>Vrai</u></u></u> pour générer un exécutable d'auto-extraction en 64 bits.<br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) pour générer un exécutable d'auto-extraction en 32 bits.<br><br><br> |
| ExécutionAdministrateur | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> pour lancer l'exécutable créé en tant qu'administrateur. Ce mode permet d'éviter la virtualisation des fichiers à partir de Windows Vista.<br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) dans le cas contraire. <br><br><br> |
| Icône | Chaîne de caractères | Chemin du fichier icône représentant l'exécutable créé. Ce chemin peut correspondre à un chemin relatif au chemin en cours ou à un chemin complet.<br>Si ce paramètre n'est pas précisé, une icône par défaut sera attribuée à l'exécutable. |
| OptionRépertoire | Constante de type Entier | Options de répertoire d'extraction :<br><br>- *zipRepCourant* : Tous les fichiers de l'archive seront extraits dans le répertoire en cours.<br><br>- *zipRepDéfaut* : Utilise le répertoire spécifié par défaut (propriété **RépertoireExtraction**).<br><br>- *zipRepTemporaire* (Valeur par défaut) : Les fichiers de l'archive seront extraits dans le répertoire temporaire de la machine sur laquelle l'exécutable est lancé. Tous les fichiers de l'archive sont extraits au même endroit.<br><br><br> |
| RépertoireExtraction | Chaîne de caractères | Répertoire proposé par défaut par la fenêtre de décompression (si la propriété **AvecUI** vaut <u><u><u>Vrai</u></u></u>). <br><br>Remarque : Si l'interface de l'extraction n'est pas proposée, ce répertoire sera utilisé par défaut pour extraire les fichiers de l'archive. |
| RespecterArborescence | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> : les fichiers de l'archive seront extraits en respectant l'arborescence des répertoires contenus dans l'archive.<br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) : tous les fichiers de l'archive seront extraits dans le même répertoire.<br><br><br> |
| Traduction | Chaîne de caractères | Chemin complet du fichier au format INI contenant la traduction des messages de l'auto-extracteur (voir Remarques). <br><br>Si cette propriété correspond à chaîne vide (""), le fichier de traduction par défaut sera utilisé. |
| Version | Chaîne de caractères | Numéro de version de l'exécutable créé. Ce numéro doit être de la forme : <br><pre><code><Version majeure>.<Version mineure>.<br><Numéro de compilation>.<Numéro de révision></code></pre><br>Exemple "30.12.15.3". <br><br>Ce numéro de version peut ensuite être connu via la fonction [ExeInfo](../WDLang1/3035001.md) avec la constante *exeVersionFormatWindows*.<br><br>Si cette propriété n'est pas spécifiée, un numéro de version par défaut sera défini (dépendant de la version utilisée pour créer l'archive autoextractible). |

## Remarques


### Traduction de l'interface de l'auto-extracteur (propriété Traduction)
<a name="traduction_interface_autoextracteur_propriete_traduction_ELTPARAGRAPHE000181"></a>Par défaut, l'auto-extracteur est livré en trois langues : français, anglais et espagnol. La langue de l'auto-extracteur s'adapte en fonction de la langue de l'exécutable ou de la langue spécifiée par la fonction [Nation](../WDLang1/3054014.md).  

L'interface de l'auto-extracteur peut utiliser une langue différente de la langue par défaut (le français).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=zipcreeExe%20-%20HC%20N%B0001.gif)
Pour cela, il suffit de créer un fichier .INI contenant les informations suivantes :

```txt
[GENERAL]
NATIONDEFAUT=1
[WDAUTOEX01]
R000=Archive Autoextractible PC SOFT
R001=Extraire le contenu de l'archive dans le répertoire :
R002=Conserver l'arborescence
R003=Extraire
R004=Fermer
```
Par exemple pour obtenir une interface en anglais :

```txt
[GENERAL]
NATIONDEFAUT=1
[WDAUTOEX01]
R000=Self-Extracting PC SOFT archive
R001=Extract the content of the archive in the directory:
R002=Keep the tree structure 
R003=Extract
R004=Close
```
**Attention** : Les trois premières lignes de ce fichier ne doivent pas être modifiées.

Dans les lignes suivantes, indiquez la traduction voulue.
