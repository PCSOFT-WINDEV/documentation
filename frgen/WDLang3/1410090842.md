
## Procédure WLangage appelée par la fonction ScanDepuisCaméraVersPDF



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") exécutée à la fin du scan réalisé avec la fonction [ScanDepuisCaméraVersPDF](../WDLang3/1410090790.md) (ou bien en cas d'échec ou annulation par l'utilisateur).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCÉDURE INTERNE onScan(EtatScan, MonPDF est un pdfDocument)
	SELON EtatScan
		CAS sdcEchec
			ToastAffiche("Erreur du scan : " + ErreurInfo)
		CAS sdcAnnulation
			ToastAffiche("Scan annulé par l'utilisateur")
		CAS sdcSuccès
			PDFSauve(MonPDF, "MonScan.pdf")
	FIN
FIN
ScanDepuisCaméraVersPDF(onscan)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ScanDepuisCaméraVersPdf_Callback(<Etat du scan> , <Document PDF>)`
---

**`<Etat du scan> : (Constante de type Entier)`**

Etat de l'opération de scan :


|   |   |
| --- | --- |
| *sdcAnnulation* | L'utilisateur a abandonné le scan des documents. |
| *sdcEchec* | Le scan des documents a rencontré une erreur. La fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus d'informations. |
| *sdcSuccès* | Les documents ont bien été scannés. |



**`<Document PDF> : (Variable de type pdfDocument)`**

Variable de type [pdfDocument](../WDLang6/1000024909.md) contenant l'ensemble des documents scannés au format PDF. Il est ensuite possible de sauver ce document (fonction [PDFSauve](../WDLang6/1000024864.md)) ou de manipuler son contenu avec les [fonctions PDF](../WDLang6/1000015007.md).
