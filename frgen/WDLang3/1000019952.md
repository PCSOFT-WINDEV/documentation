


## CarteSupprimeTout (Fonction)

***En anglais : MapDeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime dans un champ Carte : 

- tous les marqueurs, 

- toutes les formes,

- toutes les images.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Si des itinéraires ont été ajoutés à la carte (fonction [CarteAjouteItinéraire](../WDLang3/1000020383.md)), ils sont également supprimés.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression de tous les marqueurs du champ Carte
CarteSupprimeTout(CARTE_MaCarte)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`CarteSupprimeTout([<Champ Carte>])`
---

**`<Champ Carte> : (Nom de champ optionnel)`**

Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, le champ Carte auquel appartient l'événement en cours sera utilisé.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Gestion des marqueurs : 

	- Pour supprimer un marqueur en particulier affiché dans un champ Carte, utilisez la fonction [CarteSupprimeMarqueur](../WDLang3/1000019795.md).

	- Pour ajouter un nouveau marqueur sur un champ Carte, utilisez la fonction [CarteAjouteMarqueur](../WDLang3/1000019794.md).

	- Pour modifier un marqueur affiché dans un champ Carte, utilisez la fonction [CarteModifieMarqueur](../WDLang3/1000019796.md).




- Gestion des itinéraires : Pour supprimer un itinéraire particulier, utilisez la fonction [CarteSupprimeItinéraire](../WDLang3/1000020384.md).

- Gestion des images : 

	- Pour supprimer une image spécifique affichée dans un champ Carte, utilisez la fonction [CarteSupprimeImage](../WDLang3/1000025534.md). 

	- Pour ajouter une nouvelle image dans un champ Carte, utilisez la fonction [CarteAjouteImage](../WDLang3/1000025532.md). 

	- Pour modifier une image dans un champ Carte, utilisez la fonction [CarteModifieImage](../WDLang3/1000025533.md). 




- Gestion des formes : 

	- Pour supprimer une forme spécifique affichée dans un champ Carte, utilisez la fonction [CarteSupprimeForme](../WDLang3/1000025510.md). 

	- Pour ajouter une nouvelle forme dans un champ Carte, utilisez la fonction [CarteAjouteForme](../WDLang3/1000025509.md). 

	- Pour modifier une forme dans un champ Carte, utilisez la fonction [CarteModifieForme](../WDLang3/1000025511.md).
