


## BTLEInitialise (Fonction)

***En anglais : BTLEInitialize***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise le Bluetooth Low Energy.
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette fonction doit obligatoirement être appelée avant d'utiliser toute autre fonction WLangage de gestion du Bluetooth Low Energy.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Cette fonction est inutile en Android. L'initialisation est automatique. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
BTLEInitialise(InitBTLE)

	PROCEDURE INTERNE InitBTLE(nEtat est un entier)
		SI nEtat = btActif ALORS
			BTLEListePériphérique(ScanBTLE)
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`BTLEInitialise(<Procédure WLangage>)`
---

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (appelée "callback") appelée lorsque le Bluetooth Low Energy est initialisé sur l'appareil. Cette procédure est de la forme : 

```txt
PROCEDURE <Nom de la procédure> (<Etat du Bluetooth Low Energy>)
```

où &lt;Etat du Bluetooth Low Energy&gt; correspond à l'état d'activation du Bluetooth Low Energy sur l'appareil. Cet état peut correspondre à l'une des constantes (de type entier) suivantes : 



|   |   |
| --- | --- |
| *btActif* | Le Bluetooth est activé sur l'appareil. |
| *btActivationEnCours* | Le Bluetooth est en cours d'activation sur l'appareil.<br><br>![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Cette constante n'est pas disponible. |
| *btDésactivationEnCours* | Le Bluetooth est en cours de désactivation sur l'appareil.<br><br>![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Cette constante n'est pas disponible. |
| *btDésactivé* | Le Bluetooth est désactivé sur l'appareil. |

<a name="NOTE0_1"></a>

## Remarques


- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Si le Bluetooth Low Energy n'est pas disponible (version inférieure à iOS 9.0), la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et la fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.

- **Versions nécessaires**
	

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Applications ANDROID** : 

		- Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.3 (api level 18). 

		- Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. 

		- Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](../WDLang1/1000019785.md).




- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **Applications iOS** : 
			Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur les appareils disposant d'iOS 9. 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) **Applications WINDEV** : 

	- Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur :  

		- les PC gérant le Bluetooth Low Energy version 5 minimum. 

		- les PC utilisant une clé Bluetooth gérant le Bluetooth Low Energy version 5 minimum.
