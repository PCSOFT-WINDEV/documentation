
## Fonctions de gestion du partage de proximité
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion du partage de proximité sont les suivantes : 



|   |   |
| --- | --- |
| [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md) | Accepte la demande de connexion d'un appareil distant. |
| [PartageProximitéAfficheCode](../NonDocumente/1410090794.md) | Affiche le code de confirmation pour un partage de proximité. |
| [PartageProximitéArrêteAttente](../WDLang3/1410090647.md) | Arrête l'attente de la connexion des appareils aux autres appareils à proximité. |
| [PartageProximitéArrêteRecherche](../WDLang3/1410090649.md) | Arrête la recherche des appareils distants. |
| [PartageProximitéArrêteTout](../WDLang3/1410090668.md) | Arrête le ou les partages de proximité en cours. |
| [PartageProximitéAttendConnexion](../WDLang3/1410090655.md) | Rend l'appareil visible aux appareils distants qui sont en mode "recherche à proximité" (via la fonction [PartageProximitéRechercheAppareil](../WDLang3/1410090648.md)) et attend leur demande de connexion. |
| [PartageProximitéDéconnecte](../WDLang3/1410090652.md) | Ferme la connexion avec un appareil distant. |
| [PartageProximitéDemandeConnexion](../WDLang3/1410090650.md) | Demande la connexion à un appareil distant. |
| [PartageProximitéEnvoie](../WDLang3/1410090653.md) | Envoi des données (buffer binaire) à un ou plusieurs appareil(s) distant(s) au(x)quel(s) on est connecté. |
| [PartageProximitéRechercheAppareil](../WDLang3/1410090648.md) | Recherche les appareils à proximité qui ont annoncé leur présence et en attente de connexion. |
| [PartageProximitéRefuseConnexion](../WDLang3/1410090651.md) | Refuse la demande de connexion d'un appareil distant. |
