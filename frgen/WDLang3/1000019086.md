


## &lt;Variable zipArchive&gt;.Ferme (Fonction)

***En anglais : &lt;zipArchive variable&gt;.Close***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme une archive.

<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
MonArchive est un zipArchive
// Ouverture d'une archive
ResOuvreArchive = MonArchive.Ouvre("C:\Archives\Archive.zip")

SI ResOuvreArchive = 0 ALORS
	// Traitements
	...
	// Fermeture de l'archive
	MonArchive.Ferme()
FIN
```

<a name="SYNTAXE1"></a>

## Syntaxe

`<Archive>.Ferme()`
---

**`<Archive> : (Variable de type zipArchive)`**

Nom d'une variable de type [zipArchive](../WDLang3/1000018679.md) correspondant à l'archive à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000234"></a>

- La fermeture d'une archive ne peut être réalisée que si :

	- L'archive est ouverte. L'ouverture d'une archive s'effectue avec la fonction [&lt;Variable zipArchive&gt;.Ouvre](../WDLang3/1000019097.md).

	- L'archive existe. La création d'une archive s'effectue avec la fonction [&lt;Variable zipArchive&gt;.Crée](../WDLang3/1000019160.md).




- A l'arrêt de l'application, toutes les archives manipulées seront automatiquement fermées.

- Une erreur du WLangage est affichée si l'archive à fermer n'existe pas. Le programme est alors arrêté.
