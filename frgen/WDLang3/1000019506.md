
## ContactAffiche (Fonction)

***En anglais : ContactDisplay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre la fiche d'un contact dans l'application native de gestion des contacts de l'appareil (Android, iPhone ou iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple



<a name="Exemple2"></a>

```wl
// Procédure permettant d'afficher le contact sélectionné dans un champ Zone répétée
PROCEDURE AfficheContact(nNumContact est un entier)
tContact est un Contact
SI nNumContact <= gtabContacts.Occurrence ALORS
	tContact = gtabContacts[nNumContact]
	// Initialise le contact
	VariableRAZ(gContactEnCours)
	gContactEnCours = tContact
	ContactAffiche(gContactEnCours)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Afficher un contact à partir d'une variable de type Contact

`<Résultat> = ContactAffiche(<Contact>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la fiche du contact a pu être ouverte, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Contact> : (Variable de type Contact)`**

Nom de la variable de type [Contact](../WDLang3/1000020254.md) correspondant au contact à afficher. Ce contact doit exister dans la base des contacts.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000108"></a>

- La fonction **ContactAffiche** rend la main à l'application immédiatement après l'affichage de la fiche du contact.

- La fonction **ContactAffiche** peut être utilisée dans l'émulateur. Elle ne peut pas être utilisée dans le simulateur.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000260"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **ContactAffiche** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
