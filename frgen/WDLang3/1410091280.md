


## &lt;Variable zipArchive&gt;.DébutAjoutFichier (Fonction)

***En anglais : &lt;zipArchive variable&gt;.StartAddingFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Débute une série d'ajouts optimisés de fichiers dans une archive de type CAB, ZIP, WDZ, 7z, TAR, gzip ou TGZ (TAR.GZ).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Début des ajouts optimisés de fichiers
MonArchive.DébutAjoutFichier()
// Ajout des fichiers dans l'archive
POUR TOUT CheminFichier DE tabListeFichier
	MonArchive.AjouteFichier(CheminFichier)
FIN
// Fin ajouts optimisés de fichiers 
MonArchive.FinAjoutFichier()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Archive>.DébutAjoutFichier()`
---

**`<Résultat> : (Entier)`**



- 0 si la déclaration du début d'ajout de fichiers a été effectuée,

- un code d'erreur (valeur supérieure à 0) dans le cas contraire. Pour plus de détails sur ces codes d'erreur, consultez les remarques.




**`<Archive> : (Variable de type zipArchive)`**

Nom de la variable de type [zipArchive](../WDLang3/1000018679.md) correspondant à l'archive dans laquelle on veut débuter l'ajout de fichiers optimisé.

<a name="NOTE0_1"></a>

## Remarques


### Dans quels cas utiliser l'ajout optimisé de fichiers dans une archive
<a name="dans_quels_cas_utiliser_ajout_optimise_fichiers_dans_une_archive_ELTPARAGRAPHE000209"></a>Pour les archives de type ZIP, WDZ et 7Z, certaines opérations permettant d'obtenir une archive valide sont effectuées lors de chaque ajout. Ces opérations peuvent influer sur le temps de création d'une archive. 

Ainsi, une succession d'ajouts de fichiers via la fonction [&lt;Variable zipArchive&gt;.AjouteFichier](../WDLang3/1000019050.md) est plus chronophage que l'ajout de ces mêmes fichiers via la fonction [&lt;Variable zipArchive&gt;.AjouteListeFichier](../WDLang3/1000019159.md). En effet, avec la fonction [&lt;Variable zipArchive&gt;.AjouteListeFichier](../WDLang3/1000019159.md), les opérations de vérification ne sont effectuées qu'une seule fois. 

Pour obtenir un comportement similaire en utilisant la fonction [&lt;Variable zipArchive&gt;.AjouteFichier](../WDLang3/1000019050.md), il est nécessaire de réaliser les ajouts entre les fonctions **&lt;Variable zipArchive&gt;.DébutAjoutFichier** et [&lt;Variable zipArchive&gt;.FinAjoutFichier](../WDLang3/1410091281.md). 

Remarque : Cette fonction n'est pas utilisable sur les archives de type RAR et n'est utile que pour les archives de type ZIP, WDZ et 7Z.


### Comment utiliser les ajouts optimisés ? 
<a name="comment_utiliser_les_ajouts_optimises_ELTPARAGRAPHE000253"></a>Pour réaliser des ajouts optimisés : 

1. Appelez la fonction **&lt;Variable zipArchive&gt;.DébutAjoutFichier**. L'archive est en attente de l'ajout des fichiers. 

2. Utilisez la fonction [&lt;Variable zipArchive&gt;.AjouteFichier](../WDLang3/1000019050.md) pour ajouter les différents fichiers voulus. Toutes les caractéristiques de cette fonction restent valables. 

3. Terminez l'ajout des fichiers avec la fonction [&lt;Variable zipArchive&gt;.FinAjoutFichier](../WDLang3/1410091281.md). 




Remarques : 

- Tout appel à une fonction autre que [&lt;Variable zipArchive&gt;.AjouteFichier](../WDLang3/1000019050.md) sur l'archive entre un appel aux fonctions **&lt;Variable zipArchive&gt;.DébutAjoutFichier** et [&lt;Variable zipArchive&gt;.FinAjoutFichier](../WDLang3/1410091281.md) provoquera une erreur fatale.

- Il est obligatoire d'utiliser la fonction [&lt;Variable zipArchive&gt;.FinAjoutFichier](../WDLang3/1410091281.md) après la fonction **&lt;Variable zipArchive&gt;.DébutAjoutFichier** pour obtenir une archive valide.





### Codes d'erreur 
<a name="codes_erreur_ELTPARAGRAPHE000306"></a>Les codes d'erreur retournés sont les suivants :

- 1 : Le chemin passé en paramètre n'existe pas.

- 3 : L'archive est corrompue.
