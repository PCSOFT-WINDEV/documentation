
## ftpConnexion (Type de variable)

***En anglais : ftpConnection***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **ftpConnexion** permet de définir toutes les caractéristiques avancées d'une connexion FTP. 

Ce type de variable peut être utilisé: 

- avec la fonction [FTPConnecte](../WDLang3/3040016.md). 
	

- via une variable [hDescriptionSauvegarde](../WDLang4/1000017455.md) pour mettre en place le téléchargement des sauvegardes par FTP ou SFTP. 




Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarques**: 

- La fonction [FTPParamètre](../WDLang3/1000020947.md) permet de modifier le comportement des fonctions FTP. Lors de l'utilisation d'une variable de type **ftpConnexion**: 

	- Le mode de fonctionnement du FTP (constante *ftpParamètreMode*) est forcé à 1: les fonctions de gestion du FTP utilisent une implémentation native du FTP et indépendante de Windows, avec le support d'UTF8.

	- Le mode de chiffrement (constante *ftpesParamètreModeSécurisé*) est déterminé par la propriété **ModeFTPES** de la variable de type **ftpConnexion**. 

	- La constante *ftpParamètreRéutiliseConnexion* permettra de forcer ou non la réutilisation de la connexion vers un serveur FTP entre deux requêtes (par défaut, la connexion est réutilisée).




- Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Upload d'une sauvegarde sur un serveur FTP
Sauvegarde_Doc est une hDescriptionSauvegarde
Sauvegarde_Doc.Description = "SauvegardeAvecDroit"
Sauvegarde_Doc.AvecIndex = Vrai
Sauvegarde_Doc.Destination = "Back/SauvegardeAvecDroit"
Sauvegarde_Doc.Source = "Anonymisation/*"

Sauvegarde_Doc.Ftp.Connexion.Serveur = "chorizo-2k8"
Sauvegarde_Doc.Ftp.Connexion.Utilisateur = "TT"
Sauvegarde_Doc.Ftp.Connexion.MotDePasse = "TT"
Sauvegarde_Doc.Ftp.Connexion.NuméroPort = 22
Sauvegarde_Doc.Ftp.Connexion.TypeConnexion = ftpModeActif
Sauvegarde_Doc.Ftp.CheminDestination = "/tmp"

// Enregistrement de la sauvegarde 
HSauvegarde(MaConnexion, Sauvegarde_Doc)
```

## Propriétés


### Propriétés spécifiques à la description des variables de type ftpConnexion
<a name="proprietes_specifiques_description_des_variables_type_ftpconnexion_ELTPARAGRAPHE000064"></a>

Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **ftpConnexion**:

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| CléPrivée | Chaîne de caractères | Nom et chemin du fichier correspondant à la clé privée utilisée lors d'une connexion en mode SFTP. Ce fichier doit avoir été généré au format OpenSSH. <br><br>Par défaut, la connexion sécurisée utilise une authentification par &lt;Utilisateur&gt; / &lt;MotDePasse&gt;. |
| DuréeNonRéponse | Entier | Nombre de secondes au bout desquelles la requête de connexion au serveur FTP est abandonnée (par défaut 20). <br><br>Ce délai s'applique à toutes les opérations FTP réalisées sur cette connexion. Si aucune réponse du serveur n'est obtenue dans la durée spécifié, la connexion échoue. <br><br>Cette propriété peut correspondre à: <br><br>- un entier correspondant au nombre de secondes, <br><br>- une variable de type Durée, <br><br>- l'indication directe de la durée (par exemple '1s').<br><br><br> |
| IgnoreErreur | Constante de type Entier | Lors d'une connexion sécurisée, certaines erreurs de sécurité peuvent faire échouer la fonction. Il est possible de se connecter en ignorant ces erreurs grâce aux constantes suivantes: <br><br>- *ftpIgnoreCertificatInvalide*: Le certificat est ignoré.<br><br>- *ftpIgnoreCertificatExpiré*: La date du certificat est ignorée.<br><br>- *ftpIgnoreNomCertificatInvalide*: Le nom du site figurant dans le certificat est ignoré.<br><br>- *ftpIgnoreDéprécié*: Ignore les erreurs en lien avec l'utilisation d'algorithmes dépréciés (exemple: signature de certificat en SHA-1).<br><br>- *ftpIgnoreRenégociationNonSecurisée*: Ignore l'erreur stipulant que le serveur ne supporte pas la renégociation sécurisée (RFC 5746).<br><br>- *ftpIgnoreRévocation*: La révocation du certificat est ignorée.<br><br><br>Ces erreurs sont ignorées uniquement pour l'instance de la connexion en cours. <br><br> |
| ModeFTPES | Constante de type Entier | Permet de modifier le chiffrement en FTPES.<br><br>- *ftpSSLExigéSurToutes*: le chiffrement s'applique aux données et aux commandes FTP. Ce mode correspond au mode de fonctionnement par défaut des fonctions en FTPES.<br><br>- *ftpSSLExigéPourCommandes*: le chiffrement SSL est exigé uniquement pour les commandes FTP. Ce mode peut être requis pour certains serveurs FTPES.<br><br><br><br><br> |
| MotDePasse | Chaîne de caractères ou chaîne de caractères secrète | Mot de passe de l'utilisateur, permettant d'identifier l'utilisateur sur le serveur FTP. Ce mot de passe correspond:<br><br>- au &lt;Mot de passe&gt; spécifié si ce paramètre est différent d'une chaîne vide (""),<br><br>- à l'adresse email de l'utilisateur si le paramètre &lt;Nom de l'utilisateur&gt; n'est pas spécifié ou est égal à une chaîne vide (""),<br><br>- à une chaîne vide ("") si ce paramètre n'est pas spécifié et si le paramètre &lt;Nom de l'utilisateur&gt; est différent d'une chaîne vide ("").<br><br><br>Remarque: Si le mot de passe contient des caractères spéciaux, il peut être nécessaire de le convertir en UTF8 en utilisant la fonction [ChaîneVersUTF8](../WDLang1/3024042.md).<br>**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".<br>Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). <br><br>**Cette propriété est disponible en écriture uniquement.** |
| MotDePasseCléPrivée | Chaîne de caractères ou chaîne de caractères secrète | Mot de passe du fichier contenant la clé privé utilisée lors d'une connexion en mode SFTP.<br>Si l'utilisation des chaînes en exécution est en Unicode (onglet "Unicode" de la [configuration courante](../Editeurs/9000030.md)), le mot de passe ne doit pas être donné entre guillemets. Il doit être contenu dans une variable de type chaîne déclarée en ANSI.<br>Si ce paramètre n'est pas spécifié, la connexion sécurisée utilise une authentification par &lt;Utilisateur&gt; / &lt;MotDePasse&gt;.<br>**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".<br>Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). <br><br>**Cette propriété est disponible en écriture uniquement.** |
| NuméroPort | Entier | Numéro de port sur lequel le serveur doit être lancé. Ce paramètre est donné par le responsable du site FTP.<br><br>Par défaut: <br><br>- pour une connexion non sécurisée, ce port est le port 21.<br><br>- pour une connexion sécurisée en mode FTPS, ce port est le port 990. <br><br>- pour une connexion sécurisée en mode FTPES, ce port est le port 21.<br><br>- pour une connexion sécurisée en mode SFTP, ce port est le port 22.<br><br><br> |
| ProcédureTrace | Procédure | Nom de la procédure WLangage permettant de connaître les entêtes et les données envoyées et reçues. Cette procédure est de la forme : <br><br><pre><code>PROCÉDURE <Nom procédure>(<TypeInfo> est entier, <br>	<Data> est un Buffer)</code></pre><br> où : <br><br>- &lt;TypeInfo&gt; est une constante de type Entier correspondant au type de données tracées : <br><br>	- *httpTraceDonnéeEnvoyée* : Données envoyées.<br><br>	- *httpTraceDonnéeRecue* : Données reçues. <br><br>	- *httpTraceEntêteEnvoyé* : Entête envoyé. <br><br>	- *httpTraceEntêteRecu* : Entête reçu. <br><br>	- *httpTraceInfo* : Informations détaillées sur l’exécution de la requête (erreur bas niveau de cURL/OpenSSL, étape en cours, avertissements, etc.).<br><br><br><br><br>- &lt;Data&gt; est un buffer contenant les informations. <br><br><br><br><br>Exemple de procédure : <br><pre><code>PROCÉDURE ProcTrace(nTypeInfo est entier, ...<br>		bufByData est un Buffer)<br>	SELON nTypeInfo<br>		CAS httpTraceEntêteEnvoyé:<br>			Trace("Entête : ", ...<br>				UTF8VersChaîne(bufByData))<br>		CAS httpTraceDonnéeEnvoyée:<br>			Trace("Données : ", ...<br>					bufByData)<br>		CAS httpTraceEntêteRecu:<br>			Trace("Entête reçu : ", ...<br>				UTF8VersChaîne(bufByData))<br>		CAS httpTraceDonnéeRecue:<br>			Trace("Données reçues : ", ...<br>					bufByData)<br>	FIN</code></pre><br><br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Non disponible.<br><br> |
| Serveur | Chaîne de caractères | Nom du serveur FTP (par exemple "ftp.cdrom.com") ou adresse IP du serveur FTP (par exemple "192.54.12.8").<br><br>Cette propriété permet de définir le protocole utilisé: <br><br>- si le nom du serveur commence par "ftp://", la connexion est en mode non sécurisé. <br><br>- si le nom du serveur commence par "ftps://", la connexion est en mode sécurisé selon le protocole FTPS (FTP sécurisé par SSL avec chiffrement implicite). <br><br>- si le nom du serveur commence par "ftpes://", la connexion est en mode sécurisé selon le protocole FTPES (FTP sécurisé par SSL avec chiffrement explicite). <br><br>- si le nom du serveur commence par "sftp://", la connexion est en mode sécurisé par un tunnel SSH selon le protocole SFTP. <br><br><br> |
| TypeConnexion | Entier | Type de connexion à effectuer: <br><br>- *ftpModeActif*: Connexion active au serveur FTP.<br>	Lors d'un transfert de fichiers, c'est le client qui prend l'initiative du transfert. Ce type de connexion peut être refusé par certains serveurs FTP protégés.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Non disponible.<br><br>- *ftpModePassif* (Valeur par défaut): Connexion passive au serveur FTP (mode PASV). <br>	Lors d'un transfert de fichiers, c'est le serveur qui prend l'initiative du transfert. Ce type de connexion permet de franchir certains "firewalls".<br>	Remarque: Si la connexion au serveur est en IPV6, alors la connexion se fera en mode passif étendu (car le mode passif ne supporte pas IPV6). <br><br>- *ftpModePassifEtendu*: Connexion passive étendue au serveur FTP (mode EPSV).<br>	Lors d'un transfert de fichiers, c'est le serveur qui prend l'initiative du transfert. Ce type de connexion permet de franchir certains "firewalls". <br>	Si le serveur ne supporte pas le mode passif étendu (la commande FEAT est envoyée au serveur pour connaître la capacité), la connexion est dégradée en mode passif simple. <br>	Limitation: Ce mode n'est pas supporté lors de l'utilisation du module "wininet" de Windows (voir fonction [FTPParamètre](../WDLang3/1000020947.md)): la connexion est réalisée en mode *ftpModePassif*. <br><br>- *ftpModePassifIgnoreIP*: Connexion passive au serveur FTP (mode PASV). <br>	Lors d'un transfert de fichiers en mode passif le serveur donne le port et l'adresse IP pour le transfert des données. Avec ce paramètre, seul le port est pris en compte, l'adresse IP est ignorée. Ce type de connexion permet d'utiliser des serveurs FTP qui retournent des adresses IP non routables mais qui sont joignables par l'adresse IP de connexion.<br>	Limitation: Ce mode n'est pas supporté lors de l'utilisation du module "wininet" de Windows (voir fonction [FTPParamètre](../WDLang3/1000020947.md)): la connexion est réalisée en mode *ftpModePassif*. <br><br><br> |
| Utilisateur | Chaîne de caractères | Nom de l'utilisateur qui tente d'effectuer une connexion nominative (identification de l'utilisateur sur le serveur FTP). <br><br>Si cette propriété correspond à une chaîne vide (""), la connexion sera anonyme. |
