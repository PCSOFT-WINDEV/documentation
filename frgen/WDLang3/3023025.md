## Environnement de développement Mobile
<a name="environnement_developpement_mobile_ELTTEXTE000102"></a>
WINDEV Mobile est un environnement de développement sous poste PC qui permet de développer : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) des applications pour Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) des applications pour iPhone/iPad. 




**Remarques** : 

- Les applications générées fonctionnent uniquement sous des terminaux mobiles (équipés de processeur ARM, XScale, Samsung et compatible ARM). Ces applications ne fonctionnent pas sous des postes PC.

- Le développement d'applications Windows Mobile n'est plus disponible à partir de la version 27. Windows Mobile, Windows CE et Windows Embedded ne sont plus supportés par Microsoft, mais sont encore utilisés dans le domaine industriel. 
	Pour continuer à développer pour Windows Mobile, vous devez utiliser une version 26. Votre version 2026 donne accès à la version 26 qui peut être téléchargée en version Abonnement [ici](https://download.windev.com/FR/saas.awp) ou en version avec clé [ici](https://download.windev.com/FR/).

- Le développement d'applications en mode Universal Windows 10 App n'est plus disponible à partir de la version 2025. La plateforme "Universal Windows 10 App" n'est plus supportée par WINDEV, WEBDEV et WINDEV Mobile. 
	Pour continuer à développer une application en mode Universal Windows 10 App, vous devez utiliser une version 2024. Votre version 2026 donne accès à la version 2024 qui peut être téléchargée en version Abonnement [ici](https://download.windev.com/FR/) ou en version avec clé [ici](https://download.windev.com/FR/dongle.awp).

## Fonctions WLangage
<a name="fonctions_wlangage_ELTTEXTE000150"></a>
La plupart des fonctions WLangage présentes dans WINDEV standard sont également disponibles dans WINDEV Mobile. Il s'agit des fonctions communes aux deux produits.

Seules les fonctions spécifiques à Windows ne sont pas disponibles sous WINDEV Mobile.

Le schéma suivant présente les fonctions du WLangage utilisables selon le type d'application développée :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Pocket-fonctions%20communes.gif)

## Base de données
<a name="base_donnees_ELTTEXTE000174"></a>
Les données manipulées dans une application WINDEV Mobile peuvent provenir :

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) d'une base de données HFSQL Classic ou HFSQL Client/Serveur.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) d'une base de données SQLite.

- de fichiers ".INI".

- de fichiers texte (au format ANSI ou Unicode).
