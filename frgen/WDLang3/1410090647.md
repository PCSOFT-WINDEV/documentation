
## PartageProximitéArrêteAttente (Fonction)

***En anglais : NearbyShareStopWaiting***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête l'attente de la connexion des appareils aux autres appareils à proximité.

Dans ce cas, l'appareil ne sera plus visible par les autres appareils en mode recherche (fonction [PartageProximitéRechercheAppareil](../WDLang3/1410090648.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Code de modification du champ Interrupteur
// permettant de lancer ou d'arrêter l'attente de connexion
INT_Arrêt_Attente.Etat = Grisé
SI INT_Arrêt_Attente = Vrai ALORS
	PartageProximitéAttendConnexion(gsNomAppareil, CallbackRésultat, ...
		CallbackDemandeConnexion, CallbackConnexion, gnTopologieDeRéseau)
SINON
	PartageProximitéArrêteAttente()
	INT_Arrêt_Attente.Etat = Actif
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéArrêteAttente()`
