
## App shortcuts (raccourcis d'application) 
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000116"></a>


### Les raccourcis d'application
<a name="les_raccourcis_application_ELTPARAGRAPHE000009"></a>Les app shortcuts (raccourcis d'application) sont une fonctionnalité disponible sur les appareils Android qui permet aux utilisateurs d'accéder rapidement à des actions spécifiques d'une application sans avoir à ouvrir l'application complète. Ces actions apparaissent généralement sous forme d'icônes sur l'écran d'accueil ou dans le menu contextuel du raccourci d'une application.

Quelques exemples d'utilisation des app shortcuts :

- Permettre d'accéder directement à une fonction ou à une action spécifique au sein d'une application. Par exemple, un raccourci vers la fonction "Nouveau message" d'une application de messagerie.

- Afficher un aperçu ou donner accès à un contenu spécifique au sein d'une application. Par exemple, un raccourci vers le dernier article d'actualités dans une application de lecture de nouvelles.

- Permettre d'ouvrir directement une section spécifique d'une application. Par exemple, un raccourci vers l'écran de paramètres d'une application.




Pour accéder aux app shortcuts sur un appareil Android, il est possible d'effectuer les actions suivantes :

- Appuyer et maintenir l'icône d'une application sur l'écran d'accueil pour afficher les actions disponibles, le cas échéant.

- Appuyer et maintenir l'icône d'une application dans la liste des applications pour faire apparaître un menu contextuel des actions disponibles.

### Les raccourcis épinglés
<a name="les_raccourcis_epingles_ELTPARAGRAPHE000031"></a>Les "pinned shortcuts" (raccourcis épinglés) sont une fonctionnalité supplémentaire des app shortcuts. Ils permettent aux utilisateurs d'épingler sur leur écran d'accueil des actions spécifiques de l'application pour un accès encore plus rapide. Cette fonctionnalité n'est disponible qu'à partir d'Android 8.

Lorsqu'une action est épinglée, une icône correspondante est créée sur l'écran d'accueil, et il est possible d'y accéder en un seul toucher. Cela peut être pratique pour les actions ou les fonctionnalités utilisées fréquemment pour lesquelles on souhaite avoir un accès direct.

Pour épingler une action, il faut appuyer et maintenir l'icône de l'application sur l'écran d'accueil ou dans la liste des applications pour afficher les app shortcuts, faire glisser l'action souhaitée vers le haut de l'écran et relâcher pour l'épingler sur l'écran d'accueil.
Une fois épinglée, l'action restera sur l'écran d'accueil même après un redémarrage de l'appareil. Il est possible de la déplacer, de la réorganiser ou de la supprimer de la même manière qu'avec n'importe quelle autre icône sur l'écran d'accueil.

## Gestion des raccourcis d'application avec WINDEV Mobile
<a name="gestion_des_raccourcis_application_avec_windev_mobile_ELTTEXTE000146"></a>
WINDEV Mobile permet de gérer les raccourcis dynamiques. Ce type de raccourcis permet aux applications de générer des actions à la volée en fonction du contexte ou de l'activité de l'utilisateur. Ils peuvent être mis à jour ou modifiés dynamiquement par l'application en fonction des actions ou des événements récents. 

Par exemple, une application de lecteur de musique peut générer des actions pour les chansons les plus récemment écoutées ou les listes de lecture récentes. 

WINDEV Mobile met à votre disposition : 

- un type de variable : 
	


|   |   |
| --- | --- |
| [ActionRapide](../WDLang3/1410090054.md) | Le type **ActionRapide** permet de définir toutes les caractéristiques avancées d'une action rapide d'une application mobile Android (app shortcut) ou iOS (Quick Action). |

- différentes fonctions du WLangage : 
	


|   |   |
| --- | --- |
| [ActionRapideAjoute](../WDLang3/1410090053.md) | Ajoute une nouvelle action rapide à l'application. |
| [ActionRapideEpingle](../WDLang3/1410090069.md) | Demande à épingler une action rapide. |
| [ActionRapideListe](../WDLang3/1410090067.md) | Liste les actions rapides de l'application. |
| [ActionRapideSupprime](../WDLang3/1410090064.md) | Supprime une action rapide de l'application. |
| [ActionRapideSupprimeTout](../WDLang3/1410090068.md) | Supprime toutes les actions rapides de l'application. Les actions rapides épinglées sur l'écran d'accueil seront désactivées (mais pas supprimées). |




Remarques : 

- Pour savoir si une application a été lancée par une action rapide, il faut utiliser la fonction [ExeInfo](../WDLang1/3035001.md) avec la constante *exeLancement*. Dans ce cas, la fonction [ExeInfo](../WDLang1/3035001.md) retournera la constante *exeActionRapide*.

- Sous Android le nombre d'actions rapides d'une application est limité. Cette limite est en général de 5 actions par application.

- Sous iOS, il est uniquement possible d'ajouter et de supprimer des raccourcis d'application.
