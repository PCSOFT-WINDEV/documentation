


## Constantes DNS
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les constantes DNS sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **dnsA** | Permet de connaître l'adresse IPv4 associée au nom de domaine. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsAAAA** | Permet de connaître l'adresse IPv6 associée au nom de domaine. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsCNAME** | Permet de connaître les alias de nom de domaine. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsDNAME** | Permet de connaître les alias de nom de domaine et de ses sous domaines. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsMX** | Permet de connaître les serveurs de courriel pour le domaine spécifié. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsNAPTR** | Permet de connaître les règles de réécriture de l'information, permettant des correspondances assez lâches entre un nom de domaine et une ressource. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsNS** | Permet de connaître la liste les serveurs DNS du domaine spécifié. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsPTR** | Permet de connaître le nom d'hôte ou de domaine correspondant à une l'adresse IP (inverse du A/AAAA). | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsSOA** | Permet de connaître les informations générales du domaine : serveur principal, courriel de contact, différentes durées dont celle d'expiration, numéro de série de la zone, etc. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsSRV** | Permet de connaître le serveur de courriel associé à un nom de domaine avec des données complémentaires comme le taux de répartition de charge pour un service donné. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsTLSA** | Permet de connaître le certificat TLS associé au nom de domaine. | [DNSInterroge](../WDLang3/1410089873.md) |
| **dnsTXT** | Permet de connaître le texte associé à un enregistrement DNS. | [DNSInterroge](../WDLang3/1410089873.md) |
