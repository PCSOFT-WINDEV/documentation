


## DoubleAuthVérifieCode (Fonction)

***En anglais : TwoFactorAuthenticationCheckCode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie le code donné par une application d'authentification.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI DoubleAuthVérifieCode(nCode, sCléTOTP) = Faux ALORS
	Erreur("Le code ne correspond pas.")
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = DoubleAuthVérifieCode(<Code> , <Clé TOTP>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le code est correct,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Code> : (Entier ou chaîne de caractères)`**

Code à 6 chiffres donné par l'application d'authentification.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Ce paramètre est obligatoirement un entier.

**`<Clé TOTP> : (Chaîne de caractères, Buffer ou chaîne secrète)`**

Clé TOTP de l'utilisateur à authentifier.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre peut être "Buffer ASCII" ou "Buffer UTF 8".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Durée de validité
<a name="duree_validite_ELTPARAGRAPHE000054"></a>

- La durée de validité du code est légèrement supérieure à celle montrée par l'application d'authentification. Par exemple, lorsque Google Authenticator affiche un nouveau code, le précédent reste encore valide 1 minute.

- La fonction **DoubleAuthVérifieCode** vérifie les codes générés 1 minute avant et 1 minute après l'instant où la demande de vérification a été effectuée. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Pour un site Web, pensez à vérifier que l'heure UTC du serveur Web est correcte. Le serveur qui héberge le site Web peut être dans un autre fuseau horaire que les utilisateurs du site, mais le serveur et les appareils doivent être à la même heure.
