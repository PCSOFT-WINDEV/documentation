


## &lt;Variable gglDrive&gt;.Renomme (Fonction)

***En anglais : &lt;gglDrive variable&gt;.Rename***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renomme un fichier de la suite Google ou un répertoire présent dans un drive Google.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

DriveGoogle est un gglDrive
DriveGoogle = GglDriveConnecte(oOAuth2Param)

sNouveauNom est une chaîne
sNouveauNom = ExtraitChaîne(DécomplèteRep(SAI_RépertoireARenommer), 1, "/", DepuisFin)
sNouveauNom += "_NEW_" + DateHeureSys()

SI DriveGoogle.Renomme(SAI_RépertoireARenommer, sNouveauNom) = Faux ALORS
	Erreur("Impossible de renommer le répertoire demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE2"></a>

`<Résultat> = <Drive Google>.Renomme(<Fichier à renommer> , <Nouveau Nom>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été renommé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive Google> : (Variable de type gglDrive)`**

Nom de la variable de type [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la copie n'est pas réalisée.

**`<Fichier à renommer> : (Variable de type FichierGgl)`**

Nom de la variable de type [FichierGgl](../WDLang3/1410089586.md) correspondant au fichier de la suite Google à manipuler.

**`<Nouveau Nom> : (Chaîne de caractères)`**

Nouveau nom de l'élément.
