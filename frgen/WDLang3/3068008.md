
## SMSSupprime (Fonction)

***En anglais : SMSDelete***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Avertissement</B><BR>
	A partir de la version <B>25</B>,  cette fonction ne doit plus être utilisée. Le système Android n'autorise plus la suppression de SMS par programmation depuis la version 4.4 d'Android. L'utilisation de cette fonction entraîne une erreur fatale de l'application.  
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un SMS stocké dans la mémoire du téléphone Android. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Le système n'autorise plus la suppression de SMS par programmation depuis la version 4.4 d'Android.


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = SMSSupprime(<Emplacement> , <Indice du SMS>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le SMS a été supprimé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) A partir de la version 4.4 d'Android (Kit Kat), la suppression de SMSs de la boîte de réception n'est plus autorisée par le système. La fonction **SMSSupprime** retournera toujours <u><u><u><u>Faux</u></u></u></u>.

**`<Emplacement> : (Constante de type Entier)`**

Emplacement du SMS à supprimer :


|   |   |
| --- | --- |
| *smsMémoire* | SMS stocké dans la mémoire de l'appareil. |
| *smsSIM* | SMS stocké dans la carte SIM<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette constante n'est pas autorisée et provoque une erreur fatale. |



**`<Indice du SMS> : (Entier)`**

Indice du SMS à supprimer. Cet indice peut être connu grâce à la variable SMS.Indice. Pour plus de détails, consultez la [Structure SMS](../WDLang3/3068003.md).
