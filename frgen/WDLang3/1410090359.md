


## &lt;Variable Drive&gt;.ListeFichier (Fonction)

***En anglais : &lt;Drive variable&gt;.ListFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les fichiers d'un répertoire d'un drive.

**Attention** : dans le cas d'une connexion à un drive Google, les fichiers correspondant à un document de la suite Google ne sont pas listés.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

UnFichier, ResListeFichier sont des chaînes
// Liste tous les fichiers dans mon drive depuis le répertoire "MesPhotos"
// Le parcours se fait uniquement dans le répertoire courant 
ResListeFichier = oDrive.ListeFichier("/MesPhotos/", frNonRécursif)

// Pour chaque fichier trouvé
POUR TOUTE CHAÎNE UnFichier DE ResListeFichier SÉPARÉE PAR RC
	// Ajout du fichier dans la table TABLE_TableFic
	TABLE_TableFic.Ajoute(UnFichier)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Drive>.ListeFichier(<Chemin de départ> [, <Options>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des fichiers présents sur le drive spécifié, à l'emplacement spécifié. 

- Si la constante *frInformationComplète* n'est pas précisée, cette liste est de la forme : 
	
	```txt
	<Nom du fichier 1> + RC + ... + <Nom du fichier N>
	```


- Si la constante *frInformationComplète* est précisée, cette liste est de la forme : 
	
	```txt
	<Nom du fichier 1> + TAB + <Chemin du fichier 1> + TAB + <Taille (octets) du fichier 1> + TAB + 
	<Date de modification 1> + RC + ... + <Nom du fichier N> + TAB + <Chemin du fichier N> + TAB + 
	<Taille (octets) du fichier N> + TAB + <Date de modification N>
	```





**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, les fichiers ne sont pas listés.

**`<Chemin de départ> : (Chaîne de caractères)`**

Chemin du drive à partir duquel les fichiers doivent être listés. Ce chemin correspond à un chemin absolu du drive : 

- Les noms des répertoires doivent être séparés par des '/' ou des '\\'. 

- Le nom des répertoires doit débuter par un '/' ou un '\\'. 


Si le chemin est invalide, une erreur sera générée.

**`<Options> : (Constante optionnelle de type Entier)`**

Type de parcours effectué :



|   |   |
| --- | --- |
| *frInformationComplète* | Permet d'obtenir des informations complètes sur les fichiers présents sur le drive. <br><br>Cette constante doit être combinée avec les constantes *frNonRécursif* ou *frRécursif*. |
| *frNonRécursif* | Le parcours est non récursif. Les sous-répertoires ne sont pas pris en compte. |
| *frRécursif*<br>(Valeur par défaut) | Le parcours est récursif. Les sous-répertoires sont automatiquement pris en compte. |

## Remarques


### Paramètre &lt;Chemin de départ&gt;
<a name="parametre_ELTPARAGRAPHE000217"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
