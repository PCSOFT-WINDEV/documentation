


## FTPRepEnCours (Fonction)

***En anglais : FTPCurrentDir***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifie ou modifie le répertoire en cours sur un serveur FTP (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003040003&name=ftprepencours_fonction">Voir des exemples supplémentaires</a>

```wl
// Connexion du poste en cours au serveur FTP
NumConnexion = FTPConnecte("192.54.12.8")
// Identifier le répertoire en cours sur le serveur FTP
ResRepEnCours = FTPRepEnCours(NumConnexion)
```

## Syntaxe

### Connaître le répertoire en cours

`<Résultat> = FTPRepEnCours(<Connexion FTP>)`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom absolu du répertoire en cours sur le serveur FTP, 

- Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Entier ou variable de type ftpConnexion)`**



- Identifiant de la connexion, obtenu avec la fonction [FTPConnecte](../WDLang3/3040016.md).
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre est de type Variant.

- Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.
	

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible.





<a name="SYNTAXE2"></a>

### Modifier le répertoire en cours

`<Résultat> = FTPRepEnCours(<Connexion FTP> , <Nouveau répertoire en cours>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire en cours a été modifié, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Entier ou variable de type ftpConnexion)`**



- Identifiant de la connexion, obtenu avec la fonction [FTPConnecte](../WDLang3/3040016.md).
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre est de type Variant.

- Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.
	

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible.




**`<Nouveau répertoire en cours> : (Chaîne de caractères)`**

Nom et chemin absolu (ou relatif) du nouveau répertoire en cours. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/").

## Remarques


### Délai
<a name="delai_ELTPARAGRAPHE000347"></a>

Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié: 

- lors de la connexion au serveur FTP avec la fonction [FTPConnecte](../WDLang3/3040016.md) (paramètre &lt;Durée de non réponse&gt;).

- lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
	



<a name="NOTE0_3"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000387"></a>

La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000396"></a>

L'utilisation de cette fonction entraîne la modification des permissions requises par l'application. 
Permission requise : INTERNET 
Cette permission autorise l'application à ouvrir des sockets réseau.
