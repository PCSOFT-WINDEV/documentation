


## &lt;Graphe&gt;.EtiquetteSérie (Fonction)

***En anglais : &lt;Chart&gt;.SeriesLabel***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise l'étiquette d'une série de données d'un graphe.

Exemple d'étiquette de série :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteSerie.gif)
Pour afficher l'étiquette, utilisez la fonction [&lt;Graphe&gt;.Légende](../WDLang3/1000024089.md).

**Rappel** : Par défaut, un graphe n'a aucune étiquette. Pour plus de détails sur la gestion des légendes, étiquettes, ... consultez [Gestion des légendes dans les graphes](../WDChamp/3042069.md). 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Initialisation de l'étiquette "Ventes" de la série de données 2 dans le champ GRF_MonGraphe
GRF_MonGraphe.EtiquetteSérie(2, "Ventes")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Graphe>.EtiquetteSérie(<Numéro de la série> , <Étiquette>)`
---

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Numéro de la série> : (Entier)`**

Numéro de la série pour laquelle une étiquette doit être initialisée.

**`<Étiquette> : (Chaîne de caractères)`**

Libellé de l'étiquette à initialiser.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Etiquettes de série
<a name="etiquettes_serie_ELTPARAGRAPHE000258"></a>L'ensemble des étiquettes de séries correspond à la légende du graphe.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EtiquetteSerie.gif)
Les étiquettes de série ne sont pas utilisables avec les graphes de type secteur.

La définition des étiquettes de séries est réalisée avec la fonction **&lt;Graphe&gt;.EtiquetteSérie**. 

Les données définies avec la fonction **&lt;Graphe&gt;.EtiquetteSérie** seront prises en compte lors du prochain appel à la fonction [&lt;Graphe&gt;.Dessine](../WDLang3/1000024062.md).

Il est possible de modifier la police de la légende grâce à la fonction [&lt;Graphe&gt;.PoliceLégende](../WDLang3/1000024118.md).  

La fonction [&lt;Graphe&gt;.Légende](../WDLang3/1000024089.md) permet d'indiquer la présence et la position de la légende (c'est-à-dire de l'ensemble des étiquettes de série).

**Remarque** : Pour définir des étiquettes de série dans des graphes de type "Nuage de points", il est conseillé d'utiliser la fonction [&lt;Graphe&gt;.NuageEtiquetteSérie](../WDLang3/1000024107.md).
<a name="NOTE0_2"></a>


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000306"></a>La fonction **&lt;Graphe&gt;.EtiquetteSérie** est équivalente à la propriété [Légende](../Proprietes/2510143.md).
