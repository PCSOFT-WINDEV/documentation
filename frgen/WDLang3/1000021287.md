


## grSMNRécupèreDonnée (Fonction)

***En anglais : grSunburstGetData***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère une valeur numérique dans un graphe de type Secteur multiniveau.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaVal est réel = grSMNRécupèreDonnée(GRF_Graphe1, "Europe" + TAB + "France" + TAB + "Montpellier")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = grSMNRécupèreDonnée(<Nom du graphe> , <Chemin de la portion>)`
---

**`<Résultat> : (Réel)`**



- Valeur à récupérer.

- 0 si le chemin est invalide ou si la portion ne contient pas de donnée. 




**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Dans les pages, seuls les champs "Graphe interactif" sont disponibles pour les graphes de type Secteur multiniveau.

**`<Chemin de la portion> : (Chaîne de caractères)`**

Chemin complet de la portion dont la valeur doit être récupérée. Ce paramètre est de la forme :

```txt
"<Nom du niveau de base>" + TAB + ["<Nom du 1er niveau>" + TAB + ...
["<Nom du dernier niveau>" + TAB + [...]]]"<Nom de la portion>"
```




<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Pour récupérer une donnée dans un graphe Boursier, il est conseillé d'utiliser la fonction [grBourseRécupèreDonnée](../WDLang3/1000021174.md).

- Pour récupérer une donnée dans un graphe Surface, il est conseillé d'utiliser la fonction [grSurfaceRécupèreDonnée](../ErrCompil/1000001036.md).

- Pour récupérer une donnée dans un autre type de graphe (Secteur, Histogramme, Courbe, etc.), utilisez [grRécupèreDonnée](../WDLang3/1000021171.md).

- Pour récupérer une donnée dans un graphe de type Heatmap, il est conseillé d'utiliser la fonction [grHMRécupèreDonnée](../WDLang3/1000021632.md).

- Par défaut, un graphe créé avec la fonction [grCrée](../WDLang3/3042005.md) ne contient aucune donnée.
