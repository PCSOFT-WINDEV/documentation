


## MQTTDéconnecte (Fonction)

***En anglais : MQTTDisconnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de se déconnecter d'un serveur MQTT (également appelé "Broker").


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaSessionMQTT est un mqttSession
...
MQTTDéconnecte(MaSessionMQTT)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`MQTTDéconnecte(<Session MQTT>)`
---

**`<Session MQTT> : (Variable de type mqttSession)`**

Nom de la variable [mqttSession](../WDLang3/1000023023.md) correspondant aux paramètres de la connexion à terminer. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Déconnexion
<a name="deconnexion_ELTPARAGRAPHE000055"></a>Lors d'une déconnexion ou d'une perte de connexion, la propriété **EstConnectée** de la variable [mqttSession](../WDLang3/1000023023.md) passe à <u><u><u><u>Faux</u></u></u></u>.
