


## Fonctions de gestion du téléphone (syntaxe préfixée)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de gérer le téléphone via une syntaxe préfixée sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Variable Notification&gt;.Ajoute](../WDLang3/1410090431.md) | Ajoute une notification dans la barre système de l'appareil (Android) ou dans le centre de notification (iOS). |
| [&lt;Variable Notification&gt;.EnvoiePush](../WDLang3/1410090433.md) | Envoie une notification push (distante) à un appareil mobile (iOS ou Android). |
| [&lt;Variable Notification&gt;.EnvoiePushAbonné](../WDLang3/1410090479.md) | Envoie une notification push distante aux appareils Android abonnés d'un sujet. |
| [&lt;Variable Notification&gt;.Modifie](../WDLang3/1410090432.md) | Modifie une notification actuellement affichée dans la barre système de l'appareil. |
| [&lt;Variable Notification&gt;.Supprime](../WDLang3/1410090434.md) | Supprime une notification affichée dans la barre système de l'appareil. |
