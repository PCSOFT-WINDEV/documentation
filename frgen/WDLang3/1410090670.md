
## Paramètres de la procédure utilisée par la fonction PartageProximitéEnvoieFichier



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéEnvoieFichier](../WDLang3/1410090654.md) pour notifier le succès ou l'échec de l'envoi.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéEnvoieFichier(gTabAppareilsSélectionnés, sCheminRessource, CallbackEnvoi)
```



```wl
PROCÉDURE CallbackEnvoi(bResultat est un booléen, nIdTransfert est un entier)
SI bResultat ALORS
	ToastAffiche("Fichier envoyé")
SINON
	ToastAffiche(ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéEnvoieFichier_Callback(<Résultat> , <Identifiant>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si les données ont été envoyées, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur. 




**`<Identifiant> : (Entier)`**

Identifiant du transfert.
