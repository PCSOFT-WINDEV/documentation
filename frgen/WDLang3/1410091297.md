


## &lt;Variable httpRequête&gt;.EnvoieAsynchrone (Fonction)

***En anglais : &lt;httpRequest variable&gt;.SendAsynchronous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Envoie une requête HTTP en mode asynchrone : le programme continue de s'exécuter et la réponse est traitée par une procédure spécifique.  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
cMaRequête est un httpRequête
cMaRequête.URL = "http://www.monsite.fr/api/streamdata"
cMaRequête.ProcedureEntête = procédure(cMonEntête est un httpRéponse) {
	SI cMonEntête.CodeEtat = 200 ALORS Trace("Requête envoyée.")
}
cMaRequête.ProcedureDonnées = procédure(bufMorceau est un Buffer) {
	Trace("Je traite [%taille(bufMorceau)%] octets de données")
}
PROCEDURE INTERNE procFin(cMaRéponse est un httpRéponse)
	Trace("requête http terminée")
FIN
cMaRequête.EnvoieAsynchrone(procFin)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Requête HTTP>.EnvoieAsynchrone(<Procédure WLangage>)`
---

**`<Requête HTTP> : (Variable de type httpRequête)`**

Nom de la variable de type [httpRequête](../WDLang3/1000021158.md) contenant les caractéristiques de la requête HTTP à envoyer au serveur.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage appelée lors de la réponse du serveur HTTP. Pour plus de détails, consultez [Paramètres de la procédure utilisée par la fonction &lt;Variable httpRequête&gt;.EnvoieAsynchrone](../WDLang3/1000025791.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Si la gestion des cookies est mise en place pour la requête spécifiée (fonction [&lt;Variable httpRequête&gt;.GèreCookie](../WDLang3/1000021608.md)), après l'appel de la fonction **&lt;Variable httpRequête&gt;.EnvoieAsynchrone** les cookies reçus sont mis à jour dans la variable [httpRequête](../WDLang3/1000021158.md). Ainsi, lors du prochain appel de la fonction **&lt;Variable httpRequête&gt;.EnvoieAsynchrone** avec cette requête, les cookies seront pris en compte.
