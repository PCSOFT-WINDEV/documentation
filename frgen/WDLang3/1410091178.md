


## &lt;Variable sshSession&gt;.DéconnecteCommande (Fonction)

***En anglais : &lt;sshSession variable&gt;.DisconnectCommand***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes. Cette session SSH a été précédemment activée via la fonction [&lt;Variable sshSession&gt;.ConnecteCommande](../WDLang3/1410091177.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Session est une sshSession
// Propriétés de la session
// ...
// Initialise la session SSH à conserver
Session.ConnecteCommande()
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
// Ferme la session SSH pour retrouver un fonctionnement normal
Session.DéconnecteCommande()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Session SSH>.DéconnecteCommande()`
---

**`<Session SSH> : (Variable de type sshSession)`**

Nom d'une variable [sshSession](../WDLang3/1000021157.md) contenant les paramètres de connexion de la session SSH à déconnecter.
