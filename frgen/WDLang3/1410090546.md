
## Procédure WLangage appelée par les fonctions ScanDepuisCaméraVersImage/ ScanDocumentDepuisCaméra



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") exécutée à la fin du scan réalisé avec la fonction [ScanDepuisCaméraVersImage](../WDLang3/1410090763.md) (ou bien en cas d'échec ou annulation par l'utilisateur).

Remarque : Cette procédure peut également être appelée par la fonction [ScanDocumentDepuisCaméra](../WDLang3/1410090545.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCÉDURE INTERNE onScan(EtatScan, docs est un tableau d'Image)
		SELON EtatScan
			CAS sdcEchec
				ToastAffiche("Erreur du scan : " + ErreurInfo)
			CAS sdcAnnulation
				ToastAffiche("Scan annulé par l'utilisateur")
			CAS sdcSuccès
				POUR TOUT img_scannée DE docs
					TraitementImage(img_scannée)
				FIN
		FIN
FIN
ScanDepuisCaméraVersImage(onscan)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ScanDepuisCaméra_Callback(<Etat du scan> , <Images scannées>)`
---

**`<Etat du scan> : (Constante de type Entier)`**

Etat de l'opération de scan :


|   |   |
| --- | --- |
| *sdcAnnulation* | L'utilisateur a abandonné le scan des documents. |
| *sdcEchec* | Le scan des documents a rencontré une erreur. La fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus d'informations. |
| *sdcSuccès* | Les documents ont bien été scannés. |



**`<Images scannées> : (Tableau d'images)`**

Nom du tableau de variables de type [Image](../WDLang1/1000019650.md) dans lequel les différentes images scannées sont enregistrées.
