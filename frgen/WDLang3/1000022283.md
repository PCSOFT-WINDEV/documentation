


## &lt;Variable emailSessionPOP3&gt;.FermeSession (Fonction)

***En anglais : &lt;emailPOP3Session variable&gt;.CloseSession***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme la session POP3. 

Une session d'emails non terminée sera automatiquement fermée à la fin du programme WINDEV ou WINDEV Mobile ou à la fin de la session WEBDEV.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouverture d'une session POP3
MaSession est une emailSessionPOP3

MaSession.AdresseServeur = "pop.mondomaine.fr"
MaSession.Nom = "utilisateur"
MaSession.MotDePasse = "secret"

MaSession.OuvreSession()
...
MaSession.FermeSession()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Session POP3>.FermeSession()`
---

**`<Session POP3> : (Variable de type emailSessionPOP3)`**

Nom de la variable de type [emailSessionPOP3](../WDLang3/1000018759.md) correspondant à la session d'email à manipuler.
