
## SysVersionWindows (Fonction)

***En anglais : SysWindowsVersion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie des informations sur la version de Windows utilisée sur le poste en cours.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Renvoie des informations sur la version de Windows utilisée sur le poste serveur.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Renvoie la version du système.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Pour obtenir les informations sur la version d'Android, utilisez la fonction [SysVersionAndroid](../WDLang1/1000019785.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Numéro de version de Windows utilisé sur le poste en cours
ResVersion = SysVersionWindows(SysVersionNuméro)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = SysVersionWindows([<Type d'information>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Information demandée sur la version Windows, 

- Chaîne vide ("") en cas d'erreur.




**`<Type d'information> : (Constante optionnelle)`**

Indique l'information à demander :
