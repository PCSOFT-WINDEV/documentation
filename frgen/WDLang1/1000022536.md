


## &lt;Tableau de bord&gt;.SupprimeTout (Fonction)

***En anglais : &lt;Dashboard&gt;.DeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime tous les Widgets affichés dans un champ Tableau de bord.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Vérifie qu'il existe au moins un widget
SI TDB_TableauDeBord.Occurrence(toTotal) <= 0 ALORS
	Info("Il n'y a aucun widget à supprimer")
	RETOUR
FIN
// Supprime tous les widgets
TDB_TableauDeBord.SupprimeTout()
ToastAffiche("Tous les widgets ont été supprimés", toastCourt, cvMilieu, chCentre)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Tableau de bord>.SupprimeTout()`
---

**`<Champ Tableau de bord> : (Nom de champ)`**

Nom du champ Tableau de bord à manipuler.
