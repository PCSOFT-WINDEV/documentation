


## HTMLNavigue (Fonction)

***En anglais : HTMLNavigate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance une opération de navigation dans un champ d'affichage HTML.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Code du bouton Suivant
HTMLNavigue(HTM_ChampHTML1, htmlSuivant)
```
<a name="Exemple2"></a>

```wl
// Code du bouton Précédent
HTMLNavigue(HTM_ChampHTML1, htmlPrécédent)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Lance une opération de navigation sur le site affiché par le champ d'affichage HTML

`HTMLNavigue(<Champ d'affichage HTML> , <Option de navigation>)`
---

**`<Champ d'affichage HTML> : (Nom de champ)`**

Nom du champ d'affichage HTML à manipuler.

**`<Option de navigation> : (Constante)`**

Sens de la navigation :


|   |   |
| --- | --- |
| *htmlActualise* | Actualise la page en cours (équivalent au bouton "Actualiser" du navigateur). |
| *htmlDémarrage* | Affiche la page de démarrage (équivalent au bouton "Home" du navigateur). Pour obtenir la valeur initiale du champ d'affichage HTML, utilisez la propriété [ValeurInitiale](../Proprietes/2510128.md).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette constante n'est pas disponible. |
| *htmlPrécédent* | Affiche la page précédente (équivalent au bouton "BACK/Précédent" du navigateur). |
| *htmlStop* | Arrête le chargement des ressources utilisées par la page. L'événement "Chargement de ressources" du champ n'est pas exécuté. |
| *htmlSuivant* | Affiche la page suivante (équivalent au bouton "SUIVANT" du navigateur). |




<a name="SYNTAXE2"></a>

### Affiche un nouvelle URL dans le champ d'affichage HTML

`HTMLNavigue(<Champ d'affichage HTML> , <URL à afficher>)`
---

**`<Champ d'affichage HTML> : (Nom de champ)`**

Nom du champ d'affichage HTML à manipuler.

**`<URL à afficher> : (Chaîne de caractères)`**

URL à afficher dans le champ d'affichage formaté.
