
## ChampExiste (Fonction)

***En anglais : ControlExist***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Teste l'existence d'un champ (ou d'un groupe de champs) dans une fenêtre, dans une page ou dans un état.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Test de l'existence du champ "SaisieNom"
ResExiste = ChampExiste("SaisieNom")
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = ChampExiste(<Champ manipulé>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le champ (ou le groupe de champs) existe, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ manipulé> : (Chaîne de caractères ou variable de type Champ)`**

Champ pour lequel l'existence doit être testée. Ce paramètre peut correspondre : 

- au nom du champ à tester **entre guillemets**. Ce paramètre peut aussi correspondre au nom d'un groupe de champs. 
	Pour tester l'existence des champs des autres fenêtres, pages ou états, &lt;Champ manipulé&gt; est de la forme :
	"&lt;Nom de la fenêtre, de la page ou de l'état&gt;.&lt;Nom du champ de la fenêtre, de la page ou de l'état&gt;". 

- au nom d'une variable de type [Champ](../WDLang1/1000020967.md).

## Remarques




### Champs pris en compte
<a name="champs_pris_compte_ELTPARAGRAPHE000086"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Les cases des barres de message et les entrées de menus ne sont pas considérées comme des champs.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les entrées de menus ne sont pas considérées comme des champs.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Les colonnes des champs Table ne sont pas considérées comme des champs.
