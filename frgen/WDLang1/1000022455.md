
## CaméraEtat (Fonction)

***En anglais : CameraStatus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'état d'un champ Caméra.

ELTSPECIAL000184 ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)
	<B><B><B>Avertissement</B></B></B>

	 **A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS**. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître l'état du champ Caméra "CAM_Cuisine"
// L'explication est affichée dans la barre de message. 
ResEtat = CaméraEtat(CAM_Cuisine)
SELON ResEtat
	CAS viEtatAffichageCapture :
		Message("Affichage de la vidéo dans le champ Caméra. " + ...
			"Enregistrement en cours de cette vidéo")
	CAS viEtatAffichageSansCapture :
		Message("Affichage de la vidéo dans le champ Caméra. " + ...
			"Aucune enregistrement n'est actuellement réalisé")
	CAS viEtatCaptureSansAffichage :
		Message("Enregistrement en cours d'une vidéo. "+ ...
			"Cette vidéo n'est pas affichée dans le champ Caméra")
	CAS viEtatSansCaptureSansAffichage :
		Message("Aucune vidéo n'est affichée et/ou en cours " + ...
			"d'enregistrement dans le champ Caméra")
FIN
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = CaméraEtat(<Champ Caméra>)`
---

**`<Résultat> : (Constante de type entier)`**

Etat du champ Caméra spécifié :


|   |   |
| --- | --- |
| *viEtatAffichageCapture* | Affichage de la vidéo dans le champ Caméra spécifié. Capture en cours de cette vidéo. |
| *viEtatAffichageSansCapture* | Affichage de la vidéo dans le champ Caméra spécifié. Aucun enregistrement de la vidéo n'est actuellement réalisé. |
| *viEtatCaptureSansAffichage* | Capture en cours d'une vidéo. Cette vidéo n'est pas affichée dans le champ Caméra spécifié. |
| *viEtatSansCaptureSansAffichage* | Aucune vidéo n'est affichée et/ou en cours d'enregistrement dans le champ Caméra spécifié. |



**`<Champ Caméra> : (Nom de champ)`**

Nom du champ Caméra à manipuler.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques




### Conditions d'utilisation : 
<a name="conditions_utilisation_ELTPARAGRAPHE000071"></a>

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Pour utiliser cette fonction, une "web caméra" doit être connectée au poste en cours.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette fonction nécessite un matériel équipé d'une caméra.

- Cette fonction est équivalente à la fonction [VidéoEtat](../WDLang1/3079006.md).  







<a name="NOTE0_2"></a>




### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000092"></a>

- Pour capturer la vidéo actuellement retransmise par une "web caméra", utilisez la fonction [CaméraCapture](../WDLang1/1000022450.md).

- Pour afficher dans un champ Caméra la séquence vidéo actuellement retransmise par une "web caméra", utilisez la fonction [CaméraAffiche](../WDLang1/1410086595.md).





![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000107"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : CAMERA.

Cette permission permet aux applications d'accéder à la caméra.
