
## EnModeVisiteGuidée (Fonction)

***En anglais : InGuidedTourMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique si une visite guidée est en cours d'exécution. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI EnModeVisiteGuidée() ALORS
    Info("C'est bien ici qu'il fallait cliquer".)
    RETOUR
FIN
```

```wl
// Clic sur le bouton [Paramètres]
// Passage à l'étape suivante
SI EnModeVisiteGuidée() ALORS
	VisiteGuidéeChangeEtape(vgaEtapeSuivante)
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EnModeVisiteGuidée()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si une visite guidée est en cours d'exécution, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
<a name="NOTE0_2"></a>


### Disponibilité de la fonction
<a name="disponibilite_fonction_ELTPARAGRAPHE000167"></a>La fonction **EnModeVisiteGuidée** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeVisiteGuidée** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
<a name="NOTE0_3"></a>


### Exécution des traitements contenant des erreurs de compilation
<a name="execution_des_traitements_contenant_des_erreurs_compilation_ELTPARAGRAPHE000183"></a>Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.

Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
