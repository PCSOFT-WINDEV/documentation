


## &lt;Variable picCalque&gt;.DessineTexteRTF (Fonction)

***En anglais : &lt;picLayer variable&gt;.DrawTextRTF***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dessine un texte RTF dans une variable de type [picCalque](../WDLang1/1000024604.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque
// Dessin d'un texte RTF
MonCalque.DessineTexteRTF(10, 20, MonTexteRTF)
IMG_MonDessin = MonImageWDPic
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Dessiner un texte RTF selon des coordonnées

`<Image picCalque>.DessineTexteRTF(<Abscisse> , <Ordonnée> , <Texte RTF> [, <Largeur> [, <Hauteur>]])`
---

**`<Image picCalque> : (Variable de type picCalque)`**

Nom de la variable de type [picCalque](../WDLang1/1000024604.md) à manipuler. 

**`<Abscisse> : (Entier)`**

Coordonnées (abscisse) du texte RTF à dessiner (en pixels).

**`<Ordonnée> : (Entier)`**

Coordonnées (ordonnée) du texte RTF à dessiner (en pixels).

**`<Texte RTF> : (Chaîne de caractères)`**

Texte RTF à dessiner.

**`<Largeur> : (Entier optionnel)`**

Largeur maximale du texte. Par défaut, il n'y a pas de largeur maximale.

**`<Hauteur> : (Entier optionnel)`**

Hauteur maximale du texte. Par défaut, il n'y a pas de hauteur maximale.


<a name="SYNTAXE2"></a>

### Dessiner un texte RTF dans un rectangle

`<Image picCalque>.DessineTexteRTF(<Rectangle> , <Texte RTF>)`
---

**`<Image picCalque> : (Variable de type picCalque)`**

Nom de la variable de type [picCalque](../WDLang1/1000024604.md) à manipuler. 

**`<Rectangle> : (Variable de type Rectangle)`**

Nom de la variable de type [Rectangle](../Motscles/1514079.md) correspondant à la zone dans laquelle le texte doit être dessiné.

**`<Texte RTF> : (Chaîne de caractères)`**

Texte RTF à dessiner.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Syntaxe utilisant des coordonnées
<a name="syntaxe_utilisant_des_coordonnees_ELTPARAGRAPHE000388"></a>Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).

Les coordonnées correspondent au point haut gauche du rectangle dans lequel le texte sera dessiné.
