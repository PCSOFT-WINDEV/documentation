
## ChangeSéparateur (Fonction)

***En anglais : ChangeSeparator***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Change la valeur d'un des séparateurs (de décimales ou de milliers) dans les masques des numériques pour l'internationalisation.

Pour modifier le séparateur :

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) de la page en cours : utilisez la fonction **ChangeSéparateur** puis réaffichez la page en cours avec la fonction [PageUtilise](../WDLang2/3058016.md) ou [FramesetUtilise](../WDLang2/3058012.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) de la fenêtre en cours : utilisez la fonction **ChangeSéparateur** puis réaffichez la fenêtre en cours avec la fonction [Utilise](../WDLang1/3038044.md).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// -- Code d'initialisation de projet 
// Si la langue préférée de l'utilisateur est l'anglais
SI CookieLit("LANGUE_PREFEREE") = "ANGLAIS" ALORS
	// On passe les libellés en anglais
	Nation(3)
	// On utilise le "." comme séparateur décimal
	ChangeSéparateur(sepDECIMAL, ".")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`ChangeSéparateur(<Type séparateur> , <Nouvelle valeur>)`
---

**`<Type séparateur> : (Constante de type entier)`**

Spécifie le type de séparateur à modifier :


|   |   |
| --- | --- |
| *sepDECIMAL* | Séparateur décimal (si le système d'exploitation utilisé est Windows version Française, le séparateur est une virgule (",") par défaut). |
| *sepDEVISE* | Symbole utilisé pour les devises. |
| *sepMILLIER* | Séparateur millier (si le système d'exploitation utilisé est Windows version Française, le séparateur est un espace (" ") par défaut). |



**`<Nouvelle valeur> : (Caractère)`**

Nouvelle valeur du séparateur spécifié.

### Différences serveur / navigateur
<a name="differences_serveur_navigateur_ELTPARAGRAPHE000092"></a>La valeur des séparateurs peut être différente en mode développement et en mode déploiement. En effet, lors du lancement d'un site WEBDEV, la valeur par défaut des séparateurs est fixée par les paramètres régionaux affectés à l'utilisateur utilisé par le serveur Web.
