


## &lt;Lecteur PDF&gt;.TournePage (Fonction)

***En anglais : &lt;PDF Reader&gt;.RotatePage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Effectue une rotation d'une page affichée dans le champ Lecteur PDF. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Tourne la page 4 du PDF affiché dans le champ PDF_Lecteur
PDF_Lecteur.TournePage(4, rotationHoraire)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Lecteur PDF>.TournePage(<Page> , <Sens>)`
---

**`<Champ Lecteur PDF> : (Nom de champ)`**

Nom du champ Lecteur PDF à manipuler.

**`<Page> : (Entier)`**

Numéro de la page à tourner.

**`<Sens> : (Constante de type Entier)`**

Sens de rotation de la page : 


|   |   |
| --- | --- |
| *rotationAntihoraire* | Effectue une rotation à -90 degrés de la page. |
| *rotationHoraire* | Effectue une rotation à 90 degrés de la page. |

## Remarques
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits. 
Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
