
## ShamirGénèreNombrePremier (Fonction)

***En anglais : ShamirGeneratePrime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Génère un nombre premier aléatoire utilisable pour la création de clés via l'algorithme de Shamir. Ce nombre est généré en fonction du secret. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
secret est un Buffer = "mon super secret"
nombre_premier_hexa est une chaîne ANSI = ShamirGénèreNombrePremier(secret)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Nombre premier> = ShamirGénèreNombrePremier(<Secret>)`
---

**`<Nombre premier> : (Chaîne de caractères)`**

Nombre premier utilisable avec l'algorithme de Shamir pour le secret spécifié. 
Remarque : Ce nombre premier pouvant être très important, il est donné sous forme de chaîne ANSI. 

**`<Secret> : (Buffer)`**

Secret qui sera encodé avec l'algorithme de Shamir.
