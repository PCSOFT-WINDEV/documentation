
## Espagne.VérifieNuméroFiscal (Fonction)

***En anglais : Spain.CheckTaxNumber***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Teste la validité d'un numéro fiscal en Espagne.

Remarque : Le numéro fiscal correspond au NIF. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Test d'une variable 
MonNuméroFiscal est une chaîne = "B82661935"
Espagne.VérifieNuméroFiscal(MonNuméroFiscal) // renvoie Vrai

// Test d'un champ 
SAI_NuméroFiscal = "ABC"
Espagne.VérifieNuméroFiscal(SAI_NuméroFiscal) // renvoie Faux
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = Espagne.VérifieNuméroFiscal(<Numéro à vérifier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié contient un numéro fiscal valide.

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Numéro à vérifier> : (Nom de champ ou variable de type chaîne)`**

Numéro fiscal à vérifier. Ce paramètre peut correspondre :

- au nom d'une variable de type chaîne.

- au nom d'un champ.
