
## &lt;Menu&gt;.AjouteOptionNavigateur (Fonction)

***En anglais : &lt;Menu&gt;.AddOptionBrowser***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). Cette option de menu exécute une procédure navigateur WLangage.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple




```wl
// Ajoute un nouveau menu
_Menu.AjouteMenu("MNU_Dates", "Date")
// Ajoute une option exécutant un code navigateur dans le nouveau menu
MNU_Dates.AjouteOptionNavigateur("OPT_AUJOURDHUI", "Aujourd'hui", AfficheAujourdhui)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`(<Option>, <Position>) = <Menu d'origine>.AjouteOptionNavigateur(<Option à créer> , <Libellé> , <Procédure navigateur WLangage> [, <Paramètre de la procédure>])`
---

**`<Option> : (Chaîne de caractères)`**

Option ajoutée dans le menu parent. Si l'ajout de l'option n'a pas été effectué, une erreur fatale est affichée.

**`<Position> : (Chaîne de caractères)`**

Position de l'option dans le menu parent. Si l'ajout de l'option n'a pas été effectué, une erreur fatale est affichée.

**`<Menu d'origine> : (Nom de champ)`**

Nom du menu dans lequel l'option de menu doit être ajoutée. L'option de menu sera ajoutée à la suite de la dernière option de ce menu.
Remarque : Ce nom de menu peut correspondre à un menu contextuel.

**`<Option à créer> : (Chaîne de caractères)`**

Nom de l'option de menu à ajouter. Ce nom sera utilisé pour manipuler l'option de menu par programmation.
Si ce nom correspond à une option existante, une erreur fatale est affichée.

**`<Libellé> : (Chaîne de caractères)`**

Libellé de la nouvelle option de menu. Ce libellé sera affiché dans la fenêtre et permettra à l'utilisateur de sélectionner l'option.

**`<Procédure navigateur WLangage> : (Nom de procédure)`**

Nom de la procédure navigateur WLangage exécutée lorsque l'option de menu est sélectionnée.

**`<Paramètre de la procédure> : (Variant optionnel)`**

Paramètre pouvant être passé à la procédure &lt;Procédure navigateur WLangage&gt; lorsque l'option de menu est sélectionnée par l'utilisateur.
