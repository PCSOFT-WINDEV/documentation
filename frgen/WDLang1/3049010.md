


## ListeSelectOccurrence (Fonction)

***En anglais : ListSelectCount***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nombre d'éléments sélectionnés dans un champ Liste, Liste image ou Combo.

**Rappel** : L'élément sélectionné correspond à l'élément en cours sur lequel le bandeau de sélection est affiché.

**Remarque** : La fonction **ListeSelectOccurrence** peut être utilisée indifféremment sur :

- les champs Liste liée aux données ou Liste par programmation,

- les champs Liste monosélection ou multisélection.









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Nombre d'éléments sélectionnés dans le champ "LISTE_ListeClient"
ResElementSelect = ListeSelectOccurrence(LISTE_ListeClient)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = ListeSelectOccurrence(<Champ Liste>)`
---

**`<Résultat> : (Entier)`**

Nombre d'éléments sélectionnés dans le champ Liste (ou Combo) spécifiée. Ce paramètre :

- peut être supérieur à 1 uniquement si le champ Liste est multisélection,

- est égal à 1 si le champ Combo est sans saisie ou si le champ Combo est en saisie et qu'un élément est sélectionné,

- est égal à 0 si le champ Combo est en saisie et qu'aucun élément n'est sélectionné.




**`<Champ Liste> : (Nom de champ)`**

Nom du champ Liste (ou Combo) à manipuler.
Si ce paramètre correspond à une chaîne vide (""), le nombre d'éléments sélectionnés dans le champ Liste (ou Combo) auquel appartient l'événement en cours est renvoyé.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le nom du champ Liste (ou Combo) à manipuler doit obligatoirement être spécifié.

### Divers
<a name="divers_ELTPARAGRAPHE000097"></a>

- La fonction **ListeSelectOccurrence** peut être utilisée sur une colonne d'un champ Table de type "Combo".

- Les champs Liste ou Combo placés dans une zone répétée, une rupture ou une colonne conteneur ne sont pas manipulables par la fonction **ListeSelectOccurrence**.
