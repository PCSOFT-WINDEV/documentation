


## MultimédiaJoue (Fonction)

***En anglais : MultimediaPlay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Joue un fichier multimédia dans un champ Multimédia.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Remarque**: Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, son utilisation sera sans effet mais ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MaTable est une chaîne = "C:\Ma musique\mysong.mp3"
SI MultimédiaJoue(MM_Multimédia1, MaTable) = Faux ALORS
	Erreur("Erreur de lecture du fichier")
FIN
```

<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = MultimédiaJoue(<Champ Multimédia> [, <Fichier à jouer> [, <Options>]])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la lecture du fichier a réussi, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Remarque: La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia qui va jouer le fichier multimédia.

**`<Fichier à jouer> : (Chaîne de caractères optionnelle)`**

Nom et chemin du fichier multimédia à jouer. 

Si ce paramètre est précisé, le fichier multimédia indiqué est chargé en mémoire puis joué. La lecture du fichier multimédia reprend toujours au début. 

Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le fichier associé au champ (par exemple avec la fonction [MultimédiaOuvre](../WDLang1/1000017206.md)) est automatiquement utilisé.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Ce paramètre n'est pas disponible. Le fichier associé au champ est automatiquement utilisé. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Correspond: 

- au nom et chemin du fichier multimédia à jouer. 

- à une URL (pour lire la vidéo en streaming). 

- à un nom de ressource (nom du fichier + extension) ajouté à l'application via l'assistant de génération. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Correspond: 

- au nom et chemin du fichier multimédia à jouer. 

- à une URL de vidéo sur un serveur. Remarque: il n'est pas possible de lire des vidéos YouTube. 

- à un nom de ressource (nom du fichier + extension) ajouté à l'application via l'assistant de génération. 




**`<Options> : (Constante de type Entier)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Option de lecture du fichier: 


|   |   |
| --- | --- |
| *MultimédiaNonBloquant* | Le chargement du fichier multimédia est non bloquant. |

## Remarques


### Utilisation de la fonction MultimédiaJoue
<a name="utilisation_fonction_multimediajoue_ELTPARAGRAPHE000140"></a>

La fonction **MultimédiaJoue** peut être utilisée:

- pour charger en mémoire et jouer un fichier multimédia.

- pour jouer un fichier multimédia chargé avec la fonction [MultimédiaOuvre](../WDLang1/1000017206.md).

- pour relancer un fichier mis en pause avec la fonction [MultimédiaPause](../WDLang1/1000017207.md).
	Remarque: Pour faire des pauses dans la lecture d'un fichier multimédia, la lecture du fichier multimédia doit avoir été lancée via la fonction [MultimédiaOuvre](../WDLang1/1000017206.md) suivi de la fonction MultimédiaJoue en précisant uniquement le nom du champ. 






![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Plusieurs champs Multimédia peuvent être créés dans une même fenêtre. Cependant, il est impossible de lire plusieurs vidéos en parallèle avec la fonction **MultimédiaJoue**.  
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Spécificités Android
<a name="specificites_android_ELTPARAGRAPHE000179"></a>

- Par défaut, la fonction **MultimédiaJoue** est bloquante jusqu'à ce que le champ soit prêt à lire le fichier. 

- La constante *MultimédiaNonBloquant* permet de rendre le chargement non bloquant. Dans ce cas, l'appel d'une fonction Multimédia ([MultimédiaPosition](../WDLang1/1000017210.md), ...) échouera tant que le fichier multimédia n'aura pas été chargé par le champ. 

- Les chargements non bloquants sont conseillés lors de l'utilisation de fichiers multimédia non présents sur l'appareil (vidéo en ligne par exemple). 

- Si le paramètre &lt;Fichier à jouer&gt; correspond à l'URL d'une vidéo présente sur un serveur Web "https", il est nécessaire d'ajouter la permission "android.permission.INTERNET" dans l'assistant de [génération de l'application](../Editeurs/9000109.md).

- Sous Android, Il est possible de jouer tous les formats supportés par l'OS (wav, mp3, 3gp, ogg, ...). Un résumé des fichiers audio et vidéo supportés est disponible à l'adresse suivante: [http://developer.android.com/guide/appendix/media-formats.html](http://developer.android.com/guide/appendix/media-formats.html). Remarque: les fichiers wav au format 32 bits ne sont pas supportés par Android.
