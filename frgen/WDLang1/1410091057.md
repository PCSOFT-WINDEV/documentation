


## &lt;Variable sysNotificationJauge&gt;.Maj (Fonction)

***En anglais : &lt;sysNotificationProgressBar variable&gt;.Update***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Met à jour les caractéristiques d'une jauge présente dans une notification système. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
notif est une sysNotification
notif.Titre = "Téléchargement en attente ..."
notif.Jauges[1].Titre = "Vidéo"
notif.Jauges[1].Status = "Téléchargement..."
notif.Jauges[1].TexteProgression = "0/4"
notif.Jauges[1].Avancement = 0.0
notif.Envoie()

// Attend un peu pour mettre à jour la notification
Multitâche(1s)
notif.Jauges[1].Avancement = 0.25
notif.Jauges[1].TexteProgression = "1/4"
notif.Jauges[1].Maj()

// Attend un peu pour mettre à jour la notification
Multitâche(1s)
notif.Jauges[1].Avancement = 0.50
notif.Jauges[1].TexteProgression = "2/4"
notif.Jauges[1].Maj()

// Attend un peu pour mettre à jour la notification
Multitâche(1s)
notif.Jauges[1].Avancement = 0.75
notif.Jauges[1].TexteProgression = "3/4"
notif.Jauges[1].Maj()

// Attend un peu pour mettre à jour la notification
Multitâche(1s)
notif.Jauges[1].Avancement = 1.0
notif.Jauges[1].TexteProgression = "4/4"
notif.Jauges[1].Status = "Téléchargement terminé"
notif.Jauges[1].Maj()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Notification>.Maj()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la jauge a été mise à jour, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Notification> : (Variable de type sysNotificationJauge)`**

Variable de type [sysNotificationJauge](../WDLang1/1410090964.md) correspondant à la jauge à mettre à jour dans la notification.
