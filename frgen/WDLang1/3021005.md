


## OuiNon (Fonction)

***En anglais : YesNo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche un message dans une boîte de dialogue standard proposant les réponses "Oui" et "Non" et renvoie la réponse de l'utilisateur.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=fonctions_dialogue%20-%20HC%20N%B0007.gif)


Remarques: 

- **Cette boîte de dialogue est bloquante**. Pour continuer l'exécution de l'application, l'utilisateur doit valider un des boutons. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour ne pas bloquer l'application, utilisez la fonction [OuiNonAsynchrone](../WDLang1/1000025272.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV permet d'appliquer le thème de votre projet à cette boîte de dialogue. Pour plus de détails, consultez [Personnaliser les boîtes de dialogue](../WDLang1/3021003.md).

### Afficher une boîte de dialogue Oui / Non

`<Résultat> = OuiNon([<Bouton sélectionné>, ] <Texte> [, <Ligne 2> [... [, <Ligne N>]]])`
---

**`<Résultat> : (Constante de type entier)`**

Identifie le bouton sélectionné par l'utilisateur:


|   |   |
| --- | --- |
| *Non* (ou 0) | L'utilisateur a choisi le bouton [NON]<br>ou a fermé la boîte de dialogue par l'icône 'X'. |
| *Oui* (ou 1) | L'utilisateur a choisi le bouton [OUI] |



**`<Bouton sélectionné> : (Constante optionnelle de type entier)`**

Bouton sélectionné par défaut dans la boîte de dialogue:


|   |   |
| --- | --- |
| *Non* (ou 0) | Le bouton "Non" est sélectionné par défaut. |
| *Oui* (ou 1)<br>(Valeur par défaut) | Le bouton "Oui" est sélectionné par défaut. |



**`<Texte> : (Chaîne de caractères)`**

Texte à afficher.

**`<Ligne 2> : (Chaîne de caractères optionnelle)`**

Texte affiché sur la seconde ligne.



**`<Ligne N> : (Chaîne de caractères optionnelle)`**

Texte affiché sur la Nième ligne.

### Afficher une boîte de dialogue Oui / Non sur le navigateur (page interne WebDevOuiNon)

`OuiNon([<Bouton sélectionné>, ] <Code pour Oui> , <Code pour Non> , <Texte> [, <Ligne 2> [... [, <Ligne N>]]])`
---

**`<Bouton sélectionné> : (Constante optionnelle de type entier)`**

Bouton sélectionné par défaut dans la boîte de dialogue:


|   |   |
| --- | --- |
| *Non* (ou 0) | Bouton [NON] sélectionné par défaut |
| *Oui* (ou 1)<br>(Valeur par défaut) | Bouton [OUI] sélectionné par défaut |



**`<Code pour Oui> : (Chaîne de caractères)`**

Code à exécuter si l'internaute choisi le bouton Oui. Ce paramètre peut correspondre:

- au nom d'un bouton. Si le bouton Oui est sélectionné, le code de clic de ce bouton sera exécuté.

- au nom d'une fonction / procédure navigateur. Si le bouton Oui est sélectionné, cette procédure sera exécutée.

- une chaîne ou une autre valeur. Si le bouton Oui est sélectionné, la valeur sera exécutée comme étant un code JavaScript.




**`<Code pour Non> : (Chaîne de caractères)`**

Code à exécuter si l'internaute choisi le bouton Non. Ce paramètre peut correspondre:

- au nom d'un bouton. Si le bouton Non est sélectionné, le code de clic de ce bouton sera exécuté.

- au nom d'une fonction / procédure navigateur. Si le bouton Non est sélectionné, cette procédure sera exécutée.

- une chaîne ou une autre valeur. Si le bouton Non est sélectionné, la valeur sera exécutée comme étant un code JavaScript.




**`<Texte> : (Chaîne de caractères)`**

Texte à afficher.

**`<Ligne 2> : (Chaîne de caractères optionnelle)`**

Texte affiché sur la seconde ligne.



**`<Ligne N> : (Chaîne de caractères optionnelle)`**

Texte affiché sur la Nième ligne.

## Remarques


### Caractéristiques de la boîte de dialogue
<a name="caracteristiques_boite_dialogue_ELTPARAGRAPHE000170"></a>



- Le titre de la boîte de dialogue correspond au titre de la fenêtre (ou page) en cours.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour respecter les spécifications du système, le titre de la boîte de dialogue est vide par défaut. Pour définir ce titre, utilisez la fonction [TitreSuivant](../WDLang1/3038043.md).

- Pour modifier ou définir le titre de la boîte de dialogue, utilisez la fonction [TitreSuivant](../WDLang1/3038043.md).




- Le message est cadré à gauche.

- Les libellés des boutons dépendent de la langue d'exécution de Windows.

- Le nombre maximum de caractères affichés est limité à 4096. Si une chaîne plus grande est passée en paramètre, elle sera tronquée.

- L'icône affichée (point d'exclamation) ne peut pas être modifiée.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Pour personnaliser cette boîte de dialogue** (ainsi que toutes les boîtes de dialogue système de votre application), cochez l'option "Personnaliser les fenêtres système (Info, OuiNon, Confirmer, Dialogue)" dans l'onglet "Style" de la description du projet. Pour plus de détails, consultez [Personnaliser les boîtes de dialogue](../WDLang1/3021003.md).![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Pour personnaliser cette boîte de dialogue** (ainsi que toutes les boîtes de dialogue système de votre site), cochez l'option "Appliquer le thème sur les boîtes de dialogue (OuiNon et OKAnnuler)" dans l'onglet "Thème" de la fenêtre de description du projet. 
<a name="NOTE0_2"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Affichage de la boîte de dialogue
<a name="affichage_boite_dialogue_ELTPARAGRAPHE000200"></a>

L'affichage de la boîte de dialogue n'est pas bloquant. La boîte de dialogue est affichée au centre de la page, avec un effet de GFI (Grisage des Fenêtres Inaccessibles).

La fonction **OuiNon** utilise la page interne nommée "WebDevOuiNon". Pour intégrer cette page dans votre projet:

1. Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_nouveau.gif) parmi les boutons d'accès rapide. 

2. La fenêtre de création d'un nouvel élément s'affiche: cliquez sur "Page" puis sur "Page".

3. Dans l'onglet "Page Interne", sélectionnez la page interne "Oui / Non".

4. Validez. La page "WebDevOuiNon" est affichée sous l'éditeur.

5. Enregistrez la page en conservant son nom par défaut.




Limitation: la fonction **OuiNon** ne doit pas être utilisée en code navigateur dans une page dont l'édition est de type "Tranches (Responsive historique pour compatibilité)". 
<a name="NOTE0_3"></a>


### Saut de ligne dans la boîte de dialogue
<a name="saut_ligne_dans_boite_dialogue_ELTPARAGRAPHE000223"></a>La chaîne prédéfinie RC (Retour Chariot) peut être utilisée pour forcer le passage à la ligne suivante. Par exemple:


```wl
OuiNon("La fiche XXX a été modifiée." + RC + ...
	"Voulez-vous la sauver avant de quitter?")
```


est équivalent à:


```wl
OuiNon("La fiche XXX a été modifiée.", ...
	"Voulez-vous la sauver avant de quitter?")
```


Il est également possible d'utiliser la syntaxe des chaînes multilignes. Par exemple: 


```wl
OuiNon(
[
La fiche XXX a été modifiée.

Voulez-vous la sauver avant de quitter?
])
```

### Divers
<a name="divers_ELTPARAGRAPHE000242"></a>

- Les timers (fonction [TimerSys](../WDLang1/3015006.md)) ne sont pas stoppés lors de l'appel de cette fonction.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Les événements Windows ne sont pas stoppés lors de l'appel à cette fonction.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La fonction [DélaiAvantFermeture](../WDLang1/3038040.md) limite le temps d'affichage du message. La boîte de dialogue est automatiquement fermée. Pour les boîtes de question ou de confirmation, la réponse attendue correspond au bouton par défaut.

- Le libellé des boutons s'affiche dans la langue utilisée par Windows sur le poste en cours.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) La première syntaxe n'est pas disponible dans une page AWP. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Si votre projet utilise les sessions prélancées, cette fonction ne doit pas être utilisée dans l'événement "Initialisation" du projet. Cette fonction doit être utilisée dans l'événement "Initialisation lors d'une connexion à une session prélancée". 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette fonction ne doit pas être utilisée: 

	- dans l'événement "Modification de la taille" des fenêtres. Dans le cas contraire, l'application sera bloquée.

	- dans l'événement "Changement d'orientation" des fenêtres. 

	- dans l'événement "Mise au premier-plan" associé au projet. 
			 Remarque: La fonction peut par contre être utilisée dans l'événement "Mise au premier plan" d'une fenêtre. 

	- dans un thread. 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) La position des boutons est dépendante de la version de Android. A partir de la version 4.1 de Android, le bouton de validation est placé à droite par le système. L'utilisation de la fonction [Dialogue](../WDLang1/3021015.md) permet si besoin de fixer la position des boutons.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000480"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **OuiNon** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
