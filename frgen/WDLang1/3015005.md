
## Handle (Fonction)

***En anglais : Handle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le "Handle" système (HWND) d'un champ ou d'une fenêtre WINDEV. Il est ainsi possible d'appeler certaines fonctions API avec ce paramètre (avec les fonctions [API](../WDLang1/3014005.md) ou [AppelDLL32](../WDLang1/3014003.md), [SendMessage](../WDLang1/3015003.md) ou [PostMessage](../WDLang1/3015001.md)).

L'utilisation de ce "Handle" est rare avec les fonctions du WLangage.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Renvoie le UIView associé à la fenêtre. Cet identifiant peut être utilisé lors de la programmation en Objective C. 
 remarque : le UIView n'est pas initialisé dans le code de déclaration des globales de la fenêtre mais dans le code de fin d'initialisation de la fenêtre. Pour plus de détails, consultez [Saisir du code Objective C](../Editeurs/1000019887.md). 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) La notion de **handle** n'existe pas dans les applications Android. Un code natif Java peut obtenir un "context" si besoin avec les fonctions **getActiviteEnCours** et **getContexteApplication**. Pour plus de détails, consultez [Particularités des applications pour Android - Utilisation de code Java natif dans une application Android](../Editeurs/9000108.md).

<a name="sample_code"></a>

## Exemple


```wl
// Copier le contenu d'un champ de saisie dans le presse-papiers
SendMessage(Handle(SAI_SAISIE1), WM_COPY, 0, 0)
```

## Syntaxe

### Récupérer le handle d'un champ ou d'une fenêtre

`<Résultat> = Handle([<Nom de l'objet>])`
---

**`<Résultat> : (Pointeur)`**

Handle demandé.

**`<Nom de l'objet> : (Chaîne de caractères optionnelle)`**

Nom du champ ou de la fenêtre. Si ce paramètre n'est pas précisé, la fonction **Handle** utilise la fenêtre en cours. Si ce paramètre correspond à une colonne de table, le handle de son champ de saisie sera renvoyé (NULL si la colonne n'est pas en saisie).  


<a name="SYNTAXE2"></a>

### Récupérer le handle d'un élément spécifique d'un champ

`<Résultat> = Handle([<Nom de l'objet>, ] <Type de l'objet>)`
---

**`<Résultat> : (Entier)`**

Handle demandé.

**`<Nom de l'objet> : (Chaîne de caractères optionnelle)`**

Nom du champ.

**`<Type de l'objet> : (Constante de type Entier)`**

Élément de la combo dont le handle est recherché.


|   |   |
| --- | --- |
| *HandleAscenseurH* | Renvoie le handle de l'ascenseur horizontal du champ. |
| *HandleAscenseurV* | Renvoie le handle de l'ascenseur vertical du champ. |
| *HandleListeCombo* | Renvoie le handle de la liste déroulante associée à une combo (le champ doit être un champ Combo). |
| *HandleListeSaisieAssistée* | Renvoie le handle de la liste déroulante associée à un champ proposant la saisie assistée. |
| *HandleSaiseCombo* | Renvoie le handle du champ de saisie associé à une combo (le champ doit être un champ Combo). |




<a name="SYNTAXE3"></a>
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
### Récupérer le handle d'une fenêtre iPhone/iPad

`<Résultat> = Handle([<Nom de l'objet>, ] <Type de l'objet>)`
---

**`<Résultat> : (Entier)`**

UIView associé à la fenêtre.

**`<Nom de l'objet> : (Chaîne de caractères optionnelle)`**

Nom de la fenêtre. Si ce nom correspond à un nom de champ, &lt;Résultat&gt; correspondra à NULL.

**`<Type de l'objet> : (Constante de type Entier)`**

Élément dont le handle est recherché.


|   |   |
| --- | --- |
| *HandleChampNatif* | Renvoie le champ natif iOS associé au champ spécifié. Si cette constante est utilisée, &lt;Résultat&gt; correspondra à une valeur non nulle uniquement pour les champs suivants : champ Carte (MKMapView) et champ HTML (WKWebView). |
| *HandleUIViewController* | Renvoie le UIViewController associé à la fenêtre spécifiée. Si cette constante est utilisée, &lt;Résultat&gt; correspondra à une valeur non nulle uniquement pour les fenêtres (mais pas pour les champs). |
