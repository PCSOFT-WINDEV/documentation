
## UTF8VersChaîne (Fonction)

***En anglais : UTF8ToString***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Convertit une chaîne au format UTF8 en une chaîne ANSI ou une chaîne Unicode.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Conversion d'une chaîne UTF8 au format ANSI
RésultatConversion = UTF8VersChaîne(ChaîneUTF8, alphabetAnsi)
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = UTF8VersChaîne(<Chaîne UTF8 à convertir> [, <Alphabet destination>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- En mode ANSI, chaîne de caractères ANSI. 

	- Si l'alphabet destination n'est pas précisé, la conversion en ANSI utilise l'alphabet courant. 

	- Si l'alphabet destination est précisé, la conversion en ANSI utilise l'alphabet spécifié.




- En mode Unicode, chaîne de caractères Unicode contenant la conversion. L'alphabet destination est ignoré.

- EOT si des problèmes de conversion sont apparus.




**`<Chaîne UTF8 à convertir> : (Chaîne de caractères)`**

Chaîne à convertir.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cette chaîne est une chaîne ANSI au format UTF8.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Ce paramètre correspond à un buffer contenant une chaîne au format UTF8. Le résultat sera une chaîne Unicode contenant la conversion.

**`<Alphabet destination> : (Entier optionnel)`**

Alphabet à utiliser pour la création de la chaîne. Par défaut, ce paramètre correspond à l'alphabet courant (précisé avec la fonction [ChangeAlphabet](../WDLang1/3054001.md)).

## Remarques
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Conversion en PHP
<a name="conversion_php_ELTPARAGRAPHE000289"></a>La conversion réalisée en PHP utilise les extensions PHP suivantes :

- soit l'extension php_iconv.dll

- soit l'extension php_mbstring.dll




Si aucune de ces extensions PHP n'est présente, seuls les caractères latins seront convertis (par exemple, les caractères chinois ou russes ne seront pas convertis).

Les extensions php_iconv.dll ou php_mbstring.dll sont couramment proposées sur les serveurs PHP. Pour savoir si votre hébergeur propose ces extensions, il suffit de saisir les informations suivantes dans un moteur de recherche : phpinfo &lt;Nom de l'hébergeur&gt;.

Si vous possédez votre propre serveur PHP, pour installer ces extensions, il suffit de décommenter l'extension voulue dans le fichier PHP.INI.
