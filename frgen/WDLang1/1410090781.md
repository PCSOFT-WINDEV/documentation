
## JourDansLAnnéeVersDate (Fonction)

***En anglais : DayOfYearToDate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la date (au format "AAAAMMJJ") correspondant à un numéro de jour dans l'année.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
dDate est une Date
nJour est un entier = 50
dDate = JourDansLAnnéeVersDate(nJour)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = JourDansLAnnéeVersDate(<Jour> [, <Année>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Date au format "AAAAMMJJ".

**`<Jour> : (Entier)`**

Numéro de jour dans l'année (compris entre 1 et 366).

**`<Année> : (Entier optionnel)`**

Année à utiliser pour le calcul.
Si ce paramètre n'est pas spécifié, l'année en cours est utilisée.
