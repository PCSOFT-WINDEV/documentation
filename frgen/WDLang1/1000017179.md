


## TableModifieColonne (Fonction)

***En anglais : TableModifyColumn***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie une colonne dans un champ "Table horizontale".

**Remarque**: La fonction **TableModifieColonne** peut être utilisée indifféremment sur:

- un champ Table horizontale de type "fichier" ou "par programmation".

- un champ Table horizontale monosélection ou multisélection.





<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`TableModifieColonne(<Champ Table> , <Indice> [, <Élément ligne 1> [... [, <Élément ligne N>]]])`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ Table horizontale à manipuler.

Si ce paramètre correspond à une chaîne vide (""), le champ Table manipulé est le champ Table auquel appartient l'événement en cours.

**`<Indice> : (Entier)`**

Indice de la colonne à modifier. La première colonne a pour indice 1.


|   |   |
| --- | --- |
| Indice égal à -1. | La colonne en cours est modifiée. Aucun effet si aucune colonne n'est sélectionnée. |
| Indice supérieur au nombre de colonnes du champ Table. | Une erreur du WLangage est générée. |



**`<Élément ligne 1> : (Chaîne de caractères optionnelle)`**

Premier élément de la première ligne à modifier dans la colonne. La valeur de cet élément remplace la valeur existante. Chaque élément correspond à une ligne dans le champ Table. Chaque type d'élément modifié doit être compatible avec le type de la ligne concernée.
Si aucun des paramètres &lt;Elément ligne X&gt; n'est spécifié, la fonction **TableModifieColonne** n'a aucun effet.



**`<Élément ligne N> : (Chaîne de caractères optionnelle)`**

Nième élément de la Nième ligne à modifier dans la colonne. La valeur de cet élément remplace la valeur existante. Chaque élément correspond à une ligne dans le champ Table. Chaque type d'élément modifié doit être compatible avec le type de la ligne concernée.
Si aucun des paramètres &lt;Elément ligne X&gt; n'est spécifié, la fonction **TableModifieColonne** n'a aucun effet.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Caractéristique des éléments de la colonne
<a name="caracteristique_des_elements_colonne_ELTPARAGRAPHE000082"></a>

- Pour modifier uniquement la valeur d'un élément dans une colonne, utilisez la syntaxe suivante:
	
	```txt
	ChampTable.Nomligne[IndiceColonne] = NouvelleValeur
	```


- Si un élément correspond au résultat d'un calcul, mettez l'expression numérique entre parenthèses. Par exemple:
	
	```wl
	TableModifieColonne(TABLE_TableCalcul, (53+29),(83-21))
	```




<a name="NOTE0_2"></a>


### Table liée aux données: Modifications dans la table liée
<a name="table_liee_aux_donnees_modifications_dans_table_liee_ELTPARAGRAPHE000101"></a>

Si la saisie en cascade est activée, la table liée aux données liée au champ table liée aux données est automatiquement modifiée lorsque l'utilisateur passe à la colonne suivante.

Si la saisie en cascade n'est pas activée, la table liée aux données liée au champ Table liée aux données n'est pas modifiée. Pour écrire l'enregistrement dans la table, exécutez la fonction [TableEnregistre](../WDLang1/3074008.md) après la fonction **TableModifieColonne**.

**Rappel**: L'option "saisie en cascade" peut être sélectionnée:

- Lors de la création d'un champ Table.

- Dans l'onglet "Détail" de la fenêtre de description du champ Table sous l'éditeur de fenêtres.



<a name="NOTE0_3"></a>


### Modifications réalisées dans un champ Table liée aux données
<a name="modifications_realisees_dans_champ_table_liee_aux_donnees_ELTPARAGRAPHE000122"></a>

Pour modifier une colonne d'un champ table liée aux données, il est conseillé de:

- modifier directement l'enregistrement dans le fichier avec la fonction [HModifie](../WDLang4/3044042.md),

- utiliser la fonction [TableAffiche](../WDLang1/3074003.md) pour ré-actualiser le champ Table.



<a name="NOTE0_4"></a>


### Fonction TableModifieColonne et propriété Modifié
<a name="fonction_docparampagetitleshort_propriete_modifie_ELTPARAGRAPHE000140"></a>

La fonction **TableModifieColonne** n'a aucune influence sur la propriété [Modifié](../Proprietes/2510080.md). La propriété [Modifié](../Proprietes/2510080.md) permet de savoir si la colonne en cours a été modifiée directement par l'utilisateur (saisie directe dans le champ Table).
