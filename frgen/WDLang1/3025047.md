
## ChargeParamètre (Fonction)

***En anglais : LoadParameter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lit une valeur persistante. La valeur persistante a été sauvegardée grâce à la fonction [SauveParamètre](../WDLang1/3025046.md) : 

- soit dans la base de registre (ou le fichier équivalent sur la plateforme d'exécution). Par exemple : 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Sous Android, les valeurs persistantes sont sauvegardées dans les préférences partagées (Shared Preferences) de l'application. 

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Sous iOS, les valeurs persistantes sont sauvegardées dans les paramètres de l'application ("NSUserDefault"). 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Dans un site WEBDEV, les valeurs persistantes sont enregistrées dans un cookie navigateur. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Dans une application Linux, les paramètres sont sauvegardés dans le dossier $HOME/.local/share.




- ![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) soit dans le fichier spécifié avec la fonction [InitParamètre](../WDLang1/3025044.md).









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Sauvegarde
SauveParamètre("LOGIN", SAI_Saisie1)
// Restauration
SAI_Saisie1 = ChargeParamètre("LOGIN", "")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = ChargeParamètre(<Nom du paramètre> [, <Valeur par défaut>])`
---

**`<Résultat> : (Chaîne de caractères ou entier)`**



- Valeur du paramètre recherché. 

- Si le paramètre recherché n'est pas trouvé, correspond à la &lt;Valeur par Défaut&gt; ou à chaîne vide ("") si aucune valeur par défaut n'a été spécifiée.




**`<Nom du paramètre> : (Chaîne de caractères)`**

Nom du paramètre à rechercher. Ce paramètre ne doit pas correspondre à une chaîne vide.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Si le mode d'initialisation choisi est la base de registre, la fonction **ChargeParamètre** n'est sensible ni à la casse, ni à l'accentuation du nom du paramètre (Paramètre et parametre sont équivalents).

**`<Valeur par défaut> : (Chaîne de caractères optionnelle ou entier optionnel)`**

Valeur par défaut du paramètre. Cette valeur sera renvoyée si la valeur du paramètre n'est pas trouvée.
