


## &lt;Multimédia&gt;.Pause (Fonction)

***En anglais : &lt;Multimedia&gt;.Pause***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Met en pause la lecture d'un fichier multimédia dans un champ Multimédia. La lecture pourra continuer en utilisant la fonction [&lt;Multimédia&gt;.Joue](../WDLang1/1000020089.md).

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Remarque**: Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MaTable est une chaîne = "C:\Ma musique\mysong.mp3"
MM_Multimédia1.Ouvre(MaTable)
...
MM_Multimédia1.Pause()
...
MM_Multimédia1.Joue()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Multimédia>.Pause()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'affichage dans le champ Multimédia est correctement arrêté, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Remarque: La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.
