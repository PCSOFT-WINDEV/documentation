
## JourEnCours (Fonction)

***En anglais : CurrentDay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le numéro du jour en cours dans le mois courant.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
nJour est un entier

// Si la date courante est : "03/04/2023"
nJour = JourEnCours() // nJour vaut 3

// Si la date courante est : "27/07/2048"
nJour = JourEnCours() // nJour vaut 27
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = JourEnCours()`
---

**`<Résultat> : (Entier)`**

Jour en cours dans le mois courant. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Les codes suivants sont équivalents : 

```wl
dDate est une Date = DateDuJour()
```
et 

```wl
nJour est un entier
nJour = dDate.Jour
```
