


## &lt;Variable FichierDisque&gt;.LitLigne (Fonction)

***En anglais : &lt;DiskFile variable&gt;.ReadLine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lit une ligne dans un fichier externe.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Dans cette version, il est possible uniquement de lire une ligne dans un fichier externe au format ANSI.

## Syntaxe

### Lire chaque ligne d'un fichier

`<Résultat> = <Fichier manipulé>.LitLigne([<Séparateur>])`
---

**`<Résultat> : (Chaîne de caractères ou Chaîne de caractères UNICODE)`**



- Ligne lue dans un fichier externe. 

- Constante *EOT* si la fin du fichier a été atteinte. 

- Chaîne vide ("") en cas d'erreur. Dans ce cas, la variable [ErreurDétectée](../WDLang1/3087001.md) est mise à <u><u><u><u>Vrai</u></u></u></u>.




Remarque : Une ligne se termine par un retour chariot (RC).

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre doit être de type chaîne de caractères.

**`<Fichier manipulé> : (Variable de type FichierDisque)`**

Nom de la variable de type [FichierDisque](../WDLang1/1410088883.md) initialisée avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre doit être de type variant.

**`<Séparateur> : (Chaîne de caractères)`**

Séparateur utilisé entre les lignes. Par défaut, le séparateur utilisé correspond au Retour-Chariot (RC). 

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre n'est pas disponible. Le séparateur utilisé correspond au Retour-Chariot (RC).

### Lire chaque ligne d'un fichier via une procédure

`<Résultat> = fLitLigne(<Fichier manipulé> , <Procédure WLangage> [, <Séparateur>])`
---

**`<Résultat> : (Entier)`**

Nombre de lignes lues. 

Remarque : Une ligne se termine par un retour chariot (RC).

**`<Fichier manipulé> : (Entier ou variable de type FichierDisque)`**

Nom de la variable de type [FichierDisque](../WDLang1/1410088883.md) initialisée avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre doit être de type variant.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également nommée "callback") appelée pour chaque ligne lue dans le fichier. Cette procédure permet de manipuler la ligne en cours. Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction fLitLigne](../WDLang1/1410089295.md).

**`<Séparateur> : (Chaîne de caractères)`**

Séparateur utilisé entre les lignes. Par défaut, le séparateur utilisé correspond au Retour-Chariot (RC). 

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre n'est pas disponible. Le séparateur utilisé correspond au Retour-Chariot (RC).

## Remarques


### Gestion des erreurs
<a name="gestion_des_erreurs_ELTPARAGRAPHE000402"></a>La fonction **&lt;Variable FichierDisque&gt;.LitLigne** génère une erreur dans les cas suivants :

- le fichier n'est pas ouvert,

- le fichier n'est pas accessible en lecture,

- le fichier est bloqué par un autre poste ou par une autre application. La fonction [&lt;Variable FichierDisque&gt;.Débloque](../WDLang1/1410089040.md) permet de débloquer un fichier externe.



<a name="NOTE0_2"></a>


### Position dans le fichier
<a name="position_dans_fichier_ELTPARAGRAPHE000424"></a>A l'ouverture d'un fichier, la position en cours correspond :

- au premier octet du fichier (par défaut),

- au dernier octet du fichier si le fichier est ouvert en "ajout" (constante *foAjout*).




Cette position peut être modifiée par la fonction [&lt;Variable FichierDisque&gt;.Positionne](../WDLang1/1410089048.md).

La fonction **&lt;Variable FichierDisque&gt;.LitLigne** lit les éléments spécifiés à partir de la position en cours. Après l'exécution de **&lt;Variable FichierDisque&gt;.LitLigne**, la position en cours correspond au dernier octet lu. La fonction **&lt;Variable FichierDisque&gt;.LitLigne** retourne la constante *EOT* si la fin du fichier a été atteinte.

### Gestion ANSI/Unicode
<a name="gestion_ansiunicode_ELTPARAGRAPHE000457"></a>La fonction **&lt;Variable FichierDisque&gt;.LitLigne** permet de lire : 

- une chaîne de type Unicode dans un fichier Unicode. 

- une chaîne de type Ansi dans un fichier Ansi. 




Le fichier a été créé ou ouvert avec les fonctions [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md)/[&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) en précisant le type du fichier. 

Selon le format du fichier externe manipulé, certaines conversions sont nécessaires après la lecture d'une chaîne de caractères dans un fichier externe :


|   |   |   |   |
| --- | --- | --- | --- |
|   | **Poste en cours** | **Fichier externe <br>au format ANSI<br>(fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md) avec la constante *foAnsi*)** | **Fichier externe <br>au format Unicode<br>(fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md) avec la constante *foUnicode*)** |
| Fonction **&lt;Variable FichierDisque&gt;.LitLigne** | PC sous Windows | Lecture au format ANSI<br>Conversion possible en Unicode avec la fonction [&lt;Chaîne ANSI&gt;.AnsiVersUnicode](../WDLang1/1000024892.md) |
|   | Mobile | Lecture au format Unicode<br>Conversion possible en ANSI avec la fonction [UnicodeVersAnsi](../WDLang1/3024025.md) |


**Remarque** : Si le résultat de la fonction **&lt;Variable FichierDisque&gt;.LitLigne** d'un fichier ANSI est affecté à une chaîne Unicode (et inversement), la conversion sera implicitement réalisée.

Pour plus de détails, consultez [Gestion de l'Unicode](../WDLang1/3024038.md)
