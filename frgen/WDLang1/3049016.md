


## ListeSupprime (Fonction)

***En anglais : ListDelete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un élément d'un champ Liste par programmation (y compris Liste image) ou d'un champ Combo par programmation.

**Remarque** : La fonction **ListeSupprime** peut être utilisée indifféremment sur les champs Liste monosélection et multisélection.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Attention** : L'élément sera supprimé uniquement sur la page affichée dans le navigateur. Pour plus de détails, voir les Remarques.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003049016&name=listesupprime_fonction">Voir des exemples supplémentaires</a>

```wl
// Suppression de l'élément sélectionné dans le champ "LISTE_ListeClient"
ListeSupprime(LISTE_ListeClient)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`ListeSupprime(<Champ Liste> [, <Indice de l'élément>])`
---

**`<Champ Liste> : (Nom de champ)`**

Nom du champ Liste (ou Combo) à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ manipulé est le champ Liste (ou Combo) auquel appartient l'événement en cours.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le nom du champ Liste (ou Combo) à manipuler doit obligatoirement être spécifié.

**`<Indice de l'élément> : (Entier optionnel)`**

Indice de l'élément à supprimer du champ Liste (ou Combo). Si ce paramètre n'est pas précisé :

- dans un champ Liste monosélection, l'élément en cours est supprimé.

- dans un champ Liste multisélection, les éléments sélectionnés dans le champ Liste sont supprimés.

- dans un champ Combo, l'élément en cours est supprimé. Si ce champ est un champ Combo est en saisie, le champ de saisie est mis à vide.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Les champs Combo en saisie ne sont pas disponibles.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Suppression en chaîne
<a name="suppression_chaine_ELTPARAGRAPHE000095"></a>Dans le cas de la suppression en chaîne d'éléments, les éléments situés après chaque élément supprimé sont déplacés. Il est conseillé d'effectuer les suppressions en chaîne en partant du dernier élément.

Par exemple :

```wl
Indice est un entier
POUR Indice = ListeOccurrence(LISTE_ListeClient) A 1 PAS -1
	ListeSupprime(LISTE_ListeClient, Indice)
FIN
```

<a name="NOTE0_2"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Suppression d'un élément sur le navigateur
<a name="suppression_element_sur_navigateur_ELTPARAGRAPHE000114"></a>Lors de la suppression d'un élément en code navigateur, cet élément est supprimé uniquement sur la page affichée dans le navigateur. Pour que cet élément soit également supprimé sur le serveur, il est nécessaire d'exécuter la fonction **ListeSupprime** sur le serveur.

L'utilisation de la fonction **ListeSupprime** en code navigateur est intéressante lors de l'utilisation de la [technologie AJAX](../WDLang2/3055101.md), en mode "AJAX Programmé" (utilisation de la fonction [AJAXExécute](../WDLang2/3055114.md) ou [AJAXExécuteAsynchrone](../WDLang2/3055115.md)).

**Rappel** : En mode "AJAX automatique et immédiat", il suffit de passer le traitement serveur contenant la fonction **ListeSupprime** en mode AJAX automatique. Rien de plus ! Aucune programmation supplémentaire n'est nécessaire. Pour plus de détails, consultez [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_3"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000148"></a>

- Pour supprimer un élément dans un champ Table, utilisez la fonction [TableSupprime](../WDLang1/3074032.md).

- La fonction **ListeSupprime** peut être utilisée sur une colonne d'un champ Table de type "Combo".
