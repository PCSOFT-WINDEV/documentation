


## TableSupprimeSelect (Fonction)

***En anglais : TableDeleteSelect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime la ou les lignes sélectionnées dans un champ Table ou Table hiérarchique.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Supprime toutes les lignes sélectionnées
SI OuiNon("Voulez-vous vraiment supprimer les clients sélectionnés?") ALORS
	TableSupprimeSelect(TABLE_Affichage_Client)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`TableSupprimeSelect(<Champ Table>)`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à: 

- un champ Table.

- un champ Table hiérarchique.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000073"></a>

La fonction **TableSupprimeSelect** peut être utilisée indifféremment sur: 

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection. 
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Rappel**: La multisélection n'est pas disponible sur les champs Table en mode classique.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Table en mode Ajax, les champs Table en mode classique et les champs Table hiérarchique. ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode navigateur. Le champ Table hiérarchique n'est pas disponible.
<a name="NOTE0_2"></a>


### Suppression dans un champ Table ou Table hiérarchique fichier
<a name="suppression_dans_champ_table_table_hierarchique_fichier_ELTPARAGRAPHE000099"></a>

La fonction **TableSupprimeSelect** supprime les enregistrements correspondants dans la table associée au champ. Si des rubriques sont reliées à d'autres tables, aucune modification n'est effectuée automatiquement sur ces tables liées.
<a name="NOTE0_3"></a>


### Intégrité référentielle et champ Table ou Table hiérarchique fichier
<a name="integrite_referentielle_champ_table_table_hierarchique_fichier_ELTPARAGRAPHE000110"></a>

Si la gestion de l'intégrité référentielle est active (fonction [HGèreIntégrité](../WDLang4/3044058.md)), testez la fonction [HErreurIntégrité](../WDLang4/3044086.md) après l'appel de la fonction **TableSupprimeSelect** pour vérifier l'intégrité. Si une erreur d'intégrité est détectée, la ligne n'est pas supprimée et reste visible dans le champ.
<a name="NOTE0_4"></a>


### Suppression dans un champ Table liée aux données et Trigger
<a name="suppression_dans_champ_table_liee_aux_donnees_trigger_ELTPARAGRAPHE000127"></a>

Il est possible de déclencher un trigger lors de la suppression d'un enregistrement dans un champ Table liée aux données. Pour plus de détails, consultez la documentation de la fonction [HDécritTrigger](../WDLang4/3044074.md).
<a name="NOTE0_5"></a>


### Gestion des erreurs
<a name="gestion_des_erreurs_ELTPARAGRAPHE000139"></a>

En cas d'échec de la suppression, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour plus de détails sur l'erreur, il est possible d'utiliser la fonction [ErreurInfo](../WDLang1/3013008.md).
<a name="NOTE0_6"></a>


### Blocage de la table liée
<a name="blocage_table_liee_ELTPARAGRAPHE000158"></a>

Si la table est bloquée dans le traitement en cours, la fonction **TableSupprimeSelect** supprime la ligne spécifiée et débloque la table.
