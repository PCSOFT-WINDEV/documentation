


## EditeurCodeCharge (Fonction)

***En anglais : CodeEditorLoad***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Charge un fichier de code WLangage dans un champ Editeur de code. Ce fichier contient le code WLangage à afficher dans le champ.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
sFichier est une chaîne
// Ouvre le sélecteur de fichiers
sFichier = fSélecteur("", "", "Sélectionnez un fichier...", "Code WLangage (*.WL)" + TAB + "*.WL", "*.WL")

SI sFichier <> "" ALORS
	// Charge le fichier dans le champ Éditeur de code
	EditeurCodeCharge(EDCODE_Exemple, sFichier)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EditeurCodeCharge(<Champ Editeur de code> , <Fichier à charger>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été chargé dans le champ Editeur de code, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.

**`<Fichier à charger> : (Chaîne de caractères)`**

Nom et chemin complet du fichier à charger. Ce fichier correspond à un fichier précédemment sauvé avec la fonction [EditeurCodeSauve](../WDLang1/1410090245.md).
