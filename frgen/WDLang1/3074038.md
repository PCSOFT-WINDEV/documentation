


## TablePositionneEnregistrement (Fonction)

***En anglais : TableSelectToFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Positionne sur l'enregistrement de la table correspondant à une ligne sélectionnée dans le champ table liée aux données multisélection.

**Remarque** : Sur un champ table liée aux données monosélection, l'enregistrement en cours dans la table correspond toujours à l'élément sélectionné dans le champ Table.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
i est un entier
POUR i = 1 A TableSelectOccurrence(TABLE_Produit)
	TablePositionneEnregistrement(TABLE_Produit, i)
	Trace(Produit.IDProduit)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`TablePositionneEnregistrement(<Champ Table> , <Rang>)`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ Table liée aux données à manipuler. 
Si ce paramètre correspond à une chaîne vide (""), le champ Table auquel appartient l'événement en cours est manipulé.
Si ce paramètre ne correspond pas à un champ Table liée aux données, une erreur WLangage est affichée.

**`<Rang> : (Entier)`**

Rang de la sélection. Si ce paramètre ne correspond pas à un rang existant, une erreur WLangage est affichée.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Il est possible d'utiliser cette fonction avec un champ Table liée aux données monosélection si et seulement si le paramètre &lt;Rang&gt; vaut 1.
