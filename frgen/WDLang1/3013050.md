


## Trace (Fonction)

***En anglais : Trace***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche des informations demandées (contenu d'un champ par exemple) dans une fenêtre ouverte en parallèle de la fenêtre en cours.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Trace.gif)
**Remarques** : 

- La fonction **Trace** est utile en phase de développement pour vérifier le bon déroulement du programme. Sous l'éditeur, le volet ["Trace du débogueur"](../Editeurs/2027028.md) affiche les informations contenues dans la fenêtre de trace ainsi que le texte complet des erreurs rencontrées.

- La fenêtre de trace s'affiche aussi bien en mode développement qu'en exécution. Pour éviter un affichage en exécution, utilisez la fonction [EnModeTest](../WDLang1/3013011.md).




 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// ------------------
// Affichage d'informations dans la fenêtre de trace 
Trace("Résultat du calcul : " + ResCalcul)
// ----------------
```



```wl
// Surcharge de l'affichage de la trace
PROCEDURE Trace(MessageAAfficher)
SI EnModeTest() ALORS Trace(MessageAAfficher)
```

```wl
// Appel de la fonction Trace surchargée
WL.Trace("Lancement de la trace")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`Trace(<Informations> [, <Informations complémentaires 1> [... [, <Informations complémentaires N>]]])`
---

**`<Informations> : (Tout type)`**

Ensemble des éléments à afficher dans la fenêtre de trace.

**`<Informations complémentaires 1> : (Tout type (optionnel))`**

Élément supplémentaire à afficher dans la fenêtre de trace. Sera affiché sur la même ligne que &lt;Informations&gt;.




**`<Informations complémentaires N> : (Tout type (optionnel))`**

Élément supplémentaire à afficher dans la fenêtre de trace. Sera affiché sur la même ligne que &lt;Informations&gt;.

## Remarques


### Conditions d'utilisation selon les plateformes
<a name="conditions_utilisation_selon_les_plateformes_ELTPARAGRAPHE000087"></a>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) La fonction **Trace** permet d'afficher les informations demandées uniquement dans un fichier. Par défaut, ce fichier est créé dans le répertoire temporaire d'UNIX, sous le nom "Trace_&lt;Projet&gt;.txt".![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Les informations de la fonction **Trace** sont affichées au début de la page HTML renvoyée.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Pour les pages WEBDEV : 

- La fenêtre de trace est affichée uniquement en Go pour les pages dynamiques (non AWP). 

- En mode AWP et en déploiement, la fonction **Trace** permet uniquement d'écrire les informations spécifiées dans un fichier (constante ***trFichier*** utilisée avec la fonction [TraceDébut](../WDLang1/3013052.md)).




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Pour les applications Mobiles : 

- **Dans le simulateur**, la fenêtre de trace est affichée. 

- **Lors d'un test sur le mobile**, la fenêtre de trace est affichée sur le périphérique (test via WMDev (pour les applications iOS), via USB ou Wi-Fi). 
	

- **En exécution** : 

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) La fonction **Trace** affiche des informations demandées dans la fenêtre de sortie standard (output) de Xcode.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) La fonction **Trace** permet d'enregistrer les informations demandées uniquement dans le log de l'application (appelé "log ADB") en exécution ou en mode émulateur). Ces informations sont présentes au niveau "Info". 
			Ce log est consultable lorsque l'appareil est connecté en USB ou en cas d'utilisation de l'émulateur depuis l'application DDMS fournie avec le SDK Android.
			Pour plus de détails, consultez [Gestion des logs ADB](../Editeurs/9000108.md).

	- Il est possible d'afficher la fenêtre de trace en utilisant la fonction [TraceDébut](../WDLang1/3013052.md) avec la constante *trFenêtre*. 
			






<a name="NOTE0_2"></a>


### Fenêtre de trace
<a name="fenetre_trace_ELTPARAGRAPHE000157"></a>

- Les informations passées en paramètre sont affichées sur la ligne suivante de la fenêtre de trace.

- La fenêtre de trace est ouverte automatiquement dès le premier appel à la fonction **Trace** (la fonction [TraceDébut](../WDLang1/3013052.md) est exécutée automatiquement). Par défaut, cette fenêtre est ouverte en haut, à gauche de l'écran. Il est possible de la déplacer. La nouvelle position est automatiquement sauvegardée. 

- Le fonctionnement de la fonction **Trace** est similaire à celui de la fonction [Info](../WDLang1/3021011.md) mais l'affichage s'effectue dans une fenêtre parallèle, sans attente de touche.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) La fenêtre de trace affichée depuis un code navigateur est différente de celle affichée depuis un code serveur. Deux fenêtres de trace différentes peuvent donc être ouvertes en même temps.




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Spécificités sur mobile : 

- La fenêtre de trace est :

	- déplaçable au doigt par la barre de titre. 

	- redimensionnable au doigt. 




- Par défaut, la fenêtre de trace a une taille de 200x200 et est positionnée dans le coin bas droit de l'écran. 

- La fenêtre de trace peut être enroulée ou déroulée via un bouton. 

- La taille du texte peut être modifiée avec le doigt (pinch). 

- La fenêtre de trace ne peut pas sortir de l'écran. 

- La fenêtre de trace est toujours affichée par dessus toutes les fenêtres de l'application. 

- Elle peut être affichée dès le code d'initialisation du projet ou via un thread secondaire. 

- La fenêtre de trace ne peut pas être affichée depuis un widget ou un traitement en arrière-plan. 



<a name="NOTE0_3"></a>


### Menu contextuel de la fenêtre de trace
<a name="menu_contextuel_fenetre_trace_ELTPARAGRAPHE000201"></a>Le menu contextuel de la fenêtre de trace permet de :

- copier/couper/coller le contenu de la fenêtre de trace.

- enregistrer le contenu de la fenêtre de trace dans un fichier texte. 
	Attention : Cette option est disponible uniquement si la librairie wdxxxstd.dll est présente sur le poste de l'utilisateur final.

- vider le contenu de la fenêtre de trace.

- ouvrir la fenêtre de trace au-dessus de toutes les autres fenêtres (y compris les fenêtres des autres applications).

- mémoriser la taille et la position de la fenêtre de trace lors de sa fermeture. Lors du ré-affichage de cette fenêtre, la fenêtre s'affichera selon la taille et la position mémorisées.

- afficher un ascenseur horizontal.

- afficher les caractères de contrôle : Les caractères spéciaux seront affichés en gris et en littéral : EOT, TAB, etc. Ainsi, les caractères "Retour Chariot" (RC) présents dans la fenêtre de trace correspondent en littéral à "&lt;\\r&gt;&lt;\\n&gt;".
	Remarque : Cette option sera prise en compte uniquement à partir de la prochaine ligne d'informations affichée.




![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Spécificités sur mobile : 
Le menu contextuel propose les options suivantes : 

- Copier / tout copier le contenu de la fenêtre de trace. 

- vider le contenu de la fenêtre de trace.

- afficher ou masquer les caractères de contrôle.
