


## TableSelectMoins (Fonction)

***En anglais : TableSelectMinus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dé-sélectionne une ligne dans un champ Table ou Table hiérarchique. La ligne sélectionnée correspond à la ligne en cours sur laquelle le bandeau de sélection est affiché.

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Dé-sélectionne la ligne 5 dans le champ Table "TABLE_Produit"
TableSelectMoins(TABLE_Produit, 5)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`TableSelectMoins(<Champ Table> [, <Indice 1> [... [, <Indice N>]]])`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à : 

- un champ Table. 

- un champ Table hiérarchique. 


Si ce paramètre correspond à une chaîne vide (""), le champ manipulé est le champ auquel le traitement en cours appartient.

**`<Indice 1> : (Entier optionnel)`**

Indice de la première ligne à dé-sélectionner. Si ce paramètre n'est pas précisé, toutes les lignes du champ spécifié sont dé-sélectionnées. Si ce paramètre correspond à une ligne non sélectionnée, la fonction **TableSelectMoins** est sans effet. L'indice de la ligne sélectionnée peut être obtenu avec la fonction [TableSelect](../WDLang1/3074020.md).
Si ce paramètre correspond à -1, la fonction n'a aucun effet.

**`<Indice N> : (Entier optionnel)`**

Indice de la Nième ligne à dé-sélectionner. Si ce paramètre n'est pas précisé, toutes les lignes du champ Table spécifié sont dé-sélectionnées. Si ce paramètre correspond à une ligne non sélectionnée, la fonction **TableSelectMoins** est sans effet. L'indice de la ligne sélectionnée peut être obtenu avec la fonction [TableSelect](../WDLang1/3074020.md).

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000115"></a>La fonction **TableSelectMoins** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection. 
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode classique.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX", les champs Table en mode "Serveur" et les champs Table hiérarchique. ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur".![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le champ Table hiérarchique n'est pas disponible.
