


## &lt;Onglet&gt;.FermeTout (Fonction)

***En anglais : &lt;Tab&gt;.CloseAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme tous les volets dynamiques d'un champ Onglet.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ONG_OngletDyn.FermeTout()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Onglet>.FermeTout()`
---

**`<Champ Onglet> : (Nom de champ)`**

Nom du champ Onglet à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Toutes les fenêtres internes associées aux volets dynamiques sont déchargées et les volets dynamiques sont supprimés du champ Onglet spécifié.
