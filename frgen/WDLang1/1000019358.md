


## ToastAffiche (Fonction)

***En anglais : ToastDisplay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche un message de type "Toast".

Le toast est un message furtif qui apparaît durant quelques secondes à l'écran avant de disparaître avec un effet de fondu sans intervention de l'utilisateur. Un toast ne prend pas le focus, il n'est pas modal et il n'interrompt pas l'exécution de l'application.

L'affichage de toasts est recommandé pour transmettre des informations à l'utilisateur sans bloquer l'exécution de l'application (exemple : affichage d'un message pour indiquer la fin d'un téléchargement).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ToastAffiche.gif)
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Cette fonction est disponible uniquement pour les sites WEBDEV Linux.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
MonToast est un Toast
MonToast.Titre = "Le saviez-vous ?"
MonToast.Texte = "Les FAA sont un truc génial."
MonToast.Bouton[1].Libellé = "En savoir plus..."
MonToast.Bouton[1].ActionClic = FoncAide
MonToast.ActionFermeture = clicFerme
ToastAffiche(MonToast)
PROCÉDURE INTERNE FoncAide
	Ouvre("FEN_Aide")
FIN
PROCÉDURE INTERNE clicFerme(nBouton)
	Trace("Clic fermeture, bouton " + nBouton)
FIN
```

### Afficher un toast basé sur une variable de type Toast

`ToastAffiche(<Toast>)`
---

**`<Toast> : (Variable de type Toast)`**

Nom de la variable de type [Toast](../WDLang1/1000024638.md) décrivant le toast à afficher. 

Remarque : La variable de type [Toast](../WDLang1/1000024638.md) permet de définir de nombreux paramètres. 




<a name="SYNTAXE1"></a>

### Définir et afficher un toast

`ToastAffiche(<Message> [, <Durée d'affichage> [, <Cadrage Vertical> [, <Cadrage Horizontal> [, <Couleur de fond>]]]])`
---

**`<Message> : (Chaîne de caractères)`**

Message à afficher. Ce message peut être multiligne.

**`<Durée d'affichage> : (Entier optionnel)`**

Constante indiquant la durée d'affichage du message Toast : 


|   |   |
| --- | --- |
| *toastCourt*<br>(Valeur par défaut) | Le message Toast sera affiché pendant une faible période de temps. |
| *toastLong* | Le message Toast sera affiché pendant une longue période de temps. |


**Remarque** : La durée d'affichage exacte dépend de l'appareil utilisé.

**`<Cadrage Vertical> : (Entier optionnel)`**

Constante indiquant le cadrage vertical du message. Ce cadrage est relatif : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) à l'écran.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) à la fenêtre.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) à la page.





|   |   |
| --- | --- |
| *cvBas*<br>(Valeur par défaut) | Affichage du message Toast en bas. |
| *cvHaut* | Affichage du message Toast en haut. |
| *cvMilieu* | Affichage du message Toast au milieu. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) A partir de Android 11, le positionnement des toasts ne peut plus être personnalisé. Ce paramètre est ignoré. 

**`<Cadrage Horizontal> : (Entier optionnel)`**

Constante indiquant le cadrage horizontal du message. Ce cadrage est relatif : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) à l'écran.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) à la fenêtre.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) à la page.





|   |   |
| --- | --- |
| *chCentre*<br>(Valeur par défaut) | Affichage du message Toast au centre.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Le toast s'affiche toujours centré horizontalement. |
| *chDroite* | Affichage du message Toast sur la droite.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette constante n'est pas disponible. |
| *chGauche* | Affichage du message Toast sur la gauche.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Cette constante n'est pas disponible. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) A partir de Android 11, le positionnement des toasts ne peut plus être personnalisé. Ce paramètre est ignoré. 

**`<Couleur de fond> : (Entier optionnel)`**

Couleur de fond utilisée pour l'affichage du message. Ce paramètre peut correspondre à : 

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Ce paramètre n'est pas disponible.

## Remarques


### Gestion des threads
<a name="gestion_des_threads_ELTPARAGRAPHE000240"></a>

La fonction **ToastAffiche** peut être appelée depuis un thread WLangage (par exemple pour notifier l'utilisateur d'événements survenus durant l'exécution du thread).


### Appels successifs
<a name="appels_successifs_ELTPARAGRAPHE000249"></a>

Si la fonction **ToastAffiche** est appelée plusieurs fois, chaque toast est affiché lorsque le toast précédent a disparu. Ce comportement peut être modifié en utilisant la propriété **Superposable** de la variable de type [Toast](../WDLang1/1000024638.md). Cette propriété permet de retrouver le comportement de la version 24 :  les toasts se superposent les uns au-dessus des autres.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Si la fonction **ToastAffiche** est appelée plusieurs fois, seul le dernier appel à la fonction sera pris en compte.
