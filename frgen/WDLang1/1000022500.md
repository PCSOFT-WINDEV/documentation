


## &lt;Tableau de bord&gt;.Affiche (Fonction)

***En anglais : &lt;Dashboard&gt;.Display***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Rafraîchit l'affichage des éléments d'un champ Tableau de bord.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajout d'une commande et rafraîchissement du champ Tableau de bord.
HAjoute(Commande)
TDB_Principal.Affiche()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Rafraîchir l'affichage d'un Widget identifié par son nom

`<Champ Tableau de bord>.Affiche([<Widget>])`
---

**`<Champ Tableau de bord> : (Nom de champ)`**

Nom du champ Tableau de bord à manipuler.

**`<Widget> : (Nom de fenêtre interne ou nom de page interne optionnel)`**



- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Nom de la fenêtre interne à mettre à jour.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Nom de la page interne à mettre à jour.




Si ce paramètre n'est pas précisé, toutes les fenêtres internes/pages internes manipulées par le champ Tableau de bord seront mises à jour.


<a name="SYNTAXE2"></a>

### Rafraîchir l'affichage d'un Widget identifié par son indice

`<Champ Tableau de bord>.Affiche([<Indice>])`
---

**`<Champ Tableau de bord> : (Nom de champ)`**

Nom du champ Tableau de bord à manipuler.

**`<Indice> : (Entier optionnel)`**

Indice du Widget à mettre à jour.

Si ce paramètre n'est pas précisé, toutes les fenêtres internes/pages internes manipulées par le champ Tableau de bord seront mises à jour.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La fonction **&lt;Tableau de bord&gt;.Affiche** exécute l'événement "Rafraîchissement du Widget" pour le Widget spécifié ou pour tous les Widgets affichés dans le champ Tableau de bord. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) L'événement "Rafraîchissement du Widget" est un événement optionnel des fenêtres internes utilisées en tant que Widget dans un champ Tableau de bord.

- L'événement "Rafraîchissement du Widget" peut ne pas être exécuté immédiatement : il est exécuté uniquement lorsque la main est rendue à l'utilisateur (fin du code en cours d'exécution ou appel de la fonction [Multitâche](../WDLang1/3015004.md) par exemple). 

- Si plusieurs appels à la fonction **&lt;Tableau de bord&gt;.Affiche** sont effectués avant que la main ne soit rendue, les événements de rafraîchissement ne seront exécutés qu'une seule fois.
