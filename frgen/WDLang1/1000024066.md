
## Saisie assistée dans un champ de saisie (syntaxe préfixée)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000101"></a>
Le principe de la saisie assistée dans un champ de saisie est très simple: quand l'utilisateur commence à saisir dans un champ de saisie, une liste se déroule automatiquement sous le champ pour proposer les valeurs commençant par le texte de la saisie en cours. 

La saisie assistée peut être mise en place automatiquement depuis l'éditeur ou personnalisée par programmation. 



<a name="NOTE2_Fenêtre"></a>
<a name="NOTE2_Fenêtre_1"></a>


## Principe
<a name="principe_ELTTEXTE000145"></a>
WINDEV, WINDEV Mobile et WEBDEV proposent plusieurs types de saisie assistée: 

- Saisie assistée "en mémoire": Le champ de saisie n'est pas lié à une rubrique d'une table. La saisie automatique se fait à partir d'une liste de données fournie par programmation (fonction [&lt;Saisie&gt;.AjouteSaisieAssistée](../WDLang1/1000023671.md)). L'affichage des données dans la liste est effectué selon la saisie.  

- Saisie assistée "fichier": Le champ de saisie est lié à une rubrique d'une table ou d'une requête. L'affichage des données dans la liste est effectué selon la saisie.

- Saisie assistée programmée: La saisie assistée est effectuée à partir d'une liste de données personnalisée. L'affichage des données dans la liste selon la saisie est personnalisée.

## Saisie assistée "en mémoire"
<a name="saisie_assistee_memoire_ELTTEXTE000184"></a>


### Comment le faire?
<a name="comment_faire_ELTPARAGRAPHE000207"></a>

Pour mettre en place la saisie assistée "en mémoire": 

1. Utilisez la fonction [&lt;Saisie&gt;.AjouteSaisieAssistée](../WDLang1/1000023671.md) pour ajouter les éléments pris en compte par la saisie assistée. 
	Il est possible d'ajouter: 

	- une valeur simple, affichée dans la liste des propositions de la saisie assistée, 

	- une valeur affichée et une valeur mémorisée.

	- une variable de type [SaisieAssistée](../WDLang1/1410088983.md).




2. Si nécessaire, utilisez la fonction [&lt;Saisie&gt;.ParamètreSaisieAssistée](../WDLang1/1000024064.md) pour paramétrer les caractéristiques de la saisie assistée: filtre, ouverture de la liste des propositions, nombre de caractères à saisir avant d'ouvrir la liste des propositions, etc.




**Remarque**: La valeur mémorisée permet d'associer une valeur spécifique à une ligne de la saisie assistée. Cette valeur peut être utilisée par exemple pour réaliser un traitement spécifique selon le type de valeur sélectionnée.


### Exemples
<a name="exemples_ELTPARAGRAPHE000247"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Exemple pour une fenêtre**: 
	
	```wl
	// Code de fin d'initialisation de la fenêtre
	SAI_Rechercher.ParamètreSaisieAssistée(saTailleMin, 3)
	SAI_Rechercher.ParamètreSaisieAssistée(saFiltre, filtreContient)
	
	POUR TOUTE CHAÎNE sTitre DE gsTitresPhotos SEPAREE PAR RC
		SAI_Rechercher.AjouteSaisieAssistée(sTitre)
	FIN
	```


- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) **Exemple pour une page**: 
	
	```wl
	// Code de chargement de la page
	SAI_Rechercher.ParamètreSaisieAssistée(saTailleMin, 3)
	SAI_Rechercher.ParamètreSaisieAssistée(saFiltre, filtreContient)
	
	POUR TOUTE CHAÎNE sTitre DE gsTitresPhotos SEPAREE PAR RC
		SAI_Rechercher.AjouteSaisieAssistée(sTitre)
	FIN
	```






### Remarques
<a name="remarques_ELTPARAGRAPHE000278"></a>

- L'événement optionnel "Sélection d'une valeur dans la liste de saisie assistée" est exécuté lors de la sélection d'un élément. Cet événement prend en paramètre une variable de type [SaisieAssistée](../WDLang1/1410088983.md). Cette variable permet de connaître la valeur sélectionnée et la valeur mémorisée associée si elle existe.

- Par défaut, la valeur affichée dans le champ de saisie lors de la sélection dans la saisie assistée, correspond à la valeur sélectionnée. Pour modifier la valeur du champ de saisie, utilisez l'événement "Sélection d'une valeur dans la liste de saisie assistée". Il est par exemple possible d'afficher la valeur mémorisée dans le champ de saisie. 


Pour plus de détails, consultez [Evénements associés aux champs de saisie](../WDChamp/1013229.md).

## Saisie assistée "Fichier"
<a name="saisie_assistee_fichier_ELTTEXTE000292"></a>


### Comment le faire?
<a name="comment_faire_ELTPARAGRAPHE000315"></a>

Pour mettre en place la saisie assistée "Fichier": 

1. Dans la fenêtre de description du champ de saisie: 

	- Vérifiez que le champ de saisie est lié à une rubrique d'une table ou d'une requête (onglet "Liaison"). 
			Attention: La rubrique doit être une clé. 

	- Dans l'onglet "Détail", cochez l'option "Saisie assistée sur liaison fichier". 




2. Validez la fenêtre de description du champ de saisie. 




En exécution, dès la première lettre saisie dans le champ: 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une liste s'affiche avec les différentes données correspondant à la lettre saisie. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Saisie_Ass_Fic_WB.gif)


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) la première donnée correspondant à la lettre saisie s'affiche. Au fur et à mesure de la saisie, la donnée correspondant aux lettres saisies s'affiche. 




Remarques: 

- Si le champ de saisie est lié à une rubrique d'une requête, la requête est automatiquement exécutée. Cependant, si cette requête attend des paramètres, il est nécessaire de les renseigner puis d'exécuter la requête avec la fonction [&lt;Source&gt;.ExécuteRequête](../WDLang4/1000024944.md) (par exemple dans l'événement "Déclarations globales" ou l'événement "Fin d'initialisation" de la fenêtre).  

- Le filtre d'affichage de la saisie assistée est de type "Commence par". Pour utiliser un autre filtre, il est nécessaire d'utiliser la saisie assistée programmée.

## Saisie assistée "programmée"
<a name="saisie_assistee_programmee_ELTTEXTE000352"></a>


### Comment le faire? 
<a name="comment_faire_ELTPARAGRAPHE000375"></a>

La saisie assistée programmée permet de manipuler une source de données personnalisée. 

Pour utiliser la saisie assistée programmée: 

1. Désactivez le filtre par défaut grâce à la fonction [&lt;Saisie&gt;.ParamètreSaisieAssistée](../WDLang1/1000024064.md) (en utilisant la constante *filtreAucun*). La liste de la saisie assistée pourra ainsi s'ouvrir et afficher tous les éléments spécifiés.  

2. Dans l'événement "A chaque modification" du champ de saisie: 

	- Videz la liste des propositions (fonction [&lt;Saisie&gt;.SupprimeToutSaisieAssistée](../WDLang1/1000024065.md)). 

	- Reconstruisez la liste des éléments proposés en fonction des caractères saisis (fonction [&lt;Saisie&gt;.AjouteSaisieAssistée](../WDLang1/1000023671.md)).

	- Utilisez la fonction [&lt;Saisie&gt;.OuvreSaisieAssistée](../WDLang1/1000024063.md) pour ouvrir la liste des éléments proposés par la saisie assistée.








### Exemple
<a name="exemple_ELTPARAGRAPHE000414"></a>


```wl
// Recherche de type "contient" dans le nom 
// et le code d'un tableau d'actions boursières
POUR TOUT sNom, sCode de gTabAction
	SI Contient(sCode, sValeurRecherchée) _OU_ ...
		Contient(sNom, sValeurRecherchée) ALORS
		SAI_Mode_programmé.AjouteSaisieAssistée(sNom)
	FIN
FIN
```
