


## TableIndiceColonne (Fonction)

***En anglais : TableColumnIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'indice d'une colonne dans un champ Table ou Table hiérarchique.

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Indice de la colonne "Réf" du champ Table "TABLE_Produit"
// L'ordre d'affichage est pris en compte
ResIndiceColonne = TableIndiceColonne(TABLE_Produit, "Réf", ticAffichage)
```


<a name="Exemple2"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Indice de la colonne "Réf" du champ Table "TABLE_Produit"

```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = TableIndiceColonne(<Champ Table> , <Colonne> , <Ordre>)`
---

**`<Résultat> : (Entier)`**

Indice de la colonne : 

- La première colonne possède l'indice 1. 

- Les colonnes invisibles sont également listées.




**`<Champ Table> : (Nom de champ)`**

Nom du champ Table ou Table hiérarchique à manipuler.

Si ce paramètre correspond à une chaîne vide (""), la fonction **TableIndiceColonne** manipule le champ auquel appartient l'événement en cours.

**`<Colonne> : (Chaîne de caractères)`**

Nom de la colonne à manipuler.

**`<Ordre> : (Constante de type Entier)`**

Indique l'ordre des colonnes considérées :


|   |   |
| --- | --- |
| *ticAffichage* | Ordre d'affichage des colonnes en exécution. |
| *ticCréation* | Ordre de création des colonnes lors de la description du champ Table. |


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre est optionnel. Par défaut, la constante utilisée par défaut est *ticCréation* : l'ordre de création des colonnes est pris en compte.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000134"></a>La fonction **TableIndiceColonne** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection.
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode "Serveur".

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) un champ Table en mode "Serveur + AJAX", un champ Table en mode "Serveur" et un champ Table hiérarchique. 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) un champ Table en mode "Navigateur".
	![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le champ Table hiérarchique n'est pas disponible.
