


## MultimédiaHauteur (Fonction)

***En anglais : MultimediaHeight***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la hauteur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. Cette fonction est utilisable par exemple pour les fichiers vidéo.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Remarque** : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = MultimédiaHauteur(<Champ Multimédia>)`
---

**`<Résultat> : (Entier)`**



- Hauteur en pixels de l'image du fichier multimédia, 

- 0 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Remarque : La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La fonction **MultimédiaHauteur** permet de connaître la hauteur d'un fichier multimédia. 

- La fonction [MultimédiaLargeur](../WDLang1/1000017213.md) permet de connaître la largeur d'un fichier multimédia.
