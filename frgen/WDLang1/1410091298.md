
## OptionsOuvertureFenêtre (Type de variable)

***En anglais : WindowOpeningOptions***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **OptionsOuvertureFenêtre** permet de définir toutes les caractéristiques de l'ouverture d'une fenêtre. Ces caractéristiques d'ouverture peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
affiche_fiche_client est une Fenêtre FEN_Fiche_Client
affiche_fiche_client..OptionsOuverture..X = 100
affiche_fiche_client..OptionsOuverture..Y = 100
Ouvre(affiche_fiche_client)
```

fenêtre fusionnent en s'interpénétrant.<br><br>	- *afFontaine* : La fenêtre apparaît par morceaux, comme issue d'une fontaine.<br><br>	- *afLivre* : Le plan de la fenêtre est projeté sur un livre qui sphère qui se transforme peu à peu en un plan.<br><br>	- *afMorphVague* : Le plan de la fenêtre est projeté sur des vagues qui s'atténuent.<br><br><br><br><br>- Rotation :<br><br>	- *afRotationMulti*
