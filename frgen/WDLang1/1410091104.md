


## InfoImage (Fonction)

***En anglais : ImageInfo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère les caractéristiques d'un fichier image ou d'un fichier PDF :

- format.

- largeur et hauteur.

- nombre de bits par pixel.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) zone de transparence.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) couche alpha.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Les fichiers PDF ne sont pas gérés.  



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). Remarque : Cette fonction est identique à la fonction [InfoBitmap](../WDLang1/3029015.md), conservée par compatibilité.

## Exemple


```wl
bAvecTransparence est booléen = InfoImage("monImage.png", ibCouleurDeTransparence)
```

```wl
bAvecOpacité est booléen = InfoImage("monImage.png", ibAvecCoucheAlpha)
```

```wl
// Liste des pages séparées par RC. 
// Info d'une page : largeur + TAB + hauteur + TAB + bits par pixel
sListePage est chaîne = InfoImage("doc.pdf", ibListeInfoPages)
POUR TOUTE CHAÎNE sInfoPage DE sListePage SÉPARÉE PAR RC
	Trace(sInfoPage)
FIN
```

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = InfoImage(<Nom du fichier image> [, <Information recherchée>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Caractéristique demandée (si le paramètre &lt;Information recherchée&gt; est spécifié). 

- Caractéristiques complètes de l'image renvoyées sous la forme :
	
	```txt
	<Format> + TAB + <Largeur> + TAB + <Hauteur> + TAB + <Bits/pixel>
	```

	


|   |   |   |
| --- | --- | --- |
| &lt;Format&gt; | Chaîne de caractères | <br><br>	- Trois caractères permettant d'identifier le format de l'image : "BMP", "GIF", "PDF", ...<br><br>	- "BAD" si le nom de l'image est un fichier inexistant ou si le format est inconnu<br><br><br> |
| &lt;Largeur&gt; | Entier | Largeur de l'image en pixels.<br>Remarque : La largeur et la hauteur peuvent être inversées en fonction de la position du point (0,0) de l'image. Pour connaître la largeur et la hauteur en prenant en compte l'orientation de l'image, utilisez une variable de type  [Image](../WDLang1/1000019650.md). |
| &lt;Hauteur&gt; | Entier | Hauteur de l'image en pixels.<br>Remarque : La largeur et la hauteur peuvent être inversées en fonction de la position du point (0,0) de l'image. Pour connaître la largeur et la hauteur en prenant en compte l'orientation de l'image, utilisez une variable de type  [Image](../WDLang1/1000019650.md). |
| &lt;Bits/pixel&gt; | Chaîne de caractères | Nombre de bits par pixel :<br><br>	- 1 (Image monochrome)<br><br>	- 4 (palette 16 couleurs)<br><br>	- 8 (palette 256 couleurs)<br><br>	- 24 (pas de palette, 16 millions de couleurs)<br><br>	- 32 (pas de palette, couleur vrai)<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Le nombre de bits par pixels est toujours 0.<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Le nombre de bits par pixels est toujours 32. |



- En cas d'erreur, la chaîne renvoyée est : 
	```txt
	"BAD" + TAB + TAB + TAB
	```





**`<Nom du fichier image> : (Chaîne de caractères)`**



- Nom du fichier image ou du fichier PDF avec son chemin complet ou relatif (260 caractères maximum). Un chemin de type UNC peut être utilisé.

- Nom du champ lié à une rubrique de type mémo image.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Les fichiers PDF ne sont pas gérés.  

**`<Information recherchée> : (Constante optionnelle de type Entier)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Information recherchée.



|   |   |
| --- | --- |
| *ibAvecCoucheAlpha* | Permet de savoir si l'image possède une couche alpha. Si cette constante est utilisée, &lt;Résultat&gt; correspondra à : <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image possède une couche alpha, <br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |
| *ibCouleurDeTransparence* | Permet de savoir si l'image possède une zone transparente. Si cette constante est utilisée, &lt;Résultat&gt; correspondra à : <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image possède une zone transparente, <br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |
| *ibListeInfoPages*<br>(Valeur par défaut) | Permet de connaître les informations de chaque page d'une image multipage. Les différentes informations concernant chaque page sont séparées par le caractère Retour-Chariot (RC).<br><br>Les informations sont renvoyées selon le format suivant : <br><br><pre><code>Largeur + TAB + Hauteur + TAB + Bits par pixel</code></pre><br> où : <br><br>- Largeur : Largeur en pixels. <br><br>- Hauteur : Hauteur en pixels. <br><br>- Bits par pixel : Nombre de bits par pixel :<br><br>	- 1 (Image monochrome)<br><br>	- 4 (palette 16 couleurs)<br><br>	- 8 (palette 256 couleurs)<br><br>	- 24 (pas de palette, 16 millions de couleurs)<br><br>	- 32 (pas de palette, couleur vrai)<br><br><br><br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Le nombre de bits par pixels est toujours 0.![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Le nombre de bits par pixels est toujours 32. |

## Remarques


### Divers
<a name="divers_ELTPARAGRAPHE000201"></a>

- La fonction **InfoImage** peut être utilisée avec les fichiers au format PDF. 
	Attention : [le Framework GDI +](../Editeurs/2020007.md) doit être installé sur le poste.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonctionnalité n'est pas disponible. 

- Pour les images au format WMF ou EMF, &lt;Bits/pixel&gt; est égal à 0.

- Les formats des fichiers image reconnus sont :

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png) Tous les formats décrits dans la fonction [fFiltreImage](../WDLang1/3036009.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JPEG, PNG, GIF ou BMP.

	- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) JPG, PNG, GIF, BMP. Selon la version de la librairie GD, ces formats peuvent ne pas être gérés.

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000364"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".
