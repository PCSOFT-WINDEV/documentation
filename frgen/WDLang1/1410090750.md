


## &lt;Variable Commande&gt;.EcritEntréeStandard (Fonction)

***En anglais : &lt;Command variable&gt;.WriteStandardInput***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ecrit les données sur l'entrée standard de la commande exécutée en mode console.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")

// Exécution de la commande 
MaCommandeAExécuter.Exécute(Faux)
// Écriture dans l'entrée standard (possible car le flux est actif)
MaCommandeAExécuter.EcritEntréeStandard("Test Ecriture" + RC)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Commande>.EcritEntréeStandard(<Données>)`
---

**`<Commande> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande à manipuler.

**`<Données> : (Chaîne de caractères)`**

Données à envoyer à la commande. 

Attention : Le flux d'entrée de commande doit être activé dans la variable de type [Commande](../WDLang1/1410090491.md)  (propriété **Flux**).
