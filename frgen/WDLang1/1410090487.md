


## &lt;Buffer&gt;.UTF8Valide (Fonction)

***En anglais : &lt;Buffer&gt;.UTF8Valid***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Teste la validité d'un buffer au format UTF8.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
bufUTF8 est un buffer
// Test : Buffer UTF8 valide ?
SI bufUTF8.UTF8Valide() ALORS
	// Oui => conversion en UNICODE
	sUNICODE est une chaîne Unicode = bufUTF8.UTF8VersChaîne()
	...
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Buffer à vérifier>.UTF8Valide()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la chaîne correspond à un format UTF8 valide,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Buffer à vérifier> : (Buffer)`**

Buffer contenant les données au format UTF8.
