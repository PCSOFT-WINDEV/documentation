


## &lt;CodeWLangageMiseEnForme&gt;.MetEnForme (Fonction)

***En anglais : &lt;WLanguageCodeFormatting&gt;.Format***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Met en forme un code WLangage : coloration, réécriture normalisée, indentation, traduction, etc.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Chaîne à mettre en forme
sCode est une chaîne ANSI = "
MiseEnFormeCode est un CodeWLangageMiseEnForme
MiseEnFormeCode.Langue = langueFrançais
MiseEnFormeCode.Indentation = Vrai
MiseEnFormeCode.InclureDéclarationsCSS = Vrai
MiseEnFormeCode.IgnoreErreurCompilation = Vrai
MiseEnFormeCode.CasseMotsClés = codeWLangageMotsClésMinuscule
MiseEnFormeCode.Thème = codeWLangageThèmeSombre
MiseEnFormeCode.Format = codeWLangageFormatHTML
bufResHTML est un Buffer = MiseEnFormeCode.MetEnForme(sCode)
"
MiseEnFormeCode est un CodeWLangageMiseEnForme
MiseEnFormeCode.Langue = langueFrançais
MiseEnFormeCode.Indentation = Vrai
MiseEnFormeCode.InclureDéclarationsCSS = Vrai
MiseEnFormeCode.IgnoreErreurCompilation = Vrai
MiseEnFormeCode.CasseMotsClés = codeWLangageMotsClésMinuscule
MiseEnFormeCode.Thème = codeWLangageThèmeSombre
MiseEnFormeCode.Format = codeWLangageFormatHTML
bufResHTML est un Buffer = MiseEnFormeCode.MetEnForme(sCode)

// Affichage dans un champ d'affichage HTML
HTM_SansNom1 = bufResHTML.UTF8VersChaîne()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Paramètres à utiliser>.MetEnForme(<Code à mettre en forme>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Code WLangage mis en forme.

**`<Paramètres à utiliser> : (Variable de type CodeWLangageMiseEnForme)`**

Nom de la variable de type [CodeWLangageMiseEnForme](../WDLang1/1410090146.md), contenant les paramètres de mise en forme du code.

**`<Code à mettre en forme> : (Chaîne de caractères)`**

Code à mettre en forme.
