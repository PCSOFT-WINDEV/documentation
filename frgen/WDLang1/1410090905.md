


## &lt;Bouton segmenté&gt;.Supprime (Fonction)

***En anglais : &lt;Segmented button&gt;.Delete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une option dans un champ Bouton segmenté.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
POUR i = 4 A 1 PAS -1  
	SI BS_Niveau[i].Libellé = "Avancé" ALORS
		BS_Niveau.Supprime(i)
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Bouton segmenté>.Supprime(<Indice de l'option>)`
---

**`<Champ Bouton segmenté> : (Nom de champ)`**

Nom du champ Bouton segmenté manipulé.

**`<Indice de l'option> : (Entier)`**

Indice de l'option à supprimer. Cet indice doit être compris entre 1 et le nombre d'options contenues dans le champ Bouton Segmenté. La propriété [Occurrence](../Proprietes/2510097.md) permet de connaître le nombre d'options d'un champ Bouton segmenté.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Lors de la suppression d'options dans un champ Bouton segmenté, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](../Proprietes/2510059.md) et [Hauteur](../Proprietes/2510050.md).

- Lors de la suppression d'une option, les indices des options suivant l'option supprimée sont automatiquement renumérotés.
