


## TableSaisieEnCours (Fonction)

***En anglais : TableInputInProgress***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique si un champ Table ou Table hiérarchique est en cours de saisie.

**Remarque** : Si l'utilisateur utilise le mode Recherche dans l'entête de colonne (loupe), le champ Table ou Table hiérarchique est considéré en cours de saisie.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Si l'utilisateur n'est pas en train de saisir dans le champ
SI TableSaisieEnCours(TABLE_TABLE1) = Faux ALORS
	// Met à jour le champ Table
	TableAffiche(TABLE_TABLE1)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = TableSaisieEnCours(<Champ Table>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le champ est en cours de saisie (c'est-à-dire si l'utilisateur est en train de saisir des informations dans le champ), 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à : 

- un champ Table. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Table hiérarchique. 
	![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Les champs Table hiérarchique ne sont pas disponibles.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000097"></a>Cette fonction est disponible sur : 

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation. 


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX" et les champs Table hiérarchique. ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur". ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le champ Table hiérarchique n'est pas disponible.
