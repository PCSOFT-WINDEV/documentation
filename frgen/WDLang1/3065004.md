


## Fonctions de gestion de la base de registre
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion de la base de registre Windows sont les suivantes :



|   |   |
| --- | --- |
| [RegistreCherche](../WDLang1/3065005.md) | Recherche une chaîne de caractères dans la base de registre. |
| [RegistreCléSuivante](../WDLang1/3065009.md) | Identifie la clé suivant la clé spécifiée dans la base de registre de Windows. |
| [RegistreCopieClé](../WDLang1/1000019418.md) | Copie une clé de registre avec toutes ses sous-clés et ses valeurs. |
| [RegistreCréeClé](../WDLang1/3065002.md) | Crée une clé dans la base de registre de Windows. |
| [RegistreEcrit](../WDLang1/3065006.md) | Écrit une valeur dans un registre de la base de registre de Windows. |
| [RegistreExiste](../WDLang1/3065007.md) | Teste l'existence d'une clé de la base de registre de Windows. |
| [RegistreListeClé](../WDLang1/1000019881.md) | Liste les sous-clés d'une clé de la base de registre. |
| [RegistreListeValeur](../WDLang1/3065013.md) | Renvoie le nom et éventuellement le type des valeurs d'une clé de la base de registre. |
| [RegistreLit](../WDLang1/3065012.md) | Lit la valeur d'un registre dans la base de registre de Windows. |
| [RegistrePremièreSousClé](../WDLang1/3065008.md) | Identifie le chemin de la première sous-clé de la clé spécifiée dans la base de registre de Windows. |
| [RegistreRenomme](../WDLang1/1000019419.md) | Renomme une clé de la base de registre. |
| [RegistreSupprimeClé](../WDLang1/3065010.md) | Supprime une sous-clé dans la base de registre de Windows. |
| [RegistreSupprimeValeur](../WDLang1/3065011.md) | Supprime une valeur dans la base de registre de Windows. |
| [RegistreTypeValeur](../WDLang1/1000017280.md) | Renvoie le type d'une valeur présente dans la base de registre. |
