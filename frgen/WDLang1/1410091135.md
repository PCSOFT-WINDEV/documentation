
## CertificatSignePackageMSIX (Fonction)

***En anglais : CertificateSignMSIXPackage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Signe un package MSIX avec un certificat. 

Remarque : Cette fonction est d'un usage avancé. La signature du package MSIX est automatiquement réalisée lors de la création d'une installation MSIX. Pour plus de détails, consultez [Installation MSIX](../Editeurs/9000229.md). 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Charge un certificat
certificat_signature est un Certificat
tabCertificat est un tableau de Certificat
tabCertificat = CertificatCharge(nom_fichier_signature, "")
certificat_signature = tabCertificat[1]
// Signe le package
SI certificat_signature.ValidePourSignature ALORS
	CertificatSignePackageMSIX(nom_fichier_package_msix, certificat_signature)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CertificatSignePackageMSIX(<Package MSIX> , <Certificat>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le package a été signé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Package MSIX> : (Chaîne de caractères)`**

Nom du fichier correspondant au package MSIX à signer. 

**`<Certificat> : (Variable de type Certificat)`**

Nom de la variable de type [Certificat](../Proprietes/1000021684.md) correspondant au certificat à utiliser pour signer le package MSIX.
