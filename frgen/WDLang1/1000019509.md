
## fExtraitRessource (Fonction)

***En anglais : fExtractResource***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extrait une ressource de l'application dans un emplacement physique de l'appareil.

**Remarques**: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) La ressource à extraire doit avoir été incluse dans l'application générée via l'assistant de génération (voir Remarques). 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Dans les applications WINDEV ou dans les sites WEBDEV, la ressource à extraire doit être présente à la fois: 

	- dans la catégorie "Autres" du volet [Explorateur de projet](../Editeurs/2027029.md), 

	- dans la bibliothèque principale de l'application (fichier WDL). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette fonction est utilisable dans le simulateur Android. 




Attention: Pour empêcher le piratage des sources, les éléments WINDEV, WEBDEV et WINDEV Mobile (états, fenêtre, etc.) ne peuvent pas être extraits en exécution.

## Exemple

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Lit le contenu du fichier texte readme.txt inclus dans les ressources de l'application
SI fExtraitRessource("readme.txt", "/sdcard/extraction.txt") = Vrai ALORS
	SAI_Texte = fChargeTexte("/sdcard/extraction.txt") 
FIN
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Permet de localiser précisément ses données HFSQL sur le Smartphone Android
sCheminDonnées est une chaîne = SysRepCarteStockage() + fSep() + "Test clients"  + fSep()
SI PAS fRépertoireExiste(sCheminDonnées) ALORS fRepCrée(sCheminDonnées)
fExtraitRessource("Produit.fic", sCheminDonnées + "Produit.fic")
fExtraitRessource("Produit.ndx", sCheminDonnées + "Produit.ndx")
fExtraitRessource("Produit.mmo", sCheminDonnées + "Produit.mmo")
SI PAS HChangeRep(Produit, sCheminDonnées) ALORS
	Erreur(HErreurInfo())
FIN
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Extrait toutes les images au format PNG
fExtraitRessource("*.png", ComplèteRep(SysRepCarteStockage()) + "images")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = fExtraitRessource(<Nom de la ressource> [, <Destination>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la ressource a été extraite, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Nom de la ressource> : (Chaîne de caractères)`**

Nom de la ressource à extraire (nom du fichier avec son extension).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Les caractères joker (\* et?) sont autorisés. Il est ainsi possible d'extraire plusieurs ressources en un seul appel. Dans ce cas, le paramètre &lt;Destination&gt; doit correspondre à un répertoire (existant ou non).

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) La ressource à extraire doit être présente dans la bibliothèque principale de l'application (fichier WDL). La bibliothèque ne soit pas avoir été chargée avec la fonction [ChargeWDL](../WDLang1/3013020.md).

**`<Destination> : (Chaîne de caractères optionnelle)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Chemin (complet ou relatif) du fichier de destination. Ce chemin peut être relatif au répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)). Ce paramètre est sensible à la casse. 
Si le répertoire existe, la ressource est directement extraite dans ce répertoire.
Si le répertoire n'existe pas, il est créé. 
Si ce paramètre n'est pas spécifié ou vaut chaîne vide (""), la ressource sera extraite dans le répertoire courant de l'application dans un fichier portant le même nom que la ressource.
Si le fichier destination existe déjà avant l'extraction, il sera écrasé.
**Rappel**: Sous Android, sur l'appareil comme sur l'émulateur, le système de fichiers est en lecture seule. Une application a uniquement le droit d'écrire dans son répertoire d'installation ou dans un de ses sous-répertoires, ainsi que sur la mémoire externe (SDCard).

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Chemin complet du fichier destination. Ce paramètre est sensible à la casse. 
Si le répertoire existe, la ressource est directement extraite dans ce répertoire.
Si le répertoire n'existe pas, il est créé.
Si ce paramètre n'est pas spécifié ou vaut chaîne vide (""), la ressource sera extraite dans le répertoire "Documents" de l'application dans un fichier portant le même nom que la ressource.
Si le fichier destination existe déjà avant l'extraction, il sera écrasé.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Chemin complet du fichier de destination. 
Si le répertoire existe, la ressource est directement extraite dans ce répertoire.
Si le répertoire n'existe pas, il est créé. 
Si ce paramètre n'est pas spécifié ou vaut chaîne vide (""), la ressource sera extraite dans le répertoire des données de l'application (connu avec la fonction [fRepDonnées](../WDLang1/3036001.md)) dans un fichier portant le même nom que la ressource.
Si le fichier destination existe déjà avant l'extraction, il sera écrasé.

### Assistant de génération
<a name="assistant_generation_ELTPARAGRAPHE000174"></a>

L'assistant de génération d'applications Android ou iPhone/iPad permet d'indiquer si des fichiers et des librairies doivent être intégrés à l'application. 

Dans une application Android, il est par exemple possible d'intégrer: 

- des ressources spécifiques. 

- des archives Java spécifiques. 




Ces fichiers pourront ensuite: 

- soit être utilisés directement (fichiers à lire par exemple: fichiers son, image, ...). 

- soit être extraits grâce à la fonction **fExtraitRessource** (fichiers à modifier par l'application par exemple).




Si une image est intégrée à l'application, elle pourra être affectée directement à un champ en indiquant uniquement son nom. Par exemple: 


```wl
IMG_Image = image1
```

### Cas particulier: Extraction d'une base de données
<a name="cas_particulier_extraction_une_base_donnees_ELTPARAGRAPHE000223"></a>

Si le fichier à extraire est une base de données SQLite, pour l'extraire dans le répertoire des données de l'application (répertoire "databases"), utilisez la fonction [fRepDonnées](../WDLang1/3036001.md). 

Exemple: 


```txt
fExtraitRessource(<Nom de la base>.db, ComplèteRep(fRepDonnées()) + <Nom de la base>.db)
```


Pour se connecter à cette base de données, il suffit de spécifier &lt;Nom de la base&gt;.db comme source de la connexion SQLite. Pour plus de détails, consultez [Application Android: Utilisation d'une base de données](../Editeurs/9000123.md). 
<a name="NOTE0_3"></a>


### Cas particulier: fichier ".WDD" (description du schéma des données)
<a name="cas_particulier_fichier_wdd_description_schema_des_donnees_ELTPARAGRAPHE000243"></a>

La description du schéma des données (fichier ".WDD") intégré à la bibliothèque d'une application ne peut pas être extrait. 

Pour extraire une table d'une bibliothèque qui ne peut pas être extrait par la fonction **fExtraitRessource**, il est possible d'utiliser une table HFSQL intégrée à la bibliothèque. 
Pour plus de détails sur cette technique, consultez le billet suivant du blog du Support Technique: 
[Comment extraire un fichier d'un exécutable WINDEV?](https://blogs.pcsoft.fr/fr/extraire-fichier-executable-windev/107/read.awp).
