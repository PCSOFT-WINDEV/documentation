
## Fonctions de gestion de la saisie assistée (syntaxe préfixée)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


Les fonctions suivantes permettent de programmer la saisie assistée (syntaxe préfixée) dans les champs de saisie :



|   |   |
| --- | --- |
| [&lt;Saisie&gt;.AjouteSaisieAssistée](../WDLang1/1000023671.md) | Ajoute une ligne dans la liste des valeurs disponibles pour la saisie assistée d'un champ de saisie. |
| [&lt;Saisie&gt;.FermeSaisieAssistée](../WDLang1/1000023946.md) | Ferme la liste des valeurs proposées par la saisie assistée d'un champ de saisie. |
| [&lt;Saisie&gt;.OuvreSaisieAssistée](../WDLang1/1000024063.md) | Ouvre la liste des valeurs proposées pour la saisie assistée d'un champ de saisie. |
| [&lt;Saisie&gt;.ParamètreSaisieAssistée](../WDLang1/1000024064.md) | Permet de paramétrer le filtre et l'ouverture de la saisie assistée. |
| [&lt;Saisie&gt;.SupprimeToutSaisieAssistée](../WDLang1/1000024065.md) | Vide la liste des valeurs proposées pour la saisie assistée d'un champ de saisie. |
