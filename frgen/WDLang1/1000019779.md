
## dbgVérifieNonNull (Fonction)

***En anglais : dbgCheckNotNull***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie si l'expression n'est pas Null en programmation défensive et en mode test automatique. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
TableauElément est un tableau de MaClasse dynamique
// Remplissage du tableau
...
// Parcours des éléments du tableau
POUR i = 1 _A_ TableauElément.Occurrence
	// L'élément devrait avoir été alloué
	dbgVérifieNonNull(TableauElément[i], "L'objet n°%1 n'a pas été alloué", i)
	// Traitement de l'élément
	...
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`dbgVérifieNonNull(<Expression> [, <Commentaires> [, <Paramètre 1> [... [, <Paramètre N>]]]])`
---

**`<Expression> : (Chaîne de caractères)`**

Expression quelconque à vérifier. 

**`<Commentaires> : (Chaîne de caractères)`**

Chaîne de caractères au format défini par la fonction [ChaîneConstruit](../WDLang1/3024006.md). 

**`<Paramètre 1> : (Tout type)`**

Premier paramètre attendu par le paramètre &lt;Commentaires&gt;.



**`<Paramètre N> : (Tout type)`**

Dernier paramètre attendu par le paramètre &lt;Commentaires&gt;.

<a name="NOTE0_1"></a>

## Remarques


### Fonctionnement
<a name="fonctionnement_ELTPARAGRAPHE000069"></a>Lorsque l'expression est Null :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) **en mode test automatique**, une erreur est ajoutée dans le compte-rendu du test (équivalent de la fonction [TestEcritRésultat](../WDLang1/1000013001.md)).

- **en mode test manuel**, une assertion est affichée (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).

- **en mode exécution**, une assertion est affichée si les assertions ont été activées (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).




En exécution d'une application, si les assertions ne sont pas activées, l'expression n'est pas évaluée.

La fonction [dbgSurErreur](../WDLang1/1000020722.md) permet de lancer automatiquement une procédure WLangage permettant de récupérer le commentaire lié à l'erreur. 


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Gestion des assertions
<a name="gestion_des_assertions_ELTPARAGRAPHE000103"></a>Les messages de la fonction **dbgVérifieNonNull** seront écrits dans le log ADB (au niveau "Assert"). Pour plus de détails, consultez [Gestion des logs ADB](../Editeurs/9000108.md).
