
## iaConversation (Type de variable)

***En anglais : iaConversation***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **iaConversation** représente une conversation avec un modèle d'IA conversationnelle, pour utilisation par le champ Chat IA. 

Les caractéristiques de cette conversation peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Il est également possible de connaître directement les caractéristiques de la conversation via la propriété [IAConversation](../Proprietes/1410091344.md) du champ Chat IA.  

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI CHATIA_MonChatIA.IAConversation.RequêteEnCours ALORS
   IMG_Jauge.Visible = Vrai
FIN
```





<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type iaConversation
<a name="proprietes_specifiques_description_des_variables_type_iaconversation_ELTPARAGRAPHE000033"></a>Les propriétés suivantes peuvent être utilisées pour manipuler un conversation dans un champ Chat IA :


| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Elément | Tableau de [iaElémentConversation](../WDLang1/1410091337.md) | Tableau des éléments de la conversation avec l'IA : suite de questions et de réponses, dans l'ordre. <br><br>Le premier élément du tableau correspond au prompt système. |
| Nom | Chaîne de caractères | Nom de la conversation |
| NombreToken | Entier | Nombre de tokens utilisé par la conversation. <br><br>**Cette propriété est disponible en lecture seulement**. |
| RequêteEnCours | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si une requête vers l'IA est en cours. Une animation est alors affichée dans le champ Chat IA. <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire. <br><br><br><br><br>**Cette propriété est disponible en lecture seulement**. |
