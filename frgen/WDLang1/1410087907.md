


## SysNotificationSupprime (Fonction)

***En anglais : SysNotificationRemove***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une notification interactive précédemment envoyée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Création d'une notification qui propose une mise à jour
notifMAJ est une sysNotification
notifMAJ.Titre = "Une mise à jour est disponible !"
notifMAJ.Texte1 = "Téléchargez-la pour profiter des nouveautés."
notifMAJ.Boutons[1].Libellé = "Télécharger !"
notifMAJ.Boutons[1].Note = "MAJ_bouton_télécharger"
notifMAJ.Boutons[2].Libellé = "Plus tard ..."
notifMAJ.Boutons[2].Type = sysNotifBoutonRappel
// Envoi de la notification
SysNotificationEnvoie(notifMAJ)

// Plusieurs actions en rapport avec la notification ...

// Il n'est plus nécessaire d'afficher la notification, elle peut être supprimée
SysNotificationSupprime(notifMAJ)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SysNotificationSupprime(<Notification>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la notification a été envoyée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Notification> : (Variable de type sysNotification)`**

Nom de la variable de type [sysNotification](../WDLang1/1410087893.md) à supprimer. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La suppression de la notification fait disparaître cette notification de l'écran de l'utilisateur et du centre d'action de Windows.
