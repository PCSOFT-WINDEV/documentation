


## fChargeTexte (Fonction)

***En anglais : fLoadText***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Charge le contenu d'un fichier texte dans tout champ ou variable texte (variable de type chaîne, champ de saisie d'une fenêtre, un champ Libellé d'un état, etc.). La fonction [fSauveBuffer](../WDLang1/1000019412.md) permet d'extraire ce fichier du buffer.

<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// Charger le contenu du fichier "C:\Temp\MonFichier.txt" dans
// le champ de saisie "SAI_Saisie1"
SAI_Saisie1 = fChargeTexte("C:\Temp\MaTable.txt")
```

<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = fChargeTexte(<Nom et chemin du fichier Texte> [, <Mode de chargement>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Contenu du fichier texte,

- Chaîne vide ("") en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Nom et chemin du fichier Texte> : (Chaîne de caractères)`**

Nom et chemin complet (ou relatif) du fichier texte. Il est possible d'utiliser un chemin UNC. Ce fichier n'est pas forcément un fichier au format TXT: en effet, les 0 binaires sont autorisés.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Ce paramètre peut être au format Ansi ou Unicode.![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Le chemin de ce fichier peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)). Ce paramètre est sensible à la casse. 

**`<Mode de chargement> : (Constante de type Entier)`**

Mode de chargement du fichier: 


|   |   |
| --- | --- |
| *foAnsi* | Fichier de type Ansi. Dans ce cas, &lt;Résultat&gt; correspondra à une chaîne de caractères Ansi. |
| *foUnicode* | Fichier de type Unicode. Dans ce cas, &lt;Résultat&gt; correspondra à une chaîne de caractères Unicode. |


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce paramètre n'est pas supporté. Le format renvoyé correspond au format supporté par la plateforme en cours.

### Visualiser le contenu d'un fichier en Unicode
<a name="visualiser_contenu_fichier_unicode_ELTPARAGRAPHE000113"></a>

Pour visualiser le contenu d'un fichier en Unicode, il est nécessaire de réaliser le traitement suivant: 

```wl
// Charger le contenu du fichier "C:\MesFichiers\MonFichier.XML" dans la chaîne MaChaîne 
MonBuffer est un Buffer 
MaTableCrusher = fChargeTexte("C:\MesFichiers\MaTable.XML")
MaChaîne est une chaîne Unicode 
MaChaîne = MonBuffer
Info(MaChaîne)
```
