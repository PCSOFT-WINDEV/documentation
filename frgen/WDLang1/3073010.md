


## Fonctions système
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


Les fonctions système sont les suivantes :



|   |   |
| --- | --- |
| [SysArrête](../WDLang1/3073013.md) | Arrête le système ou ferme la session Windows en cours. |
| [SysAssocieExtension](../WDLang1/1000021892.md) | Associe une extension (.txt, .avi, etc.) à un programme d'exécution par défaut. |
| [SysCacheStockageExterne](../WDLang1/1000021815.md) | Renvoie le chemin du répertoire à utiliser pour stocker les données en cache de l'application sur l'espace de stockage externe de l'application. |
| [SysChangeEnvironnement](../WDLang1/1000017241.md) | Modifie les variables d'environnement du système d'exploitation du poste en cours. |
| [SysChangeRésolutionEcran](../WDLang1/1000017020.md) | Modifie la résolution d'un écran. |
| [SysCouleur](../WDLang1/3073011.md) | Identifie ou modifie la couleur d'un élément Windows. |
| [SysCouleurAccentuation](../WDLang1/1410090893.md) | Renvoie la couleur d'accentuation de Windows (couleur système également appelée couleur dominante). |
| [SysCouleurRes](../WDLang1/3073012.md) | Renvoie la résolution de l'écran en nombre de couleurs. |
| [SysCrypte](../WDLang1/1410091090.md) | Crypte des données en utilisant les informations d'identification de l'utilisateur Windows.<br><br> |
| [SysDécrypte](../WDLang1/1410091091.md) | Décrypte des données en utilisant les informations d'identification de l'utilisateur Windows. Ces données ont été précédemment cryptées par la fonction [SysCrypte](../WDLang1/1410091090.md). <br><br> |
| [SysDétecteSessionVerrouillée](../WDLang1/1000021185.md) | Détecte le changement de verrouillage de la session Windows. |
| [SysDissocieExtension](../WDLang1/1000021914.md) | Supprime l'association entre une extension et une commande, préalablement créée par la fonction [SysAssocieExtension](../WDLang1/1000021892.md). |
| [SysDocRécentAjoute](../WDLang1/1000018867.md) | Ajoute un fichier dans la liste des documents récemment ouverts. |
| [SysDocRécentListe](../WDLang1/1000018869.md) | Renvoie la liste des documents récemment ouverts. |
| [SysDonneFocus](../WDLang1/3073004.md) | Donne le focus à une fenêtre ou à un champ. |
| [SysEnvironnement](../WDLang1/3073014.md) | Renvoie les variables d'environnement du système d'exploitation du poste en cours. |
| [SysEspace](../WDLang1/3073002.md) | Renvoie l'espace mémoire physique du poste en cours. |
| [SysEstAdministrateur](../WDLang1/1410091051.md) | Indique si l'utilisateur courant possède les droits d'administrateur de la machine.<br><br> |

| [SysEtatCarteStockage](../WDLang1/1000019554.md) | Renvoie l'état de disponibilité de la carte de stockage de l'appareil. |
| [SysEtatStockageExterne](../WDLang1/1000021798.md) | Renvoie l'état de disponibilité de l'espace de stockage externe de l'appareil. |
| [SysFenActive](../WDLang1/3073005.md) | Renvoie le handle de la fenêtre active ou active une fenêtre. |
| [SysFenAffiche](../WDLang1/3073003.md) | Modifie l'état d'affichage d'une fenêtre. |
| [SysFenHandle](../WDLang1/3073007.md) | Renvoie le numéro de handle d'une fenêtre identifiée par son titre. |
| [SysFenTitre](../WDLang1/3073008.md) | Renvoie le titre d'une fenêtre. |
| [SysHandleValide](../WDLang1/3073009.md) | Teste la validité d'un handle de fenêtre. |
| [SysIconeAfficheBulle](../WDLang1/1000021767.md) | Affiche une bulle pour une icône présente dans la barre des tâches. |
| [SysIconeAjoute](../WDLang1/3073001.md) | Ajoute une icône dans la barre des tâches (en bas à droite de l'écran). |
| [SysIconeAjouteImage](../WDLang1/1000018874.md) | Ajoute une icône en surimpression de l'icône de l'application dans la barre des tâches. |
| [SysIconeBadge](../WDLang1/1000020796.md) | Renvoie ou modifie la valeur affichée dans le badge (ou pastille) associé à l'icône d'une application iOS. |
| [SysIconeModifie](../WDLang1/3073027.md) | Modifie le fichier icône et/ou le message de survol d'une icône dans la barre des tâches (en bas à droite de l'écran). |
| [SysIconeSupprime](../WDLang1/3073022.md) | Supprime une icône de la barre des tâches (à côté de l'horloge). |
| [SysIconeSupprimeImage](../WDLang1/1000018875.md) | Supprime l'icône en surimpression de l'icône de l'application dans la barre des tâches. |
| [SysIconisé](../WDLang1/3073017.md) | Permet de savoir si une fenêtre est iconisée. |
| [SysIdentifiant](../WDLang1/1000020619.md) | Renvoie l'identifiant unique de l'appareil mobile en cours. |
| [SysIMEI](../WDLang1/3073029.md) | Renvoie le numéro IMEI d'un téléphone Android. |
| [SysInfoAppareil](../WDLang1/1000023103.md) | Récupère des informations sur l'appareil mobile sur lequel s'exécute l'application |
| [SysInstance](../WDLang1/3073018.md) | Renvoie l'instance d'un module. |
| [SysLibèreDC](../WDLang1/3073021.md) | Libère le DC (Device Context) en cours récupéré par la fonction [SysRécupèreDC](../WDLang1/3073023.md). |
| [SysListeCarteGraphique](../WDLang1/1000017016.md) | Renvoie le nom des cartes graphiques connectées au poste en cours. |
| [SysListeEcran](../WDLang1/1000017014.md) | Renvoie la liste des écrans connectés sur une ou plusieurs cartes graphiques. |
| [SysListeRésolutionEcran](../WDLang1/1000017018.md) | Renvoie les résolutions possibles pour un écran. |
| [SysMémoireStockageExterne](../WDLang1/1000021817.md) | Renvoie la quantité de mémoire disponible sur la zone de stockage externe de l'appareil. |

| [SysNomEcranPrincipal](../WDLang1/1000017017.md) | Renvoie le nom de l'écran principal de l'ordinateur. |

| [SysOrientationEcran](../WDLang1/3073031.md) | Permet de : <br><br>- connaître l'orientation de l'écran de l'appareil (téléphone Android ou iOS).<br><br>- modifier l'orientation de l'écran de l'appareil (téléphone Android).<br><br><br> |
