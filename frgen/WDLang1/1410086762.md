
## BitcoinCoreTauxHash (Fonction)

***En anglais : BitcoinCoreHashRate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calcule le "taux de hash" (hashrate) actuel nécessaire pour créer de nouveaux blocs.

Remarque : Le hashrate est une mesure de la puissance de calcul totale de tous les nœuds participants, exprimée en unités de calcul de hachage par seconde.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Configuration de la connexion
BitcoinCoreParamètre(btcRpcAdresseServeur, "172.17.1.255")
BitcoinCoreParamètre(btcRpcNuméroDePort, 8332)
BitcoinCoreParamètre(btcRpcLogin, "bitcoin")
BitcoinCoreParamètre(btcRpcMotDePasse, "motdepasse")
BitcoinCoreParamètre(btcTimeout, 5) // 5 secondes
// ========================================================================
// Calcule le hashrate actuel du réseau à partir de la difficulté
// C'est le hashrate nécessaire pour créer de NOUVEAUX blocs
// ========================================================================
rTauxHashReseau est un réel 
rTauxHashReseau = BitcoinCoreTauxHash()
SI ErreurDétectée ALORS
	Erreur("Erreur lors de la récupération du taux de hash réseau", ErreurInfo())
	RETOUR
FIN
Trace("Taux de hash brut : " + NumériqueVersChaîne(rTauxHashReseau, "15,2e") + " H/s")

// Conversion en unités lisibles
rTauxHashEH est un réel = rTauxHashReseau / 1e18  // ExaHash/s
Trace("Taux de hash réseau (pour nouveaux blocs) : " + NumériqueVersChaîne(rTauxHashEH, "3,2f") + " EH/s")
Trace("(calculé à partir de la difficulté)")
// Valeur exemple : 682.45 EH/s (octobre 2024)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = BitcoinCoreTauxHash()`
---

**`<Résultat> : (Réel)`**

Taux de hash actuel.
