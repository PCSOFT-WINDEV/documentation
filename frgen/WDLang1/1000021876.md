


## SysNation (Fonction)

***En anglais : SysNation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la nation actuellement utilisée par le système. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Teste la langue du système afin que le projet utilise cette langue
soit nLangue = SysNation()
Nation(nLangue)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SysNation()`
---

**`<Résultat> : (Entier ou constante de type Entier)`**

Identifiant de la langue actuellement utilisée par le système (voir Remarques).
