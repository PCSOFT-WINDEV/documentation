


## &lt;Variable Image&gt;.Police (Fonction)

***En anglais : &lt;Image variable&gt;.Font***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déclare la police de caractères qui sera utilisée par la fonction [&lt;Variable Image&gt;.DessineTexte](../WDLang1/1000024242.md) dans une variable de type [Image](../WDLang1/1000019650.md).



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImage est une Image = "Test.bmp"
// Déclaration de la police de caractères :
// Arial, taille 12, gras
MonImage.Police("Arial", 12, iGras)

IMG_MonDessin = MonImage
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Utiliser une police spécifique pour les dessins

`<Variable Image>.Police(<Police> [, <Taille de la police> [, <Attributs de la police> [, <Inclinaison du texte>]]])`
---

**`<Variable Image> : (Variable de type Image)`**

Nom de la variable de type [Image](../WDLang1/1000019650.md) à manipuler. 

**`<Police> : (Chaîne de caractères)`**

Nom de la police utilisée lors du dessin du texte par [&lt;Variable Image&gt;.DessineTexte](../WDLang1/1000024242.md). Ce paramètre ne doit pas correspondre à une famille de polices. La liste des polices installées sur le poste en cours peut être connue avec la fonction [PoliceListe](../WDLang1/3060003.md). 

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Si le nom de la police n'est pas trouvé, Windows recherche une police dont le nom est le plus proche. Pour cela, la fonction [&lt;Variable Image&gt;.DébutDessin](../WDLang1/1000024349.md) doit avoir été utilisée.

**`<Taille de la police> : (Entier optionnel)`**

Taille de la police (en points). La valeur par défaut est 12.

**`<Attributs de la police> : (Constante (ou combinaison de constantes) optionnelle)`**

Attributs de police à utiliser :


|   |   |
| --- | --- |
| *iBarre* | Barre le texte dessiné. <br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette constante n'est pas gérée. |
| *iGras* | Met le texte dessiné en gras. |
| *iItalique* | Met le texte dessiné en italique. |
| *iNormal*<br>(Valeur par défaut) | Normalise le texte dessiné |
| *iSouligne* | Souligne le texte dessiné. <br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette constante n'est pas gérée. |



**`<Inclinaison du texte> : (Entier optionnel)`**

Indique l'inclinaison (en degrés) du texte. La valeur par défaut est 0.

### Utiliser une police créée par programmation

`<Variable Image>.Police(<Police utilisée>)`
---

**`<Variable Image> : (Variable de type Image)`**

Nom de la variable de type [Image](../WDLang1/1000019650.md) à manipuler. 

**`<Police utilisée> : (Police)`**

Police à utiliser pour les dessins. Ce paramètre correspond à une variable de type [Police](../Motscles/1514045.md). Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](../WDLang1/3060002.md) ou grâce aux [propriétés de gestion des polices](../Proprietes/2515045.md).

### Polices
<a name="polices_ELTPARAGRAPHE000600"></a>La fonction [PoliceListe](../WDLang1/3060003.md) permet de récupérer la liste des polices valides (TrueType, PostScript) installées sur la machine en cours.

Pour obtenir un résultat satisfaisant lors de l'inclinaison du texte dessiné, la &lt;Police&gt; utilisée doit être de type "TrueType".
<a name="NOTE0_3"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Polices en PHP
<a name="polices_php_ELTPARAGRAPHE000617"></a>Pour utiliser les attributs de mise en forme (gras, italique, ...), il est nécessaire que les fichiers des polices correspondantes soient accessibles (fichiers ttf). Ces fichiers doivent être présents dans le répertoire du site (répertoire _WEB connu avec la fonction [fRepWeb](../WDLang1/3036052.md)) et nommés de la façon suivante : 

- &lt;Nom de la police normale&gt;

- &lt;Nom de la police normale&gt;_Bold

- &lt;Nom de la police normale&gt;_Italic

- &lt;Nom de la police normale&gt;_Italic_Bold




La gestion du souligné est automatique comme la gestion du &.

Si aucune police n'est trouvée, le texte sera normal, sans gestion du &.
<a name="NOTE0_4"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000643"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".



<a name="NOTE0_5"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000665"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
