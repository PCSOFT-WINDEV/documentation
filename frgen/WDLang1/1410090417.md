


## &lt;Editeur de code&gt;.Insère (Fonction)

***En anglais : &lt;Code editor&gt;.Insert***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Insère une chaîne de caractères dans le champ Editeur de code. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Insère un commentaire avec la date du jour au début du code
sCommentaire est chaîne = "// le " + DateSys() + RC
EDCODE_Exemple.Insère(1, sCommentaire)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Editeur de code>.Insère(<Position> , <Texte>)`
---

**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.

**`<Position> : (Entier)`**

Positon d'insertion par rapport au début du code.

**`<Texte> : (Chaîne de caractères)`**

Texte à insérer.
