


## ChampRectangle (Fonction)

***En anglais : ControlRectangle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie les coordonnées du rectangle correspondant à la zone spécifiée d'un champ.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ZoneRectangle est un Rectangle
ZoneRectangle = ChampRectangle(SAI_SansNom1, rectSaisieBoutonADroite)
Trace(ZoneRectangle.X, ZoneRectangle.Y, ZoneRectangle.Largeur, ZoneRectangle.Hauteur)
// Ouvre la popup sous le bouton droit de <SAI_SansNom1>
OuvrePopup(FEN_pop, FEN_Saisie.X + SAI_SansNom1.X + ZoneRectangle.X, ...
	FEN_Saisie.Y + FEN_Saisie.HauteurTitre + SAI_SansNom1.Y + ZoneRectangle.Y + ZoneRectangle.Hauteur)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = ChampRectangle(<Champ manipulé> , <Zone du champ> [, <Origine>])`
---

**`<Résultat> : (Variable de type Rectangle)`**

Variable de type [Rectangle](../Motscles/1514079.md) correspondant à la zone spécifiée du champ manipulé. 

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. 

**`<Zone du champ> : (Constante de type Entier)`**

Zone recherchée : 


|   |   |
| --- | --- |
| *rectAscenseurHorizontal* | Rectangle correspondant au cadre de l'ascenseur horizontal du champ. |
| *rectAscenseurVertical* | Rectangle correspondant au cadre de l'ascenseur vertical du champ. |
| *rectExterne* | Rectangle correspondant au cadre externe du champ. |
| *rectInterne* | Rectangle correspondant au cadre interne du champ. |
| *rectSaisieBoutonADroite* | Rectangle correspondant au bouton présent à droite de la zone de saisie (cas des champs de saisie). |
| *rectSaisieBoutonAGauche* | Rectangle correspondant au bouton présent à gauche de la zone de saisie (cas des champs de saisie). |



**`<Origine> : (Constante optionnelle de type Entier)`**

Origine prise en compte pour le calcul des coordonnées du rectangle : 


|   |   |
| --- | --- |
| *crChamp*<br>(Valeur par défaut) | L'origine des coordonnées du rectangle correspond au champ manipulé.  |
| *crEcran* | L'origine des coordonnées du rectangle correspond à l'écran.  |
| *crFenêtre* | L'origine des coordonnées du rectangle correspond à la fenêtre contenant le champ.  |
