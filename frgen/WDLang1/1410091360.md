
## ChatIARegénèreDemande (Fonction)

***En anglais : AIChatRetryRequest***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance une nouvelle demande à partir de la conversation en cours dans le champ Chat IA. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ChatIARegenereDemande(CHATIA_MonChat)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ChatIARegénèreDemande(<Champ Chat IA> [, <Indice de l'élément>])`
---

**`<Champ Chat IA> : (Nom de champ)`**

Champ Chat IA manipulé. 

**`<Indice de l'élément> : (Entier optionnel)`**

Numéro de l'élément dans la conversation à partir duquel la conversation doit reprendre. 

Si ce paramètre n'est pas spécifié ou égal à -1, la conversation est regénérée à partir de la dernière demande de l'utilisateur.
