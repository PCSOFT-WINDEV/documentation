## Syntaxe

### Dessiner un rectangle en spécifiant les coordonnées du rectangle

`<Variable Image>.DessineRectangle(<X1> , <Y1> , <X2> , <Y2> [, <Fond> [, <Trait>]])`
---

**`<Variable Image> : (Variable de type Image)`**



**`<X1> : (Entier)`**

Abscisse en pixels du coin haut gauche du rectangle.

**`<Y1> : (Entier)`**

Ordonnée en pixels du coin haut gauche du rectangle.

**`<X2> : (Entier)`**

Abscisse en pixels du coin bas droit du rectangle.

**`<Y2> : (Entier)`**

Ordonnée en pixels du coin bas droit du rectangle.

**`<Fond> : (Entier, constante ou variable de type Fond (optionnel))`**



- Couleur du fond du rectangle. Cette couleur peut être :

	- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

	- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

	- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md), 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md), 

	- transparente si ce paramètre n'est pas précisé et si la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md) n'a pas été utilisée auparavant. 




- Caractéristiques du fond : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) variable de type [Fond](../WDLang1/1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte. 
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les variables de type [Fond](../WDLang1/1000022038.md) ne sont pas disponibles dans cette syntaxe. Utilisez la fonction [&lt;Variable Image&gt;.DessineCadre](../WDLang1/1000024019.md) pour personnaliser la couleur de fond.

	- caractéristiques spécifiées dans le dernier appel à la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md) si ce paramètre n'est pas précisé. 







Pour utiliser une couleur de fond dégradée, utilisez la fonction [&lt;Variable Image&gt;.DessineRectangleDégradé](../WDLang1/1000024238.md).

**`<Trait> : (Entier, constante ou variable de type Cadre (optionnel))`**



- Couleur du trait du rectangle. Cette couleur peut être :

	- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

	- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

	- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md), 

	- identique à la couleur utilisée pour le fond si ce paramètre n'est pas précisé et si la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) n'a pas été utilisée.  




- Caractéristiques du trait : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) variable de type [Cadre](../Motscles/15140100.md). Dans ce cas, seules les propriétés suivantes sont prises en compte : 

		- Couleur : si la propriété correspond à la constante *CouleurIndéfinie*, la couleur définie lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisée. Si cette fonction n'a pas été utilisée, la couleur de fond du rectangle est utilisée. 

		- Epaisseur : si la propriété correspond à la constante *EpaisseurIndéfinie*, l'épaisseur définie lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisée. Si cette fonction n'a pas été utilisée, l'épaisseur vaut 1. 

		- Trait : si la propriété correspond à *TraitIndéfini*, le type de trait défini lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisé. Si cette fonction n'a pas été utilisée, le trait est un trait continu.  




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les variables de type [Cadre](../Motscles/15140100.md) ne sont pas disponibles dans cette syntaxe. Utilisez la fonction [&lt;Variable Image&gt;.DessineCadre](../WDLang1/1000024019.md) pour personnaliser le cadre.

- caractéristiques précisées dans le dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) si ce paramètre n'est pas précisé.

### Dessiner un rectangle via une variable de type Rectangle

`<Variable Image>.DessineRectangle(<Rectangle> [, <Fond> [, <Trait>]])`
---

**`<Variable Image> : (Variable de type Image)`**



**`<Rectangle> : (Variable de type Rectangle)`**

Nom de la variable de type [Rectangle](../Motscles/1514079.md) définissant les coordonnées du rectangle à dessiner.

**`<Fond> : (Entier, constante ou variable de type Fond (optionnel))`**



- Couleur du fond du rectangle. Cette couleur peut être :

	- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

	- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md), 

	- une variable de type [Couleur](../WDLang1/1000019661.md), 

	- transparente si ce paramètre n'est pas précisé et si la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md) n'a pas été utilisée auparavant. 




- Caractéristiques du fond : 

	- variable de type [Fond](../WDLang1/1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
