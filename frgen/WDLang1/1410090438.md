


## CertificatPEMVersPFX (Fonction)

***En anglais : CertificatePEMToPFX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Convertit un fichier de certificat au format "pem" en un ficher de certificat au format "PFX" incluant la clé privée. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CheminFichierCertificat est une chaîne = "C:\MonChemin\MonCertificat.pem"
CheminFichierCléPrivée est une chaîne = "C:\MonChemin\MaClePrivee.key"
MdpCléPrivée est une chaîne = "Mon_Super_M2P_2_Cle_Privee"
CheminFichierPFX est une chaîne = "C:\MonChemin\MonCertificat.pfx" // Fichier à créer
CertificatPEMVersPFX(CheminFichierCertificat, CheminFichierCléPrivée, MdpCléPrivée, CheminFichierPFX)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CertificatPEMVersPFX(<Fichier Certificat> , <Fichier clé privée> , <Mot de passe de la clé privée> , <Fichier PFX>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la conversion a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Fichier Certificat> : (Chaîne de caractères)`**

Chemin du fichier correspondant au certificat public à convertir (au format "pem").

**`<Fichier clé privée> : (Chaîne de caractères)`**

Chemin du fichier correspondant à la clé privée. 

**`<Mot de passe de la clé privée> : (Chaîne de caractères ANSI ou Chaîne secrète)`**

Mot de passe du fichier contenant la clé privée.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi - Latin".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Fichier PFX> : (Chaîne de caractères)`**

Chemin du fichier PFX à créer. L'extension doit être précisée dans le nom du fichier.
