


## &lt;Image&gt;.DessineTexte (Fonction)

***En anglais : &lt;Image&gt;.DrawText***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dessine un texte dans un champ Image.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Dessin d'un texte en jaune clair
IMG_Dessin.DessineTexte(10, 20, "Le développement facile", JauneClair)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Image>.DessineTexte(<Abscisse> , <Ordonnée> , <Texte> [, <Couleur du texte> [, <Gestion du &>]])`
---

**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.

**`<Abscisse> : (Entier)`**

Coordonnées (abscisse) du texte à dessiner (en pixels).

**`<Ordonnée> : (Entier)`**

Coordonnées (ordonnée) du texte à dessiner (en pixels).

**`<Texte> : (Type correspondant au texte à dessiner)`**

Texte à dessiner. Ce texte peut être :

- une chaîne de caractères (sans caractères de contrôle tels que TAB, RC, etc.),

- un numérique.




**`<Couleur du texte> : (Entier ou constante (optionnel))`**

Couleur du texte à utiliser. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).




Si ce paramètre n'est pas précisé, la couleur du texte :

- est Noire si la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) n'a pas été utilisée auparavant,

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md).




**`<Gestion du &> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (valeur par défaut) si le "&" ne doit pas être interprété comme opérateur de soulignement. 

- <u><u><u><u>Faux</u></u></u></u> si le "&" doit être interprété comme opérateur de soulignement : le caractère qui suit le caractère "&" sera souligné.  


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Si ce paramètre vaut <u><u><u><u>Faux</u></u></u></u>, le "&" ne sera pas affiché mais le caractère suivant ne sera pas souligné.

<a name="NOTE0_1"></a>

## Remarques


### Police
<a name="police_ELTPARAGRAPHE000431"></a>Par défaut :

- La police utilisée est la police "MS Sans Serif" (taille 13).

- Le sens d'écriture est horizontal (de gauche à droite).

- L'angle haut gauche de l'image a les coordonnées (0,0).

- Le caractère "&" n'est pas interprété.




Pour modifier ces paramètres, utilisez la fonction [&lt;Variable Image&gt;.Police](../WDLang1/1000024232.md).
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La police par défaut peut être différente selon le système sur lequel est exécutée l'application.
<a name="NOTE0_2"></a>
<a name="NOTE0_3"></a>


### Coordonnées
<a name="coordonnees_ELTPARAGRAPHE000471"></a>Les coordonnées sont indiquées par rapport au coin haut gauche du champ Image (coordonnées (0,0)).
Les coordonnées correspondent au point haut gauche du rectangle dans lequel le texte sera dessiné. L'emplacement précis du texte dans ce rectangle dépend de la taille, de la forme et des attributs de la police.
<a name="NOTE0_3_Bis"></a>


### Gestion du '&'
<a name="gestion_ELTPARAGRAPHE000499"></a>Le paramètre &lt;Gestion du & &gt; permet de gérer la présence du caractère '&'. 
Exemple : 

- le "&" ne doit pas être interprété comme opérateur de soulignement. Par exemple : 
	
	```wl
	IMG_Dessin.DessineTexte(10, 10, "Lui&Moi", RougeClair, Vrai)
	```

	affichera "Lui&Moi".

- le "&" doit être interprété comme opérateur de soulignement : le caractère qui suit le caractère "&" sera souligné. Par exemple : 
	
	```wl
	IMG_Dessin.DessineTexte(10, 10, "&Saisie", RougeClair, Faux)
	```

	affichera "<u><u><u><u>S</u></u></u></u>aisie".

### Limitations
<a name="limitations_ELTPARAGRAPHE000603"></a>En mode anti-aliasing (fonction [&lt;Image&gt;.ChangeMode](../WDLang1/1000023997.md)) ou en mode opacité (fonction [&lt;Image&gt;.DébutDessin](../WDLang1/1000024326.md)), la fonction **&lt;Image&gt;.DessineTexte** est disponible uniquement pour les polices TrueType.
