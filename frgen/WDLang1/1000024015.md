


## &lt;Image&gt;.Remplissage (Fonction)

***En anglais : &lt;Image&gt;.Fill***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Colorie une zone dans un champ Image. 

Ce coloriage est effectué sur tous les points juxtaposés ayant la même couleur que le point de départ spécifié dans la fonction.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Coloriage d'une zone en bleu clair
IMG_Dessin.Remplissage(10, 50, BleuClair)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Image>.Remplissage(<X> , <Y> [, <Couleur de remplissage> [, <Couleur des limites>]])`
---

**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.

**`<X> : (Entier)`**

Abscisse en pixels du point à l'intérieur de la zone à colorier. Cette coordonnée est indiquée par rapport au coin haut gauche du champ Image (coordonnées (0,0)).

**`<Y> : (Entier)`**

Ordonnée en pixels du point à l'intérieur de la zone à colorier. Cette coordonnée est indiquée par rapport au coin haut gauche du champ Image (coordonnées (0,0)).

**`<Couleur de remplissage> : (Entier ou constante (optionnel))`**

Couleur de remplissage de la zone. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).




Si ce paramètre n'est pas précisé, la couleur de remplissage :

- est *Transparent* si la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md) n'a pas été utilisée auparavant,

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md).




**`<Couleur des limites> : (Entier ou constante (optionnel))`**

Couleur de la bordure de la zone. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).




Si ce paramètre n'est pas précisé, la couleur de la bordure de la zone s'adapte à la couleur du remplissage.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Dessin en mode anti-aliasing
<a name="dessin_mode_antialiasing_ELTPARAGRAPHE000423"></a>Lors d'un dessin en mode anti-aliasing (constante *dessinAntiAliasing* dans la fonction [&lt;Image&gt;.ChangeMode](../WDLang1/1000023997.md)), la carte graphique effectue un lissage des points et des couleurs utilisées en bordure des formes.

Dans ce cas, le paramètre &lt;Couleur de la bordure&gt; n'est pas retrouvé sur le dessin et le remplissage s'effectue sur la totalité du dessin.
<a name="NOTE0_2"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000453"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Limitation pour la fonction &lt;Image&gt;.Remplissage** : L'opacité définie avec la fonction [&lt;Variable Image&gt;.Fond](../WDLang1/1000024056.md) n'est pas prise en compte.
<a name="NOTE0_3"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000477"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
