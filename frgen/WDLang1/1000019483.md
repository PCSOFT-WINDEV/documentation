


## DessinDisponible (Fonction)

***En anglais : DrawingAvailable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique si le navigateur supporte les fonctionnalités de dessin.

**Remarque** : Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5).

<a name="sample_code"></a>

## Exemple


```wl
SI DessinDisponible() = Faux ALORS 
	Info("Dessin non disponible.")
FIN
```

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.

## Remarques
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000044"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction **DessinDisponible**. 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit "inclure la référence au fichier DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet. 
 **Rappel** : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
