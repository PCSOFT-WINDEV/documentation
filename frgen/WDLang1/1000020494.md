
## fAjouteTexte (Fonction)

***En anglais : fAddText***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute le contenu d'une chaîne de caractères à la fin d'un fichier.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI fAjouteTexte("C:\test\MaTable.txt", "Chaîne ajoutée en fin de table")
	Info("Ajout réussi")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = fAjouteTexte(<Nom du fichier> , <Chaîne à ajouter>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'ajout a été réalisé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Nom du fichier> : (Chaîne de caractères)`**

Fichier à manipuler (260 caractères maximum). Ce paramètre peut correspondre à: 

- un nom de fichier. Ce fichier sera automatiquement recherché dans le répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)).

- un nom de fichier avec son chemin (complet ou relatif). Un chemin de type UNC peut être utilisé.




**Attention**: Ce fichier est modifié par la fonction **fAjouteTexte**. Si le fichier n'existe pas, il sera automatiquement créé. 

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Ce paramètre peut être au format Ansi ou Unicode.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Ce paramètre peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)). Ce paramètre est sensible à la casse. 
**Rappel**: Sous les iPhone/iPad, sur l'appareil comme sur l'émulateur, le système de fichiers est en lecture seule. Une application a uniquement le droit d'écrire dans son répertoire d'installation ou dans un de ses sous-répertoires.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Ce paramètre peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)). Ce paramètre est sensible à la casse. 
**Rappel**: Sous Android, sur l'appareil comme sur l'émulateur, le système de fichiers est en lecture seule. Une application a uniquement le droit d'écrire dans son répertoire d'installation ou dans un de ses sous-répertoires, ainsi que sur la mémoire externe (SDCard).

**`<Chaîne à ajouter> : (Chaîne de caractères)`**

Texte à ajouter au fichier.
