
## Procédure WLangage appelée par la fonction TCDCalculeMiseAJourAsynchrone



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [TCDCalculeMiseAJourAsynchrone](../WDLang1/1410090401.md) à la fin du calcul complet du champ Tableau croisé dynamique. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
TCDCalculeMiseAJourAsynchrone(TCD_Statistiques, Calcul_terminé)
PROCEDURE INTERNE Calcul_terminé(bOK est booléen)
	SI PAS bOK ALORS
		Erreur(ErreurInfo())
		RETOUR
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`TCDCalculeMiseAJourAsynchrone_Callback(<Etat>)`
---

**`<Etat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le calcul du champ Tableau croisé dynamique a été effectué avec succès, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Dans ce cas, la fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître la cause de l'échec du calcul.
