


## &lt;Image&gt;.Rotation (Fonction)

***En anglais : &lt;Image&gt;.Rotation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Effectue une rotation d'un champ Image.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=dRotation.gif)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Rotation du champ IMG_Image1 de 45 degrés
Résultat1 est un booléen
Résultat1 = IMG_Image1.Rotation(45)
SI Résultat1 = Faux ALORS Erreur("L'opération a échoué")
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Effectuer une rotation simple

`<Résultat> = <Champ Image>.Rotation(<Angle de rotation> [, <Options>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la rotation a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.

**`<Angle de rotation> : (Réel)`**

Angle de rotation (en degrés). 

- Si l'angle est positif, l'image est tournée dans le sens horaire. 

- Si l'angle est négatif, l'image est tournée dans le sens anti-horaire.




**`<Options> : (Entier)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) Options de rotation : 


|   |   |
| --- | --- |
| *drAdapte* | L'image est tournée avec un agrandissement. Elle est ensuite réduite pour correspondre à la taille initiale de l'image. |
| *drDéfaut* | Agrandissement si nécessaire de l'image pour correspondre aux dimensions de l'image tournée.<br><br> |
| *drSansAgrandissement* | L'image est tournée mais n'est pas agrandie : l'image peut être tronquée.<br><br>**Constante utilisée par défaut pour les champs Image**. |

### Effectuer une rotation en modifiant le centre de rotation

`<Résultat> = <Champ Image>.Rotation(<Angle de rotation> , <X Centre de rotation> , <Y Centre de rotation> [, <Options>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la rotation a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.

**`<Angle de rotation> : (Réel)`**

Angle de rotation (en degrés).

**`<X Centre de rotation> : (Entier)`**

Abscisse en pixels du nouveau centre de rotation.

**`<Y Centre de rotation> : (Entier)`**

Ordonnée en pixels du nouveau centre de rotation.

**`<Options> : (Constante de type Entier)`**

Options de rotation : 


|   |   |
| --- | --- |
| *drDéfaut* | Agrandissement si nécessaire de l'image pour correspondre aux dimensions de l'image tournée.<br><br> |
| *drSansAgrandissement* | L'image est tournée mais n'est pas agrandie.<br><br>**Constante utilisée par défaut pour les champs Image**. |

## Remarques


### Fin du dessin
<a name="fin_dessin_ELTPARAGRAPHE000479"></a>Si la fonction [&lt;Variable WDPic&gt;.FinDessin](../WDLang1/1000024472.md) est appelée dans le même traitement que la fonction **&lt;Image&gt;.Rotation**, la transformation de l'image ne sera pas affichée.
<a name="NOTE0_2"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000501"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".



<a name="NOTE0_3"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000523"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
