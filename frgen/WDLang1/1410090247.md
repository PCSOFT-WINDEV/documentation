


## EditeurCodeCommente (Fonction)

***En anglais : CodeEditorComment***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Commente la sélection en cours dans le champ Editeur de code. Les caractères "//" sont ajoutés devant la ligne en cours. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Permet de commenter le code sélectionné dans le champ Éditeur de code
EditeurCodeCommente(EDCODE_Exemple)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`EditeurCodeCommente(<Champ Editeur de code>)`
---

**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.
