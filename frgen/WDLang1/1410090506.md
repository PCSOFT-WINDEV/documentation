


## CmdRécupèreCodeRetour (Fonction)

***En anglais : CmdGetExitCode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère le code de retour de la commande lancée en mode console, c'est-à-dire la valeur renvoyée à la terminaison de la commande.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande 
CmdExécute(MaCommandeAExécuter, Faux)
// Écriture dans l'entrée standard (possible car le flux est actif)
CmdEcritEntréeStandard(MaCommandeAExécuter, "Test Ecriture" + RC)
// Récupération du code de retour de la commande
code est un entier = CmdRécupèreCodeRetour(MaCommandeAExécuter, Vrai)
// Lecture dans la sortie standard (possible car le flux est actif)
stdout est une chaîne = CmdLitSortieStandard(MaCommandeAExécuter)
// Lecture dans la sortie d'erreur (impossible car le flux n'est pas activé)
// Message d'erreur : Le flux 'STDERR' n'est pas activé.
stderr est une chaîne = CmdLitSortieErreur(MaCommandeAExécuter)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Code Retour> = CmdRécupèreCodeRetour(<Commande à manipuler> [, <Bloquant>])`
---

**`<Code Retour> : (Entier)`**

Code de retour de l'exécution de la commande en mode console. Ce code de retour correspond à la valeur renvoyée par le programme. 
Remarque : Par convention, un programme qui se termine avec succès renvoie 0, et renvoie une autre valeur en cas d'erreur. Ce n'est en rien une règle. 

**`<Commande à manipuler> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande exécutée en mode console. 

**`<Bloquant> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (valeur par défaut) pour un fonctionnement bloquant : les données sont lues uniquement lorsque la commande a fini de s'exécuter. 

- <u><u><u><u>Faux</u></u></u></u> pour un fonctionnement non bloquant (asynchrone) : les données sont lues même si la commande n'a pas fini son exécution. Si la commande n'a pas fini son exécution, une erreur sera affichée.
