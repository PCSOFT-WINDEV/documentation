


## MultimédiaEtat (Fonction)

***En anglais : MultimediaStatus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique l'état du fichier multimédia joué dans le champ Multimédia.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Remarque**: Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, l'appel à cette fonction sera sans effet et ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MaTable est une chaîne = "C:\Ma musique\mysong.mp3"

MultimédiaOuvre(MM_Multimédia1, MaTable)
...
SI MultimédiaEtat(MM_Multimédia1) = MultimédiaEtatPause ALORS
	MultimédiaDébut(MM_Multimédia1)
	MultimédiaJoue(MM_Multimédia1)
FIN
...
MultimédiaFerme(MM_Multimédia1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = MultimédiaEtat(<Champ Multimédia>)`
---

**`<Résultat> : (Constante de type entier)`**

Etat du fichier multimédia en cours dans le champ Multimédia.


|   |   |
| --- | --- |
| *MultimédiaEtatArrêt* | Fichier arrêté.<br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Selon le type de vidéo et la configuration du navigateur, cette constante peut ne jamais être retournée: un fichier multimédia chargé peut être uniquement en lecture ou en pause. |
| *MultimédiaEtatJoue* | Fichier ouvert et en cours de lecture. |
| *MultimédiaEtatPause* | Fichier en pause. |



**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.
