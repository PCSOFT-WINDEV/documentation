


## Fonctions Caméra
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion du champ Caméra sont les suivantes : 




|   |   |
| --- | --- |
| [CaméraAffiche](../WDLang1/1410086595.md) | Affiche dans un champ "Caméra" la séquence vidéo actuellement retransmise par une "web caméra" ou par la caméra de l'appareil mobile.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraArrête](../WDLang1/1410086596.md) | Arrête l'affichage ou l'enregistrement d'une séquence vidéo affichée dans un champ Caméra.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraArrêteDécodage](../WDLang1/1000022449.md) | Arrête le décodage des codes-barres via un champ Caméra. |
| [CaméraCapture](../WDLang1/1000022450.md) | Capture la séquence vidéo actuellement retransmise par une "caméra" :<br><br>- sous forme d'une image : prend une photo.<br><br>- sous forme de vidéo : enregistre une vidéo.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraChangeDriver](../WDLang1/1000022451.md) | Connecte le champ "Caméra" à un driver de capture vidéo spécifique. |
| [CaméraConfigure](../WDLang1/1000022452.md) | Permet de configurer le driver de capture vidéo. |
| [CaméraDemandePermission](../WDLang1/1000022453.md) | Demande la permission d'utiliser la caméra de l'appareil. |
| [CaméraDémarreDécodage](../WDLang1/1000022454.md) | Démarre le décodage des codes-barres dans un champ Caméra. |
| [CaméraEtat](../WDLang1/1000022455.md) | Renvoie l'état d'un champ Caméra.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraGénèreMiniature](../WDLang1/1000022456.md) | Génère une miniature de la photo ou de la vidéo spécifiée. |
| [CaméraLanceAppli](../WDLang1/1000022470.md) | Lance l'application caméra native de l'appareil afin d'enregistrer une vidéo ou de prendre une photo. |
| [CaméraListeDriver](../WDLang1/1000022457.md) | Liste les drivers de capture vidéo installés sur le poste en cours. |
| [CaméraListeParamètre](../WDLang1/1000022458.md) | Liste les valeurs supportées par la caméra de l'appareil pour un paramètre donné.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraParamètre](../WDLang1/1000022459.md) | Renvoie ou modifie la valeur d'un paramètre de la caméra de l'appareil.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraPhoto](../WDLang1/1410087225.md) | Prend une photo via un champ Caméra dans une application Android ou iOS. |
| [CaméraVidéoArrête](../WDLang1/1410087229.md) | Arrête l'enregistrement d'une vidéo précédemment démarré par la fonction [CaméraVidéoDémarre](../WDLang1/1410087227.md). |
| [CaméraVidéoDémarre](../WDLang1/1410087227.md) | Démarre l'enregistrement d'une vidéo via un champ Caméra dans une application Android ou iOS. |
| [ScanDocumentDepuisCaméra](../WDLang3/1410090545.md) | Ouvre une fenêtre spécifique permettant de numériser un ou plusieurs documents à l'aide de la caméra du téléphone ou de la tablette. |
