


## AgendaChangeMode (Fonction)

***En anglais : OrganizerChangeMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la plage temporelle affichée par un champ Agenda (Jour/Semaine/Mois).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche les quatre premiers jours de la semaine
AgendaChangeMode(AGD_MonAgenda, agzSemaine, 4)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`AgendaChangeMode(<Champ Agenda> , <Plage d'affichage> [, <Nombre de jours>])`
---

**`<Champ Agenda> : (Nom de champ)`**

Nom du champ Agenda à manipuler. Ce champ peut correspondre : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) au champ Agenda d'une fenêtre.

- au champ Agenda d'un état.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) au champ Agenda d'une page.




**`<Plage d'affichage> : (Constante de type Entier)`**

Plage de temps à afficher dans le champ Agenda :


|   |   |
| --- | --- |
| *agzJour* | Affiche l'agenda sur une journée. |
| *agzMois* | Affiche l'agenda sur un mois. |
| *agzNbJourPersonnalisé* | Affiche l'agenda sur le nombre de jours indiqués dans le paramètre &lt;Nombre de jours&gt;.<br><br>![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *agzSemaine* | Affiche l'agenda sur le nombre de jours indiqués dans le paramètre &lt;Nombre de jours&gt;. |
| *agzSemaineSur5* | Affiche l'agenda sur 5 jours (le week-end n'est pas affiché). |



**`<Nombre de jours> : (Entier optionnel)`**

Nombre de jours affichés. Si le paramètre  &lt;Plage d'affichage&gt; est égal à  : 

- *agzSemaine* : Nombre de jours affichés dans la semaine. Si ce paramètre n'est pas précisé, l'agenda sera affiché sur une semaine complète. 

- *agzNbJourPersonnalisé* : Nombre de jours affichés dans le champ Agenda. 


Dans les autres cas, une erreur WLangage est affichée.
