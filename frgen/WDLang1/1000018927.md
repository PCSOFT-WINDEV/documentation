


## Fonctions Zones de mémoire partagées
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des zones de mémoire partagées sont les suivantes :



|   |   |
| --- | --- |
| [fMemAttend](../WDLang1/1000018915.md) | Attend la fin du traitement des notifications de modification d'une zone de mémoire partagée. |
| [fMemExiste](../WDLang1/1000018916.md) | Teste l'existence d'une zone de mémoire partagée. |
| [fMemOuvre](../WDLang1/1000018917.md) | Ouvre une zone de mémoire partagée entre plusieurs applications. |
