
## ShamirReconstruitSecret (Fonction)

***En anglais : ShamirReconstructSecret***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reconstruit un secret à partir d'un ensemble de clés.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupère les identifiants des clés à utiliser
ids_clés est un tableau d'entier = [ 1, 3, 5 ]

// Tableau des clés à utiliser pour reconstituer le secret
clés est un tableau de chaînes

// Parcours des identifiants de clés
POUR CHAQUE id DE ids_clés
	// Charge le contenu du fichier correspondant
	contenu_fichier est une chaîne = fChargeTexte(fRepExe() + [fSep()] + "bip39_cle_[%id%].txt")

	// Découpe le contenu du fichier en un tableau de bip39
	tab_bip39_clé est un tableau de chaîne
	ChaîneVersTableau(contenu_fichier, tab_bip39_clé, RC)

	// Reconstitue le tableau des sections de la clé
	sections est un tableau de chaînes

	// La première section est toujours l'identifiant
	sections.Ajoute(id)

	// Retransforme le bip39 en une chaîne hexa
	POUR CHAQUE bip39_section DE tab_bip39_clé
		buffer_section est un Buffer = PhraseVersBuffer(bip39_section)
		hexa_section est une chaîne = BufferVersHexa(buffer_section, SansRegroupement, SansLigne)
		sections.Ajoute(hexa_section)
	FIN
	// Reconstruit la clé avec des tirets comme séparateurs
	Clé est une chaîne = sections.VersChaîne("-")
	// Trace(clé)
	clés.Ajoute(clé)
FIN

// Reconstruit le secret
secret_reconstitué est un Buffer = ShamirReconstruitSecret(clés)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = ShamirReconstruitSecret(<Clés> [, <Nombre premier>])`
---

**`<Résultat> : (Buffer)`**

Buffer secret reconstruit.  

**`<Clés> : (Tableau de chaînes)`**

Tableau de chaînes contenant les clés nécessaires pour reconstruire le secret. 
Ce tableau doit contenir au moins autant de clés différentes que le seuil indiqué lors de la création des clés (fonction [ShamirCréeClésPartagées](../WDLang1/1410091293.md)). 

**`<Nombre premier> : (Chaîne de caractères optionnelle)`**

Nombre premier utilisé lors de la création des clés.
