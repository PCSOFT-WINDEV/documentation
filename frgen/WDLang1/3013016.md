


## Commandes vocales dans vos applications
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000154"></a>
Les applications que vous réalisez peuvent réagir à la voix de l'utilisateur. Par exemple, scroll de table, fermeture de fenêtres, sélection d'un interrupteur, clic sur un bouton sont automatiquement supportés.

L'ensemble des commandes standard de Windows est supporté.

Vous pouvez également ajouter vos propres commandes vocales dans vos applications. Par exemple, il suffira de dire "Trouve la fiche de Mr Jean Dupont" pour que l'action correspondante soit déclenchée.

### Conditions nécessaires
<a name="conditions_necessaires_ELTPARAGRAPHE000037"></a>![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Pour utiliser des commandes vocales dans vos applications, il est nécessaire d'avoir :

- soit Windows Vista (ou supérieur).

- soit un logiciel de reconnaissance vocale (par exemple Dragon Naturally Speaking, tests réalisés avec la version 9 "Preferred" ou "standard").


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour utiliser des commandes vocales dans vos applications, le service de reconnaissance vocale doit être installé sur le téléphone. Le déclenchement de la reconnaissance des commandes vocales doit être effectué grâce à la fonction [ReconnaissanceVocaleDéclenche](../WDLang1/1000020013.md). 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Attention** : Les fonctions de reconnaissance vocale sont utilisables uniquement à partir de iOS 10.

### Utiliser les commandes vocales dans l'application
<a name="utiliser_les_commandes_vocales_dans_application_ELTPARAGRAPHE000065"></a>Pour utiliser les commandes vocales dans l'application : 

1. Activez le logiciel de reconnaissance vocale.

2. Dictez les libellés des options de menu ou des boutons que vous souhaitez utiliser.



<a name="NOTE2_3"></a>


### Proposer des options supplémentaire ou des macro-commandes
<a name="proposer_des_options_supplementaire_des_macrocommandes_ELTPARAGRAPHE000075"></a>Il est possible d'associer des procédures ou des fonctions à une commande vocale. Il suffit d'associer la procédure à la commande voulue grâce à la fonction [ReconnaissanceVocaleAjouteCommande](../WDLang1/1000020014.md). Cette procédure est liée à la procédure pour la fenêtre en cours.

Dans la procédure, la phrase ayant déclenché la commande vocale peut être récupérée. Il est ainsi possible par exemple d'isoler les informations voulues (nom du client, nom de la ville, ...).

Il est possible de supprimer cette association grâce à la fonction [ReconnaissanceVocaleSupprimeCommande](../WDLang1/1000020017.md).

Exemple :

```wl
// Lance la procédure "Trouver" si la commande vocale est reconnue
nIdVoix est un entier 
nIdVoix = ReconnaissanceVocaleAjouteCommande("Trouver", "Trouve la fiche de")
```

```wl
PROCEDURE Trouver(Param1)
sClient est une chaîne = Param1[[21 A ]]
HLitRecherchePremier(sClient, PRENOMNOM, sClient)
```

### Désactiver la reconnaissance vocale
<a name="desactiver_reconnaissance_vocale_ELTPARAGRAPHE000098"></a>Par défaut, la reconnaissance vocale est automatiquement activée.

Pour désactiver la reconnaissance vocale dans votre application, utilisez la fonction [FAADésactive](../WDLang1/1000022018.md) avec la constante *faaReconnaissanceVocale*.
