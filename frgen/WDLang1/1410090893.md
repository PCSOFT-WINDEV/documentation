
## SysCouleurAccentuation (Fonction)

***En anglais : SysWindowsAccentColor***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la couleur d'accentuation de Windows (couleur système également appelée couleur dominante).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupération couleur dominante de Windows
oCouleurAccentuation est une Couleur = SysCouleurAccentuation()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SysCouleurAccentuation()`
---

**`<Résultat> : (Variable de type Couleur)`**

Variable de type [Couleur](../WDLang1/1000019661.md) correspondant à la couleur et à l'opacité de la couleur d'accentuation de Windows.
