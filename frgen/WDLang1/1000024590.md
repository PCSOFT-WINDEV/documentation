


## &lt;Variable picCalque&gt;.Rotation (Fonction)

***En anglais : &lt;picLayer variable&gt;.Rotation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Effectue une rotation d'une image contenue dans une variable de type [picCalque](../WDLang1/1000024604.md).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=dRotation.gif)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque

// Rotation du calque de 45 degrés
Résultat1 est un booléen
Résultat1 = MonCalque.Rotation(45)
SI Résultat1 = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImageWDPic
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Effectuer une rotation simple

`<Résultat> = <Image picCalque>.Rotation(<Angle de rotation> [, <Options>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la rotation a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Image picCalque> : (Variable de type picCalque)`**

Nom de la variable de type [picCalque](../WDLang1/1000024604.md) à manipuler.

**`<Angle de rotation> : (Réel)`**

Angle de rotation (en degrés). 

- Si l'angle est positif, l'image est tournée dans le sens horaire. 

- Si l'angle est négatif, l'image est tournée dans le sens anti-horaire.




**`<Options> : (Constante de type Entier)`**

## Remarques


### Fin du dessin
<a name="fin_dessin_ELTPARAGRAPHE000381"></a>Si la fonction [&lt;Variable picCalque&gt;.FinDessin](../WDLang1/1000024473.md) est appelée dans le même traitement que la fonction **&lt;Variable picCalque&gt;.Rotation**, la transformation de l'image ne sera pas affichée.
<a name="NOTE0_2"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000403"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".



<a name="NOTE0_3"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000425"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
