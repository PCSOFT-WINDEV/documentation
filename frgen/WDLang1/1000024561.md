


## &lt;Variable picCalque&gt;.DessinePortion (Fonction)

***En anglais : &lt;picLayer variable&gt;.DrawSlice***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dessine une portion de cercle ou d'ellipse dans une variable de type [picCalque](../WDLang1/1000024604.md).![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque

// Dessin d'une portion de cercle dont le
// fond est jaune clair et le bord bleu clair
MonCalque.DessinePortion(10, 10, 50, 50, 20, 20, 40, 50, JauneClair, BleuClair)
IMG_MonDessin = MonImageWDPic
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Dessiner une portion de cercle en précisant toutes les coordonnées du rectangle contenant le cercle

`<Image picCalque>.DessinePortion(<X1> , <Y1> , <X2> , <Y2> , <X3> , <Y3> , <X4> , <Y4> [, <Couleur du fond> [, <Couleur du trait>]])`
---

**`<Image picCalque> : (Variable de type picCalque)`**

Nom de la variable de type [picCalque](../WDLang1/1000024604.md) à manipuler. 

**`<X1> : (Entier)`**

Abscisse du coin haut gauche du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<Y1> : (Entier)`**

Ordonnée du coin haut gauche du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<X2> : (Entier)`**

Abscisse du coin bas droit du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<Y2> : (Entier)`**

Ordonnée du coin bas droit du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<X3> : (Entier)`**

Abscisse du point de départ de la portion de cercle. Ces coordonnées sont exprimées en pixels.

**`<Y3> : (Entier)`**

Ordonnée du point de départ de la portion de cercle. Ces coordonnées sont exprimées en pixels.

**`<X4> : (Entier)`**

Abscisse du point d'arrivée de la portion de cercle. Ces coordonnées sont exprimées en pixels.

**`<Y4> : (Entier)`**

Ordonnée du point d'arrivée de la portion de cercle. Ces coordonnées sont exprimées en pixels.

**`<Couleur du fond> : (Entier ou constante (optionnel))`**

Couleur du fond de la portion de cercle. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md). 




Si ce paramètre n'est pas précisé, la couleur du fond :

- est *Transparent* si la fonction [&lt;Variable picCalque&gt;.Fond](../WDLang1/1000024480.md) n'a pas été utilisée auparavant,

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Variable picCalque&gt;.Fond](../WDLang1/1000024480.md).




**`<Couleur du trait> : (Entier ou constante (optionnel))`**

Couleur du trait de la portion de cercle. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md). 




Si ce paramètre n'est pas précisé, la couleur du trait :

- est *Transparent* si la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) n'a pas été utilisée auparavant. 
	Dans le cas d'une variable de type [Image](../WDLang1/1000019650.md), la ligne aura la couleur noire. 

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md).

## Remarques


### Coordonnées
<a name="coordonnees_ELTPARAGRAPHE000663"></a>Si *les points de départ et d'arrivée* ne sont pas situés sur le bord du cercle (ou de l'ellipse), le point pris en compte est l'intersection du cercle et de la droite joignant le point précisé et le centre du rectangle (c'est-à-dire le centre du cercle).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=RbPortion.gif)
Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).

Les portions de dessin sont dessinées dans le sens trigonométrique.
<a name="NOTE0_2"></a>


### Figure non-pleine
<a name="figure_nonpleine_ELTPARAGRAPHE000693"></a>Pour dessiner une figure non-pleine (sans prendre en compte le centre du cercle), utilisez la fonction [&lt;Variable picCalque&gt;.DessineCorde](../WDLang1/1000024469.md).

### Dessin avec opacité ou anti-aliasing
<a name="dessin_avec_opacite_antialiasing_ELTPARAGRAPHE000710"></a>Dans le cas d'un dessin avec opacité (fonction [&lt;Variable picCalque&gt;.DébutDessin](../WDLang1/1000024470.md) avec la constante *dAvecOpacité*) ou anti-aliasing (fonction [&lt;Variable picCalque&gt;.ChangeMode](../WDLang1/1000024432.md) avec la constante *dessinAntiAliasing*), le contour est dessiné par-dessus l'intérieur de la portion: le trait est donc en partie combiné avec l'intérieur de la portion. Si l'épaisseur du trait est importante, le trait s'affichera en deux couleurs.

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000803"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".



<a name="NOTE0_6"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000825"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
