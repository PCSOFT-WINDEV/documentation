


## Encode (Fonction)

***En anglais : Encode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Encode une chaîne de caractères ou un buffer. Pour décoder le résultat, il suffit d'utiliser la fonction [Décode](../WDLang1/1000022259.md).

**Attention** : Le résultat de l'encodage étant une chaîne de caractères, il peut donc varier d'une configuration de projet à l'autre en fonction du réglage de la [gestion des chaînes en exécution](../WDLang1/3024038.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Encodage d'une image en Base 64
Res est une chaîne = Encode(fChargeBuffer("MonImage.jpg"), encodeBASE64)
```
<a name="Exemple2"></a>

```wl
// Encodage d'une URL
Info(Encode("https://www.google.fr/?", encodeURLDepuisAnsi) + ...
	Encode(Encode("https://www.google.fr/?é", encodeURLDepuisAnsi), encodeURLParamètre))
```
<a name="Exemple3"></a>

```wl
// Le buffer contient des caractères au format Unicode en iOS
// ou au format ANSI dans d'autres configurations (paramétrées en ANSI)
MessageEnBuffer est un Buffer = fChargeBuffer(fRepDonnées()/"monbuffer.bin")
MessageEnBuffer = Encode(MessageEnBuffer, encodeBASE64SansRC)
// Conversion permettant d'avoir un buffer en ANSI et BASE 64 dans toutes les plateformes :
MessageEnBuffer = ChaîneVersUTF8(Encode(MessageEnBuffer, encodeBASE64SansRC))
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = Encode(<Données> [, <Format d'encodage>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Données encodées selon le format choisi.

**`<Données> : (Chaîne de caractères ou Buffer)`**

Données à encoder.

**`<Format d'encodage> : (Constante optionnelle de type Entier)`**

Format d'encodage des données :


|   |   |
| --- | --- |
| *encodeBASE64*<br>(Valeur par défaut) | Format BASE 64 (respecte la norme RFC 4648). Le texte encodé comporte uniquement des caractères imprimables et les RC (Retour Chariot).<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Les RC (Retour Chariot) sont supprimés. |
| *encodeBASE64SansRC* | Format BASE 64 (respecte la norme RFC 4648) sans les RC (Retour Chariot). Le texte encodé comporte uniquement des caractères imprimables.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeBASE64URL* | Format BASE 64 URL (respecte la norme RFC 4648). Le texte encodé comporte uniquement des caractères imprimables.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeBASE85* | Format BASE 85. Le texte encodé comporte uniquement des caractères imprimables.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Format non supporté.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodePCS* | Format ASCII. Le texte encodé comporte uniquement des caractères imprimables.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Format non supporté. |
| *encodeURLDepuisAnsi* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne ANSI.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeURLDepuisUnicode* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne Unicode.<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeURLDepuisUTF8* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne UTF-8.<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeURLParamètre* | Cette constante est utilisée quand il est nécessaire de passer une URL A en paramètre d'une URL B. Les caractères réservés de l'URL A (//, ?...) sont encodés.<br><br>L'URL A (à encoder) doit être une URL valide. Si elle a elle-même des paramètres, ils doivent avoir été encodés avec une des constantes suivantes : *encodeURLDepuisAnsi*, *encodeURLDepuisUnicode* ou *encodeURLDepuisUTF8*.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette constante n'est pas disponible. |
| *encodeUUEncode* | Format UUEncode. Le texte encodé comporte uniquement des caractères imprimables.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Format non supporté. |
