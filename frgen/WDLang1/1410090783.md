
## jsonLecteur (Type de variable)

***En anglais : jsonLecteur***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **jsonLecteur** permet le parcours linéaire d'un document JSON de taille importante avec des performances optimales et une occupation mémoire réduite. Les caractéristiques de ce document JSON peuvent être lues à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Lecteur_JSON est un jsonLecteur = JSONOuvreLecteur("fichier.json")
POUR TOUT Lecteur_JSON EN PROFONDEUR
	...
FIN
```





<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type jsonLecteur
<a name="proprietes_specifiques_description_des_variables_type_jsonlecteur_ELTPARAGRAPHE000030"></a>Les propriétés suivantes peuvent être utilisées pour manipuler un document JSON :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Nom | Chaîne de caractères | <br><br>- Nom du membre, si l'élément courant est un membre d'un objet. <br><br>- Chaîne vide ("") si l'élément courant correspond à la racine ou un élément de tableau. <br><br><br><br><br>**Cette propriété est disponible en lecture seulement.** |
| Parent | jsonLecteur | Élément parent dans un parcours en profondeur. <br><br>**Cette propriété est disponible en lecture seulement.** |
| Profondeur | Entier | Profondeur de l'élément courant.<br><br>**Cette propriété est disponible en lecture seulement.** |
| SourceJSON | Chaîne de caractères | JSON source correspondant à l'élément courant. <br><br>**Cette propriété est disponible en lecture seulement.** |
| Type | Entier | Type de l'élément courant :<br><br>- *wlBooléen* : valeur JSON simple booléenne. <br><br>- *wlChaîneUnicode* : valeur JSON simple chaîne. <br><br>- *wlEntier* : valeur JSON simple entière.  <br><br>- *wlNull* : valeur JSON simple Null. <br><br>- *wlNumérique* : valeur JSON simple décimale. <br><br>- *wlVariantObjet* : objet JSON. <br><br>- *wlVariantTableau* : tableau JSON.<br><br>- *wlVide* : lecteur non initialisé.<br><br><br><br><br>**Cette propriété est disponible en lecture seulement.** |
| Valeur | Tous types | Valeur si l'élément courant est un type simple (autre que objet ou tableau). <br><br>**Cette propriété est disponible en lecture seulement.** |
