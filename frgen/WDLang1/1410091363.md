
## ChatIAStopDemande (Fonction)

***En anglais : AIChatStopRequest***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stoppe une demande en cours dans le champ Chat IA. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Clic sur STOP
ChatIAStopDemande(CHATIA_MonChat)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ChatIAStopDemande(<Champ Chat IA>)`
---

**`<Champ Chat IA> : (Nom de champ)`**

Champ Chat IA manipulé.
