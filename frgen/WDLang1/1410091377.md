
## Fonctions Chat IA
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion du champ Chat IA sont les suivantes: 



|   |   |
| --- | --- |
| [ChatIAChargeConversation](../WDLang1/1410091365.md) | Charge une conversation dans un champ Chat IA. |
| [ChatIADemande](../WDLang1/1410091334.md) | Lance une nouvelle demande dans le champ Chat IA. |
| [ChatIARegénèreDemande](../WDLang1/1410091360.md) | Lance une nouvelle demande à partir de la conversation en cours dans le champ Chat IA. |
| [ChatIASauveConversation](../WDLang1/1410091364.md) | Enregistre la conversation en cours dans un champ Chat IA (en mémoire ou sous forme de fichier au format json). |
| [ChatIAStopDemande](../WDLang1/1410091363.md) | Stoppe une demande en cours dans le champ Chat IA. |

## Types de variable associés au champ Chat IA
<a name="types_variable_associes_champ_chat_ELTTEXTE000133"></a>



|   |   |
| --- | --- |
| [iaConversation](../WDLang1/1410091340.md) | Le type **iaConversation** représente une conversation avec un modèle d'IA conversationnelle, pour utilisation par le champ Chat IA. |
