


## &lt;Table&gt;.Ajoute (Fonction)

***En anglais : &lt;Table&gt;.Add***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une ligne dans: 

- un champ Table, 

- un champ Table hiérarchique, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ "Combo avec table" (champ Table affiché dans un champ Combo).




**Remarque**: Il est conseillé d'utiliser la fonction [&lt;Table&gt;.AjouteLigne](../WDLang1/1000023404.md). La fonction [&lt;Table&gt;.AjouteLigne](../WDLang1/1000023404.md) permet d'ajouter:

- des caractères TAB dans les colonnes,

- des valeurs de n'importe quel type dans les colonnes,

- des données UNICODE automatiquement et sans conversion.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajout de "Dubois", "Pierre" et "21/06/72"
// à la fin du champ "TABLE_TableClient"
ResAjout = TABLE_TableClient.Ajoute("Dubois" + TAB + "Pierre" + TAB + "21/06/72")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Table>.Ajoute([<Ligne>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément a été ajouté, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à: 

- un champ Table.

- un champ Table hiérarchique. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Combo avec table.




**`<Ligne> : (Chaîne de caractères optionnelle)`**

Ligne à ajouter. Cette ligne est de la forme: 

```txt
<Elément de la colonne 1> + TAB + <Elément de la colonne 2> + TAB + ...
```

Si ce paramètre n'est pas spécifié, une ligne vide est ajoutée dans le champ. Pour un champ table, les valeurs par défaut définies dans la table liée sont alors prises en compte.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000302"></a>

La fonction **&lt;Table&gt;.Ajoute** peut être utilisée indifféremment sur:

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection.
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Rappel**: La multisélection n'est pas disponible sur les champs Table en mode "Serveur".


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX", les champs Table en mode "Serveur" et les champs Table hiérarchique. ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur".![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le champ Table hiérarchique n'est pas disponible.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Les champs Table liée aux données ne sont pas disponibles en saisie. La fonction **&lt;Table&gt;.Ajoute** ne peut pas être utilisée sur un champ Table liée aux données. 
<a name="NOTE0_2"></a>


### Caractéristiques d'une ligne
<a name="caracteristiques_une_ligne_ELTPARAGRAPHE000344"></a>

- Chaque élément ajouté est converti dans le type de la colonne concernée.

- Pour ne pas spécifier de valeur pour un élément, utilisez une chaîne vide ("") ou 0 (selon le type de la colonne). Par exemple:
	
	```wl
	TABLE_TableClient.Ajoute("Dubois" + TAB + "Pierre" + TAB + "" + TAB + "21/06/72")
	```


- Si un élément correspond au résultat d'un calcul, mettez l'expression numérique entre parenthèses. Par exemple:
	
	```wl
	TABLE_TableCalcul.Ajoute((53+29) + TAB + (83-21))
	```




<a name="NOTE0_3"></a>


### Position de la ligne ajoutée
<a name="position_ligne_ajoutee_ELTPARAGRAPHE000370"></a>

Par défaut, la ligne est ajoutée à la fin des lignes affichées par le champ.

Cas particulier: 

- Si le champ est trié avec la fonction [&lt;Table&gt;.Trie](../WDLang1/1000024293.md), la ligne ajoutée est positionnée dans le champ en fonction du tri en cours.

- Si le champ est trié par l'utilisateur, le tri n'est pas pris en compte lors de l'ajout de la ligne. La ligne est ajoutée à la fin du champ.



<a name="NOTE0_4"></a>


### Limites: Nombre maximum de lignes affichées
<a name="limites_nombre_maximum_lignes_affichees_ELTPARAGRAPHE000390"></a>

Le nombre maximum de lignes pouvant être affichées dans un champ Table ou Table hiérarchique est limité uniquement par la mémoire vive disponible (maximum théorique: 2 milliards de lignes).

Il est cependant déconseillé d'utiliser des champs Table ou Table hiérarchique avec un nombre de lignes important pour des raisons de performance (temps nécessaire pour remplir le champ par exemple) et d'utilisabilité.
<a name="NOTE0_5"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000402"></a>

- Pour ajouter une ligne dans un champ Table ou Table hiérarchique à une position spécifique, utilisez la fonction [&lt;Table&gt;.InsèreLigne](../WDLang1/1000023407.md).

- Si la ligne ajoutée est la première ligne du champ, la ligne ajoutée devient la ligne en cours.

### Champ Table/Table hiérarchique table: Modifications dans la table liée
<a name="champ_tabletable_hierarchique_table_modifications_dans_table_liee_ELTPARAGRAPHE000465"></a>

- **Si la saisie en cascade est activée**, la table liée au champ est automatiquement modifiée lorsque l'utilisateur passe à la ligne suivante.

- **Si la saisie en cascade n'est pas activée**, la table liée au champ n'est pas modifiée. Pour écrire le contenu de la ligne ajoutée dans la table liée, il est nécessaire d'utiliser la fonction [&lt;Table&gt;.Enregistre](../WDLang1/1000024249.md) après la fonction **&lt;Table&gt;.Ajoute**.




**Remarques**: 

- L'option "Saisie en cascade (Ajout)" peut être sélectionnée dans l'onglet "Détail" de la description du champ.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La saisie en cascade n'est pas disponible sur les champs Table liée aux données à accès direct. Cette option est disponible uniquement sur les champs Table par programmation et sur les champs Table liée aux données chargée en mémoire.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) La saisie en cascade est disponible uniquement sur les champs Table liée aux données en mode "Serveur + AJAX".

### Champ Table/Table hiérarchique fichier: Ajout de plusieurs lignes
<a name="champ_tabletable_hierarchique_fichier_ajout_plusieurs_lignes_ELTPARAGRAPHE000501"></a>

A chaque appel de la fonction **&lt;Table&gt;.Ajoute** dans un champ Table ou Table hiérarchique fichier, une ligne virtuelle est créée dans le champ. Les informations seront enregistrées dans la table liée uniquement que lors de l'appel de la fonction [&lt;Table&gt;.Enregistre](../WDLang1/1000024249.md).

Si la fonction **&lt;Table&gt;.Ajoute** est appelée successivement dans le même traitement sans être suivie de la fonction [&lt;Table&gt;.Enregistre](../WDLang1/1000024249.md), seul le PREMIER appel est effectif (les appels suivants sont ignorés). Une seule ligne est ajoutée dans le champ Table/Table hiérarchique fichier.
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ce fonctionnement est disponible uniquement pour les champs Table liée aux données "Serveur + AJAX".

### Champ Table/Table hiérarchique fichier en saisie
<a name="champ_tabletable_hierarchique_fichier_saisie_ELTPARAGRAPHE000552"></a>

Si la fonction **&lt;Table&gt;.Ajoute** est appelée:

- Dans un événement du champ, le curseur est automatiquement positionné sur la première colonne à saisir dans la ligne ajoutée.

- Dans un événement n'appartenant pas au champ (ou dans un autre traitement), utilisez la fonction [DonneFocusEtRetourUtilisateur](../WDLang1/1410088107.md) pour reprendre la saisie dans le champ Table ou Table hiérarchique.



<a name="NOTE0_12"></a>


### Ajout d'image
<a name="ajout_image_ELTPARAGRAPHE000570"></a>

Pour ajouter une image dans un champ Table ou Table hiérarchique: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) spécifiez directement le nom et le chemin complet de l'image à ajouter.
	Par exemple:
	
	```wl
	TABLE_MaTable.Ajoute("C:\MesDocuments\MonImage.BMP")
	```


- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) spécifiez le chemin et le nom de l'image à ajouter. Le chemin est relatif au répertoire "&lt;Nom_Projet&gt;_WEB". 
	Par exemple:
	
	```wl
	// Ajoute l'image située dans le répertoire "WB_MonAppli_WEB"
	TABLE_MaTable.Ajoute("MonImage.BMP")
	```



**Remarque**: Pour afficher correctement l'image ajoutée, la colonne doit être de type Image.
