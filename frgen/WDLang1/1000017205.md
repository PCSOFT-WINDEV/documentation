
## MultimédiaFerme (Fonction)

***En anglais : MultimediaClose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme le fichier multimédia en cours dans le champ Multimédia. La mémoire allouée au fichier multimédia est libérée.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MaTable est une chaîne = "C:\Ma musique\mysong.mp3"

MultimédiaJoue(MM_Multimédia1, MaTable)
...
MultimédiaFerme(MM_Multimédia1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = MultimédiaFerme(<Nom du champ Multimédia>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier joué dans le champ Multimédia est correctement fermé, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Remarque: La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Nom du champ Multimédia> : (Chaîne de caractères)`**

Nom du champ Multimédia à manipuler.

## Remarques
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Specificités pour iPhone/iPad
<a name="specificites_pour_iphoneipad_ELTPARAGRAPHE000071"></a>

La fonction **MultimédiaFerme** est équivalente à la fonction [MultimédiaArrêt](../WDLang1/1000017203.md): la lecture en cours d'un fichier multimédia dans un champ Multimédia est arrêtée mais le fichier multimédia reste chargé en mémoire.
