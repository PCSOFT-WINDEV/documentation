
## BitcoinCoreParamètre (Fonction)

***En anglais : BitcoinCoreConfigure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique les paramètres de connexion au serveur Bitcoin Core, afin d'utiliser les fonctions [BitcoinCoreXXXX](../WDLang1/1410090347.md).

Remarque : Pour utiliser les fonctions [BitcoinCoreXXXX](../WDLang1/1410090347.md), il est nécessaire de configurer un serveur Bitcoin Core. Pour plus de détails, consultez [Installation et utilisation d'un serveur Bitcoin Core](../WDLang1/1410090348.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
BitcoinCoreParamètre(btcRpcAdresseServeur, "192.31.15.55")
BitcoinCoreParamètre(btcRpcNuméroDePort, 8055)
BitcoinCoreParamètre(btcRpcLogin, "bob")
BitcoinCoreParamètre(btcRpcMotDePasse, "secret")

d est une DateHeure
d = BitcoinCoreDateHeureDernierBloc()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
Trace("Date du dernier bloc : " + DateVersChaîne(d))
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`BitcoinCoreParamètre(<Paramètre> , <Valeur>)`
---

**`<Paramètre> : (Constante de type Entier)`**

Paramètre à définir : 



|   |   |
| --- | --- |
| *btcRpcAdresseServeur* | Adresse du serveur Bitcoin Core. |
| *btcRpcLogin* | Login utilisateur de connexion au serveur Bitcoin Core. |
| *btcRpcMotDePasse* | Mot de passe utilisateur de connexion au serveur Bitcoin Core. <br><br>Si cette constante est utilisée, le paramètre &lt;Valeur&gt; peut également correspondre à une chaîne secrète. Dans ce cas, la chaîne secrète peut correspondre à un des types suivants : <br><br>- Chaîne Ansi - Latin, <br><br>- Chaîne Ansi ou Unicode, <br><br>- Chaîne Unicode.<br><br><br>Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). |
| *btcRpcNuméroDePort* | Numéro de port de connexion au serveur Bitcoin Core. |
| *btcTimeout* | Timeout de connexion au serveur Bitcoin Core (en secondes). |



**`<Valeur> : (Variant)`**

Valeur correspondant au paramètre indiqué.
