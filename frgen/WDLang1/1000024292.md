


## &lt;Table&gt;.SupprimeTout (Fonction)

***En anglais : &lt;Table&gt;.DeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime toutes les lignes dans : 

- un champ Table par programmation, 

- un champ Table hiérarchique par programmation, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une table affichée dans un champ Combo.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression de toutes les lignes dans le champ "TABLE_Produit"
TABLE_Produit.SupprimeTout()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Table>.SupprimeTout()`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à : 

- un champ Table.

- un champ Table hiérarchique. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Combo avec table.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000219"></a>La fonction **&lt;Table&gt;.SupprimeTout** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection.
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode "Serveur".


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX", les champs Table en mode "Serveur" et les champs Table hiérarchique.![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur".![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Le champ Table hiérarchique n'est pas disponible.
