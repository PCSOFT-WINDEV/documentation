## Comment installer WDTRAD?
<a name="comment_installer_wdtrad_ELTTEXTE000084"></a>
WDTRAD est installé automatiquement lors de l'installation de WINDEV, WEBDEV ou WINDEV Mobile. 

Pour installer uniquement WDTRAD, il est nécessaire d'installer et d'exécuter le fichier "InstallWDTRAD.EXE" (présent dans le package d'installation de WINDEV, WEBDEV ou WINDEV Mobile).

<a name="NOTE2_1"></a>


## Remarques
<a name="remarques_ELTTEXTE000108"></a>


- Par défaut, le dictionnaire fourni avec WDTRAD est automatiquement installé. Pour utiliser un dictionnaire personnalisé: 

	1. Utilisez WDTRAD pour créer et personnaliser votre dictionnaire. 

	2. Récupérez le dictionnaire en copiant le sous-répertoire "Dictionnaire" (contenant le dictionnaire personnalisé) présent dans le répertoire d'installation de WDTRAD.

	3. Collez ce sous-répertoire dans le répertoire d'installation de WDTRAD voulu. 




- Lors de la traduction des messages de votre application par une société extérieure, n'oubliez pas de fournir également à cette société le(s) fichier(s) des messages à traduire: 

	- soit un fichier texte,

	- soit la table HFSQL (tables .fic, .ndx et .mmo),

	- soit le fichier wdmsg.




- Après la traduction des messages, seul(s) le(s) fichier(s) contenant les messages traduits doit être récupéré. Il sera nécessaire de réintégrer ce(s) fichier(s) à l'aide de WDMSG ou de WDINT.

- Lors du premier lancement de WDTRAD, vous devez spécifier la langue dans laquelle WDTRAD sera exécuté. Il sera à tout moment possible de changer cette langue dans WDTRAD (option "? .. Langue").
