
## IAValeurSaisie (Propriété)

***En anglais : AIInputValue***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IAValeurSaisie** permet de connaître et de modifier la valeur du champ de saisie présent dans le champ Chat IA. Cette valeur correspond au prochain message qui sera traité par l'IA. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CHATIA_ChatIA.IAValeurSaisie = "Quel est le résultat de l'opération 551*87"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le prochain message à envoyer présent dans le champ Chat IA

`<Résultat> = <Champ Chat IA>.IAValeurSaisie`
---

**`<Résultat> : (Chaîne de caractères)`**

Message saisi dans le champ Chat IA. 

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.   


<a name="SYNTAXE2"></a>

### Modifier le prochain message à envoyer présent dans le champ Chat IA

`<Champ Chat IA>.IAValeurSaisie = <Message>`
---

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.

**`<Message> : (Chaîne de caractères)`**

Nouveau message affiché dans le champ de saisie du champ Chat IA.
