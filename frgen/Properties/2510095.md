


## Police (Propriété)

***En anglais : Font***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Police** permet de :

- Connaître l'identifiant de la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.

- Modifier la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) 
```wl
MaPolice est une police
MaPolice = PoliceCrée("Arial", 12, iGras)
SAI_Adresse.Police = MaPolice
```
<a name="Exemple2"></a>

```wl
// Définir les caractéristiques d'une variable de type Police
Police1 est une Police
Police1.Nom = "Arial"
Police1.Couleur = JauneClair
Police1.Taille = 14
Police1.UnitéTaille = unitéPoint
Police1.Angle = 45
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la police utilisée dans un champ

`<Résultat> = <Champ manipulé>.Police`
---

**`<Résultat> : (Police)`**

Variable de type [Police](../Motscles/1514045.md) contenant les caractéristiques de la police utilisée dans le champ spécifié.

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la police utilisée dans un champ

`<Champ manipulé>.Police = <Nouvelle police>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.

**`<Nouvelle police> : (Police)`**

Variable de type [Police](../Motscles/1514045.md) contenant les caractéristiques de la nouvelle police à utiliser dans le champ spécifié. Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](../WDLang1/3060002.md) ou grâce aux [propriétés de gestion des polices](../Proprietes/2515045.md).

## Remarques


### Police des champs d'un état
<a name="police_des_champs_etat_ELTPARAGRAPHE000098"></a>Pour manipuler les polices des champs d'un état, utilisez les propriétés :

- [Police](../Motscles/1514045.md),

- [PoliceNom](../Proprietes/2510100.md),

- [PoliceBarrée](../Proprietes/2510091.md),

- [PoliceGras](../Proprietes/2510103.md),

- [PoliceItalique](../Proprietes/2510102.md),

- [PoliceSoulignée](../Proprietes/2510099.md),

- [PoliceTaille](../Proprietes/2510072.md).

<a name="NOTE0_3"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Police des champs d'une page
<a name="police_des_champs_une_page_ELTPARAGRAPHE000133"></a>Il est conseillé d'utiliser comme nom de police une série de polices séparée par des virgules. Par exemple : "Arial, Helvetica, Sans-serif", "Time New Roman, Times, Serif", ...

La propriété **Police** ne permet pas de récupérer ou de modifier les tailles CSS en plus des tailles absolues. Pour plus de détails, consultez la page d'aide de la propriété [PoliceTaille](../Proprietes/2510072.md).
<a name="NOTE0_4"></a>


### Limites
<a name="limites_ELTPARAGRAPHE000148"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour un état, la propriété **Police** peut être utilisée sur :

- un champ Libellé.

- un champ Calculé.

- un champ Lien.

- un champ Prédéfini.

- un champ de saisie.


Pour une fenêtre et une page, la propriété **Police** peut être utilisée sur :

- un champ Libellé,

- un champ de saisie,

- un champ Bouton,

- un champ Interrupteur,

- un champ Sélecteur,

- un champ Liste,

- une ligne de liste (y compris liste image) ou de combo,

- un champ Table,

- un champ Table hiérarchique,

- une cellule de table,
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) La propriété est disponible en lecture uniquement.

- une colonne de table,

- un champ d'affichage formaté,

- un champ HTML,

- un champ Combo,

- un champ Lien,

- un champ Libellé HTML,

- un champ Réglette,

- un champ Chemin de navigation,

- un champ Arbre,

- un Champ Menu,

- une case de barre de message.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) La propriété **Police** peut être utilisée sur :

- un champ Bouton, 

- un champ Libellé,

- un champ de saisie,

- une colonne d'un champ Table,

- une ligne d'un champ Liste, Table ou Combo, 

- une ressource d'un champ Planning. 


Cette propriété n'est pas disponible sur les champs d'un état.
