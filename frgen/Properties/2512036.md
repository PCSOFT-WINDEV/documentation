
## FichierTransaction (Propriété)

***En anglais : TransactionFile***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **TableTransaction** permet de savoir si une table est une table de transaction ou non.

**Rappel**: Un fichier de transaction permet de stocker les différentes opérations effectuées lors d'une transaction. Ces opérations sont ensuite soit validées, soit annulées. Le fichier de transaction est créé lors au début de la transaction par la fonction [HTransactionDébut](../WDLang4/3044002.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
EXTERNE GESCOM_TRS
HDéclareExterne("C:\WinDev\Exemples\GestCom\GESCOM_TRS.fic", "GESCOM_TRS")
SI GESCOM_TRS.FichierTransaction = Vrai ALORS
	Info("Vous manipulez un fichier de transaction.")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Table>.FichierTransaction`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table est une table de transaction,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 
	Remarque: Les tables décrites dans le schéma des données ne sont pas des fichiers de transaction.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Peut correspondre à un nom d'alias d'une table déclarée par la fonction [HDéclareExterne](../WDLang4/3044204.md).
