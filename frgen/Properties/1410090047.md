
## Monochrome (Propriété)

***En anglais : Monochrome***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Monochrome** permet de savoir et de définir si une image doit être utilisée en mode monochrome. Cette propriété est utilisable sur :

- les champs Image, via la propriété [Monochrome](../Proprietes/1410090978.md). 

- la propriété [BoutonGauche](../Proprietes/1410090001.md) d'un champ de saisie.

- la propriété [BoutonDroit](../Proprietes/1410090002.md) d'un champ de saisie.
