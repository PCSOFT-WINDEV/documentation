


## FichierRelié (Propriété)

***En anglais : LinkedFile***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FichierRelié** permet de paramétrer les caractéristiques d'une liaison. Il est ainsi possible de:

- Connaître le nom de la table reliée utilisée dans la liaison.

- Changer la table reliée utilisée dans la liaison.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=FichierRelie.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modifier la table reliée
GestionProjet.FichierRelié = Projet
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la table reliée de la liaison

`<Table> = <Liaison>.FichierRelié`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table reliée de la liaison.

**`<Liaison> : (Chaîne de caractères)`**

Nom de la liaison définie sous l'éditeur de schémas des données ou définie grâce au type [Description de Liaison](../WDLang4/1514039.md).  


<a name="SYNTAXE2"></a>

### Changer la table reliée de la liaison

`<Liaison>.FichierRelié = <Table>`
---

**`<Liaison> : (Chaîne de caractères)`**

Nom de la liaison définie sous l'éditeur de schémas des données ou définie grâce au type [Description de Liaison](../WDLang4/1514039.md).

**`<Table> : (Chaîne de caractères)`**

Nom de la table reliée utilisée par la liaison. Ce table a été défini sous l'éditeur de schémas des données ou par programmation grâce au type [Description de Fichier](../WDLang4/1514065.md).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété [TableSource](../Proprietes/2512034.md) permet de connaître et de modifier la table source de la liaison.
