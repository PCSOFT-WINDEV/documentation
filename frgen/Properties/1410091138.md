
## Protection (Propriété)

***En anglais : Protection***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Protection** permet de connaître et de modifier les caractéristiques de protection d'un document PDF. 

Cette propriété est utilisable avec :

- une variable de type [pdfParamètre](../WDLang6/1410087857.md).

- une variable de type [pdfDocument](../WDLang6/1000024909.md).
