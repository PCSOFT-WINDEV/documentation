


## ProtégéParMotDePasse (Propriété)

***En anglais : PasswordProtected***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ProtégéParMotDePasse** permet de savoir si une table est protégée par mot de passe.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Savoir si le fichier de données Client est protégé par un mot de passe 
ResProtection = Client.ProtégéParMotDePasse
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Protégé> = <Table>.ProtégéParMotDePasse`
---

**`<Protégé> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table est protégée par mot de passe,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Cette table a été décrite sous l'Éditeur de schémas des données.
