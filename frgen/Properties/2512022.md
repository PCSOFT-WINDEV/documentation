


## CxUtilisateurDécrit (Propriété)

***En anglais : CtDescribedUserName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CxUtilisateurDécrit** permet de paramétrer le nom de l'utilisateur utilisé lors de la connexion OLE DB à une table spécifique. Il est possible de:

- Connaître le nom de l'utilisateur utilisé pour la connexion à une table par OLE DB d'une table (table définie sous l'éditeur de schémas des données ou définie par programmation). Ce nom d'utilisateur a été spécifié lors de la description de la table.

- Définir le nom de l'utilisateur utilisé pour la connexion à une table par OLE DB d'une table (lors de la description par programmation de la table uniquement). 




**Rappel**: La fonction [HConnecte](../WDLang4/3044263.md) permet de redéfinir un ou plusieurs paramètres de la connexion OLE DB sur une table. Par défaut, les caractéristiques de la connexion OLE DB sont définies sous l'éditeur de schémas des données lors de la description de la table.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir le nom de l'utilisateur
Client.CxUtilisateurDécrit = "Julie"
...
// Valide la description de la table
HDécritFichier(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le nom de l'utilisateur

`<Utilisateur> = <Table>.CxUtilisateurDécrit`
---

**`<Utilisateur> : (Chaîne de caractères)`**

Nom de l'utilisateur de la source OLE DB, défini lors de la description du fichier sous l'éditeur de schémas des données.

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le nom de l'utilisateur

`<Table>.CxUtilisateurDécrit = <Nouveau nom de l'utilisateur>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom de l'utilisateur> : (Chaîne de caractères)`**

Nom de l'utilisateur de la source OLE DB.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété [CxUtilisateur](../Proprietes/2512026.md) permet de connaître et de modifier le nom de l'utilisateur spécifié pour la connexion OLE DB lors de l'utilisation de la fonction [HConnecte](../WDLang4/3044263.md).
