
## Protocole (Propriété)
			

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Protocole** permet de connaître et de modifier le protocole utilisé. Cette propriété est utilisable sur :

- une variable de type [rssCloud](../WDLang5/1000017785.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [MessagerieInstantanée](../WDLang3/1000020247.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une variable de type [iaInfoModèleChat](../WDLang1/1410086683.md).
