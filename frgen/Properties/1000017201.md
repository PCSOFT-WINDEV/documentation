


## Zoom (Propriété)

***En anglais : Zoom***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Zoom** permet de connaître ou de modifier la valeur du zoom utilisée : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) dans un champ Image. Ce champ Image doit avoir la gestion des ascenseurs automatiques et du zoom activée (option "Ascenseurs et zoom automatiques" dans l'onglet "Détail" de la fenêtre de description du champ).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) dans un champ Carte. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) dans un champ Organigramme.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) dans un champ Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) dans une fenêtre.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) dans un champ Traitement de texte.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) dans un champ Lecteur PDF.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) dans un champ Caméra.
	Remarque : Cette propriété est utilisable uniquement pour les champs Caméra qui ne sont pas en "Mode compatible 26". 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) dans un champ Editeur de diagrammes.

### Fonctions de dessin, zoom et ascenseurs automatiques
<a name="fonctions_dessin_zoom_ascenseurs_automatiques_ELTPARAGRAPHE000341"></a>L'option "Ascenseurs et zoom automatiques" disponible sur un champ Image est incompatible avec la fonction [dDébutDessin](../WDLang1/3029009.md). Si cette option est utilisée sur le champ Image, la fonction [dDébutDessin](../WDLang1/3029009.md) entraîne un affichage figé dans le champ. Le zoom est également figé. Le comportement redevient normal lors de l'appel de la fonction [dFinDessin](../WDLang1/3029019.md).

Le même effet peut être constaté avec les fonctions [dPixelCouleur](../WDLang1/3029014.md) et [dRotation](../WDLang1/3029024.md).

### Fonctionnement du zoom
<a name="fonctionnement_zoom_ELTPARAGRAPHE000371"></a>La propriété **Zoom** correspond à une valeur entre les valeurs des propriétés [ZoomMin](../Proprietes/1410088098.md) et [ZoomMax](../Proprietes/1410088099.md). Cette valeur correspond au facteur de grossissement. Par exemple, si la propriété **Zoom** vaut 2, cela signifie qu'un zoom 'x2' est appliqué. 

- Si la valeur de la propriété **Zoom** est supérieure à celle de la propriété [ZoomMax](../Proprietes/1410088099.md), le zoom prend la valeur de [ZoomMax](../Proprietes/1410088099.md). 

- Si la valeur de la propriété **Zoom** est inférieure à celle de la propriété [ZoomMin](../Proprietes/1410088098.md), le zoom prend la valeur de [ZoomMin](../Proprietes/1410088098.md). 





<a name="NOTE0_3"></a>


### Limite
<a name="limite_ELTPARAGRAPHE000412"></a>Cette propriété s'applique uniquement : 

- aux champs Image ayant l'option "Ascenseurs et zoom automatiques".
