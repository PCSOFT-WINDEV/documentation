


## Réplication (Propriété)

***En anglais : Replication***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Réplication** permet de:

- connaître le mode de réplication utilisé pour une table (table définie sous l'éditeur de schémas des données ou définie par programmation).

- spécifier le mode de réplication utilisé pour une table (lors de la description par programmation de la table uniquement).




**Cette propriété est utilisable uniquement dans le cas d'une réplication journalée**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Teste si le fichier de données est marqué comme pouvant être répliqué (réplication journalée)
SI Client.Réplication = hNonRépliqué ALORS Info("Réplication impossible")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le mode de réplication

`<Mode actuel> = <Table>.Réplication`
---

**`<Mode actuel> : (Constante de type entier)`**

Modes de réplication:


|   |   |
| --- | --- |
| *hNonRépliqué* | La table n'est pas prévue pour effectuer une réplication journalée. Pour mettre en place la réplication journalée, cochez l'option "Réplication journalée" dans les caractéristiques de la table sous l'éditeur de schémas des données (onglet "Journalisaton" de la fenêtre de description de la table). |
| *hRéplicaAbonné* | La table est un réplica abonné (la fonction [HCréeRéplicaAbonné](../WDLang4/3044253.md) a été utilisée pour créer le réplica abonné) |
| *hRéplicaMaître* | La table est un réplica maître (la fonction [HCréeRéplicaMaître](../WDLang4/3044175.md) a été utilisée pour créer le réplica maître) |
| *hRépliqué* | La table est configurée pour être répliquée. |



**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le mode de réplication

`<Table>.Réplication = <Mode de réplication>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Mode de réplication> : (Constante de type entier)`**

Modes de réplication:


|   |   |
| --- | --- |
| *hNonRépliqué* | La table n'est pas prévue pour effectuer une réplication journalée. |
| *hRépliqué* | La table est configurée pour être répliquée. |
