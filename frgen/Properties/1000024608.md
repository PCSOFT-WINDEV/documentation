
## Visible (Propriété)

***En anglais : Visible***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Visible** permet de gérer la visibilité d'un élément. Cette propriété est utilisable sur : 

- les champs d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Visible](../Proprietes/2510138.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [picCalque](../WDLang1/1000024604.md).

- une variable de type [kbCarte](../WDLang1/1410089167.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) la propriété [BoutonGauche](../Proprietes/1410090001.md) d'un champ de saisie.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) la propriété [BoutonDroit](../Proprietes/1410090002.md) d'un champ de saisie.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [xlsCommentaire](../WDLang5/1000024870.md). 

- une variable de type [OptionsOuvertureFenêtre](../WDLang1/1410091298.md).
