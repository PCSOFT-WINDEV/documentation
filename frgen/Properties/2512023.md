


## IDAutoMax (Propriété)

***En anglais : MaxAutoID***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IDAutoMax** permet de connaître l'identifiant automatique maximum sur une table répliquée. **Cette propriété est disponible en lecture seulement**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître l'identifiant automatiquement maximum de la table Client 
ResIDAutoMax = Client.IDAutoMax
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Table>.IDAutoMax`
---

**`<Résultat> : (Entier)`**



- Valeur maximale de l'identifiant automatique défini pour la table,

- 0 si les bornes n'ont pas été définies ou si la table n'est pas répliquée.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée.
