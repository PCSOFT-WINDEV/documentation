


## GrosFichier (Propriété)

***En anglais : HugeFile***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **GrosFichier** permet de paramétrer la taille maximale possible d'une table. Il est ainsi possible de:

- Savoir si une table est configurée pour contenir plus de 2 Go de données (table définie sous l'éditeur de schémas des données ou définie par programmation).

- Définir les caractéristiques de taille d'une table (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir la taille maximale de la table Client
Client.GrosFichier = Vrai
...
// Valide la description de la table
HDécritFichier(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si la table peut contenir plus de 2 Go de données

`<Résultat> = <Table>.GrosFichier`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table est configurée pour contenir plus de 2 Go de données,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).


<a name="SYNTAXE2"></a>

### Définir si la table peut contenir plus de 2 Go de données (table définie par programmation)

`<Table>.GrosFichier = <Taille 2Go>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Taille 2Go> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table doit être configurée pour contenir plus de 2 Go de données,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Tables de plus de 2 Go
<a name="tables_plus_2_ELTPARAGRAPHE000071"></a>

Les tables de plus de 2 Go ne peuvent être créées que sur des disques de type NTFS. De plus, le système d'exploitation doit lui aussi gérer et supporter les fichiers de plus de 2 Go.
