
## Destination (Propriété)

***En anglais : Destination***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Destination** permet de définir : 

- la destination d'une sauvegarde. Cette propriété est utilisable sur  une variable de type [hDescriptionSauvegarde](../WDLang4/1000017455.md). 

- le fichier résultat d'une requête. Cette propriété est utilisable sur :

	- une variable de type [httpRequête](../WDLang3/1000021158.md). 

	- une variable de type [restRequête](../WDLang3/1000021481.md). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) une variable de type [TéléchargementInfo](../WDLang3/1410087306.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) une variable de type [TéléchargementParamètre](../WDLang3/1410087293.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une variable de type [iInfoSortie](../WDLang5/1410088954.md).
