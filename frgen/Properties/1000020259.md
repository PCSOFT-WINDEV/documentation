
## Prénom (Propriété)

***En anglais : FirstName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Prénom** peut être utilisée sur :

- une variable de type [SaasUtilisateur](../WDLang3/1000019083.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [Contact](../WDLang3/1000020254.md). 

- une variable de type [gpwUtilisateur](../WDLang6/1000021088.md).

- une variable de type [OpenIDIdentité](../WDLang3/1000023567.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [AppleID](../WDLang3/1000025405.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [gglCompte](../WDLang3/1410089816.md).
