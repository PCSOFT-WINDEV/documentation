


## WDD55 (Propriété)

***En anglais : WDD55***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **WDD55** permet de:

- Connaître le nom et le chemin complet du fichier WDD au format Hyper File 5.5. Ce fichier est utilisé pour accéder aux fichiers au format Hyper File 5.5 présents dans un schéma des données au format HFSQL Classic.

- Définir le nom et le chemin complet du fichier WDD au format Hyper File 5.5. Ce fichier est utilisé pour accéder aux fichiers au format Hyper File 5.5 présents dans un schéma des données au format HFSQL Classic. Cette propriété est utile lors de la description par programmation d'une table au format 5.5 dans un schéma des données au format HFSQL Classic.




**Attention**: Cette propriété est utilisable uniquement pour des tables Hyper File 5.5 non migrées dans un schéma des données au format HFSQL Classic.

Le nom de la table WDD au format 5.5 peut être retrouvé dans la description de la table sous le schéma des données (onglet "Compatibilité").
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le chemin de la table Commande
ResChemin = Commande.WDD55
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le chemin du fichier WDD au format Hyper File 5.5

`<Résultat> = <Table>.WDD55`
---

**`<Résultat> : (Chaîne de caractères)`**

Chemin du WDD correspondant au schéma des données initial au format 5.5. Si le répertoire du schéma des données en exécution correspond au répertoire en cours, ce chemin est relatif au répertoire en cours.

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée au format Hyper File 5.5.  


<a name="SYNTAXE2"></a>

### Définir le chemin du fichier WDD au format Hyper File 5.5

`<Table>.WDD55 = <Chemin>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Chemin> : (Chaîne de caractères)`**

Chemin du WDD correspondant au schéma des données initial au format 5.5.
