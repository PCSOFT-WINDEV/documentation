
## FlexAlignItems (Propriété)

***En anglais : FlexAlignItems***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FlexAlignItems** permet de connaître et de modifier les caractéristiques d'alignement des champs à l'intérieur d'une ligne d'un champ Flexbox selon l'axe secondaire du champ (propriété CSS correspondante "align-items"). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Caractéristiques du champ Flexbox
FLEX_MaFlexbox.FlexDirection = fbdColonne
FLEX_MaFlexbox.FlexWrap = fbwRetourALaLigne
FLEX_MaFlexbox.FlexJustifyContent = fbjcCentré
FLEX_MaFlexbox.FlexAlignContent = fbacFin
FLEX_MaFlexbox.FlexAlignItems = fbaiCentré
FLEX_MaFlexbox.FlexColumnGap = 5
FLEX_MaFlexbox.FlexRowGap = 50
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître les caractéristiques d'alignement des champs d'une ligne d'un champ Flexbox

`<Résultat> = <Champ manipulé>.FlexAlignItems`
---

**`<Résultat> : (Constante de type Entier)`**

Alignement des champs d'une ligne d'un champ Flexbox : 



|   |   |
| --- | --- |
| *fbaiBaseline* | Tous les textes des champs sont alignés. |
| *fbaiCentré* | Tous les champs sont centrés. Selon la direction du champ Flexbox, chaque champ est centré en fonction de sa hauteur ou de sa largeur. |
| *fbaiDébut* | Selon la direction du champ Flexbox, tous les champs sont cadrés par rapport au bord haut ou au bord gauche du champ Flexbox. |
| *fbaiEtiré* | Selon la direction du champ Flexbox, le champ va s'étendre verticalement ou horizontalement. |
| *fbaiFin* | Selon la direction du champ Flexbox, tous les champs sont cadrés par rapport au bord bas ou au bord droit du champ Flexbox. |



**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 


<a name="SYNTAXE2"></a>

### Modifier les caractéristiques d'alignement des champs d'une ligne d'un champ Flexbox

`<Champ manipulé>.FlexAlignItems = <Nouvel alignement>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 

**`<Nouvel alignement> : (Constante de type Entier)`**

Nouvel alignement : 



|   |   |
| --- | --- |
| *fbaiBaseline* | Tous les textes des champs sont alignés. |
| *fbaiCentré* | Tous les champs sont centrés. Selon la direction du champ Flexbox, chaque champ est centré en fonction de sa hauteur ou de sa largeur. |
| *fbaiDébut* | Selon la direction du champ Flexbox, tous les champs sont cadrés par rapport au bord haut ou au bord gauche du champ Flexbox. |
| *fbaiEtiré* | Selon la direction du champ Flexbox, le champ va s'étendre verticalement ou horizontalement. |
| *fbaiFin* | Selon la direction du champ Flexbox, tous les champs sont cadrés par rapport au bord bas ou au bord droit du champ Flexbox. |
