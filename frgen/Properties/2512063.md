


## NomPhysiqueDécrit (Propriété)

***En anglais : DescribedPhysicalName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NomPhysiqueDécrit** permet de gérer le nom physique des tables HFSQL.

Cette propriété ne tient pas compte des éventuels changements de noms réalisés grâce à la fonction [HChangeNom](../WDLang4/3044141.md). Il est ainsi possible de:

- Connaître le nom physique d'une table définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir un nom physique pour une table (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le nom physique du fichier de données Client
ResNomPhys = Client.NomPhysiqueDécrit
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le nom physique d'une table

`<Nom physique actuel> = <Table>.NomPhysiqueDécrit`
---

**`<Nom physique actuel> : (Chaîne de caractères)`**

Nom physique de la table (sans extension). Ce nom ne tient pas compte des éventuels changements de noms (fonction [HChangeNom](../WDLang4/3044141.md)).

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).

### Définir un nom physique pour une table créée par programmation

`<Table>.NomPhysiqueDécrit = <Nouveau nom physique>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom physique> : (Chaîne de caractères)`**

Nom physique de la table (sans extension).
