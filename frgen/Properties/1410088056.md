
## Forme (Propriété)

***En anglais : Shape***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Forme** permet de gérer les différentes formes d'un élément. Cette propriété est disponible sur : 

- une variable de type [MarqueurImage](../WDLang3/1000025796.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [Diagramme](../WDLang1/1410088055.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
