
## Email (Propriété)

***En anglais : Email***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Email** permet de connaître et de modifier une adresse email. Cette propriété est utilisable sur :

- une variable de type [gglAuteur](../WDLang5/1000017746.md).

- une variable de type [gglConnexion](../WDLang5/1000018009.md).

- une variable de type [gglPersonne](../WDLang5/1000017446.md).

- une variable de type [sfInfoUtilisateur](../WDLang5/1000018423.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [Contact](../WDLang3/1000020254.md).

- une variable de type [gpwUtilisateur](../WDLang6/1000021088.md).

- une variable de type [saasUtilisateur](../WDLang3/1000019083.md). 

- une variable de type [OpenIDIdentité](../WDLang3/1000023567.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [AppleID](../WDLang3/1000025405.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [adminWBCompte](../WDLang2/1410089382.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [gglCompte](../WDLang3/1410089816.md).
