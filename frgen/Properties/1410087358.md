
## Avancement (Propriété)

***En anglais : Progress***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Avancement** permet de connaître l'état d'avancement d'une tâche. Cette propriété est utilisable sur :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une variable de type [TâcheGantt](../WDLang1/1000020881.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) une variable de type [TéléchargementInfo](../WDLang3/1410087306.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une variable de type [sysNotificationJauge](../WDLang1/1410090964.md).

- une variable de type [hHistoriqueRéindexation](../WDLang4/1410091059.md).
