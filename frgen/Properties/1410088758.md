
## NullIndexé (Propriété)

***En anglais : NullableIndex***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NullIndexé** permet de paramétrer le mode de gestion de la valeur "Null" pour une rubrique clé. Il est ainsi possible de:  

- Savoir si l'index peut supporter la valeur "Null" pour une rubrique clé. 

- Définir le mode de gestion de la valeur "Null" pour une rubrique clé (lors de la description de la table par programmation uniquement). 




Remarque: Cette propriété est équivalente à l'option **"NULL indexée (la table sera incompatible avec les applications en version inférieure à 28)"** présente dans l'onglet "Détail" de la fenêtre de description de la table, dans l'éditeur de schémas des données. 

**Attention: Les tables possédant l'option "Null indexé" activée, sont incompatibles avec les applications en version inférieure à la version 28.**
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
UnFichier est une Description de Fichier
UneRubrique est une Description de Rubrique
// Description de la table "CLIENT"
UnFichier.Nom = "CLIENT"
UnFichier.Type = hTableNormale
UnFichier.NullIndexé = Vrai
// Description de la rubrique 
UneRubrique.Nom = "Message"
UneRubrique.Type = hRubTexte
UneRubrique.Taille = 40
HDécritRubrique(UnFichier, UneRubrique)
// Valide la description de la table 
HDécritTable(UneTable)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si l'index peut supporter la valeur "Null" pour une rubrique clé 

`<Résultat> = <Table>.NullIndexé`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table est configurée pour gérer la valeur "Null" pour une rubrique clé,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).


<a name="SYNTAXE2"></a>

### Définir le mode de gestion de la valeur "Null" pour une rubrique clé (table définie par programmation)

`<Table>.NullIndexé = <Gestion de la valeur Null>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Gestion de la valeur Null> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table doit être configurée pour autoriser la valeur "Null" pour une rubrique clé,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion de la valeur "Null" pour les rubriques clé
<a name="gestion_valeur_null_pour_les_rubriques_cle_ELTPARAGRAPHE000071"></a>

Si la table supporte la valeur "Null" pour les clés:

- Il est possible d'utiliser les fonctions de recherche avec la valeur "Null". 

- Plusieurs clés de la table peuvent avoir la valeur "Null".
