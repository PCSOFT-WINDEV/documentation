
## AlgorithmeSignature (Propriété)

***En anglais : SignatureAlgorithm***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **AlgorithmeSignature** permet de définir la méthode utilisée pour la signature. Cette propriété est utilisable sur : 

- une variable de type [xmlSignature](../WDLang5/1000020736.md). 

- une variable de type [xmlSignatureXAdES](../WDLang5/1410091158.md).
