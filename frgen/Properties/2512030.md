


## Extension (Propriété)

***En anglais : Extension***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Extension** permet de:

- connaître l'extension d'une table définie sous l'éditeur de schémas des données ou définie par programmation.

- définir l'extension d'une table (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le nom et le chemin complet de la table Client
NomCheminCompletFichier est une chaîne
NomCheminCompletFichier = Client.Répertoire + "\" + ...
	Client.NomPhysique + Client.Extension
// NomCheminCompletFichier correspond à "C:\MesFichiers\Client.Fic"
```
<a name="Exemple2"></a>

```wl
// Définir l'extension du fichier de données UnFichier
UnFichier est une Description de Fichier
UnFichier.Nom = "CLIENT"
UnFichier.Extension = ".AAA"
// Le fichier créé sera "CLIENT.AAA"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître l'extension d'une table

`<Extension du fichier> = <Table>.Extension`
---

**`<Extension du fichier> : (Chaîne de caractères)`**



- Extension de la table manipulée (précédée d'un point). 

- Chaîne vide ("") si la table manipulée n'a pas d'extension.




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir l'extension d'une table

`<Table>.Extension = <Nouvelle extension>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouvelle extension> : (Chaîne de caractères)`**

Extension de la table manipulée (précédée d'un point).
