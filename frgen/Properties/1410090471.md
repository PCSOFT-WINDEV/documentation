
## Commentaire (Propriété)

***En anglais : Comment***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Commentaire** permet de définir et de connaître les différentes caractéristiques des commentaires présents sur une cellule d'un champ Tableur. Ces propriétés sont les suivantes : 

- Texte : permet d'indiquer le texte du commentaire.  

- Rectangle : permet de décrire le rectangle dans lequel le commentaire sera affiché.  

- Visible : permet d'indiquer si le commentaire doit être visible ou non. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Création d'un commentaire
TBLR_MonTableur["B1"].Commentaire.Texte = "Texte de mon commentaire"
TBLR_MonTableur["B1"].Commentaire.Visible = Vrai
TBLR_MonTableur["B1"].Commentaire.Rectangle.Hauteur = 50
TBLR_MonTableur["B1"].Commentaire.Rectangle.Largeur = 50
TBLR_MonTableur["B1"].Commentaire.Rectangle.X = 50
TBLR_MonTableur["B1"].Commentaire.Rectangle.Y = 50
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître la valeur des caractéristiques d'un commentaire 

`<Résultat> = <Champ Tableur>[<Cellule>].Commentaire.<Nom de la propriété>`
---

**`<Résultat> : (Type correspondant à la propriété)`**

Résultat correspondant à la propriété utilisée. 

**`<Champ Tableur> : (Nom de champ)`**

Nom du champ Tableur manipulé. 

**`<Cellule> : (Chaîne de caractères)`**

Cellule du champ Tableur manipulée. 

**`<Nom de la propriété> : ()`**

Propriété appliquée : 


| Propriété | Type | Description |
| --- | --- | --- |
| Position | Chaîne de caractères | Nom de la cellule associé. <br><br>Cette propriété est disponible en lecture seulement. |
| Rectangle | Variable de type [Rectangle](../Motscles/1514079.md) | Permet de définir le rectangle dans lequel le commentaire est affiché. Les propriétés **Largeur** et **Hauteur** déterminent la taille du rectangle (en millimètres), et les propriétés **X** et **Y** permettent de déterminer la position du commentaire (en millimètres) par rapport au début de la feuille en cours. |
| Texte | Chaîne de caractères | Texte du commentaire. |
| Visible | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> pour afficher le commentaire, <br><br>- <u><u><u><u>Faux</u></u></u></u> pour rendre le commentaire invisible. Dans ce cas, seul un triangle rouge dans le coin haut droit de la cellule permettra à l'utilisateur de savoir que la cellule est associée à un commentaire. <br><br><br> |




<a name="SYNTAXE2"></a>

Les propriétés **Largeur** et **Hauteur** déterminent la taille du rectangle (en millimètres), et les propriétés **X** et **Y** permettent de déterminer la position du commentaire (en millimètres) par rapport au début de la feuille en cours. |
| Texte | Chaîne de caractères | Texte du commentaire. |
| Visible | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> pour afficher le commentaire, <br><br>- <u><u><u><u>Faux</u></u></u></u> pour rendre le commentaire invisible. Dans ce cas, seul un triangle rouge dans le coin haut droit de la cellule permettra à l'utilisateur de savoir que la cellule est associée à un commentaire. <br><br><br> |



**`<Nouvelle valeur> : (Type correspondant à la propriété)`**

Nouvelle valeur de la propriété utilisée.

## Remarques


### Utilisation d'une variable de type xlsCommentaire
<a name="utilisation_une_variable_type_xlscommentaire_ELTPARAGRAPHE000098"></a>Il est possible de décrire directement les propriétés d'un commentaire via une variable de type [xlsCommentaire](../WDLang5/1000024870.md). Il est alors possible de définir et de modifier les caractéristiques du commentaire via la syntaxe suivante : 

```txt
<Champ Tableur>.Commentaire = <Variable xlsCommentaire>
```


Exemple : 

```wl
// Création d'un commentaire
MonCommentaire est un xlsCommentaire
MonCommentaire.Texte = "Texte de mon commentaire"
MonCommentaire.Visible = Vrai
MonCommentaire.Rectangle.Hauteur = 50
MonCommentaire.Rectangle.Largeur = 50
MonCommentaire.Rectangle.X = 50
MonCommentaire.Rectangle.Y = 50

TBLR_MonTableur["B1"].Commentaire = MonCommentaire
```



### Fonctions de manipulation des commentaires
<a name="fonctions_manipulation_des_commentaires_ELTPARAGRAPHE000111"></a>Les fonctions permettant de manipuler les commentaires d'un champ Tableur sont les suivantes : 



|   |   |
| --- | --- |
| [TableurListeCommentaire](../WDLang1/1000024881.md) | Liste tous les commentaires de la feuille courante d'un champ Tableur. |
| [TableurSelectCommentaire](../WDLang1/1000024883.md) | Permet de : <br><br>- savoir si un commentaire est sélectionné dans un champ Tableur, <br><br>- sélectionner ou désélectionner un commentaire dans un champ Tableur.<br><br><br> |
