
## IAImage (Propriété)

***En anglais : AIImage***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IAImage** permet de connaître et de modifier l'image associée à la réponse de l'IA dans le champ Chat IA.                                                                                                                                                                                            
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CHATIA_MonChatIA.IAImage = "Robot.png"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître l'image utilisée

`<Résultat> = <Champ Chat IA>.IAImage`
---

**`<Résultat> : (Chaîne de caractères)`**

Image utilisée. 

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.   


<a name="SYNTAXE2"></a>

### Modifier l'image utilisée

`<Champ Chat IA>.IAImage = <Image>`
---

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.

**`<Image> : (Chaîne de caractères)`**

Nom de l'image utilisée: 

- Nom du fichier image correspondant à l'image, 

- Chaîne vide ("") pour ne pas utiliser d'image, 

- Constante *imgDéfaut* pour utiliser l'image par défaut.
