


## GUIDFichier (Propriété)

***En anglais : GUIDFile***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **GUIDFichier** renvoie le GUID de la table défini dans le schéma des données qui a permis de créer la table. Cet identifiant est utilisé dans le fichier .REP (pour plus de détails, consultez [Gestion du fichier .REP](../WDLang4/3044186.md)).

**Remarque**: Le GUID de la table peut également être connu dans l'éditeur de schémas des données (onglet "Général" de la description de la table).


<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GUIDFichier%20-%20HC%20N%B0001.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// GUID de la table "Client"
Trace(Client.GUIDFichier)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<GUID Fichier> = <Table>.GUIDFichier`
---

**`<GUID Fichier> : (Chaîne de caractères)`**



- GUID de la table défini dans le schéma des données. Ce schéma des données a permis de créer la table. 

- Chaîne vide ("") si la table a été créée par programmation ou si la table utilisée n'est pas au format HFSQL Classic ou Client/Serveur.




**`<Table> : (Chaîne de caractères)`**

Nom de la table pour laquelle le GUID est recherché.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété [GUIDAnalyse](../Proprietes/2512098.md) permet de connaître le GUID du schéma des données qui a permis de créer la table.
