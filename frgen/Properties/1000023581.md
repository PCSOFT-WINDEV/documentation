
## Mode (Propriété)

***En anglais : Mode***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Mode** permet de gérer : 

- le nombre de noeuds minimum devant avoir acquitté le traitement pour considérer l'écriture effectuée (variable de type [mongoOptionEcriture](../WDLang4/1000022597.md)). 

- le mode de gestion des sections multicolonnes (variable de type [docFormatMulticolonne](../WDLang1/1000023580.md)).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) le mode d'affichage de la bulle d'une étape de la visite guidée. Dans ce cas, cette propriété est utilisable sur :

	- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

	- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
