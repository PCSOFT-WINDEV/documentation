


## GUIDAnalyse (Propriété)

***En anglais : GUIDAnalysis***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **GUIDSchémaDesDonnées** renvoie le GUID du schéma des données qui a permis de créer la table. Cet identifiant est utilisé dans le fichier .REP (pour plus de détails, consultez [Gestion du fichier .REP](../WDLang4/3044186.md)). 

**Remarque**: Le GUID du schéma des données peut également être connu dans l'éditeur de schémas des données, dans l'onglet "Général" de la fenêtre de description du schéma des données. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GUIDAnalyse%20-%20HC%20N%B0001.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Trace(Client.GUIDAnalyse)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<GUID Schéma des données> = <Table>.GUIDAnalyse`
---

**`<GUID Schéma des données> : (Chaîne de caractères)`**



- GUID du schéma des données qui a permis de créer la table. 

- Chaîne vide ("") si la table a été créée par programmation ou si la table utilisée n'est pas une table au format HFSQL Classic ou Client/Serveur.




**`<Table> : (Chaîne de caractères)`**

Nom de la table pour laquelle le GUID du schéma des données est recherché.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété [GUIDFichier](../Proprietes/2512099.md) permet de connaître le GUID du fichier. Ce GUID a été défini dans le schéma des données qui a permis de créer la table.
