
## Icone

***En anglais : Icon***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Icône** peut correspondre : 

- à la propriété **Icone**. Cette propriété permet de connaître et de modifier l'icône d'un élément. Cette propriété est utilisable sur :

	- une fenêtre. Pour plus de détails, consultez [Propriété Icone](../Proprietes/1000019344.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [Notification](../WDLang3/1000019441.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [upnpPériphérique](../WDLang3/1000020903.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) une variable de type [notificationAction](../WDLang3/1000021304.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [ActionRapide](../WDLang3/1410090054.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [zipParamètreCréationExe](../WDLang3/1410091226.md). 
			




- à une variable de type [Icône](../WDLang1/1000020811.md).
