
## Arrondi (mot-clé)

***En anglais : Round***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Arrondi** peut correspondre :

- à la fonction WLangage [Arrondi](../WDLang1/3050063.md).

- à la propriété **Arrondi** utilisable sur: 

	- une variable de type [Cadre](../Motscles/15140100.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [diagSélection](../WDLang1/1410088172.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [diagRectangle](../WDLang1/1410088083.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) une variable de type [Toast](../WDLang1/1000024638.md).
