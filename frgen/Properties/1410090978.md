
## Monochrome (Propriété)

***En anglais : Monochrome***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Monochrome** permet de :

- savoir si les pixels d'une image contenue dans un champ Image sont automatiquement remplacés par une couleur spécifiée dans le style du champ (onglet "Style" de la description du champ, élément "Forcer en monochrome").

- activer ou non la gestion du monochrome dans un champ Image. Si la gestion du monochrome est activée, les pixels d'une image contenue dans un champ Image sont automatiquement remplacés par une couleur spécifiée dans le style du champ (onglet "Style" de la description du champ, élément "Forcer en monochrome"). 




Cette propriété permet d'optimiser la prise en compte des couleurs des palettes sur les images. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
IMG_MonImage = "C:\Temp\MonImage.jpeg"
IMG_MonImage.Monochrome = Vrai
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le mode actuel de gestion du monochrome

`<Résultat> = <Champ Image>.Monochrome`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le champ Image gère le monochrome, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier le mode de gestion du monochrome

`<Champ Image>.Monochrome = <Mode d'affichage>`
---

**`<Champ Image> : (Nom de champ)`**

Nom du champ Image à manipuler.  

**`<Mode d'affichage> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> pour activer la gestion du monochrome dans le champ Image, 

- <u><u><u><u>Faux</u></u></u></u> pour désactiver la gestion du monochrome.
