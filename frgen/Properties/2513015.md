
## ImageDéroulée (Propriété)

***En anglais : ExpandedImage***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ImageDéroulée** permet de : 

- connaître et/ou de modifier l'image par défaut d'une ligne déroulée dans un champ Table hiérarchique.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) connaître et/ou de modifier l'image par défaut d'une ligne déroulée dans un champ Arbre.

- connaître et/ou de modifier l'image d'une ligne spécifique déroulée dans un champ Table hiérarchique.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) connaître et/ou modifier l'image d'une ligne déroulée dans une rubrique hiérarchique d'un état de type "Tableau hiérarchique". 




Cette propriété permet par exemple de définir : 

- l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Table hiérarchique. Cette image sera prise en compte par les fonctions [TableAjoute](../WDLang1/3074017.md), [TableAjouteLigne](../WDLang1/3074006.md), [TableAjouteFils](../WDLang1/1000010004.md), [TableInsère](../WDLang1/3074025.md), [TableInsèreLigne](../WDLang1/3074026.md), [TableInsèreFils](../WDLang1/1000010005.md), ...

- l'image déroulée d'une des lignes du champ Table hiérarchique. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Arbre. Cette image sera prise en compte par les fonctions [ArbreAjoute](../WDLang1/3018012.md) et [ArbreInsère](../WDLang1/3018023.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) l'image déroulée des lignes d'un état de type "Tableau hiérarchique".





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définit l'image utilisée pour une ligne déroulée
TABLEH_Recette.ImageDéroulée = "C:\MesImages\Image.BMP"
```


<a name="Exemple2"></a>

```wl
// Change l'image déroulée de la ligne 4
TABLEH_Recette[4].ImageDéroulée = "C:\MesImages\Image.BMP"
```

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)

<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître l'image par défaut d'une ligne déroulée ou l'image associée à une ligne spécifique

`<Résultat> = <Champ manipulé>.ImageDéroulée`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom et chemin complet de l'image associée par défaut aux lignes déroulées du champ.

- Chaîne vide ("") si l'image utilisée par défaut n'a pas été modifiée.




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler : 

- Champ Table hiérarchique. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Champ Arbre.




Pour connaître l'image déroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante : 

```txt
<Champ Table hiérarchique>[<Numéro de la ligne>]
```



<a name="SYNTAXE2"></a>

### Modifier l'image par défaut d'une ligne déroulée ou l'image associée à une ligne spécifique

`<Champ manipulé>.ImageDéroulée = <Nouvelle image>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler : 

- Champ Table hiérarchique. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Champ Arbre.




Pour modifier l'image déroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante : 

```txt
<Champ Table hiérarchique>[<Numéro de la ligne>]
```


**`<Nouvelle image> : (Chaîne de caractères)`**

Nom et chemin complet de la nouvelle image associée par défaut à une ligne déroulée du champ Table hiérarchique.  

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Le chemin d'accès des images doit être relatif au répertoire "&lt;NomProjet&gt;_WEB". Par exemple, dans ce cas, l'image est dans un sous-répertoire "Images" du répertoire "_WEB" du site : 

```wl
MoiMême.ImageDéroulée = "\Images\Job_16.gif"
MoiMême.ImageEnroulée = "\Images\Job_16.gif"
```

### Connaître l'image d'une rubrique hiérarchique déroulée dans un état "Tableau hiérarchique"

`<Résultat> = <Rubrique hiérarchique>.ImageDéroulée`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom et chemin complet de l'image associée à une ligne déroulée de la rubrique hiérarchique. 

- Chaîne vide ("") si aucune image n'est utilisée.




**`<Rubrique hiérarchique> : (Chaîne de caractères)`**

Nom de la rubrique hiérarchique à manipuler.


<a name="SYNTAXE4"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) 
### Modifier l'image d'une rubrique hiérarchique déroulée dans un état "Tableau hiérarchique"

`<Rubrique hiérarchique>.ImageDéroulée = <Nouvelle image>`
---

**`<Rubrique hiérarchique> : (Chaîne de caractères)`**

Nom de la rubrique hiérarchique à manipuler.  

**`<Nouvelle image> : (Chaîne de caractères)`**

Nom et chemin complet de la nouvelle image associée à une ligne déroulée de la rubrique hiérarchique.
