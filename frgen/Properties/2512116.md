


## RépertoireSauvegardeJournal (Propriété)

***En anglais : LogBackupDirectory***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RépertoireSauvegardeJournal** permet de gérer le répertoire de sauvegarde des fichiers journal. Il est ainsi possible de:

- Connaître le répertoire de sauvegarde du journal pour une table définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir le répertoire de sauvegarde du journal pour une table (lors de la description de la table par programmation uniquement).




**Remarque**: Ce chemin est utilisé lors de la modification automatique des tables pour archiver les journaux. La fonction [HHistoriqueModification](../WDLang4/3044344.md) recherchera également l'historique des modifications dans ces fichiers.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définit le répertoire journal du fichier de données Commande
Commande.RépertoireSauvegardeJournal = "C:\MesFichiers\MesJournaux_SVG"
...
// Valide la description du fichier
HDécritTable(Commande)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire de sauvegarde du journal d'un fichier

`<Nom actuel> = <Table>.RépertoireSauvegardeJournal`
---

**`<Nom actuel> : (Chaîne de caractères)`**

Nom du répertoire de sauvegarde du fichier journal associé à la table. Par défaut, ce chemin correspond à: &lt;répertoire des fichiers JNL&gt;\\__JNLBackup. Si ce paramètre correspond à un chemin relatif (et commence par un point), le chemin sera relatif aux tables.

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir un répertoire de sauvegarde du journal pour un fichier créé par programmation

`<Table>.RépertoireSauvegardeJournal = <Nouveau nom>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom> : (Chaîne de caractères)`**

Chemin des sauvegarde des fichiers journaux correspondant à la table spécifiée. Par défaut, ce chemin correspond à: &lt;répertoire des fichiers JNL&gt;\\__JNLBackup. 
Si ce paramètre correspond à une chaîne vide (""), l'emplacement actuel n'est pas modifié. 
Si ce paramètre correspond à un chemin relatif (et commence par un point), le chemin sera relatif aux tables.
