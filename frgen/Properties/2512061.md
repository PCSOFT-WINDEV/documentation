


## NullSupporté (Propriété)

***En anglais : NullSupported***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NullSupporté** permet de gérer la valeur NULL dans des tables HFSQL.

Cette propriété permet de:

- Connaître le mode de gestion de la valeur NULL pour une table décrite sous l'éditeur de schémas des données.

- Définir que la valeur NULL va être gérée lors de la description d'une table par programmation.




**Remarque**: Si une table supporte la valeur NULL et si la rubrique autorise le NULL (propriété [NullAutorisé](../Proprietes/1000019492.md)), il sera possible d'utiliser la propriété [Null](../Proprietes/2512064.md) pour par exemple affecter NULL à la rubrique pour l'enregistrement en cours.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir la gestion de la valeur NULL dans la table Client
Client.NullSupporté = Vrai
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si la table permet la gestion de la valeur NULL

`<Résultat> = <Table>.NullSupporté`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier permet la gestion de la valeur NULL, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).

### Définir la gestion de la valeur NULL

`<Table>.NullSupporté = <Mode de gestion>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Mode de gestion> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> pour gérer la valeur NULL, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.

## Remarques


### Cas particulier: Vue et requête
<a name="cas_particulier_vue_requete_ELTPARAGRAPHE000083"></a>

La propriété **NullSupporté** utilisée sur une vue ou une requête renvoie <u><u><u><u>Vrai</u></u></u></u> si et seulement si au moins un des fichiers source supporte la gestion du NULL.


### Cas d'erreurs
<a name="cas_erreurs_ELTPARAGRAPHE000094"></a>

L'accès en écriture sur la propriété [Null](../Proprietes/2512064.md) échoue si la propriété **NullSupporté** a pour valeur <u><u><u><u>Faux</u></u></u></u>.

L'erreur 70409 ("Vous avez appelé la fonction [HModifie](../WDLang4/3044042.md). Le fichier &lt;XXXX&gt; ne supporte pas l'accès à la propriété Null. Veuillez activer la gestion du Null dans la description du fichier.") apparaît si les conditions suivantes sont réunies:

- une rubrique d'une requête ou d'une vue est mise à NULL,

- cette rubrique provient d'un fichier qui ne gère pas la valeur NULL

- la fonction [HModifie](../WDLang4/3044042.md) est utilisée sur la requête ou la vue.
