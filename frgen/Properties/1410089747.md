
## FlexColumnGap (Propriété)

***En anglais : FlexColumnGap***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FlexColumnGap** permet de connaître et de modifier la largeur de la gouttière qui sépare les colonnes d'un champ Flexbox. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Caractéristiques du champ Flexbox
FLEX_MaFlexbox.FlexDirection = fbdColonne
FLEX_MaFlexbox.FlexWrap = fbwRetourALaLigne
FLEX_MaFlexbox.FlexJustifyContent = fbjcCentré
FLEX_MaFlexbox.FlexAlignContent = fbacFin
FLEX_MaFlexbox.FlexAlignItems = fbaiCentré
FLEX_MaFlexbox.FlexColumnGap = 5
FLEX_MaFlexbox.FlexRowGap = 50
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître l'espace entre les colonnes d'un champ Flexbox

`<Résultat> = <Champ manipulé>.FlexColumnGap`
---

**`<Résultat> : (Entier)`**

Largeur en pixels de la gouttière qui sépare les colonnes d'un champ Flexbox. 

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 


<a name="SYNTAXE2"></a>

### Modifier l'espace entre les colonnes d'un champ Flexbox

`<Champ manipulé>.FlexColumnGap = <Nouvelle largeur>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 

**`<Nouvelle largeur> : (Entier)`**

Nouvelle largeur en pixels de la gouttière qui sépare les colonnes d'un champ Flexbox.
