
## PlanActif (Propriété)

***En anglais : ActivePlane***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **PlanActif** permet de connaître et de modifier le numéro du plan actif dans une fenêtre, une fenêtre interne ou un champ Cellule.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Cette propriété est disponible uniquement pour les champ Cellule.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Afficher uniquement les champs de la cellule présents sur le plan 1
CELL_Détail.PlanActif = 1
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître le numéro du plan actif

`<Résultat> = <Elément manipulé>.PlanActif`
---

**`<Résultat> : (Entier)`**

Numéro du plan actif dans l'élément spécifié. 

**`<Elément manipulé> : (Nom de champ ou nom de fenêtre)`**

Nom de l'élément manipulé. Cet élément peut correspondre : 

- au nom d'un champ Cellule. 

- au nom d'une fenêtre. 

- au nom d'une fenêtre interne. 





<a name="SYNTAXE2"></a>

### Modifier le numéro du plan actif

`<Elément manipulé>.PlanActif = <Plan actif>`
---

**`<Elément manipulé> : (Nom de champ ou nom de fenêtre)`**

Nom de l'élément manipulé. Cet élément peut correspondre : 

- au nom d'un champ Cellule. 

- au nom d'une fenêtre. 

- au nom d'une fenêtre interne. 




**`<Plan actif> : (Entier)`**

Numéro du plan à activer dans l'élément spécifié. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Seuls les champs présents sur le plan spécifié selon visibles. 

- Pour les fenêtres et les fenêtres internes, cette propriété est équivalente à la propriété [Plan](../Proprietes/2510094.md). 

- Pour les champs Cellule : 

	- la propriété [Plan](../Proprietes/2510094.md) permet d'obtenir le plan du champ Cellule par rapport à son parent. 

	- la propriété **PlanActif** permet de connaître et de définir le plan utilisé pour les champs contenus dans le champ Cellule.
