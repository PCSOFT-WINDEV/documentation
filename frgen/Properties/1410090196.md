
## DuréeAnimation (Propriété)

***En anglais : AnimationDuration***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **DuréeAnimation** permet de définir la durée d'une animation. Cette propriété est utilisable sur :

- un champ. Pour plus de détails, consultez l'aide de la propriété [DuréeAnimation](../Proprietes/1000021069.md). 

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
