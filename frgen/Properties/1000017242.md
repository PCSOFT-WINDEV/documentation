
## Contenu (Propriété)

***En anglais : Content***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Contenu** permet de lire ou écrire d'un bloc le contenu d'un champ: 

- Liste par programmation,

- Combo par programmation,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Tableur.


Il est ainsi possible de lire ou écrire en une seule ligne de code l'ensemble des lignes du champ.

**Remarque**: Sur un champ liste liée aux données ou un champ combo lié aux données, il est uniquement possible de lire la liste des éléments.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La propriété **Contenu** peut également être utilisée sur un champ Upload pour connaître la liste des fichiers uploadés. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute des éléments au contenu actuel du champ Liste
LISTE_Liste1.Contenu = LISTE_Liste1.Contenu + RC + "Florence" + RC + "Emma"
```




<a name="Exemple2"></a>


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
n est un entier
// Ajout de la ligne dans le champ Table (la colonne combo étant la 2ème)
n = TableAjouteLigne(TABLE_Table1, "1", "p2")
// Modification du contenu de la colonne Combo pour la ligne ajoutée 
// Note: On utilise des valeurs de retour par gValeurMémorisée, 
// il faut donc activer cette option dans la description de la colonne
TABLE_Table1.COL_Combo[n].Contenu = "poste 1" + gValeurMémorisée("p1") + RC + ...
			"poste 2" + gValeurMémorisée("p2")
```

## Syntaxe

### Connaître le contenu d'un champ Liste (ou Combo) par programmation ou d'un champ Tableur

`<Contenu du champ> = <Champ manipulé>.Contenu`
---

**`<Contenu du champ> : (Chaîne de caractères)`**

Liste des éléments pour le contenu du champ. Chaque élément est séparé par le caractère RC.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pour un champ Tableur, contenu du champ sous forme binaire. Ce contenu peut être sauvegardé à l'aide de la fonction [fSauveBuffer](../WDLang1/1000019412.md). 

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ doit être: 

- un champ Liste par programmation, 

- un champ Combo par programmation,

- une colonne de table "Liste de valeurs",

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) un champ Upload. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Tableur.





<a name="SYNTAXE2"></a>

### Modifier le contenu d'un champ Liste (ou Combo) par programmation ou d'un champ Tableur

`<Champ manipulé>.Contenu = <Contenu du champ>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ doit être: 

- un champ Liste par programmation, 

- un champ Combo par programmation,

- une colonne de table "Liste de valeurs", 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Tableur.




**`<Contenu du champ> : (Chaîne de caractères)`**

Liste des éléments affichés dans le champ. Chaque élément est séparé par le caractère RC.  

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pour un champ Tableur, contenu binaire à afficher dans le champ. Il est possible d'utiliser la fonction [fChargeBuffer](../WDLang1/1000019410.md).

### Champ Upload
<a name="champ_upload_ELTPARAGRAPHE000114"></a>

La propriété **Contenu** permet de connaître la liste des fichiers sélectionnés dans un champ Upload multifichier. Les différents noms de fichiers sont séparés par des RC (Retour Chariot). Dans le cas d'un champ Upload monofichier, seul le nom du fichier sélectionné est renvoyé. 

Le nom des fichiers correspond au chemin et nom du fichier temporaire uploadé. Par exemple: C\\WebDep\\Temp\\Fichier.upl
Cette propriété doit être utilisée dans l'événement "Réception des fichiers uploadés". Dans les autres cas, cette propriété renvoie une chaîne vide. 

Cette propriété est équivalente à la propriété [Valeur](../Proprietes/2510130.md). 
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Champ Tableur
<a name="champ_tableur_ELTPARAGRAPHE000138"></a>

La propriété **Contenu** permet de connaître et de modifier le contenu binaire du champ Tableur. Par exemple: 

```wl
TBLR_Defilé.Contenu = fChargeBuffer(fRepExe()+"\Défilé Haute Couture.xls")
```


Cette propriété est équivalente à la propriété [Valeur](../Proprietes/2510130.md).
