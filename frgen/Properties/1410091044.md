
## ParamètresOuverture (Propriété)

***En anglais : OpeningParameters***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ParamètresOuverture** permet de connaître et de spécifier : 

- les paramètres passés à la fenêtre interne correspondant à la fenêtre coulissante basse.
	

- les paramètres passés à une fenêtre manipulée par son type. 
	



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

**Exemple pour les fenêtres coulissantes basses :**

```wl
MaFenêtreCoulissanteBasse.SurInvisibilité = () => { Trace("La fenêtre coulissante basse a disparue") }
MaFenêtreCoulissanteBasse.ParamètresOuverture = (42, "Adams")
MaFenêtreCoulissanteBasse.FenêtreInterne = "FI_Menu_Coulissant"
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurEtendue = 0.9 // 90% 
MaFenêtreCoulissanteBasse.Modale = Vrai
MaFenêtreCoulissanteBasse.Masquable = Vrai
MaFenêtreCoulissanteBasse.CoinArrondi = Faux

// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```
<a name="Exemple2"></a>


**Exemple pour les variables de gestion des fenêtres :**

```wl
// -- Déclarations globales de FEN_Calendrier 
PROCÉDURE FEN_Calendrier(sDateSel)
//  sDateSel : date à sélectionner
```

```wl
Ma_fen_Calendrier est une Fenêtre FEN_Calendrier
// Passage de paramètres
Ma_fen_Calendrier.ParamètresOuverture.sDateSel = DateDuJour()
// Ouverture de la fenêtre
Ma_fen_Calendrier.Ouvre()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Fenêtre coulissante basse : Connaître la valeur des paramètres 

`<Résultat> = <Fenêtre coulissante>.ParamètresOuverture`
---

**`<Résultat> : (Tuple de valeurs)`**

Tuple de valeurs correspondant aux différentes valeurs passées à la fenêtre interne utilisée comme fenêtre coulissante basse. 

**`<Fenêtre coulissante> : (MaFenêtreCoulissanteBasse)`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.


<a name="SYNTAXE2"></a>

### Fenêtre coulissante basse : Spécifier la valeur des paramètres

`<Fenêtre coulissante>.ParamètresOuverture = <Nouvelles valeurs>`
---

**`<Fenêtre coulissante> : ()`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.

**`<Nouvelles valeurs> : (Tuple de valeurs)`**

Tuple des valeurs des paramètres à passer à la fenêtre interne correspondant à la fenêtre coulissante basse. 


<a name="SYNTAXE1B"></a>

### Variable fenêtre : Connaître la valeur des paramètres passés à la fenêtre 

`<Résultat> = <Fenêtre manipulée>.ParamètresOuverture.<Nom du paramètre>`
---

**`<Résultat> : (Type correspondant à la valeur du paramètre)`**

Valeur du paramètre. 

**`<Fenêtre manipulée> : (Variable Fenêtre)`**

Nom de la variable de type [Fenêtre](../WDLang1/1410091366.md) correspondant à la fenêtre manipulée. 

**`<Nom du paramètre> : (Chaîne de caractères)`**

Nom du paramètre de la fenêtre dont la valeur doit être connue. 


<a name="SYNTAXE2B"></a>

### Variable fenêtre : Spécifier la valeur des paramètres passés à la fenêtre 

`<Fenêtre manipulée>.ParamètresOuverture.<Nom du paramètre> = <Valeur>`
---

**`<Fenêtre manipulée> : (Variable Fenêtre)`**

Nom de la variable de type [Fenêtre](../WDLang1/1410091366.md) correspondant à la fenêtre manipulée.  

**`<Nom du paramètre> : (Chaîne de caractères)`**

Nom du paramètre de la fenêtre dont la valeur doit être connue.

**`<Valeur> : (Type correspondant à la valeur du paramètre)`**

Nouvelle valeur du paramètre.

## Remarques


### Syntaxe manipulant une fenêtre interne
<a name="syntaxe_manipulant_une_fenetre_interne_ELTPARAGRAPHE000095"></a>

- La propriété **ParamètresOuverture** doit être affectée avant la propriété [FenêtreInterne](../Proprietes/1410089635.md).

- La fenêtre interne sera créée lors de l'affectation d'une nouvelle valeur à la propriété [FenêtreInterne](../Proprietes/1410089635.md).





### Syntaxe manipulant une variable fenêtre
<a name="syntaxe_manipulant_une_variable_fenetre_ELTPARAGRAPHE000110"></a>

- La propriété **ParamètresOuverture** doit être affectée avant l'ouverture de la fenêtre. 

- Après l'ouverture de la fenêtre, la propriété **ParamètresOuverture** est vidée. 

- Après la fermeture de la fenêtre, la propriété **ParamètresOuverture** permet de préparer une prochaine ouverture de la fenêtre.
