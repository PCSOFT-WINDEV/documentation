
## LuminositeAuto

***En anglais : BrightnessModify***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **LuminositéAuto** est utilisé pour gérer la luminosité sur un périphérique Android ou iOS. Ce mot-clé peut correspondre à : 

- la fonction [LuminositéAuto](../WDLang3/1000020182.md). 

- la constante *luminositéAuto* utilisable avec la fonction [LuminositéModifie](../WDLang3/1000020170.md).
