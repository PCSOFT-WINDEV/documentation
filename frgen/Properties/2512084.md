


## RépertoireRéplication (Propriété)

***En anglais : ReplicationDirectory***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RépertoireRéplication** permet de gérer le répertoire du réplica (fichier ".rpl" ou ".rpm"). Il est ainsi possible de:

- Connaître le répertoire du réplica pour une table définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir le répertoire du réplica lors de la description par programmation d'une table.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Répertoire du réplica de la table Client
Info(Client.RépertoireRéplication)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire du réplica d'une table

`<Répertoire actuel> = <Table>.RépertoireRéplication`
---

**`<Répertoire actuel> : (Chaîne de caractères)`**



- Nom du répertoire du réplica de la table spécifiée,

- "." si le répertoire correspond au répertoire en cours.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le répertoire du réplica lors de la description par programmation d'une table

`<Table>.RépertoireRéplication = <Nouveau répertoire>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau répertoire> : (Chaîne de caractères)`**

Nom du répertoire du réplica.
