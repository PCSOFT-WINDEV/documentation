


## NuméroGénération (Propriété)

***En anglais : GenerationNumber***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NuméroGénération** permet de connaître le numéro de génération de la table physique associée à la table logique spécifiée.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le numéro de génération de la table Client
ResNumGénération = Client.NuméroGénération
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Table>.NuméroGénération`
---

**`<Résultat> : (Entier)`**

Numéro de génération de la table physique actuellement associée à la table logique spécifiée.

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée.
