


## RépertoireJournalOpération (Propriété)

***En anglais : OperationLogDirectory***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RépertoireJournalOpération** permet de gérer le répertoire de la table des opérations du journal associé à une table journalée. Il est ainsi possible de:

- Connaître le répertoire du journal des opérations lié à une table journalée définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir le répertoire du journal des opérations pour une table (lors de la description de la table par programmation).




**Rappel**: La table des opérations du journal (JournalOpération.fic) et la table d'identification des tables journalées (journalIdentification.fic) ne sont pas créées par défaut lors de la journalisation d'une table. Ces tables sont automatiquement créées lors de la journalisation en lecture d'une table ou lors de la mise en réplication d'une table.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définit le répertoire du journal des opérations
// pour le fichier de données Commande (décrit par programmation)
Commande.RépertoireJournalOpération = "C:\MesFichiers\Opérations"
...
// Valide la description de la table
HDécritTable(Commande)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire du fichier des opérations d'une table journalée

`<Répertoire actuel> = <Table>.RépertoireJournalOpération`
---

**`<Répertoire actuel> : (Chaîne de caractères)`**



- Nom du répertoire du fichier "JournalOpération.fic" associé à la table journalée, 

- "." si le répertoire correspond au répertoire en cours.




**`<Table> : (Chaîne de caractères)`**

Nom (logique) de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le répertoire du fichier des opérations pour une table journalée décrite par programmation

`<Table>.RépertoireJournalOpération = <Nouveau répertoire>`
---

**`<Table> : (Chaîne de caractères)`**

Nom (logique) de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau répertoire> : (Chaîne de caractères)`**

Nom du répertoire de la table "JournalOpération.fic" associée à la table journalée.
