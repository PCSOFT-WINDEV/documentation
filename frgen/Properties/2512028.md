


## CompressionMmo (Propriété)

***En anglais : MmoPackMethod***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CompressionMmo** permet de paramétrer le mode de compression de la table MMO (contenant les mémo binaires et texte) associée à la table. Il est ainsi possible de:

- connaître le mode de compression d'une table mémo (table définie sous l'éditeur de schémas des données ou définie par programmation).

- modifier le mode de compression des mémos (table définie par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Description par programmation d'un fichier de données
UnFichier est une Description de Fichier
// Modification du mode de compression de cette table
UnFichier.CompressionMmo = hCompressionZLW
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le mode de compression des mémos

`<Compression actuelle> = <Table>.CompressionMmo`
---

**`<Compression actuelle> : (Constante de type entier)`**

Les deux modes de compression sont:



|   |   |
| --- | --- |
| *hCompressionNon* | Aucune compression du fichier mémo n'est effectuée. |
| *hCompressionZLW* | Le fichier mémo est compressé selon l'algorithme de Ziw-Lempel, implémentation de Welch. |



**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le mode de compression des mémos

`<Table>.CompressionMmo = <Nouveau mode de compression>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau mode de compression> : (Constante de type entier)`**

Les deux modes de compression sont:



|   |   |
| --- | --- |
| *hCompressionNon* | Aucune compression du fichier mémo n'est effectuée. |
| *hCompressionZLW* | Le fichier mémo est compressé selon l'algorithme de Ziw-Lempel, implémentation de Welch. |
