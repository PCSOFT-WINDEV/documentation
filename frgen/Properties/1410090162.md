
## Effet (Propriété)

***En anglais : Effect***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Effet** permet de connaître et définir l'effet appliqué sur les champs. 

Cette propriété est disponible :

- pour définir l'effet d'affichage à utiliser pour mettre en évidence le ou les champ(s) cible(s) pour l'étape de la visite guidée. Cette propriété est utilisable sur :

	- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

	- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) pour définir et connaître les caractéristiques du floutage effectué sur un champ. Pour plus de détails, consultez l'aide sur la propriété [Effet](../Proprietes/1410090859.md).
