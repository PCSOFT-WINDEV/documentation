
## Contour (Propriété)

***En anglais : Outline***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Contour** permet de définir le contour d'un polygone. Ce contour correspond à une polyligne simple et fermée. Cette propriété est disponible sur : 

- une variable de type [Polygone2D](../WDLang4/1410090122.md). 

- une variable de type [PolygoneGéo](../WDLang4/1410090127.md).
