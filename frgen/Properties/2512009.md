


## Abréviation (Propriété)

***En anglais : Abbreviation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Abréviation** permet d'obtenir l'abréviation de la table. Cette abréviation a été définie sous l'éditeur de schémas des données lors de la description de la table. Cette propriété est utilisable en lecture uniquement.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Abréviation de la table Commande
ResAbréviation = Commande.Abréviation
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Abréviation de la table> = <Table>.Abréviation`
---

**`<Abréviation de la table> : (Chaîne de caractères)`**

Deux lettres permettant d'identifier l'abréviation de la table.

**`<Table> : (Chaîne de caractères)`**

Nom de la table à manipuler.
