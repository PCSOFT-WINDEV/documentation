
## InformationClé (Propriété)

***En anglais : KeyInformation***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **InformationClé** permet de définir des informations sur la clé utilisée. Cette propriété est utilisable sur : 

- une variable de type [xmlSignature](../WDLang5/1000020736.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) une variable de type [xmlSignatureXAdES](../WDLang5/1410091158.md).
