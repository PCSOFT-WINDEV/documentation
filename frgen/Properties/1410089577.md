
## Cryptage (Propriété)

***En anglais : Encryption***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Cryptage** permet de connaître et de modifier le type de cryptage utilisé. Cette propriété est utilisable sur :

- une connexion HFSQL Client/Serveur. Pour plus de détails, consultez [Cryptage](../Proprietes/2512102.md).
