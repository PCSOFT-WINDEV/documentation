
## Exécutable (Propriété)

***En anglais : Executable***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Exécutable** permet de connaître et de modifier l'exécutable à manipuler. Cette propriété est utilisée par :

- une variable de type [Processus](../WDLang1/1000018696.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) une variable de type [Commande](../WDLang1/1410090491.md).
