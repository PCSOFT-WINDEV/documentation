


## RepeatableReadSupporté (Propriété)

***En anglais : RepeatableReadSupported***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RepeatableReadSupporté** permet de: 

- Savoir si la table (définie sous l'éditeur de schémas des données ou par programmation) peut être utilisée en HFSQL Client/Serveur dans une transaction ayant un mode d'isolation "REPEATABLE READ".

- Autoriser l'utilisation d'une transaction ayant un mode d'isolation "REPEATABLE READ" pour une table (lors de la description de la table par programmation uniquement).




Attention: si cette option est activée, la table est incompatible avec les versions 18 et antérieures.

Cette propriété correspond à l'option "Autoriser les transactions REPEATABLE READ", disponible dans l'onglet "Options" de la fenêtre de description de la table dans le schéma des données. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=RepeatableReadSupport%E9%20-%20HC%20N%B0001.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI Client.RepeatableReadSupporté = Faux ALORS Info("Utilisation du mode Repeatable Read impossible")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si la table est utilisable en mode "REPEATABLE READ" 

`<Résultat> = <Table>.RepeatableReadSupporté`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table peut être utilisée en mode "REPEATABLE READ",

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  




**`<Table> : (Nom de table)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir si la table est utilisable en mode "REPEATABLE READ"

`<Table>.RepeatableReadSupporté = <Mode "REPEATABLE READ">`
---

**`<Table> : (Nom de table)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Mode "REPEATABLE READ"> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table peut être utilisée en mode "REPEATABLE READ",

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.
