


## RubriqueAffichée (Propriété)

***En anglais : DisplayedItem***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RubriqueAffichée** permet de:

- Connaître la rubrique ou la variable affichée par le champ.

- Modifier la rubrique ou la variable affichée par le champ.




**Remarques**:

- **Utilisée dans l'événement "Ouverture" de l'état**, cette propriété permet de modifier la rubrique affichée dans un champ lorsque la source de données de l'état a été modifiée par programmation (avec la propriété [NomSource](../Proprietes/2511035.md) par exemple).

- **Si cette propriété est utilisée dans l'événement "Avant impression" du champ**, le changement ne sera effectué qu'à la prochaine impression du champ (en effet, la valeur de la rubrique est déjà lue lors de l'exécution de l'événement "Avant impression" du champ).

- La rubrique affichée peut provenir d'une table, d'une vue ou d'une requête.

- La rubrique mémorisée ou la variable mémorisée est définie sous l'éditeur de fenêtres ou pages dans l'onglet "Contenu" de la description du champ.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Pour un champ Liste image, cette rubrique correspond au libellé affiché dans le champ Liste image.

### Connaître la rubrique / variable affichée par un champ Table, Liste ou Combo

`<Rubrique / variable actuellement affichée> = <Champ manipulé>.RubriqueAffichée`
---

**`<Rubrique / variable actuellement affichée> : (Chaîne de caractères)`**



- Nom de la rubrique affichée par le champ spécifié. Cette rubrique appartient à la table parcourue par le champ (connu ou modifié grâce à la propriété [TableParcourue](../Proprietes/2510040.md)).

- Nom de la variable affichée par le champ spécifié. Ce nom est de la forme: 
	
	```txt
	":<préfixe><Nom de la variable>"
	```
 ou 
	```txt
	":<Nom de la variable>"
	```
(le préfixe est présent uniquement si la charte de programmation est activée dans le projet).
	Cette variable appartient à la variable parcourue par le champ (connu ou modifié grâce à la propriété [TableParcourue](../Proprietes/2510040.md)).

- Dans le cas d'un champ Table, liste des noms des rubriques ou des variables affichées par chaque colonne du champ Table. Les noms des rubriques / variables sont séparés par le caractère "|" (combinaison de touches AltGr + 6).




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler: Table, Liste, Liste image ou Combo.

### Modifier la rubrique / variable affichée par un champ Table, Liste ou Combo

`<Champ manipulé>.RubriqueAffichée = <Nouvelle rubrique / variable>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler: Table, Liste, Liste image ou Combo.  

**`<Nouvelle rubrique / variable> : (Chaîne de caractères)`**



- Nom de la rubrique à afficher dans le champ spécifié. Cette rubrique appartient à la table parcourue par le champ (connu ou modifié grâce à la propriété [TableParcourue](../Proprietes/2510040.md)).

- Nom de la variable à afficher dans le champ spécifié. Ce nom est de la forme: 
	
	```txt
	":<préfixe><Nom de la variable>"
	```
 ou 
	```txt
	":<Nom de la variable>"
	```
Le préfixe doit être précisé si la charte de programmation est activée dans le projet (que les préfixes soient affichés ou non).
	Cette variable appartient à la variable parcourue par le champ (connu ou modifié grâce à la propriété [TableParcourue](../Proprietes/2510040.md)).

- Dans le cas d'un champ Table, liste des noms des rubriques ou des variables affichées par chaque colonne du champ Table. Les noms des rubriques / variables sont séparés par le caractère "|" (combinaison de touches AltGr + 6).

### Connaître la rubrique affichée par un champ de l'état

`<Rubrique actuellement affichée> = <Champ manipulé>.RubriqueAffichée`
---

**`<Rubrique actuellement affichée> : (Chaîne de caractères)`**

Nom de la rubrique associée au champ spécifié. Pour une liaison multifichier, le nom de la rubrique est du type: 

```txt
<Nom Fichier de données 1>.<Nom de la rubrique> + TAB + <Nom Fichier de données 2>.<Nom de la rubrique>
```
Cette rubrique correspond:

- soit à une rubrique appartenant à la table source de l'état (connue ou modifiée grâce à la propriété [NomSource](../Proprietes/2511035.md)).

- soit à une rubrique (ou à son alias) appartenant à la requête source de données de l'état.




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ de l'état à manipuler.

Dans un état, ce champ peut être:

- un champ Image,

- un champ Code-barres,

- un champ Libellé de type RTF,

- un champ Libellé,

- un champ Interrupteur,

- un champ Calculé.

- un champ Tableur

### Modifier la rubrique affichée par un champ de l'état

`<Champ manipulé>.RubriqueAffichée = <Nouvelle rubrique>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ de l'état à manipuler.

Dans un état, ce champ peut être:

- un champ Image,

- un champ Code-barres,

- un champ Libellé de type RTF,

- un champ Libellé,

- un champ Interrupteur,

- un champ Calculé.

- un champ Tableur




**`<Nouvelle rubrique> : (Chaîne de caractères)`**

Nom de la nouvelle rubrique associée au champ spécifié. Pour une liaison multifichier, le nom de la rubrique est du type: 
```txt
<Nom Fichier1>.<Nom de la rubrique> + TAB + <Nom Fichier2>.<Nom de la rubrique>
```
 Cette rubrique correspond:

- soit à une rubrique appartenant à la table source de l'état (connue ou modifiée grâce à la propriété [NomSource](../Proprietes/2511035.md)).

- soit à une rubrique (ou à son alias) appartenant à la requête source de données de l'état.

### Manipuler des champs Table liée aux données, Zone répétée liée aux données, Liste liée aux données (y compris Liste image) et Combo liée aux données grâce aux propriétés
<a name="manipuler_des_champs_table_liee_aux_donnees_zone_repetee_liee_aux_donnees_liste_liee_aux_donnees_compris_liste_image_combo_liee_aux_donnees_grace_aux_proprietes_ELTPARAGRAPHE000199"></a>

- Les enregistrements affichés dans un champ Liste, Table, Zone répétée ou combo liée aux données proviennent de la table ou de la requête spécifiée avec la propriété [TableParcourue](../Proprietes/2510040.md).

- Le sens de tri est fixé par la propriété [RubriqueParcourue](../Proprietes/2510111.md).

- Un filtrage des enregistrements peut être réalisé avec la propriété [Filtre](../Proprietes/2510042.md) ou la fonction [HFiltre](../WDLang4/3044100.md).

### Modifier la rubrique affichée dans les champs Table par programmation, Table liée aux données et Table sur variable
<a name="modifier_rubrique_affichee_dans_les_champs_table_par_programmation_table_liee_aux_donnees_table_sur_variable_ELTPARAGRAPHE000222"></a>

Si le paramètre &lt;Nouvelle rubrique / variable&gt; contient:

- Un nombre de rubriques supérieur au nombre de colonnes du champ Table, seules les premières rubriques (ou variables) sont associées aux colonnes existantes du champ Table.

- Un nombre de rubriques inférieur au nombre de colonnes du champ Table, les colonnes "supplémentaires" ne sont associées à aucune rubrique (ou variable).




**Remarque**: Pour associer une colonne avec une rubrique ou une variable, utilisez la propriété [LiaisonDonnées](../Proprietes/2510060.md).

### Champ Table par programmation
<a name="champ_table_par_programmation_ELTPARAGRAPHE000239"></a>

Si un champ Table par programmation doit afficher des données provenant d'une table, d'une requête ou d'une vue:

- Créez un champ Table par programmation sous l'éditeur de fenêtres.

- Dans votre programme, indiquez la rubrique à parcourir avec la propriété [RubriqueParcourue](../Proprietes/2510111.md). Cette rubrique doit appartenir à la table, à la requête ou à la vue dont les données seront affichées dans le champ Table par programmation.

- Utilisez la fonction [FichierVersTableMémoire](../WDLang1/3074005.md) pour initialiser le champ Table avec les données voulues. Les données seront triées selon la rubrique parcourue spécifiée.

- La propriété **RubriqueAffichée** sera automatiquement initialisée.

### Champ Liste par programmation
<a name="champ_liste_par_programmation_ELTPARAGRAPHE000261"></a>

Si un champ Liste par programmation ou Combo par programmation doit afficher des données provenant d'une table, d'une requête ou d'une vue:

- Créez un champ Liste ou Combo par programmation sous l'éditeur de fenêtres.

- Utilisez la fonction [FichierVersListeMémoire](../WDLang1/3049007.md) pour initialiser le champ Liste ou Combo avec les données voulues.

- Les propriétés [TableParcourue](../Proprietes/2510040.md), **RubriqueAffichée**, [RubriqueParcourue](../Proprietes/2510111.md) et [RubriqueMémorisée](../Proprietes/2510110.md) seront automatiquement initialisées.

### Champ Liste image
<a name="champ_liste_image_ELTPARAGRAPHE000288"></a>

Dans le cas d'un champ Liste image, la propriété **RubriqueAffichée** permet de connaître et de modifier uniquement la rubrique correspondant aux libellés des éléments affichés dans le champ.

Pour connaître et modifier la rubrique correspondant aux images affichées dans le champ, utilisez la propriété [RubriqueAffichéeImage](../Proprietes/2510109.md).
