


## RépertoireJournal (Propriété)

***En anglais : LogDirectory***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RépertoireJournal** permet de gérer le répertoire du fichier journal décrit dans le schéma des données. Il est ainsi possible de:

- Connaître le répertoire du journal pour une table définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir le répertoire du journal pour une table (lors de la description de la table par programmation uniquement).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir le répertoire journal du fichier de données Commande défini par programmation
Commande.RépertoireJournal = "C:\MesFichiers\MesJournaux"
...
// Valide la description de la table
HDécritTable(Commande)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire du journal d'une table

`<Nom actuel> = <Table>.RépertoireJournal`
---

**`<Nom actuel> : (Chaîne de caractères)`**



- Nom du répertoire du fichier journal associé à la table,

- "." si le répertoire correspond au répertoire des tables en cours.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir un répertoire de journal pour un fichier défini par programmation

`<Table>.RépertoireJournal = <Nouveau nom>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom> : (Chaîne de caractères)`**

Nom du répertoire du journal.
