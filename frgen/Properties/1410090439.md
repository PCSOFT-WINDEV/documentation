
## SaisieInvalide (Propriété)

***En anglais : InvalidInput***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **SaisieInvalide** permet de connaître et modifier la caractéristique de saisie invalide d'un champ. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI m_bCompteCritique ALORS
	SAI_MotDePasse.SaisieInvalide = saisieInvalideNonBloquante
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Savoir si la saisie invalide est activée ou non sur un champ

`<Résultat> = <Champ manipulé>.SaisieInvalide`
---

**`<Résultat> : (Constante de type Entier)`**

Mode de gestion de la saisie invalide : 


|   |   |
| --- | --- |
| *saisieInvalideBloquante* | Le contrôle de la validité de la saisie est bloquant : si la saisie ne correspond pas au masque de saisie attendu, l'utilisateur ne peut pas sortir du champ. |
| *saisieInvalideNonBloquante* | Le contrôle de la validité de la saisie est non bloquant : si la saisie ne correspond pas au masque de saisie attendu, l'utilisateur peut continuer sa saisie. |
| *saisieInvalideRien* | La saisie invalide n'est pas définie pour le champ. |



**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ de saisie, 

- un champ Combo. 





<a name="SYNTAXE2"></a>

### Activer ou non la saisie invalide sur un champ

`<Champ manipulé>.SaisieInvalide = <Saisie invalide>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ de saisie, 

- un champ Combo. 




**`<Saisie invalide> : (Constante de type Entier)`**

Nouveau mode de gestion de la saisie invalide : 


|   |   |
| --- | --- |
| *saisieInvalideBloquante* | Le contrôle de la validité de la saisie est bloquant : si la saisie ne correspond pas au masque de saisie attendu, l'utilisateur ne peut pas sortir du champ. |
| *saisieInvalideNonBloquante* | Le contrôle de la validité de la saisie est non bloquant : si la saisie ne correspond pas au masque de saisie attendu, l'utilisateur peut continuer sa saisie. |
| *saisieInvalideRien* | La saisie invalide n'est pas définie pour le champ. |
