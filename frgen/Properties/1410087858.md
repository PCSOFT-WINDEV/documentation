
## Qualité (Propriété)

***En anglais : Quality***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Qualité** permet de connaître et de définir le niveau de qualité d'un élément. Cette propriété est utilisable sur : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [VoixDeSynthèse](../WDLang3/1000025986.md). 

- une variable de type [pdfParamètre](../WDLang6/1410087857.md).
