
## Markdown (Propriété)

***En anglais : Markdown***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Markdown** permet de gérer le markdown dans les champs d'une fenêtre ou d'un état. 

**Pour les champs d'une fenêtre**, la propriété **Markdown** permet de gérer l'option "Support du Markdown" (option présente dans l'onglet "UI" de la fenêtre de description du champ). Si cette option est activée, le rendu Markdown s'applique uniquement aux éléments suivants du champ :

- libellé,

- bulle d'aide,

- jetons associés (pour un champ de saisie).




**Pour le champ Libellé d'un état**, la propriété **Markdown** permet de :  

- savoir si un champ Libellé d'un état est de type Markdown ou non. 

- modifier le type d'un champ Libellé présent dans un état pour qu'il devienne un libellé de type Markdown. 




- Remarque : Le type Markdown est une option des champs Libellé d'un état. Cette option est située dans l'onglet "Général" de la description du champ.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Si le champ Libellé "LIB_Nom" est de type Markdown, il devient visible
SI LIB_Nom.Markdown = Vrai ALORS
	LIB_Nom.Visible = Vrai
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si la gestion du Markdown est activée pour un champ d'une fenêtre

`<Résultat> = <Champ manipulé>.Markdown`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié gère le Markdown, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ manipulé> : (Nom de champ)`**

Champ d'une fenêtre. 


<a name="SYNTAXE2"></a>

### Modifier la gestion du Markdown pour un champ d'une fenêtre

`<Champ manipulé>.Markdown = <Type>`
---

**`<Champ manipulé> : (Nom de champ)`**

Champ d'une fenêtre. 

**`<Type> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié doit gérer le Markdown, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  





<a name="SYNTAXE3"></a>

### Savoir si le champ Libellé d'un état est de type Markdown

`<Résultat> = <Champ Libellé>.Markdown`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié est de type Markdown, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ Libellé> : (Nom de champ)`**

Champ Libellé d'un état. 


<a name="SYNTAXE4"></a>

### Modifier le type Markdown d'un champ Libellé d'un état

`<Champ Libellé>.Markdown = <Type>`
---

**`<Champ Libellé> : (Nom de champ)`**

Champ Libellé d'un état. 

**`<Type> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié doit être de type Markdown, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.

## Remarques


### Cas particulier : Champ de saisie
<a name="cas_particulier_champ_saisie_ELTPARAGRAPHE000100"></a>Le champ de saisie comme tous les autres champs peut supporter le Markdown. Pour que le contenu affiché par le champ de saisie soit au format Markdown, il est nécessaire d'utiliser un champ de saisie de type "Visualisation Markdown". Pour plus de détails, consultez [Gestion du Markdown](../Editeurs/9000210.md).
