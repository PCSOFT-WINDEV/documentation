
## Procédure

***En anglais : Procedure***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Procédure** peut correspondre à :

- la propriété **Procédure** utilisée sur : 

	- une variable de  type [hTâchePlanifiée](../WDLang4/1000017448.md).

	- une variable de type [rssFlux](../WDLang5/1000017795.md).

	- une variable de type [rssCloud](../WDLang5/1000017785.md).

	- une variable de type [Description de procédure](../WDLang1/1000019317.md).

	- une variable de type [Définition](../WDLang1/1000019540.md).

	- une variable de type [httpAvancement](../WDLang3/1000021222.md). 

	- une variable de type [Description de TâcheParallèle](../WDLang1/1000021586.md).

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [serveurAppliTâchePlanifiée](../WDLang2/1000022367.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une variable de type [ActionRapide](../WDLang3/1410090054.md).




- une variable de type [Procédure](../Motscles/1000018907.md).
