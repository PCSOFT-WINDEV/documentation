
## EtapePrécédente (Propriété)

***En anglais : Previous***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **EtapePrécédente** permet d'autoriser ou non le passage à l'étape précédente de la visite guidée depuis la bulle de l'étape. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
