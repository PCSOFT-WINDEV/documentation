


## MotDePasseWDD55 (Propriété)

***En anglais : WDD55Password***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **MotDePasseWDD55** permet de spécifier le mot de passe du schéma des données au format 5.5 lors de la description par programmation d'une table au format Hyper File 5.5 dans un schéma des données au format HFSQL Classic.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définit le mot de passe associé au schéma des données 
// contenant la table Client
Client.MotDePasseWDD55 = "MotDePasse"
...
// Valide la description du fichier
HDécritFichier(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Table>.MotDePasseWDD55 = <Mot de passe>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Mot de passe> : (Chaîne de caractères ou Chaîne secrète)`**

Mot de passe du WDD au format 5.5.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md).
