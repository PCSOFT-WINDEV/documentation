
## Texte (Propriété)

***En anglais : Text***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Texte** permet de connaître et de modifier un texte. Cette propriété est utilisable sur:

- les rubriques d'une table: elle permet de savoir si une rubrique est une rubrique de type texte. Pour plus de détails, consultez [Propriété Texte](../Proprietes/2512089.md).

- une variable de type [xmlNoeud](../WDLang5/1000018786.md).

- une variable de type [Filigrane](../WDLang5/1000019922.md).
