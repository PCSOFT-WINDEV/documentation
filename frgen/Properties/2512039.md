


## IDAutoMin (Propriété)

***En anglais : MinAutoID***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IDAutoMin** permet de connaître l'identifiant automatique minimum sur une table répliquée. **Cette propriété est disponible en lecture seulement**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître l'identifiant automatiquement minimum du fichier de données Client 
ResIDAutoMin = Client.IDAutoMin
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Table>.IDAutoMin`
---

**`<Résultat> : (Entier)`**



- Valeur minimale de l'identifiant automatique défini pour la table,

- 0 si les bornes n'ont pas été définies ou si la table n'est pas répliquée.




**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée.
