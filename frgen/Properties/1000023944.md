
## LibelléHTML (Propriété)

***En anglais : CaptionHTML***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **LibelléHTML** permet de manipuler un libellé sous forme de code HTML. Cette propriété est utilisable sur :

- les champs d'une page. Pour plus de détails, consultez l'aide de la propriété [LibelléHTML](../Proprietes/1000020922.md).

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) une variable de type [Jeton](../WDLang1/1000023942.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [diagTexte](../WDLang1/1410088393.md).
