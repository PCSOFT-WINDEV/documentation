


## RépertoireDécrit (Propriété)

***En anglais : DescribedDirectory***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RépertoireDécrit** permet de gérer le répertoire physique des tables HFSQL. Cette propriété ne tient pas compte des éventuels changements de répertoires réalisés grâce aux fonctions [HChangeRep](../WDLang4/3044168.md) ou [HSubstRep](../WDLang4/3044028.md). Il est ainsi possible de:

- Connaître le répertoire physique d'une table définie sous l'éditeur de schémas des données ou définie par programmation.

- Définir un répertoire physique pour une table (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir le répertoire physique du fichier de données Commande
Commande.RépertoireDécrit = "C:\MesFichiers"
...
// Valider la description de la table
HDécritTable(Commande)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire physique d'une table

`<Répertoire actuel> = <Table>.RépertoireDécrit`
---

**`<Répertoire actuel> : (Chaîne de caractères)`**

Nom du répertoire de la table. Ce nom ne tient pas compte des changements de répertoires réalisés grâce aux fonctions [HChangeRep](../WDLang4/3044168.md) ou [HSubstRep](../WDLang4/3044028.md).

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir un répertoire physique pour une table définie par programmation

`<Table>.RépertoireDécrit = <Nouveau Répertoire>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau Répertoire> : (Chaîne de caractères)`**

Nom physique du répertoire.

![HFSQL Client/Serveur](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Le répertoire de la table doit être relatif à la base de données présente sur le serveur. Par exemple: ".\\Donnees".
