


## Hauteur (Propriété)

***En anglais : Height***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Hauteur** permet de connaître et modifier la hauteur :

- d'un champ ou d'un bloc dans un état.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) d'un champ (présent dans une fenêtre), d'une fenêtre, d'une ligne d'un champ Table ou d'un champ Liste (y compris Liste image), d'une option d'un champ Sélecteur ou d'un champ Interrupteur, d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) d'un champ (présent dans une page), d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée. Le champ peut être superposable ou non.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) d'une cellule de rupture d'un champ Table ou d'un champ Zone répétée. 




Il est également possible de connaître la hauteur d'une cellule d'un champ Table.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) La modification est possible uniquement pour les champs superposables (onglet "UI" de la description du champ).

**Remarques** :

- Le cadre du champ ou du bloc est compris dans sa hauteur. La propriété [HauteurPixel](../Proprietes/2511064.md) permet de connaître la hauteur d'un champ en pixels.

- La hauteur d'un champ est définie sous l'éditeur lors de la description du champ. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour rendre le contenu d'une fenêtre maximisée scrollable, utilisez la propriété [HauteurUtile](../Proprietes/1000021504.md).

## Exemple


```wl
// Augmente la hauteur du champ "SAI_NomClient"
SAI_NomClient.Hauteur = SAI_NomClient.Hauteur + 15
// Est équivalent à : SAI_NomClient.Hauteur + = 15
```

## Syntaxe

### Connaître la hauteur d'un élément

`<Résultat> = <Elément manipulé>.Hauteur`
---

**`<Résultat> : (Réel)`**

Hauteur de l'élément spécifié. Cette hauteur est exprimée en pixels dans une fenêtre et/ou une page, et en millimètres dans un état.

**`<Elément manipulé> : (Nom de champ ou nom de bloc)`**

Nom de l'élément (champ ou bloc) à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la hauteur d'un élément

`<Elément manipulé>.Hauteur = <Nouvelle hauteur>`
---

**`<Elément manipulé> : (Nom de champ ou nom de bloc)`**

Nom de l'élément (champ ou bloc) à manipuler.

**`<Nouvelle hauteur> : (Réel)`**

Nouvelle hauteur de l'élément spécifié. Cette hauteur est exprimée en pixels dans une fenêtre et/ou une page, et en millimètres dans un état.

### Hauteur dans un état
<a name="hauteur_dans_etat_ELTPARAGRAPHE000119"></a>

- La hauteur d'un bloc insécable ne peut pas dépasser la hauteur disponible sur la page (hors blocs En-tête et Pied de page).

- La hauteur d'un bloc de Pied de page ne peut pas être modifiée. Par contre, la hauteur d'un bloc d'En-tête de page peut être modifiée par programmation.

- Un champ doit être entièrement contenu dans le bloc auquel il appartient.

### Hauteur d'une ligne
<a name="hauteur_une_ligne_ELTPARAGRAPHE000130"></a>Il est possible de fixer une hauteur pour chaque ligne d'un champ Table ou d'un champ Liste (y compris Liste image) par programmation. Dans le cas des champs Liste fichier et Table fichier, cette hauteur est conservée uniquement pour la partie visible à l'écran.

Exemple : Fixe la hauteur de la ligne 3 de la liste "LISTE_Liste1" à 200.

```wl
LISTE_Liste1[3].Hauteur = 200
```
Remarque : Pour une colonne d'un champ Table, la propriété **Hauteur** permet de connaître la hauteur visible de la colonne du champ Table. Cette propriété est disponible en lecture seulement.

### Hauteur initiale (champ et fenêtre)
<a name="hauteur_initiale_champ_fenetre_ELTPARAGRAPHE000146"></a>La hauteur initiale (décrite sous l'éditeur) peut être connue grâce à la propriété [HauteurInitiale](../Proprietes/2510043.md).

La hauteur d'un objet est normalement contrainte par les propriétés [HauteurMax](../Proprietes/2510065.md) et [HauteurMin](../Proprietes/2510035.md). Néanmoins, cette contrainte disparaît lors de la modification de la hauteur par programmation (utilisation de la propriété **Hauteur** ou de la fonction [FenTaille](../WDLang1/3038020.md)).

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Hauteur des champs d'un formulaire
<a name="hauteur_des_champs_formulaire_ELTPARAGRAPHE000172"></a>En code serveur, la hauteur renvoyée et modifiable correspond à la hauteur totale du champ (hauteur du libellé et hauteur de la zone de saisie si le libellé et la zone de saisie sont l'un au dessus de l'autre).

En code navigateur, la hauteur renvoyée et modifiable correspond uniquement à la hauteur de la zone de saisie.

### Limites
<a name="limites_ELTPARAGRAPHE000181"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) **Limite pour les états**
La propriété **Hauteur** ne peut pas être utilisée sur un état ou sur un champ Interrupteur.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La propriété **Hauteur** s'applique uniquement aux éléments suivants :

- Champ Bouton.

- Champ Libellé.

- Champ de saisie.

- Champ Image.

- Champ Interrupteur.

- Champ Sélecteur.

- Champ Liste.

- Champ Combo.

- Champ Arbre.

- Champ Onglet.

- Fenêtre.

- Champ Table.

- Colonne de champ Table.

- Superchamp.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) La propriété **Hauteur** n'est pas disponible sur les colonnes de champ Table.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La propriété **Hauteur** n'est pas disponible sur les champs iFrame.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La propriété **Hauteur** est disponible uniquement en lecture sur les champs Chemin de navigation et les champs Table.
