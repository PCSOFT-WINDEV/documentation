
## DuréeValidationAutomatique (Propriété)

***En anglais : AutomaticValidationTimeout***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **DuréeValidationAutomatique** permet de définir le délai en secondes avant la validation automatique des étapes de la visite. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
