


## PoliceNom (Propriété)

***En anglais : FontName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **PoliceNom** permet de :

- Connaître la police utilisée dans un champ.

- Modifier la police utilisée dans un champ.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modifier la police utilisée dans le champ "SAI_NomClient"
SAI_NomClient.PoliceNom = "Arial"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la police utilisée dans un champ

`<Résultat> = <Champ manipulé>.PoliceNom`
---

**`<Résultat> : (Chaîne de caractères)`**

Nom de la police utilisée dans le champ spécifié.

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la police utilisée dans un champ

`<Champ manipulé>.PoliceNom = <Nouvelle police>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  

**`<Nouvelle police> : (Chaîne de caractères)`**

Nouvelle police utilisée dans le champ spécifié.

## Remarques


### Limites
<a name="limites_ELTPARAGRAPHE000072"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Dans un état, la propriété **PoliceNom** peut être utilisée uniquement sur :

- un champ Lien URL.

- un champ Libellé.

- un champ Calculé.

- un champ Prédéfini.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Dans une fenêtre, la propriété **PoliceNom** ne peut pas être utilisée sur :

- un champ Spin,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Web Camera,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) un champ Conférence.


Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Dans une page, la propriété **PoliceNom** peut être utilisée sur :

- un champ Libellé,

- un champ de saisie,

- un champ Bouton,

- un champ Interrupteur,

- un champ Sélecteur,

- un champ Liste,

- une colonne d'un champ Table,

- une cellule d'un champ Table (en lecture uniquement),

- un champ d'affichage formaté,

- un champ HTML,

- un champ Combo,

- un champ Lien,

- un champ Libellé HTML,

- un champ Réglette,

- un champ Chemin de navigation (sauf en PHP),

- un champ Arbre,

- un menu.


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La propriété **PoliceNom** s'applique uniquement aux éléments suivants :

- Champ Bouton.

- Champ Libellé.

- Champ Combo.

- Champ Arbre.

- Colonne d'un champ Table.



![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **PHP : Fichiers des polices**
En PHP, il est nécessaire que les fichiers des polices correspondantes soient accessibles (fichiers ttf). 
Ces fichiers doivent être présents dans le répertoire du site (répertoire _WEB connu avec la fonction [fRepWeb](../WDLang1/3036052.md)) et nommés de la façon suivante : 

- &lt;Nom de la police normale&gt;

- &lt;Nom de la police normale&gt;_Bold

- &lt;Nom de la police normale&gt;_Italic

- &lt;Nom de la police normale&gt;_Italic_Bold
