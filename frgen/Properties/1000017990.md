
## Evénement

***En anglais : Event***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Evénement** peut correspondre :  

- à la fonction **[Evénement](../WDLang1/3015011.md)**, qui permet d'intercepter un événement Windows. 

- à la propriété **Evénement** d'une variable de type [gglAgenda](../WDLang5/1000017418.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) à la propriété **Evénement** d'une variable de type [Contact](../WDLang3/1000020254.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) à une variable de type [Evénement](../WDLang3/1000020248.md).
