


## Journalisation (Propriété)

***En anglais : LogMethod***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Journalisation** permet de:

- connaître le mode de journalisation utilisé pour une table (table définie sous l'éditeur de schémas des données ou définie par programmation).

- définir le mode de journalisation utilisé pour une table (lors de la description de la table par programmation uniquement).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI Client.Journalisation = hJournalisationNon ALORS Info("Réplication impossible")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le mode de journalisation 

`<Mode actuel> = <Table>.Journalisation`
---

**`<Mode actuel> : (Constante de type entier)`**

Les formats de journalisation sont: 



|   |   |
| --- | --- |
| *hJournalisationEcriture* | Journalisation des opérations d'écriture réalisées dans la table. |
| *hJournalisationLectureEcriture* | Journalisation des opérations de lecture et d'écriture réalisées dans la table. |
| *hJournalisationNon* | Pas de journalisation. |



**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).

### Définir le mode de journalisation 

`<Table>.Journalisation = <Nouveau mode>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).
