
## Membre (Propriété)

***En anglais : Member***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Membre** permet de connaître et de modifier un membre d'une variable de type Variant, JSON ou YAML. Cette propriété est utilisable sur :

- une variable de type [JSON](../WDLang1/1000023611.md).

- une variable de type [Variant](../Motscles/1514019.md).  

- une variable de type [YAML](../Motscles/1000024438.md).
