


## ScrollAuDoigt (Propriété)

***En anglais : ScrollWithFinger***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ScrollAuDoigt** permet de : 

- Savoir si le contenu d'un champ peut être déplacé avec le doigt ("scroll au doigt").

- Autoriser ou non un champ à être manipulé directement avec le doigt. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Cette propriété correspond à l'option "Déplacement au doigt" disponible dans l'onglet "Détail" des champs Liste, Table et Zone répétée.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Cette propriété permet notamment d'interrompre temporairement le scroll au doigt pour pouvoir dessiner dans un champ Image. De la même façon, il est possible d'interrompre le zoom au doigt avec la propriété [ZoomAuDoigt](../Proprietes/1000022497.md). L'appel aux fonctions [dDébutDessin](../WDLang1/3029009.md) et [dFinDessin](../WDLang1/3029019.md) désactive/réactive automatiquement les fonctionnalités de zoom et scroll au doigt.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI INT_InterfaceTactile = Vrai ALORS
	TABLE_TableClient.ScrollAuDoigt = Vrai
SINON
	TABLE_TableClient.ScrollAuDoigt = Faux
FIN
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) 
```wl
SI INT_ModeDessin = Faux ALORS
	IMG_Photo.ScrollAuDoigt = Vrai
SINON
	IMG_Photo.ScrollAuDoigt = Faux
FIN
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si un champ permet le déplacement avec le doigt

`<Résultat> = <Champ manipulé>.ScrollAuDoigt`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le champ permet le déplacement avec le doigt, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ Liste.

- un champ Table.

- un champ Zone répétée. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) un champ Image.





<a name="SYNTAXE2"></a>

### Permettre le déplacement avec le doigt ou non

`<Champ manipulé>.ScrollAuDoigt = <Défilement au doigt>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ Liste.

- un champ Table.

- un champ Zone répétée. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) un champ Image.




**`<Défilement au doigt> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si champ autorise le défilement au doigt, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.

## Remarques


### Limites
<a name="limites_ELTPARAGRAPHE000110"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) La propriété **ScrollAuDoigt** peut uniquement être utilisée sur les champs Liste, Table et Zone répétée. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) La propriété **ScrollAuDoigt** peut uniquement être utilisée sur les champs Image. ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Attention : La fonctionnalité de Scroll et zoom doit avoir été activée dans la fenêtre de description du champ Image (option "Scroll et zoom automatiques" dans l'onglet "Détail" de la fenêtre de description du champ).  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Scrollaudoigt%20-%20HC%20N%B0001.gif)

<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000136"></a>Sur certains systèmes, un défilement au doigt automatique (fourni par le système) peut être actif même si le défilement au doigt du champ est désactivé.
