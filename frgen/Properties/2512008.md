


## Alphabet (Propriété)

***En anglais : Charset***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
**Utilisation avec une variable de type Police**
La propriété **Alphabet** permet de:

- Connaître l'alphabet actuellement utilisé par une variable de type [Police](../Motscles/1514045.md).

- Modifier l'alphabet utilisé par une variable de type [Police](../Motscles/1514045.md).




**Utilisation avec les tables HFSQL**
La propriété **Alphabet** permet de connaître l'alphabet utilisé par une table HFSQL. Cet alphabet a été choisi avec la fonction [ChangeAlphabet](../WDLang1/3054001.md) et pris en compte lors de la création de la table. Cette propriété est utilisable en lecture uniquement.

**Rappel**: Par défaut, l'alphabet utilisé par une table est l'alphabet ANSI. Pour modifier l'alphabet utilisé par une table, il faut:

- Utiliser la fonction [ChangeAlphabet](../WDLang1/3054001.md) pour spécifier l'alphabet à prendre en compte.

- Créer la table en prenant en compte le changement d'alphabet (fonctions [HCrée](../WDLang4/3044255.md) ou [HCréeSiInexistant](../WDLang4/3044254.md)).

## Exemple

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) 
```wl
// Exemple avec une variable de type Police
// Définir les caractéristiques de la police
Police1 est une police
Police1.Nom = "Arial"
Police1.Taille = 14
Police1.UnitéTaille = unitéPoint
Police1.Angle = 45
Police1.Alphabet = alphabetRusse
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1
```


<a name="Exemple2"></a>

```wl
// Exemple avec les tables HFSQL
HOuvre(Client)
LangueFichier est un entier = Client.Alphabet
// Change l'alphabet affiché en fonction du format de la table
SELON LangueFichier
	CAS alphabetArabe: ChangeAlphabet(alphabetArabe)
	CAS alphabetDéfaut: ChangeAlphabet(alphabetDéfaut)
	CAS alphabetGrec: ChangeAlphabet(alphabetGrec)
	CAS alphabetHébreu: ChangeAlphabet(alphabetHébreu)
	CAS alphabetOccidental: ChangeAlphabet(alphabetOccidental)
	CAS alphabetRusse: ChangeAlphabet(alphabetRusse)
	CAS alphabetTurc: ChangeAlphabet(alphabetTurc)
	AUTRES CAS
		// On passe en caractère occidental
		ChangeAlphabet(alphabetOccidental)
FIN
```

## Syntaxe

### Connaître l'alphabet actuellement utilisé par une variable de type Police

`<Résultat> = <Police>.Alphabet`
---

**`<Résultat> : (Constante de type Entier)`**

Type d'alphabet utilisé par le champ spécifié:



|   |   |
| --- | --- |
| *alphabetAnsi* | Caractères romains à la norme ANSI |
| *alphabetArabe* | Caractères arabes |
| *alphabetBalte* | Caractères baltes |
| *alphabetChinois* | Caractères chinois (République Populaire de Chine) |
| *alphabetChinoisTraditionnel* | Caractères chinois traditionnel (République de Taiwan) |
| *alphabetCoréen* | Caractères coréen |
| *alphabetCourant* | Utilise l'alphabet courant spécifié avec la fonction [ChangeAlphabet](../WDLang1/3054001.md) |
| *alphabetDéfaut* | Alphabet par défaut du poste en cours. Aucun alphabet n'est forcé. |
| *alphabetEuropeEst* | Caractères de l'Europe de l'Est (Polonais, ...) |
| *alphabetGrec* | Caractères grecs |
| *alphabetHebreu* | Caractères hébreux |
| *alphabetJaponais* | Caractères japonais |
| *alphabetMac* | Caractères à la norme Mac Roman (utilisés sur les vieilles versions de Macintosh). |
| *alphabetOccidental* | Caractères romains à la norme ANSI |
| *alphabetRusse* | Caractères russes |
| *alphabetThaï* | Caractères thaï |
| *alphabetTurc* | Caractères turques |
| *alphabetVietnamien* | Caractères vietnamiens |



**`<Police> : (Variable de type Police)`**

Nom de la variable de type [Police](../Motscles/1514045.md) à manipuler.

## Remarques


### Changement d'alphabet
<a name="changement_alphabet_ELTPARAGRAPHE000179"></a>

Lors du changement de l'alphabet utilisé, les polices utilisant l'alphabet demandé doivent être installées sur le poste en cours.

Remarque: Pour changer l'alphabet de toutes polices en une seule opération, utilisez la fonction [ChangeAlphabet](../WDLang1/3054001.md).

### Variable de type Police
<a name="variable_type_police_ELTPARAGRAPHE000193"></a>

Une police peut être créée à partir d'une variable de type [Police](../Motscles/1514045.md).

Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](../WDLang1/3060002.md).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette fonction n'est pas disponible.

- soit les propriétés [Alphabet](../Proprietes/2512008.md), [Angle](../Proprietes/1410086632.md), [Barré](../Proprietes/2513005.md), [Couleur](../Proprietes/2510071.md), [Gras](../Proprietes/2513001.md), [Italique](../Proprietes/2513007.md), [Interlettre](../Proprietes/1410088367.md), [Interligne](../Proprietes/1410088366.md), [Nom](../Proprietes/2510082.md), [Souligné](../Proprietes/2513013.md), [Taille](../Proprietes/2510125.md) et [UnitéTaille](../Proprietes/1410088365.md).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les propriétés [Alphabet](../Proprietes/2512008.md), [Angle](../Proprietes/1410086632.md) ne sont pas disponibles pour les variables de type [Police](../Motscles/1514045.md).




Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](../WDLang1/3029020.md)).

- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](../WDLang3/3042012.md), [grPoliceLégende](../WDLang3/3042037.md), [grPoliceTitre](../WDLang3/3042048.md) et [grPoliceTitreAxe](../WDLang3/3042059.md)).

- Pour imprimer (fonction [iPolice](../WDLang5/3046014.md)).

- Dans les champs d'une fenêtre (propriété [Police](../Motscles/1514045.md) des champs d'une fenêtre).

- Dans les champs d'un état (propriété [Police](../Motscles/1514045.md) des champs d'un état).




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette police pourra être utilisée uniquement dans les champs d'une fenêtre (propriété [Police](../Motscles/1514045.md) des champs d'une fenêtre).
