
## NomAffiché (Propriété)

***En anglais : DisplayedName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NomAffiché** permet de connaître de connaître le nom du compte ou du contact tel qu'il doit être affiché dans les différentes applications l'utilisant. Ce nom peut correspondre au pseudo. 

Cette propriété est utilisable sur :

- une variable de type [Contact](../WDLang3/1000020254.md).

- une variable de type [gglCompte](../WDLang3/1410089816.md).
