


## CxMotDePasseDécrit (Propriété)

***En anglais : CtDescribedPassword***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CxMotDePasseDécrit** permet de définir le mot de passe utilisé pour ouvrir la table lors d'une connexion OLE DB (table définie par programmation uniquement). 


**Rappel**: La fonction [HConnecte](../WDLang4/3044263.md) permet de redéfinir un ou plusieurs paramètres de la connexion OLE DB sur une table. Par défaut, les caractéristiques de la connexion OLE DB sont définies:

- soit sous l'Éditeur de schémas des données lors de la description de la table,

- soit lors de la description par programmation de la table.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir le mot de passe utilisé pour ouvrir la table Client
Client.CxMotDePasseDécrit = "MotDePasse"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Table>.CxMotDePasseDécrit = <Mot de passe>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Mot de passe> : (Chaîne de caractères ou Chaîne secrète)`**

Mot de passe du fichier à ouvrir par une connexion OLE DB.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété [MotDePasse](../Proprietes/2510086.md) permet de définir le mot de passe associé à un utilisateur et une connexion.
