


## Multisélection (Propriété)

***En anglais : Multiselection***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Multisélection** permet de connaître et de modifier le mode de sélection :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) d'un champ Table.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) d'un champ Table hiérarchique.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) d'un champ Tableau croisé dynamique.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) d'un champ Liste.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) d'un champ Liste image.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) d'un champ Zone répétée.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) d'un champ Calendrier.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) des fichiers dans un champ Upload.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) d'un champ de saisie de type "Jetons de texte".





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modifie le mode de sélection selon la valeur du champ Interrupteur
SI INT_Multisel = Vrai ALORS
	TABLE_Table1.Multisélection = Vrai
SINON
	TABLE_Table1.Multisélection = Faux
FIN
```

### Connaître le mode de sélection

`<Mode de sélection> = <Champ manipulé>.Multisélection`
---

**`<Mode de sélection> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le champ est multisélection, 

- <u><u><u><u>Faux</u></u></u></u> si le champ est monosélection.

## Remarques
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Limites pour le champ Calendrier
<a name="limites_pour_champ_calendrier_ELTPARAGRAPHE000195"></a>Pour un champ Calendrier, la propriété **Multisélection** permet uniquement de passer du mode monosélection au mode multisélection. Si le mode "Sélection de période" est sélectionné sous l'éditeur (onglet "Détail" de la fenêtre de description du champ), la propriété **Multisélection** n'a aucun effet.
<a name="NOTE0_2"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Fonctionnement du champ Upload
<a name="fonctionnement_champ_upload_ELTPARAGRAPHE000210"></a>Pour un champ Upload, la propriété **Multisélection** permet uniquement de modifier le mode de sélection des fichiers dans le sélecteur de fichiers ouvert par le champ Upload. 
<a name="NOTE0_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Fonctionnement du champ Tableau Croisé Dynamique
<a name="fonctionnement_champ_tableau_croise_dynamique_ELTPARAGRAPHE000224"></a>Pour un champ Tableau Croisé Dynamique, la propriété **Multisélection** permet uniquement de passer du mode monosélection au mode multisélection. L'utilisateur pourra alors sélectionner plusieurs cellules juxtaposées. 

Cette propriété est équivalente à l'option "Autoriser la sélection multiple des lignes, colonnes et cellules" présente dans l'onglet "UI" de la fenêtre de description du champ. 
<a name="NOTE0_5"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Fonctionnement du champ de saisie avec jetons
<a name="fonctionnement_champ_saisie_avec_jetons_ELTPARAGRAPHE000244"></a>Lorsque le champ de saisie avec jetons est en mode multisélection, l'utilisateur peut sélectionner pluseiurs jetons (via la touche Ctrl par exemple). Les options "Copier", "Coller" et "Couper" tiennent compte de la multisélection. L'option "Tout copier" du menu contextuel permet de copier tous les jetons du champ. 

Cette propriété est équivalente à l'option "Jetons multi-sélectionnables" présente dans l'onglet "Général" de la fenêtre de description du champ. 
<a name="NOTE0_4"></a>

- sur les champs Table en saisie sans sélection : elle renvoie <u><u><u><u>Faux</u></u></u></u>.

- sur les champs Table en affichage sans sélection : elle renvoie <u><u><u><u>Faux</u></u></u></u>.

- sur les champs Table "Compatibles 5.5".
