
## FonctionsAutorisées (Propriété)

***En anglais : AllowedFunctions***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FonctionsAutorisées** permet de connaître et de définir la liste des fonctions autorisées dans un champ Editeur de code ou via les fonctions [Compile](../WDLang1/3013015.md), [ExécuteCode](../WDLang1/1000019783.md), [EvalueExpression](../WDLang1/1000019782.md). 

Cette propriété est disponible sur : 

- la propriété [Compilateur](../Proprietes/1410090383.md) du champ Editeur de code. 

- une variable de type [CodeWLangageCompilation](../WDLang1/1410090373.md).
