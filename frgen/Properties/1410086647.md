
## CaractèreRemplissage

***En anglais : FillCharacter***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CaractèreRemplissage** permet de connaître et de modifier le caractère utilisé pour le remplissage d'un élément. Cette propriété est utilisable sur :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une variable de type [docTabulation](../WDLang1/1000022573.md).

- une variable de type [FormatNumérique](../WDLang1/1410089836.md).
