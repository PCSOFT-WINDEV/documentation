
## Champ (mot-clé)

***En anglais : Control***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Champ** peut correspondre : 

- à une variable de type [Champ](../WDLang1/1000020967.md). 

- à la propriété **Champ** d'une variable de type [docElément](../WDLang1/1000022484.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) à la propriété **Champ** d'une variable de type [pdfPage](../WDLang6/1000024904.md).
