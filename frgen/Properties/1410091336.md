
## IAInfoModèle (Propriété)

***En anglais : AIModelInfo***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IAInfoModèle** permet de connaître et modifier les paramètres de connexion au modèle d'IA utilisé par le champ Chat IA.                                                                                                                                                                                                                           
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CHATIA_ChatBotIA.IAInfoModèle.Fournisseur = iaFournisseurGoogle
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître les caractéristiques de la connexion au modèle d'IA du champ

`<Résultat> = <Champ Chat IA>.IAInfoModèle.<Nom de la propriété>`
---

**`<Résultat> : (Type correspondant à la propriété)`**

Résultat correspondant à la propriété utilisée.

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé. 

**`<Nom de la propriété> : (Chaîne de caractères)`**

Propriétés utilisées: 


| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Adresse | Chaîne de caractères | Adresse du serveur qui fournit un moteur d'IA. <br><br>Cette propriété est nécessaire uniquement lors de l'utilisation d'un fournisseur spécialisé. |
| Fournisseur | Constante de type Entier | Type de modèle d'IA : <br><br>- *iafournisseurAnthropic* : fournisseur Anthropic (Claude)<br><br>- *iafournisseurAucun* : aucun fournisseur n'est défini. Si cette constante est indiquée, le champ Chat IA ne fonctionne plus.  Cette constante permet par exemple de désactiver l'utilisation de l'IA. <br><br>- *iafournisseurGoogle* : fournisseur Google (Gemini)<br><br>- *iafournisseurMistral* : fournisseur Mistral AI (Le chat)<br><br>- *iafournisseurOpenAI* : fournisseur OpenAI (ChatGPT)<br><br>- *iafournisseurOpenRouter* : fournisseur OpenRouter<br><br>- *iafournisseurPersonnalisé* : un fournisseur personnalisé est utilisé. Il est alors nécessaire de spécifier toutes les caractéristiques de la connexion. <br><br>- *iafournisseurXAI* : fournisseur xAI (Grok)<br><br><br> |
| Identifiant | Chaîne de caractères | Clé d'API à utiliser. <br><br>Cette propriété est nécessaire notamment pour utiliser un fournisseur externe.<br><br>Dans le cas d'un fournisseur personnalisé, cette propriété n'est pas obligatoire. |
| Nom | Chaîne de caractères | Nom du modèle utilisé. <br><br>Par exemple : "deepseek-r1:1.5b" |
| Protocole | Constante de type Entier | Permet de spécifier un protocole de discussion avec le moteur d'IA si la propriété Fournisseur correspond à la constante *iafournisseurPersonnalisé*. <br><br>Cette propriété peut correspondre à une des constantes suivants : <br><br>- *iaProtocoleOpenAI* : Protocole OpenAI. <br><br>- *iaProtocoleAnthropic* : Protocole Anthropic.<br><br>- *iaProtocoleGoogle* : Protocole Google.<br><br>- *iaProtocoleOpenRouter* : Protocole OpenRouter.<br><br>- *iaProtocoleMistral* : Protocole Mistral.<br><br>- *iaProtocoleXAI* : Protocole XAI.<br><br><br> |
