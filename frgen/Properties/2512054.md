


## Nom55 (Propriété)

***En anglais : Name55***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Nom55** permet de gérer le nom logique d'une table au format Hyper File 5.5 non migré et présent dans un schéma des données au format WINDEV 2026. Il est ainsi possible de:

- Connaître le nom logique d'une table.

- Définir le nom d'une table au format 5.5 créée par programmation dans un schéma des données au format WINDEV 2026.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le nom logique de la table Client
ResNom55 = Client.Nom55
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le nom logique d'une table au format 5.5 

`<Nom logique> = <Table>.Nom55`
---

**`<Nom logique> : (Chaîne de caractères)`**

Nom logique de la table au format 5.5.

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table dans le schéma des données au format WINDEV 2026.  


<a name="SYNTAXE2"></a>

### Définir le nom logique 5.5 d'une table créée par programmation

`<Table>.Nom55 = <Nouveau nom logique>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table défini par programmation grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom logique> : (Chaîne de caractères)`**

Nom logique de la table au format 5.5.
