


## Vignette (Propriété)

***En anglais : Thumbnail***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Vignette** permet de: 

- connaître la valeur d'une vignette d'une rubrique. Cette rubrique a été définie sous l'éditeur de schémas des données ou définie par programmation. Pour plus de détails, consultez [Vignettes HFSQL](../WDLang4/3044348.md). 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) connaître et modifier l'image associée à un champ Vignette.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Valeur de la première vignette de la rubrique Client.Photo
ValeurVignette est une chaîne
ValeurVignette = Client.Photo.Vignette[1]
// équivalent à ValeurVignette = Client.Photo.Vignette

// Valeur nulle?
SI ValeurVignette <> "" ALORS
	Info("La valeur de cette vignette est: " + ValeurVignette)
SINON
	ChaîneErreur = Client.Photo.InfoGénérationVignette[1]
	Erreur("Erreur de génération", ChaîneErreur)
FIN
```

## Syntaxe

### Connaître la valeur de la vignette d'une rubrique

`<Valeur> = <Fichier de données>.<Rubrique>.Vignette`
---

**`<Valeur> : (Chaîne de caractères)`**

Image de la vignette spécifiée sous forme de mémo binaire.

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Rubrique> : (Chaîne de caractères)`**

Nom de la rubrique de type mémo binaire manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Rubrique](../WDLang4/1514071.md).

### Connaître le chemin de l'image associée à un champ Vignette

`<Résultat> = <Champ Vignette>.Vignette`
---

**`<Résultat> : (Chaîne de caractères)`**

Chemin de l'image utilisée pour la vignette. Ce chemin est relatif au répertoire "_WEB" du projet.

**`<Champ Vignette> : (Nom de champ)`**

Nom du champ Vignette à manipuler.   


<a name="SYNTAXE3"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 
### Modifier le chemin de l'image associée à un champ Vignette

`<Champ Vignette>.Miniature = <Nouvelle image>`
---

**`<Champ Vignette> : (Nom de champ)`**

Nom du champ Vignette à manipuler. 

**`<Nouvelle image> : (Chaîne de caractères)`**

Nouveau chemin de l'image utilisée pour la vignette. Ce chemin est relatif au répertoire "_WEB" du projet.

## Remarques


### Vignette d'un rubrique
<a name="vignette_rubrique_ELTPARAGRAPHE000095"></a>

La propriété **Vignette** est disponible:

- en HFSQL Classic et en HFSQL Mobile: sur les rubriques d'une table, d'une vue ou d'une requête.

- en HFSQL Client/Serveur: sur les rubriques d'une table uniquement.




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) La propriété **Vignette** est disponible uniquement en HFSQL Client/Serveur sur les rubriques d'une table.
