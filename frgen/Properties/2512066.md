


## NomDécrit (Propriété)

***En anglais : DescribedName***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NomDécrit** permet de gérer le nom logique des tables HFSQL (sans tenir compte des éventuelles modifications effectuées par la fonction [HAlias](../WDLang4/3044176.md)). Il est ainsi possible de:

- Connaître le nom logique d'un élément:

	- table définie sous l'éditeur de schémas des données ou définie par programmation,

	- vue,

	- requête




- Définir le nom logique d'une table (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le nom logique de la table Client
ResNom = Client.NomDécrit
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le nom logique d'un élément

`<Nom logique> = <Elément>.NomDécrit`
---

**`<Nom logique> : (Chaîne de caractères)`**

Nom logique de l'élément:

- table définie sous l'éditeur de schémas des données ou définie par programmation,

- vue, 

- requête.




**`<Elément> : (Chaîne de caractères)`**

Elément manipulé (par indirection par exemple).

### Définir le nom logique d'une table créée par programmation

`<Table>.NomDécrit = <Nouveau nom>`
---

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau nom> : (Chaîne de caractères)`**

Nom logique de l'élément.
