


## RubriqueTexteComplétée (Propriété)

***En anglais : TextItemCompleted***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **RubriqueTexteComplétée** permet de paramétrer la gestion des rubriques texte dans une table HFSQL. Les rubriques texte peuvent:

- être complétées automatiquement par des espaces (fonctionnement identique à celui de WINDEV 5.5),

- ne pas être complétées par des espaces.




Il est ainsi possible de:

- Savoir si une table est configurée pour compléter ou non les rubriques texte (table définie sous l'éditeur de schémas des données ou définie par programmation).

- Définir les caractéristiques des rubriques texte (lors de la description de la table par programmation uniquement).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Caractéristiques des rubriques texte du fichier de données Commande
Commande.RubriqueTexteComplétée = Vrai
...
// Valide la description de la table
HDécritTable(Commande)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si les rubriques texte seront complétées par des espaces

`<Rubriques complétées> = <Table>.RubriqueTexteComplétée`
---

**`<Rubriques complétées> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table est configurée pour que les rubriques texte soient complétées par des espaces,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir la gestion des rubriques texte (fichier créé par programmation)

`<Table>.RubriqueTexteComplétée = <Rubriques complétées>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Rubriques complétées> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table doit être configurée pour que les rubriques texte soient complétées par des espaces,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.
