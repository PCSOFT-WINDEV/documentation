
## OptionsOuverture (Propriété)

***En anglais : OpeningOptions***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **OptionsOuverture** permet de connaître et de spécifier les options d'ouverture d'une fenêtre manipulée par une variable de type [Fenêtre](../WDLang1/1410091366.md).  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définition des options de la fenêtre pour son ouverture
Ma_fen_exe est une Fenêtre FEN_Principale
Ma_fen_exe.OptionsOuverture.X = 50
Ma_fen_exe.OptionsOuverture.Y = 100
Ma_fen_exe.OptionsOuverture.Animation = afRotationX + afMorphCylindre
// Ouverture de la fenêtre
Ouvre(Ma_fen_exe)
```
