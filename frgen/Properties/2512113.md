


## NbVignette (Propriété)

***En anglais : NbThumbnail***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NbVignette** permet de connaître le nombre de vignettes générées d'une rubrique. Cette rubrique a été définie sous l'éditeur de schémas des données ou définie par programmation.

**Remarque**: Les vignettes HFSQL d'une rubrique sont générées automatiquement lors:

- de l'écriture de l'enregistrement correspondant (fonctions [HAjoute](../WDLang4/3044147.md) ou [HEcrit](../WDLang4/3044092.md)),

- de la modification de la valeur de la rubrique (fonction [HModifie](../WDLang4/3044042.md)),

- de la [modification automatique des tables](../WDLang4/3044195.md).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître le nombre de vignettes générées 
// et le nombre de vignettes attendues
// pour la rubrique Client.Photo
NombreVignette est un entier
NombreVignetteAttendu est un entier
NombreVignette = Client.Photo.NbVignette
NombreVignetteAttendu = Client.Photo.NbVignetteDécrit
// Nombre égal?
SI NombreVignette = NombreVignetteAttendu ALORS
	Info("Toutes les vignettes ont été générées")
SINON
	POUR Nombre = 1 A NombreVignetteAttendu
		ChaîneErreur += "Vignette " + Nombre + Client.Photo.InfoGénérationVignette[n] + RC
	FIN
	Erreur("Erreur de génération", ChaîneErreur)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Nombre de vignettes générées> = <Fichier de données>.<Rubrique>.NbVignette`
---

**`<Nombre de vignettes générées> : (Entier)`**

Nombre de vignettes générées pour la rubrique spécifiée.

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Rubrique> : (Chaîne de caractères)`**

Nom de la rubrique de type mémo binaire manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Rubrique](../WDLang4/1514071.md).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La propriété **NbVignette** est disponible:

- en HFSQL Classic et en HFSQL Mobile: sur les rubriques d'une table, d'une vue ou d'une requête.

- en HFSQL Client/Serveur: sur les rubriques d'une table uniquement.




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) La propriété **NbVignette** est disponible uniquement en HFSQL Client/Serveur sur les rubriques d'une table.
