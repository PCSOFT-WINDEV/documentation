


## Nom (Propriété)

***En anglais : Name***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Nom** permet de connaître le nom d'un élément. Cette propriété est utilisable sur:

- les champs d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Propriété Nom sur les champs](../Proprietes/2510082.md).
