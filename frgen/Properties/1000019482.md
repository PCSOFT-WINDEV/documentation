
## Son

***En anglais : Sound***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Son** peut correspondre :

- à la fonction **[Son](../WDLang1/3013047.md)** qui permet de jouer un son.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) à la propriété **Son** disponible sur une variable de type [Notification](../WDLang3/1000019441.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) à la propriété **Son** disponible sur une variable de type [notificationCatégorie](../WDLang3/1000023981.md).
