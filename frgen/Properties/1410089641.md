
## CoinArrondi (Propriété)

***En anglais : RoundedCorner***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CoinArrondi** permet de savoir et de définir si la fenêtre coulissante basse associée à la fenêtre en cours possède des coins arrondis. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaFenêtreCoulissanteBasse.SurInvisibilité = () => { Trace("La fenêtre coulissante basse a disparue") }
MaFenêtreCoulissanteBasse.ParamètresOuverture = (42, "Adams")
MaFenêtreCoulissanteBasse.FenêtreInterne = "FI_Menu_Coulissant"
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurEtendue = 0.9 // 90% 
MaFenêtreCoulissanteBasse.Modale = Vrai
MaFenêtreCoulissanteBasse.Masquable = Vrai
MaFenêtreCoulissanteBasse.CoinArrondi = Faux

// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Savoir si la fenêtre coulissante possède des coins arrondis

`<Résultat> = <Fenêtre coulissante>.CoinArrondi`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la fenêtre coulissante basse est affichée avec des coins arrondis, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Fenêtre coulissante> : (MaFenêtreCoulissanteBasse)`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.


<a name="SYNTAXE2"></a>

### Définir si la fenêtre coulissante possède des coins arrondis

`<Fenêtre coulissante>.CoinArrondi = <Nouvelle valeur>`
---

**`<Fenêtre coulissante> : (MaFenêtreCoulissanteBasse)`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.

**`<Nouvelle valeur> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la fenêtre coulissante basse doit être affichée avec des coins arrondis, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Sur les périphériques Android et les iPhone, seuls les coins du haut sont arrondis.

- Sur les iPad, les quatre coins sont arrondis.
