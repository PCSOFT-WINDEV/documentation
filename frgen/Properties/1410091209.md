
## ProcédureEntête (Propriété)

***En anglais : ProcedureHeader***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ProcédureEntête** permet de définir la procédure appelée pour lire les entêtes en cas de réussite de la requête HTTP. Cette procédure peut être utilisée lorsque le serveur retourne une réponse en morceaux (chunked) ou simplement une grosse réponse.

Cette propriété est utilisable sur :

- une variable de type [httpRequête](../WDLang3/1000021158.md).

- une variable de type [restRequête](../WDLang3/1000021481.md).
