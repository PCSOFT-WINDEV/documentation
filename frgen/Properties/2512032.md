


## FichierJournal (Propriété)

***En anglais : LogFile***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **TableJournal** permet de savoir si une table est une table journal ou non.

**Rappel**: Une table journal permet de stocker les différentes opérations réalisées sur une table journalée. Un fichier journal est créé si des options de journalisation ont été définies pour une ou plusieurs tables du schéma des données.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
EXTERNE FournisseurJNL
HDéclareExterne("C:\WinDev\Exemples\GestCom\FournisseurJNL.fic", "FournisseurJNL")
SI FounisseurJNL.FichierJournal = Vrai ALORS
	Info("Vous manipulez un fichier journal")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Table>.FichierJournal`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier est un fichier journal, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


Remarque: Les tables décrites dans le schéma des données ne sont pas des tables "journal".

**`<Table> : (Chaîne de caractères)`**

Nom logique de la table manipulée. Peut correspondre à un nom d'alias d'un fichier déclaré par la fonction [HDéclareExterne](../WDLang4/3044204.md).
