


## Image (Propriété)

***En anglais : Image***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Image** permet de connaître et de modifier l'image de fond associée à un élément.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Dans un état, la propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc.![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Dans une fenêtre, la propriété **Image** permet de connaître et de modifier l'image :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) affichée dans la barre d'icônes d'une fenêtre de type mère MDI (uniquement en WINDEV),

- associée au libellé d'un bouton,

- associée à un volet d'onglet ou à un onglet,

- associée aux volets d'une boîte à outils ou à un bouton d'un volet de la boîte à outils,

- associée au libellé d'une option de menu,

- utilisée comme curseur dans une jauge ou dans un potentiomètre non rotatif,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) utilisée pour la coche des interrupteurs ou des sélecteurs (uniquement en WINDEV),

- utilisée dans les options des interrupteurs et sélecteurs au look Vista,

- utilisée en image de fond d'un champ Calendrier.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) utilisée dans un champ Notation.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) utilisée pour les marqueurs d'un champ Carte.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) utilisée en icône dans une Action Bar (propriété disponible à partir de la version 4.0 d'Android (Ice cream sandwich, api level 14)).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) utilisée pour un regroupement lorsque le regroupement d'un ruban est fermé.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) utilisée pour représenter une jauge infinie.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Dans une page, la propriété **Image** permet de connaître et de modifier l'image associée :

- à un champ Image,

- à un champ Web Caméra (code serveur uniquement),

- à un bouton à image fixe (code navigateur uniquement),

- à un champ Vignette,

- à un champ Calendrier (image de fond).

- à un champ Réseau social (dont l'image est personnalisée).

- aux marqueurs d'un champ Carte.


**Remarque** : Ces images sont définies sous l'éditeur dans la description du champ, de la fenêtre ou de la page (onglet "Général" ou "Détail").

### Image associée à un champ ou à un bloc d'un état
<a name="image_associee_champ_bloc_etat_ELTPARAGRAPHE000267"></a>

- L'image d'un champ Image peut être connue et/ou modifiée sous l'éditeur d'états dans l'onglet "Général" de la description du champ.

- L'image de fond d'un champ ou d'un bloc peut être connue et/ou modifiée sous l'éditeur d'états, dans l'onglet "Style" de la description du champ ou du bloc. Il suffit de sélectionner l'élément "Image de fond".

### Image scannée dans un état
<a name="image_scannee_dans_etat_ELTPARAGRAPHE000277"></a>La propriété **Image** ne permet pas de modifier l'image scannée d'un état. En effet, l'image scannée d'un état permet de :

- faciliter le positionnement des différents champs dans l'état,

- visualiser le résultat lors de l'aperçu avant impression.

<a name="image_dans_une_option_menu_ELTPARAGRAPHE000292"></a>Si une image est associée à une option de menu marquée, l'image remplace la marque.

### Image d'un onglet ou d'un volet d'onglet
<a name="image_onglet_volet_onglet_ELTPARAGRAPHE000301"></a>Pour modifier l'image d'un onglet (c'est-à-dire l'image des boutons de l'onglet), il suffit d'utiliser le code suivant :

```wl
ONG_Onglet.Image = "Exemple.jpg"
```
Pour modifier l'image affichée dans le bouton de l'onglet (à côté du libellé), il suffit de préciser l'indice de l'onglet à modifier :

```wl
ONG_Onglet[1].Image = "Exemple.jpg"
```

### Image des coches d'interrupteur et de sélecteur
<a name="image_des_coches_interrupteur_selecteur_ELTPARAGRAPHE000313"></a>La propriété **Image** permet de changer la coche des interrupteurs et des sélecteurs. Cette propriété correspond à l'option "Image des coches" dans l'onglet "Détail" de la description du champ.

Si l'image de la coche ne doit pas être animée : l'image utilisée doit être constituée des deux ou trois états de la coche : Coché, Décoché et Indéfini si nécessaire.

Si l'image de la coche est animée, l'image utilisée doit être une image GIF, contenant pour chaque état principal (Coché, Décoché et Indéfini), les images suivantes :

- Coche active (pas d'animation)

- Coche enfoncée (animation)

- Coche grisée (pas d'animation)

- Coche survolée (animation)

2. Images pour l'état décoché.

### Action Bar
<a name="action_bar_ELTPARAGRAPHE000344"></a>La propriété **Image** permet de changer l'icône affichée dans l'Action Bar de la fenêtre. Si la propriété **Image** correspond à une chaîne vide (""), l'icône de l'application sera utilisée (cas par défaut). 

La propriété **Image** permet de changer également de modifier l'icône affichée dans un des volets de l'Action Bar (dans la barre de navigation). Dans ce cas, la syntaxe à utiliser est la suivante : 

```txt
<Nom Action Bar>[<Indice>].Image
```
où Indice correspond à l'indice de la vue dans le champ Action Bar. 

Par exemple, pour afficher l'image "produit.jpg" dans le second volet, le code WLangage est le suivant : 

```wl
ACTB_ActionBar[2].Image = "produit.jpg"
```




Remarque : Pour plus de détails sur les volets / vues d'une action bar, consultez [Description du champ Action Bar](../WDChamp/1000025005.md).

### Limites
<a name="limites_ELTPARAGRAPHE000378"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Dans un état, la propriété **Image** ne peut pas être utilisée sur :

- un état.

- un code-barres.

- un champ Interrupteur.


Formats d'images autorisés : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Les formats d'images pouvant être affichés sont les suivants : tous les formats décrits dans la fonction [fFiltreImage](../WDLang1/3036009.md).

- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Les formats d'images pouvant être affichés sont les suivants : BMP, ICO, JPEG, et GIF.

- un volet d'une barre d'outils ou un bouton d'un volet,

- une option de menu,

- une jauge,

- un potentiomètre non rotatif,

- un interrupteur,

- un sélecteur,

- un champ Calendrier,

- un champ Notation.

- un marqueur d'un champ Carte.

- un champ Jauge infinie personnalisé.
