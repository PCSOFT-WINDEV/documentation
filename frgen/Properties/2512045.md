


## Format (Propriété)

***En anglais : Format***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Format** permet de paramétrer le format des données de la table. Il est ainsi possible de:

- Connaître le format des données utilisé pour une table (table définie sous l'éditeur de schémas des données ou définie par programmation).

- Définir le format des données d'une table (lors de la description de la table par programmation uniquement).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définir le format des données
Client.Format = hFormatUnicode
...
// Valide la description de la table
HDécritFichier(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le format des données 

`<Format actuel> = <Table>.Format`
---

**`<Format actuel> : (Constante de type entier)`**

Un des formats disponibles:



|   |   |
| --- | --- |
| *hFormatAnsi* | Format Ansi (utilisé par Windows). |
| *hFormatUnicode* | Format Unicode. |



**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom a été défini sous l'éditeur de schémas des données ou grâce au type [Description de Fichier](../WDLang4/1514065.md).  


<a name="SYNTAXE2"></a>

### Définir le format des données

`<Table>.Format = <Nouveau format>`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée. Ce nom vient d'être défini grâce au type [Description de Fichier](../WDLang4/1514065.md).

**`<Nouveau format> : (Constante de type entier)`**

Un des format disponibles:



|   |   |
| --- | --- |
| *hFormatAnsi* | Format Ansi (utilisé par Windows). |
| *hFormatUnicode* | Format Unicode. |
