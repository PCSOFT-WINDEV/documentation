
## 1. Projet et schéma des données

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Le développement d'une **Application** mobile (Android, iOS, etc.) avec WINDEV Mobile repose sur deux éléments principaux : le Projet et le Schéma des données.

Un **Projet WINDEV Mobile** est un ensemble d'éléments (fenêtres, champs, classes, composants, etc.) dont l'assemblage permet de réaliser une application.

Un **Schéma des données WINDEV Mobile** regroupe les différentes tables utilisées par l'application.

Une application est construite à partir d'un projet.

Lorsqu'un projet WINDEV Mobile utilise des tables, un schéma des données doit être associé à ce projet. Généralement, un projet est associé à un schéma des données, mais il peut également être associé à plusieurs schémas des données. 

Un schéma des données peut être associé à un ou plusieurs projets.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P9-Projet%20et%20Analyse.svg)
