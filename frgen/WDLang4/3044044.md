


## HVérifieIndex (Fonction)

***En anglais : HCheckIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie que les données contenues dans le fichier d'index (fichier .NDX) référencent correctement les données contenues dans la table (fichier .FIC). Cette fonction concerne uniquement les tables HFSQL (Classic ou Client/Serveur). 

![HFSQL Client/Serveur](https://doc.pcsoft.fr/ext/images/us/HFCS.png) La table HFSQL Client/Serveur vérifiée est automatiquement bloquée en écriture pendant la vérification.![HFSQL Client/Serveur](https://doc.pcsoft.fr/ext/images/us/HFCS.png) La vérification des index d'une table HFSQL Client/Serveur peut être effectuée de manière asynchrone grâce à la fonction [HVérifieIndexAsynchrone](../WDLang4/1410091105.md). 


**Rappel**: Un index est corrompu lorsque l'un des enregistrements qu'il référence n'est pas celui attendu. Dans ce cas, il est nécessaire de réindexer la table.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Vérification de l'index
soit RésultatIndex = HVérifieIndex(Client)
// Gère le résultat
SELON RésultatIndex
	CAS 0
		Info("Index correct")
	CAS 1
		Info("Le fichier nécessite une optimisation.")
	CAS 2
		Info("Erreur HFSQL " + HErreur() + " pendant le test")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HVérifieIndex([<Table> [, <Rubrique clé>] [, <Jauge>]])`
---

**`<Résultat> : (Entier)`**

Peut correspondre à: 

- 0 si la vérification est correcte.

- 1 si l'index est corrompu: une réindexation est nécessaire (fonction [HRéindexe](../WDLang4/3044133.md)).

- 2 lors d'une erreur HFSQL: la table est inaccessible, etc.

- 3 si la fonction est non supportée par ce type de table (table xBase, AS400, etc.).




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. Si ce nom n'est pas spécifié, la fonction **HVérifieIndex** va manipuler la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

**`<Rubrique clé> : (Chaîne de caractères optionnelle)`**

Nom de la rubrique clé à vérifier. Si ce paramètre n'est pas spécifié, toutes les clés de la table sont vérifiées.

**`<Jauge> : (Nom de champ ou nom de fenêtre optionnel)`**



- Nom de la fenêtre dans laquelle la jauge doit être affichée,

- Nom du champ de type Jauge à utiliser. 


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Ce paramètre n'est pas pris en compte.

## Remarques


### Index corrompu
<a name="index_corrompu_ELTPARAGRAPHE000114"></a>

Lorsque la fonction détecte un problème dans le fichier d'index, la variable **H.Commentaire** contient:

```txt
<Nom de la clé concernée> + TAB + <Numéro de l'enregistrement posant problème> + RC + 
<Nom de la clé concernée 2> + TAB + <Numéro de l'enregistrement posant problème 2> ...
```

&lt;Numéro de l'enregistrement posant problème&gt; est égal à -1 si l'enregistrement n'a pas pu être déterminé.

**Remarque**: Si le fichier d'index est entièrement corrompu, la variable **H.Commentaire** n'est pas renseignée.
