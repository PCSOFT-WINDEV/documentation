


## HListeHistoriqueRéindexation (Fonction)

***En anglais : HListReindexingHistory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les différentes opérations effectuées sur les tables en cours ou celles qui ont eu lieu pendant les dernières 24 heures et sur les 1000 dernières tables: réindexations, recalcul des statistiques, vérification des mémo, vérification des index, etc.  

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une connexion
tabHistoriques est un tableau de hHistoriqueRéindexation 
// Liste des réindexations / vérifications en cours
tabHistoriques = HListeHistoriqueRéindexation(CnxBaseDeDonnées)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HListeHistoriqueRéindexation(<Connexion>)`
---

**`<Résultat> : (Tableau de variables de type hHistoriqueRéindexation)`**

Tableau de variables de type [hHistoriqueRéindexation](../WDLang4/1410091059.md), contenant les caractéristiques des différentes réindexations effectuées. 

**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion vers le serveur contenant les données à manipuler. Cette connexion correspond:

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Les opérations listées par la fonction **HListeHistoriqueRéindexation** sont les suivantes: 

- réindexations lancées par la fonction [HRéindexeAsynchrone](../WDLang4/1410091053.md). 

- calculs de statistiques exécutés par la fonction [HStatCalculAsynchrone](../WDLang4/1410091108.md). 

- vérification des index exécutée par la fonction [HVérifieIndexAsynchrone](../WDLang4/1410091105.md). 

- vérification des mémos exécutée par la fonction [HVérifieMémoAsynchrone](../WDLang4/1410091107.md).
