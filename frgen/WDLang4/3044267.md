## Présentation
<a name="presentation_ELTTEXTE000081"></a>
Les rubriques "Clé" permettent d'organiser les enregistrements dans une table pour optimiser le parcours ou la recherche d'enregistrements.


<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Recherche dans une table sans clé
<a name="recherche_dans_une_table_sans_cle_ELTTEXTE000105"></a>
Tous les enregistrements sont lus pour retrouver l'enregistrement recherché.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=rubrique_cle1.gif)


<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Recherche dans une table avec une clé
<a name="recherche_dans_une_table_avec_une_cle_ELTTEXTE000129"></a>
L'utilisation d'une clé permet de créer un INDEX. L'index est une boîte noire permettant un accès direct à l'enregistrement recherché.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=rubrique_cle2.gif)
