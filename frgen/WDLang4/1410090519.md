


## &lt;Variable Polygone2D&gt;.Chevauche (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Overlap***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si un polygone en 2 dimensions chevauche une autre géométrie. 

Les conditions nécessaires pour que deux géométries se chevauchent sont les suivantes :  

- Les géométries ont la même dimension (par exemple, deux géométries de type polygone en 2 dimensions). 

- Les intérieurs des géométries ont une intersection non vide de la même dimension que les géométries considérées. 

- Chaque géométrie possède au moins un point à l'intérieur de l'autre géométrie.

## Exemple


```wl
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-4.38, 6.50)
oPolygone2D_1.Contour.AjoutePoint(-6.81, 1.51)
oPolygone2D_1.Contour.AjoutePoint(-1.42, -0.23)
oPolygone2D_1.Contour.AjoutePoint(0.89, 4.19)
oPolygone2D_1.Contour.AjoutePoint(-4.38, 6.50)
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(2.35, 7.52)
oPolygone2D_2.Contour.AjoutePoint(-3.01, 4.47)
oPolygone2D_2.Contour.AjoutePoint(1.82, 2.10)
oPolygone2D_2.Contour.AjoutePoint(2.35, 7.52)
oPolygone2D_2 = oPolygone2D_2.Corrige()

Trace("oPolygone2D_1.Chevauche(oPolygone2D_2) = " + oPolygone2D_1.Chevauche(oPolygone2D_2))
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.Chevauche(<Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si les géométries se chevauchent, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000332"></a>

- Si la géométrie A est incluse dans la géométrie B, leur intersection est égale à la géométrie A. Dans ce cas, la fonction **&lt;Variable Polygone2D&gt;.Chevauche** renvoie <u><u><u><u>Faux</u></u></u></u>.

- Si les paramètres &lt;Géométrie A&gt; et &lt;Géométrie B&gt; sont identiques, la fonction **&lt;Variable Polygone2D&gt;.Chevauche** renvoie <u><u><u><u>Faux</u></u></u></u>.

- Si les géométries considérées sont des multipolygones, il suffit que l'un des polygones de la géométrie A chevauche un des polygones de la géométrie B pour que la fonction **&lt;Variable Polygone2D&gt;.Chevauche** renvoie <u><u><u><u>Vrai</u></u></u></u>.



<a name="NOTE0_2"></a>


### Parcours des données spatiales: utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000365"></a>

Il est possible d'effectuer un parcours sur une table avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **&lt;Variable Polygone2D&gt;.Chevauche**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante: 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où: 

- Fonction_WLangage correspond à la fonction **&lt;Variable Polygone2D&gt;.Chevauche**. 

- Rubrique_spatiale correspond à une rubrique spatiale de la table. Cette rubrique doit: 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque: Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, toute la table est parcourue: les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
