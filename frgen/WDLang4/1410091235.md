
## HPolitiqueSécuritéDébloqueCompte (Fonction)

***En anglais : HSecurityPolicyUnlockAccount***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de débloquer le compte d'un utilisateur bloqué à cause d'un trop grand nombre de tentatives d'ouverture de connexion infructueuses.

**Remarque**: Pour utiliser cette fonction, il est nécessaire d'être connecté au serveur HFSQL avec un compte utilisateur de type "super utilisateur". 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI PAS HPolitiqueSécuritéDébloqueCompte(maConnexionSuperUser, "monCompteBloque") ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HPolitiqueSécuritéDébloqueCompte(<Connexion> , <Utilisateur>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le compte a été débloqué, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion au serveur HFSQL à manipuler. Cette connexion correspond: 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md). 




**`<Utilisateur> : (Chaîne de caractères)`**

Nom de l'utilisateur dont le compte doit être débloqué.
