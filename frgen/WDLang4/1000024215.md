


## &lt;Source&gt;.DécritTable (Fonction)

***En anglais : &lt;Source&gt;.DescribeFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Décrit une table par programmation.

Après l'appel à la fonction **&lt;Source&gt;.DécritTable**:

- la table peut être manipulée comme n'importe quelle table décrite dans le schéma des données.

- la description de la table ne peut plus être modifiée.

- la variable de description de la table est ré-initialisée. Une nouvelle description de table peut être effectuée.




Pour annuler la description de table par programmation, utilisez la fonction [&lt;Source&gt;.AnnuleDéclaration](../WDLang4/1000024192.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

<a name="3044206_Exemple2"></a>

```wl
UneDescriptionFichier est une Description de Fichier
UneRubrique est une Description de Rubrique
sdSource est une Source de Données 
 
// Description de la table "CLIENT"
UneDescriptionFichier.Nom = "CLIENT"
UneDescriptionFichier.Type = hTableNormale
UneDescriptionFichier.CryptageFic = hCryptageStandard
 
// Description de la rubrique "NOM"
UneRubrique.Nom = "NOM"
UneRubrique.Type = hRubTexte
UneRubrique.Taille = 40
UneRubrique.TypeClé = hCléUnique
HDécritRubrique(UneDescriptionFichier, UneRubrique)
 
// Description de la rubrique "PRENOM"
UneRubrique.Nom = "PRENOM"
UneRubrique.Type = hRubTexte
UneRubrique.Taille = 40
HDécritRubrique(UneDescriptionFichier, UneRubrique)
 
// Valide la description de la table
sdSource.DécritFichier(UneDescriptionFichier)

HCrée (sdSource)
```

## Syntaxe

### Décrire une table par programmation via une source de données

`<Résultat> = <Source de données>.DécritFichier(<Table>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la description de la table est valide et peut être utilisée,

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Source de données> : (Variable de type Source de données)`**

Nom de la variable de type [Source de données](../WDLang4/1514053.md) associée à la table.

**`<Table> : (Variable de type Description de fichier)`**

Nom de la variable de type [Description de Fichier](../WDLang4/1514065.md) (voir paragraphe Notes) permettant de décrire la table. Le nom de la table sera défini grâce à la propriété [Nom](../Proprietes/2510082.md).

## Remarques


### Comment décrire une table par programmation? 
<a name="comment_decrire_une_table_par_programmation_ELTPARAGRAPHE000226"></a>

Pour décrire une table par programmation, il faut:

1. Déclarer une variable de type [Source de données](../WDLang4/1514053.md). 

2. Utiliser des variables de type [Description de Fichier](../WDLang4/1514065.md), [Description de Rubrique](../WDLang4/1514071.md), [Description de Liaison](../WDLang4/1514039.md) et [Description d'IndexFullText](../WDLang4/1000017461.md) (si nécessaire).

3. Décrire les caractéristiques de la table, de ses rubriques, de ses liaisons et de ses index full-text (si nécessaire) grâce aux propriétés HFSQL.

4. Fixer la description des rubriques avec la fonction [HDécritRubrique](../WDLang4/3044233.md).

5. Fixer la description des index full-text avec la fonction [HDécritIndexFullText](../WDLang4/1000017407.md).

6. Associer la description de la table à la source de données (fonction **&lt;Source&gt;.DécritTable**, syntaxe 2) et des liaisons si nécessaire (fonction [HDécritLiaison](../WDLang4/3044191.md)).




Remarque: Cette solution permet d'associer la table décrite à une source de données. Dans ce cas, lorsque cette variable sera supprimée, la table sera également supprimée.  
Attention: Pour utiliser cette syntaxe, il est nécessaire d'utiliser une source de données "automatique". Pour plus de détails, consultez [Description du projet: Onglet Compilation](../Editeurs/9500218.md).

### Les types de tables pouvant être décrits avec la fonction &lt;Source&gt;.DécritTable
<a name="les_types_tables_pouvant_etre_decrits_avec_fonction_docparampagetitleshort_ELTPARAGRAPHE000538"></a>

La propriété [Type](../Proprietes/2510131.md) permet de spécifier le type de la table à créer.

Les types suivants peuvent être créés avec la fonction **&lt;Source&gt;.DécritTable**:


|   |   |
| --- | --- |
| *hTableAS400* | Fichier AS 400 |
| *hTableNormale* | Fichier normal |
| *hTableOLEDB* | Fichier OLE DB |
| *hTableOracle* | Fichier Oracle |
| *hTableSQLAzure* | Fichier SQL Azure |
| *hTableSQLServer* | Fichier SQL Server |
| *hTableSybase* | Fichier Sybase |
| *hTableXBase* | Fichier xBase |
