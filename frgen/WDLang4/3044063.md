


## HNumEnr (Fonction)

***En anglais : HRecNum***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie:

- le numéro de l'enregistrement en cours dans la table HFSQL.

- le numéro de l'enregistrement en cours dans la vue HFSQL.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003044063&name=hnumenr_fonction">Voir des exemples supplémentaires</a>

```wl
// Enregistrement en cours de la table "Client"
EnrEnCoursClient = HNumEnr(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HNumEnr([<Table>])`
---

**`<Résultat> : (Entier)`**

Correspond:

- soit au numéro de l'enregistrement en cours dans la table.

- soit au numéro de l'enregistrement en cours dans la vue ou dans la requête (et non le numéro de l'enregistrement dans la table). 
	**Attention**: Utilisée sur une vue HFSQL Classic, ce paramètre ne correspond pas à la valeur de la variable [H.NumEnr](../WDLang4/3044076.md).

- soit à la constante *hNumEnrInvalide* si aucun enregistrement n'est en cours (position en dehors de la table).




La fonction [HErreur](../WDLang4/3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) Utilisée sur une vue Hyper File 5.5, la fonction **HNumEnr** renvoie le numéro d'enregistrement en cours dans la table associée à la vue.

**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table, de la requête ou de la vue HFSQL manipulée. 
Si ce paramètre n'est pas spécifié, la fonction **HNumEnr** va manipuler la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Tables non HFSQL
<a name="tables_non_hfsql_ELTPARAGRAPHE000096"></a>

- Il n'y a pas de numéro d'enregistrement sur les tables.

- L'appel de cette fonction provoque une erreur WLangage.
