


## HListeClésSpatiales (Fonction)

***En anglais : HListSpatialKeys***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des clés spatiales d'une table (d'une requête ou d'une vue) reconnues par le moteur HFSQL.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupérer les clés spatiales d'une table présente dans le schéma des données en cours
ListeClésSpatiales est une chaîne
ListeCléSpatiales = HListeClésSpatiales(Communes)
// Ajoute la liste des clés spatiales dans COMBO_Combo1
ListeAjoute(COMBO_Combo1, ListeClésSpatiales)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HListeClésSpatiales(<Table> [, <Chemin du WDD> [, <Mot de passe du WDD>]])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des clés spatiales présentes dans la table spécifiée. Les noms des rubriques correspondant à des rubriques spatiales sont séparés par RC (Retour chariot). 

**`<Table> : (Chaîne de caractères)`**

Nom de la table (de la requête ou de la vue) dont les clés spatiales doivent être listées.

Si un nom de requête est spécifié, cette requête doit être en cours d'exécution (fonctions [HExécuteRequête](../WDLang4/3044080.md) ou [HExécuteRequêteSQL](../WDLang4/3044084.md)) pour que la fonction **HListeClésSpatiales** fonctionne. Dans le cas contraire, une erreur du WLangage est générée.

**`<Chemin du WDD> : (Chaîne de caractères optionnelle)`**

Chemin complet du schéma des données (c'est-à-dire du fichier .WDD) dans lequel la table est décrite. 
Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), la table est recherchée dans le schéma des données en cours.

**`<Mot de passe du WDD> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe défini pour le schéma des données. 
Si aucun mot de passe n'est défini, ce paramètre doit être égal à une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md).
