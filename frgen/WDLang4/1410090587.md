


## &lt;Variable Polygone2D&gt;.Union (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Union***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la géométrie correspondant à l'union entre un polygone en 2 dimensions et une autre géométrie.  
<br>![Géométries A et B de départ](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Union_Avant.png)

<br>![Résultat de l'union](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Union_apres.png)
**Remarque** : Si le type des géométries passées en paramètres est connu, alors le type du résultat est également pré-déterminé. La plupart des applications géospatiales ne travaillant pas avec des colonnes de données hétérogènes (rubrique de type "Géométrie" autorisant de mixer des points, lignes, polygones au sein d'une même rubrique), il n'y a donc en général pas besoin de vérifier le type des géométries obtenues.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(2.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, 2.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(2.00, 2.00)
// Corrige la géométrie créée
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(1.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(1.00, 1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
// Corrige la géométrie créée
oPolygone2D_2 = oPolygone2D_2.Corrige()

// On récupère l'union en tant que MultiPolygone2D
// L'union de deux polygones renvoie toujours un MultiPolygone
différence_symétrique est un MultiPolygone2D = oPolygone2D_1.Union(oPolygone2D_2)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.Union(<Géométrie B>)`
---

**`<Résultat> : (Variable de type MultiPoint2D, MultiPointGéo, MultiPolyligne2D, MultiPolyligneGéo, MultiPolygone2D ou MultiPolygoneGéo)`**

Résultat de l'union. Cette géométrie contient une collection de géométries d'un type donné : 

- [MultiPoint2D](../WDLang4/1410090129.md) ou [MultiPointGéo](../WDLang4/1410090130.md), 

- [MultiPolyligne2D](../WDLang4/1410090131.md) ou [MultiPolyligneGéo](../WDLang4/1410090133.md), 

- [MultiPolygone2D](../WDLang4/1410090135.md) ou [MultiPolygoneGéo](../WDLang4/1410090136.md). 


Si l'union entre deux géométries est constituée d'un seul élément, la collection contiendra un seul élément.
Si l'union est vide (par exemple en calculant l'union de multipolygones vides), la collection est vide.
Si le résultat de l'union est disjoint (par exemple en faisant l'union de deux géométries disjointes), la collection contient plusieurs éléments.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Seconde géométrie prise en compte pour l'union. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).
