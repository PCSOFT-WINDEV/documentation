


## &lt;Source&gt;.VersTable (Fonction)

***En anglais : &lt;Source&gt;.ToFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Copie une source de données (table, requête, vue, ...) vers une table physique HFSQL de même description. Ce table n'est ni cryptée, ni protégée par mot de passe.  

Cette fonction permet par exemple de sauvegarder un historique : une requête sélectionne tous les enregistrements de l'année 2019, le résultat est transféré dans une table, et une nouvelle requête supprime tous les enregistrements de l'année 2019.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI MaVue.VersFichier("C:\temp\Test.fic") = Vrai ALORS
	Info("Données transférées dans une table")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.VersFichier(<Fichier destination>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire (par exemple le fichier destination existe déjà).




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom logique de la source de données à copier (table, vue, requête, ...).

**`<Fichier destination> : (Chaîne de caractères)`**

Nom complet de la table physique dans laquelle les enregistrements de la source doivent être copiés. Ce table aura la même description que la source de données. Pour accéder à cette table, utilisez par exemple la fonction [&lt;Source&gt;.DéclareExterne](../WDLang4/1000024214.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Source filtrée
<a name="source_filtree_ELTPARAGRAPHE000206"></a>

Si un filtre est défini et actif sur la source de données, seuls les enregistrements correspondant au filtre seront copiés.
<a name="NOTE0_2"></a>


### Source de données : Vue ou requête
<a name="source_donnees_vue_requete_ELTPARAGRAPHE000216"></a>

Si la source de données est une vue ou une requête, toutes les rubriques seront des clés de la table créée à l'exception :

- des rubriques de type Mémo.

- des rubriques dont la taille est supérieure à 260 caractères et non clé dans le fichier source de la vue ou de la requête.
