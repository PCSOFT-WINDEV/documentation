


## PolyligneGéoAjoutePoint (Fonction)

***En anglais : LinestringGeoAddPoint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un nouveau point dans une polyligne géographique.

Rappel : Un polygone géographique est un ensemble de polylignes géographiques. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Déclaration d'une polyligne
maPolyligneGéo est une PolyligneGéo
// Construction de la polyligne : 4 points
PolyligneGéoAjoutePoint(maPolyligneGéo, 2.681548, 43.802043)
PolyligneGéoAjoutePoint(maPolyligneGéo, 2.816297, 43.725179)
PolyligneGéoAjoutePoint(maPolyligneGéo, 2.842733, 43.817899)
PolyligneGéoAjoutePoint(maPolyligneGéo, 2.644979, 43.837466)
// Sérialisation au format WKT
Trace("maPolyligneGéo : " + GéométrieSérialiseWKT(maPolyligneGéo))
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PolyligneGéoAjoutePoint(<Polyligne géographique> , <Latitude> , <Longitude>)`
---

**`<Polyligne géographique> : (Variable de type PolyligneGéo)`**

Nom de la variable de type [PolyligneGéo](../WDLang4/1410090128.md) à laquelle un nouveau point doit être ajouté. 

**`<Latitude> : (Réel)`**

Latitude du point.

**`<Longitude> : (Réel)`**

Longitude du point.
