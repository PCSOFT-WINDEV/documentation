


## HListeTrigger (Fonction)

***En anglais : HListTrigger***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des triggers appliqués sur une ou plusieurs tables HFSQL. 

**Rappel**: Un trigger est une procédure en WLangage appelée automatiquement à chaque exécution d'une ou de plusieurs fonctions HFSQL. Pour plus de détails, consultez [Gestion des triggers](../WDLang4/3044271.md)


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupérer les triggers appliqués sur les tables Client et Produit
ListeTriggers est une chaîne
ListeTriggers = HListeTrigger("Client,Produit")

// Ajoute la liste des triggers dans la combo COMBO_COMBO1
ListeAjoute(COMBO_COMBO1, ListeTriggers)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HListeTrigger([<Nom de la ou des tables>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des triggers appliqués sur la ou les tables spécifiées. Les différents triggers sont séparés par des retours chariot (RC).
La liste est de la forme:


```txt
<Fichier de données> + TAB + <Procédure WLangage> + TAB + 
<Fonction HFSQL> + TAB + <Type de Trigger> + 
TAB + <Etat du Trigger> + RC + ...
```



|   |   |
| --- | --- |
| &lt;Etat du trigger&gt; | <br><br>- "1" pour un trigger actif (fonction [HActiveTrigger](../WDLang4/3044155.md)),<br><br>- "0" pour un trigger inactif (fonction [HDésactiveTrigger](../WDLang4/3044089.md)).<br><br><br> |
| &lt;Fonction HFSQL&gt; | Fonction HFSQL sur laquelle s'applique le trigger. |
| &lt;Procédure WLangage&gt; | Nom de la procédure WLangage appelée par le trigger. |
| &lt;Table&gt; | Nom de la table sur laquelle s'applique le trigger. |
| &lt;Type de Trigger&gt; | <br><br>- "A" pour un trigger "AVANT" (la procédure associée au trigger est exécutée **avant** la fonction HFSQL du trigger).<br><br>- "P" pour un trigger "APRES" (la procédure associée au trigger est exécutée **après** la fonction HFSQL du trigger).<br><br><br> |



**`<Nom de la ou des tables> : (Chaîne de caractères optionnelle)`**

Nom d'une ou de plusieurs tables. Si ce paramètre n'est pas spécifié, les triggers de toutes les tables du schéma des données associé au projet en cours seront listés.
Pour indiquer plusieurs noms, séparez les noms des tables par une virgule (",").

### Un même trigger est appliqué sur plusieurs fichiers ou sur plusieurs fonctions WLangage
<a name="meme_trigger_est_applique_sur_plusieurs_fichiers_sur_plusieurs_fonctions_wlangage_ELTPARAGRAPHE000083"></a>

Si un trigger (décrit avec la fonction [HDécritTrigger](../WDLang4/3044074.md)) est appliqué sur plusieurs tables ou plusieurs fonctions WLangage, ce trigger apparaîtra plusieurs fois dans la liste (selon le nombre de fonctions HFSQL et/ou de tables).

**Exemple 1:** un trigger est appliqué sur plusieurs tables:


```wl
// Décrit un trigger appliqué sur les tables Client et Produit
HDécritTrigger("Client,Produit", "HAjoute", "VerifParam", hTriggerAvant)
MaListe est une chaîne = HListeTrigger()

// Le contenu de MaListe sera le suivant:
// Client  <TAB>  VerifParam  <TAB>  HAjoute  <TAB>  A  <TAB>  1
// Produit  <TAB>  VerifParam  <TAB>  HAjoute  <TAB>  A  <TAB>  1
```


****

**Exemple 2:** un trigger est appliqué sur plusieurs fonctions HFSQL:


```wl
// Décrit un trigger appliqué sur les fonctions HAjoute et HModifie
HDécritTrigger("CLIENT", "HAjoute,HModifie", "VerifParam", hTriggerAprès)
MaListe est une chaîne = HListeTrigger()
// Le contenu de MaListe est le suivant:
// CLIENT  <TAB>  VerifParam  <TAB>  HAjoute  <TAB>  P  <TAB>  1
// CLIENT  <TAB>  VerifParam  <TAB>  HModifie <TAB>  P  <TAB>  1
```

<a name="NOTE0_2"></a>


### Compatibilité avec les versions antérieures
<a name="compatibilite_avec_les_versions_anterieures_ELTPARAGRAPHE000103"></a>La syntaxe suivante de la fonction est conservée par compatibilité:


```txt
<Résultat> = HListeTrigger([<Nom de la table> [, <Nom complet du WDD>]])
```
 
Le paramètre &lt;Nom complet du WDD&gt; est conservé pour compatibilité. Ce paramètre est simplement ignoré.
