


## hParamètreFichier (Type de variable)

***En anglais : hFileParameter***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **hParamètreFichier** permet de définir les tables prises en compte par une tâche d'optimisation planifiée. Les caractéristiques de ces tables peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Ce type de variable est utilisé par le type [hOptimisationPlanifiée](../WDLang4/1000018854.md) et par différentes fonctions WLangage. 

**Remarque**: Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Recalculer les statistiques des fichier de la base "MaBase", 
// tous les samedis à 23H00
Optim est une hOptimisationPlanifiée
Optim.Description = "Recalcul des statistiques des fichiers de la base de données MaBase"

Optim.Planification.Mois = "*"
Optim.Planification.JourDeLaSemaine = "samedi"
Optim.Planification.Heure = "23"
Optim.Planification.Minute = "0"

Optim.Fichier[1].Nom = "MaBase"
Optim.Fichier[1].Option = hOptStat

HAjouteOptimisationPlanifiée(MaConnexion, Optim)
```

## Propriétés


### Propriétés spécifiques à la description des variables de type hParamètreFichier
<a name="proprietes_specifiques_description_des_variables_type_hparametrefichier_ELTPARAGRAPHE000038"></a>

Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hParamètreFichier**:

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| MotDePasse | Chaîne de caractères ou Chaîne secrète | Mot de passe des tables cryptées.<br>**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".<br>Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). <br><br>Cette propriété est disponible en écriture uniquement. |
| Nom | Chaîne de caractères | Nom de la table à traiter. Ce nom peut correspondre à une chaîne de type: <br><br>- &lt;Nom de la base&gt;/&lt;Nom de la table&gt;: Optimisation de la table "Nom de la table" dans la base "Nom de la base". <br><br>- &lt;Nom de la base&gt;: Optimisation de toutes les tables contenues dans la base "Nom de la base".<br><br>- "\*": Optimisation de toutes les tables de toutes les bases de données du serveur.<br><br><br> |
| Option | Constante de type Entier | Option d'optimisation: <br><br>- *hOptIndex*: Provoque la réindexation des tables. Cette réindexation est effectuée à chaud sur les index et les index full-text. <br><br>- *hOptStat*: Provoque le recalcul des statistiques sur les tables. Le résultat est similaire à l'utilisation de la fonction [HStatCalcule](../WDLang4/3044134.md). Ce traitement est effectué à chaud.<br><br><br><br><br>Attention: Cette propriété est prise en compte uniquement lors de l'utilisation d'une variable de type [hOptimisationPlanifiée](../WDLang4/1000018854.md). |

## Remarques


### Fonctions utilisant les variables de type hParamètreFichier
<a name="fonctions_utilisant_les_variables_type_hparametrefichier_ELTPARAGRAPHE000092"></a>




|   |   |
| --- | --- |
| [HRéindexeAsynchrone](../WDLang4/1410091053.md) | Reconstruit l'index d'une table HFSQL Client/Serveur (table d'extension ".NDX"). Cette réindexation est asynchrone: elle est effectuée sur le serveur et ne bloque pas le poste Client. <br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [HStatCalculeAsynchrone](../WDLang4/1410091108.md) | Réalise diverses statistiques sur les clés d'une table HFSQL Client/Serveur.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [HVérifieIndexAsynchrone](../WDLang4/1410091105.md) | Vérifie que les données contenues dans le fichier d'index (fichier .NDX) référencent correctement les données contenues dans la table HFSQL Client/Serveur (table .FIC).<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [HVérifieMémoAsynchrone](../WDLang4/1410091107.md) | Vérifie l'intégrité structurelle des mémos d'une table HFSQL Client/Serveur.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
