


## HVérifieMémoAsynchrone (Fonction)

***En anglais : HCheckMemoAsynchronous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie l'intégrité structurelle des mémos d'une table HFSQL Client/Serveur. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauAjoute(TableauFichier, MonFichierParam)

HVérifieMémoAsynchrone(CnxBaseDeDonnées, TableauFichier, CB_HVérifieMémoAsynchrone)
	PROCÉDURE INTERNE CB_HVérifieMémoAsynchrone(MaTable est une chaîne, MonRésultat est une chaîne)
		SI MonResultat = "" ALORS
			Trace("Table traitée et vérifiée " + MaTable)
		SINON
			Trace("Table traitée avec problème " + MaTable)
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HVérifieMémoAsynchrone(<Connexion> , <Tables à vérifier> [, <Procédure WLangage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la vérification a été lancée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion vers le serveur contenant les tables à manipuler. Cette connexion correspond:

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).




**`<Tables à vérifier> : (Tableau de variables de type hParamètreFichier)`**

Nom du tableau de variables de type [hParamètreFichier](../WDLang4/1000018900.md) correspondant à la liste des tables à traiter. 

**`<Procédure WLangage> : (Nom de procédure optionnel)`**

Nom de la procédure WLangage (également nommée "callback") appelée pour chaque table traitée. Cette procédure permet de manipuler la table en cours.

Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction HVérifieMémoAsynchrone](../WDLang4/1410091106.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La vérification de la liste des blocs libres est effectuée uniquement en HFSQL Client/Serveur.

- La fonction **HVérifieMémoAsynchrone** est plus rapide que la fonction [HRéindexeAsynchrone](../WDLang4/1410091053.md) utilisée avec la constante *hVérifieMémo*. 

- Si un problème est détecté, il est possible d'utiliser la fonction [HRéindexeAsynchrone](../WDLang4/1410091053.md) avec la constante *hVérifieMémo*.
