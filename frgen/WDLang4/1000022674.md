


## &lt;Variable Connexion&gt;.InfoPropriétéTable (Fonction)

***En anglais : &lt;Connection variable&gt;.InfoFileProperty***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de connaître les propriétés d'une table située sur un serveur HFSQL.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
NomPropriétaire est une chaîne
NomPropriétaire = MaConnexion.InfoPropriétéFichier(hPropriétaire, "MaBaseDeDonnées", "Client.fic")
SI NomPropriétaire <> "" ALORS 
	Trace("Propriétaire de la base de donnée : " + NomPropriétaire)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Connexion>.InfoPropriétéFichier(<Propriété> , <Base de données> , <Table>)`
---

**`<Résultat> : (Chaîne de caractères)`**



- Valeur de la propriété demandée, 

- Chaîne vide ("") en cas d'erreur.




**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion pour laquelle la valeur d'une propriété est recherchée.

**`<Propriété> : (Constante de type Entier)`**

Propriété du fichier recherchée : 


|   |   |
| --- | --- |
| *hApplication* | Nom de l'application à partir de laquelle la table a été créée. <br>Si cette constante est utilisée, &lt;Résultat&gt; est une chaîne de caractères de la forme : <br>&lt;Nom de l'exécutable&gt;(&lt;Nom du projet&gt;). |
| *hCréateur* | Nom du propriétaire de la table.<br>Si cette constant est utilisée, &lt;Résultat&gt; est une chaîne de caractères. |
| *hDate* | Date de la création de la table. <br>Si cette constante est utilisée, &lt;Résultat&gt; est une chaîne de caractères de la forme AAAAMMJJHHmmSSCCC. |
| *hMachine* | Nom du poste à partir duquel a été créée la table. <br>Si cette constante est utilisée, &lt;Résultat&gt; est de la forme : <br>&lt;Nom du poste client&gt; + TAB + &lt;Adresse IP du poste Client&gt;. |
| *hNotes* | Description de la table ou toute autre information associée à la table grâce à la fonction [&lt;Variable Connexion&gt;.ModifiePropriétéTable](../WDLang4/1000022718.md). <br>Si cette constante est utilisée, &lt;Résultat&gt; est une chaîne de caractères. |
| *hPropriétaire* | Propriétaire de la table. <br>Si cette constante est utilisée, &lt;Résultat&gt; est une chaîne de caractères. |



**`<Base de données> : (Chaîne de caractères)`**

Nom de la base de données contenant le fichier pour lequel les propriétés sont recherchées. 
Si ce paramètre correspond à une chaîne vide (""), la base de données utilisée sera celle définie dans la connexion. 
Si aucune base de données n'est définie dans la connexion, une erreur WLangage sera générée.

**`<Table> : (Chaîne de caractères)`**

Nom de la table HFSQL pour laquelle les propriétés sont recherchées. L'extension du fichier doit être précisée.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Pour modifier les propriétés d'une table, utilisez la fonction [&lt;Variable Connexion&gt;.ModifiePropriétéTable](../WDLang4/1000022718.md).

- Attention : la table manipulée doit avoir été créée sur le serveur (fonctions [&lt;Source&gt;.Crée](../WDLang4/1000024207.md) ou [&lt;Source&gt;.CréeSiInexistant](../WDLang4/1000024208.md)).
