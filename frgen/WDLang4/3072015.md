
## SQLFerme (Fonction)

***En anglais : SQLClose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déclare la fin d'exécution d'une requête et libère les ressources mémoire allouées lors de l'exécution de la requête (fonction [SQLExec](../WDLang4/3072007.md) ou [SQLExecWDR](../WDLang4/3072010.md)).

**Attention** : La libération d'une requête est obligatoire, même si l'exécution de la requête a échoué.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Les fonctions SQL permettent de manipuler des bases de données locales (de type Web SQL database). Pour plus de détails, consultez [Accès en mode local à une base de données (SQLite)](../WDLang4/9000119.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la requête et récupération des informations
ResSQL = SQLExec("SELECT* FROM FACT", "REQ1")
SI ResSQL = Faux ALORS
	SQLInfoGene("REQ1")
	Info("Erreur SQL : " + SQL.MesErreur)
SINON
	SQLTable("REQ1", TABLE_Table1)
FIN
SQLFerme("REQ1")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`SQLFerme(<Nom de la requête>)`
---

**`<Nom de la requête> : (Chaîne de caractères)`**

Nom de la requête : 

- créée et exécutée avec la fonction [SQLExec](../WDLang4/3072007.md), 

- exécutée avec la fonction [SQLExecWDR](../WDLang4/3072010.md).




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Les requêtes créées avec l'éditeur de requêtes doivent être spécifiées sous forme d'une chaîne de caractères avec guillemets. 

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Seules les requêtes créées et exécutées avec la fonction [SQLExec](../WDLang4/3072007.md) sont disponibles.
