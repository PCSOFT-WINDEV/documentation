


## &lt;Source&gt;.BloqueTable (Fonction)

***En anglais : &lt;Source&gt;.LockFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Bloque une table et restreint l'accès à cette table pour tous les autres sites ou applications. La table pourra ensuite être débloquée grâce à la fonction [&lt;Source&gt;.DébloqueTable](../WDLang4/1000024211.md).

Après l'exécution de la fonction **&lt;Source&gt;.BloqueTable**, plusieurs cas peuvent se présenter :

- Un enregistrement de la table est déjà bloqué par une autre application : le blocage ne peut pas être effectué.

- La table est déjà bloquée par une autre application : le blocage ne peut pas être effectué.




Lors d'un problème de blocage, la fonction [HErreurBlocage](../WDLang4/3044099.md) renvoie <u><u><u>Vrai</u></u></u>.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonction peut être utilisée avec des tables HFSQL Client/Serveur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Blocage de la table CLIENT
SI Client.BloqueFichier(HBlocageLectureEcriture) = Faux ALORS
	SI HErreurBlocage() = Vrai ALORS
		Erreur("Opération impossible")
	FIN
FIN
// Traitement sur la table ...
...
// Redonner l'accès à la table
Client.DébloqueFichier()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.BloqueFichier([<Blocage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le blocage a été réalisé, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème (par exemple le fichier est déjà bloqué, ...). La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table manipulée. 

**`<Blocage> : (Constante optionnelle de type entier)`**

Permet de déterminer le type de blocage effectué sur la table :



|   |   |
| --- | --- |
| *hBlocageEcriture*<br>(valeur par défaut) | Blocage en écriture : les enregistrements de la table pourront être lus par une autre application mais ne pourront pas être modifiés par une autre application. Aucun blocage sur la table ne pourra être défini par une autre application. |
| *hBlocageLectureEcriture* | Blocage en lecture/écriture : les enregistrements de la table ne pourront ni être lus ni être modifiés par une autre application. Aucun blocage sur la table ne pourra être défini par une autre application. |
| *hBlocageNon* | Aucun effet |


![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) Le paramètre &lt;Blocage&gt; n'est pas pris en compte.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) La gestion des blocages est réalisée uniquement sur les tables HFSQL Client/Serveur.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Modification du type de blocage sur une table
<a name="modification_type_blocage_sur_une_table_ELTPARAGRAPHE000270"></a>

Pour modifier le type de blocage d'une table, appelez la fonction **&lt;Source&gt;.BloqueTable** avec le type de blocage souhaité. Il n'est pas nécessaire de débloquer la table au préalable.
<a name="NOTE0_2"></a>


### Influence du mode de blocage
<a name="influence_mode_blocage_ELTPARAGRAPHE000282"></a>

Si la table est en mode de blocage *hModeMono* (voir la fonction [&lt;Source&gt;.Mode](../WDLang4/1000025037.md)), la fonction **&lt;Source&gt;.BloqueTable** n'a aucun effet.
<a name="NOTE0_3"></a>


### Échec du blocage
<a name="echec_blocage_ELTPARAGRAPHE000299"></a>

Si la table (ou un de ses enregistrements) est déjà bloquée, la demande de blocage est répétée [H.NbEssais](../WDLang4/3044075.md) fois (50 par défaut).

Si au bout des ***H.NbEssais*** tentatives la table ne peut être bloquée, la fonction [HErreurBlocage](../WDLang4/3044099.md) renvoie <u><u><u><u>Vrai</u></u></u></u>.
