


## HGèreTransaction (Fonction)

***En anglais : HSetTransaction***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active ou désactive la gestion des transactions sur une ou plusieurs tables.

Lorsque la gestion des transaction est désactivée, toutes les fonctions relatives aux transactions sont inhibées ([HTransactionDébut](../WDLang4/3044002.md), [HTransactionFin](../WDLang4/3044032.md), [HTransactionAnnule](../WDLang4/3044001.md)).

**Remarque**: Par défaut, la gestion des transactions est active.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette fonction peut être utilisée uniquement avec des tables HFSQL Client/Serveur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Désactive la gestion des transactions sur la table Client
HGèreTransaction(Client, Faux)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HGèreTransaction([<Table>, ] <Options>)`
---

**`<Résultat> : (Booléen)`**

Correspond à l'ancienne gestion des transactions (avant utilisation de la fonction **HGèreTransaction**): 

- <u><u><u><u>Vrai</u></u></u></u> si la gestion des transactions était active, 

- <u><u><u><u>Faux</u></u></u></u> si la gestion des transactions n'était pas active. 


Si &lt;Fichier de données&gt;= "\*", &lt;Résultat&gt; est à <u><u><u><u>Vrai</u></u></u></u> si dans l'ancien mode de gestion des transactions, la gestion des transactions était active au moins sur un des fichiers de données.

**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. Si ce nom n'est pas spécifié ou correspond à "\*", la gestion des transactions est prise en compte pour toutes les tables du schéma des données.

**`<Options> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la gestion des transactions sur la table doit être activée,

- <u><u><u><u>Faux</u></u></u></u> si cette gestion doit être désactivée.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion des transactions activée
<a name="gestion_des_transactions_activee_ELTPARAGRAPHE000121"></a>

Si la gestion des transactions est activée pour une seule table, seules les manipulations réalisées sur cette table seront prises en compte dans la gestion des transactions (quels que soient les tables indiquées dans la fonction [HTransactionDébut](../WDLang4/3044002.md)).
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 

### Limite 
<a name="limite_ELTPARAGRAPHE000135"></a>

La gestion des transactions ne s'applique pas aux fichiers xBase.
