


## &lt;Connexion HFSQL&gt;.ExécuteProcédureAsynchrone (Fonction)

***En anglais : &lt;HFSQL Connection&gt;.ExecuteAsynchronousProcedure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Exécute une procédure stockée en mode asynchrone. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCEDURE INTERNE MaCallbackCliente(CResultatPS est un Variant)
		Trace("Ma callback " + CResultatPS)
FIN
soit sRésultat = MaConnexion1.ExécuteProcédureAsynchrone(ProcédureStockée, (ParametreP), MaCallbackCliente)
Trace(sRésultat)
Trace("fin PS")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Connexion>.ExécuteProcédureAsynchrone(<Procédure stockée> , <Paramètre 1> ... [, <Paramètre N> [, <Procédure WLangage de fin>]])`
---

**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) correspondant à la connexion vers le serveur qui exécute la procédure stockée. 

**`<Procédure stockée> : (Procédure WLangage)`**

Nom de la procédure stockée à exécuter.

**`<Paramètre 1> : (Variant optionnel)`**

Premier paramètre à passer à la procédure &lt;Procédure stockée&gt;.



**`<Paramètre N> : (Variant optionnel)`**

Nième paramètre à passer à la procédure &lt;Procédure stockée&gt;.

**`<Procédure WLangage de fin> : (Nom de procédure optionnel)`**

Procédure WLangage (également nommée "callback") exécutée à la fin de l'exécution de la procédure. Cette procédure est de la forme: 

```txt
PROCEDURE Nom_Procédure(<Retour> est un variant)
```
 où &lt;Retour&gt; correspond au retour de la procédure stockée. 

- La variable [ErreurDétectée](../WDLang1/3087001.md) utilisée dans cette procédure est à <u><u><u><u>Vrai</u></u></u></u> si la procédure stockée à rencontrée une erreur (erreur d'exécution, perte de la connexion, etc.). 
	En cas de reconnexion automatique, la fonction **&lt;Connexion HFSQL&gt;.ExécuteProcédureAsynchrone** n'est pas rappelée automatiquement.  

- Cette procédure s'exécute dans la copie du contexte HFSQL réalisée lors de l'appel à la fonction **&lt;Connexion HFSQL&gt;.ExécuteProcédureAsynchrone**.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion automatique des erreurs
<a name="gestion_automatique_des_erreurs_ELTPARAGRAPHE000241"></a>

La gestion automatique des erreurs est désactivée dans les procédures stockées. Il est cependant possible d'utiliser la fonction [&lt;Source&gt;.SurErreur](../WDLang4/1000025073.md) pour exécuter une procédure spécifique (procédure stockée).
<a name="NOTE0_2"></a>


### Passage de paramètres
<a name="passage_parametres_ELTPARAGRAPHE000256"></a>

Les paramètres passés à la procédure stockée sont passés "par valeur": si ces paramètres sont modifiés dans la procédure stockée, ils ne seront pas modifiés dans l'application qui a exécuté cette procédure stockée (fonctionnement inverse de la fonction [&lt;Variable Connexion&gt;.ExécuteProcédure](../WDLang4/1000022659.md)).
<a name="NOTE0_3"></a>


### Exécution d'une procédure stockée depuis un code SQL
<a name="execution_une_procedure_stockee_depuis_code_sql_ELTPARAGRAPHE000271"></a>

Une procédure stockée peut être appelée: 

- depuis du code SQL, par exemple avec les fonctions [&lt;Source&gt;.ExécuteRequêteSQL](../WDLang4/1000024948.md) ou [SQLExec](../WDLang4/3072007.md), 

- depuis une application tierce utilisant le [driver ODBC pour HFSQL](../WDLang4/9000160.md) ou le [provider OLE DB pour HFSQL](../WDLang4/9000059.md). 




Pour plus de détails, consultez [Procédures et requêtes stockées (HFSQL Client/Serveur)](../WDLang4/3044360.md).
