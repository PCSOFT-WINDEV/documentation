


## HFermeSchémaDesDonnées (Fonction)

***En anglais : HCloseAnalysis***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme le schéma des données en cours (ou tous les schémas des données en cours dans le cas d'un projet multi-schémas des données). 

Toutes les tables, vues HFSQL et requêtes actuellement ouvertes sont fermées et libérées. Après l'exécution de la fonction **HFermeSchémaDesDonnées**, aucun schéma des données n'est en cours.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png)![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png) 
```wl
// Ouvre un schéma des données
HOuvreSchémaDesDonnées("C:\Gestcom\Gestcom.WDD")
// Traitements 
...
// Ferme le schéma des données actuellement utilisé par l'application
HFermeSchémaDesDonnées()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HFermeSchémaDesDonnées()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le schéma des données a été fermé, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème : le schéma des données n'est pas fermé. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Un projet peut être associé à une ou plusieurs analyses (projets multi-analyses).

- La fonctions **HFermeSchémaDesDonnées** permet de fermer : 

	- les schémas des données ouverts avec la fonction [HOuvreSchémaDesDonnées](../WDLang4/3044106.md).

	- les schémas des données ouverts avec la fonction [HOuvreSchémaDesDonnéesComplémentaire](../WDLang4/1410090082.md).




- Si aucun schéma des données n'est en cours, la fonction **HFermeSchémaDesDonnées** n'a aucun effet.
