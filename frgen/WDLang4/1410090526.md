


## &lt;Variable Polygone2D&gt;.Couvre (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Cover***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une géométrie A de type polygone en 2 dimensions couvre une géométrie B. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=FormeCouvre.gif)
Remarques : 

- Si la géométrie A couvre la géométrie B, tout point de la géométrie B se trouve à l'intérieur ou dans le contour de la géométrie A. Dans ce cas, il n'existe aucun point de la géométrie B à l'extérieur de la géométrie A.

- Différence par rapport à la fonction [&lt;Variable Polygone2D&gt;.Contient](../WDLang4/1410090522.md) : Avec la fonction **&lt;Variable Polygone2D&gt;.Couvre**, il n'est pas nécessaire d'avoir un point de l'intérieur de la géométrie B à l'intérieur de la géométrie A. Ainsi, un polygone couvre son contour, mais il ne le contient pas.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Création d'un grand polygone
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-5.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(4.00, 5.00)
oPolygone2D_1.Contour.AjoutePoint(4.00, -3.00)
oPolygone2D_1.Contour.AjoutePoint(-4.00, -3.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-5.00, 3.00)

// Création d'un plus petit polygone, à l'intérieur du grand
oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(-2.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(0.00, -1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(-2.00, 1.00)

// Tests des fonctions Géométrie.Couvre et Géométrie.Contient
//--------------------------------------------------
oPolygone2D_1.Couvre(oPolygone2D_2) // Vrai
oPolygone2D_1.Contient(oPolygone2D_2) // Vrai également

oPolygone2D_1.Couvre(oPolygone2D_1.Contour) // Vrai : un polygone COUVRE son contour !
oPolygone2D_1.Contient(oPolygone2D_1.Contour) // Faux : un polygone ne CONTIENT PAS son contour !
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.GéométrieCouvre(<Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie A couvre la géométrie B, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).

## Remarques


### Parcours des données spatiales: utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000339"></a>

Il est possible d'effectuer un parcours sur une table avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **&lt;Variable Polygone2D&gt;.Couvre**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante: 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où: 

- Fonction_WLangage correspond à la fonction **&lt;Variable Polygone2D&gt;.Couvre**. 

- Rubrique_spatiale correspond à une rubrique spatiale de la table. Cette rubrique doit: 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque: Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, toute la table est parcourue: les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
