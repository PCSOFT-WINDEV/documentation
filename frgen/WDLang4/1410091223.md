


## &lt;Connexion HFSQL&gt;.VérifieIndexAsynchrone (Fonction)

***En anglais : &lt;HFSQL connection&gt;.CheckIndexAsynchronous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie que les données contenues dans le fichier d'index (fichier .NDX) référencent correctement les données contenues dans la table (fichier .FIC). Cette fonction concerne uniquement les tables HFSQL Client/Serveur.
La table HFSQL Client/Serveur vérifiée est automatiquement bloquée en écriture pendant la vérification.

**Rappel**: Un index est corrompu lorsque l'un des enregistrements qu'il référence n'est pas celui attendu. Dans ce cas, il est nécessaire de réindexer la table.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaConnexion1 est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauFichier.Ajoute(MonFichierParam)

MaConnexion1.VérifieIndexAsynchrone(TableauFichier, Callback_HVérifieIndexAsynchrone)

	PROCÉDURE INTERNE Callback_HVérifieIndexAsynchrone(MaTable est une chaîne, 
			MonRésultat est un entier, CompteRendu est une chaîne)
		Res est une chaîne
		SELON MonRésultat
			CAS 0: Res = "Index correct"
			CAS 1: Res = "Le fichier nécessite une optimisation."
			CAS 2: Res = "Erreur HFSQL " + HErreurInfo() 
		FIN
		Trace("Nom de la table traitée " + MaTable)
		Trace("Résultat fonction? ", Res)
		Trace("Compte-rendu: " + Remplace(CompteRendu, RC, "<RC>"))
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion>.VérifieIndexAsynchrone(<Tables à vérifier> [, <Procédure WLangage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la vérification a été lancée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Connexion> : (Variable de type Connexion)`**

Connexion vers le serveur contenant les tables à manipuler. Cette connexion correspond au nom d'une variable de type [Connexion](../WDLang4/1514073.md).

**`<Tables à vérifier> : (Tableau de variables de type hParamètreFichier)`**

Nom du tableau de variables de type [hParamètreFichier](../WDLang4/1000018900.md) correspondant à la liste des tables à traiter.

**`<Procédure WLangage> : (Nom de procédure optionnel)`**

Nom de la procédure WLangage (également nommée "callback") appelée pour chaque table traitée. Cette procédure permet de manipuler la table en cours.

Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction &lt;Connexion HFSQL&gt;.VérifieIndexAsynchrone](../WDLang4/1410091216.md).
