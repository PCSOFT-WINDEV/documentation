


## HActiveFiltreAuto (Fonction)

***En anglais : HActivateAutoFilter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active un filtre automatique sur les tables reliées lors du parcours d'un fichier XML. Ce filtre peut être désactivé grâce à la fonction [HDésactiveFiltreAuto](../WDLang4/3044298.md).

**Attention**: Cette fonction est disponible uniquement pour le Connecteur Natif XML.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Activation de tous les filtres auto possibles de la table Client
HActiveFiltreAuto(Client, "*" )
// sauf entre les tables Client et Commande
HDésactiveFiltreAuto(Client, Commande)

/////////////////////////////

// Parcours des commandes
HLitPremier(Commande, IDCommande)
TANTQUE PAS HEnDehors()
// Parcours des lignes de commande de la commande en cours
	HLitPremier(LigneCde, IDCommande)
	TANTQUE PAS HEnDehors()
		HLitSuivant(LigneCde, IDCommande)
	FIN
	// Commande suivante
	HLitSuivant(Commande, IDCommande)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HActiveFiltreAuto(<Table de parcours> , <Table à filtrer>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le filtre est activé, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur (fichier ou rubrique inexistant).




**`<Table de parcours> : (Chaîne de caractères)`**

Nom de la table utilisée pour le parcours.

Ce paramètre peut correspondre à "\*". Dans ce cas, tous les filtres automatiques possibles seront activés.

Si les paramètres &lt;Fichier de données de parcours&gt; et &lt;Fichier de données à filtrer&gt; correspondent à "\*", &lt;Résultat&gt; vaut <u><u><u><u>Vrai</u></u></u></u> et aucun filtre n'est activé.

**`<Table à filtrer> : (Chaîne de caractères)`**

Nom de la table à filtrer lors d'un positionnement dans la table de parcours.

Ce paramètre peut correspondre à "\*". Dans ce cas, tous les filtres automatiques possibles seront activés.

Si les paramètres &lt;Fichier de données de parcours&gt; et &lt;Fichier de données à filtrer&gt; correspondent à "\*", &lt;Résultat&gt; vaut <u><u><u><u>Vrai</u></u></u></u> et aucun filtre n'est activé.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Voici un exemple simple:

```wl
HActiveFiltreAuto(Père, Fils)
```

Ce code indique que quand les enregistrements de la table Fils sont parcourus, ce parcours se fait par rapport au 'contexte' (au noeud) courant de la table Père: tous les 'Fils' du 'Père' courant seront parcourus.


```wl
HDésactiveFiltreAuto(Père, Fils)
```

Ce code indique que le filtrage précédent n'est pas actif: le parcours de la table Fils sera indépendant de celui de la table Père. Cela revient donc à parcourir tous les enregistrements de la table Fils dans le fils donné.

La fonction **HActiveFiltreAuto** permet d'activer/désactiver le lien hiérarchique entre les tables Père et Fils pendant des parcours.
