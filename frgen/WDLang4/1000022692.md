


## &lt;Variable Connexion&gt;.ListeBaseDeDonnées (Fonction)

***En anglais : &lt;Connection variable&gt;.ListDatabase***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les bases de données Client/Serveur associées à une connexion.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Liste les bases de données associées à une connexion MySQL.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
// Ajoute dans un champ de saisie les bases de données de MaConnexion
SAI_Saisie1 = MaConnexion.ListeBaseDeDonnées()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Connexion>.ListeBaseDeDonnées([<Options>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des bases de données du serveur défini par la connexion. En fonction de la constante utilisée, le résultat est plus ou moins détaillé:


|   |   |
| --- | --- |
| *hLstNormal* | Liste les bases de données du serveur défini par la connexion:<br>&lt;Nom de la base de données 1&gt; + TAB + &lt;Nom de la base de données 2&gt; + TAB + ... |
| *hLstTable* | Liste les bases de données et leurs fichiers pour le serveur défini par la connexion:<br>&lt;Nom de la base de données 1&gt; + TAB + &lt;Nom du fichier de données 1 dans la base de données 1&gt; + TAB + ... + RC + &lt;Nom de la base de données 2&gt; + TAB + &lt;Nom du fichier de données 1 dans la base de données 2&gt; + TAB + ... + RC + ... |
| *hLstTailleBaseDeDonnées* | Liste les bases de données et leur taille (en octets) pour le serveur défini par la connexion:<br>&lt;Nom de la base de données 1&gt; + TAB + &lt;Taille de la base de données 1&gt; + RC + &lt;Nom de la base de données 2&gt; + TAB + &lt;Taille de la base de données 2&gt; + RC + ...<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible. |


Où:

- &lt;Nom de la base de données X&gt;: Nom de la base de données.

- &lt;Nom de la table Y dans la base de données X&gt;: Nom de la table physique Y présente dans la base de données X.

- &lt;Taille de la base de données X&gt;: Taille de l'ensemble des fichiers constituant la base de données en octets. 




En cas d'erreur, la liste des bases de données correspond à une chaîne vide ("") et la fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.

**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion à manipuler.

**`<Options> : (Constante ou combinaison de constantes de type entier (optionnel))`**

Type de liste à effectuer:


|   |   |
| --- | --- |
| *hLstTable* | Liste détaillée, permettant de connaître les fichiers associés à chaque base de données. |
| *hLstNormal*<br>(valeur par défaut) | Liste non détaillée, contenant uniquement le nom des bases de données associées à une connexion. |
| *hLstTailleBaseDeDonnées* | Liste détaillée, permettant de connaître la taille de l'ensemble des fichiers associés à chaque base de données.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Non disponible. |

### Fonction &lt;Variable Connexion&gt;.ListeBaseDeDonnées et le Connecteur Natif MySQL
<a name="fonction_docparampagetitleshort_connecteur_natif_mysql_ELTPARAGRAPHE000273"></a>

- La fonction [HListeTable](../WDLang4/3044045.md) renvoie uniquement la liste des fichiers de la base de données en cours. 

- La fonction **&lt;Variable Connexion&gt;.ListeBaseDeDonnées** liste les bases de données MySQL accessibles et leurs fichiers.
