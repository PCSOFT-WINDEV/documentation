


## &lt;Connexion HFSQL&gt;.StatCalculeAsynchrone (Fonction)

***En anglais : &lt;HFSQL connection&gt;.StatCalculateAsynchronous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Réalise diverses statistiques sur les clés d'une table HFSQL Client/Serveur. 

Ces statistiques sont utilisées lors de la pose d'un filtre, la création d'une requête ou encore la création d'une vue sur la table. Le moteur HFSQL schéma des données la condition de sélection et s'appuie ensuite sur ces statistiques pour déterminer les rubriques les plus discriminantes qui permettront d'optimiser les parcours des tables.

Les statistiques permettent d'avoir des informations sur le contenu de la table au moment de leur calcul. Aussi, plus il y a de modifications de la table après ce calcul et moins ces statistiques sont fidèles au contenu de la table. Plus la table contient d'enregistrements et moins la modification d'un enregistrement a d'impact sur le reflet de la table que les statistiques renvoient.

**Rappel**: la fonction [&lt;Source&gt;.StatCalcule](../WDLang4/1000025064.md) bloque la table en écriture pendant le calcul des statistiques. La fonction **&lt;Connexion HFSQL&gt;.StatCalculeAsynchrone** permet de réaliser ce traitement sans blocage, en tâche de fond. 

**Remarque**: Pour un calcul de statistiques efficace, il est nécessaire de réaliser ce calcul sur toutes les tables (par exemple dans le cas d'une requête multitable).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauFichier.Ajoute(MonFichierParam)

SI bTâcheDeFond ALORS
	CnxBaseDeDonnées.StatCalculeAsynchrone(TableauFichier, hTâcheDeFond, Callback_HStatCalculeAsynchrone)
SINON
	CnxBaseDeDonnées.StatCalculeAsynchrone(TableauFichier, Callback_HStatCalculeAsynchrone)
FIN
	PROCÉDURE INTERNE Callback_HStatCalculeAsynchrone(MonFichier est une chaîne, MonRésultat est un booléen)
		SI MonRésultat ALORS
			Trace("Statistiques calculées pour la table " + MonFichier)
		SINON
			Trace("Problème dans le calcul des statistiques de la table " + MonFichier + ErreurInfo())
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion>.StatCalculeAsynchrone(<Tables à vérifier> [, <Option>] [, <Procédure WLangage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le calcul des statistiques a été lancé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Connexion> : (Variable de type Connexion)`**

Connexion vers le serveur contenant les tables à manipuler. Cette connexion correspond au nom d'une variable de type [Connexion](../WDLang4/1514073.md).

**`<Tables à vérifier> : (Tableau de variables de type hParamètreFichier)`**

Nom du tableau de variables de type [hParamètreFichier](../WDLang4/1000018900.md) correspondant à la liste des tables à traiter.

**`<Option> : (Entier optionnel)`**

Option de calcul des statistiques. 

- Si ce paramètre n'est pas précisé, le calcul des statistiques bloque la table en écriture. 

- Si ce paramètre correspond à la constante *hTâcheDeFond*, le calcul des statistiques est effectué en tâche de fond, sans bloquer la table.




**`<Procédure WLangage> : (Nom de procédure optionnel)`**

Nom de la procédure WLangage (également nommée "callback") appelée pour chaque table traitée. Cette procédure permet de manipuler la table en cours.

Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction &lt;Connexion HFSQL&gt;.StatCalculeAsynchrone](../WDLang4/1410091116.md).
