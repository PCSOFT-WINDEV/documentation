


## Fonctions de gestion des données spatiales (syntaxe préfixée)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de manipuler des données spatiales via une syntaxe préfixée sont les suivantes : 



|   |   |
| --- | --- |
| [&lt;Variable Polygone2D&gt;.Aire](../WDLang4/1410090517.md) | Calcule l'aire d'un polygone en 2 dimensions. |
| [&lt;Variable Polygone2D&gt;.Chevauche](../WDLang4/1410090519.md) | Permet de savoir si un polygone en 2 dimensions chevauche une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Contient](../WDLang4/1410090522.md) | Permet de savoir si une géométrie A de type polygone en 2 dimensions contient une géométrie B. |
| [&lt;Variable Polygone2D&gt;.Corrige](../WDLang4/1410090523.md) | Permet d'obtenir une version corrigée du polygone en 2 dimensions spécifié. |
| [&lt;Variable Polygone2D&gt;.Couvre](../WDLang4/1410090526.md) | Permet de savoir si une géométrie A de type polygone en 2 dimensions couvre une géométrie B. |
| [&lt;Variable Polygone2D&gt;.Croise](../WDLang4/1410090527.md) | Permet de savoir si un polygone en 2 dimensions croise une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Différence](../WDLang4/1410090530.md) | Renvoie la géométrie correspondant à la différence entre un polygone en 2 dimensions et une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.DifférenceSymétrique](../WDLang4/1410090531.md) | Calcule la différence symétrique entre un polygone en 2 dimensions et une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Disjoint](../WDLang4/1410090563.md) | Permet de savoir si deux géométries sont disjointes, c'est-à-dire si leur intersection est vide. |
| [&lt;Variable Polygone2D&gt;.Distance](../WDLang4/1410090566.md) | Calcule la distance entre un polygone en 2 dimensions et une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Egale](../WDLang4/1410090567.md) | Permet de savoir si deux géométries sont spatialement égales, c'est-à-dire si la première géométrie est incluse dans la seconde, et si la seconde est incluse dans la première. |
| [&lt;Variable Polygone2D&gt;.EnveloppeConvexe](../WDLang4/1410090588.md) | Calcule l'enveloppe convexe du polygone en 2 dimensions spécifié. |
| [&lt;Variable Polygone2D&gt;.EstContenu](../WDLang4/1410090571.md) | Permet de savoir si la géométrie A (de type polygone en 2 dimensions) est complètement contenue dans la géométrie B (c'est-à-dire que la géométrie B contient complètement la géométrie A). |
| [&lt;Variable Polygone2D&gt;.EstCouvert](../WDLang4/1410090572.md) | Permet de savoir si tout point de la géométrie A (de type polygone en 2 dimensions) se trouve à l'intérieur ou dans le contour de la géométrie B. |
| [&lt;Variable Polygone2D&gt;.EstValide](../WDLang4/1410090575.md) | Vérifie si le polygone en 2 dimensions spécifié est valide au sens de la norme OGC. |
| [&lt;Variable Polygone2D&gt;.Intersecte](../WDLang4/1410090576.md) | Vérifie si une géométrie de type polygone en 2 dimensions et une géométrie quelconque ont une intersection non vide.  |
| [&lt;Variable Polygone2D&gt;.Intersection](../WDLang4/1410090579.md) | Renvoie la géométrie correspondant à l'intersection d'un polygone en 2 dimensions avec une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Périmètre](../WDLang4/1410090580.md) | Calcule le périmètre d'un polygone en 2 dimensions. |
| [&lt;Variable Polygone2D&gt;.SérialiseWKT](../WDLang4/1410090583.md) | Sérialise un polygone en 2 dimensions au format Well Known Text (WKT). |
| [&lt;Variable Polygone2D&gt;.Touche](../WDLang4/1410090584.md) | Permet de savoir si un polygone en 2 dimensions touche une autre géométrie. |
| [&lt;Variable Polygone2D&gt;.Union](../WDLang4/1410090587.md) | Renvoie la géométrie correspondant à l'union entre un polygone en 2 dimensions et une autre géométrie. |
| [&lt;Variable PolygoneGéo&gt;.Aire](../WDLang4/1410090518.md) | Calcule l'aire d'un polygone en coordonnées géographiques. |
| [&lt;Variable PolygoneGéo&gt;.Chevauche](../WDLang4/1410090520.md) | Permet de savoir si un polygone en coordonnées géographiques chevauche une autre géométrie. |
