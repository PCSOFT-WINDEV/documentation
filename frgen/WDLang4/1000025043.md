


## &lt;Source&gt;.Ouvre (Fonction)

***En anglais : &lt;Source&gt;.Open***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre une table.

**Remarque**: L'ouverture des tables est automatiquement gérée. Cependant, dans certains cas, il est nécessaire d'ouvrir explicitement une table (par exemple pour tester l'existence de la table ou la validité du mot de passe).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouvre le fichier de données Client
Client.Ouvre()
```
<a name="Exemple3"></a>

```wl
// Test du compte-rendu de la fonction <source>.Ouvre
SI Client.Ouvre("ABCD", hOLecture) = Faux ALORS
	Erreur("Impossible d'ouvrir la table Client" + HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.Ouvre([<Mot de passe> [, <Mode d'accès>]])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table a été ouverte.

- <u><u><u><u>Faux</u></u></u></u> en cas de problème (mot de passe incorrect, ...). La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'obtenir plus de détails.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table manipulée (nom logique, défini dans le schéma des données). 

**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe de la table. 
Si aucun mot de passe n'est associé à la table, il est possible d'utiliser une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Mode d'accès> : (Constante de type entier optionnelle)`**

Paramètre le mode d'accès à la table. 
Si ce paramètre n'est pas spécifié, la table sera ouverte selon ses caractéristiques (si la table est en lecture seule, elle sera ouverte en lecture; si la table est en lecture/écriture, elle sera ouverte en mode lecture/écriture).


|   |   |
| --- | --- |
| *HOLecture* | La table est accessible uniquement en lecture. Seule la lecture des enregistrements est possible. Il n'est pas possible d'en ajouter ou d'en supprimer. |
| *HOLectureEcriture* | La table est accessible en lecture et en écriture. Il est possible aussi bien de lire des enregistrements que d'écrire de nouveaux enregistrements. |

## Remarques


### Gestion du mot de passe
<a name="gestion_mot_passe_ELTPARAGRAPHE000298"></a>

Le mot de passe peut être précisé:

- soit directement à l'ouverture de la table avec la fonction **&lt;Source&gt;.Ouvre**,

- soit avant l'ouverture de la table grâce à la fonction [&lt;Source&gt;.MotDePasse](../WDLang4/1000025044.md).



<a name="NOTE0_2"></a>


### Création ou ouverture d'une table
<a name="creation_ouverture_une_table_ELTPARAGRAPHE000318"></a>

La fonction [&lt;Source&gt;.CréeSiInexistant](../WDLang4/1000024208.md) peut remplacer la fonction **&lt;Source&gt;.Ouvre**. En effet, si la table existe, elle est automatiquement ouverte.
<a name="NOTE0_3"></a>


### Ouverture d'une table déjà ouverte
<a name="ouverture_une_table_deja_ouverte_ELTPARAGRAPHE000335"></a>

Si la fonction **&lt;Source&gt;.Ouvre** est utilisée sur un fichier de données déjà ouvert avec un &lt;Mode d'accès&gt; différent, les filtres, les blocages et les caractéristiques du parcours en cours sont perdus.
<a name="NOTE0_4"></a>


### Gestion de la liste des tables manipulées (.REP)
<a name="gestion_liste_des_tables_manipulees_rep_ELTPARAGRAPHE000347"></a>

WINDEV Mobile permet de mettre à jour une liste des tables manipulées par l'application (équivalent au fichier .REP sous WINDEV standard).

La fonction **&lt;Source&gt;.Ouvre** renseigne la liste des tables manipulées par l'application (.REP pour WINDEV et WEBDEV) si la mise à jour de cette liste est activée.

Pour plus de détails, consultez [Liste des tables manipulées par une application](../WDLang4/3044045.md).
<a name="NOTE0_5"></a>


### Gestion des erreurs fatales
<a name="gestion_des_erreurs_fatales_ELTPARAGRAPHE000366"></a>En cas d'erreur fatale lors de l'ouverture d'une table, il peut être intéressant de continuer le programme en traitant l'erreur rencontrée. Pour cela, il est conseillé de faire le traitement d'exception suivant:

```wl
QUAND EXCEPTION DANS
	Père.Ouvre()
FAIRE
	Erreur("Erreur HFSQL: " + HErreur())
SINON
	Trace("Fichier ouvert")
FIN
```

### Ouverture d'une connexion et de la table spécifiée
<a name="ouverture_une_connexion_table_specifiee_ELTPARAGRAPHE000387"></a>

La fonction **&lt;Source&gt;.Ouvre** ouvre si nécessaire la connexion sur la base de données avant d'ouvrir la table spécifiée. Si la connexion est déjà ouverte (avec les mêmes paramètres), cette connexion est automatiquement utilisée.

Remarque: La connexion utilisée par défaut correspond à la connexion associée à la table sous l'éditeur de schémas des données.
