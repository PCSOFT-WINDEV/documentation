


## &lt;Source&gt;.ChangeRep (Fonction)

***En anglais : &lt;Source&gt;.ChangeDir***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>


- Modifie le chemin d'accès à une table (c'est-à-dire le répertoire dans lequel la table sera manipulée). Si la table est ouverte lors de l'utilisation de **&lt;Source&gt;.ChangeRep**, la table est automatiquement fermée.
	**Rappel**: Par défaut, le fichier physique correspondant à la table décrite sous le schéma des données est manipulé dans le répertoire spécifié dans le schéma des données.

- Substitue le nom de la base de données associée à une table. Dans ce cas, le nom de la base de données spécifié dans les propriétés de la connexion de la table (sous l'éditeur de schémas des données) est alors ignoré.
	Pour modifier les paramètres de connexion d'une table non HFSQL, il est conseillé d'utiliser les fonctions [HDécritConnexion](../WDLang4/3044205.md) et [&lt;Source&gt;.ChangeConnexion](../WDLang4/1000024199.md).


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonction fonctionne uniquement pour les connexions à une base de données HFSQL.

## Syntaxe

### Utilisation avec des tables HFSQL

`<Résultat> = <Source>.ChangeRep(<Nouveau chemin de la table>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom logique de la table HFSQL (défini dans le schéma des données). 

**`<Nouveau chemin de la table> : (Chaîne de caractères)`**

Nouveau chemin d'accès à la table (260 caractères maximum). Ce chemin peut contenir le nom du lecteur et des répertoires, ou être un chemin relatif.
Si le chemin est relatif, le caractère "." (ou "?") permet de désigner le répertoire en cours et le caractère ".." permet de désigner le répertoire parent. 
Si ce paramètre correspond à une chaîne vide (""), la table sera manipulée dans le répertoire spécifié dans le schéma des données.

![HFSQL Client/Serveur](https://doc.pcsoft.fr/ext/images/us/HFCS.png) Le chemin d'accès à la table doit être relatif à la base de données présente sur le serveur. Il n'est pas possible d'indiquer un chemin en dehors de la base de données. Si l'on tente d'accéder à des tables en dehors de la base, une erreur WLangage est affichée. Par exemple: 
Chemin valide: 

```wl
NomFichier.ChangeRep("SOUSREP")
//ou 
NomFichier.ChangeRep(".\SOUSREP")
```

Chemin non valide: 

```wl
NomFichier.ChangeRep("C:\BDD\SOUSREP")
```

Si le nouveau chemin est valide et n'existe pas, il est automatiquement créé. ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Ce paramètre peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction [fRepEnCours](../WDLang1/3036022.md)). Ce paramètre est sensible à la casse. 
**Rappel**: Sous les iPhone/iPad, une application a uniquement le droit d'écrire dans son répertoire d'installation ou dans un de ses sous-répertoires.

### Utilisation avec un accès OLE DB ou un Connecteur Natif (également appelé Accès Natif)

`<Résultat> = <Source>.ChangeRep(<Nouvelle base de données>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom logique de la table (défini dans le schéma des données).

**`<Nouvelle base de données> : (Chaîne de caractères)`**

Chemin d'accès à la base de données à utiliser (260 caractères maximum). Dans ce cas, le nom de la base de données spécifié dans les propriétés de la connexion de la table dans le schéma des données est alors ignoré.
Ce chemin peut contenir le nom du lecteur et des répertoires, ou être un chemin relatif.
Si le chemin est relatif, le caractère "." (ou "?") permet de désigner le répertoire en cours, et le caractère ".." permet de désigner le répertoire parent.

<a name="NOTE0_1"></a>

## Remarques


### Changements de répertoire multiples
<a name="changements_repertoire_multiples_ELTPARAGRAPHE000370"></a>

La fonction **&lt;Source&gt;.ChangeRep** peut être appelée plusieurs fois avec des paramètres différents. Lorsque le chemin est redéfini plusieurs fois pour une même table, le dernier chemin spécifié remplace tous les autres.
<a name="NOTE0_2"></a>


### Changement de nom de la table
<a name="changement_nom_table_ELTPARAGRAPHE000382"></a>

La fonction **&lt;Source&gt;.ChangeRep** permet uniquement de changer le chemin d'accès à la table physique. Pour modifier le nom physique de la table, utilisez la fonction [&lt;Source&gt;.ChangeNom](../WDLang4/1000024201.md).
<a name="NOTE0_3"></a>


### Substitution de répertoire
<a name="substitution_repertoire_ELTPARAGRAPHE000399"></a>

La fonction **&lt;Source&gt;.ChangeRep** permet d'associer un répertoire à une table. Pour substituer un répertoire par un autre, utilisez la fonction [HSubstRep](../WDLang4/3044028.md).

**Attention**: La substitution de répertoire effectuée par [HSubstRep](../WDLang4/3044028.md) s'applique sur le répertoire défini par la fonction **&lt;Source&gt;.ChangeRep**. Par exemple:


```wl
HSubstRep("C:\Statistiques\Janvier", "C:\Nouveau\StatJanv")
Stat.ChangeRep("C:\Statistiques\Janvier") 
Stat.Création() // Table créée dans le répertoire C:\Nouveau\StatJanv
```

<a name="NOTE0_4"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000442"></a>

- Si la gestion du ".REP" est branchée (fonction [HGèreREP](../WDLang4/3044061.md)), la modification de chemin est enregistrée dans le fichier ".REP" (voir [gestion du .REP](../WDLang4/3044186.md)). 

- La fermeture de la table conserve le nouveau chemin, mais ne conserve pas un éventuel mot de passe donné à l'ouverture de la table.

- La fonction **&lt;Source&gt;.ChangeRep** est équivalente à la fonction **HAssigne** présente dans les versions précédentes.

- Cette fonction peut être utilisée lors de l'ouverture d'une connexion à un serveur HFSQL.  **Attention**: L'ordre d'utilisation des fonctions permettant de se connecter à une base de données HFSQL Client/Serveur est important. Consultez [Optimiser les temps de connexion aux bases HFSQL Client/Serveur](../WDLang4/9000176.md) pour plus de détails.

- ![Connecteurs Natifs (Accès Natifs)](https://doc.pcsoft.fr/ext/images/us/AN.png) La fonction **&lt;Source&gt;.ChangeRep** peut être utilisée avec le Connecteur Natif XML.
