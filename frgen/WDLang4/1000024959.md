


## &lt;Source&gt;.TableExiste (Fonction)

***En anglais : &lt;Source&gt;.FileExist***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une table existe, c'est-à-dire si elle a été créée physiquement (fonctions [&lt;Source&gt;.Crée](../WDLang4/1000024207.md) ou [&lt;Source&gt;.CréeSiInexistant](../WDLang4/1000024208.md)). 

Remarque : Les substitutions en cours sur la table (effectuées avec les fonctions [HSubstRep](../WDLang4/3044028.md), [&lt;Source&gt;.ChangeRep](../WDLang4/1000024202.md) et [&lt;Source&gt;.ChangeNom](../WDLang4/1000024201.md)) sont prises en compte.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Test de l'existence de la table "Client"
SI Client.FichierExiste() = Vrai ALORS
	// Traitements
	...
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Tester l'existence d'une table, d'une requête ou d'une vue

`<Résultat> = <Source>.FichierExiste()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier physique existe,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de l'élément à manipuler : 

- Nom de la table.

- Nom de la vue ou de la requête.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La fonction **&lt;Source&gt;.TableExiste** est utilisable que la table soit ouverte ou non.

- La fonction **&lt;Source&gt;.TableExiste** n'ouvre pas la table si celle-ci est fermée.
