


## HListeSchémasDesDonnées (Fonction)

***En anglais : HListAnalysis***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des schémas des données WINDEV ou WEBDEV (au format HFSQL Classic) disponibles dans un répertoire donné. La recherche est effectuée de façon récursive dans toute l'arborescence du répertoire spécifié.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003044049&name=hlisteschemasdesdonnees_fonction">Voir des exemples supplémentaires</a>

```wl
// Remplit un champ Combo avec la liste des schémas des données disponibles sur \Mes répertoires
ListeAjoute(COMBO_Combo, HListeSchémasDesDonnées("\Mes répertoires"))
```

```wl
// Remplit un champ de saisie multiligne 
// en utilisant comme séparateur la virgule et le RC
SAI_Saisie1 = HListeSchémasDesDonnées("\Mes Projets", "," + RC)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HListeSchémasDesDonnées(<Répertoire de recherche> [, <Séparateur>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Nom complet des schémas des données trouvés, exprimé sous la forme : 

```txt
<schéma des données 1> + <séparateur> + <schéma des données 2> + ...
```

où &lt;schéma des données x&gt; correspond au nom complet du schéma des données (.WDD) trouvé.

**`<Répertoire de recherche> : (Chaîne de caractères)`**

Chemin du répertoire par lequel la recherche des schémas des données doit débuter. Si ce paramètre est égal à "\*" ou "\*:\\", tous les répertoires de tous les disques accessibles seront parcourus (selon les cas, cette recherche peut être relativement longue et prendre quelques minutes).

**`<Séparateur> : (Chaîne de caractères optionnelle)`**

Chaîne de caractères utilisée pour séparer les différentes analyses dans &lt;Résultat&gt;. Si ce paramètre n'est pas spécifié, RC (Retour chariot) est utilisé par défaut.
