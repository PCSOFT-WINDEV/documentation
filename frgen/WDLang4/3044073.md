


## HFerme (Fonction)

***En anglais : HClose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme soit une table, soit toutes les tables ouvertes par l'utilisateur en cours: toutes les tables physiques correspondantes sont fermées pour l'utilisateur en cours. Pour des tables HFSQL, les tables fermées sont:

- la table (.FIC),

- le fichier d'index (.NDX) s'il existe,

- le fichier Mémo (.MMO) s'il existe.

- le fichier d'index full-text (.FTX) s'il existe.




**A la fermeture de la table**:

- Les blocages (sur la table et/ou sur certains de ses enregistrements) sont débloqués.

- Les filtres définis sur la table avec la fonction [HFiltre](../WDLang4/3044100.md) sont automatiquement supprimés. 

- Les parcours en cours sur la table sont annulés. 

- Les recherches en cours sur la table sont annulées. 




Après la fermeture de la table, les réassignations effectuées par les fonctions [HChangeNom](../WDLang4/3044141.md), [HChangeRep](../WDLang4/3044168.md) et [HSubstRep](../WDLang4/3044028.md) sont conservées.

Si une requête a été exécutée sur la table, il est nécessaire d'appeler la fonction [HAnnuleDéclaration](../WDLang4/3044174.md) sur la requête pour que la fermeture soit effective.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Fermeture de la table "Fournisseur"
HFerme(Fournisseur)
```
<a name="Exemple2"></a>

```wl
SI PAS HFerme("") ALORS
	Erreur("Problème lors de la fermeture des tables")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HFerme([<Table>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table a été fermée,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreur](../WDLang4/3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table à fermer. 
Si ce nom n'est pas spécifié, la fonction **HFerme** va fermer la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
Si ce paramètre est égal à "\*" ou à une chaîne vide (""), toutes les tables ouvertes sont fermées. 
Ce paramètre peut également correspondre au nom d'un [groupe de fichiers (ou perso-dossier) défini dans le schéma des données](../Editeurs/2011003.md) (non disponible en Android et Android Widget).

## Remarques


### Fermeture des tables et de la connexion
<a name="fermeture_des_tables_connexion_ELTPARAGRAPHE000130"></a>

Lorsque toutes les tables utilisant la même connexion (tables ouvertes sur la même base de données avec les mêmes paramètres de connexion) sont fermées, la connexion est fermée elle aussi automatiquement.

Pour fermer une connexion, utilisez la fonction [HFermeConnexion](../WDLang4/3044095.md).
