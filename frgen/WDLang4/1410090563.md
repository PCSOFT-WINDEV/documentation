


## &lt;Variable Polygone2D&gt;.Disjoint (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Disjoint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si deux géométries sont disjointes, c'est-à-dire si leur intersection est vide.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exemple 1 : deux polygones disjoints
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(-3.00, -1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(2.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, -2.00)
oPolygone2D_2.Contour.AjoutePoint(-2.00, -2.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(2.00, 4.00)
oPolygone2D_2 = oPolygone2D_2.Corrige()

Trace(oPolygone2D_1.Disjoint(oPolygone2D_2)) // Vrai
```



```wl
// Exemple 2 : deux polygones avec une intersection
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(-3.00, -1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(1.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(-1.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(-3.00, 1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(1.00, 4.00)
oPolygone2D_2 = oPolygone2D_2.Corrige()

Trace(oPolygone2D_1.Disjoint(oPolygone2D_2)) // Faux
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.Disjoint(<Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'intersection de la géométrie A et de la géométrie B est vide.  

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).
