


## HImporteJSON (Fonction)

***En anglais : HImportJSON***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Importe un fichier JSON dans une table au format HFSQL Classic (table décrite sous l'éditeur de schémas des données ou déclarée par les fonctions [HDéclare](../WDLang4/3044203.md), [HDéclareExterne](../WDLang4/3044204.md) ou [HDécritTable](../WDLang4/3044206.md)).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Importation de la table "C:\MesFichiers\Client.json" dans la table Client. 
// Si la table Client existe, cette table sera écrasée (constante hImpCréation)
// Une jauge de progression sera affichée dans le champ JAUGE_Jauge1
HImporteJSON(Client, "C:\MesFichiers\Client.json", "", "", hImpCréation, JAUGE_Jauge1)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HImporteJSON(<Table> , <Chemin du fichier JSON> [, <Liste des rubriques destination> [, <Liste des "clés" JSON à importer> [, <Options> [, <Jauge>]]]])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier le problème rencontré.




**`<Table> : (Chaîne de caractères)`**

Nom de la table au format HFSQL Classic dans laquelle l'importation des données de la table JSON doit être réalisée. Si cette table n'existe pas physiquement, elle est automatiquement créée. 

**`<Chemin du fichier JSON> : (Chaîne de caractères)`**

Chemin d'accès complet au fichier JSON à importer.

**`<Liste des rubriques destination> : (Chaîne de caractères optionnelle)`**

Liste des noms des rubriques de la table dans laquelle l'importation des données du fichier JSON est effectuée. Les noms des rubriques peuvent être délimités par des simples quotes et sont séparés par des virgules ou RC (Retour-Chariot). 
Les noms des rubriques de type clé composée, mémo binaire et de type binaire sont ignorés. 
Les rubriques ne figurant pas dans cette liste seront initialisées avec leur valeur par défaut décrite dans le schéma des données. 
Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), toutes les rubriques sont importées (sauf les clés composées, les rubriques binaire et mémos binaire) dans l'ordre physique de description.

**`<Liste des "clés" JSON à importer> : (Chaîne de caractères optionnelle)`**

Liste des clés associées aux valeurs du fichier JSON à importer. 
Si ce paramètre n'est pas précisé ou correspond à une chaîne vide, les valeurs associées à toutes les clés du fichier JSON sont importées.

**`<Options> : (Constante ou combinaison de constantes de type Entier (optionnelle))`**

Type d'importation à effectuer:


|   |   |
| --- | --- |
| *hImpCréation* | Si la table dans laquelle les données sont importées existe, elle est écrasée. |
| *hImpInterruptible* | L'importation peut être interrompue par la touche Echap du clavier. <br>Si l'importation est interrompue, les enregistrements importés sont conservés dans la table. |
| *hImpNormal*<br>(valeur par défaut) | Si la table dans laquelle les données sont importées existe déjà, elle est complétée avec les données importées, sinon la table est créée. |



**`<Jauge> : (Nom de champ ou nom de fenêtre optionnel)`**



- Nom de la fenêtre dans laquelle la jauge doit être affichée.

- Nom du champ de type Jauge affichant la progression.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Ce paramètre n'est pas disponible.

## Remarques


### Mode d'importation
<a name="mode_importation_ELTPARAGRAPHE000146"></a>

Si la liste des clés JSON est précisée: l'importation recherchera des "valeurs JSON" dont le nom de la clé associée est identique au nom des rubriques de la table.

La table décrite dans le schéma des données contient les rubriques suivantes RUB1, RUB2, ... La table JSON devra donc avoir une structure du type ci-dessous:


```txt
{"Fichier":
	{
		"RUB1":Donnée de RUB1,
		"RUB2":Donnée de RUB2,
		...
		}
}
```
Les noms des clés associées aux valeurs du fichier JSON qui n'existent pas dans le schéma des données ou ne sont pas donnés dans la liste des rubriques seront ignorés lors de l'importation.

Si la liste des clés JSON n'est pas précisée, la valeur des clés JSON est mise dans la rubrique de la table HFSQL qui porte le même nom que la clé JSON.
<a name="NOTE0_2"></a>


### Rubriques de type tableau
<a name="rubriques_type_tableau_ELTPARAGRAPHE000162"></a>

La fonction **HImporteJSON** permet également d'importer des rubriques de type tableau.
