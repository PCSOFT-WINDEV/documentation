


## HInitAbonné (Fonction)

***En anglais : HInitSubscriber***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise la plage d'identifiants automatiques d'un fichier de description d'un réplica abonné (extension ".rpl"). **Cette fonction est utilisable uniquement avec la réplication journalée**. 

L'initialisation de la plage d'identifiants automatiques est réalisée:

- automatiquement, lors de la création d'une table (fonctions [HCrée](../WDLang4/3044255.md), [HCréeSiInexistant](../WDLang4/3044254.md)).

- manuellement, avec la fonction **HInitAbonné**.




La fonction **HInitAbonné** doit être appelée uniquement lors de l'installation des tables chez l'abonné.

**Attention**: Les tables doivent être ouvertes avant l'utilisation de la fonction **HInitAbonné**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Initialise la plage d'ID Auto de la table Client
HInitAbonné("Client", "C:\DATA\Replic\AbonneParis.rpl")

// Initialise la plage d'ID Auto de toutes les tables
HInitAbonné("*", "C:\DATA\Replic\AbonneParis.rpl")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HInitAbonné(<Table> , <Réplica Abonné>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'initialisation a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Table> : (Chaîne de caractères)`**

Nom de la table HFSQL à utiliser.
Si ce paramètre est égal à "\*", les plages d'identifiants de toutes les tables décrites comme "répliquées" dans le schéma des données seront initialisées.

**`<Réplica Abonné> : (Chaîne de caractères)`**

Nom et chemin complet du réplica abonné. Ce paramètre peut correspondre à un chemin de type UNC.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Plage d'identifiants
<a name="plage_identifiants_ELTPARAGRAPHE000089"></a>

Les identifiants automatiques des fichiers des réplicas abonnés utilisent une plage d'identifiants différente de celle du fichier de réplica maître et des autres fichiers de réplicas abonnés.

Cette plage d'identifiants automatiques est inscrite dans l'entête de chaque table (extension ".fic").
Cette plage est initialisée:

- lors de la création d'une table (fonctions [HCrée](../WDLang4/3044255.md), [HCréeSiInexistant](../WDLang4/3044254.md)).

- grâce à l'outil [WDReplic](../WDReplic/3520016.md).

- lors de l'utilisation de la fonction **HInitAbonné**.




La plage d'identifiants peut être connue grâce aux propriétés [IDAutoMin](../Proprietes/2512039.md) et [IDAutoMax](../Proprietes/2512023.md).

Pour plus de détails, consultez les [conséquences de la mise en place de la réplication](../WDLang4/3044246.md). 
<a name="NOTE0_2"></a>


### Réplication et journalisation
<a name="replication_journalisation_ELTPARAGRAPHE000130"></a>

Si la fonction **HInitAbonné** est utilisée, il est également nécessaire d'initialiser l'emplacement des journaux et des tables d'opérations (fonction [HChangeRepJNL](../WDLang4/3044164.md), propriétés [RépertoireJournal](../Proprietes/2512075.md) et [RépertoireJournalOpération](../Proprietes/2512076.md)).

**Rappel**: La réplication journalée se base sur les journaux et tables d'opérations des tables. Si l'emplacement des journaux et des tables d'opérations est erroné, la réplication journalée ne peut pas fonctionner.
