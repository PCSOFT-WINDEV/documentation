


## &lt;Variable Connexion&gt;.InfoBlocage (Fonction)

***En anglais : &lt;Connection variable&gt;.InfoLock***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie des informations sur le blocage d'une table, d'un enregistrement ou de tous les enregistrements d'une table.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ConnexionCS est une Connexion
ListeLock est une chaîne
...
// Liste toutes les blocages des tables de la connexion ConnexionCS
ListeLock = ConnexionCS.InfoBlocage()
// Liste tous les blocages de la table Client.fic de la connexion ConnexionCS
ListeLock = ConnexionCS.InfoBlocage(".\client.fic")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Informations de blocage sur une table identifiée par sa connexion

`<Résultat> = <Connexion>.InfoBlocage([<Chemin de la table>] [, <Numéro d'enregistrement>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Nom de la table utilisée. 

**`<Connexion> : (Nom de champ)`**

Numéro de l'enregistrement pour lequel des informations de blocage sont demandées. 
Si ce paramètre n'est pas spécifié, la fonction **&lt;Variable Connexion&gt;.InfoBlocage** liste tous les blocages de la table.

**`<Chemin de la table> : (Chaîne de caractères optionnelle)`**

Chemin complet de la table, relatif à la base de données définie par le paramètre &lt;Connexion&gt;. 
Si le paramètre &lt;Connexion&gt; correspond au nom logique d'une table, ce paramètre est ignoré. 
Si ce paramètre n'est pas précisé, tous les blocages de toutes les tables de la base de données sont renvoyés.

**`<Numéro d'enregistrement> : (Entier optionnel)`**

Numéro de l'enregistrement pour lequel des informations de blocage sont demandées. 
Si ce paramètre n'est pas spécifié, la fonction **&lt;Variable Connexion&gt;.InfoBlocage** liste tous les blocages de la table.
