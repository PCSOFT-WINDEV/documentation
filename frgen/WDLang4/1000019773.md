


## HInfoSchémaDesDonnées (Fonction)

***En anglais : HInfoAnalysis***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie des informations sur un schéma des données (fichier WDD).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Trace(HInfoSchémaDesDonnées())
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HInfoSchémaDesDonnées([<Chemin du WDD> [, <Mot de passe du WDD>]])`
---

**`<Résultat> : (Chaîne de caractères)`**

Informations sur le schéma des données. Ces informations utilisent le format suivant : 

```txt
<GUID Schéma des données> + RC + <Numéro génération>
```


**`<Chemin du WDD> : (Chaîne de caractères optionnelle)`**

Chemin complet du schéma des données (c'est-à-dire du fichier .WDD) à manipuler. 
Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le schéma des données en cours est manipulé.
Cas des projets multi-schémas des données : Si plusieurs schémas des données sont en cours, seul le schéma des données principal est pris en compte.

**`<Mot de passe du WDD> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe défini pour le schéma des données. Si aucun mot de passe n'est défini, ce paramètre doit être égal à une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md).
