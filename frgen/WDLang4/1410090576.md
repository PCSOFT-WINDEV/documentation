


## &lt;Variable Polygone2D&gt;.Intersecte (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Intersect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie si une géométrie de type polygone en 2 dimensions et une géométrie quelconque ont une intersection non vide.  

**Remarques** : 

- Pour connaître la géométrie correspondant à l'intersection, utilisez la fonction [&lt;Variable Polygone2D&gt;.Intersection](../WDLang4/1410090579.md). 

- La fonction **&lt;Variable Polygone2D&gt;.Intersecte** ne renvoyant pas la géométrie résultat, elle est beaucoup plus rapide que la fonction [&lt;Variable Polygone2D&gt;.Intersection](../WDLang4/1410090579.md).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exemple 1 : deux polygones disjoints
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(-3.00, -1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
// Corrige la géométrie créée
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(2.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, -2.00)
oPolygone2D_2.Contour.AjoutePoint(-2.00, -2.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(2.00, 4.00)
// Corrige la géométrie créée
oPolygone2D_2 = oPolygone2D_2.Corrige()

Trace(oPolygone2D_1.Intersecte(oPolygone2D_2)) // Faux
```

```wl
// Exemple 2 : deux polygones avec une intersection
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(-3.00, -1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
// Corrige la géométrie créée
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(1.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 4.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(-1.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(-3.00, 1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(1.00, 4.00)
// Corrige la géométrie créée
oPolygone2D_2 = oPolygone2D_2.Corrige()

Trace(oPolygone2D_1.Intersecte(oPolygone2D_2)) // Vrai
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.Intersecte(<Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si les deux géométries ont une intersection non vide, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Seconde géométrie à prendre en compte pour l'intersection. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).

## Remarques


### Parcours des données spatiales: utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000354"></a>

Il est possible d'effectuer un parcours sur une table avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **&lt;Variable Polygone2D&gt;.Intersecte**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante: 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où: 

- Fonction_WLangage correspond à la fonction **&lt;Variable Polygone2D&gt;.Intersecte**. 

- Rubrique_spatiale correspond à une rubrique spatiale de la table. Cette rubrique doit: 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque: Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, toute la table est parcourue: les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
