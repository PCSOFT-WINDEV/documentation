


## &lt;Variable Connexion&gt;.SupprimeHistoriquePlanification (Fonction)

***En anglais : &lt;Connection variable&gt;.DeleteSchedulingHistory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime l'historique d'exécution d'un élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaConnexionBase est une Connexion
MaSauvegarde est une hDescriptionSauvegarde

SI PAS MaConnexionBase.SupprimeHistoriquePlanification(MaSauvegarde) ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Supprimer l'historique d'une planification de sauvegarde

`<Résultat> = <Connexion>.SupprimeHistoriquePlanification(<Sauvegarde planifiée>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'historique a été supprimé,

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion à manipuler.

**`<Sauvegarde planifiée> : (Variable de type hDescriptionSauvegarde)`**

Nom de la variable de type [hDescriptionSauvegarde](../WDLang4/1000017455.md) manipulée.
