


## &lt;Variable Connexion&gt;.DésactiveTriggerServeur (Fonction)

***En anglais : &lt;Connection variable&gt;.DeactivateServerTrigger***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Désactive un trigger Serveur HFSQL Client/Serveur sur un serveur. Ce trigger est désactivé pour tous les clients de ce serveur. Ce trigger pourra ensuite être réactivé simplement grâce à la fonction [&lt;Variable Connexion&gt;.ActiveTriggerServeur](../WDLang4/1000022637.md).  

**Remarque**: Les fonctions de manipulation des triggers serveur sont des fonctions avancées. Les triggers serveur peuvent être créés directement dans l'éditeur de schémas des données. Pour plus de détails, consultez [Triggers serveur](../WDLang4/3044369.md).


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

### Désactiver un trigger serveur sur des tables HFSQL physiques d'un serveur

`<Résultat> = <Connexion>.DésactiveTriggerServeur(<Trigger> [, <Tables physiques HFSQL Client/Serveur>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u>Vrai</u></u></u> si l'opération a été réalisée, 

- <u><u><u>Faux</u></u></u> en cas de problème. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion au serveur HFSQL.

**`<Trigger> : (Chaîne de caractères)`**

Nom du trigger à désactiver. Ce nom a été donné grâce à la fonction [&lt;Variable Connexion&gt;.DécritTriggerServeur](../WDLang4/1000022653.md).

**`<Tables physiques HFSQL Client/Serveur> : (Chaîne de caractères optionnelle)`**

Nom physique de une ou plusieurs tables HFSQL Client/Serveur associées à la connexion (par exemple "CLIENT.FIC"). 
Pour indiquer plusieurs noms, séparez les noms de tables par une virgule (","). 
Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le trigger sera désactivé sur toutes les tables de la base.
