


## HDébloqueTable (Fonction)

***En anglais : HUnlockFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Débloque les enregistrements d'une table :

- précédemment bloqués avec la fonction [HBloqueTable](../WDLang4/3044153.md).

- bloqués individuellement avec une fonction de lecture bloquante.




Le déblocage de la table peut aussi être obtenu en fermant la table (fonction [HFerme](../WDLang4/3044073.md)).

Remarque : La fonction **HDébloqueTable** ne permet pas de débloquer une table bloquée par une autre session ou un autre programme. Il est conseillé de débloquer une table le plus rapidement possible, afin que les autres sessions puissent accéder à cette table.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonction peut être utilisée avec des tables HFSQL Client/Serveur.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Blocage
HBloqueTable(CLIENT, HBlocageLectureEcriture)
// Modification du fichier
...
// Déblocage
HDébloqueTable(CLIENT)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HDébloqueTable([<Table>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table a été débloquée, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème (par exemple la table n'est pas bloquée, ...). La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. 
Si ce nom n'est pas spécifié, la fonction **HDébloqueTable** va manipuler la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La fonction **HDébloqueTable** est sans effet si :

- la table est en mode Mono (voir la fonction [HMode](../WDLang4/3044039.md)).

- la table n'est pas bloquée.

- la table a été bloquée par un autre programme.
