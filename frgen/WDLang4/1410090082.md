


## HOuvreSchémaDesDonnéesComplémentaire (Fonction)

***En anglais : HOpenComplementaryAnalysis***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre un nouveau schéma des données tout en conservant le schéma des données principal de l'application. Si des schémas des données sont déjà ouverts, ces schémas des données ne sont pas fermés. 

Attention : Pour utiliser cette fonction, il faut avoir au préalable déclaré ou ouvert un schéma des données principal (fonction [HOuvreSchémaDesDonnées](../WDLang4/3044106.md)). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouverture d'un schéma des données complémentaire
HOuvreSchémaDesDonnéesComplémentaire("C:\GESTCOM\GESTCOM.WDD", "Mot de passe")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HOuvreSchémaDesDonnéesComplémentaire(<Chemin du .WDD> [, <Mot de passe>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le schéma des données a été ouvert, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreur](../WDLang4/3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Chemin du .WDD> : (Chaîne de caractères)`**

Chemin complet du fichier ".WDD" du schéma des données. Ce fichier contient la description du schéma des données à ouvrir.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Si seuls le lecteur et le nom du schéma des données sont spécifiés, le schéma des données est recherché dans le répertoire en cours du lecteur spécifié. 
Si ni le lecteur, ni le chemin du schéma des données ne sont spécifiés, le schéma des données est recherché dans le répertoire en cours du disque en cours.
La syntaxe &lt;Unité&gt;:&lt;Nom de schéma des données&gt; permet de rechercher le schéma des données dans le répertoire courant du lecteur spécifié. 

**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**



- Mot de passe du schéma des données, défini dans l'éditeur de schémas des données. 

- Chaîne vide ("") si aucun mot de passe n'est associé au schéma des données.
	**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
	Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Lancement d'une application associée à un schéma des données principal
<a name="lancement_une_application_associee_schema_des_donnees_principal_ELTPARAGRAPHE000061"></a>

- Au lancement d'une application, le schéma des données principal associé à cette application est automatiquement ouvert. Le schéma des données est recherché dans la bibliothèque principale de l'application, puis dans le répertoire de l'application. 
	Pour éviter que le schéma des données ne soit pas trouvé, il est conseillé d'inclure le schéma des données dans la bibliothèque principale de l'application.

- Si la fonction **HOuvreSchémaDesDonnéesComplémentaire** est appelée par une application associée à un schéma des données principal, cette fonction :

	- n'a aucun effet si le chemin du schéma des données spécifié correspond au chemin du schéma des données associé à l'application.

	- retourne <u><u><u><u>Faux</u></u></u></u> si le chemin du schéma des données spécifié n'existe pas. Dans ce cas, l'application continue de travailler avec le schéma des données en cours.

	- ouvre le schéma des données et retourne <u><u><u><u>Vrai</u></u></u></u> si le schéma des données spécifié existe et est valide.






<a name="NOTE0_2"></a>


### Lancement d'une application non associée à un schéma des données
<a name="lancement_une_application_non_associee_schema_des_donnees_ELTPARAGRAPHE000085"></a>

Au lancement d'une application non associée à un schéma des données, aucun schéma des données n'est automatiquement ouvert. Il est donc nécessaire d'utiliser la fonction [HOuvreSchémaDesDonnées](../WDLang4/3044106.md).

Pour ouvrir un schéma des données complémentaire, il est nécessaire d'utiliser la fonction **HOuvreSchémaDesDonnéesComplémentaire**. Le schéma des données ouvert avec la fonction **HOuvreSchémaDesDonnéesComplémentaire** est recherché :

- tout d'abord, dans la bibliothèque principale de l'application selon son nom physique complet.

- puis, sur le disque en cours.



<a name="NOTE0_2B"></a>


### Masquage automatique des tables de même nom dans des schémas des données multiples
<a name="masquage_automatique_des_tables_meme_nom_dans_des_schemas_des_donnees_multiples_ELTPARAGRAPHE000257"></a>

Les différentes analyses peuvent utiliser des tables de même nom. Dans ce cas, une seule table est utilisée. Ce table dépend de l'ordre défini pour les différentes analyses (description du projet ou ordre d'ouverture avec les fonctions [HOuvreSchémaDesDonnées](../WDLang4/3044106.md) et [HOuvreSchémaDesDonnéesComplémentaire](../WDLang4/1410090082.md)). Le principe est le suivant : 

- Schéma des données 1 :

	- Table A

	- Table B




- Schéma des données 2 :

	- Table B. Cette table sera "masquée", car elle est présente dans le schéma des données 1. 
			**Pour utiliser la table B du schéma des données 2**, il est nécessaire de renommer cette table dans le schéma des données 2. 

	- Table C




- Schéma des données 3 :

	- Table B : Cette table sera "masquée", car elle est présente dans le schéma des données 1. 
			**Pour utiliser la table B du schéma des données 3**, il est nécessaire de renommer cette table dans le schéma des données 3.

	- Fichier C : Cette table sera "masquée", car elle est présente dans le schéma des données 2. 
			**Pour utiliser la table C du schéma des données 3**, il est nécessaire de renommer cette table dans le schéma des données 3.

	- Table D. 





Dans le volet "Explorateur de projet", section "Schéma des données", les tables affichées seront les suivantes :

- Table A (schéma des données 1)

- Table B (schéma des données 1)

- Table C (schéma des données 2)

- Table D (schéma des données 3).



<a name="NOTE0_3"></a>


### Ouverture d'un schéma des données déjà ouvert
<a name="ouverture_schema_des_donnees_deja_ouvert_ELTPARAGRAPHE000106"></a>

Si le schéma des données ouvert par la fonction **HOuvreSchémaDesDonnéesComplémentaire** est déjà ouvert, cette fonction n'a aucun effet.
<a name="NOTE0_5"></a>


### Version des schémas des données ouverts avec la fonction HOuvreSchémaDesDonnéesComplémentaire
<a name="version_des_schemas_des_donnees_ouverts_avec_fonction_docparampagetitleshort_ELTPARAGRAPHE000115"></a>

**La fonction HOuvreSchémaDesDonnéesComplémentaire ne permet pas d'ouvrir les schémas des données au format Hyper File 5.5 et inférieur. Seuls les schémas des données HFSQL Classic peuvent être ouverts.**
