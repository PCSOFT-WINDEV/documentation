


## HImporteHF55 (Fonction)

***En anglais : HImportHF55***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Importe une table Hyper File 5.5 dans une table au format HFSQL Classic.

- La table au format Hyper File 5.5 doit être décrite sous l'éditeur de schémas des données.

- La table au format HFSQL Classic doit être décrite sous l'éditeur de schémas des données ou être déclarée par les fonctions [HDéclare](../WDLang4/3044203.md), [HDéclareExterne](../WDLang4/3044204.md) ou [HDécritTable](../WDLang4/3044206.md).




**Remarques**: 

- Les deux tables peuvent avoir des structures différentes.

- Cette fonction n'est pas disponible lors de l'utilisation d'un exécutable autonome. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Importe le nom et l'adresse des clients,
// on ignore les autres rubriques
SI PAS HImporteHF55("CLIENT", "CLIENT", "C:\UnExemple\CLIENT.FIC", ...
			"", "C:\UnExemple\UnExemple.wdd", "", "NOMCOMPLET,ADRESSE", ...
			"NOM,ADR", hValDéfaut + hImpConversion) ALORS
		  Erreur("Importation impossible")
SINON
	// Traitement
	...
FIN
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Importation dans une table de même structure

`<Résultat> = HImporteHF55(<Fichier HFSQL Classic> , <Fichier HF55> , <Chemin complet du fichier HF55> , <Mot de passe du fichier HF55> , <Chemin complet du fichier WDD 55> , <Mot de passe du fichier WDD 55> [, <Options> [, <Jauge>]])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier le problème rencontré.




**`<Fichier HFSQL Classic> : (Chaîne de caractères)`**

Nom logique de la table au format HFSQL Classic dans laquelle l'importation doit être réalisée.

**`<Fichier HF55> : (Chaîne de caractères)`**

Nom logique de la table au format Hyper File 5.5, décrit dans le schéma des données WINDEV 5.5 (fichier .WDD) et contenant les données à importer.

**`<Chemin complet du fichier HF55> : (Chaîne de caractères)`**

Chemin d'accès complet à la table Hyper File 5.5 à importer.

**`<Mot de passe du fichier HF55> : (Chaîne de caractères ou Chaîne secrète)`**

Mot de passe associé à la table à importer. Ce mot de passe sera utilisé pour décrypter les données de la table. Si aucun mot de passe n'a été défini, utilisez une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Chemin complet du fichier WDD 55> : (Chaîne de caractères)`**

Chemin d'accès au fichier .WDD du schéma des données au format Hyper File 5.5. Ce schéma des données contient la description (ou structure) de la table à importer. Tous les formats de schéma des données reconnus par Hyper File 5.5 peuvent être utilisés (WINDEV 5.5B, 5.5, 5.0 et 4.1).

**`<Mot de passe du fichier WDD 55> : (Chaîne de caractères ou Chaîne secrète)`**

Mot de passe associé au schéma des données contenant la table à importer. Si aucun mot de passe n'a été défini, utilisez une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Options> : (Constante ou combinaison de constantes de type Entier (optionnel))`**

Type d'importation à effectuer: 



|   |   |
| --- | --- |
| *hCopieIDAuto* | L'identifiant automatique est recopié. Il n'est pas recalculé.<br>Si la table HFSQL Classic contient un identifiant automatique alors que la table Hyper File 5.5 n'en contient pas, l'identifiant automatique est mis à 0 dans la table HFSQL Classic. |
| *hImpConversion* | Les rubriques associées n'ont pas le même type ou la même taille: les données extraites de la table importée sont automatiquement converties ou tronquées. |
| *hImpCréation* | Si la table dans laquelle l'importation est effectuée (HFSQL Classic) existe, elle est écrasée. |
| *hImpIgnoreRubrique* | Les rubriques de la table destination (HFSQL Classic) n'ayant pas de rubriques associées dans la table importée (Hyper File 5.5) sont remplies avec leur valeur par défaut.<br>Les rubriques de la table importée (Hyper File 5.5) n'ayant pas de correspondance dans la table destination sont ignorées. |
| *hImpInterruptible* | L'importation peut être interrompue avec la touche Echap du clavier. Si l'importation est interrompue, les enregistrements importés sont conservés dans la table. Une ré-indexation (non interruptible) est automatiquement réalisée si nécessaire. |
| *hImpNormal*<br>(valeur par défaut) | Ce mode d'importation évite tout risque de perte de données. L'importation n'est pas effectuée et une erreur est générée dans les cas suivants:<br><br>- rubriques présentes dans la table Hyper File 5.5 sans correspondance dans la table HFSQL Classic.<br><br>- rubriques associées dans les deux tables avec une taille et/ou un format différent.<br><br><br>Si la table dans laquelle l'importation est effectuée (HFSQL Classic) existe déjà, elle est complétée avec les données importées, sinon la table est créée. <br>Pas de gestion d'intégrité ni de gestion de doublons.<br>Les rubriques non importées prennent la valeur de l'enregistrement en cours.<br>Les identifiants automatiques sont recalculés. |
| *hImpSansEspace* | Les espaces en fin de chaîne sont automatiquement supprimés pendant l'importation. |
| *hImpTestDoublon* | Teste les doublons lors de l'importation. |
| *hImpTestIntégrité* | Teste l'intégrité lors de l'importation. |
| *hValDéfaut* | Pour les rubriques non importées, les valeurs de l'enregistrement en cours (HFSQL Classic) sont réinitialisées avec leur valeur par défaut. |



**`<Jauge> : (Nom de champ ou nom de fenêtre optionnel)`**



- Nom de la fenêtre dans laquelle la progression de l'importation doit être affichée. 

- Nom du champ de type Jauge dans lequel la progression de l'importation doit être affichée.

<a name="NOTE0_1"></a>

## Remarques


### Table cryptée
<a name="table_cryptee_ELTPARAGRAPHE000291"></a>

Si la table au format HFSQL Classic dans laquelle l'importation doit être effectuée est cryptée, il est nécessaire de préciser le mot de passe avant l'utilisation de la fonction **HImporteHF55**: utilisez la fonction [HPasse](../WDLang4/3044108.md).
<a name="NOTE0_2"></a>


### HFSQL Client/Serveur
<a name="hfsql_clientserveur_ELTPARAGRAPHE000305"></a>

Si l'importation doit être effectuée dans une table HFSQL Client/Serveur, il est nécessaire de préciser la connexion avant d'utiliser la fonction **HImporteHF55**. Par exemple: 

```txt
HChangeConnexion(MonFichierCS, cnxHFCS)
HImporteHF55(MonFichierCS, MonFichier55, ...)
```
