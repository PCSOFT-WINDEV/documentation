


## &lt;Variable Connexion&gt;.SupprimeTable (Fonction)

***En anglais : &lt;Connection variable&gt;.DeleteTable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime les tables HFSQL (fichiers .fic, .ndx, .ftx, .sdx et .mmo s'ils existent) sur le serveur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaConnexion est une Connexion
// Supprime des tables du serveur 
SI MaConnexion.SupprimeFichier(".\sauvegarde\fichierclient_sov.fic") = Faux ALORS
	Erreur(HErreurInfo())
FIN
// Pour supprimer une table dans le répertoire de la base de données
// MaConnexion.SupprimeFichier("Client.FIC")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Connexion>.SupprimeFichier(<Chemin de la table> [, <Options>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table a été supprimée,

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur (par exemple si la table n'existe pas sur le serveur). La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion dans laquelle la table doit être supprimée.

**`<Chemin de la table> : (Chaîne de caractères)`**

Nom et chemin physique de la table à supprimer. Le chemin est relatif à la base de données: le nom de la base de données ne doit pas être précisé dans le chemin. Il est nécessaire de préciser l'extension ".fic" de la table.

**`<Options> : (Constante ou combinaison de constantes de type entier optionnel)`**

Par défaut, lors de la suppression d'une table:

- les fichiers correspondant aux journaux ne sont pas supprimés,

- les fichiers correspondant aux transactions sont supprimés. 




Ce paramètre permet de modifier ce comportement:



|   |   |
| --- | --- |
| *hConserveTRS* | Conserve le fichier de transaction associé à la table supprimée. |
| *hDétruitLiaison* | Supprime toutes les liaisons concernant la table supprimée. |
| *hSupprimeJournal* | Supprime la table Journal et toutes les opérations journalées associées à la table supprimée. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Suppression d'une table
<a name="suppression_une_table_ELTPARAGRAPHE000250"></a>

La table peut être supprimée uniquement si elle n'est pas en cours d'utilisation (c'est-à-dire si elle n'est pas utilisée par une requête, une vue, une autre fenêtre, un thread ou un composant à contexte HFSQL indépendant).

La table est automatiquement fermée dans le contexte HFSQL qui appelle la fonction **&lt;Variable Connexion&gt;.SupprimeTable**. Si la table est utilisée dans un contexte ou par une application, une erreur WLangage est affichée.
<a name="NOTE0_2"></a>


### Noms de fichiers et de répertoires sur le serveur LINUX
<a name="noms_fichiers_repertoires_sur_serveur_linux_ELTPARAGRAPHE000264"></a>

Sur un serveur LINUX, le nom des fichiers correspondant au fichies de données (fichiers .fic, .ftx, .sdx, .ndx et .mmo s'ils existent) doit être en minuscules et ne pas comporter d'accents.
