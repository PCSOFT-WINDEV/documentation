


## HSupprimeHistoriquePlanification (Fonction)

***En anglais : HDeleteSchedulingHistory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime l'historique d'exécution d'un élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI PAS HSupprimeHistoriquePlanification(MaConnexionBase, MaTachePlanifiee) ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Supprimer l'historique d'une planification de sauvegarde

`<Résultat> = HSupprimeHistoriquePlanification(<Connexion> , <Sauvegarde planifiée>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'historique a été supprimé,

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion à manipuler. Cette connexion correspond: 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md). 




**`<Sauvegarde planifiée> : (Variable de type hDescriptionSauvegarde)`**

Nom de la variable de type [hDescriptionSauvegarde](../WDLang4/1000017455.md) manipulée.
