


## HGèreDoublon (Fonction)

***En anglais : HSetDuplicates***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active ou désactive la gestion des doublons sur une clé unique.

**Remarques**: 

- Par défaut, le test des doublons est actif.

- Cette fonction n'est pas disponible sur les bases de données accédées par OLE DB ou par les Connecteurs Natifs (également appelés Accès Natifs). 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Désactive la gestion des doublons sur la table Client pour la clé "Nom"
HGèreDoublon(Client, Nom, Faux)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HGèreDoublon([<Table> [, <Rubrique clé>, ]] <Activation>)`
---

**`<Résultat> : (Booléen)`**

Ancien mode de gestion des doublons (avant utilisation de la fonction **HGèreDoublon**): 

- <u><u><u><u>Vrai</u></u></u></u> si la gestion des doublons était active, 

- <u><u><u><u>Faux</u></u></u></u> si la gestion des doublons n'était pas active (ou si la clé spécifiée est une clé avec doublons). 


Si &lt;Rubrique clé&gt; = "\*", &lt;Résultat&gt; est à <u><u><u><u>Vrai</u></u></u></u> si dans l'ancien mode de gestion des doublons, le test des doublons était actif au moins sur une rubrique. 


**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée.
Si ce paramètre n'est pas spécifié ou correspond à "\*", la gestion des doublons est prise en compte pour toutes les tables du schéma des données.

**`<Rubrique clé> : (Chaîne de caractères optionnelle)`**

Nom de la rubrique clé unique utilisée. 
Si ce paramètre n'est pas spécifié ou correspond à "\*", la gestion des doublons est prise en compte pour toutes les rubriques clés de la table spécifiée.

**`<Activation> : (Booléen)`**

Mode de gestion: 

- <u><u><u><u>Vrai</u></u></u></u> si la gestion des doublons sur la rubrique doit être activée, 

- <u><u><u><u>Faux</u></u></u></u> si cette gestion doit être désactivée. 


Si seul ce paramètre est précisé, le mode de gestion spécifié s'applique à toutes les rubriques de toutes les tables.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion des doublons activée
<a name="gestion_des_doublons_activee_ELTPARAGRAPHE000134"></a>

Si la gestion du test des doublons est branchée sur une clé définie comme étant unique, le test d'unicité est effectué automatiquement lors de chaque ajout ou modification d'un enregistrement de la table.

Aussi, si l'unicité n'est pas vérifiée lors d'un ajout (fonction [HAjoute](../WDLang4/3044147.md)) ou d'une modification (fonction [HModifie](../WDLang4/3044042.md)), l'enregistrement n'est pas ajouté (respectivement modifié), la fonction d'ajout (ou de modification) renvoie une erreur et la fonction [HErreurDoublon](../WDLang4/3044077.md) renvoie <u><u><u><u>Vrai</u></u></u></u>.

**Remarque**: Seules les fonctions [HAjoute](../WDLang4/3044147.md) et [HModifie](../WDLang4/3044042.md) peuvent générer une erreur de doublons. 
<a name="NOTE0_2"></a>


### Généralisation du test des doublons
<a name="generalisation_test_des_doublons_ELTPARAGRAPHE000166"></a>



- Pour généraliser le mode de gestion des doublons à toutes les rubriques d'une table, utilisez le méta-caractère "\*". 
	Par exemple:
	
	```txt
	HGèreDoublon(<Fichier de données>, "*", <Activation>)
	```


- Pour généraliser le mode de gestion des doublons à toutes les rubriques de toutes les tables, il faut utiliser le méta-caractère "\*".
	Par exemple: 
	
	```txt
	HGèreDoublon("*", "*", <Activation>)
	```


- Si seul le paramètre &lt;Activation&gt; est précisé, le mode de gestion spécifié s'applique à toutes les tables et à toutes les rubriques.



<a name="NOTE0_3"></a>


### Désactiver le test des doublons
<a name="desactiver_test_des_doublons_ELTPARAGRAPHE000194"></a>

Désactiver le test de doublons implique la possibilité de violer les règles d'unicité énoncées lors de la description des tables dans l'éditeur de schémas des données. Désactiver le test de doublons n'est donc pas une opération insignifiante: elle doit être utilisée à bon escient.
