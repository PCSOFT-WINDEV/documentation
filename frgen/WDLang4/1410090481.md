


## &lt;Source&gt;.SourceDeDonnéesConnue (Fonction)

***En anglais : &lt;Source&gt;.DataSourceKnown***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une source de données est initialisée. Cette fonction permet d'éviter une erreur du type "Vous avez appelé la fonction XXX. La source de données YYY n'est pas initialisée". 

**Différence avec la fonction [&lt;Source&gt;.RequêteExécutée](../WDLang4/1410090480.md)**: La fonction **&lt;Source&gt;.SourceDeDonnéesConnue** permet de savoir si la source de données est connue du moteur HFSQL, quelque soit son contenu. La fonction [&lt;Source&gt;.RequêteExécutée](../WDLang4/1410090480.md) est utilisable uniquement sur les requêtes.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaVue est une Source de Données
// MaVue est associée à une vue

SI MaVue.SourceDeDonnéesConnue() = Faux ALORS
	// Initialisation de la variable MaVue 
	MaVue.CréeVue(CLIENT, "*", "NOM,VILLE", "NOM]='A'", hVueDéfaut)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Source de données à vérifier>.SourceDeDonnéesConnue()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la source de données a été initialisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Source de données à vérifier> : (Variable de type Source de Données)`**

Variable de type [Source de Données](../WDLang4/1514053.md) à vérifier. Cette source de données peut correspondre à: 

- une table externe,

- une requête SQL, 

- une vue.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Comment initialiser une variable de type Source de Données
<a name="comment_initialiser_une_variable_type_source_donnees_ELTPARAGRAPHE000198"></a>

L'initialisation d'une variable de type Source de Données dépend de son contenu: 

- Table externe: il est nécessaire d'utiliser la fonction [&lt;Source&gt;.DéclareExterne](../WDLang4/1000024214.md). 

- Requête et requête SQL: il est nécessaire d'utiliser les fonctions [&lt;Source&gt;.ExécuteRequête](../WDLang4/1000024944.md), [&lt;Source&gt;.ExécuteRequêteSQL](../WDLang4/1000024948.md), etc. 

- Vue HFSQL: Il est nécessaire d'utiliser la fonction [&lt;Source&gt;.CréeVue](../WDLang4/1000024209.md). 




Pour plus de détails, consultez l'aide du type [Source de Données](../WDLang4/1514053.md).
