
## Paramètres de la procédure utilisée par la fonction HStatCalculeAsynchrone



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [HStatCalculAsynchrone](../WDLang4/1410091108.md) pour chaque table HFSQL Client/Serveur vérifiée.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauAjoute(TableauFichier, MonFichierParam)

SI bTâcheDeFond ALORS
	HStatCalculeAsynchrone(CnxBaseDeDonnées, TableauFichier, hTâcheDeFond, Callback_HStatCalculeAsynchrone)
SINON
	HStatCalculeAsynchrone(CnxBaseDeDonnées, TableauFichier, Callback_HStatCalculeAsynchrone)
FIN
	PROCÉDURE INTERNE Callback_HStatCalculeAsynchrone(MonFichier est une chaîne, MonRésultat est un booléen)
		SI MonRésultat ALORS
			Trace("Statistiques calculées pour la table " + MonFichier)
		SINON
			Trace("Problème dans le calcul des statistiques de la table " + MonFichier + ErreurInfo())
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`HStatCalculeAsynchrone_Callback(<Table> , <Résultat du calcul>)`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table HFSQL Client/Serveur manipulée. 

**`<Résultat du calcul> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le calcul a été effectué,

- <u><u><u><u>Faux</u></u></u></u> en cas de problème (table bloquée par une application par exemple). La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.
