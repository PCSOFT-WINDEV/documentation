


## HInfoTable (Fonction)

***En anglais : HInfoFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie les caractéristiques d'une table HFSQL Classic ou Client/Serveur.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupération de la taille d'une table
// en utilisant la connexion en cours d'une table
Trace("Taille totale table Client : " + HInfoTable(Client, hTailleTotale))
```
<a name="Exemple2"></a>

```wl
// Récupération de la taille d'une table en utilisant une connexion 
// Paramètres de la connexion
CnxTest est une Connexion
CnxTest.Provider = hAccèsHFClientServeur
CnxTest.Utilisateur = "admin"
CnxTest.MotDePasse = "pass_admin"
CnxTest.Serveur = "serveur:4930"
CnxTest.BaseDeDonnées = "BaseTest"
Trace("Taille totale table Client : " + ...
	HInfoTable(CnxTest.Nom, "NomFichier.FIC", hTailleTotale))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Obtenir des informations concernant une table HFSQL Classic

`<Résultat> = HInfoTable(<Table> , <Information>)`
---

**`<Résultat> : (Type de l'information recherchée)`**

Information recherchée.

**`<Table> : (Chaîne de caractères)`**

Nom de la table à analyser.

**`<Information> : (Constante de type Entier)`**

Information voulue sur la table :


|   |   |
| --- | --- |
| *hTailleFic* | Taille en octets de la table (table ".Fic"). |
| *hTailleFtx* | Taille en octets du fichier d'index full-text (fichier ".Ftx"). |
| *hTailleMmo* | Taille en octets du fichier mémo (fichier ".Mmo"). |
| *hTailleNdx* | Taille en octets du fichier d'index (fichier ".Ndx"). |
| *hTailleSdx* | Taille en octets du fichier d'index spatial (fichier ".Sdx"). |
| *hTailleTotale* | Taille totale en octets de la table (taille cumulée de la table, du fichier mémo et du fichier d'index). |




<a name="SYNTAXE2"></a>

### Obtenir des informations concernant une table HFSQL Client/Serveur

`<Résultat> = HInfoTable(<Connexion> , <Table> , <Information>)`
---

**`<Résultat> : (Type de l'information recherchée)`**



- Information recherchée, 

- 0 si la connexion existe mais si la table n'existe pas sur le disque.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion à utiliser. Cette connexion correspond : 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).




**`<Table> : (Chaîne de caractères)`**

Nom physique de la table à analyser.

**`<Information> : (Constante de type Entier)`**

Information voulue sur la table :


|   |   |
| --- | --- |
| *hTailleFic* | Taille en octets de la table (table ".Fic"). |
| *hTailleFtx* | Taille en octets du fichier d'index full-text (fichier ".Ftx"). |
| *hTailleMmo* | Taille en octets du fichier mémo (fichier ".Mmo"). |
| *hTailleNdx* | Taille en octets du fichier d'index (fichier ".Ndx"). |
| *hTailleSdx* | Taille en octets du fichier d'index spatial (fichier ".Sdx"). |
| *hTailleTotale* | Taille totale en octets de la table (taille cumulée de la table, du fichier mémo et du fichier d'index). |
