


## HLibère (Fonction)

***En anglais : HFree***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Transforme les enregistrements rayés (fonction [HRaye](../WDLang4/3044121.md)) d'une table en enregistrements supprimés. La place occupée par les enregistrements rayés est ainsi libérée et pourra être réutilisée lors des prochains ajouts (fonction [HAjoute](../WDLang4/3044147.md)).

**Rappel**: Un enregistrement rayé est inactif et disparaît de l'index. Les données de cet enregistrement rayé ne sont pas supprimées (contrairement à la fonction [HSupprime](../WDLang4/3044018.md)).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Supprime tous les enregistrements rayés de la table "Client"
HLibère(Client)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HLibère([<Table>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'enregistrement a été supprimé, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème: l'enregistrement n'est pas supprimé. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. Si ce nom n'est pas spécifié, la fonction **HLibère** va manipuler la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Cette fonction n'est pas adaptée à des fichiers xBase.
