


## &lt;Source&gt;.GèreTransaction (Fonction)

***En anglais : &lt;Source&gt;.SetTransaction***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active ou désactive la gestion des transactions sur une ou plusieurs tables.

Lorsque la gestion des transaction est désactivée, toutes les fonctions relatives aux transactions sont inhibées ([&lt;Variable Connexion&gt;.TransactionDébut](../WDLang4/1000023967.md), [&lt;Variable Connexion&gt;.TransactionFin](../WDLang4/1000023968.md), [&lt;Variable Connexion&gt;.TransactionAnnule](../WDLang4/1000023966.md)).

**Remarque**: Par défaut, la gestion des transactions est active.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Cette fonction peut être utilisée uniquement avec des tables HFSQL Client/Serveur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Désactive la gestion des transactions sur la table Client
Client.GèreTransaction(Faux)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.GèreTransaction(<Options>)`
---

**`<Résultat> : (Booléen)`**

Correspond à l'ancienne gestion des transactions (avant utilisation de la fonction **&lt;Source&gt;.GèreTransaction**): 

- <u><u><u><u>Vrai</u></u></u></u> si la gestion des transactions était active, 

- <u><u><u><u>Faux</u></u></u></u> si la gestion des transactions n'était pas active. 




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table manipulée. 

**`<Options> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la gestion des transactions sur la table doit être activée,

- <u><u><u><u>Faux</u></u></u></u> si cette gestion doit être désactivée.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion des transactions activée
<a name="gestion_des_transactions_activee_ELTPARAGRAPHE000251"></a>

Si la gestion des transactions est activée pour une seule table, seules les manipulations réalisées sur cette table seront prises en compte dans la gestion des transactions (quels que soient les tables indiquées dans la fonction [&lt;Variable Connexion&gt;.TransactionDébut](../WDLang4/1000023967.md)).
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 

### Limite 
<a name="limite_ELTPARAGRAPHE000268"></a>

La gestion des transactions ne s'applique pas aux fichiers xBase.
