


## HStatDate (Fonction)

***En anglais : HStatDate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la date de la dernière mise à jour des statistiques d'index. Ces statistiques ont été réalisées grâce aux fonctions [HStatCalcule](../WDLang4/3044134.md) ou [HRéindexe](../WDLang4/3044133.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Réalisation de statistiques sur la clé NomCli de la table Client
HStatCalcule(Client, NomCli)

// Connaître la date de réalisation de ces statistiques
ResDate = HStatDate()
Info("Les statistiques effectuées sur la rubrique NomCli ont été réalisées le: " + ...
			DateVersChaîne(ResDate, maskDateSystème))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HStatDate([<Table> [, <Rubrique clé>]])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Date de la dernière mise à jour des statistiques au format AAAAMMJJ (AAAA correspond à l'année, MM au mois et JJ au jour). La date renvoyée est au format UTC (Universal Time Coordinated). 

- Chaîne vide ("") si aucun calcul de statistiques n'a été effectué. 




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. Si ce nom n'est pas spécifié, la fonction **HStatDate** manipule la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

**`<Rubrique clé> : (Chaîne de caractères optionnelle)`**

Nom de la rubrique clé sur laquelle les statistiques ont été effectuées. Si ce nom n'est pas spécifié, la fonction **HStatDate** manipule la dernière rubrique clé utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Dans les tables HFSQL, seules les rubriques clés peuvent faire l'objet d'un calcul de statistiques.
