


## &lt;Source&gt;.ChangeMotDePasse (Fonction)

***En anglais : &lt;Source&gt;.ChangePassword***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Change le mot de passe d'une table HFSQL Classic ou HFSQL Client/Serveur. Les applications utilisant l'ancien mot de passe ne pourront plus accéder à cette table: une erreur de mot de passe sera affichée. 

**Attention**: Cette fonction est une fonction avancée. Il est nécessaire de l'utiliser avec prudence car elle peut entraîner des erreurs des applications clientes. 


<a name="sample_code"></a>

## Exemple


```wl
// Ancien mot de passe
HPasse("*", "MotDePasse")
// Modification du mot de passe
Client.ChangeMotDePasse("NouveauMotDePasse")
```

```wl
// Création d'une table avec un mot de passe
FichierA.MotDePasse("TEST")
FichierA.Création()

// Ajout de données
FichierA.RubriqueA = "Test 1"
FichierA.Ajoute()

// Lecture des données
FichierA.LitPremier()
Info(FichierA.RubriqueA)

// Changement du mot de passe
Info("Maintenant, changement de mot de passe ...")
FichierA.ChangeMotDePasse("NV_Test")
Info("Mot de passe changé, relecture du premier enregistrement")

// Relecture des données
FichierA.LitPremier()
Info(FichierA.RubriqueA)

// Gestion des erreurs
CAS ERREUR:
	Erreur(HErreurInfo())
	RETOUR
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.ChangeMotDePasse(<Nouveau mot de passe>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le mot de passe a été modifié, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table HFSQL (défini dans le schéma des données) à manipuler.

**`<Nouveau mot de passe> : (Chaîne de caractères ou Chaîne secrète)`**

Nouveau mot de passe à utiliser pour la table.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si la table est déjà protégée par un mot de passe, il est nécessaire d'indiquer ce mot de passe avec la fonction [&lt;Source&gt;.MotDePasse](../WDLang4/1000025044.md) avant d'utiliser la fonction **&lt;Source&gt;.ChangeMotDePasse**. 

- Pour pouvoir modifier le mot de passe d'une table, il est nécessaire de posséder les droits de modification automatique (constante *hDroitModifAuto*). Ce droit peut être défini grâce à la fonction [&lt;Variable Connexion&gt;.ModifieDroitsTable](../WDLang4/1000022709.md). 

- Cette fonction lance une modification automatique de la table. Si la table était cryptée avec un mot de passe différent, elle sera entièrement re-cryptée avec le nouveau mot de passe. Cette opération peut être relativement longue.
