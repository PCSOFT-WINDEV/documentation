
## HFSQL Client/Serveur: Optimisation planifiée
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000213"></a>


### Définition
<a name="definition_ELTPARAGRAPHE000009"></a>

Une optimisation planifiée est un mécanisme d'optimisation automatique de votre base de données. Une tâche d'optimisation planifiée permet d'effectuer de façon périodique un calcul des statistiques ou une réindexation des tables du serveur HFSQL.

Les tâches planifiées peuvent être gérées:

- soit dans le [Centre de Contrôle HFSQL](#NOTE2_1).

- soit par [programmation](#NOTE3_1).




<a name="NOTE2"></a>


## Tâches d'optimisation planifiée dans le Centre de Contrôle HFSQL
<a name="taches_optimisation_planifiee_dans_centre_controle_hfsql_ELTTEXTE000237"></a>
<a name="NOTE2_1"></a>


### Créer une optimisation planifiée
<a name="creer_une_optimisation_planifiee_ELTPARAGRAPHE000032"></a>

Dans le Centre de Contrôle HFSQL, les tâches d'optimisation peuvent être définies au niveau du serveur ou de la base de données.

Pour créer une tâche d'optimisation:

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez la description du serveur ou d'une de ses bases (double-clic sur le nom du serveur ou de la base dans l'arborescence). 

2. Cliquez sur l'onglet "Eléments planifiés". 

3. Dans le ruban, dans le groupe "Eléments planifiés", déroulez "Nouvelle planification" et sélectionnez "Planifier une optimisation". L'assistant de création d'une optimisation planifiée se lance. 

4. Sélectionnez les fichiers à optimiser: 

	- Une base de données, 

	- Une sélection de fichiers d'une base de données. 




5. Définissez la fréquence de la tâche: mois, jour, heure.

6. Indiquez l'action réalisée: 

	- **Réindexer les fichiers**: 
			Cette action permet un accès aux index optimal. La réindexation effectue automatiquement le recalcul des statistiques sur les clés. 

	- **Recalculer les statistiques sur les clés des fichiers**: 
			Cette action permet d'optimiser les parcours des tables. 




7. Indiquez si nécessaire les mots de passe des tables. 
	Attention: Si des mots de passe différents sont utilisés sur les tables, il est nécessaire de créer une tâche d'optimisation différente pour chaque table associée à un mot de passe différent. 

8. Donnez une description à votre tâche planifiée et validez l'assistant.

9. L'optimisation planifiée apparaît dans l'onglet "Eléments planifiés" du Centre de Contrôle HFSQL.



<a name="NOTE2_2"></a>


### Supprimer une optimisation planifiée
<a name="supprimer_une_optimisation_planifiee_ELTPARAGRAPHE000063"></a>

Pour supprimer une optimisation planifiée:

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez l'onglet du serveur ou de la base de données voulu.  

2. Cliquez sur l'onglet "Eléments planifiés". 

3. Sélectionnez l'optimisation planifiée à supprimer.

4. Dans le ruban, dans le groupe "Eléments planifiés", cliquez sur "Supprimer". 
	Vous pouvez également utiliser le menu contextuel de l'élément planifié (option "Supprimer"). 



<a name="NOTE2_3"></a>


### Modifier une optimisation planifiée
<a name="modifier_une_optimisation_planifiee_ELTPARAGRAPHE000077"></a>

Pour modifier une optimisation planifiée:

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez l'onglet du serveur ou de la base de données voulu. 

2. Cliquez sur l'onglet "Eléments planifiés". 

3. Sélectionnez l'optimisation planifiée à modifier.

4. Dans le ruban, dans le groupe "Eléments planifiés", cliquez sur "Editer". 
	Vous pouvez également utiliser le menu contextuel de l'élément planifié (option "Editer"). 

5. Une fenêtre de description de l'élément planifié apparaît. Toutes les caractéristiques saisies dans l'assistant sont regroupées sur plusieurs onglets:

	- Onglet "Général": Définit si l'optimisation est active.

	- Onglet "Planification": Définit les options d'exécution de l'optimisation planifiée (mois, jour, heure).




- Onglet "Contenu": Définit les éléments inclus dans l'optimisation planifiée (serveur, base de données, fichiers, etc.) ainsi que l'action réalisée. 

6. Validez.

## Optimisations planifiées par programmation
<a name="optimisations_planifiees_par_programmation_ELTTEXTE000273"></a>


### Création d'une optimisation planifiée
<a name="creation_une_optimisation_planifiee_ELTPARAGRAPHE000113"></a>

La gestion des optimisation planifiées par programmation est réalisée grâce à une variable de type [hOptimisationPlanifiée](../WDLang4/1000018854.md) et à plusieurs fonctions WLangage.

Pour créer une optimisation planifiée par programmation:

1. Créez une variable de type [hOptimisationPlanifiée](../WDLang4/1000018854.md) et décrivez les différentes caractéristiques de l'optimisation planifiée.

2. Ajoutez l'optimisation planifiée grâce à la fonction [HAjoutePlanification](../WDLang4/1000021447.md) (ou la fonction [HAjouteOptimisationPlanifiée](../WDLang4/1000018860.md)). 




Remarques: 

- Pour ajouter une tâche planifiée, il est nécessaire de posséder:

	- le droit de gérer les tâches (constante ***hDroitGèreTâche***).

	- le droit d'exécuter la commande liée à l'optimisation planifiée.




- L'optimisation planifiée sera exécutée avec l'identité de l'utilisateur défini par la connexion.





### Historique d'exécution des optimisations planifiées
<a name="historique_execution_des_optimisations_planifiees_ELTPARAGRAPHE000145"></a>

Un historique des exécutions est automatiquement enregistré lors de l'exécution automatique de l'optimisation planifiée (ou lors de son exécution via la fonction [HExécutePlanification](../WDLang4/1000021453.md)). Il est possible de manipuler cet historique par programmation, via une variable de type [hHistoriquePlanification](../WDLang4/1410090764.md) et les fonctions suivantes:



|   |   |
| --- | --- |
| [HListeHistoriquePlanification](../WDLang4/1410090762.md) | Liste l'historique d'exécution d'une opération planifiée sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| [HSupprimeHistoriquePlanification](../WDLang4/1410090760.md) | Supprime l'historique d'exécution d'un élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| [HSupprimeToutHistoriquePlanification](../WDLang4/1410090761.md) | Purge la totalité de l'historique d'exécution des éléments planifiés sur un serveur HFSQL. |






### Manipulation des optimisations planifiées en WLangage
<a name="manipulation_des_optimisations_planifiees_wlangage_ELTPARAGRAPHE000157"></a>

Les optimisations planifiées peuvent être manipulées via: 

- les fonctions de gestion des optimisations planifiées: 
	


|   |   |
| --- | --- |
| [HAjouteOptimisationPlanifiée](../WDLang4/1000018860.md) | Ajoute une tâche d'optimisation des tables HFSQL Client/Serveur. |
| [HListeOptimisationPlanifiée](../WDLang4/1000018863.md) | Liste les tâches d'optimisation planifiées des tables HFSQL Client/Serveur pour une connexion. |
| [HModifieOptimisationPlanifiée](../WDLang4/1000018931.md) | Modifie une tâche d'optimisation planifiée sur le serveur HFSQL défini par la connexion. |
| [HSupprimeOptimisationPlanifiée](../WDLang4/1000018865.md) | Supprime une tâche d'optimisation planifiée de tables HFSQL Client/Serveur. |

- les fonctions de gestion des éléments planifiés (conseillées): 
	


|   |   |
| --- | --- |
| [HAjoutePlanification](../WDLang4/1000021447.md) | Ajoute un nouvel élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation ou rafraîchissement d'une vue matérialisée. |
| [HExécutePlanification](../WDLang4/1000021453.md) | Exécute immédiatement un élément planifié sans tenir compte de sa planification: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| [HListePlanification](../WDLang4/1000021452.md) | Liste les éléments planifiés définis sur un serveur HFSQL: tâches planifiées (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| [HModifiePlanification](../WDLang4/1000021450.md) | Modifie un élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| [HSupprimePlanification](../WDLang4/1000021448.md) | Supprime un élément planifié sur un serveur HFSQL: tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
