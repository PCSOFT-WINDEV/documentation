


## HRSTransformeSpareEnServeur (Fonction)

***En anglais : HRSTransformSpareIntoServer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Transforme un serveur Spare en un serveur HFSQL. Il est ainsi possible de supprimer les réplications d'un serveur spare pour pouvoir l'utiliser à nouveau (cas par exemple d'un serveur maître inaccessible). 

**Cette fonction doit être utilisée uniquement en cas d'urgence.** 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression d'une réplication spare identifiée par l'identifiant de réplication
tabRS_SpareComplet est un tableau de hRSConfig = HRSListeConfig(gcnxSpareComplet_bdd1, hrsAbonné)
HRSTransformeSpareEnServeur(gcnxSpareComplet_bdd1, tabRS_SpareComplet[1].IdentifiantOpposé)

// Suppression des réplications spare d'un serveur maître
tabRS_SpareComplet est un tableau de hRSConfig = HRSListeConfig(gcnxSpareComplet_bdd1, hrsAbonné)
HRSTransformeSpareEnServeur(gcnxSpareComplet_bdd1, tabRS_SpareComplet[1].Serveur)

// Suppression de toutes les réplications d'un serveur spare
HRSTransformeSpareEnServeur(gcnxSpareComplet_bdd1)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HRSTransformeSpareEnServeur(<Connexion> [, <Réplication à supprimer>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion vers le serveur HFSQL spare. Cette connexion correspond: 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).




**`<Réplication à supprimer> : (Entier optionnel ou chaîne de caractères optionnelle)`**



- Identifiant de la réplication à supprimer. Cet identifiant correspond à la propriété **IdentifiantOpposé** de la variable de type [hRSConfig](../WDLang4/1000020484.md) décrivant la réplication.

- Nom du serveur maître pour lequel les réplications spare associées doivent être supprimées. 




Si ce paramètre n'est pas spécifié, toutes les réplications spare sont supprimées.
