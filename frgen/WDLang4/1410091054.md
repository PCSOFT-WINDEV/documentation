
## Paramètres de la procédure utilisée par la fonction HRéindexeAsynchrone



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [HRéindexeAsynchrone](../WDLang4/1410091053.md) pour chaque table HFSQL Client/Serveur réindexée.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier
MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
MonFichierParam.MotDePasse = "MotDePasse"
// Propriété Option de la variable hParamètreFichier non prise en compte
TableauAjoute(TableauFichier, MonFichierParam)
// Lance la réindexation
SI bTâcheDeFond ALORS
	HRéindexeAsynchrone(CnxBaseDeDonnées, TableauFichier, hTâcheDeFond, 60, CB_HRéindexeAsynchrone)
SINON
	HRéindexeAsynchrone(CnxBaseDeDonnées, TableauFichier, CB_HRéindexeAsynchrone)
FIN

	PROCÉDURE INTERNE CB_HRéindexeAsynchrone(MaTable est une chaîne, Res est un booléen)
		SI Res ALORS
			Trace("Table traitée: " + MaTable)
		SINON
			Trace("Erreur Table " + MaTable + ErreurInfo())
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`HRéindexeAsynchrone_Callback(<Table> , <Résultat réindexation>)`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table HFSQL Client/Serveur manipulée.

**`<Résultat réindexation> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la ré-indexation a été effectuée sans problème, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.
