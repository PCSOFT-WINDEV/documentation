


## HOuvreSchémaDesDonnées (Fonction)

***En anglais : HOpenAnalysis***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre un schéma des données au format HFSQL Classic. Il est ainsi possible d'accéder aux tables décrites dans ce schéma des données, et à la structure de ces tables.

**Attention** : Un seul schéma des données peut être ouvert à un moment donné avec la fonction **HOuvreSchémaDesDonnées**. 

- Si un schéma des données était déjà ouvert avant l'appel de la fonction, ce schéma des données est automatiquement fermé ainsi que les tables associées. 

- Pour ouvrir plusieurs schémas des données simultanément, utilisez la fonction **HOuvreSchémaDesDonnées** pour ouvrir le schéma des données principal et la fonction [HOuvreSchémaDesDonnéesComplémentaire](../WDLang4/1410090082.md) pour ouvrir les schémas des données complémentaires. 


**Attention** : Lors de l'utilisation de la fonction **HOuvreSchémaDesDonnées**, le contexte HFSQL en cours est automatiquement ré-initialisé. Les opérations suivantes sont automatiquement effectuées :

- Toutes les tables précédemment ouvertes sont fermées.

- Toutes les vues HFSQL existantes sont supprimées.

- Toutes les requêtes existantes sont supprimées.

- Toutes les déclarations réalisées avec les fonctions [HDéclareExterne](../WDLang4/3044204.md) et [HDécritTable](../WDLang4/3044206.md) sont supprimées.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouverture du schéma des données GESTCOM
HOuvreSchémaDesDonnées("C:\GESTCOM\GESTCOM.WDD", "Mot de passe")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HOuvreSchémaDesDonnées(<Chemin du .WDD> [, <Mot de passe>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le schéma des données a été ouvert, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreur](../WDLang4/3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Chemin du .WDD> : (Chaîne de caractères)`**

Chemin complet du fichier ".WDD" du schéma des données. Ce fichier contient la description du schéma des données à ouvrir.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Si seuls le lecteur et le nom du schéma des données sont spécifiés, le schéma des données est recherché dans le répertoire en cours du lecteur spécifié. 
Si ni le lecteur, ni le chemin du schéma des données ne sont spécifiés, le schéma des données est recherché dans le répertoire en cours du disque en cours.
La syntaxe &lt;Unité&gt;:&lt;Nom de schéma des données&gt; permet de rechercher le schéma des données dans le répertoire courant du lecteur spécifié. 

**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**



- Mot de passe du schéma des données, défini dans l'éditeur de schémas des données. 

- Chaîne vide ("") si aucun mot de passe n'est associé au schéma des données.
	**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
	Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Lancement d'une application associée à un schéma des données
<a name="lancement_une_application_associee_schema_des_donnees_ELTPARAGRAPHE000092"></a>

- Au lancement d'une application, le schéma des données associé à cette application est automatiquement ouvert. Le schéma des données est recherché dans la bibliothèque principale de l'application, puis dans le répertoire de l'application. 
	Pour éviter que le schéma des données ne soit pas trouvé, il est conseillé d'inclure le schéma des données dans la bibliothèque principale de l'application.

- Si la fonction **HOuvreSchémaDesDonnées** est appelée par une application associée à un schéma des données, cette fonction :

	- n'a aucun effet si le chemin du schéma des données spécifié correspond au chemin du schéma des données associé à l'application.

	- retourne <u><u><u><u>Faux</u></u></u></u> si le chemin du schéma des données spécifié n'existe pas. Dans ce cas, l'application continue de travailler avec le schéma des données en cours.

	- ouvre le schéma des données et retourne <u><u><u><u>Vrai</u></u></u></u> si le schéma des données spécifié existe et est valide.






<a name="NOTE0_2"></a>


### Lancement d'une application non associée à un schéma des données
<a name="lancement_une_application_non_associee_schema_des_donnees_ELTPARAGRAPHE000116"></a>

Au lancement d'une application non associée à un schéma des données, aucun schéma des données n'est automatiquement ouvert. Il est donc nécessaire d'utiliser la fonction **HOuvreSchémaDesDonnées**.

Le schéma des données ouvert avec la fonction **HOuvreSchémaDesDonnées** est recherché :

- tout d'abord, dans la bibliothèque principale de l'application selon son nom physique complet.

- puis, sur le disque en cours.



<a name="NOTE0_3"></a>


### Ouverture d'un schéma des données déjà ouvert
<a name="ouverture_schema_des_donnees_deja_ouvert_ELTPARAGRAPHE000132"></a>

Si le schéma des données ouverte par la fonction **HOuvreSchémaDesDonnées** est déjà ouvert, la fonction **HOuvreSchémaDesDonnées** n'a aucun effet.
<a name="NOTE0_5"></a>


### Version des schémas des données ouvertes avec la fonction HOuvreSchémaDesDonnées
<a name="version_des_schemas_des_donnees_ouvertes_avec_fonction_docparampagetitleshort_ELTPARAGRAPHE000143"></a>

**La fonction HOuvreSchémaDesDonnées ne permet pas d'ouvrir les schémas des données au format Hyper File 5.5 et inférieur. Seuls les schémas des données HFSQL Classic peuvent être ouverts.**

Pour utiliser la fonction **HOuvreSchémaDesDonnées** sur des fichiers Hyper File 5.5, il est nécessaire d'utiliser le fichier ".WDD" d'un schéma des données HFSQL Classic contenant des fichiers au format Hyper File 5.5. Dans ce cas, le fichier ".WDD" du schéma des données WINDEV 5.5 d'origine devra impérativement être présent dans le répertoire de l'exécutable.

**Il est également possible d'utiliser la fonction [HDéclare](../WDLang4/3044203.md) pour manipuler directement un fichier Hyper File 5.5.**
