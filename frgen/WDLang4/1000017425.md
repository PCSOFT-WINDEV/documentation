
## Politique de gestion des mots de passe
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000147"></a>
Pour manipuler les données d'une base HFSQL Client/Serveur, les utilisateurs s’identifient via un login et un mot de passe. 
La politique de gestion des mots de passe permet de définir aussi bien la taille de ces mots de passe que leur complexité ou encore leur mode de renouvellement (changement de mot de passe obligatoire tous les mois par exemple). 
Cette politique peut être définie et modifiée : 

- [via le Centre de Contrôle HFSQL](#NOTE2_1). 

- [par programmation](#NOTE3_1).

## Politique de gestion des mots de passe dans le Centre de Contrôle HFSQL
<a name="politique_gestion_des_mots_passe_dans_centre_controle_hfsql_ELTTEXTE000171"></a>
Le Centre de Contrôle HFSQL permet de : 

- [Activer la politique de gestion des mots de passe](#NOTE2_2). 

- [Définir les mots de passe des utilisateurs](#NOTE2_3)

- [Signaler les problèmes via le Widget "Audit de sécurité"](#NOTE2_4). 



<a name="NOTE2_2"></a>


### Activation de la politique de gestion des mots de passe
<a name="activation_politique_gestion_des_mots_passe_ELTPARAGRAPHE000041"></a>Pour activer les différentes options de la politique de gestion des mots de passe : 

1. Lancez le Centre de Contrôle HFSQL.  

2. Connectez-vous si nécessaire à un serveur HFSQL. Pour plus de détails, consultez [Gestion des bases de données HFSQL Client/Serveur](../CCHF/35400013.md). 

3. Double-cliquez sur le nom du serveur HFSQL dans l'arborescence. 

4. Dans le ruban, cliquez sur "Configuration du serveur". 

5. Dans la fenêtre de configuration, cliquez sur "Sécurité des mots de passe". La fenêtre qui s'affiche présente les différentes options activables pour mettre en place la gestion de la sécurité des mots de passe. 




Il est possible d'activer les options suivantes: 

- **Durée de validité du mot de passe**: Permet d'activer le contrôle sur la durée de validité d'un mot de passe. Il est possible de modifier ce délai (60 jours par défaut) en cliquant sur le nombre de jours proposé par défaut. Lorsque ce délai est écoulé, le mot de passe de l'utilisateur doit être changé. 

- **Délai avant changement**: Permet d'activer le contrôle sur le délai minimal entre deux changements de mots de passe. Il est possible de modifier ce délai (0 jours par défaut) en cliquant sur le nombre de jours proposé par défaut.

- **Délai avant réutilisation**: Permet d'activer le contrôle sur le délai entre deux réutilisations du même mot de passe.   Il est possible de modifier ce délai (365 jours par défaut) en cliquant sur le nombre de jours proposé par défaut. 

- **Changement avant réutilisation**: Permet d'activer le contrôle sur le nombre de changements de mots de passe avant la réutilisation d'un ancien un mot de passe. Il est possible de modifier ce nombre (3 changements par défaut) en cliquant sur le nombre proposé par défaut. 

- **Blocage après saisie invalide**: Permet d'activer le contrôle sur le nombre d'échec de saisie de mots de passe avant le blocage de la connexion pendant une durée déterminée. Il est possible de modifier ce nombre (5 échecs par défaut) et la durée (5 minutes par défaut) en cliquant sur les différentes valeurs proposées par défaut. 

- **Taille**: Permet d'activer le contrôle sur la taille minimale des mots de passe. Il est possible de modifier cette taille (12 caractères par défaut) en cliquant sur le nombre de caractères proposé par défaut.  

- **Complexité**: Permet de définir le contrôle sur la complexité attendue pour le mot de passe. Par défaut, aucun contrôle n'est effectué (option "Faible"). 

	- L'option "Moyenne" permet de vérifier que les mots de passe contiennent au moins une majuscule, une minuscule et un numérique. 

	- L'option "Elevée" permet de vérifier que les mots de passe contiennent au moins une majuscule, une minuscule, un numérique et un caractère spécial.








<a name="NOTE2_3"></a>


### Définition des mots de passe des utilisateurs
<a name="definition_des_mots_passe_des_utilisateurs_ELTPARAGRAPHE000059"></a>Lors de la création ou de la modification d'un utilisateur dans le Centre de Contrôle HFSQL, il est possible de définir ou de modifier le mot de passe d'un utilisateur. 

Si la politique de gestion des mots de passe a été activée, les critères concernant la taille des mots de passe, ainsi que la complexité des mots de passe sont automatiquement appliqués lors de la création d'un utilisateur. 
<a name="NOTE2_4"></a>


### Tableau de bord du serveur : Widget "Audit de sécurité"
<a name="tableau_bord_serveur_widget_audit_securite_ELTPARAGRAPHE000068"></a>Dans le tableau de bord du Centre de Contrôle HFSQL, le Widget "Audit de sécurité" permet de savoir si un ou plusieurs utilisateurs possèdent des mots de passe dont la durée de validité a expirée pour se connecter au serveur.

## Politique de gestion des mots de passe par programmation
<a name="politique_gestion_des_mots_passe_par_programmation_ELTTEXTE000243"></a>
Pour mettre en place la politique de gestion des mots de passe en WLangage : 

1. Créez une variable de type [hPolitiqueSécurité](../WDLang4/1410091181.md). Définissez les différentes valeurs des propriétés associées. 

2. Appliquez la politique de gestion des mots de passe grâce à la fonction [HPolitiqueSécuritéModifie](../WDLang4/1410091205.md). 




Plusieurs fonctions sont disponibles pour gérer la politique de gestion des mots de passe : 



|   |   |
| --- | --- |
| [HPolitiqueSécuritéDébloqueCompte](../WDLang4/1410091235.md) | Permet de débloquer le compte d'un utilisateur bloqué à cause d'un trop grand nombre de tentatives d'ouverture de connexion infructueuses.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [HPolitiqueSécuritéModifie](../WDLang4/1410091205.md) | Modifie la politique de sécurité des mots de passe d'un serveur HFSQL.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [HPolitiqueSécuritéRécupère](../WDLang4/1410091207.md) | Récupère la politique de sécurité d'un serveur HFSQL.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [HPolitiqueSécuritéVérifie](../WDLang4/1410091206.md) | Vérifie que la politique de sécurité des mots de passe associée au serveur HFSQL est respectée pour chacun des comptes des utilisateurs.<br><br>**Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
