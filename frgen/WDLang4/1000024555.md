


## HMiseAJourLiaison (Fonction)

***En anglais : HUpdateLink***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Met à jour sur le serveur l'ensemble des liaisons impliquant une table HFSQL Client/Serveur.

Remarque: L'ensemble des tables impliquées dans les liaisons doit avoir été configuré par la fonction [HChangeRep](../WDLang4/3044168.md) si besoin.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Met à jour les liaisons de la table Client
HMiseAJourLiaison(Client)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HMiseAJourLiaison(<Table> [, <Option>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la mise à jour a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. 




**`<Table> : (Chaîne de caractères)`**

Nom de la table permettant de connaître la liste des liaisons considérées. Ce paramètre peut également correspondre à: 

- "\*", pour indiquer que toutes les tables doivent être prises en compte,

- un nom de groupe de tables, défini dans le schéma des données. 




**`<Option> : (Constante ou combinaison de constantes optionnelle)`**

Options de la modification automatique des données: 


|   |   |
| --- | --- |
| *hmsNormal* <br>(Valeur par défaut) | Fonctionnement par défaut de la modification automatique des données. |
| *hmsSansContrôle* | La modification automatique des données est effectuée même si:<br><br>- la description de la table est plus récente que celle du schéma des données,<br><br>- le GUID du schéma des données et le GUID de la table sont différents.<br><br><br> |


**Remarque**: Les tables manipulées ne doivent pas être ouvertes (par l'application ou par une autre application).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Les rubriques utilisées par les liaisons doivent exister.

- Tous les fichiers du schéma des données doivent exister si vous utilisez le paramètre "\*"

- Lors de la mise à jour, les liaisons supprimées dans le schéma des données sont supprimées sur le serveur HFSQL. 

- Il est possible d'utiliser la fonction [HModifieStructure](../WDLang4/1000019439.md) avant d'utiliser la fonction **HMiseAJourLiaison**.
