


## HTableExiste (Fonction)

***En anglais : HFileExist***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir :

- si une table existe, c'est-à-dire si elle a été créée physiquement (fonctions [HCrée](../WDLang4/3044255.md) ou [HCréeSiInexistant](../WDLang4/3044254.md)). 
	Remarque : Les substitutions en cours sur la table (effectuées avec les fonctions [HSubstRep](../WDLang4/3044028.md), [HChangeRep](../WDLang4/3044168.md) et [HChangeNom](../WDLang4/3044141.md)) sont prises en compte.

- si une vue ou une requête a été définie.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple
<a class="notetitle" target="_blank" href="$DOC$=1000003044096&name=htableexiste_fonction">Voir des exemples supplémentaires</a>

```wl
// Test de l'existence de la table "Client"
SI HTableExiste(Client) = Vrai ALORS
	// Traitements
	...
FIN
```
<a name="Exemple2"></a>

```wl
// Test de l'existence d'une table Client/Serveur
SI HTableExiste(MaConnexion, "MaTable.TAB") = Vrai ALORS
	// Traitements
	...
FIN
```

## Syntaxe

### Tester l'existence d'une table, d'une requête ou d'une vue

`<Résultat> = HTableExiste([<Elément>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier physique existe,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Elément> : (Chaîne de caractères optionnelle)`**

Nom de l'élément à manipuler : 

- Nom de la table.

- Nom de la vue ou de la requête.




Si ce nom n'est pas spécifié, la fonction **HTableExiste** va manipuler la dernière table, la dernière requête ou vue manipulée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

### Tester l'existence d'une table en HFSQL Client/Serveur

`<Résultat> = HTableExiste(<Connexion> , <Fichier physique>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table physique existe sur le serveur,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion associée à la table. Cette connexion correspond : 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).




**`<Fichier physique> : (Chaîne de caractères)`**

Nom physique de la table recherchée. L'extension du fichier doit être précisée (par exemple "Client.fic").



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La fonction **HTableExiste** est utilisable que la table soit ouverte ou non.

- La fonction **HTableExiste** n'ouvre pas la table si celle-ci est fermée.
