
## Tables HFSQL de plus de 2 Giga
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000122"></a>
Par défaut, le moteur HFSQL permet de gérer des tables d'une taille très importante (jusqu'à 2 Giga). 

Lorsque la taille d'une table, de son index, de son index full-text et/ou de son mémo excède 2 Giga, une configuration spécifique est nécessaire au niveau de l'éditeur de schémas des données comme au niveau matériel.

En effet, pour gérer les tables de plus de 2 Giga, il est nécessaire d'utiliser :

- un système d'exploitation gérant les fichiers de plus de 4 Giga. Les systèmes suivants ne gèrent pas les fichiers de plus de 4 Giga : Windows 98 et Windows Me.

- un système de fichiers gérant les fichiers de plus de 4 Giga (par exemple NTFS sous Windows). 




**Attention** : Cette configuration est nécessaire aussi bien sur le poste où les tables sont installées que sur les postes accédant à ces tables. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Configurer les tables (sous l'éditeur de schémas des données)
<a name="configurer_les_tables_sous_editeur_schemas_des_donnees_ELTTEXTE000146"></a>
Pour gérer des tables de plus de 2 Giga :

1. Affichez la description de la table voulue (option "Description de la table" du menu contextuel).

2. Dans l'onglet "Compatibilité", cochez l'option "Gestion des fichiers de plus de 2 Go (conseillé pour les systèmes d'exploitation plus récents que Windows 2000 ou Linux Ext2)".

3. Validez. 




**Attention** : Ces tables seront utilisables uniquement à partir d'un poste utilisant un système d'exploitation gérant les fichiers de plus de 4 Giga.

## Utiliser des tables de plus de 2 Giga
<a name="utiliser_des_tables_plus_2_giga_ELTTEXTE000170"></a>


### Description dynamique de tables
<a name="description_dynamique_tables_ELTPARAGRAPHE000053"></a>

Lors de la description dynamique d'une table (utilisation des propriétés HFSQL et de la fonction [HDécritTable](../WDLang4/3044206.md)), il est possible de configurer la gestion de la taille de la table grâce à la propriété [GrosFichier](../Proprietes/2512037.md).
<a name="NOTE3_2"></a>


### Propriété du WLangage
<a name="propriete_wlangage_ELTPARAGRAPHE000066"></a>




|   |   |
| --- | --- |
| [GrosFichier](../Proprietes/2512037.md) | La propriété **GrosFichier** permet de paramétrer la taille maximale possible d'une table. |




<a name="NOTE3_3"></a>


### Réindexation
<a name="reindexation_ELTPARAGRAPHE000073"></a>

**Attention** : La réindexation de tables de plus de 2 Giga peut être relativement longue.
