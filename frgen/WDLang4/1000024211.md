


## &lt;Source&gt;.DébloqueTable (Fonction)

***En anglais : &lt;Source&gt;.UnlockFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Débloque les enregistrements d'une table :

- précédemment bloqués avec la fonction [&lt;Source&gt;.BloqueTable](../WDLang4/1000024196.md).

- bloqués individuellement avec une fonction de lecture bloquante.




Le déblocage de la table peut aussi être obtenu en fermant la table (fonction [&lt;Source&gt;.Ferme](../WDLang4/1000024958.md)).

Remarque : La fonction **&lt;Source&gt;.DébloqueTable** ne permet pas de débloquer une table bloquée par une autre session ou un autre programme. Il est conseillé de débloquer une table le plus rapidement possible, afin que les autres sessions puissent accéder à cette table.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonction peut être utilisée avec des tables HFSQL Client/Serveur.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Blocage
Client.BloqueFichier(HBlocageLectureEcriture)
// Modification du fichier
...
// Déblocage
Client.DébloqueFichier()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.DébloqueFichier()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la table a été débloquée, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème (par exemple la table n'est pas bloquée, ...). La fonction [HErreur](../WDLang4/3044088.md) permet d'identifier l'erreur.




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table manipulée. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
La fonction **&lt;Source&gt;.DébloqueTable** est sans effet si :

- la table est en mode Mono (voir la fonction [&lt;Source&gt;.Mode](../WDLang4/1000025037.md)).

- la table n'est pas bloquée.

- la table a été bloquée par un autre programme.
