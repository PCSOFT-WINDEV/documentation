


## mongoConnexion (Type de variable)

***En anglais : mongoConnection***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **mongoConnexion** permet de définir toutes les caractéristiques avancées d'une connexion à un serveur MongoDB. Les caractéristiques de cette connexion peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
cnxMDB est une mongoConnexion
cnxMDB = MongoCrée("mongodb://db1.exemple.net")
POUR TOUT MaBase DE cnxMDB.BaseDeDonnées
	Trace(MaBase.Nom)
FIN
```

```wl
cnxMDB est une mongoConnexion("mongodb://db1.exemple.net")
POUR TOUT MaBase DE cnxMDB.BaseDeDonnées
	Trace(MaBase.Nom)
FIN
```



## Déclaration
<a name="declaration_ELTTEXTE000154"></a>
<a name="SYNTAXE1"></a>

`MaVariable est un mongoConnexion(<Chaîne de connexion>)`
---

**`<Chaîne de connexion> : (Chaîne de caractères)`**

Chaîne de connexion au serveur ou du cluster hébergeant la base MongoDB. Pour plus de détails, consultez la documentation de MongoDB. 



<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type mongoConnexion
<a name="proprietes_specifiques_description_des_variables_type_mongoconnexion_ELTPARAGRAPHE000044"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une connexion MongoDB:

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| BaseDeDonnées | Tableau de [mongoBase](../WDLang4/1000022410.md) | Tableau associatif contenant les bases créées sur le serveur MongoDB. |
