


## &lt;Source&gt;.DésactiveFiltreAuto (Fonction)

***En anglais : &lt;Source&gt;.DeactivateAutoFilter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Désactive un filtre automatique sur les tables reliées lors du parcours d'un fichier XML. Ce filtre a été activé grâce à la fonction [&lt;Source&gt;.ActiveFiltreAuto](../WDLang4/1000024171.md).

**Attention**: Cette fonction est disponible uniquement pour l'Accès Natif XML.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Activation de tous les filtres auto possibles de la table Client
Client.ActiveFiltreAuto("*")
// sauf entre Client et Commande
Client.DésactiveFiltreAuto(Commande)

/////////////////////////////

// Parcours des commandes
Commande.LitPremier(IDCommande)
TANTQUE Commande.EnDehors() = Faux
	// Parcours les lignes de commande de la commande en cours
	LigneCde.LitPremier(IDCommande)
	TANTQUE LigneCde.EnDehors() = Faux
		LigneCde.LitSuivant(IDCommande)
	FIN
	// Commande suivante
	Commande.LitSuivant(IDCommande)
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Source>.DésactiveFiltreAuto(<Table à ne pas filtrer>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le filtre est désactivé, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur (table ou rubrique inexistante).




**`<Source> : (Type correspondant à la source spécifiée)`**

Nom de la table utilisée pour le parcours.

**`<Table à ne pas filtrer> : (Chaîne de caractères)`**



- Nom de la table à ne pas filtrer lors d'un positionnement dans la table de parcours.

- "\*" pour désactiver tous les filtres automatiques possibles.
