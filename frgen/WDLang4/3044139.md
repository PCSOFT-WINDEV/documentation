


## HGèreMémo (Fonction)

***En anglais : HSetMemo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de modifier la gestion des rubriques de type mémo. Il est possible de gérer tous les mémos d'une table ou uniquement une rubrique mémo spécifique d'une table. Par défaut, la gestion des mémos est activée.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) Seule la gestion des mémos au niveau de la table est possible: il est impossible de gérer les mémos au niveau des rubriques.![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png) L'appel de la fonction **HGèreMémo** provoque la fermeture de tous les parcours commencés. Les critères de filtrage et de recherche sont conservés.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Désactive la gestion des mémos sur les observations de la table Client
HGèreMémo(Client, Rub_Observations, hMémoNon)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HGèreMémo([<Table> [, <Rubrique mémo>, ]] <Mode de gestion>)`
---

**`<Résultat> : (Entier)`**

Ancien mode de gestion des mémos utilisé (avant utilisation de la fonction **HGèreMémo**).


|   |   |
| --- | --- |
| *hMémoAuto*<br>(valeur par défaut) | Lecture des mémos lors de l'accès à la rubrique. |
| *hMémoNon* | Pas de gestion des mémos (aucune lecture et aucune écriture ne sera effectuée dans la table ou dans la rubrique spécifiée). |
| *hMémoOui* | Lecture des mémos texte à chaque lecture de l'enregistrement.<br>Lecture des mémos binaires uniquement lors de l'accès à la rubrique. |



**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table manipulée. 
Si ce nom n'est pas spécifié ou est égal à "\*", tous les fichiers mémo sont pris en compte.

**`<Rubrique mémo> : (Chaîne de caractères optionnelle)`**

Nom de la rubrique mémo à gérer ou non. 
Si ce nom n'est pas spécifié ou est égal à "\*", toutes les rubriques mémo sont prises en compte.
![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) Seule la gestion des mémos au niveau de la table est possible: il est impossible de gérer les mémos au niveau des rubriques.

**`<Mode de gestion> : (Constante de type Entier)`**

Mode de gestion des rubriques de type mémo voulu:


|   |   |
| --- | --- |
| *hMémoAuto*<br>(valeur par défaut) | Lecture des mémos lors de l'accès à la rubrique. |
| *hMémoNon* | Pas de gestion des mémos (aucune lecture et aucune écriture ne sera effectuée dans la table ou dans la rubrique spécifiée). |
| *hMémoOui* | Lecture des mémos texte à chaque lecture de l'enregistrement.<br>Lecture des mémos binaires uniquement lors de l'accès à la rubrique. |


Si seul ce paramètre est précisé, le mode de gestion spécifié s'applique à toutes les tables et à toutes les rubriques.
![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png) La constante *hMémoAuto* est équivalente à la constante *hMémoOui*.
