


## &lt;Variable Polygone2D&gt;.Corrige (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.Correct***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'obtenir une version corrigée du polygone en 2 dimensions spécifié. 

**Remarque** : Dans certains cas, il est possible de corriger automatiquement un certain nombre de problèmes dans une géométrie, tels que, par exemple, une mauvaise orientation des points dans un polygone.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Correction d'un triangle dont les points du contour sont disposés 
// dans le sens inverse des aiguilles d'une montre
triangle est un Polygone2D
triangle.Contour.AjoutePoint(-3.00, 1.00)
triangle.Contour.AjoutePoint(1.00, -2.00)
triangle.Contour.AjoutePoint(2.00, 2.00)
triangle.Contour.AjoutePoint(-3.00, 1.00)
Trace("triangle.EstValide() = " + triangle.EstValide()) // Affiche "Faux"

// Correction
triangle_corrigé est un Polygone2D
triangle_corrigé = triangle.Corrige()
Trace("triangle_corrigé.EstValide() = " + triangle_corrigé.EstValide()) // Affiche "Vrai"
Trace("triangle.EstValide() = " + triangle.EstValide()) 
// Affiche toujours "Faux" : la géométrie donnée en paramètre n'est pas modifiée
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie>.Corrige()`
---

**`<Résultat> : (Variable correspondant à la géométrie manipulée)`**

Géométrie corrigée.

**`<Géométrie> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.
