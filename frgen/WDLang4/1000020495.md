


## HRSModifieConfig (Fonction)

***En anglais : HRSModifyConfig***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie certains paramètres d'une réplication existante entre deux serveurs HFSQL. Cette fonction doit être exécutée sur un serveur HFSQL maître d'une réplication. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Cnx est une Connexion
ConfigRéplication1 est un hRSConfig
...
ConfigRéplication1.Planification..Heure = "*/2"
HRSModifieConfig(Cnx, ConfigRéplication1)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HRSModifieConfig(<Connexion> , <Réplication>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la réplication a été modifiée,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion vers le serveur HFSQL maître sur lequel la configuration de réplication doit être modifiée. Cette connexion correspond: 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).




**`<Réplication> : (Variable de type hRSConfig)`**

Nom de la variable de type [hRSConfig](../WDLang4/1000020484.md) décrivant la réplication modifiée à mettre à jour.
