


## GéométrieEstContenu (Fonction)

***En anglais : GeometryWithin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si la géométrie A est complètement contenue dans la géométrie B (c'est-à-dire que la géométrie B contient complètement la géométrie A). 

Dans ce cas: 

- Il n'existe pas de point de la géométrie A dans l'extérieur de la géométrie B: tout point de la géométrie A est soit dans l'intérieur de la géométrie B, soit dans son contour.

- Il existe au moins un point de l'intérieur de la géométrie A dans l'intérieur de la géométrie B.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oPolygone2D_1 est un Polygone2D
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, -4.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, 2.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, 5.00, 2.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, 5.00, -4.00)
// Ajout du dernier point (identique au premier)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, -4.00)

oPolygone2D_2 est un Polygone2D
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, -1.00, -2.00)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, 2.00, 0.00)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, 2.00, -2.00)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, -1.00, -2.00) // Fermeture

soit p2_dans_p1 = GéométrieContient(oPolygone2D_1, oPolygone2D_2) // Renvoie "vrai"
GéométrieEstContenu(oPolygone2D_2, oPolygone2D_1) // Renvoie "vrai"
```

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = GéométrieEstContenu(<Géométrie A> , <Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie A est contenue dans la géométrie B, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

## Remarques
La fonction **GéométrieEstContenu** est similaire à la fonction [GéométrieEstCouvert](../WDLang4/1410090141.md). Cependant, avec la fonction [GéométrieEstCouvert](../WDLang4/1410090141.md), il n'est pas nécessaire d'avoir un point de l'intérieur de la géométrie A dans l'intérieur de la géométrie B. Ainsi, un polygone couvre son contour, mais il ne le contient pas.


### Parcours des données spatiales: utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000209"></a>

Il est possible d'effectuer un parcours sur une table avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **GéométrieEstContenu**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante: 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où: 

- Fonction_WLangage correspond à la fonction **GéométrieEstContenu**. 

- Rubrique_spatiale correspond à une rubrique spatiale de la table. Cette rubrique doit: 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque: Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, toute la table est parcourue: les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
Exemple: 


```wl
// Définition d'un triangle délimitant une zone géographique
// Mémorisation de ce triangle dans une variable de type PolygoneGéo 
polyGeo est un PolygoneGéo
polyGeo.Contour.AjoutePoint(0n48.8187479172765, 0n1.9550104465229536)
polyGeo.Contour.AjoutePoint(0n48.685649220185574, 0n2.023674998054354)
polyGeo.Contour.AjoutePoint(0n48.82612543243871, 0n2.2106580854197566)
polyGeo = GéométrieCorrige(polyGeo)

// Recherche les communes ayant un territoire dans le triangle ciblé
nbEnregs est un entier
POUR CHAQUE DatasCommunes AVEC GéométrieEstContenu(DatasCommunes.geometry, polyGeo) 
	//Nom de la commune dans une trace
	Trace(DatasCommunes.NomCommune)
FIN
```
