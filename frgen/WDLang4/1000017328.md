


## HListeIndexFullText (Fonction)

***En anglais : HListFullTextIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des index full-text d'une table reconnue par le moteur HFSQL. Il est possible de savoir:

- la formule de l'index full-text,

- si l'index full-text est sensible à la casse ou aux accents,

- la longueur minimale des mots indexés,

- si l'index full-text gère le HTML ou le RTF,

- si l'index full-text utilise une liste de mots creux

- si l'index full-text utilise une liste de synonymes

- quelle langue est utilisée pour la racination...




Les fichiers définis par les fonctions [HDéclare](../WDLang4/3044203.md), [HDéclareExterne](../WDLang4/3044204.md) et [HDécritTable](../WDLang4/3044206.md) sont pris en compte.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupérer les index full-text d'une table du schéma des données en cours
ListeFullText est une chaîne
ListeFullText = HListeIndexFullText(CLIENT, hLstDétail)
// Ajoute la liste des index dans le champ COMBO_COMBO1
ListeAjoute(COMBO_COMBO1, ListeFullText)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HListeIndexFullText(<Table> [, <Chemin du WDD> [, <Mot de passe du WDD> [, <Options>]]])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des index full-text présents dans la table spécifiée. Les différentes descriptions de chaque index full-text sont séparées par RC (Retour chariot). En fonction de la constante utilisée, le résultat est plus ou moins détaillé:


|   |   |
| --- | --- |
| *hLstDétail* non précisé | &lt;Nom de l'index full-text 1&gt; + RC + &lt;Nom de l'index full-text 2 + RC + ...<br>Le résultat avec la constante *hLstTriée* est identique. |
| *hLstDétail* précisé | <br><br>- **Avant la version 20**: &lt;Nom de l'index full-text 1&gt; + TAB + &lt;Formule&gt; + RC + ...<br><br>- **Après la version 20**: &lt;Nom de l'index full-text 1&gt; + TAB + &lt;Formule&gt; + TAB+ &lt;Sensible à la casse&gt; + TAB + &lt;Sensible aux accents&gt; + TAB + &lt;Longueur minimale&gt; + TAB + &lt;Gestion HTML&gt; + TAB + &lt;Gestion RTF&gt; + TAB + &lt;Mots Creux&gt; + TAB + &lt;Synonymes&gt; + TAB + &lt;Racinisation&gt; + RC + ...<br><br><br> |

Où:


- &lt;Nom de l'index full-text X&gt;: nom de la rubrique index full-text

- &lt;Formule&gt;: liste des rubriques qui composent l'index full-text. Les rubriques sont séparées par le caractère "+".




- &lt;Sensible à la casse&gt;: "1" si l'index full-text est sensible à la casse, "0" sinon.

- &lt;Sensible aux accents&gt;: "1" si l'index full-text est sensible aux accents, "0" sinon.

- &lt;Longueur minimale&gt;: longueur minimale des mots indexés (0 si tous les mots sont indexés).

- &lt;Gestion HTML&gt;: "1" pour que les balises HTML ne soient pas indexées, "0" pour ne pas gérer le HTML.

- &lt;Gestion RTF&gt;: "1" pour que les balises RTF ne soient pas indexées, "0" pour ne pas gérer le RTF.

- &lt;Mots Creux&gt;: "1" si l'index full-text utilise une liste de mots creux, "0" sinon.

- &lt;Synonymes&gt;: "1" si l'index full-text utilise une liste de synonymes, "0" sinon.

- &lt;Racinisation&gt;: entier correspondant à la langue utilisée pour la racinisation, "0" si l'index full-text n'utilise pas la racinisation.




**`<Table> : (Chaîne de caractères)`**

Nom de la table pour laquelle les index full-text doivent être listés.

**`<Chemin du WDD> : (Chaîne de caractères optionnelle)`**

Chemin complet du schéma des données (c'est-à-dire du fichier .WDD) dans laquelle la table est décrite. Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), la table est recherchée dans le schéma des données en cours.

**`<Mot de passe du WDD> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe défini pour le schéma des données. Si aucun mot de passe n'est défini, ce paramètre doit être égal à une chaîne vide ("").
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Options> : (Constante ou combinaison de constantes de type entier (optionnel))`**

Paramètre le type de liste à effectuer:


|   |   |
| --- | --- |
| *hLstDétail* | Informations détaillées. |
| *hLstNormal*<br>(valeur par défaut) | Informations non détaillées. |
| *hLstTriée* | Trie la liste par ordre croissant. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Affichage du résultat dans un champ Liste ou un champ Combo
<a name="affichage_resultat_dans_champ_liste_champ_combo_ELTPARAGRAPHE000154"></a>

&lt;Résultat&gt; peut être directement affecté à un champ Liste ou un champ Combo grâce à la fonction [ListeAjoute](../WDLang1/3049004.md). Chaque ligne contiendra le nom d'un des index full-text trouvés.
<a name="NOTE0_2"></a>


### Extraire une information du résultat
<a name="extraire_une_information_resultat_ELTPARAGRAPHE000166"></a>

Pour extraire une information du résultat détaillé, il est conseillé d'utiliser la fonction [ExtraitChaîne](../WDLang1/3024017.md).
