


## &lt;Connexion HFSQL&gt;.ListeHistoriqueReindexation (Fonction)

***En anglais : &lt;HFSQL connection&gt;.ListReindexingHistory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les différentes opérations effectuées sur les tables en cours ou celles qui ont eu lieu pendant les dernières 24 heures et sur les 1000 dernières tables: réindexations, recalcul des statistiques, vérification des mémo, vérification des index, etc.  

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une connexion
tabHistoriques est un tableau de hHistoriqueRéindexation 
// Liste des réindexations / vérifications en cours
tabHistoriques = CnxBaseDeDonnées.ListeHistoriqueReindexation()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion>.ListeHistoriqueReindexation()`
---

**`<Résultat> : (Tableau de variables de type hHistoriqueRéindexation)`**

Tableau de variables de type [hHistoriqueRéindexation](../WDLang4/1410091059.md), contenant les caractéristiques des différentes réindexations effectuées.

**`<Connexion> : (Variable de type Connexion)`**

Connexion vers le serveur contenant les données à manipuler. Cette connexion correspond au nom d'une variable de type [Connexion](../WDLang4/1514073.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Les opérations listées par la fonction **&lt;Connexion HFSQL&gt;.ListeHistoriqueReindexation** sont les suivantes: 

- réindexations lancées par la fonction [&lt;Connexion HFSQL&gt;.RéindexeAsynchrone](../WDLang4/1410091221.md). 

- calculs de statistiques exécutés par la fonction [HStatCalculAsynchrone](../WDLang4/1410091224.md). 

- vérification des index exécutée par la fonction [&lt;Connexion HFSQL&gt;.VérifieIndexAsynchrone](../WDLang4/1410091223.md). 

- vérification des mémos exécutée par la fonction [&lt;Connexion HFSQL&gt;.VérifieMémoAsynchrone](../WDLang4/1410091222.md).
