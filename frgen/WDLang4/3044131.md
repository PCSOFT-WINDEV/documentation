


## HRéindexationEnCours (Fonction)

***En anglais : HIndexingInProgress***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Avertissement</B><BR>
	A partir de la version <B>30.2 (2028)</B>,  ***HIndexingInProgress*</**>** is kept for backward compatibility. This function has been replaced with ***HRéindexationEnCours*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Avertit si une ré-indexation est en cours sur une table HFSQL et renvoie le pourcentage de ré-indexation effectué.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI HRéindexationEnCours(Client) <> 0 ALORS
	Trace("Opération impossible, réindexation en cours")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = HRéindexationEnCours(<Table> [, <Jauge>])`
---

**`<Résultat> : (Entier)`**



- 0 si aucune ré-indexation n'est en cours sur la table,

- un entier compris entre 1 et 100 indiquant le pourcentage de ré-indexation déjà effectué




**`<Table> : (Chaîne de caractères)`**

Nom de la table manipulée.

**`<Jauge> : (Nom de fenêtre, nom de champ ou entier optionnel)`**



- Nom de la fenêtre dans laquelle la jauge doit être affichée, ou nom du champ de type Jauge.

- Identifiant (Handle) de la fenêtre qui affiche la jauge.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Ce paramètre n'est pas pris en compte.

## Remarques


### Ré-indexation
<a name="reindexation_ELTPARAGRAPHE000081"></a>La réindexation ré-organise les index. Pendant la ré-indexation, tout accès aux données est impossible.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Par défaut, lors d'un accès à une table en cours de ré-indexation, le moteur HFSQL affiche une fenêtre indiquant qu'une ré-indexation est en cours. Cette fenêtre sera automatiquement fermée à la fin de la ré-indexation.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=HF_Reindexation.gif)
Pour plus de détails sur cette fenêtre et sa personnalisation, consultez [Gestion assistée des erreurs HFSQL](../WDLang4/3044188.md).
