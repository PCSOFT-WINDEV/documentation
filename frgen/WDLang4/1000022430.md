


## HSurveilleStop (Fonction)

***En anglais : HWatchStop***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Avertissement</B><BR>
	A partir de la version <B>29 (74)</B>,  ***HTrackStop*</**>** is kept for backward compatibility. This function has been replaced with ***HSurveilleStop*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête la surveillance d'une table sur un serveur HFSQL. Cette surveillance a été précédemment démarrée via la fonction [HSurveille](../WDLang4/1000022407.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Lance la surveillance de la table Commande
// La procédure TraiteCommande est appelée pour tout ajout d'enregistrement dans la table
HSurveille(Commande, TraiteCommande, hNumEnrTous, hsAjout)
...
// Arrête la surveillance du fichier de données Commande
HSurveilleStop(Commande, TraiteCommande, hNumEnrTous)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HSurveilleStop(<Table> , <Procédure WLangage> [, <Numéro d'enregistrement>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la surveillance a été arrêtée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire (par exemple, surveillance inexistante). Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Table> : (Chaîne de caractères optionnelle)`**

Nom de la table HFSQL à manipuler. Cette table est associée à une connexion et à un serveur. 
Si ce paramètre correspond à une chaîne vide (""), la fonction **HSurveilleStop** manipule la dernière table utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

**`<Procédure WLangage> : (Nom de procédure)`**

Nom d'une procédure WLangage à ne plus appeler pour la surveillance de la table. 

**`<Numéro d'enregistrement> : (Entier optionnel)`**

Numéro de l'enregistrement à ne plus surveiller. 
Si ce paramètre n'est pas précisé ou correspond à la constante *hNumEnrTous*, la fonction **HSurveilleStop** va arrêter de surveiller tous les enregistrements de la table (c'est-à-dire toute la table).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Les fonctions [HSurveille](../WDLang4/1000022407.md) et **HSurveilleStop** peuvent être utilisées dans un service Windows.
