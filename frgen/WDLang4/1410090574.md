


## &lt;Variable PolygoneGéo&gt;.EstValide (Fonction)

***En anglais : &lt;PolygonGeo variable&gt;.IsValid***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie si le polygone géographique spécifié est valide au sens de la norme OGC.
<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie>.EstValide()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie est valide, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie> : (Variable de type PolygoneGéo)`**

Nom de la variable de type [PolygoneGéo](../WDLang4/1410090127.md) à manipuler.
