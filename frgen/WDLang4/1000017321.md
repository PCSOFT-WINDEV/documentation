


## HListeParamètre (Fonction)

***En anglais : HListParameter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des paramètres sauvegardés à partir des procédures stockées sur le serveur.

**Remarque**: Les paramètres sont sauvegardés par base de données dans le fichier "user_param.fic".




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupération de la liste des valeurs sauvées
// (Code d'une procédure stockée)
MaListe est une chaîne
MaListe = HListeParamètre()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Liste les paramètres sauvegardés  sur le serveur (dans le code de la procédure stockée)

`<Résultat> = HListeParamètre()`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des noms de paramètre séparés par des RC (Retours Chariot).  


<a name="SYNTAXE2"></a>

### Liste les paramètres sauvegardés sur le serveur (depuis le poste Client)

`<Résultat> = HListeParamètre(<Connexion>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des noms de paramètre séparés par des RC (Retours Chariot). 

**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion à utiliser. Cette connexion correspond: 

- soit au nom de la connexion définie sous l'éditeur de schémas des données ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md).
