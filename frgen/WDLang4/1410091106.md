
## Paramètres de la procédure utilisée par la fonction HVérifieMémoAsynchrone



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [HVérifieMémoAsynchrone](../WDLang4/1410091107.md) pour chaque table HFSQL Client/Serveur vérifiée.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauAjoute(TableauFichier, MonFichierParam)

HVérifieMémoAsynchrone(CnxBaseDeDonnées, TableauFichier, CB_HVérifieMémoAsynchrone)
	PROCÉDURE INTERNE CB_HVérifieMémoAsynchrone(MaTable est une chaîne, MonRésultat est une chaîne)
		SI MonResultat = "" ALORS
			Trace("Table traitée et vérifiée " + MaTable)
		SINON
			Trace("Table traitée avec problème " + MaTable)
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`HVérifieMémoAsynchrone_Callback(<Table> , <Résultat>)`
---

**`<Table> : (Chaîne de caractères)`**

Nom de la table HFSQL Client/Serveur manipulée. 

**`<Résultat> : (Chaîne de caractères)`**



- Chaîne vide ("") si aucun problème n'a été trouvé. 

- En cas de corruption de la liste des blocs libres, &lt;Résultat&gt; contient:
	
	```txt
	<TAB> + "-1"+ RC + <Rubrique 1> + TAB + <Numéro d'enregistrement 1> + RC + ...
	<Rubrique N> + TAB + <Numéro d'enregistrement N>
	```
 où: 

	- &lt;Rubrique X&gt; est la rubrique mémo, 

	- &lt;Numéro d'enregistrement&gt; est le numéro de l'enregistrement contenant la rubrique Mémo.
