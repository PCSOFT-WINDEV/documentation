


## &lt;Zone répétée&gt;.Supprime (Fonction)

***En anglais : &lt;Looper&gt;.Delete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une répétition dans un champ Zone répétée. Le champ Zone répété est automatiquement rafraîchi.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression de la répétition 1
ZR_ZoneProd.Supprime(1)
```
<a name="Exemple2"></a>

```wl
// Suppression de la répétition en cours
ZR_ZoneProd.Supprime()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Zone répétée>.Supprime([<Indice> [, <Animation>]])`
---

**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à manipuler.

**`<Indice> : (Entier optionnel)`**

Indice de la répétition à supprimer.

- Si ce paramètre n'est pas précisé, la suppression sera effectuée sur la répétition en cours.

- Si &lt;Indice&gt; est supérieur au nombre de répétitions, la fonction **&lt;Zone répétée&gt;.Supprime** est sans effet.




**`<Animation> : (Constante optionnelle de type Entier)`**

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Gestion de l'animation lors de la suppression: 



|   |   |
| --- | --- |
| *zrAnimationAucune*<br>(Valeur par défaut) | Aucune animation n'est jouée lors de la suppression. |
| *zrAnimationSuppression* | Joue une animation lors de la suppression. Cette animation correspond à un effet de disparition par diminution de la hauteur de la répétition. |

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000237"></a>

La fonction **&lt;Zone répétée&gt;.Supprime** peut être utilisée indifféremment sur : 

- un champ Zone répétée fichier,

- un champ Zone répétée par programmation. 


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur. ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La fonction **&lt;Zone répétée&gt;.Supprime** peut être utilisée uniquement sur un champ Zone répétée par programmation.


### Utilisation avec un champ Zone répétée liée aux données
<a name="utilisation_avec_champ_zone_repetee_liee_aux_donnees_ELTPARAGRAPHE000267"></a>

Si le champ Zone répétée est basé sur une table:

- l'enregistrement est supprimé dans la table. 

- la répétition suivante est sélectionnée (si la dernière répétition est supprimée, la répétition précédente sera sélectionnée). L'enregistrement sélectionné dans la table liée correspond à la répétition sélectionnée.
