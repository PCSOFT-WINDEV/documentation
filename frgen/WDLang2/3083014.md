


## ZoneRépétéeOccurrence (Fonction)

***En anglais : LooperCount***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nombre de répétitions d'un champ Zone répétée.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Nombre de répétitions dans le champ Zone répétée "ZR_Zone1"?
Résultat1 est un entier
Résultat1 = ZoneRépétéeOccurrence(ZR_Zone1)
```
<a name="Exemple2"></a>

```wl
// Affiche le nombre de réponses trouvées: (ex: "Il y a 31 réponses")
LIB_LIBELLE1 = "Il y a " + ZoneRépétéeOccurrence(ZR_ZoneResultat) + " réponses"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = ZoneRépétéeOccurrence(<Champ Zone répétée> [, <Répétition/Attribut>])`
---

**`<Résultat> : (Entier)`**



- Nombre de répétitions du champ Zone répétée, 

- 0 si le champ Zone répétée est vide.




**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à manipuler.
Si ce paramètre est égal à chaîne vide (""), le comptage sera effectué sur le champ Zone répétée en cours.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000167"></a>

La fonction **ZoneRépétéeOccurrence** peut être utilisée indifféremment sur : 

- un champ Zone répétée fichier,

- un champ Zone répétée par programmation. 


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur. ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La fonction **ZoneRépétéeOccurrence** peut être utilisée uniquement sur un champ Zone répétée par programmation.
