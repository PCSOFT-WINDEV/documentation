


## &lt;Variable adminWBAuth&gt;.Déconnecter (Fonction)

***En anglais : &lt;WBAdminAuth variable&gt;.Disconnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une connexion sur un Serveur d'application WEBDEV.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
wbAuthLogin est un adminWBAuth
wbAuthLogin.AdresseServeur = "https://mon-serveur.interne/"
wbAuthLogin.Utilisateur = "WWW\DATA"
wbAuthLogin.MotDePasse = "www"
ConnexionsWB est un tableau de adminWBConnexions = wbAuthLogin.ListeConnexion()
wbAuthLogin.Déconnecte(ConnexionsWB[0])
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Serveur d'application WEBDEV>.Déconnecte([<Connexion>])`
---

**`<Serveur d'application WEBDEV> : (Variable de type adminWBAuth)`**

Nom de la variable de type [adminWBAuth](../WDLang2/1410089328.md) décrivant le serveur et le compte administrateur utilisé pour interroger le Serveur d'application WEBDEV.

**`<Connexion> : (Variable de type adminWBConnexion optionnel)`**

Nom de la variable de type [adminWBConnexion](../WDLang2/1410089344.md) identifiant une connexion sur le serveur. Cette connexion est connue via la fonction [&lt;Variable adminWBAuth&gt;.ListeConnexion](../WDLang2/1410089715.md). 
Si ce paramètre n'est pas précisé, toutes les connexions sont supprimées.

## Remarques


### Gestion de la double authentification
<a name="gestion_double_authentification_ELTPARAGRAPHE000179"></a>Il est possible d'activer la double authentification sur un compte via l'administrateur distant WEBDEV. La vérification en 2 étapes nécessite d'obtenir un code unique pour vérifier l'identité de l'utilisateur. Ce code peut être reçu par email ou via une application "Authenticator".

Lors de l'utilisation d'une fonction de pilotage du serveur d'application WEBDEV, si le compte utilise la double authentification, une erreur d'authentification peut survenir. Deux cas doivent être pris en compte : 

- si la fonction renvoie un booléen, &lt;Résultat&gt; est à <u><u><u><u>Faux</u></u></u></u>. Pour vérifier si l'erreur concerne l'authentification, il est nécessaire de vérifier la valeur de la variable [ErreurDétectée](../WDLang1/3087001.md) et la valeur renvoyée par la fonction [ErreurInfo](../WDLang1/3013008.md).

- si la fonction ne renvoie pas de booléen. Pour vérifier si l'erreur concerne l'authentification, les conditions suivantes doivent être réunies : 

	- la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>, 

	- la fonction [ErreurInfo](../WDLang1/3013008.md) utilisée avec la constante *errCode* renvoie 2. 







La procédure à suivre pour gérer cette erreur est la suivante : 

- Faire une fenêtre / page permettant à l'utilisateur de saisir son code de vérification. 

- En cas d'erreur due à la double authentification : 

	- Afficher la fenêtre de saisie du code de vérification. 

	- L'utilisateur reçoit automatiquement le code d'authentification selon la méthode choisie dans l'administrateur distant WEBDEV. Il peut alors saisir le code dans la fenêtre / page.

	- Affecter le code à la propriété **CodeVérification** de la variable [adminWBAuth](../WDLang2/1410089328.md). 

	- Ré-exécuter la fonction de pilotage.
