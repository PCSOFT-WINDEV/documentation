


## Fonctions Captcha
			



**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Captcha (syntaxe préfixée)](../WDLang2/1000019584.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de manipuler les champs Captcha sont les suivantes :



|   |   |
| --- | --- |
| [CaptchaAffiche](../WDLang2/1000019389.md) | Affiche un nouveau Captcha dans un champ Captcha. |
| [CaptchaVérifie](../WDLang2/1000019390.md) | Vérifie si la valeur saisie par l'utilisateur correspond à la chaîne affichée dans un champ Captcha. |
