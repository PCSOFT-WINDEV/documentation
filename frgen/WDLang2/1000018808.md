


## UploadSupprime (Fonction)

***En anglais : UploadDelete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un fichier de la liste des fichiers à uploader : le fichier ne sera pas uploadé sur le serveur. 

**Remarque** : Cette fonction est utilisable uniquement avec un champ Upload multifichier. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// -- Code de clic navigateur du champ Bouton "BTN_Supprimer"
nFichier est un entier = ListeSelect(LISTE_UploadMulti)
SI nFichier <> -1 ALORS
	UploadSupprime(UPL_UploadMulti, nFichier)
	// Il est inutile de mettre à jour la liste des fichiers à uploader
	// le code de modification du champ Upload le fera automatiquement
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`UploadSupprime(<Champ Upload> , <Indice du fichier>)`
---

**`<Champ Upload> : (Nom de champ)`**

Nom du champ Upload multifichier manipulé. 

**`<Indice du fichier> : (Entier)`**

Indice du fichier à supprimer de la liste des fichiers à uploader (1 pour le premier fichier de la liste, 2 pour le second, etc.). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Taille maximale des fichiers à uploader
<a name="taille_maximale_des_fichiers_uploader_ELTPARAGRAPHE000173"></a>**Par défaut,** la taille des fichiers à uploader est illimitée dans le moteur WEBDEV. Cette taille peut être limitée par le serveur d'application WEBDEV. 
Si le fichier à uploader dépasse la taille limite, le fichier n'est pas uploadé.
Pour modifier la taille maximale des fichiers à uploader dans le serveur d'application WEBDEV, il est nécessaire de modifier la base de registre sur le serveur :  

1. Pour modifier la taille des fichiers uploadés pour toutes les applications WEBDEV 2026, sélectionnez la clé suivante : 

	- sur une machine 32 bits : HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0  

	- sur une machine 64 bits : HKEY_LOCAL_MACHINE\\SOFTWARE\\WOW6432Node\\PC SOFT\\WEBDEV\\31.0




2. Ajoutez la chaîne MAX_UPLOAD. Cette chaîne aura pour valeur la taille maximale des fichiers à uploader (en Ko).
