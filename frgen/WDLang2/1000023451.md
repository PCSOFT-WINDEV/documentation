


## &lt;Zone répétée&gt;.Affiche (Fonction)

***En anglais : &lt;Looper&gt;.Display***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Réactualise l'affichage d'un champ Zone répétée liée aux données à partir d'une position donnée: les modifications effectuées sur la table liée sont répercutées dans le champ Zone répétée.

**Remarque**: La fonction **&lt;Zone répétée&gt;.Affiche** peut être utilisée indifféremment sur un champ Zone répétée liée aux données ou mémoire.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) La page contenant le champ Zone répétée est réactualisée.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Rafraîchissement du champ Zone répétée "ZR_ZoneProduit" à partir du début du champ
ZR_ZoneProduit.Affiche(taDébut)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Zone répétée>.Affiche([<Position>])`
---

**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à rafraîchir.

**`<Position> : (Entier, caractère ou constante (optionnel))`**

Indique la position de départ du rafraîchissement. Si ce paramètre n'est pas spécifié, les éléments du champ Zone répétée sont ré-affichés à partir de l'élément en cours dans le champ Zone répétée.

Ce paramètre peut correspondre à:

- Un entier. Le rafraîchissement est effectué à partir de cette position. La répétition sélectionnée n'est pas modifiée. L'événement "Affichage" de la répétition &lt;Position&gt; est exécuté. L'élément en cours dans le champ Zone répétée est le même que l'enregistrement en cours dans la table. Si cet entier est invalide (en dehors des bornes autorisées), l'appel de la fonction **&lt;Zone répétée&gt;.Affiche** provoque une erreur.

- Un caractère ou une constante:
