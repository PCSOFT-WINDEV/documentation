


## ZoneRépétéeModifieLigne (Fonction)

***En anglais : LooperModifyLine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Pour les champs Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés. Pour plus de détails, consultez le paragraphe [Modifier un champ Zone répétée sans attributs](#NOTE0_4).








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modification d'une ligne dans un champ Zone répétée
ZoneRépétéeModifieLigne(ZR_Zone1, Indice, NomProduit, CodeProduit)
```
<a name="Exemple2"></a>

```wl
// Modifie une valeur dans un champ Zone répétée en 12ème position
ZoneRépétéeModifieLigne(ZR_Zone1, 12, Nom, Prénom, NumTel, NumFax)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`ZoneRépétéeModifieLigne(<Champ Zone répétée> [, <Indice> [, <Valeur 1> [, <Valeur N>]]])`
---

**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à manipuler.
Si ce paramètre est égal à chaîne vide (""), la modification sera effectuée sur le champ Zone répétée en cours.

**`<Indice> : (Entier optionnel)`**

Indice de la répétition à modifier.

- Si ce paramètre n'est pas précisé, la modification sera effectuée sur l'élément en cours.

- Si &lt;Indice&gt; est supérieur au nombre de répétitions, une erreur WLangage est affichée.




**`<Valeur 1> : (Type de l'attribut associé (optionnel))`**

Valeur du 1er attribut de la ligne à modifier dans le champ Zone répétée spécifié.
Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
Si aucun de ces paramètres n'est spécifié, la fonction **ZoneRépétéeModifieLigne** affecte chaîne vide ("") ou 0.

**`<Valeur N> : (Type de l'attribut associé (optionnel))`**

Valeur du Nème attribut de la ligne à modifier dans le champ Zone répétée spécifié.
Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
Si aucun des ces paramètres n'est spécifié, la fonction **ZoneRépétéeModifieLigne** affecte chaîne vide ("") ou 0.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000123"></a>La fonction **ZoneRépétéeModifieLigne** peut être utilisée indifféremment sur : 

- un champ Zone répétée fichier,

- un champ Zone répétée par programmation. 


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur. ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) La fonction **ZoneRépétéeModifieLigne** peut être utilisée uniquement sur un champ Zone répétée mémoire.
<a name="NOTE0_2"></a>


### Caractéristiques de la répétition
<a name="caracteristiques_repetition_ELTPARAGRAPHE000138"></a>Si une valeur correspond au résultat d'un calcul, mettez l'expression numérique entre parenthèses. Par exemple :

```wl
ZoneRépétéeModifieLigne(ZR_ZoneCalcul, 5, (53+29), (83-21))
```

<a name="NOTE0_3"></a>


### Tri
<a name="tri_ELTPARAGRAPHE000153"></a>Si la fonction **ZoneRépétéeModifieLigne** modifie un attribut de tri du champ Zone répétée en cours, le tri sur cet attribut sera annulé.
<a name="NOTE0_4"></a>


### Modifier un champ Zone répétée sans attributs
<a name="modifier_champ_zone_repetee_sans_attributs_ELTPARAGRAPHE000165"></a>Pour modifier un champ Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés.

Par exemple :

```wl
// Modification de la valeur des champs
// du champ Zone répétée "ZR_Zone1" pour la répétition 23
ZR_Zone1[23].ChampNom = "Hobbes"
ZR_Zone1[23].ChampPrénom = "Samantha"
```
