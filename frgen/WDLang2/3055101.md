## Présentation
<a name="presentation_ELTTEXTE000100"></a>
La technologie AJAX est disponible nativement dans WEBDEV et dans les sites PHP développés avec WEBDEV.

**Que signifie AJAX et quel est son intérêt ?**

AJAX (pour Asynchronous Javascript and XML) permet de rafraîchir uniquement les données modifiées dans une page HTML sans réafficher la totalité de la page. 

Par exemple, si certains éléments présents dans une page affichée (le contenu du panier, les caractéristiques d'un produit, une liste de villes, une carte géographique, etc.) doivent être modifiés, seuls ces éléments seront rafraîchis. Le serveur n'aura pas à envoyer la page entière sur le poste de l'internaute.

Cette technologie a de multiples avantages :

- le serveur est moins sollicité. Il peut alors supporter un plus grand nombre de connexions simultanées.

- les informations qui circulent sont de taille réduite.

- la durée de transmission est plus courte.

- l'affichage pour l'internaute est immédiat et sans effet visuel.




Il existe plusieurs possibilités pour faire des requêtes AJAX dans un site WEBDEV :

- [En automatique](../WDLang2/3055102.md) : Il suffit que AJAX soit activé dans l'événement WLangage. Le code reste le même.

- [Par programmation (par compatibilité)](../WDLang2/3055103.md) : Les fonctions [AJAXExécute](../WDLang2/3055114.md) et [AJAXExécuteAsynchrone](../WDLang2/3055115.md) permettent de réaliser des traitements complexes.

- [Par appel direct de procédures serveur depuis le code navigateur](../WDLang2/3055119.md). Si une procédure serveur est appelée depuis un code navigateur, WEBDEV fait automatiquement une requête AJAX pour exécuter le code. Cette requête peut être synchrone ou asynchrone. 




**Remarques** :
La fonction [AJAXDisponible](../WDLang2/3055112.md) permet de savoir si le navigateur en cours supporte la technologie AJAX. Si un traitement utilisant la technologie AJAX est exécuté sur un navigateur ne supportant pas cette technologie, le traitement s'exécute "comme si" il n'utilisait pas la technologie AJAX (rafraîchissement de la page entière par exemple).
