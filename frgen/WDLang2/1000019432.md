


## ImageDernier (Fonction)

***En anglais : ImageLast***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche la dernière image du défilement.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche la dernière bannière
ImageDernier(IMG_Bannière)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ImageDernier(<Champ Image>)`
---

**`<Champ Image> : (Nom de champ)`**

Nom du champ à manipuler :

- Champ Image.

- Champ Image cliquable.

- Champ Vignette.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion des effets de transition
<a name="gestion_des_effets_transition_ELTPARAGRAPHE000048"></a>Si des effets de transition ont été spécifiés lors de la description du champ : 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Ces effets de transition sont pris en compte lors de l'utilisation de la fonction **ImageDernier**. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Ces effets de transition ne sont pas pris en compte lors de l'utilisation de la fonction **ImageDernier**. En effet, la page est totalement rafraîchie. Pour prendre en compte ces effets, il suffit d'utiliser un code en mode Ajax.
