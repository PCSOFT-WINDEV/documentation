
## 11. Les champs Table / Zone répétée
			

| [Page précédente](../Concepts_WD/1410087059.md) | [Sommaire](../Concepts_WD/1410087098.md) | [Page suivante](../Concepts_WD/1410087061.md) |

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les champs Table/Zone répétée peuvent être utilisés pour afficher un ensemble d'informations (par exemple, le contenu d'une table). Le contenu de ces champs peut être issu de trois sources différentes:

- Champs Table/Zone répétée liée aux données "accès direct",

- Champs Table/Zone répétée "par programmation",

- Champs Table/Zone répétée liée aux données "chargée en mémoire".




**Remarque**: Ces trois modes de remplissage vont être détaillés dans cette page pour le champ Table. Les mêmes concepts s'appliquent au champ Zone répétée.
<a name="NOTE1_2"></a>


### Champ Table liée aux données "accès direct"
<a name="champ_table_liee_aux_donnees_acces_direct_ELTPARAGRAPHE000023"></a>

Un champ table liée aux données de type "accès direct" permet d'afficher directement les données provenant d'une table ou d'une requête. La structure de la table a été décrite sous l'éditeur de schémas des données et les données ont été saisies par exemple dans l'application. 

Un parcours de la table permet d'afficher les données dans le champ Table. Pour chaque ligne affichée, la table est lue: l'enregistrement lu est affiché dans une ligne du champ Table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P66-Les%20champs%20Table%20Zone%20R%E9p%E9t%E9e.gif)
Les données affichées non liées à la table ne sont pas conservées lors des rafraîchissements d'affichage du champ Table (en cas de scrolling par exemple).

Il est possible de limiter les enregistrements affichés dans le champ en utilisant un filtre (fonction [HFiltre](../WDLang4/3044100.md) utilisée dans le code d'initialisation du champ).

Plusieurs fonctions du WLangage permettent de manipuler les champs Table liée aux données. Ces fonctions commencent toutes par "Table".

***Pour ajouter un enregistrement dans le champ Table***, ajoutez l'enregistrement dans la table HFSQL correspondante (fonction [HAjoute](../WDLang4/3044147.md)), puis ré-affichez le champ Table avec la fonction [TableAffiche](../WDLang1/3074003.md).

***Pour supprimer un enregistrement dans le champ Table***, supprimez l'enregistrement dans la table HFSQL correspondante (fonction [HSupprime](../WDLang4/3044018.md)), puis ré-affichez le champ Table avec la fonction [TableAffiche](../WDLang1/3074003.md).
<a name="NOTE1_3"></a>


### Champ Table "par programmation"
<a name="champ_table_par_programmation_ELTPARAGRAPHE000059"></a>

Un champ Table par programmation permet d'afficher directement des données chargées en mémoire. Les données sont ajoutées dans le champ Table par programmation, via différentes fonctions WLangage (par exemple avec la fonction [TableAjouteLigne](../WDLang1/3074006.md)). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P66-Les%20champs%20Table%20Zone%20R%E9p%E9t%E9e-2.gif)
Les données étant présentes en mémoire, le champ Table permet toutes les manipulations sur les données (tri sur n'importe quelle colonne, recherche dans les colonnes, ...).
<a name="NOTE1_4"></a>


### Champ Table liée aux données "chargé en mémoire"
<a name="champ_table_liee_aux_donnees_charge_memoire_ELTPARAGRAPHE000073"></a>

Les champs table liée aux données de type "chargé en mémoire" combinent les avantages des champs table liée aux données de type "accès direct" et ceux des champs table par programmation.

Le champ Table est lié à la table, mais le contenu de la table est totalement chargé en mémoire. Le tri et la recherche sont disponibles sur toutes les colonnes.

Les données non liées à la table sont conservées lors de la manipulation de l'ascenseur (colonne de type Interrupteur par exemple).

Les enregistrements de la table étant chargés en mémoire, ce type de champ est conseillé pour les tables de moins de 100 000 enregistrements (pour éviter une saturation mémoire). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P66-Les%20champs%20Table%20Zone%20R%E9p%E9t%E9e-3.gif)
**Remarque**: Les différents modes de remplissage (par programmation, fichier accès direct et fichier chargé en mémoire) sont disponibles pour les champs Liste, Combo, Table, Zone répétée, etc.
