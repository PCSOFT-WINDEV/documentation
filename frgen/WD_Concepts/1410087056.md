
## 7. HFSQL: les fichiers créés physiquement

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
L'Éditeur de schémas des données permet de décrire la structure des tables.

Selon les informations saisies sous l'éditeur de schémas des données, différents fichiers sont créés physiquement.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=creation_fichier_HFSQL.svg)
**Remarque**: Ce schéma présente uniquement les principaux fichiers créés. D'autres fichiers spécifiques peuvent être créés si la table utilise la journalisation, les transactions ou encore la réplication.
