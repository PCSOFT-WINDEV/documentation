
## 1. Schéma des données : structure de la base de données

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Lorsqu'un projet WINDEV, WEBDEV ou WINDEV Mobile utilise des tables, ce projet doit être associé à un schéma des données. Un schéma des données permet de décrire les structures de données (tables, rubriques, etc.) utilisées dans votre projet.

L'éditeur de schémas des données permet de créer très simplement un schéma des données.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P47-Analyse%20Structure%20de%20la%20base%20de%20donn%E9es.svg)


Le schéma des données d'un projet WINDEV, WEBDEV ou WINDEV Mobile correspond au MLD (Modèle Logique des données). Toute la structure et l'organisation des données sont décrites : les données sont regroupées par table (appelée table). Chaque table contient plusieurs données appelées rubrique.

Dans le schéma des données, il est possible de lier la description d'une table à un type de fichier (HFSQL Classic, HFSQL Client/Serveur, SQLite, etc.).
