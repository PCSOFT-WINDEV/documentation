


## WDHFDiff - Utilisation
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000162"></a>
WDHFDiff permet de comparer:

- la structure de deux tables HFSQL.

- les données de deux tables HFSQL.

- les tables communes présentes dans deux répertoires différents.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comparaison de deux tables HFSQL
<a name="comparaison_deux_tables_hfsql_ELTTEXTE000186"></a>


### Comparer la structure de deux tables HFSQL
<a name="comparer_structure_deux_tables_hfsql_ELTPARAGRAPHE000022"></a>

Pour comparer la structure de deux tables HFSQL:

1. Sous le volet "Outils", dans le groupe "Base de données", cliquez sur "WDHFDiff".

2. Cliquez sur le bouton "Comparer 2 fichiers".

3. Sélectionnez les deux tables à comparer.

4. Saisissez si nécessaire les mots de passe des tables à comparer.

5. Cliquez sur le bouton "Comparer la structure". Les différences trouvées sont automatiquement listées:

	- différences au niveau des propriétés WLangage des tables comparées.

	- liste des rubriques présentes dans la première table, dans la seconde table et communes aux deux tables.

	- différences au niveau des propriétés WLangage des rubriques des tables comparés.






<a name="NOTE2_2"></a>


### Comparer les données de deux tables HFSQL
<a name="comparer_les_donnees_deux_tables_hfsql_ELTPARAGRAPHE000051"></a>

Pour comparer les données de deux tables HFSQL:

1. Sous le volet "Outils", dans le groupe "Base de données", cliquez sur "WDHFDiff".

2. Comparez la structure des deux tables. Pour plus de détails, consultez le paragraphe ci-dessus.

3. Cliquez sur le bouton "Comparer les données".

4. Sélectionnez le type de comparaison à réaliser:

	- comparaison par numéro d'enregistrement. Les enregistrements présents dans les tables seront comparés selon leur identifiant.

	- comparaison par clé unique. Les enregistrements présents dans les tables seront comparés selon la ou les clés uniques communes des deux tables.
			Remarque: Dans ce type de comparaison, les enregistrements rayés et/ou supprimés ne seront pas comparés.




5. Sélectionnez les différentes rubriques à comparer.
	Rappel: Le bouton "Tous" permet de sélectionner toutes les rubriques disponibles. Le bouton "Aucun" permet de déselectionner les rubriques sélectionnées.

6. Cliquez sur le bouton "OK". Les différences trouvées sont automatiquement listées.

7. Double-cliquez sur une différence pour connaître ses caractéristiques.

## Comparaison des tables communes de deux répertoires
<a name="comparaison_des_tables_communes_deux_repertoires_ELTTEXTE000216"></a>
Pour comparer les tables communes à deux répertoires différents:

1. Sous le volet "Outils", dans le groupe "Base de données", cliquez sur "WDHFDiff".

2. Cliquez sur le bouton "Comparer 2 répertoires".

3. Sélectionnez les deux répertoires à comparer.

4. Cliquez sur le bouton "Scanner". Les tables communes aux deux répertoires sélectionnés sont automatiquement listées.

5. Sélectionnez les différentes tables à comparer.
	Rappel: Le bouton "Tous" permet de sélectionner toutes les tables disponibles. Le bouton "Aucun" permet de déselectionner les tables sélectionnées.

6. Cliquez sur le bouton "Comparer". Le nombre de différences trouvées dans chaque table s'affiche automatiquement.

7. Double-cliquez sur une table pour connaître ses différences:

	- différences au niveau des propriétés WLangage des tables comparées.

	- liste des rubriques présentes dans la première table, dans la seconde table et communes aux deux tables.

	- différences au niveau des propriétés WLangage des rubriques des tables comparés.




8. Cliquez sur le bouton "Comparer les données" pour effectuer une comparaison par numéro d'enregistrement sur les tables. Les différences trouvées sont automatiquement listées.

9. Double-cliquez sur une différence pour connaître ses caractéristiques.
