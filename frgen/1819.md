## Erreur ERR_BUTTON_EXPECTED
<a name="erreur_errbuttonexpected_ELTTEXTE000085"></a>
La requête est erronée. Il y manque l'action a effectuer. ERR_BUTTON_EXPECTED.

Ce message d'erreur peut apparaître dans plusieurs cas :

- **Un lien est spécifié dans la page HTML avec la syntaxe [%URL()%] sans nom de bouton dans les paramètres:**
	Solution :
il faut obligatoirement spécifier dans les paramètres d'un lien le nom du bouton dans la page WEBDEV correspondant à l'action à effectuer.




- **Un clic a été effectué sur un bouton existant dans la page HTML uniquement. Ce bouton n'existe pas dans la page.**
Solution :
Il est nécessaire que les boutons présents dans la page HTML aient leur équivalent dans la page WEBDEV correspondante.




- **Une validation de formulaire est réalisée sans utiliser un bouton (utilisation de code JavaScript ou validation réalisée par le bouton ENTREE).**
	Solution :
	Il est nécessaire d'utiliser un bouton pour réaliser la validation d'un formulaire.
	Astuce :
	Pour permettre à l'internaute de valider un formulaire par la touche ENTREE, il suffit de définir un bouton de type "Validation" dans la page WEBDEV en lui associant le raccourci clavier "Entrée" (onglet "Détal" de la fenêtre de description du champ).
