## Erreur ERR_CLOSED_PAGE
<a name="erreur_errclosedpage_ELTTEXTE000063"></a>
La requête fait référence à la page &lt;NOM_PAGE&gt;, qui n'existe plus. (le traitement l'a peut-être fermée). ERR_CLOSED_PAGE

Cette erreur signifie que la page correspondant à la page HTML n'est plus disponible. Il est possible par exemple, que lors d'un traitement une procédure ait fermé la page en cours.

Vérifiez le code de votre site dynamique, notamment l'existence du contexte de la page (fonction **ContexteExiste** par exemple).
