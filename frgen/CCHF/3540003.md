


## Centre de Contrôle HFSQL : Ouvrir un schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000179"></a>
Le Centre de Contrôle HFSQL propose une gestion complète d'un schéma des données. Il donne accès à toutes les bases de données présentes dans le schéma des données : HFSQL Classic, HFSQL Client/Serveur et bases tierces.

Les caractéristiques d'un schéma des données peuvent être affichées : 

- soit directement en lançant le Centre de Contrôle HFSQL depuis un projet : 

	1. Ouvrez le projet WINDEV, WINDEV Mobile ou WEBDEV. 

	2. Sous le volet "Outils", dans le groupe "Base de données", cliquez sur "HFSQL". 

	3. La fenêtre de bienvenue du Centre de Contrôle HFSQL est affichée. L'option "Ouvrir une analyse" est sélectionnée et le chemin du schéma des données du projet en cours est spécifié. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Passage%20analyse%20en%20CS%20-%20HC%20N%B0008.gif&type=thumb)


	4. Validez. Le schéma des données est ouvert dans le Centre de Contrôle HFSQL. 

- soit directement depuis le Centre de Contrôle HFSQL : 

	1. Lancez le Centre de Contrôle HFSQL. 

	2. Dans la fenêtre de Bienvenue, cliquez sur "Ouvrir une analyse". 

	3. Indiquez le chemin du schéma des données (fichier WDD) et le mot de passe du schéma des données si nécessaire. 

	4. Validez. Le schéma des données est ouvert dans le Centre de Contrôle HFSQL.

## Caractéristiques du schéma des données
<a name="caracteristiques_schema_des_donnees_ELTTEXTE000203"></a>


### Onglet "HFSQL Classic"
<a name="onglet_hfsql_classic_ELTPARAGRAPHE000054"></a>Cet onglet présente toutes les informations concernant les tables au format HFSQL Classic présents dans le schéma des données.
Les informations affichées sont les suivantes :

- Nom logique de la table,

- Chemin complet (s'il existe),

- Taille de la table,

- Nombre d'enregistrements actifs,

- Nombre d'enregistrements supprimés,

- Nombre total d'enregistrements.





### Onglet "HFSQL C/S"
<a name="onglet_hfsql_ELTPARAGRAPHE000067"></a>Cet onglet présente toutes les informations concernant les tables au format HFSQL Client/Serveur présentes dans le schéma des données.
Les informations affichées sont les suivantes :

- Nom logique de la table,

- Serveur,

- Base de données associée,

- Taille de la table,

- Nombre d'enregistrements actifs,

- Nombre d'enregistrements supprimés,

- Nombre total d'enregistrements.





### Onglet "Base tierce"
<a name="onglet_base_tierce_ELTPARAGRAPHE000081"></a>Cet onglet présente toutes les informations concernant les tables au format non HFSQL présentes dans le schéma des données.
Les informations affichées sont les suivantes :

- Nom logique de la table,

- Type,

- Source de données,

- Nombre total d'enregistrements.





### Onglet "Liaisons"
<a name="onglet_liaisons_ELTPARAGRAPHE000092"></a>

Cet onglet présente toutes les informations concernant les liaisons entre les tables présentes dans le schéma des données.

Les informations affichées sont les suivantes :

- Nom de la liaison, 

- Nom de la table source,

- Cardinalités source, 

- Nom de la table destination,

- Cardinalités destination, 

- Règle d'intégrité de suppression, 

- Règle d'intégrité de modification. 




Remarque : La création et la modification de liaisons sont réalisées sous l'éditeur de schémas des données.

## Options du ruban
<a name="options_ruban_ELTTEXTE000245"></a>
Lors de l'ouverture d'un schéma des données dans le Centre de Contrôle HFSQL, le ruban propose les options suivantes : 

- Dans le groupe "Gestion des fichiers" : 

	- **Synchronisation des fichiers** : Cette option permet de lancer la modification automatique des tables afin de synchroniser les tables et leur description dans le schéma des données. Cette opération est réalisée via un assistant. 

	- **Ajouter un répertoire de déploiement** : Cette option permet de sélectionner un répertoire dans lequel les tables correspondant au schéma des données doivent être recherchées. 

	- **Gestion du .REP** : Cette option permet de lister les emplacements des tables enregistrées dans le fichier .REP lié au schéma des données. Il est possible d'ajouter, supprimer des fichiers dans le .REP. 




- Dans le groupe "Tables" : Ce groupe apparaît uniquement pour les onglets d'accès aux tables. Il permet notamment d'accéder directement aux tables. Pour les tables HFSQL, il est également possible de lancer une optimisation et une réparation des tables.
