
## Gestion des tables HFSQL Classic
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000205"></a>
Le Centre de Contrôle HFSQL propose une gestion complète des tables HFSQL Classic. 

**Pour afficher les caractéristiques d'une table HFSQL Classic** :

1. Affichez si nécessaire la fenêtre de bienvenue du Centre de Contrôle HFSQL. Cette fenêtre apparaît : 

	- au lancement du Centre de Contrôle HFSQL. 

	- en déroulant ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0003%201.gif) puis en sélectionnant "Ouvrir une table HFSQL Classic". 




2. La fenêtre de bienvenue du Centre de Contrôle s'affiche. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CC_HF_FichierHFSQLClassic%20-%20HC%20N%B0001.gif&type=thumb)


3. Indiquez : 

	- le chemin de la table HFSQL Classic à ouvrir,

	- son mot de passe (si nécessaire). Il est possible de mémoriser le mot de passe. 




4. Validez. 

5. Le Centre de Contrôle HFSQL affiche le contenu de la table sélectionnée. 

	- Les différents onglets permettent de gérer les caractéristiques de la table HFSQL Classic.

	- Le ruban propose les différentes actions possibles sur le fichier. Selon l'onglet sélectionné, les actions proposées peuvent varier.

## Détail des caractéristiques d'une table HFSQL Classic
<a name="detail_des_caracteristiques_une_table_hfsql_classic_ELTTEXTE000229"></a>


### Onglet "Description"
<a name="onglet_description_ELTPARAGRAPHE000040"></a>

Cet onglet présente toutes les informations concernant les rubriques de la table.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0001.gif&type=thumb)


Les informations affichées sont les suivantes :

- Le nom de la rubrique,

- Le type de la rubrique,

- La taille de la rubrique,

- Le type de clé,

- Les statistiques,

- Si la rubrique est visible sous le logiciel "Etats & Requêtes".




Si nécessaire, des informations complémentaires sont affichées.

Remarque : Par défaut, les rubriques sont affichées dans l'ordre logique. il est possible d'utiliser l'ordre alphabétique si nécessaire via les options du Centre de Contrôle HFSQL : 

1. Déroulez le menu du Centre de Contrôle HFSQL (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CC_Suivi_Configuration%20-%20HC%20N%B0001.gif)). 

2. Sélectionnez "Options".

3. Dans la fenêtre qui s'affiche, indiquez "alphabétique" pour l'option "Ordre d'affichage des rubriques". 



<a name="NOTE2_2"></a>


### Onglet "Propriétés"
<a name="onglet_proprietes_ELTPARAGRAPHE000080"></a>L'onglet "Propriétés" affiche les propriétés de la table (nom physique, format, protection, etc.).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0002.gif&type=thumb)

<a name="NOTE2_3"></a>


### Onglet "Contenu"
<a name="onglet_contenu_ELTPARAGRAPHE000088"></a>

Cet onglet permet de visualiser les différents enregistrements de la table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0003.gif&type=thumb)


Il est également possible de filtrer les enregistrements affichés via la barre présente au-dessus des données. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0004.gif&type=thumb)
Le menu contextuel du filtre (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007%201.gif)) propose plusieurs options : 

- Application automatique : le filtre est automatiquement exécuté lors de sa validation avec la touche Entrée du clavier. Si cette option n'est pas sélectionnée, la validation doit être effectuée en cliquant sur la coche verte en fin de ligne. 

- Supprimer le filtre en cours : Permet de vider le champ du filtre. 

- Copier le code SQL : Permet de copier dans le presse-papiers le code SQL correspondant au filtre saisi. 

- Créer une requête : Permet d'afficher le volet "Requête" avec le code SQL de la requête saisie (équivalent à l'option "Nouvelle requête" du ruban). Pour plus de détails, consultez [Créer et exécuter une requête](../CCHF/35400019.md). 

- Vider l'historique des filtres : Les filtres créés sont automatiquement mémorisés pour pouvoir être rapidement ré-appliqués. Il est possible de supprimer tous les filtres mémorisés. 




Le menu contextuel des enregistrements permet de manipuler l'enregistrement sélectionné : suppression, ajout, mode d'affichage des mémos texte, etc.

Il est également possible de :

- Supprimer un enregistrement : sélectionnez l'enregistrement et cliquez sur le bouton "Supprimer" (ou appuyez sur la touche Suppr).

- Modifier ou ajouter un enregistrement : la saisie se fait directement dans la liste des enregistrements. Il suffit de se positionner sur la première ligne vide et de saisir les informations de l'enregistrement. La modification de la table est faite automatiquement.



<a name="NOTE2_6"></a>


### Onglet "Journaux"
<a name="onglet_journaux_ELTPARAGRAPHE000120"></a>

Cet onglet permet de visualiser le contenu des journaux, d'effectuer une recherche dans les journaux.

Il est nécessaire que la table soit journalée.
<a name="NOTE2_7"></a>


### Onglet "Transactions"
<a name="onglet_transactions_ELTPARAGRAPHE000129"></a>

Cet onglet permet de libérer un enregistrement ou toutes les transactions.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0005.gif&type=thumb)

## Options proposées par le ruban
<a name="options_proposees_par_ruban_ELTTEXTE000277"></a>
Pour la table HFSQL Classic sélectionnée, le ruban propose les actions suivantes : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0001%201.gif)


- Dans le groupe "Requête SQL" : 

	- Nouvelle requête : Cette option permet d'ouvrir un onglet spécifique permettant de réaliser une requête sur la table en cours.  

	- Ouvrir une requête : Cette option permet d'ouvrir un onglet spécifique correspondant à une requête précédemment réalisée. 


 Pour plus de détails, consultez [Créer et exécuter une requête](../CCHF/35400019.md). 

- Dans le groupe "Table" :

	- Optimiser et réparer : Cette option permet d'afficher la fenêtre de configuration de l'optimisation et de la réparation des tables HFSQL. Pour plus de détails, consultez [Optimiser et réparer des tables](../CCHF/3540007.md). 

	- Fermer la table : Cette option permet de fermer la table et l'onglet associé.
