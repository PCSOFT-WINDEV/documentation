
## Comment faire un parcours complet d'une table ?
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000135"></a>
Deux méthodes permettent de réaliser le parcours complet d'une table :

- [Utilisation des fonctions de parcours](#NOTE2_1). 

- [Utilisation de l'instruction POUR TOUT](#NOTE3_1). 








<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Méthode 1 : Fonctions de parcours
<a name="methode_1_fonctions_parcours_ELTTEXTE000159"></a>
Cette méthode utilise les fonctions de base du WLangage pour parcourir les tables :

- [HLitPremier](../WDLang4/3044051.md),

- [HLitSuivant](../WDLang4/3044037.md).




Dans cette méthode : 

- La fonction [HLitPremier](../WDLang4/3044051.md) permet d'accéder au premier enregistrement en fonction de la clé de parcours.

- La fonction [HLitSuivant](../WDLang4/3044037.md) permet d'accéder à l'enregistrement suivant (dans l'ordre de la clé de parcours).

- La fonction [HEnDehors](../WDLang4/3044094.md) permet de savoir si la fin de la table est atteinte.




**Note** : Il est possible d'utiliser les fonctions [HLitDernier](../WDLang4/3044140.md) et [HLitPrécédent](../WDLang4/3044048.md) pour effectuer un parcours inverse.


### Exemple
<a name="exemple_ELTPARAGRAPHE000057"></a>


```wl
// Parcours de tous les enregistrements de la table client
// trié par Nom du client. 

HLitPremier(CLIENT, NomClient)
TANTQUE PAS HEndehors(CLIENT)
	// Traitement de l'enregistrement CLIENT
	HLitSuivant(CLIENT, NomClient)
FIN
```

## Méthode 2 : Instruction POUR TOUT
<a name="methode_2_instruction_pour_tout_ELTTEXTE000189"></a>
L'instruction [POUR TOUT](../Motscles/1510013.md) permet de parcourir les enregistrements d'une table. Dans notre cas, cette instruction va permettre de lire les enregistrements d'une table.

L'instruction [POUR TOUT](../Motscles/1510013.md) attend les paramètres suivants :  

- le nom de la table à parcourir.

- le nom de l'index (ou clé) pour trier les enregistrements.




Les lectures du premier enregistrement et de l'enregistrement suivant sont effectuées par l'instruction POUR TOUT. Il n'est pas nécessaire d'utiliser les fonctions HLitXXX.

**Note** : Il est possible d'utiliser le mot DESC pour effectuer un parcours inverse.


### Exemple de code
<a name="exemple_code_ELTPARAGRAPHE000086"></a>


```wl
// Parcours de tous les enregistrements de la table client 
// Parcours trié par nom croissant

POUR TOUT CLIENT SUR NomClient
	// Traitement de l'enregistrement CLIENT
FIN
```
