
## Administrateur WEBDEV distant : Sauvegarder et restaurer un site WEBDEV
			



## Gestion des sauvegardes
<a name="gestion_des_sauvegardes_ELTTEXTE000094"></a>
L'outil d'administration à distance permet de gérer les sauvegardes de vos sites WEBDEV dynamiques et de leurs données. Il est ainsi possible de :

- Récupérer une sauvegarde effectuée lors de la mise à jour à distance d'un site.

- Réaliser une sauvegarde du site (pour traiter les fichiers de données dans une application de Back Office par exemple).




La gestion des sauvegardes est réalisée depuis l'onglet "Sites" ou "Webservices" de l'administrateur distant. 


### Restauration d'une sauvegarde
<a name="restauration_une_sauvegarde_ELTPARAGRAPHE000015"></a>La récupération d'une sauvegarde consiste à rétablir le site (pages HTML, images, etc.) et les fichiers de données associés dans l'état où ils étaient lors de la dernière sauvegarde. Cette dernière sauvegarde a été effectuée lors de la mise à jour à distance du site WEBDEV (option "Ne pas détruire le backup du site après la mise à jour" cochée).

**Attention** :

- La restauration d'une sauvegarde provoque la déconnexion de tous les internautes.

- Seule la dernière sauvegarde peut être restaurée.





### Rapatrier le site et ses fichiers de données
<a name="rapatrier_site_ses_fichiers_donnees_ELTPARAGRAPHE000025"></a>Cette option permet de créer une archive de votre site. Cette archive pourra être récupérée en local. Les fichiers contenus dans cette archive pourront alors être extraits pour être traités par la suite.

**Il est par exemple possible d'utiliser une sauvegarde réalisée par l'administrateur à distance pour transférer les fichiers de données du site WEBDEV vers le siège de la société**. Ces fichiers pourront être ensuite extraits de l'archive et traités par une application de Back Office réalisée par exemple avec WINDEV.

La sauvegarde est constituée d'un ou de deux fichiers archive au format ".ZIP" :

- un fichier &lt;Nomdusite&gt;_Fic.ZIP et un fichier &lt;Nomdusite&gt;_App.ZIP si les fichiers du site et les fichiers de données sont localisés sur des répertoires différents.

- un fichier .ZIP unique si les fichiers de données sont dans un sous-répertoire du site.




Ces fichiers sont créés dans le répertoire de transfert FTP, défini pour l'installation et la mise à jour de sites à distance. Si vous ne connaissez pas les paramètres de votre compte FTP, contactez l'administrateur du serveur.

Ces fichiers archive peuvent être récupérés :

- soit par une application WINDEV ou WEBDEV utilisant les fonctions FTP.

- soit par un programme Client FTP.




Ces fichiers archive pourront être ensuite lus et décompactés grâce aux fonctions de gestion des archives de WINDEV (ou de WEBDEV).

**Attention** : La réalisation d'une sauvegarde provoque la déconnexion de tous les internautes.
