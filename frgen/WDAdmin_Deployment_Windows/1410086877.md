## Les pré-requis : serveur Web et serveur FTP (optionnel)
<a name="les_prerequis_serveur_web_serveur_ftp_optionnel_ELTTEXTE000111"></a>
Le Serveur d'Application WEBDEV a besoin d'un serveur Web. Sous Windows, le serveur Web installé par défaut est "Internet Information Serveur", appelé IIS. Ce serveur est pris en charge de façon totalement automatique, c'est la raison pour laquelle ce serveur a été choisi dans ce document. Le serveur Web Apache peut également être utilisé, mais son paramétrage ne sera pas détaillé ici.

Les installations et mises à jour à distance des sites sont effectuées par défaut via HTTP. 
Remarque : il est également possible d'effectuer des installations et mises à jour de site à distance via FTP. Dans ce cas, la présence d'un serveur FTP est nécessaire. IIS dispose également d'un serveur FTP, c'est également celui-ci qui est utilisé dans ce document.

Pour que le Serveur d'Application WEBDEV puisse gérer entièrement automatiquement IIS, il est nécessaire que IIS soit installé avec certaines options.
<a name="NOTE1_2"></a>


### IIS sous Windows 2008
<a name="iis_sous_windows_2008_ELTPARAGRAPHE000022"></a>Pour vérifier les options de IIS sous Windows 2008 :

1. Dans le menu "Démarrer" de Windows, faite un clic droit sur l'option "Ordinateur" et choisissez "Gérer".

2. Choisissez "Rôles" puis "Serveur Web (IIS)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Deploie_Win_IIS2008.gif&type=thumb)



Dans les services de rôles les options suivantes doivent être installées :

- Serveur Web, Fonctionnalités HTTP communes, Contenu statique; Document par défaut, Erreur HTTP, CGI, Console de gestion d'IIS, Compatibilité avec la métabase de données IIS 6, Journalisation HTTP, Authentification de base

- Pour les installations et mises à jour à distance : 

	- réalisées par HTTP (par défaut) : aucune option spécifique. 

	- effectuées par FTP : Serveur FTP, Console de gestion FTP.







Vous trouverez plus de détails dans l'aide en ligne de WEBDEV.
<a name="NOTE1_3"></a>


### IIS sous Windows 2012
<a name="iis_sous_windows_2012_ELTPARAGRAPHE000045"></a>Pour vérifier les options de IIS sous Windows 2012 :

1. Lancez le gestionnaire de serveur.

2. Sélectionnez le serveur IIS.

3. Faites défiler les caractéristiques affichées jusqu'à afficher les rôles et fonctionnalités. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Deploie_win_Windows2012.gif&type=thumb)





Dans les services de rôles, les options suivantes doivent être installées :

- Serveur Web, Fonctionnalités HTTP communes, Contenu statique; Document par défaut, Erreur HTTP, CGI, Console de gestion d'IIS, Compatibilité avec la métabase de données IIS 6, Journalisation HTTP, Authentification de base

- Pour les installations et mises à jour à distance : 

	- réalisées par HTTP (par défaut) : aucune option spécifique. 

	- effectuées par FTP : Serveur FTP, Console de gestion FTP.







Vous trouverez plus de détails dans l'aide en ligne de WEBDEV.
