## Les différents modules
<a name="les_differents_modules_ELTTEXTE000186"></a>


### Modules nécessaires au fonctionnement des sites WEBDEV
<a name="modules_necessaires_fonctionnement_des_sites_webdev_ELTPARAGRAPHE000019"></a>

| Nom | Fonction | Lancé par |
| --- | --- | --- |
| Gestionnaire AWP (Active Web Pages) | <br><br>- Décode les informations provenant de l'application WEBDEV.<br><br>- Transmet les informations décodées au moteur WEBDEV.<br><br><br> | Lancé par le serveur Web à chaque requête d'un internaute dans un site dynamique WEBDEV. |
| Moteur WEBDEV | <br><br>- Exécute les informations transmises par le protocole AWP.<br><br>- Construit la page HTML dynamique affichée par le serveur Web sur le navigateur de l'internaute.<br><br><br> | Lancé par WD310AWP à chaque connexion d'un internaute sur un site dynamique WEBDEV. |
| [Administrateur local](../WDAdmin/3539021.md) | Permet à l'administrateur du serveur de :<br><br>- paramétrer et de superviser les sites réalisés avec WEBDEV et installées sur le serveur.<br><br>- créer les comptes WEBDEV.<br><br>- vérifier la configuration du serveur, ...<br><br><br>Cet outil est nécessaire au fonctionnement des sites WEBDEV. | Lancé au démarrage du poste où le serveur Web est installé. Cet outil ne peut être utilisé que par l'administrateur du serveur. |


<a name="NOTE2_2"></a>


### Modules optionnels
<a name="modules_optionnels_ELTPARAGRAPHE000062"></a>

| Nom | Fonction | Lancé par |
| --- | --- | --- |
| [Administration distant (module optionnel)](../WDAdminDeploiement/3539019.md) | Permet :<br><br>- aux responsables de sites WEBDEV de gérer directement leurs différents sites WEBDEV installés sur le serveur.<br><br>- à l'administrateur du serveur de configurer à distance les différents sites WEBDEV installés sur le serveur, les comptes WEBDEV, ...<br><br><br> | Lancé par :<br><br>- soit le responsable de sites directement depuis son navigateur.<br><br>- soit l'administrateur du serveur depuis un poste différent du serveur, directement par son navigateur.<br><br><br> |
| [Gestionnaire de comptes WEBDEV (module optionnel)](../WDAdminDeploiement/3539029.md) | Permet aux hébergeurs de configurer le serveur Web hébergeant des applications WEBDEV dynamiques.<br><br>Remarque : En version 28, ce module avait pour nom "Centre de Contrôle d'Hébergement".  | Lancé par l'hébergeur directement sur le serveur Web. |
| [Robot de surveillance (Module optionnel)](../RobotMonitor/3541100.md) | Permet :<br><br>- aux responsables de sites WEBDEV d'être avertis en cas de problèmes sur le serveur (envoi d'un email).<br><br>- à l'administrateur du serveur d'être averti en cas de problème sur le serveur (envoi d'un email).<br><br><br> | Lancé par le responsable de sites :<br><br>- soit directement sur le serveur Web (cas d'un serveur dédié).<br><br>- soit en local sur un poste de développement par exemple (cas d'un serveur mutualisé).<br><br><br>Lancé par l'administrateur du serveur directement sur le serveur Web. |
| [Test en charge (module optionnel)](../WDAdminDeploiement/3539015.md) | Permet de créer un script de test directement sur le serveur. Ce script pourra ensuite être exécuté depuis différents postes. | Lancé par le responsable de sites directement sur le serveur Web pour créer un script de test de montée en charge. |
