## Problèmes courants
<a name="problemes_courants_ELTTEXTE000067"></a>
Plusieurs problèmes peuvent exister :

- Le gestionnaire de protocole AWP n'est pas correctement paramétré au niveau du serveur Web. Consultez [Configuration du serveur Web pour le protocole AWP](../Editeurs/2037005.md).

- Le gestionnaire de protocole AWP (WD310AWP.EXE) n'est pas présent dans le sous-répertoire AWP de WEBDEV. Dans ce cas, réinstallez WEBDEV.
