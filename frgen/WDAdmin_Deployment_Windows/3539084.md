
## Administrateur WEBDEV : Gestion des clusters
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000108"></a>
L'onglet "Cluster" permet de paramétrer les clusters WEBDEV liés au Serveur d'application WEBDEV. Il est possible de : 

- Ajouter ou enlever un noeud du cluster. 

- Visualiser les noeuds du cluster. 

- Obtenir un exemple de configuration du proxy.

- Connaître les erreurs de synchronisation. 




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Détail de l'onglet "Cluster"
<a name="detail_onglet_cluster_ELTTEXTE000132"></a>


### Noeuds du cluster
<a name="noeuds_cluster_ELTPARAGRAPHE000021"></a>Les différents noeuds du cluster associé au serveur d'application WEBDEV sont listés. Il est possible de : 

- Ajouter un noeud au cluster. Dans ce cas, il est nécessaire d'indiquer dans la fenêtre qui s'affiche les informations concernant le noeud à ajouter : 

	- le nom DNS du nouveau noeud. 

	- la clé de sécurité obtenue lors de l'installation du noeud. Pour plus de détails, consultez [Installation d'un Cluster WEBDEV](../WDAdminDeploiement/1410086636.md).  

	- une description du noeud (pour information). 




- Supprimer un noeud du cluster. Sélectionnez le noeud à supprimer du cluster et cliquez sur "Enlever ce noeud du cluster". 



<a name="NOTE2_2"></a>


### Configuration du proxy
<a name="configuration_proxy_ELTPARAGRAPHE000038"></a>Rappel : Un Cluster est un ensemble de serveurs qui contiennent les mêmes sites et Webservices. Pour diriger et répartir le flux vers un des serveurs (appelé noeud du cluster), il est nécessaire d'avoir un serveur frontal, dans ce cas, un serveur de type "Proxy". 

A chaque ajout d'un noeud à un cluster, ce noeud doit être rendu accessible aux utilisateurs via le serveur Proxy. 

L'administrateur WEBDEV propose un exemple de configuration pour un serveur HAProxy. La syntaxe ou la configuration exacte à effectuer dépendra de l'infrastructure choisie. Pour plus de détails, consultez [Cluster WEBDEV : Configuration du proxy](../WDAdminDeploiement/3539085.md). 

Remarque : Si une intervention est nécessaire sur un des noeud du cluster, il suffit d'enlever ce noeud temporairement ou définitivement de la déclaration du serveur proxy.  




<a name="NOTE2_3"></a>


### Erreurs récentes
<a name="erreurs_recentes_ELTPARAGRAPHE000056"></a>Dans un cluster WEBDEV, les noeuds se synchronisent automatiquement entre eux. Les noeuds synchronisent périodiquement la configuration du Serveur d'application WEBDEV, ainsi que la configuration et le contenu des sites et des Webservices déployés. 

En cas d'erreur de synchronisation, un log est automatiquement créé et peut être consulté.
