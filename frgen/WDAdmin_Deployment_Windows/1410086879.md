
## Installation du Serveur d'application WEBDEV (Windows)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
**Attention** : L'installation doit être lancée en tant qu'administrateur du poste après avoir vérifié les pré-requis. Le numéro de série et la clé d'installation sont nécessaires.
Dans cet exemple, nous réalisons une installation complète dans le répertoire : "C:\\WEBDEV2026\\" avec l'option d'hébergement de sites en versions antérieures.
N'oubliez pas de cocher l'option permettant l'installation de l'administrateur en tant que service. Dans le cas contraire, il ne sera pas possible de se connecter aux sites WEBDEV sans session ouverte sur le serveur.

**Les différentes étapes de l'installation sont les suivantes** : 

1. Choisissez la langue d'exécution de l'installation. 

2. Sélectionnez le type de version à installer : version complète ou version 10 connexions. Dans notre cas, nous installons une version complète. Saisissez le numéro de série et la clé d'installation. 

3. Validez la licence. 

4. Indiquez le répertoire d'installation du serveur d'application WEBDEV (C:\\WEBDEV 2026 par défaut). 

5. Sélectionnez le mode de fonctionnement du serveur : "Serveur autonome". 

6. Indiquez le répertoire à utiliser pour le déploiement ("C:\\Sites" par défaut). 

7. Indiquez le ou les sites d'administration à distance à installer : 

	- Le site d'installation à distance du serveur d'application WEBDEV permet d'administrer à distance tous les sites et webservices déployés, les comptes WEBDEV ainsi que la configuration du serveur d'application. 

	- Le site d'administration HFSQL permet d'administrer à distance les bases de données HFSQL. 




8. Indiquez si **l'hébergement de sites SaaS doit être pris en compte**. Si l'option "Activer la gestion de SaaS" est sélectionné, un site et un webservice pour la gestion SaaS seront installé sur le serveur d'application WEBDEV.  

9. Indiquez si **le serveur de réplication doit être installé**. Le serveur de réplication peut être utilisé pour réaliser une réplication universelle assistée. 

10. Indiquez si le **serveur de télémétrie** des application (WDAnalytices) doit être activé. 

11. Dans le cas de l'installation du serveur de télémétrie : 

	1. Spécifiez les caractéristiques du serveur HFSQL utilisé pour la télémétrie (installé précédemment) : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Install_serveur_telemetrie%20-%20HC%20N%B0003.gif&type=thumb)


		- Nom du serveur HFSQL, 

- Port. 

- Nom et mot de passe de l'administrateur du Serveur HFSQL. Ces informations sont nécessaires pour configurer automatiquement la base de données de la télémétrie et l'utilisateur associé. 

2. Testez la connexion pour vérifier vos paramètres. 

3. Indiquez les paramètres spécifiques à la base de données utilisée par la télémétrie : 

	- le nom de la base de données dédiée à la télémétrie (TLM par défaut). 

	- le nom de l'utilisateur administrateur de la télémétrie et son mot de passe. 

12. Indiquez si les **services BaaS** doivent être activés. Ces services permettent d'utiliser le groupware utilisateur, un serveur d'authentification OAuth et un Store Privé. 

13. Dans le cas de l'installation des services BaaS :

	1. Spécifiez les caractéristiques du serveur HFSQL utilisé pour les modules WDBaaS (groupware utilisateur/Store Privé). 
			Remarque : Ce serveur HFSQL a été installé précédemment. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Install_serveur_store%20-%20HC%20N%B0003.gif)
Ces caractéristiques sont les suivantes : 

		- Nom du serveur HFSQL, 

		- Port. 

		- Nom et mot de passe de l'administrateur du Serveur HFSQL. Ces informations sont nécessaires pour configurer automatiquement la base de données WDBaaS et l'utilisateur associé. 




2. Testez la connexion pour vérifier vos paramètres. 

3. Indiquez les paramètres spécifiques à la base de données WDBaaS utilisée par le groupware utilisateur/Store Privé : 

	- le nom de la base de données dédiée : WDBAAS par défaut. 

	- le nom de l'utilisateur de cette base et son mot de passe. 

14. Passez à l'étape suivante.

15. Indiquez si **l'accès aux bases tierces** doit être activé. Si cet accès est activé, le serveur d'application intègre un webservice spécifique. Dans ce cas, il est nécessaire de spécifier l'adresse du WebService. 

16. Spécifiez si une connexion SSL doit être utilisée pour les sites d'administration à distance. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Install_serveur_store%20-%20HC%20N%B0004.gif)


17. Passez à l'étape suivante.

18. Indiquez si les pilotes ODBC pour HFSQL doivent être installés. 

19. Spécifiez les paramètres avancés d'installation : 

	- Activer la page listant les applications. 

	- Interdire l'accès aux répertoires des autres comptes WEBDEV. 

	- Activer l'authentification NTLM/Kerberos. 

	- Configurer la libération des sessions inutiles. 




20. Le résumé des informations d'installation est affiché. 

21. Passez à l'étape suivante.   

22. L'assistant vérifie si un serveur Web est présent sur le poste d'installation. 

	- Si aucun serveur Web n'est installé sur le poste d'installation, l'assistant propose d'en installer un et de le configurer. 

	- Si un serveur Web est présent sur le poste d'installation, l'assistant le configure pour utiliser le serveur d'application WEBDEV. 




23. A la fin de l'installation, l'assistant affiche un récapitulatif. 




**Une fois le Serveur d'Application WEBDEV installé**, il est possible de retrouver à tout moment le serveur Web pour lequel il est paramétré, et les sites virtuels dans lesquels il est configuré.
Pour cela il suffit de :

1. Lancer l'interface de l'administrateur WEBDEV.

2. Sélectionner l'onglet "Avancé" et cliquer sur le bouton "Serveur".

3. Choisir le serveur dans la liste.

4. Cliquer sur le bouton "Serveurs virtuels".
	Dans la table qui s'affiche, il suffit de cocher les serveurs virtuels dans lesquels vous désirez que le serveur d'application WEBDEV soit configuré : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Install_Serveur_appli%20-%20HC%20N%B0001.gif&type=thumb)



Il sera alors possible de faire fonctionner un ou plusieurs sites WEBDEV dynamiques (en mode Session ou en mode AWP) dans chacun des serveurs virtuels dans lequel le serveur d'application est configuré.

**Important pour la sécurité** :
Dès que le Serveur d'Application WEBDEV est installé, pensez à changer le mot de passe du compte WEBDEV par défaut (compte ADMIN). Pour cela :

1. Lancez l'administrateur WEBDEV.

2. Dans l'onglet "Installations/comptes", cliquez sur le bouton "Comptes".

3. Double-cliquez sur la ligne "ADMIN".

4. Dans l'onglet "Général", cliquez sur le bouton "Mot de passe".

5. Modifiez le mot de passe et validez.
