## Présentation
<a name="presentation_ELTTEXTE000166"></a>
Cette page regroupe les principaux termes spécifiques à WEBDEV utilisés dans la documentation du serveur d'application WEBDEV. Sauf mention contraire, tous les textes se référant aux sites sont également applicables aux Webservices.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Vocabulaire
<a name="vocabulaire_ELTTEXTE000190"></a>


### Administrateur du serveur
<a name="administrateur_serveur_ELTPARAGRAPHE000019"></a>Personne responsable de l'installation de logiciels, sites, ... sur un ou plusieurs postes serveurs chez l'hébergeur. Dans le cas d'un serveur mutualisé, l'administrateur du serveur est responsable de la répartition des connexions par responsable de sites, responsable de la localisation physique des sites sur le serveur, ...
<a name="NOTE2_2"></a>


### Administrateur WEBDEV Distant
<a name="administrateur_webdev_distant_ELTPARAGRAPHE000028"></a>Site installé sur le serveur Web, permettant :

- au responsable de site de vérifier / modifier à distance la configuration de ses sites WEBDEV installés sur un serveur.

- à l'administrateur du serveur de vérifier / modifier à distance la configuration de tous les sites WEBDEV installés sur le serveur. L'administrateur du serveur peut aussi gérer les comptes WEBDEV.



<a name="NOTE2_3"></a>


### Administrateur WEBDEV
<a name="administrateur_webdev_ELTPARAGRAPHE000040"></a>Application Windows installée sur le serveur permettant à l'administrateur du serveur de paramétrer les différents sites WEBDEV installés sur le serveur en cours.

L'administrateur WEBDEV local permet aussi de créer les comptes WEBDEV.
<a name="NOTE2_4"></a>


### Compte WEBDEV
<a name="compte_webdev_ELTPARAGRAPHE000051"></a>Compte associé à un responsable de sites. 

Ce compte permet à l'administrateur du serveur :

- de regrouper les sites d'un responsable de sites.

- de paramétrer le nombre de connexions autorisées pour un responsable de sites.

- de paramétrer les répertoires d'installation des sites

- de paramétrer le répertoire de transfert des fichiers (pour une installation ou des mises à jour par FTP).




Ce compte permet au responsable de sites :

- d'utiliser l'administrateur à distance.

- de faire des installations et des mises à jour de sites à distance.




Ce compte est créé sur un serveur Web par l'administrateur du serveur à l'aide :

- soit de l'administrateur local.

- soit de l'administrateur à distance.



<a name="NOTE2_5"></a>


### Développeur de sites
<a name="developpeur_sites_ELTPARAGRAPHE000077"></a>Personne qui crée et modifie des sites WEBDEV avec WEBDEV version Développement.
<a name="NOTE2_6"></a>


### Gestionnaire de comptes WEBDEV (WDCompte)
<a name="gestionnaire_comptes_webdev_wdcompte_ELTPARAGRAPHE000086"></a>Application Windows permettant de créer des comptes WEBDEV. Cette application est lancée par l'administrateur du serveur, sur un serveur Web. Cette application permet uniquement de créer des comptes pour le poste en cours.

Remarque : L'administrateur du serveur peut aussi gérer les comptes WEBDEV à distance grâce à l'outil d'administration à distance.
<a name="NOTE2_7"></a>


### Hébergeur
<a name="hebergeur_ELTPARAGRAPHE000097"></a>Société proposant d'héberger des sites Internet sur des serveurs Web.
<a name="NOTE2_8"></a>


### Internaute
<a name="internaute_ELTPARAGRAPHE000106"></a>Utilisateur de sites Internet.
<a name="NOTE2_9"></a>


### Responsable de sites
<a name="responsable_sites_ELTPARAGRAPHE000115"></a>Personne responsable du déploiement et de la maintenance d'un ou de plusieurs sites WEBDEV. Cette personne est directement en contact avec l'administrateur du serveur.
