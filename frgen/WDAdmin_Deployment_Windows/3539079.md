## Configuration du serveur Web IIS version 7 à 10 pour WEBDEV
<a name="configuration_serveur_web_iis_version_7_10_pour_webdev_ELTTEXTE000085"></a>


### Configuration du serveur pour le protocole CGI (AWP)
<a name="configuration_serveur_pour_protocole_cgi_awp_ELTPARAGRAPHE000009"></a>

1. Ouvrez le gestionnaire de service Internet Microsoft (Option "Démarrer .. Exécuter .. Inetmgr.exe" depuis le bureau de Windows).

2. Sélectionnez le serveur Web dans lequel l'alias doit être ajouté.

3. Ajoutez un nouveau répertoire virtuel (par exemple via le menu contextuel).

4. Indiquez :

	- l'alias du protocole AWP : WD310AWP.

	- le répertoire du protocole AWP (sous-répertoire "Programs\\AWP" du répertoire d'installation de WEBDEV).




5. Donnez les permissions suivantes : Lire - Exécuter

## Configuration du serveur pour les sites WEBDEV et les Webservices SOAP
<a name="configuration_serveur_pour_les_sites_webdev_les_webservices_soap_ELTTEXTE000109"></a>


1. Ouvrez le gestionnaire de service Internet Microsoft (Option "Démarrer .. Exécuter .. Inetmgr.exe" depuis le bureau de Windows).

2. Sélectionnez le serveur Web dans lequel l'alias doit être ajouté.

3. Ajoutez un nouveau répertoire virtuel (par exemple via le menu contextuel).

4. Indiquez :

	- l'alias du répertoire contenant les images de votre projet : &lt;MonProjet&gt;_WEB. Par exemple MARKET_WEB.

	- le répertoire contenant les images de votre projet : &lt;Nom Projet&gt;_WEB. Par exemple : C:\\WWprojet\\MARKET\\MARKET_WEB.




5. Donnez les permissions suivantes : Lire - Scripts
