
## Erreurs en cas d'installation par FTP
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
La liste ci-dessous présente les différents messages d'erreur apparaissant dans l'assistant d'installation à distance (chez le responsable de sites). Certains de ces messages nécessitent des actions spécifiques de configuration au niveau du serveur Web de déploiement.

Pour chaque erreur, diverses solutions sont proposées.

Des messages d'erreur peuvent apparaître à diverses étapes de l'installation à distance.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Etape 1 : Saisie des logins et mot de passe Serveur et FTP (Installation du site)
<a name="etape_1_saisie_des_logins_mot_passe_serveur_ftp_installation_site_ELTTEXTE000547"></a>
L'assistant d'installation effectue une vérification de la validité des logins et mots de passe. Voici la liste des erreurs pouvant apparaître.
<a name="NOTE2_2"></a>


### La vérification du mot de passe utilisateur a échoué : le serveur n'a pas retourné d'information.
<a name="verification_mot_passe_utilisateur_echoue_serveur_pas_retourne_information_ELTPARAGRAPHE000031"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le serveur Web ne fonctionne pas | Relancer le serveur Web sur le poste serveur. |
| Le serveur FTP ne fonctionne pas. | Relancer le serveur FTP sur le poste serveur. |
| Le serveur FTP est mal configuré : nom d'utilisateur incorrect, ... | Vérifier la configuration du serveur FTP pour l'utilisateur.<br>Attention : Si vous utilisez le serveur FTP IIS, vérifiez que :<br><br>- l'utilisateur est défini au niveau de Windows<br><br>- l'alias du répertoire de transfert FTP correspond au nom d'utilisateur Windows.<br><br><br> |
| WEBDEV Déploiement n'est pas installé correctement. | Réinstaller le serveur d'application WEBDEV. |


<a name="NOTE2_3"></a>


### Le mot de passe FTP n'est pas correct ou le serveur FTP n'est pas joignable.
<a name="mot_passe_ftp_nest_pas_correct_serveur_ftp_nest_pas_joignable_ELTPARAGRAPHE000066"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le mot de passe FTP indiqué par le responsable de sites n'est pas correct. | Vérifier le mot de passe FTP et communiquer ce mot de passe au responsable de site. |
| Le serveur FTP ne fonctionne pas. | Relancer le serveur FTP. |
| Le nombre de connexions autorisées sur le serveur FTP est dépassé. | Le responsable de site doit attendre qu'une connexion au serveur FTP soit libérée. |
| L'adresse du serveur Web est incorrecte. | Indiquer au responsable de sites l'adresse exacte du serveur Web où l'installation du site doit être effectuée par FTP. |


<a name="NOTE2_4"></a>


### La vérification du mot de passe utilisateur a échoué : l'utilisateur est inconnu du serveur. Vérifiez l'adresse du serveur et le nom d'utilisateur
<a name="verification_mot_passe_utilisateur_echoue_utilisateur_est_inconnu_serveur_verifiez_adresse_serveur_nom_utilisateur_ELTPARAGRAPHE000096"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le gestionnaire de compte WEBDEV ne reconnaît pas le responsable de sites. | Vérifier qu'un compte WEBDEV a été créé dans le gestionnaire de comptes pour ce responsable de sites et communiquer le "login" correspondant au responsable de sites. |


<a name="NOTE2_5"></a>


### La vérification du mot de passe utilisateur a échoué : le serveur n'a pas retourné d'information.
<a name="verification_mot_passe_utilisateur_echoue_serveur_pas_retourne_information_ELTPARAGRAPHE000114"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le mot de passe saisit lors de l'installation à distance ne correspond pas au mot de passe défini dans le gestionnaire de comptes. | Vérifier le mot de passe associé au responsable de sites dans le gestionnaire de comptes WEBDEV et communiquer ce mot de passe au responsable de sites. |

## Etape 2 : Installation du site (installation ou mise à jour)
<a name="etape_2_installation_site_installation_mise_jour_ELTTEXTE000595"></a>
L'assistant d'installation effectue l'installation ou la mise à jour du site. Voici la liste des erreurs pouvant apparaître.
<a name="NOTE3_2"></a>


### Impossible de créer un répertoire temporaire sur le serveur. Contactez l'administrateur du serveur.
<a name="impossible_creer_repertoire_temporaire_sur_serveur_contactez_administrateur_serveur_ELTPARAGRAPHE000141"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le compte Windows qui exécute le gestionnaire de protocole WD310AWP n'a pas les droits nécessaires pour créer un répertoire temporaire. | Accorder les droits nécessaires au compte Windows.<br><br>Remarque : Pour connaître le compte qui exécute le protocole WD310AWP, lancez le Gestionnaire des services Internet (pour IIS, option "Démarrer .. Exécuter .. Inetmgr.exe" depuis le bureau de Windows) et affichez les propriétés du service "WWW". Le compte Windows correspond au nom d'utilisateur utilisé pour ouvrir une session anonyme. Pour plus de détails, consultez [Tableau récapitulatif des droits nécessaires](../NonDocumente/3539049.md). |


<a name="NOTE3_3"></a>


### Le nom de client annoncé est inconnu. Vérifiez votre nom de client et le mot de passe associé.
<a name="nom_client_annonce_est_inconnu_verifiez_votre_nom_client_mot_passe_associe_ELTPARAGRAPHE000170"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le gestionnaire de compte WEBDEV ne reconnaît pas le responsable de sites. | Vérifier qu'un compte WEBDEV a été créé dans le gestionnaire de comptes pour ce responsable de sites et communiquer le "login" correspondant au responsable de sites. |


<a name="NOTE3_4"></a>


### Les fichiers nécessaires à l'installation n'ont pas été transmis correctement. Vérifiez que le nom d'utilisateur et le mot de passe du FTP sont corrects et correspondent bien au compte propriétaire du site
<a name="les_fichiers_necessaires_installation_nont_pas_ete_transmis_correctement_verifiez_que_nom_utilisateur_mot_passe_ftp_sont_corrects_correspondent_bien_compte_proprietaire_site_ELTPARAGRAPHE000188"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Une erreur a eu lieu pendant le transfert FTP et le fichier installé sur le serveur n'est pas lisible. | Le responsable de sites doit recommencer son installation. <br>Attention : S'il s'agit d'une première installation, le responsable de sites doit supprimer la description du serveur dans la liste "Mise à jour à distance". |


<a name="NOTE3_5"></a>


### Le fichier d'installation est invalide. La transmission du fichier ne s'est pas passée correctement ou le fichier transmis a été endommagé.
<a name="fichier_installation_est_invalide_transmission_fichier_sest_pas_passee_correctement_fichier_transmis_ete_endommage_ELTPARAGRAPHE000208"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Une erreur a eu lieu pendant le transfert FTP et le fichier installé sur le serveur n'est pas lisible. | Le responsable de sites doit recommencer son installation. <br>Attention : S'il s'agit d'une première installation, le responsable de sites doit supprimer la description du serveur dans la liste "Mise à jour à distance". |


<a name="NOTE3_6"></a>


### Erreur pendant le décryptage des informations d'installation. Vérifiez le mot de passe utilisé.
<a name="erreur_pendant_decryptage_des_informations_installation_verifiez_mot_passe_utilise_ELTPARAGRAPHE000228"></a>Lors de la programmation d'une installation différée, un des problèmes suivants est survenu :  

| Problème possible | Solution |
| --- | --- |
| Le mot de passe saisit lors de l'installation à distance ne correspond pas au mot de passe défini dans le gestionnaire de comptes. | Vérifier le mot de passe associé au responsable de sites dans le gestionnaire de comptes et communiquer ce mot de passe au responsable de sites. |


<a name="NOTE3_7"></a>


### Impossible d'ajouter la programmation à cause de l'erreur suivante : XXX  :
<a name="impossible_ajouter_programmation_cause_erreur_suivante_xxx_ELTPARAGRAPHE000246"></a>Lors de la programmation d'une installation différée, un des problèmes suivants est survenu :

| Problème possible | Solution |
| --- | --- |
| Pas assez de mémoire disponible | Il est nécessaire de libérer de la mémoire sur le serveur Web puis de rententer l'installation différée. |
| Impossible de trouver l'administrateur local WEBDEV, vérifier que le serveur d'application WEBDEV est correctement installé sur le serveur. | L'administrateur local WEBDEV ne répond pas à la demande de programmation. Erreur lors du lancement de l'administrateur local WEBDEV : vérifier que le serveur d'application WEBDEV est correctement installé sur le serveur |


<a name="NOTE3_8"></a>


### Un site de même nom est déjà installée sur ce serveur. Un même serveur ne peut pas abriter deux sites portant le même nom. Vous devez renommer votre site ou désinstaller l'existant. S'il s'agit du même site, vous devez faire une mise à jour au lieu d'une installation.
<a name="site_meme_nom_est_deja_installee_sur_serveur_meme_serveur_peut_pas_abriter_deux_sites_portant_meme_nom_vous_devez_renommer_votre_site_desinstaller_existant_sil_sagit_meme_site_vous_devez_faire_une_mise_jour_lieu_une_installation_ELTPARAGRAPHE000268"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Lors d'une installation par FTP, deux sites du même nom ne peuvent pas être installés sur un même serveur Web, même si ces sites appartiennent à des responsables de sites différents. | Dans le cas d'une première installation du site sur le poste serveur, le responsable de sites WEBDEV doit renommer son site (renommer son projet). |

Remarque : Pour effectuer une mise à jour par FTP, vous devez utiliser l'option "Mise à jour à distance" lors de l'installation du site par FTP (et non l'option "Installation à distance").

## Etape 3 : Mise à jour d'un site
<a name="etape_3_mise_jour_site_ELTTEXTE000691"></a>
Lors de la mise à jour du site, l'assistant d'installation vérifie la bonne installation du site et sa configuration. Voici la liste des erreurs pouvant apparaître.
<a name="NOTE4_2"></a>


### Nom de site inconnu :
<a name="nom_site_inconnu_ELTPARAGRAPHE000403"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le site n'est pas installé sur le serveur | Faire une installation distante complète. |
| Le site n'est plus référencé dans l'outil d'administration local WEBDEV | Référencer le site WEBDEV dans l'outil d'administration local WEBDEV (onglet "Sites", bouton "Ajouter"). |


<a name="NOTE4_3"></a>


### Le nom du client demandeur et le propriétaire du site ne correspondent pas
<a name="nom_client_demandeur_proprietaire_site_correspondent_pas_ELTPARAGRAPHE000425"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le site a été installé par un autre responsable de sites. | Dans le gestionnaire de comptes WEBDEV, attribuer le site au compte WEBDEV correspondant. Vérifier que les répertoires de base (de données, du site et de transfert FTP) sont corrects. |


<a name="NOTE4_4"></a>


### Echec lors du cryptage
<a name="echec_lors_cryptage_ELTPARAGRAPHE000443"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Le cryptage de la mise à jour a échoué. | Libérer de l'espace mémoire et / ou disque sur le poste effectuant la mise à jour (poste du responsable de sites par exemple). |


<a name="NOTE4_5"></a>


### Erreur lors de la copie du fichier d'information. Vérifiez les informations du compte WEBDEV et réessayez.
<a name="erreur_lors_copie_fichier_information_verifiez_les_informations_compte_webdev_reessayez_ELTPARAGRAPHE000461"></a>Les problèmes possibles sont les suivants :

| Problème possible | Solution |
| --- | --- |
| Impossibilité de copier le fichier temporaire décrivant l'état du site. L'utilisateur n'a pas les droits nécessaires dans le répertoire FTP | Accorder les droits d'écriture dans le répertoire FTP. |
| Impossibilité de copier le fichier temporaire décrivant l'état du site. Il n'y a pas assez de place disponible sur le disque | Libérer de l'espace disque sur le serveur. |
