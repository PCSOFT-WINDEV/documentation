## Erreur ERR_NOTAVAILABLE
<a name="erreur_errnotavailable_ELTTEXTE000062"></a>
Cette commande n'est disponible qu'en mode développement - ERR_NOTAVAILABLE (40)

WEBDEV "Version développement" est utilisé pour le déploiement d'un site dynamique WEBDEV.

Solution : Il faut installer WEBDEV "Version déploiement" pour déployer un site dynamique WEBDEV.
