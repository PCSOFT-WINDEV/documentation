## Syntaxe
<a name="syntaxe_ELTTEXTE000134"></a>
WDGenPage en mode ligne de commande permet de générer une ou plusieurs pages semi-dynamiques sans lancer WEBDEV ou WDGenPage.

Pour lancer WDGenPage en ligne de commande, plusieurs syntaxes sont possibles :

- WDGenPage.EXE

- WDGenPage.EXE /APP=&lt;NomProjet&gt; /USER=&lt;NomUtilisateur&gt; [/NOINTERF]

- WDGenPage.EXE /APP=&lt;NomProjet&gt; /USER=&lt;NomUtilisateur&gt; /PAGE=&lt;NomPage&gt; [/NOINTERF]






<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Détail
<a name="detail_ELTTEXTE000158"></a>
Détails des paramètres :

| Paramètre | Signification |
| --- | --- |
| /APP=&lt;NomProjet&gt; | Si ce paramètre est précisé, les pages semi-dynamiques du projet spécifié pourront être générées.<br>Ce projet ou le site correspondant doit obligatoirement être installé sur le poste en cours.<br>Si ce paramètre n'est pas spécifié, une fenêtre s'affichera permettant de sélectionner le projet à manipuler.<br>Seuls les projets installés sur le poste en cours sont proposés. |
| /USER=&lt;NomUtilisateur&gt; | Nom de l'utilisateur de WEBDEV. Ce nom a été spécifié au lancement de WEBDEV.<br>Sur le poste de déploiement, ce paramètre est ignoré. |
| /PAGE=&lt;NomPage&gt; | Si ce paramètre est précisé :<br><br>- et si le paramètre "/NOINTERF" n'est pas précisé, la page semi-dynamique spécifiée sera automatiquement proposée pour la génération.<br>	Cette page doit obligatoirement être de type semi-dynamique.<br><br>- et si le paramètre "/NOINTERF" est aussi précisé, la page semi-dynamique spécifiée est automatiquement générée.<br><br><br>Si ce paramètre n'est pas précisé :<br><br>- et si le paramètre "/NOINTERF" n'est pas précisé, une fenêtre s'affichera permettant de sélectionner les pages semi-dynamiques à générer.<br>	Seules les pages semi-dynamiques du projet manipulé sont proposées.<br><br>- et si le paramètre "/NOINTERF" est précisé, toutes les pages semi-dynamiques du projet seront automatiquement générées.<br><br><br> |
| /NOINTERF | Si ce paramètre est précisé, seule la jauge indiquant la progression de la génération s'affichera. |

**Exemple** : La ligne de commande suivante permet de générer la page "PAGE_MaPage" du projet "MonProjet". Seule la jauge indiquant la progression de la génération s'affichera : 


```wl
LanceAppli("C:\MesOutils\WDGenPage.EXE " + ... 
				"/APP=MonProjet /USER=STEPHANE /PAGE=PAGE_MaPage /NOINTERF")
```
