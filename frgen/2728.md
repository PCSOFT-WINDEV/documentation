## Erreur ERR_NO_PROJECT
<a name="erreur_errnoproject_ELTTEXTE000076"></a>
Le projet &lt;Nom_PROJET&gt; n'existe pas (ni en WWP ni en WDL). Vérifiez la configuration pour ce projet. ERR_NO_PROJECT (30)

Cette erreur est affichée dans les cas suivants : 

- Le site dynamique WEBDEV est mal installé (fichiers correspondants non copiés sur le disque ou entrée correspondante dans la base de registre incorrecte). Il est nécessaire de réinstaller le site et/ou de vérifier sa configuration dans la base de registre.
	**Rappel** :
	Lors de l'installation d'un site dynamique WEBDEV, une nouvelle entrée est créée dans la base de registre.
	Une nouvelle entrée est créée dans la clé :
	"HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31\\&lt;NomProjet&gt;".
	Le nom du projet et son répertoire sont indiqués.

- Le projet (.wdp) n'est pas présent dans la bibliothèque (.wdl) du site sur le serveur. Lors de la génération de la bibliothèque (assistant de déploiement du site), vérifiez que le fichier du projet est bien intégré.
