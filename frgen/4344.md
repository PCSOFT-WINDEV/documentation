## Erreur ERR_NO_END_TAG
<a name="erreur_errnoendtag_ELTTEXTE000071"></a>
Erreur de syntaxe dans le fichier &lt;NOM_FICHIER&gt;. La marque de fin pour la balise &lt;NOM_BALISE&gt; est manquante. ERR_NO_END_TAG (50)

Une erreur a été trouvée dans le fichier HTML devant être affiché : une balise de début est présente, mais sans balise de fin. La page HTML ne peut être interprétée par le moteur WEBDEV. Il est nécessaire de corriger le code correspondant.

Cette erreur peut survenir lors de l'utilisation de :

- Champs HTML

- Champs Java

- Code HTML inséré dans les champs de WEBDEV (onglet "Avancé")

- Code HML inséré dans la page (onglet "Avancé")






Vérifiez le code HTML présent dans ces champs.
