
## Administrateur WEBDEV distant : Importation des statistiques
			



## Présentation
<a name="presentation_ELTTEXTE000103"></a>
L'Administrateur distant WEBDEV propose un module de gestion des statistiques. Ce module permet : 

- d'importer les statistiques d'un site.

- de visualiser les statistiques d'un ou de plusieurs sites.




Pour accéder à ce module de statistiques, il est nécessaire d'avoir un compte spécifique, dédié à la gestion des statistiques. Ce compte peut être créé grâce à l'administrateur distant. Pour plus de détails sur la création du compte, consultez [Configuration de l'administrateur distant](../WDAdminWeb/6468.md). 





## Comment le faire ?
<a name="comment_faire_ELTTEXTE000127"></a>


### Consulter les statistiques d'un site
<a name="consulter_les_statistiques_site_ELTPARAGRAPHE000020"></a>Pour consulter les statistiques d'un site :


1. **Lancez l'administrateur WEBDEV distant** en saisissant l'adresse suivante : 
	
	```txt
	http://<serveur>/WDAdminWeb
	```
où &lt;serveur&gt; représente l'adresse (nom ou adresse IP) du Serveur d'Application WEBDEV.

2. Pour consultez les statistiques, il est nécessaire de s'authentifier avec le nom d'utilisateur et le mot de passe correspondant au compte de consultation des statistiques. 

3. Le site de consultation des statistiques apparaît. Si vous n'avez pas importé de données, un message est affiché. 







### Importer les statistiques d'un site
<a name="importer_les_statistiques_site_ELTPARAGRAPHE000034"></a>Pour importer les statistiques d'un site :

1. Cliquez sur l'onglet "Importation" de l'administrateur WEBDEV distant. 

2. Dans la partie "Importer les logs d'un site", sélectionnez : 

	- le site concerné. 

	- la date de début d'importation. 




3. Cliquez sur le bouton "Lancer l'importation". 
	**Attention** : Selon la durée spécifiée, l'importation des statistiques peut être relativement longue. 




**Remarques** : 

- Le bouton "Réinitialiser" permet de réinitialiser toutes les statistiques du site. 

- Lorsque l'importation est en cours, elle apparaît dans la zone "Importations en cours". 

- Lorsque l'importation est terminée, elle apparaît dans la zone "Importations terminées".
