## Fichiers de configuration de Apache
<a name="fichiers_configuration_apache_ELTTEXTE000135"></a>
Lors de l'installation du serveur d'application WEBDEV pour Linux, les informations suivantes sont ajoutées dans le fichier de configuration de Apache:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=config_Apache.gif)
Le serveur Apache doit donc autoriser l'accès à ces répertoires.
Il peut être nécessaire d'ajouter des directives "&lt;directory&gt;" sur le répertoire de WEBDEV et sur les répertoires des sites. Ces opérations ne sont pas réalisées par l'installation du serveur d'application WEBDEV pour Linux. Pour plus de détails, consultez [Test de l'administrateur distant](../wdadmin_deploiement_linux/1410087176.md).

## Fichiers du serveur d'application WEBDEV pour Linux
<a name="fichiers_serveur_application_webdev_pour_linux_ELTTEXTE000159"></a>
Les différents fichiers et répertoires installés par le serveur d'application WEBDEV 2026 pour Linux sont les suivants:

- Fichier de configuration de WEBDEV 2026: /etc/PC SOFT/WEBDEV/31.0/WEBDEV.conf

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_1.gif)


- Fichier de configuration des sites installés: /etc/PC SOFT/WEBDEV/31.0/Applications/&lt;Nom site&gt;.conf

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_2.gif)


- Répertoire d'installation du serveur d'application WEBDEV pour Linux: /usr/local/WebDev/31.0

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_3.gif)


- Répertoire d'installation du protocole AWP: /usr/local/WebDev/31.0/AWP

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_4.gif)


- Répertoire d'installation de l'administrateur distant: /usr/local/WebDev/31.0/WDAdminWeb

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_5.gif)


- Répertoire d'installation des programmes permettant le déploiement des sites sur le serveur: /usr/local/WebDev/31.0/WDInstalle

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_6.gif)

## Fichiers installés lors du déploiement d'un site dynamique WEBDEV
<a name="fichiers_installes_lors_deploiement_site_dynamique_webdev_ELTTEXTE000183"></a>
Lors du déploiement d'un site WEBDEV, plusieurs types de fichiers sont installés:

- les pages, les images, ... sont installées dans le sous-répertoire du site correspondant à l'utilisateur. Dans cet exemple, les fichiers sont installés dans le sous-répertoire app\\&lt;nom du site&gt; de l'utilisateur Pat. Ces informations (répertoire d'installation des pages, ...) ont été fournies lors de la création du compte Utilisateur sous l'administrateur distant ([Créer les comptes utilisateur](../wdadmin_deploiement_linux/1410087177.md)).

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_8.gif)


- les tables (HFSQL uniquement) sont installées dans le sous-répertoire des données correspondant à l'utilisateur. Dans cet exemple, les fichiers sont installés dans le sous-répertoire data\\&lt;nom du site&gt; de l'utilisateur Pat.
	Ces informations (répertoire d'installation des données, ...) ont été fournies lors de la création du compte Utilisateur sous l'administrateur distant ([Créer les comptes utilisateur](../wdadmin_deploiement_linux/1410087177.md)).

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LinuxTree_7.gif)
