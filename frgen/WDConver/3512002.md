


## WDConver : Utilisation en mode interactif
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000142"></a>
Avant toute utilisation de WDConver, il est nécessaire de disposer de:

- Le schéma des données WINDEV (fichier ".WDD") dans lequel les données doivent être importées. Ce schéma des données doit avoir été généré au moins une fois.
	Rappel: Ce schéma des données doit contenir la structure des tables HFSQL dans lesquelles les données seront importées.

- La base de données contenant les données à importer.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Choix de la conversion
<a name="choix_conversion_ELTTEXTE000166"></a>
A son lancement, WDConver propose de:

- **Créer une nouvelle description de conversion**. A la fin de sa description, cette conversion sera automatiquement exécutée.

- **Choisir une description de conversion existante** (fichier ".WDV") déjà créée avec WDConver. La conversion est automatiquement exécutée.
	Il est ainsi possible d'exécuter directement une conversion sans la re-décrire.
	Une description de conversion peut également être utilisée pour lancer une conversion depuis une application WINDEV. Pour plus de détails, consultez [Lancement de WDConver en mode ligne de commande](../WDConver/3512003.md).

## Conversion des données d'une table d'une base externe vers une table HFSQL
<a name="conversion_des_donnees_une_table_une_base_externe_vers_une_table_hfsql_ELTTEXTE000190"></a>
Pour décrire et convertir les données d'un fichier d'une base de données externe vers une table HFSQL:

1. Lancez WDConver et validez les différents écrans jusqu'au plan "Choix de la source de données".

2. Sélectionnez la source de données "Une base externe".

3. Sélectionnez le schéma des données HFSQL Classic (fichier ".WDD") contenant la structure des fichiers externes à convertir.

4. Précisez si nécessaire le mot de passe en exécution de ce schéma des données. Ce mot de passe a été défini dans la description du schéma des données.

5. Sélectionnez le mode d'accès à la base de données externe (option "Type"). La connexion peut être réalisée via:

	- un provider OLE DB,

	- un driver ODBC,

	- un accès natif (AS/400, Oracle, SQL Server, ...).
			**Remarque**: Pour définir des paramètres de connexion avancés, cliquez sur le bouton ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=btn_fleche.gif).




6. Spécifiez la source de données de la connexion. Cette source de données peut correspondre:

	- Soit au nom et au chemin complet de la base de données. 
			Par exemple, pour Access: "C:\\MonRépertoire\\BaseDeDonnéesAccess.MDB"

	- Soit au nom ou à l'alias du serveur.
			Par exemple, pour Oracle: "Serveur_Oracle"

	- Soit au répertoire contenant le fichier xBase (".DBF").
			Par exemple: "C:\\MonRépertoirexBase"




7. Saisissez si nécessaire le nom de l'utilisateur utilisé pour se connecter à la base de données. 
	**Remarque**: Ce nom a été défini lors de la création de la base de données. Il peut exister plusieurs utilisateurs ayant des droits différents sur une même base de données.

8. Saisissez si nécessaire le mot de passe utilisé pour se connecter à la base de données. Ce mot de passe a été défini lors de la création de la base de données.

9. Sélectionnez les fichiers (tables) dont les données doivent être importées. La description de ces fichiers doit être à la fois présente dans la base de données source et dans le schéma des données WINDEV destination. 
	**Remarque**: Si aucune table n'est trouvée, saisissez directement le nom de la table dont les données doivent être importées.

10. Indiquez le répertoire dans lequel les tables HFSQL Classic seront créées.

11. Sauvegardez si nécessaire la description de la conversion (fichier ".WDV") afin de pouvoir la réutiliser.

12. Lancez la conversion des données (bouton de validation de l'assistant). Les tables HFSQL Classic sont automatiquement créées dans le répertoire indiqué.
	**Remarque**: Si ces fichiers existent déjà, la conversion des données ajoutera les enregistrements convertis à la suite des enregistrements existants.

## Conversion des données d'une table au format Hyper File 5 vers une table HFSQL Classic
<a name="conversion_des_donnees_une_table_format_hyper_file_5_vers_une_table_hfsql_classic_ELTTEXTE000214"></a>
Pour décrire et convertir un fichier au format Hyper File 5 vers une table HFSQL Classic:

1. Lancez WDConver et validez les différents écrans jusqu'au plan "Choix de la source de données".

2. Sélectionnez la source de données "Hyper File 5".

3. Sélectionnez le schéma des données au format Hyper File 5 associé aux données à convertir (fichier ".WDD") et précisez si nécessaire le mot de passe en exécution de ce schéma des données. Ce mot de passe a été défini dans la description du schéma des données.

4. Sélectionnez le schéma des données HFSQL Classic (fichier ".WDD") contenant la structure des fichiers contenant les données à convertir et précisez si nécessaire le mot de passe en exécution de ce schéma des données. Ce mot de passe a été défini dans la description du schéma des données.

5. Sélectionnez les fichiers (fichiers ".FIC") dont les données doivent être importées. La description de ces fichiers doit être à la fois présente dans la base de données source et dans le schéma des données destination. Indiquez si nécessaire leur nom logique et leur mot de passe.

6. Indiquez le répertoire dans lequel les tables HFSQL Classic seront créées.

7. Sauvegardez si nécessaire la description de la conversion (fichier ".WDV") afin de pouvoir la réutiliser.

8. Lancez la conversion de données (bouton de validation de l'assistant). Les tables HFSQL Classic sont automatiquement créées dans le répertoire indiqué.
	**Remarque**: Si ces fichiers existent déjà, la conversion des données ajoutera les enregistrements convertis à la suite des enregistrements existants.
