
## Administrateur WEBDEV distant : Visualiser les statistiques
			



## Présentation
<a name="presentation_ELTTEXTE000113"></a>
L'Administrateur distant WEBDEV propose un module de gestion des statistiques. Ce module permet de : 

- importer les statistiques d'un site.

- visualiser les statistiques d'un ou de plusieurs sites.




Après avoir importé les fichiers journal, les statistiques deviennent disponibles. Le tableau de bord affiche les données suivantes : 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=WebStat1.gif)


**1.** Onglets permettant d'accéder aux différents types de statistiques. 

**2.** Nom du site actuellement observé. Sélectionnez le nom du site à observer ainsi que la période souhaitée.

**3.** Statistiques demandées. Ces différentes statistiques sont présentées sous forme de : 

- tableaux récapitulatifs.

- graphiques. Ces graphiques peuvent être personnalisés (survol du graphique). Il est ainsi possible de changer le type de graphe, d'ajouter des légendes, de modifier la police utilisée, ...

## Les statistiques disponibles
<a name="les_statistiques_disponibles_ELTTEXTE000137"></a>
Les statistiques proposées sont les suivantes :


|   |   |
| --- | --- |
| <br><br>- ***Tableau de bord :***<br><br><br> | Tableau de bord récapitulant:<br><br>- le nombre de visiteurs.<br><br>- le nombre de pages vues.<br><br>- le nombre de pages moyen par visiteur.<br><br>- le nombre moyen de visiteurs par jour.<br><br>- le nombre moyen de pages vues par jour.<br><br>- le nombre maximum de connexions<br><br>- le nombre minimum de connexions<br><br>- la date de dernière importation des fichiers journal<br><br>- le fuseau horaire du site<br><br>- le type de site (Classique ou AWP)<br><br><br> |
| <br><br>- ***Réseaux de recherche :***<br><br><br> | Liste des mot-clés utilisés sur les moteurs de recherche permettant d'arriver sur le site. |
| <br><br>- ***Données techniques :***<br><br><br> | Liste des systèmes d'exploitation des internautes et des navigateurs. |
| <br><br>- ***Fréquentation :***<br><br><br> | Graphe récapitulant le nombre de visites selon différentes répartitions temporelles. |
| <br><br>- ***Vue Géographique :***<br><br><br> | Répartition de chaque visiteur selon le pays. |
