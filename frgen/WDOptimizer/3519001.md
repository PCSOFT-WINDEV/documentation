
## WDOptimizer: Édition et modification d'un fichier ".REP"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000116"></a>
Le fichier &lt;MonProjet&gt;.REP est un fichier contenant la liste des tables manipulées par l'application (identifiant, nom logique et chemin complet du fichier physique).

Le GUID du schéma des données est l'identifiant unique du schéma des données lié au projet, contenant la description des tables. Cet identifiant peut être connu sous l'éditeur de schémas des données, dans la description du schéma des données (onglet "Options").

Le GUID de la table correspond à l'identifiant de la table logique. Cet identifiant peut être connu sous l'éditeur de schémas des données, dans la description de la table (onglet "Notes").

Ce fichier .REP est automatiquement créé dans le répertoire de l'application et renseigné par le moteur HFSQL.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Le fichier .REP
<a name="fichier_rep_ELTTEXTE000140"></a>


### A quoi sert le fichier .REP?
<a name="quoi_sert_fichier_rep_ELTPARAGRAPHE000024"></a>

Le fichier .REP permet de localiser facilement les tables qui ont été utilisées par l'application WINDEV ou le site WEBDEV.

L'application WINDEV ou le site WEBDEV met à jour automatiquement le fichier .REP mais ne se sert pas (ou rarement) du fichier .REP.

Ce fichier est utilisé par tous les outils devant manipuler les tables de l'application, et principalement par la mise à jour automatique des tables, etc.
<a name="NOTE2_2"></a>


### Mise à jour d'une application avec modification du schéma des données
<a name="mise_jour_une_application_avec_modification_schema_des_donnees_ELTPARAGRAPHE000035"></a>

Lors de la mise à jour d'une application WINDEV, la modification automatique des tables est automatiquement lancée en cas de modifications sur la structure de la base de données.

Cette procédure utilise le fichier .REP pour retrouver les tables physiques utilisées par l'application afin de les modifier.

## Éditer et modifier un fichier .REP
<a name="editer_modifier_fichier_rep_ELTTEXTE000170"></a>


### Editer et modifier un fichier .REP
<a name="editer_modifier_fichier_rep_ELTPARAGRAPHE000046"></a>

Pour éditer et modifier un fichier .REP:

1. Lancez WDOptimizer:

	- Directement depuis WINDEV, WEBDEV ou WINDEV Mobile: sous le volet "Outils", dans le groupe "Base de données", cliquez sur "WDOptimizer".

	- en lançant directement le programme "WDOptimizer.EXE".




2. Sélectionnez l'option "Éditer et modifier un fichier .REP".

3. Sélectionnez le fichier .REP. Les tables contenues dans le fichier .REP sélectionné sont listées.

4. Pour supprimer l'ensemble des tables qui n'existent pas, cliquez sur le bouton "Nettoyer".

5. Pour supprimer la table sélectionnée, cliquez sur le bouton "Supprimer".
