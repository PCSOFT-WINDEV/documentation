## Erreur ERR_BAD_FILE
<a name="erreur_errbadfile_ELTTEXTE000061"></a>


### Le fichier &lt;NOM_FICHIER&gt; ne peut être ouvert (et donc renvoyé) ERR_BAD_FILE 
<a name="fichier_peut_etre_ouvert_donc_renvoye_errbadfile_ELTPARAGRAPHE000007"></a>

Le fichier HTML devant être affiché sous le navigateur n'existe pas.
Vérifiez la présence du fichier dans le répertoire du site dynamique WEBDEV.
