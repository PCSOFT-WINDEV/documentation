## Erreur ERR_BAD_WEBDEV_CONFIG
<a name="erreur_errbadwebdevconfig_ELTTEXTE000067"></a>


### ERR_BAD_WEBDEV_CONFIG : Mauvaise configuration générale de WEBDEV. La clé &lt;NOMCLE&gt; est manquante ou erronée. 
<a name="errbadwebdevconfig_mauvaise_configuration_generale_webdev_cle_est_manquante_erronee_ELTPARAGRAPHE000007"></a>

L'installation de WEBDEV n'a pas été correctement effectuée dans la base de registre.

**Remarque** : Les informations concernant le paramétrage de WEBDEV sont enregistrées dans la base de registre sous "HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31". 
Une entrée est créée pour chaque nouveau site dynamique WEBDEV créé.
