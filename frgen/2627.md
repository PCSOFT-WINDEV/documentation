## Erreur ERR_NO_APPLICATION
<a name="erreur_errnoapplication_ELTTEXTE000082"></a>
Le site &lt;NOM_SITE&gt; est inconnu : il n'a pas été configuré pour WEBDEV. ERR_NO_APPLICATION (32)

L'application WEBDEV (site dynamique, Webservice SOAP ou Webservice REST) est mal installé (correspondance avec la base de registre incorrecte). Il est nécessaire de réinstaller l'application et/ou de vérifier sa configuration dans la base de registre.

Rappel :
Lors de l'installation d'une application WEBDEV, une nouvelle entrée est créée dans la base de registre.
Une nouvelle entrée est créée dans la clé :
"HKEY_LOCAL_MACHINE\\SOFTWARE\\WOW6432Node\\PC SOFT\\WEBDEV\\31.0\\&lt;Type&gt;\\&lt;Nom&gt;"
où : 

- &lt;Type&gt; correspond à une des possibilités suivantes : 

	- "Applications" pour les sites dynamiques WEBDEV, 

	- "Webservices" pour les Webservices SOAP, 

	- "WebservicesREST" pour les Webservices REST. 




- &lt;Nom&gt; correspond au nom de l'application déployée. 




Le nom du projet et son répertoire sont indiqués.
