
## Administrateur WEBDEV distant : Gestion des messages d'erreur
			



## Messages d'erreur du Serveur d'Application
<a name="messages_erreur_serveur_application_ELTTEXTE000383"></a>
Par défaut, lorsqu'une erreur survient dans un site dynamique WEBDEV, un message d'erreur apparaît sous le navigateur de l'internaute. Ce message est constitué :

- ***d'un identifiant*** : par exemple : *ERR_MAX_CONNECTION (14)*

- ***d'un message*** : par exemple : *La connexion est refusée car le nombre maximum de connexions autorisées (300) a été atteint. Réessayez plus tard.*

- ***d'une page HTML*** spécifique où le message d'erreur est affiché.




L'outil d'administration à distance permet de personnaliser simplement les différentes erreurs pouvant être affichées par votre site. La personnalisation de la page d'affichage de l'erreur doit être réalisée lors du développement du site dynamique WEBDEV.


### Personnaliser les messages d'erreur d'un site WEBDEV
<a name="personnaliser_les_messages_erreur_site_webdev_ELTPARAGRAPHE000016"></a>Pour personnaliser les messages d'erreur d'un site WEBDEV :

1. Cliquez sur le lien "Sites" dans la barre de menu.

2. Sélectionnez le site à configurer. 

3. Cliquez sur le bouton ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%201.gif). 

4. Sélectionnez l'identifiant de l'erreur : le libellé en cours pour cette erreur s'affiche.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0008.gif&type=thumb)

	**Remarque** : Pour obtenir une explication sur les différents messages d'erreur par défaut, consultez [Messages d'erreur](#ListeMsg).

5. Vous pouvez au choix :

	- **Personnaliser le message d'erreur proposé :**
			Il suffit de saisir le nouveau message dans la zone de texte et de cliquer sur le bouton "Appliquer".
			**Remarque** : Dans certains messages, des balises spécifiques sont utilisées. Ces balises sont remplacées selon le contexte par un nom, un nombre, ...
			Il est conseillé de conserver ces balises.

	- **Rétablir le message d'erreur par défaut :**
			Le message d'erreur personnalisé sera remplacé par le message d'erreur prévu par défaut. Il suffit de cliquer sur le bouton "Par défaut".




6. La modification est immédiatement prise en compte.




**Remarque** : Les mêmes manipulations peuvent être réalisées pour les Webservices (option de menu "Webservices").
