


## Personnalisez vos graphes : type, couleur, légendes, ...
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Le graphe affiché dans votre application ne vous convient pas ? Vous voulez changer le type de graphe utilisé ? Les données sont affichées sous forme de courbe mais vous préférez les voir sous forme d'histogramme ? 

Utilisez le menu contextuel du graphe. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Personnalisez%20vos%20graphes.jpg)


Ce menu présente les différents types de graphes disponibles : il suffit de cliquer sur le type voulu pour modifier le graphe actuellement affiché dans votre application.
