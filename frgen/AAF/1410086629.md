
## Optimisez vos manipulations en créant vos raccourcis clavier
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Qui n'a pas souhaité définir ses propres raccourcis clavier, pour accéder simplement et rapidement aux fonctionnalités les plus utilisées d'une application ? 

Dans votre application WINDEV, c'est possible : vous pouvez créer et modifier les raccourcis clavier de vos applications.

Imaginez le temps gagné ! Plus besoin d'utiliser la souris pour cliquer sur un bouton !

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000085"></a>
Pour associer un raccourci clavier à un bouton :

1. Affichez le menu contextuel du bouton (clic droit : ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=souris.png)). 

2. Dans ce menu, sélectionnez l'option de gestion des raccourcis "Choisir un raccourci clavier...".

3. Dans la fenêtre qui s'affiche, tapez directement sur les touches de votre choix. Les touches choisies apparaissent : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Choix%20d'un%20raccourci.jpg)


4. Validez la fenêtre via le bouton "OK". Le raccourci choisi est mis en place. 

5. A chaque nouvelle utilisation du bouton, le raccourci indiqué pour le bouton sera utilisable.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Remarques
<a name="remarques_ELTTEXTE000120"></a>


- Si le raccourci choisi est déjà utilisé dans la fenêtre, un message indique que le raccourci sélectionné ne peut pas être utilisé.

- Le raccourci personnalisé est automatiquement affiché dans la bulle d'aide du bouton. Si la bulle d'aide contient déjà un texte, le raccourci est affiché à la fin du texte.

- Si le bouton contient un libellé, le raccourci personnalisé est automatiquement affiché à la fin du libellé du bouton.

- Si le raccourci "&lt;Aucun&gt;" est sélectionné, le bouton retrouvera son comportement par défaut, prévu par le développeur. 

- Si le raccourci clavier associé au bouton a déjà été personnalisé, l'option "Choisir un raccourci clavier..." permet de modifier le raccourci clavier personnalisé.
