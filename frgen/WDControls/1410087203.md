## Présentation du champ Kanban
<a name="presentation_champ_kanban_ELTTEXTE000212"></a>
Kanban est à l'origine une méthode inventée au Japon qui vise à améliorer les process en vue de produire en meilleure qualité et en réduisant les stocks.
Aujourd'hui, Kanban désigne également une méthode de classification visuelle des tâches, pour gérer ces tâches de manière agile.
Chaque tâche est écrite sur une "carte" qui sera changée de liste (de colonne) selon l'avancement.

Indépendamment de tâches, il peut s'agir de n'importe quelle ressource : user story, exigence, suggestion, étape de fabrication, livraison, dépannage, etc.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Kanban%20-%20Gala.png)


En général, un Kanban est partagé entre plusieurs utilisateurs. Chaque membre de l'équipe connaît ainsi l'avancée du projet, et sait ce qu'il a à faire et où en est le travail des autres membres.

En plus d'une meilleure communication, cette technique à base de "cartes" permet de visualiser facilement l'ensemble de la chaîne de production et l'avancement des tâches, et ainsi de repérer facilement les blocages et les urgences.

Le même champ Kanban fonctionne sous WINDEV, WEBDEV et WINDEV Mobile. Les fonctionnalités sont identiques, avec quelques spécificités en mobile et en web pour mieux tirer parti de la plateforme. Par exemple le mode d’utilisation sur téléphone en mode vertical tient compte de la faible largeur de l’écran.

## Créer un champ Kanban
<a name="creer_champ_kanban_ELTTEXTE000236"></a>
**Pour créer un champ de type Kanban** :

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Bureautique" puis cliquez sur "Kanban".

2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.




Remarque: Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z: le champ retrouvera sa taille par défaut.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Remarque** : Le champ Kanban n'est pas disponible dans les pages AWP.

## Caractéristiques du champ Kanban
<a name="caracteristiques_champ_kanban_ELTTEXTE000264"></a>
Le champ Kanban est composé de listes de cartes (appelés "Listes de Kanban"). 

Les principales options de description du champ Kanban sont les suivantes : 

- Définition des différentes listes de Kanban présentes dans le champ (onglet "Général"). 

- Définition du mode d'affichage et des dimensions des listes (onglet "Détail"). 

- Sélection des fenêtres/pages internes de personnalisation (onglet "Détail") : 

	- pour l'affichage des cartes. 

	- pour la zone d'ajout et de suppression (si cette zone existe).

### Fenêtres internes
<a name="fenetres_internes_ELTPARAGRAPHE000084"></a>Deux types de fenêtres internes permettent de personnaliser le champ Kanban : 

- Fenêtre interne utilisée pour l'affichage des cartes. 

- Fenêtre interne utilisée pour la personnalisation de la zone d'ajout/suppression. 




**Pour personnaliser entièrement l'affichage des cartes** (nécessaire pour une traduction par exemple) :

1. Affichez la fenêtre de description du champ Kanban. 

2. Dans l'onglet "Détail", sélectionnez la fenêtre interne utilisée pour l'affichage des cartes : 

	- "Aucune" : l'affichage par défaut sera utilisé. 

	- "Fenêtre prédéfinie" : Si cette option est sélectionnée, le composant interne WDFAA est immédiatement ajouté dans le projet en cours. La fenêtre interne "FI_CARTE_KANBAN" est automatiquement associée à l'option "Affichage des cartes".
			Remarque : Si le composant WDFAA existe déjà, seule la fenêtre est ajoutée au composant.  

	- N'importe quelle fenêtre interne présente dans votre projet. 




3. Validez si nécessaire la fenêtre de description du champ. 




**Pour personnaliser entièrement la zone d'ajout/suppression** :

1. Affichez la fenêtre de description du champ Kanban. 

2. Dans l'onglet "Détail", sélectionnez la fenêtre interne utilisée pour l'affichage des cartes : 

	- "Aucune" : l'affichage par défaut sera utilisé. 

	- "Fenêtre prédéfinie" : Si cette option est sélectionnée, le composant interne WDFAA est immédiatement ajouté dans le projet en cours. La fenêtre interne "FI_PIED_LISTE_KANBAN" est automatiquement associée à l'option "Zone d'ajout/suppression ". 
			Remarque : Si le composant WDFAA existe déjà, seule la fenêtre est ajoutée au composant.  

	- N'importe quelle fenêtre interne présente dans votre projet. 




3. Validez si nécessaire la fenêtre de description du champ. 




**Remarques** : 

- Chaque fenêtre interne personnalisée est disponible dans le volet "Explorateur de projet", dans le dossier "Composants internes". Elle peut être modifiée dans l'éditeur de fenêtres. 
	**Attention** : ces fenêtres internes permettent uniquement de personnaliser le dessin ou le look des éléments. Seul l'événement "Déclarations globales" est exécuté. Aucun autre événement n'est exécuté. Il n'est ainsi pas possible d'ajouter des boutons ayant un code de clic spécifique. 

- Si vous utilisez la fenêtre prédéfinie proposée, les options de style de la carte (sélectionnées dans l'onglet "Style") s'appliquent.

### Pages internes
<a name="pages_internes_ELTPARAGRAPHE000134"></a>Deux types de pages internes permettent de personnaliser le champ Kanban : 

- Page interne utilisée pour l'affichage des cartes. 

- Page interne utilisée pour la personnalisation de la zone d'ajout / suppression. 




Lors de la création du champ Kanban dans un projet WEBDEV, le composant interne WDFAA est immédiatement ajouté dans le projet en cours. Ce composant contient deux pages prédéfinies : 

- WEBDEVKanban : page permettant de personnaliser les cartes. 

- WEBDEVKanbanPlus : page permettant de personnaliser le bouton d'ajout / suppression en bas de la liste de Kanban. 




Par défaut, ces pages internes sont utilisées pour personnaliser les cartes et les boutons de bas de liste. 

**Pour modifier les pages internes utilisées pour la personnalisation des cartes et des boutons de bas de liste** :

1. Affichez la fenêtre de description du champ Kanban. 

2. Dans l'onglet "Détail", sélectionnez : 

	- la page interne utilisée pour l'affichage des cartes. 

	- la page interne utilisée pour l'affichage des boutons de bas de liste. 




3. Ces pages peuvent être une page interne prédéfinie ou n'importe quelle page interne présente dans votre projet. L'option "Non défini" permet d'utiliser l'affichage par défaut.  

4. Validez si nécessaire la fenêtre de description du champ. 




**Remarques** : 

- Chaque page du composant WDFAA est disponible dans le volet "Explorateur de projet", dans le dossier "Composants internes". Elle peut être modifiée dans l'éditeur de pages. 
	**Attention** : ces pages permettent uniquement de personnaliser le dessin ou le look des éléments. Seul l'événement "Déclarations globales" est exécuté. Aucun autre événement n'est exécuté. Il n'est ainsi pas possible d'ajouter des boutons ayant un code de clic spécifique. 

- Si vous utilisez la page prédéfinie proposée, les options de style de la carte (sélectionnées dans l'onglet "Style") s'appliquent.
