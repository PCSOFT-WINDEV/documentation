
## Champ Liste lié à une table ou une requête
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000078"></a>
Un champ Liste ou un champ Combo peut être utilisé pour afficher le contenu d'une table ou d'une requête, par exemple pour qu'un utilisateur ou un internaute sélectionne un enregistrement.

Lorsqu'un champ Liste est lié à une table (ou une requête), le champ Liste pourra être initialisé avec le contenu de la table (ou de la requête):

- soit ***automatiquement*** : aucun code spécifique n'est nécessaire pour initialiser le champ Liste. Les caractéristiques du parcours de la table liée au champ Liste sont décrites dans l'onglet "Contenu" de la description du champ Liste.

- soit par ***programmation*** : Il est nécessaire de saisir le code de parcours de la table liée au champ Liste dans le code d'initialisation du champ Liste. Cette méthode est déconseillée.




**Remarque** : Lors de la création d'un champ Liste, l'assistant demande les différents renseignements nécessaires à la création d'un champ Liste lié à une table ou à une requête.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Code d'initialisation d'un champ Liste programmé
<a name="code_initialisation_champ_liste_programme_ELTTEXTE000102"></a>
Si vous utilisez un champ Liste basé sur une table avec initialisation programmée, il est nécessaire de saisir le code de parcours de la table dans le code d'initialisation du champ Liste.

Initialisation d'un champ Liste avec les clients de la table CLIENT.


```wl
// -- Code d'initialisation d'un champ Liste
HLitPremier(CLIENT, NomCli)
TANTQUE PAS HEnDehors()
	ListeAjoute(LISTE_Liste1, Client.NomCli)
	HLitSuivant(CLIENT, NomCli)
FIN
```
