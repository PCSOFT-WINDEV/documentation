


## Graphe de type Zones proportionnelles imbriquées
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000130"></a>
Un graphe de type Zones proportionnelles imbriquées permet de comparer des proportions (tailles, quantités, etc.) et d'obtenir un aperçu rapide de la taille relative des données sans utiliser d'échelle.

Les caractéristiques de ce type de graphe sont les suivantes: 

- seule une série est affichée. 

- les données de la série doivent être triées de façon croissante avant l'ajout. Si les données ne sont pas dans l'ordre croissant, le graphe ne sera pas affiché.

## Caractéristiques d'un graphe de type Zones proportionnelles imbriquées
<a name="caracteristiques_graphe_type_zones_proportionnelles_imbriquees_ELTTEXTE000154"></a><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=graphe_zone_nested.gif)
Dans ce graphe:

**1. Angle de départ**. 
Angle utilisé pour le départ du graphe. Ce paramètre peut être défini dans l'onglet "Général" de la fenêtre de description du champ Graphe (option "Angle de départ (en degrés) "). 

**2. Titre du graphe**. 
Les caractéristiques du titre du graphe sont saisies dans l'onglet "Détail" de la description du champ (bouton "Editer le titre du graphe").
Il est possible de définir le titre du graphe, sa position et son style.

**3. Légende**. 
Les caractéristiques de la légende sont saisies dans l'onglet "Détail" de la description du champ (bouton "Editer la légende du graphe").
Il est possible de définir sa position et son style.

**4. Etiquette de catégorie**. 
Les étiquettes de catégories sont affichées dans la légende. Les étiquettes de catégorie peuvent être définies dans l'onglet "Séries" de la description du champ. La source des étiquettes de catégorie peut correspondre à une colonne d'un champ Table, une table, un tableau WLangage, une liste, etc. 

**5. Couleur de la zone**. 
La couleur de parts est définie automatiquement. Pour modifier la couleur des zones, utilisez la fonction [grCouleurSérie](../WDLang3/3042013.md) en précisant le numéro de la zone. 

**6. Libellé de la zone**. 
Le libellé des zones peut contenir:

- la valeur correspondant à la zone: option "Afficher les valeurs" de l'onglet "Détail" de la fenêtre de description du champ Graphe.

- les étiquettes de catégorie (option "Afficher les étiquettes des catégories" de l'onglet "Général" de la fenêtre de description du champ Graphe). 

- les pourcentages (option "Afficher les pourcentages" de l'onglet "Général" de la fenêtre de description du champ Graphe).
