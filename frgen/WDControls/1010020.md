


## Caractéristiques des fenêtres non maximisées
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000092"></a>
Une fenêtre non maximisée peut être redimensionnée par l'utilisateur et occuper seulement une partie de l'écran. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Différentes options sont paramétrables dans l'assistant de création d'une fenêtre. 

Pour lancer l'assistant de création d'une fenêtre : 

- Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_nouveau.gif) parmi les boutons d'accès rapide. 

- La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Fenêtre" puis sur "Fenêtre".

- L'assistant de création d'une fenêtre se lance. 

- Sélectionnez "Assistant" dans l'assistant.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Il est également possible de définir des fenêtres non maximisée dans l'onglet "Style" de la fenêtre de description de la fenêtre (option "Fenêtre non maximisée"). 

Les différentes options des fenêtres non maximisées sont les suivantes : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) [Options disponibles en Android](../WDChamp/9000121.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Options disponibles en iOS](../WDChamp/9000148.md).
