
## Programmation des champs Zone répétée liée aux données (syntaxe préfixée)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000070"></a>
Voici les principaux points de la programmation des champs Zone répétée liée aux données.

Le WLangage met à votre disposition de nombreuses fonctions permettant de gérer par programmation les champs Zone répétée liée aux données.

N'hésitez pas à consultez la documentation de ces fonctions. Pour plus de détails, consultez : [Fonctions de gestions des champs Zone répétée](../WDLang2/1000023945.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Ajout et modification d'une répétition dans un champ Zone répétée liée aux données
<a name="ajout_modification_une_repetition_dans_champ_zone_repetee_liee_aux_donnees_ELTTEXTE000103"></a>
L'ajout et la modification d'une répétition dans le champ Zone répétée (et d'un enregistrement dans la table) se décompose en deux phases :

1. Ajout ou modification de l'enregistrement dans la table (par une fenêtre ou une page de type fiche par exemple)

2. Réaffichage du contenu du champ Zone répétée liée aux données (fonction [&lt;Zone répétée&gt;.Affiche](../WDLang2/1000023451.md)).




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Suppression d'une répétition dans un champ Zone répétée liée aux données
<a name="suppression_une_repetition_dans_champ_zone_repetee_liee_aux_donnees_ELTTEXTE000137"></a>
Pour supprimer une répétition dans un champ Zone répétée liée aux données :

1. Supprimez l'enregistrement dans la table (fonction [&lt;Source&gt;.Supprime](../WDLang4/1000025071.md)).

2. Réaffichez le contenu du champ Zone répétée liée aux données (fonction [&lt;Zone répétée&gt;.Affiche](../WDLang2/1000023451.md)).


**Important** : La fonction [&lt;Zone répétée&gt;.NumEnr](../WDLang2/1000023521.md) renvoie le numéro de l'enregistrement en cours dans un champ Zone répétée liée aux données.
