


## Action Bar d'une fenêtre
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation de l'Action Bar
<a name="presentation_action_bar_ELTTEXTE000239"></a>
Les "Action Bars" remplacent la barre de titre d'une fenêtre et permettent d'afficher plusieurs informations:

- l'icône de l'application,

- le titre de la fenêtre,

- certaines options de menu,

- le menu déroulant de votre fenêtre. 








<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Créer et paramétrer une Action Bar
<a name="creer_parametrer_une_action_bar_ELTTEXTE000263"></a>
Par défaut, les fenêtres sont créées avec une Action Bar.

Il est possible de configurer les barres utilisées dans la fenêtre: 

1. Affichez la fenêtre de description de la fenêtre (option "Description" du menu contextuel). 

2. Dans l'onglet "Style", indiquez le contenu de la barre du haut: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_Action_bar%20-%20HC%20N%B0001.gif)


	- Plein écran: aucune barre n'est affichée, 

- Barre système seule: Seule la barre système sera affichée. 

- Barre système + Action Bar: La barre système et l'Action Bar seront affichées. 

- Action Bar seule: Seule l'Action Bar est affichée. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Mode Feuillet (iOS13 et +): si ce type de barre est sélectionné, la fenêtre peut s'ouvrir depuis le bas de l'écran. La fenêtre reste "cascadée": elle ne recouvre pas totalement la fenêtre en dessous. Il suffit de faire un 'swipe' vers le bas pour fermer la fenêtre. 
			Si cette option est sélectionnée: 

	- la fenêtre n'a pas de barres sous l'éditeur. 

	- l'événement "Autorisation de fermeture" est automatiquement associé à la fenêtre. Si cet événement renvoie: 

		- <u><u><u><u>Vrai</u></u></u></u>, la fenêtre est fermée. 

		- <u><u><u><u>Faux</u></u></u></u>, la fenêtre est réactivée.




Selon le type de barre sélectionné, le bouton "Editer le style des barres" permet de paramétrer les options de style utilisées (couleur et police notamment). 

Remarques: 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) En cas d'utilisation de la barre système, il est possible de configurer la transparence de la barre système pour iOS 7 et supérieur.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour une utilisation sous iPhone X, il est possible de décaler les barres selon la zone des capteurs.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Jusqu'à la version 25**, la hauteur des champs Action Bar est de 48 px par défaut. 
	**A partir des nouveaux projets créés en version 26**, la hauteur du champ Action Bar passe à 56 px par défaut. Il est possible de choisir la hauteur à utiliser par défaut, dans la fenêtre de description de la configuration de projet: option "Hauteur action bar " dans l'onglet "Général". 
	Remarques: 

	- En cas de modification de la hauteur, la nouvelle hauteur s'applique à toutes les fenêtres du projet.




- Pour plus de détails sur les configurations de projet, consultez [Configuration de projet](../Editeurs/9000030.md). 





### Style des barres
<a name="style_des_barres_ELTPARAGRAPHE000118"></a>

Le bouton "Editer le style des barres" permet de définir les options de styles des barres sélectionnées: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_Action_bar%20-%20HC%20N%B0002.gif)


- Barre système.

- Action Bar.

- Barre de navigation. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **En cas d'utilisation de la barre système**, il est possible de configurer: 

- la couleur de fond: cette couleur peut être: 

	- une couleur spécifique, une couleur système ou transparent. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_Action_bar%20-%20HC%20N%B0003.gif)
Si la couleur est "Transparent", la couleur de la barre système est celle de l'Action Bar. Cette option est prise en compte uniquement si la fenêtre contient une Action Bar. 

	- adaptée à l'Action Bar. Dans ce cas, si le thème "Material design" est utilisé, la couleur de la barre système correspond à la couleur de l'Action Bar en plus sombre, sinon la couleur de l'Action Bar est utilisée. 




- la couleur du texte. 

- si la barre doit être ou non en mode recouvrement. Si l'option "Barre affichée par dessus" est cochée, l'origine des champs est modifiée et la propriété [Opacité](../Proprietes/2514006.md) pourra être utilisée sur le champ Action Bar. La barre sera affichée par dessus les champs. 




**En cas d'utilisation de l'Action Bar**, il est possible de configurer: 

- la couleur de fond: cette couleur peut être une couleur spécifique ou automatique. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) la présence ou non de l'ombre de l'Action Bar. 

- la couleur de la police. 

- si la couleur de la police doit être appliquée aux icônes actives. 

- l'image de fond de l'Action Bar. 

- si la barre doit être "affichée par dessus". Si l'option "Barre affichée par dessus" est cochée, l'origine des champs est modifiée et la propriété [Opacité](../Proprietes/2514006.md) pourra être utilisée sur le champ Action Bar. La barre sera affichée par dessus les champs. 




**En cas d'utilisation de la barre de navigation**, il est possible de configurer les couleurs utilisées pour les éléments actifs et inactifs. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Remarques: 

- Ce paramétrage de la couleur de la barre système est disponible uniquement à partir de Android 5.0. 

- Il n'est pas possible de changer la couleur de la barre sur les appareils Nexus.

- La propriété [CouleurBarreSystème](../Proprietes/1000022485.md) permet de modifier cette couleur par programmation.
