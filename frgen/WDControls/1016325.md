


## Champ Agenda lié à une table ou une variable
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000152"></a>
Il est possible de créer des champs Agenda directement liés aux données. Vous pouvez créer :

- un **champ Agenda lié à une table** : le champ Agenda sera lié à une table ou à une requête. Dans ce cas, la table contient les caractéristiques des rendez-vous. 

- un **champ Agenda sur variable** : le champ Agenda sera lié à une variable (le plus souvent une instance de classe). Dans ce cas, la classe liste les rendez-vous avec leurs caractéristiques. 




La programmation des champs Agenda est grandement simplifiée : il n'est plus nécessaire d'utiliser directement les [fonctions Agendaxxx](../WDLang1/1000019021.md). 





## Comment le faire ?
<a name="comment_faire_ELTTEXTE000176"></a>


### Créer un champ Agenda lié à une table
<a name="creer_champ_agenda_lie_une_table_ELTPARAGRAPHE000034"></a>

Pour créer un champ Agenda lié à une table, il est possible : 

- soit d'utiliser l'assistant de création du champ Agenda. Il suffit de sélectionner l'option "Afficher des données d'une table ou d'une requête existante". Répondez ensuite aux questions de l'assistant et validez. 

- soit de modifier la description du champ Agenda. 




Pour modifier les caractéristiques d'un champ Agenda existant :

1. Affichez la fenêtre de description du champ (option "Description" du menu contextuel). 

2. Dans l'onglet "Contenu", sélectionnez l'option "Table/Requête" et sélectionnez la source de données utilisée. Cette source de données peut être : 

	- une table définie dans le schéma des données,

	- une requête du projet,

	- une requête intégrée à la fenêtre ou à la page. 




3. Associez les différentes rubriques de la source de données aux caractéristiques du rendez-vous. Les éléments précédés d'une étoile sont obligatoires. 
	**Remarque** : Si la table associée ne contient pas directement la rubrique correspondante, il est possible de réaliser une liaison multitable. 

4. Validez la fenêtre de description du champ Agenda.  





### Créer un champ Agenda sur variable
<a name="creer_champ_agenda_sur_variable_ELTPARAGRAPHE000055"></a>

Pour créer un champ Agenda sur variable, il est possible : 

- soit d'utiliser l'assistant de création du champ Agenda. Il suffit de sélectionner l'option "Afficher les données d'une variable existante". Répondez ensuite aux questions de l'assistant et validez. 

- soit de modifier la description du champ Agenda. 




Pour modifier les caractéristiques d'un champ Agenda existant : 

1. Affichez la fenêtre de description du champ (option "Description" du menu contextuel). 

2. Dans l'onglet "Contenu", sélectionnez l'option "Par variable" et sélectionnez la source de données utilisée (classe, etc.). 

3. Associez les différents éléments (membres de la classe par exemple) de la source de données aux caractéristiques du rendez-vous. Les éléments précédés d'une étoile sont obligatoires. 

4. Validez la fenêtre de description du champ Agenda. 






## Manipuler un champ Agenda lié à une table ou sur variable
<a name="manipuler_champ_agenda_lie_une_table_sur_variable_ELTTEXTE000206"></a>
Un champ Agenda lié à une source de données (table ou variable) se manipule très simplement :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Si l'utilisateur manipule directement le champ Agenda via le menu contextuel, les ajouts, suppressions, modifications des rendez-vous sont automatiquement reportés dans la source de données liée au champ. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Si l'utilisateur manipule les rendez-vous via une fenêtre spécifique, il suffit de modifier directement la table (ou la variable) liée au champ Agenda. Les données affichées seront automatiquement mises à jour. Il est également possible d'utiliser la fonction [AgendaAffiche](../WDLang1/1000019425.md) pour remettre à jour les données affichées dans le champ. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Si le champ Agenda autorise la saisie directe de rendez-vous, les rendez-vous ajoutés dans le champ Agenda sont automatiquement ajoutés dans la source de données lié au champ. 

- Si le champ Agenda autorise la modification de la durée et/ou le déplacement de rendez-vous, les modifications du rendez-vous sont automatiquement reportées dans la source de données liée au champ. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) La suppression réalisée dans le champ est effectuée en même temps dans la source de données liée.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Par défaut, la suppression n'est pas autorisée dans le champ Agenda lié à une source de données. Pour autoriser la suppression des rendez-vous : 

	- Affichez la description du champ Agenda (option "Description" du menu contextuel). 

	- Dans l'onglet "Contenu", cochez l'option "Autoriser la suppression (supprime aussi dans la source de données)". 

	- Validez.
