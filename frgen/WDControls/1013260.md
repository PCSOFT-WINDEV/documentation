


## Tableau HTML
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000180"></a>
Le tableau HTML est un champ qui permet de faire des présentations spécifiques dans des pages HTML. Le tableau HTML ne permet pas de positionner des champs mais permet de présenter les informations.

Par exemple, grâce aux tableaux HTML il est possible de faire des énumérations avec des bordures et des colonnes.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Tableau_HTML.gif)


<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Création d'un tableau HTML
<a name="creation_tableau_html_ELTTEXTE000204"></a>
**Pour créer un tableau HTML** : 

- sous le volet "Création", dans le groupe "Conteneurs", cliquez sur "Tableau HTML". Dans l'assistant qui se lance, sélectionnez les caractéristiques du tableau HTML à créer : 

	- Nombre de lignes.

	- Nombre de colonnes.

	- Style du tableau et alternance des lignes et des colonnes.




- sous le volet "Création", dans le groupe "Conteneurs", cliquez sur "Tableau HTML" et sélectionnez directement le nombre de lignes et de colonnes du tableau. Dans l'assistant qui se lance, sélectionnez les caractéristiques de style du tableau et l'alternance des lignes et des colonnes. 




Lorsque le tableau HTML est créé dans la page, il est possible de manipuler le tableau et ses cellules grâce au menu contextuel.

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Utilisation d'un tableau HTML
<a name="utilisation_tableau_html_ELTTEXTE000228"></a>
Dans chaque cellule d'un tableau HTML, il est possible de mettre un champ. Le champ et la cellule ont la même taille. Le champ et la cellule ont les mêmes propriétés de bordure et de fond.

Il n'est pas possible de mettre plusieurs champs dans une cellule d'un tableau HTML.

Cependant, il est possible de mettre une cellule HTML contenant plusieurs champs dans une cellule d'un tableau HTML.

## Manipulation d'un tableau HTML
<a name="manipulation_tableau_html_ELTTEXTE000252"></a>


### Sélectionner une cellule
<a name="selectionner_une_cellule_ELTPARAGRAPHE000072"></a>Pour sélectionner une cellule vide, il suffit de :

1. Cliquer sur le champ Tableau HTML : le champ est sélectionné.

2. Cliquer à nouveau sur le champ Tableau HTML : le champ passe en édition et un cadre jaune apparaît autour du champ.  

3. Cliquer dans la cellule voulue. La cellule est alors sélectionnée : des hachures apparaissent dans la cellule.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Tableau_HTML_Cellule_select.gif)



Dans ce cas, l'option "Description" du menu contextuel permettra d'accéder à la description de la cellule.

Pour sélectionner une cellule associée à un champ, il suffit de sélectionner le champ.
Dans ce cas, l'option "Description" du menu contextuel permettra d'accéder à la description du champ. 
Pour obtenir la description de la cellule, il suffit de sélectionner l'option "Description de la cellule" dans le menu contextuel.
<a name="NOTE4_2"></a>


### Sélectionner une colonne ou une ligne
<a name="selectionner_une_colonne_une_ligne_ELTPARAGRAPHE000092"></a>Pour sélectionner une colonne ou une ligne, il suffit de :

1. Cliquer sur le champ Tableau HTML : le champ est sélectionné.

2. Cliquer à nouveau sur le champ Tableau HTML : le champ passe en édition et un cadre jaune apparaît autour du champ.

3. Sélectionner la ligne ou la colonne voulue. La ligne ou la colonne est alors sélectionnée : des hachures apparaissent.




Il est alors possible grâce au menu contextuel de :

- fractionner verticalement ou horizontalement l'élément sélectionné

- fusionner les différentes parties de l'élément sélectionné.

## Modifier la taille d'un tableau HTML
<a name="modifier_taille_tableau_html_ELTTEXTE000282"></a>


### Modifier le nombre de cellules du tableau
<a name="modifier_nombre_cellules_tableau_ELTPARAGRAPHE000110"></a>Pour modifier le nombre de cellules d'un tableau HTML, il est possible :

- d'ajouter des lignes ou des colonnes une par une grâce au menu contextuel (option "Insérer une ligne" ou "Insérer une colonne")

- d'ajouter plusieurs lignes ou colonnes grâce au menu contextuel (option "Agrandir le tableau")



<a name="NOTE5_2"></a>


### Modifier la taille du tableau
<a name="modifier_taille_tableau_ELTPARAGRAPHE000120"></a>La taille du tableau peut être modifiée de deux façons différentes :

- En agrandissant ou en réduisant proportionnellement toutes les lignes / colonnes du tableau : il suffit de réduire ou agrandir le tableau en utilisant les poignées du champ.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Tableau_HTML_Agrandissement.gif)


- en agrandissant ou en réduisant uniquement la dernière ligne / colonne du tableau : il suffit de réduire ou d'agrandir le tableau en édition (avec le cadre jaune affiché) en cliquant sur le bord de la dernière ligne ou colonne du tableau. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Tableau_HTML_Agrandis_col.gif)







## Editer le style d'un tableau HTML
<a name="editer_style_tableau_html_ELTTEXTE000312"></a>
Il est possible d'éditer séparément les caractéristiques du bord et du fond du tableau HTML et celles de chacune des cellules du tableau HTML (onglet "Bord, Fond" de la fenêtre de description). 

Il est également possible de choisir un style WEBDEV via le menu contextuel.
