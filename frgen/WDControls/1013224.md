## Présentation du champ Table
<a name="presentation_champ_table_ELTTEXTE000239"></a>
Le champ Table permet de simplifier l'affichage et la saisie d'informations. Ces informations peuvent: 

- être stockées en mémoire, 

- provenir d'une table, d'une vue ou d'une requête.




Un champ Table est composé de lignes et de colonnes. L'intersection d'une ligne et d'une colonne définit une **cellule**. Un champ Table peut être géré ligne par ligne, colonne par colonne ou cellule par cellule. 

L'utilisateur peut sélectionner une seule ligne (monosélection) ou plusieurs lignes (multisélection). Le bandeau de sélection permet d'identifier l'élément sélectionné.




### Informations affichées
<a name="informations_affichees_ELTPARAGRAPHE000039"></a>

Les informations affichées dans un champ Table peuvent:

- être déterminées par programmation: on parle alors de **Champ Table par programmation** (appelé également "Table mémoire").

- provenir d'une variable: on parle alors de **Champ Table sur variable**.

- provenir d'une table ou d'une requête: on parle alors de **Champ Table lié à une table**. Deux types de champs Table sont disponibles:

	- ***Champ  Table lié à une table en accès direct***: le champ Table manipule directement les enregistrements de la requête ou de la table.

	- ***Champ Table lié à une table chargée en mémoire***: le champ Table manipule les enregistrements de la table chargés en mémoire (champ optimisé).







Pour connaître les principales fonctionnalités de ces différents types de champs Table, consultez le [comparatif des fonctionnalités des champs Table](../WDChamp/1013290.md).

## Création du champ et caractéristiques
<a name="creation_champ_caracteristiques_ELTTEXTE000269"></a>


### Comment créer un champ Table?
<a name="comment_creer_champ_table_ELTPARAGRAPHE000060"></a>

Pour créer un champ de type Table: 

1. Sous le volet "Création", dans le groupe "Données": 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) déroulez "Table et liste" puis sélectionnez "Table (Verticale)".
			Remarque: Un champ Table peut être affiché horizontalement ou verticalement.

	- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) déroulez "Table" puis sélectionnez "Table (Verticale)".

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) déroulez "Table" puis sélectionnez "Table simple".




2. Cliquez dans la fenêtre ou la page à la position où le champ doit être créé. L'assistant de création d'un champ Table se lance automatiquement. 

3. Répondez aux différentes questions et validez la création du champ. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Remarque: Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z: le champ retrouvera sa taille par défaut.


### Autres modes de création
<a name="autres_modes_creation_ELTPARAGRAPHE000097"></a>

- Pour créer simplement un champ Table à partir d'une table décrite sous l'éditeur de schémas des données, il suffit de faire un "Drag and Drop" de la table sélectionnée dans le volet "Explorateur de projet" ou dans le volet "Schéma des données".

- Pour créer simplement un champ Table à partir de variables de type tableau présentes dans la fenêtre ou la page en cours, il suffit de faire un "Drag and Drop" de la variable sélectionnée dans le volet "Explorateur de projet".





### Caractéristiques du champ Table
<a name="caracteristiques_champ_table_ELTPARAGRAPHE000103"></a>

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ. Deux types d'informations peuvent être visualisés:

- les informations concernant le champ Table dans son ensemble: il suffit de cliquer dans le nom du champ. Les différents onglets de la partie basse affichent les caractéristiques du champ Table.  

- les informations concernant chacune des colonnes: il suffit de cliquer sur le nom d'une des colonnes. Les différents onglets de la partie basse affichent les caractéristiques de la colonne sélectionnée.




Selon la plateforme utilisée, un champ Table (comme ses colonnes) peut avoir des caractéristiques spécifiques. Pour plus de détails, consultez:

## Permuter
<a name="permuter_ELTTEXTE000305"></a>


### Champ Table/Zone répétée
<a name="champ_tablezone_repetee_ELTPARAGRAPHE000149"></a>

Il est possible de transformer automatiquement un champ Table en un champ Zone répétée: 

1. Sélectionnez le champ Table à transformer. 

2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez "Table vers Zone répétée".



<a name="NOTE4_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Champ Table/Table hiérarchique
<a name="champ_tabletable_hierarchique_ELTPARAGRAPHE000173"></a>

WINDEV et WINDEV Mobile permettent de transformer automatiquement un champ Table en un champ Table hiérarchique et inversement: 

1. Sélectionnez le champ Table (ou Table hiérarchique) à manipuler. 

2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez "Table/Table hiérarchique".
