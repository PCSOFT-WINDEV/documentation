


## Le champ Multimédia
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000199"></a>


### Champ d'une fenêtre WINDEV et WINDEV Mobile
<a name="champ_une_fenetre_windev_windev_mobile_ELTPARAGRAPHE000011"></a>Le champ Multimédia permet de jouer des fichiers multimédia.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Sur un PC**, il est nécessaire d'avoir les éléments suivants installés : Windows Media Player, une version récente de DirectX ainsi que les codecs nécessaires à la lecture des fichiers vidéo. Si les codecs nécessaires ne sont pas installés, la lecture des vidéos ne pourra pas être effectuée.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Sous Android, le champ Multimédia doit être utilisé pour jouer des fichiers Vidéo. Pour jouer des fichiers audio, utilisez la fonction [Son](../WDLang1/3013047.md).

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Dans un site**, il est conseillé d'utiliser le format MP4 (supporté par tous les navigateurs à la norme HTML5). Les anciens formats demandent l'installation de plugins de moins en moins supportés par tous les navigateurs pour des raisons de sécurité. Pour plus de détails sur le champ Multimédia dans un site WEBDEV, consultez [Le champ Multimédia (WEBDEV)](../WDChamp/9500211.md).

## Créer un champ Multimédia
<a name="creer_champ_multimedia_ELTTEXTE000223"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Pour créer un champ Multimédia dans une fenêtre : 

1. Sous le volet "Création", dans le groupe "Champs graphiques" : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) déroulez "Vidéo et capture" et sélectionnez "Multimédia".

	- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) cliquez sur "Multimédia".




2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Pour créer un champ Multimédia dans une page: 

1. Sous le volet "Création", dans le groupe "Champs usuels", déroulez "Image" et sélectionnez "Champ multimédia".

2. Cliquez dans la page à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

Pour plus de détails sur le champ Multimédia dans un site WEBDEV, consultez [Le champ Multimédia (WEBDEV)](../WDChamp/9500211.md).

## Manipuler un champ Multimédia
<a name="manipuler_champ_multimedia_ELTTEXTE000247"></a>
Un champ Multimédia peut être manipulé par programmation grâce :

- aux [fonctions Multimédia du WLangage](../WDLang1/1000015005.md). Ces fonctions permettent par exemple d'associer un ficher multimédia au champ et de le jouer.

- aux [propriétés du WLangage](../WDChamp/9500201.md). La propriété [Valeur](../Proprietes/2510130.md) permet notamment d'associer un fichier multimédia au champ et de le jouer.





### Remarques
<a name="remarques_ELTPARAGRAPHE000126"></a>

- Il n'est pas possible d'utiliser le champ Multimédia dans un champ Zone répétée.

- Il n'est pas possible de capturer l'image d'une vidéo jouée dans un champ Multimédia.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Les propriétés [ScreenCastAutorisé](../Proprietes/1000021992.md) et [ScreenCastEnCours](../Proprietes/1000021993.md) permettent de gérer la possibilité d'afficher la vidéo sur un périphérique externe (compatible Air Play).  

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Si le format de la vidéo n'est pas supporté par iOS, la vidéo n'est pas jouée (par exemple, vidéo au format AVI).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) La lecture automatique est disponible uniquement avec une vidéo sans piste son.
