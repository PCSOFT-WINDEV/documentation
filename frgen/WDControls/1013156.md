## Présentation du Champ Jauge

### Champ d'une fenêtre ou d'une page dynamique
<a name="champ_une_fenetre_une_page_dynamique_ELTPARAGRAPHE000011"></a>

Les différents types de jauges proposés sont :

- Les jauges linéaires simples (horizontales ou verticales).
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seules les jauges linéaires simples horizontales sont disponibles en WEBDEV.

- Les jauges linéaires symétriques (horizontales ou verticales) : la jauge est séparée en deux parties (négative et positive) permettant d'afficher la progression.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=jauge_exemple_lineaire.gif)
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Ce type de jauge n'est pas disponible.

- Les jauges circulaires à aiguilles : une aiguille se déplace pour indiquer la valeur de la jauge.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Les jauges circulaires "LCD" : une "barre LCD" se remplit pour indiquer la valeur de la jauge.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Jauge_exemple_circulaire.gif)

## Créer un champ Jauge

### Créer un champ de type Jauge dans une fenêtre
<a name="creer_champ_type_jauge_dans_une_fenetre_ELTPARAGRAPHE000060"></a>Pour créer un champ de type Jauge : 

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez l'option "Jauge" et sélectionnez une jauge linéaire ou circulaire. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_Jauge20.gif)

	Remarque : l'option "Jauge infinie" permet de créer un champ de type [Jauge infinie](../WDChamp/1000034001.md). 

2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

**Remarques** : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Un grand choix de jauges circulaires prédéfinies est livré en standard. Ces jauges sont directement accessibles dans le volet "Champs prédéfinis" de l'éditeur.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Seules les jauges linéaires simples sont disponibles.



![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Créer un champ de type Jauge dans une page
<a name="creer_champ_type_jauge_dans_une_page_ELTPARAGRAPHE000102"></a>Pour créer un champ de type Jauge : 

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez l'option "Jauge".

2. Cliquez dans la page à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

**Remarques** : 

- Seules les jauges linéaires simples horizontales sont disponibles en WEBDEV. 

- Le champ Jauge ne peut être inclus dans un champ Zone répétée ou dans une colonne conteneur de table





### Créer un champ de type Jauge dans un état
<a name="creer_champ_type_jauge_dans_etat_ELTPARAGRAPHE000129"></a>Pour créer un champ de type Jauge : 

1. Sous le volet "Création", dans le groupe "Visuel", déroulez l'option "Jauge".

2. Cliquez sur le type de jauge voulu puis cliquez dans l'état à la position où le champ doit être créé. 

3. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

### Caractéristiques des jauges dans une fenêtre : fenêtre à 7 onglets
<a name="caracteristiques_des_jauges_dans_une_fenetre_fenetre_7_onglets_ELTPARAGRAPHE000159"></a>L'onglet "Général" permet de configurer :

- Le type de jauge : linéaire (horizontale ou verticale) ou circulaire (à aiguille ou LCD).

- Les différentes valeurs de la jauge. Ces valeurs peuvent également être spécifiées par programmation. Pour plus de détails, consultez [Manipuler une jauge par programmation](../WDChamp/1013141.md). 




L'onglet "Détail" permet de configurer :

- Les différentes images affichées dans la jauge (pour les jauges linéaires)
	Il est possible d'utiliser le mode 9 images sur les images affichées dans les jauges.

- Si la jauge est symétrique.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette option n'est pas disponible.

- Si la jauge utilise une image fixe.

- Si le pourcentage de progression doit être affiché dans le champ Jauge. Il est possible d'indiquer si ce pourcentage doit être mis à blanc si la valeur affichée est zéro. Il est également possible de définir la position du pourcentage affiché. Cette position peut être modifiée par programmation grâce à la propriété [CadrageHorizontal](../Proprietes/2510023.md). La mise en forme de ce pourcentage peut être effectuée par programmation grâce à la propriété [MasqueSaisie](../Proprietes/2510033.md).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette option n'est pas disponible.




L'onglet "Style" permet de configurer tous les paramètres de présentation de la jauge (y compris les images et leur position pour les jauges circulaires).

**Remarque** : Ces informations sont également disponibles pour les jauges affichées dans les champs Table.
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Caractéristiques des jauges dans une page : fenêtre à 7 onglets
<a name="caracteristiques_des_jauges_dans_une_page_fenetre_7_onglets_ELTPARAGRAPHE000203"></a>L'onglet "Général" permet de configurer les différentes valeurs de la jauge. Ces valeurs peuvent également être spécifiées par programmation. Pour plus de détails, consultez [Manipuler une jauge par programmation](../WDChamp/1013141.md). 

L'onglet "Détail" permet de configurer si le pourcentage de progression doit être affiché dans le champ Jauge (option "Afficher le pourcentage de progression"). 
Il est possible d'indiquer si ce pourcentage doit être mis à blanc si la valeur affichée est zéro (option "Ne pas afficher le pourcentage s'il vaut 0%"). 

La position du pourcentage affiché peut être modifiée par programmation grâce à la propriété [CadrageHorizontal](../Proprietes/2510023.md). La mise en forme de ce pourcentage peut être effectuée par programmation grâce à la propriété [MasqueSaisie](../Proprietes/2510033.md).

L'onglet "Style" permet de configurer tous les paramètres de présentation de la jauge. Il est possible par exemple de configurer le style CSS de la barre de progression pour afficher une image de progression.
