
## Champ de saisie : boutons intégrés dans la zone de saisie
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000173"></a>
Il est possible d'afficher plusieurs boutons dans la zone de saisie d'un champ de saisie : 

- Icône cliquable à droite, 

- Icône cliquable à gauche, 

- Bouton de suppression. 




Ces boutons et les événements correspondants peuvent être définis : 

- directement dans l'interface. 

- par programmation. 




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Définition des icônes cliquables à gauche et / ou à droite de la zone de saisie
<a name="definition_des_icones_cliquables_gauche_droite_zone_saisie_ELTTEXTE000197"></a>
La gestion des boutons présents dans la zone de saisie est réalisée dans l'onglet UI de la fenêtre de description du champ de saisie.

Les boutons situés à gauche et à droite de la zone de saisie sont des icônes cliquables : il suffit de définir l'image à utiliser et à spécifier le code de clic associé. 


### Icônes cliquables définies sous l'éditeur
<a name="icones_cliquables_definies_sous_editeur_ELTPARAGRAPHE000030"></a>Pour définir les icônes cliquables à droite et à gauche de la zone de saisie : 

1. Affichez la fenêtre de description du champ de saisie. 

2. Dans l'onglet "UI", dans la zone "Boutons intégrés à la zone de saisie", cliquez sur le lien "Aucun bouton" (à gauche ou à droite selon l'icône à afficher). 

3. Dans la fenêtre qui s'affiche, indiquez : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_gauche_droit%20-%20HC%20N%B0001.gif)


	- le nom de l'image à utiliser. Cette image peut correspondre à un fichier présent sur le disque ou à une image du catalogue d'images. Dans ce dernier cas, l'image proposée correspond automatiquement à une icône pouvant être affichée dans cette zone. 

- le nombre d'états gérés par l'image. 

- l'affichage ou non du pictogramme en mode monochrome. 
			Il est possible de forcer l'affichage du bouton en monochrome, en utilisant soit la couleur du texte soit la couleur du style (définit dans l'onglet "Style", élément "Forcer en monochrome").
			

- la taille du picto (largeur et hauteur). Si ces informations ne sont pas spécifiées, la taille actuelle du picto est utilisée. 

4. Spécifiez si nécessaire les marges entre la zone de saisie et le picto via le bouton "Marges" : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_gauche_droit%20-%20HC%20N%B0002.gif)


5. Validez la fenêtre de description des paramètres du picto. Le nom de l'image sélectionnée apparaît en lien dans l'onglet "UI" de la fenêtre de description du champ. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_gauche_droit%20-%20HC%20N%B0003.gif)


6. Validez la description du champ. Le picto sélectionné apparaît dans le champ, sous l'éditeur de fenêtres. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_gauche_droit%20-%20HC%20N%B0005.gif)





Pour définir le code WLangage associé à l'icône cliquable : 

1. Affichez le code WLangage associé au champ de saisie (raccourci F2 sur le champ). 

2. Selon le picto affiché, saisissez le code WLangage correspondant dans l'événement "Clic sur le bouton gauche" ou "Clic sur le bouton droit". 







### Icônes cliquables définies par programmation
<a name="icones_cliquables_definies_par_programmation_ELTPARAGRAPHE000069"></a>Pour définir par programmation les icônes cliquables à droite et à gauche de la zone de saisie : 

1. Utilisez les propriétés [BoutonDroit](../Proprietes/1410090002.md) et/ou [BoutonGauche](../Proprietes/1410090001.md) pour définir les caractéristiques de l'icône. 
	 Par exemple : 
	
	```wl
	SAI_Saisie.BoutonDroit.Image = IMG_Plus
	SAI_Saisie.BoutonDroit.NbEtat = 5
	SAI_Saisie.BoutonDroit.Monochrome = Faux
	```


2. Utilisez la propriété [Traitement](../Proprietes/1000020878.md) avec les constantes *trtClicBoutonSaisieDroite* et *trtClicBoutonSaisieGauche* pour définir le traitement à exécuter. Par exemple : 
	
	```wl
	SAI_Saisie.Traitement[trtClicBoutonSaisieDroite] = MaProcédure
	```

## Bouton de suppression
<a name="bouton_suppression_ELTTEXTE000233"></a>
Le bouton de suppression permet de vider le contenu de la zone de saisie. Par défaut, ce bouton est une icône standard, affichée par le système. Il est possible de définir son affichage (position et image utilisée). 

Pour configurer ce bouton de suppression : 

1. Affichez la fenêtre de description du champ de saisie. 

2. Dans l'onglet "UI", dans la zone "Boutons intégrés à la zone de saisie", déroulez la liste "Bouton de suppression" et sélectionnez l'option voulue : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_suppression%20-%20HC%20N%B0001.gif)


	- Aucun : Le bouton de suppression ne sera pas affiché (option par défaut). 

- En saisie : Le bouton de suppression apparaît uniquement lorsque le champ est en cours de saisie (lorsque l'utilisateur saisit le contenu du champ). 

- Hors de la saisie : Le bouton de suppression apparaît uniquement lorsque la saisie dans le champ est terminée et que l'utilisateur a changé de champ. 

- Toujours visible : Le bouton de suppression est toujours visible. 

3. Si vous choisissez une des options d'affichage du bouton de suppression, l'option "A droite" affiche alors "Aucune personnalisation". 

	- Par défaut, si aucune personnalisation n'est effectuée, l'icône système de suppression (une croix) sera affichée selon les options choisies. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_suppression%20-%20HC%20N%B0002.gif)


	- Il est possible de personnaliser l'icône de suppression en cliquant sur le lien "Aucune personnalisation" de l'option "A droite". 

4. Validez la fenêtre de description du champ.




Remarques : 

- L'icône de suppression n'est pas visible sous l'éditeur. Il est nécessaire d'exécuter le test de la fenêtre pour la faire apparaître. 

- Pour définir la position du bouton de suppression et son affichage par programmation, utilisez la propriété [BoutonSuppression](../Proprietes/1000021924.md) du WLangage.
