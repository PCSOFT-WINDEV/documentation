## Présentation du champ Chat IA
<a name="presentation_champ_chat_ELTTEXTE000161"></a>
Avec le champ Chat IA, vos applications WINDEV peuvent s'interfacer facilement avec le modèle d'IA que vous avez choisi.
La conversation peut contenir :

- du texte,

- des images,

- une ou des actions dans l'application.


Le champ Chat IA permet de saisir des éléments de conversation.

Il les envoie au modèle, récupère la réponse du modèle en streaming et l'affiche au fur et à mesure.

Si le modèle demande d'exécuter des actions, le champ Chat IA effectue ces actions.

**Attention**

- L'utilisation d'un champ Chat IA dans une application WINDEV nécessite une clé d'API correspondant au modèle d'IA utilisé. Les modèles d'IA supportés sont : 

	- ChatGPT (fournisseur OpenAI)

	- Claude (fournisseur Anthropic)

	- Gemini (fournisseur Google)

	- OpenRouter (fournisseur OpenRouter)

	- Le chat (fournisseur Mistral AI)

	- xAI (fournisseur Grok)




- L'utilisation d'une IA conversationnelle dans votre application WINDEV entraine la facturation de tokens par le fournisseur du modèle d'IA utilisé.

## Créer un champ Chat IA
<a name="creer_champ_chat_ELTTEXTE000185"></a>
**Pour créer un champ de type Chat IA :** 

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Bureautique" puis cliquez sur "Chat IA". 

2. Cliquez dans la fenêtre à la position où le champ doit être créé.




Remarque: Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z: le champ retrouvera sa taille par défaut.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Caractéristiques du champ Chat IA
<a name="caracteristiques_champ_chat_ELTTEXTE000213"></a>
La fenêtre de description du champ Chat IA permet de paramétrer plusieurs éléments importants, notamment dans les onglets "Général" et "Détail". 


### Onglet Général
<a name="onglet_general_ELTPARAGRAPHE000070"></a>

L'onglet "Général" permet de : 

- définir le modèle d'IA utilisé. Il suffit de sélectionner : 

	- le fournisseur parmi la liste proposée. 

	- la clé d'API correspondante. 

	- le modèle (optionnel)

	- l'URL (optionnel). 




- le prompt système. 
	Ce prompt permet de fournir un contexte à l'IA conversationnelle. Il est ainsi possible d'orienter l'IA vers des domaines spécifiques. Il est également possible d'indiquer les enchaînements de procédures à utiliser pour répondre à certaines questions. 






**Fournisseurs : Cas particuliers**

- Le fournisseur correspond à l'option "Par programmation". Dans ce cas, les caractéristiques du fournisseur doivent être définies grâce à la propriété IAInfoModèle. 

- Le fournisseur correspond à l'option "Personnalisé". Dans ce cas, il est nécessaire de préciser : 

	- le protocole, 

	- la clé d'API correspondante. 

	- le modèle (optionnel)

	- l'URL (optionnel). 










### Onglet Détail
<a name="onglet_detail_ELTPARAGRAPHE000097"></a>

L'onglet "Détail" permet de personnaliser chaque élément de la zone de chat. Pour chaque élément, une fenêtre interne peut être utilisée et personnalisée. 

Les différents éléments personnalisables sont : 

- zone de question : La zone de question correspond à la zone dans laquelle la question posée est affichée. 

- zone de réflexion : La zone de réflexion correspond à la zone affichée lorsque l'IA conversationnelle recherche les éléments de réponse. 

- entête de la réponse : L'entête de la réponse correspond à la zone qui présente la réponse. Dans cette zone sont affichés par exemple : le logo correspondant au modèle, un texte indiquant que c'est l'IA qui parle, etc. 

- tool : La zone tool correspond à la zone dans laquelle l'IA conversationnelle indique le libellé du tool actuellement utilisé. 
	Rappel : les tools correspondent aux procédures WLangage appelables par le modèle d'IA utilisé. 

- réponse : La réponse correspond à la zone affichant la réponse de l'IA conversationnelle. 

- réponse (pied) : Le pied de la réponse correspond à la zone d'icônes se trouvant sous la réponse de l'IA conversationnelle. Cette zone peut par exemple permettre de copier la réponse, etc. 

- zone de saisie : La zone de saisie correspond à la zone dans laquelle l'utilisateur va saisir sa question à l'IA conversationnelle. 
	Il est possible d'afficher ou non le nombre de token correspondant à la requête. 

- erreur : La zone d'erreur correspond à la zone utilisée pour afficher les erreurs détectées.
