## Evénements gérés par défaut
<a name="evenements_geres_par_defaut_ELTTEXTE000143"></a>
WINDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :


|   |   |
| --- | --- |
| **Evénement** | **Condition d'exécution** |
| Initialisation | Exécuté à l'ouverture de la fenêtre. \* |
| Avant envoi de la demande | Cet événement est appelé avant d'envoyer la demande à l'IA. La question posée par l'utilisateur peut être modifiée. Il est notamment possible de : <br><br>- Modifier le texte envoyé. <br><br>- Filtrer le texte envoyé (supprimer des mots). <br><br>- Ajouter des informations supplémentaires, non affichées à l'utilisateur. <br><br><br><br><br>Cet événement reçoit en paramètre une variable de type iaElementConversation qui correspond à la question posée. Cette variable peut être modifiée. <br><br>Pour annuler l'envoi de la question à l'IA, il suffit d'utiliser l'instruction : <br><br><pre><code>RENVOYER Faux</code></pre><br> |
| Pendant réception de la réponse | Cet événement est exécuté à chaque réception d'un token de réponse. <br><br>Cet événement reçoit en paramètre une variable de type Chaîne qui correspond au token de réponse.  <br><br>Cet événement peut par exemple permettre d'afficher une jauge pendant la réception de la réponse. |
| Après réception de la réponse | Cet événement est exécuté après la réception complète de la réponse. <br><br>Cet événement reçoit en paramètre une variable de type iaElementConversation qui correspond au texte de la réponse. <br><br>Cet événement permet par exemple d'obtenir les éléments présents en attachement à la réponse (images, etc.). |
| Erreur lors de la réception de la réponse | Cet événement est exécuté si le modèle d'IA renvoie une erreur. <br><br>Cet événement reçoit en paramètre une variable de type Chaîne qui correspond au texte de l'erreur. |
| Notation de la réponse | Cet événement est exécuté lorsque l'utilisateur clique sur "J'aime" ou "Je n'aime pas" dans la réponse fournie par l'IA. <br><br>Il est par exemple possible de juger ainsi si un modèle d'IA est pertinent. <br><br>Cet événement reçoit en paramètres : <br><br>- une variable de type Booléen, correspondant à l'icône cliquée. <br><br>- une variable de type iaElementConversation correspondant à la question qui a été notée. <br><br>- une variable de type iaElementConversation correspondant à la réponse qui a été notée. <br><br><br><br><br>Remarque : Le clic sur "J'aime / Jaime pas" est également présent dans les informations relevées par la télémétrie de l'application. |


(\*) Par défaut, le traitement "Initialisation" de chaque champ est exécuté selon l'ordre de création des différents champs dans la fenêtre. Pour modifier cet ordre d'exécution : 

1. Sous le volet "Fenêtre", dans le groupe "Ordre", cliquez sur "Initialisation". 

2. Dans la fenêtre qui s'affiche, utilisez les flèches situées sur la droite pour modifier l'ordre d'initialisation des champs.

## Evénements optionnels
<a name="evenements_optionnels_ELTTEXTE000167"></a>
Plusieurs événements optionnels peuvent être gérés.
Pour ajouter un événement optionnel :

1. Sélectionnez le champ voulu.

2. Affichez la fenêtre de code de ce champ (touche F2).

3. Cliquez sur le lien "Ajouter d'autres événements à xxx" situé à la fin de la fenêtre de code, après le dernier événement.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Traitements_optionnels_WD_OK%20-%20HC%20N%B0001.gif)


4. La totalité des événements optionnels disponibles pour le champ est affichée. 

5. Cochez l'événement optionnel à ajouter et validez. 
	Remarque : Il est possible de sélectionner plusieurs événements optionnels. 

6. L'événement optionnel sélectionné est automatiquement ajouté dans les événements gérés par le champ.




Pour désactiver un événement optionnel, il suffit d'effectuer les mêmes manipulations pour afficher la liste des événements optionnels. Il suffit ensuite de décocher les événements optionnels à supprimer. 
Remarque : Si le code désactivé contient du code WLangage, ce code est automatiquement supprimé.Il est ainsi possible de gérer par exemple :

- le survol du champ par la souris,

- le bouton gauche enfoncé, relâché, avec un double-clic,

- le bouton droit enfoncé, relâché, avec double-clic,

- la roulette de la souris, ...




Pour plus de détails, consultez les [Evénements optionnels](../WDChamp/1014004.md).
