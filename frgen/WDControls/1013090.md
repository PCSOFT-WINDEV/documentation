


## Propriétés associées aux attributs d'un champ Zone répétée
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000102"></a>
Dans une fenêtre comme dans une page, les attributs d'un champ Zone répétée peuvent être manipulés par les propriétés WLangage.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Propriétés disponibles dans une fenêtre
<a name="proprietes_disponibles_dans_une_fenetre_ELTTEXTE000126"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Propriétés utilisables dans une fenêtre
<a name="proprietes_utilisables_dans_une_fenetre_ELTPARAGRAPHE000020"></a>Les différentes propriétés utilisables avec les attributs des zones répétées sont les suivantes:



|   |   |
| --- | --- |
| [FenEditionAutorisée](../Proprietes/1000021850.md) | La propriété **FenEditionAutorisée** permet de connaître et de modifier les manipulations autorisées sur un champ lorsque la fenêtre passe en mode "Modification de l'UI par l'utilisateur final". |
| [LiaisonDonnées](../Proprietes/2510060.md) | La propriété **LiaisonDonnées** permet de connaître et de modifier la liaison d'un champ :<br><br>- avec une rubrique d'une table.<br><br>- avec une variable. <br><br>- avec plusieurs variables. <br><br><br> |
| [Nom](../Proprietes/2510082.md) | La propriété **Nom** permet de connaître:<br><br>- le nom de la police associée à une variable de type Police.<br><br>- le nom d'un champ, d'un état ou d'un bloc d'un état.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une fenêtre.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une page.<br><br><br> |
| [NomComplet](../Proprietes/2514005.md) | La propriété **NomComplet** permet de connaître le nom complet :<br><br>- d'un champ.<br><br>- d'une fenêtre.<br><br>- d'une option de menu.<br><br>- d'une colonne de table.<br><br><br><br><br> |
| [Valeur](../Proprietes/2510130.md) | La propriété **Valeur** permet de :<br><br>- Connaître et modifier la valeur d'un champ d'un état.<br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.<br><br>- Connaître l'identifiant d'un flux. <br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une page.<br><br><br> |
| [Volet](../Proprietes/1000021098.md) | La propriété **Volet** permet de : <br><br>- Connaître les volets d'onglet associés à un champ. <br><br>- Définir les volets d'onglet associés à un champ.<br><br><br> |



Remarque: Selon la plateforme utilisée, certaines propriétés peuvent ne pas être disponibles. Consultez la page d'aide de la propriété pour plus de détails.

### Propriétés utilisables dans une page (code serveur)

|   |   |
| --- | --- |
| [Alias](../Proprietes/2510004.md) | La propriété **Alias** permet de : <br><br>- connaître ou de modifier l'alias d'une fenêtre (WINDEV et WINDEV Mobile).<br><br>- connaître ou de modifier l'alias d'un volet d'onglet dynamique (WINDEV).<br><br>- connaître le nom interne HTML / Javascript d'un champ (WEBDEV).<br><br><br> |
| [LiaisonDonnées](../Proprietes/2510060.md) | La propriété **LiaisonDonnées** permet de connaître et de modifier la liaison d'un champ :<br><br>- avec une rubrique d'une table.<br><br>- avec une variable. <br><br>- avec plusieurs variables. <br><br><br> |
| [Nom](../Proprietes/2510082.md) | La propriété **Nom** permet de connaître:<br><br>- le nom de la police associée à une variable de type Police.<br><br>- le nom d'un champ, d'un état ou d'un bloc d'un état.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une fenêtre.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une page.<br><br><br> |
| [NomComplet](../Proprietes/2514005.md) | La propriété **NomComplet** permet de connaître le nom complet :<br><br>- d'un champ.<br><br>- d'une fenêtre.<br><br>- d'une option de menu.<br><br>- d'une colonne de table.<br><br><br><br><br> |
| [OptionTri](../Proprietes/1000017044.md) | La propriété **OptionTri** permet connaître et de modifier les options de tri utilisées dans :<br><br>- les colonnes des champs Table de type texte,<br><br>- les colonnes des champs Table hiérarchique de type texte, <br><br>- les champs Liste et Liste image,<br><br>- les champs Combo,<br><br>- les attributs des champs Zone répétée, <br><br>- les images, les images cliquables et les vignettes à défilement automatique.<br><br><br> |
| [Traitement](../Proprietes/1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [Type](../Proprietes/2510131.md) | La propriété **Type** permet de connaître:<br><br>- le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur de schémas des données, vue ou requête).<br><br>- le type d'un objet.<br><br>- le type de la valeur stockée dans un variant.<br><br><br> |
| [Valeur](../Proprietes/2510130.md) | La propriété **Valeur** permet de :<br><br>- Connaître et modifier la valeur d'un champ d'un état.<br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.<br><br>- Connaître l'identifiant d'un flux. <br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une page.<br><br><br> |
