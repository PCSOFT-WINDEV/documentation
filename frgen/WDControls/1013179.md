## Présentation du champ Libellé
<a name="presentation_champ_libelle_ELTTEXTE000379"></a>


### Champ d'une fenêtre, d'une page (statique ou dynamique), d'un état
<a name="champ_une_fenetre_une_page_statique_dynamique_etat_ELTPARAGRAPHE000011"></a>

Un champ Libellé est un champ qui permet d'afficher un texte statique. Le contenu du champ ne pourra pas être saisi par l'utilisateur.

Pour donner **des effets au texte affiché**, il est possible d'utiliser:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Le style du champ, en paramétrant l'élément "Ombre". 
	<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LIBeLLe_FLOU.gif)


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Le type "RTF" pour afficher un texte au format RTF.
	<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=LIBeLLe_RTF.gif)


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Une animation spécifique (défilement ou clignotement). 
	<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Libell%E9_Animation%20-%20HC%20N%B0003.gif)





![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Remarques**: 

- Les libellés d'une fenêtre peuvent être également paramétrés avec un masque d'affichage pour formater automatiquement la valeur qui leur est affectée.

- L'onglet "Style" de la fenêtre de description du champ permet de paramétrer de nombreux effets pour le champ Libellé. Il est notamment possible de: 

	- paramétrer le cadre du champ. Cette option permet par exemple d'afficher une image dans un champ Libellé. 
			L'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Bouton_rond%20-%20HC%20N%B0001%202.gif) (à droite de l'option "Cadre") permet de configurer l'ombre du cadre du champ. Lorsque l'ombre est activée, il est possible de choisir le décalage en X et Y de l'ombre, le pourcentage d'opacité, le rayon de flou et la couleur de l'ombre. 

	- paramétrer les caractéristiques de la police utilisée via le bouton <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Trad_param.gif)
. Il est possible d'indiquer: 

		- l'interligne, 

		- l'espacement des caractères, 

		- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) l'angle correspondant à l'orientation du texte.

## Créer un champ Libellé dans une fenêtre ou une page
<a name="creer_champ_libelle_dans_une_fenetre_une_page_ELTTEXTE000403"></a>


### Créer un champ Libellé dans une fenêtre ou une page
<a name="creer_champ_libelle_dans_une_fenetre_une_page_ELTPARAGRAPHE000101"></a>

Pour créer un champ de type Libellé dans une fenêtre ou une page: 

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_libelle18.gif).

2. Cliquez dans la fenêtre ou dans la page à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ. Vous pourrez saisir par exemple le texte affiché dans le champ ou définir le type des informations affichées dans le champ. 
<a name="NOTE2_2"></a>


### Gestion des libellés trop longs
<a name="gestion_des_libelles_trop_longs_ELTPARAGRAPHE000123"></a>

En cas de libellé trop long, plusieurs solutions peuvent être mises en oeuvre: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Réduire la police**: 
	Il est possible de définir une taille de police minimale pour le texte en cas de libellé trop long (option "Réduire la police" dans l'onglet "Détail" de la fenêtre de description du champ).

- **Afficher une ellipse**: il est possible de mettre en place une ellipse. L'ellipse consiste à remplacer le texte trop long par trois points. 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Dans une page, le texte du libellé peut uniquement être tronqué à la fin, en matérialisant la fin du texte par trois points. L'option "Tronquer avec une ellipse à la fin" est disponible dans l'onglet "UI" de la fenêtre de description du champ. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Dans une fenêtre, il est possible de proposer une ellipse soit en fin soit au milieu du texte trop long. La gestion de l'ellipse est définie dans l'onglet "Détail" du champ Libellé.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Proposer une animation**: L'animation peut en effet permettre de faire défiler le texte du libellé. Ainsi, l'utilisateur verra la totalité du texte lors de l'animation. Pour plus de détails sur la mise en place de l'animation, consultez [Animer un champ Libellé](../WDChamp/1013160.md).

### Cas particulier: Champ Libellé au format RTF
<a name="cas_particulier_champ_libelle_format_rtf_ELTPARAGRAPHE000170"></a>

Pour créer un champ de type Libellé au format RTF dans une fenêtre: 

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_libelle18.gif).

2. Affichez la fenêtre de description du champ (option "Description" du menu contextuel). 

3. Dans l'onglet "Général": 

	- Sélectionnez le type du champ Libellé: "RTF". 

	- Saisissez le texte du libellé au format RTF: une barre d'outils spécifique apparaît automatiquement permettant de mettre en forme le texte saisi.







Remarques:

- Il est également possible de créer un champ Libellé au format RTF via le champ Métier "Libellé RTF". 

- Il est également possible de créer un libellé RTF en réalisant un copier - coller d'un texte RTF directement dans la fenêtre.

- Pour utiliser un champ Libellé au format RTF, le fichier "RICHED20.DLL" doit être présent sur le poste en cours. Le fichier "RICHED20.DLL" est généralement présent dans le répertoire système de Windows.

- Il est également possible d'utiliser la propriété [RichEdit](../Proprietes/2510108.md) pour modifier le type RTF d'un champ Libellé par programmation.

## Contenu d'un champ Libellé
<a name="contenu_champ_libelle_ELTTEXTE000463"></a>
Un champ Libellé peut afficher des informations: 

- saisies sous l'éditeur. 

- définies par programmation. 

- provenant d'une table. Dans ce cas, le champ Libellé est relié à une rubrique d'une table. Le champ permet alors de visualiser le contenu des rubriques de la table.





### Saisir le texte du champ Libellé sous l'éditeur
<a name="saisir_texte_champ_libelle_sous_editeur_ELTPARAGRAPHE000246"></a>

Pour saisir le texte du champ Libellé:

1. Cliquez dans le champ Libellé sous l'éditeur. Le curseur de saisie apparaît.

2. Saisissez le texte du champ Libellé.
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Dans le cas des libellés RTF (dans une fenêtre ou un état), il est possible de mettre en forme chaque élément du libellé grâce à une barre d'outils.




Remarque: Le texte du champ Libellé peut également être modifié dans la fenêtre de description du champ. 
<a name="NOTE4_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Contenu d'un champ Libellé (Éditeur d'états)
<a name="contenu_champ_libelle_editeur_etats_ELTPARAGRAPHE000264"></a>

- **La chaîne de caractères affichée dans le champ Libellé peut contenir la valeur d'une rubrique imprimée dans l'état**. Pour insérer la valeur d'une rubrique ou d'un champ de l'état dans le texte du libellé, saisissez le nom de la rubrique ou du champ entre les caractères [% et %]. 
	Par exemple, le libellé du champ peut correspondre à: 
	Le fournisseur **[**%**NomFournisseur**%**]** vend le produit **[**%**NomProduit**%**]** pour **[**%**PrixTTC**%**]**. 
	Les rubriques NomFournisseur, NomProduit et PrixTTC seront remplacées par leur valeur à l'exécution de l'état.

- **Ce libellé peut être saisi sur plusieurs lignes**. Dans ce cas, le champ doit être multiligne et la taille du champ doit être suffisante. 
	Remarque: Si un angle d'orientation est appliqué à un champ multiligne, les retours chariot automatiques ne sont pas pris en compte. Seuls les retours à la ligne manuels sont pris en compte.




**Rappel**: L'option "Auto-Extensible" permet d'augmenter automatiquement la taille du champ en fonction de son contenu.

## Notes
<a name="notes_ELTTEXTE000499"></a>


- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Pour afficher des données numériques (montant, date, heure, etc.), utilisez le [champ d'affichage formaté](../WDChamp/1013043.md): les données seront affichées selon le masque de saisie sélectionné.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Pour définir une ancre sur un champ Libellé: 

	1. Affichez la fenêtre de description du champ.

	2. Dans l'onglet "UI", cochez l'option "Définir comme une ancre".

	3. Validez. 




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Dans les fenêtres, les champs Libellé disposent d'un masque d'affichage pour formater automatiquement les données qui leurs sont affectées. Ce masque peut être modifié en programmation grâce à la propriété [MasqueSaisie](../Proprietes/2510033.md).
