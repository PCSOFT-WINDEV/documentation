


## Manipuler un champ Image par programmation
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000300"></a>
WINDEV, WEBDEV et WINDEV Mobile permettent de manipuler un champ Image directement par programmation. Il suffit d'utiliser directement la variable du champ Image dans le code.

La variable du champ Image correspond au nom du champ Image. Cette variable est de type texte.

<a name="NOTE2_1"></a>


## Afficher un fichier image dans un champ Image
<a name="afficher_fichier_image_dans_champ_image_ELTTEXTE000324"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Dans une fenêtre
<a name="dans_une_fenetre_ELTPARAGRAPHE000022"></a>Pour afficher un fichier image dans un champ Image, une simple affectation suffit.

Quelques exemples :

- affectation directe : 
	
	```wl
	IMG_MonImage = "C:\Temp\MonImage.bmp"
	```


- affectation par variable :
	
	```wl
	CheminImage = fRepEnCours() + "\MonImage.bmp"
	IMG_MonImage = CheminImage
	```

	Remarque : Un champ Image peut aussi être initialisé à partir d'une variable de type buffer ou de type texte contenant la valeur de l'image en binaire.




**Remarque** : si le champ est associé à une rubrique d'un fichier de données, l'affectation est automatiquement réalisée en utilisant la fonction [FichierVersEcran](../WDLang4/3044210.md). Pour plus de détails, consultez [Lier un champ Image à une rubrique](../WDChamp/1013135.md).
<a name="NOTE2_2"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Dans une page
<a name="dans_une_page_ELTPARAGRAPHE000050"></a>Pour afficher un fichier image dans un champ Image, une simple affectation suffit.

Si l'image est disponible dans le répertoire "&lt;Nomprojet&gt;_WEB", il est possible d'utiliser les syntaxes suivantes :

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Code serveur : 
	
	```txt
	<Champ Image> = <Nom image>
	```

	Remarque : En code serveur, si l'image est disponible dans un répertoire différent de "&lt;NomProjet&gt;_WEB", il est nécessaire de :

	- préciser le chemin complet de l'image. 

	- d'avoir les droits en lecture dans ce répertoire.




- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Code navigateur :
	
	```txt
	<Champ Image> = RépertoireWeb() + <Nom image>
	```

	**Remarque** : Dans l'onglet "Détail" de la fenêtre de description du champ Image, il est possible de définir par compatibilité, le type d'affectation en code navigateur. Si cette option correspond à "Chemin dans le répertoire _WEB", la fonction [RépertoireWeb](../WDLang2/3012015.md) est inutile. Il est possible d'utiliser directement la syntaxe :
	
	```txt
	<Champ image> = <Nom image>
	```
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=image_option_nav16.gif&type=thumb)


**Remarque** : Si le champ est associé à une rubrique d'un fichier de données, l'affectation est automatiquement réalisée en utilisant la fonction [FichierVersPage](../WDLang4/3044148.md). Pour plus de détails, consultez [Lier un champ Image à une rubrique](../WDChamp/1013135.md).

## Récupérer le nom du fichier image affiché dans le champ Image
<a name="recuperer_nom_fichier_image_affiche_dans_champ_image_ELTTEXTE000354"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Dans une fenêtre
<a name="dans_une_fenetre_ELTPARAGRAPHE000095"></a>**Pour récupérer le nom de l'image affichée dans un champ Image :**

- réalisez une simple affectation. Par exemple :
	
	```wl
	SAI_ContenuActuelImage = IMG_Image1
	```


- récupérez une partie du nom, grâce à la fonction [fExtraitChemin](../WDLang1/3036026.md). Par exemple :
	
	```wl
	NomFichierImage = fExtraitChemin(IMG_Image1, fFichier + fExtension)
	```


- utilisez la propriété [Valeur](../Proprietes/2510130.md)




**Remarque** : Pour récupérer l'image (ou son nom) dans la rubrique associée au champ Image : 

1. Si le champ est associé à une rubrique de type texte, la récupération de la valeur saisie est automatiquement réalisée en utilisant la fonction [EcranVersFichier](../WDLang4/3044146.md). Il est aussi possible d'utiliser la notation CLIENT.NOM = SAI_Saisie1.

2. Si le champ est associé à un mémo binaire, utilisez la fonction [HAttacheMémo](../WDLang4/3044173.md) pour associer le fichier image à la rubrique.

3. Si le champ Image a été affecté à partir d'une variable de type buffer ou de type chaîne, la propriété [Valeur](../Proprietes/2510130.md) renvoie une chaîne vide.
	Pour plus de détails, consultez [Lier un champ Image à une rubrique](../WDChamp/1013135.md).



<a name="NOTE3_2"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Dans une page
<a name="dans_une_page_ELTPARAGRAPHE000137"></a>**Pour récupérer le nom de l'image affichée dans un champ Image** :

- réalisez une simple affectation. Par exemple :
	
	```wl
	SAI_ContenuActuelImage = IMG_Image1
	```


- utilisez la propriété [Valeur](../Proprietes/2510130.md).

- utilisez la propriété [Libellé](../Proprietes/2510053.md) (code serveur uniquement).




![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Dans un code serveur, ces syntaxes permettent d'obtenir le nom de l'image défini dans l'onglet "Général" du champ. 
Exemple : ./fond.bmp![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Dans un code navigateur, ces syntaxes permettent d'obtenir le nom complet de l'image sur le serveur.

Exemple : http://localhost/annuaire_Web/fond_fr.gif**Remarque** : Pour récupérer l'image (ou son nom) dans la rubrique associée au champ Image,

1. Si le champ est associé à une rubrique de type texte, la récupération de la valeur saisie est automatiquement réalisée en utilisant la fonction [PageVersFichier](../WDLang4/3044022.md). Il est aussi possible d'utiliser la notation CLIENT.NOM = SAI_Saisie1.

2. Si le champ est associé à un mémo binaire, utilisez la fonction [HAttacheMémo](../WDLang4/3044173.md) pour associer le fichier image à la rubrique.
	Pour plus de détails, consultez [Lier un champ Image à une rubrique](../WDChamp/1013135.md).

## Vider ou réinitialiser le contenu d'un champ Image
<a name="vider_reinitialiser_contenu_champ_image_ELTTEXTE000408"></a>
Pour vider ou réinitialiser un champ Image, il suffit d'affecter une chaîne vide au champ Image. Par exemple : 

```wl
IMG_MonImage = ""
```

**Remarque** : Il est également possible d'utiliser les fonctions [dDébutDessin](../WDLang1/3029009.md)/[dFinDessin](../WDLang1/3029019.md) sur le champ Image.
