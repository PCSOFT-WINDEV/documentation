## Présentation
<a name="presentation_ELTTEXTE000135"></a>
Pour manipuler un champ Editeur de code par programmation, WINDEV et WEBDEV proposent les [Fonctions de gestion du champ Editeur de code](../WDLang1/1410090410.md). 

Cette page d'aide détaille comment manipuler un champ Editeur de code par programmation. 





## Manipuler le champ Editeur de code par programmation
<a name="manipuler_champ_editeur_code_par_programmation_ELTTEXTE000159"></a>
Pour manipuler un champ Editeur de code par programmation, il suffit d'utiliser directement la variable du champ dans le code.

La variable du champ Editeur de code correspond au nom du champ Editeur de code. 


### Initialiser le champ Editeur de code
<a name="initialiser_champ_editeur_code_ELTPARAGRAPHE000025"></a>Pour affecter directement un code WLangage au champ Editeur de code par programmation, il est possible de : 

- utiliser une affectation directe avec une chaîne multiligne. Par exemple : 
	
	```wl
	EDCODE_Exemple = [
	Res est une chaîne
	ChaîneAConvertir est une chaîne = "Crème brûlée"
	Res = AnsiVersOem(ChaîneAConvertir)
	Info(Res)
	]
	```


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) utiliser la fonction [EditeurCodeCharge](../WDLang1/1410090372.md). Cette fonction permet de charger le code WLangage présent dans un fichier. 



![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Définir les fonctions autorisées ou non dans le champ Editeur de code
<a name="definir_les_fonctions_autorisees_non_dans_champ_editeur_code_ELTPARAGRAPHE000042"></a>La propriété [Compilateur](../Proprietes/1410090383.md) permet de définir et de connaître les paramètres de compilation du champ Editeur de code, notamment les fonctions autorisées et les fonctions interdites.

L'exemple suivant permet par exemple d'autoriser toutes les fonctions WLangage sauf la fonction **fSupprime** : 

```wl
EDCODE_Exemple.Compilateur.FonctionsAutorisées = ToutesLesFonctions
EDCODE_Exemple.Compilateur.FonctionsInterdites = "fSupprime"
```



### Effectuer une sélection dans le champ Editeur de code
<a name="effectuer_une_selection_dans_champ_editeur_code_ELTPARAGRAPHE000053"></a>Les propriétés [Curseur](../Proprietes/2510025.md) et [FinCurseur](../Proprietes/2510047.md) permettent de réaliser simplement une sélection par programmation dans le champ Editeur de code. 
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Gestion du Undo / Redo
<a name="gestion_undo_redo_ELTPARAGRAPHE000066"></a>Il est possible de gérer par programmation le "Undo / Redo" dans le champ Editeur de code grâce à la fonction [FAAExécute](../WDLang1/1000022099.md) avec les constantes *faaUndo* et *faaRedo*. 

Exemple : 

```wl
FAAExécute(EDCODE_MonCode, faaUndo)
FAAExécute(EDCODE_MonCode, faaRedo)
```






## Propriétés spécifiques au champ Editeur de code
<a name="proprietes_specifiques_champ_editeur_code_ELTTEXTE000209"></a>
Les propriétés suivantes sont spécifiques à la gestion des caractéristiques d'un champ Editeur de code par programmation.




|   |   |
| --- | --- |
| [Compilateur](../Proprietes/1410090383.md) | La propriété **Compilateur** permet de définir et de connaître les paramètres de compilation du champ Editeur de code, notamment les fonctions autorisées et les fonctions interdites. |
| [CurseurLigne](../Proprietes/1410090384.md) | La propriété **CurseurLigne** permet de connaître et modifier le numéro de ligne où se trouve le curseur dans un champ Editeur de code. |





Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Editeur de code, consultez [Propriétés associées au champ Editeur de code](../WDChamp/1410087304.md).
