


## Animation d'un champ Graphe
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000182"></a>
L'animation du champ Graphe permet de proposer un affichage dynamique dans vos applications. 

Par exemple, au premier affichage d'un graphe de type Histogramme, chaque barre semble jaillir de l'axe des abscisses. L'animation est également effectuée lorsqu'une valeur est modifiée. 

L'animation du champ Graphe est définie sous l'éditeur dans l'onglet ["Détail"](../WDChamp/3042080.md) de la fenêtre de description du champ.

<a name="NOTE2_1"></a>


## Mise en place
<a name="mise_place_ELTTEXTE000206"></a>


### Animer un champ Graphe
<a name="animer_champ_graphe_ELTPARAGRAPHE000042"></a>Pour animer un champ Graphe : 

1. Affichez la fenêtre de description du champ Graphe.

2. Dans l'onglet "Détail" : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Dans la zone "Animations des graphes 2D", cochez l'option "Activer les animations". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Graphe_Animation_WD%20-%20HC%20N%B0001.gif)


	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Dans la zone "Animations", cochez l'option "Activer les animations".

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Dans la zone "Interactivité", cochez l'option "Graphe interactif" si nécessaire puis l'option "Activer les animations".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Graphe_Animation_WB.gif)
**Remarque** : L'option "Graphe interactif" permet d'obtenir des graphes réagissant aux actions de l'internaute. Par exemple, dans un graphe de type Secteur, la part survolée est automatiquement excentrée, la part cliquée est positionnée en bas du graphe, la valeur sélectionnée dans la légende est rendue invisible, ...
			![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Seuls les graphes interactifs sont disponibles.

3. Validez la fenêtre de description du champ. 




Remarques : 

- Cette option est disponible pour les types de graphes suivants : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Aire, Bulle, Courbe, Donut, Histogramme, MinMax, Radar, Secteur,  Waterfall. 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Aire, Bulle, Courbe, Donut, Histogramme, Secteur.

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Aire, Courbe, Histogramme, Histogramme empilé, Secteur, Donut, Hémicycle.




- L'animation effectuée sur les champs Graphe dépend du type de graphe affiché. Cette animation ne peut pas être paramétrée. 

- Par défaut, l'animation d'un champ Graphe dure 30 millisecondes. 

- Si un champ Graphe est animé, l'animation sera également effectuée lors du dessin du graphe en cas de changement d'une valeur (fonction [grDessine](../WDLang3/3042026.md)).  

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) La fonction [grDessine](../WDLang3/3042026.md) n'est pas bloquante. Si le graphe est dessiné avec une animation, la fonction rendra la main dès le début de l'animation. Ainsi, si plusieurs graphes sont affichés dans la même fenêtre, il est possible d'animer ces champs simultanément.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Par défaut, les champs Graphe créés à partir de la version 19 sont animés. 



<a name="NOTE2_2"></a>


### Modifier ou supprimer l'animation par programmation
<a name="modifier_supprimer_animation_par_programmation_ELTPARAGRAPHE000121"></a>La propriété [DuréeAnimation](../Proprietes/1000021069.md) permet de : 

- Connaître et modifier la durée de l'animation effectuée dans un champ Graphe. 
	
	```wl
	// Augmentation du délai
	GRF_MonGraphe.DuréeAnimation = 2000
	```


- Annuler l'animation d'un champ Graphe. Il suffit pour cela de changer la durée de l'animation en lui donnant une valeur nulle. 
	
	```wl
	// Arrête l'animation temporairement
	GRF_MonGraphe.DuréeAnimation = 0
	```
