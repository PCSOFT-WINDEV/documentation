## Présentation du champ Zone répétée
<a name="presentation_champ_zone_repetee_ELTTEXTE000355"></a>
Un champ Zone répétée permet de répéter des champs présents dans une zone définie. Plus précisément, un champ Zone répétée est un champ "conteneur" qui permet de répéter plusieurs fois l'ensemble de champs (champs de saisie, libellés, combos, etc.) qu'il contient.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ZR_Verticale.gif)
Le champ Zone répétée permet de simplifier l'affichage et la saisie d'informations.

Par rapport au champ Table, le champ Zone répétée permet d'obtenir des interfaces beaucoup plus riches, tous les types de champs pouvant être répétés. 

Les informations affichées dans le champ Zone répétée peuvent :

- être déterminées par programmation : on parle alors de champ ***Zone répétée par programmation***.

- provenir d'un fichier de données ou d'une requête : on parle alors de champ ***Zone répétée fichier***.

- provenir d'une variable WLangage : on parle alors de champ ***Zone répétée sur variable***. 








Remarques : 

- Selon les plateformes, les champs Zone répétée peuvent être affichés : 

	- verticalement (cas par défaut sous toutes les plateformes). 

	- horizontalement. 
			En WEBDEV, ce type de champ correspond aux [Champs Zone répétée linaire](../WDChamp/9500203.md).  




- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) sous forme de [galerie d'images](../WDChamp/1013319.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) La fonctionnalité "Tirer pour rafraîchir" (Pull to Refresh) est disponible sur le champ Zone répétée sous Android et iOS. Pour plus de détails, consultez [Pull to Refresh sur les champs Table et Zone répétée (Android/iOS)](../WDChamp/9000156.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Les téléphones ou tablettes disposent souvent d'une touche "Suivant" permettant de passer à la saisie d'un élément suivant. Dans le cas d'un champ de saisie dans un champ Zone répétée, il n'est pas possible d'utiliser cette touche pour passer à la modification de la répétition suivante, ou pour permettre la saisie en cascade. Il est nécessaire de créer une interface spécifique permettant de réaliser ce type de saisie.

## Création d'un champ Zone répétée
<a name="creation_champ_zone_repetee_ELTTEXTE000379"></a>
Pour créer un champ de type Zone répétée :

1. Sous le volet "Création", dans le groupe "Données" : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) déroulez "Zone répétée" et sélectionnez "Zone répétée (verticale)".
			![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Remarque : Il est possible de créer une zone répétée horizontale grâce à l'option "Zone répétée horizontale". 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) déroulez "Zone répétée" et sélectionnez "Zone répétée". 
			Remarque : Il est possible de créer une zone répétée de type Galerie grâce aux options "Galerie en ligne" et "Galerie en colonne". 




2. Cliquez dans la fenêtre ou dans la page à la position où le champ doit être créé. L'assistant de création d'un champ Zone répétée se lance automatiquement.




**Remarques** : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z : le champ retrouvera sa taille par défaut. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) L'assistant de création de fenêtres pour iPhone et iPad permet également de créer des zones répétées prédéfinies. Pour plus de détails, consultez [Fenêtres pour iPhone et iPad](../WDChamp/9000133.md).




**Pour afficher les caractéristiques du champ**, sélectionnez l'option "Description" dans le menu contextuel du champ. 

Pour plus de détails : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) [Caractéristiques d'un champ Zone répétée présent dans une fenêtre](../WDChamp/1013294.md). 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) [Caractéristiques d'un champ Zone répétée présent dans une page](../WDChamp/1013293.md).

### Création d'un champ Zone répétée horizontal
<a name="creation_champ_zone_repetee_horizontal_ELTPARAGRAPHE000155"></a>Il est également possible de créer des champs Zone répétée horizontale. Dans ce cas, le champ possédera un ascenseur horizontal pour faire défiler les différentes répétitions. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ZR_Horizontale.gif)
Pour créer un champ de type Zone répétée horizontale :

1. Sous le volet "Création", dans le groupe "Données", déroulez "Zone répétée" et sélectionnez "Zone répétée horizontale".

2. Cliquez dans la fenêtre ou dans la page à la position où le champ doit être créé. L'assistant de création d'un champ Zone répétée se lance automatiquement.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ. 

Pour plus de détails, consultez [Caractéristiques d'un champ Zone répétée présent dans une fenêtre](../WDChamp/1013294.md).

## Attributs d'un champ Zone répétée
<a name="attributs_champ_zone_repetee_ELTTEXTE000409"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Attributs d'un champ Zone répétée en WEBDEV
<a name="attributs_champ_zone_repetee_webdev_ELTPARAGRAPHE000190"></a>Un champ Zone répétée est composé de :

- **champs**, répétés à chaque répétition.

- **attributs**. Un attribut permet de définir la caractéristique du champ qui sera modifiée à chaque répétition. Par exemple, si à chaque répétition, le champ PRIX doit changer de valeur et de couleur, il sera nécessaire de définir deux attributs différents sur le même champ.




Pour connaître ou modifier la caractéristique d'un champ (sa valeur, sa couleur, etc.), il suffit de manipuler ce champ ou l'attribut correspondant par programmation.
<a name="NOTE2_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 

### Attributs d'un champ Zone répétée en WINDEV ou WINDEV Mobile
<a name="attributs_champ_zone_repetee_windev_windev_mobile_ELTPARAGRAPHE000204"></a>Un champ Zone répétée est composée de champs, répétés à chaque répétition.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) Le contenu des champs Table ou Graphe par exemple peut être différent à chaque répétition. Pour plus de détails, consultez [Afficher un contenu différent à chaque répétition](../WDChamp/1013289.md).

Pour connaître ou modifier la caractéristique d'un champ (sa valeur, sa couleur, etc.), il suffit de manipuler directement ce champ par programmation.

**Remarque** : Par compatibilité avec WEBDEV, il est également possible d'utiliser des attributs. Dans ce cas, pour connaître ou modifier la caractéristique d'un champ (sa valeur, sa couleur, etc.), il suffit de manipuler ce champ ou l'attribut correspondant par programmation.

## Vocabulaire
<a name="vocabulaire_ELTTEXTE000439"></a>
Pour manipuler simplement un champ Zone répétée, il est nécessaire de connaître le vocabulaire suivant :

| Nom | Définition |
| --- | --- |
| Attribut | Un attribut correspond à l'association entre le champ présent dans la zone répétée et la propriété modifiable pour ce champ à chaque répétition.<br>Pour chaque attribut, il est nécessaire de définir :<br><br>- le nom de l'attribut.<br><br>- le nom du champ de la zone répétée.<br><br>- la propriété du champ qui pourra être modifiée à chaque répétition (valeur, couleur, etc.).<br><br><br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) **Rappel** : Les attributs ne sont pas obligatoires. |
| Zone répétée Fichier | Le champ Zone répétée est basé sur un fichier de données ou une requête. A chaque répétition, un enregistrement du fichier de données est affiché. Deux types de champs Zone répétée fichier sont disponibles :<br><br>- ***Zone répétée fichier "Chargé en mémoire"*** : Le contenu du champ est chargé en mémoire puis affiché. L'accès aux différents éléments du champ est plus rapide. Ce mode est réservé pour des fichiers de données de moins de 100 000 enregistrements.<br><br>- ***Zone répétée fichier "Accès direct (sans limite)"*** : Le champ Zone répétée affiche directement le contenu du fichier de données ou de la requête. L'enregistrement en cours correspond à l'élément sélectionné. Chaque déplacement dans le champ entraîne un accès au fichier de données lié. Ce mode est réservé aux fichiers de données de plus de 100 000 enregistrements.<br><br><br> |
| Zone répétée par programmation | Le champ Zone répétée n'est basé ni sur un fichier de données ni sur une requête. Les éléments affichés dans le champ sont déterminés par le développeur (par programmation). |
| Zone répétée sur variable | Le champ Zone répétée est basé sur une variable (globale au projet, à la fenêtre ou à la page, membre de classe, etc.). |

## Notes
<a name="notes_ELTTEXTE000463"></a>


### Permuter un champ Table et un champ Zone répétée
<a name="permuter_champ_table_champ_zone_repetee_ELTPARAGRAPHE000267"></a>WINDEV, WINDEV Mobile et WEBDEV permettent de transformer automatiquement un champ Table en un champ Zone répétée : 

1. Sélectionnez le champ Table à transformer. 

2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez l'option "Table vers Zone Répétée".



<a name="NOTE5_2"></a>


### Refactoring : créer un champ Zone répétée à partir des champs sélectionnés
<a name="refactoring_creer_champ_zone_repetee_partir_des_champs_selectionnes_ELTPARAGRAPHE000289"></a>WINDEV, WINDEV Mobile et WEBDEV permettent de créer automatiquement un champ Zone répétée à partir des champs actuellement sélectionnés :

1. Sélectionnez les champs voulus. 

2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez l'option "Créer une zone répétée avec la sélection".
