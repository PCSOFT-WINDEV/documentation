## Les différents types de champs de saisie
<a name="les_differents_types_champs_saisie_ELTTEXTE000302"></a>


### Champ de saisie de type Texte
<a name="champ_saisie_type_texte_ELTPARAGRAPHE000011"></a>Ce type de champ de saisie permet d'afficher ou de saisir une chaîne de caractères (nom, adresse, ...).

Remarques : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Les champs de saisie de type Texte peuvent afficher un bouton de suppression (une croix). Ce bouton permet à l'utilisateur de supprimer le contenu du champ. Ce bouton peut être affiché dans la zone de saisie : 

	- uniquement lorsqu'une saisie est effectuée dans le champ. 

		- uniquement lorsque le champ perd le focus. 
						![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Remarque : Sous iOS 7 uniquement, la croix apparaît tout de même lors de la saisie dans le champ. 

		- toujours (que le curseur de saisie soit dans le champ ou non). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Il est possible de saisir des Emojis dans le champ de saisie. Si les informations saisies doivent être enregistrées dans une base de données, il est nécessaire que la rubrique liée soit Unicode (chaîne ou mémo texte Unicode) pour conserver les Emojis.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Lorsqu'un champ de saisie texte est agrandi sous l'éditeur, il se transforme automatiquement en champ de saisie multiligne.



<a name="NOTE1_2"></a>


### Champ de saisie de type Texte multiligne
<a name="champ_saisie_type_texte_multiligne_ELTPARAGRAPHE000041"></a>Ce type de champ de saisie permet d'afficher ou de saisir plusieurs lignes séparées par un "Retour Chariot".

Remarques : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Si les lignes sont séparées par un "Retour Chariot", il est possible d'afficher un ascenseur vertical ou horizontal.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Il est également possible d'afficher les adresses internet et les chemins de fichiers sous forme de lien.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Lorsqu'un champ de saisie texte est agrandi sous l'éditeur, il se transforme automatiquement en champ de saisie multiligne.



<a name="NOTE1_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Champ de saisie de type Texte RTF
<a name="champ_saisie_type_texte_rtf_ELTPARAGRAPHE000062"></a>Ce type de champ de saisie permet de saisir et d'afficher des informations au format RTF. Pour plus de détails, consultez [Manipuler un champ de saisie au format RTF](../WDChamp/1013190.md).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Pour les applications fonctionnant sous Windows Vista (ou supérieur) ou sous Tablet PC, il est possible d'intégrer l'option "Saisie manuscrite (Tablet PC)". Cette option permet à l'utilisateur de saisir directement le texte dans le champ à l'aide du stylet ou de la souris. Cette fonctionnalité existe par défaut dans les applications fonctionnant sous Mobile.
<a name="NOTE1_4"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Champ de saisie de type Texte HTML
<a name="champ_saisie_type_texte_html_ELTPARAGRAPHE000082"></a>Ce type de champ permet de mettre en page des textes avec enrichissement.

Caractéristiques : 

- Une barre d'outils apparaît automatiquement au-dessus du champ pour permettre de saisir les enrichissements (liens, gras, italique, ...).

- Pour saisir une image dans ce type de champ, il est nécessaire d'indiquer l'adresse de l'image. 

- Les liens présents dans le champ ne peuvent pas être testés directement par l'utilisateur. Les liens seront effectifs si le contenu du champ texte HTML est affiché dans un champ HTML.




Pour plus de détails, consultez [Manipuler un champ de saisie au format HTML](../WDChamp/9500112.md).
<a name="NOTE1_12"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Champ de saisie de type Visualisation Markdown
<a name="champ_saisie_type_visualisation_markdown_ELTPARAGRAPHE000104"></a>Ce type de champ de saisie permet d'afficher des informations au format Markdown. Ces informations en affichage peuvent être sélectionnées ou scrollées. 

Rappel : L'option "Gestion du Markdown" présente dans l'onglet "UI" de la fenêtre de description des champs de saisie s'applique uniquement au libellé, à la bulle et aux jetons associés au champ de saisie. Cette propriété ne s'applique pas au contenu du champ de saisie.

Pour modifier le type du champ de saisie (passer par exemple d'un champ de saisie de type Texte à un champ de saisie de type Visualisation Markdown), utilisez la propriété [VisualisationMarkdown](../Proprietes/1410089587.md).
<a name="NOTE1_5"></a>


### Champ de saisie de type Mot de passe
<a name="champ_saisie_type_mot_passe_ELTPARAGRAPHE000122"></a>Avec ce type de champ de saisie, lors de la saisie d'informations dans le champ, tous les caractères seront remplacés par des étoiles à l'écran. 

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/us/WBN.png) Pour éviter les failles de sécurité, il est déconseillé d'affecter un champ de saisie de type Mot de passe par programmation. En effet, même si l'icône permettant d'afficher le mot de passe est invisible, le contenu du champ peut être lu par des outils de débogage. 



![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) L'utilisateur a la possibilité de vérifier le mot de passe saisi (FAA). Pour plus de détails, consultez [Voir en clair un mot de passe (FAA)](../WDChamp/9500129.md). 
<a name="NOTE1_6"></a>


### Champ de saisie de type Numérique, Monétaire ou Monétaire + Euro
<a name="champ_saisie_type_numerique_monetaire_monetaire_euro_ELTPARAGRAPHE000143"></a>Ces différents types de champs permettent de manipuler des valeurs numériques : 

- Le champ de saisie Numérique permet d'afficher ou de saisir une valeur numérique (poids, ...). Si le champ n'est pas assez grand pour afficher le chiffre en entier, les caractères "+++" sont affichés.

- Le champ de saisie Monétaire permet d'afficher ou saisir des valeurs monétaires.

- Le champ de saisie Monétaire + Euro permet de gérer des prix par exemple.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Ce type de champ de saisie n'est pas disponible.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Les champs de saisie numériques, monétaires et monétaires + Euro proposent d'afficher un bouton **calculatrice** pour permettre à l'utilisateur de réaliser un calcul (option "Afficher le bouton calculatrice"). Il existe également diverses FAA (Fonctionnalités Automatiques de vos Applications) sur ce type de champ (modification de la valeur à l'aide de la roulette de la souris par exemple). Pour plus de détails, consultez [FAA sur les champs numériques](../Editeurs/9500122.md).
<a name="NOTE1_7"></a>


### Champ de saisie de type Date
<a name="champ_saisie_type_date_ELTPARAGRAPHE000171"></a>Ce type de champ de saisie permet d'afficher ou de saisir des dates.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) L'utilisateur pourra utiliser les touches "+" et "-" du clavier numérique pour modifier la date.
Si le champ n'est pas dans une popup, il est possible d'afficher un bouton calendrier pour permettre à l'utilisateur de saisir la date (option "Afficher un bouton calendrier"). Dans ce cas, il est possible de définir les caractéristiques du calendrier. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) ***FAA (Fonctionnalité Automatique de vos Applications)*** : Si le bouton calendrier n'est pas affiché, l'utilisateur pourra tout de même saisir la date dans un calendrier (option "Calendrier" du menu contextuel du champ). Pour supprimer cette FAA, utilisez la fonction [FAADésactive](../WDLang1/1000022018.md) avec la constante *faaCalendrier*. Pour plus de détails, consultez [FAA sur les champs Date](../Editeurs/9500124.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Pour utiliser un rouleau pour saisir la date, le masque de saisie doit être de type : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) "Rouleau Date", 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) "Rouleau Date et heure".
