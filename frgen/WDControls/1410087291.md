
## Editeur de diagrammes (WEBDEV) : Fonctionnalités
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000134"></a>
Le champ Editeur de diagrammes de WEBDEV propose de nombreuses fonctionnalités accessibles via : 

- Le ruban : ouvrir, enregistrer, rechercher, imprimer, ...

- Le panneau "Bibliothèque" qui liste les différents éléments utilisables dans le diagramme. 

- Le panneau "Modifieur" qui permet de modifier et paramétrer l'élément en cours.  




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Le ruban
<a name="ruban_ELTTEXTE000158"></a>
Le ruban du champ Editeur de diagrammes disponible en WEBDEV permet d'effectuer toutes les manipulations de base sur un diagramme. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001.gif&type=thumb)
Ce ruban propose les options suivantes : 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%201.gif) : Annuler/refaire la dernière action. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%202.gif) : Ouvrir un diagramme existant. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%203.gif) : Enregistrer (télécharger) une copie du diagramme actuellement affiché sous l'éditeur. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%204.gif) : Exporter en tant qu'image (format PNG et SVG). 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%205.gif) : Imprimer le diagramme en cours. L'aperçu avant impression s'ouvre et permet de sélectionner le mode d'impression. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%206.gif) : Reproduire le style d'un élément sur un autre. 
	Pour utiliser cette option, il suffit de : 

	1. Sélectionner l'élément dont la mise en forme doit être copiée. 

	2. Cliquer sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%206.gif). 

	3. Cliquer sur l'élément voulu. La mise en forme de l'élément de départ sera appliqué à l'élément d'arrivée. 




- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%208.gif) : Afficher ou non la grille. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2011.gif) : Positionner l'élément sélectionné en premier plan, arrière plan, monter ou descendre l'élément sélectionné, ... 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2012.gif) : Grouper / Dégrouper les éléments sélectionnés. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%2010.gif) : Réaliser un dessin à main levée.

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%209.gif) : Gérer le Zoom : Zoom avant, zoom arrière, 100%, zoom adapté à la fenêtre. 

- <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0001%207.gif)
 : Réaliser une recherche dans les différents textes du diagramme.

## Panneau "Bibliothèque"
<a name="panneau_bibliotheque_ELTTEXTE000182"></a>
Le panneau "Bibliothèque" permet d'afficher les différents éléments qui pourront être insérés dans le diagramme. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0002%201.gif)


Chaque volet du panneau bibliothèque correspond à un diagramme. Ce diagramme contient les différents éléments ou images qui peuvent être ré-utilisés dans l'éditeur de diagrammes.  

<a name="NOTE4"></a>
<a name="NOTE4_1"></a>


## Panneau "Modifieur"
<a name="panneau_modifieur_ELTTEXTE000206"></a>
Le panneau "Modifieur" permet d'avoir des informations sur l'élément sélectionné et si nécessaire permet de modifier ces informations. <br>![Caractéristiques de la page](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champ_diagramme_WB%20-%20HC%20N%B0002.gif)


Il est ainsi possible via le panneau "Modifieur" de : 

- Mettre en forme le texte d'une zone de texte : police, taille, position, etc.

- Définir les caractéristiques d'une forme : Couleur de fond, couleur de bordure, style de bordure, etc.

- Définir les caractéristiques des liens : routage, style de l'image de départ, style de l'image d'arrivée, etc.

- Définir les options de la page, etc.
