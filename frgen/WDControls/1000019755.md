## Présentation du champ Carte
<a name="presentation_champ_carte_ELTTEXTE000392"></a>
Le champ Carte permet d'afficher une carte afin de se géolocaliser, d'afficher des points d'intérêt (P.O.I), ... 

Cette carte provient : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) du service Google Maps pour les applications Android. 
	**Attention** : L'utilisation d'un champ Carte est soumise à des conditions d'utilisation spécifiques. Pour plus de détails, consultez la page d'aide [Conditions d'utilisation du champ Carte](../WDChamp/1000019823.md). Vérifiez la licence Google avant de déployer vos applications. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) du service géolocalisation de Apple pour les applications iPhone/iPad. 
	Remarques : Il est nécessaire de se conformer à la licence du service utilisé. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) du service Google Maps pour les sites Web via Google Maps API. 
	L'utilisation du champ Carte est soumis à des conditions d'utilisations spécifiques. Selon le mode d'utilisation, il peut être nécessaire d'utiliser une clé Google (fonction [CarteLicenceGgl](../WDLang3/1000021299.md)). Vérifiez la licence Google avant de déployer vos applications. ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Attention : L'utilisation du champ Carte impose l'utilisation de Windows 10 minimum pour le poste utilisateur. 




La carte affichée est interactive : il est possible de zoomer, de se déplacer, etc. Elle peut être affichée sous forme graphique ou sous forme de vue satellitaire. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ModeCarte.gif)

## Création et description du champ Carte
<a name="creation_description_champ_carte_ELTTEXTE000416"></a>
<a name="NOTE1_2"></a>


### Créer un champ de type Carte
<a name="creer_champ_type_carte_ELTPARAGRAPHE000075"></a>Pour créer un champ de type Carte : 

1. Sous le volet "Création", dans le groupe "Champs graphiques", cliquez sur "Carte".

2. Cliquez dans la fenêtre ou la page à la position où le champ doit être créé.





### Description du champ Carte
<a name="description_champ_carte_ELTPARAGRAPHE000095"></a>**Pour afficher les caractéristiques du champ**, sélectionnez l'option "Description" dans le menu contextuel du champ. 
L'onglet "Général" permet de définir : 

- le mode d'affichage : plan ou satellite, 

- l'affichage ou non des informations concernant le trafic.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) l'affichage ou non des boutons de zoom dans le champ, 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) l'affichage de la boussole.

- l'image utilisée pour les marqueurs des points d'intérêt (P.O.I.). 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Ces marqueurs peuvent être affichés avec une ombre ou non. 

- la popup affichée par défaut lors du clic sur un marqueur. Cette popup peut correspondre à : 

	- Aucune : la popup utilisée sera celle proposée par défaut. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Fenêtre prédéfinie : Dans ce cas, une fenêtre interne est automatiquement intégrée dans votre projet. 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Page prédéfinie : Dans ce cas, une page interne est automatiquement intégrée dans votre projet. 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) une fenêtre interne de votre projet.

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) une page interne de votre projet. 







L'onglet "Détail" permet de définir : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) la mise à l'échelle par double clic,

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) les options de gesture :

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Autoriser le zoom.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Autoriser la rotation.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Autoriser le scroll. 

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Autoriser l'inclinaison. 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) autoriser la mise à l'échelle par double tap.




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) la mémorisation de la dernière position affichée.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) L'identifiant unique de personnalisation de la carte Google affichée dans le champ. Pour plus de détails, consultez [Personnaliser l'apparence d'une carte Google Maps](../WDChamp/1000019827.md). 
	




**Remarques** : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Un seul champ Carte peut être utilisé dans une fenêtre. Il n'est pas possible d'utiliser plusieurs champs Carte dans la même fenêtre. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Le champ Carte n'est pas manipulable par les tests automatiques. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) La fonction [géoLanceAppli](../WDLang3/1000019954.md) permet de lancer l'application de cartographie native de l'appareil.

### Popup d'affichage des marqueurs
<a name="popup_affichage_des_marqueurs_ELTPARAGRAPHE000192"></a>Lors de l'utilisation d'une fenêtre prédéfinie ou d'une page prédéfinie pour gérer la popup des marqueurs, les éléments suivants sont intégrés selon la plateforme utilisée : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) la fenêtre interne FI_WinDevPopupMarqueur_WD (cette fenêtre est contenue dans le composant WDFAA).

- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) la fenêtre interne FI_WinDevPopupMarqueur_WM (cette fenêtre est contenue dans le composant WDFAA).

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) la page interne PI_WEBDEVPopupMarqueur.




Ces éléments contiennent : 

- deux champs permettant d'afficher le nom et la description du marqueur. 

- un code de déclaration permettant de manipuler la variable de type Marqueur en cours.

## Affichage et manipulation des cartes
<a name="affichage_manipulation_des_cartes_ELTTEXTE000461"></a>


### Affichage des cartes
<a name="affichage_des_cartes_ELTPARAGRAPHE000216"></a>A l'ouverture de la fenêtre contenant un champ Carte, une carte du monde est automatiquement affichée : la carte est centrée sur l'Europe avec un niveau de zoom moyen.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Il est possible d'afficher la dernière position mémorisée : il suffit de sélectionner l'option "Mémoriser la dernière position affichée" dans l'onglet "Détail" de la fenêtre de description du champ Carte. Dans ce cas, la dernière position est affichée avec le même niveau de zoom.


### Manipulation des cartes par l'utilisateur
<a name="manipulation_des_cartes_par_utilisateur_ELTPARAGRAPHE000229"></a>L'utilisateur peut se déplacer dans la carte : 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) en la faisant défiler avec un ou plusieurs doigts. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) en la faisant défiler à l'aide de la souris.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) via les boutons de positionnement du champ (si l'option "Afficher les boutons de zoom" a été sélectionnée dans l'onglet "Général" de la fenêtre de description du champ). 




L'utilisateur peut zoomer ou dé-zoomer : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) en utilisant les boutons de zoom du champ (si l'option a été sélectionnée dans l'onglet "Général" de la fenêtre de description du champ). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) en effectuant un geste de type "scale" (ou "pinch") : un écartement de deux doigts sur l'écran permet de zoomer et un rapprochement de deux doigts sur l'écran permet de dé-zoomer. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) en effectuant un "double tap" sur la carte pour zoomer d'un niveau sur une position (si l'option a été sélectionnée dans l'onglet "Général" de la fenêtre de description du champ). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) en effectuant un double-clic sur la carte pour zoomer d'un niveau sur une position (si l'option a été sélectionnée dans l'onglet "Général" de la fenêtre de description du champ). 

- par programmation avec la propriété [Zoom](../Proprietes/1000017201.md). 


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Si l'option de gesture "Autoriser le zoom" est désactivée (option de l'onglet "Détail" de la description du champ ou propriété [AvecZoom](../Proprietes/1000020554.md)), l'utilisateur ne pourra pas zoomer ou dézoomer.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Remarque : Des événements optionnels spécifiques au champ Carte peuvent également être utilisés. Pour plus de détails, consultez [Evénements associés au champ Carte](../WDChamp/1000019819.md).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Pour connaître toutes les manipulations disponibles en exécution, consultez [Champ Carte : Fonctionnalités Automatiques de vos Applications (FAA)](../WDChamp/1000019824.md).
