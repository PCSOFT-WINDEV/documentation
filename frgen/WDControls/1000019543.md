
## Champ Planning lié à une table ou une variable
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000139"></a>
Il est possible de créer des champs Planning directement liés aux données. Vous pouvez créer : 

- un **champ Planning lié aux données** : le champ Planning sera lié à une table ou à une requête. Dans ce cas, la table contient les caractéristiques des rendez-vous. 

- un **champ Planning sur variable** : le champ Planning sera lié à une variable (le plus souvent une instance de classe). Dans ce cas, la classe liste les rendez-vous avec leurs caractéristiques. 




La programmation des champs Planning est grandement simplifiée. 





## Comment le faire ?
<a name="comment_faire_ELTTEXTE000163"></a>


### Créer un champ Planning lié aux données
<a name="creer_champ_planning_lie_aux_donnees_ELTPARAGRAPHE000020"></a>

Pour créer un champ Planning lié aux données, il est possible :

- soit d'utiliser l'assistant de création du champ Planning. Il suffit de sélectionner l'option "Afficher des données d'une table ou d'une requête existante". Répondez ensuite aux questions de l'assistant et validez. 

- soit de modifier la description du champ Planning. 




Pour modifier les caractéristiques d'un champ Planning existant :

1. Affichez la fenêtre de description du champ (option "Description" du menu contextuel). 

2. Dans l'onglet "Contenu", sélectionnez l'option "Table/Requête" et sélectionnez la source de données utilisée. Cette source de données peut être : 

	- une table définie dans le schéma des données,

	- une requête du projet,

	- une requête intégrée à la fenêtre ou la page. 




3. Associez les différentes rubriques de la source de données aux caractéristiques du rendez-vous. Les éléments précédés d'une étoile sont obligatoires. 
	**Remarque** : Si la table associée ne contient pas directement la rubrique correspondante, il est possible de réaliser une liaison multitable. 

4. Validez la fenêtre de description du champ Planning. Le champ Planning est un planning lié aux données. 







### Créer un champ Planning sur variable
<a name="creer_champ_planning_sur_variable_ELTPARAGRAPHE000042"></a>

Pour créer un champ Planning sur variable, il est possible : 

- soit d'utiliser l'assistant de création du champ Planning. Il suffit de sélectionner l'option "Afficher les données d'une variable existante". Répondez ensuite aux questions de l'assistant et validez. 

- soit de modifier la description du champ Planning. 




Pour modifier les caractéristiques d'un champ Planning existant :

1. Affichez la fenêtre de description du champ (option "Description" du menu contextuel). 

2. Dans l'onglet "Contenu", sélectionnez l'option "Variable" et sélectionnez la source de données utilisée (classe, etc.). 

3. Associez les différents éléments (membres de la classe par exemple) de la source de données aux caractéristiques du rendez-vous. Les éléments précédés d'une étoile sont obligatoires. 

4. Validez la fenêtre de description du champ Planning. Le champ Planning est un planning sur variable. 








## Manipuler un champ Planning lié aux données ou un champ Planning sur variable
<a name="manipuler_champ_planning_lie_aux_donnees_champ_planning_sur_variable_ELTTEXTE000193"></a>


### Champ Planning lié aux données
<a name="champ_planning_lie_aux_donnees_ELTPARAGRAPHE000059"></a>

Un champ Planning lié aux données se manipule très simplement :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Si l'utilisateur manipule directement le planning via le menu contextuel du champ, les ajouts, suppressions, modifications des rendez-vous sont automatiquement reportés dans la table liée au champ. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Si l'utilisateur manipule directement le rendez-vous via la souris (suppression par la croix, ajout, déplacement de rendez-vous), les manipulations effectuées sont automatiquement reportées dans la table liée au champ.

- Si l'utilisateur manipule les rendez-vous via une fenêtre ou une page spécifique, il suffit de modifier directement la table liée au planning. Les données affichées seront automatiquement mises à jour. Il est également possible d'utiliser la fonction [PlanningAffiche](../WDLang1/1000019426.md) pour remettre à jour les données affichées dans le champ. 




**Remarque** : Si le champ est lié à une source de données, la suppression réalisée dans le champ est effectuée en même temps dans la source de données liée. 


### Champ Planning sur variable
<a name="champ_planning_sur_variable_ELTPARAGRAPHE000077"></a>

Un champ Planning sur variable se manipule très simplement : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Si l'utilisateur manipule directement le planning via le menu contextuel du champ, les ajouts, suppressions, modifications des rendez-vous sont automatiquement reportés dans la source de données du champ.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Si l'utilisateur manipule directement le rendez-vous via la souris (suppression par la croix, ajout, déplacement de rendez-vous), les manipulations effectuées sont automatiquement reportées dans la source de données du champ.

- Si l'utilisateur manipule les rendez-vous via une fenêtre ou une page spécifique, il suffit de modifier directement les éléments lié au planning (membres de classe par exemple). Les données affichées seront automatiquement mises à jour. Il est également possible d'utiliser la fonction [PlanningAffiche](../WDLang1/1000019426.md) pour remettre à jour les données affichées dans le champ.




**Remarque** : Si le champ est lié à une source de données, la suppression réalisée dans le champ est effectuée en même temps dans la source de données liée.
