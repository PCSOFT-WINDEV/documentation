## Description d'un champ Agenda
<a name="description_champ_agenda_ELTTEXTE000171"></a>
Le champ Agenda peut être paramétré directement sous l'éditeur grâce à la fenêtre de description (onglet "Détail"). 

Les différentes options disponibles sont les suivantes : 

- **Mode d'affichage** : Par défaut, l'affichage est réalisé à la semaine, mais il est également possible d'afficher un champ Agenda au jour ou au mois. 

- **Paramètres de l'agenda** : 

	- "Premier jour" : Premier jour affiché par le champ Agenda 

	- "Nombre de jours" : Nombre de jours affichés dans le champ Agenda pour une semaine. 

	- **Masque d'affichage de la date** : Permet de définir le format de la date affichée en haut des colonnes "jour" du champ Agenda.
			Il est également possible d'indiquer si le numéro de semaine doit être affiché ou non, ainsi que son format. Dans le format, la chaîne '%1' correspond au numéro de semaine. Exemple de format : "Sem. %1".

	- **Plage horaire** : 

		- "Plage horaire visible" : Plage horaire qui sera affichée dans le champ. 

		- "Plage horaire ouvrable" : Plage horaire pour laquelle un rendez-vous pourra être défini.  




- **Caractéristiques du rendez-vous** : 

	- "Chevauchement" : Permet de définir la gestion du chevauchement de plusieurs rendez-vous. Les rendez-vous pourront être côte à côte ou décalés.

	- "Granularité d'un rendez-vous" : Précision d'affichage du champ Agenda. Par défaut, la granularité est de 30 minutes. L'unité de granularité est :

		- la minute, 

		- l'heure, 

		- le jour.

- **Edition à la souris** : 

	- "Modification de la durée". Il est possible d'autoriser ou non l'utilisateur à modifier la durée d'un rendez-vous. 

	- "Déplacement". Il est possible d'autoriser ou non l'utilisateur à déplacer un rendez-vous.

### Supprimer un rendez-vous directement depuis le champ Agenda
<a name="supprimer_rendezvous_directement_depuis_champ_agenda_ELTPARAGRAPHE000108"></a>Par défaut, lors de la sélection d'un rendez-vous, le champ Agenda affiche une croix en haut à droite du rendez-vous : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Agenda_WB_Croix.gif)


Cette croix permet de supprimer le rendez-vous sélectionné. 

**Remarque** : Pour les champs Agenda liés à une source de données (fichier, variable, ...), la suppression d'un rendez-vous est interdite par défaut (la croix n'est pas affichée). Pour autoriser la suppression des rendez-vous : 

1. Affichez la description du champ Agenda (option "Description" du menu contextuel). 

2. Dans l'onglet "Contenu", cochez l'option "Autoriser la suppression (supprime aussi dans la source de données)". 

3. Validez.
