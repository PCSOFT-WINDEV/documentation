
## Ajouter des tables dans une réplication (ReplicEdit)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000107"></a>
Lorsque la réplication est décrite, il est nécessaire d'ajouter les tables prises en compte dans la réplication. Cette opération est réalisée à l'aide d'un assistant.

## Ajouter des tables dans une réplication
<a name="ajouter_des_tables_dans_une_replication_ELTTEXTE000131"></a>


### Ajout du fichier de base
<a name="ajout_fichier_base_ELTPARAGRAPHE000021"></a>

1. Sélectionnez l'option "Réplication .. Ajouter une table". L'assistant d'ajout d'une table se lance.

2. La liste des tables décrites dans le schéma des données en cours ou présentes sur le serveur est affichée. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ReplicEdit_FichierDeBase.gif&type=thumb)
Vous pouvez sélectionner une ou plusieurs tables à synchroniser. Par défaut, tous les enregistrements sont répliqués. 

3. Pour les tables sélectionnées, vous pouvez définir : 

	- le sens de réplication des tables : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ReplicEdit_FichierSens.gif&type=thumb)


	- la gestion des conflits de modification. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ReplicEdit_FichierConflit.gif&type=thumb)

			Il est possible de choisir : 

	- le mode par défaut défini précédemment (conseillé). 

	- un autre mode. 

4. L'assistant est terminé. La réplication est décrite. L'éditeur de réplication liste les tables prises en compte dans la réplication. 




Les tables affichées en gris sont des tables liées : une table liée est une table qui est liée à une table de base (appartenant déjà à la réplication). Selon la réplication effectuée, les données de la table liée peuvent être ajoutées ou non. 

Vous pouvez enregistrer la réplication (option "Fichier .. Enregistrer"). La réplication est enregistrée sous forme d'un fichier de type ".Wer". 

Ce fichier contient la description de la réplication. Il devra être présent à côté de l'exécutable sur les postes abonnés.


### Ajout d'une table liée
<a name="ajout_une_table_liee_ELTPARAGRAPHE000047"></a>

Pour ajouter une table liée :

1. Double-cliquez sur la table liée (affichée en gris) sous ReplicEdit. L'assistant d'ajout d'une table liée se lance.

2. Par défaut, les données de la table liée sont celles correspondantes à la table de base. Ainsi, si le fichier de base est filtré, les enregistrements du fichier lié utilisent le même filtre. 
	Remarque : Pour mettre un filtre sur le fichier de base, affichez la [description de la table](../ReplicEdit/3526506.md). 

3. Indiquez si un filtrage supplémentaire doit être effectué. Si vous ajouter un filtrage, donnez les caractéristiques nécessaires. 

4. Dans la suite de l'assistant, indiquez le sens de réplication de la table liée ainsi que le mode de gestion des conflits.

5. Terminez l'assistant. La table liée apparaît désormais en table à répliquer.
