
## ReplicEdit : Prise en compte des modifications du schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000078"></a>
Lors de la modification du schéma des données d'une application répliquée (ajout d'une rubrique, d'un fichier, ...), il est nécessaire de prendre en compte cette modification dans la description de la réplication.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000102"></a>
Pour prendre en compte les modifications effectuées dans le schéma des données dans le fichier .WER de la réplication :

1. Ouvrez le fichier .WER voulu sous ReplicEdit.

2. Sélectionnez l'option "Réplication .. Se mettre à jour de la description du schéma des données".



<a name="NOTE2_2"></a>


### Attention
<a name="attention_ELTPARAGRAPHE000026"></a>

Si les connexions définies dans le schéma des données nécessitent des mots de passe, il est nécessaire de ressaisir ces mots de passe dans ReplicEdit (pour plus de détails, consultez [Options de réplication](../ReplicEdit/3526502.md)).
