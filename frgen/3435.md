## Erreur ERR_BAD_URL
<a name="erreur_errbadurl_ELTTEXTE000081"></a>
L'url &lt;NOM_URL&gt; n'est pas valide. ERR_BAD_URL 

Ce message est affiché lors de l'utilisation d'une URL non valide dans la page HTML.

Une URL est valide sous WEBDEV si elle commence par :

- la syntaxe suivante : [%URL()%].... par exemple :
	&lt;a hRef="[%URL()%]?Table=[%TABLE%]&RENVOI"&gt;

- un signe "/" : par exemple :
	&lt;a hRef="/Img_WEB/Coucou.gif"&gt;

- le protocole http: par exemple :
	&lt;a hRef="http://flop.www/pages/Index.html "&gt;
