
## Le mode test ne peut fonctionner sans le projet, ses pages, ... 
			



## Erreur ERR_TEST_WDP
<a name="erreur_errtestwdp_ELTTEXTE000058"></a>
Un test d'un site dynamique réalisé avec WEBDEV "Version Développement" nécessite la présence du projet sur le poste (fichier .WWP). Si ce fichier n'est pas présent, le test ne peut être lancé.
