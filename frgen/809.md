## Erreur ERR_MAX_CONNECTION
<a name="erreur_errmaxconnection_ELTTEXTE000070"></a>


### La connexion est refusée car le nombre maximum de connexions autorisées (&lt;NB_CONNEXION&gt;) a été atteint. Réessayez plus tard. ERR_MAX_CONNECTION (14)
<a name="connexion_est_refusee_car_nombre_maximum_connexions_autorisees_ete_atteint_reessayez_plus_tard_errmaxconnection_14_ELTPARAGRAPHE000007"></a>

Ce message apparaît sur le navigateur Internet si le nombre de connexions aux sites dynamiques WEBDEV installés chez l'hébergeur est supérieur au nombre total de connexions simultanées autorisées.
Il est peut être nécessaire de revoir le paramétrage du serveur d'application de WEBDEV.

Rappel : Le nombre maximum global de connexions est défini pour le serveur et un site dans l'administrateur WEBDEV sur le serveur Web (onglet "Configuration").
Ce nombre de connexions peut également être limité :

- pour chaque site dans l'administrateur WEBDEV (bouton "Paramètres" de l'onglet "Sites").

- pour chaque compte de déploiement. Cette option est disponible dans le Gestionnaire de comptes WEBDEV pour les serveurs sous Windows, ou dans les réglages du compte dans l'administrateur WEBDEV sous Linux.
