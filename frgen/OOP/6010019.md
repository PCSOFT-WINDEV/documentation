
## Opérateur de conversion explicite sur les classes
			

<a name="description"></a>
L'opérateur de cast (downcast) permet d'effectuer une conversion d'une classe de base vers une classe dérivée sans utiliser de variable locale. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// appel d’une méthode de la classe dérivée
une_instance est ClasseBase <- Null
SI une_instance est ClasseDérivée ALORS
	((ClasseDérivée)une_instance).MéthodeDérivée()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Conversion statique : Provoque une exception en exécution si la conversion est illicite

`((<Classe dérivée>) <Instance de la classe de base>)`
---

**`<Classe dérivée> : ()`**

Classe héritant de la classe de base.

**`<Instance de la classe de base> : ()`**

Instance de la classe de base à convertir vers la &lt;Classe dérivée&gt;. 


<a name="SYNTAXE2"></a>

### Conversion dynamique : Renvoie Null si la conversion est illicite

`((<Classe dérivée> ?) <Instance de la classe de base>)`
---

**`<Classe dérivée> : ()`**

Classe héritant de la classe de base.

**`<Instance de la classe de base> : ()`**

Instance de la classe de base à convertir vers la &lt;Classe dérivée&gt;.



**Détail** : La conversion statique ne provoque pas d'erreur en exécution si la conversion est illicite. Un objet fictif est renvoyé pour lequel la comparaison à **Null** renvoie <u><u><u><u>Vrai</u></u></u></u>. Une erreur de compilation sera affichée si cet objet fictif est manipulé.
