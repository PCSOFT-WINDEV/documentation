
## Administrateur WEBDEV distant : Informations personnelles
			



## Informations utilisateur
<a name="informations_utilisateur_ELTTEXTE000132"></a>
L'outil d'administration à distance permet de vérifier et de modifier si nécessaire vos informations personnelles.

Remarque : Par défaut, ces informations ont été saisies par l'administrateur du serveur lors de la création du compte WEBDEV.


### Modifier vos informations personnelles
<a name="modifier_vos_informations_personnelles_ELTPARAGRAPHE000012"></a>Pour modifier vos informations personnelles :

1. Cliquez sur le lien "&lt;Login&gt;" présent dans la barre de menu. Dans la popup qui s'affiche, cliquez sur "Voir mon profil".

2. Dans la section "Vos informations personnelles", modifiez si nécessaire les informations affichées. Vérifiez notamment la validité de l'adresse email.

3. Cliquez sur le bouton "Modifier". Vos informations personnelles sont automatiquement modifiées.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0014.gif&type=thumb)





Ces informations sont automatiquement reportées dans la description de votre [compte WEBDEV](../WDAdminWeb/304.md) présent sur le serveur Web.





## Mot de passe
<a name="mot_passe_ELTTEXTE000162"></a>
Le mot de passe permettant d'accéder à l'outil d'administration à distance est défini par défaut par l'administrateur du serveur, lors de la création du [compte WEBDEV](../WDAdminWeb/304.md).

Ce mot de passe est utilisé :

- pour la connexion à l'outil d'administration à distance.

- lors de la réalisation d'installations ou de mises à jour de sites WEBDEV à distance (par FTP).




Ce mot de passe peut être modifié à tout moment depuis l'outil d'administration à distance.


### Modifier votre mot de passe depuis l'outil d'administration à distance
<a name="modifier_votre_mot_passe_depuis_outil_administration_distance_ELTPARAGRAPHE000042"></a>Pour modifier votre mot de passe depuis l'outil d'administration à distance :

1. Cliquez sur le lien "&lt;Login&gt;" présent dans la barre de menu. Dans la popup qui s'affiche, cliquez sur "Voir mon profil".

2. Dans la section "Vos informations personnelles", cliquez sur le bouton "Modifier le mot de passe". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0014%201.gif)
Saisissez votre ancien mot de passe, votre nouveau mot de passe et sa confirmation.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0015.gif&type=thumb)


3. Cliquez sur le bouton "Modifier". Le nouveau mot de passe est immédiatement valide.








## Comptes de statistiques
<a name="comptes_statistiques_ELTTEXTE000192"></a>


### Présentation
<a name="presentation_ELTPARAGRAPHE000060"></a>Les comptes de statistiques permettent d'accéder au module de statistiques de l'administrateur WEBDEV distant. Il suffit de lancer l'administrateur distant et d'indiquer le login et le mot de passe du compte de statistiques. Pour plus de détails sur les statistiques, consultez [Administrateur WEBDEV distant : Statistiques](../WDAdminWeb/6466.md).  


### Créer un compte de statistiques
<a name="creer_compte_statistiques_ELTPARAGRAPHE000068"></a>Pour créer un compte de statistiques :

1. Cliquez sur le lien "&lt;Login&gt;" présent dans la barre de menu. Dans la popup qui s'affiche, cliquez sur "Voir mon profil".

2. Dans la section "Edition des comptes de statistiques", cliquez sur le bouton "Nouveau".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0014%202.gif&type=thumb)


3. Saisissez les informations demandées : login, mot de passe, ...

4. Validez en cliquant sur le bouton "Appliquer". 

5. Indiquez les sites et les Webservices pour lesquels les statistiques peuvent être consultées. 

6. Le compte de consultation des statistiques est créé et peut être utilisé. 




**Remarques** : 

- Le bouton "Editer" permet de modifier les informations d'un compte de statistiques. 

- Le bouton "Supprimer" permet de supprimer un compte de statistiques.
