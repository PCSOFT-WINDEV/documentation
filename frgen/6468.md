
## Administrateur WEBDEV distant : Configuration pour utiliser les statistiques
			



## Présentation
<a name="presentation_ELTTEXTE000101"></a>
L'Administrateur distant WEBDEV propose un module de gestion des statistiques. Ce module permet : 

- d'importer les statistiques d'un site.

- de visualiser les statistiques d'un ou de plusieurs sites.




Pour accéder à ce module de statistiques, il est nécessaire d'avoir un compte spécifique, dédié à la gestion des statistiques. Ce compte peut être créé grâce à l'administrateur distant. 





## Comment le faire ?
<a name="comment_faire_ELTTEXTE000125"></a>


### Créer un compte de consultation des statistiques
<a name="creer_compte_consultation_des_statistiques_ELTPARAGRAPHE000017"></a>Pour créer un compte de consultation des statistiques : 

1. Lancez l'administrateur WEBDEV distant en saisissant l'adresse suivante : 
	
	```txt
	http://<serveur>/WDAdminWeb
	```
où &lt;serveur&gt; représente l'adresse (nom ou adresse IP) du Serveur d'Application WEBDEV.

2. Pour utiliser le site de l'Administrateur WEBDEV Distant, il est nécessaire de s'authentifier avec un nom d'utilisateur et un mot de passe. Pour créer un compte de consultation des statistiques, il n'est pas nécessaire d'être administrateur. 
	Rappel : 

	- Par défaut, le nom d'utilisateur "**admin**" (avec le mot de passe "**admin**") peuvent être utilisé à l'issue de l'installation du Serveur d'Application WEBDEV.

	- Il est important de changer le mot de passe du compte "admin" dès que possible afin de prévenir toute tentative d'accès par une personne non autorisée. Le compte "admin" dispose en effet de tous les droits sur la configuration SaaS sur le Serveur d'Application.




3. Dans le site de l'administrateur distant, cliquez sur l'option "Comptes". 

4. En bas de la page de gestion des comptes, il est possible de créer ou d'éditer les comptes de statistiques. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0012%203.gif)


5. Pour créer un compte de statistiques : 

	- Cliquez sur le bouton "Nouveau".

	- Saisissez les informations demandées : login, mot de passe, ...

	- Validez en cliquant sur le bouton "Appliquer". 




6. Indiquez les sites et les Webservices pour lesquels les statistiques peuvent être consultées. 

7. Le compte de consultation des statistiques est créé et peut être utilisé.





### Consulter les statistiques d'un site
<a name="consulter_les_statistiques_site_ELTPARAGRAPHE000043"></a>Pour consulter les statistiques d'un site : 

1. Lancez l'administrateur WEBDEV distant en saisissant l'adresse suivante : 
	
	```txt
	http://<serveur>/WDAdminWeb
	```
où &lt;serveur&gt; représente l'adresse (nom ou adresse IP) du Serveur d'Application WEBDEV.

2. Pour consultez les statistiques, il est nécessaire de s'authentifier avec le nom d'utilisateur et le mot de passe correspondant au compte de consultation des statistiques. 

3. Le site de consultation des statistiques apparaît.
