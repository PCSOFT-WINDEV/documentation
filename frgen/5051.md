## Erreur ERR_NOTADEVVERSION
<a name="erreur_errnotadevversion_ELTTEXTE000062"></a>
Cette version n'est pas utilisable en développement - ERR_NOTADEVVERSION (41)

WEBDEV version déploiement est utilisé pour développer un site dynamique WEBDEV.

Solution : Il faut installer WEBDEV version développement pour développer un site dynamique WEBDEV.
