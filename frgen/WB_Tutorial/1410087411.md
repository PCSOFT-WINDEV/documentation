## Schéma des données et projet : Définitions
<a name="schema_des_donnees_projet_definitions_ELTTEXTE000219"></a>
La création d'un site avec WEBDEV se base sur la création d'un **projet**. Ce projet contient tous les éléments nécessaires au site.

Lors de la conception d'un site, vous pouvez être amené à manipuler des données. Pour les stocker, vous devez constituer ce que l'on nomme "une base de données".

Dans WEBDEV, lors de la création d'un projet manipulant des données, vous devez tout d'abord créer un **schéma des données**. Une "schéma des données" contient la description des tables. Les données de l'application seront enregistrées dans les tables.

C'est seulement lors de l'exécution du site que ces descriptions sont utilisées pour créer la base de données et/ou les tables. C'est dans cette base de données ou dans ces tables que seront stockées les informations.

## Un projet exemple associé à un schéma des données
<a name="projet_exemple_associe_schema_des_donnees_ELTTEXTE000252"></a>
Dans ce tutoriel, nous allons créer un projet associé à une base de données HFSQL.WEBDEV sait gérer de nombreux formats de bases de données. Il propose également HFSQL, système de base de données intégrée à WEBDEV et livrée en standard. La base de données HFSQL est disponible en version Locale, Réseau, Cluster, Client/Serveur (Windows et Linux), Cloud et Mobile.

Pour créer un site avec une base de données, il faut :

- Créer le projet lié au site. Ce projet regroupera tous les éléments du site (pages, codes, requêtes, états, etc.). 

- Créer le schéma des données lié au projet. Le schéma des données permet de décrire toutes les tables manipulées par le site.

## Création du projet
<a name="creation_projet_ELTTEXTE000285"></a>
Avant tout développement avec WEBDEV, il faut un projet ? Créons-le !

Pour créer le projet, il suffit de suivre les différentes étapes de l'assistant de création de projet :

1. Lancez WEBDEV et affichez la page d'accueil de WEBDEV si nécessaire (Ctrl + &lt;). 

2. Dans la page d'accueil, cliquez sur "Créer un projet", puis sur l'option "Site, Site SaaS". L'assistant de création du projet se lance. Les différentes étapes de l'assistant vont vous aider à créer votre projet.
	Tous les renseignements indiqués dans cet assistant pourront être modifiés par la suite.


3. L'assistant propose de définir la charte graphique (également appelée "Thème"). Sélectionnez "Phoenix". 
	Les ambiances permettent d'harmoniser l'aspect visuel d'un site et rendent les changements de look plus simples et plus rapides.
Le thème fournit les images, les polices, la texture, la forme des boutons et les styles disponibles pour le projet.
.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P2_Ma%20Premi%E8re%20Base%20-%201%20-%20Cr%E9ation%20Projet%20-%20HC%20N%B0001.jpg&type=thumb)


4. Passez à l'étape suivante de l'assistant (bouton "Suivant").  

5. L'assistant permet de saisir le nom du projet et son emplacement. Dans notre cas, ce projet va simplement s'appeler "Mon_Site_WEBDEV".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P2_Ma%20Premi%E8re%20Base%20-%201%20-%20Cr%E9ation%20Projet%20-%20HC%20N%B0002.jpg&type=thumb)
Par défaut, WEBDEV propose de créer ce projet dans le répertoire ".\\Mes Projets\\Mon_Site_WEBDEV". Vous pouvez conserver cet emplacement ou le modifier grâce au bouton [...].
	Lorsque vous développez pour le Web, il est préférable d'éviter les caractères accentués dans les noms des éléments (projets, pages, etc.).


6. Cliquez sur le bouton "Terminer" : le projet est créé. La fenêtre de création d'un nouvel élément s'affiche. Fermez cette fenêtre à l'aide de la croix en haut à droite.

## Création du schéma des données
<a name="creation_schema_des_donnees_ELTTEXTE000336"></a>
Nous allons maintenant créer le schéma des données lié au projet :

1. Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Analyse_GAF.jpg) parmi les boutons d'accès rapide. L'assistant de création d'un schéma des données se lance. 

2. Indiquez le nom et le répertoire du schéma des données. Par défaut, le nom du schéma des données correspond au nom du projet et le répertoire du schéma des données est un répertoire ".ana" dans le répertoire du projet. Nous allons conserver ces paramètres par défaut. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P2_Ma%20Premi%E8re%20Base%20-%201%20-%20Cr%E9ation%20Projet%20-%20HC%20N%B0003.jpg&type=thumb)
Passez à l'étape suivante de l'assistant. 

3. Vous pouvez ensuite choisir le type de la base de données manipulée par le projet. Sélectionnez "HFSQL Classic". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P2_Ma%20Premi%E8re%20Base%20-%201%20-%20Cr%E9ation%20Projet%20-%20HC%20N%B0004.jpg&type=thumb)
Passez à l'étape suivante de l'assistant.

4. Validez. L'assistant de création d'une table se lance automatiquement.

5. Fermez cet assistant. Nous verrons dans la prochaine leçon les différentes manières disponibles pour créer la description d'une table.
