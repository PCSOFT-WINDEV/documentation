## Présentation
<a name="presentation_ELTTEXTE000301"></a>
WEBDEV permet de créer des applications/sites accédant à des bases de données HFSQL Client/Serveur.Une base de données en mode Client/Serveur permet de déporter la ou les bases de données sur un poste serveur (ce poste serveur peut être différent de celui où est déployé le site). Ce mode de fonctionnement :

- accroît la sécurité de vos données,

- permet de gérer très facilement le mode multi-utilisateurs,

- facilite la maintenance,

- permet des connexions depuis l'extérieur (siège par le back office par exemple).







Dans cette leçon, nous allons effectuer toutes les opérations nécessaires au développement et au déploiement d'un site utilisant une base de données HFSQL Client/Serveur.

Pour plus de détails sur HFSQL Client/Serveur, consultez [HFSQL Client/Serveur](../WDLang4/3044306.md).

## Installation d'un serveur HFSQL local
<a name="installation_serveur_hfsql_local_ELTTEXTE000334"></a>
La première opération à faire avant de commencer à développer consiste à installer un serveur HFSQL.

Sur le poste de développement, ce serveur peut être installé en local (c'est ce que nous allons faire). En déploiement, ce serveur peut être installé sur un poste spécifique ou directement sur le serveur hébergeant votre site.

Le programme d'installation du serveur HFSQL est disponible sur le support d'installation de WINDEV, WEBDEV et WINDEV Mobile. Si vous ne possédez pas ce support, l'installation du serveur HFSQL est également disponible sur le site de PC SOFT ([www.pcsoft.fr](https://www.pcsoft.fr)).

Pour installer le serveur HFSQL en local :

1. Lancez le programme d'installation de WINDEV, WEBDEV et WINDEV Mobile.

2. Choisissez l'option "Installer HFSQL Client/Serveur".

3. Sélectionnez ensuite l'option "Installer ou mettre à jour un serveur HFSQL".

4. Acceptez la licence.

5. Choisissez la plateforme (option "Pour Windows sur cette machine").

6. Si des serveurs HFSQL sont déjà installés sur le poste en cours, choisissez l'option "Installer un nouveau serveur".

7. Sélectionnez le répertoire d'installation et indiquez le nom du serveur et le port. Par défaut, le port utilisé est 4900.
	Pensez à ouvrir ce port sur le firewall pour se connecter au serveur HFSQL depuis une autre machine.


8. Indiquez le nom et le mot de passe de l'utilisateur ayant les droits d'administration qui sera créé par défaut sur le serveur HFSQL. Par défaut, cet utilisateur est "Admin" sans mot de passe. 
	Pour des raisons évidentes de sécurité, pensez à changer le mot de passe de l'administrateur.


9. Installez le Centre de Contrôle HFSQL si celui-ci n'est pas présent ou accessible depuis votre poste.
	
	<B><B><B><B>Avertissement</B></B></B></B>

	 Le Centre de Contrôle HFSQL est nécessaire à la gestion de la base HFSQL Client/Serveur.



10. L'assistant propose de paramétrer l'envoi de notifications afin de connaître les dysfonctionnements du serveur en temps réel. Pour notre exemple, passez à l'étape suivante et indiquez que le paramétrage sera effectué "Plus tard". 

11. L'assistant propose d'activer l'authentification par Active Directory. Activez cette option si nécessaire. 

12. Validez (ou non) la participation à l'amélioration du produit installé en autorisant la collecte d'informations relatives à l'utilisation du produit. Cette collecte, facultative et anonyme, permet à PC SOFT d'améliorer les fonctionnalités du produit.




L'installation est effectuée. Par défaut (si vous n'avez pas modifié les caractéristiques de l'administrateur), pour se connecter au serveur en mode administrateur, il faut utiliser l'utilisateur "Admin" sans mot de passe. 

**Remarque** : Dans ce tuto, nous nous attachons à l'adaptation d'une application existante au mode Client/Serveur. Lorsque le serveur HFSQL est installé, il est bien entendu également possible de développer directement une nouvelle application utilisant des données HFSQL Client/Serveur. Pour cela, la seule différence avec la création d'un projet utilisant des données HFSQL Classic, correspond au format des données manipulées dans le schéma des données : les bases de données utilisées par le projet seront de type "HFSQL Client/Serveur". Pour plus de détails sur la création d'un projet WEBDEV et d'un schéma des données, consultez le tuto [Créer un projet WEBDEV et son schéma des données](../TutoWB/1410087411.md).

## Adaptation d'un site pour utiliser une base de données HFSQL Client/Serveur
<a name="adaptation_site_pour_utiliser_une_base_donnees_hfsql_clientserveur_ELTTEXTE000431"></a>
Le passage d'une base de données HFSQL Classic en mode Client/Serveur est l'opération la plus courante.

WEBDEV propose plusieurs solutions pour réaliser ce passage :

- réaliser cette adaptation dans l'éditeur de schémas des données.

- réaliser cette adaptation depuis le Centre de Contrôle HFSQL.


Pour mieux se rendre compte des différentes étapes, nous allons passer en mode Client/Serveur le site "Site WEBDEV complet" en utilisant la première méthode, l'éditeur de schémas des données.
<a name="NOTE5_2"></a>


### Ouverture du projet exemple
<a name="ouverture_projet_exemple_ELTPARAGRAPHE000083"></a>

Ce tuto manipule le projet "Site WEBDEV Complet". Pour ouvrir cet exemple : 

1. Affichez la page d'accueil de WEBDEV (Ctrl + &lt;).

2. Dans la page d'accueil, cliquez sur "Tutoriel" puis dans la zone "Tuto - Administrer une base HFSQL Client/Serveur", cliquez sur le lien "Ouvrir le projet exercice".





	<B><B><B><B>Avertissement</B></B></B></B>

	 Cet exemple sera utilisé dans les différentes leçons de ce tuto. 





### Adaptation du projet
<a name="adaptation_projet_ELTPARAGRAPHE000096"></a>

Pour adapter le projet "Site WEBDEV Complet" :

1. Chargez le schéma des données de votre projet sous l'éditeur de schémas des données : cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Analyse_WM_GAF.jpg) parmi les boutons d'accès rapide du menu de WEBDEV. L'éditeur de schémas des données s'affiche.

2. Dans le ruban, sous le volet "Schéma des données", dans le groupe "Connexion", cliquez sur "Nouvelle connexion". Un assistant s'ouvre, permettant de créer une connexion.

3. Sélectionnez le type de connexion à créer : "HFSQL Client/Serveur". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0001.jpg&type=thumb)
Passez à l'étape suivante.

4. Indiquez dans les étapes suivantes : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0002.jpg&type=thumb)


	- le nom du serveur sur lequel vous avez installé le serveur HFSQL Client/Serveur (localhost si vous l'avez installé sur votre machine par exemple) et le numéro de port. 

- le nom de l'utilisateur et son mot de passe (pour utiliser l'administrateur, spécifier le login et le mot de passe personnalisés lors de l'installation du serveur HFSQL). 

- le nom de la base de données ("Site_WEBDEV_Complet" dans notre exemple). 

- le nom de la connexion (conservez le nom proposé).

5. Passez à l'étape suivante et validez. La connexion à la base est automatiquement créée. L'assistant propose d'associer les différentes tables présentes dans le schéma des données à la connexion qui vient d'être créée.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0003.jpg)


6. Cliquez sur "Oui".

7. Dans l'étape suivante, sélectionnez toutes les tables proposées : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0004.jpg&type=thumb)
Passez à l'étape suivante.

8. L'assistant propose ensuite de copier les tables sur le serveur. Validez (option "Copier maintenant").<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0005.jpg)


9. Sélectionnez les tables du schéma des données à copier sur le serveur : dans notre cas, ce sont toutes les tables du répertoire EXE.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0006.jpg&type=thumb)


10. Passez à l'étape suivante et validez.

11. Les tables du schéma des données sont automatiquement transformées en tables HFSQL Client/Serveur et associées à la connexion choisie.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P11_Passage%20analyse%20en%20CS%20WB%20-%20HC%20N%B0007.jpg&type=thumb)


12. **Générez le schéma des données** : Dans le ruban, sous le volet "Schéma des données", dans le groupe "Schéma des données", cliquez sur "Génération". Une modification automatique des tables est automatiquement proposée. Si toutes les tables sont à jour, vous pouvez annuler la modification automatique des tables.
	**Passage en mode Client/Serveur : quelques conseils**

	- Vérifiez le code de votre projet : en mode HFSQL Client/Serveur, les instructions de type [HSubstRep](../WDLang4/3044028.md) et autres sont inutiles.

	- Selon les paramètres indiqués lors de la création de la connexion, il est possible de modifier la connexion définie dans le schéma des données grâce aux fonctions [HOuvreConnexion](../WDLang4/3044107.md) et [HChangeConnexion](../WDLang4/3044150.md).

	- La fonction [HOuvreConnexion](../WDLang4/3044107.md) permet toujours de repasser en mode HFSQL Classic : il suffit de lui préciser le chemin du répertoire contenant les tables HFSQL Classic.





13. Vous avez adapté le projet de développement. Il peut être également nécessaire d'adapter le site déployé (par exemple si le site déployé utilise des tables HFSQL Classic). Cette opération se paramètre lors de la création du programme d'installation du site.
