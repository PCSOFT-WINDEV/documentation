## Reprenons notre exemple
<a name="reprenons_notre_exemple_ELTTEXTE000614"></a>
Dans la leçon précédente, nous avons manipulé le projet "Mes_Premieres_Pages". Nous allons reprendre ce projet pour poursuivre notre découverte de WEBDEV.


### Quel est le but de cette leçon ? 
<a name="quel_est_but_cette_lecon_ELTPARAGRAPHE000032"></a>

Nous avons créé un formulaire dans la leçon précédente. Lors de la création d'un formulaire, la première chose que l'on souhaite, c'est bien entendu, sauvegarder les données saisies. Ces données peuvent être enregistrées par exemple dans un fichier texte, un fichier XML ou encore une base de données.

C'est cette dernière option que nous avons choisie.

Dans cette leçon, nous allons : 

- définir rapidement la base de données liée aux champs que nous avons créés, grâce à une fonctionnalité très simple : la rétro-analyse.

- modifier la page pour enregistrer les données dans la base de données.

- ajouter des contrôles de saisie. 

- effectuer une recherche simple dans la base de données.

## Création de la table
<a name="creation_table_ELTTEXTE000644"></a>
Pour créer une table à partir des champs présents dans une page, WEBDEV propose un assistant :

1. Affichez si nécessaire sous l'éditeur la page "PAGE_Formulaire" (via par exemple la combinaison de touches Ctrl + E). 

2. Dans le ruban, sous le volet "Page", dans le groupe "Edition", déroulez "Autres actions" et sélectionnez "Générer une description de fichier".

3. Un nouvel éditeur apparaît : l'éditeur de schémas des données. 
	Sous WEBDEV, la description de la base de données se fait sous un éditeur spécifique, l'Éditeur de schémas des données. L'éditeur de schémas des données contient la description de toutes les tables qui seront manipulées par le projet. Nous verrons cet éditeur en détail dans le tuto [Créer un projet et son schéma des données](../TutoWB/1410087411.md).


4. L'assistant de génération d'une table se lance. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Analyse%20-%20HC%20N%B0001.jpg&type=thumb)
Le nom de la table est automatiquement renseigné avec le nom de la page. 

5. Nous allons modifier quelques éléments :

	- Saisissez "Inscription" dans le nom.

	- Saisissez "Inscription" dans le libellé.

	- Saisissez "une inscription" dans le dernier champ.




6. Passez à l'étape suivante (bouton "Suivant" en bas de l'assistant).

7. Choisissez les champs à récupérer. Dans notre cas, tous les champs de la page correspondent à une rubrique.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Analyse%20-%20HC%20N%B0003.jpg&type=thumb)


8. Passez à l'étape suivante.

9. Cette étape permet de définir les clés (également appelées index).
	Une clé permet un accès plus rapide lors des recherches (clé avec doublons) et/ou de s'assurer que la valeur d'une rubrique ne peut être enregistrée qu'une seule fois (clé unique).
 Dans cet exemple, la rubrique "Nom" sera une clé avec doublons et la rubrique "Login" sera une clé unique. La table pourra donc contenir deux personnes inscrites avec le même nom mais pas avec le même login. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Analyse%20-%20HC%20N%B0004.jpg&type=thumb)


10. Passez à l'étape suivante.

11. Validez le récapitulatif. La description de la table apparaît sous l'Éditeur de schémas des données.

12. Enregistrez le schéma des données : cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Sauver_WB_GAF.jpg) parmi les boutons d'accès rapide (ou utilisez le raccourci Ctrl + S).

13. Fermez l'éditeur de schémas des données.

14. Une fenêtre apparaît, proposant de synchroniser le projet. Il s'agit d'une vérification des différences entre les pages créées et les données définies dans le schéma des données. Cette étape est effectuée à chaque modification du schéma des données, lors du retour vers les pages du projet.

15. Cliquez sur "Oui".





Revenons au formulaire d'inscription pour mettre en place l'ajout des données saisies par l'internaute dans la table. Pour cela, il suffit d'utiliser la barre des documents, située en haut de l'éditeur : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Analyse%20-%20HC%20N%B0005.jpg)
Dans cette barre : 

- "P" représente le projet.

- "PAGE_Formulaire" représente la page "Formulaire".


Cliquez sur "Page_Formulaire" pour afficher la page correspondante sous l'éditeur.

<a name="modifications_page_pour_enregistrer_les_donnees_ELTTEXTE000686"></a>

<a name="creation_champ_bouton_ELTPARAGRAPHE000120"></a>

### Code WLangage du champ Bouton
<a name="code_wlangage_champ_bouton_ELTPARAGRAPHE000156"></a>

Nous allons maintenant définir les actions à effectuer lors du clic sur le champ Bouton en utilisant du code WLangage.

Affichons les différents événements WLangage associés au champ. Pour cela, deux possibilités : 

- Première possibilité : Affichez le menu contextuel du champ puis sélectionnez l'option "Code".

- Seconde possibilité : Sélectionnez le champ et appuyez sur la touche F2. 


Les événements associés au champ sont affichés sous l'éditeur de code. Nous retrouvons les entêtes des événements effectués sur le serveur et les entêtes des événements effectués sur le navigateur. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes_Premi%E8res_Pages%20-%20Bouton_Enregistrer%20-%20HC%20N%B0004.jpg)


Nous voulons enregistrer les données dans la base de données. L'accès à la base de données peut être effectué uniquement en code Serveur : nous devons saisir le code WLangage dans l'événement "Clic Serveur" (jaune).

Saisissez le code WLangage suivant :
Clic serveur du bouton BTN_Enregistrer

```wl
PAGE_Formulaire.VersFichier()
Inscription.Ajoute()
Info("Enregistrement ajouté.")
```
Examinons ce code :

- La fonction [&lt;Page&gt;.VersFichier](../WDLang4/1000021390.md) permet de récupérer le contenu des champs de saisie de la page PAGE_Formulaire pour le transférer vers la table Inscription.

- La fonction [&lt;Table&gt;.Ajoute](../WDLang4/1000024187.md) permet d'écrire dans la table Inscription les données transférées.

- La fonction [Info](../WDLang1/3021011.md) permet d'afficher un message.




Sauvez (Ctrl + S) et fermez l'éditeur de code (croix en haut à droite).

### Vérification du mot de passe
<a name="verification_mot_passe_ELTPARAGRAPHE000288"></a>

Pour vérifier le mot de passe, nous allons : 

- Créer le champ de saisie permettant à l'utilisateur de saisir à nouveau son mot de passe. 

- Saisir le code WLangage nécessaire à la vérification.





|   |
| --- |
| **A vous de jouer** : Créez un nouveau champ de saisie. Ce champ a pour libellé "Vérification" et est de type "Mot de passe". |


Le code WLangage de vérification du mot de passe doit être saisi dans les événements associés au champ Bouton "ENREGISTRER".

1. Cliquez sur le champ Bouton "ENREGISTRER" pour le sélectionner et appuyez sur la touche F2. 
	Cette vérification consiste à comparer la valeur saisie dans le champ "Mot de passe" et celle saisie dans le champ "Vérification". Pour effectuer cette vérification, le serveur est inutile : cette vérification peut être effectuée en local dans le navigateur.


2. Saisissez le code suivant dans l'événement navigateur "Clic" :
	Clic sur BTN_Enregistrer (onclick navigateur)

	```wl
	SI SAI_Mot_De_Passe <> SAI_Vérification ALORS
		Info("Erreur, les mots de passe sont différents.")
		SAI_Mot_De_Passe = ""
		SAI_Vérification = ""
		DonneFocusEtRetourUtilisateur(SAI_Mot_De_Passe)
	FIN
	```


3. Examinons ce code :

	- L'instruction [SI](../Motscles/1510011.md) permet de faire une action sur une condition. Dans notre cas, l'action est faite si les champs "Mot de passe" et "Vérification" sont différents (opérateur ‘&lt;&gt;'). 

	- En cas de différence, les champs de saisie sont "vidés" : on leur affecte une chaîne vide.

	- La fonction [DonneFocusEtRetourUtilisateur](../WDLang1/1410088107.md) permet de remettre le curseur dans le champ indiqué (ici, le champ "Mot de passe") sans effectuer le code qui suit. Dans notre cas, si les mots de passe saisis sont différents, le champ "Mot de passe" reprend le focus et le code en cours d'exécution est arrêté : le code serveur qui permet d'enregistrer les informations dans la base de données ne sera pas effectué.







Rien ne vaut un petit test pour vérifier le bon fonctionnement :

1. Cliquez sur l'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Go_Page_WB_GAF.jpg) parmi les boutons d'accès rapide.

2. Dans la page qui s'affiche dans un navigateur, saisissez les informations suivantes :

	- Nom : "Dupont"

	- Prénom : "Pierre"

	- Email : "Pierre.Dupont@gmail.com"

	- Login : "Pierre"

	- Mot de passe : "Pierre"

	- Vérification : "Louis"




3. Cliquez sur le bouton "ENREGISTRER".

4. Un message d'erreur est automatiquement affiché pour indiquer que les mots de passe sont différents.

5. Validez ce message.

6. Fermez le navigateur.

## Recherche simple dans une base de données
<a name="recherche_simple_dans_une_base_donnees_ELTTEXTE000831"></a>
Nous avons vu comment créer un formulaire de saisie et enregistrer des valeurs dans une base de données. Continuons notre première découverte de WEBDEV en réalisant une recherche dans la base de données.

Nous allons créer une page de login dans laquelle nous saisirons le login et le mot de passe. Nous contrôlerons ensuite si ces informations sont correctes.


### Création de la page
<a name="creation_page_ELTPARAGRAPHE000351"></a>

Pour créer la page :

1. Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Cr%E9er_WB_GAF.jpg) parmi les boutons d'accès rapide. La fenêtre de création d'un nouvel élément s'affiche.

2. Cliquez sur "Page" puis sur "Page". L'assistant de création d'une page s'affiche.

3. Sélectionnez "Vierge". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Nouvelle_page%20-%20HC%20N%B0002.jpg&type=thumb)


4. Validez.

5. La page est créée et la fenêtre de sauvegarde est automatiquement affichée.

6. Saisissez le titre de la page : "Login".

7. Validez.





### Création des champs
<a name="creation_des_champs_ELTPARAGRAPHE000367"></a>

La page de login va contenir les champs suivants :

- Deux champs de saisie :

	- "Login" pour saisir le login.

	- "Mot de passe" pour saisir le mot de passe.




- Deux champs Bouton :

	- "Se connecter" pour vérifier le login et le mot de passe.

	- "S'inscrire" pour ouvrir la page d'inscription (que nous avons déjà créée).







Nous avons déjà créé ces types de champs, voici un rappel des manipulations à faire :

Pour créer un champ de saisie :

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_champ_saisie_WB_GAF.jpg).

2. Cliquez dans la page vierge pour créer le champ.

3. Cliquez sur le champ (simple clic) : le libellé passe en édition.

4. Saisissez le libellé et validez avec la touche Entrée. Le libellé est immédiatement modifié

	- Pour le champ de saisie du login, le libellé correspond à "Login".

	- Pour le champ de saisie du mot de passe, saisissez "Mot de passe". 
			Le champ "Mot de passe" doit être de type "Mot de passe". Pour modifier le type du champ de saisie, affichez simplement la fenêtre de description du champ.








Pour créer chaque champ Bouton :

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_champ_bouton_WB_GAF.jpg).

2. Cliquez dans la page pour créer le champ Bouton (par exemple en dessous des champs de saisie). Le champ est créé.

3. Appuyez sur la barre d'espace : le libellé passe en édition.

4. Saisissez le libellé et validez avec la touche Entrée. Le libellé est immédiatement modifié.

	- Pour le premier bouton, le libellé correspond à "Se connecter".

	- Pour le second bouton, le libellé correspond à "S'inscrire". 




5. Enregistrez la page. 




Comme pour la page précédente, un pictogramme s'affiche en haut à droite du champ Bouton "SE CONNECTER" : ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes_Premi%E8res_Pages%20-%20Bouton_Enregistrer%20-%20HC%20N%B0001%201.jpg)Là encore, il s'agit d'un problème de raccourci clavier manquant. 

- Cliquez sur le picto ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes_Premi%E8res_Pages%20-%20Bouton_Enregistrer%20-%20HC%20N%B0001%201.jpg). 

- Dans la fenêtre qui s'affiche, cliquez sur "Corriger". 




Vous obtenez la page suivante : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Partie%203%20-%20HC%20N%B0002.jpg&type=thumb)


Nous allons maintenant voir en détail le fonctionnement des champs Bouton. Tout d'abord, occupons-nous du champ Bouton "S'INSCRIRE".

1. Sélectionnez le champ Bouton "S'INSCRIRE".

2. Affichez la fenêtre de description du champ (double-clic sur le champ).

3. Dans l'onglet "Général", dans la zone "Action du bouton", nous allons indiquer l'action à effectuer. Dans notre cas, nous allons ouvrir la page d'inscription : 

	- Dans la zone "Type", sélectionnez "Afficher une page du site". 

	- Dans la zone "Page", sélectionnez "PAGE_Formulaire". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P1_Mes%20Premi%E8res%20pages%20-%20Partie%203%20-%20HC%20N%B0003.jpg&type=thumb)





4. Validez la fenêtre de description.
	Ici, aucun code n'est nécessaire : nous associons directement sous l'éditeur le champ Bouton et l'action à effectuer, ici, ouvrir une page.





Pour le champ Bouton "SE CONNECTER", il est nécessaire de saisir le code WLangage permettant de réaliser la recherche :

1. Sélectionnez le champ Bouton "SE CONNECTER" et affichez les événements associés (touche F2).

2. Saisissez le code WLangage suivant dans l'événement "Clic xxx (serveur)" :
	Clic sur BTN_Se_connecter (serveur)

	```wl
	Inscription.LitRecherchePremier(Login, SAI_Login)
	SI PAS Inscription.Trouve() ALORS
		Erreur("Login inconnu.")
		RETOUR
	FIN
	
	SI SAI_Mot_De_Passe = Inscription.Mot_De_Passe ALORS
		Info("OK, vous êtes connecté.")
	SINON
		Erreur("Mot de passe incorrect.")
	FIN
	```


3. Examinons ce code WLangage :

	- Ce code est exécuté en code serveur car nous réalisons une recherche dans la base de données qui est sur le serveur.

	- La fonction [&lt;Table&gt;.LitRecherchePremier](../WDLang4/1000025034.md) permet de rechercher une valeur dans une table (ici, la table "Inscription"). Par défaut, la recherche est faite sur le nom entier. Pour effectuer une recherche de type "Commence par", il suffit d'ajouter un paramètre, la constante ***hGénérique***.

	- La fonction [&lt;Table&gt;.Trouve](../WDLang4/1000025076.md) permet de savoir si la recherche a réussi ou non dans la table Inscription. Le code "SI PAS Inscription.Trouve" permet de définir l'action si le login n'est pas trouvé (affichage de "Login inconnu"). Le mot-clé RETOUR permet dans ce cas de sortir du traitement en cours. En effet, si le Login n'est pas trouvé, il n'est pas nécessaire d'exécuter le code suivant.

	- Si le login est trouvé, le mot de passe saisi dans le champ SAI_Mot_De_Passe est comparé à celui trouvé dans la table (pour le login spécifié). Si les deux mots de passe sont égaux, alors l'internaute est connecté, sinon un message d'erreur est affiché.
			Le code présenté ici est purement didactique. Dans un projet réel :

		- Le mot de passe ne doit pas être stocké en clair. Il est conseillé de crypter le mot de passe. 

		- Il est conseillé d'afficher le même message d'erreur en cas de login ou de mot de passe incorrect (pour éviter une tentative de piratage des logins).








4. Sauvez (Ctrl + S) et fermez l'éditeur de code (croix en haut à droite).

### Pensez mobilité
<a name="pensez_mobilite_ELTPARAGRAPHE000521"></a>

Un site doit fonctionner aussi bien sur PC que sur Mobile : c'est une réalité actuelle. Le site doit être pensé dès sa conception pour une utilisation mobile. 

Pour simplifier l'utilisation de sites à la fois sur PC et sur Mobile, WEBDEV met à votre disposition les agencements. Grâce aux agencements, seule l'interface de votre page est modifiée en Mobile. Le code ne change pas. Pas besoin d'utiliser deux jeux de pages. Votre site reste le même. 

Ce premier site étant un site de découverte, nous n'utiliserons pas immédiatement les agencements. Nous aborderons ce sujet dans le tuto ["Site Mobile-Friendly"](../NonDocumente/1410087416.md).
