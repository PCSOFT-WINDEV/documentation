## Schéma des données et projet : Définitions
<a name="schema_des_donnees_projet_definitions_ELTTEXTE000209"></a>
La création d'une application avec WINDEV se base sur la création d'un projet. Ce projet contient tous les éléments nécessaires au fonctionnement de l'application.

Lors de la conception d'une application, vous pouvez être amené à manipuler des données. Pour les stocker, vous devez constituer ce que l'on nomme "une base de données".

Dans WINDEV, lors de la création d'un projet manipulant des données, vous devez tout d'abord créer un **schéma des données**. Un "schéma des données" contient la description des tables contenant les données de l'application.


C'est seulement lors de l'exécution de l'application, que ces descriptions sont utilisées pour créer la base de données et/ou les tables. C'est dans cette base ou dans ces tables que seront stockées les informations.

## Un projet exemple associé à un schéma des données
<a name="projet_exemple_associe_schema_des_donnees_ELTTEXTE000242"></a>
Dans ce tutoriel, nous allons créer un projet associé à une base de données HFSQL.WINDEV sait gérer de nombreux formats de bases de données. Il propose également HFSQL, système de base de données intégré à WINDEV et livré en standard. La base de données HFSQL est disponible en version Locale, Réseau, Cluster, Client/Serveur (Windows et Linux), Cloud et Mobile.




Pour créer une application avec une base de données, il faut :

- Créer le projet lié à l'application. Ce projet regroupera tous les éléments de l'application (fenêtre, codes, requêtes, états, etc.).

- Créer le schéma des données lié au projet. Le schéma des données permet de décrire toutes les tables manipulées par l'application.

## Création du projet
<a name="creation_projet_ELTTEXTE000275"></a>
Avant tout développement avec WINDEV, il faut un projet ? Créons-le !


Pour créer le projet, il suffit de suivre les différentes étapes de l'assistant de création de projet :

1. Lancez WINDEV et affichez la page d'accueil de WINDEV si nécessaire (Ctrl + &lt;). 

2. Dans la page d'accueil, cliquez sur "Créer un projet", puis sur l'option "Application Windows ou Linux". L'assistant de création d'un projet se lance. Les différentes étapes de l'assistant vont vous aider à créer votre projet. 
	Tous les renseignements indiqués dans cet assistant pourront être modifiés par la suite.


3. L'assistant propose de définir la charte graphique. Sélectionnez "Eleven_Palette". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0001.jpg&type=thumb)
Passez à l'étape suivante. 
	La charte graphique est définie notamment grâce aux thèmes. Les thèmes permettent d'obtenir rapidement des UI (interfaces) professionnelles. Un thème définit le look de la fenêtre mais également le look de tous les champs qui seront utilisés dans cette fenêtre. Ainsi, aucune faute de goût n'est possible.


4. L'assistant propose de saisir le nom du projet et son emplacement. Dans notre cas, ce projet va simplement s'appeler "WD Ma Première Base De Données". Par défaut, WINDEV propose de créer ce projet dans le répertoire ".\\Mes projets\\WD Ma Première Base De Données". Vous pouvez conserver cet emplacement ou le modifier grâce au bouton [...]. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0002.jpg&type=thumb)


5. Cliquez sur le bouton "Terminer" : le projet est créé. La fenêtre de création d'un nouvel élément s'affiche. Fermez cette fenêtre à l'aide de la croix en haut à droite.

## Création du schéma des données
<a name="creation_schema_des_donnees_ELTTEXTE000317"></a>
Nous allons maintenant créer le schéma des données lié au projet :

1. Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ICO_Analyse_GAF.jpg) parmi les boutons d'accès rapide. L'assistant de création d'un schéma des données se lance. 

2. Indiquez le nom et le répertoire du schéma des données. Par défaut, le nom du schéma des données correspond au nom du projet et le répertoire du schéma des données est un répertoire ".ana" dans le répertoire du projet. Nous allons conserver ces paramètres par défaut. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0003.jpg&type=thumb)
Passez à l'étape suivante de l'assistant.

3. Vous pouvez ensuite choisir le type de bases de données manipulées par le projet. Sélectionnez "HFSQL Classic". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P3_Ma%20premi%E8re%20base%20-%20Cr%E9ation%20-%20HC%20N%B0004.jpg&type=thumb)
Passez à l'étape suivante de l'assistant.

4. Validez. L'assistant de création d'une table se lance automatiquement. 

5. Fermez cet assistant. Nous verrons dans la prochaine leçon les différentes manières disponibles pour créer la description d'une table.
