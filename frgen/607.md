## Erreur ERR_BAD_CONFIG
<a name="erreur_errbadconfig_ELTTEXTE000076"></a>


### ERR_BAD_CONFIG : La configuration du site &lt;NOM_APPLICATION&gt; est incorrecte pour la valeur %s. 
<a name="errbadconfig_configuration_site_est_incorrecte_pour_valeur_ELTPARAGRAPHE000007"></a>

Cette erreur est due à une mauvaise installation du site dynamique WEBDEV dans la base de registre. Il est nécessaire :

- soit de ré-installer le site.

- soit de corriger la configuration du site dans la base de registre.




**Rappel** : Lors de l'installation d'un site dynamique WEBDEV, une nouvelle entrée est créée dans la base de registre.
Une nouvelle entrée est créée dans la clé :


- En 32 bits : 
	
	```txt
	"HKEY_LOCAL_MACHINE\SOFTWARE\PC SOFT\WEBDEV\24.0\Applications\<NomProjet>"
	```


- En 64 bits : 
	
	```txt
	"HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\PC SOFT\WEBDEV\24.0\Applications\<NomProjet>"
	```





Le nom du projet et son répertoire sont indiqués.
