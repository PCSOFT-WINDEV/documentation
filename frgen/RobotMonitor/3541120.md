
## Contrôle : Serveur d'application WEBDEV
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000080"></a>
Le robot de surveillance va tester le fonctionnement du Serveur d'application WEBDEV.

Le contrôle sera :

- réussi si le serveur d'application WEBDEV répond.

- en échec dans le cas contraire.

<a name="NOTE2_1"></a>


## Paramètres spécifiques au contrôle d'un serveur d'application WEBDEV
<a name="parametres_specifiques_controle_serveur_application_webdev_ELTTEXTE000104"></a>


### Informations sur le serveur d'application WEBDEV
<a name="informations_sur_serveur_application_webdev_ELTPARAGRAPHE000024"></a>Les informations sur le serveur d'application WEBDEV à tester sont :

- l'adresse du serveur d'application WEBDEV.

- la version du serveur d'application WEBDEV (par exemple 31).

- la plateforme (Windows ou Linux)
