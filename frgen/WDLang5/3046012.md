
## Imprimer en WLangage
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000195"></a>
WINDEV, WEBDEV et WINDEV Mobile offrent plusieurs moyens pour imprimer:

- l'éditeur d'états, qui permet de créer des "Etats prédéfinis".

- les fonctions d'impression du WLangage.





### L'éditeur d'états
<a name="editeur_etats_ELTPARAGRAPHE000017"></a>

L'éditeur d'états permet de créer des états imprimés (sous forme d'état ou d'étiquette) contenant des informations provenant de tables.

La création d'états imprimés avec l'éditeur d'états doit être préférée à celle avec les fonctions du WLangage.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Les états créés avec l'éditeur d'états ne sont pas disponibles.


### Les fonctions d'impression du WLangage
<a name="les_fonctions_impression_wlangage_ELTPARAGRAPHE000028"></a>

Toutefois pour des développements très spécifiques, l'éditeur d'états ne permet pas de créer les états souhaités. Dans ce cas, il faut utiliser les fonctions d'impression du WLangage.

**Attention**: Ce chapitre décrit uniquement le principe des impressions en WLangage.



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Principe de l'impression en WLangage
<a name="principe_impression_wlangage_ELTTEXTE000231"></a>
Les étapes pour imprimer en WLangage sont:

- **Étape 1 (optionnelle)**: [Configuration des paramètres d'impression](../WDLang5/3046037.md)

- **Étape 2 (optionnelle)**: [Création de la police ou des polices d'impression (optionnel)](../WDLang5/3046026.md)

- **Étape 3**: [Impression des caractères, des lignes ou des images et fin d'impression](../WDLang5/3046049.md).

- **Étape 4**: [Lancement de l'impression](../WDLang5/3046058.md).

## Limitations
<a name="limitations_ELTTEXTE000255"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Important
<a name="important_ELTPARAGRAPHE000081"></a>

Pour effectuer une impression directement sur une imprimante reliée au serveur, une configuration spécifique est nécessaire. Pour plus de détails, consultez [Configuration du serveur pour réaliser une impression](../WDChamp/1011002.md).
<a name="NOTE3_3"></a>
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) 

### Impression en Linux
<a name="impression_linux_ELTPARAGRAPHE000093"></a>

Sous Linux, seules les impressions au format PDF sont disponibles. 

Une configuration spécifique est nécessaire pour réaliser des impressions en Linux. Pour plus de détails, consultez [Imprimer en Linux](../Editeurs/9000078.md). 
<a name="NOTE3_4"></a>
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Impression dans les applications iPhone/iPad
<a name="impression_dans_les_applications_iphoneipad_ELTPARAGRAPHE000109"></a>

Sous iOS, seules les impressions au format PDF sont disponibles. 

Si nécessaire, le fichier PDF créé peut être imprimé depuis le matériel grâce à la fonction [iImprimePDF](../WDLang5/1000020519.md). Cette fonction permet d'utiliser la fenêtre native du système pour configurer l'impression du fichier.  
<a name="NOTE3_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Impression dans les applications Android
<a name="impression_dans_les_applications_android_ELTPARAGRAPHE000125"></a>

Sous Android, seules les impressions au format PDF sont disponibles. 

Par défaut, si la fonction [iDestination](../WDLang5/3046074.md) n'est pas appelée avant de lancer une impression PDF, un fichier "document.pdf" sera généré dans le répertoire des fichiers de l'application.

S'il est nécessaire d'ouvrir le document PDF généré par les fonctions d'impression avec une application externe (en utilisant la fonction [LanceAppliAssociée](../WDLang1/3035007.md) par exemple), le document doit se trouver sur la mémoire externe de l'appareil (sdcard par exemple) pour qu'il soit accessible par les autres applications.   

Exemple: 


```wl
iDestination(iPDFGénérique, ComplèteRep(SysRepCarteStockage()) + "document.pdf")
```


Si nécessaire, le fichier PDF créé peut être imprimé depuis le matériel grâce à la fonction [iImprimePDF](../WDLang5/1000020519.md). Cette fonction permet d'imprimer le fichier en utilisant le service Cloud Print de Google.
