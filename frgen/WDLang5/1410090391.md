
## XMLVérifieSignature (Fonction)

***En anglais : XMLVerifySignature***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie la signature d'un noeud XML. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
maVérif est un xmlVérificationSignature
maVérif.Clé = "maclépublique.pem"

monDocXML est un xmlDocument = xmlOuvre("fichieraverifier.xml", XMLConserveNoeudTexteVide)

SI PAS XMLVérifieSignature(maVérif, monDocXML.Racine.NoeudSigne) ALORS
	Erreur("Signature invalide")
SINON
	Info("Ok")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = XMLVérifieSignature(<Vérification de signature> , <Noeud XML à vérifier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la signature est correcte, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Vérification de signature> : (Variable de type xmlVérificationSignature)`**

Nom de la variable de type [xmlVérificationSignature](../WDLang5/1410090389.md) contenant les informations nécessaires pour la vérification d'une signature XML. 

**`<Noeud XML à vérifier> : (Variable de type xmlNoeud)`**

Noeud XML dont la signature doit être vérifiée. 






## Remarques
Lors de l'ouverture du document XML via la fonction [XMLOuvre](../WDLang5/1000018792.md), utilisez la constante *XMLConserveNoeudTexteVide*. En effet, le document ne doit subir aucune modification avant la vérification de la signature.
