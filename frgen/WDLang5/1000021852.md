


## FBEtatSession (Fonction)

***En anglais : FBSessionStatus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie l'état d'une session Facebook. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Attention** : Cette fonctionnalité est disponible jusqu'à Android 11. A partir d'Android 12, cette fonction provoque une erreur fatale. 
Il est conseillé de : 

- tester la version d'Android utilisée via la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- utiliser la fonction [AuthIdentifie](../WDLang3/1000022219.md) pour gérer l'authentification Facebook. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaSession est une fbSession

SI FBEtatSession(MaSession) <> fbSessionOuverte ALORS
	Info("Pas de session ouverte")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = FBEtatSession(<Session>)`
---

**`<Résultat> : (Constante de type Entier)`**

Etat de la session : 



|   |   |
| --- | --- |
| *fbSessionFermée* | Session Facebook fermée. |
| *fbSessionOuverte* | Session Facebook ouverte. |
| *fbSessionPermissionIncorrecte* | Session Facebook ouverte avec des droits différents de ceux de la session passée en paramètre. |



**`<Session> : (Variable de type fbSession)`**

Nom de la variable de type [fbSession](../WDLang5/1000021851.md) correspondant à la connexion à manipuler.
