


## Fonctions Facebook
			



**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Facebook (syntaxe préfixée)](../WDLang5/1000021947.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Attention : Ces fonctions ne sont pas disponibles pour les applications WINDEV sous Linux. Les fonctions suivantes permettent de gérer l'authentification Facebook.



|   |   |
| --- | --- |
| [FBEtatSession](../WDLang5/1000021852.md) | Vérifie l'état d'une session Facebook. |
| [FBFermeSession](../WDLang5/1000021836.md) | Ferme la session Facebook ouverte avec la fonction [FBOuvreSession](../WDLang5/1000021835.md). |
| [FBOuvreSession](../WDLang5/1000021835.md) | Permet l'authentification et la connexion à Facebook. |
| [FBRécupèreInformationUtilisateur](../WDLang5/1000021837.md) | Récupère les informations Facebook de l'utilisateur connecté. |
| [FBRequête](../WDLang5/1000021838.md) | Effectue une requête de communication (requête HTTP) à la Graph API de Facebook. |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Attention** : Cette fonctionnalité est disponible jusqu'à Android 11. A partir d'Android 12, cette fonction provoque une erreur fatale. 
Il est conseillé de : 

- tester la version d'Android utilisée via la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- utiliser la fonction [AuthIdentifie](../WDLang3/1000022219.md) pour gérer l'authentification Facebook.
