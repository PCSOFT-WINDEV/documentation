## Erreur ERR_BAD_CONTEXT
<a name="erreur_errbadcontext_ELTTEXTE000072"></a>
Le contexte auquel cette requête fait référence n'existe pas (ou plus). Vous avez peut-être été déconnecté ERR_BAD_CONTEXT. 

Ce message est affiché par le navigateur Internet lorsque le moteur WEBDEV n'est plus actif.

Le moteur WEBDEV n'est plus actif dans plusieurs cas :

- le temps d'inactivité a été dépassé : l'internaute a été déconnecté.
	**Solution :** relancer l'application, et paramétrer si nécessaire dans les options de l'outil d'administration (local ou à distance) un délai de déconnexion en cas d'inactivité plus important.

- la page HTML n'a pas été rafraîchie (en mode test uniquement)
	**Solution :** Rafraîchir l'affichage de la page par le bouton [Rafraîchir] sous le navigateur Internet.
