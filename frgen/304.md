
## Administrateur WEBDEV distant : Créer un compte WEBDEV
			



## Gestion des comptes WEBDEV
<a name="gestion_des_comptes_webdev_ELTTEXTE000126"></a>
La gestion des comptes est accessible dans l'administrateur distant uniquement pour l'administrateur du serveur.

La gestion des comptes permet de gérer les comptes WEBDEV directement depuis l'outil d'administration à distance.

**Rappel** : Un compte WEBDEV est un compte associé à un responsable de sites. Ce compte est créé par l'administrateur du serveur sur un serveur Web.

Ce compte permet à l'administrateur du serveur de :

- regrouper les différents sites d'un responsable de sites. Ces sites sont installés sur un seul serveur.

- paramétrer le nombre total de connexions autorisées pour tous les sites du responsables de sites.

- paramétrer le répertoire de transfert des fichiers (pour les installations et mises à jour de sites par FTP).




Ce compte permet aux responsables de sites de :

- utiliser l'administrateur à distance pour gérer les sites installés sur le serveur.

- faire des installation et mises à jour à distance (par FTP).






## Gestion des comptes
<a name="gestion_des_comptes_ELTTEXTE000150"></a>
Pour lister les comptes WEBDEV :

1. Sélectionnez l'option "Comptes" dans la barre de menu.

2. Dans la zone "Gestion des comptes", la liste des comptes existants apparaît.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0012.gif&type=thumb)





Il est possible de modifier les caractéristiques des comptes. Pour plus de détails, consultez [ Modifier les caractéristiques d'un compte](../WDAdminWeb/203.md).







## Création d'un compte WEBDEV
<a name="creation_compte_webdev_ELTTEXTE000174"></a>
Pour créer un nouveau compte WEBDEV :

1. Sélectionnez l'option "Comptes" dans la barre de menu.

2. Dans la zone "Création d'un compte", saisissez le login et le mot de passe du compte à créer, puis cliquez sur le bouton "Créer".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0012%201.gif)


3. Saisissez les caractéristiques du compte :

	- informations personnelles du responsable de sites,

	- nombre de connexions maximum accordées au responsable de sites pour tous ses sites dynamiques WEBDEV.

	- répertoires de base,

	- sites dynamiques associés au compte (si nécessaire).





Pour plus de détails, consultez [Modifier les caractéristiques d'un compte](../WDAdminWeb/203.md).





## Suppression d'un compte WEBDEV
<a name="suppression_compte_webdev_ELTTEXTE000198"></a>
Pour supprimer un compte WEBDEV dans l'administrateur distant :

1. Sélectionnez l'option "Comptes" dans la barre de menu de l'administrateur distant.

2. Dans la zone "Gestion des comptes", sélectionnez le compte WEBDEV à supprimer.

3. Cliquez sur le bouton "Supprimer".








## Importer des comptes WEBDEV d'une version antérieure
<a name="importer_des_comptes_webdev_une_version_anterieure_ELTTEXTE000222"></a>
Pour importer des comptes WEBDEV d'une version de Serveur d'Application antérieure :

1. Sélectionnez l'option "Comptes" dans la barre de menu de l'administrateur distant. 

2. Dans la zone "Importation de comptes", cliquez sur le bouton "Importer".

3. Renseignez le ou les chemins des fichiers de données des versions antérieures de WEBDEV.

4. Cliquez sur le bouton "Rechercher" pour actualiser la liste des comptes.

5. Cochez la case "Importer ce compte" pour tous les comptes à importer. Vous pouvez modifier toutes leurs caractéristiques.

6. Cliquez sur le bouton "Importer" pour déclencher l'import.






## Comptes de statistiques
<a name="comptes_statistiques_ELTTEXTE000276"></a>


### Présentation
<a name="presentation_ELTPARAGRAPHE000249"></a>Les comptes de statistiques permettent d'accéder au module de statistiques de l'administrateur WEBDEV distant. Il suffit de lancer l'administrateur distant et d'indiquer le login et le mot de passe du compte de statistiques. Pour plus de détails sur les statistiques, consultez [Administrateur WEBDEV distant : Statistiques](../WDAdminWeb/6466.md).  


### Créer un compte de statistiques
<a name="creer_compte_statistiques_ELTPARAGRAPHE000257"></a>Pour créer un compte de statistiques :

1. Cliquez sur le lien "&lt;Login&gt;" présent dans la barre de menu. Dans la popup qui s'affiche, cliquez sur "Voir mon profil".

2. Dans la section "Edition des comptes de statistiques", cliquez sur le bouton "Nouveau".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0014%202.gif&type=thumb)


3. Saisissez les informations demandées : login, mot de passe, ...

4. Validez en cliquant sur le bouton "Appliquer". 

5. Indiquez les sites et les Webservices pour lesquels les statistiques peuvent être consultées. 

6. Le compte de consultation des statistiques est créé et peut être utilisé. 




**Remarques** : 

- Le bouton "Editer" permet de modifier les informations d'un compte de statistiques. 

- Le bouton "Supprimer" permet de supprimer un compte de statistiques.
