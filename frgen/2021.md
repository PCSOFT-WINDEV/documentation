## Erreur ERR_NOTACTIVATED
<a name="erreur_errnotactivated_ELTTEXTE000066"></a>
Le module n'a pas été activé. Il faut le réinstaller - ERR_NOTACTIVATED (39)

WEBDEV n'a pas été installé correctement. Réinstallez WEBDEV.

**Rappel : Il existe deux versions de WEBDEV :**

- WEBDEV version développement, utilisable uniquement lors du développement d'une application WEBDEV

- WEBDEV version déploiement. Cette version doit être installée sur le poste serveur lors du déploiement d'un site dynamique WEBDEV.
