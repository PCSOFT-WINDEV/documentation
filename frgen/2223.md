## Erreur ERR_NO_TABLE
<a name="erreur_errnotable_ELTTEXTE000061"></a>
La commande &lt;NOM_COMMANDE&gt; ne fonctionne qu'avec les tables, et &lt;NOM_CHAMP&gt; n'est pas une table. ERR_NO_TABLE (37)

Le paramètre WD_ACTION_ a été utilisé sur un champ qui n'était pas de type TABLE.
Vérifiez les actions personnalisées présentes dans votre page.
