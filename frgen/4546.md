
## L'action demandée n'a pas pu être effectuée : la page n'était pas en phase
			



## Erreur ERR_SYNCHRONIZATION
<a name="erreur_errsynchronization_ELTTEXTE000063"></a>
Le contexte de page présent sur le serveur et la page affichée dans le navigateur sur le poste de l'internaute ne sont pas en phase : les données affichées et celles présentes sur le serveur ne correspondent pas.

Ce message est affiché notamment lorsque l'internaute a utilisé le bouton "Précédent" du navigateur.



Il est recommandé dans un site dynamique WEBDEV de tester complètement le site avant de le déployer, et notamment l'utilisation du bouton "Précédent" du navigateur. WEBDEV propose une méthode automatique de gestion du bouton "Précédent" du navigateur. Pour plus de détails, consultez l'aide en ligne de WEBDEV version développement.
