


## VisiteGuidée (Type de variable)

***En anglais : GuidedTour***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **VisiteGuidée** permet de définir toutes les caractéristiques avancées d'une visite guidée et de ses étapes. Les caractéristiques de cette visite guidée peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

Les caractéristiques des étapes peuvent être personnalisées grâce à la variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md). Pour toutes les caractéristiques d'étapes non personnalisées, les caractéristiques définies dans la variable **VisiteGuidée** seront utilisées.   

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
vg est une VisiteGuidée
vg.Étape[1].Titre = "Etape 1"
vg.Étape[2].Titre = "Etape 2"
vg.Étape[3].Titre = "Etape 3"
vg.Effet.Couleur = VertClair   
vg.Étape[2].Effet.Couleur = OrangeClair
// les étapes 1 et 3 ont un fond vert, l'étape 2 a un fond orange
```

## Propriétés


### Propriétés spécifiques à la description des variables de type VisiteGuidée
<a name="proprietes_specifiques_description_des_variables_type_visiteguidee_ELTPARAGRAPHE000030"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **VisiteGuidée** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| ActionCible | Entier | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours. Les actions disponibles sont les suivantes : <br><br>- *vgaAucune* : Le clic sur le ou les champs cibles est sans effet. <br><br>- *vgaDéfaut* (défaut) : L'action effectuée dépend du type d'effet choisi : <br><br>	- si l'effet choisi correspond au Grisage des Fenêtres Inactives (GFI), l'action effectuée correspondra à la constante *vgaAucune*.<br><br>	- si l'effet choisi correspond au halo, l'action effectuée correspondra à la constante *vgaChamp*.<br><br>	- si aucun effet n'a été choisi, l'action effectuée correspondra à la constante *vgaChamp*.<br><br><br><br><br>- *vgaChamp* : Le champ fonctionne normalement. Les événements associés au champ sont exécutés. Le passage à l'étape suivante doit être fait par programmation.  <br><br>- *vgaChampPuisEtapeSuivante* : Le champ fonctionne normalement. A la fin de l'exécution du code du champ, la visite guidée passe automatiquement à l'étape suivante. <br>	Cette action est opérationnelle uniquement sur les champs suivants : Bouton, Interrupteur, Sélecteur et Option de menu. Pour les autres champs, seul le passage à l'étape suivante sera effectué. <br><br>- *vgaEtapeSuivante* : Le clic sur le champ permet uniquement de passer à l'étape suivante. <br><br>- *vgaFin* : Le clic sur le champ termine toute la visite guidée.<br><br><br><br><br>Cette propriété peut être surchargée par étape. |
| ActionHorsCible | Entier | Action effectuée lors d'un clic sur des champs différents des champs cibles de l'étape en cours. Les actions disponibles sont les suivantes : <br><br>- *vgaAucune* : Le clic sur le ou les champs cibles est sans effet. <br><br>- *vgaDéfaut* (défaut) : L'action effectuée dépend du type d'effet choisi : <br><br>	- si l'effet choisi correspond au Grisage des Fenêtres Inactives (GFI), l'action effectuée correspondra à la constante *vgaAucune*.<br><br>	- si l'effet choisi correspond au halo, l'action effectuée correspondra à la constante *vgaChamp*.<br><br>	- si aucun effet n'a été choisi, l'action effectuée correspondra à la constante *vgaChamp*.<br><br><br><br><br>- *vgaChamp* : Le champ fonctionne normalement. Les événements associés au champ sont exécutés. Le passage à l'étape suivante doit être fait par programmation.  <br><br>- *vgaChampPuisEtapeSuivante* : Le champ fonctionne normalement. A la fin de l'exécution du code du champ, la visite guidée passe automatiquement à l'étape suivante. <br>	Cette action est opérationnelle uniquement sur les champs suivants : Bouton, Interrupteur, Sélecteur et Option de menu. Pour les autres champs, seul le passage à l'étape suivante sera effectué. <br><br>- *vgaEtapeSuivante* : Le clic sur le champ permet uniquement de passer à l'étape suivante. <br><br>- *vgaFin* : Le clic sur le champ termine toute la visite guidée.<br><br><br><br><br>Cette propriété peut être surchargée par étape. |
| Bulle | <br><br> | Paramètres d'affichage de la bulle d'aide affichée pour l'étape en cours. Chacune des sous propriétés peut être surchargée par étape. |
| *Bulle.ActionAutorisée* | <br><br> | Actions autorisées dans la bulle d'aide. L'interface de la fenêtre interne par défaut sera adaptée en fonction des options choisies. <br>Cette propriété et ses sous propriétés sont ignorées si le mode de la bulle d'aide correspond à la constante *vgModeTransparent*. |
| *Bulle.ActionAutorisée.EtapePrécédente* | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> (par défaut) pour autoriser le passage à l'étape précédente, <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire. <br><br><br> |
| *Bulle.ActionAutorisée.EtapeSuivante* | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> (par défaut) pour autoriser le passage à l'étape suivante, <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire. <br><br><br> |
| *Bulle.ActionAutorisée.FinVisite* | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> (par défaut) pour autoriser à terminer la visite, <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire. <br><br><br> |
| *Bulle.Couleur* | Entier | Couleur des textes de la bulle (titre et description)<br><br>Valeur par défaut : <br><br>- si la propriété **Bulle.Mode** correspond à la constante *vgModeOpaque*, la couleur sera 0x000000,<br><br>- si la propriété **Bulle.Mode** correspond à la constante *vgModeTransparent*, la couleur par défaut sera 0xFFFFFF. <br><br><br> |
| *Bulle.CouleurCadre* | Entier | Couleur du cadre de la bulle. <br><br>Valeur par défaut : 0xFF3B85FA |
| *Bulle.CouleurFond* | Entier | Couleur de fond de la bulle. <br><br>Cette propriété est ignorée si la propriété **Bulle.Mode** correspond à la constante *vgModeTransparent*.<br><br>Valeur par défaut : 0xFFFFFF |
| *Bulle.FenêtreInterne* | Chaîne de caractères | Nom de la fenêtre interne du projet à utiliser pour personnaliser l'affichage dans la bulle. <br>Si cette propriété correspond à chaîne vide (""), la fenêtre par défaut fournie par le moteur d'exécution WINDEV / WINDEV Mobile est utilisée. |
| *Bulle.Marge* | Entier | Marge en pixels entre les bords de la bulle et son contenu (fenêtre interne). <br><br>Valeur par défaut : 15 |
| *Bulle.Markdown* | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si les champs de la fenêtre interne utilisés pour afficher le titre et la description de l'étape sont affichés au format Markdown, <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire. <br><br><br> |
| *Bulle.Mode* | Constante de type Entier | Mode d'affichage de la bulle : <br><br>- *vgModeOpaque* (par défaut) : la bulle est affichée dans une fenêtre popup avec une flèche qui pointe sur le ou les champs cible. Avec la fenêtre interne par défaut, des boutons permettent de passer à l'étape suivante/précédente ou de terminer la visite.<br><br>- *vgModeTransparent* : la bulle est affichée avec un fond transparent à côté du ou des champs cible. Dans ce mode aucune interaction n'est possible avec les champs de la fenêtre interne. Dans ce mode, il est conseillé d'utiliser l'effet GFI (constante *vgtGFI* utilisée avec la propriété **Effet.Type**).<br><br><br> |
| *Bulle.PageInterne* | Chaîne de caractères | Nom de la page interne du projet à utiliser pour personnaliser l'affichage dans la bulle. <br>Si cette propriété correspond à chaîne vide (""), la page par défaut fournie par le moteur d'exécution WEBDEV est utilisée. |
| DuréeValidationAutomatique | Durée | Délai en secondes avant la validation automatique des étapes de la visite. A la fin de ce délai, la visite passe automatiquement à l'étape suivante. <br>Si le délai est de 0, aucun validation automatique n'est effectuée. <br>Par défaut, cette propriété vaut 0. |
| Effet | <br><br> | Effet d'affichage à utiliser pour mettre en évidence le ou les champ(s) cible(s) pour toutes les étapes de la visite.<br><br>Chacune des sous propriétés peut être surchargée par étape. |
| *Effet.Agrandissement* | Entier | Pourcentage d’agrandissement du halo. Par défaut, cette propriété correspond à 100%. <br><br>Cette propriété est ignorée pour les autres effets. |
| *Effet.Arrondi* | Entier | Rayon en pixels de l'arrondi à appliquer pour les coins du rectangle lorsque la forme de l'effet est un rectangle (constante vgfRectangle). Par défaut, cette propriété correspond à 5. |
| *Effet.Couleur* | Entier | Couleur de l'effet GFI ou halo. Par défaut : <br><br>- si l'effet correspond au GFI, la couleur correspond à 0x0C0C0C, <br><br>- si l'effet correspond au halo, la couleur correspond à 0xCCBFE9. <br><br><br> |
| *Effet.DuréeAnimation* | Entier | Durée de l'animation de l'effet en millisecondes. Par défaut : <br><br>- si l'effet correspond au GFI, la durée de l'animation est 300, <br><br>- si l'effet correspond au halo, la durée de l'animation est 1000. <br><br><br> |
| *Effet.Forme* | Entier | Forme à utiliser pour le "trou" (effet GFI) ou pour le halo (effet Halo) : <br><br>- *vgfCercle* : cercle, <br><br>- *vgfRectangle* : rectangle (avec bord arrondi selon la valeur de la propriété **Effet.Arrondi**). <br><br><br> |
| *Effet.Marge* | Entier | Marge en pixels entre les contours de la forme choisie (propriété Forme) et les bords du ou des champs cibles.<br><br>Par défaut, cette marge vaut 10 pixels. |
| *Effet.Opacité* | Entier | Opacité de la couleur de l'effet (pourcentage).<br><br>Par défaut, pour l'effet GFI, cette propriété correspond à 70%, et pour l'effet halo, cette propriété correspond à 100%. |
| *Effet.Type* | Constante de type Entier | Type d'effet : <br><br>- *vgtAucun* : aucun effet d'affichage<br><br>- *vgtGFI* : grise le contenu de la fenêtre hôte en laissant apparaitre un trou de la forme choisie par la propriété Forme autour du ou des champ(s) cible(s). <br><br>- *vgtHalo* (valeur par défaut) : affiche un halo de la forme choisie par la propriété Forme autour du ou des champ(s) cible(s).<br><br><br> |
| Étape | Tableau de [VisiteGuidéeEtape](../WDLang6/1410090178.md) |   |
| Identifiant | Chaîne de caractères | Identifiant de la visite utilisé pour la persistance.<br>Cette propriété doit être spécifiée et son contenu doit être unique pour le projet/l'application en cours. <br><br>Cet identifiant est notamment utilisé avec la fonction [VisiteGuidéeInfo](../WDLang6/1410090219.md). Il est par exemple possible de ne plus afficher la visite guidée si l'utilisateur l'a déjà vue. <br>Exemple : <br><br><pre><code>SI VisiteGuidéeInfo(VisiteDécouverte.Identifiant, ...<br>		vgInfoOccurrence) = 0 ALORS<br>	VisiteGuidéeDémarre(VisiteDécouverte)<br>FIN</code></pre><br> |
| Initialisation | Procédure WLangage | Procédure WLangage exécutée au lancement de la visite guidée. Si cette procédure renvoie <u><u><u>Faux</u></u></u>, la visite guidée est arrêtée. |
| Terminaison | Procédure WLangage | Procédure WLangage exécutée à la fin de la visite guidée. |
| Version | Entier | Numéro de version de la visite guidée. Par défaut, cette propriété vaut 1. <br>Cette propriété doit être incrémentée par le développeur selon les nouveautés à montrer dans la visite guidée.<br><br>Ce numéro de version peut notamment être utilisé avec la fonction [VisiteGuidéeInfo](../WDLang6/1410090219.md). Il est par exemple possible d'afficher la visite guidée si des nouveautés sont disponibles. <br>Exemple : <br><br><pre><code>// Affiche les nouveautés d'une version <br>VisiteNouveauté est un VisiteGuidée<br>VisiteNouveauté.Identifiant = "Nouveauté de la version"<br>VisiteNouveauté.Version = 29<br>SI VisiteGuidéeInfo(VisiteNouveauté, vgInfoVersion) < 29 ALORS<br>VisiteNouveauté.Étape[1].Cible = SAI_Prénom<br>VisiteNouveauté.Étape[1].Titre = "Nouveau !"<br>VisiteNouveauté.Étape[1].Description = ...<br>	"Vous pouvez maintenant saisir votre prénom"<br>VisiteGuidéeDémarre(VisiteNouveauté)<br>FIN</code></pre><br> |
