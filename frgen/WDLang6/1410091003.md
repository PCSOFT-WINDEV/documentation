


## &lt;Fenêtre&gt;.PaletteRécupère (Fonction)

***En anglais : &lt;Window&gt;.PaletteGet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère la palette de la fenêtre.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaPalette est une Palette = FEN_Menu.PaletteRécupère()
LIB_Problème.CouleurFond = MaPalette["attention"]
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Fenêtre>.PaletteRécupère()`
---

**`<Résultat> : (Variable de type Palette)`**

Variable de type [Palette](../WDLang1/1000021347.md) contenant la palette de la fenêtre spécifiée. 

**`<Fenêtre> : (Nom de la fenêtre)`**

Nom de la fenêtre pour laquelle la palette doit être récupérée.
