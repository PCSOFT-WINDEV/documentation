
## Python : Utilisation en WLangage
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000078"></a>
Le WLangage permet d'utiliser des fonctions Python en mode natif (pour plus de détails, consultez [Python : Appels natifs](../WDLang6/1410088133.md)). Il est également possible d'exécuter directement des fonctions Python depuis le code WLangage. 

Plusieurs fonctions sont à votre disposition : 



|   |   |
| --- | --- |
| [PythonAjouteChemin](../WDLang6/1410088169.md) | Permet d'ajouter le chemin d'un répertoire ou le chemin de l'environnement virtuel pour la recherche des modules Python. |
| [PythonExécute](../WDLang6/1410088102.md) | Exécute une fonction présente dans un module Python. |
| [PythonInitialise](../WDLang6/1410088100.md) | Indique l'emplacement de la DLL Python à charger. |
| [PythonTermine](../WDLang6/1410088101.md) | Décharge la DLL Python et libère la mémoire. |






### Attention
<a name="attention_ELTPARAGRAPHE000131"></a>

- L'exécutable déployé doit avoir les modules ".py" accessibles sur disque dans son dossier, ou à l'emplacement donné par la fonction [PythonAjouteChemin](../WDLang6/1410088169.md). Les modules ".py" ne peuvent pas être trouvés s'ils sont intégrés à la bibliothèque de l'exécutable.

- Python fait la différence entre les majuscules et les minuscules ("case-sensitive"). Le nom du module et de la fonction doivent donc respecter la casse.

## Exemples de code
<a name="exemples_code_ELTTEXTE000140"></a>
Exemple 1 : 

```wl
// Initialisation de l'interpréteur Python
PythonInitialise(CHEMIN_INSTALL_PYTHON + "\Python39\python3.dll")
// Déclare les chemins d'import des modules utilisés
PythonAjouteChemin("D:\source.test\pythonProject\venv\Lib\site-packages")
PythonAjouteChemin("D:\source.test\pythonProject")
// Résolution de 5x³+x²-3x+2=0
sEquation est une chaîne = "5*x**3+x**2-3*x+2"
sListeRacine est une chaîne = PythonExécute("main", "solveur", sEquation)
nNbRacine est un entier = ChaîneOccurrence(sListeRacine, ",") + 1
Trace("L'équation ""[%sEquation%]"" admet [%nNbRacine%] racines :")
POUR n = 1 _À_ nNbRacine
	Trace("r[%n%] = [%ExtraitChaîne(sListeRacine, n, "", "")%]")
FIN
```


Exemple 2 : 

```wl
sModulePython est une chaîne

	// Exemple d'emplacement du module Python
```
