
## gpwDéconnecteUtilisateur (Fonction)

***En anglais : gpwDisconnectUser***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Déconnecte l'utilisateur courant du groupware utilisateur. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Si un utilisateur est actuellement connecté
SI bConnexionEnCours() ALORS
	// Déconnecte l'utilisateur
	gpwDéconnecteUtilisateur()
	// Ferme toutes les pages et ré-ouvre la page courante 
	// avec les droits d'un utilisateur non connecté (invité)
	PageUtilise(MaPage..Nom)
SINON
	// Activation du SSL
	// Indique la popup à ouvrir lors ré-affichage de la page
	PopupAffiche(POPUP_Login)
FIN
```
