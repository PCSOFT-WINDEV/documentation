


## &lt;VisiteGuidée&gt;.Démarre (Fonction)

***En anglais : &lt;GuidedTour&gt;.Start***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Démarre une visite guidée et affiche la première étape.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaVisiteDécouverte est une VisiteGuidée
// ...
// Démarrage de la visite guidée
MaVisiteDécouverte.Démarre()
// ...
// Arrête la visite guidée MaVisiteDécouverte
MaVisiteDécouverte.Arrête()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Visite guidée>.Démarre([<Etape à afficher>])`
---

**`<Visite guidée> : (Variable de type VisiteGuidée)`**

Nom de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) correspondant à la visite guidée qui doit être démarrée.

**`<Etape à afficher> : (Entier optionnel)`**

Numéro de l'étape de la visite guidée à afficher. Par défaut, l'étape 1 est affichée.
