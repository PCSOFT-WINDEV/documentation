


## &lt;Variable pdfDocument&gt;.ExtraitPage (Fonction)

***En anglais : &lt;pdfDocument variable&gt;.ExtractPage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extrait une page d'un fichier PDF dans une variable de type [Image](../WDLang1/1000019650.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Extrait la page 3 du fichier texte.pdf
MonPDF est un pdfDocument = PDFOuvre("test.pdf")
MonImage est Image = MonPDF.ExtraitPage(3)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE2"></a>

`<Résultat> = <Document PDF>.ExtraitPage(<Numéro de la page> [, <Largeur> [, <Hauteur> [, <Mot de passe>]]])`
---

**`<Résultat> : (Image (variable de type image))`**

Variable de type [Image](../WDLang1/1000019650.md) contenant l'image de la page extraite. L'image renvoyée est une image raster (non vectorielle).

Remarque: Si le fichier PDF n'existe pas ou si la page n'existe pas, la variable [Image](../WDLang1/1000019650.md) renvoyée sera invalide. La variable [ErreurDétectée](../WDLang1/3087001.md) correspondra à <u><u><u><u>Vrai</u></u></u></u>.

**`<Document PDF> : (Variable de type pdfDocument)`**

Nom de la variable de type [pdfDocument](../WDLang6/1000024909.md) correspondant au document PDF à manipuler.

**`<Numéro de la page> : (Entier)`**

Numéro de la page à extraire.

**`<Largeur> : (Entier optionnel)`**

Largeur à laquelle la page doit être rastérisée. 
Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.

**`<Hauteur> : (Entier optionnel)`**

Hauteur à laquelle la page doit être rastérisée. 
Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.

**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe du document PDF.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.
