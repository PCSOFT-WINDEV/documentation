
## IAListeModèleChat (Fonction)

***En anglais : AIChatListModel***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des modèles d'IA disponibles pour un fournisseur. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
sListeModèle est chaîne = IAListeModèleChat(iafournisseurOpenAI, monIA.Identifiant)
COMBO_Modèles.Contenu = sListeModèle
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = IAListeModèleChat(<Fournisseur> [, <Clé d'API>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des modèles d'IA disponibles pour le fournisseur donné séparés par RC. 

**`<Fournisseur> : (Constante de type Entier)`**

Constantes disponibles:


|   |   |
| --- | --- |
| *iafournisseurGoogle* | Fournisseur Google. |
|  *iafournisseurAnthropic* | Fournisseur Anthropic. |
| *iafournisseurOpenAI* | Fournisseur OpenAI. |
| *iafournisseurMistral* | Fournisseur Mistral AI. |
| *iafournisseurPersonnalisé* | Fournisseur personnalisé. |
| *iafournisseurXAI* | fournisseur Grok. |
| *iafournisseurOpenRouter* | Fournisseur OpenRouter. |



**`<Clé d'API> : (Chaîne de caractères optionnelle)`**

Clé d'API nécessaire pour accéder au modèle d'IA. 

**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi - Latin".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md).
