
## MaVisiteGuidée

***En anglais : MyGuidedTour***
				

<a name="description"></a>
La variable **MaVisiteGuidée** permet de manipuler la visite guidée en cours. La variable **MaVisiteGuidée** permet de connaître les caractéristiques de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) utilisée. 

Si aucune visite guidée n'est en cours, **MaVisiteGuidée** renvoie une erreur. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI EnModeVisiteGuidée() = Vrai ALORS
	Trace("Version de la visite guidée en cours : " + MaVisiteGuidée.Version)
FIN
```
