
## CDListe (Fonction)

***En anglais : CDList***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les lecteurs de CD/DVD installés sur le poste en cours.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Affiche la liste des lecteurs de CD/DVD  
// du poste en cours dans le champ LISTE_ListeLecteurs  
ListeAjoute(LISTE_ListeLecteurs, CDListe())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = CDListe()`
---

**`<Résultat> : (Chaîne de caractères)`**

Liste des lecteurs installés sur le poste en cours, sous la forme :

```txt
<Identifiant du lecteur 1> + RC + ... + <Identifiant du lecteur N>
```


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Le poste en cours correspond au serveur Web.
