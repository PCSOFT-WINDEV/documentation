


## &lt;VisiteGuidée&gt;.Arrête (Fonction)

***En anglais : &lt;GuidedTour&gt;.Stop***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête la visite guidée spécifiée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaVisiteDécouverte est une VisiteGuidée
// ...
// Démarrage de la visite guidée
MaVisiteDécouverte.Démarre()
// ...
// Arrête la visite guidée MaVisiteDécouverte
MaVisiteDécouverte.Arrête()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Visite guidée>.Arrête()`
---

**`<Visite guidée> : (Variable de type VisiteGuidée)`**

Nom de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) correspondant à la visite guidée à arrêter.
