
## Fonctions Palette
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
 
Les fonctions de gestion de palettes de couleurs sont les suivantes : 



|   |   |
| --- | --- |
| [PaletteChange](../WDLang6/1410090897.md) | Modifie la palette utilisée par le projet ou par une fenêtre. |
| [PaletteRécupère](../WDLang6/1410090898.md) | Récupère la palette courante du projet ou de la fenêtre. |
