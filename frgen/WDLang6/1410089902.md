


## Fonctions de gestion des fichiers PDF (syntaxe préfixée)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>

Pour manipuler les fichiers PDF, le WLangage dispose de différents types de variables :  



|   |   |
| --- | --- |
| [pdfChamp](../WDLang6/1410090536.md) | Le type **pdfChamp** permet de connaître toutes les caractéristiques et les valeurs d'un champ présent dans un formulaire au format PDF. |
| [pdfDocument](../WDLang6/1000024909.md) | Le type **pdfDocument** permet de connaître toutes les caractéristiques d'un fichier PDF : auteur, date de création, contenu des pages, ... |
| [pdfElémentTexte](../WDLang6/1000024556.md) | Le type **pdfElémentTexte** permet de connaître toutes les caractéristiques d'un élément textuel dans une page PDF. |
| [pdfOptionChamp](../WDLang6/1410090533.md) | Le type **pdfOptionChamp** permet de connaître et de modifier les caractéristiques suivantes d'une option d'un champ présent dans un formulaire PDF : <br><br>- libellé de l'option. <br><br>- sélection ou non de l'option.<br><br><br> |
| [pdfPage](../WDLang6/1000024904.md) | Le type **pdfPage** permet de définir toutes les caractéristiques avancées d'une page d'un document PDF chargé en mémoire. |
| [pdfParamètre](../WDLang6/1410087857.md) | Le type **pdfParamètre** permet de définir toutes les caractéristiques d'un fichier PDF à générer. |
| [pdfPièceJointe](../WDLang6/1000024899.md) | Le type **pdfPièceJointe** permet de définir toutes les caractéristiques avancées d'une pièce jointe dans un document PDF. |
| [pdfProtection](../WDLang6/1410091145.md) | Le type **pdfProtection** permet de connaître les différentes protections appliquées à un document PDF présent dans une variable de type [pdfDocument](../WDLang6/1000024909.md).<br><br> |
| [pdfSignature](../WDLang6/1000022255.md) | Le type **pdfSignature** permet de définir toutes les caractéristiques avancées d'une signature à appliquer à un fichier PDF lors de la signature d'un PDF existant (via la fonction [&lt;Variable pdfDocument&gt;.Signe](../WDLang6/1410090339.md)).  |
| [pdfSignet](../WDLang6/1410089195.md) | Le type **pdfSignet** permet de définir toutes les caractéristiques avancées d'un signet dans un document PDF. |






Les fonctions suivantes permettent de manipuler des fichiers PDF via une syntaxe préfixée : 



|   |   |
| --- | --- |
| [&lt;Variable pdfDocument&gt;.AjouteFiligrane](../WDLang6/1410087872.md) | Ajoute un filigrane sur toutes les pages d'un fichier PDF existant. |
| [&lt;Variable pdfDocument&gt;.ExtraitPage](../WDLang6/1410090338.md) | Extrait une page d'un fichier PDF dans une variable de type [Image](../WDLang1/1000019650.md). |
| [&lt;Variable pdfDocument&gt;.NbSignature](../WDLang6/1410088154.md) | Récupère le nombre de signatures dans un document PDF. |
| [&lt;Variable pdfDocument&gt;.RécupèreDateSignature](../WDLang6/1410088157.md) | Récupère la date de l'une des signatures d'un document PDF. |
| [&lt;Variable pdfDocument&gt;.RécupèreSignature](../WDLang6/1410088159.md) | Récupère la signature d'un document PDF sous forme d'un buffer. |
| [&lt;Variable pdfDocument&gt;.Sauve](../WDLang6/1410088160.md) | Sauve le contenu d'une variable de type [pdfDocument](../WDLang6/1000024909.md) dans un fichier ".PDF". |
| [&lt;Variable pdfDocument&gt;.Signe](../WDLang6/1410090339.md) | Applique une signature d'approbation sur un PDF existant. |
| [&lt;Variable pdfDocument&gt;.VérifieSignatures](../WDLang6/1410091037.md) | Vérifie la validité des signatures contenues dans un PDF.<br><br> |
| [&lt;Variable pdfDocument&gt;.VersTexte](../WDLang6/1410090340.md) | Extrait le texte contenu dans un document PDF. |
| [&lt;Variable pdfPage&gt;.AjouteFiligrane](../WDLang6/1410087871.md) | Ajoute un filigrane sur une page d'un fichier PDF existant. |
| [&lt;Variable pdfPage&gt;.AjouteImage](../WDLang6/1410087875.md) | Ajoute une image dans une page d'un fichier PDF existant. |
