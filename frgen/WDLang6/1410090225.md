


## VisiteGuidéeArrête (Fonction)

***En anglais : GuidedTourStop***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête la visite guidée spécifiée ou la visite guidée en cours.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Arrête la visite guidée en cours
VisiteGuidéeArrête()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`VisiteGuidéeArrête([<Visite guidée>])`
---

**`<Visite guidée> : (Variable optionnelle de type VisiteGuidée)`**

Nom de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) correspondant à la visite guidée à arrêter. 
Si ce nom n'est pas spécifié, la visite guidée en cours est arrêtée. 
Si aucune visite guidée n'est en cours, ou si une visite guidée différente de celle spécifiée est en cours, cette fonction n'a aucun effet.
