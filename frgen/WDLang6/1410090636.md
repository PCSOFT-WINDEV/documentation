


## &lt;Variable pdfDocument&gt;.Extrait (Fonction)

***En anglais : &lt;pdfDocument variable&gt;.Extract***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Crée un nouveau document PDF à partir de différentes pages extraites d'un fichier PDF existant. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonPDFSource est un pdfDocument
MonPDFDestination est un pdfDocument
MonPDFSource = "C:\Temp\MonPDF_Source.pdf"
// Extraction des pages 3, 10, 15 à 16 et 36
MonPDFDestination = MonPDFSource.Extrait("3,10,15-16,36")
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
MonPDFDestination.Sauve("C:\Temp\MonPDF_Destination.pdf")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Fichier PDF source>.Extrait(<Pages à extraire> [, <Mot de passe>])`
---

**`<Résultat> : (Variable de type pdfDocument)`**

Variable de type [pdfDocument](../WDLang6/1000024909.md) correspondant au nouveau PDF contenant la ou les pages extraites.

**`<Fichier PDF source> : (Variable de type pdfDocument)`**

Nom de la variable de type [pdfDocument](../WDLang6/1000024909.md) correspondant au fichier PDF à partir duquel la ou les pages doivent être extraites. 

**`<Pages à extraire> : (Chaîne de caractères)`**

Liste des pages à extraire. Les différentes pages à extraire doivent être séparées par une virgule (","). Pour indiquer un ensemble de pages, la première et la dernière page de l'ensemble doivent être séparées par un tiret ("-"). Par exemple : "1-10, 15-18, 35"

**`<Mot de passe> : (Chaîne de caractères optionnelle)`**

Mot de passe du document PDF.
