


## PaletteRécupère (Fonction)

***En anglais : PaletteGet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère la palette courante du projet ou la palette de la fenêtre.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaPalette est une Palette = PaletteRécupère()
LIB_Problème.CouleurFond = MaPalette["attention"]
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = PaletteRécupère([<Fenêtre>])`
---

**`<Résultat> : (Variable de type Palette)`**

Variable de type [Palette](../WDLang1/1000021347.md) contenant la palette de la fenêtre spécifiée ou celle du projet. 

**`<Fenêtre> : (Nom de fenêtre optionnel)`**

Nom de la fenêtre pour laquelle la palette doit être récupérée. Si ce paramètre n'est pas spécifié, la palette récupérée sera celle du projet en cours.
