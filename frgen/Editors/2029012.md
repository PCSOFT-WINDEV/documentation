
## Barre des documents ouverts
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000108"></a>
La barre des documents de l'environnement permet de naviguer entre les différents éléments ouverts sous les différents éditeurs. 

Si l'éditeur de code affiche un événement WLangage d'un élément d'une fenêtre, les onglets de l'UI et du code sont regroupés dans la barre. 
Dans l'onglet correspondant au code, le nom de l'événement WLangage est affiché.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Barre_document.gif)


Le survol d'un bouton affiche une vignette de l'aperçu : fenêtre, état, requête, code, etc.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Barre_Document_visu.gif)


Chaque document peut être fermé par une croix dans le bouton ou dans la vignette d'aperçu, ce qui est plus rapide. Il est également possible de cliquer sur la roulette de la souris : l'élément survolé est alors fermé.

**Si le nombre de choix est supérieur à l'espace disponible pour son affichage**, la barre devient scrollable : il suffit d'utiliser la roulette de la souris pour faire défiler les différents éléments. 
Il est également possible de déplacer un bouton de la barre par un simple "Drag and Drop".

Un menu permet d'afficher la liste de tous les éléments ouverts. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=barre_document_Menu.gif)


Remarques : 

- Le menu contextuel de la barre des documents (et non pas d'un document) permet de rouvrir le ou les éléments qui ont été précédemment ouverts puis fermés (option "Récemment fermés"). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Recent_Ouvert.gif)


- En fonction des ressources Windows disponibles, les éléments du projet les plus anciens ouverts sous l'éditeur seront fermés si nécessaire.  





### Menu contextuel des boutons
<a name="menu_contextuel_des_boutons_ELTPARAGRAPHE000047"></a>Le menu contextuel de chacun des boutons de cette barre propose de nombreuses options. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Barre_document_Fermer.gif)
L'option "Fermer tout sauf moi-même" est vraiment incontournable. 

**Utilisation du GDS** : 
Si le projet est présent dans le GDS, le menu contextuel s'adapte. Plusieurs options permettent de manipuler l'élément en cours. L'option "Fermer les documents non extraits" permet de conserver uniquement les documents en cours de modification. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0011.gif)
