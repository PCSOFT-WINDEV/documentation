


## Synchroniser le schéma des données avec les bases de données externes
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000124"></a>
La synchronisation du schéma des données avec une base de données externe est nécessaire si votre schéma des données manipule :

- des tables provenant d'une base de données externe (Oracle, SQL Server, etc.).

- des tables dont les données n'ont pas été converties au format HFSQL Classic.




Cette synchronisation permet de prendre en compte les éventuelles modifications apportées sur la structure des tables présentes dans la base de données externe.

Il est possible :

- soit de forcer la synchronisation depuis l'éditeur de schémas des données.

- soit de programmer une vérification automatique de l'évolution de la base de données externe à l'ouverture du schéma des données.

<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000148"></a>


### Forcer la synchronisation
<a name="forcer_synchronisation_ELTPARAGRAPHE000028"></a>

Pour forcer la synchronisation : 

1. Ouvrez le schéma des données contenant des tables externes sous l'éditeur de schémas des données.

2. Sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Synchronisation" et sélectionnez "Mettre à jour le schéma des données depuis les bases de données externes". L'assistant de synchronisation avec les bases de données externes se lance.

3. Sélectionnez les bases de données utilisées dans le schéma des données à vérifier.

4. Indiquez le type de vérification et validez. Il est possible de vérifier :

	- soit uniquement les tables communes à la base de données externe et au schéma des données.

	- soit toutes les tables présentes dans la base de données externe.




5. La liste des tables qui ne sont pas en phase avec le schéma des données en cours apparaît. Il est possible de mettre à jour le schéma des données en cours. Choisissez les modifications à appliquer.

6. Programmez si nécessaire une vérification régulière de la structure des bases de données externes. Cette vérification sera effectuée automatiquement à l'ouverture du schéma des données. Indiquez si nécessaire la fréquence de cette vérification.

7. Validez.



<a name="NOTE2_2"></a>


### Programmer une synchronisation régulière (à l'ouverture du schéma des données)
<a name="programmer_une_synchronisation_reguliere_ouverture_schema_des_donnees_ELTPARAGRAPHE000068"></a>

1. Ouvrez le schéma des données contenant des fichiers externes sous l'éditeur de schémas des données.

2. Affichez la fenêtre de description du schéma des données :

	- affichez le menu contextuel du graphe du schéma des données (clic droit). 

	- sélectionnez l'option "Description du schéma des données".




3. Dans l'onglet "Options", sélectionnez la fréquence de la synchronisation :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Synchro.gif)


4. Validez.
