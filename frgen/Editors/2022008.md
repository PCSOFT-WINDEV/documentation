
## Agrandir une fenêtre ou une page
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000145"></a>
Une tendance actuelle est l'agrandissement des fenêtres, des pages et de la taille des polices dans les champs. 

Il est possible d'agrandir automatiquement la taille des polices de l'ensemble des champs d'une sélection, d'une fenêtre, d'une page ou d'un projet sans avoir à changer de thème ou de thème et sans avoir à redimensionner les champs un à un. 

L'augmentation de la taille des polices agrandit et décale automatiquement tous les champs afin de conserver la mise en page. La taille de la fenêtre ou de la page est également agrandie si nécessaire.



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire?
<a name="comment_faire_ELTTEXTE000169"></a>
Pour agrandir une fenêtre ou une page: 

1. Ouvrez la fenêtre ou la page à agrandir sous l'éditeur. 

2. Sous le volet "Alignement", dans le groupe "Autres alignements", déroulez "Agrandir
Aérer" et sélectionnez "Agrandir". 

3. Dans la fenêtre qui s'affiche, indiquez les paramètres permettant de réaliser l'agrandissement: 
	


|   |   |
| --- | --- |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Agrandir_la_fen%EAtre%20-%20HC%20N%B0002.gif&type=thumb)<br> | <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Agrandir_une_page%20-%20HC%20N%B0001.gif&type=thumb)<br> |
| Agrandissement d'une fenêtre | Agrandissement d'une page |



4. Il est possible de: 

	- indiquer le facteur d'agrandissement. 

	- spécifier si la police et les styles doivent être agrandis. 
			![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Dans ce cas, il est possible de: 

		- Créer des surcharges de style: le style de base sera surchargé pour prendre en compte les modifications. 

		- Créer / utiliser un thème agrandi: dans ce cas, un nouveau thème basé sur le thème en cours est généré. Par exemple, si la fenêtre utilise le thème "Phoenix", avec un agrandissement de 25%, un thème "Phoenix (x1.25)" sera créé.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Seuls les éléments provenant des modèles et surchargés seront agrandis.

5. Validez. Les paramètres indiqués sont appliqués. 




Remarques: 

- L'agrandissement peut être effectué sur la sélection en cours, la fenêtre, la page ou le projet. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Si la création d'un thème "agrandi" est demandée, ce thème pourra ensuite être appliqué aux autres éléments du projet. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Si le thème de base est mis à jour, le thème "agrandi" sera également mis à jour automatiquement. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Si la fenêtre contient un modèle de fenêtres, il est nécessaire d'agrandir également le modèle de fenêtres. Il est également possible d'agrandir le projet (le modèle sera automatiquement agrandi avec les autres éléments du projet). 

- Les modèles de champs ne sont pas agrandis.
