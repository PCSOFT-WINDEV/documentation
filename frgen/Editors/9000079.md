


## Génération d'une description d'une table à partir d'une fenêtre ou d'une page
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000131"></a>
Lorsque vous concevez une maquette rapide, il arrive souvent de créer rapidement quelques fenêtres (ou quelques pages), sans définir de tables. Lorsque la maquette est validée, et seulement à ce moment-là, vous décidez de créer les structures des tables.

Plutôt que de créer ces tables "à la main", WINDEV, WEBDEV et WINDEV Mobile vous proposent d'exporter le contenu de la fenêtre (ou de la page) pour créer automatiquement la structure de la table correspondante.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000155"></a>
Pour générer une description d'une table à partir d'une fenêtre ou d'une page :

1. Ouvrez la fenêtre (ou la page) à partir de laquelle vous souhaitez générer la description de la table.

2. Lancez l'assistant de génération d'une description de fichier : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Sous le volet "Fenêtre", dans le groupe "Edition", déroulez "Autres actions" et sélectionnez "Générer une description de table". Il est également possible de sélectionner l'option "Générer une description de fichier" du menu contextuel de la fenêtre. 

	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Sous le volet "Page", dans le groupe "Edition", déroulez "Autres actions" et sélectionnez "Générer une description de fichier". Il est également possible de sélectionner l'option "Générer une description de table" du menu contextuel de la page.




3. Spécifiez :

	- le nom logique de la table. Ce nom sera utilisé pour manipuler la table. Par défaut, ce nom correspond au nom de la fenêtre/page.

	- le libellé de la table résumant succinctement le sujet de la table. Par défaut, ce libellé correspond au titre de la fenêtre/page.

	- la représentation d'un enregistrement dans la table. Cette représentation permet d'améliorer la lisibilité des questions posées lors de la description des liaisons. Cette option doit être précédée d'un article indéfini (UN ou UNE).




4. Passez à l'étape suivante.

5. Sélectionnez les champs à partir desquels les rubriques de la table doivent être créées. Seuls les champs qui peuvent être liés à une rubrique sont proposés. Passez à l'étape suivante.

6. Indiquez si nécessaire le type de clé de chaque rubrique (non clé, clé unique ou clé avec doublons). Passez à l'étape suivante.

7. L'assistant présente la description de la table à générer. Validez.




La nouvelle table devient la table en cours dans l'éditeur de schémas des données. Pour le modifier, double-cliquez sur la table pour afficher la description des rubriques de la table.
Pour plus de détails sur les manipulations d'une table ou d'une rubrique, consultez [Manipulations d'une table](../Editeurs/2011007.md) et [Manipulations d'une rubrique](../Editeurs/2011009.md).

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Correspondance champ - rubrique
<a name="correspondance_champ_rubrique_ELTTEXTE000179"></a>
Tous les champs de la fenêtre / page pouvant être liés à une rubrique (champ de saisie, sélecteur, table, etc.) peuvent devenir des rubriques dans la description de la table générée.

Le type et la taille de la rubrique dépend du type d'information affichée dans le champ (texte, numérique, etc.) et de la taille de saisie.

L'ensemble des caractéristiques du champ sont reprises dans les informations partagées de la rubrique.
