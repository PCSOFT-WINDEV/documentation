
## Maintenance du schéma des données
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000098"></a>
L'éditeur de schémas des données permet d'effectuer plusieurs opérations de maintenance sur le schéma des données affiché sous l'éditeur. 

Pour accéder aux opérations de maintenance, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance". 





<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Liste des rubriques avec règle d'anonymisation
<a name="liste_des_rubriques_avec_regle_anonymisation_ELTTEXTE000122"></a>
Pour lister les rubriques anonymisées depuis l'éditeur de schémas des données :

1. Dans l'éditeur de schémas des données, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance" et sélectionnez "Liste des rubriques avec règle d'anonymisation".

2. La fenêtre qui s'affiche liste les différentes rubriques anonymisées par fichier, ainsi que la règle d'anonymisation utilisée. 




Pour plus de détails sur l'anonymisation, consultez [Anonymisation automatique des données](../WDLang4/9000215.md). 

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Modifier la casse du nom des fichiers et des rubriques
<a name="modifier_casse_nom_des_fichiers_des_rubriques_ELTTEXTE000146"></a>
Pour modifier la casse des noms de fichiers : 

1. Dans l'éditeur de schémas des données, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance" et sélectionnez "Modifier la casse du nom des fichiers". 

2. Dans la fenêtre qui s'affiche, sélectionnez : 

	- le type de casse à appliquer : minuscule, majuscule ou première lettre en majuscule. 

	- les noms de fichiers à modifier. 




3. Validez : la modification est immédiatement réalisée pour les descriptions de fichiers sélectionnées.  



Pour modifier la casse des noms de rubriques : 

1. Dans l'éditeur de schémas des données, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance" et sélectionnez "Modifier la casse du nom des rubriques". 

2. Dans la fenêtre qui s'affiche, sélectionnez : 

	- le type de casse à appliquer : minuscule, majuscule ou première lettre en majuscule. 

	- pour chaque fichier, les noms de rubriques à modifier. 




3. Validez : la modification est immédiatement réalisée pour les descriptions de rubriques sélectionnées.
