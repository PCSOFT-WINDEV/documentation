


## Le volet "Schéma des données"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000126"></a>
Le volet "Schéma des données" liste :

- les tables et leurs rubriques présentes dans le schéma des données en cours. Les clés sont affichées en gras et les clés uniques sont affichées en gras et soulignées. 

- les procédures stockées, les requêtes stockées et les triggers présents dans le schéma des données en cours.

- les vues SQL et les vues matérialisées présentes dans le schéma des données en cours.

- les connexions décrites dans le schéma des données en cours.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=VoletAnalyse.gif&type=thumb)
Le menu contextuel (clic droit) du volet "Schéma des données" permet de :

- Ouvrir le schéma des données.

- Créer : 

	- une table.

	- une vue (SQL ou matérialisée).

	- un perso-dossier. Pour plus de détails, consultez [Perso-dossiers dans le schéma des données](../Editeurs/2011003.md).

	- une collection de procédures stockées. 

	- une requête stockée.

	- un trigger.

	- une énumération.

	- une combinaison.




- Afficher la description du schéma des données. 

- Afficher la description des tables.

- Visualiser la description des tables.

- Gérer les connexions. 

- Générer le schéma des données.

- Imprimer le dossier du schéma des données.




**Attention** : Les informations affichées correspondent au schéma des données en cours de description sous l'éditeur de schémas des données. Ces informations peuvent être différentes de celles affichées dans le [volet "Explorateur de projet"](../Editeurs/2027029.md) (qui affiche les informations du dernier schéma des données généré).

## Afficher le volet "Schéma des données"
<a name="afficher_volet_schema_des_donnees_ELTTEXTE000150"></a>
**Pour afficher le volet "Schéma des données"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Schéma des données".

Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](../Editeurs/2027001.md).
