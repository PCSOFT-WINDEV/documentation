
## WEBDEV: Pages créées par le RAD "pages"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000168"></a>
L'assistant de création de pages propose de créer: 

- des pages standard et pré-définies.

- des pages internes. 

- des pages d'erreur.  

- des pages RAD, associées à des tables HFSQL. 




Pour plus de détails, consultez [Les différents types de pages](../WDChamp/2030020.md).

Les pages proposées par le RAD pour un projet en mode Session sont les suivantes: 

- Page Fiche.

- Page Table. 

- Page Vision.




Les pages proposées par le RAD pour un projet en mode AWP sont les suivantes: 

- Page Fiche. 

- Page Fiche et table reliée - liaison

- Page Fiche et table reliée - Liaison simple

- Vision. 

- Zone répétée.

## Pages proposées pour un projet en mode Session
<a name="pages_proposees_pour_projet_mode_session_ELTTEXTE000192"></a>


### Page Fiche
<a name="page_fiche_ELTPARAGRAPHE000041"></a>

Une page **fiche** affiche les valeurs d'un enregistrement dans une fiche, à raison d'une valeur par champ. Les enregistrements sont accessibles un par un.

La fiche peut au choix:

- autoriser le passage ou non aux enregistrements suivants et précédents.

- autoriser ou non la création, la modification et la suppression d'enregistrements.





### Page Table
<a name="page_table_ELTPARAGRAPHE000051"></a>

Une page **table** affiche les enregistrements sous forme d'un tableau (lignes et colonnes). Plusieurs enregistrements de la table peuvent être affichés dans la page.

Les rubriques d'un même enregistrement sont disposées en ligne.

Cette page contient: 

- Un champ Table permettant d'afficher les enregistrements. 

- Les boutons suivants: 

	- Bouton "Nouveau" permettant de créer un enregistrement. Ce bouton ouvre une page de type Fiche. 

	- Bouton "Modifier" permettant de modifier l'enregistrement sélectionné dans le champ Table. Ce bouton ouvre une page de type Fiche. 




- Bouton "Supprimer" permettant de supprimer l'enregistrement sélectionné dans le champ Table. 

- Bouton "Imprimer" permettant d'imprimer le contenu du champ Table. Ce bouton utilise un état. 





### Page Vision
<a name="page_vision_ELTPARAGRAPHE000068"></a>

Les pages Vision permettent de sélectionner un enregistrement dans un champ Table. Par exemple, lors de la saisie d'une commande, des pages Vision Plus peuvent être ouvertes pour sélectionner le client et le produit.

Les pages Vision sont appelées par le bouton qui a pour libellé [...] dans les pages reliées à une table.

## Pages proposées pour un projet en mode AWP
<a name="pages_proposees_pour_projet_mode_awp_ELTTEXTE000228"></a>


### Page Fiche
<a name="page_fiche_ELTPARAGRAPHE000085"></a>

Une page **fiche** affiche les valeurs d'un enregistrement dans une fiche, à raison d'une valeur par champ. Les enregistrements sont accessibles un par un.

La fiche peut autoriser ou non la création ou la modification.


### Page Fiche et table reliée
<a name="page_fiche_table_reliee_ELTPARAGRAPHE000092"></a>

Ce type de page permet de visualiser dans la même page le contenu de tables liées par une liaison simple (1 - N).

Les valeurs de l'enregistrement de la table principale sont visualisées dans une fiche. Les enregistrements reliés à l'enregistrement en cours (dans la table principale) sont visualisés dans un champ Table.

Ce type de page est constitué de:

- Une fiche (dans la partie haute) qui affiche les valeurs de l'enregistrement en cours de la table de base (principale).

- Un champ Table (dans la partie basse) qui affiche les enregistrements reliés à l'enregistrement en cours de la table principale.

- Boutons permettant de:

	- ajouter une ligne dans le champ Table,

	- modifier une ligne dans le champ Table,

	- supprimer une ligne dans le champ Table.







**Remarque**: Si la table affichée dans le champ Table est une table de relation, la page comporte les boutons nécessaires pour accéder à l'autre table en relation.


### Page Vision
<a name="page_vision_ELTPARAGRAPHE000111"></a>

Les pages Vision sont appelées par le bouton qui a pour libellé [...] dans les pages reliées à une table.
