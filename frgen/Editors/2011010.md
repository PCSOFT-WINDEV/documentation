


## Schéma des données : Description de la structure des tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000244"></a>
Le schéma des données permet de décrire la structure des tables utilisées par le projet.

Il est possible de décrire dans le schéma des données :

- [une nouvelle table.](#NOTE2_1)

- [une table prédéfinie, livrée avec WINDEV, WEBDEV et WINDEV Mobile.](#NOTE2_2)

- [une table importée depuis une base externe](../Editeurs/2011025.md) (appelée aussi "Base tierce").

- [une table importée depuis une version antérieure de WINDEV](../Editeurs/2011025.md).

- [une table HFSQL ISAM importée via l'explorateur de fichiers Windows](../Editeurs/2011025.md).




**Remarque** : Pour modifier la description d'une table ou de ses rubriques :

- Sélectionnez la table sous l'éditeur de schémas des données. 

- Dans le menu contextuel, sélectionnez une des options suivantes : 

	- "Description de la table".

	- "Description des rubriques".







**Rappel** : Dans une application WINDEV, WEBDEV ou WINDEV Mobile, les termes "MLD" et "Schéma des données" sont utilisés indifféremment pour définir la structure de la base de données associée à un projet.

Pour plus de détails sur les manipulations d'une table ou d'une rubrique sous l'éditeur de schémas des données, consultez [Manipulations d'une table](../Editeurs/2011007.md) et [Manipulations d'une rubrique](../Editeurs/2011009.md).

## Ajout d'une nouvelle table
<a name="ajout_une_nouvelle_table_ELTTEXTE000268"></a>


### Créer une nouvelle table
<a name="creer_une_nouvelle_table_ELTPARAGRAPHE000052"></a>

Pour créer une nouvelle table : 

1. Sous le volet "Schéma des données", dans le groupe "Création", cliquez sur "Nouvelle
table". L'assistant de création d'une table se lance.

2. Sélectionnez l'option "Créer une nouvelle description d'une table". Passez à l'étape suivante.

3. Spécifiez :

	- le ***nom logique de la table***. Ce nom sera utilisé pour manipuler la table.

	- le ***libellé*** résumant succinctement le sujet de la table.

	- la ***représentation d'un enregistrement*** dans la table. Cette représentation permet d'améliorer la lisibilité des questions posées lors de la description des liaisons. Cette option doit être précédée d'un article indéfini (UN ou UNE).

	- si la table possède une ***rubrique de type "Identifiant automatique"***. La valeur de cette rubrique est unique pour chaque enregistrement et est automatiquement calculée par le moteur HFSQL.
			Il est possible d'utiliser : 

		- soit un identifiant sur 8 octets. Ce type d'identifiant est obligatoire dans le cas de la réplication de serveurs HFSQL. 

		- soit un identifiant sur 4 octets. 




- soit un UUID automatique (128 bits). Dans ce cas, l'identifiant de chaque enregistrement correspond à un UUID sur 128 bits (l'UUID permet d'obtenir un identifiant unique non séquentiel). 

- soit un UUID automatique (256 bits). Dans ce cas, l'identifiant de chaque enregistrement correspond à un UUID sur 256 bits (l'UUID permet d'obtenir un identifiant unique non séquentiel).

4. Dans l'étape suivante, indiquez le ***type de base de données*** associé à la table. Selon le type choisi, cette table sera manipulée par le moteur HFSQL, par un pilote OLE DB ou par un des Connecteurs natifs (SQL Server, Oracle, etc.).
	Si le type de base de données utilisé ne correspond pas à HFSQL Classic (Réseau ou Monoposte), l'assistant demande les caractéristiques de connexion à la base de données.

5. La table créée devient la table en cours. La fenêtre de description des rubriques de la table s'ouvre automatiquement. Vous pouvez décrire les rubriques de la table.



<a name="NOTE2_2"></a>


### Importer une description de table prédéfinie
<a name="importer_une_description_table_predefinie_ELTPARAGRAPHE000098"></a>

Pour importer une description de table prédéfinie :

1. Sous le volet "Schéma des données", dans le groupe "Création", cliquez sur "Nouvelle
table". L'assistant de création d'une table se lance.

2. Sélectionnez l'option "Sélectionner une description parmi des tables prédéfinies".

3. Choisissez la ou les tables prédéfinies à créer. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Analyse_Fichierpredef.gif)
L'assistant propose également les tables associées qui peuvent être ajoutées sous forme de liens.

4. Pour chaque table, sélectionnez les rubriques à conserver. Ces rubriques pourront être modifiées par la suite.

5. Le(s) fichier(s) de données prédéfini(s) sont automatiquement insérés dans le schéma des données en cours. Les liaisons entre les tables prédéfinies créées sont automatiquement réalisées.

## Couleur des descriptions des tables
<a name="couleur_des_descriptions_des_tables_ELTTEXTE000298"></a>
Pour identifier rapidement les types des tables sous l'éditeur de schémas des données, les couleurs suivantes sont utilisées :

- Bleu pour les tables provenant d'un Connecteur Natif.

- Orange pour les tables HFSQL Client/Serveur.

- Marron pour les tables HFSQL Classic.

- Vert pour les tables ODBC. 

- Gris pour les tables Hyper File 5.5.

## Sécurité d'une table HFSQL
<a name="securite_une_table_hfsql_ELTTEXTE000322"></a>
Pour assurer la sécurité d'une table HFSQL :

1. Affichez la description de la table :

	- Sélectionnez la table sous l'éditeur de schémas des données. 

	- Dans le menu contextuel, sélectionnez l'option "Description de la table".




2. Dans l'onglet "Détail" : 

	- Activez l'option de chiffrement de la table, des index, des mémos. Plusieurs modes de chiffrement sont disponibles. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Base_HFSQLCS_Securite%20-%20HC%20N%B0001.gif)
Par défaut, l'option "Automatique (RC5 16 boucles si mot de passe)" est sélectionnée lors de la création d'une table. Cette option permet de chiffrer automatiquement la table si un mot de passe est défini avec la fonction [HPasse](../WDLang4/3044108.md) sur la table.

	- Activez l'option "Activer la sécurité renforcée ".
			Remarque : Par défaut, cette option est sélectionnée lors de la création d'une table. Cette option permet de demander le mot de passe à chaque modification automatique de la table.




3. Générez le schéma des données : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Génération". Pour plus de détails, consultez [Génération d'un schéma des données](../Editeurs/2011012.md).

4. Spécifiez un mot de passe pour la table par programmation avec la fonction [HPasse](../WDLang4/3044108.md). 

5. Chiffrez la connexion à la base de données dans les connexions décrites dans le schéma des données, ou par programmation grâce à la propriété [Cryptage](../Proprietes/2512102.md).




**Remarque** : Chiffrement AES (algorithme de chiffrement AES 128 bits, 192 bits et 256 bits avec un mode d'opération OFB) : 

- Si la table utilise un chiffrement AES, il est nécessaire d'utiliser la même méthode de chiffrement pour les mémos et les index. 

- Si un chiffrement AES est réalisé, l'option "Activer la sécurité renforcée " est automatiquement appliquée.
