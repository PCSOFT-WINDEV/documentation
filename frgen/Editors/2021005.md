


## Live Data: visualiser les données sous les éditeurs 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000300"></a>
Le "Live Data" consiste à visualiser le contenu des tables dans les champs en création sous les différents éditeurs du produit utilisé (éditeur de fenêtres, éditeur de pages, éditeur d'états, ...). Il est ainsi possible de configurer simplement la taille d'un champ en fonction des données pouvant être affichées dans le champ.

**Attention**: Pour utiliser le "Live Data" il est nécessaire de:

- associer un schéma des données au projet,

- manipuler des tables existantes.

## Comment mettre en place le Live Data?
<a name="comment_mettre_place_live_data_ELTTEXTE000324"></a>


### Mettre en place le "Live Data" sur le projet en cours (éditeur de fenêtres, de pages et d'états)
<a name="mettre_place_live_data_sur_projet_cours_editeur_fenetres_pages_etats_ELTPARAGRAPHE000023"></a>

Pour mettre en place le "Live Data" sur le projet en cours (éditeur de fenêtres, de pages et d'états): 

1. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". La fenêtre de description du projet s'affiche.

2. Affichez l'onglet "Live Data".

3. Cochez l'option "Activer le Live Data".

4. Pour chaque table, indiquez si nécessaire:

	- le type de table: Cette option vous permet de sélectionner le type de table à utiliser en aperçu. En effet, la table utilisée peut être une table HFSQL Classic, ou encore HFSQL Client/Serveur, Oracle, SQL Server, ...: il suffit de sélectionner la connexion correspondante.
			Des tables de différents types peuvent être utilisées simultanément.

	- le répertoire: Le répertoire peut correspondre à:

		- "Localisation automatique": la localisation de la table est effectuée automatiquement. Il est également possible d'utiliser le bouton "Localisation automatique".

		- "Répertoire du mode test": les fichiers de données utilisés sont ceux définis pour le mode Test (le répertoire est défini dans l'onglet "Fichiers de données" de la description du projet.

		- "Répertoire défini dans le schéma des données": les tables utilisées sont celles définies dans le schéma des données.

		- "Parcourir": permet de sélectionner la table voulue.




- le mot de passe de la table.  

5. Validez.


**Remarque**: Dans ce cas, la mise en place du Live Data sera prise en compte uniquement à la prochaine ouverture des fenêtres, des pages et/ou des états.

### Mettre en place le Live Data sur le projet en cours dans le logiciel Etats & Requêtes
<a name="mettre_place_live_data_sur_projet_cours_dans_logiciel_etats_requetes_ELTPARAGRAPHE000071"></a>

Pour mettre en place le Live Data sur le projet en cours dans le logiciel Etats & Requêtes: 

1. Sélectionnez l'option "Projet .. Options des fichiers du projet". La fenêtre de description s'affiche.

2. Cochez l'option "Activer le Live Data".

3. Pour chaque table, indiquez si nécessaire:

	- le type de table: Cette option vous permet de sélectionner le type de table à utiliser en aperçu. En effet, la table utilisée peut être une table HFSQL Classic, ou encore HFSQL Client/Serveur, Oracle, SQL Server, ...: il suffit de sélectionner la connexion correspondante.
			Des tables de différents types peuvent être utilisées simultanément.

	- le répertoire: Le répertoire peut correspondre à:

		- "Localisation automatique": la localisation de la table est effectuée automatiquement. Il est également possible d'utiliser le bouton "Localisation automatique".

		- "Répertoire du mode test": les tables utilisées sont celles définies pour le mode Test (le répertoire est défini dans l'onglet "Tables" de la description du projet).

		- "Répertoire défini dans le schéma des données": les tables utilisées sont celles définies dans le schéma des données.

		- "Parcourir": permet de sélectionner la table voulue.




- le mot de passe de la table.  

4. Validez.


**Remarque**: Dans ce cas, la mise en place du Live Data sera prise en compte uniquement à la prochaine ouverture des états et des requêtes modifiables sous le logiciel "Etats & Requêtes".

## Comment supprimer le Live Data?

## Comment changer le répertoire des tables à utiliser pour le Live Data?

### Changer le répertoire des tables à utiliser pour le "Live Data"
<a name="changer_repertoire_des_tables_utiliser_pour_live_data_ELTPARAGRAPHE000151"></a>

Pour changer le répertoire des tables à utiliser pour le "Live Data":

1. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". La fenêtre de description du projet s'affiche.

4. Pour chaque table, indiquez sa localisation. Le bouton "Localisation automatique" permet de rechercher automatiquement les tables. Cette recherche peut être relativement longue.

## Comment spécifier le mot de passe des tables à utiliser pour le Live Data?
<a name="comment_specifier_mot_passe_des_tables_utiliser_pour_live_data_ELTTEXTE000414"></a>


### Spécifier le mot de passe des tables à utiliser pour le "Live Data"
<a name="specifier_mot_passe_des_tables_utiliser_pour_live_data_ELTPARAGRAPHE000208"></a>Pour spécifier le mot de passe des tables à utiliser pour le "Live Data": 
Si les tables utilisées pour le "Live Data" ont un mot de passe, il est possible de le spécifier dans les options du projet:

1. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". La fenêtre de description du projet s'affiche.

2. Affichez l'onglet "Live Data".

3. Cochez l'option "Activer le Live Data".

4. Pour chaque table, indiquez le mot de passe correspondant puis validez.


**Remarque**: Si le mot de passe n'est pas indiqué pour une table protégée, les enregistrements de cette table ne seront pas affichés.
