


## Description du projet : Onglet Thème
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000148"></a>
La fenêtre de description du projet permet de configurer de nombreux éléments de votre projet. Cette fenêtre est constituée des onglets suivants :

- L'onglet ["Projet"](../Editeurs/2030046.md) qui permet de saisir les informations générales du projet.

- L'onglet "Schéma des données" qui permet d'associer un ou plusieurs schémas des données au projet et / ou un modèle UML.

- L'onglet ["Tables"](../Editeurs/2030052.md) qui permet de saisir différentes informations sur les tables gérées par l'application (uniquement disponible si le projet est lié au moins à un schéma des données).

- L'onglet "Live data" qui permet de configurer l'affichage des données (provenant des tables) sous les différents éditeurs.

- L'onglet ["Langues"](../Editeurs/9500219.md) qui permet de paramétrer les différentes langues manipulées par le projet ainsi que les options linguistiques à utiliser pour chaque langue.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) L'onglet ["Style"](../Editeurs/9500234.md) qui permet de choisir le thème, la feuille de styles personnalisée et de personnaliser l'aperçu avant impression. Il est également possible de paramétrer la taille des écrans.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) L'onglet **"Thème"** qui permet de choisir le thème du projet, la palette associée, la feuille de styles et les ressources externes. 

- L'onglet ["GDS"](../Editeurs/9500239.md) qui permet de gérer le travail en groupe (GDS ou GIT).

- L'onglet ["Options"](../Editeurs/9500227.md) qui permet de configurer les options de création, de mise à jour, et de sauvegarde des éléments. Cet onglet permet également de gérer la synchronisation des modèles, d'activer le mode strict et de définir la charte de programmation.

- L'onglet ["Avancé"](../Editeurs/9500236.md) qui permet de gérer l'utilisation de "Etats & Requêtes", les FAA et le verrouillage de l'application.

- L'onglet ["Compilation"](../Editeurs/9500218.md) qui permet de configurer les options de compilation.

- L'onglet ["Télémétrie"](../Editeurs/9500223.md) qui permet de configurer les options de télémétrie pour le projet. 
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Cette option n'est pas disponible.

## Onglet Thème
<a name="onglet_theme_ELTTEXTE000229"></a>


### Thème du projet
<a name="theme_projet_ELTPARAGRAPHE000033"></a>

L'onglet "Thème" de la fenêtre de description du projet permet de connaître et de définir le thème utilisé par le projet. Un aperçu permet de voir le thème en situation.

**Remarque** : Si le thème est modifié via la fenêtre de description du projet, cette modification est prise en compte uniquement pour les nouvelles pages créées. L'application du thème sur les pages existantes est réalisée page par page : 

1. Ouvrez la page voulue sous l'éditeur. 

2. Sous le volet "Page", dans le groupe "Thème et styles", cliquez sur "Thème". 

3. Dans la fenêtre qui s'affiche, sélectionnez le thème voulu et la palette associée. 

4. Validez. 





### Palette du projet
<a name="palette_projet_ELTPARAGRAPHE000053"></a>

Les palettes de couleurs définissent un jeu de couleurs qui sont proposées dans tous les sélecteurs de couleurs du projet.

Ces couleurs sont également appliquées sur les styles définis dans le thème du projet afin de permettre de changer rapidement et facilement l'aspect visuel d'un projet.

L'onglet "Thème" permet de connaître et de modifier la palette de couleurs associée au thème. 

**Remarque** : Si la palette est modifiée via la fenêtre de description du projet, cette modification est prise en compte uniquement pour les nouvelles pages créées. Le changement de palette sur les pages existantes est réalisée page par page : 

1. Ouvrez la page voulue sous l'éditeur. 

2. Sous le volet "Page", dans le groupe "Thème et styles", déroulez "Palette" et choisissez une des palettes associées au thème en cours. 




La fenêtre de description du projet permet également d'afficher toutes les palettes et de créer une palette de couleurs. Pour plus de détails, consultez [Palettes de couleurs](../Editeurs/2016021.md).  


### Options du thème
<a name="options_theme_ELTPARAGRAPHE000080"></a>

Il est également possible de : 

- Choisir **la langue du thème**. Les ambiances sont disponibles en Français et en Anglais. 

- Appliquer le thème sur les boîtes de dialogue (OuiNon et OKAnnuler) : Si cette option est sélectionnée, les boîtes de dialogue affichées par le site utiliseront les caractéristiques du thème. 





### Feuilles de styles
<a name="feuilles_styles_ELTPARAGRAPHE000091"></a>

Il est possible de : 

- Sélectionner la ou les feuilles de styles associées au projet. 

- Ajouter des ressources externes (fichiers javascript ou feuilles de styles CSS externes). Les feuilles de styles CSS seront automatiquement chargées à l'ouverture du projet.  




Pour plus de détails, consultez [Inclure des fichiers Javascript ou une ressource Web](../Editeurs/1012027.md).
