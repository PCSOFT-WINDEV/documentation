## Répertoire de création des tables du groupware utilisateur
<a name="repertoire_creation_des_tables_groupware_utilisateur_ELTTEXTE000225"></a>
Deux catégories de tables sont gérées :

- **les tables permettant d'identifier les utilisateurs**. Ces tables peuvent être communes à plusieurs applications.

- **les tables permettant de gérer les droits des utilisateurs sur les différentes fenêtres de l'application**. Ces fichiers sont spécifiques à l'application.




Pour plus de détails sur ces tables (noms, rubriques, ...), consultez [Les tables du groupware utilisateur](../Editeurs/2018002.md).

Par défaut, ces tables sont créées dans le sous-répertoire "&lt;NomApplication&gt;_GPW" du répertoire d'installation de l'application. Il est cependant possible de modifier ce répertoire. Ce répertoire peut correspondre :

- à un répertoire spécifique

- au répertoire des données de l'application. Ce choix est adapté au mécanisme de l'UAC de Windows Vista. Si les utilisateurs travaillent avec Windows Vista (ou supérieur) et le mécanisme de l'UAC activé, ils pourront utiliser l'application sans avoir de droits administrateur spécifiques.

## Répertoire de création des tables HFSQL Classic de l'application
<a name="repertoire_creation_des_tables_hfsql_classic_application_ELTTEXTE000249"></a>
Par défaut, les tables HFSQL sont créées dans les répertoires spécifiés lors de la description des tables dans le schéma des données. Cependant, il est possible de modifier ces répertoires :

- **lors de la création de l'exécutable de l'application**.
	Plusieurs options sont disponibles : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=D%E9ployer%20l'application%20-%20HC%20N%B0003.gif)


	- **Automatique (conseillé)** : Cette option permet d'installer les tables :

	- soit dans le répertoire des données de l'application (si l'exécutable est installé dans "Programmes files"). 

	- soit dans le répertoire de l'exécutable. 

- **par programmation** grâce aux fonctions [HSubstRep](../WDLang4/3044028.md) ou [HChangeRep](../WDLang4/3044168.md).

- **lors de l'installation de l'application**. Le répertoire de création des tables sera alors sélectionné par l'utilisateur.




Dans tous les cas, le répertoire de création des tables est défini selon l'ordre de priorité suivant :

1. Répertoire spécifié grâce aux fonctions [HSubstRep](../WDLang4/3044028.md) ou [HChangeRep](../WDLang4/3044168.md).

2. Répertoire sélectionné lors de l'installation de l'application (si cette option est proposée à l'utilisateur).

3. Répertoire sélectionné lors de la création de l'exécutable.

4. Répertoire spécifié lors de la description des tables dans le schéma des données.




Ainsi, le répertoire défini par les fonctions [HSubstRep](../WDLang4/3044028.md) ou [HChangeRep](../WDLang4/3044168.md) est prioritaire sur tous les autres répertoires définis.

**Cas particulier : tables installées avec l'application**
Ces tables sont installées dans le répertoire spécifié lors de la création du programme d'installation (répertoire de destination spécifié dans l'étape "Tables installées").
Il est conseillé d'utiliser le même répertoire pour installer les tables livrées avec l'application et pour créer les nouvelles tables.
