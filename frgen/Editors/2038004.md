


## GDS: Travailler avec le Gestionnaire de sources
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000225"></a>
Le principe du travail avec le Gestionnaire de sources est le suivant:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GestionnaireDeSources_synch.gif)


- Tous les développeurs travaillent sur une copie locale du projet. Ce projet et tous ses éléments sont par défaut en lecture seule.

- Lors de l'ouverture d'un élément du projet, cet élément est en lecture seule par défaut: il ne peut pas être modifié. Pour le modifier, il faut l'extraire du gestionnaire de sources, le modifier, puis le réintégrer.




**Remarque**: Le GDS est utilisable uniquement avec des systèmes d'exploitation gérant les tables de plus de 4 giga. Si la base de données du GDS (base de sources) est en mode HFSQL Client/Serveur, le GDS peut être utilisé avec ces systèmes d'exploitation (sur les postes clients).

## Travailler sur un projet partagé dans le GDS
<a name="travailler_sur_projet_partage_dans_gds_ELTTEXTE000249"></a>
**Pour travailler sur un projet présent dans le GDS**, il faut: 

1. Mettre en place l'environnement nécessaire (à faire une seule fois):   

	- [Ajouter le projet dans le GDS](../Editeurs/2038002.md). 
			Cette opération permet si nécessaire de créer la base de sources du GDS. Pour plus de détails, consultez [Créer une base de sources](../Editeurs/2038005.md).  

	- [Récupérer en local le projet provenant du GDS](../Editeurs/2038036.md). Cette opération doit être effectuée par chaque développeur travaillant sur le projet présent dans le GDS.




2. Modifier le projet: 

	- Ouvrir le projet local. 

	- Récupérer si nécessaire tous les éléments modifiés du GDS (pour avoir le projet local en phase avec le projet de la base de sources). 

	- [Extraire les éléments à modifier](../Editeurs/2038006.md). 

	- Faire les modifications. 




3. Réintégrer l'élément. Il est possible de: 

	- [Historiser localement les modifications (COMMIT)](../Editeurs/2510003.md). 
			

	- [Réintégrer les modifications (PUSH)](../Editeurs/2038007.md).

## Mode de gestion du projet
<a name="mode_gestion_projet_ELTTEXTE000282"></a>
Deux modes de gestion du projet sont disponibles avec le GDS:

- [Gestion du projet en mode automatique](#NOTE4_3) (mode par défaut).

- [Gestion du projet en mode Maître/Invité](#NOTE4_2).



<a name="NOTE4_3"></a>


### Gestion du projet en mode automatique
<a name="gestion_projet_mode_automatique_ELTPARAGRAPHE000077"></a>

La gestion du projet en mode automatique permet d'extraire le fichier projet uniquement si l'action réalisée le nécessite (quel que soit l'utilisateur). Lorsque l'action sur le projet a été effectuée, le fichier projet est automatiquement réintégré.

Il est par exemple possible de modifier la première fenêtre ou la première page d'un projet. Cette information est conservée dans le fichier du projet. Lors de la modification de cette information, le projet sera automatiquement extrait et lorsque la modification sera validée, le fichier du projet sera automatiquement réintégré. 

Par défaut, le projet est géré en mode automatique. 

**Pour activer ou désactiver le mode automatique**: 

1. Affichez la description du projet: sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

2. Dans l'onglet "GDS", cochez ou décochez l'option "Extraire/Réintégrer automatiquement le projet".



<a name="NOTE4_2"></a>


### Gestion du projet en mode Maître/Invité
<a name="gestion_projet_mode_maitreinvite_ELTPARAGRAPHE000109"></a>

Si la gestion du projet en mode automatique est désactivé, le projet est géré en mode "Maître/Invité". 

Dans ce cas, le Gestionnaire de sources considère 2 types d'utilisateurs:

- le maître: le maître est l'utilisateur qui a placé le projet dans le gestionnaire de sources.

- les invités: les invités sont les développeurs qui manipulent le projet depuis le gestionnaire de sources.




Il n'est pas obligatoire d'être connecté en mode maître sur un projet. Le mode "Maître" est nécessaire uniquement pour:

- modifier les caractéristiques du projet et réintégrer ces modifications dans la base de sources.

- réintégrer tous les éléments pour faire l'exécutable et le programme d'installation de l'application.




**Pour passer du mode maître au mode invité**: sous le volet "GDS", dans le groupe "Projet", déroulez "Maître / Invité" et sélectionnez "Devenir invité sur le projet (et tout réintégrer)".
Dans ce cas, le gestionnaire de sources propose la réintégration de tous les éléments du projet (y compris le fichier .WDP).

**Pour passer du mode invité au mode maître**: sous le volet "GDS", dans le groupe "Projet", déroulez "Maître / Invité" et sélectionnez "Devenir maître sur le projet".

**Modification des options du projet**
Tous les utilisateurs du projet (qu'ils soient maître ou invités) peuvent modifier les caractéristiques du projet (première fenêtre du projet, animation, charte de programmation, etc.).
Ces modifications pourront être réintégrées dans le gestionnaire de sources uniquement par le maître du projet.
Les modifications faites par un invité seront perdues lors de la mise à jour du projet depuis la base de sources.

## Cas particuliers
<a name="cas_particuliers_ELTTEXTE000318"></a>


### Changement de poste
<a name="changement_poste_ELTPARAGRAPHE000157"></a>

Si vous devez changer votre machine (ou changer le nom de votre machine), il est nécessaire AVANT de changer la machine, de tout réintégrer à l'aide de l'administrateur du GDS. 
Pour lancer l'administrateur du GDS, sous le volet "GDS", dans le groupe "Base GDS", déroulez "Gérer" et sélectionnez "Administrateur du Gestionnaire de Sources".

Pour plus de détails, consultez [Que faire en cas de changement de poste](../Editeurs/2038020.md).
