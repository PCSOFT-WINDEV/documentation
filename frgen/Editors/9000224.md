
## Entête épinglé (Editeur de code)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000150"></a>
Lorsque vous travaillez dans un fichier de code volumineux (plus grand que la taille de l'écran), il peut parfois être difficile de déterminer où vous vous trouvez dans le code. 

La fonctionnalité de "l'en-tête épinglé" permet de laisser visible la première ligne de chaque bloc de code qui n'est plus visible en haut de l'écran. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Entete_epingle%20-%20HC%20N%B0003.gif)

## Comment utiliser l'entête épinglé ?
<a name="comment_utiliser_entete_epingle_ELTTEXTE000174"></a>


### Activer ou désactiver l'entête épinglé
<a name="activer_desactiver_entete_epingle_ELTPARAGRAPHE000019"></a>L'entête épinglé est paramétrable dans les options de l'éditeur de code : 

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code".

2. Dans l'onglet "Code", sélectionnez (ou désélectionnez) l'option "Activer l'entête épinglé (WLangage)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Entete_epingle%20-%20HC%20N%B0001.gif&type=thumb)


3. Validez. 




Pour activer ou désactiver temporairement la gestion de l'entête épinglé sous l'éditeur de code : 

1. Affichez l'éditeur de code. 

2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cochez ou décochez l'option "Entête épinglé (WLangage)". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Entete_epingle%20-%20HC%20N%B0002.gif)






### Fonctionnement de l'entête épinglé
<a name="fonctionnement_entete_epingle_ELTPARAGRAPHE000063"></a>Lors d'un scroll dans l'éditeur de code, la première ligne de chaque bloc d'instructions qui ne devient plus visible est conservée en haut de l'éditeur. 

Le clic sur une des lignes épinglées permet d'accéder immédiatement au bloc d'instructions correspondant. 


### Mode de défilement des lignes épinglées
<a name="mode_defilement_des_lignes_epinglees_ELTPARAGRAPHE000070"></a>Par défaut, 8 lignes sont épinglées. 

Si le nombre de lignes à épingler est plus important, par défaut, les blocs les plus englobants sont conservés. 

Ce comportement peut être modifié dans les options de l'éditeur de code : 

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code".

2. Dans l'onglet "Code", dans la zone "Entête épinglé", il est possible de définir : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Entete_epingle%20-%20HC%20N%B0001%201.gif)


	- le nombre de lignes épinglées (8 par défaut). 

- le comportement si le nombre de lignes épinglées est dépassé : 

	- Seuls les blocs les plus englobants sont conservés (par défaut).  

	- Seuls les blocs les moins englobants sont conservés (option "Afficher les blocs les plus profonds" cochée).
