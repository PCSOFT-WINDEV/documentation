


## Schéma des données : Génération du schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000153"></a>
La génération du schéma des données intervient avant la phase de programmation et après la phase de description des tables. Cette génération permet de :

- valider les modifications effectuées sur le schéma des données (MLD).

- créer les modules nécessaires à la programmation.

- mettre à jour automatiquement les tables si nécessaire.




Chaque génération de schéma des données est numérotée. Ce numéro correspond au numéro de génération du schéma des données. Ce numéro est incrémenté lors de la génération du schéma des données uniquement si la description d'une table ou d'une des rubriques d'une table a été modifiée. Ce numéro est égal à 0 si le schéma des données n'a pas encore été généré.

Tant que le schéma des données (le MLD) n'a pas été généré, la description du schéma des données (c'est-à-dire les tables) ne pourra pas être utilisée dans le projet.

**Remarque** : Dans une application WINDEV, WEBDEV ou WINDEV Mobile, les termes "MLD" et "Schéma des données" sont utilisés indifféremment pour définir la structure de la base de données associée à un projet.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000177"></a>
La génération comporte trois étapes :

- vérification des modifications effectuées et génération des tables de la description du schéma des données.

- modification automatique des tables accessibles (tables présentes dans le [fichier ".REP"](../WDLang4/3044186.md) ou dans le répertoire "EXE" du projet). Pour plus de détails sur cette opération, consultez [Modification automatique des tables](../WDLang4/3044195.md).

- synchronisation du projet avec les différentes modifications effectuées dans le schéma des données.




**Pour générer le schéma des données**, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Génération".

**Remarque** : Il est également possible d'effectuer une **génération avancée du schéma des données** : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Génération avancée". Cette génération avancée permet de définir différents paramètres spécifiques :

- génération d'un squelette pour un programme en langage externe.

- affichage des dernières modifications effectuées sur le schéma des données.

- prise en compte avancée des modifications effectuées dans le schéma des données du projet (par exemple dans les informations partagées du projet et/ou dans les tables du projet).

## Numéro de génération d'un schéma des données ou d'un fichier du schéma des données
<a name="numero_generation_schema_des_donnees_fichier_schema_des_donnees_ELTTEXTE000201"></a>


### Numéro de génération d'un schéma des données
<a name="numero_generation_schema_des_donnees_ELTPARAGRAPHE000077"></a>

À chaque génération du schéma des données, le numéro de génération du schéma des données est automatiquement incrémenté. Pour plus de détails sur l'utilisation des différentes versions de génération du schéma des données, consultez [Gestion des versions de génération du schéma des données](../Editeurs/2011002.md).

Ce numéro permet uniquement de connaître le nombre de générations effectuées depuis la création de l'application.
<a name="NOTE3_2"></a>


### Numéro de génération d'une table du schéma des données de la table du schéma des données
<a name="numero_generation_une_table_schema_des_donnees_table_schema_des_donnees_ELTPARAGRAPHE000089"></a>

Un numéro de génération est également associé à chaque table. Ce numéro est incrémenté lors de la génération du schéma des données uniquement si la description de la table ou d'une de ses rubriques a été modifiée. Ce numéro est égal à 0 si le schéma des données n'a pas encore été généré.

Le numéro de génération d'une table est donc inférieur ou égal au numéro de génération du schéma des données.

Le numéro de génération d'une table peut être :

- connu grâce à la propriété [NuméroGénération](../Proprietes/2512068.md).

- visualisé depuis WDMap (option "Affichage .. Informations générales sur le fichier").




Lors de l'installation de la mise à jour d'une application sur le poste des utilisateurs finaux, le numéro de génération des tables indique si la [modification automatique des tables](../WDLang4/3044195.md) est nécessaire ou non.
