
## Paramétrer la modification automatique des tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000120"></a>
La modification automatique des tables permet de mettre à jour la description des tables présentes sur les postes utilisateurs.

Pour plus de détails, consultez la [Modification automatique des tables](../WDLang4/3044195.md).

## Paramétrer la modification automatique des données grâce à l'assistant
<a name="parametrer_modification_automatique_des_donnees_grace_assistant_ELTTEXTE000144"></a>
Pour paramétrer la modification automatique des données grâce à l'assistant, sélectionnez (cochez) l'application (fichier ".EXE") pour laquelle la modification automatique des tables doit être effectuée.

Si les tables sont protégées par un mot de passe ou si elles sont dans une base HFSQL Client/Serveur, il est nécessaire de fournir les mots de passe :

1. Cliquez sur le bouton "Avancé".

2. Sélectionnez le schéma des données au format WINDEV (fichier ".WDD") associé à l'application.

3. Pour chaque fichier présent dans le schéma des données, spécifiez si nécessaire :

	- le mot de passe du fichier (s'il existe) dans le schéma des données. 
			**Remarque** : Pour modifier ce mot de passe, cochez l'option "Modifier le mot de passe" et saisissez deux fois le nouveau mot de passe.

	- si l'application utilise un schéma des données WINDEV 5.5 migré, indiquez :

		- le schéma des données d'origine au format WINDEV 5.5 (fichier ".WDA").

		- le nom du fichier dans le schéma des données au format WINDEV 5.5.

		- le mot de passe du fichier (s'il existe) dans le schéma des données au format WINDEV 5.5.







Toutes ces informations à l'exception des mots de passe sont automatiquement affichées.

**Remarques** :

- Lors de la mise à jour, les tables automatiquement trouvées sont :

	- les fichiers présents dans le répertoire d'installation de l'application.

	- les fichiers listés dans le fichier ".REP". Pour plus de détails sur le fichier ".REP", consultez l'aide sur la [gestion du .REP](../WDLang4/3044186.md).




- L'assistant propose une modification automatique des données "silencieuse" : aucun écran de paramétrage ne sera affiché à l'utilisateur final. 

- Pour permettre à l'utilisateur d'accéder aux options de configuration de la modification automatique, l'éditeur d'installation WDInst permet de rendre visible le bouton "Options avancées" du programme d'installation.
