
## GDS : Récupérer le projet localement
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000148"></a>
Lorsqu'un projet a été ajouté dans le Gestionnaire de Sources (GDS), pour travailler sur ce projet, les différents développeurs doivent récupérer localement une copie du projet présent. 

Pour cela, il est nécessaire d'ouvrir le projet depuis le GDS. 

**Cette opération doit être effectuée une seule fois par chaque développeur utilisant le projet. Le développeur qui a ajouté le projet dans le gestionnaire de sources n'a aucune manipulation à effectuer.**

Important : Ne copiez pas les fichiers en local par l'explorateur de Windows.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Ouvrir le projet depuis le GDS (1ère ouverture du projet uniquement)
<a name="ouvrir_projet_depuis_gds_1ere_ouverture_projet_uniquement_ELTTEXTE000172"></a>
Pour récupérer un projet du GDS localement (1ère ouverture depuis le poste de développement) : 

1. Déroulez ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_ouvrir.gif) parmi les boutons d'accès rapide et sélectionnez "Ouvrir un projet depuis le GDS". 
	Remarque : Vous pouvez également utiliser la page d'accueil pour ouvrir un projet présent dans le GDS.

2. Dans l'assistant qui s'ouvre, indiquez les caractéristiques de la base de sources à utiliser : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0006.gif&type=thumb)


	- le type de la base de sources à utiliser.

- le chemin de la base de sources (poste du réseau ou répertoire partagé).

- le nom d'utilisateur et le mot de passe (si nécessaire).

3. Dans l'étape suivante de l'assistant : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0007.gif)


	- Sélectionnez le répertoire de la base de sources correspondant au projet voulu.

- Indiquez le répertoire local dans lequel le projet sera copié.

4. Validez. La copie du projet est réalisée en local et le projet est automatiquement ouvert selon le mode spécifié lors de son intégration dans la base de sources.




**Remarque** : Les prochaines ouvertures d'un projet géré par le GDS sont identiques aux ouvertures d'un projet non géré par le GDS : il suffit d'ouvrir le projet (fichier ".WDP") correspondant à la copie locale.

### Configuration des options d'un projet géré par le GDS
<a name="configuration_des_options_projet_gere_par_gds_ELTPARAGRAPHE000047"></a>Plusieurs options permettent de configurer un projet manipulé avec le Gestionnaire de Sources. Ces options sont regroupées dans l'onglet "GDS" de la description du projet. Ces options sont cochées par défaut.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0015.gif&type=thumb)
Les options disponibles sont les suivantes : 

- **Proposer la récupération de la dernière version des éléments à l'ouverture du projet** :
	Cette option permet lors de l'ouverture d'un projet présent dans le GDS, de proposer la récupération de la dernière version des différents éléments du projet. 
	Par défaut, cette option est cochée : la dernière version des éléments est automatiquement récupérée.

- **Proposer la réintégration des éléments à la fermeture du projet** :
	Cette option permet d'afficher lors de la fermeture du projet la liste de tous les éléments actuellement extraits, afin de réintégrer certains ou tous ces éléments.
	Par défaut, cette option n'est pas cochée : à la fermeture du projet, les éléments extraits ne sont pas réintégrés.

- **Extraire/Réintégrer automatiquement le projet** :
	Cette option permet une gestion automatique du "fichier projet" (option cochée par défaut). 
	Si cette option est cochée : 

	- Le fichier projet est extrait uniquement si l'action réalisée le nécessite. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0008.gif)


	- Lorsque l'action sur le projet a été effectuée, la réintégration du fichier projet est automatiquement proposée.
			Si l'option "Réintégrer automatiquement le projet à la fin de l'opération" a été cochée lors de l'extraction, le fichier projet est automatiquement réintégré (sans fenêtre de confirmation).
