


## Importer une feuille de styles CSS
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000107"></a>
WEBDEV offre la possibilité d'importer une feuille de styles CSS dans un projet WEBDEV.

Vous pouvez ainsi ré-utiliser des styles créés avec un autre outil et les intégrer à votre site WEBDEV.

**Remarque**: Lors de l'importation d'une page HTML existante, WEBDEV propose également d'importer les styles CSS associés à cette page. Pour plus de détails, consultez [Importation d'une page HTML existante](../Editeurs/2030029.md). 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Importer une feuille de styles existante
<a name="importer_une_feuille_styles_existante_ELTTEXTE000131"></a>
Pour importer une feuille de styles CSS existante:

1. Ouvrez une page sous l'éditeur de pages. 

2. Sous le volet "Page", dans le groupe "Thème et styles", déroulez "Styles" et sélectionnez "Editer les styles d'élément WEBDEV et CSS externes". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Styles_CSS_externe.gif)


3. Dans la fenêtre qui s'affiche, cliquez sur l'onglet "Ressources CSS externes". Depuis cette fenêtre, il est possible de: 

	- Importer un fichier CSS: 
			Dans l'explorateur de fichiers, sélectionnez le fichier CSS à importer. Ce fichier sera si nécessaire copié dans le répertoire du projet. 

	- Référencer un CSS: 
			Indiquez l'adresse URL de la ressource à référencer. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=R%E9f%E9rencer_css.gif)

			Remarque: la ressource référencée doit pouvoir être référencée et accédée depuis un domaine différent. 
			

	- Supprimer le CSS sélectionné. 

	- Relocaliser le CSS sélectionné. 




4. Validez. 




**Remarque**: Les styles importés pourront être utilisés: 

- directement dans l'onglet "Style" des champs, en précisant dans le le champ "Style de l'élément" la classe CSS à utiliser. 

- lors de la création d'un nouveau style.
