
## Statistiques de code 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000091"></a>
Les statistiques de code concernent :

- le nombre de lignes total du traitement concerné,

- le taux de commentaires,

- le nombre de lignes par traitement,

- le nombre de lignes de code avec ou sans commentaires,

- le nombre de lignes de commentaires.






<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000115"></a>


### Afficher les statistiques pour le projet
<a name="afficher_les_statistiques_pour_projet_ELTPARAGRAPHE000025"></a>Les statistiques de code pour le projet sont affichées dans le Widget "Code" du tableau de bord du projet. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Stat_code%20-%20HC%20N%B0001.gif)





### Afficher les statistiques pour l'objet en cours
<a name="afficher_les_statistiques_pour_objet_cours_ELTPARAGRAPHE000032"></a>Pour afficher les statistiques de code pour l'élément en cours sous l'éditeur de code : 

1. Sous le volet "Code", dans le groupe "Autres actions", cliquez sur "Statistiques". 

2. Dans la fenêtre qui s'affiche, indiquez :

	- le pourcentage de commentaires maximum à prendre en compte.

	- le nombre de lignes de code minimal à prendre en compte.




3. Cliquez sur le bouton "Afficher" pour calculer les statistiques.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Stat_code%20-%20HC%20N%B0002.gif)





Remarque : Il est possible d'imprimer le résultat du calcul des statistiques.
