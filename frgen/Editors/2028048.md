


## Déploiement d'un site WEBDEV : Modification automatique des tables
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000095"></a>
La modification automatique des tables permet de mettre à jour la description des tables présentes sur le serveur Web.

Pour plus de détails, consultez la [Modification automatique des tables](../WDLang4/3044195.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Paramétrer la modification automatique des données
<a name="parametrer_modification_automatique_des_donnees_ELTTEXTE000119"></a><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=D%E9ploiement%20-%20HC%20N%B0005.gif&type=thumb)
Pour effectuer la modification automatique des tables :

- au format HFSQL Classic, cochez l'option "Inclure la modification automatique des tables dans l'installation" et vérifiez le schéma des données associé au site.

- au format HFSQL Client/Serveur, cochez l'option "Effectuer la modification des tables HFSQL Client/Serveur". Le bouton "Connexions" permet de décrire les paramètres des connexions HFSQL Client/Serveur concernées.

- au format Hyper File 5.5 vers HFSQL Classic, cochez l'option "Effectuer la modification automatique des données Hyper File 5.5 et la conversion vers HFSQL Classic".



<a name="NOTE2_2"></a>


### Gestion des mots de passe pour les tables HFSQL Classic
<a name="gestion_des_mots_passe_pour_les_tables_hfsql_classic_ELTPARAGRAPHE000033"></a>

Si vos tables HFSQL Classic sont protégées par mot de passe, cliquez sur le lien "Définir les mots de passe des tables".

Pour chaque table du schéma des données, spécifiez si nécessaire :

- le mot de passe de la table (s'il existe) dans le schéma des données au format HFSQL Classic. 
	**Remarque** : Pour modifier ce mot de passe, cochez l'option "Modifier le mot de passe" et saisissez deux fois le nouveau mot de passe.

- si le site utilise un schéma des données Hyper File 5.5 migré :

	- le schéma des données d'origine au format Hyper File 5.5 (fichier ".WDA").

	- le nom de la table dans le schéma des données au format Hyper File 5.5.

	- le mot de passe de la table (s'il existe) dans le schéma des données au format Hyper File 5.5.







**Remarque** : Toutes ces informations à l'exception des mots de passe sont automatiquement affichées.
