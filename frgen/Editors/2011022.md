
## Schéma des données associé à un projet
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000069"></a>
Lorsqu'un projet WINDEV, WEBDEV ou WINDEV Mobile utilise des tables, un schéma des données doit être associé à ce projet. Un schéma des données permet de décrire les structures de données (tables, rubriques, etc.) utilisées dans votre projet.

L'éditeur de schémas des données permet de créer très simplement un schéma des données.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=P47-Analyse%20Structure%20de%20la%20base%20de%20donn%E9es.gif)


Pour décrire un schéma des données, deux méthodes sont à votre disposition :

- ** 1ère méthode** : Création directe du schéma des données (c'est-à-dire un Modèle Logique des Données (MLD)).

- ** 2ème méthode** : Création du Modèle Conceptuel des Données (MCD), puis création automatique du schéma des données à partir du MCD.




**Remarque** : Dans une application WINDEV, WEBDEV ou WINDEV Mobile, les termes "MLD" et "Schéma des données" sont utilisés indifféremment pour définir la structure de la base de données associée à un projet.
