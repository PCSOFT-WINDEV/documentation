


## Schéma des données d'un projet : le Modèle Logique des Données (MLD)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000150"></a>
Une Modèle Logique des Données (MLD) permet de décrire les structures de données (tables, rubriques, etc.) utilisées dans une application WINDEV, WEBDEV ou WINDEV Mobile. Ce Modèle Logique des Données est appelé "Schéma des données" sous WINDEV, WEBDEV ou WINDEV Mobile et peut être créé et édité via l'éditeur de schémas des données. 

**Remarques** :

- Les termes "MLD" et "Schéma des données" sont utilisés indifféremment pour définir la structure de la base de données associée à un projet.

- Pour plus de détails sur les manipulations d'un schéma des données (MLD), consultez [Manipulations d'un schéma des données (MLD)](../Editeurs/2011006.md).

## Création d'un schéma des données (MLD)
<a name="creation_schema_des_donnees_mld_ELTTEXTE000174"></a>
Pour créer un schéma des données (MLD) :

1. Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_nouveau.gif) parmi les boutons d'accès rapide. 

	- La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Données" puis sur "Schéma des données".

	- L'assistant de création d'un schéma des données se lance.




2. Spécifiez dans la première étape de l'assistant :

	- le ***nom et le répertoire du schéma des données***. Le schéma des données correspond à un fichier ".WDA". Par défaut, ce fichier sera créé dans le répertoire du schéma des données du projet (répertoire &lt;Nom du projet&gt;.ANA). Ce répertoire doit être accessible en lecture et en écriture.

	- si le schéma des données doit être associé au projet en cours à la place du schéma des données actuel (cas de la création d'un schéma des données dans un projet déjà associé à un schéma des données). 

	- la ***description du schéma des données*** décrivant succinctement le sujet du schéma des données. 




3. L'étape suivante de l'assistant permet de spécifier le type de la base de données manipulée par le projet : 

	- HFSQLDrive (solution payante). Pour plus de détails sur HFSQLDrive, consultez [HFSQLDrive, votre base de données dans le Cloud en 3 clics](https://pcscloud-drive.net/FR/HFSQLDrive/index.awp).

	- PCSCloud (solution payante). Pour plus de détails sur PCSCloud, consultez [Cloud pour base de données HFSQL](https://pcscloud.net/FR/cloud_applications.awp).

	- HFSQL Client/Serveur,

	- HFSQL Classic, 

	- Bases de données externes : SQL Server, Oracle, MySQL, etc.
			Remarque : Si le schéma des données doit manipuler une base de données externe, le connecteur natif correspondant doit être installé sur le poste. 




4. Si la base de données est différente de HFSQL Classic, l'assistant permet de définir la connexion à la base de données (nom, libellé) et de saisir les paramètres avancés (serveur, utilisateur et mot de passe). Ces informations peuvent être également modifiées par la suite, dans l'éditeur de schémas des données.

5. Validez. Le schéma des données créé devient le schéma des données en cours.

6. Créez l'ensemble des éléments (tables, rubriques et liaisons) de votre schéma des données.
	**Remarque** : Pour plus de détails, consultez [Tables du schéma des données](../Editeurs/2011010.md), [Rubriques d'une table](../Editeurs/2011009.md) et [Liaisons du schéma des données](../Editeurs/2011008.md).

7. Pour utiliser le schéma des données dans votre projet, générez le schéma des données : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Génération". Pour plus de détails, consultez [Génération d'un schéma des données](../Editeurs/2011012.md).
