


## Le volet "Schéma des données UML"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000094"></a>
Le volet "Schéma des données UML" affiche les différents diagrammes UML (diagramme de classes, diagramme de déploiement, ...) du projet en cours.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=VoletAnalyseUML.gif)
Le menu contextuel (clic droit) du volet "Schéma des données UML" permet de :

- Créer un nouveau modèle UML. Le modèle UML associé au projet peut contenir plusieurs diagrammes UML.

- Ouvrir un modèle UML.

- Ouvrir le modèle UML du projet en cours.

- Afficher la description des diagrammes.

- Ouvrir et fermer les diagrammes.

- Renommer les diagrammes.

- Supprimer les diagrammes.




Si aucun modèle UML n'est associé au projet en cours, le volet "Schéma des données UML" propose de créer un nouveau modèle.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Afficher le volet "Schéma des données UML"
<a name="afficher_volet_schema_des_donnees_uml_ELTTEXTE000118"></a>
**Pour afficher le volet "Schéma des données UML"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Schéma des données UML".

Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](../Editeurs/2027001.md).
