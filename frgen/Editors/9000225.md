
## Editeur de code : Norme Snake_case ou PascalCase
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000088"></a>
Pour écrire un nom de variable dans un code, il existe plusieurs règles de nommage.
Deux règles couramment utilisées sont :


- Pascal Case : NomDuClient : première lettre de chaque mot en majuscule.

- Snake case : nom_du_client : tout en minuscule, chaque mot séparé par un tiret bas.




L'éditeur de code permet de passer d'une règle de nommage à une autre. 

**Remarque** : Une utilisation détournée de cette fonctionnalité est d'utiliser une syntaxe pour les variables locales et l'autre syntaxe pour les variables globales. Les variables sont ainsi directement identifiables !

## Comment modifier la norme d'écriture ?
<a name="comment_modifier_norme_ecriture_ELTTEXTE000112"></a>
Pour modifier la nome d'écriture d'un traitement/événement :

1. Sous l'éditeur de code, affichez le menu contextuel du traitement / événement voulu. 

2. Sélectionnez l'option voulue : 

	- "Refactoring .. PascalCase => snake_case".

	- "Refactoring .. snake_case => PascalCase".




3. Choisissez l'étendue de l'action : 

	- Code courant.

	- Elément courant.

	- Tout le code affiché dans la fenêtre de code active.

	- Tout le code WLangage du projet.




4. Validez. 




Les noms utilisant la norme spécifiée seront recherchés dans le code et modifiés selon la norme voulue.
