
## Edition de texte (Editeur de code)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000176"></a>
Lors du développement d'une fonctionnalité, il peut être utile de conserver le même environnement pour ouvrir des fichiers texte. 

L'éditeur de code permet d'ouvrir vos fichiers texte, en proposant également une coloration syntaxique (si le langage édité est connu). 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Ouvrir un fichier texte
<a name="ouvrir_fichier_texte_ELTTEXTE000209"></a>
Pour ouvrir un fichier texte sous l'éditeur de code : 

- Réalisez un "Drag and Drop" du fichier vers l'éditeur de projets. 

- Utilisez l'option "Ouvrir" : sous le volet "Accueil", dans le groupe "Général", déroulez "Ouvrir" et sélectionnez "Ouvrir". Sélectionnez ensuite le fichier texte à ouvrir. 

- Si le fichier est présent dans le volet "Explorateur de projet", double-cliquez sur son nom. 



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Edition_texte_code%20-%20HC%20N%B0001.gif)





### Informations affichées sous l'éditeur
<a name="informations_affichees_sous_editeur_ELTPARAGRAPHE000042"></a>Lorsque le fichier est ouvert sous l'éditeur de code, un bandeau spécifique permet d'obtenir des informations sur le fichier ouvert et si nécessaire de les modifier. 

Les informations affichées sont les suivantes : 

- langage du fichier texte, 

- encodage, 

- type de fin de ligne. 




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Détail des informations affichées
<a name="detail_des_informations_affichees_ELTTEXTE000239"></a>


### Langage et coloration syntaxique
<a name="langage_coloration_syntaxique_ELTPARAGRAPHE000057"></a>Le premier indicateur correspond au langage du fichier affiché. La détection du langage est basée sur l'extension du fichier lors de son ouverture.

Pour changer le langage correspondant au fichier affiché : 

1. Cliquez sur le nom du langage actuel. Un menu alphabétique s'affiche. 

2. Sélectionnez l'initiale puis le nom du langage. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Edition_texte_code%20-%20HC%20N%B0002.gif)



Le fichier affiché est automatiquement coloré selon les caractéristiques du langage choisi. 

Remarques : 

- Les fichiers "Texte" (extension txt) ne sont pas colorés. 

- De nombreux langages sont pris en compte. Quelques exemples :

### Encodage du fichier sur disque
<a name="encodage_fichier_sur_disque_ELTPARAGRAPHE000107"></a>Lors de l'ouverture du fichier texte, l'encodage est automatiquement détecté. En création d'un fichier texte, l'encodage est automatiquement réalisé en UTF-8. 

Pour changer l'encodage correspondant au fichier affiché : 

1. Cliquez sur l'encodage actuel. La liste des encodages disponibles s'affiche.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Edition_texte_code%20-%20HC%20N%B0003.gif)


2. Sélectionnez l'encodage voulu. 

3. Enregistrez le fichier.







### Type de fin de ligne
<a name="type_fin_ligne_ELTPARAGRAPHE000120"></a>Il est possible de sélectionner et de connaître le type de délimiteur de fin de ligne utilisé par le fichier. La détection est automatiquement réalisée en ouverture du fichier. 

Pour changer le type de délimiteur de fin de ligne au fichier affiché : 

1. Cliquez sur le délimiteur actuel.  

2. Sélectionnez le délimiteur voulu. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Edition_texte_code%20-%20HC%20N%B0004.gif)


3. Enregistrez le fichier.
