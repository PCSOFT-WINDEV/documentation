


## Eléments de thème
			





## Présentation
<a name="presentation_ELTTEXTE000100"></a>
Les éléments de thème permettent de changer très rapidement l'aspect visuel d'un projet sans avoir besoin de retoucher chaque page et chaque modèle de pages.

Les éléments d'ambiances sont composées de trois éléments :

- **[les modèles de pages prédéfinis](../Editeurs/2016019.md)** : ils sont constitués de champs (essentiellement des [cellules](../WDChamp/1013096.md)) et définissent une mise en page par défaut pour les pages du projet.

- **[le thème](../Editeurs/2016020.md)** : elle est constituée d'une feuille de style normalisée pouvant être échangée avec celle de n'importe quel autre thème. Un thème s'applique sur une page, un modèle de page ou sur l'ensemble d'un projet.

- **[la palette de couleurs](../Editeurs/2016021.md)** : elle est constitué d'une série de couleurs harmonieuses entre elles et dont les noms sont normalisés pour pouvoir être interchangés. Elle s'applique sur les styles du thème pour en redéfinir les tons.






## Utilisation des éléments de thème
<a name="utilisation_des_elements_theme_ELTTEXTE000124"></a>


### Utilisation dans un nouveau projet
<a name="utilisation_dans_nouveau_projet_ELTPARAGRAPHE000030"></a>

Lors de la création d'un nouveau projet, l'assistant permet de choisir un thème et une palette de couleurs. Celles-ci seront associées au projet et utilisées par défaut dans toutes les pages.

Le thème d'un projet peut être changé à tout moment dans l'éditeur. Pour cela :

1. Affichez la description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

2. Sélectionnez l'onglet "Thème".

3. Choisissez le nouveau thème et sa palette de couleurs.

4. Validez la fenêtre de description du projet. 




Lors de la création des pages, vous pourrez choisir le ou les modèles de pages prédéfinis à utiliser.
