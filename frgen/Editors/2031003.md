


## WINDEV: Fenêtres créées via le RAD "fenêtre"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000391"></a>
L'assistant de création de fenêtres propose de nombreux types de fenêtres associées à des tables HFSQL. 

Pour lancer cet assistant: 

- Cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ico_nouveau.gif) parmi les boutons d'accès rapide. 

- La fenêtre de création d'un nouvel élément s'affiche: cliquez sur "Fenêtre" puis sur "Fenêtre".

- Dans la fenêtre de l'assistant, cliquez sur l'onglet "RAD" pour voir les différents types de fenêtres proposés. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=RAD_Fen%20-%20HC%20N%B0001.gif)





Les différents types de fenêtres dépendent du pattern RAD sélectionné. En effet, chaque type de pattern propose une sélection de types de fenêtres réutilisables.

Les types de fenêtres les plus courants sont les suivants:

- [Fenêtre fiche](#NOTE2_1): simple, avec parcours, avec table reliée liaison simple ou complexe, avec fiche reliée.

- [Fenêtre table](#NOTE3_1): simple, avec fiche détail, avec table reliée, de relation.

- [Fenêtre Vision](#NOTE3_6).




Remarque: Selon le pattern choisi, les caractéristiques des fenêtres peuvent être sensiblement différentes.

## Fenêtre fiche
<a name="fenetre_fiche_ELTTEXTE000415"></a>


### Cas général
<a name="cas_general_ELTPARAGRAPHE000043"></a>

Une fenêtre **fiche** affiche les valeurs d'un enregistrement dans une fiche, à raison d'une valeur par champ. Les enregistrements sont accessibles un par un.

La fiche peut au choix:

- Autoriser le passage ou non aux enregistrements suivants et précédents.

- Autoriser ou non la création, la modification et la suppression d'enregistrements.




Les différents types de fenêtres Fiche sont les suivants: 

- [Fiche](#NOTE2_2). 

- [Fiche avec fiche reliée](#NOTE2_6).

- [Fiche avec parcours](#NOTE2_4). 

- Fiche avec parcours et table reliée.

- [Fiche et table reliée - liaison complexe](#NOTE2_5). 

- [Fiche et table reliée - liaison simple](#NOTE2_3). 



<a name="NOTE2_2"></a>


### Fiche
<a name="fiche_ELTPARAGRAPHE000074"></a>

Ce type de fenêtre permet de visualiser et de modifier un enregistrement.

Ce type de fenêtre ne permet pas:

- Le parcours sur les différents enregistrements.

- La création et la suppression d'un enregistrement.




Une fenêtre "Fiche simple" est constituée de:

- Boutons pour valider, abandonner la saisie.

- Champs reliés aux rubriques de la table.




La fenêtre "Fiche simple" est généralement accessible depuis une fenêtre de type "Table simple" pour visualiser ou modifier l'enregistrement en cours.
<a name="NOTE2_6"></a>


### Fiche avec fiche reliée
<a name="fiche_avec_fiche_reliee_ELTPARAGRAPHE000093"></a>

Ce type de fenêtre permet de visualiser dans la même fenêtre le contenu des tables liées par une liaison simple (1 - N).

Les valeurs de l'enregistrement de la table principale et les enregistrements reliés à l'enregistrement en cours (dans la table principale) sont visualisés dans deux fiches.

Ce type de fenêtre est constitué de:

- Une fiche (dans la partie haute) qui affiche les valeurs de l'enregistrement en cours de la table de base (principale).

- Une fiche (dans la partie basse) qui affiche les valeurs d'un enregistrement relié à l'enregistrement en cours de la table principale.

- Boutons permettant de:

	- parcourir les enregistrements affichés dans les deux fiches,

	- créer un nouvel enregistrement dans la table principale et dans la table liée,

	- supprimer l'enregistrement en cours de la table principale et de la table liée,

	- fermer la fenêtre.







La fenêtre "Fiche avec table reliée" est conseillée lorsque seul un enregistrement est lié à l'enregistrement en cours dans la table principale.
<a name="NOTE2_4"></a>


### Fiche avec parcours
<a name="fiche_avec_parcours_ELTPARAGRAPHE000115"></a>

Ce type de fenêtre permet:

- La modification de l'enregistrement affiché.

- La création d'un enregistrement.

- La suppression d'un enregistrement.

- L'impression de l'enregistrement en cours.

- Le passage à un autre enregistrement (suivant ou précédent).




Une fenêtre de type "Fiche avec parcours" est constituée de:

- Champs reliés aux rubriques de la table.

- Quatre boutons de parcours.

- Boutons permettant de:

	- créer un nouvel enregistrement,

	- supprimer l'enregistrement en cours,

	- imprimer l'enregistrement en cours,

	- fermer la fenêtre.







Par rapport à une "Fiche", une "Fiche avec parcours" propose:

- le passage rapide d'une fiche à une autre,

- la possibilité de créer en chaîne plusieurs enregistrements.




**Conseil**: Pour les tables comportant de nombreux enregistrements, il est préférable de sélectionner les enregistrements dans un champ Table et de modifier ou visualiser l'enregistrement sélectionné dans une fenêtre de type "Fiche". En effet, la sélection dans un champ Table est plus rapide.
<a name="NOTE2_3"></a>


### Fiche avec table reliée - liaison simple
<a name="fiche_avec_table_reliee_liaison_simple_ELTPARAGRAPHE000146"></a>

Ce type de fenêtre permet de visualiser dans la même fenêtre le contenu de tables liées par une liaison simple (1 - N).

Les valeurs de l'enregistrement de la table principale sont visualisées dans une fiche. Les enregistrements reliés à l'enregistrement en cours (dans la table principale) sont visualisés dans un champ Table.

Ce type de fenêtre est constitué de:

- Une fiche (dans la partie haute) qui affiche les valeurs de l'enregistrement en cours de la table de base (principale).

- Un champ Table (dans la partie basse) qui affiche les enregistrements reliés à l'enregistrement en cours de la table principale.

- Boutons permettant de:

	- parcourir les enregistrements affichés dans la fiche et dans le champ Table,

	- créer un nouvel enregistrement dans la table principale,

	- supprimer l'enregistrement en cours de la table principale,

	- fermer la fenêtre,

	- ajouter une ligne dans le champ Table,

	- modifier une ligne dans le champ Table,

	- supprimer une ligne dans le champ Table.







**Remarques**:

- Si la table affichée dans la table est une table de relation, la fenêtre comporte les boutons nécessaires pour accéder à l'autre table en relation.

- Si ce type de fenêtre est sélectionné pour une table qui n'a pas de table liée (avec une liaison 1-N), WINDEV le signale.



<a name="NOTE2_5"></a>


### Fiche avec table reliée - liaison complexe
<a name="fiche_avec_table_reliee_liaison_complexe_ELTPARAGRAPHE000174"></a>

Ce type de fenêtre permet de visualiser à la fois:

- le contenu d'une table dans un champ Table,

- le contenu d'une table dans une fiche.




Les enregistrements affichés dans le champ Table et ceux enregistrés dans la fiche sont liés par une liaison complexe (N - N).

La fenêtre "Fiche avec table de relation" est constituée de:

- Une fiche (dans la partie haute) qui affiche les enregistrements de la table de base (principale).

- Un champ Table (dans la partie basse) qui affiche les enregistrements reliés à l'enregistrement en cours de la table principale.

- Boutons permettant de:

	- parcourir les enregistrements affichés dans la fiche et dans le champ Table,

	- créer un nouvel enregistrement dans la table principale,

	- supprimer l'enregistrement en cours de la table principale,

	- fermer la fenêtre,

	- ajouter une ligne dans le champ Table,

	- modifier une ligne dans le champ Table,

	- supprimer une ligne dans le champ Table.







La fenêtre "Fiche avec table de relation" est conseillée lorsque:

- le détail de la table doit être immédiatement affiché.

- la table contient des rubriques images ou multilignes à afficher.

## Fenêtre table
<a name="fenetre_table_ELTTEXTE000469"></a>


### Cas général
<a name="cas_general_ELTPARAGRAPHE000207"></a>

Une fenêtre **table** affiche les enregistrements sous forme d'un tableau (lignes et colonnes). Plusieurs enregistrements de la table peuvent être affichés dans la fenêtre.

Les rubriques d'un même enregistrement sont disposées en ligne.

**Remarque**: Ce type de fenêtre est automatiquement généré lors d'un Drag and Drop (glisser/déplacer) d'un nom de table ou d'un nom de requête présent dans le volet "Projet" ou "Schéma des données" vers l'espace de travail.

Les différents types de fenêtres Table sont les suivants: 

- [Table](#NOTE3_2). 

- [Table avec fiche détail](#NOTE3_3).

- [Table avec fiche reliée](#NOTE3_4).

- [Table de relation](#NOTE3_5). 



<a name="NOTE3_2"></a>


### Table
<a name="table_ELTPARAGRAPHE000233"></a>

Ce type de fenêtre permet:

- La visualisation des enregistrements dans un champ table.

- La création d'un enregistrement.

- La suppression d'un enregistrement.

- La modification d'un enregistrement.

- L'impression de la table. 




Une fenêtre de type "Table" est constituée de:

- Un champ Table qui affiche les enregistrements de la table liée.

- Boutons permettant de:

	- parcourir les enregistrements affichés dans le champ Table,

	- créer un nouvel enregistrement,

	- modifier un enregistrement,

	- supprimer un enregistrement,

	- imprimer les enregistrements,

	- fermer la fenêtre.







Ce type de fenêtre est conseillé dans tous les cas de gestion de tables <u><u><u><u>sauf</u></u></u></u>:

- Si le détail de l'enregistrement doit être visible immédiatement: préférez la fenêtre avec table et fiche de détail.

- Si des rubriques doivent être affichées dans des champs multilignes: préférez la fenêtre avec table et fiche de détail.

- Si la table contient des images à afficher immédiatement: préférez la fenêtre avec table et fiche de détail.

- Si la table a beaucoup de rubriques à afficher: préférez la fenêtre avec table et fiche de détail.

- Si des rubriques reliées doivent être affichées: préférez la fenêtre fiche avec table reliée.



<a name="NOTE3_3"></a>


### Table avec fiche détail
<a name="table_avec_fiche_detail_ELTPARAGRAPHE000270"></a>

Ce type de fenêtre permet de visualiser dans la même fenêtre le contenu d'une table dans un champ Table et dans une fiche. Cette fenêtre permet la sélection d'un enregistrement dans le champ Table et la visualisation du détail de l'enregistrement sélectionné dans une fiche.

La fenêtre "Table avec fiche détail" est constituée de:

- Un champ Table (dans la partie haute) qui affiche les enregistrements de la table.

- Une fiche (dans la partie basse) qui affiche les valeurs de la ligne sélectionnée dans le champ Table

- Plusieurs boutons permettant de:

	- parcourir les enregistrements affichés dans le champ Table,

	- créer un nouvel enregistrement,

	- modifier l'enregistrement en cours,

	- supprimer l'enregistrement en cours,

	- fermer la fenêtre.







La fenêtre "Table avec fiche détail" est conseillée lorsque:

- La table contient des rubriques images ou multi-lignes à afficher.

- Le détail de l'enregistrement doit être visible immédiatement.

- La table a beaucoup de rubriques à afficher.



<a name="NOTE3_4"></a>


### Table avec table reliée
<a name="table_avec_table_reliee_ELTPARAGRAPHE000295"></a>

Ce type de fenêtre permet d'afficher dans une même fenêtre le contenu de tables liées par une liaison simple ou complexe. Les champs Table sont en cascade: le second champ Table permet d'afficher les enregistrements reliés à la ligne sélectionnée dans le premier champ Table.

La fenêtre "Table avec table reliée" est constituée de:

- Un champ Table (dans la partie haute) qui affiche les enregistrements de la table de base.

- Un champ Table (dans la partie basse) qui affiche les enregistrements de la table reliée, correspondant à l'enregistrement en cours sélectionné dans le premier champ Table.

- Boutons permettant de:

	- parcourir les enregistrements affichés dans les champs Table,

	- créer un nouvel enregistrement dans la table principale,

	- modifier l'enregistrement en cours de la table principale,

	- supprimer l'enregistrement en cours de la table principale,

	- fermer la fenêtre,

	- ajouter un enregistrement dans la table reliée,

	- modifier un enregistrement dans la table reliée,

	- supprimer un enregistrement dans la table reliée.






<a name="NOTE3_5"></a>


### Table de relation
<a name="table_relation_ELTPARAGRAPHE000317"></a>

Ce type de fenêtre permet de visualiser les enregistrements d'une table.

Ce type de fenêtre ne permet pas les créations, les modifications et les suppressions d'enregistrements dans la table.

La fenêtre "Table de relation" est constituée de:

- Un champ Table qui affiche les enregistrements.

- Boutons permettant de:

	- parcourir les enregistrements,

	- fermer la fenêtre.






<a name="NOTE3_6"></a>


### Fenêtre Vision
<a name="fenetre_vision_ELTPARAGRAPHE000334"></a>

Les fenêtres Vision permettent de sélectionner un enregistrement dans une table. Par exemple, lors de la saisie d'une commande, des fenêtres Vision peuvent être ouvertes pour sélectionner le client et le produit.

Les fenêtres Vision sont appelées par le bouton qui a pour libellé [...] dans les fenêtres reliées à une table.
