
## Description d'un style WEBDEV
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000073"></a>
Lors de l'édition d'un style WEBDEV pour un type de champ, il est possible de saisir les caractéristiques des différents éléments composant le champ. 

La fenêtre de description d'un style WEBDEV permet de : 

- définir le nom du style. 

- définir pour chaque élément composant le champ associé au style WEBDEV les différents styles d'élément utilisés ainsi que les options supplémentaires. 




Pour plus de détails, consultez : 

- [Styles WEBDEV](../Editeurs/2016008.md). 

- [Styles d'éléments WEBDEV](../Editeurs/2016004.md).
