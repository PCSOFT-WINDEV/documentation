
## Cloner un thème ou un thème
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000244"></a>
Thèmes et Ambiances permettent de choisir et d'appliquer un modèle d'UI à un projet. Les Thèmes s'appliquent aux applications, les Ambiances s'appliquent aux sites.

Pour changer l'apparence d'un champ qui utilise un thème ou un thème, il suffit ensuite de surcharger le style du champ, ou de dissocier le champ du thème ou du thème.

En version 2024, il n'est plus nécessaire de surcharger les styles. Une nouvelle méthode consiste à cloner (ou dupliquer) un Thème ou un Thème existant, à le renommer, et ensuite à modifier directement les styles, nativement, sans avoir à les surcharger. La description des styles est ainsi plus simple. Notez qu'une fois dupliqué, le Thème ou le Thème ne bénéficie plus des éventuelles mises à jour fournies par PC SOFT.

**Le principe est simple** : 

1. Vous clonez [le thème](#NOTE2_1) ou [le thème](#NOTE2b_1). 

2. Vous modifiez [les styles du thème ou du thème cloné](#NOTE3_1).

## Cloner un thème
<a name="cloner_theme_ELTTEXTE000268"></a>


### Comment le faire ?
<a name="comment_faire_ELTPARAGRAPHE000034"></a>

Pour cloner un thème :

1. Ouvrir le projet WINDEV ou WINDEV Mobile voulu. 

2. Sous le menu "Projet", dans le groupe "Autres actions", déroulez "Thèmes du projet" et sélectionnez "Cloner le thème du projet". 

3. Dans la fenêtre qui s'affiche, indiquez : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0001.gif)


	- Le thème à cloner. Ce thème peut être différent du thème en cours dans le projet. 

- Le nom du nouveau thème. Ce nom permettra d'identifier le thème utilisé. 

- Les différentes options : 

	- **Appliquer ce thème cloné à toutes les fenêtres qui utilisent le thème original** : Cette option permet d'associer automatiquement le thème cloné aux fenêtres du projet utilisant le thème à cloner. Bien entendu, il est également possible d'appliquer le thème cloné ultérieurement (pour plus de détails, consultez [Appliquer un thème](../Editeurs/2016011.md)). 

	- **Renommer les images** : Cette option permet de renommer toutes les images du thème cloné avec le nouveau nom du thème. Cela permet de modifier facilement les images utilisées par le nouveau thème sans risquer de modifier les images utilisées par le thème original (par exemple si les deux thèmes restent associés au projet). 

	- **Faire de ce thème le thème par défaut du projet** : Cette option permet de modifier le thème associé au projet (dans la fenêtre de description du projet). Dans ce cas, toute nouvelle fenêtre utilisera le thème cloné. 

4. Validez. 




Le thème sélectionné est cloné dans le projet en cours. Selon les options choisies, le thème cloné est appliqué aux fenêtres utilisant le thème original et/ou il devient le thème par défaut du projet. 

Le thème cloné est copié dans le répertoire du projet (sous-répertoire "Thèmes").




### Remarques
<a name="remarques_ELTPARAGRAPHE000073"></a>

- Si le projet contient plusieurs configurations (par exemple WINDEV et WINDEV Mobile), le clonage des thèmes WINDEV s'appliquera aux configurations WINDEV et le clonage des thèmes WINDEV Mobile s'appliquera aux configurations WINDEV Mobile. 

- Si un même thème est cloné avec le même nom dans deux projets différents, les modifications effectuées dans le thème cloné du premier projet ne sont pas reportées dans le second projet. 

- Si le répertoire du thème cloné est copié dans le répertoire des thèmes de WINDEV ou de WINDEV Mobile, il sera proposé dans les thèmes applicables. 

- Si le projet utilise exclusivement les styles du thème cloné, le répertoire du thème original sera automatiquement supprimé lors de la réactualisation des styles. 

- Projet dans le GDS : 

	- Lors de la création d'un thème cloné, toutes les fenêtres sont extraites pour leur appliquer le thème cloné.

	- Pour partager un thème cloné entre plusieurs projets, il suffit de partager le répertoire du thème via le GDS.

## Cloner un thème
<a name="cloner_theme_ELTTEXTE000298"></a>


### Comment le faire ?
<a name="comment_faire_ELTPARAGRAPHE000090"></a>

Pour cloner un thème : 

1. Ouvrir le projet WEBDEV voulu. 

2. Sous le menu "Projet", dans le groupe "Autres actions", déroulez "Plus d'actions" et sélectionnez "Cloner le Thème du projet". 

3. Dans la fenêtre qui s'affiche, indiquez : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_Ambiance%20-%20HC%20N%B0001.gif)


	- Le thème à cloner. Ce thème peut être différent du thème en cours dans le projet. 

- Le nom du nouveau thème. Ce nom permettra d'identifier le thème utilisé. 

- Si le thème doit devenir le thème par défaut du projet. Si cette option est sélectionnée, le thème associé au projet sera modifié (dans la fenêtre de description du projet). Dans ce cas, toute nouvelle page utilisera le thème cloné. 

4. Validez. 




Le thème sélectionné est cloné dans le projet en cours. Selon les options choisies, le thème cloné devient le thème par défaut du projet. 

Le thème cloné est copié dans le répertoire du projet (sous-répertoire au nom du nouveau thème).




### Remarques
<a name="remarques_ELTPARAGRAPHE000110"></a>

- Si le projet contient plusieurs configurations (par exemple WINDEV et WEBDEV), le clonage des ambiances WEBDEV s'appliquera uniquement aux configurations WEBDEV. 

- Si un même thème est cloné avec le même nom dans deux projets différents, les modifications effectuées dans le thème cloné du premier projet ne sont pas reportées dans le second projet. 

- Si le répertoire du thème cloné est copié dans le répertoire des thèmes de WEBDEV, il sera proposé dans les thèmes applicables. 

- Projet dans le GDS : 

	- Lors de la création d'un thème cloné, toutes les pages sont extraites pour leur appliquer le thème cloné.

	- Pour partager un thème cloné entre plusieurs projets, il suffit de partager le répertoire du thème via le GDS.

## Modifier les styles
<a name="modifier_les_styles_ELTTEXTE000328"></a>


### Comment le faire ?
<a name="comment_faire_ELTPARAGRAPHE000126"></a>

Lorsque votre projet utilise un thème (ou un thème) cloné, il est possible de modifier les styles du thème (ou du thème) cloné pour les adapter à vos besoins. Plusieurs méthodes sont disponibles. 

**Méthode 1 : Modification du style via le report de surcharges** (onglet "Style" d'un champ) : 

1. Modifiez le style du champ : 

	- Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.

	- Affichez l'onglet "Style" de la fenêtre de description du champ. Le style affiché correspond au style du thème (ou du thème) cloné, avec ou non des surcharges. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0002.gif)


	- Réalisez les modifications voulues (et si nécessaire appliquez-les pour voir le résultat). 

2. Modifiez le style du thème (ou du thème) cloné :
	Pour reporter les différentes modifications (surcharges) dans le style du thème ou du thème cloné, vous pouvez : 

	- Cliquer dans l'entête de la fenêtre de description sur le lien "Reporter".  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0003.gif)


	- Dérouler le menu présent dans l'entête du lien et sélectionnez l'option "Reporter les surcharges".  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0004.gif)




Dans ce cas : 

- Tous les champs du projet utilisant le style du thème (ou du thème) cloné sont modifiés. 

- Les surcharges du champ sont annulées. Le champ utilise donc le style "sans surcharge". 

- Les autres champs utilisant le style modifié gardent leurs propres surcharges si elles existent. 




**Méthode 2 : Modification d'un style via l'option "Choisir un style"**: 

1. Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.

2. Affichez le menu contextuel et sélectionnez : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) l'option "Choisir un style". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0005.gif)


	- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) l'option "Choisir un style WEBDEV".

3. Sélectionnez le style voulu pour le champ dans le thème (ou le thème) modifié. 

4. Dans le menu contextuel du style, sélectionnez l'option "Modifier". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0006.gif)


5. Dans la fenêtre qui s'affiche, modifiez le style selon vos besoins. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cloner_gabarit%20-%20HC%20N%B0007.gif)


6. Validez les modifications. 




Le style du thème cloné (ou du thème cloné) est modifié. Cette modification est automatiquement reportée à tous les champs utilisant ce style du thème cloné (ou du thème cloné) dans le projet. Tous les champs gardent leurs surcharges (même le champ à partir duquel la modification a été réalisée). 

**Méthode 3 : Modification du style du thème** ("Style" d'un champ) :

1. Modifiez le style du champ : 

	- Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.

	- Affichez l'onglet "Style" de la fenêtre de description du champ. Le style affiché correspond au style du thème cloné. 

	- Réalisez les modifications voulues (et si nécessaire appliquez-les pour voir le résultat). 




2. Modifiez le style du thème cloné :
	Pour modifier le style du thème avec les modifications effectuées dans le champ, vous pouvez :

	- Cliquer dans l'entête de la fenêtre de description sur le lien "Modifier le style". 

	- Déroulez le menu présent dans l'enête du lien et sélectionnez l'option "Modifier le style". 





Dans ce cas : 

- Tous les champs du projet utilisant le style du thème cloné sont modifiés. 

- Les surcharges du champ sont conservées. 

- Les autres champs utilisant le style modifié gardent leurs propres surcharges si elles existent.
