
## Insérer un diagramme dans une page d'aide
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000095"></a>
Il est possible d'insérer un diagramme réalisé à l'aide de l'éditeur de diagramme dans une page d'aide. Il est ainsi possible d'expliciter un concept, une organisation à l'aide d'un diagramme. 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Insérer un diagramme
<a name="inserer_diagramme_ELTTEXTE000119"></a>
Pour insérer un diagramme dans une page d'aide :

1. Dans la page d'aide, positionnez le curseur à la position où le diagramme doit être inséré.

2. Sous le volet "Modification", dans le groupe "Edition", cliquez sur "Diagramme". 

3. Dans l'explorateur de fichiers, sélectionnez le fichier correspondant au diagramme à insérer dans la page d'aide (fichier wddiag) et validez. 

4. Si nécessaire, validez la copie du fichier dans le répertoire du projet. 

5. La fenêtre de description du diagramme apparaît : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Ins%E9rer_un_diagramme%20-%20HC%20N%B0001.gif)


6. Définissez si nécessaire les dimensions du diagramme dans l'aide. 

7. Validez. Le diagramme est intégré dans la page d'aide. Il peut être redimensionné grâce aux poignées de sélection.




**Remarques** : 

- Il est également possible d'utiliser l'option "Insérer un diagramme" du menu contextuel de la page d'aide. 

- Lorsque le diagramme est inséré dans la page d'aide, il est possible : 

	- d'afficher ses caractéristiques. 

	- de l'éditer dans l'éditeur de diagrammes.
