
## Tables et rubriques zombies
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000131"></a>
Lors de la vie d'une application, les rubriques vivent et meurent. Mais avant de mourir, elles peuvent se transformer en zombies.
Cela signifie que la rubrique existe encore dans la description des données, peut être utilisée dans le code existant de l'application, mais que la rubrique ne doit plus être utilisée dans l'écriture de tout nouveau code.
Une rubrique zombie mange de la place et devrait donc être supprimée.
On trouve souvent des rubriques zombies dans le code mort.
En version 23, il est possible d'indiquer les rubriques zombies dans le schéma des données; elles seront alors signalées à l'utilisation.

## Définir une table ou une rubrique comme étant "zombie"
<a name="definir_une_table_une_rubrique_comme_etant_zombie_ELTTEXTE000155"></a>


### Définir une table comme étant "zombie"
<a name="definir_une_table_comme_etant_zombie_ELTPARAGRAPHE000024"></a>

Pour définir une table zombie :

1. Sous l'éditeur de schémas des données, sélectionnez la table à manipuler. 

2. Affichez la description de la table (option "Description de la table" du menu contextuel). 

3. Dans l'onglet "Options" : 

	- Cochez l'option "Table obsolète ou zombie". 

	- Indiquez si nécessaire un commentaire. Ce commentaire sera affiché dans l'erreur de compilation générée lors de l'utilisation de la table zombie. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0001.gif)





4. Fermez la fenêtre de description de la table. 

5. Dans le graphe du schéma des données, la table zombie est identifiée par le pictogramme ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0002%201.gif) :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0002.gif)


6. Dans le volet "Schéma des données", la table zombie apparaît grisée et barrée :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0003.gif)


7. Générez le schéma des données pour prendre en compte les modifications. Dans les erreurs de compilation, une nouvelle erreur apparaît indiquant les utilisations de la table zombie. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0003%201.gif)





Remarque : Il est également possible d'effectuer l'opération inverse. 


### Définir une rubrique comme étant "zombie"
<a name="definir_une_rubrique_comme_etant_zombie_ELTPARAGRAPHE000052"></a>

Pour définir une rubrique zombie : 

1. Sous l'éditeur de schémas des données, sélectionnez la table à manipuler. 

2. Affichez la description des rubriques (option "Description des rubriques" du menu contextuel). 

3. Dans l'onglet "Avancé" : 

	- Cochez l'option "Rubrique zombie (obsolète)". 

	- Indiquez si nécessaire un commentaire. Ce commentaire sera affiché dans l'erreur de compilation générée lors de l'utilisation de la rubrique zombie. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0004.gif&type=thumb)





4. Validez. 

5. Dans le graphe du schéma des données, la rubrique zombie apparaît barrée dans la représentation de la table :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0005.gif)


6. Dans le volet "Schéma des données", la rubrique zombie apparaît grisée et barrée :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Fichier_zombie%20-%20HC%20N%B0005%201.gif)


7. Générez le schéma des données pour prendre en compte les modifications. Dans les erreurs de compilation, une nouvelle erreur apparaît indiquant que la rubrique zombie est utilisée. 




Remarque : Il est également possible d'effectuer l'opération inverse.

## Manipulation d'une table ou d'une rubrique zombie
<a name="manipulation_une_table_une_rubrique_zombie_ELTTEXTE000185"></a>
Dans les différents éditeurs manipulant des tables ou des rubriques (éditeur de fenêtres, d'états, de requêtes, etc.), les tables et les rubriques zombies sont facilement identifiables car elles sont grisées et rayées. 

De plus, une erreur de compilation permet d'identifier rapidement les éléments zombies utilisés.
