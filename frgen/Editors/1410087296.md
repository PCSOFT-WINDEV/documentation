


## Projet multi-schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000224"></a>
Un projet WINDEV, WEBDEV ou WINDEV Mobile peut désormais utiliser plusieurs analyses (descriptions des données). 
La version 2024 de WINDEV permet maintenant d'utiliser 2 ou plusieurs analyses différentes dans un même projet. 
Cette utilisation de plusieurs analyses peut être permanente, ou simplement ponctuelle afin de réaliser facilement des requêtes spécifiques. 
Le databinding est opérationnel sur toutes les tables de tous les schémas des données utilisés.

<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000248"></a>


### Définir un projet multi-schéma des données sous l'éditeur
<a name="definir_projet_multischema_des_donnees_sous_editeur_ELTPARAGRAPHE000024"></a>

Pour utiliser plusieurs analyses dans un seul projet : 

1. Ouvrez votre projet sous WINDEV, WEBDEV ou WINDEV Mobile. 

2. Affichez la fenêtre de description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". 

3. Dans l'onglet "Schéma des données", indiquez les différents schémas des données manipulés par le projet en cours via les boutons "Créer un schéma des données", "Ajouter un schéma des données", ou "Importer un schéma des données du GDS". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Description_Projet_Onglet_Analyse%20-%20HC%20N%B0001.gif)


4. Définissez l'ordre d'utilisation des schémas des données grâce aux boutons fléchés. Cet ordre est important si les schémas des données utilisés décrivent des tables de même nom (voir ci-dessous). 

5. Validez. 





### Définir un projet multi-schéma des données par programmation
<a name="definir_projet_multischema_des_donnees_par_programmation_ELTPARAGRAPHE000048"></a>

La fonction [HOuvreSchémaDesDonnées](../WDLang4/3044106.md) ouvre un schéma des données au format HFSQL Classic. Il est ainsi possible d'accéder aux tables décrites dans ce schéma des données, et à la structure de ces tables.

Pour ouvrir un schéma des données supplémentaire par programmation, il est nécessaire d'utiliser la fonction [HOuvreSchémaDesDonnéesComplémentaire](../WDLang4/1410090082.md). 
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Cette fonction n'est pas disponible.

## Remarques
<a name="remarques_ELTTEXTE000278"></a>


### Masquage automatique des tables de même nom dans des schémas des données multiples
<a name="masquage_automatique_des_tables_meme_nom_dans_des_schemas_des_donnees_multiples_ELTPARAGRAPHE000071"></a>

Les différentes analyses peuvent utiliser des tables de même nom. Dans ce cas, une seule table est utilisée. Ce table dépend de l'ordre défini pour les différentes analyses (description du projet ou ordre d'ouverture avec les fonctions [HOuvreSchémaDesDonnées](../WDLang4/3044106.md) et [HOuvreSchémaDesDonnéesComplémentaire](../WDLang4/1410090082.md)). Le principe est le suivant : 

- Schéma des données 1 :

	- Table A

	- Table B




- Schéma des données 2 :

	- Table B. Cette table sera "masquée", car elle est présente dans le schéma des données 1. 
			**Pour utiliser la table B du schéma des données 2**, il est nécessaire de renommer cette table dans le schéma des données 2. 

	- Table C




- Schéma des données 3 :

	- Table B : Cette table sera "masquée", car elle est présente dans le schéma des données 1. 
			**Pour utiliser la table B du schéma des données 3**, il est nécessaire de renommer cette table dans le schéma des données 3.

	- Fichier C : Cette table sera "masquée", car elle est présente dans le schéma des données 2. 
			**Pour utiliser la table C du schéma des données 3**, il est nécessaire de renommer cette table dans le schéma des données 3.

	- Table D. 





Dans le volet "Explorateur de projet", section "Schéma des données", les tables affichées seront les suivantes :

- Table A (schéma des données 1)

- Table B (schéma des données 1)

- Table C (schéma des données 2)

- Table D (schéma des données 3).





### Requêtes multiserveurs
<a name="requetes_multiserveurs_ELTPARAGRAPHE000109"></a>

Si vous utilisez plusieurs analyses, avec des tables utilisant des connexions à des serveurs différents, il est conseillé de définir les connexions dans l'éditeur de schémas des données (et non par programmation). Vous pouvez ainsi être certain que la connexion associée à la table utilisée est correcte (notamment si des tables de même nom sont utilisées). 


### Fonctions WLangage : comportement adapté pour gérer les projets multi-analyses
<a name="fonctions_wlangage_comportement_adapte_pour_gerer_les_projets_multianalyses_ELTPARAGRAPHE000114"></a>

Les fonctions suivantes manipulent les schémas des données, les tables, les liaisons, etc. Leur comportement a été adapté pour gérer les projets multi-analyses. 


|   |   |
| --- | --- |
| [HChangeConnexion](../WDLang4/3044150.md) | Si le nom de la table n'est pas précisé, change la connexion pour les tables décrites dans les différentes analyses. |
| [HChangeRep](../WDLang4/3044168.md) | Si le nom de la table n'est pas précisé, change le répertoire pour les tables décrites dans les différentes analyses. |
| [HCréeSiInexistant](../WDLang4/3044254.md) | Si le nom de la table n'est pas précisé, toutes les tables de tous les schémas des données seront créées ou ouvertes. |
| [HFermeSchémaDesDonnées](../WDLang4/3044054.md) | Ferme tous les schémas des données associés au projet. |
| [HGèreREP](../WDLang4/3044061.md) | Si seul le mode de gestion du fichier .rep est précisé, la modification est globale à tous les schémas des données associés au projet. |
| [HInfoSchémaDesDonnées](../WDLang4/1000019773.md) | Si le schéma des données n'est pas précisé, seul le schéma des données principal est manipulé. |
| [HListeConnexion](../WDLang4/3044046.md) | Si plusieurs schémas des données sont en cours, liste toutes les connexions de tous les schémas des données en cours. |
| [HListeLiaison](../WDLang4/3044138.md) | Si plusieurs schémas des données sont en cours, liste toutes les liaisons de tous les schémas des données. |
| [HListePersoDossier](../WDLang4/1000019775.md) | Si plusieurs schémas des données sont en cours, liste tous les perso-dossiers de tous les schémas des données. |
| [HListeREP](../WDLang4/3044229.md) | Si plusieurs schémas des données sont en cours, seul le schéma des données principal est manipulé. |
| [HListeTable](../WDLang4/3044045.md) | Si plusieurs schémas des données sont en cours, liste toutes les tables de tous les schémas des données. |
| [ProjetInfo](../WDLang1/3064004.md) | Si plusieurs schémas des données sont en cours, la constante *piAnalyse* permet de récupérer uniquement le nom du schéma des données principal. |
