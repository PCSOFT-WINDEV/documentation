## Manipulation d'une table
<a name="manipulation_une_table_ELTTEXTE000213"></a>


### Dupliquer/Copier une table
<a name="dupliquercopier_une_table_ELTPARAGRAPHE000034"></a>

La duplication d'une table permet de disposer de deux tables identiques de noms différents.

Pour dupliquer/copier une table :

1. Sélectionnez la table à dupliquer dans l'éditeur de schémas des données.

2. Sous le volet "Accueil", dans le groupe "Edition", cliquez sur "Dupliquer". 
	Remarque : Il est également possible de sélectionner l'option "Dupliquer" dans le menu contextuel de la table. 

3. Spécifiez les informations demandées et validez. La table dupliquée est automatiquement créée dans le schéma des données (MLD) en cours.



<a name="NOTE2_2"></a>


### Supprimer une table
<a name="supprimer_une_table_ELTPARAGRAPHE000061"></a>

Pour supprimer une table :

1. Sélectionnez la table à supprimer dans l'éditeur de schémas des données.

2. Affichez le menu contextuel de la table sélectionnée (clic droit).

3. Sélectionnez l'option "Supprimer". La table est automatiquement supprimée du schéma des données (MLD). Si des liaisons pointaient sur cette table, ces liaisons sont également supprimées.




**Remarque** : Lors de la création d'une table dont le nom est identique à celui d'une table précédemment supprimée, WINDEV, WEBDEV et WINDEV Mobile proposent de restaurer la description de la table supprimée.
<a name="NOTE2_3"></a>


### Renommer une table
<a name="renommer_une_table_ELTPARAGRAPHE000074"></a>

Pour renommer une table :

1. Sélectionnez la table à renommer dans l'éditeur de schémas des données.

2. Affichez la description de la table :

	- Sous le volet "Schéma des données", dans le groupe "Élément courant", cliquez sur "Description".

	- Affichez le menu contextuel de la table (clic droit) et sélectionnez l'option "Description de la table". 




3. Dans la fenêtre de description, modifiez le nom de la table (et si nécessaire son nom sur disque). 

4. Validez. La table est automatiquement renommée.



<a name="NOTE2_4"></a>


### Utiliser un dictionnaire
<a name="utiliser_dictionnaire_ELTPARAGRAPHE000101"></a>

Une table peut simplement être intégrée dans un dictionnaire pour être ré-utilisée par exemple dans une nouvelle application. L'intégration de la table dans un dictionnaire se fait par simple "Drag and Drop" de la table depuis l'éditeur de schémas des données, vers le dictionnaire (affiché dans le [volet "Dictionnaire"](../Editeurs/2027014.md)).

Lors de son intégration dans le dictionnaire, la description de la table peut être abonnée aux modifications. Toute modification réalisée dans la description de la table pourra être reportée sur l'objet du dictionnaire et sur toutes les utilisations de cet objet.

Pour plus de détails, consultez le [dictionnaire](../Editeurs/2023002.md).
<a name="NOTE2_5"></a>


### Créer à vide la table physique correspondant à la description
<a name="creer_vide_table_physique_correspondant_description_ELTPARAGRAPHE000118"></a>

Pour créer à vide la table physique correspondante :

1. Dans l'éditeur de schémas des données, sélectionnez la table pour laquelle une table physique doit être créée.

2. Affichez le menu contextuel de la table (clic droit) et sélectionnez l'option "Créer la table".

3. Sélectionnez le répertoire dans lequel la table doit être créée et validez.




Les fichiers suivants sont automatiquement créés dans le répertoire donné :

- "&lt;Nom de la table&gt;.FIC" (table).

- "&lt;Nom de la table&gt;.MMO" (table mémo).

- "&lt;Nom de la table&gt;.NDX" (table d'index).




Si la table est journalée, un sous-répertoire "JNL" sera automatiquement créé et contiendra les différentes tables du journal.

Si la table contient un index full-text, une table "&lt;Nom de la table&gt;.FTX" sera créée. 

**Remarques** :

- Cette option est identique à l'utilisation de la fonction [HCréeSiInexistant](../WDLang4/3044254.md).

- Si la table existe déjà dans le répertoire spécifié, cette option n'est pas prise en compte.
