


## Styles d'élément WEBDEV
			





## Présentation
<a name="presentation_ELTTEXTE000132"></a>
Les différents champs d'un projet WEBDEV sont associés à des styles WEBDEV. Ce style WEBDEV est composé de plusieurs styles d'élément WEBDEV. 

Les styles d'élément WEBDEV permettent de réutiliser une spécificité du style dans tous les champs utilisant ce style d'élément. Par exemple, il est possible de définir un style d'élément WEBDEV pour indiquer les caractéristiques de la police pour les champs Boutons du site. 
**Remarque** : Le style d'élément WEBDEV s'appuie sur des propriétés CSS standard (Cascading Style Sheets ou Feuilles de style en cascade). 

WEBDEV permet de gérer les styles d'élément WEBDEV. Il est possible de : 

- [Créer un style d'élément WEBDEV](#NOTE3_1).

- [Modifier un style d'élément WEBDEV](#NOTE3_2).

- [Associer un style d'élément WEBDEV à un champ](#NOTE3_3).

## Gestion des styles d'élément WEBDEV
<a name="gestion_des_styles_element_webdev_ELTTEXTE000156"></a>


### Création et modification d'un style d'élément WEBDEV
<a name="creation_modification_style_element_webdev_ELTPARAGRAPHE000037"></a>

La création et la modification d'un style d'élément WEBDEV peut être effectuée : 

- [depuis la fenêtre de description des styles d'un champ](#NOTE3_2). 

- depuis la fenêtre de gestion des styles d'élément WEBDEV. Pour plus de détails, consultez [Edition des styles d'élément WEBDEV](../Editeurs/2016001.md). 



<a name="NOTE3_2"></a>


### Création et modification d'un style d'élément WEBDEV depuis la fenêtre de description du style d'un champ
<a name="creation_modification_style_element_webdev_depuis_fenetre_description_style_champ_ELTPARAGRAPHE000052"></a>

La fenêtre de description des champs permet de gérer le style de ce champ (onglet "Style"). Différents éléments sont gérés par l'onglet "Style". Ces éléments utilisent des "Styles de l'élément". Par exemple, pour un champ de type Liste : 

- un style de l'élément est utilisé pour le libellé du champ.

- un style de l'élément est utilisé pour les éléments intérieurs du champ (la zone de saisie).




Le style de l'élément peut être modifié ou surchargé. 

- S'il est modifié, la modification sera effective pour tous les champs utilisant ce style d'élément. 
	Pour modifier un style d'élément, ouvrez le menu contextuel du jeton correspondant et sélectionnez l'option "Editer le style d'élément". 

- S'il est surchargé, les surcharges seront prises en compte localement, pour le champ en cours. Les autres champs utilisant ce style d'élément ne seront pas impactés par la modification. 
	Pour surcharger un style d'élément, modifiez directement les options présentes dans l'onglet "Style" du champ. Le lien "+ de surcharges" permet d'accéder à plus d'options. 
	 Note : Il est déconseillé d'utiliser des surcharges locales car cette option augmente la taille des pages HTML générées (et donc le temps de chargement de la page sur le navigateur de l'internaute).




Pour plus de détails sur la description d'un style d'élément WEBDEV, consultez [Fenêtre de description d'un style d'élément WEBDEV](../Editeurs/2016007.md).
<a name="NOTE3_3"></a>


### Associer un style d'élément WEBDEV à un champ
<a name="associer_style_element_webdev_champ_ELTPARAGRAPHE000078"></a>

Pour associer un style d'élément WEBDEV à un champ : 

1. Affichez la fenêtre de description du champ.  

2. Dans l'onglet "Style", sélectionnez l'élément dont le style doit être modifié : Zone de saisie, Libellé, etc.

3. Dans la zone "Styles de l'élément", ajoutez styles de l'élément à utiliser : sélectionnez dans la liste le style voulu. 

4. Validez la fenêtre de description du champ.
