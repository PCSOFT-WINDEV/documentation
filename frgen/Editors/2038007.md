


## GDS : Réintégrer un élément
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000166"></a>
La réintégration d'un élément dans la base de sources permet de mettre à disposition de tous les utilisateurs du gestionnaire de sources un élément qui a été modifié. L'élément modifié en local est recopié dans le projet de référence sur le serveur GDS.

Le GDS permet de : 

- réintégrer un élément directement dans la base de sources. 

- [historiser localement un élément](../Editeurs/2510003.md).
	




Remarque : Si une politique de réintégration a été définie, la réintégration sera possible uniquement si l'élément réintégré respecte cette politique. Pour plus de détails, consultez [Politique de réintégration](../Editeurs/2038024.md).

<a name="NOTE2_1"></a>


## Réintégration d'un élément
<a name="reintegration_element_ELTTEXTE000199"></a>
**Pour réintégrer un élément dans la base de sources**, plusieurs méthodes sont disponibles : 

- via le ruban : 
	Sous le volet "GDS", dans le groupe "Elément en cours", cliquez sur "Réintégrer" (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Barre_outils%20-%20HC%20N%B0004%201.gif)).

- via le volet "Explorateur de projet" : 
	Sélectionnez l'élément dans le volet "Explorateur de projet" puis sélectionnez l'option "Réintégrer" du menu contextuel.




**Important** : La feuille de styles est un élément spécifique du projet. Pour réintégrer la feuille de styles, sous le volet "GDS", dans le groupe "Autres actions", déroulez "Feuille de styles" et sélectionnez "Réintégrer la feuille de styles du projet".
Lors de la réintégration d'un élément dans le GDS, la fenêtre suivante est affichée :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0014.gif)
Cette fenêtre propose différents onglets pour préciser des informations sur la réintégration : 

- L'onglet "Tâches" permet d'indiquer que l'élément réintégré correspond à l'exécution ou à la réalisation d'une tâche.

- L'onglet "Incidents" permet d'indiquer que l'élément réintégré corrige un incident.

- L'onglet "Commentaire" permet de saisir un commentaire sur la réintégration. Par exemple, vous pouvez indiquer que la fenêtre propose désormais une nouvelle option de menu. 
	Le bouton "IA : Générer le commentaire" permet de générer automatiquement un commentaire à partir des modifications effectuées dans le code. Pour plus de détails, consultez [IA dans l'éditeur de code](../Editeurs/9000219.md). 




Cette fenêtre permet également de : 

- Connaître les modifications effectuées sur l'élément (bouton "Mes Modifs").

- Visualiser les propriétés de l'élément (bouton "Propriétés").

- Visualiser l'historique des actions d'extraction / réintégration effectuées sur l'élément. 




Il est possible de réintégrer les modifications effectuées dans l'élément, tout en conservant l'élément extrait (option "Garder l'élément extrait").

**Remarques** : 

- Si l'élément réintégré n'a pas été modifié, le GDS affiche un écran spécifique. 

- Si l'élément a été historisé localement, la fenêtre de réintégration de l'élément dans la base de sources affiche les informations suivantes : 

	- Nombre de versions locales. 

	- Option "Aplatir les versions locales" : Si les versions locales sont aplaties, le détail des versions locales n'apparaîtra pas dans l'historique de l'élément. Il ne sera pas possible de revenir à l'état d'une version locale. Dans le cas contraire, chaque version locale apparaîtra dans l'historique de l'élément. 




- Pour plus de détails, consultez [GDS : Historiser localement](../Editeurs/2510003.md).
