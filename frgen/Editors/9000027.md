## Présentation
<a name="presentation_ELTTEXTE000138"></a>


### Qu'est-ce qu'un métatype ?
<a name="questce_quun_metatype_ELTPARAGRAPHE000011"></a>

Un métatype est une combinaison de caractéristiques d'une rubrique et du champ relié.

Par exemple un métatype "Fax" contiendra le type et la longueur de la rubrique, le masque de saisie, le cadrage, etc.

Cette information sera ensuite reprise dans tous les modules, pour chaque action. La définition du schéma des données est ainsi simplifiée ainsi que le processus de génération RAD, la création automatique d'un champ, etc.

Il est possible :

- [soit d'utiliser un métatype proposé sous l'éditeur de schémas des données](#NOTE2_1).

- [soit de créer ses propres métatypes](#NOTE2_2).

## Comment le faire ?
<a name="comment_faire_ELTTEXTE000162"></a>


### Utiliser un métatype proposé par l'Éditeur de schémas des données
<a name="utiliser_metatype_propose_par_editeur_schemas_des_donnees_ELTPARAGRAPHE000033"></a>

Pour créer une rubrique à partir d'un métatype dans l'éditeur de schémas des données :

1. Sous l'éditeur de schémas des données, affichez la description des rubriques de la table voulue (double-cliquez sur la table par exemple).

2. Cliquez sur l'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=MLD_Metatype_ico.gif).

3. La fenêtre suivante s'affiche :<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=MLD_Metatype.gif&type=thumb)


4. Indiquez un mot-clé dans la combo et cliquez sur le bouton "Rechercher". Lorsque le métatype voulu est trouvé, cliquez sur son image. Ses caractéristiques sont affichées.

5. Validez. La rubrique correspondante est automatiquement créée.




Remarque : Il est également possible lors de la création de la rubrique, de sélectionner l'option &lt;Métatype&gt; dans la liste des noms de rubrique disponibles.
<a name="NOTE2_2"></a>


### Créer un métatype qui sera proposé par l'Éditeur de schémas des données
<a name="creer_metatype_qui_sera_propose_par_editeur_schemas_des_donnees_ELTPARAGRAPHE000051"></a>

Pour créer un métatype dans l'Éditeur de schémas des données :

1. Sous l'éditeur de schémas des données, affichez la description des rubriques de la table voulue (double-cliquez sur la table par exemple).

2. Cliquez sur l'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=MLD_Metatype_ico.gif).

3. La fenêtre de gestion des métatypes s'affiche. 

4. Cliquez sur le bouton "Nouveau" (sous l'option "Métatypes utilisateurs") pour créer un métatype.

5. Dans la fenêtre à onglets qui s'affiche, indiquez :

	- dans l'onglet "Général" : 

		- Nom du métatype.

		- Description du métatype.

		- Image du métatype.




- dans l'onglet "Paramètres" : 

	- le type et le sous type de la rubrique (ces informations correspondent aux options sélectionnées pour la rubrique de base du métatype).

	- la valeur par défaut.

	- les infos partagées (ces informations correspondent aux options sélectionnées pour la rubrique de base du métatype).

6. Validez la création du métatype. Le métatype est enregistré dans un fichier au format XML. Par défaut, ce fichier est enregistré dans le sous-répertoire "\\Personal\\Metatype" de WINDEV, WEBDEV ou WINDEV Mobile. Ce métatype pourra ensuite être importé dans l'éditeur de schémas des données d'un autre poste.



<a name="NOTE2_3"></a>


### Importer un métatype dans l'éditeur de schémas des données
<a name="importer_metatype_dans_editeur_schemas_des_donnees_ELTPARAGRAPHE000081"></a>

Pour importer un métatype utilisateur dans l'éditeur de schémas des données :

1. Sous l'éditeur de schémas des données, sélectionnez l'option "Schéma des données .. Importer un métatype utilisateur".
	Remarque : Pour accéder à cette option, utilisez le menu principal accessible par le logo de la version du produit : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Ruban_logo_menu17.gif)


2. Sélectionnez le fichier XML correspondant au métatype à importer. Ce fichier XML a été créé lors de la création du métatype.
