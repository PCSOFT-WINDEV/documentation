- [Dupliquer/Copier un schéma des données](#NOTE2_1).

- [Supprimer un schéma des données](#NOTE2_2).

- [Renommer un schéma des données](#NOTE2_3).

- [Associer un schéma des données à un projet existant](#NOTE2_4).

## Manipulation d'un schéma des données (MLD)
<a name="manipulation_schema_des_donnees_mld_ELTTEXTE000251"></a>


### Dupliquer/Copier un schéma des données
<a name="dupliquercopier_schema_des_donnees_ELTPARAGRAPHE000039"></a>

La duplication d'un schéma des données permet de disposer de deux schémas des données identiques de nom différent.

Pour dupliquer/copier un schéma des données :

1. Ouvrez le schéma des données à dupliquer sous l'éditeur de schémas des données.

2. Sous le volet "Accueil", dans le groupe "Général", déroulez "Enregistrer" et sélectionnez "Enregistrer sous". La description du schéma des données s'affiche.

3. Modifiez le nom et le répertoire du schéma des données.

4. Validez les modifications :

	- L'ensemble des fichiers décrivant le schéma des données dupliqué est automatiquement créé dans le répertoire spécifié.

	- Le schéma des données dupliqué est automatiquement associé au projet en cours.







**Remarque** : Les sous-répertoires de sauvegarde du schéma des données d'origine ne sont pas copiés. La nouvelle schéma des données ne contient aucune sauvegarde.
<a name="NOTE2_2"></a>


### Supprimer un schéma des données
<a name="supprimer_schema_des_donnees_ELTPARAGRAPHE000070"></a>

Pour supprimer un schéma des données :

1. Ouvrez l'explorateur de Windows.

2. Supprimez le répertoire complet du schéma des données (répertoire &lt;Nom du projet&gt;.SCH).




**Remarque** : Si un projet utilisait ce schéma des données, il sera nécessaire d'associer le projet à un autre schéma des données lors de l'ouverture de ce projet.
<a name="NOTE2_3"></a>


### Renommer un schéma des données
<a name="renommer_schema_des_donnees_ELTPARAGRAPHE000082"></a>

Pour renommer un schéma des données :

1. Ouvrez le schéma des données à renommer sous l'éditeur de schémas des données.

2. Sous le volet "Accueil", dans le groupe "Général", déroulez "Enregistrer" et sélectionnez "Enregistrer sous". La description du schéma des données s'affiche.

3. Saisissez le nouveau nom du schéma des données.

4. Validez la modification.

5. L'ensemble des fichiers décrivant le schéma des données renommé est automatiquement créé dans le répertoire spécifié.

6. Le schéma des données renommé n'est pas automatiquement associé au projet en cours. Associez si nécessaire le schéma des données renommé au projet en cours. Pour plus de détails, consultez [Associer un schéma des données à un projet existant](#NOTE2_4).

7. Supprimez si nécessaire sous l'explorateur de Windows le répertoire du schéma des données d'origine.



<a name="NOTE2_4"></a>


### Associer un schéma des données à un projet existant
<a name="associer_schema_des_donnees_projet_existant_ELTPARAGRAPHE000112"></a>

Pour associer un schéma des données à un projet existant :

1. Ouvrez le projet à associer.

2. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". La description du projet s'ouvre.

3. Dans l'onglet "Schéma des données", cliquez sur "Ajouter un schéma des données" et sélectionnez le chemin du fichier WDD correspondant au schéma des données à associer.




**Remarques** : 

- Il est possible d'associer plusieurs analyses à un même projet. Pour plus de détails, consultez [Projet multi-schéma des données](../Editeurs/1410087296.md). 

- Suppression d'un schéma des données et remplacement par un nouveau schéma des données : Si des données du schéma des données d'origine sont manipulées dans le projet, l'association d'un nouveau schéma des données peut entraîner des erreurs (erreurs de doublons, erreurs d'affichage, etc.).



<a name="NOTE2_5"></a>


### Facteur de zoom
<a name="facteur_zoom_ELTPARAGRAPHE000145"></a>

Il est possible de spécifier un facteur de zoom sous l'éditeur de schémas des données pour réduire ou agrandir l'affichage du graphe du schéma des données en cours.

Pour spécifier un facteur de zoom :

- **1ère méthode** :

	- Soit sous le volet "Affichage", dans le groupe "Aide à l'édition", choisissez le facteur de zoom à utiliser.

	- Soit saisissez directement le facteur de zoom dans la barre de message de l'éditeur (en bas à droite).




<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=ZoomBarreMessage.gif)


- **2ème méthode** :

	- Appuyez sur la touche Ctrl.

	- Modifiez le facteur de zoom avec la roulette de la souris tout en maintenant la touche Ctrl enfoncée.






<a name="NOTE2_6"></a>


### Déplacer l'affichage d'un schéma des données
<a name="deplacer_affichage_schema_des_donnees_ELTPARAGRAPHE000174"></a>

Pour déplacer l'affichage d'un schéma des données :

1. Affichez le schéma des données sous l'éditeur de schémas des données.

2. Appuyez sur la touche Alt.

3. Modifiez la position du graphe du schéma des données en maintenant à la fois le bouton gauche de la souris et la touche Alt enfoncés.
