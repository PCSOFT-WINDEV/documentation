


## Réparation du schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000097"></a>
Dans certains cas, des messages d'erreur peuvent apparaître lors de l'ouverture du schéma des données lié à un projet. Les messages d'erreur peuvent être par exemple :

- Le fichier recherché est inconnu.

- Fichier non trouvé dans deffic.




Il est possible de réparer directement le schéma des données.

**Remarque** : Il est conseillé de réaliser une sauvegarde du schéma des données avant de le réparer.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000121"></a>


### Réparer un schéma des données
<a name="reparer_schema_des_donnees_ELTPARAGRAPHE000025"></a>

Pour réparer un schéma des données :

1. Sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance" et sélectionnez "Réparer le schéma des données".

2. Sélectionnez le schéma des données à réparer. Il est possible de réparer :

	- Le schéma des données en cours.

	- Un schéma des données spécifique. Il suffit alors de sélectionner le fichier ".wda" correspondant au schéma des données à réparer.




3. Sélectionnez le mode de réparation à effectuer :

	- **Réparation rapide** : les tables correspondant à la description du schéma des données sont réindexées, le schéma des données est synchronisé avec sa représentation graphique et il est mis à niveau.

	- **Réparation complète** : Réparation rapide avec vérification de la cohérence du schéma des données. Il est possible de choisir les actions à effectuer.




4. Validez. La réparation du schéma des données est effectuée.
