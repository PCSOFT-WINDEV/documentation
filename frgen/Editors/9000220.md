
## Mes champs prédéfinis
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000157"></a>
Il arrive souvent qu'un développeur recrée les mêmes champs, avec le même style et le même code (ou à peu près) dans un même projet, sans désirer utiliser un modèle ou une Fenêtre Interne. L'exemple le plus parlant concerne les boutons "OK" et "Annuler".

Souvent le mode opératoire adopté par le développeur consistait à copier un champ existant depuis une autre page ou une autre fenêtre, à le coller puis à le modifier.

La notion de Champ prédéfini répond à ce besoin de manière plus simple.


	<B><B><B><B>Avertissement</B></B></B></B>

	 En version 2025, les "Champs favoris" sont devenus "Mes champs prédéfinis".

## Créer un champ prédéfini
<a name="creer_champ_predefini_ELTTEXTE000181"></a>
Pour définir un champ prédéfini: 

1. Créez votre champ, définissez son look et son code si nécessaire. 

2. Dans le menu contextuel du champ, sélectionnez l'option "Ajouter à mes Champs Prédéfinis". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champs_favoris%20-%20HC%20N%B0001.gif)


3. Dans la fenêtre qui s'affiche, indiquez les caractéristiques du champ prédéfini: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champs_favoris%20-%20HC%20N%B0002.gif)


	- Le titre: Titre du champ prédéfini. Le titre apparaît au dessus de l'aperçu du champ dans la liste "Mes champs prédéfinis". Il apparaît également en titre de la bulle d'aide lors du survol du champ prédéfini. 

- L'auteur: Créateur du champ prédéfini. 

- La description: Description du champ prédéfini (but, etc.). Cette description est affichée dans la bulle d'aide lors du survol du champ prédéfini. 

- Le type de champ concerné: Type de champ pour lequel le champ prédéfini sera proposé (lors du déroulement du menu de création du champ). 

- Les catégories: Catégories permettant de regrouper les champs prédéfinis. Pour créer une nouvelle catégorie, saisissez son nom et appuyez sur la touche Entrée. Pour utiliser une catégorie existante, saisissez la première lettre de cette catégorie. 

- Les mots-clés associés: Mots-clés permettant de rechercher un champ prédéfini dans la liste "Mes Champs Prédéfinis". Pour utiliser un mot-clé existant, saisissez la première lettre de ce mot-clé. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Indiquez si le thème de la fenêtre destination doit être appliqué lors de lâché du champ. Dans ce cas, le style du champ sera modifié pour s'harmoniser avec le thème de la fenêtre l'accueillant.
			![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/us/WBS.png) Indiquez si le thème de la page destination doit être appliqué au lâché du champ. Dans ce cas, le style du champ sera modifié pour s'harmoniser avec le thème de la page l'accueillant.

4. Validez. 




Le champ prédéfini créé sera proposé: 

- dans la fenêtre "Mes champs Prédéfinis" . 

- dans la liste des champs disponibles affichée pour chaque type de champ (dans le volet "Création" du ruban de l'éditeur). 





### Remarques
<a name="remarques_ELTPARAGRAPHE000053"></a>

- Il est également possible de créer un champ prédéfini à partir d'une sélection de champs. 

- Les champs prédéfinis concernent uniquement les fenêtres et les pages. 

- Un champ prédéfini d'une fenêtre ne peut pas être utilisé dans une page (et inversement). 

- Un champ prédéfini d'une fenêtre WINDEV ne peut pas être utilisé dans une fenêtre WINDEV Mobile (et inversement). 

- Les champs prédéfinis sont liés à un projet. Cependant, il est possible de les utiliser dans plusieurs projets. Pour plus de détails, consultez [Partager un champ prédéfini](#NOTE4_1). 

- Il est possible d'éditer la description d'un champ prédéfini directement depuis la liste proposant le champ prédéfini. Il suffit de faire un clic droit sur le champ dans la liste et de sélectionner l'option "Editer".

## Réutiliser un champ prédéfini
<a name="reutiliser_champ_predefini_ELTTEXTE000211"></a>
Pour réutiliser un champ prédéfini, plusieurs méthodes sont disponibles: 

- Utilisation de l'option "Mes Champs Prédéfinis" présente dans le volet "Création" du ruban: 

	1. Sous le volet "Création", dans le groupe "Prédéfinis  Métier", déroulez "Mes Champs Prédéfinis". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champs_favoris%20-%20HC%20N%B0004.gif)


	2. Recherchez le champ prédéfini voulu (recherche par mot-clé ou par catégorie). 

3. Sélectionnez le champ prédéfini voulu et effectuez un "Drag and Drop" vers la fenêtre ou la page en cours. 

4. Le champ est créé dans la page ou la fenêtre en cours. 

- Utilisation des champs prédéfinis pour un type de champ: 

	1. Sous le volet "Création", déroulez l'option correspondant au champ à créer. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Champs_favoris%20-%20HC%20N%B0005.gif)


	2. En début de liste, les champs prédéfinis correspondant au type de champ sélectionné apparaissent. 

3. Sélectionnez le champ prédéfini voulu et effectuez un "Drag and Drop" vers la fenêtre ou la page en cours. 

4. Le champ est créé dans la page ou la fenêtre en cours.

## Partager un champ prédéfini
<a name="partager_champ_predefini_ELTTEXTE000235"></a>
La description des champs prédéfinis est présente dans le sous-répertoire "Preset" du répertoire du projet dans lequel le champ prédéfini a été créé. 

Le partage des champs prédéfinis peut être effectué via le GDS (Gestionnaire De Sources). En effet, Il suffit de partager le répertoire "Preset" entre différents projets pour que les champs prédéfinis soient disponibles. 

Il est également possible de copier les champs prédéfinis d'un projet vers un autre: il suffit de recopier le répertoire "Preset" dans le projet voulu. 

Remarque: Dans le répertoire "Preset", les champs prédéfinis sont organisés par produit.
