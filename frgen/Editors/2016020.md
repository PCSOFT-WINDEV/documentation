


## Ambiances
			





## Présentation
<a name="presentation_ELTTEXTE000138"></a>
Les ambiances permettent d'harmoniser l'aspect visuel d'un site et rendent les changements de look faciles et rapides.

Un thème est composé de:

- une feuille de styles contenant des styles WEBDEV.

- un répertoire d'images.

- une palette de couleurs par défaut.

- un ensemble d'états utilisés comme base pour construire les nouveaux états du projet.




Détaillons ces différents éléments: 

- La feuille de styles: 
	**Rappel**: Une feuille de styles est constituée de styles WEBDEV. Chaque style WEBDEV regroupe: 

	- un ou plusieurs styles CSS,

	- des valeurs de propriétés pour le champ.
			Un style WEBDEV s'applique à un type de champ particulier.
			Les styles d'un thème ont des noms normalisés. Ainsi, les ambiances sont interchangeables les unes avec les autres.




- Les images: 
	Les images livrées avec le thème servent à définir l'aspect visuel des cellules, des tables, des champs onglets, etc.

- La palette de couleurs: 
	La palette de couleurs par défaut d'un thème peut être remplacée par n'importe quelle autre palette de couleurs. Pour plus de détails, consultez: [Palettes de couleurs](../Editeurs/2016021.md).






## Ordre d'application des ambiances
<a name="ordre_application_des_ambiances_ELTTEXTE000162"></a>
Le thème d'une page peut être défini à trois niveaux différents (par ordre décroissant de priorité):

- Dans le projet.

- Dans le modèle de pages dont la page hérite des propriétés.

- Dans la page elle-même.




Il faut définir le thème général au niveau du projet. 

Si un ensemble de pages doit utiliser un thème particulier (par exemple les pages de "Promotion" d'un site de vente), il est possible de remplacer le thème du projet: il suffit de le redéfinir au niveau d'un modèle de pages. 

Si une page particulière doit avoir un thème différent, ce thème peut être choisi au niveau de la page elle-même.



## Utilisation des ambiances
<a name="utilisation_des_ambiances_ELTTEXTE000186"></a>


### Choisir le thème d'un projet
<a name="choisir_theme_projet_ELTPARAGRAPHE000055"></a>

Pour choisir le thème d'un projet:

1. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

2. Sélectionnez l'onglet "Thème Styles".

3. Choisissez un thème parmi ceux proposés (et sa palette de couleurs) et validez. 





### Changer le thème d'un modèle de pages ou d'une page
<a name="changer_theme_modele_pages_une_page_ELTPARAGRAPHE000076"></a>

Pour changer le thème d'un modèle de pages ou d'une page:

1. Dans le menu contextuel de la page, choisissez l'option de menu "Description".

2. Sélectionnez l'onglet "Style".

3. Cliquez sur le bouton de parcours pour sélectionner un thème.

4. Si le thème sélectionné est "Aucun", le thème utilisé sera celui du projet.






## Mise à jour des ambiances
<a name="mise_jour_des_ambiances_ELTTEXTE000216"></a>
Si un thème utilisé par un projet a été mis à jour, c'est-à-dire modifié, lors de l'ouverture de ce projet, WEBDEV propose la mise à jour du projet. 

Il n'est bien sûr pas obligatoire de sélectionner cette nouvelle version du thème, le thème précédent étant directement stocké dans chaque projet.
