
## Environnement de l'éditeur de schémas des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
L'environnement de l'éditeur de schémas des données est le suivant : <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=EnvEditeurAnalyses.gif&type=thumb)


Les éléments importants de l'éditeur de schémas des données de WINDEV sont les suivants :


|   |   |
| --- | --- |
| ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=CERCLE1.gif) | **Menu de l'éditeur**<br>Permet un accès rapide aux principales fonctionnalités de l'éditeur de schémas des données. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle2.gif)<br> | **Graphe du schéma des données**<br>Des ascenseurs permettent de faire défiler les éléments du graphe (schéma des données contenant beaucoup de tables). Il est également possible de zoomer sur le graphe pour visualiser plus précisément les éléments du schéma des données (Ctrl + roulette de souris). |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle3.gif)<br> | **[Volet Schéma des données](../Editeurs/2027012.md)**<br>Liste les différentes tables présentes dans le schéma des données en cours. Il suffit de dérouler le nom de la table pour voir les noms et les types de rubriques présentes dans la table. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle4.gif)<br> | **Fenêtre de description des tables**<br>Permet de :<br><br>- visualiser et/ou de modifier les caractéristiques d'une table du schéma des données.<br><br>- accéder à la fenêtre de description des rubriques de la table.<br><br><br> |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle5.gif)<br> | **[Documents ouverts](../Editeurs/2029012.md)**<br>Affiche un bouton pour chaque document ouvert sous l'éditeur. Pour afficher l'élément voulu au premier plan, il suffit de cliquer sur le "bouton" correspondant. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle6.gif)<br> | **Fenêtre du navigateur**<br>Permet de visualiser l'ensemble des éléments contenus dans le dossier ouvert. |
| <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Cercle7.gif)<br> | **Visualisation des rubriques**<br>Permet de visualiser l'ensemble des rubriques de la table en cours. |
