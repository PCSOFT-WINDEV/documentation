


## Gestion des versions du schéma des données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000202"></a>
WINDEV, WEBDEV et WINDEV Mobile permettent de gérer les différentes versions du schéma des données directement depuis l'éditeur de schémas des données.

Pour ouvrir le schéma des données lié au projet, cliquez sur ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Analyse_bl.gif) parmi les boutons d'accès rapide.

La gestion des versions du schéma des données peut être effectuée depuis l'éditeur de schémas des données : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Gestion des versions". Chaque version du schéma des données correspond à une génération du schéma des données.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=GestionVersionAnalyse.gif&type=thumb)
Il est alors possible de travailler :

- Soit sur la version actuelle du schéma des données.

- Soit sur une version antérieure du schéma des données.




**Remarque** : Lorsque un schéma des données est endommagé, il est possible :

- Soit de réparer le schéma des données : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Maintenance" et sélectionnez "Réparer le schéma des données". Pour plus de détails, consultez [Réparer un schéma des données](../Editeurs/9500110.md).

- Soit de restaurer une version antérieure du schéma des données.

- Soit de récupérer la dernière version enregistrée du schéma des données : sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Dernière version enregistrée".




Toutes les versions du schéma des données sont visualisées sous forme d'un graphique. Le carré jaune indique le numéro de génération du schéma des données et le libellé à droite rappelle la date de la génération.

Des "petits rectangles" sont affichés entre deux versions :

- Un rectangle : peu de modifications ont été effectuées entre les deux versions.

- Plusieurs rectangles : plusieurs modifications ont été effectuées entre les deux versions.




**Pour visualiser le détail des modifications effectuées entre deux versions**, double-cliquez sur la ligne contenant les "petits rectangles" ou cliquez sur le bouton "Modifications".

Les options disponibles dans le gestionnaire de versions du schéma des données sont :

- Restauration d'un schéma des données.

- Annulation de la dernière génération.

- Remettre à 1 le numéro de version.

## Restauration d'un schéma des données
<a name="restauration_schema_des_donnees_ELTTEXTE000226"></a>
Pour restaurer un schéma des données à partir du gestionnaire de versions du schéma des données :

1. Sélectionnez la version à restaurer.

2. Vous pouvez :

	- Soit restaurer la version dans le répertoire spécifié. Un schéma des données indépendant est créé correspondant à la version choisie. Ce schéma des données ne sera pas lié au projet en cours. Cette option est sélectionnée par défaut.

	- Soit écraser le schéma des données en cours. Le schéma des données restauré sera automatiquement lié au projet en cours.




3. Validez. La restauration est effectuée.




**Attention** : Les tables associées à un schéma des données dont le numéro de version est supérieur à la version restaurée ne pourront plus être ouvertes. Il faut alors :

- Soit restaurer des tables correspondant à la version du schéma des données restauré (avec l'outil [WDLog](../WDJournal/3516012.md) par exemple).

- Soit supprimer les tables existantes pour qu'elles soient recréées.

## Annulation de la dernière génération
<a name="annulation_derniere_generation_ELTTEXTE000250"></a>
L'annulation de la dernière génération du schéma des données permet de restaurer le schéma des données dans son état avant la dernière génération. Les modifications effectuées depuis la dernière génération ne sont pas appliquées.

**Pour annuler la dernière génération du schéma des données**, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Annuler la dernière génération".

## Remettre à 1 le numéro de version
<a name="remettre_1_numero_version_ELTTEXTE000274"></a>
Il est possible de remettre le numéro de version de génération du schéma des données à "1". Dans ce cas :

- Le numéro de version de génération du schéma des données est remis à un. Les utilisateurs ne pourront donc pas voir le nombre de générations qui ont été nécessaires pour mettre au point l'application.

- Les versions des différentes générations du schéma des données sont supprimées.
	**Remarque** : Ces versions sont contenues dans les sous-répertoires "ANAxxx", présents dans le sous-répertoire "&lt;NomDuProjet&gt;.ANA" du projet.




Aucune action spécifique n'est réalisée sur les tables : le numéro de version des tables n'est pas modifié.

La remise à 1 du numéro de version du schéma des données peut être faite à tout moment et n'a aucune influence sur les versions du schéma des données diffusées.

**Pour remettre à 1 le numéro de version du schéma des données**, sous le volet "Schéma des données", dans le groupe "Schéma des données", déroulez "Génération" et sélectionnez "Remettre à 1 la version du schéma des données".
