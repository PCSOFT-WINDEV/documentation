
## Changement de comportement entre les versions 2024 et 2025
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000114"></a>
La version 2026 apporte de nombreuses nouveautés. Quelques changements de comportement sont nécessaires pour optimiser le fonctionnement des nouveautés. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Changement de comportement entre la version 2024 et la version 2025
<a name="changement_comportement_entre_version_2024_version_2025_ELTTEXTE000138"></a>


- Suppression de la plateforme UWP. 

- PHP : La version minimale supportée pour le serveur PHP est désormais PHP 7 (Version minimale conseillée : version 7.0.22). 

- Champ Editeur d'images (WEBDEV) : Pour créer le champ Editeur d'image, le menu à utiliser est désormais le suivant : Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Avancé" puis cliquez sur "Editeur d'images". 

- Les "Champs Favoris" ont été renommés en "Champs Prédéfinis". 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Décodage des codes-barres : 

	- Jusqu'à version 2025, le décodage de codes-barres utilise la librairie Zxing ([http://code.google.com/p/zxing](http://code.google.com/p/zxing)). 

	- A partir de la version 2025 Update 1, le décodage de codes-barres utilise l'API de lecture de codes-barres de ML Kit.




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Version minimale supportée : 

	- Jusqu' à version 2025, la version minimale nécessaire pour exécuter l'application était Android 6.0. 

	- A partir de la version 2025 Update 1, cette version minimale correspond désormais à Android 7.0.




- **A partir de WINDEV Suite 2025 Update 1 (version Abonnement)**, il est possible d'utiliser les nouveautés spécifiques à l'abonnement dans des projets en mode Abonnement. Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](../Editeurs/1410087359.md).

- **A partir de la version 2025 Update 2**, les fonctions [CarteChangeStyle](../WDLang3/1000025556.md) et [CarteRécupèreStyle](../WDLang3/1000025557.md) sont dépréciées. Pour gérer les styles d'un champ Carte, il est nécessaire d'utiliser la nouvelle fonction [CarteIdentifiantGgl](../WDLang3/1410091136.md). 

- **Manipulation d'un groupe de champs dans un volet dynamique (détachable)**

	- Avant la version 2025 Update 2, la manipulation d'un groupe de champs depuis une fenêtre interne d'un onglet affectait également tous les groupes de champs de même nom présents dans la fenêtre affichant l'onglet, ou dans les autres onglets dynamiques. 

	- A partir de la version 2025 Update 2, la manipulation d'un groupe de champs depuis la fenêtre interne d'un onglet dynamique affecte uniquement la fenêtre interne en cours. Si d'autres groupes de champs de même nom sont présents dans la fenêtre principale, ces groupes de champs ne seront pas modifiés. 




- **A partir de la version 2025 Update 3**, la génération Java Web Start n'est plus supportée.
