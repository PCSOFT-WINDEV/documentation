## Nouveautés de la version 2026
<a name="nouveautes_version_docparamversioncom_9667cb524fbb45f198f3c77e727e423b"></a>
Liste des nouveautés classées par thème: 




|   |
| --- |
| **Environnement** |




- Intégration de l'IA dans votre environnement : 

	- Posez des questions à votre AGL : il vous répond grâce à l'IA.

	- Demandez à l'IA d'effectuer des actions dans vos projets. 

	- Posez des questions sur votre projet, l'IA y répond. 

	- Utilisez le chat pour communiquer avec l'IA. 

	- Choisissez le modèle d'IA de votre choix : Claude, Mistral, Chatgpt, Gemini, ...

	- Les conversations sont conservées : vous pouvez y revenir.

	- Undo général sur le projet disponible.







- Utilisation de la technologie Direct2D dans l'environnement. 

- Modifieur : Nouvelles options. 

- Configuration de l'environnement synthétisée. 

- Outils de l'environnement livrés en 64 bits.






|   |
| --- |
| **Editeur de projet** |






- Nouvel audit disponible : Audit de sécurité. 

- Composants internes :

	- Tableau de bord du projet : Le widget composant affiche des informations sur les composants internes. 

	- Possibilité de renommer un composant interne. 




- Fenêtre d'accueil : 

	- La date de dernière ouverture des projets est affichée.









- **Palettes WINDEV Mobile**

	- Editeur de palettes. 

		- Création assistée de palettes. 

		- Modification de palettes existantes. 

		- Visualisation du rendu.




- Nouvelles palettes de couleurs. 

- Palettes sombres associées aux palettes claires.

| **Editeur de fenêtres** |




- **Nouveau champ**

	- Champ Grille : Utilisez une grille de positionnement relatif dans vos UI.







- **Champs Métier WINDEV Mobile : Nouveaux champs** 

	- Nouvelle présentation des Champs Métier.

	- Nouveaux Champs Métier : 

		- Boutons segmentés. 

		- Zone répétée Produit. 

		- Zone répétée Evénement. 

		- Saisie à jeton avec assistance.







- **Améliorations des champs (WINDEV Mobile)**

	- Champ Carte : 

		- Utilisation de OpenStreetMap

		- Utilisation de nombreux formats de cartes géographiques

		- Possibilité de cumuler les calques sur une même carte




- Champ Jauge circulaire : 

	- Nombreux paramètres supplémentaires. 




- **Fonctionnalités de l'éditeur de fenêtres**

	- Hot Reload : Testez vos modification en temps réel, sans arrêter le test.

	- Edit and continue.   







- **Nouvelles erreurs d'UI**

	- Erreur d'UI si le contenu d'une combo est vide dans une des langues associées au projet.

- Editeur :

	- Edition de fichiers de code au format texte : CSS, HTML, JSON, ...

	- Recherche sémantique dans le code. 

	- Bulle d'aide sur les procédures et variables des WebServices. 

	- Numérotation : Visualisation de la ligne de code en cours. 

	- Tri des méthodes et procédures. 

	- Assistant de génération des expressions régulières. 

	- Norme de programmation : signalement des mélanges de vocabulaire. 

	- Copie de code WLangage vers un logiciel tiers : format texte et format HTML

- Etat Planning : Semaines affichées au format ISO 8601

- Images : Prise en compte des infos EXIF. 

- Champ Sélecteur.

- Log des erreurs. 

- Sauvegarde de la base en un seul fichier. 

- Avertissement en cas d'utilisation d'une base du GDS en version obsolète. 

- Branche : Support des patchs d'exécutable. 

- Connexion à des bases GDS différentes.

| **Outils** |




- Audit statique : 

	- Détection des chaînes de caractères multilingues en format inadapté (format historique)







- Audit de sécurité : 

	- Audit statique de sécurité. 

	- Audit dynamique de sécurité. 







- Robot de surveillance :

	- Surveillance par SSH. 

	- Surveillance de serveur HFSQL sur un réseau local (LAN)

	- Robot en anglais et espagnol.

- Graphique d'avancement des sprints. 

- Centre de Gestion de projets livré en 64 bits. 

- Sélection multiple dans la liste des incidents. 

- Filtre multi-sprint dans la liste des tâches et des incidents.

| **Groupware utilisateur** |




- Utilisation d'un token OAuth pour l'authentification.

| --- |
| **Programmation et WLangage** |




- **Composant interne** : Factur-X

	- Un composant interne Factur-X est disponible pour la génération des factures électroniques. 

	- Gestion des différents profils. 

	- Génération du XML

	- Assistance au choix des unités. 

	- Insertion du logo Factur-X.







- **Webservices GraphQL** : Nouveau type RequêteGraphQL. 




- **Gestion des flux de données par bloc (Chunk)** : 

	- Variable de type HTTPRequête : Nouvelle propriété ProcédureDonnées. 

	- Nouvelle fonction WebserviceEnvoieMorceau. 







- **Fonctions email** : nouvelles fonctions pour gérer des cas particuliers : 

	- emailExécuteCommande 

	- emailAbonneAuDossier

	- emailDesabonneDuDossier









- **OAuth**

	- Connexion à un serveur OAuth nécessitant un certificat. 

	- Support des assertions JWT. 

	- Authentification de type "Client Secret Basic". 







- **OpenID**

	- Connexion à un serveur nécessitant un certificat. 

	- Authentification de type "Client Secret Basic". 







- **Fonctions FTP**

	- Nouvelle variable de type **ftpConnexion** utilisable par toutes les fonctions FTP. 







- **Fonctions SSH**

	- 2 nouvelles fonctions : **SSHConnecteCommande** et **SSHDéconnecteCommande**. 







- Opérateur = sur tableau.






- Fenêtre de trace sur le téléphone




- **Procédure réactive** 

	- Code unique et regroupé.

	- Déclaration et options.

	- Surveillance des variables locales. 

	- Surveillance des champs. 

	- Utilisation en cascade. 

	- Savoir qu'un champ est surveillé ou modifié par une procédure réactive.  

	- Déclarer manuellement une variable à observer. 







- **Barre de navigation des fenêtres** : possibilité de modifier les images des boutons. 

	- Le propriété Visible rend les boutons visibles. 

	- La propriété Image permet de modifier l'image associée au bouton. 







- Validation automatique d'une fenêtre coulissante lors du repli. 




- **Gestion des archives** : 

	- Amélioration des performances de compression des archives au format ZIP de 30%

	- Amélioration des performances de compression des archives au format 7z de 90% 







- **Gestion des PDF**

	- Informations de protection des fichiers PDF : 

		- La propriété **Protection** permet de récupérer les informations de protection d'un fichier PDF. 

		- Les fonctions **PDFMotDePasse** et **iParamètrePDF** permettent de définir des nouvelles options de protection pour les fichiers PDF.









- **POO (Programmation Orientée Objet)**

	- Attribut Zombie sur les classes.









- Nouvelles fonctions, propriétés et nouveaux types.

	- Nouvelles fonctions

	- Nouveaux types
