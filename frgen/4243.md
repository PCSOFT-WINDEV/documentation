## Erreur ERR_LAUNCH_FAILED
<a name="erreur_errlaunchfailed_ELTTEXTE000062"></a>


### Erreur au lancement du site 
<a name="erreur_lancement_site_ELTPARAGRAPHE000007"></a>

Le site dynamique ne peut pas se lancer car il est automatiquement fermé.
Vérifiez que vous n'utilisez pas la fonction **FinProgramme** dans le code d'initialisation du projet, ou toute autre fonction ou traitement arrêtant votre site.
