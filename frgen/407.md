
## Administrateur WEBDEV distant : Paramètres d'un site WEBDEV en mode Session ou d'un Webservice
			



## Paramétrage des sites en mode Session et des Webservices
<a name="parametrage_des_sites_mode_session_des_webservices_ELTTEXTE000147"></a>
Pour visualiser les paramètres d'un site WEBDEV en mode Session ou d'un Webservice spécifique depuis l'administrateur distant :

1. Dans la barre de menu, sélectionnez "Sites" ou "Webservices". 

2. La liste des éléments présents sur le Serveur d'Application WEBDEV est alors affichée.

3. Sélectionnez le site ou le Webservice à configurer. 

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003.gif)


**Remarque** : Le responsable du Serveur d'Application peut configurer tous les sites et Webservices, les utilisateurs ne peuvent configurer que les sites et les Webservices qui leur appartiennent.


### Paramètres disponibles
<a name="parametres_disponibles_ELTPARAGRAPHE000018"></a>Les caractéristiques du site sont regroupées en plusieurs thèmes : 

- Caractéristiques générales, 

- Sécurité

- Paramètres SaaS

- Localisation des fichiers du groupware utilisateur




**1. Paramètres généraux**

Le site peut être **Bloqué pour maintenance** : Lorsque un site est mis dans cet état, le Serveur d'Application refuse les nouvelles connexions et interrompt les connexions en cours.

Pour les options suivantes, "Général" indique que le paramètre correspond à la valeur sélectionnée dans l'option de menu "Configuration", "Spécifique" permet de personnaliser le paramètre. Il est possible de personnaliser : 

- la durée d'inactivité autorisée, 

- la durée des contextes AWP,

- la durée maximale d'une tâche,

- le nombre de connexions autorisé, 

- le nombre maximum de connexions autorisées pour le même utilisateur,

- le nombre maximum de sessions prélancées.




Il est également possible de demander la génération d'un fichier journal spécifique. 

**2. Sécurité**

Ces options de sécurité sont définies au niveau du serveur dans l'option de menu "Configuration" de l'administrateur WEBDEV distant. Ces options peuvent être personnalisées. 

**3. Paramètres SAAS**

Il est possible de préciser l'URL du webservice SaaS à utiliser. Ce paramètre correspond : 

- soit au nom de l'hôte du webservice SaaS (par exemple "Machine", "Machine.MonReseau.fr" , "http://Mondomaine.com").

- soit à l'URL complète du webservice SaaS (par exemple "http://domaine.com/WDSAAS310_WEB/WDSaaS310.awws").




**4. Localisation des fichiers du groupware utilisateur**

Si le site utilise le groupware utilisateur : 

- version 18 et supérieur : indiquez uniquement le répertoire de localisation du fichier des droits.

- version compatible : indiquez le répertoire de localisation du fichier des droits et des utilisateurs. 




**5. Icônes pour une configuration spécifique**

Différentes icônes permettent également d'effectuer une configuration spécifique : 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%202.gif) permet de lister et de gérer les tâches planifiées. En cliquant sur ce bouton, la liste des tâches planifiées apparaît. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0005.gif)
 Il est possible de : 

	- Exécuter directement une tâche planifiée, 

	- Modifier la planification d'une tâche planifiée, 

	- Supprimer une tâche planifiée. Cette tâche planifiée sera supprimée jusqu'au redémarrage du serveur ou au prochain déploiement du site. 

	- Rafraîchir la liste. 




- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%203.gif) permet d'accéder au répertoire du site. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%204.gif) permet d'accéder au répertoire des données. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%205.gif) permet d'accéder aux statistiques. 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%206.gif) permet de [gérer les sauvegardes du site](../WDAdminWeb/205.md). 

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%201.gif) permet de [personnaliser les messages d'erreur pour un site donné](../WDAdminWeb/306.md).

- ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=Admin_WebDev_distant%20-%20HC%20N%B0003%207.gif) permet de supprimer un site.
