## Erreur ERR_MSG_BOX
<a name="erreur_errmsgbox_ELTTEXTE000063"></a>
Le site a généré le message d'erreur suivant :... ERR_MSG_BOX (25)

Une boîte de messages a été affichée sur le serveur bloquant l'utilisation du site. WEBDEV ferme automatiquement la boite de messages, et le message correspondant est affiché dans le navigateur.
Corrigez le site dynamique WEBDEV en fonction du message d'erreur affiché. Le plus souvent, l'erreur correspond à une erreur de programmation présente dans le site WEBDEV.
