


## WDMap: Présentation
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000190"></a>
WDMap est un utilitaire permettant de visualiser et de manipuler une table lors du développement d'une application. **Cet utilitaire est disponible uniquement en 32 bits.** 

WDMap peut être utilisé par exemple pour:

- Vérifier rapidement le contenu d'un enregistrement.

- Tester rapidement une application avec des données réalistes.




La table manipulée peut être:

- au format HFSQL (Classic ou Client/Serveur). 

- au format Hyper File 5.5

- accédé via un provider OLE DB, un driver ODBC ou un accès natif. 


Il est également possible de manipuler un alias d'une table HFSQL.

**Important**: L'utilitaire WDMap est disponible uniquement en 32 bits. Si WINDEV, WEBDEV ou WINDEV Mobile sont installés en 64 bits, WDMap est toujours exécuté en 32 bits. Lors d'un accès via un provider OLE DB, un driver ODBC ou un Connecteur Natif, il est nécessaire d'utiliser une des méthodes suivantes: 

- avoir un client 32 bits pour la base de données, 

- utiliser le [Centre de Contrôle HFSQL](../CCHF/3540001.md).

## Lancement de WDMap
<a name="lancement_wdmap_ELTTEXTE000214"></a>


### Lancement de WDMap
<a name="lancement_wdmap_ELTPARAGRAPHE000039"></a>

WDMap peut être lancé:

- depuis l'éditeur de schémas des données: sous le volet "Schéma des données", dans le groupe "Table", cliquez "Éditer avec WDMap",

- depuis le ruban: sous le volet "Outils", dans le groupe "Base de données", cliquez sur "WDMap",

- en lançant directement le programme "WDMAP.EXE".




**Remarque**: Si WDMap est lancé depuis l'éditeur de schémas des données:

- La table physique correspondant à la description de la table sélectionnée sera créée si nécessaire.

- Pour prendre en compte toutes les modifications effectuées sur la description de la table, il est conseillé de générer le schéma des données avant de visualiser le contenu de la table.



<a name="NOTE2_2"></a>


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000079"></a>

WDMap est un outil non redistribuable. WDMap ne peut pas être installé avec les applications développées avec WINDEV ou WEBDEV.

Pour utiliser WDMap , WINDEV, WEBDEV ou WINDEV Mobile doit obligatoirement être installé sur le poste en cours.

## Notes
<a name="notes_ELTTEXTE000268"></a>


- WDMap permet de visualiser une seule table à la fois.

- Si le schéma des données est protégé par un mot de passe (mot de passe en exécution défini dans la description du schéma des données), ce mot de passe sera demandé lors de la sélection du schéma des données sous WDMap.

- Si la table est protégée par un mot de passe (mot de passe défini soit à l'aide des fonctions [HPasse](../WDLang4/3044108.md), [HCrée](../WDLang4/3044255.md) ou [HCréeSiInexistant](../WDLang4/3044254.md), soit lors de la [modification automatique des données](../WDLang4/3044195.md)), ce mot de passe sera demandé lors de la sélection de la table physique sous WDMap.

- Il est possible de visualiser les données d'une table HFSQL Client/Serveur: par exemple, si les tables du schéma des données sont définies comme étant en Client/Serveur, avec une connexion, l'option "Editer la table avec WDMAPEditer la table avec WDMAP" ouvre la table du serveur selon la connexion définie.
