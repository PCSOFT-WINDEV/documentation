


## WDMap: Caractéristiques des fichiers de donnés d'une base de données
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000274"></a>
WDMap permet d'obtenir diverses caractéristiques spécifiques:

- à chaque table présente dans une base de données manipulée par un projet WINDEV, WEBDEV ou WINDEV Mobile,

- à l'ensemble des tables présentes dans une base de données manipulée par un projet WINDEV, WEBDEV ou WINDEV Mobile.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire?
<a name="comment_faire_ELTTEXTE000298"></a>


### WDMap lancé depuis l'éditeur
<a name="wdmap_lance_depuis_editeur_ELTPARAGRAPHE000021"></a>

Pour obtenir des informations sur les tables d'une base de données:

1. Sous WDMap, sélectionnez le schéma des données WINDEV, WEBDEV ou WINDEV Mobile (table ".WDD") contenant la description de la table voulue (utilisez si nécessaire le bouton "Parcourir").

2. Précisez si nécessaire le mot de passe du schéma des données (mot de passe en exécution défini dans la description du schéma des données).

3. Sélectionnez l'option "Affichage .. Informations générales sur la base de données" (ou cliquez sur l'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=WDMap_caract_fichier%20-%20HC%20N%B0001%201.gif)). La fenêtre des caractéristiques de la base de données s'affiche.



<a name="NOTE2_2"></a>


### WDMAP lancé directement par le programme "WDMAP.EXE"
<a name="wdmap_lance_directement_par_programme_wdmapexe_ELTPARAGRAPHE000034"></a>

Pour obtenir des informations sur les tables d'une base de données:

1. Dans l'assistant, sélectionnez l'option "Sélectionnez un schéma des données" et passez à l'étape suivante.

2. Sélectionnez le schéma des données WINDEV, WEBDEV ou WINDEV Mobile (fichier ".WDD") contenant la description de la table voulue (utilisez si nécessaire le bouton "Parcourir") et passez à l'étape suivante. WDMap se lance.

3. Précisez si nécessaire le mot de passe du schéma des données (mot de passe en exécution défini dans la description du schéma des données).

4. Sélectionnez l'option "Affichage .. Informations générales sur la base de données" (ou cliquez sur l'icône ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=WDMap_caract_fichier%20-%20HC%20N%B0001%201.gif)). La fenêtre des caractéristiques de la base de données s'affiche.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Quelles sont les caractéristiques affichées?
<a name="quelles_sont_les_caracteristiques_affichees_ELTTEXTE000328"></a>
Une base de données manipulée par un projet WINDEV, WEBDEV ou WINDEV Mobile peut être composée aussi bien de tables de type HFSQL que de tables de type non HFSQL.

La fenêtre contenant les caractéristiques est divisée en deux:

- La partie haute contient les caractéristiques spécifiques aux tables de type HFSQL.

- La partie basse contient les caractéristiques spécifiques aux autres types de tables (format non HFSQL) accédées via un provider OLE DB, un driver ODBC ou un accès natif.




**Remarque**: Si la base de données en cours est composée uniquement de tables HFSQL, seule la partie haute sera affichée. Si la base de données en cours est composée uniquement de tables non HFSQL, seule la partie basse sera affichée.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=213&name=WDMap_caract_fichier%20-%20HC%20N%B0002.gif)

<a name="NOTE3_2"></a>


### Caractéristiques spécifiques aux tables de type HFSQL
<a name="caracteristiques_specifiques_aux_tables_type_hfsql_ELTPARAGRAPHE000063"></a>

Le tableau suivant présente les caractéristiques affichées par WDMap. Ces caractéristiques sont spécifiques aux tables de type HFSQL présentes dans la base de données du projet WINDEV, WEBDEV ou WINDEV Mobile:

| Nom | Commentaire |
| --- | --- |
| Nom logique | Nom de la table défini dans le schéma des données. |
| Nom physique | Nom du fichier physique associé au fichier logique. Ce nom est défini dans le schéma des données. |
| Type | HFSQL Classic ou Hyper File 5.5. |
| Taille totale | Taille actuelle (en Ko) de la table, du fichier d'index et du fichier mémo correspondant à la table logique. |
| Nombre d'enregistrements actifs | Un enregistrement actif est un enregistrement pouvant être manipulé directement (avec la fonction [HLit](../WDLang4/3044047.md) par exemple). |
| Nombre d'enregistrements rayés | Un enregistrement rayé est un enregistrement supprimé logiquement (avec la fonction [HRaye](../WDLang4/3044121.md)). Cet enregistrement pourra éventuellement être récupéré (grâce aux fonctions [HModifie](../WDLang4/3044042.md) ou [HEcrit](../WDLang4/3044092.md)). Cet enregistrement peut être supprimé physiquement (avec la fonction [HSupprime](../WDLang4/3044018.md)). |
| Nombre d'enregistrements supprimés | Un enregistrement supprimé est un enregistrement supprimé logiquement et physiquement (avec la fonction [HSupprime](../WDLang4/3044018.md)). |
| Nombre d'enregistrements total | Nombre d'enregistrements actifs, rayés et supprimés dans la table. |
| Mot de passe | Mot de passe de la table défini soit à l'aide des fonctions [HPasse](../WDLang4/3044108.md), [HCrée](../WDLang4/3044255.md) ou [HCréeSiInexistant](../WDLang4/3044254.md), soit lors de la [modification automatique des données](../WDLang4/3044195.md). |
| Cryptage | Indique si la table est cryptée. |
| Journal | Indique si la table est journalée.<br>[Le journal](../WDLang4/3044184.md) est une table particulière dans laquelle sont automatiquement mémorisées toutes les opérations réalisées sur une ou plusieurs tables depuis un moment donné. |
| Réplication | Indique si la table est répliquée.<br>[La réplication](../WDLang4/3044266.md) est l'opération permettant de maintenir à jour des bases de données distantes de structures identiques, et sur lesquelles des opérations différentes sont effectuées. |
| **Informations supplémentaires liées à la table physique lors d'un double-clic sur une table de type HFSQL** |
| Répertoire du fichier | Répertoire du fichier physique. |
| Date de la dernière modification |   |
| Chemin du schéma des données 5.5 | Uniquement si la table sélectionnée provient d'un schéma des données 5.5. |
| Répertoire du journal | Répertoire du fichier journal associé à la table sélectionnée (si le fichier journal existe). |
| Taille du fichier journal | Taille actuelle du fichier journal en Ko (si le fichier journal existe). |


Pour l'ensemble des tables de type HFSQL présentes dans la base de données, les calculs suivants sont automatiquement effectués:

- La taille totale (en Ko) de l'ensemble des tables.

- La taille totale (en Ko) des fichiers journal associés aux tables.

- Le nombre d'enregistrements présents dans l'ensemble des tables.



<a name="NOTE3_3"></a>


### Caractéristiques spécifiques aux autres types de tables (format non HFSQL)
<a name="caracteristiques_specifiques_aux_autres_types_tables_format_non_hfsql_ELTPARAGRAPHE000188"></a>

Le tableau suivant présente les caractéristiques affichées par WDMap. Ces caractéristiques sont spécifiques aux tables de type non HFSQL présentes dans la base de données du projet WINDEV, WEBDEV ou WINDEV Mobile:

| Nom | Commentaire |
| --- | --- |
| Fichier | Nom logique de la table. |
| Libellé | Libellé de la connexion utilisée pour accéder aux différentes tables présentes dans le schéma des données en cours (spécifié lors du paramétrage de la connexion sous l'éditeur de schémas des données). |
| Connexion par | Mode d'accès à la base de données en cours: provider OLE DB, driver ODBC ou accès natif. |
| Source de données | Source de données de la connexion:<br><br>- soit nom et chemin complet de la base de données,<br><br>- soit répertoire du fichier xBase,<br><br>- soit nom ou alias du serveur utilisé.<br><br><br> |
| Utilisateur | Nom d'utilisateur nécessaire pour se connecter à la base de données. |
| Accès | Type d'accès à la table: lecture seule ou lecture et écriture. |
| Nombre d'enregistrements | Nombre d'enregistrements dans la table. |
