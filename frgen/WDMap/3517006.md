


## WDMap : Réindexer une table HFSQL
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000120"></a>
WDMap permet à la fois de savoir si une table HFSQL doit être réindexée et à la fois de réindexer une table HFSQL.

Deux types de réindexation sont possibles :

- ***Réindexation normale*** : Réindexation classique (avec statistiques et sans compactage).

- ***Réindexation avec compactage*** : Réindexation avec compactage (ne conserve que les enregistrements actifs. Tous les enregistrements rayés ou supprimés sont définitivement supprimés).




**Rappel** :

- La réindexation ré-organise les index. Après réindexation, l'accès aux index est optimal. La réindexation peut être rendue nécessaire par la perte ou l'altération du fichier d'index.

- WDMap permet de réindexer simplement une table. Cependant, pour réindexer une table de façon plus complète, utilisez l'outil [WDOptimizer](../WDOptimiseur/3519002.md).

- Il est également possible de réindexer une table depuis l'explorateur de Windows. Il suffit de sélectionner l'option "Optimiser" du menu contextuel de la table à réindexer. La réindexation est alors effectuée grâce à l'outil [WDOptimizer](../WDOptimiseur/3519002.md).

## Comment le faire ?
<a name="comment_faire_ELTTEXTE000144"></a>


### WDMap lancé depuis l'éditeur
<a name="wdmap_lance_depuis_editeur_ELTPARAGRAPHE000035"></a>

Pour réindexer une table :

1. Affichez la table à réindexer (pour plus de détails, consultez [Visualiser les enregistrements présents dans une table](../WDMap/3517012.md)).

2. Pour réaliser :

	- une ***réindexation normale*** : sélectionnez l'option "Outils .. Réindexation .. Normale".

	- une ***réindexation avec compactage*** : sélectionnez l'option "Outils .. Réindexation .. Avec compactage".






<a name="NOTE2_2"></a>


### WDMap lancé par le programme "WDMAP.EXE"
<a name="wdmap_lance_par_programme_wdmapexe_ELTPARAGRAPHE000051"></a>

Pour réindexer une table :

1. Dans l'assistant, sélectionnez l'option "Réindexer un fichier" et passez à l'étape suivante.

2. Sélectionnez la table à réindexer et validez.




Remarques :

- Si la table est protégée par un mot de passe (mot de passe défini soit à l'aide des fonctions [HPasse](../WDLang4/3044108.md), [HCrée](../WDLang4/3044255.md) ou [HCréeSiInexistant](../WDLang4/3044254.md), soit lors de la [modification automatique des données](../WDLang4/3044195.md)), précisez ce mot de passe.

- Si la table provient d'un schéma des données 5.5, précisez le chemin complet du schéma des données d'origine et le mot de passe de ce schéma des données.
