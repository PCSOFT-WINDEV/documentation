
## WDStatistics: WEBDEV administrator configuration
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000110"></a>
To create the log files required to calculate the statistics for site traffic, a specific setting must be performed in the WEBDEV administrator.

This setting can be performed:

- from the remote WEBDEV administrator, accessible from the current computer (recommended).

- from the WEBDEV administrator installed at your hosting provider (supplied with the WEBDEV Application Server).




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Configuring the remote WEBDEV administrator
<a name="configuring_the_remote_webdev_administrator_ELTTEXTE000134"></a>
To create the log files for each one of the dynamic WEBDEV websites installed on the Web server: 

1. Display the main page of the remote WEBDEV administrator.
	Reminder: The remote WEBDEV administrator can be launched from any computer with an Internet browser.. To do so, use the following address: 
	
	```txt
	http://<ServeurWeb>/WDAdminWeb
	```


2. Select the desired WEBDEV website.

3. Check "Generate the log file".

4. Specify the directory where the log files must be created.




**Remark**: Remote WEBDEV administrator does not allow you to configure the creation of a common log file for all dynamic WEBDEV sites installed on the Web server.

<a name="NOTE3_1"></a>


## Configuring the WEBDEV administrator (WEBDEV Application Server)
<a name="configuring_the_webdev_administrator_webdev_application_server_ELTTEXTE000158"></a>


### Creating the log files for each one of the dynamic WEBDEV websites installed on the Web server
<a name="creating_the_log_files_for_each_one_the_dynamic_webdev_websites_installed_the_web_server_ELTPARAGRAPHE000041"></a>

To create the log files for each one of the dynamic WEBDEV websites installed on the Web server: 

1. Go to the "Sites" tab of the WEBDEV administrator (version used on the application server).

2. Select the desired WEBDEV website.

3. Check "Custom parameters".

4. Check "Generate a log file specific to this site for the traffic statistics (.log)".

5. Specify the directory where the log files must be created.

6. Click the "Apply" button.

7. Follow the same steps for each one of your sites (if necessary).



<a name="NOTE3_2"></a>


### Creating the common log files for all the dynamic WEBDEV websites installed on the Web server
<a name="creating_the_common_log_files_for_all_the_dynamic_webdev_websites_installed_the_web_server_ELTPARAGRAPHE000056"></a>

To create the common log files for all the dynamic WEBDEV websites installed on the Web server: 

1. Go to the "Configuration" tab of the WEBDEV administrator (version used with the application server).

2. Check "Generate a log file for the traffic statistics (.log)".

3. Specify the directory where the log files must be created.

4. Click the "Apply" button.
