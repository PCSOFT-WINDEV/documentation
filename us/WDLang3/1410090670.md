
## Parameters of the procedure used by NearbyShareSendFile



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareSendFile](../WDLang3/1410090654.md) to notify whether or not the data was sent successfully.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareSendFile(garrSelectedDevices, sResourcePath, CallbackSend)
```



```wl
PROCEDURE CallbackSend(bResult is boolean, nTransferID is int)
IF bResult THEN
	ToastDisplay("File sent")
ELSE
	ToastDisplay(ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareSendFile_Callback(<Result> , <Identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the data was sent, 

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error. 




**`<Identifier>: (Integer)`**

Transfer ID.
