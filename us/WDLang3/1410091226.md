
## zipExeCreationParameter (Variable type)

***In french: zipExeCreationParameter***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **zipExeCreationParameter** type is used to define all the information needed to create a self-extracting  archive (.EXE file). This information can be defined and changed using different WLanguage properties. 

This variable type must be passed as a parameter to [zipCreateExe](../WDLang3/3082013.md).

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Archive to be transformed into a self-extracting archive
Archive is zipArchive

// Open the archive
IF zipOpen(MyArchive, "D:\Backups\Backup.zip") = 0 THEN
	// Self-extracting archive creation parameters
	ParamExe is zipExeCreationParameter
	ParamExe.ExeFilePath = "C:\Directories\Archive.exe"
	ParamExe.DirectoryOption = zipCurrentDirectory
	ParamExe.Icon = "Icon.ico"
	// Create a self-extracting archive
	zipCreateExe(MyArchive, ParaExe)
	...
END
```

## Properties


### Properties specific to zipExeCreationParameter variables
<a name="properties_specific_zipexecreationparameter_variables_ELTPARAGRAPHE000037"></a>

The following properties can be used to define the creation parameters of a self-extracting archive:

| Property name | Type used | Effect |
| --- | --- | --- |
| WithUI | Boolean | <br><br>- <u><u><u>True</u></u></u> to open a dialog box. This will allow users to select the extraction directory,<br><br>- <u><u><u>False</u></u></u> (default) if no dialog box is to be displayed.<br><br><br> |
| DirectoryOption | Integer constant | Extraction directory options:<br><br>- *zipCurrentDirectory*: All files in the archive will be extracted to the current directory.<br><br>- *zipDefaultDir*: Uses the default directory (**ExtractionDirectory** property).<br><br>- *zipTempDirectory* (default): The archive files will be extracted to the temporary directory of the computer where the executable is run. All the archive files are extracted to the same location.<br><br><br> |
| Exe64 | Boolean | Self-extracting executable mode:<br><br>- <u><u><u>True</u></u></u> to create a 64-bit self-extracting executable.<br><br>- <u><u><u>False</u></u></u> (default) to create a 32-bit self-extracting executable.<br><br><br> |
| ExeFilePath | Character string | Path of the executable file to be created (up to 260 characters). This path can be relative to the current directory or a full path.<br>The ".EXE" extension is required. |
| ExtractionDirectory | Character string | Directory suggested by default in the extraction window (if the **WithUI** property is set to <u><u><u>True</u></u></u>). <br><br>Note: If there is no extraction window, this directory will be used by default to extract files from the archive. |
| Icon | Character string | Path of the icon file representing the created executable. This path can be relative to the current path or a full path.<br>If this parameter is not specified, a default icon will be used for the executable. |
| OptionPreserveDirectoryStructure | Boolean | <br><br>- <u><u><u>True</u></u></u> to display the "Preserve tree structure" option in the extraction dialog box,<br><br>- <u><u><u>False</u></u></u> (default value) otherwise. <br><br><br> |
| PreserveDirectoryStructure | Boolean | <br><br>- <u><u><u>True</u></u></u>: The files will be extracted while preserving the archive's directory structure.<br><br>- <u><u><u>False</u></u></u> (default): All the files will be extracted to the same directory.<br><br><br> |
| RunAsAdministrator | Boolean | <br><br>- <u><u><u>True</u></u></u> to run the executable as administrator. This mode avoids file virtualization from Windows Vista.<br><br>- <u><u><u>False</u></u></u> (default value) otherwise. <br><br><br> |
| Translation | Character string | Full path to the INI file containing the translations of the self-extracting archive (see Remarks). <br><br>If this property is set to an empty string (""), the default translation file will be used. |
| Version | Character string | Version number of the new executable. This number must have the following format:<br><pre><code><Major version>.<Minor version>.<br><Compilation number>.<Revision number></code></pre><br>Example "30.12.15.3". <br><br>This version number can then be retrieved using the [ExeInfo](../WDLang1/3035001.md) function with the *exeVersionWindowsFormat* constant.<br><br>If this property is not specified, a default version number will be defined based on the version used to create the self-extracting archive. |

## Remarks


### Translating the self-extractor UI (Translation property)
<a name="translating_the_selfextractor_translation_property_ELTPARAGRAPHE000180"></a>

By default, the self-extractor is available in three languages: English, Spanish and French. The self-extractor will use the language of the executable or the language specified by [Nation](../WDLang1/3054014.md).  

The interface of the self-extractor can use a language other than the default language (English).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=zipcreeExe%20-%20HC%20N%B0001.gif)
To do so, create a .INI file containing the following information:


```txt
[GENERAL]
NATIONDEFAUT=1
[WDAUTOEX01]
R000=Self-extracting PC SOFT archive
R001=Extract the content of the archive in the directory:
R002=Preserve tree structure
R003=Extract
R004=Close
```
For example, to get an interface in French:


```txt
[GENERAL]
NATIONDEFAUT=1
[WDAUTOEX01]
R000=Archive Autoextractible PC SOFT
R001=Extraire le contenu de l'archive dans le repertoire:
R002=Conserver l'arborescence 
R003=Extraire
R004=Fermer
```
**Caution**: The first three lines of this file must not be modified.

In the following lines, specify the desired translation.
