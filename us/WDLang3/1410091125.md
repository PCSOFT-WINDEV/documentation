


## &lt;ftpConnection variable&gt;.Time (Function)

***In french: &lt;Variable ftpConnexion&gt;.Heure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the different creation, modification or access times associated with a file located on an FTP server (File Transfer Protocol).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Returns the modification time of a file located on an FTP server.
<a name="sample_code"></a>

## Example

<a name="Exemple2"></a>

```wl
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Find out the time of modification made to
// "/Documents/File.txt" on the FTP server
ResTime = MyFTPConnection.Time("/Documents/File.txt")
```

<a name="SYNTAXE1"></a>

## Syntax
<a name="SYNTAXE2"></a>

`<Result> = <FTP connection>.Time(<File name> [, <Type of time>])`
---

**`<Result>: (Character string)`**



- Requested time (HHMMSS format). 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only the file modification time is available.

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 

**`<File name>: (Character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/").  
**If this parameter is not specified**, the date returned will be that of the last file accessed using one of the following FTP functions: [&lt;ftpConnection variable&gt;.Date](../WDLang3/1410091120.md), [&lt;ftpConnection variable&gt;.Time](../WDLang3/1410091125.md), [&lt;ftpConnection variable&gt;.Size](../WDLang3/1410091134.md), [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md). In this case, no request is sent to the server. This syntax is recommended.

**`<Type of time>: (Optional constant)`**

Requested time:



|   |   |
| --- | --- |
| *ftpAccess* | Time the file was last accessed. |
| *ftpCreation* | Time the file was created. |
| *ftpModification*<br>(Default value) | Time the file was last modified. |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not available. Only the modification time of the specified file is available.

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000317"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000350"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_4"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000360"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	Example: /ad/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [&lt;ftpConnection variable&gt;.CurrentDir](../WDLang3/1410091131.md).


When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.
