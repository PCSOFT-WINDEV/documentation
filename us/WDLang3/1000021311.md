
## Installing BaaS solutions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000305"></a>
Many WINDEV, WEBDEV and WINDEV Mobile functionalities use a WEBDEV Application Server that uses BaaS solutions:

- [Private Store for WINDEV applications](../Editeurs/9000203.md).

- [Private Store for mobile applications](../Editeurs/1410086652.md).

- [Mobile User Groupware (Android and iOS)](../Editeurs/1410086648.md).

- [User Groupware in BaaS mode](../Editeurs/1000021153.md).

- [Integrated OAuth server](../WDLang3/1410090993.md). 




The BaaS server used by these features can be: 

- a **PCSCloud** development platform (paid turnkey solution). For more details, see [PCSCloud](https://pcscloud.net/UK/cloud_development.awp). 

- a custom server. 




This help page explains the different steps to configure a BaaS server: 

- [Step 1: Installing an HFSQL server](#NOTE2_1). 

- [Step 2: Installing BaaS solutions](#NOTE3_1).

	1. [Installing WEBDEV Application Server](#NOTE3_1). 

	2. [Installing the Reserved WEBDEV Application Server](#NOTE3_2). 







Remarks: 

- A Web server (IIS, Apache or other) must be installed on the computer on which the reserved server will be installed. The web server must be accessible with basic authentication. 

- In the case of mobile applications (Private Store or User Groupware), the web server must: 

	- comply with the HTTPS protocol with a certificate issued by a recognized trust authority for iOS and Android mobile devices,

	- allow a maximum content size of HTTPS responses greater than the size of the installations (IPA & APK).




- BaaS solutions can be installed:

	- via the Reserved WEBDEV Application Server (free). This installation will enable you to use the User Groupware and the Private Store.

	- via the WEBDEV Application Server (paid). This installation will enable you to use the User Groupware, Private Store, oAuth server, etc.




- The HFSQL server and the reserved server can be installed on two different computers. 

- The reserved server can be installed on a Web server that also hosts a WEBDEV Application Server. 

- Caution: The BaaS server is not available in Linux.

## Step 1: Installing the HFSQL server
<a name="step_1_installing_the_hfsql_server_ELTTEXTE000329"></a>
The HFSQL server setup program is available in the WINDEV or WINDEV Mobile installation package. If you do not own this installation package, the HFSQL server setup can also be found in our site ([http://www.windev.com](https://www.windev.com)).

To install the HFSQL server from the WINDEV/WINDEV Mobile installation package:

1. Start the WINDEV/WINDEV Mobile setup program.

2. Select "HFSQL server setup".

3. Then, select "Install or update an HFSQL server".

4. Accept the license agreement.

5. Select a platform ("For Windows on this computer").

6. If there are HFSQL servers already installed on the current computer, select "Install a new server".

7. Select the installation directory and specify the server name and port. The port 4900 will be used by default. 

8. Specify the login credentials of the user with administrator privileges that will be created by default on the HFSQL server. By default, this user is "Admin" and has no password.

9. Install the HFSQL Control Center if it is not already installed or if it is not accessible from your computer. 

10. The wizard prompts you to configure the sending of notifications to identify server problems in real time. Select the desired option. 

11. The wizard allows you to enable the Active Directory authentication. Enable this option if necessary.

12. You can help us improve by allowing us to collect information regarding the use of our products. This optional and anonymous data collection allows PC SOFT to improve its software products.

13. The installation is completed. By default (if you have not changed the administrator settings), to connect to the server in administrator mode, you must use the "Admin" user without password.
	Note: For security reasons, remember to change the administrator password.

## Step 2: Installing BaaS solutions
<a name="step_2_installing_baas_solutions_ELTTEXTE000376"></a>


### Installing WEBDEV Application Server
<a name="installing_webdev_application_server_ELTPARAGRAPHE000080"></a>

To install WEBDEV Application Server:

1. Launch the WEBDEV Application Server installation package.

2. Select a language for the Application Server. 

3. Select "Install full version" and enter the serial number and installation key. 

4. Validate the license. 

5. Specify the WEBDEV Application Server installation directory (C:\\WEBDEV 2026 by default). 

6. Select the Application Server mode: "Stand-alone server". 

7. Specify the directory to be used for deployment ("C:\\Sites" by default). 

8. **If it is the first time you install WEBDEV Application Server**, specify the parameters of the Windows account that will be used as WEBDEV administrator. This account will also be called "Hosting account". 
	You can create a new Windows account or use an existing Windows account. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=P6_Install%20Serveur%2010%20Connexions%20-%20HC%20N%B0003.jpg)

	Select an option and proceed to the next step. 

9. **If a previous version of WEBDEV Application Server has already been installed on the computer**, the wizard allows you to: 

	- manage the websites and web services from earlier versions. Keep the "Keep sites in their current versions" option and proceed to the next step.

	- import WEBDEV accounts. Keep the option "Don't import existing accounts" and proceed to the next step. Enter the login credentials of the Windows account that will be used as WEBDEV administrator. This account will also be called "Hosting account". 
			You can create a new Windows account or use an existing Windows account. 
			Select an option and proceed to the next step. 




10. Specify the remote administration site(s) to be installed:

	- The WEBDEV Application Server remote installation site allows you to remotely manage all deployed sites and web services, WEBDEV accounts and application server configuration. 

	- The HFSQL administration site allows you to remotely manage HFSQL databases. 




11. Indicate whether SaaS site hosting should be taken into account. The SaaS activation automatically installs a website and a web service to manage SaaS websites. For more details, see [SaaS](../WDLang3/9500213.md). 

12. Specify whether the replication server is to be installed. The replication server can be used to perform an assisted universal replication. 

13. Indicate if you want to enable the application telemetry server (WDAnalytics). 

14. Indicate if you want to enable BaaS solutions. These solutions include the User Groupware, an OAuth authentication server and a Private Store. **In this case, these BaaS solutions must be enabled**. 

15. Specify the characteristics of the HFSQL server used for WDBaaS modules (User Groupware/Private Store). 
	Note: This HFSQL server must have been previously installed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0003.gif)
These characteristics are:

	- Name of the HFSQL server, 

	- Port. 

	- Name and password of the HFSQL server administrator. This information is required to automatically configure the WDBaaS database and the associated user. 




16. Test the connection to check your parameters. 

17. Specify the parameters specific to the WDBaaS database used by the User Groupware/Private Store: 

	- name of the dedicated database: WDBAAS by default. 

	- username and password for the database. 




18. Specify the password for the WDBaaS data files (existing or to be created).

19. Specify the password of the WDBaaS site administrator (User: Admin).

20. This database and its user will be automatically created. 

21. Go to the next step.

22. Indicate whether access to third-party databases should be enabled. If this access is enabled, the Application Server will include a specific web service. In this case, you need to specify the web service address. 

23. Specify whether an SSL connection is required for the remote administration sites. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0004.gif)


24. Go to the next step.

25. Indicate whether ODBC drivers for HFSQL are to be installed. 

26. Specify advanced installation settings:

	- Activate the application list page. 

	- Prevent access to directories of other WEBDEV accounts. 

	- Enable NTLM/Kerberos authentication. 

	- Indicate whether idle sessions should be terminated. 




27. The setup summary is displayed. 

28. Go to the next step.   

29. The wizard checks for a web server on the client computer. 

	- If no web server is installed, the wizard prompts the user to install and configure one. 

	- If there is a web server on the computer, the wizard configures it so that you can use WEBDEV Application Server. 




30. At the end of the setup, the wizard displays a summary: 
	
	```txt
	WDBaaS for the User Groupware and the Private Store has been installed.
	WDBaaS server connection token to be provided to the environment development: 
	WDXxxxxxxxxxxxxxxxxxxxxx
	
	The HFSQL connection parameters are: 
	- Server: xxx
	- Database: xxx
	- User xxx - Password: xxx
	
	File password: xxx
	```

	**Keep this information**. The token to connect to the WDBaaS server must be used: 

	- in the User Groupware settings window in your WINDEV project.  

	- in the User Groupware / Private Store settings window in your WINDEV Mobile project.

	- in the User Groupware configuration window in your WEBDEV project.  


 **Important**: The Reserved Server settings are stored in the "C:\\ProgramData\\WDBaaS\\GPUConnection.default.xml" file
	This file must be added to the server backup plan. This file will have to be restored if the server is reinstalled or duplicated on a new physical or virtual machine with the same settings.

31. Finish the wizard. You can directly launch the WDBaaS administration site of the Private Store. 




For more details on using BaaS solutions, see:

- [Private Store for WINDEV applications](../Editeurs/9000203.md).

- [Private Store for mobile applications](../Editeurs/1410086652.md).

- [Mobile User Groupware (Android and iOS)](../Editeurs/1410086648.md)

- [Integrated OAuth server](../WDLang3/1410090993.md). 




Note: If the database name is incorrect, you can restart the Reserved Server installation to specify the correct database name and keep the credentials.

### Reserved server setup (WDBaaS)
<a name="reserved_server_setup_wdbaas_ELTPARAGRAPHE000188"></a>

The reserved BaaS server is a WEBDEV Application Server reserved for the User Groupware and the Private Store. The configuration of the reserved server is common to User Groupware and the Private Store. 

To install the reserved Server for the User Groupware/Private Store: 

1. Run the installation package of the reserved server (WX2026PACKRSRV.exe file available in the "Install\\WDRServer" subdirectory of the WINDEV or WINDEV Mobile installation directory).

2. Validate the license. 

3. Select the module to be installed. In this case, choose "Install modules for the User Groupware and the Private Store". Go to the next step.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0001.gif)


4. If necessary, select the version of the reserved application server to be installed (32 or 64-bit). Go to the next step.

5. Select the installation directory. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0002.gif)
Go to the next step.

6. Specify the characteristics of the HFSQL server used for WDBaaS modules (User Groupware/Private Store). 
	Note: This HFSQL server must have been previously installed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0003.gif)
These characteristics are:

	- Name of the HFSQL server, 

	- Port. 

	- Name and password of the HFSQL server administrator. This information is required to automatically configure the WDBaaS database and the associated user. 




7. Test the connection to check your parameters. 

8. Specify the parameters specific to the WDBaaS database used by the User Groupware/Private Store: 

	- name of the dedicated database: WDBAAS by default. 

	- username and password for the database. 




9. Specify the password for the WDBaaS data files (existing or to be created).

10. Specify the password of the WDBaaS site administrator (User: Admin).

11. This database and its user will be automatically created. 

12. Go to the next step.

13. Specify whether an SSL connection is required for the remote administration sites. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Install_serveur_store%20-%20HC%20N%B0004.gif)


14. Go to the next step.

15. The setup summary is displayed. 

16. Go to the next step.   

17. The wizard checks for a web server on the client computer. 

	- If no web server is installed on the computer, the wizard prompts you to install and configure a server so that you can use the reserved server for the User Groupware and/or Private Store. 

	- If there is a web server on the computer, the wizard configures it so that you can use the reserved server for the User Groupware and/or the Private Store. 




18. At the end of the setup, the wizard displays a summary: 
	
	```txt
	WDBaaS for the User Groupware and the Private Store has been installed.
	WDBaaS server connection token to be provided to the environment development: 
	WDXxxxxxxxxxxxxxxxxxxxxx
	
	The HFSQL connection parameters are: 
	- Server: xxx
	- Database: xxx
	- User xxx - Password: xxx
	
	File password: xxx
	```

	**Copy and store this information**. The token to connect to the WDBaaS server must be used: 

	- in the User Groupware settings window in your WINDEV project.  

	- in the User Groupware / Private Store settings window in your WINDEV Mobile project.

	- in the User Groupware configuration window in your WEBDEV project.  


 **Important**: The Reserved Server settings are stored in the "C:\\ProgramData\\WDBaaS\\GPUConnection.default.xml" file
	This file must be added to the server backup plan. This file will have to be restored if the server is reinstalled or duplicated on a new physical or virtual machine with the same settings.

19. Finish the wizard. You can directly launch the WDBaaS administration site of the Private Store. 




For more details on the use of the Private Store, see: 

- [Private Store for WINDEV applications](../Editeurs/9000203.md).

- [Private Store for mobile applications](../Editeurs/1410086652.md).

- [Mobile User Groupware (Android and iOS)](../Editeurs/1410086648.md)




Note: If the database name is incorrect, you can restart the Reserved Server installation to specify the correct database name and keep the credentials.
