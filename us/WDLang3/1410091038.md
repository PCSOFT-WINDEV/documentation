


## EmailExecuteCommand (Function)

***In french: EmailExécuteCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends an IMAP command to the mail server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
session is emailIMAPSession
session.ServerAddress = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Name = "XXXXXXXX"
session.Password = "XXXXXXXXXX"

// Start a session
EmailStartSession(session)

// Execute a command
res = EmailExecuteCommand(session, "NOOP")
Trace("Command: " + res)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = EmailExecuteCommand(<IMAP session> , <Command>)`
---

**`<Result>: (Character string)`**

Command result.

In the event of an error (if the server has returned a NO or BAD error message), the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.

**`<IMAP session>: (emailIMAPSession variable)`**

Name of the [emailIMAPSession](../WDLang3/1000018957.md) variable corresponding to the IMAP session connected to the mail server. 

**`<Command>: (Character string)`**

Command to be sent to mail server. 
Note: The mail server must support the command.
