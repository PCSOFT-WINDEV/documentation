
## FaxPause (Function)

***In french: FaxSuspend***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Pauses a fax in the spooler. If the fax is enabled, it will be paused when it goes back to the spooler.

**Note** This function can only be used with Windows 2000, XP or higher. In Windows Vista (and later), the management of faxes is available with Windows Professional and Windows Integral Edition.
<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = FaxPause(<Connection ID> , <Fax name or Fax identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the fax is paused, 

- <u><u><u><u>False</u></u></u></u> otherwise (if the name of the fax does not exist for example).




**`<Connection ID>: (Integer)`**

Connection identifier, returned by [FaxConnect](../WDLang3/3037005.md).

**`<Fax name or Fax identifier>: (Character string)`**

Corresponds to:

- the name used to identify the outgoing fax. This name was defined with [FaxSend](../WDLang3/3037006.md).

- the fax identifier (obtained using [FaxOutbox](../WDLang3/3037008.md) or [FaxInbox](../WDLang3/3037009.md))
