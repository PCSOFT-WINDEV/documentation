


## grAutoRefreshSeries (Function)

***In french: grMAJAutomatiqueSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies or defines whether a series is refreshed whenever the chart is drawn. In this case, the content of the series is automatically recalculated whenever [grDraw](../WDLang3/3042026.md) is called.

**Example of use** A series in a graph is used as a reference series: this series is not updated automatically.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart created programmatically
IF grAutoRefreshSeries("MyChart", 5) = True THEN
	grDraw("MyChart")
END
```
<a name="Exemple2"></a>

```wl
// Chart control
IF grAutoRefreshSeries(CHART_MyChart, 5) = True THEN
	grDraw(CHART_MyChart)
END
```

## Syntax

### Identifying the mode used to refresh the series

`<Result> = grAutoRefreshSeries(<Chart name> , <Series number>)`
---

**`<Result>: (Boolean)`**

Current mode for refreshing the series: 

- <u><u><u><u>True</u></u></u></u> if the series is automatically refreshed, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the affected series.  


<a name="SYNTAXE2"></a>

### Defining the mode used to refresh the series

`grAutoRefreshSeries(<Chart name> , <Series number> , <Refresh mode>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the affected series.

**`<Refresh mode>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the series must be automatically refreshed, 

- <u><u><u><u>False</u></u></u></u> otherwise.
