


## &lt;Chart&gt;.Orientation (Function)

***In french: &lt;Graphe&gt;.Orientation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the orientation of chart axes. 



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Reverses the X-axis and the Y-axis
// Chart control
CHART_MyChart.Orientation(grYCoordinate, grAtLeft, grAtBottom)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Orientation([<First axis> [, <Orientation of horizontal axis> [, <Orientation of vertical axis>]]])`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).

**`<First axis>: (Optional constant)`**

Type of coordinates to display on the horizontal axis:


|   |   |
| --- | --- |
| *grXCoordinate*<br>(default value) | X-coordinates are displayed on the horizontal axis. |
| *grYCoordinate* | Y-coordinates are displayed on the vertical axis. |



**`<Orientation of horizontal axis>: (Optional constant)`**

Orientation of the horizontal axis:


|   |   |
| --- | --- |
| *grAtLeft* | The horizontal axis is oriented toward the left - negative values are on the right, positive values are on the left. |
| *grAtRight*<br>(default value) | The horizontal axis is oriented toward the right - negative values are on the left, positive values are on the right. |



**`<Orientation of vertical axis>: (Optional constant)`**

Orientation of vertical axis:


|   |   |
| --- | --- |
| *grAtBottom* | The vertical axis is oriented toward the bottom - negative values are at the top, positive values are at the bottom. |
| *grAtTop*<br>(default value) | The vertical axis is oriented toward the top (the negative values are found at the bottom, the positive values are found at the top). |

## Remarks


### Taking the orientation into account
<a name="taking_the_orientation_into_account_ELTPARAGRAPHE000254"></a>

The change of orientation is taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).
