


## HTTPSendAsynchronous (Function)

***In french: HTTPEnvoieAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends an HTTP request in asynchronous mode. This means the program continues to run and the response is processed by a specific procedure.  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
cMyRequest is httpRequest
cMyRequest.URL = "http://www.mysite.com/api/streamdata"
cMyRequest.ProcedureHeader = Procedure(cMyHeader is httpResponse) {
	IF cMyHeader.StatusCode = 200 THEN Trace("Request sent.")
}
cMyRequest.ProcedureData = Procedure(bufChunk is Buffer) {
	Trace("Processing [%size(bufChunk)%] bytes of data")
}
INTERNAL PROCEDURE procEnd(cMyResponse is httpResponse)
	Trace("HTTP request completed")
END
HTTPSendAsynchronous(cMyRequest, procEnd)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Sending an HTTP request (httpRequest variable)

`HTTPSendAsynchronous(<HTTP request> , <WLanguage procedure>)`
---

**`<HTTP request>: (httpRequest variable)`**

Name of the [httpRequest](../WDLang3/1000021158.md) variable containing the characteristics of the HTTP request to be sent to the server.

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure called during the response from the HTTP server. For more details, see [Parameters of the procedure used by HTTPSendAsynchronous](../WDLang3/1000025791.md).


<a name="SYNTAXE2"></a>

### Sending an HTTP request by specifying the URL to query

`HTTPSendAsynchronous(<URL> , <WLanguage procedure>)`
---

**`<URL>: (Character string)`**

URL to query. 

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure called during the response from the HTTP server. For more details, see [Parameters of the procedure used by HTTPSendAsynchronous](../WDLang3/1000025791.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
If cookies have been implemented for the specified request ([HTTPCookieManage](../WDLang3/1000019218.md)), they are updated in the [httpRequest](../WDLang3/1000021158.md) variable after the call to **HTTPSendAsynchronous**. Therefore, during the next call to **HTTPSendAsynchronous** with this request, the cookies will be taken into account.
