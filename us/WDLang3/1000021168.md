


## SSH functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to connect and communicate with an SSH server (prefix syntax): 



|   |   |
| --- | --- |
| [&lt;sshSession variable&gt;.Command](../WDLang3/1410091176.md) | Sends a command to an SSH server. The session is automatically started and closed as soon as the command is sent. |
| [&lt;sshSession variable&gt;.ConnectCommand](../WDLang3/1410091177.md) | Keeps the SSH session active between several commands sent to an SSH server (using the [&lt;sshSession variable&gt;.Command](../WDLang3/1410091176.md) function).<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;sshSession variable&gt;.ConnectShell](../WDLang3/1000021163.md) | Starts a new SSH session of "Shell" type. |
| [&lt;sshSession variable&gt;.DisconnectCommand](../WDLang3/1410091178.md) | Stops the SSH session that was active to send a series of commands.<br><br>**This function is only available in subscription-based versions, starting with WINDEV Suite 2025 - Update 2.** |
| [&lt;sshSession variable&gt;.DisconnectShell](../WDLang3/1000021164.md) | Closes an SSH session that was opened by [&lt;sshSession variable&gt;.ConnectShell](../WDLang3/1000021163.md). |
| [&lt;sshSession variable&gt;.Read](../WDLang3/1000021167.md) | Reads the data found on the output buffer of the SSH session. |
| [&lt;sshSession variable&gt;.Write](../WDLang3/1000021166.md) | Writes data into the specified SSH session. |



Note: SSH-2 protocol supported.
