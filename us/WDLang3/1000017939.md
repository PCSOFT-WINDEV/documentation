


## grDonutHolePercentage (Function)

***In french: grDonutPourcentageTrou***

<a name="Utilisation"></a>
<a name="description"></a>
Modifies the percentage corresponding to the radius of the hole in a Donut chart. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The hole will represent 50% of the total radius of the donut
grDonutHolePercentage(CHART_MyChart, 50)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grDonutHolePercentage(<Chart name> , <Percentage>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control (in the window, page or report editor).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Percentage>: (Integer)`**

Percentage represented by the hole of the donut (between 0 and 70).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The settings defined with **grDonutHolePercentage** will be taken into account next time [grDraw](../WDLang3/3042026.md) is called.

- This function can be used with the Donut charts only.
