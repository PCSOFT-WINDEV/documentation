


## Constants for managing appointments
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


| Constant | Description | Used by the function |
| --- | --- | --- |
| **aptCanceled** | Status of created appointment: The appointment has been cancelled.<br><br>Used in the syntax for creating an asynchronous appointment. | [AppointmentCreate](../WDLang3/1000020691.md) |
| **aptContent** | Filter by appointment: Filter by appointment description (contains search). | [AppointmentList](../WDLang3/1000020690.md) |
| **aptFailed** | Appointment created status: Appointment creation has failed. <br><br>Used in the syntax for creating an asynchronous appointment. | [AppointmentCreate](../WDLang3/1000020691.md) |
| **aptIdentifier** | Filter by appointment: Filter by appointment ID (exact-match search). | [AppointmentList](../WDLang3/1000020690.md) |
| **aptLocation** | Filter by appointment: Filter by appointment location (contains search). | [AppointmentList](../WDLang3/1000020690.md) |
| **aptSuccess** | Status of created appointment: The appointment has been created.<br><br>Used in the syntax for creating an asynchronous appointment. | [AppointmentCreate](../WDLang3/1000020691.md) |
| **aptTitle** | Filter by appointment: Filter by appointment title (contains search). | [AppointmentList](../WDLang3/1000020690.md) |
| **reminderDefault** | Reminder method: default method. This method depends on the setting of the device. | [Reminder](../WDLang3/1000020688.md) type |
| **reminderEmail** | Reminder method: send an Email. This type of reminder is available only if the account associated with the appointment calendar supports this type of reminder and if this account is configured. | [Reminder](../WDLang3/1000020688.md) type |
| **reminderNotification** | Reminder method: send a notification. | [Reminder](../WDLang3/1000020688.md) type |
| **reminderSMS** | Reminder method: send an SMS message. This type of reminder is available only if the account associated with the appointment calendar supports this type of reminder and if this account is configured. | [Reminder](../WDLang3/1000020688.md) type |
