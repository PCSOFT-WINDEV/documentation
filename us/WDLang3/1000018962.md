
## SaaSIsConnected (Function)

***In french: SaaSEstConnecté***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines whether the connection to the SaaS web service is still established. 

**Reminder** The connection to the SaaS web service was made with the [SaaSConnect](../WDLang3/1000018959.md) function. When the connection has been established, the SaaS web service periodically tests the validity of the connection by automatically calling **SaaSIsConnected** every 4 minutes.. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF SaaSIsConnected() = False THEN
	IF SaaSConnect("login", "password") = True THEN
		Info("Connection re-established")
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SaaSIsConnected()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the connection is still active, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).
