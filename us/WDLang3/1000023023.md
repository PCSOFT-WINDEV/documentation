


## mqttSession (Variable type)

***In french: mqttSession***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **mqttSession** type is used to define the parameters for connecting to the MQTT broker. These connection parameters can be defined and changed by several WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Declare the MQTT connection
gMqttSession is mqttSession

// Retrieve the data typed in the connection window
gMqttSession.Address = EDT_Broker_Address
gMqttSession.Port = EDT_Port
gMqttSession.Option = CBOX_SSL
gMqttSession.ConnectionTimeout = EDT_Connection_Timeout
gMqttSession.User = EDT_Login
gMqttSession.UserPassword = EDT_PSW
gMqttSession.PrivateKey = EDT_Private_Key
gMqttSession.PrivateKeyPassword = EDT_Private_Key_PSW
gMqttSession.ClientID = EDT_ClientID
gMqttSession.CleanSession = CBOX_Clean_Session
IF MQTTConnect(gMqttSession) THEN
	Message("Connection OK")
ELSE	
	Error("Connection problem. '" + ErrorInfo() + "')")
END
```

## Properties


### Properties specific to mqttSession variables
<a name="properties_specific_mqttsession_variables_ELTPARAGRAPHE000044"></a>

The following properties can be used to handle a MQTT session:

| Property name | Type used | Effect |
| --- | --- | --- |
| Address | Character string | Address of MQTT server (also called "MQTT broker"). This address can be specified as follows:<br><br>- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).<br><br>- IP address containing the server name (MQTTServer for example). This syntax is recommended.<br><br><br> |
| CleanSession | Boolean | <br><br>- <u><u><u>True</u></u></u> if it is necessary to empty the generic global parameters on the server,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
| ClientID | Character string | Client identifier. This property must not be left empty. |
| ConnectionTimeout | Integer or Duration | Connection timeout in seconds. This property can correspond to: <br><br>- an integer corresponding to the number of seconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., 10 s). <br><br><br> |
| IgnoreError | Integer constant | Specifies the ignored errors. Corresponds to a constant or combination of constants: <br><br>- *mqttIgnoreCertificateExpired* The certificate date is ignored.<br><br>- *mqttIgnoreCertificateInvalid* The certificate is ignored.<br><br>- *mqttIgnoreCertificateNameInvalid*: The site name in the certificate is ignored.<br><br>- *mqttIgnoreRevocation*: Certificate revocation is ignored.<br><br><br><br><br> |
| IsConnected | Boolean | <br><br>- <u><u><u>True</u></u></u> if the session is currently connected,<br><br>- <u><u><u>False</u></u></u> in case of loss of connection with the server. <br><br><br><br><br>**This property is available in read-only mode**. <br><br> |
| Option | Integer constant | Connection options. This property can correspond to the *optionSSL* constant for an SSL connection. |
| Port | Integer | Port of MQTT server. This port correspondsn to 1883 by default (or 8883 for an SSL connection). |
| PrivateKey | Character string or [Certificate](../WDLang1/1000019287.md) variable | Name of the [Certificate](../WDLang1/1000019287.md) variable or path of the pem file (to make a private key connection). <br><br>If this property is specified, a key-based authentication will be used. Only the **User**, **PrivateKey** and **PrivateKeyPassword** properties are taken into account. |
| PrivateKeyPassword | Character string or Secret string | Password of the key file (for a private-key based authentication). The **PrivateKey** property corresponds to the private key to be used.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| User | Character string | Username. |
| UserPassword | Character string or Secret string | User password (the **User** property corresponds to the user's name).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |

## Remarks
<a name="NOTE0_2"></a>


### Authentication mode
<a name="authentication_mode_ELTPARAGRAPHE000192"></a>

Key-based authentication takes precedence over password-based authentication. 

Key-based authentication is used if: 

- the server supports this authentication mode. 

- the **PrivateKey** property is specified. 




Password-based authentication is used if: 

- the server supports this authentication mode. 

- the **UserPassword** property is specified. 



<a name="NOTE0_3"></a>

| [MQTTPublish](../WDLang3/1000023060.md) | Publishes a message on the MQTT broker. |
| [MQTTSubscribe](../WDLang3/1000023073.md) | Used to subscribe to a MQTT notification. |
| [MQTTUnsubscribe](../WDLang3/1000023074.md) | Used to unsubscribe from a MQTT notification. |
| [MQTTUnsubscribeAll](../WDLang3/1000023080.md) | Allows you to unsubscribe from all the existing subscriptions. |
