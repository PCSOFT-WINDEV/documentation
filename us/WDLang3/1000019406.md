## Overview
<a name="overview_ELTTEXTE000067"></a>
The DNS (Domain Name System) is a service that translates domain names into IP addresses. 

WLanguage offers several functions that make it easy to manipulate IP addresses and domains on a DNS server.



## WLanguage functions
<a name="wlanguage_functions_ELTTEXTE000091"></a>
The following functions are used to manage DNS servers: 



|   |   |
| --- | --- |
| [DNSAddAddress](../WDLang3/1000019400.md) | Adds an "IP address/domain name" pair to the DNS server. |
| [DNSDeleteAddress](../WDLang3/1000019402.md) | Deletes an "IP address/Domain name" pair from a DNS server. |
| [DNSListAddress](../WDLang3/1000019401.md) | Lists IP addresses associated with a domain name in the DNS server. |
| [DNSQuery](../WDLang3/1410089873.md) | Sends a query to a DNS server. |
