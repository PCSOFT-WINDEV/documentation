


## FTPDeconnecte_objetftpConnexion (Function)

***In french: &lt;Variable ftpConnexion&gt;.Déconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the connection between the current computer and the FTP server (File Transfer Protocol). This connection was established by [&lt;ftpConnection variable&gt;.Connect](../WDLang3/1410091119.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()
...
// Disconnection
MyFTPConnection.Disconnect()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <FTP connection>.Disconnect()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the disconnection was performed, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. [ErrorInfo](../WDLang1/3013008.md) returns more details.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.

<a name="NOTE0_1"></a>

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000268"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000298"></a>

This function changes the permissions required by the application. 
Required permission: INTERNET 
This permission allows the applications to open the network sockets.
