


## &lt;Chart&gt;.Scatter3DDeleteAltitudeColor (Function)

***In french: &lt;Graphe&gt;.Nuage3DSupprimeCouleurAltitude***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the altitude colors specified with [&lt;Chart&gt;.Scatter3DAltitudeColor](../WDLang3/1000024098.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CHART_My3DScatter.Scatter3DDeleteAltitudeColor(1)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart control>.Scatter3DDeleteAltitudeColor(<Series number> [, <Altitude>])`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window editor).

**`<Series number>: (Integer)`**

Number of the series to use.

**`<Altitude>: (Optional real)`**

Altitude of the color that will be deleted. If this parameter is not specified, all the altitude colors are deleted. In this case, the chart will use the series color.
