


## xmlSignatureReference (Variable type)

***In french: xmlSignatureRéférence***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xmlSignatureReference** type is used to add a reference section into the XML signature. You can define and change the characteristics of this type of variable using different WLanguage properties. 

This type of variable is used by the [xmlSignature](../WDLang5/1000020736.md) type. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ref is xmlSignatureReference
ref.URI = "#id"
ref.HashAlgorithm = HA_SHA_160
ref.Transformation[1] = atEnveloped
ref.Transformation[2] = atC14NExclusive
```

<a name="PROPS"></a>

## Properties


### Properties specific to the xmlSignatureReference variables
<a name="properties_specific_the_xmlsignaturereference_variables_ELTPARAGRAPHE000054"></a>

The following properties can be used to define the characteristics of **xmlSignatureReference** variables:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| HashAlgorithm | Integer constant | Method used for the hash of the reference: <br><br>- *HA_MD5_128*: 	Standard MD5 cryptographic hash functions.<br><br>- *HA_RIPEMD_160*: Standard RIPEMD cryptographic hash functions.<br><br>- *HA_SHA_160*: Standard SHA cryptographic hash functions.<br><br>- *HA_SHA_256*: Standard SHA cryptographic hash functions.<br><br>- *HA_SHA_384*: Standard SHA cryptographic hash functions.<br><br>- *HA_SHA_512*: 	Standard SHA cryptographic hash functions.<br><br><br><br><br>In previous versions, this property corresponds to "AlgorithmHash" |
| Transformation | Array of Integer constants | List of transformations to apply to the data before passing the hash algorithm. The possible transformations are: <br><br>- *atNone*: No transform. <br><br>- *atC14N11Inclusive*: C14N11 inclusive transform. <br><br>- *atC14N11InclusiveWithComments*: C14N11 inclusive transform with comments.<br><br>- *atC14NExclusive*: C14N exclusive transform.<br><br>- *atC14NExclusiveWithComments*: C14N exclusive transform with comments.<br><br>- *atC14NInclusive*: C14N inclusive transform.<br><br>- *atC14NInclusiveWithComments*: C14N inclusive transform with comments.<br><br>- *atEnveloped*: Enveloped transform.<br><br><br> |
| URI | Character string | Location to sign. |
