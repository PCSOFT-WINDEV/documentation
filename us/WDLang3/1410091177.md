


## &lt;sshSession variable&gt;.ConnectCommand (Function)

***In french: &lt;Variable sshSession&gt;.ConnecteCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Keeps the SSH session active between several commands sent to an SSH server (using the [&lt;sshSession variable&gt;.Command](../WDLang3/1410091176.md) function)

Reminder: By default, when sending a command to an SSH server, the session is opened and closed automatically after the command has been sent.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Session is sshSession
// Session properties
// ...
// Initialize SSH session to keep
Session.ConnectCommand()
Session.Command("echo 'Hello world!'")
Session.Command("echo 'Hello world!'")
Session.Command("echo 'Hello world!'")
Session.Command("echo 'Hello world!'")
// Close SSH session to go back to normal behavior
Session.DisconnectCommand()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <SSH session>.ConnectCommand()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the session has been opened correctly,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<SSH session>: (sshSession variable)`**

Name of a variable of type [sshSession](../WDLang3/1000021157.md) containing the connection parameters of the SSH session to keep open
