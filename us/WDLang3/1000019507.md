
## ContactEdit (Function)

***In french: ContactEdite***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the details of a contact in edit mode in the default application of the device (Android, iPhone, iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open the current contact's form in edit mode
// Global variables
gCurrentContact is Contact
... 
// - Click on BTN_Modify
// Starts editing the contact
ContactEdit(gCurrentContact)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Opening a contact form in edit mode

`<Result> = ContactEdit(<Contact>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the contact was modified, 

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable corresponding to the contact whose form will be opened. This contact must exist in the database of contacts found on the device.

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000066"></a>

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000220"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ContactEdit** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
