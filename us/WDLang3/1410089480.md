


## DriveDeleteFile (Function)

***In french: DriveSupprimeFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a file from a remote drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

oDrive is Drive
oDrive = oDriveConnect(oOAuth2Param)

IF DriveDeleteFile(oDrive, "/MyDirectories/File.txt") = False THEN
	Error("Unable to delete file", ErrorInfo())
	RETURN
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Deleting a file from a remote drive

`<Result> = DriveDeleteFile(<Drive> , <File to delete>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was deleted,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Drive>: (Drive or gglDrive variable)`**

Name of the [Drive](../WDLang3/1410089369.md) or [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the drive to be used. The connection to the drive must have been previously established. Otherwise, the element is not deleted. 

**`<File to delete>: (Character string)`**

Absolute path of the file to be deleted. If this parameter does not correspond to a valid file path, the file will not be deleted.


<a name="SYNTAXE2"></a>

### Deleting a Google Docs Editor file from Google Drive

`<Result> = DriveDeleteFile(<Google Drive> , <File to delete>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was deleted,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Google Drive>: (gglDrive variable)`**

Name of the [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the Google Drive service to be used. The connection to the drive must have been previously established. Otherwise, the element is not deleted. 

**`<File to delete>: (GglFile variable)`**

Name of the [GglFile](../WDLang3/1410089586.md) variable that corresponds to the file to be manipulated. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
A file deleted with **DriveDeleteFile** cannot be recreated directly. The user must log in again to recreate the file.
