


## &lt;Chart&gt;.Draw (Function)

***In french: &lt;Graphe&gt;.Dessine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a chart according to the specified parameters.

**Remarks**: 

- **&lt;Chart&gt;.Draw** takes into account the new parameters specified since the last call to this function.

- This function must not be used for the Chart controls found in the report editor.


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Draw a chart in a Chart control
CHART_MyChart.Draw()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Draw()`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (found in a window or in a page).  
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

### Simultaneous calls
<a name="simultaneous_calls_ELTPARAGRAPHE000243"></a>

**&lt;Chart&gt;.Draw** is a non-blocking function. If he chart is drawn with an animation, the function will give control back as soon as the animation starts. Therefore, if several charts are drawn in the same window, the controls can be animated simultaneously.
