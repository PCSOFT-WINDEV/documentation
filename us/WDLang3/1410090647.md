
## NearbyShareStopWaiting (Function)

***In french: PartageProximitéArrêteAttente***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops waiting for other nearby devices to connect (i.e., stops advertising).

In this case, the device will no longer be visible to other devices trying to connect ([NearbyShareDiscoverDevice](../WDLang3/1410090648.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Check Box control modification code
// to start or stop waiting for a connection
CBOX_Stop_wait.State = Grayed
IF CBOX_Stop_wait = True THEN
	NearbyShareWaitForConnection(gsDeviceName, CallbackResult, ...
		CallbackRequestConnection, CallbackConnection, gnTopology)
ELSE
	NearbyShareStopWaiting()
	CBOX_Stop_wait.State = Active
END
```
