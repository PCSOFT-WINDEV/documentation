
## Parameters of the procedure used by NearbyShareWaitForConnection (Notification)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareWaitForConnection](../WDLang3/1410090655.md) to notify the status of the connection with a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Each time the connection wait check box is changed
CBOX_Wait_connection.State = Grayed
IF CBOX_Wait_connection THEN
	NearbyShareWaitForConnection(gsDeviceName, CallbackResult, CallbackRequestConnection, 
		CallbackConnection, Topology)
ELSE
	NearbyShareStopWaiting()
	CBOX_Wait_connection.State = Active
END
```

```wl
PROCEDURE CallbackConnection(sDeviceID is string, nStatus is int)
SWITCH nStatus
	CASE nsConnectionRejected
		ToastDisplay("The connection request has been rejected.")
	CASE nsConnected
		ToastDisplay(StringBuild("Connected to %1.", sDeviceID)
	CASE nsDisconnected
		ToastDisplay("Disconnected.")
	CASE nsConnectionFailed
		ToastDisplay("Connection failed." + ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareWaitForConnection_Callback_Notification(<Nearby device identifier> , <Status>)`
---

**`<Nearby device identifier>: (Character string)`**

Nearby device identifier.

**`<Status>: (Integer constant)`**

Nearby device connection status: 


|   |   |
| --- | --- |
| *nsConnected* | Connection established. |
| *nsConnectionFailed* | Connection failure. In this case, [ErrorInfo](../WDLang1/3013008.md) returns the details of the error. |
| *nsConnectionRejected* | Connection rejected by the nearby device. |
| *nsDisconnected* | Disconnection. |
