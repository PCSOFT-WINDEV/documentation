


## &lt;Notification variable&gt;.Delete (Function)

***In french: &lt;Variable Notification&gt;.Supprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Removes a notification from the system bar.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
notif is Notification
notif.Title = "New incoming message"
notif.Message = "Click here to display the message"
notif.Add()
...
notif.Delete()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Notification>.Delete()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the notification was deleted, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**Note** In the simulator, this function has no effect and always returns <u><u><u><u>False</u></u></u></u>.

**`<Notification>: (Notification variable)`**

Name of the [Notification](../WDLang3/1000019441.md) variable that corresponds to the notification to be deleted.
