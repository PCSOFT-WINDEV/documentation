
## Parameters of the procedure used by NearbyShareDiscoverDevice (Result)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareDiscoverDevice](../WDLang3/1410090648.md) to notify whether or not discovery could be started.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code of the check box used to start discovering nearby devices
CBOX_Discover.State = Grayed
IF CBOX_Discover THEN
	NearbyShareDiscoverDevice(CallbackResult, CallbackDiscover, gnTopology)
ELSE
	NearbyShareStopDiscovery()
	CBOX_Discover.State = Active
END
		INTERNAL PROCEDURE CallbackResult(bResult is boolean)
			IF bResult THEN
				CBOX_Discover.State = Active
			ELSE
				Info("Search or connection request failed: " + CR + ErrorInfo())
			END
		END
```

```wl
PROCEDURE CallbackDiscover(bDiscover is boolean, sDeviceID is string, sDeviceName is string)
IF bDiscover THEN
	ToastDisplay("Device discovered: " + sDeviceName)
ELSE
	ToastDisplay("Device unavailable: " + sDeviceName)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareDiscoverDevice_Callback_Result(<Result>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if discovery was started,

- <u><u><u><u>False</u></u></u></u> if an error occurs. For more details on the error, use [ErrorInfo](../WDLang1/3013008.md).
