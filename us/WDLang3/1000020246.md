


## WebAddress (Variable type)

***In french: AdresseWeb***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WebAddress** type is used to define the advanced characteristics of a site address as well as its type (custom page, blog, ftp, etc.). The characteristics of this site address can be defined and modified using various WLanguage properties. 

This type of variable is used by the [Contact](../WDLang3/1000020254.md) variables.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Opens a browser on the Web site of a contact
IF MyContacts.WebSite.Count > 0 THEN
	ASite is WebAddress = MyContacts.WebSite[1]
	BrowserRunApp(ASite.Address)
END
```

## Properties


### Properties specific to WebAddress variables
<a name="properties_specific_webaddress_variables_ELTPARAGRAPHE000038"></a>

The following properties can be used to handle a site address:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Address | Character string | Web address. |
| Label | Character string | Label for "custom" addresses (optional).<br>If the **Type** property is not set to the *webCustom* constant, the value of this property will be ignored. |
| Type | Integer constant | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Type of Web address: <br><br>- *webOther* other type.<br><br>- *webBureau*: professional website address.<br><br>- *webFTP*: FTP site address.<br><br>- *webCustom* custom type corresponding to the value of the property **Label**.<br><br>- *webSitePerso*: address of a personal website.<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Type of Web address: <br><br>- *webCustom* custom type corresponding to the value of the property **Label**.<br><br>- *webSitePerso*: address of a personal website.<br><br><br> |
