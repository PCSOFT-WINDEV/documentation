


## WLanguage procedure called by inAppPurchaseProduct



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [inAppPurchaseProduct](../WDLang3/1000020873.md) when the response to the purchase request is received. This procedure can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyProduct is inAppProduct = arrProduct[nIndex]
inAppPurchaseProduct(MyProduct, ValidateProductPurchase)
```

```wl
PROCEDURE ValidateProductPurchase(bSuccess is boolean, Product is inAppProduct, Receipt)

IF NOT bSuccess THEN
	ToastDisplay(ErrorInfo())
	RETURN
ELSE
	// Android case
	IF InAndroidMode() THEN
		// Consume the product (optional)
		inAppConsumeProduct(Product, Receipt, ConsumeProduct)
	END
	// iOS case
	IF IniOSMode() THEN
		// Activate the product in the application
		EnableProduct(Product)
		// Save the purchase in the application preferences
		SaveParameter(Product..Identifier, 1)
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`inAppPurchaseProduct_Callback(<Success> , <Product> , <Received> , <Quantity>)`
---

**`<Success>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the purchase was validated, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) before any other call to a WLanguage function (this would reinitialize the error). [ErrorInfo](../WDLang1/3013008.md) associated with the *errCode* constant returns one of the following error codes: 
	


|   |   |
| --- | --- |
| *inAppCancellation* | Purchase canceled by the user.<br><br> |
| *inAppInvalidResponse* | Invalid response. |
| *inAppSignatureError* | Error while checking the data signature received for the purchase validation (security problem). |
| *inAppUnknownError* | Unknown error. |






**`<Product>: (inAppProduct variable)`**

[inAppProduct](../WDLang3/1000020868.md) variable that corresponds to the product or subscription purchased.

**`<Received>: (Character string)`**



- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) &lt;Receipt&gt; is not available. To validate a purchase, you must use [inAppListPurchase](../WDLang3/1000020888.md) and make sure the purchase is in the list.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) &lt;Receipt&gt; is a character string corresponding to the purchase identifier. Then, this identifier can be used to consume the product that was purchased ([inAppConsumeProduct](../WDLang3/1000020880.md)).




**`<Quantity>: (Integer)`**

Quantity of products purchased. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) For a subscription, this parameter is always set to 1.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This parameter is always set to 1.
