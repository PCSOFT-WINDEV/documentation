
## NearbyShareStopDiscovery (Function)

***In french: PartageProximitéArrêteRecherche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops searching for nearby devices (i.e., stops discovery).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CBOX_Stop_search.State = Grayed
IF CBOX_Stop_search = True THEN
	NearbyShareDiscoverDevice(CallbackResult, CallbackDiscover, gnTopology)
ELSE
	NearbyShareStopDiscovery()
	CBOX_Stop_search.State = Active
END
```
