
## tapiDialerCall (Function)

***In french: telDialerCompose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the default Phone application and dials the specified number.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
tapiDialerCall("0612345678")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = tapiDialerCall(<Phone number>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the phone application was opened successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Phone number>: (Character string)`**

Phone number to dial. 
The function will return <u><u><u><u>False</u></u></u></u> if this parameter corresponds to an empty string ("").
Note: This number must not contain spaces.

## Remarks


### Special cases

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000232"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**tapiDialerCall** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
