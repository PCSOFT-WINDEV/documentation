
## NetClientSendMessage (Function)

***In french: NetEnvoieMessageClient***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	 This function is kept for backward compatibility. It is recommended to use a standard FTP, SSH or SCP server. For more details, see [Handling files on an FTP server](../WDLang3/3040009.md) and [Standard FTP functions](../WDLang3/3040004.md).

<a name="Utilisation"></a>
<a name="description"></a>
Sends a message from the server to all the connected client computers. The server is an FTP (File Transfer Protocol) or RPC (Remote Procedure Call) server powered by WINDEV.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003056007&name=netclientsendmessage_function">See additional examples</a>

```wl
NetClientSendMessage(ServerID, "Received", 0, 0)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`NetClientSendMessage(<Server identifier> , <Event> [, <Parameter 1> [, <Parameter 2>]])`
---

**`<Server identifier>: (Integer)`**

Identifier of the server used (returned by [NetStartServer](../WDLang3/3056013.md)).

**`<Event>: (Integer or Ansi chracter string)`**

Identifier of the Windows event sent to the windows of the client computers (Windows event number or specific character string).

**`<Parameter 1>: (Optional integer)`**

Parameter associated with the event.

**`<Parameter 2>: (Optional integer)`**

Parameter associated with the event.
