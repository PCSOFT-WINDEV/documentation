


## grSeriesColor (Function)

***In french: grCouleurSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the color of a series, the color of a pie section or the color of a funnel section. 

By default, the colors of series (or the colors of sections) are selected according to a preset order among a set of 11 colors. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modifies the color of series 2 in the "CHART_MyChart" control
grSeriesColor(CHART_MyChart, 2, LightYellow)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grSeriesColor(<Chart name> , <Series number> , <Color>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name can correspond to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to use. 

**For a Pie chart** (constant *grSector*), this parameter corresponds to the index of the data in the series (the sector number).
**For a Funnel chart** (constant *grFunnel*), this parameter corresponds to the index of the data in the series (the portion number).

**`<Color>: (Integer or Integer constant)`**

Color of the specified series. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).

## Remarks


- The following colors are used by default: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grCouleurSerie.gif)


- The colors defined by **grSeriesColor** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).

- To display the color gradients, use [grGradient](../WDLang3/3042029.md).

- To define a color for the series in "Scatter" charts, it is recommended to use [grScatterSeriesColor](../WDLang3/3042045.md).

- The [SeriesColor](../Proprietes/2510145.md) property allows you to get and initialize the color of a series or a pie section (same as **grSeriesColor**).
