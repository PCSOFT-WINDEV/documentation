


## &lt;emailIMAPSession variable&gt;.SubscribeToFolder (Function)

***In french: &lt;Variable emailSessionIMAP&gt;.AbonneAuDossier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an existing folder to the list of subscribed folders. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
session is emailIMAPSession
session.ServerAddress = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Name = "XXXXX"
session.Password = "XXXXXXX"
session.StartSession()

// List of email management folders and subscribed folders
res is string
res = session.ListFolder(LstFolderNormal)
Trace(res)
Trace("---------------------------------------------------")
// Subscribe to the "Test" folder
Trace("Subscribe: " + (session.SubscribeToFolder("Test")? "OK" ELSE "KO"))
Trace("---------------------------------------------------")
// List of email management folders and subscribed folders
// The Test folder is now listed
res = session.ListFolder(LstFolderNormal)
Trace(res)
Trace("---------------------------------------------------")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <IMAP session>.SubscribeToFolder(<Folder>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified folder has been subscribed,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<IMAP session>: (emailIMAPSession variable)`**

Name of the [emailIMAPSession](../WDLang3/1000018957.md) variable corresponding to the IMAP session connected to the mail server.

**`<Folder>: (Character string)`**

Name and path of the folder to be added to the list of subscribed folders.



<a name="NOTE0"></a>

## Remarks


- Folders created with [&lt;emailIMAPSession variable&gt;.AddFolder](../WDLang3/1000022273.md) are automatically subscribed. 

- [&lt;emailIMAPSession variable&gt;.ListFolder](../WDLang3/1000022290.md) with the *LstFolderNormal* constant lists folders containing emails and subscribed folders. If a subscribed folder contains subfolders, these subfolders will also be listed. 

- [&lt;emailIMAPSession variable&gt;.ListFolder](../WDLang3/1000022290.md) with the *LstFolderAll* constant lists all folders (folders containing emails and subscribed or non-subscribed folders).
