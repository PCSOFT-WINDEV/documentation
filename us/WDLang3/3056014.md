
## NetMachineName (Function)

***In french: NetNomMachine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the local computer or the name of a computer whose IP address is known (reverse DNS resolution).  

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns the name of server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the name of local computer
Info(NetMachineName())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NetMachineName([<IP address>])`
---

**`<Result>: (Character string)`**

Name of current computer. 
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Server name.In an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.

**`<IP address>: (Optional character string)`**

IP address (in XXX.XXX.XXX.XXX format) of the computer whose name you want to get. If this parameter is not specified, the name of the current computer is returned. This address must be a valid address.
