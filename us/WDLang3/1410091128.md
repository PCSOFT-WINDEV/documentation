


## &lt;ftpConnection variable&gt;.GetFile (Function)

***In french: &lt;Variable ftpConnexion&gt;.RécupèreFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Transfers a file from an FTP (File Transfer Protocol) server to the current computer. 

Note: This function allows you to recover only one file. This file must exist on the FTP server. In this case, **&lt;ftpConnection variable&gt;.GetFile** is faster than [&lt;ftpConnection variable&gt;.Get](../WDLang3/1410091127.md).


<a name="sample_code"></a>

## Example

<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Download the "/Document/File.txt" file found on the FTP server 
// in the "D:\Temp" directory on the current computer 
ResRetrieve = MyFTPConnection.GetFile("/Document/File.txt", "D:\Temp")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <FTP connection>.DownloadFile(<File to download> , <Destination file/directory> [, <WLanguage procedure> [, <Transfer mode>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the transfer has been completed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
	Note: The result may be incorrect on some Unix servers. Existing files may not be found.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.

**`<File to download>: (Character string)`**

Name and absolute (or relative) path of the file to get. This file is located on the FTP server. The different parts of the path are separated by "slashes" ("/"). 
Note: Directory names are case sensitive. You must use the same case as the one used on the FTP server (uppercase/lowercase characters). 
No wildcard character (\* or?) can be used. To retrieve several files, first use [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md) to get the name of the files to be retrieved.
					
An absolute path has the following format: "/&lt;DirectoryName&gt;/&lt;FileName&gt;". The tree structure has the following format: "/&lt;DirectoryName&gt;/&lt;FileName&gt;".
A relative path has the following format: "&lt;DirectoryName&gt;/&lt;FileName&gt;". The tree structure has the following format: "/&lt;CurrentServerDirectory&gt;/&lt;DirectoryName&gt;/&lt;FileName&gt;".
									
**When retrieving the file**:

- if &lt;Destination file/directory&gt; is a directory found on the current computer, the file to retrieve is copied to the destination directory.

- if &lt;Destination file/directory&gt; is a file found on the current computer, the file to retrieve is copied and renamed.




**`<Destination file/directory>: (Character string)`**

Name and full or relative path of the destination file or directory. A UNC path can be used.

If this parameter corresponds to a name of an existing directory on the client computer, a file with the same name as the file to get is created in this directory.

**`<WLanguage procedure>: (Procedure name)`**

Name of WLanguage procedure automatically called to check the transfer progress. This procedure can be a global method of the class (in the following format: &lt;Class name&gt;::&lt;GlobalMethodName>).

**`<Transfer mode>: (Optional Integer constant)`**

Transfer mode used:					


|   |   |
| --- | --- |
| *ftpASCIIMode* | Transfer in ASCII mode. This mode is used to transfer files between different operating systems, e.g. UNIX to Windows. The file is delivered in the ASCII format used by the receiving system. |
| *ftpBinaryMode*<br>(Default value) | Transfer performed in binary mode. The file is strictly identical between the sending and the receiving. |





<a name="NOTE0_2"></a>


### Timeout
<a name="timeout_ELTPARAGRAPHE000306"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_4"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000339"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_5"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000351"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	ex: /pub/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [&lt;ftpConnection variable&gt;.CurrentDir](../WDLang3/1410091131.md).




When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.
<a name="NOTE0_7"></a>


### AS/400 FTP server
<a name="as400_ftp_server_ELTPARAGRAPHE000373"></a>

**&lt;ftpConnection variable&gt;.GetFile** does not work properly on an AS/400 FTP server.

In this case, we recommend that you use [&lt;ftpConnection variable&gt;.Command](../WDLang3/1410091118.md) with the FTP "RETR" command (for more details, see the documentation about the FTP server).
