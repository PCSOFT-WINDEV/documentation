


## NearbyShareAcceptConnection (Function)

***In french: PartageProximitéAccepteConnexion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Accepts a connection request from a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareAcceptConnection(gsNearbyDeviceID, ReceptionCallback, ProgressCallback)
	INTERNAL PROCEDURE ReceptionCallback(sDeviceID is string, nTransferID is 8-byte int, 
					nType is int, data)
		STC_Received_message_information = [
			Message received from the following device: [%sDeviceID%]
			Transfer ID: [%nTransfertID%]
		]
		SWITCH nType
			CASE nsBuffer
				sMessage is string = data
				EDT_Message_received = sMessage
				EDT_Message_received.State = Inactive
			CASE nsFile
				BTN_Open_file_received.State = Active
				gsFileReceived = data
			END
	END
	INTERNAL PROCEDURE ProgressCallback(sDeviceID is string, nTransferID is 8-byte int, 
		nState is int, nSizeReceived is 8-byte int, 
		nTotalSize is 8-byte int)
		Message is string
		SWITCH nState
			CASE nsInProgress
				Message = [
						Transfer in progress: 
						[%Round(nSizeReceived / nTotalSize * 100, 2)%]% 
						of data was sent.
						]
				ToastDisplay(Message)
			CASE nsCompleted
				Message = [
					Data transfer completed: 
					[%Round(nSizeReceived / nTotalSize * 100, 2)%]% 
					of data was sent.
					]
				ToastDisplay(Message)
			CASE nsError
				ToastDisplay("Transfer error" + CR + ErrorInfo())
			CASE nsCanceled
				ToastDisplay("Data transfer canceled")
		END
	END
```

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareAcceptConnection(<Device identifier> , <Reception procedure> [, <Progress procedure>] [, <Confirmation request> , <Authentication token>])`
---

**`<Device identifier>: (Character string)`**

Identifier of the device for which the connection is accepted. 

**`<Reception procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called when receiving data from a nearby device.
This procedure will be called once all the data (buffer or file) has been received. 
For more details on this procedure, see [Parameters of the procedure used by NearbyShareAcceptConnection (Reception)](../WDLang3/1410090644.md). 

**`<Progress procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") used to check the progress of the current transfer.
This procedure is called on both the sender and receiver sides. 
Note: Binary buffers are always sent in a single block.
For more details on this procedure, see [Parameters of the procedure used by NearbyShareAcceptConnection (Progress)](../WDLang3/1410090657.md). 

**`<Confirmation request>: (Optional constant)`**

If this parameter is specified and is set to the *nsRequestConfirmation* constant, a dialog box will be opened to show the authentication token to the user, and will ask them to accept or reject the connection request.
If this parameter is not specified, the connection request will be accepted directly.


**`<Authentication token>: (Optional character string)`**

Short, random character string that allows users to confirm that they are connecting to the right device.

<a name="NOTE0_1"></a>

## Remarks


- In order to exchange data, both devices must accept the connection. 

- Generally, **NearbyShareAcceptConnection** is called in the procedure passed to [NearbyShareWaitForConnection](../WDLang3/1410090655.md) or [NearbyShareRequestConnection](../WDLang3/1410090650.md) (executed when a connection is initiated by the nearby device).

- To reject the connection, use [NearbyShareRejectConnection](../WDLang3/1410090651.md).
