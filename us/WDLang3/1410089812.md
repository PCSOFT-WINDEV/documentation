


## grWaffleSize (Function)

***In french: grWaffleTaille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the number of rows and columns in a Waffle chart.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Configures the chart
grWaffleSize(CHART_Chart, nbColumns, nbRows)
// Redraws the chart
grDraw(CHART_Chart)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grWaffleSize(<Chart name> , <Number of columns> , <Number of rows>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.




**`<Number of columns>: (Integer)`**

Number of columns in the Waffle chart. 

**`<Number of rows>: (Integer)`**

Number of columns in the Waffle chart.
