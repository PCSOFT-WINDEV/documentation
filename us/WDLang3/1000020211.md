


## ContactSource (Variable type)

***In french: ContactSource***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The type **ContactSource** type is used to define all the advanced characteristics of a contact source (or account) (e.g. Google, Exchange, Facebook).

You can define and change the characteristics of this source using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Lists the Google accounts of the phone
arrSource is array of ContactSource = ContactListSource()
IF NOT ErrorOccurred THEN
	FOR EACH ELEMENT source of arrSource
		IF arrSource.Type = "com.google" THEN
			// Process 	
		END
	END
END
```

<a name="PROPS"></a>

## Properties


### Properties specific to ContactSource variables
<a name="properties_specific_contactsource_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used to handle the source of contacts:

| Property name | Type used | Effect |
| --- | --- | --- |
| Name | Character string | Name of the source or account. This property can correspond to an email address for a Google account ("lastname.firstname@gmail.com" for example). |
| Type | Character string | Type of the source or account ("com.google" for a Google account). |
