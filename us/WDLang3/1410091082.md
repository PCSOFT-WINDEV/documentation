
## apiResponse (Variable type)

***In french: apiRéponse***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **apiResponse** type is used to get the result of a request sent to a previously imported REST API. The characteristics of this result are returned by several WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Response is apiResponse
// API function call
Response = MyApi.GetCustomer(1)
// Read header element
remaining_requests is int = Response.Header["Rate-Limit"]
// Read function response
customer is MyApi.Customer = Response.Value
```

<a name="PROPS"></a>

## Properties


### Properties specific to apiResponse variables
<a name="properties_specific_apiresponse_variables_ELTPARAGRAPHE000031"></a>

The following properties can be used to define the characteristics of **apiResponse** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Header | Associative array of strings | Key/value pair of received headers. |
| HTTPResponse | [httpResponse](../WDLang3/1000021165.md) variable | Raw HTTP response from the REST web service. <br><br>**This property is read-only.** |
| ReturnType | [Definition](../WDLang1/1000019540.md) variable | Type of value. <br>**This property is read-only.** |
| Value |   | Response value. <br><br>This value is deducted from:<br><br>- REST web service documentation. <br><br>- HTTP response content. <br><br>- headers. <br><br><br><br><br>This value can correspond to: <br><br>- a simple type: int, string, numeric, boolean, etc. The corresponding mime type is "byte-stream".<br><br>- an array of simple types. <br><br>- JSON content. The corresponding mime type is "application/json".  <br><br><br><br><br>If this value is empty, a problem has occurred. In this case, it is recommended to analyze the contents of the **ReturnType** and **HTTPResponse** properties. <br><br>**This property is read-only.** |
