
## Parameters of the procedure used by NearbyShareDiscoverDevice (Request)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareDiscoverDevice](../WDLang3/1410090648.md) when a new nearby device is discovered, or when a previously discovered device is no longer available.

The connection request should be written in the code of this procedure ([NearbyShareRequestConnection](../WDLang3/1410090650.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code of the check box used to start discovering nearby devices
CBOX_Discover.State = Grayed
IF CBOX_Discover THEN
	NearbyShareDiscoverDevice(CallbackResult, CallbackDiscover, gnTopology)
ELSE
	NearbyShareStopDiscovery()
	CBOX_Discover.State = Active
END
		INTERNAL PROCEDURE CallbackResult(bResult is boolean)
			IF bResult THEN
				CBOX_Discover.State = Active
			ELSE
				Info("Search or connection request failed: " + CR + ErrorInfo())
			END
		END
```

```wl
PROCEDURE CallbackDiscover(bDiscover is boolean, sDeviceID is string, sDeviceName is string)
IF bDiscover THEN
	ToastDisplay("Device discovered: " + sDeviceName)
ELSE
	ToastDisplay("Device unavailable: " + sDeviceName)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareDiscoverDevice_Callback_Discover(<Discover> , <Device identifier> , <Device name>)`
---

**`<Discover>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a new device was discovered, 

- <u><u><u><u>False</u></u></u></u> if a previously discovered device is no longer available.




**`<Device identifier>: (Character string)`**

Nearby device identifier.

**`<Device name>: (Character string)`**

Nearby device name.
This name corresponds to the device name passed to [NearbyShareWaitForConnection](../WDLang3/1410090655.md) (called by the discovered device).
