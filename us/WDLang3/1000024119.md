


## &lt;Chart&gt;.TitleFont (Function)

***In french: &lt;Graphe&gt;.PoliceTitre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the font used for the chart title.

Example of title in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Titre.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the font used for the title of CHART_MyChart
// The identifier of font used is 7.
CHART_MyChart.TitleFont(7)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Defining the font used for the chart title

`<Chart control>.FontTitle(<Font used>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font used>: (Font)`**

Font to use. This parameter corresponds to a variable of type [Font](../Motscles/1514045.md). The font characteristics have been defined with [FontCreate](../WDLang1/3060002.md) or via the [font properties](../Proprietes/2515045.md).


<a name="SYNTAXE2"></a>

### Defining the font used for the chart title (syntax kept for backward compatibility)

`<Chart control>.FontTitle(<Font identifier>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control in the window, page or report editor.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Font identifier>: (Integer)`**

Font identifier, defined by [grCreateFont](../WDLang3/3042001.md). A WLanguage error occurs if this font does not exist.

<a name="NOTE0_1"></a>

## Remarks


### Chart title
<a name="chart_title_ELTPARAGRAPHE000280"></a>The chart title can be displayed above or below the chart.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Titre.gif)
The content of the chart title is defined with [&lt;Chart&gt;.Title](../WDLang3/1000024166.md). This function can also be used to set the position of the title.

The font used for the chart title can be modified by **&lt;Chart&gt;.TitleFont**.

The data defined by **&lt;Chart&gt;.TitleFont** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).
<a name="NOTE0_2"></a>


### Initializing fonts
<a name="initializing_fonts_ELTPARAGRAPHE000310"></a>

The default font used for the chart title has the following characteristics:

- Font name: Arial

- Size: 14

- Style: Normal

- Color: Black
