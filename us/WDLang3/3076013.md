


## tapiDial (Function)

***In french: telCompose***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dials a phone number for a voice line.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Note** By default, the device used is automatically the first TAPI 3.1-compatible device found. A specific device can be selected by [tapiDevice](../WDLang3/3076032.md). In this case, this specific device will be used.![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **PABX application** In a PABX application, each line appears as a device. Therefore, to dial on a phone line, you must:

1. Choose the current phone line ([tapiDevice](../WDLang3/3076032.md)).

2. Number ([tapiDial](../WDLang3/3076013.md)).


To do so, use the [tapiLineDial](../WDLang3/3076012.md) function.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) To use the telephony application (dialer) of an Android phone, [tapiDialerCall](../WDLang3/1000019235.md) must be called.

**Note** Depending on the operating system and modem driver used, a call management window may appear when using the function **tapiDial**. This window is used to automatically end the current call.

## Example


```wl
IF tapiDial(EDT_PhoneNumber, "LineStatus")=True THEN 
	Info("Click OK to hang up") 
	tapiHangUp() 
END
```

```wl
PROCEDURE TestLineStatus(ValueLineStatus is int) 
SWITCH ValueLineStatus 
	CASE telLigneOccupée: Message("Line is busy") 
	CASE telLigneDecrochée: Message("OK, connected")
	CAS telLigneNumérote: Message("Dialing in progress") 
	CAS telLineTone: Message("Tone")
	CASE telLigneRaccrochée: Message("The correspondent has hung up")
	CAS telLigneAttendRéponse: Message("Search for correspondent")
	CASE telLigneSonnerie: Message("Ringing at correspondent's home")
END
```

## Syntax

`<Result> = tapiDial(<Number to dial> [, <WLanguage procedure> [, <Duration> [, <Custom parameter>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the line is open: you can pick up the handset and speak, 

- <u><u><u><u>False</u></u></u></u> otherwise. For more details on the error, use [tapiError](../WDLang3/3076020.md). 




**`<Number to dial>: (Character string)`**

Phone number to dial. To specify a prefix (0 for an external line for example), use a comma in the number. For example: "0.0467789066".

**`<WLanguage procedure>: (Optional procedure name)`**

Name of WLanguage procedure used to manage the progress of dialing. For more details on this procedure, see [Parameters of the procedure used by tapiDial](../WDLang3/1000024724.md). 

**Warning** This procedure must not contain a call to the debugger (no breakpoint, no STOP keyword, no auto-stop expression, etc.).

**`<Duration>: (Optional integer or optional Duration)`**

Maximum wait duration (in seconds). When this timeout is exceeded, the function assumes that there is no response (nobody picked up). 
This parameter can correspond to: 

- an integer corresponding to the number of seconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms). 




**`<Custom parameter>: (Any type, optional)`**

Parameter passed to the WLanguage procedure.

## Remarks


### Differences between tapiDial and tapiLineDial
<a name="differences_between_tapidial_and_tapilinedial_ELTPARAGRAPHE000088"></a>

- **tapiDial** is used in the context of a single outgoing call. The identifier of this call is not available.

- [tapiLineDial](../WDLang3/3076012.md) is used in a context where there may be several simultaneous calls. [tapiLineDial](../WDLang3/3076012.md) returns the call identifier. Therefore, it can be easily handled (to transfer a call for example).



<a name="NOTE0_2"></a>


### Limitation
<a name="limitation_ELTPARAGRAPHE000103"></a>

**tapiDial** cannot be called in the procedure for call detection (defined by [tapiListen](../WDLang3/3076029.md)).
<a name="NOTE0_3"></a>


### Required configuration
<a name="required_configuration_ELTPARAGRAPHE000259"></a>

Telephony functions use TAPI 2.0 technology and/or TAPI 3.1 technology. These technologies can be used on all systems.
