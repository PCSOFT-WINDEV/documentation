
## wdbaasUserInfo (Function)

***In french: wdbaasInfoUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets user information from the WEBDEV OAuth server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection parameters
param is OAuth2Parameters
param.ClientID = "d07c7d45-103c-48ad-a6b2-1bb9354eb947"
param.ClientSecret = "e260eeb0-15fb-4db7-964f-a72de7324e0d"
param.TokenURL = "https://serveur/oauth2/v1/token"
param.GrantType = gtClientCredentials
param.Scope = "wdbaas:users:read"
// Connection
admin_token is AuthToken = AuthIdentify(param)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END
// Get user details
user is gpwUser = wdbaasUserInfo(token_admin, 88)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END
Trace(user.Login, user.Email, user.ID)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = wdbaasUserInfo(<Token> , <User identifier>)`
---

**`<Result>: (gpwUser variable)`**

[gpwUser](../WDLang6/1000021088.md) variable corresponding to the specified user. You can get the different user details using the properties of the variable. 

If an error occurs, [ErrorOccurred](../WDLang1/3087001.md) is set to <u><u><u><u>True</u></u></u></u> and [ErrorInfo](../WDLang1/3013008.md) returns the details of the error. 

**`<Token>: (AuthToken variable)`**

Name of the [AuthToken](../WDLang3/1000022220.md) variable corresponding to the authentication token on the OAuth server. 

**`<User identifier>: (Integer)`**

User ID. This identifier is created using [wdbaasCreateUser](../WDLang3/1410091289.md).

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000172"></a>

To use user management functions on a WEBDEV OAuth server, you need to define permissions for the OAuth credentials. These permissions are defined in WEBDEV's BaaS administration site. 

For example, you can grant the following permissions:

- Create users only.

- Read user information only.

- All (read, create, modify, delete).

- etc. 




For more details, see [BaaS administration site](../WDLang3/1410086668.md).
