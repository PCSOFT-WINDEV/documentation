


## EmailSendMessage (Function)

***In french: EmailEnvoieMessage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends an email:

- or by using the **SMTP protocol** protocol: the Email is sent directly to the server. **The email is actually sent when disconnecting from the SMTP server** (i.e. when the session is closed).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) or via the **MS Exchange** client: the Email is placed in the MS Exchange outbox. To actually send the email, use [EmailUpdate](../WDLang3/3032036.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) or via the **Lotus Notes** the Email is placed in the mailbox of the messaging software. The email is automatically sent by the spooler of Domino. 
	Note: Lotus Notes must be installed in connected mode, not in local mode.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) or via **Outlook** the Email is placed in the outbox of the mail software. The email is actually sent from Outlook. For more details, see [Accessing Outlook](../WDLang3/3032137.md).




**Attention** Before sending the Email, it is necessary to:

- Open a session with one of the following functions: [EmailStartSession](../WDLang3/3032028.md), [EmailStartOutlookSession](../WDLang3/3032128.md) or [EmailStartNotesSession](../WDLang3/3032121.md) depending on the protocol to be used.

- Fill a variable of type [Email](../WDLang3/1000018713.md) or structure [Email](../WDLang3/3032029.md) with the message (sender, recipient, etc.).


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In this version, the emails can be sent via the SMTP protocol only.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In this version, the emails can be sent via the SMTP protocol only. Before sending this email, there is no need to start a session with [EmailStartSession](../WDLang3/3032028.md). To actually send the email, the SMTP server to use must be supplied to the PHP engine. It must be specified in the "SMTP =" entry of PHP.INI file.

```wl
// Start an SMTP session
MySession is emailSMTPSession
MySession.ServerAddress = "smtp.mycompany.us"
EmailStartSession(MySession)

// Build an email
MyMessage is Email
MyMessage.Sender = "ordering_department@mycompany.fr"
Add(MyMessage.Recipient, "customer@company.com")
MyMessage.Subject = EDT_EmailSubject
MyMessage.Message = "EDT_EmailText"

// Send the message
EmailSendMessage(MySession, MyMessage)
```
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Sending a message from a PHP WEBDEV website**


```wl
// Note: opening an SMTP session is not required 

// Build an email (by using the Email structure)
Email.Sender = "purchasing_department@mycompany.com"
Email.NbRecipient = 1
Email.Recipient[1] = "customer@company.com"
Email.Subject = EDT_EmailSubject
Email.Message = EDT_EmailText

// Send the message
EmailSendMessage()
```

## Syntax

### Sending an email using SMTP

`<Result> = EmailSendMessage(<Session> [, <Email> [, <Advanced options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the message was sent to the SMTP server,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If an error occurs, the content of Email.Error variable must be checked.

**`<Session>: (Character string or emailSMTPSession variable)`**

Identifies the user session. Corresponds to:

- the username that was used to start the email session ([EmailStartSession](../WDLang3/3032028.md) or [EmailStartSMTPSession](../WDLang3/3032025.md)).

- a variable of type [emailSMTPSession](../WDLang3/1000018765.md).


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

**`<Email>: (Optional Email variable)`**

Name of the [Email](../WDLang3/1000018713.md) variable corresponding to the email to be sent. If this parameter is not specified, the information contained in the [Email](../WDLang3/3032029.md) structure is used.
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

**`<Advanced options>: (Optional Integer constant)`**

Combination of following constants:


|   |   |
| --- | --- |
| *emailOptionEncodeHeader* | Encodes the message headers in Quoted-Printable if necessary. <br>The headers of messages are not encoded by default. This constant prevents the reception of email with wrongly decoded accented characters. |
| *emailOptionMessageID* | Takes the **Email.MessageID** variable into account to generate the email. This option is ignored if this variable is not specified.<br><br>This option is an advanced option. |
| *emailOptionReference* | Takes the **Email.Reference** variable into account to generate the email. This option is ignored if this variable is not specified.<br><br>This option is an advanced option. |

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.

### Sending an email via MS Exchange, Lotus Notes or Outlook

`<Result> = EmailSendMessage(<Session ID> [, <Email> [, <Display> [, <Type>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the message was placed in the outbox of MS Exchange, Lotus Notes or Outlook,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session ID>: (Integer or emailOutlookSession variable)`**

Identifies the current email session. This parameter can be:

- an integer returned by one of the following functions: [EmailStartSession](../WDLang3/3032028.md), [EmailStartNotesSession](../WDLang3/3032121.md) or [EmailStartOutlookSession](../WDLang3/3032128.md).

- a variable of type [emailOutlookSession](../WDLang3/1000018767.md).

- a variable of type [emailNotesSession](../WDLang3/1000018768.md).




**`<Email>: (Optional Email variable)`**

Name of the [Email](../WDLang3/1000018713.md) variable corresponding to the email to be sent.

If this parameter is not specified, the information contained in the [Email](../WDLang3/3032029.md) structure is used.

**`<Display>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> to display the message in a dialog box before sending it,

- <u><u><u><u>False</u></u></u></u> (by default) to display no dialog box.




This parameter is taken into account only if the email session was started by [EmailStartSession](../WDLang3/3032028.md), by using the MS Exchange syntax with a profile name. In the other cases, the dialog box is not displayed.

**Note**: This parameter is not available for Lotus Notes. 

**`<Type>: (Optional character string)`**

Describes the type of message to send. By default, &lt;Type&gt; = "IPM" (Inter Personal Message).

### Asynchronous mode
<a name="asynchronous_mode_ELTPARAGRAPHE000398"></a>

If the session was started in asynchronous mode ([EmailStartSession](../WDLang3/3032028.md) and [EmailStartSMTPSession](../WDLang3/3032025.md)), **EmailSendMessage** creates an identifier for each email sent.

The email identifier is stored in the ***Email.MailIdentifier*** variable and can be used by [EmailStatus](../WDLang3/3032009.md) to get the current status of the outgoing email (sent, in progress, etc.).

Line error handling in asynchronous mode: The function **EmailSendMessage** function returns <u><u><u><u>True</u></u></u></u> if the Email is placed in the Email spooler, <u><u><u><u>False</u></u></u></u> if it is not possible to contact the spooler. To determine if the email was sent, use [EmailStatus](../WDLang3/3032009.md).
