
## &lt;ftpConnection variable&gt;Attribute (Function)

***In french: &lt;Variable ftpConnexion&gt;.Attribut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies the attributes of a file located on an FTP server (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Find out the attributes of
// "/Documents/File.doc" found on the FTP server
ResAttributes = MyFTPConnection.Attribute("/Documents/File.doc")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <FTP connection>.Attribute([<File name>])`
---

**`<Result>: (Character string)`**



- "ERR" if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

- One or more letters corresponding to the file attributes ("AH" for example). The following letters are used:

	- R: Read-only file. The file is read-only.

	- H: Hidden file. The file name is grayed out or invisible in the explorer.
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is not available.

	- S: System file. The file is a Windows system file.
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is not available.

	- A: "Archive" file. This attribute indicates that the file can be archived. Some programs use this attribute to determine which files have been saved.
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is not available.

	- D: Directory or subdirectory. The file is a directory or a subdirectory.

	- C: Compressed file (on the NTFS partitions). The file was automatically compressed when copied to an NTFS partition (Windows NT or 2000).
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is not available.







**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 

**`<File name>: (Optional character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/").  
**If this parameter is not specified**, the attributes returned will be those of the last file accessed using one of the following FTP functions: [&lt;ftpConnection variable&gt;.Date](../WDLang3/1410091120.md), [&lt;ftpConnection variable&gt;.Time](../WDLang3/1410091125.md), [&lt;ftpConnection variable&gt;.Size](../WDLang3/1410091134.md), [&lt;ftpConnection variable&gt;.ListFile](../WDLang3/1410091126.md). In this case, no request is sent to the server. This syntax is recommended.

## Remarks


### Identifying the file attributes
<a name="identifying_the_file_attributes_ELTPARAGRAPHE000310"></a>

To get the different file attributes, check whether one of the letters identifying an attribute is in &lt;Result&gt;. This search can be performed using [Position](../WDLang1/3024027.md), for example.
<a name="NOTE0_2"></a>


### Timeout
<a name="timeout_ELTPARAGRAPHE000325"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_4"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000358"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_5"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000370"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	ex: /pub/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [&lt;ftpConnection variable&gt;.CurrentDir](../WDLang3/1410091131.md).




When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.
