
## GglDriveConnect (Function)

***In french: GglDriveConnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a connection to Google Drive. 
<a name="sample_code"></a>

## Example


```wl
// Authenticating to Google Drive using the OAuth 2.0 protocol
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"
 
MyDrive is gglDrive
MyDrive = GglDriveConnect(oOAuth2Param)
```

```wl
// Authenticating to Google Drive using a token (refresh token)
oOAuth2Param is OAuth2Parameters
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

oOAuth2Token is AuthToken
oOAuth2Token = AuthIdentify(oOAuth2Param)
 
MyDrive is gglDrive
MyDrive = GglDriveConnect(oOAuth2Token)
```

## Syntax
<a name="SYNTAXE1"></a>

### Authenticating to Google Drive using the OAuth 2.0 protocol

`<Result> = GglDriveConnect(<Authentication parameters>)`
---

**`<Result>: (Drive or gglDrive variable)`**

[gglDrive](../WDLang3/1410089374.md) or [Drive](../WDLang3/1410089369.md) variable that contains all the Google Drive connection information. 
If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and an invalid variable is returned. 

**`<Authentication parameters>: (OAuth2Parameters variable)`**

Name of the [OAuth2Parameters](../WDLang3/1000022212.md) variable that contains the authentication parameters:

- The **ClientID** and **ClientSecret** properties must be specified. 

- The **RedirectionURL** property can be specified. By default, this property is set to "http://localhost:3400/".





<a name="SYNTAXE2"></a>

### Authenticating to Google Drive using a token (refresh token)

`<Result> = GglDriveConnect(<Authentication parameters>)`
---

**`<Result>: (Drive or gglDrive variable)`**

[gglDrive](../WDLang3/1410089374.md) or [Drive](../WDLang3/1410089369.md) variable that contains all the Google Drive connection information. 
If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and an invalid variable is returned. 

**`<Authentication parameters>: (AuthToken variable)`**

Name of the [AuthToken](../WDLang3/1000022220.md) variable that contains the authentication parameters.

## Remarks


### Difference between Drive and gglDrive variables
<a name="difference_between_drive_and_ggldrive_variables_ELTPARAGRAPHE000081"></a>

The **GglDriveConnect** function can use both [gglDrive](../WDLang3/1410089374.md) and [Drive](../WDLang3/1410089369.md) variables. 

- Variables of type [Drive](../WDLang3/1410089369.md) will allow you to use the same code, regardless of the storage service used. 

- Variables of type [gglDrive](../WDLang3/1410089374.md) will only work with Google Drive. In this case, you will be able to manipulate files in Google Docs Editors using a variable of type [GglFile](../WDLang3/1410089586.md). Some specific functions and syntaxes allow you to manipulate this type of file: 

	- Specific functions: 
			


|   |   |
| --- | --- |
| [DriveDownloadGglFile](../WDLang3/1410089618.md) | Downloads a Google Docs Editors file from Google Drive in a given compatible format. |
| [DriveListFileGgl](../WDLang3/1410089601.md) | Lists Google Docs Editors files (Docs, Sheets, etc.) present on Google Drive. |

- Functions with specific syntax for files in Google Docs Editors: 
			







### Using an access token
<a name="using_access_token_ELTPARAGRAPHE000114"></a>

It is recommended to to pass a token with a refresh token so that users do not have to log in each time the application is launched. If necessary, the token will be automatically updated.

Information needed to connect to a drive using an existing token: 


| Properties of the OAuth2Parameters variable | Value used by the GglDriveConnect function |
| --- | --- |
| AuthURL | "https://accounts.google.com/o/oauth2/v2/auth" |
| TokenURL | "https://oauth2.googleapis.com/token" |
| Scope | "https://www.googleapis.com/auth/drive" |
| RedirectionURL (Editable) | "http://localhost:3400/" |
