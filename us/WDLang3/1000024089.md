


## &lt;Chart&gt;.Legend (Function)

***In french: &lt;Graphe&gt;.Légende***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the presence and position of legend in a chart.

Example of legend in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grLegende.gif)


**Remark**: The legend groups together the colors and labels of the series (or sectors) of a chart.. 



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Using a Chart control
// The legend is displayed on the left of CHART_MyChart
CHART_MyChart.Legend(grAtLeft)
...
CHART_MyChart.Draw()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Legend(<Position>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Position>: (Integer)`**

Position of chart legend:


|   |   |
| --- | --- |
| *grAtBottom* | Legend displayed below the chart. |
| *grAtLeft* | Legend displayed on the left of chart. |
| *grAtRight* | Legend displayed on the right of chart. |
| *grAtTop* | Chart legend displayed above the chart. |
| *grNone* | No legend. |

## Remarks


### Chart legend
<a name="chart_legend_ELTPARAGRAPHE000270"></a>The set of series labels correspond to the chart legend.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=EtiquetteSerie.gif)
Serial labels cannot be used with Pie charts.

Series labels are defined with [&lt;Chart&gt;.SeriesLabel](../WDLang3/1000024073.md). 

The legend font can be changed with [&lt;Chart&gt;.LegendFont](../WDLang3/1000024118.md).  

**&lt;Chart&gt;.Legend** indicates the presence and position of the legend (i. e. all series labels). Any changes made with **&lt;Chart&gt;.Legend** will take effect the next time [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is called. You can change the position of the chart legend via a context menu.

**Note** To define series labels for "Scatter charts", use the [&lt;Chart&gt;.ScatterSeriesLabel](../WDLang3/1000024107.md) function. For more details, see [Legends of a chart](../WDChamp/3042069.md).
<a name="NOTE0_2"></a>


### Manual legend positioning: grLegend without effect
<a name="manual_legend_positioning_grlegend_without_effect_ELTPARAGRAPHE000317"></a>

**&lt;Chart&gt;.Legend** has no effect if the legend is positioned manually ("Manual positioning" in the chart legend window).
