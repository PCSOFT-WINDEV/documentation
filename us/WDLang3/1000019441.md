


## Notification (Variable type)

***In french: Notification***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Notification** type is used to handle  

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) **the local notifications**. 

- **the push notifications**.




You can define and change the characteristics of this notification using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Simple notification
// --------------------
notif is Notification
notif.Title = "New incoming message"
notif.Message = "Click here to display the message"
NotifAdd(notif)
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Notification with two additional actions
n is notification
n.Title = "New message"
n.Message = "Order #54781-4551"
n.SecondaryMessage = "customer@company.com"
n.LargeIcon = "envelope.png"
n.AdditionalAction[1].ActionLabel = "Respond"
n.AdditionalAction[1].Icon = "respond.png"
n.AdditionalAction[1].ActionClick = "procRespond"
n.AdditionalAction[2].ActionLabel = "Delete"
n.AdditionalAction[2].Icon = "delete.png"
n.AdditionalAction[2].ActionClick = "procDelete"
NotifAdd(n)

// Notification while defining a notification format
n is notification
n.Title = "Photo saved"
n.Message = "Shooting date: 18/07/2014 19:45"
n.LargeIcon = "photo.png"
n.SecondaryMessage = "desert.png"
n.Format.Format  = notifImageFormat
n.Format.Content = fCurrentDir + "photos/desert.png"
NotifAdd(n)
```

If the procedure is a local procedure, the name of this procedure must be prefixed by the full name of object to which the procedure belongs. For example, for a local window procedure: "FEN_Window1.MyProcedure".<br>Internal procedures and lambdas are not supported. |
| ActionLabel | Character string | Caption for the action button of the notification. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available. |
