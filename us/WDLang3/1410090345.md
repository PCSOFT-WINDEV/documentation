
## Manipulating files in Dropbox, Google Drive and OneDrive
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000174"></a>
There are many online storage services available. WINDEV, WEBDEV and WINDEV Mobile allow you to easily manipulate files on Dropbox, Google Drive and OneDrive. The code is the same regardless of the storage service used. 

In Google Drive, you can also manipulate files from Google Docs Editors. 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Prerequisite
<a name="prerequisite_ELTTEXTE000198"></a>
To manipulate files, you need to configure the drives you want to use. For more details, see [Prerequisites for using Google Drive, OneDrive and Dropbox](../WDLang3/1410090346.md).

<a name="NOTE3_1"></a>


## How to?
<a name="how_ELTTEXTE000222"></a>


### Authentication
<a name="authentication_ELTPARAGRAPHE000036"></a>

The use of these storage services requires authentication. 

You can access the different services using OAuth 2.0. 

To do so: 

1. Create a new [OAuth2Parameters](../WDLang3/1000022212.md) variable. 

2. Define the various properties of this variable, including: 

	- ClientID: Client ID obtained when configuring the drive. 

	- ClientSecret: Secret identifier obtained when configuring the drive.
			![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There is no secret identifier in iOS.

	- RedirectionURL: Specify the desired URL, e.g. "http://localhost:9000". 
			![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) For iOS, the redirect URL corresponds to the "iOS URL scheme" provided by Google during the configuration process. The redirection URL should have the following format: "com.googleusercontent.apps.123-abc:/oauth". 




3. Create a variable of type [Drive](../WDLang3/1410089369.md), and use the connection function for the desired service: 
	


|   |   |
| --- | --- |
| [dpDriveConnect](../WDLang3/1410089379.md) | Creates a connection to Dropbox. |
| [GglDriveConnect](../WDLang3/1410089373.md) | Creates a connection to Google Drive. |
| [oDriveConnect](../WDLang3/1410089376.md) | Creates a connection to OneDrive. |




Note: It is also possible to pass a token with a refresh token. This solution avoids asking the user for login details again. The information to be used is detailed in the documentation of each connection function. 

Examples: 

- Authenticating to Google Drive using the OAuth 2.0 protocol: 
	
	```wl
	// Authenticating to Google Drive using the OAuth 2.0 protocol
	oOAuth2Param is OAuth2Parameters
	oOAuth2Param.ClientID = "client_id"
	oOAuth2Param.ClientSecret = "client_secret"
	oOAuth2Param.RedirectionURL = "http://localhost:9000/"
	 
	MyDrive is gglDrive
	MyDrive = GglDriveConnect(oOAuth2Param)
	```


- Authenticating to Google Drive using a token: 
	
	```wl
	// Authenticating to Google Drive using a token (refresh token)
	oOAuth2Param is OAuth2Parameters
	oOAuth2Param is OAuth2Parameters
	oOAuth2Param.ClientID = "client_id"
	oOAuth2Param.ClientSecret = "client_secret"
	oOAuth2Param.RedirectionURL = "http://localhost:9000/"
	
	oOAuth2Token is AuthToken
	oOAuth2Token = AuthIdentify(oOAuth2Param)
	 
	MyDrive is gglDrive
	MyDrive = GglDriveConnect(oOAuth2Token)
	```








### Manipulating drive files and directories
<a name="manipulating_drive_files_and_directories_ELTPARAGRAPHE000081"></a>

The following functions are used to manipulate files and directories on a drive. All these functions use the Drive variable, which is specified during the authentication. 

- File manipulation functions: 
	


|   |   |
| --- | --- |
| [DriveCopyFile](../WDLang3/1410089524.md) | Copies a single file on a remote drive to another directory on same drive. |
| [DriveCreateFile](../WDLang3/1410089477.md) | Creates a file on the remote drive. |
| [DriveDeleteFile](../WDLang3/1410089480.md) | Deletes a file from a remote drive. |
| [DriveDownloadFile](../WDLang3/1410089558.md) | Downloads a file from a remote drive to the user's computer. |
| [DriveListFile](../WDLang3/1410089380.md) | Lists the files in a cloud-based drive directory. |
| [DriveMoveFile](../WDLang3/1410089555.md) | Moves a file on a remote drive from one directory to another. |
| [DriveRename](../WDLang3/1410089566.md) | Renames a file or directory on a remote drive. |
| [DriveUploadFile](../WDLang3/1410089563.md) | Uploads a local file to a remote drive. |




- Directory functions: 
	


|   |   |
| --- | --- |
| [DriveCopyDirectory](../WDLang3/1410089554.md) | Copies a directory on a remote drive to another directory. |
| [DriveCreateDirectory](../WDLang3/1410089479.md) | Creates a directory on the remote drive. |
| [DriveDeleteDirectory](../WDLang3/1410089481.md) | Deletes a directory and its files from a remote drive. |
| [DriveDownloadDirectory](../WDLang3/1410089559.md) | Downloads a directory and its files from a remote drive to the user's computer. |
| [DriveListDirectory](../WDLang3/1410089448.md) | Lists drive directories. |
| [DriveMoveDirectory](../WDLang3/1410089556.md) | Moves a directory and its contents to another directory within a remote drive. |
| [DriveRename](../WDLang3/1410089566.md) | Renames a file or directory on a remote drive. |
| [DriveUploadDirectory](../WDLang3/1410089564.md) | Uploads a directory and its contents to a remote drive. |







### Special case: Manipulating files in Google Docs Editors
<a name="special_case_manipulating_files_google_docs_editors_ELTPARAGRAPHE000095"></a>

Google Drive allows users to manipulate files using Google Docs Editors: Docs, Sheets, Slides, etc.

These files must be manipulated using: 

- a variable of type [gglDrive](../WDLang3/1410089374.md), which is the result of the [GglDriveConnect](../WDLang3/1410089373.md) function. 

- a variable of type [GglFile](../WDLang3/1410089586.md), which allows you to manipulate files in the Google Docs Editors. 




There are two specific functions for manipulating these files: 



|   |   |
| --- | --- |
| [DriveDownloadGglFile](../WDLang3/1410089618.md) | Downloads a Google Docs Editors file from Google Drive in a given compatible format. |
| [DriveListFileGgl](../WDLang3/1410089601.md) | Lists Google Docs Editors files (Docs, Sheets, etc.) present on Google Drive. |





[DriveListFileGgl](../WDLang3/1410089601.md) gets the list of Google Docs Editors files on the drive. This function initializes the [GglFile](../WDLang3/1410089586.md) variable type. This variable type can then be used by the different Drive functions. 

Example: 

```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"

gglMyDrive is gglDrive
gglMyDrive = GglDriveConnect(oOAuth2Param) 

arrGglFile is array of GglFile
arrGglFile = DriveListFileGgl(gglMyDrive, "/", frRecursive)

FOR EACH File OF arrGglFile
	SWITCH File.MimeType
		CASE mimeTypeGglDocs: File.ExportMimeType = mimeTypeDOCX
		CASE mimeTypeGglSheets: File.ExportMimeType = mimeTypeXLSX
		OTHER CASE: File.ExportMimeType = mimeTypePDF
	END 
	let ResDownload = DriveDownloadGglFile(gglMyDrive, arrGglFile[1], "c:\MyDocuments")
	IF ErrorOccurred THEN
		// Error handling
		Trace ("An error has occurred")
		RETURN
	END
END
```
