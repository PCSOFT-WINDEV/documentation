


## &lt;Chart&gt;.Title (Function)

***In french: &lt;Graphe&gt;.Titre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the caption and/or position of the chart title.

Example of title in a chart: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Titre.gif)


The chart used can be:

- a chart created through programming ([grCreate](../WDLang3/3042005.md)).

- a Chart control in the window editor, page editor or report editor.




**Note**: By default, a graph has no title.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the caption and the position of title in CHART_MyChart
CHART_MyChart.Title("Turnover projection", grAtTop)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Title([<Title> [, <Position>]])`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Title>: (Optional character string)`**

Chart title.

**`<Position>: (Optional constant)`**

Indicates the title position:


|   |   |
| --- | --- |
| *grAtBottom* | Title displayed at the bottom of chart. |
| *grAtTop* | Title displayed at the top of chart. |
| *grNone* | No title. |

<a name="NOTE0_1"></a>

## Remarks


### Displaying the title
<a name="displaying_the_title_ELTPARAGRAPHE000280"></a>

Any changes made with **&lt;Chart&gt;.Title** will take effect the next time [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is called.
<a name="NOTE0_2"></a>


### Manual title positioning: &lt;Chart&gt;.Title no effect
<a name="manual_title_positioning_docparampagetitleshort_effect_ELTPARAGRAPHE000297"></a>

**&lt;Chart&gt;.Title** has no effect if the title of the chart is positioned manually ("Manual positioning" in the chart title window).
<a name="NOTE0_3"></a>


### Languages that use a non-Latin character set
<a name="languages_that_use_nonlatin_character_set_ELTPARAGRAPHE000317"></a>

**&lt;Chart&gt;.Title** will use the selected non-Latin character set only if the associated project configuration uses UNICODE strings at runtime.

To check the selected option in the current configuration: 

1. In the "Project Explorer" pane, display the context menu for the "Configurations" option and select "Description".  

2. Display the "Unicode" tab: the "Use UNICODE strings at runtime" option must be checked.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Gestion_Unicode%20-%20HC%20N%B0001.gif)


3. Validate if necessary.
