


## &lt;zipArchive variable&gt;.Exist (Function)

***In french: &lt;Variable zipArchive&gt;.Existe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines whether an archive exists. An archive exists if it was opened by [&lt;zipArchive variable&gt;.Open](../WDLang3/1000019097.md) or if it was created by [&lt;zipArchive variable&gt;.Create](../WDLang3/1000019160.md).

## Example

```wl
MyArchive is zipArchive
// Create the archive
ResCreate = MyArchive.Create("C:\Temp\Archive.zip")
...
// Check the archive existence 
IF MyArchinve.Exist() = True THEN
	// Add a file into an archive
	ResAddFile = MyArchive.AddFile(...
			"C:\MyDirectory\MyFiles\File.pdf", zipDrive)
	// Display an error message if the file was not added
	IF ResAddFile <> 0 THEN 
		Error(zipMsgError(ResAddFile))
	END
END
```

## Syntax

`<Result> = <Archive>.Exist()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the archive exists,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Archive>: (zipArchive variable)`**

Name of a variable of type [zipArchive](../WDLang3/1000018679.md) corresponding to the archive to use.
