
## Background task constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manipulate background tasks:

| Constant | Details | Function |
| --- | --- | --- |
| **refreshBackgroundTask** | The task is a background refresh task. <br> <br>Please note: For a refresh task to be executed, the following conditions must be met:<br><br>- task processing may take a few seconds, <br><br>- the device does not have a low battery,<br><br>- the energy-saving mode is not active on the device,<br><br>- in the device settings, the "Refresh in background" option is set to "Yes" and the option is active for the application.  <br><br>- the application has been launched and used recently,<br><br>- the application is in the list of recent applications (app switcher),<br><br>- CPU and network data budget not exceeded,<br><br>- the execution number is not exceeded.<br><br><br> | [BackgroundTaskAdd](../WDLang3/1000023454.md) |
| **processingBackgroundTask** | The task corresponds to background processing. <br>Please note: For background processing to run, the following conditions must be met:<br><br>- processing the task may take a few minutes,<br><br>- the device does not have a low battery,<br><br>- the energy-saving mode is not active on the device,<br><br>- in the device settings, the "Refresh in background" option is set to "Yes" and the option is active for the application.\* the application has been launched in the previous week (or 2 weeks),<br><br>- the application is in the list of recent applications (app switcher),<br><br>- the user is not actively using the device (e.g., loading at night).<br><br><br> | [BackgroundTaskAdd](../WDLang3/1000023454.md) |
