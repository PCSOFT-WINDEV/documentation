


## DriveCreateDirectory (Function)

***In french: DriveCréeRépertoire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a directory on a remote drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
oOAuth2Param is OAuth2Parameters
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.RedirectionURL = "http://localhost:9000/"
oDrive is Drive
oDrive = oDriveConnect(oOAuth2Param)

IF DriveCreateDirectory(oDrive, "/MyDirectories/NonexistentDirectory/MySubdirectory/") = False THEN
	Error("Unable to create directory", ErrorInfo())
	RETURN
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DriveCreateDirectory(<Drive> , <Directory to create>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the directory was created,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Drive>: (Drive or gglDrive variable)`**

Name of the [Drive](../WDLang3/1410089369.md) or [gglDrive](../WDLang3/1410089374.md) variable that corresponds to the drive to be used. The connection to the drive must have been previously established. Otherwise, the element is not created. 

**`<Directory to create>: (Character string)`**

Absolute path of the directory to be created. 
If this parameter does not correspond to a valid path, the element will not be created. Missing directories in the path will automatically be created. 
In Dropbox, the directory to be created must not end with the "/" character. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### &lt;Directory to create&gt; parameter
<a name="parameter_ELTPARAGRAPHE000072"></a>

Examples of valid paths: 

```txt
"/holidays directory/2021/"
"\photos"
```


Examples of invalid paths:

```txt
"directoryA/DirectoryB"
"This/Path/Is/invalid"
"c:\Users\"
```
<a name="NOTE0_2"></a>


### Creating subdirectories
<a name="creating_subdirectories_ELTPARAGRAPHE000078"></a>

You can create a directory and the missing subdirectories. For example: 

```wl
IF DriveCreateDirectory(MyDrive, "/MyDirectories/Directory1/") = False THEN
	Error("Unable to create directory", ErrorInfo())
	RETURN
END
```


Note: In Dropbox, the directory to be created must not end with the "/" character. The code becomes: 

```wl
IF DriveCreateDirectory(MyDrive, "/MyDirectories/Directory1") = False THEN
	Error("Unable to create directory", ErrorInfo())
	RETURN
END
```
