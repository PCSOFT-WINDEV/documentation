


## WLanguage procedure called by inAppListProductInfo



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procedure ("Callback") called by [inAppListProductInfo](../WDLang3/1000020872.md) when the product details are received. This procedure can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrIdentifier is array of strings 
IF InAndroidMode() THEN
	arrIdentifier = ["product1", "product2", "product3", "product4", "unknown product"]
ELSE
	arrIdentifier = ["ProductID1", "ProductID2", "ProductID3", ...
		"ProductID4", "ProductID5", "unknown product"]
END
IF inAppListProductInfo(arrIdentifier, ListProductInfo) THEN
	 ToastDisplay("Asks for the list of products sent.")
ELSE
	Error("ERROR: " + ErrorInfo)
END
```

```wl
// --------------------
// ListProductInfo procedure
PROCEDURE ListProductInfo(bSuccess is boolean, arrProducts is array of inAppProduct)
IF NOT bSuccess THEN
	Error("Error: " + ErrorInfo())
	RETURN
END
LooperDeleteAll(LOOP_ProductInfo)
FOR I = 1 _TO_ arrProducts.Count
	LooperAddLine(LOOP_ProductInfo, arrProducts[i].Caption, ...
		arrProducts[i].Description, arrProducts[i].Identifier, arrProducts[i].Price)
END
// Copy into the array global to the window
garrProduct <= arrProducts
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`inAppListProductInfo_Callback(<Success> , <Product details>)`
---

**`<Success>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if information about the products was retrieved, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) before any other call to a WLanguage function (this would reinitialize the error).




**`<Product details>: (Character string)`**

Array of [inAppProduct](../WDLang3/1000020868.md) variables containing the details of each product with a known ID. If the identifier does not correspond to an existing product, it is ignored. 
If &lt;Success&gt; = <u><u><u><u>False</u></u></u></u>, the array will be empty.
