


## FTPSize (Function)

***In french: FTPTaille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the size (in bytes) of a file located on an FTP server (File Transfer Protocol).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003040007&name=ftpsize_function">See additional examples</a>

```wl
// Find out the size of "/Documents/File.doc" file 
// found on the FTP server
ResSize = FTPSize(7, "/Documents/File.DOC")
```
<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
FTPConnect(MyFTPConnection)

// Find out the size of "/Documents/File.doc" file 
// found on the FTP server
ResSize= FTPSize(MyFTPConnection, "/Documents/File.doc")
```

## Syntax
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Syntax not available in PHP
### Getting the size of a file (connection via an ftpConnection variable)

`<Result> = FTPSize(<FTP connection> , <File name>)`
---

**`<Result>: (Integer)`**



- Size (in bytes) of the specified file,

- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 


**`<File name>: (Character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/"). 
**If this parameter is not specified**, the size returned will be that of the last file accessed using one of the following FTP functions: [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md). In this case, no request is sent to the server. This syntax is recommended.


<a name="SYNTAXE2"></a>

### Getting the size of a file (connection via the identifier of the connection to the FTP server)

`<Result> = FTPSize([<Connection ID> , <File name>]])`
---

**`<Result>: (Integer)`**



- File size in bytes,

- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Connection ID>: (Integer)`**

Connection identifier, returned by [FTPConnect](../WDLang3/3040016.md).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is a Variant parameter.

**`<File name>: (Character string)`**

Name and full or relative path of the file be accessed. The different parts of the path are separated by "slashes" ("/").  

**Note**: If the &lt;Connection ID&gt; and &lt;File name&gt; parameters are not specified, the size returned will be that of the last file accessed using one of the following FTP functions: [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md). In this case, no request is sent to the server. This syntax is recommended.

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000332"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified: 

- when connecting to the FTP server with [FTPConnect](../WDLang3/3040016.md) (&lt;Timeout&gt; parameter).

- when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
	



<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000372"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
<a name="NOTE0_4"></a>


### Relative and absolute path
<a name="relative_and_absolute_path_ELTPARAGRAPHE000382"></a>

The notions of relative path and absolute path are very important in an FTP application.

- A path beginning with a slash is considered an **absolute path**. This path is relative to the root of the FTP server (server-specific parameter).
	ex: /pub/user/JULIA

- If the path does not begin with a slash, it is considered a **relative path**, i.e. the path relative to the current directory. This current directory can be obtained or changed using [FTPCurrentDir](../WDLang3/3040003.md).




When connecting to an FTP site, the initial directory (the "base directory" of the user) is not necessarily found at the root of the FTP server. Therefore, we recommend that you use relative paths.

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000401"></a>

This function changes the permissions required by the application. 
Required permission: INTERNET 
This permission allows the applications to open the network sockets.
