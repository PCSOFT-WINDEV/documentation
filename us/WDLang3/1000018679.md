


## zipArchive (Variable type)

***In french: zipArchive***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **zipArchive** type is used to manipulate an archive file corresponding to one of the following formats: ZIP, CAB, RAR, WDZ, 7z, TAR, gzip or TGZ (TAR.GZ). You can define and change the characteristics of this file using different WLanguage properties.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The CAB format is not available.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create a backup archive for the "My Documents" directory
MyArchive is zipArchive
// Protect the archive by a password
MyArchive.Password = "secret"
// Create the archive
zipCreate(MyArchive, "s:\Backups\" + DateToString(DateSys(), "YYYY-MM-DD") + ".zip")
// Add the files
zipAddDirectory(MyArchive, SysDir(srMyDocuments))
// Close the archive
zipClose(MyArchive)
```

## Properties


### Properties specific to zipArchive variables
<a name="properties_specific_ziparchive_variables_ELTPARAGRAPHE000058"></a>

The following properties can be used to define the characteristics of **zipArchive** variables:

| **Name** | **Type used** | **Effect** |
| --- | --- | --- |
| ArchiveFormat | Integer constant | Format of the archive file:<br><br>- *zipFormatCAB*: File in CAB format.<br><br>- *zipFormatRAR*: File in RAR format.<br><br>- *zipFormatWDZ*: File in WDZ format.<br><br>- *zipFormatZIP*: File in ZIP format.<br><br>- *zipFormat7Z*: File in 7z format.<br><br>- *zipFormatTAR*: File in TAR format. <br><br>- *zipFormatTARGZ*: File in TGZ (TAR.GZ) or gzip format.  <br><br><br><br><br>**This property is read-only**. |
| CompressedSize | 8-byte integer | Total compressed size of the files found in the archive.<br>**This property is read-only**. |
| CompressionLevel | Int | Compression level that must be used to add files into the archive.<br>For more details, see [zipCompressionLevel](../WDLang3/3082054.md). |
| File | Array of [zipArchivedFile](../WDLang3/1000019044.md) | Array of files found in the archive. |
| Length | 8-byte integer | Total size of the files in the archive (decompressed size).<br>**This property is read-only**. |
| NbFile | Int | Number of files found in the archive.<br>**This property is read-only**. |
| NbPart | Int | Number of parts in a multi-volume archive.<br>For a single-volume archive, this property is equal to 1.<br>**This property is read-only**.<br> |
| Password | Character string or Secret string | Password that will be used to add files into the archive or to extract files from the archive. <br>For more details, see [zipPassword](../WDLang3/3082053.md).<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). This property is write-only.<br><br>Format 7z: It is not possible to use a password.<br>TAR, gzip and TGZ format (TAR.GZ): It is not possible to use a password. |
