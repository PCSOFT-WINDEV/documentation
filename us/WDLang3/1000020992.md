


## &lt;upnpDevice variable&gt;.ModifySharpness (Function)

***In french: &lt;Variable upnpPériphérique&gt;.ModifieNetteté***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the sharpness of a UPnP device.

**Attention**: To use this function, the device must have a "RenderingControl" service.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
arrDevice is array of upnpDevices
arrDevice = UPNPListDevice(...
		"urn:schemas-upnp-org:device:MediaRenderer:1", 5)
FOR EACH Device of arrDevice
	Device.ModifySharpness(50)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <UPnP device>.ModifySharpness(<New value>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the sharpness was modified, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<UPnP device>: (upnpDevice variable)`**

Name of the [upnpDevice](../WDLang3/1000020903.md) variable corresponding to the UPnP device to use.

**`<New value>: (Integer)`**

New sharpness to apply. This parameter must be included between 0 and 100.
