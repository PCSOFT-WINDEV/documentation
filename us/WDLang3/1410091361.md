
## MapAddLayer (Function)

***In french: CarteAjouteCalque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un nouveau claque à la carte à partir d'lURL d'un serveur de tuile (non compatible Google Maps)
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Ajoute le calque de OSM
CarteAjouteCalque("https://tile.openstreetmap.org/{z}/{x}/{y}.png")
// Ajoute le calque d'image satellite
CarteAjouteCalque("https://data.geopf.fr/wmts?&REQUEST=GetTile&SERVICE=WMTS&VERSION=1.0.0&STYLE=normal&TILEMATRIXSET=PM&FORMAT=image/jpe&LAYER=ORTHOIMAGERY.ORTHOPHOTO&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}", 50)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Résultat> = CarteAjouteCalque(<Nom du champ Carte> , <URL> [, <Opacité>])`
---

**`<Résultat>: (Booléen)`**

est de type Booléen

**`<Nom du champ Carte>: (Chaîne de caractères)`**

est de type Champ

**`<URL>: (Chaîne de caractères)`**

est de type Chaîne U compat A courant ptr (ex : données de l'utilisateur ; sans 0 binaire),  serveur de tuile avec sa clé en dur et les paramètres sous la forme variable comme {x}
comme https://tile.openstreetmap.org/{z}/{x}/{y}.png
https://api.maptiler.com/maps/streets-v2/{z}/{x}/{y}.png?key=MACLESECRETE

**`<Opacité>: (Entier optionnel)`**

est de type Entier32, Opacité du calque entre 0 et 100
