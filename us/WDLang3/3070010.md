
## SocketDeny (Function)

***In french: SocketRefuse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Run on the server, this function refuses a connection request to an existing socket found on the server.

**Remark**:

- If the client computer uses a WINDEV application to connect to this socket, this application will have to use [SocketConnect](../WDLang3/3070016.md).

- **SocketDeny** cannot be used with a UDP socket.

- **SocketDeny** can be used with an SSL socket.








**Reminder**: A socket is a communication resource used by applications to communicate from one computer to another regardless of the type of network.


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SocketDeny(<Socket name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the connection was denied,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Socket name>: (Character string)`**

Name of the server socket that refuses the connection. This name is defined:

- by [SocketCreate](../WDLang3/3070011.md), [SocketCreateSSL](../WDLang3/1000017041.md), [SocketCreateInfrared](../WDLang3/3070012.md) (for a simplified server).

- by [SocketAccept](../WDLang3/3070004.md) (for a standard server).




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Note: The socket name is case sensitive.
