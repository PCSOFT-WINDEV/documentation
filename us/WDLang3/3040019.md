


## FTPName (Function)

***In french: FTPNom***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the last file accessed by an FTP function.

**Note**: **FTPName** is particularly useful when browsing files on an FTP server with [FTPListFile](../WDLang3/3040018.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Name of last file accessed by an FTP function
ResName = FTPName()
```
<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
FTPConnect(MyFTPConnection)

// Name of last file accessed by an FTP function
ResName = FTPName(MyFTPConnection)
```

## Syntax
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Syntax not available in PHP
### Getting the name of the last file accessed (connection via an ftpConnection variable)

`<Result> = FTPName(<FTP connection>)`
---

**`<Result>: (Character string)`**



- Name of the last file accessed by an FTP function. The file must have been modified by one of the following FTP functions: [FTPAttribute](../WDLang3/3040006.md), [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md).  

- Empty string ("") if an error occurred.  To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server. 



<a name="SYNTAXE2"></a>

### Getting the name of the last file accessed (connection via the identifier of the connection to the FTP server)

`<Result> = FTPName()`
---

**`<Result>: (Character string)`**



- Name of the last file accessed by an FTP function. The file must have been modified by one of the following FTP functions: [FTPAttribute](../WDLang3/3040006.md), [FTPDate](../WDLang3/3040015.md), [FTPTime](../WDLang3/3040013.md), [FTPSize](../WDLang3/3040007.md), [FTPListFile](../WDLang3/3040018.md).  

- Empty string ("") if an error occurred.  To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

## Remarks


### Request to FTP server
<a name="request_ftp_server_ELTPARAGRAPHE000151"></a>

**FTPName** sends no request to the FTP server.
<a name="NOTE0_2"></a>


### Timeout
<a name="timeout_ELTPARAGRAPHE000337"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified: 

- when connecting to the FTP server with [FTPConnect](../WDLang3/3040016.md) (&lt;Timeout&gt; parameter).

- when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
	



<a name="NOTE0_4"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000377"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000386"></a>

This function changes the permissions required by the application. 
Required permission: INTERNET 
This permission allows the applications to open the network sockets.
