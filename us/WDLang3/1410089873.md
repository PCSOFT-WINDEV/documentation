
## DNSQuery (Function)

***In french: DNSInterroge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends a query to a DNS server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
s is string = DNSQuery("google.com", dnsA)
```

```wl
let ResDNS = DNSQuery("91.90.97.90", dnsPTR)
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
ELSE
	Info("the associated domain name is: " + ResDNS)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DNSQuery(<Element used> , <Query type> [, <DNS server>])`
---

**`<Result>: (Character string)`**

Result of the query sent to a DNS server. If several pieces of information are returned, they are separated by carriage returns (CR). 

In an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u> and [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.

**`<Element used>: (Character string)`**

Domain name or IP address on which the query is to be executed. 

**`<Query type>: (Integer constant)`**

Type of query to be executed: 


|   |   |
| --- | --- |
| *dnsA* | Returns the IPv4 address associated with the domain name. |
| *dnsAAAA* | Returns the IPv6 address associated with the domain name. |
| *dnsCNAME* | Returns the aliases of a domain name. |
| *dnsDNAME* | Returns the aliases of a domain and its subdomains. |
| *dnsMX* | Returns the mail servers associated with the specified domain. |
| *dnsNAPTR* | Returns rewrite rules, allowing for more possibilities of correspondence between a domain name and a resource. |
| *dnsNS* | Lists DNS servers for the specified domain. |
| *dnsPTR* | Returns the host or domain name associated with an IP address (opposite of A/AAAA). |
| *dnsSOA* | Gives general domain information: main server, contact e-mail, various durations including expiration, zone serial number, etc. |
| *dnsSRV* | Returns the mail server associated with a domain name with additional data such as the load balancing weight for a given service. |
| *dnsTLSA* | Returns the TLS certificate associated with the domain name. |
| *dnsTXT* | Returns the text associated with a DNS record. |



**`<DNS server>: (Optional character string)`**

Address of the DNS server to be used. By default, the current DNS server is used.
