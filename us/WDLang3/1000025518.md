


## zipExtractDirectory (Function)

***In french: zipExtraitRépertoire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Automatically extracts and decompresses files from a directory in the file tree of an archive to a physical location.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Archive is zipArchive
// Open an archive
IF zipOpen(Archive, "C:\Archives\Archive.zip") = 0 THEN
	// Extract the "Temp" directory at the root of the archive file tree
	zipExtractDirectory(Archive, "Temp", zipDrive)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = zipExtractDirectory(<Archive> , <Directory> [, <Destination> [, <Options> [, <WLanguage procedure> [, <Progress>]]]])`
---

**`<Result>: (Integer)`**



- 0 if the files have been extracted,

- An error code (value greater than 0) otherwise. For more details on these error codes, see the [Remarks](#NOTE0_1).




**`<Archive>: (Character string or zipArchive variable)`**

Name of the archive to be used.
This name can correspond to:

- an archive name defined with [zipOpen](../WDLang3/3082044.md) or [zipCreate](../WDLang3/3082003.md).

- the name of a variable of type [zipArchive](../WDLang3/1000018679.md). 
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [zipArchive](../WDLang3/1000018679.md) variables are not available in Java.




**`<Directory>: (Character string)`**

Archive file directory to be extracted. This directory can be an absolute path or a path relative to the root of the archive file tree.

**`<Destination>: (Optional character string)`**

Destination path of extracted files:

- Optional character string: Files are extracted to the specified path, to which the file's memorized tree structure is added (the disk is not preserved). The specified path is created if it does not exist.

- Optional constant:
	


|   |   |
| --- | --- |
| *zipDirectory*<br>(Default value) | Extraction into the current directory without restoring the tree structure of the files (if it was stored). |
| *zipDrive* | Extraction:<br><br>	- to the initial location of the files if it was stored and if the drive exists.<br><br>	- while restoring the tree structure of the files on the current drive if the drive or the stored directory does not exist.<br><br>	- in the current directory if only the name and extension of the files have been stored.<br><br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. The directories have no root.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant and *zipDirectory* will have the same effect.<br>**Archives in format 7z**: This constant will have the same effect as the *constant zipDirectory*. |
| *zipNone* | Extraction into the current directory without restoring the tree structure of the files (if it was stored). |






**`<Options>: (Optional Integer constant)`**

Configure the extraction (if &lt;Destinations&gt; corresponds to a character string):



|   |   |
| --- | --- |
| *zipOverwrite* | During the extraction, the existing read-only files are automatically overwritten by the extracted files.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |



**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure that will be called if an error occurs when extracting files. 
For more details on this procedure, see [Parameters of the error handling procedure used by zipExtractDirectory](../WDLang3/1000025747.md).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This procedure must be a server procedure.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is not allowed.

**`<Progress>: (Control name or procedure name)`**

Progress bar management mode. This parameter can correspond to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the name of a Progress Bar control found in a window. The progress bar will display the progress regarding the extraction of all the files used.  

- the name of a WLanguage procedure. 
	For more details on this procedure, see [Parameters of the progress bar management procedure used by zipExtractDirectory](../WDLang3/1000025748.md).




**If you handle an**: 

- **in TAR, gzip or TGZ (TAR.GZ) format**ProgressBar is updated only when each file has been extracted. 

- **in CAB and RAR format**, the progress bar is refreshed at the end of the extraction of each file.

## Remarks


### Error codes
<a name="error_codes_ELTPARAGRAPHE000181"></a>

The following error codes are returned:

- 1: Path passed as parameter does not exist.

- 2: Access denied: user does not have sufficient rights.

- 3: The archive is corrupt.

- 4: The path does not exist in the archive.

- 6: Sub-archive files are not in order (case of extraction from a multi-part archive).

- 21: The password specified is not correct.




The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).

Remarks: 

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Only archives in ZIP, TAR, gzip and TGZ (TAR.GZ) formats are available.

- ![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Only ZIP archives are available.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The CAB format is not available. 

- RAR is supported up to and including version 5.



<a name="NOTE0_2"></a>


### Filter
<a name="filter_ELTPARAGRAPHE000222"></a>

If a filter has been set on the archive with [zipSelectFile](../WDLang3/1000026152.md), only the files that match the filter will be extracted.
<a name="NOTE0_3"></a>


### Extracted file
<a name="extracted_file_ELTPARAGRAPHE000234"></a>

The extracted files are not deleted from the archive. To delete one file or all the files from the archive, use [zipDeleteFile](../WDLang3/3082041.md) or [zipDeleteAll](../WDLang3/3082051.md).

### Extraction and password
<a name="extraction_and_password_ELTPARAGRAPHE000251"></a>

If the file is not encrypted and if [zipPassword](../WDLang3/3082053.md) was used:

- Archive in WDZ format: The file is still extracted.

- Archive in ZIP format: An error appears.

### Stored path
<a name="stored_path_ELTPARAGRAPHE000266"></a>

The table below presents the paths stored in the archive according to:

- the access path to the file,

- the stored path section.




The current directory is: "C:\\Temp".


|   |   |   |   |   |
| --- | --- | --- | --- | --- |
| **zipAddFile** | **File location** | *zipNone* | *zipDirectory* | *zipDrive* |
| zipAddFile("Archi", <br>"File.txt") | C:\\Temp\\File.txt | File.txt | File.txt | File.txt |
| zipAddFile("Archi", <br>"Data\\File.txt") | C:\\Temp\\Data\\File.txt | File.txt | Data\\File.txt | Data\\File.txt |
| zipAddFile("Archi", <br>"D:\\Data\\File.txt") | D:\\Data\\File.txt | File.txt | Data\\File.txt | D:\\Data\\File.txt |



**Remark**: If the constant *zipDisk* is used: 

- the WDZ format stores the full path of the file (including the drive letter). 

- the ZIP format does not store the drive letter.

- the 7z format stores the directories only.
