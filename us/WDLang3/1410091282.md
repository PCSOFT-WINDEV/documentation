


## &lt;ftpConnection variable&gt;.DirExist (Function)

***In french: &lt;Variable ftpConnexion&gt;.RepExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks for a directory on an FTP server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

<a name="1410091242_Exemple2"></a>

```wl
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Check for directory on FTP server
ResDirExist = MyFTPConnection.DirExist("/Documents/File")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <FTP connection>.RepExist(<Directory>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the directory exists, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.

**`<Directory>: (Character string)`**

Name and absolute (or relative) path of the directory to check for. The different parts of the path are separated by "slashes" ("/").



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000231"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000264"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
