
## Speech synthesis in the mobile applications

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000143"></a>
The phones can talk!

WINDEV Mobile offers a number of functions that make it easy to use this feature in your Android or iOS mobile applications.

## How to?
<a name="how_ELTTEXTE000167"></a>


### Necessary conditions
<a name="necessary_conditions_ELTPARAGRAPHE000026"></a>

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Speech synthesis functions are only available on devices with Android 1.6 or higher (API level 4).
A fatal error occurs if the function is used with an earlier system version. 
To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Speech synthesis functions are only available on devices with iOS 7 and higher. The speech synthesis does not work on the iOS 8 emulators.
<a name="NOTE2_2"></a>


### Using the speech synthesis in the application
<a name="using_the_speech_synthesis_the_application_ELTPARAGRAPHE000051"></a>

To use the speech synthesis in the application:

1. Initialize the options for managing the voice synthesis with [SpeechSynthesisInitialize](../WDLang3/1000020171.md). 
	Note: This function is not mandatory. If the parameters of speech synthesis have not been defined beforehand, the default parameters will be used and the language for text reading will be the first language available for the engine of speech synthesis according to the following sequence:

	- Application language (default language or language defined by [Nation](../WDLang1/3054014.md)), 

	- Device language,

	- English,

	- Default language of the speech synthesis engine.




2. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Define (if necessary) the reading volume with [VolumeModify](../WDLang3/1000020169.md) (*volumeMusic* constant>.

3. Start the reading with the following functions: 
	


|   |   |
| --- | --- |
| [SpeechSynthesisReadFile](../WDLang3/1000020172.md) | Reads the content of the specified file by using the engine for speech synthesis found on the device. |
| [SpeechSynthesisReadText](../WDLang3/1000019805.md) | Reads the specified text using the device's text-to-speech engine. |




Remarks: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) If no engine for speech synthesis is installed on the device, its download will be automatically proposed.

- If a new read operation is triggered while another read operation is in progress, the new read operation will start once the first one is over. 
	To know whether a read operation is in progress on the speech synthesis engine, use [SpeechSynthesisInProgress](../WDLang3/1000020173.md). 
	To stop the current read operations, use [SpeechSynthesisStop](../WDLang3/1000020174.md).
