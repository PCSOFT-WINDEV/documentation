
## NotifPushSubscribe (Function)

***In french: NotifPushAbonne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Subscribes the current Android application to a topic. The application will automatically receive notifications sent with [NotifPushSendSubscriber](../WDLang3/1410089872.md) for the specified topic.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Request notifications for the "score" topic
NotifPushSubscribe("score")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = NotifPushSubscribe(<Topic>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if subscribed successfully,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) is used to identify the error returned by the notification service.




**`<Topic>: (Character string)`**

Topic of the notifications to which to subscribe the application.
