
## GroupFirst (Function)

***In french: GroupePremier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads the first group of contacts in a Lotus Notes or Outlook address book.

When reading a group of contacts, the data found in this group is refreshed in the [Group structure](../WDLang3/1000008120.md). To retrieve the data for the current group of contacts, simply retrieve the values from the [Group structure](../WDLang3/1000008120.md).

**Attention** This function **does not** read the first group of contacts in an Outlook Express address book.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", ...
	"mail\julia.nsf", "C:\Users\Julia\AppData\Local\Lotus\Notes\Data\user.id")

// Read the first group of contacts
GroupFirst(SessionID)
// Add the contact groups found into a List Box control
WHILE mGroup.Out = False
	ListAdd(LIST_ContactGroups, mGroup.Name + TAB + mGroup.Description)
	GroupNext(SessionID)
END
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = GroupFirst(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the first group of contacts was read, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).

## Remarks




### Current group of contacts
<a name="current_group_contacts_ELTPARAGRAPHE000066"></a>

The mGroup.Out variable is used to find out whether there is a current group of contacts.
<a name="NOTE0_2"></a>




### Version of Outlook used
<a name="version_outlook_used_ELTPARAGRAPHE000074"></a>

The groups of contacts are not supported by Outlook 97. Therefore, no group of contacts can be found in this version of Outlook.
