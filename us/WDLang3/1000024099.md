


## &lt;Chart&gt;.Scatter3DMarkCaption (Function)

***In french: &lt;Graphe&gt;.Nuage3DLibelléGraduation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Specifies the label of a mark in a 3D Scatter chart.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CHART_MyChart.Scatter3DMarkCaption(grXCoordinate, 1, "January")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart control>.Scatter3DMarkCaption(<Mark axis> , <Value> , <Caption>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window editor).

**`<Mark axis>: (Integer constant)`**

Type of axis on which the marks will be displayed:


|   |   |
| --- | --- |
| *grXCoordinate* | X-axis. |
| *grYCoordinate* | Y-axis. |
| *grZCoordinate* | Z-axis. |



**`<Value>: (Real)`**

Value of the mark for which the label will be modified.

**`<Caption>: (Character string)`**

New mark label.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Managing marks
<a name="managing_marks_ELTPARAGRAPHE000199"></a>

To display the mark labels:

- a mark must exist at the specified value. Otherwise, the mark label will not be displayed.

- the mark must have a value. If there is a mark with no value, the label will not be displayed.




**Rappel**: The marks in a 3D Scatter chart can be defined:

- in the editor, in the Chart control description window ("General" tab). 

- programmatically, with [&lt;Chart&gt;.Interval](../WDLang3/1000024076.md).
