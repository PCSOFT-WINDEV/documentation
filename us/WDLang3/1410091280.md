


## &lt;zipArchive variable&gt;.StartAddingFile (Function)

***In french: &lt;Variable zipArchive&gt;.DébutAjoutFichier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Declares the start of the optimized addition of files to a CAB, ZIP, WDZ, 7z, TAR, gzip or TGZ (TAR.GZ) archive.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start optimized file additions
MyArchive.StartAddingFile()
// Add files to archive
FOR EACH FilePath OF arrFileList
	MyArchive.AddFile(FilePath)
END
// End optimized file additions 
MyArchive.EndAddingFile()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Archive>.StartAddingFile()`
---

**`<Result>: (Integer)`**



- 0 if the start of the file addition has been declared,

- an error code (value greater than 0) otherwise. For more details on these error codes, see the remarks.




**`<Archive>: (zipArchive variable)`**

Name of the variable of type [zipArchive](../WDLang3/1000018679.md) corresponding to the archive in which to add files.

<a name="NOTE0_1"></a>

## Remarks


### When to use optimized addition of files
<a name="when_use_optimized_addition_files_ELTPARAGRAPHE000209"></a>

For ZIP, WDZ and 7Z archives, some operations are performed each time a file is added, in order to get a valid archive. These operations can increase the time it takes to create an archive. 

Thus, it takes longer to add a series of files with [&lt;zipArchive variable&gt;.AddFile](../WDLang3/1000019050.md) than with [&lt;zipArchive variable&gt;.AddFileList](../WDLang3/1000019159.md). With [&lt;zipArchive variable&gt;.AddFileList](../WDLang3/1000019159.md), these operations are carried out only once. 

To get the same behavior with [&lt;zipArchive variable&gt;.AddFile](../WDLang3/1000019050.md), it is necessary to add the files between the **&lt;zipArchive variable&gt;.StartAddingFile** and [&lt;zipArchive variable&gt;.EndAddingFile](../WDLang3/1410091281.md) functions. 

Note: This function can only be used for ZIP, WDZ and 7Z archives. RAR archives are not supported.


### How to use optimized additions
<a name="how_use_optimized_additions_ELTPARAGRAPHE000252"></a>

For optimized additions:

1. Call **&lt;zipArchive variable&gt;.StartAddingFile**. The archive will wait for files to be added. 

2. Use [&lt;zipArchive variable&gt;.AddFile](../WDLang3/1000019050.md) to add the desired files. The function remains unchanged. 

3. Finish adding the files with [&lt;zipArchive variable&gt;.EndAddingFile](../WDLang3/1410091281.md). 




Remarks: 

- Calling a function other than [&lt;zipArchive variable&gt;.AddFile](../WDLang3/1000019050.md) between **&lt;zipArchive variable&gt;.StartAddingFile** and [&lt;zipArchive variable&gt;.EndAddingFile](../WDLang3/1410091281.md) will cause a fatal error.

- [&lt;zipArchive variable&gt;.EndAddingFile](../WDLang3/1410091281.md) must be used after **&lt;zipArchive variable&gt;.StartAddingFile** to obtain a valid archive.





### Error codes 
<a name="error_codes_ELTPARAGRAPHE000301"></a>

The following error codes are returned:

- 1: The path passed as parameter does not exist.

- 3: The archive is corrupted.
