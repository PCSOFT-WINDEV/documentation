


## grCategoryThumbnail (Function)

***In french: grVignetteCatégorie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes a category image in a Pie, Donut or Semi-circular chart.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grVignetteCat%E9gorie%20-%20HC%20N%B0001.gif&type=thumb)


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
grDeleteAll(CHART_Consumption)
grAddData(CHART_Consumption, 1, 1, 35)
grCategoryLabel(CHART_Consumption, 1, "Heating")
grCategoryThumbnail(CHART_Consumption, 1, IMG_Heating)
grCategoryColor(CHART_Consumption, 1, HTMLToRGB("#FF5722"))

grAddData(CHART_Consumption, 1, 2, 20)
grCategoryLabel(CHART_Consumption, 2, "Water")
grCategoryThumbnail(CHART_Consumption, 2, IMG_Water)
grCategoryColor(CHART_Consumption, 2, HTMLToRGB("#2196F3"))

grAddData(CHART_Consumption, 1, 3, 12)
grCategoryLabel(CHART_Consumption, 3, "EV charging")
grCategoryThumbnail(CHART_Consumption, 3, IMG_Car)
grCategoryColor(CHART_Consumption, 3, HTMLToRGB("#8BC34A"))

grAddData(CHART_Consumption, 1, 4, 18)
grCategoryLabel(CHART_Consumption, 1, "Household appliances")
grCategoryThumbnail(CHART_Consumption, 4, IMG_Household_appliances)
grCategoryColor(CHART_Consumption, 4, HTMLToRGB("#9C27B0"))

grDraw(CHART_Consumption)
```

## Syntax
<a name="SYNTAXE1"></a>

`grCategoryThumbnail(<Chart name> , <Index> , <Image>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.

**`<Index>: (Integer)`**

Data index in the series.

**`<Image>: (Character string or Image variable)`**

Category image. This image can correspond to: 

- a memo item,

- the path of an image file (or just the file name if the image is located in the same directory as the executable),

- the name of an Image control containing image. 

- a variable of type [Image](../WDLang1/1000019650.md). 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The image is reduced to be displayed in the corresponding segment. If the image or the segment is too small, the image will not be displayed. 

- By default, the thumbnail does not shrink or grow when the chart is resized. To allow the thumbnail to be resized, use [grParameter](../WDLang3/1000018337.md) with the *grThumbnailResizeEnabled* constant. 

- The category image and label can be displayed simultaneously. 

- [grAutoRefreshCategoryLabel](../WDLang3/3042071.md) has no impact on category thumbnails.
