


## grPPCMaximumValue (Function)

***In french: grPIValeurMaximale***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Specifies the maximum value used to calculate percentages in a Pictorial Percentage chart.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ChartImage is Image = "rocket.png"
grDeleteSeries(CHART_Percentage, 1)
nSum is int
FOR EACH ROW OF TABLE_Series
	nValue is int = COL_Data
	nSum += nValue
	grAddData(CHART_Percentage, 1, nValue)
END
grPPCMaximumValue(CHART_Percentage, nSum)
grPPCImage(CHART_Percentage, ChartImage)
grDraw(CHART_Percentage)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grPPCMaximumValue(<Chart> , <Maximum value>)`
---

**`<Chart>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window or page editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.

**`<Maximum value>: (Real)`**

New maximum value to be applied. This value must be positive. 
This value is set to 100 by default, so the data is expressed as a percentage. When this value is changed, the chart data is automatically recalculated.
