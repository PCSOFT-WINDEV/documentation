
## FTP constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


| Constant | Description | Used by |
| --- | --- | --- |
| **ftpAccess** | Date/time type: Date and time the file was last accessed | [FTPDate](../WDLang3/3040015.md), <br>[FTPTime](../WDLang3/3040013.md) |
| **ftpActiveMode** | **Active connection** to the FTP server. <br><br>In this mode, the client initiates the data connection. This type of connection may be refused by some protected FTP servers. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpASCIIMode** | File transfer in ASCII mode. This mode is used to transfer files between different operating systems, e.g. UNIX to Windows. The file is delivered in the ASCII format used by the receiving system. | [FTPSend](../WDLang3/3040014.md), <br>[FTPGet](../WDLang3/3040002.md) |
| **ftpBinaryMode** | File transfer in binary mode. In this mode, the file received is strictly identical to the file sent | [FTPSend](../WDLang3/3040014.md), <br>[FTPGet](../WDLang3/3040002.md) |
| **ftpConfigureMode** | Selects the FTP mode. Two modes are available:<br><br>- FTP functions use the Windows "wininet" module. This is the default operating mode for FTP functions.<br><br>- FTP functions support UTF-8 and use a module independent from Windows. Note: In this mode, [FTPCommand](../WDLang3/3040017.md) is not supported.<br><br><br> | [FTPConfigure](../WDLang3/1000020947.md) |
| **ftpConfigureReuseConnection** | Forces the use of the same FTP server connection between two requests. Two modes are available: <br><br>- The client/application opens a connection each time it sends a command, then closes it immediately.<br><br>- The client/application opens a connection when it sends the first command, and keeps this connection open as long as the server and client are exchanging data. After a given period of inactivity, the connection is automatically closed. <br><br><br> | [FTPConfigure](../WDLang3/1000020947.md) |
| **ftpCreation** | Date/time type: File creation date/time | [FTPDate](../WDLang3/3040015.md), <br>[FTPTime](../WDLang3/3040013.md) |
| **ftpDirectory** | Search for directories only | [FTPListFile](../WDLang3/3040018.md) |
| **ftpErrorAuthentication** | Identifies a connection error due to an authentication error | [FTPConnect](../WDLang3/3040016.md) |
| **ftpesConfigureSecureMode** | Changes FTPES encryption. Two modes are available: <br><br>- SSL encryption is applied to FTP data and commands. This is the default mode for functions in FTPES.<br><br>- SSL encryption is applied only to FTP commands. This mode may be required for some FTPES servers.<br><br><br><br><br>In previous versions, this constant corresponds to "ftpesParameterSecureMode". | [FTPConfigure](../WDLang3/1000020947.md) |
| **ftpExtendedPassiveMode** | **Extended passive connection** to the FTP server (EPSV command). <br><br>In this mode, the server initiates the data connection. This type of connection allows you to bypass some firewalls. <br><br><br><br>If the server does not support the extended passive mode (the FEAT command is sent to the server to get its capabilities), the connection is downgraded to simple passive mode. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpFile** | Search for files only | [FTPListFile](../WDLang3/3040018.md) |
| **ftpIgnoreDeprecated** | Ignores errors related to the use of deprecated algorithms (e.g. SHA-1 certificate signature). | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpIgnoreExpiredCertificate** | Ignores the certificate date. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpIgnoreInvalidCertificate** | Ignores the certificate. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpIgnoreInvalidCertificateName** | Ignores the site name specified in the certificate. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpIgnoreRevocation** | Ignores certificate revocation. | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpIgnoreUnsafeRenegotiation** | Ignores the error indicating that the server does not support secure renegotiation (RFC 5746). | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpModification** | Date/time type: Date and time the file was last modified | [FTPDate](../WDLang3/3040015.md), <br>[FTPTime](../WDLang3/3040013.md) |
| **ftpPassiveMode** | **Passive connection** to the FTP server (PASV command). <br><br>In this mode, the server initiates the data connection. This type of connection allows you to bypass some firewalls.<br><br><br><br>Note: If the connection to the server is established using IPV6, then the connection will be made in extended passive mode (passive mode does not support IPv6). | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpPassiveModeIgnoreIP** | **Passive connection** to the FTP server (PASV command). <br><br>When transferring files in passive mode, the server sets the port and IP address for data transfer. With this parameter, only the port is taken into account. The IP address is ignored.<br>This type of connection allows the use of FTP servers that return non-routable IP addresses but are reachable via the connection IP address | [FTPConnect](../WDLang3/3040016.md), [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpProxyNone** | Allows to cancel the use of the FTP proxy. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpProxyOpen** | Type of proxy to be used: FTP proxy requiring the "OPEN" command. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpProxySite** | Type of proxy to be used: FTP proxy requiring the "SITE" command. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpProxySOCKS5** | FTP proxy using the SOCKS5 protocol. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpProxyUserSeparate** | Type of proxy to be used: FTP proxy requiring the "USER" and "PASS" commands. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpProxyUserTogether** | Type of proxy to be used: FTP proxy requiring the "USER" command with a username and a password. | [FTPProxy](../WDLang3/1000019366.md) |
| **ftpSSLRequiredForAll** | Changes encryption to FTPES. SSL encryption applies to FTP data and commands. This is the default mode for functions in FTPES. | [ftpConnection](../WDLang3/1410090869.md) type |
| **ftpSSLRequiredForControl** | FTPES ecnryption: SSL encryption applies only to FTP commands. This mode may be required for some FTPES servers. | [ftpConnection](../WDLang3/1410090869.md) type |
