
## iCloudKeyValueWatch (Function)

***In french: iCloudCléValeurSurveille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the procedure called when the value of a key is changed in an Apple iCloud-based container of "key-value" pairs.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF iCloudKeyValueWatch(Callback_Observer) = True THEN
	Trace("Start observing")
END

INTERNAL PROCEDURE Callback_Observer(nEvent, arrKeys)
	sEventLabel, sKeyList is string
		
	SWITCH nEvent
		CASE iccvServerModification: sEventLabel = "Server modification".
		CASE iccvModificationInitialSynchronization: sEventLabel = "Initial synchronization"
		CASE iccvViolationQuota: sEventLabel = "Quota overrun".
		CASE iccvAccountChange: sEventLabel = "Account change".
		CASE iccvSynchronizationFailure: sEventLabel = "Synchronization failure"
		OTHER CASE
				sEventLabel = "Unknown"
	END
		
	Trace("------------------>>> " + sEventLabel)
		
	FOR EACH sKey OF arrKeys
		Trace(sKey)
		sKeyList += [" / "] + sKey
	END
	gsObserverReport += [CR] + sEventLabel + TAB + sKeyList
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = iCloudKeyValueWatch(<WLanguage procedure>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the observe procedure is enabled,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called when there is a change in the iCloud server. This procedure gets the reasons of the change. 

For more details on this procedure, see [Parameters of the procedure used by iCloudKeyValueWatch](../WDLang3/1410088759.md).
