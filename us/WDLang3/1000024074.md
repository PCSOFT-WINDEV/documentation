


## &lt;Chart&gt;.Exist (Function)

***In french: &lt;Graphe&gt;.Existe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence of a chart in memory. 



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Checks the existence of CHART_MyChart
ResExist = CHART_MyChart.Exist()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Chart control>.Exist()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the chart exists, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
