


## &lt;ftpConnection variable&gt;.CurrentDir (Function)

***In french: &lt;Variable ftpConnexion&gt;.RepEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets or sets the current directory on an FTP server (File Transfer Protocol).


<a name="sample_code"></a>

## Example

<a name="Exemple2"></a>

```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()

// Identify the current directory on the FTP server
ResCurrentDir = MyFTPConnection.CurrentDir()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the current directory

`<Result> = <FTP connection>.CurrentDir()`
---

**`<Result>: (Character string)`**



- Absolute name of the current directory on the FTP server,

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.


<a name="SYNTAXE2"></a>

### Setting the current directory

`<Result> = <FTP connection>.CurrentDir(<New current directory>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the current directory was modified,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.

**`<New current directory>: (Character string)`**

Name and full or relative path of the new directory. The different parts of the path are separated by "slashes" ("/").

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000318"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000351"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.
