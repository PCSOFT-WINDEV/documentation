


## &lt;Chart&gt;.SeriesLineType (Function)

***In french: &lt;Graphe&gt;.TypeTraitSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the type of line for a series found in a Line, Area, Scatter and Radar chart.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Defines dotted lines for series 2
CHART_MyChart.SeriesLineType(2, LineDotted)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart name>.SeriesLineType(<Series number> , <Type>)`
---

**`<Chart name>: (Control name)`**

Name of the Chart control to be manipulated (present in the window or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series for which the type of line must be defined.

**`<Type>: (Integer constant)`**

Type of line for the series: 



|   |   |
| --- | --- |
| *LineDash* | Line with dashes (---). |
| *LineDotAndDash* | Line mixing dots and dashes (.-.-.-). |
| *LineDotted* | Dotted line (.......). |
| *LineNone* | No line is drawn. Only points in the series are drawn (defined with [&lt;Chart&gt;.SeriesPointType](../WDLang3/1000024155.md)). <br><br> |
| *LineSolid* | Solid line. |
