


## &lt;zipArchive variable&gt;.AddDirectory (Function)

***In french: &lt;Variable zipArchive&gt;.AjouteRépertoire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds all the files found in a directory and in its sub-directories into an archive and compresses them. This function can be used on CAB, ZIP, WDZ, 7z, TAR, gzip and TGZ (TAR.GZ) archives.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
MyArchive is zipArchive
// Create the archive
ResCreate = MyArchive.Create("C:\Temp\Archive.zip")
IF ResCreate = 0 THEN
	// Add all the directory files 
	ResAddDir = MyArchive.AddDirectory(...
			"C:\MyDirectory\MyFiles", True, zipDrive)
END
// Display an error message if the addition was not performed 
IF ResAddDir <> 0 THEN Error(zipMsgError(ResAddDir))
```

## Syntax

### Adding the directory files while specifying the path to store

`<Result> = <Archive>.AddDirectory(<Directory path> [, <Subdirectory> [, <Path section to store> [, <WLanguage procedure> [, <Progress>]]]])`
---

**`<Result>: (Integer)`**



- 0 if the addition was performed,

- An error code (value greater than 0) otherwise. For more details on these error codes, see the Remarks.




**`<Archive>: (zipArchive variable)`**

Name of a variable of type [zipArchive](../WDLang3/1000018679.md) corresponding to the archive in which the contents of the directory must be added.

**`<Directory path>: (Character string)`**

Path of directory that will be added into the archive (up to 260 characters). This path can be a full path or a path relative to the current directory. The function returns an error if this parameter corresponds to an empty string ("").
The size of the files found in this directory must be less than 4 GB. Otherwise, an error occurs.

**`<Subdirectory>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default value) if the sub-directories must be added,

- <u><u><u><u>False</u></u></u></u> if subdirectories are not to be added.




**`<Path section to store>: (Optional constant)`**

Path section to store for each file in the archive:


|   |   |
| --- | --- |
| *zipDirectory*<br>(Default value) | Stores the different directories found in the file path as well as the file name and extension. For example: \\Directory\\Files\\FileName.pdf |
| *zipDrive* | Store the full and absolute path of file (name of disk, name of directories, file name and file extension). For example: C:\\Directory\\Files\\FileName.pdf<br>**For WDZ** format: The full path of the file (including drive letter) is stored..<br>**For ZIP** format: The drive letter is not memorized. <br>**7z format**: This constant and *zipDirectory* will have the same effect.<br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available as there is no root for the drive.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant has the same effect as the *zipDirectory*. |
| *zipRelative* | The path passed as parameter is considered as being the root of the archive. The stored path for all files and sub-directories is given in relation to this root. <br>Thus, if the added directory is: "C:\\Temp\\Doc" containing the following items:<br><br>- the Test1.doc file, <br><br>- the Test2.doc file is located in the SYS subdirectory, <br><br><br>the stored information will be relative to the "C:\\Temp\\Doc" directory:<br><br>- Test1.doc, <br><br>- SYS\\Test2.Doc.<br><br><br> |


**Archive in .CAB** format: none of these constants are taken into account. Indeed, the .CAB format cannot be used to store the paths inside the archive.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of WLanguage procedure that will be called before adding each file. This procedure allows you to archive a tree structure while omitting one or more files. 
For more details on this procedure, see [Parameters of the procedure used by &lt;zipArchive variable&gt;.AddDirectory to manage the addition of files](../WDLang3/1000025732.md). 

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This procedure must be a server procedure.

**`<Progress>: (Control name or procedure name)`**

Progress bar management mode. This parameter can correspond to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) the name of a Progress Bar control found in a window. The progress bar will display the addition and compression progress of the file being managed.  

- the name of a WLanguage procedure. 
	For more details on this procedure, see [Parameters of the procedure used by &lt;zipArchive variable&gt;.AddDirectory to manage progress bars](../WDLang3/1000025733.md). 




**If you're handling an archive in TAR, gzip or TGZ (TAR.GZ)**format, the ProgressBar is updated only when each file has been added.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000491"></a>

Adding files into an archive can be performed if:

- The archive exists (archives are created using [&lt;zipArchive variable&gt;.Create](../WDLang3/1000019160.md)).

- The archive is accessible in read/write.

- The archive is a single-part archive.

- The size of the file is less than 4 GB.




**Caution**:

- **CAB archives**: Files must be added immediately after the archive is created. This format cannot be used to add files into an existing archive.

- **RAR archives**: This function is not available.

- **Archives in 7z** format: The archive is fully compressed each time the **function is called &lt;zipArchive variable&gt;.AddDirectory**.




The maximum number of files that can be included:

- in a WDZ file: 232-1.

- in a ZIP file: 65535. 

- in a CAB file: 65535. 




**Remark**: If the constant *zipEntête64* is used when creating the archive (function [&lt;zipArchive variable&gt;.Create](../WDLang3/1000019160.md)), it will be possible to create archives larger than 4 gigas..
Reminder:

<a name="NOTE0_2"></a>


### Compression level
<a name="compression_level_ELTPARAGRAPHE000544"></a>

The files added into a zip archive are compressed by default. The compression level of files added into an archive can be modified by [zipCompressionLevel](../WDLang3/3082054.md).
<a name="NOTE0_3"></a>


### Error codes
<a name="error_codes_ELTPARAGRAPHE000557"></a>

The following error codes are returned:

- 1: The path passed as parameter does not exist.

- 2: Access denied: user does not have sufficient rights.

- 3: The archive is corrupted.

- 4: The path does not exist in the archive.

- 5: Unable to write to the archive.

- 7: The file already exists in the archive.

- 8: An archive cannot be added to itself. For example, "MyArchive" cannot be added to "MyArchive".




The message corresponding to the error code is returned by [zipMsgError](../WDLang3/3082034.md).
<a name="NOTE0_4"></a>


### Adding a file that is already found in the archive
<a name="adding_file_that_already_found_the_archive_ELTPARAGRAPHE000580"></a>

An error occurs when adding a file that is already found in the archive. A file is identified by its stored path. Therefore, two files with the same name and with the same relative path cannot be added into an archive.
<a name="NOTE0_5"></a>


### Index of files in the archive
<a name="index_files_the_archive_ELTPARAGRAPHE000590"></a>

When a file is added into an archive, an index is automatically assigned to the file. This index corresponds to the order in which the files are included in the archive. To select a file in the archive, you can use:

- The index of the element. (Note: the index of an element can be known using the [&lt;zipArchive variable&gt;.FindFile](../WDLang3/1000026330.md) function)

- The stored path of the element.
