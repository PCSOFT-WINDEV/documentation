
## WebSocketClientConnect (Function)

***In french: WebSocketClientConnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to establish a **non-secure connection** (ws://) with a WebSocket server. Once the connection is established, the WebSocket can be handled like a standard socket, thus allowing you to use [SocketRead](../WDLang3/3070014.md), [SocketWrite](../WDLang3/3070002.md), [SocketClose](../WDLang3/3070015.md) or [SocketExist](../WDLang3/3070013.md).

**Remarks**: 

- This function has two syntaxes. A synchronous (with a timeout and a return value) and an asynchronous connection syntax (with a callback procedure).

- [SocketChangeTransmissionMode](../WDLang3/3070005.md) will have no effect with a socket created with **WebSocketClientConnect**. The socket uses the *SocketNoEndTag* mode.

- [WebSocketClientConnectSSL](../WDLang3/1410087752.md) is used to establish a **secure SSL connection** (wss://) with a WebSocket server.

## Example


```wl
// Connects to WebSocket server in synchronous mode
// ws://myserver.com/MyWebSocketServerProject
IF WebSocketClientConnect("client", "myserver.com", 80, "/MyWebSocketServerProject") THEN
	// Sends a message to the echo server
	IF SocketWrite("client", "Hello world!") THEN
		// Retrieves the server response
		sMsg is string = SocketRead("client", True)
		ToastDisplay("server response: " + sMsg)
	END
END
```

```wl
// Connects to WebSocket server in asynchronous mode
// ws://192.168.100.1/MyWebSocketServerProject
WebSocketClientConnect("client", WebSocketClientConnect_Callback, ...
	"192.168.100.1", 80, "/MyWebSocketServerProject")

INTERNAL PROCEDURE WebSocketClientConnect_Callback(nEvent, sMessage)
	SWITCH nEvent
		CASE SocketOpening
			SocketWrite("client", "Send message from the browser.")
		CASE SocketMessage
			Info("Server message received: " + sMessage)
		CASE SocketClosing
			Info("Socket closed", sMessage)
		CASE SocketError
			Error("Socket error")
	END
END
```

## Syntax
<a name="SYNTAXE1"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This syntax is not available in Browser code
### Establishing a synchronous connection

`<Result> = WebSocketClientConnect(<Socket name> , <Server address> [, <Port number> [, <Path> [, <Protocols> [, <Maximum timeout>]]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the connection was established,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Socket name>: (Character string)`**

Name that will be given to the connection opened on the socket. This name will be used by all socket functions.

**`<Server address>: (Character string)`**

Server address. This address can be specified as follows:

- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).

- URL containing the server name (www.windev.com for example). This syntax is recommended.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The address can also correspond to the IP address returned by [NetIPAddress](../WDLang3/3056023.md).![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The address must be the server IP address (not the server name).

**`<Port number>: (Optional integer)`**

Port number of the socket. By default, this parameter is 80 (HTTP port).

**`<Path>: (Optional character string)`**

Path to the virtual directory of the server (if any). This path must begin with "/".
In the case of a WebSocket server developed with WINDEV, this path corresponds to the name of the deployed project preceded by "/". For example: "/MyWebSocketServerProject".
By default, or if this parameter is an empty string (""), the path corresponds to "/".

**`<Protocols>: (Optional character string)`**

List of protocols the server must support to establish the connection (e.g., "mqtt,soap"). In this list, the different protocols are separated by a comma (","). A (non-exhaustive) list of protocols can be found here: [https://www.iana.org/assignments/websocket/websocket.xml](https://www.iana.org/assignments/websocket/websocket.xml)

**`<Maximum timeout>: (Optional integer or optional Duration)`**

Maximum timeout (in milliseconds) for establishing the connection. This parameter can correspond to: 

- an integer representing the number of milliseconds,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 10 ms). 


This timeout is set to 5000 milliseconds by default (5 seconds).

### Establishing an asynchronous connection

`WebSocketClientConnect(<Socket name> , <WLanguage procedure> , <Server address> [, <Port> [, <Path> [, <Protocols>]]])`
---

**`<Socket name>: (Character string)`**

Name that will be given to the connection opened on the socket. This name will be used by all socket functions.

**`<WLanguage procedure>: (Procedure name)`**

Name of the procedure called when the connection to the server is established. This procedure can be used to send a message to the server with [SocketWrite](../WDLang3/3070002.md), for example.
For more details on this procedure, see [Parameters of the procedure used by WebSocketClientConnect](../WDLang3/1410087754.md).
Caution: The procedure is called in the application's main thread:

- You can access UI controls from the procedure.

- The process should not be too long, since this could block the user. 




**`<Server address>: (Character string)`**

Server address. This address can be specified as follows:

- IP address in XXX.XXX.XXX.XXX format (e.g. 125.5.110.100).

- URL containing the server name (www.windev.com for example). This syntax is recommended.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The address can also correspond to the IP address returned by [NetIPAddress](../WDLang3/3056023.md).![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The address must be the server IP address (not the server name).

**`<Port>: (Optional integer)`**

Port number of the socket. By default, this parameter is 443 (HTTPS port).

**`<Path>: (Optional character string)`**

Path to the virtual directory of the server (if any). This path must begin with "/".
In the case of a WebSocket server developed with WINDEV, this path corresponds to the name of the deployed project preceded by "/". For example: "/MyWebSocketServerProject".
By default, or if this parameter is an empty string (""), the path corresponds to "/".

**`<Protocols>: (Optional character string)`**

List of protocols the server must support to establish the connection (e.g., "mqtt,soap"). In this list, the different protocols are separated by a comma (","). A (non-exhaustive) list of protocols can be found here: [https://www.iana.org/assignments/websocket/websocket.xml](https://www.iana.org/assignments/websocket/websocket.xml)
