


## grIncreaseData (Function)

***In french: grIncrémenteDonnée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a value to a data in a chart. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Adds the value 7 to the second data of the first series
grIncreaseData("MyChart", 1, 2, 7)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grIncreaseData(<Chart name> , <Series number> , <Index> , <Value>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series into which a value will be added. If the specified series does not exist, the chart designer creates as many series as necessary in order to get a consistent matrix. All the created series are initialized to 0.

**`<Index>: (Integer)`**

Data index in the series. If the specified data does not exist, the chart designer creates as many data as necessary in order to get a consistent data matrix. The created data is initialized to 0.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The index of the data in the series must be a strictly positive integer.

**`<Value>: (Integer or real)`**

Value that will be added to the specified data.

<a name="NOTE0_1"></a>

## Remarks


### Types of charts
<a name="types_charts_ELTPARAGRAPHE000122"></a>

For the Pie charts, only the data found in the first series will be used.
<a name="NOTE0_2"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000131"></a>

- The data defined by **grIncreaseData** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).

- A series can contain up to 8000 elements.

- A Pie chart cannot be drawn if the data found in the first series is null.
