
## WLanguage procedure called by NearbyShareAcceptConnection (Progress)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [NearbyShareAcceptConnection](../WDLang3/1410090646.md) to track the data transfer progress. This procedure gets the status of the current transfer.

**Note**: Binary buffers are always sent in a single block.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareAcceptConnection(gsNearbyDeviceID, ReceptionCallback, ProgressCallback)
	INTERNAL PROCEDURE ReceptionCallback(sDeviceID is string, nTransferID is 8-byte int, 
					nType is int, data)
		STC_Received_message_information = [
			Message received from the following device: [%sDeviceID%]
			Transfer ID: [%nTransfertID%]
		]
		SWITCH nType
			CASE nsBuffer
				sMessage is string = data
				EDT_Message_received = sMessage
				EDT_Message_received.State = Inactive
			CASE nsFile
				BTN_Open_file_received.State = Active
				gsFileReceived = data
			END
	END
	INTERNAL PROCEDURE ProgressCallback(sDeviceID is string, nTransferID is 8-byte int, 
		nState is int, nSizeReceived is 8-byte int, 
		nTotalSize is 8-byte int)
		Message is string
		SWITCH nState
			CASE nsInProgress
				Message = [
						Transfer in progress: 
						[%Round(nSizeReceived / nTotalSize * 100, 2)%]% 
						of data was sent.
						]
				ToastDisplay(Message)
			CASE nsCompleted
				Message = [
					Data transfer completed: 
					[%Round(nSizeReceived / nTotalSize * 100, 2)%]% 
					of data was sent.
					]
				ToastDisplay(Message)
			CASE nsError
				ToastDisplay("Transfer error" + CR + ErrorInfo())
			CASE nsCanceled
				ToastDisplay("Data transfer canceled")
		END
	END
```

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareAcceptConnection_Callback_Progress(<Sending device ID> , <Transfer ID> , <Status> , <Size received> , <Total size>)`
---

**`<Sending device ID>: (Character string)`**

Identifier of the sending nearby device.

**`<Transfer ID>: (Integer)`**

Identifier of the current transfer.

**`<Status>: (Integer constant)`**

Transfer status. This parameter can correspond to one of the following constants: 



|   |   |
| --- | --- |
| *nsCanceled* | Transfer canceled. |
|  *nsCompleted* | Transfer completed. |
| *nsError* | Transfer error. |
| *nsInProgress* | Transfer in progress. |



**`<Size received>: (Integer)`**

Size of data already received (in bytes). 

**`<Total size>: (Integer)`**

Total size of data transferred (in bytes).
