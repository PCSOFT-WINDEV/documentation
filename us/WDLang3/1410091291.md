
## wdbaasEditUser (Function)

***In french: wdbaasModifieUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Updates a user in the WEBDEV OAuth authentication server. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection parameters
param is OAuth2Parameters
param.ClientID = "d07c7d45-103c-48ad-a6b2-1bb9354eb947"
param.ClientSecret = "e260eeb0-15fb-4db7-964f-a72de7324e0d"
param.TokenURL = "https://serveur/oauth2/v1/token"
param.GrantType = gtClientCredentials
param.Scope = "wdbaas:users:readwrite"
// Connection
admin_token is AuthToken = AuthIdentify(param)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END
// New user details
user is gpwUser
user.Login = "Test2"
user.Email = "test2@gmail.com"
user.FirstName = "bob dylan"
user.Enabled = True
// Modify the user
IF NOT wdbaasEditUser(admin_token, User_ID, user)
	Error(ErrorInfo())
	RETURN
END
// Get user details
updated_user is gpwUser = wdbaasUserInfo(admin_token, User_ID)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END
Trace(updated_user.Login, updated_user.Email, updated_user.ID)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = wdbaasEditUser(<Token> , <User identifier> , <User>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if user information has been updated,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.  




**`<Token>: (AuthToken variable)`**

Name of the [AuthToken](../WDLang3/1000022220.md) variable corresponding to the authentication token on the OAuth server. 

**`<User identifier>: (Integer)`**

User ID. This identifier is created using [wdbaasCreateUser](../WDLang3/1410091289.md).  

**`<User>: (gpwUser variable)`**

Name of the [gpwUser](../WDLang6/1000021088.md) variable containing the new user details.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000173"></a>

To use user management functions on a WEBDEV OAuth server, you need to define permissions for the OAuth credentials. These permissions are defined in WEBDEV's BaaS administration site. 

For example, you can grant the following permissions:

- Create users only.

- Read user information only.

- All (read, create, modify, delete).

- etc. 




For more details, see [BaaS administration site](../WDLang3/1410086668.md).
