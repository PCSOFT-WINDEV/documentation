
## WidgetDisplay (Function)

***In french: WidgetAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Refreshes a Widget window and runs the "Refresh widget" event. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WidgetDisplay(WIN_Widget1)
```


<a name="Exemple2"></a>

```wl
// "Refresh the WIN_Widget widget" event
// Refreshes the APT 
RefreshAPT()

WidgetDisplay(WIN_Details)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`WidgetDisplay([<Window used>])`
---

**`<Window used>: (Optional window name)`**

Name of the Widget window to be refreshed. 

![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) If this parameter is not specified or is an empty string (""), the current window will be manipulated.![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The name of the window must be between quotation marks. If this parameter is not specified, all the widget windows in the application will be refreshed. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Displaying the Widget window
<a name="displaying_the_widget_window_ELTPARAGRAPHE000048"></a>

Widget windows are displayed by the process that manages the device's home screen. The refresh of the display is not performed permanently but in the following cases only: 

- After adding a new instance of the widget to the Home screen.

- After clicking the widget (or one of its controls). 

- When the content of the widget is updated. 




**WidgetDisplay** forces the display to be refreshed. This function also runs the "Refresh widget" event in the Widget window.
