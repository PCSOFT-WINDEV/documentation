


## grDraw (Function)

***In french: grDessine***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws a chart according to the specified parameters.

**Remarks**: 

- **grDraw** takes into account the new parameters specified since the last call to this function.

- This function must not be used for the Chart controls found in the report editor.


![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Draw a chart created programmatically
grDraw("MyChart")
```
<a name="Exemple2"></a>

```wl
// Draw a chart in a Chart control
grDraw(CHART_MyChart)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grDraw(<Chart name>)`
---

**`<Chart name>: (Control name or character string)`**

This name can correspond to:

- the name of the chart to draw, defined by [grCreate](../WDLang3/3042005.md).

- the name of Chart control (found in a window or in a page).  


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

## Remarks


### Creating and drawing a chart programmatically
<a name="creating_and_drawing_chart_programmatically_ELTPARAGRAPHE000119"></a>

To create and draw a chart:

- create the chart ([grCreate](../WDLang3/3042005.md)),

- add data ([grAddData](../WDLang3/3042023.md), [grStockAddData](../WDLang3/3042009.md) and [grScatterAddDataXY](../WDLang3/3042032.md)),

- define the chart destination with the following functions: 

	- [grDestinationBMP](../WDLang3/3042018.md), 

	- [grDestinationControl](../WDLang3/3042020.md), 

	- [grDestinationEMF](../WDLang3/3042017.md), 

	- [grDestinationWnd](../WDLang3/3042031.md),

	- [grDestinationImage](../WDLang3/1000020952.md),

	- [grDestinationWMF](../WDLang3/3042019.md). 




- draw the chart (**grDraw**).



<a name="NOTE0_2"></a>


### Charts and threads
<a name="charts_and_threads_ELTPARAGRAPHE000168"></a>

A single chart can be handled in a thread.

Consequences:

- Two threads cannot handle the same chart.

- A chart created in a thread is automatically destroyed at the end of this thread. The chart exists in the thread that contains the call to [grCreate](../WDLang3/3042005.md).




**Note**: It is not advisable to call the function **grDraw FUNCTION** function in a thread. The call to this function outside the main thread may trigger deadlocks and/or unexpected behaviors.

### Simultaneous calls
<a name="simultaneous_calls_ELTPARAGRAPHE000191"></a>

**grDraw** is a non-blocking function. If he chart is drawn with an animation, the function will give control back as soon as the animation starts. Therefore, if several charts are drawn in the same window, the controls can be animated simultaneously.
