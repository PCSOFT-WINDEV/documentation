## Implementing the GPS management
<a name="implementing_the_gps_management_ELTTEXTE000554"></a>


### Checking whether the GPS is enabled
<a name="checking_whether_the_gps_enabled_ELTPARAGRAPHE000080"></a>

To check whether the GPS is enabled, all you have to do is use [GPSStatus](../WDLang3/1000019207.md). 

Example: 


```wl
// Is the GPS enabled?
IF GPSStatus() = gpsEnabled THEN
	Error("The GPS cannot operate.", ...
		"It must be enabled to access this application.")
	EndProgram()
END
```



### Be notified when the GPS status changes
<a name="notified_when_the_gps_status_changes_ELTPARAGRAPHE000092"></a>

To be notified when the GPS status changes, simply call [GPSStatus](../WDLang3/1000019207.md) and specify the name of the procedure that will handle the current GPS status.  

Example: 


```wl
GPSStatus(_ChangeOfGPSStatus)
```


The procedure code is as follows: 


```wl
PROCEDURE _ChangeOfGPSStatus(Status)

IF CurrentStatus = Status THEN RETURN
CurrentStatus = Status
EndTimerSys(TIMER_RETRIEVAL)
SWITCH Status
	CASE gpsEnabled 
		// The provider was enabled by the user.
		STC_Status = "GPS enabled"
	CASE gpsDisabled 
		// The provider was disabled by the user.
		STC_Status = "GPS disabled"
	CASE gpsOffService 
		// The provider is off service.
		STC_Status = "GPS off service"
	CASE gpsUnavailable 
		// The provider is temporarily unavailable.
		STC_Status = "GPS unavailable"
	CASE gpsAvailable 
		// The provider is available.
		STC_Status = "GPS available"
		// Requests location tracking with a maximum time between two calls to 
		// GPSFollowMovement(_GetLocation, 1000)			
	OTHER CASE		
END
```
In this procedure, if GPS is enabled, a specific procedure is used to track the device. 
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This feature is not available.


### Position tracking
<a name="position_tracking_ELTPARAGRAPHE000112"></a>

To track the device's location, simply use [GPSFollowMovement](../WDLang3/1000019206.md) and specify the name of the procedure that will handle location changes.  

Example: 


```wl
GPSFollowMovement(_GetLocation, 1000)
```


The code of the procedure can be as follows: 


```wl
PROCEDURE _GetLocation(MyLocation)
// Update the information about the location
// Latitude and longitude
LIB_Latitude = StringBuild("Latitude: %1", MaPosition.Latitude)
LIB_Longitude = StringBuild("Longitude: %1", MaPosition.Longitude)
// Speed
IF MyLocation.SpeedValid = True THEN
	LIB_Vitesse = StringBuild("Speed: %1 m/s", MaPosition.Vitesse)
	IMG_SPEED_VALIDITY = IMG_OK
ELSE
	LIB_Vitesse = "Speed: N/A"
	IMG_SPEED_VALIDITY = IMG_NOTOK
END
// Altitude
IF MyLocation.AltitudeValid = True THEN
	LIB_Altitude = StringBuild("Altitude: %1 m", MaPosition.Altitude)
	IMG_ALTITUDE_VALIDITY = IMG_OK
ELSE
	LIB_Altitude = "Altitude: N/A"
	IMG_ALTITUDE_VALIDITY = IMG_NOTOK
END
// Direction
IF MyLocation.DirectionValid = True THEN
	LIB_Direction = StringBuild("Direction: %1 ° E", MaPosition.Direction)
	IMG_DIRECTION_VALIDITY = IMG_OK
ELSE
	LIB_Direction = "Direction: N/A"
	IMG_DIRECTION_VALIDITY = IMG_NOTOK
END
STC_Last_update = StringBuild("Last update on %1 at %2.", ...
	DateToString(MyLocation.MeasurementDate.Date), ...
	TimeToString(MyLocation.MeasurementDate.Time))
STC_Last_update.Visible = True
```


In this code, **MyLocation** is a [geoPosition](../WDLang3/1000019191.md) variable. The properties of this type of variable are used to find out the location characteristics. 

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The WLanguage procedure used requires specific parameters.


### Ending the use of GPS functions
<a name="ending_the_use_gps_functions_ELTPARAGRAPHE000137"></a>

Depending on the selected settings and on the call frequency, geolocation functions can consume a lot of resources on the device (battery, bandwidth, etc.). [GPSEnd](../WDLang3/1000019210.md) must be called when the location functions are no longer used by the application.

## Implementing geolocation tracking
<a name="implementing_geolocation_tracking_ELTTEXTE000596"></a>


### Overview
<a name="overview_ELTPARAGRAPHE000156"></a>

On a mobile device, you may need to track the user's location even when the application is closed or in the background. 

You should be able to set up tracking while using as little resources as possible, especially when it comes to battery. This can be achieved by reducing accuracy, compared to standard GPS tracking.
<a name="NOTE3_2"></a>


### Principle and implementation
<a name="principle_and_implementation_ELTPARAGRAPHE000165"></a>

To manage location tracking: 

1. Enable location tracking with [geoTrackingEnable](../WDLang3/1000021583.md). 

2. Define the procedure called when changing the location with [geoTrackingProcedure](../WDLang3/1000021585.md). This function must be used in the initialization process of project. 




It is possible to: 

- Disable location tracking with [geoTrackingDisable](../WDLang3/1000021584.md). 

- Get the tracking status with [geoTrackingStatus](../WDLang3/1000021592.md). 




Caution: Low precision tracking. The events are sent only if significant changes of location occur and at time intervals exceeding several minutes. For information, the sending conditions per platform are as follows: 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The events regarding the change of location are not sent if the location did not change by more than 500 meters, or if the time interval is less than 5 minutes (December 2014). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Location change events are sent at intervals that range from 30 seconds to 10 minutes, depending on the distance between locations.


For a more precise tracking, you must use [GPSFollowMovement](../WDLang3/1000019206.md). However, this function: 

- requires the application to be started,

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) requires the application to be in the foreground,

- consumes more battery.



<a name="NOTE3_3"></a>


### Operation according to the mode of use of the application
<a name="operation_according_the_mode_use_the_application_ELTPARAGRAPHE000214"></a>

**If the application is already running**, the procedure given to [geoTrackingProcedure](../WDLang3/1000021585.md) is automatically called when a location event is received. Any operation of application can be performed in this procedure.

**When the application is stopped**, if a location event is received, the application is restarted in the background. The "Initialization" event of the project is run, then the procedure specified in [geoTrackingProcedure](../WDLang3/1000021585.md).

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) iOS limits the operations that can be performed when the application is started in the background. Therefore:  

- The execution of background operation cannot exceed ten seconds.

- No window can be opened and no interface can be displayed (however, a notification can be sent). 




Reminder: **To find out if the application has been launched in the background**use function [ExeInfo](../WDLang1/3035001.md) with constant *exeRunning*. The *exeGeoTracking* constant will be returned if the application was started in the background.

## When to use each function?
<a name="when_use_each_function_ELTTEXTE000632"></a>


| Function | When to use it? | Accuracy | Energy consumption |
| --- | --- | --- | --- |
| geoTrackingXXX | Permanent tracking of location changes, even when the application is in the background. | High accuracy, but the frequency of notifications is low and varies depending on the system. | Low |
| [GPSFollowMovement](../WDLang3/1000019206.md) | Permanent tracking of location changes when the application is in the foreground. | Accuracy according to [GPSInitParameter](../WDLang3/1000019204.md). | Consumption according to [GPSInitParameter](../WDLang3/1000019204.md). |
| [GPSDetectPosition](../WDLang3/1000019209.md) | Notification of the proximity of a given location when the application is in the foreground. | Accuracy according to [GPSInitParameter](../WDLang3/1000019204.md). | Consumption according to [GPSInitParameter](../WDLang3/1000019204.md). |
| [GPSGetPosition](../WDLang3/1000019205.md) | Get current location at a specific moment when the application is in the foreground. It may take long, depending on the surroundings (inside a building, cloudy day, etc.). | Accuracy according to [GPSInitParameter](../WDLang3/1000019204.md). | Depends on the number of calls. |
| [GPSLastPosition](../WDLang3/1000019239.md) | Immediately get the last known location of the device. | Low consumption, since it depends on when the last location was actually retrieved. Also depends on [GPSInitParameter](../WDLang3/1000019204.md). | Low consumption. |
