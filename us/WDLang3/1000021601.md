


## PhotoRunApp (Function)

***In french: PhotoLanceAppli***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts the native camera application of the device in order to take a photo.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sPhoto is string = PhotoRunApp()
IF sPhoto <> "" THEN
	Info("Photo saved in file: " + sPhoto)
END
```
<a name="Exemple2"></a>

```wl
// Starts the application
PhotoRunApp(CB_PhotoRunApp)

	INTERNAL PROCEDURE CB_PhotoRunApp(sPath is string)
		// If the return is an empty string vide (""), an error occurred
		IF sPath ~= "" THEN
			Error(ErrorInfo())
			RETURN
		END
		// Message for end of recording
		Info("The photo was saved here: " + sPath)
	END
```





<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Starting the native camera application (locking call)

`<Result> = PhotoRunApp()`
---

**`<Result>: (Character string)`**



- Full path of the file where the photo was saved, 

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).





<a name="SYNTAXE2"></a>

### Starting the native camera application (non-locking call)

`<Result> = PhotoRunApp([<WLanguage procedure>])`
---

**`<Result>: (Character string)`**



- Full path of the file where the photo was saved, 

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called when the photo is saved.
This procedure has the following format:

```txt
PROCEDURE <Procedure name> (<Path>)
```

where &lt;Path&gt; corresponds to the backup path of the image.

## Remarks


### Photos saved
<a name="photos_saved_ELTPARAGRAPHE000060"></a>

The photo settings (format, resolution, size) are the ones defined in the native camera application.
<a name="NOTE0_2"></a>


### Backup directories
<a name="backup_directories_ELTPARAGRAPHE000067"></a>

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **In Android applications**: 

- The photo is stored on the device's SDCard and is automatically added to the album.
	**From Android 11**, the photo is stored in the public image directory on the external storage. This location is returned by the [SysDirExternalStorage](../WDLang1/1000021793.md) function with the **ssePublicPhoto** constant.
	For more details on allowed locations from Android 11, see [Android 11: Changes in the behavior of applications](../Editeurs/9000201.md).
	

- If photos must be used in your Android applications, we advise you to work with thumbnails and not with the initial photos taken by the device. To generate the thumbnails, use [VideoGenerateThumbnail](../WDLang1/1000020268.md). 




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **In iPhone/iPad applications**: 
By default, the photos are saved in the "Documents" directory of the application. 

You can also: 

- store the binary content of the image in a database, via a Memo item. 

- add the photo to the photo album of the device with [AlbumSave](../WDLang3/1000020191.md). In this case, the image can be re-used via [AlbumPicker](../WDLang3/1000020186.md). 



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000110"></a>

Using this function automatically changes the permissions required by the application.

Required permissions:

- READ_EXTERNAL_STORAGE: This permission allows an application to read from external storage (memory card, etc.).

- WRITE_EXTERNAL_STORAGE: This permission allows an application to write to external storage (memory card, etc.).

- READ_MEDIA_VIDEO: This permission allows an application to read video files from external storage.

- READ_MEDIA_IMAGES: This permission allows an application to read image files from external storage.




**Note**: **From Android 13**, when publishing to Google Play Store, READ_MEDIA_VIDEO, READ_MEDIA_IMAGES and READ_MEDIA_AUDIO permissions require a justification in the Google Play console. If necessary, you can remove permissions from the generation wizard. For more details, see [Storing files in Android](../WDLang1/1000021925.md).
