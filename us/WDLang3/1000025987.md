
## Constants for managing speech synthesis
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used by the speech synthesis functions:

| Constant | Details | Function / Type of variable |
| --- | --- | --- |
| **ssQualityLow** | Voice quality: Low quality. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssQualityHigh** | Voice quality: High quality. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssQualityStandard** | Voice quality: Normal quality. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssQualityVeryLow** | Voice quality: Very low. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssQualityVeryHigh** | Voice quality: Very high quality. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssVoiceFemale** | Synthesized voice genre: Female voice. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssVoiceUndefined** | Synthesized voice genre: Neutral voice. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
| **ssMaleVoice** | Synthesized voice genre: Male voice. | [SpeechSynthesisVoice](../WDLang3/1000025986.md) type |
