
## URI constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following constants are used by URIxxx functions:

| Constant | Details | Function |
| --- | --- | --- |
| **uriAdd** | The contents of the file or buffer are added at the end of the initial contents of the resource. | [FileToURI](../WDLang3/1410087413.md)<br>[BufferToURI](../WDLang3/1410087415.md) |
| **uriAudio** | MIME types supported: Allows all audio file types. | [URISelect](../WDLang3/1000024026.md) |
| **uriCreate** | <br><br>- Opens the picker in "Creation" mode to create a new document. <br><br>- The initial contents of the resource are replaced by the contents of the file or buffer.<br><br><br> | <br><br>- [URISelect](../WDLang3/1000024026.md)<br><br>- [FileToURI](../WDLang3/1410087413.md)<br>	[BufferToURI](../WDLang3/1410087415.md)<br><br><br> |
| **uriImage** | MIME types supported: Allows all image file types. | [URISelect](../WDLang3/1000024026.md) |
| **uriInfoName** | Required information: Resource name (without extension). | [URIGetInfo](../WDLang3/1000024037.md) |
| **uriInfoSize** | Required information: Resource size (in bytes). | [URIGetInfo](../WDLang3/1000024037.md) |
| **uriInfoTypeConversion** | Information requested: MIME types (and corresponding file extensions) into which the resource can be converted when exporting the resource. | [URIGetInfo](../WDLang3/1000024037.md) |
| **uriInfoOriginType** | Information requested: MIME type of origin of the resource and corresponding file extension. | [URIGetInfo](../WDLang3/1000024037.md) |
| **uriOpen** | Opens the picker in "Open" mode to open an existing document. | [URISelect](../WDLang3/1000024026.md) |
| **uriVideo** | MIME types supported: Allows all image file types. | [URISelect](../WDLang3/1000024026.md) |
