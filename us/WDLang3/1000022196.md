


## &lt;btleDevice variable&gt;.Disconnect (Function)

***In french: &lt;Variable btlePériphérique&gt;.Déconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to disconnect from a Bluetooth Low Energy device.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
myDevice is btleDevice
myDevice.Connect()
...
myDevice.Disconnect()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Device>.Disconnects()`
---

**`<Device>: (btleDevice variable)`**

Name of the [btleDevice](../WDLang3/1000022054.md) variable representing the Bluetooth device to use.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000174"></a>

[BTLEListDevice](../WDLang3/1000021882.md) is used to list the Bluetooth LE devices accessible from the device.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000190"></a>

This function changes the permissions required by the application.

Permission required: BLUETOOTH.

This permission allows the applications to connect to the Bluetooth services.

**Necessary versions**


- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Android applications**: 

	- Bluetooth Low Energy WLanguage functions are only available on devices with Android 4.3 or later (api level 18). 

	- A fatal error occurs if the function is used with an earlier system version. 

	- To determine the version of Android the application is running on, use [SysAndroidVersion](../WDLang1/1000019785.md).




- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) **iOS applications**: 
	The WLanguage Bluetooth Low Energy functions are available for the devices running iOS 9. 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) **WINDEV applications**:

	- Bluetooth Low Energy WLanguage functions are only available on:  

		- PCs that support at least Bluetooth Low Energy 5. 

		- PCs using a Bluetooth device that supports at least Bluetooth Low Energy 5. 




- If necessary, you can check the Bluetooth version of a PC in the Windows device manager: [https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793](https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793)

- Pairing must be done via Windows. Therefore, [BTLEListDevice](../WDLang3/1000021882.md) will only list devices that are visible and associated in the Windows Bluetooth settings.
