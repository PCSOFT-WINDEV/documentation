
## GroupAdd (Function)

***In french: GroupeAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a group of contacts in a Lotus Notes or Outlook address book. The [Group structure](../WDLang3/1000008120.md) is used to define the data for this group of contacts.

**Attention** This function **does not** add a group of contacts to the address book of an Outlook Express mailbox. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", ...
		"mail\julia.nsf", "C:\Users\Julia\AppData\Local\Lotus\Notes\Data\user.id")
// Initialize the variables of the Group structure
GroupReset()
// Fill the variables for the new group
mGroup.Name = "My friends"
mGroup.Description = "Group of friends"
mGroup.NbContact = 3
mGroup.Contact[1] = "Peter"
mGroup.Contact[2] = "Paul"
mGroup.Contact[3] = "Jack"
// Add the group
IF GroupAdd(SessionID) = True THEN
	Info("Group of contacts successfully added")
ELSE
	Error("Error during the addition", ErrorInfo())
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = GroupAdd(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The groups of contacts are not supported by Outlook 97. Therefore, no group of contacts can be added in this version of Outlook.
