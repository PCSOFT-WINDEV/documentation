


## grBarColor (Function)

***In french: grCouleurBarre***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Initializes the color of a specific bar in a Column or Stacked Column chart. 


<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Changes bar 2 of series 1
grBarColor(CHART_MyColumnChart, 1, 2, RGB(200,150,45))
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`grBarColor(<Chart name> , <Series number> , <Category number> , <Color>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name can correspond to:

- the chart name defined through programming with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to use. 

**`<Category number>: (Integer)`**

Number of the category to use.

**`<Color>: (Integer or Integer constant)`**

Bar color. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To modify the color of all bars found in a category, use [grCategoryColor](../WDLang3/1000020928.md). 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The graph is automatically modified. You don't need to use the [grDraw](../WDLang3/3042026.md) function.
