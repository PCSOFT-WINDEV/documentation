


## FTPCurrentDir (Function)

***In french: FTPRepEnCours***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets or sets the current directory on an FTP server (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003040003&name=ftpcurrentdir_function">See additional examples</a>

```wl
// Connect the current computer to the FTP server
ConnectionNumber = FTPConnect("192.54.12.8")
// Identify the current directory on the FTP server
ResCurrentDir = FTPCurrentDir(ConnectionNumber)
```

## Syntax

### Getting the current directory

`<Result> = FTPCurrentDir(<FTP connection>)`
---

**`<Result>: (Character string)`**



- Absolute name of the current directory on the FTP server,

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (Integer or ftpConnection variable)`**



- Connection identifier, returned by [FTPConnect](../WDLang3/3040016.md).
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is a Variant parameter.

- Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.
	

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available.





<a name="SYNTAXE2"></a>

### Setting the current directory

`<Result> = FTPCurrentDir(<FTP connection> , <New current directory>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the current directory was modified,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<FTP connection>: (Integer or ftpConnection variable)`**



- Connection identifier, returned by [FTPConnect](../WDLang3/3040016.md).
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is a Variant parameter.

- Name of the [ftpConnection](../WDLang3/1410090869.md) variable that corresponds to the FTP connection used.
	

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available.




**`<New current directory>: (Character string)`**

Name and full or relative path of the new directory. The different parts of the path are separated by "slashes" ("/").

## Remarks


### Timeout
<a name="timeout_ELTPARAGRAPHE000347"></a>

By default, all the FTP functions fail if the FTP server does not respond within 20 seconds. This time can be modified: 

- when connecting to the FTP server with [FTPConnect](../WDLang3/3040016.md) (&lt;Timeout&gt; parameter).

- when defining the parameters of the [ftpConnection](../WDLang3/1410090869.md) variable (**Timeout** property).
	



<a name="NOTE0_3"></a>


### Rights of users
<a name="rights_users_ELTPARAGRAPHE000387"></a>

Only a user who has read rights on the FTP server can get information about the files or the directories located on an FTP server. In most cases, the read rights are granted to the "anonymous" users.

### Required permissions

Required permission: INTERNET 
This permission allows the applications to open the network sockets.
