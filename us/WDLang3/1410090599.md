
## WLanguage procedure called by AppointmentCreate



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called when an appointment is created with the [AppointmentCreate](../WDLang3/1000020691.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
apt is Appointment
...
AppointmentCreate(apt, ProcApt)

	INTERNAL PROCEDURE ProcApt(Status)
		SWITCH Status 
			CASE aptCanceled
			Trace("Appointment canceled by the user")
			CASE aptFailed
			Trace("Unable to create appointment")
			CASE aptSuccess
			Info("Appointment created successfully")
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`AppointmentCreate_Callback(<Status>)`
---

**`<Status>: (Integer constant)`**

Appointment creation status: 


|   |   |
| --- | --- |
| *aptCanceled* | The appointment creation was canceled. |
| *aptFailed* | The appointment could not be created. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md). |
| *aptSuccess* | The appointment was created successfully. |
