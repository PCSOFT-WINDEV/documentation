


## grLabel (Function)

***In french: grLibellé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates various parameters of additional legend in a chart.

Example of additional parameters: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grLibell%E9%20-%20HC%20N%B0001.gif)




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart created programmatically
// Display the caption for the labels of data categories in "MyChart"
grLabel("MyChart", grShowLabel, True)
```
<a name="Exemple2"></a>

```wl
// Chart control
// Display the caption for the percentages of data categories in "CHART_MyChart"
grLabel(CHART_Chart, grShowPercent, True)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grLabel(<Chart name> , <Additional legend> , <Display>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Additional legend>: (Constant)`**

Additional legend that will be displayed with the chart:

- ***with a pie chart:***: 
	


|   |   |
| --- | --- |
| *grShowLabel* | Label of data categories. |
| *grShowPercent* | Percentage of data categories. |
| *grShowValue* | Value of data categories. |






- ***with a column chart***:
	


|   |   |
| --- | --- |
| *grShowValue* | Value of data categories. |






- ***with a stacked column chart***: 
	


|   |   |
| --- | --- |
| *grShowValueIfNull* | Label of data categories, even for the null values in the stacked column chart. |






**`<Display>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the additional legend must be displayed, 

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks


### Chart caption
<a name="chart_caption_ELTPARAGRAPHE000166"></a>

The chart caption can include three elements:

- the category labels.

- the value of categories.

- the percentage of categories.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grLibell%E9%20-%20HC%20N%B0001.gif)
Chart captions can only be displayed in Pie, Column and Stacked Column charts.

**grLabel** displays the different elements of the chart caption. Different elements are displayed according to the type of chart.

The category labels displayed correspond to the ones defined by [grCategoryLabel](../WDLang3/3042015.md).

The value of categories depends on the chart data.

The percentage of categories is automatically calculated.

The information display can be formatted by [grMask](../WDLang3/3042034.md).

Any changes made with **grLabel** will take effect the next time [grDraw](../WDLang3/3042026.md) is called.
