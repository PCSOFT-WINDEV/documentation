


## NetIPAddress (Function)

***In french: NetAdresseIP***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the IP (Internet Protocol) address of a computer. 

**Warning** Only IPV4 addresses are returned. This operating mode is kept for backward compatibility with the earlier versions. To find out the IPV4 and/or IPV6 addresses, use [NetListIPAddress](../WDLang3/1000019683.md). 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Caution**: This information is available up to Android 10. As of Android 11, this information is no longer available: This function returns an empty string.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the IP address of local computer
Info(NetIPAddress())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NetIPAddress([<Computer name>] [, <Index>])`
---

**`<Result>: (Character string)`**



- IP address of specified computer (in XXX.XXX.XXX.XXX format), 

- Empty string ("") if the computer has less IP addresses than the desired &lt;Index&gt;.




**`<Computer name>: (Optional character string)`**

Name of the computer to use. If this parameter is not specified, the current computer will be considered.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) You cannot retrieve the addresses of a computer other than the one onto which the application is run.

**`<Index>: (Optional integer)`**

Index of the IP address in the list of computer addresses. By default, the address returned is the first address found in the list of computer addresses. The index of the first address is set to 0.

## Remarks


### Number of IP addresses
<a name="number_addresses_ELTPARAGRAPHE000063"></a>

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a WEBDEV website, **NetIPAddress** returns the IP address of the server on which the site is installed. 
	To find out the IP address of the Web user, you must use [BrowserIPAddress](../WDLang2/3055003.md). 
	**Attention**: If the user is behind a router, the [BrowserIPAddress](../WDLang2/3055003.md) function returns the router's IP address.

- An IP address is found for each TCP/IP protocol installed on the same computer.

- To list the different IP addresses of a computer (IPV4 and/or IPV6), use [NetListIPAddress](../WDLang3/1000019683.md).
