
## ContactDisplay (Function)

***In french: ContactAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens the contact details window in the native application of the device (Android, iPhone or iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example



<a name="Exemple2"></a>

```wl
//Procedure used to display the contact selected in a Looper control
PROCEDURE DisplayContact(nContactNum is int)
tContact is Contact
IF nContactNum <= gtabContacts.Count THEN
	tContact = gtabContacts[nContactNum]
	// Initializes the contact
	VariableReset(gCurrentContact)
	gCurrentContact = tContact
	ContactDisplay(gCurrentContact)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Displaying a contact from a Contact variable

`<Result> = ContactDisplay(<Contact>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the contact details window has been opened,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Contact>: (Contact variable)`**

Name of the [Contact](../WDLang3/1000020254.md) variable corresponding to the contact to display. This contact must exist in the database of contacts.

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000108"></a>

- **ContactDisplay** gives control back to the application once the contact details window has been displayed.

- **ContactDisplay** can be used in the emulator. It cannot be used in the simulator.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000257"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**ContactDisplay** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
