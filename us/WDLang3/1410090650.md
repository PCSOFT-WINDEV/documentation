
## NearbyShareRequestConnection (Function)

***In french: PartageProximitéDemandeConnexion***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends a connection request to a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareRequestConnection(gSelectedDevice.ID, ...
	gsDeviceName, CallbackRequestConnection, CallbackConnection)
```



```wl
PROCEDURE CallbackRequestConnection(sDeviceID is string, sDeviceName is string, sToken is string)
Info([
	ID: [%sDeviceID%]
	Name: [%sDeviceName%]
])
```



```wl
PROCEDURE CallbackConnection(sDeviceID is string, nStatus is int)
SWITCH nStatus
	CASE nsConnectionRejected
		ToastDisplay("The connection request has been rejected.")
	CASE nsConnected
		ToastDisplay(StringBuild("Connected to %1.", sDeviceID)
	CASE nsDisconnected
		ToastDisplay("Disconnected.")
	CASE nsConnectionFailed
		ToastDisplay("Connection failed." + ErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareRequestConnection(<Remote device identifier> , <Device name> , <Request reception procedure> , <Notification procedure>)`
---

**`<Remote device identifier>: (Character string)`**

Identifier of the nearby device to connect to. This identifier must have been received as a parameter of the callback procedure passed to [NearbyShareDiscoverDevice](../WDLang3/1410090648.md).

**`<Device name>: (Character string)`**

Name of the device requesting the connection. This name will be received by the nearby device as a parameter of the procedure of [NearbyShareWaitForConnection](../WDLang3/1410090655.md), which is executed when the nearby device receives the connection request.

**`<Request reception procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") executed when the nearby device receives the connection request.
In the code of this procedure, the request can be accepted ([NearbyShareAcceptConnection](../WDLang3/1410090646.md)) or rejected ([NearbyShareRejectConnection](../WDLang3/1410090651.md)). 

For more details on this procedure, see [Parameters of the procedure used by NearbyShareRequestConnection (Request)](../WDLang3/1410090666.md).

**`<Notification procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called to notify the nearby device connection status.

For more details on this procedure, see [Parameters of the procedure used by NearbyShareRequestConnection (Notification)](../WDLang3/1410090667.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **NearbyShareRequestConnection** can be called when a nearby device is found after calling [NearbyShareDiscoverDevice](../WDLang3/1410090648.md).

- If the nearby device accepts the connection request, the request reception procedure passed to **NearbyShareRequestConnection**will be executed. You will then need to call [NearbyShareAcceptConnection](../WDLang3/1410090646.md) to start exchanging data with between the devices.
