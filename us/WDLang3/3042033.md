


## grSmoothing (Function)

***In french: grLissage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Smoothes a Line chart or a Scatter chart by using the "cubic splines" algorithm. 

**Reminder** By default, a graph is unsmoothed.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Smooth CHART_MyChart
grSmoothing(CHART_MyChart, True)
```

## Syntax

### Smoothing a chart

`grSmoothing(<Chart name> , <Smoothing>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Smoothing>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the smoothing must be enabled,

- <u><u><u><u>False</u></u></u></u> otherwise.  





<a name="SYNTAXE2"></a>

### Smoothing a chart series

`grSmoothing(<Chart name> , <Series number> , <Smoothing>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series to smooth.  

**`<Smoothing>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the smoothing must be enabled,

- <u><u><u><u>False</u></u></u></u> otherwise.

## Remarks
The smoothing is taken into account:

- in Line charts (*grLine* constant),

- in Scatter charts (*grScatter* constant) with linked points ([grScatterLinkPoint](../WDLang3/3042040.md)).




**Caution**: This function has no effect on a 3D graph.

The parameters defined by **grSmoothing** will be taken into account during the next call to [grDraw](../WDLang3/3042026.md).
