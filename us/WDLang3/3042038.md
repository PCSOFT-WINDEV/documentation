


## grScatterSeriesLabel (Function)

***In french: grNuageEtiquetteSérie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the label of data series in a "Scatter" chart.

Example of series label: <br>![Series label](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=EtiquetteSerie.gif)


**Reminder**: By default, charts have no labels.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initializes the "Sales" label of second data series in "MyChart"
grScatterSeriesLabel("MyChart", 2, "Sales")
```
<a name="Exemple2"></a>

```wl
// Initializes the "Purchase" label of third data series in CHART_MyChart
grScatterSeriesLabel(CHART_MyChart, 3, "Purchase")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`grScatterSeriesLabel(<Chart name> , <Series number> , <Label>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Series number>: (Integer)`**

Number of the series for which a label will be initialized.

**`<Label>: (Character string)`**

Caption of label to initialize.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The label font can be modified by [grLabelFont](../WDLang3/3042012.md).

- The data defined by **grScatterSeriesLabel** will be taken into account in the next call to [grDraw](../WDLang3/3042026.md).

- **grScatterSeriesLabel** and [grSeriesLabel](../WDLang3/3042024.md) are equivalent. 
	The syntax of [grSeriesLabel](../WDLang3/3042024.md) used with "Scatter" charts is as follows:
	
	```txt
	grSeriesLabel(<Chart name>, 2*<Index>-1, <Label>)
	```
**Reminder**: A "Scatter chart" uses data in groups of two series (for more details, see [grScatterAddDataXY](../WDLang3/3042032.md)).
