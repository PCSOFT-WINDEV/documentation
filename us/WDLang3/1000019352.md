


## WiFiConnect (Function)

***In french: WiFiConnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Connects the device to the specified Wi-Fi network.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) **Remarks**: 

- The Wi-Fi access is not available in the Android emulator.

- Starting with Android 6, it is no longer possible to connect to a network that has not been added by the application itself.

- Warning: as of Android 10, it is no longer possible to connect to a Wi-Fi network programmatically. This function causes a fatal error.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF WiFiConnect("14758") = True THEN
	Info("Wi-Fi connection established.")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = WiFiConnect(<Identifier> [, <Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the connection was established,

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns more information on the error.




**`<Identifier>: (Character string)`**

Identifier of the network to which we want to connect. This identifier can be: 

- the identifier returned by [WiFiAddNetwork](../WDLang3/1000019351.md) (for a network that was just added). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) the identifier of a network selected in the list of available networks ([WiFiListNetwork](../WDLang3/1000019356.md)).
	Please note: As of Android 6, this type of identifier is no longer available. 




**`<Password>: (Optional string or Secret string)`**

Password used to connect to a secured network. If this parameter is not specified, the password used will be the one saved in the network configuration (if this password exists).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications.

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000082"></a>

This function changes the permissions required by the application.

Required permissions:  

- ACCESS_WIFI_STATE: this permission allows applications to access information about Wi-Fi networks. 

- CHANGE_WIFI_STATE: this permission allows applications to change the Wi-Fi connectivity state.
