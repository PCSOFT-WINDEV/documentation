
## iCloud constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The iCloud constants are as follows:

| Constant | Details | Function |
| --- | --- | --- |
| **ickvAccountChange** | Cause of event: User has changed account. | [iCloudKeyValueWatch](../WDLang3/1410088760.md) |
| **ickvSynchronizationFailed** | Cause of event: Error when attempting to synchronize the device with the Apple iCloud server. | [iCloudKeyValueWatch](../WDLang3/1410088760.md) |
| **ickvServerChange** | Cause of event: The keys have been modified from the Apple iCloud server. | [iCloudKeyValueWatch](../WDLang3/1410088760.md) |
| **ickvInitialSynchronizationChange** | Cause of event: Initial synchronization with Apple iCloud server. | [iCloudKeyValueWatch](../WDLang3/1410088760.md) |
| **ickvQuotaViolation** | Cause of event: Key quota exceeded (number of keys, storage space, etc.). | [iCloudKeyValueWatch](../WDLang3/1410088760.md) |
