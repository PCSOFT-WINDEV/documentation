


## &lt;Chart&gt;.CategoryColor (Function)

***In french: &lt;Graphe&gt;.CouleurCatégorie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initializes the category color for a chart whose type is: 

- Pie,

- Column,

- Bubble chart,

- Waterfall. 




By default, the colors of categories (or the colors of sections, bubbles, ...) are selected according to a preset order among a set of 11 colors. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modifies the color of category 3 in the "CHART_Chart1" control
CHART_Chart1.CategoryColor(3, LightRed)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart control>.CategoryColor(<Category number> , <Color>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Category number>: (Integer)`**

Number of the category to modify. 
**For a Pie chart** (constant *grSector*), this parameter corresponds to the index of the data in the series (the sector number). In this case, this function is equivalent to [&lt;Chart&gt;.SeriesColor](../WDLang3/1000023599.md). 
**For a column chart type** (constant *grHistogramme*), this parameter corresponds to the category index: all bars in the category will be colored. The colors specified for the category series will be ignored. 
**For a Bubble chart** (constant *grGrapheBulle*), this parameter corresponds to the category index: the bubble corresponding to the category will be colored.

**`<Color>: (Integer or Integer constant)`**

Color of specified category. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).

## Remarks


- The colors defined by **&lt;Chart&gt;.CategoryColor** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The defined colors are immediately taken into account. [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md) is not available.

- To display the color gradients, use [&lt;Chart&gt;.Gradient](../WDLang3/1000024061.md).

- The colors specified by **&lt;Chart&gt;.CategoryColor** are taken into account in the Waterfall charts. You also have the ability to define the colors of categories in the Waterfall charts with [&lt;Chart&gt;.WaterfallColor](../WDLang3/1000024158.md).
