
## AuthGetUserInfo (Function)

***In french: AuthRécupèreInfoUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves user information from an access token. 

Note: In web services, this function is particularly useful to identify the user. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
token is JSON = g_token.ServerResponse
access_token is JSON = token.access_token

Res is JSON = AuthGetUserInfo(access_token, "http://myserver/oauth2/v1/userinfo")
Trace(Res)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = AuthGetUserInfo(<Access token> , <User information URL>)`
---

**`<Result>: (JSON string)`**

JSON string containing the metadata of the token. 

**`<Access token>: (Character string)`**

Access token. 

**`<User information URL>: (Character string)`**

URL for retrieving user information.
