
## PowerStatus (Function)

***In french: EtatAlimentation***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>26</B>, this function is available for backward compatibility. Use the [SysPowerStatus](../WDLang1/1000026039.md) function. 
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to get various information about the battery (main or secondary) of the device on which the application is running.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Status of main battery?
Info("The battery is charged to: " + EtatAlimentation(PourcentageCharge) + " %")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = PowerStatus(<Type of information> [, <Battery>])`
---

**`<Result>: (Integer or boolean according to the type of information)`**



- Requested information, 

- Empty string ("") if the requested information is not available.




**`<Type of information>: (Integer constant)`**

Specifies the requested type of information: 



|   |   |
| --- | --- |
| *ACLineStatus* | <br><br>- <u><u><u><u>True</u></u></u></u> if the device is plugged in,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise.<br><br><br> |
| *ChargeLevel* | Charge level of battery:<br><br>- 0: No battery.<br><br>- 1: High level.<br><br>- 2: Low level.<br><br>- 3: Critical level.<br><br><br> |
| *ChargePercentage* | Percentage of battery load. |
| *Charging* | <br><br>- <u><u><u><u>True</u></u></u></u> if the battery is charging,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise.<br><br><br> |
| *RemainingLife* | Remaining lifetime (in seconds) of battery.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |
| *TotalLife* | Total lifetime (in seconds) of battery.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |



**`<Battery>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (by default) to get information about the main battery of device,

- <u><u><u><u>False</u></u></u></u> to get information about the secondary battery of device.  


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) No information can be retrieved about the secondary battery. If &lt;Battery&gt; is set to False, &lt;Result&gt; will correspond to an empty string ("").

## Remarks




### Battery
<a name="battery_ELTPARAGRAPHE000127"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) No information can be retrieved about the secondary battery.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The returned information is invalid in emulator mode.



<a name="NOTE0_2"></a>




### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000144"></a>

**Caution**: **PowerStatus** returns no error code. To determine if this function has generated an error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.
