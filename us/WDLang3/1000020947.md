
## FTPConfigure (Function)

***In french: FTPParamètre***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>28</B>, ***FTPParameter*</**>** is kept for backward compatibility. This function has been replaced with ***FTPConfigure*</**>**.

<a name="Utilisation"></a>
<a name="description"></a>
Modifies the behavior of standard FTP functions. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enable the native implementation of FTP
FTPConfigure(ftpConfigureMode, 1)
```


<a name="Exemple2"></a>

```wl
// Enable the Windows implementation ("wininet") of FTP
FTPConfigure(ftpConfigureMode, 0)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`FTPConfigure(<Option> , <Option value>)`
---

**`<Option>: (Integer constant)`**

Option to define: 


|   |   |
| --- | --- |
| *ftpConfigureMode* | Selects the FTP operating mode.<br><br>- **If &lt;Option value&gt; is set to 0**, the FTP functions use the Windows "wininet" module, except for secure protocols ([FTPIS, FTPES and SFTP](../WDLang3/3040016.md)). This is the default operating mode for FTP functions.<br><br>- **If &lt;Option value&gt; is set to 1**, the FTP functions use a native, Windows-independent implementation of FTP, with UTF-8 support. <br>	**Note**: In this mode, [FTPCommand](../WDLang3/3040017.md) is not supported. This mode is systematically used for secure protocols ([FTPIS, FTPES and SFTP](../WDLang3/3040016.md)).<br><br><br> |
| *ftpConfigureReuseConnection* | Forces the use of the same FTP server connection between two requests. <br><br>- **If &lt;Option value&gt; is set to 0**, the client/application opens a connection each time it sends a command, then closes it immediately.<br><br>- **If &lt;Option value&gt; is set to 1** (default), the client/application opens a connection when it sends the first command, and keeps this connection open as long as the server and client are exchanging data. After a given period of inactivity, the connection is automatically closed. This connection will be automatically reopened when the next command is executed, with no user action required.<br><br><br> |
| *ftpesConfigureSecureMode* | Sets the FTPES encryption mode.<br><br>- **If &lt;Option value&gt; is set to 0**, the encryption is applied to FTP data and commands. This is the default mode for functions in FTPES.<br><br>- **If &lt;Option value&gt; is set to 1**, the SSL encryption is applied only to FTP commands. This mode may be required for some FTPES servers.<br><br><br><br><br>In previous versions, this constant corresponds to "ftpesParameterSecureMode". |



**`<Option value>: (Integer)`**

New value of the option. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
By default, WLanguage FTPxxx functions use the Windows API FTP functions (WININET.DLL). In Windows 8.1, these APIs do no longer return the expected results:

- transfer not completed, 

- "unable to modify the directory to.".




While waiting for the standard FTP functions to be restored by Windows Update, WLanguage FTPxxx functions can be modified so that they no longer use Windows API FTP functions. To do so, insert the following call in the FTP transfer process, before the existing call to [FTPConnect](../WDLang3/3040016.md): 


```wl
FTPConfigure(ftpConfigureMode, 1)
```


Note: **FTPConfigure** applies to all WLanguage FTPxxx functions, except for [FTPCommand](../WDLang3/3040017.md). If necessary, this function can be replaced with [FTPSend](../WDLang3/3040014.md) or [FTPGet](../WDLang3/3040002.md).
