


## &lt;Chart&gt;.Zoom (Function)

***In french: &lt;Graphe&gt;.Zoom***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the zoom of a chart. 

**Note**: This function is similar to [&lt;Chart&gt;.Origin](../WDLang3/1000024114.md).. However, the **&lt;Chart&gt;.Zoom FUNCTION** function allows the user to return to the initial zoom of the graph using one of the following methods: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) via the context menu of the chart ("Initial zoom"). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) via the Ctrl + 0 keys. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) via a double tap on the chart.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CHART_MyChart.Zoom(5, 12, grXCoordinate)
CHART_MyChart.Draw()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Chart control>.Zoom(<Minimum mark> [, <Maximum mark> [, <Axis>]])`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window editor).

**`<Minimum mark>: (Real)`**

Start mark on the specified axis.
This parameter can also correspond to a duration, a date, a time or a date-time. 

**`<Maximum mark>: (Optional real)`**

End mark on the specified axis. 

If this parameter is not specified, &lt;Maximum mark&gt; corresponds to the maximum value of chart data.
This parameter can also correspond to a duration, a date, a time or a date-time. 

**`<Axis>: (Optional Integer constant)`**

Axis for which the marks must be modified: 



|   |   |
| --- | --- |
| *grSecondaryYCoordinate* | Secondary Y-axis (vertical axis). |
| *grXCoordinate*<br>(default value) | X-axis (horizontal axis). |
| *grYCoordinate* | Y-axis (vertical axis). |

<a name="NOTE0_1"></a>

## Remarks


### Marks on axes
<a name="marks_axes_ELTPARAGRAPHE000258"></a>

- X-axis (horizontal axis): the parameters &lt;Graduation minimale&gt; and &lt;Graduation maximale&gt; correspond to the minimum and maximum index of data in the series displayed.

- Y-axis (vertical axis): the parameters &lt;Graduation minimale&gt; and &lt;Graduation maximale&gt; correspond to the minimum and maximum value of the data.

- Limits: 100 graduations above and 100 graduations below the x-axis.

- To modify the frequency of marks on the horizontal or vertical axis of a chart, use [&lt;Chart&gt;.Interval](../WDLang3/1000024076.md).

- The data defined by **&lt;Chart&gt;.Zoom** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).



<a name="NOTE0_2"></a>


### Types of charts
<a name="types_charts_ELTPARAGRAPHE000286"></a>

The marks on axes have no effect on the Pie charts.
<a name="NOTE0_3"></a>


### Restoring the default values
<a name="restoring_the_default_values_ELTPARAGRAPHE000296"></a>To restore the chart display before the zoom, the minimum and maximum values of axes must be used. These values can be known via the following properties: 



|   |   |
| --- | --- |
| [XAxisMax](../Proprietes/1000018169.md) | The **XAxisMax** property gets the maximum value of the X-axis in a Chart control. This property can be used in the "Zoom" event of a Chart control to identify the section displayed. |
| [XAxisMin](../Proprietes/1000018168.md) | The **XAxisMin** property gets the minimum value of the X-axis in a Chart control. This property can be used in the "Zoom" event of a Chart control to identify the section displayed. |
| [YAxisMax](../Proprietes/1000018171.md) | The **YAxisMax** property gets the maximum value of the Y-axis in a Chart control. This property can be used in the "Zoom" event of a Chart control to identify the section displayed. |
| [YAxisMin](../Proprietes/1000018170.md) | The **YAxisMin** property gets the minimum value of the Y-axis in a Chart control. |
| [ZAxisMax](../Proprietes/1000020626.md) | The **ZAxisMax** property gets the maximum value of the Z-axis in a Chart control (Surface chart). |
| [ZAxisMin](../Proprietes/1000020662.md) | The **ZAxisMin** property gets the minimum value of the Z-axis in a Chart control (Surface chart). |



For example: 

```wl
// Code used to zoom
CHART_MyChart.Zoom(5, 12, grXCoordinate)
CHART_MyChart.Draw()
```

```wl
// Code used to zoom out
CHART_MyChart.Zoom(CHART_MyChart.XAxisMin, CHART_MyChart.XAxisMax, grXCoordinate)
CHART_MyChart.Draw()
```
