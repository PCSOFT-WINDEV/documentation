
## QuickAction (Variable type)

***In french: ActionRapide***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **QuickAction** type allows you to define all the advanced characteristics of a quick action of an app on Android (app shortcut) or iOS (Quick Action). A quick action is defined, among other things, by an identifier, a label and an action.
You can define and change the characteristics of this action using different WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Creates a new quick action for the application
action is QuickAction
action.Identifier = "ACTION_ID__SEND_MESSAGE"
action.Caption = "New message"
action.Procedure = ProcSendMessage
QuickActionAdd(action)
```

## Properties


### Properties specific to QuickAction variables
<a name="properties_specific_quickaction_variables_ELTPARAGRAPHE000027"></a>

The following properties can be used to define the characteristics of QuickAction variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Icon | Desired type | Path to the icon associated with the action. This property can correspond to: <br><br>- the image path as a string, <br><br>- a variable of type [Image](../WDLang1/1000019650.md), <br><br>- a variable of type [URI](../WDLang3/1000024027.md). <br><br><br><br><br>This property is optional. If this property is not specified, the application icon will be used. |
| Caption | Character string | Short description of the action to be performed.<br><br>This property must be specified. |
| Identifier | Character string | Identifier of the action to be executed.<br><br>This property must be specified. |
| LongCaption | Character string | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Detailed description of the action. <br>This description will be displayed instead of the short caption if there is enough space. <br>Maximum recommended size: 25 characters. |
| Note | Character string | Stores additional data associated with the action. |
| Order | Integer | Positive integer value used to set the position of the action in the context menu of the application. The lower the value, the higher the action will rank. |
| Procedure | Procedure | Name of the global WLanguage procedure called when the user taps the icon associated with the action. <br>This procedure has the following format: <br><br><pre><code>PROCEDURE <Procedure name>(<action>)</code></pre><br>where &lt;action&gt; is a **QuickAction** variable corresponding to the action selected by the user. Note: in this case, the Property **Icon** property of the **QuickAction** variable will be left blank.<br><br>If this property is set to an empty string, the application will be launched as a standard application. <br><br>If the application is not already running when the action is triggered, it will be launched automatically, the application initialization WLanguage events will be run, and then the procedure will be executed. If no window is open once the procedure is executed, the first window of the application will be automatically opened.<br><br>If the application is already running, it will move to the foreground and the procedure will be executed.<br><br>It is not recommended to call [Info](../WDLang1/3021011.md), [Error](../WDLang1/3021013.md), or similar functions in this procedure. |
| SubCaption | Character string | ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Subtitle of the quick action. |
