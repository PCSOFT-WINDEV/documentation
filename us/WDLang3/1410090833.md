
## Nearby sharing functions
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manage data exchange between nearby devices: 



|   |   |
| --- | --- |
| [NearbyShareAcceptConnection](../WDLang3/1410090646.md) | Accepts a connection request from a nearby device. |
| [NearbyShareDisconnect](../WDLang3/1410090652.md) | Closes the connection with a nearby device. |
| [NearbyShareDiscoverDevice](../WDLang3/1410090648.md) | Discovers nearby devices that have advertised themselves and are waiting to connect ("advertisers"). |
| [NearbyShareRejectConnection](../WDLang3/1410090651.md) | Rejects a connection request from a nearby device. |
| [NearbyShareRequestConnection](../WDLang3/1410090650.md) | Sends a connection request to a nearby device. |
| [NearbyShareSend](../WDLang3/1410090653.md) | Sends data (binary buffer) to one or more nearby devices to which the current device is connected. |
| [NearbyShareSendFile](../WDLang3/1410090654.md) | Sends a file to one or more nearby devices to which the current device is connected. |
| [NearbyShareStopAll](../WDLang3/1410090668.md) | Stops all current nearby share tasks: <br><br>- stop waiting for connections (advertising), <br><br>- stop searching for nearby devices (discovery), <br><br>- disconnect all currently connected devices.<br><br><br> |
| [NearbyShareStopDiscovery](../WDLang3/1410090649.md) | Stops searching for nearby devices (i.e., stops discovery). |
| [NearbyShareStopWaiting](../WDLang3/1410090647.md) | Stops waiting for other nearby devices to connect (i.e., stops advertising). |
| [NearbyShareWaitForConnection](../WDLang3/1410090655.md) | Makes the device visible to nearby devices in discovery mode (via [NearbyShareDiscoverDevice](../WDLang3/1410090648.md)) and waits for their connection request. |
