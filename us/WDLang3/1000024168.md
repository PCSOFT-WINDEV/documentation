


## &lt;Chart&gt;.Type (Function)

***In french: &lt;Graphe&gt;.Type***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies or modifies the type of chart.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the type of Chart control CHART_MyChart
CHART_MyChart.Type(grPie)
```

## Remarks


### Changing the type of chart
<a name="changing_the_type_chart_ELTPARAGRAPHE001076"></a>

- When changing the type of chart, the parameters of the former chart that cannot be reproduced in the new chart are reinitialized.

- Changing the type of chart may produce unexpected effects. For example, when a Pie chart (*grPie* constant) is changed into a Scatter chart (*grScatter* constant), all the points are aligned on the X-axis (horizontal axis).

- The type of chart can be changed in the context menu. However, the display options produce different visual effects for each type of chart.

- The parameters defined by **&lt;Chart&gt;.Type** will be taken into account during the next call to [&lt;Chart&gt;.Draw](../WDLang3/1000024062.md).
