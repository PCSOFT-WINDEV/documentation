
## DomoClose (Function)

***In french: DomoFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the communication opened by [DomoOpen](../WDLang3/1000003102.md).

**Note** For the X10 powerline protocol to work properly, electrical continuity must be maintained between devices. For example, the transmission cannot pass through an insulation transformer.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open the X10 connection
ConnectionID is int
ConnectionID = DomoOpen("COM4", "A")  
// Switch on the lamps connected to the A3 and A4 modules
DomoSwitchOn(ConnectionID, "A3 A4")
// Equivalent to: DomoSend(IDConnexion, "A3 A4", domoMarche)
...
// Close the connection
DomoClose(ConnectionID)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`DomoClose(<Connection ID>)`
---

**`<Connection ID>: (Integer)`**

Identifier of the connection to close. This identifier is defined by [DomoOpen](../WDLang3/1000003102.md).
