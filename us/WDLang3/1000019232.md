


## HTTPCookieReset (Function)

***In french: HTTPCookieRAZ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all the cookies (globally or for a domain) stored: 

- by the calls to [HTTPRequest](../WDLang3/3043007.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) by the calls to [HTTPSend](../WDLang3/1000021183.md).


**Note** Cookies read and sent by the [HTTPRequest](../WDLang3/3043007.md) function are only stored in the application's memory. They are not related to the cookies of Web browsers installed on the computer.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Request on the Google.com site as if it was the very first call
HTTPCookieReset(".google.com")
HTTPRequest("www.google.com")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Clears the cookies stored by HTTPRequest

`HTTPCookieReset([<Domain>])`
---

**`<Domain>: (Optional character string)`**

Domain for which the cookies will be cleared. If this parameter is not specified (if no domain is specified), all the cookies will be cleared.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
### Clears the cookies stored by HTTPSend

`HTTPCookieReset(<HTTP request> [, <Domain>])`
---

**`<HTTP request>: (httpRequest variable)`**

Name of the [httpRequest](../WDLang3/1000021158.md) variable for which the cookies will be cleared.  

**`<Domain>: (Optional character string)`**

Domain for which the cookies will be cleared. If this parameter is not specified (if no domain is specified), all the cookies will be cleared.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- A domain corresponds to the end of address of HTTP server (".windev.com" for example).

- Using **HTTPCookieReset** will affect the next call to [HTTPRequest](../WDLang3/3043007.md) or to [HTTPSend](../WDLang3/1000021183.md).

- Using **HTTPCookieReset** is equivalent to the call to [HTTPCookieReplace](../WDLang3/1000019231.md) with an empty array.

- **Attention** The function **HTTPCookieReset** function does not clear Internet Explorer cookies.
