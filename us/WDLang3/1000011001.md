
## AppointmentAdd (Function)

***In french: RendezVousAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an appointment: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in a Lotus Notes or Outlook calendar. The [Appointment](../WDLang3/1000011010.md) structure can be used define the details of this appointment.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) in a calendar on an Android device. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) in a calendar on an iOS device. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) in the device's default calendar.

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000020711&name=appointmentadd_function">See additional examples</a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf", "C:\Lotus Notes\julia.id")
// Initialize the variables of the Appointment structure
AppointmentReset()
// Fill the variables for the new appointment
mAppointment.Subject = "Sales meeting"
mAppointment.StartDate ="20070125100000"
mAppointment.Location = "Room 3B"
mAppointment.NbParticipant = 3
mAppointment.Participant[1] = "Robert"
mAppointment.Participant[2] = "Lucas"
mAppointment.Participant[3] = "Stephen"
// Add the appointment
IF AppointmentAdd(SessionID) = True THEN
	Info("Appointment added")
ELSE
	Error("Error during the addition", ErrorInfo())
END
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) 
```wl
gAPT is Appointment
gCal is Calendar
arrCalendar is array of Calendar 
// Retrieves the list of calendars
arrCalendar = AppointmentListCalendar()
gCal = arrCalendar[1]

// Add a new appointment into the first calendar
gAPT.Title = EDT_Title
gAPT.StartDate = EDT_StartDate + EDT_StartTime
gAPT.EndDate = EDT_EndDate + EDT_EndTime
gAPT.Location = EDT_Location
gAPT.Content = EDT_Desc
IF EDT_TimeZone <> "" THEN
	gAPT.TimeZone = EDT_TimeZone
END
gAPT.Author = EDT_Author
gAPT.Guest = EDT_Guests
gAPT.WholeDay = CBOX_WholeDay[1]

IF AppointmentAdd(gCal, gAPT) THEN
	ToastDisplay("APT added")
ELSE
	Error(ErrorInfo())
END
```

### Adding an appointment to a calendar on an Android/iOS device

`<Result> = AppointmentAdd([<Calendar>, ] <Appointment>)`
---

**`<Result>: (Boolean)`**



- <u><u><u>True</u></u></u> if the appointment was added,

- <u><u><u>False</u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Calendar>: (Optional Calendar variable)`**

Name of the [Calendar](../WDLang3/1000020663.md) variable that corresponds to the Android/iOS calendar the appointment will be added to. 
If this parameter is not specified, the appointment will be added to the device's default calendar. 
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) If there are multiple accounts on the phone and a default calendar is associated with them, a window will appear to allow the user to select the desired account. 

**`<Appointment>: (Appointment variable)`**

Name of the [Appointment](../WDLang1/1000019244.md) variable that corresponds to the appointment that will be added to the specified calendar on the Android/iOS device.

## Syntax

### Adding an appointment to a Lotus Notes or Outlook calendar

`<Result> = AppointmentAdd(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the appointment was added,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).

### Lotus Notes or Outlook calendar
<a name="lotus_notes_outlook_calendar_ELTPARAGRAPHE000138"></a>

- When you create an appointment with a reminder in Outlook, the reminder appears immediately, regardless of the appointment date.

- The appointments are added as "meetings". To change the type of appointment, modify the "AppointmentType" control of the new appointment (with [NotesModifyItem](../WDLang3/1000005113.md), for example).
	The different possible values for the types are as follows:

	- "0": appointment

	- "1": anniversary

	- "2": event

	- "3": meeting

	- "4": reminder


 Example:
	
	```wl
	NotesModifyItem(ID, "AppointmentType", "0")
	```


- In Outlook, the management mode of contacts/participants can be specified when starting the session ([EmailStartOutlookSession](../WDLang3/3032128.md) or [OutlookStartSession](../WDLang3/3032123.md)). 

- **Reminder**: This function cannot be used to add an appointment to an Outlook Express calendar.
