


## &lt;Chart&gt;.ColumnBarType (Function)

***In french: &lt;Graphe&gt;.HistoTypeBarre***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Defines the type of bar used in a column chart.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Column chart bars have rounded corners
CHART_MyChart.ColumnBarType(grColumnRoundedCorners)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Chart control>.ColumnBarType(<Bar shape>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).

**`<Bar shape>: (Integer constant)`**

Constant used to specify the shape of the bars: 


|   |   |
| --- | --- |
| *grColumnRoundedCorners* | Column chart bars have rounded corners. |
| *grColumnSquareCorners* | Column chart bars have square corners. |
