


## grColumnBarType (Function)

***In french: grHistoTypeBarre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the type of bar used in a column chart.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Column chart bars have rounded corners
grColumnBarType(CHART_MyChart, grColumnRoundedCorners)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`grColumnBarType(<Chart name> , <Bar shape>)`
---

**`<Chart name>: (Control name or character string)`**

Name of the chart to be used. This name corresponds to:

- the name of the chart defined programmatically with [grCreate](../WDLang3/3042005.md).

- the name of the Chart control in the window, page or report editor.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only Chart controls are available.

**`<Bar shape>: (Integer constant)`**

Constant used to specify the shape of the bars: 


|   |   |
| --- | --- |
| *grColumnRoundedCorners* | Column chart bars have rounded corners. |
| *grColumnSquareCorners* | Column chart bars have square corners. |
