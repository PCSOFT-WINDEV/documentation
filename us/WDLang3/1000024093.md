


## &lt;Chart&gt;.Mask (Function)

***In french: &lt;Graphe&gt;.Masque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Formats the data displayed by [&lt;Chart&gt;.Label](../WDLang3/1000024165.md)  or by [&lt;Chart&gt;.Tooltip](../WDLang3/1000024163.md)



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [The charts](../WDChamp/3042060.md). 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
CHART_MyChart.Mask(grMaskPercent, "99.99%")
CHART_MyChart.Label(grShowPercent, True)
CHART_MyChart.Draw()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Chart control>.Mask(<Type of mask> , <Mask value>)`
---

**`<Chart control>: (Control name)`**

Name of the Chart control to use (in the window, page or report editor).
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only interactive Chart controls are available.

**`<Type of mask>: (Numeric constant)`**

Mask used:


|   |   |
| --- | --- |
| *grMaskAxis* | The specified mask is used to format the values displayed on the chart axes.<br>**Example** Displays the value in the current currency: the mask value is "+99.999.999.999,99 $". |
| *grMaskPercent* | The specified mask is used to format the percentages displayed in the chart (grLabel(&lt;Chart Name&gt;, grShowPercent, True))<br>**Attention**: the % sign must be present in the &lt;Mask value&gt; parameter.<br>**Example**: "99.99%" allows displaying the percentage with 2 decimal places. |
| *grMaskTimeAxis* | The specified mask is used to format the dates or times displayed on the chart axes.<br>**Example** Displays the date in "DD/MM/YYYY" format: the value of the mask is "DD/MM/YYYY".<br><br><pre><code>CHART_MyChart.Mask(grMaskTimeAxis, "MM/DD/YYYY")</code></pre><br>This constant is supported only by chart types that can have a time axis: Histogram, Horizontal histogram, Curve and Area.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available. |
| *grMaskValue* | The specified mask is used to format the values displayed in the chart (grLabel(&lt;Chart Name&gt;, grShowValue, True))<br>**Example** Displays the value in the current currency: the mask value is "+99.999.999.999,99 $". |



**`<Mask value>: (Character string)`**

Description of the mask to use.

- For the constant *grMaskValue* Empty string ("", default value) to disable display mask.

- For the constant *grMasquePercent* constant: "99%": default value.

- For the *grMaskTimeAxis* constant: 
	

	- If the value to display is a date, it must be in "YYYYMMDD" format. The supported masks are identical to the ones used by [&lt;Date type&gt;.ToString](../WDLang1/1000023952.md).

	- If the value to display is a time, it must be in "HHMMSSCC" format. The supported masks are identical to the ones used by [TimeToString](../WDLang1/3027023.md).





Masks are defined using the following characters: "9", ".", ",", "+", "-" and spaces.. For example: "99.999,99". For the currency masks, use up to 17 significant digits for the integer part and 6 for the decimal part. For example: "99 999 999 999 999,999999".

**Remarks**:

- In order for the number to be filled with zeros on the left, the "0" character must be used on the left of the mask. For example: "099.999.99".

- To force the signs, use the "+" character on the left. For example: "+9999".
