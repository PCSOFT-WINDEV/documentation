


## SSHDisconnectCommand (Function)

***In french: SSHDéconnecteCommande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops the SSH session that was active to send a series of commands. This SSH session must have been previously activated with [SSHConnectCommand](../WDLang3/1410091112.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Session is sshSession
// Session properties
// ...
// Initialize SSH session to keep
SSHConnectCommand(Session)
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
SSHCommand(Session, "echo 'Hello world!'")
// Close SSH session to go back to normal behavior
SSHDisconnectCommand(Session)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`SSHDisconnectCommand(<SSH session>)`
---

**`<SSH session>: (sshSession variable)`**

Name of a variable of type [sshSession](../WDLang3/1000021157.md) containing the connection parameters of the SSH session to be closed.
