


## &lt;websocketClient variable&gt;.Disconnect (Function)

***In french: &lt;Variable websocketClient&gt;.Déconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Disconnects a client from a WebSocket server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve list of clients
arrClients is array of websocketClient = WebSocketListConnectedClient()
// Disconnect some clients
FOR ALL tabClient oClients
	IF oClient.Disconnect() THEN
		oClient.Disconnect()
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Client>.Disconnects()`
---

**`<Client>: (websocketClient variable)`**

Name of the [websocketClient](../WDLang3/1000025952.md) variable that corresponds to the client to be disconnected.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The client disconnection process is called when the client is disconnected.

- **This function is asynchronous**the function only requests the client to disconnect. The client can be actually disconnected later (after **&lt;websocketClient variable&gt;.Disconnect** has been executed). **&lt;websocketClient variable&gt;.Disconnect** never returns an error (for example, if the client has been disconnected in the meantime).
