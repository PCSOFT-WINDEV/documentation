
## NearbyShareDisconnect (Function)

***In french: PartageProximitéDéconnecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the connection with a nearby device.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NearbyShareDisconnect(gSelectedDevice.ID)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`NearbyShareDisconnect(<Device identifier>)`
---

**`<Device identifier>: (Character string)`**

Identifier of the nearby device for which the connection is to be closed.
