
## sInExitQueue (Function)

***In french: sDansFileSortie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the number of bytes waiting to be transferred in the output buffer of the specified serial port or parallel port.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function returns information regarding the server.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// The COM2 port is opened
// Send a message to the output buffer of COM2
sWrite(2, MyMessage)
// Wait for the end of the write operation
LOOP
	IF sInExitQueue(2) = 0 THEN BREAK
END
Info("End of write operation")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = sInExitQueue(<Port number>)`
---

**`<Result>: (Integer)`**

Number of bytes waiting to be transferred. 

**`<Port number>: (Integer)`**



- Serial port number: 1, 2, 3, ... 32 for COM1, COM2, COM3, ... COM32.

- Parallel port number: -1, -2, -3 or -4 for LPT1, LPT2, LPT3 or LPT4.

- Number of relevant infrared port: 1, 2, 3, ... 32 for IR1, IR2, IR3, ... IR32.

- Port number returned by [sOpen](../WDLang3/3062013.md) (if this function was called with a port name).
