
## HTTPConfigure (Function)

***In french: HTTPParamètre***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>28</B>, ***HTTPParameter*</**>** is kept for backward compatibility. This function has been replaced with ***HTTPConfigure*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Configures the functions that use the HTTP protocol ([HTTPRequest](../WDLang3/3043007.md), [HTTPSendForm](../WDLang3/1000017190.md), [SOAPRun](../WDLang3/3069013.md), [SOAPRunXML](../WDLang3/3069014.md), [Imported web services](../WDLang3/3086001.md), [SFExecuteQuery](../WDLang5/1000018438.md), etc.).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HTTPConfigure(httpConfigureMode, 1)
HTTPRequest("www.pcsoft.fr")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HTTPConfigure(<Option to modify> , <New value>)`
---

**`<Option to modify>: (Integer constant)`**

Parameter to modify: 


|   |   |
| --- | --- |
| *httpConfigureDisableCache* | In secure mode (HTTPS), used to manage the cache of Internet Explorer. The &new value> associated with this constant can be:<br><br>- 0 (<u><u><u><u>False</u></u></u></u> default): Re-enables Internet Explorer's cache.<br><br>- 1 (<u><u><u><u>True</u></u></u></u>): Disables Internet Explorer's cache.<br><br><br> |
| *httpConfigureDisableCookie* | In secure mode (HTTPS), used to configure the mode for managing the HTTP cookies of Internet Explorer. The &lt;New value&gt; associated with this constant can be:<br><br>- 0 (<u><u><u><u>False</u></u></u></u> default): Re-enables Internet Explorer's HTTP cookie handling.<br><br>- 1 (<u><u><u><u>True</u></u></u></u>): Disables HTTP cookie handling in Internet Explorer. <br><br><br> |
| *httpConfigureMode* | Configures the request handling mode. The &lt;New value&gt; associated with this constant can be:<br><br>- 0 (<u><u><u><u>False</u></u></u></u> by default): HTTP requests handled by the common framework for WINDEV executables, WEBDEV sites and web services. In this mode, if a request requires HTTPS, mode 1 will automatically be used.<br><br>- 1 (<u><u><u><u>True</u></u></u></u>): Handling of HTTP and/or HTTPS requests by the Windows API running the Process.<br><br>- 2: Management of HTTP and/or HTTPS requests by a cross-platform implementation common to all frameworks. <br>	In this mode, a WINDEV application can exchange HTTPS data in the same way as a WINDEV Mobile application for iOS or Android. This mode can be used to replace the Windows API when it cannot encrypt HTTPS data.<br><br><br> |



**`<New value>: (Integer)`**

New value of the modified parameter.
