


## &lt;Chart&gt;.Tooltip (Function)

***In french: &lt;Graphe&gt;.Bulle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays and formats: 

- the tooltip associated with each graph section (sector for a Pie chart, bar for a Bar chart, etc.). This function also gets the characteristics of the tooltip associated with each section of the chart.

- a custom tooltip, associated with a point.




By default, a tooltip is automatically displayed (*grShowTooltip* set to <u><u><u>True</u></u></u>) when a chart is hovered by the mouse cursor.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In a page of a WEBDEV website, the chart must be interactive in order for the tooltip to be displayed. To make the chart interactive, check "Interactive chart" in the "Details" tab of the control description.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Chart control
// Display the percentages on a column chart
CHART_MyChart.Label(grShowPercent, True)
CHART_MyChart.Tooltip(grTooltipFormat, -%"[%SERIES%]" + CR + -%"[%CATEGORY%]" + CR + -%"[%VALUE%]")
CHART_MyChart.Tooltip(grShowTooltip, True)
// Draw chart in Chart control
CHART_MyChart.Draw()
```
<a name="Exemple2"></a>

```wl
// Chart control
// Display a specific tooltip for a point
CHART_MyChart.Tooltip(1, 2, "The content of my tooltip")
// Draw chart in Chart control
CHART_MyChart.Draw()
```

If the default format is used:

- "[%CATEGORY%]" is ignored if no category label was specified by [&lt;Chart&gt;.CategoryLabel](../WDLang3/1000024072.md).

- "[%SERIES%]" is ignored if no series label was specified with [&lt;Chart&gt;.SeriesLabel](../WDLang3/1000024073.md).


**Warning: A compilation error may occur** If you use dynamic string construction (option "Allow "[% %]" in strings" in the "Compilation" tab of the project description), a compilation error may appear (unknown identifier). In this case, each string must be preceded by '-%'. Example: 

```wl
CHART_Deadline.Tooltip(grTooltipFormat, "[%CATEGORY%]" +CR +CR + "[%VALUE%]" + "H")
```
 becomes

```wl
CHART_Deadline.Tooltip(grTooltipFormat, -%"[%CATEGORY%]" + CR + CR + -%"[%VALUE%]" + " H")
```

### Customizable tooltip via an internal window
<a name="customizable_tooltip_via_internal_window_ELTPARAGRAPHE001422"></a>

The function **&lt;Chart&gt;.Tooltip** used with the constant *grFormatBubbleInternalWindow* is used to specify the internal window used to display the tooltip for a Chart control. 

This internal window is for display only. No interaction between user and bubble possible. 

This internal window uses the following prototype: 

```txt
PROCEDURE MyWindow(FieldGraph is Field, 
IndexSeries is an integer, IndexValue is an integer, Value is a real, LabelBubble is a string)
```
where: 

- ChartControl: Name of the Chart control used. 

- SeriesIndex: Index of the series corresponding to the point hovered over. 

- Index: Index of the point value overflown. 

- Value: Value of the point hovered over. 

- BubbleLabel: Label of the bubble normally displayed. This label can be formatted using the function **&lt;Chart&gt;.Tooltip** used with the constant *grFormatBulle*. 



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=grBulle_Perso%20-%20HC%20N%B0001.gif)


Characteristics of internal window: 

- Fields in the internal window cannot be manipulated by the user. 

- The opacity defined for fields in the internal window is taken into account. 

- The size of the internal window used for the tooltip automatically adapts to the content when displayed. 




Special cases: 

- In the case of a multi-series crosshairs, the series index and value correspond to the point closest to the mouse. In this case, the "Index" parameter is identical for all points. 
	For Stock chart, Bubble chart, Heatmap and Range Area chart types, a single value is returned. 

- In the internal window code, it is possible to retrieve data from other series using the [&lt;Chart&gt;.GetData](../WDLang3/1000024122.md) function. For example: 
	



```wl
// Retrieve previous value
FieldGraph.retrieveData(NumSeries, Indice-1)
```
It is also possible to retrieve information such as the legend or color of the series using the properties available in the Chart control.
