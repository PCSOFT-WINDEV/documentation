
## TaskModify (Function)

***In french: TâcheModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the current task in a Lotus Notes or Outlook task list.

When a task is read, the data of this task is updated in the [Task structure](../WDLang3/1000012010.md). To modify the current task, all you have to do is modify the values of the [Task structure](../WDLang3/1000012010.md) and validate the modifications with **TaskModify**.

**Note**: This function **cannot be used** to modify the current task in an Outlook Express task list.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start a Lotus Notes session
SessionID is int
SessionID = EmailStartNotesSession("Password", "MarsServer", "email/julia.nsf",...
					"C:\Users\Julia\AppData\Local\Lotus\Notes\Data\user.id")

// Read the first task
TaskFirst(SessionID)
// Modify the start date
mTask.StartDate = "20070125100000"
TaskModify(SessionID)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = TaskModify(<Session identifier>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the modification was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant. 




**`<Session identifier>: (Integer)`**

Session ID to be used. This ID is returned by one of the following functions: [EmailStartNotesSession](../WDLang3/3032121.md), [EmailStartOutlookSession](../WDLang3/3032128.md), [NotesOpenDatabase](../WDLang3/1000005101.md) or [OutlookStartSession](../WDLang3/3032123.md).
