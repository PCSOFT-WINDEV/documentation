


## &lt;ftpConnection variable&gt;.Connect (Function)

***In french: &lt;Variable ftpConnexion&gt;.Connecte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Connects the current computer to an FTP server (File Transfer Protocol).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The available secure connection modes are as follows: 

- FTPS: FTP secured using SSL with implicit encryption. 

- FTPES: FTP secured using SSL with explicit encryption. 

- SFTP: FTP secured using an SSH tunnel.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Syntax not available in PHP
// Connect the current computer to the FTP server
MyFTPConnection is ftpConnection
MyFTPConnection.Server = "192.54.12.8"
MyFTPConnection.Connect()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = FTPConnect(<FTP connection>)`
---

**`<Result>: (Integer)`**



- <u><u><u><u>True</u></u></u></u> if the connection has been established,

- <u><u><u><u>False</u></u></u></u> otherwise. The details of the error are returned by [ErrorInfo](../WDLang1/3013008.md) with the *errCode* or *errMessage* constant. 
	If an authentication error occurs, [ErrorInfo](../WDLang1/3013008.md) with the *errCode* constant returns the *ftpErrorAuthentication* constant.




**`<FTP connection>: (ftpConnection variable)`**

Name of the [ftpConnection](../WDLang3/1410090869.md) variable that describes the characteristics of the connection to the FTP server.
