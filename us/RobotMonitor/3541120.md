
## Checking the WEBDEV Application Server
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000078"></a>
The monitoring robot can check the WEBDEV Application Server.

The result of the check will be:

- success, if the WEBDEV Application Server responds.

- failure otherwise.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Parameters specific to WEBDEV Application Server checks
<a name="parameters_specific_webdev_application_server_checks_ELTTEXTE000102"></a>


### WEBDEV Application Server information
<a name="webdev_application_server_information_ELTPARAGRAPHE000023"></a>

The WEBDEV Application Server characteristics to be checked are:

- WEBDEV Application Server address.

- WEBDEV Application Server version (e.g., 31).

- platform (Windows or Linux)
