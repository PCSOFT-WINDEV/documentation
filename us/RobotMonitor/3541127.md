
## SSL certificate validity
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000074"></a>
The robot will check that the SSL certificate expiration time is greater than the time specified in the check parameters. 

The result of the check will be: 

- success, if the time before the certificate expires is greater than the specified duration. 

- error, otherwise.  




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## SSL certificate check parameters
<a name="ssl_certificate_check_parameters_ELTTEXTE000098"></a>


### Details of the server hosting the certificate
<a name="details_the_server_hosting_the_certificate_ELTPARAGRAPHE000021"></a>

To check the validity of the SSL certificate, you need to specify:

- server address.

- connection port.

- number of days before an alert is generated. This duration will be compared with the number of days remaining before the certificate expires.
