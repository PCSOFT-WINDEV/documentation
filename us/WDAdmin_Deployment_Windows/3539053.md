## Overview
<a name="overview_ELTTEXTE000118"></a>
**WEBDEV** is a full development environment dedicated to Internet and Intranet. WEBDEV is the perfect tool for developing Internet and Intranet sites that require access to a  database.

The technology we use ensures that our dynamic sites work with all browsers on the market, whatever their version, whether they run on PC, MAC, Unix, etc.

This technology also enables applications to be used with all Windows servers on the market: Apache, IIS, etc.

WEBDEV includes:

- **WEBDEV Development Version**: 
	This version, Installed on the development computer, allows you to develop a WEBDEV website and test it locally.

- **WEBDEV Application Server**: 
	Installed on a server at the hosting provider, this version is used to deploy a WEBDEV website. The site can be used by all Web users.




**Remark**: To deploy a static site (which does not use data), the WEBDEV Application Server is not required.

## WEBDEV Application Server features
<a name="webdev_application_server_features_ELTTEXTE000142"></a>
**The WEBDEV** application server must be installed on a server workstation (at the hosting company or on an Intranet server workstation).. Via the WEBDEV Application Server:

- Web users can use dynamic WEBDEV websites.

- The server administrator can:

	- Manage and configure dynamic WEBDEV websites located on the server.

	- Configure the WEBDEV accounts associated with each site manager.

	- Install dynamic WEBDEV websites from the DVD supplied by the site manager.

	- Monitor the setup and update of dynamic WEBDEV websites remotely (via FTP or HTTP).

	- Monitor the servers where the dynamic WEBDEV websites are installed.




- The manager of the WEBDEV sites can:

	- Perform remote setups and updates of his dynamic sites (by FTP or HTTP).

	- Change the configuration of dynamic WEBDEV websites.

	- Perform stress tests on the deployment server.

	- Monitor the Web server where the WEBDEV sites are installed.

### Warning
<a name="warning_ELTPARAGRAPHE000057"></a>

Even though WEBDEV 2026 assists you the best it can, the remote setup requires an "expert" level for configuring the server. This area is NOT directly related to WEBDEV. These settings cannot be defined by a novice.

You must have a minimum knowledge of this area or have knowledgeable help.



If you want to use these advanced features, plan to spend the required time for installing them and for configuring them. This setting depends on several parameters not related to PC SOFT and to WEBDEV.
