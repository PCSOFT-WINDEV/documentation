
## Errors during an FTP installation
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The list below presents the error messages that are displayed in the remote setup wizard (for the site manager). Some of these messages require specific actions for configuring the deployment Web server.

Several solutions are proposed for each error.

Error messages can be displayed at different steps of remote setup.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Step 1: typing the logins and the Server/FTP passwords (site setup)
<a name="step_1_typing_the_logins_and_the_serverftp_passwords_site_setup_ELTTEXTE000545"></a>
The setup wizard checks the validity of usernames and passwords. The list of errors that can occur is as follows.
<a name="NOTE2_2"></a>


### Failure checking the user password: no information was returned by the server.
<a name="failure_checking_the_user_password_information_was_returned_the_server_ELTPARAGRAPHE000031"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The Web server does not operate | Restart the Web server on the server. |
| The FTP server is not working. | Restart the FTP server on the server. |
| The FTP server is not configured properly: wrong username, ... | Check the configuration of the FTP server for the user.<br>Warning: If you are using the IIS FTP server, check that:<br><br>- the user is defined at Windows level<br><br>- the alias of FTP transfer directory corresponds to the Windows username.<br><br><br> |
| WEBDEV Deployment is not installed properly. | Reinstall the WEBDEV Application Server. |


<a name="NOTE2_3"></a>


### The FTP password is incorrect or the FTP server cannot be accessed.
<a name="the_ftp_password_incorrect_the_ftp_server_cannot_accessed_ELTPARAGRAPHE000066"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The FTP password specified by the site manager is incorrect. | Check the FTP password and communicate this password to the site manager. |
| The FTP server is not working. | Restart the FTP server. |
| The number of authorized connections on the FTP server is exceeded. | The site manager must wait for a connection to the FTP server to be freed. |
| The Web server address is incorrect. | Indicate to the site manager the exact address of Web server where the site will be installed by FTP. |


<a name="NOTE2_4"></a>


### Failure checking the user password: the user is unknown. Check the server address and the username
<a name="failure_checking_the_user_password_the_user_unknown_check_the_server_address_and_the_username_ELTPARAGRAPHE000096"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| WEBDEV Account Manager does not recognize the site manager. | Check that a WEBDEV account has been created in the WEBDEV Account Manager for this site manager and communicate the corresponding login to the site manager. |


<a name="NOTE2_5"></a>


### Failure checking the user password: no information was returned by the server.
<a name="failure_checking_the_user_password_information_was_returned_the_server_ELTPARAGRAPHE000114"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The password specified during the remote setup does not correspond to the password defined in the account manager. | Check the password associated with the site manager in WEBDEV Account Manager and communicate this password to the site manager. |

## Step 2: Installing the site (setup or update)
<a name="step_2_installing_the_site_setup_update_ELTTEXTE000593"></a>
The setup wizard allows you to install or update the site. The list of errors that can occur is as follows.
<a name="NOTE3_2"></a>


### Unable to create a temporary directory on the server. Contact the server administrator.
<a name="unable_create_temporary_directory_the_server_contact_the_server_administrator_ELTPARAGRAPHE000141"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The Windows account that runs the WD310AWP protocol manager has no sufficient rights to create a temporary directory. | Grant the necessary rights to the Windows account.<br><br>Note: To find out which account is running the WD310AWP protocol, start the Internet Services Manager (for IIS, option "Start . Run . Inetmgr.exe" from the Windows desktop) and display the properties of the "WWW" service. The Windows account corresponds to the username used to start an anonymous session. For more details, see [Summary table about the necessary rights](../NonDocumente/3539049.md). |


<a name="NOTE3_3"></a>


### The client name is unknown. Check the client name and the associated password.
<a name="the_client_name_unknown_check_the_client_name_and_the_associated_password_ELTPARAGRAPHE000170"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| WEBDEV Account Manager does not recognize the site manager. | Check that a WEBDEV account has been created in the WEBDEV Account Manager for this site manager and communicate the corresponding login to the site manager. |


<a name="NOTE3_4"></a>


### The files required for setup have not been transmitted properly. Check whether the username and the FTP password are correct and correspond to the owner account of site
<a name="the_files_required_for_setup_have_not_been_transmitted_properly_check_whether_the_username_and_the_ftp_password_are_correct_and_correspond_the_owner_account_site_ELTPARAGRAPHE000188"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| An error occurred during the FTP transfer. The file installed on the server cannot be read. | The site manager must restart their setup. <br>Warning: If this is a first-time installation, the site manager must delete the server description from the "Remote update" list. |


<a name="NOTE3_5"></a>


### The setup file is invalid. The file was transmitted incorrectly or was damaged.
<a name="the_setup_file_invalid_the_file_was_transmitted_incorrectly_was_damaged_ELTPARAGRAPHE000208"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| An error occurred during the FTP transfer. The file installed on the server cannot be read. | The site manager must restart their setup. <br>Warning: If this is a first-time installation, the site manager must delete the server description from the "Remote update" list. |


<a name="NOTE3_6"></a>


### Error while decrypting the setup information. Check the password used.
<a name="error_while_decrypting_the_setup_information_check_the_password_used_ELTPARAGRAPHE000228"></a>

When programming a delayed setup, one of the following problems occurred:  

| Possible problem | Solution |
| --- | --- |
| The password specified during the remote setup does not correspond to the password defined in the account manager. | Check the password associated with the site manager in the account manager and communicate this password to the site manager. |


<a name="NOTE3_7"></a>


### Unable to add schedule due to the following error: XXX:
<a name="unable_add_schedule_due_the_following_error_xxx_ELTPARAGRAPHE000246"></a>

When programming a delayed setup, one of the following problems occurred:

| Possible problem | Solution |
| --- | --- |
| Insufficient memory | You need to free up memory on the Web server and then re-enter the deferred installation. |
| Local WEBDEV administrator cannot be found. Check that WEBDEV Application Server is correctly installed on the server. | The local WEBDEV administrator does not respond to the programming request. Error when launching local WEBDEV administrator: check that the WEBDEV Application Server is correctly installed on the server. |


<a name="NOTE3_8"></a>


### A site with the same name is already installed on this server. The same server cannot host two sites with the same name. Rename your site or uninstall the existing one. If it is the same site, you must update your site (instead of a creating a new setup).
<a name="site_with_the_same_name_already_installed_this_server_the_same_server_cannot_host_two_sites_with_the_same_name_rename_your_site_uninstall_the_existing_one_the_same_site_you_must_update_your_site_instead_creating_new_setup_ELTPARAGRAPHE000268"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| During a setup via FTP, two sites with the same name cannot be installed on the same Web server, even if they belong to different site managers. | For a first setup of the site on the server, the WEBDEV website manager must rename their site (rename their project). |

Note: To perform an update via FTP, you must use the "Remote update" option when installing the site via FTP (and not the "Remote install" option).
<a name="NOTE3_9"></a>


### Unable to create the site directory. Contact the server administrator.
<a name="unable_create_the_site_directory_contact_the_server_administrator_ELTPARAGRAPHE000288"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The base directory of sites does not exist | Check the base directory of sites specified in the account manager and make sure this directory exists. |
| Access rights to the site directory are insufficient | Grant the necessary rights to the Windows account that runs the WD310AWP.EXE protocol manager. |


<a name="NOTE3_9a"></a>


### Unable to create the directory of data files. Contact the server administrator.
<a name="unable_create_the_directory_data_files_contact_the_server_administrator_ELTPARAGRAPHE000312"></a>

The possible problems are as follows:


|   |   |
| --- | --- |
| Problems | Solution |
| The base directory of data does not exist. | Check the base directory of data specified in the account manager and make sure this directory exists. |
| The access rights to the base directory of data are insufficient. | Grant the necessary rights to the Windows account that runs the WD310AWP.EXE protocol manager. |


<a name="NOTE3_9b"></a>


### Write error in the registry. Contact the server administrator.
<a name="write_error_the_registry_contact_the_server_administrator_ELTPARAGRAPHE000336"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The Windows account that runs the WD310AWP protocol manager has no sufficient rights to write into the registry. | Grant the necessary rights to the Windows account. Use Regedt32.exe to grant the rights to write into the registry. |


<a name="NOTE3_10"></a>


### Unable to open the file containing the custom error messages.
<a name="unable_open_the_file_containing_the_custom_error_messages_ELTPARAGRAPHE000356"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The message file was not supplied in the setup. | Reinstall and check whether the files required to customize the error messages are found (.REG file). |


<a name="NOTE3_11"></a>


### Error writing to the registry while creating the custom error messages.
<a name="error_writing_the_registry_while_creating_the_custom_error_messages_ELTPARAGRAPHE000374"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The message file is invalid. | Check whether the configuration file of error messages supplied with the setup corresponds to the site to install. |

## Step 3: Updating a site
<a name="step_3_updating_site_ELTTEXTE000689"></a>
When updating the site, the setup wizard checks whether the site is installed and configured properly. The list of errors that can occur is as follows.
<a name="NOTE4_2"></a>


### Unknown site name:
<a name="unknown_site_name_ELTPARAGRAPHE000401"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The site is not installed on the server | Perform a full remote setup. |
| The site is no longer referenced in the local WEBDEV administrator | Reference the WEBDEV website in the local WEBDEV management tool ("Sites" tab, "Add" button). |


<a name="NOTE4_3"></a>


### The name of requesting client does not correspond to the name of site owner
<a name="the_name_requesting_client_does_not_correspond_the_name_site_owner_ELTPARAGRAPHE000423"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| This site was installed by another site manager. | In WEBDEV Account Manager, assign the site to the corresponding WEBDEV account. Check whether the home directories (for data, site and FTP transfer) are correct. |


<a name="NOTE4_4"></a>


### Failure during the encryption
<a name="failure_during_the_encryption_ELTPARAGRAPHE000441"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| The update failed to be encrypted. | Free memory space and/or disk space on the computer that performs the update (computer of site manager for example). |


<a name="NOTE4_5"></a>


### Error while copying the information file. Check the information of WEBDEV account and retry.
<a name="error_while_copying_the_information_file_check_the_information_webdev_account_and_retry_ELTPARAGRAPHE000459"></a>

The possible problems are as follows:

| Possible problem | Solution |
| --- | --- |
| Unable to copy temporary file that describes the site status. The user does not have sufficient rights in the FTP directory | Grant the rights to write into the FTP directory. |
| Unable to copy temporary file that describes the site status. Insufficient disk space | Free disk space on the computer. |
