### The WEBDEV administrator
<a name="the_webdev_administrator_ELTPARAGRAPHE000010"></a>

The WEBDEV administrator is a module used to manage dynamic WEBDEV websites (in Session or AWP mode). This module is required to implement the dynamic WEBDEV sites installed on the server.

During the deployment phase, two types of WEBDEV administrators are available:

- **the WEBDEV administrator** that allows the hosting provider to manage the dynamic WEBDEV websites installed on a Web server.

- **the remote WEBDEV administrator** that allows the site manager to manage their dynamic WEBDEV websites remotely from any computer.




To start the WEBDEV administrator, select "Programs .. WEBDEV 2026 application server.. WEBDEV administrator" from the "Start" menu.

You can:

- automate the administrator start by creating a shortcut in the start group of Windows.

- install the administrator in service, when installing WEBDEV Application Server.
	When the WEBDEV administrator is installed as service, you can start its interface only by specifying the INTERFONLY parameter in the command line. The command line becomes:
	C:\\WEBDEV31\\Programs\\WD310ADMIN.EXE /INTERFONLY 




**Caution**: The WEBDEV administrator must run in the background.

The WEBDEV administrator includes a window containing several tabs:

- ["Connections"](../WDAdminDeploiement/3539007.md) tab to configure the characteristics of current connections.

- ["Sites"](../WDAdminDeploiement/3539005.md) tab, which lists the WEBDEV websites installed on the current computer. 

- ["Web services"](../WDAdminDeploiement/3539076.md) tab, which lists the (SOAP or REST) WEBDEV web services installed on the current computer.

- ["WebSockets"](../WDAdminDeploiement/3539083.md) tab, which lists the WebSocket servers installed on the current computer. 

- ["Configuration"](../WDAdminDeploiement/3539006.md) tab to configure the general configuration of WEBDEV websites installed on the current computer.

- ["Advanced"](../WDAdminDeploiement/3539068.md) tab to configure specific features.

- ["Cluster"](../WDAdminDeploiement/3539084.md) tab to configure the WEBDEV Cluster and its nodes. 

- ["Setups"](../WDAdminDeploiement/3539067.md) tab to manage the WEBDEV server on the current computer.

- ["Logs"](../WDAdminDeploiement/3539074.md) tab to view the content of logs.




**With a Linux server**:

With a Linux server, we recommend that you use the remote administrator to manage the dynamic WEBDEV websites.

However, a WEBDEV administrator is also available. To view the interface of this administrator, you must:

- have the X11 server installed to see the graphic administrator interface.

- start the administrator by using the following command line: wd310admin /INTERFONLY (case sensitive). This file is located in the installation directory of WEBDEV Application Server.




**Remark**: Some features of the WEBDEV administrator are not available in Linux, including:

- the management of email spooler.

- the management of error messages. This option is available in the remote administrator.

- the management of prints.
