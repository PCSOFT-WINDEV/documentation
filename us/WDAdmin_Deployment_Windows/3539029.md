## Overview
<a name="overview_ELTTEXTE000074"></a>
WEBDEV Account Manager allows you easily host websites developed with WEBDEV 2026. This tool is mainly intended for webmasters and hosting providers. WEBDEV Account Manager manages WEBDEV and IIS accounts (versions 5.xx and later) and the rights of the Windows operating system.

A default choice is proposed, allowing you to easily install a server, with no particular knowledge.

The creation of Client accounts can be automated. The following elements are centralized: 

- Windows accounts,

- Groups of FTP users,

- Groups of WEBDEV clients,

- Home Directory,

- FTP alias,

- WEBDEV accounts,

- Data directories,

- Virtual websites, etc.
