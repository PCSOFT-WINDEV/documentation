
## Configuring the server for the CGI/AWP protocol
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000124"></a>
To use the WEBDEV Application Server, a Web server must be found on the computer where the WEBDEV Application Server, the WEBDEV websites and the web services are installed. This server allows you to run the test of developed sites and web services.

Several Web servers are available for Windows: IIS, Apache, ... 

The configuration mode of these servers depends on:

- the editor,

- the server version,

- the operating system,

- and other parameters.




Using a Web server to run the test of dynamic WEBDEV websites with the WEBDEV Application Server requires a specific configuration for the CGI protocol.

This configuration is defined during the setup of the WEBDEV Application Server.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## WEBDEV Application Server installation
<a name="webdev_application_server_installation_ELTTEXTE000148"></a>
When installing WEBDEV, the Web server for the CGI protocol is automatically configured for the following Web servers:

- Apache 2.x.

- IIS version 7 to 10: Microsoft Windows server.




If the Apache server is detected on the setup computer, it is automatically configured. In some cases, specific information may be required to manage manual Apache settings (Easy php, Wamp, ...).

If the Apache server is not installed, IIS is automatically configured on the systems later than Windows Vista. On systems that use IIS 5 or 6 or without Web server, you can install an Apache server and configure it automatically.  

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Manual configuration of Web servers for WEBDEV
<a name="manual_configuration_web_servers_for_webdev_ELTTEXTE000172"></a>
Follow this method:

1. Create an alias on the CGI protocol of WEBDEV.

2. This alias must have the following characteristics:

	- Name: WD310AWP

	- Associated directory: WEBDEV engine directory (subdirectory "Programs\\AWP" of the WEBDEV installation directory).

	- Associated rights: Read, Execute
