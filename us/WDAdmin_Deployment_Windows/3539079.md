## Configuring the Web IIS server version 7 to 10 for WEBDEV
<a name="configuring_the_web_iis_server_version_7_10_for_webdev_ELTTEXTE000085"></a>


### Configuring the server for the CGI protocol (AWP)
<a name="configuring_the_server_for_the_cgi_protocol_awp_ELTPARAGRAPHE000009"></a>



1. Open the Microsoft Internet service manager ("Start .. Run .. Inetmgr.exe" from the Windows desktop).

2. Select the Web server into which the alias is be added.

3. Add a new virtual directory (via the context menu for example).

4. Specify:

	- AWP protocol alias: WD310AWP.

	- the AWP protocol directory ("Programs\\AWP" subdirectory of the WEBDEV installation directory).




5. Grant the following rights: Read - Execute

## Configuring the server for the WEBDEV websites and the SOAP web services
<a name="configuring_the_server_for_the_webdev_websites_and_the_soap_web_services_ELTTEXTE000109"></a>


1. Open the Microsoft Internet service manager ("Start .. Run .. Inetmgr.exe" from the Windows desktop).

2. Select the Web server into which the alias is be added.

3. Add a new virtual directory (via the context menu for example).

4. Specify:

	- the alias of the directory containing your project images: &lt;MonProjet&gt;_WEB. For example: MARKET_WEB.

	- the directory containing the images of your project: &lt;Project Name&gt;_WEB. For example: C:\\WWProject\\MARKET\\MARKET_WEB.




5. Grant the following rights: Read - Scripts
