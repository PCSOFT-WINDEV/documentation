## Overview
<a name="overview_ELTTEXTE000068"></a>
The remote WEBDEV administrator is a WEBDEV website, installed on the Deployment web server. This site allows:

- the site manager to directly manage their WEBDEV sites installed on the Web server.

- the server administrator to directly manage the WEBDEV accounts and the WEBDEV sites installed on the Web server.




**On a Linux server, it is recommended to use the remote administrator to manage the server and the dynamic WEBDEV websites installed on the server**.

Whether the WEBDEV website is installed remotely or via physical media, the manager of WEBDEV websites has the ability to use the remote administrator (if it is installed on the server). 

For more details, see the online help of remote of the WEBDEV administrator.
