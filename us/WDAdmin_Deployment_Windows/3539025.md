## Overview
<a name="overview_ELTTEXTE000166"></a>
This page presents the main terms specific to WEBDEV used in the documentation of WEBDEV Application Server. Unless stated otherwise, all texts referring to the sites can be applied to web services.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Vocabulary
<a name="vocabulary_ELTTEXTE000190"></a>


### Server administrator
<a name="server_administrator_ELTPARAGRAPHE000019"></a>

Person who installs software, websites, etc., on one or more servers of the hosting company. In the case of a shared server, the server administrator handles the distribution of connections per site manager, the physical location of sites on the server, etc.
<a name="NOTE2_2"></a>


### Remote WEBDEV administrator
<a name="remote_webdev_administrator_ELTPARAGRAPHE000028"></a>

Site installed on the Web server, allowing:

- the site manager to remotely check and/or modify the configuration of their WEBDEV websites installed on a server.

- the server administrator to remotely check and/or modify the configuration of all WEBDEV websites installed on the server. The server administrator can also manage the WEBDEV accounts.



<a name="NOTE2_3"></a>


### WEBDEV administrator
<a name="webdev_administrator_ELTPARAGRAPHE000040"></a>

Windows application installed on the server, allowing the server administrator to configure the different WEBDEV websites installed on the current server.

The local WEBDEV administrator can also be used to create the WEBDEV accounts.
<a name="NOTE2_4"></a>


### WEBDEV account
<a name="webdev_account_ELTPARAGRAPHE000051"></a>

Account associated with a site manager. 

This account allows the server administrator to:

- group the sites that belong to a site manager.

- configure the number of authorized connections for a site manager.

- configure the setup directories of sites

- configure the transfer directory (for a setup or an update via FTP).




This account allows the site manager to:

- use the remote administrator.

- perform remote site setups and updates.




This account is created on a Web server by the server administrator via:

- the local administrator,

- the remote administrator.



<a name="NOTE2_5"></a>


### Site developer
<a name="site_developer_ELTPARAGRAPHE000077"></a>

Person who creates and modifies WEBDEV websites with WEBDEV Development version.
<a name="NOTE2_6"></a>


### Manager of WEBDEV accounts (WDCompte)
<a name="manager_webdev_accounts_wdcompte_ELTPARAGRAPHE000086"></a>

Windows application used to create WEBDEV accounts. This application is started by the server administrator on a Web server. This application can only be used to create accounts for the current computer.

Note: The server administrator can also manage the WEBDEV accounts remotely via the remote administration tool.
<a name="NOTE2_7"></a>


### Hosting provider
<a name="hosting_provider_ELTPARAGRAPHE000097"></a>

Company proposing to host Internet sites on their Web servers.
<a name="NOTE2_8"></a>


### Web user
<a name="web_user_ELTPARAGRAPHE000106"></a>

User of Internet sites.
<a name="NOTE2_9"></a>


### Site manager
<a name="site_manager_ELTPARAGRAPHE000115"></a>

Person responsible for deploying and maintaining one or more WEBDEV websites. This person is in direct contact with the server administrator.
