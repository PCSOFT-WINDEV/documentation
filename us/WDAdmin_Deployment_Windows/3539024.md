## Common problems
<a name="common_problems_ELTTEXTE000070"></a>
The most common problems are as follows:

- **No Web server is installed on your computer**. In this case, install a Web server and reinstall WEBDEV.
	To find out whether a Web server is installed, click the "Server" button found in WEBDEV administrator ("Advanced" tab). If the selected option is "Other", then no Web server is installed on your computer or your Web server is not recognized by WEBDEV.
	Note: WEBDEV Application Server is supplied with a copy of the free Apache Web server.

- **A Web server is installed but this server is not started**. In this case, start the Web server used (for more details, see the documentation of Web server).

- **A Web server is installed but it does not work in the current environment**. In this case, install a Web server that is compatible with your environment and reinstall WEBDEV.

- **Several Web servers are installed on your computer and these servers are started at the same time**. In this case, choose the Web server that will be used with WEBDEV and stop the additional Web server.




Note: Check in WEBDEV administrator that the Web server set in the "Server" option of the "Advanced" tab corresponds to the chosen server.
