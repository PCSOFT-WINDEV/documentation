
## A site with the same name is installed on the server
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Setup by FTP/HTTP
<a name="setup_ftphttp_ELTTEXTE000077"></a>
During a setup by FTP or HTTP, two sites with the same name can be installed on the same Web server, even if these sites belong to different site managers. You can choose a deployment name that is different from the project name in the setup wizard.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Setup via physical media
<a name="setup_via_physical_media_ELTTEXTE000101"></a>
During a setup by physical media, two cases may occur if the site to install and an existing site have the same name:

- **Case 1: the new site is an update of the existing site**:
	Its setup will replace the files of the existing site. 
	Important: block the site beforehand using the WEBDEV administrator.

- **Case 2: the new site is unrelated to the existing site**:
	If this site is installed, the existing site will no longer be referenced in the WEBDEV administrator and it can no longer be used (the site is still found on disk but there is a single entry for each site name in the registry).
