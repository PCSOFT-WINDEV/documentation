
## Configuring the remote administrator
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000130"></a>
The remote WEBDEV administrator is an optional tool provided with WEBDEV 2026 application server. The remote WEBDEV administrator is a WEBDEV website, installed on the deployment Web server. This site allows:

- site managers to directly manage their WEBDEV sites installed on the Web server.

- the server administrator to remotely manage the WEBDEV accounts and the WEBDEV sites installed on the Web server.


**In Linux**, we recommend that you use the remote administrator to manage the dynamic WEBDEV sites as well as the WEBDEV server. 

Regardless of the type of deployment performed, the Web server must be configured to allow the use of remote WEBDEV administrator:

|   | Initial deployment via FTP/HTTP | Initial deployment by physical media |
| --- | --- | --- |
| Using the remote WEBDEV administrator | Operation to perform: Specify the launch address | Operation to perform: Specify the launch address |


**Note**: For optimum security, we recommend using the Remote Administrator in the following context:

- SSL access (with a purchased or self-signed certificate).

- Isolated on a virtual site different from the rest of sites or web services and where the AWP protocol is run by a user account created for this purpose only.



<a name="NOTE1_2"></a>


### Address for starting the remote WEBDEV administrator
<a name="address_for_starting_the_remote_webdev_administrator_ELTPARAGRAPHE000043"></a>

To use the remote WEBDEV administrator, the site manager must know the address for starting the remote WEBDEV administrator.

This address must be given to the site manager.

The syntax for a ** Windows or Linux server** address is of the form: 

```txt
http://PosteServeur/WDAdminWeb
```
where Server is the name of the web server where the WEBDEV Application Server is installed. This name can be:

- an IP address (192.178.1.130 for example)

- the computer name (DocComputer for example)



<a name="NOTE1_3"></a>


### Note: Secure access to the remote administrator
<a name="note_secure_access_the_remote_administrator_ELTPARAGRAPHE000062"></a>

If the remote WEBDEV administrator was secured during its setup (and if an SSL key was installed to secure the remote WEBDEV administrator), the remote WEBDEV administrator will be automatically started in secure mode. 
**Attention**: SSL key installation and all SSL protocol formalities must be carried out.

**In Windows**, a registry key allows you to specify whether the remote WEBDEV administrator must be started in secure mode or in standard mode:

- Registry key: HKEY_LOCAL_MACHINE/SOFTWARE/PC SOFT/WEBDEV/31.0

- Value name: SSLADMIN (REG_SZ)




**In Linux**, simply add the following line into the /etc/PCSOFT/WEBDEV/31.0/WEBDEV.conf file:
SSLADMIN = 1
The value 1 is used to automatically enable the secure mode.
