## The different modules
<a name="the_different_modules_ELTTEXTE000186"></a>


### Modules required by the WEBDEV websites to operate
<a name="modules_required_the_webdev_websites_operate_ELTPARAGRAPHE000019"></a>



| Name | Function | Started by |
| --- | --- | --- |
| AWP (Active Web Pages) manager | <br><br>- Decodes the information coming from the WEBDEV application.<br><br>- Sends the decoded information to the WEBDEV engine.<br><br><br> | Started by the Web server whenever a request is made by a Web user in a dynamic WEBDEV site. |
| WEBDEV engine | <br><br>- Runs the information transmitted by the AWP protocol.<br><br>- Builds the HTML dynamic page displayed by the Web server on the user's browser.<br><br><br> | Started by WD310AWP whenever a Web user connects to a dynamic WEBDEV website. |
| [Local administrator](../WDAdmin/3539021.md) | Allows the server administrator to:<br><br>- configure and manage the sites developed by WEBDEV and installed on the server.<br><br>- create the WEBDEV accounts.<br><br>- check the server configuration, ...<br><br><br>This tool is required for the WEBDEV sites to operate. | Executed when starting the computer where the Web server is installed. This tool can only be used by the server administrator. |


<a name="NOTE2_2"></a>


### Optional modules
<a name="optional_modules_ELTPARAGRAPHE000062"></a>



| Name | Function | Started by |
| --- | --- | --- |
| [Remote administrator (optional module)](../WDAdminDeploiement/3539019.md) | Allows you to:<br><br>- the managers of WEBDEV sites to directly manage their different WEBDEV sites installed on the server.<br><br>- the server administrator to remotely configure the different WEBDEV sites installed on the server, the WEBDEV accounts, ...<br><br><br> | Started by:<br><br>- the site manager from their browser.<br><br>- the server administrator from a computer other than the server, from their browser directly.<br><br><br> |
| [WEBDEV Account Manager (optional module)](../WDAdminDeploiement/3539029.md) | Allows the hosting providers to configure the Web server that is hosting the dynamic WEBDEV applications.<br><br>Note: Until version 28, this module was named "Hosting Control Center".  | Started by the hosting provider on the Web server. |
| [Monitoring robot (optional module)](../RobotMonitor/3541100.md) | Allows you to:<br><br>- the managers of WEBDEV sites to be informed if a problem occurs on the server (via email).<br><br>- the server administrator to be informed if a problem occurs on the server (via email).<br><br><br> | Started by the site manager:<br><br>- on the Web server (for a dedicated server).<br><br>- locally on a development computer for example (for a shared server).<br><br><br>Started by the server administrator on the Web server. |
| [Stress test (optional module)](../WDAdminDeploiement/3539015.md) | Used to create a test script on the server directly. Then, this script can be run from different computers. | Started by the site manager on the Web server directly to create a script for stress test. |
