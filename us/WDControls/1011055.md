## The different data sources
<a name="the_different_data_sources_ELTTEXTE000161"></a>
WINDEV, WEBDEV and WINDEV Mobile allow you to create reports with the report editor. The reports can be created with the data coming from:

- [a data file](../WDChamp/1011052.md).

- [the result of a query](../WDChamp/1011013.md).

- [a Table control in a window or page](../WDChamp/1011012.md).

- [a Looper control in a window or page](../WDChamp/1011093.md).

- [a variable](../WDChamp/1011058.md). 

- [a class passed as a parameter (MVP architecture)](../WDChamp/1011097.md).
	

- [a TreeView Table control in a window or page](../WDChamp/1011082.md).

- [an Organizer control in a window or page](../WDChamp/1011081.md). 

- [a Scheduler control in a window or page](../WDChamp/1011080.md). 

- [a view on an HFSQL data file](../WDChamp/1011064.md).

- [a memory area](../WDChamp/1011061.md).

- [a text file](../WDChamp/1011011.md).

- [a programmed data source](../WDChamp/1011034.md).




The report editor also allows you to create reports without a data source.[Reports & Queries](../Presentation/3088004.md) cannot be used to create:

- reports based on an HFSQL view. 

- reports based on a memory area. 

- reports based on a Table control. 

- reports based on a Looper control. 

- reports based on a TreeView Table control. 

- reports based on an Organizer control. 

- reports based on a Scheduler control. 

- reports based on a programmed data source. 




For more details, see [Limitations of Reports & Queries](../Presentation/3088005.md).
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only reports based on data files, queries or programmed data sources are available.

## Notes
<a name="notes_ELTTEXTE000203"></a>
If one of the above-mentioned data sources is selected, the report editor entirely manages the programming of the browse operations performed on the records to display in the report.

To program and select the records that will be displayed in the report, choose a [report based on a programmed data source](../WDChamp/1011034.md).
