## Default events
<a name="default_events_ELTTEXTE000143"></a>
The following events appear by default in the WINDEV code editor:


|   |   |
| --- | --- |
| **Event** | **Runtime condition** |
| Initialization | Executed when the window is opened. \* |
| Before sending the request | This event is called before sending the request to the AI provider. The question entered by the user can be modified. You can: <br><br>- Edit the text sent. <br><br>- Filter the text sent (delete words). <br><br>- Add additional information, which is not visible to the user. <br><br><br><br><br>This event receives a variable of type aiConversationElement as parameter, which represents the question entered by the user. This variable can be modified. <br><br>To prevent the question from being sent to the AI provider, use: <br><br><pre><code>RETURN False</code></pre><br> |
| While receiving the response | This event is executed each time a response token is received. <br><br>This event receives a String variable as parameter, which represents the response token.  <br><br>For example, this event allows you to display a progress bar while waiting for the response. |
| After receiving the response | This event is executed after the response has been received. <br><br>This event receives an aiConversationElement variable as parameter, which represents the text of the response. <br><br>For example, this event allows you to retrieve the elements attached to the response (images, etc.). |
| Error receiving the response | This event is executed if the AI model returns an error. <br><br>This event receives a String variable as parameter, which represents the error description. |
| Rate the response | This event is executed when the user clicks the "Like" or "Dislike" icons in the response provided by the AI model. <br><br>This allows you to determine if the AI model suits the users' needs, for example. <br><br>This event receives the following parameters: <br><br>- a Boolean variable, which represents to the clicked icon. <br><br>- an aiConversationElement variable, which represents the question that has been rated. <br><br>- an aiConversationElement variable, which represents the response that has been rated. <br><br><br><br><br>Note: Likes and Dislikes are also included in the information gathered by the application's metrics tools. |


(\*) By default, "Initialization" events are executed in the order in which the controls were created. To change this order:

1. On the "Window" tab, in the "Order" group, click "Initialization". 

2. In the window that appears, use the arrows on the right to change the order in which the controls are initialized.

## Optional events
<a name="optional_events_ELTTEXTE000167"></a>
Several optional events can be added.
To add an optional event:

1. Select the desired control.

2. Display the code window of this control (F2 key).

3. Click the link "Add other events to xxx" at the bottom of the window code, after the last event.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Traitements_optionnels_WD_OK%20-%20HC%20N%B0001.gif)


4. All the optional events available for the control are displayed. 

5. Check the optional event to add and validate. 
	Note: Several optional events can be selected. 

6. The selected optional event is automatically added to the events managed by the control.




To disable an optional event, simply perform the same operations to display the list of optional events. Then simply uncheck the optional events to delete. 
Note: If the deactivated code contains WLanguage code, this code is automatically deleted..For example, you can use the following events:

- the control rollover with the mouse,

- the left mouse button down, up, double click,

- right button down, up, double click,

- the mouse wheel, ...




For more details, see the [Optional events](../WDChamp/1014004.md).
