


## Manipulating Toolbar controls programmatically
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000139"></a>
WINDEV allows you to programmatically manipulate Toolbar controls. Simply use the variable of the Toolbar control in the code.

This variable of the Toolbar control corresponds to the toolbar name. This variable has no value.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Manipulating controls in a toolbar
<a name="manipulating_controls_toolbar_ELTTEXTE000163"></a>
The controls of a toolbar can be accessed:

- like any other control, by using their name directly.

- by specifying the name of the Toolbar control, then the name of the control. For example: 
	
	```txt
	Barre1.Bouton1
	```





**Remark**: size and position properties of toolbar fields are read-only.

<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## How to close a floating Toolbar control?
<a name="how_close_floating_toolbar_control_ELTTEXTE000187"></a>
To close a floating Toolbar control using the X button, you must write the following line of code in the "Close" event of the Toolbar control:


```wl
MoiMême..Visible = Faux
```
**Caution**: Do not use the [Close](../WDLang1/3038018.md) function.. This function closes the window and not the Toolbar control.

## Functions specific to Toolbar controls
<a name="functions_specific_toolbar_controls_ELTTEXTE000211"></a>
The following functions can be used to programmatically manipulate Toolbar controls:



|   |   |
| --- | --- |
| [ToolbarDock](../WDLang1/3020003.md) | Docks a Toolbar control to a window or changes the anchoring position of a docked Toolbar control. |
| [ToolbarPosition](../WDLang1/3020004.md) | Indicates the display mode of a Toolbar control. |
| [ToolbarUndock](../WDLang1/3020001.md) | Transforms a docked Toolbar control into a floating Toolbar control. |

## Properties specific to Toolbar controls
<a name="properties_specific_toolbar_controls_ELTTEXTE000258"></a>
The following properties can be used to programmatically define the characteristics of Toolbar controls: 


|   |   |
| --- | --- |
| [Height](../Proprietes/2510050.md) | Gets the height of a Toolbar control. |
| [InitialHeight](../Proprietes/2510043.md) | Gets the initial height of a Toolbar control. |
| [InitialWidth](../Proprietes/2510067.md) | Gets the initial width of a Toolbar control. |
| [Width](../Proprietes/2510059.md) | Gets and sets the width of a Toolbar control. |


For a complete list of WLanguage properties that can be used with Toolbar controls, see [Toolbar control properties](../WDChamp/1013124.md).
