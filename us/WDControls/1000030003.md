
## Gantt Chart control properties
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000081"></a>
You can manipulate Gantt Chart columns in Table or TreeView Table controls using the following WLanguage properties.

Note: These properties are the same as those used for a column in a Table or TreeView Table control.

You can also use WLanguage properties on Gantt charts in a report.
