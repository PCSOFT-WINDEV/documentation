
## Styling maps from Google Maps
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000174"></a>
In WINDEV and Android applications, Map controls use Google Maps. Google has updated their map styling functionalities and now offers a wide range of possibilities. 

Prior to this update, map styles were predefined and could be manipulated using the [MapChangeStyle](../WDLang3/1000025556.md) and [MapGetStyle](../WDLang3/1000025557.md) functions. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) These functions are still supported, if no customized maps are used. If you use a customized map, these functions have no effect. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) These functions are no longer available. 




Now, the steps for defining and using a map style are as follows:

1. [Defining map styles in the Google Cloud Console](#NOTE2_1). 

2. [Associating a map ID with a map style](#NOTE2_2). 

3. [Associating the ID with the Map control](#NOTE2_3): 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) via the control description window. 
			

	- via [MapIDGgl](../WDLang3/1410091136.md). 







A map ID is a unique identifier that represents Google Maps styling and configuration settings stored in Google Cloud. Map IDs can be used to enable certain features, or to manage or style maps in your applications.

## Detailed steps
<a name="detailed_steps_ELTTEXTE000207"></a>


### Defining map styles in the Google Cloud Console
<a name="defining_map_styles_the_google_cloud_console_ELTPARAGRAPHE000059"></a>

Go to the Google Cloud console (https://console.cloud.google.com):

1. Log in with your developer account.

2. Select a "Google" project (or create a new one if necessary). 

3. Select "Google Maps Platform", either from the menu on the left or from the search bar at the top.

4. Click "Map styles". 

5. Click "Create style". 

6. Choose whether you want to use a light or dark theme.


You can then customize the different elements of the map (background colors, text colors, visibility).

Once you have finished customizing the different elements, save the style.
<a name="NOTE2_2"></a>


### Associating a map ID with a map style
<a name="associating_map_with_map_style_ELTPARAGRAPHE000077"></a>

To create a map ID, still in your Google project:

1. Click "Map Management" in the left-hand menu.

2. Click "Create map ID".

3. Give the ID a name.

4. Select the map type: JavaScript or Android.
	In the case of a WINDEV application, select "JavaScript".

5. Click "Save".

6. In the "Map styles" section, you can change the map style for the light and dark themes.

7. Select the desired theme and click "Change style". In the pane that appears, select the custom style you just created.

8. Save the map ID. You will need this identifier in the WLanguage code of the application. 



<a name="NOTE2_3"></a>


### Associating the ID with the Map control
<a name="associating_the_with_the_map_control_ELTPARAGRAPHE000095"></a>

To use the custom map style, the map ID must be used in your application. Two methods are available: 

- [MapIDGgl](../WDLang3/1410091136.md) function:
	
	```txt
	MapIDGgl(MAP_EX, <Map ID>)
	```


- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Map control description: You can specify the map ID in the Map control description window ("Details" tab).
	




Note: If there is no custom style, the default Google Maps style is used.

## Special case: Switching between light and dark themes
<a name="special_case_switching_between_light_and_dark_themes_ELTTEXTE000252"></a>
The change of theme depends on the style used:

- Without a map ID: If the *ccsAutomatic* constant is used to define the map style, the light and dark themes associated with the current style will be used.  

- With a map ID: For the light theme, the custom style is used. For the dark theme, style customization is ignored. The default dark theme is used.
