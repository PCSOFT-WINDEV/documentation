## Overview of windows
<a name="overview_windows_ELTTEXTE000194"></a>
Windows constitute the main interface of a WINDEV or WINDEV Mobile application. Indeed, windows allow users to view and handle information. This information can be dynamic information (coming from files or queries) or static information (entered in the window controls directly).

<a name="NOTE2_1"></a>


## Creating a window
<a name="creating_window_ELTTEXTE000218"></a>
To create a window: 

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_nouveau.gif) in the quick access buttons: 

	- In the window that appears, click "Window" then "Window".

	- The window creation wizard opens.




2. Select the type of window to create:

	- The "Standard" tab is used to created blank windows, without any control.

		- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The window creation wizard allows you to create [maximized windows](../WDChamp/9000113.md) or [non-maximized windows](../WDChamp/9000121.md). 

		- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The "Blank for widget" option is used to create a [Widget window](../WDChamp/9000143.md) in an Android application.

		- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The wizards for creating blank windows [for iPhone](../WDChamp/9000133.md) and [for iPad](../Editeurs/9000147.md) are used to define the main characteristics of the window. 
						For the iPad applications, the wizard allows you to create simple windows or double windows. You also have the ability to create [non-maximized windows](../WDChamp/9000148.md). 

		- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The "Non-maximized blank with arrow" option is used to create a "Window with arrow" window or a "Popup" window available for the applications operating on iPad. For more details, see [Window with arrow](../Editeurs/9000146.md). 

		- ![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) The "Blank" option is used to create maximized or non-maximized windows. 




- the "RAD" tab lets you create RAD-type windows. These windows can be used to display and enter data. This type of window can be based on a data file, a query, ... For more details, see: 

	- [RAD WINDEV: the different types of windows available](../Editeurs/2031003.md). 

	- [Creating modern windows for mobile apps with the RAD model](../Editeurs/9000231.md).




**To display the characteristics of the window**, select "Description" in the context menu of the window.
