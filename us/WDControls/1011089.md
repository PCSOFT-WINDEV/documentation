## Overview
<a name="overview_ELTTEXTE000173"></a>


The "Preview" pane allows the user to configure how the printout is displayed in the current preview: Zoom, crosshairs, move, move between pages, etc. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Apercu_Volet_Apercu.gif&type=thumb)

## The different options
<a name="the_different_options_ELTTEXTE000197"></a>


### Zoom
<a name="zoom_ELTPARAGRAPHE000029"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_Apercu_Zoom.gif)
The report viewer offers various zoom options: 

- view 100% of current printout. 

- adapt print width. The printout will be displayed in full width in the viewer. 

- show full page. 

- zoom in or out. Select the desired zoom mode: each click in the preview window automatically zooms in. 

- select page display mode. It is possible to: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_Apercu_Mode_deroule.gif)


	- display pages one after the other ("One page" option). 

- display two pages simultaneously ("Two pages" option). In this case, if a cover page was defined, when displaying side by side, the first page will be displayed on the right.




Note: More precise zoom management can be performed: 

- using the "Zoom lasso" tool in the "Tools" group. This option allows zooming in a specific area, defined by the mouse lasso.  

- by pressing Ctrl + ('+' sign on the numeric keypad) and Ctrl - ('-' sign on the numeric keypad). 

- by specifying the zoom percentage directly in the menu bar of the viewer (top right).

### Report viewer tools
<a name="report_viewer_tools_ELTPARAGRAPHE000057"></a>
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_Apercu_Outils.gif)
The available options are as follows: 

- The "Move" option is used to move in the current edit while keeping the left mouse button down. 

- The "Select" option allows you to select text in the report viewer to copy and/or paste it afterwards. For more details, see [Copying text in the report viewer](../WDChamp/1011059.md).

- The "Crosshair" option is used to display a crosshair. This tool makes reading large tables much easier. When the end user points a data with the crosshair, he can easily read the row and the column of pointed data, such as the title for example.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Apercu_Etat_Mire%20-%20HC%20N%B0001.gif&type=thumb)
By clicking the arrow found below the crosshair, you have the ability to configure the thickness and color of the crosshair. 

- The "Annotation" option is used to display the pane specific to the management of annotations. 

- The "Snapshot" option is used to take a screenshot. Two options are available: 

	- Lasso selection: the mouse cursor becomes a lasso. The selection defined in the preview is automatically copied as image to the clipboard. 

	- Intelligent: the entire content of the current page in the preview is automatically copied to the clipboard. 


Then, the clipboard content can be pasted in any tool for image management. 

- The "Zoom lasso" option completes the zoom options in the "Zoom" group, allowing you to zoom in on an area selected by the lasso.

### Display mode
<a name="display_mode_ELTPARAGRAPHE000094"></a>

Several display modes are available: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_Apercu_Affichage.gif)


- **"Full-screen" mode**: Current edit occupies all available space. The menu shaped like a ribbon is no longer visible. To restore the standard display mode, press the Esc key on the keyboard or click the screen icon found at the top right. 

- **Thumbnail pane** Display of individual report pages in the form of thumbnails. **thumbnails**. The thumbnails are automatically resized when modifying the display area of thumbnails. A context menu specific to thumbnails allows you to print the desired page directly. 
	The part viewed is represented in the thumbnail. The zoom and positioning area in the thumbnail can be resized, moved, the zoom factor can be changed, etc.
	If bookmarks are available, you have the ability to display them in the thumbnail area. These bookmarks are displayed hierarchically. To access a specific section, all you have to do is click the corresponding bookmark.



<a name="NOTE2_4"></a>


### Navigation in the pages
<a name="navigation_the_pages_ELTPARAGRAPHE000111"></a>

If the report viewer displays a printout with several pages, you can move between the pages, or directly display the desired page by entering the number of that page. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_apercu_pages.gif)

<a name="NOTE2_5"></a>


### Specific features
<a name="specific_features_ELTPARAGRAPHE000121"></a>

If the report viewer displays an editable report in "Reports and Queries", two additional options are available: 

- Create: to create a new report. 

- Modify: to modify the current status.
