


## The Radio Button control
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000196"></a>
The Radio Button control is a control allowing the user to select an option among several ones.

A radio button can display up to 256 options arranged in several rows and columns. A single option can be selected by the user. The radio button returns the number of the selected option.

## Creating a Radio Button control
<a name="creating_radio_button_control_ELTTEXTE000220"></a>


### Creating a Radio Button control
<a name="creating_radio_button_control_ELTPARAGRAPHE000049"></a>

To create a Radio Button control:

1. On the "Creation" tab, in the "Usual controls" group, click "Radio Button".

2. Click where the control will be created in the window or page. The control appears in the editor.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) **Tip** You can also create a "pre-formatted" picker directly by selecting "Picker". The list of available controls is displayed with the project skin template. Simply click the control you want to create in the editor.

To view the characteristics of the control, select "Description" in the context menu.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Remark**: It is possible to manage either a general tooltip for the field, or a tooltip for each of the field's options.

### Limitations in Java
<a name="limitations_java_ELTPARAGRAPHE000083"></a>

The following characteristics are not supported in Java:

- proportional columns (if the options of the radio button are displayed over several columns).

- multiline captions for the options of radio buttons.

- formatted text for the options of radio buttons (R. T. F.).

- help number associated with each option of the radio button.

### Limitations in Android and iOS
<a name="limitations_android_and_ios_ELTPARAGRAPHE000097"></a>

Only images are supported for option checkmarks. If no image is specified, the system image is used. The elements "Checkmark" and "Checkmark border", in the style of Radio Button controls, are ignored.

## Display modes available
<a name="display_modes_available_ELTTEXTE000256"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
WINDEV and WINDEV Mobile propose different display modes for the radio buttons:

- standard radio button, 

- standard radio button with sub-captions, 

- radio button in Vista style (an image can be used for each option), 

- radio button in Vista style with sub-captions (an image can be used for each option). 


The display mode of the radio button can be selected in the "General" tab of the control description. The "Content" tab is used to enter the characteristics specific to the display mode (image, sub-caption, row height, etc.) in the different languages of the application. These elements can be modified programmatically.

The programming mode can change according to the type of display. For more details, see [Handle a radio button programmatically](../WDChamp/1013254.md).

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Only the standard mode and the standard mode with sub-captions are proposed.

## Swap
<a name="swap_ELTTEXTE000280"></a>
WINDEV, WINDEV Mobile and WEBDEV allow you to automatically change a Radio Button control into a Check Box control and vice versa: 

1. Select the control to transform. 

2. On the "Modification", in the "Transformations" group, expand "Refactoring and swapping" and select "Radio Button / Check Box".
