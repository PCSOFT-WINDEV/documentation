


## The Upload control
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000234"></a>


### Control in a dynamic or static page
<a name="control_dynamic_static_page_ELTPARAGRAPHE000011"></a>

The Upload control is used to upload files on the Web server. 

WEBDEV proposes an advanced Upload control that can be used immediately. It includes several controls (that can be deleted if necessary): 

- Looper used to manage the files to upload. This looper is used to specify the file characteristics, to display a progress bar during the upload and to propose a button used to delete the file from the list if necessary. 

- Caption indicating where the files to upload will be dropped. 

- "Add" button used to add the files. 

- "Send" button to start the file upload. 


This control can be used in singlefile mode or in multifile mode. 

The Upload control directly manages the Drag and Drop of files from the explorer (if the browser supports the HTML 5 standard). For more details, see [Manipulating Upload controls programmatically](../WDChamp/1016333.md).

**Remarks**: 

- These controls support HTML 5 (see [Control characteristics](#NOTE1_3)).

- The Upload edit control is kept for backward compatibility. For more details, see [File upload](../WDLang2/3012024.md). 

- The pre-defined upload field is asynchronous: you can continue to use the current site without being blocked by the upload.



<a name="NOTE1_2"></a>


### Creating an Upload control
<a name="creating_upload_control_ELTPARAGRAPHE000059"></a>

To create an Upload control: 

1. In the page editor, on the "Creation" tab, in the "Usual controls" group, expand "Button".

2. In the list that opens, select the "File upload" control type.

3. Click where you want to create the control in the page. The control appears in the page.




**To display the control characteristics**, select "Description" in the context menu of the Upload control ("Send" or "Add").

**The WLanguage code for managing uploads** code is present in the events associated with the Upload control field. This code can be modified according to your requirements. 

**Important** The "Receive uploaded files" event must be modified before deploying the site. A code sample is supplied in comment. This code can for example: 

- copy the uploaded files into a specific site directory,

- Insert uploaded files into a binary memo, etc.


For more details, see [Upload control events](../WDChamp/1016331.md). 
<a name="NOTE1_3"></a>


### Control characteristics
<a name="control_characteristics_ELTPARAGRAPHE000101"></a>

Several specific options are available in the "Details" and "UI" tabs of the Upload control description (accessible via the description of the "Add" button): 

- **Multi-file selection** ("UI" tab): enables multi-selection in the. If this option is not checked, only the upload of a single file will be possible. 

- **Generate an image for the button, with embedded caption (for compatibility)** ("Detail" tab): generates an image containing the graphic appearance of the button. The button caption is embedded in the image. The aspect of the button will be the same even if different browsers are used. 

- **Drag/Drop Management** (tab "UI"): Enables "Drag and Drop" from Windows Explorer. For more details, see [Managing Drag and Drop of files to an Upload control (HTML5)](../WDChamp/1016333.md).

### AWP multi-file upload field
<a name="awp_multifile_upload_field_ELTPARAGRAPHE000128"></a>

A multi-file Upload control in AWP implicitly creates an AWP context on disk. This type of control is not compatible with the management of contexts via cookies. For more details on AWP contexts, see [Management of AWP sessions](../WDChamp/3539060.md).

### Maximum size of files to upload
<a name="maximum_size_files_upload_ELTPARAGRAPHE000145"></a>

**By default**, the size of files to upload is not limited in the WEBDEV engine. This size can be limited: 

- by the Web server used. For more details, see the documentation about the Web server used. 

- by WEBDEV Application Server. 




The file will not be uploaded if its size exceeds the limit size.

**To modify the maximum size of files to upload in WEBDEV Application Server**, the registry must be modified on the server. This modification can be performed for all the WEBDEV applications.  

**To change the size of uploaded files for all WEBDEV applications**: 

1. Select the following registry key: 

	- On a 64-bit workstation: HKEY_LOCAL_MACHINE\\SOFTWARE\\WOW6432Node\\PC SOFT\\WEBDEV\\31.0

	- On a 32-bit workstation: HKEY_LOCAL_MACHINE\\SOFTWARE\\PC SOFT\\WEBDEV\\31.0




2. Add the MAX_UPLOAD key. The value of this key corresponds to the maximum size of files to upload (in KB).




Note: There may also be a web server limitation (IIS, Apache, etc.). For example, for IIS, you have the ability to edit the XML "%windir%\\system32\\inetsrv\\config\\applicationhost.config" file and to create or modify the "maxAllowedContentLength" attribute of "requestLimits" tag by specifying the size in bytes. 
Example to set the limit to 50 MB in IIS:


```txt
<system.webServer>
          	<security>
		.....
		<requestFiltering>
		.....
			<requestLimits maxAllowedContentLength="52428800"/>
		</requestFiltering>
....
```


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Limits in PHP**: 


- The size of the uploaded files is limited by the "upload_max_filesize" and "post_max_size" directives in the configuration file of PHP (php.ini file).

- The file upload must be allowed by the PHP server. To do so, the "file_uploads" directive must be set to "on" in the configuration file of PHP (php.ini file).

- The upload_tmp_dir directive of the configuration file must be specified toward a directory with read/write rights.
