## Facebook
<a name="facebook_ELTTEXTE000586"></a>
Several types are available in a Facebook Social Network control. Each type can be associated with a specific target. 

The table below presents the information used for each type and target. 


| Type | Target | Effect |
| --- | --- | --- |
| **I like or Recommend** | Domain | Creates a link to the domain of the current site on the user's Facebook wall.<br><br>Caution: A default index page must exist on the hosting server. |
|   | The site | Creates a link to the current site on the user's Facebook wall.<br><br>Caution: A default index page must exist on the hosting server. |
|   | The page | Creates a link to the page of the current site on the user's Facebook wall. |
|   | Custom target | <br><br>The URL must be typed in the "Target URL" field.<br><br><br><br>**Case 1: URL of a Facebook page**: <br><br>- Increments the counter of Facebook page that was liked.<br><br>- Creates a favorite on the user's Facebook wall.<br><br><br>**Case 2: URL of any page or site**: <br>Creates a link to the specified page or site on the user's Facebook wall. |
| **Send** | Domain | Used to send a link on the domain to another Facebook user. The message sent is a private message. |
|   | The site | Used to send a link on the site to another Facebook user. The message sent is a private message. |
|   | The page | Used to send a link on the page to another Facebook user. The message sent is a private message. |
|   | Custom target | Used to send a link to another Facebook user. This link corresponds to a link to any page or site. The message sent is a private message.<br><br><br><br><br><br>The URL of the link to be sent must be entered in the "Target URL" field. |
| **Subscribe** | Custom target | <br><br>In "Target account", you can enter:<br><br>- the URL of the Facebook page to which the user wants to subscribe. For example: "www.facebook.com/01net" or "http://www.facebook.com/pages/PC-SOFT/247782873866"<br><br>- the ID of the Facebook account to which the user wants to subscribe. For example: "01net" or "247782873866".<br><br><br> |
| **View profile** | Custom target | In "Target account", you can enter the identifier of the desired Facebook account. For example: "01net" or "247782873866". |





Remark: To allow posting on the user's wall, the page containing the Social Network control must meet the following conditions: 

- the page must include a title. 

- the page must include at least one Image control. 




Caution: During the site test (GO in localhost mode), only the tooltips are correct. You cannot publish on a wall.

## Twitter
<a name="twitter_ELTTEXTE000610"></a>
Several types are available in a Twitter Social Network control. Each type can be associated with a specific target. 

The table below summarizes the information used for each target. 


| Type | Target | Effect |
| --- | --- | --- |
| **Tweeter** | Domain | Creates a message containing a link to the domain of the current site on the user's Twitter feed. |
|   | The site | Creates a message containing a link to the current site on the user's Twitter feed. |
|   | The page | Creates a message containing a link to the page of the current site on the user's Twitter feed. |
|   | Custom target | <br><br>The URL must be typed in the "Target URL" field.<br><br><br><br>Creates a message containing a link to the specified URL on the user's Twitter feed. |
| **Follow** | Custom target | <br><br>In the "Target URL" control, you have the ability to type:<br><br><br><br>- the URL of the Twitter page to which the user wants to subscribe. For example: "https://twitter.com/PCSOFT_FR"<br><br>- the ID of the Twitter account to which the user wants to subscribe. For example: "PCSOFT_FR".<br><br><br> |
| **View profile** | Custom target | In "Target account", you can enter the identifier of the desired Twitter account. For example: "PCSOFT_FR". |


Remarks: 

- The Twitter messages are limited to 140 characters. 

- Twitter Social Network controls can be run in test mode (but the URL is not contained in the messages).

## LinkedIn
<a name="linkedin_ELTTEXTE000634"></a>
You can share the current content in a LinkedIn Social Network control. 

The table below presents the information used for each type and target. 


| Type | Target | Effect |
| --- | --- | --- |
| **Share** | Domain | Creates a LinkedIn post with a link to the domain.<br><br>Caution: A default index page must exist on the hosting server. |
|   | The site | Creates a LinkedIn post with a link to the site.<br><br>Caution: A default index page must exist on the hosting server. |
|   | The page | Creates a LinkedIn post with a link to the web page. |
|   | Custom target | Creates a LinkedIn post with a custom link.<br><br>The URL of the link to be sent must be entered in the "Target URL" field. |
| **View profile** | Custom target | Displays the page corresponding to the LinkedIn profile. <br><br>In "Target account", you can enter the identifier of the desired LinkedIn account. |


**Caution**: During the site test (GO in localhost mode), no test can be run for this type of control. 

Remark: To specify the thumbnail to be displayed in the news, provide the image via an OpenGraph description. A specific tag must be included in the page header. This tag must contain the image to display.

For example: 


```txt
<meta property="og:image" content="http://mydomain.com/myimage.jpg"/>
```
