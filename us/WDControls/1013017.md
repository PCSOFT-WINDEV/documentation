


## Modifying the characteristics of report controls
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000492"></a>
The characteristics of the controls can be viewed and/or changed in:

- [the control description window](#NOTE2_1).

- [the "Modifier"pane](#NOTE3_1). 




The report editor also allows you to:

- change the control caption.

- change the control name.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Description window of report controls
<a name="description_window_report_controls_ELTTEXTE000516"></a>
To open the description window of a control, use one of the following methods:

- double-click the control (recommended).

- right-click to open the context menu of the control and select "Description".

- select the control, go to the "Modification" tab and click the dialog box launcher ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_regroup.gif) of the "Quick edit" group (Alt + Enter).

- on the "Display" tab, click the dialog box launcher ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_regroup.gif) of the "Options" group (F12). Then, select the control and click the "Description" button.




**Note**: You can open a description window for a selection of controls. Only the characteristics common to the selected controls will be displayed.
<a name="NOTE2_2"></a>


### Characteristics by tab
<a name="characteristics_tab_ELTPARAGRAPHE000064"></a>

The description window shows the characteristics of the selected control(s) in different tabs:

| Tab | Characteristics |
| --- | --- |
| **General** | Allows you to specify the name and the display options of the control. For example:<br><br>- the control caption (this caption can be multilingual).<br><br>- the type of information displayed in the control (text, numeric, etc.).<br><br>- the display mask used for the control (the mask can be multilingual). <br><br>- the image displayed in an Image control, the type of bar code used in a Bar Code control, the type of chart used in a Chart control, etc. For more details, see the online help of the desired type of control.<br><br><br> |
| **UI** | Allows you to define:<br><br>- the print options of the control (visible, breakable, etc.). <br><br>- the control size.<br><br>- the control position in the report and in the block to which the control belongs.<br><br>- the control anchors.<br><br>- the associated group of controls. <br><br>- the associated plane. <br><br><br> |
| **Binding** | Enables you to define the item or variable in the data source to which the control is bound. The value of this item or variable will be displayed in the control.<br><br>To bind the control to an item or variable from the data source of the report, select the item directly from the "Bound item or variable:" list.<br><br><br><br>To bind the control to an item that does not belong to the data source of the report, select "Multiple data files", then select the item you want to bind to the current control. |
| **Note** | Allows you to describe the detailed operating mode of the control.<br>This information will be printed in the technical documentation (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_imprimer.gif) icon on the "General" tab, "Home" group).<br><br>This information can be get and set programmatically using the [Note](../Proprietes/2510085.md) and [NoteTitle](../Proprietes/2510121.md) properties. |
| **Style** | Allows you to define:<br><br>- the style of the control (background color, border, etc.).<br><br>- the font used in the control.<br><br><br>**Note**: You can also define the font used in the control via the icons in the "Quick edit" group of the "Modification" tab. |


Note: All options in the description windows feature comprehensive tooltips with brief explanations, but also with the corresponding WLanguage properties, availability by platform, multilingual values, etc.

## Main print options of report controls
<a name="main_print_options_report_controls_ELTTEXTE000546"></a>
The print options of a control are as follows (defined in the "UI" tab of the description window):

| Parameter | Description | Available for the following controls |
| --- | --- | --- |
| ***Visible*** | The control can be displayed or hidden. This characteristic can be modified programmatically with the [Visible](../Proprietes/2510138.md) property. | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md), [Image](../WDChamp/1013218.md), [Bar code](../WDChamp/1013010.md), [RTF control](../WDChamp/1013056.md), [Preset control](../WDChamp/1013058.md), [Chart](../WDChamp/1013006.md), [Shape](../WDChamp/1013102.md), [Internal Report control](../WDChamp/1013044.md) |
| ***Auto-resizing*** | The control size defined in the report editor can be adjusted depending on the content of the control. The controls placed after the control that supports automatic sizing are pushed. <br>**Remarks**:<br><br>- If the "auto-resizing" option is not enabled, the content of the control can be truncated.<br>	To get the height of an auto-resizing control when enlarged, use the [FutureHeight](../Proprietes/2511061.md) property.<br><br>- If a control in a block supports automatic sizing behavior, the associated block will also support this behavior. A block containing controls with automatic sizing with also support this feature. A block containing controls without the "auto-sizing" option enabled will not support automatic sizing.<br><br>- The controls in a page footer cannot automatically resize themselves.<br><br><br>**Limitation**: In a report in Label mode, controls cannot automatically resize themselves. | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md), [Shape](../WDChamp/1013102.md), [Bar code](../WDChamp/1013010.md), [Internal Report control](../WDChamp/1013044.md) |
| ***Multiline*** | The control content can be displayed over several lines. This characteristic can be modified programmatically with the [Multiline](../Proprietes/2510105.md) property.<br>**Remarks**:<br><br>- The control height must be sufficient to display several lines.<br><br>- You can programmatically change the control height using the [Height](../Proprietes/2510050.md) property.<br><br>- If an angle is applied to a multiline control, automatic carriage returns are ignored. Only manual carriage returns are taken into account.<br><br><br> | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md), [Preset control](../WDChamp/1013058.md) |
| ***Breakable*** | The content of a breakable control can be printed over several pages if there is not enough space to print the entire control on a page.<br>**Remarks**:<br><br>- For a control to be breakable, this option must also be enabled for the block containing the control.<br><br>- If there is not enough space on the current page to print a non-breakable control, the entire control will be printed on the next page.<br><br><br> | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md), [Image](../WDChamp/1013218.md), [Bar code](../WDChamp/1013010.md), [RTF control](../WDChamp/1013056.md), [Preset control](../WDChamp/1013058.md), [Chart](../WDChamp/1013006.md), [Shape](../WDChamp/1013102.md) |
| ***Blank if zero*** | The control value is displayed only if it is different from 0.<br>If the control value is set to 0, the control displays an empty string (""). | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md) |
| ***Ellipsis (long captions will end with '...')*** | Ellipses indicate that a text is too long. In this case, three dots ("...") are added to the text. These dots can be added at the end or in the middle of the text (recommended for file paths). | [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md) |
| ***Show only if the value changes*** | The control value is only displayed if the value of the bound item changes when moving to the next record in the report data source. | [Item](../WDChamp/1013059.md), [Calculated control](../WDChamp/1013212.md) |
| ***Reset to 0 after printing*** | The control value is automatically reset to 0 once it has been printed.<br>This parameter is often used for calculations on a break. | [Calculated control](../WDChamp/1013212.md) |
| ***RTF*** | The control value can be RTF.<br>**Reminder**: RTF takes into account the character attributes (bold, italic, underlined, etc.) of a text. | [Static Text](../WDChamp/1013179.md), [Item](../WDChamp/1013059.md), [RTF control](../WDChamp/1013056.md) |
| ***Use shared info at runtime*** | The control will display the "shared information" of the item bound to the control (and not the index corresponding to this "shared information").<br>For example, the "RAD information" of the "Title" item corresponds to the following combo box: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=UtiliserInfosRad.gif)<br>Only the indexes of the shared information are stored in the database. | [Item](../WDChamp/1013059.md) |
| ***Horizontal/Vertical gridlines*** | Horizontal and/or vertical gridlines can be displayed or hidden in a chart. | [Chart](../WDChamp/1013006.md) |

## Changing the control caption
<a name="changing_the_control_caption_ELTTEXTE000600"></a>
To change the caption of a control in the current report:

1. Select the control you want to modify.

2. Click the control again or press Enter. The mouse cursor turns into an input cursor. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=LibelleModifDirectetat.gif)


3. Enter the new text.

4. Confirm by pressing the Enter key.

## Changing the control name
<a name="changing_the_control_name_ELTTEXTE000624"></a>
You can change the name of a control directly from the status bar of the report editor.

To change the control name:

1. Select the control you want to modify.

2. Type the new control name in the status bar. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=NomChampModifEtat.gif)
