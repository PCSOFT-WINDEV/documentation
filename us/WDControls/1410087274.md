## Overview of the Flexbox control
<a name="overview_the_flexbox_control_ELTTEXTE000171"></a>
Flexbox is a standard layout system for web pages. 
Flexbox controls were introduced in WEBDEV 28. 
Starting with version 2024, the Flexbox control is available in WINDEV and WINDEV Mobile.

Here's how it works: 

- Drop the controls onto the Flexbox control.

- The Flexbox control then automatically positions the controls according to the desired parameters.




The Flexbox control allows you to: 

- Define how controls are positioned when the browser or window is resized. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) For more details, see [Flexbox example: Automatic control layout](../WDChamp/1410087285.md). 

- Set ratios to distribute available space among the controls.
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) For more details, see [Flexbox example: Ratios to distribute available space among controls](../WDChamp/1410087275.md).

## Creating a Flexbox control
<a name="creating_flexbox_control_ELTTEXTE000195"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) To create a Flexbox control:

1. On the "Creation" tab, in the "Containers" group, click "Flexbox". 

2. Click where you want to create the control in the page. The control appears in the editor.




Note: Several preset Flexbox controls appear when you expand the "Flexbox" option, including:

- Column Flexbox,

- Row Flexbox,

- Flexbox cards. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To create a Flexbox control:

1. On the "Creation" tab, in the "Containers" group, expand "Flexbox and similar" and select the display mode of the Flexbox control: horizontal or vertical. . 

2. Click where you want to create the control in the page. The control appears in the editor.




To display the characteristics of the control: 

1. Select the control. 

2. Select "Description" in the control context menu.

## Defining page layouts using Flexbox controls
<a name="defining_page_layouts_using_flexbox_controls_ELTTEXTE000243"></a>
When the page contains a direct wire control, the page is generated with a minimum width (min-width) equal to that defined in editing.

In order to adapt content to a browser that's less wide than the edit length, all fields must be placed in Flexbox controls.

Example: A page contains only one Flexbox control in "wrap" mode with width anchoring corresponding to "Enlarge/Reduce like browser".
To add a Button control below the Flexbox control, it is necessary to create a second horizontal Flexbox control containing the button below the first Flebox control.
