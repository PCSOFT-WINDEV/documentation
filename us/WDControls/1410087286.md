
## Flexbox control description: General Tab
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000152"></a>
In the "General" tab of the Flexbox control description window, you can view and change the options of the different controls integrated into a flexbox container. 

You can define the flex properties of each control to get the desired behavior in the flexbox container. 

Note: These parameters are also displayed when displaying the field anchoring parameters present in the Flexbox control.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Options of the "General" tab
<a name="options_the_general_tab_ELTTEXTE000176"></a>
For each control in the flexbox container, you can configure the following aspects: 

- **Width** if the Flexbox control items are laid out as a row, **Height** if the Flexbox control items are laid out as a column: 
	Distribution of the horizontal free space into "parts".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Flexbox_General%20-%20HC%20N%B0001%201.gif)


	- **if the width of the flexbox container increases**, the controls will stretch horizontally to fill the available space (flex-grow). The possible values are as follows: 

	- 0: no enlargement

	- 1: default enlargement, fields will be enlarged in equal proportions, depending on the space available in width. 

	- other value: fields will be enlarged in proportion to this coefficient, depending on the space available in width.

- **Height** if the Flexbox control items are laid out as a row, **Width** if the Flexbox control items are laid out as a column: 
	Definition of vertical alignment and anchors (align-self). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Flexbox_General%20-%20HC%20N%B0002.gif)
The possible values are: 

	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) inherited, the control will stretch vertically (stretch).

	- auto, defined by the Flexbox control

	- flex-start

	- center

	- flex-end

	- \* text alignment (baseline): Alignment along text baseline. 
			Note: "\*" indicates that this option is not supported by the editor. 

	- stretch


 By default, the control will stretch vertically (stretch). ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The alignment can be defined programmatically using the [FlexAlignSelf](../Proprietes/1410089751.md) property.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Other settings**: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Flexbox_General%20-%20HC%20N%B0001%203.gif)


	- **Display order**: Fields are displayed according to the order defined by this parameter.. If no value is specified (undefined or 0), the control is positioned to the right of the previous control. Please note: a field with an order number can no longer be moved in the editor: it remains in the position given by its order.

- **Custom anchor in CSS** format: This option lets you enter the custom CSS code indicating the desired anchor.. This CSS code overrides the previously defined parameters. For example: 
			
		```txt
		flex 20 1 100px;
		```
corresponds to:

	- flex-grow: 20

	- flex-shrink: 1

	- flex-basis: 100px
