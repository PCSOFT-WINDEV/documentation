


## Manipulating the Chart controls at runtime (AAF)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000231"></a>
At runtime, the user can set the parameters of the displayed graph using several functions available in the context menu. 

This context menu consists of two panes, allowing you to configure: 

- [the display options](#NOTE3_1).

- [axis management options](#NOTE3_1). 




**Note**: This menu can be configured:

- additional options can be added. For more details, see [Configuring the context menu displayed by the AAFs](../Editeurs/2010040.md).

- [grMenuOption](../WDLang3/3042042.md) is used to change the caption of an option or to avoid displaying an option.

## Context menu: display options
<a name="context_menu_display_options_ELTTEXTE000255"></a>
A chart is associated with a context menu by default (displayed via a right mouse click).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Graphe_MenuCtx.gif)


Thanks to the "View" section of this context menu, end-users can perform a wide range of operations:   

- choice of graph type. 

- whether or not to display gridlines. 

- smoothing, gradient or animation options. 

- show legend

- bubble and crosshairs management. 

- graph recording

- Printing the chart. 




Let's take a closer look at a few options. 


### Choice of graph type
<a name="choice_graph_type_ELTPARAGRAPHE000053"></a>

The context menu allows you to choose the most appropriate display mode for the data you are viewing: sector, curve, column chart, stock chart, etc..

### Gridlines
<a name="gridlines_ELTPARAGRAPHE000063"></a>

Use the context menu to: 

- display a vertical gridlines, 

- to display a horizontal gridlines, 

- display no gridlines.  





### Additional options
<a name="additional_options_ELTPARAGRAPHE000072"></a>

The context menu can also be used to smooth the various values, use a color gradient or even animate the display.. 


### Show legend
<a name="show_legend_ELTPARAGRAPHE000077"></a>

Use the context menu to display or hide the graph legend and set its position.. 


### Tooltip and crosshair
<a name="tooltip_and_crosshair_ELTPARAGRAPHE000082"></a>

A bubble can be displayed when the mouse cursor hovers over a piece of data.. This tooltip contains the value and the caption of series and category. This tooltip can be customized by [grTooltip](../WDLang3/3042010.md). 
The characteristics of this tooltip are as follows: 

- Immediate display for better visibility, 

- Tooltip border that use the color of the series. The association between the tooltip and the series is immediate. 

- Semi-transparent bubble: the graph below appears.

- Arrow precisely pointing to the targeted point.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WD%20-%20Bulle%20Graphe.jpg)
For further details, you can also activate the crosshairs. The crosshair allows the user to precisely know the pointed value. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Graphe_Mire.gif&type=thumb)
For more details, see [Chart crosshair](../WDChamp/3042078.md). 




### Save and print
<a name="save_and_print_ELTPARAGRAPHE000110"></a>

The graph can be saved as an image. The currently displayed graph (with all its characteristics) is saved in the selected directory and in the required format.

The graph is printed on the chosen printer. The chart will be printed in color on a color printer.

### Enabling the zoom
<a name="enabling_the_zoom_ELTPARAGRAPHE000146"></a>

The context menu of the chart is used to enable the zoom in the chart. You have the ability to enable:

- the horizontal zoom only.

- the vertical zoom only.

- the vertical and horizontal zoom.




This zoom can also be enabled by default when displaying the chart.

When the zoom is enabled, the chart can be handled via one of the following methods:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Graphe_zoom.gif&type=thumb)


- Using the vertical and horizontal scrollbars: you have the ability to specify the area to zoom by moving the boxes of scrollbars.

- Use Ctrl + mouse wheel: the area pointed to by the mouse is automatically zoomed.. 
	The zoom wheel also operates when the Chart control is hovered (even if the control does not have focus).

- Using the lasso of the mouse: the area selected by the lasso of the mouse is automatically zoomed. To stop the zoom, press the Esc key.

- Use Ctrl + ('+' sign on the Numerical keypad) and Ctrl - ('-' sign on the Numerical keypad): the area at the center of the graph is automatically zoomed.




To return the graph to its initial state, simply press Ctrl + 0.

**Note**: If the graph is associated with a background image, the background image is not zoomed.


### Ordinate limit
<a name="ordinate_limit_ELTPARAGRAPHE000175"></a>

It is possible to modify the limit values of the ordinates displayed in the graph (Curve or Histogram graphs).. In particular, this feature can be used to avoid empty, unused areas in a graph and refocus its values.. 


### Interval between marks
<a name="interval_between_marks_ELTPARAGRAPHE000182"></a>

Use the graph context menu to change the graduation step used in the graph.. Coupled with gridlines or zoom, this feature can be used to display specific data, for example.
