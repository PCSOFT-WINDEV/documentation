## Code Editor control overview
<a name="code_editor_control_overview_ELTTEXTE000218"></a>
The Code Editor control allows end users to write WLanguage code.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) This means you can use this type of control in an application: 

- to allow developers to run tests,

- to allow advanced users to enter formulas, run scripts, etc. 

- to customize a feature for a specific client.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Users can write WLanguage code and benefit from syntax highlighting in a WEBDEV site. Code cannot be executed natively. Executing WLanguage code written by the user leads to security vulnerabilities. 

CAUTION: The Code Editor control works independently. It does not have access to the project analysis nor to the associated data files. To access the data, use [HDeclareExternal](../WDLang4/3044204.md), for example. Example: 

```wl
IF NOT HDeclareExternal(fDataDir() + fSep() + "CUSTOMERS.FIC", "CUSTOMERS") THEN
	Error(HErrorInfo())
	RETURN
END
HReadSeekFirst(CUSTOMERS,"CUSTOMERCODE","0018300")
Info(CUSTOMERS.NAME1)
```

## Create a Code Editor control
<a name="create_code_editor_control_ELTTEXTE000242"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To create a Code Editor control**:

1. On the "Creation" tab, in the "Graphic controls" group, expand "Office" and select "Code Editor". 

2. Click at the desired location to create the control.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **To create a Code Editor control**:

1. On the "Creation" tab, in the "Graphic controls" group, expand "Advanced" and select "Code Editor". 

2. Click where you want to create the control in the page.




Note: The dimensions of the control are optimized to take up the available space at the specified position. If you are not happy with the size of the control, press Ctrl + Z key to restore the control to its default size.

To view the characteristics of the control, select "Description" in the context menu.

## Code Editor control features
<a name="code_editor_control_features_ELTTEXTE000270"></a>
The Code Editor control includes a toolbar that provides access to the main functions: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001.gif)


Several keyboard shortcuts are also available: 

| Shortcut | Effect |
| --- | --- |
| **Ctrl + A** | Selects the content of the control. |
| **Ctrl + C** | Copies the selection to the clipboard. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%204.gif) |
| **Ctrl + D** | Duplicates the current line. |
| **Ctrl + O** | Opens a file containing the WLanguage code to be displayed in the control. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%201.gif) |
| **Ctrl + S** | Saves the contents of the Code Editor control to a file. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%202.gif) |
| **Ctrl + V** | Pastes the content of the clipboard. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%205.gif) |
| **Ctrl + X** | Cuts the selection and copies it to the clipboard. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%203.gif) |
| **Ctrl + mouse wheel** | Changes the zoom. |
| **Ctrl + Z** | Undoes the last action. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%208.gif) |
| **Ctrl + Y** | Redoes the last action. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%209.gif) |
| **Ctrl + /** (numeric keypad) | Comments. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%206.gif) |
| **Ctrl + Shift + /** (numeric keypad) | Deletes the comment. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%207.gif) |
| **F9** | Runs the code. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%2011.gif) |
| **F1** | Opens the help page of the current word. ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%2012.gif) |
