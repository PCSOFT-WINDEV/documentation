## Default events
<a name="default_events_ELTTEXTE000134"></a>
The following events appear by default in the WINDEV and WINDEV Mobile code editor:


| Event | Runtime condition |
| --- | --- |
| Initializing | Executed when the window is opened. (\*) |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Click the control | Executed when clicking the control.<br><br>This event allows you, for example, to take a picture or record a clip (and then stopping it) by clicking on the preview.<br><br><br>	<B><B><B><B>Warning</B></B></B></B><br><br>	 This event can only be and executed if the Camera control is in "Version-26-compatible" mode.<br>
 |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Zoom in or out | Executed when the user zooms in or out in the Camera control<br><br>**Note: This event is only available for Camera Fields created with version 27 or higher (field not having the "Compatible 26" option ticked in the "General" tab of the field description window).** |
| ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Decoding a bar code | Executed when a bar code is detected by the camera. <br><br>**This event is only available if bar code decoding has been configured in the "Details" tab of the control description window.** <br><br>This event has the following format: <br><br><pre><code>PROCEDURE DécodeCodeBarre(cb est un CodeBarres)</code></pre><br><br><br>The information read can be retrieved by the [BarCode](../WDLang5/1000019451.md) variable. <br><br>For more details, see [Camera field: decode barcodes](../WDChamp/1013304.md). |


(\*) By default, the "Initialization" event of each control is executed according to the order in which the controls were created in the window. To modify this runtime order: 

1. On the "Window" tab, in the "Order" group, click "Initialization".

2. In the window that appears, use the arrows on the right to change the order in which the controls are initialized.
