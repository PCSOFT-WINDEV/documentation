


## Binding Bar Code controls to items
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Item characteristics
<a name="item_characteristics_ELTTEXTE000099"></a>
A Bar Code control can be bound to an item in a data file, query, etc.

Two types of items can be bound to a Bar Code control:

- a "Text" item.

- a "Numeric" item.








<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Binding Bar Code controls to items
<a name="binding_bar_code_controls_items_ELTTEXTE000123"></a>
**To define the item that will be bound to the Bar Code control directly from the window, page or report editor**:

1. Right-click and select "Description" in the context menu, then go to the "Binding" tab in the control description window.

2. Select the data file or query, and then the item to be bound to the Bar Code control.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Updating the item with the data from the Bar Code control
<a name="updating_the_item_with_the_data_from_the_bar_code_control_ELTTEXTE000147"></a>
**1st case: window or page fields are bound to fields in a data file** (Binding)
All the items in the data file (or a related file) that are bound to a control in the window or page will be updated by:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) [ScreenToFile](../WDLang4/3044146.md) in WINDEV or WINDEV Mobile.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [PageToFile](../WDLang4/3044022.md) in WEBDEV.




**Case 2: window or page fields are not associated with fields in a data file**
The value of each control must be assigned to each item using the following syntax:


```txt
<Data file>.<Item> = <Control name>
```
