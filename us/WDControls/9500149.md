## The different types of Edit controls
<a name="the_different_types_edit_controls_ELTTEXTE000302"></a>


### Text Edit control
<a name="text_edit_control_ELTPARAGRAPHE000011"></a>

This type of Edit control is used to show or enter character strings (name, address, etc.).

Remarks: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Text Edit controls can display a Delete ("X") button. This button allows the user to delete the content of the control. The button can be displayed in the input area: 

	- only when the user enters data in the control. 

		- only when the control loses focus. 
						![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Note: In iOS 7 only, the "X" icon sill appears when the user enters data in the control. 

		- always (whether the input cursor is in the control or not). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) You can insert emojis in the Edit control. If the information typed must be saved in a database, the linked item must be in Unicode format (Unicode string or text memo) to store the Emojis.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) When a Text Edit control is enlarged in the editor, it automatically becomes a multiline Edit control.



<a name="NOTE1_2"></a>


### Multiline Text Edit control
<a name="multiline_text_edit_control_ELTPARAGRAPHE000041"></a>

This type of Edit control is used to show or enter multiple lines separated by a "Carriage Return".

Remarks: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) If the lines are separated by a "Carriage Return", you have the ability to display a vertical or horizontal scrollbar.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) You can also display web addresses and file paths as links.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) When a Text Edit control is enlarged in the editor, it automatically becomes a multiline Edit control.



<a name="NOTE1_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### RTF Text Edit control
<a name="rtf_text_edit_control_ELTPARAGRAPHE000062"></a>

This type of Edit control is used to show and enter RTF content. For more details, see [Handling RTF in an Edit control](../WDChamp/1013190.md).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) For applications running on Windows Vista (or later) or in Tablet PC, you can include the "Handwritten input (PC tablet)" option. This option allows the user to directly write in the control using the mouse or a stylus. This feature is available by default in mobile applications.
<a name="NOTE1_4"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### HTML Text Edit control
<a name="html_text_edit_control_ELTPARAGRAPHE000082"></a>

This type of control is used to format rich text.

Characteristics: 

- A toolbar automatically appears at the top of the control, and allows users to add rich formatting (links, bold, italics, etc.).

- To enter an image in this type of control, you must specify the address of the image. 

- The user cannot open the links in the control directly. The links will work if the HTML content is displayed in an HTML control.




For more details, see [Handling HTML text in an Edit control](../WDChamp/9500112.md).
<a name="NOTE1_12"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Edit control with Markdown text (read-only)
<a name="edit_control_with_markdown_text_readonly_ELTPARAGRAPHE000104"></a>

This type of Edit control is used to display Markdown text. The user can select or scroll through this text. 

Reminder: The "Markdown" option in the "UI" tab of the Edit control description window applies only to the caption, tooltip and tokens associated with the control. This property does not apply to the content of the Edit control.

To change the type of the Edit control (from Text to Markdown, for example), use the [DisplayAsMarkdown](../Proprietes/1410089587.md) property.
<a name="NOTE1_5"></a>


### Password Edit control
<a name="password_edit_control_ELTPARAGRAPHE000122"></a>

In this type of control, all characters entered are replaced with asterisks on the screen. 

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) To avoid security breaches, it is not recommended to programmatically assign values to password Edit controls. Even if the password icon is invisible, the contents of the control can be read by debugging tools. 



![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The user can check the password entered (AAF). For more details, see [Showing passwords (AAF)](../WDChamp/9500129.md). 
<a name="NOTE1_6"></a>


### Numeric, Currency or Currency + Euro Edit control
<a name="numeric_currency_currency_euro_edit_control_ELTPARAGRAPHE000143"></a>

These different types of controls allow you to handle numerical values: 

- The Numeric Edit control is used to show or enter numeric values (weight, etc.). The "+++" characters are displayed if the control is not large enough to display the entire number.

- The Currency Edit control is used to show or enter currency values.

- The Currency + Euro Edit control is used to handle prices, for example.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of Edit control is not available.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The Numeric, Currency and Currency + Euro edit controls can display a **calculator** button allowing the user to perform a calculation ("Display calculator button" option). Several AAFs (Automatic Application Features) are available for this type of control (e.g., change the value with the mouse wheel). For more details, see [AAFs for numeric controls](../Editeurs/9500122.md).
<a name="NOTE1_7"></a>


### Date Edit control
<a name="date_edit_control_ELTPARAGRAPHE000171"></a>

This type of Edit control is used to show or enter dates.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The user can use the "+" and "-" keys on the numeric keypad to change the date.
If the control is not in a popup, you can display a calendar button to allow the user to enter the date ("Display a calendar button" option). In this case, you can define the characteristics of the calendar. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) ***AAF (Automatic Application Features)***: If the Calendar button is not displayed, the user can still enter a date in the calendar ("Calendar" option in the context menu of the control). To delete this AAF, use [AAFDisable](../WDLang1/1000022018.md) with the constant *aafCalendar*. For more details, see [AAFs for Date controls](../Editeurs/9500124.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To use a date picker, the input mask must be of type: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) "Date picker",

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) "Date and Time picker".
