## Selection mode
<a name="selection_mode_ELTTEXTE000152"></a>
The "UI" tab in the List Box control description window allows you to define the selection mode in the control. 

The available selection modes are as follows: 

- **Simple selection**: Selection banner displayed on selected line. The row selection code is executed.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Android/iOS selection mode (hide banner after selection)**: This option hides the selection banner after selection.. The banner appears only when the line is pressed.. Then, the row selection code is executed. 

- **Multiple selection**: Selection banner displayed on selected lines. To select several rows, hold the Shift or Ctrl key down. The row selection code is executed each time a row is selected.

## Move
<a name="move_ELTTEXTE000176"></a>
The options to move through the List Box control can be defined in the "Details" tab of the control description window. You can define: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **The display mode of the horizontal/vertical scrollbar**. It can be:

	- automation: the elevator will be displayed only when needed.

	- always visible: the elevator will always be displayed.

	- never visible: the elevator will never be displayed.




- **The scrolling mode**: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Per-pixel scrolling: rows can be displayed partially according to the scrollbar position.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Touch scrolling: used to handle the scrollbar in a touch screen.

	- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Fast scrolling: you can scroll through the control with a specific scrollbar on the right edge of the control.
			If the "With alphabetical indexing" option is selected, an alphabetical scrollbar will appear to allow users to jump to the element that starts with the desired letter.
			Use conditions:

		- Fast scrolling is only available for List Box controls populated programmatically or with in-memory data source.

		- Fast scrolling is available for List Box controls sorted alphabetically.
