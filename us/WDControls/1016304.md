
## Manipulating days in a Calendar control programmatically
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000129"></a>
WINDEV, WEBDEV and WINDEV Mobile allow you to programmatically manipulate the following elements:

- A Calendar control. For more details, see [Manipulating Calendar controls programmatically](../WDChamp/1016301.md).

- A day in a Calendar control.






<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000153"></a>


### Programming
<a name="programming_ELTPARAGRAPHE000044"></a>

To handle days in a Calendar control, use the following syntax:


```txt
<Calendar control>[<Date>]
```


For example:


```wl
// Displays the date on a red background
CAL_Calendar1["20120701"].BackgroundColor = LightRed
```


Several properties can be used to handle a day in a Calendar control.
