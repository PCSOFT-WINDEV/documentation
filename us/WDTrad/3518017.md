## How to install WDTRAD?
<a name="how_install_wdtrad_ELTTEXTE000084"></a>
WDTRAD is installed automatically when WINDEV, WEBDEV or WINDEV Mobile is installed. 

To install WDTRAD only, you need to install and run the "InstallWDTRAD.EXE" file (included in the WINDEV, WEBDEV or WINDEV Mobile installation package).

<a name="NOTE2_1"></a>


## Remarks
<a name="remarks_ELTTEXTE000108"></a>


- The dictionary provided with WDTRAD is installed by default. To use a custom dictionary: 

	1. Use WDTRAD to create and customize your dictionary. 

	2. Retrieve the dictionary by copying the "Dictionary" subdirectory from the WDTRAD installation directory.

	3. Paste this subdirectory into the desired WDTRAD installation directory. 




- If the messages found in your application must be translated by an external company, don't forget to also the provide the company the files containing the messages to translate: 

	- a text file, 

	- the HFSQL data file (.fic, .ndx and .mmo files), 

	- the wdmsg file.




- Once the translation is completed, the files containing the translated messages must be retrieved. These files must be checked in by WDMSG or WDINT.

- You must specify the language used the first time you start WDTRAD. You can change this language at any time in WDTRAD (option "? .. Language").
