


## DayOfMonth (Property)

***In french: JourDuMois***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DayOfMonth** property gets and sets the number of the day of the month on which the scheduled task should be executed. 

This property can be used on:

- a variable of type [hScheduledTask](../WDLang4/1000017448.md).

- a variable of type [hScheduling](../WDLang4/1000018853.md).

- a variable of type [Repetition](../WDLang1/1000019262.md). 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [appServerScheduledTask](../WDLang2/1000022367.md).
