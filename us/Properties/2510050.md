


## Height (Property)

***In french: Hauteur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Height** property gets and sets the height:

- of a control or block in a report.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) of a control (in a window), window, row of a Table, List Box or ListView control, option of a Radio Button or Check Box control, break header or footer of a Table or Looper control.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) of a control (in a page), break header or footer in a Table or Looper control. The control can be overlayable or not.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) of a break cell in a Table or Looper control. 




You can also get the height of a cell in a Table control.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The modification is available for overlayable controls only ("UI" tab of the control description).

**Remarks**:

- The border of the control or block is included in its height. The [HeightInPixel](../Proprietes/2511064.md) property is used to get the height of a control in pixels.

- The height of a control is defined in the editor, in the control description. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To make the content of a maximized window scrollable, use the [UsefulHeight](../Proprietes/1000021504.md) property.

## Example


```wl
// Increases the height of "EDT_CustomerName"
EDT_CustomerName.Height = EDT_CustomerName.Height + 15
// Is equivalent to: SAI_CustomerName.Height + = 15
```

## Syntax

### Finding out the height of an element

`<Result> = <Element used>.Height`
---

**`<Result>: (Real)`**

Height of the specified element. This height is expressed in pixels in a window and/or in a page, and in millimeters in a report.

**`<Element used>: (Name of control or block.)`**

Name of the element (control or block) to use.  


<a name="SYNTAXE2"></a>

### Modifying the height of an element

`<Element used>.Height = <New height>`
---

**`<Element used>: (Name of control or block.)`**

Name of the element (control or block) to use.

**`<New height>: (Real)`**

New height of the specified element. This height is expressed in pixels in a window and/or in a page, and in millimeters in a report.

### Height in a report
<a name="height_report_ELTPARAGRAPHE000119"></a>

- The height of a non-breakable block cannot exceed the available page height (excluding the page header and the page footer).

- The height of a page footer cannot be modified. However, the height of a page header can be modified through programming.

- A control must be entirely contained in the block to which it belongs.

### Row height
<a name="row_height_ELTPARAGRAPHE000130"></a>

The height of each row in a Table, List Box or ListView control can be defined programmatically. For browsing List Box and Table controls, this height is kept for the visible section on the screen only

Example: Set the height of line 3 of the "LISTE_Liste1" list to 200.


```wl
LIST_List1[3].Height = 200
```
Note: For a column in a Table control, the property **Height** property indicates the visible height of the Table control column. This property is read-only.

### Initial height (control and window)
<a name="initial_height_control_and_window_ELTPARAGRAPHE000146"></a>

The initial height (described in the editor) is returned by the [InitialHeight](../Proprietes/2510043.md) property.

In most cases, the height of an object depends on [MaxHeight](../Proprietes/2510065.md) and [MinHeight](../Proprietes/2510035.md). However, this constraint no longer applies when the height is changed through programming (with the **Height** property or the [WinSize](../WDLang1/3038020.md) function).
<a name="NOTE0_4"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Height of controls in a form
<a name="height_controls_form_ELTPARAGRAPHE000171"></a>

In server code, the returned and modifiable height corresponds to the total height of the control (height of the caption plus height of the input area if the caption and the input area are one above each other).

In browser code, the returned and modifiable height corresponds to the height of the input area.

### Limitations
<a name="limitations_ELTPARAGRAPHE000180"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) **Limitations for reports**
The **Height** property cannot be used on a report or on a Check Box control.

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **Height** property can only be used with the following elements:

- Button control.

- Static Text control.

- Edit control.

- Image control.

- Check Box control.

- Radio Button control.

- List Box control.

- Combo Box control.

- TreeView control.

- Tab control.

- Window.

- Table control.

- Columns of a Table control.

- Supercontrol.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The **Height** property is not available on Table control columns.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The **Height** property is not available on iFrame controls.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The **Height** property is only available in read-only mode on Breadcrumb and Table controls.
