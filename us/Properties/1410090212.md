
## ActionTarget (Property)

***In french: ActionCible***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ActionTarget** defines the action performed when the user clicks the target control(s) of a step of a Guided Tour. This property can be used on:

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
