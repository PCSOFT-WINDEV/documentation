
## Zoom (Property)

***In french: Zoom***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Zoom** property gets and sets the zoom applied to an element. This property can be used on: 

- a control or a window. For more details, see [Zoom](../Proprietes/1000017201.md). 

- a variable of type [pdfParameter](../WDLang6/1410087857.md).
