


## CompactOption (Property)

***In french: CompacteOption***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CompactOption** property is used to:

- determine whether the options of a Radio Button, Check Box or Dashboard control are compacted.

- define whether the options of a Radio Button, Check Box or Dashboard control should be compacted.




In compact mode, the space between the options is reduced: 

- when an option is hidden. 

- when an option is removed.




If the options are not compacted, they keep their initial position. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
CBOX_Options.CompactOption = True
// Deletes option #3 from a Check Box control
CheckBoxDelete(CBOX_Options, 3)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining whether the options of a control are compacted

`<Result> = <Control used>.CompactOption`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if options are compacted, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Check Box control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Radio Button control, 

- a Dashboard control.





<a name="SYNTAXE2"></a>

### Defining whether the options of a control should be compacted

`<Control used>.CompactOption = <Compact>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Check Box control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Radio Button control, 

- a Dashboard control.




**`<Compact>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if field options are to be compacted, 

- <u><u><u><u>False</u></u></u></u> otherwise. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
This property is available for: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Check Box controls. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Radio Button controls. 

- Dashboard controls.




**Remarks**:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Switch and Picker fields: This property corresponds to the "Compact invisible options" option available in the "Detail" tab of the field description.

- Dashboard field: This property corresponds to the "Compact Widgets" option available in the "Detail" tab of the field description.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is available for Dashboard controls only.
