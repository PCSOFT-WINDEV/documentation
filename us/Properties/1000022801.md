
## InitialValue (Property)

***In french: ValeurInitiale***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **InitialValue** property gets and/or sets an initial value. This property can be used on:

- the controls of a window or page. For more details, see [ InitialValue](../Proprietes/2510128.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docNumberingLevel](../WDLang1/1000022799.md).
