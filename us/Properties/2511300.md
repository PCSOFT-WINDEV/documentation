
## Source (Property)

***In french: Source***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Source** property gets and sets the source of an element. This property can be used on:

- a Chart control or a connection. For more details, see [Source property on a chart or connection](../Proprietes/2510147.md).

- a variable of type [hBackupDescription](../WDLang4/1000017455.md). 

- a variable of type [rssEntry](../WDLang5/1000017792.md). 

- the [Email](../WDLang3/3032029.md) structure

- a variable of type [Email](../WDLang3/1000018713.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Contact](../WDLang3/1000020254.md).

- a variable of type [OpenIDIdentity](../WDLang3/1000023567.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [AppleID](../WDLang3/1000025405.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadInfo](../WDLang3/1410087306.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) a variable of type [DownloadParameter](../WDLang3/1410087293.md).
