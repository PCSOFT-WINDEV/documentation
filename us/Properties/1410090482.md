
## DisplayedValueComboBox (Property)

***In french: ValeurAffichéeCombo***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DisplayedValueComboBox** property gets and sets the value displayed in a Combo Box control, i.e., the value displayed when the row that contains that value is selected. This makes it possible to display different values when the Combo Box control is expanded and collapsed. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ListAdd(COMBO_Class, "First class (More comfort)")
COMBO_Class[1].DisplayedValueComboBox = "First class"
ListAdd(COMBO_Class, "Second class (Cheapest)")
COMBO_Class[2].DisplayedValueComboBox = "Second class"
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the displayed value associated with a row of a Combo Box control

`<Result> = <Control used>.DisplayedValueComboBox`
---

**`<Result>: (Type of value)`**

Value displayed in the Combo Box control if the row is selected. 

**`<Control used>: (Control name)`**

Row of the Combo Box control to be used. The following syntax must be used: 

```txt
<Combo Box control name>[Element index]
```



<a name="SYNTAXE2"></a>

### Changing the displayed value associated with a row of a Combo Box control

`<Control used>.DisplayedValueComboBox = <New value>`
---

**`<Control used>: (Control name)`**

Row of the Combo Box control to be used. The following syntax must be used: 

```txt
<Combo Box control name>[Element index]
```


**`<New value>: (Type of value)`**

Value to be displayed in the Combo Box control if the row is selected. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- This property is only available for Combo Box controls populated programmatically. 

- When the row is selected (by the user or programmatically), the value displayed in the Combo Box control corresponds to the value specified by the **DisplayedValueComboBox** property.

- The value displayed in the Combo Box control can be read using the [DisplayedValue](../Proprietes/2510129.md) property. 

- For Combo Box controls in edit mode, the **DisplayedValueComboBox** property corresponds to the value to be displayed in the input field.
