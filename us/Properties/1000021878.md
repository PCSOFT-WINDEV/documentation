


## EndControl (Property)

***In french: ChampArrivée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **EndControl** property gets or sets the target control of a Wire control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create and initialize a Wire control 
// This wire links the BTN_ControlA and BTN_ControlB controls
WireName is Control
WireName <- ControlCreate("", typWire)
WireName.StartControl = BTN_ControlA
WireName.EndControl = BTN_ControlB
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the target control of a Wire control

`<Result> = <Control used>.EndControl`
---

**`<Result>: (Character string)`**

Name of the control. 

**`<Control used>: (Control name)`**

Name of the Wire control. 


<a name="SYNTAXE2"></a>

### Setting the target control of a Wire control

`<Control used>.EndControl = <New target control>`
---

**`<Control used>: (Control name)`**

Name of the Wire control. 

**`<New target control>: (Character string)`**

Name of the new target control. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The wire is displayed if the [StartControl](../Proprietes/1000021877.md) and **EndControl** properties have been specified. 

- Connection points can be set using the [AttachPointStart](../Proprietes/1000021907.md) and [AttachPointEnd](../Proprietes/1000021908.md) properties.
