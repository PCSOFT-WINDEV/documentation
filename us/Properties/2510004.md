


## Alias (Property)

***In french: Alias***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
**Caution**: In WEBDEV, the **Alias** property works in a different way than in WINDEV and WINDEV Mobile.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The **Alias** property is used to get or change: 

- the alias of a window. To change the alias of a window, you can also use [WinChangeAlias](../WDLang1/3038028.md). 
	**Reminder**: Aliases can be used to identify a window opened multiple times (common case in an MDI application).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the alias of a pane in a Dynamic Tab control. 




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The **Alias** property returns the internal HTML/JavaScript name of a control.
WLanguage is less restrictive with control and page names than JavaScript. This allows you to use special characters, have two controls with the same name in the same page, etc.
Controls and pages are renamed in HTML pages. These names can be compressed for optimization purposes.
The **Alias** property gets the name used in the HTML page.

### Getting the alias of a window

`<Current alias> = <Window>.Alias`
---

**`<Current alias>: (Character string)`**



- Alias of the window,

- Empty string ("") if the specified window has no alias.




**`<Window>: (Window name)`**

Name of the window used. This parameter can be equal to:

- [MySelf](../Motscles/1511007.md). If you want to get the alias of the current window, for example.

- an indirection to the alias of the window. The alias will be known at runtime. The name of the alias is unknown when the code is compiled.

### Changing the alias of a window

`<Window>.Alias = <New alias>`
---

**`<Window>: (Window name)`**

Name of the window used. This parameter can be equal to:

- [MySelf](../Motscles/1511007.md). If you want to get the alias of the current window, for example.

- an indirection to the alias of the window. The alias will be known at runtime. The name of the alias is unknown when the code is compiled.




**`<New alias>: (Character string)`**

New window alias.

### Getting the alias of the current Dynamic Tab control pane

`<Current alias> = <Tab pane name>.Alias`
---

**`<Current alias>: (Character string)`**

Alias of the dynamic tab pane. 

**`<Tab pane name>: (Character string)`**

Name of the current Tab control pane identified by the following syntax: 
```txt
<Tab control>[<Tab control>]
```



<a name="SYNTAXE4"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
### Changing the alias of the current Dynamic Tab control pane

`<Tab pane>.Alias = <New alias>`
---

**`<Tab pane>: (Character string)`**

Name of the current Tab control pane identified by the following syntax: 
```txt
<Tab control>[<Tab control>]
```


**`<New alias>: (Character string)`**

New alias of the dynamic tab pane.

### Getting the internal HTML/JavaScript name of an element

`<Current alias> = <Element name>.Alias`
---

**`<Current alias>: (Character string)`**

Name of the element used in the HTML or JavaScript code.

**`<Element name>: (Character string)`**

Name of the desired control or page.

### Differences between the Name and **Alias** properties
<a name="differences_between_the_name_and_docparampagetitleshort_properties_ELTPARAGRAPHE000142"></a>

The [Name](../Proprietes/2510082.md) property returns the WLanguage name of the control, whereas **Alias** returns the HTML name of the control. To pass a control name as a parameter to a JavaScript procedure, use the **Alias** property.
