


## FontUnderlined (Property)

***In french: PoliceSoulignée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FontUnderlined** property is used to:

- Determine if the text is underlined.

- Underline (or not) a text.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Underline the text displayed in "STC_StaticControl"
STC_StaticControl.FontUnderlined = True
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining if the text displayed in a control is underlined

`<Result> = <Control used>.FontUnderlined`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the text is underlined,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (Control name)`**

Name of the control to be used.  


<a name="SYNTAXE2"></a>

### Applying or removing underline formatting from the text displayed in a control

`<Control used>.FontUnderlined = <Underlined/Not underlined>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.

**`<Underlined/Not underlined>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the text must be underlined,

- <u><u><u><u>False</u></u></u></u> otherwise.

### Special case: Link control
<a name="special_case_link_control_ELTPARAGRAPHE000095"></a>

The result of the **FontUnderlined** property ignores that browsers underline links by default.

Therefore, the value returned by the **FontUnderlined** property in browser code and in server code for the same Link control can be different. 


### Limitations
<a name="limitations_ELTPARAGRAPHE000106"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) In a report, the **FontUnderlined** property can only be used on:

- a Static Text control.

- a Calculated control.

- a URL Link control.

- a Preset control.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) In a window, the **FontUnderlined** property cannot be used on:

- a Spin control, 

- a Web Camera control, 

- a Conference control.Note: This property only applies to ListView controls in standard "List Box" display mode.


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The **FontUnderlined** property cannot be used on table columns.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) In a page, the **FontUnderlined** property can be used on:

- a Static Text control, 

- an Edit control,

- a Button control,

- a Check Box control,

- a Radio Button control, 

- a List Box control, 

- a column in a Table control,

- a cell of a Table control (read only),

- a formatted display control, 

- an HTML control,

- a Combo Box control,

- a Link control, 

- an HTML Static control, 

- a Pager control, 

- a Breadcrumb control (except in PHP),

- a TreeView control, 

- a menu.
