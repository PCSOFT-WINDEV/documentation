
## EndTimestamp (Property)

***In french: DateHeureFin***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **EndTimestamp** property sets the end date and time of an action. It is available for the following types of variables:

- [hbReading](../WDLang4/1000021701.md)

- [hbScanParameter](../WDLang4/1000021715.md)
