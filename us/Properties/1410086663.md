
## KeyPassword (Property)

***In french: MotDePasseClé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **KeyPassword** property defines the password used to decrypt the private key. This property can be used on:

- a variable of type [xmlSignature](../WDLang5/1000020736.md). 

- a variable of type [xmlXAdESSignature](../WDLang5/1410091158.md).
