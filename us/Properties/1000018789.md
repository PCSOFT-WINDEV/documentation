
## XMLSource (Property)

***In french: SourceXML***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **XMLSource** property gets the XML source code. This property can be used with: 

- a variable of type [wsResponse](../WDLang3/1000020568.md). 

- a variable of type [xmlNode](../WDLang5/1000018786.md).
