
## Certificate

***In french: Certificat***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Certificate** keyword can correspond to:

- the [Certificate](../WDLang1/1000019287.md) variable type. 

- the **Certificate** property of a variable of type [Email](../WDLang3/1000018713.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the [Certificate](../Proprietes/1000021684.md) property used on Signature controls in reports.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a property of a variable of type [pdfSignature](../WDLang6/1000022255.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a property of a variable of type [JWTParameters](../WDLang3/1410089572.md).
