
## Encryption (Property)

***In french: Cryptage***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Encryption** property gets and sets the encryption algorithm used. This property can be used on:

- an HFSQL Client/Server connection. For more details, see [Encryption](../Proprietes/2512102.md).
