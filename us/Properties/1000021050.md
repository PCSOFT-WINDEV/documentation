
## Member (Property)

***In french: Membre***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Member** property gets and sets a member of a variable of type Variant, JSON or YAML. This property can be used on:

- a variable of type [JSON](../WDLang1/1000023611.md).

- a variable of type [Variant](../Motscles/1514019.md).  

- a variable of type [YAML](../Motscles/1000024438.md).
