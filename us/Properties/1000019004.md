


## Num1stDayOfTheWeek (Property)

***In french: Num1erJourDeLaSemaine***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Num1stDayOfTheWeek** property gets and sets the 1st day of the week displayed in:

- a Calendar control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) a Scheduler control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) an Edit control in Date format with Calendar.




**Remark**: The first day of the week can also be set in the field description window ("Detail" tab)..

## Example

```wl
	ORG_Organizer1.Num1stDayOfTheWeek = 6 // Saturday
ELSE
	ORG_Organizer1.Num1stDayOfTheWeek = 1 // Monday
END
```

## Syntax
<a name="SYNTAXE1"></a>

### Getting the first day of the week

`<Result> = <Control used>.Num1stDayOfTheWeek`
---

**`<Result>: (Integer)`**

First day of the week defined for the specified control. The days of the week are manipulated via the following identifiers:
0 - Sunday
1 - Monday 
2 - Tuesday
3 - Wednesday
4 - Thursday
5 - Friday
6 - Saturday

**`<Control used>: (Control name)`**

Name of the control used: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Organizer control.

- Calendar control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Scheduler control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Edit control in Date format with Calendar.





<a name="SYNTAXE2"></a>

### Changing the first day of the week

`<Control used>.Num1stDayOfTheWeek = <New first day>`
---

**`<Control used>: (Control name)`**

Name of the control used: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Organizer control.

- Calendar control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Scheduler control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Edit control in Date format with Calendar.




**`<New first day>: (Integer)`**

Identifier of the day to use as first day of the week. The identifiers of the days of the week are as follows: 
0 - Sunday
1 - Monday 
2 - Tuesday
3 - Wednesday
4 - Thursday
5 - Friday
6 - Saturday
