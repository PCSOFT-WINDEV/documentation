
## IndentFirstLine (Property)

***In french: RetraitPremièreLigne***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **IndentFirstLine** property gets and sets the indent of the first line of an element. This property can be used on:

- [docParagraph](../WDLang1/1000022483.md) variables.

- [docNumberingLevel](../WDLang1/1000022799.md) variables.
