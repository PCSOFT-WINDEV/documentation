


## Category (Property)

***In french: Catégorie***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Category** property gets and sets the category of an element. This property can be used on:

- a variable of type [Email](../WDLang3/1000018713.md). 

- a variable of type [EventTimeline](../WDLang1/1000020612.md).

- a variable of type [Appointment](../WDLang1/1000019244.md).

- a variable of type [rssChannel](../WDLang5/1000017769.md).

- a variable of type [rssEntry](../WDLang5/1000017792.md).

- the [Email](../WDLang3/3032029.md) structure. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docProperty](../WDLang1/1000022945.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [Notification](../WDLang3/1000019441.md).
