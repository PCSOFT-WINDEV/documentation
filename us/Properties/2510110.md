


## StoredItem (Property)

***In french: RubriqueMémorisée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StoredItem** property is used to:

- Get the stored item or variable of a Table, Looper, TreeView, List Box or Combo Box control.

- Set the stored item or variable of a Table, Looper, TreeView, List Box or Combo Box control.




**Remarks**:

- The stored item is used for controls associated with a data file or query. The stored variable is used for controls associated with a variable.

- The stored item or variable is defined in the window or page editor, in the "Content" tab of the control description.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=RubriqueMemorisee.gif)








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the stored item of the "TABLE_CustomerTable" control
TABLE_CustomerTable.StoredItem = "CustomerName"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the stored item or variable of a control

`<Stored item/variable> = <Control used>.StoredItem`
---

**`<Stored item/variable>: (Character string)`**



- Name of the stored item for the specified control. This item belongs to the data file the control is based on (returned or modified with the [BrowsedFile](../Proprietes/2510040.md) property).

- Name of the stored variable for the specified control. This name has the following format ":&lt;prefix&gt;&lt;Variable name&gt;" or ":&lt;Variable name&gt;" (the prefix is used only if the code style is enabled in the project).
	This variable belongs to the variable the control is based on (returned or modified with the [BrowsedFile](../Proprietes/2510040.md) property).

- Empty string ("") if no item or variable is associated with the control.




**`<Control used>: (Control name)`**

Name of the control to be used: 

- Table control,

- List Box control, 

- Combo Box control, 

- TreeView control.





<a name="SYNTAXE2"></a>

### Setting the stored item or variable of a control

`<Control used>.StoredItem = <New item/variable>`
---

**`<Control used>: (Control name)`**

Name of the control to be used: 

- Table control,

- List Box control, 

- Combo Box control, 

- TreeView control.




**`<New item/variable>: (Character string)`**



- Name of the new stored item for the specified control. This item must belong to the data file the control is based on (returned or modified with the [BrowsedFile](../Proprietes/2510040.md) property).

- Name of the new stored variable for the specified control. This name has the following format ":&lt;prefix&gt;&lt;Variable name&gt;" or ":&lt;Variable name&gt;". The prefix must be specified only if the code style is enabled in the project (whether or not prefixes are displayed).
	This variable belongs to the variable the control is based on (returned or modified with the [BrowsedFile](../Proprietes/2510040.md) property).

- Empty string ("") if no item or variable must be associated with the control.

## Remarks


### Value property
<a name="value_property_ELTPARAGRAPHE000106"></a>

The **StoredItem** property modifies the value returned by the [Value](../Proprietes/2510130.md) property.

Two distinct cases may occur: 

- The List Box or Table control is manipulated programmatically OR the **StoredItem** property is set to an empty string (""). The [Value](../Proprietes/2510130.md) property allows you to:

	- Get the selected row. If no row is selected, the [Value](../Proprietes/2510130.md) property returns -1. If you use a multiple-selection List Box or Table control, the number of the last selected row is returned.

	- Select another row by specifying the number of the new row to select. The rows previously selected are deselected.
			**To get the selected row**, use one of the following syntaxes: 
			
		```txt
		ResRow = <List Box or Table control>.Value
		ResRow = <List Box or Table control>
		```





- The List Box or Table control is bound to a data file AND the **StoredItem** property is not an empty string (""). The [Value](../Proprietes/2510130.md) property is used to identify the stored item for the record associated with the selected row. If no row is selected, the [Value](../Proprietes/2510130.md) property returns an empty string ("").
	**To get the stored item associated with the selected row**, the following syntaxes are equivalent:
	
	```txt
	ResStoredItem = <List Box or Table control>.Value
	ResStoredItem = <List Box or Table control>.StoredItem
	```




<a name="NOTE0_2"></a>


### DataBinding property
<a name="databinding_property_ELTPARAGRAPHE000150"></a>

The **StoredItem** property is often used in combination with the [DataBinding](../Proprietes/2510060.md) property . This association creates an automatic link between two data files when [FileToScreen](../WDLang4/3044210.md) and [ScreenToFile](../WDLang4/3044146.md) are called.
<a name="NOTE0_3"></a>


### Table control populated programmatically
<a name="table_control_populated_programmatically_ELTPARAGRAPHE000168"></a>

If a Table control populated programmatically must display data coming from a data file, a query or a view:

- Create a Table control populated programmatically in the window editor or in the page editor.

- In the code, specify the item to loop through with the [BrowsedItem](../Proprietes/2510111.md) property. This item must be in the data file, query or view whose data will be displayed in the Table control populated programmatically.

- In the code, specify the item to be stored with the **StoredItem** property. This item must be in the data file, query or view whose data will be displayed in the Table control populated programmatically.

- Use [FileToMemoryTable](../WDLang1/3074005.md) to initialize the Table control with the desired data. The data will be sorted according to the specified search item.

- The [DisplayedItem](../Proprietes/2510123.md) property will be automatically initialized.



<a name="NOTE0_4"></a>


### List Box control populated programmatically
<a name="list_box_control_populated_programmatically_ELTPARAGRAPHE000192"></a>

If a List Box or Combo Box control populated programmatically must display data from a data file, query or view:

- Create a List Box or Combo Box control populated programmatically in the window editor or in the page editor.

- Use [FileToMemoryList](../WDLang1/3049007.md) to initialize the control with the desired data.

- The [BrowsedFile](../Proprietes/2510040.md), [DisplayedItem](../Proprietes/2510123.md), [BrowsedItem](../Proprietes/2510111.md) and **StoredItem** properties will be automatically initialized.



<a name="NOTE0_5"></a>


### Finding and selecting an item in a data-bound List Box control (or Combo Box control)
<a name="finding_and_selecting_item_databound_list_box_control_combo_box_control_ELTPARAGRAPHE000217"></a>To find and/or select an item in a data-bound List Box or Combo Box control, use the following syntax:

```wl
LIST_OrderList.StoredItem = "CustomerID"
// Find and select the element with CustomerID "135"
LIST_OrderList = 135
// If the element is not found, LIST_OrderList will be set to -1
```

<a name="NOTE0_6"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000227"></a>

The **StoredItem** property can only be used in the following controls:

- Table control,

- List Box control,

- Combo Box control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) ListView control,

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Looper control.

- TreeView control.
