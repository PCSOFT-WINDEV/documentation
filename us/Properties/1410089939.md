
## MinimumLength (Property)

***In french: LongueurMinimale***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **MinimumLength** property gets and sets the minimum length of an element. This property can be used on:

- a description of a full-text index. For more details, see [MinimumLength](../Proprietes/1000017716.md).

- a variable of type [NumericFormat](../WDLang1/1410089836.md).
