
## Major (Property)

***In french: Major***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Major** property gets and sets the Major number of a Beacon. This property can be used on: 

- a variable of type [beaconDetectionInfo](../WDLang3/1000023109.md). 

- a variable of type [beaconGroup](../WDLang3/1000023105.md).
