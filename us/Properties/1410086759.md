
## AIImage (Property)

***In french: IAImage***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AIImage** property gets and sets the image associated with a response in an AI Chat control.                                                                                                                                                                                            
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AICHAT_MyAIChat.AIImage = "Robot.png"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the image

`<Result> = <AI Chat control>.AIImage`
---

**`<Result>: (Character string)`**

Image used. 

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.   


<a name="SYNTAXE2"></a>

### Setting the image

`<AI Chat control>.AIImage = <Image>`
---

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.

**`<Image>: (Character string)`**

Name of the image used: 

- Image file name,

- Empty string ("") to use no image,

- *imgDefault* constant to use default image.
