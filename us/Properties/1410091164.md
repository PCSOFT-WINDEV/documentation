
## ControlColor (Property)

***In french: CouleurChamp***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ControlColor** property allows you to get and set the background color used for the various interactive controls of a PDF form displayed in a PDF Reader control. 

Note: This property applies to Edit, Combo Box, List Box, Check Box and Radio Button controls. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Background color for controls in PDF forms displayed in the PDF Reader control
PDF_Reader.ControlColor = DarkGreen
// Color of the control that has focus in PDF forms displayed in the PDF Reader control
PDF_Reader.FocusColor = LightBlue
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the background color of interactive controls in PDF forms displayed in the PDF Reader control

`<Result> = <Control used>.ControlColor`
---

**`<Result>: (Constant or character string)`**

Background color of controls in the PDF form displayed in the PDF Reader control. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- [a preset color](../WDLang5/3010002.md).




**`<Control used>: (Control name)`**

Name of the PDF Reader control.


<a name="SYNTAXE2"></a>

### Setting the background color of interactive controls in PDF forms displayed in the PDF Reader control

`<Control used>.ControlColor = <New color>`
---

**`<Control used>: (Control name)`**

Name of the PDF Reader control.

**`<New color>: (Constant or character string)`**

New background color of controls in the PDF form displayed in the PDF Reader control. Corresponds to one of the following options:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a preset color](../WDLang5/3010002.md).
