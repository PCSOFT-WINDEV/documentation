
## ResponseRawContent

***In french: ContenuBrutRéponse***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ResponseRawContent** property determines if the Content property of the variable should correspond to the raw content. This property can be used on:

- a variable of type [httpRequest](../WDLang3/1000021158.md). 

- a variable of type [restRequest](../WDLang3/1000021481.md).
