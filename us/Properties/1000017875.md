


## MIMEType (Property)

***In french: TypeMIME***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MIMEType** property gets and sets the MIME type of an element. This property can be used on:

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [nfcData](../WDLang3/1000020406.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [upnpImage](../WDLang3/1000020905.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [gglDocument](../WDLang5/1000018001.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [gglAttachment](../WDLang5/1000026182.md).

- a variable of type [GglFile](../WDLang3/1410089586.md).
