


## LineSpacingType (Property)

***In french: TypeInterligne***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LineSpacingType** property gets and sets the type of line spacing used. This property can be used on:

- [docParagraph](../WDLang1/1000022483.md) variables.

- [docNumberingLevel](../WDLang1/1000022799.md) variables.
