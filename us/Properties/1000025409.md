
## IDToken (Property)

***In french: IDToken***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **IDToken** property gets the token associated with an authentication. This property is available for: 

- a variable of type [OpenIDIdentity](../WDLang3/1000023567.md),

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [AppleID](../WDLang3/1000025405.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [gglAccount](../WDLang3/1410089816.md).
