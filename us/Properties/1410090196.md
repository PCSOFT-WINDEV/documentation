
## AnimationDuration (Property)

***In french: DuréeAnimation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DurationAnimation** property sets the duration of an animation. This property can be used on:

- a control. For more details, see the help on the [AnimationDuration](../Proprietes/1000021069.md) property. 

- a variable of type [GuidedTour](../WDLang6/1410090170.md).

- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
