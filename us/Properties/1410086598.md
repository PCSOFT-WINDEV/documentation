
## Alignment

***In french: Alignement***
	

<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Alignment** property is used to align elements. This property can be used on:

- a variable of type [Marker](../WDLang3/1000019940.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docParagraph](../WDLang1/1000022483.md) (formatting characteristics).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docNumberingLevel](../WDLang1/1000022799.md).

- a variable of type [MapImage](../WDLang3/1000025523.md).

- a variable of type [NumericFormat](../WDLang1/1410089836.md).
