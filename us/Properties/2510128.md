


## InitialValue (Property)

***In french: ValeurInitiale***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InitialValue** property is used to get the initial value of a control in a window or page. This value corresponds to the initial value defined in the editor ("Content" tab of the control description window).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initialize the value of "EDT_Customer" with its initial value
EDT_Customer = EDT_Customer.InitialValue
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Initial value> = <Control used>.InitialValue`
---

**`<Initial value>: (Any type)`**

Initial value of specified control.

**`<Control used>: (Control name)`**

Name of the control to be used.

## Remarks
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### ActiveX control
<a name="activex_control_ELTPARAGRAPHE000070"></a>

For an ActiveX control, the initial value corresponds to the COM identifier (ProgID) of the ActiveX selected when creating the window.
<a name="NOTE0_2"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 

### iFrame control
<a name="iframe_control_ELTPARAGRAPHE000079"></a>

For an iFrame control, the **InitialValue** property corresponds to:

- the name of the page displayed (name selected in the description window of iFrame control). For example: "MyPage1".

- a full URL if the page displayed corresponds to a page of another Internet site.



<a name="NOTE0_3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 

### Chart control
<a name="chart_control_ELTPARAGRAPHE000093"></a>

For a Chart control, the initial value corresponds to the image displayed in the control background, selected when creating the window or the page.
<a name="NOTE0_4"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Drawer control
<a name="drawer_control_ELTPARAGRAPHE000102"></a>

For a Drawer control, the **InitialValue** property corresponds to the state of a control (expanded (1) or collapsed(0)) selected when the control was created.
<a name="NOTE0_5"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Combo Box control
<a name="combo_box_control_ELTPARAGRAPHE000113"></a>

For a Combo Box control, the **InitialValue** property is used to read again the initial string assigned to the element.

For example, if the following code is used to add an element: 

```wl
ListAdd(COMBO_Combo1, gImage(nImageNum,i) + "Customer.CustomerName" + i + ...
	gStoredValue("Customer.CustomerName" + i))
```
the following code is used to read the initial string again: 

```wl
COMBO_Combo1[1].InitialValue
```


Note: The result of the [DisplayedValue](../Proprietes/2510129.md) property does allow you to retrieve information about the content added with [gStoredValue](../WDLang1/1410088363.md).. 
<a name="NOTE0_6"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000137"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) In a window, the **InitialValue** property cannot be used on:

- a window,

- a Static Text control, 

- a Button control,

- a Shape control, 

- an option in a radio button or check box, 

- a row in a list box, listview or table, 

- a cell or a column in a table, 

- a menu, 

- a tab pane,

- a group of controls,

- an element in a TreeView control.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a page, the **InitialValue** property can only be used on:

- an Edit control,

- a formatted display control, 

- a Combo Box control,

- a List Box control, 

- a Static Text control, 

- a Table control,

- a Rich Text Area control, 

- a layout cell (if the cell is in stream mode).


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **InitialValue** property can only be used with the following elements:

- Edit control.

- Image control.

- Check Box control.

- Radio Button control.

- List Box control.

- Combo Box control.

- Table control.

- Supercontrol.


![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The **InitialValue** property applies only to Image controls.
