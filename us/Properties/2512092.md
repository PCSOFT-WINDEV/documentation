


## DefaultValue (Property)

***In french: DefaultValue***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **DefaultValue** property is used to:

- Find out the default value of an item. This item was defined in the data model editor or programmatically.

- Set the default value of an item (only for items defined programmatically).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the default value of the Orders.Title item
Civility.DefaultValue = 1
...
Address2 is Item Description
Address2.NullAllowed = True
// Set default value
Address2.DefaultValue = Null
...
// Validate the data file description
HDescribeFile(Orders)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Find out the default value of an item

`<Result> = <Data file>.<Item>.DefaultValue`
---

**`<Result>: (Type of item)`**

Default value of the item.

**`<Data file>: (Character string)`**

Name of the data file used.

**`<Item>: (Character string)`**

Name of the item used.

### Setting the default value of an item described programmatically

`<Item>.DefaultValue = <Value>`
---

**`<Item>: (Character string)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<Value>: (Type of item)`**

Default value of the item.
