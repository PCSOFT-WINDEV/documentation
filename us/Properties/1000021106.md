


## StoreTheValue (Property)

***In french: MémoriserLaValeur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StoreTheValue** property is used to:

- Determine if the value of a control is persistent, i.e. is preserved when an application is closed and reopened. 

- Enable or disable data persistence for a control. 




This property corresponds to the "Remember value" option in the "Details" tab of the description window of the following controls:

- Check box/Radio button,

- Combo box/List box,

- Edit control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Static tab/Dynamic tab.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
c is Control
c <- ControlCreate("EDT_Date_1", typDate, 0, 0, 100, 20)
c.Caption = "Today's date"
c.StoreTheValue = True
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Determining if the value of a control is persistent

`<Result> = <Control used>.StoreTheValue`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control keeps its value between two application starts,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Control used>: (Control name)`**

Name of the control to be used. This control can be: 

- a Check Box or Radio Button control,

- a Combo Box or List Box control,

- an Edit control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a static Tab control or a Dynamic Tab control.





<a name="SYNTAXE2"></a>

### Enabling or disabling data persistence for a control

`<Control used>.StoreTheValue = <New mode>`
---

**`<Control used>: (Control name)`**

Name of the control to be used. This control can be: 

- a Check Box or Radio Button control,

- a Combo Box or List Box control,

- an Edit control,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a static Tab control or a Dynamic Tab control.




**`<New mode>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the control must keep its value between two application starts,

- <u><u><u><u>False</u></u></u></u> otherwise. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If this property is set to <u><u><u><u>True</u></u></u></u> after the initialization step, the control will not take the previous value.

- This property is useful to configure the controls created by [ControlCreate](../WDLang1/1000020876.md) and [ControlClone](../WDLang1/3025017.md). 

- This property corresponds to the "Store the value" option found in the AAF context menu (Automatic Application Features). Controls created with [ControlCreate](../WDLang1/1000020876.md) give end users access to the AAF menu. This menu allows them to enable data persistence at any moment (unless the option is disabled with [AAFDisable](../WDLang1/1000022018.md)).
