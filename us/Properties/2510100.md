


## FontName (Property)

***In french: PoliceNom***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FontName** property is used to:

- Identify the font used in a control.

- Change the font used in a control.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Modify the font used in "EDT_CustomerName" control
EDT_CustomerName.FontName = "Arial"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the font used in a control

`<Result> = <Control used>.FontName`
---

**`<Result>: (Character string)`**

Name of the font used in the specified control.

**`<Control used>: (Control name)`**

Name of the control to be used.  


<a name="SYNTAXE2"></a>

### Changing the font used in a control

`<Control used>.FontName = <New font>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.  

**`<New font>: (Character string)`**

New font used in the specified control.

<a name="NOTE0_1"></a>

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000072"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In a report, the **FontName** property can only be used on:

- a URL Link control.

- a Static control.

- a Calculated control.

- a Preset control.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) In a window, the **FontName** property cannot be used on:

- a Spin control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Web Camera control, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a Conference control.


Note: This property only applies to ListView controls in standard "List Box" display mode.![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a page, the **FontName** property can be used on:

- a Static control, 

- an Edit control,

- a Button control,

- a Check Box control,

- a Radio Button control, 

- a List Box control, 

- a column in a Table control,

- a cell of a Table control (read only),

- a formatted display control, 

- an HTML control,

- a Combo Box control,

- a Link control, 

- an HTML Static control, 

- a Pager control, 

- a Breadcrumb control (except in PHP),

- a TreeView control, 

- a menu.


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **FontName** property can only be used with the following elements:

- Button control.

- Static Text control.

- Combo Box control.

- TreeView control.

- Column of a Table control.



![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **PHP: Font files**
In PHP, the files of corresponding fonts must be accessible (ttf files). 
These files must be in the directory of the site (directory _WEB returned by [fWebDir](../WDLang1/3036052.md)) and be named as follows: 

- &lt;Name of standard font&gt;

- &lt;Name of standard font&gt;_Bold

- &lt;Name of standard font&gt;_Italic

- &lt;Name of standard font&gt;_Italic_Bold
