


## FontBold (Property)

***In french: PoliceGras***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FontBold** property is used to:

- Determine if the text is bold.

- Change the weight of the text.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Write the text displayed in "STC_StaticControl" in bold
STC_StaticControl.FontBold = True
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining if the text displayed in a control is bold

`<Result> = <Control used>.FontBold`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the text is bold, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Control used>: (Control name)`**

Name of the control to be used.  


<a name="SYNTAXE2"></a>

### Applying or removing bold formatting from the text displayed in a control

`<Control used>.FontBold = <Bold/Not bold>`
---

**`<Control used>: (Control name)`**

Name of the control to be used.

**`<Bold/Not bold>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the text must be displayed in bold, 

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000086"></a>

In a report, the **FontBold** property can only be used on:

- a Static Text control.

- a URL Link control.

- a Calculated control.

- a Preset control.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) In a window, the **FontBold** property cannot be used on:

- a Spin control, 

- a Web Camera control, 

- a Conference control.


Note: This property only applies to ListView controls in standard "List Box" display mode.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a page, the **FontBold** property can be used on:

- a Static Text control, 

- an Edit control,

- a Button control,

- a Check Box control,

- a Radio Button control, 

- a List Box control, 

- a table column,

- a table cell (read-only),

- a formatted display control, 

- an HTML control,

- a Combo Box control,

- a Link control, 

- an HTML Static control, 

- a Pager control, 

- a Breadcrumb control,

- a TreeView control, 

- a menu.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In a PHP page, the **FontBold** property can be used on:

- a Static Text control, 

- an Edit control,

- a Button control,

- a Check Box control,

- a Radio Button control, 

- a List Box control, 

- a table column,

- a formatted display control, 

- an HTML control,

- a Combo Box control,

- a Link control, 

- an HTML Static control, 

- a Pager control, 

- a TreeView control, 

- a menu.


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In Java, the **FontBold** property applies only to the following elements:

- Button control.

- Static Text control.

- Combo Box control.

- TreeView control.

- Table column.
