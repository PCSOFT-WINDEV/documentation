
## MaskingRule (Property)

***In french: RègleAnonymisation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MaskingRule** property gets the masking rule applied to a data file item. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(Customer.FirstName.MaskingRule) // Displays "partial(2,"X",4)"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Masking rule> = <Data file>.<Item>.MaskingRule`
---

**`<Data masking rule>: (Character string)`**

Masking rule used, in SQL format. 

**`<Data file>: (Character string)`**

Name of the data file used. This name is defined in the data model editor.

**`<Item>: (Character string)`**

Name of the item used. This name is defined in the data model editor.
