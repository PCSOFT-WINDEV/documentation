
## Outline (Property)

***In french: Contour***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Outline** property is used to define the outline of a polygon. This outline is a simple, closed linestring. This property is available for: 

- a variable of type [Polygon2D](../WDLang4/1410090122.md). 

- a variable of type [PolygonGeo](../WDLang4/1410090127.md).
