
## LinkedKey (Property)

***In french: CléReliée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LinkedKey** property sets the characteristics of a link. You can:

- Get the item of the linked data file.

- Change the item of the linked data file.



<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=cleReliee.gif)



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Change linked key
LinkClubPerson.LinkedKey = Person.ClubID
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the linked key

`<Key name> = <Link name>.LinkedKey`
---

**`<Key name>: (Character string)`**

Name of the key used in the linked data file.

**`<Link name>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.  


<a name="SYNTAXE2"></a>

### Changing the linked key

`<Link name>.LinkedKey = <New key>`
---

**`<Link name>: (Character string)`**

Name of the link defined in the data model editor or via the [Link Description](../WDLang4/1514039.md) type.

**`<New key>: (Character string)`**

Name of the new key in the linked data file. This key was defined in the data model editor or via the [Item Description](../WDLang4/1514071.md) type.
