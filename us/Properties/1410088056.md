
## Shape (Property)

***In french: Shape***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Shape** property allows you to handle the different shapes of an element. This property is available for: 

- a variable of type [MarkerImage](../WDLang3/1000025796.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [Diagram](../WDLang1/1410088055.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [GuidedTour](../WDLang6/1410090170.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [GuidedTourStep](../WDLang6/1410090178.md).
