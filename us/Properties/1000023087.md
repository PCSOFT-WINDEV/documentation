
## Company (Property)

***In french: Société***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Company** property is used to get and modify the company associated with an element. This property is available for: 

- [gglContact](../WDLang5/1000017434.md) variables.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [docProperty](../WDLang1/1000022945.md) variables. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [WBAdminAccount](../WDLang2/1410089382.md) variables.
