


## Border (Property)

***In french: Cadre***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Border** property gets and sets the characteristics of the borders: 

- for a report control or block.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Not available.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) for a window control.
	Note: This property is not available for Button controls. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) for a cell of the Table control.




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is only available for reports.

## Example


```wl
// Define the characteristics of the borders for report controls
MyBorder is Border
MyBorder.Color = LightRed
MyBorder.Thickness = 5

// Borders for the NumNbPage control in the report
NumNbPage.Border = MyBorder
// Modify the characteristics of the borders for the NumNbPage control
NumNbPage.Border.Thickness = 1

// Get the characteristics of the borders for the NumNbPage control
MyBorder2 is Border = NumNbPage.Border
```
<a name="Exemple2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Configures the borders
MyBorder is Border
MyBorder.Color = LightRed 
MyBorder.Thickness = 5

// Specific feature of the bottom line
MyBorder.LineBottom.Type = LineDash
MyBorder.LineBottom.Color = DarkRed

// Applies the borders to cell 2, 2 (2nd row, 2nd column)
TABLE_MyTable[2,2].Border = MyBorder
// or 
TABLE_MyTable.COL_NoName2[2].Border = MyBorder
```

## Syntax

### Getting the border characteristics of an element

`<Characteristics> = <Element used>.Border`
---

**`<Characteristics>: (Border variable)`**

[Border](../Motscles/15140100.md) variable containing the characteristics of the borders for the specified element.

**`<Element used>: (Control name)`**



- Name of the control or block used. This element is in the current report. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Not available.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Name of the window control used.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Cell in a Table control using one of the following syntaxes:

	- syntax using the row and column numbers: 
		```txt
		<Table control>[RowNum,ColumnNum]
		```


	- syntax using the column name and row number: 
		```txt
		<Table control>.<Column name>[RowNum]
		```









<a name="SYNTAXE2"></a>

### Defining the borders programmatically

`<Element used>.Border = <Border characteristics>`
---

**`<Element used>: (Control name)`**



- Name of the control or block used. This element is in the current report.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Not available.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Name of the window control used.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Cell in a Table control using one of the following syntaxes:

	- syntax using the row and column numbers: 
		```txt
		<Table control>[RowNum,ColumnNum]
		```


	- syntax using the column name and row number: 
		```txt
		<Table control>.<Column name>[RowNum]
		```








**`<Border characteristics>: (Border variable)`**

[Border](../Motscles/15140100.md) variable containing the characteristics of the borders that will be applied to the specified element.
