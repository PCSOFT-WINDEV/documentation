
## StartPosition (Property)

***In french: PositionDébut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StartPosition** property gets the starting position of an element in a Word Processing document. This property can be used on:

- [docElement](../WDLang1/1000022484.md) variables. 

- [docFragment](../WDLang1/1000022482.md) variables

- [docParagraph](../WDLang1/1000022483.md) variables.
