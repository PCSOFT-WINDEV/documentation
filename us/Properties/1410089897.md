
## Prefix (Property)

***In french: Prefix***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Prefix** property is used to define prefixes. This property can be used on:

- a variable of type [mongoGridFS](../WDLang4/1000022416.md).

- a variable of type [NumericFormat](../WDLang1/1410089836.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [aiConversationElement](../WDLang1/1410091337.md).
