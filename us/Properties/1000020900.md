
## SerialNumber (Property)

***In french: NuméroSérie***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SerialNumber** property is used to manage serial numbers. This property can be used on: 

- a variable of type [Certificate](../WDLang1/1000019287.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [upnpDevice](../WDLang3/1000020903.md).
