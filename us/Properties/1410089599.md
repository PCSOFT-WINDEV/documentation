
## IntervalY (Property)

***In french: GraduationY***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **IntervalY** property gets the interval between marks on the Y-axis. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Shows the interval between marks on the Y-axis
Info(CHART_MyChart.IntervalY)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Chart control>.IntervalY`
---

**`<Result>: (Real)`**

Interval between marks on the Y-axis. 

**`<Chart control>: (Control name)`**

Name of the Chart control to be used.
