


## VerticalSwipe (Property)

***In french: BalayageVertical***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **VerticalSwipe** property gets and changes the swipe direction in an internal window with swipe gesture support.

Note: This property corresponds to the "Swipe orientation" option in the "UI" tab of the Internal Window field description.. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Event: Change window orientation
// The following code is used to always swipe on the same axis
IW_MyInternalWin1.VerticalSwipe = NOT IW_MyInternalWin1.VerticalSwipe
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the swipe direction

`<Result> = <Internal Window control>.VerticalSwipe`
---

**`<Result>: (boolean)`**



- <u><u><u><u>True</u></u></u></u> if the swipe gesture direction is vertical,

- <u><u><u><u>False</u></u></u></u> otherwise: the sweep is horizontal.  




**`<Internal Window control>: (Control name)`**

Name of the Internal Window control used. 


<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available for Android applications
### Changing the swipe direction

`<Internal Window control>.VerticalSwipe = <Direction>`
---

**`<Internal Window control>: (Control name)`**

Name of the Internal Window control used.

**`<Direction>: (boolean)`**



- <u><u><u><u>True</u></u></u></u> if the swipe gesture direction must be vertical,

- <u><u><u><u>False</u></u></u></u> if the swipe gesture direction must be horizontal.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
This property has no effect if the swipe gesture is not enabled on the Internal Window control. For more details, see [Changing the window content with a swipe gesture](../WDChamp/1013277.md). 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **This property is read-only**.
