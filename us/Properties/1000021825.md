


## CalculatedDefaultValue (Property)

***In french: ValeurParDéfautCalculée***
	

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>26</B>, ***CalculatedDefaultItem*</**>** is kept for backward compatibility. This property has been replaced with ***CalculatedDefaultValue*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CalculatedDefaultValue** property is used to:

- Finding out the SQL expression defining the default value of an item. This item was defined in the data model editor or programmatically.

- Define the SQL expression that returns the default value of an item (item described through programming only).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AFile is File Description
AnItem is Item Description
AnItem.Name = "CmdDate"
AnItem.Type = hItemDateTime
AnItem.CalculatedDefaultValue = "SYSDATE"
HDescribeItem(AFile, AnItem)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Finding out the SQL expression defining the default value of an item

`<Result> = <Data file>.<Item>.CalculatedDefaultValue`
---

**`<Result>: (Character string)`**

SQL expression defining the default value of the item.

**`<Data file>: (Name of data file)`**

Name of the data file used.

**`<Item>: (Item name)`**

Name of item used.

### Defining the SQL expression that returns the default value of an item described programmatically

`<Item>.CalculatedDefaultValue = <SQL expression>`
---

**`<Item>: (Item name)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<SQL expression>: (Character string)`**

SQL expression defining the default value of the item. This expression must not use any other items.
