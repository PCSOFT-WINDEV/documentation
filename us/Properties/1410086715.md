
## AIInputValue (Property)

***In french: IAValeurSaisie***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AIInputValue** property gets and sets the value of the Edit control in an AI Chat control. This value corresponds to the next message that will be processed by the AI model. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AICHAT_AIChat.AIInputValue = "What is the result of 551*87"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the message currently present in the AI Chat control

`<Result> = <AI Chat control>.AIInputValue`
---

**`<Result>: (Character string)`**

Message entered in the AI Chat control. 

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.   


<a name="SYNTAXE2"></a>

### Modifying the message currently present in the AI Chat control

`<AI Chat control>.AIInputValue = <Message>`
---

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.

**`<Message>: (Character string)`**

New message displayed in the Edit control contained in the AI Chat control.
