
## AISystemPrompt (Property)

***In french: IAPromptSystème***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AISystempPrompt** property gets and sets the first text sent by the AI Chat control to the AI model to define its role and instructions.                                                                                                                                                                                    
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let Prompt = [
	You are a friendly AI companion named Philo. 
	- The user's name is %1
	- Today's date is %2
	- Answer user questions clearly, concisely and precisely.
]
Prompt = StringBuild(Prompt, NetworkUser(), DateToString(Today()))
AICHAT_AIChat.AISystemPrompt = Prompt
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Getting the system prompt used for the AI model

`<Result> = <AI Chat control>.AISystemPrompt`
---

**`<Result>: (Character string)`**

System prompt used.  

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.   


<a name="SYNTAXE2"></a>

### Setting the system prompt used for the AI model

`<AI Chat control>.AISystemPrompt = <New caption>`
---

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used.

**`<New caption>: (Character string)`**

New system prompt used.
