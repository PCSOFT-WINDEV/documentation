


## Before (Property)

***In french: Avant***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Before** property replaces or inserts a procedure before the other procedures in: 

- a variable of type [Procedure](../Motscles/1000018907.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an event associated with a control.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
p is Procedure
p = MyProcedure
p.After = MyProcedureCalledAfter
p.Before = MyProcedureCalledBefore

// The order for calling the procedures will be:
// - MyProcedureCalledBefore
// - MyProcedure
// - MyProcedureCalledAfter
p()
```


<a name="Exemple2"></a>
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) 
```wl
// Specify the event to run on a click
BTN_BUTTON1.Process[trtClick] = myProcedure1

// Add a procedure to run on a click
BTN_BUTTON1.Process[trtClick] += myProcedure2

// Add a procedure to run before the click process
BTN_BUTTON1.Process[trtClick].Before += myProcedure3
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Replacing existing procedures with the Before property (= operator)

`<Element>.Before = <WLanguage procedure>`
---

**`<Element>: (Character string)`**

Element to use: 

- Name of a variable of type [Procedure](../Motscles/1000018907.md). 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Event of a control. The events of a control can be handled with the [Process](../Proprietes/1000020878.md) property. 




**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure that will replace the existing procedures. 


<a name="SYNTAXE2"></a>

### Inserting a procedure before the existing procedures (+= operator)

`<Element>.Before += <WLanguage procedure>`
---

**`<Element>: (Character string)`**

Element to use: 

- Name of a variable of type [Procedure](../Motscles/1000018907.md). 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Event of a control. The events of a control can be handled with the [Process](../Proprietes/1000020878.md) property.




**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure to be inserted before the current procedure.

## Remarks


### Exiting a sequence of procedures
<a name="exiting_sequence_procedures_ELTPARAGRAPHE000106"></a>

If several procedures are executed in a sequence, this sequence can be interrupted from the code of one of the procedures using [SetFocusAndReturnToUserInput](../WDLang1/1410088107.md). 

Example: 


```wl
// Click on BTN_Button1
BTN_Button2.Process[trtClick].Before += MyProc1
BTN_Button2.Process[trtClick].Before += MyProc2
```



```wl
// Click on BTN_Button2
Trace("Button 2 clicked")
```



```wl
PROCEDURE MyProc1()
Trace(dbgInfo(dbgProcess))
SetFocusAndReturnToUserInput(MySelf.Name)
```



```wl
PROCEDURE MyProc2()
Trace(dbgInfo(dbgProcess))
```
