


## LogDirectory (Property)

***In french: RépertoireJournalOperation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LogDirectory** property is used to manage the directory of the log file described in the analysis. You can:

- Find out the directory of the log for a data file defined in the data model editor or programmatically.

- Define the log directory of a data file (only when the file is described through programming).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the log directory of the Orders data file defined programmatically
Orders.LogDirectory = "C:\MyFiles\MyLogs"
...
// Validate the data file description
HDescribeFile(Orders)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Finding out the log directory of a data file

`<Current name> = <Data file>.LogDirectory`
---

**`<Current name>: (Character string)`**



- Name of the directory of the log file associated with the data file, 

- "." if the directory corresponds to the current directory of the data files.




**`<Data file>: (Character string)`**

Logical name of the data file used. This name is defined in the data model editor or with the [File Description](../WDLang4/1514065.md) type.  


<a name="SYNTAXE2"></a>

### Defining the directory of the log for a file defined programmatically

`<Data file>.LogDirectory = <New name>`
---

**`<Data file>: (Character string)`**

Logical name of the data file used. This name is defined with the [File Description](../WDLang4/1514065.md) type.

**`<New name>: (Character string)`**

Name of the log directory.
