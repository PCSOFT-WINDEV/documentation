
## Depth (Property)

***In french: Profondeur***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Depth** property gets the depth of an element. This property can be used on:

- a variable of type [xmlReader](../WDLang5/1000023392.md).

- a variable of type [jsonReader](../WDLang1/1410090783.md).
