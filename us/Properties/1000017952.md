


## Longitude (Property)

***In french: Longitude***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Longitude** property gets and sets the longitude of an element. This property can be used on:

- a variable of type [gglCoordinate](../WDLang5/1000017489.md).

- a variable of type [gglMarker](../WDLang5/1000017442.md).

- a variable of type [geoPosition](../WDLang3/1000019191.md).

- a variable of type [PointGeo](../WDLang4/1410090102.md).
