
## SubCaption (Property)

***In french: SousLibellé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **SubCaption** property gets and sets the secondary caption of: 

- an option in a Radio Button or Check Box control. For more details, see [SubCaption](../Proprietes/1000017232.md). 

- an element of a TreeMap control. For more details, see [SubCaption](../Proprietes/1000017232.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [QuickAction](../WDLang3/1410090054.md).
