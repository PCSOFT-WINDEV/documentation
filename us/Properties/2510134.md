


## ReturnedValue (Property)

***In french: ValeurRenvoyée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ReturnedValue** property is used to:

- Get and change the value returned by a window, page or report.

- Get and change the value returned by an option in a Radio Button control. 




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Reminder** A window opened by function [Opens](../WDLang1/3038035.md) can return a result when closed. This value is returned:

- by the [Result](../Motscles/1510007.md) keyword in the window closing code,

- by the [Closes](../WDLang1/3038018.md) function,
	**Note** The [Closes](../WDLang1/3038018.md) function can be used to return several values.

- by the **ReturnedValue** property used before closing the window.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Reminder** A page opened by function [PageDisplayDialog](../WDLang2/1000017124.md) may return a result when closed. This value is returned:

- by the [Result](../Motscles/1510007.md) keyword in the page closing code,

- by the [PageCloseDialog](../WDLang2/1000017166.md) function,

- by the **ReturnedValue** property used before closing the page,

- by the [ContextClose](../WDLang2/3058003.md) function.


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) Used on the [MyChildWindow](../Motscles/1511021.md) keyword, the **ReturnedValue** property is used to get the value returned by a child window in a mobile application.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png) **Reminder** A report printed by function [iPrintReport](../WDLang5/3046032.md) can return a result at the end of its printing. This value is returned:

- by the [Result](../Motscles/1510007.md) keyword in the report closing code,

- by the **ReturnedValue** property used before closing the report.




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The **ReturnedValue** property gets and sets the value returned by a popup in a Combo Box Popup control.

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) 
```wl
// Code used to open the "WIN_EditPassword" window
MyPassword = Open(WIN_EditPassword)
IF MyPassword <> "" THEN
	Info("Wrong password")
END

// --------------------------------------------------------------------------------
// -- Click code on the "OK" Button control in "WIN_EditPassword"
// The user types his password in the "EDT_Password" control
// and validates the window
Close()

// --------------------------------------------------------------------------------

// -- Closing code of the window
WIN_EditPassword.ReturnedValue = EDT_Password
```

## Syntax

### Finding out the returned value

`<Result> = <Element used>.ReturnedValue`
---

**`<Result>: (Any type)`**

Value that will be returned:

- when closing the current window, page or report.

- if the option is selected in the radio button.




**`<Element used>: (Name of window, page, report, option)`**

Name of element used:

- Name of the window, page, report or internal report used. This window, page or report must be opened.

- Name of the option in the radio button. This name is of the form: &lt;Selector Field&gt;[&lt;Option Number&gt;].  





<a name="SYNTAXE2"></a>

### Modifying the returned value 

`<Element used>.ReturnedValue = <New value>`
---

**`<Element used>: (Name of window, page, report, option)`**

Name of element used:

- Name of the window, page or report used. This window, page or report must be opened.

- Name of the option in the radio button. This name has the following format: &lt;Radio Button control&gt;[&lt;Option number&gt;].




**`<New value>: (Any type)`**

New value to return. The following types can be used:

- structure 

- dynamic structure

- class

- advanced type

- array

- associative array

- queue

- stack

- list

### Finding out the value returned by a child window
<a name="finding_out_the_value_returned_child_window_ELTPARAGRAPHE000194"></a>

In the mobile applications, the windows are opened by [OpenMobileWindow](../WDLang1/1000021018.md) (or [OpenChild](../WDLang1/3038021.md)) instead of [Opens](../WDLang1/3038035.md). 

You can get the value returned by a child window in the "Close a child window" event of the window that opened it (the one that called [OpenMobileWindow](../WDLang1/1000021018.md) or [OpenChild](../WDLang1/3038021.md)).

For example:

- In the closing code of the child window, [Closes](../WDLang1/3038018.md) is used to return a parameter: 
	
	```wl
	Close("", MyParameter)
	```


- The name of the child window as well as the returned value can be retrieved in the "Close a child window" event of the calling window, using the [MyChildWindow](../Motscles/1511021.md) keyword: 
	
	```wl
	// Close a child window
	NameChildWindow = MyChildWindow.Name
	ValueChildWindow = MyChildWindow.ReturnedValue
	```
