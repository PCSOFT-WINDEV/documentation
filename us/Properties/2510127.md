


## StoredValue (Property)

***In french: ValeurMémorisée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **StoredValue** property is used to get the value currently stored by: 

- a row in a List Box, ListView or Combo Box control. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a "Text token" Edit control.

- a row of a Table control. 

- an input suggestion in an Edit control (if the suggestion is selected). 




The currently stored value can correspond to:

- **for List, List Box control and Combo fields linked to a data file** for List, Image List and Combo fields linked to a data file: to the value of the stored item defined in the window editor ("Contents" tab of the field description): <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=rubriquememorisee.gif)
. 

- **for List, Image List and Combo Box control fields by programming** to the value defined in programming by function [gStoredValue](../WDLang1/1410088363.md).
	Reminder: To activate the retrieval of the value defined by function [gStoredValue](../WDLang1/1410088363.md):

	- use the [gStoredValueEnable](../WDLang1/1410088364.md) function.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) check "Return value specified with gStoredValue" ("Details" tab of the control description). 


 **Note** This property can be used, for example, to retrieve stored values from a multi-selection List Box control.

- **for "Text tokens" type Edit control fields** token value. 

- **for a line in a programmatically populated Table field** to the stored value of the line. For this type of control, you can also assign the stored value of the row. 

- **for a row of a Table control based on a variable**, populated by an array of structures: a structure of the array. 

- **for an Edit control assisted input line** the stored value associated with the line. This value is defined when the suggestion is added with the [AssistedInputAdd](../WDLang1/1000020043.md) function, or with a variable of type [AssistedInput](../WDLang1/1410088983.md).

## Example


```wl
// Values selected in a multi-selection List Box control
i is int = 1
iSelectedRow is int
iSelectedRow = ListSelect(LIST_Cedex, 1)
WHILE iSelectedRow <> -1
	Trace(LIST_Cedex[iSelectedRow].StoredValue)
	i++
	iSelectedRow = ListSelect(LIST_Cedex, i)
END
```


<a name="Exemple2"></a>

```wl
// Get the stored value when selecting the 3rd element of the List Box control
Info("The stored value is " + LIST_Cedex[3].StoredValue)
```


## Syntax

### Getting the stored value of a List Box, ListView or Combo Box control

`<Stored value> = <Control used>[<Element index>].StoredValue`
---

**`<Stored value>: (Character string)`**

Value that will be stored if the user selects the element in the specified control.

**`<Control used>: (Control name)`**

Name of the List Box, ListView or Combo Box control to use.

**`<Element index>: (Integer)`**

Index of the element in the control (List Box, ListView or Combo Box) whose stored value you want to get.  


<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
### Getting the value stored in a "Text token" Edit control

`<Stored value> = <Edit control>.StoredValue`
---

**`<Stored value>: (Character string)`**

Stored value. If the control has several tokens, this parameter will have the following syntax: 

```txt
<Token Value 1> + CR + ... + <Token Value N>
```


**`<Edit control>: (Control name)`**

Name of the "Text token" Edit control to use. 


<a name="SYNTAXE3"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available in browser code
### Getting the stored value of a row of a Table control

`<Stored value> = <Table control>[<Row index>].StoredValue`
---

**`<Stored value>: (Character string)`**

Stored value for the row. 

**`<Table control>: (Control name)`**

Name of the Table control to be used. 

**`<Row index>: (Integer)`**

Index of the row whose value you want to get.  


<a name="SYNTAXE4"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Not available in browser code
### Getting the stored value of an input suggestion

`<Stored value> = <Element>.StoredValue`
---

**`<Stored value>: (Character string)`**

Stored value for the row. 

**`<Element>: (AssistedInput variable or control name)`**



- [AssistedInput](../WDLang1/1410088983.md) variable containing the characteristics of the selected row. 
	When used in the "Select a value in the list of input suggestions" event, this variable contains the characteristics of the selected suggestion.

- Name of the Edit control in which the row was selected.

## Remarks


### Limitations
<a name="limitations_ELTPARAGRAPHE000194"></a>

The **StoredValue** property applies only to: 

- List Box, ListView and Combo Box controls.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Text token" Edit controls. 

- Edit controls with input suggestions. 

- the Table controls.




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The **StoredValue** property applies only to: 

- List Box and Combo Box controls.

- Edit controls with input suggestions. 




![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The **StoredValue** property can only be used with the following elements:

- Combo Box controls and rows of Combo Box controls.

- ListView controls and rows of ListView controls.

- Group of controls.


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The **StoredValue** property can only be used with the following elements: 

- Combo Box controls and rows of Combo Box controls.

- ListView controls and rows of ListView controls.


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The **StoredValue** property applies only to: 

- List Box controls.

- Edit controls with input suggestions.
