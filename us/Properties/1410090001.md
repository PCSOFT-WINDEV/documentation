
## LeftButton (Property)

***In french: BoutonGauche***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **LeftButton** property gets and sets the characteristics of a button located on the left side of an Edit control. This button corresponds to a clickable image. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
EDT_Edit.LeftButton.Image = IMG_Plus
EDT_Edit.LeftButton.NbState = 5
EDT_Edit.LeftButton.Monochrome = False
EDT_Edit.Process[trtClickButtonEditControlLeft] = MyProcedure
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the characteristics of a button on the left of an Edit control

`<Result>=<Edit control>.LeftButton.<Property name>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<Edit control>: (Control name)`**

Name of the Edit control used. 

**`<Property name>: ()`**

Name of the applied property: 


| Property | Type | Description |
| --- | --- | --- |
| *Height* | Integer | Height of the clickable image in the input area, expressed in pixels. |
| *Image* | String, memo | Image used as the button in the input area. |
| *Margin.Bottom* | Integer | Bottom margin of the clickable image, expressed in pixels. |
| *Margin.Left* | Integer | Left margin of the clickable image, expressed in pixels. |
| *Margin.Right* | Integer | Right margin of the clickable image, expressed in pixels. |
| *Margin.Top* | Integer | Top margin of the clickable image, expressed in pixels. |
| *Margin.Value* | Integer | <br><br>- Value of the top, bottom, right and left margins expressed in pixels, if these values are the same, <br><br>- -1 if the margins are not identical. <br><br><br> |
| *Monochrome* | Boolean | <br><br>-  if the image must be monochrome,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *NbState* | Integer | Number of image states. |
| *Visible* | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the clickable image is visible at runtime,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *Width* | Integer | Width of the clickable image in the input area, expressed in pixels. |



<a name="SYNTAXE2"></a>

### Setting the characteristics of a button on the left of an Edit control

`<Control used>.LeftButton.<Property name> = <New value>`
---

**`<Control used>: (Control name)`**

Name of the control used. 

**`<Property name>: ()`**

Name of the property to be applied: 


| Property | Type | Description |
| --- | --- | --- |
| *Height* | Integer | Height of the clickable image in the input area, expressed in pixels. |
| *Image* | String, memo | Path to the image used as button in the input area. |
| *Margin.Bottom* | Integer | Bottom margin of the clickable image, expressed in pixels. |
| *Margin.Left* | Integer | Left margin of the clickable image, expressed in pixels. |
| *Margin.Right* | Integer | Right margin of the clickable image, expressed in pixels. |
| *Margin.Top* | Integer | Top margin of the clickable image, expressed in pixels. |
| *Margin.Value* | Integer | Value of the top, bottom, right and left margins, expressed in pixels. Sets all margin properties if the values are the same. |
| *Monochrome* | Boolean | <br><br>-  if the image must be monochrome,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *NbState* | Integer | Number of image states. |
| *Visible* | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the clickable image is visible at runtime,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br> |
| *Width* | Integer | Width of the clickable image in the input area, expressed in pixels. |



**`<New value>: (Type corresponding to the property)`**

New value for the property.

## Remarks


### Associating WLanguage code with the left button
<a name="associating_wlanguage_code_with_the_left_button_ELTPARAGRAPHE000218"></a>

To associate WLanguage code with the button located on the left of an Edit control , simply use the [Process](../Proprietes/1000020878.md) property with the *trtClickButtonEditControlLeft* constant.
