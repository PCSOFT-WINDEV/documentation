


## Numerical (Property)

***In french: Numerical***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Property **Numeric** property indicates whether a field is of the numeric type. **This property is read-only**.

**Note** The following fields are considered to be numeric fields:

- int,

- real, 

- currency, etc 

- numeric, 

- boolean.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Is the Customer.Phone item a numeric item?
ResNum = Customer.Phone.Numerical
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Data file>.<Item>.Numerical`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the item is numeric, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Data file>: (Character string)`**

Logical name of the data file used.

**`<Item>: (Character string)`**

Name of the item used.
