
## ProcedureHeader (Property)

***In french: ProcédureEntête***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **ProcedureHeader** property defines the procedure called to read headers in the event of a successful HTTP request. This procedure can be used when the server returns a chunked or a large response.

This property can be used on:

- a variable of type [httpRequest](../WDLang3/1000021158.md).

- a variable of type [restRequest](../WDLang3/1000021481.md).
