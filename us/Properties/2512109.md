


## VisibleEndUser (Property)

***In french: VisibleUtilisateurFinal***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **VisibleEndUser** property is used to:

- Find out whether an item is visible (or not) to the end users. This item was defined in the data model editor or programmatically.

- Define if an item must be visible to the end users (only for items defined programmatically).




When the item is visible to the end users:

- this item can be accessed in [Reports & Queries](../Presentation/3088003.md). The end users will be able to use this item in their own custom reports and queries.

- the values of this item can be modified in the different [HFSQL windows for automatic assistance](../WDLang4/3044188.md) (if a duplicate error occurs for example). 




**Remark**: The visibility of a field is defined in the editor when describing the fields in a file (option "Visible to the end user in "Reports and Queries"" in the "Reports and Queries" tab of the field description window).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the visibility of the Orders.OrdDate item
OrdDate.VisibleEndUser = True
...
// Validate the data file description
HDescribeFile(Orders)
```

## Syntax

### Finding out whether an item is visible to the end user

`<Résultat> = <Fichier de données>.<Rubrique>.VisibleFinalUser`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the item is visible to end users, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Data file>: (Character string)`**

Name of the data file used.

**`<Item>: (Character string)`**

Name of the item used.  


<a name="SYNTAXE2"></a>

### Defining the visibility of an item described programmatically

`<Item>.VisibleEndUser = <Visibility>`
---

**`<Item>: (Character string)`**

Name of the item used. This name is defined with the [Item Description](../WDLang4/1514071.md) type.

**`<Visibility>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the item is to be visible to end users, 

- <u><u><u><u>False</u></u></u></u> otherwise.
