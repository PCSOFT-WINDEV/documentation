
## FlexAlignContent (Property)

***In french: FlexAlignContent***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FlexAlignContent** property gets and sets the alignment of the lines within the Flexbox control along the cross axis (corresponding CSS property: "align-content"). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Flexbox control characteristics
FLEX_MyFlexbox.FlexDirection = fbdColumn
FLEX_MyFlexbox.FlexWrap = fbwWrap
FLEX_MyFlexbox.FlexJustifyContent = fbjcCenter
FLEX_MyFlexbox.FlexAlignContent = fbacEnd
FLEX_MyFlexbox.FlexAlignItems = fbaiCenter
FLEX_MyFlexbox.FlexColumnGap = 5
FLEX_MyFlexbox.FlexRowGap = 50
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the alignment of lines in the Flexbox control

`<Result> = <Control used>.FlexAlignContent`
---

**`<Result>: (Integer constant)`**

Alignments of lines in the Flexbox control: 



|   |   |
| --- | --- |
| *fbacCenter* | Items of all the lines are centered along the cross axis, taking into account the total height or width of the lines. |
| *fbacEnd* | Depending on the direction of the Flexbox control: <br><br>- items in the last line (N) are aligned to the bottom or right edge of the Flexbox control.<br><br>- items in the second to last line (N-1) are aligned to the top or left edge of the items in the last line (N), etc.<br><br><br> |
| *fbacSpaceAround* | Items in each line are distributed from start to end along the cross axis. Items in each line are distributed with equal space around them, taking into account both the other items and the edges of the Flexbox control. |
| *fbacSpaceBetween* | Depending on the direction of the Flexbox control: <br><br>- items in the first line are aligned to the top or left edge of the Flexbox control.<br><br>- items in the last line (N) are aligned to the bottom or right edge of the Flexbox control.<br><br><br>Items in the inner lines are aligned and distributed at equal distance from the items in the first and last line. |
| *fbacStart* | Depending on the direction of the Flexbox control: <br><br>- items in the first line are aligned to the top or left edge of the Flexbox control.<br><br>- items in the second line are aligned to the bottom or right edge of the items in the first line, etc.<br><br><br> |
| *fbacStretch* | Items will stretch horizontally and vertically to take up the remaining space in the Flexbox control. This is the default value ("undefined"). |



**`<Control used>: (Control name)`**

Name of the Flexbox control used. 


<a name="SYNTAXE2"></a>

### Setting the alignment of lines in the Flexbox control

`<Control used>.FlexAlignContent = <New alignment>`
---

**`<Control used>: (Control name)`**

Name of the Flexbox control used. 

**`<New alignment>: (Integer constant)`**

New alignment: 



|   |   |
| --- | --- |
| *fbacCenter* | Items of all the lines are centered along the cross axis, taking into account the total height or width of the lines. |
| *fbacEnd* | Depending on the direction of the Flexbox control: <br><br>- items in the last line (N) are aligned to the bottom or right edge of the Flexbox control.<br><br>- items in the second to last line (N-1) are aligned to the top or left edge of the items in the last line (N), etc.<br><br><br> |
| *fbacSpaceAround* | Items in each line are distributed from start to end along the cross axis. Items in each line are distributed with equal space around them, taking into account both the other items and the edges of the Flexbox control. |
| *fbacSpaceBetween* | Depending on the direction of the Flexbox control: <br><br>- items in the first line are aligned to the top or left edge of the Flexbox control.<br><br>- items in the last line (N) are aligned to the bottom or right edge of the Flexbox control.<br><br><br>Items in the inner lines are aligned and distributed at equal distance from the items in the first and last line. |
| *fbacStart* | Depending on the direction of the Flexbox control: <br><br>- items in the first line are aligned to the top or left edge of the Flexbox control.<br><br>- items in the second line are aligned to the bottom or right edge of the items in the first line, etc.<br><br><br> |
| *fbacStretch* | Items will stretch horizontally and vertically to take up the remaining space in the Flexbox control. This is the default value ("undefined"). |
