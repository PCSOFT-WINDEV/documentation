
## MandatoryInput (Property)

***In french: SaisieObligatoire***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MandatoryInput** property is used to determine if a control is required and to enable or disable the required data input. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF m_bCriticalAccount THEN
	EDT_Password.MandatoryInput = invalidInputBlocking
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Determining if the required data input is enabled or disabled on a control

`<Result> = <Control used>.MandatoryInput`
---

**`<Result>: ()`**

Required input behavior: 



|   |   |
| --- | --- |
| *invalidInputBlocking* | Required input verification is enabled and prevents users from leaving the control if they haven't entered any data. <br><br>The control will throw errors in the following cases: <br><br>- Edit control: Error if the control is empty. <br><br>- Editable Combo Box control: Error if the control is empty. <br><br>- Non-editable Combo Box control: Error if no row is selected. <br><br>- Check Box control: Error if no option is checked. <br><br>- Radio Button control: Error if no option is checked. <br><br>- Ranking control: Error if no stars are displayed. <br><br><br> |
| *invalidInputNonBlocking* | Required input verification is enabled, but allows users to leave the control, even if they haven't entered enter any data. |
| *invalidInputNone* | Required input verification is not enabled. |



**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- an Edit control, 

- a Check Box control, 

- a Radio Button control, 

- a Combo Box control, 

- a Rating control. 





<a name="SYNTAXE2"></a>

### Enabling or disabling required input in a control

`<Control used>.MandatoryInput = <Required input>`
---

**`<Control used>: (Control name)`**

Name of the control used. This control can be: 

- an Edit control, 

- a Check Box control, 

- a Radio Button control, 

- a Combo Box control, 

- a Rating control. 




**`<Required input>: (Integer constant)`**

New required input verification mode: 



|   |   |
| --- | --- |
| *invalidInputBlocking* | Required input verification is enabled and prevents users from leaving the control if they haven't entered any data. <br><br>The control will throw errors in the following cases: <br><br>- Edit control: Error if the control is empty. <br><br>- Editable Combo Box control: Error if the control is empty. <br><br>- Non-editable Combo Box control: Error if no row is selected. <br><br>- Check Box control: Error if no option is checked. <br><br>- Radio Button control: Error if no option is checked. <br><br>- Ranking control: Error if no stars are displayed. <br><br><br> |
| *invalidInputNonBlocking* | Required input verification is enabled, but allows users to leave the control, even if they haven't entered enter any data. |
| *invalidInputNone* | Required input verification is not enabled. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Until version 2024, the **MandatoryInput** property could only be used to determine whether input was required (True) or optional (False). It is now possible to determine whether or not a control with required input prevents users from leaving.
