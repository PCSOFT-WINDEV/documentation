
## AIConversation (Property)

***In french: AIConversation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **AIConversation** property gets different details of the current conversation in an AI Chat control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF AICHAT_MyAIChat.AIConversation.RequestInProgress THEN
   IMG_ProgressBar.Visible = True
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the details of a conversation in an AI Chat control

`<Result> = <AI Chat control>.AIConversation.<Property name>`
---

**`<Result>: (Type corresponding to the property)`**

Result corresponding to the property used. 

**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used. 

**`<Property name>: (Character string)`**

Properties used: 


| Property name | Type used | Effect |
| --- | --- | --- |
| Element | Array of [aiConversationElement](../WDLang1/1410091337.md) | Array of AI conversation elements: Sequence of questions and answers, in order. <br><br>The first element of the array corresponds to the system prompt. |
| Name | Character string | Conversation name |
| RequestInProgress | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if a request to the AI model is in progress. An animation is then displayed in the AI Chat control. <br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br><br><br>**This property is read-only**. |
| TokenCount | Integer | Number of tokens used by the conversation. <br><br>**This property is read-only**. |
