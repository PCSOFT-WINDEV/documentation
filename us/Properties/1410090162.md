
## Effect (Property)

***In french: Effect***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Effect** property gets and sets the effect applied to the controls. 

This property is available:

- to define the effect that will be used to highlight the target controls of a Guided Tour step. This property can be used on:

	- a variable of type [GuidedTour](../WDLang6/1410090170.md).

	- a variable of type [GuidedTourStep](../WDLang6/1410090178.md).




- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) to get and set the blurring characteristics of a control. For more details, see the help on the [Effect](../Proprietes/1410090859.md) property.
