
## BackgroundPattern (Property)

***In french: TrameFond***
	

<DIV class="specObsolete">

	From version <B>27</B>, ***BackgroundFrame*</**>** is kept for backward compatibility. This property has been replaced with ***BackgroundPattern*</**>**.

<a name="Utilisation"></a>
<a name="description"></a>
The **BackgroundPattern** property gets and sets the background pattern of an element. This property can be used on:

- [docCell](../WDLang1/1000022927.md) variables.

- [docFragment](../WDLang1/1000022482.md) variables.

- [docParagraph](../WDLang1/1000022483.md) variables.

- [docNumberingLevel](../WDLang1/1000022799.md) variables.
