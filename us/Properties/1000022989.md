
## PrivateKey (Property)

***In french: CléPrivée***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PrivateKey** property manages connections that use private keys (SSH or MQTT connections). This property can be used on: 

- a variable of type [sshSession](../WDLang3/1000021157.md). 

- a variable of type [mqttSession](../WDLang3/1000023023.md).
