
## Sound

***In french: Son***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Sound** keyword can correspond to:

- the **[Sound](../WDLang1/3013047.md)** function, which is used to play Wav audio files.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the **Sound** property, which can be used on a variable of type [Notification](../WDLang3/1000019441.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) the **Sound** property, which can be used on a variable of type [notificationCategory](../WDLang3/1000023981.md).
