
## CaptionHTML (Property)

***In french: LibelléHTML***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **CaptionHTML** property is used to manipulate text as HTML code. This property can be used on:

- the controls of a page. For more details, see the help on the [CaptionHTML](../Proprietes/1000020922.md) property.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) a variable of type [Token](../WDLang1/1000023942.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [diagText](../WDLang1/1410088393.md).
