
## Order (Property)

***In french: Order***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Order** property gets and sets the order of a list of elements. This property can be used: 

- on a variable of type [Appointment](../WDLang1/1000019244.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) on a variable of type [QuickAction](../WDLang3/1410090054.md).
