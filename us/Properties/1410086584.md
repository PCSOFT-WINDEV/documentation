
## Compile

***In french: Compile***
	



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **Compile** keyword can correspond to:

- the **[Compile](../WDLang1/3013015.md)** function, which dynamically compiles a procedure whose source code is specified.. 

- \* the **&lt;COMPILE IF&gt;** statement, which allows you to compile WLanguage code according to a condition (mainly used to compile code according to a platform or configuration type).
