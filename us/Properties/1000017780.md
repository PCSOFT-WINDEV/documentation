


## Image (Keyword)

***In french: Image***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Image** keyword can correspond to: 

- a variable of type [Image](../WDLang1/1000019650.md). 

- the **Image** property gets and sets the image of an element. This property can be used on:

	- a control. For more details, see [Image property on controls](../Proprietes/2510034.md).

	- a variable of type [EventTimeline](../WDLang1/1000020612.md).

	- a variable of type [Marker](../WDLang3/1000019940.md).

	- a variable of type [Appointment](../WDLang1/1000019244.md).

	- a variable of type [rssChannel](../WDLang5/1000017769.md).

	- a variable of type [rssStream](../WDLang5/1000017795.md).

	- a variable of type [OrgElement](../WDLang1/1000019713.md).

	- a variable of type [Icon](../WDLang1/1000020811.md).

	- a variable of type [Tiff](../WDLang1/1000021025.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [GanttTask](../WDLang1/1000020881.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a variable of type [upnpImage](../WDLang3/1000020905.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [pdfSignature](../WDLang6/1000022255.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [docElement](../WDLang1/1000022484.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [WDPic](../WDLang1/1000023503.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) a variable of type [BarCode](../WDLang5/1000019451.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [picLayer](../WDLang1/1000024604.md).

	- a variable of type [MapImage](../WDLang3/1000025523.md).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) the [LeftButton](../Proprietes/1410090001.md) property of an Edit control.
