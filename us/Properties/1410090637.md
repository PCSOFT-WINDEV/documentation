
## PaneVisibleByDefault (Property)

***In french: VoletVisibleParDéfaut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **PaneVisibleByDefault** property determines if the image editor pane is visible by default. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Champ_Editeur_img_reglages%20-%20HC%20N%B0002%201.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Do not display the pane when the Image Editor control is opened
IE_Editor.PaneVisibleByDefault = False
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Determining if the pane of the Image Editor control is visible by default

`<Result> = <Image Editor control>.PaneVisibleByDefault`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the pane is visible by default,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Image Editor control>: (Control name)`**

Name of the Image Editor control to be used.  


<a name="SYNTAXE2"></a>

### Showing or hiding the pane of the Image Editor control by default

`<Image Editor control>.PaneVisibleByDefault = <Visibility>`
---

**`<Image Editor control>: (Control name)`**

Name of the Image Editor control to be used.

**`<Visibility>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the pane should be visible by default,

- <u><u><u><u>False</u></u></u></u> if the pane should be invisible by default.
