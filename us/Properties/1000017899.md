
## Enabled (Property)

***In french: Activé***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Enabled** property enables or disables an element. This property can be used on:

- a variable of type [hBackupDescription](../WDLang4/1000017455.md).

- a variable of type [hScheduledOptimization](../WDLang4/1000018854.md). 

- a variable of type [InfoVersion](../WDLang1/1000018905.md).

- a variable of type [gpwUser](../WDLang6/1000021088.md).

- a variable of type [hScheduledTask](../WDLang4/1000017448.md).

- a variable of type [hScheduleMaterializedView](../WDLang4/1000021444.md). 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [appServerScheduledTask](../WDLang2/1000022367.md).
