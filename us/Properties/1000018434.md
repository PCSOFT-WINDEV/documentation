
## FullName (Property)

***In french: NomComplet***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **FullName** property gets the full name of an element. This property can be used on:

- a control, window or menu option. For more details, see [FullName](../Proprietes/2514005.md).

- a variable of type [sfUserInfo](../WDLang5/1000018423.md).
