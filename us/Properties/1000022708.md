
## MaxSize (Property)

***In french: TailleMax***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **MaxSize** property is used to get and set a maximum size. This property is available for: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) a variable of type [nfcTag](../WDLang3/1000020411.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a variable of type [mongoCollectionOption](../WDLang4/1000022413.md).
