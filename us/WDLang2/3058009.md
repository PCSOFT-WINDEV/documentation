


## CurrentPage (Function)

***In french: PageCourante***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of the page containing the WLanguage code currently run.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Str is string
Str = CurrentPage()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = CurrentPage()`
---

**`<Result>: (Character string)`**




|   |   |
| --- | --- |
| Name of the current page in uppercase | If the WLanguage code being executed is:<br><br>- an event associated with the page: <br><br>	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Global declarations" event,<br><br>	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Initialization" event of the page,<br><br>	- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) "Load" event of the page,<br><br>	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) "Closing" or "Unload" event of the page,<br><br>	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Synchronization" event.<br><br><br><br><br>- an event associated with a control (initializing, click).<br><br>- a procedure local to the page.<br><br><br> |
| Empty string ("") | If the code being executed is:<br><br>- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) an event associated with the project<br><br>- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a class constructor or destructor code<br><br>- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) a class method<br><br>- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) a procedure global to the project.<br><br><br> |

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The case of the page name corresponds to the real case of the page name. For example, if the current page corresponds to the "Home.WWH" page, the name returned will be "Home".
