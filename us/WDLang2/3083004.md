


## LooperAddLine (Function)

***In french: ZoneRépétéeAjouteLigne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row at the end of a Looper control. The attributes of the new row may contain tabulations.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Initialize the Looper control named LOOP_LOOPER1 
LooperDeleteAll(LOOP_LOOPER1) 
HReadFirst(Product, ProdName) 
WHILE HOut(Product) = False
	LooperAddLine(LOOP_LOOPER1, Product.ProdName, Product.Code) 
	HReadNext(Product, ProdName) 
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE2"></a>

## Syntax

### Adding a row to a Looper control with attributes

`<Result> = LooperAddLine(<Looper control> [, <Value 1> [... [, <Value N>]]])`
---

**`<Result>: (Integer)`**



- Number of the added row,

- 0 if an error occurs.




**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter is an empty string (""), the row will be added in the current Looper control.

**`<Value 1>: (Type of associated attribute (optional))`**

Value of 1st attribute for the new row. 
The different values must be specified in the order of the attributes (Looper control description window).
If you don't want to specify a value for one of the attributes, use an empty string ("") or 0 (depending on the attribute type).
An empty row will be added if none of these parameters is specified.



**`<Value N>: (Type of associated attribute (optional))`**

Value of Nth attribute for the new row. 
The different values must be specified in the order of the attributes (Looper control description window).
If you don't want to specify a value for one of the attributes, use an empty string ("") or 0 (depending on the attribute type).
An empty row will be added if none of these parameters is specified.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000123"></a>

**LooperAddLine** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **LooperAddLine** can only be used on a Looper control populated programmatically.
<a name="NOTE0_2"></a>


### Adding an empty row
<a name="adding_empty_row_ELTPARAGRAPHE000137"></a>

After adding an empty row, each attribute or control must be initialized individually.

For example:
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) For a Looper control with attributes:

```wl
// Add an empty row
Index = LooperAddLine(LOOP_Looper1)

// Then, initialize the attributes
ATT_AttributeLastName[Index] = "Hobbes"
ATT_AttributeFirstName[Index] = "Samantha"
ATT_ColorAttributeFirstName[Index] = LightRed
ATT_AttributeAddressVisible[Index] = False
```


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) For a Looper control without attributes:

```wl
// Add an empty row
Index = LooperAddLine(LOOP_Looper1)

// Then, initialize the controls
LOOP_Looper1[Index].ControlLastName = "Hobbes"
LOOP_Looper1[Index].ControlFirstName = "Samantha"
LOOP_Looper1[Index].ControlFirstName.BackgroundColor = LightRed
LOOP_Looper1[Index].ControlAddress.Visible = False
```

<a name="NOTE0_3"></a>


### Row characteristics
<a name="row_characteristics_ELTPARAGRAPHE000169"></a>

- If a value is the result of a calculation, enclose the numerical expression in brackets. 
	For example:
	
	```wl
	LooperAddLine(LOOP_CalculationLooper, (53+29), (83-21))
	```


- Formatting attributes (e. g. color) that are not specified in the row display code are automatically reset.



<a name="NOTE0_4"></a>


### Position of the new row
<a name="position_the_new_row_ELTPARAGRAPHE000188"></a>

By default, the row is added at the end of the Looper control.

If the Looper control is sorted ([LooperSort](../WDLang2/3083009.md)), the added row is positioned in the Looper control according to the current sort.
<a name="NOTE0_5"></a>
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 

### Tips
<a name="tips_ELTPARAGRAPHE000204"></a>

- **Optimizing the referencing**: 
	If the Looper control contains an image, add an "Alternative text" attribute. Its value can be defined through programming so that the referencing of your Internet site will be improved.

- **Active WEBDEV Page with a Looper control containing images to display in 100% mode**: 
	In order for the 100% property to be taken into account, a border must be added to the Image control. To avoid displaying this border, the background color of the border must be identical to the background color of the page.
