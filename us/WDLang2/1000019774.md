


## LooperExpandAll (Function)

***In french: ZoneRépétéeDérouleTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Expands all breaks in a Looper control with break. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click the [1.2 stars only] Button control
LooperExpandAll(LOOP_HOTEL)
LooperCollapse(LOOP_HOTEL, nRow3Star)
LooperCollapse(LOOP_HOTEL, nRow4Star)
LooperCollapse(LOOP_HOTEL, nRow5Star)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`LooperExpandAll(<Looper control>)`
---

**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter is equal to an empty string (""), the current Looper control will be used.




## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000048"></a>

**LooperExpandAll** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls.
