
## PageWriteHTTPCode (Function)

***In french: PageEcritCodeHTTP***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Specifies the HTTP code that will be returned to the client after the Server code of the page is executed. This function classifies return codes as follows:

- 2xx codes for **Successful** responses.

- 3xx codes for **Redirections**.

- 4xx codes for **Client errors**.

- 5xx codes for **Server errors**.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
PageWriteHTTPCode(204)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PageWriteHTTPCode(<HTTP code>)`
---

**`<HTTP code>: (Integer)`**

HTTP code returned. The following codes are supported:

- 2xx codes (Successful responses).

- 3xx codes (Redirections).

- 4xx codes (Client errors).

- 5xx codes (Server errors).


For more details, see [Code details](#NOTE0_2).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000046"></a>

The code specified by [PageWriteHTTPCode](../WDLang2/1410090194.md) is ignored:

- In case of error (4xx and 5xx codes) or redirection (3xx codes).

- In an AJAX call.



<a name="NOTE0_2"></a>


### Code details
<a name="code_details_ELTPARAGRAPHE000180"></a>

The HTTP codes currently supported are:

- 1xx codes are not supported




- 2xx codes (Successful responses) from 200 to 207

	- 200 OK

	- 201 Created

	- 202	Accepted

	- 203	Non-Authoritative Information

	- 204 No Content

	- 205 Reset Content

	- 206 Partial Content

	- 207 Multi-Status







- 3xx codes (Redirections) 301 and 302

	- 301	Moved Permanently

	- 302 Found







- 4xx codes (Client errors) from 400 to 451

	- 400 Bad Request

	- 401 Unauthorized

	- 402 Payment Required

	- 403 Forbidden

	- 404 Not Found

	- 405 Method Not Allowed

	- 406 Not Acceptable

	- 407	Proxy Authentication Required

	- 408	Request Time-out

	- 409	Conflict

	- 410 Gone

	- 411	Length Required

	- 412	Precondition Failed

	- 413 Request Entity Too Large

	- 414	Request-URI Too Long

	- 415 Unsupported Media Type

	- 416 Requested range unsatisfiable

	- 417 Expectation failed

	- 421 Bad mapping / Misdirected Request

	- 422 Unprocessable entity

	- 423 Locked

	- 424 Method failure

	- 425 Too Early

	- 426 Upgrade Required

	- 428 Precondition Required

	- 429 Too Many Requests

	- 431 Request Header Fields Too Large

	- 451 Unavailable For Legal Reasons







- 5xx codes (Server errors) from 500 to 511

	- 500 Internal Server Error

	- 501 Not Implemented

	- 502 Bad Gateway or Proxy Error

	- 503 Service Unavailable

	- 504 Gateway Time-out

	- 505 HTTP Version not supported

	- 506 Variant Also Negotiates

	- 507 Insufficient storage

	- 508 Loop detected

	- 510 Not extended

	- 511 Network authentication required
