


## &lt;Looper&gt;.InfoXY (Function)

***In french: &lt;Zone répétée&gt;.InfoXY***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to find out the element located at a given position in the Looper control (X, Y). This element can be: 

- a row,

- a control, 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) a break.




This function can be used on Looper controls based on a data file or populated programmatically.  






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click on the left mouse button
x is int = MouseXPos() 
y is int = MouseYPos() 
nRow is int = LOOP_Looper1.InfoXY(liLineNumber, x, y) 
Trace("You have clicked on the row: " + nRep)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Looper control>.InfoXY(<Type of information> , <X> , <Y>)`
---

**`<Result>: (Character string or integer)`**



- Requested information.

- An empty string ("") if no control is found at specified location.

- -1 if no row number is found at specified location.




**`<Looper control>: (Control name)`**

Name of the Looper control to be used.

**`<Type of information>: (Constant)`**

Type of information requested:


|   |   |
| --- | --- |
| *liBreakName* | Name of the break at (x,y).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *liControlName* | Name of the control found at (x,y). |
| *liLineNumber* | Number of the row found at (x,y). |
| *liOriginScreen* | By default, point (0,0) corresponds to row 1, column 1 (with scrollbars at origin).<br>If the *liOriginScreen* constant is combined with the previous constants, the (0,0) point corresponds to the origin of the screen.<br>This constant cannot be used on its own. |



**`<X>: (Integer)`**

X-coordinate (in pixels) to be analyzed. This coordinate is given in relation to the Looper control (if the *liOriginScreen* constant is not specified).

**`<Y>: (Integer)`**

Y-coordinate (in pixels) to be analyzed. This coordinate is given in relation to the Looper control (if the *liOriginScreen* constant is not specified).
