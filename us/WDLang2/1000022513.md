


## BannerFirst (Function)

***In french: BandeauPremier***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Displays the first plane of a Sliding Banner control.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the first banner
BannerFirst(BAN_Banner)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`BannerFirst(<Sliding Banner control>)`
---

**`<Sliding Banner control>: (Control name)`**

Name of Sliding Banner control to use.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The invisible planes of the Sliding Banner control are ignored.
