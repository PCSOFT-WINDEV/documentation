
## ConfigureAWPContext (Function)

***In french: ConfigureContexteAWP***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Configures the mode of the AWP session. 

For more details on the available modes, see [Managing AWP contexts](../WDChamp/3539060.md). 

**Note**: If **ConfigureAWPContext** is not called, sessions are managed via cookies by default. 

**Note**: This function is intended for developers who are familiar with WEBDEV.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Manage the session of a file on the server
// and transmit the identifier by cookie
ConfigureAWPContext(ctxDisk, ctxIDCookie)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ConfigureAWPContext(<Content storage mode> [, <Identifier transmission mode>])`
---

**`<Content storage mode>: (Integer constant)`**

Mode for storing the content of the session:


|   |   |
| --- | --- |
| *ctxCookie* | The content is transmitted in a cookie (behavior compatible with version 11).<br><br>**Caution**: This constant must not be used to store sensitive data. Indeed, this information is stored "without being encrypted". |
| *ctxDisk* | The content of the session is saved in a file on the server. |



**`<Identifier transmission mode>: (Integer constant (optional))`**

Define the transmission mode of identifier (taken into account only if &lt;Content storage mode&gt; corresponds to the *ctxDisk* constant):


|   |   |
| --- | --- |
| *ctxIDCookie* | The identifier is transmitted by a cookie. |
| *ctxIDCookieURL*<br>(default value) | The identifier is transmitted by cookies. If the cookies do not operate, the identifier is transmitted by the URL. When the session is created, both modes are used, as it is not possible to determine whether cookies will be accepted. |
| *ctxIDUrl* | The identifier is transmitted by the URL. |









<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- It is recommended to use **ConfigureAWPContext** in the "Initialization" event of the project. Indeed, this mode cannot be modified once the session was started.

- **ConfigureAWPContext** is taken into account in AWP mode only.

- If **ConfigureAWPContext** is not called, sessions are managed via cookies by default. 

- **Reminder**: The project initialization process is executed whenever an Active WEBDEV Page is displayed.

- If your project uses pre-launched sessions, this function must not be used in the project initialization event. This function must be used in the "Initialization in pre-launched session mode" event. 

- For more details, see [The dynamic Active WEBDEV Pages](../WDChamp/3539009.md).
