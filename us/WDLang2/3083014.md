


## LooperCount (Function)

***In french: ZoneRépétéeOccurrence***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of rows in a Looper control.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Number of rows found in the "LOOP_Looper1" Looper control?
Result1 is int
Result1 = LooperCount(LOOP_Looper1)
```
<a name="Exemple2"></a>

```wl
// Displays the number of answers found: (e.g. "There are 31 answers")
STC_CAPTION1 = "There are " + LooperCount(LOOP_ResultLooper) + " answers"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = LooperCount(<Looper control> [, <Row/Attribute>])`
---

**`<Result>: (Integer)`**



- Number of rows found in a Looper control,

- 0 if the Looper control is empty.




**`<Looper control>: (Control name)`**

Name of the Looper control to be used.
If this parameter corresponds to an empty string (""), the count will be performed on the current Looper control.

**`<Row/Attribute>: (Optional constant)`**




|   |   |
| --- | --- |
| *toColumn* | Number of attributes found in the Looper control. |
| *toShown*<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Default constant for a Looper control based on a data file. | Number of non-empty visible rows.<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant must not be used:<br><br>- with Looper controls in AJAX mode.<br><br>- with linear Looper controls.<br><br><br><br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *toTotal*<br>(Default value)<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Default constant for a Looper control populated programmatically. | **Looper control based on a data file**:<br><br>- Total number of records:<br><br>	- in the linked data file (if there is no filter). <br><br>	- filtered in the linked data file (if there is a filter).<br><br>	- in the query (if the Looper control is linked to a query).<br><br><br><br><br>- Number of visible records.<br><br><br>**Warning** the "End of initialization" event is only executed when the total has been calculated.<br><br>**Looper control populated programmatically**:<br>Total number of rows added by [LooperAdd](../WDLang2/3083006.md), [LooperAddLine](../WDLang2/3083004.md), [LooperInsert](../WDLang2/3083003.md) or [LooperInsertLine](../WDLang2/3083002.md). |
| *toVisible* | Number of visible rows (including the empty rows or the rows partially displayed). Corresponds to the maximum number of rows that can be displayed in the Looper control.<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant must not be used:<br><br>- with Looper controls in AJAX mode.<br><br>- with linear Looper controls.<br><br><br><br><br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000167"></a>

**LooperCount** can be used on: 

- a Looper control based on a data file, 

- a Looper control populated programmatically. 


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function is not available for Linear Looper controls. This function is available for Looper controls in browser mode only. ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function is available for Looper controls in AJAX mode, Looper controls in classic mode and Linear Looper controls. ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **LooperCount** can only be used on a Looper control populated programmatically.
