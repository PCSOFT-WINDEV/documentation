
## CapsLockVerify (Function)

***In french: CapsLockVérifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the CapsLock key is pressed.

**Warning** This function must only be used in the onkeypress browser code. The check will be performed when the first letter is typed.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays a warning if the CapsLock key is pressed
IF CapsLockVerify() = True THEN Info("The CapsLock key is pressed.")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CapsLockVerify()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the CapsLock key is pressed, 

- <u><u><u><u>False</u></u></u></u> otherwise.
