


## appServerScheduledTask (Variable type)

***In french: serveurAppliTachePlanifiée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **appServerScheduledTask** type is used to manage a scheduled task of WEBDEV Application Server through programming (for a site or a web service).

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Programs the task so that it is run every hour
MyScheduledTask is appServerScheduledTask
MyScheduledTask.Name = "MyTask"
MyScheduledTask.Procedure = MyProc
MyScheduledTask.Month = "*"
MyScheduledTask.DayOfMonth = "*"
MyScheduledTask.DayOfWeek = "*"
MyScheduledTask.Hour = "*"
MyScheduledTask.Minute = "0"

IF NOT AppServerAddScheduledTask(MyScheduledTask) THEN
	// Error case (if a task with the same name already exists for example)
END
```

## Properties


### Properties specific to appServerScheduledTask variables
<a name="properties_specific_appserverscheduledtask_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to handle a scheduled task:

| Property name | Type used | Effect |
| --- | --- | --- |
| DayOfMonth | Character string | Number of the day for which the scheduled task must be run ("31" for example). This number is between 0 and 31.<br><br>This property can also correspond to:<br><br>- a comma-separated list of numbers: to specify several months.<br><br>- an interval. For example, "9-13" (the task is scheduled from the 9th to the 13th of the month).<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step, "\*/2" for example to perform the task on every odd day of the month.<br><br><br> |
| DayOfMonthOrDayOfWeek | Boolean | Managed the execution of a scheduled task by specifying the day number of the week or day number of the month. <br><br>Example: execution every Monday, 1st day of the month.<br><br>This property can correspond to:<br><br>- <u><u><u>True</u></u></u> to run the scheduled task every Monday AND on the first day of the month (cumulative conditions).<br><br>- <u><u><u>False</u></u></u> to perform the task only on Monday 1st (exclusive conditions).<br><br><br> |
| DayOfWeek | Character string | Number of the day for which the scheduled task must be run ("2" for example). This number is included between 1 and 7 (1 = Monday, 2 = Tuesday, ...).<br><br>This property can also correspond to:<br><br>- a comma-separated list of numbers: to specify several days.<br><br>- an interval. For example, "1-3" (the task is scheduled for Monday, Tuesday and Wednesday).<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step, "\*/2" for example to perform the task on every even day of the week.<br><br>- the day of the week in letters ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday").<br><br><br> |
| Enabled | Boolean | Indicates whether the task is enabled or not: <br><br>- <u><u><u>True</u></u></u> if the task scheduling is enabled. <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| Hour | Character string | Execution time of scheduled task. If **TimeUTC** is set to <u><u><u>True</u></u></u>, this time will be in UTC.<br><br>The possible values are:<br><br>- a digit included between 0 and 23.<br><br>- a comma-separated list of numbers: to specify several hours.<br><br>- an interval. For example, "9-13".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step, "\*/2" for example to perform the task at every even hour.<br><br><br> |
| InProgress | Boolean | Indicates whether the task is currently run: <br><br>- <u><u><u>True</u></u></u> if the task is currently run.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>**This property is read-only**.<br><br>This property is updated by [AppServerInfoScheduledTask](../WDLang2/1000022789.md) and [AppServerListScheduledTask](../WDLang2/1000022352.md) only. The value read reflects the status during the call to these functions (and not the status when reading the property). |
| Minute | Character string | Minutes of the execution time of the scheduled task. If **TimeUTC** is set to <u><u><u>True</u></u></u>, this time will be in UTC.<br><br>The possible values are:<br><br>- a digit included between 0 and 59.<br><br>- a comma-separated list of numbers: to specify several minutes.<br><br>- an interval. For example, "9-13".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step, "\*/2" for example to perform the task at every even minute.<br><br><br> |
| Month | Character string | Number of the execution month of scheduled task ("11" for example).<br><br>The possible values are:<br><br>- a digit between 1 and 12<br><br>- a comma-separated list of numbers: to specify several months.<br><br>- an interval. For example, "9-11".<br><br>- a star ("\*") to specify the entire range.<br><br>- an interval with a step, "\*/2" for example to perform the task on every odd month.<br><br><br> |
| Name | Character string | Task name. <br><br>This name is used to differentiate the tasks associated with the same procedure. <br><br>If this property is not set, the task name will correspond to the full name of the Procedure (for example: MyColletion.ProcedureName). |
| Parameter | Array | Parameters that will be transmitted to the scheduled task during its execution. <br><br>Each one of the parameters should be transformed by [Serialize](../WDLang1/3013065.md) (binary serialization is used). The WEBDEV Application Server needs to keep the parameters to pass them at each call. To do so, the value of each parameter will be serialized. <br><br>Note: When the scheduled task is executed, WEBDEV Application Server will automatically transfer the parameters to the Procedure. The same procedure can therefore be associated with multiple scheduled tasks that will pass different parameters. |
| Password | Character string or Secret string | User password.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| Procedure | Procedure name | Procedure that will be run by the scheduled task. This name has the following format:<br><br>- for a procedure in a collection of procedures: &lt;Nom de la collection de procédures&gt;.&lt;Nom de la procédure&gt;.<br><br>- for a Procedure present in a component: &lt;Nom du composant&gt;.&lt;Nom de la collection de procédures&gt;.&lt;Nom de la procédure&gt;.<br><br><br><br><br>This property does not accept:<br><br>- The local procedures. A local procedure only exists in the context of the call to its parent procedure. This context will not exist anymore during the call to the scheduled task.<br><br>- A [Procedure](../Motscles/1000018907.md) variable (except if this one identifies a procedure belonging to a set of procedures).<br><br><br> |
| ProcedureName | Character string | Name of the procedure to be executed. <br><br>This property is read-only and it is used to retrieve the name of the procedure associated with the task (to display it in a specific screen for example). |
| TimeUTC | Boolean | <br><br>- <u><u><u>True</u></u></u> (default value) if the time is in UTC (**Hour** and **Minute** properties). <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| User | Character string | Indicates the user of the operating system who will run the task. If this value is not filled, the user that will be used is the default user of the application (site or web service). |
