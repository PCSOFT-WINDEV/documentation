


## &lt;Popup&gt;.Close (Function)

***In french: &lt;Popup&gt;.Ferme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Hides a Popup control displayed in the page via [&lt;Popup&gt;.Display](../WDLang2/1000021654.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
POPUP_Question.Close()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Popup>.Close()`
---

**`<Popup>: (Control name)`**

Name of the Popup control that will be hidden.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Browsers do not refresh pages in the middle of JavaScript code. [&lt;Popup&gt;.Display](../WDLang2/1000021654.md) and **&lt;Popup&gt;.Close** must be used in different events/processes. If these functions are used in the same process/event, the Popup control is not displayed.
