


## PageAddress (Function)

***In french: PageAdresse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out the Internet address of a page.  

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Returns the address of a WEBDEV page.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Returns the address of the current page.

## Syntax

### Retrieving the address of a page 

`<Result> = PageAddress([<Page> [, <Option>]])`
---

**`<Result>: (ANSI character string)`**

Address of the specified page or empty string ("") if:

- the page does not exist in the project

- the page context is not opened ([ContextOpen](../WDLang2/3058004.md)).




**`<Page>: (Page name)`**

Name of the page whose address must be returned.
If this parameter is not specified or if it corresponds to an empty string (""), the name of the page corresponds to the name of the current page.

**`<Option>: (Optional constant)`**

Type of address to return:


|   |   |
| --- | --- |
| *pdFull* | Full address of the page (HTTP address). |
| *pdFullAuto* | Full address of the page with the protocol used (HTTP or HTTPS). |
| *pdRelative*<br>(Default value) | Address relative to the current domain. |
| *pdSecure* | Full address of the page, secured by SSL (HTTPS address). |

### Retrieving the address of the current page

`<Result> = PageAddress()`
---

**`<Result>: (Unicode string)`**

Full address of the current page.
