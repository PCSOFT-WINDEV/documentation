
## Screen,Current (External language)

***In french: Ecran,Courant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retrieves the name of the control being edited and its index, if necessary.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// In C
CALLWD("Screen,Current");
strcpy(CurrentControl,WDName);
```


<a name="Exemple2"></a>



```txt
// In Pascal
CALLWD('Screen,Current');
CurrentControl:=WdName;
```


<a name="Exemple3"></a>



```txt
// In VB
call CALLWD("Screen,Current")
CurrentControl=WdName
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Screen,Current()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- WdName contains the name of the control. If the control is an indexed control, WdIndex contains the subscript of the control.

- The space characters found at the end of WdName are deleted by default. Space, Yes must be used in order for the space characters not to be deleted from WdName (on 10 characters).
