
## nWDInitProject: Project initialization code
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Use
<a name="use_ELTTEXTE000072"></a>
Run the project initialization code.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Syntax
<a name="syntax_ELTTEXTE000096"></a>

```wl
Int      nWDInitProject(LPCTSTR pszProjectName)
```


**Details of parameters**

**pszProjectName:** *Character string*

Name of the project whose initialization code must be run. Note: Only one project initialization code can be executed in an application.
