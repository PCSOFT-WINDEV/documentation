
## nWDExecuteEx: Execute a WLanguage function
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Use
<a name="use_ELTTEXTE000077"></a>
Runs a WLanguage function by dynamic compilation, without command formatting.

**Note**: this function behaves like the [nWDExecute](../LangageExt/7513015.md) function, but does not interpret the string containing the command. This allow for faster execution of non-formatted commands (commands not containing %s, %d, ...).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Syntax
<a name="syntax_ELTTEXTE000101"></a>

```wl
Int      nWDExecuteEx(LPCTSTR pszCommande);
```


**Details of parameters**

**pszCommand**: 

WLanguage command to run
