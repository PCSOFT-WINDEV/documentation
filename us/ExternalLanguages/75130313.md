
## Table,Insert (External language)

***In french: Table,Insere***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Inserts an element into a table at a given position. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```txt
// En C
APPELWD("Table,Insere,TableProd,10=%s",Ligne);
```


<a name="Exemple2"></a>





```txt
// En Pascal
APPELWD('Table,Insere,TableProd,10='+Ligne);
```


<a name="Exemple3"></a>





```txt
// En VB
call APPELWD("Table,Insere,TableProd,10="+Ligne)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Table,Insert(<Table name> , <Subscript> , <Row value>)`
---

**`<Table name>: (Character string)`**

Name of the table to use.

**`<Subscript>: (Character string)`**

Index of the element in the table.

**`<Row value>: (Character string)`**

Value of the row to insert.

## Remarks


### Notes
<a name="notes_ELTPARAGRAPHE000045"></a>

- After **Table,Insert**, the table is not in edit. To perform an input in the table, you must call [Screen,Input](../LangageExt/75130265.md).

- If the table contains several columns, the columns must be separated by the numeric value of [TAB] (binary code 9):

	- Example in C: 
			
		```txt
		APPELWD("Table,Insere,TabCli,14=DUPOND\tJean");
		```


	- Example in Pascal: 
			
		```txt
		APPELWD('Table,Insere,TabCli,14=DUPOND'+#9+'Jean');
		```


	- Example in VB: 
			
		```txt
		call APPELWD("Table,Insere,TabCli,14=DUPOND"+CHR$(9)+"Jean")
		```







<a name="NOTE0_2"></a>




### File table
<a name="file_table_ELTPARAGRAPHE000073"></a>

- For a table based on a data file, the record is not inserted into the file, you must call [Table,Save](../LangageExt/75130312.md).

- To modify the file associated with a table, don't use the HAdd function: use functions **Table,Insere** and [Table,Save](../LangageExt/75130312.md).
