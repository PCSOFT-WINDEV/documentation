


## Managing HFSQL Client/Server data files
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000272"></a>
The HFSQL Control Center allows you to fully manage HFSQL Client/Server data files.

To display the characteristics of an HFSQL Client/Server data file: 

1. Connect (if necessary) to an HFSQL server. For more details, see [Managing HFSQL Client/Server databases](../CCHF/35400013.md). 

2. Select the name of the HFSQL server in the tree structure. 

3. Select the name of the desired database.

4. Double-click the name of the desired data file.

5. The right section of Control Center displays a tab with the name of the data file. This tab includes: 

	- several tabs used to manage the characteristics of the HFSQL data file. The "Content" tab is displayed by default. 

	- a ribbon used to configure the HFSQL data file. 




<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0002.gif&type=thumb)


**Note**: In the Control Center pane, you can use the context menu of data files to:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0001.gif)


- Optimize and repair the data file. For more details, see [Optimize and repair data files](../CCHF/3540007.md). 

- Close the data file. 

- Change the password of the data file. 

- Delete the data file. 

- Manage the rights on the database.

## Detailed characteristics of an HFSQL Client/Server data file
<a name="detailed_characteristics_hfsql_clientserver_data_file_ELTTEXTE000296"></a>


### "Description" and "Properties" tabs
<a name="description_and_properties_tabs_ELTPARAGRAPHE000048"></a>

The "Description" tab displays the description of the different data file items: 

- The item name,

- The type of the item, 

- The size of the item, 

- The type of key, 

- Whether the item is visible in "Reports & Queries".




Additional information is displayed if necessary.

Note: By default, headings are displayed in logical order.. You can use the alphabetical order if necessary via the HFSQL Control Center options: 

1. Expand the HFSQL Control Center menu (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_Suivi_Configuration%20-%20HC%20N%B0001.gif)). 

2. Select "Options".

3. In the window that appears, select "alphabetical" for the "Item display order" option. 




The "Properties" tab displays the properties of the data file (physical name, format, protection, etc.).
<a name="NOTE2_2"></a>


### "Connections" tab
<a name="connections_tab_ELTPARAGRAPHE000067"></a>

This tab lists the different users connected to the data file.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0005.gif)


The list of active connections contains the following information:

- username,

- computer name,

- name of the application accessing the file, etc.




From this tab, you can:

- Filter connections by machine, user and/or connection.

- Disconnect users. 
	Simply select the user(s) you wish to disconnect, and click "Disconnect selected users".

- Send a message to the users. 
	Simply select the recipients, and click "Send a message to the selected users".




The option "Don't display the connections of HFSQL Control Center (stated on this computer)" is used to only display the connections of users via the applications. 
<a name="NOTE2_3"></a>


### "Locks" tab
<a name="locks_tab_ELTPARAGRAPHE000108"></a>

This tab allows you to manage locks.

The following information is displayed: 

- number of the locked record, 

- name of the locking user,

- name of the locking computer,

- IP address of the locking computer, 

- name of the locking application, 

- lock start date,

- lock duration.



<a name="NOTE2_4"></a>


### "Content" tab
<a name="content_tab_ELTPARAGRAPHE000125"></a>

This tab is used to view the different records found in the data file. 

You can also filter the records displayed using the bar above the table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007.gif)
The filter context menu (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007%201.gif)) includes several options:

- Apply automatically: The filter is automatically applied when you press Enter. If this option is not selected, you must apply the filter by clicking the green check mark on the right of the filter bar. 

- Remove current filter: Clears the filter bar. 

- Copy SQL code: Copies the SQL code matching the filter conditions to the clipboard. 

- Create a query: Opens a "Query" tab with the SQL code corresponding to the entered conditions (same as the "New query" option in the ribbon). 

- Clear filter history: Previously used filters are automatically saved so that they can be quickly reapplied. You can clear the filter history. 




The context menu of the records includes multiple options to: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0009.gif&type=thumb)


- view the record details (select the "View record" option or double-click the row). A window opens allowing you to view and edit the item values. You can use the navigation buttons to quickly view other records in the same window.

- manipulate the selected record: delete, add, modify, etc. The data file is automatically updated. Note: The records can be added and edited directly in the record details window.

- configure the display options.

- filter the current column. 

- print the record. 

- etc.




The ribbon shows certain options specific to the content being displayed:

- Create, edit, view or delete a record. 

- Find a record by number. 

- Search for duplicates in the data file. Simply specify the desired item, the type of comparison and launch the search. The value of each duplicate found and the number of occurrences are displayed. 
	



<a name="NOTE2_6"></a>


### "Logs" tab
<a name="logs_tab_ELTPARAGRAPHE000183"></a>

This tab is used to view the content of the logs and to perform a search in the logs.

To do so, the data file must be logged.
<a name="NOTE2_8"></a>


### "Transactions" tab
<a name="transactions_tab_ELTPARAGRAPHE000192"></a>

This tab is used to free a record or all transactions.

## Other available options
<a name="other_available_options_ELTTEXTE000383"></a>


### Ribbon details
<a name="ribbon_details_ELTPARAGRAPHE000203"></a>

For an HFSQL Client/Server data file, the ribbon offers the following actions:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0002%201.gif)


- In the "SQL query" group: 

	- New query: This option opens a special tab for running SQL queries on the current database.  

	- Open a query: This option opens a specific tab with a previously executed query. 


 For more details, see [Creating and executing a query](../CCHF/35400019.md).

- In the "Data file" group:

	- Optimize and repair: This option opens the data file optimization configuration window. For more details, see [Optimize and repair data files](../CCHF/3540007.md). 

	- Close data file: This option closes the data file and the corresponding tab. 




- In the "Rights" group, the "Manage rights" option allows you to manage the rights granted to the users and groups on the data file. 




Additional options may appear in the ribbon according to the selected tab.
