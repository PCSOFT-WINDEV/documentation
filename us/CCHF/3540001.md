## HFSQL Control Center features
<a name="hfsql_control_center_features_ELTTEXTE000386"></a>
The HFSQL Control Center allows you to manage: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=cc_HF_Presentation%20-%20HC%20N%B0001.gif)


- HFSQL Client/Server databases. You can manipulate and get the details of:

	- [the server](../CCHF/35400014.md): Stop, restart, server configuration, definition of users, scheduled tasks, backups.

	- [the database](../CCHF/35400015.md): Description, search, backup, maintenance of data files, transactions, etc.

	- [each data file in the database](../CCHF/35400016.md): Description, content, search, logs, transactions, etc.




- [HFSQL Classic data files](../CCHF/35400010.md). It is possible to obtain information and manipulate each data file in the database: description, content, search, log, transactions, etc.

- [An analysis](../CCHF/3540003.md). You can manipulate and get the details of all the data files in the analysis. These data files can be:

	- HFSQL Client/Server,

	- HFSQL Classic,

	- External databases




- External databases. You can manipulate and get the details of data files (tables) in other formats:

	- Oracle,

	- SQL Server

	- MySQL

	- etc.




- [An HFSQL cluster](../CCHF/3540005.md). You can manipulate and get the details of HFSQL Cluster data files.

## HFSQL Control Center options
<a name="hfsql_control_center_options_ELTTEXTE000410"></a>
The HFSQL Control Center includes a number of general options for all the available features. To access these options: 

1. Expand the HFSQL Control Center menu (<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_Suivi_Configuration%20-%20HC%20N%B0001.gif)
). 

2. Select "Options". 


The options window appears. This window groups options according to several themes: 

- [General options](#NOTE4_2). 

- [Data view](#NOTE4_3). 

- [SQL queries](#NOTE4_4).

- [Optimization and repair](#NOTE4_5).
	

- [Keychain](#NOTE4_6).
	




Please note: From version 2024 onwards, the format for saving CCHFSQL data (settings, connection list, query history, etc.) is not compatible with previous versions of the HFSQL Control Center. Settings from previous versions are retrieved the first time the HFSQL Control Center is opened. Older versions of the HFSQL Control Center continue to read and save data in the old format.
<a name="NOTE4_2"></a>


### "General" options
<a name="general_options_ELTPARAGRAPHE000129"></a>

The available options are as follows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Presentation_options%20-%20HC%20N%B0001.gif)


- **Display "x" icon to view entered passwords** Display an eye next to "Password" fields. This option allows users to simply click the icon to see the password. 

- **Show the system database of HFSQL servers (requires the rights to connect to the database)** Displays the system database of HFSQL servers. 

- **Remember displayed panes (HFSQL Client/Server connections only)** Memorize open views (panes displaying information on server, database, data file, query, etc.) when the Control Center is closed or disconnected. Tabs are automatically restored next time the Control Center is opened. This option is selected by default. 
	The "reset" option resets the saved views. 

- **Item display order**: Allows you to specify the order in which fields are displayed when data file descriptions are shown ("Description" tab of the data file).. You can choose between logical order (default) or alphabetical order. 

- **Maximum number of open tabs** Allows you to limit the maximum number of shutters open simultaneously. This saves memory resources. 

- **"'Do not show again' Dialog Boxes"**: Allows listing the memorized questions and answers from the 'Do not show again' dialog boxes, displayed by the HFSQL Control Center. This option allows you to disable or re-enable these dialog boxes. 



<a name="NOTE4_3"></a>


### "Data view" options
<a name="data_view_options_ELTPARAGRAPHE000166"></a>

Data files are displayed in a display table. The HFSQL Control Center lets you set a wide range of display options. The available options are as follows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Presentation_options%20-%20HC%20N%B0002.gif)


- **Show Text Memo items** Displays text memo fields in the data file content. 

- Binary Memo items: 

	- **Display contents**: Directly displays the contents of the binary memo. Caution, this option may slow down the loading of the data file content. 

	- **Display content only if connection quality is sufficient, otherwise display size**: Image memos will be displayed only if connection quality is sufficient. Otherwise, only the memo size will be displayed. This option reduces data access and display times. Caution, this option may slow down the loading of the data file content.

	- **Show size only** (default option): Displays the binary memo field specifying only the memo size. 

	- **Do not display**: Binary memo fields will not be displayed in the data file content. 




- **Show composite keys**: displays compound keys and their contents. 

- **Show text on multiple lines** This option displays all text fields on several lines, if required. In this case, you have the ability to define: 

	- if this applies only to text memos. 

	- the maximum number of lines. 




- **Show record numbers** Displays the record number in the first column of the table listing the records in the data file. 

- **Show date the records were last modified (tooltip and details window)**: Displays record modification date in a tooltip. 




You can also specify if records can be modified directly from the HFSQL Control Center, by checking the "Allow editing records in the table" option. Simply choose whether you want to open records in view or edit mode. 
<a name="NOTE4_4"></a>


### "SQL queries" options
<a name="sql_queries_options_ELTPARAGRAPHE000213"></a>

The available options are as follows: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Presentation_options%20-%20HC%20N%B0003.gif)


- **Detect integrity errors when running SQL queries** Enables integrity management to be taken into account when executing SQL queries from the HFSQL Control Center.

- **Detect duplicates when running SQL queries** Enables duplicate management to be taken into account when executing SQL queries from the HFSQL Control Center.



<a name="NOTE4_5"></a>


### Options "Optimizations and Repairs"
<a name="options_optimizations_and_repairs_ELTPARAGRAPHE000237"></a>These options manage the operation of data file optimizations. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Presentation_options%20-%20HC%20N%B0004.gif)
Data files can be optimized: 

- in synchronous mode: Re-indexing via the HFSQL Control Center is blocking. 

- in asynchronous mode: reindexing is performed in asynchronous mode. The results are displayed in the "Optimization" tab and are stored on the server for 48 hours. 




If the "Run data file optimization and repair tasks in asynchronous mode* (if supported by the server)" option is checked, asynchronous mode is activated. For more details, see [HFSQL Control Center: Optimizing and repairing data files](../CCHF/3540007.md). 




<a name="NOTE4_6"></a>


### "Keychain Options"
<a name="keychain_options_ELTPARAGRAPHE000261"></a>

The "Keychain passwords" pane allows you to view and delete the various passwords memorized by the HFSQL Control Center. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Presentation_options%20-%20HC%20N%B0005.gif)


Passwords stored in the HFSQL Control Center are now saved in a password keychain.

This keychain corresponds to a file stored in the HFSQL Control Center data directory. It is encrypted using the Windows user's authentication information. It can therefore only be used by this user on this machine.

Note: Only newly memorized passwords are added to the keychain; old passwords remain in the HFSQL Control Center backup as long as no changes are made. 

If HFSQL Control Center is launched from a version that does not support the password keychain, stored passwords will not be available. 

The stored passwords are as follows: 

- HFSQL classic data file passwords. 

- Client/Server HFSQL data file passwords. 

- Analysis passwords. 

- Login and password for HFSQL Client/Server connections. 

- Login and password for connections to third-party databases. 

- Login and password for HFSQL Cluster connections. 

- Cluster password.
