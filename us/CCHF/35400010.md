
## Managing HFSQL Classic data files 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000205"></a>
The HFSQL Control Center allows you to fully manage HFSQL Classic data files. 

**To display the characteristics of an HFSQL Classic data file**:

1. Open the HFSQL Control Center home window. This window is displayed: 

	- when starting the HFSQL Control Center. 

	- by scrolling down ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0003%201.gif) then selecting "Open an HFSQL Classic data file". 




2. The home window of the Control Center is displayed. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_FichierHFSQLClassic%20-%20HC%20N%B0001.gif&type=thumb)


3. Specify: 

	- the path of the HFSQL Classic data file to open,

	- its password (if necessary). You have the ability to store the password. 




4. Validate. 

5. The HFSQL Control Center displays the content of the selected data file. 

	- The different tabs used to manage the characteristics of the HFSQL Classic data file.

	- The ribbon proposes the different actions that can be performed on the file. The options may differ according to the selected tab.

## Detailed characteristics of an HFSQL Classic data file
<a name="detailed_characteristics_hfsql_classic_data_file_ELTTEXTE000229"></a>


### "Description" tab
<a name="description_tab_ELTPARAGRAPHE000040"></a>

This tab presents the information regarding the items of the data file.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0001.gif&type=thumb)


The following information is displayed:

- The item name,

- The type of the item, 

- The size of the item, 

- The type of key, 

- Statistics,

- Whether the item is visible in "Reports & Queries".




Additional information is displayed if necessary.

Note: By default, headings are displayed in logical order.. You can use the alphabetical order if necessary via the HFSQL Control Center options: 

1. Expand the HFSQL Control Center menu (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_Suivi_Configuration%20-%20HC%20N%B0001.gif)). 

2. Select "Options".

3. In the window that appears, select "alphabetical" for the "Item display order" option.

### "Properties" tab
<a name="properties_tab_ELTPARAGRAPHE000080"></a>The "Properties" tab displays the properties of the data file (physical name, format, protection, etc.).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0002.gif&type=thumb)

<a name="NOTE2_3"></a>


### "Content" tab
<a name="content_tab_ELTPARAGRAPHE000088"></a>

This tab is used to view the different records found in the data file. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0003.gif&type=thumb)


You can also filter the records displayed using the bar above the table. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0004.gif&type=thumb)
The filter context menu (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007%201.gif)) includes several options:

- Apply automatically: The filter is automatically applied when you press Enter. If this option is not selected, you must apply the filter by clicking the green check mark on the right of the filter bar. 

- Remove current filter: Clears the filter bar. 

- Copy SQL code: Copies the SQL code matching the filter conditions to the clipboard. 

- Create a query: Opens a "Query" tab with the SQL code corresponding to the entered conditions (same as the "New query" option in the ribbon). For more details, see [Creating and executing a query](../CCHF/35400019.md). 

- Clear filter history: Previously used filters are automatically saved so that they can be quickly reapplied. You can clear the filter history. 




The recordings context menu lets you manipulate the selected recording: delete, add, display text memos, etc.

You can also:

- Delete a recording: select the recording and click on the "Delete" button (or press the Delete key).

- Modify or add a record: entry is made directly in the record list. All you have to do is position on the first empty row and enter the record information. The data file is automatically updated.

<a name="logs_tab_ELTPARAGRAPHE000120"></a>

To do so, the data file must be logged.

## Options proposed by the ribbon
<a name="options_proposed_the_ribbon_ELTTEXTE000277"></a>
For the selected HFSQL Classic data file, the Ribbon proposes the following actions: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=CCHF_Fichiers_HFClassic%20-%20HC%20N%B0001%201.gif)


- In the "SQL query" group: 

	- New query: This option opens a special tab for querying the current data file..  

	- Open a query: This option opens a specific tab with a previously executed query. 


 For more details, see [Creating and executing a query](../CCHF/35400019.md). 

- In the "Data file" group: 

	- Optimize and repair: This option displays the configuration window for optimizing and repairing HFSQL data files. For more details, see [Optimize and repair data files](../CCHF/3540007.md). 

	- Close data file: This option closes the data file and the associated tab.
