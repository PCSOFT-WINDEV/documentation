


## Int (Variable type)

***In french: Entier***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Int** type is used to easily perform calculations on integer values. Integer variables can have a value ranging from -2 x 109 to 2 x 109 (approximately). 

Note: For advanced calculations, WLanguage offers [different types of integers](#NOTE0_5). 


The Int type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md).

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
i is int
i = 5
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Variable name> is int

<Variable name 1>, <Variable name  2> are int`
---

**`<Variable name>: ()`**

Name of the variable to declare.

## Remarks


### Declaration and initialization
<a name="declaration_and_initialization_ELTPARAGRAPHE000043"></a>

An "Integer" variable that is declared but not initialized is equal to 0.
<a name="NOTE0_2"></a>


### Hexadecimal value
<a name="hexadecimal_value_ELTPARAGRAPHE000050"></a>To enter a hexadecimal value in the code, the hexadecimal value must be prefixed by "0x".


```wl
MyVariable is int
MyVariable = 0x4D5
```


Note: The '_' character can be used as a block separator in hexadecimal numbers. The blocks can have a size equal to 2, 4 or 8 characters long. 
Example: 

```wl
Nb1 is int = 0x_12_15_A4_BC
Nb2 is int = 0x_CD4A_DE58
```

<a name="NOTE0_3"></a>


### Thousand separator
<a name="thousand_separator_ELTPARAGRAPHE000069"></a>

You can use spaces and underscore characters to separate thousands in numbers. For example:

```wl
num1 is int
num1 = 123 456
let num2 = 246_789
```

### PHP-specific features
<a name="phpspecific_features_ELTPARAGRAPHE000080"></a>

- Numbers (real, integer, currency, numeric) cannot exceed 14 significant digits in PHP. If they exceed this limit, they are rounded to 14 digits.

- The maximum value of 32-bit integers is: 
	2147483647 for a 32-bit integer value <=> 0x7FFFFFFF

- The maximum value of 64-bit integers is: 
	9223372036854775807<=>0x7FFFFFFFFFFFFFFF

### Differences between WINDEV 5.5 and WINDEV 2026
<a name="differences_between_windev_55_and_windev_docparamversioncom_ELTPARAGRAPHE000293"></a>

The types of integers have been modified between WINDEV 5.5 and WINDEV 2026:

| Type of integers in WINDEV 5.5 | Type of integers in WINDEV 2026 |
| --- | --- |
| Int | 2-byte int |
| Unsigned int | 2-byte unsigned int |
| Long int | 4-byte int |
| Short int | 1-byte unsigned int |


In WINDEV 5.5, integers were 2-byte integers by default. Since the versions 7.x, integers are 4-byte integers by default.
