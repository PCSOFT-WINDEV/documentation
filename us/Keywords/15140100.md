
## Border (Variable type)

***In french: Cadre***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Border** type is used to handle a border programmatically. The characteristics of this border can be modified by [several WLanguage properties](#NOTE0_2).

A **Border** type can be used: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) in the controls of a window ([Border](../Proprietes/1000018157.md) property).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) in the cells of a Table control in a window ([Border](../Proprietes/1000018157.md) property of cells of Table controls).

- in the controls of a report ([Border](../Proprietes/1000018157.md) property).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available.

- in the drawing functions ([dBorder](../WDLang1/1000021894.md)).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in Excel cells ([Border](../WDLang5/1000017464.md) property of cells in an Excel document).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) in the paragraphs of a Word Processing document (**Border** property on the layout options of [docParagraph](../WDLang1/1000022483.md) variables). 




**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
// Define the characteristics of the borders for report controls
MyBorder is Border
MyBorder.Color = LightRed
MyBorder.Thickness = 5

// Borders for the NumNbPage control in the report
NumNbPage.Border = MyBorder
// Modify the characteristics of the borders for the NumNbPage control
NumNbPage.Border.Thickness = 1

// Get the characteristics of the borders for the NumNbPage control
MyBorder2 is Border = NumNbPage.Border
```


<a name="Exemple2"></a>

```wl
// Define the border characteristics
MyBorder is Border
MyBorder.Color = LightRed
MyBorder.Thickness = 5

// Borders for the NumNbPage control in the report
NumNbPage.Border = MyBorder
// Modify the characteristics of the borders for the NumNbPage control
NumNbPage.Border.TopLeftCorner.Width = 2
NumNbPage.Border.TopLeftCorner.Height = 3
```
<a name="Exemple3"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 
```wl
// Configures the borders
MyBorder is Border
MyBorder.Color = LightRed 
MyBorder.Thickness = 5

// Specific feature of the bottom line
MyBorder.LineBottom.Type = LineDash
MyBorder.LineBottom.Color = DarkRed

// Applies the borders to cell 2, 2 (2nd row, 2nd column)
TABLE_MyTable[2,2].Border = MyBorder
// or 
TABLE_MyTable.COL_NoName2[2].Border = MyBorder
```

## Remarks




### Default characteristics of border
<a name="default_characteristics_border_ELTPARAGRAPHE000108"></a>

**By default, a border found in a report** has the following characteristics:

- thickness set to 0. The border is visible if the thickness is greater than 0. The border is invisible if the thickness is set to 0.

- black.

- solid line.

- no rounded corners.

- all the border edges are displayed.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **By default,** the border of a cell found in an XLS worksheet has the same characteristics. However, the thickness of the line and the rounding of corners are not supported for an XLS cell.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **By default, in a Table control cell**, a border has the following characteristics:

- thickness set to 0. The border is visible if the thickness is greater than 0. The border is invisible if the thickness is set to 0.

- transparent.

- solid line.

- no rounded corners.

- no border edge displayed.




To define the characteristics of a border programmatically, use the border properties.

### WLanguage properties that can be used with the Border type
<a name="wlanguage_properties_that_can_used_with_the_border_type_ELTPARAGRAPHE000140"></a>

The following properties can be used to define the characteristics of **Border** variables. 

| Property name | Type used | Effect |
| --- | --- | --- |
| BottomLeftCorner |   | Characteristics of the lower-left corner: <br><br>- **Width** property: Border corner width (real). <br><br>- **Height** property: Border corner height (real). <br><br><br><br><br>Not supported in XLS cells. |
| BottomRightCorner |   | Characteristics of the lower-right corner:<br><br>- **Width** property: Border corner width (real). <br><br>- **Height** property: Border corner height (real). <br><br><br><br><br>Not supported in XLS cells. |
| Color | Integer | Border color. This color can correspond to:<br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- [a preset color](../WDLang5/3010002.md).<br><br><br><br><br>This property can be used: <br><br>- In edit mode, to modify the color of all borders. <br><br>- In read mode, this property returns: <br><br>	- the color of the borders if all the borders have the same color. <br><br>	- the *ColorUndefined* constant if all the borders do not have the same color.<br><br><br><br><br><br> |
| Edges | Integer constant | Returns and modifies the presence of edges. This property can correspond to a combination of the following options:<br><br>- *BorderNone*: There are no borders.<br><br>- *BorderBottom*: Sets a bottom border.<br><br>- *BorderRight*: Sets a right border.<br><br>- *BorderLeft*: Sets a left border.<br><br>- *BorderTop*: Sets a top border.<br><br>- *BorderAll*: All four borders are displayed.<br><br><br> |
| Line | Integer constant | Returns and modifies the type of line for the border (see the next paragraph).<br><br><br><br>- In edit mode, modifies the type of line for all borders. <br><br>- In read mode, returns: <br><br>	- the type of line for the borders if this parameter is identical for all borders. <br><br>	- the *TypeUndefined* constant if all the borders do not have the same line.<br><br><br><br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The type of line will only be taken into account for frames where all corners are rounded and all edges have the same color and thickness. |
| LineBottom |   | Characteristics of the bottom line: <br><br>- **Color** property: Line color corresponding to an RGB value (returned by [RGB](../WDLang1/3029012.md)), or to [a preset color](../WDLang5/3010002.md).<br><br>- **Thickness** property (Real): Line thickness (millimeters for print layouts and pixels for graphics functions). <br><br>- **Type** property (Integer constant): Type of line (see the next paragraph).<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The type of line will only be taken into account for frames where all corners are rounded and all edges have the same color and thickness.<br><br><br><br><br>Not supported in XLS cells. |
| LineLeft |   | Characteristics of the left line: <br><br>- **Color** property: Line color corresponding to an RGB value (returned by [RGB](../WDLang1/3029012.md)), or to [a preset color](../WDLang5/3010002.md).<br><br>- **Thickness** property (Real): Line thickness (millimeters for print layouts and pixels for graphics functions). <br><br>- **Type** property (Integer constant): Type of line (see the next paragraph).<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The type of line will only be taken into account for frames where all corners are rounded and all edges have the same color and thickness.<br><br><br><br><br>Not supported in XLS cells. |
| LineRight |   | Characteristics of the right line: <br><br>- **Color** property: Line color corresponding to an RGB value (returned by [RGB](../WDLang1/3029012.md)), or to [a preset color](../WDLang5/3010002.md).<br><br>- **Thickness** property (Real): Line thickness (millimeters for print layouts and pixels for graphics functions). <br><br>- **Type** property (Integer constant): Type of line (see the next paragraph).<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The type of line will only be taken into account for frames where all corners are rounded and all edges have the same color and thickness.<br><br><br><br><br>Not supported in XLS cells. |
| LineTop |   | Characteristics of the top line: <br><br>- **Color** property: Line color corresponding to an RGB value (returned by [RGB](../WDLang1/3029012.md)), or to [a preset color](../WDLang5/3010002.md).<br><br>- **Thickness** property (Real): Line thickness (millimeters for print layouts and pixels for graphics functions). <br><br>- **Type** property (Integer constant): Type of line (see the next paragraph).<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) The type of line will only be taken into account for frames where all corners are rounded and all edges have the same color and thickness.<br><br><br><br><br>Not supported in XLS cells. |
| Round | Real | Value of rounding for the corners. Corresponds to the radius of rounding.  <br><br><br><br>- In modification, modifies the rounding of all corners. <br><br>- In read mode, returns: <br><br>	- the width and the height of corners if these parameters are identical for all corners. <br><br>	- the *RoundingUndefined* constant if all the corners do not have the same width and height.<br><br><br><br><br><br><br><br>Not supported: <br><br>- in the XLS cells.<br><br>- in the prargraphs of Word Processing documents.<br><br><br> |
| Thickness | Real | Returns and modifies the thickness of the border (in millimeters in the prints and in pixels in the graphic functions). <br><br><br><br>- In edit mode, changes the thickness of all the borders. <br><br>- In read mode, returns: <br><br>	- the thickness of the borders if the parameter is the same for all the borders. <br><br>	- the *ThicknessUndefined* constant if all the borders do not have the same thickness.<br><br><br><br><br><br><br><br>Not supported in XLS cells. |
| TopLeftCorner |   | Characteristics of the upper-left corner: <br><br>- **Width** property: Border corner width (real). <br><br>- **Height** property: Border corner height (real). <br><br><br><br><br>Not supported in XLS cells. |
| TopRightCorner |   | Characteristics of the upper-right corner: <br><br>- **Width** property: Border corner width (real). <br><br>- **Height** property: Border corner height (real). <br><br><br><br><br>Not supported in XLS cells. |


These properties can be used:

- on the **Border** variable. Example:
	
	```wl
	MyBorder is Border
	MyBorder.Color = LightRed
	MyBorder.Thickness = 5
	```


- on the **Border** property of the element used. 
	
	```wl
	// Modify a characteristic of the border for the NumNbPage element
	NumNbPage.Border.Thickness = 1
	```





**Note**: You can also assign the characteristics of a border defined programmatically to an element:


```wl
// Define the border characteristics
MyBorder is Border
MyBorder.Color = LightRed
MyBorder.Thickness = 5

// Borders for the NumNbPage control in the report
NumNbPage.Border = MyBorder
```
