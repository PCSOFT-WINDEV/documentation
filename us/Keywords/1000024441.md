
## Boolean (Variable type)

***In french: Booléen***
				



<a name="XUse"></a>
<a name="Use"></a>


<a name="description"></a>
The **Boolean** type is recommended for all logical operations where only two alternatives are possible:

- True (value different from 0).

- False (value equal to 0). 


The Boolean type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md). 





<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
b is boolean
```

<a name="XSYNTAX"></a>
<a name="SYNTAX1"></a>

## Syntax

`<Variable name> is boolean

<Variable name 1>, <Variable name 2> are booleans`
---

**`<Variable name>: ()`**

Name of the variable to declare.
