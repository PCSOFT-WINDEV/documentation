


## Duration (Variable type)

***In french: Durée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Duration** type is used to easily manipulate intervals of dates and times. The **Duration** type can be used to perform calculations (subtraction, addition, etc.). For more details, see [Operations available with the Duration type](../Motscles/1514040.md).

**Remarks**:

- Several properties can be used with the **Duration** type, to retrieve the number of days or minutes, for example.

- To assign a duration from the result of a function, use [StringToDuration](../WDLang1/3027002.md).

- For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


The Duration type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md). 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
StartTime is Time = "1330"
EndTime is Time = "1730"
ConferenceDuration is Duration = EndTime - StartTime
```

```wl
TaskDuration is Duration = 3 min 30s
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Variable name> is Duration = <Value>
OR

 <Variable name> is Duration
<Variable name> = <Value>`
---

**`<Variable name>: ()`**

Name of the variable to declare. When several variables of the same type are declared and initialized on the same line, only the last variable is initialized.

**`<Value>: ()`**

In most cases, a duration is the result of an operation between the [Date](../Motscles/1514066.md), [Time](../Motscles/1514068.md) and [DateTime](../Motscles/1514070.md) variables. 
This value can correspond to: 

- a character string,

- an integer (duration in milliseconds),

- a duration (for example, another Duration variable),

- direct indication of duration (e.g. 30 s). 


0 is used to reset the duration.

## Remarks


### Duration values
<a name="duration_values_ELTPARAGRAPHE000105"></a>

If a Duration variable is manipulated: 

- using a string in the format: "+JHHMMSSCCC" (Days, hours, minutes, seconds, thousandths of a second).  

- using an integer, this integer corresponds to the duration in milliseconds.

- using a duration, this duration can correspond to a Duration variable or to a clear description of the duration. 


In most cases, a duration is the result of an operation between the [Date](../Motscles/1514066.md), [Time](../Motscles/1514068.md) and [DateTime](../Motscles/1514070.md) variables. This value can be a duration.

0 is used to reset the duration.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) It is now possible to use a clear description of the duration.

### Duration properties
<a name="duration_properties_ELTPARAGRAPHE000135"></a>

The following properties can be used with durations: 


|   |   |
| --- | --- |
| [InHours](../Proprietes/1000017296.md) | Returns or modifies the number of hours corresponding to a duration. The number of hours is expressed as a real number. |
| [InDays](../Proprietes/1000017295.md) | Returns or modifies the number of days corresponding to a duration. The number of days is expressed as a real number. |
| [InMilliseconds](../Proprietes/1000017299.md) | Returns or modifies the number of milliseconds corresponding to a duration. The number of milliseconds is expressed as an integer. |
| [InMinutes](../Proprietes/1000017297.md) | Returns or modifies the number of minutes corresponding to a duration. The number of minutes is expressed as a real number. |
| [InSeconds](../Proprietes/1000017298.md) | Returns or modifies the number of seconds corresponding to a duration. The number of seconds is expressed as a real number. |
| [Time](../Proprietes/2512038.md) | Returns or modifies the number of hours. The number of hours is expressed as an integer. |
| [Day](../Proprietes/2512043.md) | Returns or modifies the number of days. The number of days is expressed as an integer. |
| [Millisecond](../Proprietes/2512062.md) | Returns or modifies the number of milliseconds. The number of milliseconds is expressed as an integer. |
| [Minute](../Proprietes/2512050.md) | Returns or modifies the number of minutes. The number of minutes is expressed as an integer. |
| [Second](../Proprietes/2512081.md) | Returns or modifies the number of seconds. The number of seconds is expressed as an integer. |


For more details on the possible operations on durations (addition, subtraction, comparison), see [Operations available with the Duration type](../Motscles/1514040.md).

```wl
StartTime is Time = "1330"
EndTime is Time = "1730"     
ConferenceDuration is Duration = EndTime - StartTime
Info("The conference lasted: " + ConferenceDuration.Hour + " hours")
```

**Important**: To store the values of the properties listed in the array above, it is imperative to respect the type of variable returned by each property.. For example:

```wl
MyDuration is Duration
HowManyHours is real

MyDuration.Day = 5
HowManyHours = MyDuration.InHours

Info(MyDuration.Day + " days = " + HowManyHours + " hours")
```

In this example, the **HowManyHours** variable must be declared as a real (and not as an integer). If this variable is declared as an integer, its value will be an approximate number.
<a name="NOTE0_3"></a>


### Supported values
<a name="supported_values_ELTPARAGRAPHE000207"></a>

The **Duration** type supports durations ranging from -2 billion days to 2 billion days. The precision is up to the millisecond.
<a name="NOTE0_4"></a>


### Displaying a duration in an Edit control
<a name="displaying_duration_edit_control_ELTPARAGRAPHE000214"></a>

To display a duration in an Edit control, you can use the [DisplayMask](../Proprietes/1000020008.md) property. For more details, see [Display mask for durations](../Proprietes/1000020008.md).
