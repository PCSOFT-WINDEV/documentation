
## MyLeftSlidingWindow (Reserved word)

***In french: MaFenêtreCoulissanteGauche***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
**MyLeftSlidingWindow** is used to handle the left sliding window associated with the current window. When running the window, **MyLeftSlidingWindow** is replaced with the window (and not by the name of the window). Then, **MyLeftSlidingWindow** can be used like any other window.

**Interest**: The **MyLeftSlidingWindow** keyword lets you manipulate the fields present in the left sliding window associated with the current window.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyLeftSlidingWindow.ConnectAfter(False)
WinSlidingVisible(swLeft, True)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MyLeftSlidingWindow`

## Remarks




### Manipulating the controls of the sliding window from the current window
<a name="manipulating_the_controls_the_sliding_window_from_the_current_window_ELTPARAGRAPHE000030"></a>

The **MyLeftSlidingWindow** keyword is always replaced with the left sliding window defined for the current window. In the example below, the [Color](../Proprietes/2510071.md) property is used on a Static Text control:


```wl
// Changes the color of a caption in the left sliding window
MyLeftSlidingWindow.STC_Caption.Color = LightRed
```





### Limitation
<a name="limitation_ELTPARAGRAPHE000043"></a>

The **MyLeftSlidingWindow** keyword allows you to access the controls in the sliding window. It can also be used to call the procedures of this window.
However, the **MyLeftSlidingWindow** keyword cannot be used to access the variables or properties of the sliding window.
