
## Currency (Variable type)

***In french: Currency***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Monetary** type is used to perform calculations on real values requiring guaranteed decimal precision, such as monetary values.

A variable of type **Monétaire** manages 24 significant digits (17 maximum for the integer part, 6 maximum for the decimal part).. A **Currency** variable corresponds to a 10-byte decimal number. 

The **Monétaire** type is recommended to avoid rounding errors due to the binary coding of real numbers.. An **Monetary** variable can take a value between -604 462 909 807 314 587,353 087 and +604 462 909 807 314 587,353 087..

The Currency type supports null values. For more details, see [Allowing nullable types](../Motscles/1511031.md). 

**Remarks**:

- For greater precision, it is recommended to use [numerics](../Motscles/1514072.md) (38 significant digits). Please note: calculations performed with Numericals will be slower than those performed with Coins.. 

- For calculations that don't require great precision, it's preferable to use [reals](../Motscles/1514048.md), which are faster.

## Syntax

`<Variable name> is currency

<Variable name 1>, <Variable name 2> are currencies`
---

**`<Variable name>: ()`**

Name of the variable to declare. This will be a currency variable.

## Remarks


### Declaration and initialization
<a name="declaration_and_initialization_ELTPARAGRAPHE000076"></a>

A "Currency" variable that is declared but not initialized is equal to 0.

When assigning a Monetary type variable with a value (value directly entered, supplied by a function, etc.), **this value is automatically converted to real by the**compiler.

**To force the assignment of a currency**, use **0m** in front of the value. For example:


```wl
num1 est un monétaire
num1 = 0m12345678901234567891234567
Trace(num1)
```

<a name="NOTE0_2"></a>


### Binary encoding of real numbers
<a name="binary_encoding_real_numbers_ELTPARAGRAPHE000089"></a>

All [reals](../Motscles/1514048.md) have the same number of significant digits (15).

If the result of a calculation performed on [reals](../Motscles/1514048.md) includes more than 15 significant digits, this result will be automatically rounded to 15 significant digits. The precision of the result will be less than the precision of a calculation performed with the **currency** type.

[numerics](../Motscles/1514072.md) provide even greater precision (32 digits for the integer part and 6 digits for the decimal part).




<a name="NOTE0_3"></a>


### Thousand separator
<a name="thousand_separator_ELTPARAGRAPHE000111"></a>

You can use spaces and underscore characters to separate thousands in numbers. For example: 

```wl
num1 est un monétaire
num1 = 123 456.478

num2 est un monétaire
num2 = 568_014.478
```





<a name="NOTE0_4"></a>


### Calculations on currency values
<a name="calculations_currency_values_ELTPARAGRAPHE000121"></a>

All the calculations that use at least one **currency** will be performed in **currency** format. For a more precise result, all the operands will be automatically converted to **currency**.

For example, when a real is multiplied by a currency, the calculation is performed using the currency type.

Note: For greater precision, we recommend using [Numeric type](../Motscles/1514072.md) to perform calculations.
<a name="NOTE0_5"></a>

### PHP-specific features
<a name="phpspecific_features_ELTPARAGRAPHE000137"></a>

Numbers (real, integer, currency, numeric) cannot exceed 14 significant digits in PHP. If they exceed this limit, they are rounded to 14 digits.
<a name="NOTE0_6"></a>


### External language
<a name="external_language_ELTPARAGRAPHE000144"></a>

The **Monétaire** type is not available in the external language.
