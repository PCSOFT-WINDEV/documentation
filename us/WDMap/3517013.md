


## WDMap: Characteristics of database data files
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000230"></a>
WDMap is used to get various characteristics specific to:

- to each data file present in a database manipulated by a WINDEV, WEBDEV or WINDEV Mobile project,

- all data files in a database handled by a WINDEV, WEBDEV or WINDEV Mobile project.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000254"></a>


### WDMap started from the editor
<a name="wdmap_started_from_the_editor_ELTPARAGRAPHE000021"></a>

For information on a database's data files:

1. Under WDMap, select the WINDEV, WEBDEV or WINDEV Mobile analysis (".WDD" file) containing the description of the desired data file (use the "Browse" button if necessary).

2. Specify (if necessary) the password of the analysis (runtime password defined in the analysis description.

3. Select "Display .. General information about the database" (or click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WDMap_caract_fichier%20-%20HC%20N%B0001%201.gif)). The window containing the database characteristics is displayed.



<a name="NOTE2_2"></a>


### WDMAP started by "WDMAP.EXE" directly
<a name="wdmap_started_wdmapexe_directly_ELTPARAGRAPHE000034"></a>

For information on a database's data files:

1. In the wizard, select "Select an analysis" and go to the next step.

2. Select the WINDEV, WEBDEV or WINDEV Mobile analysis (".WDD" file) containing the description of the desired data file (use the "Browse" button if necessary) and proceed to the next step.. WDMap starts.

3. Specify (if necessary) the password of the analysis (runtime password defined in the analysis description.

4. Select "Display .. General information about the database" (or click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WDMap_caract_fichier%20-%20HC%20N%B0001%201.gif)). The window containing the database characteristics is displayed.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## What are the displayed characteristics?
<a name="what_are_the_displayed_characteristics_ELTTEXTE000284"></a>
A database manipulated by a WINDEV, WEBDEV or WINDEV Mobile project can be made up of both HFSQL and non-HFSQL data files.

The window containing the characteristics is divided in half:

- The top section contains the characteristics specific to the HFSQL data files.

- The bottom section contains the characteristics specific to the other types of data files (not in HFSQL format) accessed via an OLE DB provider, an ODBC driver or a native access.




**Note** If the current database consists solely of HFSQL data files, only the top part will be displayed. If the current database consists only of non-HFSQL data files, only the bottom part will be displayed.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WDMap_caract_fichier%20-%20HC%20N%B0002.gif)

### Characteristics specific to HFSQL data files
<a name="characteristics_specific_hfsql_data_files_ELTPARAGRAPHE000063"></a>

The following table presents the characteristics displayed by WDMap. These characteristics are specific to the HFSQL data files found in the database of the WINDEV, WEBDEV or WINDEV Mobile project:

| Name | Comment |
| --- | --- |
| Logical name | Name of data file defined in the analysis. |
| Physical name | Name of the physical file associated with the logical file. This name is defined in the analysis. |
| Type | HFSQL Classic or Hyper File 5.5. |
| Total size | Current size (in KB) of the data file, the index file and the memo file corresponding to the logical file. |
| Number of active records | An active record is a record that can be used directly (by [HRead](../WDLang4/3044047.md) for example). |
| Number of crossed records | A crossed record is a record that is logically deleted (by [HCross](../WDLang4/3044121.md)). This record can be retrieved (with <[[3044042\HModify]] or [[3044092\HWrite]]). This record can be physically deleted (by [[3044018\HDelete]]).<br>\-<br>\ <br>Number of deleted records<br>\ <br>A deleted record is a record that is deleted both logically and physically (by [[3044018\HDelete]]).<br>\-<br>\ <br>Total number of records<br>\ <br>Number of active, deleted and deleted records in the data file.<br>\-<br>\ <br>Password<br>\ <br>Data file password set either by [[3044108\HPass]], [[3044255\HCreation]] or [[3044254\HCreationIfNotFound]], or by [[3044195\automatic data modification]].<br>\-<br>\ <br>Encryption<br>\ <br>Indicates whether the data file is encrypted.<br>\-<br>\ <br>Log<br>\ <br>Indicates whether the data file is logged.<br>[The log](../WDLang4/3044184.md) is a specific file used to automatically store all the operations performed on one or more data files from a given time. |
| Replication | Indicates whether the data file is replicated.<br>[The replication](../WDLang4/3044266.md) is the operation used to maintain remote databases with identical structure, and on which different operations are performed. |
| **Additional information linked to the physical file during a double click on an HFSQL data file** |
| File directory | Directory of physical file. |
| Date of last modification |   |
| Path of analysis in version 5.5 | Only if the selected data file comes from a 5.5 analysis. |
| Directory of the log | Directory of the log file associated with the selected data file (if the log file exists). |
| Size of log file | Current size (in KB) of the log file (if the log file exists. |


For all the HFSQL data files found in the database, the following calculations are automatically performed:

- The total size (in KB) of all the data files.

- The size (in KB) of the log files associated with the data files.

- The number of records found in all the data files.

### Characteristics specific to the other types of files (not in HFSQL format)
<a name="characteristics_specific_the_other_types_files_not_hfsql_format_ELTPARAGRAPHE000144"></a>

The following table presents the characteristics displayed by WDMap. These characteristics are specific to the data files not in HFSQL format found in the database of the WINDEV, WEBDEV or WINDEV Mobile project:

| Name | Comment |
| --- | --- |
| File | Logical name of data file. |
| Caption | Name of the connection used to access the different data files found in the current analysis (specified during the configuration of the connection in the data model editor). |
| Connection via | Current database access mode: OLE DB provider, ODBC driver or native access. |
| Data source | Data source of the connection:<br><br>- name and full path of the database, <br><br>- directory of xBase file,<br><br>- name or alias of the server used.<br><br><br> |
| User | Username required to connect to the database. |
| Access | Data file access type: read-only or read and write. |
| Number of records | Number of records in data file. |
