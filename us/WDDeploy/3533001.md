## Overview

### WDDeploy
<a name="wddeploy_ELTPARAGRAPHE000011"></a>

WDDeploy is a utility that makes it easy to deploy a website or a website package. 

WDDeploy can be used to:

- [Deploying a WEBDEV site via a package](../WDDeploie/3533002.md). 

- [Deploying a SOAP or REST web service via a package](../WDDeploie/3533002.md). 

- [Deploying a static site](../WDDeploie/3533003.md). 

- [Deploying a PHP site](../WDDeploie/3533003.md).




You can also: 

- [compress and create an archive with the files of a remote site](../WDDeploie/3533003.md).

- [restore site files contained in a previously created archive](../WDDeploie/3533003.md).

## Starting WDDeploy
<a name="starting_wddeploy_ELTTEXTE000158"></a>
To start WDDeploy:

- on the "Tools" tab, in the "Web utilities" group, click "WDDeploy".

- run "WDDeploy.EXE" directly.

## Use conditions
<a name="use_conditions_ELTTEXTE000182"></a>
WDDeploy can be redistributed. WDDeploy can be used to install any static site, whether or not they have been developed with WEBDEV.

The WEBDEV license is fully enforced.


### Installing WDDeploy on another computer
<a name="installing_wddeploy_another_computer_ELTPARAGRAPHE000077"></a>

The following files are required to install WDDeploy:

- WDDeploy.exe

- wd310xxx.dll

- WDOutil.WDK

- WDDeploy_FR.pdf

- WDDeploy_EN.pdf
