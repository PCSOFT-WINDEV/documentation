


## Scanner (Variable type)

***In french: Scan***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Scanner** type is used to handle the information from a scanner. You can define and change the characteristics of the scanner using different WLanguage properties.

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Scan an image
MyScanner is Scanner = ScanSelect()
IMG_Scan = ScanToImage(MyScanner)
```

## Properties


### Properties specific to Scanner variables
<a name="properties_specific_scanner_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to handle the characteristics of a scanner:

| Property name | Type used | Effect |
| --- | --- | --- |
| Area | [Rectangle](../Motscles/1514079.md) | Area to be scanned (in thousandths of a millimeter). By default, a rectangle with all zero coordinates and dimensions (0,0,0,0) is used to scan the entire page.<br><br>**Note** This zone is taken into account by the ScanProperty function if the constant **scanFormatPaperPerso** is used. |
| BitPerPixel | Integer | <br><br>- Number of bits per pixel, <br><br>- *scanBitsPerPixelDefault* constant (default value) if the value of the property should not be changed in the next scan. The property will use the previous value. <br><br><br> |
| Brightness | Integer | <br><br>- Brightness, between -1000 and 1000,<br><br>- *scanBrightnessDefault* constant (default value) if the value of the property should not be changed in the next scan. The property will use the previous value. <br><br><br> |
| ColorFormat | Integer constant | Image color format:<br><br>- *scanFormatColorAuto* Color format automatically detected by device (default).<br><br>- *scanFormatColorRGB* RGB image (24 bits per pixel).<br><br>- *scanFormatColorGrayLevel*: Grayscale image.<br><br>- *scanFormatColorBlackWhite*: Black and white image.<br><br><br> |
| Contrast | Integer | <br><br>- Contrast, between -1000 and 1000,<br><br>- *scanContrastDefault* constant (default value) if the value of the property should not be changed in the next scan. The property will use the previous value.<br><br><br> |
| Duplex | Integer constant | Duplex mode options: <br><br>- *scanDuplexDefault* constant (default value) if the value of the property should not be changed in the next scan. The property will use the previous value.<br><br>- *scanRectoVersoYes*: the scan is a duplex scan.<br><br>- *scanRectoVersoNon*: the scan is a single-sided scan only. <br><br><br> |
| Height | Integer | <br><br>- Maximum height (in thousandths of a millimeter),<br><br>- *scanHeightDefault* constant (default value).<br><br><br><br><br>**This property is read-only**. |
| Name | Character string | <br><br>- Scanner name,<br><br>- Empty string if the variable has not been initialized (default value).<br><br><br><br><br>**This property is read-only**. |
| ProcedureProgress | Procedure | <br><br>- Name of the WLanguage procedure called when scanning a page,<br><br>- Empty string to not use a procedure (default value). <br><br><br><br><br>This procedure has the following format: <br><br><pre><code><Procedure name>(<Page number>, <br>	<Progress percentage>)</code></pre><br>where: <br><br>- &lt;Numéro de page&gt; Number of scanned page.<br><br>- &lt;Progress percentage&gt;: Scan progress percentage of the page (between 0 and 100)<br><br><br>If the procedure returns <u><u><u>False</u></u></u>, the scan is interrupted. |
| Resolution | Integer | <br><br>- Image resolution in pixels per inch,<br><br>- *scanResolutionDefault* constant (default value) if the value of the property should not be changed in the next scan. The property will use the previous value.<br><br><br> |
| ScanFrom | Integer constant | Indicates the source of the scan: <br><br>- *scanFromAuto* scan from feeder if there is a feeder and pages in the feeder, otherwise scan from tray (default value). <br><br>- *scanFromFeeder*: scan from feeder. <br><br>- *scanfromPlateau*: scan is performed from the plateau. <br><br><br> |
| Width | Integer | <br><br>- Maximum width (in thousandths of a millimeter),<br><br>- *scanWidthDefault* constant (default value).<br><br><br><br><br>**This property is read-only**. |

### WLanguage functions
<a name="wlanguage_functions_ELTPARAGRAPHE000158"></a>The following WLanguage functions use the Scanner type: 



|   |   |
| --- | --- |
| [ScanGet](../WDLang6/1410087836.md) | Retrieves the characteristics of a scanner in a variable of type [Scanner](../WDLang6/1410087808.md). |
| [ScanProperty](../WDLang6/1410087853.md) | Used to get and change the properties of a scanner. |
| [ScanSelect](../WDLang6/1410087835.md) | Opens a standard dialog box with the available scanners. |
| [ScanToImage](../WDLang6/1410087838.md) | Retrieves a document from a scanner in a variable of type [Image](../WDLang1/1000019650.md). |
| [ScanToPDF](../WDLang6/1410087839.md) | Saves a document from a scanner to a PDF file. |
| [ScanWithUserInterface](../WDLang6/1410087840.md) | Saves a document from a scanner to one or more files, using the scanner's user interface. |
