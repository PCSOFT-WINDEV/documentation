


## GuidedTourStart (Function)

***In french: VisiteGuidéeDémarre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts a Guided Tour and displays the first step.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyGetStartedTour is GuidedTour
// ...
// Start Guided Tour
GuidedTourStart(MyGetStartedTour)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`GuidedTourStart(<Guided Tour> [, <Step to display>])`
---

**`<Guided Tour>: (GuidedTour variable)`**

Name of the [GuidedTour](../WDLang6/1410090170.md) variable that corresponds to the Guided Tour to be started.  

**`<Step to display>: (Optional integer)`**

Number of the Guided Tour step to be displayed. By default, step 1 is displayed.
