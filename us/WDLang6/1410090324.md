


## &lt;GuidedTour&gt;.ChangeStep (Function)

***In french: &lt;VisiteGuidée&gt;.ChangeEtape***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Moves to another step of a Guided Tour.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Moves to the next step if the user has entered an email address
IF InGuidedTourMode() = True THEN
	IF EDT_Email <> "" THEN 
		MyGetStartedTour.ChangeStep(gtNextStep)
	END
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Specifying the index of the step to be displayed

`<Guided Tour>.ChangeStep(<Index>)`
---

**`<Guided Tour>: (GuidedTour variable)`**

Name of the [GuidedTour](../WDLang6/1410090170.md) variable to be used. If this parameter is not specified, the current Guided Tour will be used.

**`<Index>: (Integer)`**

Index of the Guided Tour step to be displayed.


<a name="SYNTAXE2"></a>

### Moving to another step via an option

`<Guided Tour>.ChangeStep(<Option>)`
---

**`<Guided Tour>: (GuidedTour variable)`**

Name of the [GuidedTour](../WDLang6/1410090170.md) variable to be used. If this parameter is not specified, the current Guided Tour will be used.

**`<Option>: (Character String constant)`**

Step to display: 


|   |   |
| --- | --- |
| *gtPreviousStep* | Goes to the previous step. |
| *gtNextStep* | Goes to the next step. |
