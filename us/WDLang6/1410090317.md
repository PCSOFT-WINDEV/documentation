
## Guided Tour functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The functions for handling guided tours are as follows: 



|   |   |
| --- | --- |
| [GuidedTourChangeStep](../WDLang6/1410090229.md) | Moves to another step of the Guided Tour. |
| [GuidedTourInfo](../WDLang6/1410090219.md) | Returns information about a Guided Tour. |
| [GuidedTourStart](../WDLang6/1410090176.md) | Starts the Guided Tour and displays the first step. |
| [GuidedTourStop](../WDLang6/1410090225.md) | Stops the current Guided Tour or another specified Guided Tour. |
