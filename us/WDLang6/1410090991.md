
## Palette functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
 
The following functions are used to manipulate color palettes: 



|   |   |
| --- | --- |
| [PaletteChange](../WDLang6/1410090897.md) | Changes the palette used by the project or by a window. |
| [PaletteGenerate](../WDLang6/1410090825.md) | Generates a palette from a base color. |
| [PaletteGet](../WDLang6/1410090898.md) | Gets the palette currently used by the project or window. |
| [PaletteLoad](../WDLang6/1410090780.md) | Loads a palette from a .wdpalette file. |
| [PaletteSave](../WDLang6/1410090779.md) | Saves a palette to a file. |
