


## &lt;Palette variable&gt;.Save (Function)

***In french: &lt;Variable Palette&gt;.Sauve***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves a palette to a file.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Generate a palette
Palette1 is Palette
Palette1.Generate(0x90CAF9)
// Modify a palette element
Palette1["Logo"] = 0xA0305
// Save modified palette
Palette1.Save("WithLogo.wdpalette")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Palette>.Save(<File name>)`
---

**`<Palette>: (Palette variable)`**

Name of the [Palette](../WDLang1/1000021347.md) variable to be saved to a file.

**`<File name>: (Character string)`**

Full name of the file to which to save the palette. By default, this file is of type .wdpalette.
