


## &lt;pdfDocument variable&gt;.Extract (Function)

***In french: &lt;Variable pdfDocument&gt;.Extrait***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a new PDF document from individual pages extracted from an existing PDF file. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySourcePDF is pdfDocument
MyTargetPDF is pdfDocument
MySourcePDF = "C:\Temp\My_source_PDF.pdf"
// Extract pages 3, 10, 15 to 16 and 36
MyTargetPDF = MySourcePDF.Extract("3,10,15-16,36")
IF ErrorOccurred THEN
	Error(ErrorInfo(errFullDetails))
	RETURN
END
MyTargetPDF.Save("C:\Temp\My_target_PDF.pdf")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Source PDF file>.Extracts(<Pages to extract> [, <Password>])`
---

**`<Result>: (pdfDocument variable)`**

[pdfDocument](../WDLang6/1000024909.md) variable corresponding to the new PDF file that contains the extracted page(s).

**`<Source PDF file>: (pdfDocument variable)`**

Name of the [pdfDocument](../WDLang6/1000024909.md) variable corresponding to the PDF file from which the page(s) are to be extracted. 

**`<Pages to extract>: (Character string)`**

List of pages to extract. The individual pages to be extracted must be separated by a comma (","). To specify a set of pages, the first and last pages of the set must be separated by a hyphen ("-"). For example: "1-10, 15-18, 35"

**`<Password>: (Optional character string)`**

Password of the PDF document.
