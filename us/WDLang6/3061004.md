
## BurnerPath (Function)

***In french: GraveurChemin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the path of the current burner. This burner can be selected by [BurnerSelect](../WDLang6/3061012.md).

**Note** To find out which burners are available from the current workstation, use the [BurnerList](../WDLang6/3061009.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the burners installed
ListBurner is string
ListBurner = BurnerList()
IF ListBurner ~= "" THEN
	Error("No burner was detected on the computer")
	RETURN
END
// Fill TABLE_BurnerTable with the list of burners
ABurner is string
PathOfBurner is string

FOR EACH STRING ABurner OF ListBurner SEPARATED BY CR
	// Select the burner
	IF BurnerSelect(ExtractString(ABurner, 1)) = False THEN
		Error("Failure selecting the burner", ErrorInfo())
		RETURN
	END
	// Path of current burner
	PathOfBurner = BurnerPath()
	// Add into the table
	TableAddLine(TABLE_BurnerTable, PathOfBurner, ABurner)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = BurnerPath()`
---

**`<Result>: (Character string)`**



- Path of current burner. 
	This path always ends with a backslash character ("\\").

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

## Remarks




### Required configuration 
<a name="required_configuration_ELTPARAGRAPHE000050"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Burning CDs is available for Windows XP and later. Burning DVDs is available for Windows Vista and for Windows XP when using the KB932716 update for Windows XP (this update must be downloaded from the Microsoft site and installed manually because it is not taken into account by the Live Update mechanism). ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The CDs and the DVDs will be burned on the Web server. To burn CDs or DVDs, the server must be running Windows XP or later. To burn CDs in Windows 2003 Server, the IMAPI burn service (named "IMAPI CD-burning COM service") must be enabled. To burn DVDs in Windows 2003 Server, you also have to install the KB932716 update.
