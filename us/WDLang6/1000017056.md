
## gpwInLDAPMode (Function)

***In french: gpwEnModeLDAP***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines whether users will authenticate to the User Groupware using an LDAP directory.  
<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = gpwInLDAPMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the User Groupware uses an LDAP directory for user authentication,

- <u><u><u><u>False</u></u></u></u> otherwise.




![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) &lt;Result&gt; is always set to <u><u><u><u>False</u></u></u></u>.
