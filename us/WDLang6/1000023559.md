
## gpwRegisteredUsers (Function)

***In french: gpwUtilisateursEnregistrés***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the value corresponding to the word "Registered users" depending on the framework used or the language specified. The term "Registered users" is used when a user is registered in the groupware.

Note: As groupware and groupware files are multilingual, it is possible to retrieve the value of the constant representing the word "Registered users".
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sCstgpwRegisteredUsers is string
sCstgpwRegisteredUsers = gpwRegisteredUsers()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = gpwRegisteredUsers([<Language>])`
---

**`<Result>: (Character string)`**

Value of "Record users" word. 

If the &lt;Langue&gt; parameter is not specified, the value returned depends on the framework used: 

- "Registered users" if the framework is in English,

- "Utilisateurs enregistrés" if the framework is in French. 




**`<Language>: (Optional constant)`**

Language to be used to obtain the value corresponding to "Registered users": 


|   |   |
| --- | --- |
| *languageEnglish* | Value corresponding to "Registered user". |
| *languageFrench* | Value corresponding to "Registered users" in French: "Utilisateurs enregistrés". |
| *languageSpanish* | Value corresponding to "Registered users" in Spanish: "Registered user". |
