
## PDFIsProtected (Function)

***In french: PDFEstProtégé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the PDF file requires a password to be read.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Checks whether the PDF file is protected
IF PDFIsProtected("C:\Temp\MyDocument.pdf") = True THEN
	Info("Password-protected PDF file")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = PDFIsProtected(<PDF file>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a password is required to open the PDF file, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<PDF file>: (Character string)`**

Name and path of the PDF file to be analyzed.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Only the password required to open the file is taken into account. If the PDF file only requires a password to change the protection settings, it is not considered as protected (**PDFIsProtected** will return <u><u><u><u>False</u></u></u></u>).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Starting with version 28, this function is not supported by 32-bit ARM processors. New PDF features require a 64-bit execution mode. 
	If an application is to be run on devices with 32-bit ARM processors, it must be generated with WINDEV Mobile 27.
