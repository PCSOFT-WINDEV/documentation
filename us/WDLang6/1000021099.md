
## gpwConnectUser (Function)

***In french: gpwConnecteUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Logs a user in to the User Groupware. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
// User login
nReturnedValue is int = gpwConnectUser(EDT_Login, EDT_Password)

// If the connection fails
IF nReturnedValue <> gpwOk THEN
	SWITCH nReturnedValue
		CASE gpwErreur: Error("Connection not possible.")
		CASE gpwUnknownUser, gpwInvalidPassword: 
				Error("Invalid user or password.")
	END
ELSE
	// Log in as an administrator
	If gpwGetUserInfo(gpwInfoSupervisor) THEN
		// Opens the groupware administration page
		gpwOpenConfiguration()
		// Refreshes the page
	ELSE
		PageUse(MyPage..Name)
	END
END
```

## Syntax
<a name="SYNTAXE1"></a>

### Logging a user in to the User Groupware

`<Result> = gpwConnectUser(<Username> , <Password>)`
---

**`<Result>: (Integer constant)`**

Result of the connection: 


|   |   |
| --- | --- |
| *gpwError* | An error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md). |
| *gpwInvalidPassword* | The user password is unknown. |
| *gpwOK* | The user was logged in. |
| *gpwUnknownUser* | The user is unknown: it is not present in the User Groupware database. |



**`<Username>: (Character string)`**

Username. 

**`<Password>: (Character string)`**

Password associated with the username. 


<a name="SYNTAXE2"></a>

### Logging a user in to the User Groupware using their email address

`<Result> = gpwConnectUser(<User's email address>)`
---

**`<Result>: (Integer constant)`**

Result of the connection: 


|   |   |
| --- | --- |
| *gpwError* | An error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md). |
| *gpwInvalidPassword* | The user password is unknown. |
| *gpwOK* | The user was logged in. |
| *gpwUnknownUser* | The user is unknown: it is not present in the User Groupware database. |



**`<User's email address>: (Character string)`**

User email retrieved in an OpenID authentication (**Email** property of the [OpenIDIdentity](../WDLang3/1000023567.md) variable).
