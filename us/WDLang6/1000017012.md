
## LockAppOff (Function)

***In french: VerrouAppliDébloque***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Unlocks an application that was locked automatically or by [LockAppOn](../WDLang6/1000017011.md).

**Note**: This function is used in particular in the unlock window of the. It can also be used to unlock an application through programming (use of a specific keyboard shortcut for instance).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
LockAppOff()
```
