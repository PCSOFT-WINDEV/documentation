
## Guided Tour constants
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manage Guided Tours:

| Constant | Details | Function |
| --- | --- | --- |
| **gtaNone** | Action performed when the user clicks the target control(s) of the current step: <br>Clicking the target control(s) has no effect. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtaControl** | Action performed when the user clicks the target control(s) of the current step: <br>The control has a standard behavior. The events associated with the control are executed. The transition to the next step must be programmed. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtaControlThenNextStep** | Action performed when the user clicks the target control(s) of the current step: <br>The control has a standard behavior. Once the code of the control is executed, the Guided Tour automatically moves on to the next step.<br>This action only works on the following fields: Buttons, Switches, Pickers and Menu options. For other controls, only the transition to the next step will be run. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtaDefault** | Action performed when the user clicks the target control(s) of the current step: <br>The action depends on the type of effect | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtaNextStep** | Action performed when the user clicks the target control(s) of the current step:<br>Clicking the control only takes the user to the next step. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtaEnd** | Action performed when the user clicks the target control(s) of the current step:<br>Clicking the control ends the Guided Tour. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtPreviousStep** | Stage to display: Displays the previous stage of the current stage. | [GuidedTourChangeStep](../WDLang6/1410090229.md) |
| **gtNextStep** | Stage to display: Displays the next stage of the current stage. | [GuidedTourChangeStep](../WDLang6/1410090229.md) |
| **gtsCircle** | Shape to be used for the "hole" (GFI effect) or for the halo (Halo effect): Circle | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtsRectangle** | Shape to be used for the "hole" (GFI effect) or for the halo (Halo effect): Rectangle | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtInfoDate** | Date the Guided Tour was last viewed on the current computer. | [GuidedTourInfo](../WDLang6/1410090219.md) |
| **gtInfoCount** | Number of times the user has seen the Guided Tour. | [GuidedTourInfo](../WDLang6/1410090219.md) |
| **gtInfoVersion** | Version number of the last Guided Tour viewed by the user. | [GuidedTourInfo](../WDLang6/1410090219.md) |
| **gtModeOpaque** | Tooltip display mode: <br>The tooltip is displayed in a popup window with an arrow pointing to the target controls(s). The default internal window includes two buttons to go to the next/previous step or to end the tour. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gtModeTransparent** | Tooltip display mode: <br>The tooltip is displayed with a transparent background next to the target control(s). In this mode, the user cannot interact with the controls in the internal window. In this mode, it is recommended to use the Dim Disabled Windows (DDW) effect. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gttNone** | Effect type: no display effect. | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gttDDW** | Type of effect: grayed out the host window content, leaving a hole around the target field(s). | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
| **gttHalo** | Effect type: displays a halo around the target field(s). | [GuidedTour](../WDLang6/1410090170.md) type<br>[GuidedTourStep](../WDLang6/1410090178.md) type |
