
## CDList (Function)

***In french: CDListe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of CD/DVD players installed on the current computer.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Displays the list of CD/DVD players  
// found on the current computer in LIST_ListPlayers  
ListAdd(LIST_ListPlayers, CDList())
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = CDList()`
---

**`<Result>: (Character string)`**

List of players installed on the current computer, in the following format:


```txt
<Reader ID 1> + CR + ... + <Reader ID N>
```


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The current computer corresponds to the Web server.
