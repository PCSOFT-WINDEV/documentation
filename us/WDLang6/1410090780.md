


## PaletteLoad (Function)

***In french: PaletteCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a palette from a .wdpalette file.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Load colors for WIN_Info
DarkPalette is Palette
PaletteLoad(DarkPalette, "default_dark.wdpalette")
PaletteChange(WIN_Info, DarkPalette)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Loading a .wdpalette file into an existing palette

`PaletteLoad(<Palette> , <Palette file>)`
---

**`<Palette>: (Palette variable)`**

Name of the [Palette](../WDLang1/1000021347.md) variable into which the file is to be loaded. 

**`<Palette file>: (Character string)`**

Path and name of the file containing the color palette description. This must be a .wdpalette file. 


<a name="SYNTAXE2"></a>

### Creating a new palette from a .wdpalette file

`<Result> = PaletteLoad(<Palette file>)`
---

**`<Result>: (Palette variable)`**

[Palette](../WDLang1/1000021347.md) variable corresponding to the loaded file. 

**`<Palette file>: (Character string)`**

Path and name of the file containing the color palette description. This must be a .wdpalette file.
