
## AIChatListModel (Function)

***In french: IAListeModèleChat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns a list of AI models available for a given provider. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sListModel is string = AIChatListModel(aiProviderOpenAI, myAI.ID)
COMBO_Models.Content = sListModel
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = AIChatListModel(<Provider> [, <API key>])`
---

**`<Result>: (Character string)`**

List of AI models available for the given provider, separated by carriage returns. 

**`<Provider>: (Integer constant)`**

Available constants:


|   |   |
| --- | --- |
| *aiProviderGoogle* | Google. |
|  *aiProviderAnthropic* | Anthropic. |
| *aiProviderOpenAI* | OpenAI. |
| *aiProviderMistral* | Mistral AI. |
| *aiProviderCustom* | Custom provider. |
| *aiProviderXAI* | Grok. |
| *aiProviderOpenRouter* | OpenRouter. |



**`<API key>: (Optional character string)`**

API key required to access the AI model. 

**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
