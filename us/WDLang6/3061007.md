
## BurnerStatus (Function)

***In french: GraveurEtat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the status of the current burner. This burner can be selected by [BurnerSelect](../WDLang6/3061012.md).

**Note** To find out which burners are available from the current workstation, use the [BurnerList](../WDLang6/3061009.md) function.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Find out the status of the burner
ResStatus is int
ResStatus = BurnerStatus() 
// Status of burner 
SWITCH ResStatus
	// Burn process in progress
	CASE burnerBurn 
		Info("Burn process in progress")
	// Burner disabled
	CASE burnerInactive 
		Info("The burner is inactive")
	// Burner currently used
	CASE burnerExclusivelyUsed 
		Info("The burner is currently used")
	CASE burnerPrepareErasing
		Info("Preparing to erase")
	CASE burnerPrepareBurning
		Info("Preparing to burn")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = BurnerStatus()`
---

**`<Result>: (Integer constant)`**



- Current status of the burner: 
	The burner can be in one of the following states:
	


|   |   |
| --- | --- |
| *burnerBurn* | Burn process in progress |
| *burnerExclusivelyUsed* | Burner currently used by the current application or by another application |
| *burnerInactive* | Burner disabled |
| *burnerPrepareBurning* | Burner being prepared to burn files |
| *burnerPrepareErasing* | Burner preparing to erase some files |



- -1 if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

## Remarks




### Required configuration 
<a name="required_configuration_ELTPARAGRAPHE000068"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Burning CDs is available for Windows XP and later. Burning DVDs is available for Windows Vista and for Windows XP when using the KB932716 update for Windows XP (this update must be downloaded from the Microsoft site and installed manually because it is not taken into account by the Live Update mechanism).   ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The CDs and the DVDs will be burned on the Web server. To burn CDs or DVDs, the server must be running Windows XP or later. To burn CDs in Windows 2003 Server, the IMAPI burn service (named "IMAPI CD-burning COM service") must be enabled. To burn DVDs in Windows 2003 Server, you also have to install the KB932716 update.
