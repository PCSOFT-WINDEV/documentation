
## gpwAuthLogin (Function)

***In french: gpwAuthLogin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to log in to the User Groupware using an account such as Facebook, Google, Microsoft, etc. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
```wl
Identity is OpenIDIdentity = gpwAuthLogin(gpwFacebook)
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
arrOAuthParam is array of gpwOAuthParameters
arrOAuthParam = gpwListOAuthParameters()
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END

Parameters is gpwOAuthParameters = arrOAuthParam[1]
sCode is string = gpwAuthLogin(Parameters)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END

User is gpwUser
sToken is string
(sToken, User) = gpwRemoteConnect(Parameters, sCode)
IF ErrorOccurred THEN
	Error(ErrorInfo())
	RETURN
END
```

## Syntax
<a name="SYNTAXE1"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) 
`<Result> = gpwAuthLogin(<Type> [, <Index>])`
---

**`<Result>: (OpenIDIdentity variable)`**

[OpenIDIdentity](../WDLang3/1000023567.md) variable that contains the user information.

**`<Type>: (Integer constant)`**

Type of login that allows for authentication: 


|   |   |
| --- | --- |
| *gpwConnection* | Standard login with a user that has been created and registered. |
| *gpwFacebook* | Login with a Facebook account. |
| *gpwGoogle* | Login with a Google account. |
| *gpwMicrosoft* | Login with a Microsoft MSN account. |
| *gpwSalesforce* | Login with a Salesforce account. |
| *gpwYahoo* | Login with a Yahoo account. |



**`<Index>: (Optional integer)`**

Index of the custom connection when adding it with [gpwAddAuthLogin](../WDLang6/1000023576.md). To use this parameter, &lt;Type&gt; must correspond to the *gpwConnection* constant. 
Note: Login information is defined and added using [gpwAddAuthLogin](../WDLang6/1000023576.md).


<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
`<Result> = gpwAuthLogin(<Parameter>)`
---

**`<Result>: (Buffer)`**

User identification code to use with [gpwRemoteConnect](../WDLang6/1000024855.md). 

**`<Parameter>: (gpwOAuthParameters variable)`**

Name of the [gpwOAuthParameters](../WDLang6/1000024751.md) variable that contains the characteristics of the OAuth application to use for authentication.

## Remarks


### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000110"></a>

If a login error occurs, the  variable is set to <u><u><u><u>True</u></u></u></u>. The error can be identified using [ErrorInfo](../WDLang1/3013008.md).

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000263"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**gpwAuthLogin** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
