
## gpwCheckUser (Function)

***In french: gpwVérifieUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence and validity of the password for a user of the User Groupware.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
nRes is int = gpwCheckUser(Login, Password)
// If the login failed
IF nRes <> gpwOK THEN
        SWITCH nRes
                CASE gpwErreur: Error("Error initializing groupware.")
                CASE gpwUserUnknown: Error("User unknown.")
                CASE gpwPasswordInvalid: Error("Invalid password.")
        END
        EndProgram()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = gpwCheckUser(<Login> , <Password>)`
---

**`<Result>: (Integer)`**

Result of the check: 


|   |   |
| --- | --- |
| *gpwError* | An error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md). |
| *gpwInvalidPassword* | The user password is not valid. It does not match the user password described in the User Groupware database.  |
| *gpwOK* | The user is logged in. |
| *gpwUnknownUser* | The user is unknown: it is not present in the User Groupware database. |



**`<Login>: (Character string)`**

Username. 

**`<Password>: (Character string)`**

Password associated with the username.
