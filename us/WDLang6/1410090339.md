


## &lt;pdfDocument variable&gt;.Sign (Function)

***In french: &lt;Variable pdfDocument&gt;.Signe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an approval signature to an existing PDF.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPDF is pdfDocument
MyPDF = "c:\temp\MyPDFDocument.pdf"
MySignature is pdfSignature
MyCertificates is array of Certificates = CertificateLoad("test.pfx", "pwd")
MySignature..Certificate = MyCertificates[1]
// This is an approval signature, it must have a minimum size of 1X1
MySignature.X = 1
MySignature.Y = 1
MySignature.Height = 1
MySignature.Width = 1
mypdf.Sign(MySignature)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE2"></a>

`<Result> = <PDF document>.Sign(<Signed PDF file> , <Signature> , <Signature mode>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the PDF file was signed,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<PDF document>: (pdfDocument variable)`**

Name of the [pdfDocument](../WDLang6/1000024909.md) variable that corresponds to the PDF document to be signed.

**`<Signed PDF file>: (Character string)`**

Name and path of the signed PDF file.

**`<Signature>: (pdfSignature variable)`**

Name of the [pdfSignature](../WDLang6/1000022255.md) variable corresponding to the description of the approval signature to be added to the PDF file.

**`<Signature mode>: (Integer constant)`**

Signature format to use: 

- PAdES (PDF Advanced Electronic Signatures):
	


|   |   |
| --- | --- |
| *iSignature_CAdES_B* | CAdES Basic (CMS Advanced Electronic Signature). |
| *iSignature_CAdES_C* | CAdES C (CMS Advanced Electronic Signature). |
| *iSignature_CAdES_T* | CAdES Trust token (CMS Advanced Electronic Signature). |
| *iSignature_CAdES_X* | CAdES X Type 2 (CMS Advanced Electronic Signature).  |
| *iSignature_CAdES_XL* | CAdES XL Type 2 (CMS Advanced Electronic Signature). |



- Adobe signature format: 
	


|   |   |
| --- | --- |
| *iSignature_PKCS7*<br>(default value) | PKCS7 signature. This is an Adobe standard format not approved by the ETSI and Chorus standards. |








<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The signature added by **&lt;pdfDocument variable&gt;.Sign** is an approval signature. The PDF file can be signed and countersigned several times.

- This signature must correspond to a control in the PDF file (its must have a minimum size of 1 X 1 mm²). The Signature control can be invisible but it should be associate it with a label or image so that the user can see the signature and click on it. 

- **&lt;pdfDocument variable&gt;.Sign** cannot be used to sign a PDF file with a certificate-based signature. You need to use [iPrintSignature](../WDLang5/1000021690.md), which allows both methods.

- Encrypted PDFs (password protected) are not supported. 

- PDF files with versions higher than PDF 1.5 will be saved in PDF 1.4 before being signed. 

- **Attention**: For a signed PDF file to be recognized by Acrobat, the organization issuing the signature certificate must be a member of the AATL list ([Adobe Authorized Trust List](https://helpx.adobe.com/acrobat/kb/trust-services.html)) or the CDS (Certified Document Services) program.. 
	If the certificate is not recognized, Acrobat will display the following message: "At least one signature has problems".
