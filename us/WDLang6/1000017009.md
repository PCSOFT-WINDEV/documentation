


## ValidatePassword (Function)

***In french: ValideMotDePasse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates whether the specified password is valid for the current user. The password can be:

- the Windows authentication password

- the password of the WINDEV/WEBDEV User Groupware.

- the password used to lock applications (password specified with [LockAppPassword](../WDLang6/1000017010.md)).




![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is only available to check if the password is valid for the User Groupware. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF ValidatePassword("MyPassword") = True THEN
	Info("User validated")
ELSE
	info("Invalid password")
END
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ValidatePassword(<Password> [, <Authentication>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the password is correct, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Password>: (Character string or Secret string)`**

Password to validate for the current user.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Authentication>: (Optional Integer constant)`**

Password authentication method:



|   |   |
| --- | --- |
| *pwdCustom* | Authentication performed according to the password specified in [LockAppPassword](../WDLang6/1000017010.md).<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *pwdGpw* | Authentication performed by the WINDEV/WEBDEV User Groupware. |
| *pwdWindows* | Authentication performed according to the Windows password.<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |


If &lt;Authentication&gt; is not specified:

- If [LockAppPassword](../WDLang6/1000017010.md) was used, this password is checked.

- If the User Groupware is enabled, the password is checked in relation to the User Groupware.

- Otherwise, the password is checked against the Windows account.
