
## PDFClose (Function)

***In french: PDFFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Closes the PDF file loaded in memory in a [pdfDocument](../WDLang6/1000024909.md) variable. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyPDF is pdfDocument = "test.pdf"
FOR EACH DocumentPage OF MyPDF.Page
	Trace(DocumentPage.Height)
END
PDFClose(MyPDF)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PDFClose(<PDF to close>)`
---

**`<PDF to close>: (pdfDocument variable)`**

Name of the [pdfDocument](../WDLang6/1000024909.md) variable that corresponds to the PDF file to close.

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Starting with version 28, this function is not supported by 32-bit ARM processors. New PDF features require a 64-bit execution mode. 
If an application is to be run on devices with 32-bit ARM processors, it must be generated with WINDEV Mobile 27.
