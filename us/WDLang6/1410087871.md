


## &lt;pdfPage variable&gt;.AddWatermark (Function)

***In french: &lt;Variable pdfPage&gt;.AjouteFiligrane***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a watermark to a page of an existing PDF file.

Note: This function can be used multiple times on the same page to add different watermarks.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWatermark is Watermark
MyWatermark.Text = "Confidential"
MyWatermark.Font.Name = "Arial"
MyWatermark.Position = iCenterH + iBottom

MyPDF is pdfDocument = fExeDir() + [fSep()] + "RPT_NoName1.pdf"

// Add watermark to one page of the PDF document
MyPDF.Page[1].AddWatermark(MyWatermark)

PDFSave(MyPDF, fExeDir() + [fSep()] + "RPT_NoName1_With_Watermark.pdf")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Page>.AddWatermark(<Watermark>)`
---

**`<Page>: (pdfPage variable)`**

Name of the [pdfPage](../WDLang6/1000024904.md) variable that corresponds to the page of the PDF file in which the watermark is to be added.

**`<Watermark>: (Watermark variable)`**

Name of the [Watermark](../WDLang5/1000019922.md) variable that corresponds to the watermark to be added to the page.
