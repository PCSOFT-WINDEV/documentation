## Behavior changes between versions 2024 and 2025
<a name="behavior_changes_between_versions_2024_and_2025_ELTTEXTE000138"></a>


- UWP is no longer supported. 

- PHP: The minimum version supported for the PHP server is now PHP 7 (recommended minimum version: 7.0.22). 

- To create an Image Editor control in WEBDEV, go to the "Creation" tab, "Graphic controls" group, expand "Advanced", and then select "Image Editor". 

- "Favorite controls" are now "Preset controls". 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Bar code decoding: 

	- Until version 2025, bar codes are decoded using the Zxing library ([http://code.google.com/p/zxing](http://code.google.com/p/zxing)). 

	- Starting with version 2025 - Update 1, bar codes are decoded using ML Kit's bar code scanning API.




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Minimum supported version: 

	- Until version 2025, the minimum version required to run the application was Android 6.0. 

	- Starting with version 2025 - Update 1, the minimum version required is Android 7.0.




- **Starting with WINDEV Suite 2025 Update 1 (Subscription version)**, it is possible to use the new features specific to subscription in projects in Subscription mode. For more details, see [Using new features exclusive to the subscription-based version of WINDEV Suite 2025](../Editeurs/1410087359.md).

- **Starting with version 2025 - Update 1**, the [MapChangeStyle](../WDLang3/1000025556.md) and [MapGetStyle](../WDLang3/1000025557.md) functions have been deprecated. To define the styles of a Map control, use the new [MapIDGgl](../WDLang3/1410091136.md) function. 

- **Manipulating a group of controls in a dynamic undockable tab**

	- Before version 2025 - Update 2, manipulating a group of controls from the internal window of a tab also affected all the groups of controls of the same name present in the window, or in other dynamic tabs. 

	- Starting with version 2025 - Update 2, manipulating a group of controls from the internal window of a dynamic tab affects only the current internal window. If there are other groups of controls with the same name in the main window, they will not be modified. 




- **From version 2025 - Update 3**, Java Web Start generation is no longer supported.
