<a name="Procedures_reactives_en_Mobile"></a>

	
		MOBILE REACTIVE PROCEDURES
	

	
		 
	
		A powerful concept
	

	
		Reactive Procedures first appeared in WINDEV. 
In version 2026, they are now available on mobile. 
Reminder: a Reactive Procedure is executed when a variable or the value or content of a field used in the procedure is modified, either by the end user or by programming. 
The Reactive Procedure constantly "observes" the variables and fields concerned to detect changes in value, and in this case executes automatically 
A variable or field changes? The Procedure is executed! 

	


 
	
		Unique and centralized code
	

	
		The main advantage of this Reactive Procedure method is that monitoring the change in value of a field is delegated to the. 
There's no need to write the calls in every control where changes can be made. 
Resource consumption is zero, because the framework takes care of everything in an optimized way: it's the field (or variable) that automatically signals its change of value to the Reactive Procedure. 
The single, clear code of the Reactive Procedure makes it possible to "monitor" and update several different fields and variables without a single line of code! 

	


 
	
		How to declare a reactive procedure
	

	
		The Reactive keyword indicates that the procedure should monitor the variables and fields used in its code. 
And, of course, to execute in the event of a modification. 


- REACTIVE PROCEDURE: CalculateTTC()


A Reactive Procedure can be global (and therefore permanently reactive), local to a window or local to a control. 

	


 
	
		Reactive procedure options
	

	
		Reactive Procedures offer 2 options: 


- Deadline: to execute after a given deadline. For example, the procedure will execute 100 milliseconds after a value change

- Execution: a Reactive Procedure can be programmatically triggered.



	


 
	
		Cascade
	

	
		A Reactive Procedure can modify a variable or a field used by another Reactive Procedure. 
In this case, the other Reactive Procedure will run. 
The framework implements the necessary security mechanisms to avoid calls in a loop, for example.

<a name="Gemini"></a>

	
		TRIGGER ACTIONS BY VOICE (GEMINI)
	

	
		 
	
		Trigger actions by voice (or according to a "prompt" entered in its app)
	

	
		<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=iA%20Gemini%20Mobile.png)
You're probably familiar with Gemini, Google's AI, integrated into many Android-based devices. 
In version 2026, WINDEV Mobile enables you to integrate Gemini calls directly into your applications, and to Execute application actions. 

	


 
	
		A concrete example of use 
	

	
		An elevator repairman can ask your app "Show me the manual for the elevator in shaft A of the Snoopy residence, 43 rue de la niche, Woodstock". 
Of course, in this case, it means that this record is present in your database. 

	


 
	
		How it works
	

	
		The principle is straightforward: 


- Your application needs to anticipate the requests it can handle. Each request corresponds to a WLanguage procedure.

- The new GeminiAnalyzePrompt WLanguage function enables AI to be triggered by text dictated or input by the user.

- The AI will search for the procedure corresponding to the request and execute it.



	


 
	
		Specific procedures
	

	
		To define that a procedure can be used by Gemini, simply indicate what the procedure does and what its parameters correspond to between the tags &lt;IA&gt; and &lt;FIN&gt; . 
In our previous example, the procedure description will be "Retrieves an elevator record based on its address and shaft location" . 
This procedure will accept 2 parameters, the address and the cage. Each parameter has a description. For example, the address description could be "Complete address of the building to which the elevator belongs" . 

	


 
	
		Total customization
	

	
		It is of course possible to create as many procedures as required in an application. 
Note: the number of free calls to Gemini is limited by Google. Obtaining the Google API key is currently free of charge. 
When the number of tokens used exceeds a certain limit within a defined period, a paid subscription is required.
