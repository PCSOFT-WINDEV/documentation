## Starting a distributable tool in command line
<a name="starting_distributable_tool_command_line_ELTTEXTE000470"></a>
The following code enables you to start a distributable tool in command line:


```wl
sPath is string
sPath = """" + CompleteDir(SysDir(srCommonProgramFiles)) + ...
	"PC SOFT\<Tool version>\<Tool name>\<Tool name>.exe"""
ExeRun(sPath)
```


Where:

- &lt;Tool version&gt;: Version number of the tool used (e.g., "31.0" for a tool provided with WINDEV 2026).

- &lt;Tool name&gt;: Name of the desired tool (e.g., "WDLog").
