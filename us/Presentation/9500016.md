<a name="nouveau_champ_cellule"></a>

	
		NEW CELL CONTROL
	

	
		 
	
		The WINDEV Cell control: an easy-to-use container
	

	
		WINDEV 2024's new Cell control makes it possible to group together a set of fields. 
This allows them to be manipulated simultaneously for editing and programming.. 
The Cell control field is styled, allowing all fields to be highlighted: frame, background color, etc.
A Cell can also be used to group fields which will be used in a Flexbox field, and which will therefore be positioned in fixed coordinates in the cell. 
The Cell control field can have several planes, independently of the host window.. 
The Cell control can be anchored to the content: the Cell control automatically enlarges when the fields contained in the cell are enlarged. 
On a cross-platform level, it works in the same way as WEBDEV's Cell control.

		FLEXBOX IN WINDEV EXAMPLES
	

	
		 
	
		Flexbox overview
	

	
		Flexbox is an adaptive layout method that allows controls to be positioned relative to each other. 
Although it is mostly used in web applications, this mode is also used on Windows and mobile devices, for controls with dynamic content (e.g., long text spanning over several lines or translation into several languages), or when a window is resized. 
Controls are laid out in rows or columns, according to precise rules which are cumulative. 
Positioning is relative rather than pixel-based. 
Flexbox can be used on the entire window, or only on a group of controls. 
A familiar example is the repositioning of fields in the Windows 11 settings window.

For more details, see [The Flexbox control](../WDChamp/1410087274.md). 
	


 
	
		Available rules
	

	
		A Flexbox control can be considered as a box. 
Controls are positioned one after another, within a box (Flexbox control). 
Important point: one or more of these fields may themselves be Flexbox control fields. 
First, indicate how controls should be positioned within each box: In rows or columns. 
You must then indicate how the fields will behave when the box or fields are resized: return to line or not, enlargement, reduction, etc. 
Apply this method to as many controls as necessary to define their positioning and resizing behavior. 
An elevator appears automatically if required. 
Behaviours are easily defined thanks to the 7-tab visual technology, which proposes all possible behaviours. 

For more details, see [The Flexbox control](../WDChamp/1410087274.md). 
	


 
	
		Examples of local use
	

	
		Multilingual: texts translated into different languages are almost always different lengths! Buttons change size: the enlarging button pushes the other button. 
To keep buttons aligned at the bottom right of the window when translating and/or enlarging or reducing the window, a Flexbox control is the ideal solution.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WD-Flexbox-2-boutons-1.png)<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=WD-Flexbox-2-boutons-2.png)


For more details, see [The Flexbox control](../WDChamp/1410087274.md). 
	


 
	
		Window application
	

	
		Using flexboxes to organize an entire window solves the problem of repositioning when changing window size.

For more details, see [The Flexbox control](../WDChamp/1410087274.md).
