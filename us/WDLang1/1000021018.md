


## OpenMobileWindow (Function)

***In french: OuvreFenêtreMobile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a window in a mobile application. 

Remarks: 

- This function replaces [OpenChild](../WDLang1/3038021.md) used to open windows in a mobile application. Only the mobile feature will be presented in this documentation page. For more details, see [OpenChild](../WDLang1/3038021.md).  

- **OpenMobileWindow** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **OpenMobileWindow** can be shared between several products without generating any compilation error.


**Remarks**:

- By default, the window retains focus once open.

- **OpenMobileWindow** can also be used to pass parameters to the child window.

	- In standard syntax, these parameters are passed directly. 

	- When you use a variable of type [Window](../WDLang1/1410091366.md) to open a window, you can use the [OpeningParameters](../Proprietes/1410091044.md) property to pass parameters.

```wl
OpenMobileWindow(WIN_EditOrder, gnOrderID)
```

```wl
MyMobileWindow.OpeningParameters.OrderNumber = gnOrderID

```

## Syntax

### Opening a window (standard syntax)

`OpenMobileWindow(<Window> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window>: (Window name)`**



- Name of the mobile window to open.

- Name and full path of the window (".WDW" file) to be opened.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) You cannot specify the full name of the file to open (".WDW" file).




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).


<a name="SYNTAXE2"></a>
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This syntax is only available for Java applications
### Opening a window (with a Window variable)

`OpenMobileWindow(<Window to open> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window to open>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened.  

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property.  




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

## Remarks


### Parameters passed to the window to open
<a name="parameters_passed_the_window_open_ELTPARAGRAPHE000416"></a>The parameters are retrieved in the "Global declarations" event associated with  the window. The first line of code of this event must correspond to the following line:


```txt
PROCEDURE <Window> (<Parameter 1> [, ... [, <Parameter N>]])
```
where: 

- &lt;Window&gt; must correspond to the name of the window. 

- &lt;Parameter N&gt; must correspond to the parameters expected. **Note: These parameters are passed by value, not by reference.**


For more details, see [Window with parameters](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Window opening mode
<a name="window_opening_mode_ELTPARAGRAPHE000188"></a>

The window opens as a non-modal window:

- the opened window becomes the current window.

- after the window opening, the processes following the call to **OpenMobileWindow** in the parent window are run.

- the user will have the ability to click one of the parent windows of opened window. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The controls found in the parent windows cannot be accessed by the user as long as a child window is opened. 



<a name="NOTE0_3"></a>


### Limitation
<a name="limitation_ELTPARAGRAPHE000207"></a>

**OpenMobileWindow** must not be called in the "Initialization" event associated with the project.
<a name="NOTE0_6"></a>


### Closing a window
<a name="closing_window_ELTPARAGRAPHE000218"></a>

A window opened with **OpenMobileWindow** can be closed with [Close](../WDLang1/3038018.md) (without parameters) from any event associated with the window or a control in the window.
<a name="NOTE0_7"></a>


### Title of the window to be opened
<a name="title_the_window_opened_ELTPARAGRAPHE000464"></a>

By default, the window title is the one defined in the editor (in the "General" tab of the description window).

To change the window title:

- In standard syntax, use [NextTitle](../WDLang1/3038043.md) or [CurrentTitle](../WDLang1/3038023.md).

- With a variable of type [Window](../WDLang1/1410091366.md), use the [OpeningOptions](../Proprietes/1410091299.md) property (**OpeningOptions.Title**).

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000245"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**OpenMobileWindow** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
