


## VideoParameter (Function)

***In french: VidéoParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns or modifies the value of a parameter for the device camera.


	<B><B><B>Warning</B></B></B>

	 ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Starting with version 27, this function is ignored for Android and iOS applications**. This function is kept only for Camera controls from earlier versions and with the "Version-26-compatible mode" option enabled ("General" tab of the control description window).



**Remarks**: 

- To find out the list of values supported by the camera for a given parameter, use [VideoListParameter](../WDLang1/1000019695.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **VideoParameter** can be used in the Android emulator but not in the simulator.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Use the maximum resolution to take a photo
sListResolution is string 
sListResolution = VideoListParameter(vipPhotoResolution)
IF ErrorOccurred = False THEN
	VideoParameter(vipPhotoResolution, ExtractString(sListResolution, lastRank, CR))
ELSE
	Error("Error while retrieving the resolutions supported by the camera.")
END

// Use the maximum zoom value
sListZoom is string
sListZoom = VideoListParameter(vipZoom)
IF ErrorOccurred = False THEN
	nZoom is int = Val(ExtractString(sListZoom, lastRank, CR))
	IF VideoParameter(vipZoom, nZoom) = False THEN
		Error("The camera cannot zoom.")
	END
END

// Geolocation of photos taken by the camera
MyPosition is geoPosition = GPSGetPosition()
VideoParameter(vipGeoPosition, MyPosition)

// Set the ISO sensitivity
VideoParameter(vipISO, 800)
```

### Retrieving the value of a parameter for the device camera

`<Result> = VideoParameter(<Parameter>)`
---

**`<Result>: (Type of retrieved parameter)`**



- Parameter value, 

- Empty string ("") if the specified parameter is not supported by the camera or if an error occurred while retrieving the camera parameters.




If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

**`<Parameter>: (Character String constant or character string)`**

Parameter for which the value will be retrieved. This parameter can correspond to: 

- one of the preset constants. These constants correspond to the most common parameters. 

- a String corresponding to the name of the desired parameter. 
	**Caution**: parameter name is case sensitive and accentuated. See the documentation about the Android SDK or about the device to find out the name of additional supported parameters. If the specified name does not correspond to a parameter supported by the camera, the function will return an empty string.


The available constants are as follows:

| --- | --- |
| *vipBalance* | White balance mode currently supported by the camera: automation, daylight, cloudy, ...<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *vipCamera* | Index of camera currently used:<br><br>- Subscript between 1 and the number of cameras found on the device.<br><br>- -1 if no camera is currently used.<br><br><br> |
| *vipCompressionJPEG* | Compression of JPEG images, corresponding to an integer between 1 and 100.<br><br>- 1: Maximum compression (low quality)<br><br>- 100: No compression (very high quality)<br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *vipEffect* | Color effects currently supported: black and white, poster, sepia, ...<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |

### Modifying the value of a parameter for the device camera

`<Result> = VideoParameter(<Parameter> , <Value>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the parameter has been modified successfully, 

- <u><u><u><u>False</u></u></u></u> otherwise or if an error occurred while retrieving the camera parameters. For example, **VideoParameter** will return <u><u><u><u>False</u></u></u></u> if the specified parameter (or its value) is not supported by the camera.




If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).
