
## Confirm (Function)

***In french: Confirmer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a message in a standard dialog box with the "Yes", "No" and "Cancel" options, and returns the user's choice. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=fonctions_dialogue%20-%20HC%20N%B0005.gif)


Remarks: 

- **This is a modal warning window**. To continue running the application, the user must validate one of the buttons. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To avoid blocking the application, use [ConfirmAsynchronous](../WDLang1/1000025305.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV allows you to apply the skin template of your project to this dialog box. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
Res is int 
NextTitle("Edit form")
Res = Confirm("Changes have been made to the form.", ...
	"Save changes before closing?")
SWITCH Res 
	CASE Yes: SaveForm() // Save process
	CASE No: Close()
	CASE Cancel: SetFocusAndReturnToUserInput()
END
```

```wl
Res is boolean
Res = Confirm("Do you want to load this page?") 
IF Res = True THEN
	// User validation
ELSE
	// No user validation
	SetFocusAndReturnToUserInput("VALIDBTN")
END
```

### Displaying a Confirm dialog box

`<Result> = Confirm([<Selected button>, ] <Text> [, <Line 2> [... [, <Line n>]]])`
---

**`<Result>: (Integer constant)`**

Identifies the button selected by the user:


|   |   |   |
| --- | --- | --- |
| *No* | 0 | The user selected [NO]. |
| *Yes* | 1 | The user selected [YES]. |
| *Cancel* | 2 | The user selected [CANCEL]. |



**`<Selected button>: (Optional integer constant)`**

Button selected by default in the dialog box:


|   |   |   |
| --- | --- | --- |
| *No* | 0 | selected by default. |
| *Yes*<br>(Default value) | 1 | selected by default. |
| *Cancel* | 2 | selected by default. |



**`<Text>: (Character string)`**

Text to display.

**`<Line 2>: (Optional character string)`**

Text displayed on the second line.



**`<Line n>: (Optional character string)`**

Text displayed on the Nth line.

## Remarks


### Features of the dialog box
<a name="features_the_dialog_box_ELTPARAGRAPHE000178"></a>

- The message is aligned to the left.

- The text of the buttons changes according to the language used by Windows at runtime (or used by the browser, in the case of a WEBDEV website).

- The maximum number of characters cannot exceed 4096. If a larger string is passed as parameter, it will be truncated.

- The icon displayed (exclamation mark in a WINDEV application, question mark in a WEBDEV application) cannot be modified.




- The title of the dialog box corresponds to the title of the current window (or page).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To comply with the system specifications, the title of dialog box is empty by default. To define this title, use [NextTitle](../WDLang1/3038043.md).

- To modify or define the title of dialog box, use [NextTitle](../WDLang1/3038043.md).




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To customize this dialog box** (and all the system dialog boxes in your application), check "Customize system windows (Info, YesNo, Confirm, Dialog)" in the "Style" tab of the project description. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **To customize this dialog box** (and all the system dialog boxes in your site), check "Apply the skin to the dialog boxes (YesNo and OKCancel)" in the "Skin" tab of the project description window. 
<a name="NOTE0_2"></a>


### Line break in the dialog box
<a name="line_break_the_dialog_box_ELTPARAGRAPHE000194"></a>

The CR string (Carriage Return) can be used to force a break to the next line. For example:


```wl
Confirm("The XXX form was modified." + CR + ...
	"Do you want to save it before exiting?")
```


is equivalent to:


```wl
Confirm("The XXX form was modified.", ...
	"Do you want to save it before exiting?")
```


You also have the ability to use the syntax of multiline strings. For example: 


```wl
Confirm(
[
The XXX form has been modified.

Do you want to save changes before closing?
])
```

<a name="NOTE0_3"></a>




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000212"></a>

- Timers ([TimerSys](../WDLang1/3015006.md)) are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Windows events are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) [DelayBeforeClosing](../WDLang1/3038040.md) limits how long the message is displayed. The dialog box is automatically closed. For question or confirmation dialog boxes, the default button corresponds to the expected answer.

- The text of the buttons is displayed in the system language.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) If your project uses pre-launched sessions, this function must not be used in the project initialization event. This function must be used in the "Initialization in pre-launched session mode" event.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function must not be used: 

	- in the "Resize" event of the window. Otherwise, the application will be locked.

	- in the "Change the orientation" event of the window. 

	- in the "Move to the foreground" event associated with the project. 
			Note: However, the function can be used in the "Move to the foreground" event of a window. 

	- in a thread.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000453"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**Confirm** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
