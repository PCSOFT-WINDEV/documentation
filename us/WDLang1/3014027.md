


## InAutomaticTestMode (Function)

***In french: EnModeTestAutomatique***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out whether an automated test is currently run or not.

**Note**: Automation tests can only be run on windows, classes or procedures.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF InAutomaticTestMode() = True THEN 
	Trace("Variable NumClient: " + NumClient)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = InAutomaticTestMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if an automation test is in progress, 

- <u><u><u><u>False</u></u></u></u> otherwise.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Function availability
<a name="function_availability_ELTPARAGRAPHE000202"></a>

**InAutomaticTestMode** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **InAutomaticTestMode** can be shared between several products without generating any compilation error.
