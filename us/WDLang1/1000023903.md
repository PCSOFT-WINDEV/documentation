


## &lt;Window&gt;.Open (Function)

***In french: &lt;Fenêtre&gt;.Ouvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a modal WINDEV window.

When **&lt;Window&gt;.Open** is called, the following events and actions are executed:

- the "Global declarations" event of the window,

- the "Initialization" events of the controls in the window (in any order),

- the window "Initialization" event,

- the window is displayed (it becomes the current window).


For more details on the events associated with a window, see [Events associated with a window](../WDChamp/1010021.md).

**Remarks**:

- The controls in the previous window are disabled.

- **&lt;Window&gt;.Open** can also be used to define the position and pass parameters to the window.

	- In standard syntax, these parameters are passed directly. 

	- When you use a variable of type [Window](../WDLang1/1410091366.md) to open a window, you can use the [OpeningOptions](../Proprietes/1410091299.md) property to define the characteristics of the window, and the [OpeningParameters](../Proprietes/1410091044.md) property to pass parameters. 
			







![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In Java, modal windows appear in the taskbar.

**Mobile platforms**: 

- **iOS**: **&lt;Window&gt;.Open** is not available. Use [&lt;Window&gt;.OpenMobileWindow](../WDLang1/1000023887.md) instead.

- **Android**: **&lt;Window&gt;.Open** is not recommended. We recommend that you use [&lt;Window&gt;.OpenMobileWindow](../WDLang1/1000023887.md). If it is necessary to process the value returned by the window, use the "Close a child window" event of the calling window.

In a WEBDEV website, this function has the same behavior as [&lt;Page&gt;.DisplayDialog](../WDLang2/1000021663.md).

## Example


```wl
// Open and reposition the "WIN_Edit" window
// The Value1 and Value2 parameters are passed to the event
// "Global declarations" of "WIN_Edit"
// ReturnedValue will retrieve the returned value
// when the "WIN_Edit" window is closed
ReturnedValue = WIN_Edit.Open(Value1, Value2)
```
<a name="3038035_Exemple2"></a>
<a name="3038035_Exemple3"></a>

```wl
// Set window opening options
My_Exe_Window is Window WIN_Main
My_Exe_Window.OpeningOptions.X = 50
My_Exe_Window.OpeningOptions.Y = 100
My_Exe_Window.OpeningOptions.Animation = waRotationX + waMorphCylinder
// Open window
My_Exe_Window.Open()
```

## Syntax

### Opening a modal window (standard syntax)

`<Result> = <Window>.Open([<Parameter 1> [... [, <Parameter N>]]])`
---

**`<Result>: (Type corresponding to the retrieved value (optional))`**

Value returned by the popup window when it is closed. This value is returned:

- by the [RETURN](../Motscles/1510007.md) keyword in the window "Close" event,

- by the [Close](../WDLang1/3038018.md) function,

- by the [ReturnedValue](../Proprietes/2510134.md) property used before closing the window.




**`<Window>: (Window name)`**

Name of the window to be opened.

By default, the window is displayed according to the position defined in the editor. 

**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.


<a name="SYNTAXE2"></a>
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This syntax is only available for Java applications
### Opening a modal window (with a Window variable)

`<Result> = Open(<Window to open> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Result>: (Type corresponding to the retrieved value (optional))`**

Value returned by the popup window when it is closed. This value is returned:

- by the [RETURN](../Motscles/1510007.md) keyword in the window "Close" event,

- by the [Close](../WDLang1/3038018.md) function,

- by the [ReturnedValue](../Proprietes/2510134.md) property used before closing the window.




**`<Window to open>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened.  

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property.




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

## Remarks


### Parameters passed to the window to open
<a name="parameters_passed_the_window_open_ELTPARAGRAPHE000424"></a>The parameters are retrieved in the "Global declarations" event associated with  the window. The first line of code of this event must correspond to the following line:


```txt
PROCEDURE <Window> (<Parameter 1> [, ... [, <Parameter N>]])
```
where: 

- &lt;Window&gt; must correspond to the name of the window. 

- &lt;Parameter N&gt; must correspond to the parameters expected. **Note: These parameters are passed by value, not by reference.**


For more details, see [Window with parameters](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Window opening mode
<a name="window_opening_mode_ELTPARAGRAPHE000454"></a>

The window is opened in modal mode:

- the result of **&lt;Window&gt;.Open** will be known once the window is closed,

- the user will not be able to click in one of the parent windows of the current window.




To manage modeless windows, use [&lt;Window&gt;.OpenChild](../WDLang1/1000023904.md) or [&lt;Windows&gt;.OpenSibling](../WDLang1/1410086669.md).

To manage MDI, use [&lt;Window&gt;.MDIOpen](../WDLang1/3052007.md).
<a name="NOTE0_3"></a>


### Number of opened windows
<a name="number_opened_windows_ELTPARAGRAPHE000488"></a>

The number of windows that can be opened simultaneously depends on the available memory.
<a name="NOTE0_4"></a>


### Closing a window
<a name="closing_window_ELTPARAGRAPHE000498"></a>

A window opened with **&lt;Window&gt;.Open** can be closed with [Close](../WDLang1/3038018.md) (without parameters) from any event associated with the window or a control in the window.

If a parent window is closed, its child windows are also closed.
<a name="NOTE0_5"></a>


### Title of the window to be opened
<a name="title_the_window_opened_ELTPARAGRAPHE000517"></a>

By default, the window title is the one defined in the editor (in the "General" tab of the description window).

To change the window title:

- In standard syntax, use [NextTitle](../WDLang1/3038043.md) or [CurrentTitle](../WDLang1/3038023.md).

- With a variable of type [Window](../WDLang1/1410091366.md), use the [OpeningOptions](../Proprietes/1410091299.md) property (**OpeningOptions.Title**).

### Minimized window
<a name="minimized_window_ELTPARAGRAPHE000559"></a>

If the current window is minimized, the entire project is minimized.

The displayed icon is:

- the one of the current window if the current window has an icon, 

- the one of the current project if the current window has no icon.



<a name="NOTE0_7"></a>


### Opening the window of a component
<a name="opening_the_window_component_ELTPARAGRAPHE000574"></a>To open the window of a component, simply use the name of the component window (component included in the project). For example:

```wl
ComponentWindow.Open()
```
If a conflict occurs with a project element, the name of the element must be prefixed by the name of the component. For example:

```wl
MyComponent.Window.Open()
```
To use the name of the window in a variable, specify the name of the component. For example:

```wl
sWindow is string = "MyComponent.MyWindow"
sWindow.Open()
```
