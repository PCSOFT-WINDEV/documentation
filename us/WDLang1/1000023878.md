


## &lt;Treeview&gt;.ItemStatus

***In french: &lt;Arbre&gt;.EtatElément***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the state of a node: wound, unwound or non-existent.

Example of TreeView control: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Arbre_Vocabulaire.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Status of the "Desserts" node in the "TREE_TVRecipe" TreeView control 
ResStatus = TREE_TVRecipe.ItemStatus("Recipes" + TAB + "Desserts")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <TreeView control>.ItemStatus(<Node>)`
---

**`<Result>: (Integer constant)`**

Node status.


|   |   |
| --- | --- |
| *tvCollapse* | The node is collapsed. |
| *tvError* | Node not found. |
| *tvExpand* | The node is expanded. |



**`<TreeView control>: (Control name)`**

Name of the TreeView control to be used.

**`<Node>: (Character string)`**

Path of node to use. This parameter has the following format:

```txt
"<Root name>" + TAB + ["<Name of 1st node>" + TAB + ...
["<Name of 2nd node>" + TAB + [...]]]"<Leaf name>"
```
If there are two elements with the same name in the path, you can add the IDs of the elements (after their names using [TreeID](../WDLang1/3018027.md)).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### A collapsed or expanded node can be visible or not
<a name="collapsed_expanded_node_can_visible_not_ELTPARAGRAPHE000192"></a>

The status returned corresponds to the internal status of the element. An expanded element is not necessarily visible because one of its parents may be collapsed.

For example: If the node "Recipes" + TAB + "Desserts" is rolled up, the node "Recipes" + TAB + "Desserts" + TAB + "Ice cream" can be rolled up or unrolled.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ArbreEtat.gif)
