


## PVTSave (Function)

***In french: TCDSauve***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves the result of the calculation performed in a Pivot Table control (in a file or in memory). This result can be loaded again in a Pivot Table control using [PVTLoad](../WDLang1/1000020507.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sFile is string
// Builds the file name
sFile = SysDir(srAppData) + ["\"] + "StatsByCountry.tcd"

// The file exists?
IF fFileExist(sFile) THEN
	// Yes, load it 
	PVTLoad(PVT_Statistics, sFile)
	IF YesNo("Do you want to recalculate everything?") THEN PVTCalculateAll(PVT_Statistics)
ELSE
	// The file does not exist. It is going to be calculated
	PVTCalculateAll(PVT_Statistics)
END
PVTSave(PVT_Statistics, sFile)
```

## Syntax
<a name="SYNTAXE1"></a>

### Saving a Pivot Table control with its interface and a password

`<Result> = PVTSave(<Pivot Table control> , <Save destination> [, <Save mode> [, <Password>]])`
---

**`<Result>: (Type according to save destination)`**



- Memory: Buffer containing the result. This result can be then saved in a file (using [fSaveBuffer](../WDLang1/1000019412.md)), etc.

- File:

	- <u><u><u><u>True</u></u></u></u> if saved successfully,

	- <u><u><u><u>False</u></u></u></u> otherwise.  







**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Save destination>: (Character string or constant)`**



- To save the contents of the Pivot Table control to memory, use the *inMemory* constant. &lt;Result&gt; contains the result. 

- To save the Pivot Table control as a file, specify the name and full path of the file.




**`<Save mode>: (Optional Integer constant)`**

By default, only the data is saved. You can also save the Pivot Table control interface:


|   |   |
| --- | --- |
| *pvtWithUI* | Saves the configuration of the Pivot Table control:<br><br>- size of columns, <br><br>- size of rows, <br><br>- collapsed/expanded row headers or column headers.<br><br><br><br><br>Note: Before version 25, this constant was named *pvtWithGUI*. |

If &lt;Save mode&gt; and &lt;Password&gt; are not specified, only the data in the Pivot Table control will be saved and the result will not be password protected. To save the data only and password-protect the result, use syntax 2. 

**`<Password>: (Optional string or Secret string)`**

Result password. If the result is password protected, the password must be specified when [PVTLoad](../WDLang1/1000020507.md) is used.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).

## Remarks


### Saving and loading a Pivot Table control
<a name="saving_and_loading_pivot_table_control_ELTPARAGRAPHE000155"></a>

When the content of a Pivot Table control is calculated with [PVTCalculateAll](../WDLang1/1000020539.md), the result can be saved with **PVTSave**. Then, it can be loaded again using [PVTLoad](../WDLang1/1000020507.md). In this case, the content of the Pivot Table control is not recalculated.
