
## AppUPDAvailable (Function)

***In french: AppliMAJDisponible***

<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out whether an update is available for the specified application.





![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This function is only available for applications deployed in the Private Store. In this case, the function searches only for the reference version (indicated by a yellow star in the Private Store). This reference version is not necessarily the latest available.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF AppUPDAvailable() = appUPDAvailMandatory THEN
	IF YesNo("An update is available for the application.", ...
		  "Do you want to perform this update?") = Yes THEN
			  AppInstallUPD()
	END
END
```

## Syntax

`<Result> = AppUPDAvailable([<Application path>])`
---

**`<Result>: (Integer constant)`**

Returns:

- 0 if an error occurred when searching for the update. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).

- one of the following constants:
	


|   |   |
| --- | --- |
| *appUPDAvaiilOptional* | An optional update is available. |
| *appUPDAvailMandatory* | A mandatory update is available. |
| *appUPDNotAvail* | . |






**`<Application path>: (Optional character string)`**

Full path of executable to use. If this parameter is not specified, the current application will be handled.
