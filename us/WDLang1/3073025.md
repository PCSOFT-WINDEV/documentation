
## SysWindowsVersion (Function)

***In french: SysVersionWindows***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the Windows version used on the current computer.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Returns information about the Windows version used on the server.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Returns the version of the system.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) To get information about the Android version, use [SysAndroidVersion](../WDLang1/1000019785.md).

## Example

ResVersion = SysWindowsVersion(SysVersionNumber)

## Syntax

`<Result> = SysWindowsVersion([<Type of information>])`
---

**`<Result>: (Character string)`**



- Information about the Windows version,

- Empty string ("") if an error occurred.




**`<Type of information>: (Optional constant)`**
