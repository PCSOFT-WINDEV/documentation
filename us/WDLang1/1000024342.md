### Saving an image in a file in GIF format

`<Result> = <Image control>.SaveGIF(<File name> [, <Number of colors>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the image was saved,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Image control>: (Control name)`**



**`<File name>: (Character string)`**

Name and full (or relative) path of GIF file. A UNC path can be used. The file extension is optional.

**Caution**: 

- The destination directory must exist in order for the image to be saved.

- The existence of the GIF file is not checked. This file is automatically overwritten if it already exists.




**`<Number of colors>: (Optional integer)`**

Number of colors for the image saved. Value included between 16 and 256 (256 by default). This parameter corresponds to the number of colors proposed in the color palette when using the GIF file.


<a name="SYNTAXE2"></a>

### Saving an image in memory 

`<Result> = <Image control>.SaveGIF(<inMemory> [, <Number of colors>])`
---

**`<Result>: (Buffer)`**

Byte string containing the image in GIF format.
Then, this byte string can be assigned to an Image control, saved in a file ([fSaveText](../WDLang1/3036046.md)), sent via a network (with the [Socket functions](../WDLang3/3070007.md)), ...
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, this byte string can only be assigned to another image ("Localize the image in the _WEB directory in browser code" must be unchecked). It cannot be saved in a file to build an image file.

**`<Image control>: (Control name)`**



**`<inMemory>: (Constant)`**

*inMemory*: Constant used to save an image in memory.

**`<Number of colors>: (Optional integer)`**

Number of colors for the image saved. Value included between 16 and 256 (256 by default). This parameter corresponds to the number of colors proposed in the color palette when using the GIF file.

## Remarks


### Image found in a Web Camera control
<a name="image_found_web_camera_control_ELTPARAGRAPHE000413"></a>

Only the image displayed when **&lt;Image&gt;.SaveGIF** is executed is saved as a GIF image. To save this image, you can also use:

- function [&lt;Camera&gt;.Capture](../WDLang1/1000022382.md): the image will be saved in BMP format.

- the [&lt;Image&gt;.SaveBMP](../WDLang1/1000024341.md) function: the image will be saved in BMP or memory format.

- the [&lt;Image&gt;.SaveJPEG](../WDLang1/1000024344.md) function: the image will be saved in JPEG format or in memory.

- the [&lt;Image&gt;.SavePNG](../WDLang1/1000024345.md) function: the image will be saved in PNG format or in memory.

### Drawing in browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000454"></a>

The image saved in memory can be directly assigned to an Image control. Depending on the browser used, the result may not be the expected one. 

For example, with the current version of FireFox (available when this documentation was published), images in GIF format are not displayed properly. 

This may be fixed in future browser updates.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000472"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.
