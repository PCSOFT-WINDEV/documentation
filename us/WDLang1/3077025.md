


## EventDestroy (Function)

***In french: SignalDétruit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Explicitly destroys an event.

**Note** All signals are released at the end of the application.








<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`EventDestroy(<Event>)`
---

**`<Event>: (Character string)`**

Name of the event to destroy.
