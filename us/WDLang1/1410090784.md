
## JSONOpenReader (Function)

***In french: JSONOuvreLecteur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a reader to read a JSON document without loading it into memory.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
JSON_reader is jsonReader = JSONOpenReader(file_name)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = JSONOpenReader(<Document> [, <Source>])`
---

**`<Result>: (jsonReader variable)`**

[jsonReader](../WDLang1/1410090783.md) variable used to read a JSON document without loading it into memory.

**`<Document>: (Character string)`**



- Path of the file containing the JSON document to read.

- JSON content to manipulate.  




**`<Source>: (Optional Integer constant)`**

Contents of the &lt;Document&gt; parameter:


|   |   |
| --- | --- |
| *fromFile* | The &lt;Document&gt; parameter corresponds to the name of a file. |
| *fromString* | The &lt;Document&gt; parameter is a UTF-8 string containing the JSON document to be manipulated. |
