
## BitwiseNOT (Function)

***In french: NONBinaire***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29</B>, ***BinaryNOT*</**>** is kept for backward compatibility. This function has been replaced with ***BitwiseNOT*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the result of a bitwise NOT operation performed on a value.

**Reminder** The logical NOT operation is equivalent to "One's complement". The logical negation is applied to ALL the bits of the value.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the result of a logical NOT operation
ResBitwiseNOT = BitwiseNOT(6)  // Returns -7
ResBitwiseNOT = BitwiseNOT(2)  // Returns -3
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = BitwiseNOT(<Value>)`
---

**`<Result>: (Integer)`**

Result of the logical NOT operation.

**`<Value>: (Integer)`**

Value to evaluate.

## Remarks




### Bitwise operation
<a name="bitwise_operation_ELTPARAGRAPHE000061"></a>

**BitwiseNOT** performs the bitwise operation on &lt;Value&gt; based on the following table:


|   |   |   |
| --- | --- | --- |
| **Value** | 0 | 1 |
| **Result** | 1 | 0 |


<a name="NOTE0_2"></a>




### Bitwise operator
<a name="bitwise_operator_ELTPARAGRAPHE000084"></a>

**BitwiseNOT** is equivalent to the **~** bitwise operator. For more details, see [Bitwise operators](../Motscles/1512009.md).
