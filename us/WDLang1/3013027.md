
## NumHelp (Function)

***In french: NumHelp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of the help context associated with the specified control. This help number was specified when the control was created in the window editor.

**Remark**: This help number can be used with the [WHelp](../WDLang1/3013053.md) function to display the help page (HLP or CHM format) corresponding to the field.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open the MyHelp.HLP help on the page
// whose context number is NumHelp(NameCurrentControl)
// NameCurrentControl is a variable containing the name of the current control
WHelp("MyHelp.hlp", NumHelp(NameCurrentControl))
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = NumHelp(<Control name>)`
---

**`<Result>: (Integer)`**

Number of the context-sensitive help.

**`<Control name>: (Character string)`**

Name of the control whose number of context-sensitive help you want to get. For the options of a check box or radio button, the number of the option must be enclosed in brackets (CheckBox[1] for the first option of a check box for example).
