
## docElementCheckBox (Variable type)

***In french: docElémentInterrupteur***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docElementCheckBox** type allows you to define all the advanced characteristics of a check box used in a form. You can define and change the characteristics of this check box using different WLanguage properties. 

To manipulate check boxes, the **docElementCheckBox** variable must be instantiated with the **&lt;-** operator and the **Control** property of the [docElement](../WDLang1/1000022484.md) variable. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

<a name="sample_code"></a>

## Example


```wl
// Insert a checked box
o is docElement
o.Type = typeDocElementCheckBoxControl
CheckBox is docElementCheckBox <- o..Control
CheckBox.Checked = True
DocInsert(MyDoc, 2, o)
	
// Insert an unchecked box
o2 is docElement
o2.Type = typeDocElementCheckBoxControl
CheckBox2 is docElementCheckBox <- o2..Control
CheckBox2.Checked = False
DocInsert(MyDoc, 23, o2)
```



```wl
// Opens a docx file in the Word Processing control
WP_MyDoc = DocOpen(fExeDir() + fSep() + "MyDoc.docx")
MonDoc is a Document = TT_MonDoc
// Go through the paragraphs to find the switches
sElement is string
sParagraph is a string
sValue,sBegin,sEnd,sType are strings
FOR EACH MyPara OF MyDoc.Paragraph
	sParagraph = sParagraph + [RC] + sElement
	sElement = ""
	FOR ALL MyElement OF MyPara.Element
		sDebut = MyElement.StartPosition
		sFin = MyElement.PositionFin
		SELON MonElement.Type
			CAS typeDocElementFieldSwitch
			sType = "Checkbox"
			CheckBox is a docToggleElement <- MyElement..Field
			sValue = CheckBox.Checked
		END
		sElement = sElement + [RC] + sValue + TAB + sBegin + TAB + sEnd + TAB + sType
	END
END
```

## Properties


### Properties specific to docElementCheckBox variables
<a name="properties_specific_docelementcheckbox_variables_ELTPARAGRAPHE000033"></a>

The following properties can be used to handle **docElementCheckBox** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Checked | Boolean | Check box state: <br><br>- <u><u><u>True</u></u></u> if the box is checked,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
| CheckedChar | Character string | Unicode character representing a checked box (Ballot Box with Check). |
| CheckedCharFont | Character string | Name of the font used to represent the checked box. |
| UncheckedChar | Character string | Unicode character representing an unchecked box (Ballot Box). |
| UncheckedCharFont | Character string | Name of the font used to represent the unchecked box. |


Note: "Legacy" check boxes are not supported. Use only check boxes in a recent format.
