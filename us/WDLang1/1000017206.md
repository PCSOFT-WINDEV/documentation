
## MultimediaOpen (Function)

***In french: MultimédiaOuvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a media file in a Multimedia control. The file is loaded in memory. To play the file, you must use [MultimediaPlay](../WDLang1/1000017202.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)

MultimediaOpen(MM_Multimedia1, MyFile)

## Syntax

`<Result> = MultimediaOpen(<Multimedia control> , <File to open>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was successfully opened,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Multimedia control>: (Control name)`**

Name of Multimedia control used to play the media file.

**`<File to open>: (Character string)`**

Name and path of media file to open.  

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Corresponds to: 

- the name and path of media file to play. 

- a URL (to play the video in streaming). 

- a resource name (file name + extension) added to the application via the generation wizard. 




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Corresponds to: 

- the name and path of media file to play. 

- a video URL on a server. Note: YouTube videos cannot be played.

- a resource name (file name + extension) added to the application via the generation wizard.

## Remarks
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Android specific features
<a name="android_specific_features_ELTPARAGRAPHE000089"></a>

- By default, [MultimediaPlay](../WDLang1/1000017202.md) is a blocking function until the control is ready to play the file. 

- The *MultimediaNonBlocking* constant used with [MultimediaPlay](../WDLang1/1000017202.md) allows you to perform a non-locking load operation. In this case, the call to a Multimedia function ([MultimediaPosition](../WDLang1/1000017210.md), ...) will fail as long as the media file is not loaded by the control. 

- The non-locking load operations are recommended when using media files not found on the device (online video for example).
