


## docCell (Variable type)

***In french: docCellule***
				



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **docCell** type is used to define the advanced characteristics of a table cell in a Word Processing document. You can define and change the characteristics of this cell using different WLanguage properties. 

**CAUTION: This type must not be used directly.** It must only be used: 

- via the [docElement](../WDLang1/1000022484.md) type (for a Cell element). 

- via the [docParagraph](../WDLang1/1000022483.md) type (for a Table paragraph). 


For more details on the different types related to Word Processing documents, see [Types associated with Word processors](../WDLang1/1000022736.md). 


<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the document
MyDocument is Document <- WP_Table
// Retrieve the table, here the paragraph 1
pTable is docParagraph <- MyDocument.Paragraph[1]

// Browses the rows
FOR i = 1 _TO_ pTable.Table.Rows.Count
	// Browses the columns
	FOR j = 1 _TO_ pTable.Table.Columns.Count
		Trace("Value of cell [[%i%]][[%j%]] = " + 
		pTable.Table.Cells[i, j].Content.Text)
	END
END
```

## Remarks
<a name="NOTE0_1"></a>


### Properties specific to docCell variables
<a name="properties_specific_doccell_variables_ELTPARAGRAPHE000044"></a>

The following properties can be used to handle **docCell** variables:

   | --- |
| --- | --- | --- |
| **Property name** | Type used | Effect |
|   | PageLayout.Border | [Border](../Motscles/15140100.md) variable | Characteristics of the border used for the paragraph.  <br><br>Remark: rounded corners are not supported. |
|   | PageLayout.BackgroundPattern | [Background](../WDLang1/1000022038.md) variable | Characteristics of the cell background. <br><br> |
|   | PageLayout.BackgroundColor | Integer | Cell background color. This color can correspond to:<br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- [a preset color](../WDLang5/3010002.md). <br><br><br> |
| ColSpan | Integer | Index of the current column. |
| ColumnIndex | Integer | Index of the current column. |
| Content | [docFragment](../WDLang1/1000022482.md) variable | Content of a table cell. |
| PageLayout |   | Layout of the current cell. <br><br> |
| RowIndex | Integer | Index of the current row. |
| RowSpan | Integer | Index of the current row. |
