


## fFileExist (Function)

***In french: fFichierExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence of an external file.

**Note** Under 64-bit Windows, access to a system directory from a 32-bit executable may be made in a different directory from the one expected. For more details, see [Native 64-bit and native 32-bit](../Editeurs/2030048.md).

AFile is string
AFile = "C:\Temp\Example.txt"
IF fFileExist(AFile) = True THEN 
	Info("The file named " + AFile + " exists on the disk")
END

## Syntax

`<Result> = fFileExist(<File name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file exists, 

- <u><u><u><u>False</u></u></u></u> otherwise (the file name corresponds to a directory name for example).




**`<File name>: (Character string)`**

Name and full path of file. Wildcard characters (\*,?) are not allowed. You can call [fDir](../WDLang1/3036056.md) to use wildcard characters. If only the file name is specified (without the path), the file is searched in the current directory (for example: fFileExist("Test.jpg"))
![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive.
