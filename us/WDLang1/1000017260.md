
## AppChangeParameter (Function)

<a name="description"></a>
Changes an information in the mechanism for automatic application update.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
IF AppParameter(appUPDMode) = 3 THEN
	AppliChangeParameter(appUPDMsgStop, "The application " + ProjectInfo(piEXEName) + ...
			"will be automatically stopped.")
END
```

## Syntax

`<Result> = AppChangeParameter(<Information> , <New value> [, <Application path>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the requested information was modified,

- <u><u><u><u>False</u></u></u></u> if a problem occurs. For more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Information>: (Integer constant)`**

Characteristic of the application to modify:  


|   |   |
| --- | --- |
| *appUPDAutoCheck* | Enable automatic check for updates: <br><br>- <u><u><u><u>True</u></u></u></u> to enable,<br><br>- <u><u><u><u>False</u></u></u></u> to disable. <br><br><br><br><br> |
| *appUPDBackgroundTask* | Download application updates from the Private Store in the background. <br>If the application is in use, it is not interrupted. <br>When the update is downloaded, a notification is displayed to install the update. If necessary, the notification is also displayed next time the application is launched. <br><br>Please note: This constant is only taken into account for applications in the Private Store.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Not available. |
| *appUPDDisplayError* | Allows you to display a message if a problem is encountered when checking for updates: <br><br>- <u><u><u><u>True</u></u></u></u> to display a message, <br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Constant not available. |
| *appUPDDisplayMode* | Display options for update notifications:<br><br>- 0: A window in the application is used to warn the user.<br><br>- 1: A notification is used to alert the user.<br><br><br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Constant not available. |
| *appUPDLocalVersion* | Version number of local executable. |
| *appUPDMode* | Current operating mode of the application:<br><br>- 0: Normal operation.<br><br>- 1: Launch prohibited: current executables continue to run.<br><br>- 2: Launch prohibited: executables in progress receive a warning message periodically.<br><br>- 3: Launch prohibited: executables in progress are automatically stopped after a certain time.<br><br><br> |
| *appUPDMsgForbid* | Message displayed when the startup of the application is forbidden. |
| *appUPDMsgStop* | Message displayed before the application is automatically stopped (when appUPDMode = 3). |
| *appUPDMsgWarning* | Message displayed on a regular basis (when appUPDMode = 2). |
| *appUPDNetwork* | Level of update:<br><br>- 0: No update. <br>	The update in network is not used.<br><br>- 1: Network update enabled. <br>	The available updates are checked and the dialog box of automatic update is displayed.<br><br>- 2: Network update enabled and applications registered with update server. <br>	The available updates are checked and the dialog box of automatic update is displayed. <br>	As soon as it is started, the executable creates a ".LOK" file on the server. This file allows [WDAdminExe](../WDAdminExe/2028052.md) to identify the clients that use the application.<br><br><br> |
| *appUPDPath* | Path of update information on the server. |
| *appUPDProtocol* | Network protocol used to search for updates. This protocol can correspond to "LOCAL" or to "HTTP". |
| *appUPDServer* | Server where the updates will be sought.<br>If the HTTP protocol is used, IP address or name of computer.<br>If the LOCAL protocol is used, name of network share. |
| *appUPDTimeout* | Timeout between two messages (if appUPDMode = 2) or before the application is automatically stopped (if appUPDMode = 3). This timeout is expressed in seconds. |



**`<New value>: (Expected type)`**

New value that will be given to the specified information.

**`<Application path>: (Optional character string)`**

Full path of executable to use. If this parameter is not specified, the current application will be handled.
