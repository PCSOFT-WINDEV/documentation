
## ShamirReconstructSecret (Function)

***In french: ShamirReconstruitSecret***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reconstructs a secret from a set of shares.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Gets the share identifiers to be used
share_ids is array of int = [ 1, 3, 5 ]

// Array of shares to be used to reconstruct the secret
shares is array of strings

// Iterate over share identifiers
FOR EACH id OF share_ids
	// Loads the contents of the corresponding file
	file_content is string = fLoadText(fExeDir() + [fSep()] + "bip39_share_[%id%].txt")

	// Splits the contents of the file into an array of BIP39 mnemonic phrases
	bip39_share_arr is array of strings
	StringToArray(file_content, bip39_secret_arr, CR)

	// Reconstructs the array of share sections
	sections is array of strings

	// The first section is always the identifier
	sections.Add(id)

	// Converts the BIP39 mnemonic phrase back to a hex string
	FOR EACH bip39_section OF bip39_share_arr
		section_buffer is Buffer = PhraseToBuffer(bip39_section)
		hex_section is string = BufferToHexa(section_buffer, NoGrouping, NoLine)
		sections.Add(hex_section)
	END
	// Reconstruct the share with hyphens as separators
	Share is string = sections.ToString("-")
	// Trace(share)
	shares.Add(share)
END

// Reconstructs the secret
reconstructed_secret is Buffer = ShamirReconstructSecret(shares)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ShamirReconstructSecret(<Shares> [, <Prime number>])`
---

**`<Result>: (Buffer)`**

Reconstructed secret buffer.  

**`<Shares>: (Array of strings)`**

Array of strings containing the shares required to reconstruct the secret. 
This array must contain at least as many shares as the threshold specified with [ShamirCreateShares](../WDLang1/1410091293.md). 

**`<Prime number>: (Optional character string)`**

Primary number used to create the shares.
