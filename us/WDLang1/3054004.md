
## ChangeSeparator (Function)

***In french: ChangeSéparateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the value of the separators (decimal separator or thousand separator) used in the numeric masks for internationalization.

To modify the separator:

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) of the current page: use function **ChangeSeparator** then redisplay the current page with function [PageUse](../WDLang2/3058016.md) or [FramesetUse](../WDLang2/3058012.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) of the current window: use function **ChangeSeparator** then redisplay the current window with function [Use](../WDLang1/3038044.md).

## Example

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
// -- Project initialization code 
// If English is the favorite language of the user
IF CookieRead("PREFERRED_LANGUAGE") = "ENGLISH" THEN
	// Change the captions to English
	Nation(3)
	// Use "." as decimal separator
	ChangeSeparator(sepDECIMAL, ".")
END
```

<a name="SYNTAXE1"></a>

## Syntax

`ChangeSeparator(<Separator Type> , <New value>)`
---

**`<Separator Type>: (Integer constant)`**

Specifies the type of separator to modify:


|   |   |
| --- | --- |
| *sepCURRENCY* | Symbol used for the currencies. |
| *sepDECIMAL* | Decimal separator (if the operating system used is the French version of Windows, the decimal separator is the comma (",") by default). |
| *sepTHOUSAND* | Thousand separator (if the operating system used is the French version of Windows, the separator is a space character ("") by default). |



**`<New value>: (Character)`**

New value for the specified separator.

### Server/Browser differences
<a name="serverbrowser_differences_ELTPARAGRAPHE000090"></a>

The value of the separators can differ in development mode and in deployment mode. Indeed, when running a WEBDEV website, the default value of the separators is defined by the regional settings assigned to the user by the Web server.
