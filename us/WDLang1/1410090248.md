


## CodeEditorUncomment (Function)

***In french: EditeurCodeDécommente***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Uncomments the current selection in the Code Editor control. "//" characters at the beginning of the current line are removed.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Uncomments the code selected in the Code Editor control
CodeEditorUncomment(CODEEDT_Example)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`CodeEditorUncomment(<Code Editor control>)`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
