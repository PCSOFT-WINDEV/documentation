
## SchedulerMode (Function)

***In french: PlanningMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the display mode of a Scheduler control: day, week, month, ...

**Remark**: The [SchedulerChangeMode](../WDLang1/1000019440.md) function is used to change the display mode of the Scheduler control.. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
nMode is int = SchedulerMode(SCH_MySchedule)
IF nMode = schModeDay THEN
	SCH_MyScheduler..GranularityAppointment = 15 // 15 minutes in Day mode
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SchedulerMode(<Scheduler control>)`
---

**`<Result>: (Integer)`**

Time interval displayed by the Scheduler control: 


|   |   |
| --- | --- |
| *schModeAccordingApt* | Schedule that displays a number of days allowing you to see all the available appointments.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |
| *schModeCustomNbDay* | Schedule for a specific number of days. |
| *schModeDay* | Schedule for a day. |
| *schModeMonth* | Schedule for a month. |
| *schModeWeek* | Schedule for a week of 5 days or for a week of 7 days. |



**`<Scheduler control>: (Control name)`**

Name of the Scheduler control to be used. This control can correspond to:

- the Scheduler control of a window,

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the Scheduler control of a page,

- the Scheduler control of a report.
