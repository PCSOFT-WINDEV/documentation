


## CalendarSelect (Function)

***In french: CalendrierSelect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the date selected in a Calendar control.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the selected date in a trace window
Trace(CalendarSelect(CAL_Calendar1))
```
<a name="Exemple2"></a>

```wl
// Retrieves the date in an edit control
EDT_Date = CalendarSelect(CAL_Calendar1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = CalendarSelect(<Calendar control> [, <Index of the selected element>])`
---

**`<Result>: (Character string or Date variable)`**

Day selected in the Calendar control. This parameter has the following format: "YYYYMMDD". For example, if the selected day is November 12 2008, &lt;Result&gt; is equal to "20081112".

**`<Calendar control>: (Control name)`**

Name of Calendar control used.

**`<Index of the selected element>: (Optional integer)`**

Rank of selection for a multi-selection calendar. 
If this parameter is not specified, the date corresponding to the first selected element is returned.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The Calendar control is not multi-selection. If this parameter is specified, only index 1 is valid and the result will correspond to the result of the [Value](../Proprietes/2510130.md) property.
