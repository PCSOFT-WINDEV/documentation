


## Segmented Button functions
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate Segmented Button controls:



|   |   |
| --- | --- |
| [SegmentedButtonAdd](../WDLang1/1410090834.md) | Adds a new option (i.e. a new button) to a Segmented Button control. |
| [SegmentedButtonDelete](../WDLang1/1410090836.md) | Deletes an option from a Segmented Button control. |
| [SegmentedButtonDeleteAll](../WDLang1/1410090837.md) | Deletes all the options from a Segmented Button control. |
| [SegmentedButtonInsert](../WDLang1/1410090835.md) | Inserts a new option into a Segmented Button control. |
