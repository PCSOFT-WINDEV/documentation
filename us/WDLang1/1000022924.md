


## docTable (Variable type)

***In french: docTableau***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docTable** type is used to define the advanced characteristics of a Table paragraph found in a Word Processing document. The characteristics of this array can be defined and modified using various WLanguage properties. 

**ATTENTION: This type must not be used directly.** It must only be used via variables of type [docParagraph](../WDLang1/1000022483.md) corresponding to an array. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the document
MyDocument is Document <- WP_Table
// Retrieve the table, here the paragraph 1
pTable is docParagraph <- MyDocument.Paragraph[1]

// Browses the rows
FOR i = 1 _TO_ pTable.Table.Rows.Count
	// Browses the columns
	FOR j = 1 _TO_ pTable.Table.Columns.Count
		Trace("Value of cell [[%i%]][[%j%]] = " + 
		pTable.Table.Cells[i, j].Content.Text)
	END
END
```

## Properties


### Properties specific to docTable variables
<a name="properties_specific_doctable_variables_ELTPARAGRAPHE000030"></a>

The following properties can be used to define the characteristics of **docTable** variables:

   | --- |
| --- | --- | --- |
| Property name | Type used | Effect |
| Cells[Row,Column] | Table of table cells ([docCell](../WDLang1/1000022927.md)) | Accessing the cells of a Table paragraph. The type of table cells is [docCell](../WDLang1/1000022927.md). |
| Columns |   | [docColumn](../WDLang1/1000023160.md) variable | Used to handle the table columns. <br><br>For example, to insert a column at the 3rd column of a table: <br><br><pre><code>Insert(pTable.Table.Columns, 3)</code></pre><br> |
|   | Columns.WidthMillimeters | Real | Width of row (in millimeters). |
|   | Columns.WidthMode | Integer constant | Mode for calculating the column width: <br><br>- *docModeWidthNo* Special case. <br><br>- *docModeAutomaticWidth* The column width is automatically calculated based on the text in the current column and the text in the other columns. <br><br>- *docWidthModeNotDefined*: Column width calculation mode not defined because cells in the column have different widths. <br><br>- *docModeWidthPercent*: The column width is calculated as a percentage of the total width of the array.. <br><br>- *docModeWidthValue* The column width is calculated according to the width given in millimetres. If the Columns.WidthMillimeters property is set, this mode is automatically selected.. <br><br><br><br><br>This property is read-only. |
| Rows |   | [docRow](../WDLang1/1000022925.md) variable | Used to handle the table rows. <br><br>For example, to insert a row at the 3rd row of a table: <br><br><pre><code>Insert(pTable.Table.Rows, 3)</code></pre><br> |
|   | Rows.Height | Integer | Height of row (in millimeters). |
|   | Rows.HeightMode | Integer constant | Mode for calculating the row height: <br><br>- *docModeHeightAtLeast*: The height of the line will be at least that defined by the property **Height**. <br><br>- *docModeAutomaticHeight* The height of the line is automatically calculated according to the text present in the cells of the line. <br><br>- *docModeExactHeight* The height of the line will be that defined by the property **Height**. <br><br>- *docHeightModeNotDefined*: Line height calculation mode not defined (default is automatic calculation mode). <br><br><br> |
|   | Rows.CellCount | Integer | Number of row cells. <br><br>This property is read-only. |
