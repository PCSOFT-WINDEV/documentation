
## diagHead (Variable type)

***In french: diagExtrémité***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **diagHead** type is used to define all the advanced characteristics of an end of a connector in a diagram. You can define and change the characteristics of this end using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create a link between rectangle1 and rectangle2
rectangle1 is diagRectangle
rectangle2 is diagRectangle
Connector is diagConnector

Connector.Beginning.ConnectionPoint = rectangle1.ConnectionPoint(100, 50) 
Connector.Beginning.Drawing = shapeNone
Connector.Ending.ConnectionPoint = rectangle2.ConnectionPoint(0, 50) 
Connector.Beginning.Drawing = shapeTriangle
```

## Properties


### Properties specific to diagEnd variables
<a name="properties_specific_diagend_variables_ELTPARAGRAPHE000026"></a>

The following properties can be used to handle the end of a connector:

| Property name | Type used | Effect |
| --- | --- | --- |
| ConnectionPoint | [diagConnectionPoint](../WDLang1/1410088457.md) | Point the connector will snap to. |
| Drawing | Integer constant | Arrow drawing: <br><br>- *shapeNo*: End has no particular shape. <br><br>- *shapeSquare* end is a square. <br><br>- *shapeRoundedSquare* End is a rounded square. <br><br>- *shapeArrow* The end is an arrow. <br><br>- *shapeLosange* End is a rhombus. <br><br>- *shapeRound* end is round. <br><br>- *formTriangle* end is a triangle. <br><br><br> |
| SnapMode | Integer constant | How the connector will snap to the target shape:  <br><br>- *linkDestinationAuto* The position of the end of the link is determined automatically according to the position of the link and the shape. <br><br>- *linkDestinationForm* The position of the end of the link is in the middle of the shape. <br><br>- *linkDestinationPointDAttache* The position of the end of the link corresponds to an attachment point. <br><br>- *linkDestinationEnglobeRectangle* The position of the end of the link corresponds to a point on the rectangle enclosing the shape. <br><br><br> |
| X | Real | X-coordinate of the end in the diagram. |
| Y | Real | Y-coordinate of the end in the diagram. |
