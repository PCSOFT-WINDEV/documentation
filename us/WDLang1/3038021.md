


## OpenChild (Function)

***In french: OuvreFille***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a non-modal child window. 

The following events are executed when **OpenChild** is called:

- "Global declarations" event of the child window,

- "Initialization" events of controls in the child window (in any order),

- events after the call to **OpenChild** in the code of the parent window,

- the child window is displayed.




**Remarks**:

- By default, the child window retains focus once it is opened.

- **OpenChild** can also be used to define the position and pass parameters to the child window.

	- In standard syntax, these parameters are passed directly. 

	- When you use a variable of type  to open a window, you can use the  property to define the characteristics of the window, and the  property to pass parameters.

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000020349&name=openchild_function">See additional examples</a>

```wl
// Open the child window named "WIN_EditWindow"
// without positioning and without passing parameters
OpenChild(WIN_EditWindow)
```
<a name="Exemple2"></a>

```wl
// Open the child window named "WIN_EditWindow".
// The value of the "EDT_EditCustomer" control is passed as parameter to the event 
// "Global declarations" of "WIN_EditWindow".
OpenChild(WIN_EditWindow, EDT_EditCustomer)
```

```wl
// -- Event "Global declarations" of "WIN_EditWindow"
// Retrieve the parameters
PROCEDURE WIN_EditWindow(Customer)
HReadSeek(Customer, CustomerName, Customer)
IF HFound() = True THEN
	FileToScreen()
ELSE
	Error("No customer matches")
END
```

## Syntax

### Opening a child window (standard syntax)

`OpenChild(<Window> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window>: (String or window name)`**



- Name of child window to open.

- Name and full path of child window (".WDW" file) to open.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) You cannot specify the full name of the file to open (".WDW" file).


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To avoid giving focus to the opened window, use the following notation: &lt;Window name&gt; + *NoFocus*. The focus gain process of the child window will not be run. **Caution: in this case, the window name must be enclosed in quotes.**

**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).


<a name="SYNTAXE2"></a>

### Opening a child window by defining its position and level (standard syntax)

`OpenChild(<Window name [ + <Level>]> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window name [ + ]>: (String + Integer constant)`**

Used to specify: 

- **the window to open** (&lt;Window name&gt;). This parameter can correspond to: 

	- Name of child window to open.

	- Name and full path of child window (".WDW" file) to open.
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) You cannot specify the full name of the file to open (".WDW" file).


 By default, the window is displayed according to the position defined in the editor. You can define the display position of the window. The window name is completed by the window display coordinates when opened. This parameter has the following format:
	
	```txt
	"[<Alias>] = <Window Name> [, <Y>, <X>]"
	```

	 where:

- &lt;Alias&gt;: Window alias if the same window is opened several times.

- &lt;Window name&gt;: Name of the child window to be opened. 
			![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To avoid giving focus to the opened window, use the following notation: &lt;Window name&gt; + *NoFocus*. The event "Gain of focus" of the child window will not be run. **Caution: in this case, the window name must be enclosed in quotes.**

- &lt;Y&gt;: Y-coordinate of the window (in pixels), relative to the upper-left corner of the screen or parent window.

- &lt;X&gt;: X-coordinate of the window (in pixels), relative to the upper-left corner of the screen or parent window.

- **the window display level** (&lt;Level&gt;):
	


|   |   |
| --- | --- |
| *Above* | Window opened above all its sibling windows. |
| *AboveAll* | Window opened above all the other windows (including the windows of other applications).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. |


	**If one of these constants is used, the name of the window must be enclosed in quotes.**
	Note: If two windows are opened with the same constant (*Above* or *AboveAll*), the second window will be opened above the first one.
	It is recommended to use [WinStatus](../WDLang1/3038030.md) to change the display level of a window.




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

<a name="SYNTAXE3"></a>
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This syntax is only available for Java applications
### Opening a child window (with a Window variable)

`OpenChild(<Window to open> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window to open>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened.  

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property. 




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

## Remarks


### Parameters passed to the window to open
<a name="parameters_passed_the_window_open_ELTPARAGRAPHE000538"></a>The parameters are retrieved in the "Global declarations" event associated with  the window. The first line of code of this event must correspond to the following line:


```txt
PROCEDURE <Window> (<Parameter 1> [, ... [, <Parameter N>]])
```
where: 

- &lt;Window&gt; must correspond to the name of the window. 

- &lt;Parameter N&gt; must correspond to the parameters expected. **Note: These parameters are passed by value, not by reference.**


For more details, see [Window with parameters](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Window opening mode
<a name="window_opening_mode_ELTPARAGRAPHE000279"></a>

The window opens as a non-modal window:

- the child window becomes the current window.

- once the child window is opened, the processes following the call to **OpenChild** in the parent window are run.

- the user will have the ability to click one of the parent windows of opened window. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) The controls found in the parent windows cannot be accessed by the user as long as a child window is opened. 


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **Note**: **OpenChild** gives focus to the child window. The code for gaining focus is run in the child window and the code for losing focus is run in the parent window. In order for the parent window to keep focus, use the *NoFocus* constant in the &lt;Window name&gt; parameter. 
To manage MDI, use [MDIOpen](../WDLang1/3052005.md).
<a name="NOTE0_3"></a>


### Position of parent window
<a name="position_parent_window_ELTPARAGRAPHE000309"></a>

The parent window always remains below the child window, even if the parent window is in edit.

If this situation is not suitable, the child window must be opened by [OpenSister](../WDLang1/3038045.md) (providing that the parent window is a non-modal window).
<a name="NOTE0_4"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Opening the same window several times
<a name="opening_the_same_window_several_times_ELTPARAGRAPHE000325"></a>

- If the same window is opened several time, we recommend that you use an alias. This alias is used to differentiate between each window.

- The position of the calling window (relative to the screen or to the parent window) is chosen when the window is described in the editor. If the same window is opened several times (with an alias), the display positions must be modified at each opening (otherwise the windows will be stacked).

- The number of windows that can be opened simultaneously depends on the available memory.



<a name="NOTE0_5"></a>


### Limitation
<a name="limitation_ELTPARAGRAPHE000336"></a>

**OpenChild** must not be called in the project initialization code.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To display a "splash screen" window at the start of the application, use the "Splash screen" option when creating the executable.
<a name="NOTE0_6"></a>


### Closing a window
<a name="closing_window_ELTPARAGRAPHE000351"></a>

A window opened with **OpenChild** can be closed with [Close](../WDLang1/3038018.md) (without parameters) from any event:

- of the window,

- of a window control.




If a parent window is closed, its child windows are also closed.
<a name="NOTE0_7"></a>


### Title of the window to be opened
<a name="title_the_window_opened_ELTPARAGRAPHE000598"></a>

By default, the window title is the one defined in the editor (in the "General" tab of the description window).

To change the window title:

- In standard syntax, use [NextTitle](../WDLang1/3038043.md) or [CurrentTitle](../WDLang1/3038023.md).

- With a variable of type [Window](../WDLang1/1410091366.md), use the [OpeningOptions](../Proprietes/1410091299.md) property (**OpeningOptions.Title**).
	



<a name="NOTE0_8"></a>


### Opening the window of a component
<a name="opening_the_window_component_ELTPARAGRAPHE000377"></a>To open the window of a component, simply use the name of the component window (component included in the project). For example:


```wl
OpenChild(ComponentWindow)
```
If a conflict occurs with a project element, the element name must be prefixed by the component name. For example:


```wl
OpenChild(MyComponent.Window)
```
To use the name of the window in a variable, the name of the component must be specified. For example:


```wl
sWindow is string ="MyComponent.MyWindow"
OpenChild(sWindow)
```
