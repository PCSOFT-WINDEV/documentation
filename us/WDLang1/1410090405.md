


## &lt;Pivot Table&gt;.CalculateAllAsynchronous (Function)

***In french: &lt;Tableau croisé dynamique&gt;.CalculeToutAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Entirely calculates or recalculates a Pivot Table control, without blocking the application.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
PVT_Statistics.CalculateAllAsynchronous(Calculation_completed)
	INTERNAL PROCEDURE Calculation_completed(bOK is boolean)
		IF NOT bOK THEN
			Error(ErrorInfo())
			RETURN
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Pivot Table control>.CalculateAllAsynchronous([<WLanguage procedure>])`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to calculate or recalculate.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called once the calculation is completed. 
For more details on this procedure, see [Parameters of the procedure used by PVTCalculateAllAsynchronous](../WDLang1/1410090051.md).

## Remarks


### How is data calculated?
<a name="how_data_calculated_ELTPARAGRAPHE000190"></a>

Data is calculated by iterating over all the necessary records. This can take a long time depending on the size of the database. For example, calculating one million records can take several minutes. **&lt;Pivot Table&gt;.CalculateAllAsynchronous** does not block the application and executes the specified WLanguage procedure after the calculation is completed. 

The content of the Pivot Table control must be entirely recalculated: 

- When adding new items. 

- When changing filter options. 

- When changing the source data. 




The content of the Pivot Table control does not need to be entirely recalculated: 

- When using a filter on a dimension that is already calculated. 

- When changing dimension.  

- When expanding or collapsing a dimension (e.g. to display quarters instead of years).
