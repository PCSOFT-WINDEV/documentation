


## CodeEditorGetError (Function)

***In french: EditeurCodeRécupèreErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the first error encountered when compiling the code displayed in the Code Editor control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Compiles the code in the Code Editor control
// and displays potential errors directly in the control
bResult is Boolean = CodeEditorCompile(CODEEDT_Example)
IF bResult = True THEN
	ToastDisplay("Your code compiles perfectly!")
ELSE
	ToastDisplay("Just a few more adjustments, you're almost there!" + 
			CR + CodeEditorGetError(CODEEDT_Example))
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CodeEditorGetError(<Code Editor control>)`
---

**`<Result>: (Character string)`**

Text of the first error encountered when compiling the code displayed in the Code Editor control. 

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
