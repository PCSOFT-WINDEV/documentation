## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Document to convert>.ToHTML([<Path>] [, <Managing the CSS styles>])`
---

**`<Result>: (Boolean or Buffer)`**



- If &lt;Path&gt; is specified: 

	- <u><u><u><u>True</u></u></u></u> if the file was generated,

	- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




- If &lt;Path&gt; is not specified, &lt;Result&gt; corresponds to a buffer containing the HTML code.




**`<Document to convert>: (Document variable)`**



**`<Path>: (Optional character string)`**

Path of HTML file to be generated. If the path is not specified, the HTML code is returned in buffer format.

**`<Managing the CSS styles>: (Optional constant)`**

Style attributes to use:



|   |   |
| --- | --- |
| *dthWithCSS*<br>(Default value) | Applies **external** CSS styles<br>The CSS code is generated in a ".CSS" file external to the HTML page. This file is created in the same directory as the generated HTML page. It has the same name as the HTML page, with the ".CSS" extension. A link to this file is added into the HTML code of the page.<br><br>If the document contains images, these ones are saved in a subdirectory named like the generated HTML file. |
| *dthWithoutCSS* | Applies CSS styles **inline** CSS code is generated and integrated into the HTML code of the generated page. Each tag contains the CSS styles applied to it. <br><br>If the document contains images, they are integrated and are encoded in base64. <br><br>This constant allows, for example, to create an HTML generation adapted to new email messaging. <br><br>Note: if an image contained in an Email is larger than 100 Kb, it will generally be displayed as an attachment to the Email, even if it is encoded in base 64 in the Email. |
