
## ThreadStopRequested (Function)

***In french: ThreadArrêtDemandé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks if a stop request has been sent to the running thread. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// If a stop request was sent to the thread
IF ThreadStopRequested() THEN
	// Free thread resources
	...
	// End thread
	ThreadEnd()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ThreadStopRequested()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if a stop request has been sent to the running thread, 

- <u><u><u><u>False</u></u></u></u> otherwise. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- One thread requests another thread to stop via [ThreadRequestStop](../WDLang1/1000021218.md).

- The current thread's code must regularly check (loops, etc.) whether a stop has been requested, and terminate cleanly if so.

- When a thread's code is on a wait function (e.g. [ThreadPause](../WDLang1/3077029.md), [ThreadWaitSignal](../WDLang1/3077022.md) or [EventWait](../WDLang1/3077007.md)), the wait is automatically terminated when a request to stop the thread is made by another thread.
