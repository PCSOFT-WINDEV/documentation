
## Accessibility in mobile applications
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000151"></a>
On smartphones and tablets, there is an operating mode designed for visually impaired and blind users. 
This mode is called TalkBack on Android and VoiceOver on iOS. 

In version 2024, WINDEV Mobile allows you to utilize these modes. 

Each control contains a generic description by default, and can contain a custom description.
By default, the generic description is the caption or hint text of the control. 
You can customize the description using one of the following methods: 

- via the control description window. 

- programmatically, using various WLanguage properties.

## Defining and customizing accessibility information via the control description window
<a name="defining_and_customizing_accessibility_information_via_the_control_description_window_ELTTEXTE000175"></a>
By default, all controls used in Android or iOS UIs can be taken into account by the accessibility mechanism. 

For the accessibility information of a control to be taken into account by the mobile device: 

1. Open the control description window. 

2. Go to the "Help" tab and make sure the "Include this control in the accessibility system" option is checked. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Accessibilit%E9%20-%20HC%20N%B0001.gif)
A default description and an automatic action are defined for the control. 




To customize accessibility options: 

1. Open the control description window. 

2. Go to the "Help" tab and make sure the "Include this control in the accessibility system" option is checked. 

3. Click "Customize". 

4. In the window that appears, specify the elements you want to customize.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Accessibilit%E9%20-%20HC%20N%B0002.gif)


	- Description of the control and the expected content. 

- Description of the action performed when the control is used.  

5. Confirm. 




Note: If your interface uses "decor" type fields, which are only used to improve the interface's legibility, it is possible in this case not to include them in the accessibility properties. To do so, simply uncheck "Include this control in the accessibility system".

## Customizing accessibility options programmatically
<a name="customizing_accessibility_options_programmatically_ELTTEXTE000199"></a>
You can use several properties and functions to manage the accessibility options of controls in a window: 

- Properties: 
	


|   |   |
| --- | --- |
| [Accessibility.DécorativeContent](../Proprietes/1410090235.md) | Indicates whether the control is a decorative element and should be ignored by the screen reader. |
| [Accessibility.Description](../Proprietes/1410090235.md) | Describes the contents of the control. |
| [Accessibility.ActionDescription](../Proprietes/1410090235.md) | Describes the action of the control. |
| [Accessibility.ReadOrder](../Proprietes/1410090235.md) | Specifies the order in which the screen reader will read the controls. Simply specify the number. Controls will be read in ascending order. |



- Function: 
	


|   |   |
| --- | --- |
| [AccessibilityScreenReaderEnabled](../WDLang1/1410090330.md) | Determines if the screen reader is enabled. |
