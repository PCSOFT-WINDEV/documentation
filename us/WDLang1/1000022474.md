


## &lt;Camera&gt;.StopDecoding (Function)

***In french: &lt;Caméra&gt;.ArrêteDécodage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops decoding bar codes in a Camera control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stops decoding bar codes in the Camera control
CAM_Camera1.StopDecoding()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Camera control>.StopDecoding()`
---

**`<Camera control>: (Control name)`**

Name of the Camera control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- When the Camera control is configured to allow the decoding of bar codes (in the description window), the decoding automatically starts when the window is opened. To prevent this behavior, **&lt;Camera&gt;.StopDecoding** can be called in the initialization event of the Camera control.

- When the decoding of bar codes is stopped, the decoding crosshair is not displayed in the Camera control anymore.

- If the Camera control was not configured to support bar code decoding (in the description window) or if no decoding is in progress, the function has no effect.

- This function is equivalent to [CameraStopDecoding](../WDLang1/1000022449.md).
