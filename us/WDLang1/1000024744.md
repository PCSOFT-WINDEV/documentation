
## Reduce (Function)

***In french: Agrège***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Applies a computation to each element of a WLanguage array.

This function can be used:

- on one-dimensional arrays,

- on associative arrays.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.

## Example


```wl
arrValue is array of int = [1,2,3,4,5]
TheSum is int
TheSum = Reduce(arrValue, (Value, SumCalculationVariable) => { RETURN Value + SumCalculationVariable }, 0)
Trace(TheSum)
// Note: This example is for illustrative purposes only; to find the sum of elements of an array,
// it is preferable to use the Sum function
```



```wl
// -> count the number of strings in an array that contain the letter "e" (Prefix syntax)
arr3 is array of strings = ["a","one","some","our","their"]
let Cpt = Reduce(arr3, ( Source, Total ) => { RETURN Total + (Source [=] "e"? 1 ELSE 0 ) }, 0)
// Cpt = 3
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = Reduce(<Array> , <Operation to perform> [, <Initial value>])`
---

**`<Result>: (Type corresponding to the result)`**

Result of the requested reduce operation.

**`<Array>: (WLanguage array)`**

Name of the Array variable to use. This array can be: 

- a one-dimensional array.

- an associative array.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.




**`<Operation to perform>: (WLanguage procedure)`**

Name of WLanguage procedure to run. This procedure can be: 

- a global or local procedure, 

- an internal procedure. 


It is also possible to directly use a lambda. 

**`<Initial value>: (Optional parameter, type corresponding to the initial value)`**

Initial value to use the first time the &lt;Operation to perform&gt; procedure is run.

## Remarks


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000108"></a>

The &lt;Operation to perform&gt; procedure is called once with multiple parameters:

- the first element of the array,

- the element key.
	In the case of a simple array, the key corresponds to the element index. This parameter is optional.
	In the case of an associative array, the key is the indexing key. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.

- the initial value specified with &lt;Initial value&gt;.




The procedure is then called for all other elements of the array with two parameters: 

- the element of the array,

- the element key.
	In the case of a simple array, the key corresponds to the element index. This parameter is optional.
	In the case of an associative array, the key is the indexing key.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.

- the value returned by the previous call.




**Illustrative example**
Let's take a look at the following example:

```wl
arrValue is array of int = [1,2,3,4,5]
TheSum is int
TheSum = Reduce(arrValue, (Value, TheSum) => { RETURN Value + TheSum }, 0)
```

In this example, the code:
```wl
TheSum = Reduce(arrValue, (Value, TheSum) => { RETURN Value + TheSum }, 0)
```
is equivalent to the following code:
```wl
TheSum = Reduce(arrValue, Adds, 0)
	
	INTERNAL PROCEDURE Adds(Value, Total)
		RETURN Value + Total
	END
```

With this internal procedure, the calculation can be broken down as follows: 

- IntermediateResult1 = Adds (t[1], InitialValue). In the example, Adds( 1, 0 ) -> 1

- IntermediateResult2 = Adds (t[2], IntermediateResult1). In the example, Adds( 2, 1 ) -> 3

- ...


Note: This example is for illustrative purposes only. To find the sum of elements of an array, it is preferable to use [Sum](../WDLang1/1000019892.md).
