
## InApplicationTestMode (Function)

***In french: EnModeTestApplication***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines if there is an application test in progress.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF InApplicationTestMode() THEN
 	// Specific initialization for automatic application test
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = InApplicationTestMode()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if an automatic application test is in progress, 

- <u><u><u><u>False</u></u></u></u> otherwise.










<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Function availability
<a name="function_availability_ELTPARAGRAPHE000160"></a>

**InApplicationTestMode** can be used in all IDEs to allow for cross-platform code. Functions or procedures that use **InApplicationTestMode** can be shared between several products without generating any compilation error.
