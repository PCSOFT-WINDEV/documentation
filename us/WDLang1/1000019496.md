


## SchedulerDisplayNextPeriod (Function)

***In french: PlanningAffichePeriodeSuivante                        ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Moves the time area displayed on the next area (next weeks for example) in a Scheduler control. The Scheduler control is displayed from the day corresponding to the next time area. 

**Note** The [SchedulerDisplayPreviousPeriod](../WDLang1/1000019495.md) and **SchedulerDisplayNextPeriod** functions are used to implement simple "Next / Previous" Button control fields. These controls allow you to scroll through the time areas displayed by the Scheduler control.
 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click the BTN_Next Button control
SchedulerDisplayNextPeriod(SCH_OfficeScheduling)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`SchedulerDisplayNextPeriod(<Scheduler control>)`
---

**`<Scheduler control>: (Control name)`**

Name of the Scheduler control to be used.
