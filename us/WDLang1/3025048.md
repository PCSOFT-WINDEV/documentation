
## DeleteParameter (Function)

***In french: SupprimeParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a parameter or a set of saved parameters: 

- with the [SaveParameter](../WDLang1/3025046.md) function,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) automatically via the [data persistence](../WDChamp/9000019.md) in the controls.




**Warning**: This operation is irreversible and cannot be undone.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete a parameter (syntax 1)
DeleteParameter("MyParameter")
```

## Syntax

### Deleting a saved parameter

`<Result> = DeleteParameter(<Parameter name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Parameter name>: (Character string)`**

Name of parameter to delete. This parameter is sought: 

- in the registry (or equivalent file on the runtime platform), 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) in the parameter file specified by [InitParameter](../WDLang1/3025044.md). 


This name can be a value or a full path (the accepted separators are the dot (.) and the slash (\\)). For a full path, all the values found "below" this path will be deleted (see example in the Notes section).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If the selected initialization mode is the registry, **DeleteParameter** is case and accent-insensitive (Parameter and parameter are equivalent).

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
### Deleting all the parameters saved for the specified element

`<Result> = DeleteParameter(<Element name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md).




**`<Element name>: (Character string)`**

Name of the control or window whose saved parameters must be deleted. This element is sought in the parameter file specified by [InitParameter](../WDLang1/3025044.md) (in the registry by default).

### Deleting all the saved parameters

`<Result> = DeleteParameter()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, you can get more details on the error with [ErrorInfo](../WDLang1/3013008.md). 




All the parameters saved by the application are deleted. During the next start, the application will behave like if it was its first start.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) The parameter file of the application specified by [InitParameter](../WDLang1/3025044.md) is entirely cleared. If the parameters have been saved in a INI or XML file, this file is deleted.

### Special cases
<a name="special_cases_ELTPARAGRAPHE000230"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) In Android, the persistent values are saved in the Shared Preferences of the application.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In iOS, the persistent values are stored in the parameters of the application ("NSUserDefault"). 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a WEBDEV website, persistent values are stored in a browser cookie.
