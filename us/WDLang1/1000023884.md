


## &lt;Window&gt;.Iconize (Function)

***In french: &lt;Fenêtre&gt;.Iconise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Minimizes a WINDEV window.

**Note** The function **&lt;Window&gt;.Iconize** function performs the same action as the minimize button in the top right-hand corner of windows.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Minimizes the "WIN_EditCustomer" window
WIN_EditCustomer.Iconize()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Window>.Iconize()`
---

**`<Window>: (Window name)`**

Name of window to minimize.
Note: If the specified window corresponds to a child window, the parent window is also iconized..  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
To find out whether a window is minimized, use [WinSize](../WDLang1/3038020.md).
