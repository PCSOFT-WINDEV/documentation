


## Input suggestion functions
			



**Note**: These functions are also available in prefix syntax ([Sliding Banner functions (prefix syntax)](../WDLang2/1000022632.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to program input suggestion options in Edit controls:



|   |   |
| --- | --- |
| [AssistedInputAdd](../WDLang1/1000020043.md) | Adds a row to the list of values available in the input suggestions of an Edit control. |
| [AssistedInputClose](../WDLang1/1000020049.md) | Closes the list of input suggestion of an Edit control. |
| [AssistedInputConfigure](../WDLang1/1000021074.md) | Specifies how to open and filter the autocomplete suggestion list. |
| [AssistedInputDeleteAll](../WDLang1/1000020044.md) | Clears the values in the suggestion list of an Edit control. |
| [AssistedInputOpen](../WDLang1/1000020048.md) | Opens the list of suggestions of an Edit control. |
