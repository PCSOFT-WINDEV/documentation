


## EventChange (Function)

***In french: SignalModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the status of an event.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create an event
EventCreate("Let's go", eventManual, eventClose)
// Run a first thread
ThreadExecute("Thread1", threadNormal, "Thread_First")
// Locks the current thread until the event is obtained
ThreadWaitSignal()

// Run a second thread
ThreadExecute("Thread2", threadNormal, "Thread_Second")
// Locks the current thread until the event is obtained
ThreadWaitSignal()

// Modifies the event to run the threads
EventChange("Let's go", eventOpen)
```

```wl
//----------------------------------------------
PROCEDURE Thread_First()
Trace(dbgInfo(dbgProcess) + " - ThreadSendSignal(threadMain)")
ThreadSendSignal(threadMain)
EventWait("Let's go")
Trace(dbgInfo(dbgProcess) + " - Event received")
```

```wl
//--------------------------------------------
PROCEDURE Thread_Second()
Trace(dbgInfo(dbgProcess) + " - ThreadSendSignal(threadMain)")
ThreadSendSignal(threadMain)
EventWait("Let's go")
Trace(dbgInfo(dbgProcess) + " - Event received")
```

## Syntax

`EventChange(<Event> [, <New status>])`
---

**`<Event>: (Character string)`**

Name of the event to modify. If this event does not exist, it is automatically created with the default options (automatic mode) and in the specified status.

**`<New status>: (Optional constant)`**

Status of the event:


|   |   |
| --- | --- |
| *eventClose* | Closes the event.<br>This constant is equivalent to [EventClose](../WDLang1/1000021272.md). |
| *eventOpen*<br>(Default value) | Opens the event. If threads are waiting for the event, they are automatically unlocked. <br>This constant is equivalent to [EventOpen](../WDLang1/1000021271.md). |
| *eventOpenAndClose* | Opens the event, unlocks all the pending threads and closes the event.<br>This constant is not recommended. It is kept for backward compatibility. |

## Remarks


### Summary table about the operating mode of event
<a name="summary_table_about_the_operating_mode_event_ELTPARAGRAPHE000113"></a>

| Value of EventChange | Automatic event (by default) | Manual event |
| --- | --- | --- |
| *eventOpen* | A single thread is processed by the event. <br>The event is automatically closed once the thread is processed. <br>**Waiting threads** If no thread was waiting, the signal remains open until the next thread passes, then closes again. <br>**New threads** If more threads arrive, they are put on hold. | The event is opened. <br>**Waiting threads**: All waiting threads pass through. <br>**New threads**: If other threads arrive while the signal is still open, they pass. |
| *eventOpenAndClose*<br>**This constant is not recommended. It is kept for backward compatibility.** | A single thread is processed by the event. <br>The event is automatically closed once the thread is processed. <br>**Waiting threads** If no thread is waiting, the signal remains closed. <br>**New threads** If more threads arrive, they are put on hold. | All the threads are processed by the event. <br>The event is automatically closed once all the threads are processed. <br>**New threads** If more threads arrive, they are put on hold. |
| *eventClose* | The event remains closed. <br>**New threads** If more threads arrive, they are put on hold. | The event is closed. <br>**New threads** If more threads arrive, they are put on hold. |
