


## Thread (Variable type)

***In french: Thread***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Thread** type allows you to define all the characteristics of a thread. You can define and change the characteristics of this thread using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Declare a variable to handle a thread
t is thread
// Build a thread and trigger its execution on a procedure
t = ThreadExecute(Proc, ("First parameter", 2))
```



```wl
// Build a thread
t is Thread(Proc, ("First parameter", 2))
// Trigger the execution of the thread
ThreadExecute(t)
```



## Declaration
<a name="declaration_ELTTEXTE000295"></a>
<a name="SYNTAXE1"></a>

### Declaring a non-described thread

`MyVariable is Thread`
---

In this case, the thread is not described. The variable will have to be assigned with an existing thread or with the result of one of the thread execution functions.


<a name="SYNTAXE2"></a>

### Describing a thread via the Thread type

`MyVariable is Thread (<Procedure> [, <Parameters> [, <Options>]])`
---

**`<Procedure>: (Character string or Procedure variable)`**

Procedure to run. This parameter can correspond to: 

- the name of the procedure to run. 

- the name of [Procedure](../Motscles/1000018907.md) variable corresponding to the procedure to run.




**`<Parameters>: (List of values enclosed in brackets and separated by commas)`**

Parameters of procedure to run. This list of parameters has the following format: 


```txt
(<Parameter 1>, ..., <Parameter N>)
```
where: 

- &lt;Parameter 1&gt;: First parameter of the procedure.

- ...

- &lt;Parameter N&gt;: Nth parameter of the procedure.




**`<Options>: (Optional Integer constant)`**

Mode for starting the thread.


|   |   |
| --- | --- |
| *threadFullCopyHFSQLContext*<br>(Default value) | Triggers the immediate copy of the current HFSQL context.<br>Recommended if the thread must take into account the current positions in the files and queries of caller context. |
| *threadGlobalContext* | Forces the use of the global context of the project if the thread is run from a window. The thread will continue to run until the application is closed.<br>The window context is used by default, therefore the thread is stopped when closing the window. |
| *threadLightCopyHFSQLContext* | Triggers the immediate copy of a part of the current HFSQL context. <br>The following elements are stored: <br><br>- the directories where the HFSQL Classic data files are located. <br><br>- HFSQL Client/Server connections.<br><br><br> |
| *threadWaitForStart* | Waits for the actual start of the thread before continuing the execution. |



**In this case**:

- **the thread is described and its description can no longer be modified.** 
	The thread is not executed automatically, so a declaration alone will not start the execution of the thread. You must call one of the thread execution functions to start the thread execution.

- **thread safety is automatically implemented**. In this mode:

	- a compilation error will occur if the controls are accessed in the thread. 

	- an exception will be thrown: 

		- if the thread accesses the controls at runtime,

		- if the [ThreadStop](../WDLang1/3077019.md) function is called.




- when the window that triggered the thread is closed, a request to stop the thread is generated (but the thread continues to run after the window is closed).

## Properties


### Properties specific to Thread variables
<a name="properties_specific_thread_variables_ELTPARAGRAPHE000116"></a>

The following properties can be used to handle **Thread** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Extra | Variant | Allows you to store advanced information without affecting the execution of the application. You can store values of any type (array, etc.). It is also possible to add members to the **Extra** property. <br>Example: <br><br><pre><code>MyVariable.Extra.Info1 = Value<br>MyVariable.Extra[Info2] = Value2<br>MyVariable.Extra.Date = DateSys()</code></pre><br> |
| Name | Character string | Thread name. <br><br>**This property is read-only**. |
| Priority | Integer constant | Current thread priority:<br><br>- *PriorityHigh*: High priority.<br><br>- *PriorityNormal*: Normal priority.<br><br>- *PriorityLow*: Low priority.<br><br><br><br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/us/APPLEWATCH.png) Not available. |
| ReturnedValue | Value returned by the thread. | Caution: <br><br>- If the thread is still running, the **ReturnedValue** property blocks the execution until the thread terminates.<br><br>- If the thread terminates without a fatal error, the property returns the return value(s) of the main procedure of the thread.<br><br><br><br><br>**This property is read-only**. <br><br>Reminder:<br><br>- The **State** property is used to determine the state of the thread. <br><br>- It is possible to wait for the end of a thread with [ThreadWait](../WDLang1/3077020.md). <br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This property is non-blocking in Android 6. An error appears if the thread has not completed execution. |
| State | Integer constant | Thread state:<br><br>- *threadStopRequested*: The thread has been requested to stop. <br><br>- *threadRunning*: The thread is running. <br><br>- *threadNotExecuted*: The thread has not been executed. <br><br>- *threadSuspended*: The thread has been suspended. <br><br>- *threadEnded*: The thread exists but has terminated. <br><br><br><br><br>**This property is read-only**. |
| StopRequested | Boolean | <br><br>- <u><u><u>True</u></u></u> if the thread was requested to stop, <br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**. |
