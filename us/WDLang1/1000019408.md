
## ExceptionDisplay (Function)

***In french: ExceptionAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays the standard window of exceptions with the content of the current exception.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The standard window of exceptions is displayed in test mode only. The window is not displayed during the execution of the site.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WHEN EXCEPTION IN
	Proc()
DO
	// Display the exception
	ExceptionDisplay()
	// Specific code after the display
	...
	// End of application
	EndProgram()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ExceptionDisplay()`
---

**`<Result>: (Integer constant)`**

Operation performed on the window by the user: 


|   |   |
| --- | --- |
| *edEndProgram* | "Restart the application" was not checked by the user. |
| *edRelaunchProgram* | "Restart the application" was checked by the user. |


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The standard window of exceptions is displayed in test mode only. The window is not displayed during the execution of the site. In this case, &lt;Result&gt; is set to *edEndProgram*.
