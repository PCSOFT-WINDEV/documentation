


## Palette (Variable type)

***In french: Palette***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Palette** type is used to define the advanced characteristics of a color palette. You can define and change the characteristics of this palette using different WLanguage properties. 

This type of variable is used: 

- by the [Icon](../WDLang1/1000020811.md) type.  

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) to manipulate color palettes for use in windows and projects. 




**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve the first palette color for the first image of an icon
MyIcon is Icon = "MyIcon.ico"
Palette1 is Palette = MyIcon.Palette[1]
Color1 is Color = Palette1[1]
```

<a name="PROPS"></a>

## Properties


### Properties specific to Palette variables
<a name="properties_specific_palette_variables_ELTPARAGRAPHE000045"></a>

The following properties can be used to handle a color palette:

| Property name | Type used | Effect |
| --- | --- | --- |
| Color | Array of [Color](../WDLang1/1000019661.md) | Array containing the palette colors. |
