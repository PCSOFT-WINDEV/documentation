


## Background (Variable type)

***In french: Fond***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Background** type defines the advanced characteristics of the element background. You can define and change the characteristics of this background using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Draw a rectangle with blue borders, green background and rounded corners
// in an Image control

// Initializes the drawing in the Image control
dStartDrawing(IMG_Drawing)

Rect is Rectangle
Rect.X = 10
Rect.Y = 15
Rect.Width = 100
Rect.Height = 150
BorderStyle is Border
BorderStyle.Color = LightBlue
BorderStyle.Round = 30
BorderStyle.Thickness = 1
BackgroundStyle is Background
BackgroundStyle.Color = LightGreen
dBorder(Rect, BorderStyle, BackgroundStyle)
```

## Properties


### Properties specific to Background variables
<a name="properties_specific_background_variables_ELTPARAGRAPHE000040"></a>

The following properties can be used to handle the background of an element:

| Property name | Type used | Effect |
| --- | --- | --- |
| Color | [Color](../WDLang1/1000019661.md) variable | Background color. |
| Gradient |   | Gradient of the background color: <br><br>- Property **StartColor** (type [Color](../WDLang1/1000019661.md)): Gradient start color. <br><br>- Property **ColorFin** (type [Color](../WDLang1/1000019661.md)): Gradient end color.<br><br>- **property Angle** (integer): Angle to be used for gradient color selection. The angle value is included between 0 (horizontal angle, default value) and 360°.<br><br>- Property **Color3** (type [Color](../WDLang1/1000019661.md)): Color to be used in the Gradient.<br><br>- Property **DistanceColor3** (integer): Percentage separating start color and color 3. <br><br>- Property **Color4** (type [Color](../WDLang1/1000019661.md)): Color to be used in the Gradient.<br><br>- **property DistanceColor4** (integer): Percentage separating start color and color 4.  <br><br><br><br><br>The color parameters are used as follows:<br><br><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=drectangledegrade.gif)<br><br><br>The angle is used to define the orientation of the gradient.<br><br><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=angle_degrade.gif)<br><br><br>Gradients with 3 or 4 colors are only available for 0 or 90 degree angles.<br><br>**Remarks**: <br><br>- On some systems (e.g., 256-color Remote Desktop Connection), gradients are not available. In this case, the color defined via the **ColorStart** property is used.<br><br>- Gradient backgrounds are not supported in docx documents. <br><br><br> |
| Hatch | Integer constant | Type of hatching used: <br><br>- *HatchingNone*: No hatching. <br><br>- *Crosshatch*: Crosshatch.<br><br>- *DiagonalCrossHatch*: DiagonalCrossHatch.<br><br>- *DiagonalSplit*: 60% diagonal splits.<br><br>- *DiagonalHatchBottom*: 120% diagonal hatches.<br><br>- *HorizontalHachure*: Horizontal Hachure.<br><br>- *VerticalHatch* Vertical hatching. <br><br><br> |
| Type | Integer constant | Type of background: <br><br>- *FullBottom* Solid background.<br><br>- *TransparentBackground* Transparent background (the Property **Color** property is ignored).<br><br>- *Hatching background* Hatching Background (the Property **Hatch** property is taken into account). <br><br>- *GradientBackground* Gradient: Background with a color gradient (the Property **Gradient** property is taken into account).<br><br><br> |
