
## fExtractResource (Function)

***In french: fExtraitRessource***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extracts a resource from the application into a physical device location.

**Remarks**: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The resource to extract must have been included in the generated application by the generation wizard (see Notes). 

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) In WINDEV applications or WEBDEV websites, the resource to extract must be: 

	- in the "Other" category of the [Project explorer](../Editeurs/2027029.md) pane,

	- in the main library of the application (WDL file). 




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This function can be used in the Android simulator. 




Warning: To prevent source code piracy, WINDEV, WEBDEV and WINDEV Mobile elements (states, windows, etc.) cannot be extracted at runtime.

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Reads the content of readme.txt text file included in the application resources
IF fExtractResource("readme.txt", "/sdcard/extraction.txt") = True THEN
	EDT_Text = fLoadText("/sdcard/extraction.txt") 
END
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Used to precisely locate the HFSQL data on the Android Smartphone
sDataPath is string = SysRepDirStorageCard() + fSep() + "Customer tests"  + fSep()
IF NOT fDirectoryExist(sDataPath) THEN fMakeDir(sDataPath)
fExtractResource("Product.fic", sDataPath + "Product.fic")
fExtractResource("Product.ndx", sDataPath + "Product.ndx")
fExtractResource("Product.mmo", sDataPath + "Product.mmo")
IF NOT HChangeDir(Product, sDataPath) THEN
	Error(HErrorInfo())
END
```


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Extracts all the images in PNG format
fExtractResource("*.png", CompleteDir(SysDirStorageCard()) + "images")
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fExtractResource(<Resource name> [, <Destination>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the resource was extracted,

- <u><u><u><u>False</u></u></u></u> otherwise. If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Resource name>: (Character string)`**

Name of resource to extract (file name with its extension).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Wildcard characters (\* and?) are allowed. This allows you to extract several resources in a single call. In this case, the &lt;Destination&gt; parameter must correspond to a directory (that exists or not).

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) The resource to extract must be found in the main application library (WDL file). The library must have not been loaded by [LoadWDL](../WDLang1/3013020.md).

**`<Destination>: (Optional character string)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Full or relative path of destination file. This path can be relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
If the directory exists, the resource is directly extracted into this directory.
The directory is created if it does not exist. 
If this parameter is not specified or is an empty string (""), the resource will be extracted into the current application directory in a file named like the resource.
The destination file will be overwritten if it already exists before the extraction.
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) Full path of destination file. This parameter is case-sensitive. 
If the directory exists, the resource is directly extracted into this directory.
The directory is created if it does not exist.
If this parameter is not specified or is an empty string (""), the resource will be extracted into the "Documents" application directory in a file named like the resource.
The destination file will be overwritten if it already exists before the extraction.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) Full path of destination file. 
If the directory exists, the resource is directly extracted into this directory.
The directory is created if it does not exist. 
If this parameter is not specified or is an empty string (""), the resource will be extracted into the application data directory (returned by [fDataDir](../WDLang1/3036001.md)) in a file named like the resource.
The destination file will be overwritten if it already exists before the extraction.

### Generation wizard
<a name="generation_wizard_ELTPARAGRAPHE000174"></a>

The Android or iPhone/iPad application generation wizard lets you specify whether files and libraries are to be integrated into the application. 

In an Android application, you have the ability to include: 

- specific resources. 

- specific Java archives. 




Then, these files can be: 

- used directly (files to be read, for example: sound files, image files, etc.). 

- extracted with **fExtractResource** (e.g., files that will be modified by the application)




If an image is included in the application, it can be directly assigned to a control by specifying its name. For example: 


```wl
IMG_Image = image1
```

### Special case: database extraction
<a name="special_case_database_extraction_ELTPARAGRAPHE000223"></a>

If the file to extract is an SQLite database, use [fDataDir](../WDLang1/3036001.md) to extract it into the data directory of the application ("databases" directory). 

Example: 


```txt
fExtractResource(<Database vame>.db, CompleteDir(fDataDir()) + <Database name>.db)
```


To connect to this database, all you have to do is specify &lt;Database name&gt;.db as source for the SQLite connection. For more details, see [Android application: Using a database](../Editeurs/9000123.md). 
<a name="NOTE0_3"></a>


### Special case: ".WDD" file (analysis description)
<a name="special_case_wdd_file_analysis_description_ELTPARAGRAPHE000243"></a>

An analysis description (".WDD" file) integrated to the library of an application cannot be extracted. 

To extract a file from a library that cannot be extracted by **fExtractResource**, you can use an HFSQL data file integrated in the library.
