
## TypeIsNullable (Function)

***In french: TypeEstNullable***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines whether an element is nullable. 
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
PROCEDURE AProcedure(AParameter)
IF TypeIsNullable(AParameter) THEN
	// ...
END
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = TypeIsNullable(<Expression>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the element passed as parameter is nullable,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Expression>: (Corresponding type)`**

Expression to manipulate.
