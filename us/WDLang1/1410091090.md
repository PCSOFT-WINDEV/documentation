


## SysEncrypt (Function)

***In french: SysCrypte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Encrypts data using Windows user credentials.

Data can be decrypted ([SysDecrypt](../WDLang1/1410091091.md)) only by the user who encrypted the data and on the computer where it was encrypted.
For example, encrypted data can be saved in a file and then decrypted by the same user on the same computer as the application that encrypted the data.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Buffer encryption
MyBuffer is Buffer
MyEncryptedBuffer is Buffer = SysEncrypt(MyBuffer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = SysEncrypt(<Buffer> [, <Application password>])`
---

**`<Result>: (Buffer)`**



- Buffer containing the encrypted data.

- Empty buffer if an error occurs. [ErrorInfo](../WDLang1/3013008.md) returns the details of the error.




**`<Buffer>: (Character string or Buffer)`**

Buffer to encrypt.

**`<Application password>: (Optional buffer)`**

Password used to apply an additional encryption key (salt).

- If this parameter is not specified, data will be encrypted without a salt.

- If this parameter is specified, it must also be used for data decryption. 


This password prevents another application launched by the same user on the same computer from decrypting the data, if it doesn't have the password.
Note: To initialize this buffer using a string, it is recommended to use a UTF-8 string in applications that use ANSI or Unicode strings.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter can be "Buffer - ASCII" or "Buffer - UTF-8".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If the user changes their password between encryption and decryption, they will still be able to decrypt the data.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The credentials used are those of the Windows account used to run the sites and web services (set up for the site administrator in the WEBDEV Account Manager).
	All users of sites managed by the same WEBDEV server account share the same Windows user.
	As a result, if a user on a site encrypts data, this data can be decrypted by another user on this site, or on another site managed by the same account (provided the user has access to this data).
