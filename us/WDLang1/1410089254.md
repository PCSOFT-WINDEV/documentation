


## &lt;Image variable&gt;.DrawTextMarkdown (Function)

***In french: &lt;Variable Image&gt;.DessineTexteMarkdown***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Draws Markdown text in a variable of type [Image](../WDLang1/1000019650.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is Image
// Draw Markdown text at 8,10 in the MyImage variable
s is string = [
# Title
Row 2 with **bold**
*Italics* on row 3
]
MyImage.Font("Arial", 16)
MyImage.Pen(LightGreen) // light green text
MyImage.DrawTextMarkdown(8, 10, s, MyImage.Width-16)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Image variable>.DrawTextMarkdown(<X-coordinate> , <Y-coordinate> , <Markdown text> [, <Text color>])`
---

**`<Image variable>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used.

**`<X-coordinate>: (Integer)`**

X-coordinate of text to draw (in pixels).

**`<Y-coordinate>: (Integer)`**

Y-coordinate of text to draw (in pixels).

**`<Markdown text>: (Type corresponding to the text to draw)`**

Markdown text to draw.

**`<Text color>: (Integer or constant (optional))`**

Color to use for the Markdown text. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the color of the text:

- is Black if [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) has not been used beforehand,

- corresponds to the color specified in the last call to [&lt;Image&gt;.Pen](../WDLang1/1000024016.md).

## Remarks


### Font
<a name="font_ELTPARAGRAPHE000347"></a>

By default:

- The font used is "MS Sans Serif" (size 13).

- The writing direction is horizontal (from left to right).

- The coordinates of the upper-left corner of the image are (0,0).

- The "&" character is not interpreted.




To change these parameters, use [&lt;Image variable&gt;.Font](../WDLang1/1000024232.md).
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The default font may differ according to the system on which the application is run.
<a name="NOTE0_2"></a>


### Background color
<a name="background_color_ELTPARAGRAPHE000372"></a>

By default, the background color of an Image control is transparent. To change the background color of an Image control, use the [BackgroundColor](../Proprietes/2510022.md) property.
<a name="NOTE0_3"></a>


### Coordinates
<a name="coordinates_ELTPARAGRAPHE000385"></a>

Coordinates are specified with respect to the upper-left corner of the image or Image control (coordinates: (0,0)).

The coordinates correspond to the upper-left corner of the rectangle into which the text will be drawn. The precise location of the text in this rectangle depends on the size, shape and attributes of the font.

### Limitations
<a name="limitations_ELTPARAGRAPHE000466"></a>

In anti-aliasing mode ([&lt;Image variable&gt;.ChangeMode](../WDLang1/1000024039.md)) or in opacity mode ([&lt;picLayer variable&gt;.StartDrawing](../WDLang1/1000024470.md)), **&lt;Image variable&gt;.DrawTextMarkdown** is available for the TrueType fonts only.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000495"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000515"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
