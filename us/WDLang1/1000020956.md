


## DashMode (Function)

***In french: TDBMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens or closes the Dashboard control edit mode.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Informs the user if the Dashboard control is already in edit mode
IF DashMode(DASH_Dashboard) <> dashNoModif THEN
	Error("The dashboard is in edit mode already")
	RETURN
END
nOption is int
// Defines the edit option
IF CBOX_EditOptions[1] THEN nOption += dashMove
IF CBOX_EditOptions[2] THEN nOption += dashResize
IF CBOX_EditOptions[3] THEN nOption += dashDelete
// Checks that at least one option is checked
IF nOption = 0 THEN
	Error("At least one edit option must be checked")
	SetFocusAndReturnToUserInput(CBOX_EditOptions)
END
// Modifies the edit mode
DashMode(DASH_Dashboard, nOption)
```
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Disable the deletion of widgets 
// but not their move or resizing:
DashMode(DASH_NoName1, dashMove + dashResize)
// Caution, to avoid displaying the toolbar, 
// you must use DissableAAF (or AAFDisable) with the constant aafDashEditTdbMode.
```

## Syntax
<a name="SYNTAXE1"></a>

### Changing the mode of the Dashboard control 

`DashMode(<Dashboard control> , <Mode>)`
---

**`<Dashboard control>: (Control name)`**

Name of the Dashboard control to be used. 

**`<Mode>: (Integer constant (or combination of constants))`**

Edit options available for the user: 


|   |   |
| --- | --- |
| *dashDelete* | Switch to edit mode: the user can hide Widgets in the Dashboard control array. |
| *dashMove* | Switch to edit mode: the user can move Widgets into the Dashboard control array. |
| *dashNoModif* | Edit mode closed: the user cannot edit Widgets in the Dashboard control array.<br><br>This constant cannot be combined with the other constants. |
| *dashResize* | Switch to edit mode: users can resize Widgets in the Dashboard control array. |




<a name="SYNTAXE2"></a>

### Finding out the current mode of the Dashboard control

`<Result> = DashMode(<Dashboard control>)`
---

**`<Result>: (Integer constant)`**

Current edit mode of Dashboard control: 


|   |   |
| --- | --- |
| *dashDelete* | Edit mode: the user can hide Widgets in the Dashboard control array. |
| *dashMove* | Edit mode: the user can move Widgets into the Dashboard control array. |
| *dashNoModif* | Classic mode: the user cannot modify Widgets in the Dashboard control array. |
| *dashResize* | Edit mode: users can resize Widgets in the Dashboard control array. |



**`<Dashboard control>: (Control name)`**

Name of the Dashboard control to be used.

## Remarks

### Disabling options and bar of the edit mode
<a name="disabling_options_and_bar_the_edit_mode_ELTPARAGRAPHE000135"></a>

**DashMode** is used to disable some features of the Dashboard control. Deleting these features can make changes to the bar of the edit mode. Thus, if it is no longer possible to remove widgets, the bin button is not displayed in the toolbar.

Note: To completely disable toolbar display on the Dashboard control array, use the [AAFDisable](../WDLang1/1000022018.md) function with the constant *faaTdbModeEdition*. 


### Deleting the Edit mode for the end user (via the AAF)
<a name="deleting_the_edit_mode_for_the_end_user_via_the_aaf_ELTPARAGRAPHE000149"></a>

**DashMode** is used to switch to edit mode programmatically. 

To prevent the user from switching to edit mode (via the context menu or with a long click), use [AAFDisable](../WDLang1/1000022018.md) with the *aafDashEditMode* constant.
