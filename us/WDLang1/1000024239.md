


## &lt;Image variable&gt;.Fill (Function)

***In french: &lt;Variable Image&gt;.Remplissage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Colors an area in a variable of type [Image](../WDLang1/1000019650.md).

This coloring is applied to all the juxtaposed points that have the same color as the specified start point.



![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is Image = "Test.bmp"

// Color an area in light blue
MyImage.Fill(10, 50, LightBlue)
IMG_MyDrawing = MyImage
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Image variable>.Fill(<X> , <Y> [, <Fill color> [, <Color of limits>]])`
---

**`<Image variable>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used.

**`<X>: (Integer)`**

X-coordinate (in pixels) of the point inside the area to color. This position is given in relation to the upper-left corner of the image control (coordinates set to (0,0)).

**`<Y>: (Integer)`**

Y-coordinate (in pixels) of the point inside the area to color. This position is given in relation to the upper-left corner of the image control (coordinates set to (0,0)).

**`<Fill color>: (Integer or constant (optional))`**

Color used to fill the area. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the fill color:

- is *Transparent* if [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) has not been used beforehand, 

- corresponds to the color specified in the last call to [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md).




**`<Color of limits>: (Integer or constant (optional))`**

Area border color. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




If this parameter is not specified, the area border color adapts to the fill color.

## Remarks


### Drawing in anti-aliasing mode
<a name="drawing_antialiasing_mode_ELTPARAGRAPHE000423"></a>

When drawing in anti-aliasing mode (*drawAntiAliasing* constant in [&lt;Image variable&gt;.ChangeMode](../WDLang1/1000024039.md)), the graphics card smooths out the points and colors used in the border of shapes.

In this case, &lt;Border color&gt; is not displayed in the drawing and the fill is applied to the entire drawing.
<a name="NOTE0_2"></a>
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000452"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Limitation for function &lt;Image variable&gt;.Fill**: Opacity defined with function [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) is not taken into account.
<a name="NOTE0_3"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000476"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
