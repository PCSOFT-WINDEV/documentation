


## &lt;Image variable&gt;.Crop (Function)

***In french: &lt;Variable Image&gt;.Découpe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the cropped part of an image. This image is in a variable of type [Image](../WDLang1/1000019650.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyCroppedImage is Image
MyImage is image
MyImage = "image.png"

MyCroppedImage = MyImage.Crop(10, 10, 100, 100)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Cropping an image by specifying coordinates

`<Result> = <Image variable>.Crop(<X> , <Y> , <Width> , <Height>)`
---

**`<Result>: (Image variable)`**

[Image](../WDLang1/1000019650.md) variable containing the cropped image.

**`<Image variable>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable corresponding to the image to be cropped.

**`<X>: (Integer)`**

X-coordinate (in pixels) of the upper-left corner of the area to be cropped.

**`<Y>: (Integer)`**

Y-coordinate (in pixels) of the upper-left corner of the area to be cropped.

**`<Width>: (Integer)`**

Width of the area to crop.

**`<Height>: (Integer)`**

Height of the area to crop.

### Cropping an image using a rectangle

`<Result> = dCrop(<Image> , <Rectangle>)`
---

**`<Result>: (Image variable)`**

[Image](../WDLang1/1000019650.md) variable containing the cropped image.

**`<Image>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable corresponding to the image to be cropped.

**`<Rectangle>: (Rectangle variable)`**

Name of the [Rectangle](../Motscles/1514079.md) variable corresponding to the area to be cropped in the image.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
This function triggers a non-fatal error if the area to crop is invalid (area larger than the source image or empty area).
