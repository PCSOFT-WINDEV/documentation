
## TrustedCertificateAdd (Function)

***In french: CertificatDeConfianceAjoute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a certificate to the list of trusted root authorities used to validate certification strings. 

Caution: This action only applies to the current application. No additions are made in the Windows certificate stores.

Note: This function affects: 

- HTTP requests that use [httpRequest](../WDLang3/1000021158.md) variables,

- File management by FTPS,

- SSL sockets, 

- MQTT via SSL,

- the verification of signatures (2nd syntax of [CertificateCheckString](../WDLang1/1000019298.md)).



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
TrustedCertificateAdd("MyAC.pem")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = TrustedCertificateAdd(<Certificate>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the addition was performed,

- <u><u><u><u>False</u></u></u></u> if an error occurs. 




**`<Certificate>: (Character string)`**

Path of the certificate file to add to the list of trusted root authorities. 

Note: This file can be included in the application's library (WDL file).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- Certificates in cer, pem, der and p12 formats are supported.

- **TrustedCertificateAdd** is taken into account by [SocketConnectSSL](../WDLang3/1000017042.md) only if the mode used for Socket functions supports OpenSSL ([SocketConfigure](../WDLang3/1410088949.md)):
	
	```wl
	SocketConfigure(socketConfigureMode, 1)
	```
