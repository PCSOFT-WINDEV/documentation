


## OrganizerDeleteAppointment (Function)

***In french: AgendaSupprimeRendezVous***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes an appointment from an Organizer control. If the Organizer control is linked to a data source, the appointment is also deleted from the data source. 






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000020057&name=organizerdeleteappointment_function">See additional examples</a>

```wl
// Deletes the selected appointment from the Organizer control 
OrganizerDeleteAppointment(ORG_Organizer1)
```
<a name="Exemple2"></a>

```wl
// Deletes the first added appointment
OrganizerDeleteAppointment(ORG_Organizer1, 1)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Deleting an appointment identified by its index

`OrganizerDeleteAppointment(<Organizer control> [, <Appointment index>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Appointment index>: (Optional integer)`**

Index of the appointment to be deleted. The index of the first appointment is set to 1. If this parameter is not specified, the selected appointment will be deleted.

### Deleting an appointment identified by an Appointment variable

`OrganizerDeleteAppointment(<Organizer control> [, <Appointment to delete>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window. 

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) an Organizer control in a page.




**`<Appointment to delete>: (Appointment variable)`**

Name of the [Appointment](../WDLang1/1000019244.md) variable that corresponds to the appointment to delete. 
If this parameter is not specified, the selected appointment will be deleted.

### Deleting multiple appointments

`OrganizerDeleteAppointment(<Organizer control> [, <Appointment to delete>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window. 

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) an Organizer control in a page.




**`<Appointment to delete>: (Array of Appointment variables)`**

Name of the variable of type Array of [Appointment](../WDLang1/1000019244.md) that corresponds to the appointments to be deleted. 
If this parameter is not specified, the selected appointment will be deleted.
