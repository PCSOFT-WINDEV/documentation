


## ArraySeek (Function)

***In french: TableauCherche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Seeks the index of an element in a WLanguage array. The following searches can be performed:

- Search for an element in a one-dimensional array of simple elements.

- Search for an element in a two-dimensional array of simple elements using a column.

- Search for an element in a two-dimensional array of simple elements using multiple columns.

- Search for an element in a one-dimensional array of structures or classes.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Search for an element in an array of records.

- Search for an object in an array. 




Remarks:

- This function is equivalent to [Seek](../WDLang1/1000017365.md). 

- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) In PHP, the search cannot be performed in an array containing more than one dimension or in an array of structures.

## Example


```wl
arrMyArray is array of 0 string 
// Fill the array
ArrayAdd(arrMyArray, "WINDEV")
ArrayAdd(arrMyArray, "WEBDEV")
ArrayAdd(arrMyArray, "WINDEV and WEBDEV")
// Find "WINDEV"
ResIndex is int
ResIndex = ArraySeek(arrMyArray, asLinearFirst, "WINDEV")
Info("The WINDEV string is at index: " + ResIndice)
// Returns: "The WINDEV string is at index: 1".
```

## Syntax

### Search for an element in a one-dimensional array of simple elements

`<Result> = ArraySeek(<WLanguage array> , <Type of search> , <Search value> [, <Start index>])`
---

**`<Result>: (Integer)`**



- Index of the sought element,

- -1 if the element is not found in the array.




**`<WLanguage array>: (Array)`**

Name of the Array variable to use. This array must be a one-dimensional array.
This array can also correspond to a one-dimensional array associated with a property of an advanced variable.

**`<Type of search>: (Integer constant)`**

Type of search to perform:


|   |   |
| --- | --- |
| *asBinary* | Binary search. <br>This search mode is fast but it must be used on an array sorted in ascending order, without duplicates. <br>Search options (lexicographical order, ignore punctuation, etc.) must be exactly the same for the search (**ArraySeek**) and for the sort ([ArraySort](../WDLang1/3075007.md)). |
| *asLinear* | Linear search. The search starts:<br><br>- from the first element.<br><br>- from the value of the parameter &lt;Start index&gt;.<br><br><br>The search stops at the first element found. |
| *asLinearFirst* | Linear search from the first element. &lt;Start index&gt; is ignored when this constant is specified. |
| *asLinearLast* | Linear search from the last element. This constant must not be used if &lt;Start index&gt; is specified. |
| *asLinearNext* | Linear search for the next element. This search is performed from the current position or the value of &lt;Start index&gt;. |
| *asLinearPrevious* | Linear search for the previous element. This search is performed from the current position or the value of &lt;Start index&gt;. |


The type of search can be combined with one or more search options:



|   |   |
| --- | --- |
| *tccIgnoreAccent* | Accent-insensitive search.<br>This option can only be used on arrays of strings.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tccIgnoreCase* | Case-insensitive search.<br>This option can only be used on arrays of strings. |
| *tccIgnoreInsideSpace* | Search ignoring spaces inside strings.<br>This option can only be used on arrays of strings. |
| *tccIgnorePunctuationAndSpace* | Search ignoring spaces and punctuation.<br>This option can only be used on arrays of strings.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tccIgnoreSpace* | Search ignoring spaces at the beginning and end of strings.<br>This option can only be used on arrays of strings. |
| *tccLexicographicOrder* | Array sorted linguistically.<br>This option is only useful for binary search and has no effect on linear searches.<br>This option can only be used on arrays of strings.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |
| *tccRespectNumeric* | Array sorted by numeric values.<br>This option is only useful for binary search and has no effect on linear searches.<br>This option can only be used on arrays of strings.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This constant is not available. |


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The constants used to define the search options are not available.For a dichotomous search, the search options must be exactly the same as the options that were used to sort the array (see [ArraySort](../WDLang1/3075007.md)).

**`<Search value>: (Any type)`**

Value of the element with the desired index.

**`<Start index>: (Optional integer)`**

Start position for the search (linear search only). This parameter is not required for a binary search.

**`<Type of search>: (Integer constant)`**

**`<Columns>: (Character string)`**



- **Simple array**: List of columns to be searched. The different columns must be separated by a semicolon. For example, "2;3" to search on columns 2 and 3.
	

- **Advanced array**: List of properties to be used for the search. The properties must be separated by a semicolon.




**`<Search value 1>: (Any type)`**

Value of the element with the desired index or property. A value must be indicated for each column or property specified in &lt;Columns&gt;.

**`<Search value 2>: (Any optional type)`**

Value of the element with the desired index or property. A value must be indicated for each column or property specified in &lt;Columns&gt;.



**`<Search value N>: (Any optional type)`**

Value of the element with the desired index or property. A value must be indicated for each column or property specified in &lt;Columns&gt;.

**`<Start index>: (Optional integer)`**

Start position for the search (linear search only). This parameter is not required for a binary search.

**`<Search members>: (Character string)`**



- **Structures and classes**: Names of the search members. To search for multiple members, separate their names using semicolons. It is also possible to chain the members to be searched using "." or ":" between the members. You can also perform a search in the properties of a class.  

- **Advanced types**: Names of the search properties. To search for multiple properties, separate their names using semicolons. It is also possible to chain the properties to be searched using "." or ":" between the properties. For example, "Border.Color".

- **Records**: Names of the search items. To search for multiple items, separate their names using semicolons. It is also possible to chain the items to be searched using "." or ":" between the properties.




**`<Search value 1>: (Any type)`**

Value of the element with the desired member or property. A value must be indicated for each member specified in &lt;Search members&gt;.

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000775"></a>

- This function cannot be used on fixed arrays.

- This function can be used on arrays of advanced variables. 

- This function cannot be used on arrays of "Dynamic objects". The type of the objects must be specified. 

- This function must be used on arrays of **typed** objects.

	- For example, no search can be performed in the following array: 
			
		```wl
		t is array of 2 objects dynamic
		```


	- On the contrary, a search can be performed in the following array:
			
		```wl
		t is array of 2 MyClass
		```

			
		```wl
		t is array of 2 MyClass dynamic
		```





- No search can be performed on an array of variants.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If you use a binary search algorithm and the array is not sorted, no WLanguage error will be displayed, but the search result will be undefined.
