
## Code Editor control functions (prefix syntax)

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following functions are used to manipulate Code Editor controls using prefix syntax: 



|   |   |
| --- | --- |
| [&lt;Code Editor&gt;.Comment](../WDLang1/1410090412.md) | Comments the current selection in the Code Editor control. "//" characters are inserted at the beginning of the current line. |
| [&lt;Code Editor&gt;.Compile](../WDLang1/1410090413.md) | Compiles the WLanguage code displayed in the Code Editor control and displays any errors. |
| [&lt;Code Editor&gt;.DeleteAll](../WDLang1/1410090422.md) | Deletes the contents of the Code Editor control. |
| [&lt;Code Editor&gt;.DuplicateLine](../WDLang1/1410090415.md) | Duplicates the current line in the Code Editor control. |
| [&lt;Code Editor&gt;.Execute](../WDLang1/1410090416.md) | Executes the WLanguage code displayed in the Code Editor control. |
| [&lt;Code Editor&gt;.GetError](../WDLang1/1410090419.md) | Gets a compilation error from the code in the Code Editor control. |
| [&lt;Code Editor&gt;.Insert](../WDLang1/1410090417.md) | Inserts a string in the Code Editor control. |
| [&lt;Code Editor&gt;.Load](../WDLang1/1410090411.md) | Loads a WLanguage code file in a Code Editor control. |
| [&lt;Code Editor&gt;.Replace](../WDLang1/1410090420.md) | Finds and replaces a string in the Code Editor control. |
| [&lt;Code Editor&gt;.Save](../WDLang1/1410090421.md) | Saves the contents of a Code Editor control to a file. |
| [&lt;Code Editor&gt;.Search](../WDLang1/1410090418.md) | Searches for a string or regular expression in the Code Editor control. |
| [&lt;Code Editor&gt;.Uncomment](../WDLang1/1410090414.md) | Uncomments the current selection in the Code Editor control. "//" characters at the beginning of the current line are removed. |
