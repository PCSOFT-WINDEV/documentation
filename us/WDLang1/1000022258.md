


## Encode (Function)

***In french: Encode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Encodes a character string or a buffer. To decode the result, simply use [Decode](../WDLang1/1000022259.md).

**Caution**: As the result of encoding is a character string, it may vary from one project configuration to another, depending on the setting of [string management at runtime](../WDLang1/3024038.md).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Encode an image in Base64
Res is string = Encode(fLoadBuffer("MyImage.jpg"), encodeBASE64)
```
<a name="Exemple2"></a>

```wl
// Encode a URL
Info(Encode("https://www.google.fr/?", encodeURLFromAnsi) + ...
	Encode(Encode("https://www.google.fr/?é", encodeURLFromAnsi), encodeURLParameter))
```
<a name="Exemple3"></a>

```wl
// The buffer contains characters in Unicode format in iOS
// or ANSI format in other configurations (set in ANSI)
MessageEnBuffer is a Buffer = fLoadBuffer(fDataDir()/"monbuffer.bin")
MessageEnBuffer = Encode(MessageEnBuffer, encodeBASE64SansRC)
// Conversion to ANSI and BASE 64 buffering on all platforms:
MessageEnBuffer = StringToUTF8(Encode(MessageEnBuffer, encodeBASE64SansRC))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = Encode(<Data> [, <Encoding format>])`
---

**`<Result>: (Character string)`**

Data encoded according to the selected format.

**`<Data>: (Character string or Buffer)`**

Data to encode.

**`<Encoding format>: (Optional Integer constant)`**

Format for encoding data:


|   |   |
| --- | --- |
| *encodeBASE64*<br>(Default value) | BASE 64 format (complies with the RFC 4648 standard). Encoded text contains only printable characters and CRs (Carriage Returns).<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Carriage returns (CR) are removed. |
| *encodeBASE64NoCR* | BASE 64 format (complies with RFC 4648 standard) without RCs (Carriage Returns). The encoded text contains printable characters only.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeBASE64URL* | BASE 64 URL format (complies with the RFC 4648 standard). The encoded text contains printable characters only.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeBASE85* | BASE 85 format. The encoded text contains printable characters only.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Unsupported format.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodePCS* | ASCII format. The encoded text contains printable characters only.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Unsupported format. |
| *encodeURLFromAnsi* | URL format. The encoded text only contains characters allowed in a URL. The text to encode is an ANSI string.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeURLFromUnicode* | URL format. The encoded text only contains characters allowed in a URL. The text to encode is a Unicode string.<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeURLFromUTF8* | URL format. The encoded text only contains characters allowed in a URL. The text to encode is a UTF-8 string.<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeURLParameter* | This constant is used when it is necessary to pass a given URL (URL A) as a parameter to another URL (URL B). The reserved characters of URL A (//,?...) are encoded.<br><br>URL A (to be encoded) must be a valid URL. If it has parameters of its own, they must have been encoded with one of the following constants: *encodeURLDfromAnsi*, *encodeURLDfromUnicode* or *encodeURLDfromUTF8*.<br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encodeUUEncode* | UUEncode format. The encoded text contains printable characters only.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Unsupported format. |
