
## aiConversationElement (Variable type)

***In french: iaElementConversation***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **aiConversationElement** type represents an element from a conversation in an AI Chat control. You can define and change the characteristics of this element using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Adds the content of the AGENTS.md file in the suffix of the conversation's first question
// "Before sending the request" AI Chat control event
PROCEDURE BeforeRequest(question is aiConversationElement)
conversation is aiConversation = Myself..AIConversation
IF conversation.Element.Count <= 1 THEN
	sSuffix is string = fLoadText(fExeDir()/"AGENTS.md")
	question.suffix = sSuffix
END
RETURN True
```

```wl
// Get all the assistant's responses from the conversation
sAIResponse is string
conversation is aiConversation = AICHAT_NoName1.AIConversation
IF NOT conversation..RequestInProgress THEN
	reply is aiConversationElement
	FOR EACH reply OF conversation..Element
		IF reply..Role = aiRoleAssistant THEN
			sAIResponse += [CR] + reply..Text
		END
	END
END
```

## Properties


### Properties specific to aiConversationElement variables
<a name="properties_specific_aiconversationelement_variables_ELTPARAGRAPHE000027"></a>

The following properties can be used to manipulate an element of a conversation:

| Property name | Type used | Effect |
| --- | --- | --- |
| Extra | Variant | Allows you to store advanced information without affecting the execution of the application. You can store values of any type (array, etc.). It is also possible to add members to the **Extra** property. <br>Example: <br><br><pre><code>MyVariable.Extra.Info1 = Value<br>MyVariable.Extra[Info2] = Value2<br>MyVariable.Extra.Date = DateSys()</code></pre><br> |
| Grayed | Boolean | <br><br>- <u><u><u>True</u></u></u> if the element is no longer valid. In this case, it will not be sent to the AI model. It will be grayed out in the AI Chat control. <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| ID | Integer | Element identifier. <br><br>**This property is read-only.** |
| Image | Array of Image | Images associated with the element. |
| Prefix | Character string | If the element is a user question, the property allows you to specify a prefix.<br>This makes it possible to add elements to a question. These elements will not be displayed in the AI Chat control by default. |
| Rating | Integer | Indicates whether or not the user liked the response:<br><br>- -1: dislike,<br><br>- 0: no rating,<br><br>- 1: like. <br><br><br> |
| Role | Integer constant | Type of element. Indicates the author or the type of an element in the AI Chat control:<br><br>- *aiRoleAssistant*: Conversation element created by the AI assistant. <br><br>- *aiRoleError*: Conversation element corresponding to an error. <br><br>- *aiRoleTool*: Conversation element created by an AI tool. <br><br>- *aiRoleUser*: Conversation element created by the user. <br><br><br><br><br>**This property is read-only.** |
| Suffix | Character string | If the element is a user question, the property allows you to specify a suffix.<br>This makes it possible to add elements to a question. These elements will not be displayed in the AI Chat control by default. |
| Text | Character string | Text of the question, response or error. |
| Tool | Array | Array of tools available only if Role is set to *aiRoleTool*.<br>The available properties are: <br><br>- Name: Tool name. <br><br>- Caption: Tool label. <br><br>- Running: <u><u><u>True</u></u></u> if the tool is still running, <u><u><u>False</u></u></u> otherwise. <br><br><br><br><br>**This property is read-only.** |
| UserQuestionID | Integer | If the element is a response, this property allows you to get the identifier of the corresponding question sent to the AI model. <br><br>**This property is read-only.** |
