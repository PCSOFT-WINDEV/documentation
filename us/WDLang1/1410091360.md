
## AIChatRetryRequest (Function)

***In french: ChatIARegénèreDemande***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Launches a new request based on the current conversation in the AI Chat control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
AIChatRetryRequest(AICHAT_MyChat)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`AIChatRetryRequest(<AI Chat control> [, <Element index>])`
---

**`<AI Chat control>: (Control name)`**

AI Chat control used. 

**`<Element index>: (Optional integer)`**

Number of the element in the conversation from which the conversation is to resume. 

If this parameter is not specified or is equal to -1, the conversation resumes from the last user request.
