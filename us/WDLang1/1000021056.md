


## WinChangeLayout (Function)

***In french: FenChangeAgencement***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Applies a specific layout to: 

- a window. 

- an internal window.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Force use of first layout if screen is 320 pixels wide
IF MySelf..Width = 320
	WinChangeLayout(WIN_Details, 1)
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Changing the layout on the current window

`WinChangeLayout(<Layout number>)`
---

**`<Layout number>: (Integer)`**

Number of the layout to apply. 


<a name="SYNTAXE2"></a>

### Changing the layout on a specific window

`WinChangeLayout(<Window> , <Layout number>)`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. 

**`<Layout number>: (Integer)`**

Number of the layout to apply. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The layout number is specified in the layout title bar. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Agencement_Numero.gif&type=thumb)


- The sizes, positions and visibility of the controls are modified according to the layout defined during editing. 

- The initial layout is automatically chosen according to the platform, orientation and screen size. 

- The layout used is automatically modified when the device switches from portrait mode to landscape mode. 

- This function does not trigger the "Change layout" event of the window. To force the execution of this event, use [ExecuteProcess](../WDLang1/3013031.md) with the *trtChangeLayout* constant.
