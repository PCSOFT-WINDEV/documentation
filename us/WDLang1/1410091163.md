
## CertificateExtractEnvelopedMessage (Function)

***In french: CertificatExtraitMessageEnveloppé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the validity of a PKCS7 wrapped signature and extracts the wrapped message. 

[CertificateExtract](../WDLang1/1000019300.md) is used to identify the certificate used for signing.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let bufP7 = CertificateSignString(StringToUTF8("String to sign"), ...
			sKeyFile, sKeyPassword, certPKCS7Enveloped)
let (nStatus,bufMessage) = CertificateExtractEnvelopedMessage(bufP7)
IF nStatus = certificateOk THEN
	CertificateUsed is Certificate
	CertificateUsed = CertificateExtract(bufP7, certificateFromBuffer)
	Info("The message has been signed." + CR + ...
	     "Author: " + CertificateUsed.Name + CR + ...
		 "Message: " + UTF8ToString(bufMessage))
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`(<Signature verification>, <Signed message>) = CertificateExtractEnvelopedMessage(<Signature buffer> [, <Certificate file> [, <Password> [, <Trusted authorities>]]])`
---

**`<Signature verification>: (Integer constant)`**

Signature verification result:


|   |   |
| --- | --- |
| *certificateExpired* | Valid signature but expired certificate. |
| *certificateInvalid* | Invalid signature or certificate. |
| *certificateOk* | Trusted signature and certificate. |
| *certificateUntrusted* | Valid signature but untrusted certificate root. |


Caution: If the signature is invalid, you should not trust the content of the message.

**`<Signed message>: (Buffer)`**

Message signed with the certificate.
Caution: If the signature is invalid, you should not trust the content of the message.

**`<Signature buffer>: (Buffer)`**

Buffer containing an enveloped signature in PKCS7 format. This buffer is returned by [CertificateSignString](../WDLang1/1000019296.md).

**`<Certificate file>: (Optional string or Buffer)`**

Corresponds to:

- the full path of the certificate file to be used (in PEM, DER or P12 format). 

- the buffer containing the certificate to be used.


For a PKCS7 signature, this parameter allows you to add certificates used to search for the trusted string.

**`<Password>: (Character string or Secret string)`**

Password that will be used to decrypt the certificate file if this one is password-protected.
Note: This parameter is particularly useful if the certificate used is identical to the one used for signing.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Trusted authorities>: (String or Array of strings)`**

Full path of trusted certificate to use. 
This parameter can also correspond to an array of strings containing the full path of different trusted certificates to use.

Note: Trusted certificates added with [TrustedCertificateAdd](../WDLang1/1000024320.md) are also taken into account.
