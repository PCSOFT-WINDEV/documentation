


## OrganizerDeleteAll (Function)

***In french: AgendaSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all the appointments from an Organizer control.

**Remarks**: 

- For an Organizer control populated programmatically, all appointments are deleted. 

- For an Organizer control bound to a data file or to a variable, appointments are only deleted from the control. The appointments are kept in the data source linked to the control. 









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete appointments from the ORG_MyOrganizer control
OrganizerDeleteAll(ORG_MyOrganizer)
```
