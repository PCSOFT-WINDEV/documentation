


## &lt;Code Editor&gt;.Load (Function)

***In french: &lt;Editeur de code&gt;.Charge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a WLanguage code file in a Code Editor control. This file contains the WLanguage code to be displayed in the control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sFile is string
// Opens the file picker
sFile = fSelect("", "", "Select a file...", "WLangage code (*.WL)" + TAB + "*.WL", "*.WL")

IF sFile <> "" THEN
	// Loads the file into the Code Editor control
	CODEEDT_Example.Load(sFile)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Code Editor control>.Load(<File to load>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was loaded into the Code Editor control,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.

**`<File to load>: (Character string)`**

Name and full path of the file to be loaded. This file corresponds to a file previously saved with [&lt;Code Editor&gt;.Save](../WDLang1/1410090421.md).
