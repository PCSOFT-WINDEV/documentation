


## pvtPosition (Variable type)

***In french: tcdPosition***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **pvtPosition** type can be used to manipulate a cell of a Pivot Table control. This type of variable is mainly used to get the value of a cell or modify its characteristics (the background color, for example). 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
// Declaration
x is pvtPosition of PVT_Sales
// Specify the values of the cell headers 
x.Year = "2020"
x.Quarter = "2020Q1"
x.Month = "202001"
x.Product.Cumulated = True 
// Display the total of sales for all the products in January 2020
STC_Result = PVT_Sales.Value1[x]
```

## Remarks
<a name="NOTE0_2"></a>


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000075"></a>

To manipulate a **pvtPosition** variable, simply:

- specify the values of the headers of the desired cell. For example: 
	
	```wl
	MyPosition is pvtPosition of PVT_Statistics
	// Indicates the headers
	MyPosition.COL_Continent = "Europe"
	MyPosition.COL_OrderDate_Year = "2022"
	```


- access a value of the pivot table via the following syntax: 
	
	```txt
	<Pivot table name>.<Value name>[<pvtPosition variable>]
	```

	For example: 
	
	```wl
	// Retrieves the "VAL_Qty" value
	nQuantity = PVT_Statistics.VAL_Qty[MyPosition]
	```





Remarks: 

- If the position does not correspond to a displayed cell (because it's collapsed, for example), you cannot retrieve the value of the cell or change its color. 

- If the position does not correspond to a value that exists in the result (a product that was not sold this particular day for example), the returned value is 0. 

- If the position has a header name that does not exist in the pivot table, a WLanguage error is displayed.

- A WLanguage error occurs if the position is outside the pivot table. 

- To get a cumulated total on a header, specify no header or set [Cumulated](../Proprietes/1000020702.md) to True.

- The **Out** property can be used to determine if the position returned by [PVTInfoXY](../WDLang1/1000020735.md) exists. 



<a name="NOTE0_3"></a>


### Pivot tables with filter
<a name="pivot_tables_with_filter_ELTPARAGRAPHE000108"></a>

**pvtPosition** variables manipulate all the data of the Pivot Table control. This means that non-displayed data is also taken into account. When using filters ([PVTFilter](../WDLang1/1000020531.md)), this filter must be declared in the **pvtPosition** variable. 

Example: 


```wl
MyPosition is pvtPosition of PVT_Statistics
// Indicates the filter
MyPosition.COL_FILTER_Product = COMBO_Product
// Indicates the headers
MyPosition.COL_Continent = "Europe"
MyPosition.COL_OrderDate_Year = "2022"
// Retrieves the "VAL_Qty" value
nQuantity = PVT_Statistics.VAL_Qty[MyPosition]
```

<a name="NOTE0_4"></a>


### Modifying the characteristics of a cell
<a name="modifying_the_characteristics_cell_ELTPARAGRAPHE000122"></a>

To highlight a cell (maximum, minimum value, etc.), you can use a variable of type **pvtPosition**.  

Example: 


```wl
MyPosition is pvtPosition of PVT_Statistics

// Indicates the headers
MyPosition.COL_Continent = "Europe"
MyPosition.COL_OrderDate_Year = "2022"

// Modifies the background color of the "VAL_Qty" value
VAL_Qty[MyPosition].BackgroundColor = LightRed
```
