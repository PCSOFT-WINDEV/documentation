
## Lower (Function)

***In french: Lower***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts all characters in a string to lowercase according to the region settings defined in Windows.

**Note** The function **Lower** function is retained for compatibility and works only with Latin character sets. To configure the formatting of a string more precisely or to handle other character sets, use [StringFormat](../WDLang1/3024019.md).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Lower("ABCD") 		// Returns "abcd"
Lower("HELLO")            // Returns "hello"
Lower("Peter and Paul")		// Returns "peter and paul"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = Lower(<String to convert>)`
---

**`<Result>: (Character string)`**

String in lowercase characters.

**`<String to convert>: (Character string)`**

String to convert to lowercase.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Conversion rules
<a name="conversion_rules_ELTPARAGRAPHE000074"></a>

- Unaccented lowercase characters remain unchanged.

- Accented lowercase characters remain unchanged.

- Unaccented uppercase characters are converted to unaccented lowercase characters.

- Accented uppercase characters remain unchanged.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Accented uppercase characters are converted to accented lowercase characters.




**Note** The function **Lower** function is retained for compatibility and works only with Latin character sets. To configure the formatting of a string more precisely or to handle other character sets, use [StringFormat](../WDLang1/3024019.md).
<a name="NOTE0_2"></a>




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000091"></a>

- "Whitespaces" are kept.

- The HFSQL engine automatically performs case-insensitive searches. Therefore, **Lower** has no effect when performing this type of operation.
