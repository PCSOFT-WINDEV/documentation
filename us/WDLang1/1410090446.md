


## DocFormatPainterMode (Function)

***In french: DocModeCopieMiseEnForme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables the format painter mode in the Word Processing control or determines if this mode is enabled. When this mode is enabled: 

- the format painter icon is pressed. 

- the formatting of the selection is saved,

- the cursor changes to indicate the mode is enabled. 


The formatting is applied as the user drags the cursor over a new selection.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enables format painter mode to copy the formatting of the selected text
DocFormatPainterMode(WP_Letter)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Enabling or disabling the format painter mode

`DocFormatPainterMode(<Word Processing control> , <Copy mode>)`
---

**`<Word Processing control>: (Control name)`**

Name of the Word Processing control to use.

**`<Copy mode>: (Integer constant)`**

Copy mode to be used: 


|   |   |
| --- | --- |
| *docFormatPainterModeDisabled* | Disables the format painter mode (if enabled). The cursor changes back to standard. In the ribbon, the format painter icon is no longer pressed. |
| *docFormatPainterModeMultiple* | Permanently enables the format painter mode. This means you can apply the same formatting several times. <br>The cursor changes to a paintbrush and only changes back when: <br><br>- the user clicks the format painter icon. <br><br>- the *docFormatPainterModeDisabled* is used. <br><br><br> |
| *docFormatPainterModeOnce* | Enables the format painter mode to copy formatting only once. This mode is automatically disabled once the formatting is applied |




<a name="SYNTAXE2"></a>

### Determining which format painter mode is currently enabled

`<Result> = DocFormatPainterMode(<Word Processing control>)`
---

**`<Result>: (Integer constant)`**

Current mode: 



|   |   |
| --- | --- |
| *docFormatPainterModeOnce* | The format painter mode is enabled to copy formatting only once. |
| *docFormatPainterModeMultiple* | The format painter mode is enabled to copy formatting multiple times. |
| *docFormatPainterModeDisabled* | The format painter mode is not enabled. |



**`<Word Processing control>: (Control name)`**

Name of the Word Processing control to use.
