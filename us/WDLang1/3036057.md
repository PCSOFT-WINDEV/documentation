
## fStopCompress (Function)

***In french: fStopCompacte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops the operation used to compress or decompress a file. The compressed or decompressed file is not created.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003036057&name=fstopcompress_function">See additional examples</a>

```wl
// Stop compressing a file
fStopCompress()
```

<a name="SYNTAXE1"></a>

## Syntax

`fStopCompress()`
