


## MDIOpen (Function)

***In french: MDIOuvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens and enables an MDI child window.

The following events are executed when **MDIOpen** is called:

- "Global declarations" event of the window.

- Initialization events of the controls (in any order).


The window is then displayed (this window is always a child window of the MDI parent window). This window cannot be moved outside the MDI area of the MDI parent window.

**Remarks**:

- **MDIOpen** only opens the windows defined as "MDI child windows" in the window editor. An MDI child window can only be opened if the MDI parent window exists and is open.

- **MDIOpen** can also be used to define the window alias, define the title of the window to be opened, and pass parameters to the window.

	- In standard syntax, these parameters are passed directly. 

	- When you use a variable of type  to open a window, you can use the  property to define the characteristics of the window, and the  property to pass parameters. 
			






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open the "WIN_CustomerInput" window
// The title of the window is "New customer"
// Value1 and Value2 are passed to the "Global declarations" event of the "WIN_CustomerInput" window 
ResAlias = MDIOpen(WIN_CustomerInput, "New customer alias", "New customer", Value1, Value2)
```

```wl
My_MDI_Window is Window WIN_CustomerInput
// The title of the window is "New customer"
My_MDI_Window.OpeningOptions.Title = "New customer"
// The window alias is "Alias New customer"
My_MDI_Window.OpeningOptions.Alias = "Alias New customer"
// Value1 and Value2 are passed to the "Global declarations" event of the "WIN_CustomerInput" window
My_MDI_Window.OpeningParameters.Param1 = Value1
My_MDI_Window.OpeningParameters.Param2 = Value2
// Open the "WIN_CustomerInput" window
ResAlias = MDIOpen(My_MDI_Window)
```

## Syntax

### Opening an MDI window (standard syntax)

`<Result> = MDIOpen(<Window> [, <Alias name> [, <Window title> [, <Parameter 1> [... [, <Parameter N>]]]]])`
---

**`<Result>: (Character string)`**

Alias generated for the window to be opened. The same window can be opened multiple times. This alias identifies the open window. You can change this alias using [WinChangeAlias](../WDLang1/3038028.md).

**`<Window>: (Window name)`**



- Name of the window to be opened.

- Name and full path of the window (".WDW" file) to be opened.




**`<Alias name>: (Character string)`**

Alias of the window. If this parameter is not specified or is an empty string (""), an alias is automatically generated (e.g. "A0001").

**`<Window title>: (Character string)`**

Title of the window to be opened. If this parameter is not specified or is an empty string (""), the window title is the one defined in the editor.

**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and it is considered as being a global variable of the window.
This parameter cannot contain array variables (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and it is considered as being a global variable of the window.
This parameter cannot contain array variables (arrays can only be passed by reference).


<a name="SYNTAXE2"></a>

### Opening an MDI window (with a Window variable)

`<Result> = MDIOpen(<Window> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Result>: (Character string)`**

Alias generated for the window to be opened. The same window can be opened multiple times. This alias identifies the open window. You can change this alias using [WinChangeAlias](../WDLang1/3038028.md).

**`<Window>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened. 

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property. 




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by reference and is considered as a variable global to the window.

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

## Remarks


### Parameters passed to the window to open
<a name="parameters_passed_the_window_open_ELTPARAGRAPHE000359"></a>The parameters are retrieved in the "Global declarations" event associated with  the window. The first line of code of this event must correspond to the following line:


```txt
PROCEDURE <Window> (<Parameter 1> [, ... [, <Parameter N>]])
```
where: 

- &lt;Window&gt; must correspond to the name of the window. 

- &lt;Parameter N&gt; must correspond to the parameters expected. **Note: These parameters are passed by value, not by reference.**


For more details, see [Window with parameters](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Window opening mode
<a name="window_opening_mode_ELTPARAGRAPHE000164"></a>

The window opens as a non-modal window:

- The MDI parent window remains the current window.

- Once the MDI child window is opened, the processes following the call to **MDIOpen** are executed.

- The user will be able to click in the parent window of the open window.



<a name="NOTE0_3"></a>


### Number of opened windows
<a name="number_opened_windows_ELTPARAGRAPHE000179"></a>

The number of windows that can be opened simultaneously depends on the available memory.
<a name="NOTE0_4"></a>


### Closing a window
<a name="closing_window_ELTPARAGRAPHE000188"></a>

A window opened with **MDIOpen** can be closed with [Close](../WDLang1/3038018.md) (without parameters) from any event associated with the window or a control in the window.

If an MDI parent window is closed, its MDI child windows are also closed.
<a name="NOTE0_5"></a>


### Minimized window
<a name="minimized_window_ELTPARAGRAPHE000204"></a>

Minimizing an MDI child window does not affect other windows.

The displayed icon is:

- the one of the minimized window if the current window has an icon,

- the one of the current project if the current window has no icon.
