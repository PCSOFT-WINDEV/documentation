


## &lt;Table&gt;.ToWord (Function)

***In french: &lt;Table&gt;.VersWord***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a Word file (.RTF) from the data found in a Table or TreeView Table control.

**Remark**: This file can be opened in Word or OpenOffice Writer (depending on the software installed on the current workstation).

<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
sFile is string
// Asks for the file name
sFile = fSelect("", "", "Choose the export file", ...
	"Word files (*.rtf) *.rtf", "rtf", fSelCreate + fSelExist)
// If the name was not specified, cancels the export
// Otherwise, exports the content of TABLE_TABLE1
IF sFile <> "" THEN TableToWord(TABLE_TABLE1, sFile, taNoTitle)
```

## Syntax

`<Result> = <Table control>.ToWord(<Doc file name> [, <Options> [, <Start row> [, <End row>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was created,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Table control>: (Control name)`**

Name of the control to be used. This field may correspond to: 

- a Table control. 

- a TreeView Table control.




**`<Doc file name>: (Character string)`**

Name and full path of the Word file to create. The file is replaced with the new file if it already exists.

**`<Options>: (Optional Integer constant)`**

Configures the Word file to create.


|   |   |
| --- | --- |
| *taColumnDisplayedOrder* | Exports the columns according to the order of columns currently displayed in the control (and not according to the order of columns defined in the editor).<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *taColumnsTitles*<br>(Default value) | The title of the columns is inserted in the file. |
| *taNoTitle* | Only the data is copied to the file. |
| *taNoTotal* | Does not export: <br><br>- the rows containing totals, mean and automatic count (these rows are exported by default).<br><br>- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) the rows containing custom calculations (these rows are exported by default).<br><br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *taSelectedLines* | Exports the selected rows only (all the rows are exported by default).<br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This constant is not available. |
| *taWithInvisibleColumns* | Also exports the invisible control columns.<br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The columns defined as non printable and non exportable are exported. These columns are defined: <br><br>- or by programming: property [VisibleInExportAndPrint](../Proprietes/1000022320.md) to <u><u><u><u>False</u></u></u></u>. <br><br>- either in the "General" tab of the column description window: option "Export and print" to "Never".<br><br><br> |



**`<Start row>: (Optional integer)`**

Number of the row where the export will start. If this parameter is not specified, the start row is the first row of the control.

**`<End row>: (Optional integer)`**

Number of the row where the export will end. If this parameter is not specified, the end row is the last row of the control.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000304"></a>

**&lt;Table&gt;.ToWord** can be used on: 

- Table or TreeView Table controls based on a data file.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.



<a name="NOTE0_2"></a>


- The created file can be opened by Word 95 (or later) or by OpenOffice Writer 2 (or later).

- The merged columns are ignored.
