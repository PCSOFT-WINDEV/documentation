
## WinForceDDW (Function)

***In french: FenForceGFI***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Forces the DDW (Dim Disabled Windows) feature on a window even if this window is not accessible.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Hourglass(True)
// Force DDW on the main window
WinForceDDW(WIN_Main, True)
// Start an important calculation
ImportantCalculation()
// Stop DDW on the main window
WinForceDDW(WIN_Main, False)
HourGlass(False)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`WinForceDDW(<Window> , <DDW activation>)`
---

**`<Window>: (Window name)`**

Name of the window to be used. 

**`<DDW activation>: (Boolean)`**

New DDW status:

- <u><u><u><u>True</u></u></u></u>: GFI is activated immediately on the specified window. The window comes up grayed out. 

- <u><u><u><u>False</u></u></u></u> GFI is immediately deactivated on the specified window. The window reappears as normal (unless it is inactive, in which case it remains grayed)..
