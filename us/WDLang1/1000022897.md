


## &lt;Organizer&gt;.Position (Function)

***In french: &lt;Agenda&gt;.Position***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays an Organizer control from a specified date or returns the date of the first day (or the date of the last day) displayed in an Organizer control.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Positions the organizer on today's date
ORG_Organizer1.Position(Today())
// Positions the organizer on December 20, 2022
AGD_Agenda1.Position("20221220")
```
<a name="Exemple2"></a>

```wl
// Find out the first date displayed in the organizer
OrganizerDate is Date
OrganizerDate = ORG_MyOrganizer.Position()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Positioning the organizer on a specified date

`<Organizer control>.Position(<Start date>)`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Start date>: (Character string or Date variable)`**

Start date for the display.


<a name="SYNTAXE2"></a>

### Finding out the first date or the last date displayed by the Organizer control

`<Result> = <Organizer control>.Position(<Sought date>)`
---

**`<Result>: (Character string or Date variable)`**

Date displayed by the Organizer control.

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Sought date>: (Optional Integer constant)`**

Type of sought date:


|   |   |
| --- | --- |
| *orgCurrentMonth* | First day of the month displayed in the Organizer control. |
| *orgDateTimeFirstVisible* | First date and time displayed in the Organizer control (depending on the position of the scrollbar).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available. |
| *orgEndDate* | Last date displayed in the Organizer control. |
| *orgStartDate*<br>(Default value) | First date displayed in the Organizer control. |


**Note** If the Organizer control is in "by day" display mode, the constants *agDateStart* and *agDateEnd* constants are equivalent.
