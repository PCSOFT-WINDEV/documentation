


## &lt;Pivot Table&gt;.ToExcel (Function)

***In french: &lt;Tableau croisé dynamique&gt;.VersExcel***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates an Excel file with data from a Pivot Table control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sFile is string

// Builds the file name
sFile = SysDir(srAppData) + ["\"] + "StatsByCountry.xls"

PVT_Statistics.ToExcel(sFile)
ShellExecute(Sysdir(srAppData) + ["\"] + "StatsByCountry.xls")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Pivot Table control>.ToExcel(<XLS file> [, <Options>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was created,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<XLS file>: (Character string)`**

Name and full path of the Excel file to be created. If the file already exists, it is replaced with the new file.

**`<Options>: (Optional constant)`**

Configuration of the XLS file to be created.


|   |   |
| --- | --- |
| *taColumnsTitles*<br>(default value) | The title of the columns is inserted in the file. |
| *taNoTitle* | Only the data is copied to the file. |
| *taWithLayout* | Exports the color and font of the Pivot Table control. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The Excel files cannot exceed 65536 rows and 256 columns if the extension used is ".xls". You can work around this limitation by using the ".xlsx" extension. Note: In this case, older versions of Excel will require the "Office 2007 Compatibility Pack" to open the generated documents. This pack can be downloaded free of charge from the Microsoft website.

- The file created can be opened with Excel 97 (or later) or with OpenOffice Calc 2 (or later).
