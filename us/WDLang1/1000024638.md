


## Toast (Variable type)

***In french: Toast***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Toast** type is used to define all the advanced characteristics of a toast notification. You can define and change the characteristics of this toast using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyToast is Toast
MyToast.Title = "Did you know?"
MyToast.Text = "AAFs are really cool."
MyToast.Button[1].Caption = "Learn more..."
MyToast.Button[1].ActionClick = FuncHelp
MyToast.ActionClose = clickClose
ToastDisplay(MyToast)
INTERNAL PROCEDURE FuncHelp
	Open ("WIN_Help")
END
INTERNAL PROCEDURE clickClose(nButton)
	Trace("Click to close. Button: " + nButton)
END
```

```wl
// Displays a toast without the product name
MyToast is Toast
MyToast.DisplayDuration = toastLong
MyToast.VerticalAlignment = vaBottom 
MyToast.HorizontalAlignment = haCenter
ToastDisplayIW(IW_TOAST_DELETE, MyToast, PRODUCT.NAME)
//------------------------------------
// Global declarations of the internal window
PROCEDURE IW_TOAST_DELETE(ProductName)
STC_TEXT = StringBuild("The product %1 has been deleted", ProductName)
```

## Properties


### Properties specific to Toast variables
<a name="properties_specific_toast_variables_ELTPARAGRAPHE000044"></a>

The following properties can be used to handle a toast notification:

| Property name | Type | Effect |
| --- | --- | --- |
| ActionClose | WLanguage procedure | Action to be performed when the toast is closed. <br>This property corresponds to the name of the procedure to be executed when the button in the toast is clicked. <br>This procedure takes the number of the clicked button as an optional parameter. If no button has been clicked to close the toast (toast closed via a timer, click on the toast, parent window closed, etc.), this parameter is set to 0. |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) ClosingAnimation | Integer or constant | Animation to be started when the toast is closed. This property can take the following values: <br><br>- -1: No animation. <br><br>- 0 (Default value): Default animation, defined in project options ("Control animations" button in the "Advanced" tab of the project description window). <br><br>- *animFadeIn*: Crossfade animation: Toast opacity goes from %1 to 100%.<br><br><br><br><br> |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) OpeningAnimation | Integer or constant | Animation to be started when the toast is opened. This property can take the following values: <br><br>- -1: No animation. <br><br>- 0 (Default value): Default animation, defined in project options ("Control animations" button in the "Advanced" tab of the project description window). <br><br>- *animFadeIn*: Crossfade animation: Toast opacity goes from 100% to 1%. <br><br><br><br><br> |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Round | Integer | Radius to be applied to the corners of the toast. If this value is 0, the toast is rectangular. <br><br>By default, this property is set to 24. <br><br> |
| Button[n] |   | Buttons displayed in the toast. <br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Only one button can be added to a toast. |
| Button[n].ActionClick |   | Action to perform when the button is clicked on. <br>This property corresponds to the name of the procedure to be executed when the button in the toast is clicked. |
| Button[n].Caption |   | Button caption. <br><br>Note: You can use [gPen](../WDLang1/3029039.md) to change the toast text color. For example: <br><br><pre><code>MyToast.Button[3].Caption = gPen(LightYellow) + <br>	"Don't ask again"</code></pre><br> |
| HorizontalAlignment | Integer constant | Horizontal alignment of the toast, relative to the window:<br><br>- *haCenter* (Default): The toast is aligned in the center of the window.<br><br>- *haRight*: The toast is aligned to the right of the window.<br><br>- *haLeft*: The toast is aligned to the right of the window.<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available. |
| VerticalAlignment | Integer constant | Vertical alignment of the toast, relative to the window:<br><br>- *vaBottom* (Default): The toast is aligned to the bottom of the window.<br><br>- *vaTop*: The toast is aligned to the top of the window.<br><br>- *vaMiddle*: The toast is aligned in the center of the window.<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available. |
| BackgroundColor | Integer | Toast background color. This parameter can be: <br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)),<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a WLanguage preset color](../WDLang5/3010002.md).<br><br><br> |
| DisplayDuration | Integer constant | Toast display time:<br><br>- *toastShort* (Default): The toast will be displayed for a short period of time.<br><br>- *toastLong*: The toast will be displayed for a long period of time.<br><br><br>**Note**: The exact display duration depends on the device. |
| CloseOnClick | Boolean | Toast closing mode: <br><br>- <u><u><u>True</u></u></u>: The toast closes automatically if the user clicks on it, <br><br>- <u><u><u>False</u></u></u>: The toast closes after the specified display time. <br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available. |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Image | Character string | Path to the image displayed at the top left corner of the toast. <br><br> |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) ExternalMargin | Integer | Margin between the edge of the toast and the edge of the parent window (in pixels). <br><br>By default, this property is set to 8. <br><br> |
| Opacity | Integer | Toast opacity level. The value of this property ranges from 0 to 100:<br><br>- 0, default: slightly transparent toast. <br><br>- 1, transparent toast,<br><br>- 100, full opacity. <br><br><br> |
| Overlayable | Boolean | <br><br>- <u><u><u>True</u></u></u> (default): If several toasts are displayed, they overlap each other. <br><br>- <u><u><u>False</u></u></u>: If several toasts are displayed, they overlap each other (compatible version 24). <br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Not available. |
| Text | Character string | Text displayed in the toast. |
| Title | Character string | Toast title.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Not available. |
