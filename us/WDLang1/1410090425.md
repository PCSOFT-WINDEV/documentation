


## TableAddBeginning (Function)

***In french: TableAjouteDébut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row at the top of an Infinite Table control. The row is inserted before the first row of the Table control. The scroll position of the Table control doesn't change. 

Note: It is recommended to use this function in the "Add additional elements at the top" event of the Table control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// insert a new email address at the top of the Table control
TableAddBeginning(TABLE_Email, Email.Date, Email.Text)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`TableAddBeginning(<Table control> [, <Element column 1> [... [, <Element column N>]]])`
---

**`<Table control>: (Control name)`**

Name of the Table control to be used. 
If this parameter corresponds to an empty string (""), the control used will be the control to which the current event belongs.

**`<Element column 1>: (Type of associated column (optional))`**

First element of the row to be inserted into the specified control. Each element corresponds to a column of the control. The type of the inserted element must be compatible with the column type.
If none of these parameters is specified, an empty row is added to the control. 



**`<Element column N>: (Type of associated column (optional))`**

Nth element of the row to be inserted in the specified control. Each element corresponds to a column of the control. The type of the inserted element must be compatible with the column type.
If none of these parameters is specified, an empty row is added to the control.
