


## WinOutHeight (Function)

***In french: FenExtHaut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the outer height of a window. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the Windows operating system, the outer height includes the border, menu bar, status bar and title bar.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Maximized mobile windows: The outer height includes the action bar and navigation bar. The system bar is ignored.

- Non-maximized mobile windows and popup windows: The outer height is the total height of the window. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt_Mobile.gif)



If the keyboard is displayed: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) If the window has automatic scrollbars, the window height is reduced. 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) The window height remains unchanged.




**Note**: The **WinOutHeight** function is equivalent to the [Height](../Proprietes/2510050.md) property (&lt;Window&gt;.Height).

<a name="sample_code"></a>

## Example


```wl
// Height of "WIN_EditCustomer" window 
ResHeight = WinOutHeight(WIN_EditCustomer)
```

## Syntax

`<Result> = WinOutHeight([<Window>])`
---

**`<Result>: (Integer)`**

Window height (in pixels).

**`<Window>: (Optional window name)`**

Name or alias of the window to be used. 
If this parameter is not specified or is an empty string (""), the height of the current window is returned.

## Remarks
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) 

### Difference between the result of WinOutHeight and the resolution
<a name="difference_between_the_result_docparampagetitleshort_and_the_resolution_ELTPARAGRAPHE000091"></a>

The result of **WinOutHeight** used on a maximized window may be 8 pixels more that the resolution because **WinOutHeight** takes into account the "Border" of the window outside the screen (4 pixels on each side).

Therefore, for a resolution of 1280x1024, **WinOutHeight** and [WinOutWidth](../WDLang1/3038029.md) return 1288x1032.
