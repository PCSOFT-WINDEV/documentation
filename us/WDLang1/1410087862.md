


## &lt;Window&gt;.OpenAsynchronous (Function)

***In french: &lt;Fenêtre&gt;.OuvreAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a window whose result will be retrieved via a WLanguage procedure ("callback").
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open asynchronously without passing parameters 
WIN_DateSelect.OpenAsynchronous((),CloseDateSelect)
INTERNAL PROCEDURE CloseDateSelect(SelectedDate)
	EDT_DATE = SelectedDate
END
```

```wl
// Open asynchronously without passing parameters and lambda
WIN_DateSelect.OpenAsynchronous((), (SelectedDate) => {EDT_DATE = SelectedDate})
```

```wl
// Open asynchronously with 2 parameters
WIN_DateSelect.OpenAsynchronous((DateSys(), "Select a date"), CloseDateSelect)
INTERNAL PROCEDURE CloseDateSelect(SelectedDate)
	EDT_DATE = SelectedDate
END
```


<a name="1410087804_Exemple3"></a>

```wl
// Set window opening options
My_Date_Window is Window WIN_DateSelect
My_Date_Window.OpeningOptions.X = 50
My_Date_Window.OpeningOptions.Y = 100
// Open window
My_Date_Window.OpenAsynchronous(CloseDateSelect)
INTERNAL PROCEDURE CloseDateSelect(SelectedDate)
	EDT_DATE = SelectedDate
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Standard syntax

`<Window>.OpenAsynchronous([<Parameter 1> [... [, <Parameter N>]]] [, <WLanguage procedure>])`
---

**`<Window>: (Window name)`**

Name of the window to be opened.

**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

**`<WLanguage procedure>: (Name of the procedure or lambda procedure)`**

Name of the WLanguage procedure ("callback") called after the window is closed. For more details on this procedure, see [Parameters of the procedure used by &lt;Window&gt;.OpenAsynchronous](../WDLang1/1410087805.md). 

This WLanguage procedure can correspond to: 

- a name of a global procedure,

- a name of an internal procedure,

- a lambda procedure.

### Syntax for manipulating a variable of type Window 

`<Window>.OpenAsynchronous([<Parameter 1> [... [, <Parameter N>]]] [, <WLanguage procedure>])`
---

**`<Window>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened. 

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property.




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

**`<WLanguage procedure>: (Name of the procedure or lambda procedure)`**

Name of the WLanguage procedure ("callback") called after the window is closed. For more details on this procedure, see [Parameters of the procedure used by &lt;Window&gt;.OpenAsynchronous](../WDLang1/1410087805.md). 

This WLanguage procedure can correspond to: 

- a name of a global procedure,

- a name of an internal procedure,

- a lambda procedure.








<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **&lt;Window&gt;.OpenAsynchronous** opens the window in modal and asynchronous mode: 

	- code execution continues without waiting for the window to be closed,

	- the WLanguage procedure will be called when the window is closed. 

	- the user cannot click the parent window of the calling window. 




- A window opened with **&lt;Window&gt;.OpenAsynchronous** will be automatically closed if the calling window is closed. However, the "Close a child window" event of the calling window will not be executed.
