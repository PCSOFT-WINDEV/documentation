


## WinEdDeselectAll (Function)

***In french: FenEdDésélectionneTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deselects all the controls when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Enables editing in the window 
WInEdActive(WIN_Form, True)
WinEdDeselectAll(WIN_Form)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`WinEdDeselectAll(<Window>)`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. This window must be in edit mode ([WinEdActive](../WDLang1/1000021843.md)).
