


## &lt;Edit&gt;.TokenCount (Function)

***In french: &lt;Saisie&gt;.OccurrenceJeton***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of tokens present in a "Text token" Edit control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Update the caption
STC_Info = "Number of recipients: " + EDT_Recipient.EditTokenCount()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Edit control>.TokenCount()`
---

**`<Result>: (Integer)`**

Number of tokens associated with the Edit control.

**`<Edit control>: (Control name)`**

Name of the "Text token" Edit control.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- If duplicates are allowed in the "Text token" Edit control, they will be included in the number of tokens returned. 

- An error is displayed if the Edit control is not a "Text token" Edit control ([TokenEnabled](../Proprietes/1000023782.md) property is <u><u><u><u>False</u></u></u></u>). 

- The edit control [StoredValue](../Proprietes/2510127.md) property returns the stored values for the tokens, separated by the characters &lt;CR&gt; (Carriage Return).
