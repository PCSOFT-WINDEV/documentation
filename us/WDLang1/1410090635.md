
## GetVariableDefinition (Function)

***In french: RécupèreDéfinitionVariable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the variable type definition. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
po is dynamic BaseClass
d is Definition
po = new BaseClass
d = GetDefinition(po)		// Returns the definition of BaseClass
d = GetVariableDefinition(po)	// Returns the definition of BaseClass
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GetVariableDefinition(<Element>)`
---

**`<Result>: (Definition)`**

[Definition](../WDLang1/1000019540.md) variable. 

**`<Element>: (Character string)`**

Element for which the definition will be retrieved. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Retrieving the variable type definition
<a name="retrieving_the_variable_type_definition_ELTPARAGRAPHE000035"></a>

**GetVariableDefinition** gets the variable type definition, and not the content type definition.

Example:
Two classes, "DerivedClass" and "BaseClass", derive from each other. If the instances of "DerivedClass" and "BaseClass" are manipulated by a variable of type "Dynamic BaseClass", [GetDefinition](../WDLang1/1000019333.md) returns the definition of the real class of the instance. **GetVariableDefinition** always returns the base class.

```wl
po is dynamic BaseClass
d is Definition
po = new BaseClass
d = GetDefinition(po)		// Returns the definition of BaseClass
d = GetVariableDefinition(po)	// Returns the definition of BaseClass

po = new DerivedClass
d = GetDefinition(po)		// Returns the definition of DerivedClass
d = GetVariableDefinition(po)	// Returns the definition of BaseClass
```



### Error handling
<a name="error_handling_ELTPARAGRAPHE000052"></a>

If the type of the element is not supported, **GetVariableDefinition** returns a Null definition with a non-fatal error ("Invalid definition"). 

If the element has not been created, **GetVariableDefinition** returns a Null definition with a non-fatal error ("The element has not been created").

Error cases can be processed:

- by comparing the description to Null.

- by checking the value of the [ErrorOccurred](../WDLang1/3087001.md) variable.





### Supported and unsupported elements
<a name="supported_and_unsupported_elements_ELTPARAGRAPHE000071"></a>

The following types of elements are supported: 

- native variables and members

- advanced variables and members

- class variables and members

- structure variables and members




The following types of elements are not supported:

- .NET variables and members

- windows, reports, pages, controls, etc.

- HFSQL data files, queries, items, etc.



<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000089"></a>

- In a project, you cannot retrieve the definition of an instance coming from: 

	- an external component.

	- an internal component.




- In an external component, you cannot retrieve the definition of an instance coming from the host project.
