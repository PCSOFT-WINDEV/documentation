
## fWatchStop (Function)

***In french: fSurveilleStop***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***fTrackStop*</**>** is kept for backward compatibility. This function has been replaced with ***fWatchStop*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops watching a file or directory. The watch task could have been started with [fWatchFile](../WDLang1/1000020522.md) or [fWatchDirectory](../WDLang1/1000020523.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Stop all current watch tasks of the "C:\Test\Important folders" directory
IF NOT fWatchStop("C:\Test\Important folders") THEN
	Error("No watch task was enabled")
ELSE
	Info("Watch task stopped")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fWatchStop(<Element name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the active watch task was stopped, 

- <u><u><u><u>False</u></u></u></u> otherwise (no watch task was found).




**`<Element name>: (Character string)`**

Full name of the file or directory to use.
