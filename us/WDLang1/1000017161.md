
## dbgEndRecording (Function)

***In french: dbgFinEnregistrement***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops recording the scenario. The recording was started by [dbgStartRecording](../WDLang1/1000017160.md).

**Note**: This function is for use with [creating an automated test by the end user](../Editeurs/2019031.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
dbgEndRecording()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`dbgEndRecording()`
---



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
**dbgEndRecording** has no effect if no scenario is being recorded.

**Note** Scenario recording can also be started using the ".wx" file next to the executable. For more details, see [Scenario created by the user](../Editeurs/2019031.md).
