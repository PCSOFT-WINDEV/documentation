
## MultitaskRedraw (Function)

***In french: MultitâcheRepeint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Immediately redraws the window controls that will be graphically refreshed.

**Note**: This function is identical to [WinRedraw](../WDLang1/3038006.md).



![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available only to simplify the Webification of WINDEV/WINDEV Mobile projects. In a WEBDEV website, this function has no effect.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
i is int
FOR i = 1 TO 1000
	LongProcess()
	MultitaskRedraw()
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`MultitaskRedraw([<Window or page>])`
---

**`<Window or page>: (Name of window or page)`**

Name of window to redraw. The current window is redrawn if this parameter is not specified. 

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter corresponds to a page name. This function has no effect.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Unlike [Multitask](../WDLang1/3015004.md), the call to **MultitaskRedraw** does not interrupt the current code (the [Timer](../WDLang1/3015008.md) functions are not called for example).
