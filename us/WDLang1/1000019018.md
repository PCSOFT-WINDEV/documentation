The following constants are used to manipulate Organizer controls: 

| Constant | Description | Used by the functions or types of variables |
| --- | --- | --- |
| **orgAptHovered** | Appointment type searched for: Appointment hovered over in Organizer control. | [OrganizerListAppointment](../WDLang1/1000018880.md) |
| **orgAptSelected** | Appointment type searched: Appointment currently selected in the Organizer control field. | [OrganizerListAppointment](../WDLang1/1000018880.md) |
| **orgCurrentMonth** | Type of date searched: First day of the month displayed in the Organizer control. | [OrganizerPosition](../WDLang1/1000018889.md) |
| **orgDateTimeFirstVisible** | Date type searched: First date and time displayed in the Organizer control or Scheduler control. | <br><br>- [OrganizerPosition](../WDLang1/1000018889.md)<br><br>- [SchedulerPositionDateTime](../WDLang1/1000019998.md)<br><br><br> |
| **orgEndDate** | <br><br>- Date type searched: Last date displayed in Organizer control.<br><br>- Last date of the range selected in the Organizer control.<br><br><br> | <br><br>- [OrganizerPosition](../WDLang1/1000018889.md)<br><br>- [OrganizerSelectedRange](../WDLang1/1000022399.md)<br><br><br> |
| **orgStartDate** | Type of sought date: <br><br>- First date displayed in the Organizer control.<br><br>- First date of the range selected in the Organizer control.<br><br><br> | <br><br>- [OrganizerPosition](../WDLang1/1000018889.md)<br><br>- [OrganizerSelectedRange](../WDLang1/1000022399.md)<br><br><br> |
| **orgzCustomNbDay** | Calendar display mode: Agenda displayed over a customized number of days. | [OrganizerChangeMode](../WDLang1/1000019497.md), [OrganizerMode](../WDLang1/1000019545.md) |
| **orgzDay** | Agenda display mode: Agenda displayed for one day. | [OrganizerChangeMode](../WDLang1/1000019497.md), [OrganizerMode](../WDLang1/1000019545.md) |
| **orgzMonth** | Agenda display mode: Agenda displayed for one month. | [OrganizerChangeMode](../WDLang1/1000019497.md), [OrganizerMode](../WDLang1/1000019545.md) |
| **orgzWeek** | Calendar display mode: The calendar displays a full (or partial) week. | [OrganizerChangeMode](../WDLang1/1000019497.md), [OrganizerMode](../WDLang1/1000019545.md) |
| **orgzWeekOn5** | Calendar display mode: The calendar displays the first five days of the week. | [OrganizerChangeMode](../WDLang1/1000019497.md), [OrganizerMode](../WDLang1/1000019545.md) |
| **oriAppointment** | Type of information requested: Appointment index corresponding to the contact details provided. | [OrganizerInfoXY](../WDLang1/1000018887.md) |
| **oriDateTime** | Type of information requested: Date and time of appointment corresponding to the contact details provided. | [OrganizerInfoXY](../WDLang1/1000018887.md) |
| **oriScreenOrigin** | The coordinates are relative to the screen. | [OrganizerInfoXY](../WDLang1/1000018887.md) |
