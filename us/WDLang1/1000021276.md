


## CoordinateScreenToEditor (Function)

***In french: CoordonnéeEcranVersEditeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts a size or a position specified in the native dpi of the screen on the device where the application is run to the reference dpi in the editor (160 dpi). 

This function is mainly used to perform a positioning at pixel level.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) This function is available only to simplify the Webification of WINDEV projects.  
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieves the size and position of a control as they have been defined in the editor
nX is int = CoordinateScreenToEditor(MyInputControl.X)
nY is int = CoordinateScreenToEditor(MyInputControl.Y)
nWidth is int = CoordinateScreenToEditor(MyInputControl.Width)
nHeight is int = CoordinateScreenToEditor(MyInputControl.Height)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CoordinateScreenToEditor(<Value>)`
---

**`<Result>: (Integer)`**

Conversion result: converted size or position in the reference dpi under the editor (160 dpi). 
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter always corresponds to &lt;Value&gt;.

**`<Value>: (Integer)`**

Value to convert: given size or position in the device's native screen dpi.

<a name="NOTE0_1"></a>

## Remarks


- ![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Under the editor, the sizes and positions of Android or iPhone window fields always correspond to a 160 dpi (dot per inch) screen.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) When running the application, these sizes and positions are automatically converted according to the native dpi of the screen on the host device. This allows you to get a WYSIWYG rendering regardless of the device dpi. For example, if a control is 100x100 in the editor, at runtime it will be 150x150 on a 240 dpi screen, 200x200 on a 320 dpi screen, etc.

- [CoordinateEditorToScreen](../WDLang1/1000021277.md) allows making the inverted conversion, i.e., from the reference dpi in the editor (160 dpi) to the native dpi of the device on which the application is run.
