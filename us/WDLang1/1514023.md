


## List (Variable type)

***In french: Liste (Type de variable)***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
A **List** variable is a structured type that is used to group a set of elements of the same type. The elements can be added at the end of the list or they can be inserted into the list.




<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Declaring and initializing a list

`<List name> is List of <Type of list elements>`
---

**`<List name>: ()`**

Name of the List variable to declare.

**`<Type of List Elements>: ()`**

Type of elements in the list. 
All types of variables can be used, including arrays, associative arrays, queues, stacks and lists. For example: 


```txt
<variable> is List of arrays of int

<variable> is List of fixed arrays of 5 int

<variable> is List of associative arrays of int

<variable> is List of Queues of int

<variable> is List of Stacks of int

<variable> is List of Lists of int
```

### The lists and multithreading
<a name="the_lists_and_multithreading_ELTPARAGRAPHE000105"></a>

Multithreading is supported when adding, inserting and deleting an element.

Multithreading also allows you to use properties, but the result is not persistent. For example:


```wl
IF MyList.Occurrence > 0 THEN
	// The list may be empty when the thread reaches this point
END
```

<a name="NOTE0_4"></a>


### Looping through lists
<a name="looping_through_lists_ELTPARAGRAPHE000116"></a>

The FOR EACH statement can be used to loop through lists.

The syntax is the same as the one used for arrays:


```txt
FOR EACH [ELEMENT] <Variable> [, <Counter> [, <Counter>]] OF <List> [<Direction>]
	...
END
```
Elements can be modified during the iteration. In this case, the iteration is affected by add and delete operations. The following functions can be used during the iteration:

- Syntax 1: 
	
	```txt
	Insert(<List Name>, BeforeCurrentElement, <Value>)
	```

	Note: In a descending loop, the element will be taken into account in the next iteration.

- Syntax 2: 
	
	```txt
	Insert(<List Name>, AfterCurrentElement, <Value>)
	```

	Note: In an ascending loop, the element will be taken into account in the next iteration.

- Syntax 3: 
	
	```txt
	Delete(List Name, CurrentElement)
	```




<a name="NOTE0_5"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000142"></a>

- The content of the list can be displayed in the debugger. 

- A list can be used to type a procedure parameter.

- A list can be copied by the = operator. You also have the ability to copy an instance of class or structure containing a list.

- A list can be initialized by a list of elements.
