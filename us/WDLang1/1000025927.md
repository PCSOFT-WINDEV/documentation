


## HTMLEditorToPDF (Function)

***In french: EditeurHTMLVersPDF***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Exports the content of an HTML Editor control to a PDF file. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Export the content of the HTML Editor control to the invoice.pdf file
HTMLEditorToPDF(HTMEDT_MyHTMLEditor, "c:\my documents\invoice.pdf")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HTMLEditorToPDF(<HTML Editor control> , <PDF file>)`
---

**`<HTML Editor control>: (Control name)`**

Name of the HTML Editor control used. 

**`<PDF file>: (Character string)`**

Name and full path of the PDF file to be created. The file is replaced with the new file if it already exists.
