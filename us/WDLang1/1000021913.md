
## TelemetryConfigure (Function)

***In french: TélémétrieParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets and sets the telemetry settings. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Forces telemetry data to be sent every 30 minutes
TelemetryConfigure(tcMaximumPeriodCollection, 1800)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Getting the telemetry settings

`<Result> = TelemetryConfigure(<Parameter>)`
---

**`<Result>: (Integer)`**

Value of the specified parameter. 

**`<Parameter>: (Integer constant)`**

Parameter to retrieve. This parameter corresponds to one of the following constants: 


|   |   |
| --- | --- |
| *tcEnableLog* | Telemetry log settings. Can correspond to a combination of the following constants: <br><br>- *tpLogFichier*: Telemetry uses a log file. The corresponding file is saved in the "&lt;user&gt;\\AppData\\Roaming\\&lt;company&gt;\\&lt;application&gt;" directory. <br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This constant is not available.<br><br>- *tpLogMemory*: Telemetry uses a memory log. <br><br><br> |
| *tcGetMemoryLog* | Returns the contents of the memory log. |
| *tcIdleTimeout* | Used to count activity time on a window: the counting timer is automatically stopped after this period of inactivity. <br>This timeout is set to 1 minute by default. |
| *tcMaximumPeriodCollection* | Maximum telemetry data collection interval (in seconds). The data will be sent at the end of this period, regardless of the size of the data collected. <br>This period is set to 1 hour by default. |
| *tcMinimumPeriodCollection* | Minimum telemetry data collection interval (in seconds). The data can be sent at the end of this period if the minimum size is reached. <br>This period is set to 5 minutes by default. |
| *tcMinimumSizeCollection* | Minimum amount of data collected for the minimum collection interval (expressed in kilobytes). <br>This size is set to 5 MB by default. |
| *tcNumberSendAttempts* | Maximum number of attempts to send telemetry data in online mode: <br><br>- 0. Attempts are not counted. Data is sent every time, even if the server does not respond. <br><br>- 1. Data is sent only once when the application is started. If the server does not respond, there will be no more attempts. <br><br>- other value (3 by default). Allows you to set a total number of attempts within a given period to send data. <br><br><br><br><br>By default, tcNumberSendAttempts = 3 and tcMaximumPeriodCollection = 1 so there are 3 hours of attempts. |
| *tcOfflineMode* | Telemetry operating mode: <br><br>- <u><u><u><u>True</u></u></u></u> (default value). Telemetry works in offline mode. <br><br>- <u><u><u><u>False</u></u></u></u>. Telemetry works in online mode (default behavior before version 25).. <br><br><br><br><br>For more details on how telemetry works, see [Telemetry: Data transmission mode](../WDLang1/1410086649.md). |
| *tcStatus* | Current telemetry status. This status can correspond to one of the following constants: <br><br>- *teAbandon*: telemetry abandoned after too many sending errors. <br><br>- *teCollection*: telemetry is active and being collected. <br><br>- *teEnAttente*: telemetry is active but sending information to the server has failed. Data is waiting to be sent at a later date. <br><br>- *teSend* telemetry is active and has successfully sent information. <br><br>- *teError*: telemetry is active but sending information to the server has failed. <br><br>- *teInactive*: telemetry is inactive.<br><br><br> |

The corresponding file is saved in the "&lt;user&gt;\\AppData\\Roaming\\&lt;company&gt;\\&lt;application&gt;" directory. <br><br>- *tpLogMemory*: Telemetry uses a memory log. <br><br><br> |
| *tcIdleTimeout* | Used to count activity time on a window: the counting timer is automatically stopped after this period of inactivity. This timeout is set to 1 minute by default. |
| *tcMaximumPeriodCollection* | Maximum telemetry data collection interval (in seconds). The data will be sent at the end of this period, regardless of the size of the data collected. This period is set to 1 hour by default. |
| *tcMinimumPeriodCollection* | Minimum telemetry data collection interval (in seconds). The data can be sent at the end of this period if the minimum size is reached. This period is set to 5 minutes by default. |
| *tcMinimumSizeCollection* | Minimum amount of data collected for the minimum collection interval (expressed in kilobytes). This size is set to 5 MB by default. |
| *tcNumberSendAttempts* | Maximum number of attempts to send telemetry data in online mode: <br><br>- 0. Attempts are not counted. Data is sent every time, even if the server does not respond. <br><br>- 1. Data is sent only once when the application is started. If the server does not respond, there will be no more attempts. <br><br>- other value (3 by default). Allows you to set a total number of attempts within a given period to send data. <br><br><br><br><br>By default, tcNumberSendAttempts = 3 and tcMaximumPeriodCollection = 1 so there are 3 hours of attempts. |
| *tcOfflineMode* | Telemetry operating mode: <br><br>- <u><u><u><u>True</u></u></u></u> (default value). Telemetry works in offline mode. <br><br>- <u><u><u><u>False</u></u></u></u>. Telemetry works in online mode (default behavior before version 25).. <br><br><br><br><br>For more details on how telemetry works, see [Telemetry: Data transmission mode](../WDLang1/1410086649.md). |



**`<New value>: (Integer)`**

<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
**TelemetryConfigure** can be called before [TelemetryEnable](../WDLang1/1000021900.md). 

If **TelemetryConfigure** is called after [TelemetryEnable](../WDLang1/1000021900.md), the new parameters will be taken into account after a timeout not corresponding to the previous minimum collection time.
