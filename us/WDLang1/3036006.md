


## fLoadText (Function)

***In french: fChargeTexte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads the contents of a text file into any text field or variable (string variable, window edit control, report label field, etc.). [fSaveBuffer](../WDLang1/1000019412.md) is used to extract this file from the buffer.

## Syntax

`<Result> = fLoadText(<Name and path of text file> [, <Load mode>])`
---

**`<Result>: (Character string)`**



- Content of text file, 

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Name and path of text file>: (Character string)`**

Name and full (or relative) path of the text file. A UNC path can be used. This file doesn't have to be in TXT format: binary 0s are allowed.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The file path can correspond to a full path or to a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 

**`<Load mode>: (Integer constant)`**

Load mode of the file: 


|   |   |
| --- | --- |
| *foAnsi* | Ansi file. In this case, &lt;Result&gt; will correspond to an Ansi character string. |
| *foUnicode* | Unicode file. In this case, &lt;Result&gt; will correspond to an Unicode character string. |


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not supported. The returned format corresponds to the format supported by the current platform.

### View the contents of a file in Unicode
<a name="view_the_contents_file_unicode_ELTPARAGRAPHE000113"></a>

To view the contents of a file in Unicode, perform the following operation: 

```wl
// Load the content of "C:\MyFiles\MyFile.XML" into MyString 
MyBuffer is Buffer 
MyBuffer = fLoadText("C:\MyFiles\MyFile.XML")
MyString is Unicode string 
MyString = MyBuffer
Info(MyString)
```
