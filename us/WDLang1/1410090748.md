


## &lt;Command variable&gt;.AddArgument (Function)

***In french: &lt;Variable Commande&gt;.AjouteArgument***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds an argument to a command to be executed in console mode.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Define the command
MyCommandToExecute is Command
// Executable to run 
MyCommandToExecute = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("C:\path\file.log")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Command>.AddArgument(<Argument>)`
---

**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command to be manipulated.

**`<Argument>: (Character string)`**

Argument to add.
