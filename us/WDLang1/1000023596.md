
## gFontStrikeout (Function)

***In french: gPoliceBarrée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a sequence of characters used to specify whether the text that follows the call to this function is crossed out or not.

**Note** All text written after the function is assigned.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) In a window, this sequence of characters allows you to use strikethrough (or normal) text:  

- in an element of a List Box or Combo Box control.

- in the title bar and/or status bar of a window. 

- in a Static Text control. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the "WINDEV, IDE #1 (not 2) in France" title of next window
NextTitle("WINDEV, AGL #" + gFontStrikeout() + "2" + gFontStrikeout(False) + "1 in France.")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = gFontStrikeout([<Line-through>])`
---

**`<Result>: (Character string)`**

Sequence of characters defining whether the rest of the text must be crossed out or not.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This sequence of characters can be: 

- used in [ListAdd](../WDLang1/3049004.md), [ListInsert](../WDLang1/3049002.md) or [ListModify](../WDLang1/3049009.md).

- assigned to a Static Text control. 

- used in the title bar or status bar of a window. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This sequence of characters is not interpreted by the controls in WEBDEV. This function can be used to format the string returned by a WEBDEV web service consumed by a WINDEV or WINDEV Mobile application.

**`<Line-through>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (by default) if the text that follows **gFontStrikeout** must be crossed out,

- <u><u><u><u>False</u></u></u></u> otherwise.

<a name="NOTE0_1"></a>

## Remarks


- The default font is restored after the call to the [gFontXXX](../WDLang1/3029028.md) functions.

- All the other characteristics of the font are kept (italics, etc.).
