


## dSaveImagePNG (Function)

***In french: dSauveImagePNG***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves an image:

- in a PNG file.

- in memory.




This image corresponds to the image contained in one of the following elements:

- in an Image control. 

- in a variable of type [Image](../WDLang1/1000019650.md).
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available. 

- in a Bar Code control. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The Bar Code controls are not available in this version. Therefore, no image found in a Bar Code control can be saved.

- in a Web Camera control. 




**Remarks**:

- Only the visible part of the Image control is saved.

- The border of the Image control (if it exists) is also saved. 
	Reminder: The Image control frame is defined in the "Style" tab of the control description window. 

- This function can only be used to save the images for screen resolutions up to 32 bits.

- This function cannot be used with the Image controls found in reports.


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, this function can only be used to save an image in memory. ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md).

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003029027&name=dsaveimagepng_function">See additional examples</a>

```wl
// Saves the image found in "IMG_ImageDrawing" in "C:\Documents\Image.PNG"
ResSave = dSaveImagePNG(IMG_ImageDrawing, "C:\Documents\Image.PNG")
```

```wl
// Saves in memory the image found in "IMG_ImageDrawing"
ResSave = dSaveImagePNG(IMG_ImageDrawing, inMemory)
```

### Saving an image in a PNG file

`<Result> = dSaveImagePNG(<Image> , <File name> [, <Transparency color>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the image was saved,

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Image>: (Name of the Image control or variable)`**



- Name of the Image, Bar Code or Web Camera control to be saved. Image controls in a report cannot be used.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Name of the Image or Web Camera control to be used.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Name of the Image control to be used.

- Name of the [Image](../WDLang1/1000019650.md) variable to be used.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.




**`<File name>: (Character string)`**

Name and full (or relative) path of PNG file. A UNC path can be used. The file extension is optional.

**Caution**: 

- The destination directory must exist in order for the image to be saved.

- The existence of the PNG file is not checked. This file is automatically overwritten if it already exists.




**`<Transparency color>: (Optional integer)`**

Color that will be considered as being transparent in the image. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).


If this parameter is not specified, the generated image is not transparent.

### Saving an image in memory

`<Result> = dSaveImagePNG(<Image> , <inMemory> [, <Transparency color>])`
---

**`<Result>: (Buffer)`**

Byte string containing the image in PNG format.
Then, this byte string can be assigned to an Image control, saved in a file ([fSaveText](../WDLang1/3036046.md)), sent via a network (with the [Socket functions](../WDLang3/3070007.md)), ...
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) In browser code, this byte string can only be assigned to another image ("Localize the image in the _WEB directory in browser code" must be unchecked). It cannot be saved in a file to build an image file.

**`<Image>: (Name of the Image control or variable)`**



- Name of the Image, Bar Code or Web Camera control to be used. Image controls in a report cannot be used. 

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) Name of the Image or Web Camera control to be used.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Name of the Image control to be used.

- Name of the [Image](../WDLang1/1000019650.md) variable to be used.
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This type of variable is not available.




**`<inMemory>: (Constant)`**

*inMemory*: Constant used to save an image in memory.

**`<Transparency color>: (Optional integer)`**

Color that will be considered as being transparent in the image. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).


If this parameter is not specified, the generated image is not transparent.  

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This parameter is ignored.

### Displaying a PNG image

**Caution**: If the PNG image is semi-transparent, the image display will be slower.
<a name="NOTE0_3"></a>


### Transparent image in PNG format
<a name="transparent_image_png_format_ELTPARAGRAPHE000325"></a>

To save a transparent image in PNG format, the Image control must be filled with the transparent color beforehand.

Example used to draw a transparent line and to save it in PNG format: 

```wl
dStartDrawing(IMG_Image1, dWithOpacity)
dChangeMode(drawDefault)
FOR nI = 0 _TO_ IMG_Image1..Width
	FOR nJ = 0 _TO_ IMG_Image1..Height
		 dPoint(nI, nJ, RGB(255,255,255), 0)
	END 
END
dPen(RGB(100, 020, 200), 0,10, 100)
dLine(10, 10, 100, 10)
dSaveImagePNG(IMG_Image1, CompleteDir(fExeDir()) + "img.png")
```

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000488"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.
