
## fDir (Function)

***In french: fRep***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Finds a file or directory. This search can be performed with wildcard characters (\*,?).

**Remarks**: 

- To check if a file exists, use [fFileExist](../WDLang1/3036015.md).

- To check the existence of a directory, disk or share, use [fDirectoryExist](../WDLang1/3036059.md).

- To list the subdirectories of a directory, use [fListDirectory](../WDLang1/3036062.md).




It is also possible to build file paths directly with the / (slash) operator between components: the path will be automatically built dynamically with the expected format. Example: 

```wl
Disk is a string = "c:"
Directory is a string = "My documents".
FileName is a string = "SortieDeStock.xlsx"
PathComplete is a string
// Improved code readability
FullPath = Disk / Directory / FileName
```

## Syntax

`<Result> = fDir(<Name of sought file or directory> [, <Options>])`
---

**`<Result>: (Character string)`**



- Name of file (with its extension) or directory found. 

- Empty string ("") otherwise. To determine if this function has generated an error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.




**`<Name of sought file or directory>: (Character string)`**

Name and full (or relative) path of the sought file or directory (up to 260 characters). A UNC path can be used. You have the ability to use wildcard characters (\*,?) in the name of the file.
If this parameter is empty, the function continues the search to obtain the name of the next corresponding file (or directory): in this way, it is possible to obtain a list of files or directories belonging to a given directory.
If this parameter corresponds to a directory name, this name may (or may not) end with "\\".

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) If "\*.\*" is used, only files with an extension will be searched.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: On iPhone or iPad, an application has the rights to write to its installation directory or one of its subdirectories

**`<Options>: (Optional Integer constant (or combination of constants))`**

Search options:


|   |   |
| --- | --- |
| *frDirectory* | Find a directory. |
| *frFile*<br> (Default value) | Find a file. |
| *fUnicodePath* | &lt;Result&gt; will be a Unicode string.<br>This constant can be combined with *frFile* or *frDirectory*. |

## Remarks




### Note: the fDir function retains access to the
<a name="note_the_docparampagetitleshort_function_retains_access_the_ELTPARAGRAPHE000134"></a>

Calling **fDir** keeps an access to the directory, and prevents you from deleting or renaming it. To unlock the directory, add the following line of code to your process:


```wl
fDir("")
```

<a name="NOTE0_2"></a>




### Looping through directories
<a name="looping_through_directories_ELTPARAGRAPHE000148"></a>

Directory iterations performed with **fDir** must not be nested.

fDir must not be used when **[fCopyFile](../WDLang1/3036004.md)** is used to a loop through directories.
<a name="NOTE0_3"></a>




### Windows
<a name="windows_ELTPARAGRAPHE000164"></a>

In Windows, a file name or a directory name can contain lowercase and/or uppercase characters (the names of the files are not "case sensitive").

Therefore, you should not write:


```wl
IF fDir(FileName) = "TOTO" THEN Info("File found")
```


But you should write:


```wl
IF fDir(FileName) ~= "TOTO" THEN Info("File found")
```

<a name="NOTE0_4"></a>




### Using fDir in threads
<a name="using_docparampagetitleshort_threads_ELTPARAGRAPHE000180"></a>

It is not recommended to use **fDir** at the same time in two different threads. 

The last iteration started with **fDir** automatically replaces the current iteration.
