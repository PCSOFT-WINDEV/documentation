


## &lt;Array&gt;.DeleteAll (Function)

***In french: &lt;Tableau&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all elements:

- from a one-dimensional or two-dimensional WLanguage array.

- from an associative array.

- from an array property of an advanced variable type (array of events of a gglCalendar variable, etc.).

- from a WLanguage queue.

- from a WLanguage stack.  

- from a WLanguage list. 




![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) **Remarks**: 

- ![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This function can only be used with Array and Associative array variables.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This function can only be used with:

	- Array and Associative array variables.

	- WLanguage queues. 

	- WLanguage stacks.

	- WLanguage lists. 
			














<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyArray is array of 2 strings
MyArray[1] = "WINDEV"
MyArray[2] = "WEBDEV"
// Delete all the elements
MyArray.DeleteAll()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<WLanguage variable>.DeleteAll()`
---

**`<WLanguage variable>: (Array, queue, stack or list)`**

Name of the WLanguage variable to use. This variable can be:

- an Array. This array must be a one-dimensional array or a two-dimensional array.

- a Queue.

- a Stack.

- a List.


![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only Array variables can be used. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Deleting elements
<a name="deleting_elements_ELTPARAGRAPHE000299"></a>

- **One-dimensional array**: The array size is set to 0. The array is not deleted. You can add new elements without recreating the array.

- **Two-dimensional array**: Only array rows are deleted. Columns are preserved. Therefore, [&lt;Array&gt;.AddLine](../WDLang1/1000024300.md) can be used after **&lt;Array&gt;.DeleteAll**.

- **Associative array**: All the elements of the array are deleted.

- **Queue**: All the elements of the queue are deleted.

- **Stack**: All the elements of the stack are deleted.

- **List**: All the elements of the list are deleted.




Note: To set the elements of the array to 0 (or "") without changing the array size, use [VariableReset](../WDLang1/3013069.md).

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Elements of Queue, Stack and List variables cannot be deleted.
<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000330"></a>

This function cannot be used with fixed arrays.
