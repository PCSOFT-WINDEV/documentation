


## Parameters of the procedure used by fReadLine



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("Callback") called by [fReadLine](../WDLang1/3036031.md) for each line read in the file. This procedure can be a local, global or internal procedure.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Declare the variables
FileNameAndPath is string
FileID is int
NumberLinesRead is int = 0

// Declaration of the WLanguage procedure
	INTERNAL PROCEDURE AnsiCallback(LineRead is ANSI string)
		Trace("Callback | Line read: " + LigneLue)
	END

// Select the file name and path
FileNameAndPath = "C:\Directory\AnsiFile.txt"

// Open file
FileID = fOpen(FileNameAndPath, foAnsi)
// Display an error message if no file was opened
IF FileID = -1 THEN
	Error(ErrorInfo(errMessage))
ELSE
	// Read the lines of the file
	NumberLinesRead = fReadLine(FileID, AnsiCallback)
	IF ErrorOccurred THEN
		Error(ErrorInfo())
	END
	Trace("Number of lines read: " + nbLigneLu)	
	// Close the file
	fClose(FileID)
	Trace("Read operation completed")
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fReadLine_Callback(<Row read>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the line was read,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Row read>: (Character string)`**

Content of the line read in the file.
