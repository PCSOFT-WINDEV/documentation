
## TelemetryIsEnabled (Function)

***In french: TélémétrieEstActive***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to find out whether the telemetry is enabled. 

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
If TelemetryIsEnabled() = False THEN TelemetryEnable()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = TelemetryIsEnabled()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the telemetry is enabled, 

- <u><u><u><u>False</u></u></u></u> otherwise. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Caution: Telemetry is never activated in test mode, to avoid filling the database with partial data. Telemetry is enabled and can only be activated in the generated application.
