


## &lt;HTML Display control&gt;.ControlValue (Function)

***In french: &lt;Champ d'affichage HTML&gt;.ValeurChamp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to identify or modify a control in an HTML form contained in an HTML Display control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF HTM_Display.ControlValue("LOGIN") <> "" THEN
	HTM_Display.ControlValue("LOGIN", NetworkUser())
END
```

```wl
HTM_Sites.ControlValue("input4")
IF ErrorOccurred THEN
	Trace(ErrorInfo()) // ex: The field <"input4"> does not exist in page.
	RETURN
ELSE
	HTM_Sites.ControlValue("input4", sControlValue)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Identifying the value of a control in an HTML form

`<Result> = <HTML Display control>.ControlValue(<Control in the page>)`
---

**`<Result>: (Character string)`**



- Value of the control in the HTML Display control,

- Empty string ("") if an error occurs (e.g. if the control is not found in the page). In this case, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<HTML Display control>: (Control name)`**

Name of the HTML Display control used.

**`<Control in the page>: (Character string)`**

Name of the control contained in the HTML page displayed by the HTML Display control.


<a name="SYNTAXE2"></a>

### Modifying the value of a control in an HTML form

`<HTML Display control>.ControlValue(<Control in the page> , <Value>)`
---

**`<HTML Display control>: (Control name)`**

Name of the HTML Display control used.

**`<Control in the page>: (Character string)`**

Name of the control contained in the HTML page displayed by the HTML Display control. If the control is not found, a non-fatal error occurs.

**`<Value>: (Character string)`**

Control value to be modified.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **Important** For this function to execute in the context of the HTML page displayed in the HTML Display control, the field must be accessible in Javascript in the page. There should be no access restrictions on this page.

- This function allows you to automate processes in the Web page displayed in an HTML Display control.

- The control is searched by its name and then by its ID. The name of the control (or its ID) can be known by editing the source code of the HTML page.

- Please note: HTML names are case sensitive.
