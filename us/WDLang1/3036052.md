
## fWebDir (Function)

***In french: fRepWeb***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the physical name of the directory containing the images, JavaScript files and Java files of the WEBDEV website. This directory corresponds to the &lt;Project name&gt;_WEB directory. This directory is present on both the development computer and the deployment computer.

This enables you to read, write or modify the files found in this directory. 


	<B><B><B>Warning</B></B></B>

	 Modifications and write operations are performed on the development computer. 
These operations can only be performed **on the deployment server** if the hosting provider grants the necessary permissions.



![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Returns the full physical name of the directory containing the PHP page currently run, the images, the JavaScript and Java files of the WEBDEV site. This directory corresponds to the language subdirectory of &lt;Project name&gt;_WEB. This directory is present on both the development computer and the deployment computer.

Npte: To get the "&lt;Project name&gt;_WEB" directory, you can use:

- [FolderWeb](../WDLang2/3012015.md): This function returns a relative path to be interpreted by the browser. 

- **fWebDir**: This function returns an absolute path to be used from the server with the [external file functions (fxxx)](../WDLang1/3036034.md).

## Example


```wl
// Runtime directory
Info("Image files located in the following directory: " + fWebDir())
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = fWebDir()`
---

**`<Result>: (Character string)`**

Full physical name of the directory containing the images, the JavaScript and Java files of the WEBDEV site. This result has the following format: "C:\\My Project\\Schedule\\Schedule_WEB". No "\\" character is found at the end of this result.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Full physical name of the directory containing the PHP page, the images, the JavaScript and Java files of the WEBDEV site. This result has the following format: "C:\\My Projects\\Schedule\\Schedule_WEB\\US". No "\\" character is found at the end of this result.
