
## CertificateSignMSIXPackage (Function)

***In french: CertificatSignePackageMSIX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Signs an MSIX package with a certificate. 

Note: This function is for advanced use only. The MSIX package is automatically signed when it is created. For more details, see [MSIX installation format](../Editeurs/9000229.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Load a certificate
signature_certificate is Certificate
arrCertificate is array of Certificate
arrCertificate = CertificateLoad(signature_file_name, "")
signature_certificate = arrCertificate[1]
// Sign package
IF signature_certificate.ValidForSignature THEN
	CertificateSignMSIXPackage(msix_package_file_name, signature_certificate)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CertificateSignMSIXPackage(<MSIX package> , <Certificate>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the package was signed,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<MSIX package>: (Character string)`**

Name of the file corresponding to the MSIX package to be signed. 

**`<Certificate>: (Certificate variable)`**

Name of the [Certificate](../Proprietes/1000021684.md) variable corresponding to the certificate to be used to sign the MSIX package.
