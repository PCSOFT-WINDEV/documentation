
## OptimalHeight (Function)

***In french: HauteurAdaptée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the height a control needs to display its entire content. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Optimal_height is int = OptimalHeight(LIST_Recipes)
IF Optimal_height < 100 THEN
	// Show details directly under the List Box control
	LIST_Recipes.Height = Optimal_height
	BTN_Show_details.Visible = False
	IW_Details.Visible = True
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Height> = OptimalHeight(<Control>)`
---

**`<Height>: (Integer)`**

Height the control needs to display its entire content. 

**`<Control>: (Control name)`**

Name of the control used. This can be a Table, Layout, Edit control, etc.
