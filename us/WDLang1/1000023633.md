


## &lt;Html&gt;.Navigate (Function)

***In french: &lt;HTML&gt;.Navigue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts navigation in an HTML Display control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Code of Forward button
HTM_HTMLControl1.Navigate(htmlForward)
```
<a name="Exemple2"></a>

```wl
// Code of Back button
HTM_HTMLControl1.Navigate(htmlBack)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<HTML control>.Navigate(<Navigation option>)`
---

**`<HTML control>: (Control name)`**

Name of the HTML Display control to be used.

**`<Navigation option>: (Constant)`**

Navigation direction:


|   |   |
| --- | --- |
| *htmlBack* | Displays the previous page (equivalent to the browser's "BACK/Previous" button). |
| *htmlForward* | Displays the next page (equivalent to the browser's "FORWARD" button). |
| *htmlHome* | Displays the home page (equivalent to the browser's "Home" button). To get the initial value of the HTML Display control, use the [InitialValue](../Proprietes/2510128.md) property.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This constant is not available. |
| *htmlRefresh* | Refreshes the current page (equivalent to the browser's "Refresh" button). |
| *htmlStop* | Stops loading resources used by the page. The "Load resources" event of the control is not executed. |





`<HTML control>.Navigate(<URL to display>)`
---

**`<HTML control>: (Control name)`**

Name of the HTML Display control to be used.

**`<URL to display>: (Character string)`**

URL to be displayed in the Formatted Display control.
