


## docFormatting (Variable type)

***In french: docMiseEnForme***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docFormatting** type is used to define the formatting characteristics of an element in a Word Processing document. Formatting characteristics can be defined and changed using different WLanguage properties. 

**CAUTION: This type must not be used directly. It must be used via**: 

- the [docElementFormula](../WDLang1/1000022937.md) type. 

- the [docElementText](../WDLang1/1000022493.md) type. 



<a name="PROPS"></a>

## Properties


### Properties specific to docFormatting variables
<a name="properties_specific_docformatting_variables_ELTPARAGRAPHE000026"></a>

The following properties can be used to handle the formatting:

| Property name | Type used | Effect |
| --- | --- | --- |
| VerticalAlign | Integer constant | Vertical alignment of text in relation to the base line: <br><br>- *alignmentBaseline* Text is positioned on the baseline. <br><br>- *alignmentExponent* Text is positioned in superscript. <br><br>- *alignmentIndex* Text is positioned in index. <br><br><br> |
| UnderlineColor | Integer | Color used to underline the text. This color can correspond to:<br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)).<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a preset color](../WDLang5/3010002.md) functions.<br><br><br> |
| HighlightColor | Integer | Color used to highlight the text. Only the following colors are available: <br><br>- *Transparent*<br><br>- *Black*<br><br>- *LightBlue*<br><br>- *LightCyan*<br><br>- *LightGreen*<br><br>- *LightMagenta*<br><br>- *LightRed*<br><br>- *LightYellow*<br><br>- *White*<br><br>- *DarkBlue*<br><br>- *DarkCyan*<br><br>- *DarkGreen*<br><br>- *DarklMagenta*<br><br>- *DarkRed*<br><br>- *DarkYellow*<br><br>- *LightGray*<br><br>- *DarkGray*<br><br><br> |
| TextColor | Integer | Text color. This color can correspond to:<br><br>- an RGB color (returned by [RGB](../WDLang1/3029012.md)).<br><br>- an HSL color (returned by [HSL](../WDLang1/3029057.md)),<br><br>- [a preset color](../WDLang5/3010002.md) functions.<br><br><br> |
| FontStrikeOut | Boolean | <br><br>- <u><u><u>True</u></u></u> if the text font is struck through,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
| FontBold | Boolean | <br><br>- <u><u><u>True</u></u></u> if the text font is bold,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
| FontItalic | Boolean | <br><br>- <u><u><u>True</u></u></u> if the text font is in italics,<br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
| FontName | Character string | Name of font used for the text. |
| FontUnderlined | Integer constant | Type of underline: <br><br>- *underlinedNo*: No underlining<br><br>- *underlinedDouble*: Double underlining<br><br>- *thick underlining*: thick underlining<br><br>- *underlinedWords*: Underlining of words only<br><br>- *underlinedDotted*: Dotted underlining<br><br>- *underlinedThick dotted*: Thick dotted underlining<br><br>- *underlinePointDash* Underline type '..-' (dot dot dash)<br><br>- *underlineDotDashThick* Underline type '..-' (dot dot dash) thick<br><br>- *underlinePointTiret* Underline type '.-' (dash point)<br><br>- *underlineThickDashPoint* Underline type '.-' (dash point) thick<br><br>- *underlinedSimple*: Simple underlining<br><br>- *underlinedTiret*: Underlining with dashes<br><br>- *: Underline with thick dashes*: Underline with thick dashes<br><br><br> |
| FontSize | Real | Size of font. |
