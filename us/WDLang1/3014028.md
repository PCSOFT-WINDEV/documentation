
## ExecutePresetAction (Function)

***In french: ExécuteActionPrédéfinie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Runs a preset WINDEV action.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
// Open an explorer on the "C:\My Documents\" directory
ExecutePresetAction(actBrowseDirectory, "C:My Documents\")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ExecutePresetAction(<Action> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Action>: (Integer constant)`**

Preset action to run. The available constants are as follows:

| Constant | Action | Parameters |
| --- | --- | --- |
| *actPaste* | Paste clipboard content | &lt;none&gt; |
| *actCopy* | Copy the selected content to the clipboard | &lt;none&gt; |
| *actCut* | Cut the selected content from the clipboard | &lt;none&gt; |
| *actEraseRWDisk* | Erase the content of a directory on CD-RW/DVD-RW<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available | Constant used to specify the erase mode: <br><br>- *burnerCompleteErasement*: complete erasure of media (may take some time). <br><br>- *burnerFastErase*: quick erasing of the media. <br><br><br> |
| *actSendEmail* | Send an email | 1: SMTP server<br>2: Login<br>3: Password<br>4: Sender<br>5: Recipient<br>6: Subject<br>7: Contents<br>8: Port number |
| *actBrowseDirectory* | Open an explorer on a directory<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. | 1: Directory path |
| *actBurnADirectory* | Burn the content of a directory onto a CD-R/DVD-R<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. | 1: Directory path |
| *actMinimize* | Minimize the current window | &lt;none&gt; |
| *actWinImageToClipboard* | Copy the image of the current window to the clipboard | &lt;none&gt; |
| *actRunContextSensitiveHelp* | Switch to "Context-sensitive help" mode<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. | &lt;none&gt; |
| *actRunInternetSite* | Open an Internet browser on an URL<br><br>![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. | 1: URL to display |
| *actReadLast* | Read the last record (in the data file currently used). | &lt;none&gt; |
| *actReadPrevious* | Read the previous record (in the data file currently used). | &lt;none&gt; |
| *actReadFirst* | Read the first record (in the data file currently used). | &lt;none&gt; |
| *actReadNext* | Read the next record (in the data file currently used). | &lt;none&gt; |
| *actOpenReport* | Open the print preview of a report<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Constant not available. | 1: State name |


![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png) Only the *actOpenReport* and *actSendEmail* constants are available.

**`<Parameter 1>: (Character string or integer (optional))`**

First parameter associated with the preset action.



**`<Parameter N>: (Character string or integer (optional))`**

Nth parameter associated with the preset action.
