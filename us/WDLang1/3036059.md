
## fDirectoryExist (Function)

***In french: fRépertoireExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence of a directory.

Note: This function is equivalent to [fDirExist](../WDLang1/1000021899.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/us/AJAX.png) 
```wl
MyDirectory is string = "C:\DataDirectory"
IF fDirectoryExist(MyDirectory) = True THEN 
	Info("The directory " + MyDirectory + " exists on disk")
END
```

## Syntax

`<Result> = fDirectoryExist(<Directory name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the directory exists, 

- <u><u><u><u>False</u></u></u></u> otherwise (the directory name corresponds to a file name for example).




**`<Directory name>: (Character string)`**

Name and full (or relative) path of the directory. Wildcard characters (\*,?) are not allowed.

![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This parameter can be in Ansi or Unicode format.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: In Android, the file system is read-only on the device and on the emulator. An application can only write to its installation directory or one of its subdirectories, as well as to the external memory (SDCard).

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder** Under iPhone/iPad, on both the device and the emulator, the file system is read-only. An application can only write to its installation directory or one of its subdirectories.
