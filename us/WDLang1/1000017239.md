


## ExeGetPID (Function)

***In french: ExeDonnePID***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about the current process.

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In the server code of a dynamic site, **ExeGetPID** returns the identifier of the connection visible in the WEBDEV administrator (for more details, see [WEBDEV administrator](../WDAdminDeploiement/3539007.md)). This identifier is unique during the call and as long as the connection is established. It is not unique in time.



![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function is now available for iPhone/iPad applications.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// PID of the application
MyPID is int
MyPID = ExeGetPID()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = ExeGetPID([<Desired information>])`
---

**`<Result>: (System integer)`**

Requested information.

**`<Desired information>: (Optional Integer constant)`**

Information about the current process:


|   |   |
| --- | --- |
| *exeParentPID* | PID of parent (which means the process that started the current process).<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *exePID*<br>(default value) | PID (Processus Identifier) of the current process. |
| *exeTID* | Identifier of the current thread.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
