


## HourGlass (Function)

***In french: Sablier***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Transforms the mouse cursor into hourglass and vice versa. This allows you to inform the user that a long process is performed by displaying an hourglass. For the duration of the HourGlass display, the window is inactive: the user cannot click in the window.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Displays or hides an endless progress bar. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
HourGlass()         // Display the hourglass
ProcProcess()  // Long process
HourGlass(False)     // Restore the initial pointer
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
// Display the message in the progress bar
NextTitle("Connection...") 
HourGlass() 

// Long process
ProcProcess()  

// In Android and IOS, update the progress bar during the process.
Multitask(-1)    

// Stop the infinite progress bar
HourGlass(False)     
NextTitle("")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`HourGlass([<Activation>])`
---

**`<Activation>: (Optional constant)`**

Activation or deactivation constant: 


|   |   |
| --- | --- |
| *False* | Cancels the hourglass that was enabled last. If this houglass is the only one that is enabled, the mouse cursor takes its initial shape. |
| *falseAllHourglass* | Cancels all current hourglasses to restore the initial shape of mouse cursor.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Deletes the infinite progress bar. |
| *True*<br>(Default value) | Enables the hourglass. |

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000081"></a>

- To restore the cursor to its initial status: 

	- call **HourGlass(False)** as many times as **HourGlass(True)** was run.

	- use the *falseAllHourglass* constant. 




- When a WLanguage process ends, the cursor is automatically restored to its standard shape.



![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Operating mode in Android
<a name="operating_mode_android_ELTPARAGRAPHE000096"></a>

Using **HourGlass** triggers the display of an infinite progress bar. The application interface can no longer be handled by the user as long as the hourglass is displayed. 

By default, no message is displayed beside the progress bar. 

The following actions can be performed: 

- To display a message, use [NextTitle](../WDLang1/3038043.md). 

- To change the message while the progress bar is displayed, simply run [NextTitle](../WDLang1/3038043.md) again, and then run **HourGlass**. 

- To hide the progress bar, use **HourGlass** with &lt;Activation&gt; = False as many times as **HourGlass** was called with &lt;Activation&gt; = True.


**Note** When running long processes, we recommend adding calls to function [Multitask](../WDLang1/3015004.md) in the code, to give the ProgressBar time to refresh its display.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 

### Operating mode in iPhone/iPad
<a name="operating_mode_iphoneipad_ELTPARAGRAPHE000132"></a>

Using **HourGlass** triggers the display of an infinite progress bar. The application interface can no longer be handled by the user as long as the hourglass is displayed. 

By default, no message is displayed beside the progress bar. 

To display a message, use [NextTitle](../WDLang1/3038043.md). 

**Note** When running long processes, we recommend adding calls to function [Multitask](../WDLang1/3015004.md) in the code, to give the ProgressBar time to refresh its display.
