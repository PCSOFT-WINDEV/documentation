


## DocOpen (Function)

***In french: DocOuvre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a Word Processing file (docx format) in Read/Write mode. The docx file is opened and locked until it is closed.

**Note** To create a docx file without using an initial file, simply create a variable of type [Document](../WDLang1/1000022461.md) (the function **DocOpen** function).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Using a Document variable
d is Document
d = DocOpen("C:\Users\test\Documents\file.docx")

IF ErrorOccurred() THEN
	Error(ErrorInfo())
	RETURN
END
```



```wl
// Using a Word Processing control
DocOpen(WP_MyWP, "C:\Users\test\Documents\file.docx")

IF ErrorOccurred() THEN
	Error(ErrorInfo())
	RETURN
END
```

## Syntax
<a name="SYNTAXE1"></a>

### Associating a docx file with a Document variable

`<Result> = DocOpen(<Document source> [, <Password>])`
---

**`<Result>: (Document variable)`**

Name of the [Document](../WDLang1/1000022461.md) variable corresponding to the docx file. This variable can be used in all the [DocXXX](../WDLang1/1000022618.md) functions.

In the event of an error, variable [ErrorOccurred](../WDLang1/3087001.md) is set to <u><u><u><u>True</u></u></u></u> and function [ErrorInfo](../WDLang1/3013008.md) is used to find out the cause of the error.

**`<Document source>: (Type corresponding to the source)`**

Corresponds to one of the following elements: 

- Full or relative path of docx file to open (up to 260 characters).

- Name of the Buffer variable with the docx document to display in the Word Processing control. 

- Name of the memo item with the docx document to display in the Word Processing control. This parameter is of the form: &lt;Fichier de données&gt;.&lt;Rubrique&gt;.




**`<Password>: (Optional string or Secret string)`**

Password to open the docx file to use (if the file is protected by a password).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).

### Associating a docx file with a Word Processing control

`<Result> = DocOpen(<Word Processing control> , <Document source> [, <Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the docx file was opened in the Word Processing control,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<Word Processing control>: (Control name)`**

Name of Word Processing control where the docx file will be opened.

**`<Document source>: (Type corresponding to the source)`**

Corresponds to one of the following elements: 

- Full or relative path of docx file to open (up to 260 characters).

- Name of the Buffer variable with the docx document to display in the Word Processing control. 

- Name of the memo item with the docx document to display in the Word Processing control. This parameter is of the form: &lt;Fichier de données&gt;.&lt;Rubrique&gt;.




**`<Password>: (Optional string or Secret string)`**

Password to open the docx file to use (if the file is protected by a password).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
