


## &lt;Multimedia&gt;.Width (Function)

***In french: &lt;Multimédia&gt;.Largeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the width (in pixels) of the source image of the media file played in the Multimedia control. This function can be used for the video files for example.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Note** Depending on the type of video and browser configuration, this function may not be supported. In this case, its use will have no effect but no error will be triggered.


<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Multimedia control>.Width()`
---

**`<Result>: (Integer)`**



- Width of the image of the media file (in pixels), 

- 0 if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Note: The [ErrorInfo](../WDLang1/3013008.md) function is not available.

**`<Multimedia control>: (Control name)`**

Name of the Multimedia control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- [&lt;Multimedia&gt;.Height](../WDLang1/1000019999.md) gets the height of a media file. 

- **&lt;Multimedia&gt;.Width** gets the width of a media file.
