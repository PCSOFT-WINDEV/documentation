


## InfoVersion (Variable type)

***In french: InfoVersion***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **InfoVersion** type is used to get the characteristics of a specific application version. The characteristics of this version are returned by several WLanguage properties.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sRes is string = AppliListVersion()
IV is InfoVersion

sDisplay is string = [
Number = %1
Date = %2
Size = %3 bytes
Comment = %4
Enabled = %5
Forced = %6
Forbidden = %7
]

FOR EACH STRING MyString OF sRes SEPARATED BY CR
	IV = AppVersionInfo(MyString)
	Trace(StringBuild(sDisplay, ...
		IV.VersionNumber, IV.Date, ...
		IV.Size, IV.Comment, ...
		IV.Enabled, IV.Forced, IV.Forbidden))
	Trace("===============================================")
END
```

## Properties


### Properties specific to InfoVersion variables
<a name="properties_specific_infoversion_variables_ELTPARAGRAPHE000037"></a>

The following properties can be used to define the characteristics of **InfoVersion** variables:


| Property name | Type used | Effect |
| --- | --- | --- |
| Enabled | Boolean | <br><br>- <u><u><u>True</u></u></u> if the version is enabled (which means visible by the client computers),<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>**This property is read-only**.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
| Comment | Character string | Information about new features in this version. This information was specified by the developer. The content of this property can be: <br><br>- a text,<br><br>- a text, RTF or CHM file,<br><br>- a "link" to a help page (help about new features generated when creating the executable). <br><br><br>**This property is read-only**. |
| Date | DateTime | Version release date. <br>**This property is read-only**. |
| Forced | Boolean | <br><br>- <u><u><u>True</u></u></u> if the version is forced, <br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br>**This property is read-only**.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
| Forbidden | Boolean | <br><br>- <u><u><u>True</u></u></u> if this version is forbidden, <br><br>- <u><u><u>False</u></u></u> if the version is allowed. <br><br><br>**This property is read-only**.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This property is not available. |
| VersionNumber | Character string | Number of the version. <br>**This property is read-only**. |
| Size | Integer | Size of the version on disk (in bytes). <br>**This property is read-only**. |
