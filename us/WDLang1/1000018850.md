


## KeyCompareKey (Function)

***In french: CléCompareClé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Compares an initial key with an activation key. The match between these two keys is verified: an "initial key/activation key" pair is valid only on a given workstation.

**Note**: As a general rule, this function is used on the application user's workstation: the initial key is compared with the corresponding activation key supplied by the application supplier.. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Your secret to customize
Secret is string = "]$x+9*EBM%u]yK|R@=y"
// ------------------------------------
// In the application, client side
InitialKey is string 
InitialKey = KeyGenerateInitialKey(ClientID)
Info("Your license key is: " + InitialKey)

// -> InitialKey is transmitted to the application provider

// --------------------------------------------
// Supplier side: activation key calculation
ActivationKey is string 
Identifier is string 

ActivationKey = KeyCalcActivationKey(InitialKey, Secret)
Identifier = KeyGetIdentifier(InitialKey)
Info("Activation key generated for customer " + Username + ": " + ActivationKey)
// -> ActivationKey is transmitted to the client for the activation of his license

//--------------------------------------------
// Customer side: Enter activation key
gbActivationOK = KeyCompareKey(InitialKey, ActivationKey, Secret)
IF gbActivationOK = False THEN
	Error("Wrong activation key")
	EndProgram()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = KeyCompareKey(<Initial key> , <Activation key> [, <Secret>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the activation key matches the initial key, 

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Initial key>: (Character string)`**

Initial key supplied by the client of the application. This key was generated by [KeyGenerateInitialKey](../WDLang1/1000018848.md).

**`<Activation key>: (Character string)`**

Activation key corresponding to the initial key. This activation key was generated by [KeyCalcActivationKey](../WDLang1/1000018849.md).

**`<Secret>: (Character string or Secret string)`**

Decryption key of the activation key. This parameter must be identical to the &lt;Secret&gt; parameter specified in [KeyCalcActivationKey](../WDLang1/1000018849.md). 
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
