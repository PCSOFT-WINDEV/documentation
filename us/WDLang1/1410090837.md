


## SegmentedButtonDeleteAll (Function)

***In french: BoutonSegmentéSupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all the options from a Segmented Button control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SegmentedButtonDeleteAll(SB_Responses)
FOR I = 1 TO nbResponse
	SegmentedButtonAdd(SB_Responses, "Response" + I)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`SegmentedButtonDeleteAll(<Segmented Button control>)`
---

**`<Segmented Button control>: (Control name)`**

Name of the Segmented Button control used. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Deleting an option does not change the size of the Segmented Button control. The control size can be changed using the [Width](../Proprietes/2510059.md) and [Height](../Proprietes/2510050.md) properties.
