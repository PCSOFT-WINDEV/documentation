


## &lt;Command variable&gt;.Execute (Function)

***In french: &lt;Variable Commande&gt;.Exécute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Executes a command in console mode. This command must have been defined by a variable of type [Command](../WDLang1/1410090491.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'
// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute.Executable = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Command>.Execute([<Blocking>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the command was run,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command to be executed in console mode.

**`<Blocking>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default) to block the application until the command finishes executing. 

- <u><u><u><u>False</u></u></u></u> to let the application run without waiting for the command to finish executing.
