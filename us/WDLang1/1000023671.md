


## &lt;Edit&gt;.AddAssistedInput (Function)

***In french: &lt;Saisie&gt;.AjouteSaisieAssistée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a row to the list of values available in the input suggestions of an Edit control. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
EDT_Direction.DeleteAllAssistedInput()
EDT_Direction.AddAssistedInput("Left")
EDT_Direction.AddAssistedInput("Left to the top")
EDT_Direction.AddAssistedInput("Left to the bottom")
EDT_Direction.AddAssistedInput("Right")
EDT_Direction.AddAssistedInput("Right to the top")
EDT_Direction.AddAssistedInput("Right to the bottom")
EDT_Direction.AddAssistedInput("Center")
EDT_Direction.OpenAssistedInput()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Adding a row to the list of values available in the input suggestions

`<Result> = <Edit control>.AddAssistedInput(<Text> [, <Stored value>])`
---

**`<Result>: (Integer)`**

Number of the added row.

**`<Edit control>: (Control name)`**

Name of the Edit control to be used.

**`<Text>: (Character string)`**

Value to be added to the input suggestions.

**`<Stored value>: (Type of value)`**

Stored value associated with the added value.

![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available.


<a name="SYNTAXE2"></a>

### Adding a row (AssistedInput variable) to the list of available values

`<Result> = <Edit control>.AddAssistedInput(<Suggestion>)`
---

**`<Result>: (Integer)`**

Number of the added row.

**`<Edit control>: (Control name)`**

Name of the Edit control to be used.

**`<Suggestion>: (AssistedInput variable)`**

Name of the [AssistedInput](../WDLang1/1410088983.md) variable containing the value of the suggestion to be added.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
To open the list with the different options:  

- the user can enter a value in the Edit control (starting with the letters of one of the available options). 

- programmatically, you can use [&lt;Edit&gt;.OpenAssistedInput](../WDLang1/1000024063.md). It is recommended to filter the list of values and open it from the "Whenever modifying" event of the Edit control.
