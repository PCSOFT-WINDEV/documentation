
## AIChatSaveConversation (Function)

***In french: AIChatSauveConversation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Saves the current conversation in an AI Chat control to memory or as a JSON file. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Click "Save conversation"
AIChatSaveConversation(myAIChat, "file.json")
IF ErrorOccurred THEN
	Error()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Saving a conversation to a file

`<Result> = AIChatSaveConversation(<AI Chat control> , <File>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the conversation was saved,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<AI Chat control>: (Control name)`**

AI Chat control used. 

**`<File>: (Character string)`**

File name and full or relative path. A UNC path can be used. The conversation is saved as a JSON file. 


<a name="SYNTAXE2"></a>

### Saving a conversation in a buffer

`<Result> = AIChatSaveConversation(<AI Chat control> , <Save>)`
---

**`<Result>: (Buffer)`**

Buffer corresponding to the conversation. 

**`<AI Chat control>: (Control name)`**

AI Chat control used. 

**`<Save>: (Integer constant)`**



- *inMemory* constant to save the conversation in a buffer. This buffer will contain the conversation in JSON format.
