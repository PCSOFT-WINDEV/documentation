
## aiModelInfoChat (Variable type)

***In french: aiModelInfoChat***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **aiModelInfoChat** type is used to define all the advanced characteristics of a connection to the AI model used by an AI Chat control. You can define and change the characteristics of this connection using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
myAI is aiModelInfoChat
myAI.Provider = aiProviderCustom
myAI.Protocol = aiProtocolOpenAI
myAI.Address = "localhost:11434"
AICHAT_AIChat.AIModelInfo = myAI
```

<a name="PROPS"></a>

## Properties


### Properties specific to aiModelInfoChat variables
<a name="properties_specific_aimodelinfochat_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to manipulate the connection to the AI model linked to an AI Chat control:



| Property name | Type used | Effect |
| --- | --- | --- |
| Address | Character string | Address of the server that hosts the AI engine. <br><br>This property is only necessary when using a specialized provider. |
| Identifier | Character string | API key to use. <br><br>This property is necessary when using an external provider.<br><br>In the case of a custom provider, this property is not required. |
| Name | Character string | Name of the model used. <br><br>Example: "deepseek-r1:1.5b" |
| Protocol | Integer constant | Specifies the protocol used to exchange data with the AI engine if the Provider property is set to *aiProviderCustom*. <br><br>This property can use one of the following constants:<br><br>- *aiProtocolOpenAI*: OpenAI protocol. <br><br>- *aiProtocolAnthropic*: Anthropic protocol.<br><br>- *aiProtocolGoogle*: Google protocol.<br><br>- *aiProtocolOpenRouteur*: OpenRouter protocol.<br><br>- *aiProtocolMistral*: Mistral protocol.<br><br>- *aiProtocolXAI*: xAI protocol.<br><br><br> |
| Provider | Integer constant | AI model type:<br><br>- *aiProviderAnthropic*: Anthropic (Claude)<br><br>- *aifProviderNone*: No provider defined. If this constant is specified, the AI Chat control will stop working.  This constant can be used to disable the use of AI, for example. <br><br>- *aiProviderGoogle*: Google (Gemini)<br><br>- *aiProviderMistral*: Mistral AI (Le Chat)<br><br>- *aiProviderOpenAI*: OpenAI (ChatGPT)<br><br>- *aiProviderOpenRouter*: OpenRouter<br><br>- *aiProviderCustom*: Custom provider. It is necessary to specify all the details of the connection. <br><br>- *aiProviderXAI*: xAI (Grok)<br><br><br> |
