
## ExecuteUpdateUI (Function)

***In french: ExécuteMiseAJourIHM***

<a name="Utilisation"></a>
<a name="description"></a>
Immediately executes the "Request for refreshing the display" event of the window, page, internal window, internal page, control template or supercontrol.

If the function is called several times during a process, the refresh event will be run several times.

**Note**: This function is used in particular: 

- when refreshing the interface via threads. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) when using MVP (Model - View - Presenter) programming. For more details, see [Model - View - Presenter (MVP) F 9](../Editeurs/1000021496.md).

## Syntax

**`<Parameter 1>: (Type of value expected by the "Request for refreshing the display" event)`**

Nth parameter that will be passed to the "Request for refreshing the display" event of the window or page.

## Remarks


### "Request for refreshing the display" event
<a name="request_for_refreshing_the_display_event_ELTPARAGRAPHE000068"></a>

One of the events associated with the window (or page) is "Request for refreshing the display". This event is used to group together the code for updating the fields of the window (or page): field content, status (visible, grayed, etc.), label to be updated, etc.

This event can receive parameters. Simply declare a procedure in the event. For example: 


```wl
// Request for refreshing the display
PROCEDURE AskForRefresh(RefreshType is Boolean)
```


This event is started upon request by the following functions: 

- [RequestUpdateUI](../WDLang1/1000021378.md): Executes the "Request for refreshing the display" event at the end of the current process (asynchronous execution). 

- **ExecuteUpdateUI** Executes the "Display update request" event immediately. 

- [RequestUpdateUIParent](../WDLang1/1000022961.md): Executes the "Request for refreshing the display" event of the higher level at the end of the current process (asynchronous execution).

- [ExecuteUpdateUIParent](../WDLang1/1000022961.md): Immediately executes the "Request for refreshing the display" event of the higher level.


When these functions are called, you can specify the value of the parameters expected by "Request for refreshing the display". 

Note: The "Display update request" event can also be executed immediately with the [ExecuteProcess](../WDLang1/3013031.md) function, using the following syntax: 


```txt
ExecuteProcess(<Element name>, trtRequestRefresh)
```

### MVP: Presentation attribute
<a name="mvp_presentation_attribute_ELTPARAGRAPHE000107"></a>

The **presenter** attribute is used to associate a class of the presenter layer with a view (window, page or report). This attribute is mainly used in the global declaration of the windows generated by the MVP RAD.

For example: 


```wl
PROCEDURE WIN_Table_MyExampleFile(...
	gclPresenter is PTableMyExampleFile dynamic <presenter>=Null)
```


When this attribute is used, the call to the "Request for refreshing the display" event of the window (or page) will be triggered by:

- any call to [RequestUpdateUI](../WDLang1/1000021378.md) from a class declared as &lt;presenter&gt;, 

- any call from any class associated with the &lt;presenter&gt; class. 




For more details, see [RAD MVP: "presentation" attribute](../Editeurs/1000021508.md).
