
## BitwiseXOR (Function)

***In french: OUExclusifBinaire***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>

<a name="Utilisation"></a>
<a name="description"></a>
Returns the result of a bitwise exclusive OR operation performed between two values.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get the result of the logical exclusive OR operation
ResBitwiseXOR = BitwiseXOR(6, 6)  // Returns 0
ResBitwiseXOR = BitwiseXOR(6, 2)  // Returns 4
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = BitwiseXOR(<Value 1> , <Value 2>)`
---

**`<Result>: (Integer)`**

Result of the logical exclusive OR operation.

**`<Value 1>: (Integer)`**

First value to be evaluated.

**`<Value 2>: (Integer)`**

Second value to be evaluated.

<a name="NOTE0_1"></a>

## Remarks




### Bitwise operation
<a name="bitwise_operation_ELTPARAGRAPHE000061"></a>

**BitwiseXOR** performs the bitwise operation on &lt;Value 1&gt; and &lt;Value 2&gt; based on the following table:


|   |   |   |
| --- | --- | --- |
|   | **0** | **1** |
| **0** | 0 | 1 |
| **1** | 1 | 0 |


<a name="NOTE0_2"></a>




### Bitwise operator
<a name="bitwise_operator_ELTPARAGRAPHE000088"></a>

- **BitwiseXOR** is equivalent to the **||** bitwise operator for 4-byte integers. For more details, see [Bitwise operators](../Motscles/1512009.md).

- **BitwiseXOR** returns a precise result when you pass 4-byte integers. Passing 8-byte integers causes an overflow.

- The **||** operator can be used to perform bitwise operations between 8-byte integers.
