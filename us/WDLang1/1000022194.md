


## Pivot Table control functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


These functions are used to manipulate Pivot Table controls in prefix syntax:



|   |   |
| --- | --- |
| [&lt;Pivot Table&gt;.AxisXY](../WDLang1/1000022178.md) | Allows you to: <br><br>- Set the row and column headers displayed in a Pivot Table control. <br><br>- Get the row and column headers displayed in a Pivot Table control.<br><br><br><br><br> |
| [&lt;Pivot table&gt;.CalculateAll](../WDLang1/1000022180.md) | Calculates or recalculates all the data of a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.CalculateAllAsynchronous](../WDLang1/1410090405.md) | Entirely calculates or recalculates a Pivot Table control, without blocking the application.<br><br> |
| [&lt;Pivot Table&gt;.CalculateUpdate](../WDLang1/1000022179.md) | Updates part of the data in a Pivot Table control from a given date.<br><br> |
| [&lt;Pivot Table&gt;.CalculateUpdateAsynchronous](../WDLang1/1410090404.md) | Updates some of the data found in a Pivot Table control from a given date without blocking the application.<br><br> |
| [&lt;Pivot Table&gt;.Collapse](../WDLang1/1000022184.md) | Collapses all the data in a Pivot Table control according to a row or column header. <br><br> |
| [&lt;Pivot Table&gt;.CollapseAll](../WDLang1/1000022185.md) | Collapses all row and/or column headers in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.Expand](../WDLang1/1000022182.md) | Expands all the data in a Pivot Table control according to a row or column header.<br><br> |
| [&lt;Pivot Table&gt;.ExpandAll](../WDLang1/1000022183.md) | Expands all row and/or column headers in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.Filter](../WDLang1/1000022186.md) | Enables or disables a filter in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.HeaderValue](../WDLang1/1000022192.md) | Returns the value displayed in a Pivot Table control header.<br><br> |
| [&lt;Pivot Table&gt;.InfoXY](../WDLang1/1000022187.md) | Returns the values of the headers at a given position expressed in pixels in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.ListPositionHeader](../WDLang1/1000022188.md) | Returns all values associated with a row or column header in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.Load](../WDLang1/1000022181.md) | Loads the result of a Pivot Table control calculation from a backup file located on disk or in a buffer.<br><br> |
| [&lt;Pivot Table&gt;.Save](../WDLang1/1000022189.md) | Saves the result of the calculation performed in a Pivot Table control (in a file or in memory).<br><br> |
| [&lt;Pivot Table&gt;.Select](../WDLang1/1000022190.md) | Gets the position of selected cells and selects cells in a Pivot Table control. <br><br> |
| [&lt;Pivot Table&gt;.SelectCount](../WDLang1/1000022191.md) | Returns the number of selected cells in a Pivot Table control.<br><br> |
| [&lt;Pivot Table&gt;.ToExcel](../WDLang1/1000022193.md) | Creates an Excel file with data from a Pivot Table control.<br><br> |
