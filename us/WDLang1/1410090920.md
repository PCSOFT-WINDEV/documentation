
## MenuAddOptionBrowser (Function)

***In french: MenuAjouteOptionNavigateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a new option after the last option of a drop-down or context menu. This menu option executes a WLanguage procedure written in browser code. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add a new menu
MenuAddMenu(_Menu, "MNU_Dates", "Date")
// Add a menu option that executes browser code
MenuAddOptionBrowser("MNU_Dates", "OPT_TODAY", "Today", DisplayToday)
```



<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`(<Option>, <Position>) = MenuAddOptionBrowser(<Source menu> , <Option to create> , <Caption> , <WLanguage browser procedure> [, <Procedure parameter>])`
---

**`<Option>: (Character string)`**

Option added to parent menu. If the option is not added, a fatal error occurs.

**`<Position>: (Character string)`**

Position of the option in the parent menu. If the option is not added, a fatal error occurs.

**`<Source menu>: (Character string)`**

Name of the menu to which the menu option should be added. The option will be added after the last option in this menu.
Note: This name may correspond to a context menu.

**`<Option to create>: (Character string)`**

Name of the menu option to add. This name will be used to programmatically handle the menu option.
If there is an option with the same name, a fatal error occurs.

**`<Caption>: (Character string)`**

Text of the new menu option. This text will be displayed in the window and will allow users to select the option.

**`<WLanguage browser procedure>: (Procedure name)`**

Name of the WLanguage browser procedure executed when the menu option is selected.

**`<Procedure parameter>: (Optional variant)`**

Parameter that can be passed to &lt;WLangage browser procedure&gt; when the menu option is selected by the user.
