
## Constants for managing projects
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manage projects:

| Constant | Description | Used by the functions |
| --- | --- | --- |
| **enumAll** | Enumerates all project elements. | [EnumElement](../WDLang1/3064001.md) |
| **enumContextMenu** | Enumerates the context menus found in a window. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumDynamicPage** | Enumerates all dynamic pages of project. | [EnumElement](../WDLang1/3064001.md) |
| **enumExternalComponent** | Enumerates the public elements of an external component included in the project. | [EnumElement](../WDLang1/3064001.md) |
| **enumFirst** | Starts the enumeration. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumGPU** | Constant intended for the User Groupware. | [EnumElement](../WDLang1/3064001.md) |
| **enumGroup** | Enumerates all window groups. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumInternalPage** | Enumerates all internal pages of project. | [EnumElement](../WDLang1/3064001.md) |
| **enumInternalWindow** | Enumerates all internal windows of project. | [EnumElement](../WDLang1/3064001.md) |
| **enumMainMenu** | Enumerates the drop-down menus found in a window. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumPage** | Enumerates all project pages. | [EnumElement](../WDLang1/3064001.md) |
| **enumPageTemplate** | Enumerates the page templates of project. | [EnumElement](../WDLang1/3064001.md) |
| **enumPane** | Enumerates the tab panes. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumQuery** | Enumerates all project queries. | [EnumElement](../WDLang1/3064001.md) |
| **enumReport** | Enumerates all project reports. | [EnumElement](../WDLang1/3064001.md) |
| **enumReportTemplate** | Enumerates the reports templates of project. | [EnumElement](../WDLang1/3064001.md) |
| **enumSideBar** | Enumerates the panes found in a sidebar. | [EnumSubElement](../WDLang1/3064002.md) |
| **enumWindow** | Enumerates all project windows. | [EnumElement](../WDLang1/3064001.md) |
| **enumWindowTemplate** | Enumerates the window templates of project. | [EnumElement](../WDLang1/3064001.md) |
| **piAnalysis** | Type of information to be returned: Physical name without extension of the .WDD file used by the project or Component. | [ProjectInfo](../WDLang1/3064004.md) |
| **piApplicationCCDataPath** | Type of information to be returned: path to the Control Center data directory defined when the executable, library or Component was created.<br>If this constants is used in a component, gives the path of the data directory for the application that uses it. | [ProjectInfo](../WDLang1/3064004.md) |
| **piApplicationEmail** | Type of information to be returned: Email defined when the executable, library or Component is created. | [ProjectInfo](../WDLang1/3064004.md) |
| **piApplicationInternetAddress** | Type of information to be returned: Internet address defined when creating the executable, library or component. | [ProjectInfo](../WDLang1/3064004.md) |
| **piCCDataPath** | Type of information to be returned: path to the Control Center data directory defined when the executable, library or Component was created.<br>If this constant is used in the project, gives the path of data directory corresponding to the project. If this constant is used in a component, gives the path of data directory corresponding to the component. | [ProjectInfo](../WDLang1/3064004.md) |
| **piCompany** | Type of information to be returned: Company name specified when creating the executable. | [ProjectInfo](../WDLang1/3064004.md) |
| **piConfiguration** | Type of information to be returned: Name of the project configuration used to generate the executable or component currently running. | [ProjectInfo](../WDLang1/3064004.md) |
| **piCopyright** | Type of information to be returned: Copyright defined when the executable is created. | [ProjectInfo](../WDLang1/3064004.md) |
| **piDescription** | Type of information to be returned: Description of the company defined when the executable was created. | [ProjectInfo](../WDLang1/3064004.md) |
| **piEmail** | Type of information to be returned: Email defined when the executable, library or Component is created. | [ProjectInfo](../WDLang1/3064004.md) |
| **piEXEName** | Type of information to be returned: Executable name specified when creating the executable. | [ProjectInfo](../WDLang1/3064004.md) |
| **piGenerationDate** | Type of information to be returned: Application or Component library (WDL) generation date. | [ProjectInfo](../WDLang1/3064004.md) |
| **piInternetAddress** | Type of information to be returned: Internet address defined when creating the executable, library or component. | [ProjectInfo](../WDLang1/3064004.md) |
| **piNameCurrentProject** | Type of information to be returned: Name of the project in which the ProjectInfo function is called.<br>If this constant is used in the code of the main project, the result is the name of the main project.<br>If this constant is used in a component, the result is the name of the component project. | [ProjectInfo](../WDLang1/3064004.md) |
| **piNameDeployedSite** | Type of information to be returned: Real name of deployed site (in the case of a WEBDEV site in a multi-site deployment). | [ProjectInfo](../WDLang1/3064004.md) |
| **piNewFeaturesHelpContext** | Type of information to be returned: Context number of the page to be displayed in the new features help file. | [ProjectInfo](../WDLang1/3064004.md) |
| **piNewFeaturesHelpName** | Type of information to be returned: Name of new features help file. | [ProjectInfo](../WDLang1/3064004.md) |
| **piProjectName** | Type of information to be returned: Project name. | [ProjectInfo](../WDLang1/3064004.md) |
| **piRegistry** | Type of information to be returned: path in the registry where project-specific information can be saved. | [ProjectInfo](../WDLang1/3064004.md) |
| **piVersion** | Type of information to be returned: Version number of the application's main library (WDL file). In the case of web services (SOAP or REST), the result is an empty string (""). | [ProjectInfo](../WDLang1/3064004.md) |
