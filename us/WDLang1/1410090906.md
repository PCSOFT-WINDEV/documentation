


## &lt;Segmented Button&gt;.DeleteAll (Function)

***In french: &lt;Bouton segmenté&gt;.SupprimeTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes all the options from a Segmented Button control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SB_Responses.DeleteAll()
FOR I = 1 TO nbResponse
	SB_Responses.Add("Response" + I)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Segmented Button control>.DeleteAll()`
---

**`<Segmented Button control>: (Control name)`**

Name of the Segmented Button control used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Deleting an option does not change the size of the Segmented Button control. The control size can be changed using the [Width](../Proprietes/2510059.md) and [Height](../Proprietes/2510050.md) properties.
