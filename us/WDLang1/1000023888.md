


## &lt;Window&gt;.Restore (Function)

***In french: &lt;Fenêtre&gt;.Restaure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a WINDEV window to its initial size.

**Note** The function **&lt;Window&gt;.Restore** function performs the same action as the restore button in the top right-hand corner of windows.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the "WIN_EditCustomer" window in its initial size
WIN_CustomerInput.Restore()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Window>.Restore()`
---

**`<Window>: (Window name)`**

Name of the window that must be displayed in its initial size.
