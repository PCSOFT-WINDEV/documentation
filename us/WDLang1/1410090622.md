


## &lt;Control&gt;.Rectangle (Function)

***In french: &lt;Champ&gt;.Rectangle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the coordinates of the rectangle corresponding to the specified area of a control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
RectangleArea is Rectangle
RectangleArea = EDT_NoName1.Rectangle(rectEditButtonRight)
Trace(RectangleArea.X, RectangleArea.Y, RectangleArea.Width, RectangleArea.Height)
// Opens the popup under the button on the right of <EDT_NoName1>
WIN_pop.OpenPopup(WIN_Edit.X + EDT_NoName1.X + RectangleArea.X, ...
	WIN_Edit.Y + WIN_Edit.TitleHeight + EDT_NoName1.Y + RectangleArea.Y + RectangleArea.Height)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Control used>.Rectangle(<Control area> [, <Origin>])`
---

**`<Result>: (Rectangle variable)`**

Variable of type [Rectangle](../Motscles/1514079.md) corresponding to the specified area of the control.

**`<Control used>: (Control name)`**

Name of the control used.

**`<Control area>: (Integer constant)`**

Desired area: 


|   |   |
| --- | --- |
| *rectEditButtonLeft* | Rectangle corresponding to the button on the left of the input area of an Edit control. |
| *rectEditButtonRight* | Rectangle corresponding to the button on the right of the input area of an Edit control. |
| *rectExternal* | Rectangle corresponding to the external borders of the control. |
| *rectHorizontalScrollbar* | Rectangle corresponding to the area occupied by the horizontal scrollbar of the control. |
| *rectInternal* | Rectangle corresponding to the internal borders of the control. |
| *rectVerticalScrollbar* | Rectangle corresponding to the area occupied by the vertical scrollbar of the control. |



**`<Origin>: (Optional Integer constant)`**

Origin used to calculate the coordinates of the rectangle: 


|   |   |
| --- | --- |
| *crControl*<br>(Default value) | The origin of the rectangle is the upper-left corner of the control.  |
| *crScreen* | The origin of the rectangle is the upper-left corner of the screen.  |
| *crWindow* | The origin of the rectangle is the upper-left corner of the window that contains the control.  |
