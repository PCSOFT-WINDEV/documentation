
## ScrollbarPosition (Function)

***In french: AscenseurPosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to manage the position of scrollbars: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Gets or sets the position of one of the scrollbars of a control or window in a WINDEV or WINDEV Mobile application. 

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Gets the position of one of the horizontal or vertical scrollbars in a page of a WEBDEV website.

## Syntax

### Finding out the scrollbar position

`<Result> = ScrollbarPosition(<Element used> [, <Angle>])`
---

**`<Result>: (Int)`**



- Position of scrollbar box. 

- 0 if the scrollbar does not exist or if it is grayed.  




**`<Element used>: (Control, window or page name)`**



- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Name of the control used. 
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function is not available for the Image control.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Name of the window used.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Name of page used.




**`<Angle>: (Optional Integer constant)`**

Orientation of scrollbar for which the position must be retrieved: 


|   |   |
| --- | --- |
| *sbHorz* | The position is calculated for the horizontal scrollbar of control. |
| *sbVert*<br>(Default value) | The position is calculated for the vertical scrollbar of control. |




<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
### Modifying the scrollbar position

`<Result> = ScrollbarPosition(<Control used> , <Angle> , <New position>)`
---

**`<Result>: (Int)`**

New position of scrollbar box.  

**`<Control used>: (Control name)`**

Name of the control used.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function is not available for the Image control.

**`<Angle>: (Optional Integer constant)`**

Orientation of the scrollbar for which the position must be modified: 


|   |   |
| --- | --- |
| *sbHorz* | The position is modified for the horizontal scrollbar of the control. |
| *sbVert* | The position is modified for the vertical scrollbar of the control. |



**`<New position>: (Optional integer)`**

New position of the scrollbar. The scrollbar position starts from 1. 

A correct position is forced if the specified value is not included within the bounds specified for the control scrollbar. 

If the scrollbar does not exist or is grayed out, the new position is not taken into account: the function does nothing.
