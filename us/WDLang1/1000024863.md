


## &lt;Toast&gt;.Display (Function)

***In french: &lt;Toast&gt;.Affiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a "Toast" message.

Toasts are a short messages that appear on the screen for a few seconds before fading out without any user intervention. Toasts are modeless, don't take focus and don't interrupt the execution of the application.

Toasts are recommended to show information to the user without blocking the execution of the application (e.g. short message to indicate that a download has been completed).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ToastAffiche.gif)
![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available for Linux WEBDEV websites only.





<a name="Exemple1"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) 
```wl
MyToast is Toast
MyToast.Title = "Did you know?"
MyToast.Text = "AAFs are really cool."
MyToast.Button[1].Caption = "Learn more..."
MyToast.Button[1].ActionClick = FuncHelp
MyToast.ActionClose = clickClose
MyToast.Display()
INTERNAL PROCEDURE FuncHelp
	Open ("WIN_Help")
END
INTERNAL PROCEDURE clickClose(nButton)
	Trace("Click to close. Button: " + nButton)
END
```

<a name="SYNTAXE2"></a>

`<Toast>.ToastDisplay()`
---

**`<Toast>: (Toast variable)`**

Name of the [Toast](../WDLang1/1000024638.md) variable that defines the toast to be displayed.

## Remarks


### Managing threads
<a name="managing_threads_ELTPARAGRAPHE000210"></a>

**&lt;Toast&gt;.Display** can be called from a WLanguage thread (to notify the user of events that occurred during the thread execution for example).


### Successive calls
<a name="successive_calls_ELTPARAGRAPHE000222"></a>

If **&lt;Toast&gt;.Display** is called several times, each toast is displayed once the previous toast has disappeared. This behavior can be changed using the **Overlayable** property of the [Toast](../WDLang1/1000024638.md) variable. This property allows you to get the same behavior as in version 24, in which toasts could be displayed one over another.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If **&lt;Toast&gt;.Display** is called several times, only the last call to the function will be taken into account.
