
## BitcoinCoreDiskSpaceUsed (Function)

***In french: BitcoinCoreEspaceDisqueUtilisé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates the blockchain size on disk.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Get disk space used by the blockchain
n is int
n = BitcoinCoreDiskSpaceUsed()
IF ErrorOccurred THEN
	Error()
	RETURN
END
Trace("Disk space used by the blockchain: " + n
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = BitcoinCoreDiskSpaceUsed()`
---

**`<Result>: (Integer)`**

Blockchain size on disk (in bytes).
