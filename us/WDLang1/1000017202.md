


## MultimediaPlay (Function)

***In french: MultimédiaJoue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Plays a media file in a Multimedia control.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Note** Depending on the type of video and browser configuration, this function may not be supported. In this case, its use will have no effect but no error will be triggered.

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MyFile is string = "C:\My music\mysong.mp3"
IF MultimediaPlay(MM_Multimedia1, MyFile) = False THEN
	Error("Error while playing the file")
END
```

## Syntax

`<Result> = MultimediaPlay(<Multimedia control> [, <File to play> [, <Options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the file was successfully played, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Note: The [ErrorInfo](../WDLang1/3013008.md) function is not available.

**`<Multimedia control>: (Control name)`**

Name of Multimedia control used to play the media file.

**`<File to play>: (Optional character string)`**

Name and path of the media file to play. 

If this parameter is specified, the media file is loaded in memory and played. The media file is always played from the beginning. 

If this parameter is not specified or is an empty string (""), the file associated with the control (by [MultimediaOpen](../WDLang1/1000017206.md) for example) is automatically used.
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) This parameter is not available. The file associated with the control is automatically used. ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Corresponds to: 

- the name and path of media file to play. 

- a URL (to play the video in streaming). 

- a resource name (file name + extension) added to the application via the generation wizard. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Corresponds to: 

- the name and path of media file to play. 

- a video URL on a server. Note: YouTube videos cannot be played. 

- a resource name (file name + extension) added to the application via the generation wizard. 




**`<Options>: (Integer constant)`**

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Option for reading the file: 


|   |   |
| --- | --- |
| *MultimediaNonBlocking* | The loading of the media file is a non-locking operation. |

## Remarks


### Using the MultimediaPlay function
<a name="using_the_multimediaplay_function_ELTPARAGRAPHE000140"></a>

**MultimediaPlay** can be used:

- to load a media file in memory and to play this file.

- to play a media file loaded by [MultimediaOpen](../WDLang1/1000017206.md).

- to restart a file paused by [MultimediaPause](../WDLang1/1000017207.md).
	Note: To pause the playback of a media file, the media file must have been started via the [MultimediaOpen](../WDLang1/1000017206.md) function followed by the MultimediaPlay function, specifying only the field name.. 






![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Several Multimedia controls can be created in the same window. However, multiple videos cannot be played simultaneously with **MultimediaPlay**.  
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Android specific features
<a name="android_specific_features_ELTPARAGRAPHE000179"></a>

- By default, **MultimediaPlay** is a blocking function until the control is ready to play the file. 

- The *MultimediaNonBlocking* constant is used to perform a non-locking load operation. In this case, the call to a Multimedia function ([MultimediaPosition](../WDLang1/1000017210.md), ...) will fail as long as the media file is not loaded by the control. 

- The non-locking load operations are recommended when using media files not found on the device (online video for example). 

- If &lt;File to play&gt; is the URL of a video on a "https" web server, the "android.permission.INTERNET" permission must be added in the [application generation](../Editeurs/9000109.md) wizard.

- In Android, all the formats supported by the OS can be played (wav, mp3, 3gp, ogg, ...). A summary of the supported audio and video files is available from the following address: [http://developer.android.com/guide/appendix/media-formats.html](http://developer.android.com/guide/appendix/media-formats.html). Note: 32-bit wav files are not supported by Android..
