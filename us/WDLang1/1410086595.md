
## CameraDisplay (Function)

***In french: CaméraAffiche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays the video being captured by a web camera or by the camera of a mobile device in a "Camera" control.

ELTSPECIAL000015 ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)
	<B><B><B>Warning</B></B></B>

	 **Starting with version 27, this function is deprecated for Android and iOS applications**. This function is kept only for Camera controls created with earlier versions and with the "Version-26-compatible mode" option enabled ("General" tab of the control description window).

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays the video captured by the "CAM_Camera" control
ResFilm = CameraDisplay(CAM_Camera)
IF ResFilm = True THEN
	// Displays a caption
	CAM_Camera.Caption = "Now in the kitchen"
ELSE
	Error(ErrorInfo())
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = CameraDisplay(<Camera control>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the video captured is displayed in the Camera control,

- <u><u><u><u>False</u></u></u></u> if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Camera control>: (Control name)`**

Name of the Camera control to be used.

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000050"></a>

- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) To use this function, a "camera" must be connected to the current computer.

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This function requires a device equipped with a camera. It can also be used in the Android emulator.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function requires a device equipped with a camera.




**Note**: This function is equivalent to [VideoDisplay](../WDLang1/3079004.md). 




<a name="NOTE0_2"></a>




### Special cases
<a name="special_cases_ELTPARAGRAPHE000072"></a>

- At runtime, the video captured by the camera is automatically shown as soon as the window containing the Camera control is opened. In this case, the call to **CameraDisplay** is not required.

- To stop recording the video, use [CameraStop](../WDLang1/1410086596.md).





![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 

### Required permissions
<a name="required_permissions_ELTPARAGRAPHE000086"></a>

This function changes the permissions required by the application.

Permission required: CAMERA.

This permission allows the applications to access the camera.
