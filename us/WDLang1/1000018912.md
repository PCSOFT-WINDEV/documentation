


## GetColor (Function)

***In french: DonneCouleur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Allows you to get a set of harmonious colors without having to use a table of colors.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Fill in the data of the Chart control
FOR I = 1 TO 12
	// Adds the turnover of month number I
	grAddData(CHART_MyChart, I, arrValues[I])
	
	// Assigns a color to the series of month number I
	grSeriesColor(CHART_MyChart, I, GetColor())	
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = GetColor([<Subscript> [, <Serial>]])`
---

**`<Result>: (Integer)`**

Color in RGB format.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) &lt;Result&gt; corresponds to a [Color](../WDLang1/1000019661.md) variable. 

**`<Subscript>: (Optional integer)`**

Number of the color to retrieve. 
If this parameter is not specified, the color returned is a color that has never been used. 
If this parameter is specified, the same color will always be returned for a given subscript.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This parameter is not available. 

**`<Serial>: (Optional Integer constant)`**

Constant indicating the style of color set to retrieve: 


|   |   |
| --- | --- |
| *colSetDark* | The returned color is chosen among a set of darker colors (suitable for the TreeMap control for example). |
| *colSetDefault*<br>(Default value) | The returned color is chosen among a set of standard colors. |
| *colSetPalette* | The returned color is chosen among the set of colors defined for the current palette. <br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *colSetPastel* | The returned color is chosen among a set of lighter colors. |
| *colSetTemplate* | The returned color is chosen among the set of colors defined for the current skin template. <br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
