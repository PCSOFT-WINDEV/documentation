
## DDEString (Function)

***In french: DDEChaîne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the information retrieved by [DDERetrieve](../WDLang1/3028017.md).

**Reminder** The [DDERetrieve](../WDLang1/3028017.md) function is used to retrieve a data item. This data is stored in **DDEString**.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003028002&name=ddestring_function">See additional examples</a>

```wl
// Runs a server action
DDEExecute(ConnectionNum, "EXE1")
IF DDERetrieve(ConnectionNum, "Item1") THEN
	Info("The retrieved data is" + DDEString())
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = DDEString([<Connection ID>])`
---

**`<Result>: (Character string)`**

Retrieved information.

**`<Connection ID>: (Optional integer)`**

Connection identifier, returned by [DDEConnect](../WDLang1/3028015.md). If this parameter is not specified, **DDEString** uses the last connection handled.
