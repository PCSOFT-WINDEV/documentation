
## Spain.CheckTaxNumber (Function)

***In french: Espagne.VérifieNuméroFiscal***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the validity of a Spanish tax number.

Note: The tax number corresponds to the NIF. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Check a variable 
MyTaxNumber is string = "B82661935"
Spain.CheckTaxNumber(MyTaxNumber) // Returns True

// Check a control 
EDT_TaxNumber = "ABC"
Spain.CheckTaxNumber(EDT_TaxNumber) // Returns False
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = Spain.CheckTaxNumber(<Number to check>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified element contains a valid tax number.

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Number to check>: (Control name or string variable)`**

Tax number to check. This parameter can correspond to:

- the name of a string variable.

- the name of a control.
