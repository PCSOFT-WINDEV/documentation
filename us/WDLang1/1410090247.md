


## CodeEditorComment (Function)

***In french: EditeurCodeCommente***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Comments the current selection in the Code Editor control. "//" characters are inserted at the beginning of the current line. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Comments the code selected in the Code Editor control
CodeEditorComment(CODEEDT_Example)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`CodeEditorComment(<Code Editor control>)`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
