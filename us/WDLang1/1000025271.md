
## InfoWithTimeoutAsynchronous (Function)

***In french: InfoAvecDélaiAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a custom message in a non-blocking system information window for a given amount of time. After the timeout, the system window is automatically closed.

Remarks: 

- **This is a non-blocking error window**. The WLanguage code that follows the call to **** continues to run. To close the window, the user must validate the OK button or wait for the end of the timeout. When the user clicks "OK", the code of a WLanguage procedure can be run.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) To use this function, you must integrate a custom dialog box into your project. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

- In the WLanguage code following the call to the function, another modal window cannot be opened before closing the dialog box. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV allows you to apply the skin template of your project to this dialog box. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Displays an information window that automatically closes after 10 seconds
InfoWithTimeoutAsynchronous(1000, "Action successful!", MyProcedure_Info)

	INTERNAL PROCEDURE MyProcedure_Info()
		ToastDisplay("Close info")
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`InfoWithTimeoutAsynchronous(<Timeout> , <Text> [, <WLanguage procedure>])`
---

**`<Timeout>: (Integer or Duration)`**

Amount of time (expressed in hundredths of a second) before automatically closing the system information window. The minimum timeout is 1 second. This parameter can correspond to: 

- an integer corresponding to the number of hundredths of a second,

- a Duration variable,

- the duration in a readable format (e.g., 1 s or 1000 ms).




**`<Text>: (Character string)`**

Text to display.

**`<WLanguage procedure>: (Optional name of procedure or lambda procedure)`**

Name of the WLanguage procedure ("callback") called when the user clicks "OK" in the information window. 

This WLanguage procedure can correspond to: 

- a name of a global procedure,

- a name of an internal procedure,

- a lambda procedure. 


If this parameter is not specified, no procedure is run when the user clicks "OK" in the information window.

## Remarks




### Features of the dialog box
<a name="features_the_dialog_box_ELTPARAGRAPHE000073"></a>



- The title of the dialog box corresponds to the title of the current window (or page).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To comply with the system specifications, the title of dialog box is empty by default. To define this title, use [NextTitle](../WDLang1/3038043.md).

- To modify or define the title of dialog box, use [NextTitle](../WDLang1/3038043.md).




- The message is aligned to the left.

- The button caption depends on the runtime language of Windows.

- The maximum number of characters cannot exceed 4096. If a larger string is passed as parameter, it will be truncated.

- The icon displayed (information tooltip) cannot be modified.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To customize this dialog box** (and all the system dialog boxes in your application), check "Customize system windows (Info, YesNo, Confirm, Dialog)" in the "Style" tab of the project description. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

### Line break in the dialog box
<a name="line_break_the_dialog_box_ELTPARAGRAPHE000099"></a>The CR string (Carriage Return) can be used to force a break to the next line. For example:


```wl
InfoWithTimeoutAsynchronous(500, "The form XXX was modified." + CR + "This form will be saved.")
```


You also have the ability to use the syntax of multiline strings. For example: 

```wl
InfoWithTimeoutAsynchronous(
[
The XXX form has been modified. 

This form will be saved.
])
```

<a name="NOTE0_3"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000112"></a>

- Timers ([TimerSys](../WDLang1/3015006.md)) are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Windows events are not stopped when this function is called.

- The caption of the button is displayed in the language used by Windows on the current computer.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This function must not be used: 

	- in the "Resize" event of the window. Otherwise, the application will be locked.

	- in the "Change the orientation" event of the window. 

	- in the "Move to the foreground" event associated with the project. 
			 Note: However, the function can be used in the "Move to the foreground" event of a window. 

	- in a thread.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000303"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**InfoWithTimeoutAsynchronous** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
