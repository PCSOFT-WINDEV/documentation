
## WLanguageCodeFormatting (Variable type)

***In french: CodeWLangageMiseEnForme***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **WLanguageCodeFormatting** type is used to define all the WLanguage code formatting options. These options can be defined and changed using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// String to format
sCode is ANSI string = "
CodeFormatting is WLanguageCodeFormatting
CodeFormatting.Language = languageEnglish
CodeFormatting.Indentation = True
CodeFormatting.IncludeCSSDeclarations = True
CodeFormatting.IgnoreCompilationError = True
CodeFormatting.KeywordCase = WLanguageCodeKeywordLowercase
CodeFormatting.Theme = WLanguageCodeThemeDark
CodeFormatting.Format = WLanguageCodeFormatHTML
bufHTMLRes is Buffer = CodeFormatting.Format(sCode)
"
CodeFormatting is WLanguageCodeFormatting
CodeFormatting.Language = languageEnglish
CodeFormatting.Indentation = True
CodeFormatting.IncludeCSSDeclarations = True
CodeFormatting.IgnoreCompilationError = True
CodeFormatting.KeywordCase = WLanguageCodeKeywordLowercase
CodeFormatting.Theme = WLanguageCodeThemeDark
CodeFormatting.Format = WLanguageCodeFormatHTML
bufHTMLRes is Buffer = WLanguageCodeFormatting(CodeFormatting, sCode)

// Display content in an HTML Display control
HTM_NoName1 = UTF8ToString(bufHTMLRes)
```

## Properties


### Properties specific to WLanguageCodeFormatting variables
<a name="properties_specific_wlanguagecodeformatting_variables_ELTPARAGRAPHE000026"></a>

The following properties can be used to handle the WLanguage code formatting options:

| Property name | Type used | Effect |
| --- | --- | --- |
| KeywordCase | Integer constant | Uppercase or lowercase characters to be used for keywords: <br><br>- *codeWLanguageKeywordsShift*: Keywords are capitalized. <br><br>- *codeWLanguageKeywordsLowercase*: Keywords are lowercase. <br><br><br> |
| Compilation | [WLanguageCodeCompiling](../WDLang1/1410090373.md) variable | Compilation options (allowed functions, forbidden functions, etc.). |
| Format | Integer constant | Code format:<br><br>- *codeWLanguageFormatTexte* (Default value): Plain text. <br><br>- *codeWLanguageFormatHTML* Text in HTML format. <br><br><br> |
| IgnoreCompilationError | Boolean | <br><br>- <u><u><u>True</u></u></u> to ignore compilation errors. Formatting and syntax highlighting will be less accurate.<br><br>- <u><u><u>False</u></u></u> (default value) otherwise.<br><br><br> |
| IncludeCSSDeclarations | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to include the CSS declarations required for formatting and highlighting in the formatted code. This property is taken into account only if the **Format** property is set to *WLanguageCodeFormatHTML*. <br><br>- <u><u><u>False</u></u></u> not to include CSS declarations. In this case, you can get them using [WLanguageCodeGetCSSDeclarations](../WDLang1/1410090145.md).<br><br><br> |
| Indentation | Boolean | <br><br>- <u><u><u>True</u></u></u> to enable indentation,<br><br>- <u><u><u>False</u></u></u> (default) to disable indentation. <br><br><br> |
| Language | Integer constant | Language of code to be generated: <br><br>- 0 (default): no translation, code remains in the language used. <br><br>- *langueFrançais*: the code is translated into French. <br><br>- *languageEnglish*: the code is translated into English. <br><br><br>Note: Only keywords, variable types, functions and properties are translated. |
| Theme | Integer constant | Theme used for syntax highlighting: <br><br>- *codeWLanguageClear theme*: Use of the clear theme. <br><br>- *codeWLanguageGray theme*: Use of the gray theme. <br><br>- *codeWLanguageDarkTheme*: Using the dark theme. <br><br><br> |
