


## &lt;Image variable&gt;.Clear (Function)

***In french: &lt;Variable Image&gt;.Efface***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Clears the content of a variable of type [Image](../WDLang1/1000019650.md) and fills it with the specified color.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
MyDrawing is Image
MyDrawing.StartDrawing()
// Draw a rectangle with a light yellow background and a light blue border
MyDrawing.DrawRectangle(10, 10, 50, 50, LightYellow, LightBlue)
// Clear the drawing and apply blue
MyDrawing.Clear(LightBlue)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX2"></a>

`<Image>.Clear([<Color>])`
---

**`<Image>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable to be used.

**`<Color>: (Optional constant or Color variable)`**

Color used to fill the cleared element. This color can correspond to: 

- one of the WLanguage color constants,

- a variable of type [Color](../WDLang1/1000019661.md). 

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- a preset color (see [the preset colors of WLanguage](../WDLang5/3010002.md)).


If this parameter is not specified, the image will be reset to its initial state: 

- transparent for a variable of type [Image](../WDLang1/1000019650.md),

- background color of the window for an Image control.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Opacity
<a name="opacity_ELTPARAGRAPHE000230"></a>

- If the drawing mode has been enabled in the control without an opacity value ([&lt;Image variable&gt;.StartDrawing](../WDLang1/1000024349.md) without the *dWithOpacity* constant): 

	- ![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png) In Windows, when **&lt;Image variable&gt;.Clear** is used with a color, it will not take the opacity into account. 

	- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) In Linux, only colors with maximum opacity can be used.




- If the drawing mode has been enabled in the control with an opacity value ([&lt;Image variable&gt;.StartDrawing](../WDLang1/1000024349.md) function with the *dWithOpacity* constant), opacity will be taken into account when **&lt;Image variable&gt;.Clear** is used with a color.
