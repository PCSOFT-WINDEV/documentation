
## DDETopic (Function)

***In french: DDESujet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifies the subject of conversation associated with a DDE connection.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open a DDE connection
ConnectionNum = DDEConnect(ServerName, "MyTopic")

...

// Conversation subject?
Subject = DDETopic(ConnectionNum)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = DDETopic([<Connection ID>])`
---

**`<Result>: (Character string)`**

Subject of conversation.

**`<Connection ID>: (Optional integer)`**

Connection identifier, returned by [DDEConnect](../WDLang1/3028015.md). If this parameter is not specified, **DDETopic** uses the last connection handled.
