


## &lt;Code Editor&gt;.Uncomment (Function)

***In french: &lt;Editeur de code&gt;.Décommente***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Uncomments the current selection in the Code Editor control. "//" characters at the beginning of the current line are removed.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Uncomments the code selected in the Code Editor control
CODEEDT_Example.Uncomment()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Code Editor control>.Uncomment()`
---

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.
