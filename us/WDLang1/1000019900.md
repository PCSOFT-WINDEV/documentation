
## RestartProgram (Function)

***In french: RelanceProgramme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ends the application and restarts it. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Restart the application
RestartProgram()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`RestartProgram([<Code Execution>])`
---

**`<Code Execution>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> to run the code for ending the project. 

- <u><u><u><u>False</u></u></u></u> (default) to avoid running the closing code of the project. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
The application is relaunch with the same conditions as the initial launch, in particular with the same command line and environment variables.
