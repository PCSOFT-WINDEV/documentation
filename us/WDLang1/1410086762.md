
## BitcoinCoreHashRate (Function)

***In french: BitcoinCoreNombreHashParSeconde***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the current hash rate required to create new blocks.

Note: Hash rate is a measure of the total computing power of all participating nodes, expressed in hashes per second.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection configuration
BitcoinCoreConfigure(btcRpcServerAddress, "172.17.1.255")
BitcoinCoreConfigure(btcRpcPortNumber, 8332)
BitcoinCoreConfigure(btcRpcUser, "bitcoin")
BitcoinCoreConfigure(btcRpcPassword, "password")
BitcoinCoreConfigure(btcTimeout, 5) // 5 seconds
// ========================================================================
// Calculates the current network hash rate based on difficulty
// This is the hash rate required to create new blocks
// ========================================================================
rNetworkHashRate is real 
rNetworkHashRate = BitcoinCoreHashRate()
IF ErrorOccurred THEN
	Error("Error retrieving network hash rate", ErrorInfo())
	RETURN
END
Trace("Hash rate: " + NumToString(rNetworkHashRate, "15,2e") + " H/s")

// Conversion to readable units
rHashRateEH is real = rNetworkHashRate / 1e18  // ExaHash/s
Trace("Network hash rate (for new blocks): " + NumToString(rHashRateEH, "3,2f") + " EH/s")
Trace("(based on difficulty)")
// Example value: 682.45 EH/s (October 2024)
```
