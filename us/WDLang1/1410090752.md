


## &lt;Command variable&gt;.ReadErrorOutput (Function)

***In french: &lt;Variable Commande&gt;.LitSortieErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads error output data for the command executed in console mode.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Execute the command 'C:\Path\MyProgram.exe -opt1=val1'

// Define the command
MyCommandToExecute is Command
// Executable to run
MyCommandToExecute = "C:\Path\MyProgram.exe"
// Arguments to pass to the executable
MyCommandToExecute.Arguments = "Argument1"
// Open streams
MyCommandToExecute.Streams = cmdStandardInput + cmdStandardOutput
// Add an argument to the command line
MyCommandToExecute.AddArgument("Argument2")
// Add an option to the command line
MyCommandToExecute.AddOption("opt1", "val1")

// Execute command 
MyCommandToExecute.Execute(False)
// Read from error output (not possible because the stream is not open)
// Error message: 'STDERR' is not open.
stderr is string = MyCommandToExecute.ReadErrorOutput()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Command>.ReadErrorOutput([<Blocking>])`
---

**`<Result>: (Character string)`**

Error output data. 

**Caution**: The output stream must be open in the [Command](../WDLang1/1410090491.md) variable (**Streams** property).

**`<Command>: (Command variable)`**

Name of the [Command](../WDLang1/1410090491.md) variable corresponding to the command executed in console mode.

**`<Blocking>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> (default) to read data only after the command has been executed. 

- <u><u><u><u>False</u></u></u></u> to read data even if the command is still being executed.
