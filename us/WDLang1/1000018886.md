


## OrganizerDisplayPreviousPeriod (Function)

***In french: AgendaAffichePériodePrécédente***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Moves the time area displayed to the previous area (previous weeks for example) in an Organizer control. The Organizer control is displayed from the day corresponding to the previous time area. 

**Remarks**:

- **** and  allow you to simply set up "Next / Previous" Button controls. These controls allow you to scroll through the time areas displayed by the Organizer control. 

- The displayed period can also be modified by [OrganizerChangeMode](../WDLang1/1000019497.md) and [OrganizerPosition](../WDLang1/1000018889.md).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Switch to monthly display
OrganizerChangeMode(ORG_MyOrganizer, orgzMonth)
// Display the current month
OrganizerPosition(ORG_MyOrganizer, DateSys())
// Switch to previous month
OrganizerDisplayPreviousPeriod(ORG_MyOrganizer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`OrganizerDisplayPreviousPeriod(<Organizer control>)`

**`<Organizer control>: (Control name)`**
