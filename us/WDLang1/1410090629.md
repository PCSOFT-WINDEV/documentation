


## &lt;Window&gt;.InHeight (Function)

***In french: &lt;Fenêtre&gt;.IntHaut***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the interior height of a window.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the Windows operating system, the interior height does not include the title bar or the border.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Maximized mobile windows with an Action Bar control and a system bar: 

	- If the Action Bar control overlaps the other controls (style option), its height is ignored. The vertical height of the window starts below the system bar. In this case, **&lt;Window&gt;.InHeight** returns the same result as [&lt;Window&gt;.OutHeight](../WDLang1/1410088867.md). 

	- If the system bar overlaps the other controls (style option), its height is ignored. The interior height of the window starts at the top of the screen. 




- Non-maximized mobile windows and popup windows: This height corresponds to the height of the window without its border.

<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt_Mobile.gif)

## Example


```wl
//Interior height of the "WIN_EditCustomer" window
ResHeight = WIN_EditCustomer.InHeight()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Window>.InHeight()`
---

**`<Result>: (Integer)`**

Interior height of the window (in pixels).

**`<Window>: (Window name)`**

Name or alias of the window to be used. If this parameter is not specified or if it is an empty string (""), the interior height of the current window is returned.
