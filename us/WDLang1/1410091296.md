
## JSON variable functions
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate JSON data. 





|   |   |
| --- | --- |
| [JSONOpenReader](../WDLang1/1410090784.md) | Creates a reader to read a JSON document without loading it into memory.<br><br> |
| [JSONValid](../WDLang1/1410089147.md) | Checks the validity of a JSON string. |





Note: There are also functions for converting other variable types to JSON format.
