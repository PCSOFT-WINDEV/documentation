


## &lt;Menu&gt;.Delete (Function)

***In french: &lt;Menu&gt;.Supprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a menu or a menu option.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) You can delete options from the main menu or from a context menu

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Only the menus, options and separators added through programming (with [&lt;Menu&gt;.AddMenu](../WDLang1/1000020592.md), [&lt;Menu&gt;.AddOption](../WDLang1/1000020593.md) and [&lt;Menu&gt;.AddSeparator](../WDLang1/1000020603.md)) can be deleted.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete the "OPT_Exit" option from the "FileMenu" menu
FileMenu.OPT_Exit.Delete()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Deleting a menu

`<Menu name>.Delete()`
---

**`<Menu name>: (Menu name)`**

Name of the menu to delete.


<a name="SYNTAXE2"></a>

### Deleting a menu option

`<Option name>.Delete()`
---

**`<Option name>: (Menu name)`**

Name of the menu option to delete, in the following format: "&lt;Menu name&gt;.&lt;Option name&gt;".

This option will be permanently deleted from the menu.


<a name="SYNTAXE3"></a>

### Deleting a menu option by its index

`<Menu name>.Delete(<Option rank>)`
---

**`<Menu name>: (Menu name)`**

Name of the menu containing the option to delete. It can be a main menu or a context menu.

**`<Option rank>: (Integer)`**

Rank of the option to delete from the menu (the ranks start from 1).

This option will be permanently deleted from the menu.
