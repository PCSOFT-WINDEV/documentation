
## Upper (Function)

***In french: Majuscule***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts all characters in a string to uppercase according to the region settings defined in Windows.

**Note** The function **Upper** function is retained for compatibility and works only with Latin character sets. To configure the formatting of a string more precisely or to handle other character sets, use [StringFormat](../WDLang1/3024019.md).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Upper("abcd")   // Returns "ABCD"
Upper("élan")  // Returns "ELAN"
Upper("this!")   // Returns "THIS!"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = Upper(<String to convert>)`
---

**`<Result>: (Character string)`**

String in uppercase characters.

**`<String to convert>: (Character string)`**

String to convert to uppercase.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Conversion rules
<a name="conversion_rules_ELTPARAGRAPHE000074"></a>

- Unaccented lowercase characters are converted to unaccented uppercase characters.

- Accented lowercase characters are converted to unaccented uppercase characters. 
	![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Accented lowercase characters are converted to accented uppercase characters.

- Unaccented uppercase characters remain unchanged.

- Accented uppercase characters remain unchanged.




**Note** The function **Upper** function is retained for compatibility and works only with Latin character sets. To configure the formatting of a string more precisely or to handle other character sets, use [StringFormat](../WDLang1/3024019.md).
<a name="NOTE0_2"></a>




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000091"></a>

- "Whitespaces" are kept.

- The HFSQL engine automatically performs case-insensitive searches. Therefore, **Upper** has no effect when performing this type of operation.
