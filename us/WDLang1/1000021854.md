


## End-user UI functions
			



**Note**: These functions are also available in prefix syntax ([End-user UI editing functions (prefix syntax)](../WDLang1/1000022336.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following WLanguage functions allow the end user to manipulate the UI:



|   |   |
| --- | --- |
| [WinEdActive](../WDLang1/1000021843.md) | Allows: <br><br>- determine if the "Allow end users to modify the UI" option is enabled in a window (or internal window).<br><br>- enable or disable the "Allow end users to modify the UI" option in a window (or internal window).<br><br><br> |
| [WinEdCreateNote](../WDLang1/1000022270.md) | Creates a Repositionable Note control. |
| [WinEdDeclareUndo](../WDLang1/1000021898.md) | Declares how to cancel an action that was added by [WinEdDo](../WDLang1/1000021897.md). |
| [WinEdDeselectAll](../WDLang1/1000021873.md) | Deselects all the controls when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdDo](../WDLang1/1000021897.md) | Runs an action (defined programmatically) and enables Undo/Redo operations on this action. |
| [WinEdLoad](../WDLang1/1000021849.md) | Loads the changes made by the end user in a window. |
| [WinEdRedo](../WDLang1/1000021905.md) | Runs the last action undone by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdRestore](../WDLang1/1000021869.md) | Undoes all the changes made by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdSave](../WDLang1/1000021848.md) | Saves the changes made when the "Modification of UI by the end user" mode is enabled. |
| [WinEdSaveNote](../WDLang1/1000022120.md) | Exports the repositionable notes created by the user into a file. |
| [WinEdSelect](../WDLang1/1000021871.md) | Returns one of the controls selected when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdSelectMinus](../WDLang1/1000021874.md) | Deselects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdSelectOccurrence](../WDLang1/1000021870.md) | Indicates the number of controls selected when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdSelectPlus](../WDLang1/1000021872.md) | Selects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled). |
| [WinEdUndo](../WDLang1/1000021904.md) | Undoes the last action performed by the end user when modifying the interface ("Allow end users to modify the UI" option enabled). |
