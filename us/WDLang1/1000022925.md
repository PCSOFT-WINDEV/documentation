


## docRow (Variable type)

***In french: docLigne***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docRow** type is used to define the advanced characteristics of a table row in a Word Processing document. You can define and change the characteristics of this table row using different WLanguage properties. 

**ATTENTION: This type must not be used directly.** It must only be used via variables of type [docParagraph](../WDLang1/1000022483.md) corresponding to an array. 


<a name="PROPS"></a>

## Properties


### Properties specific to docRow variables
<a name="properties_specific_docrow_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to define the characteristics of **docRow** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| CellCount | Integer | Number of row cells. <br><br>This property is read-only. |
| Height | Integer | Height of row (in millimeters). |
| HeightMode | Integer constant | Mode for calculating the row height: <br><br>- *docModeHeightAtLeast*: The height of the line will be at least that defined by the property **Height**. <br><br>- *docModeAutomaticHeight* The height of the line is automatically calculated according to the text present in the cells of the line. <br><br>- *docModeExactHeight* The height of the line will be that defined by the property **Height**. <br><br>- *docHeightModeNotDefined*: Line height calculation mode not defined (default is automatic calculation mode). <br><br><br> |
