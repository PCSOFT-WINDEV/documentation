
## Apply (Function)

***In french: Applique***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Executes a procedure for each element of a WLanguage array.

This function can be used:

- on one-dimensional arrays,

- on associative arrays.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.

## Example


```wl
// Fill a List Box control with the names of customers
arrCustomer is array of Customer
Apply(arrCustomer, ACustomer=>{ListAdd(LIST_Customer, ACustomer.Name)})
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`Apply(<Source array> , <Operation to perform>)`
---

**`<Source array>: (WLanguage array)`**

Name of the Array variable to use. This array can be: 

- a one-dimensional array.

- an associative array.
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.




**`<Operation to perform>: (WLanguage procedure)`**

Name of the WLanguage procedure to be executed for each element of the &lt;Source array&gt;. This procedure can be: 

- a global or local procedure,

- an internal procedure. 


It is also possible to directly use a lambda procedure.

<a name="NOTE0_1"></a>

## Remarks


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000097"></a>

The &lt;Operation to perform&gt; procedure is called for each element of the array. The procedure receives: 

- manipulated element.

- the element key.
	In the case of a simple array, the key corresponds to the element index. This parameter is optional.
	In the case of an associative array, the key is the indexing key. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Not available.




Not all the results of the calls are stored.
