
## &lt;ANSI string&gt;.Format (Function)

***In french: &lt;Chaîne ANSI&gt;.Formate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Formats a character string according to the selected options.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyString1 is string = "Developing is fantastic"
MyString1 = MyString1.Format(ccUpCase)
// MyString1 contains "DEVELOPING IS FANTASTIC"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <String>.Formats(<Options>)`
---

**`<Result>: (Character string)`**

String formatted according to the selected criteria.

**`<String>: (Character string)`**

Character string to format.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) You can use Unicode strings.

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) You cannot use Unicode strings.

**`<Options>: (Constant or combination of constants)`**

Formatting options:               


|   |   |
| --- | --- |
| *ccIgnoreAccent* | Format without accented characters. |
| *ccIgnoreInsideSpace* | The following characters are deleted within the string:<br><br>- space (character 32)<br><br>- tab (character 9)<br><br>- carriage return (character 13) and line feed (character 10)<br><br>- control characters 11 and 12<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *ccIgnorePunctuationAndSpace* | Removes spaces and punctuation characters. |
| *ccIgnoreSpace* | The following characters are deleted at the beginning and at the end of the string:<br><br>- space (character 32)<br><br>- tab (character 9)<br><br>- carriage return (character 13) and line feed (character 10)<br><br>- control characters 11 and 12<br><br><br> |
| *ccLowCase* | Converts the string to lowercase characters. |
| *ccNormal* | No formatting is performed. |
| *ccUpCase* | Converts the string to uppercase characters (including accented characters). |

## Remarks


### &lt;ANSI string&gt;.Format and UNICODE
<a name="docparampagetitleshort_and_unicode_ELTPARAGRAPHE000258"></a>

If the string passed as a parameter is an ANSI string, the result will be an ANSI string.

If the string passed in parameter is in Unicode format, the result will be in Unicode format.

**Note** If the result of the **&lt;ANSI string&gt;.Format** function used on an ANSI string is assigned to a Unicode string (and vice versa), ANSI/Unicode conversion will be implicitly performed.

For more details, see [Unicode management](../WDLang1/3024038.md).
