


## PVTLoad (Function)

***In french: TCDCharge***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads the result of a Pivot Table control calculation from a backup file located on disk or in a buffer. This calculation should have been previously saved using [PVTSave](../WDLang1/1000020471.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sFile is string
// Builds the file name
sFile = SysDir(srAppData) + ["\"] + "StatsByCountry.tcd"

// The file exists?
IF fFileExist(sFile) THEN
	// Yes, load it 
	PVTLoad(PVT_Statistics, sFile)
	IF YesNo("Do you want to recalculate everything?") THEN PVTCalculateAll(PVT_Statistics)
ELSE
	// The file does not exist. It is going to be calculated
	PVTCalculateAll(PVT_Statistics)
END
PVTSave(PVT_Statistics, sFile)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PVTLoad(<Pivot Table control> , <Backup media> [, <Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the content of the Pivot Table control was loaded. 

- <u><u><u><u>False</u></u></u></u> otherwise




**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Backup media>: (Character string or Buffer)`**



- To save to a file: Name and full path of the file to be loaded. This file must have been previously saved with [PVTSave](../WDLang1/1000020471.md).

- To save to memory: Save buffer returned by [PVTSave](../WDLang1/1000020471.md). 




**`<Password>: (Optional string or Secret string)`**

Password associated with the backup file of the Pivot Table control. This password is specified when the Pivot Table control is saved using [PVTSave](../WDLang1/1000020471.md).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).

## Remarks


### Saving and loading the content of a Pivot Table control
<a name="saving_and_loading_the_content_pivot_table_control_ELTPARAGRAPHE000091"></a>

When the Pivot Table control is calculated with [PVTCalculateAll](../WDLang1/1000020539.md), the result can be saved using [PVTSave](../WDLang1/1000020471.md). Then, it can be loaded again using **PVTLoad**. In this case, the content of the Pivot Table control is not recalculated.
