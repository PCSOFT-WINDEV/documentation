


## GanttGetTask (Function)

***In french: GanttRécupèreTâche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets a task using its identifier in a Gantt Chart column in a Table or TreeView Table control.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve a task to modify it
MyTask is GanttTask
MyTask <- GanttGetTask(COL_Gantt, "ID2")
MyTask.Title = "New title"
```


<a name="Exemple2"></a>

```wl
// Retrieve a task
MyTask is GanttTask
MyTask = GanttGetTask(COL_Gantt, "ID1")
InfoBuild("Task retrieved: %1", MyTask.Title)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GanttGetTask(<Gantt column> , <Identifier>)`
---

**`<Result>: (GanttTask variable)`**

Name of the [GanttTask](../WDLang1/1000020881.md) variable from which the task characteristics are retrieved.

**`<Gantt column>: (Control name)`**

Name of the Gantt Chart column (in a Table or TreeView Table control) to be used.

**`<Identifier>: (Character string)`**

Identifier of the task to retrieve. This identifier corresponds to the **ID** property defined in the [GanttTask](../WDLang1/1000020881.md) variable. 

A WLanguage error occurs if the specified identifier does not exist.

## Remarks


### Retrieving a task
<a name="retrieving_task_ELTPARAGRAPHE000068"></a>

To retrieve a task, you can: 

- use the "=" operator. In this case, you can get the characteristics of the retrieved task. 

- use the "&lt;-" operator. **In this case, you can dynamically modify the retrieved task**. 




**Case 1: Use of the "="**operator . 

In this case, you can get the characteristics of the retrieved task. 


```txt
<Variable name> = GanttGetTask(<Gantt column>, <Identifier>)
```

For example:

```wl
// Retrieve a task
MyTask is GanttTask
MyTask = GanttGetTask(COL_Gantt, "ID1")
InfoBuild("Task retrieved: %1", MyTask.Title)
```

You also have the ability to retrieve a task by using the following syntax: 


```txt
<Variable name> = <Gantt column>["<Identifier>"]
```

For example: 


```wl
MyTask is GanttTask
MyTask = COL_Gantt["ID1"]
InfoBuild("Task retrieved: %1", MyTask.Title)
```


**2nd case: Use of the "&lt;-". operator.**

In this case, you can dynamically modify the retrieved task. 


```txt
<Variable name> <- GanttGetTask(<Gantt column>, <Identifier>)
```
where Identifier is the identifier of the task to retrieve. 

For example: 

```wl
// Modify a task
MyTask is GanttTask
MyTask <- GanttGetTask(COL_Gantt, "ID1")
MyTask.Progress = 70
MyTask.ProgressColor = LightGreen
```

You also have the ability to retrieve a task by using the following syntax: 


```txt
<Variable name> <- <Gantt column>["<Identifier>"]
```
For example: 


```wl
t <-COL_Gantt["ID1"]
t.BackgroundColor = LightBlue
```
