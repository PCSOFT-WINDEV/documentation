


## dAlphaBlend (Function)

***In french: dFusionne***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Blends two images together. This allows you to create fade-in effects between 2 images. This function handles: 

- Image controls, 

- [Image](../WDLang1/1000019650.md) variables. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [WDPic](../WDLang1/1000023503.md) variables,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [picLayer](../WDLang1/1000024604.md) variables.






![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Declare the promotion image
MyPromoImage is Image = "PromoImage.png"

// Blend the promotion image in the product image with an opacity set to 80%
dAlphaBlend(IMG_PRODUCT, MyPromoImage, 80)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`dAlphaBlend(<Destination image> , <Source image> [, <Opacity>])`
---

**`<Destination image>: (Image control or Image, WDPic or picLayer variable)`**

Image in which the merge must be performed. This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [WDPic](../WDLang1/1000023503.md). Only the background layer will be handled. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [picLayer](../WDLang1/1000024604.md).


For the blend, this image will be considered as the background image.

**`<Source image>: (Image control or Image, WDPic or picLayer variable)`**

Image to merge. This image can correspond to: 

- the name of an Image control. 

- the name of a variable of type [Image](../WDLang1/1000019650.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [WDPic](../WDLang1/1000023503.md). Only the background layer will be handled. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the name of a variable of type [picLayer](../WDLang1/1000024604.md).




**`<Opacity>: (Optional real)`**

Percentage of opacity that must be applied to &lt;Source image&gt; before performing the blend (100% by default, no opacity is applied). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The size of the destination image corresponds to the reference size.

- **dAlphaBlend** blends the images and keeps the alpha channel of the destination image. Therefore, the alpha channel of the source image is not used.
