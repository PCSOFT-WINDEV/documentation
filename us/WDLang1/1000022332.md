


## &lt;Window&gt;.EdSelectMinus (Function)

***In french: &lt;Fenêtre&gt;.EdSelectMoins***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deselects a control when the interface is modified by the end user ("Allow end users to modify the UI" option enabled).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Deselects the current control
X is Control
X <- WIN_Form.EdSelect() 
WIN_Form.EdSelectMinus(X)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Window>.EdSelectMinus(<Control used>)`
---

**`<Window>: (Window name)`**

Name of the window or internal window to be used. This window must be in edit mode ([&lt;Window&gt;.EdActive](../WDLang1/1000022294.md)).

**`<Control used>: (Optional control)`**

Control to deselect in the window. The selected control is returned by [&lt;Window&gt;.EdSelect](../WDLang1/1000022331.md). 

- If the multiple selection is allowed, the specified control is removed from the selection. 

- The function has no effect if the specified control is not selected. 




If this parameter is not specified: 

- if multiple selection is enabled, all fields in the window are deselected.

- if the multiple selection is not allowed, deselects the selected control.
