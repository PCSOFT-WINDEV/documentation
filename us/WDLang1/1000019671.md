
## dHalo (Function)

***In french: dHalo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a halo effect on an image found in an [Image](../WDLang1/1000019650.md) variable. 

![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) **Caution**: In Linux, this function requires a specific configuration. For more details, see [Drawing in WINDEV, WEBDEV and WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is Image
MyImage = "image.png"

// Adds a 5-pixel wide yellow halo
dHalo(MyImage, LightYellow, 5)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`dHalo(<Image> , <Halo color> [, <Thickness> [, <Clipping>]])`
---

**`<Image>: (Image variable)`**

Name of the [Image](../WDLang1/1000019650.md) variable that corresponds to the image to use. 

**`<Halo color>: (Integer)`**

Color of the halo that must be added to the image. This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Thickness>: (Optional integer)`**

Thickness of the halo in pixels (2 pixels by default). 

**`<Clipping>: (Optional boolean)`**



- <u><u><u><u>True</u></u></u></u> if the halo is to be trimmed, 

- <u><u><u><u>False</u></u></u></u> (default value) otherwise.
