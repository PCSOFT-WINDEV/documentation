
## CameraStartDecoding (Function)

***In french: CaméraDémarreDécodage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts decoding bar codes in a Camera control. You can specify the type of bar code to decode.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Starts decoding QRCode bar codes in the Camera control
CameraStartDecoding(CAM_Camera1, BC_QRCODE)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`CameraStartDecoding(<Camera control> [, <Type of bar code>])`
---

**`<Camera control>: (Control name)`**

Name of the Camera control to be used.

**`<Type of bar code>: (Optional Integer constant)`**

Type of bar codes that can be decoded: 


|   |   |
| --- | --- |
| *BC_AZTEC* | Aztec bar code. <br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_CODE128* | Code128 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_CODE39* | Code39 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_CODE93* | Code93 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_DATAMATRIX* | DATAMATRIX bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Not available. |
| *BC_EAN13* | EAN13 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_EAN8* | EAN8 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_INTER2OF5* | Interleaved 2 of 5 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_PDF417* | PDF417 bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_QRCODE* | QR Code bar code. |
| *BC_UPCA* | UPC-A bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Not available. |
| *BC_UPCE* | UPC-E bar code.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) This type of bar code is available from iOS 7. |
| *BC_ALL* | All the types of bar codes supported by this function can be decoded. |


If this parameter is not specified: 

- the bar codes specified last time **CameraStartDecoding** was called will be decoded. 

- the bar codes specified in the description window of Camera control will be decoded. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The Camera control must have been configured to allow the decoding of bar codes (in the description window). Otherwise, the call to **CameraStartDecoding** will trigger a fatal error.

- When the Camera control is configured to allow the decoding of bar codes (in the description window), the decoding automatically starts when the window is opened. To prevent this behavior, [CameraStopDecoding](../WDLang1/1000022449.md) can be called in the initialization event of the Camera control.

- If **CameraStartDecoding** is called when a decoding process is already in progress in the Camera control, the decoding process is stopped and then restarted to take into account the new type of bar code to decode. If the type of bar code is the same, the function has no effect.

- When a bar code is detected, the "Decode a bar code" event  of the Camera control is called with a [BarCode](../WDLang5/1000019451.md) variable as parameter, which corresponds to the detected bar code. If this event returns <u><u><u><u>True</u></u></u></u>, bar code decoding will be automatically stopped.

- This function is equivalent to [VideoStartDecoding](../WDLang1/1000022163.md).
