


## Gantt functions (prefix syntax)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions can be used to handle a Gantt Chart column in a Table or TreeView Table control, using prefix syntax: 




|   |   |
| --- | --- |
| [&lt;Gantt chart&gt;.AddHoliday](../WDLang1/1000021118.md) | Defines a new holiday period on a row in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.AddLink](../WDLang1/1000021120.md) | Creates an "End to Start" link between two tasks displayed in a Gantt Chart column found in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.AddTask](../WDLang1/1000021121.md) | Adds a task in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt Chart&gt;.ChangeMode](../WDLang1/1000021122.md) | Changes the number of days displayed in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.DeleteAll](../WDLang1/1000021140.md) | Removes all tasks from a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.DeleteLink](../WDLang1/1000021138.md) | Removes links from a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.DeleteTask](../WDLang1/1000021139.md) | Removes a task from a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.GetTask](../WDLang1/1000021137.md) | Gets a task using its identifier in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.ListLink](../WDLang1/1000021128.md) | Lists the links in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.ListTask](../WDLang1/1000021129.md) | Returns: <br><br>- the list of tasks between two given dates in a Gantt Chart column, <br><br>- all the tasks in a Gantt Chart column,<br><br>- a specific task (selected or hovered). <br><br><br> |
| [&lt;Gantt chart&gt;.OrganizeTask](../WDLang1/1000021130.md) | Reorganizes the tasks of a Gantt chart according to the constraints (dependencies and resources). |
| [&lt;Gantt chart&gt;.PositionDateTime](../WDLang1/1000021131.md) | Sets the first day and time displayed in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.TimeDisplayed](../WDLang1/1000021123.md) | Defines the time range displayed in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.WorkingHour](../WDLang1/1000021124.md) | Overwrites the working hours on a row in a Gantt Chart column in a Table or TreeView Table control. |
| [&lt;Gantt chart&gt;.WorkingWeekDay](../WDLang1/1000021125.md) | Indicates if a day of the week is a working day in a Gantt Chart column in a Table or TreeView Table control. |
