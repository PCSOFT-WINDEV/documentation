


## Application and executable management constants
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The constants for managing executables are as follows: 


| Constant | Description | Used by the functions |
| --- | --- | --- |
| **alStartup** | Run the application when the PC is started | [AutoRunAdd](../WDLang1/3019002.md), [AutoRunDelete](../WDLang1/3019001.md) |
| **exeAboveNormalPriority** | Application priority: Priority higher than *exeNormalPriority*and lower than *exePriorityRealTime*. | [ExePriority](../WDLang1/3035010.md) |
| **exeActionRapide** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Application startup mode: the application is launched automatically via a quick action. | [ExeInfo](../WDLang1/3035001.md) |
| **exeActive** | Program launch mode: program launched active | [ExeRun](../WDLang1/3035006.md) |
| **exeBelowNormalPriority** | Application priority: Priority higher than *exeLowPriority* and lower than *exeNormalPriority*. | [ExePriority](../WDLang1/3035010.md) |
| **exeCommandLine** | Command line of executable. | [ExeListProcess](../WDLang1/3035008.md) |
| **exeCompany** | Information to be retrieved: name entered for the company when creating the executable. | [ExeInfo](../WDLang1/3035001.md) |
| **exeCopyright** | Information to be retrieved: program copyright | [ExeInfo](../WDLang1/3035001.md) |
| **exeDeepLink** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Application startup mode: the application is launched automatically via a "deep link". | [ExeInfo](../WDLang1/3035001.md) |
| **exeDescription** | Information to be retrieved: program description | [ExeInfo](../WDLang1/3035001.md) |
| **exeDirectory** | Information to retrieve: Directory of the executable file (without the final backslash "\\" but with the colon ":") | [ExeInfo](../WDLang1/3035001.md) |
| **exeDontWait** | Resume program in progress delay: the program in progress and the launched program run in parallel | [ExeRun](../WDLang1/3035006.md) |
| **exeDownloadComplete** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Application startup mode: the application is launched automatically by the system when a download previously requested by the application is completed (for example, if the application was closed during download). | [ExeInfo](../WDLang1/3035001.md) |
| **exeGeoTracking** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Application startup mode: the application is launched in the background when geolocation tracking is managed.. <br><br>Note: This constant is retained for compatibility from version 230050 onwards. It is identical to the *exeInBackground* constant. | [ExeInfo](../WDLang1/3035001.md) |
| **exeHighPriority** | Application priority: High priority | [ExePriority](../WDLang1/3035010.md) |
| **exeIconize** | Program launch mode: program launched inactive and reduced to an icon | [ExeRun](../WDLang1/3035006.md) |
| **exeInactive** | Program launch mode: program launched inactive | [ExeRun](../WDLang1/3035006.md) |
| **exeInBackground** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Application startup mode: the application is launched in the background when managing geolocation tracking or when a group of beacons is detected.. | [ExeInfo](../WDLang1/3035001.md) |
| **exeLaunch** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) Information to be retrieved: application startup mode. | [ExeInfo](../WDLang1/3035001.md) |
| **exeLongName** | Name and full path of application executable | [ExeListProcess](../WDLang1/3035008.md) |
| **exeLowPriority** | Application priority: Low | [ExePriority](../WDLang1/3035010.md) |
| **exeMaximize** | Program launch mode: program launched active, "taking over" the current program (the execution window has the maximum authorized size) | [ExeRun](../WDLang1/3035006.md) |
| **exeMaxMemory** | Maximum amount of memory consumed by the application | [ExeListProcess](../WDLang1/3035008.md) |
| **exeMemory** | Amount of memory currently consumed by the application | [ExeListProcess](../WDLang1/3035008.md) |
| **exeMode** | Information to be retrieved: executable compilation mode (16-, 32- or 64-bit or DOS) | [ExeInfo](../WDLang1/3035001.md) |
| **exeName** | Information to be retrieved: full executable name | [ExeInfo](../WDLang1/3035001.md) |
| **exeNoHandleInheritance** | Indicates that the executable should not inherit handles from the parent (applies to ALL handles, including files). The executable is independent of the application that launched it.  | [DDEStart](../WDLang1/3028013.md)<br>[ExeRun](../WDLang1/3035006.md) |
| **exeNormalPriority** | Application priority: Priority higher than *exeLowerNormalPriority*and lower than *exeTopNormalPriority*. | [ExePriority](../WDLang1/3035010.md) |
| **exeParentPID** | PID of parent (which means the process that started the current process). | [ExeGetPID](../WDLang1/1000017239.md), [ExeListProcess](../WDLang1/3035008.md) |
| **exePID** | Identifier of application process.<br>This identifier can be used in some APIs for example. | [ExeGetPID](../WDLang1/1000017239.md), [ExeRun](../WDLang1/3035006.md), [ExeListProcess](../WDLang1/3035008.md) |
| **exePushNotification** | Application startup mode: the application is launched automatically by the system on receipt of a push notification. | [ExeInfo](../WDLang1/3035001.md) |
| **exeRealTimePriority** | Application priority: Real-time priority. | [ExePriority](../WDLang1/3035010.md) |
| **exeReturnValue** | The current program resumes its execution when the program run is over. &lt;Result&gt; is the return value of the executable. | [ExeRun](../WDLang1/3035006.md) |
| **exeShortName** | Name and extension of application executable | [ExeListProcess](../WDLang1/3035008.md) |
| **exeStartup** | ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Application start-up mode: the application is launched automatically by the system, when the device is started up. | [ExeInfo](../WDLang1/3035001.md) |
| **exeTID** | Identifier of the current thread. | [ExeGetPID](../WDLang1/1000017239.md) |
| **exeVersion** | Information to be retrieved: program version | [ExeInfo](../WDLang1/3035001.md) |
| **exeVersionWindowsFormat** | Information to be retrieved: program version in standard Windows format. | [ExeInfo](../WDLang1/3035001.md) |
| **exeWait** | Resume current program delay: the current program resumes execution when the launched program is finished. | [ExeRun](../WDLang1/3035006.md) |
| **formApplication** | Type of file to open: Opens the application file. | [AppOpenForm](../WDLang1/1000020980.md) |
| **formInAppPurchase** | Type of card to open: Opens the application's in-App purchases settings window. | [AppOpenForm](../WDLang1/1000020980.md) |
| **shareDocument** | One or more documents (image, video, pdf, ...) are shared. These documents are identified by their full path, passed as parameter. | [StartShare](../WDLang1/1000020620.md) |
| **shareText** | Text is shared. | [StartShare](../WDLang1/1000020620.md) |
