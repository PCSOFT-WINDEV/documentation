


## WinInWidth (Function)

***In french: FenIntLarg***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the interior width of a window. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In the Windows operating system, this width does not include the borders.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt.gif)


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) There are two cases to consider: 

- Maximized mobile windows: This width corresponds to the total width of the window.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FenExtInt_Mobile.gif)
This width is the same as the one returned by [WinOutWidth](../WDLang1/3038029.md). 

- Non-maximized mobile windows and popup windows: This width corresponds to the width of the window without its border. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Interior width of the "WIN_EditCustomer" window
ResInternalWidth = WinInWidth(WIN_EditCustomer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = WinInWidth([<Window used>])`
---

**`<Result>: (Integer)`**

Interior width of the window (in pixels).

**`<Window used>: (Optional window name or optional string)`**

Name or alias of the window to be used. If this parameter is not specified or is an empty string (""), the interior width of the current window is returned.
