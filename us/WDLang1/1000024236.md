## Syntax

### Drawing a rectangle by specifying the coordinates of rectangle

`<Image variable>.DrawRectangle(<X1> , <Y1> , <X2> , <Y2> [, <Background> [, <Line>]])`
---

**`<Image variable>: (Image variable)`**



**`<X1>: (Integer)`**

X-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<Y1>: (Integer)`**

Y-coordinate (in pixels) of the upper-left corner of the rectangle.

**`<X2>: (Integer)`**

X-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Y2>: (Integer)`**

Y-coordinate (in pixels) of the lower-right corner of the rectangle.

**`<Background>: (Integer, constant or Background variable (optional))`**



- Background color of rectangle. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

	- [a WLanguage preset color](../WDLang5/3010002.md), 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a variable of type [Color](../WDLang1/1000019661.md),

	- transparent if this parameter is not specified and if [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) has not been used. 




- Background characteristics: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) variable of type [Background](../WDLang1/1000022038.md). In this case, the gradient defined in the variable is ignored. 
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) [Background](../WDLang1/1000022038.md) variables are not available in this syntax. Use [&lt;Image variable&gt;.DrawBorder](../WDLang1/1000024019.md) to customize the background color.

	- characteristics specified in the last call to [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) if this parameter is not specified. 







To use a gradient background color, call [&lt;Image variable&gt;.DrawRectangleGradient](../WDLang1/1000024238.md).

**`<Line>: (Integer, constant or Border variable (optional))`**



- Color of rectangle line. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

	- [a WLanguage preset color](../WDLang5/3010002.md),

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) a variable of type [Color](../WDLang1/1000019661.md),

	- identical to the color used for the background if this parameter is not specified and if [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) has not been used.  




- Characteristics of the line: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) variable of type [Border](../Motscles/15140100.md). In this case, only the following properties are taken into account: 

		- Color: if the Property corresponds to the constant *UndefinedColor*the color defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the background color of the rectangle will be used. 

		- Thickness: if the Property corresponds to the constant *ThicknessIndefined*the thickness defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the thickness will be set to 1. 

		- Trait: if the property corresponds to *TraitIndéfini*the stroke type defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the line will be solid.  




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) [Border](../Motscles/15140100.md) variables are not available in this syntax. Use [&lt;Image variable&gt;.DrawBorder](../WDLang1/1000024019.md) to customize the borders.

- characteristics specified in the last call to [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) if this parameter is not specified.

### Drawing a rectangle via a Rectangle variable

`<Image variable>.DrawRectangle(<Rectangle> [, <Background> [, <Line>]])`
---

**`<Image variable>: (Image variable)`**



**`<Rectangle>: (Rectangle variable)`**

Name of the [Rectangle](../Motscles/1514079.md) variable that defines the coordinates of the rectangle to draw.

**`<Background>: (Integer, constant or Background variable (optional))`**



- Background color of rectangle. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

	- [a WLanguage preset color](../WDLang5/3010002.md), 

	- a variable of type [Color](../WDLang1/1000019661.md),

	- transparent if this parameter is not specified and if [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) has not been used. 




- Background characteristics: 

	- variable of type [Background](../WDLang1/1000022038.md). In this case, the gradient defined in the variable is ignored. 
			![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This type of variable is not available.
			![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) [Background](../WDLang1/1000022038.md) variables are not available in this syntax. Use [&lt;Image variable&gt;.DrawBorder](../WDLang1/1000024019.md) to customize the background color.

	- characteristics specified in the last call to [&lt;Image variable&gt;.Background](../WDLang1/1000024056.md) if this parameter is not specified. 







To use a gradient background color, call [&lt;Image variable&gt;.DrawRectangleGradient](../WDLang1/1000024238.md).

**`<Line>: (Integer, constant or Border variable (optional))`**



- Color of rectangle line. This color can be:

	- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

	- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

	- [a WLanguage preset color](../WDLang5/3010002.md),

	- a variable of type [Color](../WDLang1/1000019661.md),

	- identical to the color used for the background if this parameter is not specified and if [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) has not been used.  




- Characteristics of the line: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) variable of type [Border](../Motscles/15140100.md). In this case, only the following properties are taken into account: 

		- Color: if the Property corresponds to the constant *UndefinedColor*the color defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the background color of the rectangle will be used. 

		- Thickness: if the Property corresponds to the constant *ThicknessIndefined*the thickness defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the thickness will be set to 1. 

		- Trait: if the property corresponds to *TraitIndéfini*the stroke type defined during the last call to function [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) is used. If this function has not been used, the line will be solid.  


![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) [Border](../Motscles/15140100.md) variables are not available in this syntax. Use [&lt;Image variable&gt;.DrawBorder](../WDLang1/1000024019.md) to customize the borders.

- characteristics specified in the last call to [&lt;Image&gt;.Pen](../WDLang1/1000024016.md) if this parameter is not specified.
