


## Random (Function)

***In french: Hasard***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns a random number.

Note: To obtain a random number that can be used with cryptographic technologies (recommended for security reasons), use the [RandomCryptoInteger](../WDLang1/1000023426.md) function. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Retrieve a real included between 0 and 1
ResRandom = Random()
// Retrieve an integer included between 1 and 33
ResRandom = Random(33)
// Retrieve an integer included between 7 and 21
ResRandom = Random(7, 21)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

### Retrieving a random number included between 0 and 1

`<Result> = Random()`
---

**`<Result>: (Real)`**

Random number included between 0 and 1.  


<a name="SYNTAXE2"></a>

### Retrieving a random number between 1 and a value

`<Result> = Random(<Upper bound>)`
---

**`<Result>: (Int)`**

Random number between 1 and a specified value (inclusive).

**`<Upper bound>: (Int)`**

Upper bound of returned number (value included between 1 and 2 147 483 647).  


<a name="SYNTAXE3"></a>

### Retrieving a random number included between two values

`<Result> = Random(<Lower bound> , <Upper bound>)`
---

**`<Result>: (Int)`**

Random number included between two specified values (inclusive).

**`<Lower bound>: (Int)`**

Lower bound of the number returned (value included between 0 and 2 147 483 647).

**`<Upper bound>: (Int)`**

Upper bound of returned number (value included between 0 and 2 147 483 647).

<a name="NOTE0_1"></a>

## Remarks


### Random pool
<a name="random_pool_ELTPARAGRAPHE000082"></a>

The "pool" from which the random number is "chosen" can be initialized by [InitRandom](../WDLang1/3013030.md).

If [InitRandom](../WDLang1/3013030.md) is not called, the random values generated by **Random** will be the same for each program execution.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The [InitRandom](../WDLang1/3013030.md) function is not available as it is useless: the random values generated by the **Random FUNCTION** will be different each time the program is run.
