
## Warning (Function)

***In french: Avertissement***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a custom message in a system warning window.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=fonctions_dialogue%20-%20HC%20N%B0004.gif)


Remarks: 

- **This is a modal warning window**. To continue running the application, the user must validate this window by clicking OK. 
	![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To avoid blocking the application, use [WarningAsynchronous](../WDLang1/1000025270.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) WINDEV allows you to apply the skin template of your project to this dialog box. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This function displays a modal dialog box.  





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
NextTitle("Caution")
Warning("This operation was not validated" + ...
	CR + "Contact the application manager")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`Warning(<Text> [, <Line 2> [... [, <Line n>]]])`
---

**`<Text>: (Character string)`**

Text to be displayed on the first line.

**`<Line 2>: (Optional character string)`**

Text to be displayed on the second line. 



**`<Line n>: (Optional character string)`**

Text to be displayed on the Nth line.

## Remarks




### Features of the dialog box
<a name="features_the_dialog_box_ELTPARAGRAPHE000074"></a>



- The title of the dialog box corresponds to the title of the current window (or page).
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) To comply with the system specifications, the title of dialog box is empty by default. To define this title, use [NextTitle](../WDLang1/3038043.md).

- To modify or define the title of dialog box, use [NextTitle](../WDLang1/3038043.md).




- The message is aligned to the left.

- The button caption depends on the runtime language of Windows.

- The maximum number of characters cannot exceed 4096. If a larger string is passed as parameter, it will be truncated.

- The icon displayed (exclamation mark in yellow triangle) cannot be modified.




![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) **To customize this dialog box** (and all the system dialog boxes in your application), check "Customize system windows (Info, YesNo, Confirm, Dialog)" in the "Style" tab of the project description. For more details, see [Customizing dialog boxes](../WDLang1/3021003.md).
<a name="NOTE0_2"></a>




### Line break in the dialog box
<a name="line_break_the_dialog_box_ELTPARAGRAPHE000089"></a>

The CR string (Carriage Return) can be used to force a break to the next line. For example:


```wl
Warning("The XXX form was modified" + CR + ...
	"Any new modification must be validated.")
```


is equivalent to:


```wl
Warning("The XXX form was modified", ...
	"Any new modification must be validated.")
```


You also have the ability to use the syntax of multiline strings. For example: 


```wl
Warning(
[
This operation was not validated.

Contact the application provider
])
```

### Displaying the dialog box
<a name="displaying_the_dialog_box_ELTPARAGRAPHE000108"></a>

The dialog box is a modal window. The dialog box is displayed in the center of the page, with a DDW effect (Dim Disabled Windows).

**Warning** uses the "WebDeVYesNo" internal page. To include this page in your project:

1. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_nouveau.gif) in the quick access buttons. 

2. In the window that appears, click "Page" then "Page".

3. On the "Internal Page" tab, select the internal page named "Yes/No".

4. Validate. The "WebDeVYesNo" page appears in the editor.

5. Save the page by keeping its default name.

### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000128"></a>

- Timers ([TimerSys](../WDLang1/3015006.md)) are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Windows events are not stopped when this function is called.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) [DelayBeforeClosing](../WDLang1/3038040.md) limits how long the message is displayed. The dialog box is automatically closed. For question or confirmation dialog boxes, the default button corresponds to the expected answer.

- The caption of the button is displayed in the language used by Windows on the current computer.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000344"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**Warning** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
