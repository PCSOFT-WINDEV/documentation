


## PVTSelectCount (Function)

***In french: TCDSelectOccurrence***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***PVTSelectOccurrence*</**>** is kept for backward compatibility. This function has been replaced with ***PVTSelectCount*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of selected cells in a Pivot Table control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Loop through the selected cells
pvtPos is pvtPosition of PVT_MyPVT

nbSel is int = PVTSelectCount(PVT_MyPVT)
FOR i = 1 TO nbSel
	pvtPos = PVTSelect(PVT_MyPVT, i)
	Trace(pvtPos.COL_Today_Date + ":" + pvtPos.COL_Product))
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = PVTSelectCount(<Pivot Table control>)`
---

**`<Result>: (Integer)`**

Number of selected cells in the Pivot Table control. 

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.
