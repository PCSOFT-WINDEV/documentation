


## &lt;ANSI string&gt;.AnsiToOem (Function)

***In french: &lt;Chaîne ANSI&gt;.AnsiVersOem***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts an ANSI string (Windows) to an OEM string (DOS). Accented characters are different in both standards. The conversion consists in modifying the accented characters.

**Reminder**:

- ANSI is the character set used in Windows.

- OEM is the character set used in DOS (or Windows console).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Res is string
StringToConvert is ANSI string = "Crème brûlée" 
Res = StringToConvert.AnsiToOem()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <String to convert>.AnsiToOem()`
---

**`<Result>: (OEM character string)`**

OEM character string.

**`<String to convert>: (ANSI character string)`**

ANSI string to convert.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- **&lt;ANSI string&gt;.AnsiToOem** does not convert characters with an ASCII code between 0 and 31 (control characters).

- **Caution**: Do not use the **&lt;ANSI string&gt;.AnsiToOem** function with a string containing OEM-specific characters (accented characters): these characters will be transformed and the result will be incorrect.
