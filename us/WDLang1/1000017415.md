


## &lt;List Box&gt;.Delete (Function)

***In french: &lt;Liste&gt;.Supprime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes an element from a List Box, ListView or Combo Box control populated programmatically.

**Note**: The **&lt;List Box&gt;.Delete** function can be used for both single-selection and multi-selection List Box controls..
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Caution**: The item will be deleted only on the page displayed in the browser. For more details, see Remarks.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete the selected element from "LIST_CustomerList"
LIST_CustomerList.Delete()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<List Box control>.Delete([<Element index>])`
---

**`<List Box control>: (Control name)`**

Name of List Box (or Combo Box) control to use.

**`<Element index>: (Optional integer)`**

Index of the element to delete from the List Box or Combo Box control. If this parameter is not specified:

- in a single-selection List Box control, the current element is deleted.

- in a multi-selection List Box control, the selected elements are deleted.

- in a Combo Box control, the current element is deleted. If this control is an editable Combo Box control, the edit control is cleared.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The editable Combo Box controls are not available.

## Remarks


### Cascading deletions
<a name="cascading_deletions_ELTPARAGRAPHE000223"></a>

When deleting a set of elements, the elements found after each deleted element are moved. To perform cascading deletions, we advise you to start from the last element.

For example:

```wl
Index is int
FOR Index = LIST_CustomerList.Count() TO 1 STEP -1
	LIST_CustomerList.Delete(Index)
END
```

<a name="NOTE0_2"></a>
![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Deleting an element on the browser
<a name="deleting_element_the_browser_ELTPARAGRAPHE000243"></a>

When deleting an element in browser code, this element is only deleted from the page displayed in the browser. In order for this element to be deleted from the server, **&lt;List Box&gt;.Delete** must be run on the server.

Calling **&lt;List Box&gt;.Delete** in browser code is useful when using [AJAX technology](../WDLang2/3055101.md), in "Programmed AJAX" mode (via [AJAXExecute](../WDLang2/3055114.md) or [AJAXExecuteAsynchronous](../WDLang2/3055115.md)).

**Reminder** In "automatic and immediate AJAX" mode, simply pass the server processing containing the function **&lt;List Box&gt;.Delete FUNCTION** in automatic AJAX mode. That's it! No additional programming is required. For more details, see [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_3"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000275"></a>

- To delete an element from a Table control, use [&lt;Table&gt;.Delete](../WDLang1/1000024289.md).

- **&lt;List Box&gt;.Delete** can be used on a "Combo Box" table column.
