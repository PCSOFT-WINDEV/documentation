


## RegexSearch (Function)

***In french: RegexCherche***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Searches for all the parts of a string that match a specific format.

Note: The grammar used for regular expressions is ECMAScript.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Search for all the dates in a string 
// and retrieve days, months and years.
sString is string = "The order will be delivered between 28/08/2024 and 02/09/2024."
nFound is int = 0
arrDate is array of string
arrDays is array of string
arrMonths is array of string
arrYears is array of string
TXT_Result is string

nFound = RegexSearch(sString, "([0-9]{1,2})/([0-9]{1,2})/([0-9]{4})", tabDate, tabDays, tabMonths, tabYears)
FOR i = 1 TO nFound
	TXT_Resultat += StringBuild("Date: %1 | Days: %2 | Months: %3 | Years: %4", ...
		arrDate[i], arrDays[i], arrMonths[i], arrYears[i])
	TXT_Result += CR
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = RegexSearch(<Source string> , <Format> , <Strings found> ... [, <Strings found N>])`
---

**`<Result>: (Int)`**

Number of strings found.

**`<Source string>: (Character string)`**

String in which the search will be performed. 

**`<Format>: (Character string)`**

Regular expression that indicates the format of the part of the string to search for in &lt;Source string&gt;. 

**`<Strings found>: (Array of strings)`**

Name of the Array of strings variable that will contain the different substrings in &lt;Source string&gt;.



**`<Strings found N>: (Optional array of strings)`**

Name of the Array of strings variable that will contain the different substrings in &lt;Source string&gt;.
