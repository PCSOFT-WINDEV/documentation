
## dbgCheckNull (Function)

***In french: dbgVerifieNull ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether an expression is Null in assertive programming and in automated test mode.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// If FindCustomer is a procedure used to find a customer identified by its name and that returns
// the CCustomer object corresponding to the customer if the customer is known and Null otherwise 
// A customer who already exists must not be added
dbgCheckNull(FindCustomer(CustomerName), "Customer '%1' is already known", CustomerName)
// Adds the customer
AddCustomer(CustomerName)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`dbgCheckNull(<Expression> [, <Comments> [, <Parameter 1> [... [, <Parameter N>]]]])`
---

**`<Expression>: (Character string)`**

Expression that must be checked. 

**`<Comments>: (Character string)`**

Character string in the format defined by [StringBuild](../WDLang1/3024006.md). 

**`<Parameter 1>: (Any type)`**

First parameter expected by &lt;Comments&gt;.



**`<Parameter N>: (Any type)`**

Last parameter expected by &lt;Comments&gt;.

## Remarks


### Operating mode
<a name="operating_mode_ELTPARAGRAPHE000069"></a>

When the expression is not Null:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **in automated test mode**, an error is added to the test status report (equivalent to [TestWriteResult](../WDLang1/1000013001.md)). 

- **in manual test mode**, an assertion is displayed (equivalent to [dbgAssert](../WDLang1/3014022.md)).

- **in runtime mode**, an assertion is displayed if the assertions have been enabled (equivalent to [dbgAssert](../WDLang1/3014022.md)).




When running an application, the expression is not evaluated if the assertions are not enabled.

[dbgOnError](../WDLang1/1000020722.md) allows you to automatically start a WLanguage procedure used to retrieve the comment linked to the error. 
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) 

### Managing assertions
<a name="managing_assertions_ELTPARAGRAPHE000101"></a>

The messages of **dbgCheckNull** will be written into the ADB log (at "Assert" level). For more details, see [Managing ADB logs](../Editeurs/9000108.md).
