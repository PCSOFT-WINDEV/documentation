


## Compression / encryption functions (prefix syntax)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to handle encryption and compression in prefix syntax:



|   |   |
| --- | --- |
| [&lt;Buffer type&gt;.DecryptAsymmetric](../WDLang1/1410087282.md) | Decrypts a buffer with a private/public key algorithm with RSA encryption. |
| [&lt;Buffer type&gt;.DecryptAsymmetricEnveloped](../WDLang1/1410087283.md) | Performs the asymmetric encryption of an envelope that has been encrypted with [EncrypteAsymmetricEnveloped](../WDLang1/1410087280.md). |
| [&lt;Buffer type&gt;.EncryptAsymmetric](../WDLang1/1410087279.md) | Encrypts a buffer using an asymmetric encryption algorithm (RSA) that requires a public key and a private key. |
| [&lt;Buffer type&gt;.EncryptAsymmetricEnveloped](../WDLang1/1410087280.md) | Performs an asymmetric encryption of an envelope. |
| [&lt;Buffer type&gt;.EncryptStandard](../WDLang1/1410087281.md) | Encrypts a character string or a binary buffer by using a symmetrical encryption algorithm (AES, DES, etc.) |
| [&lt;Type Buffer&gt;Decode](../WDLang1/1410087344.md) | Decodes a character string that was encoded by [&lt;Type Buffer&gt;Encode](../WDLang1/1410087345.md). |
| [&lt;Type Buffer&gt;Encode](../WDLang1/1410087345.md) | Encodes a character string or a buffer. To decode the result, simply use [&lt;Type Buffer&gt;Decode](../WDLang1/1410087344.md). |
