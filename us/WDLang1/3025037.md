
## ControlDelete (Function)

***In french: ChampSupprime***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permanently deletes a control from a window, page or report. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) In a window or in a report, this control may have been created in the editor or by [ControlClone](../WDLang1/3025017.md).





![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) In a page, **ControlDelete** can only be used to delete the controls created by [ControlClone](../WDLang1/3025017.md).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **ControlDelete** can only be used to delete the controls created by [ControlClone](../WDLang1/3025017.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Delete a group of controls
FOR I = 1 TO 10
	s is string = "EDT_" + I
	IF ControlExist(s) = True THEN
		ControlDelete(s)
	END
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`ControlDelete(<Control used>)`
---

**`<Control used>: (Control name)`**

Name of the control or column (in a Table control) to delete. A WLanguage error occurs if this control does not exist.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks




### Deleting a column from a Table control
<a name="deleting_column_from_table_control_ELTPARAGRAPHE000096"></a>

When a column is deleted from a Table control (based on a data file or populated programmatically), the contents associated with the column are also deleted.
<a name="NOTE0_2"></a>




### Limits
<a name="limits_ELTPARAGRAPHE000104"></a>

A deleted control cannot be re-used later as source for cloning controls ([ControlClone](../WDLang1/3025017.md)).
