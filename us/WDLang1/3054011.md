## Adapting a project to support multiple languages
<a name="adapting_project_support_multiple_languages_ELTTEXTE000858"></a>
This page summarizes the main steps involved in transforming your projects into multilingual projects: 

- [Choosing the different languages](#NOTE1_2). 

- [Taking into account the language when creating a control](#NOTE1_3). 

- Translating the different elements: 

	- [Without specific tools](#NOTE1_4).

	- [With WDINT and WDMSG](#NOTE1_5).




- [Displaying the interface in a specific language in the editors](#NOTE1_6). 

- [Testing in different languages](#NOTE1_7). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) [Creating the executable](#NOTE1_8).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) [Deploying the site](#NOTE1_9). 




Please note: It is also necessary to manage the special cases corresponding to the different windows and pages proposed by default. For more details, see [Special case: Translation of default windows and pages](#NOTE2_1).
<a name="NOTE1_2"></a>


### 1. Choosing the different languages
<a name="1_choosing_the_different_languages_ELTPARAGRAPHE000052"></a>


|   |   |
| --- | --- |
| <br><br>- **Project**<br><br><br> | You can select the languages of the project in the project description:<br><br>1. On the "Project" tab, in the "Project" group, click "Description".<br><br>2. Select the "Languages" tab and click "Add". <br><br>3. The selected languages are taken into account for all elements (open elements are automatically closed).<br><br><br>For more details, see [Project description, "Languages" tab](../Editeurs/9500219.md). |
| <br><br>- **Windows, pages, reports and controls (text, input masks and images)**<br><br><br> | The different project languages are automatically managed. <br>Case of elements shared between several projects that do not use the same languages: when the element is opened in one of the projects, the additional languages are automatically added to the element. |
| <br><br>- **Help system (hlp or chm)**<br><br><br> | The different project languages are automatically managed. <br>In the case of helpers shared between several projects which do not use the same languages: when the element is opened in one of the projects, the additional languages are automatically added to the element. |
| <br><br>- **Messages in the code (code, procedures, classes)**<br><br><br> | The different project languages are automatically managed.<br>In the case of classes and procedures shared between several projects: when the element is opened in one of the projects, additional languages are automatically added to the element. |


<a name="NOTE1_3"></a>


### 2. Creating a new control
<a name="2_creating_new_control_ELTPARAGRAPHE000101"></a>




|   |   |
| --- | --- |
| <br><br>- **Windows, pages, reports and controls (text, input masks and images)**<br><br><br> | By default, only the caption of runtime language is specified. The caption of the control must be translated into the supported languages. |
| <br><br>- **Help system (hlp or chm)**<br><br><br> | The title of the new pages and the keywords are automatically created in English. |


<a name="NOTE1_4"></a>


### 3. Translation without specific tool (in WINDEV directly)
<a name="3_translation_without_specific_tool_windev_directly_ELTPARAGRAPHE000116"></a>


|   |   |
| --- | --- |
| <br><br>- **Windows, pages, reports and controls (text, input masks and images)**<br><br><br> | Text must be translated in all window, page, report and control descriptions. |
| <br><br>- **Help system (hlp or chm)**<br><br><br> | For table of contents and indexes: translation must be performed in the page description windows. <br>For help page content: translation must be carried out after the display language has been changed. |
| <br><br>- **Messages in the code (code, procedures, classes)**<br><br><br> | The translation must be performed in the message editor (Ctrl + T). |


<a name="NOTE1_5"></a>


### 3 b. Translating messages with WDMSG/WDINT
<a name="3_translating_messages_with_wdmsgwdint_ELTPARAGRAPHE000136"></a>




|   |   |
| --- | --- |
| <br><br>- **Windows, pages and controls (text, input masks and images)**, **Reports and controls (text, display mask and images)**, **Help system (hlp or chm)**, **Code messages (code, procedures, classes)**<br><br><br> | Extract all messages to be translated with WDMSG, translate the generated file and reintegrate the translations. |
| <br><br>- **WINDEV messages**<br><br><br> | Extract and translate with WDINT. Generate a WDM file. |

### Display in the editor in a given language
<a name="display_the_editor_given_language_ELTPARAGRAPHE000151"></a>




|   |   |
| --- | --- |
| <br><br>- **Project**<br><br><br> | Change the display language of all project elements: in the "Display" pane, in the "Options" group, pull down "Language displayed".<br>**Please note: the default language for project execution remains unchanged.** |
| <br><br>- **Windows, pages and controls (text, input masks and images)**<br><br><br> | The language of the editor changes automatically according to the language of the project. <br>To change the display language for all project elements: in the "Display" pane, in the "Options" group, scroll down to "Language displayed" (\*). |
| <br><br>- **Reports and controls (text, display mask and images)**<br><br><br> | The language of the editor changes automatically according to the language of the project. <br>To change the display language for all project elements: in the "Display" pane, in the "Options" group, scroll down to "Language displayed" (\*). |
| <br><br>- **Help system (hlp or chm)**<br><br><br> | The language of the editor changes automatically according to the language of the project <br>To change the display language for all project elements: in the "Display" pane, in the "Options" group, scroll down to "Language displayed" (\*). |
| <br><br>- **Messages in the code (code, procedures, classes)**<br><br><br> | The language of the editor changes automatically according to the language of the project. <br>To change the display language for all project elements: in the "Display" pane, in the "Options" group, scroll down to "Language displayed" (\*). |


<a name="NOTE1_7"></a>


### Test
<a name="test_ELTPARAGRAPHE000248"></a>




|   |   |
| --- | --- |
| <br><br>- **Project**<br><br><br> | The test of the project is run using the language selected as "Default language at runtime". The default language used at runtime is selected in the project description window ("Languages" tab). |
| <br><br>- **Windows, pages and controls (text, input masks and images)**<br><br><br> | The window test is run in the default language of the project. |
| <br><br>- **Reports and controls (text, display mask and images)**<br><br><br> | The report is tested in the default language of the project. |
| <br><br>- **Help system (hlp or chm)**<br><br><br> | Compilation and test run in the display language of help system. <br>You must create as many help files as the number of languages. |
| <br><br>- **Messages in the code (code, procedures, classes)**<br><br><br> | When testing a window or project, the messages from the code are displayed in the default language of the project. |
| <br><br>- **WINDEV messages**<br><br><br> | Define the WDM file associated with each language in the project description:<br><br>1. On the "Project" tab, in the "Project" group, click "Description".<br><br>2. Select the "Language" tab.<br><br>3. Select the desired language. <br><br>4. On the "Miscellaneous" tab, select the WDM translation file. <br><br><br> |


<a name="NOTE1_8"></a>


### Executable
<a name="executable_ELTPARAGRAPHE000298"></a>




|   |   |
| --- | --- |
| <br><br>- **Project**<br><br><br> | The executable is created in the default language of the project. <br>To change this language as soon as the executable is run, use [Nation](../WDLang1/3054014.md) in the initialization code of the project. <br>Please note: the language will be changed from the moment the [Nation](../WDLang1/3054014.md) function is used until the next time the [Nation](../WDLang1/3054014.md) function is used. |
| <br><br>- **Windows, pages and controls (text, input masks and images)**<br><br><br> | The windows are displayed in the language of the executable. <br>To change the display language of a window, use [Nation](../WDLang1/3054014.md) before opening the window. <br>Please note: the language will be changed from the moment the [Nation](../WDLang1/3054014.md) function is used until the next time the [Nation](../WDLang1/3054014.md) function is used. |
| <br><br>- **Reports and controls (text, display mask and images)**<br><br><br> | The reports are printed by default in the language of the executable. <br>To change the print language of a report, use:<br><br>- [Nation](../WDLang1/3054014.md) before printing the report. <br>	Please note: the language will be changed from the moment the [Nation](../WDLang1/3054014.md) function is used until the next time the [Nation](../WDLang1/3054014.md) function is used.<br><br>- the [iPrintingNation](../WDLang5/1000020968.md) function.<br><br>- **Help system (hlp or chm)**:<br>	Open the help file corresponding to the desired language ([WHelp](../WDLang1/3013053.md)).<br><br><br> |
| <br><br>- **Messages in the code (code, procedures, classes)**<br><br><br> | Messages are displayed in the current runtime language. <br>To change the language used to display the message, use [Nation](../WDLang1/3054014.md). <br>Please note: the language will be changed from the moment the [Nation](../WDLang1/3054014.md) function is used until the next time the [Nation](../WDLang1/3054014.md) function is used. |
| <br><br>- **WINDEV messages**<br><br><br> | Define the WDM file associated with each language in the project description:<br><br>1. On the "Project" tab, in the "Project" group, click "Description".<br><br>2. Select the "Language" tab.<br><br><br> |

## Special case: Translation of default windows and pages
<a name="special_case_translation_default_windows_and_pages_ELTTEXTE000930"></a>
The following elements can be automatically included in your applications or sites: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) preview window.

- HFSQL windows for automatic management of HFSQL programming errors.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) User Groupware windows or pages. These elements are used to manage the connection of a user to an application and the different access levels for each user.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) windows of AAF (Automatic Application Features). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) the setup program, allowing the user to install his application or his site.

### Including and translating the windows and pages proposed by default
<a name="including_and_translating_the_windows_and_pages_proposed_default_ELTPARAGRAPHE000508"></a>

**These windows and pages are available in English and French by default**. To support additional languages, the following operations must be performed:




### Report viewer
<a name="report_viewer_ELTPARAGRAPHE000514"></a>


|   |   |
| --- | --- |
| <br><br>- **Purpose**<br><br><br> | Display the report in "Preview" mode, and allow the user to print via the desired medium (printer, XML file, etc.). |
| <br><br>- **Integration into the project**<br><br><br> | Request the integration of windows in your project:<br><br>1. Open the project description window. To do so, go to the "Project" tab, "Project" group, and select "Description".<br><br>2. Go to the "Style" tab.<br><br>3. In "Report viewer", select "Custom (included in the project)".<br><br>4. Select the type of customization to perform:<br><br>	- &lt;Visualisateur de rapports standard (sans gabarit)&gt; This option imports standard print windows directly into your project.<br><br>	- &lt;Visualisateur de rapports standard au gabarit du projet&gt; This option directly imports print windows corresponding to your project's skin template.<br><br><br><br><br><br> |
| <br><br>- **Translation with WDMSG, or without specific tools**<br><br><br> | See previous paragraph. |
| <br><br>- **Language used**<br><br><br> | The runtime language of the project will be used by default. |
| <br><br>- **Change of language with [Nation](../WDLang1/3054014.md)**<br><br><br> | The language changes automatically.. |

### Windows of AAF (Automatic Application Features)
<a name="windows_aaf_automatic_application_features_ELTPARAGRAPHE000759"></a>

Some AAFs (Automatic Application Features) use specific windows. These windows can be included in the application to be translated. List of main features that require a specific integration in order to be translated: 

- [Scheduler control](../WDChamp/1000019498.md) and [Organizer control](../WDChamp/1016329.md): Possibility of customizing and translating the appointment window. 

- [Organization Chart control](../WDChamp/1000019822.md): Ability to customize and translate the window of elements.

- [Locking the application](../WDLang6/3061101.md): Ability to customize and translate the lock window. 

- [Managing the keyboard shortcuts](../Editeurs/9500108.md): Ability to customize and translate the shortcut window. 

- [Displaying a line of an edit control](../Editeurs/9500120.md): Ability to customize and translate the input window of a given line. 

- [Defining a timer](../Editeurs/9500100.md): Ability to customize and translate the timer settings window. 

- [Multi-control search](../Editeurs/9500101.md): Ability to customize and translate the search window.

- [History of modifications](../WDLang4/3044344.md): Ability to customize and translate the history window. 

- [Calendar](../WDChamp/1016300.md): Ability to customize and translate the context menu of the calendar. 

- [Calculator](../Editeurs/9500122.md): Ability to customize the calculator and translate its options.

- [Automatic print of Scheduler controls](../WDChamp/1000019561.md): Ability to customize and translate the print settings window.

- [Automatic print of Organizer controls](../WDChamp/1016327.md): Ability to customize and translate the print settings window.
