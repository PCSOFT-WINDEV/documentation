


## MultimediaDuration (Function)

***In french: MultimédiaDurée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the size of the media file currently played (in milliseconds) in the Multimedia control.  

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) **Note** Depending on the type of video and browser configuration, this function may not be supported. In this case, its use will have no effect but no error will be triggered.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 
```wl
MyFile is string = "C:\My music\mysong.mp3"
MultimediaOpen(MM_Multimedia1, MyFile)
Info("The duration of this file is " + MultimediaDuration(MM_Multimedia1) + " milliseconds")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = MultimediaDuration(<Multimedia control>)`
---

**`<Result>: (Integer)`**



- Duration (in milliseconds) of media file,

- 0 if an error occurs. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).


![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Note: The [ErrorInfo](../WDLang1/3013008.md) function is not available.

**`<Multimedia control>: (Control name)`**

Name of the Multimedia control to be used.
