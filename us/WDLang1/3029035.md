


## Drawing in WINDEV, WEBDEV and WINDEV Mobile

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000265"></a>
WINDEV, WEBDEV and WINDEV Mobile include several functions for displaying, drawing, copying and saving the drawings and images from your applications or sites.

WINDEV, WEBDEV and WINDEV Mobile propose functions used to:

- draw several drawings, 

- display any type of image, 

- copy the drawings and the images, 

- save drawings and images.

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000314"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.



![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000042"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.

### Using the drawing functions in Linux
<a name="using_the_drawing_functions_linux_ELTPARAGRAPHE000076"></a>

To use the drawing function in Linux, the QT library (Core and GUI) version 5 (or later) must be installed. 

**In Ubuntu**, this library can be installed with the following commands: 


```txt
sudo apt-get install libqtcore5
sudo apt-get install libqtgui5
```


**In mandriva 2010 Spring**, this library can be installed with the following commands: 


```txt
urpmi libqtgui5
```

## How to draw?
<a name="how_draw_ELTTEXTE000337"></a>


### Drawing in an Image control
<a name="drawing_image_control_ELTPARAGRAPHE000106"></a>

To draw in an Image control: 

1. Initialize the drawing in the Image control ([dStartDrawing](../WDLang1/3029009.md)). This initialization is used to allocate a specific memory area for the management of drawings.

2. Draw with the [drawing functions](../WDLang1/3029033.md).

3. If necessary, insert text in your drawings with [dText](../WDLang1/3029032.md).

4. Zoom and copy images as required with [dCopyImage](../WDLang1/3029007.md).

5. If necessary, save the drawing using the save functions ([dSaveImageBMP](../WDLang1/3029026.md), [dSaveImageGIF](../WDLang1/3029040.md), [dSaveImageJPEG](../WDLang1/3029038.md), [dSaveImagePNG](../WDLang1/3029027.md)).

6. If necessary, print the file using [iPrintImage](../WDLang5/3046017.md).

7. If necessary, destroy the drawing in memory with [dEndDrawing](../WDLang1/3029019.md).


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Note: Before manipulating the Image control, check that the Image or Clickable Image control is of "Generated image" type.


### Drawing in an Image variable
<a name="drawing_image_variable_ELTPARAGRAPHE000155"></a>

To draw in an Image variable, some rules must be complied with:

1. Declare a variable of type [Image](../WDLang1/1000019650.md). 

2. Initialize the drawing in the variable ([dStartDrawing](../WDLang1/3029009.md)). This initialization is used to allocate a specific memory area for the management of drawings.

3. Draw with the [drawing functions](../WDLang1/3029033.md).

4. If necessary, insert text in your drawings with [dText](../WDLang1/3029032.md).

5. If necessary, save the drawing using the save functions ([dSaveImageBMP](../WDLang1/3029026.md), [dSaveImageGIF](../WDLang1/3029040.md), [dSaveImageJPEG](../WDLang1/3029038.md), [dSaveImagePNG](../WDLang1/3029027.md)).

6. If necessary, print the file using [iPrintImage](../WDLang5/3046017.md).

7. If necessary, destroy the drawing in memory with [dEndDrawing](../WDLang1/3029019.md).



![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) 

### Drawing in browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000202"></a>

In browser code, transferring the drawing into the image can be quite long (several drawing functions will be used). 

**To optimize the drawing in the image**, the drawing can be displayed once the drawing functions have been used. To do so, simply: 

1. Start the drawing with [dStartDrawing](../WDLang1/3029009.md) using the *dForceDisplay* constant. 

2. Use the drawing functions to create the drawing. 

3. Use [dDisplay](../WDLang1/1000019566.md) to display the drawing in the image.
