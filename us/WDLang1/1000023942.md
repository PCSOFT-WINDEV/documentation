


## Token (Variable type)

***In french: Jeton***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **Token** type is used to define all the advanced characteristics of a token displayed in an edit control. You can define and change the characteristics of this token using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The Token type is only available in the V2 framework. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add a token to an Edit control
MyToken is Token 
MyJeton.Label = Customer.Name
MyJeton.Value = Customer.CustomerId
EditAddToken(EDT_Customer, MyToken)

// Modify the background color of a token
FOR EACH MyToken OF EDT_Customer.Token
	IF MyJeton.Value = Customer.CustomerID THEN
		MyJeton.BackgroundColor = LightRed
	END
END
```

## Properties


### Properties specific to Token variables
<a name="properties_specific_token_variables_ELTPARAGRAPHE000029"></a>

The following properties can be used to handle a token:

| Property name | Type used | Effect |
| --- | --- | --- |
| BackgroundColor | [Color](../WDLang1/1000019661.md) variable | Background color of the token.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Note: This color can be ignored if the **HTML label** property contains background color indications. |
| Caption | Character string | Caption of the token as it will be displayed in the Edit control. If this property is not specified, the caption of the token will correspond to its stored value.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Note: This information can be ignored if the **HTML label** property is specified. |
| ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) CaptionHTML | Character string | HTML code of the token caption as it will be displayed in the Edit control. If this property is not specified, the caption specified with the **Caption** property is used. |
| Color | [Color](../WDLang1/1000019661.md) variable | Color of the token text.<br><br>![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Note: This color can be ignored if the **HTML label** property contains text color indications. |
| Extra | Variant | Allows you to store advanced information without affecting the execution of the application. You can store values of any type (array, etc.). It is also possible to add members to the **Extra** property. <br>Example: <br><br><pre><code>MyVariable.Extra.Info1 = Value<br>MyVariable.Extra[Info2] = Value2<br>MyVariable.Extra.Date = DateSys()</code></pre><br> |
| StoredValue | Character string | Stored value of the token. Stores any type of value. |
| Tooltip | Character string | Tooltip displayed when hovering over the token. |
| Value | Character string | Token value. |

## Remarks
<a name="NOTE0_2"></a>


### Manipulating tokens
<a name="manipulating_tokens_ELTPARAGRAPHE000108"></a>

- To manipulate the tokens of an Edit control, it is possible to use: 

	- the [token functions](../WDLang1/1000024042.md). 

	- the [Token](../Proprietes/1000023976.md) property of the Edit control that returns an editable list containing all the tokens displayed in the control.




- To reset the content of a Token variable, use [VariableReset](../WDLang1/3013069.md).
