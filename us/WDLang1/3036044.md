
## fTempPath (Function)

***In french: fRépertoireTemp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the name of directory used to store the temporary files.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003036044&name=ftemppath_function">See additional examples</a>

```wl
// Retrieve the name of temporary directory
ResTempDir = fTempPath()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = fTempPath()`
---

**`<Result>: (Character string)`**



- Path of directory used to store the temporary files (up to 260 characters). This path ends with the "\\" character. 
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This path corresponds to the "tmp" directory of application. 

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.   


**Note**: The result of the **fTempPath** function is always a character string in Ansi format.. However, the result can be stored in a Unicode character string.

<a name="NOTE0_1"></a>

## Remarks


### Temporary directory
<a name="temporary_directory_ELTPARAGRAPHE000055"></a>

In Windows Vista (and later), when the [UAC system](../Editeurs/2025014.md) is enabled, the temporary directory is different depending on whether the user has administrator privileges or not.


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000065"></a>

**fTempPath** and [fTempDir](../WDLang1/1000021768.md) are equivalent.
