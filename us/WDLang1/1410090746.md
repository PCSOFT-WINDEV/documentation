


## Functions for handling commands in console mode
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to handle commands executed in console mode: 




|   |   |
| --- | --- |
| [CmdAddArgument](../WDLang1/1410090501.md) | Adds an argument to a command to be executed in console mode. |
| [CmdAddOption](../WDLang1/1410090502.md) | Adds an option to the command to be executed in console mode. |
| [CmdExecute](../WDLang1/1410090500.md) | Executes a command in console mode. |
| [CmdGetExitCode](../WDLang1/1410090506.md) | Gets the exit code of the command executed in console mode, i.e. the value returned when the command finishes executing. |
| [CmdIsRunning](../WDLang1/1410091011.md) | Indicates whether the executable associated with a command is currently running. <br><br> |
| [CmdKill](../WDLang1/1410091013.md) | Forces the termination of a running executable associated with a command.<br><br> |
| [CmdReadErrorOutput](../WDLang1/1410090505.md) | Reads error output data for the command executed in console mode. |
| [CmdReadStandardOutput](../WDLang1/1410090504.md) | Reads standard output data, for the command executed in console mode. |
| [CmdWriteStandardInput](../WDLang1/1410090503.md) | Writes data to the standard input of the command executed in console mode. |
