
## ShamirCreateShares (Function)

***In french: ShamirCréeClésPartagées***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a set of shares for the same secret using Shamir's algorithm. 

Here's how it works: 

- Sensitive data (the "secret") is split into a number of shares. 

- A certain number of shares is required to reconstruct the secret.  





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Definition of input parameters
secret is Buffer = "Secret data"
shares_to_generate is int = 5
shares_required_for_reconstruction is int = 3

// Array of generated shares
generated_shares is array of strings
// Generation of shares
generated_shares = ShamirCreateShares(secret, shares_to_generate, 
			shares_required_for_reconstruction)
// Split secrets to create BIP39 mnemonic phrases and save them to a file
FOR EACH share OF generated_shares
	// Trace(share)
	// Split the share into sections
	share_sections is array of strings = StringSplit(share, "-")
	// Retrieve share identifier
	// the first section is always the identifier
	id is int = share_sections[1]
	// Create a BIP39 mnemonic phrase from each 256-bit section
	bip39_arr is array of strings
	// If the prime number has not been specified, 
	// the following sections will have the value of the share divided into chunks of up to 256 bits
	// Otherwise 
	// there is only one section after the identifier, 
	// the size of the section is less than or equal to the size of the prime number
	FOR section_index = 2 _TO_ share_sections.Count
		// Transform hex into buffer then buffer into BIP39 mnemonic phrase
		section_buffer is Buffer = HexaToBuffer(share_sections[section_index])
		bip39_section is string = BufferToPhrase(section_buffer, languageFrench)
		// Adds the BIP39 mnemonic phrase to the array of phrases of the share
		bip39_arr.Add(bip39_section)
	END
	// Save the BIP39 mnemonic phrases to a file
	fSaveText(fExeDir() + [fSep()] + "share_bip39_[%id%].txt", bip39_arr.ToString(CR))
END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = ShamirCreateShares(<Secret> , <Number of shares> , <Threshold> [, <Prime number>])`
---

**`<Result>: (Array)`**

Array of strings containing the various generated shares. 

**`<Secret>: (Buffer)`**

Secret buffer to split. 

**`<Number of shares>: (Integer)`**

Minimum number of shares to be created. 

**`<Threshold>: (Integer)`**

Minimum number of shares required to reconstruct the secret. 

**`<Prime number>: (Optional character string)`**

Prime number represented as a hexadecimal string. This number must be identical when creating and reconstructing the secret. 
If this parameter is not specified, shares will be split into 256-bit sections. 
If this parameter is specified, the prime number must be greater than the &lt;Secret&gt;. [ShamirGeneratePrime](../WDLang1/1410091295.md) can be used to generate a prime number of the desired size.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Shamir's secret sharing is a cryptographic algorithm that makes it possible to distribute private information (known as "secrets"). The secret is divided into parts, giving each user their own share. Some or all of these parts are needed to reconstruct a passphrase that gives access to the secret.

Not all users are needed to reconstruct the minimum required to form the secret access passphrase. A &lt;Threshold&gt; can be set.
