


## docTableOfContents (Variable type)

***In french: docTableDesMatières***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docTableOfContents** type is used to define all the options to generate a table of contents in a Word Processing document. You can define and change the characteristics of this table of contents using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
doc is Document
...
// Define the table of contents
toc is docTableOfContents
toc.WithPageNumber = True

// Paragraphs that use the default style for level 1 (Heading 1) 
// are used for level 1 entries in the table of contents
toc.StylesPerLevel[1] = styleTOCDefault1

// Paragraphs that use the default style for level 2 (Heading 2) 
// and the paragraphs that use "MyCustomStyle"
// are used for level 2 entries in the table of contents
toc.StylesPerLevel[2] = styleTOCDefault2 + CR + "MyCustomStyle"

// Paragraphs that use "MyCustomStyle3"
// are used for level 3 entries in the table of contents
toc.StylesPerLevel[3] = "MyCustomStyle3"

// Insert table of contents at the beginning of the document
fDocBeginning is docFragment = doc[1 ON 0]
DocInsert(fDocBeginning, toc)
```

## Properties


### Properties specific to docTableOfContents variables
<a name="properties_specific_doctableofcontents_variables_ELTPARAGRAPHE000025"></a>

The following properties can be used to handle a table of contents:


| Property name | Type used | Effect |
| --- | --- | --- |
| StylesPerLevel | Array of strings | Used to specify the style(s) to use when generating the corresponding level in the table of contents.<br><br>If various styles are used, they must be separated by CR (Carriage Return). <br><br>You can use: <br><br>- one or more custom styles,<br><br>- the constants corresponding to the default styles: <br><br>	- *styleTDMDefault1* Default paragraph style for level 1 of table of contents (Heading 1). <br><br>	- *styleTDMDefault2* Default paragraph style for level 2 of table of contents (Title 2). <br><br>	- *styleTDMDefault3* Default paragraph style for level 3 of table of contents (Heading 3). <br><br>	- *styleTDMDefault4* Default paragraph style for level 4 of table of contents (Heading 4). <br><br>	- *styleTDMDefault5* Default paragraph style for level 5 of table of contents (Heading 5). <br><br>	- *styleTDMDefault6* Default paragraph style for level 6 of table of contents (Heading 6). <br><br>	- *styleTDMDefault7* Default paragraph style for level 7 of table of contents (Title 7). <br><br>	- *styleTDMDefault8* Default paragraph style for level 8 of the table of contents (Heading 8). <br><br>	- *styleTDMDefault9* Default paragraph style for level 9 of the table of contents (Heading 9). <br><br><br><br><br><br> |
| WithPageNumber | Boolean | <br><br>- <u><u><u>True</u></u></u> if the page number must be displayed on each line of the table of contents, <br><br>- <u><u><u>False</u></u></u> otherwise. <br><br><br> |
