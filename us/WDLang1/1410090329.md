


## &lt;WLanguageCodeFormatting&gt;.Format (Function)

***In french: &lt;CodeWLangageMiseEnForme&gt;.MetEnForme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Formats WLanguage code: coloring, normalized rewriting, indentation, translation, etc.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// String to format
sCode is ANSI string = "
CodeFormatting is WLanguageCodeFormatting
CodeFormatting.Language = languageEnglish
CodeFormatting.Indentation = True
CodeFormatting.IncludeCSSDeclarations = True
CodeFormatting.IgnoreCompilationError = True
CodeFormatting.KeywordCase = WLanguageCodeKeywordLowercase
CodeFormatting.Theme = WLanguageCodeThemeDark
CodeFormatting.Format = WLanguageCodeFormatHTML
bufHTMLRes is Buffer = CodeFormatting.Format(sCode)
"
CodeFormatting is WLanguageCodeFormatting
CodeFormatting.Language = languageEnglish
CodeFormatting.Indentation = True
CodeFormatting.IncludeCSSDeclarations = True
CodeFormatting.IgnoreCompilationError = True
CodeFormatting.KeywordCase = WLanguageCodeKeywordLowercase
CodeFormatting.Theme = WLanguageCodeThemeDark
CodeFormatting.Format = WLanguageCodeFormatHTML
bufHTMLRes is Buffer = CodeFormatting.Format(sCode)

// Display content in an HTML Display control
HTM_NoName1 = bufHTMLRes.UTF8ToString()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Parameters to use>.Format(<Code to format>)`
---

**`<Result>: (Character string)`**

Formatted WLanguage code.

**`<Parameters to use>: (WLangageCodeFormatting variable)`**

Name of the [WLanguageCodeFormatting](../WDLang1/1410090146.md) variable containing the code formatting parameters.

**`<Code to format>: (Character string)`**

Code to format.
