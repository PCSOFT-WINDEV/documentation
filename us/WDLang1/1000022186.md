


## &lt;Pivot Table&gt;.Filter (Function)

***In french: &lt;Tableau croisé dynamique&gt;.Filtre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enables or disables a filter in a Pivot Table control. 

Caution: Only a filter defined in the "Content" tab of the Pivot Table control description window can be used. When **&lt;Pivot Table&gt;.Filter** is used, only the display of the Pivot Table control is modified, the different totals are not updated.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// -- Selecting a row of COMBO_Filter_by_family
// Filters the Pivot Table control on the family of products that must be taken into account
PVT_Statistics.Filter(COL_Caption, MySelf)
IF PVT_Statistics.Count = 0 THEN
	STC_NO_DATA.Visible = True
ELSE
	STC_NO_DATA.Visible = False
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Pivot Table control>.Filter(<Display filter> , <Value>)`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used.

**`<Display filter>: (Character string)`**

Name of the filter to be applied. This filter must have been defined in the "Content" tab of the Pivot Table control description window.

**`<Value>: (Type of the filter)`**



- Value of the filter to be applied. 

- Empty string ("") to delete the filter.

## Remarks


### Implementation
<a name="implementation_ELTPARAGRAPHE000195"></a>

To apply a filter to a Pivot Table control, you must: 

1. Create the Pivot Table control. 

2. In the Pivot Table control description window, in the "Content" tab, add one or more filters. 

3. Create a control allowing the user to select the filter value. Selecting the value will execute **&lt;Pivot Table&gt;.Filter**.
