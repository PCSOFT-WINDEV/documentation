


## CodeEditorExecute (Function)

***In french: EditeurCodeExécute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Executes the WLanguage code displayed in the Code Editor control. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Executes the code in the Code Editor control
CodeEditorExecute(CODEEDT_Example)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = CodeEditorExecute(<Code Editor control>)`
---

**`<Result>: (Character string)`**

Value returned by the WLanguage code displayed in the Code Editor control (using the RETURN keyword). 

**`<Code Editor control>: (Control name)`**

Name of the Code Editor control to be used.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
Warning: If the WLanguage code displayed in the Code Editor field does not compile, it will not be executed. No error will be displayed.
