
## Constants for managing masks
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following constants are used to manage masks: 

| Constant | Description | Used by the functions |
| --- | --- | --- |
| **mzcLockExit** | Prevents users from leaving the control until the value entered is valid (e.g., 5 digits for postal codes in France). | [MaskZipCode](../WDLang1/1000024742.md) |
| **mzcFreeExit** | Allows leaving the control even if the input mask is not checked. | [MaskZipCode](../WDLang1/1000024742.md) |
| **mphoneWithOrWithoutPrefix** | Phone number features: Phone number with or without international prefix. | [MaskPhoneNumber](../WDLang1/1000024741.md) |
| **mphoneForcePrefix** | Phone number feature: Phone number always with international prefix. Exemple: +33 4 67 03 20 32 | [MaskPhoneNumber](../WDLang1/1000024741.md) |
| **mphoneWithoutPrefix** | Phone number features: Phone number without international prefix. Exemple: 04 67 03 20 32. | [MaskPhoneNumber](../WDLang1/1000024741.md) |
