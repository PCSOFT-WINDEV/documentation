


## DecryptStandard (Function)

***In french: DécrypteStandard***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>24</B>, ***UncryptStandard*</**>** is kept for backward compatibility. This function has been replaced with ***DecryptStandard*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Decrypts a message that was encrypted with a standard encryption algorithm. 

Unlike [Encrypt](../WDLang1/3024014.md) and [Decrypt](../WDLang1/3024035.md), [EncryptStandard](../WDLang1/1000021293.md) and **DecryptStandard** use the standard encryption algorithms that allow you to exchange encrypted messages between different runtime platforms (Windows, Linux, Android, Java, iOS, PHP, etc.) and/or with external tools.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000021295&name=decryptstandard_function">See additional examples</a>

```wl
// Encrypt a character string by using the AES algorithm
sMessage is Buffer = "Message to encrypt"
sPassword is ANSI string = "password"
bufKey is Buffer = HashString(HA_MD5_128, sPassword)
bufEncrypt is Buffer = EncryptStandard(sMessage, bufKey, cryptAES128)
// Decryption 
bufResult is Buffer = DecryptStandard(bufEncrypt, bufKey, encryptAES128)
Info(bufResult)
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = DecryptStandard(<Encrypted message> , <Key> [, <Algorithm> [, <Operation mode> [, <Padding>]]])`
---

**`<Result>: (Binary buffer)`**



- Result of decryption for the specified message, 

- Empty string ("") if an error occurred. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Encrypted message>: (Binary buffer)`**

Message to decrypt. This message can be the encryption result obtained during the call to [EncryptStandard](../WDLang1/1000021293.md).

This buffer must include two sections: 

- The initialization vector (or IV) used to encrypt data.

- The encrypted data.




If the message was encrypted: 

- by [EncryptStandard](../WDLang1/1000021293.md), this parameter must correspond to the value returned by the function. 

- by an external tool, the buffer must be built by concatenating the encrypted data to initialization vector used.




Note: if the operating mode specified is *crypteECB*no initialization vector has been used to encrypt the message, in which case the parameter must correspond directly to the encrypted data.

**`<Key>: (Buffer or Secret string)`**

Key with which the data was encrypted. This key must be identical to the one supplied when encrypting the message.
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter can be "Buffer - ASCII" or "Buffer - UTF-8".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications.

**`<Algorithm>: (Optional Integer constant)`**

Encryption algorithm used. This parameter must correspond to the algorithm used to encrypt the message. 


|   |   |
| --- | --- |
| *cryptAES192* | Advanced Encryption Standard. <br><br>- Key size: 192 bits. <br><br>- Block size: 128 bits. <br><br>- Initialization vector (IV) size: 128 bits.<br><br><br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encrypt3DES* | Triple Data Encryption Standard. <br><br>- Key size: 192 bits. <br><br>- Block size: 64 bits.<br><br>- Initialization vector (IV) size: 64 bits.<br><br><br> |
| *encryptAES128*<br>(Default value) | Advanced Encryption Standard. <br><br>- Key size: 128 bits. <br><br>- Block size: 128 bits. <br><br>- Initialization vector (IV) size: 128 bits.<br><br><br> |
| *encryptAES256* | Advanced Encryption Standard. <br><br>- Key size: 256 bits. <br><br>- Block size: 128 bits. <br><br>- Initialization vector (IV) size: 128 bits.<br><br><br> |
| *encryptDES* | Data Encryption Standard. <br><br>- Key size: 64 bits. <br><br>- Block size: 64 bits. <br><br>- Initialization vector (IV) size: 64 bits.<br><br><br>Warning: this algorithm is currently deprecated. |



**`<Operation mode>: (Optional Integer constant)`**

Process mode of blocks by the encryption algorithm used. This parameter must correspond to the operation mode used to encrypt the message.


|   |   |
| --- | --- |
| *encryptCBC* <br>(Default value) | Cipher Block Chaining - Sequence of blocks. |
| *encryptCFB* | Cipher Feedback - Feedback encryption. <br><br>From now on, this processing mode is available regardless of the algorithm used.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encryptCTR* | Cipher Counter - Encryption based on a counter. <br><br>From now on, this processing mode is available regardless of the algorithm used.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This constant is not available. |
| *encryptECB* | Electronic Code Book - Dictionary of codes. This mode of operation is not recommended and should only be used for compatibility reasons. |



**`<Padding>: (Optional Integer constant)`**

Padding mode for encrypted data to be compatible with the size required by block encryption algorithms. This parameter must correspond to the fill mode used to encrypt the message.


|   |   |
| --- | --- |
| *encryptPaddingPKCS* <br>(Default value) | The data is filled with bytes whose value corresponds to the total number of bytes added to reach the requested size. |
| *encryptPaddingZero* | The data is filled with binary zeros until the requested size is reached. |

## Remarks


### Compatibility
<a name="compatibility_ELTPARAGRAPHE000195"></a>

The old [Encrypt](../WDLang1/3024014.md) and [Decrypt](../WDLang1/3024035.md) functions used a proprietary internal encryption format.. A string encrypted using the [Encrypt](../WDLang1/3024014.md) algorithm cannot therefore be decrypted using the usual algorithms to which the **DecryptStandard** function.

To change your encryption solution, you must: 

1. decrypt all current encrypted data (function [Decrypt](../WDLang1/3024035.md))

2. encrypt this data with function [EncryptStandard](../WDLang1/1000021293.md) and a new algorithm.
