


## &lt;picLayer variable&gt;.ChangeMode (Function)

***In french: &lt;Variable picCalque&gt;.ChangeMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the drawing mode on a variable of type [picLayer](../WDLang1/1000024604.md). This drawing mode is used by the drawing functions ([&lt;picLayer variable&gt;.DrawLine](../WDLang1/1000024495.md), [&lt;picLayer variable&gt;.DrawRectangle](../WDLang1/1000024564.md), etc.).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyImage is WDPic = "Test.bmp"
MyLayer is picLayer

// Draws a rectangle in a layer and erases it
MyLayer.ChangeMode(drawXOR)
// Displays the rectangle (in XOR mode)
MyLayer.DrawRectangle(0, 0, 100, 100)
Multitask(10)
// Erases the rectangle
MyLayer.DrawRectangle(0, 0, 100, 100)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<picLayer image>.ChangeMode(<New mode>)`
---

**`<picLayer image>: (picLayer variable)`**

Name of the [picLayer](../WDLang1/1000024604.md) variable to be used.

**`<New mode>: (Integer constant)`**

Mode for drawing in the image:



|   |   |
| --- | --- |
| *drawAntiAliasing* | Uses the GDI+ and/or the features of the video card to draw the lines and the circles without jagged effects. This drawing mode is slower but the results are better than with the standard mode.<br>![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Constant not available.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) This drawing mode is not supported. |
| *drawDefault* | Standard colors. |
| *drawXOR* | Colors applied via an "exclusive or" operation with the background. Erases a drawing if this option is used twice.<br>WARNING: This drawing mode is not compatible with opacity management (the drawing no longer fades)..<br>**Caution**: <br><br>- The drawing in XOR mode is available for the Image controls only. The drawing in XOR mode is not available for the [Image](../WDLang1/1000019650.md) variables. <br><br>- The *drawXOR* constant cannot be combined with the *drawAntiAliasing* constant. <br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The drawing in XOR mode only affects [&lt;picLayer variable&gt;.DrawPoint](../WDLang1/1000024500.md). |

### Anti-aliasing
<a name="antialiasing_ELTPARAGRAPHE000422"></a>The anti-aliasing consists in drawing the lines and the circles without jagged effects. This feature requires the GDI+ framework (which means the WINDEV framework).
Example:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=dchangemode.gif)
Limits:

- [&lt;picLayer variable&gt;.DrawChord](../WDLang1/1000024469.md) is not supported in this mode.

- To avoid the jagged edges, the colors and the lines of elements are smoothed out. Some drawing functions can have an unexpected behavior because the specified colors are no longer found. For example, if you specify a border color for the [&lt;picLayer variable&gt;.Fill](../WDLang1/1000024588.md) function, this color is not retrieved: the entire area is filled.

- For a drawing with anti-aliasing, [&lt;picLayer variable&gt;.DrawPolygon](../WDLang1/1000024504.md) and [&lt;picLayer variable&gt;.DrawSlice](../WDLang1/1000024561.md) have the following behavior. The contour is drawn on top of the polygon's interior: the line is therefore partly combined with the polygon's interior. If the line is very thick, it will be displayed in two colors.

- For more details on the use of GDI+, see [GDI+ framework](../Editeurs/2020007.md).

### Drawing in PHP
<a name="drawing_php_ELTPARAGRAPHE000543"></a>

In PHP, the drawing functions are based on the graphic library GD. This library is commonly used by the PHP hosting providers and therefore it is always enabled. The version of the GD library must be version 2.0.28 (or later). This library can be downloaded from the PHP site.

**To enable (if necessary) this library locally**, the following elements are required:

- PHP installed.

- the PHP.INI file found in the Windows directory must contain the following line: "extension=php_gd2.dll" (instead of ";extension=php_gd2.dll").

- the php_gd2.dll file must exist in the directory of PHP extensions. This directory is defined in the PHP.INI file by the "extension_dir" variable.

### Drawing in Browser code
<a name="drawing_browser_code_ELTPARAGRAPHE000565"></a>

Some drawing functions are available in Browser code. The drawing functions in Browser code are based on the HTML 5 standard. More specifically, these functions are based on the "canvas" tag of HTML 5.  

The drawing features in browser code are available for the recent browsers only (supporting the HTML 5 standard). To find out whether the drawing features are proposed by your browser, use [DrawingAvailable](../WDLang1/1000019483.md). 

**Please note** To use the drawing functions with Internet Explorer 9, the project must include a reference to the DTD file. To do so, the HTML mode must be "HTML 4.01 Transitional + DTD". This option is available in the "Advanced" tab of the project description window.
Reminder: To display the project description window, under the "Project" pane, in the "Project" group, click on "Description".

**Special case: Drawing in the browser of an Android phone** Browser drawing functions are only available in Android version 3 and higher.
