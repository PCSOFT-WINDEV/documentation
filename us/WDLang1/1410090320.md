
## BitcoinCoreConfigure (Function)

***In french: BitcoinCoreParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Specifies the Bitcoin Core server connection parameters, in order to use [BitcoinCoreXXXX](../WDLang1/1410090347.md) functions.

Note:To use [BitcoinCoreXXXX](../WDLang1/1410090347.md) functions, you need to configure a server on Bitcoin Core. For more details, see [Setting up and using a Bitcoin Core server](../WDLang1/1410090348.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
BitcoinCoreConfigure(btcRpcServerAddress, "192.31.15.55")
BitcoinCoreConfigure(btcRpcPortNumber, 8055)
BitcoinCoreConfigure(btcRpcUser, "bob")
BitcoinCoreConfigure(btcRpcPassword, "secret")

d is DateTime
d = BitcoinCoreDateTimeLatestBlock()
IF ErrorOccurred THEN
	Error()
	RETURN
END
Trace("Latest block: " + DateToString(d))
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`BitcoinCoreConfigure(<Parameter> , <Value>)`
---

**`<Parameter>: (Integer constant)`**

Parameter to be defined: 



|   |   |
| --- | --- |
| *btcRpcServerAddress* | Bitcoin Core server address. |
| *btcRpcUser* | Username used to log in to the Bitcoin Core server. |
| *btcRpcPassword* | Password used to log in to the Bitcoin Core server. <br><br>If this constant is used, the &lt;Value&gt; parameter can also be a secret string. In this case, the secret string can correspond to one of the following types:<br><br>- ANSI string - Latin,<br><br>- ANSI or Unicode string,<br><br>- Unicode string.<br><br><br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| *btcRpcPortNumber* | Bitcoin Core server connection port number. |
| *btcTimeout* | Bitcoin Core server connection timeout (in seconds). |



**`<Value>: (Variant)`**

Value corresponding to the specified parameter.
