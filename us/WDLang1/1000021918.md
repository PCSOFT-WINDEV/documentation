
## iCalendarToOrganizer (Function)

***In french: iCalendarVersAgenda***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Imports data in iCalendar format into an Organizer control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
siCal is ANSI string
siCal = fLoadBuffer("calendar.ics")

iCalendarToOrganizer(ORG_MyOrganizer, siCal)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`iCalendarToOrganizer(<Organizer control> , <iCalendar data>)`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window. 

- an Organizer control in a report.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) an Organizer control in a page.




**`<iCalendar data>: (ANSI character string in UTF-8 format)`**

Data in iCalendar format. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- To export data from an Organizer control in iCalendar format, use [OrganizerToiCalendar](../WDLang1/1000021919.md). 

- ![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) This function is available for the WEBDEV websites in Linux. This function is not available for WINDEV applications in Linux.
