The following constants are used to manipulate TreeView controls:

| Constant | Description | Used by the functions |
| --- | --- | --- |
| **tizButton** | Type of zone hovered over: "+ / -" button in front of the tree element label. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizCaption** | Hovered zone type: Element label. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizCheckmark** | Type of area hovered over: Element tick. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizImage** | Type of hovered area: Image in front of element label. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizLeft** | Type of area hovered over: Space to the left of the element label. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizOut** | Type of area overflown: Space below tree elements. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tizRight** | Type of area hovered over: Space to the right of the element label. | [TreeInfoXY](../WDLang1/3018026.md) |
| **treeBranchID** | Type of information requested: Element identifier at point (X,Y). | [TreeInfoXY](../WDLang1/3018026.md) |
| **treeBranchName** | Type of information requested: Name of element at point (X, Y). | [TreeInfoXY](../WDLang1/3018026.md) |
| **treeLineNumber** | Type of information requested: Line number at point (X, Y). | [TreeInfoXY](../WDLang1/3018026.md) |
| **treeOriginScreen** | If this option is specified, the origin of specified coordinates corresponds to the screen (and not the TreeView control). | [TreeInfoXY](../WDLang1/3018026.md) |
| **treeZone** | Type of information requested: Type of area overflown. | [TreeInfoXY](../WDLang1/3018026.md) |
| **tvAcceptDuplicate** | Sheet position relative to elements on the same level: duplicates are accepted. | [TreeAdd](../WDLang1/3018012.md), [TreeMoveItem](../WDLang1/3018024.md) |
| **tvAfter** | Inserted sheet position: sheet inserted after specified "sibling" element. | [TreeInsert](../WDLang1/3018023.md) |
| **tvAll** | Level of elements to be taken into account: all "threads" are taken into account. | [TreeCount](../WDLang1/3018009.md) |
| **tvAlphaSort** | Sheet position relative to elements on the same level: sheet inserted or moved in character set order. | [TreeAdd](../WDLang1/3018012.md), [TreeMoveItem](../WDLang1/3018024.md) |
| **tvBefore** | Inserted sheet position: sheet inserted before specified "sibling" element. | [TreeInsert](../WDLang1/3018023.md) |
| **tvCollapse** | Node status: wound node | [TreeStatus](../WDLang1/3018015.md) |
| **tvDefault** | Type of image associated with the sheet: default image. | [TreeAdd](../WDLang1/3018012.md), [TreeInsert](../WDLang1/3018023.md), [TreeModify](../WDLang1/3018013.md) |
| **tvDown** | Sort type: reverse sorting in character set order. | [TreeSort](../WDLang1/3018020.md) |
| **tvError** | Node status / Element type: non-existent node or element. | [TreeStatus](../WDLang1/3018015.md), [TreeTypeItem](../WDLang1/3018014.md) |
| **tvExpand** | Node status: node unrolled | [TreeStatus](../WDLang1/3018015.md) |
| **tvFirst** | Position of sheet in relation to elements on same level / Indicates desired "son": sheet inserted or moved to first place on level / First son element. | [TreeAdd](../WDLang1/3018012.md), [TreeMoveItem](../WDLang1/3018024.md)<br>[TreeGiveChild](../WDLang1/3018010.md) |
| **tvLast** | Sheet position relative to elements on the same level: sheet inserted or moved to the last position on the level. | [TreeAdd](../WDLang1/3018012.md), [TreeMoveItem](../WDLang1/3018024.md) |
| **tvLeaf** | Element type: leaf element. | [TreeTypeItem](../WDLang1/3018014.md), [TreeFind](../WDLang1/3018030.md) |
| **tvNext** | Indicates the desired "son": next son. | [TreeGiveChild](../WDLang1/3018010.md) |
| **tvNode** | Element type: node element. | [TreeTypeItem](../WDLang1/3018014.md), [TreeFind](../WDLang1/3018030.md) |
| **tvOneLevel** | Level of elements to be taken into account: only immediate "sons" are taken into account. | [TreeCount](../WDLang1/3018009.md), [TreeFind](../WDLang1/3018030.md) |
| **tvUp** | Sort order: sort by character set. | [TreeSort](../WDLang1/3018020.md) |
