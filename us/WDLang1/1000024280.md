


## &lt;Table&gt;.RestorePositionAndSelection (Function)

***In french: &lt;Table&gt;.RestaurePositionEtSélection***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Restores the scrollbar position in a Table or TreeView Table control as well as the selected elements. These elements have been saved by [&lt;Table&gt;.SavePositionAndSelection](../WDLang1/1000024283.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
SaveTable is string
SaveTable = TABLE_Table1.SavePositionAndSelection()
TABLE_Table1.Display(taInit)
TABLE_Table1.RestorePositionAndSelection(SaveTable)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Table control>.RestorePositionAndSelection([<Save>])`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This control can correspond to: 

- a Table control.

- a TreeView Table control.




**`<Save>: (Optional character string)`**

Backup characteristics returned by function [&lt;Table&gt;.SavePositionAndSelection](../WDLang1/1000024283.md). If this parameter is not specified:

- The last save performed by [&lt;Table&gt;.SavePositionAndSelection](../WDLang1/1000024283.md) on the control is used (if it exists).

- fIf the option "Remember position and selection" is checked in the control description ("Details" tab), the last value saved is used.

- Otherwise, an error occurs.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000217"></a>

**&lt;Table&gt;.RestorePositionAndSelection** can be used on:

- Table or TreeView Table controls based on a data file.

- Table or TreeView Table controls populated programmatically.

- single-selection or multi-selection controls.



<a name="NOTE0_2"></a>


### Special cases
<a name="special_cases_ELTPARAGRAPHE000233"></a>

- The name of the control used for the save ([&lt;Table&gt;.SavePositionAndSelection](../WDLang1/1000024283.md)) can differ from the name used for the restore operation. This feature can be useful to duplicate the position and the selection on two Table controls displayed alternatively for example.

- **&lt;Table&gt;.RestorePositionAndSelection** has no effect if the control is empty.

- **&lt;Table&gt;.RestorePositionAndSelection** does not work on Table controls based on a data file with ongoing movement (i.e. Table controls without proportional scrollbar).



<a name="NOTE0_3"></a>


### Equivalence
<a name="equivalence_ELTPARAGRAPHE000254"></a>

The functions [&lt;Table&gt;.SavePositionAndSelection](../WDLang1/1000024283.md) and **&lt;Table&gt;.RestorePositionAndSelection** are equivalent to the option "Remember position and selection" available in the "Details" tab of the control description.
