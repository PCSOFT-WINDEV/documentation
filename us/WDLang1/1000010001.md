


## TableExpandAll (Function)

***In french: TableDérouleTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Expands:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) the entire hierarchy (all nodes) of a TreeView Table control.

- all breaks of a Table control. 




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Breaks are not available for Table controls in this version.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) 
```wl
// Expands all nodes found in the "TVT_Schedule" TreeView Table control
TableExpandAll(TVT_Schedule)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`TableExpandAll(<Table control>)`
---

**`<Table control>: (Control name)`**

Name of the control to be used. This name can correspond to:

- the name of TreeView Table control for which all nodes will be expanded.

- the name of the Table control for which all the breaks must be expanded.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000099"></a>

**TableExpandAll** can be used on: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) a TreeView Table control.

- a Table control populated programmatically. 

- a Table control with in-memory data source.  

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) a Table control in "Server" or "Server + AJAX" mode.

- ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) a Table control in "Browser" mode.




This function cannot be used on the Table controls based on a data file (direct access). 
<a name="NOTE0_2"></a>


### TreeView Table control
<a name="treeview_table_control_ELTPARAGRAPHE000126"></a>

When **TableExpandAll** is called, if the specified branch and/or one of its children have a procedure associated via the [AddChildDelayed](../Proprietes/1000020927.md) property, this procedure will be executed.
