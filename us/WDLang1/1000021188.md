


## &lt;Radio Button&gt;.Count (Function)

***In french: &lt;Sélecteur&gt;.Occurrence***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the number of options found in a Radio Button control.

Note: This function returns the same result as the [Count](../Proprietes/2510097.md) property used on a Radio Button control.. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Number of options found in the "RADIO_Options" control
ResNumberOptions = RADIO_Options.Count()

// Identical to: 
// ResNumberOptions = RADIO_Options.Count
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Radio Button control>.Count()`
---

**`<Result>: (Integer)`**

Number of options found in the specified Radio Button control.

**`<Radio Button control>: (Control name)`**

Name of the Radio Button control to use.
