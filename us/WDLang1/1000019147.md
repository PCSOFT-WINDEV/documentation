


## OrganizerSelectMinus (Function)

***In french: AgendaSelectMoins***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deselects an appointment from an Organizer control.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Add an appointment into an Organizer control
nAppointmentIndex is int
nAppointmentIndex = OrganizerAddAppointment(ORG_MyOrganizer, ...
				"Meeting with sales team", ...
				DateSys() + "1400", DateSys() + "1600")
// Select the added appointment
OrganizerSelectPlus(ORG_MyOrganizer, nAppointmentIndex)
...
// Click the "Deselect" Button control
OrganizerSelectMinus(ORG_MyOrganizer)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Deselecting an appointment identified by its index

`OrganizerSelectMinus(<Organizer control> [, <Appointment index>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to be used. This control can be:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) an Organizer control in a window.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) an Organizer control in a page.




**`<Appointment index>: (Optional integer)`**

Index of the appointment to deselect. Appointment indexes start at 1.
If this parameter is not specified, the appointment that is currently selected is deselected.
If this parameter is specified and does not match the index of the appointment currently selected in the Organizer control, the function has no effect.


<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) 
### Deselecting an appointment identified by an Appointment variable

`OrganizerSelectMinus(<Organizer control> [, <Appointment to deselect>])`
---

**`<Organizer control>: (Control name)`**

Name of the Organizer control to use (control in a window). 

**`<Appointment to deselect>: (Optional Appointment variable)`**

Name of the [Appointment](../WDLang1/1000019244.md) that corresponds to the appointment to deselect. 
If this parameter is not specified, the appointment that is currently selected is deselected.
If this parameter is specified and does not correspond to the appointment currently selected in the Organizer control, the function has no effect.
