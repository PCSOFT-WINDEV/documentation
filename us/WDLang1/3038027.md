


## WinOutXPos (Function)

***In french: FenExtPosX***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the horizontal position of the upper-left corner of a window in relation to the upper-left corner of the screen.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **Windows**: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Fenet2.gif)
**Note**: The **WinOutXPos** function is equivalent to the [X](../Proprietes/2510135.md) property.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) **Movable windows** There are two cases to consider: 

- Maximized mobile windows: This position is always set to 0. 

- Non-maximized mobile windows and popup windows: This position corresponds to the [X](../Proprietes/2510135.md) property.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
//Horizontal position of the "WIN_EditCustomer" window in relation to the screen
ResHPos = WinOutXPos(WIN_EditCustomer)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = WinOutXPos([<Window>])`
---

**`<Result>: (Integer)`**

Returns the horizontal position or X-coordinate (in pixels) of the upper-left corner of a window in relation to the upper-left corner of the screen.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png) If you are manipulating a maximized mobile window, this position is set to 0.

**`<Window>: (Optional window name)`**

Name or alias of the window to be used. If this parameter is not specified or is an empty string (""), the horizontal position of the current window is returned.
