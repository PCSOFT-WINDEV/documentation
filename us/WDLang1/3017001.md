


## AnimationSetMode (Function)

***In french: AnimationChangeType***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the type of animation:

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) for an image in an Image control.

- for a text in a Static Text control.




The parameters specific to the new type can be modified by [AnimationSetParameter](../WDLang1/3017002.md).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) In this version, you can only change the type of animation used for a text in a Static Text control.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Changes the animation of the IMG_Image1 control
IMG_Image1.Animation = True
AnimationSetMode(IMG_Image1, actScrolling)
```
<a name="Exemple2"></a>

```wl
// Change the animation parameters of a Static Text control
STC_MyStatic.Animation = True
AnimationSetMode(STC_MyStatic, actBlinking)
AnimationSetParameter(STC_MyStatic, acpDuration, 100)
AnimationSetParameter(STC_MyStatic, acpColor, DarkBlue)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`AnimationSetMode(<Control used> , <Type of animation>)`
---

**`<Control used>: (Control name)`**

Name of the image control or static control to use.

**`<Type of animation>: (Constant or character string)`**

Animation to perform.



|   |   |
| --- | --- |
| *actBlinking* (or "Blinking") | The static is alternately displayed in its default color and in its flashing color. |
| *actScrolling* (or "Scrolling") | The image (or the text) is displayed progressively, from the right, from the left, and so on.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant can be used with the Static Text controls only. |
| *actWinDevAnimation* (or "Image to animate") | The image is divided into several drawings. Each drawing is displayed successively, giving an illusion of video. <br>This constant can only be used with Image controls.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Changing the type of animation
<a name="changing_the_type_animation_ELTPARAGRAPHE000165"></a>

If the new type corresponds to the current type, the parameters specific to this type are reinitialized with the default parameters.
<a name="NOTE0_2"></a>


### Stopping or restarting an animation
<a name="stopping_restarting_animation_ELTPARAGRAPHE000174"></a>

The animation can be enabled or disabled with the [Animation](../Proprietes/2510006.md) property.
<a name="NOTE0_3"></a>
![Reports and Queries](https://doc.pcsoft.fr/ext/images/us/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/us/WINDOWS.png)![User code (UMC)](https://doc.pcsoft.fr/ext/images/us/MCU.png) 

### Images that use an animated format
<a name="images_that_use_animated_format_ELTPARAGRAPHE000188"></a>

**AnimationSetMode** has no effect on images that use an animated format. Therefore, for an image in animated GIF format, the parameters are read in the file and they cannot be modified.
