
## HexaToBuffer (Function)

***In french: HexaVersBuffer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Converts a string with hexadecimal bytes to a binary buffer.

**Note** To convert a buffer to a hexadecimal string, use the [BufferToHexa](../WDLang1/1000019916.md) function.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
s is string = "61 00 62 00 64 00 63 00 65 00 66 00 67 00 68 00<\r><\n>69 00 6A 00 6B 00 6C 00"
buf is Buffer 
buf = HexaToBuffer(s)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HexaToBuffer(<Hexadecimal value> [, <Nb bytes per word> [, <Option>]])`
---

**`<Result>: (Buffer)`**

Conversion result.

**`<Hexadecimal value>: (Character string)`**

Hexadecimal value to convert. 

**`<Nb bytes per word>: (Optional integer or constant)`**

Format for grouping values in &lt;Hexadecimal value&gt;. Can correspond to: 

- 1 (default): values are grouped by byte. For example: 61 00 62 12.

- 2: values are grouped in 2-byte words. For example: 6100 6212. 

- 4: values are grouped in double 4-byte words. For example: 61006212. 

- the *constant No*Grouping: no grouping will be performed. All hexadecimal codes are written without spaces in the &lt;Hexadecimal value&gt; parameter. Example: 61002345A1. 




**`<Option>: (Optional Integer constant)`**

By default, &lt;Hexadecimal value&gt; is grouped according to the Little-Endian format (most significant bytes at the end, like in x86). 
To manage a grouping in Big-Endian format, use the *BigEndian* constant.
