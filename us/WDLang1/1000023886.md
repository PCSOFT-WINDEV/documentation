


## &lt;Window&gt;.Maximize (Function)

***In french: &lt;Fenêtre&gt;.Maximise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Displays a WINDEV window in its maximum size.

**Note** The function **&lt;Window&gt;.Maximize** function performs the same action as the enlarge button in the top right-hand corner of windows.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Display the "WIN_EditCustomer" window in its maximum size
WIN_CustomerInput.Maximize()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Window>.Maximize()`
---

**`<Window>: (Window name)`**

Name of the window that must be displayed in its maximum size.
