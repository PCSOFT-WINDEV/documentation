
## &lt;Windows&gt;.OpenSibling (Function)

***In french: &lt;Fenêtre&gt;.OuvreSoeur***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a non-modal sibling window. 

The following operations are performed when **&lt;Windows&gt;.OpenSibling** is called:

- "Global declarations" event of the sibling window,

- "Initialization" events of controls (in any order),

- code after the call to **&lt;Windows&gt;.OpenSibling** of the calling window,

- display the sibling window.




**Remarks**:

- By default, the sibling window retains focus once it is opened.

- **&lt;Windows&gt;.OpenSibling** can also be used to define the position and pass parameters to the sibling window.

	- In standard syntax, these parameters are passed directly. 

	- When you use a variable of type  to open a window, you can use the  property to define the characteristics of the window, and the  property to pass parameters.

## Example


```wl
// Open the sibling window named "WIN_EditWindow"
// without positioning and without passing parameters
WIN_EditWindow.OpenSibling()
```

## Syntax

### Opening a sibling window (standard syntax)

`<Window name>.OpenSister([<Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window name>: (Window name)`**



- Name of sibling window to open.

- Name and full path of sibling window (".WDW" file) to open. 
	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) You cannot specify the full name of the file to open (".WDW" file).




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).


<a name="SYNTAXE2"></a>
![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This syntax is only available for Java applications
### Opening a sibling window (with a Window variable)

`OpenSister(<Window to open> [, <Parameter 1> [... [, <Parameter N>]]])`
---

**`<Window to open>: (Window variable)`**

Name of the [Window](../WDLang1/1410091366.md) variable corresponding to the window to be opened. 

- The window opening options must have been defined using the [OpeningOptions](../Proprietes/1410091299.md) property. 

- The value of the parameters expected by the window must have been defined using the [OpeningParameters](../Proprietes/1410091044.md) property.




**`<Parameter 1>: (Type of value sent to the window (optional))`**

First parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.



**`<Parameter N>: (Type of value sent to the window (optional))`**

Nth parameter to be passed to the "Global declarations" event of the window to open. This parameter is passed by value and is considered a variable global to the window.
This parameter cannot be a variable of type array (arrays can only be passed by reference).

Note: Parameter values can also be defined using the [OpeningParameters](../Proprietes/1410091044.md) property, which can be used in conjunction with a variable of type Window.

## Remarks


### Parameters passed to the window to open
<a name="parameters_passed_the_window_open_ELTPARAGRAPHE000336"></a>The parameters are retrieved in the "Global declarations" event associated with  the window. The first line of code of this event must correspond to the following line:


```txt
PROCEDURE <Window> (<Parameter 1> [, ... [, <Parameter N>]])
```
where: 

- &lt;Window&gt; must correspond to the name of the window. 

- &lt;Parameter N&gt; must correspond to the parameters expected. **Note: These parameters are passed by value, not by reference.**


For more details, see [Window with parameters](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Window opening mode
<a name="window_opening_mode_ELTPARAGRAPHE000366"></a>

The window opens as a non-modal window:

- the parent window remains the current window.

- once the sibling window is opened, the processes following the call to **&lt;Windows&gt;.OpenSibling** in the calling window are run.

- the user will have the ability to click one of the parent windows of current window.


![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) To manage MDI, use [&lt;Window&gt;.MDIOpen](../WDLang1/3052007.md).
<a name="NOTE0_3"></a>


### Opening the same window several times
<a name="opening_the_same_window_several_times_ELTPARAGRAPHE000391"></a>

- If the same window is opened several time, we recommend that you use an alias. This alias is used to differentiate between each window.

- The position of the calling window (relative to the screen or to the sibling window) is chosen when the window is described in the editor. If the same window is opened several times (with an alias), the display positions must be modified at each opening (otherwise the windows will be stacked).

- The number of windows that can be opened simultaneously depends on the available memory.



<a name="NOTE0_4"></a>


### Closing a window
<a name="closing_window_ELTPARAGRAPHE000403"></a>

A window opened with **&lt;Windows&gt;.OpenSibling** can be closed with [Close](../WDLang1/3038018.md) (without parameters) from any event:

- of the window,

- of a window control.



<a name="NOTE0_5"></a>


### Title of the window to be opened
<a name="title_the_window_opened_ELTPARAGRAPHE000423"></a>

By default, the window title is the one defined in the editor (in the "General" tab of the description window).

To change the window title:

- In standard syntax, use [NextTitle](../WDLang1/3038043.md) or [CurrentTitle](../WDLang1/3038023.md).

- With a variable of type [Window](../WDLang1/1410091366.md), use the [OpeningOptions](../Proprietes/1410091299.md) property (**OpeningOptions.Title**).

### Opening the window of a component
<a name="opening_the_window_component_ELTPARAGRAPHE000465"></a>To open the window of a component, simply use the name of the component window (component included in the project). For example:


```wl
OpenSibling(ComponentWindow)
```
If a conflict occurs with a project element, the element name must be prefixed by the component name. For example:


```wl
OpenSibling(MyComponent.Window)
```
To use the name of the window in a variable, the name of the component must be specified. For example:


```wl
sWindow is string = "MyComponent.MyWindow"
OpenSibling(sWindow)
```
