


## docParagraph (Variable type)

***In french: docParagraphe***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **docParagraph** type is used to handle the characteristics of a paragraph in a DOCX document. You can define and change the characteristics of this paragraph using different WLanguage functions and properties. 

This type of variable is used by [Document](../WDLang1/1000022461.md) variables. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WP_MyDoc = DocOpen(fExeDir() + fSep() + "MyDoc.docx") 
TextFragment is docFragment(WP_MyDoc, 1, Length(DocToText(WP_MyDoc)))
FOR EACH MyCurrentElement OF TextFragment.Element
	MyParagraph is docParagraph = MyCurrentElement.Paragraph
	Trace(MyParagraph.StartPosition)
	Trace(MyParagraph.EndPosition)
END
```

## Properties


### Properties specific to docParagraph variables
<a name="properties_specific_docparagraph_variables_ELTPARAGRAPHE000032"></a>

The following properties can be used to define the characteristics of **docParagraph** variables:

| --- | --- | --- |
| **Property name** | Type used | Effect |
| Cell | [docCell](../WDLang1/1000022927.md) variable | Used to access the cell of parent table. |
| StartSection | Integer constant | Section break to apply before the paragraph. Can correspond to one of the following constants: <br><br>- *ssAucunSaut*: No section break before the paragraph. <br><br>- *ssSectionJump* A section break of the page break type precedes the paragraph. <br><br>- *ssContinuousSectionJump*: A continuous section break precedes the paragraph.. <br><br>- *ssOddPageSectionJump* A section break of the odd page break type precedes the paragraph. <br><br>- *ssEvenPageSectionFeed* A section break of the even page break type precedes the paragraph. <br><br><br><br><br>Remarks: <br><br>- The **EndSection** property of a paragraph returns the same value as the **StartSection** property of the next paragraph.  <br><br>- The **StartSection** property of the first paragraph returns the *ssNoBreak* constant.<br><br><br> |
| RightToLeft | Boolean | <br><br>- <u><u><u>True</u></u></u> if the actual writing direction goes from right to left, <br><br>- <u><u><u>False</u></u></u> if the actual writing direction goes from left to right.  <br><br><br> |
| Element | Array of [docElement](../WDLang1/1000022484.md) | Elements included in the paragraph. The elements found in the paragraph can be browsed via the FOR EACH statement. |
| EndSection | Integer constant | Section break to apply after the paragraph. Can correspond to one of the following constants: <br><br>- *ssAucunSaut*: No section jump after the paragraph. <br><br>- *ssSectionLeap* A section break of the page break type follows the paragraph. <br><br>- *ssContinuousSectionBreak*: A continuous section break follows the paragraph.. <br><br>- *ssOddPageSectionFeed* A section break of the odd page break type follows the paragraph. <br><br>- *ssEvenPageSectionFeed* A section break of the even page break type follows the paragraph. <br><br><br><br><br>Remarks: <br><br>- The **EndSection** property of a paragraph returns the same value as the **StartSection** property of the next paragraph. <br><br>- The **EndSection** property of the last paragraph returns the *ssNoBreak* constant. <br><br><br> |

|   | PageLayout.IndentFirstLine | Real | Indent of first line in paragraph (expressed in millimeters). <br><br>This property is set to 0 by default. |
