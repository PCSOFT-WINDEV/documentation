
## fWatchFile (Function)

***In french: fSurveilleFichier***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (73)</B>, ***fTrackFile*</**>** is kept for backward compatibility. This function has been replaced with ***fWatchFile*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts watching a file. In case of file modification, a specific procedure is run in a thread. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Name of the file to watch
sFileName is string = "C:\Temp\MyDir\MyFile.extension"
// The ProcessModification procedure will be called when the 
// "C:\Temp\MyDir\MyFile.extension" file is modified.
IF fWatchFile(sFileName, fWatchFile_Callback, ...
		fwCreateFile + fwModifyFile + fwDeleteFile +  ...
		fwRename) THEN
	// Notifies the user that the file will be watched
	Info("The " + sFileName + " file will be watched.")
ELSE
	// Notifies the user that the file will not be watched
	Info("The " + sFileName + " file will not be watched.")
END

// Code of the internal procedure
INTERNAL PROCEDURE fFileMonitor_Callback(sCompleteName, sFileMonitorName, nAction, sOldFileName)
	sActionDesignation is string
	// The designation of the action depends on nAction
	SWITCH nAction
		CASE fsFileCreation: sDesignationAction = "File creation".
		CASE fsDeleteFile: sDesignationAction = "Delete file".
		CASE fsFileModification: sDesignationAction = "File modification".
		CASE fsRename: sDesignationAction = "Rename file".
	END
	// Add a line containing the information about the modification 
	// in the TABLE_MODIFICATIONS control
	TableAddLine(TABLE_MODIFICATIONS, sFullName, sWatchedFileName, ...
		sActionDesignation, sOldFileName)
END
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = fWatchFile(<File to watch> , <WLanguage procedure> [, <Changes to notify>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if file watching is enabled, 

- <u><u><u><u>False</u></u></u></u> otherwise. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<File to watch>: (Character string)`**

Full name of the file to be watched.

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure ("callback") called when a change is made to the specified file.

For more details on this procedure, see [Parameters of the procedure used by fWatchFile](../WDLang1/1000025349.md). 

**`<Changes to notify>: (Optional Integer constant (or combination of constants))`**

Changes made to the watched file and for which the procedure is to be executed: 


|   |   |
| --- | --- |
| *fwAll* | All actions are watched. Corresponds to *fwCreateFile* + *fwModifyFile* + *fwRename* + *fwDeleteFile*.<br><br>Before version 2024 Update 2, this constant was named *ftAll*. |
| *fwCreateFile* | Creation of &lt;File to watch&gt;.<br><br>Before version 2024 Update 2, this constant was named *ftCreateFile*. |
| *fwDeleteFile* | Deletion of &lt;File to watch&gt;.<br><br>Before version 2024 Update 2, this constant was named *ftDeleteFile*. |
| *fwModifyFile* | Modification of &lt;File to watch&gt;.<br><br>Before version 2024 Update 2, this constant was named *ftModifyFile*. |
| *fwRename* | Renaming of &lt;File to watch&gt;.<br><br>Before version 2024 Update 2, this constant was named *ftRename*. |

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000109"></a>

- To stop watching the file, use [fWatchStop](../WDLang1/1000020575.md) and [fWatchStopAll](../WDLang1/1000020576.md).

- To watch changes made to the contents of a directory, use [fWatchDirectory](../WDLang1/1000020523.md).

- Limitations: 

	- Only 5 files can be watched at the same time.

	- It is not possible to watch a file located at the root of a disk (for performance reasons).  






<a name="NOTE0_2"></a>


### WLanguage procedure
<a name="wlanguage_procedure_ELTPARAGRAPHE000130"></a>

The WLanguage procedure is run in a WLanguage thread.
Please note: the following processes cannot be run in threads:

- opening windows with WLanguage functions such as [Open](../WDLang1/3038035.md), [Use](../WDLang1/3038044.md), [Close](../WDLang1/3038018.md), etc. A specific management mode must be implemented if some windows must be handled in threads (rare case). For more details, see [Opening a window in a secondary thread](../WDLang1/3077015.md). 

- managing events.

- managing timers.




For more details on threads, see [Managing threads](../WDLang1/3077026.md).
