
## ThreadEnd (Function)

***In french: ThreadFin***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>

## Remarks


- If the current thread is the main thread, both **ThreadEnd** and [EndProgram](../WDLang1/3013033.md) stop the application. 




- **To stop a secondary thread**:

	- First method: 

		- Call [ThreadRequestStop](../WDLang1/1000021218.md) from the thread that should request the stop. The secondary thread will not be stopped automatically. 

		- The code of the secondary thread must use [ThreadStopRequested](../WDLang1/1000021219.md) to check if the stop has been requested. If so, the thread must be properly stopped by terminating the current code or by calling **ThreadEnd**.




- Second method: Implement a stop system using **ThreadEnd**. You have the ability to: 

	- Declare a global variable of type Boolean in the main thread. This variable determines whether the secondary thread must be stopped. 

	- In the secondary thread, check the value of the variable. If this value is set to <u><u><u><u>True</u></u></u></u>, use **ThreadEnd** to terminate the current secondary thread. 

	- In main the thread, set the variable to <u><u><u><u>True</u></u></u></u> to force the secondary thread to stop.
