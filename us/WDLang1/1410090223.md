
## Belgium.CheckTaxNumber (Function)

***In french: Belgique.VérifieNuméroFiscal***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the validity of a Belgian tax number.

Note: The tax number corresponds to the NISS for individuals and the BCE for companies. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Check a variable 
MyTaxNumber is string = "0436649062"
Belgium.CheckTaxNumber(MyTaxNumber) // Returns True
 
// Check a control 
EDT_TaxNumber = "ABC"
Belgium.CheckTaxNumber(EDT_TaxNumber) // Returns False
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = Belgium.CheckTaxNumber(<Number to check>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified element contains a valid tax number.

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Number to check>: (Control name or string variable)`**

Tax number to check. This parameter can correspond to:

- the name of a string variable.

- the name of a control.
