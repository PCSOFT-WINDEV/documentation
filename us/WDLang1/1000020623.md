


## PVTExpandAll (Function)

***In french: TCDDérouleTout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Expands all row and/or column headers in a Pivot Table control. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Loads the data file
PVTLoad(PVT_Statistics, sFile)
// Expands all headers of the Pivot Table control
PVTExpandAll(PVT_Statistics)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`PVTExpandAll(<Pivot Table control> [, <Type of header>])`
---

**`<Pivot Table control>: (Control name)`**

Name of the Pivot Table control to be used. This Pivot Table control must have been populated using [PVTCalculateAll](../WDLang1/1000020539.md) or [PVTLoad](../WDLang1/1000020507.md). 

**`<Type of header>: (Optional Integer constant (or combination of constants))`**

Type of the header to expand: 


|   |   |
| --- | --- |
| *pvtColumnHeader* | Expands the column headers. |
| *pvtRowHeader* | Expands the row headers. |


If this parameter is not specified, row headers **AND** column headers are expanded.
