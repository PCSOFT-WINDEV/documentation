


## Bitwise operation functions
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


The following functions can be used for bitwise operations:



|   |   |
| --- | --- |
| [BitwiseAND](../WDLang1/3050010.md) | Returns the result of a bitwise AND operation performed between two values. |
| [BitwiseNOT](../WDLang1/3050011.md) | Returns the result of a bitwise NOT operation performed on a value. |
| [BitwiseOR](../WDLang1/3050038.md) | Returns the result of the bitwise OR operation performed between two values. |
| [BitwiseXOR](../WDLang1/3050023.md) | Returns the result of a bitwise exclusive OR operation performed between two values. |
