
## AIChatLoadConversation (Function)

***In french: ChatIAChargeConversation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a conversation into an AI Chat control. This conversation must have been saved with [AIChatSaveConversation](../WDLang1/1410091364.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// "Load conversation" button
AIChatLoadConversation(AICHAT_MyChat, "Conversation1.json")
IF ErrorOccurred THEN
	Error()
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = AIChatLoadConversation(<AI Chat control> , <Conversation>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the conversation was loaded. 

- <u><u><u><u>False</u></u></u></u> otherwise. [ErrorInfo](../WDLang1/3013008.md) returns the cause of the error.




**`<AI Chat control>: (Control name)`**

Name of the AI Chat control used. 

**`<Conversation>: (Character string or Buffer)`**

Conversation to load. This conversation can correspond to:

- the full or relative path of the file containing the conversation.  

- a buffer. 


This conversation must have been saved with [AIChatSaveConversation](../WDLang1/1410091364.md).
