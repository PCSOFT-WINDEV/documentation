
## fInsertTextAtBeginning (Function)

***In french: fInsèreTexteAuDébut***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Inserts text at the beginning of a file without overwriting the existing text.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// File path
FileNameAndPath = "C:\MyDirectories\File.txt"
// String to insert
sStringToWrite is string
sStringToWrite = "This is the text that will be inserted at the beginning of the file"
// Insert at the beginning
let bInsert_success = fInsertTextAtBeginning(sFilePath, sStringToWrite)
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = fInsertTextAtBeginning(<File path> , <Text>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the insertion was performed,

- <u><u><u><u>False</u></u></u></u> otherwise. 




**`<File path>: (Character string)`**

Name and full (or relative) path of file (up to 260 characters). A UNC path can be used.

The file is automatically created if it does not exist. 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This parameter can correspond to a full path or a path relative to the current directory (returned by [fCurrentDir](../WDLang1/3036022.md)). This parameter is case-sensitive. 
**Reminder**: On iPhone/iPad, an application has the rights to write into its setup directory or into one of its subdirectories.

**`<Text>: (Character string)`**

Text to Insert.
