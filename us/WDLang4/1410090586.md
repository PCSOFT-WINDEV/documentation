


## &lt;PolygonGeo variable&gt;.Union (Function)

***In french: &lt;Variable PolygoneGéo&gt;.Union***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Returns a geometry corresponding to the union between a geographic polygon and another geometry. 

**Note**: If the type of the geometries passed as parameters is known, then the type of the result is also pre-determined. Most geospatial applications don't support columns with heterogeneous data (points, lines or polygons within a single item of type "Geometry"), so there's generally no need to check the type of geometry returned by the function.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Union(<Geometry B>)`
---

**`<Result>: (Variable of type MultiPoint2D, MultiPointGeo, MultiLinestring2D, MultiLinestringGeo, MultiPolygon2D or MultiPolygonGeo)`**

Union result. This geometry contains a collection of geometries of a given type: 

- [MultiPoint2D](../WDLang4/1410090129.md) or [MultiPointGeo](../WDLang4/1410090130.md), 

- [MultiLinestring2D](../WDLang4/1410090131.md) or [MultiLinestringGeo](../WDLang4/1410090133.md), 

- [MultiPolygon2D](../WDLang4/1410090135.md) or [MultiPolygonGeo](../WDLang4/1410090136.md). 


If the union between two geometries consists of a single element, the collection will contain a single element.
If the union is empty (e.g., union of two empty multipolygons), the collection will be empty.
If the result of the union is disjoint (e.g. union of two disjoint geometries), the collection will contain several elements.

**`<Geometry A>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Second geometry taken into account for the union. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).
