


## HClusterParameter (Function)

***In french: HClusterParamètre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads and modifies the parameters of an HFSQL cluster.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Read the DNS name of server
sDNS is string 
sDNS = HClusterParameter("clustermanager.mydomain.com", "secret", hCPDNS)
InfoBuild("Use <%1> as server address in your client applications" + ...
    " to connect to the cluster.", sDNS)
```


## Syntax

### Finding out the value of a cluster parameter

`<Result> = HClusterParameter(<Coordinator> , <Password> , <Parameter>)`
---

**`<Result>: (Character string)`**

Parameter value. 

**`<Coordinator>: (Character string)`**

DNS name of the cluster coordinator's machine.

**`<Password>: (Character string or Secret string)`**

Password used to connect to the coordinator. This password was supplied at the time of [installing the cluster](../WDLang4/1000019031.md).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Parameter>: (Integer constant)`**

Parameter to read. The possible values are:



|   |   |
| --- | --- |
| *hCPClientPort* | Listening port of client connections.<br><br>**Remark**: This parameter will be modified the next time the cluster is restarted. |
| *hCPDNS* | Cluster DNS name. This parameter is for information only.<br><br>**Note** It is important not to confuse:<br><br>- cluster name (corresponding to the value associated with this parameter): name used to access cluster databases.<br><br>- coordinator name (used in parameter &lt;Coordinateur&gt;): name (DNS) of the machine on which the cluster coordinator has been installed.<br><br>- node name (not used by this function): name (DNS) of the machine on which the new HFSQL server has been installed.<br><br><br> |
| *hCTelemetryActive* | Parameter &lt;Active&gt; in the TELEMETRY section of the clustermanager.conf file<br>Data transmission configuration for HFSQL Cluster enhancement.<br>Value:<br><br>- 1, if data transmission (telemetry) was enabled when the HFSQL Cluster was installed,<br><br>- 0, if data transmission (telemetry) was refused when the HFSQL Cluster was installed,<br><br>- another value if no choice was made during the setup regarding the use of telemetry. This question will be asked again the next time you install the HFSQL Cluster.<br><br><br>**Note** If the "TELEMETRY" section does not exist in the clustermanager.conf file, transmission of product usage data is not enabled for the HFSQL Cluster. |





### Modifying the value of a cluster parameter

`<Result> = HClusterParameter(<Coordinator> , <Password> , <Parameter> [, <New value>])`
---

**`<Result>: (Character string)`**

Former value of parameter.

**`<Coordinator>: (Character string)`**

DNS name of the cluster coordinator's machine.

**`<Password>: (Character string or Secret string)`**

Password used to connect to the coordinator. This password was supplied at the time of [installing the cluster](../WDLang4/1000019031.md).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Parameter>: (Integer constant)`**

Parameter to modify. The possible values are:



|   |   |
| --- | --- |
| *hCPClientPort* | Listening port of client connections.<br><br>**Remark**: This parameter will be modified the next time the cluster is restarted. |
| *hCPDNS* | Cluster DNS name. This parameter is for information only.<br><br>**Note** It is important not to confuse:<br><br>- cluster name (corresponding to the value associated with this parameter): name used to access cluster databases.<br><br>- coordinator name (used in parameter &lt;Coordinateur&gt;): name (DNS) of the machine on which the cluster coordinator has been installed.<br><br>- node name (not used by this function): name (DNS) of the machine on which the new HFSQL server has been installed.<br><br><br> |
| *hCTelemetryActive* | Parameter &lt;Active&gt; in the TELEMETRY section of the clustermanager.conf file<br>Data transmission configuration for HFSQL Cluster enhancement.<br>Value:<br><br>- 1, if data transmission (telemetry) was enabled when the HFSQL Cluster was installed,<br><br>- 0, if data transmission (telemetry) was refused when the HFSQL Cluster was installed,<br><br>- another value if no choice was made during the setup regarding the use of telemetry. This question will be asked again the next time you install the HFSQL Cluster.<br><br><br>**Note** If the "TELEMETRY" section does not exist in the clustermanager.conf file, transmission of product usage data is not enabled for the HFSQL Cluster. |



**`<New value>: (Optional character string)`**

New value for the parameter.
