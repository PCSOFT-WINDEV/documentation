


## &lt;Source&gt;.Read (Function)

***In french: &lt;Source&gt;.Lit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Reads a record in a data file according to a given record number. This read mode is called "Direct access". The record read is loaded in memory. [&lt;Source&gt;.State](../WDLang4/1000024943.md) is used to find out the record status (active, crossed or deleted).

In most cases, **&lt;Source&gt;.Read** is used to position in the data file in order to perform a read loop by specifying the record number.

Several cases may occur after the call to **&lt;Source&gt;.Read**:

- the specified record number does not exist (greater than the total number of records or negative): no reading is performed and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.

- the specified record number no longer exists (record scratched, deleted, etc.): no playback is performed and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>False</u></u></u>.
	Use [&lt;Source&gt;.State](../WDLang4/1000024943.md) to find out the record status.

- the data file is empty: function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.

- the function attempts to block a record already blocked in play mode: function [HErrorLock](../WDLang4/3044099.md) returns <u><u><u>True</u></u></u> and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: lock management is not supported for databases that are accessed through JDBC.




This function can be used with the data files (indexed or not) and with the HFSQL views.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Sequential iteration to display the name of all customers
i is int
FOR i = 1 _TO_ Customer.NbRec(hStateAll)
	Customer.Read(i)
	IF Customer.State() = hStateActive THEN 
		Info("Customer name: " + Customer.Name)
	END
END
```

## Syntax

`<Result> = <Source>.Read([<Record number> [, <Options>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the record was read,

- <u><u><u><u>False</u></u></u></u> in the event of an error (block, end of data file, etc.): the record is not read. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Source>: (Type corresponding to the specified source)`**

Name of the HFSQL data file, view or query used.

**`<Record number>: (Optional integer)`**

Number of the record to read.

If this parameter is not specified (or is equal to 0 or to the *hCurrentRecNum* constant), **&lt;Source&gt;.Read** will read the current record.
![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) **&lt;Source&gt;.Read** reads the current record only. You cannot specify a record number other than the current one. To specify the current record number, use the *hCurrentRecNum* constant.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Access via JDBC: The **&lt;Source&gt;.Read FUNCTION** function reads only the current Record. You cannot specify a record number other than the current one. To specify the current record, use the *hCurrentRecNum* constant. 

**`<Options>: (Optional constant)`**

Configures the lock set on the record read by **&lt;Source&gt;.Read**:


|   |   |
| --- | --- |
| *hLockNo* | No blocking: the Record can be played back or modified by another application during playback. |
| *hLockReadWrite* | Read/write lock: the record being read cannot be read or modified by another application. |
| *hLockWrite* | Write lock: the record currently read can be read by another application but it cannot be modified by another application. |

![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) The lock options are ignored. Use locking functions ([&lt;Source&gt;.LockRecNum](../WDLang4/1000024197.md)) kept for backward compatibility.![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The lock options will have no effect if the locks are not supported by the OLE DB provider or by the Native Connector.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Access through JDBC: This parameter is ignored.

### Records read
<a name="records_read_ELTPARAGRAPHE000355"></a>

**&lt;Source&gt;.Read** is the only function that can be used to access a crossed or deleted record. If the record is deleted, the content of the record is not valid anymore.
<a name="NOTE0_2"></a>


### Looping through a data file
<a name="looping_through_data_file_ELTPARAGRAPHE000367"></a>

**&lt;Source&gt;.Read** cannot be used to continue an iteration started by [&lt;Source&gt;.ReadFirst](../WDLang4/1000025022.md), [&lt;Source&gt;.ReadNext](../WDLang4/1000025035.md).
<a name="NOTE0_3"></a>


### Memos
<a name="memos_ELTPARAGRAPHE000389"></a>

The memos associated with the record can be automatically read (or not) when reading the record. [&lt;Source&gt;.SetMemo](../WDLang4/1000024987.md) is used to customize this automatic read operation.

If the memos are supported, the associated text memos are read when the record is read. The binary memos are read only when they are explicitly used ([&lt;Source&gt;.ExtractMemo](../WDLang4/1000024957.md)).

### Locks
<a name="locks_ELTPARAGRAPHE000413"></a>

By default (&lt;Options&gt; not specified), the record is not locked.

If a lock is requested (*hLockWrite* or *hLockReadWrite* constant), the record will be read only if this record is not already locked.

![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The lock options will have no effect if the locks are not supported by the OLE DB provider or by the Native Connector.
<a name="NOTE0_5"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000429"></a>

- The result of [&lt;Source&gt;.Found](../WDLang4/1000025076.md) must be ignored ([&lt;Source&gt;.Found](../WDLang4/1000025076.md) must be used for the searches performed by [&lt;Source&gt;.ReadSeekFirst](../WDLang4/1000025034.md) and [&lt;Source&gt;.ReadSeekLast](../WDLang4/1000025024.md)).

- [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md) returns the current record number. The first record found in the data file is record #1.

- This function replaces **HReadLock** and **HReadNoLock**, which were kept for compatibility with WINDEV 5.5.
