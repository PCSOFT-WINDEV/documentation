
## HDescribeSemanticIndex (Function)

***In french: HDécritIndexSémantique***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de définir un index sémantique
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MonIndexSemantic est une Description d'IndexSémantic



HDécritIndexSemantic(UnFichier, MonIndexSemantic)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HDécritIndexSémantique(<Fichier> , <Description>)`
---

**`<Fichier>: (Chaîne de caractères)`**

est de type Description Fichier HF

**`<Description>: (Variable de type IndexSémantique)`**

est de type IndexSémantique
