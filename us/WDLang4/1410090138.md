


## GeometryContain (Function)

***In french: GéométrieContient***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines if geometry A contains geometry B. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=FormeContient.gif)
**Remarks**: 

- If geometry A "contains" geometry B, this means that geometry B lies completely inside geometry A. In this case: 

	- No point of geometry B lies outside geometry A. All points of geometry B are either in the interior or on the boundary of geometry A.

	- The interiors of A and B have at least one point in common.




- Difference compared with [GeometryCover](../WDLang4/1410090140.md): With [GeometryCover](../WDLang4/1410090140.md), the interiors of both geometries must not necessarily have a point in common. A polygon covers its own boundary, but it does not contain it.

## Example


```wl
o2DPolygon_1 is Polygon2D
Linestring2DAddPoint(o2DPolygon_1.Outline, -4.00, -4.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, -4.00, 2.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 5.00, 2.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 5.00, -4.00)
// Add last point (same as first)
Linestring2DAddPoint(o2DPolygon_1.Outline, -4.00, -4.00)

o2DPolygon_2 is Polygon2D
Linestring2DAddPoint(o2DPolygon_2.Outline, -1.00, -2.00)
Linestring2DAddPoint(o2DPolygon_2.Outline, 2.00, 0.00)
Linestring2DAddPoint(o2DPolygon_2.Outline, 2.00, -2.00)
// Add last point (same as first)
Linestring2DAddPoint(o2DPolygon_2.Outline, -1.00, -2.00)

let p2_in_p1 = GeometryContain(o2DPolygon_1, o2DPolygon_2) // Returns "True"
GeometryWithin(o2DPolygon_2, o2DPolygon_1) // Returns "True"
```

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GeometryContain(<Geometry A> , <Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if geometry A contains geometry B,

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Variable containing spatial data)`**

Variable corresponding to the geometry for which we want to determine if it contains geometry B. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

## Remarks


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000352"></a>

In a data file, you can apply a filter on spatial data and loop through the data file. For example, the filter can be based on the result of **GeometryContain**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **GeometryContain**. 

- Spatial_item is a spatial item in the data file. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire data file is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
Example: 


```wl
// Define a triangle delimiting a geographic area
// Store this triangle in a variable of type PolygonGeo 
polyGeo is PolygonGeo
LinestringGeoAddPoint(polyGeo.Outline, 0n48.8187479172765, 0n1.9550104465229536)
LinestringGeoAddPoint(polyGeo.Outline, 0n48.685649220185574, 0n2.023674998054354)
LinestringGeoAddPoint(polyGeo.Outline, 0n48.82612543243871, 0n2.2106580854197566)
polyGeo = GeometryCorrect(polyGeo)
// Search for municipalities whose territory lies entirely within the specified triangle
NumberOfRecords is int
FOR EACH MunicipalityData WHERE GeometryContain(MunicipalityData.geometry, polyGeo) 
	// Name of municipality in a trace window
	Trace(MunicipalityData.MunicipalityName)
END
```
