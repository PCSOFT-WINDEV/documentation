


## &lt;Polygon2D variable&gt;.Correct (Function)

***In french: &lt;Variable Polygone2D&gt;.Corrige***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Returns a corrected version of the specified 2D polygon. 

**Note**: Some problems can be automatically corrected, such as misaligned points in a polygon.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Correct a triangle whose exterior ring is oriented 
// counterclockwise
triangle is Polygon2D
triangle.Outline.AddPoint(-3.00, 1.00)
triangle.Outline.AddPoint(1.00, -2.00)
triangle.Outline.AddPoint(2.00, 2.00)
triangle.Outline.AddPoint(-3.00, 1.00)
Trace("triangle.IsValid() = " + triangle.IsValid()) // False

// Correction
corrected_triangle is Polygon2D
corrected_triangle = triangle.Correct()
Trace("corrected_triangle.IsValid() = " + corrected_triangle.IsValid()) // True
Trace("triangle.IsValid() = " + triangle.IsValid()) 
// Still False: The geometry passed as a parameter is not modified
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.Correct()`
---

**`<Result>: (Variable corresponding to the geometry)`**

Corrected geometry.

**`<Geometry>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.
