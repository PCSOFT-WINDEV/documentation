
## HFSQL data files exceeding 2 gigabytes 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000122"></a>
By default, the HFSQL engine allows you to manage large data files (up to 2 gigabytes). 

When the size of a data file (including its index, its full-text index and/or its memo) exceeds 2 gigabytes, a specific configuration is required in the data model editor and in the hardware.

Indeed, to manage data files exceeding 2 gigabytes, you must use:

- an operating system that handles files larger than 4 Gigabytes. The following systems do not support files larger than 4 Giga: Windows 98 and Windows Me.

- A file system that supports the files exceeding 4 gigabytes (NTFS for example in Windows). 




**Warning**: This configuration is necessary both on the seat where the data files are installed and on the seats accessing these data files. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Configuring the data files (in the data model editor)
<a name="configuring_the_data_files_the_data_model_editor_ELTTEXTE000146"></a>
To manage the data files exceeding 2 gigabytes: 

1. Display the description of the desired data file ("Data file description" option in the context menu).

2. On the "Compatibility" tab, check "Support files larger than 2 GB (recommended for operating systems later than Windows 2000 or Linux Ext2)".

3. Confirm. 




**Warning**: These data files can only be used from a seat running an operating system that supports files larger than 4 Giga.

## Using data files exceeding 2 gigabytes
<a name="using_data_files_exceeding_2_gigabytes_ELTTEXTE000170"></a>


### Dynamic description of data files
<a name="dynamic_description_data_files_ELTPARAGRAPHE000053"></a>

During the dynamic description of a data file (via the HFSQL properties and [HDescribeFile](../WDLang4/3044206.md)), the management mode of the file size can be configured by [HugeFile](../Proprietes/2512037.md).
<a name="NOTE3_2"></a>


### WLanguage property

|   |   |
| --- | --- |
| [HugeFile](../Proprietes/2512037.md) | The **HugeFile** property sets the maximum possible size of a data file. |




<a name="NOTE3_3"></a>


### Reindexing
<a name="reindexing_ELTPARAGRAPHE000073"></a>

**Warning** Re-indexing data files larger than 2 gigabytes can take a long time.
