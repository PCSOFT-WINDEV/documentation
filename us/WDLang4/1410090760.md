


## HDeleteSchedulingHistory (Function)

***In french: HSupprimeHistoriquePlanification***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes the executions of a scheduled job on an HFSQL server. This job can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF NOT HDeleteSchedulingHistory(MyDatabaseConnection, MyScheduledTask) THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

### Deleting the history of a scheduled backup

`<Result> = HDeleteSchedulingHistory(<Connection> , <Scheduled backup>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the history was deleted,

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Character string or Connection variable)`**

Connection to use. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 




**`<Scheduled backup>: (hBackupDescription variable)`**

Name of the [hBackupDescription](../WDLang4/1000017455.md) variable used.
