
## Accessing HFSQL data files via SAMBA on Linux
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000076"></a>
To access HFSQL data files via Samba on Linux, you need to set up specific parameters.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Specific settings
<a name="specific_settings_ELTTEXTE000100"></a>
In the **smb.conf** file found in /etc/samba, add or modify the following parameters as indicated below in the [global] section of the file.


```txt
[global]
locking = yes
strict locking = yes
share modes = yes
oplocks = no
kernel oplocks = no
blocking locks = no
fake oplocks = no
level2 oplocks = no
```


Then, restart the Samba service to take the new setting into account.
