
## IndexSemantique description (Type of variable)

***In french: Description de IndexSemantique***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de créer dynamiquement un index sémantique

Une variable de type **Description de IndexSemantique** permet de décrire par programmation un IndexSemantique.

Les caractéristiques de ce type peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MonIndexSémantique est une Description d'IndexSémantique

HDécritIndexSémantique(UnFichier, MonIndexSémantique)
```
