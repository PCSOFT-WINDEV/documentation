


## redisConnection (Variable type)

***In french: redisConnexion***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **redisConnection** type is used to define all the advanced characteristics of a connection to a Redis server (or cluster). You can define and change the characteristics of this connection using different WLanguage properties. 

This type of variable can also be used to define the characteristics of a connection to a Valkey server. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection to a server
gRedisSimple is redisConnection
gRedisSimple.Server = "myserveur:7001"
gRedisSimple.ConnectionTimeout = 1s
gRedisSimple.Password = "secret password"
```

```wl
// Connection to a cluster 
gRedisCluster is redisConnexion
gRedisCluster.Server[1] = "RedisNode1:7001"
gRedisCluster.Server[2] = "RedisNode1:7002"
gRedisCluster.Server[3] = "RedisNode2:7001"
gRedisCluster.Server[4] = "RedisNode2:7002"
```

## Properties


### Properties specific to redisConnection variables
<a name="properties_specific_redisconnection_variables_ELTPARAGRAPHE000030"></a>

The following properties can be used to manipulate a connection to a Redis server or cluster:

| Property name | Type used | Effect |
| --- | --- | --- |
| ConnectionTimeout | Duration, integer | Maximum timeout for the connection expressed in milliseconds (20 seconds by default, i.e. 20000 milliseconds). This property can correspond to: <br><br>- an integer representing the number of milliseconds,<br><br>- a Duration variable,<br><br>- the duration in a readable format (e.g., '20s' or '20000ms'). <br><br><br> |
| Password | Character string or Secret string | Password used if a connection to a Redis server requires authentication.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). |
| Server | Array of strings | Array of Redis servers.<br><br>Ability to specify multiple Redis servers. In the case of a Redis cluster, it will be possible to connect even if a node of the Redis cluster is inaccessible.<br><br>The format of the server name must be "ip:port or dnsname:port"<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png) On Linux, it is possible to use the "unix:unixdomainsocket" format to use a Unix domain socket connection. |
