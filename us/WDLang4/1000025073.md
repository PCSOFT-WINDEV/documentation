


## &lt;Source&gt;.OnError (Function)

***In french: &lt;Source&gt;.SurErreur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Customizes the management of HFSQL errors.

WINDEV, WEBDEV and WINDEV Mobile propose an automatic management of errors. The automatic management of errors can be disabled or enabled for one or more data files, for one or more types of errors. To do so, use **&lt;Source&gt;.OnError** and specify an empty string for the name of window, page or procedure. For more details, see [HFSQL error handling help](../WDLang4/3044188.md).


![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png)![Stored procedures](https://doc.pcsoft.fr/ext/images/us/PS.png) The automatic management of errors is not available for the stored procedures. 
![Stored procedures](https://doc.pcsoft.fr/ext/images/us/PS.png) **&lt;Source&gt;.OnError** can be used to manage the error in a stored procedure.

## Syntax

`<Result> = <Source>.OnError(<Type of error> [, <Procedure/window/page>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the operation was successfully performed,

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<Source>: (Type corresponding to the specified source)`**

Name of the data file used. 

**`<Type of error>: (Constant or combination of constants)`**

Type of error to configure.


|   |   |
| --- | --- |
| *hErrAll* | Configure all previous errors (except *hErrIndex*).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrConnectionLoss* | Configure the errors caused by a loss of connection with the HFSQL server. |
| *hErrDatabaseAccess* | Configures the access errors to an HFSQL Client/Server database (access forbidden by [&lt;Connection variable&gt;.NoDatabaseAccess](../WDLang4/1000022690.md)).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrDuplicates* | Configure duplicate errors.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrIndex* | Configures indexing errors (reindexing in progress during the file access).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrIntegrity* | Configure integrity errors.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrLock* | Configure lock errors.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrModify* | Configure a modification conflict.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrNeedValue* | Configure errors caused by a required value that has not been specified (OLE DB and some Native Connectors).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *hErrPassword* | Configure password errors (wrong password).<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |



**`<Procedure/window/page>: (Optional character string)`**

Corresponds to: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) Name of window or procedure to call when a &lt;Type of error&gt; error occurs.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Name of page or procedure to call when a &lt;Type of error&gt; error occurs.

- Name of object method if **&lt;Source&gt;.OnError** is called in a method of this object. 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) Name of procedure to call when a &lt;Type of error&gt; error occurs.

- Parameter not specified. If "Enable the automatic HFSQL help" is checked in the project, the default window or page for automatic management of errors is used for the specified type of error and for the specified data file.

- Empty string. In this case, the automatic management of errors will be disabled.
	Note: To disable automatic error handling, you can also uncheck the project option "Enable HFSQL automatic assistance". 




Note: In some cases (e.g. lost connection errors), the procedure/window/page will only be executed on the next call to the WLanguage function following the event causing the error.
![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) Only some of the windows/pages for the automatic management of errors are available. The automatic management of errors is disabled for these errors.
**Special case: using a Component window, page or Procedure** The following syntax must be used:
Procedure: 

```txt
<Data file>.OnError(<Type>, ...
	"<Component>.<Name of set of procedures>.<Procedure name>")
```

 
Window: 

```txt
<Data file>.OnError(<Type>, "<Component>.<Window name>")
```

Page: 

```txt
<Data file>.OnError(<Type>, "<Component>.<Page name>")
```
![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) If a loss of connection occurs, to ask for reconnection, this procedure must call [HReconnect](../WDLang4/1000017278.md).

## Remarks


### Operating mode of custom errors
<a name="operating_mode_custom_errors_ELTPARAGRAPHE000381"></a>

The procedure, window or page used to customize the error must return one of the following constants:


|   |   |
| --- | --- |
| *opCancel* | The function that triggered the error returns an error as if the assisted management was disabled. <br>**Note** For loss-of-connection errors, the error is fatal. |
| *opEndProcess* | The function that triggered the error returns an error and the current process stops. Equivalent to the following line of code:<br><br><pre><code>IF NOT <HFSQL function> THEN SetFocusAndReturnToUserInput()</code></pre><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *opEndProgram* | The function that triggered the error returns an error and the program stops. Equivalent to the following line of code:<br><br><pre><code>IF NOT <HFSQL function> THEN EndProgram()</code></pre><br> |
| *opRelaunchProgram* | The program stops and the application is automatically restarted.<br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This constant is not available. |
| *opRetry* | The function that triggered the error is re-run. |


![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) If a loss of connection occurs, to ask for reconnection, [HReconnect](../WDLang4/1000017278.md) must be used in the procedure called by **&lt;Source&gt;.OnError**.
<a name="NOTE0_2"></a>


### Using a class method to customize the errors
<a name="using_class_method_customize_the_errors_ELTPARAGRAPHE000434"></a>

&lt;Name of procedure or window&gt; can also correspond to a method of an object if **&lt;Source&gt;.OnError** is called in a method of this object. All you have to do is specify the name of the method to use (without using the object name as prefix).

A fatal error occurs if the object used in the call to **&lt;Source&gt;.OnError** is no longer allocated when the HFSQL engine calls the method

### Customizing the default error windows
<a name="customizing_the_default_error_windows_ELTPARAGRAPHE000452"></a>

The default error windows and their WLanguage code are available in the "\\Programs\\Data\\Preset Windows\\EN\\HyperFileSQL - Automatic Help Windows" directory.

These windows can be customized, included in your projects, and passed as parameters to **&lt;Source&gt;.OnError**.

For more details, see [HFSQL error handling help](../WDLang4/3044188.md).
