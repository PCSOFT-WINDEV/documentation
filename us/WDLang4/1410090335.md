


## GeometryDeserializeWKTGeo (Function)

***In french: GéométrieDésérialiseWKTGéo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a geometry in geographic coordinates from a Well-Known Text (WKT) representation.

Remarks: 

- Points in the WKT description represent a latitude/longitude pair. 

- Note: In WKT format, longitude comes before latitude. A point (latitude, longitude) is represented by "POINT(longitude latitude)".





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WKTDescription is ANSI string
WKTDescription = "
	POLYGON( (4.9746785 47.13040029, 4.97344728 47.13107359, 4.97345634 47.13108307, 
	4.97388735 47.13087471, 4.9746785 47.13040029) )
	"
myPolygon is PolygonGeo = GeometryDeserializeWKTGeo(WKTDescription)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GeometryDeserializeWKTGeo(<WKT representation>)`
---

**`<Result>: (Variable containing spatial data)`**

Geometry variable in geographic coordinates corresponding to the WKT representation. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).




**`<WKT representation>: (ANSI character string)`**

String corresponding to the WKT representation of the geometry in geographic coordinates to be built.
