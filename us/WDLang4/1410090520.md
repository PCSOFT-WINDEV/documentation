


## &lt;PolygonGeo variable&gt;.Overlap (Function)

***In french: &lt;Variable PolygoneGéo&gt;.Chevauche***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if a geographic polygon overlaps another geometry. 

Two geometries overlap if they meet the following criteria:  

- The geometries have the same dimension (i.e., two 2D polygons). 

- The interiors of the geometries have a non-empty intersection of the same dimension as the input geometries. 

- Each geometry has at least one point inside the other.



<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
polyGeo is PolygonGeo
polyGeo.Outline.AddPoint(0n48.8187479172765, 0n1.9550104465229536)
polyGeo.Outline.AddPoint(0n48.685649220185574, 0n2.023674998054354)
polyGeo.Outline.AddPoint(0n48.82612543243871, 0n2.2106580854197566)
polyGeo = polyGeo.Correct()

myPolygon is PolygonGeo
myPolygon.Outline.AddPoint(0n47.13040029, 0n4.9746785)
myPolygon.Outline.AddPoint(0n47.13107359, 0n4.97344728)
myPolygon.Outline.AddPoint(0n47.13108307, 0n4.97345634)
myPolygon.Outline.AddPoint(0n47.13040029, 0n4.9746785)
myPolygon = myPolygon.Correct()

Trace("polyGeo.Overlap(myPolygon) = " + polyGeo.Overlap(myPolygon))
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Overlap(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the geometries overlap, 

- <u><u><u><u>False</u></u></u></u> otherwise. 


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).

## Remarks


### Special cases
<a name="special_cases_ELTPARAGRAPHE000324"></a>

- If geometry A is contained in geometry B, their intersection is equal to geometry A. In this case, **&lt;PolygonGeo variable&gt;.Overlap** returns <u><u><u>False</u></u></u>.

- If the &lt;Geometry A&gt; and &lt;Geometry B&gt; parameters are identical, **&lt;PolygonGeo variable&gt;.Overlap** returns <u><u><u>False</u></u></u>.

- If the input geometries are multipolygons, **&lt;PolygonGeo variable&gt;.Overlap** returns <u><u><u>True</u></u></u> if one of the polygons of geometry A overlaps one of the polygons of geometry B.



<a name="NOTE0_2"></a>


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000354"></a>

In a data file, you can apply a filter on spatial data and loop through the data file. For example, the filter can be based on the result of **&lt;PolygonGeo variable&gt;.Overlap**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;PolygonGeo variable&gt;.Overlap**. 

- Spatial_item is a spatial item in the data file. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire data file is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
