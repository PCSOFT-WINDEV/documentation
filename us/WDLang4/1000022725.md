


## &lt;Connection variable&gt;.NotifAddEmailRecipient (Function)

***In french: &lt;Variable Connexion&gt;.NotifAjouteDestinataireEmail***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds recipients for the notifications sent by email. These notifications are sent when the HFSQL server encounters a problem. 

**Note** Send by email uses parameters specified with [&lt;Connection variable&gt;.NotifConfigure](../WDLang4/1000022726.md) (email server, ...).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Describe the connection
ctCSConnection is Connection

ctCSConnection is Connection
ctCSConnection.Provider = hAccessHFClientServer
ctCSConnection.User = "admin"
ctCSConnection.Password = ""
ctCSConnection.Server = "test:4900"
ctCSConnection.OpenConnection()

ctCSConnection.NotifConfigure(hNotifEmail, "FLOWER:25", "test.doc", "doc", "doc@pcsoft.com", False)
ctCSConnection.NotifAddEmailRecipient("test.app@gmail.com", hNotifWarning)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.NotifAddEmailRecipient(<Recipient> , <Minimum level>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the recipient was added. 

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<Recipient>: (Character string)`**

Email address of recipient.

**`<Minimum level>: (Integer constant)`**

Minimum level of gravity from which a notification is sent: 


|   |   |
| --- | --- |
| *hNotifCritical* | The notifications will be sent from the critical level (for the critical and error problems).<br><br>Example of a critical error: "Error during replica preparation on the master." |
| *hNotifError* | The notifications will be sent for the error problems only.<br><br>Error example: "The server activity statistics file is damaged. It will be reinitialized." |
| *hNotifInformation* | The notifications will be sent from the information level (for the information, warning, critical and error problems)<br><br>Examples of information: <br><br>- During the automatic server update: <br><br>	- "The server will be stopped for update. Another notification will be added after the update."<br><br>	- "The server was updated to version XXX."<br><br><br><br><br>- During the search for necessary keys on a database in exploitation. <br><br><br> |
| *hNotifWarning* | The notifications will be sent from the warning level (for the warning, critical and error problems).<br><br>Example warning: "Server XX and server YY do not have the same time. Conflict resolution during replication may be distorted." |


The order of gravity is: 

- Information.

- Warning.

- Error.

- Critical.
