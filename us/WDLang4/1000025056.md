


## &lt;Source&gt;.Backward (Function)

***In french: &lt;Source&gt;.Recule***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Moves backward several records from the current position in the data file, according to a specified item.

The destination Record is read and loaded into memory: HFSQL variables are updated (e.g. Customer.Name, i.e. the field *Name* field of the *Client*).

Several cases may occur after the call to **&lt;Source&gt;.Backward**:

- there are no more records in the data file: function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>. No read operation is performed.

- the function attempts to block a record already blocked in play mode: function [HErrorLock](../WDLang4/3044099.md) returns <u><u><u>True</u></u></u> and function [&lt;Source&gt;.Out](../WDLang4/1000024605.md) returns <u><u><u>True</u></u></u>.
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Management of locks not available in PHP.
	![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: Lock management is not available for databases accessed via JDBC.




This function can be used with the data files, HFSQL views or queries.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Go back to the 200th record of the Customer data file
// according to the CustName key
Customer.ReadLast(CustName)
Customer.Backward(CustName, 199)
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Source>.Backward([<Item> [, <Step> [, <Options>]]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the backward move was performed in the data file,

- <u><u><u><u>False</u></u></u></u> in case of error (block, end of data file, etc.): the record is not read. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Source>: (Type corresponding to the specified source)`**

Name of the data file, view or query used. 

**`<Item>: (Optional character string)`**

Name of item according to which the browse is performed. If this name is not specified, **&lt;Source&gt;.Backward** handles the last item in the data file used by the last HFSQL function (function starting with "H").
![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) All the items used to move backward in the file are considered as being key items.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) The &lt;Step&gt; parameter is mandatory if this parameter is not specified.

**`<Step>: (Optional integer)`**

Number of steps backward (which means number of records to browse). By default, &lt;Step&gt; = 1.

**`<Options>: (Optional Integer constant (or combination of constants))`**

Configures:

- the lock mode applied to the record read. By default, the lock performed corresponds to the current lock.
	


|   |   |
| --- | --- |
| *hLockNo* | No blocking: the Record can be played back or modified by another application during playback. |
| *hLockReadWrite* | Read/write lock: the record being read cannot be read or modified by another application. |
| *hLockWrite* | Write lock: the record currently read can be read by another application but it cannot be modified by another application. |


	![OLE DB](https://doc.pcsoft.fr/ext/images/us/OLEDB.png)![Native Connectors (Native Accesses)](https://doc.pcsoft.fr/ext/images/us/AN.png) The lock options will have no effect if the locks are not supported by the OLE DB provider or by the Native Connector.

- the management of duplicates during the browse. By default, all duplicates are iterated over.
	


|   |   |
| --- | --- |
| *hDistinct* | Only one record is read if duplicates are found when looping through a key item. |




![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) &lt;Options&gt; is ignored.![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) &lt;Options&gt; is ignored.![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: The &lt;Options&gt; parameter is not taken into account.

## Remarks


### Read operation according to a key item or not
<a name="read_operation_according_key_item_not_ELTPARAGRAPHE000322"></a>

In all cases, the route must have been initialized with one of the following functions: [&lt;Source&gt;.ReadFirst](../WDLang4/1000025022.md), [&lt;Source&gt;.First](../WDLang4/1000025048.md), [&lt;Source&gt;.ReadSeekFirst](../WDLang4/1000025034.md), [&lt;Source&gt;.SeekFirst](../WDLang4/1000025055.md), [&lt;Source&gt;.ChangeKey](../WDLang4/1000024198.md), [&lt;Source&gt;.RestorePosition](../WDLang4/1000025061.md).

If the item used is a key item:

- if the *hDistinct* constant is not enabled, **&lt;Source&gt;.Backward** moves backward of &lt;Step&gt; key values from the current position.

- if the *hDistinct* constant is enabled, **&lt;Source&gt;.Backward** moves backward of &lt;Step&gt; distinct key values from the current position. If duplicates are found, a single duplicate is read.




If the item used is not a key item:

- the *hDistinct* constant is not available, 

- **&lt;Source&gt;.Backward** moves backward of &lt;Step&gt; active records from the current position.



<a name="NOTE0_2"></a>


### Memos
<a name="memos_ELTPARAGRAPHE000378"></a>

The memos associated with the record can be automatically read (or not) when reading the record. [&lt;Source&gt;.SetMemo](../WDLang4/1000024987.md) is used to customize this automatic read operation.

If the memos are supported, the associated text memos are read when the record is read. The binary memos are read only when they are explicitly used ([&lt;Source&gt;.ExtractMemo](../WDLang4/1000024957.md)).
<a name="NOTE0_3"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000400"></a>

- The result of [&lt;Source&gt;.Found](../WDLang4/1000025076.md) must be ignored ([&lt;Source&gt;.Found](../WDLang4/1000025076.md) must be used for the searches performed by [&lt;Source&gt;.ReadSeek](../WDLang4/1000025023.md), [&lt;Source&gt;.ReadSeekFirst](../WDLang4/1000025034.md), [&lt;Source&gt;.ReadSeekLast](../WDLang4/1000025024.md)).

- [&lt;Source&gt;.RecNum](../WDLang4/1000025041.md) returns the current record number.

- **&lt;Source&gt;.Backward** respects the current active filter (defined by [&lt;Source&gt;.Filter](../WDLang4/1000024960.md)).

- [&lt;Source&gt;.ChangeKey](../WDLang4/1000024198.md) is used modify the search key while being positioned on the current record.

- **&lt;Source&gt;.Backward**(Customer,Name) is equivalent to [&lt;Source&gt;.ReadPrevious](../WDLang4/1000025021.md)(Customer,Name)

### Lock
<a name="lock_ELTPARAGRAPHE000463"></a>

By default (no lock variable specified), the lock performed corresponds to the current lock mode.

If a lock is requested (*hLockWrite* or *hLockReadWrite* constant), the record will be read and locked only if this record is not already locked by another application.
