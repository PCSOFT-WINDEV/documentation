


## &lt;Connection variable&gt;.DeleteGroup (Function)

***In french: &lt;Variable Connexion&gt;.SupprimeGroupe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes (from the server) a group of users associated with a connection.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Describe the connection
MyConnection is Connection

// Open the connection
MyConnection.OpenConnection()
// Associate the data file with the connection
Customer.ChangeConnection(MyConnection)
...
IF MyConnection.DeleteGroup("User1") = True THEN
	Info("User1 group deleted")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Connection>.DeleteGroup(<Group>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the group has been deleted, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




Note: An "Unknown Group" error will be returned by the function [HErrorInfo](../WDLang4/3044071.md) if the current user does not have the right to view users (constant *hDroitVisualisationUtilisateur*) and if they request the deletion of another group.

**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection for which a group must be deleted.

**`<Group>: (Character string)`**

Name of group to delete.
