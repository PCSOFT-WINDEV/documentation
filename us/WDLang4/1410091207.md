
## HSecurityPolicyGet (Function)

***In french: HPolitiqueSécuritéRécupère***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the security policy of an HFSQL server. 

Retrieved information varies depending on the type of user:

- In the case of "super users", all security policy information is retrieved. 

- For other user types, only the password complexity and minimum length criteria are retrieved. This information can be used to create a password that meets these criteria.  





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let myPolicy = hSecurityPolicyGet(myConnection)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HSecurityPolicyGet(<Connection>)`
---

**`<Result>: (hSecurityPolicy variable)`**

[hSecurityPolicy](../WDLang4/1410091181.md) variable corresponding to the password security policy currently implemented on the HFSQL server. 

**`<Connection>: (String or Connection variable)`**

HFSQL server connection to be manipulated. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).
