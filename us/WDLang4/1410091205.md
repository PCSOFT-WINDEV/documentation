
## HSecurityPolicySet (Function)

***In french: HPolitiqueSécuritéModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sets the password security policy of an HFSQL server. 

Note: To use this function, you need to be connected to the HFSQL server with a "super user" account. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MySecurityPolicy is hSecurityPolicy
IF NOT HSecurityPolicySet(MyConnection, MySecurityPolicy) THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HSecurityPolicySet(<Connection> , <SecurityPolicy>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the specified password security policy has been applied,

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error. 




**`<Connection>: (String or Connection variable)`**

HFSQL server connection to be manipulated. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 




**`<SecurityPolicy>: (hSecurityPolicy variable)`**

[hSecurityPolicy](../WDLang4/1410091181.md) variable corresponding to the password security policy to be applied.
