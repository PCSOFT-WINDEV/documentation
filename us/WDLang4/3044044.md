


## HCheckIndex (Function)

***In french: HVérifieIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks whether the data found in the index file (.NDX file) properly refers the data found in the data file (.FIC file). This function applies to the HFSQL data files (Classic or Client/Server) only. 

![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The HFSQL Client/Server data file is automatically locked during the verification.![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) The indexes of an HFSQL Client/Server data file can be checked asynchronously using [HCheckIndexAsynchronous](../WDLang4/1410091105.md). 


**Reminder**: An index is corrupted when one of the records it references is not the one expected. In this case, the data file must be reindexed.

## Example


```wl
// Check the index
let IndexResult = HCheckIndex(Customer)
// Manage the result
SWITCH IndexResult
	CASE 0
		Info ("The index is correct")
	CASE 1
		Info("The file must be optimized.")
	CASE 2
		Info("HFSQL error" + HError() + " during the test")
END
```

## Syntax

`<Result> = HCheckIndex([<Data file> [, <Key item>] [, <Progress Bar>]])`
---

**`<Result>: (Integer)`**

Can correspond to: 

- 0 if the check is correct.

- 1 if the index is corrupted. This means that a reindex is required ([HIndex](../WDLang4/3044133.md)).

- 2 in the event of an HFSQL error: Inaccessible data file, etc.

- 3 if the function is not supported by this type of data file (xBase, AS400, etc.).




**`<Data file>: (Optional character string)`**

Name of the data file used. If this name is not specified, **HCheckIndex** will use the last data file used by the last HFSQL function (function starting with "H").

**`<Key item>: (Optional character string)`**

Name of the key item to check. If this parameter is not specified, all the keys of the data file are checked.

**`<Progress Bar>: (Optional control name or window name)`**



- Name of the window in which the progress bar will be displayed, 

- Name of the Progress Bar control to use. 


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter is ignored.

## Remarks


### Corrupted index
<a name="corrupted_index_ELTPARAGRAPHE000114"></a>

When the function detects a problem in the index file, the **H.Comment** variable contains:

```txt
<Name of affected key> + TAB + <Record number causing problem> + CR + 
<Name of affected key 2> + TAB + <Record number causing problem 2> ...
```

&lt;Record number causing problem&gt; is equal to -1 if no record was defined.

**Note**: If the index file is entirely corrupted, no values are specified for the *H.Comment* variable.
