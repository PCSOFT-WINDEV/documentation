


## GeometryDeserializeWKT2D (Function)

***In french: GéométrieDésérialiseWKT2D***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Builds a 2D geometry from a Well-Known Text (WKT) representation. 

**Note**: Points in the WKT description represent X/Y coordinates.  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
WKTDescription is ANSI string
WKTDescription = "
	POLYGON((4.9746785 47.13040029, 4.97344728 47.13107359, 4.97345634 47.13108307, 
	4.97388735 47.13087471, 4.9746785 47.13040029) )
	"
myPolygon is Geometry = GeometryDeserializeWKT2D(WKTDescription)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = GeometryDeserializeWKT2D(<WKT representation>)`
---

**`<Result>: (Variable containing spatial data)`**

[Geometry](../WDLang4/1410090098.md) variable that corresponds to the WKT representation. Geometries can be variables of the following types: 

- [Point2D](../WDLang4/1410090100.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygon2D](../WDLang4/1410090135.md). 




**`<WKT representation>: (ANSI character string)`**

String corresponding to the WKT representation of the 2D geometry to be built.
