


## &lt;Connection variable&gt;.InfoServer (Function)

***In french: &lt;Variable Connexion&gt;.InfoServeur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the specified information about the server. The server corresponds to the computer on which the connection is established.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Describe the connection
MyConnection is Connection

Trace(MyConnection.InfoServer(hInfoHardware))
// Return "Intel Pentium" + TAB + "639MB" + CR
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = <Connection>.InfoServer([<Type of information>])`
---

**`<Result>: (Character string)`**

Requested information.  If several types of information are requested, each type of information is separated by a CR character (Carriage Return).

The order in which the information is returned (if requested) is as follows:

*hInfoVI* + *hInfoVersion* + *hInfoPlatform* + *hInfoHardware* + *hInfoName* + *hInfoLogicalName* + *hInfoDate*

**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection for which the server information must be retrieved.

**`<Type of information>: (Optional constant (or combination of constants))`**

Requested type of information. The result depends on the type of requested information.


|   |   |
| --- | --- |
| *hInfoAll*<br>(Default value) | Full information about the server (corresponds to * hInfoVi* + *hInfoVersion* + *hInfoPlatform* + *hInfoHardware* + *hInfoName* + *hInfoLogicalName* + *hInfoDate*).<br>The different values are separated by CR characters (Carriage Return). |
| *hInfoCluster* | Information about the HFSQL Client/Server cluster, in the following format: <br> &lt;Name of cluster manager&gt; + CR + &lt;List of cluster nodes&gt;. <br><br>The list of cluster nodes has the following format: <br>&lt;Node name&gt; + &lt;TAB&gt; + &lt;Node status&gt; + TAB + &lt;Version&gt;. <br>The states of the node can be:<br><br>- 0: Node not part of the cluster.<br><br>- 1: Knot stopped.<br><br>- 2: Node waiting to start.<br><br>- 3: Node starting up<br><br>- 4: Node waiting for synchronization source.<br><br>- 5: Node being synchronized.<br><br>- 6: Active node.<br><br>- 7: Node stopped.<br><br>- 8: Status unknown.<br><br><br> |
| *hInfoDate* | Date and time of server on 8 bytes in UTC format (universal time). This information is a character string of the type "YYYYMMDDHHmmSS". |
| *hInfoFreeDiskSpace* | Available space on the server disk, expressed in bytes. |
| *hInfoHardware* | Information about the hardware used:<br><br>- Processor type (example: Intel Pentium).<br><br>- Server RAM size (example: 630MB)<br><br><br>This information is returned in the following format:<br>&lt;Type of CPU&gt; = TAB + &lt;Size of server RAM&gt; |
| *hInfoLogicalName* | Name of the server given in the HFConf.ini file or specified during the setup. This name appears in the HFSQL Control Center. |
| *hInfoName* | Name of server (DNS) |
| *hInfoPlatform* | Information about the server platform:<br><br>- Name of operating system: <br><br>	- Windows Windows Vista, Windows Vista (64 bits), Windows 7, Windows 8, Windows 8.1, Windows 10, Windows 2008, Windows 2008 R2, Windows 2012, Windows 2012 R2.<br><br>	- LINUX followed by the distribution name. For example: "LINUX Ubuntu 14"<br><br><br><br><br>- System version: corresponds to the Windows service pack, or empty string if no service pack is installed. In Linux, corresponds to the version of Linux kernel (2.4.20-8 for example).<br><br><br>This information is returned in the following format:<br><a name="NOTE0"></a>
