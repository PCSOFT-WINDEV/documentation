


## HOpenComplementaryAnalysis (Function)

***In french: HOuvreAnalyseComplémentaire***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Opens a new analysis, but keeps the main analysis of the application. Already open analyses are not closed. 

Caution: To use this function, you must first have declared or opened a main analysis (function [HOpenAnalysis](../WDLang4/3044106.md)). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Open a complementary analysis
HOpenComplementaryAnalysis("C:\SALESMGT\SALESMGT.WDD", "Password")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HOpenComplementaryAnalysis(<WDD file path> [, <Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the analysis was opened, 

- <u><u><u><u>False</u></u></u></u> otherwise. [HError](../WDLang4/3044088.md) returns more details about the problem.




**`<WDD file path>: (Character string)`**

Full path of the ".WDD" file of the analysis. This file contains the description of the analysis to be opened.

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) If only the drive and the name of the analysis are specified, the analysis is searched for in the current directory of the specified drive. 
If neither the drive, nor the analysis path are specified, the analysis is searched for in the current directory of the current disk.
The &lt;Unit&gt;:&lt;Analysis name&gt; syntax is used to search for the analysis in the current directory of the specified drive. 

**`<Password>: (Optional string or Secret string)`**



- Analysis password, defined in the data model editor. 

- Empty string ("") if no password is associated with the analysis.
	**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
	To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).

## Remarks


### Launching an application associated with a main analysis
<a name="launching_application_associated_with_main_analysis_ELTPARAGRAPHE000061"></a>

- The main analysis is automatically opened when the application is launched. The analysis is searched for in the main library of the application, then in the directory of the application. 
	To make sure the analysis is found, we advise you to include the analysis in the main library of the application.

- If **HOpenComplementaryAnalysis** is called by an application associated with a main analysis, this function:

	- has no effect if the path of the specified analysis corresponds to the path of the analysis associated with the application.

	- returns <u><u><u><u>False</u></u></u></u> if the path of the specified analysis does not exist. In this case, the application keeps working with the current analysis.

	- opens the analysis and returns <u><u><u><u>True</u></u></u></u> if the specified analysis exists and if it is valid.






<a name="NOTE0_2"></a>


### Starting an application not associated with an analysis
<a name="starting_application_not_associated_with_analysis_ELTPARAGRAPHE000085"></a>

When an application that is not associated with an analysis is started, no analysis is automatically opened. In this case, you need to use the [HOpenAnalysis](../WDLang4/3044106.md) function.

To open a complementary analysis, use **HOpenComplementaryAnalysis**. The analysis opened by **HOpenComplementaryAnalysis** is searched:

- first, in the main library of the application according to its full physical name.

- then, on the current disk.



<a name="NOTE0_2B"></a>


### Automatically hide data files with the same name in different analyses
<a name="automatically_hide_data_files_with_the_same_name_different_analyses_ELTPARAGRAPHE000257"></a>

Different analyses can contain data files with the same name. In this case, only one data file will be used. This data file relies on the order specified for the different analyses, either in the project description or through the opening sequence defined using [HOpenAnalysis](../WDLang4/3044106.md) and [HOpenComplementaryAnalysis](../WDLang4/1410090082.md). Here is how it works: 

- Analysis 1: 

	- Data file A 

	- Data file B




- Analysis 2: 

	- Data file B. This data file will be "hidden", as it is present in Analysis 1. 
			**To use data file B in analysis 2**, it is necessary to rename this data file in analysis 2. 

	- Data file C




- Analysis 3: 

	- Data file B: This data file will be "hidden", as it is present in Analysis 1. 
			**To use data file B in analysis 3**, it is necessary to rename this data file in analysis 3.

	- Data file C: This data file will be "hidden", as it is present in Analysis 2. 
			**To use data file C in analysis 3**, it is necessary to rename this data file in analysis 3.

	- Data file D. 





In the "Analysis" action of the "Project Explorer" pane, the following data files will be shown: 

- Data file A (analysis 1)

- Data file B (analysis 1)

- Data file C (analysis 2)

- Data file D (analysis 3).



<a name="NOTE0_3"></a>


### Opening an analysis that is already open
<a name="opening_analysis_that_already_open_ELTPARAGRAPHE000106"></a>

If the analysis you are trying to open with **HOpenComplementaryAnalysis** is already open, the function has no effect.
<a name="NOTE0_5"></a>


### Analysis version supported by HOpenComplementaryAnalysis
<a name="analysis_version_supported_docparampagetitleshort_ELTPARAGRAPHE000115"></a>

**HOpenComplementaryAnalysis cannot be used to open Hyper File 5.5 analyses (and earlier versions). Only HFSQL Classic analyses can be opened.**
