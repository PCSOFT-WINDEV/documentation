


## &lt;PolygonGeo variable&gt;.IsValid (Function)

***In french: &lt;Variable PolygoneGéo&gt;.EstValide***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Checks whether the specified geographic polygon is valid according to the OGC rules.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.IsValid()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the geometry is valid,

- <u><u><u><u>False</u></u></u></u> otherwise.


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.
