


## Spatial data functions (prefix syntax)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manipulate spatial data using prefix syntax: 



|   |   |
| --- | --- |
| [&lt;Linestring2D variable&gt;.AddPoint](../WDLang4/1410090485.md) | Adds a new point to a 2D linestring. |
| [&lt;LinestringGeo variable&gt;.AddPoint](../WDLang4/1410090486.md) | Adds a new point to a geographic linestring. |
| [&lt;Polygon2D variable&gt;.Area](../WDLang4/1410090517.md) | Calculates the area of a polygon defined using 2D coordinates. |
| [&lt;Polygon2D variable&gt;.Contain](../WDLang4/1410090522.md) | Determines if geometry A (of type 2D polygon) contains geometry B. |
| [&lt;Polygon2D variable&gt;.ConvexHull](../WDLang4/1410090588.md) | Calculates the convex hull of the specified 2D polygon. |
| [&lt;Polygon2D variable&gt;.Correct](../WDLang4/1410090523.md) | Returns a corrected version of the specified 2D polygon. |
| [&lt;Polygon2D variable&gt;.Cover](../WDLang4/1410090526.md) | Determines if geometry A (of type 2D polygon) covers geometry B. |
| [&lt;Polygon2D variable&gt;.CoveredBy](../WDLang4/1410090572.md) | Determines if every point of geometry A (2D polygon) lies inside or on the boundary of geometry B. |
| [&lt;Polygon2D variable&gt;.Cross](../WDLang4/1410090527.md) | Determines if a 2D polygon crosses another geometry. |
| [&lt;Polygon2D variable&gt;.Difference](../WDLang4/1410090530.md) | Returns a geometry representing the difference between a 2D polygon and another geometry. |
| [&lt;Polygon2D variable&gt;.Disjoint](../WDLang4/1410090563.md) | Determines whether two geometries are disjoint, i.e. whether their intersection is empty. |
| [&lt;Polygon2D variable&gt;.Distance](../WDLang4/1410090566.md) | Calculates the distance between a 2D polygon and another geometry. |
| [&lt;Polygon2D variable&gt;.Equal](../WDLang4/1410090567.md) | Determines whether two geometries are spatially equal, i.e. whether the first geometry is included in the second, and vice versa. |
| [&lt;Polygon2D variable&gt;.Intersect](../WDLang4/1410090576.md) | Checks whether the intersection of a 2D polygon and another geometry does not result in an empty set.  |
| [&lt;Polygon2D variable&gt;.Intersection](../WDLang4/1410090579.md) | Returns a geometry representing the intersection between a 2D polygon and another geometry. |
| [&lt;Polygon2D variable&gt;.IsValid](../WDLang4/1410090575.md) | Checks whether the specified 2D polygon is valid according to the OGC rules. |
| [&lt;Polygon2D variable&gt;.Overlap](../WDLang4/1410090519.md) | Determines if a 2D polygon overlaps another geometry. |
| [&lt;Polygon2D variable&gt;.Perimeter](../WDLang4/1410090580.md) | Calculates the perimeter of a polygon defined using 2D coordinates. |
| [&lt;Polygon2D variable&gt;.SerializeWKT](../WDLang4/1410090583.md) | Serializes a 2D polygon using the Well-Known Text (WKT) format. |
| [&lt;Polygon2D variable&gt;.SymmetricDifference](../WDLang4/1410090531.md) | Calculates the symmetric difference between a 2D polygon and another geometry. |
| [&lt;Polygon2D variable&gt;.Touch](../WDLang4/1410090584.md) | Determines whether a 2D polygon touches another geometry. |
| [&lt;Polygon2D variable&gt;.Union](../WDLang4/1410090587.md) | Returns a geometry corresponding to the union between a 2D polygon and another geometry. |
| [&lt;Polygon2D variable&gt;.Within](../WDLang4/1410090571.md) | Determines whether geometry A (2D polygon) is completely within geometry B (i.e., geometry B completely contains geometry A). |
| [&lt;PolygonGeo variable&gt;.Area](../WDLang4/1410090518.md) | Calculates the area of a polygon defined using geographic coordinates. |
| [&lt;PolygonGeo variable&gt;.Contain](../WDLang4/1410090521.md) | Determines if geometry A (of type geographic polygon) contains geometry B. |
| [&lt;PolygonGeo variable&gt;.ConvexHull](../WDLang4/1410090569.md) | Calculates the convex hull of the specified geographic polygon. |
| [&lt;PolygonGeo variable&gt;.Correct](../WDLang4/1410090524.md) | Returns a corrected version of the specified geographic polygon. |
| [&lt;PolygonGeo variable&gt;.Cover](../WDLang4/1410090525.md) | Determines if geometry A (of type geographic polygon) covers geometry B. |
| [&lt;PolygonGeo variable&gt;.CoveredBy](../WDLang4/1410090573.md) | Determines if every point of geometry A (geographic polygon) lies inside or on the boundary of geometry B. |
| [&lt;PolygonGeo variable&gt;.Cross](../WDLang4/1410090528.md) | Determines if a geographic polygon crosses another geometry. |
| [&lt;PolygonGeo variable&gt;.Difference](../WDLang4/1410090529.md) | Returns a geometry representing the difference between a geographic polygon and another geometry. |
| [&lt;PolygonGeo variable&gt;.Disjoint](../WDLang4/1410090564.md) | Determines whether two geometries are disjoint, i.e. whether their intersection is empty. |
| [&lt;PolygonGeo variable&gt;.Distance](../WDLang4/1410090565.md) | Calculates the distance between a geographic polygon and another geometry. |
| [&lt;PolygonGeo variable&gt;.Equal](../WDLang4/1410090568.md) | Determines whether two geometries are spatially equal, i.e. whether the first geometry is included in the second, and vice versa. |
| [&lt;PolygonGeo variable&gt;.Intersect](../WDLang4/1410090577.md) | Checks whether the intersection of a geographic polygon and another geometry does not result in an empty set. |
| [&lt;PolygonGeo variable&gt;.Intersection](../WDLang4/1410090578.md) | Returns a geometry representing the intersection between a geographic polygon and another geometry. |
| [&lt;PolygonGeo variable&gt;.IsValid](../WDLang4/1410090574.md) | Checks whether the specified geographic polygon is valid according to the OGC rules. |
| [&lt;PolygonGeo variable&gt;.Overlap](../WDLang4/1410090520.md) | Determines if a geographic polygon overlaps another geometry. |
| [&lt;PolygonGeo variable&gt;.Perimeter](../WDLang4/1410090581.md) | Calculates the perimeter of a geographic polygon. |
| [&lt;PolygonGeo variable&gt;.SerializeWKT](../WDLang4/1410090582.md) | Serializes a geographic polygon using the Well-Known Text (WKT) format. |
| [&lt;PolygonGeo variable&gt;.SymmetricDifference](../WDLang4/1410090532.md) | Calculates the symmetric difference between a geographic polygon and another geometry. |
| [&lt;PolygonGeo variable&gt;.Touch](../WDLang4/1410090585.md) | Determines whether a geographic polygon touches another geometry. |
| [&lt;PolygonGeo variable&gt;.Union](../WDLang4/1410090586.md) | Returns a geometry corresponding to the union between a geographic polygon and another geometry. |
| [&lt;PolygonGeo variable&gt;.Within](../WDLang4/1410090570.md) | Determines whether geometry A (geographic polygon) is completely within geometry B (i.e., geometry B completely contains geometry A). |
