


## hFileParameter (Variable type)

***In french: hParamètreFichier***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **hFileParameter** type is used to define the data files taken into account by a scheduled optimization task. You can define and change the characteristics of these data files using different WLanguage properties.

This type of variable is used by the [hScheduledOptimization](../WDLang4/1000018854.md) type and by various WLanguage functions. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Recalculate the statistics for the files found in "MyDatabase", 
// every Saturday at 23:00
Optim is hScheduledOptimization
Optim.Description = "Recalculating the statistics for the files found in the MyDatabase database"

Optim.Scheduling.Month = "*"
Optim.Scheduling.DayOfWeek = "Saturday"
Optim.Scheduling.Hour = "23"
Optim.Scheduling.Minute = "0"

Optim.File[0].Name = "MyDatabase"
Optim.File[0].Option = hOptStat

HAddScheduledOptimization(MyConnection, Optim)
```

## Properties


### Properties specific to hFileParameter variables
<a name="properties_specific_hfileparameter_variables_ELTPARAGRAPHE000038"></a>

The following properties can be used to define the characteristics of **hFileParameter** variables:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Name | Character string | Name of the data file to be processed. This name can be a string of type: <br><br>- &lt;Database name&gt;/&lt;Data file name&gt;: Optimization of "Data file name" in "Database name". <br><br>- &lt;Database name&gt;: Optimization of all the data files contained in "Database name".<br><br>- "\*": Optimization of all data files in all server databases.<br><br><br> |
| Option | Integer constant | Optimization options: <br><br>- *hOptIndex*: Reindexes all data files. A zero-downtime reindexing process is performed on indexes and full-text indexes. <br><br>- *hOptStat*: Recalculates data file statistics. The result is similar to the use of [HStatCalculate](../WDLang4/3044134.md). This process is performed with zero-downtime.<br><br><br><br><br>Note: This property is only taken into account when using a variable of type [hScheduledOptimization](../WDLang4/1000018854.md). |
| Password | Character string or Secret string | Password of encrypted data files.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). <br><br>This property is available in write mode only. |
