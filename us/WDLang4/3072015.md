
## SQLClose (Function)

***In french: SQLFerme***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Declares the end of execution of a query and frees the memory resources allocated during the execution of the query ([SQLExec](../WDLang4/3072007.md) or [SQLExecWDR](../WDLang4/3072010.md)).

**Note**: The memory allocated to the query must be released even if the query execution has failed.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The SQL functions are used to handle the local databases (such as Web SQL databases). For more details, see [Accessing a database in local mode (SQLite)](../WDLang4/9000119.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Run the query and retrieve the information
ResSQL = SQLExec("SELECT* FROM INV", "QRY1")
IF ResSQL = False THEN
	SQLInfo("QRY1")
	Info("SQL error: " + SQL.MesError)
ELSE
	SQLTable("QRY1", TABLE_Table1)
END
SQLClose("QRY1")
```

## Syntax

`SQLClose(<Query name>)`
---

**`<Query name>: (Character string)`**

Name of the query: 

- created and run by [SQLExec](../WDLang4/3072007.md), 

- run by [SQLExecWDR](../WDLang4/3072010.md).




![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The queries created with the query editor must be specified in the format of a character string. 

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Only the queries created and run by [SQLExec](../WDLang4/3072007.md) are available.
