


## HReindexingInProgress (Function)

***In french: HRéindexationEnCours***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>30.2 (2028)</B>, ***HIndexingInProgress*</**>** is kept for backward compatibility. This function has been replaced with ***HReindexingInProgress*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indicates that a reindex operation is currently performed on an HFSQL data file and returns the percentage of reindexing already performed.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF HReindexingInProgress(Customer) <> 0 THEN
	Trace("Operation unavailable, reindexing")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HReindexingInProgress(<Data file> [, <Progress Bar>])`
---

**`<Result>: (Integer)`**



- 0 if no reindex operation is in progress on the data file, 

- an integer included between 1 and 100 indicating the percentage of reindexing already performed




**`<Data file>: (Character string)`**

Name of the data file used.

**`<Progress Bar>: (Optional control or window name, or optional integer)`**



- Name of the window in which the progress bar will be displayed, or name of the Progress Bar control.

- Handle of the window that displays the progress bar.


![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This parameter is ignored.

## Remarks


### Reindexing
<a name="reindexing_ELTPARAGRAPHE000081"></a>The indexes are reorganized by the reindex operation. The data cannot be accessed during the reindex operation.
![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) When accessing a data file on which a reindex operation is performed, the HFSQL engine displays a window indicating that a reindex operation is in progress. This window will be automatically closed at the end of the reindexing.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=HF_Reindexation.gif)
For more details on this window and its customization options, see [HFSQL error handling help](../WDLang4/3044188.md).
