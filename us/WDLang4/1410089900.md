


## HListWatchedFiles (Function)

***In french: HListeFichiersSurveillés***

	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***HListTrackedFiles*</**>** is kept for backward compatibility. This function has been replaced with ***HListWatchedFiles*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of data files watched by [HWatch](../WDLang4/1000022407.md).

Caution: 

- This function can only be used in Client/Server mode. 

- The list will contain the data files being watched when the function is called. If data files are no longer being watched ([HWatchStop](../WDLang4/1000022430.md)), they will not appear in the list. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyWatchedFiles is array of strings
MyWatchedFiles = HListWatchedFiles()
```

```wl
MyConnection is Connection
MyWatchedFiles is array of strings
MyWatchedFiles = HListWatchedFiles(MyConnection)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HListWatchedFiles([<Connection>])`
---

**`<Result>: (WLanguage array)`**

Array of strings containing the watched data files. 

**`<Connection>: (Optional character string or Connection variable)`**

Connection to use. This connection corresponds to:

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 


If this parameter is specified, you can list only the data files being watched by this connection.
If this parameter is not specified, all data files watched by all connections coming from the calling application will be returned. Data files watched by other applications will not be returned.
