


## HDataSourceKnown (Function)

***In french: HSourceDeDonnéesConnue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines if a data source has been initialized. This function prevents errors such as "You called XXX . The YYY data source has not been initialized". 

**Difference with function [HQueryExecuted](../WDLang4/1410090242.md)** function: The **HDataSourceKnown FUNCTION** function determines whether the data source is known to the HFSQL engine, regardless of its content. [HQueryExecuted](../WDLang4/1410090242.md) can only be used with queries. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyView is Data Source
// MyView is associated with a view

IF HDataSourceKnown(MyView) = False THEN
	// Initialize the MyView variable 
	HCreateView(MyView, CUSTOMER, "*", "NAME,CITY", "NAME]='A'", hViewDefault)
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HDataSourceKnown(<Data source to check>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the data source has been initialized,

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) returns more details about the problem.




**`<Data source to check>: (Data Source)`**

[Data Source](../WDLang4/1514053.md) variable to be checked. This data source can correspond to: 

- an external data file,

- an SQL query, 

- a view.

## Remarks


### How to initialize a Data Source variable
<a name="how_initialize_data_source_variable_ELTPARAGRAPHE000074"></a>

The initialization of a Data Source variable depends on its content: 

- External data file: use function [HDeclareExternal](../WDLang4/3044204.md). 

- SQL queries and requests: use functions [HExecuteQuery](../WDLang4/3044080.md), [HExecuteSQLQuery](../WDLang4/3044084.md), etc. 

- HFSQL view: use function [HCreateView](../WDLang4/3044159.md). 




For more details, see the help page on the [Data Source](../WDLang4/1514053.md) variable type.
