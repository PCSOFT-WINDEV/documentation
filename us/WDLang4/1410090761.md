
## HClearSchedulingHistory (Function)

***In french: HSupprimeToutHistoriquePlanification***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Clears the execution history of scheduled jobs on an HFSQL server. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF NOT HClearSchedulingHistory(MyDatabaseConnection) THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HClearSchedulingHistory(<Connection>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if all the scheduled jobs have been deleted from the history file,

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Character string or Connection variable)`**

Connection used. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).
