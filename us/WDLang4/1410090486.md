


## &lt;LinestringGeo variable&gt;.AddPoint (Function)

***In french: &lt;Variable PolyligneGéo&gt;.AjoutePoint***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Adds a new point to a geographic linestring.

Reminder: A geographic polygon is a set of geographic linestrings..
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
// Linestring declaration
myGeoLinestring is LinestringGeo
// Build linestring: 4 points
myGeoLinestring.AddPoint(2.681548, 43.802043)
myGeoLinestring.AddPoint(2.816297, 43.725179)
myGeoLinestring.AddPoint(2.842733, 43.817899)
myGeoLinestring.AddPoint(2.644979, 43.837466)
// WKT serialization
Trace("myGeoLinestring: " + mGeoLinestring.SerializeWKT())
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Linestring in geographic coordinates>.AddPoint(<Latitude> , <Longitude>)`
---

**`<Linestring in geographic coordinates>: (LinestringGeo variable)`**

Name of the [LinestringGeo](../WDLang4/1410090128.md) variable to which to add a new point.

**`<Latitude>: (Real)`**

Latitude of the point.

**`<Longitude>: (Real)`**

Longitude of the point.
