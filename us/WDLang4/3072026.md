
## SQLReqExists (Function)

***In french: SQLReqExiste***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the existence of a query.

![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) The SQL functions are used to handle the local databases (such as Web SQL databases). For more details, see [Accessing a database in local mode (SQLite)](../WDLang4/9000119.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Checks the existence of a query
IF SQLReqExists("QRY1") = 1 THEN
	Info("The query exists")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = SQLReqExists(<Query name>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the query exists,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Query name>: (Character string)`**

Name of the query created and executed with [SQLExec](../WDLang4/3072007.md), or executed with [SQLExecWDR](../WDLang4/3072010.md).

![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) The queries created with the query editor must be specified in the format of a character string. ![WEBDEV - Browser code](https://doc.pcsoft.fr/ext/images/us/WBN.png) Only the queries created and run by [SQLExec](../WDLang4/3072007.md) are available.
