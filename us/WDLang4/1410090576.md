


## &lt;Polygon2D variable&gt;.Intersect (Function)

***In french: &lt;Variable Polygone2D&gt;.Intersecte***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Checks whether the intersection of a 2D polygon and another geometry does not result in an empty set.  

**Remarks**: 

- To get the geometry corresponding to the intersection, use [&lt;Polygon2D variable&gt;.Intersection](../WDLang4/1410090579.md). 

- Since **&lt;Polygon2D variable&gt;.Intersect** does not return a result geometry, it is much faster than [&lt;Polygon2D variable&gt;.Intersection](../WDLang4/1410090579.md).

<a name="sample_code"></a>

## Example


```wl
// Example 1: Two disjoint polygons
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1.Outline.AddPoint(0.00, 3.00)
o2DPolygon_1.Outline.AddPoint(-2.00, -1.00)
o2DPolygon_1.Outline.AddPoint(-3.00, -1.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
// Corrects the new geometry
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(2.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, -2.00)
o2DPolygon_2.Outline.AddPoint(-2.00, -2.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(2.00, 4.00)
// Corrects the new geometry
o2DPolygon_2 = o2DPolygon_2.Correct()

Trace(o2DPolygon_1.Intersect(o2DPolygon_2)) // False
```

```wl
// Example 2: Two polygons with an intersection
o2DPolygon_1 is Polygon2D
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
o2DPolygon_1.Outline.AddPoint(0.00, 3.00)
o2DPolygon_1.Outline.AddPoint(-2.00, -1.00)
o2DPolygon_1.Outline.AddPoint(-3.00, -1.00)
// Add last point (same as first)
o2DPolygon_1.Outline.AddPoint(-1.00, 3.00)
// Corrects the new geometry
o2DPolygon_1 = o2DPolygon_1.Correct()

o2DPolygon_2 is Polygon2D
o2DPolygon_2.Outline.AddPoint(1.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 4.00)
o2DPolygon_2.Outline.AddPoint(3.00, 1.00)
o2DPolygon_2.Outline.AddPoint(-1.00, -1.00)
o2DPolygon_2.Outline.AddPoint(-3.00, 1.00)
// Add last point (same as first)
o2DPolygon_2.Outline.AddPoint(1.00, 4.00)
// Corrects the new geometry
o2DPolygon_2 = o2DPolygon_2.Correct()

Trace(o2DPolygon_1.Intersect(o2DPolygon_2)) // True
```

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.Intersect(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the intersection of two geometries does not result in an empty set,

- <u><u><u><u>False</u></u></u></u> otherwise.


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (Polygon2D variable)`**

Name of the [Polygon2D](../WDLang4/1410090122.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Second input geometry used for the intersection. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).

## Remarks


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000351"></a>

In a data file, you can apply a filter on spatial data and loop through the data file. For example, the filter can be based on the result of **&lt;Polygon2D variable&gt;.Intersect**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;Polygon2D variable&gt;.Intersect**. 

- Spatial_item is a spatial item in the data file. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire data file is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
