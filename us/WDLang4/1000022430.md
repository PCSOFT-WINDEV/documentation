


## HWatchStop (Function)

***In french: HSurveilleStop***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***HTrackStop*</**>** is kept for backward compatibility. This function has been replaced with ***HWatchStop*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Stops watching a data file on an HFSQL server. This watch task was started with [HWatch](../WDLang4/1000022407.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Starts watching the Order data file
// The ProcessOrder procedure is called whenever a record is added to the data file
HWatch(Order, ProcessOrder, hRecNumAll, hwAdd)
...
// Stops watching the Order data file
HWatchStop(Order, ProcessOrder, hRecNumAll)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HWatchStop(<Data file> , <WLanguage procedure> [, <Record number>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the watch task was stopped,

- <u><u><u><u>False</u></u></u></u> otherwise (watch task not found, for example). To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<Data file>: (Optional character string)`**

Name of HFSQL data file to use. The data file is associated with a connection and with a server. 
If this parameter is an empty string (""), **HWatchStop** manipulates the last data file used by the last HFSQL function (function starting with "H").

**`<WLanguage procedure>: (Procedure name)`**

Name of the WLanguage procedure that should no longer be called to watch the data file. 

**`<Record number>: (Optional integer)`**

Number of the record that will no longer be watched. 
If this parameter is not specified or corresponds to the *hRecNumAll* constant, **HWatchStop** will stop watching all the data file records (i.e. the entire data file).
