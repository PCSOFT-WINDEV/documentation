


## redisResponse (Variable type)

***In french: redisRéponse***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **redisResponse** type makes it possible to define all the advanced characteristics of a response received by [RedisExecuteCommand](../WDLang4/1000023541.md) or [RedisPipelineGet](../WDLang4/1000023543.md). The characteristics of this response can be known using different WLanguage properties. 

This type of variable can also be used to define the characteristics of a Valkey server response. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
INTERNAL PROCEDURE DisplayResult (r is redisResponse, sIdent="")
	SWITCH r.Type
		CASE redisTypeInt
			Trace(sIdent + "integer: " + r.Integer)
		CASE redisTypeError
			Trace(sIdent + "error: " + r.String)
		CASE redisTypeStatus
			Trace(sIdent + "status: " + r.String)
		CASE redisTypeNil
			Trace(sIdent + "Nil")
		CASE redisTypeArray
			Trace(sIdent + "array: ")
			FOR EACH r2 OF r.Array
				ShowResponse(r2, sIdent + TAB)
			END
		CASE redisTypeBuffer
			Trace(sIdent + "buffer in string: " + r.String)
			Trace(sIdent + "buffer in hexa: " + BufferToHexa(r.Buffer))
	END
END

r1 is redisResponse = RedisExecuteCommand(gRedis, "GET keyString")
DisplayResult(r1)
```

## Properties


### Properties specific to redisResponse variables
<a name="properties_specific_redisresponse_variables_ELTPARAGRAPHE000035"></a>

The following properties can be used to manipulate a Redis response:

| Property name | Type used | Effect |
| --- | --- | --- |
| Array | Array of redisResponse | If the **Type** property is set to the *redisTypeArray* constant, this property contains an array of **redisResponse** variables. |
| Buffer | Buffer | Binary value if the **Type** property is set to the *redisTypeBuffer* constant. <br><br>**This property is read-only**. |
| Integer | Integer | Integer value if the **Type** property is set to the *redisTypeInt* constant.<br><br>**This property is read-only**. |
| String | Character string | <br><br>- If the **Type** property is set to the *redisTypeStatus* constant, this property contains the string corresponding to the returned state. <br><br>- If the **Type** property is set to the *redisTypeError* constant, this property contains the error message. <br><br>- If the **Type** property is set to the *redisTypeBuffer* constant, this property contains the buffer converted to a string using UTF-8 encoding.<br><br><br><br><br>**This property is read-only**. |
| Type | Integer | Type of result. This type can correspond to one of the following constants: <br><br>- *redisTypeBuffer* The result is a buffer. <br><br>- *redisTypeInteger* The result is an integer.<br><br>- *redisTypeErreur* The result corresponds to an error. <br><br>- *redisTypeNil* Result has no value. <br><br>- *redisTypeStatus* The result corresponds to a. <br><br>- *redisTypeTableau*: The result is an array. <br><br><br><br><br>**This property is read-only**. |
