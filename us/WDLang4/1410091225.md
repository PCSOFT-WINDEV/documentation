


## &lt;HFSQL connection&gt;.ListReindexingHistory (Function)

***In french: &lt;Connexion HFSQL&gt;.ListeHistoriqueReindexation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists the operations performed on current data files, over the last 24 hours, or on the last 1000 files. These operations include reindexing, recalculation of statistics, memo verification, index verification, etc.  

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
DatabaseConnection is Connection
arrHistoryEntries is array of hReindexingHistory 
// List of reindex/check operations in progress
arrHistoryEntries = DatabaseConnection.ListReindexingHistory()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.ListReindexingHistory()`
---

**`<Result>: (Array of hReindexingHistory variables)`**

Array of [hReindexingHistory](../WDLang4/1410091059.md) variables, containing the details of reindexing operations.

**`<Connection>: (Connection variable)`**

Connection to the server containing the data to be manipulated. This connection corresponds to the name of a variable of type [Connection](../WDLang4/1514073.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
**&lt;HFSQL connection&gt;.ListReindexingHistory** lists the following operations:

- reindexings started with [&lt;HFSQL connection&gt;.ReindexAsynchronous](../WDLang4/1410091221.md). 

- statistics calculated with [&lt;HFSQL connection&gt;.StatCalculateAsynchronous](../WDLang4/1410091224.md). 

- index verifications with [&lt;HFSQL connection&gt;.CheckIndexAsynchronous](../WDLang4/1410091223.md). 

- memo verifications with [&lt;HFSQL connection&gt;.CheckMemoAsynchronous](../WDLang4/1410091222.md).
