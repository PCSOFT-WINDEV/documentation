


## &lt;PolygonGeo variable&gt;.CoveredBy (Function)

***In french: &lt;Variable PolygoneGéo&gt;.EstCouvert***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if every point of geometry A (geographic polygon) lies inside or on the boundary of geometry B. In this case, no point of geometry A lies outside geometry B.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry A>.CoveredBy(<Geometry B>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if geometry A is covered by geometry B, 

- <u><u><u><u>False</u></u></u></u> otherwise.


If an error occurs, the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>. To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md) with the *errMessage* constant.

**`<Geometry A>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.

**`<Geometry B>: (Variable containing spatial data)`**

Variable corresponding to the second geometry. This geometry can correspond to one of the following variable types:  

- [PointGeo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [LinestringGeo](../WDLang4/1410090128.md).

- [Linestring2D](../WDLang4/1410090109.md).

- [PolygonGeo](../WDLang4/1410090127.md).

- [Polygon2D](../WDLang4/1410090122.md).

- [MultiPointGeo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiLinestringGeo](../WDLang4/1410090133.md).

- [MultiLinestring2D](../WDLang4/1410090131.md).

- [MultiPolygonGeo](../WDLang4/1410090136.md).

- [MultiPolygon2D](../WDLang4/1410090135.md).






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- This function is equivalent to [&lt;PolygonGeo variable&gt;.Cover](../WDLang4/1410090525.md) but with the parameters in reverse order. 

- The [&lt;PolygonGeo variable&gt;.Within](../WDLang4/1410090570.md) function is similar to **&lt;PolygonGeo variable&gt;.CoveredBy**. However, **&lt;PolygonGeo variable&gt;.CoveredBy** does not require the interiors of both geometries to have a point in common. A polygon covers its own boundary, but it does not contain it.



<a name="NOTE0_2"></a>


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000296"></a>

In a data file, you can apply a filter on spatial data and loop through the data file. For example, the filter can be based on the result of **&lt;PolygonGeo variable&gt;.CoveredBy**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **&lt;PolygonGeo variable&gt;.CoveredBy**. 

- Spatial_item is a spatial item in the data file. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire data file is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
