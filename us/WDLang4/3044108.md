


## HPass (Function)

***In french: HPasse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Defines the password used to create or open a data file. The password is stored and it will be used when opening or creating the data file if no password is specified.

Remarks: 

- **Attention** A password is required to encrypt data. The data encryption must be configured during the file description in the data model editor ("Details" tab).

- This password can also be specified in the functions for creating the data file ([HCreation](../WDLang4/3044255.md), [HCreationIfNotFound](../WDLang4/3044254.md)) and for opening the data file ([HOpen](../WDLang4/3044120.md)).

- **Encrypted files in an HFSQL connection**:  **Caution**: The order of use of functions for connecting to an HFSQL Client/Server database is important.. For more details, see [Optimizing the connection times to the HFSQL Client/Server databases](../WDLang4/9000176.md).


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) JDBC access: This function is not available for databases accessed via JDBC.

<a name="sample_code"></a>

## Example


```wl
// Open a data file with password and error check
HPass(CUSTOMER, "Password")
IF HCreationIfNotFound(CUSTOMER) = False THEN
	Error("HFSQL error: " + HErrorInfo())
	RETURN
END
// HErrorPassword is used to find out whether the error that occurred is a password error
IF HCreationIfNotFound() = False THEN
	// Error details
	IF HErrorPassword() = True THEN
		Error("Invalid password")
		// Code to retry
	END
END
```

## Syntax

`<Result> = HPass(<Data file> [, <Password>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the password is saved,

- <u><u><u><u>False</u></u></u></u> if an error occurred (insufficient memory for example). [HError](../WDLang4/3044088.md) and [HErrorInfo](../WDLang4/3044071.md) return more details about the problem.




**`<Data file>: (Character string)`**

Name of data file that uses a password. 
If this parameter corresponds to "\*", the password will be used for all the data files described in the analysis. 
This parameter can also correspond to the name of a [group of files (or custom-folder) defined in the analysis](../Editeurs/2011003.md) (not available in Android and Android widget). In this case, the password will be used for all the files of the group. 
If the data file is declared with [HDeclareExternal](../WDLang4/3044204.md), &lt;File name&gt; corresponds to the name of the data file alias.

**`<Password>: (Optional string or Secret string)`**

Password associated with the data file. 
If this parameter is not specified or is an empty string (""), no password is defined for the data file. The password size is not limited.


**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![HFSQL Classic](https://doc.pcsoft.fr/ext/images/us/HF.png)![HFSQL Client/Server](https://doc.pcsoft.fr/ext/images/us/HFCS.png) HFSQL data file password is case insensitive.

## Remarks


### When to use HPass?
<a name="when_use_docparampagetitleshort_ELTPARAGRAPHE000135"></a>

**HPass** must be called:

- before explicit opening or creation functions: [HOpen](../WDLang4/3044120.md), [HCreation](../WDLang4/3044255.md), [HCreationIfNotFound](../WDLang4/3044254.md).

- before the HFSQL functions that access the date files and that automatically open the data files if not already done (read, search, add, ...).




Remarks: 

- If a password is specified in the explicit opening or creation functions ([HOpen](../WDLang4/3044120.md), [HCreation](../WDLang4/3044255.md), [HCreationIfNotFound](../WDLang4/3044254.md)), the password specified in **HPass** is ignored.

- HFSQL data file passwords are case insensitive.

- To change a password on an existing data file or add a password to a data file created without a password, you must use [HChangePassword](../WDLang4/1000018781.md).



<a name="NOTE0_2"></a>


### Defining a password on a data file
<a name="defining_password_data_file_ELTPARAGRAPHE000180"></a>

A data file will be protected by password if:

- **HPass** was used before the function for creating the data file ([HCreation](../WDLang4/3044255.md) and [HCreationIfNotFound](../WDLang4/3044254.md)),

- or the password has been specified directly in the data file creation function.




**Note** A data file can be password-protected without being encrypted, and vice versa. The password is independent of data encryption. The data encryption must be configured during the file description in the data model editor ("Details" tab).
<a name="NOTE0_3"></a>


### Deleting the password defined on a data file
<a name="deleting_the_password_defined_data_file_ELTPARAGRAPHE000202"></a>

To delete a password on a data file, an automatic data file modification must be performed.

To do so, perform a modification in the analysis (modify the size of an item for example). In this case, an automatic data file modification will be proposed when the analysis is generated. You will be able to modify or delete the password associated with one or more data files.

If your data files are already deployed, specify that an automatic data file modification is required when creating the setup program. The password will be deleted or modified.

**Attention**: if you remove the password from your data files, don't forget to adapt your code.
