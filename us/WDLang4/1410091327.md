
## &lt;Connection variable&gt;.SecurityPolicyUnlockAccount (Function)

***In french: &lt;Variable Connexion&gt;.PolitiqueSécuritéDébloqueCompte***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Unlocks a user account that has been locked due too many unsuccessful login attempts.

**Note**: To use this function, you need to be connected to the HFSQL server with a "super user" account. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
IF NOT myConnection.SecurityPolicyUnlockAccount("myLockedAccount") THEN
	Trace(HErrorInfo())
END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.SecurityPolicyUnlockAccount(<User>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the account has been unlocked,

- <u><u><u><u>False</u></u></u></u> if a problem occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<User>: (Character string)`**

Name of the user whose account is to be unblocked.
