
## HFSQL Client/Server: Scheduled optimization
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000213"></a>


### Definition
<a name="definition_ELTPARAGRAPHE000009"></a>

Scheduled optimization is a mechanism for automatically optimizing databases. Scheduled optimizations periodically calculate statistics or reindex data files on the HFSQL server.

You can manage scheduled tasks:

- in the [HFSQL Control Center](#NOTE2_1).

- by [programming](#NOTE3_1).




<a name="NOTE2"></a>


## Scheduled optimization tasks in the HFSQL Control Center
<a name="scheduled_optimization_tasks_the_hfsql_control_center_ELTTEXTE000237"></a>
<a name="NOTE2_1"></a>


### Create a scheduled optimization
<a name="create_scheduled_optimization_ELTPARAGRAPHE000032"></a>

In the HFSQL Control Center, optimization tasks can be defined at server or database level.

To create an optimization task:

1. If necessary, connect to an HFSQL server and open the description of the server or one of its databases (double-click the server or database name in the tree structure). 

2. Click the "Scheduled elements" tab. 

3. In the ribbon, in the "Scheduled elements" group, expand "New scheduled job" and select "Schedule an optimization". The scheduled optimization creation wizard opens. 

4. Select the files to optimize: 

	- A database,

	- A selection of database files. 




5. Define the task frequency: month, day, hour.

6. Specify the desired action:

	- **Reindex files**: 
			This action provides optimum access to the indexes. Reindexing automatically recalculates the key statistics. 

	- **Recalculate file key statistics**: 
			This action allows for optimum data file reading. 




7. Specify data file passwords if necessary. 
	Caution: If different passwords are used on data files, it is necessary to create a different optimization task for each data file associated with a different password. 

8. Give your scheduled task a description and confirm.

9. The scheduled optimization appears in the "Scheduled elements" tab of the HFSQL Control Center.



<a name="NOTE2_2"></a>


### Deleting a scheduled optimization
<a name="deleting_scheduled_optimization_ELTPARAGRAPHE000063"></a>

To delete a scheduled optimization:

1. If necessary, connect to an HFSQL server and open the corresponding server or database tab.  

2. Click the "Scheduled elements" tab. 

3. Select the scheduled optimization you want to delete.

4. In the ribbon, in the "Scheduled elements" group, click "Delete". 
	You also have the ability to use the context menu of the scheduled element ("Delete" option). 



<a name="NOTE2_3"></a>


### Editing a scheduled optimization
<a name="editing_scheduled_optimization_ELTPARAGRAPHE000077"></a>

To edit a scheduled optimization:

1. If necessary, connect to an HFSQL server and open the corresponding server or database tab. 

2. Click the "Scheduled elements" tab. 

3. Select the scheduled optimization you want to edit.

4. In the ribbon, in the "Scheduled elements" group, click "Edit". 
	You also have the ability to use the context menu of the scheduled element ("Edit" option). 

5. A description window of the scheduled element is displayed. All the characteristics specified in the wizard are grouped in several tabs:

	- "General" tab: Indicates if the optimization is enabled.

	- "Schedule" tab: Sets the execution options for the scheduled optimization (month, day, time).




- "Content": Defines the elements included in the scheduled optimization (server, database, files, etc.) and the desired action. 

6. Confirm.

## Optimizations scheduled programmatically
<a name="optimizations_scheduled_programmatically_ELTTEXTE000273"></a>


### Creating a scheduled optimization
<a name="creating_scheduled_optimization_ELTPARAGRAPHE000113"></a>

Scheduled optimizations are managed programmatically using variables of type [hScheduledOptimization](../WDLang4/1000018854.md) and several WLanguage functions.

To programmatically create a scheduled optimization:

1. Create a variable of type [hScheduledOptimization](../WDLang4/1000018854.md) and define the various characteristics of the scheduled optimization.

2. Add the scheduled optimization with [HAddScheduling](../WDLang4/1000021447.md) (or [HAddScheduledOptimization](../WDLang4/1000018860.md)). 




Remarks: 

- To add a scheduled task, you must have:

	- the rights to manage the tasks (***hRightsManageTask*** constant).

	- the rights to run the command linked to the scheduled optimization.




- The optimization will be executed with the user credentials defined by the connection.





### Scheduled optimization execution history
<a name="scheduled_optimization_execution_history_ELTPARAGRAPHE000145"></a>

A history is created when the scheduled optimization is executed automatically (or with [HExecuteScheduling](../WDLang4/1000021453.md)). This history can be manipulated programmatically, using a variable of type [hSchedulingHistory](../WDLang4/1410090764.md) and the following functions:



|   |   |
| --- | --- |
| [HClearSchedulingHistory](../WDLang4/1410090761.md) | Clears the execution history of scheduled jobs on an HFSQL server. |
| [HDeleteSchedulingHistory](../WDLang4/1410090760.md) | Deletes the executions of a scheduled job on an HFSQL server. This job can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |
| [HListSchedulingHistory](../WDLang4/1410090762.md) | Lists the executions of a scheduled job on an HFSQL server. This job can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |






### Manipulating scheduled optimizations in WLanguage
<a name="manipulating_scheduled_optimizations_wlanguage_ELTPARAGRAPHE000157"></a>

Scheduled optimizations can be manipulated using:

- scheduled optimization functions: 
	


|   |   |
| --- | --- |
| [HAddScheduledOptimization](../WDLang4/1000018860.md) | Adds an optimization task of HFSQL Client/Server data files. |
| [HDeleteScheduledOptimization](../WDLang4/1000018865.md) | Deletes a scheduled optimization task from HFSQL Client/Server data files. |
| [HListScheduledOptimization](../WDLang4/1000018863.md) | Lists the scheduled optimization tasks of HFSQL Client/Server data files for a connection. |
| [HModifyScheduledOptimization](../WDLang4/1000018931.md) | Modifies a scheduled optimization task on the HFSQL server defined by the connection. |

- scheduled element functions (recommended): 
	


|   |   |
| --- | --- |
| [HAddScheduling](../WDLang4/1000021447.md) | Adds a scheduled operation on an HFSQL server. This operation can be a scheduled task (stored procedure), backup, optimization or a materialized view refresh. |
| [HDeleteScheduling](../WDLang4/1000021448.md) | Delete a scheduled item on an HFSQL server: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
| [HExecuteScheduling](../WDLang4/1000021453.md) | Immediately executes a scheduled item regardless of its scheduling: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
| [HListScheduling](../WDLang4/1000021452.md) | Lists scheduled elements defined on an HFSQL server: scheduled tasks (stored procedure), backup, optimization, refresh of a materialized view. |
| [HModifyScheduling](../WDLang4/1000021450.md) | Modify a scheduled item on an HFSQL server: scheduled task (stored procedure), backup, optimization, refresh of a materialized view. |
