


## &lt;Source&gt;.DataSourceKnown (Function)

***In french: &lt;Source&gt;.SourceDeDonnéesConnue***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Determines if a data source has been initialized. This function prevents errors such as "You called XXX . The YYY data source has not been initialized". 

**Difference with function [&lt;Source&gt;.QueryExecuted](../WDLang4/1410090480.md)** function: The **&lt;Source&gt;.DataSourceKnown FUNCTION** function determines whether the data source is known to the HFSQL engine, regardless of its content. [&lt;Source&gt;.QueryExecuted](../WDLang4/1410090480.md) can only be used with queries.
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
MyView is Data Source
// MyView is associated with a view

IF MyView.DataSourceKnown() = False THEN
	// Initialize the MyView variable 
	MyView.CreateView("CUSTOMER", "*", "NAME,CITY", "NAME]='A'", hViewDefault)
END
```

<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Data source to check>.DataSourceKnown()`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the data source has been initialized,

- <u><u><u><u>False</u></u></u></u> otherwise. [HErrorInfo](../WDLang4/3044071.md) returns more details about the problem.




**`<Data source to check>: (Data Source variable)`**

[Data Source](../WDLang4/1514053.md) variable to be checked. This data source can correspond to: 

- an external data file,

- an SQL query, 

- a view.

## Remarks


### How to initialize a Data Source variable
<a name="how_initialize_data_source_variable_ELTPARAGRAPHE000197"></a>

The initialization of a Data Source variable depends on its content: 

- External data file: use function [&lt;Source&gt;.DeclareExternal](../WDLang4/1000024214.md). 

- SQL queries and requests: use functions [&lt;Source&gt;.ExecuteQuery](../WDLang4/1000024944.md), [&lt;Source&gt;.ExecuteSQLQuery](../WDLang4/1000024948.md), etc. 

- HFSQL view: use function [&lt;Source&gt;.CreateView](../WDLang4/1000024209.md). 




For more details, see the help page on the [Data Source](../WDLang4/1514053.md) variable type.
