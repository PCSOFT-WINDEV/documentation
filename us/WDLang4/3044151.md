


## HChangeKey (Function)

***In french: HChangeClé***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Changes the browse item. The current record is not modified.

After the function is executed, the browse is performed from the current record, according to the new browse item. **HChangeKey** can be used to start browsing a data file, after being positioned on a record with direct access (with [HRead](../WDLang4/3044047.md) for example).

**Remark**: This function can be used on a data file, a query or an HFSQL view..

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003044151&name=hchangekey_function">See additional examples</a>

```wl
// Change the search key
IF HChangeKey(Customer, Name) = False THEN
	Error("Select a customer in the table")
END
```

## Syntax

`<Result> = HChangeKey(<Data file> [, <Item> [, <Browse mode>]])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the search key was modified, 

- <u><u><u><u>False</u></u></u></u> in the event of a problem (e.g. no read function preceded the key change): the route key is not modified. [HError](../WDLang4/3044088.md) is used to identify the error.




**`<Data file>: (Character string)`**

Name of data file, HFSQL view or query used.

**`<Item>: (Optional character string)`**

Name of the new browse item. 
If this name is not specified, the function **HChangeKey** function will use the last browse item specified on this data file by the last HFSQL management function (function starting with the letter H).

**`<Browse mode>: (Optional Integer constant)`**

Characteristics of the data file browse on the new key:


|   |   |
| --- | --- |
| *hKeepFilter* | The filter set by [HFilter](../WDLang4/3044100.md) will be taken into account, even if the search key is not optimized for the filter. <br>**Reminder** function [HFilter](../WDLang4/3044100.md) returns the optimized route key for the filter.<br>**Caution**: In this case, on large data files, performance problems may arise. |


![Hyper File 5.5](https://doc.pcsoft.fr/ext/images/us/HF55.png) The &lt;Browse mode&gt; parameter cannot be used.
