


## HDeleteScheduledBackup (Function)

***In french: HSupprimeSauvegardePlanifiée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Deletes a scheduled backup from an HFSQL Client/Server server.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
ctMyDatabase is Connection
// Delete all scheduled backups
arrBckDesc is array dynamic of hBackupDescription 
arrBckDesc = HListScheduledBackup(ctMyDatabase)
hBckDesc is hBackupDescription
FOR EACH hBckDesc OF arrBckDesc
	IF Position(hBckDesc.Source, ctMyDatabase.Database, 0, IgnoreCase) > 0 THEN
		HDeleteScheduledBackup(ctMyDatabase, hBckDesc.Identifier)
	END
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HDeleteScheduledBackup(<Connection> , <Scheduled backup>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the scheduled backup has been deleted, 

- <u><u><u><u>False</u></u></u></u> if an error occurs. [HErrorInfo](../WDLang4/3044071.md) is used to identify the error.




**`<Connection>: (Character string or Connection variable)`**

Connection for which the scheduled backup must be deleted. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).




**`<Scheduled backup>: (Integer)`**

Identifier of the scheduled backup to delete.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


### Necessary rights
<a name="necessary_rights_ELTPARAGRAPHE000089"></a>

To have the rights to delete a scheduled backup, you must: 

- be the owner of the scheduled backup. 

- or be a super-user.
