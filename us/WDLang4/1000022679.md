


## &lt;Connection variable&gt;.InfoBackup (Function)

***In french: &lt;Variable Connexion&gt;.InfoSauvegarde***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns information about one or more backups performed on an HFSQL Client/Server server.

The backups have been performed by [&lt;Connection variable&gt;.Backup](../WDLang4/1000022752.md) (or via the HFSQL Control Center) and they can be restored by [&lt;Connection variable&gt;.RestoreBackup](../WDLang4/1000022751.md) (or via the HFSQL Control Center).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connection description
gctConnection is Connection

// Displays information about the backups in a Table control
sReport is string = gctConnection.InfoBackup()
sLine is string
FOR EACH STRING sLine OF sReport SEPARATED BY EOT
	IF sLine ~="" THEN CONTINUE
	TABLE_Backups.Add()
	nSub is int = TABLE_Backups.Count()
	TABLE_Backups.COL_BackupID[nSub] = ExtractString(sLine, 1)
	TABLE_Backups.COL_DateTime[nSub] = ExtractString(sLine, 2)
	TABLE_Backups.COL_Filter[nSub] = ExtractString(sLine, 3)
	TABLE_Backups.COL_Name[nSub] = ExtractString(sLine, 4)
	TABLE_Backups.COL_Description[nSub] = ExtractString(sLine, 5)
	TABLE_Backups.COL_Status[nSub] =  ...
			SWITCH(Val(ExtractString(sLine, 6)) + 1, "In progress", "Completed", "Canceled", "Error")
	TABLE_Backups.COL_PerThousand[nSub] = ExtractString(sLine, 7)
END
```

## Syntax

### Information about the backups performed on the server

`<Result> = <Connection>.InfoBackup()`
---

**`<Result>: (Character string)`**

Description of backups performed on the specified server. This description has the following format: 

```txt
<Identifier of backup 1> + TAB + <Date of backup 1> + TAB + 
<Files saved> + TAB + <Destination path of backup 1> + TAB + 
<Description> + TAB + <Status> + TAB + <Per thousand> + TAB + <Error Message> + TAB + 
<Type> + TAB + <Server name> + TAB + <Full backup ID> + TAB +
<With index> + TAB + <Compression> + TAB + <Task identifier> + EOT
```
 where:

- &lt;Files saved&gt; is the list of data saved separated by semicolons (";"). 
	&lt;Status&gt; corresponds to an integer (or to an Integer constant) used to get the backup status:
	


|   |   |   |
| --- | --- | --- |
| *hBackupCanceled* | 2 | Backup canceled |
| *hBackupCompleted* | 1 | Backup completed |
| *hBackupError* | 3 | Error during backup |
| *hBackupInProgress* | 0 | Backup in progress |



- &lt;Per thousand&gt; corresponds to the rate of backup completion if the backup is in progress (expressed in per thousand).

- &lt;Error Message&gt; is the error message if the backup failed.

- &lt;Type&gt; corresponds to an integer (or to an Integer constant) used to identify the type of backup: 
	


|   |   |   |
| --- | --- | --- |
| *hBackupDifferential* | 1 | Differential backup |
| *hBackupFull* | 0 | Full backup |



- &lt;Full backup IPD&gt;: Identifier of the corresponding full backup in the case of a differential backup.

- &lt;Server name&gt;: Backup server name. 

- &lt;With Index&gt;: Determines whether the backup contains the indexes:

	- 0 if the backup of indexes was not performed,

	- 1 if the backup of indexes was performed. 




- &lt;Compression&gt;: Constant representing the backup compression:

	- *zipFormatNone*: The backup is not compressed.

	- *zipFormatZIP*: The backup is compressed. 




- &lt;Task ID&gt; Identifier of the scheduled backup that created the backup.


Note: The separator used between the different descriptions is "EOT" (and not "RC") as the different description parameters may contain Carriage Returns (RC).

**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to the server whose backups will be listed.

### Information about a specific backup

`<Result> = <Connection>.InfoBackup(<Backup identifier>)`
---

**`<Result>: (Character string)`**

Description of specified backup on the specified server. This description has the following format:

```txt
<Identifier of backup 1> + TAB + <Date of backup 1> + TAB + 
<Files saved> + TAB + <Destination path of backup 1> + TAB + 
<Description> + TAB + <Status> + TAB + <Per thousand> + TAB + <Error Message> + TAB + 
<Type> + TAB + <Server name> + TAB + <Full backup ID> + TAB + <With index> + TAB + 
<Compression> + TAB + <Task identifier> + EOT
```

 where:

- &lt;Files saved&gt; is the list of data saved separated by semicolons (";"). 
	&lt;Status&gt; corresponds to an integer (or to an Integer constant) used to get the backup status:
	


|   |   |   |
| --- | --- | --- |
| *hBackupCanceled* | 2 | Backup canceled |
| *hBackupCompleted* | 1 | Backup completed |
| *hBackupError* | 3 | Error during backup |
| *hBackupInProgress* | 0 | Backup in progress |



- &lt;Per thousand&gt; corresponds to the rate of backup completion if the backup is in progress (expressed in per thousand).

- &lt;Error Message&gt; is the error message if the backup failed.
	&lt;Type&gt; corresponds to an integer (or to an Integer constant) used to identify the type of backup:
	


|   |   |   |
| --- | --- | --- |
| *hBackupDifferential* | 1 | Differential backup |
| *hBackupFull* | 0 | Full backup |



- &lt;Full backup ID&gt; corresponds to the identifier of the corresponding full backup in case of differential backup.

- &lt;Server name&gt; Name of the backup server. 

- &lt;With Index&gt;: Determines whether the backup contains the indexes:

	- 0 if the backup of indexes was not performed,

	- 1 if the backup of indexes was performed. 




- &lt;Compression&gt;: Constant representing the backup compression: 

	- *zipFormatNone*: The backup is not compressed.

	- *zipFormatZIP*: The backup is compressed. 





Note: The separator used between the different descriptions is "EOT" (and not "RC") as the different description parameters may contain Carriage Returns (RC). 

- &lt;Task ID&gt; Identifier of the scheduled backup that created the backup.




**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to the server that performed the backup.

**`<Backup identifier>: (Integer)`**

Identifier of the backup for which to get the characteristics. This identifier is returned by [&lt;Connection variable&gt;.Backup](../WDLang4/1000022752.md).

## Remarks


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000418"></a>

- **&lt;Connection variable&gt;.InfoBackup** is used to list the tasks performed or the current tasks. The scheduled tasks that have not been performed are not listed.

- The backups performed by the HFSQL Control Center and the ones performed programmatically are listed.

- The dates and times are expressed in universal time (UTC).



<a name="NOTE0_2"></a>


### Necessary rights
<a name="necessary_rights_ELTPARAGRAPHE000434"></a>

To get in formation about a backup, the user or the group must have: 

- for each database affected by the backup, the rights to perform backups (*hRightsBackup* constant) or the rights to connect (*hRightsConnection* or *hRightsEncryptedConnection* constant). 

- for a full server backup, the rights to perform backups (*hRightsBackup* constant) on the server. 




To determine whether these rights are granted to a user or to a group, use [&lt;Connection variable&gt;.InfoServerRights](../WDLang4/1000022668.md) or [&lt;Connection variable&gt;.InfoDatabaseRights](../WDLang4/1000022666.md).

To modify the rights granted to a user or group of users, use [&lt;Connection variable&gt;.ModifyServerRights](../WDLang4/1000022710.md) or [&lt;Connection variable&gt;.ModifyDatabaseRights](../WDLang4/1000022707.md).
