


## HClusterSynchronizationErrorInfo (Function)

***In french: HClusterInfoErreurSynchronisation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the error that occurred during the previous synchronization step of HFSQL Cluster.

Reminder: Synchronization is automatically performed, for example, when a cluster node has stopped abnormally: on restart, this node synchronizes with another node containing the updated data.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sSyncError is string
sSyncError = HClusterSynchronizationErrorInfo("MyCoordinator", "MyPassword", "NodeName")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HClusterSynchronizationErrorInfo(<Coordinator> , <Password> , <Node>)`
---

**`<Result>: (Character string)`**

Error that occurred during the last synchronization.

**`<Coordinator>: (Character string)`**

DNS name of the cluster coordinator's machine.

**`<Password>: (Character string or Secret string)`**

Password used to connect to the coordinator. This password was given when .
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). 

**`<Node>: (Character string)`**

DNS name of node to use.
