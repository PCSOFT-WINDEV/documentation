
## Parameters of the procedure used by HCheckIndexAsynchronous



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
WLanguage procedure ("callback") called by [HCheckIndexAsynchronous](../WDLang4/1410091105.md) for each HFSQL Client/Server data file checked.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyConnection1 is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
ArrayAdd(FileArray, MyFileParam)

HCheckMemoAsynchronous(MyConnection1, FileArray, Callback_HCheckMemoAsynchronous)

	INTERNAL PROCEDURE Callback_HCheckIndexAsynchronous(MyFile is string, 
			MyResult is int, Report is string)
		Res is string
		SWITCH MyResult
			CASE 0: Res = "Correct index"
			CASE 1: Res = "The file requires optimization."
			CASE 2: Res = "HFSQL error" + HErrorInfo() 
		END
		Trace("File processed: " + MyFile)
		Trace("Function result: ", Res)
		Trace("Summary: " + Replace(Report, CR, "<CR>"))
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HCheckIndexAsynchronous_Callback(<Data file> , <Check result> , <Status report>)`
---

**`<Data file>: (Character string)`**

Name of the HFSQL Client/Server data file manipulated. 

**`<Check result>: (Integer)`**

Can correspond to: 

- 0 if the check is correct.

- 1 if the index is corrupted. This means that a reindex is required ([HIndex](../WDLang4/3044133.md) or [HReindexAsynchronous](../WDLang4/1410091053.md)).

- 2 in the event of an HFSQL error: Inaccessible data file, etc.

- 3 if the function is not supported by this type of data file (xBase, AS400, etc.).




**`<Status report>: (Character string)`**

Status report if a problem is found in the index file. This report has the following format:
```txt
<Name of affected key> + TAB + <Record number causing problem> + CR + 
<Name of affected key 2> + TAB + <Record number causing problem 2> ...
```

&lt;Record number causing problem&gt; is equal to -1 if no record was defined.
