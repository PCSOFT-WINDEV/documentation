


## DSVFormat (Variable type)

***In french: FormatDSV***
			
				



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
The **DSVFormat** is used to define and change characteristics of the Delimiter Separated Values (DSV) format. 
The (Delimiter Separated Values) DSV format is a spatial data serialization format in which the user can choose custom delimiters to generate the character string representing their data.

This type of variable is used by [GeometrySerializeDSV](../WDLang4/1410090121.md). 

You can define and change the characteristics of this format using different WLanguage properties. 

**Remark**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).
<a name="Example1"></a>
<a name="sample_code"></a>

## Example


```wl
myLine is Linestring2D
myLine.AddPoint(31, 21)
myLine.AddPoint(32, 22)
myLine.AddPoint(33, 23)

myFormat is DSVFormat
myFormat.CoordinateSeparator = ", "
myFormat.PointOpen = "("
myFormat.PointClose = ")"
myFormat.PointSeparator = "; "
myFormat.ListOpen = "["
myFormat.ListClose = "]"

Trace(GeometrySerializeDSV(myLine, myFormat))
```

## Properties


### Properties specific to DSVFormat variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000033"></a>

The following properties can be used to manipulate a variable of type **DSVFormat**:

| Property name | Type used | Effect |
| --- | --- | --- |
| ListOpen | ANSI character string | Character opening the declaration of a list of points.<br><br>Example: <br>Points (1, 2) and (3, 4) with "{" as opening character of the list, "}" as closing character of the list and ";" as point separator: "{(1, 2); (3, 4)}". |
| CoordinateSeparator | ANSI character string | String used to separate the coordinates of a point.<br><br>Example: <br>Point (1, 2) with ";$;" as separator: "(1;$;2)". |
| ListClose | ANSI character string | Character closing the declaration of a list of points.<br><br>Example: <br>Points (1, 2) and (3, 4) with "{" as opening character of the list, "}" as closing character of the list and ";" as point separator: "{(1, 2); (3, 4)}". |
| ListSeparator | ANSI character string | String used to separate lists in a list of lists of points.<br><br>Example: lists ((1, 2), (3, 4) and ((5, 6), (7, 8)) with "LSEP" as list separator: "(((1, 2), (3, 4)) LSEP ((5, 6), (7, 8)))". |
| PointClose | ANSI character string | Character closing the declaration of a point. <br><br>Example: <br>Point (1, 2) with "[" as opening character, "]" as closing character, and ", " as coordinate separator: "[1, 2]". |
| PointOpen | ANSI character string | Character opening the declaration of a point. <br><br>Example: <br>Point (1, 2) with "[" as opening character, "]" as closing character, and ", " as coordinate separator: "[1, 2]". |
| PointSeparator | ANSI character string | String used to separate points in a list of points.<br><br>Example: points (1, 2) and (2, 3) with "! " as point separator: "(1, 2)! (2, 3)". |
