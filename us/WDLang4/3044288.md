


## HListDatabase (Function)

***In french: HListeBaseDeDonnées***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lists the Client/Server databases associated with a connection.
![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Lists the databases associated with a MySQL connection.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Describe the connection
HDescribeConnection("MyConnection", "Julia", "Password", ...
		"MyHFServer", "", hAccessHFClientServer, HORead)
// Open the connection
HOpenConnection("MyConnection")
...
// Add the databases of "MyConnection" into an edit control
EDT_Edit1 = HListDatabase("MyConnection")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = HListDatabase(<Connection> [, <Options>])`
---

**`<Result>: (Character string)`**

List of databases of the server defined by the connection. The result is more or less detailed depending on the constant used:


|   |   |
| --- | --- |
| *hLstNormal* | Lists the databases of the server defined by the connection:<br>&lt;Name of database 1&gt; + TAB + &lt;Name of database 2&gt; + TAB + ... |
| *hLstFile* | Lists the databases and their files for the server defined by the connection:<br>&lt;Database Name 1&gt; + TAB + &lt;Data File Name 1 in Database 1&gt; + TAB + ... + CR + &lt;Database Name 2&gt; + TAB + &lt;Data File Name 1 in Database 2&gt; + TAB + ... + CR + ... |
| *hLstDatabaseSize* | Lists the databases and their size (in bytes) for the server defined by the connection:<br>&lt;Name of database 1&gt; + TAB + &lt;Size of database 1&gt; + CR + &lt;Name of database 2&gt; + TAB + &lt;Size of database 2&gt; + CR + ...<br>![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available. |


Where:

- &lt;Nom de la base de données X&gt; Database name.

- &lt;Nom du fichier de données Y dans la base de données X&gt; Name of physical data file Y in database X.

- &lt;Taille de la base de données X&gt; Size of all the files making up the database in bytes. 




If an error occurs, the list of databases corresponds to an empty string ("") and [HError](../WDLang4/3044088.md) is used to identify the error.

**`<Connection>: (Character string or Connection variable)`**

Connection to use. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md). 




**`<Options>: (Optional Integer constant (or combination of constants))`**

Type of list to perform:


|   |   |
| --- | --- |
| *hLstFile* | Detailed list, used to find out the files associated with each database. |
| *hLstNormal*<br>(default value) | Non-detailed list, containing the name of the databases associated with a connection. |
| *hLstDatabaseSize* | Detailed list, used to find out the size of all the files associated with each database.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) Not available. |
