


## &lt;Connection variable&gt;.ListWatchedFiles (Function)

***In french: &lt;Variable Connexion&gt;.ListeFichiersSurveillés***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>29 (74)</B>, ***Variable Connection.ListTrackedFiles*</**>** is kept for backward compatibility. This function has been replaced with ***&lt;Connection variable&gt;.ListWatchedFiles*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the list of data files watched by [&lt;Source&gt;.Watch](../WDLang4/1000025029.md).

Caution: 

- This function can only be used in Client/Server mode. 

- The list will contain the data files being watched when the function is called. If data files are no longer being watched ([&lt;Source&gt;.WatchStop](../WDLang4/1000025030.md)), they will not appear in the list.

<a name="sample_code"></a>

## Example


```wl
MyConnection is Connection
MyWatchedFiles is array of strings
MyWatchedFiles = MyConnection.ListWatchedFiles()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.ListWatchedFiles()`
---

**`<Result>: (WLanguage array)`**

Array of strings containing the watched data files.

**`<Connection>: (Connection variable)`**

Name of a variable of type [Connection](../WDLang4/1514073.md) corresponding to the connection used.
