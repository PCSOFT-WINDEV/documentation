


## GeometryCoveredBy (Function)

***In french: GéométrieEstCouvert***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Determines if every point of geometry A lies inside or on the boundary of geometry B. In this case, no point of geometry A lies outside geometry B.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Create a large polygon
o2DPolygon_1 is Polygon2D
Linestring2DAddPoint(o2DPolygon_1.Outline, 5.00, 3.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 4.00, 5.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, 4.00, -3.00)
Linestring2DAddPoint(o2DPolygon_1.Outline, -4.00, -3.00)
// Add last point (same as first)
Linestring2DAddPoint(o2DPolygon_1.Outline, 5.00, 3.00)

// Create a smaller polygon inside the larger one
o2DPolygon_2 is Polygon2D
Linestring2DAddPoint(o2DPolygon_2.Outline, -2.00, 1.00)
Linestring2DAddPoint(o2DPolygon_2.Outline, 3.00, 1.00)
Linestring2DAddPoint(o2DPolygon_2.Outline, 0.00, -1.00)
// Add last point (same as first)
Linestring2DAddPoint(o2DPolygon_2.Outline, -2.00, 1.00)

// Test GeometryCoveredBy and GeometryWithin
// -------------------------------------------------------
GeometryCoveredBy(o2DPolygon_2, o2DPolygon_1) // True
GeometryWithin(o2DPolygon_2, o2DPolygon_1) // Also True

GeometryCoveredBy(o2DPolygon_1.Contour, o2DPolygon_1) // True: A polygon COVERS its own boundary.
GeometryWithin(o2DPolygon_1.Outline, o2DPolygon_1) // False: A polygon DOES NOT CONTAIN its own boundary.
```

## Remarks


- This function is equivalent to [GeometryCover](../WDLang4/1410090140.md) but with the parameters in reverse order. 

- The [GeometryWithin](../WDLang4/1410090139.md) function is similar to **GeometryCoveredBy**. However, **GeometryCoveredBy** does not require the interiors of both geometries to have a point in common. A polygon covers its own boundary, but it does not contain it.



<a name="NOTE0_2"></a>


### Accessing spatial data using spatial indexes
<a name="accessing_spatial_data_using_spatial_indexes_ELTPARAGRAPHE000331"></a>

In a data file, you can apply a filter on spatial data and loop through the data file. For example, the filter can be based on the result of **GeometryCoveredBy**.

It is recommended to use the following syntax to apply a filter on spatial data: 

```txt
FOR EACH File WHERE WLanguage_function(File.Spatial_item, Spatial_variable)
```

where: 

- WLanguage_function corresponds to **GeometryCoveredBy**. 

- Spatial_item is a spatial item in the data file. This item must: 

	- be of type "Geographic data" or "Geometric data".   

	- be defined as a "Spatial key". 




- Spatial_variable is a given spatial variable, used for comparison with the spatial item. This variable can be of type PolygonGeo, Polygon2D, etc.   




Note: The "FOR EACH File" syntax is available but not recommended, as it doesn't use spatial indexes and is therefore not optimized. In this case, the entire data file is looped through and spatial indexes are not used. 

```txt
FOR EACH File 
	IF WLanguage_function(File.Spatial_item, Spatial_variable) = True THEN
    ...
    END
END
```
Example: 


```wl
// Define a triangle delimiting a geographic area
// Store this triangle in a variable of type PolygonGeo 
polyGeo is PolygonGeo
polyGeo.Outline.AddPoint(0n48.8187479172765, 0n1.9550104465229536)
polyGeo.Outline.AddPoint(0n48.685649220185574, 0n2.023674998054354)
polyGeo.Outline.AddPoint(0n48.82612543243871, 0n2.2106580854197566)
polyGeo = GeometryCorrect(polyGeo)
// Search for municipalities with territory within the specified triangle
NumberOfRecords is int
FOR EACH MunicipalityData WHERE GeometryCoveredBy(MunicipalityData.geometry, polyGeo) 
	// Name of municipality in a trace window
	Trace(MunicipalityData.MunicipalityName)
END
```
