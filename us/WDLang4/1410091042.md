


## HExecuteAsynchronousProcedure (Function)

***In french: HExécuteProcédureAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Executes a stored procedure in asynchronous mode. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
INTERNAL PROCEDURE MyClientCallback(CSPResult is Variant)
		Trace("My callback " + CPSResult)
END
let sResult = HExecuteAsynchronousProcedure(MyConnection1, StoredProcedure, ...
			(PParameter), MyClientCallback)
Trace(sResult)
Trace("End SP")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HExecuteAsynchronousProcedure(<Connection> , <Stored procedure> , <Parameter 1> ... [, <Parameter N> [, <End WLanguage procedure>]])`
---

**`<Connection>: (String or Connection variable)`**

Connection to the server that runs the stored procedure. This connection corresponds to: 

- the name of the connection defined in the data model editor or with [HDescribeConnection](../WDLang4/3044205.md) or [HOpenConnection](../WDLang4/3044107.md).

- the name of a variable of type [Connection](../WDLang4/1514073.md).




**`<Stored procedure>: (WLanguage procedure)`**

Name of the stored procedure to run.

**`<Parameter 1>: (Optional variant)`**

First parameter to pass to &lt;Stored procedure&gt;.



**`<Parameter N>: (Optional variant)`**

Nth parameter to pass to &lt;Stored procedure&gt;.

**`<End WLanguage procedure>: (Optional procedure name)`**

WLanguage procedure ("callback") executed at the end of the execution of the procedure. This procedure has the following format: 

```txt
PROCEDURE ProcedurenName(<Response> is a variant)
```
 where &lt;Response&gt; is the response of the stored procedure. 

- The [ErrorOccurred](../WDLang1/3087001.md) variable used in this procedure is set to <u><u><u><u>True</u></u></u></u> if the stored procedure encounters an error (execution error, loss of connection, etc.). 
	In the event of an automation reconnection, **HExecuteAsynchronousProcedure** is not called again automatically.  

- This procedure is executed in the copy of the HFSQL context made when **HExecuteAsynchronousProcedure** is called.

<a name="NOTE0_1"></a>

## Remarks


### Automatic error handling
<a name="automatic_error_handling_ELTPARAGRAPHE000105"></a>

Automatic error handling is disabled in stored procedures. However, [HOnError](../WDLang4/3044017.md) can be used to run a specific procedure (stored procedure).
<a name="NOTE0_2"></a>


### Passing parameters
<a name="passing_parameters_ELTPARAGRAPHE000117"></a>

Parameters are passed by value. If these parameters are modified in the stored procedure, they will remain unchanged in the applications that executed the procedure. This is the oppositite behavior, compared with [HExecuteProcedure](../WDLang4/3044358.md).
<a name="NOTE0_3"></a>


### Running a stored procedure from an SQL code
<a name="running_stored_procedure_from_sql_code_ELTPARAGRAPHE000129"></a>

A stored procedure can be called: 

- from SQL code, with [HExecuteSQLQuery](../WDLang4/3044084.md) or [SQLExec](../WDLang4/3072007.md) for example, 

- from an external application that uses the [ODBC driver for HFSQL](../WDLang4/9000160.md) or the [OLE DB provider for HFSQL](../WDLang4/9000059.md). 




For more details, see [Stored procedures and queries (HFSQL Client/Server)](../WDLang4/3044360.md).
