


## HClusterStart (Function)

***In french: HClusterDémarre***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Starts an HFSQL cluster. This cluster was stopped beforehand (by [HClusterStop](../WDLang4/1000019058.md) for example).

**Note**: This function is for advanced use only.. We recommend that you use the HFSQL Control Center to manage an HFSQL cluster.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Start the cluster
HClusterStart("clustermanager.mydomain.com", "secret")
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = HClusterStart(<Coordinator> , <Password>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the function was successful,

- <u><u><u><u>False</u></u></u></u> otherwise. For more details on the error, use [ErrorInfo](../WDLang1/3013008.md). 




**`<Coordinator>: (Character string)`**

DNS name of the cluster coordinator's machine.

**`<Password>: (Character string or Secret string)`**

Password used to connect to the coordinator. This password was given when [installing the cluster](../WDLang4/1000019031.md).
**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI or Unicode string".
To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md).
