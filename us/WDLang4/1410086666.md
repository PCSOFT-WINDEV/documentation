
## &lt;Connection variable&gt;.SecurityPolicyGet (Function)

***In french: &lt;Variable Connexion&gt;.PolitiqueSécuritéRécupère***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the security policy of an HFSQL server. 

Retrieved information varies depending on the type of user:

- In the case of "super users", all security policy information is retrieved. 

- For other user types, only the password complexity and minimum length criteria are retrieved. This information can be used to create a password that meets these criteria.  





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
let myPolicy = myConnection.SecurityPolicyGet()
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.SecurityPolicyGet()`
---

**`<Result>: (hSecurityPolicy variable)`**

[hSecurityPolicy](../WDLang4/1410091181.md) variable corresponding to the password security policy currently implemented on the HFSQL server.

**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.
