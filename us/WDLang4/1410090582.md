


## &lt;PolygonGeo variable&gt;.SerializeWKT (Function)

***In french: &lt;Variable PolygoneGéo&gt;.SérialiseWKT***



<a name="XUse"></a>
<a name="Use"></a>
<a name="description"></a>
Serializes a geographic polygon using the Well-Known Text (WKT) format. This format corresponds to an ANSI string.
<a name="XSYNTAX"></a>

## Syntax
<a name="SYNTAX1"></a>

`<Result> = <Geometry>.SerializeWKT([<Precision>])`
---

**`<Result>: (ANSI character string)`**

WKT representation of the specified geometry.

**`<Geometry>: (PolygonGeo variable)`**

Name of the [PolygonGeo](../WDLang4/1410090127.md) variable to be used.

**`<Precision>: (Optional integer)`**

Precision of coordinates, corresponding the the number of significant digits (i.e., total digits in the number, not only digits after the point). By default, this parameter is set to 8.
