
## &lt;Connection variable&gt;.SecurityPolicyCheck (Function)

***In french: &lt;Variable Connexion&gt;.PolitiqueSécuritéVérifie***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks that each user accounts complies with the password security policy associated with the HFSQL server. 

Note: To use this function, you need to be connected to the HFSQL server with a "super user" account. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
Trace(MyConnection.SecurityPolicyCheck())
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.SecurityPolicyCheck(<Type of check>)`
---

**`<Result>: (Character string)`**

List of users that match the criteria of the security check. User names are separated by carriage returns (CR).

**`<Connection>: (Connection variable)`**

Name of the [Connection](../WDLang4/1514073.md) variable that describes the connection to use.

**`<Type of check>: (Integer constant)`**

Type of verification:



|   |   |
| --- | --- |
| *hLockedOutAccount* | Returns a list of users whose accounts have been locked. <br><br>Note: To unlock a locked account, use [&lt;Connection variable&gt;.SecurityPolicyUnlockAccount](../WDLang4/1410091327.md). |
| *hPasswordCheckExpiration* | Returns a list of users who have exceeded the password validity period. |
