


## &lt;HFSQL connection&gt;.CheckMemoAsynchronous (Function)

***In french: &lt;Connexion HFSQL&gt;.VérifieMémoAsynchrone***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Checks the structural integrity of memos in an HFSQL Client/Server data file. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
DatabaseConnection is Connection
FileArray is array of hFileParameter

MyFileParam is hFileParameter
MyFileParam.Name = "AvailableAction"
// MyFileParam.Password = ""
// The Option property is ignored
FileArray.Add(MyFileParam)

DatabaseConnection,.CheckMemoAsynchronous(FileArray, CB_HCheckMemoAsynchronous)
	INTERNAL PROCEDURE CB_HCheckMemoAsynchronous(MyFile is string, MyResult is string)
		IF MyResult = "" THEN
			Trace("File processed and checked" + MyFile)
		ELSE
			Trace("File processed. Some problems were found " + MyFile)
		END
	END
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = <Connection>.CheckMemoAsynchronous(<Data files to check> [, <WLanguage procedure>])`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the check has been started,

- <u><u><u><u>False</u></u></u></u> otherwise.




**`<Connection>: (Connection variable)`**

Connection to the server containing the data files to be manipulated. This connection corresponds to the name of a variable of type [Connection](../WDLang4/1514073.md).

**`<Data files to check>: (Array of hFileParameter variables)`**

Name of the array of [hFileParameter](../WDLang4/1000018900.md) variables corresponding to the list of data files to be processed.

**`<WLanguage procedure>: (Optional procedure name)`**

Name of the WLanguage procedure ("callback") called for each data file processed. This procedure is used to manipulate the current data file.

For more details on this procedure, see [Parameters of the procedure used by &lt;HFSQL connection&gt;.CheckMemoAsynchronous](../WDLang4/1410091106.md).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks


- The list of free blocks is checked in HFSQL Client/Server only.

- **&lt;HFSQL connection&gt;.CheckMemoAsynchronous** is faster than [&lt;HFSQL connection&gt;.ReindexAsynchronous](../WDLang4/1410091221.md) with the *hCheckMemo* constant.. 

- If a problem is detected, you can use [&lt;HFSQL connection&gt;.ReindexAsynchronous](../WDLang4/1410091221.md) with the *hCheckMemo* constant.
