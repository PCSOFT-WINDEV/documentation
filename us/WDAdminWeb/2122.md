## ERR_ALREADYCONNECTED error
<a name="erralreadyconnected_error_ELTTEXTE000062"></a>
The connection is refused because you are already connected to this site - ERR_ALREADYCONNECTED 

The maximum number of connections for a single Web user on a dynamic WEBDEV website has been reached. The Web user must disconnect from one of the sites.

**Reminder**: The maximum number of connections by a single user to a dynamic WEBDEV site is configured in the local or remote WEBDEV administrator.
