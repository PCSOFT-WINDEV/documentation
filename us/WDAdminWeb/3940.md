## ERR_BAD_CONTEXT_INVALID error
<a name="errbadcontextinvalid_error_ELTTEXTE000070"></a>
The ERR_BAD_CONTEXTE_INVALID error, followed by a number, indicates that a request has been made to the WEBDEV server with a reference to a context that is no longer valid.. 

This situation generally occurs when links from the browsing history or cache are no longer correct.. It is important to note that these situations are not considered errors in the strict sense, but rather a protection mechanism built into dynamic WEBDEV sites.. 

This mechanism is designed to prevent users from accessing information displayed during a previous session or by another user.. Most of these accesses are usually carried out by search engines and tools such as monitoring robots.

However, the ERR_BAD_CONTEXTE_INVALID error can be considered a real error in certain cases, in particular when it occurs while the same user is browsing the site without having voluntarily logged out.. 

Possible reasons for disconnection include:

- Stopping and restarting the WEBDEV administrator while the user is browsing.

- Forced logout from WEBDEV administrator.

- Use of the **FinProgram** function in the application code to intentionally close the session without redirecting the user to a logout page.

- A fatal session error caused by the application code.
