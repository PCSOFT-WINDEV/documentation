### Error while starting the site 
<a name="error_while_starting_the_site_ELTPARAGRAPHE000007"></a>

The dynamic site cannot be started because it is automatically closed.
Check whether **EndProgram** is not used in the initialization code of the project (or any other function or process that stops your site).
