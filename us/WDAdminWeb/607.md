### ERR_BAD_CONFIG: &lt;NOM_APPLICATION&gt; site configuration is incorrect for value %s. 
<a name="errbadconfig_site_configuration_incorrect_for_value_ELTPARAGRAPHE000007"></a>

This error is caused by a wrong setup of the dynamic WEBDEV website in the registry. You must:

- re-install the site.

- correct the site configuration in the registry.




**Reminder**: When a dynamic WEBDEV site is installed, a new entry is created in the registry.
A new entry is created in the following key:


- In 32 bits: 
	
	```txt
	"HKEY_LOCAL_MACHINE\SOFTWARE\PC SOFT\WEBDEV\24.0\Applications\<NomProjet>"
	```


- In 64 bits: 
	
	```txt
	"HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\PC SOFT\WEBDEV\24.0\Applications\<NomProjet>"
	```





The project name and directory are specified.
