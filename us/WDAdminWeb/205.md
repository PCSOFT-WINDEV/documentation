
## Remote WEBDEV administrator: Backing up and restoring a WEBDEV site
			



## Manage the backups
<a name="manage_the_backups_ELTTEXTE000092"></a>
The remote administration tool is used to manage the backups of your dynamic WEBDEV websites. You can:

- Retrieve a backup performed during the remote update of a site.

- Perform a backup of the site (to process the data files in a Back Office application for example).




The management of backups is performed from the "Sites" or "web services" tab of the remote administrator. 


### Restore a backup
<a name="restore_backup_ELTPARAGRAPHE000015"></a>

Backup recovery involves restoring the site (HTML pages, images, etc.) and associated data files to the state they were in at the time of the last backup. This last backup was performed during the remote update of the WEBDEV site ("Do not destroy the site backup after the update" checked).

**Caution**:

- Restoring a backup disconnects all the Web users.

- Only the last backup can be restored.





### Downloading site and its data files
<a name="downloading_site_and_its_data_files_ELTPARAGRAPHE000025"></a>

This option is used to create an archive of your site. This archive can be retrieved locally. The files found in this archive can be extracted in order to be processed thereafter.

**You have the ability to use a backup performed by the remote administrator to transfer the data files from the WEBDEV website to the company head office**. Then, these files can be extracted from the archive and processed by a Back Office application developed in WINDEV for example.

The backup includes one or two archive files in ".ZIP" format:

- a &lt;SiteName&gt;_Fic.ZIP file and a &lt;SiteName&gt;_App.ZIP file if the site files and the data files are found in different directories.

- a single .ZIP file if the data files are found in a subdirectory of the site.




These files are created in the FTP transfer directory, defined for the remote setup and update of the sites. Contact the server administrator if you do not know the parameters of your FTP account.

These archive files can be retrieved:

- by a WINDEV or WEBDEV application that uses the FTP functions.

- by an FTP client program.




Then, these archive files can be read and decompressed via the functions for archive management of WINDEV (or WEBDEV).

**Attention** Backing up causes all users to disconnect.
