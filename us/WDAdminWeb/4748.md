## ERR_UPDATING_SERVER error
<a name="errupdatingserver_error_ELTTEXTE000062"></a>
This error message signals to the Web users that they cannot connect to their site because an update is currently performed on the server.

To display this message on the computer of the Web users during an update and to avoid any new connection to a dynamic site of the server, you must:

- check the option "Lock the server (for an update)" in the local management tool

- or disable the site in the remote administration tool.
