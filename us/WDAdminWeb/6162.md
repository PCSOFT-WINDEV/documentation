## ERR_DISCONNECTED_EXEC error
<a name="errdisconnectedexec_error_ELTTEXTE000064"></a>
This message is displayed when the user tries to use a dynamic WEBDEV website that has already ended. For example, when users click the back button of the browser to return to a page of the site, but they have already left the site with the [Exit] button.

By default, the Web user is automatically reconnected to the site after 3 seconds.
