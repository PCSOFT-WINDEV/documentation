## ERR_TIMEOUTINIT error
<a name="errtimeoutinit_error_ELTTEXTE000068"></a>
The engine was not initialized within the timeout (&lt;TIMEOUT&gt; seconds). - ERR_TIMEOUTINIT (43)



This error, that occurs when starting the WEBDEV engine, can have several reasons:

- using a response time that is not long enough between two requests.
	Solution: Modify timeout for inactive users (option available in local or remote administration tool)

- the server is saturated
	Solution: Use a larger server or parallel server stations.
