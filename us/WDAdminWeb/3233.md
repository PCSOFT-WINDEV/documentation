## ERR_SESSION_CLOSED error
<a name="errsessionclosed_error_ELTTEXTE000065"></a>
You have been logged out. ERR_SESSION_CLOSED (23)

The Web user was disconnected by the WEBDEV administrator.

Reminder: From the local WEBDEV administration tool, you can disconnect:

- a Web user connected to a dynamic WEBDEV website.

- all Internet users connected to dynamic WEBDEV sites installed on the Web server.
