
## Remote WEBDEV administrator: Creating a WEBDEV account
			



## Managing WEBDEV accounts
<a name="managing_webdev_accounts_ELTTEXTE000125"></a>
The management of accounts is accessible in the remote administrator for the server administrator only.

The management of accounts is used to manage the WEBDEV accounts from the remote administration tool.

**Reminder:** A WEBDEV account is an account associated with a site administrator. This account is created on a Web server by the server administrator.

This account allows the server administrator to:

- group the different sites that belong to a site manager. These sites are installed on the same server.

- configure the total number of connections allowed for all the sites of the site manager.

- configure the directory for file transfer (for the setups and updates of sites by FTP).




This account allows the site managers to:

- use the remote administrator to manage the sites installed on the server.

- perform remote setups and updates (by FTP).






## Managing accounts
<a name="managing_accounts_ELTTEXTE000149"></a>
To list the WEBDEV accounts:

1. Select "Accounts" in the menu bar.

2. The list of existing accounts is displayed in the "Managing the accounts" section.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Admin_WebDev_distant%20-%20HC%20N%B0012.gif&type=thumb)





The characteristics of the accounts can be modified. For more details, see [ Modifying the characteristics of an account](../WDAdminWeb/203.md).





## Creating a WEBDEV account
<a name="creating_webdev_account_ELTTEXTE000173"></a>
To create a new WEBDEV account:

1. Select "Accounts" in the menu bar.

2. In the "Creating an account" area, type the login and password of the account to create, then click the "Create" button.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Admin_WebDev_distant%20-%20HC%20N%B0012%201.gif)


3. Enter the account characteristics:

	- personal information of the site manager, 

	- maximum number of connections granted to the sites manager for all his dynamic WEBDEV websites.

	- home directories, 

	- dynamic sites associated with the account (if necessary).





For more details, see [Modifying the characteristics of an account](../WDAdminWeb/203.md).





## Deleting a WEBDEV account
<a name="deleting_webdev_account_ELTTEXTE000197"></a>
To delete a WEBDEV account from the remote administrator:

1. Select "Accounts" in the menu bar of the remote administrator.

2. In the "Managing the accounts" section, select the WEBDEV account to delete.

3. Click "Delete".








## Importing WEBDEV accounts from an earlier version
<a name="importing_webdev_accounts_from_earlier_version_ELTTEXTE000221"></a>
To import WEBDEV accounts from an earlier version of the Application Server:

1. Select "Accounts" in the menu bar of the remote administrator. 

2. In the "Importing accounts" area, click the "Import" button.

3. Specify the paths of data files found in the earlier WEBDEV versions.

4. Click the "Find" button to refresh the list of accounts.

5. Check "Import this account" for all the accounts to import. All their characteristics can be modified.

6. Click the "Import" button to start the import.






## Statistics accounts
<a name="statistics_accounts_ELTTEXTE000274"></a>


### Overview
<a name="overview_ELTPARAGRAPHE000248"></a>

The statistical accounts are used to access the statistical module of the remote WEBDEV administrator. All you have to do is start the remote administrator and specify the login and password of the statistical account. For more details on statistics, see [Remote WEBDEV administrator: Statistics](../WDAdminWeb/6466.md).  


### Creating a statistical account
<a name="creating_statistical_account_ELTPARAGRAPHE000256"></a>

To create a statistical account:

1. Click the "&lt;Login&gt;" link found in the menu bar. In the popup that is displayed, click "See my profile".

2. In the "Editing the statistical accounts" section, click the "New" button.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Admin_WebDev_distant%20-%20HC%20N%B0014%202.gif&type=thumb)


3. Enter the requested information: login, password, ...

4. Click the "Apply" button to validate. 

5. Indicate the sites and the web services for which the statistics can be viewed. 

6. The account for viewing statistics is created and it can be used. 




**Remarks**: 

- The "Edit" button is used to modify the information about a statistical account. 

- The "Delete" button is used to delete a statistical account.
