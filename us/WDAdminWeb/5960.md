## ERR_DISCONNECTED_UPDATE error
<a name="errdisconnectedupdate_error_ELTTEXTE000061"></a>
This message is displayed when the Web user was disconnected for an update.

Reminder: when updating a dynamic WEBDEV site remotely, users connected to the site are automatically disconnected.

By default, the Web user is automatically reconnected to the site after 3 seconds.
