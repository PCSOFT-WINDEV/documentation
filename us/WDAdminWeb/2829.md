## ERR_CANNOT_OPEN_FILE error
<a name="errcannotopenfile_error_ELTTEXTE000061"></a>
The &lt;FILE_NAME&gt; HTML file cannot be opened. ERR_CANNOT_OPEN_FILE

The HTML file corresponding to the WEBDEV page or requested by **PageDisplay** is not accessible and it cannot be opened.
