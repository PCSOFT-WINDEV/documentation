
## Remote WEBDEV administrator: Configuration for using statistics
			



## Overview
<a name="overview_ELTTEXTE000099"></a>
The remote WEBDEV administrator proposes a module for managing the statistics. This module is used to: 

- import the statistics of a site.

- view the statistics about one or more sites.




A specific account dedicated to the management of statistics is required to access this statistical module. This account can be created via the remote administrator. 





## How to?
<a name="how_ELTTEXTE000123"></a>


### Creating an account for viewing the statistics
<a name="creating_account_for_viewing_the_statistics_ELTPARAGRAPHE000017"></a>

To create an account for viewing the statistics: 

1. Launch the remote WEBDEV administrator by entering the following address: 
	
	```txt
	http://<server>/WDAdminWeb
	```
where &lt;server&gt; represents the WEBDEV Application Server address (name or IP address).

2. To use the remote WEBDEV administrator website, you need to log in. There is no need to be administrator to create an account for viewing the statistics. 
	Reminder: 

	- By default, the "**admin**" username (with the **admin** password) can be used once the WEBDEV Application Server is installed.

	- The password of the "admin" account must be changed as soon as possible in order to prevent any access by an unauthorized person. Indeed, the "admin" account has all the rights for SaaS configuration on the Application Server.




3. In the remote administrator site, click the "Accounts" option. 

4. At the bottom of the account management page, you can create or edit statistics accounts. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Admin_WebDev_distant%20-%20HC%20N%B0012%203.gif)


5. To create a statistical account: 

	- Click the "New" button.

	- Enter the requested information: login, password, ...

	- Click the "Apply" button to validate. 




6. Indicate the sites and the web services for which the statistics can be viewed. 

7. The account for viewing statistics is created and it can be used.





### Viewing the statistics of a site
<a name="viewing_the_statistics_site_ELTPARAGRAPHE000043"></a>

To view the statistics of a site: 

1. Launch the remote WEBDEV administrator by entering the following address: 
	
	```txt
	http://<server>/WDAdminWeb
	```
where &lt;server&gt; represents the WEBDEV Application Server address (name or IP address).

2. To view the statistics, you must authenticate yourself with the username and the password corresponding to the account for viewing statistics. 

3. The site for viewing the statistics appears.
