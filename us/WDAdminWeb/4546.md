## ERR_SYNCHRONIZATION error
<a name="errsynchronization_error_ELTTEXTE000063"></a>
The page context found on the server and the page displayed in the browser on the computer of the Web user are out of sync: the data displayed and the data found on the server do not correspond.

This message is displayed when the Web user clicked the browser "Back" button.



We recommend that you thoroughly run the test of a dynamic WEBDEV website before deploying it, especially the use of browser "Back" button. WEBDEV proposes an automatic method for managing the browser "Back" button. For more details, see the online help of WEBDEV Development.
