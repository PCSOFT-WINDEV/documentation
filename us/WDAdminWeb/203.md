
## Remote WEBDEV administrator: Modify a WEBDEV account
			



## Editing a user account
<a name="editing_user_account_ELTTEXTE000076"></a>
To modify a WEBDEV account from the remote WEBDEV administrator:

1. Select "Accounts" in the menu bar.

2. Select an account and click the "Edit" button. The account description is displayed.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Admin_WebDev_distant_compte%20-%20HC%20N%B0001.gif)


3. The following information can be modified:

	- **personal information**: This information is used to identify the person responsible for the site and to provide contact details.

	- **"Account deactivated "**: This option temporarily deactivates a WEBDEV account: this account can no longer perform remote installations or updates, and cannot use the remote administration tool.. However, the WEBDEV websites of this site manager will still be active and available.

	- The **maximum number of connections allowed** for all the dynamic sites of the site manager. This number applies to all the WEBDEV websites associated with this account. The site manager can distribute them among his dynamic WEBDEV websites via the remote administration tool.

	- **The FTP directories and the directories of the WEBDEV applications**

		- **FTP transfer directory**: directory where file transfers required for remote installation and updating of a site will take place. This directory must be identical to the FTP transfer directory configured in the FTP server. 

		- **Basic site directory**: Directory where the files for this user's WEBDEV sites are or will be installed.. A subdirectory with the name of the site will be created for each site. 
						**Remark**: The site master directory is essential to enable the site manager to carry out remote site installations or updates.

		- **Basic directory for data files**: Directory where the data files (HFSQL database) used by the various sites of this site manager are or will be installed.. A subdirectory with the name of the site will be created for each site.
						**Remark**: The data file base directory is essential to enable the site manager to carry out remote site installations or updates.




- **Account password**: To change a WEBDEV account password, enter the server administrator's password, followed by the new account password and confirmation.. 
			 The "Change the password" button is used to take the modification into account.

- **WEBDEV sites** If the site manager has not yet installed dynamic sites on the server workstation, no site should be associated with it. When new dynamic WEBDEV websites are installed remotely (by FTP), these sites will be automatically assigned to the corresponding account. If the site manager has installed a WEBDEV site using physical media, his site appears in the list of unassigned sites: the "Add" button is used to associate the account with the site.
