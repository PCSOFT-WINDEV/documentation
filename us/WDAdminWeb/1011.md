### The management program of WEBDEV was not started. ERR_NO_WDADMIN (12)
<a name="the_management_program_webdev_was_not_started_errnowdadmin_12_ELTPARAGRAPHE000007"></a>

The access to a dynamic WEBDEV website can be performed only if the local WEBDEV management tool (WD310ADMIN.EXE) is started and run on the Internet server.
Check whether the local WEBDEV management tool is started on the server.

Note: The administration tool can be installed as a Windows service. All you have to do is run the following command line as administrator: 

```txt
WD220ADMIN.EXE /SERVICE /INSTALL
```
