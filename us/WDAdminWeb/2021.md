## ERR_NOTACTIVATED error
<a name="errnotactivated_error_ELTTEXTE000066"></a>
The module has not been enabled. It must be reinstalled - ERR_NOTACTIVATED (39)

WEBDEV was not installed properly. Reinstall WEBDEV.

**Reminder: There are two versions of WEBDEV:**

- WEBDEV development version, the can only be used when developing a WEBDEV application

- WEBDEV deployment version. This version must be installed on the server when deploying a dynamic WEBDEV website.
