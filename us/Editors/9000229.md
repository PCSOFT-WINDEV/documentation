


## MSIX installation packages
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000145"></a>
MSIX is a secure installation format for Windows applications. 

This format groups together all the required files in a "package". This prevents installation files from being scattered across Windows directories. It also makes it easier to uninstall the application. The user cannot choose the application installation directory. All application files are installed in a subdirectory of "Program files\\WindowsApps".
The various files required by the application (DLLs, etc) are virtualized. 
These installation packages must be signed. 

Installation packages are lightweight and allow the installer to be used in the context of group policies.

In WINDEV, you can create MSIX installation packages. You customize this installation package by editing its manifest. 

**Note**: MSIX installation programs can only be used as part of a stand-alone installation. Currently, installations with a "Live update" feature or automatic data file modification are not supported.

## How to?
<a name="how_ELTTEXTE000178"></a>


### Creating an MSIX installation package using the wizard
<a name="creating_msix_installation_package_using_the_wizard_ELTPARAGRAPHE000036"></a>

To create an MSIX installation package:

1. Create the application executable. To do so, go to the "Project" tab, "Generation" group, and select "Generate".

2. Create the setup procedure. Go to the "Project" tab, "Generation" group, and click "Setup procedure".

3. In the setup wizard, click "2 - Setup" on the left of the wizard. In the dialog box that appears, select "Access setup options".

4. Select "Stand-alone setup", then "Setup via MSIX package".<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Installation_MSIX%20-%20HC%20N%B0001.gif)


5. In the next step of the wizard:

	- Select the files you want to install.

	- No add-on modules can be specified. 

	- Specify the package details:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Installation_MSIX%20-%20HC%20N%B0002.gif)


		- Application name, Package title and Version: The information specified in the executable is used by default. 

- Publisher: By default, this information is specified in the certificate. 

- Description (required): Application description. 

- Application image (required): The image must be square, in JPEG or PNG format. This image will be used in the setup wizard (top right), in the taskbar and in the Windows Start menu.  

- Identifier: Identifies the application package. To get a new identifier, click "Generate". 
						You can modify this identifier to allow a given user to install different versions. 

- MSIX manifest file: Manifest file generated automatically using the specified information. You can provide a custom manifest file:

	- This manifest file should be named AppxManifest.xml. 

	- If you provide this file, all the information specified in this step will be ignored. 

	- If the information in the manifest does not comply with the MSIX API, package generation will fail. For more details on the information contained in the manifest file and its format, see [https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-manual-conversion#create-a-package-manifest](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-manual-conversion#create-a-package-manifest)

	- Likewise, the certificate used for signing must be the one specified in the AppxManifest.xml file

- Specify the package generation options:

	- File to generate (msix extension). 

	- Certificate to be used for signing. 

6. Finish the wizard. The MSIX installation package is automatically created. 




The MSIX installation package is ready to use. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Installation_MSIX%20-%20HC%20N%B0003.gif)
