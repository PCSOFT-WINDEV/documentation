


## The "Context-sensitive code view" pane
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000083"></a>
The "Context-sensitive code view" pane allows you to view and edit the code of the element (window, page, report, control, etc) selected in the editor.

The characteristics of the code displayed in the pane correspond to the characteristics of the code editor.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Volet_code%20-%20HC%20N%B0001.gif)
The context menu contains the same options as the Code Editor context menu.

## Displaying the "Context-sensitive code view" pane
<a name="displaying_the_contextsensitive_code_view_pane_ELTTEXTE000107"></a>
**To display the "Context-sensitive code view"** pane, go to the "Home" tab, "Environment" group, expand "Panes", select "Panes", and then select "Context-sensitive code view".
