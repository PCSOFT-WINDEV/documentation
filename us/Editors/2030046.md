


## Project description: Project tab

## Overview
<a name="overview_ELTTEXTE000300"></a>
The project description window allows you to configure various elements of your project. This window includes the following tabs:

- The **"Project"** tab, which allows you to enter general information about the project.

- The "Analysis" tab, which allows you to associate one or more analyses with the project and/or a UML model.

- The ["Data files"](../Editeurs/2030052.md) tab, which allows you to enter information about the data files used by the application. This tab is only available if the project uses an analysis.

- The "Live Data" tab, which allows you to configure how the data from the data files is displayed in the different editors.

- The ["Languages"](../Editeurs/9500219.md) tab, which is used to configure the different languages used by the project as well as the options to be used for each language.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) The ["Style"](../Editeurs/9500234.md) tab, which allows you to customize the print preview and to choose the skin template and custom style sheet. You can also configure screen sizes.

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The ["Skin"](../Editeurs/1410087360.md) tab, which allows you to choose the project skin, the associated palette, style sheet and external resources. 

- The ["SCM"](../Editeurs/9500239.md) tab, which is used to manage teamwork (SCM or Git).

- The ["Options"](../Editeurs/9500227.md) tab, which allows you to define the creation, update and save options of the different elements of the project. This tab also allows you to synchronize templates, enable strict mode and define the code style.

- The ["Advanced"](../Editeurs/9500236.md) tab, which allows you to enable "Reports and Queries", configure the AAFs and lock the application.

- The ["Compilation"](../Editeurs/9500218.md) tab, which allows you to configure the compilation options.

- The ["Telemetry"](../Editeurs/9500223.md) tab, which allows you to configure the telemetry options for the project. 
	![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) This option is not available.

## Project tab
<a name="project_tab_ELTTEXTE000324"></a>


### Project details
<a name="project_details_ELTPARAGRAPHE000090"></a>

Project details include:

- **Project name and directory**. This information cannot be modified. To change the project directory, we advise you to copy the project via the Windows explorer.

- **Project description**: Here, you can enter a brief description of the project. This description will be used in the project documentation.

- **Task list directory**. For more details, see [Task list](../Editeurs/2021004.md).

- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) **Site icon**. Used to define the [site icon (favicon)](../Editeurs/2030061.md).

### Analytics tools
<a name="analytics_tools_ELTPARAGRAPHE000178"></a>

WEBDEV supports different analytics tools for your projects. You can use: 

- Google Analytics 4 or Universal Analytics

- Matomo, etc.




**To link Google Analytics to your site**, you need to:

1. Create a Google Analytics account. This account must be linked to your site.

2. Retrieve the Google Analytics tracking ID associated with your account.

3. Specify the following in the WEBDEV project description window:

	- tracking ID.

	- the desired mode: Google Analytics 4 or Universal Analytics. 
			
	<B><B><B><B>Warning</B></B></B></B>

	 On July 1, 2023, Google Analytics is moving from Universal Analytics to Google Analytics 4. WEBDEV 2026 supports both versions. The WLanguage functions have been adapted. For existing projects, Universal Analytics is used by default. For new projects, Google Analytics 4 is used by default.






4. Deploy the WEBDEV project.


For more details, see [WEBDEV and Google Analytics](../WDLang2/1000022374.md). 

**To use the Matomo**, you need to:

1. Set up a Matomo account ([https://matomo.org/](https://matomo.org/)) with your email address and website address. 

2. Choose the desired tracking method. In this case, select "INSTALL WITH JAVASCRIPT CODE". 

3. Copy the suggested JavaScript code. 

4. Copy the JavaScript code in "Custom HTML header (Matomo, etc.)". For example: 
	
	```txt
	<!-- Matomo -->
	<script>
	  var _paq = window._paq = window._paq || [];
	  /* tracker methods like "setCustomDimension" should be called before "trackPageView" */
	  _paq.push(['trackPageView']);
	  _paq.push(['enableLinkTracking']);
	  (function() {
	    var u="https://xxxx.matomo.cloud/";
	    _paq.push(['setTrackerUrl', u+'matomo.php']);
	    _paq.push(['setSiteId', '1']);
	    var d=document, g=d.createElement('script'), s=d.getElementsByTagName('script')[0];
	    g.async=true; g.src='https://cdn.matomo.cloud/xxx.matomo.cloud/matomo.js'; s.parentNode.insertBefore(g,s);
	  })();
	</script>
	<!-- End Matomo Code -->
	```

### Google Maps API license
<a name="google_maps_api_license_ELTPARAGRAPHE000229"></a>

You must specify a license key to use Google's mapping service.
A Google Developer account is required to get a Google Maps API key. Refer to the Google license to learn more about the terms of service (free or paid service, usage quota, etc.).
You can generate a Google Maps key from a Google developer account. This key can be specified in the project description or with [MapLicenseGgl](../WDLang3/1000021299.md).

For more details, see [Map control](../WDChamp/1000019755.md).
