


## Deploying an action plan
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000115"></a>
Once created, the action plans must be deployed in order to be run.  

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000139"></a>


### Deploy an action plan from WINDEV, WEBDEV or WINDEV Mobile
<a name="deploy_action_plan_from_windev_webdev_windev_mobile_ELTPARAGRAPHE000018"></a>

To deploy an action plan: 

1. Open the project containing the action plan to deploy. 

2. Click the action plan generation icon in the quick access buttons: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_generation_Plan.gif)


3. Save the action plan if necessary. 

4. The wizard for generating and deploying the action plans starts.  

5. In the wizard, enter the general details of the library containing the action plans:

	- name of the action plan library. By default, this name corresponds to the project name. 

	- organization.

	- description.

	- version. This version can be automatically incremented at each generation. 

	- the copyright.




6. Select the public action plans, accessible in the Software Factory administrator. 

7. Specify the desired deployment option. The action plan library can be deployed immediately or at a later date:

	- To deploy the library immediately, specify the name of the computer corresponding to the Software Factory coordinator. 

	- To deploy the library at a later date, go to the Software Factory administrator. 




8. Finish the wizard. 

9. You have the ability to perform a backup of the current project. 

10. If you have chosen to deploy immediately, the coordinator is displayed and it indicates the result of the deployment. 





### Deploying an action plan from the Software Factory administrator
<a name="deploying_action_plan_from_the_software_factory_administrator_ELTPARAGRAPHE000044"></a>

To deploy an action plan from the Software Factory administrator: 

1. Generate the action plan library on the development computer, and choose the deployment at a later date. 

2. Launch the Software Factory administrator. Go to the "Tools" tab, "Utilities" group, and click "WDFAdmin".

3. In the window that appears, specify the name of the coordinator to which the administrator must connect. 

4. The Software Factory administrator starts. 

5. In the "Warehouse" tab:

	- Click "Add a library". 

	- Select the "wdfab" file corresponding to the library of the action plan to deploy. This file was generated in the Exe directory of the project linked to the action plan. 




6. The library containing the action plan is deployed. It appears in the warehouse.
