
## Inserting a diagram in a help page
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000092"></a>
You can insert a diagram created with the Diagram Editor into a help page. This makes it possible to easily explain a concept or a structure using a diagram. 



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Insert a diagram
<a name="insert_diagram_ELTTEXTE000116"></a>
To insert a diagram into a help page:

1. In the help page, position the cursor where you want to insert the diagram.

2. On the "Modification" tab, in the "Edit" group, select "Diagram". 

3. In the file explorer, select the desired diagram (wddiag file) and confirm. 

4. If necessary, confirm you want to copy the diagram to the project directory. 

5. The diagram description window appears: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Ins%E9rer_un_diagramme%20-%20HC%20N%B0001.gif)


6. If necessary, set the size of the diagram in the help page. 

7. Confirm. The diagram is integrated into the help page. You can resize it using the sizing handles.




**Remarks**: 

- You can also select "Insert a diagram" in the context menu of the help page. 

- Once the diagram is inserted in the help page, you can: 

	- view its characteristics. 

	- edit it in the Diagram Editor.
