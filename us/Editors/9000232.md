## Overview
<a name="overview_ELTTEXTE000193"></a>
WINDEV has established its own vocabulary.
In version 2025, you can choose the desired vocabulary.
One common case is WINDEV's "file" or "data file", which is often replaced with "table". 

You can now replace certain legacy terms.
For example:


|   |   |
| --- | --- |
| **Legacy vocabulary** | **Generic vocabulary** |
| Data file | Table |
| Analysis | Database schema |
| Skin template | Theme |


<a name="NOTE1_2"></a>
A series of elements in the development environment adapt to the chosen vocabulary:

- input suggestions,

- 7-tab windows,

- help, etc. 




You can use the vocabulary of your choice in WLanguage. Some WLanguage functions and properties have been renamed to use the terms of the chosen vocabulary. For example: 




|   |   |
| --- | --- |
| [ScreenToFile](../WDLang4/3044146.md) | WindowToTable |
| [FileToScreen](../WDLang4/3044210.md) | TableToWindow |
| [BuildBrowsingTable](../WDLang1/3074002.md) | TableBuildDataBinding |
| [HOpenAnalysis](../WDLang4/3044106.md) | HOpenDatabaseSchema |
| [HListFile](../WDLang4/3044045.md) | HListTable |
| [ChangeSkinTemplate](../WDLang1/3013026.md) | ChangeTheme |

## Implementing vocabulary selection options
<a name="implementing_vocabulary_selection_options_ELTTEXTE000223"></a>


### Choice of vocabulary
<a name="choice_vocabulary_ELTPARAGRAPHE000084"></a>

You can choose the desired vocabulary in the WINDEV, WEBDEV and WINDEV Mobile options:

1. In the ribbon, under the "Home" pane, in the "Environment" group, expand "xxx general options". 

2. In the "General" tab, select the desired vocabulary:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Options_G%E9n%E9rales_wd%20-%20HC%20N%B0002%201.gif)


3. Confirm




Next time the IDE is launched, the interface will use the chosen vocabulary. 


### Programming standard
<a name="programming_standard_ELTPARAGRAPHE000096"></a>

You can implement a programming standard to check the use of the chosen vocabulary. In this case, all lines of code that do not correspond to the current vocabulary in the editor will be highlighted. 

Some WLanguage functions have different names depending on the vocabulary used. 

To enable programming standard errors from the project description:

1. Open the project description window (go to the "Project" tab, "Project" group and click "Description"). 

2. On the "Compilation" tab, in "Programming standard", check "Report mixed vocabulary". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Descriptions_projet_options%20-%20HC%20N%B0010%204.gif)


3. Confirm. The project will then be recompiled. 

4. "Vocabulary mix" errors, if any, will appear in the compilation errors pane. Double-click on the error to see the line of code causing the problem. 








### Converting code
<a name="converting_code_ELTPARAGRAPHE000129"></a>

You can automatically convert WLanguage code to the chosen vocabulary. 

To change the vocabulary used in the code:

1. Open the desired code in the code editor. 

2. On the "Code" tab, in the "Languages" group, select the desired language:

	- If you are currently using "legacy" vocabulary, the code will use legacy vocabulary when translated into French or English. 

	- If you are currently using "generic" vocabulary, the code will use generic vocabulary when translated into French or English. 

	- The "Convert entire project to xxx" option automatically converts all the WLanguage code of the project and its elements to a given vocabulary.
