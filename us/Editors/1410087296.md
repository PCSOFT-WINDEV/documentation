


## Project with multiple analyses
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000224"></a>
A single WINDEV, WEBDEV or WINDEV Mobile project can now use multiple analyses (data descriptions). 
WINDEV 2024 makes it possible to use two or more different analyses in the same project. 
You can use multiple analyses permanently, or as a one-off alternative in order to run specific queries. 
All the data files from all the analyses support databinding.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000248"></a>


### Defining a project with multiple analyses in the editor
<a name="defining_project_with_multiple_analyses_the_editor_ELTPARAGRAPHE000024"></a>

To use multiple analyses in a single project: 

1. Open your project in WINDEV, WEBDEV or WINDEV Mobile. 

2. Open the project description window. To do so, go to the "Project" tab, "Project" group, and click "Description". 

3. On the "Analysis" tab, indicate the different analyses used by the current project via the "Create an analysis", "Add an analysis", or "Import an analysis from the SCM" buttons. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Description_Projet_Onglet_Analyse%20-%20HC%20N%B0001.gif)


4. Use the arrow buttons to define the order in which analyses are used. This is an important step, especially if the analyses contain data files with the same name (see below). 

5. Confirm. 





### Defining a project with multiple analyses programmatically
<a name="defining_project_with_multiple_analyses_programmatically_ELTPARAGRAPHE000048"></a>

The [HOpenAnalysis](../WDLang4/3044106.md) function opens an analysis in HFSQL Classic format. This allows you to access the data files defined in the analysis as well as their structure.

To open an additional analysis programmatically, use [HOpenComplementaryAnalysis](../WDLang4/1410090082.md).

## Remarks
<a name="remarks_ELTTEXTE000278"></a>


### Automatically hide data files with the same name in different analyses
<a name="automatically_hide_data_files_with_the_same_name_different_analyses_ELTPARAGRAPHE000071"></a>

Different analyses can contain data files with the same name. In this case, only one data file will be used. This data file relies on the order specified for the different analyses, either in the project description or through the opening sequence defined using [HOpenAnalysis](../WDLang4/3044106.md) and [HOpenComplementaryAnalysis](../WDLang4/1410090082.md). Here is how it works: 

- Analysis 1: 

	- Data file A 

	- Data file B




- Analysis 2: 

	- Data file B. This data file will be "hidden", as it is present in Analysis 1. 
			**To use data file B in analysis 2**, it is necessary to rename this data file in analysis 2. 

	- Data file C




- Analysis 3: 

	- Data file B: This data file will be "hidden", as it is present in Analysis 1. 
			**To use data file B in analysis 3**, it is necessary to rename this data file in analysis 3.

	- Data file C: This data file will be "hidden", as it is present in Analysis 2. 
			**To use data file C in analysis 3**, it is necessary to rename this data file in analysis 3.

	- Data file D. 





In the "Analysis" action of the "Project Explorer" pane, the following data files will be shown: 

- Data file A (analysis 1)

- Data file B (analysis 1)

- Data file C (analysis 2)

- Data file D (analysis 3).





### Multi-server queries
<a name="multiserver_queries_ELTPARAGRAPHE000109"></a>

If you use multiple analyses containing data files that use connections to different servers, it is recommended to define the connections in the data model editor (and not programmatically). This allows you to make sure you are associating the right connection with the data file (especially when there are data files with the same name). 


### WLanguage functions: Adaptations made to manage projects with multiple analyses
<a name="wlanguage_functions_adaptations_made_manage_projects_with_multiple_analyses_ELTPARAGRAPHE000114"></a>

The following functions manipulate analyses, data files, relationships, etc. They have been improved to manage projects with multiple analyses. 


|   |   |
| --- | --- |
| [HChangeConnection](../WDLang4/3044150.md) | If the data file name is not specified, changes the connection for the data files defined in the different analyses. |
| [HChangeDir](../WDLang4/3044168.md) | If the data file name is not specified, changes the directory for the data files defined in the different analyses. |
| [HCloseAnalysis](../WDLang4/3044054.md) | Closes all the analyses associated with the project. |
| [HCreationIfNotFound](../WDLang4/3044254.md) | If the data file name is not specified, all data files for all analyses will be created or opened. |
| [HInfoAnalysis](../WDLang4/1000019773.md) | If the analysis is not specified, only the main analysis is used. |
| [HListConnection](../WDLang4/3044046.md) | If there are multiple analyses, lists all the connections of all the analyses. |
| [HListCustomFolder](../WDLang4/1000019775.md) | If there are multiple analyses, lists all the Custom-Folders of all the analyses. |
| [HListFile](../WDLang4/3044045.md) | If there are multiple analyses, lists all the data files of all the analyses. |
| [HListLink](../WDLang4/3044138.md) | If there are multiple analyses, lists all the links of all the analyses. |
| [HListREP](../WDLang4/3044229.md) | If there are multiple analyses, only the main analysis is used. |
| [HSetREP](../WDLang4/3044061.md) | If you only specify the parameter that enables or disables the .rep file, the change is made in all the analyses associated with the project. |
| [ProjectInfo](../WDLang1/3064004.md) | If there are multiple analyses, the *piAnalysis* constant gets only the name of the main analysis. |
