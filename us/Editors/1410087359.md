
## Using new features exclusive to a subscription-based version in a project
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000153"></a>
WINDEV Suite 2025 Update 1 introduces various subscription-exclusive new features. These new features can only be used if your project is opened in a subscription-based IDE, and if the project is in Subscription mode. 

**Important: Projects in Subscription mode can no longer be used in a dongle-based version.**

<a name="NOTE2_1"></a>


## Using new features exclusive to a subscription-based version in a project
<a name="using_new_features_exclusive_subscriptionbased_version_project_ELTTEXTE000177"></a>


### Using new features exclusive to the subscription-based version of WINDEV Suite
<a name="using_new_features_exclusive_the_subscriptionbased_version_windev_suite_ELTPARAGRAPHE000018"></a>

There are two ways to enable these new features in your projects:

- From the dashboard: 
	Go to the project widget and click the "Subscription" switch. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Projet_SaaS%20-%20HC%20N%B0001.gif)


- From the project description window: Go to the "Options" tab and check "Enable WINDEV Suite's subscription-exclusive features in the project". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Projet_SaaS%20-%20HC%20N%B0002.gif)





Caution: Once this option is enabled, the project switches to "Subscription mode". This means that its elements can no longer be opened with a dongle-based version of WINDEV. The project will no longer be compatible. 

Until the Subscription mode is enabled, the project and its elements will use a format that is compatible with the dongle-based version. 

**Special case: Working for several clients who use either a dongle-based version or a subscription-based version. Which version should you use?**
Simply use the subscription-based version to work on all your projects. This version opens all types of projects. The "Subscription mode" will determine whether subscription-exclusive new features can be integrated into the project. Therefore: 

- Subscription mode will be disabled in projects for clients using version 2025 with a dongle-based license.

- Subscription mode will be enabled in projects for clients with a WINDEV Suite 2025 subscription. These projects will benefit from subscription-exclusive new features.

## Default configuration and switching between modes
<a name="default_configuration_and_switching_between_modes_ELTTEXTE000201"></a>


### Opening an existing project with the subscription-based version of WINDEV Suite
<a name="opening_existing_project_with_the_subscriptionbased_version_windev_suite_ELTPARAGRAPHE000045"></a>

Starting with WINDEV Suite 2025 - Update 1 (subscription version), this project remains in compatible version by default. You will be able to work on it both with the subscription-based and dongle-based versions of WINDEV Suite, as long as the "Subscription" option is not enabled.  


### Creating a new project with the subscription-based version of WINDEV Suite
<a name="creating_new_project_with_the_subscriptionbased_version_windev_suite_ELTPARAGRAPHE000050"></a>

Starting with the subscription-based version of WINDEV Suite - Update 1, new projects are automatically created in Subscription mode. By default, these projects cannot be used in a dongle-based version. 


### Disabling Susbscription mode for a project
<a name="disabling_susbscription_mode_for_project_ELTPARAGRAPHE000055"></a>

To disable Subscription mode for a given project, simply disable the corresponding "Subscription" option. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Projet_SaaS%20-%20HC%20N%B0003.gif)


In this case, subscription-exclusive features will be removed from the project. The project will then be recompiled. If you have used features or WLanguage elements that are exclusive to a project in Subscription mode, the compilation errors pane will show notifications explaining that these features are not enabled in the project.
Once these errors are fixed (if any), the project can be used again in a dongle-based version.

## Special cases
<a name="special_cases_ELTTEXTE000237"></a>


### Project and project configurations
<a name="project_and_project_configurations_ELTPARAGRAPHE000070"></a>

Subscription mode applies to all project elements and configurations. The same project cannot have a project configuration with Subscription mode enabled, and another configuration without Subscription mode.


### Sharing an analysis
<a name="sharing_analysis_ELTPARAGRAPHE000075"></a>

An analysis can be shared between a project in "Subscription mode" and a project where the "Subscription" option is not enabled.


### Internal component
<a name="internal_component_ELTPARAGRAPHE000080"></a>

Internal components cannot be shared between a project in "Subscription mode" and a project where the "Subscription" option is not enabled.


### External component
<a name="external_component_ELTPARAGRAPHE000085"></a>

An external component from a project in "Subscription mode" cannot be imported into a project where the "Subscription" option is not enabled. Likewise, an executable created with a project where the "Subscription" option is disabled cannot use a component generated by a project in "Subscription mode". 


### HFSQL Client/Server server
<a name="hfsql_clientserver_server_ELTPARAGRAPHE000090"></a>

You can use HFSQL Client/Server with applications generated from projects in "Subscription mode" and projects where the "Subscription" option is not enabled. 


### Source Code Manager (SCM)
<a name="source_code_manager_scm_ELTPARAGRAPHE000095"></a>

For projects synchronized with the SCM, the "VI" column in the SCM administrator will be preceded by an "S" to differentiate elements saved using Subscription mode. For example: "S1A302028". 




### Application patch
<a name="application_patch_ELTPARAGRAPHE000102"></a>

An executable compiled from a project that is not in "Subscription mode" cannot load an application patch file created with a project in "Subscription mode". 
If you use patches in a project to deploy updates after activating "Subscription mode", the next time you deploy, you need to use a new executable file, not just a patch.
