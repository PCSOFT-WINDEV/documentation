## Configuring the automatic data modification
<a name="configuring_the_automatic_data_modification_ELTTEXTE000116"></a><br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=D%E9ploiement%20-%20HC%20N%B0005.gif&type=thumb)
To perform the automatic modification of data files:

- in HFSQL Classic format, check the "Include automatic modification of data files in installation" option and check the analysis associated with the site.

- in HFSQL Client/Server format, check "Perform the modification of the HFSQL Client/Server data files". The "Connections" button is used to describe the parameters of the relevant HFSQL Client/Server connections.

- in Hyper File 5.5  format to HFSQL Classic, check "Perform the automatic modification of the Hyper File 5.5 data files and the conversion to HFSQL Classic".



<a name="NOTE2_2"></a>


### Managing the passwords for the HFSQL Classic data files
<a name="managing_the_passwords_for_the_hfsql_classic_data_files_ELTPARAGRAPHE000030"></a>

If your HFSQL Classic data files are password-protected, click on the "Set file passwords" link.

For each data file of analysis, specify if necessary:

- data file password (if any) in HFSQL Classic analysis format. 
	**Note**: To change this password, select "Change password" and enter the new password.

- if the site uses a migrated Hyper File 5.5 analysis:

	- the source analysis in Hyper File 5.5 format (".WDA" file).

	- the name of the data file in Hyper File 5.5 format.

	- the password of the data file (if any) in Hyper File 5.5 format.







**Note** All information except passwords is automatically displayed.
