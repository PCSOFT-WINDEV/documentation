
## Code editor: Snake_case or PascalCase
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000088"></a>
There are several naming conventions to write variables in the code.
Two commonly used conventions are:


- Pascal Case ("CustomerName"): The first letter of each word is capitalized.

- Snake case ("customer_name"): Lowercase letters only. Words are separated by underscores.




The code editor lets you switch from one naming convention to another. 

**Note**: One way of taking advantage of this feature is to use one syntax for local variables, and the other for global variables. This allows you to identify variables at a glance.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to change the naming convention?
<a name="how_change_the_naming_convention_ELTTEXTE000112"></a>
To change the naming convention used in a process/event:

1. In the code editor, open the context menu of the desired process/event. 

2. Select the desired option: 

	- "Refactoring .. PascalCase => snake_case".

	- "Refactoring .. snake_case => PascalCase".




3. Choose the scope of the action: 

	- Current code.

	- Current element.

	- The entire code displayed in the active code window.

	- All the WLanguage code of the project.




4. Confirm. 




The code editor will identify and modify all the names that use the specified convention.
