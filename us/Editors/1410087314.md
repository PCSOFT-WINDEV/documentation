
## Cloning a skin template or a skin
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000244"></a>
"Skin templates" and "skins" are UI templates that you can apply to a project. Skin templates apply to applications, while Skins apply to websites.

If necessary, you can dissociate the control from the skin template or skin, or override the style of the control.

In version 2024, you no longer need to override styles. A new method consists in cloning (or duplicating) an existing Skin template or Skin, renaming it, and then directly modifying the styles, natively, without having to override them. This makes it easier to define styles. Please note that once duplicated, the Skin template or Skin no longer benefits from any updates provided by PC SOFT.

**The principle is straightforward**: 

1. Clone [the skin template](#NOTE2_1) or [the skin](#NOTE2b_1). 

2. Edit [the styles of the cloned skin template or skin](#NOTE3_1).

## Cloning a skin template
<a name="cloning_skin_template_ELTTEXTE000268"></a>


### How to?
<a name="how_ELTPARAGRAPHE000034"></a>

To clone an skin template: 

1. Open the desired WINDEV or WINDEV Mobile project. 

2. On the "Project" tab, in "Other actions", expand "Project skin templates" and select "Clone project skin template". 

3. In the window that appears, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0001.gif)


	- The skin template to clone. You can choose a skin template other than the one currently used in the project. 

- The name of the new skin template. This name will identify the skin template used. 

- The different options: 

	- **Apply cloned skin template to all the windows that use the original skin template**: This option automatically associates the cloned skin template with the windows that use the skin template to be cloned. Keep in mind you can apply the cloned skin template at any time (for more details, see [Apply a skin template](../Editeurs/2016011.md)). 

	- **Rename images**: This option renames all the images of the cloned skin template. This makes it possible to modify the images of the new skin template without accidentally modifying those of the original skin template (for example, if both skin templates remain associated with the project). 

	- **Set as default skin template for the project**: This option allows you to change the skin template associated with the project (in the project description window). In this case, all new windows will use the cloned skin template. 

4. Confirm. 




The selected skin template is cloned in the current project. Depending on the selected options, the cloned skin template is applied to the windows that use the original skin template and/or becomes the project's default skin template. 

The cloned skin template is copied to the project directory ("Templates" subdirectory).




### Remarks
<a name="remarks_ELTPARAGRAPHE000073"></a>

- If the project contains multiple configurations (e.g. WINDEV and WINDEV Mobile), cloning WINDEV templates will apply to WINDEV configurations and cloning WINDEV Mobile skin templates will apply to WINDEV Mobile configurations. 

- If the same skin template is cloned with the same name in two different projects, the changes made in the cloned skin template in the first project are not carried over to the second project. 

- If the cloned skin template is copied to the WINDEV or WINDEV Mobile skin template directory, it will appear in the list of available skin templates. 

- If the project only uses the styles of the cloned skin template, the directory of the original skin template will be automatically deleted when the styles are updated. 

- Project in the SCM: 

	- When a skin template is cloned, all windows are checked out to apply that skin template.

	- To share a cloned skin template between multiple projects, simply share the skin template directory via the SCM.

## Cloning a skin
<a name="cloning_skin_ELTTEXTE000298"></a>


### How to?
<a name="how_ELTPARAGRAPHE000090"></a>

To clone an skin: 

1. Open the desired WEBDEV project. 

2. On the "Project" tab, in "Other actions", expand "More actions" and select "Clone project skin". 

3. In the window that appears, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_Ambiance%20-%20HC%20N%B0001.gif)


	- The skin to clone. You can choose a skin other than the one currently used in the project. 

- The name of the new skin. This name will identify the skin used. 

- If the skin should become the project's default skin. By selecting this option, you will change the skin associated with the project (in the project description window). In this case, all new pages will use the cloned skin. 

4. Confirm. 




The selected skin is cloned in the current project. Depending on the selected options, the cloned skin becomes the project's default skin. 

The cloned skin is copied to the project directory (as a subdirectory with the name of the new skin).




### Remarks
<a name="remarks_ELTPARAGRAPHE000110"></a>

- If the project contains multiple configurations (e.g. WINDEV and WEBDEV), cloning WEBDEV skins will only apply to WEBDEV configurations. 

- If the same skin is cloned with the same name in two different projects, the changes made in the cloned skin in the first project are not carried over to the second project. 

- If you copy the directory of the cloned skin to the WEBDEV skins directory, the cloned skin will appear in the list of available skins. 

- Project in the SCM: 

	- When a skin is cloned, all pages are checked out to apply that skin.

	- To share a cloned skin between multiple projects, simply share the skin directory via the SCM.

## Editing styles
<a name="editing_styles_ELTTEXTE000328"></a>


### How to?
<a name="how_ELTPARAGRAPHE000126"></a>

When your project uses a cloned skin template (or skin), you can edit the styles to suit your needs. Several methods are available. 

**Method 1: Modifying the style by propagating overrides** ("Style" tab):

1. Change the control style: 

	- Select the control for which you want to change the default style.

	- Go to the "Style" tab of the control description window. The style displayed is the style of the cloned skin template (or skin), with or without overrides. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0002.gif)


	- Make the desired changes, and apply them if you want to see the result. 

2. Edit the style of the cloned skin template (or skin):
	To propagate the changes (overrides) to the style of the cloned skin template or skin, you can: 

	- Click the "Propagate" link in the description window.  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0003.gif)


	- Expand the burger menu next to the style and select "Propagate overrides".  <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0004.gif)




In this case: 

- All the controls that use the style of the cloned skin template (or skin) are modified. 

- The control will appear to no longer contain any overrides. It will use a style "without overrides". 

- Other controls using the modified style will keep their own overrides, if any. 




**Method 2: Modifying a style via the "Choose a style" option**:

1. Select the control for which you want to change the default style.

2. Open the context menu and select: 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/us/WM.png) "Choose a style". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0005.gif)


	- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) "Choose a WEBDEV style".

3. Select the desired style for the control in the modified skin template (or skin). 

4. In the context menu of the style, select "Modify". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0006.gif)


5. Make the desired changes to the style in the window that appears. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Cloner_gabarit%20-%20HC%20N%B0007.gif)


6. Confirm changes. 




The style of the cloned skin template (or skin) is modified. These changes are automatically applied to all controls using the style from the cloned skin template (or skin) in the project. All controls keep their overrides (even the control from which the changes were made). 

**Method 3: Modifying the style of a skin template** (Control style):

1. Change the control style: 

	- Select the control for which you want to change the default style.

	- Go to the "Style" tab of the control description window. The style displayed is the style from the cloned skin template. 

	- Make the desired changes, and apply them if you want to see the result. 




2. Edit the style of the cloned skin template:
	To apply the changes made in the control to the style of the skin template, you can: 

	- Click the "Change style" link in the description window. 

	- Expand the burger menu next to the style and select "Change style". 





In this case: 

- All the controls that use the style of the cloned skin template are modified. 

- The control keeps its overrides. 

- Other controls using the modified style will keep their own overrides, if any.
