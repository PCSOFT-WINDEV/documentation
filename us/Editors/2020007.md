


## GDI+ framework
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000064"></a>
Some WINDEV features use the GDI+ framework.

This specific framework allows you to exploit all the system's graphics resources.

This framework consists of a specific library: gdiplus.dll.

This library comes as standard with most operating systems (above Windows 2000).
