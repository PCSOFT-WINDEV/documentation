
## Setting the language of an executable file
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000077"></a>
When creating the executable, you have the ability to choose the languages that will be included in the executable. This option enables you to generate a different executable for each language.

**Note**: If you are going to generate the executable file for a single language, don't forget to modify the menu options that allow changing the language.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Languages of the executable
<a name="languages_the_executable_ELTTEXTE000101"></a>
The current language in WINDEV is proposed by default.

You have the ability to select:

- One of the languages used by the project, 

- All project languages, 

- The current language in the editor.




**Note**: Selecting a limited number of languages reduces the size of the application's library (WDL). The project configurations can also be used to manage the languages. You have the ability to use a project configuration to generate a FR + US library from a project containing 5 languages for example.
