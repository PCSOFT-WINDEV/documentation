
## Code statistics 
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000089"></a>
The code statistics affect:

- the total number of lines in the relevant process, 

- the rate of comments, 

- the number of lines per process, 

- the number of lines of code with and without comments, 

- the number of comment lines.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000113"></a>


### View project statistics
<a name="view_project_statistics_ELTPARAGRAPHE000024"></a>

Code statistics for the project are displayed in the "Code" widget of the project dashboard. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Stat_code%20-%20HC%20N%B0001.gif)



### Display statistics for current object
<a name="display_statistics_for_current_object_ELTPARAGRAPHE000030"></a>

To display code statistics for the current element in the code editor: 

1. In the "Code" pane, in the "Other actions" group, click on "Statistics". 

2. In the window that appears, indicate:

	- the maximum percentage of comments to take into account.

	- the minimum number of lines of code to take into account.




3. Click the "Display" button to calculate the statistics.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Stat_code%20-%20HC%20N%B0002.gif)





Note: You can print out the results of the statistics calculation.
