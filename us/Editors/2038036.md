
## SCM: Retrieving the project locally
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000148"></a>
Once a project has been added to the Source Code Manager (SCM), developers must get a local copy in order to work on it. 

To do so, the project must be opened from the SCM. 

**This operation must be performed once only by each developer who uses the project. The developer who added the project to the Source Code Manager does not have to perform any operations.**

Important: Do not copy files locally using Windows Explorer.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Opening the project from SCM (1st project opening only)
<a name="opening_the_project_from_scm_1st_project_opening_only_ELTTEXTE000172"></a>
To retrieve a project from the SCM the first time you open it on the development computer:

1. Expand ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_ouvrir.gif) in the quick access buttons and select "Open a project from the SCM". 
	Note: You can also open a project hosted in the SCM from the home page.

2. In the wizard that opens, specify the characteristics of the repository you want to use:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0006.gif&type=thumb)


	- the type of repository to be used.

- the path of the repository (network computer or shared directory).

- the username and password (if necessary).

3. In the next step of the wizard:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0007.gif)


	- Select the directory of the repository that corresponds to the desired project.

- Specify the local directory into which the project will be copied.

4. Confirm. The project is copied locally and it is automatically opened according to the mode specified when it was checked into the repository.




**Note**: Projects hosted in the SCM only require these operations the first time. To open the project afterwards, simply open the project file (".WDP" file) corresponding to the local copy.
<a name="NOTE2_2"></a>


### Options for a project in the SCM
<a name="options_for_project_the_scm_ELTPARAGRAPHE000047"></a>

There are several options for configuring a project hosted in the Source Code Manager. These options can be found in the "SCM" tab of the project description. These options are checked by default.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0015.gif&type=thumb)
The available options are as follows: 

- **Suggest getting the latest version of the elements when the project is opened**:
	When opening a project located in the SCM, this option prompts you to get the latest version of the project elements. 
	This option is checked by default. This means the latest version of the elements is automatically retrieved.

- **Suggest checking the elements back in when the project is closed**:
	When the project is closed, this option displays a list of the checked out elements to check some or all of them back in.
	This option is unchecked by default. When the project is closed, checked-out elements are not checked in.

- **Check out/Check in the project automatically**:
	This option is checked by default and is used to automatically manage the project file. 
	If this option is checked: 

	- The project file is checked out only if the action performed requires it. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0008.gif)


	- Once changes are made to the project, a check-in prompt appears automatically.
			If the option "Check in the project automatically at the end of the operation" was checked during the check-out, the project file is automatically checked back in (without confirmation window).
