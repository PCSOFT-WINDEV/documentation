


## Creating, editing and deleting a style (help system)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000148"></a>
WINDEV, WEBDEV and WINDEV Mobile allow you to handle the styles defined for a help system.

To edit the styles available in the current help system, go to the "Modification" tab, "Styles" group and select "Edit styles". This option is available when the help system is displayed in the editor.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Edition_Styles.gif)
This window shows the different styles in the help system and the characteristics of each style.

## Adding a new style
<a name="adding_new_style_ELTTEXTE000172"></a>
To add a new style: 

1. Open the style description window. To do so, go to the "Modification" tab, "Styles" group, and select "Edit styles".

2. Click the "New" button.

3. Enter the name of the new style and its characteristics in the window for style properties.

4. Validate the window for style properties. The style is displayed in the style description window.

5. Validate the style description window.




<a name="NOTE3"></a>
<a name="NOTE3_1"></a>


## Modify a style
<a name="modify_style_ELTTEXTE000196"></a>
To modify a style: 

1. Open the style description window. To do so, go to the "Modification" tab, "Styles" group, and select "Edit styles".

2. Select the style to modify.

3. Click the "Modify" button.

4. Enter the characteristics of the style in the window for style properties.

5. Validate the window for style properties. The style is displayed in the style description window.

6. Validate the style description window.




<a name="NOTE4"></a>
<a name="NOTE4_1"></a>


## Deleting a style
<a name="deleting_style_ELTTEXTE000220"></a>
To delete a style: 

1. Open the style description window. To do so, go to the "Modification" tab, "Styles" group, and select "Edit styles".

2. Select the style to delete.

3. Click "Delete". The style is deleted. The paragraphs associated with this style are no longer associated with a style (the "Style" combo box is empty).
