
## Creating a model class
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000107"></a>
In MVP projects, you need to create a base class (MBase if you're using the RAD tool for MVP applications). This is the base class for all Model classes (M stands for "Model"). It contains the basic functionalities of the business code (which will be shared with the other model classes through inheritance).

You can: 

- create a custom class pattern. This pattern can then be used to generate a model class (based on a data file). 
	

- generate a model class using the class pattern suggested by WINDEV, or a custom pattern.

<a name="NOTE2_1"></a>


## Generating a model class and/or a pattern class
<a name="generating_model_class_andor_pattern_class_ELTTEXTE000131"></a>
To generate a pattern class: 

1. In the "Project explorer" pane, use one of the following methods: 

	- Open the context menu of the "Class" folder and select "Create a class mapped to a file description". Then, select the desired data file. 

	- Right-click one of the data files in the analysis and select "Generate a model class".




2. In the window that appears, choose the desired pattern class: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Classe_modele%20-%20HC%20N%B0003.gif)


	- **WINDEV's built-in pattern class**. In this case, the class mapped to the data file will be automatically generated. 
			Example of declaration code generated automatically for the MOrderLine class: 
			
		```wl
		MOrderLine is Class <MAPPING=OrderLine>
		
			// The code between <MAPPING> and <END> is automatically generated.
			// It will be deleted and recreated each time the class is generated
			<MAPPING>
			m_OrderID is int <MAPPING=OrderID>
			m_Reference is string <MAPPING=Reference>
			m_Quantity is 4-byte int <MAPPING=Quantity>
			m_TotalExclTax is Currency <MAPPING=TotalExclTax>
			m_TotalInclTax is Currency <MAPPING=TotalInclTax>
			<END>
		END
		```


- Use **a pattern class from the project** (default option if a pattern class has already been generated from the same data file). 

- Use a pattern class on disk. 

- Generate a pattern class. You can also click "Create custom pattern class" to create the pattern class used to generate the various model classes in your project. A "CMdl" class is automatically created. The following code is generated: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Classe_modele%20-%20HC%20N%B0004.gif)
You will be able to use this file when generating model classes. 
			You can customize the generated code by writing the desired code before and after the &lt;MAPPING&gt; and &lt;END&gt; tags. The code between these two tags will be automatically generated along with the model classes. 




To generate the model class using the custom pattern class: 

1. In the "Project explorer" pane, use one of the following methods: 

	- Open the context menu of the "Class" folder and select "Create a class mapped to a file description". Then, select the desired data file. 

	- Right-click one of the data files in the analysis and select "Generate a model class".




2. In the window that appears, choose the desired pattern class: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Classe_modele%20-%20HC%20N%B0005.gif)


	- built-in pattern class

- existing pattern class (if you have generated the custom pattern class in the project). 

- pattern class on disk.
