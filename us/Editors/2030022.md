## General case: an application or site associated with a library
<a name="general_case_application_site_associated_with_library_ELTTEXTE000116"></a>
A library is a WDL file containing all WINDEV or WEBDEV resources: windows, pages, states, classes, procedure collections, data files, etc.

This file is opened by the executable or by the site. The necessary elements are automatically loaded when they are used. 

![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) When creating the executable, the library corresponding to the project is generated. It can be included (or not) in the executable. For more details, see [Create an executable](../Editeurs/2025002.md). 
**Note** For compatibility with version 5.5, it is possible to create an executable without a library. For more details, see [Creating an executable without library](../Editeurs/2030025.md). 

![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) When creating the setup program of a dynamic site, the library of the site is created. For more details, see [Deploy a site](../Editeurs/2028039.md).

## Special case: dividing an application or a large site into several libraries
<a name="special_case_dividing_application_large_site_into_several_libraries_ELTTEXTE000140"></a>
To reduce load times when working with large projects (e.g. hundreds of windows), you can split the project into: 

- a main "Executable" or "Site" project. 

- one or more "Library" projects. Each "Library" project contains the project elements associated with a theme. 




The main project creates the main library. This library is created when creating the executable. This library contains at least the project-specific elements: analysis, project, etc. The main library cannot be shared between multiple projects. It is unique for each project.

The "Library" projects create the secondary libraries of the application by grouping the application elements by theme. 

For example, a project for business management groups several hundreds of windows and reports. To optimize the loading time of the project in the editor, it is split into: 

- a main project. This project creates the main library and uses the secondary libraries. 

- a "Customer management" project. This project is used to create a secondary library. 

- an "Order management" project. This project is used to create a secondary library. 

- etc.




For more details, see [Use several libraries](../Editeurs/2030027.md). 

**Note** To share resources between applications or sites, we recommend the use of external or internal components. They are very easy to use. For more details, see: 

- [External components](../Editeurs/2014011.md).

- [Internal components](../Editeurs/2014100.md).
