## Manipulating a data file
<a name="manipulating_data_file_ELTTEXTE000213"></a>


### Duplicate/Copy a data file
<a name="duplicatecopy_data_file_ELTPARAGRAPHE000034"></a>

Duplicating a data file is used to get two identical data files with different names.

To duplicate/copy a data file:

1. Select the data file to be duplicated in the data model editor.

2. On the "Home" tab, in the "Editing" group, click "Duplicate". 
	Note: It is also possible to select the "Duplicate" option from the data file context menu. 

3. Specify the requested information and validate. The duplicated data file is automatically created in the current analysis (LDM).



<a name="NOTE2_2"></a>


### Delete a data file
<a name="delete_data_file_ELTPARAGRAPHE000061"></a>

To delete a data file:

1. Select the data file to be deleted in the data model editor.

2. Right-click to open the context menu of the data file.

3. Select "Delete". The data file is automatically deleted from the analysis (LDM). If links pointed to this data file, these links are also deleted.




**Note** When creating a data file with the same name as a previously deleted data file, WINDEV, WEBDEV and WINDEV Mobile offer to restore the description of the deleted data file.
<a name="NOTE2_3"></a>


### Rename a data file
<a name="rename_data_file_ELTPARAGRAPHE000074"></a>

To rename a data file:

1. Select the data file to be renamed in the data model editor.

2. Display the file description: 

	- On the "Analysis" tab, in the "Current element" group, click "Description".

	- Display the data file context menu (right-click) and select "Data file description". 




3. In the description window, modify the name of the data file (and its name on disk if necessary). 

4. Validate. The data file is automatically renamed.



<a name="NOTE2_4"></a>


### Use a dictionary
<a name="use_dictionary_ELTPARAGRAPHE000101"></a>

A data file can be included in a dictionary in order to be reused in a new application for example. To integrate the data file into a dictionary, simply drag and drop the data file from the data model editor into the dictionary (displayed in ["Dictionary" pane](../Editeurs/2027014.md)).

When it is included in the dictionary, the description of the data file can subscribe to the modifications. Any modification made in the description of the data file will be applied to the dictionary object and to all the uses of this object.

For more details, see [dictionary](../Editeurs/2023002.md).
<a name="NOTE2_5"></a>


### Create an empty physical the data file corresponding to the description
<a name="create_empty_physical_the_data_file_corresponding_the_description_ELTPARAGRAPHE000118"></a>

To create the corresponding empty physical data file:

1. In the data model editor, select the data file for which a physical file is to be created.

2. Display the data file context menu (right-click) and select "Create data file".

3. Select the directory where the data file will be created and validate.




The following files are automatically created in the specified directory:

- "&lt;Data file&gt;.FIC" (data file).

- "&lt;Data file name&gt;.MMO" (memo file).

- "&lt;Data file name&gt;.NDX" (index file).




If the data file is logged, a "JNL" sub-directory will be automatically created, containing the various log files.

If the data file contains a full-text index, a "&lt;Nom du fichier de données&gt;.FTX" file will be created. 

**Remarks**:

- This option is equivalent to calling [HCreationIfNotFound](../WDLang4/3044254.md).

- This option will be ignored if the data file already exists in the specified directory.
