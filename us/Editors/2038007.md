


## SCM: Checking in an element
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000165"></a>
When an element is checked back into the repository, it becomes available to all the users of the Source Code Manager. The element that was modified locally is copied into the reference project on the SCM server.

The SCM allows you to:

- check an element directly into the repository. 

- [create a local history for an element](../Editeurs/2510003.md).
	




Note: If a check-in policy has been defined, elements will only be checked in if they comply with it. For more details, see [Check-in policy](../Editeurs/2038024.md).

<a name="NOTE2_1"></a>


## Checking an element back in
<a name="checking_element_back_ELTTEXTE000198"></a>
**To check an element into the repository** several methods are available:

- in the ribbon: 
	On the "SCM" tab, "Current element" group, click "Check in" (![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Barre_outils%20-%20HC%20N%B0004%201.gif)).

- in the "Project explorer" pane: 
	Right-click the element and select "Check in".




**Important**: Style sheets are specific to each project. To check in the style sheet, on the "SCM" tab, in the "Other actions" group, expand "Style sheet" and select "Check in the project style sheet".
When you check an element into the SCM, the following window appears:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0014.gif)
This window includes different tabs where you can specify the check-in details:

- The "Tasks" tab, where you can indicate whether the checked-in element corresponds to the execution or completion of a task.

- The "Incidents" tab, where you can indicate if the checked-in element fixes an incident.

- The "Comment" tab, where you can enter a check-in comment. For example, you can indicate that the window proposes a new menu option. 
	The "AI: Generate comment" button automatically generates a comment based on changes made in the code. For more details, see [AI in the code editor](../Editeurs/9000219.md). 




This window also allows you to: 

- View the changes made to the element ("My changes" button).

- View the properties of the element ("Properties" button).

- View the check-in/check-out history of the element. 




You can check in the changes made to the element and keep the element checked out ("Keep element checked out" option).

**Remarks**:

- If the checked-in element was not modified, the SCM opens a specific window. 

- If you have enabled a local history for the element, the check-in window will display the following information:

	- Number of local versions. 

	- "Squash local versions": If this option is enabled, the details of the different local versions will not appear in the history. It will not be possible to revert to the state of a local version. Otherwise, each local version will appear in the history of the element. 




- For more details, see [SCM: Local history](../Editeurs/2510003.md).
