<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000093"></a>
The SCM administrator (Source Code Manager) allows you to handle the different projects included in the Source Code Manager.

It allows you to:

- [manage repositories](../Editeurs/2038021.md) (creation, connection to a repository).

- [manage the branches of a project](../Editeurs/2038022.md).

- [manage files and directories located in a project of the repository](../Editeurs/2038021.md) (add, delete, rename files and directories).

- [manage the different files of the repository](../Editeurs/2038021.md) (check-out, check-in, share, etc.).

- [run some tools](../Editeurs/2038023.md).

- [create backups, purge data, etc.](../Editeurs/2038034.md) (options accessible only via the SCM administrator). 




To open the SCM administrator, go to the "SCM" tab, "Repository" group, expand "Manage" and select "SCM administrator".
