
## Figma: How to find the Figma key
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
To import Figma designs, you need to enter the Figma key in the WINDEV, WEBDEV or WINDEV Mobile general options. 

This key is a token that must be generated from Figma. 

Note: This token is only valid for a limited amount of time. Once this time has elapsed, the Figma import feature will no longer work, and you will have to generate a new token. It is recommended to choose a time-unlimited token (see below).

## Generating the Figma token
<a name="generating_the_figma_token_ELTTEXTE000113"></a>
To generate the Figma token: 

1. Open Figma (Desktop or Web app). 

2. Log in or create a new account. 

3. Go to the account settings.

4. In "Personal access tokens", click "Generate new token". <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Figma1.gif)


5. In the window that appears, specify: <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=figma2.gif)


	- The token name. 

- The validity period. Caution: By default, tokens are valid for 30 days. You can set a 90-day period, or choose "No expiration". 
			Note: Once the token has expired, you will no longer be able to import Figma designs into WINDEV, WEBDEV or WINDEV Mobile. You will need to generate a new token. 

6. Keep the default options. 

7. Click "Generate token". 

8. The token is displayed. Copy and keep this token. 
	Caution: There will be no other way to retrieve this token. If you do not copy it, you will need to generate a new token. 

9. Close the Figma settings window. 





### Entering the key in WINDEV, WEBDEV or WINDEV Mobile
<a name="entering_the_key_windev_webdev_windev_mobile_ELTPARAGRAPHE000042"></a>

Enter the Figma token in the WINDEV, WEBDEV or WINDEV Mobile general options: 

1. On the "Home" tab, in the "Environment" group, expand "Options" and select "XXX general options". 

2. Go to the "Third-party APIs" tab. 

3. In "Figma key", enter the previously generated Figma key. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Figma%20-%20HC%20N%B0001.gif)

	Note: The "Test" button is used to test the validity of the Figma key.
