
## Creating modern windows for mobile apps with the RAD model
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000111"></a>
The RAD (Rapid Application Development) model for mobile applications automatically generates modern UI elements and functional code from a database.

In WINDEV Mobile 2025, the new RAD model quickly creates Android and iOS applications, and generates advanced and cohesive UIs adapted to all screens.**Why use the new RAD model for mobile?**

- Automatically generates the main elements of the application, saving you time.

- Creates a modern and cohesive UI, providing an optimal user experience.

- Generates code for both Android and iOS.

- Uses WLanguage, which can be fully customized to suit your needs.

<a name="NOTE2_1"></a>


## How to?
<a name="how_ELTTEXTE000144"></a>
To use all the features of the latest RAD Mobile model:

1. Create a new window: 

2. Click ![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=ico_nouveau.gif) in the quick access buttons: 

	- In the window that appears, click "Window" then "Window".

	- The window creation wizard opens and shows several types of window, including 5 RAD windows:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=RAD_Mobile%20-%20HC%20N%B0001.gif)


		- Display (details form)

- Gallery (image list)

- List

- Edit (add/modify form)

- Selection (list of options).

3. Select the desired template. The wizard will prompt you to select a data source (data files, queries, views, etc.) and define a window title.

4. The necessary windows are created in the editor. These windows are ready to use and can be fully modified. 




**Remarks**: 

- **Creation of associated windows**: 
	The RAD model for mobile doesn't simply create a single window. 
	For example, when a "list" window is generated, the RAD model automatically adds complementary windows:<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=RAD_Mobile%20-%20HC%20N%B0002.gif&type=thumb)


	- Details form to view the details of a given element,<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=RAD_Mobile%20-%20HC%20N%B0004.gif&type=thumb)

- **Customizable code**
	Windows generated by the RAD model for mobile are fully customizable, both visually (controls) and programmatically.
