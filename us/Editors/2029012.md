
## Open document tabs
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000106"></a>
The document tabs allow you to navigate between the different elements opened in the different editors. 

If the code editor displays a WLanguage event from an element of the window element, the UI and code tabs are grouped together in the bar. 
The name of the WLanguage event is displayed in the code tab.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Barre_document.gif)


A preview thumbnail appears as you hover over an element.
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Barre_Document_visu.gif)


Each document can be closed by clicking the close icon in the tab or in the preview thumbnail. You can also click the mouse wheel to close the element.

**If the tabs overflow the available space, they become scrollable**. Simply use the mouse wheel to scroll through the different elements. 
You can also drag and drop tabs.

A menu displays a list of all open elements. 
<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=barre_document_Menu.gif)


Remarks: 

- The context menu of the open documents bar (not of an individual tab) allows you to open recently closed elements ("Recently closed" option). <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Recent_Ouvert.gif)


- If necessary, the oldest project elements opened in the editor may be closed, depending on available resources.  





### Button context menu
<a name="button_context_menu_ELTPARAGRAPHE000047"></a>

Each tab has a context menu with several options. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Barre_document_Fermer.gif)
The "Close all but this" option is absolutely essential. 

**Using SCM**: 
If the project is located in the SCM, the context will show specific options. Several options allow you to manipulate the current element. The "Close non-checked-out documents" option allows you to keep only documents currently being modified. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0011.gif)
