## The Control Centers dedicated to project management
<a name="the_control_centers_dedicated_project_management_ELTTEXTE000150"></a>


### Overview
<a name="overview_ELTPARAGRAPHE000018"></a>

You can monitor projects in WINDEV, WEBDEV and WINDEV Mobile via the [Project Management Hub](../CCSuivi/3540701.md). 

The Project Management Hub allows you to manage the different events during the lifetime of a project: Requirements, Tasks, Personal schedule, Incidents, etc. In this hub, contributors can indicate pending or completed tasks, fixed incidents, etc. This hub also allows collecting user feedback on deployed applications.

## The redistributable Control Centers
<a name="the_redistributable_control_centers_ELTTEXTE000180"></a>


### Several redistributable Control Centers are provided with WINDEV, WEBDEV and WINDEV Mobile:
<a name="several_redistributable_control_centers_are_provided_with_windev_webdev_and_windev_mobile_ELTPARAGRAPHE000046"></a>

- **[Control Center of engines and HFSQL databases (network and Client/Server)](../CCHF/3540001.md)**
	This Control Center (also named HFSQL Control Center) is used to manage the different HFSQL databases (Network, Mobile and mainly Client/Server) found in the company. This Control Center can be used when developing an application. It can be redistributed along with the HFSQL Client/Server applications.

- **[User Control Center](../CCUser/3540201.md)**
	This Control Center is used to manage the applications deployed on a company network. From this Control Center, the users will be able to install their dedicated applications. The User Control Center can be redistributed.

- The **[Network Application Control Center](../WDAdminExe/2028052.md)**: The WINDEV Application Control Center gives the manager of an application on the network a complete overview of the application.: updates, users, update with push notifications, ... This Control Center is redistributable. It is automatically installed with applications where "Live update" is enabled.

## Specific control centers
<a name="specific_control_centers_ELTTEXTE000204"></a>
WINDEV, WEBDEV and WINDEV Mobile include several specific Control Centers: 

- **[WEBDEV Account Manager](../WDAdminDeploiement/3539029.md)**: The WEBDEV Account Manager allows you easily host websites developed with WEBDEV. This tool is mainly intended for hosting providers and webmasters.

- **[Android Control Center](../CCAndroid/1410086630.md)**: The Android Control Center allows you to easily manage your Android devices during the development phase. This Control Center is included with WINDEV Mobile, and is not redistributable.
