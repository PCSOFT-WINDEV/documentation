
## Office tools

<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000077"></a>
WINDEV includes multiple "Office" controls that allow end users to use the desired tools without leaving the application. 

These features are now available to developers. You can use office tools directly from the UI of your program of choice. Simply click the corresponding icon in the "Tools" tab of the WINDEV, WEBDEV or WINDEV Mobile ribbon.<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Outils_bureautiques%20-%20HC%20N%B0001.gif)


Note: These tools are part of WINDEV and the WINDEV license agreement applies in full. These tools cannot be redistributed.

<a name="NOTE2_1"></a>


## Tools available
<a name="tools_available_ELTTEXTE000101"></a>
5 office tools are at your disposal: 

- WD Docs: Word processing tool to easily create DOCX documents. You can open existing documents or create a document from scratch. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=Outils_bureautiques%20-%20HC%20N%B0002.gif)


- WD Spreadsheet: Spreadsheet tool to easily create XLSX documents. You can open existing documents or create a document from scratch. 

- WD PDF: PDF reader tool. 

- WD Pic: Image editing tool to easily create, open and edit images.  

- WD Diagram: Diagram editing tool to easily create, open and edit diagrams. 




**Note**: You can open all files with extensions supported by these applications. For example, you can associate docx files with WD Docs.
