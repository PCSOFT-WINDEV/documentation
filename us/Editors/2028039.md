


## Deploying a site (from the development computer)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000199"></a>
Regardless of the type of site created by WEBDEV (static site or dynamic site), WEBDEV Development version allows your to automatically install the site on the server.

- **If you develop a static site or a PHP site**:
	WDDeploy lets you deploy your static or PHP sites via FTP or over a local network. To start WWDeploy, go to the "Project" tab, "Generation" group, expand "Deploy site" and select "Generate and deploy site". For more details, see [WDDeploy help](../WDDeploie/3533001.md).
	
	![PHP](https://doc.pcsoft.fr/ext/images/us/PHP.png) To prepare the setup of the PHP site in the Windows Azure Cloud, on the "Project" tab, in the "Generation" group, expand "Deploy site" and select "Create a PHP package for Windows Azure". 
	To use this option, the Windows Azure SDK must be installed on the development computer (the Windows Azure software development kit can be installed from [http://www.microsoft.com/en-US/download/details.aspx?id=15658](http://www.microsoft.com/en-US/download/details.aspx?id=15658)). 
	This option creates a specific package. Then, this package can be directly uploaded into the Azure Cloud from the dedicated portal.




- **If you develop a dynamic site**: 
	To start the setup wizard, go to the "Project" tab, "Generation" group, expand "Deploy site" and select "Generate and deploy site".
	This wizard proposes to:

	1. Create (if necessary) the library of the dynamic site. For more details, see [Options for creating the library](../Editeurs/2028097.md).
			**Reminder** A library is a WDL file containing all WEBDEV resources: pages, states, classes, procedure collections, etc. The presence of a library is mandatory for a dynamic site.
			

	2. Choose the type of setup:

		- [Deployment to PCSCloud](../Editeurs/2028107.md) (more details on [http://www.pcscloud.net](http://www.pcscloud.net)). 

		- [Site deployment directly to a remote WEBDEV Application Server or WEBDEV Cluster.](../Editeurs/2028019.md) This setup will be completed using FTP or HTTP.

		- [Creation of a deployment package](../Editeurs/2028089.md).

		- [Setup via physical media](../Editeurs/2028090.md).

		- [Setup by stand-alone physical media](../Editeurs/2028091.md).

		- Setup via a Docker image of the site. 

		- [Deploying the WEBDEV website via PC SOFT's test hosting service](../Editeurs/2028101.md).
						
	<B><B><B><B>Warning</B></B></B></B>

	 From version 2024 onwards, this deployment mode is available for projects already deployed via this service. We now recommend deployment via PCSCloud.











- **If you develop a web service**: 
	At the end of the web service generation wizard, the deployment of the web service is automatically proposed. During the deployment on a WEBDEV Application Server, the following types of setup are available: 

	- [Site deployment directly to a remote WEBDEV Application Server or WEBDEV Cluster.](../Editeurs/2028019.md) This setup will be completed using FTP or HTTP.

	- [Deployment to PCSCloud](../Editeurs/2028107.md) (more details on [http://www.pcscloud.net](http://www.pcscloud.net)). 

	- [Creation of a deployment package](../Editeurs/2028089.md).

	- [Setup via physical media](../Editeurs/2028090.md).

	- [Setup by stand-alone physical media](../Editeurs/2028091.md).

	- [Deploy web service to the local computer](../WDLang3/3086002.md). This option is proposed only if WEBDEV Development version is installed on the current computer.

	- [Deploying the WEBDEV website via PC SOFT's test hosting service](../Editeurs/2028101.md).
			
	<B><B><B><B>Warning</B></B></B></B>

	 From version 2024 onwards, this deployment mode is available for projects already deployed via this service. We now recommend deployment via PCSCloud.
