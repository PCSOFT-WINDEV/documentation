


## sfSessionInfo (Variable type)

***In french: sfInfoSession***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **sfSessionInfo** type is used to get information about the current session. You can define and change the characteristics of this type of variable using different WLanguage properties.

This type of variable is used by [sfConnection](../WDLang5/1000017579.md) variables. The properties of this type are available after the call to [SFConnect](../WDLang5/1000017583.md).

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Connect to Salesforce
Cnt is sfConnection
Cnt.Login = "balthazar@gmail.com"
Cnt.Password = "qwerty" + "XXB12VCZ54"
IF SFConnect(Cnt) = False THEN
	Error("The connection failed")
ELSE
	Trace("User id logged in: " + Cnx.InfoSession.UserID)
END
```

## Properties


### Properties specific to sfSessionInfo variables
<a name="properties_specific_sfsessioninfo_variables_ELTPARAGRAPHE000045"></a>

The following properties can be used to handle the information about the current session:

| Property name | Type used | Effect |
| --- | --- | --- |
| SessionID | Character string | Session identifier. <br><br>**This property is read-only**. |
| UserID | Character string | User identifier. <br><br>**This property is read-only**. |
| UserInfo | [sfUserInfo](../WDLang5/1000018423.md) | User information. <br><br>**This property is read-only**. |
| SandboxMode | Boolean | <br><br>- <u><u><u>True</u></u></u> if the "Sandbox" mode is enabled, <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>**This property is read-only**. |
| PasswordExpired | Boolean | <br><br>- <u><u><u>True</u></u></u> if the password has expired, <br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br>**This property is read-only**. |
| ServerURL | Character string | Server URL. <br><br>**This property is read-only**. |
| MetadataServerURL | Character string | URL of the meta-data server. <br><br>**This property is read-only**. |
