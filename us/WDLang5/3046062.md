
## iAreaHeight (Function)

***In french: iHauteurZone***

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Warning</B><BR>
	From version <B>28</B>, ***iZoneHeight*</**>** is kept for backward compatibility. This function has been replaced with ***iAreaHeight*</**>**.
</DIV><a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calculates the height of a fixed-width area required to print the entire text that uses the current font.

Note: This function must not be used in the "Opening" event of the. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003046062&name=iareaheight_function">See additional examples</a>

```wl
// Selects a font 
iFont(FontNum)
// Retrieves the height of the column
dHeight is real = iAreaHeight("My Text", 100)
// Draws the borders
iBorder(0, 0, dHeight*2, 200)
```

## Syntax

`<Result> = iAreaHeight(<Text> , <Area width> [, <Type> [, <Beginning> [, <End>]]])`
---

**`<Result>: (Real)`**

Height of the area (in millimeters) allowing to entire text to be printed.

**`<Text>: (Character string)`**

Text to print. This text can be in RTF or HTML. This string must be encoded using UTF-8. If necessary, use [StringToUTF8](../WDLang1/3024042.md) to perform the conversion. 

**`<Area width>: (Real)`**

Width of area (in millimeters).

**`<Type>: (Optional constant)`**

Type of text to print: 



|   |   |
| --- | --- |
| *iHTML* | Text in HTML format.<br><br>![Linux](https://doc.pcsoft.fr/ext/images/us/LX.png)![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *iMarkdown* | Markdown text.<br><br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This constant is available only for reports. For print jobs set programmatically, this constant is not available. |
| *iRTF* | Text in RTF.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This constant is not available. |
| *iText*<br>(default value) | Normal text. |


![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter will be ignored. The text is always of normal type. 

**`<Beginning>: (Optional integer)`**

Index of the first &lt;Text&gt; character to print. If this parameter is not specified, the first character of the string is used.

**`<End>: (Optional integer)`**

Index of the last &lt;Text&gt; character to print. If this parameter is not specified, the last character of the string is used.
