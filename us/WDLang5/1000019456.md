
## BCCapture (Function)

***In french: CBCapture***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Decodes the information stored in a bar code by using the device camera (Android, iPhone, iPad).

**Tip: Use the Camera control**: 

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The Camera control can also be used to decode bar codes directly. For more details, see [Decoding bar codes using a Camera control](../WDChamp/1013304.md).

- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) It is recommended to replace this function with an application window containing a Camera control that allows decoding bar codes. For more details, see [Decoding bar codes using a Camera control](../WDChamp/1013304.md).

<a name="sample_code"></a>

## Example


```wl
// Decode a QR Code
bc is BarCode
bc = BCCapture()
IF ErrorOccurred = False _AND_ bc.TypeContent = bcTypeEmail THEN
    	Info("Email address:" + bc.RawValue)
END
```

## Remarks


### Use conditions
<a name="use_conditions_ELTPARAGRAPHE000223"></a>

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) In an Android application: 

- **BCCapture** opens a new window that displays the camera preview stream. Then, you must: 

	- center the bar code to decode in the relevant area. 

	- tap to read the bar code.







- Bar codes are decoded using ML Kit's bar code scanning API. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) For iPhone/iPad applications: 

- **BCCapture** opens a new window that displays the camera preview stream. Then, you just need to center the bar code to decode in the relevant area. 

- The window used to take photos is included in the WINDEV Mobile application. No additional library is required. 







<a name="NOTE0_2"></a>


### Handling errors
<a name="handling_errors_ELTPARAGRAPHE000272"></a>

To determine whether the bar code failed to be read, use the [ErrorOccurred](../WDLang1/3087001.md) variable.

The function will fail in the following cases: 

- if it is used in the simulator,

- if it is used in the emulator,

- if it is used in a device not equipped with a camera.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) if the "Cancel" button was used. In this case, the **TypeBarCode** property of the [BarCode](../WDLang5/1000019451.md) variable will be different from BC_QRCODE. 




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) If the barcode is decoded but its type is not recognized, the **TypeBarCode** property of the [BarCode](../WDLang5/1000019451.md) variable will correspond to the *BC_UNKNOWN* constant.

### Application in the background: Specific case from Android 10
<a name="application_the_background_specific_case_from_android_10_ELTPARAGRAPHE000445"></a>

Starting with Android 10, it is no longer possible to open a window when the application is in the background. 

**BCCapture** can open a window. If this function is used while the application is in the background, a fatal error will occur. 

Tips: 

- It is possible to determine if the application is in the background using [InBackgroundMode](../WDLang1/1000023457.md). 

- If an application needs to interact with the user while it is in the background, the solution is to display a notification (via the [Notification](../WDLang3/1000019441.md) type). The application will be brought back to the foreground when the notification is clicked, if the **ActivateApplication** property is set to <u><u><u><u>True</u></u></u></u>. You can also open a window from the procedure passed to the **ActionClick** property.




For more details, see [Android 10: Behavior of applications in the background](../Editeurs/9000195.md).
