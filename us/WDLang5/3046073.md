
## iSkipPage (Function)

***In french: iSautePage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Forces a page skip: the corresponding code is sent to the printer spooler. The print cursor is positioned at coordinates (0,0) of the next page.

The print job is not started (only [iEndPrinting](../WDLang5/3046053.md) can be used to start the print job).

**Note**: We strongly advise against using this function in reports created with the report editor.. Use [iPageEnd](../WDLang5/3046038.md) instead.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Print a text
iPrint("Hello")
// Page break
iSkipPage()
// Print a text
iPrint("We are" + DateSys())
// Start the print job
iEndPrinting()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`iSkipPage()`
