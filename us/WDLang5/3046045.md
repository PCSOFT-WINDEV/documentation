
## iCreateFont (Function)

***In french: iCréePolice***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Creates a new print font. This font can be used in different processes. This font is identified by a font number, chosen during the development process. To choose this font and use it in the different print functions, simply select it with [iFont](../WDLang5/3046014.md).

**Remark**: This function MUST be called AFTER the [iPreview](../WDLang5/3046069.md) function.. Otherwise, the previews will be ignored.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003046045&name=icreatefont_function">See additional examples</a>

```wl
// Create a 48-point Pica font
iCreateFont(1, 48, iBold + iItalic, iRoman)
// Print a text with this font
iPrint(iFont(1) + "48-pica text")
```

## Syntax

### Create a new font

`iCreateFont(<Identifier> , <Size> , <Style> , <Name> [, <Color> [, <Angle>]])`
---

**`<Identifier>: (Integer)`**

Font identifier. This identifier will be used in the different print functions to specify the font used.

**`<Size>: (Integer)`**

Height of font in Pica points (1 Pica point = 0.353 mm).

**`<Style>: (Integer constant (or combination of constants))`**

Font attributes.


|   |   |
| --- | --- |
| *iBold* | Bold font |
| *iCondensed* | Condensed characters<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is ignored. |
| *iExtended* | Extended characters<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is ignored. |
| *iItalic* | Italic font |
| *iLarge* | Large characters<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This option is ignored. |
| *iNormal*<br>(default value) | Standard font, without attributes |
| *iStrikeOut* | Strikethrough font |
| *iUnderlined* | Underlined font |



**`<Name>: (Character string)`**

Name of font (among the fonts installed on the current computer).

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) **PDF printouts** fonts: only the following fonts are supported: Courier, Helvetica, Times, Symbol and ZapfDingbats. If the name of specified font does not correspond to a supported font, the Helvetica font will be used.

**`<Color>: (Optional integer)`**

Color used for the font. If this parameter is not specified, the color used is black. 
This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Angle>: (Optional integer)`**

Angle (in degrees) according to which the text will be printed. The angle is calculated counterclockwise from a horizontal line (trigonometric direction).

### Creating a font family

`iCreateFont(<Identifier> , <Size> , <Style> , <Family> [, <Color> [, <Angle>]])`
---

**`<Identifier>: (Integer)`**

Font identifier. This identifier will be used in the different print functions to specify the font used.

**`<Size>: (Integer)`**

Height of font in Pica points (1 Pica point = 0.353 mm).

**`<Style>: (Integer constant (or combination of constants))`**

Font attributes.


|   |   |
| --- | --- |
| *iBold* | Bold font |
| *iCondensed* | Condensed characters |
| *iExtended* | Extended characters |
| *iItalic* | Italic font |
| *iLarge* | Large characters |
| *iNormal*<br>(default value) | Standard font, without attributes |
| *iStrikeOut* | Strikethrough font |
| *iUnderlined* | Underlined font |



**`<Family>: (Integer constant)`**

Font family.


|   |   |
| --- | --- |
| *iCourier* | Courier font (fixed character width) |
| *iDefault* | Any font ("Don't care") |
| *iRoman* | Roman font (exotic font) |
| *iSwiss* | Swiss font (quality font) |



**`<Color>: (Optional integer)`**

Color used for the font. If this parameter is not specified, the color used is black. 
This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Angle>: (Optional integer)`**

Angle (in degrees) according to which the text will be printed. The angle is calculated counterclockwise from a horizontal line (trigonometric direction).

## Remarks




### Default font
<a name="default_font_ELTPARAGRAPHE000231"></a>

If **iCreateFont** is not used, the default font will have the following characteristics: 

- Font #0,

- size: 12, 

- normal style.

### Font and family
<a name="font_and_family_ELTPARAGRAPHE000246"></a>

With some configurations, [iPrint](../WDLang5/3046031.md) can produce unexpected results if the name of a font family was specified in **iCreateFont**. It is recommended to specify the name of a font in **iCreateFont**.

### Getting the list of fonts installed on a computer
<a name="getting_the_list_fonts_installed_computer_ELTPARAGRAPHE000261"></a>

To get the list fonts installed on a computer:

1. In the program manager of Windows, select the main group.

2. Click the "Control panel" icon and select "Fonts".

3. In the list of fonts installed, write down the names without taking the attributes and the types into account.

### Differences between FontCreate and iCreateFont
<a name="differences_between_fontcreate_and_icreatefont_ELTPARAGRAPHE000287"></a>

[FontCreate](../WDLang1/3060002.md) creates a font definition that can be used in all the elements of a WINDEV or WEBDEV application. This font is stored using the [Font](../Motscles/1514045.md) variable type and can be used:

- to write text in drawings ([dFont](../WDLang1/3029020.md)).

- to select a print font ([iFont](../WDLang5/3046014.md)).

- to set the font used in the controls of a window ([Font of window controls](../Motscles/1514045.md) property).

- to set the font used in the controls of a report ([Font of report controls](../Motscles/1514045.md) property).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png)![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) to select the font used in charts ([grLabelFont](../WDLang3/3042012.md), [grLegendFont](../WDLang3/3042037.md), [grTitleFont](../WDLang3/3042048.md), [grAxisTitleFont](../WDLang3/3042059.md)).




**iCreateFont** can only create a font that can be used by print functions.
<a name="NOTE0_5"></a>




### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000336"></a>

- **iCreateFont** can be used to create as many fonts as necessary (memory limit).

- You must create as many fonts as the number of colors found in the text.

- When printing to HTML or RTF files (functions [iPreview](../WDLang5/3046069.md) or [iDestination](../WDLang5/3046074.md)), 90° fonts are replaced by 0° fonts: text is printed horizontally.



<a name="NOTE0_7"></a>


### Freeing the fonts created by iCreateFont
<a name="freeing_the_fonts_created_icreatefont_ELTPARAGRAPHE000353"></a>

When no longer used, the fonts created with **iCreateFont** can be destroyed by [iReset](../WDLang5/3046067.md) to free resources. If [iReset](../WDLang5/3046067.md) is not used, the fonts will be automatically destroyed when the application is closed.
