
## xmlXAdESSignature (Variable type)

***In french: xmlSignatureXAdES***
Inherits from [xmlSignature (Variable type)](../WDLang5/1000020736.md)
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xmlXAdESSignature** type is used to define all the advanced characteristics of a XAdES-compliant signature. You can define and change the characteristics of this type of variable using different WLanguage properties. 

**Remarks**:

- Only XAdES-B is supported. 

- For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
sign is xmlXAdESSignature
sign.NormalizationAlgorithm = atC14NExclusive
sign.SignatureAlgorithm = saRSA_SHA_256
sign.Key = MyCertificate // Or path to certificate file
sign.KeyFileType = tfcPKCS12
sign.SignaturePolicyIdentifier = "urn:oid:x.x.x.x.x.x.x.x.x.x.x"

sGUID is string = "xxxxxxxx"
sign.Reference[1].URI = "#" + sGUID 
			// Or replace (GetGUID(guidFormatted), ["{", "}"], "") 
			// for an identifier without braces but with "-" separating it into several blocks
sign.Reference[1].Transformation [1] = atEnveloped
sign.Reference[1].Transformation [2] = atC14NExclusive
sign.Reference[1].HashAlgorithm = HA_SHA_256

x509 is xmlSignatureInformationKeyX509
x509.WithCertificate = False
sign.KeyInformation[1] = x509

xml is xmlDocument
xml.Body:Id = sGUID
xml.Body.Data = "Hello World!"
```

## Properties


### Properties specific to xmlXAdESSignature variables
<a name="properties_specific_docparampagetitleshort_variables_ELTPARAGRAPHE000035"></a>

Note: The **xmlXAdESSignature** type inherits from the [xmlSignature](../WDLang5/1000020736.md) type. This means all the properties of the [xmlSignature](../WDLang5/1000020736.md) type are available for the **xmlXAdESSignature** type. These properties appear in italics in the list below. 

The following properties can be used to manipulate a variable of type xmlXAdESSignature:

| Property name | Type used | Effect |
| --- | --- | --- |
| *NormalizationAlgorithm* | Integer constant | XML canonicalization method (C14N):<br><br>- *atNone*: No canonicalization method. <br><br>- *atC14N11Inclusive*: C14N11 inclusive canonicalization. <br><br>- *atC14N11InclusiveWithComments*: C14N11 inclusive canonicalization with comments.<br><br>- *atC14NExclusive*: C14N exclusive canonicalization.<br><br>- *atC14NExclusiveWithComments*: C14N exclusive canonicalization with comments.<br><br>- *atC14NInclusive*: C14N inclusive canonicalization.<br><br>- *atC14NInclusiveWithComments*: C14N inclusive canonicalization with comments.<br><br><br> |
| *Key* | <br><br>- [Certificate](../WDLang1/1000019287.md) variable<br><br>- Character string<br><br><br> | Certificate or key file used for the signature. <br><br>- If this property corresponds to a file, the **KeyFileType** property must be specified.<br><br>- If this property corresponds to a variable of type [Certificate](../WDLang1/1000019287.md), you can use a certificate present on a smart card. <br>	<br><br><br> |
| *KeyFileType* | Integer constant | If the **Key** property corresponds to a file, the **KeyFileType** property is used to define the type of file encoding: <br><br>- *tfcBinary*: Binary encoding.<br><br>- *tfcDER*: Distinguished Encoding Rule (DER) encoding.<br><br>- *tfcPEM*: PEM encoding.<br><br>- *tfcPKCS12*: PKCS12 encoding.<br><br>- *tfcPKCS8DER*: PKCS8 DER encoding.<br><br>- *tfcPKCS8PEM*: PKCS8 PEM encoding.<br><br><br> |
| *KeyInformation* | Array of [xmlSignatureInformationKeyX509](../WDLang3/1000020742.md) variables | Used to specify information about the key used. |
| *KeyPassword* | Character string or Secret string | Password used to decrypt the private key.<br>**Secret strings**: If you use the secret string vault, the type of secret string used for this parameter must be "ANSI string - Latin".<br>To learn more about secret strings and how to use the vault, see [Secret string vault](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) Secret strings are not available for this parameter in Android/Android widget applications. |
| *Reference* | Array of [xmlSignatureReference](../WDLang3/1000020746.md) | Elements to sign. |
| *SignatureAlgorithm* | Integer constant | Signature algorithm:  <br><br>- *saDSA_SHA_160*: Digital Signature Algorithm (DSA) and SHA-160. <br><br>- *saECDSA_SHA_224*: Elliptic Curve Digital Signature Algorithm (ECDSA) and SHA-224.<br><br>- *saECDSA_SHA_256*: Elliptic Curve Digital Signature Algorithm (ECDSA) and SHA-256.<br><br>- *saECDSA_SHA_384*: Elliptic Curve Digital Signature Algorithm (ECDSA) and SHA-384.<br><br>- *saECDSA_SHA_512*: Elliptic Curve Digital Signature Algorithm (ECDSA) and SHA-512.<br><br>- *saRSA_SHA_160*: RSA encryption algorithm and SHA-160. <br><br>- *saRSA_SHA_256*: RSA encryption algorithm and SHA-256. <br><br>- *saRSA_SHA_384*: RSA encryption algorithm and SHA-384.<br><br>- *saRSA_SHA_512*: RSA encryption algorithm and SHA-512.<br><br><br> |
| SignaturePolicyIdentifier | Character string | Signature policy identifier.<br>Generally, this identifier has the following format: <br><br><pre><code>"urn:oid:x.[...].x"</code></pre><br> |
