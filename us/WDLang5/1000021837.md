


## FBGetUserInformation (Function)

***In french: FBRécupèreInformationUtilisateur***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Gets the Facebook information of the connected user. 

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This function is available in the simulator.

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Note**: This feature is available up to Android 11. Starting with Android 12, this function causes a fatal error. 
We advise you to: 

- use [SysAndroidVersion](../WDLang1/1000019785.md) to test the Android version used.

- use [AuthIdentify](../WDLang3/1000022219.md) to manage Facebook authentication.

## Example


```wl
MySession is fbSession
...
sEmail is string = FBGetUserInformation(MySession, fbEmail)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Result> = FBGetUserInformation(<Session> , <Information>)`
---

**`<Result>: (Character string or Buffer)`**

Requested information. 

**`<Session>: (fbSession variable)`**

Name of the [fbSession](../WDLang5/1000021851.md) variable corresponding to the Facebook connection to handle. 

**`<Information>: (Character String constant)`**

Requested information: 


|   |   |
| --- | --- |
| *fbEmail* | User's email address. |
| *fbIdentifier* | User's Facebook ID. |
| *fbImage* | User's image. |
| *fbName* | Name of the user. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarks
During the connection, the rights (permissions) corresponding to the requested information must have been granted. Otherwise, the function will fail.
