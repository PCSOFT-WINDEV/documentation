


## BarCodes (Variable type)

***In french: CodeBarres***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **BarCodes** type is used to handle the information found in a bar code. You can define and change the characteristics of this barcode using different WLanguage properties. 

The BarCodes type can be used as follows: 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/us/WD.png) The **BarCodes** type is mainly used to: 

	- generate bar codes in the windows and reports.

	- decode QR Codes (in an image).

	- print bar codes ([iPrintBarCode](../WDLang5/3046020.md)). 




- ![WEBDEV - Server code](https://doc.pcsoft.fr/ext/images/us/WBS.png) The **BarCodes** type is mainly used to: 

	- generate bar codes in the pages.

	- generate bar codes in the reports.

	- print bar codes ([iPrintBarCode](../WDLang5/3046020.md)).




- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) The **BarCodes** type is mainly used to: 

	- decode bar codes read by the device camera. 

	- generate bar codes in the windows.







- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) The **BarCodes** type is mainly used to: 

	- generate QR Code bar codes in the windows. 

	- decode bar codes read by the device camera.

	- decode the QR Code bar codes found in an image.

	- print bar codes ([iPrintBarCode](../WDLang5/3046020.md)). 





**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) 
```wl
// Decode a QR Code
bc is BarCode
bc = BCCapture()
IF ErrorOccurred = False _AND_ bc.TypeContent = bcTypeEmail THEN
    	Info("Email address: " + cb.ValueBrute)
END
```



```wl
MyQRCode is BarCode 
MyQRCode.ContentType = bcTypeText 
MyQRCode.TypeBarCode = BC_QRCODE 
MyQRCode.Content = "http://www.windev.com" 

// Assign to a Bar Code control
BAC_BCControl = MyQRCode
```



```wl
// Generate a QRCode with an image
// ------------- Bar code or report initialization code
QRCodeWithImage is BarCode
// Image to be inserted in the center of the barcode
ImageQRCodeCenter is Image
ImageQRCodeCenter = IMG_FLAG
// Type of bar code
QRCodeWithImage.TypeBarCode = BC_QRCODE
QRCodeWithImage.ContentType = bcTypeText
// Image at the center
QRCodeWithImage.Image = ImageQRCodeCenter
// High error correction level to compensate for the image at the center
QRCodeWithImage.CorrectionError = qrcodeLevelH
QRCodeWithImage.ImageProportion = 3
// For an image proportion of 3%, a Level L correction (qrcodeLevelL) would not be enough
// to have a readable bar code

// (Initial) value
QRCodeWithImage.Content = "https://www.windev.com"
// In a report, the value can be reassigned:
//- by binding the control to data
//- in the code before printing 
//- in the code for reading data in the report
// or anywhere else afterwards

// Assign to a Bar Code control
BAC_Invoice = QRCodeWithImage

// ------------- Code before printing
BAC_Invoice.Value = "QR code with a flag in the center!"
```

## Properties


### Properties specific to BarCodes variables
<a name="properties_specific_barcodes_variables_ELTPARAGRAPHE000093"></a>

The following properties can be used to handle a bar code:

| **Property name** | **Type used** | **Effect** |
| --- | --- | --- |
| Content | Any type | Value of bar code. <br><br>- For QR codes, the type of this value depends on the **ContentType** property . <br>	See the note below to find out the correspondence between the type of content and the type of value. <br><br>- When reading bar codes other than QR codes, this property is always of type "String" and its value is the same as that of the **RawValue** property.<br><br><br> |
| ContentType | Integer constant | Nature of the data stored in the bar code: <br><br>- *cbTypeTexte* (default value when variable is created): Plain text<br><br>- *cbTypeTelephone* Telephone number<br><br>- *cbTypeSMS* SMS number<br><br>- *cbTypeEmail* Email address<br><br>- *cbTypeContact* Contact description<br><br>- *cbTypePosition* Geographical position<br><br>- *cbTypeURL* URL (bookmark). To insert an http address into the bar code, use the *cbTypeText* type.  <br>	This constant is kept for backward compatibility and it must be used in very specific cases. <br><br>- *cbTypeMarket* Link to an application on Google Play (for Android applications only)<br><br>- *cbTypeWiFi* Wi-Fi network connection settings (for Android application only)<br><br><br>**Note** These data natures are available for 2D barcodes (e.g. QR Code, Aztec, datamatrix, PDF417, ...). For bar codes other than 2D bar codes, the data is always text data. |
| CorrectionError | Integer constant | Error correction level: defines the threshold for reading a damaged barcode. <br><br>This property is available for: <br><br>- the QR Code bar codes. <br><br>- the PDF-417 bar codes.<br><br>- the Aztec bar codes.<br><br><br><br><br>**The following constants are available for the QR Code**: <br><br>- *qrcodeH* level: around 30% of encoded words can be restored.<br><br>- *qrcodeL* level: around 7% of encoded words can be restored.<br><br>- *qrcodeLevelM*: around 15% of encoded words can be restored.<br><br>- *qrcodeLevelQ*: around 25% of encoded words can be restored.<br><br><br>The selected correction level triggers: <br><br>- the resizing of bar code.<br><br>- the modification of the maximum number of characters allowed in the bar code.<br><br><br><br><br>A higher correction level means that the drawing of the bar code will have an important size and that less data will be drawn. On the contrary, a higher correction level means that the bar code will be readable even if the support is damaged.<br><br>**Tips:**: <br><br>- If the bar code contains a URL, the level L is sufficient. <br><br>- If a logo is inserted into the bar code, we recommend that you use a higher level (M or Q). <br><br>- If the bar code is intended for printing labels for a warehouse, the level H must be used. <br><br><br><br><br>**For the PDF-417 bar codes**, the correction level of the error corresponds to an integer included between 0 and 8. <br><br>**For the Aztec bar codes**, the correction level corresponds to an integer included between 5 and 95, representing the percentage of error correction. The  default value is 33. If the given value is <br><br>- less than 5, the value will be set to 5, <br><br>- greater than 95, the value will be set to 95, <br><br>- negative, the value will be set to 33 (default value). <br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available. |
| Image |   | Image added in the center of the bar code (only for QR Codes). This image can correspond to: <br><br>- a variable of type [Image](../WDLang1/1000019650.md),<br><br>- a character string containing the path of the image file to be used,<br><br>- an image memo item, etc.<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available. |
| ImageProportion | Real | Percentage of the area occupied by the image added to the center of the barcode (only for QR codes for which the **Image** property is specified). This value must not exceed half of the area reserved for error correction.<br><br><br>\   \   \<br>\ --- \ --- \<br>\ Value of the CorrectionError property \ Maximum value of the ImageProportion property \<br>\ qrcodeLevelH \ 5 \<br>\ qrcodeLevelL \ 1 \<br>\ qrcodeLevelM \ 3 \<br>\ qrcodeLevelQ	 \ 5 \<br><br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property is not available. |
| Options | Integer constant (or combination of constants) | Characteristics of bar code. These characteristics are mainly used when a bar code is printed by [iPrintBarCode](../WDLang5/3046020.md). The following constants can be used: <br><br>- *CB_Bas*: Barcode positioned at bottom of destination rectangle.<br><br>- *CB_ControlCharacter* Bar code containing control characters (valid only for bar codes of type *CB_CODE128*, *CB_DATAMATRIX*, *CB_EAN128*, *CB_GS1_128* and *CB_PDF417*). By default, control characters are enclosed between "&lt;" and "&gt;". To avoid interpreting these characters as control characters, simply double the first "&lt;":  <br><br>	- "&lt;C40&gt;" = control character   <br><br>	- "&lt;&lt;AB&gt;" = &lt;AB&gt; to be encoded in the bar code.<br><br><br><br><br><br>For more details, see [The different types of bar codes](../WDLang5/3046064.md).<br><br>- *CB_CVerificationCharacter* Bar code containing check digit (valid only for bar codes of type *CB_CODE128*, *CB_DATAMATRIX*, *CB_EAN128*, *CB_GS1_128* and *CB_PDF417*).<br>	If this option is selected, the *BC_ControlDigits* and *BC_Charsets* constants are automatically taken into account.<br><br>- *CB_CentreH*: Horizontal centering of barcode in destination rectangle.<br><br>- *CB_CentreV* Vertical centering of barcode in destination rectangle.<br><br>- *CB_Droite*: Right-aligned barcode in destination rectangle.<br><br>- *CB_Extended* Extended barcode (valid only for barcodes of type *CB_CODE39* and *CB_CODE93*).<br><br>- *CB_FormateTexte* Formats the text displayed for barcodes of type *EAN 128* type barcodes: brackets are added around AIs in the printed text.<br><br>- *CB_Left*: Left-aligned barcode in destination rectangle.<br><br>- *CB_Haut*: Barcode positioned at the top of the destination rectangle.<br><br>- *CB_IgnoreFormatting* Ignore parentheses in code 128, EAN-128 or GS1-128 (valid only for barcodes of type *CB_CODE128*, *CB_EAN128* and *CB_GS1_128*).<br>	The brackets allow the users to easily read the bar code but they are not drawn in the code.<br><br>- *CB_CharacterSets* Bar code using one or more character sets used for bar code compression. This set of characters must be defined in the bar code value.<br>	For more details, see [The different types of bar codes](../WDLang5/3046064.md).<br><br>- *CB_NonProportional*: Adjusts the barcode to the size of the destination rectangle.<br><br>- *CB_SansTexte* Does not display the text under the barcode (valid only for barcodes of type *CB_UPCA*, *CB_UPCB*, *CB_EAN13* and *CB_EAN8*).<br><br>- *CB_Text* Displays the text under the barcode. <br>	The text is normalized for the *BC_UPCA*, *BC_UPCE*, *BC_EAN13* and *BC_EAN8* bar codes. <br>	For the other types of bar codes, the text can exceed the display border of bar code.<br><br>- *CB_TextCenter* Centers the text below the barcode (valid only for barcodes of type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*).<br><br>- *CB_RightText* Aligns the text below the barcode to the right (valid only for barcodes of type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*). <br><br>- *CB_TextLeft* Aligns the text below the barcode to the left (valid only for barcodes of type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*).<br><br>- *CB_Verification* Bar code with check digit (valid only for bar codes of type *CB_CODE39*, *CB_CODE93*, *CB_INTER2OF5* and *CB_CODABAR*).<br><br>- *CB_Vertical* Print barcode vertically.<br><br>- *CB_90* Print barcode vertically.<br><br>- *CB_180*: Prints the barcode by rotating it 180 degrees.<br><br>- *CB_270*: Prints barcodes rotated through 270 degrees.<br><br><br> |
| RawValue | Unicode string | Raw value of bar code. <br><br>For barcodes other than QR codes, the value of this property is the same as that of the **Content** property.<br><br>**This property is read-only**.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This property contains the value of the bar code as read by the [BCCapture](../WDLang5/1000019456.md) function, regardless of the nature of the data stored in the bar code.<br> <br>For example, this property corresponds to "mailto:address@mail.com" if a QR Code containing an email address is decoded. <br><br>In previous versions, this property was called 'RoughValue'. |
| TypeBarCode | Integer constant | Type of bar code: <br><br>- *CB_AZTEC* AZTEC barcode.<br><br>- *CB_MAXICODE* MaxiCode type barcode.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Not available.<br><br>- *CB_QRCODE* QR Code barcode. This constant is used by default when creating a BarCode variable. <br><br>- *CB_UPCA* UPC-A barcode.<br><br>- *CB_UPCE* UPC-E barcode.<br><br>- *CB_EAN8* EAN8 barcode.<br><br>- *CB_EAN13* EAN13 barcode.<br><br>- *CB_CODE39* Code39 barcode.<br><br>- *CB_CODE93* Code93 barcode.<br><br>- *CB_CODE128* Code128 barcode.<br><br>- *CB_GS1_128* GS1-128 barcode (new name for EAN128 barcode).<br><br>- *CB_INTER2OF5* Interleaved 2 of 5 barcode.<br><br>- ![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) *CB_INCONNU* Bar code decoded by function [BCCapture](../WDLang5/1000019456.md) with an unrecognized type. <br>	 Note: This constant is available in read-only mode. <br><br>- *CB_DATAMATRIX* DATAMATRIX type barcode.<br>	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/us/IPHONE.png)![IOS Widget](https://doc.pcsoft.fr/ext/images/us/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/us/CATALYST.png) This type of bar code is not available.<br><br>- *CB_PDF417* PDF417 barcode.<br><br>- *CB_CODABAR* Codabar barcode.<br><br>- *CB_CODE11* Code11 barcode.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of bar code is not available.<br><br>- *CB_EAN128* EAN128 bar code.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of bar code is not available.<br><br>- *CB_MSI* MSI type barcode.<br>	![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) This type of bar code is not available.<br><br><br><br><br>These types are also available for the prints performed by [iPrintBarCode](../WDLang5/3046020.md). |

### Correspondence between the Content and ContentType properties
<a name="correspondence_between_the_content_and_contenttype_properties_ELTPARAGRAPHE000401"></a>

| Type of content | Type of value (Content property) | Remark |
| --- | --- | --- |
| *bcTypeText* | Character string | Example: "WINDEV is good!" |
| *bcTypePhone* | Character string | Exemple: "0612345678" |
| *bcTypeSMS* | Character string<br>By reading: The members of the [SMS structure](../WDLang3/3068003.md) (SMS.Message and SMS.Number) will be automatically filled with the values read from the barcode. the content will correspond to a string of the form: &lt;Numéro&gt; + RC + &lt;Message&gt;<br><br>In generation: If they exist, members of the [SMS structure](../WDLang3/3068003.md) (SMS.Message and SMS.Number) will be automatically taken into account. It is also possible to use a character string of the form: &lt;Numéro&gt; + RC + &lt;Message&gt; | Example: "0612345678&lt;CR&gt;Text to send" |
| *bcTypeURL* | Character string<br><br>Corresponds to a bookmark. The content will be encoded in the following format: "urlto::URL". For example: "urlto::http://www.pcsoft.fr". Some decoders do not support this type of content. <br><br>To specify an http address, use the *cbTypeText* type. <br><br>Note: This constant is kept for compatibility and must be used in very specific cases. | Example: "http://www.google.com" |
| *bcTypeMarket* | Character string | Example: "market://search?q=pname:com.company.application" |
| *bcTypeWiFi* | Character string | Character string in the following format: <br>&lt;SSID&gt; + TAB + &lt;Security protocol&gt;+ TAB + &lt;Key&gt;<br>Example: "MyNetwork&lt;TAB&gt;WPA&lt;TAB&gt;pwd" |
| *bcTypeEmail* | Character string | Example: "name@email.com" |
| *bcTypeContact* | Empty. <br>Read: The members of the [mContact structure](../WDLang3/1000006111.md) will be automatically filled in with the values read from the barcode.<br>In generation: [mContact structure](../WDLang3/1000006111.md) members will be automatically used to generate the barcode. |   |
| *bcTypeLocation* | [geoPosition](../WDLang3/1000019191.md) variable.<br><br>Reading: Properties **Latitude** and **Longitude** of the variable will be automatically filled in with the values read from the barcode.<br>In generation: Properties **Latitude** and **Longitude** properties of the variable are automatically used to generate the barcode. |   |
