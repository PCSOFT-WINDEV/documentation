


## XMLModify (Function)

***In french: XMLModifie***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifies the content of the current element found in the XML document.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Position on the root
XMLRoot("MyXMLDoc")
// Replace the links
XMLFind("MyXMLDoc", "Link", XMLTag)
WHILE XMLFound("MyXMLDoc") = True
	// Calculate the new value of the link
	New_link = Process_Link(XMLData("MyXMLDoc"))
	// Modification in the XML document
	XMLModify("MyXMLDoc", New_link)
	XMLNext("MyXMLDoc")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = XMLModify(<XML document> , <New element value>)`
---

**`<Result>: (Boolean)`**



- <u><u><u><u>True</u></u></u></u> if the modification is performed,

- <u><u><u><u>False</u></u></u></u> otherwise (the [ErrorOccurred](../WDLang1/3087001.md) variable is set to <u><u><u><u>True</u></u></u></u>).
	To get more details on the error, use [ErrorInfo](../WDLang1/3013008.md).




**`<XML document>: (Character string)`**

XML document where the modification will be performed.

**`<New element value>: (Character string)`**

New value for the current element:

- value of the tag if the current element is a tag.

- value of the attribute if the current element is an attribute.

<a name="NOTE0_1"></a>

## Remarks


### Reading the value of the current element
<a name="reading_the_value_the_current_element_ELTPARAGRAPHE000083"></a>

To read the value of the current element, use [XMLData](../WDLang5/3081004.md).
<a name="NOTE0_2"></a>


### Saving the modifications in the XML file
<a name="saving_the_modifications_the_xml_file_ELTPARAGRAPHE000093"></a>

To save the modifications performed in an XML file, you must:

1. Use the [XMLBuildString](../WDLang5/3081016.md) function. This function retrieves and formats the content of an XML document.

2. Save the character string generated by [XMLBuildString](../WDLang5/3081016.md) in an XML file. To do so, use the [fSaveText](../WDLang1/3036046.md) function.




Example:

```wl
// Once the XML document was modified 
XMLSource = XMLBuildString("XMLDoc")
// Save the XML file
fSaveText("ModifiedExample.xml", XMLSource)
```
