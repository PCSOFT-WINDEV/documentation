


## GglRequest (Function)

***In french: GglRequête***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sends a communication request (HTTP request) to a Google service.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000021454&name=gglrequest_function">See additional examples</a>

```wl
// Connection
Cnt is gglConnection
...
IF GglConnect(Cnt) = False THEN
	Error(ErrorInfo())
END

// Query without parameter
XMLQry is string = GglRequest(Cnt, gglServiceDocuments, ...
		"http://docs.google.com/feeds/documents/private/full") 
// Query with parameters (search for "Casimir")
XMLQry = GglRequest(Cnt, gglServiceDocuments, ...
		"http://docs.google.com/feeds/documents/private/full?q=Casimir")
```

<a name="SYNTAXE1"></a>

## Syntax

`<Result> = GglRequest(<Google connection> , <Google service> , <HTTP request> [, <Data to send> [, <Query type>]])`
---

**`<Result>: (ANSI character string)`**



- Server response,

- Empty string ("") if an error occurs ([ErrorOccurred](../WDLang1/3087001.md) variable set to <u><u><u><u>True</u></u></u></u>).




**`<Google connection>: (gglConnection variable)`**

Name of the [gglConnection](../WDLang5/1000018009.md) variable to be used. This connection was validated by [GglConnect](../WDLang5/1000017332.md).

**`<Google service>: (Integer constant)`**

Google service on which the request will be performed:


|   |   |
| --- | --- |
| *gglServiceCalendar* | Service "Google Calendar": Agenda Google |
| *gglServiceContacts* | Service "Google Contacts": Management of Google Contacts. <br><br><br>	<B><B><B><B>Warning</B></B></B></B><br><br>	 Since June 15, 2021, the Google Contacts API used by this feature is no longer available ([https://developers.google.com/contacts/v3/announcement](https://developers.google.com/contacts/v3/announcement)). For more details, see [Management of Google contacts](../WDLang5/1000017560.md).<br>
 |
| *gglServiceDocuments* | Google Docs List service: Document management |
| *gglServicePicasa* | "Picasa" service |
| *gglServiceStaticMaps* | Google Static Maps service: Maps management |



**`<HTTP request>: (Character string)`**

Full URL of the request (including the parameters stored in the URL if necessary). For more details, see the Google documentation corresponding to the service used.

**`<Data to send>: (Optional character string)`**

Data that must be sent onto the server. For more details, see the Google documentation corresponding to the service used.

**`<Query type>: (Optional integer constant)`**

Type of HTTP request to send:


|   |   |
| --- | --- |
| *gglHTTPDelete* | Delete request. |
| *gglHTTPGet* | Get request. |
| *gglHTTPPost* | Post request. |
| *gglHTTPPut* | Put request. |


If &lt;Data to send&gt; is specified, the requests are ***gglHTTPPost*** requests by default.
If &lt;Data to send&gt; is not specified, the requests are ***ggHTTPGet*** requests by default.

## Remarks


### Possible error cases: 
<a name="possible_error_cases_ELTPARAGRAPHE000130"></a>

- The Internet connection is not valid.

- The authentication was not performed properly.

- The server returns an error.




To find out whether an error occurred, use the [ErrorOccurred](../WDLang1/3087001.md) variable.
