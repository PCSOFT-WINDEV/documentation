
## rssInitialize (Function)

***In french: rssInitialise***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Loads a RSS feed in memory. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
MyRSSStream is rssStream
MyRSSStream = rssInitialize("http://blogs.webdev.info/rss.awp?blog=technicalsupport", fromURL)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = rssInitialize(<Source of RSS Stream> [, <Source type>])`
---

**`<Result>: (rssStream variable)`**

[rssStream](../WDLang5/1000017795.md) variable containing the characteristics of the specified RSS feed. If the initialization of the stream fails, the stream is empty and [ErrorInfo](../WDLang1/3013008.md) returns more details about the error.

**`<Source of RSS Stream>: (Character string)`**

Source of the RSS feed used for the initialization. This parameter can correspond to:

- An Ansi character string or a buffer containing the content of the RSS feed. In this case, &lt;Source type&gt; must correspond to the *fromString* constant.

- A character string containing the full path of an XML file. This file must be accessible from the current computer. In this case, &lt;Source type&gt; must correspond to the *fromFile* constant.

- A character string containing the URL address. The content of the RSS feed is retrieved from this URL. In this case, &lt;Source type&gt; must correspond to the *fromURL* constant.




**`<Source type>: (Optional Integer constant)`**

Indicates the source of the RSS feed to load.  


|   |   |
| --- | --- |
| *fromFile* | The RSS feed to load is contained in a file. |
| *fromString* | The RSS feed to load is contained in an Ansi character string or in a buffer. |
| *fromURL* | The RSS feed to load is accessible by a URL. |





An automatic detection is performed if this parameter is not specified. The type of the source is automatically deduced from &lt;Source of RSS Stream&gt;:

- if &lt;Source of RSS Stream&gt; starts with "http://", the *fromURL* constant will be automatically used.

- if &lt;Source of RSS Stream&gt; starts with a drive letter or with a UNC path, the *fromFile* constant will be automatically used.

- otherwise, the *fromString* constant will be automatically used.
