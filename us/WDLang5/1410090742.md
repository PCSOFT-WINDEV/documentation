


## Electronic invoicing: Factur-X in WLanguage
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Overview
<a name="overview_ELTTEXTE000163"></a>
Factur-X is an electronic invoicing standard that offers both fully readable invoices as PDF documents, and XML files containing the invoice data required for processing.
With WINDEV, you can generate Factur-X invoices.

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Factur-X: 5 data profiles
<a name="facturx_5_data_profiles_ELTTEXTE000187"></a>
Factur-X standard offers 5 data profiles, which correspond to 5 levels of accuracy of the data contained in the XML:

- **Minimum**: Minimum data required by Chorus Pro. This profile is equivalent to extracting header and footer data using OCR.

- **Basic WL**: Corresponds to the invoice header and footer data most commonly required or useful for buyers for process automation.

- **Basic**: Equivalent to the Basic WL profile, but adds essential line data. 

- **EN 16931**: Corresponds to all the data specified in the European semantic standard EN16931.

- **Extended**: Equivalent to the EN16931 profile, with additional date. This profile is currently being defined, and has not yet been documented.

## How to create a Factur-X invoice with WINDEV
<a name="how_create_facturx_invoice_with_windev_ELTTEXTE000211"></a>


### Steps to follow
<a name="steps_follow_ELTPARAGRAPHE000033"></a>

To create a Factur-X invoice, follow these steps: 

1. Print the PDF invoice. 

2. Create an XML file according to the Factur-X guidelines. 

3. Attach the XML file to the PDF file. 

4. Validate the resulting document. 





### Step 1: Printing the PDF invoice
<a name="step_1_printing_the_pdf_invoice_ELTPARAGRAPHE000043"></a>

You can use a report, or create an invoice using WLanguage print functions. 

Make sure to generate a PDF/A-3b file.

Use [iParameterPDF](../WDLang5/3046007.md) to generate the PDF file with the required standard. 

Example: 

```wl
// Prepare creation of PDF file
PDFParams is pdfParameter
PDFParams.Protection = iPDFA3b
iParameterPDF(PDFParams)
iDestination(iGenericPDF, gsInvoiceFile)
```



### Step 2: Creating an XML file according to the Factur-X guidelines
<a name="step_2_creating_xml_file_according_the_facturx_guidelines_ELTPARAGRAPHE000059"></a>

For each data profile, Factur-X provides an XSD file describing the XML data to be generated for the invoice. 

You must import this XSD file into your project to simplify the generation of the XML code corresponding to your invoice. 

The folder containing the various XSD files corresponding to each profile can be downloaded here: "[https://fnfe-mpe.org/factur-x/factur-x_en/](https://fnfe-mpe.org/factur-x/factur-x_en/)".

Then, you can simply generate the XML file using the WLanguage functions. 

**Important:** The name of the XML document is set by Factur-X ("factur-x.xml").
<a name="NOTE3_4"></a>


### Step 3: Adding the generated XML file to the PDF
<a name="step_3_adding_the_generated_xml_file_the_pdf_ELTPARAGRAPHE000077"></a>

To add the XML file to the PDF file, simply use [iAddAttachment](../WDLang5/1000024059.md). 

This function allows you to specify: 

- the name of the XML file to be added as an attachment,

- the description of the file to be integrated,

- the Mime type associated with the added file (*mimeTypeXMLText* constant in the case of Factur-X).

- the possible relationship (AFRelationship value expected by Factur-X). You can select the expected format.




Example: 

```wl
iAddAttachment(sXMLFile, "factur-x", mimeTypeXMLText, relationshipAlternative)
iPrintReport(RPT_Invoice)
```


Note: In this version, the configuration of the "AFRelationship" option has been simplified. If you are using a previous version, please see the following FAQ: [How to select Data or Alternative for AFRelationship when generating a PDF for electronic invoicing with Factur-X](https://faq.windev.com/faqread.awp?idfaq=25507). 
<a name="NOTE3_5"></a>


### Step 4. Validation
<a name="step_4_validation_ELTPARAGRAPHE000105"></a>

By validating the invoice, you can make sure it complies with the Factur-X standard. 

To complete the validation process, create an account at: "[https://services.fnfe-mpe.org/register](https://services.fnfe-mpe.org/register)".
You can then provide the PDF file for validation. Any errors, such as missing or invalid elements, will be highlighted.
