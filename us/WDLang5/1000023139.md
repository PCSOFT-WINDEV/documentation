


## xlsLayout (Variable type)

***In french: xlsMiseEnPage***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xlsLayout** type is used to define all the layout characteristics to print a sheet of an XLSX document in a Spreadsheet control. You can define and change the characteristics of this layout using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Current sheet [NoMargins]
xLayout is xlsLayout = PSHEET_SpreadsheetControl.PageLayout
xLayout.LeftMargin = 0
xLayout.RightMargin = 0
PSHEET_SpreadsheetControl.PageLayout = xLayout
```

<a name="PROPS"></a>

## Properties


### Properties specific to xlsLayout variables
<a name="properties_specific_xlslayout_variables_ELTPARAGRAPHE000033"></a>

The following properties can be used to manipulate the layout of an XLSX document:

| Property name | Type used | Effect |
| --- | --- | --- |
| HeaderPrinted | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to print the sheet header.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| HeaderVisible | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to show the sheet header in the Spreadsheet control.<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
| PageHeader | Real | Height of the page header in the printed sheet, expressed in millimeters. |
| PageHeight | Real | Height of the printed page, expressed in millimeters. |
| PageWidth | Real | Width of the printed page, expressed in millimeters. |
| BottomMargin | Double real | Bottom margin of the printed page, expressed in millimeters. |
| RightMargin | Real | Right margin of the printed page, expressed in millimeters. |
| LeftMargin | Real | Left margin of the printed page, expressed in millimeters. |
| TopMargin | Real | Top margin of the printed page, expressed in millimeters. |
| AdjustmentMode | Integer constant | <br><br>- *adjustmentModeNone*: No adjustment is applied. <br><br>- *adjustmentModeColumns*: All columns are adjusted to the width of the control. <br><br>- *adjustmentModeRows*: All rows are adjusted to the height of the control. <br><br>- *adjustmentModeRowsAndColumns*: The spreadsheet is adjusted to the dimensions of the Spreadsheet control. <br><br><br> |
| LandscapeOrientation | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) for landscape orientation,<br><br>- <u><u><u>False</u></u></u> for portrait orientation.<br><br><br> |
| PageFooter | Real | Height of the footer in the printed page, expressed in millimeters. |
| GridlinesPrinted | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to print the gridlines around the cells,<br><br>- <u><u><u>False</u></u></u> to print without gridlines.<br><br><br> |
| GridlinesVisible | Boolean | <br><br>- <u><u><u>True</u></u></u> (default) to show the gridlines around the cells in the Spreadsheet control,<br><br>- <u><u><u>False</u></u></u> otherwise.<br><br><br> |
