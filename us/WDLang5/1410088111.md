


## &lt;htmlNode variable&gt;.InsertBefore (Function)

***In french: &lt;Variable htmlNoeud&gt;.InsèreAvant***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Adds a node before the specified node in an HTML document.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
hDoc is htmlDocument = "
	<html><head/><body><div id="div"><p>Text</p></div></body></html>
"
hNode is htmlNode <- hDoc.FindElementByID("div")
// body: <div id="div"><p>Text</p></div>
hNode1 is htmlNode
hNode1..TagName = "h1"
hNode1..Text = "h1_text"
hNode.InsertBefore(hNode1)
// <html><head><body><h1>text_h1</h1><div id="div"><p>Text</p></div></body></html>
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`<Source node>.InsertBefore(<Node to insert>)`
---

**`<Source node>: (htmlNode variable)`**

Name of the [htmlNode](../WDLang5/1000026081.md) variable that corresponds to the insert reference node.

**`<Node to insert>: (htmlNode variable)`**

Name of the [htmlNode](../WDLang5/1000026081.md) variable that corresponds to the node to be inserted before &lt;Source node&gt;.
