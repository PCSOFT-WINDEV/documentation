
## iDocumentCanceled (Function)

***In french: iImpressionAbandonnée***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Used to find out whether the current print was canceled by the user.

**Note**: If the user aborts a print job in progress, the print functions have no effect until the next call to function [iEndPrinting](../WDLang5/3046053.md).. However, the WLanguage code continues to run.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003046006&name=idocumentcanceled_function">See additional examples</a>

```wl
IF iDocumentCanceled() = True THEN
	Info("The current print was canceled")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = iDocumentCanceled()`
---

**`<Result>: (Boolean)`**

<u><u><u><u>True</u></u></u></u> if the user:

- closed the report viewer before printing was completed,

- clicked the ***Cancel*** button in the current print window.
