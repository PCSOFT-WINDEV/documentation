


## HTMLWrapAllChildren (Function)

***In french: HTMLEncadreTousLesFils***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Wraps all children of the given node in a new node in an HTML document. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
hDoc is htmlDocument = "
<html>
	<head/>
	<body>
		<h1></h1><div id="div">
			<p>Text1</p>
			<p>Texte2</p>
		</div><h3></h3>
	</body>
</html>
"
hNode is htmlNode <- HTMLFindElementByID(hDoc, "div")
hNodeInsert is htmlNode

hNodeInsert..TagName = "h2"
HTMLWrap(hNode, hNodeInsert)
// body: <h1/><h2><div id="div"><p>Texte1</p><p> Texte2</p></div></h2><h3/>
Trace(hDoc)
hNodeInsert..TagName = "span"
HTMLWrapAllChildren(hNode, hNodeInsert)
// body: <h1/><h2><div id="div"><span><p>Texte1</p><p> Texte2</p></span></div></h2><h3/>
Trace(hDoc)
HTMLUnwrapAllChildren(hNode)
// body: <h1/><h2><span><p>Text1</p><p>Text2</p></span></h2><h3/>
Trace(hDoc)
```

<a name="XSYNTAXE"></a>

## Syntax
<a name="SYNTAXE1"></a>

`HTMLWrapAllChildren(<Source node> , <Wrapping node>)`
---

**`<Source node>: (htmlNode variable)`**

Name of the [htmlNode](../WDLang5/1000026081.md) variable that corresponds to the reference node.

**`<Wrapping node>: (htmlNode variable)`**

Name of the [htmlNode](../WDLang5/1000026081.md) variable corresponding to the node that wraps the children of the &lt;Source node&gt;.
