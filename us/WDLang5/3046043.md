
## iReportPrintingStatus (Function)

***In french: iStatusImpressionEtat***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Returns the status of the current print.

This function must be used in the closing code of report.



**Caution**: In Linux, this function requires a specific configuration. For more details, see [Printing in Linux](../Editeurs/9000078.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// End of print
SWITCH iReportPrintingStatus() 
	CASE -2: Trace("Printout abandoned")
	CASE 0: Trace("Printing in progress")
	CASE 1: Trace("Empty state: no data to print")
END
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`<Result> = iReportPrintingStatus()`
---

**`<Result>: (Integer)`**

Status of the current print:

- 1: No data to print

- 0: Printing in progress

- -1: No printing in progress

- -2: Abandon
