


## xlsComment (Variable type)

***In french: xlsCommentaire***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xlsComment** type is used to defined all the advanced characteristics of a comment in a cell of an XLS file or  Spreadsheet control. You can define and change the characteristics of this comment using different WLanguage properties. 

**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example


```wl
// Adds a comment for cell A1 and makes it visible
PSHEET_Spreadsheet["A1"].Comment.Text = "Title" + CR + "my note"
PSHEET_Spreadsheet["A1"].Comment.Visible = True
```



```wl
sFile is string = "file.xlsx"
xlsDoc is xlsDocument
xlsDoc.AddWorksheet("F1")
xlsDoc.Cell[2, 5] = xlsCoordinatesToName(2, 2)
xlsDoc.Comment[2, 5].Text = "Comment"
xlsDoc.Comment[2, 5].Rectangle.X = 10
xlsDoc.Comment[2, 5].Rectangle.Y = 10
xlsDoc.Comment[2, 5].Rectangle.Width = 40
xlsDoc.Comment[2, 5].Rectangle.Height = 20
xlsDoc.Comment[2, 5].Visible = True
xlsDoc.Save(sFile)
xlsDoc.Close()
```

## Properties


### Properties specific to xlsComment variables
<a name="properties_specific_xlscomment_variables_ELTPARAGRAPHE000041"></a>

The following properties can be used to manipulate a comment in a cell:

| Property name | Type used | Effect |
| --- | --- | --- |
| Position | Character string | Cell in which the comment is displayed (e.g., "A3"). <br><br>**This property is read-only.** |
| Rectangle | [Rectangle](../Motscles/1514079.md) variable | Size and position in pixels of the rectangle containing the comment. <br><br>Note: The origin of the rectangle (0.0) is the upper-right corner of the cell.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png) This property is not available. |
| Text | Character string | Comment text. |
| Visible | Boolean | <br><br>- <u><u><u>True</u></u></u> to show the comment, <br><br>- <u><u><u>False</u></u></u> to make the comment invisible. In this case, a red triangle in the upper-right corner of the cell will let the user know that the cell is associated with a comment.<br><br><br> |
