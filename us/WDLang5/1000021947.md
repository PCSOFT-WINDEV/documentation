


## Facebook functions (prefix syntax)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The following functions are used to manage Facebook authentication (prefix syntax).



|   |   |
| --- | --- |
| [&lt;fbSession variable&gt;.GetUserInformation](../WDLang5/1000021945.md) | Gets the Facebook information of the connected user. |
| [&lt;fbSession variable&gt;.Request](../WDLang5/1000021946.md) | Sends an HTTP request to the Facebook Graph API. |
| [&lt;fbSession variable&gt;.Start](../WDLang5/1000021944.md) | Used to authenticate and log in to Faceboook. |
| [&lt;fbSession variable&gt;.Status](../WDLang5/1000021942.md) | Checks the status of a Facebook session. |
| [&lt;fbSession variable&gt;.Stop](../WDLang5/1000021943.md) | Closes the Facebook session opened with [&lt;fbSession variable&gt;.Start](../WDLang5/1000021944.md). |




![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) **Note**: This feature is available up to Android 11. Starting with Android 12, this function causes a fatal error. 
We advise you to: 

- use [SysAndroidVersion](../WDLang1/1000019785.md) to test the Android version used.

- use [AuthIdentify](../WDLang3/1000022219.md) to manage Facebook authentication.
