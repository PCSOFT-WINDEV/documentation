
## xmlNode (Variable type)

***In french: xmlNoeud***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **xmlNode** type is used to handle a node of an XML document. You can define and change the characteristics of this node using different WLanguage properties.

This type of variable is used by: 

- the [xmlDocument](../WDLang5/1000018782.md) type. 

- the [xpathResult](../WDLang5/1000021967.md) type.




**Note**: For more details on the declaration of this type of variable and the use of WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).

## Example


```wl
MyXMLText is string = [
<?xml version="1.0"?>
<!DOCTYPE PLAY SYSTEM "play.dtd">
<PLAY>
<TITLE>The Tragedy of Romeo and Juliet</TITLE>
<ACT><TITLE>ACT I</TITLE>
<PROLOGUE><TITLE>PROLOGUE</TITLE></PROLOGUE>
<SCENE><TITLE>SCENE I.  Verona. A public place.</TITLE></SCENE>
</ACT>
<ACT><TITLE>ACT II</TITLE>

<PROLOGUE><TITLE>PROLOGUE</TITLE></PROLOGUE>
<SCENE><TITLE>SCENE I.  A lane by the wall of Capulet's orchard.</TITLE></SCENE>
</ACT>
<ACT><TITLE>ACT III</TITLE>

<PROLOGUE><TITLE>PROLOGUE</TITLE></PROLOGUE>
<SCENE><TITLE>SCENE I.  A public place.</TITLE></SCENE>
</ACT>
</PLAY>
]

// Load an XML document
RomeoAndJuliet is xmlDocument
RomeoAndJuliet = XMLOpen(MyXMLText, fromString)

// Display the title of acts
Act is xmlNode
FOR EVERY ACT OF RomeoEtJuliette.PLAY on ACT
	Trace(Act.TITLE)
END
```

## Remarks
<a name="NOTE0_1"></a>


### Declaring an xmlNode variable
<a name="declaring_xmlnode_variable_ELTPARAGRAPHE000061"></a>

The **xmlNode** variables can be declared by specifying a template node (node in an XSD file). The structure of this document will be read by WINDEV and the automatic completion will be available for the names of nodes in the code editor.

To declare an xmlNode variable with a sample document:

1. Add the XML or XSD document into the project. 

2. The XML or XSD document appears in the project browser, in the "XML descriptions" branch. You have the ability to see its structure.

3. Declare the variable as follows:
	
	```txt
	<Variable name> is xmlNode, description =  <Path of node in XSD document>
	```





Note: the node declaration syntax can also be obtained by dragging and dropping the node from the project explorer. 

The child nodes of the variable can now be directly accessed by their names. These names are automatically proposed by the automatic completion mechanism of the code editor.
<a name="NOTE0_2"></a>


### Properties specific to xmlNode variables
<a name="properties_specific_xmlnode_variables_ELTPARAGRAPHE000080"></a>

The following properties can be used to define the characteristics of **xmlNode** variables:

| **Name** | **Type used** | **Effect** |
| --- | --- | --- |
| Attribute | Array of [xmlAttribute](../WDLang5/1000018799.md) | Array of XML attributes associated with the node. |
| ChildNode | Array of [xmlNode](../WDLang5/1000018786.md) | Array of child nodes. |
| Exist | Boolean | <br><br>- <u><u><u><u>True</u></u></u></u> if the node exists,<br><br>- <u><u><u><u>False</u></u></u></u> otherwise. <br><br><br><br><br>In read mode, this property is used, for example, to test the existence of a particular child of a document node.<br><br>When writing, assigning this property to <u><u><u><u>Vrai</u></u></u></u> forces the creation of an empty node.<br><br> |
| Name | Unicode string | Node name.<br><br>![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png) Please note: It is not possible to create elements (tags or attributes) with accented characters. |
| Namespace | [xmlNamespace](../WDLang5/1000018803.md) variable | XML namespace of node. |
| NamespaceDeclared | Array of [xmlNamespace](../WDLang5/1000018803.md) | Array of XML namespaces declared by the node. |
| Occurrence | Integer | Number of nodes of same level and with the same name in the XML document.<br>**This property is read-only**. |
| Text | Unicode string | Text found in the node. |
| Type | Integer | Type of node. The possible types are as follows:<br><br>- *XMLBalise* (default): Simple XML node that can contain children. <br>	For example: <br>	<br><pre><code><NODE> <CHILDNODE> </CHILDNODE> </NODE></code></pre><br><br><br>- *XMLText* XML node containing text. <br>	For example: <br>	<br><pre><code><NODE> Text </NODE></code></pre><br><br><br>- *XMLCDATA* XML node containing data to be ignored by the XML parser.<br>	For example: <br>	<br><pre><code><NODE><![CDATA[This data is not <br>		processed by the XML analyzer]]> <br>	</NODE></code></pre><br><br><br><br><br><br>**Remarks**: <br><br>- The type can be assigned once only. Then, the property is read-only.<br><br>- If a value is assigned to the **Name** property, the node will automatically be of type *XMLTag*.<br><br>- If a value is assigned to the **Text** property, the node will automatically be of type *XMLText*.<br><br>- When a value is assigned to the **Text** property, all the child nodes of type *XMLText* and *XMLCData* are deleted.<br><br><br> |
| XMLSource | Unicode string | Fragment of XML code corresponding to the node. This property also returns the XML code of the child nodes.<br>**This property is read-only**. |
