


## gglCoordinate (Variable type)

***In french: gglCoordonnée***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
The **gglCoordinate** type is used to describe and handle a geographical point on a map. You can define and change the characteristics of this type of variable using different WLanguage properties.

This type of variable is used by:

- the [gglMapParameter](../WDLang5/1000017505.md) type.

- the [gglPath](../WDLang5/1000017433.md) type.




**Notes** For more details on declaring this type of variable and using WLanguage properties, see [Declaring a variable](../Motscles/1514032.md).


<a name="PROPS"></a>

## Properties


### Management properties
<a name="management_properties_ELTPARAGRAPHE000045"></a>

The following properties can be used to define the characteristics of **gglCoordinate** variables:

| Property name | Type used | Effect |
| --- | --- | --- |
| Latitude | Real | Latitude of the point. |
| Longitude | Real | Longitude of the point. |
