
## iEllipse (Function)

***In french: iEllipse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Prints an ellipse (in a rectangle).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Example
<a class="notetitle" target="_blank" href="$DOC$=1000003046009&name=iellipse_function">See additional examples</a>

```wl
// Print an ellipse
iEllipse(50, 50, 150, 130, 1, 100, RGB(0,0,0), iDotted, iCrossed)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntax

`iEllipse(<X1> , <Y1> , <X2> , <Y2> [, <Thickness> [, <Lightness> [, <Color> [, <Line> [, <Brush>]]]]])`
---

**`<X1>: (Real)`**

Horizontal coordinate of the upper-left corner of the rectangle where the ellipse will be drawn (in millimeters). 
Value between 0 and the page width (returned by [iPageWidth](../WDLang5/3046036.md)).

**`<Y1>: (Real)`**

Vertical coordinate of the upper-left corner of the rectangle where the ellipse will be drawn (in millimeters). 
Value between 0 and the page height (returned by [iPageHeight](../WDLang5/3046052.md)).

**`<X2>: (Real)`**

Horizontal coordinate of the lower-right corner of the rectangle where the ellipse will be drawn (in millimeters). 
Value between 0 and the page width (returned by [iPageWidth](../WDLang5/3046036.md)).

**`<Y2>: (Real)`**

Vertical coordinate of the lower-right corner of the rectangle where the ellipse will be drawn (in millimeters).
Value between 0 and the page height (returned by [iPageHeight](../WDLang5/3046052.md)).

**`<Thickness>: (Optional real)`**

Thickness of the ellipse line (in picas). Default value = 1 (one Pica = 0.353 mm).
**Attention** Depending on the value of this parameter, the thickness is obtained by adding several lines side by side from outside to inside.
![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter must correspond to an integer value. Otherwise, the thickness will be rounded to the nearest integer value.

**`<Lightness>: (Optional integer (included between 1 and 200))`**

Rate for the line color and for the background color. If this parameter is:

- Equal to 0 (default): no filling.

- Equal to 100: full filling with the specified color.

- Less than 100: the closer this parameter is to 0, the lighter the color.

- Greater than 100: the closer this parameter gets to 200 the darker the color is.




**`<Color>: (Optional integer)`**

Color used for the background and for the border of the ellipse. If this parameter is not specified, the color used is black. 
This color can correspond to:

- an RGB color (returned by [RGB](../WDLang1/3029012.md)),

- an HSL color (returned by [HSL](../WDLang1/3029057.md)),

- [a WLanguage preset color](../WDLang5/3010002.md).




**`<Line>: (Optional integer constant)`**

Type of line.



|   |   |
| --- | --- |
| *iContinuous*<br>(default value) | Solid line |
| *iDashed* | Dashed line (-----) |
| *iDotAndDash* | Dot-and-dash line (-.-.) |
| *iDotted* | Dotted line (....) |



**`<Brush>: (Optional integer constant)`**

Pattern used to fill the border.



|   |   |
| --- | --- |
| *iCrossed* | Cross hatch brush |
| *iDiagonalCrossed* | Diagonal cross hatch brush |
| *iDownwardDiagonal* | Downward diagonal hatch brush |
| *iHorizontal* | Horizontal hatch brush |
| *iSolid*<br>(default value) | Solid brush |
| *iUpwardDiagonal* | Upward diagonal hatch brush |
| *iVertical* | Vertical hatch brush |

![Android](https://doc.pcsoft.fr/ext/images/us/ANDROID.png)![Android Widget ](https://doc.pcsoft.fr/ext/images/us/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/us/JAVA.png) This parameter is ignored.

## Remarks


### Lightness of black color
<a name="lightness_black_color_ELTPARAGRAPHE000162"></a>

For the black color, the rate corresponds to a rate of gray whose values are included between 1 (white) and 100 (solid black). In this case, the values greater than 100 will be processed like the value 100.
<a name="NOTE0_2"></a>


### Miscellaneous
<a name="miscellaneous_ELTPARAGRAPHE000169"></a>

- The cursor position is not modified when the outline is drawn.

- The dotted type (*iDotted*) or the mixed type (*iDotAndDash*) combined with a thick border may produce unpleasant effects.
