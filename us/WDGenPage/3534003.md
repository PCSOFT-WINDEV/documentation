## Syntax
<a name="syntax_ELTTEXTE000132"></a>
WDGenPage run in command line is used to generate one or more semi-dynamic pages without starting WEBDEV or WDGenPage.

Several syntaxes can be used to start WDGenPage in command line:

- WDGenPage.EXE

- WDGenPage.EXE /APP=&lt;ProjectName&gt; /USER=&lt;UserName&gt; [/NOINTERF]

- WDGenPage.EXE /APP=&lt;ProjectName&gt; /USER=&lt;UserName&gt; /PAGE=&lt;PageName&gt; [/NOINTERF]




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Details
<a name="details_ELTTEXTE000156"></a>
Details of parameters:

| Parameter | Meaning |
| --- | --- |
| /APP=&lt;ProjectName&gt; | If this parameter is specified, the semi-dynamic pages of the specified project will be generated.<br>This project or the corresponding site must necessarily be installed on the current computer.<br>If this parameter is not specified, a window will be displayed, allowing you to select the project to handle.<br>Only the projects installed on the current computer are proposed. |
| /USER=&lt;UserName&gt; | Name of the WEBDEV user. This name was specified when starting WEBDEV.<br>This parameter is ignored on the deployment computer. |
| /PAGE=&lt;PageName&gt; | If this parameter is specified:<br><br>- and if "/NOINTERF" is not specified, the specified semi-dynamic page will be automatically proposed for the generation.<br>	This page must be a semi-dynamic page.<br><br>- and if "/NOINTERF" is also specified, the specified semi-dynamic page is automatically generated.<br><br><br>If this parameter is not specified:<br><br>- and if "/NOINTERF" is not specified, a window will be displayed, allowing you to select the semi-dynamic pages to generate.<br>	Only the semi-dynamic pages of the project are proposed.<br><br>- and if "/NOINTERF" is specified, all the semi-dynamic pages of the project will be automatically generated.<br><br><br> |
| /NOINTERF | If this parameter is specified, only the progress bar indicating the progress of the generation will be displayed. |

**Example**: The following row of Command generates the "PAGE_MyPage" page of the "MyProject" project.. Only the progress bar indicating the progress of the generation will be displayed: 


```wl
LanceAppli("C:\MesOutils\WDGenPage.EXE " + ... 
				"/APP=MonProjet /USER=STEPHANE /PAGE=PAGE_MaPage /NOINTERF")
```
