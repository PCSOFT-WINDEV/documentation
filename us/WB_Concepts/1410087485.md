
## 4. Publishing a dynamic WEBDEV website

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Your dynamic WEBDEV website in Session or AWP mode can be accessed as soon as it published. Publishing a WEBDEV website means you make it available online.

There are several methods to publish a WEBDEV website:

- using HTTP to install the website. In this case, the website is automatically published. A checkbox allows you to deploy and publish the website at a later date<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=P7_D%E9ploiement%20-%20HC%20N%B0008.gif&type=thumb)


- via the remote administrator.

- in the WEBDEV administrator installed on the deployment computer ("Enabled" option, in the "Sites" tab).<br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=P7_Administrateur%20WB%20-%20HC%20N%B0002%202.gif&type=thumb)
