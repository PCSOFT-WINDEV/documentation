
## 6. WEBDEV Account Manager

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
WEBDEV Account Manager allows you easily host websites developed with WEBDEV. This tool is mainly intended for webmasters and hosting providers.

The Control Center manages the WEBDEV and the web server accounts, as well as and the permissions for the operating system.

A default option allows you to easily install a server with a single click.

The configuration of the following elements is centralized:

- Windows accounts,

- Groups of FTP users,

- Groups of WEBDEV clients,

- Home Directory,

- FTP alias,

- WEBDEV accounts,

- Data directories,

- Virtual websites, etc.




WEBDEV Account Manager runs on a Windows environment with the IIS web server (Internet Information Services, all versions from 5 upwards).
