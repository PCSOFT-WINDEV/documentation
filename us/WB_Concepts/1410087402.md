<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Most sites rely on many external factors: Websites, HFSQL server, network availability, etc. WEBDEV includes a monitoring robot to help you manage incidents.

The monitoring robot, which is composed of three executables running on different computers, is used to run different tests: Internet tests, network tests, etc.

If a problem occurs during a test, the monitoring robot sends a message using one of the following methods:

- Message sent via PC SOFT's messaging tool (WDBAL).

- Email

- Via a third-party program.Additionally, a sound alert can be set on the monitor.
