
## 6. Editing a page: Zoning mode

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
The zoning mode is an easy and powerful page editing tool. Simply split the page into "zones" using the "Pencil" tool. These zones are automatically configured and allow you to define the architecture of the page: header, footer, etc.

You can easily manipulate these zones in the editor. For example, when the header area is enlarged, it automatically pushes the body of the page. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=P2_Edition%20d'une%20page%20en%20mode%20zoning%20-%20HC%20N%B0001.gif&type=thumb)


When the page is edited, the position and anchors of the controls in the different areas do not change. <br>![](https://doc.pcsoft.fr/en-US/images/image.awp?langid=3&name=P2_Edition%20d'une%20page%20en%20mode%20zoning%20-%20HC%20N%B0002.gif&type=thumb)


You can associate HTML 5 elements with each zone. This allows you to optimize the page for SEO purposes.
