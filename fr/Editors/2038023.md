


## Administrateur du GDS : Outils disponibles
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000407"></a>
Via le volet "Outils", l'administrateur du GDS (Gestionnaire de sources) permet de : 

- configurer certaines [options du GDS](#NOTE2_1). 

- [utiliser différents outils permettant d'optimiser la base de sources du GDS](#NOTE3_1). 




Remarques : 

- Quelques options sont accessibles uniquement à des utilisateurs de type "Administrateur". L'onglet "Administration" de l'administrateur du GDS regroupe les options disponibles uniquement pour les administrateurs. Pour plus de détails, consultez [Options spécifiques d'administration](../Editeurs/2038034.md).  

- L'administrateur du GDS permet également de gérer les éléments de la base de sources, etc. Pour plus de détails, consultez [Présentation de l'administrateur du GDS](../Editeurs/2038008.md).

## Options du GDS
<a name="options_gds_ELTTEXTE000431"></a>
Pour configurer les options du GDS, sous le volet "Outils", dans le groupe "Option", cliquez sur "Options".
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0001.gif)

<a name="NOTE2_2"></a>


### Options générales
<a name="options_generales_ELTPARAGRAPHE000056"></a>L'onglet "Général" des options du GDS permet de définir un modèle de commentaire, qui sera proposé lors de l'extration / réintégration d'un élément dans la base de sources. Dans ce modèle de commentaire, il est possible d'utiliser des macros pour utiliser des termes spécifiques à l'action réalisée. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin_options%20-%20HC%20N%B0001.gif)


Il est également possible d'indiquer si la messagerie intégrée (WDBal) doit être utilisée. Dans ce cas, des messages pourront être envoyés aux autres utilisateurs (demande de déblocage, informations de réintégration, etc.).

Si nécessaire, il est également possible de demander à envoyer un message aux utilisateurs du GDS lors de chaque réintégration d'éléments dans le GDS.
<a name="NOTE2_4"></a>


### Options concernant les branches
<a name="options_concernant_les_branches_ELTPARAGRAPHE000068"></a>L'onglet "Branches" permet de paramétrer les chemins créés par défaut lors de l'utilisation des branches.

Cet onglet permet d'indiquer les répertoires distants et locaux utilisés par défaut lors de la création d'une branche. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin_options%20-%20HC%20N%B0002.gif)


Pour plus de détails sur la gestion des branches, consultez [Gestion des branches](../Editeurs/2038016.md).
<a name="NOTE2_5"></a>


### Options avancées
<a name="options_avancees_ELTPARAGRAPHE000084"></a>L'onglet "Avancé" permet de configurer les performances de la base de sources dans le cas d'une base de sources au format HFSQL Client/Serveur utilisée par ADSL.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin_options%20-%20HC%20N%B0003.gif)


L'option "Limiter la taille des paquets pour l'ADSL" permet dans certains cas de gérer les spécificités de certains routeurs.

**Attention** : Si cette option est mal utilisée, elle peut ralentir le GDS.

Il est également possible d'interdire aux utilisateurs d'utiliser l'option permettant de réparer ou réindexer la base de sources. L'option disponible dans le volet "Outils" sera grisée ou non. 

Attention : Cette option n'est disponible que pour les administrateurs.

## Recherche dans le GDS
<a name="recherche_dans_gds_ELTTEXTE000473"></a>
L'administrateur du GDS propose plusieurs modes de recherche dans les éléments présents dans la base de sources du GDS. 

- **Recherche par nom** (sous le volet "Outils", dans le groupe "Recherche", cliquez "Par nom") : Cette option permet de rechercher simplement un élément dans la base de sources du GDS. Il suffit d'indiquer le nom de l'élément recherché.

- **Recherche par extraction** (sous le volet "Outils", dans le groupe "Recherche", cliquez "Par extraction") : Cette option permet de rechercher les extractions selon l'utilisateur (utilisateur en cours, utilisateur spécifique, tous les utilisateurs) et le type d'extraction (pour test, exclusive, ...). Il est alors possible de réintégrer un élément ou encore d'annuler une extraction.

- **Recherche par tâche ou incident** : Cette option permet de rechercher le ou les éléments correspondant à la réalisation d'une tâche ou d'un incident. Il est possible de voir les modifications effectuées.

- **Recherche dans l'historique** : Cette option permet de réaliser une recherche dans l'historique des actions réalisées dans le GDS. Il est ainsi possible d'obtenir tous les commentaires saisis entre deux dates et de les exporter dans un fichier. Pour plus de détails, consultez [Recherche dans l'historique du GDS](../Editeurs/2038028.md).







### Recherche par nom
<a name="recherche_par_nom_ELTPARAGRAPHE000141"></a>La recherche par nom permet de rechercher simplement un élément dans la base de sources du GDS. Il suffit d'indiquer le nom de l'élément recherché.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0002.gif)





### Recherche par extraction
<a name="recherche_par_extraction_ELTPARAGRAPHE000149"></a>La recherche par extraction permet de rechercher les extractions en cours. Il est possible de filtrer : 

- par utilisateur : utilisateur en cours, utilisateur spécifique ou tous les utilisateurs.

- par type d'extraction : pour test, exclusive, etc. 



<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0003.gif)


Pour chaque élément listé, il est possible de réintégrer un élément ou encore d'annuler une extraction.




### Recherche par tâche ou incident
<a name="recherche_par_tache_incident_ELTPARAGRAPHE000162"></a>La recherche par tâche ou incident permet de rechercher le ou les éléments correspondant à la réalisation d'une tâche ou d'un incident. Il est possible de voir les modifications effectuées.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0004.gif)


Pour chaque tâche, il est possible de voir les diverses modifications effectuées et sur quel fichier. 




### Recherche "Mes Projets"
<a name="recherche_mes_projets_ELTPARAGRAPHE000172"></a>Cette recherche permet de lister les projets ayant un répertoire local sur le poste en cours. 

Pour effectuer cette recherche, indiquez si nécessaire le login voulu et cliquez sur le bouton "Rechercher". 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0005.gif)


Pour chaque projet trouvé, le répertoire distant et le répertoire local sont affichés.

Il est possible de supprimer l'association entre le répertoire distant et le répertoire local (bouton "Supprimer l'association"). Cette option est intéressante par exemple lorsqu'un projet du GDS a été ouvert puis supprimé du poste local : en supprimant l'association, l'utilisateur ne recevra plus les messages automatiques du GDS concernant ce projet.




### Recherche "Recherche dans l'historique"
<a name="recherche_recherche_dans_historique_ELTPARAGRAPHE000186"></a>Cette recherche permet de réaliser une recherche dans l'historique des actions réalisées dans le GDS. Il est ainsi possible d'obtenir tous les commentaires saisis entre deux dates et de les exporter dans un fichier. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0006.gif)


Pour plus de détails, consultez [Recherche dans l'historique du GDS](../Editeurs/2038028.md).

## Maintenance du GDS
<a name="maintenance_gds_ELTTEXTE000527"></a>
L'administrateur du GDS propose différentes options de maintenance. Ces options permettent à tout moment d'optimiser et de gérer la base de sources du GDS.
<a name="NOTE3_2"></a>


### Migrer la base de sources dans le format le plus récent
<a name="migrer_base_sources_dans_format_plus_recent_ELTPARAGRAPHE000208"></a>Pour migrer la base de sources du GDS dans un format plus récent, sous le volet "Outils", dans le groupe "Maintenance", cliquez sur "Migrer au format le plus récent ". Ce format permet d'optimiser les accès à la base de données.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0007.gif)


**Remarque** : Pour utiliser cette option, la base de sources du GDS ne doit pas être installée directement sur un nom de partage.

Par exemple, si les fichiers sont installés sur "\\\\PosteServeur\\GDS" où "GDS" est le nom du répertoire partagé, l'option ne fonctionnera pas. Il est nécessaire que les fichiers soient installés dans un répertoire de type "\\\\PosteServeur\\GDS\\BaseGDS"

Si ce n'est pas le cas, vous pouvez déplacer manuellement les fichiers de données (tous les utilisateurs doivent être déconnectés). A la prochaine ouverture des projets, il suffira de préciser le nouveau répertoire de la base de sources du GDS.

Attention : N'hésitez pas à consulter la page d'aide [Evolutions du format des fichiers du GDS](../Editeurs/2038018.md). 
<a name="NOTE3_3"></a>


### Passer la base de sources en Client/Serveur
<a name="passer_base_sources_clientserveur_ELTPARAGRAPHE000239"></a>Pour lancer l'assistant de passage de la base de sources en mode HFSQL Client/Serveur, sous le volet "Outils", dans le groupe "Maintenance", cliquez sur "Passer en Client/Serveur".

**Attention** : Cette opération peut être effectuée uniquement si un moteur HFSQL Client/Serveur est installé sur le poste Serveur où la base de sources du GDS doit être installée.

Il est nécessaire d'indiquer :

- Le nom du serveur. 

- Le nom de la base de données et son port.

- Le nom et le mot de passe d'un administrateur de la base de données HFSQL.




Selon la taille de la base de sources du GDS, la migration de la base de sources peut être relativement longue.

A la fin de cette opération, le GDS propose de créer automatiquement le compte utilisateur correspondant à la personne connectée (si celui-ci n'existe pas).

A la prochaine ouverture du projet, il sera nécessaire d'indiquer les nouveaux paramètres de connexion au GDS.

**Remarque** : La base de sources du GDS en mode "Classic" n'est pas supprimée. Après l'opération de migration au format HFSQL Client/Serveur, il est nécessaire de prévenir tous les utilisateurs afin qu'ils changent leurs paramètres de connexion à la base de sources du GDS.
<a name="NOTE3_4"></a>


### Réindexer et réparer
<a name="reindexer_reparer_ELTPARAGRAPHE000274"></a>Sous le volet "Outils", dans le groupe "Maintenance", cliquez sur "Réindexer et réparer". Les différentes options proposées sont les suivantes : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0008.gif)


- **Optimiser les index** : Permet de réindexer la base de sources du GDS (qu'elle soit en mode HFSQL Classic ou en mode HFSQL Client/Serveur).

- **Annuler les transactions bloquées** : Permet d'annuler les transactions bloquées sur la base de sources du GDS.

- **Optimisation des index et de la taille de la base de sources** : Permet de compacter la base de sources après la réindexation. 

- **Analyser et réparer** :  Permet d'analyser et réparer si nécessaire la base de sources du GDS.



<a name="NOTE3_5"></a>


### Réparer un répertoire
<a name="reparer_repertoire_ELTPARAGRAPHE000303"></a>Dans certains cas, la réparation d'un répertoire permet de régler certains problèmes d'accès aux données d'un répertoire du GDS. Cette option permet de réparer le répertoire sans bloquer la base de sources du GDS pendant la réparation. 

Pour réparer un répertoire : 

- Sélectionnez le répertoire à réparer dans la liste des répertoires de la base de sources du GDS. 

- Sous le volet "Outils", dans le groupe "Maintenance", cliquez sur "Réparer un répertoire". Cette option permet de réparer la base de sources du GDS pour ce répertoire.




Remarque : Si nécessaire, le GDS propose automatiquement de réparer uniquement le répertoire (au lieu de réparer toute la base de sources du GDS).

## Options diverses
<a name="options_diverses_ELTTEXTE000575"></a>


### Renommage ou changement de machine
<a name="renommage_changement_machine_ELTPARAGRAPHE000331"></a>L'option "Renommage ou changement de machine" permet de mettre à jour dans le GDS le nom du poste utilisé. Pour plus de détails, consultez [Renommage et changement de machine](../Editeurs/2038020.md).
<a name="NOTE6_3"></a>


### Statistiques
<a name="statistiques_ELTPARAGRAPHE000341"></a>L'option "Statistiques" permet d'obtenir diverses statistiques sur la base de sources du GDS. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0010.gif)



<a name="NOTE6_4"></a>


### Log de la session
<a name="log_session_ELTPARAGRAPHE000353"></a>L'option "Log de la session" permet d'obtenir la liste des opérations effectuées dans le GDS depuis la connexion de l'utilisateur au GDS. Il est possible de voir les informations, les avertissements comme les erreurs. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Admin%20-%20HC%20N%B0011.gif)


Vous pouvez extraire ces informations sur demande du Support Technique Gratuit pour une analyse des éventuels problèmes rencontrés sur une base de données du GDS.
