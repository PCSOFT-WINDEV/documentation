## Manipulation d'une analyse (MLD)
<a name="manipulation_une_analyse_mld_ELTTEXTE000251"></a>


### Dupliquer/Copier une analyse
<a name="dupliquercopier_une_analyse_ELTPARAGRAPHE000039"></a>La duplication d'une analyse permet de disposer de deux analyses identiques de nom différent.

Pour dupliquer/copier une analyse :

1. Ouvrez l'analyse à dupliquer sous l'éditeur d'analyses.

2. Sous le volet "Accueil", dans le groupe "Général", déroulez "Enregistrer" et sélectionnez "Enregistrer sous". La description de l'analyse s'affiche.

3. Modifiez le nom et le répertoire de l'analyse.

4. Validez les modifications :

	- L'ensemble des fichiers décrivant l'analyse dupliquée est automatiquement créé dans le répertoire spécifié.

	- L'analyse dupliquée est automatiquement associée au projet en cours.







**Remarque** : Les sous-répertoires de sauvegarde de l'analyse d'origine ne sont pas copiés. La nouvelle analyse ne contient aucune sauvegarde.
<a name="NOTE2_2"></a>


### Supprimer une analyse
<a name="supprimer_une_analyse_ELTPARAGRAPHE000070"></a>Pour supprimer une analyse :

1. Ouvrez l'explorateur de Windows.

2. Supprimez le répertoire complet de l'analyse (répertoire &lt;Nom du projet&gt;.ANA).




**Remarque** : Si un projet utilisait cette analyse, il sera nécessaire d'associer le projet à une autre analyse lors de l'ouverture de ce projet.
<a name="NOTE2_3"></a>


### Renommer une analyse
<a name="renommer_une_analyse_ELTPARAGRAPHE000082"></a>Pour renommer une analyse :

1. Ouvrez l'analyse à renommer sous l'éditeur d'analyses.

2. Sous le volet "Accueil", dans le groupe "Général", déroulez "Enregistrer" et sélectionnez "Enregistrer sous". La description de l'analyse s'affiche.

3. Saisissez le nouveau nom de l'analyse.

4. Validez la modification.

5. L'ensemble des fichiers décrivant l'analyse renommée est automatiquement créé dans le répertoire spécifié.

6. L'analyse renommée n'est pas automatiquement associée au projet en cours. Associez si nécessaire l'analyse renommée au projet en cours. Pour plus de détails, consultez [Associer une analyse à un projet existant](#NOTE2_4).

7. Supprimez si nécessaire sous l'explorateur de Windows le répertoire de l'analyse d'origine.



<a name="NOTE2_4"></a>


### Associer une analyse à un projet existant
<a name="associer_une_analyse_projet_existant_ELTPARAGRAPHE000112"></a>Pour associer une analyse à un projet existant :

1. Ouvrez le projet à associer.

2. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description". La description du projet s'ouvre.

3. Dans l'onglet "Analyse", cliquez sur "Ajouter une analyse" et sélectionnez le chemin du fichier WDD correspondant à l'analyse à associer.




**Remarques** : 

- Il est possible d'associer plusieurs analyses à un même projet. Pour plus de détails, consultez [Projet multi-analyse](../Editeurs/1410087296.md). 

- Suppression d'une analyse et remplacement par une nouvelle analyse : Si des données de l'analyse d'origine sont manipulées dans le projet, l'association d'une nouvelle analyse peut entraîner des erreurs (erreurs de doublons, erreurs d'affichage, etc.).



<a name="NOTE2_5"></a>


### Facteur de zoom
<a name="facteur_zoom_ELTPARAGRAPHE000145"></a>Il est possible de spécifier un facteur de zoom sous l'éditeur d'analyses pour réduire ou agrandir l'affichage du graphe de l'analyse en cours.

Pour spécifier un facteur de zoom :

- **1ère méthode** :

	- Soit sous le volet "Affichage", dans le groupe "Aide à l'édition", choisissez le facteur de zoom à utiliser.

	- Soit saisissez directement le facteur de zoom dans la barre de message de l'éditeur (en bas à droite).




<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=ZoomBarreMessage.gif)


- **2ème méthode** :

	- Appuyez sur la touche Ctrl.

	- Modifiez le facteur de zoom avec la roulette de la souris tout en maintenant la touche Ctrl enfoncée.






<a name="NOTE2_6"></a>


### Déplacer l'affichage d'une analyse
<a name="deplacer_affichage_une_analyse_ELTPARAGRAPHE000174"></a>Pour déplacer l'affichage d'une analyse :

1. Affichez l'analyse sous l'éditeur d'analyses.

2. Appuyez sur la touche Alt.

3. Modifiez la position du graphe de l'analyse en maintenant à la fois le bouton gauche de la souris et la touche Alt enfoncés.
