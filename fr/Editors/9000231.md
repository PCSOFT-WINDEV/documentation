
## RAD Mobile : Créez des fenêtres modernes
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000111"></a>
Le RAD Mobile (Rapid Application Development) permet de générer automatiquement des UI modernes et du code fonctionnel à partir d'une base de données.

Avec WINDEV Mobile 2025, le nouveau RAD Mobile permet de créer rapidement des applications Android et iOS en générant des UI soignées et adaptées à tous les écrans.**Pourquoi utiliser le nouveau RAD Mobile ?**

- Gain de temps : génère automatiquement le squelette de l'application.

- Interfaces modernes : UI soignée et optimisée pour l'expérience utilisateur.

- Compatible Android et iOS : génère du code pour les deux plateformes.

- Code 100% modifiable : tout est en WLangage et peut être ajusté selon les besoins.

## Comment le faire ?
<a name="comment_faire_ELTTEXTE000144"></a>
Pour utiliser toutes les fonctionnalités du RAD Mobile dernière génération : 

1. Créez une nouvelle fenêtre : 

2. Cliquez sur ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=ico_nouveau.gif) parmi les boutons d'accès rapide : 

	- La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Fenêtre" puis sur "Fenêtre".

	- L'assistant de création d'une fenêtre se lance et propose plusieurs types de fenêtres, dont 5 fenêtres RAD : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=RAD_Mobile%20-%20HC%20N%B0001.gif)


		- Affichage (fiche détaillée)

- Galerie (liste visuelle)

- Liste (affichage sous forme de liste)

- Saisie (formulaire d'ajout / de modification)

- Sélection (choix dans une liste).

3. Cliquez sur le modèle voulu. L'assistant se déroule très rapidement en quelques étapes : choix de la source de données (fichiers de données, requêtes, vues, ...), titre de la fenêtre.

4. Les différentes fenêtres nécessaires sont créées sous l'éditeur. Ces fenêtres sont fonctionnelles, prêtes à êtres utilisées ou modifiées. 




**Remarques** : 

- **Création des fenêtres associées** : 
	Le RAD Mobile ne se contente pas de créer une seule fenêtre. 
	Par exemple, lorsque une fenêtre "liste" est générée, le RAD ajoute automatiquement les fenêtres complémentaires :<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=RAD_Mobile%20-%20HC%20N%B0002.gif&type=thumb)


	- Fiche détail pour afficher les informations d'un élément,<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=RAD_Mobile%20-%20HC%20N%B0004.gif&type=thumb)

- **Code personnalisable**
	Les fenêtres générées par le RAD Mobile sont entièrement personnalisables, aussi bien visuellement (champs) qu'au niveau du code.
