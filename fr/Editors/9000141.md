


## Coloration du code WLangage
			



<a name="NOTE1_VMaj22"></a>
<a name="NOTE1_1_VMaj22"></a>


## Présentation
<a name="presentation_ELTTEXTE000186"></a>
L'environnement de WINDEV, WEBDEV et WINDEV Mobile propose un thème clair et un thème foncé. Ces thèmes sont également disponibles dans l'éditeur de code. Vous avez également la possibilité de créer et configurer votre propre thème ou encore d'importer un thème existant. 

Remarque : Copie de code WLangage depuis l'éditeur vers un outil tiers :

- Le copier / coller d'un code utilise désormais toujours les couleurs du thème clair. Si vous copiez un code en thème sombre, finis les bandeaux noirs.

- Le copier / coller d'un code utilise désormais le presse-papiers au format texte et HTML. Si le code est collé dans un outil gérant le texte HTML (par exemple Thunderbird ou Outlook), il sera directement collé au format HTML. Le thème utilisé pour la coloration du code est le thème clair.

## Comment le faire ?
<a name="comment_faire_ELTTEXTE000217"></a>


### Fenêtre de configuration des thèmes de l'éditeur de code
<a name="fenetre_configuration_des_themes_editeur_code_ELTPARAGRAPHE000029"></a>Pour afficher la fenêtre de configuration des thèmes de l'éditeur de code : 

1. Affichez les options d'édition de l'éditeur de code : sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code".

2. Dans l'onglet "Styles" les différents thèmes de l'éditeur de code sont listés : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Coloration_Code_22%20-%20HC%20N%B0001.gif&type=thumb)


	- Clair (Version 21 et antérieures) : thème de l'éditeur de code correspondant à la version 21. 

- Clair : thème clair de l'éditeur de code (sur fond blanc).

- Foncé : thème foncé de l'éditeur de code (sur fond noir).

- Gris : thème gris de l'éditeur de code (sur fond gris).




Depuis cette fenêtre, vous pouvez : 

- utiliser un des thèmes proposés. 

- modifier un des thèmes proposés. 
	Remarque : Les thèmes proposés par défaut ne peuvent pas être modifiés directement. Il est nécessaire de les dupliquer pour les modifier. 

- supprimer un des thèmes proposés, 

- importer un thème. 





### Modifier le thème utilisé
<a name="modifier_theme_utilise_ELTPARAGRAPHE000066"></a>Pour utiliser un thème dans l'éditeur de code : 

1. Affichez la fenêtre de configuration des thèmes. 

2. Double-cliquez sur le nom du thème dans la fenêtre de configuration des thèmes : le libellé "(Actif)" est alors affiché sur la ligne du thème.





### Modifier un des thèmes standard
<a name="modifier_des_themes_standard_ELTPARAGRAPHE000074"></a>Pour modifier un des thèmes proposés en standard : 

1. Affichez la fenêtre de configuration des thèmes. 

2. Sélectionnez le thème voulu et cliquez sur "Dupliquer". 

3. Donnez un nom au nouveau thème et validez. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Coloration_Code_22%20-%20HC%20N%B0002.gif)


4. Le nouveau thème apparaît dans la liste des thèmes disponible. Pour modifier ses caractéristiques, sélectionnez le thème et cliquez sur "Modifier". 

5. La fenêtre de paramétrage du thème est affichée. La liste de tous les éléments configurables est affichée. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Coloration_Code_22%20-%20HC%20N%B0004.gif&type=thumb)
Pour chaque élément, il est possible de paramétrer (selon le type de l'élément): 

	- La couleur de fond. 

	- La couleur de la police. 

	- La police. 

	- La taille de la police. 

	- Les caractéristiques de la polices (gras, italique, souligné, barré). 




6. Pour quitter le mode modification, cliquez sur ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Coloration_Code_22%20-%20HC%20N%B0005%201.gif). L'éditeur  propose alors de sauvegarder ou d'annuler les modifications. 




Les couleurs spécifiées pour certains éléments du thème (nombre, chaînes, etc.) peuvent être utilisés pour personnaliser la couleur des variables avec l'attribut &lt;couleur&gt;. Pour plus de détails, consultez [Déclaration et utilisation d'une variable](../Motscles/1514032.md).


### Supprimer un thème
<a name="supprimer_theme_ELTPARAGRAPHE000104"></a>Pour supprimer un thème : 

1. Affichez la fenêtre de configuration des thèmes. 

2. Sélectionnez un thème non actif. 

3. Cliquez sur le bouton "Supprimer" et validez. 


Attention : Les thèmes proposés par défaut ne peuvent pas être supprimés. 


### Importer un thème
<a name="importer_theme_ELTPARAGRAPHE000115"></a>Pour importer un thème : 

1. Affichez la fenêtre de configuration des thèmes. 

2. Cliquez sur le bouton "Importer". 

3. Sélectionnez le fichier ".sco" correspondant au thème à importer et validez. 


Remarque : Pour exporter un thème : 

1. Affichez l'écran de modification du thème. 

2. Cliquez sur le bouton ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Coloration_Code_22%20-%20HC%20N%B0005%202.gif) et sélectionnez l'option "Exporter un thème". 

3. Indiquez le nom du fichier ".sco" correspondant au thème et validez. 





### Cas particulier : Coloration du code hors configuration
<a name="cas_particulier_coloration_code_hors_configuration_ELTPARAGRAPHE000132"></a>Lorsqu'un élément hors configuration est ouvert sous l'éditeur, le code est coloré, mais affiché sur une couleur de fond spécifique (par défaut fond gris si vous utilisez le thème clair).
