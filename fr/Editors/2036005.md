
## Services IA : Comment trouver la clé ? 
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000075"></a>
Plusieurs fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile utilisent une clé d'API : 

- le compagnon IA de l'environnement,

- [la génération de commentaires de code](../Editeurs/9000219.md),

- [la génération des commentaires de réintégration dans le GDS](../Editeurs/9000219.md). 




Pour utiliser ces fonctionnalités, il est nécessaire de posséder chez un fournisseur de modèle d'IA un compte API. Ce compte API permet d'utiliser l'API du fournisseur. A ce compte est attaché une clé d'API. 

**Remarques** : 

- Selon les fournisseurs, la méthode permettant de créer un compte API est différente. Il est conseillé de consulter directement le site du fournisseur pour obtenir plus de détails. 

- Selon les fournisseurs, le nom utilisé pour le compte API diffère. 

- Votre compte API doit être associé à un moyen de paiement. Selon les fournisseurs, il est possible de provisionner un compte ou d'avoir une facture en fin de mois. 

- Selon l'abonnement souscrit, le message "quota dépassé" peut être affiché.
