


## Edition de la feuille de styles WEBDEV
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000100"></a>
WEBDEV offre la possibilité de gérer l'ensemble des styles WEBDEV utilisés dans un projet. Les styles WEBDEV disponibles sont visualisables par type de champ.  

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Editer la feuille de styles WEBDEV d'un projet
<a name="editer_feuille_styles_webdev_projet_ELTTEXTE000124"></a>
Pour éditer les styles WEBDEV d'un projet :

1. Sélectionnez un champ du type pour lequel vous souhaitez connaître les styles WEBDEV disponibles (par exemple un champ Bouton pour voir les différents styles WEBDEV associés au champ Bouton). 

2. Sous le volet "Modification", dans le groupe "Style", cliquez sur "Styles".

3. La liste des styles WEBDEV présents dans le projet et pouvant être associés au champ sélectionné (champ Bouton dans notre exemple) s'affiche. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Edition_styles_WB%20-%20HC%20N%B0001.gif)





Il est possible de sélectionner un style WEBDEV différent pour le champ en cours.

Le menu contextuel des différents styles WEBDEV permet de :   <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Edition_styles_WB%20-%20HC%20N%B0002.gif)


- Modifier un style existant. Cette option est disponible uniquement pour les styles ne provenant pas d'une ambiance. 

- Dupliquer le style sélectionné.

- Supprimer un style. Cette option est disponible uniquement pour les styles ne provenant pas d'une ambiance. 

- Créer un nouveau style.

- Supprimer le style sélectionné : dans ce cas, le style associé au champ sera le même mais sera local au champ.

- Définir un nouveau style par défaut. Tous les nouveaux champs du type en cours créés utiliseront par défaut ce style. 

- Voir les utilisations du style. Il est ainsi possible de consulter la liste des champs du projet utilisant le style sélectionné. 




La fenêtre d'édition du style reprend les caractéristiques de style correspondant au champ pour lequel le style a été défini. Pour plus de détails, consultez [Fenêtre d'édition des styles WEBDEV](../Editeurs/2016002.md).
