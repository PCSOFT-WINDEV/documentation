
## Fenêtre "A propos"
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000124"></a>
La fenêtre "A propos" permet d'afficher et d'accéder à diverses informations sur l'application en cours :

- le nom de l'application.

- la version de l'application.

- le copyright.

- la société.

- le site Internet de la société.

- l'adresse email de la société.

- la licence.

- la liste des équipes et/ou des intervenants.

- etc.



<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=APropos.gif)


WINDEV permet de créer automatiquement la fenêtre "A propos" de votre application lors de l'intégration du [menu "?"](../Editeurs/9000070.md).

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000148"></a>


### Créer la fenêtre "A propos"
<a name="creer_fenetre_propos_ELTPARAGRAPHE000034"></a>Pour créer la fenêtre "A propos" :

1. Intégrez le menu "?" dans votre application. Pour plus de détails, consultez [Intégration du menu "?"](../Editeurs/9000070.md).

2. Choisissez d'ajouter l'option "A propos".

3. Générez automatiquement une fenêtre "A propos" (option "Générer une fenêtre "A Propos" automatiquement.").

4. Sélectionnez les informations à afficher dans la fenêtre "A propos".

5. Dans la suite de l'assistant, saisissez le détail des informations à afficher. 

6. Terminez l'assistant.

7. La fenêtre "FEN_About" est alors automatiquement ajoutée dans le projet.





<a name="NOTE2_2"></a>


### Informations affichées dans la fenêtre "A propos"
<a name="informations_affichees_dans_fenetre_propos_ELTPARAGRAPHE000062"></a>Les informations pouvant être affichées sont les suivantes : 

- **Nom du module** : Nom de l'exécutable spécifié lors de la création du programme exécutable.

- **Version du module** : Numéro de version de l'application spécifié lors de la création du programme exécutable.

- **Copyright** : Texte du copyright spécifié lors de la création de l'exécutable. 

- **Adresse du site Internet** et **l'adresse email** : Adresses spécifiées dans l'assistant d'intégration du menu "?". Elles peuvent être modifiées lors de la création du programme exécutable.

- **Texte d'avertissement** : Texte saisi dans l'assistant d'intégration du menu "?". Par défaut, ce texte est le suivant : 
	"Avertissement : ce logiciel est protégé par la loi du copyright et par les conventions internationales. Pour utiliser ce produit, vous avez accepté la licence d'utilisation."

- **Société** : Nom de la société indiqué lors de la création du programme exécutable.




Le fichier de licence correspond à celui défini lors de la génération de la procédure d'installation de l'application.

La fenêtre "A propos" permet de faire défiler le **nom des équipes et/ou des intervenants** de votre application. Cette équipe et/ou ces intervenants ont été spécifiés sont précisés dans l'assistant d'intégration du menu "?".
