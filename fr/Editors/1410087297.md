
## Activation des types Nullables
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000093"></a>
L'activation des types nullables entraîne de nombreuses modifications dans la gestion du Null effectuée par votre projet. 

L'activation sur un projet existant n'est pas recommandée. De nombreuses modifications sont à effectuer aussi bien au niveau de l'analyse qu'au niveau du code de votre application. 

Cette page liste les principales différences entre la nouvelle et l'ancienne gestion du Null. 

<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Différences de comportements dues à l'activation des valeurs nullables
<a name="differences_comportements_dues_activation_des_valeurs_nullables_ELTTEXTE000117"></a>
En cochant l'option "Autoriser les types nullables", différentes fonctionnalités sont activées. Ces fonctionnalités changent la programmation de la gestion du Null : 

- [Stockage de la valeur Null dans une variable : définition d'un type nullable](../Motscles/1511031.md). 

- [Savoir si un élément est null](../Motscles/1511031.md). 

- [Récupérer la valeur d'un élément qui autorise le Null](../Motscles/1511031.md). 

- [Utilisation du Null dans les fonctions WLangage](../Motscles/1511031.md). 

- [Utilisation du Null dans les procédures](../Motscles/1511031.md).

- [Opérations réalisables sur des variables autorisant le Null](../Motscles/1511031.md).

- [Gestion du Null dans les rubriques HFSQL](../WDLang4/3044187.md).
