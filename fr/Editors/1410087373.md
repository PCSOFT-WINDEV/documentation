
## Compagnon IA dans l'environnement
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000112"></a>
L'environnement de développement de vos outils intègre à partir de la version 2026 une IA conversationnelle (un compagnon) : posez des questions et l'environnement vous répond. 

Ce compagnon conversationnel est affiché dans le volet "Compagnon IA" de votre environnement. 

Le compagnon IA peut aussi bien : 

- répondre à vos questions en mode "Conversation". Ces questions peuvent concerner le code de votre projet et de ses éléments. 
	Ce compagnon IA vous permet par exemple d'effectuer des recherches dans votre code, d'obtenir une aide pour réaliser une action, résumer l'action d'une procédure, ...

- agir sur votre projet en mode "Action". 
	Le compagnon IA peut par exemple créer des requêtes, créer une analyse, un fichier, etc. Il suffit de demander l'action à réaliser en langage naturel : "Génère une requête qui sélectionne les clients d'un département", "Crée un fichier de données pour stocker des commandes", "Passe toutes les variables en majuscules", etc. 




Cette IA est une IA conversationnelle : un des avantages de l'IA conversationnelle est que vous pouvez affiner et expliciter vos demandes. 
Et l'IA peut poser des questions pour demander des précisions. 
Vous obtenez ainsi un résultat précis.

## Pré-requis
<a name="prerequis_ELTTEXTE000136"></a>
Pour utiliser l'IA conversationnelle, il est nécessaire de posséder un compte API chez un fournisseur de modèle d'IA. Ce compte API permet d'utiliser l'API du fournisseur. A ce compte, est attaché une clé d'API.

Les informations concernant le modèle d'IA choisi et la clé d'API correspondantes doivent être saisies dans les options de WINDEV Suite. 

Remarques :

- Selon les fournisseurs, la méthode permettant de créer un compte API est différente. Il est conseillé de consulter directement le site du fournisseur pour obtenir plus de détails.

- Selon les fournisseurs, le nom utilisé pour le compte API diffère.

- Votre compte API doit être associé à un moyen de paiement. Selon les fournisseurs, il est possible de provisionner un compte ou d'avoir une facture en fin de mois.

- Selon l'abonnement souscrit, le message "quota dépassé" peut être affiché.

## Utiliser le compagnon IA
<a name="utiliser_compagnon_ELTTEXTE000160"></a>
Pour utiliser l'IA conversationnelle : 

1. Affichez le volet "Compagnon IA" : sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Compagnon IA".

2. Cliquez sur "Nouvelle conversation". 

3. Sélectionnez le mode d'utilisation : conversation ou action. 

4. Saisissez votre demande et validez.  








<a name="NOTE4"></a>
<a name="NOTE4_1"></a>


## Le compagnon connaît votre projet et peut intervenir sur votre projet
<a name="compagnon_connait_votre_projet_peut_intervenir_sur_votre_projet_ELTTEXTE000184"></a>
Que ce soit en mode conversation ou en mode action, le compagnon connaît votre projet en utilisant différents "tools". Ces tools permettent par exemple à l'IA de lister les éléments de votre projet, de lire le code des éléments de votre projet, ...

Lorsque vous posez une question, le moteur d'IA exécute le ou les tools permettant d'obtenir une réponse ou de faire une recherche. Un enchaînement de tools est possible pour répondre à une question ou pour faire une action. Les tools utilisés sont automatiquement indiqués dans le volet correspondant à la conversation.
