


## Yousign
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000213"></a>
La signature électronique de contrats avec des particuliers ou des professionnels est aujourd’hui généralisée. La signature électronique permet de :

- indiquer à différents intervenants que le document a été lu et que son contenu est validé. 

- figer l'état d'un document. La moindre modification du document rendra sa signature invalide. Les utilisateurs seront avertis que le document a été modifié depuis la dernière signature.




A partir des versions 2025, un assistant permet d'intégrer la signature de documents par Yousign en WLangage.

Note : Pour réaliser une signature de document à l'aide des solutions Yousign, une clé d'API est nécessaire. Cette clé est disponible après souscription d'un abonnement adéquat auprès de Yousign.

## Principe d'utilisation
<a name="principe_utilisation_ELTTEXTE000237"></a>


### Cheminement d'une signature avec Yousign
<a name="cheminement_une_signature_avec_yousign_ELTPARAGRAPHE000025"></a>

1. L'application WINDEV fournit à Yousign le document (le plus souvent au format PDF) à signer ainsi que la liste des personnes qui doivent le signer.

2. Yousign envoie ensuite un email aux signataires avec un lien vers le site de Yousign pour réaliser la signature. 

3. Quand tous les signataires ont signé, Yousign notifie l'application WINDEV. L'application WINDEV récupère alors le document signé auprès de Yousign.



<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign-Sch%E9ma.gif)


Remarque : Un document peut également être approuvé avant d'être signé (optionnel). 

L'assistant de code Yousign permet de gérer toutes les étapes d'une signature, de suivre l'état de la signature d'un document, etc. 


### Signature
<a name="signature_ELTPARAGRAPHE000038"></a>La signature d'un document est réalisée via un tiers de confiance, ici Yousign. Ce tiers de confiance engage sa responsabilité sur la validité de la signature.

Il est possible de demander 3 types de signatures électroniques :

- La signature électronique simple (SES)

- La signature électronique avancée (AES), qui nécessite une confirmation au moins par SMS. Dans ce cas, le numéro de téléphone sera alors obligatoire. 

- La signature électronique avancée qualifiée (QES), avec vérification de la pièce d'identité. 




Remarque : La seule signature électronique ayant la même validité juridique que la signature manuscrite est la signature qualifiée.

## Pré-requis
<a name="prerequis_ELTTEXTE000267"></a>


### Pré-requis pour effectuer des tests
<a name="prerequis_pour_effectuer_des_tests_ELTPARAGRAPHE000055"></a>Pour tester l'intégration de la signature électronique dans votre application, il est nécessaire de suivre les étapes suivantes : 

1. Créer un compte Yousign ([https://yousign.app/welcome](https://yousign.app/welcome)).  

2. Créez une nouvelle clé API. Précisez : 

	- Environnement : Sandbox

	- Permissions : Full-Access




3. Validez la création de la clé.  

4. Copiez et conservez la clé. 




Remarque : Dans ce mode, les mails de demande de signature sont réellement envoyés, mais dans le contenu, il est indiqué que le mail est envoyé pour test uniquement. 


### Pré-requis pour utiliser réellement Yousign
<a name="prerequis_pour_utiliser_reellement_yousign_ELTPARAGRAPHE000073"></a>Pour utiliser réellement les fonctionnalités de Yousign, il est nécessaire de créer un compte de production. Vous pouvez consulter les différentes possibilités à l'adresse suivante : [https://yousign.com/fr-fr/prix-api](https://yousign.com/fr-fr/prix-api).

## Assistant Yousign
<a name="assistant_yousign_ELTTEXTE000297"></a>


### Lancer l'assistant de code
<a name="lancer_assistant_code_ELTPARAGRAPHE000085"></a>Pour utiliser l'assistant de génération de code Yousign : 

1. Ouvrez l'éditeur de code sur le code du champ devant lancer la signature Yousign. 

2. Saisissez le mot "Yousign" et validez.
	<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0001.gif)

	L'assistant Yousign se lance. 

3. La première étape de l'assistant consiste à renseigner la clé d'API précédemment obtenue via le compte Yousign.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0002.gif)


4. Dans l'étape suivante, vous pouvez sélectionner le service à utiliser.

<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0003.gif)



### Demande de signature
<a name="demande_signature_ELTPARAGRAPHE000102"></a>Pour utiliser la signature Yousign via votre application, la première étape consiste à demander une signature. Cette fonctionnalité est disponible dans l'assistant Yousign : 

1. Sélectionnez l'option "Demander une signature" dans l'assistant et passez à l'étape suivante. 

2. Indiquez le document à signer.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0004.gif)
 Ce document peut correspondre : 

	- à une variable, un champ ou être renvoyé par une fonction. 

	- à un fichier. Il suffit dans ce cas d'indiquer le chemin du fichier. 




3. L'étape suivante permet de sélectionner les destinataires du document.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0005.gif)
 Pour chaque destinataire, il est nécessaire de préciser : 

	- L'identité du destinataire.  

	- Si le destinataire doit : 

		- signer le document. 

		- approuver le document. 

		- recevoir une copie. 




- Si le destinataire doit signer le document, il est nécessaire d'indiquer le niveau de signature souhaité, la méthode d'identification du destinataire pour la signature, son email et/ou son numéro de téléphone. 

- Si le destinataire doit approuver le document ou recevoir uniquement une copie, seul son email est nécessaire. 

- La langue de l'interface utilisée. Il est possible d'utiliser une langue spécifique pour chaque destinataire (7 langues différentes disponibles). 

4. L'assistant demande ensuite pour chaque signataire le ou les emplacements de signature. Cet emplacement peut correspondre à une chaîne présente dans le document ou à des coordonnées. Si plusieurs pages du document doivent être signées, il est nécessaire d'ajouter plusieurs emplacements pour la signature.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0006.gif)


5. L'étape suivante permet de configurer l'email qui va être envoyé aux destinataires.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0007.gif)


6. L'étape suivante permet de visualiser le code généré. Ce code peut être copié et/ou imprimé.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Yousign%20-%20HC%20N%B0008.gif)


7. Terminez l'assistant. 

	- Le code WLangage est automatiquement intégré dans le code en cours. Ce code peut être modifié, adapté, etc. 

	- Le composant Yousign est intégré au projet. Ecrit en WLangage, ce composant interne réalise les opérations "bas niveau". 
			Remarque : Il est déconseillé de modifier le code de ce composant interne.








### Autres fonctionnalités de l'assistant
<a name="autres_fonctionnalites_assistant_ELTPARAGRAPHE000140"></a>L'assistant Yousign propose de nombreuses fonctionnalités permettant de gérer les documents et les signatures : 

- Récupérer un document (signé ou non).

- Connaître l'avancement d'une demande de signature. 

- Obtenir des informations relatives aux documents : date de dernière modification, etc. 

- Obtenir des informations relatives aux signataires : identité, documents signés, etc. 

- Annuler ou lister les demandes, 

- Importer le composant. 




Pour la plupart de ces fonctionnalités, il est nécessaire de spécifier l'identifiant généré par Yousign transmis au retour de l'envoi de la demande de signature. Cet identifiant correspond à la propriété 'Id' de la variable clRequête.  


### Composant Yousign
<a name="composant_yousign_ELTPARAGRAPHE000154"></a>Le composant Yousign est automatiquement intégré à votre projet. Ce composant comprend toutes les procédures nécessaires à l'utilisation des fonctionnalités de Yousign.

## Remarques
<a name="remarques_ELTTEXTE000339"></a>


- Il est possible de signer des documents de type docx, pdf ou html. 

- Rappel : Pour tester l'application, il est conseillé d'utiliser un compte développeur (gratuit). 

- Attention : En exécution, lors de la connexion au compte Yousign, une page Web d'identification peut s'afficher. Lorsque l'identification est effectuée, un page blanche est affichée et peut fermée. 

- Par défaut, les messages envoyés par Yousign aux différentes personnes devant effectuer une signature sont en anglais.
