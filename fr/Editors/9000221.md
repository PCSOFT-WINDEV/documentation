
## Intelligence Artificielle Générative de code WLangage
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000156"></a>
L'Intelligence Artificielle Générative de code WLangage permet d'obtenir des propositions de code WLangage à partir du code saisi. 
Ces propositions peuvent être par exemple : 

- compléter automatiquement la ligne en cours de saisie, 

- proposer un bloc de code, 

- proposer une boucle de parcours, 

- compléter les commentaires,

- générer un code WLangage réalisant l'action décrite dans les commentaires, etc.




La proposition de code est affichée de manière non intrusive sous forme de "texte fantôme" (texte gris clair) à partir de la ligne en cours de saisie ou du curseur. Par défaut, une proposition apparaît après un délai de 100 millisecondes sans taper.

Pour valider la proposition, il suffit d'utiliser la touche **Tab**. 

La proposition ne vous convient pas ? Utilisez la combinaison de touches **Ctrl Maj Tab** pour obtenir une autre proposition. 

Pour ne pas tenir compte de la proposition, continuez de saisir votre code ou utilisez la touche **Echap**. D'autres propositions peuvent continuer d'apparaître en cours de saisie.

## Activation / Désactivation de l'IA générative de code
<a name="activation_desactivation_generative_code_ELTTEXTE000180"></a>
L'Intelligence Artificielle Générative de code WLangage est activée par défaut. 

**Pour activer / désactiver l'Intelligence Artificielle Générative de code** :

1. Affichez les options de l'éditeur de code : sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code". 

2. Dans l'onglet "IA (preview)", activez ou désactivez la fonctionnalité. 

3. Validez.  




**Remarque** : Cette fonctionnalité utilise une adresse internet spécifique. Dans le cas d'une connexion Internet sécurisée, il peut être nécessaire d'autoriser expressément certains domaines dans une "liste blanche". Pour connaître la liste des domaines concernés, consultez la FAQ **22325** : [Quels domaines autoriser afin d'utiliser toutes les fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile depuis une connexion Internet sécurisée ?](https://faq.pcsoft.fr/faqread.awp?idfaq=22325).

## Fonctionnement de l'IA générative de code
<a name="fonctionnement_generative_code_ELTTEXTE000204"></a>
L'Intelligence Artificielle Générative de code WLangage propose des suggestions en temps réel pendant la saisie de code, réduisant ainsi le temps nécessaire pour les phases de codage.
Cela permet de coder plus rapidement, en évitant les tâches répétitives, en bénéficiant d'automatismes et de suggestions pour les parties prévisibles du code. 

Les suggestions de code sont contextuelles et dépendent :

- du projet,

- du code en cours d'écriture (au-dessus et en dessous de la ligne en cours),

- des codes modifiés précédemment,

- des fenêtres,

- des états,

- des collections de procédures,

- des rubriques des fichiers de données (les colonnes des tables).


En fonction de tous ces éléments, l'IA propose le code le plus probable.




### Exemples
<a name="exemples_ELTPARAGRAPHE000086"></a>

- **Exemple de génération de code à partir du code déjà saisi** : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=IA%201%20integre%20editeur%20testSL.gif)
L'IA a détecté les rubriques de la requête, a trouvé le champ Table et remplit les colonnes avec les rubriques correspondants.




- **Exemple de génération d'une nouvelle répétition** : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=IA%202%20-%20V2.gif)
L'IA a analysé le code, détecté une répétition de code et propose donc la répétition pour les éléments suivants de la structure de départ (JSON). Pour valider la proposition (en jaune pâle), touche Tab. 




- **Exemple de génération de code à la volée** : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=IA%20a%20la%20volee.gif)
L'IA a détecté dans la fenêtre qu'une procédure calcule une date d'échéance, elle a détecté un champ de saisie avec une date de contrat, et propose le code le plus probable pour continuer la ligne en cours de saisie. Pour valider la proposition (en jaune pâle), touche Tab. 
	Si le résultat ne vous convient pas, redemandez plusieurs fois une proposition : Ctrl Maj Tab.




- **Exemple de génération de code à partir d'un commentaire** : 

	- En saisie de code, je tape un commentaire...<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=IA%20code%20saisie%20commentaire.gif)


	- L’IA propose un code qui réalise l’action décrite dans le commentaire en tenant compte du projet en cours. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=IA%20code%20saisie%20commentaire%20apres.gif)
La touche Tab valide ce code, la combinaison de touches Ctrl Maj Tab génère une nouvelle proposition, la touche Echap ou la saisie font disparaître le code proposé.
