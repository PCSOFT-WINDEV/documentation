
## Options de l'éditeur de code
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000395"></a>
De nombreuses options permettent de personnaliser et d'utiliser toutes les possibilités de l'éditeur de code. 

Pour configurer les options générales de l'éditeur de code :

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code".

2. La fenêtre de configuration est affichée. Les modifications possibles sont regroupées en 4 thèmes :

	- [Code](#NOTE2_1).

	- [Débogueur](#NOTE3_1).

	- [Styles](#NOTE5_1). 

	- [Doc](#NOTE5_1).

	- [IA (preview)](#NOTE6_1).

## Options de code
<a name="options_code_ELTTEXTE000419"></a>


### Aide à la saisie
<a name="aide_saisie_ELTPARAGRAPHE000051"></a>Les options concernant l'aide à la saisie sont les suivantes : 

- **Activer l'aide à la saisie après une inactivité de** : 
	Cette option permet d'activer la complétion automatique dans votre projet. Pour plus de détails, consultez [Complétion automatique](../Editeurs/2013001.md). 

- **Activer l'aide à la saisie des paramètres** : 
	Cette option permet d'activer la saisie assistée pour les paramètres documentés des procédures et des méthodes de classes. Pour plus de détails, consultez [Documentation automatique des procédures et méthodes](../Motscles/1513006.md). 

- **Ne jamais passer en mode écrasement avec la touche Ins.** : 
	Cette option permet d'éviter la suppression inopinée de code. 

- Surligner les blocs de code (SI/ALORS/FIN, parenthèses, ...) : 
	Si le curseur de la souris est positionné sur une instruction de bloc (SI, ALORS, SINON, POUR, FIN, BOUCLE, QUAND EXCEPTION DANS, ...), les différents éléments de ce bloc sont surlignés. Pour plus de détails, consultez [Editeur de code : Manipulations diverses](../Editeurs/2010031.md). 

- **Surligner la ligne courante** : 
	La ligne en cours est rapidement identifiable grâce à des pointillés permettant de surligner la ligne courante. Pour plus de détails, consultez [Editeur de code : Manipulations diverses](../Editeurs/2010031.md). 

- **Surligner la déclaration et les utilisations de la variable en cours** : 
	A chaque fois que le curseur est placé sur un identifiant (variable, procédure, fichier de données, ...), toutes les utilisations de cet identifiant dans le code courant sont surlignées. Pour plus de détails, consultez [Editeur de code : Manipulations diverses](../Editeurs/2010031.md). 

- **F2 : ouvrir les procédures des classes et des collections dans des fenêtres séparées** : 
	Par défaut, les procédures des classes et des collections de procédures sont automatiquement ouvertes dans la fenêtre de code en cours. Cette option permet d'utiliser une fenêtre de code différente.  

- **Compléter automatiquement les caractères ouvrants ()/[]/""/... ** : Cette option permet de ne pas avoir à saisir le caractère final. La saisie est effectuée entre le caractère ouvrant et le caractère fermant. 

- **Indentation auto. Aligner sur '=', 'est', '//'** : 
	Cette option permet d'aligner tous les textes et codes présents à droite des signes '=', 'est' ou '//'. Cette option sera prise en compte automatiquement pour toutes les prochaines réindentations automatiques effectuées via le raccourci clavier CTRL + R. Pour plus de détails, consultez [Indentation du code](../Editeurs/2013011.md). 

- **Afficher le fil d'ariane**
	Cette option permet d'afficher un fil d'ariane au bas des fenêtres de l'éditeur de code. Il est ainsi possible de connaître le chemin parcouru pour afficher le code. 

- **Type d'ascenseur** :
	Cette option permet de paramétrer le type d'ascenseur utilisé dans l'éditeur de code. Pour plus de détails, consultez [Ascenseur visuel de code](../Editeurs/9000180.md). 

- **Activer la correction automatique au saut de ligne** : 
	Cette option permet d'activer la correction automatique des erreurs de frappe. Lors du passage à la ligne suivante, les mots saisis contenant des fautes sont automatiquement corrigés. 

- **Largeur des tabulations** : 
	Cette option permet de définir la largeur des tabulations (en caractères) pour l'indentation. 

- **Langue du code ** : 
	Cette option permet de définir la langue utilisée pour la saisie du code WLangage. 

- **Casse des mots-clés** : 
	Cette option permet de définir la casse utilisée pour les mots-clés du WLangage (SI, POUR, ... ou bien si, pour, ...). 









### Actions automatiques sur le coller de code
<a name="actions_automatiques_sur_coller_code_ELTPARAGRAPHE000179"></a>Lors d'un copier/coller de code d'un projet à un autre ou d'une fenêtre à une autre, il est possible de spécifier des options de collage : 

- **Conversion du code en** : Cette option permet de traduire automatiquement le code collé. Tous les mots du langage seront automatiquement traduits. Il est possible de traduire le code collé en français ou en anglais.  

- **Indentation (le code collé est mis en forme et réindenté pour s'adapter à la mise en page)** : Permet de paramétrer ou non la réindentation automatique d'un code collé. Pour plus de détails, consultez [Indentation du code](../Editeurs/2013011.md). 





### Activer le correcteur orthographique
<a name="activer_correcteur_orthographique_ELTPARAGRAPHE000190"></a>Le correcteur orthographique peut être activé dans 

- les commentaires de code. 

- les chaînes de caractères littérales. 


Pour plus de détails, consultez [Correcteurs disponibles dans l'éditeur de code](../Editeurs/9000073.md). 


### Historique du code
<a name="historique_code_ELTPARAGRAPHE000203"></a>L'option "Sauver l'historique des modifications du code" permet de : 

- conserver le code complet de chaque traitement/événement modifié.

- restaurer un code existant à une date donnée, ce code ayant été effacé ou modifié par la suite.




Pour plus de détails, consultez [Historique du code](../Editeurs/2013010.md). 


### Affichage des erreurs
<a name="affichage_des_erreurs_ELTPARAGRAPHE000222"></a>A partir de la version 2024, les erreurs sont affichées directement dans la ligne de code. Cet affichage peut être paramétré via les options de l'éditeur de code. 

Il est possible de configurer les informations affichées sur la ligne de code : 

- Les erreurs. 

- Les erreurs et les avertissements. 

- Les erreurs, avertissements et infos de compilation. 

- Les avertissements et les info de compilation. 

- Rien. 




En cas d'affichage des erreurs, une bulle de proposition de correction peut être affichée.

Remarque : les erreurs, avertissements et information de compilation sont également affichées dans le volet [Erreurs de compilation](../Editeurs/2027031.md).  




### Accélération matérielle
<a name="acceleration_materielle_ELTPARAGRAPHE000245"></a>L'option "Activer l'accélération matérielle de l'éditeur de code" permet d'activer Direct 2D et ainsi de profiter de toutes les fonctionnalités de la carte graphique de votre ordinateur. L'utilisation de l'éditeur de code devient plus fluide. 




### Entête épinglé
<a name="entete_epingle_ELTPARAGRAPHE000257"></a>L'option "Activer l'entête épingle" permet de simplifier la lecture d'un code volumineux (plus grand que la taille de l'écran).
La fonctionnalité de "l'en-tête épinglé" permet de laisser visible la première ligne de chaque bloc de code qui n'est plus visible en haut de l'écran. 

Pour plus de détails, consultez [Entête épinglé](../Editeurs/9000224.md).

## Options du débogueur
<a name="options_debogueur_ELTTEXTE000479"></a>


### Débogueur
<a name="debogueur_ELTPARAGRAPHE000272"></a>Les options de l'éditeur de code concernant le débogage sont les suivantes : 

- Comportement lors du retour sous l'éditeur alors qu'un test est en cours : Il est possible de proposer de terminer le test (par défaut), terminer le test automatiquement ou continuer le test. 

- Iconiser l'éditeur en mode test : Par défaut, lors d'un test, l'éditeur s'icônise. Selon la configuration matérielle (écran large, 2 écrans, etc.), cette icônisation peut ne pas être utile.

- Afficher les expressions automatiques dans le code. 





### Débogage distant - WMDev
<a name="debogage_distant_wmdev_ELTPARAGRAPHE000281"></a>Il est possible de fixer l'adresse IP utilisée pour le débogage.

## Options de style
<a name="options_style_ELTTEXTE000509"></a>
L'environnement de WINDEV, WEBDEV et WINDEV Mobile propose plusieurs thèmes. Ces thèmes sont également disponibles dans l'éditeur de code. Vous avez également la possibilité de créer et configurer votre propre thème ou encore d'importer un thème existant. 

Pour plus de détails, consultez [Coloration du code WLangage](../Editeurs/9000141.md). 

Il est possible de définir des options de style pour le curseur de texte utilisé dans l'éditeur de code : 

- Période de clignotement : Intervalle de temps (en millisecondes) entre deux affichages du curseur. 

- Largeur du curseur : Epaisseur du curseur de 1 à 8. Si l'option "Bloc" est sélectionnée, le curseur correspondra à un caractère. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=wx-taille-du-curseur-vitesse-clignotement.gif)

## IA (preview)
<a name="preview_ELTTEXTE000584"></a>
L'Intelligence Artificielle Générative de code WLangage permet d'obtenir des propositions de code WLangage à partir du code saisi. 
Ces propositions peuvent être par exemple : 

- compléter automatiquement la ligne en cours de saisie, 

- proposer un bloc de code, 

- proposer une boucle de parcours, 

- compléter les commentaires,

- générer un code WLangage réalisant l'action décrite dans les commentaires, etc.




La proposition de code est affichée de manière non intrusive sous forme de "texte fantôme" (texte gris clair) à partir de la ligne en cours de saisie ou du curseur. Par défaut, une proposition apparaît après un délai de 100 millisecondes sans taper.

Pour valider la proposition, il suffit d'utiliser la touche **Tab**. 

La proposition ne vous convient pas ? Utilisez la combinaison de touches **Ctrl Maj Tab** pour obtenir une autre proposition. 

Pour ne pas tenir compte de la proposition, continuez de saisir votre code ou utilisez la touche **Echap**. D'autres propositions peuvent continuer d'apparaître en cours de saisie. 


L'Intelligence Artificielle Générative de code WLangage est activée par défaut. 

**Pour activer / désactiver l'Intelligence Artificielle Générative de code** :

1. Affichez les options de l'éditeur de code : sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options de l'éditeur de code". 

2. Dans l'onglet "IA (preview)", activez ou désactivez la fonctionnalité. 

3. Validez.  




**Remarque** : Cette fonctionnalité utilise une adresse internet spécifique. Dans le cas d'une connexion Internet sécurisée, il peut être nécessaire d'autoriser expressément certains domaines dans une "liste blanche". Pour connaître la liste des domaines concernés, consultez la FAQ **22325** : [Quels domaines autoriser afin d'utiliser toutes les fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile depuis une connexion Internet sécurisée ?](https://faq.pcsoft.fr/faqread.awp?idfaq=22325).


Pour plus de détails, consultez [Intelligence Artificielle Générative de code WLangage](../Editeurs/9000221.md).
