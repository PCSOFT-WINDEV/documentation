


## Recherche dans le code en cours
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000178"></a>
Lors de l'écriture de code, il arrive souvent de vouloir effectuer rapidement une recherche dans le code.


Plusieurs méthodes permettent d'effectuer cette recherche : 

- Utiliser la [recherche générale de l'environnement](../Editeurs/9000150.md) (Ctrl F).
	Cela oblige cependant à saisir la souris et à régler cette recherche. 

- Utiliser la [recherche immédiate](#NOTE1b_1) effectuée sur l'élément présent dans l'éditeur de code (Ctrl F3)
	Cela oblige à avoir le volet "Rechercher remplacer" affiché. 

- Utiliser la [recherche rapide](#NOTE2_1), permettant d'effectuer une recherche dans le code en cours (Alt F3). 




**Remarque** : Il est également possible d'accéder à un événement WLangage de l'élément en cours. Pour plus de détails, consultez [Accès aux événements de l'élément en cours](#NOTE3_1).

## Comment faire une recherche immédiate ?
<a name="comment_faire_une_recherche_immediate_ELTTEXTE000202"></a>
**Pour effectuer une recherche immédiate sur un élément présent dans l'éditeur de code**, il suffit d'utiliser la combinaison de touches Ctrl F3 sur un élément de l'éditeur de code (le volet "Rechercher / Remplacer" étant affiché). 

La combinaison de touches Ctrl + F3 : 

- remplit le champ de recherche avec le mot sur lequel se trouve le curseur. 

- déclenche la recherche. 

- surligne dans le code toutes les occurrences trouvées et positionne sur la première occurrence. 





### Recherche dans une sélection
<a name="recherche_dans_une_selection_ELTPARAGRAPHE000052"></a>L'éditeur de code permet d'effectuer une recherche (et un remplacement) dans une sélection. 

Si une sélection de plus d'une ligne est active, la recherche s'effectue automatiquement dans cette sélection. 

Lors d'une recherche dans une sélection, le mot recherché apparaît surligné dans le code. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Code_Recherche_Selection.gif)
Les touches F3 et Shift F3 permettent de naviguer d'occurrence en occurrence directement par le clavier.

## Comment faire une recherche rapide ?
<a name="comment_faire_une_recherche_rapide_ELTTEXTE000232"></a>
Lors d'une recherche rapide la chaîne recherchée est mise en évidence (surlignage) dans le code en temps réel lors de la frappe. Le nombre d'occurrences est affiché.

**Pour effectuer une recherche rapide dans le code** : 

1. Ouvrez un projet sous l'éditeur et affichez le code d'un élément. 

2. Utilisez la combinaison de touches Alt F3 pour afficher la fenêtre de recherche rapide : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0001.gif)


3. Pour afficher la fenêtre en mode "Rechercher / Remplacer", utilisez la combinaison de touches Ctrl R lorsque la fenêtre de recherche a le focus. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002.gif)

	Remarque : Pour quitter le mode de remplacement vous pouvez cliquer sur la croix ou utiliser la touche Echap. 




**Fonctionnement de la fenêtre de recherche**

- Il n'est pas possible d'afficher plusieurs fenêtres de recherche rapide. 

- La fenêtre se ferme via la croix ou la touche Echap. 

- Il est possible de parcourir les résultats via les touches fléchées ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%201.gif) ou les raccourcis F3 ou Maj F3.  

- Si une sélection monoligne est en cours lors de l'appel à la fenêtre de recherche, la sélection est automatiquement prise en compte dans la fenêtre de recherche et la recherche est lancée. 

- La recherche est automatiquement réalisée lors de la saisie de l'utilisateur dans la fenêtre de recherche. 

- Les options de filtrage pour la recherche sont les suivantes : 

	- ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%205.gif) Respect de la casse et des accents. 

	- ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%206.gif) Recherche des mots complets. 

	- ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%207.gif) Recherche via les expressions régulières. 




- Pour effectuer un remplacement : 

	- Ctrl R affiche la fenêtre de remplacement. Le curseur apparaît automatiquement dans la zone de saisie du texte de remplacement. 

	- Alt R (![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%203.gif)) remplace l'élément courant et sélectionne l'élément suivant. 

	- Entrée (![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%202.gif)) remplace tous les éléments trouvés.




- Ctrl F (![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Recherche_rapide_code%20-%20HC%20N%B0002%204.gif)) permet d'ouvrir le volet de recherche.

## Comment accéder à un événement de l'élément en cours ?
<a name="comment_acceder_evenement_element_cours_ELTTEXTE000256"></a>


### Recherche et accès à un événement
<a name="recherche_acces_evenement_ELTPARAGRAPHE000116"></a>L'éditeur de code permet de rechercher et d'accéder à un événement de l'élément en cours : fenêtre, page, état, ... 

1. Sous le volet "Code", dans le groupe "Navigation", saisissez les lettres permettant de retrouver l'événement voulu. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Code_Recherche_Traitement.gif)
Remarque : Pour afficher automatiquement la liste des événements, utilisez la combinaison de touches Alt + C.

2. Sélectionnez dans la liste l'événement voulu. Il est automatiquement affiché sous l'éditeur de code.
