
## GDS : Récupérer tout et réintégrer tout
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000118"></a>
Lors du développement d'un projet présent dans le GDS, il peut être nécessaire de récupérer en local tous les éléments présents dans la base de sources, ou de réintégrer tous les éléments présents localement dans la base de sources. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Barre_outils%20-%20HC%20N%B0002%205.gif)


**Avant la génération de l'analyse**, il est conseillé de récupérer la dernière version de tous les éléments du projet. En effet, les éléments extraits ne pourront pas être modifiés et donc pas être synchronisés avec l'analyse. Il est donc nécessaire que :

- tous les éléments du projet soient réintégrés,

- la dernière version des éléments du projet soit sur le poste où la génération de l'analyse est effectuée.




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Récupérer tous les éléments
<a name="recuperer_tous_les_elements_ELTTEXTE000142"></a>
L'option "Tout récupérer" permet de récupérer toutes les nouvelles versions des éléments du projet qui sont présents dans la base de sources. Les éléments qui sont actuellement extraits par l'utilisateur ne sont pas proposés.

Cette option permet de mettre à jour la version locale avec tous les éléments actuellement présents dans la base de sources. 

Cette fenêtre propose les options suivantes : 

- "Modifications" : Permet d'obtenir les modifications réalisées entre l'élément local et l'élément correspondant à récupérer dans la base de source. 

- "Historique" : Permet d'obtenir l'historique des actions effectuées sur l'élément sélectionné. 

- "Propriétés" : Affiche la fenêtre des propriétés de l'élément sélectionné. 

- "Supprimer" : Permet de supprimer en local l'élément au lieu de le récupérer. 

- "Filtrer les différences binaires" : Permet de griser les éléments pour lesquels il n'existe pas de modification de code ou d'UI dans la base de sources. Ces éléments grisés présentent uniquement une différence du point de vue binaire (par exemple passage de la fenêtre de la version N-1 à la version N). Ces éléments grisés seront automatiquement récupérés. 




L'option "Recompiler le projet" permet de recompiler le projet immédiatement après la récupération des éléments provenant de la base de sources du GDS.

<a name="NOTE3_1"></a>


## Réintégrer tous les éléments
<a name="reintegrer_tous_les_elements_ELTTEXTE000166"></a>
L'option "Tout réintégrer" permet de réintégrer dans la base de sources du GDS tous les éléments du projet en cours qui ont été extraits. Il est possible de ne pas réintégrer certains éléments (il suffit d'enlever la coche devant l'élément) ou de garder les éléments extraits. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=GDS_Reintegrer_recup%E9rer%20-%20HC%20N%B0009.gif)


Cette fenêtre propose les options suivantes : 

- "Mes modifs" : Permet d'obtenir la liste des modifications que vous avez réalisées sur l'élément sélectionné depuis votre dernière extraction de la base de sources. 

- "Comparer" : Permet d'obtenir la liste des modifications entre l'élément sélectionné présent localement et celui présent dans la base de sources. 

- "Historique" : Permet d'obtenir l'historique des actions effectuées sur l'élément sélectionné. 

- "Propriétés" : Affiche la fenêtre des propriétés de l'élément sélectionné. 

- "Fusion" : En cas de conflit de réintégration sur l'élément sélectionné, ouvre la fenêtre de comparaison pour permettre de fusionner les modifications effectuées. 

- "Filtrer les différences binaires" : Permet de griser les éléments pour lesquels il n'existe pas de modification de code ou d'UI. Ces éléments grisés présentent uniquement une différence du point de vue binaire (par exemple passage de la fenêtre de la version N-1 à la version N). Ces éléments grisés seront automatiquement réintégrés. 




Il est également possible de sélectionner tous les éléments ou aucun. 
Le bouton "Tous sans conflit" permet de sélectionner tous les éléments ne posant pas de problème de conflit pour leur réintégration. Il est ainsi possible de réintégrer ces éléments pour ensuite se concentrer sur les éléments avec conflit. 

Dans la partie basse de la fenêtre, les différents onglets permettent de lier la réintégration des éléments sélectionnés à : 

- une ou plusieurs tâches, 

- un ou plusieurs incidents, 

- un commentaire.




L'option "Garder les éléments extraits" permet de réintégrer les éléments sélectionnés dans la base de sources tout en laissant les éléments extraits localement.

Remarque : Selon les options choisies, cette fenêtre est également proposée lors de la fermeture du projet.
