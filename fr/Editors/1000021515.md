
## Créer une classe modèle
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000108"></a>
Lors d'un développement en MVP, il est nécessaire de créer une classe de base (MBase si vous utilisez le RAD MVP). Cette classe est la classe de base de toutes les classes Modèle (M pour Modèle). Elle contient les fonctionnalités de base du code métier (qui seront partagées avec les autres classes modèles grâce à l'héritage).

Il est possible de : 

- créer un pattern de classe personnalisé. Ce pattern sera ensuite utilisé pour générer une classe modèle (basée sur un fichier de données). 
	

- générer une classe modèle utilisant le pattern de classe proposé par WINDEV ou celui personnalisé. 




<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Génération d'une classe modèle et / ou d'une classe pattern
<a name="generation_une_classe_modele_une_classe_pattern_ELTTEXTE000132"></a>
Pour générer une classe pattern : 

1. Dans le volet "Explorateur de projet", utilisez une des méthodes suivantes : 

	- Affichez le menu contextuel du dossier "Classe" et sélectionnez l'option "Créer une classe liée à une description de fichier". Sélectionnez ensuite le fichier de données concerné. 

	- Affichez le menu contextuel d'un des fichiers de données de l'analyse et sélectionnez l'option "Générer une classe modèle".




2. Dans la fenêtre qui s'affiche, indiquez la classe pattern à utiliser : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Classe_modele%20-%20HC%20N%B0003.gif)


	- **La classe pattern intégrée à WINDEV**. Dans ce cas, la classe liée au fichier de données sera automatiquement générée. 
			Exemple de code de déclaration de la classe MLigneCommande généré : 
			
		```wl
		MLigneCommande est une Classe <MAPPING=LigneCommande>
		
			// Le code se trouvant entre <MAPPING> et <FIN> est généré automatiquement.
			// Il sera effacé et recréé entièrement à chaque génération
			<MAPPING>
			m_IDCommande est un entier <MAPPING=IDCommande>
			m_Référence est une chaîne <MAPPING=Référence>
			m_Quantité est un entier sans signe sur 4 octets <MAPPING=Quantité>
			m_TotalHT est un monétaire <MAPPING=TotalHT>
			m_TotalTTC est un monétaire <MAPPING=TotalTTC>
			<FIN>
		FIN
		```


- Utiliser **une classe pattern du projet** (cas par défaut si une classe pattern a déjà été générée sur le même fichier de données). 

- Utiliser une classe pattern présente sur le disque. 

- Générer une classe pattern. Le bouton "Créer votre classe pattern personnalisée" permet de créer la classe pattern utilisée pour générer les différentes classes modèles dans votre projet. Une classe "CMdl" est automatiquement créée. Le code généré est le suivant : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Classe_modele%20-%20HC%20N%B0004.gif)
Lors de la génération des classes modèle, ce fichier pourra être utilisé. 
			Il est possible de personnaliser le code généré en saisissant le code voulu avant et après les balises &lt;MAPPING&gt; et &lt;FIN&gt;. Le code situé entre ces deux balises sera automatiquement généré lors de la génération des classes modèle. 




Pour générer la classe modèle en utilisant la classe pattern personnalisée : 

1. Dans le volet "Explorateur de projet", utilisez une des méthodes suivantes : 

	- Affichez le menu contextuel du dossier "Classe" et sélectionnez l'option "Créer une classe liée à une description de fichier". Sélectionnez ensuite le fichier de données concerné. 

	- Affichez le menu contextuel d'un des fichiers de données de l'analyse et sélectionnez l'option "Générer une classe modèle".




2. Dans la fenêtre qui s'affiche, indiquez la classe pattern à utiliser : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Classe_modele%20-%20HC%20N%B0005.gif)


	- la classe pattern intégrée

- la classe pattern déjà présente (si vous avez générée la classe pattern personnalisé dans le projet). 

- la classe pattern présente sur le disque.
