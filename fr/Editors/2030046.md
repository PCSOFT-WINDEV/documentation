


## Description du projet : Onglet Projet
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000300"></a>
La fenêtre de description du projet permet de configurer de nombreux éléments de votre projet. Cette fenêtre est constituée des onglets suivants :

- L'onglet **"Projet"** qui permet de saisir les informations générales du projet.

- L'onglet "Analyse" qui permet d'associer une ou plusieurs analyses au projet et / ou un modèle UML.

- L'onglet ["Fichiers de données"](../Editeurs/2030052.md) qui permet de saisir différentes informations sur les fichiers de données gérés par l'application (uniquement disponible si le projet est lié au moins à une analyse).

- L'onglet "Live data" qui permet de configurer l'affichage des données (provenant des fichiers de données) sous les différents éditeurs.

- L'onglet ["Langues"](../Editeurs/9500219.md) qui permet de paramétrer les différentes langues manipulées par le projet ainsi que les options linguistiques à utiliser pour chaque langue.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/fr/WM.png) L'onglet ["Style"](../Editeurs/9500234.md) qui permet de choisir le thème de gabarit, la feuille de styles personnalisée et de personnaliser l'aperçu avant impression. Il est également possible de paramétrer la taille des écrans.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) L'onglet ["Ambiance"](../Editeurs/1410087360.md) qui permet de choisir l'ambiance du projet, la palette associée, la feuille de styles et les ressources externes. 

- L'onglet ["GDS"](../Editeurs/9500239.md) qui permet de gérer le travail en groupe (GDS ou GIT).

- L'onglet ["Options"](../Editeurs/9500227.md) qui permet de configurer les options de création, de mise à jour, et de sauvegarde des éléments. Cet onglet permet également de gérer la synchronisation des modèles, d'activer le mode strict et de définir la charte de programmation.

- L'onglet ["Avancé"](../Editeurs/9500236.md) qui permet de gérer l'utilisation de "Etats & Requêtes", les FAA et le verrouillage de l'application.

- L'onglet ["Compilation"](../Editeurs/9500218.md) qui permet de configurer les options de compilation.

- L'onglet ["Télémétrie"](../Editeurs/9500223.md) qui permet de configurer les options de télémétrie pour le projet. 
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette option n'est pas disponible.

### Informations sur le projet
<a name="informations_sur_projet_ELTPARAGRAPHE000090"></a>Les informations sur le projet concernent :

- **le nom et le répertoire du projet**. Ces informations ne peuvent pas être modifiées. Si vous voulez changer le répertoire du projet, il est conseillé de faire une copie du projet grâce à l'explorateur Windows.

- **la description du projet** : Ce champ permet de saisir un résumé sur le but du projet. Cette description sera reprise dans la documentation technique du projet.

- **le répertoire de la liste des tâches**. Pour plus de détails, consultez [Liste des tâches](../Editeurs/2021004.md).

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) **Icône du site**. Permet de définir l'[icône du site (favicone)](../Editeurs/2030061.md).

### Outils de mesure de statistiques
<a name="outils_mesure_statistiques_ELTPARAGRAPHE000178"></a>WEBDEV permet d'utilisation de plusieurs outils de statistiques sur un projet. Il est possible d'utiliser : 

- Google Analytics 4 ou Universal Analytics

- Matomo, etc.




**Pour lier Google Analytics et votre site**, il est nécessaire de :

1. Définir un compte dans Google Analytics. Ce compte doit être lié à votre site.

2. Récupérer l'identifiant de suivi Google Analytics associé à votre compte.

3. Renseigner dans la fenêtre de description du projet WEBDEV :

	- l'identifiant de suivi.

	- le mode de gestion utilisé : Google Analytics 4 ou Universal Analytics. 
			
	<B><B><B><B>Avertissement</B></B></B></B>

	 Au 1er Juillet 2023, Google Analytics passe de Universal Analytics à Google Analytics 4. WEBDEV 2026 gère les deux versions. Les fonctions WLangage ont été adaptées. Pour les projets existants, le mode par défaut correspond à Universal Analytics par défaut. Pour les nouveaux projets, le mode par défaut correspond à Google Analytics 4.






4. Déployer le projet WEBDEV.


Pour plus de détails, consultez [WEBDEV et Google Analytics](../WDLang2/1000022374.md). 

**Pour utiliser l'outil de Web analyse MATOMO**, il est nécessaire de : 

1. Définir un compte dans Matomo ([https://fr.matomo.org](https://fr.matomo.org)) en indiquant votre adresse email et l'adresse de votre site. 

2. Choisir la méthode de suivi voulue. Dans notre cas, sélectionnez "Installer avec Code Javascript". 

3. Copier le code JavaScript proposé. 

4. Coller le code JavaScript dans le champ "Entête HTML personnalisée (Matomo, etc.)". Par exemple : 
	
	```txt
	<!-- Matomo -->
	<script>
	  var _paq = window._paq = window._paq || [];
	  /* tracker methods like "setCustomDimension" should be called before "trackPageView" */
	  _paq.push(['trackPageView']);
	  _paq.push(['enableLinkTracking']);
	  (function() {
	    var u="https://xxxx.matomo.cloud/";
	    _paq.push(['setTrackerUrl', u+'matomo.php']);
	    _paq.push(['setSiteId', '1']);
	    var d=document, g=d.createElement('script'), s=d.getElementsByTagName('script')[0];
	    g.async=true; g.src='https://cdn.matomo.cloud/xxx.matomo.cloud/matomo.js'; s.parentNode.insertBefore(g,s);
	  })();
	</script>
	<!-- End Matomo Code -->
	```

### Licence Google Maps API
<a name="licence_google_maps_api_ELTPARAGRAPHE000229"></a>Il est obligatoire de spécifier une clé de licence pour utiliser le service de cartographie Google.
Vous devez posséder un compte Développeur Google pour obtenir une clé Google Maps API. Consultez la licence Google pour connaître les conditions d'utilisation (service gratuit ou payant, quota d'utilisation, etc.).
Le compte développeur Google permet de générer une clé Google Maps. Cette clé peut être indiquée dans la description du projet ou via la fonction [CarteLicenceGgl](../WDLang3/1000021299.md).

Pour plus de détails, consultez [Champ Carte](../WDChamp/1000019755.md).
