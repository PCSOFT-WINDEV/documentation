
## Comment utiliser les nouveautés spécifiques à l'abonnement dans vos projets ? 
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000156"></a>
A partir de la version 2025 Update 1, des nouveautés spécifiques à WINDEV Suite version Abonnement sont disponibles. Ces nouveautés seront utilisables dans votre projet uniquement si ce dernier est ouvert dans un produit en version Abonnement et si ce projet est en "Mode Abonnement". 

**Attention : Un projet en "Mode Abonnement" ne peut plus être utilisé dans une version avec clé.**

## Comment utiliser les nouveautés spécifiques à l'abonnement dans vos projets ?
<a name="comment_utiliser_les_nouveautes_specifiques_abonnement_dans_vos_projets_ELTTEXTE000180"></a>


### Utiliser les nouveautés de WINDEV Suite version Abonnement
<a name="utiliser_les_nouveautes_windev_suite_version_abonnement_ELTPARAGRAPHE000018"></a>Pour utiliser les nouveautés spécifiques à l'abonnement dans vos projets, deux solutions : 

- Depuis le tableau de bord : 
	Dans le widget correspondant au projet, l'interrupteur "Abonnement" permet d'indiquer si le projet peut utiliser les nouveautés de la version Abonnement. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Projet_SaaS%20-%20HC%20N%B0001.gif)


- Depuis la fenêtre de description du projet : dans l'onglet "Options", il suffit de cocher l'option "Autoriser l'utilisation des fonctionnalités WINDEV Suite Abonnement dans le projet". <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Projet_SaaS%20-%20HC%20N%B0002.gif)





Attention : Lorsque cette option est active le projet passe en "Mode Abonnement" : tous ses éléments ne peuvent plus être manipulés par une version de WINDEV avec clé. Le projet ne sera plus compatible. 

Tant que le mode "Abonnement" n'est pas activé, le projet et ses éléments gardent un format compatible entre les deux versions du produit (version Abonnement et version avec clé). 

**Cas particulier : Je travaille pour plusieurs clients qui utilisent soit une version avec clé, soit une version Abonnement. Quelle version doit être utilisée ?**
Il suffit d'utiliser une version Abonnement pour travailler avec tous les projets. En effet, tous les types de projets peuvent être ouverts avec cette version. Le "mode Abonnement" permettra de déterminer si des nouveautés spécifiques à la version Abonnement pourront être intégrées ou non dans le projet. Ainsi : 

- les projets pour des clients utilisant la version 2025 avec clé n'auront pas l'option "Abonnement" activée.

- les projets pour les clients utilisant WINDEV Suite Abonnement 2025 seront en "Mode Abonnement" et pourront bénéficier des nouveautés spécifiques Abonnement.

## Configuration par défaut et changement de mode
<a name="configuration_par_defaut_changement_mode_ELTTEXTE000204"></a>


### Ouverture d'un projet existant avec WINDEV Suite version Abonnement
<a name="ouverture_projet_existant_avec_windev_suite_version_abonnement_ELTPARAGRAPHE000046"></a>A partir de WINDEV Suite 2025 Update 1 (version Abonnement), ce projet reste par défaut en version compatible. Il pourra être manipulé avec WINDEV Suite version Abonnement et version avec clé tant que l'option "Abonnement" n'est pas activée sur le projet.  


### Création d'un nouveau projet avec WINDEV Suite version Abonnement
<a name="creation_nouveau_projet_avec_windev_suite_version_abonnement_ELTPARAGRAPHE000051"></a>A partir de WINDEV Suite 2025 Update 1 (version Abonnement), les nouveaux projets créés sont automatiquement en "Mode Abonnement". Par défaut, ils ne peuvent pas être utilisés avec la version avec clé. 


### Désactiver le "mode Abonnement" sur un projet
<a name="desactiver_mode_abonnement_sur_projet_ELTPARAGRAPHE000056"></a>Il est possible de désactiver le "mode Abonnement" sur un projet : il suffit de désactiver l'option "Abonnement" correspondante. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Projet_SaaS%20-%20HC%20N%B0003.gif)


Dans ce cas, toutes les fonctionnalités utilisées spécifiques à l'abonnement ne seront plus disponibles dans le projet. Le projet est recompilé. Des erreurs de compilation du type "Les fonctionnalités WINDEV Suite Abonnement ne sont pas autorisées dans le projet" peuvent apparaître si vous avez utilisé des fonctionnalités ou des syntaxes disponibles uniquement dans un projet en "Mode Abonnement".
Après correction des éventuelles erreurs, le projet pourra de nouveau être utilisé avec une version avec clé.

## Cas particuliers
<a name="cas_particuliers_ELTTEXTE000240"></a>


### Projet et configurations de projet
<a name="projet_configurations_projet_ELTPARAGRAPHE000071"></a>Le mode Abonnement s'applique à la totalité des éléments du projet, et à toutes ses configurations de projet. Un même projet ne peut pas avoir une configuration de projet avec le mode Abonnement activé, et une autre configuration qui n'aurait pas le mode Abonnement actif.


### Partage d'analyse
<a name="partage_analyse_ELTPARAGRAPHE000076"></a>Une analyse peut être partagée entre un projet en "Mode Abonnement" et un projet qui n'a pas l'option "Abonnement" activée.


### Composant interne
<a name="composant_interne_ELTPARAGRAPHE000081"></a>Un composant interne ne peut pas être partagé entre un projet en "Mode Abonnement" et un projet qui n'a pas l'option "Abonnement" activée.


### Composant externe
<a name="composant_externe_ELTPARAGRAPHE000086"></a>Un composant externe provenant d'un projet en "Mode Abonnement" ne peut pas être importé dans un projet qui n'a pas l'option "Abonnement" activée. De même, un exécutable créé avec un projet dans un projet qui n'a pas l'option "Abonnement" activée, ne peut pas utiliser en exécution un composant générée par un projet en "Mode Abonnement". 


### Serveur HFSQL Client/Serveur
<a name="serveur_hfsql_clientserveur_ELTPARAGRAPHE000091"></a>Il est possible d'utiliser un serveur HFSQL Client/Serveur aussi bien avec une application générée via un projet en "Mode Abonnement" qu'avec une application générée avec un projet qui n'a pas l'option "Abonnement" activée. 


### GDS (Gestionnaire de Sources)
<a name="gds_gestionnaire_sources_ELTPARAGRAPHE000096"></a>Pour les projets synchronisés avec le GDS, la colonne "VI" (disponible dans l'administrateur du GDS) aura un "S" en premier pour différencier les éléments enregistrés avec le mode Abonnement activé. Par exemple : "S1A302028". 




### Patch d'application
<a name="patch_application_ELTPARAGRAPHE000103"></a>Un exécutable compilé à partir d'un projet qui n'est pas en "Mode Abonnement" ne peut pas charger un patch d'application créé avec un projet en "Mode Abonnement". 
Si les patchs sont utilisées dans un projet pour déployer des mises à jour, le déploiement qui suivra l'activation du mode Abonnement doit se faire avec un nouvel exécutable, et pas seulement un patch.
