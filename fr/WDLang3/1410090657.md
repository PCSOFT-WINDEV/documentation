
## Procédure WLangage appelée par la fonction PartageProximitéAccepteConnexion (Progression)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md) pour suivre la progression du transfert des données. Cette procédure permet de connaître l'état du transfert en cours.

**Remarque** : l'envoi de buffers binaires est toujours effectué en un seul bloc.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéAccepteConnexion(gsIDAppareilDistant, CallbackRéception, CallbackProgression)
	PROCÉDURE INTERNE CallbackRéception(sIdAppareil est une chaîne, nIdTransfert est un entier sur 8, 
					nType est un entier, donnee)
		LIB_Information_message_reçu = [
			Réception d'un message de l'appareil : [%sIdAppareil%]
			Identifiant de transfert : [%nIdTransfert%]
		]
		SELON nType
			CAS ppBuffer
				sMessage est une chaîne = donnee
				SAI_Message_reçu = sMessage
				SAI_Message_reçu.Etat = Inactif
			CAS ppFichier
				BTN_Ouvrir_le_fichier_reçu.Etat = Actif
				gsFichierReçu = donnee
			FIN
	FIN
	PROCÉDURE INTERNE CallbackProgression(sIdAppareil est une chaîne, nIdTransfert est un entier sur 8, 
		nEtat est un entier, nTailleReçu est un entier sur 8, 
		nTailleTotale est un entier sur 8)
		Message est une chaîne
		SELON nEtat
			CAS ppEnCours
				Message = [
						Transfert en cours : 
						[%Arrondi(nTailleReçu / nTailleTotale * 100, 2)%]% 
						des informations ont été transmises.
						]
				ToastAffiche(Message)
			CAS ppTerminé
				Message = [
					Transfert d'information terminé : 
					[%Arrondi(nTailleReçu / nTailleTotale * 100, 2)%]% 
					des informations ont été transmises.
					]
				ToastAffiche(Message)
			CAS ppErreur
				ToastAffiche("Erreur lors du transfert" + RC + ErreurInfo())
			CAS ppAnnulé
				ToastAffiche("Transfert d'information annulé")
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéAccepteConnexion_Callback_Progression(<Identifiant de l'appareil expéditeur> , <Identifiant du transfert> , <Etat> , <Taille reçue> , <Taille totale>)`
---

**`<Identifiant de l'appareil expéditeur> : (Chaîne de caractères)`**

Identifiant de l'appareil distant expéditeur.

**`<Identifiant du transfert> : (Entier)`**

Identifiant du transfert en cours.

**`<Etat> : (Constante de type Entier)`**

Etat du transfert. Ce paramètre peut correspondre à une des constantes suivantes : 



|   |   |
| --- | --- |
| *ppAnnulé* | Transfert annulé. |
| *ppEnCours* | Transfert en cours. |
| *ppErreur* | Transfert en erreur. |
|  *ppTerminé* | Transfert terminé. |



**`<Taille reçue> : (Entier)`**

Taille des données déjà reçues (en octets). 

**`<Taille totale> : (Entier)`**

Taille totale des données transférées (en octets).
