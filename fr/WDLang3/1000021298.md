


## grSMNPortionRacine (Fonction)

***En anglais : grSunburstRootSection***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Change ou précise le chemin de la racine dans un graphe de type Secteur multiniveau.

**Remarque** : Cette fonction permet de se déplacer dans la hiérarchie du graphe (drill down ou drill up).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
grSMNPortionRacine(GRF_Graphe, "Europe" + TAB + "France")
grDessine(GRF_Graphe)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grSMNPortionRacine(<Nom du graphe> , <Chemin de la portion>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Dans les pages, seuls les champs "Graphe interactif" sont disponibles pour les graphes de type Secteur multiniveau.

**`<Chemin de la portion> : (Chaîne de caractères)`**

Chemin complet de la portion à utiliser en racine. Ce paramètre est de la forme :

```txt
"<Nom du niveau de base>" + TAB + ["<Nom du 1er niveau>" + TAB + ...
["<Nom du dernier niveau>" + TAB + [...]]]"<Nom de la portion>"
```


Ce chemin détermine la position de la portion, en précisant ses différents niveaux hiérarchiques. 

Si le chemin n'existe pas, la racine globale du graphe est utilisée.
