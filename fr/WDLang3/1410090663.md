
## Paramètres de la procédure utilisée par la fonction PartageProximitéRechercheAppareil (Résultat)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéRechercheAppareil](../WDLang3/1410090648.md) pour notifier la réussite ou l'échec du démarrage de la recherche.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Code de l'interrupteur permettant d'activer ou non la recherche des appareils
INT_Recherche.Etat = Grisé
SI INT_Recherche ALORS
	PartageProximitéRechercheAppareil(CallbackRésultat, CallbackDécouverte, gnTopologieDeRéseau)
SINON
	PartageProximitéArrêteRecherche()
	INT_Recherche.Etat = Actif
FIN
		PROCÉDURE INTERNE CallbackRésultat(bRésultat est un booléen)
			SI bRésultat ALORS
				INT_Recherche.Etat = Actif
			SINON
				Info("Échec de la recherche d'appareils ou de l'attente de connexion :" + RC + ErreurInfo())
			FIN
		FIN
```

```wl
PROCÉDURE CallbackDécouverte(bDecouverte est un booléen, sIdAppareil est une chaîne, sNomAppareil est une chaîne)
SI bDecouverte ALORS
	ToastAffiche("Appareil découvert : " + sNomAppareil)
SINON
	ToastAffiche("Appareil indisponible : " + sNomAppareil)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéRechercheAppareil_Callback_Résultat(<Résultat>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la recherche a été lancée,

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour plus de détails sur le problème rencontré, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).
