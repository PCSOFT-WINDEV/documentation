
## RendezVousRAZ (Fonction)

***En anglais : AppointmentReset***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Réinitialise : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) la structure [RendezVous](../WDLang3/1000011010.md).
	**Rappel** : Cette fonction ne permet pas de réinitialiser la structure RendezVous d'une messagerie Outlook Express.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) la variable de type [RendezVous](../WDLang1/1000019244.md) utilisée par un calendrier (ou agenda) d'un appareil Android. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) 
```wl
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Initialisation des variables de la structure RendezVous
RendezVousRAZ()
// Renseignements des variables pour le nouveau rendez-vous
mRendezVous.Objet = "Réunion commerciaux"
mRendezVous.DateDébut = "20070125100000"
mRendezVous.Lieu = "Salle 3B"
mRendezVous.NbParticipant = 3
mRendezVous.Participant[1] = "Romain"
mRendezVous.Participant[2] = "Lucas"
mRendezVous.Participant[3] = "Stéphane"
// Ajout du rendez-vous
SI RendezVousAjoute(IDSession) = Vrai ALORS
	Info("Rendez-vous ajouté")
SINON
	Erreur("Erreur lors de l'ajout", ErreurInfo())
FIN
```


<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
```wl
// Ajout d'un nouveau rendez-vous
RendezVousRAZ(gRDV)
gRDV.Titre = SAI_Titre
gRDV.DateDébut = SAI_DateDeb + SAI_HeureDeb
gRDV.DateFin = SAI_DateFin + SAI_HeureFin
gRDV.Lieu = SAI_Lieu
gRDV.Contenu = SAI_Desc
SI SAI_Fuseau <> "" ALORS
	gRDV.FuseauHoraire = SAI_Fuseau
FIN
gRDV.Auteur = SAI_Auteur
gRDV.Invité = SAI_Invités
gRDV.JournéeEntière = INT_Jentière[1]

SI RendezVousAjoute(gCal, gRDV) ALORS
	ToastAffiche("RDV ajouté")
SINON
	Erreur(ErreurInfo())
FIN
```
