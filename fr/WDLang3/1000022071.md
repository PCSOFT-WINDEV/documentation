


## BTLECaractéristiqueChangementValeur (Fonction)

***En anglais : BTLECharacteristicChangeOfValue***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Active ou désactive la détection des changements de valeur d'une caractéristique Bluetooth Low Energy. 

Par exemple, lors de l'utilisation d'un capteur de température, il est possible de savoir que la température change. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
caractéristique est une btleCaractéristique
BTLECaractéristiqueChangementValeur(caractéristique, CB_ChangementValeur)
// ===========================
PROCÉDURE CB_ChangementValeur(caractéristique est une btleCaractéristique <utile>, bufValeur est un Buffer)
// Récupération de la valeur et affichage dans un champ Libellé
sBuf est une chaîne ANSI = bufValeur
LIB_ValeurAbonnement = sBuf
```

```wl
crtq est une btleCaractéristique
BTLECaractéristiqueChangementValeur(crtq)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Demander à être prévenu à chaque changement de la valeur d'une caractéristique

`BTLECaractéristiqueChangementValeur(<Caractéristique> [, <Procédure WLangage>])`
---

**`<Caractéristique> : (Variable de type btleCaractéristique)`**

Nom de la variable de type [btleCaractéristique](../WDLang3/1000022060.md) correspondant à la caractéristique à manipuler.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (appelée "callback") appelée lorsqu'une caractéristique change sur l'appareil. Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction BTLECaractéristiqueChangementValeur](../WDLang3/1000024784.md).


<a name="SYNTAXE2"></a>

### Arrêter la détection des changements de valeur d'une caractéristique

`BTLECaractéristiqueChangementValeur(<Caractéristique>)`
---

**`<Caractéristique> : (Variable de type btleCaractéristique)`**

Nom de la variable de type [btleCaractéristique](../WDLang3/1000022060.md) correspondant à la caractéristique à manipuler.
