
## NotifPushDésabonne (Fonction)

***En anglais : NotifPushUnsubscribe***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Désabonne l'application Android des notifications push envoyées pour le sujet spécifié. L'application ne recevra plus les notifications push envoyées avec la fonction [NotifPushEnvoieAbonné](../WDLang3/1410089872.md) pour le sujet spécifié.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// L'application ne recevra plus les notifications push relatives au thème "score"
NotifPushDésabonne("score")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = NotifPushDésabonne(<Sujet>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le désabonnement a été effectué, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître l'erreur renvoyée par le service de notification.




**`<Sujet> : (Chaîne de caractères)`**

Sujet (ou topic) associé aux notifications push auxquelles l'application veut se désabonner.
