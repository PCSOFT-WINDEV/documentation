


## ContactRAZ (Fonction)

***En anglais : ContactReset***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Réinitialise : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png) la structure [Contact](../WDLang3/1000006111.md). Cette structure permet de manipuler le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [Contact](../WDLang3/1000020254.md). 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 
```wl
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Initialisation des variables de la structure Contact
ContactRAZ()
// Renseignements des variables pour le nouveau contact
mContact.Nom = "Dupont"
mContact.Prénom = "Axelle"
mContact.Email = "axelle.dupont@mesmails.com"
// Ajout du contact
SI ContactAjoute(IDSession) = Vrai ALORS
	Info("Contact ajouté")
SINON
	Erreur("Erreur lors de l'ajout", ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Réinitialiser la structure Contact

`ContactRAZ()`
---


<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
### Réinitialiser les variables de type Contact

`ContactRAZ([<Contact>])`
---

**`<Contact> : (Variable de type Contact)`**

Nom de la variable de type [Contact](../WDLang3/1000020254.md) à réinitialiser.
