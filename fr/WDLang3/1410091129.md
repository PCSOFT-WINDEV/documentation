


## &lt;Variable ftpConnexion&gt;.RenommeFichier (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.RenameFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renomme ou déplace un fichier (ou un répertoire) présent sur un serveur FTP (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

<a name="Exemple3"></a>

```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()

// Le fichier "/Documents/Fichier.txt" est renommé "/Documents/Essai.txt"
Res = MaConnexionFTP.RenommeFichier("/Documents/Fichier.txt", "/Documents/Essai.txt")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Connexion FTP>.RenommeFichier(<Fichier/Répertoire à renommer> , <Nouveau nom du fichier/répertoire>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été renommé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.

**`<Fichier/Répertoire à renommer> : (Chaîne de caractères)`**

Nom et chemin absolu (ou relatif) du fichier ou du répertoire à renommer. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/").

**`<Nouveau nom du fichier/répertoire> : (Chaîne de caractères)`**

Nouveau nom et chemin absolu (ou relatif) du fichier ou du répertoire. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/"). Si le chemin spécifié par ce paramètre est différent du chemin initial, le fichier à renommer est déplacé.

## Remarques
<a name="NOTE0_2"></a>


### Délai
<a name="delai_ELTPARAGRAPHE000280"></a>Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
<a name="NOTE0_4"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000313"></a>La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
<a name="NOTE0_5"></a>


### Chemin relatif et absolu
<a name="chemin_relatif_absolu_ELTPARAGRAPHE000325"></a>Les notions de chemin relatif et de chemin absolu sont très importantes dans une application FTP.

- Un chemin commençant par un slash est considéré comme un **chemin absolu** : il s'agit du chemin par rapport à la racine du serveur FTP (paramètre propre au serveur).
	ex: /pub/user/JULIE

- Si le chemin ne commence pas par un slash, il est considéré comme un **chemin relatif**, c'est-à-dire le chemin par rapport au répertoire en cours. Ce répertoire en cours peut-être connu ou modifié avec la fonction [&lt;Variable ftpConnexion&gt;.RepEnCours](../WDLang3/1410091131.md).




Lors de la connexion à un site FTP, le répertoire initial, le "home directory" de l'utilisateur n'est pas forcément la racine du serveur FTP. Il est donc conseillé d'utiliser des chemins relatifs.
