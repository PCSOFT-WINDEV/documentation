


## CarteRécupèrePosition (Fonction)

***En anglais : MapGetPosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la position géographique du point situé au centre de la carte actuellement affichée dans un champ Carte.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) **Remarque** : Cette fonction est disponible dans l'émulateur Android et dans le simulateur Android.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
```wl
// Retourne le point de la carte correspondant à la position courante de l'utilisateur
MaPosition est une géoPosition
MaPosition = CarteRécupèrePosition(CARTE_Position)
SI ErreurDétectée = Faux ALORS
	RENVOYER CarteInfoPosition(CARTE_Position, MaPosition)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CarteRécupèrePosition([<Champ Carte>])`
---

**`<Résultat> : (Variable de type géoPosition)`**

Variable de type [géoPosition](../WDLang3/1000019191.md) correspondant à la position géographique du point actuellement affiché au centre du champ Carte.

![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et le détail de l'erreur peut être obtenu avec la fonction [ErreurInfo](../WDLang1/3013008.md).

**`<Champ Carte> : (Nom de champ optionnel)`**

Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, le champ Carte auquel appartient l'événement en cours sera utilisé.
