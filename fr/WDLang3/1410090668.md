
## PartageProximitéArrêteTout (Fonction)

***En anglais : NearbyShareStopAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête le ou les partages de proximité en cours : 

- arrêt de l'attente de connexion, 

- arrêt de la recherche d'appareils distants, 

- déconnexion de tous les appareils actuellement connectés.

<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéArrêteTout()
```
