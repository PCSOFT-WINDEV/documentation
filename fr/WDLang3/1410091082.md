
## apiRéponse (Type de variable)

***En anglais : apiResponse***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **apiRéponse** permet d'obtenir le résultat d'une requête envoyée sur une API REST précédemment importée. Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Réponse est une apiRéponse
// Appel de la fonction de l'API
Réponse = MonApi.RécupèreClient(1)
// Lecture d'un élément de l'entête
nb_requetes_restantes est un entier = Réponse.Entête["Rate-Limit"]
// Lecture de la réponse de la fonction
client est un MonApi.Client = Réponse.Valeur
```

<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type apiRéponse
<a name="proprietes_specifiques_description_des_variables_type_apireponse_ELTPARAGRAPHE000031"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **apiRéponse** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Entête | Tableau associatif de chaînes de caractères | Ensemble clé/valeur des entêtes reçues. |
| RéponseHTTP | Variable de type [httpRéponse](../WDLang3/1000021165.md) | Réponse HTTP brute du Webservice REST. <br><br>**Cette propriété est disponible en lecture seulement.** |
| TypeValeurRetour | Variable de type [Définition](../WDLang1/1000019540.md) | Type de la valeur. <br>**Cette propriété est disponible en lecture seulement.** |
| Valeur | <br><br> | Valeur de la réponse. <br><br>Cette valeur est déduite : <br><br>- de la documentation du Webservice REST. <br><br>- du contenu de la réponse HTTP. <br><br>- des entêtes. <br><br><br><br><br>Cette valeur peut correspondre à : <br><br>- un type simple : entier, chaîne de caractères, numérique, booléen, etc. Le type mime correspondant est "octet-stream".<br><br>- un tableau de types simples. <br><br>- un contenu JSON. Le type mime correspondant est "application/json".  <br><br><br><br><br>Si cette valeur est vide, un problème est survenu. Dans ce cas, il est conseillé d'analyser le contenu des propriétés **TypeValeurRetour** et **RéponseHTTP**. <br><br>**Cette propriété est disponible en lecture seulement.** |
