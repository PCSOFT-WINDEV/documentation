


## zipNbPartie (Fonction)

***En anglais : zipNbPart***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nombre de sous-archives (parties) d'une archive au format CAB, RAR, ZIP, WDZ, 7z, gzip, TAR ou TGZ (TAR.GZ).

## Syntaxe

`<Résultat> = zipNbPartie(<Archive>)`
---

**`<Résultat> : (Entier)`**

Nombre de parties présentes dans l'archive spécifiée :

- 1 : si l'archive est mono-partie ou si l'archive multi-parties contient une seule sous-archive.

- n : si l'archive est multi-parties.




**`<Archive> : (Chaîne de caractères ou variable de type zipArchive)`**

Nom de l'archive à manipuler.
Ce nom peut correspondre :

- soit au nom d'une archive défini avec la fonction [zipOuvre](../WDLang3/3082044.md) ou la fonction [zipCrée](../WDLang3/3082003.md).

## Remarques


### Une archive multi-parties peut être constituée d'une seule partie
<a name="une_archive_multiparties_peut_etre_constituee_une_seule_partie_ELTPARAGRAPHE000108"></a>Une archive multi-parties peut être composée d'une seule sous-archive (partie). En effet, lors du découpage d'une archive, la taille spécifiée pour les sous-archives peut être supérieure à la taille de l'archive.
