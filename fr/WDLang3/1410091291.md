
## wdbaasModifieUtilisateur (Fonction)

***En anglais : wdbaasEditUser***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie un utilisateur existant dans le serveur d'authentification OAuth WEBDEV. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Paramètres de connexion
param est un OAuth2Paramètres
param.ClientID = "d07c7d45-103c-48ad-a6b2-1bb9354eb947"
param.ClientSecret = "e260eeb0-15fb-4db7-964f-a72de7324e0d"
param.URLToken = "https://serveur/oauth2/v1/token"
param.TypeAutorisation = taApplicationCliente
param.Scope = "wdbaas:users:readwrite"
// Connexion
token_admin est un AuthToken = AuthIdentifie(param)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
// Nouvelles caractéristiques de l'utilisateur
utilisateur est un gpwUtilisateur
utilisateur.Login = "Test2"
utilisateur.Email = "test2@gmail.com"
utilisateur.Prénom = "bob dylan"
utilisateur.Activé = Vrai
// Modification de l'utilisateur
SI PAS wdbaasModifieUtilisateur(token_admin, ID_Utilisateur, utilisateur)
	Erreur(ErreurInfo())
	RETOUR
FIN
// Récupération des infos d'un utilisateur
utilisateur_modifié est un gpwUtilisateur = wdbaasInfoUtilisateur(token_admin, ID_Utilisateur)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
Trace(utilisateur_modifié.Login, utilisateur_modifié.Email, utilisateur_modifié.ID)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = wdbaasModifieUtilisateur(<Token> , <Identifiant utilisateur> , <Utilisateur>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si les informations concernant l'utilisateur ont été modifiées, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.  




**`<Token> : (Variable de type AuthToken)`**

Nom de la variable [AuthToken](../WDLang3/1000022220.md) correspondant au token d'identification sur le serveur OAuth. 

**`<Identifiant utilisateur> : (Entier)`**

Identifiant de l'utilisateur à manipuler. Cet identifiant est créé par la fonction [wdbaasCréeUtilisateur](../WDLang3/1410091289.md).  

**`<Utilisateur> : (Variable de type gpwUtilisateur)`**

Nom de la variable de type [gpwUtilisateur](../WDLang6/1000021088.md) contenant les nouvelles caractéristiques de l'utilisateur.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000173"></a>L'utilisation des fonctions de gestion d'un utilisateur sur un serveur OAuth WEBDEV nécessite la mise en place de droits au niveau de l'identifiant OAuth utilisé. Ces droits sont mis en place dans le site d'administration des services BaaS de WEBDEV. 

Il est possible par exemple de donner les droits suivants : 

- Autoriser la création d'utilisateurs uniquement.

- Autoriser la lecture des informations des utilisateurs.

- Tout autoriser (lecture, création, modification, suppression).

- etc. 




Pour plus de détails, consultez [Site d'administration des services BaaS](../WDLang3/1410086668.md).
