


## &lt;Variable ftpConnexion&gt;.Déconnecte (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.Disconnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme la connexion entre le poste en cours et le serveur FTP (File Transfer Protocol). Cette connexion a été établie avec la fonction [&lt;Variable ftpConnexion&gt;.Connecte](../WDLang3/1410091119.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()
...
// Déconnexion
MaConnexionFTP.Déconnecte()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Connexion FTP>.Déconnecte()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la déconnexion a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. La fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus de détails.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.

<a name="NOTE0_1"></a>

## Remarques


### Délai
<a name="delai_ELTPARAGRAPHE000268"></a>Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000298"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application. 
Permission requise : INTERNET 
Cette permission autorise l'application à ouvrir des sockets réseau.
