


## &lt;Variable ftpConnexion&gt;.Nom (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.Name***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol).

**Remarque** : La fonction **&lt;Variable ftpConnexion&gt;.Nom** est utile notamment lors d'un parcours de fichiers sur un serveur FTP au moyen de la fonction [&lt;Variable ftpConnexion&gt;.ListeFichier](../WDLang3/1410091126.md).


<a name="sample_code"></a>

## Exemple

<a name="Exemple2"></a>

```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()

// Nom du dernier fichier accédé par une fonction FTP
ResNom = MaConnexionFTP.Nom()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe
<a name="SYNTAXE2"></a>

`<Résultat> = Nom(<Connexion FTP>)`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom du dernier fichier accédé par une fonction FTP. Ce fichier a été modifié par une des fonctions FTP suivantes : [&lt;Variable ftpConnexion&gt;.Attribut](../WDLang3/1410091117.md), [&lt;Variable ftpConnexion&gt;.Date](../WDLang3/1410091120.md), [&lt;Variable ftpConnexion&gt;.Heure](../WDLang3/1410091125.md), [&lt;Variable ftpConnexion&gt;.Taille](../WDLang3/1410091134.md), [&lt;Variable ftpConnexion&gt;.ListeFichier](../WDLang3/1410091126.md).  

- Chaîne vide ("") en cas d'erreur.  Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) décrivant les caractéristiques de la connexion au serveur FTP. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Requête au serveur FTP
<a name="requete_serveur_ftp_ELTPARAGRAPHE000288"></a>La fonction **&lt;Variable ftpConnexion&gt;.Nom** ne provoque pas l'envoi d'une requête au serveur FTP.
<a name="NOTE0_2"></a>


### Délai
<a name="delai_ELTPARAGRAPHE000303"></a>Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
<a name="NOTE0_4"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000336"></a>La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
