


## &lt;Carte&gt;.FinDéplacement (Fonction)

***En anglais : &lt;Map&gt;.EndOfMove***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête le suivi du déplacement de l'appareil dans un champ Carte. Ce suivi de déplacement a été précédemment lancé avec la fonction [&lt;Carte&gt;.SuitDéplacement](../WDLang3/1000022464.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Démarre le suivi du déplacement dans le champ Carte 
CARTE_Position.SuitDéplacement()
...
// Stoppe le suivi du déplacement dans le champ Carte 
CARTE_Position.FinDéplacement()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Carte>.FinDéplacement()`
---

**`<Champ Carte> : (Nom de champ)`**

Nom du champ Carte à manipuler.
