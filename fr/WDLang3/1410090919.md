
## AuthRécupèreInfoUtilisateur (Fonction)

***En anglais : AuthGetUserInfo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère les informations concernant un utilisateur à partir d'un jeton d'accès (access token). 

Remarque : Cette fonction est notamment utile dans les Webservices pour connaître l'identité de l'utilisateur. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
token est un JSON = g_token.RéponseServeur
access_token est un JSON = token.access_token

Res est un JSON = AuthRécupèreInfoUtilisateur(access_token, "http://monserveur/oauth2/v1/userinfo")
Trace(Res)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = AuthRécupèreInfoUtilisateur(<Token d'accès> , <URL des informations utilisateur>)`
---

**`<Résultat> : (Chaîne de caractères au format JSON)`**

Chaîne de caractères au format JSON contenant les informations concernant l'utilisateur. 

**`<Token d'accès> : (Chaîne de caractères)`**

Token d'accès. 

**`<URL des informations utilisateur> : (Chaîne de caractères)`**

URL permettant de retrouver les informations concernant l'utilisateur.
