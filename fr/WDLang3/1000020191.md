
## AlbumSauve (Fonction)

***En anglais : AlbumSave***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sauve une image, une photo ou une vidéo dans l'album de photos de l'appareil mobile. Cette image pourra être réutilisée avec la fonction [AlbumSélecteur](../WDLang3/1000020186.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Sauvegarde d'une image présente dans une variable de type image
MonImage est une Image = "Test.png"
AlbumSauve(MonImage)
```


<a name="Exemple2"></a>



```wl
// Sauvegarde d'une photo
SI AlbumSauve(VidéoLanceAppli(viCaptureImage)) = Faux ALORS
	Info("Image non sauvegardée")
FIN
```


<a name="Exemple3"></a>


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
```wl
// Sauvegarde d'une vidéo
SI AlbumSauve(VidéoLanceAppli(viCaptureVidéo)) = Faux ALORS
	Info("Vidéo non sauvegardée")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Sauve une image présente dans une variable de type Image

`<Résultat> = AlbumSauve(<Image>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'enregistrement de l'image a réussi, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Image> : (Variable de type Image)`**

Nom de la variable de type [Image](../WDLang1/1000019650.md) correspondant à l'image à ajouter dans l'album.


<a name="SYNTAXE2"></a>

### Sauve une image présente dans un champ (Image ou Graphe)

`<Résultat> = AlbumSauve(<Nom du champ>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'enregistrement de l'image a réussi, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Nom du champ> : (Chaîne de caractères)`**

Nom du champ Image ou du champ Graphe contenant l'image à ajouter dans l'album.


<a name="SYNTAXE3"></a>

### Sauve une image présente dans un fichier

`<Résultat> = AlbumSauve(<Nom du fichier Image>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'enregistrement de l'image a réussi, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Nom du fichier Image> : (Chaîne de caractères)`**

Nom complet ou relatif du fichier image ou vidéo à ajouter dans l'album (par exemple, nom du fichier renvoyé par la fonction [VidéoLanceAppli](../WDLang1/1000019368.md)). 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Les vidéos pouvant être ajoutées dans l'album photos correspondent aux fichiers ayant pour extension : ".mp4", ".mov", ".avi" et ".mpg".

## Remarques
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Ajout d'une image dans l'album de photos
<a name="ajout_une_image_dans_album_photos_ELTPARAGRAPHE000111"></a>Lors de l'ajout d'une image dans l'album de photos, l'image est tout d'abord sauvée dans le répertoire public de stockage des images ou des vidéos de l'appareil puis référencée dans les albums de l'appareil.

Le répertoire public de stockage des images correspond à une mémoire externe (SD Card par exemple). Si ce répertoire n'est pas accessible, la fonction échouera. 
<a name="NOTE0_2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Photos présentes sur une mémoire externe
<a name="photos_presentes_sur_une_memoire_externe_ELTPARAGRAPHE000122"></a>Sous Android, les images et les vidéos présentes sur la mémoire externe (SDCard par exemple) de l'appareil sont scannées automatiquement par le système pour être ajoutées aux albums. 

Lors de l'ajout d'une image présente dans un fichier (syntaxe 3) : 

- si le fichier spécifié est présent sur la mémoire externe, la fonction sera sans effet. 

- si le fichier est présent dans un autre répertoire, le fichier sera copié dans le répertoire public de stockage des images ou des vidéos de l'appareil et référencé dans les albums de l'appareil.





![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000135"></a>L'utilisation de cette fonction entraîne automatiquement la modification des permissions requises par l'application.

Permissions requises :

- READ_EXTERNAL_STORAGE : Cette permission permet à une application de lire sur un stockage externe (carte mémoire, ...).

- WRITE_EXTERNAL_STORAGE : Cette permission permet à une application d'écrire sur un stockage externe (carte mémoire, ...).

- READ_MEDIA_VIDEO : Cette permission permet à une application de lire des fichiers vidéo à partir d'un stockage externe.

- READ_MEDIA_IMAGES : Cette permission permet à une application de lire des fichiers image à partir d'un stockage externe.




**Attention** : **A partir de Android 13**, lors d'une publication sur Google Play Store, les permissions READ_MEDIA_VIDEO, READ_MEDIA_IMAGES, READ_MEDIA_AUDIO nécessitent une justification de leur utilisation dans la console Google Play. Si nécessaire, il est possible de retirer les permissions depuis l'assistant de génération. Pour plus de détails, consultez [Stockage de fichiers sous Android](../WDLang1/1000021925.md).
