


## &lt;Variable sshSession&gt;.Commande (Fonction)

***En anglais : &lt;sshSession variable&gt;.Command***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Envoie une commande à un serveur SSH. La session est ouverte et refermée automatiquement après l'envoi de la commande.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
cMaSession est un sshSession
cMaSession.Adresse = "127.0.0.1"
cMaSession.Port = 22
cMaSession.Utilisateur = "login"
cMaSession.MotDePasseUtilisateur = "pass"
nExitCode est un entier
sSortie est une chaîne ANSI
sSortieErr est une chaîne ANSI
(nExitCode, sSortie, sSortieErr) = cMaSession.Commande(SAI_Commande)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
SAI_ExitCode = nExitCode
SAI_StdOut = UTF8VersChaîne(sSortie)
SAI_StdErr = UTF8VersChaîne(sSortieErr)
```

```wl
cMaSession1 est un sshSession
cMaSession1.Adresse = "127.0.0.1"
cMaSession1.Utilisateur = "login"
cMaSession1.MotDePasseUtilisateur = "pass"

bufDonnéesEnvoyées est un Buffer = 'Il est [%HeureVersChaîne(HeureSys, "HH:mm:SS")%]'
nExitCode est un entier
sSortie est une chaîne ANSI
sSortieErr est une chaîne ANSI
	
// Exécution d'une script Linux qui stocke les données envoyées dans un fichier 
// puis qui affiche le contenu du fichier sur la sortie standard
(nExitCode, sSortie, sSortieErr) = cMaSession1.Commande(...
	"echo $(</dev/stdin) > donnees_envoyees.txt; cat donnees_envoyees.txt", bufDonnéesEnvoyées)
Trace(sSortie) //Affiche le contenu du buffer bufEntréeStandard
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`(<Résultat>, <Données reçues>, <Données en cas d'erreur>) = <Session SSH>.Commande(<Commande> [, <Données à envoyer>])`
---

**`<Résultat> : (Entier)`**

Code de sortie de la commande.

**`<Données reçues> : (Buffer)`**

Données reçues du serveur.

**`<Données en cas d'erreur> : (Buffer)`**

Données reçues du serveur en cas d'erreur.

**`<Session SSH> : (Variable de type sshSession)`**

Nom de la variable de type [sshSession](../WDLang3/1000021157.md) correspondant à la session SSH sur laquelle la commande doit être exécutée.

**`<Commande> : (Chaîne de caractères)`**

Commande à envoyer au serveur SSH.

**`<Données à envoyer> : (Buffer optionnel)`**

Données à envoyer au serveur. Ces données seront lisibles depuis l'entrée standard (stdin).



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Keep Alive des sessions SSH
<a name="keep_alive_des_sessions_ssh_ELTPARAGRAPHE000214"></a>Il est possible d'activer la fonctionnalité "Keep Alive" lors de l'ouverture de la session SSH (propriété **IntervalleKeepAlive** de la variable de type [sshSession](../WDLang3/1000021157.md)). Le "Keep Alive" consiste à envoyer dans un délai plus ou moins long deux requêtes au serveur afin de conserver la connexion ouverte et de vérifier si le serveur répond toujours. La propriété **IntervalleKeepAlive** permet de définir la durée entre ces deux requêtes.  

Si le serveur SSH s'arrête brutalement lors d'une commande "longue" exécutée via la fonction **&lt;Variable sshSession&gt;.Commande**, l'activation du "Keep Alive" peut permettre de détecter la déconnexion de l'application au serveur.
