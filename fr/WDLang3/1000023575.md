


## Fonctions de gestion des protocoles OAuth et OpenID
			



**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des protocoles OAuth et OpenID (syntaxe préfixée)](../WDLang3/1000023630.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des protocoles OAuth et OpenID sont les suivantes :  



|   |   |
| --- | --- |
| [AuthDéconnecte](../WDLang3/1410090538.md) | Déconnecte un utilisateur précédemment authentifié via :<br><br>- le protocole OAuth 2.0 sur un service Web quelconque.<br><br>- le protocole OpenID sur un service Web quelconque.<br><br>- un token JWT.<br><br><br> |
| [AuthIdentifie](../WDLang3/1000022219.md) | Effectue une authentification utilisant le protocole OAuth 2.0 sur un webservice quelconque. |
| [AuthImporteToken](../WDLang3/1410089557.md) | Crée un token d'accès à un webservice à partir d'une description de token au format JSON. |
| [AuthIntrospecteToken](../WDLang3/1410090841.md) | Introspecte un token OAuth. |
| [AuthRécupèreInfoUtilisateur](../WDLang3/1410090919.md) | Récupère les informations concernant un utilisateur à partir d'un jeton d'accès (access token). |
| [AuthRenouvelleToken](../WDLang3/1000026168.md) | Renouvelle un token OAuth2 d'un utilisateur si ce token est expiré. |
| [AuthRévoqueToken](../WDLang3/1410090634.md) | Révoque un token JWT. |
| [AuthVérifieAuthentification](../WDLang3/1410090756.md) | Vérifie la validité du token de l'utilisateur courant dans le cas d'une authentification SSO. |
| [JWTCréeAssertion](../WDLang3/1410091014.md) | Crée une assertion JWT.<br> |
| [OpenIDLitIdentité](../WDLang3/1000023573.md) | Récupère l'identité d'un utilisateur contenue dans une variable de type [AuthToken](../WDLang3/1000022220.md). |







Les types de variables spécifiques aux protocoles OAuth et OpenID sont les suivants : 



|   |   |
| --- | --- |
| [AuthToken](../WDLang3/1000022220.md) | Le type **AuthToken** contient les caractéristiques d'un token d'accès à un service Web. |
| [JWTParamètres](../WDLang3/1410089572.md) | Le type **JWTParamètres** permet de définir toutes les informations nécessaires pour effectuer une authentification JWT. |
| [OAuth2Paramètres](../WDLang3/1000022212.md) | Le type **OAuth2Paramètres** permet de définir toutes les informations nécessaires pour s'authentifier sur un service Web implémentant le standard OAuth 2.0. |
| [OpenIDIdentité](../WDLang3/1000023567.md) | Le type **OpenIDIdentité** permet de définir toutes les caractéristiques avancées d'un utilisateur connecté à un service Web via le protocole OAuth 2.0. |
| [OpenIDParamètres](../WDLang3/1000023561.md) | Le type **OpenIDParamètres** permet de définir toutes les caractéristiques avancées d'une authentification pour OpenID. |
