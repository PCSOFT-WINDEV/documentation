
## ActionRapideSupprimeTout (Fonction)

***En anglais : QuickActionRemoveAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime toutes les actions rapides de l'application. Les actions rapides épinglées sur l'écran d'accueil seront désactivées (mais pas supprimées). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ActionRapideSupprimeTout()
```
