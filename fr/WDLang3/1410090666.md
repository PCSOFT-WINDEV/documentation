
## Paramètres de la procédure utilisée par la fonction PartageProximitéDemandeConnexion (Demande)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéDemandeConnexion](../WDLang3/1410090650.md) exécutée lorsque la demande de connexion a été reçue par l'appareil distant.

Dans le code de cette procédure, il est d'usage que d'accepter la connexion (fonction [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md)) ou de la refuser (fonction [PartageProximitéRefuseConnexion](../WDLang3/1410090651.md)).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéDemandeConnexion(gAppareilSélectionné.ID, ...
	gsNomAppareil, CallbackDemandeConnexion, CallbackConnexion)
```



```wl
PROCÉDURE CallbackDemandeConnexion(sIdAppareil est chaîne, sNomAppareil est une chaîne, sToken est une chaîne)
Info([
	ID : [%sIdAppareil%]
	Nom : [%sNomAppareil%]
])
```



```wl
PROCÉDURE CallbackConnexion(sIdAppareil est une chaîne, nEtat est un entier)
SELON nEtat
	CAS ppRefusConnexion
		ToastAffiche("La demande de connexion a été refusée.")
	CAS ppConnexion
		ToastAffiche(ChaîneConstruit("Vous êtes connecté à l'appareil %1.", sIdAppareil)
	CAS ppDéconnexion
		ToastAffiche("Vous êtes déconnecté.")
	CAS ppEchecConnexion
		ToastAffiche("La connexion a échoué." + ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéDemandeConnexion_Callback_Demande(<Identifiant de l'appareil> , <Nom de l'appareil> , <Jeton d'authentification>)`
---

**`<Identifiant de l'appareil> : (Chaîne de caractères)`**

Identifiant de l'appareil distant qui a reçu la demande la connexion.

**`<Nom de l'appareil> : (Chaîne de caractères)`**

Nom de l'appareil distant qui a reçu la demande de connexion. 
Ce nom correspond au nom d'appareil qui a été donné à la fonction [PartageProximitéAttendConnexion](../WDLang3/1410090655.md).

**`<Jeton d'authentification> : (Chaîne de caractères)`**

Chaîne de caractères courte et aléatoire permettant aux utilisateurs de confirmer qu'ils se connectent bien à l'appareil prévu.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion du jeton d'authentification
<a name="gestion_jeton_authentification_ELTPARAGRAPHE000053"></a>Les deux appareils reçoivent le même jeton. La vérification de ces jetons doit être effectuée par programmation. 

Une pratique courante consiste à afficher le jeton sur les deux appareils et de demander aux utilisateurs de comparer et de confirmer manuellement (comme dans le cas d'un couplage Bluetooth).

La fonction [PartageProximitéAccepteConnexion](../WDLang3/1410090646.md) permet d'afficher une boîte de dialogue pour afficher le jeton d'authentification. Il est alors possible d'accepter ou refuser la connexion.
