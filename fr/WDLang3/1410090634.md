


## AuthRévoqueToken (Fonction)

***En anglais : AuthRevokeToken***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Révoque un token JWT. 

Remarques : 

- La révocation consiste à exécuter une requête afin d'invalider le token spécifié.  A la prochaine connexion, le processus de connexion devra être entièrement refait.

- Lors de l'utilisation d'une variable de type [OAuth2Paramètres](../WDLang3/1000022212.md), il est nécessaire de spécifier l'URL de révocation avec la propriété **URLRévocation**. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
stOpenIdParam est un OpenIDParamètres
stOpenIdParam.URLConfiguration = "https://accounts.google.com/.well-known/openid-configuration"
stOpenIdParam.ClientID = "686331726510-0ojt7fqbkmtns8qjne242v5fuqb8v3tr.apps.googleusercontent.com"
stOpenIdParam.ClientSecret = "vEhFxP8I5AjppVFJsLYi0uKt"
stOpenIdParam.Scope = "email openid"
stOpenIdParam.URLRedirection = "http://localhost:9874"
stToken est un AuthToken = AuthIdentifie(stOpenIdParam)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
identite est un OpenIDIdentité = OpenIDLitIdentité(stToken)
 SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
Trace(identite.Email)
AuthRévoqueToken(stToken)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = AuthRévoqueToken(<Token de connexion>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la déconnexion a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Token de connexion> : (Variable de type AuthToken)`**

Nom de la variable de type [AuthToken](../WDLang3/1000022220.md) correspondant au token de la connexion.
