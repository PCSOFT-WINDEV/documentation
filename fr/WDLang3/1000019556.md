
## ContactCrée (Fonction)

***En anglais : ContactCreate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche la fenêtre de création de contact de l'application native de gestion des contacts de l'appareil (Android, iPhone ou iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
```wl
// Création d'un contact et initialisation de la structure Contact
SI ContactCrée() = Vrai ALORS
	Info(ChaîneConstruit("Le contact %1 a été ajouté à la liste de vos contacts : ", ...
		 mContact.Nom))
FIN
```


<a name="Exemple2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
```wl
gContactEnCours est un Contact
gtabContacts est un tableau de Contact

// Création d'un contact dans la fenêtre par défaut
SI ContactCrée() = Vrai ALORS
	// Rafraîchit la liste des contacts affichée dans un champ Zone répétée
	nIndice est un entier = ZR_CONTACTS
	ZoneRépétéeSupprimeTout(ZR_CONTACTS)
	// Liste des contacts
	gtabContacts = ContactListe()
	// Tri des contacts
	TableauTrie(gtabContacts, ttMembre, "+Nom")
	// Ajout dans la zone répétée
	POUR TOUT tContact DE gtabContacts
		ZoneRépétéeAjouteLigne(ZR_CONTACTS, tContact..Nom, tContact..Prénom)
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = ContactCrée([<Contact>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si un contact a été créé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Contact> : (Variable de type Contact)`**

Nom de la variable de type [Contact](../WDLang3/1000020254.md) contenant les données correspondant au contact créé.

<a name="NOTE0_1"></a>

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000066"></a>

- Si l'utilisateur crée un nouveau contact, la [structure Contact](../WDLang3/1000006111.md) ou la variable [Contact](../WDLang3/1000020254.md) est automatiquement renseignée avec les informations relatives à ce nouveau contact.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La fonction **ContactCrée** est bloquante jusqu'à ce que l'utilisateur valide ou annule la fenêtre de création de contact.

- La fonction **ContactCrée** peut être utilisée dans l'émulateur. Elle ne peut pas être utilisée dans le simulateur.



<a name="NOTE0_2"></a>


### Création d'un contact (sans utiliser la fenêtre de création)
<a name="creation_contact_sans_utiliser_fenetre_creation_ELTPARAGRAPHE000089"></a>Pour créer un nouveau contact entièrement par programmation (sans ouvrir de fenêtre) : 

1. Décrivez le contact à l'aide de la variable [Contact](../WDLang3/1000020254.md). 

2. Utilisez la fonction [ContactAjoute](../WDLang3/1000006101.md).



<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000262"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **ContactCrée** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
