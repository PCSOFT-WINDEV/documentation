
## RendezVousSupprime (Fonction)

***En anglais : AppointmentDelete***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook.
	**Rappel** : Cette fonction ne permet pas de supprimer le rendez-vous en cours de l'agenda d'une messagerie Outlook Express.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) un rendez-vous dans un calendrier (ou agenda) d'un appareil Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) un rendez-vous dans un calendrier (ou agenda) d'un appareil iOS.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) 
```wl
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier rendez-vous
RendezVousDernier(IDSession)
// Suppression du rendez-vous
RendezVousSupprime(IDSession)
```


<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
```wl
// Supprime le rendez-vous correspondant à l'identifiant <25>
tabRDV est un tableau de RendezVous
tabRDV = RendezVousListe(MonCalendrier, rdvIdentifiant, 25)
SI tabRDV..Occurrence > 0 ALORS
	RendezVousSupprime(tabRDV[1])
FIN
```

## Syntaxe

### Supprimer le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook 

`<Résultat> = RendezVousSupprime(<Identifiant de la session> [, <Identifiant du rendez-vous>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*. 




**`<Identifiant de la session> : (Entier)`**

Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](../WDLang3/3032121.md), [EmailOuvreSessionOutlook](../WDLang3/3032128.md), [NotesOuvreBase](../WDLang3/1000005101.md) ou [OutlookOuvreSession](../WDLang3/3032123.md).  

**`<Identifiant du rendez-vous> : (Chaîne de caractères optionnelle)`**

Identifiant du rendez-vous à supprimer. Cet identifiant est contenu dans la variable mRendezVous.ID.

### Supprimer un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS)

`<Résultat> = RendezVousSupprime(<Rendez-vous>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Rendez-vous> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) correspondant au rendez-vous à supprimer dans le calendrier de l'appareil mobile (Android/iOS).

## Remarques

### Agenda Android
<a name="agenda_android_ELTPARAGRAPHE000128"></a>La fonction **RendezVousSupprime** peut être utilisée dans l'émulateur mais pas dans le simulateur.
<a name="NOTE0_2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000142"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.
Permissions requises : 

- READ_CALENDAR : Cette permission autorise l'application à lire les données calendrier de l'utilisateur.

- WRITE_CALENDAR : Cette permission autorise l'application à écrire les données calendrier de l'utilisateur.
