


## &lt;Variable gglDrive&gt;.CopieFichier (Fonction)

***En anglais : &lt;gglDrive variable&gt;.CopyFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Copie un fichier de la suite Google présent dans le drive (disque distant) vers un autre répertoire du même drive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

DriveGoogle est un gglDrive
DriveGoogle = GglDriveConnecte(oOAuth2Param)

tabFicGgl est un tableau de FichierGgl
tabFicGgl = DriveListeFichierGgl(gglMonDrive, "/", frRécursif)

POUR TOUT MonFichier DE tabFicGgl
	SI DriveGoogle.CopieFichier(MonFichier, "/Sauvegardes/") = Faux ALORS
		Erreur("Impossible de copier le fichier demandé", ErreurInfo())
		RETOUR
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE2"></a>

`<Résultat> = <Drive Google>.DriveCopieFichier(<Fichier Source> , <Répertoire destination>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la copie a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive Google> : (Variable de type gglDrive)`**

Nom de la variable de type [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la copie n'est pas réalisée.

**`<Fichier Source> : (Variable de type FichierGgl)`**

Nom de la variable de type [FichierGgl](../WDLang3/1410089586.md) correspondant au fichier de la suite Google à manipuler.

**`<Répertoire destination> : (Chaîne de caractères)`**

Chemin du répertoire destination dans le drive dans lequel le fichier sera copié. Si ce chemin n'est pas valide, le fichier ne sera pas copié.
