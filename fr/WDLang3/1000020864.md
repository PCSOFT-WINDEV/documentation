
## SMSLanceAppli (Fonction)

***En anglais : SMSRunApp***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance l'application native d'envoi de SMS de l'appareil (Android ou iPhone/iPad). Le contenu et les destinataires du SMS sont initialisés à partir des informations renseignées dans la [structure SMS](../WDLang3/3068003.md) du WLangage.

Attention : Le SMS n'est pas envoyé. Seuls les champs de l'application d'envoi de SMS sont initialisés. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SMS.Numéro = "0610203040" 
SMS.Message = "J'envoie des SMS avec WINDEV Mobile !"
SMSLanceAppli()
```

<a name="XSYNTAXE"></a>

## Syntaxe

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000216"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **SMSLanceAppli** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
