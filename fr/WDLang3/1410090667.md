
## Paramètres de la procédure utilisée par la fonction PartageProximitéDemandeConnexion (Notification)



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéDemandeConnexion](../WDLang3/1410090650.md) exécutée pour notifier l'état de la connexion avec un appareil distant.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PartageProximitéDemandeConnexion(gAppareilSélectionné.ID, ...
	gsNomAppareil, CallbackDemandeConnexion, CallbackConnexion)
```



```wl
PROCÉDURE CallbackDemandeConnexion(sIdAppareil est chaîne, sNomAppareil est une chaîne, sToken est une chaîne)
Info([
	ID : [%sIdAppareil%]
	Nom : [%sNomAppareil%]
])
```



```wl
PROCÉDURE CallbackConnexion(sIdAppareil est une chaîne, nEtat est un entier)
SELON nEtat
	CAS ppRefusConnexion
		ToastAffiche("La demande de connexion a été refusée.")
	CAS ppConnexion
		ToastAffiche(ChaîneConstruit("Vous êtes connecté à l'appareil %1.", sIdAppareil)
	CAS ppDéconnexion
		ToastAffiche("Vous êtes déconnecté.")
	CAS ppEchecConnexion
		ToastAffiche("La connexion a échoué." + ErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PartageProximitéDemandeConnexion_Callback_Notification(<Identifiant de l'appareil distant> , <Etat>)`
---

**`<Identifiant de l'appareil distant> : (Chaîne de caractères)`**

Identifiant de l'appareil distant.

**`<Etat> : (Constante de type Entier)`**

Etat de la connexion avec l'appareil distant : 


|   |   |
| --- | --- |
|  *ppConnexion* | Connexion établie. |
| *ppDéconnexion* | Déconnexion |
| *ppEchecConnexion* | Echec de la connexion. Dans ce cas, la fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir le détail de l'erreur. |
| *ppRefusConnexion* | Connexion refusée par l'appareil distant. |
