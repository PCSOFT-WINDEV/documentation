
## RendezVousCrée (Fonction)

***En anglais : AppointmentCreate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de créer un rendez-vous via la fenêtre de création de rendez-vous de l'application native de gestion des rendez-vous de l'appareil Android ou iOS.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
rdv est un RendezVous
SI RendezVousCrée(rdv) ALORS
	Info(ChaîneConstruit("Le rendez-vous %1 a été ajouté au calendrier %2", ...
			rdv.Nom, rdv.Calendrier.Nom))
FIN
```
<a name="Exemple2"></a>

```wl
rdv est un RendezVous
...
RendezVousCrée(rdv, procRdv)

	PROCEDURE INTERNE procRdv(Etat)
		SELON Etat 
			CAS rdvAnnulation
			Trace("Rendez-vous annulé par l'utilisateur")
			CAS rdvEchec
			Trace("Création en échec")
			CAS rdvSuccès
			Info("Le rendez-vous a été créé avec succès")
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Création d'un rendez-vous (syntaxe synchrone)

`<Résultat> = RendezVousCrée(<RendezVous>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si un rendez-vous a été créé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<RendezVous> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) à renseigner avec les données correspondant au rendez-vous créé dans la fenêtre de l'application native du périphérique.


<a name="SYNTAXE2"></a>

### Création d'un rendez-vous (syntaxe asynchrone)

`RendezVousCrée(<RendezVous> , <Procédure WLangage>)`
---

**`<RendezVous> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) à renseigner avec les données correspondant au rendez-vous créé dans la fenêtre de l'application native du périphérique.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également nommée "callback") appelée lors de la création du rendez-vous. Cette procédure permet de savoir si le rendez-vous a été créé. 

Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction RendezVousCrée](../WDLang3/1410090599.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000080"></a>

- Pour créer un nouveau rendez-vous entièrement par programmation, sans ouvrir de fenêtre, utilisez la fonction [RendezVousAjoute](../WDLang3/1000011001.md).

- Si la syntaxe synchrone est utilisée, la fonction **RendezVousCrée** est bloquante jusqu'à ce que l'utilisateur valide ou annule la fenêtre de création de rendez-vous.

- La syntaxe asynchrone permet de ne pas bloquer l'application pendant que la fenêtre de création d'un rendez-vous est affichée. 

- La fonction **RendezVousCrée** peut être utilisée dans l'émulateur mais pas dans le simulateur.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000238"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **RendezVousCrée** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
