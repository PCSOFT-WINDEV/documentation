


## grWaffleTaille (Fonction)

***En anglais : grWaffleSize***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de définir le nombre de lignes et de colonnes d'un graphe de type Waffle.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Configure le graphe
grWaffleTaille(GRF_Graphe, nbColonnes, nbLignes)
// Redessine le graphe
grDessine(GRF_Graphe)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`grWaffleTaille(<Nom du graphe> , <Nombre de colonnes> , <Nombre de lignes>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.




**`<Nombre de colonnes> : (Entier)`**

Nombre de colonnes dans le graphe de type Waffle. 

**`<Nombre de lignes> : (Entier)`**

Nombre de colonnes dans le graphe de type Waffle.
