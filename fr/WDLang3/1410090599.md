
## Procédure WLangage appelée par la fonction RendezVousCrée



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") exécutée lors de la création d'un rendez-vous avec la fonction [RendezVousCrée](../WDLang3/1000020691.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
rdv est un RendezVous
...
RendezVousCrée(rdv, procRdv)

	PROCEDURE INTERNE procRdv(Etat)
		SELON Etat 
			CAS rdvAnnulation
			Trace("Rendez-vous annulé par l'utilisateur")
			CAS rdvEchec
			Trace("Création en échec")
			CAS rdvSuccès
			Info("Le rendez-vous a été créé avec succès")
		FIN
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`RendezVousCrée_Callback(<Etat>)`
---

**`<Etat> : (Constante de type Entier)`**

Etat de l'opération de création du rendez-vous : 


|   |   |
| --- | --- |
| *rdvAnnulation* | La création du rendez-vous a été annulée. |
| *rdvÉchec* | La création du rendez-vous est en échec. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md). |
| *rdvSuccès* | Le rendez-vous a bien été créé. |
