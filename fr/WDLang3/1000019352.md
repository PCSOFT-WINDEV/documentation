


## WiFiConnecte (Fonction)

***En anglais : WiFiConnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Connecte l'appareil au réseau Wi-Fi spécifié.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) **Remarques** : 

- L'accès Wi-Fi n'est pas disponible dans l'émulateur Android.

- A partir de Android 6, il n'est pas possible de se connecter à un réseau qui n'a pas été ajouté par l'application elle-même.

- Attention : A partir d'Android 10, il n'est plus possible de se connecter à un réseau Wi-Fi par programmation. Cette fonction provoque une erreur fatale.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI WiFiConnecte("14758") = Vrai ALORS
	Info("Connexion Wi-Fi établie.")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = WiFiConnecte(<Identifiant> [, <Mot de passe>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la connexion a réussi, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.




**`<Identifiant> : (Chaîne de caractères)`**

Identifiant du réseau auquel on souhaite se connecter. Cet identifiant peut être : 

- l'identifiant renvoyé par la fonction [WiFiAjouteRéseau](../WDLang3/1000019351.md) (cas d'un réseau qui vient d'être ajouté). 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) l'identifiant d'un réseau sélectionné dans la liste des réseaux disponibles (fonction [WiFiListeRéseau](../WDLang3/1000019356.md)).
	Attention : A partir de Android 6, ce type d'identifiant n'est plus disponible. 




**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Mot de passe utilisé pour se connecter à un réseau sécurisé. Si ce mot de passe n'est pas spécifié, le mot de passe utilisé sera celui enregistré dans la configuration du réseau (si ce mot de passe existe).
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000082"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permissions requises :  

- ACCESS_WIFI_STATE : cette permission permet aux applications d'accéder à des informations concernant les réseaux Wi-Fi. 

- CHANGE_WIFI_STATE : cette permission permet aux applications de modifier l'état de connectivité Wi-Fi.
