


## &lt;Variable Notification&gt;.Ajoute (Fonction)

***En anglais : &lt;Notification variable&gt;.Add***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une notification dans la barre système de l'appareil (Android) ou dans le centre de notification (iOS).

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) La notification est affichée dans la barre système et peut ensuite être déroulée pour voir son détail. La notification peut contenir des actions spécifiques, affichées sous forme de texte cliquable en dessous du message de la notification.
La mise en place des notifications supplémentaires est réalisée via la propriété **ActionSupplémentaire** de la variable de type [Notification](../WDLang3/1000019441.md). 
**A partir d'Android 8.0 (Oreo, API level 26)**, toutes les notifications créées par une application Android doivent être associées à une catégorie de notification (connue également sous le nom de "channel"). Les catégories de notification sont définies par la propriété **Catégorie** des variables de type [Notification](../WDLang3/1000019441.md). 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La notification sera visible dans le centre de notification uniquement si l'application est en arrière-plan (par exemple, utilisation du suivi de position en arrière-plan avec la fonction [géoSuiviActive](../WDLang3/1000021583.md)).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
notif est une Notification
notif.Titre = "Nouveau message reçu"
notif.Message = "Cliquez pour afficher le message"
notif.Ajoute()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Notification>.Ajoute()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la notification a été ajoutée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**Remarque** : Dans le simulateur, cette fonction est sans effet et renvoie toujours <u><u><u><u>Faux</u></u></u></u>.

**`<Notification> : (Variable de type Notification)`**

Nom de la variable de type [Notification](../WDLang3/1000019441.md) contenant la description de la notification à afficher.

Si ce paramètre correspond à une notification déjà ajoutée, cette notification sera mise à jour. La fonction **&lt;Variable Notification&gt;.Ajoute** aura alors le même effet que la fonction [&lt;Variable Notification&gt;.Modifie](../WDLang3/1410090432.md).
