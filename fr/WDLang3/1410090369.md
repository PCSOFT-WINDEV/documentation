


## &lt;Variable Drive&gt;.SupprimeRépertoire (Fonction)

***En anglais : &lt;Drive variable&gt;.DeleteDirectory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un répertoire (et les fichiers qu'il contient) sur un drive (disque distant).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI oDrive.SupprimeRépertoire("/MesRépertoires/MonSousRepertoire/") = Faux ALORS
	Erreur("Impossible de supprimer le répertoire demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Drive>.SupprimeRépertoire(<Répertoire à supprimer>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire a été supprimé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la copie n'est pas réalisée.

**`<Répertoire à supprimer> : (Chaîne de caractères)`**

Chemin absolu du répertoire à supprimer. Si ce paramètre ne correspond pas à un chemin de répertoire valide, le répertoire ne sera pas supprimé.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Spécificités
<a name="specificites_ELTPARAGRAPHE000190"></a>

- Si le répertoire spécifié contient des sous-répertoires, ces sous-répertoires et les fichiers qu'ils contiennent seront également supprimés. 

- Un répertoire supprimé via la fonction **&lt;Variable Drive&gt;.SupprimeRépertoire** ne peut pas être recrée directement. L'utilisateur doit se connecter à nouveau au drive pour que la recréation du répertoire soit possible.





### Paramètre &lt;Répertoire à supprimer&gt;
<a name="parametre_ELTPARAGRAPHE000204"></a>Exemples de chemins valides : 

```txt
"/mon répertoire de vacances/2021/"
"\photos"
```


Exemples de chemins invalides :

```txt
"répertoireA/RépertoireB"
"Ce/Chemin/Est/invalide"
"c:\Users\"
```
