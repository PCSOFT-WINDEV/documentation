


## Fonctions SSH
			



**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions SSH (syntaxe préfixée)](../WDLang3/1000021168.md)).

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de se connecter et de dialoguer avec un serveur SSH sont les suivantes : 



|   |   |
| --- | --- |
| [SSHCommande](../WDLang3/1000021143.md) | Envoie une commande à un serveur SSH. La session est ouverte et refermée automatiquement après l'envoi de la commande. |
| [SSHConnecteCommande](../WDLang3/1410091112.md) | Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [SSHCommande](../WDLang3/1000021143.md)) à un serveur SSH.<br><br> |
| [SSHConnecteShell](../WDLang3/1000021147.md) | Ouvre une nouvelle session SSH de type "Shell". |
| [SSHDéconnecteCommande](../WDLang3/1410091113.md) | Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes.<br><br> |
| [SSHDéconnecteShell](../WDLang3/1000021148.md) | Ferme une session SSH précédemment ouverte grâce à la fonction [SSHConnecteShell](../WDLang3/1000021147.md). |
| [SSHEcrit](../WDLang3/1000021150.md) | Ecrit des données dans la session SSH spécifiée. |
| [SSHLit](../WDLang3/1000021149.md) | Lit les données présentes sur le buffer de sortie de la session SSH. |



Remarque : Le protocole géré est SSH-2.
