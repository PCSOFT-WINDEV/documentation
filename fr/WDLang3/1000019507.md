
## ContactEdite (Fonction)

***En anglais : ContactEdit***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre en édition la fiche d'un contact en cours dans l'application native de gestion des contacts de l'appareil  (Android, iPhone ou iPad).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ouvre en édition la fiche du contact en cours
// Variables globales
gContactEnCours est un Contact
... 
// - Clic sur BTN_Modifier
// Lance l'édition du contact
ContactEdite(gContactEnCours)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Ouvrir la fiche d'un contact en édition

`<Résultat> = ContactEdite(<Contact>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le contact a été modifié, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Contact> : (Variable de type Contact)`**

Nom de la variable de type [Contact](../WDLang3/1000020254.md) correspondant au contact dont la fiche doit être ouverte. Ce contact doit exister dans la base des contacts de l'appareil. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000066"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La fonction **ContactEdite** est bloquante jusqu'à la fermeture de la fiche du contact par l'utilisateur. 

- Pour mettre à jour la variable [Contact](../WDLang3/1000020254.md) avec les informations relatives au contact précédemment édité, utilisez la fonction [ContactLit](../WDLang3/1000006112.md).

- La fonction **ContactEdite** peut être utilisée dans l'émulateur. Elle ne peut pas être utilisée dans le simulateur.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000223"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **ContactEdite** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
