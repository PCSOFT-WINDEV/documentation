


## &lt;Variable ftpConnexion&gt;.RepExiste (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.DirExist***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si un répertoire existe sur un serveur FTP (File Transfer Protocol).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

<a name="1410091242_Exemple2"></a>

```wl
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()

// Vérification de l'existence du répertoire sur le serveur FTP
ResRepExiste = MaConnexionFTP.RepExiste("/Documents/Fichier")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion FTP>.RepExiste(<Répertoire>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire existe, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.

**`<Répertoire> : (Chaîne de caractères)`**

Nom et chemin absolu (ou relatif) du répertoire à vérifier. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/").



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Délai
<a name="delai_ELTPARAGRAPHE000231"></a>Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
<a name="NOTE0_3"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000264"></a>La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
