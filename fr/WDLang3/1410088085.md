


## grAngleDépart (Fonction)

***En anglais : grStartAngle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique l'angle de départ de la première part dans un graphe de type :

- Secteur, Hémicycle ou Donut.

- Secteur multiniveau.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Graphe circulaire de progrès.




Exemple d'angle de départ d'un graphe de type Hémicycle : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=grSecteurPartExcentr%E9e%20-%20HC%20N%B0001.gif)


![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Les graphes](../WDChamp/3042060.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Augmentation de l'angle de départ du champ Graphe "GRF_MonGraphe"
grAngleDépart(GRF_MonGraphe, 45)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`grAngleDépart(<Nom du graphe> , <Angle>)`
---

**`<Nom du graphe> : (Nom de champ ou chaîne de caractères)`**

Nom du graphe à manipuler. Ce nom correspond :

- soit au nom du graphe défini par programmation avec la fonction [grCrée](../WDLang3/3042005.md).

- soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Seuls les champs Graphe sont disponibles.![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Seuls les champs Graphe interactif sont disponibles.

**`<Angle> : (Entier)`**

Angle de départ de la première part (exprimé en degrés dans le sens des aiguilles d'une montre à partir du point haut du disque). 
Par défaut, l'angle de départ dans un graphe de type Secteur, Hémicycle ou Donut est égal à 0.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La définition de l'angle de départ de la première part d'un graphe est disponible uniquement sur les graphes suivants : 

	- graphes de type Secteur (constante *grSecteur*). 

	- graphes de type Hémicycle (constante *grHémicycle*).
			![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Ce type de graphe n'est pas disponible.

	- graphes de type Donut (constante *grDonut*).

	- graphes circulaires de progrès (constante *grCirculaireDeProgrès*).
			![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce type de graphe n'est pas disponible.




- Les données définies avec la fonction **grAngleDépart** seront prises en compte lors du prochain appel à la fonction [grDessine](../WDLang3/3042026.md).
	![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Les données définies avec la fonction **grAngleDépart** sont prises en compte immédiatement.
