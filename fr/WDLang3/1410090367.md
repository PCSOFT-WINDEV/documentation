


## &lt;Variable gglDrive&gt;.SupprimeFichier (Fonction)

***En anglais : &lt;gglDrive variable&gt;.DeleteFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un fichier de la suite Google à l'intérieur d'un drive Google.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

DriveGoogle est un gglDrive
DriveGoogle = GglDriveConnecte(oOAuth2Param)

SI DriveGoogle.SupprimeFichier("/MesRépertoires/Fichier.txt") = Faux ALORS
	Erreur("Impossible de supprimer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE2"></a>

`<Résultat> = <Drive Google>.SupprimeFichier(<Fichier à supprimer>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le fichier a été supprimé, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive Google> : (Variable de type gglDrive)`**

Nom de la variable de type [gglDrive](../WDLang3/1410089374.md) correspondant au drive Google à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la suppression n'est pas réalisée.

**`<Fichier à supprimer> : (Variable de type FichierGgl)`**

Nom de la variable de type [FichierGgl](../WDLang3/1410089586.md) correspondant au fichier à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Un fichier supprimé via la fonction **&lt;Variable gglDrive&gt;.SupprimeFichier** ne peut pas être recréé directement. L'utilisateur doit se connecter à nouveau au drive pour que la recréation du fichier soit possible.
