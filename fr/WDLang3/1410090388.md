


## Fonctions de gestion des raccourcis d'application (app shortcuts)  (syntaxe préfixée)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant la gestion des raccourcis d'application (syntaxe préfixée) (également appelés "apps shortcuts" ou "Action rapide") sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Variable ActionRapide&gt;.Ajoute](../WDLang3/1410090385.md) | Ajoute une nouvelle action rapide à l'application. |
| [&lt;Variable ActionRapide&gt;.Epingle](../WDLang3/1410090409.md) | Demande à épingler une action rapide. |
| [&lt;Variable ActionRapide&gt;.Supprime](../WDLang3/1410090386.md) | Supprime une action rapide de l'application. |
