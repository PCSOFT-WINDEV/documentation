
## WiFiSupprimeRéseau (Fonction)

***En anglais : WiFiDeleteNetwork***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime un réseau de la liste des réseaux Wi-Fi configurés de l'appareil.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Attention : Cette fonctionnalité est disponible jusqu'à Android 9. A partir d'Android 10, cette information n'est plus accessible : cette fonction provoque une erreur fatale. Il est conseillé de tester la version d'Android utilisée via la fonction [SysVersionAndroid](../WDLang1/1000019785.md). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
WiFiSupprimeRéseau("1478")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = WiFiSupprimeRéseau(<Identifiant>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la suppression a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.




**`<Identifiant> : (Chaîne de caractères)`**

Identifiant du réseau à supprimer.

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000059"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permissions requises :  

- ACCESS_WIFI_STATE : cette permission permet aux applications d'accéder à des informations concernant les réseaux Wi-Fi. 

- CHANGE_WIFI_STATE : cette permission permet aux applications de modifier l'état de connectivité Wi-Fi.
