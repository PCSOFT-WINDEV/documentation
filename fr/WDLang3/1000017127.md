
## BTEstVisible (Fonction)

***En anglais : BTIsVisible***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une radio Bluetooth est visible.

**Remarque** : Une radio Bluetooth correspond à un émetteur Bluetooth. Cet émetteur peut par exemple correspondre à une clé USB Bluetooth, ou être un élément intégré au poste (par exemple dans le cas d'un portable).

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) **Attention** : Les fonctions Bluetooth ne sont pas disponibles dans l'émulateur Android.

## Exemple

![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 
```wl
bVisible est un booléen
// Identifiant des radios Bluetooth listés dans un champ Table
nIdRadio est un entier 
nIdRadio = TABLE_Radios.COL_ID[TABLE_Radios]
// Teste si la radio sélectionnée est visible
bVisible = BTEstVisible(nIdRadio)
// Affichage 
SI bVisible = Vrai ALORS
	Trace("Visible")
SINON 
	Trace("Non visible")
FIN
// Changement de la visibilité
BTChangeVisibilité(nIdRadio, PAS bVisible)
```

## Syntaxe
![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 
### Syntaxe utilisable sous Windows

`<Résultat> = BTEstVisible(<Identifiant de la radio>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la radio Bluetooth est visible, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Identifiant de la radio> : (Entier)`**

Identifiant de la radio Bluetooth à manipuler. Cet identifiant est retourné par la fonction [BTListeRadio](../WDLang3/1000017125.md).

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000102"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : BLUETOOTH.

Cette permission permet aux applications de se connecter à des services Bluetooth.
