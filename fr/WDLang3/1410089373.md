
## GglDriveConnecte (Fonction)

***En anglais : GglDriveConnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Crée une connexion à un drive Google Drive. 
<a name="sample_code"></a>

## Exemple


```wl
// Connexion au drive Google Drive via le protocole OAuth 2.0
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"
 
MonDrive est un gglDrive
MonDrive = GglDriveConnecte(oOAuth2Param)
```

```wl
// Connexion au drive Google Drive via un token (refresh token)
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oOAuth2Token est un AuthToken
oOAuth2Token = AuthIdentifie(oOAuth2Param)
 
MonDrive est un gglDrive
MonDrive = GglDriveConnecte(oOAuth2Token)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connexion au drive Google Drive via le protocole OAuth 2.0

`<Résultat> = GglDriveConnecte(<Paramètres d'authentification>)`
---

**`<Résultat> : (Variable de type Drive ou gglDrive)`**

Variable de type [gglDrive](../WDLang3/1410089374.md) ou variable de type [Drive](../WDLang3/1410089369.md) contenant toutes les informations de connexion au drive Google Drive. 
En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et une variable invalide est renvoyée. 

**`<Paramètres d'authentification> : (Variable de type OAuth2Paramètres)`**

Nom de la variable de type [OAuth2Paramètres](../WDLang3/1000022212.md) contenant les paramètres d'authentification :

- Les propriétés **ClientID** et **ClientSecret** doivent être renseignées. 

- La propriété **URLRedirection** peut être renseignée. Par défaut, cette propriété correspond à "http://localhost:3400/".





<a name="SYNTAXE2"></a>

### Connexion au drive Google Drive via un token (refresh token)

`<Résultat> = GglDriveConnecte(<Paramètres d'authentification>)`
---

**`<Résultat> : (Variable de type Drive ou gglDrive)`**

Variable de type [gglDrive](../WDLang3/1410089374.md) ou variable de type [Drive](../WDLang3/1410089369.md) contenant toutes les informations de connexion au drive Google Drive. 
En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et une variable invalide est renvoyée. 

**`<Paramètres d'authentification> : (Variable de type AuthToken)`**

Nom de la variable de type [AuthToken](../WDLang3/1000022220.md) contenant les paramètres d'authentification.

## Remarques


### Différence d'utilisation des variables Drive et gglDrive
<a name="difference_utilisation_des_variables_drive_ggldrive_ELTPARAGRAPHE000083"></a>La fonction **GglDriveConnecte** permet d'utiliser aussi bien une variable de type [gglDrive](../WDLang3/1410089374.md) qu'une variable de type [Drive](../WDLang3/1410089369.md). 

- Une variable de type [Drive](../WDLang3/1410089369.md) permettra de réaliser un code commun quelque soit le drive utilisé. 

- Une variable de type [gglDrive](../WDLang3/1410089374.md) permettra de manipuler explicitement un drive Google. Dans ce cas, il sera possible de manipuler les fichiers de la suite Google via une variable de type [FichierGgl](../WDLang3/1410089586.md). Certaines fonctions et syntaxes spécifiques permettent de manipuler ce type de fichiers : 

	- Fonctions spécifiques : 
			


|   |   |
| --- | --- |
| [DriveListeFichierGgl](../WDLang3/1410089601.md) | Liste les fichiers de la suite Google (Google Docs, Google Sheets, etc.) présents dans un drive Google. |
| [DriveRécupèreFichierGgl](../WDLang3/1410089618.md) | Récupère un document de la suite Google présent sur un Google Drive dans le format compatible souhaité. |

- Fonctions proposant une syntaxe spécifique pour les fichiers de la suite Google : 
			







### Utilisation d'un token d'accès
<a name="utilisation_token_acces_ELTPARAGRAPHE000117"></a>Afin d'éviter à l'utilisateur de se reconnecter à chaque lancement de l'application, il est préférable de passer un token avec "refresh token". Le drive mettra automatiquement le token à jour si nécessaire.

Informations nécessaires pour se connecter à un drive en utilisant un token existant : 


| Propriétés du type OAuth2Paramètres | Valeur utilisée par la fonction GglDriveConnecte |
| --- | --- |
| URLAuth | "https://accounts.google.com/o/oauth2/v2/auth" |
| URLToken | "https://oauth2.googleapis.com/token" |
| Scope | "https://www.googleapis.com/auth/drive" |
| URLRedirection (Peut être modifiée) | "http://localhost:3400/" |
