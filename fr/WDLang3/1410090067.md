
## ActionRapideListe (Fonction)

***En anglais : QuickActionList***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste les actions rapides de l'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
tabAction est un tableau de ActionRapide = ActionRapideListe()
POUR TOUTE action DE tabAction
	SI action.Identifiant = "ID_ACTION_ENVOI_MESSAGE" ALORS
		ActionRapideEpingle(action)
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = ActionRapideListe()`
---

**`<Résultat> : (Tableau)`**

Tableau de variables de type [ActionRapide](../WDLang3/1410090054.md) décrivant les actions rapides de l'application.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La propriété **Icône** de la variable de type [ActionRapide](../WDLang3/1410090054.md) n'est pas récupérable.
