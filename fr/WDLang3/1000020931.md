


## UPNPModifieMuet (Fonction)

***En anglais : UPNPModifyMute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifier l'état 'Muet' d'un périphérique UPnP.

**Attention** : Pour utiliser cette fonction, le périphérique doit posséder un service "RenderingControl". 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
tabPériphérique est un tableau de upnpPériphériques 
tabPériphérique = UPNPListePériphérique(...
		"urn:schemas-upnp-org:device:MediaRenderer:1", 5)
POUR TOUT Périphérique de tabPériphérique
	UPNPModifieMuet(Périphérique, Vrai)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = UPNPModifieMuet(<Périphérique UPnP> , <Nouvel état>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'état muet a été modifié, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Périphérique UPnP> : (Variable de type upnpPériphérique)`**

Nom de la variable [upnpPériphérique](../WDLang3/1000020903.md) correspondant au périphérique UPnP à manipuler.

**`<Nouvel état> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le périphérique doit être muet, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.
