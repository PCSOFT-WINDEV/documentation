
## LuminositéRécupère (Fonction)

***En anglais : BrightnessGet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le réglage actuel de la luminosité de l'écran de l'appareil.

**Remarque** : Cette fonction peut être utilisée dans l'émulateur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
nLuminosité est un entier = LuminositéRécupère()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = LuminositéRécupère()`
---

**`<Résultat> : (Entier)`**

Réglage actuel de la luminosité de l'écran en mode manuel, compris entre 0 et 100.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) **Attention** : Si le réglage de la luminosité est en mode automatique, la valeur retournée peut être différente de la luminosité réelle de l'écran. Pour savoir si le réglage a été effectué en mode automatique, utilisez la fonction [LuminositéAuto](../WDLang3/1000020182.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>
