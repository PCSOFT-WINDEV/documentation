


## &lt;Variable ftpConnexion&gt;.RepEnCours (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.CurrentDir***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifie ou modifie le répertoire en cours sur un serveur FTP (File Transfer Protocol).


<a name="sample_code"></a>

## Exemple

<a name="Exemple2"></a>

```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()

// Identifier le répertoire en cours sur le serveur FTP
ResRepEnCours = MaConnexionFTP.RepEnCours()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le répertoire en cours

`<Résultat> = <Connexion FTP>.RepEnCours()`
---

**`<Résultat> : (Chaîne de caractères)`**



- Nom absolu du répertoire en cours sur le serveur FTP, 

- Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.


<a name="SYNTAXE2"></a>

### Modifier le répertoire en cours

`<Résultat> = <Connexion FTP>.RepEnCours(<Nouveau répertoire en cours>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire en cours a été modifié, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) correspondant à la connexion FTP utilisée.

**`<Nouveau répertoire en cours> : (Chaîne de caractères)`**

Nom et chemin absolu (ou relatif) du nouveau répertoire en cours. Les parties du chemin sont séparées par des "slash" (barre oblique normale, "/").



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Délai
<a name="delai_ELTPARAGRAPHE000318"></a>Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié lors de la définition des paramètres de la variable [ftpConnexion](../WDLang3/1410090869.md) (propriété **DuréeNonRéponse**).
<a name="NOTE0_3"></a>


### Droits des utilisateurs
<a name="droits_des_utilisateurs_ELTPARAGRAPHE000351"></a>La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.
