


## &lt;Variable ftpConnexion&gt;.Connecte (Fonction)

***En anglais : &lt;ftpConnection variable&gt;.Connect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Connecte le poste en cours à un serveur FTP (File Transfer Protocol).

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les modes de connexion sécurisés disponibles sont les suivants : 

- FTPS : FTP sécurisé selon le protocole SSL avec chiffrement implicite. 

- FTPES : FTP sécurisé selon le protocole SSL avec chiffrement explicite. 

- SFTP : FTP sécurisé par un tunnel SSH.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est un ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = FTPConnecte(<Connexion FTP>)`
---

**`<Résultat> : (Entier)`**



- <u><u><u><u>Vrai</u></u></u></u> si la connexion a été effectuée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](../WDLang1/3013008.md) utilisée avec la constante *errCode* ou *errMessage*. 
	En cas d'erreur d'identification, la fonction [ErreurInfo](../WDLang1/3013008.md) utilisée avec la constante *errCode* renvoie la constante *ftpErreurIdentification*.




**`<Connexion FTP> : (Variable de type ftpConnexion)`**

Nom de la variable de type [ftpConnexion](../WDLang3/1410090869.md) décrivant les caractéristiques de la connexion au serveur FTP.
