


## InternetConnecté (Fonction)

***En anglais : InternetConnected***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Détermine si une connexion Internet est active sur le poste en cours. 

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Permet d'être notifié lors du changement d'état de la connexion Internet. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connexion Internet active ?
ResConnexion = InternetConnecté()
SI ResConnexion = Vrai ALORS
	Info("Une connexion Internet est active")
SINON
	Info("Aucune connexion Internet n'est active")
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si une connexion Internet est active

`<Résultat> = InternetConnecté()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si une connexion Internet est active sur le poste en cours, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  





<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
### Demander une notification lors d'un changement d'état de la connexion Internet

`<Résultat> = InternetConnecté([<Procédure WLangage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la procédure a été associée à la fonction **InternetConnecté**, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Procédure WLangage> : (Nom de procédure)`**

Procédure WLangage (également nommée "callback") appelée lors d'un changement d'état de la connexion Internet.

Cette procédure est de la forme : 

```txt
PROCEDURE <Nom de la procédure>(<Etat>)
```


Le paramètre &lt;Etat&gt; est une constante de type entier correspondant au nouvel état de la connexion Internet.
Il peut prendre les valeurs suivantes : 



|   |   |
| --- | --- |
| *réseauDéconnecté* | Le réseau est déconnecté ou inaccessible. |
| *réseauEthernet* | La connexion Internet est réalisée par Ethernet. |
| *réseauMobile* | La connexion Internet est réalisée en mode mobile : edge, 2G, 3G, 4G, ... |
| *réseauWifi* | La connexion Internet est réalisée par Wi-Fi. |


Si le paramètre &lt;Procédure WLangage&gt; correspond à une chaîne vide (""), la procédure WLangage précédemment définie ne sera plus appelée.

## Remarques
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 

### Firewall
<a name="firewall_ELTPARAGRAPHE000118"></a>La fonction **InternetConnecté** utilise une requête **ping** afin de tester l'accès à Internet. Il faut donc que les paramètres de sécurité du réseau autorise le ping pour que le résultat de la fonction soit pertinent.

Remarque : Le ping est réalisé sur le DNS de Google (6 secondes, 1 essai). Le code équivalent est : 

```wl
Ping("8.8.8.8", 6000, 1)
```

<a name="NOTE0_2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) **Permissions requises**
L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : ACCESS_NETWORK_STATE : cette permission permet aux applications d'accéder à des informations concernant les réseaux.
<a name="NOTE0_3"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Changement d'état de la connexion (syntaxe 2)**


- Appel de la procédure :

	- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La procédure WLangage n'est appelée qu'en cas de changement de l'état du réseau. Elle n'est pas appelée lors de l'appel de la fonction **InternetConnecté**. Il est nécessaire d'appeler la fonction **InternetConnecté** (sans paramètre) pour savoir si la connexion Internet est active ou non. 

	- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) La procédure WLangage est automatiquement appelée lors de l'appel de la fonction **InternetConnecté**. 




- Une seule procédure peut être associée à la fonction **InternetConnecté**. Si la fonction **InternetConnecté** est appelée plusieurs fois avec des noms de procédure différents, la procédure utilisée pour la détection de l'état de la connexion Internet sera remplacée par la nouvelle procédure spécifiée.   

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Si la fonction **InternetConnecté** est appelée depuis un thread secondaire, la procédure sera appelée dans le thread principal de l'application.
