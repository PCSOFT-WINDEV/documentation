
## telDialerAffiche (Fonction)

***En anglais : tapiDialerDisplay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre l'application de téléphonie (dialer) par défaut et affiche le numéro spécifié. Aucun appel n'est déclenché.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
telDialerAffiche("0612345678")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = telDialerAffiche(<Numéro de téléphone>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'application de téléphonie (dialer) a pu être ouverte, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Numéro de téléphone> : (Chaîne de caractères)`**

Numéro de téléphone à afficher dans l'écran de numérotation. 

Si ce paramètre est une chaîne vide (""), l'application de téléphonie sera ouverte sur l'écran de numérotation.

<a name="NOTE0_1"></a>

## Remarques


### Appel automatique
<a name="appel_automatique_ELTPARAGRAPHE000054"></a>Pour déclencher automatiquement l'appel du numéro spécifié, utilisez la fonction [telDialerCompose](../WDLang3/1000019235.md).

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000196"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **telDialerAffiche** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
