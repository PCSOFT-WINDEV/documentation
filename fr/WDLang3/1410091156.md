


## &lt;Carte&gt;.IdentifiantGgl (Fonction)

***En anglais : &lt;Map&gt;.IDGgl***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie ou modifie le style de la carte affichée dans le champ Carte. Ce style correspond à un ID de carte défini dans la console Google Cloud. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définit quelle carte utiliser parmi celles définies dans Google Cloud Platform
CARTE_SansNom1.IdentifiantGgl("idCarteDétaillée")
// Affiche l'identifiant
Trace(CARTE_SansNom1.IdentifiantGgl())
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître l'identifiant de carte associé à un champ Carte

`<Résultat> = <Champ Carte>.IdentifiantGgl()`
---

**`<Résultat> : (Chaîne de caractères)`**

Identifiant de carte associé au champ.

**`<Champ Carte> : (Nom du champ manipulé)`**

Nom du champ Carte manipulé.


<a name="SYNTAXE2"></a>

### Modifier l'identifiant de carte associé à un champ Carte

`<Champ Carte>.IdentifiantGgl(<Identifiant>)`
---

**`<Champ Carte> : (Nom du champ manipulé)`**

Nom du champ Carte manipulé.

**`<Identifiant> : (Chaîne de caractères)`**

Identifiant de carte correspondant au style de carte à utiliser.

## Remarques


### Définir un identifiant de carte
<a name="definir_identifiant_carte_ELTPARAGRAPHE000191"></a>Un identifiant de carte est un identifiant unique qui représente les styles et les paramètres de configuration de Google Maps stockés dans Google Cloud. Les identifiants de carte peuvent être utilisés pour activer des fonctionnalités, ou pour gérer ou styliser des cartes sur vos sites Web et dans vos applications.

Pour plus de détails, consultez [https://developers.google.com/maps/documentation/javascript/cloud-customization?hl=fr#creating_map_styles](https://developers.google.com/maps/documentation/javascript/cloud-customization?hl=fr#creating_map_styles). 

Un identifiant de carte (ID de carte) peut être défini dans la console de développement Google : 

1. Lancez la console Google cloud et identifiez-vous. 

2. Dans le menu, cliquez sur "Styles de cartes". Le bouton "Créer un style" permet de lancer l'assistant de création d'un style de carte. Il est possible de définir des couleurs différentes pour les routes, les éléments naturels, etc. Enregistrez et donnez un nom au style créé.

3. Dans le menu, sélectionnez "Gestion de plans" et cliquez sur "Créer un ID de carte". Saisissez le nom de cet ID de carte (ce nom sera utilisé dans la fonction **&lt;Carte&gt;.IdentifiantGgl**). Le type de carte associé doit être "Javascript". 

4. Dans la description du style de carte, il est possible d'ajouter des ID de carte. Il est alors possible d'associer l'ID de carte au style de carte créé.

5. Publiez votre style de carte pour l'utiliser dans votre application/site.
