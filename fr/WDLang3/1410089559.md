


## DriveRécupèreRépertoire (Fonction)

***En anglais : DriveDownloadDirectory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère un répertoire (et ses fichiers) présent sur un drive (disque distant) pour l'enregistrer sur le poste de l'utilisateur.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

// Choix du répertoire local
sRépertoire est une chaîne
sRépertoire = fRepSélecteur(fRepExe(), "Répertoire local où récupérer le répertoire")

// Récupère le répertoire
SI DriveRécupèreRépertoire(oDrive, "/MesPhotos", sRépertoire) = Faux ALORS
	Erreur("Impossible de récupérer le répertoire demandé", ErreurInfo())
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = DriveRécupèreRépertoire(<Drive> , <Répertoire à récupérer> , <Répertoire local>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le répertoire et ses fichiers ont été récupérés, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Drive> : (Variable de type Drive ou gglDrive)`**

Nom de la variable de type [Drive](../WDLang3/1410089369.md) ou [gglDrive](../WDLang3/1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, le répertoire n'est pas récupéré. 

**`<Répertoire à récupérer> : (Chaîne de caractères)`**

Chemin absolu du répertoire présent sur le poste distant et devant être récupéré. Si ce paramètre ne correspond pas à un chemin valide, le répertoire ne sera pas récupéré. 

**`<Répertoire local> : (Chaîne de caractères)`**

Chemin absolu du répertoire à enregistrer sur le poste local. Si ce paramètre ne correspond pas à un chemin valide ou si un répertoire de même nom existe déjà, le répertoire ne sera pas récupéré.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Le répertoire récupéré et ses fichiers n'ont plus de lien avec le drive. Le répertoire et les fichiers récupérés sur le poste de l'utilisateur ne seront pas modifiés si le répertoire et les fichiers présents sur le drive sont modifiés (et inversement).
