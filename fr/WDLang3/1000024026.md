


## URISélecteur (Fonction)

***En anglais : URISelect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre une fenêtre du système pour sélectionner ou créer une ressource provenant : 

- du système de fichiers de l'appareil, 

- du Cloud (Google Drive, Microsoft OneDrive, etc.) 

- d'un des gestionnaires de contenu installés sur l'appareil.

## Exemple

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
```wl
// Ouvre la fenêtre système pour la sélection d'une image ou d'un pdf
UriRessource est une URI = URISélecteur(uriImage + TAB + "application/pdf")
SI PAS ErreurDétectée ALORS
	// Affiche le nom de la ressource sélectionnée
	Info(URIRécupèreInfo(UriRessource, uriInfoNom))
FIN
```


<a name="Exemple2"></a>
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 
```wl
// Ouvre la fenêtre système pour la sélection d'une image ou d'un pdf
URISélecteur(MaProcURISélecteur, uriImage + TAB + "application/pdf")

PROCEDURE INTERNE MaProcURISélecteur(Succès est un booléen, Résultat1 est une URI)
	SI Succès = Vrai ALORS
		// Affiche le nom de la ressource sélectionnée
		ToastAffiche(URIRécupèreInfo(Résultat1, uriInfoNom))
	FIN
FIN
```

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)

URISélecteur(MaProcURISélecteur, uriAudio + TAB + uriImage + TAB + uriVidéo)

	SI Succès = Vrai ALORS
		// Affiche le nom de la ressource sélectionnée

### Sélectionner ou créer une ressource (code synchrone)

`<Résultat> = URISélecteur([<Types MIME> [, <Mode> [, <Nom du document>]]])`
---

**`<Résultat> : (Variable de type URI)`**



- Variable de type [URI](../WDLang3/1000024027.md) correspondant à la ressource sélectionnée. 

- En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Types MIME> : (Chaîne de caractères ou constante optionnelle)`**



- Liste des types MIME des fichiers pouvant être sélectionnés, séparés par TAB. 

- Une des constantes spécifiques suivantes : 
	


|   |   |
| --- | --- |
| *uriAudio* | Autorise tous les types de fichier audio. |
| *uriImage* | Autorise tous les types de fichier image. |
| *uriVidéo* | Autorise tous les types de fichier vidéo. |


	Remarque : Il est possible de concaténer les constantes en les séparant par TAB. 


Si un type MIME spécifié n'est pas connu par le système, il sera ignoré.
Si ce paramètre n'est pas spécifié, tous les fichiers seront sélectionnables.
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Sous Android, les fichiers qui ne correspondent pas aux types MIME spécifiés seront visibles mais non sélectionnables par l'utilisateur. 

**`<Mode> : (Constante optionnelle de type Entier)`**

Mode de sélection : 



|   |   |
| --- | --- |
| *uriCréation* | Ouvre le sélecteur en mode "Création" pour créer un nouveau document. Le nom par défaut de ce document peut être spécifié dans le paramètre &lt;Nom du document&gt;. |
| *uriOuverture*<br>(Valeur par défaut) | Ouvre le sélecteur en mode "Ouverture" pour ouvrir un document existant.  |



**`<Nom du document> : (Chaîne de caractères optionnelle)`**

Nom par défaut du document à créer lorsque le sélecteur est ouvert en mode création. Ce paramètre est pris en compte uniquement si le paramètre &lt;Mode&gt; correspond à la constante *uriCréation*.

## Remarques


### Divers
<a name="divers_ELTPARAGRAPHE000205"></a>

- Pour manipuler l'URI renvoyée par la fonction **URISélecteur**, utilisez les fonctions de la famille URIxxx.

- Pour récupérer des informations supplémentaires (nom, taille, type MIME) sur la ressource sélectionnée, utilisez la fonction [URIRécupèreInfo](../WDLang3/1000024037.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) La fonction **URISélecteur** est disponible uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.4 (api level 19). 
	Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. 
	Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Cette fonction est disponible notamment pour obtenir un code multiplateforme.



![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000371"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **URISélecteur** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
