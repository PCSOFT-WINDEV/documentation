


## EmailExécuteCommande (Fonction)

***En anglais : EmailExecuteCommand***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Envoie une commande IMAP au serveur de mails.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXXXXX"
session.MotDePasse = "XXXXXXXXXX"

// Ouverture d'une session
EmailOuvreSession(session)

// Exécution d'une commande
res = EmailExécuteCommande(session, "NOOP")
Trace("Commande : " + res)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EmailExécuteCommande(<Session IMAP> , <Commande>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Résultat de la commande.

En cas d'erreur (si le serveur a retourné un message d'erreur NO ou BAD), la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](../WDLang1/3013008.md).

**`<Session IMAP> : (Variable de type emailSessionIMAP)`**

Nom de la variable de type [emailSessionIMAP](../WDLang3/1000018957.md) correspondant à la session IMAP connectée au serveur de mails. 

**`<Commande> : (Chaîne de caractères)`**

Commande à envoyer au serveur de mails. 
Attention : Le serveur de mails doit supporter la commande envoyée.
