
## CarteAjouteCalque (Fonction)

***En anglais : MapAddLayer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un nouveau calque à une carte à partir de l'URL d'un serveur de tuiles (non compatible Google Maps)
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute le calque de OSM
CarteAjouteCalque("https://tile.openstreetmap.org/{z}/{x}/{y}.png")
// Ajoute le calque d'image satellite
CarteAjouteCalque("https://data.geopf.fr/wmts?&REQUEST=GetTile&SERVICE=WMTS&VERSION=1.0.0&STYLE=normal&TILEMATRIXSET=PM&FORMAT=image/jpe&LAYER=ORTHOIMAGERY.ORTHOPHOTO&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}", 50)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CarteAjouteCalque(<Champ Carte> , <URL> [, <Opacité>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le calque a été ajouté, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Champ Carte> : (Nom de champ)`**

Nom du champ Carte à manipuler. 

**`<URL> : (Chaîne de caractères)`**

URL du serveur de tuile en précisant sa clé en dur et les paramètres sous la forme variable {x}. Exemples : 

- https://tile.openstreetmap.org/{z}/{x}/{y}.png

- https://api.maptiler.com/maps/streets-v2/{z}/{x}/{y}.png?key=MACLESECRETE




**`<Opacité> : (Entier optionnel)`**

Opacité du calque ajouté comprise entre 0 et 100.
