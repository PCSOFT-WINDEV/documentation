
## SynthèseVocaleLitFichier (Fonction)

***En anglais : SpeechSynthesisReadFile***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lit le contenu du fichier spécifié en utilisant le moteur de synthèse vocale de l'appareil.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SynthèseVocaleLitFichier("/sdcard/email.txt")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SynthèseVocaleLitFichier(<Nom et chemin du fichier Texte> [, <Bloquant>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le contenu du fichier a été lu (mode bloquant) ou si le contenu du fichier a été ajouté à la file d'attente de lecture (mode non bloquant),

- <u><u><u><u>Faux</u></u></u></u> en cas d'échec. En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Nom et chemin du fichier Texte> : (Chaîne de caractères)`**

Nom et chemin complet (ou relatif) du fichier texte à lire.

**`<Bloquant> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> : la fonction est exécutée en mode bloquant. Le code suivant l'appel de la fonction sera exécuté lorsque la totalité du fichier aura été lue ou en cas d'échec de la fonction. Un sablier sera affiché durant la lecture. Utilisez la fonction [TitreSuivant](../WDLang1/3038043.md) pour personnaliser le message affiché par le sablier.
	![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Ce mode d'exécution n'est pas disponible.

- <u><u><u><u>Faux</u></u></u></u> (valeur par défaut) : la fonction est exécutée en mode non bloquant. Le code suivant l'appel de la fonction sera exécuté dès le début de la lecture du fichier ou en cas d'échec de la fonction.

## Remarques


### Fonctionnement
<a name="fonctionnement_ELTPARAGRAPHE000085"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 1.6 (api level 4).
	Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. 
	Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure à la version 6. La synthèse vocale ne fonctionne pas sur les émulateurs iOS 8.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Si aucun moteur de synthèse vocale n'est installé sur l'appareil, son téléchargement sera automatiquement proposé.

- Si une nouvelle lecture est déclenchée alors qu'une autre est en cours, la nouvelle lecture démarrera uniquement à la fin de la précédente. 
	Pour savoir si une lecture est en cours par le moteur de synthèse vocale, utilisez la fonction [SynthèseVocaleEnCours](../WDLang3/1000020173.md). 
	Pour stopper les lectures en cours, utilisez la fonction [SynthèseVocaleArrête](../WDLang3/1000020174.md).

- Pour fixer les paramètres à utiliser par le moteur de synthèse vocale (langue, vitesse d'énonciation, etc.), utilisez la fonction [SynthèseVocaleInitialise](../WDLang3/1000020171.md).
	Si les paramètres de la synthèse vocale n'ont pas été précédemment fixés par la fonction [SynthèseVocaleInitialise](../WDLang3/1000020171.md), les paramètres par défaut seront utilisés et la langue pour la lecture du texte sera la première langue disponible pour le moteur de synthèse vocale parmi la séquence suivante : 

	- Langue de l'application (langue par défaut ou définie par la fonction [Nation](../WDLang1/3054014.md)),

	- Langue de l'appareil,

	- Anglais,

	- Langue par défaut du moteur de synthèse vocale.




- Pour lire le contenu d'une chaîne de caractères, utilisez la fonction [SynthèseVocaleLitTexte](../WDLang3/1000019805.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Pour régler le volume de la lecture, utilisez la fonction [VolumeModifie](../WDLang3/1000020169.md) avec la constante *volumeMusique*.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000282"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **SynthèseVocaleLitFichier** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
