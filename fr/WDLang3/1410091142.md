


## Fonctions FTP Standard (syntaxe préfixée)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant la gestion du FTP (syntaxe préfixée) sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Variable ftpConnexion&gt;.Attribut](../WDLang3/1410091117.md) | Identifie les attributs d'un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Commande](../WDLang3/1410091118.md) | Envoie une commande FTP spécifique à un serveur.<br><br> |
| [&lt;Variable ftpConnexion&gt;.Connecte](../WDLang3/1410091119.md) | Connecte le poste en cours à un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Date](../WDLang3/1410091120.md) | Renvoie les différentes dates (date de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.DateHeure](../WDLang3/1410091121.md) | Renvoie les différentes dates et heures (de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Déconnecte](../WDLang3/1410091122.md) | Ferme la connexion entre le poste en cours et le serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Envoie](../WDLang3/1410091123.md) | Transfère un fichier ou un répertoire sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.FichierExiste](../WDLang3/1410091124.md) | Teste l'existence d'un fichier sur un serveur FTP.<br><br> |
| [&lt;Variable ftpConnexion&gt;.Heure](../WDLang3/1410091125.md) | Renvoie les différentes heures (heure de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.ListeFichier](../WDLang3/1410091126.md) | Liste les fichiers d'un répertoire (et/ou les répertoires) d'un serveur FTP et retourne le nombre de fichiers (et/ou de répertoires) listés.<br><br> |
| [&lt;Variable ftpConnexion&gt;.Nom](../WDLang3/1410091137.md) | Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Récupère](../WDLang3/1410091127.md) | Transfère un fichier ou un répertoire d'un serveur FTP (File Transfer Protocol) sur le poste en cours.<br><br> |
| [&lt;Variable ftpConnexion&gt;.RécupèreFichier](../WDLang3/1410091128.md) | Transfère un fichier d'un serveur FTP (File Transfer Protocol) sur le poste en cours.<br><br> |
| [&lt;Variable ftpConnexion&gt;.RenommeFichier](../WDLang3/1410091129.md) | Renomme ou déplace un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.RepCrée](../WDLang3/1410091130.md) | Crée un répertoire sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.RepEnCours](../WDLang3/1410091131.md) | Identifie ou modifie le répertoire en cours sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.RepExiste](../WDLang3/1410091282.md) | Permet de savoir si un répertoire existe sur un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.RepSupprime](../WDLang3/1410091132.md) | Supprime un répertoire et son contenu (fichiers et sous-répertoires) d'un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.SupprimeFichier](../WDLang3/1410091133.md) | Supprime un fichier d'un serveur FTP (File Transfer Protocol).<br><br> |
| [&lt;Variable ftpConnexion&gt;.Taille](../WDLang3/1410091134.md) | Renvoie la taille (en octets) d'un fichier présent sur un serveur FTP (File Transfer Protocol).<br><br> |
