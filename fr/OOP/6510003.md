
## Gestion des objets en mode référence
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000076"></a>
L'activation de la gestion des objets en mode référence entraîne de nombreuses modifications dans les manipulations des types à objets :

- structures

- classes

- types avancés

- type Champ

- type Fenêtre

- objets .Net

- objets Python


L'activation sur un projet existant n'est pas recommandée. De nombreuses modifications sont à effectuer au niveau du code de votre application.
