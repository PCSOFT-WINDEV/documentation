


## PDFVersTexte (Fonction)

***En anglais : PDFToText***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Extrait le texte contenu dans un document PDF.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaChaîne est une chaîne
MaChaîne = PDFVersTexte("C:\Temp\MonDocument.pdf")
// Affichage dans un champ de saisie multiligne
SAI_SaisieTexteMulti = MaChaîne
```
<a name="Exemple2"></a>

```wl
MonPDF est un pdfDocument = PDFOuvre("test.pdf")
MaChaîne = PDFVersTexte(MonPDF, "1-2")
// Affichage dans un champ de saisie multiligne
SAI_SaisieTexteMulti = MaChaîne
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Extraire le contenu d'un fichier PDF identifié par son chemin

`<Résultat> = PDFVersTexte(<Fichier PDF> [, <Pages à extraire> [, <Mot de passe> [, <Options>]]])`
---

**`<Résultat> : (Chaîne de caractères)`**

Texte du fichier PDF.

**`<Fichier PDF> : (Chaîne de caractères)`**

Nom et chemin du fichier PDF à analyser.

**`<Pages à extraire> : (Chaîne de caractères optionnelle)`**

Plage de pages dont le texte doit être extrait. Le format utilisé est identique à celui utilisé dans les boîtes d'impression standard : numéros individuels de pages ou étendue de pages séparés par des points-virgules. Par exemple "1;3;4;6-10;12" signifie que le texte des pages 1, 3, 4, 6 à 10, et 12 sera extrait.

Si ce paramètre n'est pas spécifié ou correspond à une chaîne vide (""), toutes les pages sont extraites.

**`<Mot de passe> : (Chaîne de caractères optionnelle ou Chaîne secrète)`**

Si le fichier PDF est protégé en ouverture, mot de passe nécessaire pour ouvrir le fichier.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Options> : (Constante de type Entier)`**

Mode de découpage du texte : 


|   |   |
| --- | --- |
| *pvtCompatible* | Découpage du texte du PDF en utilisant l'algorithme des versions 24 et précédentes. |
| *pvtDéfaut*<br>(Valeur par défaut) | Découpage du texte du PDF en utilisant un algorithme optimisé. Ce découpage peut être différent de celui effectué avec les versions précédentes. |




<a name="SYNTAXE2"></a>

### Extraire le contenu d'un document PDF présent dans une variable pdfDocument

`<Résultat> = PDFVersTexte(<Document PDF> [, <Pages à extraire>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Texte du fichier PDF.

**`<Document PDF> : (Variable de type pdfDocument)`**

Nom de la variable de type [pdfDocument](../WDLang6/1000024909.md) à manipuler. 

**`<Pages à extraire> : (Chaîne de caractères optionnelle)`**

Plage de pages dont le texte doit être extrait. Le format utilisé est identique à celui utilisé dans les boîtes d'impression standard : numéros individuels de pages ou étendue de pages séparés par des points-virgules. Par exemple "1;3;4;6-10;12" signifie que le texte des pages 1, 3, 4, 6 à 10, et 12 sera extrait.

Si ce paramètre n'est pas spécifié ou correspond à une chaîne vide (""), toutes les pages sont extraites.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conversion du PDF vers texte
<a name="conversion_pdf_vers_texte_ELTPARAGRAPHE000134"></a>

- La conversion du PDF vers du texte est réalisée sans conserver le formatage du document.

- Le texte est extrait dans l'ordre d'apparition des commandes PDF et écrit séquentiellement dans la chaîne résultat. L'organisation du texte en paragraphes et en blocs est conservée (ainsi que les retours chariot).  

- Les caractères Unicode ne sont pas renvoyés.

- Les données d'un formulaire PDF ne sont pas extraites (ces données ne sont pas stockées dans le fichier PDF).  



<a name="NOTE0_2"></a>


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000146"></a>

- La fonction [PDFEstProtégé](../WDLang6/1000017491.md) permet de savoir si un mot de passe est nécessaire pour l'ouverture d'un fichier PDF.

- La fonction [PDFNombreDePages](../WDLang6/1000017480.md) permet de connaître le nombre total de pages d'un fichier PDF.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) A partir de la version 28, si la constante *pvtCompatible* n'est pas utilisée, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits.
	Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
