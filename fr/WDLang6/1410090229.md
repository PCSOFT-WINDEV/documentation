


## VisiteGuidéeChangeEtape (Fonction)

***En anglais : GuidedTourChangeStep***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie l'étape en cours d'une visite guidée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Change d'étape si l'utilisateur a saisi une adresse email
SI EnModeVisiteGuidée() = Vrai ALORS
	SI SAI_Mail <> "" ALORS 
		VisiteGuidéeChangeEtape(MaVisiteDécouverte, vgEtapeSuivante)
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Spécifier l'indice de l'étape à afficher

`VisiteGuidéeChangeEtape([<Visite guidée>, ] <Indice>)`
---

**`<Visite guidée> : (Variable de type VisiteGuidée)`**

Nom de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) à manipuler. Si ce paramètre n'est pas spécifié, la visite guidée en cours d'exécution est modifiée. 

**`<Indice> : (Entier)`**

Indice de l'étape de la visite guidée à afficher.


<a name="SYNTAXE2"></a>

### Modifier l'étape via une option

`VisiteGuidéeChangeEtape([<Visite guidée>, ] <Option>)`
---

**`<Visite guidée> : (Variable de type VisiteGuidée)`**

Nom de la variable de type [VisiteGuidée](../WDLang6/1410090170.md) à manipuler. Si ce paramètre n'est pas spécifié, la visite guidée en cours d'exécution est modifiée. 

**`<Option> : (Constante de type Chaîne de caractères)`**

Etape à afficher : 


|   | <br><br> |
| --- | --- |
| *vgEtapePrécédente* | Affiche l'étape précédente de l'étape en cours. |
| *vgEtapeSuivante* | Affiche l'étape suivante de l'étape en cours. |
