
## gpwListeUtilisateur (Fonction)

***En anglais : gpwListUser***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère la liste des utilisateurs du groupware utilisateur.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
TabUtilisateur est un tableau de gpwUtilisateur
UnUtilisateur est un gpwUtilisateur
TabUtilisateur = gpwListeUtilisateur()
SI ErreurDétectée ALORS
	ErreurInfo(errMessage)
SINON
	POUR TOUT UnUtilisateur DE TabUtilisateur
		Trace(UnUtilisateur.Login + "//" + UnUtilisateur.Nom + "//" + UnUtilisateur.Prénom)
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Utilisateurs> = gpwListeUtilisateur()`
---

**`<Utilisateurs> : (Tableau WLangage)`**

Tableau de variables de type [gpwUtilisateur](../WDLang6/1000021088.md) correspondant aux utilisateurs du groupware utilisateur. 
En cas d'erreur (aucune connexion par exemple), la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u> et la fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître le détail de l'erreur.
**Remarque** : Les informations récupérées sont différentes si l'utilisateur actuellement connecté est superviseur ou simple utilisateur. Si l'utilisateur n'est pas un superviseur, seules les propriétés **Login** et **Activé** de la variable [gpwUtilisateur](../WDLang6/1000021088.md) sont disponibles.
