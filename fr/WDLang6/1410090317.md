
## Fonctions de gestion des visites guidées
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de manipuler les visites guidées sont les suivantes : 



|   |   |
| --- | --- |
| [VisiteGuidéeArrête](../WDLang6/1410090225.md) | Arrête la visite guidée spécifiée ou la visite guidée en cours. |
| [VisiteGuidéeChangeEtape](../WDLang6/1410090229.md) | Modifie l'étape en cours de la visite guidée. |
| [VisiteGuidéeDémarre](../WDLang6/1410090176.md) | Démarre la visite guidée et affiche la première étape. |
| [VisiteGuidéeInfo](../WDLang6/1410090219.md) | Renvoie des informations sur une visite guidée. |
