
## pdfProtection (Type de variable)

***En anglais : pdfProtection***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **pdfProtection** permet de connaître les différentes protections appliquées à un document PDF présent dans une variable de type [pdfDocument](../WDLang6/1000024909.md). 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
mon_doc est un pdfDocument = "monpdf.pdf"

SI mon_doc.Protection.Modification = Vrai ALORS
	Info("Modification autorisée")
FIN

SI mon_doc.Protection.Assemblage = Vrai ALORS
	Info("Ajout, suppression et rotation de page autorisés")
FIN
```

## Propriétés


### Propriétés spécifiques à la description des variables de type pdfProtection
<a name="proprietes_specifiques_description_des_variables_type_pdfprotection_ELTPARAGRAPHE000033"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **pdfProtection** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Assemblage | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si l'assemblage de documents est autorisé,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| Commentaire | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si l'insertion de commentaires dans le document est autorisée,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| CopieAccessibilité | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si la copie du contenu pour accessibilité est autorisée,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| Impression | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si l'impression du document est autorisée,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| Modification | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si la modification du document est autorisée,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| RemplissageFormulaire | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si le remplissage des champs de type formulaire est autorisé,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
| Sélection | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si le contenu du fichier PDF peut être copié ou extrait,<br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br>Cette propriété est disponible en lecture seulement. |
