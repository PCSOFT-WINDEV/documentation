


## &lt;Variable pdfDocument&gt;.RécupèreDateSignature (Fonction)

***En anglais : &lt;pdfDocument variable&gt;.GetSignatureDate***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère la date de l'une des signatures d'un document PDF.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonPDF est un pdfDocument = PDFOuvre("test.pdf")

// Nombre de signatures dans le fichier PDF
nNbSignature est un entier = MonPDF.NbSignature()

// Récupération des informations sur les signatures
POUR i = 1 _A_ nNbSignature
	// Récupération de la signature
	bufSignature est un Buffer = MonPDF.RécupèreSignature(i)
	
	// Récupération de la date de la signature
	dhDateSignature est un DateHeure = MonPDF.RécupèreDateSignature(i)

	// Récupération du certificat
	Certif est un Certificat = CertificatExtrait(bufSignature)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = PDFRécupèreDateSignature(<Document PDF> , <Indice>)`
---

**`<Résultat> : (DateHeure)`**

Date de la signature examinée.

**`<Document PDF> : (Variable de type pdfDocument)`**

Variable de type [pdfDocument](../WDLang6/1000024909.md) correspondant au document PDF à analyser. 

**`<Indice> : (Entier)`**

Indice de la signature dans le document (le nombre de signatures est connu par la fonction [&lt;Variable pdfDocument&gt;.NbSignature](../WDLang6/1410088154.md)).
