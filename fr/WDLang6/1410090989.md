
## Paramètres de la procédure utilisée par la fonction PDFVérifieSignatures



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (également nommée "callback") appelée par la fonction [PDFVérifieSignatures](../WDLang6/1410090988.md) exécutée lorsqu'une signature invalide est détectée dans un document PDF.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCÉDURE Proc_vérification(Doc_pdf, Indice_Signature, Code_Erreur)
// Traitement du code d'erreur
texte_erreur est une chaîne
SELON Code_Erreur
	CAS pdfSignatureInvalide : texte_erreur = ChaîneConstruit("Signature %1 non valide", indice_signature)
	CAS pdfCertificatExpiré : texte_erreur = ChaîneConstruit("Le certificat de la signature %1 est expiré", indice_signature)
	CAS pdfModifiéApresSignature : texte_erreur = "Le PDF a été modifié après signature"
FIN
// Identification de la signature posant problème 
SI Indice_Signature > 0 ALORS
	texte_erreur += RC + RC
	// Informations sur la signature
	soit buf_signature = PDFRécupèreSignature(Doc_pdf, Indice_Signature)
	certif est un Certificat = CertificatExtrait(buf_signature)
	texte_erreur += ChaîneConstruit([
		Signature numéro %1
		Émetteur : %2
		Nom : %3
		Date de début de validité : %4
		Date de Fin de validité : %5
		Date de la signature : %6
	],
	Indice_Signature,
	certif.Emetteur,
	certif.Nom,
	DateVersChaîne(certif.DateValiditéDébut),
	DateVersChaîne(certif.DateValiditéFin),
	DateVersChaîne(PDFRécupèreDateSignature(Doc_pdf, indice_signature)))
FIN
// Si 
SI ErreurDétectée ALORS
	texte_erreur += RC + RC+ ErreurInfo(errRésumé)
	// Affiche l'erreur
	Info(texte_erreur)
	// On ne continue pas le parcours des signatures
	RENVOYER Faux
SINON
	// On continue le parcours des signatures
	// Si une signature fausse est trouvée, la procédure est relancée. 
	RENVOYER VRAI
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = PDFVérifieSignatures_Callback(<Document PDF> , <Indice de la signature> , <Code erreur>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la fonction [PDFVérifieSignatures](../WDLang6/1410090988.md) doit continuer le parcours des signatures du document (la procédure doit utiliser "RENVOYER Vrai").

- <u><u><u><u>Faux</u></u></u></u> si la fonction  [PDFVérifieSignatures](../WDLang6/1410090988.md) doit arrêter le parcours des signatures du document (la procédure doit utiliser "RENVOYER Faux").




**`<Document PDF> : (Variable de type pdfDocument)`**

Variable de type [pdfDocument](../WDLang6/1000024909.md) correspondant au document PDF manipulé. 

**`<Indice de la signature> : (Entier)`**

Numéro de la signature trouvée en erreur dans le document PDF analysé. Il est possible de récupérer la signature pour connaître ses caractéristiques grâce à la fonction [PDFRécupèreSignature](../WDLang6/1410088120.md). 

**`<Code erreur> : (Constante de type Entier)`**

Code correspondant à l'erreur associée à la signature invalide : 


|   |   |
| --- | --- |
| *pdfCertificatExpiré* | Le certificat de la signature est expiré. |
| *pdfModifiéAprèsSignature* | Le PDF a été modifié après sa signature. |
| *pdfSignatureInvalide* | La signature est invalide. |




}
