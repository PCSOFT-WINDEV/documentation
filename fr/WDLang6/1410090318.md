
## Constantes de gestion des visites guidées
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les constantes utilisées par la gestion de la visite guidée sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **vgaAucune** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours : <br>Le clic sur le ou les champs cibles est sans effet. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgaChamp** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours : <br>Le champ fonctionne normalement. Les événements associés au champ sont exécutés. Le passage à l'étape suivante doit être fait par programmation. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgaChampPuisEtapeSuivante** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours : <br>Le champ fonctionne normalement. A la fin de l'exécution du code du champ, la visite guidée passe automatiquement à l'étape suivante.<br>Cette action est opérationnelle uniquement sur les champs suivants : Bouton, Interrupteur, Sélecteur et Option de menu. Pour les autres champs, seul le passage à l'étape suivante sera effectué. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgaDéfaut** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours : <br>L'action effectuée dépend du type d'effet choisi | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgaEtapeSuivante** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours :<br>Le clic sur le champ permet uniquement de passer à l'étape suivante. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgaFin** | Action effectuée lors d'un clic sur le ou les champ(s) cibles de l'étape en cours :<br>Le clic sur le champ termine toute la visite guidée. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgEtapePrécédente** | Etape à afficher : Affiche l'étape précédente de l'étape en cours. | [VisiteGuidéeChangeEtape](../WDLang6/1410090229.md) |
| **vgEtapeSuivante** | Etape à afficher : Affiche l'étape suivante de l'étape en cours. | [VisiteGuidéeChangeEtape](../WDLang6/1410090229.md) |
| **vgfCercle** | Forme à utiliser pour le "trou" (effet GFI) ou pour le halo (effet Halo) : Cercle | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgfRectangle** | Forme à utiliser pour le "trou" (effet GFI) ou pour le halo (effet Halo) : Rectangle | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgInfoDate** | Date à laquelle la visite guidée a été vue pour la dernière fois sur le poste en cours. | [VisiteGuidéeInfo](../WDLang6/1410090219.md) |
| **vgInfoOccurrence** | Nombre de fois où l'utilisateur a vu la visite guidée. | [VisiteGuidéeInfo](../WDLang6/1410090219.md) |
| **vgInfoVersion** | Numéro de version de la dernière visite guidée vue par l'utilisateur. | [VisiteGuidéeInfo](../WDLang6/1410090219.md) |
| **vgModeOpaque** | Mode d'affichage de la bulle : <br>La bulle est affichée dans une fenêtre popup avec une flèche qui pointe sur le ou les champs cible. Avec la fenêtre interne par défaut, des boutons permettent de passer à l'étape suivante/précédente ou de terminer la visite. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgModeTransparent** | Mode d'affichage de la bulle : <br>La bulle est affichée avec un fond transparent à côté du ou des champs cible. Dans ce mode aucune interaction n'est possible avec les champs de la fenêtre interne. Dans ce mode, il est conseillé d'utiliser l'effet GFI. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgtAucun** | Type d'effet : aucun effet d'affichage. | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgtGFI** | Type d'effet : grise le contenu de la fenêtre hôte en laissant apparaitre un trou autour du ou des champ(s) cible(s). | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
| **vgtHalo** | Type d'effet : affiche un halo autour du ou des champ(s) cible(s). | Type [VisiteGuidée](../WDLang6/1410090170.md)<br>Type [VisiteGuidéeEtape](../WDLang6/1410090178.md) |
