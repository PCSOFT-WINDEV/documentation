
## Fonctions Palette
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
 
Les fonctions de gestion de palettes de couleurs sont les suivantes : 



|   |   |
| --- | --- |
| [PaletteChange](../WDLang6/1410090897.md) | Modifie la palette utilisée par le projet ou par une fenêtre. |
| [PaletteCharge](../WDLang6/1410090780.md) | Charge une palette à partir d'un fichier de type ".wdpalette". |
| [PaletteGénère](../WDLang6/1410090825.md) | Génère une palette à partir d'une couleur de base. |
| [PaletteRécupère](../WDLang6/1410090898.md) | Récupère la palette courante du projet ou la palette de la fenêtre. |
| [PaletteSauve](../WDLang6/1410090779.md) | Sauve une palette dans un fichier. |
