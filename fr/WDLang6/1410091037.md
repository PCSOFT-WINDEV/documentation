


## &lt;Variable pdfDocument&gt;.VérifieSignatures (Fonction)

***En anglais : &lt;pdfDocument variable&gt;.VerifySignatures***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie la validité des signatures contenues dans un PDF. En cas de signature invalide, il est possible de connaître les caractéristiques de la signature qui pose problème. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Chargement du pdf
Mon_pdf est un pdfDocument = chemin_pdf

// Vérification de la signature
// Lance la procédure uniquement si une signature invalide est détectée
Mon_pdf.VérifieSignatures(Proc_vérification)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Document>.VérifieSignatures(<Procédure WLangage>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la vérification a été effectuée et n'a pas détecté de problème : le document a été ouvert et il contient des signatures valides ou aucune signature. 
	Rappel : Le nombre de signatures peut être vérifié avec la fonction [&lt;Variable pdfDocument&gt;.NbSignature](../WDLang6/1410088154.md). 

- <u><u><u><u>Faux</u></u></u></u> dans les cas suivants : le document n'a pas pu être ouvert, une des signatures est invalide ou le PDF a été modifié après sa signature.




**`<Document> : (Variable de type pdfDocument)`**

Nom de la variable de type [pdfDocument](../WDLang6/1000024909.md) contenant le document PDF à analyser.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage (également nommée "callback") exécutée pour chaque signature non valide trouvée.
Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction &lt;Variable pdfDocument&gt;.VérifieSignatures](../WDLang6/1410090989.md).
