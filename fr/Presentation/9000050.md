


## Nouvelles fonctionnalités de WINDEV 2026
			



<a name="NOTE1"></a>

## Présentation
<a name="presentation_ELTTEXTE000076"></a>
WINDEV 2026 est disponible ! 

Voici la liste des principales nouveautés que vous pourrez découvrir dans WINDEV 2026.

<a name="NOTE2_1"></a>


## Nouveautés de la version 2026
<a name="nouveautes_version_docparamversioncom_b972d91723d541edbb4aa32ee98a3030"></a>
Liste des nouveautés classées par thème : 




|   |
| --- |
| **Environnement** |




- Intégration de l'IA dans votre environnement : 

	- Posez des questions à votre AGL : il vous répond grâce à l'IA.

	- Demandez à l'IA d'effectuer des actions dans vos projets. 

	- Posez des questions sur votre projet, l'IA y répond. 

	- Utilisez le chat pour communiquer avec l'IA. 

	- Choisissez le modèle d'IA de votre choix : Claude, Mistral, Chatgpt, Gemini, ...

	- Les conversations sont conservées : vous pouvez y revenir.

	- Undo général sur le projet disponible.







- Utilisation de la technologie Direct2D dans l'environnement. 

- Modifieur : Nouvelles options. 

- Configuration de l'environnement synthétisée. 

- Outils de l'environnement livrés en 64 bits.






|   |
| --- |
| **Editeur de projet** |




- Nouvel audit disponible : Audit de sécurité. 

- Composants internes :

	- Tableau de bord du projet : Le widget composant affiche des informations sur les composants internes. 

	- Possibilité de renommer un composant interne. 




- Fenêtre d'accueil : 

	- La date de dernière ouverture des projets est affichée.









- Nouvelle configuration de projet : DLL, pour la création de DLL.

- Création d'exécutable : Message d'avertissement en cas d'erreurs de compilation.






- RAD MVP : Génération d'états.






- **Palettes WINDEV**

	- Editeur de palettes.

		- Création assistée de palettes. 

		- Modification de palettes existantes. 

		- Visualisation du rendu.  




- Nouvelles palettes de couleurs.

- Palettes sombres associées aux palettes claires. 

- Toast : Adaptation automatique aux couleurs de la palette en cours. \*

- Possibilité de créer des dégradés de couleurs à partir des couleurs de la palette. 

- Création d'installation avec utilisation de la palette de couleurs.






|   |
| --- |
| **Editeur de fenêtres** |




- **Nouveau champ**

	- Champ Chat IA : 

		- Interfacez vos applications WINDEV avec le modèle d'IA de votre choix. 

		- Intégrez un agent conversationnel dans vos applications. 




- Champ Grille : Utilisez une grille de positionnement relatif dans vos UI.




- **Champs Métier WINDEV : Nouveaux champs**

	- Nouvelle présentation des Champs Métier. 

	- Nouveaux champs métier : 

		- Boutons segmentés. 

		- Zone répétée Produit. 

		- Zone répétée Evénement. 

		- Saisie d'IBAN avec analyse de document. 

		- Saisie de numéro SIREN avec vérification de validité.







- **Améliorations des champs (WINDEV)**

	- Champs de saisie : 

		- Choisissez le style des boutons présents dans les champs de saisie.




- Champ TCD : 

	- Par défaut, le champ TCD conserve les choix de présentation précédemment effectués. 

	- Le calcul d'un champ TCD peut désormais être effectué en mode asynchrone. 




- **Fonctionnalités de l'éditeur de fenêtres**

	- Hot Reload : Testez vos modification en temps réel, sans arrêter le test.

	- Edit and continue.   







- **Nouvelles erreurs d'UI**

	- Erreur d'UI si le contenu d'une combo est vide dans une des langues associées au projet.









|   |
| --- |
| **Editeur d'images** |




- Multisélection au lasso. 

- Recadrage intelligent (magic crop)






|   |
| --- |
| **Editeur d'analyses** |




- Volet "Modifieur" dans l'analyse. 

	- Informations sur les fichiers de données. 

	- Informations sur les rubriques. \*




- Réorganisation automatique du schéma des données. \*






|   |
| --- |
| **Editeur de requêtes** |




- Optimisations des requêtes : une requête possédant des plages de conditions qui se chevauchent est optimisée.






|   |
| --- |
| **Editeur de code** |




- Editeur :

	- Edition de fichiers de code au format texte : CSS, HTML, JSON, ...

	- Recherche sémantique dans le code. 

	- Bulle d'aide sur les procédures et variables des WebServices. 

	- Numérotation : Visualisation de la ligne de code en cours. 

	- Tri des méthodes et procédures. 

	- Assistant de génération des expressions régulières. 

	- Norme de programmation : signalement des mélanges de vocabulaire. 

	- Copie de code WLangage vers un logiciel tiers : format texte et format HTML







- Débogueur : 

	- Point d'arrêt : détection des fuite mémoire. 

	- Edit and Continue. 

	- Visualisation des chaînes de grande taille.









|   |
| --- |
| **Editeur d'états** |




- Modèles de champs. 

- Création d'états sur classe (MVP)

- Création d'états basés sur un tableau de classes. 

- Flexbox dans les états. 

- Etat Planning : Semaines affichées au format ISO 8601

- Images : Prise en compte des info EXIF. 

- Champ Sélecteur. 

- Visualisateur de rapport : Bulle d'aide sur les champs

- Logiciel Etats et Requête livré en version 64 bits.






|   |
| --- |
| **Editeur d'aide** |




- Aide au format PDF : Options de présentation du fichier PDF (simple ou double page, page de garde, protection, etc.).






|   |
| --- |
| **GDS (Gestionnaire de sources)** |




- Historisation locale. 

- Log des erreurs. 

- Sauvegarde de la base en un seul fichier. 

- Avertissement en cas d'utilisation d'une base du GDS en version obsolète. 

- Branche : Support des patchs d'exécutable. 

- Connexion à des bases GDS différentes.






|   |
| --- |
| **Git / GitHub / GitLab** |




- Chaînes multilingues au format Texte.






|   |
| --- |
| **Installation** |




- Création d'exécutable : Message d'avertissement si des erreurs de compilation sont détectées. 

- UI du programme d'installation : Utilisation de la palette de couleurs. 

- Génération d'installations au format MSIX. 

- Génération d'installations au format MSI en 64v bits. 

- Passer d'une installation "avec UAC" à une installation "sans UAC".






|   |
| --- |
| **Store privé** |




- Les caractéristiques saisies par l'administrateur à propos d'une application sont automatiquement reportées dans la page de téléchargement de l'application.








|   |
| --- |
| **Documentation Technique et Fonctionnelle** |




- Les rubriques RGPD sont signalées.






|   |
| --- |
| **Intégration continue - Fabrique logicielle** |




- Gestion des droits. 

- Nouvelles actions :

	- Supprimer une branche du GDS

	- Passer un projet au format texte ou binaire

	- Générer un fichier de statistiques sur le projet




- Administrateur de la fabrique disponible en Espagnol.






|   |
| --- |
| **Outils** |




- Audit statique : 

	- Détection des chaînes de caractères multilingues en format inadapté (format historique)







- Audit dynamique : 

	- Utilisation de l'ancienne méthode d'ouverture des fenêtres avec paramètres. 







- Audit de sécurité : 

	- Audit statique de sécurité. 

	- Audit dynamique de sécurité. 







- Télémétrie : 

	- Collecte des exceptions (fonction TélémétrieEnvoieException).







- Tests automatiques 

	- Copier/coller de scénarios. \*







- Robot de surveillance :

	- Surveillance par SSH. 

	- Surveillance de serveur HFSQL sur un réseau local (LAN)

	- Robot en anglais et espagnol.









|   |
| --- |
| **Centre de Gestion de Projets** |




- Graphique d'avancement des sprints. 

- Centre de Gestion de projets livré en 64 bits. 

- Sélection multiple dans la liste des incidents. 

- Filtre multi-sprint dans la liste des tâches et des incidents.






|   |
| --- |
| **FAA (Fonctionnalités Automatiques de vos Applications)** |




- Champ Tableau Croisé Dynamique (TCD)

	- L'option "Mémoriser la taille et les regroupements" mémorise également la réorganisation des entêtes réalisée par l'utilisateur final. \*











|   |
| --- |
| **Groupware utilisateur** |




- Utilisation d'un token OAuth pour l'authentification.




- Mode BaaS : La fonction **gpwRechercheUtilisateur** est désormais disponible.






|   |
| --- |
| **Programmation et WLangage** |






- **Composant interne** : Factur-X

	- Un composant interne Factur-X est disponible pour la génération des factures électroniques. 

	- Gestion des différents profils. 

	- Génération du XML

	- Assistance au choix des unités. 

	- Insertion du logo Factur-X.







- **Webservices GraphQL** : Nouveau type RequêteGraphQL. 




- **Gestion des flux de données par bloc (Chunk)** : 

	- Variable de type HTTPRequête : Nouvelle propriété ProcédureDonnées. 

	- Nouvelle fonction WebserviceEnvoieMorceau. 







- **Fonctions email** : nouvelles fonctions pour gérer des cas particuliers : 

	- emailExécuteCommande 

	- emailAbonneAuDossier

	- emailDesabonneDuDossier









- **OAuth**

	- Connexion à un serveur OAuth nécessitant un certificat. 

	- Support des assertions JWT. 

	- Authentification de type "Client Secret Basic". 







- **OpenID**

	- Connexion à un serveur nécessitant un certificat. 

	- Authentification de type "Client Secret Basic". 







- **Fonctions FTP**

	- Nouvelle variable de type **ftpConnexion** utilisable par toutes les fonctions FTP. 







- **Fonctions SSH**

	- 2 nouvelles fonctions : **SSHConnecteCommande** et **SSHDéconnecteCommande**. 







- Opérateur = sur tableau.






- Instruction POUR TOUT : Attribut &lt;Sans filtre&gt; pour parcourir une table sans tenir compte des filtres utilisateur éventuel. 




- **Signature numérique par certificat sur une carte à puce**

	- Les fonctions de signature fonctionnent avec un certificat présent sur une carte à puce. 







- **Gestion des PDF**

	- Informations de protection des fichiers PDF : 

		- La propriété **Protection** permet de récupérer les informations de protection d'un fichier PDF. 

		- Les fonctions **PDFMotDePasse** et **iParamètrePDF** permettent de définir des nouvelles options de protection pour les fichiers PDF. 




- Possibilité de connaître le champ présent sous le curseur de souris. 




- **Ouverture d'une fenêtre** : 

	- Initialisation des propriétés d'affichage d'une fenêtre avant son ouverture. 

	- Initialisation des paramètres passés à une fenêtre avant son ouverture.







- **Procédure réactive** 

	- Déclarer manuellement une variable à observer. 







- **Notifications Windows** : 

	- Gestion des jauges. 

	- Nouvelles fonctions et nouvelles propriétés. 







- **Gestion des archives** :

	- Création d'archives auto-extractibles en 64 bits. 

	- Possibilité de donner un numéro de version lors de la création d'une archive auto-extractible. 

	- Amélioration des performances de compression des archives au format ZIP de 30%

	- Amélioration des performances de compression des archives au format 7z de 90% 







- **JSON**

	- Sérialisation des types JSON en binaire.

	- La fonction JSONVersChaîne permet désormais d'encoder les caractères accentués à la norme UTF8.









- **POO (Programmation Orientée Objet)**

	- Nouveau mode "Les classes sont des références". 

		- Passage de paramètres simplifié. 

		- Mode pour le projet ou le composant interne

		- Possibilité de modifier la référence de l'appelant.

		- Les classes sont nullables




- Attribut Zombie sur les classes. 

- Egalité des structures. 

- Réflexion : Possibilité de récupérer les méthodes de classe surchargées par la réflexion. 

- Interface : les mots-clés EST et DOWNCAST ainsi que la propriété Classe sont disponibles sur les interfaces.






- **Nouvelles fonctions, propriétés et nouveaux types**.

	- Nouvelles familles de fonctions : 

		- Fonctions de gestion du champ Chat IA. 

		- Fonctions de gestion de la clé secrete de Shamir. 




- Nouvelles fonctions : 

	- Fonctions de gestion des fenêtres

		- **FenListeFenêtreOuverte** : Liste toutes les fenêtres ouvertes. 

		- **FenListeFenêtreFilleOuverte** : Liste les fenêtres filles ouvertes par une fenêtre donnée. 

- **Fonctions modifiées** : 

	- **TablePosition** : Nouvelle constante permettant de se positionner sur la fin de la dernière ligne. 

	- **SysVersionWindows** : la constante *sysEstServeur* permet de savoir si le sytème d'exploitation en cours est un système serveur. 




- **Types modifiés** : 

	- **tcdPosition** : Permet de connaître les informations concernant l'élément sélectionné dans un champ TCD. \*









- **Langages tiers** : 

	- Possibilité de saisir du code de langages tiers directement sous l'éditeur de code.









- **IOT**

	- MQTT : Possibilité de connaître l'état d'une connexion MQTT. 

	- Sockets : Possibilité de passer le store de certificats Windows en paramètre à la fonction **SocketCréeSSL**.
