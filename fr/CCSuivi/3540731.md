
## Centre de Gestion de Projets : Kanban
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000082"></a>
Le centre de Gestion de Projets propose de suivre les tâches d'un intervenant présentes dans un sprint grâce à un Kanban. 

Grâce au Kanban, il est possible de visualiser rapidement l'état d'avancement des tâches d'un développeur : tâches en attente, en cours, bloquées ou terminées. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_Suivi_Kanban%20-%20HC%20N%B0001.gif)


L'état des tâches peut être modifié par simple Drag and Drop.

<a name="NOTE2_1"></a>


## Comment le faire ?
<a name="comment_faire_ELTTEXTE000106"></a>


### Afficher le kanban
<a name="afficher_kanban_ELTPARAGRAPHE000022"></a>Le kanban des tâches peut être affiché via un onglet "Kanban". Par défaut, le kanban de l'utilisateur en cours est affiché pour le sprint en cours. 



Le Centre de Gestion de projet permet de sélectionner les tâches affichées dans le kanban : 

- Sélection du sprint concerné. 

- Sélection du type de tâche à présenter. 

- Intervenant(s) concerné(s). 




Les tâches sont présentées sous forme de cartes, affichées dans 4 listes : en attente, en cours, bloquées ou terminées.

Les cartes peuvent être affichées en mode standard ou compact.
