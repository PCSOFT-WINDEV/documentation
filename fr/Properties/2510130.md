


## Valeur (Propriété)

***En anglais : Value***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Valeur** permet de :

- Connaître et modifier la valeur d'un champ d'un état.

- Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.

- Connaître l'identifiant d'un flux. 

- Connaître et modifier la valeur d'un champ ou le titre d'une page.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Connaître les fichiers gérés par un champ Upload.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Connaître et modifier le plan actuellement affiché dans un champ Bandeau défilant.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) Centrer la carte présente dans un champ Carte sur une position spécifique.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Connaître et modifier la valeur inférieure de l'intervalle actuellement sélectionné dans un champ Potentiomètre d'intervalle.

- Connaître la valeur associée à une valeur d'une variable de type [Enumération](../Motscles/1514067.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) Connaître l'identifiant ou le handle associé à un champ Conteneur natif.




**Remarque** : La propriété **Valeur** est rarement utilisée et peut être remplacée par une syntaxe équivalente (voir Remarques).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modifier le fichier image associé au champ Image "IMG_Image"
IMG_Image.Valeur = "C:\MesImages\Image.BMP"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la valeur d'un élément

`<Résultat> = <Elément manipulé>.Valeur`
---

**`<Résultat> : (Tout type)`**

Ce résultat dépend du type de l'élément.

**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la valeur d'un élément

`<Elément manipulé>.Valeur = <Nouvelle valeur>`
---

**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément à manipuler.

**`<Nouvelle valeur> : (Tout type)`**

Nouvelle valeur de l'élément spécifié. Ce paramètre dépend du type de l'élément spécifié.

### Valeur d'un champ de saisie

### Valeur d'un champ Bouton segmenté
<a name="valeur_champ_bouton_segmente_ELTPARAGRAPHE000313"></a>La propriété **Valeur** permet de récupérer ou de modifier les éléments sélectionnés dans un champ Bouton segmenté. 

Il est possible de : 

- connaître et modifier l'option sélectionnée via la syntaxe : 
	
	```txt
	<Champ Bouton segmenté>[Indice de l'option]
	```
La valeur renvoyée ou affectée correspond à 0 si l'option n'est pas sélectionnée, et à 1 si l'option est sélectionnée. 

- connaître et modifier l'option sélectionnée dans un champ Bouton segmenté de type "sélecteur". Dans ce cas, la propriété **Valeur** correspond au numéro de l'option sélectionnée. 
	Exemple : Dans le champ, l'option 1 est sélectionnée :
	
	```wl
	Trace(BS_Test.Valeur) // Renvoie 1
	```


- connaître et modifier les options sélectionnées dans un champ Bouton segmenté de type "interrupteur". Dans ce cas, la propriété **Valeur** correspond à une chaîne de caractères composée de 0 et de 1 correspondant aux options sélectionnées (1) ou non (0). 
	
	Exemple : Dans le champ, les options 1 et 3 sont sélectionnées et l'option 2 et 4 ne sont pas sélectionnées : 
	
	```wl
	Trace(BS_Test.Valeur) // Renvoie 1010
	```

### Valeur d'un champ Interrupteur ou d'une option d'un champ Interrupteur
<a name="valeur_champ_interrupteur_une_option_champ_interrupteur_ELTPARAGRAPHE000351"></a>La propriété **Valeur** permet de :

- Cocher ou décocher une option d'un champ Interrupteur.

- Savoir si une option d'un champ Interrupteur est cochée ou décochée




&lt;Résultat&gt; est un booléen : 

- <u><u><u><u>Vrai</u></u></u></u> si l'option est cochée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




Pour savoir si une option d'un champ Interrupteur est cochée ou non, les syntaxes suivantes sont équivalentes :

```txt
ResCoché = <Champ Interrupteur>[<Numéro de l'option>].Valeur

ResCoché = <Champ Interrupteur>[<Numéro de l'option>]

ResCoché = <Nom de l'option>.Valeur

ResCoché = <Nom de l'option>
```
Remarque : Si le paramètre &lt;Numéro de l'option&gt; n'est pas spécifié, la première option est sélectionnée par défaut.

### Valeur d'un champ Sélecteur

### Valeur d'un champ Liste, Liste image ou Table
<a name="valeur_champ_liste_liste_image_table_ELTPARAGRAPHE000403"></a>Deux cas distincts se présentent.

- Le champ Liste (champ Liste image ou champ Table) est un champ par programmation OU la propriété [RubriqueMémorisée](../Proprietes/2510110.md) correspond à une chaîne vide ("").
	La propriété **Valeur** permet de :

	- Connaître la ligne sélectionnée. Si aucune ligne n'est sélectionnée, la propriété **Valeur** retourne -1. Si le champ est multisélection, le numéro de la dernière ligne sélectionnée est renvoyé.
			Pour connaître la ligne sélectionnée, les syntaxes suivantes sont équivalentes :
			
		```txt
		ResLigne = <Nom du champ>.Valeur
		
		ResLigne = <Nom du champ>
		```


	- Déplacer la sélection en indiquant le numéro de la nouvelle ligne à sélectionner. La ou les lignes précédemment sélectionnées sont dé-sélectionnées.   




- Le champ Liste (champ Liste image ou champ Table) est un champ fichier ET la propriété [RubriqueMémorisée](../Proprietes/2510110.md) n'est pas vide.
	La propriété **Valeur** permet de connaître la rubrique mémorisée pour l'enregistrement associé à la ligne sélectionnée. Si aucune ligne n'est sélectionnée, la propriété **Valeur** retourne une chaîne vide ("").
	Pour connaître la rubrique mémorisée associée à la ligne sélectionnée, les syntaxes suivantes sont équivalentes :
	
	```txt
	ResRubMem = <Nom du champ>.Valeur
	
	ResRubMem = <Nom du champ>.RubriqueMémorisée
	```
