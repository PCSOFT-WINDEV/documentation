


## Alias (Propriété)

***En anglais : Alias***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
**Attention** : La propriété **Alias** n'a pas la même fonction dans WEBDEV que dans WINDEV et WINDEV Mobile.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/fr/WM.png) La propriété **Alias** permet de connaître ou de modifier : 

- l'alias d'une fenêtre. Pour modifier l'alias d'une fenêtre, il est également possible d'utiliser la fonction [FenChangeAlias](../WDLang1/3038028.md). 
	**Rappel** : Un alias permet de différencier la même fenêtre ouverte plusieurs fois (cas fréquent dans une application MDI).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) l'alias d'un volet d'un champ Onglet dynamique. 




![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La propriété **Alias** renvoie le nom interne HTML/Javascript d'un champ.
En effet, le WLangage est plus permissif sur les noms des champs et des pages que le Javascript : utilisation de caractères spéciaux, possibilité d'avoir deux champs de même nom dans une même page, etc.
Les noms de champs et de pages sont donc renommés dans les pages HTML. De plus, ces noms peuvent être compressés pour des raisons d'optimisation.
La propriété **Alias** permet de connaître le nom utilisé dans la page HTML.

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) 
```wl
// Ouverture d'une nouvelle fenêtre fille
OuvreFille(FEN_Fille, sNomFichier)
{sNomFichier}..x = 10
// {sNomFichier} = alias de la fenêtre
```

```wl
// -- Code d'ouverture de FEN_Fille
PROCEDURE FEN_Fille(sNomFic)
MoiMême.Alias = sNomFic
// Définition de l'alias
// Change le titre de la fenêtre que l'on vient d'ouvrir
{sNomFic}..Titre = "Fichier = " + {sNomFic}..Alias
```

### Connaître l'alias d'une fenêtre

`<Alias en cours> = <Fenêtre>.Alias`
---

**`<Alias en cours> : (Chaîne de caractères)`**



- Alias de la fenêtre, 

- Chaîne vide ("") si la fenêtre spécifiée n'a pas d'alias.




**`<Fenêtre> : (Nom de fenêtre)`**

Nom de la fenêtre manipulée. Ce paramètre peut être égal :

- soit à [MoiMême](../Motscles/1511007.md). Par exemple, si le nom de l'alias de la fenêtre en cours est recherché.

- soit à une indirection sur l'alias de la fenêtre. En effet, le nom de l'alias ne sera connu qu'en exécution. Lors de la compilation du code, le nom de l'alias n'est pas encore connu.

### Modifier l'alias d'une fenêtre

`<Fenêtre>.Alias = <Nouvel alias>`
---

**`<Fenêtre> : (Nom de fenêtre)`**

Nom de la fenêtre manipulée. Ce paramètre peut être égal :

- soit à [MoiMême](../Motscles/1511007.md). Par exemple, si le nom de l'alias de la fenêtre en cours est recherché.

- soit à une indirection sur l'alias de la fenêtre. En effet, le nom de l'alias ne sera connu qu'en exécution. Lors de la compilation du code, le nom de l'alias n'est pas encore connu.




**`<Nouvel alias> : (Chaîne de caractères)`**

Nouvel alias de la fenêtre.

### Différences entre la propriété Nom et la propriété **Alias**
<a name="differences_entre_propriete_nom_propriete_docparampagetitleshort_ELTPARAGRAPHE000144"></a>La propriété [Nom](../Proprietes/2510082.md) renvoie le nom WLangage du champ alors que la propriété **Alias** renvoie le nom HTML du champ. Pour passer un nom de champ en paramètre à une procédure Javascript, utilisez la propriété **Alias**.
