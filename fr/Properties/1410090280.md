
## EtapeSuivante (Propriété)

***En anglais : NextStep***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **EtapeSuivante** permet d'autoriser ou non le passage à l'étape suivante de la visite guidée depuis la bulle de l'étape. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
