
## Profondeur (Propriété)

***En anglais : Depth***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Profondeur** permet de connaître la profondeur d'un élément. Cette propriété est utilisable sur :

- une variable de type [xmlLecteur](../WDLang5/1000023392.md).

- une variable de type [jsonLecteur](../WDLang1/1410090783.md).
