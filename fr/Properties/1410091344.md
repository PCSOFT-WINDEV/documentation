
## IAConversation (Propriété)

***En anglais : IAConversation***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IAConversation** permet de connaître les différents éléments de la conversation en cours dans un champ Chat IA. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI CHATIA_MonChatIA.IAConversation.RequêteEnCours ALORS
   IMG_Jauge.Visible = Vrai
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître les caractéristiques d'une conversation dans un champ Chat IA

`<Résultat> = <Champ Chat IA>.IAConversation.<Nom de la propriété>`
---

**`<Résultat> : (Type correspondant à la propriété)`**

Résultat correspondant à la propriété utilisée. 

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé. 

**`<Nom de la propriété> : (Chaîne de caractères)`**

Propriétés utilisées : 


| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Elément | Tableau de [iaElémentConversation](../WDLang1/1410091337.md) | Tableau des éléments de la conversation avec l'IA : suite de questions et de réponses, dans l'ordre. <br><br>Le premier élément du tableau correspond au prompt système. |
| Nom | Chaîne de caractères | Nom de la conversation |
| NombreToken | Entier | Nombre de tokens utilisé par la conversation. <br><br>**Cette propriété est disponible en lecture seulement**. |
| RequêteEnCours | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si une requête vers l'IA est en cours. Une animation est alors affichée dans le champ Chat IA. <br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br><br><br>**Cette propriété est disponible en lecture seulement**. |
