
## GraduationX (Propriété)

***En anglais : IntervalX***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **GraduationX** permet de connaître le pas de graduation sur l'axe des X. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche le pas de graduation sur l'axe des X
Info(GRF_MonGraphe.GraduationX)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Graphe>.GraduationX`
---

**`<Résultat> : (Réel)`**

Pas de graduation sur l'axe des X. 

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler.
