
## TypeFichierClé (Propriété)

***En anglais : KeyFileType***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **TypeFichierClé** permet de définir le type d'encodage du fichier de clé. Cette propriété est utilisable sur : 

- une variable de type [xmlSignature](../WDLang5/1000020736.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) une variable de type [xmlVérificationSignature](../WDLang5/1410090389.md). 

- une variable de type [xmlSignatureXAdES](../WDLang5/1410091158.md).
