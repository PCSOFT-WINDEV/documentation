
## MotDePasseClé (Propriété)

***En anglais : KeyPassword***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **MotDePasseClé** permet de définir le mot de passe permettant de décrypter la clé privée. Cette propriété est utilisable sur : 

- une variable de type [xmlSignature](../WDLang5/1000020736.md). 

- une variable de type [xmlSignatureXAdES](../WDLang5/1410091158.md).
