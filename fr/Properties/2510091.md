


## PoliceBarrée (Propriété)

***En anglais : FontStrikeOut***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **PoliceBarrée** permet de :

- Savoir si le texte affiché est barré ou non.

- Barrer ou non le texte affiché dans un champ.




![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette propriété est disponible uniquement pour les champs des états.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Barrer le texte affiché dans le champ "LIB_ChampLibellé"
LIB_ChampLibellé.PoliceBarrée = Vrai
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si le texte affiché dans un champ est barré

`<Résultat> = <Champ manipulé>.PoliceBarrée`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le texte affiché est barré, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  


<a name="SYNTAXE2"></a>

### Barrer ou non le texte affiché dans un champ

`<Champ manipulé>.PoliceBarrée = <Barré/Non barré>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  

**`<Barré/Non barré> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le texte affiché doit être barré, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Limites
<a name="limites_ELTPARAGRAPHE000090"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Dans un état, la propriété **PoliceBarrée** peut être utilisée uniquement sur :

- un champ Libellé.

- un champ Calculé.

- un champ Lien URL.

- un champ Prédéfini.


Dans une fenêtre, la propriété **PoliceBarrée** ne peut pas être utilisée sur :

- un champ Spin,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) un champ Web Camera,

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) un champ Conférence.


Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
