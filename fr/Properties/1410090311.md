
## CouleurCadre (Propriété)

***En anglais : BorderColor***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CouleurCadre** permet de définir la couleur du cadre de la bulle de l'étape de la visite guidée. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
