
## Masquable (Propriété)

***En anglais : Hideable***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Masquable** permet de savoir et de définir si l'utilisateur peut fermer au doigt la fenêtre coulissante basse associée à la fenêtre en cours.

Remarque : Il est toujours possible de fermer la fenêtre coulissante basse par programmation avec la fonction [FenCoulissanteVisible](../WDLang1/1000020978.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaFenêtreCoulissanteBasse.SurInvisibilité = () => { Trace("La fenêtre coulissante basse a disparue") }
MaFenêtreCoulissanteBasse.ParamètresOuverture = (42, "Adams")
MaFenêtreCoulissanteBasse.FenêtreInterne = "FI_Menu_Coulissant"
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurEtendue = 0.9 // 90% 
MaFenêtreCoulissanteBasse.Modale = Vrai
MaFenêtreCoulissanteBasse.Masquable = Vrai
MaFenêtreCoulissanteBasse.CoinArrondi = Faux

// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Savoir si l'utilisateur peut fermer la fenêtre coulissante basse au doigt

`<Résultat> = <Fenêtre coulissante>.Masquable`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'utilisateur peut fermer la fenêtre coulissante basse au doigt, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Fenêtre coulissante> : (MaFenêtreCoulissanteBasse)`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.


<a name="SYNTAXE2"></a>

### Définir si l'utilisateur peut fermer la fenêtre coulissante basse au doigt

`<Fenêtre coulissante>.Masquable = <Nouvelle valeur>`
---

**`<Fenêtre coulissante> : (MaFenêtreCoulissanteBasse)`**

Mot-clé [MaFenêtreCoulissanteBasse](../Motscles/1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.

**`<Nouvelle valeur> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'utilisateur peut fermer la fenêtre coulissante basse au doigt, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.
