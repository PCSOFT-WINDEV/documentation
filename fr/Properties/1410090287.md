
## Markdown (Propriété)

***En anglais : Markdown***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Markdown** permet de gérer le format Markdown : 

- dans un champ d'une fenêtre. Pour plus de détails, consultez l'aide de la propriété [Markdown](../Proprietes/1410089000.md). 

- dans un champ Libellé d'un état. Pour plus de détails, consultez l'aide de la propriété [Markdown](../Proprietes/1410089000.md). 

- dans les champs de la fenêtre interne (titre et description) correspondant à l'étape de la visite guidée. Cette propriété est utilisable sur :

	- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

	- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
