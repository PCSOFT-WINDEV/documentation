
## Parent (Propriété)

***En anglais : Parent***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Parent** permet de connaître l'élément parent d'un élément. Cette propriété est utilisable sur :

- une variable de type [docElément](../WDLang1/1000022484.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [docParagraphe](../WDLang1/1000022483.md).

- une variable de type [jsonLecteur](../WDLang1/1410090783.md). 
	

- une variable de type [OptionsOuvertureFenêtre](../WDLang1/1410091298.md).
