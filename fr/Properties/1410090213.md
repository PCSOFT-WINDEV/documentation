
## ActionHorsCible (Propriété)

***En anglais : ActionOutsideTarget***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ActionHorsCible** permet de définir l'action effectuée lors d'un clic sur des champs différents des champs cibles de l'étape d'une visite guidée. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).
