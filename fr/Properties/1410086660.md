
## AlgorithmeNormalisation (Propriété)

***En anglais : NormalizationAlgorithm***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **AlgorithmeNormalisation** permet de définir la méthode de standardisation du XML (C14N). Cette propriété est utilisable sur : 

- une variable de type [xmlSignature](../WDLang5/1000020736.md). 

- une variable de type [xmlSignatureXAdES](../WDLang5/1410091158.md).
