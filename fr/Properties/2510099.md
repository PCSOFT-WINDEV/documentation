


## PoliceSoulignée (Propriété)

***En anglais : FontUnderlined***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **PoliceSoulignée** permet de :

- Savoir si le texte affiché est souligné ou non.

- Souligner ou non le texte.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Souligner le texte affiché dans le champ "LIB_ChampLibellé"
LIB_ChampLibellé.PoliceSoulignée = Vrai
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si le texte affiché dans un champ est souligné

`<Résultat> = <Champ manipulé>.PoliceSoulignée`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le texte est souligné, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la mise en forme souligné du texte affiché dans un champ

`<Champ manipulé>.PoliceSoulignée = <Souligné/Non souligné>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.

**`<Souligné/Non souligné> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le texte affiché doit être souligné, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.

### Cas particulier : champ Lien
<a name="cas_particulier_champ_lien_ELTPARAGRAPHE000095"></a>Le résultat de la propriété **PoliceSoulignée** ne tient pas compte du fait que les navigateurs soulignent par défaut les liens.

La valeur renvoyée par la propriété **PoliceSoulignée** en code navigateur et en code serveur pour un même champ Lien peut donc être différente. 


### Limites
<a name="limites_ELTPARAGRAPHE000108"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) Dans un état, la propriété **PoliceSoulignée** peut être utilisée uniquement sur :

- un champ Libellé.

- un champ Calculé.

- un champ Lien URL.

- un champ Prédéfini.


![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WINDEV Mobile](https://doc.pcsoft.fr/ext/images/fr/WM.png) Dans une fenêtre, la propriété **PoliceSoulignée** ne peut pas être utilisée sur :

- un champ Spin,

- un champ Web Camera,

- un champ Conférence.


Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La propriété **PoliceSoulignée** ne peut pas être utilisée sur les colonnes de table.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) Dans une page, la propriété **PoliceSoulignée** peut être utilisée sur :

- un champ Libellé,

- un champ de saisie,

- un champ Bouton,

- un champ Interrupteur,

- un champ Sélecteur,

- un champ Liste,

- une colonne d'un champ Table,

- une cellule d'un champ Table (en lecture uniquement),

- un champ d'affichage formaté,

- un champ HTML,

- un champ Combo,

- un champ Lien,

- un champ Libellé HTML,

- un champ Réglette,

- un champ Chemin de navigation (sauf en PHP),

- un champ Arbre,

- un menu.
