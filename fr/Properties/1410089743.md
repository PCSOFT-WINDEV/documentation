
## FlexJustifyContent (Propriété)

***En anglais : FlexJustifyContent***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FlexJustifyContent** permet de connaître et de modifier l'alignement des champs à l'intérieur du champ Flexbox selon l'axe principal du champ (propriété CSS correspondante "justify-content"). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Caractéristiques du champ Flexbox
FLEX_MaFlexbox.FlexDirection = fbdColonne
FLEX_MaFlexbox.FlexWrap = fbwRetourALaLigne
FLEX_MaFlexbox.FlexJustifyContent = fbjcCentré
FLEX_MaFlexbox.FlexAlignContent = fbacFin
FLEX_MaFlexbox.FlexAlignItems = fbaiCentré
FLEX_MaFlexbox.FlexColumnGap = 5
FLEX_MaFlexbox.FlexRowGap = 50
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître l'alignement des champs à l'intérieur du champ Flexbox

`<Résultat> = <Champ manipulé>.FlexJustifyContent`
---

**`<Résultat> : (Constante de type Entier)`**

Alignement des lignes dans le champ Flexbox : 



|   |   |
| --- | --- |
| *fbjcCentré* | Les champs sont centrés selon l'axe principal. Les champs sont collés les uns contre les autres sans espace de séparation. Un espacement identique est généré à chaque extrémité du groupe de champs. |
| *fbjcDébut* | Le premier champ est cadré au début de l'axe principal. Selon la direction du champ Flexbox, les autres champs sont positionnés de gauche à droite ou de haut en bas. |
| *fbjcEspaceExterne* | Selon la direction du champ Flexbox, les champs sont répartis sur l'axe principal. Les champs sont répartis avec un espacement identique entre chaque champ ainsi que par rapport aux bords du champ Flexbox. |
| *fbjcEspaceInterne* | Selon la direction du champ Flexbox, les champs sont répartis sur l'axe principal. Le premier champ est cadré au début de l'axe principal. Le dernier champ est cadré à la fin de l'axe principal. Les autres champs sont répartis dans l'espace restant avec un espace identique entre chaque champ. |
| *fbjcFin* | Le dernier champ est cadré à la fin de l'axe principal. Selon la direction du champ Flexbox, les autres champs sont positionnés de droite à gauche ou de bas en haut. |



**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 


<a name="SYNTAXE2"></a>

### Modifier l'alignement des champs à l'intérieur du champ Flexbox

`<Champ manipulé>.FlexJustifyContent = <Nouvel alignement>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 

**`<Nouvel alignement> : (Constante de type Entier)`**

Nouvel alignement : 



|   |   |
| --- | --- |
| *fbjcCentré* | Les champs sont centrés selon l'axe principal. Les champs sont collés les uns contre les autres sans espace de séparation. Un espacement identique est généré à chaque extrémité du groupe de champs. |
| *fbjcDébut* | Le premier champ est cadré au début de l'axe principal. Selon la direction du champ Flexbox, les autres champs sont positionnés de gauche à droite ou de haut en bas. |
| *fbjcEspaceExterne* | Selon la direction du champ Flexbox, les champs sont répartis sur l'axe principal. Les champs sont répartis avec un espacement identique entre chaque champ ainsi que par rapport aux bords du champ Flexbox. |
| *fbjcEspaceInterne* | Selon la direction du champ Flexbox, les champs sont répartis sur l'axe principal. Le premier champ est cadré au début de l'axe principal. Le dernier champ est cadré à la fin de l'axe principal. Les autres champs sont répartis dans l'espace restant avec un espace identique entre chaque champ. |
| *fbjcFin* | Le dernier champ est cadré à la fin de l'axe principal. Selon la direction du champ Flexbox, les autres champs sont positionnés de droite à gauche ou de bas en haut. |
