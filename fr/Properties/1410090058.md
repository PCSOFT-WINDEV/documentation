
## Ordre (Propriété)

***En anglais : Order***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Ordre** permet de connaître et de définir l'ordre utilisé pour une liste d'éléments. Cette propriété est utilisable : 

- sur une variable de type [RendezVous](../WDLang1/1000019244.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) sur une variable de type [ActionRapide](../WDLang3/1410090054.md).
