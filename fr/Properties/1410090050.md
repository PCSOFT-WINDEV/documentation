


## CalculEnCours (Propriété)

***En anglais : CalculationInProgress***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **CalculEnCours** permet de savoir si le calcul d'un champ Tableau croisé dynamique est en cours (calcul synchrone ou asynchrone).

Ce calcul peut avoir été lancé par les fonctions [TCDCalculeTout](../WDLang1/1000020539.md), [TCDCalculeToutAsynchrone](../WDLang1/1410090244.md), [TCDCalculeMiseAJour](../WDLang1/1000020534.md) ou [TCDCalculeMiseAJourAsynchrone](../WDLang1/1410089990.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Code du bouton de recalcul
TCDCalculeToutAsynchrone(TCD_Statistiques, Calcul_terminé)
	PROCÉDURE INTERNE Calcul_terminé(bOK est booléen)
		SI PAS bOK ALORS
			Erreur(ErreurInfo())
			RETOUR
		FIN
	FIN
```

```wl
// Code de clic du bouton "Détail facture"
SI TCD_Statistiques.CalculEnCours ALORS
	ToastAffiche("Calcul du Tableau croisé dynamique en cours")
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Tableau croisé dynamique>.CalculEnCours`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le calcul du champ Tableau croisé dynamique est en cours, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Champ Tableau croisé dynamique> : (Nom de champ)`**

Nom du champ Tableau croisé dynamique manipulé.
