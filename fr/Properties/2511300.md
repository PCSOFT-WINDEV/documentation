
## Source (Propriété)

***En anglais : Source***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Source** permet de connaître et de modifier la source d'un élément. Cette propriété est utilisable sur :

- un champ Graphe ou une connexion. Pour plus de détails, consultez [Propriété Source sur un graphe ou une connexion](../Proprietes/2510147.md).

- une variable de type [hDescriptionSauvegarde](../WDLang4/1000017455.md). 

- une variable de type [rssEntrée](../WDLang5/1000017792.md). 

- la structure [Email](../WDLang3/3032029.md)

- une variable de type [Email](../WDLang3/1000018713.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) une variable de type [Contact](../WDLang3/1000020254.md).

- une variable de type [OpenIDIdentité](../WDLang3/1000023567.md).

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [AppleID](../WDLang3/1000025405.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) une variable de type [TéléchargementInfo](../WDLang3/1410087306.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) une variable de type [TéléchargementParamètre](../WDLang3/1410087293.md).
