
## VoletVisibleParDéfaut (Propriété)

***En anglais : PaneVisibleByDefault***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **VoletVisibleParDéfaut** permet de savoir et d'indiquer si le volet de l'éditeur d'images est visible par défaut. 
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_img_reglages%20-%20HC%20N%B0002%201.gif)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ne pas afficher le volet dans l'éditeur d'images à son ouverture
EI_Editeur.VoletVisibleParDéfaut = Faux
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si le volet du champ Editeur d'images est visible par défaut

`<Résultat> = <Champ Editeur d'images>.VoletVisibleParDéfaut`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le volet du champ est visible par défaut, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Champ Editeur d'images> : (Nom de champ)`**

Nom du champ Editeur d'images à manipuler.  


<a name="SYNTAXE2"></a>

### Rendre le volet du champ Editeur d'images visible ou invisible par défaut

`<Champ Editeur d'images>.VoletVisibleParDéfaut = <Visibilité>`
---

**`<Champ Editeur d'images> : (Nom de champ)`**

Nom du champ Editeur d'images à manipuler.

**`<Visibilité> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le volet du champ doit être visible par défaut, 

- <u><u><u><u>Faux</u></u></u></u> si le volet du champ doit être invisible par défaut.
