


## Largeur (Propriété)

***En anglais : Width***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Largeur** permet de connaître et modifier la largeur :

- d'un champ ou d'un bloc dans un état.

- d'un champ (présent dans une fenêtre), d'une fenêtre, d'une colonne de table ou d'une liste (y compris liste image).

- d'un champ (présent dans une page), d'une colonne de table ou d'une liste. Le champ peut être superposable ou non.




Il est également possible de connaître la largeur d'une cellule de table. Pour modifier sa largeur, il suffit de modifier la largeur de la colonne correspondante.

**Remarques** :

- Dans un état, le cadre du champ ou du bloc est compris dans sa largeur. La propriété [LargeurPixel](../Proprietes/2511052.md) permet de connaître la largeur d'un champ d'un état en pixels.

- La largeur d'un champ est définie sous l'éditeur lors de la description du champ.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Augmente la largeur du champ "SAI_NomClient"
SAI_NomClient.Largeur = SAI_NomClient.Largeur + 15
// Est équivalent à : SAI_NomClient.Largeur += 15
```
<a name="Exemple2"></a>

```wl
// Modification de la largeur de deux champs
SAI_NomClient.Largeur += 100	// Ajoute 100 pixels
SAI_PrénomClient.Largeur += 10		// Ajoute 10 pixels
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la largeur d'un élément

`<Résultat> = <Elément manipulé>.Largeur`
---

**`<Résultat> : (Réel)`**

Largeur de l'élément spécifié. Cette largeur est exprimée en pixels dans une fenêtre et/ou une page, et en millimètres dans un état.

**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément (champ, fenêtre, bloc, ...) à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la largeur d'un élément

`<Elément manipulé>.Largeur = <Nouvelle largeur>`
---

**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément (champ, fenêtre, bloc, ...) à manipuler.

**`<Nouvelle largeur> : (Réel)`**

Nouvelle largeur de l'élément spécifié. Cette largeur est exprimée en pixels dans une fenêtre et/ou une page, et en millimètres dans un état.

### Largeur d'une fenêtre : Particularités 
<a name="largeur_une_fenetre_particularites_ELTPARAGRAPHE000099"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) La largeur d'une fenêtre tient compte de l'effet d'ombre défini dans le thème de Windows.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) La largeur d'une fenêtre peut être différente selon les événements dans lesquels la propriété **Largeur** est utilisée. En effet, la fenêtre est redimensionnée par le système entre les événements de déclaration et d'initialisation, d'où une différence de valeur potentielle : 

	- dans l'événement "Déclarations globales", la fenêtre n'est pas encore visible et n'a donc pas reçu sa taille en fonction de l'appareil. La propriété renvoie la largeur initiale (d'édition) de la fenêtre. 

	- dans l'événement "Initialisation", la fenêtre est visible à l'écran et les ancrages comme les modifications de taille sont appliqués. La largeur de la fenêtre peut donc être différente.




- La largeur réelle d'une fenêtre est donc connue uniquement dans l'événement "Initialisation" de la fenêtre.

### Largeur initiale (champ et fenêtre)
<a name="largeur_initiale_champ_fenetre_ELTPARAGRAPHE000121"></a>La largeur initiale (décrite sous l'éditeur) peut être connue grâce à la propriété [LargeurInitiale](../Proprietes/2510067.md).

La largeur d'un élément est normalement contrainte par les propriétés [LargeurMax](../Proprietes/2510068.md) et [LargeurMin](../Proprietes/2510062.md). Néanmoins, cette contrainte disparaît lors de la modification de la largeur par programmation (utilisation de la propriété **Largeur** ou de la fonction [FenTaille](../WDLang1/3038020.md)).

### Largeur d'une colonne
<a name="largeur_une_colonne_ELTPARAGRAPHE000147"></a>Lors de la modification de la largeur d'une colonne d'un champ Table, si la largeur spécifiée est inférieure à la largeur minimale de la colonne, il est nécessaire de modifier également la largeur minimale (propriété [LargeurMin](../Proprietes/2510062.md)) pour prendre en compte la modification.

**Champ Table horizontale** : La propriété **Largeur** modifie la hauteur de la ligne. La propriété [Hauteur](../Proprietes/2510050.md) permet de connaître la largeur de la totalité de la table. **Cette propriété est disponible en lecture seulement**.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Largeur des champs d'un formulaire
<a name="largeur_des_champs_formulaire_ELTPARAGRAPHE000167"></a>En code serveur, la largeur renvoyée et modifiable correspond à la largeur totale du champ (largeur du libellé et largeur de la zone de saisie).

En code navigateur, la largeur renvoyée et modifiable correspond uniquement à la largeur de la zone de saisie.

### Limites
<a name="limites_ELTPARAGRAPHE000176"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) La propriété **Largeur** ne peut pas être utilisée sur un état.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) La propriété **Largeur** est disponible en modification uniquement pour les champs suivants :

- Bouton.

- Image.

- Image cliquable.

- Applet Java.

- Graphe.

- Colonne de table.




![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La propriété **Largeur** n'est pas disponible sur les champs iFrame.

![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) La propriété **Largeur** s'applique uniquement aux éléments suivants :

- Bouton.

- Libellé.

- Champ de saisie.

- Image.

- Interrupteur.

- Sélecteur.

- Liste.

- Combo.

- Arbre.

- Onglet.

- Fenêtre.

- Table.

- Colonne de table.

- Superchamp.




![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) La propriété **Largeur** n'est pas disponible sur les champs Table. Par contre, elle est disponible sur les colonnes de table.
