
## Version (Propriété)

***En anglais : Version***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Version** permet de connaître et de modifier la version d'un élément. Cette propriété est utilisable sur :

- une variable de type [rssFlux](../WDLang5/1000017795.md).

- une variable de type [xlsDocument](../WDLang5/1000017464.md).

- une variable de type [xmlDocument](../WDLang5/1000018782.md).

- une variable de type [hbLecture](../WDLang4/1000021701.md).

- une variable de type [pdfParamètre](../WDLang6/1410087857.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [zipParamètreCréationExe](../WDLang3/1410091226.md).
