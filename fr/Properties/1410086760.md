
## IALibellé (Propriété)

***En anglais : AICaption***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IALibellé** permet de connaître et de modifier le libellé affiché dans le champ Chat IA pour identifier la réponse de l'IA.                                                                                                                                                                                      
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
CHATIA_ChatIA.IALibellé = "Assistant numérique"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le libellé utilisé pour identifier la réponse de l'IA

`<Résultat> = <Champ Chat IA>.IALibellé`
---

**`<Résultat> : (Chaîne de caractères)`**

Libellé utilisé. 

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.   


<a name="SYNTAXE2"></a>

### Modifier le libellé utilisé pour identifier la réponse de l'IA

`<Champ Chat IA>.IALibellé = <Nouveau libellé>`
---

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.

**`<Nouveau libellé> : (Chaîne de caractères)`**

Nouveau libellé.
