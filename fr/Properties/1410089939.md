
## LongueurMinimale (Propriété)

***En anglais : MinimumLength***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **LongueurMinimale** permet de connaître et de modifier la longueur minimale d'un élément. Cette propriété est utilisable sur :

- une description d'un index full-text. Pour plus de détails, consultez [LongueurMinimale](../Proprietes/1000017716.md).

- une variable de type [FormatNumérique](../WDLang1/1410089836.md).
