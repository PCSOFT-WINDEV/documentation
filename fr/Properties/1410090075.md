
## Marge (Propriété)

***En anglais : Margin***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Marge** permet de définir la taille d'une marge, par exemple autour d'un texte. Cette propriété est utilisable sur :

- une variable de type [diagTexte](../WDLang1/1410088393.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [VisiteGuidée](../WDLang6/1410090170.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [VisiteGuidéeEtape](../WDLang6/1410090178.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) la propriété [BoutonGauche](../Proprietes/1410090001.md) d'un champ de saisie.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) la propriété [BoutonDroit](../Proprietes/1410090002.md) d'un champ de saisie.
