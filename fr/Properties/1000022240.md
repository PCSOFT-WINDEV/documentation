Le mot-clé "Fond" peut correspondre : 

- au type de variable [Fond](../WDLang1/1000022038.md), 

- à la propriété **Fond** de la variable de type [docParagraphe](../WDLang1/1000022483.md). 

- à la propriété **Fond** de la variable de type [docElémentZoneDeTexte](../WDLang1/1000023420.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) à la propriété **Fond** de la variable de type [diagSélection](../WDLang1/1410088172.md).
