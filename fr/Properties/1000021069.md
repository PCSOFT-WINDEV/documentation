


## DuréeAnimation (Propriété)

***En anglais : AnimationDuration***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **DuréeAnimation** permet de connaître et de modifier la durée de l'animation : 

- d'un champ Graphe. Par défaut, cette durée est fixée à 30 centièmes de seconde.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) d'un champ Jauge infinie personnalisé. Par défaut, cette durée est fixée à 200 centièmes de seconde.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) d'un champ Zone répétée de type Galerie d'images. Cette durée est fixée dans l'onglet "Général" de la fenêtre de description de la galerie d'images.







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Augmentation du délai
GRF_MonGraphe.DuréeAnimation = 2000
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la durée de l'animation

`<Résultat> = <Champ manipulé>.DuréeAnimation`
---

**`<Résultat> : (Entier)`**

Durée de l'animation du champ exprimée en centièmes de seconde. 

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- Un champ Graphe. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Un champ Jauge infinie personnalisé.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Un champ Zone répétée de type Galerie d'images.





<a name="SYNTAXE2"></a>

### Modifier la durée de l'animation

`<Champ manipulé>.DuréeAnimation = <Nouvelle durée>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- Un champ Graphe. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Un champ Jauge infinie personnalisé.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Un champ Zone répétée de type Galerie d'images.




**`<Nouvelle durée> : (Entier ou Durée)`**

Nouvelle durée de l'animation du champ exprimée en centièmes de seconde. Si cette nouvelle durée vaut 0, l'animation ne sera plus effectuée. 
Ce paramètre peut correspondre à : 

- un entier correspondant au nombre de centièmes de seconde, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) une variable de type Durée, 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) la durée en clair (par exemple '1cs' ou '10 ms').
