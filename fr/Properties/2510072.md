


## PoliceTaille (Propriété)

***En anglais : FontSize***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **PoliceTaille** permet de :

- Connaître la taille de la police utilisée dans un champ.

- Modifier la taille de la police utilisée dans un champ.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Modifier la taille de la police utilisée dans le champ "SAI_NomClient"
SAI_NomClient.PoliceTaille = 16
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la taille de la police utilisée dans un champ

`<Résultat> = <Champ manipulé>.PoliceTaille`
---

**`<Résultat> : (Entier)`**

Taille de la police utilisée dans l'objet spécifié.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Ce paramètre correspond à une chaîne de caractères.

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la taille de la police utilisée dans un champ

`<Champ manipulé>.PoliceTaille = <Taille de la police>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler.

**`<Taille de la police> : (Entier)`**

Nouvelle taille de la police utilisée dans le champ spécifié.  
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Ce paramètre correspond à une chaîne de caractères.

## Remarques


### Limites
<a name="limites_ELTPARAGRAPHE000078"></a>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Dans un état, la propriété **PoliceTaille** peut être utilisée uniquement sur :

- un champ Libellé.

- un champ Calculé.

- un champ Prédéfini.

- un champ Lien.


![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Dans une fenêtre, la propriété **PoliceTaille** ne peut pas être utilisée sur :

- un champ Spin,

- un champ Web Camera,

- un champ Conférence.


Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) La propriété **PoliceTaille** ne peut pas être utilisée sur les colonnes de table.![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) La propriété **PoliceTaille** s'applique uniquement aux éléments suivants :

- Bouton,

- Libellé,

- Combo,

- Arbre,

- Colonne de table.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Dans une page, la propriété **PoliceTaille** s'applique uniquement aux éléments suivants :

- Champ de saisie,

- Libellé,

- Bouton,

- Interrupteur/sélecteur,

- Liste, combo,

- Table,

- Champ d'affichage formaté,

- Champ HTML,

- Lien,

- Libellé HTML,

- Colonne de table (non disponible en code navigateur),

- Cellule de table (disponible en lecture seulement et non disponible en code navigateur),

- Réglette (non disponible en code navigateur),

- Chemin de navigation (non disponible en code navigateur et en PHP),

- Groupe de champs (non disponible en code navigateur).
