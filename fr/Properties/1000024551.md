
## ParamètresSupplémentaires (Propriété)

***En anglais : AdditionalParameters***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ParamètresSupplémentaires** permet de spécifier des paramètres supplémentaires dans la chaîne d'authentification. Cette propriété est utilisable sur : 

- une variable de type [OAuth2Paramètres](../WDLang3/1000022212.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) une variable de type [JWTParamètres](../WDLang3/1410089572.md).
