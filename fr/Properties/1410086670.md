
## Propriétés diverses
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Ces propriétés peuvent s'appliquer à différents types d'éléments. 




|   |   |
| --- | --- |
| [AjoutTerminé](../Proprietes/1000018388.md) | La propriété **AjoutTerminé** permet de connaître ou de modifier l'état de l'ajout d'un élément dans une file, une liste ou une pile (ajout en cours ou ajout terminé). |
| [Après](../Proprietes/1000020917.md) | La propriété **Après** remplace ou insère une procédure après les autres procédures dans : <br><br>- une variable de type [Procédure](../Motscles/1000018907.md).<br><br>- un événement associé à un champ. <br><br><br> |
| [Avant](../Proprietes/1000020916.md) | La propriété **Avant** remplace ou insère une procédure avant les autres procédures dans : <br><br>- une variable de type [Procédure](../Motscles/1000018907.md).<br><br>- un événement associé à un champ. <br><br><br> |
| [BorneMax](../Proprietes/2510009.md) | La propriété **BorneMax** permet de :<br><br>- connaître et de modifier la borne maximale d'un état basé sur un fichier de données. <br><br>- connaître la borne maximale du filtre en cours.<br><br>- connaître la valeur maximale d'une série d'un graphe.<br><br>- connaître et modifier la valeur maximale de certains types de champs.<br><br><br> |
| [BorneMin](../Proprietes/2510008.md) | La propriété **BorneMin** permet de :<br><br>- connaître et de modifier la borne minimale d'un état basé sur un fichier de données. <br><br>- connaître la borne minimale du filtre en cours.<br><br>- connaître la valeur minimale d'une série d'un graphe.<br><br>- connaître et modifier la valeur minimale de certains types de champs. <br><br><br> |
| [Classe](../Proprietes/2514004.md) | La propriété **Classe** permet de connaître le type réel de l'instance de classe manipulée par une variable de type objet, variant ou de type objet dynamique. |
| [Couleur](../Proprietes/2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :<br><br>- une variable de type Police.<br><br>- un texte d'un champ Libellé ou calculé d'un état.<br><br>- un texte d'un champ d'une fenêtre.<br><br>- un texte d'un champ d'une page.<br><br><br> |
| [CouleurFond](../Proprietes/2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [DateDébut](../Proprietes/1000017426.md) | La propriété **DateDébut** permet de connaître et de modifier la date de début de la période sélectionnée :<br><br>- dans un champ Calendrier. <br><br>- dans un champ Agenda.<br><br>- dans un champ Planning.<br><br><br> |
| [DateFin](../Proprietes/1000017427.md) | La propriété **DateFin** permet de connaître et de modifier la date de fin de période sélectionnée : <br><br>- dans un champ Calendrier,<br><br>- dans un champ Agenda.<br><br>- dans un champ Planning.<br><br><br><br><br> |
| [Défaut](../Proprietes/1000017046.md) | La propriété **Défaut** permet de savoir si le paramètre passé à une procédure a été renseigné ou a été affecté avec sa valeur par défaut. |
| [DroiteAGauche](../Proprietes/1000017228.md) | La propriété **DroiteAGauche** permet de connaître le sens d'écriture réel, effectif sur un champ, une colonne, une fenêtre ou un état. |
| [Epaisseur](../Proprietes/2510144.md) | La propriété **Epaisseur** permet de :<br><br>- Connaître et modifier l'épaisseur du trait d'une série (uniquement pour les graphes de type Courbe). <br><br>- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Connaître et modifier l'épaisseur du trait d'un champ Fil. <br><br><br> |
| [Etat](../Proprietes/2510039.md) | La propriété **Etat** permet de connaître et de modifier l'état d'affichage d'un élément. |
| [Existe](../Proprietes/1000022167.md) | La propriété **Existe** permet de savoir si un élément d'un tableau associatif existe ou non. |
| [Groupe](../Proprietes/2510049.md) | La propriété **Groupe** permet de : <br><br>- savoir si le champ appartient ou non à un groupe de champs. Si le champ appartient à un ou plusieurs groupes, la propriété **Groupe** permet d'identifier ces groupes de champs.<br><br>- associer un champ à un groupe de champs. <br><br><br> |
| [Hauteur](../Proprietes/2510050.md) | La propriété **Hauteur** permet de connaître et modifier la hauteur :<br><br>- d'un champ ou d'un bloc dans un état.<br><br>- d'un champ (présent dans une fenêtre), d'une fenêtre, d'une ligne d'un champ Table ou Liste (y compris Liste image), d'une option d'un champ Sélecteur ou Interrupteur, d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée.<br><br>- d'un champ (présent dans une page), d'un haut ou bas de rupture d'un champ Table ou Zone répétée. Le champ peut être superposable ou non.<br><br>- d'une cellule de rupture d'un champ Table ou d'un champ Zone répétée.<br><br><br> |
| [Icone](../Proprietes/1000019344.md) | La propriété **Icone** permet de :<br><br>- Connaître l'icône affichée dans la barre de titre d'une fenêtre ou d'un champ Panneau dockable. <br><br>- Modifier l'icône de la barre de titre d'une fenêtre ou d'un champ Panneau dockable.<br><br><br> |
| [Image](../Proprietes/2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [Largeur](../Proprietes/2510059.md) | La propriété **Largeur** permet de connaître et modifier la largeur :<br><br>- d'un champ ou d'un bloc dans un état.<br><br>- d'un champ (présent dans une fenêtre), d'une fenêtre, d'une colonne de table ou d'une colonne de liste (y compris liste image).<br><br>- d'un champ (présent dans une page), d'une colonne de table ou d'une liste. Le champ peut être superposable ou non.<br><br><br> |
| [Libellé](../Proprietes/2510053.md) | **Dans une base de données**, la propriété **Libellé** permet de :<br><br>- Connaître le libellé associé à une rubrique d'un fichier de données. <br><br>- Connaître le libellé associé à un fichier de données. <br><br>- Connaître et modifier le libellé d'une connexion. <br><br><br><br><br>**Dans un état**, la propriété **Libellé** permet de :<br><br>- Connaître le texte d'un champ Libellé ou Lien.<br><br>- Modifier le texte d'un champ Libellé ou Lien.<br><br><br><br><br>**Dans une fenêtre ou une page**, la propriété **Libellé** permet également de :<br><br>- Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page.<br><br>- Connaître et modifier le libellé d'une option de menu.<br><br>- Connaître et modifier le titre d'une fenêtre ou d'une page.<br><br>- Connaître le contenu d'un champ chemin de navigation.<br><br><br><br><br> |
| [Membre](../Proprietes/1000021078.md) | La propriété **Membre** sur les variables de type Variant permet d'obtenir le tableau des éléments nommés. |
| [Multiligne](../Proprietes/2510105.md) | Dans une fenêtre ou une page, la propriété **Multiligne** permet :<br><br>- de savoir et de modifier l'option "Multiligne" d'un champ de saisie.<br><br>- de savoir et de modifier l'option "Multiligne" d'une colonne d'un champ Table.  <br><br><br><br><br>Dans un état, la propriété **Multiligne** permet de connaître et de modifier l'option "Multiligne" d'un champ d'un état. |
| [NbReçus](../Proprietes/1000017047.md) | La propriété **NbReçus** permet de connaître le nombre de paramètres réellement reçus par une procédure. |
| [NbThreadAttente](../Proprietes/1000018387.md) | La propriété **NbThreadAttente** permet de connaître le nombre de threads en attente d'une file ou d'une pile. |
| [Nom](../Proprietes/2510082.md) | La propriété **Nom** permet de connaître :<br><br>- le nom de la police associée à une variable de type Police.<br><br>- le nom d'un champ, d'un état ou d'un bloc d'un état.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une fenêtre.<br><br>- le nom d'un champ, d'un groupe de champs ou d'une page.<br><br><br> |
| [Note](../Proprietes/2510085.md) | La propriété **Note** permet de :<br><br>- Connaître les notes associées à un champ, à une fenêtre, à une page ou un état.<br><br>- Modifier les notes associées à un champ, à une fenêtre, à une page ou un état.<br><br><br> |
| [Numérique](../Proprietes/2512067.md) | La propriété **Numérique** permet de savoir si une rubrique est de type numérique. |
| [Occurrence](../Proprietes/2510097.md) | La propriété **Occurrence** permet de connaître le nombre d'éléments présents dans un ensemble. |
| [OptionsOuverture](../Proprietes/1410091299.md) | La propriété **OptionsOuverture** permet de connaître et de spécifier les options d'ouverture d'une fenêtre manipulée par une variable de type Fenêtre.  <br><br> |
| [ParAdresse](../Proprietes/1000017048.md) | La propriété **ParAdresse** permet de savoir si un paramètre d'une procédure a été passé par adresse ou non. |
| [ParamètresOuverture](../Proprietes/1410091044.md) | La propriété **ParamètresOuverture** permet de connaître et de spécifier les paramètres passés à une fenêtre.<br><br> |
| [ParRéférence](../Proprietes/1000024379.md) | La propriété **ParRéférence** permet de savoir si un paramètre d'une procédure a été passé par référence ou non. |
| [Police](../Proprietes/2510095.md) | La propriété **Police** permet de :<br><br>- Connaître l'identifiant de la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.<br><br>- Modifier la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.<br><br><br> |
| [Taille](../WDLang1/3024031.md) | Renvoie :<br><br>- la taille d'une chaîne de caractères, c'est-à-dire le nombre de caractères composant la chaîne de caractères (y compris les caractères espace et 0 binaire).<br><br>- la taille d'un buffer, c'est-à-dire le nombre d'octets composant le buffer.<br><br><br> |
| [Type](../Proprietes/2510131.md) | La propriété **Type** permet de connaître :<br><br>- le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête).<br><br>- le type d'un objet.<br><br>- le type de la valeur stockée dans un variant.<br><br><br> |
| [Valeur](../Proprietes/2510130.md) | La propriété **Valeur** permet de :<br><br>- Connaître et modifier la valeur d'un champ d'un état.<br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.<br><br>- Connaître l'identifiant d'un flux. <br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une page.<br><br><br> |
| [Vide](../Proprietes/2510126.md) | La propriété **Vide** permet de savoir si :<br><br>- un champ Zone répétée, Table, Liste ou Combo est vide. Le champ peut être un champ fichier ou mémoire.<br><br>- un champ Graphe ne contient aucune série.<br><br>- un champ d'un état est vide (champ lié à une rubrique).<br><br>- un tableau (ou un tableau associatif) ne contient aucun élément.<br><br>- un élément d'un tableau associatif existe ou non.<br><br>- une file, une liste ou une pile ne contient aucun élément. <br><br><br> |
