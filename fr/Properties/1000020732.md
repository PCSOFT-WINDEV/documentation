
## IgnoreErreur (Propriété)

***En anglais : IgnoreError***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IgnoreErreur** permet de spécifier les erreurs ignorées. Cette propriété est utilisable sur :

- une variable de type [httpRequête](../WDLang3/1000021158.md). 

- une variable de type [restRequête](../WDLang3/1000021481.md).

- une variable de type [mqttSession](../WDLang3/1000023023.md).
