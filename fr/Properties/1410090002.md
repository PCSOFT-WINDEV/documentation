


## BoutonDroit (Propriété)

***En anglais : RightButton***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **BoutonDroit** permet de définir et de connaître les caractéristiques d'un bouton droit présent dans un champ de saisie. Ce bouton correspond à une image cliquable. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SAI_Saisie.BoutonDroit.Image = IMG_Plus
SAI_Saisie.BoutonDroit.NbEtat = 5
SAI_Saisie.BoutonDroit.Monochrome = Faux
SAI_Saisie.Traitement[trtClicBoutonSaisieDroite] = MaProcédure
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître les caractéristiques d'un bouton droit dans un champ de saisie

`<Résultat> = <Champ de saisie>.BoutonDroit.<Nom de la propriété>`
---

**`<Résultat> : (Type correspondant à la propriété)`**

Résultat correspondant à la propriété utilisée. 

**`<Champ de saisie> : (Nom de champ)`**

Nom du champ de saisie manipulé. 

**`<Nom de la propriété> : ()`**

Nom de la propriété utilisée : 


| Propriété | Type | Description |
| --- | --- | --- |
| *Hauteur* | Entier | Hauteur de l'image cliquable dans la zone de saisie, exprimée en pixels. |
| *Image* | Chaîne de caractères, mémo | Image utilisée pour le bouton présent dans la zone de saisie. |
| *Largeur* | Entier | Largeur de l'image cliquable dans la zone de saisie, exprimée en pixels. |
| *Marge.Bas* | Entier | Marge basse de l'image cliquable, exprimée en pixels. |
| *Marge.Droite* | Entier | Marge droite de l'image cliquable, exprimée en pixels. |
| *Marge.Gauche* | Entier | Marge gauche de l'image cliquable, exprimée en pixels. |
| *Marge.Haut* | Entier | Marge haute de l'image cliquable, exprimée en pixels. |
| *Marge.Valeur* | Entier | <br><br>- Valeur de la marge haute, basse, droite et gauche exprimée en pixels, si ces valeurs sont les mêmes, <br><br>- -1 si les différentes marges ne sont pas identiques. <br><br><br> |
| *Monochrome* | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image doit être monochrome, <br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |
| *NbEtat* | Entier | Nombre d'états de l'image. |
| *Visible* | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image cliquable est visible en exécution,<br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |




<a name="SYNTAXE2"></a>

### Définir ou modifier les caractéristiques d'un bouton droit dans un champ de saisie

`<Champ manipulé>.BoutonDroit.<Nom de la propriété> = <Nouvelle valeur>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. 

**`<Nom de la propriété> : ()`**

Nom de la propriété à appliquer : 


| Propriété | Type | Description |
| --- | --- | --- |
| *Hauteur* | Entier | Hauteur de l'image cliquable dans la zone de saisie, exprimée en pixels. |
| *Image* | Chaîne de caractères, mémo | Chemin de l'image utilisée pour le bouton présent dans la zone de saisie. |
| *Largeur* | Entier | Largeur de l'image cliquable dans la zone de saisie, exprimée en pixels. |
| *Marge.Bas* | Entier | Marge basse de l'image cliquable, exprimée en pixels. |
| *Marge.Droite* | Entier | Marge droite de l'image cliquable, exprimée en pixels. |
| *Marge.Gauche* | Entier | Marge gauche de l'image cliquable, exprimée en pixels. |
| *Marge.Haut* | Entier | Marge haute de l'image cliquable, exprimée en pixels. |
| *Marge.Valeur* | Entier | Valeur de la marge haute, basse, droite et gauche exprimée en pixels. Permet de définir toutes les propriétés de marge si celles-ci sont les mêmes. |
| *Monochrome* | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image doit être monochrome, <br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |
| *NbEtat* | Entier | Nombre d'états de l'image. |
| *Visible* | Booléen | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'image cliquable est visible en exécution,<br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. <br><br><br> |



**`<Nouvelle valeur> : (Type correspondant à la propriété)`**

Nouvelle valeur de la propriété spécifiée.

<a name="associer_code_wlangage_bouton_droit_ELTPARAGRAPHE000047"></a>Pour associer un code WLangage au bouton droit présent dans un champ de saisie, il suffit d'utiliser la propriété [Traitement](../Proprietes/1000020878.md) avec la constante *trtClicBoutonSaisieDroite*.
