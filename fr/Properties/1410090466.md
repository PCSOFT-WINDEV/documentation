
## NomUtilisateur (Propriété)

***En anglais : Username***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **NomUtilisateur** permet de connaître et de modifier le nom de l'utilisateur. Cette propriété est utilisable :

- une variable de type [OpenIDParamètres](../WDLang3/1000023561.md).

- une variable de type [OAuth2Paramètres](../WDLang3/1000022212.md).
