
## ContenuBrutRéponse

***En anglais : ResponseRawContent***
	

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **ContenuBrutRéponse** permet de savoir si la propriété Contenu de la variable doit correspondre ou non au contenu brute. Cette propriété est utilisable sur :

- une variable de type [httpRequête](../WDLang3/1000021158.md). 

- une variable de type [restRequête](../WDLang3/1000021481.md).
