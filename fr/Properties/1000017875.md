


## TypeMIME (Propriété)

***En anglais : MIMEType***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **TypeMIME** permet de connaître et de modifier le type MIME d'un élément. Cette propriété est utilisable sur :

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) une variable de type [nfcDonnée](../WDLang3/1000020406.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [upnpImage](../WDLang3/1000020905.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [gglDocument](../WDLang5/1000018001.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [gglPièceJointe](../WDLang5/1000026182.md).

- une variable de type [FichierGgl](../WDLang3/1410089586.md).
