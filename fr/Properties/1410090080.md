
## SousLibellé (Propriété)

***En anglais : SubCaption***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **SousLibellé** permet de connaître et de modifier le libellé secondaire défini pour : 

- une option d'un champ Sélecteur ou Interrupteur. Pour plus de détails, consultez [SousLibellé](../Proprietes/1000017232.md). 

- un élément d'un champ TreeMap. Pour plus de détails, consultez [SousLibellé](../Proprietes/1000017232.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) une variable de type [ActionRapide](../WDLang3/1410090054.md).
