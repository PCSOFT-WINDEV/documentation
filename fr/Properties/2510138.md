


## Visible (Propriété)

***En anglais : Visible***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Visible** permet de :

- Savoir si un élément est visible.

- Rendre un élément visible ou invisible.




Cette propriété s'applique aux :

- champs et groupes de champs d'une fenêtre, d'une page ou d'un état.

- blocs d'un état,

- options de menu.




**Remarques** :

- Sous l'éditeur de fenêtres et de pages, la visibilité d'un champ est définie dans l'onglet "UI" de la description du champ.

- Sous l'éditeur d'états, la visibilité d'un champ est définie dans l'onglet "Détail" de la description du champ.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) La propriété **Visible** est disponible sur les lignes des champs Table.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Rendre visible le champ "SAI_Société" s'il est invisible
SI SAI_Société.Visible = Faux ALORS
	SAI_Société.Visible = Vrai
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Savoir si un élément est visible

`<Résultat> = <Elément manipulé>.Visible`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié est visible, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément à manipuler.  


<a name="SYNTAXE2"></a>

### Rendre visible/invisible un champ ou un bloc d'un état

`<Elément manipulé>.Visible = <Visible/Invisible>`
---

**`<Elément manipulé> : (Type de l'élément)`**

Nom de l'élément à manipuler.

**`<Visible/Invisible> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément spécifié doit être visible, 

- <u><u><u><u>Faux</u></u></u></u> si l'élément spécifié doit être invisible.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Attribut d'un champ
<a name="attribut_champ_ELTPARAGRAPHE000108"></a>La propriété **Visible** ne modifie pas les autres attributs d'état du champ (sélection sans saisie, actif ou grisé).
<a name="NOTE0_2"></a>


### Groupe de champs
<a name="groupe_champs_ELTPARAGRAPHE000118"></a>Si l'objet spécifié est un groupe de champs, l'état de visibilité de l'ensemble des champs appartenant au groupe est modifié.
<a name="NOTE0_7b"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Connaître la visibilité d'un élément sous WEBDEV
<a name="connaitre_visibilite_element_sous_webdev_ELTPARAGRAPHE000127"></a>La lecture de la propriété **Visible** en WEBDEV peut poser problème. En effet, le résultat de la propriété **Visible** correspond à une visibilité qui tient compte de la visibilité des parents. 

Si une page Popup est ouverte, l'utilisation de la propriété **Visible** sur un des champs de la Popup en code serveur renverra toujours <u><u><u><u>Faux</u></u></u></u>. En effet, l'affichage de la popup est un événement navigateur uniquement. Le serveur ne sait pas que la popup est visible. Donc la visibilité des champs présents dans la popup est toujours à <u><u><u><u>Faux</u></u></u></u>.

### Fonctionnement des lettres d'appel en fonction de l'état d'un champ
<a name="fonctionnement_des_lettres_appel_fonction_etat_champ_ELTPARAGRAPHE000156"></a>Il est impossible d'utiliser les lettres d'appel d'un champ invisible. Par exemple, un bouton invisible ne fonctionne pas via l'utilisation des lettres d'appel.

### Champs sur onglets
<a name="champs_sur_onglets_ELTPARAGRAPHE000165"></a>Si un champ présent sur un volet d'onglet est visible, mais si ce volet n'est pas affiché, la propriété **Visible** renverra <u><u><u><u>Faux</u></u></u></u>.
<a name="NOTE0_5"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 

### Lignes d'un champ Table
<a name="lignes_champ_table_ELTPARAGRAPHE000181"></a>Il est possible rendre visible ou invisible une ligne d'un champ Table. Par exemple :

```wl
// Rend la seconde ligne du champ Table invisible
TABLE_Table[2].Visible = Faux
```
Si le champ Table utilise des bandeaux de couleurs alternées, l'alternance de couleurs sera respectée.

Remarque : Si la propriété **Visible** est utilisée sur une cellule de table, toutes les cellules de la colonne correspondante seront rendues invisibles.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 

### Action Bar
<a name="action_bar_ELTPARAGRAPHE000199"></a>La propriété **Visible** peut être utilisée pour rendre un champ Action Bar invisible. 
Dans ce cas, une animation est automatiquement effectuée lors de la disparition de l'Action Bar.

La propriété **Visible** peut également être utilisée pour afficher ou non un volet de l'action bar (affiché dans la barre de navigation). Dans ce cas, la syntaxe à utiliser est la suivante : 

```txt
<Nom Action Bar>[<Indice>].Visible
```
où Indice correspond à l'indice de la vue dans le champ Action Bar. 

Par exemple, pour rendre le second volet invisible, le code WLangage est le suivant : 

```wl
ACTB_ActionBar[2].Visible = Faux
```




Remarque : Pour plus de détails sur les volets / vues d'une action bar, consultez [Description du champ Action Bar](../WDChamp/1000025005.md). 
<a name="NOTE0_7"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) 

### Colonnes d'un champ Table
<a name="colonnes_champ_table_ELTPARAGRAPHE000234"></a>La propriété **Visible** peut être utilisée pour rendre des colonnes d'un champ Table invisibles.

Cependant, la propriété **Visible** ne doit pas être utilisée dans un code en mode Ajax pour modifier une colonne d'un champ Table non Ajax : dans ce cas, seules les colonnes seront invisibles, les titres de colonnes ne seront pas invisibles.
