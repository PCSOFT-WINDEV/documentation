
## Commentaire (Propriété)

***En anglais : Comment***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Commentaire** permet de gérer les commentaires. Cette propriété est utilisable sur :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) un champ de type Tableur. Pour plus de détails, consultez [Commentaire](../Proprietes/1410090471.md). 

- une variable de type [sfRequêteTraitementSoumission](../WDLang5/1000018516.md).

- une variable de type [sfRequêteTraitementTâche](../WDLang5/1000018520.md).

- une variable de type [Cookie](../WDLang3/1000019222.md).

- une variable de type [InfoVersion](../WDLang1/1000018905.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [docPropriété](../WDLang1/1000022945.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [diagForme](../WDLang1/1410088082.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [diagSélection](../WDLang1/1410088172.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [mongoLotOpérationsOption](../WDLang4/1410089271.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [xlsDocument](../WDLang5/1000017464.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [pdfProtection](../WDLang6/1410091145.md).
	Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. 
	Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](../Editeurs/1410087359.md).
