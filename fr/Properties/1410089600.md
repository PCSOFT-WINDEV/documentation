
## GraduationYSecondaire (Propriété)

***En anglais : IntervalYSecondaryAxis***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **GraduationYSecondaire** permet de connaître le pas de la graduation sur l'axe secondaire des Y. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche le pas de graduation sur l'axe secondaire des Y
Info(GRF_MonGraphe.GraduationYSecondaire)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Champ Graphe>.GraduationYSecondaire`
---

**`<Résultat> : (Réel)`**

Pas de graduation sur l'axe secondaire des Y. 

**`<Champ Graphe> : (Nom de champ)`**

Nom du champ Graphe à manipuler.
