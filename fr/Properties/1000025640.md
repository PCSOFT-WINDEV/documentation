
## Polygone (Propriété)

***En anglais : Polygon***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **Polygone** peut correspondre à : 

- une variable de type [Polygone](../WDLang1/1000025624.md). 

- une propriété d'une variable de type [ocrBlocTexte](../WDLang6/1000025639.md). 

- une propriété d'une variable de type [MultiPolygone2D](../WDLang4/1410090135.md).

- une propriété d'une variable de type [MultiPolygoneGéo](../WDLang4/1410090136.md).

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) une variable de type [iaRésultatImage](../WDLang6/1410087965.md).
