
## FlexDirection (Propriété)

***En anglais : FlexDirection***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **FlexDirection** permet de connaître et de modifier le sens et la direction de l'axe principal d'un champ Flexbox (propriété CSS correspondante "flex-direction"). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Caractéristiques du champ Flexbox
FLEX_MaFlexbox.FlexDirection = fbdColonne
FLEX_MaFlexbox.FlexWrap = fbwRetourALaLigne
FLEX_MaFlexbox.FlexJustifyContent = fbjcCentré
FLEX_MaFlexbox.FlexAlignContent = fbacFin
FLEX_MaFlexbox.FlexAlignItems = fbaiCentré
FLEX_MaFlexbox.FlexColumnGap = 5
FLEX_MaFlexbox.FlexRowGap = 50
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Connaître le sens et la direction de l'axe principal d'un champ Flexbox

`<Résultat> = <Champ manipulé>.FlexDirection`
---

**`<Résultat> : (Constante de type Entier)`**

Sens selon lequel sont affichés les champs contenus dans le champ Flexbox : 



|   |   |
| --- | --- |
| *fbdColonne* | Les champs sont affichés verticalement les uns en dessous des autres du haut vers le bas. |
| *fbdColonneInversée* | Les champs sont affichés verticalement les uns en dessous des autres du bas vers le haut. |
| *fbdLigne* | Les champs sont affichés horizontalement les uns à coté des autres, de la gauche vers la droite. |
| *fbdLigneInversée* | Les champs sont affichés horizontalement les uns à coté des autres de la droite vers la gauche.<br><br> |



**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 


<a name="SYNTAXE2"></a>

### Modifier le sens et la direction de l'axe principal d'un champ Flexbox

`<Champ manipulé>.FlexDirection = <Nouvelles caractéristiques>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ Flexbox manipulé. 

**`<Nouvelles caractéristiques> : (Constante de type Entier)`**

Sens selon lequel doivent être affichés les champs contenus dans le champ Flexbox : 



|   |   |
| --- | --- |
| *fbdColonne* | Les champs sont affichés verticalement les uns en dessous des autres du haut vers le bas. |
| *fbdColonneInversée* | Les champs sont affichés verticalement les uns en dessous des autres du bas vers le haut. |
| *fbdLigne* | Les champs sont affichés horizontalement les uns à coté des autres, de la gauche vers la droite. |
| *fbdLigneInversée* | Les champs sont affichés horizontalement les uns à coté des autres de la droite vers la gauche.<br><br> |
