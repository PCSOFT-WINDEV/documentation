
## SaisieObligatoire (Propriété)

***En anglais : MandatoryInput***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **SaisieObligatoire** permet de connaître et modifier la caractéristique de saisie obligatoire d'un champ. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI m_bCompteCritique ALORS
	SAI_MotDePasse.SaisieObligatoire = saisieInvalideBloquante
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Savoir si la saisie obligatoire est activée ou non sur un champ

`<Résultat> = <Champ manipulé>.SaisieObligatoire`
---

**`<Résultat> : ()`**

Mode de gestion de la saisie obligatoire : 



|   |   |
| --- | --- |
| *saisieInvalideBloquante* | Le contrôle de la saisie obligatoire est activé et bloquant : lorsque l'utilisateur n'effectue pas de saisie dans le champ, il ne peut pas sortir du champ. <br><br>Dans ce cas, le champ est considéré en erreur dans les cas suivants : <br><br>- Champ de saisie : Champ en erreur si le contenu est vide. <br><br>- Champ Combo en saisie : Champ en erreur si le contenu est vide. <br><br>- Champ Combo sans saisie : Champ en erreur si aucune ligne n'est sélectionnée. <br><br>- Champ Interrupteur : Champ en erreur si aucune option n'est cochée. <br><br>- Champ Sélecteur : Champ en erreur si aucune option n'est cochée. <br><br>- Champ Notation : Champ en erreur si aucune étoile n'est affichée. <br><br><br> |
| *saisieInvalideNonBloquante* | Le contrôle de la saisie obligatoire est non bloquant : lorsque l'utilisateur n'effectue pas de saisie dans le champ, il peut continuer sa saisie. |
| *saisieInvalideRien* | La saisie obligatoire n'est pas définie pour le champ. |



**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ de saisie, 

- un champ Interrupteur, 

- un champ Sélecteur, 

- un champ Combo, 

- un champ Notation. 





<a name="SYNTAXE2"></a>

### Activer ou non la saisie obligatoire sur un champ

`<Champ manipulé>.SaisieObligatoire = <Saisie obligatoire>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ manipulé. Ce champ peut être : 

- un champ de saisie, 

- un champ Interrupteur, 

- un champ Sélecteur, 

- un champ Combo, 

- un champ Notation. 




**`<Saisie obligatoire> : (Constante de type Entier)`**

Nouveau mode de gestion de la saisie obligatoire : 



|   |   |
| --- | --- |
| *saisieInvalideBloquante* | Le contrôle de la saisie obligatoire est activé et bloquant : lorsque l'utilisateur n'effectue pas de saisie dans le champ, il ne peut pas sortir du champ. <br><br>Dans ce cas, le champ est considéré en erreur dans les cas suivants : <br><br>- Champ de saisie : Champ en erreur si le contenu est vide. <br><br>- Champ Combo en saisie : Champ en erreur si le contenu est vide. <br><br>- Champ Combo sans saisie : Champ en erreur si aucune ligne n'est sélectionnée. <br><br>- Champ Interrupteur : Champ en erreur si aucune option n'est cochée. <br><br>- Champ Sélecteur : Champ en erreur si aucune option n'est cochée. <br><br>- Champ Notation : Champ en erreur si aucune étoile n'est affichée. <br><br><br> |
| *saisieInvalideNonBloquante* | Le contrôle de la saisie obligatoire est non bloquant : lorsque l'utilisateur n'effectue pas de saisie dans le champ, il peut continuer sa saisie. |
| *saisieInvalideRien* | La saisie obligatoire n'est pas définie pour le champ. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Jusqu'à la version 2024, la propriété **SaisieObligatoire** permettait uniquement de connaître et de modifier si la saisie était obligatoire (Vrai) ou non (Faux). Il est désormais possible de savoir si la saisie obligatoire est bloquante ou non.
