


## URL (Propriété)

***En anglais : URL***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **URL** permet de :

- Connaître l'adresse associée à un champ.

- Modifier l'adresse associée à un champ.




Ce champ peut correspondre :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) sous l'éditeur de fenêtres à un Champ d'affichage HTML.

- sous l'éditeur de pages, à un lien, un bouton, une image cliquable, un champ iFrame, un champ Page cornée, un champ Code-barres ou une option de menu (définie sous l'éditeur ou par programmation).

- sous l'éditeur d'états, à un lien.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
LIEN_LIEN1.URL = "http://www.pcsoft.fr"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître l'adresse associée à un champ

`<Résultat> = <Champ manipulé>.URL`
---

**`<Résultat> : (Chaîne de caractères)`**

Adresse associée au champ.

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler :

- Champ d'une fenêtre : champ d'affichage HTML. 

- Champ d'une page : Lien, Bouton, Image, iFrame, Page cornée, Code-barres ou option de menu.

- Champ d'un état : Lien.  





<a name="SYNTAXE2"></a>

### Modifier l'adresse associée à un lien

`<Champ manipulé>.URL = <Nouvelle adresse>`
---

**`<Champ manipulé> : (Nom de champ)`**

Nom du champ à manipuler :

- Champ d'une fenêtre : champ d'affichage HTML. 

- Champ d'une page : Lien, Bouton, Image, iFrame, Page cornée, Code-barres ou option de menu.

- Champ d'un état : Lien.




**`<Nouvelle adresse> : (Tout type)`**

Nouvelle adresse associée au lien. Cette adresse doit contenir "http://".

### Limites
<a name="limites_ELTPARAGRAPHE000102"></a>![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) La propriété **URL** est disponible uniquement sur :

- les champs Lien d'une page.

- les champs Bouton d'une page.

- les champs Image cliquable d'une page.

- les champs iFrame d'une page.

- les options de menu d'une page.

- les champs Page cornée d'une page.

- les champs Code-barres d'une page.  

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) les champs Lien d'un état.


 
![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La propriété **URL** peut être utilisée uniquement sur :

- les champs Lien d'une page.

- les champs Image d'une page.

- les champs Image cliquable d'une page.

- les liens d'un champ Chemin de navigation.

- les champs Page cornée d'une page.

- les champs Captcha d'une page.

- les options de menu d'une page.
