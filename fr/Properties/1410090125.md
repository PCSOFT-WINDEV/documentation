
## Trou (Propriété)

***En anglais : Hole***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Trou** permet de définir les trous d'un polygone. Ce trou correspond à une polyligne simple et fermée présente à l'intérieur d'un polygone. Cette propriété est disponible sur : 

- une variable de type [Polygone2D](../WDLang4/1410090122.md). 

- une variable de type [PolygoneGéo](../WDLang4/1410090127.md).
