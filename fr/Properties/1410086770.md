
## Notation

***En anglais : Notation***
	

<a name="description"></a>
La propriété **Notation** permet de connaître et modifier une notation. Cette propriété est utilisable sur :

- une variable de type [FormatNumérique](../WDLang1/1410089836.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) une variable de type [iaElementConversation](../WDLang1/1410091337.md).
