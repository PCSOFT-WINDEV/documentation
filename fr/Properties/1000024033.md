


## Requête

***En anglais : Query***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé "Requête" permet de désigner : 

- les requêtes SQL disponibles en WLangage. Pour plus de détails, consultez [Requêtes SQL en WLangage](../Motscles/1514082.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) les requêtes utilisées par les variables de type [URI](../WDLang3/1000024027.md).
