
## IAPromptSystème (Propriété)

***En anglais : AISystemPrompt***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **IAPromptSystème** permet de définir et de modifier le premier texte envoyé par le champ Chat IA au modèle d'IA pour définir son rôle et des instructions.                                                                                                                                                                                    
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
soit Prompt = [
	Vous êtes un assistant IA amical nommé Philibert. 
	- L'utilisateur s'appelle %1
	- La date du jour est le %2
	- Répondez aux questions de l'utilisateur de manière claire, concise et précise.
]
Prompt = ChaîneConstruit(Prompt, RéseauUtilisateur(), DateVersChaîne(DateDuJour()))
CHATIA_ChatIA.IAPromptSystème = Prompt
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le prompt système utilisé pour le modèle d'IA

`<Résultat> = <Champ Chat IA>.IAPromptSystème`
---

**`<Résultat> : (Chaîne de caractères)`**

Prompt système utilisé.  

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.   


<a name="SYNTAXE2"></a>

### Modifier le prompt système utilisé pour le modèle d'IA

`<Champ Chat IA>.IAPromptSystème = <Nouveau libellé>`
---

**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé.

**`<Nouveau libellé> : (Chaîne de caractères)`**

Nouveau prompt système utilisé.
