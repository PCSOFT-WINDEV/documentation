
## Polyligne (Propriété)

***En anglais : Linestring***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Polyligne** permet de définir les différentes polylignes d'un multipolyligne. Cette propriété est disponible sur : 

- une variable de type [MultiPolyligneGéo](../WDLang4/1410090133.md). 

- une variable de type [MultiPolyligne2D](../WDLang4/1410090131.md).
