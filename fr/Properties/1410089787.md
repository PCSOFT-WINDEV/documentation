
## Coché (Propriété)

***En anglais : Checked***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Coché** permet de savoir si un élément est coché ou non. 

Cette propriété est utilisable : 

- sur les options de menu et les lignes d'un champ Arbre. Pour plus de détails, consultez [la propriété Cochée sur les champs](../Proprietes/2510019.md). 

- sur une variable de type [docElémentInterrupteur](../WDLang1/1410089762.md).
