
## HnswEfConstruction (Propriété)

***En anglais : HnswEfConstruction***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **HnswEfConstruction** permet de connaître et de modifier le nombre de voisins maximum de l'élément dans le HNSW de l'index sémantique.
 
Il est ainsi possible de :

- Connaître le nombre maximum de voisins à prendre en compte pour un index sémantique (défini sous l'éditeur d'analyses ou défini par programmation).

- Définir  le nombre maximum de voisins à prendre en compte pour un index sémantique (lors de la description de l'index sémantique par programmation).




Remarque : Plus la valeur de cette propriété est grande, plus l'insertion sera précise. L'index gagnera en qualité mais le temps d'insertion sera plus long. Par défaut, cette propriété a pour valeur 64. Ce nombre est un compromis entre performance et précision.
<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le nombre maximum de voisins

`<Résultat> = <Fichier de données>.<Index sémantique>.HnswEfConstruction`
---

**`<Résultat> : (Entier)`**

Nombre maximum de voisins. 

**`<Fichier de données> : (Chaîne de caractères)`**

Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de IndexSémantique](../WDLang4/1410086697.md).

**`<Index sémantique> : (Chaîne de caractères)`**

Nom de l'index sémantique manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de IndexSémantique](../WDLang4/1410086697.md).  


<a name="SYNTAXE2"></a>

### Définir le nombre maximum de voisins

`<Index sémantique>.HnswEfConstruction = <Nombre de voisins>`
---

**`<Index sémantique> : (Chaîne de caractères)`**

Nom de l'index sémantique manipulé. Ce nom vient d'être défini grâce au type [Description de IndexSémantique](../WDLang4/1410086697.md).  

**`<Nombre de voisins> : (Entier)`**

Nombre maximum de voisins.
