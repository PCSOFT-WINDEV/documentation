
## Préfixe (Propriété)

***En anglais : Prefix***
	



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
La propriété **Préfixe** permet de définir des préfixes. Cette propriété est utilisable sur :

- une variable de type [mongoGridFS](../WDLang4/1000022416.md).

- une variable de type [FormatNumérique](../WDLang1/1410089836.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) une variable de type [iaElementConversation](../WDLang1/1410091337.md).
