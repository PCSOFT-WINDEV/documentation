
## CBCapture (Fonction)

***En anglais : BCCapture***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Décode les informations stockées dans un code-barres en utilisant la caméra de l'appareil (Android, iPhone, iPad).

**Conseil : Préférez le champ Caméra** : 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Le champ Caméra permet également de décoder directement les codes-barres. Pour plus de détails, consultez [Champ Caméra : décoder les codes-barres](../WDChamp/1013304.md).

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Il est conseillé de remplacer cette fonction par une fenêtre de l'application contenant un champ Caméra qui autorise le décodage des différents codes-barres. Pour plus de détails, consultez [Champ Caméra : décoder les codes-barres](../WDChamp/1013304.md).









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Décodage d'un code-barres QR Code
cb est un CodeBarres
cb = CBCapture()
SI ErreurDétectée = Faux _ET_ cb.TypeContenu = cbTypeEmail ALORS
    	Info("Adresse email : " + cb.ValeurBrute)
FIN
```

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000224"></a>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Dans une application Android : 

- La fonction **CBCapture** ouvre une nouvelle fenêtre affichant la prévisualisation de la caméra de l'appareil. Il suffit ensuite de : 

	- cadrer le code-barres à décoder dans la zone prévue à cet effet. 

	- valider comme pour une prise de photo classique.







- Le décodage de codes-barres utilise l'API de lecture de codes-barres de ML Kit. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Pour les applications iPhone/iPad : 

- La fonction **CBCapture** ouvre une nouvelle fenêtre affichant la prévisualisation de la caméra de l'appareil. Il suffit ensuite de cadrer le code-barres à décoder dans la zone prévue à cet effet. 

- La fenêtre permettant de prendre les photos est inclue dans l'application WINDEV Mobile. Aucune librairie supplémentaire n'est nécessaire. 







<a name="NOTE0_2"></a>


### Gestion des erreurs
<a name="gestion_des_erreurs_ELTPARAGRAPHE000275"></a>Pour savoir si la récupération du code-barres a échoué, utilisez la variable [ErreurDétectée](../WDLang1/3087001.md).

La fonction échouera dans les cas suivants : 

- si elle est utilisée dans le simulateur, 

- si elle est utilisée dans l'émulateur, 

- si elle est utilisée sur un appareil ne disposant pas d'une caméra.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) si le bouton "Annuler" a été utilisé. Dans ce cas, la propriété **TypeCodeBarre** de la variable [CodeBarres](../WDLang5/1000019451.md) sera différente de CB_QRCODE. 




![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Si le code-barres est décodé mais que son type n'est pas reconnu, la propriété **TypeCodeBarre** de la variable [CodeBarres](../WDLang5/1000019451.md) correspondra à la constante *CB_INCONNU*.

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000448"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **CBCapture** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
