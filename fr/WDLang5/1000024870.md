


## xlsCommentaire (Type de variable)

***En anglais : xlsComment***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **xlsCommentaire** permet de définir toutes les caractéristiques avancées d'un commentaire dans une cellule d'une feuille XLS ou dans une cellule d'un champ Tableur. Les caractéristiques de ce commentaire peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute un commentaire pour la cellule A1 et le rend visible
TBLR_Tableur["A1"].Commentaire.Texte = "Titre" + RC + "ma note"
TBLR_Tableur["A1"].Commentaire.Visible = Vrai
```



```wl
sFic est une chaîne	= "fichier.xlsx"
xlsDoc est un xlsDocument
xlsDoc.AjouteFeuille("F1")
xlsDoc.Cellule[2, 5] = xlsCoordonnéesVersNom(2, 2)
xlsDoc.Commentaire[2, 5].Texte = "Commentaire"
xlsDoc.Commentaire[2, 5].Rectangle.X = 10
xlsDoc.Commentaire[2, 5].Rectangle.Y = 10
xlsDoc.Commentaire[2, 5].Rectangle.Largeur = 40
xlsDoc.Commentaire[2, 5].Rectangle.Hauteur = 20
xlsDoc.Commentaire[2, 5].Visible = Vrai
xlsDoc.Sauve(sFic)
xlsDoc.Ferme()
```

<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type xlsCommentaire
<a name="proprietes_specifiques_description_des_variables_type_xlscommentaire_ELTPARAGRAPHE000041"></a>Les propriétés suivantes peuvent être utilisées pour manipuler un commentaire d'une cellule :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Position | Chaîne de caractères | Cellule pour laquelle le commentaire est affiché (par exemple, "A3"). <br><br>**Cette propriété est disponible en lecture seulement.** |
| Rectangle | Variable de type [Rectangle](../Motscles/1514079.md) | Taille et position en pixels du rectangle contenant le commentaire. <br><br>Remarque : L'origine du rectangle 0,0 est donnée par rapport au point haut droit de la cellule.<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Cette propriété n'est pas disponible. |
| Texte | Chaîne de caractères | Texte du commentaire. |
| Visible | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> pour afficher le commentaire,<br><br>- <u><u><u>Faux</u></u></u> pour rendre le commentaire invisible. Dans ce cas, seul un triangle rouge dans le coin haut droit de la cellule permettra à l'utilisateur de savoir que la cellule est associée à un commentaire.<br><br><br> |
