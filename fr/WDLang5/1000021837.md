


## FBRécupèreInformationUtilisateur (Fonction)

***En anglais : FBGetUserInformation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère les informations Facebook de l'utilisateur connecté. 

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette fonction est disponible dans le simulateur.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) **Attention** : Cette fonctionnalité est disponible jusqu'à Android 11. A partir d'Android 12, cette fonction provoque une erreur fatale. 
Il est conseillé de : 

- tester la version d'Android utilisée via la fonction [SysVersionAndroid](../WDLang1/1000019785.md).

- utiliser la fonction [AuthIdentifie](../WDLang3/1000022219.md) pour gérer l'authentification Facebook. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaSession est une fbSession
...
sEmail est chaîne = FBRécupèreInformationUtilisateur(MaSession, fbEmail)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = FBRécupèreInformationUtilisateur(<Session> , <Information>)`
---

**`<Résultat> : (Chaîne de caractères ou Buffer)`**

Information demandée. 

**`<Session> : (Variable de type fbSession)`**

Nom de la variable de type [fbSession](../WDLang5/1000021851.md) correspondant à la connexion Facebook à manipuler. 

**`<Information> : (Constante de type chaîne de caractères)`**

Information demandée : 


|   |   |
| --- | --- |
| *fbEmail* | Email de l'utilisateur. |
| *fbIdentifiant* | Identifiant Facebook de l'utilisateur. |
| *fbImage* | Image de l'utilisateur. |
| *fbNom* | Nom de l'utilisateur. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Lors de la connexion, les droits (permissions) correspondant à l'information demandée devront avoir été accordés. Dans le cas contraire, la fonction échouera.
