


## WDDeploy : Déployer un package

## Présentation
<a name="presentation_ELTTEXTE000167"></a>
WDDeploy permet de :

- installer un package de déploiement (généré avec WEBDEV) sur un serveur Web. 

- [installer les fichiers d'un site statique ou PHP sur un serveur Web](#NOTE2_1).

## Installer un package de déploiement sur un serveur Web
<a name="installer_package_deploiement_sur_serveur_web_ELTTEXTE000191"></a>


### Lancement direct de WDDeploy
<a name="lancement_direct_wddeploy_ELTPARAGRAPHE000023"></a>Rappel : la création d'un package de déploiement est une des options de déploiement proposée par WEBDEV. L'utilisation d'un package de déploiement peut être nécessaire par exemple pour : 

- déployer un site ou un Webservice à l'identique de celui en production sur un nouveau serveur, 

- déléguer le déploiement à une équipe infrastructure dédiée.




Lors la création de ce package, certaines informations (les profils) sont soit non connues soit fournies par l'équipe chargée du déploiement, comme :

- les adresses de déploiement de serveurs,

- les comptes WEBDEV et mots de passe, etc.




A la fin de l'assistant de création du package, le bouton "Déployer" permet de lancer WDDeploy. 

Il est également possible de lancer directement le programme WDDeploy.exe présent dans le sous-répertoire "Programs" du répertoire d'installation de WEBDEV. Dans ce cas, une fenêtre permet de choisir le type de déploiement à effectuer. Dans notre cas, il suffit de sélectionner "Site WEBDEV". 
De la même façon, il est possible de déployer un package d'un Webservice REST ou SOAP. 


### Contenu du package de déploiement et possibilité d'adaptation du package
<a name="contenu_package_deploiement_possibilite_adaptation_package_ELTPARAGRAPHE000042"></a>Le package de déploiement contient l'ensemble des informations et des données nécessaires au déploiement du site ou Webservice. 

- Si certaines informations n'ont pas été renseignées, elles devront être complétées au préalable par l'équipe chargée du déploiement. Ce package est fourni sous la forme d'une archive zip.

- Il est conseillé de nommer cette archive avec un numéro de version et un timestamp et de documenter l'historique des versions.


Ce fichier peut ensuite être transmis au service qui s'occupera du déploiement.

Le package de déploiement étant fourni sous la forme d'une archive au format zip, il est possible d'en modifier le contenu pour des personnalisations programmées si nécessaire. Par exemple pour un déploiement spécifique dans une infrastructure de pré-production.
**Important** : le package de déploiement (.zip) utilise un format avancé que l'explorateur Windows ne sait pas gérer (vous ne verriez pas les fichiers du site / Webservice). Pour une édition "visuelle", il est donc nécessaire d'utiliser WDZip (accessible depuis le menu "Outils" de WINDEV) ou des outils externes (7-Zip, Winzip, etc.).

L'archive contient notamment un fichier .wwf de configuration. Ce fichier est au format XML et peut donc être modifié par script ou programmation. En cas de modifications, il est important de réaliser des tests au préalable.




### Déploiement du package avec WDDeploy : interface interactive
<a name="deploiement_package_avec_wddeploy_interface_interactive_ELTPARAGRAPHE000059"></a>Pour installer un package de déploiement sur un serveur Web via WDDeploy :

1. Sélectionnez si nécessaire le package à traiter (fichier ZIP créé par WEBDEV).

2. Créez ou sélectionnez **le(s) profil(s) de déploiement** correspondant(s) à votre site. Les caractéristiques sont saisies dans différents onglets :

	- Nom du profil. 
			Lors de la création d'un profil, un nom par défaut est automatiquement donné. Il est possible de modifier ce nom.

	- Onglet "Général" : 

		- Paramètres du serveur d'application : adresse, compte et mot de passe. 

		- Paramètres du site : Nom de déploiement, domaine, répertoire des fichiers de données HFSQL Classic, langues déployées. 




- Onglet "Avancé" : 

	- Mode de transfert des fichiers d'installation : 

		- HTTP (aucune configuration spécifique n'est nécessaire). 

		- FTP : Dans ce cas, les caractéristiques du serveur FTP doivent être indiquées.

3. Vérifiez (et modifiez si nécessaire) **les informations du package**, disponibles dans les différents onglets de WDDeploy. Ces informations correspondent aux informations saisies dans l'assistant de déploiement : 

	- l'onglet "Fichiers" liste les différents fichiers contenus dans le package à déployer. 

	- l'onglet "Paramètres" permet de connaître les paramètres de déploiement du site. Ces informations peuvent être modifiées. 

	- l'onglet "Synchro. Données" permet connaître et modifier les informations concernant la modification automatique des fichiers de données. 

	- l'onglet "Statistiques" permet de configurer la génération du fichier de statistiques pour le site. 

	- l'onglet "Groupware" permet de connaître et modifier si nécessaire le répertoire d'installation des fichiers du groupware utilisateur. 




4. Cliquez sur "Déployer le site" pour déployer le package. 





### Déploiement du package avec WDDeploy en ligne de commande
<a name="deploiement_package_avec_wddeploy_ligne_commande_ELTPARAGRAPHE000095"></a>Il est également possible d'effectuer le déploiement en ligne de commande (sans interaction) en indiquant le chemin de package de déploiement et le nom du profil de déploiement à ajouter : 

```txt
WDDeploy.exe /DYNAMIQUE=<package déploiement> 
	/TARGET=<nom du profil de déploiement> /AUTO
```


Détails des paramètres :

| Paramètre | Signification |
| --- | --- |
| /DYNAMIQUE=&lt;package déploiement.zip&gt; | Nom et chemin du package de déploiement |
| /TARGET=&lt;nom du profil de déploiement&gt; | Nom du profil de déploiement utilisé. |
| /AUTO | Déploiement sans interface. |
