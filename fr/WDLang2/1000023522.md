


## &lt;Zone répétée&gt;.Occurrence (Fonction)

***En anglais : &lt;Looper&gt;.Count***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nombre de répétitions d'un champ Zone répétée.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Nombre de répétitions dans le champ Zone répétée "ZR_Zone1" ?
Résultat1 est un entier
Résultat1 = ZR_Zone1.Occurrence()
```
<a name="Exemple2"></a>

```wl
// Affiche le nombre de réponses trouvées : (ex : "Il y a 31 réponses")
LIB_LIBELLE1 = "Il y a " + ZR_ZoneResultat.Occurrence() + " réponses"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Zone répétée>.Occurrence([<Répétition/Attribut>])`
---

**`<Résultat> : (Entier)`**



- Nombre de répétitions du champ Zone répétée, 

- 0 si le champ Zone répétée est vide.




**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à manipuler.

**`<Répétition/Attribut> : (Constante (optionnelle))`**




|   |   |

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000294"></a>La fonction **&lt;Zone répétée&gt;.Occurrence** peut être utilisée indifféremment sur : 

- un champ Zone répétée fichier,

- un champ Zone répétée par programmation. 


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur. ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire. ![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La fonction **&lt;Zone répétée&gt;.Occurrence** peut être utilisée uniquement sur un champ Zone répétée par programmation.
