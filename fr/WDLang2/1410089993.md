
## adminWBApplication (Type de variable)

***En anglais : WBAdminApplication***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **adminWBApplication** permet de définir toutes les caractéristiques avancées d'une application WEBDEV déployée sur un serveur WEBDEV. Les caractéristiques de cette application peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
login est un adminWBAuth
login.AdresseServeur = "http://xxxx"
login.Utilisateur = "monuser"
login.MotDePasse = "monmotdepasse"

Applications est un tableau de adminWBApplication
Applications = AdminWBListeApplication(login)
POUR i = 1 _À_ Applications.Occurrence  
     Trace(Applications[i].Nom)
     Trace(Applications[i].ComptePropriétaire)
FIN
```





<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type adminWBApplication
<a name="proprietes_specifiques_description_des_variables_type_docparampagetitleshort_ELTPARAGRAPHE000026"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **adminWBApplication** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| ComptePropriétaire | Chaîne de caractères | Compte propriétaire de l'application. |
| Nom | Chaîne de caractères | Nom de l'application. |
| Type | Constante de type Entier | Type de l'application :<br><br>- *adminWBTypeSite* : Site. <br><br>- *adminWBTypeWebserviceSOAP* : Webservice SOAP. <br><br>- *adminWBTypeWebserviceREST* : Webservice REST. <br><br>- *adminWBTypeWebSocket* : WebSocket. <br><br><br> |
