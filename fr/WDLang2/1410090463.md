
## Constantes de pilotage du serveur d'application WEBDEV
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les constantes utilisées pour le pilotage du serveur d'application WEBDEV sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **adminWBEcraseSiExistant** | Permet la recréation d'un compte existant. | [AdminWBCréeCompte](../WDLang2/1410089450.md) |
| **adminWBTypeSite** | Type d'application : Site. | [AdminWBListeApplication](../WDLang2/1410089996.md)<br>[AdminWBSupprimeApplication](../WDLang2/1410089999.md) |
| **adminWBTypeWebserviceREST** | Type d'application : Webservice REST. | [AdminWBListeApplication](../WDLang2/1410089996.md)<br>[AdminWBSupprimeApplication](../WDLang2/1410089999.md) |
| **adminWBTypeWebserviceSOAP** | Type d'application : Webservice SOAP. | [AdminWBListeApplication](../WDLang2/1410089996.md)<br>[AdminWBSupprimeApplication](../WDLang2/1410089999.md) |
| **adminWBTypeWebSocket** | Type d'application : WebSocket. | [AdminWBListeApplication](../WDLang2/1410089996.md)<br>[AdminWBSupprimeApplication](../WDLang2/1410089999.md) |
