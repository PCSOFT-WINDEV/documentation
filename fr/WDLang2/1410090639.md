


## &lt;Zone répétée&gt;.AjouteDébut (Fonction)

***En anglais : &lt;Looper&gt;.AddBeginning***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une répétition (ou ligne) au début d'un champ Zone répétée infinie. La répétition est insérée avant la première répétition du champ Zone répétée. La position de défilement du champ Zone répétée n'est pas modifiée. 

Remarque : Il est conseillé d'utiliser cette fonction dans l'événement "Ajout d'éléments supplémentaires (par le haut)" du champ Zone répétée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ZR_Email.AjouteDébut(Email.Date, Email.Texte, Email.Auteur)
ZR_Email.AjoutEnCours(taIndicateurRafraîchissementHaut, Faux)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Zone répétée>.AjouteDébut([<Valeur 1> [... [, <Valeur N>]]])`
---

**`<Champ Zone répétée> : (Nom de champ)`**

Nom du champ Zone répétée à manipuler.

**`<Valeur 1> : (Type de l'attribut associé (optionnel))`**

Valeur du 1er attribut de la répétition à insérer dans le champ Zone répétée spécifié.
Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
Pour ne pas spécifier de valeur pour un des attributs, utilisez une chaîne vide ("") ou 0 (selon le type de l'attribut).
Si aucun des ces paramètres n'est spécifié, une répétition vide est insérée dans le champ Zone répétée.



**`<Valeur N> : (Type de l'attribut associé (optionnel))`**

Valeur du Nième attribut de la répétition à insérer dans le champ Zone répétée spécifié.
Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
Pour ne pas spécifier de valeur pour un des attributs, utilisez une chaîne vide ("") ou 0 (selon le type de l'attribut).
Si aucun des ces paramètres n'est spécifié, une répétition vide est insérée dans le champ Zone répétée.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000203"></a>La fonction **&lt;Zone répétée&gt;.AjouteDébut** peut être utilisée indifféremment sur : 

- un champ Zone répétée fichier,

- un champ Zone répétée par programmation. 


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur. ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire. 
<a name="NOTE0_3"></a>


### Caractéristiques de la répétition
<a name="caracteristiques_repetition_ELTPARAGRAPHE000228"></a>Si une valeur correspond au résultat d'un calcul, mettez l'expression numérique entre parenthèses. 

Par exemple :

```wl
ZR_ZoneCalcul.AjouteDébut((53+29), (83-21))
```

<a name="NOTE0_4"></a>


### Tri
<a name="tri_ELTPARAGRAPHE000248"></a>La fonction **&lt;Zone répétée&gt;.AjouteDébut** ne tient pas compte du tri.
