


## PageAdresse (Fonction)

***En anglais : PageAddress***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'obtenir l'adresse Internet d'une page.  

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Renvoie l'adresse d'une page WEBDEV.

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Renvoie l'adresse de la page en cours.

## Syntaxe
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 
### Récupérer l'adresse d'une page 

`<Résultat> = PageAdresse([<Page> [, <Option>]])`
---

**`<Résultat> : (Chaîne de caractères Ansi)`**

Adresse de la page spécifiée ou chaîne vide ("") si :

- la page n'existe pas dans le projet

- le contexte de la page n'est pas ouvert (fonction [ContexteOuvre](../WDLang2/3058004.md)).




**`<Page> : (Nom de page)`**

Nom de la page dont l'adresse doit être renvoyée.
Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le nom de la page correspond au nom de la page en cours.

**`<Option> : (Constante optionnelle)`**

Type d'adresse à renvoyer :


|   |   |
| --- | --- |
| *paComplète* | Adresse complète de la page (adresse en HTTP). |
| *paComplèteAuto* | Adresse complète de la page avec le protocole utilisé pour son affichage (HTTP ou HTTPS). |
| *paRelative*<br>(Valeur par défaut) | Adresse relative au domaine en cours. |
| *paSécurisée* | Adresse complète de la page, sécurisée par SSL (adresse en HTTPS). |

### Récupérer l'adresse de la page en cours

`<Résultat> = PageAdresse()`
---

**`<Résultat> : (Chaîne de caractères Unicode)`**
