


## &lt;Image&gt;.Premier (Fonction)

***En anglais : &lt;Image&gt;.First***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche la première image du défilement.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche la première bannière
IMG_Bannière.Premier()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Image>.Premier()`
---

**`<Champ Image> : (Nom de champ)`**

Nom du champ à manipuler : 

- Champ Image,

- Champ Image cliquable,

- Champ Vignette.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Gestion des effets de transition
<a name="gestion_des_effets_transition_ELTPARAGRAPHE000167"></a>Si des effets de transition ont été spécifiés lors de la description du champ : 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ces effets de transition sont pris en compte lors de l'utilisation de la fonction **&lt;Image&gt;.Premier**. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Ces effets de transition ne sont pas pris en compte lors de l'utilisation de la fonction **&lt;Image&gt;.Premier**. En effet, la page est totalement rafraîchie. Pour prendre en compte ces effets, il suffit d'utiliser un code en mode Ajax.
