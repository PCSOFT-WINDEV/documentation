
## NavigateurPartage (Fonction)

***En anglais : BrowserShare***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance le partage natif de l'appareil. Il est possible d'indiquer le texte à partager, le titre du partage et l'URL à partager (de type https).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
NavigateurPartage("Les meilleures recettes pour les gourmands", "40 recettes", "https://cuisine.precilia.com")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = NavigateurPartage(<Texte> [, <Titre> [, <URL>]])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la fonctionnalité de partage est supportée par le navigateur, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Texte> : (Tous types)`**

Texte à partager.

**`<Titre> : (Chaîne de caractères optionnelle)`**

Titre du partage. 

**`<URL> : (Chaîne de caractères optionnelle)`**

URL du partage (de type https).
