


## &lt;Page&gt;.Adresse (Fonction)

### Récupérer l'adresse d'une page 

`<Résultat> = <Page>.Adresse([<Option>])`
---

**`<Résultat> : (Chaîne de caractères Ansi)`**

Adresse de la page spécifiée ou chaîne vide ("") si :

- la page n'existe pas dans le projet

- le contexte de la page n'est pas ouvert (fonction [ContexteOuvre](../WDLang2/3058004.md)).




**`<Page> : (Nom de page)`**

Nom de la page dont l'adresse doit être renvoyée.

**`<Option> : (Constante optionnelle)`**

Type d'adresse à renvoyer :


|   |   |
| --- | --- |
| *paComplète* | Adresse complète de la page (adresse en HTTP). |
| *paComplèteAuto* | Adresse complète de la page avec le protocole utilisé pour son affichage (HTTP ou HTTPS). |
| *paRelative*<br>(Valeur par défaut) | Adresse relative au domaine en cours. |
| *paSécurisée* | Adresse complète de la page, sécurisée par SSL (adresse en HTTPS). |
