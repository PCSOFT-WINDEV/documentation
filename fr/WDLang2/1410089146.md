
## Procédure WLangage appelée par la fonction PopupAffichePage



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Procédure WLangage (appelée "callback") appelée par la fonction [PopupAffichePage](../WDLang2/1410087258.md) après la fermeture de la page affichée en mode popup. Cette procédure est une procédure navigateur et elle peut correspondre à une procédure locale, globale ou interne.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 
```wl
// Affiche la page PAGE_DétailsProduit en popup
// Attend la fermeture de la page et affiche la valeur renvoyée
PopupAffichePage(PAGE_Détail, (nIDProduit), PopupAffiche_Callback, BTN_CHAMP, popupPositionXY, 10, 10)
	
	PROCÉDURE INTERNE PopupAffiche_Callback(RetourPagePopup)
		Trace("La popup a renvoyé : [%RetourPagePopup%]")
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`PopupAffichePage_Callback(<Valeur de retour>)`
---

**`<Valeur de retour> : (Type de la valeur de retour)`**

Valeur qui sera renvoyée par la page via la fonction [PopupFermePage](../WDLang2/1410087259.md).
