## Présentation du champ Bouton segmenté
<a name="presentation_champ_bouton_segmente_ELTTEXTE000145"></a>
Le champ Bouton Segmenté peut se comprendre comme un ensemble de boutons ON/OFF regroupés dans un seul champ. Le rendu visuel est automatiquement plus soigné.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=wd-bouton-segmente-3.gif)<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=wd-bouton-segmente-1.gif)<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=wd-bouton-segmente-2.gif)


Le fonctionnement est standardisé : choix exclusif (mode sélecteur) ou multiple (mode interrupteur) possible.

Le contenu de chaque choix peut être un texte ou une image.

<a name="NOTE2_1"></a>


## Créer un champ Bouton segmenté
<a name="creer_champ_bouton_segmente_ELTTEXTE000169"></a>
**Pour créer un champ de type Bouton segmenté :**

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur "Bouton segmenté".

2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création. 




**Pour afficher les caractéristiques du champ**, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Caractéristiques du champ Bouton segmenté
<a name="caracteristiques_champ_bouton_segmente_ELTTEXTE000193"></a>


### Fenêtre de description
<a name="fenetre_description_ELTPARAGRAPHE000049"></a>L'onglet "Général" de la fenêtre de description du champ Bouton segmenté permet de saisir les principales caractéristiques du champ : 

- **Mode** : Cette option correspond au mode d'utilisation du champ Bouton segmenté. Il est possible d'autoriser : 

	- la sélection d'un seul élément (mode Sélecteur). 

	- la sélection de plusieurs éléments (mode Interrupteur).




- **Options** : Chaque segment du champ correspond à une option. Pour chaque option, il est possible de définir : 

	- l'image de fond du segment. Cette image est prioritaire sur le libellé. Cette image peut avoir plusieurs états : Off, Survol, Enfoncé, On, Grisé.  

	- le libellé de l'option. 

	- la bulle d'aide de l'option. 







Des paramètres supplémentaires peuvent être définis dans les différents onglets de la fenêtre de description du champ : 

- L'espace entre les options (onglet "Détail"). 

- Le style des différents segments du champ (onglet "Style"). Il est par exemple possible : 

	- d'afficher ou non un séparateur vertical entre les options.  

	- d'utiliser une couleur de fond spécifique pour visualiser le bouton enfoncé, en modifiant l'état "On" du cadre des options. 







Remarque : Pour afficher un libellé et un picto dans une option d'un bouton segmenté, il est nécessaire : 

- soit d'utiliser la fonction [gImage](../WDLang1/3029042.md). 

- soit d'utiliser un libellé en markdown. 





### Fonctionnement du mode interrupteur et du mode sélecteur
<a name="fonctionnement_mode_interrupteur_mode_selecteur_ELTPARAGRAPHE000080"></a>Selon le mode de fonctionnement du champ Bouton segmenté, le comportement du champ est différent. 

- En mode sélecteur, une seule option peut être sélectionnée. Le clic sur une option sélectionnée ne la désélectionne pas. 
	Pour désélectionner une option sélectionnée (et ainsi avoir aucune option sélectionnée), il est nécessaire de le faire par programmation (en modifiant la valeur de l'option). 

- En mode interrupteur, plusieurs options peuvent être sélectionnées. Le clic sur une option sélectionnée désélectionne automatiquement cette option.  



![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) 

### FAA (Fonctionnalités Automatiques de vos Applications) associées au champ
<a name="faa_fonctionnalites_automatiques_vos_applications_associees_champ_ELTPARAGRAPHE000092"></a>Par défaut, la FAA "Mémoriser la valeur" est associée au champ. L'option est proposée dans le menu contextuel du champ.
