
## Manipuler un champ Bouton segmenté par programmation
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000154"></a>
WINDEV et WINDEV Mobile permettent de manipuler un champ Bouton segmenté directement par programmation. Il suffit d'utiliser directement la variable du champ Bouton segmenté dans le code.

Un champ Bouton segmenté est composé de plusieurs boutons, chaque "bouton" correspondant à une option. 

Plusieurs fonctions WLangage permettent d'ajouter, d'insérer ou de supprimer des options dans un champ Bouton segmenté. Pour plus de détails, consultez [fonctions de gestion des champs Bouton segmenté](../WDLang1/1410090900.md).

## Manipuler une option d'un champ Bouton segmenté
<a name="manipuler_une_option_champ_bouton_segmente_ELTTEXTE000178"></a>


### Présentation
<a name="presentation_ELTPARAGRAPHE000024"></a>Pour manipuler une option d'un champ Bouton segmenté, il suffit de préciser l'indice de l'option à manipuler. 

Par exemple, pour récupérer la valeur d'une option, utilisez la syntaxe suivante :

```txt
<Champ Bouton segmenté>[Indice de l'option].Propriété = <Valeur de la propriété>
```



### Connaître les options sélectionnées
<a name="connaitre_les_options_selectionnees_ELTPARAGRAPHE000033"></a>**Pour savoir si une option est sélectionnée**, il suffit de récupérer la valeur d'une option, via la syntaxe suivante :

```txt
<Valeur_Option> = <Champ Bouton segmenté>[Indice de l'option]
```

Dans ce cas, le paramètre &lt;Valeur_Option&gt; est un booléen qui vaut :

- Vrai (1) si l'option est sélectionnée,

- Faux (0) si l'option n'est pas sélectionnée.




**Pour connaître toutes les options sélectionnées** : 

- Solution 1 : parcourir toutes les options du champ. Exemple : 
	
	```wl
	Options_sélectionnées est une chaîne
	POUR I = 1 A BS_Test.Occurrence
		SI BS_Test[I] = 1 ALORS 
			Options_selectionnées += BS_Test[I].Libellé + RC
		FIN
	FIN
	```


- Solution 2 : utiliser la valeur du champ Bouton segmenté. 

	- Si le champ Bouton segmenté est en mode "sélecteur", la valeur du champ correspond à l'option sélectionnée.  
			Exemple : Dans le champ, l'option 1 est sélectionnée : 
			
		```wl
		Trace(BS_Test) // Renvoie 1
		Trace(BS_Test.Valeur) // Renvoie 1
		```


	- Si le champ Bouton segmenté est en mode "interrupteur", la valeur du champ correspond à une chaîne composée de 0 et 1 correspondant aux options sélectionnées (1) ou non (0). 
			Exemple : Dans le champ, les options 1 et 3 sont sélectionnées et l'option 2 et 4 ne sont pas sélectionnées : 
			
		```wl
		Trace(BS_Test) // Renvoie 1010
		Trace(BS_Test.Valeur) // Renvoie 1010
		```



 Ces syntaxes sont également utilisables pour initialiser la valeur d'un champ Bouton segmenté. 







### Propriétés spécifiques
<a name="proprietes_specifiques_ELTPARAGRAPHE000068"></a>Les propriétés suivantes peuvent être utilisées sur une option d'un champ Bouton segmenté : 


|   |   |
| --- | --- |
| [Grisé](../Proprietes/1000019648.md) | Permet de griser ou dégriser une option. <br><br> |
| [Libellé](../Proprietes/2510053.md) | Permet de connaître et modifier le libellé d'une option. |
| [Police](../Proprietes/2510095.md) | Permet de modifier la police du libellé d'une option. |
| [Valeur](../Proprietes/2510130.md) | Permet de savoir si une option est sélectionnée ou non et de la sélectionner / désélectionner. |
| [Visible](../Proprietes/2510138.md) | Permet de rendre visible ou invisible une option. |


Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Bouton segmenté ou ses options, consultez [Propriétés associées au champ Bouton segmenté](../WDChamp/1410087356.md).
