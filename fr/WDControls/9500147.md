


## Champ Image dans une fenêtre
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000258"></a>
Cette page d'aide présente les caractéristiques d'un champ Image présent dans une fenêtre. 

Rappel : Pour créer un champ de type Image : 

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur "Image".

2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.




**Pour afficher les caractéristiques du champ**, sélectionnez l'option "Description" dans le menu contextuel du champ.

<a name="NOTE2_1"></a>


## Options de la fenêtre de description
<a name="options_fenetre_description_ELTTEXTE000282"></a>


### Onglet "Général"
<a name="onglet_general_ELTPARAGRAPHE000037"></a>L'onglet "Général" permet de définir l'image affichée et ses caractéristiques. 

**Choix de l'image affichée dans le champ** : 
L'image affichée par le champ est sélectionnée via le bouton ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Menu_Image_Editeur%20-%20HC%20N%B0001.gif), option "Parcourir".
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) **Remarque** : Les images au format SVG avec style CSS ne sont pas supportées.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Si le champ Image affiche un fichier PDF**, il suffit de sélectionner le fichier PDF à afficher. Les propriétés WLangage suivantes sont disponibles pour configurer la page du fichier PDF affichée : 


|   |   |
| --- | --- |
| ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) [ImageMode](../Proprietes/2510058.md) | Permet de connaître et de modifier le mode d'affichage d'une image. |
| [NombrePage](../Proprietes/2510084.md) | Permet de connaître le nombre de pages présentes dans un fichier PDF affiché dans un champ Image. |
| [NuméroPage](../Proprietes/2510106.md) | Permet de connaître et de modifier le numéro de la page d'un fichier PDF affiché dans un champ Image d'une fenêtre. |





![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) **Attention** : L'affichage d'un fichier PDF dans une image nécessite le [framework GDI+](../Editeurs/2020007.md). 

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Pour gérer les DPI des appareils**, le nom du fichier image doit suivre un format spécifique. Pour plus de détails, consultez [Android/iOS : Fournir une image par DPI](../WDChamp/9500137.md).

**Autres options** : Il est possible de définir : 

- l'utilisation du [mode 9 images](../WDChamp/1010040.md).

- le mode d'affichage, de transparence, la position et la symétrie des images. Pour plus de détails, consultez [Choisir le mode d'affichage de l'image](../WDChamp/1013134.md).









### Onglet "UI"
<a name="onglet_ELTPARAGRAPHE000104"></a>Dans l'onglet "UI", il est possible de définir : 

- l'état initial du champ, 

- l'affichage ou non d'un symbole de représentation dans le champ. Le symbole de représentation correspond à la vignette affichée par défaut dans le champ Image sous l'éditeur.
	<br>![Image avec symbole de représentation](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Image_Mire%20-%20HC%20N%B0001.gif)<br>![Image sans symbole de représentation](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Image_Mire%20-%20HC%20N%B0001%201.gif)
 Cette option peut également être activée / désactivée pour tous les champs Image dans les options de l'éditeur de fenêtres. Pour plus de détails, consultez [Options de l'éditeur de fenêtres](../Editeurs/9000166.md). 

- l'action effectuée lors d'un clic droit, 

- le menu contextuel associé au champ, 

- ...





### Onglet "Détail"
<a name="onglet_detail_ELTPARAGRAPHE000126"></a>L'onglet "Détail" permet de définir :

- Les paramètres d'affichage

	- **Chargement en tâche de fond** : Cette option permet de ne pas bloquer l'application si l'image doit être chargée depuis un site. Une animation d'attente est automatiquement affichée dans le champ Image si nécessaire. 
			**Remarque** : Si le champ Image est présent dans un champ Zone répétée, l'image est toujours chargée en tâche de fond (que l'option soit activée ou non).

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) **Orienter selon les données Exif de l'image** : Si cette option est activée, une photo sera automatiquement affichée dans le sens adéquat (portrait ou paysage) selon les données Exif de la photo.
			

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) **Ascenseurs et zoom automatiques** :  Cette option est nécessaire pour l'affichage des PDF dans les champs Image. Si le PDF ne peut pas être affiché entièrement dans le champ Image, des ascenseurs sont affichés et le zoom est disponible en utilisant la touche Ctrl + la roulette de la souris. Le zoom peut également être manipulé par programmation grâce à la propriété [Zoom](../Proprietes/1000017201.md).

	- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Zoom et scroll au doigt** : Cette option permet de gérer le multi-touch dans les applications mobiles. Pour plus de détails, consultez [Multi-touch dans un champ Image](../WDChamp/9500131.md). 




- Les options d'animation
	Pour plus de détails, consultez [Animer une image](../WDChamp/1013244.md).

- Les options de cliquage
	Pour plus de détails, consultez [Image cliquable dans une fenêtre](../WDChamp/1013133.md).





### Onglet "Style"
<a name="onglet_style_ELTPARAGRAPHE000178"></a>L'onglet "Style" permet de définir le style des différents éléments du champ Image. Il est possible notamment de définir : 

- Une animation lors du changement de l'image affichée dans le champ (élément "Animation de champ"). Le bouton "Paramètres" permet de définir la durée de l'animation.

- Un cadre (élément "Cadre extérieur").

- Une ombre floue (élément "Ombre floue").




**Pour définir le cadre de l'image** : 

1. Sélectionnez l'élément "Cadre extérieur". 

2. Déroulez la liste "Cadre". Les différents cadres disponibles apparaissent. 

	- Les options "Arrondi xxx" permettent de définir un cadre arrondi. Si ces options sont sélectionnées, une flèche bleue permet d'ouvrir la fenêtre de paramétrage du style dans l'onglet "Style". 

	- L'option "Image (mode 9 images)" permet de choisir une image pour le cadre et de la paramétrer grâce au mode 9 images. 

	- L'option "Personnalisé" permet de définir un cadre personnalisé. Si cette option est sélectionnée, une flèche bleue permet d'ouvrir la fenêtre de paramétrage de la forme personnalisée.  

	- L'option "Rond" permet de créer une image ronde. Si ces options sont sélectionnées, une flèche bleue permet d'ouvrir la fenêtre de paramétrage (épaisseur et style du trait)
			Attention : Pour ne pas être déformée, l'image doit avoir un mode d'affichage homothétique.







Remarque : L'icône ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Bouton_rond%20-%20HC%20N%B0001%202.gif) (à droite de l'option "Cadre") permet de configurer l'ombre du cadre du champ. Lorsque l'ombre est activée, il est possible de choisir : 

- le décalage en X et Y de l'ombre, 

- le pourcentage d'opacité, 

- le rayon de flou, 

- la couleur de l'ombre.
