## Propriétés disponibles dans une fenêtre
<a name="proprietes_disponibles_dans_une_fenetre_ELTTEXTE000108"></a>


### Action Bar : Propriétés disponibles dans une fenêtre
<a name="action_bar_proprietes_disponibles_dans_une_fenetre_ELTPARAGRAPHE000017"></a>Les différentes propriétés associées aux "Action Bar" sont les suivantes :



|   |   |
| --- | --- |
| [Accessibilité](../Proprietes/1410090235.md) | La propriété **Accessibilité** permet de définir et de connaître les propriétés d'accessibilité définies sur un champ. |
| [Couleur](../Proprietes/2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :<br><br>- une variable de type Police.<br><br>- un texte d'un champ Libellé ou calculé d'un état.<br><br>- un texte d'un champ d'une fenêtre.<br><br>- un texte d'un champ d'une page.<br><br><br> |
| [CouleurFond](../Proprietes/2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [Extra](../Proprietes/1410089327.md) | La propriété **Extra** permet de :<br><br>- Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page.<br><br>- Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page.<br><br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) En code navigateur, il est uniquement possible de connaître les informations supplémentaires associées à un champ ou une page. |
| [Image](../Proprietes/2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [ImageFond](../Proprietes/2510056.md) | La propriété **ImageFond** permet de connaître et de modifier l'image de fond d'un élément : fenêtre, page, champ ou état. |
| [Note](../Proprietes/2510085.md) | La propriété **Note** permet de :<br><br>- Connaître les notes associées à un champ, à une fenêtre, à une page ou un état.<br><br>- Modifier les notes associées à un champ, à une fenêtre, à une page ou un état.<br><br><br> |
| [Opacité](../Proprietes/2514006.md) | La propriété **Opacité** permet de connaître et définir le pourcentage d'opacité d'une fenêtre ou des champs présents dans une fenêtre ou une page. |
| [Style](../Proprietes/1000021472.md) | La propriété **Style** permet de récupérer ou d'affecter le style complet d'un champ (y compris les surcharges). |
| [TitreNote](../Proprietes/2510121.md) | La propriété **TitreNote** permet de :<br><br>- Connaître le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. <br><br>- Modifier le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état.<br><br><br> |
| [Traitement](../Proprietes/1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [Valeur](../Proprietes/2510130.md) | La propriété **Valeur** permet de :<br><br>- Connaître et modifier la valeur d'un champ d'un état.<br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.<br><br>- Connaître l'identifiant d'un flux. <br><br>- Connaître et modifier la valeur d'un champ ou le titre d'une page.<br><br><br> |
| [ValeurRecherche](../Proprietes/1000021602.md) | La propriété **ValeurRecherche** permet de connaître et modifier la valeur du champ de recherche dans une Action Bar. |
| [Visible](../Proprietes/2510138.md) | La propriété **Visible** permet de :<br><br>- Savoir si un élément est visible.<br><br>- Rendre un élément visible ou invisible.<br><br><br> |
| [VisibleAvecAnimation](../Proprietes/1410087232.md) | La propriété **VisibleAvecAnimation** permet de rendre un champ visible ou invisible en jouant l'animation "Apparition/Disparition". |
| [Volet](../Proprietes/1000021098.md) | La propriété **Volet** permet de : <br><br>- Connaître les volets d'onglet associés à un champ. <br><br>- Définir les volets d'onglet associés à un champ.<br><br><br> |





![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Les propriétés d'un champ Action Bar ne sont pas modifiables par programmation.

### Bouton de changement de vue d'une Action Bar : Propriétés disponibles dans une fenêtre
<a name="bouton_changement_vue_une_action_bar_proprietes_disponibles_dans_une_fenetre_ELTPARAGRAPHE000032"></a>Les différentes propriétés associées au bouton de changement de vue d'une "Action Bar" sont les suivantes :



|   |   |
| --- | --- |
| [FenEditionAutorisée](../Proprietes/1000021850.md) | La propriété **FenEditionAutorisée** permet de connaître et de modifier les manipulations autorisées sur un champ lorsque la fenêtre passe en mode "Modification de l'UI par l'utilisateur final". |
| [FenêtreSource](../Proprietes/2511020.md) | La propriété **FenêtreSource** permet de connaître la source d'une fenêtre interne (c'est-à-dire la fenêtre interne affichée par le champ de type Fenêtre Interne). |
| [Image](../Proprietes/2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [ImageEtat](../Proprietes/2510055.md) | La propriété **ImageEtat** permet de connaître et de modifier le nombre de dessins présents dans :<br><br>- L'image associée à un bouton.<br><br>- L'image du curseur dans un potentiomètre.<br><br>- L'image associée au bouton d'un volet de boîte à outils.<br><br>- L'image associée au bouton d'un volet d'onglet.<br><br>- L'image associée au champ Notation.<br><br>- L'image associée au regroupement d'un champ Ruban.<br><br>- L'image associée à une option de menu.<br><br><br> |
| [Libellé](../Proprietes/2510053.md) | **Dans une base de données**, la propriété **Libellé** permet de :<br><br>- Connaître le libellé associé à une rubrique d'un fichier de données. <br><br>- Connaître le libellé associé à un fichier de données. <br><br>- Connaître et modifier le libellé d'une connexion. <br><br><br><br><br>**Dans un état**, la propriété **Libellé** permet de :<br><br>- Connaître le texte d'un champ Libellé ou Lien.<br><br>- Modifier le texte d'un champ Libellé ou Lien.<br><br><br><br><br>**Dans une fenêtre ou une page**, la propriété **Libellé** permet également de :<br><br>- Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page.<br><br>- Connaître et modifier le libellé d'une option de menu.<br><br>- Connaître et modifier le titre d'une fenêtre ou d'une page.<br><br>- Connaître le contenu d'un champ chemin de navigation.<br><br><br><br><br> |
| [TauxParallaxeHauteur](../Proprietes/1000021921.md) | La propriété **TauxParallaxeHauteur** permet de connaître et d'indiquer à quelle vitesse un champ est réduit lorsque l'ascenseur de la fenêtre, de la fenêtre interne ou de la page se déplace. |
| [TauxParallaxeY](../Proprietes/1000021922.md) | La propriété **TauxParallaxeY** permet de connaître et d'indiquer à quelle vitesse un champ se déplace lorsque l'ascenseur de la fenêtre, de la fenêtre interne ou de la page se déplace. |
| [Traitement](../Proprietes/1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [Visible](../Proprietes/2510138.md) | La propriété **Visible** permet de :<br><br>- Savoir si un élément est visible.<br><br>- Rendre un élément visible ou invisible.<br><br><br> |
| [Volet](../Proprietes/1000021098.md) | La propriété **Volet** permet de : <br><br>- Connaître les volets d'onglet associés à un champ. <br><br>- Définir les volets d'onglet associés à un champ.<br><br><br> |
