## Présentation des fenêtres
<a name="presentation_des_fenetres_ELTTEXTE000194"></a>
Les fenêtres constituent l'interface principale d'une application WINDEV ou WINDEV Mobile. En effet, c'est grâce aux fenêtres que les utilisateurs vont pouvoir consulter et manipuler des informations. Ces informations peuvent être dynamiques et provenir par exemple de fichiers, requêtes ou être statiques, saisies directement dans les champs de la fenêtre.



<a name="NOTE2"></a>
<a name="NOTE2_1"></a>


## Créer une fenêtre
<a name="creer_une_fenetre_ELTTEXTE000218"></a>
Pour créer une fenêtre : 

1. Cliquez sur ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=ico_nouveau.gif) parmi les boutons d'accès rapide : 

	- La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Fenêtre" puis sur "Fenêtre".

	- L'assistant de création d'une fenêtre se lance.




2. Sélectionnez le type de fenêtre à créer :

	- l'onglet "Standard" permet notamment de créer des fenêtres vierges, sans aucun champ.

		- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) L'assistant de création de fenêtres vierges permet de créer des [fenêtres maximisées](../WDChamp/9000113.md) ou [non maximisées](../WDChamp/9000121.md). 

		- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) L'option "Vierge pour Widget" permet de créer une [fenêtre de type Widget](../WDChamp/9000143.md) dans une application Android.

		- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Les assistants de création de fenêtres vierges [pour iPhone](../WDChamp/9000133.md) et [pour iPad](../Editeurs/9000147.md) permettent de définir les principales caractéristiques de la fenêtre. 
						Pour les applications iPad, l'assistant permet de créer des fenêtres simples ou des fenêtres doubles. Il est également possible de créer des [fenêtres non maximisées](../WDChamp/9000148.md). 

		- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) L'option "Vierge non maximisée avec flèche" permet de créer une fenêtre de type "Fenêtre à flèche" ou "Popup" disponible uniquement pour les applications fonctionnant sous iPad. Pour plus de détails, consultez [Fenêtre à flèche](../Editeurs/9000146.md). 

		- ![Apple Watch](https://doc.pcsoft.fr/ext/images/fr/APPLEWATCH.png) L'option "Vierge" permet de créer des fenêtres maximisées ou non maximisées. 




- l'onglet "RAD" permet de créer des fenêtres de type RAD. Ces fenêtres permettent d'afficher et de saisir des données. Ce type de fenêtre peut être basé sur un fichier de données, une requête, ... Pour plus de détails, consultez : 

	- [RAD WINDEV : les différents types de fenêtres disponibles](../Editeurs/2031003.md). 

	- [RAD Mobile : Créez des fenêtres modernes](../Editeurs/9000231.md).




**Pour afficher les caractéristiques de la fenêtre**, sélectionnez l'option "Description" dans le menu contextuel de la fenêtre.
