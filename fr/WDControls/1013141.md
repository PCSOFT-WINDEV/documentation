
## Manipuler un champ Jauge par programmation
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000231"></a>
Un champ Jauge peut être manipulé directement par programmation. Il suffit d'utiliser directement la variable du champ Jauge dans le code.

La variable du champ Jauge :

- correspond au nom du champ Jauge.

- est initialisée avec la position de la jauge.

### Jauge non symétrique (linéaires ou circulaires)
<a name="jauge_non_symetrique_lineaires_circulaires_ELTPARAGRAPHE000025"></a>La progression se fait de la borne minimale à la borne maximale. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=JaugeSimple.GIF)



```wl
POUR I = JAUGE_Jauge1.BorneMin _A_ JAUGE_Jauge1.BorneMax
	JAUGE_Jauge1 = I
FIN
```

### Jauge symétrique
<a name="jauge_symetrique_ELTPARAGRAPHE000038"></a>La progression se fait de la manière suivante :<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=JaugeSymetrique_prog.gif)



```wl
POUR I = 2 * JAUGE_Jauge1.BorneMin - JAUGE_Jauge1.BorneMax _A_ JAUGE_Jauge1.BorneMax
	JAUGE_Jauge1 = I
FIN
```

### Jauge non symétrique linéaire horizontale
<a name="jauge_non_symetrique_lineaire_horizontale_ELTPARAGRAPHE000052"></a>Plusieurs méthodes permettent de faire varier une jauge en WEBDEV : 

- **Méthode 1 : Effectuer le traitement correspondant à l'avancement de la jauge en code serveur**. Le rafraîchissement de la jauge est effectué en code navigateur par la fonction [JaugeActive](../WDLang2/1000019477.md). 
	**Attention** : Ce code ne doit pas être effectué dans un traitement serveur en mode Ajax. 
	Exemple : 
	
	```wl
	// -- Code serveur du bouton BTN_Traitement
	POUR I = JAUGE_SansNom1.BorneMin _A_ JAUGE_SansNom1.BorneMax
		JAUGE_SansNom1 = I
		Multitâche(-1)
	FIN
	```

	
	```wl
	// -- Code navigateur du bouton BTN_Traitement
	JaugeActive(JAUGE_SansNom1, 10)
	```

	![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) **Remarque** : Cette méthode n'est pas disponible en PHP ou en AWP.

- **Méthode 2 (méthode pour les pages AWP) : Effectuer le traitement de la jauge en code navigateur** grâce à la fonction [JaugeExécute](../WDLang2/1000019481.md). Cette fonction appelle régulièrement une procédure WLangage Navigateur qui permet de gérer l'avancement de la jauge. Si un traitement serveur doit être effectué, il est nécessaire d'utiliser la fonction [AjaxExécute](../WDLang2/3055114.md) dans la procédure navigateur. 
	**Attention** : Pour afficher une jauge, un gros traitement serveur ou navigateur doit être découpé en plusieurs traitements. Cette méthode est conseillée pour des petits traitements répétitifs (par exemple, un traitement à réaliser pour un ensemble d'images). 
	Exemple : 
	
	```wl
	// -- Code Navigateur
	JaugeExécute(JAUGE_1, MAJ_Jauge, 0, 100, 10)
	```

	
	```wl
	// Procédure navigateur appelée par la fonction JaugeExécute
	PROCEDURE MAJ_Jauge(nValeur)
	// Code optionnel permettant de réaliser un traitement serveur
	AJAXExécute(TraitementServeur)
	```

	![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) **Remarque** : Cette méthode est disponible en PHP et en AWP.




**Remarque** : Plusieurs fonctions permettent de manipuler une jauge dans une page WEBDEV. Pour plus de détails, consultez [Fonctions de gestion des jauges](../WDLang2/1000019541.md).

## Récupérer la position de la jauge
<a name="recuperer_position_jauge_ELTTEXTE000291"></a>
Pour récupérer la position d'une jauge, utilisez la syntaxe suivante : 

```txt
<Position> = <Champ Jauge>
```


&lt;Position&gt; est une variable de type entier. 

**Remarque** : Il est également possible d'utiliser la propriété [Valeur](../Proprietes/2510130.md).



<a name="NOTE4"></a>
<a name="NOTE4_1"></a>


## Modifier la position de la jauge
<a name="modifier_position_jauge_ELTTEXTE000315"></a>
Pour modifier la position d'une jauge, utilisez la syntaxe suivante : 

```txt
<Champ Jauge> = <Valeur>
```


&lt;Valeur&gt; est une valeur comprise entre la valeur minimale et la valeur maximale de la jauge. Ces valeurs ont été décrites dans la fenêtre de description du champ ou par programmation, grâce aux propriétés [BorneMin](../Proprietes/2510008.md) et [BorneMax](../Proprietes/2510009.md).

**Remarque** : Il est également possible d'utiliser la propriété [Valeur](../Proprietes/2510130.md).

## Propriétés spécifiques à la gestion d'un champ Jauge
<a name="proprietes_specifiques_gestion_champ_jauge_ELTTEXTE000339"></a>
Les propriétés suivantes sont spécifiques à la gestion des caractéristiques d'un champ Jauge par programmation.


|   |   |
| --- | --- |
| [BorneMax](../Proprietes/2510009.md) | Permet de connaître et de modifier la borne maximale d'un champ Jauge. |
| [BorneMin](../Proprietes/2510008.md) | Permet de connaître et de modifier la borne minimale d'un champ Jauge. |
| [CadrageHorizontal](../Proprietes/2510023.md) | Permet de connaître et de modifier le cadrage horizontal du pourcentage de progression affiché dans le champ Jauge. |
| [Image](../Proprietes/2510034.md) | Permet de connaître et de modifier l'image de progression d'un champ Jauge. |
| [ImageFond](../Proprietes/2510056.md) | Permet de connaître et de modifier l'image de fond d'un champ Jauge. |
| [TexteJauge](../Proprietes/1000017246.md) | Permet de connaître ou de modifier le texte affiché dans un champ Jauge (au lieu du pourcentage). |
| [Vertical](../Proprietes/2510133.md) | Permet de savoir si  le champ Jauge correspond à une jauge horizontale ou verticale. |


Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Jauge, consultez [Propriétés associées au champ Jauge](../WDChamp/1013137.md).
