


## Programmation des attributs des zones répétées
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000086"></a>
Il est possible de manipuler tous les attributs des champs Zone répétée par programmation.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) En code navigateur, seuls les types d'attributs suivants sont manipulables : 



|   |   |
| --- | --- |
| Attribut sur un interrupteur | Il est uniquement possible de manipuler un attribut sur la valeur de l'interrupteur (lecture et modification). |
| Attribut sur un libellé | Aucune manipulation possible par programmation. |
| Attribut sur un lien | Aucune manipulation possible par programmation. |
| Attribut sur un sélecteur | Il est uniquement possible de manipuler un attribut sur la valeur du sélecteur (lecture et modification). |
| Attribut sur une image ou une image cliquable | Il est uniquement possible de manipuler un attribut sur la valeur de l'image associée au champ (lecture et modification). |
