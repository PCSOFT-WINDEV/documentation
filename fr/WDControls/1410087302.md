## Présentation du champ Editeur de code
<a name="presentation_champ_editeur_code_ELTTEXTE000218"></a>
Le champ Editeur de code permet à un utilisateur de l'application ou du site de saisir du code WLangage.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Il est ainsi possible d'utiliser ce type de champ dans une application : 

- pour que le développeur puisse faire des tests, 

- pour qu'un utilisateur final averti saisisse par exemple des formules, lance des scripts, etc. 

- pour effectuer une personnalisation spécifique à un client.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Dans un site WEBDEV, il est possible de saisir du code WLangage pour le colorer. Le code saisi n'est pas exécutable nativement. En effet, exécuter un code WLangage saisi par l'internaute entraîne nécessairement une faille de sécurité. 

ATTENTION : Ce champ Editeur de code est indépendant : il ne connaît ni l'analyse liée au projet, ni les fichiers de données associés. Pour accéder aux données, il est nécessaire d'utiliser par exemple la fonction [HDéclareExterne](../WDLang4/3044204.md). Exemple : 

```wl
SI PAS HDéclareExterne(fRepDonnées() + fSep() + "CLIENTS.FIC", "CLIENTS") ALORS
	Erreur(HErreurInfo())
	RETOUR
FIN
HLitRecherchePremier(CLIENTS,"CODECLI","0018300")
Info(CLIENTS.NOM1)
```

## Créer un champ Editeur de code
<a name="creer_champ_editeur_code_ELTTEXTE000242"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) **Pour créer un champ de type Editeur de code** :

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Bureautique" puis cliquez sur "Editeur de code". 

2. Cliquez dans la fenêtre à la position où le champ doit être créé.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Pour créer un champ de type Editeur de code** :

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Avancé" puis cliquez sur "Editeur de code". 

2. Cliquez dans la page à la position où le champ doit être créé.




Remarque : Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z : le champ retrouvera sa taille par défaut.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Caractéristiques du champ Editeur de code
<a name="caracteristiques_champ_editeur_code_ELTTEXTE000270"></a>
Le champ Editeur de code possède une barre d'outils qui permet d'accéder aux principales fonctionnalités du champ : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001.gif)


De nombreux raccourcis clavier sont également disponibles : 

| Raccourci | Effet |
| --- | --- |
| **Ctrl + A** | Sélectionne le contenu du champ. |
| **Ctrl + C** | Copie la sélection dans le presse-papiers. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%204.gif) |
| **Ctrl + D** | Duplique la ligne en cours. |
| **Ctrl + O** | Ouvre un fichier contenant un code WLangage à afficher dans le champ. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%201.gif) |
| **Ctrl + S** | Sauvegarde le contenu du champ Editeur de code dans un fichier. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%202.gif) |
| **Ctrl + V** | Colle le contenu du presse-papiers. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%205.gif) |
| **Ctrl + X** | Coupe la sélection et la place dans le presse-papiers. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%203.gif) |
| **Ctrl + molette de la souris** | Change le zoom. |
| **Ctrl + Z** | Annule la dernière action. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%208.gif) |
| **Ctrl + Y** | Refait la dernière action. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%209.gif) |
| **Ctrl + /** (du pavé numérique) | Met en commentaire. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%206.gif) |
| **Ctrl + Maj + /** (du pavé numérique) | Supprime le commentaire. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%207.gif) |
| **F9** | Exécute le code. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%2011.gif) |
| **F1** | Lance l'aide sur le mot en cours. ![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Champ_Editeur_de_code%20-%20HC%20N%B0001%2012.gif) |
