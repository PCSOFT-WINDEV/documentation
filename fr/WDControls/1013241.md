## Présentation du champ Potentiomètre
<a name="presentation_champ_potentiometre_ELTTEXTE000170"></a>


### Champ d'une fenêtre
<a name="champ_une_fenetre_ELTPARAGRAPHE000011"></a>Un potentiomètre est un champ qui permet de sélectionner une valeur entre deux bornes. Son fonctionnement ressemble à celui d'un ascenseur. La valeur courante est identifiée par un curseur que l'utilisateur déplace à l'aide de la souris (ou de la roulette de la souris).

Des graduations visuelles peuvent être affichées. Ces graduations ne sont pas magnétiques : le curseur du potentiomètre est déplacé unité par unité.
Il est possible de créer :

- des potentiomètres standard<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Potentiometre.gif)


- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) des potentiomètres rotatifs<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=PotRotatif.gif)







## Créer un champ Potentiomètre
<a name="creer_champ_potentiometre_ELTTEXTE000194"></a>


### Créer un champ de type Potentiomètre
<a name="creer_champ_type_potentiometre_ELTPARAGRAPHE000040"></a>Pour créer un champ de type Potentiomètre : 

1. Sous le volet "Création", dans le groupe "Champs graphiques" : 

	- ![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) déroulez "Potentiomètre" et sélectionnez le type de potentiomètre à créer :
			<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=ico_pot3.gif)


	- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) cliquez sur "Potentiomètre".

2. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.




Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Remarque : WEBDEV propose également un champ Potentiomètre. Pour plus de détails, consultez [Champ Potentiomètre en Web](../WDChamp/1000027001.md).

### Modifier la valeur du potentiomètre en exécution à l'aide de la roulette de la souris
<a name="modifier_valeur_potentiometre_execution_aide_roulette_souris_ELTPARAGRAPHE000082"></a>L'utilisateur peut modifier directement la valeur du potentiomètre à l'aide de la roulette de la souris : le déplacement du curseur sera effectué selon le pas (les graduations) défini pour le potentiomètre. 
<a name="NOTE2_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) 

### Permuter
<a name="permuter_ELTPARAGRAPHE000091"></a>WINDEV permet de transformer un champ Potentiomètre standard en un champ Potentiomètre rotatif et inversement : 

1. Sélectionnez le champ à transformer. 

2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez "Potentiomètre / Potentiomètre Rotatif".



<a name="NOTE2_3"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) 

### Caractéristiques du champ Potentiomètre
<a name="caracteristiques_champ_potentiometre_ELTPARAGRAPHE000115"></a>

- Le curseur du potentiomètre est obligatoirement une image. 

- Il est possible d'utiliser un potentiomètre natif (option "Potentiomètre natif" présente dans l'onglet "Détail" de la fenêtre de description du champ). Dans ce cas :

	- le potentiomètre s'adaptera automatiquement au look du système. Les options graphiques définies pour le champ Potentiomètre (graduation, image du curseur, ...) ne seront pas prises en compte. Les propriétés permettant de gérer les images associées au champ ne seront pas prises en compte. 

	- le potentiomètre ne pourra pas être vertical. Seuls les potentiomètres horizontaux sont gérés.
