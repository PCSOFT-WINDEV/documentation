## Mode de sélection
<a name="mode_selection_ELTTEXTE000152"></a>
L'onglet "UI" de la fenêtre de description du champ Liste permet de définir le mode de sélection dans le champ. 

Les différents modes de sélection disponibles sont : 

- **Sélection simple** : Le bandeau de sélection s'affiche sur la ligne sélectionnée. Le code de sélection de ligne est exécuté.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Mode de sélection Android/iOS (masquer le bandeau après la sélection)** : Cette option permet de masquer le bandeau de sélection après la sélection. Cela permet d'obtenir le fonctionnement standard sur ces plateformes : le bandeau apparaît uniquement lors de l'appui sur la ligne. Le code de sélection de ligne est ensuite exécuté. 

- **Sélection multiple** : Le bandeau de sélection s'affiche sur les lignes sélectionnées. Pour sélectionner plusieurs lignes, il suffit de maintenir la touche Maj ou Ctrl enfoncée. A chaque ligne sélectionnée, le code de sélection d'une ligne est exécuté.

## Déplacement
<a name="deplacement_ELTTEXTE000176"></a>
L'onglet "Détail" de la fenêtre de description d'un champ Liste permet notamment de définir les options de déplacement de la liste. Il est possible de définir : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **L'affichage de l'ascenseur horizontal / vertical**. Il peut être :

	- automatique : l'ascenseur sera affiché uniquement en cas de besoin.

	- toujours visible : l'ascenseur sera toujours affiché.

	- jamais visible : l'ascenseur ne sera jamais affiché.




- **Le mode de déplacement** : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Scroll au pixel : selon la position de l'ascenseur, une ligne peut ne pas être affichée complètement.

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Scroll au doigt : permet de manipuler l'ascenseur par un écran tactile.

	- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Scroll rapide : le déplacement dans le champ s'effectue plus rapidement à l'aide d'une cage d'ascenseur spécifique présente sur le côté du champ.
			Si l'option "Avec indexation alphabétique" est sélectionnée, une réglette alphabétique permettra à l'utilisateur de se déplacer rapidement sur les lignes dont l'élément commence par la lettre choisie.
			Conditions d'utilisation :

		- Le déplacement rapide est disponible uniquement sur les champs Liste par programmation ou les champs Liste fichier chargé en mémoire.

		- Le déplacement rapide est disponible uniquement sur les listes triées alphabétiquement.
