
## TypeEstNullable (Fonction)

***En anglais : TypeIsNullable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si un élément est nullable. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCEDURE UneProcédure(UnParamètre)
SI TypeEstNullable(UnParamètre) ALORS
	// ...
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = TypeEstNullable(<Expression>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'élément passé en paramètre est nullable, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Expression> : (Type correspondant)`**

Expression à manipuler.
