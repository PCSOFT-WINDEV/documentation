


## SysDécrypte (Fonction)

***En anglais : SysDecrypt***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Décrypte des données en utilisant les informations d'identification de l'utilisateur Windows. Ces données ont été précédemment cryptées par la fonction [SysCrypte](../WDLang1/1410091090.md). 

Les données peuvent être décryptées uniquement par l'utilisateur ayant crypté les données et sur la machine où elles ont été cryptées.
Les données cryptées peuvent par exemple provenir d'un fichier sauvegardé par le même utilisateur de la même machine que l'application qui décrypte les données.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Décryptage des données
MonBuffer est un Buffer = SysDécrypte(BufferCrypté)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SysDécrypte(<Buffer à décrypter> [, <Mot de passe application>])`
---

**`<Résultat> : (Chaîne de caractères)`**



- Buffer contenant les données décryptées.

- Buffer vide en cas d'erreur. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Buffer à décrypter> : (Buffer)`**

Buffer à décrypter. Ce buffer a été crypté avec la fonction [SysCrypte](../WDLang1/1410091090.md). 

**`<Mot de passe application> : (Buffer optionnel)`**

Buffer contenant le mot de passe ayant permis d'appliquer une clé supplémentaire au cryptage des données (clé de salage). Ce buffer a été utilisé avec la fonction [SysCrypte](../WDLang1/1410091090.md). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si l'utilisateur change le mot de passe de connexion à la machine entre le cryptage et le décryptage, il pourra toujours décrypter les données.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Les informations d'identification utilisées sont celles du compte Windows utilisé pour l'exécution des sites et Webservices (paramétrées pour le compte de l'administrateur du site dans le gestionnaire de comptes du serveur WEBDEV).
	Tous les internautes des sites administrés par le même compte du serveur WEBDEV partagent le même utilisateur Windows.
	Par conséquent, si un internaute d'un site crypte des données, ces données pourront être décryptées par un internaute de ce site ou d'un autre site administré par le même compte (à condition que l'internaute ait accès à ces données).
