


## PileInfo (Fonction)

***En anglais : StackInfo***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère les caractéristiques d'une pile : types des éléments et nombre d'éléments.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Pile dont les éléments sont des instances de MaClasse
MaPile est une Pile de MaClasse
// Récupère la définition du type des éléments
MaDéfinition est une Définition 
MaDéfinition = PileInfo(MaPile, tiDéfinitionElément)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = PileInfo(<Pile WLangage> , <Information>)`
---

**`<Résultat> : (Variant)`**

Information demandée. 

**`<Pile WLangage> : (Pile)`**

Nom de la variable de type [Pile](../WDLang1/1514022.md) à manipuler.

**`<Information> : (Constante de type Entier)`**

Information à récupérer :


|   |   |
| --- | --- |
| *tiDéfinitionElément* | &lt;Résultat&gt; est une variable de type [Définition](../WDLang1/1000019540.md) et contient la définition du type des éléments.<br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Cette constante n'est pas disponible. |
| *tiNombreTotal* | &lt;Résultat&gt; est une variable de type Entier et contient le nombre total d'éléments dans la pile. |
| *tiTypeElément* | &lt;Résultat&gt; est une variable de type Entier et contient le type des éléments de la pile. Ce résultat est compatible avec la fonction [TypeVar](../WDLang1/3013056.md).<br><br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Cette constante n'est pas disponible. |
