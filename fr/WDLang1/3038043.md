
## TitreSuivant (Fonction)

***En anglais : NextTitle***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie le titre de la prochaine fenêtre à ouvrir.

**Rappel** : Par défaut, le titre de la fenêtre est celui défini sous l'éditeur.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Modifie le titre de la prochaine boîte de dialogue ouverte.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Remarque : Exécutée dans le code d'initialisation du projet, la fonction **TitreSuivant** permet de mettre à jour le message de chargement affiché sur le splash screen.

<a name="sample_code"></a>

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png)

## Remarques




### Titre des boîtes de dialogues
<a name="titre_des_boites_dialogues_ELTPARAGRAPHE000083"></a>Par défaut, les fenêtres ouvertes par les fonctions [Avertissement](../WDLang1/3021009.md), [Confirmer](../WDLang1/3021007.md), [Dialogue](../WDLang1/3021015.md), [Erreur](../WDLang1/3021013.md), [ErreurInfo](../WDLang1/3013008.md), [Info](../WDLang1/3021011.md), [OKAnnuler](../WDLang1/3021004.md) ou [OuiNon](../WDLang1/3021005.md) ont le même titre que la fenêtre précédente. La fonction **TitreSuivant** permet de modifier ce titre. 

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) La fonction **TitreSuivant** permet de modifier le titre des boites de dialogue ouvertes par les fonctions [Confirmer](../WDLang1/3021007.md), [OKAnnuler](../WDLang1/3021004.md) ou [OuiNon](../WDLang1/3021005.md). Il n'est pas possible de modifier le titre des boîtes de dialogue affichées par les fonctions [Erreur](../WDLang1/3021013.md) et [Info](../WDLang1/3021011.md).  
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 

### Présentation du titre
<a name="presentation_titre_ELTPARAGRAPHE000141"></a>Les [fonctions de dessin](../WDLang1/3029033.md) dans les listes (fonctions commençant par "g") permettent de :

- ajouter des dessins au titre,

- modifier la mise en forme d'un titre (couleur de fond, couleur de texte, etc.) avec les fonctions [gFond](../WDLang1/3029037.md) et [gStylo](../WDLang1/3029039.md).




Par exemple : pour modifier la couleur de texte et la couleur de fond d'un titre :


```wl
TitreSuivant(EOT + gFond(RVB(0, 255, 255)) + gStylo(RVB(255, 0, 0)) + "Test de couleur")
```


**Cas particulier sous Windows Vista et supérieur** : Les fenêtres utilisant le look "Aero system" ne peuvent pas avoir de titre graphique : la partie graphique est ignorée. Si "Aero" n'est pas actif, le titre graphique sera affiché normalement.

### Fenêtre iconisée
<a name="fenetre_iconisee_ELTPARAGRAPHE000168"></a>Quand une fenêtre est iconisée, le titre de cette fenêtre apparaît à côté de l'icône dans la barre de tâches.
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) 

### Cas particulier sous Android et iOS : Utilisation de la fonction Sablier
<a name="cas_particulier_sous_android_ios_utilisation_fonction_sablier_ELTPARAGRAPHE000177"></a>L'utilisation de la fonction [Sablier](../WDLang1/3071011.md) provoque l'affichage d'une jauge infinie. L'interface de l'application n'est plus manipulable par l'utilisateur durant le temps d'affichage du sablier. 

Par défaut, aucun message n'est affiché à côté de la jauge. 

Il est possible de réaliser les actions suivantes : 

- Pour afficher un message, utilisez la fonction **TitreSuivant**. 

- Pour modifier le message alors que la jauge est affichée, il suffit de ré-exécuter les fonctions **TitreSuivant** puis [Sablier](../WDLang1/3071011.md). 

- Pour masquer la jauge, utilisez la fonction [Sablier](../WDLang1/3071011.md) avec le paramètre &lt;Activé&gt; = Faux autant de fois que la fonction [Sablier](../WDLang1/3071011.md) a été utilisée avec le paramètre &lt;Activé&gt; = Vrai.


**Remarque** : Lors de l'exécution de traitements longs, il est conseillé d'ajouter des appels à la fonction [Multitâche](../WDLang1/3015004.md) dans le code afin de laisser le temps à la jauge de rafraîchir son affichage.


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Exemple :


```wl
// Cet exemple montre une copie de plusieurs fichiers de données HFSQL 
// depuis un serveur HFSQL vers un répertoire local.
// Dans cet exemple, on affiche une information pour chaque copie. 
// sConnexion est une connexion définie par programmation.

gsMonCheminHFLocal est une chaîne = SysRepCarteStockage() + fSep() + "MonApplication Data" + fSep() 
sMotDePasse est une chaîne = "Mon mot de passe"

TitreSuivant("Copie du fichier Catégorie")
Sablier(Vrai)
SI PAS HCopieFichier("", ...
	gsMonCheminHFLocal + Catégorie..Nom + ".fic", sConnexion, Catégorie..Nom + ".fic", ...
	hCopieIndex, "", sMotDePasse) ALORS 
		Erreur("Erreur pendant la copie du fichier " + Catégorie..Nom + " en local")
FIN

TitreSuivant("Copie du fichier CompteBancaire")
Sablier(Vrai) 
SI PAS HCopieFichier("", gsMonCheminHFLocal + CompteBancaire..Nom + ".fic", ...
	sConnexion, CompteBancaire..Nom + ".fic", hCopieIndex, "", sMotDePasse) ALORS 
		Erreur("Erreur pendant la copie du fichier " + Catégorie..Nom + " en local")
FIN

TitreSuivant("Copie du fichier Opérations")
Sablier(Vrai)
SI PAS HCopieFichier("", gsMonCheminHFLocal + Operations..Nom + ".fic", ...
	sConnexion, Operations..Nom + ".fic", hCopieIndex, "", sMotDePasse) ALORS 
		Erreur("Erreur pendant la copie du fichier " + Catégorie..Nom + " en local")
FIN

TitreSuivant("Copie du fichier SousCatégorie")
Sablier(Vrai)
SI PAS HCopieFichier("", gsMonCheminHFLocal + SousCatégorie..Nom + ".fic", ...
	sConnexion, SousCatégorie..Nom + ".fic", hCopieIndex, "", sMotDePasse) ALORS 
		Erreur("Erreur pendant la copie du fichier " + Catégorie..Nom + " en local")
FIN

TitreSuivant("Copie du fichier Utilisateur")
Sablier(Vrai)
SI PAS HCopieFichier("", gsMonCheminHFLocal + Utilisateur..Nom + ".fic", ...
	sConnexion, Utilisateur..Nom + ".fic", hCopieIndex, "", sMotDePasse) ALORS 
		Erreur("Erreur pendant la copie du fichier " + Catégorie..Nom + " en local")
FIN
// Fermeture des sabliers 
Sablier(Faux)
Sablier(Faux)
Sablier(Faux)
Sablier(Faux)
Sablier(Faux)

Info("La copie des fichiers sur le Smartphone est maintenant terminée.")
```
