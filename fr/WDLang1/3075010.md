


## TableauSupprimeTout (Fonction)

***En anglais : ArrayDeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime tous les éléments :

- d'un tableau WLangage à une dimension ou deux dimensions.

- d'un tableau associatif.

- d'une propriété de type tableau d'un type avancé (tableau des événements de gglAgenda, etc.).

- d'une file WLangage.

- d'une pile WLangage.  

- d'une liste WLangage. 




**Remarques** : 

- Cette fonction est équivalente à la fonction [SupprimeTout](../WDLang1/1000017357.md).

- ![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette fonction est utilisable uniquement avec les variables de type Tableau et Tableau associatif.











<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonTableau est un tableau de 2 chaînes
MonTableau[1] = "WINDEV"
MonTableau[2] = "WEBDEV"
// Suppression de tous les éléments
TableauSupprimeTout(MonTableau)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`TableauSupprimeTout(<Variable WLangage>)`
---

**`<Variable WLangage> : (Tableau, File, Pile ou Liste)`**

Nom de la variable WLangage à manipuler. Cette variable peut être :

- de type Tableau. Ce tableau doit être un tableau à une dimension ou deux dimensions.

- de type File.

- de type Pile.

- de type Liste.


![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Seules les variables de type Tableau peuvent être manipulées. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Suppression des éléments
<a name="suppression_des_elements_ELTPARAGRAPHE000166"></a>

- **Tableau à une dimension** : la taille du tableau passe à 0. Le tableau n'est pas libéré : il est possible de faire de nouveaux ajouts sans ré-allouer le tableau.

- **Tableau à deux dimensions** : seules les lignes du tableau sont supprimées. Les colonnes sont conservées. Il est donc possible d'utiliser la fonction [TableauAjouteLigne](../WDLang1/3075013.md) après la fonction **TableauSupprimeTout**.

- **Tableau associatif** : tous les éléments du tableau sont supprimés.

- **File** : tous les éléments de la file sont supprimés.

- **Pile** : tous les éléments de la pile sont supprimés.

- **Liste** : tous les éléments de la liste sont supprimés.




Remarque : Pour remettre à 0 (ou "") les éléments du tableau sans changer la taille du tableau, utilisez la fonction [VariableRAZ](../WDLang1/3013069.md).

![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La suppression d'éléments pour les variables de type File, Pile et Liste n'est pas disponible.
<a name="NOTE0_2"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000195"></a>Cette fonction ne peut pas être utilisée avec les tableaux fixes.
