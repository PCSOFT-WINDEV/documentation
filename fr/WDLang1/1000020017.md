
## ReconnaissanceVocaleSupprimeCommande (Fonction)

***En anglais : SpeechRecognitionDeleteCommand***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime une commande vocale précédemment ajoutée par la fonction [ReconnaissanceVocaleAjouteCommande](../WDLang1/1000020014.md).

**Remarques** : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) Un moteur de reconnaissance vocale doit être installé sur le poste d'exécution. Windows Vista est fourni par défaut avec un moteur de reconnaissance vocale. Pour les autres systèmes, il est nécessaire d'installer le logiciel "Dragon Naturally Speaking" (tests réalisés avec la version 9 "Preferred" ou "standard").

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Le service de reconnaissance vocale doit être installé sur le téléphone. Le déclenchement de la reconnaissance des commandes vocales doit être effectué grâce à la fonction [ReconnaissanceVocaleDéclenche](../WDLang1/1000020013.md). 

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette fonction est utilisable uniquement à partir de iOS 10. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Lance la procédure "Proc_Anim_Fenêtre" si la commande vocale est reconnue
IDVoix1 est un entier
IDVoix1 = ReconnaissanceVocaleAjouteCommande("Proc_Anim_Fenêtre", "Animer la fenêtre")
...
// Supprime la commande vocale
ReconnaissanceVocaleSupprimeCommande(IDVoix1)
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`ReconnaissanceVocaleSupprimeCommande(<Identifiant de la commande vocale>)`
---

**`<Identifiant de la commande vocale> : (Entier)`**

Identifiant de la commande vocale à supprimer. Cet identifiant a été donné par la fonction [ReconnaissanceVocaleAjouteCommande](../WDLang1/1000020014.md).
