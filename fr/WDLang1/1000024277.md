


## &lt;Table&gt;.Occurrence (Fonction)

***En anglais : &lt;Table&gt;.Count***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie : 

- soit le nombre de colonnes présentes dans un champ Table ou Table hiérarchique.

- soit le nombre de lignes présentes dans un champ Table ou Table hiérarchique. 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Nombre de lignes présentes dans le champ "TABLE_Produit"
ResNombreLigne = TABLE_Produit.Occurrence()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Table>.Occurrence([<Ligne/Colonne>])`
---

**`<Résultat> : (Entier)`**

Nombre de lignes ou de colonnes présentes dans le champ spécifié.

**`<Champ Table> : (Nom de champ)`**

Nom du champ à manipuler. Ce champ peut correspondre à : 

- un champ Table.

- un champ Table hiérarchique.




**`<Ligne/Colonne> : (Constante de type Entier (optionnel))`**

Permet d'indiquer le type du résultat renvoyé : 

- les constantes *toAffichée*, *toTotal* et *toVisible* permettent d'obtenir un nombre de lignes. 

- la constante *toColonne* permet d'obtenir le nombre de colonnes du champ.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000338"></a>La fonction **&lt;Table&gt;.Occurrence** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection. 
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode classique.


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX", les champs Table en mode "Serveur" et les champs Table hiérarchique. ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur".![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Le champ Table hiérarchique n'est pas disponible.

### Équivalence fonction &lt;Table&gt;.Occurrence et propriété Taille
<a name="equivalence_fonction_docparampagetitleshort_propriete_taille_ELTPARAGRAPHE000378"></a>La fonction **&lt;Table&gt;.Occurrence** et la propriété [Taille](../Proprietes/2510125.md) sont équivalentes :

```txt
ResNbColonne = <Champ Table>.Occurrence(toColonne)

ResNbColonne = <Champ Table>.Taille
```

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 

### Cas des champs Table en mode "Serveur + AJAX"
<a name="cas_des_champs_table_mode_serveur_ajax_ELTPARAGRAPHE000406"></a>La valeur renvoyée par la fonction **&lt;Table&gt;.Occurrence** correspond toujours au nombre de lignes disponible sur le serveur (dans le cas des champs Table fichier). Cette valeur ne correspond pas forcément aux informations visualisées dans le champ Table sous le navigateur. En effet, les changements réalisés par l'utilisateur sur un champ Table en mode "Serveur + AJAX" sont réalisés uniquement sur le navigateur.

Exemple :

```wl
TABLE_Table_Ajax.Occurrence(toAffichée)
// Renvoie 10 au lieu de 9
```
