
## SysEtatAlimentation

***En anglais : SysPowerStatus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de connaître diverses informations sur la batterie (principale ou de secours) de l'appareil sur lequel l'application est exécutée.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Etat de la batterie principale ?
Info("La batterie est chargée à : " + SysEtatAlimentation(PourcentageCharge) + " %")
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = SysEtatAlimentation(<Type d'information> [, <Batterie>])`
---

**`<Résultat> : (Entier ou booléen selon le type d'information demandé)`**



- Information demandée, 

- Chaîne vide ("") si l'information demandée n'est pas disponible.




**`<Type d'information> : (Constante de type entier)`**

Indique le type d'information à rechercher : 



|   |   |
| --- | --- |
| *EnRecharge* | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si la batterie est en charge,<br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.<br><br><br> |
| *NiveauCharge* | Niveau de charge de la batterie :<br><br>- 0 : batterie inexistante.<br><br>- 1 : niveau haut.<br><br>- 2 : niveau bas.<br><br>- 3 : niveau critique.<br><br><br> |
| *PourcentageCharge* | Pourcentage de charge de la batterie. |
| *SurSecteur* | <br><br>- <u><u><u><u>Vrai</u></u></u></u> si l'appareil est branché sur le secteur,<br><br>- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.<br><br><br> |



**`<Batterie> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (par défaut) pour obtenir des informations sur la batterie principale de l'appareil, 

- <u><u><u><u>Faux</u></u></u></u> pour obtenir des informations sur la batterie de secours de l'appareil.  


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Il n'est pas possible de récupérer des informations sur la batterie de secours. Si le paramètre &lt;Batterie&gt; est à Faux, &lt;Résultat&gt; correspondra à une chaîne vide (""). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques




### Batterie
<a name="batterie_ELTPARAGRAPHE000088"></a>

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Il n'est pas possible de récupérer des informations sur la batterie de secours.

- En mode émulateur, les informations retournées ne sont pas valides.





<a name="NOTE0_2"></a>




### Gestion des erreurs
<a name="gestion_des_erreurs_ELTPARAGRAPHE000102"></a>**Attention** : La fonction **SysEtatAlimentation** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.
