


## &lt;Agenda&gt;.SelectPlus (Fonction)

***En anglais : &lt;Organizer&gt;.SelectPlus***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Sélectionne un rendez-vous dans un champ Agenda.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Sélectionne le premier rendez-vous du champ Agenda
AGD_MonAgenda.SelectPlus(1)
// Récupère la description de ce rendez-vous
tabRendezVous est un tableau de RendezVous
tabRendezVous = AGD_MonAgenda.ListeRendezVous(agRdvSélectionné)
```
<a name="Exemple2"></a>

```wl
// Ajoute un rendez-vous dans un champ Agenda puis sélectionne ce rendez-vous
IndiceAjout est un entier
gMonRendezVous est un RendezVous
IndiceAjout = AGD_MonAgenda.AjouteRendezVous(gMonRendezVous)
AGD_MonAgenda.SelectPlus(IndiceAjout)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Sélectionner un rendez-vous identifié par son indice

`<Champ Agenda>.SelectPlus(<Indice du rendez-vous>)`
---

**`<Champ Agenda> : (Nom de champ)`**

Nom du champ Agenda à manipuler. Ce champ peut correspondre : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) au champ Agenda d'une fenêtre.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) au champ Agenda d'une page.




**`<Indice du rendez-vous> : (Entier)`**

Indice du rendez-vous à sélectionner. Les indices des rendez-vous commencent à 1.


<a name="SYNTAXE2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) 
### Sélectionner un rendez-vous identifié par une variable de type RendezVous

`<Champ Agenda>.SelectPlus(<Rendez-vous à sélectionner>)`
---

**`<Champ Agenda> : (Nom de champ)`**

Nom du champ Agenda à manipuler dans une fenêtre.

**`<Rendez-vous à sélectionner> : (Variable de type RendezVous)`**

Nom de la variable de type [RendezVous](../WDLang1/1000019244.md) correspondant au rendez-vous à sélectionner.
