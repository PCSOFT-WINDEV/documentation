


## TestVérifieFaux (Fonction)

***En anglais : TestCheckFalse***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie si une expression est fausse en programmation défensive et en mode test automatique. 

Remarque : Cette fonction est équivalente à la fonction [dbgVérifieFaux](../WDLang1/1000019781.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Le tableau ne devrait pas être vide
TestVérifieFaux(TableauElément.Vide)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`TestVérifieFaux(<Expression> [, <Commentaires> [, <Paramètre 1> [... [, <Paramètre N>]]]])`
---

**`<Expression> : (Chaîne de caractères)`**

Expression quelconque à vérifier. 

**`<Commentaires> : (Chaîne de caractères)`**

Chaîne de caractères au format défini par la fonction [ChaîneConstruit](../WDLang1/3024006.md). 

**`<Paramètre 1> : (Tout type)`**

Premier paramètre attendu par le paramètre &lt;Commentaires&gt;.



**`<Paramètre N> : (Tout type)`**

Dernier paramètre attendu par le paramètre &lt;Commentaires&gt;.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Fonctionnement
<a name="fonctionnement_ELTPARAGRAPHE000045"></a>Lorsque l'expression ne vaut pas <u><u><u><u>Faux</u></u></u></u> :

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) en mode test automatique, une erreur est ajoutée dans le compte-rendu du test (équivalent de la fonction [TestEcritRésultat](../WDLang1/1000013001.md)).

- en mode test manuel, une assertion est affichée (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).

- en mode exécution, une assertion est affichée si les assertions ont été activées (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).




En exécution d'une application, si les assertions ne sont pas activées, l'expression n'est pas évaluée.

La fonction [dbgSurErreur](../WDLang1/1000020722.md) permet de lancer automatiquement une procédure WLangage permettant de récupérer le commentaire lié à l'erreur. 
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Gestion des assertions
<a name="gestion_des_assertions_ELTPARAGRAPHE000078"></a>Les messages de la fonction **TestVérifieFaux** seront écrits dans le log ADB (au niveau "Assert"). Pour plus de détails, consultez [Gestion des logs ADB](../Editeurs/9000108.md).
