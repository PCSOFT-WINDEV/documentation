
## RAZ (Fonction)

***En anglais : Reset***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ré-initialise :

- soit tous les champs de la fenêtre ou de la page en cours (y compris les groupes de champs, les superchamps, les popups et les fenêtres internes).

- soit les champs présents dans un groupe de champs, un superchamp, une popup, une fenêtre interne ou une page interne.




![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Réinitialise tous les champs à leur valeur initiale. La valeur initiale des champs correspond à la valeur des champs lors du dernier affichage de la page sur le navigateur (premier affichage de la page ou affichage lors d'une réactualisation, ...).

## Syntaxe

### Ré-initialiser tous les champs de la fenêtre ou de la page en cours

`RAZ([<Gestion des champs spéciaux>])`
---

**`<Gestion des champs spéciaux> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> :

	- les champs de saisie et les champs Libellé sont ré-initialisés avec leur valeur initiale,

	- les champs Liste, Combo, Table et Zone répétée (fichier ou mémoire) ne sont ni vidés ni ré-initialisés. Ils conservent leur contenu actuel.




- <u><u><u><u>Faux</u></u></u></u> (par défaut) :

	- les champs de saisie et les champs Libellé sont ré-initialisés avec leur valeur initiale,

	- les champs Liste, Combo, Table et Zone répétée "mémoire" sont vidés et ré-initialisés avec leur contenu initial,

	- les champs Liste, Combo, Table et Zone répétée "fichier" sont uniquement ré-initialisés (ils ne sont pas vidés).







![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre n'est pas disponible : tous les champs de la page sont ré-initialisés à leur valeur initiale. La valeur initiale des champs correspond à la valeur des champs lors du dernier affichage de la page sur le navigateur (premier affichage de la page, ou affichage lors d'une réactualisation, ...).

### Ré-initialiser tous les champs d'un groupe de champs, d'un superchamp, d'une fenêtre interne ou d'une page interne

`RAZ(<Nom de l'élément> [, <Gestion des champs spéciaux>])`
---

**`<Nom de l'élément> : (Chaîne de caractères)`**

Nom de l'élément dont les champs doivent être ré-initialisés. Peut correspondre au : 

- Nom du groupe de champs. 

- Nom du superchamp. 

- Nom de la fenêtre interne ou de la page interne. 

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Nom du modèle de champs.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Nom de la popup.


![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Nom du groupe de champs à réinitialiser.

**`<Gestion des champs spéciaux> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> :

	- les champs de saisie et les champs Libellé sont ré-initialisés avec leur valeur initiale,

	- les champs Liste, Combo, Table et Zone répétée (fichier ou mémoire) ne sont ni vidées ni ré-initialisées. Elles conservent leur contenu actuel.




- <u><u><u><u>Faux</u></u></u></u> (par défaut) :

	- les champs de saisie et les champs Libellé sont ré-initialisés avec leur valeur initiale,

	- les champs Liste, Combo, Table et Zone répétée "mémoire" sont vidées et ré-initialisées avec leur contenu initial,

	- les champs Liste, Combo, Table et Zone répétée "fichier" sont uniquement ré-initialisées (elles ne sont pas vidées).  







![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre n'est pas disponible : tous les champs de la page sont ré-initialisés à leur valeur initiale. La valeur initiale des champs correspond à la valeur des champs lors du dernier affichage de la page sur le navigateur (premier affichage de la page, ou affichage lors d'une réactualisation, ...).

### Variables de fichiers
<a name="variables_fichiers_ELTPARAGRAPHE000168"></a>La fonction [HRAZ](../WDLang4/3044118.md) permet de remettre à vide les variables des fichiers de données HFSQL. Pour réinitialiser uniquement les variables des fichiers de données HFSQL dans une page, il est nécessaire d'utiliser le code suivant :


```txt
HRAZ(<Nom de fichier de données>)
FichierVersPage()
```


**Attention** : Si des champs sont associés à des rubriques de fichiers de données, ces rubriques contiennent des étoiles ("\*").

### Traitement d'initialisation
<a name="traitement_initialisation_ELTPARAGRAPHE000185"></a>Il ne faut pas confondre la fonction **RAZ** et la fonction [PageInitialisation](../WDLang2/3058025.md). En effet :

- la fonction **RAZ** remet les champs à vide

- la fonction [PageInitialisation](../WDLang2/3058025.md) remet les champs à vide et relance les traitements d'initialisation.

### Champs Table et Zone répétée
<a name="champs_table_zone_repetee_ELTPARAGRAPHE000209"></a>Un champ Table ou Zone répétée lié à un fichier de données ne peut jamais être vide. Ce champ s'initialise automatiquement avec les valeurs des rubriques reliées dans le fichier de données.
<a name="NOTE0_4"></a>




### Limites
<a name="limites_ELTPARAGRAPHE000217"></a>La fonction **RAZ** ne réinitialise pas les libellés des champs Bouton. 

![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La fonction **RAZ** n'a aucun effet sur les champs suivants :

- Champ Libellé,

- Champ Bouton,

- Champ Image.
