


## LecteurPDFRechercheSuivant (Fonction)

***En anglais : PDFReaderSeekNext***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Positionne sur le résultat suivant d'une recherche initiée par la fonction [LecteurPDFRecherchePremier](../WDLang1/1000023409.md) dans le contenu d'un champ Lecteur PDF (si le contenu du champ Lecteur PDF contient plusieurs occurrences du texte recherché).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Recherche un texte dans un champ Lecteur PDF et affiche le texte
LecteurPDFRecherchePremier(PDF_MonLecteurPDF, "société")
// Recherche l'élément suivant
SI LecteurPDFRechercheSuivant(PDF_MonLecteurPDF) = Faux ALORS
	Info("Recherche terminée")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = LecteurPDFRechercheSuivant(<Champ Lecteur PDF>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le texte spécifié dans la fonction [LecteurPDFRecherchePremier](../WDLang1/1000023409.md) a été trouvé dans le document en cours dans le champ Lecteur PDF, 

- <u><u><u><u>Faux</u></u></u></u> si le texte n'a pas été trouvé. 




**`<Champ Lecteur PDF> : (Nom de champ)`**

Nom du champ Lecteur PDF à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Le texte et les options de recherche ont été spécifiés dans la fonction [LecteurPDFRecherchePremier](../WDLang1/1000023409.md). 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits. 
	Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
