


## Fonctions de gestion des chaînes de caractères (syntaxe préfixée)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de manipuler des chaînes de caractères via une syntaxe préfixée sont les suivantes :




|   |   |
| --- | --- |
| [&lt;Buffer&gt;.AnsiVersUnicode](../WDLang1/1000026033.md) | Convertit un buffer contenant une chaîne de caractères au format ANSI (Windows) en un buffer contenant une chaîne de caractères au format UNICODE. |
| [&lt;Buffer&gt;.UTF8Valide](../WDLang1/1410090487.md) | Teste la validité d'un buffer au format UTF8. |
| [&lt;Chaîne ANSI&gt;.AnsiVersOem](../WDLang1/1000024891.md) | Convertit une chaîne de caractères au format ANSI (Windows) en une chaîne de caractères au format OEM (DOS). |
| [&lt;Chaîne ANSI&gt;.AnsiVersUnicode](../WDLang1/1000024892.md) | Convertit une chaîne de caractères au format ANSI (Windows) en une chaîne de caractères au format Unicode. |
| [&lt;Chaîne ANSI&gt;.BufferVersHexa](../WDLang1/1000024894.md) | Convertit une chaîne Ansi ou Unicode en une chaîne hexadécimale affichable (par exemple : "4A 5B 00"). |
| [&lt;Chaîne ANSI&gt;.CaractOccurrenceType](../WDLang1/1000024895.md) | Renvoie le nombre de caractères vérifiant les informations de type données. |
| [&lt;Chaîne ANSI&gt;.CommencePar](../WDLang1/1000024901.md) | Vérifie si une chaîne de caractères commence : <br><br>- soit par une chaîne de caractères spécifique. <br><br>- soit par une des chaînes de caractères présentes dans un tableau.<br><br><br> |
| [&lt;Chaîne ANSI&gt;.Complète](../WDLang1/1410089823.md) | Renvoie une chaîne de caractères spécifique de taille déterminée. |
| [&lt;Chaîne ANSI&gt;.Contient](../WDLang1/1410089824.md) | Permet de savoir si une sous-chaîne est contenue dans une chaîne. |
| [&lt;Chaîne ANSI&gt;.Découpe](../WDLang1/1000024902.md) | Extrait toutes les sous-chaînes d'une chaîne de caractères en fonction d'un ou plusieurs séparateurs de chaînes. |
| [&lt;Chaîne ANSI&gt;.Droite](../WDLang1/1410089825.md) | Extrait la partie droite (c'est-à-dire les derniers caractères) d'une chaîne de caractères ou d'un buffer. |
| [&lt;Chaîne ANSI&gt;.ExtraitChaîne](../WDLang1/1000024876.md) | Permet de :<br><br>- extraire une sous-chaîne d'une chaîne de caractères en fonction d'un séparateur de chaîne donné.<br><br>- effectuer un parcours de sous-chaînes dans une chaîne de caractères en fonction d'un séparateur de chaîne donné.<br><br><br> |
| [&lt;Chaîne ANSI&gt;.FinitPar](../WDLang1/1000024903.md) | Vérifie si une chaîne de caractères se termine : <br><br>- soit par une chaîne de caractères spécifique.<br><br>- soit par une des chaînes de caractères présentes dans un tableau.<br><br><br> |
| [&lt;Chaîne ANSI&gt;.Formate](../WDLang1/1000024877.md) | Formate une chaîne de caractères selon les options choisies. |
| [&lt;Chaîne ANSI&gt;.Incrémente](../WDLang1/1000024905.md) | Incrémente un nombre situé en fin ou début d'une chaîne de caractères. |
| [&lt;Chaîne ANSI&gt;.Insère](../WDLang1/1000024906.md) | Insère une chaîne dans une autre chaîne de caractères à une position donnée. |
| [&lt;Chaîne ANSI&gt;.Inverse](../WDLang1/1000024908.md) | Inverse les caractères d'une chaîne. |
| [&lt;Chaîne ANSI&gt;.RegexCherche](../WDLang1/1410090616.md) | Cherche toutes les parties d'une chaîne de caractères qui respectent un format donné. |
| [&lt;Chaîne ANSI&gt;.RegexRemplace](../WDLang1/1410090617.md) | Remplace toutes les parties d'une chaîne qui respectent un format donné. |
| [&lt;Chaîne ANSI&gt;.RegexVérifie](../WDLang1/1410090618.md) | Vérifie si une chaîne respecte un format défini par une expression régulière. |
| [&lt;Chaîne ANSI&gt;.Remplace](../WDLang1/1000024890.md) | Remplace toutes les occurrences d'un mot présent dans une chaîne par un autre mot. |
| [&lt;Chaîne ANSI&gt;.SupprimeDoublon](../WDLang1/1410087983.md) | Supprime les doublons parmi les sous-chaînes d'une chaîne de caractères en fonction d'un ou plusieurs séparateurs. |
| [&lt;Chaîne ANSI&gt;.VersNumérique](../WDLang1/1410087984.md) | Renvoie la valeur numérique d'une chaîne de caractères. Il est ainsi possible d'effectuer des calculs numériques sur des chaînes de caractères. |
| [&lt;Chaîne OEM&gt;.OemVersAnsi](../WDLang1/1410090334.md) | Convertit une chaîne de caractères au format OEM (DOS) en une chaîne de caractères au format ANSI (Windows). |
| [&lt;Chaîne Unicode&gt;.RegexCherche](../WDLang1/1410090619.md) | Cherche toutes les parties d'une chaîne de caractères qui respectent un format donné. |
| [&lt;Chaîne Unicode&gt;.RegexRemplace](../WDLang1/1410090620.md) | Remplace toutes les parties d'une chaîne qui respectent un format donné. |
| [&lt;Chaîne Unicode&gt;.RegexVérifie](../WDLang1/1410090621.md) | Vérifie si une chaîne respecte un format défini par une expression régulière. |
