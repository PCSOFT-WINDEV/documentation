
## ExécuteProcédureRéactive (Fonction)

***En anglais : ExecuteReactiveProcedure***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Force l'exécution immédiate d'une procédure réactive.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ExécuteProcédureRéactive(CalculTTC)
```



```wl
PROCEDURE REACTIVE CalculeTTC()
SAI_TTC = SAI_HT + SAI_HT * (SAI_TVA + 1) / 100
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`ExécuteProcédureRéactive(<Procédure WLangage> [, <Paramètre 1> [... [, <Paramètre N>]]])`
---

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure réactive WLangage à lancer. Cette procédure doit avoir été définie comme procédure réactive sous l'éditeur de code. Pour plus de détails, consultez [Procédures réactives](../Motscles/1514090.md).

**`<Paramètre 1> : (Type du paramètre)`**

Premier paramètre associé à la procédure.



**`<Paramètre N> : (Type du paramètre)`**

Nième paramètre associé à la procédure.
