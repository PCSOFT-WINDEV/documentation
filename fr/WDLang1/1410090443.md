


## DocEffaceMiseEnForme (Fonction)

***En anglais : DocClearFormatting***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Remplace la mise en forme actuelle de la sélection par la mise en forme par défaut. Ce remplacement est effectuée : 

- sur la sélection en cours dans un champ Traitement de texte. 

- sur un fragment.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) 
```wl
// Efface la mise en forme du fragment sélectionné dans le champ Traitement de texte
DocEffaceMiseEnForme(TT_Lettre.Sélection.Fragment)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`DocEffaceMiseEnForme(<Elément manipulé>)`
---

**`<Elément manipulé> : (Variable de type docFragment ou nom de champ)`**

Elément manipulé. Cet élément peut correspondre : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) au nom du champ Traitement de texte. Dans ce cas, seule la sélection en cours sera manipulée. 

- à une variable de type [docFragment](../WDLang1/1000022482.md).
