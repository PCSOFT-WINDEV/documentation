
## CodeWLangageMiseEnForme (Type de variable)

***En anglais : WLanguageCodeFormatting***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **CodeWLangageMiseEnForme** permet de définir tous les paramètres de mise en forme du code WLangage. Ces paramètres peuvent être définis et modifiés à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Chaîne à mettre en forme
sCode est une chaîne ANSI = "
MiseEnFormeCode est un CodeWLangageMiseEnForme
MiseEnFormeCode.Langue = langueFrançais
MiseEnFormeCode.Indentation = Vrai
MiseEnFormeCode.InclureDéclarationsCSS = Vrai
MiseEnFormeCode.IgnoreErreurCompilation = Vrai
MiseEnFormeCode.CasseMotsClés = codeWLangageMotsClésMinuscule
MiseEnFormeCode.Thème = codeWLangageThèmeSombre
MiseEnFormeCode.Format = codeWLangageFormatHTML
bufResHTML est un buffer = MiseEnFormeCode.MetEnForme(sCode)
"
MiseEnFormeCode est un CodeWLangageMiseEnForme
MiseEnFormeCode.Langue = langueFrançais
MiseEnFormeCode.Indentation = Vrai
MiseEnFormeCode.InclureDéclarationsCSS = Vrai
MiseEnFormeCode.IgnoreErreurCompilation = Vrai
MiseEnFormeCode.CasseMotsClés = codeWLangageMotsClésMinuscule
MiseEnFormeCode.Thème = codeWLangageThèmeSombre
MiseEnFormeCode.Format = codeWLangageFormatHTML
bufResHTML est un Buffer = CodeWLangageMetEnForme(MiseEnFormeCode, sCode)

// Affichage dans un champ d'affichage HTML
HTM_SansNom1 = UTF8VersChaîne(bufResHTML)
```

## Propriétés


### Propriétés spécifiques à la description des variables de type CodeWLangageMiseEnForme
<a name="proprietes_specifiques_description_des_variables_type_codewlangagemiseenforme_ELTPARAGRAPHE000026"></a>Les propriétés suivantes peuvent être utilisées pour manipuler les caractéristiques de mise en forme d'un code WLangage:

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| CasseMotsClés | Constante de type Entier | Casse à utiliser pour les mots-clés : <br><br>- *codeWLangageMotsClésMajuscule* : Les mots-clés sont en majuscules. <br><br>- *codeWLangageMotsClésMinuscule* : Les mots-clés sont en minuscules. <br><br><br> |
| Compilation | Variable de type [CodeWLangageCompilation](../WDLang1/1410090373.md) | Paramètres de compilation (fonctions autorisées, interdites, etc.). |
| Format | Constante de type Entier | Format du code mis en forme :<br><br>- *codeWLangageFormatTexte* (Valeur par défaut) : Texte simple. <br><br>- *codeWLangageFormatHTML* : Texte au format HTML. <br><br><br> |
| IgnoreErreurCompilation | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> pour ignorer les erreurs de compilation. La coloration et la mise en forme sera moins précise.<br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) dans le cas contraire.<br><br><br> |
| InclureDéclarationsCSS | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> (Valeur par défaut) pour inclure dans le code mis en forme les déclarations CSS nécessaires à la coloration et à la mise en forme. Cette propriété est prise en compte uniquement si la propriété **Format** correspond à la constante *CodeWLangageFormatHTML*. <br><br>- <u><u><u>Faux</u></u></u> pour ne pas inclure les déclarations CSS. Dans ce cas, il est possible de les obtenir avec la fonction [CodeWLangageDonneDéclarationsCSS](../WDLang1/1410090145.md).<br><br><br> |
| Indentation | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> pour activer l'indentation,<br><br>- <u><u><u>Faux</u></u></u> (Valeur par défaut) pour désactiver l'indentation. <br><br><br> |
| Langue | Constante de type Entier | Langue du code à générer : <br><br>- 0 (Valeur par défaut) : pas de traduction, le code reste dans la langue utilisée. <br><br>- *langueFrançais* : le code est traduit en français. <br><br>- *langueAnglais* : le code est traduit en anglais. <br><br><br>Remarque : Seuls les mot-clés, types de variables, fonctions et propriétés sont traduites. |
| Thème | Constante de type Entier | Thème utilisé pour la coloration : <br><br>- *codeWLangageThèmeClair* : Utilisation du thème clair. <br><br>- *codeWLangageThèmeGris* : Utilisation du thème gris. <br><br>- *codeWLangageThèmeSombre* : Utilisation du thème sombre. <br><br><br> |
