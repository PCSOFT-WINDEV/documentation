


## &lt;Tableau&gt;.Filtre (Fonction)

***En anglais : &lt;Array&gt;.Filter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie un tableau contenant les éléments d'un tableau source pour lesquels une procédure renvoie <u><u><u>Vrai</u></u></u>.

Cette fonction est utilisable : 

- sur les tableaux à une dimension, 

- sur les tableaux associatifs.
	![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Non disponible.

<a name="sample_code"></a>

## Exemple

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Tableau source>.Filtre(<Condition à vérifier>)`
---

**`<Résultat> : (Tableau WLangage)`**

Tableau contenant les éléments du &lt;Tableau source&gt; pour lesquels la procédure &lt;Condition à vérifier&gt; renvoie <u><u><u><u>Vrai</u></u></u></u>.

**`<Tableau source> : (Tableau WLangage)`**

Nom de la variable de type Tableau à manipuler. Ce tableau peut être : 

- un tableau à une dimension.

- un tableau associatif.
	![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Non disponible.




**`<Condition à vérifier> : (Procédure WLangage)`**

Nom de la procédure WLangage à exécuter pour chaque élément du &lt;Tableau source&gt;. Cette procédure doit renvoyer <u><u><u><u>Vrai</u></u></u></u> ou <u><u><u><u>Faux</u></u></u></u>. 
Cette procédure peut être : 

- une procédure globale ou locale, 

- une procédure interne. 


Il est également possible d'utiliser directement une procédure lambda.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Fonctionnement
<a name="fonctionnement_ELTPARAGRAPHE000244"></a>La procédure &lt;Condition à vérifier&gt;  est appelée pour chaque élément du tableau source en passant en paramètre : 

- l'élément du tableau source, 

- la clé de l'élément.
	Dans le cas d'un tableau simple, la clé correspond à l'indice de l'élément. Ce paramètre est optionnel.
	Dans le cas d'un tableau associatif, la clé correspond à la clé d'indexation des éléments. 
	![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Non disponible.




Si la procédure renvoie <u><u><u><u>Vrai</u></u></u></u>, l'élément du tableau source est stocké dans le tableau &lt;Résultat&gt;.
