
## GesteNbPointeur (Fonction)

***En anglais : GestureNbPointer***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Retourne le nombre de pointeurs en contact avec l'écran. 

La valeur renvoyée varie selon le mode d'utilisation de la fonction :

- Utilisée dans un événement lié au mouvement du pointeur (clic, déplacement, enfoncé, relâché, ...), retourne le nombre de pointeurs (doigt ou stylet) actuellement en contact avec l'écran

- Utilisée dans un autre événement ou traitement, retourne le dernier nombre de points de contacts connu.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// -- Code de clic sur un champ Image
nbPointsContact est un entier
nbPointsContact = GesteNbPointeur()

ToastAffiche("Vous utilisez actuellement " + nbPointsContact + " doigt(s) sur l'écran")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = GesteNbPointeur()`
---

**`<Résultat> : (Entier)`**

Nombre de pointeurs (doigts ou stylets) en contact avec l'écran.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) **Remarque** : Dans le simulateur ou l'émulateur Android, ce nombre est toujours égal à 1. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) 

### Gestion de plusieurs pointeurs
<a name="gestion_plusieurs_pointeurs_ELTPARAGRAPHE000058"></a>Pour gérer plusieurs pointeurs sur l'écran, l'appareil doit être muni d'un dispositif multi-points (multi-touch).

**Attention** : Sur certains appareils, la fonction **GesteNbPointeur** peut retourner une valeur inférieure au nombre de pointeurs effectivement en contact avec l'écran. En effet, le nombre de points de contact simultanés géré par le système est limité (cette limite peut varier d'un appareil à l'autre). 


<a name="NOTE0_2"></a>


### Limitations
<a name="limitations_ELTPARAGRAPHE000071"></a>

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Seuls 2 pointeurs maximum peuvent être gérés. 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Le navigateur utilisé doit gérer la fonctionnalité de multi-touch. 



<a name="NOTE0_3"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000096"></a>

- Pour connaître la position verticale (Y) d'un pointeur, utilisez la fonction [GestePosY](../WDLang1/1000019745.md).

- Pour connaître la position horizontale (X) d'un pointeur, utilisez la fonction [GestePosX](../WDLang1/1000019741.md). 

- Pour connaître l'indice du pointeur ayant déclenché l'exécution d'un événement lié à un mouvement sur l'écran, utilisez la fonction [GestePointeurEncours](../WDLang1/1000019751.md).
