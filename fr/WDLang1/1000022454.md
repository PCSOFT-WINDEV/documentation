
## CaméraDémarreDécodage (Fonction)

***En anglais : CameraStartDecoding***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Démarre le décodage des codes-barres dans un champ Caméra. Il est possible de spécifier le type des codes-barres à décoder.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Démarre le décodage des codes-barres de type QRCode dans le champ Caméra
CaméraDémarreDécodage(CAM_Caméra1, CB_QRCODE)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`CaméraDémarreDécodage(<Champ Caméra> [, <Type de codes-barres>])`
---

**`<Champ Caméra> : (Nom de champ)`**

Nom du champ Caméra à manipuler.

**`<Type de codes-barres> : (Constante de type Entier optionnelle)`**

Type de codes-barres pouvant être décodé : 


|   |   |
| --- | --- |
| *CB_AZTEC* | Code-barres de type Aztec. <br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |
| *CB_CODE128* | Code-barres de type Code128.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |
| *CB_CODE39* | Code-barres de type Code39.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |
| *CB_CODE93* | Code-barres de type Code93.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |
| *CB_DATAMATRIX* | Code-barres de type DATAMATRIX.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Non disponible. |
| *CB_EAN13* | Code-barres de type EAN13.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |
| *CB_EAN8* | Code-barres de type EAN8.<br>![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce type de code-barres est disponible à partir de iOS 7. |

| *CB_QRCODE* | Code-barres de type QR Code. |

Si ce paramètre n'est pas spécifié : 

- les codes-barres spécifiés lors du dernier appel à la fonction **CaméraDémarreDécodage** seront décodés. 

- les codes-barres spécifiés dans la fenêtre de description du champ Caméra seront décodés. 








<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Le champ Caméra doit avoir été configuré pour autoriser le décodage de code-barres (dans la fenêtre de description). Si ce n'est pas le cas, l'appel de la fonction **CaméraDémarreDécodage** déclenchera une erreur fatale.

- Lorsque le champ Caméra est configuré pour autoriser le décodage de code-barres (dans la fenêtre de description), le décodage démarre automatiquement à l'ouverture de la fenêtre. Pour empêcher ce comportement, il est possible d'appeler la fonction [CaméraArrêteDécodage](../WDLang1/1000022449.md) dans l'événement "Initialisation" du champ Caméra.

- Si la fonction **CaméraDémarreDécodage** est appelée alors qu'un décodage est déjà en cours dans le champ Caméra, le décodage est arrêté puis relancé pour prendre en compte le nouveau type de code-barres à décoder. Si le type de code-barres est identique, la fonction est sans effet.

- Lorsqu'un code-barres est détecté, l'événement "Décodage d'un code-barres" du champ Caméra est appelé avec en paramètre une variable de type [CodeBarres](../WDLang5/1000019451.md) correspondant au code-barres détecté. Si cet événement renvoie <u><u><u><u>Vrai</u></u></u></u>, le décodage de code-barres sera automatiquement arrêté.

- Cette fonction est équivalente à la fonction [VidéoDémarreDécodage](../WDLang1/1000022163.md).
