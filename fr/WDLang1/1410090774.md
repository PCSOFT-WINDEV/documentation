
## BitcoinCoreHashBloc (Fonction)

***En anglais : BitcoinCoreBlockHash***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le hash d'un bloc identifié par son indice.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Récupération du hash d'un bloc identifié par son indice
soit hashBloc = BitcoinCoreHashBloc(2)
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = BitcoinCoreHashBloc(<Indice>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Hash du bloc. 

**`<Indice> : (Entier)`**

Numéro du bloc.

<a name="NOTE0_1"></a>
