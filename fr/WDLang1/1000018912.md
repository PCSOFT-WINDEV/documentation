


## DonneCouleur (Fonction)

***En anglais : GetColor***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'obtenir une suite de couleurs harmonieuses sans avoir à utiliser une table de couleurs.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Remplit les données du champ Graphe
POUR I = 1 A 12
	// Ajoute le chiffre d'affaires du mois numéro I
	grAjouteDonnée(GRF_MonGraphe, I, tabValeurs[I])
	
	// Affecte une couleur à la série du mois numéro I
	grCouleurSérie(GRF_MonGraphe, I, DonneCouleur())	
FIN
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = DonneCouleur([<Indice> [, <Série>]])`
---

**`<Résultat> : (Entier)`**

Couleur au format RVB.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) &lt;Résultat&gt; correspond à une variable de type [Couleur](../WDLang1/1000019661.md). 

**`<Indice> : (Entier optionnel)`**

Numéro de la couleur à récupérer. 
Si ce paramètre n'est pas spécifié, la couleur renvoyée est une couleur qui n'a jamais été utilisée. 
Si ce paramètre est spécifié, pour un indice donné, la même couleur sera toujours renvoyée.
![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre n'est pas disponible. 

**`<Série> : (Constante optionnelle de type Entier)`**

Constante indiquant le style de série de couleur à récupérer : 


|   |   |
| --- | --- |
| *coulSérieDéfaut*<br>(Valeur par défaut) | La couleur renvoyée est choisie parmi une série de couleurs standard. |
| *coulSérieFoncée* | La couleur renvoyée est choisie parmi une série de couleurs plus foncées (adaptée au champ TreeMap par exemple). |
| *coulSérieGabarit* | La couleur renvoyée est choisie parmi la série de couleurs définie pour le gabarit en cours. <br><br>![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette constante n'est pas disponible. |
| *coulSériePalette* | La couleur renvoyée est choisie parmi la série de couleurs définie pour la palette en cours. <br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Cette constante n'est pas disponible. |
| *coulSériePastel* | La couleur renvoyée est choisie parmi une série de couleurs plus claires. |
