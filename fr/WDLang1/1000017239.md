


## ExeDonnePID (Fonction)

***En anglais : ExeGetPID***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie des informations sur le processus courant.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Dans le code serveur d'un site dynamique, la fonction **ExeDonnePID** retourne l'identifiant de la connexion visible dans l'administrateur de WEBDEV (pour plus de détails, consultez [Administrateur WEBDEV](../WDAdminDeploiement/3539007.md)). Cet identifiant est unique au moment de l'appel et tant que dure la connexion. Il n'est pas unique dans le temps.



![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette fonction est désormais disponible pour les applications iPhone/iPad.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// PID de l'application
MonPID est un entier
MonPID = ExeDonnePID()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = ExeDonnePID([<Information recherchée>])`
---

**`<Résultat> : (Entier système)`**

Information demandée.

**`<Information recherchée> : (Constante de type Entier optionnelle)`**

Information demandée sur le processus courant :


|   |   |
| --- | --- |
| *exePID*<br>(valeur par défaut) | PID (Processus Identifier) du processus courant. |
| *exePIDParent* | PID du parent (c'est-à-dire le processus qui a lancé le processus en cours).<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette constante n'est pas disponible. |
| *exeTID* | Identificateur du thread courant.<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette constante n'est pas disponible. |
