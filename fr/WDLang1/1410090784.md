
## JSONOuvreLecteur (Fonction)

***En anglais : JSONOpenReader***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Crée un lecteur permettant de lire un document JSON sans le charger en mémoire.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
lecteur_JSON est un jsonLecteur = JSONOuvreLecteur(nom_du_fichier)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = JSONOuvreLecteur(<Document> [, <Origine>])`
---

**`<Résultat> : (Variable de type jsonLecteur)`**

Variable de type [jsonLecteur](../WDLang1/1410090783.md) permettant de lire un document JSON sans le charger en mémoire.

**`<Document> : (Chaîne de caractères)`**



- Chemin du fichier contenant le document JSON à lire.

- Contenu JSON à manipuler.  




**`<Origine> : (Constante optionnelle de type Entier)`**

Contenu du paramètre &lt;Document&gt; : 


|   |   |
| --- | --- |
| *depuisFichier* | Le paramètre &lt;Document&gt; correspond au nom d'un fichier. |
| *depuisChaîne* | Le paramètre &lt;Document&gt; est une chaîne UTF8 contenant le JSON à manipuler. |
