
## RéseauUtilisateur (Fonction)

***En anglais : NetworkUser***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifie le nom de l'utilisateur connecté.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Sous WEBDEV : 

- En mode test, identifie le nom de l'utilisateur connecté sur le poste serveur. En déploiement, identifie l'utilisateur utilisé par défaut par le serveur Web.

- Dans un contexte Intranet, peut permettre de connaître le login Windows du poste Client. Cependant, pour des raisons de sécurité les navigateurs sont "bridés" afin de ne pouvoir divulguer aucune information sur la configuration ou la connexion. Cette sécurité bloque la récupération du login utilisateur Windows. 
	 **Cas particulier** : Configuration full Windows (IIS - IE) avec le poste de l'internaute et le serveur Web sur le même domaine : possibilité de connaître le nom de l'utilisateur Windows connecté en paramétrant le serveur IIS : il ne faut plus autoriser la "Connexion anonyme" mais il faut activer l "Authentification intégrée de Windows".
