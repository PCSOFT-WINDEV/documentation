


## &lt;Variable FichierDisque&gt;.Lit (Fonction)

***En anglais : &lt;DiskFile variable&gt;.Read***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lit un bloc d'octets dans un fichier externe. 

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Dans cette version, il est possible uniquement de lire un bloc d'octets dans un fichier externe au format ANSI.

## Syntaxe

### Lire un bloc d'octets dans un fichier externe

`<Résultat> = <Fichier manipulé>.Lit(<Nombre d'octets à lire>)`
---

**`<Résultat> : (Chaîne de caractères)`**



- Le bloc d'octets lu. 

- Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Fichier manipulé> : (Variable de type FichierDisque)`**

Nom de la variable de type [FichierDisque](../WDLang1/1410088883.md) initialisée avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md).

**`<Nombre d'octets à lire> : (Entier)`**

Nombre d'octets à lire (2 147 483 648 octets maximum). 

Si les données sont une chaîne Unicode, le nombre d'octets à lire correspond : 

- en UTF16 : au nombre de caractères multiplié par 2.

- en UTF32 : au nombre de caractères multiplié par 4.

### Lire le contenu d'un fichier externe pour l'affecter dans une portion de mémoire (identifiée par son adresse)

`<Résultat> = <Fichier manipulé>.Lit(<Nombre d'octets à lire> , <Adresse>)`
---

**`<Résultat> : (Entier)`**



- Nombre d'octets lus, 

- 0 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.




**`<Fichier manipulé> : (Variable de type FichierDisque)`**

Nom de la variable de type [FichierDisque](../WDLang1/1410088883.md) initialisée avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md).

**`<Nombre d'octets à lire> : (Entier)`**

Nombre d'octets à lire (2 147 483 648 octets maximum). 

Si les données sont une chaîne Unicode, le nombre d'octets à lire correspond : 

- en UTF16 : au nombre de caractères multiplié par 2.

- en UTF32 : au nombre de caractères multiplié par 4.




**`<Adresse> : (Adresse)`**

Adresse de la portion de mémoire affectée.

## Remarques


### Gestion des erreurs
<a name="gestion_des_erreurs_ELTPARAGRAPHE000326"></a>La fonction **&lt;Variable FichierDisque&gt;.Lit** génère une erreur dans les cas suivants :

- le fichier n'est pas ouvert,

- le fichier n'est pas accessible en lecture,

- le fichier est bloqué par un autre poste ou par une autre application,

- la fin du fichier a été atteinte.



<a name="NOTE0_2"></a>


### Position dans le fichier
<a name="position_dans_fichier_ELTPARAGRAPHE000344"></a>A l'ouverture d'un fichier, la position en cours correspond :

- au premier octet du fichier (par défaut),

- au dernier octet du fichier si le fichier est ouvert en "ajout" (constante *foAjout*).




Cette position peut être modifiée par la fonction [&lt;Variable FichierDisque&gt;.Positionne](../WDLang1/1410089048.md).

La fonction **&lt;Variable FichierDisque&gt;.Lit** lit les éléments spécifiés à partir de la position en cours. Après l'exécution de **&lt;Variable FichierDisque&gt;.Lit**, la position en cours correspond au dernier octet lu.

Remarque : Pour lire toujours le début du fichier, il faut donc faire appel à la fonction [&lt;Variable FichierDisque&gt;.Positionne](../WDLang1/1410089048.md) puis à la fonction **&lt;Variable FichierDisque&gt;.Lit**.
