
## EnModeTestApplication (Fonction)

***En anglais : InApplicationTestMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si le test automatique en cours est un test d'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI EnModeTestApplication() ALORS
 	// Initialisation spécifique pour le test automatique de l'application
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EnModeTestApplication()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si un test automatique d'application est en cours, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.










<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Disponibilité de la fonction
<a name="disponibilite_fonction_ELTPARAGRAPHE000160"></a>La fonction **EnModeTestApplication** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeTestApplication** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
