
## SysYRes (Fonction)

***En anglais : SysYRes***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la résolution verticale de l'écran.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Renvoie la résolution verticale de l'écran de l'internaute.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Résolution verticale de l'écran
ResResVert = SysYRes()
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = SysYRes()`
---

**`<Résultat> : (Entier)`**

Résolution verticale de l'écran.

<a name="NOTE0_1"></a>

### Résolution des configurations multi écrans
<a name="resolution_des_configurations_multi_ecrans_ELTPARAGRAPHE000181"></a>Dans les configurations multi écrans, il est nécessaire d'employer les fonctions [SysListeCarteGraphique](../WDLang1/1000017016.md), [SysListeEcran](../WDLang1/1000017014.md) et [SysRésolutionEcran](../WDLang1/1000017019.md) pour obtenir la résolution maximale dans une dimension donnée.
