


## MultimédiaDurée (Fonction)

***En anglais : MultimediaDuration***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la taille du fichier multimédia en cours de lecture (en millisecondes) dans le champ Multimédia.  

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Remarque** : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, son utilisation sera sans effet mais ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"
MultimédiaOuvre(MM_Multimédia1, MonFichier)
Info("La durée de ce fichier est " + MultimédiaDurée(MM_Multimédia1) + " millisecondes")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = MultimédiaDurée(<Champ Multimédia>)`
---

**`<Résultat> : (Entier)`**



- Durée (en millisecondes) du fichier multimédia, 

- 0 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Remarque : La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.
