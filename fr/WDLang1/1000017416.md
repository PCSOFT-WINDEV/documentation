


## &lt;Liste&gt;.SupprimeTout (Fonction)

***En anglais : &lt;List Box&gt;.DeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vide de tous ses éléments un champ Liste par programmation (y compris Liste image) ou un champ Combo par programmation.

**Remarque** : La fonction **&lt;Liste&gt;.SupprimeTout** peut être utilisée indifféremment sur les champs Liste monosélection et multisélection.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Attention** : Le champ Liste (ou Combo) sera vidé uniquement sur la page affichée dans le navigateur. Pour plus de détails, voir les Remarques.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Suppression de tous les éléments présents dans le champ "LISTE_ListeClient"
LISTE_ListeClient.SupprimeTout()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Champ Liste>.SupprimeTout()`
---

**`<Champ Liste> : (Nom de champ)`**

Nom du champ Liste (ou Combo) à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Suppression sur le navigateur
<a name="suppression_sur_navigateur_ELTPARAGRAPHE000210"></a>Lors de la suppression des éléments d'un champ Liste (ou Combo) en code navigateur, ces éléments sont supprimés uniquement sur la page affichée dans le navigateur. Pour que ces éléments soient également supprimés sur le serveur, il est nécessaire d'exécuter la fonction **&lt;Liste&gt;.SupprimeTout** sur le serveur.

L'utilisation de la fonction **&lt;Liste&gt;.SupprimeTout** en code navigateur est intéressante lors de l'utilisation de la [technologie AJAX](../WDLang2/3055101.md), en mode "AJAX Programmé" (utilisation de la fonction [AJAXExécute](../WDLang2/3055114.md) ou [AJAXExécuteAsynchrone](../WDLang2/3055115.md)).

**Rappel** : En mode "AJAX automatique et immédiat", il suffit de passer le traitement serveur contenant la fonction **&lt;Liste&gt;.SupprimeTout** en mode AJAX automatique. Rien de plus ! Aucune programmation supplémentaire n'est nécessaire. Pour plus de détails, consultez [AJAX](../WDLang2/3055101.md).
<a name="NOTE0_2"></a>


### Divers
<a name="divers_ELTPARAGRAPHE000245"></a>

- Pour supprimer l'ensemble des lignes d'un champ Table, utilisez la fonction [&lt;Table&gt;.SupprimeTout](../WDLang1/1000024292.md).

- La fonction **&lt;Liste&gt;.SupprimeTout** peut être utilisée sur une colonne d'un champ Table de type "Combo".

- Dans le cas des champs Combo avec saisie, la zone de saisie est vidée.
