
## fRepRessource (Fonction)

***En anglais : fResourceDir***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le chemin des ressources en lecture seule de l'application.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// La fonction renvoie le contenu du fichier
fChargeBuffer(fRepRessource() + ["\"] + "data.bin")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = fRepRessource()`
---

**`<Résultat> : (Chaîne de caractères)`**

Chemin complet des ressources en lecture seule de l'application. Correspond au répertoire ".app" de l'application. Il n'est pas possible d'écrire dans ce répertoire.

### Intégration de ressources lors de la génération de l'application iPhone/iPad
<a name="integration_ressources_lors_generation_application_iphoneipad_ELTPARAGRAPHE000033"></a>L'assistant de génération de l'application pour iOS permet d'inclure des fichiers dans l'exécutable. Il est possible d'intégrer :

- des ressources spécifiques.

- des images spécifiques.

- des fichiers de données. 



<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=P4_D%E9ploiement%20ios%20-%20HC%20N%B0002.jpg)


**Si les fichiers ont l'option "Ecriture" cochée**, ces fichiers seront extraits automatiquement (fichiers à modifier par l'application par exemple). Dans ce cas, spécifiez dans quel répertoire de l'application ce fichier doit être extrait (répertoire "Documents" ou répertoire "Library"). 

**Si les fichiers ont l'option "Ecriture" décochée**, ces fichiers pourront ensuite :

- soit être utilisés directement (fichiers à lire par exemple : fichiers son, image, ...). Ces fichiers sont intégrés à l'application et ne seront pas extraits. La fonction **fRepRessource** permet d'accéder en lecture à ces fichiers.  

- soit être extraits par programmation avec la fonction [fExtraitRessource](../WDLang1/1000019509.md). 




**Attention** : Le système iOS est sensible à la casse.

### Manipulation des fichiers en lecture seule présents dans le répertoire des ressources
<a name="manipulation_des_fichiers_lecture_seule_presents_dans_repertoire_des_ressources_ELTPARAGRAPHE000064"></a>L'arborescence du répertoire des ressources est identique à l'arborescence du répertoire du projet sur le poste de développement : 

- sur le poste de développement, la ressource intégrée au projet Xcode peut être présente dans un répertoire de la forme :  
	&lt;Nom_Projet&gt;\\EXE\\&lt;Nom de la configuration&gt;\\&lt;Répertoire personnalisé&gt;.  

- sur l'iPhone ou l'iPad, le ressource sera présente dans un répertoire de la forme : 
	 fRepRessource() + \\EXE\\&lt;Nom de la configuration&gt;\\&lt;Répertoire personnalisé&gt;. 




**Exemple** : Le code suivant permet de vérifier l'existence du fichier "stop.png" dans le répertoire des ressources. Sur le poste de développement, ce fichier était présent dans le répertoire "C:\\Mes Projets\\MonAppli\\Exe\\Application iOS\\stop.png". 

Sur l'iPhone ou l'iPad, ce chemin correspond à : "&lt;Répertoire de l'application&gt;/MonAppli.app/Exe/Application iOS/stop.png". 


```wl
SI fFichierExiste(ComplèteRep(fRepRessource()) + ComplèteRep("Exe") + ...
		ComplèteRep("Application iOS") + "stop.png") = Vrai ALORS
	Info("L'image a été trouvée")
SINON
	Info("Image inexistante.")
FIN
```
