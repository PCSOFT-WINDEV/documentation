
## LanceAppliAssociée (Fonction)

***En anglais : ShellExecute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre directement un document dans son application associée. L'application est tout d'abord ouverte, puis le document spécifié.

**Remarques** : 

- L'application utilisée pour ouvrir le document est celle associée à l'extension du document dans Windows (fichier INI ou base de registre). Cette application associée peut varier selon les configurations utilisées.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Ce document est ouvert sur le serveur. Cette fonction est utilisable sur le poste de développement, car ce poste fait office de serveur.

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Ce document doit être présent sur le serveur ou à n'importe quelle adresse Internet. Ce document est ouvert sur le poste de l'internaute.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) L'application utilisée pour ouvrir le document est l'application correspondant au type MIME associé à l'extension du fichier. Si plusieurs applications correspondent au même type de fichier, une boîte de dialogue sera affichée pour sélectionner l'application à lancer.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png) La fonction **LanceAppliAssociée** est bloquante : l'application continuera de s'exécuter uniquement à la fermeture du document et de son application associée. Le document doit être présent sur le poste. 

- Pour afficher une page quelconque dans un navigateur, il est également possible d'utiliser la fonction [NavigateurLanceAppli](../WDLang2/1000019424.md).

## Syntaxe

`<Résultat> = LanceAppliAssociée(<Nom du fichier> [, <Verbe>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le document existe et si l'application associée a été lancée. 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre n'est pas disponible. Cette fonction ne retourne pas de résultat.

![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Renvoie <u><u><u><u>Faux</u></u></u></u> si l'application est exécutée avec une machine virtuelle Java (JRE) inférieure à la version 1.6. 

**`<Nom du fichier> : (Chaîne de caractères)`**

Nom et chemin complet (ou relatif) du document à ouvrir. Un chemin de type UNC peut être utilisé. 
Si des espaces sont présents dans le nom ou dans le chemin du document à ouvrir, triplez les guillemets encadrant ce paramètre.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) Ce paramètre peut également correspondre à un raccourci Windows.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Ce paramètre peut correspondre à un chemin de fichier complet, relatif ou à une URI. 

Par exemple : 

- "/sdcard/photo.png"

- "/sdcard/video.3gp". 

- "http://www.pcsoft.fr" : lance le navigateur Web sur la page spécifiée. 

- "geo:1.44951,43.604363" : lance Google Maps ou équivalent. 

- "mailto:pcsoft@pcsoft.fr" lance l'application d'envoi d'emails. 

- "sms:0612345678" : lance l'application d'envoi de SMS. 




Les fichiers situés dans le répertoire de l'application ou l'un de ses sous-répertoires ne sont pas accessibles par la plupart des applications externes. Il est conseillé d'utiliser la fonction **LanceAppliAssociée** avec des fichiers situés sur la mémoire externe de l'appareil (exemple : sdcard) car ils sont accessibles depuis toutes les applications.



**`<Verbe> : (Chaîne de caractères optionnelle)`**

Verbe à utiliser pour lancer le document. Les verbes sont définis par application, pour indiquer les actions pouvant être effectuées. Les verbes les plus courants sont **open** ou **print**. Si ce paramètre n'est pas indiqué, le verbe utilisé sera le verbe par défaut pour le type de document.

## Remarques


### Utilisation en mode Service
<a name="utilisation_mode_service_ELTPARAGRAPHE000176"></a>La fonction **LanceAppliAssociée** utilisée en mode service permet bien de lancer l'application associée, mais l'interface de cette application n'est pas visible. 




<a name="NOTE0_4"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) 

### Lancer l'installation d'un fichier APK
<a name="lancer_installation_fichier_apk_ELTPARAGRAPHE000191"></a>A partir d'Android 8, pour lancer l'installation d'un fichier APK avec la fonction **LanceAppliAssociée**, il est nécessaire de modifier les permissions requises par l'application.  

Permission requise : REQUEST_INSTALL_PACKAGES. 

Cette permission permet d'installer des packages. 

Pour plus de détails (notamment pour les versions précédentes de WINDEV Mobile), consultez [FAQ 16927 : Que faire sous Android 8 si l'installation d'un APK avec la fonction LanceAppliAssociée n'est plus autorisée ?](https://faq.pcsoft.fr/faqread.awp?idfaq=16927). 
<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000349"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **LanceAppliAssociée** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
