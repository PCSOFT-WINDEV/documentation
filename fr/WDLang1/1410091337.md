
## iaElementConversation (Type de variable)

***En anglais : aiConversationElement***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **iaElementConversation** représente un élément dans une conversation effectuée via le champ Chat IA. Les caractéristiques de cet élément peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute le contenu du fichier AGENTS.md dans le suffixe de la première question de la conversation
// Evénement : Avant envoi de la demande du champ ChatIA
PROCEDURE AvantDemande(question est iaElementConversation)
conversation est une iaConversation = MoiMême..IAConversation
SI conversation.Element.Occurrence <= 1 alors
	sSuffixe est une chaîne = fChargeTexte(fRepExe()/"AGENTS.md")
	question.Suffixe = sSuffixe
FIN
RENVOYER Vrai
```

```wl
// Récupérer toutes les réponses de l'assistant de la conversation
sRéponseIA est une chaîne
conversation est une iaConversation = CHATIA_SansNom1.IAConversation
SI PAS conversation..RequêteEnCours ALORS
	réplique est une iaElementConversation
	POUR TOUTE réplique DE conversation..Element
		SI réplique..Rôle = iaRôleAssistant ALORS
			sRéponseIA += [RC] + réplique..Texte
		FIN
	FIN
FIN
```

## Propriétés


### Propriétés spécifiques à la description des variables de type iaElementConversation
<a name="proprietes_specifiques_description_des_variables_type_iaelementconversation_ELTPARAGRAPHE000027"></a>Les propriétés suivantes peuvent être utilisées pour manipuler un élément d'une conversation :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Extra | Variant | Permet de stocker une information avancée sans avoir d'influence sur l'exécution de l'application. Il est possible de stocker une valeur de n'importe quel type, un tableau, etc. Il est également possible d'ajouter des membres à la propriété **Extra**. <br>Exemple : <br><br><pre><code>MaVariable.Extra.Info1 = Valeur<br>MaVariable.Extra[Info2] = Valeur2<br>MaVariable.Extra.Date = DateSys()</code></pre><br> |
| Grisé | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si l'élément n'est plus valide : il ne sera pas envoyé aux moteurs de chat. Il sera affiché grisé dans un champ Chat IA. <br><br>- <u><u><u>Faux</u></u></u> dans le cas contraire.<br><br><br> |
| ID | Entier | Identifiant de l'élément. <br><br>**Cette propriété est disponible en lecture seulement.** |
| IDQuestionUtilisateur | Entier | Si l'élément correspond à une réponse, cette propriété permet de connaître l'identifiant de la question correspondante posée à l'IA. <br><br>**Cette propriété est disponible en lecture seulement.** |
| Image | Tableau de Image | Images associées à l'élément. |
| Notation | Entier | Indique si l'utilisateur a aimé ou non la réponse de l'IA : <br><br>- -1 : je n'aime pas,<br><br>- 0 : non évalué,<br><br>- 1 : j'aime. <br><br><br> |
| Préfixe | Chaîne de caractères | Si l'élément est une question de l'utilisateur, permet de spécifier un préfixe à la question.<br>Il est ainsi possible d'ajouter des éléments à une question. Ces éléments ne seront pas affichés dans le champ Chat IA par défaut. |
| Rôle | Constante de type Entier | Type de l'élément. Permet de savoir qui a parlé dans le champ Chat IA : <br><br>- *iaRôleAssistant* : Elément de conversation réalisé par l'assistant IA. <br><br>- *iaRôleErreur* : Elément de conversation correspondant à une erreur. <br><br>- *iaRôleTool* : Elément de conversation réalisé par un outil IA (tool). <br><br>- *iaRôleUtilisateur* : Elément de conversation réalisé par l'utilisateur. <br><br><br><br><br>**Cette propriété est disponible en lecture seulement.** |
| Suffixe | Chaîne de caractères | Si l'élément est une question de l'utilisateur, permet de spécifier un suffixe à la question.<br>Il est ainsi possible d'ajouter des éléments à une question. Ces éléments ne seront pas affichés dans le champ Chat IA par défaut. |
| Texte | Chaîne de caractères | Texte de la question, de la réponse ou de l'erreur. |
| Tool | Tableau | Tableau des outils disponible uniquement si Rôle correspond à la constante *iaRôleOutil*.<br>Les propriétés disponibles sont : <br><br>- Nom : Nom de l'outil. <br><br>- Libellé : Libellé de l'outil. <br><br>- ExécutionEnCours : <u><u><u>Vrai</u></u></u> si l'outil est toujours en cours, <u><u><u>Faux</u></u></u> sinon. <br><br><br><br><br>**Cette propriété est disponible en lecture seulement.** |
