


## Fonctions de cryptage / compression (syntaxe préfixée)
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de gérer le cryptage et la compression via une syntaxe préfixée sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Type Buffer&gt;.CrypteAsymétrique](../WDLang1/1410087279.md) | Crypte un buffer en utilisant un algorithme de chiffrement asymétrique (RSA) nécessitant une clé publique et une clé privée. |
| [&lt;Type Buffer&gt;.CrypteAsymétriqueEnveloppé](../WDLang1/1410087280.md) | Réalise un cryptage asymétrique d'une enveloppe. |
| [&lt;Type Buffer&gt;.CrypteStandard](../WDLang1/1410087281.md) | Crypte une chaîne de caractères ou un buffer binaire en utilisant un algorithme de chiffrement symétrique (AES, DES, etc.). |
| [&lt;Type Buffer&gt;.Décode](../WDLang1/1410087344.md) | Décode une chaîne de caractères précédemment encodée avec la fonction [&lt;Type Buffer&gt;.Encode](../WDLang1/1410087345.md). |
| [&lt;Type Buffer&gt;.DécrypteAsymétrique](../WDLang1/1410087282.md) | Décrypte un buffer avec un algorithme clé privée/publique selon le cryptage RSA. |
| [&lt;Type Buffer&gt;.DécrypteAsymétriqueEnveloppé](../WDLang1/1410087283.md) | Réalise le décryptage asymétrique d'une enveloppe encryptée avec la fonction [&lt;Type Buffer&gt;.CrypteAsymétriqueEnveloppé](../WDLang1/1410087280.md). |
| [&lt;Type Buffer&gt;.Encode](../WDLang1/1410087345.md) | Encode une chaîne de caractères ou un buffer. Pour décoder le résultat, il suffit d'utiliser la fonction [&lt;Type Buffer&gt;.Décode](../WDLang1/1410087344.md). |
