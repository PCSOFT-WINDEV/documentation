


## Exécute (Fonction)

***En anglais : Execute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lance l'exécution d'un traitement par programmation. Cette fonction est utilisée principalement pour exécuter les procédures.

Par compatibilité, le traitement exécuté peut également être un traitement d'un champ, d'une fenêtre ou d'une page. Dans ces différents cas, il est conseillé d'utiliser [ExécuteTraitement](../WDLang1/3013031.md).

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Le traitement exécuté correspond à un traitement serveur.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Le traitement exécuté correspond à un traitement navigateur.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution d'une procédure
Exécute("Proced1")
```


<a name="Exemple2"></a>

```wl
// -- Clic sur le bouton BTN_BOUTON1
// Exécution d'une procédure retournant un résultat
Info(Exécute("Doubler_Nombre", 2)) // Affiche 4
```

```wl
// Procédure Doubler_Nombre
PROCEDURE Doubler_Nombre(X)
RENVOYER 2*X
```

### Exécuter une procédure pouvant retourner un résultat

`<Résultat> = Exécute(<Procédure WLangage> [, <Paramètre 1> [... [, <Paramètre N>]]])`
---

**`<Résultat> : (Quelconque)`**

Valeur de retour de la procédure appelée. Cette valeur est identique à la valeur obtenue si la procédure est directement lancée.

**`<Procédure WLangage> : (Nom de procédure)`**

Nom de la procédure WLangage à exécuter. Cette procédure retourne un résultat.

**`<Paramètre 1> : (Type quelconque optionnel)`**

Premier paramètre optionnel à passer à la procédure. Ces paramètres sont toujours passés par valeur.



**`<Paramètre N> : (Type quelconque optionnel)`**

Nème paramètre optionnel à passer à la procédure. Ces paramètres sont toujours passés par valeur.

### Exécuter l'événement associé à un champ ou une procédure d'une fenêtre (ou d'une page) différente de la fenêtre (ou de la page) en cours
<a name="executer_evenement_associe_champ_une_procedure_une_fenetre_une_page_differente_fenetre_page_cours_ELTPARAGRAPHE000526"></a>Il est possible d'exécuter l'événement associé à un champ ou une procédure d'une fenêtre (ou d'une page) différente de la fenêtre (ou de la page) en cours. Il suffit de préfixer le nom du champ ou de la procédure par le nom de la fenêtre (ou de la page).

Par exemple : 


```wl
// Exécuter l'événement "Clic" du bouton Valider de MaSoeur (fenêtre ou page ouverte)
Exécute("MaSoeur.Valider..CLI")

// Exécuter la procédure PROC1 de MaSoeur (fenêtre ou page ouverte)
Exécute("MaSoeur.PROC1")
```


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Il n'est pas possible d'exécuter un événement WLangage associé à un champ présent sur une page différente de la page en cours.

### Chaîne passée en paramètre à la fonction Exécute
<a name="chaine_passee_parametre_fonction_docparampagetitleshort_ELTPARAGRAPHE000543"></a>La chaîne passée en paramètre à la fonction **Exécute** ne peut pas être une chaîne construite ou une variable. Il est nécessaire d'utiliser directement la chaîne contenant le nom du champ, de la fenêtre ou de la page et le traitement/événement à exécuter.


```wl
// Code correct
Exécute("Saisie2..Sortie")

// Code incorrect
i est un entier = 5
Exécute("Saisie" + i + "..Sortie")
```

### Les tableaux
<a name="les_tableaux_ELTPARAGRAPHE000559"></a>La fonction **Exécute** ne reconnaît pas les tableaux.

Par exemple :


```wl
var_tab est un tableau de 10 chaînes
// Appel une procédure MAPROC avec un tableau passé en paramètre
MAPROC(var_tab)
// L'instruction suivante provoque une erreur
Exécute("MAPROC..PRO", var_tab)
```

<a name="appeler_une_procedure_globale_composant_ELTPARAGRAPHE000587"></a>La fonction **Exécute** permet d'appeler une procédure globale de composant. Il suffit d'utiliser la syntaxe suivante :


```txt
Exécute(<Nom Composant>.<Nom Collection de procédures>.<Nom Procédure>)
```


Exemple : 


```wl
Exécute("MonComposant.Collection_WDExemple.MaProcédure")
```


Dans un thread lancé par un composant, il n'est pas possible d'appeler une procédure locale d'une fenêtre du projet hôte par **Exécute**.

Il est nécessaire d'utiliser un procédure globale du projet hôte qui rappelle la procédure locale de la fenêtre.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Utilisation de fonctions spécifiques
<a name="utilisation_fonctions_specifiques_ELTPARAGRAPHE000612"></a>Si l'appel de la fonction **Exécute** est précédé par les fonctions [EmailOuvreMessagerie](../WDLang2/3032021.md) et [PageValide](../WDLang2/3058020.md), ces fonctions seront ignorées si le code appelé par la fonction **Exécute** contient les fonctions [PageValide](../WDLang2/3058020.md) et [EmailOuvreMessagerie](../WDLang2/3032021.md). En effet, les navigateurs autorisent uniquement une action par page. Seule la dernière action demandée sera effectuée.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Exécution de l'événement associé à un champ
<a name="execution_evenement_associe_champ_ELTPARAGRAPHE000639"></a>Si le paramètre &lt;Nom du champ&gt; correspond à un bouton, l'exécution du code de clic sera similaire au clic sur le bouton. Si un code serveur (ou une action s'exécutant sur le serveur) est associée au bouton, ce code sera donc exécuté.
