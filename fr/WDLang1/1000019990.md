


## &lt;Multimédia&gt;.Etat (Fonction)

***En anglais : &lt;Multimedia&gt;.Status***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique l'état du fichier multimédia joué dans le champ Multimédia.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Remarque** : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, l'appel à cette fonction sera sans effet et ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"

MM_Multimédia1.Ouvre(MonFichier)
...
SI MM_Multimédia1.Etat() = MultimédiaEtatPause ALORS
	MM_Multimédia1.Début()
	MM_Multimédia1.Joue()
FIN
...
MM_Multimédia1.Ferme()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Multimédia>.Etat()`
---

**`<Résultat> : (Constante de type entier)`**

Etat du fichier multimédia en cours dans le champ Multimédia.


|   |   |
| --- | --- |
| *MultimédiaEtatArrêt* | Fichier arrêté.<br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Selon le type de vidéo et la configuration du navigateur, cette constante peut ne jamais être retournée : un fichier multimédia chargé peut être uniquement en lecture ou en pause. |
| *MultimédiaEtatJoue* | Fichier ouvert et en cours de lecture. |
| *MultimédiaEtatPause* | Fichier en pause. |



**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.
