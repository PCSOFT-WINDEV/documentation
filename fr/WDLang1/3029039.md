
## gStylo (Fonction)

***En anglais : gPen***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Construit une séquence de caractères permettant de décrire la couleur d'affichage du texte et/ou du contour d'une figure (rectangle ou cercle).

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) **Dans une fenêtre**, cette séquence de caractères permet de paramétrer la couleur du texte et/ou de contour :  

- dans un élément d'un champ Liste ou Combo.

- dans la barre de titre et/ou de message d'une fenêtre. 

- dans un champ Libellé. 
	Remarque : Il peut être nécessaire de recadrer ce libellé après la définition de son contenu.





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) 
```wl
// Ajout du mot "Jaune" de couleur jaune dans le champ "LISTE_ListeCouleurs"
ListeAjoute(LISTE_ListeCouleurs, gStylo(JauneClair) + "Jaune")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = gStylo(<Couleur>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Séquence de caractères définissant la couleur d'affichage du texte ou du contour d'une figure (cercle, rectangle, ...).

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette séquence de caractères peut être : 

- utilisée dans les fonctions [ListeAjoute](../WDLang1/3049004.md), [ListeInsère](../WDLang1/3049002.md) ou [ListeModifie](../WDLang1/3049009.md).

- affectée à un champ Libellé. 

- utilisée dans la barre de titre ou de message d'une fenêtre. 


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.

**`<Couleur> : (Entier ou constante)`**

Couleur d'affichage du texte ou du contour d'une figure (rectangle ou cercle). Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).
