


## Fonctions de gestion des répertoires et des fichiers externes (syntaxe préfixée)
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des fichiers externes via une syntaxe préfixée sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Variable FichierDisque&gt;.Bloque](../WDLang1/1410089037.md) | Bloque entièrement ou partiellement un fichier externe. |
| [&lt;Variable FichierDisque&gt;.ChangeTaille](../WDLang1/1410089038.md) | Change la taille d'un fichier externe. |
| [&lt;Variable FichierDisque&gt;.Cherche](../WDLang1/1410089039.md) | Cherche une chaîne de caractères ou un buffer dans un fichier ouvert avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md). |
| [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md) | Crée un fichier externe. |
| [&lt;Variable FichierDisque&gt;.Débloque](../WDLang1/1410089040.md) | Débloque entièrement ou partiellement un fichier externe. |
| [&lt;Variable FichierDisque&gt;.Ecrit](../WDLang1/1410089041.md) | Écrit :<br><br>- une chaîne de caractères dans un fichier externe.<br><br>- une portion de mémoire.<br><br><br> |
| [&lt;Variable FichierDisque&gt;.EcritLigne](../WDLang1/1410089042.md) | Écrit une ligne dans un fichier texte (au format ANSI ou Unicode). |
| [&lt;Variable FichierDisque&gt;.Ferme](../WDLang1/1410089043.md) | Ferme un fichier externe. |
| [&lt;Variable FichierDisque&gt;.Lit](../WDLang1/1410089044.md) | Lit :<br><br>- un bloc d'octets (bloc de caractères) dans un fichier externe (ANSI ou Unicode),<br><br>- le contenu d'un fichier externe (ANSI ou Unicode) pour l'affecter dans une portion de mémoire.<br><br><br> |
| [&lt;Variable FichierDisque&gt;.LitLigne](../WDLang1/1410089045.md) | Lit une ligne dans un fichier externe (au format ANSI ou Unicode). |
| [&lt;Variable FichierDisque&gt;.LitLigneExpressionRégulière](../WDLang1/1410089046.md) | Lit une ligne d'un fichier externe et récupère dans des variables les morceaux de cette ligne en fonction d'une expression régulière. |
| [&lt;Variable FichierDisque&gt;.NomFichier](../WDLang1/1410089047.md) | Renvoie le nom d'un fichier externe actuellement ouvert. |
| [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) | Ouvre un fichier externe (ANSI ou Unicode) pour le manipuler par programmation. |
| [&lt;Variable FichierDisque&gt;.OuvreFichierTemp](../WDLang1/1410090203.md) | Crée et ouvre un fichier temporaire. |
| [&lt;Variable FichierDisque&gt;.Positionne](../WDLang1/1410089048.md) | Renvoie et modifie la position en cours dans un fichier externe. |
| [&lt;Variable FichierDisque&gt;.Taille](../WDLang1/1410089049.md) | Renvoie la taille d'un fichier en octets. |
