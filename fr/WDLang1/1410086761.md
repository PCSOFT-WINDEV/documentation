
## BitcoinCoreDifficulté (Fonction)

***En anglais : BitcoinCoreDifficulty***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la difficulté courante du réseau.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// ========================================================================
// CONFIGURATION DE LA CONNEXION
// ========================================================================
BitcoinCoreParamètre(btcRpcAdresseServeur, "172.17.1.255")
BitcoinCoreParamètre(btcRpcNuméroDePort, 8332)
BitcoinCoreParamètre(btcRpcLogin, "bitcoin")
BitcoinCoreParamètre(btcRpcMotDePasse, "motdepasse")
BitcoinCoreParamètre(btcTimeout, 5) // 5 secondes

// ========================================================================
// Récupère la difficulté courante du réseau via getblockchaininfo
// ========================================================================
rDifficulte est un réel = BitcoinCoreDifficulté()
SI ErreurDétectée ALORS
	Erreur("Erreur lors de la récupération de la difficulté", ErreurInfo())
	RETOUR
FIN

Trace("Difficulté courante du réseau : " + NumériqueVersChaîne(rDifficulte, "15,2f"))
Trace("(source : getblockchaininfo)")
// Valeur exemple : 95 672 703 408 223.15 (octobre 2024)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = BitcoinCoreDifficulté()`
---

**`<Résultat> : (Réel)`**

Difficulté actuelle du réseau.
