


## Fonctions Bouton segmenté (syntaxe préfixée)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de gérer les champs Bouton segmenté (syntaxe préfixée) sont les suivantes :



|   |   |
| --- | --- |
| [&lt;Bouton segmenté&gt;.Ajoute](../WDLang1/1410090903.md) | Ajoute une nouvelle option (c'est-à-dire un nouveau bouton) dans un champ Bouton segmenté. |
| [&lt;Bouton segmenté&gt;.Insère](../WDLang1/1410090904.md) | Insère une nouvelle option dans un champ Bouton segmenté. |
| [&lt;Bouton segmenté&gt;.Supprime](../WDLang1/1410090905.md) | Supprime une option dans un champ Bouton segmenté. |
| [&lt;Bouton segmenté&gt;.SupprimeTout](../WDLang1/1410090906.md) | Supprime toutes les options d'un champ Bouton segmenté. |
