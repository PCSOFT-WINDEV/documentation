


## AgendaPosition (Fonction)

***En anglais : OrganizerPosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche un champ Agenda à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Agenda.






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Positionne le champ Agenda sur la date du jour
AgendaPosition(AGD_Agenda1, DateDuJour())
// Positionne le champ Agenda au 20 décembre 2022
AgendaPosition(AGD_Agenda1, "20221220")
```
<a name="Exemple2"></a>

```wl
// Obtenir la première date affichée dans le champ Agenda
DateAgenda est une Date
DateAgenda = AgendaPosition(AGD_MonAgenda)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Positionner le champ Agenda sur une date spécifiée

`AgendaPosition(<Champ Agenda> , <Date de début>)`
---

**`<Champ Agenda> : (Nom de champ)`**

Nom du champ Agenda à manipuler. Ce champ peut correspondre : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) au champ Agenda d'une fenêtre.

- au champ Agenda d'un état.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) au champ Agenda d'une page.




**`<Date de début> : (Chaîne de caractères ou variable de type Date)`**

Date de début de l'affichage. 


<a name="SYNTAXE2"></a>

### Connaître la première date ou la dernière date affichée par le champ Agenda

`<Résultat> = AgendaPosition(<Champ Agenda> , <Date recherchée>)`
---

**`<Résultat> : (Chaîne de caractères ou variable de type Date)`**

Date affichée par le champ Agenda. 

**`<Champ Agenda> : (Nom de champ)`**

Nom du champ Agenda à manipuler. Ce champ peut correspondre : 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) au champ Agenda d'une fenêtre.

- au champ Agenda d'un état.

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) au champ Agenda d'une page.




**`<Date recherchée> : (Constante optionnelle de type Entier)`**

Type de date recherchée :


|   |   |
| --- | --- |
| *agDateDébut*<br>(Valeur par défaut) | Première date affichée dans le champ Agenda. |
| *agDateFin* | Dernière date affichée dans le champ Agenda. |
| *agDateHeure1erVisible* | Première date et heure affichée dans le champ Agenda (en fonction de la position de l'ascenseur).<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Non disponible. |
| *agMoisEnCours* | Premier jour du mois affiché dans le champ Agenda. |


**Remarque** : Si le champ Agenda est en mode d'affichage "par jour", les constantes *agDateDébut* et *agDateFin* sont équivalentes.
