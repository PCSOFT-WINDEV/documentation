| --- | --- |

| [&lt;Elément&gt;.ExécuteMiseAJourUI](../WDLang1/1410088729.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" de l'élément spécifié. |
| [&lt;Fenêtre&gt;.ActiveGFI](../WDLang1/1410088766.md) | Active ou désactive le GFI (Grisage des Fenêtres Inaccessibles) d'une fenêtre spécifique. |
| [&lt;Fenêtre&gt;.AgencementEnCours](../WDLang1/1410088841.md) | Renvoie l'indice de l'agencement en cours dans la fenêtre ou dans la fenêtre interne spécifiée. |
| [&lt;Fenêtre&gt;.ChangeAgencement](../WDLang1/1410088842.md) | Applique un agencement spécifique sur : <br><br>- une fenêtre. <br><br>- une fenêtre interne.<br><br><br> |
| [&lt;Fenêtre&gt;.ExtHaut](../WDLang1/1410088867.md) | Renvoie la hauteur totale d'une fenêtre. |
| [&lt;Fenêtre&gt;.ExtLarg](../WDLang1/1410090624.md) | Renvoie la largeur totale d'une fenêtre. |
| [&lt;Fenêtre&gt;.ExtPosX](../WDLang1/1410090628.md) | Renvoie la position horizontale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [&lt;Fenêtre&gt;.ExtPosY](../WDLang1/1410090625.md) | Renvoie la position verticale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [&lt;Fenêtre&gt;.Iconise](../WDLang1/1000023884.md) | Iconise une fenêtre WINDEV. |
| [&lt;Fenêtre&gt;.ImageFenêtre](../WDLang1/1000023885.md) | Crée l'image de la fenêtre spécifiée dans un fichier BMP. |
| [&lt;Fenêtre&gt;.IntHaut](../WDLang1/1410090629.md) | Renvoie la hauteur interne d'une fenêtre (sans la barre de titre ni le cadre). |
| [&lt;Fenêtre&gt;.IntLarg](../WDLang1/1410090626.md) | Renvoie la largeur interne d'une fenêtre (sans le cadre). |
| [&lt;Fenêtre&gt;.IntPosX](../WDLang1/1410088866.md) | Renvoie la position horizontale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [&lt;Fenêtre&gt;.IntPosY](../WDLang1/1410090627.md) | Renvoie la position verticale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [&lt;Fenêtre&gt;.Maximise](../WDLang1/1000023886.md) | Affiche une fenêtre WINDEV dans sa taille maximale. |
| [&lt;Fenêtre&gt;.Ouvre](../WDLang1/1000023903.md) | Ouvre une fenêtre modale WINDEV ou WINDEV Mobile. |
| [&lt;Fenêtre&gt;.OuvreAsynchrone](../WDLang1/1410087862.md) | Ouvre une fenêtre dont le résultat sera récupéré via une procédure WLangage (appelée "callback"). |
| [&lt;Fenêtre&gt;.OuvreFenêtreMobile](../WDLang1/1000023887.md) | Ouvre une fenêtre dans une application mobile. |
| [&lt;Fenêtre&gt;.OuvreFille](../WDLang1/1000023904.md) | Ouvre une fenêtre fille non modale. |
| [&lt;Fenêtre&gt;.OuvrePopupAsynchrone](../WDLang1/1410087873.md) | Ouvre une fenêtre de type popup dont le résultat sera récupéré par une procédure WLangage (également appelée "Callback"). |
| [&lt;Fenêtre&gt;.OuvrePopupPosition](../WDLang1/1410087874.md) | Ouvre une fenêtre de type popup en précisant sa position d'ouverture et attend sa fermeture. |
| [&lt;Fenêtre&gt;.OuvreSoeur](../WDLang1/1410086669.md) | Ouvre une fenêtre soeur non modale. |
| [&lt;Fenêtre&gt;.Repeint](../WDLang1/1000023634.md) | Redessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique. |
| [&lt;Fenêtre&gt;.Restaure](../WDLang1/1000023888.md) | Affiche une fenêtre WINDEV dans sa taille initiale. |
