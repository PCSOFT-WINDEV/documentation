


## &lt;Variable Image&gt;.ChangeMode (Fonction)

***En anglais : &lt;Image variable&gt;.ChangeMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Change le mode de dessin sur une variable de type [Image](../WDLang1/1000019650.md). Ce mode de dessin est utilisé par les fonctions de dessin (fonctions [&lt;Variable Image&gt;.DessineLigne](../WDLang1/1000024230.md), [&lt;Variable Image&gt;.DessineRectangle](../WDLang1/1000024236.md), ...).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImage est une Image = "Test.bmp"

// Dessine un rectangle dans une variable de type Image puis l'efface
MonImage.ChangeMode(dessinXOR)
// Affiche le rectangle (en mode XOR)
MonImage.DessineRectangle(0, 0, 100, 100)
Multitâche(10)
// Efface le rectangle
MonImage.DessineRectangle(0, 0, 100, 100)

IMG_MonDessin = MonImage
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Variable Image>.ChangeMode(<Nouveau mode>)`
---

**`<Variable Image> : (Variable de type Image)`**

Nom de la variable de type [Image](../WDLang1/1000019650.md) à manipuler.

**`<Nouveau mode> : (Constante de type entier)`**

Mode de dessin dans l'image :



|   |   |
| --- | --- |
| *dessinAntiAliasing* | Utilise le GDI+ et/ou les fonctionnalités de la carte graphique pour dessiner les lignes et les cercles sans crénelage. Ce mode de dessin est plus lent mais le résultat est meilleur qu'avec le mode standard.<br>![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Constante non disponible.![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce mode de dessin n'est pas géré. |
| *dessinNormal* | Couleurs normales. |
| *dessinXOR* | Couleurs appliquées via une opération de "ou exclusif" avec le fond. Permet d'effacer un dessin si cette option est utilisée 2 fois.<br>ATTENTION : Ce mode de dessin n'est pas compatible avec la gestion de l'opacité (le dessin ne s'efface plus).<br>**Attention** : <br><br>- Le dessin en mode XOR est disponible uniquement sur les champs Image. Le dessin en mode XOR n'est pas disponible sur les variables de type [Image](../WDLang1/1000019650.md). <br><br>- La constante *dessinXOR* n'est pas combinable avec la constante *dessinAntiAliasing*. <br><br><br>![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Le dessin en mode XOR a des effets uniquement sur la fonction [&lt;Variable Image&gt;.DessinePoint](../WDLang1/1000024231.md). |

### Anti-aliasing
<a name="antialiasing_ELTPARAGRAPHE000422"></a>L'anti-aliasing consiste à dessiner les traits et les cercles en évitant l'effet de crénelage. Cette fonctionnalité nécessite le framework GDI + (c'est-à-dire le framework de WINDEV).
Exemple :<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=dchangemode.gif)
Limites :

- La fonction [&lt;Variable Image&gt;.DessineCorde](../WDLang1/1000024040.md) n'est pas supportée dans ce mode.

- Pour éviter l'effet de crénelage, les couleurs et les traits des éléments sont lissés. Certaines fonctions de dessin peuvent avoir un comportement inattendu car les couleurs spécifiées ne sont plus retrouvées. Ainsi, si vous spécifiez une couleur de bordure pour la fonction [&lt;Variable Image&gt;.Remplissage](../WDLang1/1000024239.md), cette couleur n'est pas retrouvée : le remplissage s'effectue sur toute la zone.

- Dans le cas d'un dessin avec anti-aliasing, les fonctions [&lt;Variable Image&gt;.DessinePolygone](../WDLang1/1000024233.md) et [&lt;Variable Image&gt;.DessinePortion](../WDLang1/1000024235.md) ont le comportement suivant. Le contour est dessiné par-dessus l'intérieur du polygone : le trait est donc en partie combiné avec l'intérieur du polygone. Si l'épaisseur du trait est importante, le trait s'affichera en deux couleurs.

- Pour plus de détails sur les conditions d'utilisation du GDI+, consultez [Framework GDI+](../Editeurs/2020007.md).

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000546"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000568"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
