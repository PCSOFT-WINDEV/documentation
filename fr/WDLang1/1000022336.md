


## Fonctions de manipulation de l'UI par l'utilisateur final (syntaxe préfixée)



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>



|   |   |
| --- | --- |
| [&lt;Fenêtre&gt;.EdActive](../WDLang1/1000022294.md) | Permet : <br><br>- de savoir si le mode "Modification de l'UI par l'utilisateur final" est activé dans une fenêtre (ou une fenêtre interne).<br><br>- d'activer ou non le mode "Modification de l'UI par l'utilisateur final" dans une fenêtre (ou une fenêtre interne).<br><br><br> |
| [&lt;Fenêtre&gt;.EdCharge](../WDLang1/1000022292.md) | Charge les modifications faites par l'utilisateur final dans une fenêtre. |
| [&lt;Fenêtre&gt;.EdCréeNote](../WDLang1/1000022301.md) | Crée un champ Note repositionnable. |
| [&lt;Fenêtre&gt;.EdDésélectionneTout](../WDLang1/1000022317.md) | Désélectionne tous les champs lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdDo](../WDLang1/1000022327.md) | Exécute une action (définie par programmation) avec support du Undo/Redo. |
| [&lt;Fenêtre&gt;.EdRedo](../WDLang1/1000022328.md) | Exécute la dernière action annulée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdRestaure](../WDLang1/1000022329.md) | Annule toutes les modifications effectuées par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdSauve](../WDLang1/1000022330.md) | Sauve les modifications réalisées en mode "Modification de l'UI par l'utilisateur final". |
| [&lt;Fenêtre&gt;.EdSelect](../WDLang1/1000022331.md) | Renvoie l'un des champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdSelectMoins](../WDLang1/1000022332.md) | Dé-sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdSelectOccurrence](../WDLang1/1000022333.md) | Indique le nombre de champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdSelectPlus](../WDLang1/1000022334.md) | Sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [&lt;Fenêtre&gt;.EdUndo](../WDLang1/1000022335.md) | Annule la dernière action effectuée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
