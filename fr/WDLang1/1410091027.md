
## &lt;Menu&gt;.AjouteMenuNavigateur (Fonction)

***En anglais : &lt;Menu&gt;.AddMenuBrowser***

<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un nouveau menu dans un menu existant. Ce nouveau menu peut exécuter une procédure navigateur passée en paramètre.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Ajoute un nouveau menu en autorisant la sélection de l'option du menu
_Menu.AjouteMenuNavigateur("MNU_Dates", "Date", AfficheDate)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`(<Option>, <Position>) = <Menu d'origine>.AjouteMenuNavigateur(<Menu à ajouter> , <Libellé> , <Procédure navigateur WLangage> [, <Paramètre>])`
---

**`<Option> : (Chaîne de caractères)`**

Option ajoutée dans le menu parent. Si l'ajout de l'option n'a pas été effectué, une erreur fatale est affichée.

**`<Position> : (Chaîne de caractères)`**

Position de l'option dans le menu parent. Si l'ajout de l'option n'a pas été effectué, une erreur fatale est affichée.

**`<Menu d'origine> : (Nom de champ)`**

Nom du menu (déroulant ou contextuel) dans lequel le nouveau menu doit être ajouté.

**`<Menu à ajouter> : (Chaîne de caractères)`**

Nom du menu à ajouter. Ce nom sera utilisé pour manipuler le menu par programmation. Si ce nom correspond à un menu existant, une erreur fatale sera affichée.

**`<Libellé> : (Chaîne de caractères)`**

Libellé du nouveau menu. Ce libellé sera affiché dans la page.

**`<Procédure navigateur WLangage> : (Nom de procédure)`**

Nom de la procédure navigateur WLangage exécutée lorsque le menu est sélectionné.

**`<Paramètre> : (Variant optionnel)`**

Paramètre pouvant être passé à la procédure &lt;Procédure navigateur WLangage&gt; lorsque le menu est sélectionné par l'utilisateur.
