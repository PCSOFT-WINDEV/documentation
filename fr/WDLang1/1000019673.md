


## dFusionne (Fonction)

***En anglais : dAlphaBlend***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Fusionne une image dans une autre image. Il est ainsi possible de créer des effets de fondu entre 2 images. Cette fonction manipule aussi bien : 

- les champs Image, 

- les variables de type [Image](../WDLang1/1000019650.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) les variables de type [WDPic](../WDLang1/1000023503.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) les variables de type [picCalque](../WDLang1/1000024604.md).






![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Déclaration de l'image de promo
MonImagePromo est une Image = "ImagePromo.png"

// Fusion de l'image de promo dans l'image du produit avec une opacité à 80 %
dFusionne(IMG_PRODUIT, MonImagePromo, 80)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`dFusionne(<Image Destination> , <Image Source> [, <Opacité>])`
---

**`<Image Destination> : (Champ Image ou variable de type Image, WDPic ou picCalque)`**

Image dans laquelle la fusion doit être effectuée. Cette image peut correspondre : 

- au nom d'un champ Image. 

- au nom d'une variable de type [Image](../WDLang1/1000019650.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) au nom d'une variable de type [WDPic](../WDLang1/1000023503.md). Seul le calque d'arrière-plan sera manipulé. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) au nom d'une variable de type [picCalque](../WDLang1/1000024604.md).


Lors de la fusion, cette image sera considérée comme l'image d'arrière-plan.

**`<Image Source> : (Champ Image ou variable de type Image, WDPic ou picCalque)`**

Image à fusionner. Cette image peut correspondre : 

- au nom d'un champ Image. 

- au nom d'une variable de type [Image](../WDLang1/1000019650.md). 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) au nom d'une variable de type [WDPic](../WDLang1/1000023503.md). Seul le calque d'arrière-plan sera manipulé. 

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) au nom d'une variable de type [picCalque](../WDLang1/1000024604.md).




**`<Opacité> : (Réel optionnel)`**

Pourcentage d'opacité à appliquer sur &lt;Image Source&gt; avant d'effectuer la fusion (100% par défaut, aucune opacité n'est appliquée). 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La taille de l'image destination correspond à la taille de référence.

- La fonction **dFusionne** effectue la fusion en conservant la couche alpha de l'image destination. La couche alpha de l'image source n'est donc pas utilisée.
