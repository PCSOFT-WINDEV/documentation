


## &lt;Variable FichierDisque&gt;.Ferme (Fonction)

***En anglais : &lt;DiskFile variable&gt;.Close***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ferme un fichier externe.

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Fichier manipulé>.Ferme()`
---

**`<Résultat> : (Entier)`**



- 0 si le fichier externe est fermé, 

- -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*. La fonction **&lt;Variable FichierDisque&gt;.Ferme** génère une erreur si le fichier n'est pas ouvert.




**`<Fichier manipulé> : (Variable de type FichierDisque)`**

Nom de la variable de type [FichierDisque](../WDLang1/1410088883.md) initialisée avec la fonction [&lt;Variable FichierDisque&gt;.Ouvre](../WDLang1/1410090197.md) ou [&lt;Variable FichierDisque&gt;.Crée](../WDLang1/1410090211.md).
![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Non disponible.![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre doit être de type variant.

## Remarques


### Fermeture d'un fichier ouvert plusieurs fois
<a name="fermeture_fichier_ouvert_plusieurs_fois_ELTPARAGRAPHE000260"></a>Il est possible d'ouvrir un même fichier plusieurs fois en même temps. Chaque version du fichier doit être fermée individuellement par son propre identifiant.
<a name="NOTE0_2"></a>
![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png) 

### Fermeture d'un fichier bloqué
<a name="fermeture_fichier_bloque_ELTPARAGRAPHE000272"></a>Un fichier bloqué sera automatiquement débloqué lors de sa fermeture.

**Rappel** : La fonction [&lt;Variable FichierDisque&gt;.Bloque](../WDLang1/1410089037.md) permet de bloquer un fichier externe. La fonction [&lt;Variable FichierDisque&gt;.Débloque](../WDLang1/1410089040.md) permet de débloquer un fichier externe.
