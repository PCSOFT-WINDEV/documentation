


## &lt;Variable Commande&gt;.Exécute (Fonction)

***En anglais : &lt;Command variable&gt;.Execute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Exécute une commande en mode console. Cette commande a été définie par une variable de type [Commande](../WDLang1/1410090491.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter.Exécutable = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")

// Exécution de la commande 
MaCommandeAExécuter.Exécute(Faux)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Commande>.Exécute([<Bloquant>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la commande a été exécutée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.




**`<Commande> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande à exécuter en mode console.

**`<Bloquant> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (valeur par défaut) pour un fonctionnement bloquant : l'application est bloquée tant que la commande n'est pas exécutée. 

- <u><u><u><u>Faux</u></u></u></u> pour un fonctionnement non bloquant (asynchrone) : l'application continue de s'exécuter sans attendre la fin de l'exécution de la commande.
