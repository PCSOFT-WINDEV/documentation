


## &lt;Table&gt;.IndiceColonne (Fonction)

***En anglais : &lt;Table&gt;.ColumnIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'indice d'une colonne dans un champ Table ou Table hiérarchique.

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
// Indice de la colonne "Réf" du champ Table "TABLE_Produit"
// L'ordre d'affichage est pris en compte
ResIndiceColonne = TABLE_Produit.IndiceColonne("Réf", ticAffichage)
```


<a name="Exemple2"></a>
![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Ajax](https://doc.pcsoft.fr/ext/images/fr/AJAX.png)

// Indice de la colonne "Réf" du champ Table "TABLE_Produit"

<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = <Champ Table>.IndiceColonne(<Colonne> , <Ordre>)`
---

**`<Résultat> : (Entier)`**

Indice de la colonne : 

- La première colonne possède l'indice 1. 

- Les colonnes invisibles sont également listées.




**`<Champ Table> : (Nom de champ)`**

Nom du champ Table ou Table hiérarchique à manipuler.

**`<Colonne> : (Chaîne de caractères)`**

Nom de la colonne à manipuler.

**`<Ordre> : (Constante de type Entier)`**

Indique l'ordre des colonnes considérées :


|   |   |
| --- | --- |
| *ticAffichage* | Ordre d'affichage des colonnes en exécution. |
| *ticCréation* | Ordre de création des colonnes lors de la description du champ Table. |


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Ce paramètre est optionnel. Par défaut, la constante utilisée par défaut est *ticCréation* : l'ordre de création des colonnes est pris en compte.

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000253"></a>La fonction **&lt;Table&gt;.IndiceColonne** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.

- un champ Table ou Table hiérarchique par programmation.

- un champ monosélection ou multisélection.
	![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode "Serveur".

- ![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) un champ Table en mode "Serveur + AJAX", un champ Table en mode "Serveur" et un champ Table hiérarchique. 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) un champ Table en mode "Navigateur".
	![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Le champ Table hiérarchique n'est pas disponible.
