
## AppliOuvreFiche (Fonction)

***En anglais : AppOpenForm***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre : 

- la fiche d'une application sur le market Android (Play Store) ou iOS (App Store) pour que l'utilisateur puisse la noter et/ou la commenter.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) la fiche de paramétrage des achats In-App d'une application.

## Exemple

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
```wl
// Ouverture de la fiche d'une application 
AppliOuvreFiche("com.pcsoft.wm_note_de_frais")

// Ouverture de la fiche de l'application courante
AppliOuvreFiche()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`AppliOuvreFiche([<Application> [, <Type de fiche>]])`
---

**`<Application> : (Chaîne de caractères optionnelle)`**

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Nom complet de l'application pour laquelle la fiche doit être ouverte. Ce nom est de forme &lt;package&gt;.&lt;nom de l'application&gt; (exemple : com.pcsoft.wm_note_de_frais). Si ce paramètre n'est pas spécifié, la fiche de l'application courante sera ouverte.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Identifiant iTunes de l'application. Pour obtenir cet identifiant :  
**1.** Rendez vous sur [http://linkmaker.itunes.apple.com/us/](http://linkmaker.itunes.apple.com/us/). 
**2.** Saisissez le nom de l'application. Le numéro se trouve alors dans l'URL fournie. 

Par exemple, pour l'application WB Quizz de PC Soft, l'adresse est "https://itunes.apple.com/us/app/wb-quizz/id473232570?mt=8&uo=4" target="itunes_store"" et l'identifiant est **473232570**. 

**`<Type de fiche> : (Constante optionnelle de type Entier)`**

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Indique le type de fiche à ouvrir : 


|   |   |
| --- | --- |
| *ficheAchatInApp* | Ouvre la fenêtre de paramétrage des achats In-App de l'application.<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Ouvre la même fiche qu'en utilisant la constante *ficheApplication*. |
| *ficheApplication*<br>(Valeur par défaut) | Ouvre la fiche de l'application. |

## Remarques


### Conditions nécessaires
<a name="conditions_necessaires_ELTPARAGRAPHE000088"></a>L'application pour laquelle la fiche doit être ouverte doit préalablement avoir été publiée sur le store.
<a name="NOTE0_5"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000226"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **AppliOuvreFiche** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
