
## Fonctions de manipulation des variables JSON
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions suivantes permettent de manipuler le format JSON. 





|   |   |
| --- | --- |
| [JSONOuvreLecteur](../WDLang1/1410090784.md) | Crée un lecteur permettant de lire un document JSON sans le charger en mémoire.<br><br> |
| [JSONValide](../WDLang1/1410089147.md) | Teste la validité d'une chaîne au format JSON. |
| [JSONVersChaîne](../WDLang1/1000024530.md) | Convertit le contenu d'une variable de type JSON en une chaîne au format JSON. |
| [JSONVersTable](../WDLang1/1410090328.md) | Initialise le contenu d'un champ Table ou Table hiérarchique à partir d'une chaîne JSON ou d'une variable JSON. |
| [JSONVersVariant](../WDLang1/1000021052.md) | Convertit une chaîne au format JSON en une variable de type Variant. |
| [JSONVersXML](../WDLang1/1410087330.md) | Convertit une chaîne de caractères au format JSON en une chaîne de caractères au format XML. |





Remarque : Il existe également des fonctions permettant de convertir des types de variable en variable au format JSON.
