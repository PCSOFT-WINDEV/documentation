


## &lt;Multimédia&gt;.Volume (Fonction)

***En anglais : &lt;Multimedia&gt;.Volume***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie ou modifie le volume sonore du fichier multimédia joué dans un champ Multimédia. 

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Remarque** : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"
MM_Multimédia1.Joue(MonFichier)
// Fixe le son
MM_Multimédia1.Volume(50)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître le volume sonore

`<Résultat> = <Champ Multimédia>.Volume()`
---

**`<Résultat> : (Entier)`**

Volume sonore actuel (compris entre 0 et 100, 0 pour muet).

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.


<a name="SYNTAXE2"></a>

### Modifier le volume sonore

`<Résultat> = <Champ Multimédia>.Volume(<Nouveau volume>)`
---

**`<Résultat> : (Entier)`**

Volume sonore avant modification (compris entre 0 et 100, 0 pour muet).

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.

**`<Nouveau volume> : (Entier)`**

Volume sonore souhaité (compris entre 0 et 100, 0 pour muet).
