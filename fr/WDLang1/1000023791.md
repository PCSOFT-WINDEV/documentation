


## &lt;Chrono&gt;.RAZ (Fonction)

***En anglais : &lt;Chrono&gt;.Reset***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête et remet un chronomètre existant à zéro. La valeur de la durée écoulée est perdue.  


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonChrono est un chrono
...
// -- Code de clic du bouton BTN_Reinit
...
// Réinitialise le chronomètre MonChrono
MonChrono.RAZ()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Chronomètre>.RAZ()`
---

**`<Chronomètre> : (Variable de type Chrono)`**

Nom de la variable de type [Chrono](../WDLang1/1000023560.md) correspondant au chronomètre à utiliser.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Erreur
<a name="erreur_ELTPARAGRAPHE000267"></a>Si la fonction [&lt;Chrono&gt;.Début](../WDLang1/1000023788.md) n'a pas été appelée avant la fonction **&lt;Chrono&gt;.RAZ**, une erreur WLangage est affichée (erreur de type "le chronomètre n'est pas démarré").
