


## PlanningPositionDateHeure

***En anglais : SchedulerPositionDateTime***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche un champ Planning à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Planning. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Positionne le champ Planning sur la date du jour
PlanningPositionDateHeure(PLN_Planning, DateDuJour())

// Positionne le champ Planning au 20 décembre 2018
PlanningPositionDateHeure(PLN_Planning, "20181220")
```

```wl
// Renvoie la première date et heure affichée dans le champ Planning
Trace(PlanningPositionDateHeure(PLN_Planning, agDateHeure1erVisible))
// Renvoie par exemple : 20220309175800000
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Positionner le planning sur une date spécifiée

`PlanningPositionDateHeure(<Champ Planning> , <Date de début>)`
---

**`<Champ Planning> : (Nom de champ)`**

Nom du champ Planning à manipuler. Ce champ peut correspondre : 

- au champ Planning d'une fenêtre, 

- au champ Planning d'un état.




**`<Date de début> : (Chaîne de caractères ou variable de type Date)`**

Date de début de l'affichage.


<a name="SYNTAXE2"></a>

### Connaître la première date ou la dernière date affichée par le champ Planning

`<Résultat> = PlanningPositionDateHeure(<Champ Planning> [, <Date recherchée>])`
---

**`<Résultat> : (Chaîne de caractères, variable de type Date ou DateHeure)`**

Date (ou Date et Heure) affichée par le champ Planning.

**`<Champ Planning> : (Nom de champ)`**

Nom du champ Planning à manipuler. Ce champ peut correspondre : 

- au champ Planning d'une fenêtre, 

- au champ Planning d'un état.




**`<Date recherchée> : (Constante optionnelle de type Entier)`**

Type de date recherchée : 


|   |   |
| --- | --- |
| *agDateHeure1erVisible* | Première date et heure affichée dans le champ Planning (en fonction de la position de l'ascenseur).<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Non disponible. |
| *plnDateDébut* <br>(Valeur par défaut) | Première date affichée dans le champ Planning. |
| *plnDateFin* | Dernière date affichée dans le champ Planning. |
| *plnMoisEnCours* | Premier jour du mois affiché dans le champ Planning. |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Positionnement dans le champ Planning
<a name="positionnement_dans_champ_planning_ELTPARAGRAPHE000122"></a>Lors de l'utilisation de la fonction **PlanningPositionDateHeure** pour afficher une date, le champ Planning conserve vos préférences d'affichage. 

Par exemple, si le champ Planning est affiché à la semaine commençant un Lundi, la fonction **PlanningPositionDateHeure** utilisée sur la date du vendredi affiche le planning du Lundi au Dimanche pour la semaine contenant le Vendredi spécifié.
