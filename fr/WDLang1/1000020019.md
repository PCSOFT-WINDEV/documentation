
## HeureSélecteur (Fonction)

***En anglais : TimePicker***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche le sélecteur d'heure du système.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=HeureSelecteur.gif)


**Remarque** : Pour sélectionner une heure à l'aide du rouleau, il est conseillé d'utiliser directement le **masque de saisie de type "Rouleau Heure"**pour le champ de saisie de type "Heure". Ce masque de saisie est également disponible pour les applications iPhone/iPad. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
h est une Heure = HeureSélecteur()
```



```wl
HeureDébut est une Heure = "0730"
HeureSélectionnée est une Heure = HeureSélecteur(HeureDébut, Vrai, "Saisissez l'heure d'arrivée")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HeureSélecteur([<Heure initiale> [, <Mode 24 heures> [, <Titre>]]])`
---

**`<Résultat> : (Heure ou chaîne de caractères)`**



- Heure sélectionnée dans le sélecteur, 

- Chaîne vide ("") si la sélection a été annulée par l'utilisateur.




**`<Heure initiale> : (Heure ou chaîne de caractères optionnelle)`**

Heure affichée à l'ouverture du sélecteur. Si cette heure n'est pas spécifiée, le sélecteur affichera l'heure courante.

**`<Mode 24 heures> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (valeur par défaut) pour afficher l'heure au format 24 heures.

- <u><u><u><u>Faux</u></u></u></u> pour afficher l'heure au format AM/PM. 




**`<Titre> : (Chaîne de caractères optionnelle)`**

Titre à afficher dans le sélecteur. Si ce paramètre n'est pas spécifié, le titre affiché sera une représentation textuelle de l'heure affichée par le sélecteur.

## Remarques
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000187"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **HeureSélecteur** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
