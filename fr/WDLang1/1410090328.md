


## JSONVersTable (Fonction)

***En anglais : JSONToTable***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise le contenu d'un champ Table ou Table hiérarchique à partir d'une chaîne JSON ou d'une variable JSON.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Copie d'un champ Table hiérarchique vers un autre
s est une chaîne
s = TableVersJSON(TABLEH_Commandes)
JSONVersTable(TABLEH_Copie, s)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`JSONVersTable(<Champ Table> , <JSON manipulé>)`
---

**`<Champ Table> : (Nom de champ)`**

Nom du champ Table ou Table hiérarchique manipulé. 

**`<JSON manipulé> : (Chaîne de caractères ou variable de type JSON)`**



- Chaîne de caractères contenant le JSON correspondant au contenu du champ Table ou Table hiérarchique. 

- Variable de type JSON correspondant au contenu du champ Table ou Table hiérarchique.
