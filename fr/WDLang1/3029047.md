
## gPolice (Fonction)

***En anglais : gFont***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Construit une séquence de caractères décrivant la police d'affichage à utiliser pour le texte.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) **Dans une fenêtre**, cette chaîne permet de décrire la police d'affichage du texte :  

- dans un élément d'un champ Liste ou d'un champ Combo.

- dans la barre de titre et/ou de message d'une fenêtre. 

- dans un champ Libellé. 
	Remarque : Il peut être nécessaire de recadrer ce libellé après la définition de son contenu.









<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png) 
```wl
// Ecrit le mot "Poussin" en arial
ListeAjoute(LISTE_Animaux, gPolice("Arial") + "Poussin")
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = gPolice(<Nom de la police> [, <Alphabet utilisé>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Séquence de caractères décrivant la police d'affichage à utiliser pour le texte. 

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette séquence de caractères peut être : 

- utilisée dans les fonctions [ListeAjoute](../WDLang1/3049004.md), [ListeInsère](../WDLang1/3049002.md) ou [ListeModifie](../WDLang1/3049009.md).

- affectée à un champ Libellé. 

- utilisée dans la barre de titre ou de message d'une fenêtre. 


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.

**`<Nom de la police> : (Chaîne de caractères)`**

Nom exact de la police voulue. Si ce paramètre correspond à une chaîne vide (""), la fonction **gPolice** n'a aucun effet.

**`<Alphabet utilisé> : (Constante optionnelle de type Entier)`**

Constante correspondant à l'alphabet à utiliser. Si ce paramètre n'est pas précisé, l'alphabet utilisé sera l'alphabet par défaut de l'élément manipulé.  


|   |   |
| --- | --- |
| *alphabetAnsi* | Caractères romains à la norme ANSI |
| *alphabetArabe* | Caractères arabes |
| *alphabetBalte* | Caractères baltes |
| *alphabetChinois* | Caractères chinois (République Populaire de Chine) |
| *alphabetChinoisTraditionnel* | Caractères chinois traditionnel (République de Taïwan) |
| *alphabetCoréen* | Caractères coréens |
| *alphabetDéfaut* | Utilise l'alphabet par défaut du poste. Aucun alphabet n'est forcé. |
| *alphabetEuropeEst* | Caractères d'Europe de l'est (polonais, ...) |
| *alphabetGrec* | Caractères grecs |
| *alphabetHébreu* | Caractères hébreux |
| *alphabetJaponais* | Caractères japonais |
| *alphabetMac* | Caractères à la norme Mac Roman (utilisés sur les vieilles versions de Macintosh). |
| *alphabetOccidental* | Caractères romains à la norme ANSI |
| *alphabetRusse* | Caractères russes |
| *alphabetThaï* | Caractères thaï |
| *alphabetTurc* | Caractères turques |
| *alphabetVietnamien* | Caractères vietnamiens |


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Ce paramètre est ignoré.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La police par défaut est rétablie à la fin de l'appel à cette fonction.

- Toutes les autres caractéristiques de la police sont conservées (Gras, ...).
