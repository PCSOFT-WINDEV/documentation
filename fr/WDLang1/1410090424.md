
## Fonctions de gestion du champ Editeur de code (syntaxe préfixée)

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


Les fonctions permettant de gérer les champs Editeur de code (via une syntaxe préfixée) sont les suivantes : 



|   |   |
| --- | --- |
| [&lt;Editeur de code&gt;.Charge](../WDLang1/1410090411.md) | Charge un fichier de code WLangage dans un champ Editeur de code. |
| [&lt;Editeur de code&gt;.Commente](../WDLang1/1410090412.md) | Commente la sélection en cours dans le champ Editeur de code. Les caractères "//" sont ajoutés devant la ligne en cours. |
| [&lt;Editeur de code&gt;.Compile](../WDLang1/1410090413.md) | Compile le code WLangage affiché dans le champ Editeur de code et affiche les potentielles erreurs. |
| [&lt;Editeur de code&gt;.Décommente](../WDLang1/1410090414.md) | Décommente la sélection en cours dans le champ Editeur de code. Les caractères "//" présents devant la ligne en cours sont supprimés. |
| [&lt;Editeur de code&gt;.DupliqueLigne](../WDLang1/1410090415.md) | Duplique la ligne courante dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.Exécute](../WDLang1/1410090416.md) | Exécute le code WLangage affiché dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.Insère](../WDLang1/1410090417.md) | Insère une chaîne de caractères dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.Recherche](../WDLang1/1410090418.md) | Recherche une chaîne de caractères ou une expression régulière dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.RécupèreErreur](../WDLang1/1410090419.md) | Permet de récupérer l'erreur de compilation du code présent dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.Remplace](../WDLang1/1410090420.md) | Recherche et remplace une chaîne de caractères dans le champ Editeur de code. |
| [&lt;Editeur de code&gt;.Sauve](../WDLang1/1410090421.md) | Sauve le contenu d'un champ Editeur de code dans un fichier. |
| [&lt;Editeur de code&gt;.SupprimeTout](../WDLang1/1410090422.md) | Supprime le contenu du champ Editeur de code. |
