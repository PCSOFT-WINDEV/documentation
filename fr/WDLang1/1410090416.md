


## &lt;Editeur de code&gt;.Exécute (Fonction)

***En anglais : &lt;Code editor&gt;.Execute***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Exécute le code WLangage affiché dans le champ Editeur de code.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécute le code présent dans le champ Éditeur de code
EDCODE_Exemple.Exécute()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Champ Editeur de code>.Exécute()`
---

**`<Résultat> : (Chaîne de caractères)`**

Valeur renvoyée par le code WLangage affiché dans le champ Editeur de code (à l'aide du mot-clé RENVOYER).

**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Attention : Si le code WLangage affiché dans le champ Editeur de code ne compile pas, il ne sera pas exécuté. Aucune erreur ne sera affichée.
