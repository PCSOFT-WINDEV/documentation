
## EnModeRecyclage (Fonction)

***En anglais : InRecycleMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Identifie si le mode "Recyclage des sessions prélancées" est activé dans les options du projet. 

Remarque :  Le mode "Recyclage des sessions prélancées" est disponible uniquement pour les Webservices. Ce mode correspond à l'utilisation spécifique des sessions prélancées. Pour plus de détails, consultez [Les sessions prélancées](../WDLang2/1000019485.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI EnModeRecyclage() ALORS
	// Remise à zéro des variables.
	bAuthentifié = Faux
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EnModeRecyclage()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le mode "Recyclage des sessions prélancées" est activé dans les options du projet. 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 










<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Disponibilité de la fonction
<a name="disponibilite_fonction_ELTPARAGRAPHE000170"></a>La fonction **EnModeRecyclage** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeRecyclage** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
<a name="NOTE0_2"></a>


### Exécution des traitements contenant des erreurs de compilation
<a name="execution_des_traitements_contenant_des_erreurs_compilation_ELTPARAGRAPHE000186"></a>Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.

Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
