
## SysEspace (Fonction)

***En anglais : SysSpace***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie l'espace mémoire physique du poste en cours.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Renvoie l'espace mémoire physique du poste serveur.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Cette fonction permet de connaître uniquement l'espace libre ou total sur la carte de stockage (zone de stockage externe primaire). 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Connaître l'espace mémoire physique
ResEspMémoire = SysEspace()
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = SysEspace([<Type de mémoire>])`
---

**`<Résultat> : (Entier)`**

Espace demandé (en octets) du poste en cours (ou du poste serveur).

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Si la carte de stockage n'est pas disponible ou absente, la fonction **SysEspace** renvoie 0.

**Remarque** : La fonction **SysEspace** retourne un entier sur 8 octets si la taille demandée est supérieure à 2 Go.

**`<Type de mémoire> : (Constante optionnelle de type entier)`**

Type de mémoire à renvoyer :


|   |   |
| --- | --- |
| *sysEspaceProgramme*<br>(Valeur par défaut) | Espace mémoire physique.<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Cette constante n'est pas disponible. |
| *sysEspaceProgrammeLibre* | Espace mémoire physique inutilisé.<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Cette constante n'est pas disponible. |
| *sysEspaceStockage* | Espace utilisé pour le stockage<br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette constante n'est pas disponible. |
| *sysEspaceStockageLibre* | Espace libre pour le stockage<br><br><br>![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette constante n'est pas disponible. |
