


## &lt;Variable Commande&gt;.AjouteOption (Fonction)

***En anglais : &lt;Command variable&gt;.AddOption***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute une option à la commande à exécuter en mode console. 

Remarque : Par défaut, l'indicateur d'option correspond à : 

- '/' sous Windows, 

- '-' sous Linux.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande 
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Commande>.AjouteOption(<Clé> , <Valeur> [, <Séparateur>])`
---

**`<Commande> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande à manipuler.

**`<Clé> : (Chaîne de caractères)`**

Clé de la nouvelle option.

**`<Valeur> : (Chaîne de caractères)`**

Valeur de la nouvelle option.

**`<Séparateur> : (Chaîne de caractères optionnelle)`**

Séparateur à utiliser entre la clé et la valeur. Par défaut, le séparateur est '=' (afin de pouvoir être utilisé avec la fonction [LigneCommande](../WDLang1/3013051.md)).
