
## iaInfoModèleChat (Type de variable)

***En anglais : iaInfoModèleChat***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **iaInfoModèleChat** permet de définir toutes les caractéristiques avancées d'une connexion au modèle d'IA utilisé par le champ Chat IA. Les caractéristiques de cette connexion peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
monIA est un iaInfoModèleChat
monIA.Fournisseur = iafournisseurPersonnalisé
monIA.Protocole = iaProtocoleOpenAI
monIA.Adresse = "localhost:11434"
CHATIA_ChatIA.IAInfoModèle = monIA
```

<a name="PROPS"></a>

## Propriétés


### Propriétés spécifiques à la description des variables de type iaInfoModèleChat 
<a name="proprietes_specifiques_description_des_variables_type_iainfomodelechat_ELTPARAGRAPHE000025"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une connexion à un modèle d'IA lié au champ Chat IA :



| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Adresse | Chaîne de caractères | Adresse du serveur qui fournit un moteur d'IA. <br><br>Cette propriété est nécessaire uniquement lors de l'utilisation d'un fournisseur spécialisé. |
| Fournisseur | Constante de type Entier | Type de modèle d'IA : <br><br>- *iafournisseurAnthropic* : fournisseur Anthropic (Claude)<br><br>- *iafournisseurAucun* : aucun fournisseur n'est défini. Si cette constante est indiquée, le champ Chat IA ne fonctionne plus.  Cette constante permet par exemple de désactiver l'utilisation de l'IA. <br><br>- *iafournisseurGoogle* : fournisseur Google (Gemini)<br><br>- *iafournisseurMistral* : fournisseur Mistral AI (Le chat)<br><br>- *iafournisseurOpenAI* : fournisseur OpenAI (ChatGPT)<br><br>- *iafournisseurOpenRouteur* : fournisseur OpenRouteur<br><br>- *iafournisseurPersonnalisé* : un fournisseur personnalisé est utilisé. Il est alors nécessaire de spécifier toutes les caractéristiques de la connexion. <br><br>- *iafournisseurXAI* : fournisseur xAI (Grok)<br><br><br> |
| Identifiant | Chaîne de caractères | Clé d'API à utiliser. <br><br>Cette propriété est nécessaire notamment pour utiliser un fournisseur externe.<br><br>Dans le cas d'un fournisseur personnalisé, cette propriété n'est pas obligatoire. |
| Nom | Chaîne de caractères | Nom du modèle utilisé. <br><br>Par exemple : "deepseek-r1:1.5b" |
| Protocole | Constante de type Entier | Permet de spécifier un protocole de discussion avec le moteur d'IA si la propriété Fournisseur correspond à la constante *iafournisseurPersonnalisé*. <br><br>Cette propriété peut correspondre à une des constantes suivants : <br><br>- *iaProtocoleOpenAI* : Protocole OpenAI. <br><br>- *iaProtocoleAnthropic* : Protocole Anthropic.<br><br>- *iaProtocoleGoogle* : Protocole Google.<br><br>- *iaProtocoleOpenRouter* : Protocole OpenRouter.<br><br>- *iaProtocoleMistral* : Protocole Mistral.<br><br>- *iaProtocoleXAI* : Protocole XAI.<br><br><br> |
