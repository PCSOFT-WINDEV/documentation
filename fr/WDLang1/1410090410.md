
## Fonctions de gestion du champ Editeur de code
			

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion du champ Editeur de code (syntaxe préfixée)](../WDLang1/1410090424.md)).



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de manipuler le champ Editeur de code sont les suivantes : 



|   |   |
| --- | --- |
| [EditeurCodeCharge](../WDLang1/1410090372.md) | Charge un fichier de code WLangage dans un champ Editeur de code. |
| [EditeurCodeCommente](../WDLang1/1410090247.md) | Commente la sélection en cours dans le champ Editeur de code. Les caractères "//" sont ajoutés devant la ligne en cours. |
| [EditeurCodeCompile](../WDLang1/1410090249.md) | Compile le code WLangage affiché dans le champ Editeur de code et affiche les potentielles erreurs. |
| [EditeurCodeDécommente](../WDLang1/1410090248.md) | Décommente la sélection en cours dans le champ Editeur de code. Les caractères "//" présents devant la ligne en cours sont supprimés. |
| [EditeurCodeDupliqueLigne](../WDLang1/1410090252.md) | Duplique la ligne courante dans le champ Editeur de code. |
| [EditeurCodeExécute](../WDLang1/1410090253.md) | Exécute le code WLangage affiché dans le champ Editeur de code. |
| [EditeurCodeInsère](../WDLang1/1410090254.md) | Insère une chaîne de caractères dans le champ Editeur de code. |
| [EditeurCodeRecherche](../WDLang1/1410090250.md) | Recherche une chaîne de caractères ou une expression régulière dans le champ Editeur de code. |
| [EditeurCodeRécupèreErreur](../WDLang1/1410090257.md) | Permet de récupérer l'erreur de compilation du code présent dans le champ Editeur de code. |
| [EditeurCodeRemplace](../WDLang1/1410090251.md) | Recherche et remplace une chaîne de caractères dans le champ Editeur de code. |
| [EditeurCodeSauve](../WDLang1/1410090245.md) | Sauve le contenu d'un champ Editeur de code dans un fichier. |
| [EditeurCodeSupprimeTout](../WDLang1/1410090256.md) | Supprime le contenu du champ Editeur de code. |
