
## ChatIAChargeConversation (Fonction)

***En anglais : AIChatLoadConversation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Charge une conversation dans un champ Chat IA. Cette conversation a été précédemment enregistrée via la fonction [ChatIASauveConversation](../WDLang1/1410091364.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Bouton "Charger une conversation"
ChatIAChargeConversation(CHATIA_MonChat, "Conversation1.json")
SI ErreurDétectée ALORS
	Erreur()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = ChatIAChargeConversation(<Champ Chat IA> , <Conversation>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la conversation a été chargée. 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [ErreurInfo](../WDLang1/3013008.md) permet de connaître la cause de l'erreur.




**`<Champ Chat IA> : (Nom de champ)`**

Nom du champ Chat IA manipulé. 

**`<Conversation> : (Chaîne de caractères ou Buffer)`**

Conversation à charger. Cette conversation peut correspondre : 

- au chemin complet où relatif du fichier contenant la conversation.  

- à un buffer. 


La conversation a été précédemment enregistrée via la fonction [ChatIASauveConversation](../WDLang1/1410091364.md).
