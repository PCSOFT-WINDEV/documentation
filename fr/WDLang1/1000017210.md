


## MultimédiaPosition (Fonction)

***En anglais : MultimediaPosition***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie ou modifie la position en cours du fichier multimédia en cours dans le champ Multimédia.
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) **Remarque** : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"
MultimédiaJoue(MM_Multimédia1, MonFichier)
// Positionne à 10 secondes du début du fichier
MultimédiaPosition(MM_Multimédia1, 10000) 
MultimédiaArrêt(MM_Multimédia1)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître la position dans le fichier

`<Résultat> = MultimédiaPosition(<Champ Multimédia>)`
---

**`<Résultat> : (Entier)`**

Position actuelle dans le fichier exprimée en millisecondes.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.  


<a name="SYNTAXE2"></a>

### Modifier la position dans le fichier

`<Résultat> = MultimédiaPosition(<Champ Multimédia> , <Nouvelle position>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le positionnement demandé a été effectué, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).


![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Remarque : La fonction [ErreurInfo](../WDLang1/3013008.md) n'est pas disponible.

**`<Champ Multimédia> : (Nom de champ)`**

Nom du champ Multimédia à manipuler.

**`<Nouvelle position> : (Entier ou Durée)`**

Nouvelle position dans le fichier multimédia, exprimée en millisecondes. Ce paramètre peut correspondre à : 

- un entier correspondant au nombre de millisecondes, 

- une variable de type Durée, 

- l'indication directe de la durée (par exemple 1 s ou 10 ms).
