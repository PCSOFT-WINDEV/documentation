


## &lt;Variable WDPic&gt;.DessineCorde (Fonction)

***En anglais : &lt;WDPic variable&gt;.DrawChord***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Dessine une corde de cercle (intersection d'une ellipse et d'une droite) dans une variable de type [WDPic](../WDLang1/1000023503.md).

![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonImage est un WDPic = "Test.bmp"
// Dessin dans une variable WDPic d'une corde de cercle dont le 
// fond est jaune clair et le bord bleu clair
MonImage.DessineCorde(10, 10, 50, 50, 20, 20, 40, 50, JauneClair, BleuClair)

IMG_MonDessin = MonImage
```

<a name="SYNTAXE1"></a>

## Syntaxe

### Dessiner une corde en précisant toutes les coordonnées du rectangle contenant la corde

`<Image WDPic>.DessineCorde(<X1> , <Y1> , <X2> , <Y2> , <X3> , <Y3> , <X4> , <Y4> [, <Couleur du fond> [, <Couleur du trait>]])`
---

**`<Image WDPic> : (Variable de type WDPic)`**

Nom de la variable de type [WDPic](../WDLang1/1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.

**`<X1> : (Entier)`**

Abscisse du coin haut gauche du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<Y1> : (Entier)`**

Ordonnée du coin haut gauche du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<X2> : (Entier)`**

Abscisse du coin bas droit du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<Y2> : (Entier)`**

Ordonnée du coin bas droit du rectangle dans lequel le cercle est inscrit. Ces coordonnées sont exprimées en pixels.

**`<X3> : (Entier)`**

Abscisse du point de départ de la corde de cercle. Ces coordonnées sont exprimées en pixels.

**`<Y3> : (Entier)`**

Ordonnée du point de départ de la corde de cercle. Ces coordonnées sont exprimées en pixels.

**`<X4> : (Entier)`**

Abscisse du point d'arrivée de la corde de cercle. Ces coordonnées sont exprimées en pixels.

**`<Y4> : (Entier)`**

Ordonnée du point d'arrivée de la corde de cercle. Ces coordonnées sont exprimées en pixels.

**`<Couleur du fond> : (Entier ou constante (optionnel))`**

Couleur du fond de la corde de cercle. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) une variable de type [Couleur](../WDLang1/1000019661.md).




Si ce paramètre n'est pas précisé, la couleur du fond :

- est *Transparent* si la fonction [&lt;Variable WDPic&gt;.Fond](../WDLang1/1000024481.md) n'a pas été utilisée auparavant,

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Variable WDPic&gt;.Fond](../WDLang1/1000024481.md).




**`<Couleur du trait> : (Entier ou constante (optionnel))`**

Couleur du trait de la corde du cercle. Cette couleur peut correspondre à :

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) une variable de type [Couleur](../WDLang1/1000019661.md).

	Dans le cas d'une variable de type [Image](../WDLang1/1000019650.md), la ligne aura la couleur noire. 

- correspond à la couleur précisée dans le dernier appel à la fonction [&lt;Variable WDPic&gt;.Stylo](../WDLang1/1000024636.md).

## Remarques


### Limites
<a name="limites_ELTPARAGRAPHE000665"></a>

- La fonction **&lt;Variable WDPic&gt;.DessineCorde** n'est pas disponible en mode Anti-aliasing (pour plus de détails, consultez l'aide de la fonction [&lt;Variable WDPic&gt;.ChangeMode](../WDLang1/1000024405.md)).

- La fonction **&lt;Variable WDPic&gt;.DessineCorde** n'est pas disponible en cas de dessin avec gestion du canal alpha (pour plus de détails, consultez l'aide de la fonction [&lt;Variable WDPic&gt;.DébutDessin](../WDLang1/1000024471.md)). Cette fonction n'a aucun effet.



<a name="NOTE0_2"></a>


### Coordonnées
<a name="coordonnees_ELTPARAGRAPHE000692"></a>Si ***les points de départ et d'arrivée*** ne sont pas situés sur le bord du cercle (ou de l'ellipse), le point pris en compte est l'intersection du cercle et de la droite joignant le point précisé et le centre du rectangle (c'est-à-dire le centre du cercle).<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=RbCorde.gif)
Les coordonnées sont indiquées par rapport au coin haut gauche du champ Image (coordonnées (0,0)).
<a name="NOTE0_3"></a>


### Figure pleine
<a name="figure_pleine_ELTPARAGRAPHE000704"></a>La fonction **&lt;Variable WDPic&gt;.DessineCorde** permet uniquement de dessiner une corde : contour uniquement ou zone de la corde. Pour dessiner une figure pleine (portion délimitée par le centre du cercle et les deux points sur le cercle), utilisez la fonction [&lt;Variable WDPic&gt;.DessinePortion](../WDLang1/1000024562.md).

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000804"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".


![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) **Limitation pour la fonction &lt;Variable WDPic&gt;.DessineCorde** : L'opacité définie avec la fonction [&lt;Variable WDPic&gt;.Fond](../WDLang1/1000024481.md) n'est pas prise en compte.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000828"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
