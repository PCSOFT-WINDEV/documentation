


## &lt;Saisie&gt;.OccurrenceJeton (Fonction)

***En anglais : &lt;Edit&gt;.TokenCount***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le nombre de jetons présents dans un champ de saisie de type "Jetons de texte".
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Mise à jour du libellé
LIB_Info = "Nb de destinataire : " + SAI_Destinataire.OccurrenceJeton()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Champ de saisie>.OccurrenceJeton()`
---

**`<Résultat> : (Entier)`**

Nombre de jetons associé au champ de saisie.

**`<Champ de saisie> : (Nom de champ)`**

Nom du champ de saisie de type "Jetons de texte".



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si les doublons sont autorisés dans le champ de saisie de type "Jetons de texte", le nombre de jetons renvoyé prend en compte les doublons. 

- Une erreur est affichée si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](../Proprietes/1000023782.md) vaut <u><u><u><u>Faux</u></u></u></u>). 

- La propriété [ValeurMémorisée](../Proprietes/2510127.md) du champ de saisie renvoie les valeurs mémorisées des jetons du champ séparées par le caractère &lt;RC&gt; (Retour Chariot).
