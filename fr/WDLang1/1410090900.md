


## Fonctions Bouton segmenté
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions permettant de gérer les champs Bouton segmenté sont les suivantes :



|   |   |
| --- | --- |
| [BoutonSegmentéAjoute](../WDLang1/1410090834.md) | Ajoute une nouvelle option (c'est-à-dire un nouveau bouton) dans un champ Bouton segmenté. |
| [BoutonSegmentéInsère](../WDLang1/1410090835.md) | Insère une nouvelle option dans un champ Bouton segmenté. |
| [BoutonSegmentéSupprime](../WDLang1/1410090836.md) | Supprime une option dans un champ Bouton segmenté. |
| [BoutonSegmentéSupprimeTout](../WDLang1/1410090837.md) | Supprime toutes les options d'un champ Bouton segmenté. |
