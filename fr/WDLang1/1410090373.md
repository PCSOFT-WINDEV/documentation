
## CodeWLangageCompilation (Type de variable)

***En anglais : WLangageCodeCompiling***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **CodeWLangageCompilation** permet de définir tous les paramètres de compilation utilisés par les fonctions [Compile](../WDLang1/3013015.md), [ExécuteCode](../WDLang1/1000019783.md), [EvalueExpression](../WDLang1/1000019782.md) ainsi que le champ Éditeur de code (via l'intermédiaire de la propriété [Compilateur](../Proprietes/1410090383.md)). Les caractéristiques de ces paramètres peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ParamètresCompilation est CodeWLangageCompilation
ParamètresCompilation.FonctionsParDéfaut = ToutesLesFonctions
ParamètresCompilation.FonctionsInterdites = "fSupprime"

// Paramétrage Champ Editeur de code
EDCODE_MonChamp.Compilateur.FonctionsParDéfaut = ToutesLesFonctions
EDCODE_MonChamp.Compilateur.FonctionsInterdites = "fSupprime"


// Paramétrage fonction Compile
MonCodeSource est une chaîne = [
PROCÉDURE AdditionneXetY(aa, bb)
RENVOYER aa + bb
]
MaProc est une procédure = Compile(MonCodeSource, ParamètresCompilation)
Trace(MaProc(2, 3))
```

## Propriétés


### Propriétés spécifiques à la description des variables de type CodeWLangageCompilation
<a name="proprietes_specifiques_description_des_variables_type_codewlangagecompilation_ELTPARAGRAPHE000038"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **CodeWLangageCompilation** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| FonctionsAutorisées | Chaîne de caractères | Liste des fonctions autorisées, séparées par des RC, des virgules ou des points-virgules. <br>Exemple : <br><br><pre><code>"fOuvre" + RC + "fCrée"</code></pre><br>Remarques : <br><br>- Seuls les noms des fonctions en syntaxe classique doivent être spécifiés. Les syntaxes préfixées associées seront automatiquement prises en compte également. <br><br>- Les noms des fonctions peuvent être en français ou en anglais : les deux langues seront automatiquement prises en compte.   <br><br><br> |
| FonctionsInterdites | Chaîne de caractères | Liste des fonctions interdites, séparées par des RC, des virgules ou des points-virgules. <br>Exemple : <br><br><pre><code>"fOuvre" + RC + "fCrée"</code></pre><br>Remarques : <br><br>- Seuls les noms des fonctions en syntaxe classique doivent être spécifiés. Les syntaxes préfixées associées seront automatiquement prises en compte également. <br><br>- Les noms des fonctions peuvent être en français ou en anglais : les deux langues seront automatiquement prises en compte.   <br><br><br> |
| FonctionsParDéfaut | Constante de type Entier | Indique les fonctions disponibles par défaut :<br><br>- *ToutesLesFonctions* : Toutes les fonctions du WLangage sont disponibles par défaut. Il est possible d'interdire certains fonctions via la propriété **FonctionsInterdites**. <br><br>- *AucuneFonction* : Aucune fonction n'est disponible par défaut. Il est possible d'autoriser certains fonctions grâce à la propriété **FonctionsAutorisées**.<br><br><br> |
