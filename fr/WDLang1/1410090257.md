


## EditeurCodeRécupèreErreur (Fonction)

***En anglais : CodeEditorGetError***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Récupère la première erreur de compilation rencontrée lors de la compilation du code affiché dans le champ Editeur de code. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Compile le code présent dans le champ Éditeur de code
// et affiche les erreurs potentielles directement dans le champ
bResult est un booléen = EditeurCodeCompile(EDCODE_Exemple)
SI bResult = Vrai ALORS
	ToastAffiche("Bravo ! Votre code compile parfaitement !")
SINON
	ToastAffiche("Encore quelques petites erreurs à corriger. Vous y êtes presque !" + 
			RC + EditeurCodeRécupèreErreur(EDCODE_Exemple))
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EditeurCodeRécupèreErreur(<Champ Editeur de code>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Texte de la première erreur rencontrée lors de la compilation du code affiché dans le champ Editeur de code. 

**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.
