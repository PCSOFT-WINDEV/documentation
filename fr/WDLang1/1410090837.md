


## BoutonSegmentéSupprimeTout (Fonction)

***En anglais : SegmentedButtonDeleteAll***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Supprime toutes les options d'un champ Bouton segmenté. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
BoutonSegmentéSupprimeTout(BS_Réponses)
POUR I = 1 A nbRéponse
	BoutonSegmentéAjoute(BS_Réponses, "Réponse " + I)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`BoutonSegmentéSupprimeTout(<Champ Bouton segmenté>)`
---

**`<Champ Bouton segmenté> : (Nom de champ)`**

Nom du champ Bouton segmenté manipulé. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Lors de la suppression d'options dans un champ Bouton segmenté, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](../Proprietes/2510059.md) et [Hauteur](../Proprietes/2510050.md).
