


## &lt;Variable WDPic&gt;.FinDessin (Fonction)

***En anglais : &lt;WDPic variable&gt;.EndDrawing***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Libère les ressources associées à la variable de type [WDPic](../WDLang1/1000023503.md).
**Remarque** : L'appel de la fonction **&lt;Variable WDPic&gt;.FinDessin** est optionnel. Les ressources sont automatiquement libérées au moment de la fermeture de la fenêtre ou de la page.

![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) **Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](../WDLang1/3029035.md). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonWDPic est un WDPic = "Test.bmp"
...
// Destruction de l'image présente dans la variable de type WDPic
MonWDPic.FinDessin()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Image WDPic>.FinDessin()`
---

**`<Image WDPic> : (Variable de type WDPic)`**

Nom de la variable de type [WDPic](../WDLang1/1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Utilisation dans le cadre de la syntaxe préfixée
<a name="utilisation_dans_cadre_syntaxe_prefixee_ELTPARAGRAPHE000431"></a>La fonction [&lt;Variable WDPic&gt;.DébutDessin](../WDLang1/1000024471.md) doit être appelée avant l'utilisation des fonctions de dessin. La fonction [&lt;Variable WDPic&gt;.DébutDessin](../WDLang1/1000024471.md) permet de définir les options de dessin utilisées sur le type [WDPic](../WDLang1/1000023503.md).

La fonction **&lt;Variable WDPic&gt;.FinDessin** ne doit pas être appelée dans le même traitement que la fonction [&lt;Variable WDPic&gt;.DébutDessin](../WDLang1/1000024471.md).
Si la fonction **&lt;Variable WDPic&gt;.FinDessin** est appelée dans le même traitement que la fonction [&lt;Variable WDPic&gt;.DébutDessin](../WDLang1/1000024471.md), le dessin n'apparaîtra pas : il sera automatiquement effacé.

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000557"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".



<a name="NOTE0_4"></a>
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000579"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
