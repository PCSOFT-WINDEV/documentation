
## CaméraAffiche (Fonction)

***En anglais : CameraDisplay***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Affiche dans un champ "Caméra" la séquence vidéo actuellement retransmise par une "web caméra" ou par la caméra de l'appareil mobile.

ELTSPECIAL000015 ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)
	<B><B><B>Avertissement</B></B></B>

	 **A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS**. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affiche la séquence vidéo actuellement retransmise dans le champ "CAM_Caméra"
ResFilm = CaméraAffiche(CAM_Caméra)
SI ResFilm = Vrai ALORS
	// Affiche un libellé
	CAM_Caméra.Libellé = "En ce moment dans la cuisine"
SINON
	Erreur(ErreurInfo())
FIN
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = CaméraAffiche(<Champ Caméra>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la séquence vidéo actuellement retransmise est correctement affichée dans le champ Caméra, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Champ Caméra> : (Nom de champ)`**

Nom du champ Caméra à manipuler.  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000052"></a>

- ![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png) Pour utiliser cette fonction, une "caméra" doit être connectée au poste en cours.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette fonction nécessite un matériel équipé d'une caméra.




**Remarque** : Cette fonction est équivalente à la fonction [VidéoAffiche](../WDLang1/3079004.md). 




<a name="NOTE0_2"></a>




### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000074"></a>

- En exécution, dès l'ouverture de la fenêtre contenant le champ Caméra, la séquence vidéo retransmise par la Caméra associée s'affiche automatiquement. Dans ce cas, l'utilisation de la fonction **CaméraAffiche** n'est pas nécessaire.

- Pour arrêter l'affichage d'une séquence vidéo, utilisez la fonction [CaméraArrête](../WDLang1/1410086596.md).





![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000089"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : CAMERA.

Cette permission permet aux applications d'accéder à la caméra.
