
## SysOrientationEcran (Fonction)

***En anglais : SysScreenOrientation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de : 

- connaître l'orientation de l'écran de l'appareil (téléphone Android ou iOS).

- modifier l'orientation de l'écran de l'appareil (téléphone Android).







<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Remplir le champ Liste "LISTE_Orientations" avec les orientations possibles
ListeAjoute(LISTE_Orientations, SysListeOrientationEcran())

// Sélectionner l'orientation actuel de l'écran dans le champ Liste
LISTE_Orientations = SysOrientationEcran()
```


<a name="Exemple2"></a>


![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
```wl
// Changer l'orientation de l'écran
// L'écran sera retourné
SysOrientationEcran(Orient180)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Connaître l'orientation de l'écran

`<Résultat> = SysOrientationEcran()`
---

**`<Résultat> : (Constante de type chaîne de caractères)`**

Valeur de l'orientation actuelle de l'écran :


|   |   |
| --- | --- |
| *Orient0* | L'écran est orienté dans la direction par défaut. |
| *Orient90* | L'écran est tourné de 90° dans le sens des aiguilles d'une montre. |
| *Orient180* | L'écran est retourné de 180°. |
| *Orient270* | L'écran est tourné de 90° dans le sens inverse des aiguilles d'une montre (ou 270° dans le sens des aiguilles d'une montre). |




<a name="SYNTAXE2"></a>
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) 
### Modifier l'orientation de l'écran

`<Résultat> = SysOrientationEcran(<Orientation>)`
---

**`<Résultat> : (Constante de type chaîne de caractères)`**

Orientation de l'écran après l'appel de la fonction.

**`<Orientation> : (Constante de type chaîne de caractères)`**

Indique la nouvelle orientation de l'écran :


|   |   |
| --- | --- |
| *Orient0* | L'écran est orienté dans la direction par défaut. |
| *Orient90* | L'écran est tourné de 90° dans le sens des aiguilles d'une montre. |
| *Orient180* | L'écran est retourné de 180°. |
| *Orient270* | L'écran est tourné de 90° dans le sens inverse des aiguilles d'une montre (ou 270° dans le sens des aiguilles d'une montre). |





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Tous les appareils mobiles ne supportent pas la fonctionnalité de rotation d'écran. Quand cette fonctionnalité n'est pas disponible, la fonction **SysOrientationEcran** renvoie toujours *Orient0*.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) La modification de l'orientation n'affectera que la fenêtre en cours. 

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Selon le modèle d'appareil sur lequel est exécutée l'application (téléphone ou tablette), l'orientation par défaut (*Orient0*) peut correspondre : 

	- soit au mode portrait (le cas sur la plupart des téléphones), 

	- soit au mode paysage (le cas sur la plupart des tablettes). 




- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Pour déterminer si une application est affichée en mode portrait ou paysage, il est conseillé de comparer les valeurs renvoyées par les fonctions [SysXRes](../WDLang1/3073024.md) et [SysYRes](../WDLang1/3073006.md) : 

	- si la valeur renvoyée par la fonction [SysXRes](../WDLang1/3073024.md) est inférieure à celle renvoyée par la fonction [SysYRes](../WDLang1/3073006.md), l'application est en mode portrait, 

	- dans le cas contraire, elle est en mode paysage.
