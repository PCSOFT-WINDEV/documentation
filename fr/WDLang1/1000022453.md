
## CaméraDemandePermission (Fonction)

***En anglais : CameraRequestPermission***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Demande la permission d'utiliser la caméra de l'appareil.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI CaméraDemandePermission() = Vrai ALORS
	OuvreFenêtreMobile(FEN_Caméra)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CaméraDemandePermission()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la permission d'utiliser la caméra a été accordée,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) 

### Fonctionnement sous Android
<a name="fonctionnement_sous_android_ELTPARAGRAPHE000041"></a>

- Si la permission "CAMERA" n'a pas été ajoutée à la liste des permissions de l'application dans l'assistant de génération, la fonction **CaméraDemandePermission** retournera <u><u><u><u>Faux</u></u></u></u>.

- A partir de Android 6.0 ou supérieure, l'appel de cette fonction peut provoquer l'affichage d'une boîte de dialogue pour demander à l'utilisateur d'autoriser l'application à utiliser la caméra de l'appareil. Si l'utilisateur ne donne pas son autorisation, cette boîte de dialogue sera affichée à chaque appel de cette fonction. 







### Equivalence
<a name="equivalence_ELTPARAGRAPHE000055"></a>Cette fonction est équivalente à la fonction [VidéoDemandePermission](../WDLang1/1000022355.md).
