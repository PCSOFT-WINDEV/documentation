
## gPoliceBarrée (Fonction)

***En anglais : gFontStrikeout***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est barré ou non.

**Remarque** : Tout le texte écrit à la suite de la fonction est affecté.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Dans une fenêtre, cette séquence de caractères permet d'utiliser un texte barré (ou non) :  

- dans un élément d'un champ Liste ou Combo.

- dans la barre de titre et/ou de message d'une fenêtre. 

- dans un champ Libellé. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Affichage du titre "WINDEV, AGL n°1 (pas 2) en France." de la prochaine fenêtre
TitreSuivant("WINDEV, AGL n°" + gPoliceBarrée() + "2" + gPoliceBarrée(Faux) + "1 en France.")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = gPoliceBarrée([<Barrée>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Séquence de caractères définissant si la suite du texte doit être en barrée ou non.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette séquence de caractères peut être : 

- utilisée dans les fonctions [ListeAjoute](../WDLang1/3049004.md), [ListeInsère](../WDLang1/3049002.md) ou [ListeModifie](../WDLang1/3049009.md).

- affectée à un champ Libellé. 

- utilisée dans la barre de titre ou de message d'une fenêtre. 


![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.

**`<Barrée> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (par défaut) si le texte suivant la fonction **gPoliceBarrée** doit être en barré, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- La police par défaut est rétablie à la fin de l'appel des fonctions [gPoliceXXX](../WDLang1/3029028.md).

- Toutes les autres caractéristiques de la police sont conservées (italique, ...).
