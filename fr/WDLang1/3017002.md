


## AnimationChangeParamètre (Fonction)

***En anglais : AnimationSetParameter***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Change un des paramètres d'animation utilisé pour :

- une image animée (dans un champ Image),

- un texte animé (dans un champ Libellé).




![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Dans cette version, il est possible uniquement de changer les paramètres d'animation utilisés pour un texte animé (dans un champ Libellé).


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple

![Etats et Requêtes](https://doc.pcsoft.fr/ext/images/fr/ER.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 
```wl
// Changement des paramètres d'animation d'un champ Image
IMG_Image1.Animation = Vrai
AnimationChangeParamètre(IMG_Image1, acpAllerRetour, Vrai)
```
<a name="Exemple2"></a>

```wl
// Changement des paramètres d'animation d'un champ Libellé
LIB_MonLibellé.Animation = Vrai
AnimationChangeType(LIB_MonLibellé, actClignotement)
AnimationChangeParamètre(LIB_MonLibellé, acpDurée, 100)
AnimationChangeParamètre(LIB_MonLibellé, acpCouleur, BleuFoncé)
```

### Changer les paramètres d'animation d'une image

`AnimationChangeParamètre(<Champ Image> , <Paramètre à modifier> , <Valeur du paramètre>)`
---

**`<Champ Image> : (Chaîne de caractères)`**

Nom du champ Image à manipuler.

**`<Paramètre à modifier> : (Constante ou chaîne de caractères)`**

Nom du paramètre à modifier.


|   |   |
| --- | --- |
| *acpAllerRetour* (ou "AllerRetour") | Lecture des dessins de l'image du premier dessin au dernier, puis du dernier au premier en continu (ce paramètre est <u><u><u><u>Faux</u></u></u></u> par défaut). |
| *acpBoucle* (ou "Boucle") | Lecture des dessins de l'image du premier dessin au dernier en continu (ce paramètre est <u><u><u><u>Vrai</u></u></u></u> par défaut). |
| *acpDurée* (ou "Durée") | Temps d'affichage de chaque dessin de l'animation en millisecondes (300ms par défaut). |
| *acpInverse* (ou "Inverse") | Lecture des dessins de l'image du dernier dessin en bas à droite au premier dessin en haut à gauche (ce paramètre est <u><u><u><u>Faux</u></u></u></u> par défaut) |
| *acpNbEtape* (ou "NombreEtape") | 10 par défaut<br>**Animation de type "Défilement" uniquement.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette constante n'est pas disponible. |
| *acpNbImageX* (ou "NombreImageX") | Nombre de dessins présents dans la largeur du fichier image. En fonction du nombre indiqué, l'image sera automatiquement découpée en autant de dessins que nécessaire (1 par défaut).<br>**Animation de type "Image à animer" uniquement.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette constante n'est pas disponible. |
| *acpNbImageY* (ou "NombreImageY") | Nombre de dessins présents dans la hauteur du fichier image. En fonction du nombre indiqué, l'image sera automatiquement découpée en autant de dessins que nécessaire (1 par défaut).<br>**Animation de type "Image à animer" uniquement.**<br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette constante n'est pas disponible. |
| *acpSens* (ou "Sens") | Sens de défilement.<br>**Animation de type "Défilement" uniquement.**<br>Ces paramètres peuvent être combinés.<br><br>- 1 (par défaut) : étirement de gauche à droite<br><br>- 2 : étirement de droite à gauche<br><br>- 4 : étirement de bas en haut<br><br>- 8 : étirement de haut en bas<br><br><br>Exemple de combinaison :<br><br>- 3 (2+1) : gauche droite : élargissement progressif depuis le centre<br><br>- 5 (4+1) de bas en haut et de droite à gauche<br><br><br><br><br>![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Cette constante n'est pas disponible. |



**`<Valeur du paramètre> : (Type du paramètre attendu)`**

Nouvelle valeur du paramètre.  


<a name="SYNTAXE2"></a>

### Changer les paramètres d'animation d'un libellé

`AnimationChangeParamètre(<Champ Libellé> , <Paramètre à modifier> , <Valeur du paramètre>)`
---

**`<Champ Libellé> : (Chaîne de caractères)`**

Nom du champ Libellé à manipuler.

**`<Paramètre à modifier> : (Constante ou chaîne de caractères)`**

Nom du paramètre à modifier.


|   |   |
| --- | --- |
| *acpBoucle* (ou "Boucle") | Défilement en en continu (ce paramètre est <u><u><u><u>Vrai</u></u></u></u> par défaut).<br>**Animation de type "Défilement" uniquement.**<br> |
| *acpCouleur* (ou "Couleur") | Couleur de clignotement. Ce paramètre peut correspondre à une [constante de couleur](../WDLang5/3010002.md). Par défaut, cette couleur correspond à *Transparent*.<br>**Animation de type "Clignotement" uniquement.** |
| *acpDurée* (ou "Durée") | Temps d'affichage de chaque élément de l'animation en millisecondes (300ms par défaut). |
| *acpNbBoucleMax* (ou "NombreBoucleMax") | Nombre de boucles à effectuer pour un défilement en continu (0 nombre de boucles illimité). <br>**Animation de type "Défilement" uniquement.**<br> |
| *acpNbPixel* (ou "NombrePixel") | Nombre de pixels pour chaque pas de défilement.<br>**Animation de type "Défilement" uniquement.** |
| *acpSens* (ou "Sens") | Sens de défilement.<br>**Animation de type "Défilement" uniquement.**<br>Ces paramètres ne peuvent pas être combinés.<br><br>- 1 (par défaut) : défilement vers la gauche<br><br>- 2 : défilement vers la droite<br><br>- 4 : défilement vers le bas<br><br>- 8 : défilement vers le haut <br><br><br> |



**`<Valeur du paramètre> : (Type du paramètre attendu)`**

Nouvelle valeur du paramètre.
