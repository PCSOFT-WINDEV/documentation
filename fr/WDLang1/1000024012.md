## Syntaxe

### Dessiner un rectangle en spécifiant les coordonnées du rectangle

`<Champ Image>.DessineRectangle(<X1> , <Y1> , <X2> , <Y2> [, <Fond> [, <Trait>]])`
---

**`<Champ Image> : (Nom de champ)`**



**`<X1> : (Entier)`**

Abscisse en pixels du coin haut gauche du rectangle.

**`<Y1> : (Entier)`**

Ordonnée en pixels du coin haut gauche du rectangle.

**`<X2> : (Entier)`**

Abscisse en pixels du coin bas droit du rectangle.

**`<Y2> : (Entier)`**

Ordonnée en pixels du coin bas droit du rectangle.

**`<Fond> : (Entier, constante ou variable de type Fond (optionnel))`**



- Couleur du fond du rectangle. Cette couleur peut être :

	- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

	- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

	- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md), 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md), 

	- transparente si ce paramètre n'est pas précisé et si la fonction [&lt;Image&gt;.Fond](../WDLang1/1000023999.md) n'a pas été utilisée auparavant. 




- Caractéristiques du fond : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) variable de type [Fond](../WDLang1/1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte. 
			![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les variables de type [Fond](../WDLang1/1000022038.md) ne sont pas disponibles dans cette syntaxe. Utilisez la fonction [&lt;Variable Image&gt;.DessineCadre](../WDLang1/1000024019.md) pour personnaliser la couleur de fond.

	- caractéristiques spécifiées dans le dernier appel à la fonction [&lt;Image&gt;.Fond](../WDLang1/1000023999.md) si ce paramètre n'est pas précisé. 







Pour utiliser une couleur de fond dégradée, utilisez la fonction [&lt;Variable Image&gt;.DessineRectangleDégradé](../WDLang1/1000024238.md).

**`<Trait> : (Entier, constante ou variable de type Cadre (optionnel))`**



- Couleur du trait du rectangle. Cette couleur peut être :

	- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

	- une couleur TSL (obtenue avec la fonction [TSL](../WDLang1/3029057.md)),

	- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md),

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) une variable de type [Couleur](../WDLang1/1000019661.md), 

	- identique à la couleur utilisée pour le fond si ce paramètre n'est pas précisé et si la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) n'a pas été utilisée.  




- Caractéristiques du trait : 

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) variable de type [Cadre](../Motscles/15140100.md). Dans ce cas, seules les propriétés suivantes sont prises en compte : 

		- Couleur : si la propriété correspond à la constante *CouleurIndéfinie*, la couleur définie lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisée. Si cette fonction n'a pas été utilisée, la couleur de fond du rectangle est utilisée. 

		- Epaisseur : si la propriété correspond à la constante *EpaisseurIndéfinie*, l'épaisseur définie lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisée. Si cette fonction n'a pas été utilisée, l'épaisseur vaut 1. 

		- Trait : si la propriété correspond à *TraitIndéfini*, le type de trait défini lors du dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) est utilisé. Si cette fonction n'a pas été utilisée, le trait est un trait continu.  




- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les variables de type [Cadre](../Motscles/15140100.md) ne sont pas disponibles dans cette syntaxe. Utilisez la fonction [&lt;Variable Image&gt;.DessineCadre](../WDLang1/1000024019.md) pour personnaliser le cadre.

- caractéristiques précisées dans le dernier appel à la fonction [&lt;Image&gt;.Stylo](../WDLang1/1000024016.md) si ce paramètre n'est pas précisé.

### Dessin en PHP
<a name="dessin_php_ELTPARAGRAPHE000844"></a>En PHP, les fonctions de dessin s'appuient sur la librairie graphique GD. Cette librairie est très courante chez les hébergeurs PHP, et donc toujours activée. La version de la librairie GD devra être au moins 2.0.28. Cette librairie peut être téléchargée sur le site de PHP.

**Pour activer si nécessaire cette librairie en local**, les éléments nécessaires sont :

- PHP installé.

- le fichier PHP.INI présent dans le répertoire Windows doit avoir la ligne "extension=php_gd2.dll" et non pas ";extension=php_gd2.dll".

- le fichier php_gd2.dll doit exister dans le répertoire des extensions PHP. Ce répertoire est défini dans le fichier PHP.INI par la variable "extension_dir".

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Dessin en code Navigateur
<a name="dessin_code_navigateur_ELTPARAGRAPHE000866"></a>Certaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5.  

Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction [DessinDisponible](../WDLang1/1000019483.md). 

**Attention** : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.
Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".

**Cas particulier : Dessiner dans le navigateur d'un téléphone Android** : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
