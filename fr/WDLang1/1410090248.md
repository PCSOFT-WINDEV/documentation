


## EditeurCodeDécommente (Fonction)

***En anglais : CodeEditorUncomment***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Décommente la sélection en cours dans le champ Editeur de code. Les caractères "//" présents devant la ligne en cours sont supprimés.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Décommente le code sélectionné dans le champ Éditeur de code
EditeurCodeDécommente(EDCODE_Exemple)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`EditeurCodeDécommente(<Champ Editeur de code>)`
---

**`<Champ Editeur de code> : (Nom de champ)`**

Nom du champ Editeur de code à manipuler.
