


## SysEstAdministrateur (Fonction)

***En anglais : SysIsAdministrator***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Indique si l'utilisateur courant possède les droits d'administrateur de la machine.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI SysEstAdministrateur() = Vrai ALORS
	Info("Vous êtes administrateur de la machine.")
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = SysEstAdministrateur()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'utilisateur courant possède les droits d'administrateur de la machine,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.
