


## &lt;Fenêtre&gt;.OuvreFenêtreMobile (Fonction)

***En anglais : &lt;Window&gt;.OpenMobileWindow***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre une fenêtre dans une application mobile. 

Remarques : 

- Cette fonction remplace la fonction [&lt;Fenêtre&gt;.OuvreFille](../WDLang1/1000023904.md) utilisée pour ouvrir des fenêtres dans une application mobile. Dans cette page de documentation, seul l'aspect mobile est détaillé. Pour plus de détails, consultez [&lt;Fenêtre&gt;.OuvreFille](../WDLang1/1000023904.md).  

- La fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.


**Remarques** : 

- Par défaut, la fenêtre conserve le focus une fois ouverte.

- La fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** permet également de passer des paramètres à la fenêtre fille.

	- Lors de l'ouverture classique d'une fenêtre, ces paramètres sont spécifiés directement dans la syntaxe. 

	- Lors de l'ouverture d'une fenêtre via une variable de type [Fenêtre](../WDLang1/1410091366.md), la propriété [ParamètresOuverture](../Proprietes/1410091044.md) peut être utilisée pour passer les paramètres à la fenêtre.

Dans un site WEBDEV, cette fonction se comporte comme la fonction [&lt;Page&gt;.Affiche](../WDLang2/1000021661.md).

## Exemple


```wl
FEN_CommandeEdition.OuvreFenêtreMobile(gnIDCommande)
```
<a name="1000021018_Exemple2"></a>

```wl
MaFenMobile est une fenêtre FEN_CommandeEdition
MaFenMobile.OptionsOuverture.Titre = "Edition Commande"
MaFenMobile.ParamètresOuverture.numCommande = gnIDCommande
MaFenMobile.OuvreFenêtreMobile()
```

## Syntaxe

### Ouvrir une fenêtre (syntaxe classique)

`<Fenêtre>.OuvreFenêtreMobile([<Paramètre 1> [... [, <Paramètre N>]]])`
---

**`<Fenêtre> : (Nom de fenêtre)`**

Nom de la fenêtre mobile à ouvrir.

**`<Paramètre 1> : (Type de la valeur envoyée à la fenêtre (optionnel))`**

Premier paramètre à passer à l'événement "Déclarations globales" de la fenêtre à ouvrir. Ce paramètre est passé par valeur et il est considéré comme une variable globale à la fenêtre.
Ce paramètre ne peut pas correspondre à une variable de type tableau (les tableaux peuvent uniquement être passés par référence).



**`<Paramètre N> : (Type de la valeur envoyée à la fenêtre (optionnel))`**

Nième paramètre à passer à l'événement "Déclarations globales" de la fenêtre à ouvrir. Ce paramètre est passé par valeur et il est considéré comme une variable globale à la fenêtre.
Ce paramètre ne peut pas correspondre à une variable de type tableau (les tableaux peuvent uniquement être passés par référence).


<a name="SYNTAXE2"></a>
![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Cette syntaxe n'est disponible pour les applications Java
### Ouvrir une fenêtre (via une variable de type Fenêtre)

`<Fenêtre à ouvrir>.OuvreFenêtreMobile([<Paramètre 1> [... [, <Paramètre N>]]])`
---

**`<Fenêtre à ouvrir> : (Fenêtre)`**

Nom de la variable de type [Fenêtre](../WDLang1/1410091366.md) correspondant à la fenêtre à ouvrir.  

- Les options d'ouverture de la fenêtre ont été définies grâce à la propriété [OptionsOuverture](../Proprietes/1410091299.md). 

- La valeur des paramètres attendus par la fenêtre a été définie grâce à la propriété [ParamètresOuverture](../Proprietes/1410091044.md).




**`<Paramètre 1> : (Type de la valeur envoyée à la fenêtre (optionnel))`**

Premier paramètre à passer à l'événement "Déclarations globales" de la fenêtre à ouvrir. Ce paramètre est passé par valeur et il est considéré comme une variable globale à la fenêtre.
Ce paramètre ne peut pas correspondre à une variable de type tableau (les tableaux peuvent uniquement être passés par référence).

Remarque : La valeur des paramètres peut également être définie grâce à la propriété [ParamètresOuverture](../Proprietes/1410091044.md) utilisable avec une variable de type Fenêtre.



**`<Paramètre N> : (Type de la valeur envoyée à la fenêtre (optionnel))`**

Nième paramètre à passer à l'événement "Déclarations globales" de la fenêtre à ouvrir. Ce paramètre est passé par valeur et il est considéré comme une variable globale à la fenêtre.
Ce paramètre ne peut pas correspondre à une variable de type tableau (les tableaux peuvent uniquement être passés par référence).

Remarque : La valeur des paramètres peut également être définie grâce à la propriété [ParamètresOuverture](../Proprietes/1410091044.md) utilisable avec une variable de type Fenêtre.





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Paramètres passés à la fenêtre à ouvrir
<a name="parametres_passes_fenetre_ouvrir_ELTPARAGRAPHE000361"></a>Les paramètres sont récupérés dans l'événement "Déclarations globales" associé à la fenêtre. La première ligne de code de cet événement doit correspondre à la ligne suivante :

```txt
PROCEDURE <Fenêtre> (<Paramètre 1> [, ... [, <Paramètre N>]])
```
où : 

- &lt;Fenêtre &gt; correspond au nom de la fenêtre. 

- &lt;Paramètre N&gt; correspond aux paramètres attendus. **Attention : Ces paramètres sont passés par valeur et non par référence.**


Pour plus de détails, consultez [Fenêtre paramétrée](../WDChamp/1010026.md).


<a name="NOTE0_2"></a>


### Mode d'ouverture de la fenêtre
<a name="mode_ouverture_fenetre_ELTPARAGRAPHE000390"></a>L'ouverture de la fenêtre est non modale :

- la fenêtre ouverte devient la fenêtre en cours.

- après l'ouverture de la fenêtre, les traitements suivants l'appel de la fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** dans la fenêtre mère sont exécutés.

- l'utilisateur pourra cliquer dans l'une des fenêtres parentes de la fenêtre ouverte. 
	![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Les champs des fenêtres parentes ne sont pas accessibles par l'utilisateur tant qu'une fenêtre fille est ouverte. 



<a name="NOTE0_3"></a>


### Limitation
<a name="limitation_ELTPARAGRAPHE000411"></a>La fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** ne doit pas être appelée dans l'événement "Initialisation" associé au projet.
<a name="NOTE0_6"></a>


### Fermeture d'une fenêtre
<a name="fermeture_une_fenetre_ELTPARAGRAPHE000424"></a>Une fenêtre ouverte avec la fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** peut être fermée avec la fonction [Ferme](../WDLang1/3038018.md) (sans paramètre) à partir de n'importe quel événement de la fenêtre ou d'un champ de la fenêtre.
<a name="NOTE0_7"></a>


### Titre de la fenêtre à ouvrir
<a name="titre_fenetre_ouvrir_ELTPARAGRAPHE000442"></a>Par défaut, le titre de la fenêtre est celui défini sous l'éditeur (dans l'onglet "Général" de la fenêtre de description).

Pour modifier le titre de la fenêtre : 

- En syntaxe classique, utilisez les fonctions [TitreSuivant](../WDLang1/3038043.md) ou [TitreEnCours](../WDLang1/3038023.md).

- En utilisant une variable de type [Fenêtre](../WDLang1/1410091366.md), utilisez la propriété [OptionsOuverture](../Proprietes/1410091299.md) (**OptionsOuverture.Titre**).

### Application en arrière-plan : Spécificité à partir de Android 10
<a name="application_arriereplan_specificite_partir_android_10_ELTPARAGRAPHE000488"></a>A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. 

La fonction **&lt;Fenêtre&gt;.OuvreFenêtreMobile** peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. 

Conseils : 

- Il est possible de savoir si l'application est en arrière-plan grâce à la fonction [EnModeArrièrePlan](../WDLang1/1000023457.md). 

- Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type [Notification](../WDLang3/1000019441.md)). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété **ActiveApplication** est à <u><u><u><u>Vrai</u></u></u></u>. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété **ActionClic**.




Pour plus de détails, consultez [Android 10 : Comportement des applications en arrière-plan](../Editeurs/9000195.md).
