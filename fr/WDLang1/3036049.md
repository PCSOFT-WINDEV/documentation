
## fRepExe (Fonction)

***En anglais : fExeDir***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie le répertoire à partir duquel l'exécution est lancée.

![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Renvoie le répertoire d'exécution du projet. Ce répertoire doit normalement être accessible en lecture et en écriture. Il contient généralement les fichiers de données et les autres fichiers manipulés par le site WEBDEV.

**Attention** : La fonction **fRepExe** permet de connaître le répertoire de lancement, alors que la fonction [fRepEnCours](../WDLang1/3036022.md) permet de connaître le répertoire courant.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Répertoire de lancement
Info("Cette application a été lancée depuis " + fRepExe())
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = fRepExe()`
---

**`<Résultat> : (Chaîne de caractères)`**

Répertoire à partir duquel est lancé l'exécutable. Ce chemin ne se termine pas par le caractère "\\". 

- En mode test (GO depuis WINDEV), correspond : 

	- au répertoire de génération donné dans la description de la [configuration de projet](../Editeurs/9000030.md) courante. 

	- sinon au sous-répertoire EXE du répertoire du projet. 




- En exécution, correspond au répertoire contenant l'exécutable en cours.




![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Répertoire d'exécution du projet. En mode test et en déploiement (GO depuis WEBDEV), correspond au sous-répertoire EXE du répertoire du projet.

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Répertoire d'installation de l'application (dans la zone de stockage interne). 

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Widget IOS](https://doc.pcsoft.fr/ext/images/fr/WIDGETIOS.png)![Mac Catalyst](https://doc.pcsoft.fr/ext/images/fr/CATALYST.png) Répertoire racine de l'application (accessible en lecture seulement).

### Serveur SOAP
<a name="serveur_soap_ELTPARAGRAPHE000093"></a>La fonction **fRepExe** utilisée sur un serveur SOAP retourne le chemin du répertoire contenant la bibliothèque du serveur SOAP en cours d'exécution.

![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Code Utilisateur (MCU)](https://doc.pcsoft.fr/ext/images/fr/MCU.png) 

### Application utilisée sous Windows Vista (et supérieur) 
<a name="application_utilisee_sous_windows_vista_superieur_ELTPARAGRAPHE000105"></a>Sous Windows Vista (et supérieur), le [mécanisme de l'UAC](../Editeurs/2025014.md) entraîne certaines contraintes de développement.

Ainsi, il est recommandé pour stocker les fichiers utilisés par l'application (fichiers de données ou les fichiers INI par exemple), d'utiliser les répertoires spécifiques de l'application (au lieu du répertoire de l'exécutable). Ces répertoires sont connus par les fonctions [fRepDonnéesCommun](../WDLang1/3036070.md), [fRepDonnéesUtilisateur](../WDLang1/3036071.md), [fRepGlobalCommun](../WDLang1/3036072.md) et [fRepGlobalUtilisateur](../WDLang1/3036073.md).
