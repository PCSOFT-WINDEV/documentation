
## SysMiseEnVeille (Fonction)

***En anglais : SysStandby***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de : 

- activer et désactiver la mise en veille de l'appareil.
	**Remarque** : Le paramétrage de la mise en veille est propre à l'application : 

	- lorsque l'application est terminée, le paramétrage d'origine est restauré. 

	- lorsque l'application est mise en arrière-plan, le paramétrage d'origine est restauré. Lorsque l'application repasse en avant-plan, le paramétrage de la mise en veille est rétabli.








<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Active la mise en veille
SysMiseEnVeille(sysBatterie, sysVeilleActive)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe
<a name="SYNTAXE4"></a>

### Activer/Désactiver la mise en veille

`SysMiseEnVeille(<Mode d'alimentation> , <Mise en veille>)`
---

**`<Mode d'alimentation> : (Constante de type entier)`**

Mode d'alimentation pour lequel la gestion de la mise en veille doit être modifiée :


|   |   |
| --- | --- |
| *sysBatterie* | Gestion de la mise en veille lorsque le matériel est alimenté par la batterie. |
| *sysSecteur* | Gestion de la mise en veille lorsque le matériel alimenté via le secteur. |

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Ce paramètre est ignoré. La mise en veille s'applique à la fois sur la batterie et le secteur.

**`<Mise en veille> : (Constante de type Entier)`**

Activation ou désactivation de la mise en veille : 


|   |   |
| --- | --- |
| *sysVeilleActive* | Activation de la mise en veille. La durée d'inactivité avant le passage en mode veille dépend des paramétrages du système. |
| *sysVeilleInactive* | Désactivation de la mise en veille de l'appareil lorsque l'application passe au premier plan. |




<a name="SYNTAXE5"></a>

### Connaître le mode de mise en veille

`<Résultat> = SysMiseEnVeille(<Mode d'alimentation>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la mise en veille est activée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Mode d'alimentation> : (Constante de type entier)`**

Mode d'alimentation pour lequel la gestion de la mise en veille doit être connue :


|   |   |
| --- | --- |
| *sysBatterie* | Gestion de la mise en veille lorsque le matériel est alimenté par la batterie. |
| *sysSecteur* | Gestion de la mise en veille lorsque le matériel alimenté via le secteur. |





Ce paramètre est ignoré. La mise en veille s'applique à la fois sur la batterie et le secteur.
