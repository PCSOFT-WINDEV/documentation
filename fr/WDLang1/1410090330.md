


## AccessibilitéLecteurEcranActif (Fonction)

***En anglais : AccessibilityScreenReaderEnabled***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si le lecteur d'écran est actif.

![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Pour iOS, cette fonctionnalité correspond à "VoiceOver".

![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Pour Android, cette fonctionnalité correspond à "TalkBack". 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
AccessibilitéLecteurEcranActif(onVoiceOver)

	PROCEDURE INTERNE onVoiceOver(bActif)
		GR_Détail.Visible = PAS bActif
	FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = AccessibilitéLecteurEcranActif([<Procédure WLangage>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le lecteur d'écran est actif, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Procédure WLangage> : (Nom de procédure optionnelle)`**

Nom de la procédure WLangage permettant de savoir si le lecteur d'écran est actif et d'indiquer le changement d'état. Cette procédure est de la forme : 

```txt
PROCEDURE <Nom de la procédure>(<Activation>)
```
 ou &lt;Activation&gt; correspond à un booléen : 

- <u><u><u><u>Vrai</u></u></u></u> si le lecteur d'écran est actif, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.  


Si le nom de la procédure n'est pas spécifié, la détection du lecteur d'écran est arrêtée.
