


## &lt;Bouton segmenté&gt;.Insère (Fonction)

***En anglais : &lt;Segmented button&gt;.Insert***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Insère une nouvelle option dans un champ Bouton segmenté.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
BS_Mode.Insère(2, "Mode Avancé")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Champ Bouton segmenté>.Insère(<Indice de l'option> , <Libellé de l'option>)`
---

**`<Résultat> : (Entier)`**



- Indice de l‘option insérée. 

- -1 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Champ Bouton segmenté> : (Nom de champ)`**

Nom du champ Bouton segmenté dans lequel l'option doit être ajoutée. L'option est ajoutée à la suite des options existantes.

**`<Indice de l'option> : (Entier)`**

Indice de l'option à insérer.
Si ce paramètre :

- est supérieur au nombre d'options présentes dans le champ, l'option est ajoutée après la dernière option du champ.

- est égal à 1 ou 0, l'élément est ajouté avant la première option du champ.




**`<Libellé de l'option> : (Chaîne de caractères)`**

Libellé de l'option à insérer.
