


## TestErreur (Fonction)

***En anglais : TestError***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Provoque : 

- une assertion lors du test de l'élément ou du projet (mode Go). 

- une erreur en mode test automatique. 




Remarque : Cette fonction est équivalente à la fonction [dbgErreur](../WDLang1/1000020526.md). 
<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`TestErreur(<Commentaire 1> [, <Commentaire 2> [... [, <Commentaire N>]]])`
---

**`<Commentaire 1> : (Chaîne de caractères)`**

Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire. 

**`<Commentaire 2> : (Chaîne de caractères optionnelle)`**

Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire. 



**`<Commentaire N> : (Chaîne de caractères optionnelle)`**

Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Lorsque la fonction **TestErreur** est appelée :

	- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) en mode test automatique, une erreur est ajoutée dans le compte-rendu du test (équivalent de la fonction [TestEcritRésultat](../WDLang1/1000013001.md)).

	- en mode test manuel, une assertion est affichée (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).

	- en mode exécution, une assertion est affichée si les assertions ont été activées (équivalent de la fonction [dbgAssertion](../WDLang1/3014022.md)).




- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) Les commentaires de la fonction **TestErreur** seront écrits dans le log ADB (au niveau "Assert"). Pour plus de détails, consultez [Gestion des logs ADB](../Editeurs/9000108.md).
