
## Fonctions BitcoinCore
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions Bitcoin permettant notamment de manipuler un serveur Bitcoin Core sont les suivantes : 



|   |   |
| --- | --- |
| [BitcoinAdresseValide](../WDLang1/1410088858.md) | Vérifie si une adresse d'un portefeuille Bitcoin est valide. |
| [BitcoinCoreConnexionOccurrence](../WDLang1/1410090772.md) | Renvoie le nombre de pairs connectés.<br><br> |
| [BitcoinCoreDateHeureDernierBloc](../WDLang1/1410090322.md) | Renvoie la date et l'heure de création du dernier bloc. |
| [BitcoinCoreDateHeureDernierLancement](../WDLang1/1410090771.md) | Renvoie la date et l'heure du dernier lancement du logiciel Bitcoin Core.<br><br> |
| [BitcoinCoreDifficulté](../WDLang1/1410086761.md) | Renvoie la difficulté courante du réseau. |
| [BitcoinCoreEspaceDisqueUtilisé](../WDLang1/1410090773.md) | Indique la taille sur disque de la blockchain.<br><br> |
| [BitcoinCoreHashBloc](../WDLang1/1410090774.md) | Renvoie le hash d’un bloc identifié par son indice.<br><br> |
| [BitcoinCoreNombreBloc](../WDLang1/1410090321.md) | Renvoie la taille de la chaîne de blocs connue par le noeud Bitcoin (c'est-à-dire le nombre de blocs créés depuis le 3 janvier 2009). Il est ainsi possible de calculer par exemple la date approximative du prochain "halving". |
| [BitcoinCoreNombreHashParSeconde](../WDLang1/1410090319.md) | Renvoie le nombre de fois où la fonction sha256 a du être calculée par secondes pour calculer le dernier bloc. Ce nombre correspond à une preuve de travail. |
| [BitcoinCoreParamètre](../WDLang1/1410090320.md) | Indique les paramètres de connexion au serveur Bitcoin Core, afin d'utiliser les fonctions [BitcoinCoreXXXX](../WDLang1/1410090347.md). |
| [BitcoinCoreTauxHash](../WDLang1/1410086762.md) | Calcule le "taux de hash" (hashrate) actuel nécessaire pour créer de nouveaux blocs. |





Remarque : L'utilisation des fonctions BitcoinCorexxx nécessite la mise en place d'un serveur Bitcoin et d'un serveur RPC. Pour plus de détails, consultez [Installation et utilisation d'un serveur Bitcoin Core](../WDLang1/1410090348.md).
