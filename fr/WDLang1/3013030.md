


## InitHasard (Fonction)

***En anglais : InitRandom***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Initialise le générateur de nombres aléatoires.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) Cette fonction n'a aucun effet en code navigateur.




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Initialisation du générateur de nombres aléatoires
InitHasard()
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = InitHasard(<n>)`
---

**`<Résultat> : (Entier)`**

Valeur de la graine aléatoire choisie par le système pour initialiser le générateur de nombres aléatoires. 
Si le paramètre &lt;n&gt; est précisé, la graine correspond à cette valeur. 
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png)![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) Cette valeur n'est pas disponible.

**`<n> : (Entier)`**

Nombre de base du générateur de nombres aléatoires. 
Si ce paramètre n'est pas spécifié, le générateur de nombres aléatoires se base sur l'heure système (centièmes de seconde).  



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Si la fonction **InitHasard** n'est pas appelée, les valeurs aléatoires générées par la fonction [Hasard](../WDLang1/3013037.md) seront les mêmes à chaque exécution du programme.

- Des appels à la fonction **InitHasard** très rapprochés dans le temps donneront des séquences identiques car la fonction **InitHasard** utilise l'heure système pour générer des suites de nombres aléatoires.

- L'utilisation du paramètre &lt;n&gt; ne garantit pas d'obtenir des séquences différentes.
