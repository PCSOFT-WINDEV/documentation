
## RVBVersHTML (Fonction)

***En anglais : RGBToHTML***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la couleur HTML correspondant à la couleur RVB. 




<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
RVBVersHTML(255) // Renvoie "#0000FF"
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = RVBVersHTML(<Couleur RVB>)`
---

**`<Résultat> : (Chaîne de caractères)`**

Couleur HTML exprimée en hexadécimal.

![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) &lt;Résultat&gt; correspond à une variable de type [Couleur](../WDLang1/1000019661.md). 

**`<Couleur RVB> : (Entier)`**

Couleur RVB à convertir en couleur HTML. Cette couleur peut correspondre à : 

- une couleur RVB (obtenue avec la fonction [RVB](../WDLang1/3029012.md)),

- [une couleur prédéfinie du WLangage](../WDLang5/3010002.md).

## Remarques
![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png) 

### Astuce
<a name="astuce_ELTPARAGRAPHE000082"></a>Si le résultat est affiché dans une trace à l'écran (fonction [Trace](../WDLang1/3013050.md)), la variable de type [Couleur](../WDLang1/1000019661.md) est convertie en chaîne correspondant à la couleur au format RVB.
