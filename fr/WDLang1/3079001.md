


## VidéoArrête (Fonction)

***En anglais : VideoStop***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Arrête l'affichage ou la sauvegarde d'une séquence vidéo dans un champ Caméra.

ELTSPECIAL000199 ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)
	<B><B><B>Avertissement</B></B></B>

	 **A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS**. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).






<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Arrête l'affichage de la séquence vidéo actuellement retransmise
// dans le champ Caméra "CAM_Cuisine"
ResArrêt = VidéoArrête(CAM_Cuisine, viArrêteAffichage)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Résultat> = VidéoArrête(<Champ Caméra> [, <Action à arrêter>])`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'affichage et/ou la sauvegarde dans le champ Caméra est correctement arrêtée, 

- <u><u><u><u>Faux</u></u></u></u> en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md).




**`<Champ Caméra> : (Nom de champ)`**

Nom du champ Caméra à manipuler.

**`<Action à arrêter> : (Constante optionnelle de type entier)`**

Type d'action à arrêter :


|   |   |
| --- | --- |
| *viArrêteAffichage* | Arrête l'affichage de la vidéo. Le champ Caméra spécifié devient vide. |
| *viArrêteCapture* | Arrête l'enregistrement de la séquence vidéo. Le fichier généré est disponible. |
| *viArrêteTout*<br>(Valeur par défaut) | Arrête l'affichage et l'enregistrement de la séquence vidéo. Le fichier généré est disponible. Le champ Caméra spécifié devient vide. |

## Remarques


### Conditions d'utilisation
<a name="conditions_utilisation_ELTPARAGRAPHE000080"></a>

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![Windows](https://doc.pcsoft.fr/ext/images/fr/WINDOWS.png) Pour utiliser cette fonction, une "caméra" doit être connectée au poste en cours.

- ![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.

- ![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png) Cette fonction nécessite un matériel équipé d'une caméra.


**Remarque** : Cette fonction est équivalente à la fonction [CaméraArrête](../WDLang1/1410086596.md).
<a name="NOTE0_2"></a>


### Cas particuliers
<a name="cas_particuliers_ELTPARAGRAPHE000107"></a>

- Pour sauvegarder la vidéo actuellement retransmise par une "web caméra", utilisez la fonction [VidéoCapture](../WDLang1/3079007.md).

- Pour afficher dans un champ Caméra la séquence vidéo actuellement retransmise par une "web caméra", utilisez la fonction [VidéoAffiche](../WDLang1/3079004.md).



![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png) 

### Permissions requises
<a name="permissions_requises_ELTPARAGRAPHE000125"></a>L'utilisation de cette fonction entraîne la modification des permissions requises par l'application.

Permission requise : CAMERA.

Cette permission permet aux applications d'accéder à la caméra.
