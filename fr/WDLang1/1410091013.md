


## CmdTermine (Fonction)

***En anglais : CmdKill***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Force la terminaison de l'exécutable associé à une commande en mode console en cours d'exécution. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter.Exécutable = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande 
CmdExécute(MaCommandeAExécuter, Faux)
...
SI CmdExécutionEstEnCours(MaCommandeAExécuter) = Vrai ALORS
	CmdTermine(MaCommandeAExécuter)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`CmdTermine(<Commande manipulée>)`
---

**`<Commande manipulée> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande en mode console à manipuler. 



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Il est possible de forcer l'arrêt de l'exécutable associé à une commande via la propriété **DestructionAutomatique** d'une variable de type [Commande](../WDLang1/1410090491.md). 

Si la propriété **DestructionAutomatique** est à <u><u><u><u>Faux</u></u></u></u>, il est possible de : 

- savoir si l'exécutable est en cours d'exécution via la fonction [CmdExécutionEstEnCours](../WDLang1/1410091011.md). 

- forcer l'arrêt de l'exécutable via la fonction **CmdTermine**.
