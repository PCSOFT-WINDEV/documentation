


## TraceDébut (Fonction)

***En anglais : TraceStart***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ouvre la fenêtre de trace ou enregistre les différentes informations de trace dans un fichier texte.

**Remarques** :

- Si la fenêtre de trace est déjà ouverte, la fonction **TraceDébut** n'a aucune action.

- La fonction **TraceDébut** est optionnelle. Le premier appel à la fonction [Trace](../WDLang1/3013050.md) ou à la fonction [TraceConstruit](../WDLang1/1000021683.md) ouvre automatiquement la fenêtre de trace.

**`<Fichier de trace> : (Chaîne de caractères optionnelle)`**

Nom et chemin complet du fichier dans lequel les informations contenues dans la fenêtre de trace doivent être enregistrées. Si ce paramètre n'est pas spécifié, le fichier de trace sera créé dans à la racine du lecteur "C" et son nom sera de la forme "Trace_&lt;NomDuProjet&gt;.txt".

## Remarques


### Conditions d'utilisation selon les plateformes
<a name="conditions_utilisation_selon_les_plateformes_ELTPARAGRAPHE000211"></a>![Linux](https://doc.pcsoft.fr/ext/images/fr/LX.png) La fonction **TraceDébut** permet d'enregistrer les informations demandées uniquement dans un fichier. Par défaut, ce fichier est créé dans le répertoire temporaire d'UNIX, sous le nom "Trace_&lt;Projet&gt;.txt".![PHP](https://doc.pcsoft.fr/ext/images/fr/PHP.png) La fonction **TraceDébut** permet d'afficher les informations demandées dans la page en cours ou de les enregistrer dans un fichier.![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) En mode AWP, la fonction **TraceDébut** permet d'enregistrer les informations demandées uniquement dans un fichier.![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png) La fonction **TraceDébut** permet d'enregistrer les informations demandées : 

- soit dans le log de l'application (en exécution ou en mode émulateur). Ce log est consultable lorsque l'appareil est connecté en USB ou en cas d'utilisation de l'émulateur depuis l'application DDMS fournie avec le SDK Android.

- soit dans un fichier texte spécifique. 


![iPhone/iPad](https://doc.pcsoft.fr/ext/images/fr/IPHONE.png)![Apple Watch](https://doc.pcsoft.fr/ext/images/fr/APPLEWATCH.png) La fonction **TraceDébut** permet : 

- soit d'afficher les informations demandées dans la fenêtre de sortie standard (output) de Xcode. 

- soit d'enregistrer les informations demandées dans un fichier texte spécifique. 



<a name="NOTE0_2"></a>


### Fermeture de la fenêtre de trace
<a name="fermeture_fenetre_trace_ELTPARAGRAPHE000253"></a>La fonction [TraceFin](../WDLang1/3013044.md) permet de fermer la fenêtre de trace.

Si la constante *trFichier* est spécifiée, la fonction [TraceFin](../WDLang1/3013044.md) arrête l'enregistrement dans le fichier de trace.

<a name="fenetre_trace_ELTPARAGRAPHE000270"></a>La fenêtre de trace affichée depuis un code navigateur est différente de celle affichée depuis un code serveur. Deux fenêtres de trace différentes peuvent donc être ouvertes en même temps.
