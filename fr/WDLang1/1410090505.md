


## CmdLitSortieErreur (Fonction)

***En anglais : CmdReadErrorOutput***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lit les données disponibles sur la sortie d'erreur pour la commande lancée en mode console. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande 
CmdExécute(MaCommandeAExécuter, Faux)
// Lecture dans la sortie d'erreur (impossible car le flux n'est pas activé)
// Message d'erreur : Le flux 'STDERR' n'est pas activé.
stderr est une chaîne = CmdLitSortieErreur(MaCommandeAExécuter)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = CmdLitSortieErreur(<Commande à manipuler> [, <Bloquant>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Données présentes dans la sortie d'erreur. 

**Attention** : Le flux de sortie d'erreur doit être activé dans la variable de type [Commande](../WDLang1/1410090491.md) (propriété **Flux**).

**`<Commande à manipuler> : (Variable de type Commande)`**

Nom de la variable de type [Commande](../WDLang1/1410090491.md) correspondant à la commande exécutée en mode console. 

**`<Bloquant> : (Booléen optionnel)`**



- <u><u><u><u>Vrai</u></u></u></u> (valeur par défaut) pour un fonctionnement bloquant : les données sont lues uniquement lorsque la commande a fini de s'exécuter. 

- <u><u><u><u>Faux</u></u></u></u> pour un fonctionnement non bloquant (asynchrone) : les données sont lues même si la commande n'a pas fini son exécution.
