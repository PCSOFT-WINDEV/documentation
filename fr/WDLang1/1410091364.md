
## ChatIASauveConversation (Fonction)

***En anglais : AIChatSaveConversation***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Enregistre la conversation en cours dans un champ Chat IA (en mémoire ou sous forme de fichier au format json). 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Clic sur Sauver la conversation
ChatIASauveConversation(monChatIA, "fichier.json")
SI ErreurDétectée ALORS
	Erreur()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Sauver une conversation dans un fichier

`<Résultat> = ChatIASauveConversation(<Champ Chat IA> , <Fichier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la conversation a été enregistrée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Champ Chat IA> : (Nom de champ)`**

Champ Chat IA manipulé. 

**`<Fichier> : (Chaîne de caractères)`**

Nom et chemin complet (ou relatif) du fichier d'enregistrement. Un chemin de type UNC peut être utilisé. La conversation est enregistrée au format Json. 


<a name="SYNTAXE2"></a>

### Sauver une conversation dans un buffer

`<Résultat> = ChatIASauveConversation(<Champ Chat IA> , <Enregistrement>)`
---

**`<Résultat> : (Buffer)`**

Buffer correspondant à la conversation. 

**`<Champ Chat IA> : (Nom de champ)`**

Champ Chat IA manipulé. 

**`<Enregistrement> : (Constante de type Entier)`**



- Constante *enMémoire* pour enregistrer la conversation dans un buffer. Ce buffer contiendra la conversation au format Json.
