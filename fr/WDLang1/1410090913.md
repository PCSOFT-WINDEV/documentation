


## &lt;Liste image&gt;.ProcédureChargeImage (Fonction)

***En anglais : &lt;ListView&gt;.ProcedureLoadImage***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'indiquer la procédure appelée lors de l'affichage d'une ligne d'un champ Liste image. Il est ainsi possible d'afficher une image calculée plutôt qu'une image stockée sur le disque. 

Remarque : Cette fonction doit être appelée dans l'événement "Affichage d'une ligne" d'un champ Liste image.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PROCÉDURE INTERNE ChargeImagePerso(numLigne est un entier, largeur est entier, hauteur est entier)
	ImageACharger est une Image
	ImageACharger.Largeur = largeur
	ImageACharger.Hauteur = hauteur
	ImageACharger.DébutDessin(dAvecOpacité)
	dPolice("Arial", 12, iNormal, 0)
	ImageACharger.DessineTexte(4, 0, "Ligne " + numLigne)
	RENVOYER ImageACharger
FIN

LSI_MaListeImage.ProcédureChargeImage(ChargeImagePerso)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Champ Liste image>.ProcédureChargeImage(<Procédure de remplissage>)`
---

**`<Champ Liste image> : (Nom de champ)`**

Nom du champ Liste image à manipuler.

**`<Procédure de remplissage> : (Nom de procédure)`**

Nom de la procédure effectuant le remplissage des images du champ Liste image. Pour chaque ligne du champ Liste image affiché, cette procédure renvoie l'image à ajouter dans le champ. Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction &lt;Liste image&gt;.ProcédureChargeImage](../WDLang1/1410090911.md).
