


## PoliceCharge (Fonction)

***En anglais : FontLoad***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Charge une police personnelle depuis un fichier ou un buffer. Après le chargement, les polices et variantes déclarées par le fichier (ou le buffer) seront disponibles dans toute l'application.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
PoliceCharge("Roboto-Regular.ttf")
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = PoliceCharge(<Police>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la police a été chargée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 




**`<Police> : (Chaîne de caractères ou Buffer)`**



- Nom et chemin du fichier correspondant à la police à charger. 

- Buffer contenant la police à charger. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


- Pour décharger une police, utilisez la fonction [PoliceDécharge](../WDLang1/1410090995.md).

- Les formats gérés dépendent des plateformes : .ttf, .otf et .woff.

- Si une même police est chargée plusieurs fois, il faut effectuer autant d'appels à la fonction [PoliceDécharge](../WDLang1/1410090995.md) que d'appels de **PoliceCharge**.

- Si un police de même nom est chargée depuis plusieurs fichiers/buffers, seul le premier chargement sera pris en compte.

- Les polices chargées par la fonction **PoliceCharge** ne sont pas listées par la fonction [PoliceListe](../WDLang1/3060003.md).
