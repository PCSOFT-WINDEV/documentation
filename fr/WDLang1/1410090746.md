


## Fonctions de gestion de l'exécution des commandes en mode console
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les fonctions de gestion des commandes exécutées en mode console sont les suivantes : 




|   |   |
| --- | --- |
| [CmdAjouteArgument](../WDLang1/1410090501.md) | Ajoute un argument à une commande à exécuter en mode console. |
| [CmdAjouteOption](../WDLang1/1410090502.md) | Ajoute une option à la commande à exécuter en mode console. |
| [CmdEcritEntréeStandard](../WDLang1/1410090503.md) | Ecrit les données sur l'entrée standard de la commande exécutée en mode console. |
| [CmdExécute](../WDLang1/1410090500.md) | Exécute une commande en mode console. |
| [CmdExécutionEstEnCours](../WDLang1/1410091011.md) | Indique si l'exécutable lié à une commande exécutée en mode console est actuellement en cours d'exécution. <br><br> |
| [CmdLitSortieErreur](../WDLang1/1410090505.md) | Lit les données disponibles sur la sortie d'erreur pour la commande lancée en mode console. |
| [CmdLitSortieStandard](../WDLang1/1410090504.md) | Lit les données disponibles sur la sortie standard pour la commande lancée en mode console. |
| [CmdRécupèreCodeRetour](../WDLang1/1410090506.md) | Récupère le code de retour de la commande lancée en mode console, c'est-à-dire la valeur renvoyée à la terminaison de la commande. |
| [CmdTermine](../WDLang1/1410091013.md) | Force la terminaison de l'exécutable associé à une commande en mode console en cours d'exécution.<br><br> |
