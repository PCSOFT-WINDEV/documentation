
## EnModeTestUnitaire (Fonction)

***En anglais : InUnitTestMode***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si un test unitaire est en cours.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// En mode test unitaire, la première fenêtre du projet n'est pas ouverte
SI PAS EnModeTestUnitaire() ALORS
 	Ouvre(PremièreFenêtre)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = EnModeTestUnitaire()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si un test unitaire est en cours, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Disponibilité de la fonction
<a name="disponibilite_fonction_ELTPARAGRAPHE000160"></a>La fonction **EnModeTestUnitaire** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeTestUnitaire** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
