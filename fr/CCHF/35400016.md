


## Gestion des fichiers de données HFSQL Client/Serveur
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000273"></a>
Le Centre de Contrôle HFSQL propose une gestion complète des fichiers de données HFSQL Client/Serveur.

Pour afficher les caractéristiques d'un fichier de données HFSQL Client/Serveur : 

1. Connectez-vous si nécessaire à un serveur HFSQL. Pour plus de détails, consultez [Gestion des bases de données HFSQL Client/Serveur](../CCHF/35400013.md). 

2. Sélectionnez le nom du serveur HFSQL dans l'arborescence. 

3. Sélectionnez ensuite le nom de la base de données voulue.

4. Double-cliquez ensuite sur le nom du fichier de données voulu.

5. La partie droite du Centre de Contrôle affiche un onglet au nom du fichier de données. Cet onglet est constitué de : 

	- différents onglets permettant de gérer les caractéristiques du fichier de données HFSQL. Par défaut, l'onglet "Contenu" est affiché. 

	- un ruban permettant de configurer le fichier de données HFSQL. 




<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0002.gif&type=thumb)


**Remarque** : Depuis le volet du Centre de Contrôle, le menu contextuel du fichier de données permet de :<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0001.gif)


- Optimiser et réparer le fichier de données. Pour plus de détails, consultez [Optimiser et réparer des fichiers de données](../CCHF/3540007.md). 

- Fermer le fichier de données. 

- Changer le mot de passe du fichier de données. 

- Supprimer le fichier de données. 

- Gérer les droits sur le fichier de données.

## Détail des caractéristiques d'un fichier de données HFSQL Client/Serveur
<a name="detail_des_caracteristiques_fichier_donnees_hfsql_clientserveur_ELTTEXTE000297"></a>


### Onglets "Description" et "Propriétés"
<a name="onglets_description_proprietes_ELTPARAGRAPHE000049"></a>L'onglet "Description" affiche la description des différentes rubriques du fichier de données : 

- Le nom de la rubrique,

- Le type de la rubrique,

- La taille de la rubrique,

- Le type de clé,

- Si la rubrique est visible sous le logiciel "Etats & Requêtes".




Si nécessaire, des informations complémentaires sont affichées.

Remarque : Par défaut, les rubriques sont affichées dans l'ordre logique. il est possible d'utiliser l'ordre alphabétique si nécessaire via les options du Centre de Contrôle HFSQL : 

1. Déroulez le menu du Centre de Contrôle HFSQL (![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_Suivi_Configuration%20-%20HC%20N%B0001.gif)). 

2. Sélectionnez "Options".

3. Dans la fenêtre qui s'affiche, indiquez "alphabétique" pour l'option "Ordre d'affichage des rubriques". 




L'onglet "Propriétés" affiche les propriétés du fichier de données (nom physique, format, protection, etc.).
<a name="NOTE2_2"></a>


### Onglet "Connexions"
<a name="onglet_connexions_ELTPARAGRAPHE000068"></a>Cet onglet liste les différents utilisateurs connectés sur le fichier de données.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0005.gif)


La liste des connexions actives contient les informations suivantes :

- le nom de l'utilisateur,

- le nom de la machine,

- le nom de l'application qui accède au fichier, etc.




Depuis cet onglet, il est possible de : 

- Filtrer les connexions selon les machines, les utilisateurs et/ou les connexions.

- Déconnecter les utilisateurs. 
	Il suffit de sélectionner le ou les utilisateurs à déconnecter dans la liste des connexions, puis d'utiliser l'option "Déconnecter les utilisateurs sélectionnés" présente dans le ruban.

- Envoyer un message aux utilisateurs. 
	Il suffit de sélectionner le ou les utilisateurs destinataires dans la liste des connexions, puis d'utiliser l'option "Envoyer un message aux utilisateurs sélectionnés" présente dans le ruban.




L'option "Ne pas afficher les connexions du Centre de Contrôle HFSQL (lancé sur cette machine)" permet d'afficher uniquement les connexions des utilisateurs via les applications. 
<a name="NOTE2_3"></a>


### Onglet "Blocages"
<a name="onglet_blocages_ELTPARAGRAPHE000109"></a>Cet onglet permet de gérer les blocages.

Les informations affichées sont les suivantes : 

- le numéro de l'enregistrement bloqué, 

- le nom de l'utilisateur qui bloque, 

- le nom de la machine qui bloque,

- l'adresse IP de la machine qui bloque, 

- le nom de l'application qui bloque, 

- la date de début de blocage, 

- la durée du blocage.



<a name="NOTE2_4"></a>


### Onglet "Contenu"
<a name="onglet_contenu_ELTPARAGRAPHE000126"></a>Cet onglet permet de visualiser les différents enregistrements du fichier de données. 

Il est également possible de filtrer les enregistrements affichés via la barre présente au-dessus des données. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007.gif)
Le menu contextuel du filtre (![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0007%201.gif)) propose plusieurs options : 

- Application automatique : le filtre est automatiquement exécuté lors de sa validation avec la touche Entrée du clavier. Si cette option n'est pas sélectionnée, la validation doit être effectuée en cliquant sur la coche verte en fin de ligne. 

- Supprimer le filtre en cours : Permet de vider le champ du filtre. 

- Copier le code SQL : Permet de copier dans le presse-papiers le code SQL correspondant au filtre saisi. 

- Créer une requête : Permet d'afficher le volet "Requête" avec le code SQL de la requête saisie (équivalent à l'option "Nouvelle requête" du ruban). 

- Vider l'historique des filtres : Les filtres créés sont automatiquement mémorisés pour pouvoir être rapidement ré-appliqués. Il est possible de supprimer tous les filtres mémorisés. 




Le menu contextuel des enregistrements permet de : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0009.gif&type=thumb)


- afficher l'enregistrement en mode fiche (option "Visualiser l'enregistrement" ou double-clic sur la ligne). La fenêtre qui s'affiche permet de visualiser les valeurs de rubriques de manière claire et de simplifier la modification des valeurs. Les boutons de parcours permettent de visualiser rapidement les autres enregistrements dans la même fenêtre.

- manipuler l'enregistrement sélectionné : suppression, ajout, modification, etc. La modification du fichier de données est faite automatiquement. Remarque : La modification et l'ajout d'un enregistrement sont réalisés dans la fenêtre de visualisation.

- configurer les options d'affichage.

- réaliser un filtre sur la colonne en cours. 

- imprimer l'enregistrement. 

- etc.




Dans le ruban, certaines options spécifiques au contenu affiché sont disponibles : 

- Créer, éditer, visualiser ou supprimer un enregistrement. 

- Rechercher un enregistrement par son numéro. 

- Rechercher les doublons présents dans le fichier de données. Il suffit d'indiquer la rubrique à traiter, le type de comparaison souhaité et de lancer la recherche. Pour chaque doublon trouvé, la valeur du doublon rencontré et le nombre d'occurrences est affiché. 
	



<a name="NOTE2_6"></a>


### Onglet "Journaux"
<a name="onglet_journaux_ELTPARAGRAPHE000184"></a>Cet onglet permet de visualiser le contenu des journaux et d'effectuer une recherche dans les journaux.

Il est nécessaire que le fichier de données  soit journalé.
<a name="NOTE2_8"></a>


### Onglet "Transactions"
<a name="onglet_transactions_ELTPARAGRAPHE000193"></a>Cet onglet permet de libérer un enregistrement ou toutes les transactions.
<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0008.gif)

## Autres options disponibles
<a name="autres_options_disponibles_ELTTEXTE000384"></a>


### Détail du ruban
<a name="detail_ruban_ELTPARAGRAPHE000204"></a>Pour le fichier de données HFSQL Client/Serveur sélectionné, le ruban propose les actions suivantes : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=CC_HF_Gestion_Fichier_HFCS%20-%20HC%20N%B0002%201.gif)


- Dans le groupe "Requête SQL" : 

	- Nouvelle requête : Cette option permet d'ouvrir un onglet spécifique permettant de réaliser une requête SQL sur la base de données en cours.  

	- Ouvrir une requête : Cette option permet d'ouvrir un onglet spécifique correspondant à une requête précédemment réalisée. 


 Pour plus de détails, consultez [Créer et exécuter une requête](../CCHF/35400019.md).

- Dans le groupe "Fichier de données" :

	- Optimiser et réparer : Cette option permet d'ouvrir la fenêtre de configuration de l'optimisation du fichier de données. Pour plus de détails, consultez [Optimiser et réparer des fichiers de données](../CCHF/3540007.md). 

	- Fermer le fichier de données : Cette option permet de fermer le fichier de données et l'onglet correspondant. 




- Dans le groupe "Droits", l'option "Gestion des droits" permet de gérer les droits des utilisateurs et des groupes sur le fichier de données. 




Selon l'onglet sélectionné, des options supplémentaires peuvent apparaître dans le ruban.
