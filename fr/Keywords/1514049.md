


## Entier (Type de variable)

***En anglais : Int***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **Entier** permet de réaliser simplement des calculs sur des valeurs entières. Une variable de type entier peut avoir une valeur comprise entre -2 x 109 et 2 x 109 (environ). 

Remarque : Pour des calculs avancés, le WLangage propose [différents types d'entiers](#NOTE0_5). 


Le type Entier est un type nullable. Pour plus de détails, consultez [Activation des types nullables](../Motscles/1511031.md).

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
i est un entier
i = 5
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Nom de la variable> est un entier

<Nom de la variable 1>, <Nom de la variable 2> sont des entiers`
---

**`<Nom de la variable> : ()`**

Nom de la variable à déclarer.

<a name="NOTE0_1"></a>

## Remarques


### Déclaration et initialisation
<a name="declaration_initialisation_ELTPARAGRAPHE000043"></a>Une variable de type "Entier" déclarée et non initialisée est égale à 0.
<a name="NOTE0_2"></a>


### Valeur Hexadécimale
<a name="valeur_hexadecimale_ELTPARAGRAPHE000050"></a>Pour saisir une valeur hexadécimale dans le code, il suffit de préfixer la valeur hexadécimale par "0x".

```wl
MaVariable est un entier
MaVariable = 0x4D5
```


Remarque : Il est possible d'utiliser le caractère '_' comme séparateur de blocs dans les nombres hexadécimaux. Les blocs peuvent avoir une taille de 2, 4 ou 8 caractères de long. 
Exemple : 

```wl
Nb1 est un entier = 0x_12_15_A4_BC
Nb2 est un entier = 0x_CD4A_DE58
```

<a name="NOTE0_3"></a>


### Séparateur des milliers
<a name="separateur_des_milliers_ELTPARAGRAPHE000068"></a>Il est possible d'utiliser le caractère 'Espace' ou le caractère '_' comme séparateur de milliers dans les nombres. Par exemple :

```wl
num1 est un entier
num1 = 123 456
soit num2 = 246_789
```

### Spécificités PHP
<a name="specificites_php_ELTPARAGRAPHE000079"></a>

- Les nombres (réels, entiers, monétaires, numériques) ne peuvent pas dépasser 14 chiffres significatifs en PHP. S'ils dépassent cette limite, ils sont arrondis à 14 chiffres.

- Les entiers en 32 bits ont pour valeur maximum : 
	2147483647 pour 32 bits <=> 0x7FFFFFFF

- Les entiers en 64 bits ont pour valeur maximum : 
	9223372036854775807<=>0x7FFFFFFFFFFFFFFF

### Différences entre WINDEV 5.5 et WINDEV 2026
<a name="differences_entre_windev_55_windev_docparamversioncom_ELTPARAGRAPHE000292"></a>Les types d'entiers ont été modifiés entre WINDEV 5.5 et WINDEV 2026 :

| Type d'entiers avec WINDEV 5.5 | Type d'entiers avec WINDEV 2026 |
| --- | --- |
| Entier | Entier sur 2 octets |
| Entier sans signe | Entier sans signe sur 2 octets |
| Entier long | Entier sur 4 octets |
| Entier court | Entier sans signe sur 1 octet |


Par défaut, avec WINDEV 5.5, les entiers étaient des entiers sur 2 octets. Par défaut, depuis les versions 7.x, les entiers sont des entiers sur 4 octets.
