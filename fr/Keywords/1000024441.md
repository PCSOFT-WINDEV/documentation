
## Booléen (Type de variable)

***En anglais : Boolean***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>


<a name="description"></a>
Le type **Booléen** est conseillé pour toutes les opérations logiques où seules deux alternatives sont possibles :

- Vrai (valeur différente de 0).

- Faux (valeur égale à 0). 


Le type Booléen est un type nullable. Pour plus de détails, consultez [Activation des types nullables](../Motscles/1511031.md). 





<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
b est un booléen
```



<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`<Nom de la variable> est un booléen

<Nom de la variable 1>, <Nom de la variable 2> sont des booléens`
---

**`<Nom de la variable> : ()`**

Nom de la variable à déclarer.
