
## Chaîne Unicode sur (Type de variable)

***En anglais : Unicode string of***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **Chaîne Unicode sur** est une chaîne de taille fixée contenant uniquement des caractères au format Unicode.

**Remarques** : 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Ce type de chaîne de caractères n'est pas supporté. Il est remplacé par le type Chaîne. 

- Pour une variable de type "Chaîne Unicode sur", la fonction [TypeVar](../WDLang1/3013056.md) renvoie la constante *wlChaîneUnicode* (valeur 16). 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
Prénom est une chaîne Unicode sur 8
Prénom = "Florence"
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

### Déclarer et initialiser une variable de type "Chaîne UNICODE sur"

`<Nom de la variable> est une chaîne Unicode sur <Taille> = <Valeur>
OU

 <Nom de la variable> est une chaîne Unicode sur <Taille>
<Nom de la variable> = <Valeur>`
---

**`<Nom de la variable> : ()`**

Nom de la variable à déclarer. Lorsque plusieurs variables du même type sont déclarées et initialisées sur la même ligne, seule la dernière variable est initialisée.

**`<Taille> : ()`**

Taille maximale fixée pour la chaîne. 

**`<Valeur> : ()`**

Valeur donnée à la variable.

## Remarques


### Valeur par défaut
<a name="valeur_par_defaut_ELTPARAGRAPHE000046"></a>Une variable de type "Chaîne Unicode sur" déclarée et non initialisée correspond à une chaîne vide ("").

### Chaîne fixe
<a name="chaine_fixe_ELTPARAGRAPHE000172"></a>

- Lors de la déclaration d'une chaîne fixe, la mémoire nécessaire est immédiatement allouée. Il est donc nécessaire d'éviter d'utiliser des chaînes de trop grande taille.

- La chaîne fixe est complétée par des espaces. L'initialisation et l'affectation d'une chaîne de grande taille (plusieurs centaines de kilo octets) peuvent être relativement longues.

### Code multi-plateforme
<a name="code_multiplateforme_ELTPARAGRAPHE000186"></a>Les chaînes fixes ne sont pas disponibles en Java. Elles sont remplacées en exécution par le type Chaîne.

Il est cependant possible d'utiliser la fonction [Complète](../WDLang1/3024010.md) sur une variable de type Chaîne :

```wl
MaChaîne est une chaîne
MaChaîne = Complète("Test", 10)
// Equivalent à 
// MaChaîne est une chaîne fixe sur 10 caractères
// MaChaîne = "Test"
```
