
## MaValeurMémorisée

***En anglais : MyStoredValue***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le mot-clé **MaValeurMémorisée** permet de connaître l'objet en cours du tableau de classes pendant l'impression d'un état basé sur une classe. 

Il est ainsi possible de connaître les différentes valeurs des membres de la classe en cours et si nécessaire de les regrouper. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
soit o = MaValeurMémorisée
Trace(o.m_snomclient + o.m_sSociete)
```

<a name="XSYNTAXE"></a>
<a name="SYNTAXE1"></a>

## Syntaxe

`MaValeurMémorisée`
