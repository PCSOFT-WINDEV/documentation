## Instructions conditionnelles
<a name="instructions_conditionnelles_ELTTEXTE000160"></a>
Les instructions conditionnelles du WLangage sont les suivantes : 



|   |   |
| --- | --- |
| [SELON](../Motscles/1510008.md) | Exécution d'une action ou d'une autre en fonction d'une expression |
| [SI](../Motscles/1510011.md) | Exécution d'une action ou d'une autre en fonction d'une condition. |

## Instructions répétitives
<a name="instructions_repetitives_ELTTEXTE000184"></a>
Les instructions répétitives du WLangage sont les suivantes : 



|   |   |
| --- | --- |
| [BOUCLE](../Motscles/1510004.md) | Bloc d'instructions répété à l'infini |
| [POUR](../Motscles/1510001.md) | Bloc d'instructions répété jusqu'à une valeur limite |
| POUR TOUT | Parcours d'éléments : <br><br>- [POUR TOUT](../Motscles/1510013.md) : Parcours HFSQL (parcours complet, parcours avec recherche, parcours avec filtre).<br><br>- [POUR TOUT](../Motscles/1510016.md) : Parcours de tableaux.<br><br>- [POUR TOUT](../Motscles/1510019.md) : Parcours de tableaux associatifs.<br><br>- [POUR TOUT](../Motscles/1510018.md) : Parcours de chaînes.<br><br>- [POUR TOUT](../Motscles/1510017.md) : Parcours de champs.<br><br>- [POUR TOUT](../Motscles/1510024.md) : Parcours des options disponibles dans les combinaisons.<br><br>- [POUR TOUT](../Motscles/1510023.md) : Parcours des valeurs disponibles dans les énumérations.<br><br>- [POUR TOUT](../Motscles/1510022.md) : Parcours sur une variable de type [xmlLecteur](../WDLang5/1000023392.md). <br><br>- [POUR TOUT](../Motscles/1510029.md) : Parcours sur une variable de type [jsonLecteur](../WDLang1/1410090783.md).<br>	<br><br><br><br><br> |
| [TANTQUE](../Motscles/1510010.md) | Bloc d'instructions répété en fonction d'une condition |


L'instruction POUR TOUT peut également être utilisée pour parcourir les objets DotNet qui implémentent l'interface IEnumerable.
