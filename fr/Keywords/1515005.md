
## Opérateur de conversion explicite sur les types avancés
			



<a name="description"></a>
Les instances d'une variable de type avancé qui héritent d'un type avancé de base peuvent être manipulées par une variable du type de base. 

Pour manipuler l'instance par son type réel à partir d'une variable du type de base, il est possible d'utiliser une variable du type réel et l'affecter grâce à l'opérateur &lt;-.

L'opérateur de conversion explicite permet de manipuler l'instance par son type réel sans variable intermédiaire. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Code n'utilisant pas la conversion explicite
POUR TOUTE formeDiag DE EDIAG_MonDiagramme.Forme
	FormeImage est un diagImage <- formeDiag
	SI FormeImage <> Null ALORS
 	 // La forme est une image
	FIN
FIN
```

```wl
// Code utilisant la conversion explicite
POUR TOUTE formeDiag DE EDIAG_MonDiagramme.Forme
	SI ((diagImage?)formeDiag) ALORS
 	 // La forme est une image
	FIN
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Conversion statique : Provoque une exception en exécution si la conversion est illicite

`((<Type dérivé>) <Variable du type de base>)`
---

**`<Type dérivé> : ()`**

Type de variable héritant du type de base.

**`<Variable du type de base> : ()`**

Variable à convertir vers le &lt;Type dérivé&gt;. 


<a name="SYNTAXE2"></a>

### Conversion dynamique : Renvoie Null si la conversion est illicite

`((<Type dérivé> ?) <Variable du type de base>)`
---

**`<Type dérivé> : ()`**

Type de variable héritant du type de base.

**`<Variable du type de base> : ()`**

Variable à convertir vers le &lt;Type dérivé&gt;. 

**Détail** : La conversion dynamique ne provoque pas d'erreur en exécution si la conversion est illicite. Un objet fictif est renvoyé pour lequel la comparaison à **Null** renvoie <u><u><u><u>Vrai</u></u></u></u>. Une exception sera déclenchée si cet objet fictif est manipulé.
