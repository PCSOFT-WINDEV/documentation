
## Chaîne fixe sur (Type de variable)

***En anglais : Fixed string of***
				

<DIV class="specObsolete">
	<IMG style="float:left;margin-right:10px;" src="$IMGLOCAL$=warning_big.png"><B>Avertissement</B><BR>
	 Ce type de variable est conservé par compatibilité. 
</DIV><a name="description"></a>
Le type **Chaîne fixe sur** correspond à une chaîne de taille fixe. La longueur d'une chaîne fixe est limitée à environ 2 Go. La chaîne de caractères est complétée : 

- avec 0 si la variable n'est pas encore affectée.

- avec des espaces si nécessaire si la variable est affectée (elle est semblable au type "string" du Basic).




Remarques : 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Le type Chaîne fixe n'est pas supporté. Il est remplacé par le type Chaîne.

- ![WINDEV](https://doc.pcsoft.fr/ext/images/fr/WD.png)![WEBDEV - Code Serveur](https://doc.pcsoft.fr/ext/images/fr/WBS.png) Ce type de chaîne de caractères est au format ANSI.

- Pour une variable de type "Chaîne fixe sur", la fonction [TypeVar](../WDLang1/3013056.md) renvoie la constante *wlChaîneFixe* (valeur 22).

<a name="sample_code"></a>

## Exemple


```wl
Prénom est une chaîne fixe sur 8
Prénom = "Florence"
```

## Syntaxe

### Déclarer et initialiser une variable de type "Chaîne fixe sur"

`<Nom de la variable> est une chaîne fixe sur <Taille> = <Valeur>
OU

 <Nom de la variable> est une chaîne fixe sur <Taille>
<Nom de la variable> = <Valeur>`
---

**`<Nom de la variable> : ()`**

Nom de la variable à déclarer. Lorsque plusieurs variables du même type sont déclarées et initialisées sur la même ligne, seule la dernière variable est initialisée.

**`<Taille> : ()`**

Taille maximale fixée pour la chaîne. 

**`<Valeur> : ()`**

Valeur donnée à la variable.

## Remarques


### Valeur par défaut
<a name="valeur_par_defaut_ELTPARAGRAPHE000054"></a>Une variable de type "Chaîne fixe sur" déclarée et non initialisée est complétée avec des 0.

Remarque : Le type "Chaîne fixe sur" doit être utilisé pour envoyer des paramètres en entrée / sortie à une API Windows.

### Chaîne fixe
<a name="chaine_fixe_ELTPARAGRAPHE000182"></a>

- Lors de la déclaration d'une chaîne fixe, la mémoire nécessaire est immédiatement allouée. Il est donc nécessaire d'éviter d'utiliser des chaînes de trop grande taille.

- La chaîne fixe est complétée par des espaces. L'initialisation et l'affectation d'une chaîne de grande taille (plusieurs centaines de kilo octets) peuvent être relativement longues.

### Code multi-plateforme
<a name="code_multiplateforme_ELTPARAGRAPHE000196"></a>Les chaînes fixes ne sont pas disponibles en Java. Elles sont remplacées en exécution par le type Chaîne.

Il est cependant possible d'utiliser la fonction [Complète](../WDLang1/3024010.md) sur une variable de type Chaîne :

```wl
MaChaîne est une chaîne
MaChaîne = Complète("Test", 10)
// Equivalent à 
// MaChaîne est une chaîne fixe sur 10 caractères
// MaChaîne = "Test"
```
