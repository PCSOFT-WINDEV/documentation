
## Opérateur de conversion explicite sur les types simples
			



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Lors d'une affectation réalisée via l'opérateur '=' entre plusieurs variables de type simple (entiers, réels, chaînes, etc.), une conversion implicite peut avoir lieu.

Exemple de conversion implicite : 

```wl
s est une chaîne = "43"
n est un entier
n = s // n contient 43 : la chaîne a été convertie en entier
```


L'opérateur '()' permet de forcer la conversion d'une variable dans le type voulu. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
ref_produit est une chaîne = (chaîne) 378 + (chaîne) 578
// ref_Produit vaut 378578 et non 956
```

```wl
// Conversion de la chaîne en entier
UneProcédure((entier)une_valeur)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`(<Type destination>) <Expression source>
(<Type destination>) (<Expression source>)
`
---

**`<Type destination> : ()`**

Type de variable voulu.

**`<Expression source> : ()`**

Expression ou variable à convertir vers le &lt;type destination&gt;. 





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Les types gérés
<a name="les_types_geres_ELTPARAGRAPHE000038"></a>Les types simples gérés sont :

- booléen

- entier

- réel

- monétaire

- numérique

- Date

- Heure

- Durée

- DateHeure

- chaîne

- chaîne ANSI

- chaîne Unicode

- Buffer


Seule la conversion statique est disponible pour les types simples : si la conversion n'est pas autorisée, une exception se produira à l'exécution.
