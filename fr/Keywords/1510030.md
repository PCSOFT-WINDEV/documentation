
## UTILISER DANS (transaction)

***En anglais : USING IN***
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
L'instruction **UTILISER ... DANS** permet de définir le bloc d'opérations à effectuer dans une transaction. 

Cette instruction est utilisée pour encadrer un bloc de code dans lequel plusieurs opérations doivent être traitées comme une seule transaction atomique.

Ainsi toutes les opérations doivent réussir ensemble ou être annulées entièrement en cas d'erreur, garantissant ainsi l'intégrité des données.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
UTILISER HTransaction() DANS
	// Ajout d'un client
	HAjoute(CLIENT)
	// Ajout d'une commande liée à ce client	
	HAjoute(COMMANDE)	
	// En cas d'erreur, on peut annuler la transaction
	SI ErreurDétectée() ALORS
		ABANDONNER ET SORTIR
	FIN
FIN
```





<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`UTILISER HTransaction() DANS 
     ...
FIN
`
---

**`<UTILISER DANS> : ()`**

Signale le début du bloc d'instructions. à l'entrée dans ce bloc, une transaction est automatiquement ouverte.
Il est ainsi possible de regrouper plusieurs opérations (ajouts, modifications, suppressions) sur les fichiers de données gérés par HFSQL.

**`<HTransaction> : ()`**

Active la transaction. 





<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Sortie du bloc : validation ou annulation
<a name="sortie_bloc_validation_annulation_ELTPARAGRAPHE000042"></a>Plusieurs comportements sont possibles en sortie du bloc : 

- Validation de la transaction
	Si le code s'exécute jusqu'à la fin du bloc sans interruption (jusqu'au FIN) ou si l'instruction SORTIR est utilisée, la transaction est validée automatiquement.
	Ce comportement est équivalent à l'appel à la fonction WLangage [HTransactionFin](../WDLang4/3044032.md).
	Dans ce cas, toutes les modifications de données HFSQL effectuées dans ce bloc sont définitivement enregistrées.

- Annulation de la transaction
	Pour interrompre la transaction et annuler toutes les modifications effectuées sur les données HFSQL, il suffit d'utiliser l'instruction **ABANDONNER ET SORTIR**.
	Cette instruction provoque une annulation de la transaction et permet de sortir du bloc tout en conservant des données cohérentes.
	Ce comportement est équivalent à la fonction WLangage [HTransactionAnnule](../WDLang4/3044001.md).

- Toute autre sortie (exception, fonctions [RepriseSaisie](../WDLang1/3025027.md), [Ferme](../WDLang1/3038018.md), [FinProgramme](../WDLang1/3013033.md), etc.)
	Dans ce cas, la transaction est également automatiquement annulée.
