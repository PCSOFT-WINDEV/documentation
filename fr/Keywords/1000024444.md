
## Chaîne ASCIIZ sur (Type de variable)

***En anglais : ASCIIZ string of***
				



<a name="description"></a>
Le type **Chaîne ASCIIZ sur** permet de manipuler une chaîne terminée par un 0 binaire (identique au langage C). 

La longueur d'une chaîne ASCIIZ est limitée à environ 2 Go. La taille à donner à la chaîne ASCIIZ doit être égale à la taille de la chaîne plus 1 (pour le zéro binaire).

Remarques : 

- ![WEBDEV - Code Navigateur](https://doc.pcsoft.fr/ext/images/fr/WBN.png)![Android](https://doc.pcsoft.fr/ext/images/fr/ANDROID.png)![Widget Android](https://doc.pcsoft.fr/ext/images/fr/ANDROIDWIDGET.png)![Java](https://doc.pcsoft.fr/ext/images/fr/JAVA.png) Le type Chaîne ASCIIZ n'est pas supporté. Il est remplacé par le type Chaîne. 

- Pour une variable de type Chaîne ASCIIZ, la fonction [TypeVar](../WDLang1/3013056.md) renvoie la constante *wlChaîneASCIIZ* (valeur 23).

<a name="sample_code"></a>

## Exemple


```wl
Prénom est une chaîne ASCIIZ sur 8
Prénom = "Florence"
```

## Syntaxe

### Déclarer et initialiser une variable de type "Chaîne ASCIIZ sur"

`<Nom de la variable> est une chaîne ASCIIZ sur <Taille> = <Valeur>
OU

 <Nom de la variable> est une chaîne ASCIIZ sur <Taille>
<Nom de la variable> = <Valeur>`
---

**`<Nom de la variable> : ()`**

Nom de la variable à déclarer. Lorsque plusieurs variables du même type sont déclarées et initialisées sur la même ligne, seule la dernière variable est initialisée.

**`<Taille> : ()`**

Taille maximale fixée pour la chaîne. 

**`<Valeur> : ()`**

Valeur donnée à la variable.

### Chaîne ASCIIZ
<a name="chaine_asciiz_ELTPARAGRAPHE000058"></a>Lors de la déclaration d'une chaîne ASCIIZ, la mémoire nécessaire est immédiatement allouée. Il est donc nécessaire d'éviter d'utiliser des chaînes de trop grande taille.

### Code multi-plateforme
<a name="code_multiplateforme_ELTPARAGRAPHE000205"></a>Les chaînes fixes ne sont pas disponibles en Java. Elles sont remplacées en exécution par le type Chaîne.

Il est cependant possible d'utiliser la fonction [Complète](../WDLang1/3024010.md) sur une variable de type Chaîne :

```wl
MaChaîne est une chaîne
MaChaîne = Complète("Test", 10)
// Equivalent à 
// MaChaîne est une chaîne fixe sur 10 caractères
// MaChaîne = "Test"
```
