


## HListeFichiersSurveillés (Fonction)

***En anglais : HListWatchedFiles***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des fichiers de données surveillés par la fonction [HSurveille](../WDLang4/1000022407.md).

Attention : 

- Cette fonction est utilisable uniquement en mode Client/Serveur. 

- La liste des fichiers de données surveillés correspond à la liste au moment de l'exécution de la fonction. Si des fichiers de données ne sont plus surveillés (fonction [HSurveilleStop](../WDLang4/1000022430.md)), ils n'apparaîtront pas dans la liste. 



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MesFichiersSurveillés est un tableau de chaînes
MesFichiersSurveillés = HListeFichiersSurveillés()
```

```wl
MaConnexion est une Connexion
MesFichiersSurveillés est un tableau de chaînes
MesFichiersSurveillés = HListeFichiersSurveillés(MaConnexion)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HListeFichiersSurveillés([<Connexion>])`
---

**`<Résultat> : (Tableau WLangage)`**

Tableau de chaînes contenant les différents fichiers de données surveillés. 

**`<Connexion> : (Chaîne de caractères ou variable de type Connexion optionnelle)`**

Connexion à manipuler. Cette connexion correspond :

- soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md). 


Si ce paramètre est spécifié, il est ainsi possible de restreindre la liste des fichiers de données surveillés uniquement à ceux dont la surveillance a été initiée par la connexion spécifiée.
Si ce paramètre n'est pas spécifié, tous les fichiers de données surveillés par toutes les connexions venant de l'application appelante seront renvoyés. Les fichiers de données surveillés par d'autres applications ne seront pas renvoyés.
