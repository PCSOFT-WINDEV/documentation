
## HPolitiqueSécuritéModifie (Fonction)

***En anglais : HSecurityPolicySet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la politique de sécurité des mots de passe d'un serveur HFSQL. 

Remarque : Pour utiliser cette fonction, il est nécessaire d'être connecté au serveur HFSQL avec un compte utilisateur de type "super utilisateur". 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaPolitiqueDeSécurité est un hPolitiqueSécurité
SI PAS HPolitiqueSécuritéModifie(MaConnexion, MaPolitiqueDeSécurité) ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HPolitiqueSécuritéModifie(<Connexion> , <PolitiqueSécurité>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la politique de sécurité des mots de passe spécifiée a été appliquée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur. 




**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion au serveur HFSQL à manipuler. Cette connexion correspond : 

- soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md). 




**`<PolitiqueSécurité> : (Variable de type hPolitiqueSécurité)`**

Nom de la variable de type [hPolitiqueSécurité](../WDLang4/1410091181.md) correspondant à la politique de sécurité des mots de passe à appliquer.
