
## &lt;Variable Connexion&gt;.PolitiqueSécuritéDébloqueCompte (Fonction)

***En anglais : &lt;Connection variable&gt;.SecurityPolicyUnlockAccount***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de débloquer le compte d'un utilisateur bloqué à cause d'un trop grand nombre de tentatives d'ouverture de connexion infructueuses.

**Remarque** : Pour utiliser cette fonction, il est nécessaire d'être connecté au serveur HFSQL avec un compte utilisateur de type "super utilisateur". 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
SI PAS maConnexion.PolitiqueSécuritéDébloqueCompte("monCompteBloque") ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion>.PolitiqueSécuritéDébloqueCompte(<Utilisateur>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si le compte a été débloqué, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Connexion> : (Variable de type Connexion)`**

Nom de la variable de type [Connexion](../WDLang4/1514073.md) décrivant la connexion à manipuler.

**`<Utilisateur> : (Chaîne de caractères)`**

Nom de l'utilisateur dont le compte doit être débloqué.
