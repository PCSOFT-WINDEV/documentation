


## &lt;Variable redisConnexion&gt;.Déconnecte (Fonction)

***En anglais : &lt;redisConnection variable&gt;.Disconnect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Force la fermeture de la connexion vers un serveur Redis (ou un cluster Redis).

Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"
SI gRedis.Connecte() ALORS
    gRedis.Déconnecte()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Connexion>.Déconnecte()`
---

**`<Connexion> : (Variable de type redisConnexion)`**

Nom de la variable de type [redisConnexion](../WDLang4/1000023527.md) correspondant à la connexion au serveur Redis.
