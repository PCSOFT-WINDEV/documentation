


## HListeHistoriquePlanification (Fonction)

***En anglais : HListSchedulingHistory***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Liste l'historique d'exécution d'une opération planifiée sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonTableau est un tableau de hHistoriquePlanification
MonTableau = HListeHistoriquePlanification(MaConnexionBase, MaTachePlanifiée)
SI ErreurDétectée = Vrai ALORS
	Trace(HErreurInfo())
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Lister l'historique d'exécution d'une planification de sauvegarde

`<Résultat> = HListeHistoriquePlanification(<Connexion> [, <Planification de sauvegarde> [, <Nombre d'éléments>]])`
---

**`<Résultat> : (Tableau de variables de type hHistoriquePlanification)`**

Tableau de variables de type [hHistoriquePlanification](../WDLang4/1410090764.md), correspondant aux différentes exécutions de la sauvegarde planifiée.

**`<Connexion> : (Chaîne de caractères ou variable de type Connexion)`**

Connexion à manipuler. Cette connexion correspond : 

- soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](../WDLang4/3044205.md) ou [HOuvreConnexion](../WDLang4/3044107.md).

- soit au nom d'une variable de type [Connexion](../WDLang4/1514073.md). 




**`<Planification de sauvegarde> : (Variable de type hDescriptionSauvegarde optionnelle)`**

Nom de la variable de type [hDescriptionSauvegarde](../WDLang4/1000017455.md) pour laquelle l'historique doit être listé. Si ce paramètre n'est pas précisé, le résultat correspondra à l'historique d'exécution de toutes les planifications de sauvegarde définies pour la connexion.

**`<Nombre d'éléments> : (Entier optionnel)`**

Nombre maximum d'éléments de l'historique à lister. 
Remarque : Par défaut, 100000 éléments sont stockés dans l'historique. Il est possible de modifier cette limite soit avec la fonction [HGèreServeur](../WDLang4/3044359.md), soit via le fichier [HFCONF.INI](../WDLang4/3044345.md).
