
## RechercheSémantique (Fonction)

***En anglais : SemanticSearch***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Parcourt un index sémantique.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Parcours d'un fichier de données avec une recherche sémantique par rapport à un vecteur
data est un tableau de réels = [0.1, 0.1, 0.1, 0.1]
mon_vec est un iaVecteurSémantique = IACréeVecteurSémantique(data)
POUR CHAQUE FicSemantique, Similarité AVEC RechercheSémantique(RubVecteur, mon_vec, 10, 0.5)
	Trace(FicSemantique.RubText, " : ", Similarité)
FIN
```



```wl
// Parcours d'un fichier de données avec une recherche sémantique par rapport à une chaîne de caractères
POUR CHAQUE FicSemantique, Similarité AVEC RechercheSémantique(RubVecteur, "ma chaîne à rechercher", 10, 0.5)
	Trace(FicSemantique.RubText, " : ", Similarité)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

### Recherche d'un vecteur sémantique

`<Résultat> = RechercheSémantique(<Index sémantique> , <Valeur recherchée> , <Maximum> [, <Seuil de similarité>])`
---

**`<Résultat> : (Chaîne de caractères)`**

Résultat attendu par la boucle de parcours POUR TOUT/POUR CHAQUE. 

**`<Index sémantique> : (Chaîne de caractères)`**

Rubrique clé sémantique du fichier de données. 

**`<Valeur recherchée> : (Variable de type iaVecteurSémantique)`**

Valeur recherchée dans le fichier de données. Cette valeur est une variable de type iaVecteurSémantique.

**`<Maximum> : (Entier)`**

Nombre maximum d'éléments à renvoyer. 

**`<Seuil de similarité> : (Réel optionnel)`**

Si la valeur de similarité est inférieur à ce paramètre, l'enregistrement ne sera pas renvoyé. 


<a name="SYNTAXE2"></a>

### Recherche d'une collection de vecteurs sémantiques

`<Résultat> = RechercheSémantique(<Index sémantique> , <Valeur recherchée> , <Max> [, <Seuil de similarité>])`
---

**`<Résultat> : (Chaîne de caractères)`**

est de type Type exécution

**`<Index sémantique> : (Chaîne de caractères)`**

est de type Rubrique clé sémantique

**`<Valeur recherchée> : (Variable de type iaCollectionVecteurSémantique)`**

est de type Interface iaCollectionVecteurSémantique

**`<Max> : (Entier)`**

est de type Entier32

**`<Seuil de similarité> : (Réel optionnel)`**

est de type Réel


<a name="SYNTAXE3"></a>

### Recherche d'une chaîne de caractères

`<Résultat> = RechercheSémantique(<Index sémantique> , <Valeur recherchée> , <Max> [, <Seuil de similarité>])`
---

**`<Résultat> : (Chaîne de caractères)`**

est de type Type exécution

**`<Index sémantique> : (Chaîne de caractères)`**

est de type Rubrique index sémantique

**`<Valeur recherchée> : (Chaîne de caractères)`**

est de type Chaîne U compat A courant ptr (ex : données de l'utilisateur ; sans 0 binaire)

**`<Max> : (Entier)`**

est de type Entier32

**`<Seuil de similarité> : (Réel optionnel)`**

est de type Réel
