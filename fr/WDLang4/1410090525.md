


## &lt;Variable PolygoneGéo&gt;.Couvre (Fonction)

***En anglais : &lt;PolygonGeo variable&gt;.Cover***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une géométrie A de type polygone géographique couvre une géométrie B. 

Remarques : 

- Si la géométrie A couvre la géométrie B, tout point de la géométrie B se trouve à l'intérieur ou dans le contour de la géométrie A. Dans ce cas, il n'existe aucun point de la géométrie B à l'extérieur de la géométrie A.

- Différence par rapport à la fonction [&lt;Variable PolygoneGéo&gt;.Contient](../WDLang4/1410090521.md) : Avec la fonction **&lt;Variable PolygoneGéo&gt;.Couvre**, il n'est pas nécessaire d'avoir un point de l'intérieur de la géométrie B à l'intérieur de la géométrie A. Ainsi, un polygone couvre son contour, mais il ne le contient pas.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
polyGeo est un PolygoneGéo
polyGeo.Contour.AjoutePoint(0n48.8187479172765, 0n1.9550104465229536)
polyGeo.Contour.AjoutePoint(0n48.685649220185574, 0n2.023674998054354)
polyGeo.Contour.AjoutePoint(0n48.82612543243871, 0n2.2106580854197566)
polyGeo = polyGeo.Corrige()

polyGeo1 est un PolygoneGéo
polyGeo1.Contour.AjoutePoint(0n45.8187479172765, 0n1.9550104465229536)
polyGeo1.Contour.AjoutePoint(0n45.685649220185574, 0n2.023674998054354)
polyGeo1.Contour.AjoutePoint(0n45.82612543243871, 0n2.2106580854197566)
polyGeo1 = polyGeo1.Corrige()

Trace(polyGeo.Couvre(polyGeo1))
Trace(polyGeo1.Couvre(polyGeo))
```

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.Couvre(<Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie A couvre la géométrie B, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable de type PolygoneGéo)`**

Nom de la variable de type [PolygoneGéo](../WDLang4/1410090127.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).

## Remarques


### Parcours des données spatiales : utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000339"></a>Il est possible d'effectuer un parcours sur un fichier de données avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **&lt;Variable PolygoneGéo&gt;.Couvre**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante : 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où : 

- Fonction_WLangage correspond à la fonction **&lt;Variable PolygoneGéo&gt;.Couvre**. 

- Rubrique_spatiale correspond à une rubrique spatiale du fichier de données. Cette rubrique doit : 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque : Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, tout le fichier de données est parcouru : les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
