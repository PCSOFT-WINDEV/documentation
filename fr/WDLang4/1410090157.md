


## GéométrieCorrige (Fonction)

***En anglais : GeometryCorrect***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet d'obtenir une version corrigée de la géométrie spécifiée. 

**Remarque** : Dans certains cas, il est possible de corriger automatiquement un certain nombre de problèmes dans une géométrie, tels que, par exemple, une mauvaise orientation des points dans un polygone. 


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
// Correction d'un triangle dont les points du contour sont disposés 
// dans le sens inverse des aiguilles d'une montre
triangle est un Polygone2D
Polyligne2DAjoutePoint(triangle.Contour, -3.00, 1.00)
Polyligne2DAjoutePoint(triangle.Contour, 1.00, -2.00)
Polyligne2DAjoutePoint(triangle.Contour, 2.00, 2.00)
Polyligne2DAjoutePoint(triangle.Contour, -3.00, 1.00)
Trace("GéométrieEstValide(triangle) = " + GéométrieEstValide(triangle)) // Affiche "Faux"

// Correction
triangle_corrigé est un Polygone2D
triangle_corrigé = GéométrieCorrige(triangle)
Trace("GéométrieEstValide(triangle_corrigé) = " + GéométrieEstValide(triangle_corrigé)) // Affiche "Vrai"
Trace("GéométrieEstValide(triangle) = " + GéométrieEstValide(triangle)) 
// Affiche toujours "Faux" : la géométrie donnée en paramètre n'est pas modifiée
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = GéométrieCorrige(<Géométrie>)`
---

**`<Résultat> : (Variable correspondant à la géométrie manipulée)`**

Géométrie corrigée. 

**`<Géométrie> : (Variable correspondant à des données spatiales)`**

Géométrie à corriger, potentiellement incorrecte. Ce paramètre n'est pas modifié par la fonction. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).
