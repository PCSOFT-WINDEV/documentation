


## HSourceDeDonnéesConnue (Fonction)

***En anglais : HDataSourceKnown***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une source de données est initialisée. Cette fonction permet d'éviter une erreur du type "Vous avez appelé la fonction XXX. La source de données YYY n'est pas initialisée". 

**Différence avec la fonction [HRequêteExécutée](../WDLang4/1410090242.md)** : La fonction **HSourceDeDonnéesConnue** permet de savoir si la source de données est connue du moteur HFSQL, quelque soit son contenu. La fonction [HRequêteExécutée](../WDLang4/1410090242.md) est utilisable uniquement sur les requêtes. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaVue est une Source de Données
// MaVue est associée à une vue

SI HSourceDeDonnéesConnue(MaVue) = Faux ALORS
	// Initialisation de la variable MaVue 
	HCréeVue(MaVue, CLIENT, "*", "NOM,VILLE", "NOM]='A'", hVueDéfaut)
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HSourceDeDonnéesConnue(<Source de données à vérifier>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la source de données a été initialisée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Source de données à vérifier> : (Source de Données)`**

Variable de type [Source de Données](../WDLang4/1514053.md) à vérifier. Cette source de données peut correspondre à : 

- un fichier de données externe, 

- une requête SQL, 

- une vue. 






<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques


### Comment initialiser une variable de type Source de Données
<a name="comment_initialiser_une_variable_type_source_donnees_ELTPARAGRAPHE000076"></a>L'initialisation d'une variable de type Source de Données dépend de son contenu : 

- Fichier de données externe : il est nécessaire d'utiliser la fonction [HDéclareExterne](../WDLang4/3044204.md). 

- Requête et requête SQL : il est nécessaire d'utiliser les fonctions [HExécuteRequête](../WDLang4/3044080.md), [HExécuteRequêteSQL](../WDLang4/3044084.md), etc. 

- Vue HFSQL : Il est nécessaire d'utiliser la fonction [HCréeVue](../WDLang4/3044159.md). 




Pour plus de détails, consultez l'aide du type [Source de Données](../WDLang4/1514053.md).
