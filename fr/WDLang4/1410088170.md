


## RedisAffecte (Fonction)

***En anglais : RedisSet***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Modifie la valeur d'une clé sur un serveur Redis. 

Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"

RedisAffecte(gRedis, "MaClé", "MaValeur", 1h)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`RedisAffecte(<Connexion> , <Clé> , <Valeur> [, <Durée de validité>])`
---

**`<Connexion> : (Variable de type redisConnexion)`**

Nom de la variable de type [redisConnexion](../WDLang4/1000023527.md) correspondant à la connexion au serveur Redis.

**`<Clé> : (Chaîne de caractères ou Chaîne secrète)`**

Nom de la clé à affecter.
**Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](../Editeurs/1410087353.md). 

**`<Valeur> : (Chaîne de caractères)`**

Nouvelle valeur de la clé. Cette nouvelle valeur peut être une chaîne au format UTF8, Unicode ou binaire. 

**`<Durée de validité> : (Durée optionnelle)`**

Durée de validité de la clé en millisecondes. Ce paramètre peut correspondre à :

- un entier correspondant au nombre de millisecondes,

- une variable de type Durée,

- l'indication directe de la durée (par exemple 1 s).
