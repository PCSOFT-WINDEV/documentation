


## GéométrieEstValide (Fonction)

***En anglais : GeometryIsValid***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Vérifie si la géométrie spécifiée est valide au sens de la norme OGC.


<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
monPoly est un Polygone2D = FichierCommune.RubriquePolygone
// => Vrai ou Faux selon que la variable monPoly est valide : 
// points dans le bon ordre, 
// pas d'intersections du contour et des trous du polygone, etc.
Trace(GéométrieEstValide(monPoly))
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = GéométrieEstValide(<Géométrie>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie est valide, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire.


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la géométrie à vérifier. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).
