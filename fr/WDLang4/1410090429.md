


## &lt;Variable Connexion&gt;.ListeFichiersSurveillés (Fonction)

***En anglais : &lt;Connection variable&gt;.ListWatchedFiles***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Renvoie la liste des fichiers de données surveillés par la fonction [&lt;Source&gt;.Surveille](../WDLang4/1000025029.md).

Attention : 

- Cette fonction est utilisable uniquement en mode Client/Serveur. 

- La liste des fichiers de données surveillés correspond à la liste au moment de l'exécution de la fonction. Si des fichiers de données ne sont plus surveillés (fonction [&lt;Source&gt;.SurveilleStop](../WDLang4/1000025030.md)), ils n'apparaîtront pas dans la liste.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaConnexion est une Connexion
MesFichiersSurveillés est un tableau de chaînes
MesFichiersSurveillés = MaConnexion.ListeFichiersSurveillés()
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Connexion>.ListeFichiersSurveillés()`
---

**`<Résultat> : (Tableau WLangage)`**

Tableau de chaînes contenant les différents fichiers de données surveillés.

**`<Connexion> : (Variable de type Connexion)`**

Nom d'une variable de type [Connexion](../WDLang4/1514073.md) correspondant à la connexion manipulée.
