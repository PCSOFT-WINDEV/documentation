


## Constantes de gestion des données spatiales
			



<a name="NOTE1"></a>
<a name="NOTE1_1"></a>
Les constantes de gestion des données spatiales sont les suivantes :

| Constante | Détail | Type de variable |
| --- | --- | --- |
| **tgInvalide** | Type de la géométrie en cours : Type invalide.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfInvalide*. | Variable de type [Géométrie](../WDLang4/1410090098.md) |
| **tgMultiGéométrie** | Type de la géométrie en cours : Ensemble de géométries.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiForme*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiGéométrie](../WDLang4/1410090298.md) |
| **tgMultiPoint2D** | Type de la géométrie en cours : Type MultiPoint2D.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPoint2D*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiPoint2D](../WDLang4/1410090129.md) |
| **tgMultiPointGéo** | Type de la géométrie en cours : Type MultiPointGéo.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPointGéo*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiPointGéo](../WDLang4/1410090130.md) |

| **tgMultiPolygoneGéo** | Type de la géométrie en cours : Type MultiPolygoneGéo.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPolygoneGéo*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiPolygoneGéo](../WDLang4/1410090136.md) |
| **tgMultiPolyligne2D** | Type de la géométrie en cours : Type MultiPolyligne2D.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPolyligne2D*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiPolyligne2D](../WDLang4/1410090131.md) |
| **tgMultiPolyligneGéo** | Type de la géométrie en cours : Type MultiPolyligneGéo.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPolyligneGéo*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [MultiPolyligneGéo](../WDLang4/1410090133.md) |
| **tgPoint2D** | Type de la géométrie en cours : Type Point2D.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPoint2D*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [Point2D](../WDLang4/1410090100.md) |
| **tgPointGéo** | Type de la géométrie en cours : Type PointGéo.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPointGéo*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [PointGéo](../WDLang4/1410090102.md) |
| **tgPolygone2D** | Type de la géométrie en cours : Type Polygone2D.<br>Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPolygone2D*. | Variable de type [Géométrie](../WDLang4/1410090098.md), Variable de type [Polygone2D](../WDLang4/1410090122.md) |
