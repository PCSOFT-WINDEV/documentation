


## GéométrieContient (Fonction)

***En anglais : GeometryContain***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une géométrie A contient une géométrie B. <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=FormeContient.gif)
**Remarques** : 

- Si la géométrie A contient la géométrie B, cela signifie que la géométrie B est complètement dans la géométrie A. Dans ce cas : 

	- Il n'existe pas de point de la géométrie B dans l'extérieur de la géométrie A : tout point de la géométrie B est soit dans l'intérieur de la géométrie A, soit dans son contour.

	- Il existe au moins un point de l'intérieur de la géométrie B dans l'intérieur de la géométrie A.




- Différence par rapport à la fonction [GéométrieCouvre](../WDLang4/1410090140.md) : Avec la fonction [GéométrieCouvre](../WDLang4/1410090140.md), il n'est pas nécessaire d'avoir un point de l'intérieur de géométrie B à l'intérieur de géométrie A. Un polygone couvre son contour, mais il ne le contient pas.

## Exemple


```wl
oPolygone2D_1 est un Polygone2D
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, -4.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, 2.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, 5.00, 2.00)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, 5.00, -4.00)
// Ajout du dernier point (identique au premier)
Polyligne2DAjoutePoint(oPolygone2D_1.Contour, -4.00, -4.00)

oPolygone2D_2 est un Polygone2D
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, -1.00, -2.00)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, 2.00, 0.00)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, 2.00, -2.00)
// Ajout du dernier point (identique au premier)
Polyligne2DAjoutePoint(oPolygone2D_2.Contour, -1.00, -2.00)

soit p2_dans_p1 = GéométrieContient(oPolygone2D_1, oPolygone2D_2) // Renvoie "vrai"
GéométrieEstContenu(oPolygone2D_2, oPolygone2D_1) // Renvoie "vrai"
```

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = GéométrieContient(<Géométrie A> , <Géométrie B>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la géométrie A contient la géométrie B,

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire. 


En cas d'erreur, la variable [ErreurDétectée](../WDLang1/3087001.md) est à <u><u><u><u>Vrai</u></u></u></u>. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](../WDLang1/3013008.md) avec la constante *errMessage*.

**`<Géométrie A> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la géométrie dont on veut savoir si elle contient la géométrie B. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).




**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

## Remarques


### Parcours des données spatiales : utilisation des index spatiaux
<a name="parcours_des_donnees_spatiales_utilisation_des_index_spatiaux_ELTPARAGRAPHE000351"></a>Il est possible d'effectuer un parcours sur un fichier de données avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **GéométrieContient**.

Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante : 

```txt
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où : 

- Fonction_WLangage correspond à la fonction **GéométrieContient**. 

- Rubrique_spatiale correspond à une rubrique spatiale du fichier de données. Cette rubrique doit : 

	- être de type "Données géographiques" ou de type "Données géométriques".   

	- être définie comme une "Clé spatiale". 




- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.   




Remarque : Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, tout le fichier de données est parcouru : les index spatiaux ne sont pas utilisés. 

```txt
POUR TOUT Fichier 
	SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS
    ...
    FIN
FIN
```
Exemple : 

```wl
// Définition d'un triangle délimitant une zone géographique
// Mémorisation de ce triangle dans une variable de type PolygoneGéo 
polyGeo est un PolygoneGéo
PolyligneGéoAjoutePoint(polyGeo.Contour, 0n48.8187479172765, 0n1.9550104465229536)
PolyligneGéoAjoutePoint(polyGeo.Contour, 0n48.685649220185574, 0n2.023674998054354)
PolyligneGéoAjoutePoint(polyGeo.Contour, 0n48.82612543243871, 0n2.2106580854197566)
polyGeo = GéométrieCorrige(polyGeo)
// Recherche les communes ayant leur territoire contenu entièrement dans le triangle ciblé
nbEnregs est un entier
POUR CHAQUE DatasCommunes AVEC GéométrieContient(DatasCommunes.geometry, polyGeo) 
	// Nom de la commune dans une trace
	Trace(DatasCommunes.NomCommune)
FIN
```
