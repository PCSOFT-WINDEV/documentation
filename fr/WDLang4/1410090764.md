
## hHistoriquePlanification (Type de variable)

***En anglais : hSchedulingHistory***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Le type **hHistoriquePlanification** permet de connaître toutes les caractéristiques de l'historique de l'exécution d'une opération planifiée : optimisation, sauvegarde, etc. Ces caractéristiques peuvent être connues à l'aide de différentes propriétés WLangage. 

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
monHistorique est un hHistoriquePlanification
```

## Propriétés


### Propriétés WLangage utilisables avec le type hHistoriquePlanification
<a name="proprietes_wlangage_utilisables_avec_type_hhistoriqueplanification_ELTPARAGRAPHE000026"></a>Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hHistoriquePlanification** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateDébut | DateHeure | Date et Heure de début de l'exécution de l'opération planifiée.<br>**Cette propriété est disponible en lecture seulement**. |
| DateFin | DateHeure | Date et Heure de fin de de l'exécution de l'opération planifiée.<br>**Cette propriété est disponible en lecture seulement**. |
| Erreur | Chaîne de caractères | Erreur rencontrée (si la propriété **Etat** correspond à la constante *hExecPlanificationErreur*). |
| Etat | Entier | Etat de l'exécution de l'opération planifiée : <br><br>- *hExecPlanificationAnnulée* : L'exécution de l'opération planifiée a été annulée. <br><br>- *hExecPlanificationEnCours* : L'exécution de l'opération planifiée est en cours. <br><br>- *hExecPlanificationErreur* : L'exécution de l'opération planifiée est en erreur. <br><br>- *hExecPlanificationTerminée* : L'exécution de l'opération planifiée est terminée.<br><br><br><br><br>**Cette propriété est disponible en lecture seulement**. |
| Identifiant | Entier | Identifiant de l'exécution de l'opération planifiée. <br>**Cette propriété est disponible en lecture seulement**. |
| LancementManuel | Booléen | <br><br>- <u><u><u>Vrai</u></u></u> si l'exécution de l'opération planifiée a été lancée manuellement (c'est-à-dire via une fonction WLangage ou via le Centre de Contrôle HFSQL), <br><br>- <u><u><u>Faux</u></u></u> dans la cas contraire. <br><br><br>**Cette propriété est disponible en lecture seulement**. |
| Type | Entier | Opération planifiée exécutée : <br><br>- *hlpOptimisation* : Optimisation des fichiers de données.<br><br>- *hlpSauvegardeComplète* : Sauvegarde complète. <br><br>- *hlpSauvegardeDifférentielle* : Sauvegarde différentielle. <br><br>- *hlpTâche* : Tâche planifiée.<br><br>- *hlpVueMatérialisée* : Rafraîchissement d'une vue matérialisée.<br><br><br><br><br>**Cette propriété est disponible en lecture seulement**. |
| Utilisateur | Chaîne de caractères | <br><br>- Si l'exécution a été réalisée automatiquement, utilisateur ayant créé l'opération planifiée. <br><br>- Si l'exécution a été réalisée manuellement, utilisateur ayant exécuté l'opération planifiée. <br><br><br>**Cette propriété est disponible en lecture seulement**. |
