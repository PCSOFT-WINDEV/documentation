


## &lt;Variable Polygone2D&gt;.DifférenceSymétrique (Fonction)

***En anglais : &lt;Polygon2D variable&gt;.SymmetricDifference***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Calcule la différence symétrique entre un polygone en 2 dimensions et une autre géométrie. Cette opération est commutative.

Exemple : <br>![Géométries A et B de départ](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Spatial_DifferenceS_Avant.png)

<br>![Résultat de la différence symétrique](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=Spatial_DifferenceS_Apres.png)

<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(2.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, 2.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(2.00, 2.00)
// Corrige la géométrie créée
oPolygone2D_1 = oPolygone2D_1.Corrige()

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
oPolygone2D_2.Contour.AjoutePoint(3.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(1.00, -1.00)
oPolygone2D_2.Contour.AjoutePoint(1.00, 1.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(3.00, 1.00)
// Corrige la géométrie créée
oPolygone2D_2 = oPolygone2D_2.Corrige()

// La différence symétrique correspond à un MultiPolygone2D
// La différence symétrique de deux polygones renvoie toujours un MultiPolygone
différence_symétrique est un MultiPolygone2D = oPolygone2D_1.DifférenceSymétrique(oPolygone2D_2)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Géométrie A>.DifférenceSymétrique(<Géométrie B>)`
---

**`<Résultat> : (Variable de type MultiPoint2D, MultiPointGéo, MultiPolyligne2D, MultiPolyligneGéo, MultiPolygone2D ou MultiPolygoneGéo)`**

Résultat de la différence symétrique. Cette géométrie contient une collection de géométries d'un type donné : 

- [MultiPoint2D](../WDLang4/1410090129.md) ou [MultiPointGéo](../WDLang4/1410090130.md), 

- [MultiPolyligne2D](../WDLang4/1410090131.md) ou [MultiPolyligneGéo](../WDLang4/1410090133.md), 

- [MultiPolygone2D](../WDLang4/1410090135.md) ou [MultiPolygoneGéo](../WDLang4/1410090136.md). 


Si la différence symétrique entre deux géométries est constituée d'un seul élément, la collection contiendra un seul élément.
Si la différence symétrique est vide (par exemple en calculant la différence d'une géométrie avec elle-même), la collection est vide. 
Si le résultat de la différence symétrique est disjoint (par exemple en coupant un polygone en deux avec un autre polygone), la collection contient plusieurs éléments.

**`<Géométrie A> : (Variable de type Polygone2D)`**

Nom de la variable de type [Polygone2D](../WDLang4/1410090122.md) à manipuler.

**`<Géométrie B> : (Variable correspondant à des données spatiales)`**

Géométrie soustraite à la géométrie A. Cette géométrie peut correspondre à un des types de variables suivants :  

- [PointGéo](../WDLang4/1410090102.md).

- [Point2D](../WDLang4/1410090100.md).

- [PolyligneGéo](../WDLang4/1410090128.md).

- [Polyligne2D](../WDLang4/1410090109.md).

- [PolygoneGéo](../WDLang4/1410090127.md).

- [Polygone2D](../WDLang4/1410090122.md).

- [MultiPointGéo](../WDLang4/1410090130.md).

- [MultiPoint2D](../WDLang4/1410090129.md).

- [MultiPolyligneGéo](../WDLang4/1410090133.md).

- [MultiPolyligne2D](../WDLang4/1410090131.md).

- [MultiPolygoneGéo](../WDLang4/1410090136.md).

- [MultiPolygone2D](../WDLang4/1410090135.md).
