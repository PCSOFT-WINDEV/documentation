
## HFSQL : Recherche sémantique HFSQL
			

<a name="NOTE1"></a>
<a name="NOTE1_1"></a>


## Présentation
<a name="presentation_ELTTEXTE000169"></a>
En version 2026, le serveur HFSQL intègre un moteur d'intelligence artificielle capable de réaliser des recherches sur le sens des mots : des recherches sémantiques.

Prenons un exemple simple : sur un site de vente en ligne de vêtements, l'internaute cherche "manteau".
Grâce à la recherche sémantique, le site propose automatiquement les manteaux mais aussi, les vestes, coupe-vent, parkas, anoraks, doudounes,etc. 

Plus besoin de prévoir en base de données tous les synonymes, toutes les correspondances de mots, etc. Avec les index sémantiques, les utilisateurs trouvent toujours ce qu'ils cherchent !

## La recherche sémantique HFSQL : comment ça marche ?
<a name="recherche_semantique_hfsql_comment_marche_ELTTEXTE000193"></a>
La recherche sémantique de HFSQL s'appuie sur un modèle d'IA intégré au serveur HFSQL.

Ce modèle permet de convertir du texte en un vecteur mathématique qui sera utilisé pour la recherche : c'est **l'embedding**.

Chaque mot, chaque phrase est transformé en un ensemble de réels : un vecteur.

La recherche sémantique fait une recherche de proximité des vecteurs. Plus les vecteurs sont proches, plus le sens global sera le même.

Par exemple : "pomme", "poire" et "orange" sont sémantiquement proches car ce sont tous des fruits ! Donc leurs vecteurs sont  également proches.

## Comment mettre en place une recherche sémantique
<a name="comment_mettre_place_une_recherche_semantique_ELTTEXTE000217"></a>


### Créer une rubrique de type Index sémantique
<a name="creer_une_rubrique_type_index_semantique_ELTPARAGRAPHE000037"></a>Pour créer une rubrique de type Index sémantique : 

1. Ouvrez l'analyse associée au projet. 

2. Sélectionnez le fichier de données dans lequel l'index sémantique doit être ajouté. 

3. Affichez la description des rubriques (option "Description des rubriques" du menu contextuel du fichier de données). 

4. Ajoutez une rubrique de type "Index sémantique". 

5. Dans la fenêtre qui s'affiche, indiquez les différentes rubriques correspondant à l'index sémantique.<br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=HF_Semantique_Analyse%20-%20HC%20N%B0001.gif)

	Note : l'index sémantique peut indexer les rubriques de type "Texte" ou "Mémo Texte".

6. Validez. 

7. Dans l'onglet "Général" de la description de la rubrique, indiquez les paramètres de l'index sémantique : <br>![](https://doc.pcsoft.fr/fr-FR/images/image.awp?langid=5&name=HF_Semantique_Analyse%20-%20HC%20N%B0002.gif)


	- Paramètres du modèle d'embedding : 
			**Nom du modèle** : Le modèle d'IA intégré au serveur HFSQL HFSQL est le modèle "gte-small.Q5_K_M.gguf". Ce modèle est open source. Ses caractéristiques techniques sont disponibles à l'adresse suivante : 
			"https://huggingface.co/ChristianAzinn/gte-small-gguf".
			Ce modèle sémantique livré par défaut avec le serveur HFSQL fonctionne aussi bien avec des mots en français qu'en anglais.
			Il est également possible d'ajouter d'autres langues, ou encore d'indexer des images, du son, de la vidéo, etc. Il suffit pour cela d'utiliser un **modèle personnalisé** (voir ci dessous) 
			**Conseil d'expert** : 
"Nous avons volontairement opté pour un modèle léger offrant une qualité correcte afin de garantir une compatibilité étendue et un fonctionnement fluide sans nécessiter une infrastructure particulièrement puissante.
Cependant, pour des clients disposant d'une infrastructure robuste et recherchant des performances optimales, il peut être pertinent d'envisager des modèles plus avancés et exigeants."

8. Validez la description des rubriques. 




La recherche sémantique sémantique sera disponible dans les fichiers de données dès que la modification automatique des fichiers de données sera réalisée. 




### Réaliser une recherche sémantique par programmation
<a name="realiser_une_recherche_semantique_par_programmation_ELTPARAGRAPHE000087"></a>Pour effectuer une recherche sémantique par programmation, il suffit d'utiliser l'instruction POUR TOUT associée à la fonction WLangage [RechercheSémantique](../WDLang4/1410091374.md) via la syntaxe suivante : 

```txt
POUR TOUT <Fichier de données> AVEC RechercheSémantique(<Index sémantique>, <Valeur recherchée>, <Seuil de similarité>)
...
<Traitement de l'enregistrement>
...
FIN
```
où : 

- &lt;Fichier de données&gt; correspond au nom du fichier de données contenant l'index sémantique. 

- &lt;Index sémantique&gt; correspond au nom de la rubrique de l'index sémantique définie pour le fichier de données dans l'éditeur d'analyses. 

- &lt;Seuil de similarité&gt; correspond au nombre maximum de résultats. 




Exemple :

```wl
POUR TOUT produit AVEC RechercheSémantique(Index_Sémantique, SAI_Recherche, 10)
   ...
FIN
```



### Spécifications techniques requises pour la machine serveur HFSQL
<a name="specifications_techniques_requises_pour_machine_serveur_hfsql_ELTPARAGRAPHE000105"></a>Pour que le serveur HFSQL puisse calculer les vecteurs de la recherche sémantique, la machine serveur doit disposer d'un GPU (une carte spécialisée dans le calcul parallèle).
Un GPU compatible Vulkan (version = 1.2) avec prise en charge des Compute Shaders est requis. Les cartes d'entrée de gamme proposées par NVIDIA et AMD offrent généralement de bonnes performances pour ce type d'usage, tandis que les solutions haut de gamme sont principalement dominées par NVIDIA.
Concernant le CPU, il doit être relativement récent (postérieur à 2012) et prendre en charge les jeux d'instructions AVX et AVX2.

PCS Cloud met à votre disposition des serveurs avec GPU sur lesquels vous appuyer pour effectuer l'embedding.


### Modèle personnalisé
<a name="modele_personnalise_ELTPARAGRAPHE000116"></a>Pour utiliser un moèle personnalisé : 

- Ce modèle personnalisé doit obligatoirement être un modèle d'embedding au format gguf. 

- Ce modèle personnalisé peut être spécifié depuis l'éditeur d'analyses ou par programmation via la propriété NomModelEmbedding.

- Ce modèle doit être installé dans le dossier **AI Models** de HFSQL sur le serveur qui héberge le moteur HFSQL. Ensuite dans l’éditeur, il faut indiquer comme nom dans l’analyse le nom du fichier qui a été installé représentant le modèle.
