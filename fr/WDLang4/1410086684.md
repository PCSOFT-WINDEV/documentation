
## HDécritIndexSémantique (Fonction)

***En anglais : HDescribeSemanticIndex***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Décrit un index sémantique d'un fichier de données créé par programmation.

Après l'appel de la fonction **HDécritIndexSémantique** :

- La rubrique peut être manipulée comme n'importe quelle rubrique de l'analyse.

- La description de la rubrique ne peut plus être modifiée.

- La variable de description de la rubrique est ré-initialisée. Une nouvelle description d'index peut être effectuée.



<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonIndexSemantic est une Description d'IndexSémantique
MonIndexSemantic..Nom = "DescriptionSémantique"
MonIndexSemantic..Rubrique[1] = UnFichier.Libellé_produit
MonIndexSemantic..Rubrique[2] = UnFichier.Description_produit

HDécritIndexSémantique(UnFichier, MonIndexSemantic)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = HDécritIndexSémantique(<Fichier de données> , <Index sémantique>)`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si l'opération a été réalisée, 

- <u><u><u><u>Faux</u></u></u></u> en cas de problème. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'identifier l'erreur.




**`<Fichier de données> : (Chaîne de caractères)`**

Nom du fichier de données HFSQL (décrit avec la fonction [HDécritFichier](../WDLang4/3044206.md)).

**`<Index sémantique> : (Variable de type Description d'IndexSémantique)`**

Nom de la variable de type [Description de IndexSémantique](../WDLang4/1410086697.md) contenant la description de l'index sémantique.

## Remarques


### Comment décrire un index sémantique par programmation ? 
<a name="comment_decrire_index_semantique_par_programmation_ELTPARAGRAPHE000063"></a>Pour décrire un index sémantique par programmation, il faut :

1. Utiliser des variables de type [Description de Fichier](../WDLang4/1514065.md), [Description de Rubrique](../WDLang4/1514071.md), [Description de Liaison](../WDLang4/1514039.md), [Description d'IndexFullText](../WDLang4/1000017461.md) et [Description de IndexSémantique](../WDLang4/1410086697.md) (si nécessaire).

2. Décrire les caractéristiques du fichier de données, de ses rubriques, de ses liaisons, de ses index full-text et de ses index sémantiques grâce aux propriétés HFSQL.

3. Fixer la description des rubriques avec la fonction [HDécritRubrique](../WDLang4/3044233.md).

4. Fixer la description des index full-text avec la fonction [HDécritIndexFullText](../WDLang4/1000017407.md).

5. Fixer la description des index sémantiques avec la fonction **HDécritIndexSémantique**.

6. Fixer la description du fichier de données (fonction [HDécritFichier](../WDLang4/3044206.md)) et des liaisons (fonction [HDécritLiaison](../WDLang4/3044191.md)).
