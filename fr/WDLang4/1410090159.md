


## Polyligne2DAjoutePoint (Fonction)

***En anglais : Linestring2DAddPoint***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Ajoute un nouveau point dans une polyligne en 2 dimensions (polyligne géométrique).

**Rappel** : Un polygone en 2 dimensions est un ensemble de polylignes géométriques. 
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MaLigne est une Polyligne2D
// Ajout de points dans la polyligne
Polyligne2DAjoutePoint(MaLigne, 32, 22)
Polyligne2DAjoutePoint(MaLigne, 134, 12)
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`Polyligne2DAjoutePoint(<Polyligne> , <X> , <Y>)`
---

**`<Polyligne> : (Variable de type Polyligne2D)`**

Nom de la variable de type [Polyligne2D](../WDLang4/1410090109.md) dans laquelle des points doivent être ajoutés. 

**`<X> : (Réel)`**

 Coordonnée X du point en 2 dimensions.

**`<Y> : (Réel)`**

Coordonnée Y du point en 2 dimensions.
