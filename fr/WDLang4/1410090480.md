


## &lt;Source&gt;.RequêteExécutée (Fonction)

***En anglais : &lt;Source&gt;.QueryExecuted ***



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Permet de savoir si une requête a été exécutée. Cette fonction peut être notamment utilisée avant de parcourir les résultats de la requête. En effet, si le parcours est effectué sur le résultat d'une requête non exécutée, une erreur WLangage sera affichée. 

**Différence avec la fonction [&lt;Source&gt;.SourceDeDonnéesConnue](../WDLang4/1410090481.md)** : La fonction [&lt;Source&gt;.SourceDeDonnéesConnue](../WDLang4/1410090481.md) permet de savoir si la source de données est connue du moteur HFSQL, quelque soit son contenu. La fonction **&lt;Source&gt;.RequêteExécutée** est utilisable uniquement sur les requêtes.
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
reqStatVols est une Requête SQL =
[
	SELECT * FROM  Vols
	WHERE Vols.IDAéroportDépart = {ParamIDAéroportDépart}
	AND Vols.IDAéroportArrivée = {ParamIDAéroportArrivée}
]
reqStatVols.ParamIDAéroportDépart = 12
reqStatVols.ParamIDAéroportArrivée = 2

SI PAS reqStatVols.RequêteExécutée() ALORS
	reqStatVols.ExécuteRequêteSQL()
FIN
```

<a name="XSYNTAXE"></a>

## Syntaxe
<a name="SYNTAXE1"></a>

`<Résultat> = <Requête à vérifier>.RequêteExécutée()`
---

**`<Résultat> : (Booléen)`**



- <u><u><u><u>Vrai</u></u></u></u> si la requête a déjà été exécutée, 

- <u><u><u><u>Faux</u></u></u></u> dans le cas contraire ou si le paramètre &lt;Requête à vérifier&gt; ne correspond pas à une requête. La fonction [HErreurInfo](../WDLang4/3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.




**`<Requête à vérifier> : (Nom de requête)`**

Nom de la requête à vérifier. Ce paramètre peut correspondre à : 

- Nom et chemin complet de la requête (fichier ".WDR").

- Nom logique de la requête.

- Nom d'une variable de type [Requête SQL](../Motscles/1514082.md).


Si ce paramètre ne correspond pas au nom d'une requête, &lt;Résultat&gt; correspondra à <u><u><u><u>Faux</u></u></u></u>.



<a name="NOTE0"></a>
<a name="NOTE0_1"></a>

## Remarques
Les requêtes de type "INSERT", "DELETE" et "CREATE" ne sont parcourables que si elles contiennent l'ordre SQL "RETURNING".
