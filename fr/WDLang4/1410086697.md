
## Description de IndexSémantique (Type de variable)

***En anglais : IndexSemantique description***
			
				



<a name="XUtilisation"></a>
<a name="Utilisation"></a>
<a name="description"></a>
Une variable de type **Description de IndexSémantique** permet de décrire par programmation un ou plusieurs index sémantiques. Les caractéristiques de ce type peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. 

Pour ajouter la description de cet index dans la description d'un fichier de données, utilisez la fonction [HDécritIndexSémantique](../WDLang4/1410086684.md). La variable de type "Description d'IndexSémantique" est alors réinitialisée et pourra être utilisée pour décrire un autre index sémantique par programmation.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](../Motscles/1514032.md).
<a name="Exemple1"></a>
<a name="sample_code"></a>

## Exemple


```wl
MonIndexSemantic est une Description d'IndexSémantique
MonIndexSemantic..Nom = "DescriptionSémantique"
MonIndexSemantic..Rubrique[1] = UnFichier.Libellé_produit
MonIndexSemantic..Rubrique[2] = UnFichier.Description_produit

HDécritIndexSémantique(UnFichier, MonIndexSemantic)
```

## Remarques


### Propriétés spécifiques à la description d'un index sémantique
<a name="proprietes_specifiques_description_index_semantique_ELTPARAGRAPHE000066"></a>Les propriétés spécifiques à la description d'un index sémantique sont détaillées dans le tableau suivant :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| HnswEfConstruction | Entier | Paramètres du Hierarchical Navigable Small World (Hnsw). <br><br>Nombre de voisins lors de l'insertion (EfConstruction). Cette propriété influence la qualité de l'index. <br>Lors de l'insertion d'une valeur, l'algorithme d'insertion explore le graphe des valeurs pour trouver la position d'insertion optimale. <br><br>Cette propriété correspond au nombre de voisins à explorer pour faire l'insertion. <br><br>Plus la valeur de cette propriété est grande, plus l'insertion sera précise. L'index gagnera en qualité mais le temps d'insertion sera plus long. <br><br>Par défaut, cette propriété a pour valeur 64. Ce nombre est un compromis entre performance et précision. |
| HnswM | Entier | Paramètres du Hierarchical Navigable Small World. <br><br>Nombre de voisins maximal (M). Cette propriété influence la pertinence du résultat. Plus le nombre est élevé, plus le résultat est précis et pertinent. Cependant, le temps de calcul sera plus long. <br><br>Par défaut, cette propriété a pour valeur 10. Ce nombre est un compromis entre performance et précision. |
| Nom | Chaîne de caractères | Propriété obligatoire permettant de définir et de connaître le nom de la rubrique de type index sémantique. |
| NomModelEmbedding | Chaîne de caractères | Modèle d'IA à utiliser. Cette propriété permet notamment d'utiliser un modèle d'IA personnalisé. <br><br>Par défaut, le modèle d'IA intégré au serveur HFSQL HFSQL est le modèle "gte-small.Q5_K_M.gguf". Ce modèle est open source. Ses caractéristiques techniques sont disponibles à l'adresse suivante : <br>"https://huggingface.co/ChristianAzinn/gte-small-gguf".<br>Ce modèle sémantique livré par défaut avec le serveur HFSQL fonctionne aussi bien avec des mots en français qu'en anglais. |
| Rubrique | Tableau de chaîne de caractères | Permet de définir et de connaître les différentes rubriques composant l'index full-text. |




<a name="NOTE0_2"></a>


### Comment décrire des fichiers de données par programmation ? 
<a name="comment_decrire_des_fichiers_donnees_par_programmation_ELTPARAGRAPHE000131"></a>Pour décrire des fichiers de données par programmation, il faut :

1. Déclarer des variables de type "[Description de Fichier](../WDLang4/1514065.md)", "[Description de Rubrique](../WDLang4/1514071.md)", "**Description d'IndexFullText**" et "[Description de Liaison](../WDLang4/1514039.md)" (si nécessaire).

2. Pour chaque fichier de données :

	- Décrire les caractéristiques du fichier de données grâce aux [propriétés HFSQL](../Proprietes/2512070.md).

	- Décrire les caractéristiques des rubriques grâce aux [propriétés HFSQL](../Proprietes/2512070.md).

	- Valider la description de chaque rubrique (fonction [HDécritRubrique](../WDLang4/3044233.md)).

	- Décrire si nécessaire les caractéristiques des index full-text grâce aux [propriétés HFSQL](../Proprietes/2512070.md).

	- Valider la description de chaque index full-text (fonction [HDécritIndexFullText](../WDLang4/1000017407.md)).

	- Valider la description du fichier de données (fonction [HDécritFichier](../WDLang4/3044206.md)).




3. Décrire si nécessaire les caractéristiques des liaisons grâce aux [propriétés HFSQL](../Proprietes/2512070.md).

4. Valider si nécessaire la description de chaque liaison (fonction [HDécritLiaison](../WDLang4/3044191.md)).
